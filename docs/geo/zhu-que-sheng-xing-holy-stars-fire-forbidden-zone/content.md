# 第八卷 联盟隐秘 第1027章 朱雀圣星

## 一、联盟星域的「死亡禁地」

- 在**联盟星域**深处，有几处不多的、连**修真联盟**都无法掌控的地域。
- 联盟庞大组织内的一切修士都无法踏入半步，一旦踏入立刻面临灭顶之灾，没有半点幸存可能。
- **净涅**修士亦闻风丧胆，不敢越雷池半步；**除非修为达到碎涅，方可有胆量踏入**，但同样需格外谨慎，往往一念之差便形神俱灭。
- 这几处地域在修真联盟内被称为**「死亡禁地」**。凡联盟内修为达到**第二步**者，都会或多或少知晓此事。
- 外界传闻很多，真正知晓其中因果者却不多。

## 二、永恒燃烧的火海

- 禁地之一常年被浓浓火焰燃烧，火焰成海、弥漫星域，火光明暗不定，高温与热浪令观者颤抖。
- 这一幕终生难忘，「即便是轮回，也无法磨灭」瞳孔内映照赤红火焰的记忆。
- **性质辨析**：此火海与**仙帝青霖**的**焚天之术**不同——焚天之术乃至极神通，而这火海**自然而生**。
- **年代**：传说仙界存在之时此火海便已拥有，追溯**远古时期**似乎也已存在。无人知晓它燃烧了多少岁月：修士代代交替、仙界遇劫崩溃、远古上古流逝，火焰却如永恒般始终燃烧。亦无人知晓是何种力量、何种规则使其无始无终、从不熄灭。

## 三、朱雀之地与朱雀圣星（地理结构）

| 层级 | 名称 | 要点 |
|---|---|---|
| 星域 | **朱雀之地** | 位于联盟星域深处，死亡禁地之一，全域为火的世界 |
| 星球群 | **朱雀圣星**（九颗） | 无数年燃烧下其余星球与尘埃尽消，只剩九颗**连珠成圆**；皆已不完整，**如月牙般存在** |
| 首星 | **第一朱雀圣星** | 九星以其为尊 |

### 第一圣星环境
- 无海洋（即便早年有，也早已蒸发，只留干裂海底）。
- 无任何绿意，植物通体火红、炫目之美下隐藏死亡——能在此环境生存的植物绝非简单。
- 灵气浓郁，但**蕴含火毒**：凡人吸一口，全身连同骨头瞬间成黑灰；修士在火毒下也无法承受太久。

### 朱雀圣像
- 位于第一圣星**正南**，高耸直插九霄的**暗红色巨像**，形为一只展翅欲腾飞的朱雀。
- 尾部散开如升空火焰，弥漫方圆十里；朱雀之身占据方圆数百里，燃烧星空中一眼可见。
- 双目完全由火焰形成，**每隔一个时辰**有浓浓火海自天空云涌凝聚，化作两道融入朱雀之目。
- 其余八颗朱雀圣星上均有一模一样的圣像，**九像**是整个**朱雀圣宗**最巅峰的象征。

## 四、朱雀圣宗的日常修炼

- 圣像下方盘膝坐着数十名身穿**赤红袍**的男女修士，不断吸收四周火焰之力。
- 朱雀尾部分出三系，其上各盘坐**一名老者**（共三人），双手掐诀、口诵奇异之音，使圣像**每一片羽毛都散发火焰**，供下方修士吸收。
- 层级分布：最内数十人 → 数百人 → 外围数千、数万，密密麻麻、统一装束，以圣像为中心环绕吐纳。
- 这是朱雀圣宗**每天必要的修炼**：借圣像吸收火焰之力；火焰渐散、众修收功，即表示一天修行结束。

## 五、本章惊变：圣像火焰暴涨，九星同现

1. 收功之际，最外围已有修士睁眼，众人陆续终止吐纳、恢复神识；尾部三老者亦从入定中苏醒，其中一人起身正要对下方弟子说话。
2. **异变骤起**：朱雀圣像蓦然一震，原本黯淡的全身火焰刹那间暴增赤红之芒，疯狂亮起、不断增长攀升。
3. 三名老者面色大变、毫不犹豫飞出，一人大吼「朱雀圣宗弟子，全部后退——速速后退」；另两人大袖甩动卷起狂风，将地面数十弟子掀至半空令其后撤。
4. 环绕圣像的所有朱雀宗弟子立即退后，自天空俯瞰**如潮水般倒卷**。
5. 圣像火焰更猛，直接滔天弥漫整个天空，向四周疯狂推动，形成**环形扩散的火海浪潮**。
6. **并非孤例**：其余八颗朱雀圣星上几乎**同时**出现同样一幕。
7. **反应分化**：绝大部分朱雀宗之人神色骤变；但一些朱雀圣宗的**老人**看到圣像这一变化后身子颤抖——「这颤抖不是因为害怕，而是激动」。

## 六、待解伏笔

- 火海永恒不灭背后的「力量与规则」，以及朱雀之地成为死亡禁地的真正因果，本章仍未揭示。

# 第950章 朱雀之变

## 一、朱雀之变爆发

- 九颗朱雀圣星上，知晓「朱雀之变」之人（人数不多，但个个修为极高）激动仰望天空。一名白发苍老老者望着朱雀圣像大笑落泪：「老夫有生之年竟然可以看到朱雀之变。」
- 第一圣星朱雀惊变的瞬间，正东方一片紫红色火海中大地崩溃，飞出一名紫红身影——满是皱纹的老者，火海凝聚环绕其身，他望着朱雀惊变浑身颤抖、流泪狂笑。其余八颗圣星同时上演相同一幕。

## 二、九星火柱与朱雀真灵

1. **火焰倒卷**：朱雀圣像本在外推火海，忽然逆转，整颗圣星上所有位置的火焰疯狂倒流回圣像，远看如大海归流。
2. **喷出火柱**：圣像如火山爆发，涌出赤红火柱直冲天际，穿透云层、罡风、热浪，冲出圣星，进入燃烧星域。
3. **九柱汇聚**：其余八星同时各出一道火柱，九道火柱在成圆排列的九颗圣星中央凝聚。
4. **真灵现世**：一声朱雀之音响起，其嘹亮与气势比王林在瓶中界内所闻强大无数倍；随之出现一头堪比一颗修真星大小的朱雀真灵，已无数万年未现。整个燃烧星域（修真联盟忌惮之地）中如永恒般自生的火焰齐齐涌动，掀起震惊星空的呼啸。

## 三、朱雀之变的意义

- 这是朱雀圣宗自败于修真联盟之后的**第一次朱雀之变**。
- 含义：**有一个可以成为朱雀圣皇的「序列者」已经觉醒了朱雀**。只有如此，方可引起朱雀之变，并召出数万年未现的朱雀真灵。

## 四、九名碎涅修士出动

- 九颗朱雀圣星内各飞出一道紫红身影，共九人，**每人皆为碎涅修为**，为朱雀之变而来。
- 真灵再度雀鸣、化作波纹横扫，火焰四推；随后身体急速旋转化作巨大火球，火海漩涡中扭曲显出一幕画面。

## 五、火球画面（仙帝洞府现场）

画面所见人物：

| 人物 | 描述 |
|---|---|
| **王林** | 长发飘动，身上朱雀图腾弥漫，浑身浓浓火焰，远看形如一只朱雀 |
| **符族圣祖秋瑶** | 容颜凄厉，双眼空空流下黑血；忽然「看」向画面，令九人心神一震 |
| **青霖分神** | 晶光闪烁组成，立于秋瑶面前；九人猜测「莫非是当年的仙帝青霖」 |
| **虚空子、天运子** | 一同在场 |

九人议论：
- 「符族圣祖秋瑶」——认出女子身份。
- 「她面前那人……莫非是当年的仙帝青霖。」
- 「朱雀觉醒者，竟然是在这等凶险之处；虚空子身为联盟重要人物，定然不会允许我朱雀宗有觉醒者。」
- 「只是这个觉醒者，老夫从未见过，他如何得到的朱雀序列。」

## 六、朱雀圣皇的神念敕令

燃烧星域深处横扫而来一股磅礴神念，强到使星域燃烧为之一顿：

1. 「此子身份不用怀疑，其**朱雀印记，是老夫分身所送**。」
2. 「你等**倾全族之力，寻真灵引路，不惜一切代价，去把他安全的带回来**。」
3. 「**老夫时间不多了，当年伤势越加严重**，此子在此刻觉醒，是我朱雀圣宗的希望。」

九人狂热恭敬：「尊圣皇之命。」

## 七、洞府内的即时反应

- 仙帝洞府内，晶光所化青霖出现的瞬间，王林感到身上朱雀图腾一热，尚未查看便有数道目光投来。
- **虚空子目光杀机一闪**，当即察觉王林身上的图腾变化，心道：「朱雀宗，发现了此人觉醒。」

## 八、伏笔与看点

- 王林的朱雀印记来源被点明：朱雀圣皇的**分身**所赠。
- 朱雀圣皇伤重、时日无多，急需继承者，故不惜倾全族之力接应王林。
- 觉醒暴露于虚空子（修真联盟一方）面前，杀机已现，朱雀宗与联盟围绕王林的冲突即将展开。
