# 第1909章 金、天、跃！

## 一、仙罡大陆·空劫之上的四大巅峰称号

本章为境界体系的重要设定章，系统交代空劫境之上的称号阶梯：

| 称号 | 修为定位 | 说明 |
|---|---|---|
| 大尊 | 踏入空劫即可称 | 即便空劫后期修士也依旧称大尊 |
| 金尊 | 空劫后期最巅峰 | 无限接近圆满但无法度过达到圆满者 |
| 虚天尊（天尊） | 空劫圆满 | 大天尊之下最强一类，罕见；大天尊极为看重、礼遇厚待、大力笼络 |
| 跃天尊 | 天尊与大天尊之间的模糊境界 | 超越一切空劫圆满，大天尊麾下也极少见 |
| 大天尊 | 顶点 | 彼此交战后果太大，非必须不出手 |

### 权力结构推论
- 大天尊之间也有矛盾，但一旦亲自爆发大战后果太大，故**绝大部分纷争由麾下天尊的强弱与数量决定**。
- 例外：道一与玄罗当年因**地域问题**曾一战，但即便战下去彼此也奈何不了对方太多。
- 因此，一个天尊的存在在仙罡大陆上可获得无法想象的尊荣与地位。

### 跃天尊的唯一实例：罗云海
- 大魂门当年的**罗云海**据说便是跃天尊，故有胆量挑战道一大天尊。
- 此人桀骜不驯，且与道一之间似有不为外人所知的**因果**，逼得道一不得不出手将其灭杀。
- 道一惜其才，**留下其魂，让其魂归宗门**。
- 整个天牛洲自诞生之日起，外人所知**只出过这一位跃天尊**。

## 二、东州九宗十三门·三宗底细（出自青牛真人所赠地图龟甲）

入选九宗十三门的门槛：宗派内**拥有空劫后期巅峰的力量**。

### 大魂门
- 有**青牛老祖（青牛真人）**：空劫后期巅峰**金尊**，且**有真身存在**。
- 当年出过罗云海这样敢挑战大天尊的强者，声名大振。
- 神通诡异、渊源神秘，列为十三门之一且较为强势。

### 归一宗
- **无金尊**，宗主仅空劫后期大尊，距巅峰有天地沟壑，无法跨越。
- 但有**五名空劫后期修士**，各占据重要位置。
- 传承一套名气极大的**原始铠甲**：空劫后期大尊穿上后修为暴增，**祭献生命**可爆发出与金尊一战的威力。
- 限制：祭献生命**不能超过三次，三次后必死无疑**。
- 因有五人具备穿戴资格，故此宗处境尴尬却仍勉强列为九宗之一。

### 道魔宗
- 位于**绿魔洲西北部**一片连绵不断的沼泽之中。
- 宗主：空劫后期巅峰**金尊**，名震东州；但与青牛真人同为金尊，因对方有真身辅助，宗主不是对手。
- 另有**四位空劫大尊**：二人在天牛洲主持战场，二人留守宗门。
- **道魔宗老祖**：修为已至**天尊**层次，不问世事、不尊绿魔蝎庙、只修自身，**一万三千年前**被**道一大天尊**请走成为其麾下。
  - 该老祖对道魔宗感情随修为提高而稀薄：小打小闹死多少人无所谓；**但若有人要毁道魔宗道统，碍于颜面必定追究**。
- 因这位老祖，道魔宗名震东州，并在绿魔洲内占据最主导地位。

## 三、王林的判断与杀意

- 情报来源：大魂门青牛真人所赠的**地图龟甲**。
- 王林估算：**整个东州尚活着的天尊层次之人只有七位**。
- 自问：以现在修为，穿上**天牛魂铠**爆发全部力量能如何？
- 结论：「**金尊可以无视，天尊我没有战过，但也很想一战**」。
- 形貌：白袍加身，大袖一甩笼罩头部，遮盖面貌与白发，透出神秘与沧桑（本片段外貌记录）。

### 结仇因由
1. 道魔宗曾在与**孟土洲**边缘之地，**聚一宗之力围堵王林**，不让其安全离去，且一个个发狂般冲来。
2. 围杀中**抛出一个个头颅**——那些人是与王林一同在**极天草原**奋战之修，其死亡皆因王林而起。
3. 那阴毒之声：「你不是喜欢人头么，这些，便是我道魔宗，给你的第一份大礼」。
4. 王林答：「我喜欢人头？我的确喜欢。」
5. 另有道魔宗宗主的擒拿，以及王林在**绿魔蝎庙**中的痛苦与小心翼翼。

王林性情注记：一生杀戮滔天却并非嗜杀，修为越高越少主动出手，除非被主动招惹或逼至生死绝境。但此番既是一宗之力为敌，报复方式便是**毁道统、灭满门**——「不管什么修为，一个也别想逃走。要怪，就怪你们是道魔宗之人」。

## 四、道魔宗形制与现状

- 门徒：原本不下十万，经**一百多年远征**后剩余**不到三万**；但战力未减太多。
- 宗主**一百多年前闭关**，似要冲击天尊层次，始终未出现。
- 一百多年中始终开启**道魔迷雾大阵**，遮天迷雾笼罩全宗，守护并防意外。
- 建制：
  - 取天边之山填入沼泽，形成一处处**仙山**；
  - 取天边之石以法力压成**青石板**铺满沼泽，弟子行走如平地；
  - 山峰与阁楼呈**八卦阵**排布，将核心笼罩在中央；
  - 中心非沼泽而是一片**清澈湖泊**，湖底时有涟漪，仿若其内生存着某个仙兽；
  - 湖中**小岛**即宗主闭关所在，也是**道魔宗大殿**与**藏法之处**。

## 五、封锁三重与开战

王林立于迷雾之外半空，右手向道魔宗一挥，依次布下三重封锁：
1. **火海**呼啸而起，化作**九十九条火龙**咆哮，环绕道魔宗四周层层封死；
2. **雷霆闪电**弥漫成连接一体的**电网**，融入火海形成严密封锁；
3. **禁制**大片扩散，使火焰与闪电紧密融合、浑然一体，化作**封印镇压**。

随后王林抬头，一步步走向道魔宗；每一步落下都有轰鸣惊天回荡，其身内散出滔天煞气直逼道魔宗。

## 六、待验证/伏笔
- 道魔宗老祖（天尊，道一麾下）是否因道统被毁而出手追究——本章已明示其触发条件。
- 道魔宗宗主闭关冲击天尊是否成功。
- 湖底疑似仙兽为何物。
- 王林与天尊层次一战的意愿，指向后续与东州七位天尊之一的交锋。
