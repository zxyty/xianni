# 第1917章 仙族大天尊

## 一、王林赴仙族皇城的心念

夜里，簦烩宗废墟内，王林独立沉思，定下前往**仙族皇城**的决断。

- **动机不在『感谢』**：他明言「不为那所谓感谢」，而是为了**当年对连道非发下的誓言**——「今生今世，必定要让道非恢复记忆，以报其当年对我血融之恩」。
- **重恩之人**：王林自评「他重恩」。当年的疯子（连道非）对他有恩，因此他必须亲往仙族皇城，看疯子是否已完全恢复记忆；若无遗憾，则了却心念。
- **不问对方是否变质**：「无论他是什么姓格，改变也好，没有改变也罢，即便是对我有了叵测之念，我也要去亲眼看一看。」
- **惆怅**：他不知当年的疯子如今变成什么样，霜隋是否还如当年一般在其身边咆哮叫嚣。王林回忆起疯子当年的种种混不吝之语（自称「本王」、要咬死人、提到「飞飞」这个妖女给他吃过东西等）。

## 二、王林与疯子的两段旧恩（闪回）

| 事件 | 内容 |
| --- | --- |
| **朱雀星生死劫** | 疯子出现抱住王林，为其抵挡了那足以致死的一式神通。 |
| **第三次化凡梦道** | 王林与疯子二人在虚无中飘荡；梦道中王林遇到疯子，与凡尘的自己走过了甲子岁月。 |

王林自省：「实际上，我给予疯子的，不多，更谈不上恩，反倒是疯子，对王林，有大恩。」并叹「希望他没有变化太多」——他朋友很少，疯子算一个。

## 三、行前准备的判断

- 「仙族皇城，一定要去，不过那里必定危险，去之前，我还需有些准备。」
- 情报来源：右手一翻取出**大魂门老祖所赠的龟甲碎片**，其上除**地图**外还有**对大天尊的介绍**；另有在**洞府界**时**玄罗**所讲述的大天尊之事。

## 四、仙族五大天尊格局（七十二洲的『五个太阳』）

这便是仙族之地七十二洲中的五位绝世强者、五个太阳。

## 五、天尊层级的稀缺性与规则

- **天尊**：超越**金尊**的存在，于仙罡大陆极为罕见。
- **数量**：每位大天尊麾下最多不足**百位天尊**；整个仙族大陆天尊修士**不超过一千人**。
- **跃天尊**：更为稀少罕见，全仙族大陆仅**四十八人**；其中大部分闭关不出、隐藏在仙罡大陆各处，能被大天尊收为麾下者**不到三成**。
- **潜规则**：即便是仙皇八极大天尊，想杀其他大天尊麾下的天尊，也需给出一个缘由；若所杀者是**跃天尊程度**的修士，则无论哪一位大天尊都不会容忍。

## 六、王林的战略盘算

1. 以他如今的修为，一旦被某位大天尊知晓，**必定会被加以笼络**，招为麾下。
2. 一旦背后有大天尊撑腰，则**仙族皇城之行的危险程度将大范围下降**（因上述『杀天尊需缘由』的规则）。
3. 因此，赴皇城前的『准备』，很可能指向择一大天尊势力作为倚仗。

## 七、待跟进

- 连道非（疯子）在仙族皇城的现状与记忆恢复程度。
- 霜隋、飞飞等旧人的下落。

# 第1824章 跃天尊之贵与三条神脉

## 一、跃天尊修士在仙罡的地位（设定）

- 跃天尊修士是**大天尊之下整个仙罡的最强者**，数量「太少太少」。
- 大天尊对其给予相当尊重：若跃天尊不愿跟随，除非像**罗云海**那样主动去挑战大天尊，否则大天尊不会为难、也不会强要求跟随。
- 一旦跃天尊跟随某位大天尊，该大天尊必在**考核调查**后引为心腹、礼遇有加——因为这种程度的修士，是大天尊**转世之时最好的守护者**。
- 因果规则：麾下跃天尊若被其余大天尊所杀，**必定不容**。这关系到名誉、日后招揽，甚至关系到转世后的重要守护；若该跃天尊是独自一人（未投靠），则另当别论。

## 二、王林的处境判断

### 必须隐瞒的
- 王林虽是**玄罗唯一的弟子**，但在仙族**绝不能表露**：以他如今修为，一旦泄露必遭大天尊轰杀。仙族决不允许古族中出现这样的修士。
- 师尊之事**连疯子也不知晓**，唯有**归一宗**知情。玄罗敢让归一宗知晓、且未在洞府界灭口，王林相信师尊必有把握归一宗不会说出去（具体原因王林不知）。

### 不必隐瞒的
- **吉族血脉、古仙同修**：仙罡大陆无数年来仙族与古族血脉已有交融，部分仙族修士同样拥有吉族肉身，只是未获**古祖庙宇**承认。故王林的古族身体在寻常修士眼中惊人，在大天尊那里并不稀奇——**前提是不知其与玄罗的关系**。
- **来自洞府界**：对其他人需隐瞒，对大天尊则大可不必——他们必定查得出，且能借此真切知晓王林来历，对大天尊反倒是好事。有洞府界修士走出虽会极为震惊，但在王林的修为面前不重要，重要的是**王林的选择**。

## 三、定策：引大天尊主动来寻

- 核心思路：**展露出能杀天尊的修为 → 名震仙族 → 大天尊自行找来**，这才是最好的方式。
- 五大天尊盘点：
  - **仙皇**——可以不考虑。
  - **道一大天尊 / 武封大天尊 / 久帝大天尊**——皆不熟悉。
  - **紫阳宗双子大天尊**——同属**东洲**，且在洞府界有过一面之缘：当年遇**贪狼**时，见过那两个名为**娃娃**与**涵涵**的可爱小女孩。
- 王林闭目等待**道魔宗天尊老祖**到来，要保持巅峰状态与天尊一战，借此测定自己的层次——**金尊已无法作为参照，唯有天尊可准确判断**。

## 四、速神诀：连凝第二、第三条神脉

| 神脉 | 所吞元神 | 结果 |
| --- | --- | --- |
| 第二条 | 九个**玄劫五次以下**元神（先炼化被压制的道魔宗宗主元神但未即刻凝脉） | 天空渐亮之际体内轰鸣，化作漩涡凝聚；施法速度更快 |
| 第三条 | 七个**玄劫五次以上**修士元神 + 一个**空劫初期**元神（玄劫元神不足所补） | 体内轰鸣回荡中赫然出现 |

- 三条神脉漩涡同时旋转 → 可**瞬间施展诸多神通之术**，连**道古身躯**的速度都明显改变。
- 对照：另一名获得速神诀的修士只能增加施法速度、无法引动身体，关键在于其第一条神脉由**空涅**修士吞噬而成，而王林是**空玄**。
- 数十枚参差不齐的元神被吞噬大半后收起，留作他用。
- 章末王林闭目，开始以**道魔宗宗主元神**凝聚神脉，自问「可以让我的速神诀增加几条神脉」。

## 五、章末：天尊跨洲而来

天空大亮、阳光洒落之际，**孟土洲与绿魔洲的边界**上一道长虹带惊天气势轰轰而来，刹那穿越孟土洲边界、踏入绿魔洲。孟土洲内修士纷纷心神震撼，丝毫不敢冒头。

> 洲与洲的界限，对于天尊来说，直接无视。

## 六、伏笔与看点

- 王林「以杀天尊之名引大天尊来寻」的路线正式确立，紫阳宗双子大天尊（娃娃、涵涵）是既定的潜在接触对象。
- 玄罗师徒关系是王林在仙族最大的死穴，归一宗为唯一外部知情方。
- 速神诀神脉数量取决于所吞元神层次，道魔宗宗主（天尊级之下的宗主级）元神能凝几条尚未揭晓。
