# 第九卷 云海之巅 · 第1284章 天逆的来历（第二更）

> 归属说明：本章「吕子浩」化名沿用自第1063章，主角一律归于【王林】。

## 一、通天之门内的景象
- 王林踏入天逆内的**通天之门**，一步之下如入另一世界：一片**无尽星空**，无雾，只有璀璨星云，极静而陌生。
- 呢喃之声称他为「**第三个踏入此门之人**」「第三个有缘人」；星辰爆发星光凝成**巨大星光漩涡**。
- 踏入漩涡瞬间魂魄消散，再现身时到达门内一处星辰：**黑色大地、青草弥漫、蔚蓝无云天空**（好似海水倒挂）。
- 前方立有**齐天苍天巨木**，青光弥漫却掩不住破损裂缝，生机将绝、正缓慢死去。其大足以与古神一拼。
- 巨木自陈：「这是我的**本命涅劫之宝**所化，唯有如此，才可使我残存至今。」

## 二、封界之尊的身份
- 来自**远古仙域**，本名已忘，降临后世人称**封界之主／封界之尊**。
- 身份：**界内远古仙域道仙**，降临使命是统领界内一切生灵、抵抗界外入侵并与之一战。
- 对前两位进入者的赐予：
  - 第一人（女性，「她」）：**绝伦的道法**与他对天地的感悟。
  - 第二人：**半个规则之体**，使其资质惊天。
  - 二人皆未成为天逆下一任主人，「只是我的棋子」。

## 三、界内界外的由来（惊天秘辛）
1. 恒久以前，**太古星辰没有界内界外之分**；星辰内有圣地**远古仙域**，统领星辰、教化万族。
2. 生灵修行至一定程度、**开启自身星辰**后即可飞升，入远古仙域成为仙域之民，一切在循环之内。
3. 因一件**来自外星辰的至宝**（即天逆），发生翻天覆地的剧变：
   - 远古仙域**一分为二**，最终消散隐藏，**封锁飞升之路、封闭一切通道**；
   - **太古星辰随之一分为二**，出现**界内**与**界外**，并有**界心大阵**。
4. 分裂出去的那部分成为**界外的圣地**；界内亦存另一部分远古仙域，封界之尊即由此降临。
5. 剧变中远古仙域死伤惨重、陨落无数，**天地初开就存在的远古仙皇**被那法宝重伤，**闭关不问世事**。
6. 界外远古仙域之人在**九位仙妃**带领下时刻虎视界内，所求为：当年那件法宝（天逆）、以及**通往界内远古仙域的通天大路**。

## 四、封界之尊的败亡经过
- 使命未成，先遭**道奴（水道子）偷袭**；
- 又被**界外之民 + 数名界外远古仙域之人联手重伤**；
- 最后**仙妃出手灭其肉身**，被迫进入天逆，以**法宝之灵**形态残存至今。

## 五、天逆的真相
- **真正的天逆是一个罗盘**，罗盘之上应有**九样天地至宝**。
- 当年他们得到天逆罗盘时，其上**只有三样宝物**；**天逆珠**是放在**正中心**之物。
- 分裂之后，**界内远古仙域得到其中两样**；仙皇因他身为道仙、须统领界内与界外一战，遂将**天逆珠赐予他**。
- 他**并非天逆珠第一代主人**：无数万年研究后得知，其前还有**两位主人**，每一位都远超他，且**应为外星辰之修**。
- 他推断：**天逆珠才是罗盘上最重要之物**；破开天逆最终秘密即可寻到**太古神境**（他自承所知不多，但认为其应存在）。惜仙皇闭关，无从求证。

## 六、逼退水道子的原因
- 出手前提：王林**找到了他当年消散的玉佩**，他方可借玉佩施展一些残存之力（否则无法相助）。
- 出手理由：**道奴当年叛他**，他曾给道奴**三次不灭机会**，至此**最后一次已然用完**。

## 七、交易与条件
- 王林已让**天逆融入元神**，成为**天逆之主**，故与前两人不同。
- 封界之尊要求王林：
  - **代其成为封界之尊**，守护封界、抵抗界外入侵；
  - 直至**仙皇从闭关中苏醒**、界内远古仙域**封印打开**。
- 封界之尊的代价与去向：助王林后**彻底散去**，随王林寻回的**玉佩**与其所化**涅劫之宝**一同**融入界心大阵**，使大阵威力更强，**为王林争取成长时间**。
- 诱饵：若立此大功并在**仙皇苏醒后献出天逆**，仙皇必大加赏赐，可完成一切夙愿——**即便是放在避天棺内的女子（李慕婉/婉儿）也可重生苏醒**。

## 八、王林的心理判断
- 此人多年观察自己，**知晓其一切**，尤知他对**复活婉儿**的渴望，并以此为要挟令其屈服于仙皇。
- 一旦献出天逆，便**完全被仙皇掌控**，生死荣辱全凭赏赐——「这种事情，我岂能去做」。
- 但眼下欲离开此地，**必须先与此人虚与委蛇应承一番**。
- 对封界之尊的评价：**并非对我有歹意，而是古板迂腐至极**——因先前三次不灭之言，错失杀叛徒（水道子）的机会，遗祸至今。

## 九、本章结尾
- 王林反问「**你能给我什么**」；
- 巨木通体一震，爆发惊天动地威压化作风暴，瞬息笼罩并**将王林卷回巨树内部**。

## 待续/伏笔

# 第1285、1286章 苏醒！（第三更、第四更合一）

## 一、开篇：天逆与道境烙印

一道苍老的声音回荡天地后渐渐消散，其言要点：

- 自称参悟「天逆」多年，其内蕴含太多隐秘，连他也无法尽数看出。
- 可从天逆内**抽取太古外星辰之力**，化作**烙印**留在对方魂魄内。
- 此烙印**无法一步登天**，但可让人**进入道境**，并从道境内**衍变天道感悟**。
- 「能有多少造化，就看你自身了」——造化多寡取决于承受者本身。

（按世界状态须知：本片段中王林于云海星域以化名『吕子浩』立足，此处以本尊「王林」记录。）

## 二、场景：云海二阶星域·蛮荒大陆·山谷

王林已化作石像，静立山谷之中。李倩梅陪伴石像，以鲜血涂抹之法维系，历时十年。苍老之声曾言：**此法若能坚持十年，王林有苏醒的可能**。

### 石像的变化

- 最初为**沧桑的老者**之貌。
- 六年之后，已化作**青年**，几乎与王林化石像之前无任何区别。
- 李倩梅每次凝望石像，都好似看到王林站在自己面前。

## 三、十年血祭的逐年阶梯（关键时间线）

| 年份 | 石像吸收速度 | 李倩梅每日休息 | 所用之血 |
|---|---|---|---|
| 第1–6年 | 常态 | 不足两个时辰（全用于打坐恢复生机） | 全身鲜血 |
| 第7年 | 明显加快 | 仅半个时辰 | 鲜血；丹药几近耗尽且无暇消化 |
| 第8年 | 一遍抹完立刻吸收殆尽 | **无休息、无打坐** | 鲜血，纯靠碎涅修为透支生命 |
| 第9年 | 前方刚抹完即消散，双手齐用亦跟不上 | 无 | **舌尖心神精血**，掐诀化血雾弥漫全身 |
| 第9年下半年 | 再度加快，舌尖精血不足 | 无 | 以**银色小剑刺心头**取精血 |
| 第10年 | 心头、舌尖精血皆不足 | 无 | **元神道血** |

### 设定要点：精血与元神道血

- **精血**：修士极为重要之物，其多少可决定修士的一切；**不存于四肢，而存于舌尖、心头**；此处血液**一滴相当于全身**。
- **元神道血**：修士一生修道、感悟天地意境融入元神而成的**修为根本**，须**炼化逼出化作一团气息**；不是血液，却**比血液更为贵重**，蕴含施术者的**全部生机**。李倩梅动用后，如败落花絮，凋零加快。

## 四、李倩梅的心境

- 容颜仍美却充满病态，日渐消瘦，最终瘦得皮包骨，往昔绝伦容颜不再；唯双眼始终**坚定、执着**。
- 反复自问「这一切，为什么会成为了现在的样子」「真的有前世么」，但**不去思考值与不值**，只知自己需要这么做、这么做不后悔。
- 反复浮现的画面：水面下鱼儿的双眼，望着天空中的飞鸟；飞鸟落下饮水时与水下鱼儿目光相接，片刻成永恒。
- 第十年临别之言（面对石像，含笑闭眼）：
  - 「你心中有另外一个女子存在，我不会与你抢夺，也不会让你去选择」——不逼王林。
  - 认为若那女子（李慕婉）来临，会做得更好；**木冰眉**若知晓一切来到此地，想必也会做到。
  - 前世之说：「你是飞鸟，我是鱼儿」；自述看到化作飞鸟的王林**两次**落在她游荡的水面——一次饮水，一次受伤坠水，她用力气把他推到岸边，让他可以呼吸、继续飞走。
  - 心结：「你还没有回答我第三个问题，我还没有听到你说出第三个问题。」
- 文中对照：她**没有李慕婉当年数百年的孤独等待与孤独琴音**，但有**同样的执着**。

## 五、结尾节点

第十年比前九年加起来还要漫长。**第十年的第九个月**，李倩梅睁开双眼，望着雕像沉默了很久很久。（章名「苏醒！」，指向王林即将苏醒。）

# 第1200章 魂血送至·王林苏醒

## 一、李倩梅的托付与离去

- 李倩梅取下颈间玉佩——其内藏着她的**命魂**——挂到王林所化石像颈部，以求撑过最后三个月；她自知“以我的所有，也无法帮你渡过这最后的三个月”。
- 她道出妖宗规矩：凡赴妖宗战场且被妖宗认可者，可由**妖宗太上长老**施展神通取出**魂血**储存，一旦战死可凭魂血重塑魂魄、**转世重修**。她当年被妖宗认可，留有魂血，故欲返妖宗取回以救王林。
- 临行布下守护：自储物空间取出**九把飞剑**分刺山谷四周，组成她法宝中最强的**剑阵**（曾于战场斩杀无数凶兽）。
- 她吞下丹药、以虚弱之身疾驰而去，这是十年内第一次离开山谷、离开**蛮荒大陆**，直奔**九阶星域妖宗**。自陈：命魂玉佩只能维持约一个月，一个月内必须取回魂血。
- 石像三年前已与蛮荒大陆融为一体，她带不走。**此去再未回来。**

## 二、山谷的三个月

- 凶兽咆哮渐盛，逼近山谷，但踏入剑阵范围者尽数惨叫而亡，久之凶兽不敢再来。
- 玉佩散发柔和之芒滋润石像，如她未曾离去；至第二十日仍无音信，玉佩光芒如风中烛火，越发黯淡。

## 三、白衣老妪送魂血（第27–28日）

- 第二十七天，一名**白衣老妪**踏星空而来，一脸阴沉，持**玉简**印证方向；一日后寻至蛮荒大陆，一步跨空落地，散开神识，爆发**碎涅大圆满**气息横扫全陆，锁定山谷。
- 九道剑气拦阻，老妪以玉简迎上，玉简散出柔和气息环绕剑气，九道剑气**放弃抵抗**、消散（暗示玉简与李倩梅相关）。
- 入谷见石像与颈上玉佩，长叹：“李倩梅，你牺牲了那么多，就是为了此人么……老身曾答应你，代你送魂血而来，也算完成了与你的承诺。”
- 自储物裂缝取出**拳头大小的絮状血球**——非真血，更像魂魄凝聚——送入石像。血光滔天而无煞气，反有生机、温柔与十年相伴之意。

## 四、王林苏醒与“一目破法”

- 石像剧震，王林**十年来第一次睁开双眼**，脸上石皮陆续崩溃（本需时间才能全碎）。
- 醒来时茫然，自觉做了一场梦，梦中进入一个奇异境界——那是**道境**。
- 目光落在老妪身上，一眼看穿：
  - 其体内一尊**元神**运转，元神内种种神通闪烁，且在他目光下**瞬息停止变化**，仿佛心念一动即可看清神通根本、甚至将其神通自记忆内清除；
  - 其右心处有一道存在**不下千年**的疗伤**封印**（妖宗太上长老千年前所留），在他一目之下几乎崩溃，足以引动几近痊愈的伤势、逆转千年重现重伤。
- 老妪骇然后退、额头见汗，仍以恶劣性格低喝质问。王林出声留人时，“天地之间好似有规则变化”，老妪竟无法离去。

## 五、老妪揭出的真相（连问“你可知晓”）

1. 十年前李倩梅为去**无极宗**见一个人，放弃成为**妖宗弟子**的大机缘、舍弃妖宗器重，成为**第一个中途离开战场之人**；妖宗不愿，**破天宗**亦有微词，恐开先例。
2. 十年前她奉师尊之命离开无极宗回宗，回宗即被师尊**封困三个月**——正因彼时有一人（王林）面临生死危机。
3. 为去救王林，她与**如父一般的师尊决裂**，以死换来离去的机会，从此**无门无派**。
4. 十年内她整日以**鲜血**为石像涂抹全身；血尽以**精血**，精血不足以**意境元神**代替，从未间断。
5. 十年除最后几个月外从未离谷半步；血中蕴含**生机**，耗尽生机送入王林体内，虚弱至极。
6. 最终元神亦无法代替，遂赴妖宗以代价取回魂血，托老妪送来；临走仍留下命魂玉佩滋养他。
7. 老妪自陈身份：**看着李倩梅从小长大的师姐**，在妖宗逼问出她全部之事；并言“她不让我告诉你，但你既然问了……我就是要让你知道这一切”。

### 取魂血的代价
- 李倩梅十年前离场、十年未回、被破天宗驱除，妖宗必罚；欲取魂血须付代价：**前往裂缝战场最深处**，为妖宗探查那充满凶兽的世界内是否有**连接界外的通道**。
- 若真有通道则她无法安全回来；即便没有，深处亦有至强凶兽，她**必死无疑**。何况她此刻生机破灭、修为大损、透支生命。妖宗意在**让她死在战场，以儆效尤**。

## 六、崩碎与出发

- 王林听罢剧震，终于明白**天逆**内那从未间断、连道境中也在滋养其魂魄的温柔血光是什么；低头见玉佩光芒黯淡，其上**出现一道细微裂缝**。
- 全身石皮裂缝疯狂蔓延、轰然尽碎，石皮与血肉相连，王林顿成血人。
- 石像与蛮荒大陆相连，崩碎瞬间**整个蛮荒大陆轰然瓦解、四分五裂**。
- 王林冲天而出，**绝强修为气息爆发**，右手虚空一抓擒住老妪——碎涅大圆满亦无从闪躲、元神颤抖、神通不能化出。
- 结语二句：“**带路，我要去妖宗战场**”“**我去救她**”。
