# 仙逆 第八卷 联盟隐秘 第945章 隐秘

## 一、天逆夺印，收场（承接上章战局）

- 眉心带月牙印记的老者绝望凄厉求饶：「**封界之尊**，饶我一命」，目光看向闪烁之网内的王林。
- 王林尚在心神震撼中，**根本无力操控天逆珠子**，更谈不上阻止。
- 黑白二气漩涡内伸出的**大手**，将老者眉心的月牙印记（**太古印记**）连着无数血丝彻底抓离、缓缓收回。
- 老者眉心喷出大片血雾，人立刻萎靡，双目黯淡无光，身子如遭大力冲击向后抛去。
- 黑衣青年目露恐惧，看向王林的目光冰冷崩溃、惊骇闪躲不敢直视；抱住老者后依老者「速退」之言疾驰退去。
- 黑白二气漩涡消散，重化黑白二气，穿透已彻底收拢的闪烁之网，融入天逆珠子内消失。
- **望月与罗尘被隔绝在闪烁之网外**，随虚无弥漫而**永久消失**。
- 闪烁之网被虚无覆盖消失，此地只余无尽黑暗与安静。
- 清水的**仙元被此地奇异之力封印了绝大部分**，望着王林，目中由迷茫渐有凝点。

## 二、天逆珠归体

- 王林心神震撼不亚于失去太古印记的老者：**漩涡中那条手臂他并不陌生——当年天逆珠子第一次打开时便曾见过**。
- 王林谨慎抬右手触碰天逆珠子，**珠子瞬间融入其右手，钻入体内元神中消失**。

## 三、清水口述隐秘：远古仙域与四大仙界的由来（本章设定核心）

### 1. 远古仙域
- 远古之时有**远古之民**，自修天地、列为仙班，成就**远古仙域**。
- 远古仙域是「我仙界的圣地」，**真正的仙界**。
- 清水之师尊**白凡**即远古之民，证道于仙域，而后沉入凡间、教化万民。
- 白凡之言：远古仙域乃**星空世间万灵之守护**——「**仙域在，则天地在；仙域亡，则万灵摧**」。

### 2. 仙域崩塌与纪元更替
- 白凡原以为仙域永恒，然而**东西南北支撑远古仙域的参天巨木崩溃**，远古仙域**无声无息消失**，再无半点踪迹；白凡一生追查亦不得。
- **远古仙域的消失＝远古时期崩溃，迎来上古**。
- 自此世间生灵迷茫：**仙已不再，何来修仙 → 于是有了炼气士**。
- 清水自述：「我清水，就是炼气士中的一人，当年**清水国储君**。」

### 3. 四大仙界＝通往仙域的四大通道
- 白凡与几位同为仙域之人**另开天地**，把当年通向仙域的**四大通道自成地域，称之为仙界**。
- **风雨雷电四大仙界把天地星空化成四份**：

| 仙界 | 其下星域 |
|---|---|
| 风之仙界 | 云海 |
| 雨之仙界 | **昆虚** |
| 雷之仙界 | 罗天 |
| 电闪之仙界 | 召河 |

- **关键隐秘：雨之仙界下的昆虚星域最终换了名字，被世人称为「联盟」**——今人已无人知晓这里曾叫昆虚。（呼应卷名「联盟隐秘」）
- 清水长叹追忆：「在**雷界**，我遇到了**她**。」（未点名）

## 四、王林本尊：五星王族古神

- 身体在砰砰声中由**三百多丈缩回常人大小**。
- **眉心五个古神星点环绕缓旋**，散发凌厉古神气息。
- 王林本尊已有**五星古神之力**，「已然站在了强者之列」。
- 战力标定：**五星王族古神展开神通可战净涅初期修士**；若回到星空、体内被压制封印的元力解开融合，**净涅初期中能败王林者凤毛麟角，几乎没有**。
- 王林握拳，第一次感受到自己已然强大如此；神色如常，平静望着清水，始终未发一言。

## 五、要点提炼

1. 本章为《仙逆》世界观级揭秘章：给出**远古仙域—上古炼气士—风雨雷电四仙界**的完整起源链。
2. **联盟星域的前身＝雨之仙界下的昆虚星域**，本卷标题「联盟隐秘」由此落地。
3. 天逆珠展现「夺取太古印记」的主动行为，且其内大手与第一次开珠时同源，伏笔延续。
4. 王林战力节点：本尊五星古神成型，横向对标净涅初期。

# 清水仙君口述上古秘辛：四大仙界之战与符文族的来历

## 一、清水的旧伤（背景）
- 清水眼中柔和旋即被痛苦取代：当年迷失本质、陷入疯狂时，**错手杀死自己挚爱的伴侣**。
- 这份痛被他深深隐藏，独自打坐的每个日夜都无法忘记。

## 二、上古：四大仙界为「一物」而战
- **上古时期是仙人鼎盛之时**，但鼎盛持续时间不久。
- 四大仙界（风雨雷电）**因一物展开生死大战**，持续太久太久，四界损落无数。
- 大战巅峰之时，**一人自虚无中走出**制止此战。据清水师尊 **白凡** 回忆，此人是「随**远古仙域**消失的故人」。
- 此人**持远古仙域之令**，在四大仙界之间**形成壁垒、相互隔绝**，并留下警告：
  > 若是壁垒再次被打开，远古仙域将会降下怒火，焚烧一切。

### 争夺之物 = 一个珠子
- 清水不知那根源之物具体为何，**只知那是「一个珠子」**——说时特意看了王林一眼。
- 王林**神色如常，心神却震**（指向其所得石珠）。
- 清水仿若自语：「若我获得了那珠子，定会仔细隐藏，绝不轻易拿出，更不会让任何人看到，此物实在太过重要。」——等同于对王林的隐晦告诫。

## 三、符文族（仙遗族）自虚无而来
- 四大仙界战后，风雨雷电四界**均处最虚弱阶段**，此时出现惊天变故。
- 一群自称 **符文族（符族）** 的怪人**凭空出现在四大仙界下域内**。
- **道统差异**：
  - 仙人：**不修天道，只修仙元**，可逆转天地之力为己用。
  - 符族：把一切神通**凝聚在一张张类似法宝的纸符之上**，以此施展，极为诡异。
- 结果：激战之后**仙人胜**，符族被打散，**大片被奴役成为仙人奴仆**；但四大仙界**损伤更重**。
- **事后追查**：符族之人是**从这星空下的虚无而来**——清水一指脚下，即二人当下所在。
- 王林倒吸口气：他接触甚多的**仙遗族竟源自虚无**；联想到之前遇到的**老少二人**，心中升起一个念头（未明言）。
- **虚无并非只在联盟星域，而是弥漫四大仙界内所有星域。**

## 四、未解谜团
1. **清水发狂之始**：与符族之战后他便有发狂迹象，当时并未重视；再往后的事王林已从炎雷子处知晓。
2. **太古仙族·月噬一族**：王林告知清水，先前那老者自称太古仙族月噬一族。清水**从未听过太古仙族**，遂疑「当年符族之人，莫非也与那老者同处一地、亦是太古仙族？」
3. **七彩之气与幻觉**：清水不解为何七彩之气出现之刻自己会产生幻觉；并追问——**师尊白凡当年指天癫狂而亡，到底看到了什么？**
- 谜团如浓烟环绕，二人在虚无中沉默。

## 五、虚无中的九日行程与出口
- 清水**体内仙元最终被全部封印**，渐渐虚弱；**第三天**已如同失去飞行之力。
- 王林扶着清水前行，身外**炎雷子所赠的仙界碎片**缓缓飘动、散发柔和之光，与外界有奇异联系，**被牵引在前引路**。
- **第九天**：清水虚弱不堪，交代两事：
  - **玄宝元神**：他只取记忆，**留给王林**——其元神内蕴含**仙元**，对王林有大用。
  - **临别评语**：「你的姓子，与我当年很像」——同样的冷酷、同样的杀戮、同样的孤独；「希望你会比我更懂珍惜，因为我已经没有了珍惜的资格与人。」
- 随后仙界碎片**蓦然闪烁金光**、一顿停下，前方金光环绕中出现**漩涡**；漩涡中有一座**祭坛**，无数修士盘膝打坐、咒语之音回荡，**炎雷子带着微笑传音：「欢迎回来。」**

## 与既有设定的勾连（供检索）
- 「珠子」→ 极可能即王林所持 **石珠**（司徒南所在之物），解释了其被四大仙界争夺的分量与「绝不可示人」的风险。
- 「符文族」→ 即王林熟悉的 **仙遗族** 之源，来处为 **虚无**。
- 「壁垒」→ 解释 **风雨雷电四大仙界相互隔绝** 的成因，也预埋「壁垒被打开则远古仙域降怒」的后果。
