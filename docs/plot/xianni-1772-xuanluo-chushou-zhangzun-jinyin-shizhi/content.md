# 第1772章 玄罗出手！

## 一、掌尊的抢先与算计

- **情报来源**：掌尊虽不完全知晓古之墓地之事，但当年曾借七彩道人之力救出妙音等人，从妙音口中获知此地部分隐秘，故能快速定位路径。
- **判断依据**：第二花一战中，掌尊始终留意王林。王林连续开弓三次后，掌尊结合对王林的了解断定其再无开弓之力——否则王林绝不会放过七彩、任由战老鬼追去；又想王林若无绝对把握不会设「以狮吞虎」之计，由此推测其极限。
- **时机选择**：亲眼见王林重伤，掌尊认为这是杀王林、报旧仇、取**第三魂**的最好机会，趁战老鬼追击吞噬七彩之时全速追入第四花古之墓地，抢在众人之前现身于**倒数第二层**。
- **意外**：他料到第三妃或先至，却没想到云逸封也比他快，判断云逸封另有手段与造化。

## 二、云逸封与唐姗联手迎战

- **云逸封**：既输给王林便不反悔，在洞府核心选择听从王林号令。身外环绕唐姗所施**七道金门**，散发温暖滋养其身、伤势略有恢复并起防护之效、提速一分。施展**八刀斩身魂之术**斩向掌尊。
- **唐姗（第三妃）**：先为王林与云逸封各施七道金门，再掐诀幻化**九把金色飞剑**结成剑阵，带浓郁血脉仙气袭向掌尊；护身另有**手腕金色珠子**。
- **交锋结果**：
  - 掌尊大袖一甩，七彩光芒化七道长虹迎击，毁去八刀中的七刀；云逸封身前七道金门崩溃、喷血，最后一刀仍斩至掌尊身前，掌尊退出三步。
  - 掌尊双手拇指食指连圈，金光化无数金色利剑击碎唐姗九把飞剑，倒卷金光轰向唐姗；唐姗以金珠与七道金门抵抗，仍嘴角溢血急退。
  - 掌尊冷斥：「残兵弱将，也配在本尊面前出手偷袭。」

## 三、王林撕天 vs 掌尊掌灭三道

- 王林双手向虚空一扣撕开，**撕天之术**再起，连接天地的裂缝直奔掌尊。掌尊可不在乎云逸封与第三妃，却不能不在乎王林的撕天之术，瞳孔骤缩，以**度过数次玄劫**的修为爆发相抗。
- **掌灭三道**：
  1. **第一灭灵道**：双手圆圈金光再起，化无数利剑对撞撕天之术。
  2. **第二灭鬼道**：衣袍膨胀，身后幻化一轮初阳，**太初规则之力**环绕其身，状如仙神。
  3. **第三灭神道**：咬破舌尖喷出金色鲜血，化作巨大**金印**，越行越大砸向裂缝。
- **结果**：金光碰裂缝即扭曲碎散，初阳与撕天之术同归于尽，唯金印冲开一切屏障，向王林头顶砸落。掌尊呼吸急促、狞笑冲向王林：「没有了李广弓，我看你拿什么来对抗老夫。」

## 四、玄罗出手：虚幻化实质

- **玄罗的观察**：一路见识王林手段、心智、执着与果断，对王林欣赏极高；此刻很想知道王林如何对抗玄劫修士的神通，甚至猜测王林会取出**连道真的族弟**、以**仙人不灭体**硬抗。
- **王林的选择**：神色毫不慌乱，极为冷静，在金印砸来刹那连退三步——第一步距玄罗百丈，第二步不足三十丈，第三步直接落到玄罗**身后**，随即盘膝坐下。玄罗转身看向王林，二人目光似无形交错（对不见玄罗者而言此幕极为诡异）。
- **出手**：金印逼至头顶不足十丈、地面裂陷之际，玄罗笑道「有意思」，随意抬手一指——金印骤停于二人头顶三丈外，随后金光剧烈闪烁，以肉眼可见之速**缩小成巴掌大小**，轻飘飘落至王林身前漂浮，嗡鸣似有灵性、颤抖臣服。**此物已然实质，成为一件法宝。**

## 五、各方反应

- **云逸封**：本欲再度出手，只见王林退后盘膝、金印诡异停空，先是一愣；由掌尊神色反应过来后看向金印露出骇然，立刻想到什么、连忙低头——但其表情被王林**有意**看得清清楚楚。
- **唐姗**：掐诀停顿，本欲全力为王林加护，此刻只余诧异。
- **掌尊**：目瞪口呆、下意识揉眼，心神震撼**超过见到李广弓之时**。其内心崩溃点在于——金印是他的**神通所化**，本是虚幻不存在之物，绝无可能实质化为法宝。他判定「把虚幻神通之物化作实质，这种改天换地、取造化创物的能力」，是「**主人的哥哥仙罡九阳，九大天尊**」才可以做到，恐惧为其平生之最。

## 六、要点提示

- 玄罗此举首次向外界（掌尊）暴露其层次直指九大天尊之列，成为本章最大信息量转折。
- 王林在无弓可开的状态下，以「退三步坐于玄罗身后」的方式借势，体现其对玄罗态度的精准判断。
- 「主人的哥哥仙罡九阳」一语，透露掌尊背后另有主人，且与九大天尊体系相关。
