# 第1929章 海子

## 一、天尊涅之地：弃闯第五殿而去

- 王林已闯过天尊涅之地的四座宫殿，四殿金光弥漫连成一片。他虽知欲最快引起大天尊注意，天尊涅之地是最佳选择，但因另有要事，未继续闯第五座宫殿，自第四殿直下大地。
- 常理：闯此地者即便自知无法过关，也会去见识下一殿以知难度、据此修炼。王林却对第五殿丝毫不理会。
- **竹林天尊**由此起了忌惮，暗忖：「他若非是没有丝毫把握去闯第五层，那么便是在他看去，第五层无论看不看，只要他想，就可以轻易闯过」，并表示「我倒是期望，是后者」。
- 落地后众天尊修士抱拳恭贺，其中大部分是王林五十年内交战过的对手，也有意图结交者。王林一一温和回礼后，以「还有要事」告辞，化长虹入古老传送阵，化雾消失。
- 众修士神念议论其深浅：有断言这白发天尊最少可闯过第七层；有三十年前与其交手者认为四层已是极限；亦有人认为岁月虽短但机缘可致进步，静待其第二次来此。

## 二、回归山海洲洞府

- 王林肉身盘坐于**山海洲**山海旁的山峦洞府内，睁眼时目中奇芒一闪；守护肉身的**金尊海龙**露出喜色，缩身环绕低嘶亲昵。
- 王林以洞府禁制中特意留下的**岁月禁**校验时间，确认「与在天尊涅之地的时间一样，没有变化」（内外时间一致）。
- 出洞时为黑夜，明月高悬，海风吹起其一头白发，月光下如可折射银光。

## 三、此行目的：夺取山海树灵

- 王林现已具备**天尊层次战力**：在仙族大地七十二洲内，除**大天尊**及四十八个**跃天尊**外何处皆可去，九成九宗派可踏于脚下，堪称立于仙族巅峰之列；即便面对被封印的古老之魂亦可一战。
- 目标：取撑起整个山海的**山海树（山海树灵）**——此事在他未得天尊战力前根本无法完成。
- 阻碍：山海内有可将**七十道神通融于一指**的**海子天尊**。

## 四、山海对峙

- 王林踏金尊海龙潜行入海（海龙在山海中如鱼得水，速度更快），激起漩涡与呼啸，海兽退避。
- **战前盘算**：「天牛魂铠时间无法太长，即便是如今，也只能有不到半个时辰」；「那海子天尊很强，但在我魂铠与速神诀下，她想要败我，却是不可能」；但他短时间内也胜不了她。
- 临近山海中心时，滔天海浪化作海墙拦路，被海龙撞碎；海水沸腾中升起约万丈大小的**章鱼海兽**（气息相当于金尊修士），其头顶立着**海子天尊**。
  - 形貌：绿色衣裙、碧绿笛子、长发束脑后、明眸绝美，额头有**五彩海星**。王林认为其容颜为此生仅有可与**木冰眉**难分上下者，且身为天尊别具气质。
  - 章鱼海兽与金尊海龙互相敌视，显非初次相遇，此前已有争斗。

### 双方交涉
- 海子天尊：「王林，你又来干什么？那山海树灵，我虽无用，但也绝不可能让你取走。」
- 王林：山海树灵对他有大用，且只需一部分，不影响山海变化；并指出此物本为**仙祖**当年封印于此，海子天尊仅因占据此地为洞府，不能据为独有。
- 海子天尊：「我在这里，这山海的一切都是我的」；讥其三年前**真身齐出**尚接不下她三式，三年而已又来自取其辱。

### 交手
- 海子天尊一指之下天地色变，四周海水现出**七十个巨大漩涡**，每个漩涡蕴含一道神通——出手即最强之术，意在一式逼退王林。
- 王林面孔幽光一闪，早已隐藏的**天牛圈腾**幻化而出，弥漫全身——**天牛魂铠**阔别五十多年再度出现，修为气息轰然暴增，其身自海龙背飞起俯视对手。
- 海子天尊瞳孔骤缩，认出其为数量堪比跃天尊的「**魂者**」，当年一战便看出对方有所保留，却没想到是此等身份。
- 海子天尊瞬间把握关键：「魂铠都有时限，我倒要看看，你穿此魂铠，可以坚持多久」，玉指向天空一挥。（章节至此中断）

## 五、要点提炼

1. 王林战力已达天尊层次，行事重心从「引起大天尊注意」暂转为「夺取山海树灵」。
2. 竹林天尊对王林深浅的忌惮，为后续埋线。
3. 天牛魂铠的**时限（不到半个时辰）**是本战最大变量，海子天尊已抓住此弱点，战法转为拖延消耗。
4. 山海树灵的归属存在法理争议：仙祖所封 vs. 占地者所有。
