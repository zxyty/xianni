# 第1895章 第九本源

## 一、百一十年枯坐

- 王林在绿魔蝎庙的绿色空间中，于**天逆**（夭逆）的保护下枯坐等待，本章交代总时长达**一百一十年**（先八十年，后又三十年）。
- 这段岁月中他**吸收不到天地之力、无法修炼**，只能默默等待，人似成老者，记忆封尘如隔雾：洞府界、天牛洲、乃至自身危机都渐渐淡忘。
- 唯有几个身影始终不忘：**父母**，以及那个「温柔含笑、抚琴不语的女子」（指李慕婉）。文中以「颠覆整个世界，或许只为寻找一个身影……哪怕只是倒影，也要逆转苍穹将其摆正」点题「逆」之母题。

## 二、绿袍老者的最后试探

- 老者寿元**不足三十年**，不愿本族代代流转所备的贡品成为他人嫁衣，也不信有人能以走向死亡的代价坐上一百一十年，遂决定收手试探。
- 他在两名**绿魔使者**陪同下走入王林所在空间，言辞恳切：
  - 敬佩王林之忍；
  - 告知据绿魔使者感应，**天牛洲与绿魔洲的交战已到最后程度**；
  - 提出条件：得造化后**不要为难绿魔洲**，则即便王林尚存神智，他也毫不犹豫给予造化；
  - 临终托付：将蝎庙下埋葬的**本族历代祭祀骨灰送回中州**（其族之家）。
- **暗手**：袍中右手捏一枚**绿色玉简**，不需修为引动、唯历代祭祀可用，功能除毁灭外还可**察觉四周心神波动**。只要王林有半点心神波动，便立刻轰杀。王林毫无波动，试探过关。

## 三、赐予造化：孟土珠与本源沙土

### 1. 三颗孟土珠
- 老者咬破舌尖喷血，绿魔蝎群嘶鸣退散，露出王林枯萎肉身。
- 老者道「八道本源，还缺少一道」，抬起长满绿色毛发、干枯腐朽的**右臂**，绿毛脱落、黄芒笼罩，**手臂融化**析出三颗**孟土珠**。
- 三珠分别融入王林**眉心、胸口、丹田** → 土黄光芒万丈，数个时辰后王林体表覆一层土，如泥人不动。
- 三日后毫无变化，老者诧异：三颗孟土珠**只够让土本源小成**。

### 2. 三粒本源沙土（关键设定）
- 老者以特殊手段从自己眉心拽出**三粒暗红色沙土**，为其族耗费极大、无数年中收集而来，蕴含莫大土本源之力。
- **来历传闻**：此乃**仙祖当年开辟出第一块大陆时诞生的九粒本源沙土**之三。
- **九粒去向**：三粒在此老者手中；**五粒被人吸收，成就土本源之力**；**一粒化作一块大陆，其上修建了中州皇城**。

### 3. 三粒沙土之效（逐粒）
| 顺序 | 效果 |
|---|---|
| 第一粒 | 王林体外薄土暴增成**九丈土球**，维持九天后急速收缩消失，又自体内扩散，如此**循环八次**后失效 |
| 第二粒 | 土球本源气息再起，直接**循环九次**；第九次完成刹那，王林体内凝出**第九道本源** |
| 第三粒 | 土本源之力轰然剧增，王林**枯萎之身刹那恢复、体内一切伤势全部逆转**；土本源膨胀，现出凝聚**第三具本源真身**之兆 |

- 第九道本源出现后，沙土残余本源之力继续轰入其中，向**本源真身**冲击。
- **卡点**：因王林意志（元神）未散出融入，第三具本源真身**始终无法彻底凝聚**。

## 四、结论与前瞻

- 一旦王林元神自天逆保护下散出，将**一举占据土本源与雷霆本源两具真身**，成为**三具本源真身之修**；即便修为仍是**空灵巅峰**，实力亦将暴增数倍不止。
- 王林此刻已有**九道本源**，元神一现即可以此**冲击空玄**。
- 老者对王林体内本源的判断（重要设定）：
  - **虚之本源 3 道**
  - **特殊本源 2 道**
  - **实之本源 4 道**
  - 他无法助其凝聚特殊与虚之本源的真身，但**四道实之本源可以**——暗示后续尚有可为。

## 五、伏笔与待办

- 绿袍老者的两项请求（不为难绿魔洲、送骨灰回中州）尚未获王林回应。
- 天牛洲与绿魔洲战事已至尾声，王林出关时机与战局关联。
- 中州皇城所在大陆由第九粒本源沙土所化——为后文中州线埋设定。
- 另五粒沙土被何人吸收、成就土本源者是谁，未交代。
