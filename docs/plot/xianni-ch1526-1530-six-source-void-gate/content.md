# 仙逆 第1616-1617章：本源一出万人惊 / 这里是，仙罡大陆

## 一、场景与战局背景
- 地点：昆虚星域，朱雀星外星空。
- 战况：界内（昆虚一方，南云子、司徒南、龙磐子、鲁夫子及数千修士）与界外修士（周瑾、青衣男子等）激战已持续数月，界外久攻朱雀星不下。
- 朱雀星外护星大阵为数十年内不断巩固而成，抵抗力极强。

## 二、空门显现与本源层层加码
星空中凭空出现「空之大门」，无人能找出引动者。空门凝实如实质，光芒万丈照亮漆黑星空，威压如天地，逼得低阶修士跪拜、双方战场被横扫推开。

本源依次显现（界外视角所见）：
1. **雷本源** —— 无数雷霆环绕，星空震颤。
2. **火本源** —— 火海汹汹，与雷霆争辉。
3. **因果本源** —— 化作模糊图案「因果印」，无人能看清；看清即被吸入因果，九死一生。
4. **生死本源** —— 空门上黑白二气旋转交错。
5. **真假本源** —— 空门模糊，其后再现一虚幻空门，两门并立难辨真假。
6. **第六道本源** —— 第1617章末尾显现，属性未点明，虚神天尊、周瑾、青衣男子同时色变。

### 战力评估（青衣男子口径）
| 本源数 | 一旦轰开空门可战 |
| --- | --- |
| 三道 | 空灵初期大能（引动者仍为空涅初期） |
| 四道 | 空灵中期修士 |
| 五道 | 空灵后期 |

青衣男子认为四道已是极限、「当为天之骄子」，并断言：若引动者是界内之辈，必须立刻杀死，否则后患无穷。周瑾则震骇于此空门远超自己当年引动之时。

## 三、王林一侧：生死本源与第五道神通「生死印」
王林身在苍茫虚无中，并不知外界空门已现，只听到遥遥轰鸣。

- 盘膝坐下，凝出**第四道本源：生死本源**，出现在血色光芒之外。
- **「我左手为生」** —— 左手白气化作白色印记，蕴含无尽生机与天空意志。
- **「我右手为死」** —— 右手黑气缭绕，死气惊天，蕴含大地之力，与生机鲜明对比。
- **「我王林，便是生与死的天地」** —— 双掌合一，黑白交错光芒穿透而出，笼罩虚无。
- **生死印**：黑白光芒在血光中化作生死印记，环绕王林，与其余三道本源相融。此为王林自创的**第五道神通**，「足以让天死地生，其威力莫测」。

> 归属提示：外界所见空门本源与王林在苍茫虚无中的修行同步对应，文本已作明确并叙。

## 四、虚神天尊分身出手
南云子看破良机，低吼震醒界内数千修士，率司徒南、龙磐子、鲁夫子等反攻青衣男子一方，腥风血雨再起。

随即远处星空一声冷哼，紫色雾气瞬息临场：
- **南云子**：本就有伤，被撞得面色惨白、喷血倒卷回朱雀星，喝令「太古五尊速退朱雀星，以阵法对抗」。
- **鲁夫子**：喷出大口鲜血，**肉身轰然崩溃**，元神萎靡急遁。
- **司徒南**：危急中取出**青霖所赠的玉简法宝**挡下，玉简崩溃，其人喷血后退。
- **龙磐子**：身子一散，重凝后几近透明，大袖卷起司徒南与鲁夫子元神退入朱雀星。
- 数千界内修士齐齐退回朱雀星。

紫雾散去，走出一名不怒自威的老者——**太古五尊之一「虚神天尊」**，本次到场的是其**分身**。他冷视空门，瞳孔微不可查地一缩，随即斥责界外修士「数月时间还没攻下此地」，率众向朱雀星走去；每一步落下，朱雀星外阵法即轰鸣剧变，隐隐欲崩。

## 五、伏笔与看点

- **忍住第三步的诱惑**：南云子感慨世间竟有人能忍住第三步诱惑而积攒多道本源，凸显王林选择的稀有。

# 王林凝聚第六道杀戮本源、窥见仙罡大陆并归来朱雀星（第1617-1618章）

## 一、虚无中的最后准备

### 第六道神通：真假永恒印
- 王林右手在前一挥，以第五道**真假本源**凝聚成印，化作其**第六道神通「真假永恒印」**，威力莫测。

### 第六道本源：杀戮本源
- 五道本源之后，王林起身以储物裂缝取出一把剑——此剑正是**清水**杀戮本源大成时凝聚而出的法宝，剑即杀戮本源本身。
- 王林一抓之下剑体崩溃，化作无数暗红色气息成雾，包裹全身；几次呼吸间尽数自汗毛孔吸入，成为其**此生第六道本源——杀戮本源**。
- 雾散后王林神色泛起疯狂萧杀，滔天杀戮自体内爆发。
- 宣言：「我王林今日，便以这六道本源，去轰开空门，成就第三步大能。」

### 仙人不灭体之血的处置
- 王林收走仍在昏迷的**疯子**，一挥大袖使环绕体外的血光崩溃、重新凝聚成当年被**掌尊**从其体内分离出的那滴血液。
- 血液凝成刹那血光转为金色，透出惊人仙气——**此血即仙人不灭体的全部**。
- 王林**并未与之融合**，而是按于眉心化作一个金点隐没，定位为「**日后的一件法宝**」。
- 王林在此虚无之地**沉睡了七十多年**，临行有追忆、不舍、难忘。

## 二、岔路漩涡与仙罡大陆惊鸿一瞥

### 漩涡一分为二
王林一步踏出，前方虚无出现巨大漩涡，却在急速转动中**一分为二**，形成两条道路：

| 漩涡 | 指向 | 特征 |
| --- | --- | --- |
| 其一 | **朱雀星**（王林当年消失之地） | 传出王林熟悉的气息 |
| 其二 | **仙罡大陆** | 隐透金光、浓郁仙气，吸引王林眉心的金色血液 |

### 神识所见之天地
- 无边无际的大地，天空悬有**九个太阳**，无限之大、光芒笼罩。
- 山峰峥嵘、无尽大海、湖泊河流密布；王林神识全力一扫，**仅覆盖不足万分之一**，其大几乎堪比无数个界内界外星域。
- 仙气浓度无法想象；地面植被无一为王林所识，小兽中已有仙气缭绕、具备不俗修为者。
- 王林感受到多股强大气息，强度令他联想到当年在**七彩界**所见的**七彩道人**。
- 一道蓝光自天空掠过，半空一顿化作**穿蓝色衣衫的女童**，看似十七八岁、相貌漂亮、双眼无暇带好奇，其目光似能穿透一切、依稀看到了王林。
- 王林神念方出，即有一股力量自漩涡内传出加以阻止，将其神识弹回。

### 「我叫娃娃，你叫什么」
- 王林沉默许久后**选择走向通往朱雀星的漩涡**；脚步落入刹那，脑海传来稚嫩童音：「你怎么走了？这里是**仙罡大陆**啊，我叫**娃娃**，你叫什么？」声音因距离太远而模糊消散。

## 三、王林的推断：界内界外的惊天隐秘
- 「仙罡大陆」并非首次听闻——**疯子**曾说其故乡即仙罡大陆。
- 王林梳理出一根贯穿众人的线：**仙罡大陆、七彩道人、清水、疯子、掌尊、战老鬼、饲养天道、天逆珠子、远古仙域**，以及战老鬼当年在**云海**与掌尊交谈时提到的一个词——**「内府」**。
- 他判断：当这根线把所有人联系起来，便是界内界外最终的惊天隐秘。
- 「或许**梦道**之前的我，没有资格去知晓这些事情，但如今，这个资格，我有。」随后冰冷走入通往朱雀星的漩涡。

## 四、朱雀星外：空门之压与阵法崩碎
- 昆虚星域朱雀星外，星空中无限之大的**空门**上缭绕**六道本源之力**，成为古往今来界内界外从未出现过的巅峰之相。
- 破门之人迟迟未出，形成无形窒息之力，连**虚神天尊**都感到压力。
- 虚神天尊的判断：
  - 六道本源「就算是掌尊也都无法做到」；
  - 破门者修为即便仍是**空涅初期**，也可与**空玄初期**一战；
  - 其将在很短时间内**跨越空境**；
  - 若为界内之修，**必须杀之**。
- 虚神天尊（**分身**前来，具空玄初期修为）整条手臂化作紫色雾气，一拍轰碎已坚持数月、本将崩溃的朱雀星护星阵法，**朱雀星再无保护**。
- 他踏过碎阵，见到高耸入云的**封尊雕像**，雕像四周有**数千界内修士**环绕死战；下令「杀进去，毁灭此星后速速离去」。
- 正要毁灭雕像之际，他面色骤变转身——「破门之人！」

## 一、浩然之气喝退虚神天尊

虚神天尊分身出手前放言：王林「当年没死，今日也必死无疑」，讥其尚未踏入第三步；并自陈当年欲夺舍王林肉身未成，今日既送上门便是其物。对虚神天尊而言，当年之事是耻辱，更让他后怕——他怕的是**那支箭**。但身为太古五尊，他不能不战而逃。

王林神色冷漠，闭眼后猛地睁开，眉目间滔滔涌出**当代大儒的浩然正气**：明悟天地、不畏鬼神的天地之气，连天地规则在其面前也如同虚设。文中点明其理据——修士也是人，纵修至第三步成大能，本质仍是人。

王林一眼看去，只道二字：「**退下**」。在他眼中，对方无论多强，与凡人、蝼蚁、一山一石一草一木无异。

效果：
- 虚神天尊分身身形一顿，感到王林仿佛成为天地，气息顺双眼轰入灵魂，令其重回未修道时仰望天空、自感渺小如蝼蚁的震撼；他下意识后退数丈，露出罕见惊恐，此刻之态与王林梦中的筑基修士无异。
- 周瑾面色惨白，眼露绝望。
- 青衣男子本欲出手杀王林，此刻脚步一颤、道心不稳；他未修道前曾为举子，心中浮现当年遇大儒先生的震撼。
- 四周数万修士齐齐再退，目露无尽畏惧。

## 二、六道本源引动空门

王林大袖一甩，看都不看对方，右手抬起五指迎空门，宣言：「**雷霆、火焰、因果、生死、真假、杀戮，六道本源，以吾王林之名，凝聚这天地间，轰开空门**」——空门上传出无上威压。

关键设定：
- 王林等这一天等了**两千多年**；这是他第二次面对空门，第一次雷霆本源大成却未轰开。
- **本源越多，引动的空门越难轰开**。王林的六道本源天地间从未出现，故所凝聚之门为界内界外史无前例、前无古人甚至后无来者的最强一次，难度数倍于清水当年，更远超周瑾之辈。
- 一旦轰开、接受空门之力灌入，可将六道本源在空门之力下融合，修为突飞猛进，成为第三步大能。
- 轰开空门的意义：成第三步大能、叱咤风云、有资格知晓界内界外最终的隐秘。

往例对照：
- **清水**当年以杀戮本源引动空门，一剑之下空门打开，更崩溃出几道裂缝、令空门碎开一角，是罕见的惊鸿一击。
- **周瑾**之辈所谓轰开空门，需拼尽全力、配合香火，如凡人推千斤大石，打开后已如经历一场大战。
- **司徒南**当年轰空门有**青霖**帮助，仍吃了苦头，故此刻最为担忧。

## 四、雷霆一拳与昆虚雷海（第1619章 一语雷霆四海轰）

王林跃身而起，喝「以我王林之名，号令天地雷霆」，右手一握，无数闪电如被抓在手中，一拳直抵空门前。其身影与庞大空门相比极为渺小，却如宇宙初开时第一道不灭雷霆。

- 此拳当年也曾轰出，只能将空门大开一丝；如今六道本源大成（尚未融合），仅雷霆之力已是当年数倍不止。
- 一拳落下，天地轰鸣，震动令四周数万修士不少喷血倒卷。
- **庞大空门通体一震，慢慢打开了一丝**。

随即王林一声长啸，引发昆虚星域级异象：
- 昆虚星域无尽星空中凭空出现道道雷霆闪电，如受呼唤般自四面八方直奔**朱雀星**；一颗颗修真星上的雷霆仿若被抽出。
- 整个昆虚星域震动，雷霆几乎连成一片，如大海卷起滚滚雷浪横扫星空。
- 文中定性：天地间所有雷霆在迷茫无数万年后，找到了它们的**雷霆之王**，君王一声长啸便是召唤。
- 昆虚星域内成群（几十上百乃至千人）追杀昆虚残余修士的界外修士一片哗然茫然，有人闪躲不及被雷霆碰到即全身崩溃惨叫；众多神识扩散追查，察觉雷霆皆去往朱雀星方向，疑其地有惊天变故。

结尾三方震动：周瑾绝望更浓、完全呆住；青衣男子虽为空玄初期亦头皮发麻、面色苍白；虚神天尊一愣后震惊，判定「这绝非寻常的雷霆本源」，自言见过雷修大能却绝无此等声势，暗自推究王林的雷霆本源究竟如何形成。

## 五、悬念

空门仅开一丝，六道本源之门能否被彻底轰开、王林能否踏入第三步，尚未见分晓；南云子、青龙圣皇（四圣宗四宝）的援手与虚神天尊的伺机出手均未落地。

# 第1619—1620章 雷门一开惊人鸣：四域雷霆与连碎空门

## 一、序幕：一啸召来界内四大星域之雷

王林在朱雀星外、空门旁一声长啸，其召唤以无声的特殊方式层层扩散：

1. **昆虚**：雷霆先起，虚神天尊本不放在眼中。
2. **云海星域**：一道道雷霆自各大陆涌出，更从稀薄雾气中冲出连成一片，**直接轰开了与昆虚之间的壁障**冲入。
3. **召河星域**：闪电照亮漆黑星空，大量界外修士冲出修真星呆滞观望，齐问「发生了什么」。
4. **罗天星域（罗夭）**：此域**尚未被界外攻陷，仍在界内手中**，界内修士目瞪口呆看着滔滔雷霆直奔昆虚。

序幕的落点是**罗天星域内破碎的雷仙界**——其大门上那道恒古以来存在的**不灭雷霆**，在轰鸣下颤抖、脱离雷仙界，**无数万年来第一次飞出**，远看如一道银河直奔昆虚。至此界内所有雷霆尽数扑向朱雀星、扑向白衣长发仰天长啸的王林。

## 二、界外太古星辰亦被引动

往昔有完整**封界大阵**阻隔，界内界外难以相通；但此时封界大阵已被界外撕开一道**缺口（在云海）**。王林的长啸遂由缺口传出，弥漫界外太古星辰：

- 界外虚无中幻化出无数雷霆，直奔云海缺口。
- **界外凡修行雷霆之术者，全身元力不受控制地滔滔涌出，化作雷霆远去。**
- 界外之雷自缺口涌入，与界内之雷融合，共赴朱雀星。

## 三、第一击：以万雷轰碎空门（雷之本源）

啸声一停，界内界外雷霆同至。四周界外修士心神巨震、七窍流血，全力施展神通对抗。王林右手一指空门，遂有**古往今来从未有过的「轰门之画」**：以界内界外所有雷霆之力，极为嚣张霸道地轰击空门。

- 空门先现细密裂缝 → 边缘碎末 → 光芒亮过太阳。
- 王林大喝「给我碎」，空门右侧先崩、左侧继崩，瞬间彻底碎裂。
- 空门崩溃处出现**巨大漩涡**，如河流般的**空门之力**宣泄涌向王林。
- **王林大袖一甩，把空门之力尽数卷回漩涡，拒绝吸收。**

### 修为变化（关键）

轰开空门使王林**自碎涅大圆满、自天地衰劫中迈出最关键一步**，达到**第三步空境·空涅初期**。但文中明确：

> 这**并非实质修为，而是一股气势**——只要他愿意吸收空门之力，即可瞬间化作实质修为。

王林拒绝：这样的初期只是**雷霆一道本源**而已。他忍到今日、忍到**六道本源大成**，若只换来一个空涅，他不满足。**他要的是一鸣惊人。**

## 四、虚神天尊的解说与评价（设定要点）

太古五尊之一的虚神天尊，从震惊到失声，再到**第一次从心里称王林为「封尊」而非「小辈」**，并给出关于空门的关键设定：

- 古往今来轰开空门者，**往往立刻吸收空门之力**凝固自身本源，瞬间达到真正的第三步；**一旦吸收，空门即消散**。
- 若拖延，**空门会很快重新凝聚**；一旦再凝聚，先前的空门之力便消散，之前的轰开等于无用，且**第二次凝聚的空门强度更大**。
- 但王林**在无空门、修为未到第三步时就能斩杀三步大能**，故空门虽强也无法奈何他——虚神天尊承认自己此前判断错误。
- 王林的真实图谋：**以每一道本源轰开一座大门，做到真正的「六道本源成三步大能」**。难度极大，好处却比轰开一次强上无数。
- 虚神天尊态度：复杂之中**杀机更浓**——「他既然如此狂妄，当着老夫的面去做此事，那么我倒要看看，他能如何」。

## 六、第二击：以九色火焰焚碎第二座空门（火之本源）

王林大袖一甩，漩涡急速转动，扩散出**比方才强烈数倍的威压**，星空咔咔碎裂；漩涡消散，**取而代之的是第二扇空之大门——比方才小一些，但浩荡之威更浓**。

王林右手一指，其声如同法则，使星空一颤：

> **「火之本源，以我王林之名，焚此空门」**

- 九色火焰滔滔而起，卷动星空；昆虚、云海、罗天、召河乃至界外太古星辰，无尽火焰如那雷霆一样呼啸而来。
- 火海笼罩空门，轰然崩溃——**这一次没有碎片散开，所有碎片尽在火焰中烧成灰烬**。
- 宣泄出的空门之力**比第一次浓厚十倍**，但仍不足以融合六道本源，王林再次甩袖卷回，重归于更大的漩涡。
- 王林长笑：「空门，再来」

### 气势再增

第二道空门碎裂，王林气势**自空涅初期直接暴增到空涅中期**。文中点明：今日是王林的**造化之日**，是他踏向巅峰的一天，他忍了这么多年就为成为大能这一刻。

## 七、王林的底层判断

- 他此前见过数次空门，隐隐知晓：**每多轰开一次，崩溃时散出的空门之力就越多**。
- 他六道本源大成，欲将六道融合一起，**所需空门之力庞大到无法想象**。
- 空门之力为何物他不知，但明白它是**修士成为第三步大能的关键，堪比炼气之于筑基**。
- 故而，他必须连续轰碎空门。
