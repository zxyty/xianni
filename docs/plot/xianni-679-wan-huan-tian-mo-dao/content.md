# 第679章 万幻天魔道（第七卷 名震罗天·第二更）

## 一、抵达冉云星
- 王林收起**星罗盘**，迈步踏入**冉云星**，穿透罡风层的刹那眼中寒芒闪烁。
- 早在星外便察觉：大地一片废墟、仙力波动回荡——此地**刚经历一场大战**。
- 神识见到**冉云星南部**的**柳眉**，其样貌比当年更加惊艳绝伦。王林一踏之下瞬移至极南之地，与柳眉相隔百丈。

## 二、冷淡驱离与身份识破
- 王林开口：「人你也杀了，可以离开了。」
- 神识扫到下方城池内**孙析的分身**，遂想明前因后果：**冉云星三人在分身一事上有所隐瞒**，王林不愿强出头，「略尽心意便可」。
- 令王林心沉的是柳眉修为已达**问鼎后期大圆满**，瞳孔微缩。他判断：
  - 此女身上余留仙力环绕，为**被人强行提升**（疑与**幻家老祖**有关）；
  - 强行提升只是**仙力**突破，**意境感悟断然不到等同地步**。
- 柳眉试探「我们之前可曾见过」，王林答「没有」。柳眉一笑（一如当年朱雀星），王林极为厌恶。
- 柳眉挑明：「王林，你真的以为，我认不出你么」——理由是**除了你，没有人会拥有这种冷漠的目光**；样貌可改，目光不可改，而改变一切正是为了不被她认出。
- 王林承认：「我就是王林」，并警告若再如朱雀星那般纠缠便杀人。柳眉内心大浪滔天：没想到会在**罗天星域**遇到王林，且其修为强到她看不透。

## 三、动手：柳眉的判断与旧怨
- 柳眉断言王林修为不可能超过自己，必是**有隐藏修为的宝物或神通**，今日不许他走。
- 王林抬手发出**寂灭指**风：黑芒呼啸、半空掀起环形波纹、内蕴雷鸣。柳眉掐诀成法印光幕硬接，光幕电光游走、顷刻龟裂。
- 柳眉据此确认：「你的修为，只是**问鼎初期**。」
- 王林冷道：强行提升弊端太多，**你那师尊如此行事，怕是另有目的**。
- 柳眉要**了结朱雀星恩怨**，扬言「让我，送你去与**李慕婉**团聚」。王林怒喝「找死」，一拍储物袋放出**七星剑阵**，化作七道长虹。

## 四、红蝶之形与道化黄泉
- 柳眉玉指点眉心，**红芒**包裹全身，凝化成**红蝶**——神色高傲、凤目带煞。王林神识看去，**分明就是真真正正的红蝶，再无任何柳眉气息**。
- 红蝶取出**红色玫瑰**，花瓣带异力飞袭；王林以七星剑阵七剑成圆旋转成剑风，尽数绞碎。
- 红蝶甩出**花蕊**组成**符文**，放大至百丈如巨峰压来。
- 王林一指天际，霹雳划过，**道化黄泉**横展而出，腥风血雨、内闪电光，捏碎符文，如黄龙卷住红蝶欲拉入黄泉。
- 红蝶惊道：「**道念**，你居然拥有了道念」。

## 五、周茹与母亲——攻心
- 危机之际，柳眉再按眉心，**黄光**化出瘦小身影：**周茹**。一声「叔叔」蕴含奇异力量，令道化黄泉**蓦然一顿**。
- 周茹哀求「你不要把我扔下好么」；王林痛苦喝道「够了，柳眉」，黄泉将其卷入。周茹落泪问「叔叔，你要杀茹儿么」，王林断言「这是假的」，黄泉绞杀风暴冲入其体。
- 千钧一发，一声「**铁柱**」如洪钟回荡——黄泉内浮现王林**阔别八百余年的母亲**，慈祥望着他。王林心颤、手颤，**道化黄泉崩溃，化作虚无消散**。
- 王林眼中红芒：「这，也是假的。」柳眉声音四面八方传来：「假的么王林，我**万幻天魔道**下，**有假有真**。」

## 六、万幻天魔道全面展开
- 虚无中依次幻化：周茹、红蝶、**王林之父**（和蔼目光）、**王卓**（不再沧桑老者，而是当年意气风发的少年）、**遁天**（苍老嘱托「徒儿，你要切记将**炼魂宗**传承下去」）。
- 随后一个个王林熟悉之人纷纷现身，目光各异（复杂、失落、喜悦、哀愁）。
- 蓝芒化作一女，正是**李慕婉**，温柔问：「王林，我，也是假的么」——她站在王林母亲身边，好似一对母女。
- 王林闭目道破功法本质：「**万幻天魔道，如天魔化身，入体，勾起元神之火，焚烧身心**」，并质问柳眉有多少深仇大恨，竟煞费苦心搜集他的过去。
- **章末**：四周熟人尽化青烟，飘渺般齐齐涌向王林，**融入其体内**。

## 关键判断与伏笔
1. 柳眉的问鼎后期大圆满为外力强灌，意境不足——是王林可能翻盘的破绽。
2. 柳眉背后「师尊」（疑涉幻家老祖）另有目的，为后续埋线。
3. 万幻天魔道以「有假有真」搜集目标过去为杀招，直攻元神，非力量对抗。
4. 孙析等冉云星三人隐瞒分身之事，王林选择不再介入。
