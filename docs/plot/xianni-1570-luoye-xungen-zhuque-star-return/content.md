# 第1570章 落叶寻根

## 一、天梯与封尊雕像

- 王林带着**疯子**站在天梯上俯瞰朱雀星：山河改变，地面青草弥漫、清香随风，已然陌生。
- 天梯连接处为朱雀星**最高之峰**，被人以大神通之术以山为体凿成巨大雕像：身穿长袍的修士，左手掐诀，右手握**开天斧**，抬头望天，威严欲与天争。
- 因高低落差，朝圣修士踏入此星、越行越近时威压渐强，如同膜拜。
- **此雕像所刻正是王林**——云海第一战时的王林；唯**面部略有模糊**，外人难以看清。
- 老者解说：此像取自封尊当年云海第一战、斩杀**火雀族老祖**与**南诏上人**后，立于**封界大阵缺口**处以一人之力对抗界外入侵修士大军、使万人不敢迈出半步的英姿。
- 雕像来历：第一战后封尊之名赫赫，界内修士得知其出自朱雀星，遂自发组织，由几位大神通前辈主持，在朱雀星**周武泰**的认同下将最高峰凿成封尊雕像。
- 王林暗记：此峰当年属**朱雀国**，是朱雀国圣地——如今已改。

## 二、朝圣者一行的插曲

- 天梯上有一老三少（师徒四人）向石像参拜。
- 疯子拍手大笑，讥此山像粗糙、不如自己捏的泥人；三名弟子回头怒视、面露鄙夷。
- 王林不愿多留，带疯子远去。三弟子中一青年冷笑「如此粗俗之人，也配来朝圣封尊故乡」，同门附和称其二人口出不逊、必遭惩罚、狼狈被逐出此星。

## 三、故地巡礼：处处物是人非

| 旧地 | 今貌 | 王林的旧忆 |
| --- | --- | --- |
| 朱雀星诸修真国 | 合并为一个国度；宗派整合为**朱雀星九大宗门**，占据绝大部分地域 | 当年驳杂林立 |
| 炼魂宗 | 山峰消失成湖泊，四周阁楼灵力波动，已是另一宗派 | **遁天**慈祥容颜；**司徒南**在此苏醒，「让天不下雨」的霸道之言犹在耳 |
| 巨魔族 | 变为草原，凡人游牧、歌声、羊群与大狗 | — |
| 雪域国 | 白雪早融，成茂密丛林；城池推倒埋成废墟 | 一处凡人都城承载王林近百年时光与凡童**曾牛**的成长痕迹 |
| 雪域国某城残骸 | 杂草小兽穿梭；街道被一处**巨大深坑**吞没 | 王林当年居住的街道，仅存的一丝熟悉随之崩溃 |
| 修魔海 | 盆地被填满，成为九大宗门其中一宗的山门区域 | 与**李慕婉**同居的山洞、那条庞大龙身、李慕婉留下心血之处 |
| 温馨山谷 | 被抹平，成为一处很美的内海 | 李慕婉红颜老去之地，**周茹**长大的地方 |
| **赵国** | **「这里，没有变」** | 封尊幼年长大之地 |

## 四、心境

- 王林之前也曾回过朱雀星并见过变化，但此次几乎翻天覆地、来得太突然，无法适应。
- 他**不敢散开神识**看清全星，不敢去赵国、不敢去父母墓前，害怕看到更多陌生。
- 对「圣地」的评价：世人只知此为封尊故乡，欲改造成圣地，却不明白这样的圣地是**空洞的**；外表再美也只是浮尘。
- 自我定位：即便成了封尊，他仍是「一个普普通通的人」「一个小小修士」，不在意外表与名声。
- 所求：一个家、一个能平静回忆的故乡、哪怕一丝熟悉，用以温暖**两千年冰冷修道**——如今这温暖成了奢侈。
- 王林问疯子「为什么会这样」，疯子只咧嘴傻笑说「本王觉得挺漂亮啊」；疯子罕见沉默时，隐隐也想家了。
- 结尾：王林长叹，前往他最不敢去的**真正的家**——往昔的赵国；在天空望着下方，眼中模糊。老者的声音同时响起：「此地，便是封尊幼年长大的地方了。」

## 五、要点提示

- 本章为纯粹的还乡抒情章，无战斗，无境界突破；主要功能是标注**时间跨度之久**（朱雀星改朝换代、地貌重塑）与王林作为「封尊」与「游子」的身份割裂。
- 云海第一战的战果在此被追述定格：斩火雀族老祖、南诏上人，封界大阵缺口独挡界外大军。
