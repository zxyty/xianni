# 仙逆 第1223章 惊变（第九卷 云海之巅）

## 一、蚊兽蜕变成功
- 地点：七彩界司马墨旧洞府群第一座洞府。
- 手段：王林打开陈天军搜集的储物袋，元晶不断飞出落于禁制上，被吸干元力后化飞灰，新元晶随即补上；元力经禁制阵法源源涌入蚊兽体内。
- 过程：蚊兽生机渐浓 → 身上紫色消散、透出淡金之芒（金芒一现即有威压） → 元晶耗去近七成后咆哮挣脱卵状包裹，反手以口器刺卵吸干。
- 结果：百年祭炼 + 海量元晶 + 特殊手段，蚊兽蜕变成功。体型缩至三丈，气息堪比**净涅**。
- 处置：王林当即收起，蚊兽是其**杀手锏**，未彻底成群前不让人看到。

## 二、清点洞府与旧事收尾
- 王林收走余下洞府之物，包括那座巨大丹炉。
- 关押**迷失者**与**铭志者**的洞府已空——当年与**白发老者**一战中，随白发老者召唤道念而亡。
- 第八间洞府的老者亦消失无影，仅余一片骨灰。
- 王林暗叹：司马墨尽管找齐了同门，最终无一人苏醒，全部消散。

## 三、强破岁月禁，独占传承
- 第六间洞府：石门上**岁月禁**化作波纹散开；王林一拳轰出，体内爆发强大冲击落入山石，眉心**意境所化规则星点**闪烁，山石崩溃。
  - 目击者：谷内陈天军倒吸凉气、更加敬畏；谷外**云魂子**亦有察觉、心神一震。
  - 王林自感比当年强大太多，“这种感觉，很好”。
- 第六、第七间洞府各取一枚玉简，内容正是四大禁制之一的**岁月禁**。
- 王林神识记全后**捏碎玉简**——不允许他人因自己疏忽从玉简学去，要让岁月禁唯自己掌握。
- 破禁得手的三大前提：修为大进、身为**破灭禁传人**（禁制造诣登峰造极）、司马墨所留岁月禁本就未至精髓（其人亦需百年才略学会一些）。

## 四、第九洞府：七彩雾气与鹿骨短剑
- 第九间洞府禁制最多、最神秘，当年王林只见七彩雾气缭绕，看不清内里。
- 此次按石成波纹透明，见洞内**七彩雾气**似永恒存在、岁月无法抹去；雾心地面有一具**形似小鹿的兽骨**，骨上插着一把**短剑**。
- 王林记起：当年在七彩界也曾见过同样一幕，含义不明。
- 两拳方破山石（第一拳只裂不崩）；雾气不受影响，弥漫成团、诡异蠕动。
- 神识观察后判断：雾气**并非凭空出现，似从鹿骨中诞生**。

## 五、天运子魂魄吸收七彩雾气（本章关键异变）
- 王林正要探手入雾，忽觉被吞入元神的**十八地狱封仙印**中，**天运子分身的魂魄**挣扎欲出——这是被封印、不入轮回的魂魄**首次**在未脱离情况下出现挣扎。
- 王林心神入封仙印，横扫十八层地狱，直入天运子魂魄所在之层，冲入魂内与之融合：气息惊天动地一变，宛如自己成了天运子，神色平静、万事不动容。
- 融合中清晰感到该魂魄对七彩雾气的强烈渴望，遂伸右手入雾。
- 雾气疯狂钻入右手、经元神入封仙印，被天运子魂魄疯狂吸收；鹿骨随即再生新雾，持续约**一炷香**后不再散出。
- 吸收后魂魄晶莹盘膝吐纳；王林产生“印内被封的仿佛是一个真正的天运子，而非两个分身融合的魂魄”的错觉，且这种感觉“让王林很不喜欢”，越来越清晰。
- 王林评语：“很有趣。”

## 六、第二把封印短剑
- 拔出兽骨中的短剑：其上**有封印，与王林此前所得那把几乎一模一样**。
- 短剑一出，兽骨震动坍塌成骨灰。
- 王林判断此时不是解开封印之时，收剑出洞。

## 七、撤离受阻——漩涡降临
- 王林卷陈天军出谷，云魂子紧随，直奔七彩界边缘；**青衫老妇人**赶来，犹豫不敢靠近，遥遥跟在后面（四道长虹）。
- 抵达当初进入时的祭坛处，**祭坛已崩溃成废墟**。
- 王林依**苍松子记忆**中获得的离开之法与印诀掐诀，印记落于虚空，一道被隐藏的裂缝将要打开。
- 骤变：漆黑天空崩碎化作无数碎片，凭空幻化出**巨大漩涡**搅动天地；漩涡深处出现两道蕴含万古沧桑的无情目光，直奔王林落下。
- 来者喝问：**“吞了本尊道果，就这么想要离开了”** —— 章末悬念。
