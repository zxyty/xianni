# 仙逆 第1957-1958章 一鸣惊人（第十一层→第十二层）

## 一、第十一层闯关结果

- 金光扩散，王林自第十一层一步走出，**面色苍白**，随即盘膝于金光内回想闯关经过。
- 第十一层共出现 **九个天外之灵**，几乎无间隔连番而至：
  - 第一灵：**绿魔蝎**
  - 最后一灵：庞大如一颗修真星的**巨象**，象力其大无穷
- 王林判断：九灵皆**虚幻而出**，实力不及本体，但仍几乎每一尊都可达**天尊巅峰**，最后四尊**足以与寻常跃天尊一战**。
- 通关手段：全程**穿魂铠**全力以赴；因魂铠有**使用时限**，战毕立刻脱下以争取最大程度使用。

## 二、仙祖连云决的传承：八极道·极火道

走出第十一层瞬间，王林脑海中响起**唯他可闻**的威严之声：

> 「吾为**连云决**，留吾之感悟于此天尊涅，更有吾一生神通凝聚所化**八极道**，后人若有机缘者，可于此天尊涅中得到……汝闯过了吾之考验，可赐**极火道**……此术不归神通，不归本源，不归法术，也非吾自创，而是**传承太古神境**。」

- 随声出现的画面：一只手掌，**不蕴含丝毫火之力**，抬手一按，一道**青色烟丝**缭绕一根手指**九圈**后幻化放大，形成**九个青色烟环**，散发极恐怖气息。
- 王林**当年曾见过此术**并略有感悟，甚至曾**借虚无内分身之力**略作施展；此番**不借分身**，闭目打坐中抬右手，青烟自现，缭绕指周。
- **关键结论（王林所悟）**：
  - 天尊涅十一层往上，**每一层都有造化**（印证雪雨跃天尊之言）。
  - 八极道**非仙祖自创**，而传承于**太古神境**。
  - 王林推想：**天逆**似从太古神境出来，**大天尊的修为**亦从那里获得，连**仙祖神通**也源出于此——太古神境到底是何存在，成为其新的追问。

## 三、围观者反应

### 天尊修士
- 惊叹：「跃天尊中闯过第十一层的都不多」「他竟从**第五层**在短短时间内直接闯过第十一层」「已无法猜测他的极限」。
- 层次差距：王林至此**与天尊层次彻底脱离**；下方天尊修士**看不到**金光内他指上的青烟。

### 雪雨等三位跃天尊
- 唯此三人看得极清。雪雨辨认：「这青烟我曾在**才微尊**那里看到过，分明是**仙祖八极道中的极火道**。」
- 心态转折：本以为王林与自己同级，方知其「具备闯过第十一层之力」，**跃天尊中每多闯一层差距极大**；三人沉默暗叹，其后化作**更深的复杂与敬佩**（「雁雀岂知鸿鹄之志……我等只能远看」）。
- 雪雨判断王林能过第十二层：「此人绝不会做没有把握之事，既敢踏上，必有其自信。」另有人反驳：唯冥道尊当年首次成跃天尊后能过第十二层。

### 子妥跃天尊
- 罕见地心生**嫉妒**与阴狠：自己当年很久才过第十一层且**未获传承**；断言「第十一层定是他的极限，绝不可能闯过第十二层」。

## 四、王林的目标：何谓「一鸣惊人」

- 只闯过（第十一层）**不算**一鸣惊人。
- 与止步第十二层的**才微尊**齐平，**也不算**。
- **超过跃天尊中最强者冥道尊**，或许才勉强算一鸣惊人。
- 加之对源自太古神境的八极道兴趣极深，遂直奔**第十二层**大殿。

## 五、第十二层前的招揽风暴（第1958章）

1. **近三十位跃天尊**自仙族大陆各地神识冲天而来，齐聚天尊涅仰头凝望，神色凝重。已点名者：**天炎、尘凡、碎梦、韩丹**跃天尊。
2. 古老传送阵再放光芒，**武封大天尊**（五大天尊之一）现身，全场天尊与跃天尊齐齐一拜。他不理拜见，直接向十二层外的王林开价：
   > 「王林，不管你有没有闯过这第十二层，若跟随本尊，本尊给你一个承诺，**你任意提出的承诺**。」
   - 王林抱拳低头：「谢大天尊，不过眼下王某还需全力闯这天尊涅，此事容后再谈，可好？」武封不以为忤，招揽之心更盛。
3. **道一大天尊**自传送阵缓步走出，一身简单道袍，含笑重提旧约：
   - 王林确认：「若王某闯过了**第九层**，道一大天尊还会前来招揽。」
   - 道一：「此事不急，先去闯这第十二层就可。」
4. **武封 vs 道一** 神念对峙：
   - 武封：「此子我看好了，你莫要与我争夺。」
   - 道一：「跃天尊修士就算我等也不能强行要求，一切要看他自己的选择……一旦他度过第十二层，可堪比当年冥道尊，莫说你我，就算那**久帝**老家伙说不定也会心动而来，还有那位**仙皇**——当年不知他许了什么诺给冥道尊，结果被他招揽了。」
5. 众修士侧目：除当年冥道尊一事外，**这是第二次**看到大天尊为一个人当场争抢。
6. 王林深吸口气，**迈步踏入第十二层大殿**；道一与武封立即止谈抬头凝望，全场屏息。

## 六、冥道尊旧事（背景闪回）

- 冥道尊**首次成为跃天尊**即闯过第十二层，引来**大天尊亲自来此观看**，几乎绝大部分跃天尊到场。
- 数位大天尊为招揽冥道尊各出极诱人条件，最终他**选择了仙皇**。
- 当年**才微尊**也未引起如此规模的风暴。

## 七、场外：紫阳宗的算盘

- 紫阳宗一名中年修士借**镜子**远观，苦涩叹息：
  - 「此人怎么闯过了第十一层……第十二层可千万不要闯过！一旦闯过，我拿什么去游说招揽？」
  - 判断：王林一旦成功将**立刻被九帝大天尊与仙皇大力笼络**，连道一、武封在底蕴上都难比那两位。
  - 遗憾：「若是我紫阳宗**双子大天尊上一次转世没有出现意外**，倒也可以与久帝和仙皇比一比。」

## 八、势力/层次要点速记

- 修为层级：天尊 < 跃天尊 < 大天尊（共五位），其上另有**仙皇**、**久帝（九帝）**之称。
- 跃天尊闯天尊涅的历史标尺：多数止于第十一层以下 → 才微尊止步第十二层 → **唯冥道尊过第十二层**。
- 待解伏笔：**太古神境**（八极道之源、疑与天逆及大天尊修为相关）、王林能否闯过第十二层、最终投向哪一方大天尊。

## 概要

承接王林闯天尊涅之势。本片段以「围观视角」写王林闯过第十二层并直冲第十三层，引爆整个仙族：紫阳宗、帝山、中州燕京皇城三方大天尊势力同时被惊动，招揽与杀意并起。结尾回到王林本人，第三问「何为道」，答案指向真假。

## 一、紫阳宗石室：双子大天尊与小孤崖

- 中年修士（被小女孩唤作「小孤崖」）以镜观天尊涅，本已近乎绝了招揽王林的念头。
- 一红衣小女孩踢门而入，喊他去帮自己和「涵涵」收拾不听话的「小狼」（即贪狼）。
- 女孩看镜中人「有些眼熟」——小孤崖以为她指的是武封大天尊与道一大天尊（女孩称之为「死光头」和「假面人」），实则她指的是踏入第十二层的王林。
- 女孩想起：当年找小狼时见过王林，她和涵涵还帮过他一次，且涵涵比她更早见过王林。
- 小孤崖闻言由沮丧转为激动大笑：认为双子大天尊「提前预料到如今的变化」，有救命旧缘在，招揽大有可能。女孩得意自夸「我运筹帷幄」，斥责小孤崖此前不听她的、不该理会那些离去之人。
- **小孤崖来历**：当年只是双子大天尊麾下毫不起眼的一个天尊；双子大天尊转世出现意外后所有人离去，唯他留下照顾这两个小女孩至今，只因当年全盛期双子大天尊对他之恩。「如今，却是唯一。」

## 二、中州帝山：久帝大天尊的摇摆

- 久帝大天尊原本懒散晒太阳，以「秋叶」观战，见王林过第十一层去闯第十二层，评价「勉强算个人物，可以勉勉强强招揽一下」，又顾虑「海子在那里」「与戮之前说的不太符合」。
- 自我劝退：「不就是个第十一层，远不如那冥道尊」，闭眼又睁眼，反复纠结「到底能不能过呢」。
- 见王林过十二层后仍下判断：以魂铠之力过十二层仍无法与冥道尊比，除非能穿魂铠再过第十三层，否则只是寻常跃天尊，「鸡肋啊真是鸡肋」。
- 随后察觉王林身外弥漫无形水汽、隔着秋叶亦有威压——认出**极水道**；旋即见王林不退反进，直奔第十三层，老者猛然起身，双眼奇异之芒，神色由懒散转为凝重。

## 三、中州燕京皇城：仙皇与冥道尊

- 黑衣冥道尊盯着大殿虚幻之影皱眉。平静之声（仙皇）问「一息，可以杀他么」，冥道尊沉默后答「一息，可以」。
- 仙皇断言王林闯不过十二层，其天牛魂铠会在十二层遇到天牛，「就让别人去抢好了，本皇没有兴趣」——话音未落，第十二层金光爆发穿透虚无，笼罩大殿。
- 仙皇（金袍、帝冠，相貌与仙祖极为相似的中年男子）自龙椅波纹中幻化现身，露出震惊：「他闯过了十二层」。
- 冥道尊骤然散发惊天杀机：过十二层者必受万众瞩目、被诸大天尊争取，且日后提起自己必被加上此人之名——这对以「跃天尊第一人」自喻的他极不喜。他重申「区区十二层，杀他，还是一息」。
- 王林冲入第十三层后，冥道尊冷哼，杀机一闪，向仙皇宣告：**「仙皇，我要去一趟这天尊涅，去闯第十六层。」** 随即盘膝坐下，神识凝聚天灵，前往天尊涅。

## 四、仙族震动与旁观者反应

- 几乎所有天尊、跃天尊乃至五位大天尊，注意力全被吸引；这种瞩目此前只有当年的冥道尊获得过，如今被分走一部分给王林。
- 定位：仙族**第四十九位跃天尊**，首次成为跃天尊即连闯第十一、十二层，如今再闯十三层；其名或将传至古族。
- 天尊涅内的天尊修士沉默仰望，自觉从第五层到第十二层的差距已使他们「没有资格评论」王林；雪雨等人复杂心绪被差距磨灭。
- 子妥跃天尊面色苍白，仍嘴硬「十三层他绝过不去」。
- 在场二十余名跃天尊议论：当年冥道尊止步第十三层；若王林过之，将完全压过「当年的冥道尊」，成为首次成跃天尊者中第一人，虽仍不如现在能过第十五层的冥道尊，但相差不远。仙族跃天尊在第十三层止步者，含才微尊与冥道尊共九人（若王林亦止步则成十人）。
- 道一大天尊暗叹：招揽这样的修士需付出代价，但值得——日后若其成大天尊，付出即化作善缘，在仙族地位大幅攀升。武封大天尊预见将重现「除双子外其余四大天尊共争一人」的局面，除非出现未知意外。

## 五、王林视角：十三层与第三问

- 王林面色苍白入第十三层，眼前仍是模糊虚无、迷雾缭绕，且比前两层更浓郁。
- 内心盘点：第十二层出现九尊天外之灵、其中有天牛；能过十二层已是穿上魂铠后的极限。魂铠非万能，可提升修为战力，但随修为渐高作用递减，最多让他「无限接近天牛」，接近仍有差距。
- 收获：第十一层学到**极火道**，第十二层明悟**极水道**——仙祖传承于太古神境的**八极道**，已掌握两种。
- 迷雾中传出与前两层一模一样的问题：**「何为道」**。
- 王林三答之序：第一次以**生死**为道，第二次以**因果**为道，第三次——**以真假为道**。

# 第1959-1961章 天尊涅十三层与仙皇的当众揭破

## 一、第十三层的悟道

第十三层考验的是对「道」的明悟。王林在洞府界时便已思索过此类问题，故并不为难：

- **生死为绳索，绳索两头相连成圆 → 此为因果。**
- **众生有梦障，分不清何为梦醒、何为沉睡，沉浸真假不能自拔；破开梦障、睁开双眼的力量，为「真假」，亦是道。**

王林由此想到自己在**朱雀星的一甲子梦道**，缓缓开口作答，迷雾骤散，露出完整星空。

他心中打定主意：「一鸣惊人我应该算是勉强达到，闯过第十三层后就此止步——即便大天尊看出我有魂铠，也足以说明问题。」

## 二、外界的等待与冥道尊到场

- 一柱香过去，等待中的天尊/跃天尊们认定王林要止步十三层，惋惜其「终有极限」；道一大天尊反而放心（越难过关越容易招揽）。
- **冥道尊**自古老传送阵现身：黑衣青年，神色冷峻，跃天尊第一强者、大天尊下第一人，连才微尊也被其压制。他只向道一、武封抱拳行礼，不看在场任何天尊、跃天尊。
- 武封回忆：当年曾给冥道尊极好条件，对方仍选择仙皇。
- 话音未落，第十三层大殿爆发金光，云雾尽染成金天——**王林闯过了十三层，超越冥道尊当年**。冥道尊瞳孔收缩，神色阴沉。

## 三、冥道尊的挑衅

王林现身于十三层外，面色苍白，未闯十四层而是缓缓下沉。

- 冥道尊冷声：「怎么不闯了？」——众人视为对王林的挑战。
- 王林问其身份，判断此人**以孤傲入道**、容不得他人超越，故不予理会。
- 王林转向道一、武封抱拳辞行。武封：「能闯过十三层，当为我仙族跃天尊中巅峰之人，我会前去寻你。」道一：「你既记得当年的约定，本尊也会去寻你，条件见面详谈。」
- **关键内情**：王林自知第十三层是动用了**虚无中的分身之力**才过的，单凭魂铠在九尊天外之灵下无法通过；故见好就收。
- 四周议论声由神念转为嗡鸣，似有目的地渲染「王林不敢招惹冥道尊」「王林狂傲」。
- 冥道尊连问第二遍后要求王林去闯第十四层「失败后便可以走」。王林一笑离去，冥道尊杀机一闪，**当众一指轰向传送阵**——若王林不避则传送中神识受损甚至崩溃，若闪避则被逼出传送阵。
- 天尊涅「禁制争斗」为后人所定的规矩（非仙祖所定），故出手不会被抹杀，但罕有人敢违。四周骇然后退。
- 武封欲出手阻止，一名天尊修士体外浮现**金袍帝冠的仙皇虚影**，一挥化解武封之力。王林走出传送阵，那手指于其身前消散——原只是嘲讽的一指。

## 四、急转：仙皇揭破魂铠

武封与仙皇当众交锋：

| 立场 | 要点 |
|---|---|
| 仙皇 | 冥道未伤人不算违规；王林「只是鸡肋」，靠魂铠才过十三层，无魂铠连跃天尊都难达；劝众修士勿因外物耽误修行 |
| 武封 | 若王林不出传送阵，此指必损其神识，行为无耻；大天尊封号亦是太古神境传下的**外力**，仙皇一脉靠仙祖遗泽血脉世袭「八极」，「在仙祖眼中，你这个后人或许也是一个鸡肋」 |

**魂铠之事此前几乎无人知晓**，仙皇一语掀起风暴：众修士的嫉妒瞬间爆发，讥其欺世盗名、实为「空劫中期」连金尊都不到，甚至倒推久帝大天尊始终不现身是早看透其无耻。冥道尊冷笑令其「滚吧」，称其急着走是魂铠时限将到。

- **海子天尊**（久帝大天尊弟子，仙族声名极大）以全部修为发声辩护：几十年前王林未穿魂铠时便能与她一战；魂铠本身正是**天外之灵的认同**与赐予，也是其修为的一部分；讥讽者谁敢上去与其对战。
- 仙皇以「依靠外力终有极限，十三层便是其极限，此后数百上千年也难再进一步」压回，并**当众立下条件：若王林现在能闯过第十五层，他即日传旨为其正名，昭告仙族其为大天尊下第一人**。
- 道一大天尊暗叹，认定王林从此在仙族臭名远扬，**放弃招揽**。

## 五、各方观战

- **帝山**：久帝大天尊望着身前的**秋叶**，本认同仙皇之言，见王林再度冲天而罕见诧异：「此子，凭什么去闯？」
- **中州皇族皇宫**：仙皇本尊坐于龙椅望虚幻之幕，欲借冥道尊教训王林，令其「来我皇城也要低头」。
- **东州紫阳宗**：中年修士对镜观战，不满冥道尊当众轻蔑；玩耍归来的**双子大天尊**为王林被千夫所指而愤怒；备受折磨的**贪狼**呆望镜子，脑中一片空白。

## 六、章末转折

王林长叹抬头，直视将散的仙皇虚影：「十五层么，仙皇，你且看好。」身化长虹直冲九霄。道一驻足、仙皇虚影重新凝实、武封双目一亮，冥道尊心惊肉跳，隐有不妙之感。全场抬头凝望。

## 七、看点与伏笔

1. 王林过十三层的真正底牌是**虚无中的分身之力**，非魂铠——仙皇与众人的判断皆有误。
2. 仙皇的「十五层换正名圣旨」是当众之诺，成为下一步剧情的直接赌注。
3. 冥道尊「以孤傲入道」的道基被王林当场看破，构成后续针对性的破绽。
4. 名望在一日之内两度反转：一鸣惊人 → 欺世盗名 → 待验。
