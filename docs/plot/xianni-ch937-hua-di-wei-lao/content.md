# 第八卷 联盟隐秘 第937章 画地为牢

## 一、王林的布置：飞剑扰敌与留后路
- 动机：让望月体内的众老怪元力消耗更快，同时为自己留一条后路。
- 手段：一拍储物袋取出十多把大战中缴获的飞剑，双手掐诀灌注并压缩元力，使每把飞剑自爆皆有不弱破坏力，随后挥手散射，直奔望月体内他所知的**一处处敏感之地**。
- 优势说明：唯有王林如此了解望月、知其敏感之处，换作他人无法布此后手。

## 二、探路受挫：漩涡逆流
- 第一把缭绕神识的飞剑将入漩涡时，漩涡中逆流宣泄出磅礴元力冲击。
- 王林神识抢先一息脱离，飞剑仍自剑尖至剑柄寸寸崩溃；神识被余波扫中，消散大半。盘坐于望月之骨处的王林面色异样红润，良久方复。
- 判断：那只是余波；漩涡吸力（望月本身神通）令内部冲击外泄时层层受阻、威力大减，否则神识将一点不剩。

## 三、潜入通道
- 第二把飞剑等余波停息后借漩涡吸力「啵」的一声穿透进入通道。
- 通道内狂暴风暴横扫：大量触手崩溃，其上缠绕的死尸尽化碎末。飞剑贴肉壁钻入触手崩溃后的缝隙，险避冲击。
- **关键地形变化**：通道只剩当初一半长短，尽头肉壁已将**古神幼子**所在之处彻底封死。王林藏身不动，密切关注战局。

## 四、战局：清水 vs 金色真龙（护玄宝上人）
- 远古上人（玄宝上人）元神萎靡，被十余触手缠身、双目紧闭气若游丝，仙元之力被持续吸取。
- 金色真龙如蟒盘旋护住玄宝上人，身上五张黄纸符散发电光并与其紧密连接。
- 更远处：一木子四周浮大量气泡，武东禅追上与之缠斗。

### 招式交锋
1. **残金**：金龙低喝，上百鳞片脱体凝成金鳞之剑，带天威与真龙气息斩向清水。
2. **红色闪电**：清水右目红光幻化手臂粗细的红色闪电相迎；对撞惊天，通道肉壁被生生扩展、裂出缝隙渗绿色血液；金龙惨吼后退、皮开肉绽喷金色血液，仍死守玄宝上人。
3. **望月异动**：望月闷吼，通道剧震，上方撕开巨大裂缝，绿血与无尽煞气涌出，似有一物欲冲出。
4. **杀戮界**：清水长发无风披散，脚下红光扩散弥漫，内有无数残魂——其一生杀戮极端之表现。
5. **五行逆转**：金龙令五张纸符停转、一一烙入体内，爆发极强气息，口吐五道光芒化作**缺坚之金、刑罚之木、化贡之水、绝毒之火、葬仙之土**，隔绝通道内一切、自成天地；一木子与武东禅退后观望。
6. **画地为牢**：清水以杀戮界为基础另开乾坤的自创仙术；右指点下，牢狱规则疯狂弥漫，以其为中心四周尽被无形封印，连逆转五行也被困住。

## 五、转折：血手夺人，清水震怒
- 清水速如闪电，右手穿透金龙之身抓住玄宝上人元神，一抖之下缠绕触手轰然崩溃、绿血飞溅；玄宝上人睁眼露出恐惧却无法挣脱。
- 就在退走刹那，通道上方裂缝中伸出一只**血红色手臂**（浓郁煞气 + 望月气息 + 破开一切神通的大力），砸中清水，令其修为之身亦承受不住、被震退喷血，并将玄宝上人元神狠狠拽回、欲缩入裂缝。
- 玄宝上人是清水目前**唯一可知晓仙界之事的希望**，被夺走后清水冷漠双目涌现大量血色，几近疯狂。

## 六、清水其人（背景补充）
- 所修法术以**仙帝白凡六术**为根本，但天资惊人，自创仙术（如画地为牢）。
- 当年即便白凡也不愿轻易触其反怒，只能怀柔施恩、收其为弟子。
- 连罗天星域中让**炎雷子**极为恭敬的神秘人，也不想惹清水怒火。

## 七、悬念
- 血红手臂之主（疑与望月/裂缝内之物相关）身份未明。
- 玄宝上人元神被夺、清水暴怒，后续冲突一触即发。
- 通道尽头肉壁封死古神幼子所在，王林潜伏观望，尚未出手。
