# 第1195章 七彩钉

> 第九卷 云海之巅 · 承第1105/1110章七彩界夺宝乱局。本章王林在云海星域以化名『吕子浩』行事（自第1063章由吕烟菲奉上），文中直呼「王林」即本尊。

## 一、洞府静养：银衣女子布下生死禁

- 银衣女子目光茫然，隐约想起些什么，抬手一挥，幽光化作**禁制**落在洞府出口。
- 该禁制正是**生死禁**，手法娴熟，隐隐**超过青衫老妪**。（王林当时昏迷，未见此幕）
- 数个时辰后王林醒来，见洞府口禁制一怔，扫了银衣女子一眼却未多问，盘膝吐纳。
- 外界连续三天一片平静，七彩界内众修士似都在抓紧疗伤。

## 二、七彩钉之毒：三重折磨

三天后王林面色反而更加苍白，右肩透出七彩光芒，伤口虽已愈合，钉子仍死钉骨中：

1. **肉身**：骨头不断碎裂，古神恢复力又不断愈合，周而复始，剧痛无尽。
2. **元神**：元神好似同被钉住，运转缓慢、萎靡不振。
3. **生机**：七彩钉持续吸收王林生机，不吸干誓不罢休。

王林震惊：此物竟能将**次空涅铁剑**（伴随多年、一路斩杀的利器）截断成两半。

## 三、强行拔钉：七彩入骨与发狂之兆

- 王林左手划开右肩、扩大伤口露出骨上钉子，七彩之芒弥漫洞府。
- **许立国**旁观舔嘴唇暗道：「煞星果然是煞星，不但对别人狠，对自己也是如此。」
- 王林闪电抓钉外拽，剧痛如潮、汗透衣衫、身子颤抖，**未能拔出**——钉子如与骨头长在一起。
- 更诡异：钉上七彩光芒**融入右侧整条骨头**，骨色化作七彩；瞬间王林脑中模糊，**生出一丝不受控的发狂迹象**，心神如坠地狱、被层层封印，「自己不再是自己」。
- 迹象片刻消散，但**七彩钉缩小了一半**。王林断定：钉子若全部消失（融入骨中），骨头彻底七彩，发狂将**永久**。

## 四、局势复盘：四人之算计

王林忍痛梳理七彩界内敌手态势：

| 对象 | 现状（王林判断） |
|---|---|
| 苍松子 | 役灵印下肉身崩溃、仅元神逃出，又被铁剑所伤、耗费大量法宝，定然重伤；下次相遇「必死无疑」 |
| 青衫老妪 | 被困阵法内，虽精通生死禁之术，但阵中蕴含王林**破灭心禁**，强行破开也必重伤 |
| 云魂子 | 被王林传送改变方位，去向不明；此地危机四伏，胡乱传送极险，怕是自顾不暇 |
| 陈天军（役兽宗） | 提前离开，途中曾感其神通波动消散，但难以证明其已死亡 |

王林自陈布局：先使云魂子被传送他处，再以阵法困住青衫老妪，留下苍松子与之一战。信条：「人无伤虎心，虎有害人意」，一味被动只会被人算计。

## 五、七彩界与天运子的关联

- 苍松子所抛珠子每一颗都能在七彩界内召唤神通，诡异莫测，其中竟出现**天运一指**。
- 结合先前**天运子战魂**出现后抬头望天迷茫的一幕，王林断定：**此地定然与天运子有关联**。

## 六、苍松子的目标物：黑色液体玉瓶

- 昏迷时放下的玉瓶，正是苍松子进入七彩界的**最终目的**。
- 神识散入：内有**半瓶黑色液体**，似血却无血腥气味。
- 王林：「待取了苍松子元神，此物到底是什么便一目了然，若无意外，应与提高修为有关。」随即收入怀中。

## 七、以凶兽为「帮手」逼出七彩钉

- 又运转元力与古神之力三天（合计六天），只能**略作压制**，无法逼出骨中七彩之芒，更遑论钉子。
- 结论：「能略作压制，便没有到绝路，眼下需要找帮手」——足够外力方可把七彩之芒逼退、把钉子逼出。
- 令银衣女子拍散洞府口生死禁（女子自承「有一些记忆」），王林大袖一甩，将**许立国与银衣女子一并收入储物空间**。
- 目的地并非七彩界内部，而是**山谷外山峰后的外围**：山峰林立，遍布化作雾气的凶兽——这些凶兽就是他要找的「帮手」。
- 原路穿过山脉通道，王林盯着通道所在山峰上的浓雾，斟酌计划后道：「且看看我的古神肉身，到底有多强」，化长虹直冲峰顶。

### 硬抗三鹰

1. **第一头鹰兽**：百丈大小，随雾气冲出直撞王林。王林不闪不避、以肉身硬抗，蹬蹬后退，撞击之力毫不化解全数传入右侧骨头，骨中七彩之芒闪烁并**透出皮肤**。
2. **第二头鹰兽**：山峰雾气翻滚又冲出一头，两鹰化作黑芒齐攻。王林如被无数山峰撞击，面色更白、嘴角流血，双目却越来越亮——两只均为**十二阶**凶兽，撞击之力尽数导入右骨，等于替他逼出七彩之光，光芒渐向右肩凝聚。
3. 王林肉身逼近承受临界，右侧七彩之芒**全部凝聚右肩、重新化作完整的七彩钉**，且钉子隐隐松动、有外移迹象。
4. **第三头鹰兽**：自峰顶雾中飞出，化黑色长虹狠撞王林**胸口**。重伤之躯几近崩溃，王林却露惊喜、长笑中**右肩砰的爆开**，血肉横飞间一道七彩之芒飞出，其内正是那**七彩钉**。

## 八、要点小结

- 王林战术核心：**以古神肉身「只要没动根本、重伤可短时间恢复」为本钱，借外力震出异物**。
- 新增未解伏笔：七彩钉来历与法宝归属未明；玉瓶黑色液体待验；七彩界与天运子的关联待揭。
