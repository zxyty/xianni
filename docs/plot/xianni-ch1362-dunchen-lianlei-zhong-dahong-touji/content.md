# 第1362章 遁尘炼雷（第九卷 云海之巅·第四更）

> 归属提示：本章行为主体为【王林】。其先前夺舍于非之身的伪装已于第1275章暴露，本章正文直呼王林本名。

## 一、天道使者的晶掌与掌纹之谜

- 此番天道使者**始终未曾露面**，实力远强于王林当年在**朱雀星**所遇者，但仍被王林**雷、火、战合一之剑**斩断一掌而遁。
- 王林收取了那道**虚弱但本源仍在的不灭雷霆**，随即压下两股情绪：因天道使者再现而起的疯狂，以及思及**李慕婉**弥漫心神的悲哀。
- 断掌落地后**不再是血肉，而化作手掌形状的晶石**，璀璨生芒。
- 关键发现：**此掌无掌纹**。王林判断，修为再高之人也不会毁去掌纹，遂生疑问——「莫非天道使者，都是没有掌纹之人不成？」
- 处置：晶掌被收入**储物空间**，成为其手中天道使者的实物线索。

## 二、钟大洪叛族投主

- 王林正欲离开闪雷族（此地后续自有**散灵上人**处置，与他再无关联），远处修士中有一人挣扎许久后咬牙冲出。
- 来者身外环绕**星光**、脚踏**梭状飞行之物**，自报姓名**钟大洪**（「钟是小钟的钟，洪是小洪的洪」），称王林为「主子」。
- 其心声点明代价：此举等同**叛族**，很可能先被族人杀死，但「人这一生总要有些选择」「左右留在这里也是死」。
- 投效表态：「一日为主，终身为主」「一生跟随，绝不背叛」，并自夸「杀人放火劫财劫色，我样样精通，**绝不比那许立国差**」。
- 结果：王林大袖一甩，风浪将钟大洪卷入**储物空间**，**与许立国作伴**。

## 三、瞬杀二修与别过散灵

- 王林一步跨越星空，现身于**散灵上人**与数名闪雷族**天人衰劫**修士交战之处。
- 出手：双眼红光一闪，**极境**化作**红色闪电**呼啸横扫——钻入一名**天人第一衰**修士体内崩溃其元神、自后心穿出，再入一名**天人第二衰**修士眉心、爆其头颅穿过。**瞬杀二人**。
- 王林道「散灵道友好自为之，王某告退」，收回极境，消失于星空，走出闪雷族星域。散灵长笑相送：「王兄慢走，老夫有预，你我还会有相见之日。」
- 王林自虚无中回话：「**再次相见之时，你会大吃一惊。**」——散灵不解其意，转身与闪雷族残存之人展开复仇之战。

## 四、遁入凡尘：隐匿与炼雷

- 遁行手段：星空中急速而走，气息层层收敛至几近凡人，**体内五道本源相互搅动**，使一切气息不露半点。
- 自我评估：若有**第三步大能**搜寻，找他本应极为轻松；但凭本源搅乱，再寻一处**人多杂乱**之地，应可略作躲避、略作隐瞒。
- 当务之急：**尽快炼化雷霆**。一旦不灭雷霆全部炼入元神，修为「不知会增加多少」。
- 落脚点：以**缩地成寸**数次，落于**太古星辰**内一处小族所在的**修真星**——凡人不下千万，都城人声鼎沸，生机弥漫。
- 伪装形态：头发变黑、以发巾竖起，一身**白衣**、手持**折扇**，作**书生**样貌入城。

## 五、太古星辰凡间风物（背景设定）

- 该地民风与**朱雀星**不同：男女之间毫不避嫌，街市商铺济济一堂。
- 酒楼说书公开谈论修士：讲**真言族**仙修**豫寰**——性格古怪、最喜在凡间流转，留下无数佳话；传闻其双修道侣**楚月萱**便是如此相识。王林哑然一笑，认为所言大都杜撰，但可见此地凡人对修士不陌生。
- 城中修士不少：无需展开神识即可察觉，眼前酒楼内便有一男一女两名修士听书，**东处皇城**所在更有修士近百。
- 王林结论：生机越混乱越好，加上本源隐藏，短时间内应可无碍，足够他炼化雷霆。
