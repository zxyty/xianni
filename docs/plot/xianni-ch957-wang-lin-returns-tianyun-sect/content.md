# 第八卷 联盟隐秘 第957章 来临

## 一、背景：王林之名成天运星禁忌

- 数百年过去，「王林」二字几乎成为天运星的禁忌，越是禁忌传言越多。
- 天运宗广场上，当年认识王林的人各怀心思，但**无一人认为王林今日若出现能活着走出**。

## 二、天运宗内的旧识群像

| 人物 | 现状 / 心思 |
|---|---|
| 白薇 | 神色复杂，难以想象当年那人如今变成什么样；对大师兄赵星煞极为忌惮 |
| 赵星煞 | 紫衣中年、双目如电；闭关感悟中修为突飞猛进，已**突破问鼎，只差一步入阴虚**；三十年前成为**天运七子**之一；当年与王林有仇隙，白薇料其必起杀心 |
| 紫系四师姐 | 神色低落、意兴阑珊。当年被赵星煞所逼、以神通困住王林；后王林脱困，她**传授大挪移之术**算是化解恩怨 |
| 司马如风 | 蓝系弟子，三旬青年，蓝衫绣三条栩栩如生的蓝龙。当年与紫系四师姐一同困住王林 |

## 三、王林现身

- 白衣如雪、黑发飘逸（阳光下透紫），独自一人自天边缓步而来，身后火红之阳映得面部一片暗色，唯双目透出千年沧桑与孤独暮色。
- 数人当场认出：「王林」「王林」。

### 各方老怪的震动

- **凌天候**：目光如电蕴森森剑意，眉头一皱，眼中闪过震惊——「窥涅初期这王林当年只不过是婴变，短短数百年竟然达到了如此高度，除非有了天大的造化」；尤其在意其**眉心印记**。
- **肉山般的老者**：猛睁双眼爆出精光，目露不可思议。
- **干瘦若尸的老者**：神色一动，深意地看王林一眼后又看天运子。
- **葫芦上黑白道袍老者**：一怔之下嘴角含笑，双目幽光闪烁，心思难测。
- **村姑般中年美妇**：轻咦「朱雀印记」，仔细打量。
- **粉衣女子**：美目流盼，露出感兴趣之色。
- 四周修士多看不出王林修为，但几乎所有人都感到一股威压自其身上散开。

## 四、拜师与口舌交锋

- 王林一拍衣衫，从容向天运子抱拳：「弟子王林，见过师尊」。
- 天运子盯其眉心印记良久，含笑和蔼道「回来就好」，并要他如实回答几位前辈的问题。
- 凌天候身后中年男子喝斥王林当年在妖灵之地杀大罗剑宗众人、今日血偿。王林**笑而目冷**，反问凌天候：「你这门下弟子，可有与我这般说话的资格」。
- 凌天候大袖一甩震退该弟子，承认「他的确没有资格」，并罕见表态：**小小年纪能达窥涅初期，放开恩怨来说，即便老夫也有些佩服**。
- 此言掀起惊天骇浪：白薇倒吸凉气、脑中空白；赵星煞身子一震、呆立当场；几乎所有修士皆难以置信。

## 五、核心焦点：仙府令牌

1. 葫芦老者转口以「有资格之人」相待，问王林当年为何当着众人面遁入漩涡逃走、是否有不愿人知之事。
2. 王林答：在妖灵之地确实惹下祸事，故必须离去。
3. 干瘦如尸老者追问何祸。王林平淡道：**自保之下囚禁了血祖之女**，眼见诸位前辈与血祖追来，自然要逃。
4. 肉山老者坐起身沉声追问「那仙府令牌可是在你手中」。王林不答反问其从何人口中听闻——王林记得当年追击自己的老怪中并无此人，且此人修为仅**净涅初期**；被王林一望，肉山老者竟心神一震、面色起变、眼露惊疑。
5. 天运子出面相询，王林恭敬承认：**当年在妖灵之地的确得到了一个仙府令牌**。
6. 四周老怪目光一闪、齐齐沉默，压抑之感凝聚在王林身上。

## 六、动手与化解

- 葫芦老者：「把令牌拿出，今日你尚可保命」。
- 肉山老者：「你，没有获得那令牌的资格」。
- **凌天候**杀机一闪：「令牌之事既然已知在他手中，何须废话」——右手前指，一道惊天动地剑气直取王林。
- **王林**神色平静，退后几步、右手握拳向前一击，音爆轰隆，拳上凭空生出**黑色漩涡**横扫，与剑气正面相撞。
- **天运子**双目一闪，大袖前甩化出**七彩之风**，落于二人之间：吹散王林拳上黑色漩涡、化解其力，同时阻隔凌天候剑气，**轻描淡写化解一切**。
- 天运子淡语警告：「凌天候，在我天运宗山门，对我弟子出手，未免太过不把老夫放在眼里」。
- 凌天候背后**四把元神之剑**尽数飞出环绕四周，阴森喝问：「天运子，你莫非要独吞那令牌不成」——章节在此对峙中收束。

## 七、要点提炼

- 王林境界跃迁的公开确认（婴变→窥涅初期）是本章最大冲击，直接改变各方对他的定位（从「小辈」变为「有资格之人」）。
- 眉心印记为多重伏笔：朱雀印记之外尚有**另外两股力量**，唯凌天候察觉。
- 仙府令牌成为天运宗当下所有矛盾的交汇点，天运子护徒姿态与其自身图谋均未明朗。
- 旧怨线索复起：赵星煞（杀心）、大罗剑宗（妖灵之地灭众之仇）、血祖（囚其女）。
