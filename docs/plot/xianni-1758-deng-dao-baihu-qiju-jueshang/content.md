# 第1758章 等刀！

## 一、局面：棋局即修罗战场

- 此战并非普通斗法，而是「下棋」——一场杀戮军旗，如同真正的修罗战场；棋盘幻化出无尽军兵，杀戮越多、棋子越强。
- 白甲将领此刻不能后退：大将若退则气势锐减，等同示弱于王林；且时间流逝中王林所杀越多越强，退则再无胜机。
- 场上共三枚棋子：
  - **王林神识所化黑甲棋子**（黑气笼罩、白发飘动、黑马、丈长黑刀，刀尖滴血）；
  - **白虎所化白甲战将**（虎斑白马、长枪、白虎虚影加持）；
  - **五行星中年修士神识所化金甲将领**（三者中最弱，一路后退）。

## 二、第一次对冲：兵碎马亡

- 千丈距离内双方一黑一白两道旋风急速接近，沿途不断杀戮以抢占优势。
- 天空上的白虎心神融入白甲之内，其身后幻化盘踞猛虎，坐骑白马也似化虎；白甲将领一枪刺出，白虎虚影融枪，形如扑食白虎。
- 王林沉默不语，黑马踏空，长刀挥出死亡弧形，刀芒乌光与昏暗天空、身后血月交错；其身外黑气凝成巨人虚影——**道古王林**（明确不是道古烨寞）。
- 撞击结果：长枪崩溃、白虎虚影瓦解，王林长刀亦碎；两马头部崩溃、全身瓦解，各化黑白二气。**兵碎，马亡。**
- 二人跃起近身厮杀，轰鸣震动大地、传遍星域。

## 三、白虎的补血法：屠兵重凝

- 白虎战将（天空本体）喷血，面色苍白却凶焰滔滔，惊恐地想：「他怎么可能有如此煞气？他这一生，到底杀了多少人？」
- 王林本尊亦身颤面白，但双眼更亮，断言：「你要输了。」白虎回应：「我白虎绝不会输，这是我定的规则世界。」
- 白虎拍胸再喷一口血，血落地与崩溃的白甲战将融合，使其重新起身。该战将转而疯狂屠杀身边所有军兵，每杀一人伤势即恢复、铠甲重凝；又逼出千滴鲜血化作上千血气吞噬军兵，**片刻间死亡军兵已接近十万**。
- 十万死兵之气凝聚，白甲战将重铸白甲、重凝白马；千滴鲜血仍在继续杀戮。

## 四、王林的补血法：吞魂第三子

- 王林不循同法，锁定不断后退的**金甲将领**（五行星中年修士神识所化）。
- 关键判断：他杀的并非其本尊，而是「规则下的凡人分身」，故轻易得手；若非在此界规则下，杀此人本需耗时。
- 王林一掌拍下，金甲崩溃，随即神识所化棋子张口吞噬——王林本为**吞魂**之体，神识同样具备吞魂本能，虽被此地压制、吞不了白虎，但吞下规则下虚弱的第三子可行。
- 收益：铠甲重凝且比先前威武数倍，**首次凝出头盔**（仅露头盔后白发），坐骑由马变为**雾化黑龙**，盘旋嘶吼。

## 五、第二次对冲：斩虎，定输赢

- 白甲将领虚空一抓重凝长枪，千滴鲜血回体，白马扭曲化作巨大白虎，其立于虎背手持三丈长枪扑来。
- 王林手握黑气所化三丈大刀，乘黑龙迎上；龙争虎斗，修真星几欲崩溃。
- 王林一刀落下并发出久违的低吼，身外**道古虚影**幻化随刀而落：白甲将领长枪崩、铠甲崩、白虎崩，眉心现出血丝，全身轰然瓦解。
- 王林宣告：**「从今以后，你白虎就是我王林之奴。」** 白虎战将面色惨白、喷血、神色黯淡。

## 六、危机将至：灭天一刀与火焰小伞

- 盘膝的**王林本尊**猛然站起、瞳孔收缩，察觉一股强烈危机正急速逼近。
- 他不假思索向前一步，整个人与下方神识所化之身**重叠**，张口吞尽白甲将领崩溃后的全部气息，黑气滔天化风暴横扫四方。
- 凝出数丈大刀高举，全身精气神借此地规则尽融此刀，是为——**灭天一刀**：此界最强之力，意在**破开白虎既定的规则**。
- 他不出手，只**等**：等那个带来危机之人出现。
- 与此同时，王林**左手在身后掐诀**，火光闪烁化作一把**火焰小伞**，一闪之后消失不见（暗中埋伏的后手）。
