# 仙逆 第1441章 传闻传闻又传闻（第九卷 云海之巅）

## 一、外围淘汰落幕：二十八人

- 首轮厮杀极为残酷：原本数百外围修士，死亡九成以上，尸体或崩溃成血肉、或沉入雾海，最终只余 **二十八个平台、二十八人**。
- 二十八处平台中有 **七处** 被外围修士成功闯入夺得，能在此环境下夺台者皆非寻常之辈。

### 值得注意的夺台者

| 人物 | 表现 |

### 平台上的其他关注对象

- **干瘦修士**：位于平台一侧。
- **肥胖员外**：身子硕大如球，员外袍、扁帽、和善笑容，手持小算盘，一晃啪啪作响，口中念叨「不划算」，抬手化出无数禁制封印冲上来的修士，将其倒卷落入雾海。
- **紫袍男子**：身后有千丈大鱼幻化，神色阴沉。
- **凶煞之修**：抢到平台，看向王林目光不善。
- **封灭族少女**：面色苍白，咬唇，眼中怯色更浓。
- **长发白衣女子**：默默收回目光，望了王林片刻又转向别处，神色平静。

## 二、王林的藏拙与他人的判读

王林盘膝吐纳，将此前吞噬的修士元神血肉之力化作疗伤之用。他至此 **仍未暴露**：

1. 虚火修士的身份；
2. 种种大神通之术；
3. 连法宝也未取出。

判断依据：此地危机处处、诡异难料，危险不仅来自墓地，也来自四周之修。**略作隐藏使人感觉神秘莫测，必要时立威**，才是最有效的手段。

四周修士对王林的评判：

- 紫袍男子：「此人方才的战斗，没有露出太多的神通，看不出端倪。」
- 凶煞之修：「一吼之力，让对方神通崩溃、肉身消散，看来此人的神通与音有关。」
- 肥胖员外：别人只看到狠辣与吼力，**却忘了此人杀人时吞噬血雾这等魔功——近年来在太古星辰出现了不少**。
- 封灭族少女：认定「他定然欲杀我，需尽快找到帮手」。
- 天人第四衰老者：「此人不能去招惹，他方才没杀我，倒是欠下了一个人情」，目露恐惧。

王林此前的战绩背书：干净利落连杀六人，一声低吼压过此地一切声息，生生震碎一名天人衰劫修士的肉身。

## 三、取走古神大幡

短暂恢复后，有修士起身直奔各自平台上头颅前的法宝。王林右手向后虚空一抓，摄来 **古神头颅前的三丈大幡**，凝神一扫，判定为 **古神法宝，但并非绝佳**，不动声色收起。

## 四、剧变：二十八平台下沉万丈

- 天空骤然咆哮，雷霆轰轰似要撕开天空，二十八个平台剧烈颤抖后 **轰然下沉**，瞬息便下沉万丈不止。
- 下沉之势撕裂欲呕，血液似要被抛出；但能撑过首轮厮杀者心智坚定，无人惊呼，皆死死固定身形。
- 平台转眼深入雾气之内，被雾气彻底淹没；天空与四周尚未打开防护的平台在众人眼中渐成黑点。
- 不知过了多久，轰的一声巨响，平台停止下沉——四周尽是雾气，漆黑一片。

## 五、人形凶兽与「入墓考验」

- 王林骤感危机，转身反手一挥，逼出雾中一头 **通体脓包、样似人形的凶兽**（双手指甲细长锋利），一掌隔空拍中，凶兽急退遁入雾中。
- 同时远处传来凄厉惨叫，已有修士被偷袭得手。
- 众修同时以神通挥散雾气，数万丈内雾气被逼退，露出空旷——**二十八平台中已有三处空无一人**（余二十五人）。
- **关键辨识**：王林认出这凶兽虽外表略有不同，但与 **妖灵之地内从古神头颅中冲出的奇异之物** 给他的感觉如出一辙。
- **绿袍老妪的说明**：她自称熟读古典，对古之墓地尚算了解——「此墓地眼下我们只是在外围，要经历 **入墓考验** 后，存活者才有资格进入内部。」并劝众人莫再留手。
- 话音落下，雾中 **不下数千** 的人形凶兽疯狂嘶吼，尽数冲向二十八平台上的二十五名修士。

## 六、虚火传闻（本章题眼）

王林在这些凶兽体内看到了 **暴虐的情绪**——而这情绪，正是 **点燃虚火的引线**。

虚火修士的设定与传闻：

- 无论界内界外都极为神秘，很少有修士能遇到；但其可怕而鲜明的神通征兆，在界外 **太古星辰** 名气极大。
- **数万年罕见一个**，故传闻几乎将虚火修士传成堪比 **三步大能** 的强大人物。
- 流传的传闻：
  1. 挥手间可令千军万马灰飞烟灭；
  2. 目光所在，七情六欲顿起，无法抵抗；
  3. 如隐藏在心神中的噩梦，点燃敌人情绪，焚烧而死；
  4. 一怒可引爆所有人的怒火，成为尸山中唯一站立仰天星空之人。
- **反差收束**：此地除封灭族少女外，无人知晓传闻中的虚火修士就藏在他们之中——即便白衣女子也不知。**虚火在没有施展之时，是看不到的。**

## 七、后续伏笔

- 数千凶兽围攻二十五名修士的战斗即将展开，王林是否被迫动用虚火成为悬念。
- 封灭族少女掌握王林的虚火秘密，且已在寻找帮手，构成潜在威胁。
- 天人第四衰老者自认欠王林人情，可能成为变数。
- 凶兽与妖灵之地古神头颅所出之物同源，指向古神一族的深层设定。
