# 第2006章 一叶遮目

## 一、黑石城外：宋致被带走

- 时令乍寒还暖，秋风卷起枯叶，一片落叶飘落遮住王林与计都皇子等人的目光视线——即「一叶遮目」之名。
- 走出城门的青衣女子名 **宋致**：拥有古妖血脉却无丝毫妖气，清纯如白莲；右眼下一颗小痣，平添妩媚。人如其名，「精致如画中之人」。
- 计都皇子介绍：宋致是始古 **大天尊宋家** 一脉的分支子弟，因宋家族人众多，其血脉较远，但在黑石城已算望族。
- 古魔（大古妖）头顶的老者神色凝重确认「正是姓宋」，向计都皇子抱拳：将带走此女，**若是没有威妃，则会将此女送回**。
- 计都皇子毫不在意地应允。宋致性格柔和无法拒绝，咬唇走向古魔；途经王林身旁时略欠身以示恭敬，一阵淡淡清香随其远去消散。
- 宋致登上古魔头顶后回望家乡，目透惆怅不舍，心中默念：「希望自己不要被选中……我长的本就不是那么美丽，应该不会被选中……常姨，东梅，还在这里等我」，秀发下似有泪光。
- 道古使团客气告别后，大古妖仰天嘶吼、跃入天空裂缝，化黑雾消失。此地距 **道古皇城** 极远，纵有大古妖代步也需数月方可返回。

## 二、王林报名与对古族皇权的判断

- 使团离去后，金甲大汉等人被皇子挥退，城外只余王林、颤抖的古妖、计都皇子及其身后女子。
- 计都皇子求问名讳，王林直答：「**王林**」。
- 皇子邀王林前往不远处 **幽郡** 的行宫详谈，以补偿此前鲁莽。
- 王林见其态度由冷漠转恭敬，心中判断：
  - 皇权在强者面前脆弱不堪一击；
  - 古族皇权能压过大天尊，实与 **古道大天尊** 的威慑有极深关联；
  - 一旦失去古道大天尊的威慑，古族皇权必将渐渐如仙族一样（衰落）。
- 王林点头应邀。皇子大喜，请王林先踏上古妖之身；其身边女子欲言，被皇子瞪眼制止，委屈咽下。
- 数万丈大古妖在王林踏上头顶后极为顺从，红光依旧却不再疯狂，跃入裂缝消失，天幕裂缝随之弥合如初。

## 三、封口令

计都皇子传音金甲大汉 **梁云**、**孔司** 与黑衣青年：

> 「有关这位王前辈在此地的一切之事，你三人不得外传，更不允许他人传开……若有半点风声传出，你三人诛灭九族。」

## 四、幽郡与行宫

- **幽郡**：始古一脉十二郡之一，常年被迷雾笼罩、遮天盖地呈一片幽色，故而为名。
- 传闻幽郡之下封印着一团雾气，此雾气乃 **另一种形态的生命**，被 **古祖** 擒住后封印于此。
- 雾气内群山中有 **马蹄形山环**，内建磅礴行宫，宫殿大气，仆从护卫众多、守卫森严。
- 大古妖破雾而出时，行宫上下尽跪，齐呼「恭迎皇子回宫」，可见计都皇子在此地地位无比高贵。
- 大古妖落于专为其准备的巨大青石广场，单膝跪地、头颅贴地。

## 五、大古妖来历

- 王林赞其「不错」。皇子解释：
  - 此古妖为 **父皇所赠**，平日代步兼护卫皇子安全；
  - 这种程度的大古妖很是少见；
  - 它生前本是 **始古一脉的禁卫战士**，在 **二十七星融合** 后 **获得古祖承认失败**，重新退化为妖体、失去神智。
- 皇子咬牙表示愿将大古妖赠予王林；王林反问「这就是你说的补偿」，皇子答曰区区代步之物不足为补偿，请入宫详谈。

## 六、身份被道破：「白发跃天尊」

- 王林踏入奢华而霸气的大殿，计都皇子抢步上前抱拳蓦然一拜：

> 「晚辈始古皇子计都，拜见 **白发跃天尊**。」

- 身后女子惊呼失色，连退数步掩口愣住，被这五个字彻底震撼。
- **古族三脉** 从未间断打探仙族动向与大事，尤重新出强者。对王林的重视程度甚至在仙族五位大天尊之上——五大天尊古族大都了解，而这位被誉为 **「大天尊下第一人」** 的白发跃天尊，古族却知之甚少。
- 王林露讶色，目光渐转阴冷。计都皇子冷汗泌出仍咬牙拜着，陈述推断依据：
  1. 王林出现在黑石城，此地接近 **苍茫大海**、与仙族相隔；
  2. 拥有让堪比天尊的大古妖如此恐惧之力；
  3. 不屑隐瞒身份，直告名讳；
  4. 手中有一张 **仙族强者图录**，其上新添了王林画像。
- **仙族强者图录**（玉简）：
  - 载有仙族五位大天尊、所有跃天尊画像，天尊亦有不少；
  - 唯有王林与五位大天尊的画像 **散发金光**，其余画像寻常；
  - 此图录 **唯有三族皇室才可看到**，故而外人遇到王林并不认识。
