# 第八卷 联盟隐秘 第1044章 迷惑

## 一、深坑之战：呼风唤雨退敌

- 人形之物自深坑紧追而上，双目冰冷无情死盯王林。
- 王林抬手下指，身边环绕的**五条火焰黑龙**咆哮扑入深坑，与人形之物撞击时接连自爆，如同五道天雷，洞府剧震、深坑大片碎石崩落。
- 未及查看战果，王林紧接施展**唤雨之术**：无数晶莹雨滴幻化于身周，出现瞬间即从洞府中吸取一丝天地之力融入其中，每一滴都蕴含王林元力并具备高温——落石即通红成灰，穿透碎石嗤嗤生烟，逼得深坑坍塌至极致。
- 作者点明修为进境：**窥涅中期**时呼风唤雨已有一定实力，此刻**窥涅圆满（巅峰）**，方能把当年**白凡**赖以成名的这两门仙术发挥出“一定的真容”；呼风与唤雨配合更出现奇异变化（王林无暇细看）。
- 结果：人形之物破开神通冲出深坑，全身仍半透明，但体外**红色丝线大半残破**，颇为狼狈，确实吃了亏。

## 二、人形之物的诡异之处（王林的观察）

- 一声咆哮即震得四周禁制砰砰自动开启，却又未及发威便在吼声中一一崩溃；地面大范围碎裂，狂风直冲九霄。
- 身前生出一圈圈**扭曲波纹**，踏入其中如穿梭般高速逼近。
- 具人形而样貌极诡异，双目虽有神采，但一见其目光便绝不会认为此物是人。
- 追击全程**未施展任何神通**，连体表细丝射出也仿佛只是本能。
- 最令王林心中生阴云的一点：**此物竟存在于古神的头颅内**。

## 三、王林的疑问链（关于八星古神与铁剑）

1. 此物是在古神死前就存在，还是死后钻入？
2. 若死前即在，**八星古神之死是否与此物有关**？此前“古神死于飘渺虚无之天道”的猜测因而动摇。
3. 当年究竟发生了什么，是谁杀了八星古神并砍下头颅？
4. 为何仙人能获得该头颅？
5. **仙人既得头颅，怎会没发现头颅内的那把铁剑？为何不将铁剑取出？**

## 四、竹林禁制：算计与脱身

- 前方竹林翠绿娇艳，实则蕴含**数万道禁制**，触发其一则全部开启、毁灭入内之人。
- 王林早在深坑底部时便已算计好，并在看玉简地图时留意此林。
- 王林踏入竹林瞬间身影消失；人形之物在林外徘徊、谨慎旋即被焦虑取代，终究冲入林中，光芒一闪身影消失（被禁制困住）。
- 王林随后自竹林深处走出，向旁迈出一步便已踏出竹林——凭玉简地图与自身禁制之术，可做到**不开启禁制而置身其内**。
- 王林判断：竹林禁制虽强，但人形之物更诡异，困不了它太久，须尽快深入洞府内部。

## 五、仙帝洞府结构情报（本章关键设定）

- 洞府**共九层**，每层建筑不同，禁制逐层增强，最终会达到恐怖程度；第一层禁制已然不弱。
- 众多阁楼建筑深处有一片黑雾，隐约可见宫殿一角；该处为整个洞府的**中心**，也是**第一层通往第二层的入口**。
- 王林所得玉简地图**只有前七层**清晰，最后两层模糊不清、好似被人抹去——刚得玉简时便有察觉，此番与洞府印证后更加确定。
- 出竹林后有一条**铺满仙玉**的小路，散发柔和之芒，通向黑雾方向。

## 六、传送真相复盘

王林梳理：众人从外界被传送时，本应直接出现在仙帝洞府此处；但传送过程被**散魔以白玉瓶干扰**，连同王林在内的众人被送入**瓶中界**；瓶中界破开后，散魔又开启**葬仙池**引起崩溃，使众人再次散开。散魔的目的，就是让众人**彻底迷惑在仙帝洞府内**（应本章标题“迷惑”）。

## 七、章末动向

王林踏上仙玉小路，谨慎地身形一晃，直奔远处黑雾所在（第二层入口）。
