# 第1615章 众修目前空门现

## 一、王林悟成第四式神通「因果印」

- **成印原理**：以掌开化作「天地之因」，以掌握为「灭世之果」，握住手掌的过程即为「缘」；以此缘之外力凝作因果一印。
- **威力与性质**：属【道术】，方式极为霸道，一印足以将人打入因果轮回、自定因果；与梦道「如雨水润物」般在梦中缓慢改变截然不同。
- **感悟由来**：十多年梦道 + 两千多年思索 + 种种造化，在苏醒刹那因果大成而顿悟。文中断言天地间无人比王林更了解因果。
- **气象**：身上弥漫大儒般浩荡之气，可惊退鬼神；一目之下令第三步空涅修士骇然避退——「拥有这股气息的王林，他感悟了天地的道理，他就是天地」。
- **三本源大成**：因果印与雷霆本源、火之本源交错环绕，形成一个个环形圆圈，第三步大能气息数倍暴增；此刻纵有空涅大圆满修士在场，也抵挡不住其全力一击。
- **连锁反应**：三道本源幻化而出的刹那，苍茫虚无内传来阵阵闷声，仿佛自虚无之外遥遥传来（即外界空门降临之声）。

## 二、昆虚星域最后一战（朱雀星外）

### 战场态势
- 昆虚星域已**全部沦陷**，仅余朱雀星一地。数万界外修士（眉心皆有印记，神色残忍萧杀）结成环形封锁，死死围住朱雀星。
- 界内残军**不足八千**，以**南云子**为首，已坚持数月，此战为昆虚最后一战。
- 昆虚修士拒绝撤往罗天星域：既然到哪都是死，宁可死在家乡、死战在**封尊的故乡**。朱雀星上封尊雕像如山屹立，被围修士惨笑中忘却死亡。
- 悲壮场面：中年修士被飞剑穿体后自爆，裹住两名界外修士同亡；「封尊荣耀，昆虚荣耀」的呐喊此起彼伏，连成一片。

### 界内一方
| 人物 | 状态与作为 |
|---|---|
| 南云子 | 界内残余力量首领，率众死战到底 |
| 司徒南（自称司徒南者） | 本应随青霖赴罗天，毅然赶回；三十年前经青霖教导与相助轰开空门，已是第三步大能。苍发、紫色大袍，长笑「死又何妨」 |
| 龙磐子 | 独自前来（未带弟子玄重），修为堪比空玄之力，挥舞**山河图**笼罩朱雀星，使其不被一举轰碎 |
| 鲁夫子 | 罗天修士老祖，几十年目睹无数生死，尤其被王林触动，选择留下：「老夫寻死而战」 |
| 青龙圣皇 | **未死**，几十年前携四圣宗突然现身加入昆虚，修为达天人第五衰巅峰（未至第三步），率四圣宗诸长老死战 |
| 十三、大头等 | 修为不足但在数次战争中快速成长，满身伤势仍杀机滔天 |

### 界外一方（仅三名第三步大能）
- **青衣男子**：一脸冷酷，出手寒冰无数，感悟**冰之本源**，修为**空玄初期**，且为本体亲至；一人压制龙磐子与司徒南节节败退。系当年王林生死大劫中出现者之一。放言「封尊当年被我等所杀，已死之人，何来荣耀」。
- **周瑾（奉天狼族）**：王林失踪后悄然背叛，率奉天狼族在界内掀起腥风血雨，似欲洗刷早年为王林之奴的耻辱。三名大能中修为最弱，在朱雀星左侧星空与鲁夫子交战，化巨大血狼欲吞鲁夫子而未能得手。听到「封尊」二字露出屈辱之色。
- 第三人未在本章明确点出。

## 三、空之大门降临（章末转折）

- 杀戮战场上空、无尽星辰内传来仿佛万古长存的轰鸣，初在远处，瞬息回荡于众人心神，透出沧桑与惊天气息。
- 一座**几乎占据星空的虚幻大门**浮现，大到无法形容，修士在其面前如蝼蚁——即「**空之大门**」（空门）。
- 反应：司徒南面色大变急退；龙磐子瞳孔一缩、忧虑；鲁夫子一愣后急退、眼露绝望；界内外普通修士尽皆目瞪口呆。
- **周瑾**因身负王林印记、曾为王林之奴，对该气息的敏感远超在场任何人，隐隐的熟悉感令其几乎魂飞魄散。
- 青衣男子眯眼寒光一闪：要看看界内数千人中是谁本源大成，「我要让他刚刚成为第三步，就立刻道消而亡」。
- 设定要点：空门降临无论界内界外都是莫大盛典，代表有人本源大成、可能踏入第三步大能。众人误以为是战场上某方修士突破，实为王林因果本源大成所引。

## 四、伏笔与看点

1. 王林三本源（雷/火/因果）大成 + 自创第四式神通，实力跃至可抗空玄乃至空涅大圆满层级。
2. 空门降临与朱雀星绝境**同时发生**，界内残军的救援即将到来。
3. 青衣男子自认参与「杀死封尊」，与王林构成直接血仇；周瑾的背叛亦待清算。
4. 青龙圣皇「未死」并携四圣宗重现，修正了此前其阵亡的印象（本章明言「他没有死」）。

> 归属说明：本章「司徒南」的言行按世界状态须知归于【司徒南的断臂】（自第336章起自称司徒南，真司徒南第61章已死，真伪未定）。「青龙圣皇」在本章被明确写为未死并现身参战，与此前第1178章死亡记录相左，按本章原文记录。
