# 第九卷 云海之巅 第1340章 这就是天劫么！（第三更）

## 一、七百万天地中心广场：设局

- 张景云带王林（此时以「于非」之身，刚晋升闪雷榜）向众新人介绍，新修士纷纷抱拳寒暄「久闻大名」。
- 张景云一行另有四名同伙，以「看羊羔」的目光打量王林，皮笑肉不笑地应付；五人隐成包围之势防止意外。王林扫了一眼即闭目，不看其传念。
- 阵法外其余修士看出端倪却无人理会——此类事在中心广场时常发生。
- 五人传念内容（王林尽收眼底）：
  - 赞张景云把刚晋升闪雷榜的「于非」弄来；
  - 周姓修士提醒此人能入闪雷榜必有过人之处，莫要马失前蹄；
  - 另一人称其不过**问鼎初期**，四人同时出手乃至任一人皆可轰杀，况有**赵前辈**在此；
  - 赵前辈修为已至**阴虚**，再进一步便是**阳实**，「万人之上」；
  - 目的：收了这群新人的**念雷**，几人合在一起可凝聚出完整的一道**灵念之雷**，便可去**雷晶殿**换取四把**仙品飞剑**。

## 二、传送入界

- 数百修士所在阵法渐放光芒，四周修士打起精神，不少人露出兴奋——显然很享受「化身天道」的感觉，连那阴虚修士也舔了舔嘴唇。
- 张景云招呼众人取出**灵符**，五人合力护法以保传入后不分散。众人飞入阵法，光芒万丈、风暴撕裂星空，瞬息消失。

## 三、下界一隅：鲁备迎劫

- 场景：七百万天地其中一处，风雨交加、雷鸣轰轰，地面有一片凡人城池，正值黑夜。
- 远处山峰上立一白发苍苍、双目如电的青衫老者，气息**化神巅峰**。
- 老者自陈：「我鲁备七岁修仙……在三百七十二岁化神，至今修道五百余年，终迈入化神巅峰，今日要破开这天地，迎天劫，进入仙界成仙人。」
- 又言：**此番渡劫，若失败则转世重修，若成功，我在仙界等你们。**
- 山峰四周跪着数千修士，皆其徒子徒孙，神色狂热。
- 鲁备低吼：「天劫阻我，我便渡劫；仙人阻我，我便弑仙」，冲天而起。

## 四、劫云之上：化身天道

- 劫云凭空凝聚，其上隐现**十多个虚影**，全身晶光、仙气弥漫，宛如真仙；虚影身后空间撕开，露出阁楼弥漫、仙鹤飞舞、仙宫耸立的「仙界」景象。
- 下方数千修士惊呼「那就是仙界」「十多个仙人同现，是瑞兆」，对成仙的渴望疯狂暴增；威压降下将其驱出方圆十里。
- **王林即是这十多个虚影之一**。他毫无兴奋——因为他亲身经历过天劫，且不止一次而是数次；其天劫与鲁备所迎之劫**一模一样**，只是范围更大、威力更猛。一股可怕的感觉在心中弥漫。

## 五、张景云降劫

- 张景云依「惯例」向同伴讨要此次渡劫者，众人应允。
- 他一步踏出云层，仙气弥漫，指向下方喝道：「下界修士，渡劫升仙」——水桶粗的闪电应声而下。
- 鲁备呆望天空，头皮发麻却生出自豪，迎劫而上；第一道雷后面色苍白、身前数个法宝崩溃，仍双眼不屈，掐诀布置防护迎第二道。

## 六、关键设定揭露：天劫为何渐强

- 新入者黑衣青年发问：为何不一下轰杀，而要一道道渐强？
- 王林闻言双眼露出奇异之芒——他自己渡的天劫亦是循序渐进、越来越强；此前视为理所当然，此刻疑问如闪电冲入脑中。
- 周姓修士答：
  - **族中冠冕堂皇的说法**：天道有好生之德，万险之中留一线生机；降临天劫只为磨练下界修士，越来越强方能在摧毁其心神时让其感受天威浩荡。
  - **实际原因**：操控天劫越来越强，是为**逼出下界修士的求生挣扎与不屈之意**，唯有如此，其体内方可诞生那可称为**灵念之雷**的奇异之力。
- 王林闭目，心神掀起轩然大浪，隐隐明白了一些什么。

## 七、鲁备之死

- 第二至第五道天雷在张景云操控下接连降临；张景云神色扭曲、兴奋异常，自谓此感比双修还舒服千万倍，口称「吾为天道，降下雷霆」。
- 鲁备喷血、血肉模糊，眼中渐露绝望。
- 第六道天雷粗约数丈，出现即卷动天地、大地欲崩。鲁备发出生命中最后一次怒吼「**我要成仙**」，声音传入王林耳中，使其睁开双眼。
- 天雷落下，鲁备**肉身崩溃，形神俱灭**。

## 八、要点归纳

- 七百万天地=闪雷族的「养殖场」：以假仙界、假仙人、假天劫收割下界修士挣扎所生的灵念之雷。
- 灵念之雷可在雷晶殿兑换仙品飞剑等物，构成闪雷族修士的功利链条。
- 对王林的冲击：他自己渡过的数次天劫与此完全同构——暗示其此前所历「天劫」也可能是被更高层者操控/收割，构成本章最大的伏笔。
