# 第九卷 云海之巅 第1252章 叱咤无极（三）

> 归属须知：本章各方口中的「归元宗吕子浩」「那神秘的吕姓之人」「师叔祖」即【王林】的化名身份（自第1063章由吕烟菲主动奉上归元宗故人之名）。本章他本人直至结尾方以白发身影现身，前半段皆为他人议论与等待。

## 一、余波：三女与看台众生相

- **木冰眉**：眼露明亮，心中苦笑——他无论到了何处，似乎都会做出惊世骇俗之事。
- **李倩梅**：咬着下唇，眼中明亮含笑，抬头望天，心极为喜悦。
- **吕烟菲**：脑中空白许久方复，震惊被喜悦压下。她确认——对方没有忘记百年前的承诺，披星斩月，穿过六阶、七阶、八阶星域而来。
- **王珊珊**：目露奇异之色，脑中浮现自己虚幻而出的画面——白衣、白发的男子带着惊人呼啸远远临近；她唯一费解的是，对方竟然会**役灵印**。
- **卢云从**：苦笑，没想到那位吕兄人还没来，就已因两名无极宗长老的话语引起如此浩荡。
- **无极宗宗主（白袍老者）**：深深呼出一口气，对那神秘之人的心态已由「看晚辈」转为「视作同辈」；他让吕烟菲不必回去，就在此等待师叔祖赶来。

### 三女的暗流
李倩梅应王珊珊之邀坐于其旁，木冰眉双目如电扫来。王珊珊居中互相引见后，忽觉身体一冷，眨眼后微微后靠，让二女目光直视再无阻隔。木冰眉冰冷轻言「李姑娘果然天生丽质，修为不凡」；性子宁静的李倩梅不明所以，回以「若论丽质，却是比不上木道友」。

## 二、六阶分宗比试：袁飞崛起

- **身份**：六阶巨灵宗大弟子。
- **状态**：样似中年，修为**碎涅初期**；常年闭关，多年前离宗，二百年前方回来，错过两次分宗大比。
- **战风**：出手辛辣无比，与其对战的分宗之人往往受伤极重，一时风头无量。
- **旧账**：他早年便是六阶分宗小辈弟子中的第一人；若非外出多年，仙音门不会取得头筹，也不会成就**吕英杰**的名声。本届他代表宗派出手，吕英杰心中顾忌，沉默冷笑，未曾出场。
- **挑衅**：袁飞目光炯炯锁定木冰眉三女，毫不掩饰狂热，朗声问「不知在下，与李道友口中的神秘之人，又如何」——李倩梅只平淡两字：「**不如**」。
- **战书**：袁飞转向卢云从索战。卢云从目露寒芒，沉声道：「若归元宗吕兄未来，我与你一战又何妨。」

## 三、关键决定：宗主下令五阶宗派对决

六阶分宗比试将尽，众人等待的吕子浩仍未到来。七阶分宗即将开赛，而五阶星域第一尚未决出；四周观望修士众多且不乏外宗之人，拖延更为不妥。

- **冯海**犹豫，看向宗主。
- **无极宗宗主（白袍老者）**裁定：「等也等了，即便那吕子浩事后前来，也无话可说。」下令 **卢云从、吕烟菲入大比平台，完成五阶宗派的比试**。
- 卢云从沉默后起身，向吕烟菲一抱拳，踏空直奔平台。吕烟菲咬唇轻叹，化作彩蝶落于平台，目光越加坚定：「即便他没来，这一战，我也要继续下去。」
- **李倩梅的打算**：此为无极宗分宗私事，她无理由干涉；但心中打定主意——**若归元宗解散，她将带走所有归元宗之人，去往破天宗**。

> 归元宗这一区区小宗，因一个尚未到来之人，第一次被数万修士记在心里。

## 四、恶意的伏笔

- **仙音门吕英杰**：怨毒目光死盯二人，握紧拳头，欲看此人是否真如所言。
- **寻栾宗**：赵龙**已失去肉身、仅剩元神**，飘在寻栾宗大长老与宗主身边，神色萎靡而目露恶毒，远超吕英杰。宗门放话：「那人若不来也就罢了，一旦来了，老夫就让他暴毙当场」「即便是李倩梅阻挡……但那神秘的吕姓之人，却是必须要死」——并判断得罪李倩梅不等于得罪破天宗。
- **信息差**：先前无极宗看台上之事距离太远，外人只见一个模糊虚幻之影，看不清晰。
- **袁飞**：亦盼那神秘之人前来，好亲眼看看他有何神通。

## 五、结尾：天雷迎人

吕烟菲被无数目光凝聚，孤独感浮上心头——等了百年的人始终未现，抬头望天，眼中晶莹却未落下。她转身请卢云从赐教，卢云从声明「此战，我不会留手」。

吕烟菲掐诀，天地元力于半空化作漩涡；刹那间漩涡骤然疯狂，好似有一股**从虚无中走出的奇异力量**融入其中，搅动风云，最终脱离掌控直奔天空。

- 吕烟菲呆滞后剧烈颤抖，猛地抬头。
- 卢云从元神在体内颤抖，感到自遥远天空呼啸降临的、蕴含无法反抗意志的惊天威压——**这意志他非常熟悉**。
- 近十万修士同时感受威压：天空雷鸣骤起，银蛇游走，仿佛整个星空的雷霆都被吸引而来，交错成雷网自天凝聚轰隆压下，天地轰然成为**雷池地狱**。
- **一个白色的身影**，在至高的天空、无尽雷鸣之下缓缓出现，一头白发飘摇，似卷动天雷。

> 「他，来了。」

## 六、看点与后续钩子

1. 五阶宗派之战被强行开打，吕烟菲与卢云从被迫同门相残——王林恰在此刻降临，战局必生变。
2. 寻栾宗（赵龙）与仙音门（吕英杰）已明确立下杀心，是下一步冲突主线。
3. 袁飞（碎涅初期）作为六阶新锐，与卢云从的战约悬而未决，亦是待挑之人。
4. 王珊珊对「役灵印」的费解，暗示其与王林之间尚未点破的渊源。
5. 李倩梅的备案（归元宗并入破天宗）为归元宗前途留下退路。
