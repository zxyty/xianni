# 第1938章 不悔的执着（第一更）

## 一、脱身山海
- 王林以**残夜信术**将断掌虚影崩溃削弱，趁机一冲而出，身形融入天地远离山海洲。
- 冲出海面刹那，隐隐感受到天空上有**三股足以压迫天地的气息**若隐若现——结合此前猜测，即三位**大天尊**。三者眼看他离开而不阻拦，王林判断自己已通过其测试。
- 落脚点：**山海临洲**一片万古苍松弥漫之地，藏身于一棵苍松之内。
- 王林断言：**那断掌内定有隐秘之事**（悬念未解）。

## 二、本章收获盘点
1. **山海树灵**：数年间吸收其余树灵，体内**木本源已然大成**，可感应天地一切木之本源气息。本章将最后两颗树灵融入体内慢炼。
   - 疑点：木本源融入后吸收越来越缓慢，能否诞生**木本源真身**、何时能尽数化为自身本源之物，均未知。
2. **仙极剑碎片（第二枚）**：从山海树封印内冒险夺出。巴掌大小、边缘不规则，气息可斩开天地万物。因在**海子天尊**光幕内无法当面吸收，故脱困后方炼化。

## 三、仙极剑碎片融合（七日闭关）
- 王林双目瞳孔中本就隐有一枚仙极剑碎片；手中新碎片与双目金光交错，产生召唤与吸引之力，碎片化作无数**金色细丝**尽数没入双目。
- 脑海中两枚碎片彻底融合，幻化出一柄**约一尺多长的金色小剑**，通体锋利、弥漫无上威压。
- **第八日**睁眼：滔天金光自双目扩散，镇压之力超过此前数倍、化作实质如剑出天崩地裂；数个时辰后金光一寸寸收缩，尽数凝聚于瞳孔，外表**清澈无异、返璞归真**，与其对望者却会心神轰鸣、不战而退。
- 定性：**以仙祖的仙极剑镇压众生万物**——此为镇压之力。
- 副产物（重大突破）：仙极剑乃**天地一切金属性之巅**，融合后王林体内诞生出**五行最后一个本源——金本源**。至此五行本源齐备。
- 效率对比：**一枚碎片 ≈ 数年山海树灵**。

## 四、战力测算：十三道神通融体
| 状态 | 一拳一指可出神通数 |
|---|---|
| 去山海前闯天尊涅之地时 | 9 道 |
| 本章本体（未展开真身与本源）极限 | **13 道** |
| 展开真身与本源叠加 | **44 道** |

- 过程：右手一挥九十八个残影融合握拳，第十道气旋涌现；再握出第十一道；左手成掌按压右手，全身一震、低吼中逼出第十二、第十三道，至此已是极限（呼吸略显急促）。
- 叠加原理：**五行真身**与本体同样可发挥双倍神通；加**雷霆真身**再度暴增；**三大虚本源融为一体**（虚本源虽未凝真身，但比实本源更诡秘）足以支撑此叠加。
- 来历：这是王林在**五十年挑战**中凭真身特性自行明悟的专属战力方式。
- 自估：即便**没有穿魂铠甲**，展开真身与本源后也可与**融五十二道神通的天尊**一战；再闯天尊涅之地当可过第五层。

## 五、后续路线（王林本章定下的行程）
1. **回东州 → 东临宗 → 东临池**：比对此池与洞府界幻境中所见是否有不同之处。
2. **第二次闯天尊涅之地**：暂不立刻去，时机未到；不闯则已，一闯必**一鸣惊人**，目的是**吸引所有大天尊的注意**，看能过几层。
3. **选定一个大天尊**。
4. **中州皇城**：仙族大地上最后一站，了结皇城内的心结。
5. 离开仙族大地 → **古族三十六郡**，去见师尊**玄罗**，完成承诺。

## 六、情感线
王林疾驰中双眼露出罕见温柔：「婉儿，当我成为大天尊之时，就是我亲自将你、我的妻子复活的一日……很近了。」——数千年不悔的执着，本章标题即由此而来。
