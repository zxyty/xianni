# 第1544章 离去！

## 一、疯子拜师

地点：幽冥兽体内之界中，那颗残破的修真星上。

- 疯子直接跪地磕头，神色凝重，双眼透出狂热崇敬。
- 立誓词：「以吾仙祖之誓，本王连道非，愿拜高人为师，此生永不叛宗，拜见师尊」——此处首次自报名号**连道非**。
- 立誓同时右手拍向眉心，一股奇异之力自其体内涌出，融入王林体内。
- 王林当场愣住：他本意只是吓唬对方、套问神通道术口诀，未料出现拜师这一转折。
- 连道非的算盘（内心独白）：自认为哥哥找到了高人、自己还能学到神通，「这笔买卖，划算」。
- 王林右手一拍幽冥兽，此兽消散无影，修真星归于寂静，只余二人。

## 二、试探与保留

- 王林托词：收服此兽的神通玄奥，「眼下还不是传授你之时」，需先知晓其掌握哪些神通方能抉择。
- 连道非眼珠一转，谎称「不会了啊，就那些了，别的我都忘了」。
- 王林转而抛出诱饵：我可以带你离开这里，但要知道你最强的神通是什么。
- 连道非激动应答：**仙之九绝道**，并称「就连我哥，也只摸索出了第七绝道」；随即捂口摇头，称体内有**誓道**，详说会遭**仙罚**——但其扣鼻孔、目光乱扫的做派并不像所说那般。
- 王林摇头一笑不再追问：已从其身上获得**四样神通口诀**，造化已然巨大，每一样都需莫大时间消化感悟，再贪则过。
- 约定：**三日后**带其离去。

## 三、遍演神通，无一入眼

王林闭目吐纳三日以压制排斥之力，被连道非咆哮絮叨（还对着「小红」抱怨）扰得睁眼，遂逐一施展毕生所学供其挑选：

| 施展的神通 | 表现 | 连道非反应 |
|---|---|---|
| 呼风 | 金风化九条金龙，吹紫色寒风，大地冰封 | 不屑，「这小小神通，我才不学」 |
| 唤雨 | 乌云弥天、雷声轰鸣，降金色雨引动天地元力凝聚 | 打哈欠，「又糊弄我」 |
| 撒豆成兵、山崩之术 | — | 只看一眼便摇头，渐渐愤怒咆哮 |
| 翻天印（蓝梦道尊所授） | — | 「这也叫翻天不学」 |
| 光影遁（蓝梦道尊所授） | — | 「全身光光的，这是什么神通啊」 |
| 道术融合（蓝梦道尊所授） | — | 「太弱了，本王一口血就可容一切」 |
| 化天地为海洋、初阳升起、残夜之力 | 天地一黑化作海洋，尽头初阳光芒万丈 | 眼前一亮旋即黯淡，「我有比这个还厉害的」 |
| 岁月石门 | 巨大石门幻化天地间，岁月流转仿若度过数千上万年 | 「这石门还没我王府大门好」 |

连道非反而比王林更愤怒，多次大吼「你是高人，你不可能只会这点神通，你就是不想教我」。

## 四、转折：引力术

- 王林怒极而笑，撂下「最后一个神通，你爱学不学」，**不需掐诀**便施出他这一生学到的**第一个神通——引力术**（炼气期所学）。
- 效果：大地震动，掀起一块巨石在半空绕飞。
- 连道非狂喜：「这个好玩啊……师傅不愧是高人，居然有这种大神通道术」。
- 王林以**玉简**烙印引力术甩给对方，随即闭目吐纳。
- 连道非神识一扫几乎瞬间学会：先引数十石块环身旋转（转到眩晕仍兴奋），再飞至远处一指令地面裂开、引起数百上千石块环绕。

## 五、三日之后与离去

- **王林的紧迫感**：需尽快获得足够**道果**，方可完成心中计划，解决如悬梁之剑的**排斥之力**；三天内要把体内排斥之力再压一压，以保持一定程度实力，完成余下几件事。
- 三日后王林睁眼，**目中金光被其隐藏**，不仔细看不会发现。
- 远处连道非已操控上万石块分作两军在半空厮杀，还自导自演调戏「小娘子」的戏码（一会儿扮「本王有上万大军」，一会儿捏兰花指扮女子「你这个银贼」）。
- 王林哭笑不得，长叹起身：「行了，出去再玩」；连道非意犹未尽、回头不舍石块，王林道「外面有的是」。
- 二人越走越远，渐渐消失在这天地之内——离去。

## 六、要点提示

- 本章重要伏笔：**仙之九绝道**（连道非之兄仅摸索至第七绝道）、连道非体内的**誓道/仙罚**约束、拜师时融入王林体内的**奇异之力**。
- 人物基调对照：王林毕生所学的高深神通尽遭嫌弃，唯有其起步之初的**引力术**被疯子视若至宝——呼应「大道至简/初心」的反讽笔法。
