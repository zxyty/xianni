# 第1849章 丹海仙丹！

## 一、夺阵前奏：连环夺舍心神潜近

- 持罗盘女子不断掐诀，罗盘内「岁月逆转」，隐隐要还原王林降临钻入修士耳内夺取心神的一幕。
- 王林所在小队距女子尚有千丈。王林操控的修士突然越众而出，来到队伍最前方一名**第三步空涅初期**的中年男子身后；眉心钻出一缕烟丝入其双目，强行接管其心神（该男子挣扎片刻即化作冷静）。
- 女子罗盘剧震、即将显形之际，被控中年男子抢先出手：越过数百丈，声称「在途中从海水内发现一滴黑色液体」，抬手将黑液弹出。
- 黑液散出浓浓本源气息，女子瞳孔骤缩，惊呼「**万净化污液**」。趁其震惊，被控男子再进数百丈，逼至不足百丈。

## 二、破阵与灭口

1. **暴露**：此地三杆大旗波纹回荡、呼啸示警，罗盘清晰映出王林自雾气飞出钻入修士耳内的画面。女子尖叫「站住」，其身后面白如玉的青年（赵姓）亦骇然。
2. **本源散**：被控男子低吼「本源散」，身躯轰然崩溃，一缕烟丝化作王林本体。
3. **毒爆**：先前弹出的万净化污液炸开，黑墨笼罩方圆千丈——数百盘膝修士与王林身后十余名绿魔修士来不及逃走，尽数腐蚀成黑水。
4. **折旗**：断了一臂的**己司**狰狞幻化而出，接连轰断三杆大旗，阵法示警与外传通道尽废。
5. **定身**：王林一步跨过百丈，右手一指喝「定」，无数细丝缠身，将女子与青年生生定住——女子左手距罗盘不到一寸而顿。
6. **屠戮**：王林一掌拍在女子眉心，其人连同元神化为血雾；甩袖驱血雾裹向赵姓青年，血剑随之直取头颅。二人俱亡。
7. **收尾**：黑墨疯狂回缩成一滴黑液，被王林吞入体内；收走己司，遁向海底。王林面色略显苍白——此战他要的就是「快」。

## 三、夺罗盘 = 夺丹海禁制大阵

- 王林在海水中疾驰，神识涌入罗盘，以**禁制本源**轰入其中，抹去原主神识，将罗盘炼化为自身之物（原文明言：换旁人或许做不到，王林有禁制本源方能做到）。
- **拥有罗盘 = 拥有丹海上的禁制大阵。**
- 罗盘显示：丹海内只剩三五个绿色光点，其中一点极为刺目（云空）；其余光点皆在海面之上（因云空施法，不便停留海水内）。
- 王林起杀机：「云空，下一个该是你了」，随即整个人融入禁制大阵，瞬间移动至丹海最中心海域。

## 四、转念潜伏：为「三千万道魂」留余地

- 抵近后察觉四周海水疯狂卷动、几乎要将其身体扯入。
- 王林沉吟：「或许，不需要我放弃那三千万道魂」——遂**不再前行**，沉入海底隐匿，等云空凝出仙丹的一瞬再暴起发难。

## 五、云空炼化丹海

- 丹海滔天大浪，九大漩涡齐转：外围八漩涡以正中**第九漩涡**为中心、卷着海水轰隆飘起同旋。
- 云空盘坐第九漩涡深处，面色略白，双手不停掐诀。
- **关键设定披露**：「传说当年丹海，由一颗仙丹落下后幻化而出，但实际上，这里并非是整粒仙丹，而是半粒而已。」
- 施法「丹海，凝」：海水急凝渐少，一丝丝**仙气**扩散；丹海如盆地，中心巨漩涡轰轰转动。天空上密密麻麻数万绿魔洲修士凝重围观，等他凝出半粒仙丹后**炸开天牛洲壁障**。
- 收缩进度：无尽 → **十万丈** → **五万丈** → **三万丈**；其余海域露出满是海草珊瑚的大地，无数海中之兽纷纷爆体死亡。
- 云空修为古怪，爆发时看不出境界，只有滔天**剑气**与笼罩八方的**剑意**。

## 六、云空的动机（自述）

> 师尊令其凝聚丹海仙丹，是为把他的声名再推一步、凌驾于其余三大天骄之上，以**东州第一人**身份前往**仙族皇城中州**，获得进入**祖庙**的资格。

## 七、信息差与伏笔

- 三杆大旗折断、罗盘易主——**无人察觉**，众人目光尽被云空吸引；且丹海经数次清洗，无人认为还有天牛洲修士潜伏。
- 云空从未想过王林会**去而复返**。
- 悬置伏笔：三千万道魂的取舍、王林待仙丹凝成一瞬的暴起。
