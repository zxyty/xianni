# 第八卷 联盟隐秘 · 第1102章（三更）

## 一、神识笼罩星域

- 朱雀圣宗所在星域内所有修真星尽被王林神识弥漫，沧桑气息充斥全域，宗内长老震惊莫名，无法想象「新圣皇」在修行何等神通。
- 长老们以自身见识与修为，无法理解**仙帝白凡的山崩神通**之强，情理之中。
- 王林原本神识覆盖不到这么远：他此刻忘却一切，**化成火山之魂**，与一颗颗修真星融合，借**星魂之力**不断蔓延，才成此景。
- 其神识实为整个朱雀圣宗全部修真星之集合，内蕴无数万年沧桑，令闻者几欲腐朽；连最早那四名心怀不满的老者也彻底被震撼。

## 二、顿悟：真假一念

沧桑神念在神识中回荡，落入每一个人耳中：

> 「若无因，自然无果，于是，就没有了因果。若无生，自然无死，没有了生死，便是永恒。若无真，也就无假，真与假之间，唯一念尔。」

- 王林随神念苏醒，感慨：「原来是这样……只是一念间罢了，难怪清水师兄没有留下详细的感悟，这一切，明白，就是明白了。」
- 苏醒刹那，燃烧星域轰然而动，各修真星星魂散出，星球之上一处处火山**同时爆发**，轰鸣传荡星域。

## 三、来客：炎雷子与尸阴宗第三王

- 二人恰在此刻踏入燃烧星域。
- **尸阴宗第三王**（中年男子）瞬间感受到磅礴神识，倒吸凉气，觉得面对的不像一个人，而是整个存在了无数万年的星域，自己竟有小辈之感。
  - 先想到「朱雀圣皇」，但据李莹芝汇报，新朱雀圣皇修行时间不长，不似；遂疑为「老朱雀圣皇」，神色极为谨慎。
- **炎雷子**同样震惊，认为这神识几乎不是一个修士可以拥有的；他对神念有些熟悉，已有猜测却不敢置信。
- 王林神识动，星域内雷鸣轰然、火焰云涌，传念点名「炎雷子」。自称「朱雀圣皇」后，炎雷子失声：「你是王林」——尸阴宗第三王亦为之震惊。

## 四、玉简之地：朱雀星

| 来客 | 来意 | 玉简来源 |
| --- | --- | --- |
| 尸阴宗第三王 | 询问玉简内之物在何处，允诺尸阴宗感激不尽 | 宗内小辈**李莹芝**带回 |
| 炎雷子（雷仙殿） | 同一疑问：玉简所说之地究竟在哪 | **烈云子**带回雷仙殿 |

- 王林答：可以告知，但**那里危机处处，去与不去自行决定**；随即以无数晶光凭空化作**星图**，清晰展露**朱雀星**，数息后消散。
- 尸阴宗第三王点破「圣皇怕是另有打算」，王林直言：**「各有所需，借刀杀那守尸之人而已。」** 对尸阴宗与罗天此事不必隐瞒，本非阴谋。第三王一怔后大笑，称「我尸阴宗承情」，抱拳而去。
- 炎雷子留后感叹：「老夫还是低估了你……抛开老夫雷仙殿身份，抛开你朱雀圣皇身份，老夫在罗天待你如何」——王林答「**尚可**」。炎雷子再问玉简真假，王林明言「**千真万确**」，炎雷子点头化虹而去。
- 二人离去后，覆盖星域的神识骤然崩溃，化作点点滴滴消散；星魂各归修真星；崩溃牵动天地元力，朱雀圣宗族人心神震撼。

## 五、突破：窥涅 → 净涅

王林于最大火山内部睁眼，双目明亮如电光划过岩浆，自述其道：

- 「我王林之意境，**悟生死轮回，后转因果循环**，此刻借着**山崩之意，初窥真假一念之间**，因果圆满，修为突破了**窥涅，进军净涅**。」
- 意境因感悟山崩而动，出现**真假之变**；并明确判断：**真与假与虚实不同，是其上的大道。**
- 突破后体感变化：此前体内可承受的火元力已至极限，如今心神一动，天地风起云涌，火元力轰然凝聚灌入体内。

### 空间裂缝取代储物袋

1. 右手虚空一抓，撕出一道尚不稳定、随时可能崩溃的裂缝。
2. 挥手注入无穷元力，裂缝内空间不断扩张并趋于稳固，最终几达极限，轻易不会崩溃。
3. 「储物袋，以后倒是不必再用了。」——袋中之物尽数飞出吸入裂缝，空袋被一搓化作飞灰。
4. 于裂缝上留下**神念烙印**，挥手收拢隐没。

## 六、尾声：重伤蚊兽归来，杀机骤起

- 王林神色一动，一步踏入星空，见一只**通体紫色的蚊兽**挣扎飞来：鲜血淋漓、萎靡不振，背部一道狰狞伤口不断散发**青色之气**，长长口器断裂，全凭「回来见主人」的意念未死。
- 王林右手一拍其背，青气消散；左手抓开裂缝，取出大量丹药喂服。
- 神识钻入蚊兽头部翻看记忆后，面色更为阴沉，滔天杀机骤然爆发：**「你们找死」**

## 关键要点

- 王林现以「朱雀圣皇」身份公开示人，且身份已被炎雷子当面点破为王林。
- 玉简线索被王林主动公开给尸阴宗与雷仙殿（罗天一方），是**借刀杀守尸之人**的阳谋。
- 境界节点：窥涅 → 净涅；意境链条：生死轮回 → 因果循环 → 真假一念。
