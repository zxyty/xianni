# 第2008章 炉香一拜皇尊森（第一更）

## 一、道古一脉的疆域与交通

- **方位**：古之三族中，道古一脉位于**仙族大陆西南方位**，所辖为**道吉十二郡**，范围堪比仙族一州，甚至略大。
- **横渡之难**：如此庞大范围，若无缩地成寸之术，纯靠飞行需很多年方可横渡。
- **古族特有运力**：古族有**大古神、大古妖、大古魔**三类“半生的存在”，依靠它们**撕裂天幕**行走，可大量缩减耗时。从始吉一脉归来的**道古使团**，只需数月便可回到道古皇城。

## 二、道古皇城（天空之城）

- **形制**：一座漂浮在半空的庞大城池，天地间透出深深威压。
- **护城禁制**：城池四周漂浮无数大小不一的碎石，以天空城为中心环绕缓缓转动，组成一片**严密禁制防护**；入城者须持**身份玉简**，否则无法踏入半步。
- **古祖雕像**：城正中间屹立一尊男子巨像，仰天而望、神色轻蔑，王林轻声喃喃：“**古祖**”。
- **道古皇宫（正东方）**：整片东部区域由一座座华丽大殿组成，守卫森严、禁制密布，笼罩在淡淡**紫气**之内，令人压抑。紫气中隐隐凝聚出一个**极为庞大、似支撑天空、看不清面目、头戴帝冠**的模糊身影，散发**精纯吉族气息**。
- **对比**：此城不及仙族祖城磅礴，皇宫亦无法与仙皇之宫比较，但**守卫程度与压抑感远超仙皇之宫**；宫中侍卫、仆从皆有不弱修为。
- **繁华**：皇城居住的道古族人数量极大，颇为繁华热闹。

## 三、王林入城：第十人

- **时间线**：道古使团回城**一个月后**，王林凭**地图玉简**，自**始古之地**度过广阔大地来到此处，望着天空之城许久。
- **禁制豁免**：在道古族人看来，当今天下唯有**仙罡九阳**这九人可无视皇城禁制、如履平地进入古族三大皇城之一。而王林步伐不快、身影却消失化作一道**烟丝**飘入城中，层层禁制无法阻拦——等于在九人之外多了一人。
- **心境**：望着城中男男女女无数古族之人，王林却**不再有初到古族时那种隐隐的归属感**。

## 四、道古殿与香炉

- **位置**：天空之城**最南端**有一座城中之山，云雾缭绕，散发**大天尊气息**；王林不需散开神识即可感受到，且觉出其中柔和之意，微微一笑转身向南。
- **山路**：一行台阶蜿蜒而下，旁有扶手，青灵气息扩散，深吸一口可精神一振；不少族人神色虔诚，一步步登山。
- **道古殿（道吉殿）**：山顶大殿，为道吉一脉**唯一的大天尊玄罗**的居所，对每一位族人开放，可来寻求修为上的突破。极少有人能见到玄罗本人，指导修为的是**追随玄罗的九个道古强者**，任何时候都有一人在殿内为族人**开灵择体**。
- **香炉**：殿外有一巨大香炉，需**十人环抱**之大，内盛白色灰沙，插**九根巨大燃香**，青烟直上九天。此炉奇异：**跪拜者越多，青烟越浓**；九支燃香似永不燃尽，万古如此。求解修为之惑者皆先在炉前跪拜。

## 五、核心事件：王林一拜

1. **拜的对象**：王林走到香炉旁**抱拳深深一拜**——所拜不是此炉、不是炉中之香，而是**他的师尊玄罗**。
2. **决意**：他既选择来到道古一脉、追随师尊、**履行当年的誓约**，便已想扎根于此。**流浪数千年**之后，他想在这个地方平静地生活下去——**守护道古，守护其师尊的转世**。入乡随俗，故有此一拜。
3. **异象**：拜下的刹那，香炉轰鸣巨响，九支燃香以肉眼可见的速度**疯狂燃烧**，滚滚青烟骤然浓郁**十倍、百倍、千倍、万倍以上**，与之前相比“如皓月与萤火”。青烟冲天而起直冲九霄，在天空尽头化作**蘑菇形状**向八方扩散。
4. **范围**：山中所有人、山下、整个天空城南部乃至其他方位，甚至**正东方皇宫内**都看得一清二楚；先前拜完之人与石阶上后来者纷纷驻足、骇然、难以置信。
5. **青烟弯腰**：更惊人的是，天边滚滚青烟**弯腰划出巨大弧形**，似无法承受那一拜之力而涣散、几近崩溃——在众人看来，这哪里是拜香，**分明是青烟在向王林一拜**。
6. **中止**：王林这一拜**只进行了一半**便未再继续，因他看到万倍浓郁的青烟承受不住，再拜必溃。
7. **玄罗传音**：耳边响起熟悉、柔和、带慈意之声——“**王林，不要拜了，来后山**”。王林身子抬起，青烟不再弯腰，随其走过香炉，滔天之烟恢复正常。

## 六、皇宫的反应（支线）

- 道古皇宫最高阁楼内，一名**身穿皇袍、头戴帝冠的男子**背手皱眉盯着天边青烟。
- 身后老者正恭敬禀报：“**此番选妃，共找到三十一女，如今已全部安排下去，一一进行融魂**”——话未说完即被青烟异象震住。
- 皇袍男子下令：“**能让道古殿前香炉散出如此青烟……查一查，此人是……**”话未说完，见青烟弯腰，全身一震、双目滔天精光；老者倒吸口气、后退数步，内心生出**惊恐**。

## 七、要点与伏笔

- 王林正式在道古一脉“亮相”，且以最惊世的方式暴露了实力层级——超越皇城禁制、压弯万古香炉之烟。
- 道古皇权（皇袍帝冠者/紫气帝冠虚影）已开始追查王林身份，与玄罗一系形成潜在张力。
- “选妃三十一女，一一融魂”为独立伏笔，指向皇宫的某种秘法用途。
- 玄罗召王林去**后山**，为下一步剧情入口。
