# 第1913章 老祖海龙！

## 一、仙皇圣旨降临（天牛洲战场）

### 皇族威权设定
- 金色身影现于归一宗上空，宣告『圣旨』，全场（道魔宗、毒魔宗、归一宗）修士无论修为齐齐躬身一拜。
- **仙皇圣旨**极为罕见，数万年难得一现；每现一次即代表远在**中州**的仙皇不可抗拒的无上威严，称之天威亦不为过。
- 仙皇身负**仙祖血脉**，是整个仙族至高无上的存在。虽只名义上统领仙族，但绝非一宗一派、一洲一州可以抵抗；除非想要叛仙，否则圣旨一到，众洲必听。
- **这一代仙皇本身就是九阳之一**，实力+身份叠加，使皇权在这一代达到极高程度。
- 传旨的金色身影本身并非仙皇，但持圣旨即为仙皇化身。

### 仙祖定下的两条祖规
1. **遇皇不跪，一拜即可** —— 仙祖认为修仙本就是与天之争，岂能轻易跪人。
2. **诸侯放任，非大事不参与** —— 仙祖意志：仙族者不可强行约束，若被约束则不配成仙。故仙皇一脉对仙族之地放任，连其余**四个大天尊**也对仙皇一脉给予一定尊重。

### 圣旨内容（三道）
> 「圣旨三道，一道于此，一道于大魂门，最后一道，于绿魔洲道魔宗。」

- **停战令**：天牛洲、绿魔洲仙族之民即刻停止战争。
- **征召令**：云逸封、唐佳、边云、周海、赵东青等**八人**奉旨入宫，入**祖庙试炼**。被点名者神色瞬间激动。
- 圣旨化金光落于归一宗山门，漂浮不动，散发柔和金光。金色身影随即消失。

### 大魂门同步一幕
- 几乎同一时间，大魂门外双方厮杀最烈处，第二个金色身影幻化而出，重演同样一幕。
- 圣旨内容大同小异，唯八人名单换成**云空**等大魂门在此战中崛起的修士。

## 二、战争的真相与终结

- **战争本质**：看似复杂实则简单 —— 双方为的是在群洲中展现两洲新一辈修士的夺目，以此吸引仙皇注意、换取进入祖庙的机会。此战最夺目者共十六人，归一宗、大魂门各八。
- 归一宗宗主深吸一口气、嘴角微笑；绿魔洲几个空劫大尊亦抱拳再拜，齐呼「吾等，遵仙皇旨」。
- **青牛老祖**抬头望天，神色复杂轻叹：此战死去太多修士，但为这一个机会不得不如此。心中暗道：「当年老祖留下的推衍，虽说有些出入，但大致相同……只是那**王林，我没有告诉他全部的因果**。」随即转身走向闭关之处。
- 持续**一百多年**的两洲战争就此结束，绿魔洲修士大量退回家乡。天牛洲死亡很多，绿魔洲死亡更多。

## 三、绿魔洲·道魔宗覆灭（王林线）

- 王林布下的**环形禁制封印**急速收缩，凡碰触的道魔宗之人纷纷凄厉死亡，宗门建筑轰然崩溃成废墟。
- **不到三十息**内摧毁一切、杀尽所有修士，禁制随后凝聚于半空王林脚下、湖泊四周边缘。
- 死亡近**三万修士**：元神大都毁灭，唯**数十个大能之辈**元神被困禁制内，此刻齐齐飞出被王林一把抓住，挥袖收入储物空间。

### 元神与速神决（关键设定）
- 元神是王林修炼**速神决**的重要之物。
- 王林此时**只有一条神脉**；多吞噬元神可增加神脉，同时让施法速度达到极为惊人的程度。
- 此前死亡的两名空劫大能（一个元神毁灭、一个元神燃烧死亡）王林未曾收取 —— 因他要借这一战**准确判断自身修为达到何等程度、每一丝力量的使用**；若还分心护住元神便无法判准。且日后再取空劫元神并非难事。
- 天牛洲发生之事，王林此刻并不知晓。

## 四、逼出老祖海龙

- 王林冷声：「道魔宗宗门已毁，满门皆亡……你，还不出来么。」右手挥落，禁制封印爆发刺目光芒、轰鸣着向湖泊急速收缩。
- 湖水掀起波纹、水汽扩散，湖泊大片崩溃瓦解，光芒直奔**湖泊中心岛屿**。
- 收缩至湖泊一半时，湖中传出惊天嘶吼 —— 一条**深蓝色海龙**冲天而出。

### 海龙形貌与来历
| 项 | 内容 |
| --- | --- |
| 类别 | 仙罡大陆之**仙兽**，散发浓郁至极的仙气 |
| 体量 | 全身蓝色，**万丈之长**，身粗百丈 |
| 形态 | **无爪**，形似大蟒却拥有媲美龙的力量；背部一排排利刺；头部两扇巨大成扇状的鳍 |
| 异相 | 暗红色双眼之上又现两眼 —— **四目** |
| 修为 | 不弱于一个**空劫巅峰金尊** |
| 栖息 | 本应生于大海，却栖息于道魔宗此湖泊 |
| 来历 | 常年跟随道魔宗那位**天尊老祖**；多年前老祖离去时将其留下作**守护仙兽**，自信有此龙加道魔宗自身力量足保万万载安生 |

- 海龙出现瞬间，崩溃湖泊中的**中心岛屿**散发土黄色光芒，笼罩成防护光幕，阻挡禁制封印轰击。
- 海龙威压笼罩八方，随即张开血盆龙口带腥气直奔王林吞噬而来，背刺尽竖泛冷冽寒芒。
