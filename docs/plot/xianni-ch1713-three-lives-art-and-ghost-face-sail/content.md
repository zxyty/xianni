# 第1713章 斩鬼帆！

## 一、三命术成：三斩、三祭坛、三个王林

### 斩身过程
- 王林忍痛咆哮「斩三神」——双影长刀一刀落下，血光万丈自体内扩散，其**元神被封灭族的奇异之力生生分成三份**，刀随之崩溃化作碎片。
- 王林再低吼「斩三身」——已只剩单影的长刀爆发惊天呼啸，第三次斩下；刀在斩过身体的刹那崩溃，**王林身体直接一分为三**。
- 三份身体各自融合了三份魂、蕴含三份元神，直奔四周三个样式不同的**封灭族祭坛**。

### 祭坛孕育（十四天）
- 三祭坛吸收三份魂神身后血光更浓，彼此环绕缓缓旋转。
- 第一个七天：血光渐弱但依旧闪烁；第二个七天后：血光全部消失。
- 三祭坛依次崩溃，各走出一个王林；最后崩的是**血阁**，层层爆开，**道古气息冲天而起**。

### 三句合一
- 第一个王林：「三命术」
- 第二个王林：「强开造化」
- 第三个王林（双目奇异之芒）：「三体归一」
- 三身同时前迈一步，重叠融合，许久后化作一人。白发舞动，漂浮星空。

### 结果与代价
- 体内生机有三份，**每一份都相当于他之前的全部**——「有此术在身，我便拥有了三条命」。
- 被分成三份的不只是**道古血脉**，还有他的**分身修士**，可以说他的一切均被分成三份，融合后即三条命。
- 代价：其魂与肉身太强，封灭族祭坛承受不住分化冲击而崩溃消散，**自他之后再无三命之术**（绝响）。

## 二、了结旧恩怨
- 王林右手手心托着一个女子的魂——即**当年藏身在血阁内的故人**。
- 「你我恩怨，一笔勾销，送你入轮回，好自为之」——挥手令其魂消散、入轮回。

## 三、当前实力与下一步规划

| 项目 | 现状 / 目标 |
|---|---|
| 肉身 | 已获得**道古血脉** |
| 妖魔神 | 三者均达**八星** |
| 修为 | **空灵中期** |
| 禁制本源（第七道本源） | 待炼化鬼脸帆而成；成则修为达**空灵后期**，配合道古血脉可与**空玄后期**一战 |
| 战之本源 | 当年感悟的一切已化作**规则之星**，需时间重新调整；若也诞生本源，则达**空灵巅峰** |

- 王林认为「是到了离开这里的时候了」，但离开前须彻底炼化鬼脸帆。

## 四、鬼脸帆的真正价值：幻道与第三魂
- 王林明言「禁制本源倒还是其次」，**最重要的是幻道**：鬼脸帆布既能被**矾珊梦**（按世界状态须知，第1606章起以「矾珊梦」之名行事者实为矾珊璐）作为**介子**施展幻术，其中必有**大魂门的幻道神通**。
- 若能明悟幻道，他或可凭此法宝像**七彩道人**一样，以同样方法去找第三魂。
- 「眼下的局面，就看谁能第一个找到第三魂了。」

### 第三魂争夺格局（王林推衍）
1. **七彩道人**——从其愤怒判断，他在幻境内并未追寻到第三魂的轮回之处。
2. **战老鬼**——同样在寻找第三魂，方法与心思不明。
3. 前两人**引发了界内界外大战**只为寻找第三魂；眼下战争已结束，或正以战争换来的方法继续寻找。
4. **远古仙域四大战将与那些仙人**——第三股力量，亦在寻找。
5. **五行星纳多一脉**——隐藏此地无数年，估计将要浮出水面。
- 终极目的：**只有找到第三魂，才能去往大门并将之打开，带着所有人进入仙罡大陆。**

## 五、漏算之人：天运子
- 王林突然神色一凝：「我少算了一个人」——**天运子**。
- 天运子当年获得**天道之血**，尽管青龙圣皇说那血液有问题，但他不可能因此死亡；他始终没出现，连界内界外大战都销声匿迹。
- 「他算计惊人，早年便多次算计于我」——王林自成为其弟子起，对天运子的忌惮随其神秘而越来越深。
- **七彩仙尊当年化作三魂七魄**：三魂衍化至今；七魄中王林只确知**清水**是其一，另外六人略有猜测。疑问：天运子是七魄之一，还是干脆就是**第三魂**？
- 七彩幻境所见：第三魂**穿过召河，进入昆虚**。若第三魂最终停留昆虚，则天运子可能性最大——但「若他真是第三魂，若要寻找未免也太简单了一些」。
- 疑点：天运子曾**吞噬大量其弟子**，其心神内王林曾见**三千分身**。当年以为是为冲击第三步，如今看或是**以三千分身为香火**，也可能另有目的。
- **远古仙域天劫中同样没有天运子的命运之魂。**
- 王林最终压下心绪：此事多想无用，随时间流逝自会知晓。

## 六、剖解鬼脸帆：禁制风暴笼罩云海裂缝
- 鬼脸帆布内存在数之不尽的禁制，**包罗万象，有四大禁，更有其他**。
- 成本源之法：**推衍融合，把帆布内所有禁制最终化作一道**。
- 王林神识沉浸帆布十天，百万、千万、数千万禁制一闪而过；至第六天双眼充满血丝抬头——「**它们可以自行演变，无法算出具体的数量**」。心神很是疲惫。
- 判断：这是一个**完美的禁制组合**，必须**完美打破**方可进行推衍融合。
- 动手：左手一抓取出**血剑**，一剑斩下，血剑穿透帆布**撕开一道缺口**；王林**全部神识顺缺口疯狂钻入**。
- 反噬：帆上鬼脸狰狞、阵阵嘶吼笼罩星空；缺口内如狂风吹出无数禁制，弥漫八方、无尽虚空，最终**占据了整个云海裂缝的每一寸星空**，如风暴回旋，王林身影被淹没其中。
- 成败判定：**当这占据整个星空的禁制风暴消散、化作一道时，王林的禁制本源便告大成**，他将拥有与空玄后期修士一战的强悍之力。
