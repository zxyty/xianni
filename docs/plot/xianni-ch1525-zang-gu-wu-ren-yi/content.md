# 第1525章 葬骨无人忆！

## 一、开天斧与第八颗星

王林握住开天斧的一刹那，一股磅礴的**古神之力**顺着右手疯狂冲入体内，直奔眉心。彼时其眉心第八颗星尚未完全成形，仅出现气旋；这股古神之力冲入之下，第八颗星的气旋顿时膨胀，展开了疯狂的吸收。

## 二、点燃死战：我辈修士，何惜一战

- 王林吼声如雷：「我辈修士，何惜一战」——身后仅存的数千云海修士齐声呐喊咆哮，忘记死亡、只余战意滔天。
- 王林站在星空、站在数万人之上，回头问：「你们，可愿随我一死」，引出惊天之吼。
- 这声音传入无尽界外修士耳中，令其心神颤抖。他们看向王林的骇然与恐惧，与**当年第二次封界大战**中其祖先看向**封界之尊**时的目光一模一样。
- **云海修士的战争意志**：可以战死，绝不能逃遁；荣耀战死之荣耀要传遍界内、深入每个界内修士之心，点燃战火，如此在悬殊之战中方有一线生机。此战不知要维持多少岁月，眼下仅是开始；若最终界内败，则要有战后界内再无任何修士的决心——这才是死战。
- 章题所本：「寒山远，烽火烧几季，边陲亡，葬骨无人忆」。

## 三、直指云落大司

王林目光如电，一眼看向遥远处被无数修士保护的**云落大司**，杀机滔天。红杉子被阻止而未能做到的事情，他现在准备去做。

一声「杀」为**古神吼**，星空颤抖，大量界外修士面色大变全部后退；在他们眼中，持开天斧的王林仿若不可战胜。数千云海修士随之疯狂前冲，如利剑刺入敌阵，王林右手开天斧仅仅抬起未挥，便无人敢阻半步。云落大司抬手一指下令，退缩的界外修士狰狞冲出，却一触即溃——恐惧压过了伪装的狰狞。

## 四、战场态势：红杉子与南云子的牵制

- 红杉子与南云子同时出现，阻止任何一个**第三步大能**离去。
- 但与红杉子交战的**寒衣童子**本就修为高深，红杉子又被**仙妃**偷袭带伤，加之交战大能数量众多，无法牵住所有人。
- **火雀族老祖**因此成为第一个冲出战团、直扑王林者。

## 五、一斧瞬杀火雀族老祖

1. 火雀族老祖全身缭绕黑色火焰，眉心**火雀印记**闪烁，轰然化作一头巨大黑色火鸟将其包裹，火鸟之上弥漫大量**香火之力**，穿过层层大军逼至王林不足千丈，狂言「小杂种，有那开天斧又如何，看老夫如何杀你」。
2. 王林眉心星点急速旋转，**吉神之力**弥漫全身，抬斧狠斩，低吼「阻我者，死」，身前幻化出几可堪比**封阵之灵**的巨大斧影。
3. 双方目光齐聚：界外修士期望王林被轰杀以驱散畏惧；云海修士则担忧王林被阻会挫伤刚点燃的气势——「一股气，不断阻」。
4. 斧影撞上黑色火鸟，火焰外扩却毫无抵抗之力，被直接穿透。
5. 火鸟一分为二，露出面色苍白、神色骇然的火雀族老祖；斧落其眉心，眉心爆血、血色细丝扩散撕开血肉、**断开其族印**，露出头骨；头骨粉碎裂开，斧影切入剖开脑部，将整个头颅分成两半，颈脖、胸部尽数被穿透，全身分开。
6. 其**元神亦无法逃脱**，随身子分离而直接毁灭，消散星空。
7. 全程仅一瞬——**瞬杀第三步大能**。

## 六、余波：封尊荣耀

- 星空骤然安静，界外修士呆立不敢置信。
- 王林自被撕裂的尸体中穿过，赤红双眼死盯云落大司疯狂冲去；其前方所有界外修士惊恐尖叫、齐齐避退，连云落身边最近的修士也惨白后退——他们眼中的王林如自黄泉走出的仙魔，带天地煞气欲毁灭一切生灵。
- 云落大司恐惧最浓，眼中浮现出她曾**推算出的画面**：画面中那个令她恐怖的背影，似正向自己走来。
- 数千云海修士高吼「封尊荣耀」，越来越激昂，终化作一个声音在星空中似永恒回荡。
