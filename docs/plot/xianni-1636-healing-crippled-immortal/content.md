# 第1636章 疗伤的残仙

## 一、第九阳内的命运搜寻（承前）

- 王林神识深入第九个太阳搜寻众生命运气息，**找到了很多人的命运，却唯独找不到清水仙君、司徒南，以及对他至关重要的女人（李慕婉）**。
- 神识归体，王林目露迷茫：“司徒、清水的命运，为什么不存在于这里？难道他们，不属于这个洞府么？”

### 三条推测线
1. **清水**：王林忆起召河七彩界所见——清水的一生处处有**七彩道人**的目光注视，那奇异目光或可解释清水命运为何不在第九阳中。
2. **司徒**：王林自认对司徒了解很多——天资惊人、**每一次相遇修为都会暴增数筹**——怀疑这正是其命运不在第九阳的答案。
3. **天运子**：从一开始便琢磨不透，“即便如今我修为达到了**空灵中期**，对于天运子，依然还是有些忌惮”，认定此人秘密很多很深、让人可怕。

### 婉儿命运被取走 —— 逆鳞与誓言
- 与司徒、清水不同，**婉儿的命运气息在此留有痕迹**，说明其本应存在，如今却寻不到 → 结论：**被人取走**。
- 王林立誓：“我王林在这**远古仙域**发下誓言，必定将其取回，若有人将其命运改变，那么上天入地，即便是**仙罡大陆**，我王林也必定如当年**藤家之仇**一样，血洗仙罡。”
- 心境刻画：婉儿是王林的逆鳞；知晓越多越痛苦，但已无退路。
- **关键目标确认**：让婉儿如自己一样超脱命运之外，是**让李慕婉苏醒（复活）的第一步**——王林至此明白，他如今所做的一切就是在复活李慕婉。

## 二、洞府大地：轰碎古之三族雕像

### 场景
- 大地广阔无垠、无任何生灵，苍凉北风卷起尘沙；地面遍布**恒古之前某次大战**留下的沟壑与深坑，如疤痕坑洼，当年神通留下的天地气息仍未散去。
- 地面上耸立一座座**古之三族（古神／古魔／古妖）雕像**。

### 王林的判断与行动
- 雕像中的古神已死，但**内有一股奇异力量，使其随时可苏醒为失去自我的傀儡，即所谓“天道使者”**。
- 王林评语：“古之三族，却成为这洞府侍卫，可悲、可怜、可恨。”
- 一脚点碎第一尊古神雕像，并道：“**尘归尘，土归土**，既然当年已然战死，就不要持有残存苟活之心，死在战场，方是我等之人，最好的归宿。”
- 理由：“我今日不毁你等，日后你们苏醒，定会扰乱世间，成为傀儡。”
- 所过之处，古神、古魔、古妖雕像尽数崩溃。

### 残魂归附
- 雕像崩溃时逸出气息化作烟丝，形成**生前模样的模糊虚影（甚至可见当初伤势）**；虚影初时迷茫，随即了然，**苦涩中向王林一拜**，扭曲成烟丝直奔王林，与其身体融合。
- 无数古之三族气息融入王林的**眉心、左目、右目的星点**内。
- 天空中抱拳似解脱的虚影成片，北风呜咽如喃喃诉说往事。

## 三、九星古神雕像与残仙出世

### 雕像
- 高约**数千丈**，眉心有**九个星点**（第九星略模糊但已有雏形）→ **无限接近九星巅峰**，是王林一路所见星点最多的古神。
- 姿态：右手握拳只挥出一半，神色蕴含痛苦与不甘，被一股力量凝固；身着简单铠甲，铠甲亦成雕像一部分。
- 王林感受到其惊天之威，仿佛能听到万古岁月前的怒吼咆哮；**抱拳一拜后**才挥手将其轰碎。

### 残仙
- 崩溃瞬间，眉心九星连接成环的中心点出现**急速旋转的漩涡**，雕像眉心如同融化，尖锐嘶吼惊天传出。
- 一只**带无数粘液的干枯右手**自漩涡中挣扎伸出，扩散出阴森气息，似代表死亡、蕴含无上威严，手内隐有**金芒**闪烁。
- 残仙怒喝（自称“吾仙”）：“汝惊扰了吾仙的沉睡，汝毁灭了**吾疗伤的胚体**，汝犯下了死罪……不但汝要死，汝所在的族落也要全部陪葬！汝毁灭了胚体，**汝之身便成吾之胚体**……”
- 王林一声“聒噪”打断，上前一把抓住干枯之手猛地外拽：“你挣扎的如此痛苦，我便帮你出来好了，给我滚出来！”
- 雕像彻底崩溃，一个**干瘦身影**被拽出，被狠狠甩向大地，砸出大坑。
- 王林跃入坑中：“**有活人就好，不管你是仙还是修，你的记忆，王某要了。**”
