# 第八卷 联盟隐秘 · 第1029章 鸟散

## 一、场景与开局
葬仙池地面巨坑内，葬仙漩涡冲天而起，爆发出无法想象的吸力。无数铁链拽动符族圣祖女子，将其缓缓拖回漩涡。她眉心符文每闪烁一次，身外大片铁链便崩溃、化作被撕碎的魂魄惨叫消散，但漩涡内立刻又冲出无数魂魄凝聚成新铁链，死死拽住她。围观者尽皆沉默、心神震动。

女子被封印年岁太久，早无当年修为；她自陈：若无**青霖分神**在场，尚有几分脱困之机，眼下毫无机会。她空洞的眼眶内有一团青气流转，取代双眼而有了灵动。

## 二、秋瑶的控诉（本章核心信息）
女子自称**秋瑶**，向青霖分神惨笑控诉，交代了大量前史：

1. **符族入封界的缘由**：当年符族冒犯了**掌尊**，不得不逃入掌尊无法操控的**封界**，只想避开纷争、远离死亡地生存下去。
2. **两界之战的起因**：仙界看中符族**本源之力**，出手在先。大战持续极久，仙界手段尽出；青霖更为抢夺符族至宝**圣瓶**，杀了符族无数强者。
3. **情感上的欺骗**：青霖身为**仙帝**、四大仙界内第一强者，许诺立她为**符妃**。秋瑶为此背叛族部，甘心为妃，只求换符族在封界内一处栖息之地。
4. **献目**：青霖说喜欢她的眼睛。她便把符族自太古之民以来凝聚无数万万载、蕴含太古之初一丝力量、历代圣祖需继承的**太初之力所化双目**，亲手挖下相赠——眼眶留血的一幕她仍记得。
5. **被封印**：她甘愿被封印在葬仙池内镇压滔天魂魄，明知这是变相封印，仍选择相信。
6. **谎言的败露**：因感应到族人接近，她不惜代价现身，才得知符族根本没有获得一界，反而在她被封印后沦为**仙界之人的奴仆**。
7. **最恨之处（奴印真相）**：寻常奴印封不了符族世世代代；符族身上的奴印，分明是从她所献双目内的**太初之力**酝化而出。青霖借这一丝太初融入无数奴印，使四大仙界内所有符族人尽成蝼蚁不如的奴仆，世代膜拜仙人。

她流下的是黑色血泪，承载无数万年的期待与刹那崩溃后的滔滔怨恨。最后厉声质问：「青霖，你分身在，则你人未亡，你可敢现身见我」——由此确认青霖本尊仍存活。

## 三、两次赠予

### 1. 本命符文 → 塔山
身子将没入漩涡之际，秋瑶眉心符文疯狂闪烁并生生脱离，可见一道道血丝与符文相连，其痛可想。她抬右手抓住符文狠狠一拽、向上抛出。符文以闪电之速烙在**塔山**眉心，刺痛之下深深融入。塔山在旁目睹全程，有所明悟，但双眼仍透出迷茫。

### 2. 枯符之术 → 王林
抛出符文后秋瑶极为虚弱，渐沉入漩涡，青气双目看向王林，喃喃道：「你帮助过我符族，对我符族有恩者，我秋瑶不会忘记。」随即双手抬起狠狠刺向自己双目，抽出眼眶内代替双眼的两团青光，合为一道甩给王林，并传来神念：

> 「我符族除了本命符文，名震界外之物，还有**枯符之术**，这便是制作枯符的方法，以你对我符族的照顾，可以让我符族后人，为你添入符文之力。」

**王林的判断**：枯符之术需符族之力，等于一道无形锁链把王林与符族绑在一起；秋瑶如此有信心，可见枯符绝非寻常。他随即回想起在**罗天星域**与**姚家**之人一战时，见过的那种**可以封印元力的黄色纸符**，心中生疑「莫非……」，双目一凝。

## 四、结局：同归于尽
女子身体全部沉入葬仙漩涡，四周与漩涡内无数魂魄一同静默融入，漩涡渐渐下沉、眼看要从深坑内消散。

骤然惊变：秋瑶身影在下沉漩涡中心再度浮现，怨毒撕唳——「青霖，即便我死，也不会放过你」。葬仙池内涌现大量魂魄，并非冲出而是不断崩溃，每崩溃一个，葬仙池便随之颤抖。她道出关键：无数年来她**已与葬仙池融为一体**，「他们不让我离开，你也不让我离开，那么，就让我们同归于尽」。

整个葬仙池轰然崩溃，无数魂魄被生生撕裂彻底瓦解，化作毁灭性力量融入漩涡；漩涡吸纳这股力量后产生惊人变化——本章至此断在剧变发生之时。

## 五、要点与伏笔
- **青霖未死**：分身尚在即本尊未亡，为后续埋线。
- **奴印的死穴**：符族奴印源于太初之力，暗示破解奴印可能须回溯太初/双目。
- **枯符之术**：王林获得的新底牌，且与罗天星域姚家封印元力的黄符疑为同源。
- **塔山承继**：秋瑶本命符文烙入塔山眉心，塔山成为符族传承的新载体。
- **葬仙池的毁灭**：秋瑶自爆式反击，池内魂魄化作毁灭之力，局势即将剧变。

## 一、识破「大海」：一滴露水化作一界

王林右手一捏，海水团崩溃，随即断定此处**不是海水**：

- 依据是早期修行依靠**天逆珠**的经历，对露水极为熟悉，绝不会认错。
- 结论：此地并非大海，而是**花丛内一片花瓣或一束青草叶上的一滴露水所化之世界**。
- 评语：「好厉害的禁制之术，以一滴露水化作一界，困人于无形之中。」

看破后王林非但没有轻松，反而更为凝重：

- 禁制之术讲究**困与攻化为一体**，少有专为困人之术。
- 此处是**仙帝洞府**，据符族圣祖**秋瑶**所言，仙帝**青霖**乃灭绝人性之辈，这种人所设禁制不可能仅为困人。
- 决断：**此地禁制绝不能让其再次开启**。

### 关于青霖的判断态度

- 进入此处前，王林清晰看到**青霖分神所化的晶光**飞来，融入其**储物袋内的黄色结晶**中。
- 王林以一千多年阅历为凭：黑与白分看是两色，融在一起却是**灰色**——外人所说只听不信，除非亲眼所见或自行分析而得。
- 自省：若放在当年尚未修仙、或在**恒岳派**之时，说不定就真信了。

## 二、海底疗伤七日与全局复盘

王林操控气泡缓缓沉至海底（大地一片灰色、朦胧），盘膝闭目疗伤，但**神识不闭**，环绕四周十丈警戒。七天后，第八天睁眼，**双目开阖间火焰之芒一闪而过**。

随后在脑中逐幕回忆入仙帝洞府的经历：

1. **朱雀觉醒**：意外觉醒并破开了**瓶中界**。记忆定格在**古妖贝罗**出现时其右手之上的**画轴**——王林推测那就是**山河图**中的**大漠孤烟图**。
2. **暴露风险**：朱雀之音竟穿透**九十九界**，所有人都听到了，因此都会认为他是**四圣宗**之人。
   - **虚空子**：神色无端倪，但王林总有针芒在背之感。
   - **村姑美妇**：修为只是**净涅**，看他的目光掩饰得很好，仍被看出一丝不善。
   - **疑似昆虚圣女之人**：同样目光不善。
   - 结论：此行须更为谨慎，否则极可能因朱雀觉醒而引来杀身之祸。（王林摸了摸身上的**朱雀图腾**，面色阴沉。）
3. **葬仙池·塔山**：塔山本是王林的**仙卫**，在葬仙池遇到**符族圣祖**算是其造化；王林不知他此刻身在何处、记忆中是否还记得自己。

## 三、枯符参悟：从青气团到遁类实测

### 1. 青气团（秋瑶所赠）

- 王林右臂青气缭绕凝于手心成团，此团**并非静止，而是不断运转**。
- 分出一丝神识融入查看，面色时惊喜、时思索、时迷惑，许久后捏散。

### 2. 枯符设定要点

- **枯符**：唯有**符族**才可制作的符文。
- 若由外人制作，需寻**符族之人**帮助完成**最终的开启**。
- 威力主要分四类：**封、崩、遁、解**。

### 3. 验符

- 王林拍储物袋取出黄纸符：其上符文复杂、颇具年代、略有旧色。**原本共有两张，得自罗天星域**，研究很久不明其功效，唯一一次动用是**与罗天姚家族人之战**。
- 看过青气团后确认：此纸符**就是枯符**。
- 手法：咬破左手食指挤血向前一挥，按青光团内记录掐出印记点在鲜血上——此为**刚学会的、查看枯符属于何类的印决**。
- 反应：鲜血停在半空、生出无数细密鼓包，呲的一声化作赤红之气融入纸符；纸符一动，其上生出极快的**黑色旋风**，旋风中隐约幻化出一只**样似大鹏、通体黑色、双目电芒闪烁**的飞鸟，横扫一圈后与旋风一同消散。
- 判定：**已经被符族开启过的「遁」类枯符**。

### 4. 实测遁速

- 载体：从储物袋取出一把**大剑**，得自**杀域界九十九之一**；虽已崩溃十多把，袋中仍有很多。
- 操作：把枯符按在大剑上，右手掐出一个古怪印决向上一指。
- 结果：大剑通体一震、其上起旋风，**瞬息消失，出现在十丈外**；王林眼前一花才看清。事后旋风消失，符上符文**略有一丝黯淡**（有消耗）。
- 评价：「这种速度，即便是我全力施展，也绝难达到，或许可以与**碎涅**之速一拼——若是配合**缩地成寸**……」王林露出惊喜之色。

## 四、要点与后续伏笔

- **禁制层面**：露水化界之禁制已被看破但未破解，王林决意不让其再次开启；仙帝洞府禁制大概率兼具攻杀属性。
- **身份危机**：朱雀之音已让九十九界误认其为四圣宗之人，虚空子、村姑美妇、疑似昆虚圣女三方已现敌意。
- **底牌新增**：手中枯符（遁类）遁速可比碎涅，且尚有第二张枯符类别未验明。
- **未解**：储物袋内黄色结晶已融入青霖分神晶光，隐患未爆；塔山下落不明；大漠孤烟图在古妖贝罗手中。
