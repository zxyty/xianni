# 第2086章 轮回就在那里

## 场景
太古神境，王林与天运子对峙。王林背对天运子、望着其后那座桥，平静自陈多年布局的全貌。

## 一、疑心的起点：始古祖庙的那一幕
- 王林第二次在始古祖庙内看到「飘着七彩雪花的山峰上、抱着尸体的身影」，心生不妙，同时升起一个疯狂的念头。
- 他害怕的是：这一切为真——即他曾在某一世相识李慕婉却复活失败，最终沉浸梦道、想在梦道中改变轮回。
- 但他不认为那是「前世」。为破此疑，他要去验证、去改变。

## 二、三条线索的汇合
1. **天逆珠子内的声音**：不断重复「缺了一个」，王林长年不解缺的是什么。
2. **洞府界·仙帝白凡**：王林曾见白凡指天癫狂的虚幻一幕。后来推断白凡是无意中悟到——自己存在的世界竟是一座洞府，承受不住而疯癫；与散灵上人同一境遇，只是他没有散灵上人的勇气与毅力。此事给王林启发，也给他更深的恐惧。
3. **万古空门门后之声**：王林在洞府界冲击第三步时出现的万古空门，门后之声与天逆珠子内「缺了一个」之音极为相似。
4. **吉穷（古穷）的头骨**：王林在洞府界看到吉穷死后的头颅，头颅上留有一道神念。本章他虚空一抓取出该头骨——符文印记闪烁，散发冷冽幽光与杀戮气息。

看到头骨的那一刻，「一切，我有了答案」。

## 三、揭破：天运子是定界罗盘的器灵
王林抬头直言：
> 「天逆珠子内那缺少的一个，就是你。你不是所谓的守护者，而是这定界罗盘的器灵。」

天运子身躯轻颤，黑气翻滚，恐惧弥漫——他发现自己所知的一切与真相存在极大差异。

## 四、王林的方法：杀戮分身逆转流月
- 王林会**流月之术**。他让**杀戮分身**在大成之后逆转流月，以自身修为之力如逆转岁月一般，把分身送回**无数万年前**。
- 分身在过去的岁月里**模仿今生、展开属于他的梦道**，推衍并遂行王林今生所发生的一切事情。
- 王林给了这具分身**自主意识与一切自由**。

### 由此得出的结论
- 天运子所说的「前世」，其实是王林**亲自送去的杀戮分身**。
- **仙罡大陆不是梦、不是虚幻**；王林**不是转世**，他出生在朱雀星，走到今日——「我，就是我」。
- 之所以天运子等人认定其为转世，是因为杀戮分身在过去的岁月中**成功改变了一些什么**。

### 杀戮分身留下的关键信息（吉穷头骨上的杀戮神识）
- 分身按王林当年的要求，留下了**让李慕婉苏醒的方法**。
- 分身在过去岁月里**逆转天地、借来了一个罗盘**（定界罗盘）——这是复活婉儿的关键。
- 分身把罗盘放在**仙罡大陆**上，数次进入其内，但每次踏入都会很快消散。
- 最后一次「如轮回般」再次来到**太古神境**，在消散前完成王林的意志：**轰开此盘**，令其不完整，同时**释放出定界罗盘的器灵**——即天运子。
- 王林至今**不知这具杀戮分身在过去岁月都做了什么，也不知其如今身在何处**。

## 五、最终目的
> 「把你释放出来，以你身为定界罗盘的此界本源，来复活我的妻子。」

## 六、王林的轮回论
- 「轮回就在那里」：参悟透彻，它便**因你意而动**；参悟不出，就说它是前生转世。
- 轮回是**一个圆圈**，本就存在，可看到、可感受到；参悟透了便可随意走去、随意选择一个点、信手捏来。
- 佐证：如**墨智**的话语、如**红蝶**的记忆、如天运子在**道古荒山**认出**戮墨**。
- **古祖与仙祖**参悟不透轮回，以为一切虚幻虚假，故而**问道而亡**。

## 七、攻守易位与收场
- 王林：「你在算计我，却不知，这一切，在结尾的时候，是我在算计你——如灯火阑珊处的蓦然回首。」
- 天运子崩溃：他坚称亲眼看到王林前世的一幕幕、看到王林借走他所在的罗盘、带着罗盘沉入梦道，更亲眼看到其在一次次轮回转世中走入罗盘内消散。
- 天运子从当年罗盘被轰开、自己被释放起，一直以为那是一场意外，没想到是眼前王林的计划；算计了一辈子，最后关头算错。
- 王林：「亲眼看到的，不一定是真。因为你看不到轮回，它就在那里，你懂便是懂，不懂，永远也不会明白。」
- 天运子凄吼，庞大身躯化作**遮盖天空的黑雾**，狰狞直扑王林，似要将其吞噬。
