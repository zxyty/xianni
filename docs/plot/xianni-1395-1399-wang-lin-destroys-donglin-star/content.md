# 仙逆 第1484-1486章：东临星覆灭

## 一、九千九百九十九万层光幕（第1484章）

- 王林迈步逼近，东临星吕家连发封命传音：「阵化天幕」「禁魔天仙」「阵禁八方」。
- 东临星外旋转的数十颗小星内，数千修士齐齐掐诀，光幕层层叠加至 **九千九百九十九万层**，光芒穿透星空，弥漫整个罗天东部，其余三方星域亦见「强光东起」，整个罗天星域为之哗然。
- 传闻东临星阵法传自上古，吕家为之饲养阵灵数万年，全阵开启、阵灵入内则威力惊人。

### 鲁夫子的判断
在罗天备战之地（六百余颗修真星组成的星阵中心漩涡），鲁夫子与面色苍白的炎雷子、血神子、烈云子远观。鲁夫子自估破阵需 **二十息**，认为此阵已是第二步神通的极限，天人第五衰单人绝无可能破开。

## 二、道古·神震一拳

- 王林右手指天，眉心 **七个古神星点** 骤转，爆发「道古」气息——比古神更强大，古神即由道古分离而出。星空扭曲、隐现撕裂缝隙。
- 身后幻化出巨大模糊虚影：**只是一个没有左目的头颅**，其大遮盖星空，威压弥漫罗天东部。鲁夫子瞳孔骤缩，惊问「古神？古妖？古魔？」——道古之存在，鲁夫子此生亦第一次见。
- 王林握拳隔空一击，喝「神震」。数万丈虚幻巨拳轰出：
  1. 九千多万层光幕如水面被砸，一息尽碎，仅抵消不足十分之一之力；
  2. 拳头穿透阵法，打爆数十颗修真星组成的漩涡，十余颗修真星大地碎灭、四分五裂，其上修士与维阵老者肉身元神俱碎；
  3. 吕家近万修士喷血入体，数十老者膨胀如血球后自爆，「祭血影，凝阵灵」，血影冲天拦拳——被一拳轰爆化作血雨；
  4. 拳头落地，东临星北部崩溃，出现 **数万丈大小、深入地底六成的天坑**，海水被震离地面后倒灌成湖。
- **全程仅八息**。文中点明：七星古神单以肉身之力即可与第三步大能一战。

### 转折：鲁夫子推翻旧判
鲁夫子从盘膝中猛地站起：「没有达到第三步，仅仅是一拳之力，就如此恐怖……八息！」他推翻此前看到雨剑后的判断，**将王林的位置提到与自己持平**。

## 三、死战到底（第1485章）

- 东临星山峰尽碎，海雨倾落如「东临的眼泪」。南部许家、东部刘家、极西向家近万修士各自骇然，公论「这已然是第三步大能的范畴」「东临星，能否再承受一次这样的一拳」。
- 三家目光齐聚极西向家老祖闭关处，等一句「是战，还是降」。先等来的却是雨中白衣如雪的王林现身天空：**「还不从那棺材里滚出来么？」**
- 极西传出沙哑咆哮 **「死战到底！」**，透着惊恐与疯狂。三家数万修士如被抹去神智般齐齐升空扑杀。

### 血葵术
- 刘家近万修士祭出法宝后齐齐盘坐诵咒，施展 **血葵术**：地面幻化数万丈金黄葵花，花心黑处的「种子」实为万颗人头；咒毕血线一闪，万颗头颅齐断。
- 化作数万丈粗光柱冲天，内藏 **无头铠甲长枪虚影**，气息超过天人第五衰极限，无限接近第三步空涅初期/香火神通之击。
- 王林不闪不避，右手前按硬接。长枪之尖点在掌心，白发衣衫狂卷，**身形一动不动、神色不变**。反震撕裂地层，**东临星东部整块分离**，载着施术者尸体倒卷星海，东临星残缺、开始大范围崩溃。
- 王林评语：「竟有如此神通……毁之有些可惜了。」

### 虚火焚敌
面对发狂扑来的数万修士，王林道「我王林一生杀戮极多，我，不介意杀人的」，左眼九色虚火燃起，随手一挥横扫天地，来者体内虚火砰起、尽化黑灰。**「虚火修士，擅群战」**——王林如烛，众修如蛾。他就在这火海中步步走向极西：那正是当年 **强行夺走他全部生机** 的向家老祖闭关之地。

## 四、神长老（第1486章）

- 王林踏入极西沟壑，土黄棺木喷出黄色粘稠液浪与腐臭死气风暴，被其大袖一甩崩溃。
- 棺内传出 **「远古诏曰，毁东临星者，诛灭九世！」**，向家老祖坐起。

### 向家老祖（东临泰）其人
- 外形：干瘦腐烂、几无皮肤，青筋血管在血肉内蠕动；胸口暴露一颗拳头大小暗红心脏，跳动散发的是死气而非生机；血红双目，怒中带惧。
- 修为：天人第五衰，气息凝成卷动死气的巨大气旋，内含无数凄厉之魂鬼哭狼嚎——王林一步踏入，气旋即倒卷退避。
- 大神通 **七夕之术**：点心逆转全身死气化为生机，腐躯急速恢复；未及展开即被王林两指崩去双臂、双腿，身体被吸力扯至身前，天灵被一把抓住。
- 自报身份：「我向家是远古东临家族分支，老夫更是东临家族旁系族人，老夫东临泰」，威胁王林毁星屠族触犯东临家族当年诏曰，「不但你要死，你的一切亲友，都要形神俱灭」。
- 王林一句「聒噪」，震碎其颈下躯体，只抓头颅继续 **搜魂之术**——不浪费时间问话，直取答案。

### 悬念
搜魂进行中，王林目光一闪，抬头望向沟壑外的天空（章末未揭示来者）。

# 第1395章 东临金门现世·王林踏空而去

## 一、金色大门与东临之姓

- 东临星天空金光凭空蔓延，一扇金色大门轰然出现于天地之间。
- 门上有两个古老文字，是一个姓氏——**东临**。这个家族在罗天星域存在极久，**甚至四大星域尚还是一体之时便已存在**。
- 大门缓缓打开，浩荡威压扩散，一个高约数千丈的金色光影一步迈出：**金甲巨人**，身子极为凝实，如真正存在一般。

## 二、三罪当诛九族

金甲巨人对王林宣判三罪：

| 罪名 | 内容 |
| --- | --- |
| 凌迟之罪 | 毁东临星 |
| 灭魂死罪 | 屠杀此星修士 |
| 滔天大罪 | 伤我东临家族人 |

> 「三罪合一，当诛九族。」

随即右手一抬，幻化出一把**金色千丈大剑**，轰向地面沟壑内的王林。

## 三、一指一剑破幻神

- 王林右手一捏，**向家老祖的头颅爆开**，身子跃起。
- 回话：「杀便杀了，哪里来的如此啰嗦，**今曰王某杀人，阻者，皆杀**。」
- **一指**：蕴含道古之力 + 体内修为之力 + 雷霆火焰本源，直接撞上金色大剑。
- **血剑**同时自身边血光而出，呼啸前扑。
- 结果：金色大剑剧烈颤抖、轰然崩溃四分五裂倒卷；金甲巨人身子震动、步伐一顿急急后退；血剑自其体内一穿而过，金光爆开，巨人与大剑一同崩溃。
- 金光弥漫中，大门下现出**身穿金袍的老者**——王林的一指一剑破开了他的**幻神之术**，逼其露出本体。

## 四、金袍老者的修为与退让

- 老者面色苍白、喷血，双眼震惊。
- **修为已超越天人第五衰，如当年的灵动上人一样，半只脚踏入第三步。**
- 王林升空，白发飘动，一股**宗师气势**表露无疑：「今曰杀人已够，王某要走，你要阻我？」
- 老者抱拳：「阁下修为高深莫测，老夫没有能力阻止，但你杀我东临星族人、毁东临星，犯了我东临一族诏曰，此事老夫会上报族中，在族内长老会定夺。」
- **王林的立场**：若那东临星修士不阻，他断然不会杀人；莫非要因这些修士阻止就任由攻击而不还手，此事大谬。
- 临别之语「**人不犯我，我不犯人，好自为之**」——话语并非对老者所说，而是**看向其身后那打开了一半的金色大门**。
- 转身向星空一步迈去，波纹回荡，身影消失。

## 五、王林离去后：东临二人的判断

王林走后，金袍老者再压不住伤势，连喷数口鲜血，胸部血痕染透——**已然重伤，生死一线**。

门内走出第二人：一名同样身着金袍的**中年男子**。老者问其为何不出手，答：

1. **老祖闭关前曾言：「东临星毁，则我东临家现世」——此为我东临族一劫。**
2. 此人既发现了我的存在，还能说出警告的话语，绝非简单。
3. 你我修为相差不多，都没有真正迈入第三步，就算出手恐怕也留不住此人。
4. **「我所修功法奇异，可以感受到一些你察觉不到的气息……我感受到了两股大能的气息。」**
5. 此战距离王林真正实力「怕是只拿出了小部分」，我如何去战。
6. 「我族族人已经很少，**眼下只有你我二人苏醒**。」

## 六、门内：冰封的世界与睁眼的古神女子

二人正说着，忽感半开的大门内有一股**惊人气息**轰轰而出，同时露出喜色，不假思索踏入门内消失。金色大门则始终留在天地之间，一动不动。

门内另有天地——**一片全部被冰封的世界**：

- 天空的云朵成为**冰云**；
- 诸多漂浮的**碎石大陆**形成一座座冰雕；
- 巨大冰凌垂下，如同利剑。

处于**中心位置**的一块冰封碎石上，盘膝坐着一名女子：

- 相貌**美艳绝伦**，却**充满冷意**；
- 身体与所在碎石大陆一同被冰封；
- 此刻**双眼赫然睁开**，眉心之中**星点一一幻化、慢慢旋转**，一股**古神的气息**浩荡而出。

两名金袍修士疾驰而来，**恭敬**站在这女子所在的大陆之上。

## 七、伏笔与看点

- 东临家族现世被预言为「一族之劫」，且与王林毁东临星直接挂钩，后续有族内长老会定夺的追杀线。
- 王林身上被感知到「**两股大能的气息**」——指向其道古之力/烨寞化身等来历。
- 冰封世界的**古神气息女子**是东临一族真正的上位者，古神线在此接上。
- 已苏醒者仅二人，说明东临一族尚有大量族人处于冰封/沉睡状态。


# 第1487章 往昔红颜梦（第十卷 叱咤界内）

## 一、七星女古神苏醒

- 碎石大陆冰封尽碎：阵阵咔咔声中冰层寸寸裂开，最终整个碎石大陆的冰层轰然崩溃、四分五裂倒卷四射。
- 女子容貌：美貌比当年的木冰眉更胜几分，即便无笑亦令修士怦然心动；眉目间蕴含英气，与寻常女子极为不同；睁眼时目内似蕴星辰，令人迷失其中。
- 苏醒过程：深吸一口气 → 眉心古神星点旋转骤然加快 → 磅礴古神之力自眉心涌入全身 → 许久后双目露精光，右手一握，轰轰之声震动八方。
- **身份揭晓**：一握之下眉心星点旋转一顿，清晰露出其内**七颗紫色之星**——七星古神、**七星女古神**。
- 章首另有二人齐声「恭迎神长老出关」，压住神色上的激动（与出关者相呼应）。

## 二、王林的推演：东临星旧案的真相

王林此刻正在罗天星域星空中前行，虽未全知，却已明悟大半。七星女古神身份的揭露，令此前诸事有了明晰答案：

- 为何一木子会奉命出去直奔望月；
- 为何王林在东临星会被向家老祖吸去全部生机——**被吸走的是古神的生机**。

搜魂所得的向家老祖记忆：

1. 吸王林生机本是一己私欲，与其所修功法有关，且断然没有放王林活着离开的打算。
2. 王林踏入东临星的一刹那，向家老祖便感到王林身上有**一丝向家族人的怨念**，并品味出属于哪一位族人。
3. 就算没有这怨念也会下手——当时王林虽未与本尊融合，但通过魂魄牵引透出的生机之大，足以令其心动。
4. 正要杀王林的一瞬，**远古东临家族**之人传出一道神念，向家老祖不敢不从，遂放弃当场杀人，改按神念要求，**通过王林灵魂、自其本尊处吸收无尽古神生机**。

王林的判断与态度：

- 「这个家族内有古神……只是不知这古神，是恒古存在，还是如我当年一样传承而来。」
- 回头远望后收回目光：「我的警告已经传达，不要来惹我。」
- 东临星现已残破不堪，其上向家及一切分支家族尽数崩溃。

## 三、四件事之第三件：姚家、血神子

王林神色平静但煞气未散，明言四件事已完成两件，第三件是**姚家、血神子**，动机有三：

1. **旧仇**：血神子当年追杀他，若非**清水师兄**，其分身怕早已形神俱灭。
2. **所需**：血神子体内似有**古妖**，而他的**古妖分身**目前急需古妖之力。
3. **因果**：当年虽未答应那姚家女子，却在其梦中留下承诺，留下因果——此行要了却这一丝因果。（呼应章名「往昔红颜梦」）

## 四、罗天震动与姚家女子登场

- 东临星是**罗天星域第一凶星**，凶名赫赫；其崩溃与毁灭的剧烈声响传遍整个罗天，很快被罗天修士大范围知晓，足以掀起惊天震动。
- 场景切换至**罗天南部星域**：约百人的修士小队沉默疾驰，队中有一女修。

### 毁容女修（姚家女子）

| 项 | 内容 |
| --- | --- |
| 外貌 | 容颜已如中年妇人，带岁月痕迹；隐约可见年轻时应是绝美之人 |
| 标志特征 | 满脸触目惊心的暗红色伤疤，交错如沟壑，血肉翻开处只余狰狞可怕，令人望而生厌、不愿近身 |
| 伤疤来历 | 非寻常法术可消——她在岁月中久久自行划出，一次次痊愈后重新撕开，慢慢刻进骨子里、刻在元神上，成为永恒 |
| 修为 | 仅**阳实**境界 |
| 状态 | 透出深深的疲惫与茫然 |

身世：

- 家族在当年与**修真联盟**之战中几乎死亡殆尽，只剩不多几人。
- 最疼爱她的老祖在那场大战中重伤，更在**联盟朱雀星的古神之地**为救她而道陨，整个家族随之崩溃。
- 战后她疲惫不堪、受伤颇重地回到罗天，族人分裂、家族不再，悲伤欲绝中黯然离去，在罗天星域独自默默修行，成为无家之人。
- 乱局中一个柔弱女子难以不屈辱地生存：窥伺其美貌者大有人在，以修为相许诺者更是诸多；家族世交人走茶凉，无所依凭。
- **对照吕菲烟**：如同云海归元宗的吕菲烟一样处境，只不过罗天的她更为决断——**亲自毁去自己那绝美的容颜，断去了一切窥伺的目光**。

# 第1487-1488章 西子凤移星受创与雷仙旧忆

## 一、人物处境：西子凤

- **出身**：罗天星域西家嫡系族人。近千年前的西家在罗天虽非顶尖，但也极为庞大。
- **今日境况**：容颜狰狞丑陋，修为仅**阳实**，无家族在后，被视为「一介野修，可以任意欺辱」。
- **毁容原因**：修士大都爱惜肉身、寻觅不老之法，而她主动毁去美貌。旁人与使者的话点明——「有着好看的容颜偏要去毁掉」。文中给出内因：**红颜薄命，可若颜毁至丑，或许薄命，也就不再了**。若非心中有一个身影，她「怕是早已成为了别人的炉鼎之物，凭着身体去换取继续修行下去的资格与保护」。
- **本愿**：如老祖一样成为修为高深的女修，屹立罗天，有自己的一片天地——此愿已渐行渐远。

## 二、八百年的执念：雷仙界中的那个身影

据【世界状态须知】，该「身影」即**王林**。西子凤记得的三件事：

1. 当年**雷仙界**崩溃之际，那个并不高大的身影带着诸多修士在崩溃的仙界中寻找出路；
2. 与守护阵法的**雷仙殿**之人悍然一战；
3. **封仙一战**中一鸣惊天，**成为雷仙**。

关键落差：
- 当时王林并不知晓四周观望修士中有她；她心中的喜悦却极为浓郁。
- 八百年来，每每想起往事，靠回忆中那身影**给自己带来一丝挣扎下去的勇气**。
- 她自认对方「或许早已忘记了自己的存在，甚至连自己的名字都已经不记得」。

## 三、移星事件

### 场景
近百修士行至一颗灵气浓郁的修真星外停下。该星上凡人与修士**已搬迁一空**。带头者为**雷仙殿使者**——一名神色孤傲的中年男子，修为**窥涅中期**。

### 冲突
- 使者点名：「西子凤，你去以元神撼动此星轨迹。」
- **移星机制**：需先以元神撼动修真星运转轨迹；轨迹被改变撼动的刹那会有**反震之力**传出，对元神伤害极大。
- 西子凤陈情：之前**三颗修真星**都是她撼动轨迹，元神之伤尚未恢复。使者仅皱眉冷哼，她便咬唇转身而去。
- **私怨背景**：使者很早就认识她，曾是窥探其美貌者之一，曾向她提出要求被拒；越看她如今丑貌越不舒服。事后冷笑：「当初你若同意我的要求，何来今曰。」

### 受创经过（第1488章）
1. 运转修为，柔和之芒扩散，元神飘出一丝化作神识连向修真星，猛地一扯——星辰轰鸣、转动一顿。
2. 停顿刹那，无法形容的大力反震冲来，西子凤喷血，**神识从中间撕裂**，身子后退数十丈。
3. 元神再化神识，二次扯动——修真星剧烈震动，隐有改变轨迹之兆，但反震更为剧烈，**神识寸寸瓦解，元神重创倒卷回体内**，再度喷血，面色死灰，双眼黯淡。

### 结果
- 使者冷哼「没用的废物」，越过她亲自出手，大袖一甩神识直取修真星，低喝之下该星**脱离了无数年来转动的轨迹**。
- 使者双手虚抱如抓住星辰，喝令「移星」；近百修士放出**银色细丝**连向该星，结成巨大**银网**笼罩此星，同时发力拽动。

## 四、人情与旧部网络

- 一名老者路过西子凤身边时叹息，自储物袋取出**一瓶罗天珍贵丹药**递给她，轻声道：「西子道友，老夫当年也是他带出的雷仙界。」
- 西子凤接过药瓶，眼中露出感激，吞服加速疗伤。
- **要点**：这八百年来，当年西家的世交所给予的帮助，**反倒不如这些曾一同被王林带出雷仙界之人**。若非这些人，她的修道之路会更艰辛。
- 队中另有一些修士眼露不忍、暗叹，议论：「西子凤是一个罕见的坚毅女子」「修道本就是残酷之事，大战之后，比她更要凄惨之人，大有人在」。

## 五、叙事意义

- 从被救者视角侧写王林在雷仙界一役中的重量：**一个人的身影，成了另一个人八百年的支柱**。
- 铺陈罗天星域大战八百年后的众生凋敝，与雷仙殿基层势力的倨傲欺压。
- 埋线：西子凤与王林迄今**素未相识、单向铭记**，为日后可能的重逢留下极强张力。

## 六、时间锚点

- 章节：第1487章（末段）—第1488章「今朝朦胧泪」，第十卷《叱咤界内》。
- 世内时序：雷仙界崩溃/封仙一战 → 约八百年后 → 本章移星。
- 「近千年前」西家在罗天极为庞大。

## 场景与背景

地点为星空之中，雷仙殿一行近百修士正牵引一颗修真星「移星」。队伍由一名中年男子使者统领，修为最高、位于最前方。

## 冲突：使者苛待西子凤

- 西子凤已加入雷仙殿，身份与众人相同，但修为不够；她此前撼动多颗修真星，伤势未愈。
- 中年使者咄咄逼人，不许其调养，喝令「西子凤，还有你，速去移星」。
- 一名此前为西子凤送药的老者（修为仅窥涅初期）忍不住反驳，顶住使者的庞大威压，冷笑指出：
  - 「你现在也应该知晓了西子道友当年钟情于他，他在之时，你可敢如此」
  - 使者辩称「他早已离去，甚至死了都有可能」，老者打断：「如果回来了呢」
- 使者沉默良久，冷哼甩袖，心绪不宁，那句话久久萦绕耳边。
- 西子凤始终沉默，放弃疗伤，分出神识化作银线牵动修真星，随众前行。

## 使者对王林的旧日记忆

- 封仙一战中，使者当时仅为**阳实**境界，对王林的气势只能仰视，不敢有半点不敬。
- **联盟星域一战**中王林彻底崛起，名震**罗天联盟两大星域**，声名赫赫；使者自认在其面前如同蝼蚁。

## 转折：王林现身

- 前方星空出现白衣身影，一头白发飘动，缓步而行，每一步跨越无尽星空；众人只见白影一花，山峰压顶般的窒息感骤起又消散，白影消失。
- 随即一声轻咦自星空传来，近百修士心神轰鸣、面色大变、齐齐后退。
- 白衣身影重新出现在众人身前，目光扫来。众人无法看清其样貌，如同直视太阳。
- 中年使者被这目光锁住咽喉与元神，全身停滞，元神深压体内不敢动弹，直接跪在星空，颤声唤「前前辈」。
- 该白衣身影正是**王林**。

## 重逢：王林与西子凤

- 王林本无意在意这群修士，一晃而过时感知到当年对自己产生爱慕之意的女子。
- 「若与当年一样，王林不会停留」——但他所见令其心中一痛：在他目光下众修士尽数消散，只剩那个低头躲藏、面色苍白、身子颤抖的女子。
- 西子凤虽低头，脸上一处处狰狞疤痕仍清晰可见。王林沉默。
- 西子凤咬唇：八百年中她本以为眼泪早已流干，此刻仍有两行清泪滑落，却因脸颊上沟壑般的深疤而改了方向。
- 她不愿以丑陋容颜、狼狈之态被那个人看到，只想躲到天涯海角、星空尽处，默默擦去早已遗忘感觉的泪。
- 王林轻声开口：「西子凤，我是王林。」他回忆起当年人群中那张带着微笑、慢慢老去、慢慢忧伤凝望自己的俏脸。
- **「王林」二字出口**，近百修士轰然剧震；最前方的中年修士瞬间褪尽血色，心脏似乎停跳，元神在这一句话下崩溃——「王林」是曾经在罗天名震八方的名字。
- 西子凤后退中颤声否认：「我不是西子凤，前辈认错了。」

## 要点

- 王林当前形象：白衣、白发，境界远超在场所有人（使者为在场修为最高者仍只能跪伏）。
- 王林之名在罗天星域仍具压倒性威慑，众人闻名即崩。
- 西子凤的状态：加入雷仙殿、修为偏低、身负旧伤、容颜被疤痕毁尽、历经约八百年、心态与当年已判若两人（自卑、回避、否认身份）。
