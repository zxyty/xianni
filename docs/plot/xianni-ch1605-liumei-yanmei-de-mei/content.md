# 第1605章 柳眉，眼眉的眉

## 一、双亲离世

- 王林父亲走后第二年，母亲在一次睡下中再未醒来，容颜似睡着，露出幸福微笑，仿佛梦中与丈夫重逢而不愿归来。
- 本章以大段抒情铺陈「母亲」与「父亲」的形象（哄睡的呢音、夜起摸被褥、鱼头鱼尾的谎言、缝补衣衫的针血；举高高、扶着学步、带看天地、严厉背后的爱、临终时在儿子怀中不再害怕）。
- 王林坐在父母墓前，流着泪，笑着哭着，未饮酒却如醉。
- 关键对照：他梦中「那另外的人生」来不及为父母送终、来不及抱父亲、来不及亲吻母亲含笑睡下的额头；**而这一生，他做到了**。
- 作者点出王林悲伤之重的根由：此世他无妻无子，没有依托，悲伤「足以遮盖天地」。

## 二、守墓三年与白头

- 守墓三年后，王林头发全白，身子不再挺拔而略弯，透出沧桑与岁月痕迹。
- 王林自语「三十八年了」，脸上已有皱纹，接近六十岁的老人。
- 大福更为苍老，拄拐棍立于其后，低头看自己右手腕，许久后轻轻点头（伏笔）。
- 王林追忆古庙旧事：「在那古庙里，我说我缺一个书童，你便跟了过来」；大福眼皮一翻咧嘴笑答「大福还可以做书童」。

## 三、离村求悟

- 王林交代大福「帮我守着家，等我回来」，抬头望天，看到那只白色的飞鸟。
- 自陈：**对天地的感悟还差一丝**，要用余生走遍朱雀星诸多国家，「或许我什么也没有得到，或许我顿悟了」。
- 第三十八年春天，王林独自离村，大福留守等待——或许十年、二十年、或许一辈子。

## 四、走出赵国边界

- 王林独自坐马车、饮酒，离恒岳山越来越远；数月后抵赵国边境，下车遣散车夫。
- 深吸气回望赵国，转身迈出一步，**此生第一次走出赵国国界**；「路在脚下」。
- 就在这一步的刹那，天空数道长虹（修士）呼啸掠过其上空，他没有抬头，平静前行。

## 五、柳眉重逢

- 长虹中一声轻咦：一名极美、天然妩媚的女子停在半空，低头望着王林，秀眉微皱，神色不解迷茫。
- 同行修士唤其「柳师妹」；她令众人先回宗派，坚定表示「师兄，我想独自一人」，众人诧异离去。
- 她化作紫衣女子落在王林身前十丈外。王林评其美貌「比之当年的周蕊更胜数筹不止」，但已看透——最终闭目葬土与寻常女子无异，故不曾恍惚。
- 女子欠身一拜：「老人家，几十年前我曾见过你一次，今日第二次相遇，你可还记得么。」
- 王林摇头沙哑答：「我忘了。」
- 女子追问姓名，王林答「老夫王林」；女子迟疑确认「可是赵国大儒，王林」，王林点头，目中沧桑深邃「仿若蕴含了天地」。
- 女子终究想不起那份熟悉与心痛的根源，且此次刺痛比当年剧烈无数，尤其对方苍老的样子更令她惆怅。她轻叹告辞。
- 王林轻声问芳名，女子回头一笑：**「柳眉，眼眉的眉。」**
- 柳眉在储物袋上一拍，取出一粒**可让人保持精力**的丹药相赠：「你年纪大了……你我相逢也算有缘」，随后踏云雾飘然而去。

## 六、末尾嘶喊

- 王林望着丹药暗忖：「到底是前生，还是轮回，亦或者是梦……柳眉，梦中的那一生，让我刺痛苏醒的女人」——心绪隐藏得极好。
- 直至柳眉身影远去，王林猛地抬头，用尽最大力气嘶哑喊出：
  > 「柳眉，你要切记，不管是什么时候，或许是下一世，或许是一次轮回，或许是一场梦中，不要再去认识一个叫做王林的修士！不要去认识他，不要去接触他！」
- 柳眉是否听到未知；王林喊至嗓子沙哑，直至远处长虹再无影子。

## 七、要点与伏笔

1. 本章为王林凡俗一世（朱雀星）的送终与转折点：亲情圆满 → 孤身求道。
2. 「梦中的那一生」与现世互为映照，前生/轮回/梦的界限被有意模糊，呼应仙逆「虚幻」母题。
3. 大福低头看右手腕并点头，为其身份/来历留白伏笔。
4. 柳眉对王林的「刺痛」为跨世因果的关键线索；王林选择主动割断，而非相认。
5. 王林求的是「对天地的感悟还差一丝」，游历诸国即为补足此悟。
