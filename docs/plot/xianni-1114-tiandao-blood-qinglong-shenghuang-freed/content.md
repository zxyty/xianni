# 第八卷 联盟隐秘 第1114章（二更）

## 一、雨界碎片崩塌与天运子夺宝

- **三分身自爆**：天运子三个分身自爆形成无法想象的冲击，大地震动达到巅峰，雨界碎片就此裂开，裂缝与空间裂缝大量出现。
- **趁乱入山**：冲击迫使王巍、胡娟后退、王林无法上前。天运子高呼「王林，老夫帮你救出这青龙圣皇」，化作长虹冲入三十五名碎涅修士的包围，钻入山峰之下。
- **锁山逆转**：山峰在金锁压力下不再下沉，反而再抬三丈，累计抬升近十丈。

## 二、青龙圣皇脱困

- 青光中挣扎而出的老者（青龙圣皇）脱离山峰底部，立刻下令「四圣宗所有族人，展开全部神通，毁掉此山」。
- 其身后幻化出数万丈、充满沧桑之感的巨大青龙，张口喷出青气轰击山峰；四圣宗长老齐施神通。
- 山峰颤抖、碎石大片脱落，金锁亦有不稳之象——但青龙圣皇面色反而越发难看。

## 三、天道之血被夺、雨之仙界终结

- 天运子从山峰中破缝而出，面露罕见激动，手中托着**拳头大小的一团黑色血液**；金锁化作金光追上，落在血团之上如封印一般，天运子毫不在意。
- 天运子右手下拍崩溃的大地，虚无中出现巨大漩涡，将碎片绞碎吸入——**并非仅此处雨界碎片崩溃，而是整个雨之仙界最终瓦解**，如当年雷界一般陆续崩裂。
- 天运子留言：「老夫要多谢你这一路所作所为，他曰有缘，你我定会再次相见，到了那时，老夫能成天道。」

## 四、青龙圣皇重创天运子

- 青龙圣皇掐诀放出青龙，并拍胸喷血化血箭融入龙体，血光环绕的青龙吞噬天运子。
- 结果：青龙消散，天运子身子抛出，**眉心封印被撕开两道**，嘴角流血，沙哑笑道「不愧是四圣宗最强圣皇，领教了」，随即远去。
- 青龙圣皇制止长老追击：此人隐藏极深修为，逼其爆发则今日死伤太多不值；且自己被困太久，此刻是强弩之末。

## 五、天道之血的来历（关键设定披露）

### 青龙圣皇口述
- 当年与**玄重子**等人于雨界刚崩溃后第一批到来，本为仙界传承仙术与法宝，却发现许多神秘之物——**仙界之所以被毁，正因这些东西的存在**。
- **锁山本是仙帝青霖的封印布置**，仙界浩劫中出现裂缝；他受玄重子蛊惑一同进入，遭遇意外被困其中无法外出。
- 封印使其呼救之声**唯有特殊之人才可听到**（呼应王林听闻求救）。
- 锁山之下发现那团血液，亦是青霖封印之物，研究多年不知来历。**天人第四衰**降临、必死之局下他吞了那血液，仅一口便昏迷，醒来第四衰已过；但封印内无天地之力，空有第四衰修为仍无法脱困，只能日渐虚弱。

### 王巍、胡娟（仙帝门人）补充
- 仙界浩劫前约**一百年**，雨之仙界降下**如血红雨**，内蕴奇异之力，师尊名之为**天道之血**。
- 师尊认为**天道也是一种生灵**；远古仙域尚在时便有传闻「**天道已死**」，即便未死也已重伤，降临雨界之物自然是天道血迹。
- 天道之血被师尊搜集炼化，最终只余拳头大小一团。师尊曾找人吞服，**所有吞噬者立刻化作血水而亡**，此后无人再敢吞（王巍说到此处怪异地看了青龙圣皇一眼）。
- 师尊猜测：雨仙界降天道之血，其余三界或降天道其余之物——把天道当作一个人，重伤后肉身四分五裂洒落、元神亦崩碎成无数碎片落下。**王巍本人不认同此观点**，称仅为师尊研究后的猜测。

### 王林的暗线感应
- 王林觉得那血液气息**与自己铁剑上的血锈相似**，并蕴含一丝**妖灵之地八星古神头颅内所获晶体之力**。

## 六、收尾：反算计与索还圣器

- 众人升空至**雨界大门**所在平台。青龙圣皇冷笑透露：那团天道之血**早被他当年吞了一半**，剩余部分之所以大小如旧，是因掺了他自身的血液——「我倒要看看，他如何以此修炼」。
- 青龙圣皇认定王林即**新朱雀**，称四圣宗血脉相连，故不言谢；并推断**今日只有王林前来，其余圣皇想必已然死去**，邀其回四圣宗介绍这些年变故。
- 王林不动声色退近王巍、胡娟，以「还有要事」推辞，与青龙圣皇对视片刻后获准。
- 青龙圣皇率四圣宗众长老（连朱雀圣宗长老也在内）踏入雨界大门离去，仅个别人回头看王林一眼。远处传来其毫无波动的声音：「新朱雀，记得回来时，把**朱雀太古圣器**送回。」

## 关键悬念

1. 天运子已得（掺有青龙圣皇之血的）天道之血，扬言将「成天道」——此为后续主线伏笔。
2. 王林铁剑血锈、八星古神头颅晶体与天道之血同源的暗示。
3. 王林与四圣宗、青龙圣皇之间的张力：新朱雀身份、其余圣皇之死、朱雀太古圣器的归还要求。
