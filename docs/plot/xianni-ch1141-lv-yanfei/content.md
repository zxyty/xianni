# 第九卷 云海之巅 · 第1141章 吕烟菲

## 一、场景：归元宗雨季清晨

- 地点：莫罗大陆·归元宗（南苑药院、宗内山脉之巅）。
- 时间：雨季清晨起，至午后雨停、天现彩虹。
- 王林撑油伞、一身白衣出药院，未施神通，纯以肉身踏山阶登顶，享受雨中天地之力。
- 孙芸留在药院打坐吐纳，试图突破**阴虚**达到**阳实**，未察觉王林离去。

## 二、王林的隐匿状态（本章设定要点）

- 来归元宗后**未隐藏修为**——以他的身份已不屑隐藏。
- 但**净涅修士**体内元力与天地融合为引，可从天地间取无尽元力；元力不动，则四周天地元力无变化，故不施展神通时无人看得出他是修士。
- 王林体内有**一丝本源**，且曾在**天逆珠**内看到第三步、在**仙帝青霜**造化下感受第三步，已非寻常净涅修士——**整个莫罗大陆无人能看破其修为**。
- 对外自称「**曾牛**」（王林自创化名，非冒用他人姓名），身份被认作北部带回的三十一名凡人之一。

## 三、山巅相遇：吕烟菲

### 人物首现
- 红衣女子，黑发散开、面孔略显苍白，娇艳中透出浓浓孤独、无助与楚楚之色。
- 归元宗地位极高的**大神通修士**，除已归墟的师尊外，宗内弟子见之无不紧张恭敬；三位师兄修为低她一阶，见面亦有恭敬。

### 交锋与转折
1. 吕烟菲冷声喝问来者何人，欲赶其下山峰。
2. 王林答「我叫曾牛」，神色如常、镇定异常。
3. 吕烟菲以目光如电反复探查，确认其**只是凡人**；正因其毫无修为、且平静具感染力，她反而愿向他倾诉。
4. 她开口挽留：「等一下，你可愿意，听我说说话」——她只想找一个能听她说话的人。

## 四、吕烟菲自述（背景信息）

- **十三岁**被师尊收为弟子，踏入修道。
- **问鼎**时，师尊不惜耗费宗派大量药材、远赴其他宗派换取，亲自为她炼成一粒**瞒天丹**，使她成功问鼎。
- 师尊曾带她在**星雾**内狩猎三年，帮她抓到一头**六目红狐**，成为其**本命灵兽**。
- 师尊已**归墟**，此后再见不到他老人家。

## 五、归元宗的困局

| 项 | 内容 |
|---|---|
| 仇怨 | 吕烟菲认定**紫道宗害了师尊** |
| 逼婚 | 师尊归墟后，**紫道宗少宗主卢海**送来玉简，要她与其**双修** |
| 威胁 | 若不从，紫道宗将趁归元宗实力大损之际**上禀主宗**，对归元宗开战 |
| 形势 | **主宗一向偏袒紫道宗**，若真请奏，八成会被应允 |
| 内部 | **三个师兄丝毫不敢出面**，默认此事，欲牺牲她一人换归元宗平安 |
| 她的判断 | 鼠目寸光——从了卢海，归元宗未必真能平安 |

- 雨停彩虹现，吕烟菲落泪：「风雨之后有彩虹，可是我归元宗的彩虹，却是一片黯淡。」
- 王林见其无意再说，转身下山；吕烟菲不再挽留，久望天边后**面露坚定、起了煞气**。
- 她回望王林离去方向：「此人心坚如我辈中人，若踏上道途，日后定有成就……可惜。」

## 六、王林的推演：云海星域的丹道

回到药院屋舍后，王林目露沉思：

- 由**赵玉的记忆**已知：**云海星域**与雨、雷两界截然不同。
- 结合归元宗长老言辞得出：云海星域**主修本命灵兽**，且**在炼丹上有独到之处**；漫漫星海尽是**星雾**，星雾内是属于灵兽的世界。
- 关键发现：竟有**可以帮助问鼎的丹药**——**瞒天丹**。
- 触动旧事：他自己问鼎时，若非**周佚的问鼎之晶**相助，早被**元火**烧成灰烬。「问鼎问鼎，闻道者，朝生夕死。」
- 推断：修道第一生死关卡竟可用丹药度过，可见云海星域炼丹之术**登峰造极**，恐怕连修道**第二步**也有丹药可助。
- 疑问与心动：修道者主重**意境明悟**，丹药本属旁门左道，云海星域为何独重丹道？——「莫非有可以帮助感悟意境的丹药不成？」王林庞然心动。

## 七、章末：孙芸吞丹被喝止

- 孙芸冲击**阳实**再次失败，睁眼喷血、面色苍白，且**伤了元神**。
- 她果断拍开储物袋，取出一枚蜡丸并捏碎，露出一颗**黑色丹药**——丹药一现，浓浓天地元力散出，隐含**奇异魂力**。
- 丹名：**入死离魂丹**。
- 孙芸咬牙欲吞，王林一声平静飘渺的「**定**」传入其耳——章节至此收束（悬念）。
