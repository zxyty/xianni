# 第七卷 名震罗天 第857章 第三步

## 一、古妖本体现世

- 清水冷漠出手，目光并不看血神子，而是盯着其身后延伸出的数十丈虚幻妖物；右目红光闪烁、殷红杀机涌现，右手黑色雾团膨胀至三丈直扑血神子。
- 血神子一指前方【古灯】。王林在古灯出现之刻便凝视观察：**灯芯处有一名女子虚影在挣扎**，随火光燃烧弥漫出无声的悲意。
- 古灯之火暴涨，火中冲出一头古妖虚影，样貌与血神子身外妖物几乎一致，但气息强大到「萤火与皓月」之别。
- **王林当场明悟：古灯上的古妖才是本体，血神子体内、姚云体内之物皆是其分身。**

## 二、妖焰噬神 vs 极境

- 血神子狂喝「妖焰噬神」，古灯火焰炸散，古妖本体冲出。
- 妖气瞬间笼罩**整个罗天南域**：无数修士元力不稳；修真星上的凶兽如兴奋般疯狂吸收妖力；星空下弥漫远古苏醒般的沧桑。
- 古妖之火为无数万年不灭之妖火，可燃烧天地一切；巨爪一抓蕴含「比规则还要霸道」的气息，规则在其面前消散。
- 清水抛出黑雾团，同时右目施展【极境】：一道极致红色闪电冲出，星空尘埃避退、生灵胆寒，四周浓郁妖气被极致寒气融入而瞬间崩溃。
- 古妖右爪硬接极境 → 爪碎，崩溃顺身蔓延，庞大躯体完全碎裂。

## 三、古妖重凝与「天道之力」

- 古灯火焰疯狂燃烧，再度凝聚出古妖虚影（略黯淡），**眉心红光内含一丝极境的力量**。
- 古妖沧桑之言：「这世间的一切原始神通，全部都是我古妖一族教化而出，唯有这蕴含了一丝天道的力量，非我古妖一族所拥有，不过，这力量现在，却是属于了我。」
- 古妖以眉心红光化闪电反击清水，几乎刚出现便在清水一目之下崩溃。
- 清水平静告知王林（时以「许木」之名行事）：**「师尊六大神通中，第四式，山崩」**——招式将出未出。
- 古妖后退抓起血神子并钻入其体：血神子青筋暴起、痛苦低吼，赤发无风自动暴长，天灵冲出两只虚幻之角，青光弥漫全身，双目只余妖光，形同古妖，咆哮扑向清水。

## 四、第三步修士降临（本章核心转折）

- 王林与清水同时抬头：一股【本源气息】自上方星空降临，气息不强，但王林感觉对方只需一个念头便可让自己全身瓦解、化作本源之力。王林面色大变：「这是第三步」
- 一声「够了」，一个**全身由无数星光组成的虚幻身影**一步现身于清水与血神子之间：
  - 随手向血神子一拍 → 血神子喷血，体内古妖被直接轰出体外。
  - 对古妖：「你借姚家恢复妖体，此事我不管，但若引起**罗天杀劫**、影响**进入联盟**之事，我便捏息你不灭妖火。」
  - 对清水：「清水仙君，**仙界已碎**，这里，是**罗天星域**。」这一眼无威力，却在清水四周激起连串雷鸣，天地如要屈服。
  - 清水冰冷对视良久，冷哼一声，未发一言（未再动手）。
- 虚幻之影相貌模糊，说完伸开双臂化作无数晶光弥漫四周：**崩溃的星空迅速收拢恢复如常，罗天南域因此战造成的一切毁灭全部逆转，凶兽体内吸收的妖气亦被无声化解。**
- 临去留话：「你们两个，若再出手，我便全部杀了」——杀机只露半点已可天地色变。

## 五、战后：清水指路升仙池

- 血神子沉默片刻，抓起古灯，看都不看清水，一步融入天地离去。
- 星空只余清水与王林。王林心神震动难平：确信那虚幻之影**定然是第三步修士**；那种灵魂深处的惊骇，如同千年前身为凡人初见修士。
- 王林抱拳道谢「多谢前辈出手相救，此恩铭记」。
- 清水追忆惆怅后平静答复（本章关键信息）：
  1. 「不必谢我。我不管你如何学得了**呼风**，既已学会，那便是**师尊隔代弟子**。」
  2. 「我清水在这罗天星域，没有任何牵挂，遇到你，许是师尊冥冥之中安排。」
  3. 「你体内尚未形成**仙元**，若无**升仙池**，凝聚不出仙元。」
  4. 「眼下**雷仙殿的一百零八仙、天罡三十六仙**可拥有进入升仙池的机会，你可去争取一下。」

## 六、要点与后续钩子

- **层级揭示**：第三步修士 > 清水（仙君）/ 古妖本体，可随手镇压并逆转一域战损。
- **古妖体系**：古妖一族教化世间一切原始神通；分身遍布（血神子、姚云体内）；本体寄于古灯；借姚家恢复妖体。
- **禁忌红线**：罗天杀劫、影响罗天星域「进入联盟」之事——第三步修士出手的唯一理由。
- **王林行动线**：欲凝仙元 → 需升仙池 → 需争取雷仙殿一百零八仙 / 天罡三十六仙之位。
- **未展开伏笔**：古灯灯芯中挣扎的女子虚影；清水师尊六大神通第四式「山崩」未真正施展。
