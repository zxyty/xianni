# 仙逆 第七卷 名震罗天 第880章 婉儿

## 一、升仙池：两条道路的抉择

升仙池青波涌动、仙气弥漫，一百一十名修士面临抉择，整个罗天星域的修士通过传音石凝神观望，鸦雀无声。炎雷子未加逼迫，只是平静旁观。

**两条路的设定对比（本章核心 lore）：**

| | 修仙之路（上古） | 修道之路（当世） |
|---|---|---|
| 核心 | 不修意境、不存感悟 | 一切离不开「悟」：感悟、顿悟、明悟 |
| 手段 | 入仙界进升仙池，元力化为仙元，自成真仙 | 悟天道，或顺从或反抗 |
| 提升 | 全凭天材地宝、仙气丹药 | 无感悟则寸步难进 |
| 由来 | 上古炼气士的终极追求 | 仙界崩溃后仙界已无，故转而修道 |

孰强孰弱，书中明言「不到最后，谁也说不清」。

## 二、许霆入池

- 清水希望王林入雷池化去意境，成为师尊**白凡**门下真正的弟子。
- **许霆**沉默后看王林一眼，咬牙走向升仙池。其心理：一生高傲，离开东临星后未遇敌手，却在雷仙殿封仙之战中于王林手下连连挫败，更在**一线天**内完全溃败身亡；对王林有一丝敬佩，但远不及不甘心，认定必须剑走偏锋、求一次质的飞跃，故毅然放弃意境选择成仙之路。
- 入池后剧痛如削肉剔骨抽髓，千年意境被迅速吸取；大量仙力与元力融合。半柱香后仰天咆哮，发丝无风自动，体内砰砰巨响，仙气爆发——**实力比之前生生高出一筹**，且对所学仙术有了完全操控、自由发挥之感。
- 出池时留话：**「许木，终有一曰，你我还需一战」**。

许霆的表现坚定了众人决心，陆续有人入池，出池者皆惊喜不悔。

## 三、王林的拒绝

最终十七人入池。未入者除王林外，还有**南宫寒、申公虎、战空烈**等十几人。

王林拒绝的理由：
1. 他已看到**第三步**，更在雷仙界内知道**仙帝白凡指天疯癫**——修仙充满谜团，绝非简单；
2. 这条路分不清正确与否，只是自己不愿选择；
3. **最重要**：升仙池出现的一刻，蒲团之上的那些老怪根本没有人去看一眼。

炎雷子挥手，升仙池轰隆隆飘向天空消失。

## 四、封仙石

- 炎雷子神情恭敬低喝「请封仙石」，天空祥云化作云龙盘旋，一条云龙张口吐出半丈山石；落地时雷仙殿大地轰响颤动，磅礴仙气带一丝暴虐蔓延。
- 石上密密麻麻刻满无数名字，每个名字都散发强大气息，其中不乏罗天星域赫赫之辈。
- **代价**：刻名者元神会被封仙石吸走一部分。许霆被青光震退，冷笑后仙元疯狂运转、眉心黑气缭绕分出一股融入指尖，才勉强刻下名字，随即虚脱后退数步、面色苍白——王林看出他**元神分出了一小半被吸收**，因此暗自警惕。
- 三十六天罡仙中，**除南宫寒、六指修士、大头童子外，无一人能刻下名字**。
- 炎雷子对许霆满意，暗道其在与联盟之战中定可大放异彩。

### 王林刻名（本章关键动作）

王林最后一人上前，沉吟良久（引全星域瞩目）。以食指刻下，反弹之力一次强过一次，直至砰砰巨响似要崩溃；最后一划之际元神开始向右指涌去，**王林蓦然抬手、借封仙石的大力向后退出数步**，元神未融入石中。

- 所刻之名既非「王林」也非「许木」，而是 **「魔道子」**。
- 炎雷子大有深意地看了一眼，评：「这许木不愧是来自联盟星域，行事毫不贪恋，而是以谨慎为主。」

## 五、最后奖励：一个要求

炎雷子宣布封仙最后一项奖励：**正副雷仙与三十六天罡共三十八人，每人可提出一个要求**，由**雷仙殿、向家、公孙家**三方尽所能帮其达成；**故意刁难者取消奖励**。

王林心神剧震、强行平复快速跳动的心，目露前所未有的精光——他来雷仙殿参与封仙，**就是为了这最后一个奖励**。

> **「婉儿」**

即王林所求指向**李慕婉**（已于第188章身死）。本章在此处收束，为后续复活/求索婉儿的主线埋下明确动机。
