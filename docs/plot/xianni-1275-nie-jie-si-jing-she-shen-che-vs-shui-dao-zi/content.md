# 第九卷 云海之巅 第1275章 涅劫四境

## 一、射神车来历（追述·闪回）

- **制造者**：雨仙界有「疯仙」之称的**多宝上人**。
- **造物执念**：他要造出天地间威力最大的法器——可杀死天地神灵、可毁灭一切规则、可破开天地。
- **代价**：一生所学、一生所修尽数投入射神车；走遍天下寻材，耗费心神使无尽寿元急速枯萎，末年已白发苍苍、生机将绝。即便无仙界大劫，射神车彻底完成后他也必死。
- **结局**：射神车尚未完全开启，他外出寻材时遭遇**仙界大劫**，带着滔天遗憾身亡。
- **传承路径**：遗憾留在**玉简**内 → 玉简最终落入**王林**之手 → 本章第一次在王林手中展现射杀天地神灵的恐怖威力。
- **认知盲区**：水道子虽存活无数万年、曾是封界之主的仆从、身为神宗大长老，仍不可能知晓四大仙界一切，更不知有一位道号「多宝」的仙人造出过足以威胁**第三步修士**的通天法宝。

## 二、战斗经过

### 第一击：万丈长矛

- 雷兽所化射神车射出**万丈长矛**，破开苍穹、分离五阶星域，直奔水道子，无呼啸之声、只有「飞出必杀人」的杀机。
- 白发童子（水道子）面色变化：「不是空涅之宝，甚至无法分出其品阶」——他本以为杀王林十拿九稳，唯一顾虑是**天逆**，从未料到对方有此等法宝。
- 水道子施**大自在切割道**：右手成爪，虚空被切割得四分五裂，化作锯齿蔓延撞上长矛；摩擦之声令王林七窍流血、喷血急退，声响传至六阶星域使无数修士喷血惊骇。
- 再施**大自在切割道刃「破灭一切规则」**：天地间裂开一道连接天地的锯齿状巨缝，所过之处一切物质一分为二，扫过长矛，将万丈长矛强行斩成两半。
- 附带结果：王林所在最后一处**蛮荒大陆**轰然崩溃化为碎末，王林多处喷血成为血人。

### 第二击：七彩之虹（第三辆射神车）

- 长矛崩溃中透出**七彩之虹**——即第三辆射神车，多宝上人一生所制最强法器，也是水道子真正在意、隐隐觉得可怕之物。
- 水道子**第一次后退三步**，挥出斩断长矛的天地巨缝迎击，裂缝却在相撞刹那无声收缩、化为虚无，如从未出现。
- 水道子面色大变，再退数步，喷出漆黑雾气，内现**九个巨大鬼头**（**九鬼雾气**神通，每个鬼头相当于一名**天人第三衰**修士全部之力，足以横扫任何星域，罕有抵抗者）。
- 九鬼欲吞七彩之芒，反被骤亮的七彩光芒逼退惨叫，两个鬼头躲避不及被撞得瓦解，化作磅礴天地之力消散。

### 王林的全力攻势（被无视）

王林面色苍白而杀机爆闪，同时施展：

- **三叉戟**出手，身形暴增化作数百丈**巨大古神**前冲。
- **呼风之术**：化数条黑龙，吹出寂灭之风，形成一把把黑色长枪。
- **唤雨之术**：漫天晶光化作一把把冰剑。
- **撒豆成兵之术**：**封仙印**自口中飞出，其内无数战魂在**虚空子**与**天运子之魂**带领下扑向水道子。
- **山崩之术**：脚下一座座虚幻火山幻化，爆发毁天灭地之威。

水道子对此**根本不在意**，全部心神只放在七彩之虹上。

### 第三阶段：定神术与夺宝

- 水道子连续闭目再睁，目光如实质轰出，一击崩一道光彩；数次之后七彩只剩**红黄蓝三道**，距其不足十丈。
- 危急关头，水道子轻吐**「定神术」**三字：定天、定地、定规则、定运转、定一切神通、定生灵万物。王林所有神通与身形尽数停顿，全身元力凝聚无法运转半点。三道长虹亦如疾驰野马被拉住缰绳，止于其身前三丈外。
- 水道子评语：「好强的法宝……可惜其上显然还有一道封印没有解开，否则的话，即便是老夫**空涅初期**，也要在其下受伤，更逼得老夫施展了定神术，**吕子浩**，你能做到这点，当为天骄了。」
- 若非他掌握了**不属于这一界的神术**，今日尚未杀死吕子浩就要先行受伤——身为第三步大能被蝼蚁反击致伤，是耻辱。
- 「这等法宝，你无权使用，当归老夫所有」——水道子大袖一甩，**眉心现出漩涡如大口**，冲出吞噬了红黄蓝三道长虹，夺走射神车。

## 三、关键设定披露：涅劫四境

> 「空涅、空灵、空玄、空劫，第三步中**涅劫四境**，唯有到了**空灵期**的大能，方有把握能在这法宝全部封印开启下毫发无损。」

- 第三步境界序列：**空涅 → 空灵 → 空玄 → 空劫**。
- 水道子当前为**空涅初期**。
- 射神车全封印开启后的威力标尺：需空灵期方能毫发无损。

## 四、章末悬念

双方修为差距如跨越不去的万古沟壑，王林怔怔望着法宝被夺，眼中不甘的火焰燃烧：

> 「我不甘心，我还有**三道杀招**，即便是死，也要让此人付出难以磨灭的代价。」

## 五、归属说明

- 本章水道子口中的「**吕子浩**」即**王林**的化名（自第1063章起，由吕烟菲奉上归元宗故人身份），相关言行一律归属王林。
- 「白发童子」为水道子在本章的外貌称呼。
- 天运子已于第514章身亡，本章出现的是其战魂（封仙印内**天运子之魂**），非本人行动。
