# 仙逆 第七卷 名震罗天 第669章 孙泰

## 一、无人敢买的八品丹药

- **拍卖品**：二楼拍卖大厅中，一名身穿红色长袍的中年男子手持**墨玉盒**，开盒露出**婴儿拳头大小的蜡丸**，无任何药气散出，外表极为寻常，实为**八品丹药**。
- **无人喊价的三重原因**：
  1. 八品丹药对在场修士是罕见重宝，但**修为不足吞下即成毒药**；
  2. **怀璧其罪**——无保护能力者买下，只怕走出此城便面临大祸，「此物不是灵丹，而是人头」；
  3. **来路诡异**——冉家有问鼎老祖，为何不自用反而拍卖？众人猜疑不敢出价。有年轻修士欲报价，被身边长辈严厉阻止。
- **冉家的布局**：红袍男子毫无不耐，因为**本次拍卖令牌是冉家仔细思索后发放**，断定来者不会出价；若真有人不开眼，「冉家不介意干那杀人夺宝之事」。男子目光时而扫向四楼——他并非本城宝合楼之人，而是**从冉家本族而来，目的是把丹药卖给一个特定之人**（即王林）。

## 二、「一枚仙玉」——王林的反击

- 男子高声宣告：若无人出价，此八品丹药将存放宝合楼内。
- **王林目光久久停在蜡丸上，眼中寒芒，平淡开口：「一枚仙玉」**（底价为一万仙玉）。内心独白：*你既然想卖给我，我便买就是*。
- 全场哗然，评价集中于：此人疯了 / 分明是给宝合楼难堪 / 四楼者绝非等闲但已得罪冉家。
- **红袍男子的两难**：接受，等于向所有人昭示这桩买卖大有端倪，冲击冉家名誉，更等于宣告「**冉家怕了**」；不接受，则违背老祖「此丹必须卖出去」的死命令。犹豫后咬牙：「既然只有一人出价，便卖一枚仙玉」
- **成交**：王林嘴角冷笑，右手虚空一抓摄来蜡丸，扔出一枚仙玉，向四楼孙析抱拳，转身踏步离去，出门即瞬移到宝合楼外。
- **王林的判断**：「**一枚丹药，便想让我入局，不够**」——明确识破冉家以八品丹药为饵拉他入局，且认为筹码不足。

## 四、心神烙印与孙泰相认

- **老者的困惑**：「这不是他的声音，但为何我心神中却是颤动？老夫这一生，**除了那个曾牛外，再无任何心神烙印**。」他起身又坐下，怔怔发呆：「**我的烙印，在东临星时便已经被破除了才对，为何还会有？**」
- 老者咬牙追出，在偏僻处现身于王林身后，仔细看后露出疑惑，抱拳道：「道友，老夫认错人了，莫要见怪。」转身欲走，背影充满沧桑。
- **王林缓缓道出两个字：「孙泰」**——老者身子蓦然一震，猛地转头直勾勾望着王林，失声：「你真的是你」
- **两点悬疑**：
  1. 王林神识一扫后皱眉：「**当日巨魔族老祖的神通，怎么可能把你送至这罗天星域？**」孙泰苦涩摇头，称此事他自己也疑惑了**数百年**，以他的了解，**巨魔族的神通没有那么强**。
  2. 王林问：「**你身上的烙印，很淡，这是为何？**」孙泰沉默后反问：「你可知晓，这**罗天星域内，有一个东临星**？」
- **王林当即打断**，未让孙泰在露天处继续说下去，大袖一甩卷着孙泰消失，挪移进入**城北房府**中自己的住处，盘膝而坐后才道：「你现在，可以说了」——本章至此中断。

## 五、关键线索与伏笔

1. **曾牛** = 王林早年自创化名，是孙泰一生唯一的心神烙印来源；王林如今声音已变（「这不是他的声音」），却仍引动烙印。
2. **东临星**：位于罗天星域内，与孙泰烙印被破除一事直接相关，是解释「孙泰为何跨星域至此」的关键。
3. **巨魔族老祖神通**：数百年前送走孙泰的手段，其威能超出巨魔族应有水平，来历存疑。
4. **冉家的局**：八品丹药只是投饵，王林明确表态「不够」，冉家后续必有加码。
5. 孙析称王林为「许兄」，说明王林此时在罗天星域对孙家使用的是「许」姓身份。
