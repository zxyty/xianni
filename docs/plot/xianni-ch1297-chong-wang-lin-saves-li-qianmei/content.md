# 《仙逆》第九卷 云海之巅 第1297章 冲！！！

## 场景
- 地点：一处**紫色裂缝天地**——天地皆紫、紫意滔天，无形冰冷气息如暗流卷动风云，充满不可琢磨的异变。
- 环境：凶兽无边无际，另有**数只身子约万丈的巨大凶兽**在更远处窥伺；王林身边有上万蚊兽随行。

## 事件经过

### 1. 感应与冲杀
- 李倩梅护身蓝光被巨大鞭子虚影抽击，蓝光短暂崩溃，数头凶兽扑向她。
- 王林感应到远处神通波动中**熟悉的气息=李倩梅**，毫不犹豫疯狂疾驰前往。
- 王林掐诀凝聚天地元力，凶兽崩溃化作血雾；上万蚊兽环绕形成**巨大的杀戮漩涡**，所过之处再无活兽。
- 王林双眼通红狂吼「死死死死」，速度达到巅峰，硬生生杀出一条血路；鲜血弥漫，紫色天地被染成暗红。

### 2. 照亮与目睹
- 王林右手掐诀凝出刺目金光冲上高空崩溃，**化作强光笼罩方圆万里**，照亮漆黑天地。
- 他看到数千丈外：白衣女子李倩梅面色苍白，怔怔望着他，露出温柔的笑容；其护身蓝光被鞭影击破，鞭子直取其身，落下必死。

### 3. 出手救人
- 王林抬手一指大喝「**定**」——规则化作无数丝线缠住鞭影，仅令其略缓，**无法定住**（该鞭蕴含奇异力量，连规则都难阻）。
- 借这一瞬，王林一步迈出、脚下波纹回荡，**缩地成寸**融入虚无。
- 鞭影距李倩梅身体七寸时，王林自虚无踏出，凭空一手抓住鞭影，挡在李倩梅身前「就好似一座大山」。
- 大力传来如数千万马车撞击，王林喷血但**未退半步**；眉心**古神星点**幻化旋转，古神之力弥漫全身汇入右手，身外幻化古神虚影，一声低吼「**给我断**」，鞭子瞬息崩溃。
- 崩溃反冲横扫而至，王林仍立于原地硬抗，眼露滔天寒光，宣告：「不管你是谁，我不会允许你剥夺这女子的生命。」

### 4. 无力回天
- 李倩梅在此前已**元神崩溃、生机灭绝、油尽灯枯**，仅凭一道说不清的意志支撑；见王林无碍苏醒便已满足。
- 她手中的**金色笔**在鞭影临身前崩溃化作金芒散开。
- 她轻声道「谢谢你」，睫毛颤抖，闭目如沉睡。
- 王林掐诀连点数下，以元力封印其体内将灭的生机，仍挡不住死气弥漫、元神衰弱、魂魄涣散、身体失去光泽。

### 5. 岁月神通续命
- 王林右手一按，施展「**岁月**」神通：巨大石门耸立天地，沧桑感弥漫，化作岁月流淌笼罩李倩梅。
- 效果：其飞速灭绝的生机**大幅减缓**。
- 代价/限制：**神通不能停止**，一旦停止李倩梅生机将在极短时间消散——此后天地间纵有同名的李倩梅，也不再是她；王林须持续消耗元力维持。

### 6. 旧伤与解封
- 王林由此忆起**一千多年前李慕婉**在自己怀中老去、慢慢死亡，只剩躯体与沉睡的魂魄，如今仍在**避天棺**内残存、至今未醒。
- 心声回响：「如果有一天，我不在了，你是否会记得，有一个叫做李倩梅的女子，在你的人生中匆匆走过。」
- 王林闭目，右手按眉心，眉心浮现复杂的**封印禁制**；左手一抓向下狠狠一撕，**打开了当年在七彩界被他封印的全部修为**——以这两千年来最强的姿态现身裂缝天地。

## 结尾悬念
- 虚无中两道巨大鞭子虚影再度抽向王林，远处凶兽群与万丈巨兽同时逼近。
- 王林抱着李倩梅：「倩梅，我带你冲出去。」
