# 第八卷 联盟隐秘 第1094章 认错

## 一、场景与在场者
- 地点：朱雀圣宗大殿（四圣宗之一，朱雀星域一方）。
- 在场：新圣皇（铠甲之人，实为**王林**）、其身侧四名碎涅老者、罗天雷仙殿**烈云子**、出云国**墨智**、**尸阴宗妖艳女子**。

## 二、试探与逼问
1. 烈云子察觉新圣皇语气不善，四名碎涅老者目光锁定自己，心生不安。
2. 新圣皇笑声牵动大殿天地火元力急速环绕，其中弧形电光游走，砰砰作响。
3. 新圣皇追问：索要王林，**是你之意，还是雷仙殿之意**？
   - 烈云子答：王林虽为罗天正品雷仙，但**已被革除雷仙资格**；此番既是老夫之意，**也是雷仙殿的意思**。
4. 再问过节。烈云子答：与罗天雷仙殿过节牵及众多，与他自己则是「**王林拿走我战家重宝**，老夫自然要追回」。
5. 烈云子抬出「罗天与四圣宗有共同敌人——修真联盟」求成全。

## 三、身份揭露（本章转折）
- 新圣皇突然道：「你说那王林拿走了你战家重宝，此事，我怎么不知道」
- 随即起身，右手一扫面部铠甲，铠甲化作波纹弥漫，露出真容：**新圣皇即王林**。
- 烈云子倒吸凉气、连退数步，惊呼「不可能，你怎么会是朱雀圣皇」——在他眼中，当年的王林不过是可随手捏死的蝼蚁。
- 四老之一踏前一步，碎涅气息化无形冲击直奔烈云子，烈云子喷血再退，被迫接受现实。

## 四、定性与人证
- 王林反问：你是代表罗天来恭贺王某成为圣皇，还是专程羞辱王某？在朱雀圣宗内索要本圣皇，太过荒唐。
- 王林类比施压：此举**不亚于王某派人去罗天索要雷仙殿炎雷子**；今日走不出朱雀圣宗，明日罗天也要付出代价。
- 人证：
  - **墨智**（出云国）：作证是烈云子无理在先，其话语可代表出云国。
  - **尸阴宗妖艳女子**：亦愿作证，讥其「荒唐至极」。
- 王林重新落座，佯装观察右手指纹，全然不理会烈云子。

## 五、双方心理
- **墨智**：感慨师尊口中的「故交」竟是王林；回忆当年**朱雀星雨夜古庙**初遇——那时王林**刚获得意境、处于化神**，一夜论道令他铭记。
- **烈云子**：
  - 自知修为无法逃出四圣宗；
  - 王林「太过恶毒」，把私事抬成**整个罗天雷仙殿侮辱朱雀圣宗圣皇**，与罗天初衷南辕北辙；
  - 若无墨智与尸阴宗女子在场，他本可拼死一战、由罗天复仇；如今有人证，罗天不愿因此同时与四圣宗、修真联盟开战；
  - 屈辱回忆：当年王林须对其恭敬、随召即来为其**查看战字图**，**若非清水**，王林早已成为他的傀儡。

## 六、结果：认错与交贴
1. 烈云子被迫抱拳：「此事老夫鲁莽，但此为私事，与我罗天无关」「并无侮辱之意」，最终吐出「**战某错了**」。
2. 王林开价：「**我要你战家全部战字帖给我，此事罢休**」，以火元力凝聚出一支实质燃香，限**半柱香**考虑。
3. 燃香将尽，烈云子点头屈服，右手虚空一抓开出裂缝，飞出**三个画轴**，浓浓战意笼罩四周。

## 七、要点归属提示
- 本章新圣皇/铠甲之人的全部言行归属【王林】。
- 「战字帖／战字图」为战家（烈云子）之重宝相关物，本章成为勒索标的。
