# 仙逆 第八卷 联盟隐秘 第1047章 反抗

## 一、局势起点：虚空子必杀之击

- 虚空子出手击杀王林，但王林**没有肉身崩溃，也没有立刻死亡**。
- 关键因素一：**突然出现的青光小盾**，几乎抵消了虚空子七成之力。
- 关键因素二：剩余三成本足以杀死王林，却只令其**喷血重伤**——虚空子为之吃惊。
- 体内波纹之力横冲直撞直奔元神；王林元神虽有**古神皮甲**守护，仍在震动下**黯淡**。
- 王林身受重伤（即便是古神肉身），但**双眼始终平静**，紧盯虚空子。

## 二、落点玄机：两尊雕像双目的中心

- 王林被抛出后，落在**大殿内两个雕像怒视双目的中心**。
- 虚空子隐约察觉王林所在位置**有些不对劲**，抬手虚空一拍补上必杀一击，化作**黄色沙尘之暴**卷向王林，并身形一晃亲自掠去。

## 三、王林的主动谋划（内心逻辑）

1. **预判杀机**：葬仙池外即感虚空子对己不善；联系**朱雀觉醒**之事，已有**八成确定**对方有杀机。
2. **自知不敌**：以自身修为反抗徒劳。
3. **借力就位**：干脆借对方一击之力，把身体抛向**已隐约找到的第二层入口**。
4. **临阵布局**：短暂时间内构架了一个**杀局**，目标正是虚空子。
5. **行事准则**：「人不犯我，我不犯人」——对方不出手则杀局不开；一旦出手绝不束手待毙。
6. **底线目标**：「即便在这杀局杀不了你，也要给你留下一个深坑的记忆」。

## 四、开启通道：雕像印诀与紫光漩涡

- 王林双手掐诀，**印诀与两尊雕像的印诀一模一样**。
- 印记掐出瞬间，雕像**怒视的双目紫光闪烁**，两道紫光冲出环绕王林，形成**漩涡**，王林身体直奔漩涡下沉。
- 危险点：按漩涡速度，王林尚未彻底融入，沙尘之暴便会先行击中，崩溃而亡。

## 五、转折核心：眉心第三目与本源之力

- 王林**开启眉心第三目**——其神通中最强的一个，轻易绝不舍得使用；此刻生死危机中毫不犹豫开启。
- 第三目内射出**一道红光，成扇形弥漫前方**（初为三丈，随后暴增数倍）。
- 红芒内蕴含**本源之力**：与沙尘之暴相撞，**无声无息**间令这拥有**碎涅神通**的沙尘之暴一震而消散、崩溃化作元力。
- 代价：王林眉心刺痛，**本源之力本就不多，飞快流逝**；但他不但不收回，反而心神一动令第三目之力更疯狂透出。

## 六、诱敌成功

- 王林算准：对**欲寻找第三步道路者**而言本源何等重要，不信虚空子不上当。
- 红芒扩张数倍，本源之力直奔虚空子。虚空子**本可避开**，但不甘放弃「数万载难遇」的亲身感受本源之机，**犹豫**了。
- 这一犹豫：红芒瞬间笼罩，本源之力弥漫其身体四周，虚空子身体**仿若被层层掀去，呈半透明感**。
- 虚空子自认可琢磨透彻本源，且原本只为「铲除日后祸端」，竟撞上传说中成为**第三步修士**的本源——激动异常。

## 七、章末：杀局启动

- 王林身体随紫色漩涡旋转渐渐沉入，眼中杀机骤增：**杀局已完全布置，虚空子已入局**。
- 一拍**储物袋**，取出一把**剑鞘**，鞘内插着一把**铁剑**；王林眼露寒光，右手握上剑柄。
- （悬念：出手在即，未叙结果。）

## 关键看点

- 王林由「被动挨打」转为「主动引诱」，本章标题「反抗」即指此。
- 本源之力首次在虚空子等大能面前暴露，成为诱饵，也埋下巨大隐患（更多势力窥觑）。
- 雕像印诀 = 第二层入口钥匙，构成杀局的地利。
