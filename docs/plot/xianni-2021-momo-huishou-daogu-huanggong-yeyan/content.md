# 第2021章 暮然回首！

## 一、登场：第九声鼓鸣中的白发白衣

- 王林白衣飘逸、白发不动，神色如常，独自踏空而入道古皇宫夜宴广场，习惯了万众目光凝聚。
- 全场低议：此人是谁？为何敢在第九声鼓鸣时出现？是否有特殊身份？
- 他走过数千案几，走过**一百零八禁、七十二圣、三十六杖**，径直走向最前方。
- 最前方案几布局：**一个在前、三个在后**——为大天尊与国师所设，另两个位置留给道古至今尚存的两位老祖。

## 二、七王起拜与不灭将被慑

- 飞过十八王上空时，十八位道古王爷神色凝重，其中**七人起身抱拳一拜**，引发的议论超过此前十八王与九个不灭将出场之时。王林略停脚步，扫过七人，微笑点头。
- 走入九尊黑气缭绕的道古不灭将上空：八人沉默，唯有那位**堪比仙族闯过十四层的跃天尊之人**冷哼欲起身阻拦。
- 王林冷眼一望，目中**红芒杀机**一闪，惊人威压瞬散即收。
  - 该不灭将全身一震、无法起身，恐惧跌坐；心神轰鸣、冷汗瞬出。
  - 其感受：如置身疯狂杀戮场，被王林连杀数千次；如目光轰入体内绞碎五脏、生刮骨血、取魂嚼碎。
- 王林落座于扇形案几**最前方**——即道古大天尊之位，全场再掀滔天大浪。

## 三、身份被认出

- 众议：坐在大天尊之位者何人？其散出的威压令人心脏似停顿，**吉族之力深不可测**。
- 认出者多为古族三脉皇族（如计都皇子一类）：此人即**玄罗大天尊新收的弟子**、**白发跃天尊王林**，更有传闻称其为**仙罡大陆第十阳**。
- 背景：玄罗曾带王林走过**始古**与**极吉**两族之地，故各族来贺者除送礼外亦借机观察道古实力；对王林目光复杂、隐含忌惮。
- **计都皇子**在天空平台激动狂热地注视，握拳暗道：「义父之名，古族皆知；义父之威，更是震慑人心，若义父能助我……」并等待王林**逆出道古**的一天。

## 四、心魔骤发：关乎一生的预感

- 王林闭目而坐，内心却心肝气躁、如心魔滋生，几近失控。
- 来源：**入道古皇宫后**由此前的**心悸**转化而来；数日前已隐现，今日尤烈；坐下刹那轰然爆发。
- 影响：若非如此，那不灭将的起身根本不配让他散开威压、外露修为波动；他甚至生出杀尽此地所有人的疯狂念头。
- 排查：怀疑道古皇宫布有阵法禁制影响自己，但四周并无禁制迹象。
- 判断：此感似预示**关乎其一生的大事**，强过历次生死危机 → 定计「**此道古皇宫，不能久留**」。

## 五、皇尊临与当众封赏

- 第九声鼓鸣消散，全场骤静；正殿内尖锐之声喝「皇尊临」，殿门隆隆推开。
- **道古皇尊**着皇袍戴帝冠、坐巨大龙椅，不怒自威。
- 拜礼规矩：道古族人**单膝跪地**，非道古族人可不跪；王林起身一拜，**未跪**。
- 皇尊举杯敬道古族人与友族，万人共饮；王林只略触酒杯并未喝，正欲开口告辞。
- 皇尊当众宣布：**玄罗大天尊弟子、仙族白发跃天尊王林，从此为道古一脉守护者**，令其上前听封。
- 冲突点：王林走出几步、殿外抱拳一拜，皇尊沉声喝「还不跪」，随后平静注视；全场察觉异常，目光尽聚。计都皇子压着激动，正是等待此刻。
- 王林答：「王某代师尊送上贺礼，还有要事，就此离开。」此时他心烦气躁、面色隐白，看皇尊竟生出说不出的杀机与反感。
- 大袖一甩，将**玄罗所赠锦盒**抛出，由皇尊身前虚影接住呈上。
- 皇尊转口：封王林为道古一脉**皇子守护者**，准其离去，并望其**明日大典**再来；深看一眼后不再看他。内心不喜阴沉，神色却含笑。

## 六、结尾转折：铃声与凤袍女子

- 皇尊悠悠开口：「有请皇后。」
- 王林转身欲化长虹离去，忽闻**一阵铃铛声**，心中烦躁于这一刹那**消失无影**。
- 王林一愣，**暮然回首**——见一名**穿着凤袍的女子**自殿中走来，走向道古皇尊。

## 七、要点与伏笔

1. 王林在道古的地位被公开抬到「大天尊之位／皇子守护者」，但他拒跪，与皇尊之间已现裂痕。
2. 计都皇子视王林为「义父」，明确期待其**逆出道古**——为后续政变埋线。
3. 数日前起的心悸→今日皇宫内的疯狂杀意，与「凤袍女子出场时烦躁尽消」形成强关联，暗示此女与王林宿缘（心魔之源与解）。
4. 王林原定「不可久留、明日大典或不来」，因回首一望而被打断。
