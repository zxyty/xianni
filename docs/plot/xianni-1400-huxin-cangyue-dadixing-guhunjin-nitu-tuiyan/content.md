# 第1400章 湖心藏月（第九卷 云海之巅）

## 一、古魂禁现世：四大禁与六道本源

- 巨龟虚影彻底消散后，王林确认：**大帝星内存在「古魂禁」**，且大帝竟以古魂禁去布置一个赛场禁制。
- 王林已得三禁：**破灭禁、生死禁、岁月禁**（尚未有充足时间推衍）。若再学到古魂禁，则**四大禁制彻底完整**。
- 四禁融合之下，凭莫大机缘，他有可能**感悟出禁制本源**——本源将由**五道**变为**六道本源**。
  - 五道本源已极为惊人；六道本源足以令一切修士震撼，连第三步大能也会骇然。
  - 代价：六道本源若想全部大成，难度**倍增无数**。

## 二、对神秘大帝的忌惮

- 能用古魂禁布置赛场禁制 → 大帝底蕴深不可测，王林忌惮更深。
- 疑点：大帝**提前让王林独自进入**大帝星，是否早已算准他必被此禁制吸引？分析越深，狂喜越淡。
- 大帝星三处诡异：**无罡风层、植被奇异、存在古魂禁**。

## 三、泥土推演：造星之秘

### 取样与转移
1. 落于大帝星**西北区域**（植被稀少、地面灰土），抓起一把泥土细看，神色转沉。
2. 远处大帝使者携修士随后而至，王林抬头一望即一步迈开，转至**大帝星东部**无尽植被中的一片巨叶上盘坐。

### 记忆依据（天逆之忆）
- 当年**天逆**某次开启，王林半只脚踏入其内，化身混沌于虚无中飘荡，**最终成为一颗修真星**。
- 由此亲历得知修真星与泥土的生成链：修真星诞生之初**无泥土** → 火山爆发喷出地心之物弥漫全星 → 岁月风化成颗粒 → 形成泥土 → 泥土中诞生原始植被 → 在一次次死亡与诞生中泥土生出生机，与修真星生机融为一体。
- 推论：**泥土的寿元参差不齐，且少于修真星本身寿元**。

### 施术与结论
- 王林轻喝「**流月**」，岁月之感笼罩泥土，追溯其诞生之日；因年代太久，以其修为**无法完整追溯**，只能感受端倪。
- 换取植被下方泥土再施流月，得出明悟：**此地泥土同时诞生、寿元一模一样**。
- 两种解释：
  1. 修真星诞生不久后全星火山同时爆发、同时毁灭 —— 但**使泥土有生机的原始植被不可能同时出现、同时死亡**，故说不通；
  2. **此地一切皆为人为**：悠久之前被人以大神通之术开辟而成。
- 王林自身已是大神通修士，尚不敢相信「单独从星空内制造一颗修真星」所需的修为。
- 文本评断：**王林是至今第一个从泥土中分析出修真星起源之人**；若大帝知晓，其震撼将超过王林造星本身。
- 作者旁白：修士之差距除修为外还有**对「道」（道理、因果）的理解**，二者相符则可怕难信。

## 四、心境与谋略

- 王林躺在巨叶上望灰蒙天空思索——正因喜好思索，他才能在一生危机中走到今日。
- 对**长尊会**的**云落大司**与**司墨子**：口头张狂，内心极谨慎。
- 立场：不知大帝图谋，但不妨碍**借大帝之势化为自己的力量**；「懂得借势之人，才可以在错综复杂的他乡中找出自己想要的结果与目的」。

## 五、树叶异状

- 右手摩挲叶面时，体内**一丝极微弱元力不受控制地自右手钻出，被叶子吸入**。
- 仔细查看却毫无发现，仿佛错觉；但王林心惊肉跳。
- 应对：**不再踏足大叶**，化作长虹在大帝星上空缓飞，神识谨慎散开密切观察。

## 六、湖心藏月：白衣老者

- 黄昏时分，见到被无数植被环绕的**湖泊**，湖边有一**白衣老者**持鱼竿垂钓，身旁放一**酒壶**。
- 这是王林在大帝星上除大帝使者与过往长虹外，遇到的**第一个人**。
- 王林落下坐于老者身后，老者不予理会；随后王林盘膝坐于一旁，二人隔酒壶相对无言。
- 湖水清澈**无鱼**；天色全暗，明月升空，轻风拂动植被沙沙作响，湖面涟漪似把明月摘下藏于湖心，分不清月在天幕还是埋在湖中。
- 此景之下，王林那颗来到**太古星辰**后疲惫的心也似放松下来。
- 章末：老者沙哑开口——「**你，喝酒么**」。
