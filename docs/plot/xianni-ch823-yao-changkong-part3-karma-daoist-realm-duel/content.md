# 仙逆 第823章 姚长空（段3/3）：因果道境破荣耀道境

## 一、战况承接
- 蝴蝶每次扇动翅膀，姚长东体外符文便大量崩溃，但其身形仍高速逼近王林。
- 姚长东内心独白：必须杀掉「许木」——对方仅阳实修为已如此厉害，若达窥涅，自己绝非对手。
- 王林盘膝坐于塔山左手之上，塔山不断后退拉开距离，但对方速度太快，瞬息迫近。

## 二、王林施展意境之道
- 王林杀机消散、闭目轻语：「我之道，先生死轮回，后入因果，世间之事，可逃轮回，惟独因果，逃不掉。」
- 设定要点：意境不需元力施展，非神通、非法宝，而是修道者一生所修之道、一种信念与感悟；千年修道所悟即王林的意境。此为其久未使用之法。
- 意境之战＝道法之战，道法千变万化，无胜负，只有生死。
- 施展形态：摊开双手，「左手掌世间之因，右手握天地之果」；睁目时左目有日、右目含月；抬左手一指——「因，出」。
- 效果：意境临身，星空与四周一切消失；姚长东被迫止步。其眼中王林身影无限高大，双手间浮现首尾相连成圈的虚幻之鞭，即为因果。若再踏出一步，纵能杀王林，自身也将永沉道幻因果之中无法苏醒。
- 关键设定：道境之战只能以道境对抗；能把自身之道完整施展者极少，与修为无关，取决于对天地、人生与自身之道的感悟。

## 三、姚长东的「荣耀道境」
- 姚长东未退，反而在不足三丈处盘膝闭目，头顶散出金光虚影——仙风道骨、仙气弥漫的仙人。
- 其自陈：姚家传承至仙界，是仙人后代；仙人不修意境，但后人以「先祖之荣耀」为意境，昔日先祖荣耀即姚族道境。
- 虚影随其狂热崇敬渐渐凝实，脱离其身，一步迈向王林因果之圈。

## 四、王林的破道之论（道念交锋）
1. 「这世间万物皆为因果，这因便是仙人的荣耀」——右手抬起、轻轻一握——「这果，便是仙界崩溃」；追问：你荣耀之人可还存活，你之道可能逃出因果？
2. 因果之圈旋转成漩涡：漩涡外为因，漩涡内为果，飞向仙人虚影，临近时停下。
3. 核心论证：仙人不修意境，凭仙力强开天地之力，是大错——否则仙界何以崩溃；以仙帝之强不修道境，仍要指天疯癫而亡。仙帝不修道是「因」，疯癫而亡是「果」。姚家先祖身份、修为、神通皆不如仙帝，不修道而强驱天地之力，在天道之下灭亡即是因果。
4. 诛心之语：人已被天所灭，何来荣耀；姚长东从未真正见过、感受过先祖荣耀，凭空所想，荣耀即空；修至窥涅初期，道念上却无半点自身感悟，全是虚幻所生。断言姚家一族必然灭亡。
5. 王林自陈道念来历：经历人生剧变、亲人离别之痛、嗜血杀戮之恨、爱人身亡之苦、亡子消怨之惆，明悟生死轮回、知晓世间之事，「虽说归去须归，但却要逆天而行，不受命运操控」，成就生死轮回大道；更因意境变化，感悟出因果之境。
6. 收尾：「你姚家杀我，是为因，而你道念被我因果所破，就是果」——一声大喝，仙人虚影彻底崩溃。

## 五、结果与代价
- 姚长东两度喷血、心神重创，面无血色、双目黯淡迷茫；虚影崩溃后四周恢复星空，落在其眼中「好似万年时光一晃而过」。
- 王林因果道念随之消散，眉心的**半片纸符**在道念之战中崩溃；他运转元力一跃而出。
- 蝴蝶轻扇一下翅膀 → 姚长东身子崩溃化作血肉，连储物袋也在这**破坏规则的力量**下崩溃，在世间半点痕迹不存。
- 王林面色苍白喷出一口鲜血，自陈道念之战太过凶险，非万不得已不愿使用。

## 六、王林的复盘评述
- 荣耀道念并非如他所说那般脆弱，只是姚长东**道心不稳**、未经人生百态，如温室花朵经不起真正风雨。
- 星域对比：**联盟星域**同等程度修士远强于**罗天星域**家族修士——联盟星域内一切靠自己，师门保护不了自己，稍有不慎便身亡，弱肉强食、杀戮是天定法则；罗天星域家族修士大多无法想象那种黑暗，若被放到联盟星域很难生存，除非修为高到不屑一切规则。

## 七、离场与两处伏笔
- 王林收起法宝，塔山化作虚影融入其身后；拖着虚弱身躯，双目杀机更浓：「姚家，要杀我王林，你们要付出代价。」一踏之下波纹撒开，融入天地消失无影。
- **伏笔一（追踪者）**：其消失瞬间，旁边星空波纹中走出一名白衣冰冷女子，相貌绝佳、一脸冰冷，秀眉微皱，一步之间融入虚无，向王林遁走方向追去。
- **伏笔二（血神子）**：罗天东域一处血红色星球上有姚家巨大祠堂，旁边十丈高巨木刻着带凌厉杀气的「姚」字。祠堂内盘坐赤色弯眉老者，身后灵牌各自散出浓郁元力；最下方一块灵牌咔的一声一分为二。老者自称「血神子」，喃喃：「终于死了一个……来自联盟星域的王林，老夫想要看看，你到底能杀几个，可不要让老夫血神子失望。」抬右手一指，将碎裂灵牌内飘出的白气卷入袖中，道：「继续杀吧。」

## 八、归属提示
- 依据世界状态须知：本章「许木」为王林自创化名（非冒用他人姓名），其言行一律归属【王林】。
- 塔山虽在既有须知中标为第753章死亡，但本片段其以法宝/虚影形态被王林驱使并融入身后，属于王林所掌之物的形态，非人物新行动。
