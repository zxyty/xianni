# 第七卷 名震罗天 第672章 因果循环，寻生寻死

## 一、冉云星：三修士纳贡投靠

### 条件与抉择
- 王林（此时以「许木」之名行事）向冉家老祖、孙析、逍遥散人三人抛出庇护条件，语气不容选择：同意则庇护，不同意则不趟这浑水。
- **冉家老祖**沉吟后果断答应——幻家威胁太大，若无人出头，一旦被查出，冉家将面临**灭族之危**。
- 答应后，冉家老祖与孙析同时把目光转向此前在玄冰内修炼的中年男子**逍遥散人**。冉家老祖寒声道：「赵兄，当日之事，是我三人同时做出，你莫非想独善其身不成」——点明四年前之事为三人共同所为。
- 逍遥散人沉默后苦笑同意，取出存放仙玉的储物袋，分出一些扔给王林，自称「赵某家族不大，仙玉没有那么多，这储物袋内的仙玉，还是赵某辛苦攒下」。

### 交付之物
1. **仙玉**：三人各自交出。仙玉为珍贵消耗品，修士往往随身携带。
2. **四年前死去的幻家族人遗物**：三人毫不犹豫全部取出交给王林。这些东西在他们手中存放四年，「并非是宝，而是杀劫」，压在心底令其心神不宁。

### 王林离去
- 收物后王林转身踏步即消失原地，只留一句：「无事，莫要打扰，若幻家来人，我自会出手。」

### 三人各怀心思
- **孙析**：心中另有念头，此刻最为轻松，微笑抱拳称有要事先行告退。
- **逍遥散人**：叹气称要回家族一趟，为日后「许道友再次提出仙玉的要求」做准备。
- 二人一北一南化虹而去。
- **冉家老祖**独立原地良久，喃喃：「罢了，破财免灾……四年前之事被这许木抗下，若他不死，我们便不会有事，而且此人看起来也不像是违反诺言之人，但也要堤防此人暗自离开冉云星。」

## 二、千幻星：幻家追查失踪族人

### 祖宅问责
- 地点：**千幻星南部，幻家祖宅**。
- 人物：家主**幻封神**恭敬立于一名面容消瘦的老者身前；该老者正是带着柳眉自**联盟星域**归来之人（幻家老祖）。
- 老祖冷声质问：「四年前便失踪，为何此刻才处理」。
- 幻封神解释：失踪者本是幻家一个**分支族人**，只因天资较好、修为达**问鼎中期**才获得外职；幻家族人太多，除嫡系外即便失踪也不可能一一细查。

### 三个月之期
- 老祖追问「没有再比此人修为还高的了么」。
- 幻封神称老祖要求时间太紧，**若再给三个月**便可找到更具资格之人，目前无法。
- 老祖沉吟后果断应允：**再给三个月**。

### 处置令
- 老祖裁决：「既然知晓了此事，派分配给**幻眉**的族卫去处理吧，所有涉事之人，**连根拔起**……幻家之威，是要立的」。
- 幻封神告退后眼中阴沉，内心暗道：「老祖真的老了，居然为了一个外人不惜施展**换血**，而且还要让这幻眉立威，莫非是准备日后把幻家，交给此人不成」——透露两条关键信息：老祖为柳眉施展了「换血」；幻封神疑心老祖有意让柳眉日后接掌幻家。

## 三、三天后：柳眉遣幻东赴冉云星

- 柳眉在其阁楼内望天，平淡道：「冉云星……既然义父把此事交给了我，让我派族卫处理，那么，幻东，你去吧」——确认幻家老祖为其**义父**。
- 身后虚无中化出一人**幻东**：看似三十许岁，相貌堂堂，现身后单膝在地，望向柳眉背影的目光「充满了狂热」。
- 柳眉交代：「你修为达到了**问鼎中期的巅峰**，此去一行，应该不会出现意外，此事虽小，但却是我在幻家第一次做事，你，要速断速决」。
- 幻东回应：「那冉云星，修为最高者也就只是冉家老祖，此人与我一样，都是**问鼎中期**，给此人一百个胆子，他也不敢反抗」——同时点明冉家老祖与柳眉修为同阶。
- 柳眉展颜一笑，幻东眼中狂热更浓，甚至带着浓郁痴迷。

## 四、因果结构与伏笔

- **因果循环**：四年前三人合杀幻家族人 → 幻家追查 → 三人纳贡求庇于「许木」 → 王林承诺幻家来人时出手；幻家同时派幻东赴冉云星「连根拔起」，双线即将正面相撞。
- **未爆之雷**：幻东此行只当是小事（问鼎中期巅峰对问鼎中期），却不知冉云星背后已有王林。
- **柳眉线**：老祖为其换血、令其立威、以「义父」相称，家主幻封神对此心怀不满，埋下幻家内部权位之争。
- **时间锚**：幻家老祖另给幻封神三个月，去找一名修为更高、更「具资格」之人（用途本章未明言，与「换血」相关）。

# 第632章（承接第631章后）剧情梳理

## 一、归返孙家小城·意境之问

- 王林挪移回到**孙家小城**，未直接回**房府**，而是在街道上步行，借人间烟火思索意境。
- **生死轮回意境已与元神融合唯一**：他的元神本身，便是那生死轮回的感悟。
- 王林的推演链条：
  - 「生死之上，可是因果」——但**因果之道太大**，无法确定。
  - 之前**问鼎**时明悟**心道**，化作**黄泉**；但黄泉道只是**生死中「死」的表现**（死于黄泉）。
  - 悬而未决的问题：**「生之道」却是在哪？**
- 望着四周熙熙攘攘之人，王林眉头微皱——凡俗众生正是他参悟「生」的参照。

## 二、北城重逢·「你可以达到化神」

王林踏入**北城**，见到盘膝在山石下的**青年**（心底善良的修士，此前曾指点王林修炼）。

| 项 | 内容 |
|---|---|
| 青年反应 | 惊喜：「你不是被人抓走了么」 |
| 王林答复 | 「问了我一些事情，便让我离开了」——语焉不详，青年未追问（各有各的秘密） |
| 青年劝勉 | 看王林修为与当初来时毫无变化，重申上次所言，强调「**勤能补拙**」 |
| 王林回赠 | 「努力修炼，争取可以早日达到**化神**」 |
| 青年的化神观 | 苦涩摇头：家族长辈说过，**化神与勤奋无关**；没有对**天道的领悟**，再勤奋也无法成为**半神**的存在，无法真正摸索**道的边缘** |
| 青年的自期 | 「此生能达到**元婴后期大圆满**，就已经很知足了」 |
| 王林的断言 | 「**保持现在的心态，化神，你可以达到**」（阳光落在身后，笑容沾染阳光） |

青年只当是安慰，笑称若真有化神之日，定会想起王林今日的**未卜先知**；王林离去后，青年独自低语：「真的能化神么」

> 叙事要点：此段与王林所参的「**生之道**」互为呼应——善良、心态、生机，正是他在死道之外要找的另一半。

## 三、清点幻家族人遗物

回到房府，王林盘膝而坐。体内**仙力充足**，但明确一条修炼律则：

> **意境不提升，即便吞下再多仙气，也是无用。**

随后取出**冉家老祖三人**交出的**幻家族人遗物**，全部装在一个**储物袋**内。

### 遗物清单

1. 一些衣衫以及琐碎之物
2. **八品丹药**
3. **一枚玉简**
4. **一块令牌**
5. **两样法宝**（重点）

### 两样法宝的共同异状

- 其上**均无任何神识烙印**；
- 还残存着当年**幻家族人死亡时留下的一丝怨念**；
- 推断：得到它们的**冉家老祖**与**逍遥散人**，**不敢**在其上留下自己的神识。

### 法宝一：黑色梳子

- 梳齿共**十九**根；
- 散发**血腥味**，出现即感其上**凶焰**；
- 其上**更有法阵**；
- 定性：**攻击类的伪仙宝**，「这法宝的威力，不凡」。

### 法宝二：一对紫金火石（本章最大发现）

- 金属性，**通体紫金**，飘在手心即传出**阵阵刺手之芒**；
- 王林捏住一块相互略一摩擦，立刻**繁星点点般火星**涌现，**热浪扑面**；
- 王林倒吸口气，判定：**天然形成的法宝**。

## 四、设定披露：天然形成的法宝 / 火石

- 一切法宝**绝大部分为修士炼成**，但也有一些**天然形成**；
- 这一类**数量太少，甚至比传承法宝都要少**；
- 王林是在**古神涂司的记忆**中才知晓有此一类；
- **在古神眼中**，此物算不上法宝，而是**炼器的材料**；
- **火石**即天然形成的炼器材料之一：
  - 本是**金属性**之物；
  - **硬度极强**，且其内**蕴含一些奇异的神通**；
  - 相互摩擦时便可**引出火星**；
  - 此火星非凡人生火所用，而是一种**金火**，与当年**妖灵之地天妖郡总管**所施展的**阳火**有异曲同工之妙；
  - **不以此物炼器、而当作法宝使用，威力一样不凡**。

## 五、待解与伏笔

- **生之道**尚未明悟——王林意境突破的下一道关口。
- 火石的**金火**用途（炼器 or 直接作战）未定，且与天妖郡阳火的关联留有线索。
- 玉简与令牌的内容本章未展开。
- 北城青年能否化神，被王林当面「未卜先知」，构成后续照应。
