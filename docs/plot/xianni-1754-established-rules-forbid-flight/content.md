# 仙逆 第1754章 既定规则

## 一、大鼎前的血丝禁制
- 四大战将、当年七道宗弟子及几名仙妃陆续踏入此地，神色复杂。
- 一名来自**界外远古仙域**的仙人（七道宗老者）身形前晃，未触发禁制变化，缓缓接近**大鼎**。
- 其余人看向下方**废墟**：数人目光一凝止步；另有数人未察觉而踏入废墟上空，瞬间被一道道**红色血丝**爆发红芒笼罩，凄厉惨叫中急速后退。血丝密密麻麻结成屏障，几乎阻隔视线。
- 侥幸过关的老者心有余悸，当即转身踏入大鼎。
- 暗处的**掌尊**目睹这一幕，双目一闪，嘴角冷笑。

## 二、洞府核心：第一花三百露水 = 三百残界
- 大鼎内昏暗天地中，是那朵挂着**三百滴露水**的巨大花朵。
- **蓝梦**三人先前已进入，此时已消失不见。
- 七道宗老者谨慎观察后，择一滴露水融入。
- 设定要点：三百露水内即三百**残界**，容纳了所有进入此地者；王林在自己所在的残界**守株待兔**。

## 三、王林的「既定规则」：禁止飞行
- 老者融入露水刹那，山峰顶盘膝的王林抬头望天：「来了，这是第一个……拿他实验一下此地我既定的规则好了。」
- 规则实验结果（王林自述）：
  - 尝试了很多规则，**只有「禁止飞行」能完全凝聚出来**；
  - **无法影响法宝**；
  - 对**肉身的影响时长随修为而变**；
  - **无法定下「禁止仙人血脉」的规则**，推测三百残界皆做不到——「毕竟它们是残界而已」。
- 规则的战术用途：一旦来者是**七彩道人**或**战老鬼**，禁飞可为他争取从容撤离的时间。王林本人早过时限，不受规则约束。

## 四、第一杀：七道宗老者
1. 老者自漩涡中凝聚现身，神识横扫却无法发现王林。
2. 迈步疾驰时**一脚落空**，失去一切飞行之力，体内修为爆发也无法阻止急速下坠；坠速在星空中激起类罡风之物，撞得其体内砰砰巨响。
3. 老者祭出**拂尘**垫于脚下托身。
4. 王林挥手放出**血剑**，血剑融入其神通、达到**缩地成寸**之境，数息即至，自老者**眉心**一闪而过——喷血、眉心爆出血雾、肉身崩溃、**元神亦被血剑粉碎**，就地死亡。
5. 王林双手掐诀，**第三魂**自体内飞出包融印诀，念咒：**「祭此血肉神魂，融己司之身」**。星域中死者旁浮现一只**缠绕黑气的漆黑手臂**，虚空一抓，将碎裂的血肉、元神与魂尽数摄走消失。
6. 血剑飞回幻化嗡鸣。王林沉吟：「禁制阵法我能感受到，只杀了三人而已，加上此人，还远远不够。」

## 五、五日等待与最后期限
- 王林闭目、神识弥漫星空等待下一个进入者。
- 自定期限：**七天内若无人进入，就要再换一界**。
- 五天中大部分时间沉浸**第三魂**里，试图多融合一些记忆；同时警惕七彩道人/战老鬼。

## 六、第二杀：七道宗三人，三息毙命
- 第六天晌午，**东方一处星域**出现漩涡，内现三个模糊虚影。王林一步融入虚空迫近，隐藏身形与血剑；判断非七彩道人/战老鬼后仍不急出手，等其清晰。
- 三人道袍与先前所杀老者一模一样，确认为**远古仙域七道宗之人**：
  - 一人**空涅初期**；
  - 两人约**第二步天人第五衰**，未迈入第三步。
- 出手时机：漩涡消散、三人刚看清四周、神识尚未散开的刹那。
  1. 血剑呼啸，一名第二步仙人**头颅与身体分离**；
  2. 另一人被同门鲜血喷面、欲后退，瞳孔中已是一袭白影，王林**一指点其眉心**，轰鸣中崩溃而亡；
  3. 空涅初期者退步、虚空一抓取出**一根燃香**（似为求援/示警之物），未及点燃便被禁飞规则拖着急速下坠；血剑自**胸口穿透**，王林大袖甩动、手印幻化**一掌拍下**，其身体轰然崩溃。
- **杀三人，用时不到三息。**

## 七、章末悬念
- 王林正要离去，忽觉身后杀机再起：万里之外星空又现漩涡，其内**一个隐隐似女性的模糊身影**。

## 要点提炼
- 本章确立了「残界可被强者设定既定规则」这一设定，及其明确边界（不及法宝、时效随修为、不能禁仙人血脉）。
- 王林的杀戮带有**目的性**：以血肉神魂饲第三魂/司之身，且明言击杀数「还远远不够」，指向后续禁制阵法的开启条件。
- 归属提示：据世界状态须知，王林自第1380章起亦以「烨寞（道古烨寞）」之名/身行事，本章以本名叙述。
