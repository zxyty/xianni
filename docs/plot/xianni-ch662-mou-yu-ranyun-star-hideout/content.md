# 第七卷 名震罗天 · 第662章 谋玉

## 场景
**罗天星域 → 冉云星**。王林现身的一瞬，三股强大神识立刻横扫而来。

## 一、三股神识与冉云星势力格局
- 王林现身刹那便身影消失、气息全无。
- 三道神识：
  - 其中两道彼此似有忌惮，未作交谈，各自扫过区域后收回。
  - 另一道蛮横强扫整个冉云星，无收获后冷哼一声消失；哼声传遍全星，也落入王林耳中。
- 王林在冉云星北部平原现身后判断：**一个问鼎中期，两个问鼎初期**。
- 王林的疑惑：冉云星灵力极为充足，却只有三方势力、每方仅一名问鼎修士。若此星在**修真联盟**境内，早被踏出第二步的老怪独占，或被**六级修真国**整体迁移占据，绝不会是这般局面。

## 二、隐匿与伪装
- 王林不断收敛气息，转眼间再无问鼎气息，外显仅**结丹后期**修为。
- 其本身修为为**问鼎初期**，加之元神诡异，除非修为高于他之人贴近查看，单凭神识不可能看破隐匿；但**踏出第二步的老怪**不在此例。
- 王林盘算：隐匿于此不会被发现，即便**天运子**等人追来，也想不到他会藏在这么一个修真星内。
- 目光精芒渐渐收敛变弱，眼中除黑白分明外再无夺目光彩；神态转为温和，好似春风吹过，再无冷峻。
- 从**储物袋**取出一柄寻常飞剑，化剑光远遁；飞行中相貌缓缓改变，熟人亦认不出。
  - 关键点：变貌并非王林自行施展的寻常变貌神通（此类神通在高阶修士眼中鸡肋，凝神一看便露端倪），而是**身影内的仙卫神通**所为，能看破者不多。

## 三、东临星的判断
从此前那四个小家伙的表情看来，**东临星**势力极强——在修为足够之前，不能去那里。

## 四、入孙家城池
- 前方城池通体由青色巨石环绕，威严扑面，城门书写「**孙家**」二字。
- 王林于城外数里收剑落地，拂去灰尘，从容步行入城。
- 因外显结丹后期修为，城门盘查并不严苛；被告知**城北**有专为外来修士准备的洞府。
- 缴纳灵石，换取暂时居住令牌，进入孙家操控的城池。
- 城内景象：凡人居多，修士常见；街道两旁商铺林立，售修士常用之物，亦有面向凡人的店铺。

## 五、城北洞府区
- 城北安静、灵气浓郁，无数独居之房交错，每处外皆有**禁制**防护。
- 入口处有禁制阻止凡人入内；旁有三丈多高山石，其上挂着七八个**黑色令牌**。
- 山石下盘膝坐着一名**元婴期青年**，双目紧闭吐纳，两道气龙自鼻孔散出。
- 王林视入口禁制极为简单，甚至无需破解、直接踏入亦不会引发反应。
- 青年睁眼相询：只余**八间空余房府**。
- 报价：**上房一年一千块下品灵石，下房一百块**。

## 要点归纳
1. 王林进入罗天星域后的第一步是「藏」——降修为表象至结丹后期、改貌、改气质，落脚一个不起眼的修真星。
2. 冉云星的势力真空（只有三个问鼎）被王林视为反常，也正是其可藏身的理由。
3. 仙卫神通是其伪装难被识破的技术底牌。
4. 东临星被明确标记为「暂时不可去」的强势力目标。
5. 章节结束于租房议价，尚未落定选哪间。

# 王林租住孙家房舍，炼制三宝以谋仙玉

## 一、租下洞府

- 王林拿出**一百块灵石**交给守在山石下吐纳的孙家青年。青年眼露轻蔑，甩袖收灵石，虚空抓来一块**令牌**扔给王林，只道“**西首第五，去吧**”，随即闭目继续吐纳。
- 令牌上有**两道禁制**，其中一道用于通过入口。
- 青年背后自语：“又是一个外来修士，想必是准备借我孙家的灵力来结婴……此人资质寻常，能达到结丹，恐怕也是丹药所致。” 王林听到，只回头看了一眼便继续前行——外界对其修为的判断与实情（问鼎修为）严重不符。

## 二、房舍与禁制

- 屋舍素雅：一张床、一个打坐铺垫，偏房内有**丹炉**，另有**半封闭的闭关室**，其内灵气缭绕。
- 王林在房外右手一挥，于房间**固有禁制**上略作完善，使其威力**增添十倍不止**。
- 盘膝吐纳，感慨“倒是很久没有吐纳灵气了”，但断定**此地灵气再浓也无法提高其修为**（问鼎境已非灵气可养）。

## 三、资源盘点：仙玉与仙液

| 资源 | 现状 | 判断 |
| --- | --- | --- |
| 仙玉 | 问鼎之时几乎全部耗尽，所剩极少 | 无法满足日常吐纳，**获取仙玉为首重之事** |
| 仙液 | 仅剩**五滴**；此前服升仙果时已吞四滴 | 药力沉淀后（再多几年）将无法维持仙力生生不息 |

- 关于仙液的效用推演：**一滴仙液可以问鼎**；但问鼎之后所需仙力多出无数倍，再吞已无旧日之效。故结论是——**吞之浪费**，最佳用途是**疗伤**或**短时间内使体内仙力生生不息**。

## 四、青色珠子：罗天星域的阵法造诣

- 天色渐暗，王林挥手点燃烛台。屋顶镶嵌一枚**拳头大小的青色珠子**，吸收烛火烟丝，半柱香后珠内大亮，青光柔和落下，**反使四周烛台熄灭**，成为屋内唯一光源。
- 王林解析：珠内**蕴含三个阵法**，构成“**收烟化热、由热凝光**”的小法术。
- 第三个阵法散出**淡淡檀香**，闻之心旷神愉；此香**无毒**，可**加快修士吐纳速度**，属并不常见的**炼丹材料**。
- 评语：“这罗天星域，在这方面，比**修真联盟**要强很多。”

## 五、被否决的方案：抢夺

王林曾升起抢夺仙玉的念头，随即抹去，理由有三：

1. 出手抢夺**是为下乘**；
2. 所需仙玉数量巨大，**非寻常修士可以拥有**，目标只能是**问鼎修为者**或**罗天星域的家族势力**；
3. 一旦动手，事后必须**离开冉云星另寻去处**，不妥。

## 六、决断：炼器三件

王林一拍储物袋，取出炼器材料，**吐出一口元神之气**包裹，材料顷刻融化，按神识所念化作**三个模具**：

- **一把飞剑**
- **一面铜镜**
- **一根钗子**

随后双手掐诀，将一道道**禁制**融入其中；三宝散发威压，且因经**元神炼化**，其内**蕴含一丝电光，时而游走**。

### 意境与印诀的封入

| 法宝 | 封入内容 | 来源 |
| --- | --- | --- |
| 铜镜 | **岁月意境** | 回想当年在**朱雀星**遇到的那位「意境为岁月」的修士，凭自身**道念**模仿，已具几分神似 |
| 钗子 | **千幻无情道**（幻化之像） | 冥想当年**柳眉**的千幻无情道，种种幻象化作亮光自双目爆出 |
| 飞剑 | 未印任何意境，改打入**挪移印诀** | 王林自行打出 |

## 七、要点

- 王林此刻已是**问鼎修为**并**拥有自身道念**，故能模仿他人意境。
- 三件法宝显系为**换取仙玉**而作的准备（前文推断的“获取仙玉为首重之事”与此决断相接）。
- 外人（孙家青年）只当他是结丹修士，身份被严重低估。
