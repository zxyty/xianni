# 第2082章 惊变

## 一、大战前的集结
- **仙族**：各宗组成的无数修士大军，经仙族大地上罕见启用的传送阵，一批批传送至**苍茫盆地**。
- **古族**：由三位**皇尊**带领的无数古族军兵，同样以传送方式赶来。
- **开战与否的关键**：看此番进入太古神境的双方，哪一方能再出**大天尊**，甚至哪一方的大天尊能在境内**再次攀升**。
  - 若平衡得以保持则罢；一旦打破——且仙族已猜出**古道大天尊无法走出古族太远**——大战在所难免。
  - 唯一例外：古族退避不战，不踏出范围半步。

## 二、太古神境之谜
- 无人知晓太古神境自何时出现，其存在似**比仙罡大陆更久远**。
- 即便是当年从虚无中诞生的**仙祖**与**古祖**，对太古神境的了解也非全部。

## 三、王林的等待与自问
- 王林盘膝坐在海墙风暴一侧，注视风暴内由**通天柱子形成的门**——门紧闭，已快到打开之时。
- 他等这一天已**数千年**，不差这数月。
- 心中疑问：「若是我没有在那始古祖庙内，开始那疯狂的计划，不知这太古神境开启后又是一个什么模样。」——此问无解。

## 四、古族三位大天尊来临（开启前一月）
来者：**宋天**、**玄罗**、神秘的**极古大天尊**。

- 宋天神色复杂、恭敬抱拳：「宋天，参见王尊。」极古大天尊同样恭敬抱拳。
- **三百年前**，二人目睹虚幻而出的一幕后，又亲往**古道山**向古道大天尊求证，确认仙罡大陆第一强者已非古道大天尊，而是**王林**。
- 玄罗较当年苍老不少，面带微笑，为昔日弟子如此强大而喜悦，正要随宋天同拜。
- **王林抢先起身向玄罗一拜**：「王林，参见师尊。」
  - 若只有宋天与极古大天尊来，他不会如此；唯玄罗到来令他毫不迟疑。
  - 二人当年在**道古皇宫**已斩断师徒之情，且以强者为尊之理，王林受玄罗一拜亦属应当——但王林做不到忘恩负义。
- 宋天与极古大天尊心神一震：他们见惯师徒反目、弟子成强者后不再尊师，唯王林之真诚清晰可感。
- **余波**：此后数日，本与玄罗地位平等的宋天与极古大天尊，对玄罗多了一丝尊敬。能让仙罡大陆最强者、击败古道大天尊的王林称一声师尊，仅此一点足以改变一切。

## 五、海墙风暴异变（开启前十五天）
- 海墙轰鸣瞬息**暴增数倍**，震耳欲聋，足可震死凡人；低阶修士轻则心神创伤肉身欲碎，重则爆体而亡。
- **古往今来低阶修士不敢闯太古神境的原因**，正与此轰鸣密切相关：随时间推移轰鸣越来越烈，最后之日震惊天地，修为低于**第三步**者来临必死，法宝守护毫无作用；最终可横扫一切**空劫以下**修士，生生限制此地来临人数。
- 海墙内**九色光芒**刺目而出，弥漫天空、大地与四周，透出如刀般凌厉之气，在轰鸣中化作漩涡横扫。
- 王林看出：**九根柱子组成的大门已有松动**，轰鸣暴增正因门松动而生，仿佛门内有一股力量咆哮着要冲出。

### 玄罗的判断：提前了一周
- 「我记得上一次太古神境开启，是在距离开启之日一周时才出现如此强烈的轰鸣，可眼下却提前了一周。」
- 推论：此次轰鸣**持续更长**，且极可能**再剧烈数倍不止**。
- 忧虑：甚至连古族**二十七星完全具备且虚化融合**的族人也无法来临。
  - 王林久居古族，明白此层次可与仙族的**金尊**相比。
- 惯例：以往开启，双方会派遣大量**空劫**修士入内碰运气求造化；但重点在**金尊、天尊**，最重之点是罕见的**跃天尊**层次。

## 六、双方人马齐至与再度惊变
- 王林感知后方古族大地有**数百古族族人**疾驰而来，预计三日后全部抵达。
- 第二天、第三天，轰鸣接连暴增，天地似有不稳，宋天与极古大天尊面色阴沉、露出焦急。
- **第三天中午（距开启十二天）**，王林平静开口：「仙族的大天尊，来了。」
  - 海墙另一侧三道长虹：**久帝、武封、道一**。
  - **双子大天尊**未来，思索良久放弃太古神境，选择留守仙族大地；已成**仙皇**的**连道非**同样留守。
  - 三人立刻察觉轰鸣与往昔不同，神色顿时阴沉，与玄罗等人判断一致。
- 见礼：道一毫不迟疑「道一参见王尊」；武封神色如常抱拳一拜（三百年时间已让他接受现实）；久帝犹豫、暗叹后抱拳，未发一言。
- 王林点头，向武封微微一笑：「好久不见了。」武封内心略暖：「有几百年了，没想到王尊修为竟到了如此程度。」
- 玄罗三人后方大量长虹呼啸而至——古族此番挑选的入境者；久帝等人身后凭空出现巨大传送阵，走出数百身影，其中多人王林曾在**天尊涅之地**见过。
- **惊变**：众人临近的一瞬，诸多气息似令此地空间不稳，海墙轰鸣再次暴增，天地颤抖似随时可崩，四周浮现一道道若隐若现的**空间裂缝**。六位大天尊神色齐齐一变。
