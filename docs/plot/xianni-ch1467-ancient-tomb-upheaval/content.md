# 第1467章 古墓剧变

## 一、古墓内外同震
- 古墓内裂缝被撕开的瞬间，古墓地图内所有雾气沸腾翻滚，向四面八方云涌轰鸣。
- 内部变化引起外界震动：太古星辰中，原本已消失的**古之墓地裂缝**再次闪烁而出。
- 裂缝再现刹那，此前收拢后仍弥漫在外的无尽雾气与古墓内雾气同步云涌、相互碰撞轰鸣，随即被一股大力吸撤——裂缝化作一张吸气的大口，滚滚雾气呼啸倒卷而入，刹那消失大半，余者仍在急速被吸入。

## 二、关键变化：修为限制消失
- 剧变后最重大的规则变动：**进入古墓不再有进入者的修为限制**。
- 这一变化被大荒上人、妙音道尊各自独立察觉，直接引来数尊大能入局。

## 三、大荒上人抢先入墓
- 位置：距古之墓地不远的一处**干枯死亡的修真星**上盘膝闭关。
- 状态：分魂崩溃，本尊面色略显苍白，目透无情之色。
- 性情披露：一生修道为己、**极爱毁誓**；所有知晓其这一爱好的人均已死亡，故未传开。与二代朱雀虽有交情，但交情比之利益不值一提；正因刻薄寡恩，修道数万年而无知交。
- 行动：冷哼身晃、一步迈入星空，转瞬现身于正吸雾的裂缝外；悬于雾中如不动之山，盯视半晌后目露果断，确认「居然没有了进入者修为的限制」，不假思索踏入裂缝，成为**第一个进入者**。

## 四、妙音道尊出紫海
- 所在：远在一处无尽星辰之地，似虚幻之中的一片**紫色海洋（紫海）**，海底深处盘膝而坐。
- 动机（两条恨意）：
  1. **大荒上人敢抢我分身**；
  2. **「王持」（按世界状态须知即王林）坏我好事**。
- 手段：右手一挥，海浪轰鸣凝成一扇由海浪组成的大门，起身迈入，身影骤去，现身古墓裂缝外。
- 背景：已有几万年没有离开紫海。

## 五、九天魔尊现身与结盟
- 出场方式：妙音道尊身前星空扭曲成九份，浮现一幕幕虚幻天地，自九处天地中迈出一人。
- 形貌：沧桑中年男子，面色略黑，双目如电。
- 互称：九天魔尊称对方「几万年没有离开紫海的妙音老道」；妙音道尊沙哑作答「你九天老魔能来，本尊自然也可以」。
- **陷阱之疑**：妙音道尊指出「大荒老毒已经进去了」，怀疑是陷阱；九天魔尊皱眉判断，能在古墓内布置陷阱之修「不会如此出手」，二人遂露坚定之色。
- **分赃协议**：
  - 妙音道尊：「大荒要封（杀）」；
  - 九天魔尊：「本尊帮你封老毒，所得之物本尊取六（成）」；
  - 妙音道尊：「可以，但那小家伙要给我」。
  - → 协议达成，二人化作两道长虹直奔已吞尽雾气、安静漂浮于星辰中的裂缝。

## 六、黑袍人拦阻
- 二人临近将踏入的刹那，太古星辰轰然一震，浩荡之威自四面八方疯狂凝聚，化作一个**大到似可遮盖整片星域的巨大掌印**虚影漂浮上空。
- 掌印之下黑气凭空交错，凝成一个全身被黑袍笼罩、看不清面目的模糊黑影。
- 黑袍人（声音沙哑、透出无尽沧桑）警告：「**大战将起，你二人不能出现意外，这古墓还是不要去**。」
- 此时裂缝并未收缩，而是始终漂浮，似在**等待修士的进入**。
- 妙音道尊追问「你确定会有意外」，黑袍人答「**尚未算出**」——本章至此悬置。

## 七、伏笔与看点
- 「那小家伙」身份未明，为妙音道尊指定的所得份额，疑指王林或与其相关者。
- 「大战将起」暗示更高层面的战事格局，古墓之争只是前哨。
- 大荒上人已入墓、二尊被拦在外，形成「内有猎物、外有围杀者、更外有阻拦者」的三层局面。

## 归属说明
- 依【世界状态须知】：文中「王持」应为王林（疑为文本讹字），其言行/被指涉归属【王林】。
- 【大荒上人】按须知已于第1375章记为死亡；本章其本尊活跃行动，属本尊仍在（此前为分魂崩溃/分身身死），故不另记新死亡，仅按本章文本记述其行动。

# 第1377章 古墓剧变（第九卷 云海之巅）

## 一、外界：诸强相继入墓

- **妙音道尊**留下「无妨，出不了意外，就算是有，你也定有办法救我等出来」之言后，转身一步踏入裂缝，身影消失。
- **九天魔尊**面露微笑，向**黑袍人**抱拳，笑称「你伤势看来已经恢复了大半，此番若真有意外，有劳了」，随后身子一晃踏入裂缝。
- 众人进入后，**古墓裂缝并未消散**，而是如永恒一般保持撕裂之状，漂浮在星辰之内。
- 模糊的黑袍人独立许久，轻叹并自语点明入墓阵容之重：
  - **太古五尊之二**——空玄之境**大荒**（注：大荒上人已于第1375章死亡，此处为黑袍人对入墓势力的清点/追述）
  - **周座**
  - **远古仙尊二人**
  - 这些人「占据了我太古星辰三成之力」，全部进入古墓，令黑袍人「还是不放心」。

## 二、古墓内：巨手毁台，裂缝洞开

- 两只巨手横扫拍击而过，**摧毁了首个出现的九阶墓台**，同时**撕开一道似通往另一个世界的裂缝**。
- **王林**面色苍白却毫无犹豫，在裂缝出现刹那向前一步直接踏入。
- 外界之人——包括九天魔尊与风情粉衣女子——在巨手之威下不敢前行半点，只能眼睁睁看着王林消失。
- 王林入内瞬间，两只巨手化作一片晶光缓缓消散。
- 但危机未止：**被打开封印而出现的古妖**双眼露出红芒、舔着嘴唇，仰天发出尖锐嘶吼。

## 三、传承之声：轮回门与「本道天府」

王林踏入裂缝刹那，脑海内轰然浮现**第九幅地图**，但此刻这第九张地图已无作用。与此同时，古老寂寞沧桑之声传入心神：

- 「**九阶墓启，汝为吾之传承**」——可踏**轮回门**，入**本道天府**。
- **天府被本道世敌所封**，进入需足够修为，且需莫大机缘。
- 「吾之一生，仅有一次（机缘），然吾不悔。」
- **道门之士「左旋」封锁了吾退路**。
- **「道忆李广」射下了吾左眼**——那左眼内包含了它**半生的记忆与对故乡的思念**。
- 「传承者，若汝能……若能……若能——」最后两句极为模糊，听不清晰（悬念）。

> 注：原文有多处明显错讹（「裂缕/裂缝」「墓台耀毁/摧毁」「不灭雷筵/不灭雷炎」「王抹/王林」等），此处按通行文意校读。

## 四、尸烛大殿：所见景象

王林视线清晰后，身处一座**庞大无比的宫殿**：

| 要素 | 描述 |
|---|---|
| 规模 | 如星空一般，一眼难见尽头 |
| 气象 | 金碧辉煌、透出无尽威严，同时弥漫阴森 |
| 尸队 | 前方四排并列延伸极远，每排近千修士，笔直站立、七窍流血、双目睁着，残留狰狞与杀机 |
| 衣衫 | 材质如流水般似活物；王林仅在**闪雷族收取不灭雷炎**时、脑海虚幻画面中的「当年外来者」身上见过 |
| 灯火 | 每人头顶燃**绿色火焰**，发出轻微燃烧声，照亮大殿；乃**尸油与元神融合**形成的火烛 |
| 石台 | 前方远处高高耸立，顶端有巨大座椅 |
| 裂缝 | 石台自底部直至椅下有一道巨大裂缝缺口，残余惊天之气，似当年有人一剑或一箭破开天地一切阻隔、自远处呼啸而至直指座椅之人 |
| 座椅 | 空无一人，唯有一个**椭圆形光团**散发柔和之芒静静漂浮 |
| 巨鼎 | 四排修士中间矗立约**数百丈**大小之鼎，鼎内燃香渺渺直奔上空；石台**前后左右整整八方**位置各有一鼎，各有无数尸修 |

## 五、悬念收束

王林心神震撼，深吸口气后飞高，越过石台看到宫殿小半；随即右手抬起猛地一挥，**狂风横扫、刺目之芒笼罩大半宫殿**，看清远处存在的刹那——**双眼瞳孔猛地一缩**。（所见为何，本章未揭）

## 六、线索与伏笔

1. **轮回门 / 本道天府**：九阶墓台传承的最终指向，需修为 + 莫大机缘，且被「世敌」所封。
2. **左旋** 与 **道忆李广**：两位对古墓主人下手的道门之敌，前者封退路、后者射落左眼。
3. **失落的左眼**：内含半生记忆与故乡之思——极可能是后续必取之物。
4. **石台裂缝**：一剑/一箭破开天地直指座椅——当年弑主之战的物证。
5. **座椅上的光团**：主位无人，仅余光团，身份成谜。
6. **外来者衣衫**与闪雷族不灭雷炎画面的呼应——大殿尸修与「当年外来者」同源。
7. **古妖**已破封嘶吼，外界危机延续。
8. **第九幅地图**功成身退，标志王林地图线告一段落。
