# 第2004章 计都皇子

## 一、选妃传闻与地图之念

- 皮甲大汉向王林陈述：道古使团出行有**计都皇子**陪伴，必是**始古皇**首肯，否则城主不会下令封城。
- 王林愕然于「选妃」二字——自己未来要守护的道古一脉之皇，竟为择妃而遣使团往其余两个古国，觉此事荒唐。
- 王林转念：既遇道古一脉之人，其身上必有前往**道吉十二郡**的详细地图，可省去自行寻找之功。

## 二、黑石城三巨头出城

城内传出脚步声，两队青色铠甲的吉族兵士（近千人）列于城门外，随后走出三人：

| 人物 | 称谓 | 形貌 |
|---|---|---|
| **梁云** | 神圣城主（黑石城城主） | 身高一丈余，金色铠甲，红色皮肤，不怒自威，性爽朗 |
| **孔司** | 妖圣大人 | 青衫仙风道骨，三缕胡须，肤色白皙，手持黑扇；双目妖异，左目似有雾气回旋 |
| **孟洛** | 魔圣大人 | 黑衣青年，冷漠，暗藏暴虐杀戮，如身外燃烧极冷之火 |

- 三人以梁云为首。众吉族大汉与兵士见之皆单膝跪拜。
- 三人几乎同时察觉王林，目光凝聚在其**眉心九个星点**上，神色一闪。
- 梁云抱拳自报家门相询；孔司微笑抱拳自称「孔司」；孟洛不言不语。
- 王林抱拳自称「王林」，称偶然途经、闻计都皇子与道古使团临近而留下一望，若不便则离去。文中点明其性格：他人客气，他必礼待回敬，从不因修为身份而傲然。
- 王林感受到梁云身上的**吉神之力**，心生亲切。

## 三、「融妖炼魔」之问（重要设定线索）

- 梁云问：「王兄也是神圣，想必也度过了第二劫，应该到了**融妖炼魔**的阶段，不知如今进展如何？」
- 王林内心一动（首次听闻此说），神色如常，摇头一笑不答。
- 孟洛冷言：「**通、融、炼**之难，岂能是那么容易」，判断王林毫无妖魔气息散出，必仍在摸索阶段，讥梁云此问「与不问等同」。
- 梁云致歉，自承「通、融、炼之术的确太难，梁某如今也进展不多」。
- 此后梁云与孔司言语间试探王林来历，始终未问出结果，众人渐归沉默。

## 四、古妖破空、计都皇子降临

- 天空风云色变，层层波纹回荡，一巨大拳头凭空轰向天幕；天幕如崩，两只手掌自天幕之后撕开一道巨大裂缝。
- **一尊约数万丈、头生单角、身着青色铠甲的古妖**一步迈出，滔天魔气化雾笼罩八方，双目血红暴躁，仰天嘶吼、踏地起浪。
- 王林一眼看出端倪：此非寻常古妖。他在**洞府界**见过的古妖如古神一般，不显本体时与常人无异，即便显露本体也保持神智不陷疯狂；而此妖体内爆发的妖气之强，**等同于仙族的天尊修士**。
- 古妖头顶立一皇袍青年（**计都皇子**）：长发飘摇，相貌寻常却气质莫测；身后另有一蓝衣裙年轻女子，望向王林露出诧异。
- 紧随其后，天幕裂缝中又走出**一尊万丈大小、通体漆黑、头生双角的古魔**，双目通红、疯狂暴虐、似不受控；其头顶站着**七人（五男二女）**，向古妖顶上的皇子抱拳一拜。

## 五、唯一不跪者与杀令

- 梁云、孔司、孟洛及近千兵士、城内所见者尽数跪拜，**全场唯王林一人站立**。
- 三人骇然：区区皇子如何能让王林跪拜——莫说皇子，纵是**大天尊**也无法令其跪拜，**即便仙皇，也只需抱拳**。
- 皇袍青年凝望王林一眼后，转看古魔头顶七人，微笑道「族人不敬，让诸位见笑了」。
- 皇子问梁云此人是否为其新招揽麾下；梁云撇清，称此人刚出现、说要一望皇子，自请「现在就将其轰杀，以儆效尤」。
- 皇子冷道「不用」，随即下令：「**陀咯，将他杀了**」。数万丈古妖咆哮，巨大右爪抬起抓向王林，指甲锋利似可豁开虚无，化作数道黑线携滔天妖气直奔王林。

## 六、要点与悬念

1. 「第二劫」与「融妖炼魔（通、融、炼）」是道古一脉/神圣境的修行阶段术语，本章首次出现。
2. 道古一脉的古妖、古魔被役使为坐骑/战力，且与洞府界古妖不同——疯狂无智、力比天尊。
3. 王林的目标是道吉十二郡地图；与计都皇子的冲突即将开启。
