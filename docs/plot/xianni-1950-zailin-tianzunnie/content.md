# 第1950章 再临！

## 一、十三年东临池静修

- 王林在东临宗东临池外的祭坛平台盘膝十三年：
  - **太初本源**：已完全感悟在心，使其特殊本源多出一道。
  - **默灭本源**：十三年内四千余次观看「黑夜吞噬光明」，加上东临池感悟，虽未完全掌握，但已有所明白（略有小成）。
  - 十三年多次入东临池感悟，那道**低沉的声音再未出现**。
- 外相变化：修为依旧，但在日出日落的观察中**长发垂至与腰齐平**；睁眼时**左目一轮初阳、右目漆黑一片**，气息诡异。
- 来东临宗的目的：**寻找修为突破的契机**。一旦突破，便可再闯天尊涅，完成去仙族皇城前的准备。

## 二、雷霆真身与五道本源融合

### 真身状态
- 王林身现重叠之影，弧形闪电游走间**雷霆真身**分出，盘膝坐于本体对面，一脸冷漠、全身闪电啪啪作响，散发难以形容的毁灭之感——这股「杀戮雷霆」连王林自己都感到陌生。
- 王林挥手将真身**白衣化为黑衣**（如黑暗吞噬光明），令其化身黑暗，以更好明悟默灭本源；衣变的刹那，其体内毁灭感更浓。

### 融合过程
1. 左目瞳中的**初阳轮廓（太初本源）**浮出，融入雷霆真身 → 真身震动，刺目光芒散出，**光明与毁灭相互排斥**。
2. 右目漆黑如墨蔓延，凝于右手化作**黑色天阳（默灭本源）**，再度打入真身；王林本体神识同时扩散，以强大威压强行令真身内所有本源**按其意志融合**。
3. 黑色天阳蕴含本源不多，但性质近于毁灭，一入真身即被**杀戮雷霆吸收**，融为一体，杀戮雷霆再生变化。

### 平衡的崩溃与重建
- 杀戮雷霆本就毁灭天地、撕裂光明化作虚无；融合默灭本源后，**毁天灭地的气息**扩散，连王林的意志都有压制不住之感。
- 这股力量原被**禁制本源**如封印般困于真身之内，一旦外泄将掀起恐怖浩劫。原先「禁制锁杀戮」的勉强平衡，因默灭融入而**直接崩溃**。
- 王林早有预料：崩溃刹那，代表光明的**太初本源与禁制本源融合**，形成新的封印，与杀戮+毁灭再度平衡。
- 作者评语式设定：这具真身如同**随时可燃的火苗**，「凡人掌火——要么彻底掌控，要么被火焚身」。禁制+太初的合力似仍不足以对抗杀戮+默灭，**危机没有消散**，但王林必须如此。
- 该真身自杀戮雷霆被无意创造出的那一刻起，就注定**与五行截然不同**的特殊性。

## 三、突破：空劫初期 → 空劫中期大尊

- 四道特殊本源在真身内融合对抗、勉强成一体的刹那，真身睁眼——**左目为光，右目为暗**——走近本体，似透明般与王林重叠，盘膝坐下并**融入王林体内**。
- 修为气息轰然暴增，自空劫初期不断攀升；东临宗上空**时而黑暗、时而光明**急速交错，天地色变、风云倒卷。
- 体内闷雷轰鸣，白发飘起，衣衫如被狂风吹动，修为**自空劫初期突破为空劫中期大尊**。突破完成后天地变化消散，四周风止、万物不动。

## 四、离开东临死宗

- 王林一晃身，敬畏他的**金尊海龙**飞来，王林踏于其头顶；**刘金彪**咽了口唾沫，满怀敬畏地飞上龙背恭立其后。
  - 刘金彪十三年内因**记忆苏醒**并讨好金尊海龙、得其相助，修为**已恢复大半**。
- 升空后王林望向下方东临宗与东临池，抱拳**深深一拜**：「前辈尽管已亡，但感悟之恩，王某铭记在心。」目光最终落向东临殿，依稀看到殿内那孤独悲哀的老者。
- 海龙化长虹远去。身后被深山淹没的**东临死宗**内，传出蕴含无数年孤独与悲伤的惆怅叹息：
  - 因**孤独** → 梦障衍化，形成记忆之幻相伴；
  - 因**悲哀** → 岁月中留守死宗，数着回忆默默守护；
  - 因**执着** → 千年万年，隐于悲哀深处的恨与疯狂化作似鲜血之物，一笔一笔临摹石碑上的话语。

## 五、大圣洲高峰闭关三月

- 王林未离开**大圣洲**，在一处高峰盘膝坐下，以金尊海龙守护、阵法禁制铺垫，迎着初阳闭目。
- 三个月后平复并适应修为暴增的波动，挥手凝聚诸多神通试演：
  - 空劫初期时受修为限制，**最多融十三道神通于体**；如今空劫中期可融多少？再加上真身与本源的叠加，效果未知。
- 立誓四条：一鸣惊人 / 让仙族大陆所有天尊仰望注视 / 列位跃天尊之一 / **成为仙族大陆第四十九位跃天尊**，并**动用天牛魂铠之力**。

## 六、再临天尊涅

- 王林神识凝于天灵，化无形之体直冲九霄，脑海轰鸣后抵达当年来过的**天尊涅**：远处漂浮着层层递高的一座座大殿，**第一层大殿外盘膝打坐着数百天尊**。
- 众天尊见他自古老的特殊传送阵内化长虹疾驰而来，纷纷议论：
  - 「**白发天尊**」；
  - 当年他**连续闯过前四层**且间隔极短，本以为会闯第五层，却放弃离开；
  - 众人推测他是自觉闯不过而知难而退，此番来必是对第五层有了把握。
- **竹林**：第一层大殿外的黑衣中年男子，性格孤僻、所在之地四周无人，是**第一个看到王林**的人。其当年**穿过第七层，却在第八层止步**。

## 七、悬念

- 王林此番能闯过天尊涅几层？能否位列第四十九位跃天尊？天牛魂铠之力将如何施展？
- 雷霆真身内四道本源的封印平衡随时可能失控，是后续隐患。
