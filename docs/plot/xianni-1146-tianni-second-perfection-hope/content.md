# 第九卷 云海之巅 第1146章 天逆二次圆满的希望

（对应本地卷次 01063-01067 之2）

## 一、星雾之中：紫道宗主得知丧子

- **场景**：一片星雾之外的紫色大陆附近，紫道宗宗主（中年男子）与随行紫衣老者。
- **猎兽进度**：中年男子言“还差九头”，但附近星雾内的**星虎兽已被猎至灭绝**，需去更远处捕捉。此举与章节标题“天逆二次圆满的希望”相呼应（猎兽疑为某种圆满所需）。
- **噩耗**：其虚空一抓，储物裂缝中飞出一枚玉简，玉简咔然裂开，飘出一丝**残魂——正是卢迪**，眼中带着死前恐惧，随即消散。
- **紫衣老者反应**：惊呼“少宗”，笑容收起，目露震惊；他跟随宗主多年，深知**宗主越平静，风暴越大**。

## 二、卢云从的态度与决断

- 追问卢迪去向，老者答：**去了莫罗大陆**。宗主接问“**莫罗大陆，归元宗**，此事为什么没人禀告于我”。
- 老者心惊：竟有人敢在**五阶星域**内，冒着得罪紫道宗、得罪宗主**卢云从**的风险杀死少宗。（宗主之名由此点出）
- 宗主自语揭穿其子劣迹：**身为修道之人却贪恋美色、狂妄自大，以紫道少宗之名祸害诸多宗派女弟子，行吸其元阴之歹毒事**。老者沉默，因所述句句属实。
- 推断同行者为**宋五德**——卢迪自幼由宋五德照看长大，视其为第二个父亲；此行动机是**看中归元宗吕烟菲**，并欲趁归元宗掌门（“那老匹夫”）身亡之机将归元宗据为寝宫。
- **决断**（语气平静、似无感情）：
  - “这不成器的逆子，死就死了，这世间从此也少了一个祸害。”
  - 但终究是父亲——**让吕烟菲为其陪葬**；
  - **杀他之人，也一起陪葬**。
  - 补一句“他以前，不是这样的”，背影萧瑟。

## 三、天阴幡与阴仙——真正的惊怒点

- 紫衣老者犹豫后咬牙补充：卢迪临走前曾对宋五德说，**要先去紫云海取紫道宗存放在那里的「天阴幡」**，打算把**吕烟菲的魂魄及其此前收集的女子魂魄尽数封入幡内，喂养「阴仙」**。
- 卢云从背影**骤然一顿**，缓缓转身，平静崩溃，**滔天之怒**中更弥漫**源自心神的恐惧与惊慌**，怒喝“逆子”。
- 伏笔：天阴幡/阴仙显然牵涉紫道宗极大禁忌或隐秘，连宗主亦感恐惧。

## 四、归元宗药院：吕烟菲求见王林

- 地点：**莫罗大陆·归元宗·药院**，王林所居的平凡木屋。
- **吕烟菲**犹豫后走进药院，徒弟**孙芸**紧张相随，可闻己心跳。
- 门闭。吕烟菲抿唇轻问：“**前辈可在**”
- 屋内平淡回答：“**不在**”，师徒二人愕然。
- **呼应闪回**：很久很久之前，在**联盟星域**内，也曾有一个女子问过同样的话，得到的也是同样的答案。（王林一贯的拒人方式）

## 五、伏笔与后续看点

1. 紫道宗将向归元宗与“杀卢迪之人”（实为王林一线）展开报复，吕烟菲已被列为陪葬对象。
2. 天阴幡、阴仙之秘引发宗主级恐惧，或为后续重大隐线。
3. 星虎兽“还差九头”与“天逆二次圆满”之间的关联待揭。
4. 王林闭门谢客，与吕烟菲师徒的交集尚未展开。

# 第1063章 剧情梳理

## 一、吕烟菲赠身份：归元宗「吕子浩」

吕烟菲在药院子中，向屋舍欠身作揖，讲述了一段旧事：

- 师尊当年有一位师叔名为 **吕子浩**，是个「道痴」。
- 吕子浩一生除最后那一次外出失踪外，**从未离开过莫罗大陆**，连归元宗主宗也未去过。
- 朋友稀少；事隔太过久远，归元宗内已经没有见过他的人，连吕烟菲的三个师兄都没见过。
- 吕烟菲当年偶然见过其画像一次，是师尊单独给她看的，并把画像送给了她——因为 **吕子浩是吕家的先祖**。
- 该画像年月太久破损不堪，**在方才回来的路上已经破碎**。

讲完这番话，吕烟菲恭敬离开药院子，面带微笑。同在场的孙芸完全摸不着头绪。

### 弦外之音

这番话是一份**量身定制、无从对证的身份**：无人见过其人、画像恰好已毁、活动范围只在莫罗大陆、结局是「外出失踪」——王林可以「吕子浩」之名在云海星域立足。

## 二、王林的判读

王林盘膝于床，双目望着右手黑色荷花，抬头目露精光，目光仿佛穿透房屋落在离去的吕烟菲身上；吕烟菲身子一顿，未回头，平静走出院子。

王林的推断：

- 吕烟菲通过**弟子汇报的蛛丝马迹 + 山脉半天交谈 + 之前所见王林出手杀宋五德和卢迪**，推出王林即那个「白发人」，且似乎已经很确定。
- 在吕烟菲看来，王林有此修为还要隐在归元宗，除对归元宗有所图外，定是**躲避仇家**；而她想不出归元宗有何可图之处，故对「躲避仇家」更为确定。
- 因此她主动送来一个不被怀疑的身份；至于仇家问题，她显然不得不忽略。

王林评价：「好聪明的女子。」——**聪睿，而且不轻易显露的聪睿**，不同于柳眉的千变万化、红蝶的冷傲绝伦、李慕婉的温和柔弱。

王林喃喃：「吕子浩这样的身份，倒是使得我在这云海星域，有了根。」

### 为何重视身份（承罗天教训）

- 在**罗天星域**时王林没注意身份问题，最终身份在那些大神通修士眼中**如同透明**，带来很大不便。
- 任何一个星域都存在排外与「非我族人其心必异」的言辞。
- 以其现在修为，身份问题更不好处理；眼下虽未完善，但已有一丝解决途径。

## 三、黑色荷花：天然可成法宝的植物

- 王林神识反复探查，惊奇发现这荷花**浑然天作，是一株真实的植物**，只是后加了一些简单法阵略作封印。
- 若打开其上封印，可形成**极强的防护**。
- 王林感叹：云海星域神奇莫测，竟有这种天然可成法宝的植物存在。

## 四、紫衣青年的储物袋

物品较杂，除银秽之物与零散法宝外，三样引起注意：

| 物品 | 描述 |
|---|---|
| 紫色玉瓶 | 通体紫色 |
| 金色小旗 | 内封极阴，详见下节 |
| 燃香 | 一整支，婴儿手臂粗细 |

- **仙玉罕见稀少，不足百块**。
- 王林摇头感叹：修为到了**净涅**后不再需要储物袋，改为自行开辟储物空间，即便死亡外人也无法知晓方位与打开——否则那净涅老者身上定有不少丹药与宝贝。

## 五、金色小旗与「一丝极阴」

王林神识扫入小旗，面色顿时阴沉：

- 旗内**阴风阵阵**，封有**不下数百名女子阴魂**，个个相貌秀美，更有几个堪称绝伦；被封无法出来，样子凄惨。
- 旗中另有一头**蛇形兽魂**，似在吞噬女子阴魂；被王林神识惊醒后散出惊人气息，王林双目为之一凝，神识被冲击退回。
- 王林判定：这是 **极阴的气息**。他猛地站起，平静心绪波涛汹涌。

### 与天逆珠的关联

- 惜其**不完整**，只具备一丝极阴之气，且**饲养的方法完全不对**，与当年**天运子借白微而生的极阳**差之太多。
- 但终究是一丝极阴。
- **天逆珠五行圆满后成为阴阳**；当年在白微那里获得了极阳，只缺极阴——得极阴，**天逆便可第二次圆满**。

## 六、关键伏笔

1. 「吕子浩」身份将成为王林在云海星域行走的正式马甲。
2. 吕烟菲已看破王林即白发人，双方形成心照不宣的默契。
3. 黑色荷花解封后的防护之能待用。
4. 极阴之路开启：天逆珠第二次圆满有了方向。

## 章前说明

开篇一句「毕竟无论是本尊还是分身，都是王林」承接分身线；本片段所有言行归属王林本尊。
