# 第九卷 云海之巅 第1431章 这一天，到了！

## 一、焚世古伞成形与灭世火气
- 火焰风暴停在半空，与火骨伞架融合，形成**焚世古伞**（文中亦称焚界古伞）。王林一口鲜血落于伞上，磅礴生机疯狂涌入，巨伞轰鸣。
- 正在崩溃的火雀族圣地弥漫无法形容的炙热，逼近的掌印为热浪一冲略有停顿，掌尊面色大变。
- 古伞缓缓撑开，开至约一成时，一股**灭世之火**宣泄而出——无色，已不能称火焰，而是一股**无形的火气**；所过之处尽数毁灭，化为虚无。
- 该火气正面撞碎掌印，并把此前朱雀源灵与掌尊神通碰撞掀起的、毁灭一切生灵的无尽冲击尽数焚灭。

## 二、掌尊撕铠甲，掌压乾坤
- 掌尊本已重伤：先「井中捞月」失算，后被朱雀源灵重创，封印源灵后又遇焚世古伞。
- 他双手掐诀按肩，疯狂低吼中生生撕下与肉身融合的**铠甲**——得自其师尊的**太古之宝**，甩出化作遮天巨掌，大小几乎与朱雀喙相比，直击王林，宣称「尚未完全开启的古伞，足以对抗掌压乾坤」。
- 巨掌穿透火气并急速消散，缩至一半后砸在古伞上；王林修为不够，只能开至两成，喷血倒卷，生机紊乱。

## 三、引爆古伞，圣地崩毁
- 古伞失去生机将散之际，王林神色狰狞低吼「**爆**」。
- 古伞轰然爆开，毁灭之力扩散：火雀族圣地彻底崩溃，铠甲所化灰色掌印被卷灭。
- 圣地大门轰然崩溃，碎片直扑门外盘膝打坐的**火雀族老祖**——他毫无察觉，被碎片击中喷血急退，眼中尽是震惊、骇然与无法置信。

## 四、逃遁中的层层硬抗（手段序列）
王林自崩溃的大门中冲出，掌尊在毁灭之力中追击并连拍掌印。王林依次动用：
1. **呼风唤雨界** —— 一撞即崩。
2. **光影盾**（蓝梦道尊神通）—— 在修真星地心光芒中凝成巨大光影，剧烈折射，仅撑瞬息即溃。
3. **天皇炉** —— 自眉心古神星点第一颗星内飞出结成防护，未崩溃，却被掌印之力轰得无法成形，生生打回王林眉心。
4. **古神护臂** —— 以**古神之骨**祭炼的古神法器，自右臂化出硬接掌印；王林连喷七口鲜血，元神几被逼出体外。
- 修真星承受不住冲击，地表遍布裂缝，如水球被打散般四分五裂瓦解。王林被轰穿地心，抛入**太古星辰的星空**，肉身几乎崩溃、元神萎靡；全赖古神肉身才未当场身死。

## 五、古之庇佑——八星古神保命之术
- 王林左手按住右臂护臂，低喝：「**八星古神，保命之术，古之庇佑**」，体内古神之力尽数涌入护臂。
- 星空扭曲，一尊堪比修真星大小、通体虚幻、遍体战伤的古神现身，眉心清晰浮出**八个旋转星点**；它背对掌尊，双臂环抱将王林护在怀中，如父母护子，传出温暖之感。
- 掌尊掌印落在古神背部，如蝇蚊撞击般在其体内崩溃。
- 古之庇佑并非纯防御：这是**给幼年古神的保命神通**。古神猛地转身，回首一拳如流星陨石轰中掌尊——掌尊面色惨白喷血，彻底重伤，连同此前朱雀喙、焚界古伞所迫、被其**数万年调养压制**的旧伤一并疯狂爆发。一拳之后古神散去，复化护臂融回王林右臂。

## 六、结尾转折：掌尊以复活李慕婉相诱
- 王林本可立即逃遁，却反手掷出**血剑**（离开圣地前被收走的法宝之一）追击掌尊，被掌尊祭出不明法宝挡下。
- 王林伤重「全凭一口气」，抓回血剑欲以**缩地成寸**遁走。
- 掌尊虚弱之声传来：「王林王林，你胆大心细，狠毒果断，狡猾至极，你可愿成为老夫之士，只要你同意，我可以让你妻子复活——不是魂醒，而是真正的复活。」
- 王林如遭雷噬，当场僵立，死死盯住远处扶胸的中年男子（掌尊），脑中回响旧问：「如果那一日，我换成了司马墨，其妹妹换做了婉儿，我该如何选择」「或许会有那一天」——**这一天，到了**。
