# 第565章 老祖回归

## 一、虚幻一掌：无名神通慑退妖将

- **对峙**：妖将莫厉海身周妖浪汹涌旋转，眼前世界被王林打出的巨大掌印取代。掌印自天而降，带来“无法战胜、无法抵抗、无法闪躲”之感——好似这一掌便是天地、便可灭世、便可摧毁一切生灵。
- **不屈战意**：妖将虽被气势几乎摧毁战意，仍咆哮拔地而起，妖浪化作无数海龙冲天，喊出“即便你是天地，也要战”。
- **反转**：掌印落下，却只是**微风拂面**，从其身上一扫而过，毫无变化。王林落地一句：“**你，已经死了**。”
- **问答**：妖将问是什么神通，王林平淡答“**此招无名**”。妖将指出“这一招，你尚未学全”，王林只回“**你，可以再尝试一下**”。
- **心理博弈**：妖将心底九分怀疑此掌只有虚幻、无实际攻击，但那生死刹那的余悸让他不敢赌那一分真实。他给自己的唯一解释是：以王林修为真正施展必遭极大反噬、甚至自身崩溃，故只打虚幻一掌。
- **王林的算计**：不解释即最优解——“解释越多，破绽越多”；真真假假、虚虚实实，怀疑永远只是怀疑。

## 二、和解与结盟条件

| 项 | 内容 |
|---|---|
| 王林的“罪” | 杀莫厉海数万妖兵、毁其十里城阁 |
| 十三的处境 | 妖将闭关为炼制法宝需炼化十八名身体强度足够之人，十三排在后面**尚未被炼化** |
| 交换条件 | 三个月后莫厉海回天妖郡都**京天妖城**述职，各地妖将将有一场比斗，王林助战 → 杀兵之事一笔勾销 |
| 威胁 | 否则“即便我战死，你也无法在这天妖郡内立足” |
| 封赏 | 王林即日起为**左翼妖将莫厉海的第一副将**；若莫厉海入京都妖将前三，将帮王林向妖帝索要**将位**（独享一城、握十万妖兵） |
| 归还方式 | 妖将虚空一抓现出黑色漩涡（内中繁星点点），随意一点碎去一颗星辰，十三之身幻化飞出 |

- 妖将不以十三要挟，以将位相诱使王林尽全力，谓之“**诚**”；此举完全基于他见识了王林实力、尤其那一掌之后的判断。
- 妖将评价：此人修为与我相当；若非神通之术不如我，此战恐极为艰难。想到那一掌后，“我的神通又算得了什么，**恐怕唯有妖帝，才可以对抗此神通**”。

## 三、妖将事后复盘（对五名婴变后期老者）

- 老者进言：那一掌应是假的，大人出手定可擒杀此人。
- 妖将回应要点：
  1. 明知九成是虚张声势，仍无法下决心去赌。
  2. 一年前王林曾以秘术一言破开十崩拳意的**第七崩**；一年之后修为突飞猛进。
  3. 王林与**姚统领**一起失踪，却只一人回来，其中必有隐秘之事——但与我无关。
- 此战使王林在妖将眼中地位飙升：仅凭破十崩拳意、承受妖海之浪，便已被视为可平起平坐之人。

## 四、黑牢寻虎咆（未果）

- 王林神识扩散，在城内找到**黑牢**，位于古妖城地下，有阵法封印，但除黑牢深处外无法限制王林。
- 判断虎咆身份不可能被关在深处，神识一扫未发现踪迹，暗叹后离去。

## 五、返回炼魂部落·老祖归位

- 王林修为达**婴变后期大圆满**后速度快数倍，携十三未耗多少时日便自古妖城回到炼魂部落，数十里外瞬移光华闪现。
- **炼魂部落现状**：一年来未向外扩张，族人持续修行；方圆十里尽为其势力范围；十里上空浓浓黑雾中魂魄穿梭呼啸（声越凄厉＝魂魄越多）；族人身前魂幡飘动，魂魄自幡内飞出融入黑雾、又自黑雾飞回融入魂幡。
- **防务**：数十里内有十多人隐匿观察，百里之内守护者数百，多为王林熟识。
- **迎接**：王林于部落百丈外停身，被人认出高呼“老祖”；欧阳华化作黑雾冲出，十多丈外恭敬道“恭迎老祖回归”，全族纷纷单膝跪地齐声相和。
- 十三体内无伤，仅是昏迷。

## 六、后续伏笔 / 待办

- **三个月后**：王林须赴京天妖城，助莫厉海参加妖将比斗（约期明确，为下一阶段主线）。
- **虎咆下落不明**：黑牢未寻到，线索待续。
- **姚统领失踪之谜**：妖将已起疑，王林独自归来的隐秘尚未被揭破。
- **无名一掌未学全**：妖将点破“尚未学全”，此神通完整形态与反噬代价仍是悬念。
