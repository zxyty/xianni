# 第1377章：万粒龙崩丹熔一，仰天挑战

## 一、龙甲族三宝与龙崩丹交易

龙甲族少族向王林介绍第三宝**龙崩丹**：

- 用法：**并非吞服，而是以爆开伤敌**。
- 威力：单粒不大，但百枚、千枚、万枚之后其威无穷。
- 来历：龙甲族三宝中除第一宝外，余下两种**并非本族创造，而是颠落大帝所赐**，独属龙甲族。

王林拒绝龙鳞、白骨，只要龙崩丹，索取样品查验：丹内**四种气息混乱交错、形成平衡**，平衡一旦打破立刻爆开，威力**相当于窥涅修士一击**。

王林斩钉截铁开价：**一粒魂丹换百粒龙崩丹**，要**一万粒**。少族双目猛缩后应允，并道：「一万龙崩丹，若是全部爆开，足以威胁**天人一衰**修士了。」王林大袖收走万丹，留下**百粒魂丹**离去。

## 二、支开暗蝎族，钓上火雀族

出阁楼后王林令暗蝎族族长先回族中，自称有私事。他在城中缓步而行，心中盘算：

> 「闪雷族我是直接闯入进去，至于这火雀族，我要让他们送我进去。」——**诱饵已放，只等上钩**。

火雀族老者一路尾随，被王林冷声喝破后极为恭敬地求交易：以**百块炎火异晶**（大小与先前所换三块相当）换**魂丹**。老者拍开眉心取出一团**淡蓝色火焰**（作用类似储物袋，内藏百块炎晶）交予王林，王林掷还**百粒魂丹**，转身消失。

## 三、山巅重炼：万粒融一

王林现身于修真星中心一处山峰顶，取出一万龙崩丹。他已识破定价异常：

> 「魂丹虽贵，但也不可能一粒换百粒这种堪比窥涅修士一击的龙崩丹。龙甲族，既然你们非要参与进来，那么就休怪王某殃及池鱼。」

炼制过程（威力逐级叠加）：

| 步骤 | 手段 | 结果 |
|---|---|---|
| 1 | 左目火焰化火海熔丹 + **蓝梦道尊「道术·融天地一切之物」**（神通也好、法宝也好、力量也好、规则也好，都能融） | 万丹融一，成指甲盖大小**金色丹药**；气息由四道→**五道**（新增火焰之力） |
| 2 | 道术不断压缩 | 万粒融一即具**天人第一衰**崩溃之威；压缩下可无限接近**天人第二衰**；加火焰之力达**天人第三衰** |
| 3 | 右目雷霆化雷图融入 + **闪雷族凝雷神通** | **六道气息**，可伤**天人第四衰** |
| 4 | 咬破舌尖喷出**古神血液+元神精气** | 金光转**血色**、惊天煞气，足以威胁**天人第五衰** |

## 四、炎火异晶炼化

王林判断：这些炎晶**无法让朱雀第四次觉醒，吞之无用**，但凭其对火焰的操控可炼成堪比法宝的利器。以左目火焰（隐现**朱雀之影**）配合道术融合，炼化全部炎晶为**一粒深蓝色晶体**，内蕴**火焰本源之力**与朱雀之影，**毁灭之威不弱于重新祭炼后的龙崩丹**。

## 五、鹿骨断剑封印再开

王林食指一指天空，幻化出**两条鹿兽**，宣称要以**雷霆大成的本源**开启刺入鹿骨的断剑**最后一道封印**。全身雷霆化滔天雷网环绕食指，剑气自一道、百道、万道、十万、百万、千万不断攀升，破开千万局限冲出雷网，充塞天空，最终停在**三千九百九十九万**。

结论：**封印尚无法全开，但破开一部分，剑气之威暴增**。

## 六、战前决断与长啸

王林的预案：

- 若来者**是分身** → 让其灭绝于此；
- 若**非分身**，则爆发**第三步之力** → 第三步神通一展，**颠落之地顷刻可崩溃**；
- 即便无人阻止，大不了逃出此地——**火雀族的引子已埋，火雀族自会来寻**。

随后仰天长啸：**「我在这里等你，可敢一战」**，啸声惊天动地传遍修真星，全星修士尽闻。

## 七、两处反应（同一时间）

- **修真星东部城池·火雀族居所**：老者与七名族人以火焚化那百粒魂丹，魂丹与其内魂魄尽皆消散，火中却留下**一滴散发赤红之芒的鲜血**。老者倒吸凉气：「果然不出老夫所料，这丹药之所以有本源气息，正是因为这血液存在……这是什么血？」话音未落，长啸传来，老者面色一变抬头。
- **龙甲族圣地阁楼**：龙甲族族长与**司墨子**同坐，少族回禀「父尊，已经按照您的吩咐，将一万龙崩丹送出」。族长请司墨子出手：「此人从我龙甲族抢走一万龙崩丹……将此人擒杀，事后我龙甲族必有重谢。」司墨子含笑欲言，长啸骤至。

## 八、伏笔与看点

1. **万丹交易是双向下套**：龙甲族刻意送出万丹为局，王林则早知定价荒谬、借局取材并「殃及池鱼」。
2. **魂丹之血**被火雀族识破为本源气息之源，指向王林身份的下一个危险。
3. 王林手中现有**血色崩丹（伤天人第五衰）+ 深蓝炎晶 + 三千九百九十九万剑气**三张底牌，直接叫阵。
4. 王林对火雀族「让他们送我进去」的谋划已成型，与闪雷族的强闯路线形成对照。
