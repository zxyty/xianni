# 第656–658章 解开画轴的秘密 / 老怪降临（此卷终）

## 一、画轴女子破十三年沉默

- 王林在深坑中感悟吸力十三年，画轴内女子始终不语；此刻突然出声，语调带悲哀与急切，恳求王林「带我下去」，称自己走不出画轴，不会给王林带来危险，只是「想看一眼」。
- 王林取出画轴展开，第一次认真打量：只见背影，却有绝代风华之气。他拒绝——洞府禁制必须在天运子等人抵达妖灵之地前尽数破解；由当初与姚惜雪的交谈得到线索，天运子等人恐怕很快来临。此外还要设法不让天运子察觉端倪，任一环节出错代价即是身亡。**时间对他太少了。**

## 二、两句话击碎八百年道心

画轴女子在王林将要升离时抛出两句：
1. 「你不想知道，你元神内的珠子，真正的来历么」
2. 「你，不想让那珠子内的女子残魂，复活么」

- 第二句令王林元神与记忆如洪水爆发、天地坍塌，定力尽失、身子颤抖，目光如野兽，八百余年修道的冷静荡然无存。此刻天运子、洞府、血祖、妖灵之地尽数崩溃瓦解。
- 女子承诺三事：告知珠子来历、告知珠内幽魂复活之法、给他离开此地的契机。
- 王林不辨真假、不问她为何知晓自己一切，抓画轴直坠深坑底部——**哪怕一线生机也要争取**。文本点明：他并非冷酷的仙、无情的神，「只有在失去之后才知道自己一直想要珍惜一个人」。旁证其冷静本能之深：曾冷静地为朱雀星的周茹留下一个无情的储物袋，等待其打开的一天。

## 三、深坑底部：通往罗天星域的漩涡

- 下落极久（「或许一天、或许一月、或许一年」），崖壁霜气更浓、隐透晶光，吸力愈强。
- 底部出现一处短暂回廊，其中有缓慢旋转的巨大漩涡，**吸力正源自漩涡**；奇异的是漩涡近处吸力如被封印，出一定范围后才骤然变大。
- 一股奇异之力自画轴钻入王林体内凝于双目，使其目光穿透漩涡：内为一片星空、无数修真星，宛若另一个世界。
- 女子言：「我的家乡——罗天星域。」王林记忆中，连古神涂司的记忆传承里都无「星域」之说。

## 四、秘辛：仙域、四大仙界与天逆珠来历

- **仙域**：恒久之前，星空中有一处神秘星域，为所有修士的圣地，称作仙域；传闻多已湮灭，其存否无人可确认。
- **四大仙界**：传说仙域放弃修士、离开这片星空而消失，只遗下当年四处通往仙域的通道；无数万万年来，这四处通道成为高阶修士飞升之地，化作另一个仙界，即**风、雨、雷、电**四大仙界，其下各自对应一个星域。
  - 罗天星域之上 → **雷之仙界**
  - 联盟星域 → 属 **雨之仙界**
- **天逆珠来历**：不属于联盟星域，最早出现在罗天星域；无人知其如何出现，只知其现世刹那，罗天星域所有顶峰修士同时感受到远古仙域的存在，几乎为之疯狂。随后珠子诡异消失；无数年后线索表明它出现在雨之仙界的联盟星域。
- **古传送阵**：王林指认上方传送阵为其所设，女子摇头否认由此进入联盟星域，但承认该阵**确出自罗天星域修士之手**；此阵已废弃，**非有「罗天石」不可开启，仙玉亦不行**。

## 五、交易与识破

- 女子开价：带她通过漩涡进入罗天星域、送她回家，她便求先祖帮王林复活珠内残魂（李慕婉倩影残魂）。
- 罗天星域设定（据女子自述）：与联盟星域不同，**没有宗派，只有修真家族**；她的家族是**东临星上的向家**。
- 王林试探后判定：她言之凿凿称「有天逆珠定可通过漩涡」，必然隐瞒大量事实，分明是要把自己引进罗天星域。见到罗天星域的刹那，王林已恢复冷静。
- 王林不再废话，抓画轴不入漩涡而向上飘去；女子沿途劝说，他一语不发，散开元神与肉身、与吸力融合上行。

## 六、灭迹与三重封印（此卷终）

1. **毁传送阵**：回到凸出大石处，元神化电光透入石内，石块寸寸碎裂、被吸力吸落，此处遂与上下崖壁一模一样，再无出奇之处。
2. **深埋画轴**：进入二十丈外的裂缝，将画轴掷插墙壁，掐诀布下层层禁制笼罩四周。理由——此画轴以他之力无法毁灭，而其内女子知晓太多秘密，**既不能杀，便永久封印**。
3. 女子恶毒放言：「没有我，你珠子内的残魂永生永世都将再无复活之日。」声音在封印下渐弱直至消失。
4. 封印持续**数月**，无数禁制组合成可怕的巨大封印；随后一掌拍塌一丈大小的裂缝口，将画轴深埋其中，外界看来毫无异常，即便有人来到此地，在对抗吸力之下也无暇细查这看似一致的墙壁。
5. **三次镇压**：王林并未即刻离开，而是在远处闭目守候。
   - 数日后封印之地传出微弱波动 → 王林召出**仙卫傀儡**，喝一声「封」，傀儡掐诀按下浩然封印，隐约传来一声惨哼；随后两者同时打出封印透入墙壁深处。
   - 数月后波动再起 → 又一次彻底封印。
   - 三次封印之后，王林方才腾空离去。

## 七、王林的判断（本卷收束）

- 画轴女子曾拥有极强修为，被人封印于画轴之内，本应一生无法脱印而出；
- 当年在**仙遗之地**，她吸收了**三祖的符兽**，才因此获得一丝神通。

## 关键伏笔

- 罗天星域 / 东临星向家 / 罗天石 —— 通往新星域的钥匙与目的地。
- 仙域 → 风雨雷电四大仙界 → 各自对应星域 —— 宇宙层级设定首次揭示。
- 天逆珠源出罗天星域、携远古仙域气息。
- 天运子等人即将降临妖灵之地（卷末悬念「老怪降临」）。

# 第618章 出深渊·蚊兽重逢与成年蚊兽自绝

## 一、上升途中的盘算（画轴女子与罗天星域）

王林在深坑内上升时，心中对**画轴女子**做出判断：

- 此女这些年已知晓他太多秘密，若非身处深渊内的特殊之地，本不会道出原委，而会继续默默等待恢复之日。
- 留她在身边是隐患，日后必受连累；她引王林去**罗天星域**，恐怕别有目的。
- 「她之前所说，十分里只能听三分」——但**罗天星域**一节应当不假，否则她不会要求王林带她过去。

由此定下行止：

1. 先往**东临星的向家**打听此女身份——即便向家与她无关，也应能问出来历。
2. 她自称家族老祖可使**李慕婉（婉儿）**复活，无论真假，值得一看。
3. 甩开画轴女子后再去罗天星域，则无人知晓他拥有**天逆珠**。

## 二、对妖灵之地与洞府的判断

- 妖灵之地处处危机，**天运子**等人随时可能降临；一旦碰面，以王林当前修为无法抵抗这些「修为我无法想象的存在」。
- 但**最后一块令牌在王林手中**：没有他，天运子等人休想进入真正的洞府；即便从**贪狼**处得知令牌下落并最终确认，那时王林已离开此地前往罗天星域。
- 结论：待日后修为提高、可与天运子等人平等对话之时，再回来一探洞府奥秘。
- 王林轻叹：走之前尚有一些事要处理，「这一走，不知何时才能回来」。

## 三、冲出深坑

- 深坑吸力极大，王林虽已化身为吸力的一部分，仍能感到上方另有一层压力阻其上行。
- 手段一：拍储物袋放出**七星剑阵**，环绕身外形成大量推力。
- 手段二：剑阵效果渐差后，身后虚影一晃，**仙卫傀儡**幻化为黑色飓风继续加速。
- 成功脱困的三因：与吸力融为一体、七星宝剑与仙卫傀儡之助、**深坑吸力恰逢变弱**。作者点明该吸力变化莫测、时强时弱，若在至强之时，王林纵有上述优势也难冲出。

## 四、紫色蚊兽重逢

- 深坑出口处蚊兽群呼啸，其中一只**通体紫色的蚊兽**原本双目萎靡，此刻骤然明亮，撞开同伴直冲深渊而下，任凭全群呼唤也不回头。
- 此兽正是与王林阔别**数十年**的坐骑，见到王林如「离开父母多年的游子突然见到亲人」，托起王林一举飞出深渊。
- 出坑后四周密密麻麻数千蚊兽以通红双目盯着王林，凶光浓浓；王林注意到蚊兽数量比多年前少了一大半。

## 五、神识读取记忆：当年之变

王林右手按在蚊兽头顶，神识流转，读出往事：

- **周佚与贪狼之战**进行到一半时，从**火妖郡出口**降临一男一女两名修士。
- 二人修为极强：一抓便擒住贪狼，同样以神通拿住周佚。
- 对周佚**并无恶意**——那男子看到周佚的瞬间，眼中露出**惆怅与怀念**。
- 蚊兽群并非灭亡，而是被这对道侣以神通之术取走绝大部分。
- 王林的蚊兽因见事态不妙，以一种奇异方法改变身体，伪装得与寻常蚊兽无异，才幸免于难。

读罢，王林**面色阴沉**。

## 六、水妖郡潮汐入口的诀别

- 王林拍蚊兽，未飞向火妖郡出口，改由**水妖郡入口**离去——因其化身吸力，任何地方都可以是出口。
- 沿途数千蚊兽跟随，时而发出不舍与绝望的嘶鸣，似在劝阻紫色蚊兽留下。
- 水妖郡潮汐入口处紫光冲出，两千多蚊兽呼啸围拢，目光尽落在紫色蚊兽身上。王林起身，**元神散出电光透体而出**，目光如电；紫色蚊兽随之厉啸，威压逼得蚊兽群缓缓散开。
- 王林打开储物袋缺口相邀：先有一只化灰芒钻入，其后陆续有蚊兽跟进，但仅约**三分之一**进入，约三分之二沉默不动，目送王林与它们的王消失天边。
- 随后留下的蚊兽齐声悲鸣，身子一一崩溃，**自断心脉**，从半空坠落潮汐入口内。远处紫色蚊兽身子一颤，回望潮汐深渊，眼中同样悲哀；王林轻叹，抚摸其头。

## 七、设定要点：蚊兽的族群法则

- 蚊兽**除幼兽外，成年后绝不可能被收服**——进入储物袋的全是幼兽，自绝者全是成年蚊兽。
- 蚊兽世界的规矩：**若被王抛弃，唯有一死**，除非有新的王出现。

## 八、待处理线索

- 离开前尚有「一些事要处理」（未点明）。
- 前往东临星向家，查画轴女子来历与复活李慕婉之说。
- 最后一块令牌与真正洞府，留待日后修为足够时重返妖灵之地。

# 第618章 封洞府·辞别炼魂部落

## 一、安抚蚊兽
- 蚊兽神情失落，王林心中不忍，腾空而起将其收入储物袋。
- 袋中另有数百蚊兽同伴与雷蛙作陪，王林认为唯有如此才能让它慢慢从悲伤中恢复。

## 二、传送回洞府并彻底封印
- 王林身在半空，抬头望蓝天白云，久未见此天空，沉默少顷。
- 一拍储物袋取出一枚**水晶**，神识融入其内，晶芒笼罩，人与晶芒一同消失——瞬间抵达洞府。
- 洞府内**尚有众多未破解的禁制**。王林目光闪动，喃喃自语：“等我下次回来之时，此地的所有禁制，都将被我一一破解，打开这洞府的奥秘。”
- 决定与执行：
  1. 双手掐诀**封印洞府**；
  2. **破除传送阵**，使此后无人可入，**即便是血祖也再无法进来**。
- 离去之际，洞府之门上**洞府之灵**幻化而出，遥遥看向王林，一言未发。王林转身，捏着水晶离开。

## 三、天妖郡·炼魂部落的告别
- 王林现身炼魂部落外并踏步而进；族人见到他的瞬间有一丝恍惚，随即惊喜、连连叩拜。
- **未收走**炼魂部落族人收集的魂魄。
- 把**十三**与**欧阳华**叫进**宝塔**内：
  - 嘱咐一番；
  - 留下一些功法，**其中包括十三所修的巨魔族后续功法**。
- 随后踏着虚空离开。二人跪地磕头，眼中露出悲哀——王林虽未明言，但他们有一种“此生怕是很难再有相见之日”的感觉。

## 四、余音：妖将府
- 天妖郡妖将府中，**陈涛**同样吐纳；经多年疗伤已恢复，修为甚至略有精进，距（某境界）已不再遥远（原文此处残缺）。
- 少顷，**石萧**睁开双眼（片段在此中断）。

- **陈涛**：与石萧同处一地，同样睁开双目，眸中一片深邃。身份将由石萧举荐为**妖将**。

## 石萧的许诺

石萧平淡开口：

1. 明日上奏**妖帝**，举荐陈涛为**妖将**；
2. 让陈涛前往**龙潭**感悟——虽非真正的传承，但在那里感悟“对你来说也是好处众多”。

陈涛道谢，并点明：“明天，陈某就要称呼你为副帅了。”

## 副帅之位的旧怨（约100多年前）

石萧傲然一笑，道出旧账：

- 副帅之位在**100多年前**本该属于他；
- 被**莫厉海**以卑鄙手段抢走；
- “若无那卑贱的王林，莫厉海，又算得了什么” —— 石萧认定莫厉海得位与王林有关。

## 关于王林的争执

陈涛平淡回应：“王林，是我师弟。”

石萧眉毛一挑，冷笑列出对王林的指控：

- 天妖郡与**火妖郡**内大战之时，王林趁后期火妖郡空虚，**抢走了石萧等人的功劳**；
- 虽说帮助了**古妖大人**，但此举“为我等不耻”；
- 王林**已失踪多年**，“现在恐怕尸骨已寒”；
- 即便陈涛记得他是师弟，“恐怕此人，早就不记得你是他师兄了”。

陈涛沉默不语。

石萧眼露嘲讽，更进一步：“我说他卑贱，还是轻的，若他没死，我定要杀他，让他知晓，在这**妖灵之地**，身为修士，到底该如何看待自己的身份。”

# 第618章 踏月斩石萧·妖灵之门提前开启

## 一、月下诛石萧

- **出场**：一道黑色身影现于天空，背负一轮明月，踏月光缓行而来；身上阵阵电光游走，噼里啪啦作响。陈涛一眼认出：「你你是王林」。
- **石萧的姿态**：石萧冷喝「好大的胆子，敢闯我府邸，三息内，立刻滚开，否则的话，斩」。其近年修为暴增，体内妖力浓郁，实力**相当于修士之中的问鼎初期**。
- **王林的理由**：落地后平静开口——「昔曰答应一人，要取你姓命，今曰，便是为此而来」。此为**履行旧日承诺**的了断，具体受托者本章未言明。
- **交手过程**：
  1. 石萧化作残影直冲，双手掐诀欲施神通。
  2. 王林**身子未动**，月光下其身后影子狰狞延伸，化作黑影冲出地面，刹那间与半空扑来的石萧**交错而过**。
  3. 陈涛欲踏出相助，黑影一道凌厉目光扫来，陈涛身子一颤、**体内元神一缩**，生生止步，冷汗淋漓，骇然道出神通之名：**「阴阳虚实」**。
  4. 黑影缩回王林脚下重化影子；石萧砰然坠地，双目始终睁着、犹带余留杀机，但**生机与体内一切已全部碎裂**。
- **离去**：王林转身而去，明月下衣衫飘动、发丝飞舞，好似踏月远飞。陈涛耳边回荡王林传音——**「小心，师尊」**——他怔怔望天，许久无言。

> 提示：这一句留言暗示陈涛的师尊有问题/有危险，是本章埋下的伏笔。

## 二、王林收尾，赴潮汐深渊

- 王林在**妖灵之地**处理完一切琐事，出现在**潮汐深渊入口**。
- 临行回望大地，目光最终落于天空，视线**穿透天之临界**，不断攀升，延伸至**东海之上**——与下一幕的东海妖灵之门形成呼应。

## 三、东海妖灵之门外：三大神通修士的不安

列阵者：**天运子、凌天候、血祖**，以及**八个老者**。众人正等凌天候开启妖灵之门。

- **提前数十年入门**：他们进入妖灵之门的时间，比原定**提前了数十年**。
- **天运子的异感**：十多年前打坐时忽觉心惊肉跳，此感**数万年未有过**。源头来自妖灵之地——来自他当年留在弟子**王林**身上的**烙印被强行驱除**。开门刹那他又轻咦一声、看向妖灵之门、眉头微皱。
  - **先例**：此并非首次烙印被驱除，很久之前有一个叫**孙云**的弟子亦曾做到。
- **血祖的不安**：源自其女儿**姚惜雪**，且随时间流逝越发浓烈。以他的层次，不安绝非空穴来风。姚惜雪是他**唯一的女儿、唯一的亲人**，为此他可以不顾一切——故天运子提议提前入妖灵之地时，他**第一个赞同**。
- **凌天候的怒火**：**剑肖十二子的本命神灯已熄灭九盏**（原文「剑肖十二子」「本命}申灯」，疑为「剑霄/剑宵十二子」「本命神灯」之误植）。怒火压在心底，他准备入妖灵之地后找**贪狼**好好询问。
- **总纲式点题**：这三人此刻并不知晓，让他们三个高高在上的大神通修士苦恼的事情，**全部来源于一个人**（即王林）。

## 四、收束

凌天候一掌按下，**打开妖灵之门**，大袖一甩，踏步而入。（未完待续）
