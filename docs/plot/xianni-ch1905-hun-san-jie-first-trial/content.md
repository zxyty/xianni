# 第1905章 魂三劫！

## 一、血影劫（内三劫·第二劫）

- 王林跃空直扑蝎庙上空、层层波纹内的**千丈大鼓**，右手骨阴刀寒气凌厉，似可冰封一切。
- 鼓声既震其体内骨脉，又在大鼓四周波纹中幻化出**近千红色铠甲血影**，如血色仙兵，带浓煞气扑向王林。
- **血影劫特性**：每个血影修为不弱于空玄；不死不灭，摧毁后立即从波纹重新凝聚；每死一次修为增强，拖延越久越强，可生生抹灭渡劫者。
- **常规应对**：寻常修士罕有连续度过内三劫者，多在勉强度过斩离劫后强行退出玄劫，待若干年后准备充足再来度血影劫。
- **王林的破法**：双目骤爆滔天金光，散出**天威镇压之力**（由绿袍老者以仙极剑碎片融合变化而出，此前连蝎魂都被其镇压）。目光所过之处血影齐颤停滞，感如天威化金剑轰入体内，再走半步即被摧毁。王林一句「滚回去」如天威怒吼，近千血影本能恐惧、倒卷数百丈重新融入波纹消失。
- **意义**：古往今来度此劫者用过各种方式，从未有人如王林这般不曾出手，仅凭一道目光、一句话就令血影劫自行崩溃。

## 二、斩碎千丈大鼓，崩溃内三劫根本

- 血影消散刹那，王林如长虹直扑大鼓；大鼓正欲发出第三声鼓音。
- 王林骨阴刀一斩，身后**五行真身**同步幻化重叠之影，刀影一化为三，紧随其后轰落——远看如**四把开天之刀**斩灭天地。
- 第三声鼓音虽起，却被刀啸轰鸣完全淹没；大鼓中裂、四分五裂化作无数碎片倒卷，掀起狂风大浪。
- **结果**：内三劫第三劫尚未显露，其根本已被这一刀崩溃。

## 三、王林的判断与状态

- 已连续度过**六次玄劫**，神色转为凝重，不复此前轻松。
- 判断：**内三劫强于外三劫数倍不止**，已需动用镇压目光与骨阴刀；按此推演，**最后三劫将远超内三劫**，是修士成就**空劫大尊**的沟壑。
- 落于蝎尾，骨阴刀缩回血肉之间，抬头静待最后三劫。

## 四、绿袍老者的遗产（补述）

绿袍老者留予王林者，除天威镇压目光、骨阴刀、坚韧身躯外，另有：

- 一条以**仙祖发丝**凝聚而成的**经脉**；
- 该发丝蕴含浓郁至极仙气，可**代替仙族血脉**，使王林在某种程度上**仙古同体**（虽不完美，但可令其呼吸间流转精纯仙力）；
- 这股仙力使王林得以动用一件**在洞府界内几乎无敌的法宝**，此宝一出可威胁真正的**空劫初期**修士。（本章未出手，仅铺垫）

## 五、第七劫：十息枯神劫（魂三劫·第一劫）

### 劫象

- 天空阴暗云散，天幕内透出幽光，凝聚成一个**鬼脸状印记符文**，散发如同「规则」一般的气息，似为天地运转的一部分。
- 王林感到若隐若现的危机，却寻不到危机的显露方式。

### 杀机

- 王林元神原本饱满盘膝运转，**一息之内枯萎小半**；此劫名**十息枯神劫**，元神在**七息内完全枯萎**，形神俱灭。
- 此劫无声无息、杀人于无形，无数年来死于此劫者极多。
- **符文为关键但无法毁灭**，会一直存在，直至修士死亡方才消散。
- 数千里内被玄劫威压笼罩：外人无法进入，**天地之力亦无法被吸收补充**——断绝了以吞噬天地之力拖延元神枯萎的常规路径。

### 王林的应对过程

1. **第一息**：元神枯萎小半，心神一震，第一次深刻感受玄劫可怕。
2. **第二息**：张口猛吸，四周天地之力虽动却无法吞噬；元神枯萎更重。
3. **第三息**：身化长虹扑向符文，一拳轰出，身后现**道古虚影**同施一拳——拳劲直接从符文内穿透，无法伤其半点，符文如虚幻之影可见不可触。元神已近乎枯萎一半，神色阴沉。
4. **推演**：此地数千里吸不到天地之力，但**尚有一团精纯至极的天地之力存在——蝎魂**。
5. **第四息**：身形一晃，双手按在蝎庙之上，蝎庙轰震，庙内传出凄厉嘶吼。
6. **第五息**：蝎庙散出魂雾，直奔王林双手，化作天地之力被其疯狂吸入体内。

### 蝎魂来源梳理

- 蝎子分魂此前被王林**斩成六份**：其中**四份被王林吸收用以冲击空玄**，余下**两份融入蝎庙**隐藏。
- 平常王林难以寻得，但此刻修为暴增且已吸四份气息，**气息相引**之下立即从蝎庙内吸撤出余下两份。
