# 第1936章 半丈的

## 一、断掌显仙祖之面

- 光幕外的模糊身影面孔无皮、血肉一片；王林当年在天牛洲吸收地火主脉时曾陷入奇异状态，看到仙祖封印天牛的一幕，比对之下，此身影面孔与仙祖极为相似。
- 身影剧烈咆哮撞击光幕约半个时辰，光幕自五十丈缩为三十丈，王林与海子天尊被迫靠近；随后身影退入漆黑不见踪影。
- 海子天尊判断：「这光幕坚持不了多久。」
- 王林隐隐感觉断掌内藏有隐秘之事，否则不会幻化出仙祖的样子。（王林并未把「认出仙祖」说出口，海子天尊并不知情。）

## 二、海子天尊转述的仙祖旧事

源自其师尊久帝大天尊：

1. 很久之前仙族大地只有一块大陆。
2. 仙祖封印了一尊尊自天外来临之灵，才有了如今的十二洲。
3. 封印第七十二灵后，仙祖失踪，去向不明，连其后人也寻找多年无果。
4. 久帝大天尊曾偶然自语，怀疑仙祖并非失踪，而是当年遇到了什么变故；具体不肯详谈。

## 三、王林的推衍链

- **断掌归属**：这断掌很可能就是仙祖的左手 → 谁砍断了仙祖的左手？
- **与仙极剑的关联**：仙极剑崩溃传闻众多，其崩溃原因会不会与这断掌有关？
- **封印疑点**：封印存在于此无数年，且此地属道一大天尊控制区域，以大天尊修为不可能毫无察觉，为何如今才出？
- **结论（令王林自己心神震动）**：包括道一在内的几位大天尊早就知晓山海树封印的古怪与端倪，却一直按兵不动。

## 四、诱饵局：三位大天尊的算计

| 角色 | 布置 | 用意 |
|---|---|---|
| 久帝大天尊 | 二百年前令弟子海子天尊离中州、以南州山海为洞府长住 | 以弟子为诱饵，默默吸引山海树灵、引出断掌；手法相对温和 |
| 武封大天尊 | 令麾下天尊指点王林「山海内有木灵」 | 既验证王林身份来历（是否真正的古国之修），又借其引出断掌；不在乎其死活 |
| 道一大天尊 | 山海为其领地，却任由此局发生 | 立场不明，王林目露寒芒，视为最大未知数 |

- 王林反问「你师尊既是久帝大天尊，为何远离中州住在山海」，海子天尊立刻警觉反问「你怀疑我」，王林内心赞其「好聪明的女子」，不作解释；海子天尊沉思后自行想通，坦承是师尊安排，并称哪怕为诱饵也无怨念——师尊养她长大、教她修道。
- 海子天尊反疑：为何武封大天尊会打王林的主意，巧妙地引他来此。
- 王林的自评：他的来历在寻常修士乃至天尊眼中看不出端倪，但对大天尊而言没有秘密；他们不在意他是否来自洞府界，在意的是他是不是真正的古国之修。
- 王林的底牌：师尊敢让归一宗知晓其身份必有信心，刨除这个破绽后，无人可知他是玄罗大天尊的唯一弟子；此身份不露则无碍。
- 王林另存疑问：久帝大天尊既以海子天尊为诱饵，此女必有奇异之处；断掌与仙族之间到底藏着什么秘密，能如此吸引大天尊。
- 王林处世准则：不管未来如何，提升战力与修为才是日后解决一切事端的根本 → 继续闭目吸收山海树灵。

## 五、七年困局与光幕缩至半丈

- 又过三年，连同之前时日，二人被困已达七年。
- 三年中断掌所化模糊身影出现九次，每次怒吼咆哮轰击光幕，光幕九度缩减。
- 第九次轰击时光幕传出「咔咔」之声，范围只剩三丈——王林骨阴刀展开即有三丈之长，可见其小。
- 三丈时王林可闻海子天尊体香，海子天尊亦能感到王林体温；海子天尊无法继续打坐，面泛红晕，看王林的目光渐趋复杂，并起了羞恼：范围太小，光幕随时可破，一旦再缩……
- 断掌虚影再度出现轰击，裂缝在光幕上扩散弥漫，范围一路缩减：三丈 → 两丈 → 一丈 → 半丈。
- 半丈时海子天尊几乎整个人贴着王林右侧，隔衣可感体温。王林自陈一生除有限几个女子外极少与陌生女子如此接近，加之七年相处、此女是堪比木冰眉的绝色，令他暗叹「不能这么下去了」。
- 章末：断掌不知为何停止轰击，四周死寂，黑暗中只余海子天尊呼吸声，她吐气如兰轻唤：「王……王林。」
