# 第八卷 联盟隐秘 第1012章 仙府开启

## 一、贝罗出关：洞府开启的变故

- 贝罗（妖异之脸）复盘：**青霖**的算计精妙，但其洞府开启刹那出现惊人变故——若贝罗此前未吸收其他妖灵，此刻必被死死压制。
- 贝罗判定：变故已无关紧要，即便妖灵之地再次恢复成当年模样，也无碍洞府打开；此次「我一定会成功」。
- 出关宣言：「**古魔、仙帝**，我贝罗来了」——狰狞扭曲中冲出水潭，化作妖芒直上天空。
- 关键设定：**仙风扫过贝罗身体时被当场吞噬，反化作妖气**，使其妖芒之光更盛。（妖仙相克在贝罗身上呈单向吞噬）

## 二、仙风横扫仙灵天境：两处存续之地

仙气/仙风席卷仙灵天境，对妖气有消散之效。文中明确保存下来的有两处：

### 1. 妖郡燕京 —— 姚惜雪破关
- 姚惖雪于燕京下方盘膝，仙风扫过刹那抬头，感受到仙气后身体颤抖、目露幽光。
- 磅礴妖气爆发成庞大漩涡，将扫身的仙气**全部卷入、迅速搅碎吸收**（与贝罗同类手段）。
- 身形一晃消失，现身半空：全身妖气弥漫、看不清相貌，气息冰冷浓郁；略一停顿即化妖芒直奔前方。

### 2. 火妖郡 / 炼魂宗 —— 数百万弟子护石像
- 火妖郡即今之炼魂宗；宗内有**王林的黑色石像**。
- 仙气欲消散石像内妖气，石像发出尖锐啸声。
- 数百万炼魂宗弟子从啸声中感受到焦急与含义，**无需带领**齐施魂幡，无法想象数量的魂魄弥漫都城，层层防护笼住山谷中的黑色石像。
- 都城黑雾弥漫、万魂呼啸对抗仙风；仙风之力太大，炼魂宗如怒浪孤舟，随时可能崩溃，弟子面露惶恐仍咬牙坚持。
- **转折**：冲击中的一部分仙风「仿若拥有自己的意志」，不再缭绕炼魂宗，反而在其四周化作漩涡，**帮炼魂宗抵抗其余三股仙风**。
- 融合为一的三股仙风一顿，未强行冲击，从四周绕过呼啸而去；护宗的仙风漩涡迅速收缩跟上，再次融入其内一同横扫天地。

## 三、四道光柱与防护之罩重启

- 仙风弥漫全境时，**东西南北四道光柱**散发绚丽光彩并射出光线，天空笼罩于光芒中。
- 四柱之间以光线彼此连接，在仙灵天境内交织出一层防护——**昔日仙灵天境本应存在的防护之罩再次开启**。

## 四、九龙阵法现世（本章高潮）

- 位置：四道光柱之间的正中位置，即**仙灵天境最中心点**，原为山脉纵横之地。
- 防护罩重开之际，大地震动、山脉落石、尘埃遮天。
- 一条山脉碎石落尽，内里紫光大盛，**万丈之长的紫龙**咆哮升空，龙目透出无尽冰冷、极为威严。
- 随后山脉接连崩溃，紫龙陆续冲出，片刻间**九条紫龙**环绕半空，龙啸如永恒之声。
- 九龙盘旋交错，紫光闪烁中化作**圆形阵法（九龙阵法）**；阵成刹那，**整个仙灵天境仙气暴增**，漫天紫意远距亦可清晰见到。

# 第939章 第五座洞府开启

## 二、云仙道侣与周佚虚影

- **云仙道侣**：男名王巍，女名胡娟。二人把持一座洞府，长年从未外出。王林当年从姚惜雪处得知有这么一对道侣存在，此刻立刻对上号。
- **修为深不可测**：王林看不透王巍修为，胡娟更是高深莫测。
- **周佚虚影**：王巍身后跟随一道虚幻身影，王林一眼认出正是**周佚**。王林现身刹那，该虚影一震，仔细端详王林，目露**感慨与欣慰**。王林目光看似随意扫过虚影时，周佚双目微不可查一闪，王林立刻明白——二人间存在未言明的默契或旧交（王林早年与周佚有交集）。

## 三、王巍与王林的交锋（试探与赞赏）

1. 王巍开口点破：“你就是拿走了第四座洞府钥匙的王林。”王林平静承认：“正是。”
2. 胡娟对王巍笑道：“**当年我们的打赌，你输了**。”——暗示二人早年就王林（或其禁制之主的身份/成就）打过赌。
3. 王巍虚空一挥，掌中多出**一棵小草**，指为王林当年布置在**潮汐深渊火妖郡入口处**的禁制。王林一眼认出自己的手笔，不动声色略一点头。
4. 王巍长叹赞赏：“**后生可畏，我如你这样的年纪，尚无法布置出这样巧妙的禁制**。”王林抱拳称“前辈谬赞”。

此段确认：王林当年在潮汐深渊火妖郡入口处布下的禁制，早已被云仙道侣注意并留存样本；其禁制造诣被把持洞府的强者当面认可。

## 四、后续到场者

- **村姑般的中年美妇**：率四名弟子御长虹而至，其中有**千琴**与**疑似昆虚圣女**者。她先见过天运子，再仔细打量云仙道侣并露出善意微笑，最后对王林略一点头，随即走向**虚空子**身边。天运子神色如常，**眉头却皱了一下**——其站队令天运子不悦。
- **葫芦老者**：坐在葫芦之上，目光一扫众人，见到云仙道侣时**瞳孔一缩**，沉默片刻后站到**天运子**旁边。
- **冰冷黑衣男子**：一语不发站到王林一行旁。王林与其从未交谈过，只隐约感到此人性情孤僻冷傲、不喜与人接近。此人首次开口，仅平静道：“**带我进去**。”王林略一沉吟，点头应允。
- **妖焰人影**：九龙阵法已在紫光中缓缓转动时，一股浓郁妖焰轰然而至，化作人影，周身妖气缭绕，容貌乃至男女皆不可辨。其出现瞬间王林心神一动，二人对视，**仇恨的目光如利剑直射王林**；但此人未发一言，转而站到天运子旁边。此为王林在此界的一处未解旧怨伏笔。
- **贝罗**：最后现身，身穿红衣的光头青年，相貌极为英俊、隐透妖异之美，头顶无一丝头发，身上仙气缭绕。第一眼即看向王林，笑称“**王老弟，我来晚了**”，王林答“**不算晚，此刻正好**”。贝罗一到，**虚空子瞳孔猛缩**，**云仙道侣目中寒芒微闪**，唯**天运子嘴角露出微笑**——贝罗的立场明显偏向王林/天运子一方，且其分量足以震动虚空子。

## 五、洞府开启

九龙阵法运转，仙气环绕，组成阵法的**九条紫龙**声声咆哮，阵上紫光蓦然剧烈闪烁，覆盖方圆数百丈。光芒转瞬即逝，众人身影尽数消失——**第五座洞府，开启**。

## 六、要点与伏笔

- 王林已明确被各方认定为“拿走第四座洞府钥匙”之人，成为焦点。
- 周佚以虚幻身影形态随于王巍身后，身份与处境（从属？寄魂？契约？）未明，但对王林态度友善。
- 天运子与虚空子两派拉锯：村姑美妇归虚空子，葫芦老者与妖焰人影归天运子，贝罗与黑衣男子倾向王林。
- 妖焰人影对王林的深仇未解，为洞府内的冲突埋下引信。
- 王林早年的禁制造诣（潮汐深渊火妖郡入口）在此被公开印证。
