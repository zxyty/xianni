# 第1541章 有些无耻了

## 一、开局：辨认役灵印的差异

王林凝重盯着天空幻化而出的巨大掌印——掌纹清晰如真手，四周有一片片波纹向八方回荡，非虚幻之物。

与王林所知役灵印的对比：

| 版本 | 掌纹 | 边缘波纹 | 缺陷 |
|---|---|---|---|
| 王林自悟版 | 模糊，无清晰掌纹 | 无 | 出现后疯狂吸收天地之力，越大越难操控，最终必脱离掌控 |
| 水道子所施（真传） | 较清晰但不及疯子 | 无 | 无王林版的失控缺陷 |
| 疯子所施 | 每一道掌纹极清晰 | 有，形似玄武最强之术的「震」 | 未见 |

王林明白，自己版本的缺陷源于「非得传承、乃自行明悟」。

## 二、推衍所得的役灵印原理

王林在掌印笼罩之下反而不避，任其落身以体察其变化，得出：

- **震力在外**：以震动之力震动天地，如奴役一般；
- **路径一**：奴役天地元力，直接化作掌印；
- **路径二**：奴役天地之力凝成一个「灵」，此灵再被仙力弥漫，即成役灵印；
- **缺口**：仍有细节不清晰，需要**役灵印传承的绝密口诀**。

## 三、激将：以轻蔑换数百遍演示

1. 疯子仰天大笑炫耀，表面向黑猿显摆，实则眼神扫向王林求关注。
2. 王林笑称「此神通尚可，但此术我也会，且威力强上不少」。
3. 疯子不屑，称其神通「除了我哥没人比得过」，并声明**我哥说了谁也不能传授**，还提到当年有人想偷学被他一眼看穿。
4. 王林亲自出手：抬手按天，模糊掌印疯狂吸收天地之力下落，威压狂风撕开大地沟壑；王林深吸口气连念**三个「凝」字**，掌印急速缩小、一度显出失控迹象，最终轰然落地，**整个修真星一震**，在远处大地烙出约**数万丈**的掌印天坑。
5. 王林下战书：「你若能打出同样的烙印天坑，我便承认你的神通很厉害」，并**恰到好处地露出一丝轻蔑**。

### 情绪操控节奏
- 疯子被激怒，学黑猿的姿态挥臂捶胸（他认为很霸气），开始轰击；首击只留下浅浅痕迹。
- 半个时辰、数十次后疯子气喘欲弃，一抬头又见王林轻蔑，怒而再战。
- 一个时辰、两个时辰、三个时辰……每欲放弃，王林脸上的轻蔑便更浓。
- **六个时辰**后已数百遍，疯子大汗淋漓、吐舌喘息，决定「不玩了去睡觉」；转头却看到王林脸上**一丝震惊**——信心大增，重新兴奋咆哮（心中称王林为「这小娘子」）。
- **七个时辰**后，疯子吼声嘶哑、双眼通红，终于打出与王林掌印**深度相差不多**的掌印深坑。

### 王林这一侧
- 全程打起全部精神、双眼急速闪烁疯狂推衍，右手在身前挥舞揣摩；
- 双眼充满血丝，浑然忘记一切，眼中只剩那一遍遍的役灵印；
- 感叹此等造化机会「就算师徒之间怕也很难做到」；
- 最终脑海内刻下一个越来越深刻的清晰掌印。

## 四、结尾：更无耻的一手

- 疯子邀功，王林答「这个我需要亲自检查一下」，起身走到深坑外细看很久。
- 疯子偷觑其表情，见王林由震撼转为平静，最终**轻蔑再现**。
- 王林反诬：「没想到你居然如此阴险，明明神通无法比得过我，却暗中做了手脚」「你这几个时辰用的神通，与最早那次并非同一个」，随即转身盘膝而坐，看都不看一眼。
- 疯子憋得通红、冲上前大吼「我没有，本王没有」，眼中隐隐出现水汽，觉得自己辛苦数个时辰竟被说成欺骗，**非常非常冤枉**。

## 五、要点提炼

- 这是一次**以情绪操控换取神通细节**的典型王林式行事，章名「有些无耻了」即指此。
- 役灵印的关键短板已定位：缺**传承绝密口诀**，故王林版本必然失控。
- 玄武之「震」与役灵印之间存在术理关联（波纹=震动之力）。
