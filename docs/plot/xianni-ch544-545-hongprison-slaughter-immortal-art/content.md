# 仙逆 第571章「强颜」/ 第572-574章「杀戮仙诀」

## 一、洪牢入眼（第571章前段）

- 王林在洪城夜色中缓行，随行两名军士不解其整日只在河道边发呆踱步。
- 王林注意到洪城内一片罕见的漆黑建筑群，被死意与怨气笼罩——即**洪牢**，京都四大牢狱之一，关押重犯，把守森严，无令牌不得入。
- 王林察觉洪牢内有数股强大妖气，强悍程度不弱于莫厉海。

## 二、与莫厉海谈条件

- 王林回莫府直言：「我要去洪牢」，欲留**一个月**修炼。理由：**「我需要杀戮」**，而在天妖城内大量杀戮会引起不必要麻烦；并加码承诺「若我功成，在助你时，把握更大」。
- 莫厉海追问「你确定」，王林右手一挥，指缝射出**五道杀戮之气化作五道苍龙**：
  - 莫厉海一拳打散，灰气**瞬间重新融合**再成五龙，杀气笼罩四周，惊动莫府家兵；
  - 第二次冲过其拳锋，最终被莫厉海身前七寸处无声浮现的**妖力之幕**弹回，但妖幕剧烈晃动。
- 王林反问：「若此灰气超过数千，你还能这般轻易挡下么」
- 莫厉海结论：一个月做不到，**七天可以**；洪牢内重犯上万，足够七天之用；三日内给准信。

### 莫厉海的私下评估
- 「当初以那十三之命换来此人相助，却是做对了。」
- 灰色杀气之利胜过一些妖剑；更关键的是灰气内有他无法理解的变化，**竟可引动他体内生机**；若真成数千「极为可怕」。
- 决断：**不与王林为敌，保持现有关系为佳**。

## 三、三日琴音与道心洗礼（本章题眼「强颜」）

- 当夜王林不修炼、不吐纳、不思杀戮仙诀，独坐院中，携古妖城美酒对月独饮，耳边始终萦绕画舫琴音。
- **王林的自述与悟道**：
  - 「我王林十六岁学道，时至今日，却是早就忘却了岁月，不知具体。」
  - 「修道者，逆天而行，注定要一生孤独」；「一生孤独，方可有一颗求道之心」。
  - 核心道论：**心无感动而修天地不仁之道，则己身亦不仁，那不过是顺天而行；顺天者为天地宠儿，宠儿背后却是蝼蚁之身。我之道，以心中之感动逆天而行、逆仙而修，求的不仅是长生，更是摆脱背后的蝼蚁之身——此谓之「逆」。**
- 醉后天明，王林将昨夜一切深埋心底、封印于触摸不到之处。
- 此后三天，王林每日清晨赴河道，只等画舫路过时那段短暂琴音；悲伤琴音穿过其封印的记忆进入心底深处。这三天他**忘却拓森之危、忘却莫厉海之约、忘却自己对问鼎的期待**，经历一场「心的洗礼」。
- 他始终不曾看那女子正面——「只需要一个背影，一缕琴音，便已经足够」。

### 明萱与「强颜欢笑」
- 王林离去转身之际，画舫女子回头望向河道——**她眼前始终一片黑暗（目盲）**，却「看见」了那男子离去的身影。
- 一个平淡不容拒绝的声音唤她「**明萱**」，斥其琴声太悲，令她换曲。对她而言那声音「代表的是天，是不可抵抗的命运」。
- 她颤抖着改弹阳春三月般的欢快之曲，实则是**无声的哭泣——强颜欢笑**，悲苦被藏得极深，与画舫内的欢声笑语始终无法融合。「明萱知道，这琴音中的悲伤，无人可以听懂。」

## 四、入洪牢（第572-574章）

- 午夜，莫厉海与王林两道身影自莫府掠出直奔洪牢。洪牢阴森杀怨之气几欲滔天，如妖焰燃烧。
- 黑铁大门开缝，走出**面色阴森的驼背许姓男子**（狱将），修为相当于修士的**婴变后期大圆满**，与莫厉海同级。
- 莫厉海托付后离去，留言「王老弟，保重，希望你修炼有成」。
- 许姓男子带王林沿阴森阶梯入**地下洪牢**；越深入杀怨之气越浓，比外部所见浓十倍。他暗中试探，惊讶发现王林面色如常且非伪装，**反而有种要与四周融为一体的感觉**，遂收起小觑之心。
- 地下尽头是「井」字形巨牢，分割成上千个单独牢房，咆哮咒骂震耳；多处有禁制守护。
- 许姓男子交底：此处犯人皆其精挑细选、**一月后问斩**，「即便是全都弄死了，也没有关系」；并点明代价——**莫厉海给了他「十崩拳意」前三层功法**。王林由此确认「莫厉海这一次，的确是为我付出了很多」。

## 五、五日屠戮与瓶颈

- 犯人多因长年受杀怨之气侵袭而疯癫，向王林吐痰、辱骂、伸手抓挠；亦有沉默不语者。
- **首杀**：一名全身漆黑的犯人抓向王林，王林双指成剑点其手掌，杀戮之气钻入——犯人七窍流黑血、全身抽搐、迅速枯萎成干尸，灰气归回指缝且**更浓，但仍只有一道**。
- **机理观察**：杀戮之气入体后疯狂吸收全身生机，生机「包裹魂、血、肉等一切精气神」。
- **结论**：「以杀戮之气杀人，只能做到养气，想要使其单独分裂幻化而出，却是少了一些东西，少了一些明悟。」
- **对照实验**：对一对互相求死的犯人，王林虚空点出两点鲜红杀之（未用杀戮之气），尸体完好不枯萎，但其身上「有一丝奇异的气息，消失了」。二人眼中皆有解脱之色。
- **死气之源**：洪牢杀怨之气中夹杂的死气，并非死人太多所致，而是来源于**一心寻死却无勇气自断的牢犯本身**。
- **杀戮仙诀要旨**：「**炼生机，化烙印**」——王林修炼至今「似而非似」，时明时糊。
- 五天后，牢中上千人死去大半，死气弥漫。王林观察近千具尸体，明悟仍如隔一层纱。

## 六、许姓男子的点拨与交易

- 断语：**「因为你杀的不够，因为你的杀心不足。」** 王林五日多在研究而非融入杀戮，无法生出足够杀心，故无杀气。
- 自陈：洪牢有**狱将十人**，唯他修炼**「杀戮妖道」——以杀炼心，以心化妖**。他展示杀心时无一丝杀气外涌，却令王林全身汗毛倒立、元神不由自主而动，危险感弥漫。
- 比喻：**「出窍之剑，寒气逼人也有杀气，但比之未出窍之剑少了一层底蕴；真正的杀心，便是那未出窍之剑。」**
- **交易条件**：帮他杀掉**妖将石萧**——「以我的杀心，正面我可与之平手，但暗中杀他有十足把握」，然而他受限制无法离开洪牢，而石萧此生绝不会踏入洪牢；追加条件：**必须以杀戮神通杀之，让石萧死在杀戮神通之下**（眼中闪过至恨之芒）。
- 王林回应留有余地：「我若真的完成了杀戮的修行，你的条件，可接受」——**并未把话说全**。

## 七、通往最底层（章末悬念）

- 许姓男子揭秘：**「洪牢十狱只不过是表面。天妖城的四大牢狱，其真正的作用，是为了妖帝提供杀戮之气喂食帝剑。」**
- 真正需去之处是**牢狱最底层**，唯有在那里方可感悟杀心。
- 二人沿另一道仿佛没有尽头的阶梯继续下行，越过一个个牢狱不作停留；血腥味扑面，杀气比上方强烈十倍、百倍、千倍；前方通道不再漆黑，而是有**血光映出**。

# 血色世界杀戮修行：王林悟透杀戮仙诀与生死轮回之理

## 一、入场：许姓男子的破例引荐

- 许姓男子坦言带王林进入此地**违反了此地规矩**，要求保密，**即便是莫厉海也不要提及**。
- 交代此地来历与法门：
  - 此地由**帝君亲自打造**，常年累积之后蕴含的杀伐**可以影响人心**。
  - 入内后**不用抵抗**，只需**收住心灵，体会那杀心的凝聚**。
- 王林的真实动机：他对许姓男子的话「只听了两分」。真正促使他踏入的，是**右手指缝内数道杀戮之气自动加快旋转并微微颤动**——这颤意非畏惧，而是**杀念**。
  - 内心判断：「能引动杀戮之气的变化，此地定可让我的杀戮仙诀成功」。
  - 心境：「世间之事，有所取舍，想要得到，就要面临失去，此事必须要做」。

## 二、血色世界：结构与规则

沿血光通道阶梯下行约一炷香后，抵达一片血色世界。

- **空间性质**：看不到边界，应是**独立存在的空间**，并非真的位于天妖城之下。
- **地貌**：大地遍布浓郁血痕，其上分布**一处处血潭**。
- **住民**：潭中之人半身浸泡、闭目打坐，身上狰狞伤口诡异蠕动；王林神识一扫，**数量接近数千**。
- **核心规则（王林后续观测所得）**：
  1. 每天上演**数次集体厮杀**，所有血潭之人同时睁眼、杀气爆发、飞起互攻。
  2. **被杀者并非真死**，受此地阵法影响会**在血潭内复活**——他们实际已不能称之为人，而是一个个**提供杀戮之气的工具**。
  3. 厮杀产生的气会**被天空吸走，不知去向**。
  4. 幸存者身外凝出**血杀之雾**（初期三丈多厚），彼此互不理睬，各自独占一处血潭；后来者一到，潭内原有复活者立即让出整潭。

## 三、王林的修行过程

### 初次沉浸
- 五道杀戮之气飞出环绕其身，发出兴奋呼啸。
- 踏入血潭盘膝而坐，血腥空气入口即化杀念融入全身；**每一次吐纳都有更多杀念融入**，双目转红。
- 起初运起仙力抵抗，随后**索性放开仙力，只把心神包裹**，任由杀念流转。

### 参与厮杀
- 王林失去意识、完全融入杀念，出手即杀招：**寂灭指、化魔指**，法宝不断变化，抬手间便是人亡；甚至毫不犹豫施展**同归于尽的神通**。
- 首轮杀戮结束，含王林在内共**一百多人**幸存。

### 阶段性进境（血杀之雾厚度为标尺）

| 阶段 | 场上幸存者 | 王林血杀之雾 |
|---|---|---|
| 第一天（共四场杀戮） | 一百多人 | 数十丈 |
| 若干时日后 | 不到五十人 | 五十丈 |
| 再进一步 | 不到二十人 | 七十丈 |
| 最终 | 仅剩两人（王林 + 黑发青年） | 数百丈，如血色太阳 |

- **关键依仗**：王林把五道杀戮之气**全部化作生之烙印弥漫全身**，如虎添翼；他自认若无此物，「自己在这里会死很多次」。

## 四、银龙（帝君妖剑）与黑发青年

- **银色恶龙**在天空闪电中现身，冷漠一吸，全场之人的血杀之雾尽数脱体飞起、被其吞入口中。
- **黑发青年**（首日即如王者，血杀之雾厚约上百丈）两度冲击银龙：
  - 第一次：飞起千丈，银龙双目银芒一闪，其身崩溃、血肉模糊坠落，血杀之雾被吸收。
  - 第二次：银龙露出嘲讽，巨爪下按（如天坍之感），青年化作血肉；化血肉瞬间，其体外血雾分出一丝融入体内，随后身亡。
  - 两次皆在血潭复活，**杀气尽数消失、形同凡人**，须重新攀升。
- **王林的判断**：此银龙**恐怕就是许姓男子所说的帝君妖剑**，此地杀戮之气化作的血杀之雾便是**妖剑的食物**。
- **王林的应对**：最后一次银龙将目光投向他时，他**毫不犹豫散出血雾、身子落下**，只留血雾在半空被吸走。

## 五、明悟：杀戮仙诀 = 生死轮回

### 第一层领悟（首日后）
> 「杀心，在我看来就是**杀戮之心**；拥有了杀戮之心，才可以炼化杀戮之气。若无杀戮之心，炼化杀戮之气极难——**我之前那几次成功，只能说是巧合**。」

### 关键回忆
> 「当年我掌这杀戮仙诀时，那人曾说过，因为我的**意境是生死轮回**，所以可以修炼这杀戮仙诀。」此时终于明白；但仍有细节模糊——**杀戮仙诀与生死轮回的关联**。

### 终极明悟（大笑于血潭中）
- 杀戮仙诀：**以杀念夺人性命，炼生机为烙印**——此为**由死至生**，符合轮回之道；**取一人之死，成就一道生之烙印**。
- 这实际就是**生死轮回、生与死之间的转化**。
- **银龙吸收杀雾**同理，为的是化作体内生机；**此血色世界内的阵法，原理亦同**。
- **异象**：明悟瞬间，五道灰色杀戮之气自体外生之烙印内幻化而出，迅速凝聚，在**胸前交错形成一道灰色气旋**。

## 六、要点提炼

- 血色世界是「以复活者为薪柴、以杀戮之气饲喂帝君妖剑」的养剑场，本质是生死转化的巨型阵法。
- 王林的突破点不在功力而在**心**：先得杀戮之心，再谈炼化杀戮之气。
- 生之烙印是王林在此地长期存活的根本保障，也是最终明悟的实证载体。

# 第574-575章 帝剑的委屈

## 一、杀戮之气觉醒（血色世界）

- 气旋急速旋转融入王林胸口消失，王林气势蓦然一变，爆发出此血色世界从未出现过的**杀戮气息**。血潭中所有人同时睁眼看向他。
- 王林口出“杀戮之气”四字；**杀戮仙诀**气息扩散的瞬间，最近的几个血潭内传出砰砰之声，那些不知死去多少次又被复活之人身体崩溃，灰气自破碎肉身散出，化作一道道杀戮之气，如灰色游魂环绕其身。
- 崩溃自王林为中心向整个血色世界蔓延，所有血潭中人尽数化作灰气。
- **这些人不再复活，是真正的死亡**；崩溃瞬间眼中露出无数年来第一次清明，隐有解脱之意。
- 最终凝聚 **三千七百九十二道**灰气（杀戮之气）环绕王林飞舞。
- 唯一例外：远处血潭中的**黑发男子**，眼中一片血色、身外浮现淡淡血杀之雾，低声咆哮咬牙硬撑，成为此地唯一未崩溃者。此时血色世界内只剩他与王林二人。

## 二、银龙（帝剑）交手

- 天空霹雳，电光再化**银龙**去而复返，杀机涌现，一爪从天而降，如天地倒转。
- 王林身未动，三千七百九十二道杀戮之气化作滔天利剑冲天迎上——**银龙之爪被生生绞碎**。
- 银龙暴怒：它悠久岁月中虽曾受损，却第一次在“蝼蚁食物”一击之下败落；这一爪未出全力，但**即便妖将也无法抵抗**。身为**帝君之剑**，它有不可侵犯的尊严，决意直接抹杀。
- 银龙口吐剑芒，血色世界如崩溃般只剩这一道剑芒。

## 三、生之烙印与脱身

- 王林不迎战，化电光之影直奔此地**入口**。
- 身后三千七百九十二道杀戮之气瞬间追上，化作一个个**烙印**在眉心叠加，全部融入后延伸弥漫覆盖全身——三千多道**生之烙印**叠加，等于多了三千多层防护。
- 剑芒落身，生之烙印疯狂闪烁、噼啪作响，王林毫无停顿冲入入口消失。
- 黑发男子在其消失瞬间轻声道：“**救我一次**”。银龙无暇理会，破开虚无而去。

## 四、帝剑出阵，天妖城震动

- **燕京皇宫剑阁**（天妖城最中心）内四周空旷，地面有庞大血色阵法，一把**蛇形银剑**插于阵法中心。此剑剑鸣自地抽出，化银光穿透剑阁屋顶，带全城可感的剑气直奔**洪城**。
- 城中反应：
  - **地帅府**白袍中年男子：“是谁惹的帝剑如此愤怒，居然离开了阵限”
  - 妖将**石萧**与**孙涛**：帝剑自己飞出，此事诡异。
  - **宇城**别院中的黑发男子——即**妖将第一人墨非**（驻守火妖郡边界）——问身后两名背负大剑的道袍之人如何评价帝剑，答曰“**不次于师尊之剑**”。此人相貌**与洪牢深处血色世界的黑发男子一模一样**。
  - **莫府**内**莫厉海**见银光去向正是洪牢，心中一跳：“帝剑不会是为了王林而去吧”，随即摇头自否，但不祥预感越来越浓。
  - 皇宫贵妃楼内黄袍之人（被身边女子称**帝君**）轻笑：“莫非是吃了什么苦头，很久没看到它如此发怒了，有趣”。

## 五、洪牢脱逃与藏匿

- 王林顺阶梯疾驰而上，剑气虽被生之烙印消融，体内血气仍被掀起。
- 阶梯顶处**许姓男子**长叹：“此事有些弄大了”“不能从这里出去，快跟我走”，带王林在洪牢内七绕八绕。王林全身气息内敛不露半点。
- 二人离开不久，帝剑冲破洪牢之门钻入地底横扫寻找。
- 洪城一处民宅后墙壁裂口，王林独自走出；许姓男子留内提醒“**别忘了你我的约定**”，随后离去自语：亏了，早知此人会把帝剑引来，说什么也不会把他送去那里。
- 王林不施展仙力飞行、低头快步而行，半柱香后进入**莫府**。莫厉海一眼看破，苦笑，拍假山开洞口：“这是我闭关之处，你先进去躲躲”，随即关上假山盘膝吐纳如无事发生。

## 六、帝剑的一夜与迁怒

- 整夜天妖城银光闪烁。帝剑在洪牢未找到伤它之“食物”，怒意更重，索性把洪牢破坏一番，再冲出在城上空盘旋疯狂搜寻。
- 莫厉海整夜不眠，不断运转妖力覆盖王林气息；帝剑扫过时因其妖力散得太大而直接略过。
- 实际上即便细查也找不到：**王林已全身敛息并第一时间进入天逆珠子内，坐在李慕婉元婴对面**。
- 清晨，帝剑带浓浓不甘朝洪牢发出一道强猛剑芒，劈出**长约千丈的巨大沟壑**，泄愤后怒气冲冲回到剑阁阵法之内。
- **洪牢是天妖城四大牢狱之一**，虽被迁怒但很快修复；此后近**一个月**内，洪牢刚修好帝剑便再来毁坏发泄。

## 七、要点与伏笔

1. 王林获得三千七百九十二道**生之烙印**作为随身防护，可硬抗帝剑一击。
2. 血色世界内被囚者被杀戮仙诀“解脱”，为其真正死亡。
3. 黑发男子未死且开口求救（“救我一次”），与妖将第一人**墨非**同貌——身份悬念。
4. 帝剑归**帝君**所有，平日镇于剑阁血色阵法（阵限）之内。
5. 王林与**许姓男子**存在未言明的“约定”。
6. 莫厉海因掩护王林而与帝剑之怒产生牵连。
