# 仙逆 第1918章 身体，就是道！

## 一、炼化金尊元神：神脉增至六道

- 搜魂术对金尊修为的元神极难奏效：即便失去防护，无数年修行凝聚的元神也只能被搜出片段记忆，除非修为远超金尊方能完美搜魂。
- 王林将道魔宗宗主元神炼化入体、成为神脉，并曾试图搜魂，只得到无关紧要的记忆：
  - **未得**：天牛洲与绿魔洲交战的隐秘。
  - **仅得**：与那天尊老祖相关的一些思绪，确认对方为「道魔宗天尊老祖，道一大天尊麾下」。
- 结果：体内出现第四、第五条神脉，合计**六道神脉**。一个金尊即增两条神脉。
- 提升的不只是施法速度，还有恐怖的肉身之力——这正是**速神决（速神诀）**吸引王林之处。

## 二、九十八残影：纯肉身速度的极限

- 王林试速：身体仍盘膝而坐，阳光扭曲中先后浮现第二、第三个「王林」，直至**九十八个身影**，遍布方圆千丈，姿态各异（盘膝、飞行、行走、施法、挥拳）。
- 第九十八影出现后自语「九十八个残影，是如今的极限了」，随后前九十七影一一消散。
- 性质说明：这些身影可视为分身，实为极快肉身速度在阳光下留下的**折射残影**；靠法术神通做到不难，纯以肉身达到则绝非寻常。
- 速神诀可成**九道神脉**，但原文未言九为极限，九道之后或有新变化。王林定其为接下来要尽快修炼的神通。

## 三、修炼路线推演（王林自述，未经验证）

王林现修为：**空劫初期**。九道本源分作三份，推演如下：

| 本源 | 条件 | 推演所达境界 |
| --- | --- | --- |
| 五行本源（以五行真身为例） | 再凝聚其余两种五行之力，五行归一 | 空劫中期 |
| 特殊本源（以雷霆本源真身为主） | 再多两道，归一 | 空劫后期·金尊 |
| 虚之本源（最难） | 再感悟两种，五种归一 | 空劫圆满·天尊层次 |

- 若所有本源皆凝聚出真身，**三种归一的真身**可使修为超越空劫圆满，达到仅次于大天尊的程度。
- 冲击大天尊之法王林不知；师尊曾言需莫大机缘，或在**太古神境**开启时看有无造化。但若三大本源真身凝聚并完成最后归一，或可径成大天尊。
- 更进一步的判断：大天尊之上必还有一层（或为第四步、或不是），需三大本源真身归一凝聚出**唯一真身**、达到**真神**程度；此程度或即**仙祖、吉祖**之实力，连大天尊亦未达到、始终在追求。
- 近期取材方向：特殊本源与虚之本源不好获得，**五行中的金、木两种本源应较容易**。

## 四、后续目标

- 处理完仙族的事情后，前往师尊处，随师尊修炼、令自己更强，以便去任何地方寻找**婉儿（李慕婉）的那缕命魂**。
- 自评：战力很高，但修为与那些老怪相比仍差很多。

## 五、天尊降临与三拳之约

- 晌午阳光渐散，远天雷鸣。一道长虹豁天而来直奔道魔宗废墟，天地轰鸣骤然寂灭，长虹崩溃，王林身前百丈现出**赤发老者**。
- 外形：紫袍绣金边，右侧衣角有火红**太极图案**，似代表「道」。
- 对话：
  - 老者问「是你毁了我道魔宗」——其声平静却引发层层回音，最终如天嘶地吼冲击王林全身。
  - 王林答「是」；老者再问是否要挑战本尊，王林答「是的」。
- 条件：「我给你挑战的机会，**你能接我三拳**，则毁道魔宗之事，就此罢休。」

## 六、第一拳：身体，就是道

- 老者隔百丈一拳落下：整片废墟在阳光下扭曲，空间变换使此地成为单独存在；天地之力被一拳吸空，空间内再无天地之力。
- **道一大天尊之教**（老者归其麾下后所受）：修为到天尊级别已不需施展神通之术；人为修士，身体为修士之本，不需极强悍的肉身，而要把**道融入身体**——身体为道，一拳一脚虽无轰开天地的肉身之力，却蕴含毁灭一切的大道轨迹。
- 这一拳与天地完全融合，一拳动则天地动，内蕴**九种神通**，不需印诀、不需神念，随意一拳即「法随身动」。任何金尊修士面对此拳，一拳足以轰杀百次以上。
- 王林应对：**未穿天牛魂铠**，要看自己无魂铠时与天尊的差距；不退反进，向前一步，右手抬起同样一拳轰出。
- 结果（本章止于交手瞬间）：天地爆出轰隆巨响，地面层层崩溃，碎末向八方倒卷却被扭曲的虚无阻碍，只能向上飞扬，弥漫成尘土风暴。

## 存疑与标注

- 本章「本源真身归一→境界攀升」全系王林**个人分析与猜测**，原文明言「需要时间来验证」，不应作为既定设定。
- 「婉儿」即已于第188章死亡的**李慕婉**，此处为王林寻其命魂之念，非其本人现身。
