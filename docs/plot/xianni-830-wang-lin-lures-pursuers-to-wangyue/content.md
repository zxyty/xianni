# 第七卷 名震罗天 第830章 大计划（第二更）

## 一、开场态势：追杀升级

- 追杀非但没有结束，反而更激烈：无数修士化作长虹，密密麻麻如流星般追击王林。
- 王林自虚空幻化而出时略一踉跄，面色苍白再喷一口鲜血，神色阴沉、杀机更浓。
- 王林自述：**“若非有古神皮甲，那一指神通，我必死无疑”** —— 点明其重伤来源与保命依仗。

## 二、王林的抉择：不逃，而是「引」

前方封锁已解、天地之力平稳，王林却刻意不逃出追击范围，理由有二：

1. **客观**：姚家女子（姚冰云）同样能融入天地，无论逃到何处都会被追上。
2. **主观**：王林行事秉承「人不犯我，我不犯人；人若犯我，我必杀人」。追兵点燃了他的杀机与怒火。

因此他**始终与追兵保持一定距离**，意图：
- 把这些人**一网打尽**，尤其是那个能融入天地的冰冷女子；
- 唯有如此才能换来短时间松懈，否则连休息时间都没有；
- 连这些追杀者的**家族**也不打算放过——他已警告过，对方仍执意追杀，就要付出代价。

## 三、路线：西域 → 北域

- 追兵一冲而过**罗天西域与北域的交界**，纷纷施展大神通挪移追击，杀机凝聚如出鞘之剑。
- 王林现身**罗天北域**——他从联盟星域来临后的第一个所在之处，此刻重回却毫无心绪波动，只是不断散开神识**寻找某物**。
- 途中一次身后星空波纹回荡，姚冰云现身刹那，王林已一步迈出、融入天地消失；姚冰云煞气浓郁、冷哼追击。
- 随后追杀修士与姚家族人化虹赶到。

### 追兵内部的动摇

- 王林因需反复散开神识搜寻、又要立即收回以免被姚冰云追上，**遁速大范围减慢**，追兵渐在北域纵横。
- 但**来自罗天北域的修真家族开始犹豫、部分退出**：罗天西域的一场场「屠星」事件此前只是震撼，如今战火烧到自家地盘，一旦「许木」发起狂来后果不堪设想。
- 仍有一部分「不知死活者」家族就在北域却继续追杀。

## 四、目标揭晓：望月所化的禁地星球

王林抵达**罗天北域中心、距五大主星较近之处**（附近的**冉云星**他曾居住近百年），神识散开后双目精光一闪，露出兴奋之色：**“找到了，它果然还在罗天北域。”**

### 望月星球的来历（数年前）

| 项 | 内容 |
|---|---|
| 时间 | 数年前突然出现在罗天星域五大主星旁 |
| 原形 | 庞大奇异生命体，椭圆形，无数触须延伸，望之可怖 |
| 变化 | 身子收缩化作巨大星球，数年间星空尘埃吸附其上形成薄薄大地 |
| 外观 | 远看与修真星毫无区别 |
| 现状 | 外围弥漫浓郁黑雾、阴森气息；数年前起几乎成为**罗天北域禁地** |
| 认知 | 北域修士知其绝非修真星，不可招惹，路过必远远绕开 |

**它，正是当年的望月。**

## 五、入局：王林潜入望月体内

- 王林盯着望月，眼露谨慎，却毫不犹豫一步冲入雾气。
- 其入雾刹那，**姚冰云**现身雾外，秀眉皱起，判断：「此人一路引人来到这里，定有诡计」，目光似欲穿透雾气，**未轻举妄动，谨慎观察**。
- 追杀修士与姚家族人陆续赶到；北域出身者半路已觉不妙，见到望月星球面色阴沉：
  - 「此物不是修真星，而是一个奇异的凶兽所化，当年我便亲眼看到此物化作星球的过程。」
  - 「此物虽说没有攻击力，但显然不是善物，那许木把我等引到这里，莫非是想要借此物杀人不成。」
- 王林已穿透黑雾登上望月：地面大地极为稀薄，触手摇曳，与当年相比变化不大。他嘴角冷笑，身子一晃**沉入望月体内**，顺**当年的痕迹**行走，直奔**望月体内骨头所在之处**。

## 六、大计划（章名点题）

> 「来，进攻吧，只要你们把望月激怒，一切就都可以解决了」——王林眼中闪烁阴森之芒。

**计划要点**：以自身为饵，把追兵引至望月禁地；追兵一旦对望月出手，望月被激怒，即可借凶兽之力一网打尽追杀者。

## 七、待跟进的悬念

- 望月是否会被激怒、王林深入其体内骨头处所图为何（当年痕迹暗示旧日渊源）。
- 姚冰云谨慎观望，是否会识破并破局。
- 王林对追杀者「家族」的报复是否兑现。
