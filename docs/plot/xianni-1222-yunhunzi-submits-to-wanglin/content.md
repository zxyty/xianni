# 第九卷 云海之巅 第1222章 云魂子的敬畏

## 一、出关：沉睡九十九年
- 王林踏出山峰，山峰顶部的裂缝已消失，照耀整个七彩界的光芒散去，此地重归黑暗。
- 王林神识散开，察觉不远处山谷中藏有他人，喝令「出来见我」。
- 声音寒冷如阴风、如言出法随，震动整个七彩界，凡闻者心神剧震。
- 后经云魂子回答确认：王林此次沉睡共计 **九十九年**（王林自谓「原来过去了这么久」）。

## 二、云魂子的敬畏与臣服
### 苏醒与恐惧
- 云魂子本在山谷洞府内入定，因山峰裂缝的光芒而醒，心惊肉跳。
- 他隐隐猜测「那百年前之人」重新回来了；其百年前对王林的杀机，在岁月中已剩不多。

### 被王林之音所制
- 王林话语如利刃穿透其身，直落元神。
- 云魂子面色苍白，全身浮现**蓝色火焰**，火焰中**雷霆**弥漫，全身麻木。
- 更有一股疯狂**战意**升起，却被一股**意境道念**生生锁在体内，元神被战意烘烤，痛不欲生，以其修为竟惨哼出声。
- 他确信：若不立刻现身，对方一个念头便可令其道消身亡。
- 对比感受：此刻的王林比百年前是「天地之差」；当年被王林扰乱传送后面对雾中凶兽的恐惧，与此刻相比微不足道。王林之气息「足以横扫七彩界」，自己如同蝼蚁。

### 第三只眼
- 云魂子强烈感到：王林**空白的眉心**处似有一只眼睛死死盯着自己。
- 那眼睛蕴含他无法想象的规则；体内的蓝色火焰、雷霆与可崩溃元神的战意，皆由这第三只眼传来。

### 生死操控印记
- 王林抬右手，食指落于虚空，幻化出一道**诡异印记**，缓缓（可轻易躲避的速度）飞向云魂子。
- 云魂子在王林目光下一动不敢动，预感只要一动即被瞬杀；最终放弃抵抗，任印记落入眉心深深印下。
- 印记落下刹那，其体内蓝色火焰、雷霆与元神内的奇异战意尽数向眉心凝聚，与印记融合后消失。
- 云魂子看出这**不是杀人之印，而是生死操控**——「要么生为其奴，要么死为其魂」。他遂恭敬低声：「老奴参见主人。」
- 王林确有此念：云魂子若不开眼，便斩杀之。
- 云魂子内心苦涩却无不甘，感慨「进入时自己不屑之人，如今成为自己的主子」。

## 三、重返司马墨山谷：蚊兽蜕变
- 王林化长虹疾驰，速度骤快，很快抵达**司马墨的山谷**；云魂子恭立谷外，未奉命不敢入内半步。
- 该山谷此前在雷火下得以保存，因雷火中蕴含王林的意志。
- 王林心生危机：「**拓森**，应该已经出来了。」
- 第一座洞府情形：无数禁制中的元晶尽成碎末，兽魂消散；**蚊兽**倒地，身外被卵样之物包裹，极为虚弱，因缺少元晶未能彻底蜕变、无法挣脱。
- 蚊兽见王林神识探入，先迷茫后喜悦，挣扎欲出。
- 王林心痛，进入洞府后虚空一抓撕开**储物裂缝**，把自己获得的**所有元晶**尽数放出，元晶散出浓浓元力涌向卵中蚊兽，蚊兽吸收后继续蜕变。

## 四、召见陈天军
- 王林神念传音命云魂子：「去把陈天军请来，他应该没死。」
- **陈天军的百年**：独自坐于百年前那座洞府，心绪复杂，希望近乎灭绝，常茫然望着漆黑天地回想入此地前的一生；念及「师尊与师兄弟们此刻应在**九阶星域**的战场上与凶兽厮杀，那里才是我该去的地方」。
- 王林苏醒时黑暗百年之地骤现光明，陈天军绝望之心复颤，冲出洞府猜测「他回来了么」。
- 云魂子飞来时，陈天军先是心中咯噔、退后戒备；听闻「主人有请」愣住片刻，似有所悟，随即同行。
- 抵达司马墨山谷后，陈天军感受到王林气息，狂喜；见到王林激动颤声称「**吕兄**」。
- 王林问「元晶可取够」，陈天军答「够，足够」，撕开储物裂缝取出**储物袋**恭敬奉上。
- 王林接过神识一扫，留下一句「**等我，会带你离开**」后转身进入洞府。陈天军等了百年，此刻只觉漆黑天空也似有了光明：「终于可以出去了。」

## 五、要点与后续伏笔
- 王林战力经此次沉睡后跃升，压制得元神级修士云魂子毫无反抗之念。
- 王林新得一名奴仆（云魂子，受生死操控印记约束）。
- 蚊兽蜕变仍在进行中，需元晶供养。
- 拓森可能已经出来，构成潜在威胁。
- 王林许诺带陈天军离开此地，为下一步出七彩界埋线。

> 注：本章王林以化名「吕子浩」行事（自第1063章由吕烟菲奉上归元宗故人身份），故陈天军称其「吕兄」；相关言行归属【王林】。
