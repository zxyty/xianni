# 第1432章 情与恩（第九卷 云海之巅）

## 一、掌尊的招揽（重伤后的许诺）

重伤的掌尊以虚弱之声传音星空，向王林抛出其修道一生最难拒绝的诱饵：

- **知根知底**：掌尊称早在**一千二百年前**便听闻王林之名，更知其「修道一生，所为只是让妻子复活」，也知其曾遍求诸修而无人能成。
- **坦承局限**：掌尊承认自己重伤，且即便未受伤也绝做不到复活死者。
- **真正的筹码——师尊**：掌尊之师与**远古仙尊齐名**，在太古便声名赫赫。
- **方案**：求师尊寻**生灵界**，**屠万兆之人取其魂，化作「长生印」**，不但可复活王林之妻（李慕婉），连其独子（王平）也一并复活。
- **代价**：王林须成为掌尊之**死士（奴士）**，听从一切命令。
- **许诺**：赐道号**「林殇子」**；地位将**超越司墨子，超越清水与青霖**，为「本尊最有潜力的死士之巅」。
- **让步**：可先让师尊复活其妻，夫妻重聚之后再答应亦不迟。

## 二、王林的挣扎

王林闻「妻子复活」四字，心神如遭雷霆撕裂，本就极重的伤势因气泄而喷出鲜血。文本明言此次挣扎**远超当年蓝梦道尊的提议、亦超一代朱雀的话语**——因其直击王林道心最脆弱的逆鳞，「堪比一击井中捞月，捞出了王林的婉魂」。

脑海中催其答应的四重呐喊：
1. 婉儿可复活，你一生修道不正为她一人？
2. **一千五百多年的离别**可以重逢，王平也能复活，一家团聚是此生最大奢求。
3. 个人自由与婉儿性命相比，孰重？
4. 代价是成为第二个司墨子——叛离界内，与司徒南、清水、界内一切道友一刀两断。

王林自问的四问：若掌尊命我**杀司徒**？命我**焚清水**？命我**杀回界内**面对周佚、周茹、大头等一张张熟悉面孔？命我**害二代朱雀**？

## 四、司墨子的镜鉴

司墨子为让妹妹重生，放弃破天宗、放弃界内、放弃一切师兄弟，连自身灵魂也一并放弃，成为掌尊之奴、之走狗；掌尊一指，即便对当年的师尊，司墨子也会流泪举起屠刀。

王林在司墨子记忆中看到的是自己的追忆——**「如今的司墨子，就是日后的王林」**。文中点明：若无司墨子的记忆、若无蓝梦道尊的提议与一代朱雀的话语在前，王林未必能做出这一生最大的抉择。

## 五、抉择与结局

王林的宣告（要点）：
- 「我不想成为司墨子」「我不想成为你之奴士」。
- 「情，是我无法割舍的痛，是我一生修道所为的一切；只是，我之一生，并不仅仅只有情。」
- 对司墨子式的「为亲情舍弃一切、受千夫所指」表示**敬佩**，但自己**害怕面对所有对他有恩之人**；且「就算妻儿苏醒，我们也将成为傀儡」。
- **「或许，你之师尊，真的可以让我妻儿苏醒，但他能做到，我王林，也可以」「我王林的妻儿，我要自己去复活」。**

王林转身望向无尽星空，化作长虹带着悲哀远去，掌尊愣在原地。无人看见两行泪落入星海。心中低问：「婉儿、平儿，你们会怪我么」。

## 六、要点提炼

- 本章为王林道心的**分水岭**：拒绝外力捷径，确立「自力复活妻儿」的路线。
- 反派线索：**清水仙君之疯源自界外（掌尊一方）之谋**，为日后因果埋伏笔。
- 伏笔：**七代朱雀人选**（二代朱雀嘱托）、**焚界古伞**、**长生印/生灵界**、道号「林殇子」未成。
- 卷末附语（作者语）：「昨日曾言，剑出鞘，不染血，数日不收剑已亮，然血还没饮够，还不够热」。
