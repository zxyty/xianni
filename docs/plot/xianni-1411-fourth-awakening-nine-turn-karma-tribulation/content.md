# 仙逆 第九卷 云海之巅 第1411章 四次觉醒！

## 一、异象：人方香灭、地方香自燃

- 第三少帝试炼中，代表人方界的「人方香」竟然熄灭。老朱雀心神震动：无论是他当年试炼，还是四代小朱雀试炼，都从未出现过香灭之事。
- 众人疑惑：香既已灭，试炼时间到底算七息还是永恒？第三少帝试炼中究竟发生了什么，居然能让香灭？
- 更骇人的是：无人碰触，代表地方界的第二根「地方香」轰然自燃，浓烟升空。

## 二、王林入地方界

- 王林破开人方界的天，自一个通往人方界的巨大深坑中冲出，现身于一片无边无尽的大地，落点四周大地遍布裂缝。
- 其身火焰四散，映红大地。
- 大地尽头秃山之上，盘坐着一名看似中年、身穿文袍、头带方巾之人，眉心有虚幻朱雀印决，仿若万年不动，此刻缓缓睁眼，感应到「族人的气息」。

## 三、九转业劫·前七劫收束：三色火劫焚魂

- 王林现身刹那，漫天火海剧震：青光先出、蓝焰随后（青本出于蓝），其后紫意如墨横扫，化作如魔气纵横的紫炎。
- 青蓝紫三色火劫成海压来。王林面部扭曲、魂魄欲溃，体内火焰穿体爆发，赤橙红绿四色火焰将其身躯撕裂，连融入其体内的朱雀也在凄厉惨叫中焚烧而亡。
- **王林魂魄崩溃**。四周七彩火焰齐聚其崩溃魂魄之外，远看如「彩虹焚天」。
- 老朱雀言：这九转业劫，即便一代朱雀老祖都无法度过，须仙尊庇护。

## 四、三道救援与「天逆」再现

三方同时出手救援：

| 施救者 | 手段 | 结果 |
|---|---|---|
| 地方界秃山中年男子 | 眉心朱雀印记飞出破空 | 砰然弹回，倒卷千万里 |
| 老朱雀 | 掌按地方香，神识轰入 | 一触即卷，被逼出地方界；大帝星上右手被大力抬起，退后数步 |
| 蓝梦道尊 | 双指点在地方香上 | 蓝光急闪，被逼出地方界；双指发麻，退后数步 |

- 弹开三道救援的，是从七彩火焰内**苏醒**的一股奇异之力：透出万古沧桑，有天地至极、如万物之祖之意，仿佛决不允许任何人靠近、亦无人有资格靠近半点。
- **蓝梦道尊一眼认出：那正是「天逆」**。他沉默半晌后回到李倩梅身边，只留一句「他此番，无碍」。
- 设定要点：自当年**封界之尊**离去后，天逆便始终未曾出现，王林在心神内如何寻找也无法找到，仿若失踪；此章王林魂焚成尽的刹那，**天逆再现**。
- 天逆形态：一个婴儿拳头大小的珠子悬于半空。它将四周七彩火焰尽数吸入，化作**七道不灭火种**，火种漂浮于外，一个虚幻身影被重新凝练而出，七道火种所在正对应其身体各处——王林由此重生，神色平静。

## 五、九转业劫最后两劫：黑白成九色

- 天地褪去一切颜色，只余黑白，如一幕苍凉山水画；唯王林身外七彩炎暴example存。
- **白色为天，黑色为地**，两极火焰挤压而来。
- 白焰先至，融入七彩风暴 → **八色**。
- 黑炎随后卷地而入 → **九色**，天地至极。
- 「九转业劫，从黑炎而起，至黑炎而落，成一轮回。」
- 王林体内除七色不灭之火外，**白火凝于丹田、黑火凝于眉心**。二火幻化完成之刹，王林睁眼。

## 六、第四次觉醒

- 王林喝道：**「燃我轮回业障之火」**——九色火焰自体内各处直奔眉心融合，化作**九瓣九色火莲**。
- 火莲中幻化冲出一条**九色朱雀**，于空中飞舞，仰头长嘶，是为**第四次觉醒之鸣**。
- 大帝星上，觉醒之音回荡，**地方香仅燃一半便骤然停顿**，其上散发九色之芒，映照整座大帝星。

## 七、老朱雀「作弊」相助

- 老朱雀仰天长笑、神色激动：竟真度过九转业劫、燃起轮回业障、促成朱雀第四次觉醒。
- 关键判断：**第四次觉醒所需火焰之力极大**，能否彻底觉醒、能否从**实火**踏入**虚火**境界，就看这一次。
- 老朱雀自陈「我身为长辈，即便是作弊，也要帮他一把」，身影消失。
- 片刻后天际龙吼，老朱雀抬着一条挣扎咆哮的**万丈炎龙**一步迈来，于其头部结痂伤口处斩开伤痕，鲜血如瀑落下，染红燃烧的地方香。
- 老朱雀一掌拍下，以火焰之力冲入炎龙体内催血更快更多，并许诺：「这次若那小子觉醒成功，老子放你自由。」炎龙先是犹豫，随即咬牙极为卖力地挤血。

## 八、旁观者反应

- **司墨子**：震撼——看出蓝梦道尊二人是在救人，却没想到两位大能竟被弹开。
- **云落大司**：神色阴沉，掐诀更快，隐隐感觉即将窥知其中一切隐秘。
- **妙音道尊**：猛然从云端起身，目光闪烁：「水道子说的，果然没错。」（水道子已于第1242章死亡，此为对其旧言的追述。）
