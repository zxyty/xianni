# 第1688章 两弓之力！（第四更）

## 一句话概括
王林守在远古仙域缺口外，专等七道宗仙人走出的一刻，以李广弓一箭尽屠。

## 场景与前情
- 地点：远古仙域缺口之外的星空，属洞府界一方星域。
- 王林早已埋伏于此，目的明确——**等待远古仙域开启，在仙人走出的刹那以弓杀人**。
- 出缺口者为七道宗仙人，来自**仙罡大陆**，向来视洞府界修士为蝼蚁。

## 事件经过

### 1. 取弓·拉弓
- 王林双眼金光弥漫，左手虚空一抓，李广弓轰然而至被握入手中。
- 右手拉弦成满月，弓弦上在波纹扭曲中幻化出那支箭。
- 此箭一现：天地色变、星空震动。

### 2. 仙人的认弓与恐惧
- 后退的仙人认出「李广弓」，神色剧变、身子颤抖、发出恐惧尖叫、疯狂逼后。
- 他知晓此弓在其故乡**仙罡大陆**亦是震动人心的至宝，一箭之力足以让人绝望。
- 其余仙人看清弓与弓开波纹后同样色变，纷纷疯狂后退，想退回远古仙域内。
- 关键判断：**「掌尊都没有这样的资格」**——连掌尊也无法在李广弓箭下逃遁。

### 3. 「两弓之力」
- 王林在已拉满的状态下，低吼中再次发力生生多拉开一些，弓在其手中弯曲得如同要被掰断。
- 此即本章标题「两弓之力」。

### 4. 杀机与宣言
- 王林眼中滔天杀机，要杀的正是这群狂傲自大的七道宗弟子。
- 原话：**「你们与闪雷族那群人，没什么区别。」**

### 5. 屠戮
- 右手松弦，震动整个星空的巨响轰起，箭呼啸而出，压过天地之威，星空在箭前崩溃。
- 最前方那名之前要杀王林的修士，无处闪躲，身体崩溃、被箭穿透、**形神俱灭**。
- 旁白：他「不是王林所杀第一个仙罡之修，也不是最后一个」。
- 箭出后膨胀至**数千丈**并持续扩张：
  - 三个仙人全身崩溃、惨叫死亡；
  - 又四个仙人肉身碎开，元神刚逃出即瓦解，消散在他们轻蔑的洞府界；
  - 金色箭光映照整片星域并向外扩散，其下又有八个仙人惨死。
- 前一息还沉浸在走出仙域的狂喜，下一息狂喜即成死亡的结果。

### 6. 余波
- 箭瞬息轰杀所有走出缺口的仙人后，直奔缺口而去、没入其中。
- 缺口内轰鸣回荡，出现剧烈崩溃。
- 崩溃冲击化作气浪向八方横扫，其烈**足以改变修真星的轨迹**，却无法吹动王林的**古神陵身**。

## 要点提炼
- 李广弓的战略价值：可用以在界外强者初入本界、立足未稳时进行斩首式截杀。
- 王林此战的因果动机：为洞府界修士出头，将七道宗与旧敌闪雷族并列。
- 王林肉身层次：古神陵身可硬抗足以偏移修真星轨迹的气浪。
- 远古仙域缺口在此箭下受创崩溃，仙人退回之路被截断。

# 第1596章 二连李广弓：崩灭远古仙域缺口

## 一、王林的决意
- 王林发丝衣衫在星空剧震中狂舞，双眼坚定无一丝涣散——他要杀人，一箭不足以杀够。
- 他自知：远古仙域内究竟有多少七道宗仙人、其中几人修为通天，他都不知晓；凭李广弓无法把这些人尽数毁灭。
- 于是改变目标：**崩灭远古星域之门**，让此门再次闭合，令这些修士丧失这一次出来的机会，无法走出。

## 二、第二弓：代价与威力
- 这是王林获得李广弓后**第一次连续开两弓之力**。
- 代价：额头渗汗；融合于双目内的**仙人血脉金光急速黯淡**；第二箭射出刹那，双目金光直接崩溃——左目金光彻底消散，右目金光尚隐隐存在却瞬息失去（不知是隐藏还是与左目金光相消散）。
- 箭矢来源：射入前方远古仙域裂缝缺口的第一箭，在波纹扭曲中再次幻化出来、搭回弓弦，箭身沾血、透出血腥味。
- 阻力：弓被拉开之际，裂缝内呼啸而出两股气息，**每一股都相当于『尊』一般**。

## 三、封门一箭
- 右手一送，弓弦嗡然回弹，第二箭射出。
- 箭尖圆圈传出**巨大破开吸力**，回旋于箭身；箭冲入缺口瞬间，缺口裂缝急速收缩。
- 箭完全进入远古仙域后，缺口在持续收缩下**轰然崩溃**。
- 结果：碎灭缺口 → 阻止界外远古仙域之修外出 → 毁灭通道，阻隔一切外出可能；那两股极强气息刹那被阻隔，再无法散出半点。
- 星空中只余闷闷轰鸣，越来越远。

## 四、界内远古仙域：四大战将的判断
- 界外与界内远古仙域**冥冥中有连接**：界内苍天倒卷似要崩溃，如同镜子模糊映出界外末日般画面。
- 四大战将飘在半空，神色凝重骇然：
  - **青龙战将**：“此子……我们还是不要招惹的好。”
  - **玄武战将**：“他绝非只剩下两弓之力，他不是傻子，此人心智成妖一般，岂能把底线让人轻易摸索——我猜测，他最少还有三弓之力。”
  - 四人相互看过，彼此点头（默认不招惹）。
- 与掌尊的误判形成鲜明对照：这是本章最大的**认知落差伏笔**。

## 五、太古星辰一方：合围杀局
- **掌尊**：在千万里外骤然一顿，眼露惊喜——“我算定他只有两弓之力，此刻已然浪费一次，再有一次，他今日必死无疑。”
  - 见第二弓射出后狂喜，笑声回旋，透出**压抑了三年的怨气**。
  - 掐诀一挥，以强悍修为**封印太古星辰这片星域**：此封印**不阻止人进来，但阻止外出**。
  - 随后身影消散、刹那前行，最终出现在王林身后**万丈之外**，杀机浓浓走来（本章收尾）。
- **第七妃**：面色苍白、踉跄，双眼滔天怨恨，银牙欲碎：“王林，我要杀你。”
- **妙音仙尊**：伤势未复仍疾驰而来，狞笑“有这些人都要杀你，我就不信你还能活”。
- **九天魔尊**：双眼幽光，“老夫要把他的魂抽出一丝，点天灯长燃万年，听其魂凄万年，如此方解心头之恨”。
- 三人皆循**神识锁定**直奔王林。

## 六、要点归纳
1. 战略转向：由“杀尽仙域修士”改为“封死出口”，是王林一贯的以小博大式取舍。
2. 硬指标：李广弓两箭 = 崩碎界外远古仙域缺口 + 隔绝两股尊级气息。
3. 状态代价：双目仙人血脉金光尽失，为后续战力埋线。
4. 局面：王林身处**被掌尊封锁（只进不出）**的太古星辰，四方强敌（掌尊、第七妃、妙音仙尊、九天魔尊）合围逼近。
