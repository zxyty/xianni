# 第624章 捆他！（仙逆 00586-00590 之1）

## 一、捆仙网之赌

矮小老者拿着捆仙网停步不逃，心中盘算：

- 自己只是**问鼎中期的虚架子**，而王林是**拥有自身道念、真正达到问鼎修为**的强者，逃走难度太大，被擒只是早晚。
- 赌一把：若捆仙网“心情好”，能捆住王林三天，则足够他远遁；若不逃，则可趁机把王林炼化成神秘玉简所载的**真正下品仙卫**。

### 仙卫炼制的成功率设定（出自神秘玉简）

| 材料修士 | 成功率 |
|---|---|
| 婴变期修士 | 极为渺茫 |
| 问鼎修士 | 略有增加，仍很少 |
| 问鼎后期大圆满修士 | 万分之一 |
| 拥有自身道念的修士（特殊） | 万分之一 |

老者此前炼制的仙卫**全是残次品**，不符合玉简记录。

## 二、反噬：捆仙网捆住主人

1. 王林踏空现身，老者大喝祭出捆仙网，网融于天地，天地各生青芒相互收拢。
2. 王林神识扫过**无法穿透青芒**，警惕大起；他在现身刹那已在脚下压缩了**无数个挪移神通**，随时可强行穿透遁走。
3. 老者癫狂咆哮“捆他，捆他，捆他”“一定要捆他”，面红筋暴。
4. 青芒骤然加速——目标却是**老者本人**。老者惊惧求饶：“别捆我……我把你们救出来……求求你了捆仙网，放我一条生路吧”。
5. 老者接连爆出火光、金光等**十多种完全不同的逃遁神通，全部当场失效**，被青芒淹没，全身捆得连手指都动不了，并被捆仙网直接送到王林面前。
6. 老者怒骂：“你个吃里爬外的捆仙网，你只会捆我，从来不捆敌人”“你原来的主人，一定就是被你害死的”。

### 王林的反应

- 斗法七百多年来**第一次**见到对手被自己扔出的法宝捆住送上门，罕见地愣住，露出哭笑不得之色，甚至**笑出声**（在他身上极为少见）。
- 同时对捆仙网的**忌惮瞬间达到不可思议的高度**——亲眼见到其内一切神通失效。
- 老者豁出去：“没见过自己送上门的么，老夫法宝失效了，不行啊”“要杀要剐，你看着办吧”，内心仍紧张。

## 三、城堡余波与孙家兄妹

- 城堡处修士**仙种已除**、等于获得自由，绝大部分趁王林追击时逃走；余下数人留下向王林道谢，随后各自散去。
- **孙若南**独自望天发呆，被王林左手虚空抓走。她挣扎、冷笑，认定自己会被当作**炉鼎**：“事后放我离开就行”。
- 王林以看死尸般无情的目光回答：**“你，没有做我炉鼎的资格”**。
- 数万里外，王林把孙若南甩给**孙云山**，同时召出**麒麟兽**——孙云山与地上十多名修士眉心的**青纹（仙种禁制）**尽数颤抖成团飞出，被麒麟兽一口吸入；麒麟兽随后化作魂魄被王林收入**魂幡**内。
- 王林留话：“禁制已解，令妹也被救出，你那几个师叔，就要你去寻找了，至于我炼魂部落内的那位，我会把他放出。”随即挪移离开，懒得理会兄妹二人的纠葛。

## 四、炼魂部落宝塔：三才剑阵与逼问

- 王林回到**炼魂部落宝塔**内，把矮小老者随手扔在地上，盘膝而坐。
- 一拍储物袋，**三道剑芒**飞出悬于老者身边，剑尖寒气逼肤——正是**子鼠、末羊、亥猪三剑**。王林已将三剑炼化、融合其内剑气，**把三剑中的剑阵融会贯通**，可开启**剑尊凌天候的三才剑阵**。
- 剑阵渊源：王林**搜亥猪之魂**时得知——剑肖十二剑以三为数结成三才剑阵；若十二把剑同时展开，便成剑尊凌天候引以为傲的**天杀十二地剑阵**。
- 王林警告：捆仙网解开时若有任何异动，便让他领教三才剑阵的玄妙。
- 王林一眼看出此人胆子极小，话中带**魔音**逼问：“现在告诉我，你，到底是什么身份”；若不说，便施展**搜魂术**，将其炼化成魂魄、**永世不入轮回**。

## 五、悬念

- 矮小老者**自称来自仙界**，其真实身份、捆仙网的来历（奇遇所得）以及神秘玉简的出处，本章未揭晓。
- 老者自评：明明得了让无数人疯狂的奇遇，最终却毁在从奇遇中获得的法宝上，堪称修真界最委屈之人。
