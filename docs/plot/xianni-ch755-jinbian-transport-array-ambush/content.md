# 第七卷 名震罗天 · 第755章 惊变

## 一、场景与人物
- 地点：一处碎片大陆上的树林（树下有骸骨），属仙界残破之地。
- 人物：王林（本片段以自创化名「许木」行事，李元称「许兄」）、李元（同行者，精于禁制推衍）。
- 王林视角贯穿全章，情绪线由「悲哀」起，到结尾「大吃一惊」。

## 二、古神之皮与情绪伏笔
- 骸骨身穿一件**以古神之皮做成的皮甲**，不知是几星古神。
- 王林见之神色阴沉、心生悲哀，**联想到本尊**——暗示分身/本尊体系与旧日故人之物的因果。
- 对李元的回答是：「不认识，只不过与一件故人之物有些相似罢了。」（隐瞒真实联想）

## 三、破禁：仙禁八法第三法（蜃幻）
- 李元推衍后双手掐诀，一指打出一道禁制，**化作十八朵梅花**齐飞向树木。
- 落下后空间扭曲、波纹荡漾，如镜碎裂——树木与骸骨尽数消失，皆为幻象。
- 李元判定：此为**仙禁八法中的第三法，以蜃幻为主**。
- 二人共识：**以骸骨（与诱人的仙家法宝皮甲）为饵**，引人靠近后由禁制变化杀之；若骸骨为真，不可能保存至今。历年死者数目不明。

## 四、关于禁制来历的推演
| 议题 | 王林 | 李元 |
|---|---|---|
| 是否首次被破 | —— | 确定是**第一次被破除**，无破掉重组痕迹，禁制年代悠久，时间上略有符合 |
| 为何景象外泄 | 岁月太久禁制内生变，**禁制之光外泄**，把内景表露于禁眼之处 | 认可「**七成**如许兄所说」 |
| 是否人为陷阱 | 存疑：仙人所留，还是后人设置 | 不排除有人故意设置，**以禁杀人夺宝** |

> 二人皆机敏心智不凡，略一探讨便推出无限接近真实的答案。

## 五、传送阵现世与崩溃征兆
- 破禁后现出**一座散发柔和之光的传送阵**。
- 久不见天日，乍现之下与外界游离气息、仙气冲突，**边缘出现无数细小漩涡**——崩溃前征兆。
- 漩涡散出支离破碎的幻象：**古老建筑与尸体残骸**，印证阵后另有天地。
- 李元笑称「还是许兄的推算正确」，提议二人一探究竟。

## 六、惊变：强大神识与「血空凝」
1. **神识压境**：一股蛮横神识自远处弥漫，其内似蕴含神通；所过之处天空阴云齐齐退开。李元呼吸困难、仙力不受控云涌，**喷出一口鲜血**。神识本只扫过，随即回退**直勾勾锁定此处**。
2. **王林的熟悉感**：王林大吃一惊，因这神识**给他一种熟悉的感觉**（重要伏笔——疑为宿敌），不假思索直奔传送阵。
3. **红雾阴魂**：四周百丈天地骤然变红，红色烟雾扭曲化作一个个阴魂，尖啸扑向王林。
4. **二人分工**：王林大喝「禁制」，抓住李元后襟主冲速度；李元主攻，掐诀放出的禁制**每一个一晃化作十八**，瞬间弥漫挡住阴魂。
5. **血空凝**：冷哼与冰冷声音自凝聚的神识内传出，喝出**「血空凝」**三字——方圆百丈如被天地挤压迅速凝固，如无形大手挖出百丈天地在掌心五指收缩欲捏碎。王林距传送阵仅**一步之遥**，抬脚后却如绑一座山峰，落势缓慢；面色苍白冷汗流下，**连抬手取法宝都无法做到**。
6. **红影将至**：王林隐约看到不远处虚空一道**红芒**直奔而来，其内**红色身影正飞快幻化而出**；红影透出的恨意**可以跨过两个星域**，杀机浓郁无法想象。

## 七、悬念与看点
- 「熟悉的神识」＋「跨两个星域的恨意」＝ 旧因果找上门，来敌身份为本章最大悬念。
- 传送阵已在崩溃边缘，一步之差可能决定生死与后续去向。
- 古神之皮皮甲勾起王林对本尊的联想，属分身/本尊线索的延伸铺垫。
