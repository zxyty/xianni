# 仙逆 第1805章 老祖归来！（第一更）

## 一、道喃之术 vs 心动雷音

- 苍龙宗弟子在燃烧的宗门内施展**道喃**：源自**大魂门**的群修连击之术，声音不尖锐不刺耳却带奇异魔力，令王林魂魄似要与肉身分离，间接影响其**道念意境**乃至**本源**。目的是干扰王林、阻其离去。
- 该神通王林在**洞府界**也曾遇过，但威力远不及此。王林此时修为已可与**几次玄劫**的修士一战，仍被影响。
- 王林以感悟自**道古墓地**的**心动雷音**相抗：以心跳化作雷霆，雷霆轰轰越加紧密，牵动数万苍龙宗门人心脏一同狂跳，双方**平分秋色**。

## 二、抽地火支脉之魂

- 王林迈步走出洞府，四大长老齐齐进入之际，其右手向大地虚空一抓。
- 神通来历：在**洞府界**学会的、如**抽山魂**、**星魂**一般的抽魂神通；此次所抽为**地火脉之魂**。
- 设定要点：整个**天牛洲**拥有一条巨大**地火脉**，分支极多、错综复杂，俨然如一个巨大阵法，**不知为封印何物存在**。以王林当前修为尚无法抽出**地火主脉之魂**，但可抽苍龙宗山峦下的**地火分支之脉**。
- 结果：地面轰鸣，地火自阵法中爆发；洞府所在山峰崩溃、碎石飞出不远即化飞灰，山峰**烟消云散**。
- 火龙形态：身长约**数万丈**、仅头颅便如山峰般大，由火焰组成、**没有实体**，透出万古沧桑的灵魂气息——实为地火支脉之魂。

## 三、王林之威

- 形象：一头**白发**飘动、双目如星辰、**背后背着棺材**，立于龙头之巅，睥睨天下、唯我独尊。
- 数万修士道喃立止，心神颤抖、灵魂恐惧，视其如九阳般无法直视。
- 定位重申：王林在**洞府界**是**至极封尊**、天地最高之巅；初入**仙罡大陆**，气势依旧。

## 四、四大长老溃败

| 长老 | 手段 | 下场 |
| --- | --- | --- |
| 面色苍白的中年男子 | 速度最快，掐诀硬撼火龙 | 全身水汽瞬息蒸发、头发燃烧、皮斑遍体，伤及元神灵魂；喷血退数十丈后逃遁，**双臂被风一吹化作飞灰** |
| 白发老者 | 咬破舌尖以精血化滔天血雾（其内似有恶鬼） | 血雾崩溃，**肉身四分五裂**，仅元神尖叫逃退 |
| 一男一女二长老 | 各化巨龙封死道路 | 龙身崩溃、喷血，**身体爆开**，元神逃出 |

- 四人皆为**空涅**修为，之所以拼死阻拦，是因苍龙宗几乎被毁，畏惧**老祖归来后的暴怒**甚于畏死；但中年男子在死亡恐惧超过对老祖的畏惧时仍选择了逃。
- 王林与火龙融为一体，一冲之下四人尽废，冷语：「**萤火之光，也敢于皓月争辉**」。

## 五、离去与留言

- 火龙冲天，数万弟子喷血倒卷、生生让开道路。
- 王林于龙头低头留言：「**王某并未杀人，今日祸事，乃你宗欲炼王某成傀引下，你等，好自为之**」，随即踏地火支脉龙魂远去消失。
- 影响：一人之力，一宗不可阻止半步。此战注定王林将在**天牛洲**扬名，其身影深深烙印在苍龙宗门人心中。

## 六、老祖归来（悬念）

- 王林离去**一炷香**后，一声惊天怒吼传来，天地色变，地面燃烧的火焰齐齐一顿、刹那熄灭化作黑烟滚滚升空。
- 两道长虹呼啸而至，其中一道几乎撕裂天地：
  - **苍龙宗老祖**：外表是一名唇红齿白、剑眉星目、本应极为英俊的**少年**，此刻神色狰狞、透出戾气怒意；望着废墟沉默，给四大长老带来莫大压力与恐惧。
  - **绝色女子**：千娇百媚，看清废墟后**立刻毫不犹豫地离那少年远了一些**。
