# 第1734章 如此大恩！！（第四更）

## 一、局势起点：水球困杀

- **施术者**：归一宗水将，于五行水阵中凝聚巨大水球困住王林，意在将其炼化为归一宗大道神通**乾坤一滴**。
- **关键设定**：水球内的水本源之力**并非水将法力所化，而是其铠甲所化**，浓郁程度连纳多都感到恐怖。
- **纳多的判断**（高塔第十层，送出五行金力、以神识观战）：
  - 认为王林若有手段早在水球初凝时就走了，此刻久困必已绝望。
  - 自陈与王林「没有什么仇隙」，杀他只因**他是洞府界之修**。
  - 推断：洞府界大乱、几方势力都在寻找**第三魂**，王林此时来此目的显而易见。
- **高塔内四人**（黑袍老者、中年女子及两名尚存理智的修士）围观漩涡镜面：
  - 黑袍老者大笑，称「乾坤一滴」是归一宗大道，此人必死。
  - 中年女子恨意滔天，尖笑称王林一死「司徒南」必悲伤，并放话「下一个就是你」。

## 二、转折：挤压即馈赠

1. **水将喷血加压**：因莫名的心惊肉跳之感，水将担心生变，喷出一口鲜血、身体大幅虚弱，水球由近万丈骤缩至**七千余丈**。
2. **对王林的真实作用**：王林正明悟水本源的变化，变化本已到极限而缓慢下来，「如同知晓秘密只知一半」；水将这一记加压恰恰让本源重新运转。王林几乎大笑，认定「那水将之恩绝不会忘」，舍不得杀他。
3. **全宗助攻**：水将下令「纳多，还有归一宗所有弟子，全部心神入阵，借我力量在三息之内将其化作一滴」。
   - 纳多以五行金力化作金光铠甲，修为暴增，走出高塔第十层，高呼「今日我归一宗为天地除魔，诛杀此人，成万古造化」，神识入阵。
   - 四周**数百名归一宗修士**盘膝坐下、神识齐入五行水阵，加上黑袍老者等四人爆发全部神识之力。
   - 水球连续暴缩：三千丈 → 两千 → 一千 → 五百 → 二百丈。
4. **本源变化暴增**，王林几乎看尽所有本源变化，双手无意识掐诀模仿，喃喃「我有些明白了，还差一点」。

## 三、悟道与夺灵

- 王林右手一挥，取出**天运子此前所赠的一滴蕴含一丝本源的水滴**，水滴散发晶光旋转，状若水晶。
- 王林开口：「**水本源，三亿八千万变化，凝**」。
- 二百丈水球剧烈抖动、水本源气息爆发；在归一宗最后一波神识尚未起效之际，水球**自行**急速收缩：二百丈 → 五丈 → 尽数凝入王林右手水晶 → 水晶消散于其手上。
- 王林盘膝转为起身，含笑向所有神识与呆滞的水将**弯腰抱拳一拜**：「**如此大恩，请受王某一拜**」。
- 拜毕大袖前甩，天地色变、狂风呼啸，**所有神识（含纳多神识）尽被轰出水阵**，阵中只余水将与王林二人。

## 四、余波

- 水将身子一颤、喷出鲜血，惨笑踉跄后退数步。
- 五行星上归一宗众修士齐齐惊醒，先是死寂如被定身，继而哗然：「他收走了土灵，让火灵膜拜，更是取走了乾坤一滴所化的水灵本源」「这需要多恐怖的计算与明悟之力」。
- 纳多目露迷茫，至此仍无法相信。黑袍老者与中年女子承受不住剧变，黑袍老者半晌无言、目中掀起滔天恐惧。

## 五、要点提炼

- **母题呼应**：敌人的全力围杀反成王林的道途资粮，「如此大恩」一拜是冷硬的嘲弄，也是仙逆式因果反转。
- **战果**：王林已连得**土灵**（收走）、**火灵**（膜拜）、**水灵本源**（取自乾坤一滴），五行之灵已得其三。
- **悬念**：洞府界大乱、各方争夺第三魂；中年女子与司徒南（实为司徒南的断臂所化人影）的旧怨未了；水将独困阵中，生死待决。

> 注：据世界状态须知，王林在近段以「烨寞（道古烨寞）」等名/身行事，本章文本直呼其本名「王林」，一切言行归属【王林】本人；文中「司徒南」之名自第336章起由**司徒南的断臂**所化人影自称，真司徒南已于第61章身死。
