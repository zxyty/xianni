# 仙逆 第765章 血星（第七卷 名震罗天）

## 一、血星的方位与洞府选址法则
- **血星**：一颗充满血光的星球，位于**联盟星域**边缘，**不属天运星势力范围**，距天运星遥远。
- 大神通修士独占修真星为洞府的通例：
  - 彼此绝不相近，即便至交好友亦然（防人之心不可无）。
  - 有资格开辟修真星者不需天运星庇护，故多择偏僻之地。
  - 最关键的一条：洞府绝不可在他人神识范围内，否则一举一动皆被察觉。
- 血祖本就身怀秘密，择址尤为谨慎。**天运子当年给予王林的星图**上，血星四周没有任何大神通修士的修真星——这是本尊敢于亲自出手的原因之一。

## 二、本尊出手的动机与底气
### 直接动机：分身垂危
- 分身此次昏迷**极为严重**，与本尊之间「切不断的联系」变得若有若无，随时可能断裂。
- **联系一断 = 分身死亡**。
- 王林心中分身与本尊「已无主次」：分身是他，本尊也是他；**分身死亡等于他被人杀了一次**。
- 若此时仍龟缩隐匿、等曰后修为提高再出现，「他就不是王林了」——**有些事不能考虑后果也要去做**。这是他姓格中的「逆」。

### 现身的客观依托
- 四大星域内真正认识**古神**的修士极少，多数只从古籍上略知丁点。
- 古籍所载古神多为**六星以上成年体**，身躯堪比一颗修真星甚至更大——巨大体型才是古神的独特标志。
- **四星古神**的古神气息并不明显，除非当年亲见过古神，否则无人会联想到已灭绝无数万年的古神。

### 保命底牌：化灵
- 古神传承记忆中攻击类神通多不可用，但**保命神通**有若干，王林在**半四星**后可施展。
- **化灵**：古神一族保护幼体的神通——融入一颗星球，**不吸收其灵力**，将整个身子化作灵气进入沉睡；除非遇到与古神同等层次的存在，否则无人能看破。层次高于修士手段。

### 唯一顾虑：拓森
- 本尊自评：唯一需顾虑者为**拓森**；但此人若脱困，以**八星古神之躯**一现身便会被大神通修士认出。
- 结论：「即便在这联盟星域引起浩劫，又与我何干。**我王林，不是圣人**。」

## 三、赴星途中
- 本尊带着一条**长长的碎石河**，一脸冰冷、速度极快直奔血星；星空浩瀚、联盟星域似无尽头，其体型与之相比微不足道。
- **历时数月**，中途不作停顿；沿途所遇修士见之皆一怔，无人轻举妄动。

## 四、血星内部：奴仆体系与崩坏
### 血奴 / 血卫
- **血奴**：元神中有**血祖烙印**，血祖生则生、血祖死则死。绝大部分是血祖从四周修真国强行掳来、夺其自由为奴。
- **血卫**：血祖搜集的有天资少年，以**血丹**饲养炼成，守护血星。
- 血祖天姓薄凉，**唯独对其女儿**才露出身为人父的慈祥。除血祖父女外，全星生灵皆为奴仆，生死只在一念间。

### 崩坏征兆
- 近数月，血奴与血卫**大批莫名爆体而亡**，至本章已死亡超过**七成**。
- 唯一解释：**血祖出了问题**（实为其在外遭劫）。

## 五、紫芯与四红袍老者的决裂
- **紫芯**（被称「主母」）坐于**血阁**外祭坛，面露焦虑、频频回望；血阁为血祖禁地，连她亦不得入内。
- 四道血光化作四名老者，皆有元力波动、**已踏入第二步的大神通修士**：
  - 一者禀报「又有一批血奴身亡」。
  - 一者抬头直问「血祖大人到底去了哪里」——此前绝不会如此说话。
  - 紫芯厉声呵斥「放肆」，内心却更加彷徨，人人（包括她自己）都在怀疑血祖是否正在死亡。
- 第一名老者冷笑离去，心情恶劣却带一丝解脱：
  - 「老夫自**六千年前**被血祖强行烙下封印，若无血祖之令，不敢踏出这血星半步。眼下血祖显然出了变故，老夫在这里也是等死，但死，也要死在我的家乡。」
- 其余三人相视无言，化作三道长虹随之冲天。
- 紫芯厉喝「你们好大的胆子，就不怕血祖回」，被半空老者当面折辱：
  - 「聒噪。你只不过血祖的一个玩物……我等修士躬身对你，是因为血祖。若无血祖，你算什么东西。老夫在这血星近万年，如你这般的女娃，见过不下数十。」
- 未死血奴见状纷纷抬头挣扎，随即几乎全部飞出，集体叛离。

## 六、章末：威压临星
- 紫芯眼露果断，回身来到血阁前，回想血祖开阁手法，踌躇后**银牙一咬**（欲强开血阁）。
- 此刻天空骤暗，**浓郁威压**瞬间弥漫整个血星，紫芯面色刹那苍白：「这……这是什么」
- 星空中：一条**碎石组成的长河**呼啸而来，长河之上立着一个**百丈大小的巨人**，双眼冰冷、杀机浓郁。
- 四红袍老者目光一凝、迅速对视，随即化四道长虹从不同方向逃走，全不理会巨人来意，心中几乎同时浮现——「**血祖，你也有今天**」。
- 大量血奴见本尊亦无一为血星而战，带着快意冷笑四散；部分人未走远，遥望血星，准备**亲眼目睹血星的灭亡**。

## 七、要点提炼
- 本章为「王林本尊亲征血星」的开场：动机（分身垂危 = 自己被杀一次）、依托（古神身份难辨 + 化灵保命 + 星图确认孤立方位）、姿态（逆天不计后果）三者齐备。
- 血祖体系的致命结构缺陷暴露：**以元神烙印绑定生死**，主上一旦垂危，全体奴仆连锁爆体、幸存者反噬叛离。
- 紫芯的处境被彻底揭穿——她并非「主母」，只是血祖的玩物，血祖一失势即失去一切庇护。

# 第765-766章 血星覆灭与碎片陆地天炼之宝

## 一、血星终局（承第765章）

### 1. 陨石轰星
- 王林一眼看出血奴的端倪，未加阻止，携大量碎石直冲血星。
- 临近血星时自碎石上升起，庞大双臂各抓一颗百丈大石砸向血星；血色光幕浮现将其击碎。
- 王林不停歇地连续投掷巨石，最后一跃而出，以体内灵力牵引所有碎石如长河般冲撞血星。
- 血幕虽强，但已失去血祖操控，威力有限，在王林这个**幼年古神**的庞大力量前，**半柱香后崩溃**。
- 碎石轰然落星，每次撞击星球震颤，肉眼可见的环形波纹向四面八方扩散。

### 2. 紫芯之死
- 紫芯面色苍白、恐惧如潮，无法想象这是何等力量与神通。
- 她在血星潜伏数年，**暗中记牢血祖每次开启血阁的手印**，血祖不在时曾偷偷尝试，但不敢以血阁为目标。
- 此刻血祖濒死、血星大乱、外敌侵袭，她再无顾忌，急速掐诀，血阁内红芒大闪，隐现**红光通道**。
- 天空骤暗，百丈巨人（王林）踏虚空而来，冷冷俯视，其身后数颗百丈碎石呼啸砸落。
- 紫芯不顾一切冲向通道，踏入刹那惨叫——通道红芒使其皮肤肉眼可见地腐烂、青烟升起，**元神崩溃**，全身化作青烟被血阁通道吸入。

### 3. 夺阁与灭星
- 王林大手一抓，将连同血阁在内的**百丈地面**生生从大地拽起。
- 一手抓血阁，一手握拳疯狂砸击大地；陨石不断降临，血星化为一片残骸。
- 王林一踏冲天，远远消失于星空。

### 4. 血奴血卫的解脱
- 四周观望的血奴与血卫**无人阻止，反而向王林离去方向抱拳相送**。
- 王林走后不久，众人眼中一片茫然，仿佛心神中**无形枷锁被解开**，纷纷散去，各自回到多年未曾踏及的家乡。

## 二、第七卷《名震罗天》第766章 天炼之宝

### 1. 余波与本尊隐匿
- 血星覆灭在**联盟星域**内未掀起大波澜，且血星地处极偏僻，很久之后才被人察觉。
- 王林本尊抓着血阁飞行，身形缓缓缩回**正常修士大小**；血阁被封印缩小后**吞入口中，以体内灵力包裹**，准备仔细研究——此阁甚为奇异。
- 寻一处**六级修真星**，潜入星球内部盘膝坐下藏身。
- 灵魂中与**分身**的感应，由若有若无转为**稳定**。
- 此行虽引起一些大神通修士注意，**但无人怀疑到古神身上**——古神距眼下修真界实在太过遥远。

### 2. 雷之仙界·碎片陆地上的天劫
- 地点：**罗天星域·雷之仙界**内一片虚无中缓缓漂荡的**碎片陆地**。
- 陆地外凝聚起大片**本不该出现在此地**的云层，其内雷光游走。
- 雷霆自云层降临落于陆地，散作无数细微电光，寻到深处**昏迷中的王林**并钻入其体内，王林身子蓦然一颤。
- 雷霆一道接一道降临，陆地震动，边缘大量碎石崩溃。

### 3. 血祖的旁观与算计
- 血祖感知到**自己一半血身就在陆地深处**，且其中蕴含的**天地元力正被飞速吸收**——想杀人反而助人成长，他一生首次遇到，几欲发狂。
- 血祖不敢前行，谨慎观望云层中愈发酝酿壮大的力量。
- 判断：「这是天劫……想必当年从星空中落入**妖灵之地**的天威，便是因此人而现。」
- 决定在旁等待，**盼天劫将王林活活劈死**以解其恨。

### 4. 天劫降临
- 碎片陆地因云层浓郁如受限制而**静止**下来；雷霆持续降临**一个月**，最后几乎望不见云层边缘。
- **数日后**，陆地上空、下方虚无及四周尽被云层弥漫，远望只见云层不见陆地——天劫准备完成，天劫到来。
- 无穷雷霆自**四面八方所有云层**射出（非只自上方），碎片陆地不断崩溃瓦解，雷霆游走冲入昏迷的王林体内。
- **许立国**吓得缩在仙剑内不敢出来——一道雷霆之力就能让他险些魂飞魄散。

### 5. 天劫之利：两股力量的融合
- 王林体内，**神秘老者的力量**与**血祖的血身**正在相互抵消、相互融合。
- 此过程原需极久，但在不断传入的雷霆之力下**大幅加快**；其体内元力疯狂增长。
- 天劫落身不但未伤他，反而好处难以想象；**因其昏迷，若清醒以意念引导，好处更大**。

### 6. 天炼之宝
- 碎片陆地如置身天地烘炉，被天雷炼化——此种炼化在如今修真界极少出现，因无任何物质能承受如此轰击。
- **唯有雷之仙界的大地例外**：它本是雷之仙界未崩溃前承受无数年仙雷弥漫的大地，虽后来碎裂，仍是雷之仙界的一部分。
- 天雷之下，陆地边缘不断崩溃，但内部随雷霆游走**愈发稳固**，越来越像一件**法宝**。
- 此法宝威力难以想象，因其：①材料为**仙界碎片**，非世间凡物；②**并非修士炼出，而是「天」所炼**。
- 血祖察觉此点后倒吸口气、眼露贪色——以其修为世间已少有法宝能令其动心，此刻却怦然心动。

## 三、要点提炼
- 血星线彻底终结：星毁、紫芯死、血阁易主、血奴血卫获自由。
- 血阁被王林吞入体内待研究，成为后续伏笔。
- 本尊与分身感应恢复稳定，双线（六级修真星藏身 / 雷之仙界渡劫）并行。
- 天劫非灾而是机缘：加速融合神秘老者之力与血祖血身。
- 碎片陆地正在「天炼」成宝，血祖起贪念，埋下争夺伏笔。


# 第766-768章 天劫为食：王林连破阴虚、阳实，反击血祖

> 所属卷：第七卷 名震罗天。地点：仙界碎片所化的碎片大陆（罗天星域范围内）。

## 一、开场：血祖的算盘与真正的天劫

- 血祖感慨「一饮一啄自有天定」，自认此番损失太多，但断定**仙界碎片若经过天炼，威力将截然不同**，可散发当年真正的仙界之威——「此物就是为老夫准备」。
- 云层内原有雷霆尽数消失，翻滚酝酿出**一道黑色雷霆**，这才是真正的天劫，直奔碎片大陆而去。
- 同一刻，碎片陆地深处的王林睁开双眼。

## 二、第767章 阴虚：以天劫为养分的突破

### 触发
- 黑雷劈裂大地，直接轰在缝隙深处的王林身上。雷霆入体，与**半具血身**、**神秘老者的气息**三方在其肉身为战场撞击，化作大量天地元力，元神疯狂吞噬成长。
- 王林被雷一霹反而彻底清醒，忆起当年在**妖灵之地**所历天劫。
- 他立刻察觉体内混乱：不尽快解决，不待天劫灭他，自己就会爆体。故**不惊反喜**——「这天劫，来的正好」。

### 收物起身
- 王林拍地而起；仙剑内的**许立国**尖叫求带（要回储物袋，「这里太可怕了」）。王林右手一召，将仙剑连同**仙界山石**一并收入储物袋。

### 雷劫层层加码
1. **四道黑雷**从上下左右齐至，其中下方雷电竟穿透碎片陆地打中王林；王林张臂不闪不避。
2. 三股力量碰撞前所未有剧烈，散出浓郁天地元力，王林咆哮，气息疯狂攀升，元神完成**问鼎后期大圆满 → 阴虚**的关键过程，突破成功；突破瞬间他仿佛感受到了「自己的道」，天地万物清晰无比。
3. **八道黑雷**齐落，王林元神冲出眉心，已不再是人形，而是彻底化作**太古雷龙**，连吞八道闪电，回体后释放，换来更多元力，阴虚瞬间稳固并向阴虚巅峰推进。

### 血祖的反应
- 血祖本幸灾乐祸盼王林被劈死，闻长啸而变色，判断是「我的那半具血身内的元气」让此人暂抗天劫并达阴虚；随即再变色——「还在攀升」。

## 三、第768章 阳实与反击

### 七彩天劫
- 云层凝出**七彩雷霆**，为王林生平所见天劫中首次出现的形态；碎片大陆边缘再度崩解、体积缩小而质地愈坚。
- 七彩雷带魔音，令王林四周浮现无数熟悉人影（心魔幻象），王林目光始终平静。
- 七彩雷落，王林被生生打落地面，体内血身与老者气息大范围瓦解；他一跃而起，全身电光游走、头发无风自动，「犹如仙魔」，喝道「再来」。
- 七彩雷如雨落下，笼罩整个碎片陆地，最终碎片只剩**不足千丈**。

### 阴虚巅峰
- **半具血身彻底崩溃**，化作无数元力融入王林元神，修为由稳定的阴虚直冲**阴虚巅峰**，无限接近阳实。
- 王林判断：若不清除体内残余的神秘老者一口气，将对身体造成大影响。遂决意「富贵险中求」。

### 主动反击天劫
- 王林**首次主动进攻天劫**：冲入雷层张臂猛吸，引所有云层凝聚、无数闪电落身；元神散开包裹全身，边吸雷边令老者气息在雷下消散、化作天地元力。
- 他张口吞噬云层，云层渐薄，远处血祖都能看清其身影，惊呼「疯子」——「没有人在天劫下会去主动反抗」。
- 王林认定这是**自修道以来除看见第三步方向外最大的机缘**。

### 突破阳实
- 老者气息**全部消散**，体内再无驳杂力量、只余元力；修为自阴虚巅峰突破至**阳实境界**，并随肉身内仙力散尽而迅速稳固。
- 血祖头皮发麻：「不能让他继续，若是继续下去，说不定此人都可以达到窥涅初期」。

### 云中交手
- 血祖化血影冲入云层。因无雷之元神、修为大降，他在天劫中生出敬畏之感，且越待越有危机感，欲速战速决。
- 王林凭**雷元神**在天劫云层中如鱼得水、如履平地：老者气息（此前）抵消雷力、体内元力庞大。
- 交手：王林右手下斩施**斩罗诀**，击溃血祖血影神通；血祖以血光符文崩碎，逼退四周云层一丈；血祖凝双血球扑杀。王林隐于云层游走、退后并持续吞噬雷云，斩罗诀毫不顾惜元力挥出，如斩开规则的利刃。
- 血祖首次见王林时错觉所见非人，而是**一条全身闪烁雷光的雷龙**。
- 收尾：王林右手按眉心，元神冲出化作**长约百丈的太古雷龙**，肉身以神通牵引落地盘膝打坐，喝道「血祖，你既送上门来，索性成全了王某吧」。
- 血祖怔望云层，杀机更浓：「我来杀他，却为他送了一场造化，我，不甘心」。

## 四、关键设定（lore）

### 元神的真义
- 修为未达阴虚、未历那一关键过程，所谓元神**全部都是虚假**。
- **真正的元神**：可吞吐天地元力，在元力之中新生。
- 上古**练气士**修的是一口气（元气），气在体内酝酿日久便**气化成神**，此神即元神；今世修士在这一步上次序相反，唯有达到阴虚后才可勉强追上当年练气士的脚步。

### 阴虚 / 阳实 / 化元
- 阴虚、阳实是**修道第一步与第二步之间的过渡**，取「阴阳圆满」之意。
- **阴虚 = 元神改变**；**阳实 = 仙力消散**，修士体内完全被元力取代。
- 该过程称为**化元**：彻底把修士改变成如练气士般的存在。
- 自练气士之后、自仙界崩溃仙人损落之后，本界修士中只有**极少数人**能在问鼎大圆满突破的瞬间连续度过两境，这些人日后无一例外站在**第二步的最巅峰**。此事**与天资无关，起最大作用的是元力**。

### 度境耗时对照（本章给出）
| 人物 | 度过阴虚+阳实耗时 |
|---|---|
| 天运子 | 三百年 |
| 凌天候（剑尊） | 八百年 |
| 血祖 | 近千年 |
| 王林 | 一次天劫内连续完成 |

### 境界序列
- 问鼎后期大圆满 →（第一步极限）→ **阴虚** → 阴虚巅峰 → **阳实** → **窥涅**（血祖现修为为阳实巅峰，距窥涅尚差一丝）。

## 五、状态变化清单

- 王林：问鼎后期大圆满 → 阴虚 → 阴虚巅峰 → 阳实（本片段末已稳固）。
- 王林元神：彻底化作太古雷龙形态（出窍时约百丈长）。
- 王林体内：**半具血身彻底崩溃**（转化为元力）、**神秘老者的气息全部消散**、体内仙力散尽只余元力。
- 血祖：修为持续削弱至阳实巅峰；已由虚体凝实为肉身；损失一半血身，反成王林造化。
- 碎片大陆：被雷劫轰击至不足千丈，越小越坚固。
- 许立国：仍在仙剑内，已被王林收入储物袋。
