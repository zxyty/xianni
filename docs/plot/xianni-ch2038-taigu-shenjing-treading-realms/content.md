# 第2038章 太古神境！

## 一、王林：燃大天尊之阳，强行踏界

- **力量来源**：王林依靠**仙皇之魂**，短时间融入**仙祖头颅**之内，使头颅融化了一些，与他的**大天尊之阳**融合，由此借来一股极强之力。
- **燃阳换力**：随着大天尊之阳燃烧，巨大的尊阳肉眼可见地急速收缩至极限，化为虚无的同时，其内全部力量以奇异方式涌入王林体内，支撑他提起右脚向前迈出一步；迈步刹那王林低吼，身外凭空回荡轰鸣巨响。

## 二、空间判断：为何能踏界

1. 传送阵所在空间与**仙罡大陆**空间不同——所以此前王林的一切攻击对此阵毫无作用，阵法如透明一般，看得到却摸不到。
2. 但此阵出现在此地并能吸收**来自皇宫的死气**，足以说明：即便是不同空间，在此地也存在**重叠**。
3. 王林曾在**仙族皇宫**内遇到过类似的一幕，故识得此类神通。
4. 王林的打算：以燃阳换来的踏破虚空之力融入这一步，凭强悍肉身与修为，从自己所在空间**生生踏入**阵法所在的另一空间。此举堪比从**洞府界**迈出一步即落在仙罡大陆之上；隔界而过对**大天尊**亦难度极大，除非另有手段（如仙族皇宫那样早已开辟出入口），而王林是在**没有入口**处硬踏，难度极大。

## 三、无形之网与道古国师的阻挠

- 王林右脚将落时，身外轰鸣滔天，**传送阵光芒急速闪烁**，其面前隐隐出现一张**无形大网**，其脚踏在网上使网弯曲；踏破此网即可踏界而过。
- 此网肉眼不可见、只能模糊感受；随右脚落下，网似达承受极限，王林身体颤抖、额头渗出头大汗珠——即便借来莫大之力，仍极为艰难。
- **道古国师**（与**天运子**、**七彩仙尊**相似之人）正因王林此疯狂之举而色变：起身双手掐诀，**十色光芒**回旋直奔王林脚下之网，使网凝固不少、更具韧性，隐隐反弹欲将王林右脚抬起。
- 与此同时，王林前方那**巨大的苍蝇之兽**发狂撞击，欲撕破阻拦它临近的壁障冲向王林。

## 四、以吾之血，引苍穹之魂

- 稳固大网后，道古国师**咬破舌尖喷出一口鲜血**；诡异的是这血并未落在其脚下阵法上，而是**穿透阵法不知去向**。
- 阵法运转随即**加快数倍**，引动阵阵喃喃之音回旋四周，如无数人说话却听不清晰。
- 老者低吼：「**以吾之血，引苍穹之魂，开**」——阵法运转中赫然出现**大量虚幻之魂**。
- 关键震撼：这些魂**竟都是曾经在洞府界死在王林手中之人**，王林见之身子蓦然一震。

## 五、天幕漩涡与仙族大地异象

- 首批死魂化作一股黑气冲出传送阵，极速上升冲入天幕，化作**一个巨大漩涡**，漩涡中骤然出现一片虚景。
- **虚景内容**：折射的是**仙族大地**——山海洲的山海之内，零散几个修士望海目瞪口呆；大海咆哮巨浪翻滚，整个海面凹陷，一根**足有万丈粗细、不知多长的巨大黑色柱子**自海底轰轰而起，破开海面直奔天空，一闪消失。
- **王林反应**：心神震动，不知其代表何意，但毛骨悚然，似有惊天之事将与此刻同时震惊整个**仙罡大陆**。
- **续招**：王林深吸口气，右脚狠狠踏下欲踏破此网；网被加固后爆发无穷之力阻止，脚与网之间轰轰不断。道古国师则**连续喷出三口鲜血**，引来更多死魂——同样无一例外全是死在王林手中之人，它们嘶吼狰狞、面露痛苦，化作黑气陆续直奔天幕，**化作三个巨大漩涡**，与先前那个漩涡成**弧形排列**，其中赫然出现**三个不同的画面**（本章止于此，画面内容未揭）。

## 六、要点与悬念

- 王林的攻坚方式已从「攻击阵法」转为「**踏入阵法所在空间**」，胜负手在于能否踏破那张被十色光芒加固的无形之网。
- 道古国师的反制核心是**以自身精血为引召唤「苍穹之魂」**，且所召皆为**王林旧日因果中的亡魂**——针对性极强，兼具心神冲击与仪式意义。
- 四个弧形排列的天幕漩涡＋仙族大地海底万丈黑柱冲天，暗示**仙罡大陆级别的惊天变故**正在同步发生。

## 一、四海巨柱同时冲天

- **云涛洲**：一座庞大海洋平日浪花不大，海中诸多小岛住有不少修士。此刻海水骤然咆哮，无数岛屿被淹没，修士骇然飞起。海面化作凹陷，一根同样大小的惊天柱子蓦然而起，直奔天幕而去，消失无影。
- **另外两处**：毫无例外都在仙族内的海洋，海水呼啸，巨柱冲天而去。
- **最后一处**：并非海洋，而是**武封大天尊闭关的冰封之地**。冰层骤然爆开，露出下方寒冷深海，巨柱破冰而出，轰开一座冰山向天而去。

巨柱散发出**沧桑**之感，如存在了无数岁月，更有莫大威压散开，惊天动地。武封站在远处望着这一幕，喃喃：**「竟提前了」**——随即双眼露出精光。

> 要点：巨柱共四处（云涛洲一处 + 仙族海洋两处 + 冰封之地一处），时间被判定为「提前」。

## 二、王林借虚无分身之力，踏破大网

王林在天幕上的漩涡中将这一幕幕看得清清楚楚。眼看道古国师正要喷出第五口鲜血，他没有丝毫犹豫：

1. **召唤虚无分身**（其最强的分身）——身外朦胧之雾凭空出现，笼罩全身的一瞬修为轰然暴增。
2. **全力一踏**：全部力量凝聚于右脚，狠狠踏向那大网。右脚上出现重叠虚影，正是虚无分身幻化重叠。
3. **踏出缺口**：砰的一声，大网直接崩溃一个缺口，右脚落地一瞬便踏在了阵法所在的空间之内。

此为其**极限之力**：全身无法进入那空间，唯右脚可入，但已足够达成目的。

## 三、杀戮真身「戮默」入阵

- 右脚黑芒一闪、猛然抬起收回的同时，王林全身钻出无数黑气，顺着**正在愈合**的大网缺口疯狂钻入。
- 黑气在阵法边缘、道古国师前方凝聚，化作一个**满头黑发的王林**，双眼无情冷漠、没有丝毫情绪——正是被送入的**杀戮真身**。
- **说出真身之名「戮默」的，竟是道古国师**。老者死死盯着它，眼中恐惧之意一闪而过。
- 杀戮真身开口：「我不习惯隔着空间与人交谈，还是喜欢像这样，当面谈话。」
- **阵内空间描写**：四周仿若无限大，又仿若只有如此大小，给人诡异错觉；隐隐有阵阵喃喃之音自四周传来，仿若无数人在说话，却无法听清一句。
- 阵法外，**王林本体盘膝坐下、双目闭合**，全部神识凝聚于另一空间的杀戮真身之上。

## 四、道古国师的阻拦与太古神境之秘

杀戮真身右手抬起、无数黑丝幻化，正要毁灭此阵。道古国师急言：

1. **毁阵 = 李慕婉再无苏醒可能**。残魂只是残魂，即便抽出后融入**避天棺**内，她也无法苏醒；**让死人复活，唯有依靠此阵**。
2. **吉祖魂血创族之力**可让其暂时醒来，但**逃不出轮回**，数年之后依旧化作残骸。想不受轮回限制，也唯有依靠此阵。
3. 王林（本体睁眼）与杀戮真身同时追问：**「此阵打开的是什么地方」**——答曰：**「太古神境」**。
4. **超轮回之法**：要让李慕婉从此不在轮回之中、不受轮回之苦，就必须去太古神境。那里可以**遮盖轮回**，可以**展开轮回本源**，**破开李慕婉的梦障，寻找其真我**，如此可超轮回。
5. **开启方式**：太古神境历代开启都只是**部分**打开；而以道古国师之法，**可将其完全打开**。

**外貌提示**：道古国师与**天运子**及**七彩仙尊**相似。

## 五、悬念

道破一切之后，杀戮真身右手一顿，却**竟要再次落下**，仍作毁去此阵之势——是否毁阵、是否入太古神境，本片段未决。
