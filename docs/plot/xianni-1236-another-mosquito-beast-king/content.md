# 第1236章 另一个蚊兽王（第九卷 云海之巅·第三更）

## 一、外围探查：仙玉与蚊兽分布规律
- 王林以其速度用两天绕风之仙界外围飞了一大圈，一边搜寻红雾中的蚊兽，一边在风仙界内发现并收获了不少**仙玉**——因蚊兽盘踞，进入此界的修士极少，故所获颇丰。
- 异常之处：外围被风吹来的蚊兽红雾越来越稀少，最后常常数个时辰才见一处从天边滚来。若风界蚊兽仅此规模，绝不足以令云海修士止步、谈仙界而色变。
- 观察结论：**蚊兽大都凝聚在风界内部**，外围红雾只是被风从内部吹出，所以稀薄；深处蚊兽极多，必然存在更强大的蚊兽乃至蚊兽王，不可贸然闯入。

## 二、召唤引诱：从上千到数万的震撼
1. 王林心神一动，蚊兽王轻嘶，旁边赤红色蚊兽仰天剧吼，声中带穿透力，如遇生死危机召唤同伴，嘶鸣化作无形波纹回荡全界。
2. 第一波来袭：天边滔天红芒、雷鸣轰隆，数量上千，风界天空震颤裂开大量裂缝。
3. 蚊兽王飞出，淡金色光芒环绕、威压横扫：
   - 赤红色蚊兽立刻臣服；
   - 近百**暗红色**蚊兽挣扎片刻后臣服；
   - 数十只**褐红色**蚊兽瞬间倒退欲远遁。
4. 王林正要示意追击，第二波来临：**不下数万**的无边蚊兽群轰隆而至，其中有一大片蓝光、一小片白芒。以蚊兽王当前状态难以同时凝聚，王林头皮发麻。
5. 王林隐匿身形，被近两千蚊兽包裹，由蚊兽王带队远远避开。大群蚊兽环绕一圈未发现敌踪后退去，但遮天盖地一幕永留其记忆。

## 三、蚊兽等级谱系（本章所见）
| 色阶 | 对应/描述 |
| --- | --- |
| 赤红色 | 最基础、数量最庞大 |
| 暗红色 | 高于赤红，第一波中近百只 |
| 褐红色 | 高于暗红，数十只，不惧威压欲逃 |
| 蓝色 | 气息**堪比净涅修士**（落单者为净涅初期，深蓝者堪比净涅中期）；对红色蚊兽极为霸道 |
| 白色 | 通体半透明，散发**碎涅气息**；数万群中约三百余只 |
| 紫色 | 仅见于**涂司的记忆**，王林不知相当于何等修士 |

- 王林估算：三百余只白色蚊兽的力量**足以胜过数万赤红蚊兽**，为之升起贪念。
- 定论：「这风仙界对别人来说是一个生死之地，但对我来说，这里，是我王林此生最大的宝地。」

## 四、悬而未解的两个疑问
1. 蚊兽王**得自朱雀星**，王林至今不知此兽为何会出现在那里。
2. 自己的蚊兽曾达紫色、如今已至**金色**，实力却远逊于风仙界蚊兽；若非那属于蚊兽王者的威压，王林甚至怀疑自己的蚊兽是否为真。困扰已久，本章仍无答案。
- 后续从落单蓝蚊兽处得到旁证：其难以操控「与我那只蚊兽并非生长在这里有关」。

## 五、策略转向与收服落单蓝蚊兽
- 引诱之法风险不可控、代价太大，王林决定**缓慢深入、伺机而动**。
- 进入风仙界**第五天**，仍在外围但略近中心处，遇一片漂浮的**仙界碎片大陆**，前方蓝光闪烁——一头**净涅初期**的落单蓝色蚊兽。
- 蚊兽王长嘶阻其前行；蓝蚊兽眼露迷茫挣扎。蚊兽王化淡金长虹冲上，口器横扫将其抽出百丈；蓝蚊兽欲化蓝芒逃遁。
- 蚊兽王全身淡金光散、嘶鸣更嘹亮，四周红色蚊兽尽皆颤抖恐惧；蓝蚊兽体内两种意念碰撞，终于飞至蚊兽王身前臣服。
- 王林一步迈至其旁，蓝蚊兽狰狞欲以口器扫向王林，被王林抬手一指定住不动。
- 王林以**神识**探入其头部读取记忆：**前方不远处存在另一只蚊兽王**；此界之大，蚊王虽不多但应有一些。

## 六、关键计划：杀蚊王、吸收、接管其群
> 「按照蚊兽的习姓，若是那只蚊王死亡，被我的蚊兽吸收，就可全面接受它所艹控的所有蚊兽。」
- 这一想法极为大胆，王林咬牙决定实行。

## 七、元神附体：伪装潜入
1. 王林落于下方仙界碎片大陆，两千蚊兽随蚊兽王落下环绕，中心被红云弥漫遮蔽，外人难辨其内有人。
2. 王林盘膝掐诀，闭目点向眉心，**意境所化规则之星**闪烁旋转、自眉心飞出，落于蚊兽王身上。
3. 王林**元神出窍**化作青光，融入蚊兽王身上的规则之星内，烙印于蚊兽王。
4. 蚊兽王身上淡金色光芒收敛隐去，幻化出淡淡蓝芒——外观、气息俱如一只**普通蓝色蚊兽**，兽王威压被王林元神完全封印，不漏半点。
5. 蚊兽王留下命令：两千蚊兽**哪怕全部死亡也要保护王林肉身**；新收的蓝色蚊兽成为留守群中最强者，虽仍对王林凶焰连连，却贴身密切护卫其肉身。

## 八、潜行沿途与目标锁定
- 王林操控伪装后的蚊兽王疾驰，数个时辰间遇**三波百只规模的蓝色蚊兽群**呼啸而过，其中一只蓝芒略深、气息堪比**净涅中期**者飞过时回头看了一眼，目露迷茫，未加阻拦。
- 王林震惊感叹：「难怪就连涂司当年都要狼狈而逃」——蚊兽单个不强，胜在数量；仅外围如此，若入内部且蓝、白以上蚊兽数量巨大，**天人衰劫修士在此也会尸骨无存**，冲出希望渺茫。
- 沿途无任何修士气息：「这里，是蚊兽的世界。」
- 目标现身：碎片大陆边缘一处**极为庞大、高耸入天的山脉**。
  - 山脉外：数千赤红色蚊兽 + 数百蓝色蚊兽环绕飞行，蓝色蚊兽极为霸道，红色蚊兽遇之连忙让道。
  - 更深处、近山脉天空：两只**白色蚊兽**抓在山壁上，以巨大口器不断摩擦山石，发出刺耳之声。
- 王林元神收拢于规则之星内，密切观察：「就是这里了。」
