# 第九卷 云海之巅 第1312章 宿命第一战（第一更）

> 归档批次：仙逆 01227-01231 之1。按【世界状态须知】，王林自第1063章起以归元宗故人『吕子浩』之名行走云海星域（身份由吕烟菲奉上），本章文本直呼其本名王林，言行均归【王林】。

## 一、战前态势

- **拓森**：碎星之后（九星→现存六星），受古神**传承法则**限制，无法施展众多古神神通，但**肉身之力**已足以惊天动地。
- **王林**：六星古神，眉心第七星呈朦胧漩涡、急速旋转似要凝固；手持来历神秘的**血剑**；体内携有**开天巨斧残留气息**；一路抽取了**七个修真星之魂**。
- **战场**：月族所在，大地遍布**古神雕像**，充盈**古神之气**。

## 二、交锋过程（按序）

1. **血剑 vs 拳风**：王林后退中斩出血剑之芒，与拓森一拳相撞，轰鸣震天。
2. **开天巨斧残气**：王林大袖一甩，虚幻之斧如流星轰向拓森右拳。血剑锋利胜过拓森肉身，拳头碰撞见血；斧气顺血肉冲入其右臂，青筋鼓起、血脉怒张，拓森**身形被阻一顿**——这是二人第一次真正的正面交锋。
3. **拳风余威**：王林双臂前档、爆发全部古神之力硬抗，感觉如被一颗修真星撞击，喷血倒退，撞入一座古神雕像。雕像碎裂，古神气息涌入其体内，**伤势刹那恢复**。
4. **七个修真星之魂**：王林左拳散出七个乳白光团，幻化七个巨大修真星虚影撞向拓森。拓森双拳轰击，先爆一颗（星域月色随之崩溃化作月晶消散），再爆两颗，最后以身如流星一撞将剩余四颗**全部撞碎**。
5. **齐天掌印（役灵印）**：王林掐诀，元力与古神之力尽注左掌，吸引八荒天地元力化作实质掌印。拓森双手抬起狠狠一撕，掌印被**撕裂一分为二**从其身侧穿过。
6. **鲁夫子式一击**：王林早不指望掌印能挡，同时左手按上拓森挥来的右臂，右手在左手背连点数下，如当年**鲁夫子**一般抽空星空之力融于一掌正面对轰。王林喷血、骨骼作响，撞入另一尊古神雕像补充古神之气；拓森身形又是一顿，随即张口吸走此地**大半**古神之气（王林占近四成）。
7. **古神·神拳**：拓森化作遮天巨掌抓来（意在**生擒**而非击杀）。王林借浓郁古神之气，毫不犹豫施展六星古神可发挥的古神神通——**神拳**：双掌握拳、血剑在中，全身化作惊天漩涡，体外幻化古神虚影，**将拓森右手震得生生抬起**。王林则全身喷血、化作血人坠地。
8. **吞噬与反转**：拓森右手发麻、心神震撼，惊觉王林短时间内成长如此之快，遂以眉心**六个星点**急速闪烁笼罩王林，欲如吞噬第三步大能一般吞噬之。王林目露奇异之芒——他等的就是这一刻，开口道：「拓森，你以为涂司，真的死亡了么」。拓森面色大变，**异变骤起**（本章戛然而止）。

## 三、关键设定披露

### 拓森的实力构成
- 本体为**古神涂司**（王林斥其为「涂司一缕魔念」）。
- 星点账目：当年闯**封界大阵**爆开一星；与三个**第三步大能**一战又爆开一星；现剩**六星**。
- 但涂司存活太久，其**肉身强悍程度无限接近九星**，非六星可衡量。
- 独创神通：**封印第三步大能以催发自身星点之力**。星点内尚有一尊被封印的第三步大能，加上此前封印的女子。

### 传承之分（本章核心矛盾）
- 王林 = **记忆传承**（知晓古神神通，却无力施展）。
- 拓森 = **力之传承**（掌握涂司全部肉身之力，明悟**力之本源**）。
- 拓森据此断言：「你即便达到六星，凭什么与我争夺，唯有我拓森才是真正的古神。」

### 拓森的诉求
反复咆哮劝诱王林**融合**：融合后本神可达当年涂司巅峰、可破开传承法则、发挥古神一族莫大神通、重现古神一族辉煌。因此其手段是**生擒**而非杀死。

### 时间线锚点
- 拓森称「本神给了你近两千年的成长」。
- 王林自认「存活不到两千年的古神」，与涂司无法相比。

## 四、看点与伏笔

- **伏笔（未解）**：「涂司真的死亡了么」——王林蓄谋已久的杀招，直指拓森作为「涂司一缕魔念」的身份根基，下一章异变待揭。
- **对比**：王林的成长速度远超拓森预期，是其心神震撼的直接原因。
- **代价**：七个修真星之魂全数损耗、两度撞碎古神雕像疗伤、全身化作血人——王林已近力竭。
