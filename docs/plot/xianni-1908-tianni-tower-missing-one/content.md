# 第1908章 缺了一个！

## 一、再入天逆大门

- 天逆圆满者可现「天逆大门」，王林此前曾数次进入，所见惟有一片苍茫；门上青色手臂蕴含强大威压，阻止一切人踏入。
- 此番王林已是**空劫大尊**，青色手臂抓来时被他随手一拍，掀起数十丈；手臂再度扑来，王林不愿毁之，抬手一指喝「定」，一字定身，手臂僵在半空。
- 王林连行七步至门前，左手按门内推，门开数丈缝隙，整个人踏入。
- 触发点：王林反复思索**蝎魂死前所言「白珠」**之意，遂决意再探。

## 二、门内世界：无门四方塔与四具骸骨

- 门内是他从未见过的世界：**有天有地，却无任何生命迹象**。
- 群山之中，一座高耸入云的塔，**在虚幻与真实之间闪烁，时而为真，时而为幻**；塔顶一片模糊。
- 此塔**四方形、越上则细、通体无门**。
- 塔下四方之角，赫然有**四具盘膝骸骨**：两具白袍、两具黑袍，不知存在多少年，散发阵阵死气。
- 与以往不同：这一次不是当年所见「封界至尊」之所在，仿佛此前皆是迷雾，如今迷雾掀开，王林**无限接近天逆的核心隐秘**。

## 三、两次神识触塔

### 第一次
- 神识碰触塔的刹那，脑海轰鸣，无数细微声音涌入：婴儿出生的啼哭、老人死亡的叹息、凄厉惨叫、温和呢喃……如置身凡间庞大都城听尽所有声响。
- 众声化作嗡鸣疯狂环绕，王林面色苍白，**以其空劫大尊修为竟有无法承受、濒临崩溃之象**。
- 一声**婴儿凄厉啼哭**刺入心神，令其惊醒，后退十余步，面色煞白。
- 王林认出：那正是**王平尚为怨婴时，他听到的第一个声音**。他遂寻至天逆内沉睡的**王平与王平妻之魂**处，默然良久，目露柔和与悲伤而去。

### 第二次（自残取痛为锚）
- 王林咬牙再至塔前，先行准备：右手指甲延长如针，握掌欲刺入掌心，掌心有一层柔和之光阻挡，约**十息**即将散尽。
- 神识散出触塔，嘈杂之声再度轰入，王林如怒海孤舟，双目无神、身躯颤抖。
- **第九息**白光散尽，锋利指甲刺入掌心肉内，鲜血滴落，剧痛传遍全身，王林蓦然清醒。
- 清醒瞬间，他从嗡鸣中听清一句若隐若现的话——**「缺了一个」**。
- 王林倒退数百丈，眼中露出罕见忌惮：短短十息如经生死考验，若无第一次的婴儿啼哭与第二次的早有准备，恐已沉溺众声、失去自我。

## 四、出关与结论

- 场景切回**绿魔洲**：本应是**蝎庙**所在之地，此刻被风暴弥漫，风暴中站着一名闭目的**白发青年**（即王林），睁眼时眼中仍存深深忌惮。
- 天逆珠子完全没入王林手心，融入身体、无踪于灵魂之中。
- 王林自评：
  - **「我的神识还不够，还远远不够」**，总有一天要压过嘈杂之声、听清其内隐藏的话语。
  - 获得此珠**已近三千年**（伴随他两千多年、已近三千年），有足够耐心等待答案。
  - 能看到那塔，已说明**距离珠子真正的隐秘很接近了**。

## 五、转向：道魔宗劫

- 王林抬头望向**道魔宗**方位，寒意毕露，重申当年誓言：**灭道魔宗满门、毁其道统，让仙罡大陆从此再无道魔一门**。
- 大袖一甩，四周风暴化作巨大黑色飓风，卷其身直奔远处。
- 章末定调：**「道魔宗劫，降」**。

## 六、悬念清单

1. 「天逆」到底是什么？困扰王林两千余年、近三千年。
2. 四方无门之塔的本质；塔下两白袍两黑袍四具骸骨的身份。
3. 「缺了一个」——缺的是什么/是谁？
4. 蝎魂死前所言「白珠」之意仍未解。
