# 第八卷 联盟隐秘 第930章 联盟长老团

## 一、王林浑水摸鱼夺银尸

### 事前预判
- 王林事先察觉变故，准备充分：在**古神一指自爆前一息**急速后退，并施展**古神大鼎**神通，因此受波及很小。
- 退避时特意调整方位，目的就是那具**银尸**。
- 两具银尸中，男尸伤重被放弃；女尸受伤明显轻得多，被望月抛向王林方向。
- 心理独白：「我参与这大战，即便是捞些法宝，想必也不会有人说些什么，更何况此刻这战场大乱。」

### 七人争尸与女尸的古怪
- 战场上共有**七人**（罗天、联盟双方皆有）同时扑向女尸；王林并非最近，但速度最快。
- 王林察觉女尸不对劲，**故意略微放缓速度**试探：
  1. 一名罗天修士抢先抓向女尸，一名联盟修士吐剑光拦截，二人近距离撕斗；
  2. 另一罗天修士趁隙抓住女尸手臂，瞬间惊恐惨叫、身子萎缩、化为一滩血水；
  3. 撕斗二人犹豫后仍同时出手，同样惨叫枯萎化为血水。
- 三人精血被女尸吸收，**凝聚眉心成一点妖艳红芒**。
- 王林的判断：若女尸始终如此古怪则宁可放弃（大战中自保为先）；但发现其**吸收三人精血后隐约有变化**，遂决定继续争夺。

### 换位与「定」
- 王林以古神大鼎神通，**与一名冲上前的罗天修士瞬间互换位置**；该修士知晓王林身份，苦笑退走另寻目标。
- 一名**蟒袍联盟修士**几乎同时抵达，手中蕴含神通，看似抓取实为攻击女尸，讥讽道：「雷仙许木，原来也贪图这女尸的美色。」
- 王林双指成剑喝「让开」未果，遂一指喝「**定**」——该修士如被无数无形细线缭绕，刹那不能动。

### 破红芒、封印入袋
- 王林抓取手法巧妙：触及女尸瞬间运转体内元力，凝聚**古神之力**，幻化**阴阳双鱼**印在女尸眉心。
- 砰然一声，女尸震动，眉心红芒**涣散**。
- 王林抓住女尸掠过被定住的联盟修士时，右脚踢中其胸口——白光一闪，该修士倒卷喷血、面色苍白但未死，恶毒瞪视后捂胸急退。
- 女尸身上血光弥漫涌向脸部，涣散中再度向眉心凝聚；王林左手掐诀打出无数**禁制**，喷一口**元神精气封印**，收入**储物袋**，随即直奔远处星空崩溃处。

## 二、主战场态势

- **万里星空崩溃**形成巨大漩涡，吸力欲吞噬一切；唯独**望月**不受影响，横冲屠杀。
- 联盟数名老怪环绕阻拦望月，**云龙妖尊**亦临近。
- 罗天方面：**血神子**等人 + **罗浮血球**所化的一个个血人环绕望月，与联盟修士交错混战，呈**压倒性**之势。
- 上方：**炎雷子 vs 武东禅**，黑雾内翻滚云涌，波动余威连血神子等人都要避开。
- 远处：**水罗蓝裙女子**神色平静如水；身旁**龙袍金尸**冷漠站立，头顶**五张黄纸**缓缓旋转、丝丝雷光与其天灵连接，持续封印。

## 三、请出玄宝上人

- 水罗蓝裙女子抬手一指前方：「请**地玄殿大长老，玄宝上人**。」
- 一声长笑回荡星空——笑声中并无多少修为蕴含，却令四周**几乎所有修士的法宝齐齐一颤，好似要脱主而出**。
- 逃遁中的**黑煞魔尊**松了口气；**云龙妖尊**神色一松，索性不再交战、急速后退。

## 四、设定披露：修真联盟的真正顶层

### 两殿四尊八方界
- 所谓「四尊」并非只有黑煞魔尊、云龙妖尊等几人。
- 真正的四尊 = **月、云、贤、药**四人；**极贤天**即其中的**贤尊**。
- 这四人**每人各有三个手下**，相互之间任何一组都可组成「四尊」。
- 此番大战，修真联盟实际只出动了**地玄一殿、一尊三界**。

### 联盟长老团
- 玄宝上人在地玄殿身份极高；但令联盟上下恭敬乃至惧怕的真正原因，是他为**联盟长老团**成员之一——该团可**决定联盟星域一切事情**。
- 长老团具体人数，除成员外无人知晓；每一成员都是在联盟星域中**可以逆转乾坤的极端强者**，掌握联盟一切隐秘与力量，是联盟星域**真正的王者**。
- **天运子亦是长老团成员**：故其寿宴修真联盟都要送贺礼。后因一场变故地位一落千丈，但仍保留成员身份；此后更加低调，连长老团会议也几乎不参与，仿佛自我封闭。
- 若非天运子低调，**根本不会有凌天候等人的存在**——只要他愿意，一切可在瞬间消失。
- **极贤天**与**武东禅**都**没有资格**成为长老团成员，在玄宝上人面前「什么也不是」。
- 成为成员的门槛无人知晓，有人怀疑与修为有关但绝不占全部。

### 玄宝上人形象
- 一身白衣，略显清瘦，仙风道骨；双目明亮深邃，与之对望会沉浸其中久久不能自拔；容颜和善如真正长者，手持拂尘。
- 与水罗蓝裙女子的关系：女子恭称「**师叔**」。
- 玄宝上人语：「丫头，你师尊让你来主持这场战事，一切人等听你号令，又特意选择此地作为战场，这等造化，可不常有。」
- 对眼前战事**丝毫不放在眼里**；唯独看向**望月**时**瞳孔一缩**，露出**大有深意的笑容**——伏笔。

## 五、要点与伏笔

1. 王林获得一具会吞噬修士精血、并在吸血后产生变化的**银尸女尸**（已封印于储物袋），后续用途待观。
2. 王林此时在联盟中的公开身份是「**雷仙许木**」（自创化名），被联盟修士当面称呼。
3. 阴阳双鱼 + 古神之力可**击散**女尸吸血凝成的红芒，是对付此类炼尸的手段。
4. 联盟真正的权力核心是**长老团**，凌驾于两殿四尊之上；**天运子**竟是其成员——为王林与天运子的关系埋下极大伏笔。
5. 玄宝上人对望月的意味深长笑容，暗示其对望月来历/弱点另有所知。
