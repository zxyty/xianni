# 第2019章 风起道古！

## 一、参悟古祖一指与第六条神脉

- **对古祖之术的判读**：王林喃喃分析，古祖那一指「施展的不是神通，而是沟通天地，亦或者说操控天地的力量」；攻击对象并非那群诡异凶兽，而是凶兽所在的**天与地**——撕开那片天地，以一指作为逼压，令天地坍塌挤压，凶兽只是附带。
- **模仿受阻**：王林抬手缓缓点出，手指前方却似有一层层无形壁障，无法如古祖那般点去；半晌收指，不再尝试，低头沉吟。结论是「古祖之强，已然到了一种另外的境界」，但凭脑海中的记忆碎片与**速神诀**，尚可略作模仿。
- **开辟第六神脉**：体内驳杂元神来自**仙族祖城**杀戮所得，久已默默炼化、凝聚将成，足够再开一条神脉。王林原有五条神脉，一动之下可现**九十九道残影**，遂好奇第六条之后又能如何。展开速神诀凝聚，七日时光流逝。
- **异兆**：大典前一日清晨出关，第六条神脉已成，但心神内莫名生出**一丝悸动**，来得突然，令他疑惑。

## 二、道古皇城：封后大典前夕

### 盛况
- 全城喜气洋洋，街巷由皇宫之人精心布置；夜间几乎不夜，五彩通明，连道古皇城天幕都染成五彩。
- 道古皇尊极为重视，道古一脉族人、各地强者族人与各郡之主纷纷赶赴皇城。
- **来客**：极古一脉、始古一脉使者携贺礼陆续抵达；**古道山**亦送出礼物，使道古皇尊吸引古族三脉所有人的焦点。
- **始古一脉**贺礼尤多，带队者为**皇子计都**——当年曾亲自陪同使团选出**宋致**；因皇后姓宋、系始古一脉**宋天大天尊**后人旁支子孙，宋天大天尊另派使者送来贺礼。
- **住宿安排**：来人过多，道古一脉祭出**镇族宝物**，化作**九十九座**略小于道古皇城的巨大平台，以道古天空城为中心铺展，强者在其上迅速布置居所；期间三族族人彼此交易，形成坊市与多处拍卖之地。
- **防务**：皇宫守卫森严，几乎所有道古强者与拥有皇族血脉的各地王侯尽数来临。

### 皇宫阁楼：皇尊与七属下
道古皇尊背手远眺五彩天地，宣称「朕日后，要让朕所在的地方，天天都如大典的这般日子，成为整个古族的中心」；七人单膝跪地、神色狂热表忠。逐条复命：

| 事项 | 复命要点 |
|---|---|
| 使团 | 始古、极古使团已安排；两位大天尊的使者已招待；古道山来使安排在皇城中 |
| 住宿 | 本族族人与另两族强者分散安置于四周九十九台，足以容纳 |
| 大典布置 | 全程负责，确保进行与完整 |
| 守护 | 禁一军至七军全员严密守卫，绝不出意外 |
| 国师 | 传话：大典之日会亲自参加 |
| 宋后 | 如常，整日不出，似总在回想记忆，每次皆疼痛不已，似未想起什么 |
| 大天尊 | 尚未传来话语，是否参加未知 |

**皇尊决定**：大典按规格举办**九十九天**；除第一天祭祖外其余时间不再参与；若出丝毫意外「你等当诛」。并确认道古一脉历代古皇的旧例——大典前一天夜里举行**封后庆历**，让族人与各国使者一见皇后，此事已全部安排下去。临去前独白：「朕娶她为后，给她这个身份，是最好的赏赐了，国师，朕期待你推衍出的结果。」

## 三、凤袍女子（宋后）：咫尺天涯

- 幽静宫殿内，凤袍女子对镜自望，相貌非绝伦却别具气质，目露迷茫。
- 梦醒后一切模糊：记不起梦里女子的模样、男子的相貌，**只记得两句话**——
  - 「走，我带你去杀人」
  - 「天让你死，我也要将你抢回来了」
- 闭目时泪水顺眼角滑落浸湿衣衫，自问：「我为什么会流泪？他是谁？我，是谁？是宋致么？我是宋致么？」
- **叙述者点明**：王林修为通天，却看不到这女子的眼泪、感受不到她的气息；即便当面亲眼也无法看出她是谁——因其**残魂上存在一股迷雾**遮掩一切，且与**宋致融合**后迷雾更浓。他始终要找的**婉儿之魂**，竟距自己这般近；而她也不知自己的名字、他的名字，二人同在一片天空下呼吸同样的灵气。

## 四、出关与代师赴宴

- 王林闭关**三个月**，出关时木屋中那金雾光团隐隐现出人形，开始**真身的凝聚**——「比我预料的时间要长一些」。他盘膝守候至日落，抬手将**五行真身**与金色雾气吸入体内，起身推门。
- 夕阳中**玄罗**含笑相候，言明：明日册后大典王林可不参加，但今日道古一脉**夜宴庆礼**须代师走一趟——「我知你性格不喜热闹，去后略做停留，回来就是。」
- 玄罗虚空一抓取出**礼盒**，命王林转赠**烨道**，作为自己的贺礼。王林接过未看即收起，抱拳一拜，化长虹飞向道古皇宫。
- 王林心中打算：送完礼即回继续修炼，**金本源凝聚在即**，再无更重要之事。念头升起的瞬间，心中**再次悸动**，遂皱眉望向远处皇宫方向。

## 五、伏笔与看点

1. **悸动两度出现**（第六神脉成时、决意速去速回时），皆指向皇宫方向——与宋后即婉儿之魂的伏线呼应。
2. **迷雾遮魂 + 与宋致融合**：解释了为何王林查不出、也是后续相认的最大障碍。
3. **国师推衍**：皇尊期待「推衍出的结果」，暗示封后另有目的。
4. **金本源凝聚在即**：王林修行进度节点。
5. 玄罗令王林送礼给**烨道**，使王林必然在庆历现场——与皇后照面的舞台已搭好。
