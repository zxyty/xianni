# 第1569章 朱雀星

## 一、归途：昆虚星域中的王林与疯子

- 星空平静如漆黑海洋，王林望着星光生出思乡与失去至亲之痛。
- 王林带着疯子在昆虚星域中前行，越来越接近**朱雀星**。他称自己闭着眼也能在昆虚星域内找到朱雀星——与神通或许有关，但更多是因为**那星上有让他魂悲之灵**。
- 疯子一路喋喋不休、绕圈咆哮，反复要求：把**许立国**变成树叶踩死；把骗过他的**刘金彪**变成树叶踩死，认为『为奴千年』的惩罚太轻。

## 二、王林点破疯子的『互骗』

王林被吵得思绪打断，一把抓住疯子，指出：

- 疯子交给许立国与刘金彪的**血液根本是废弃之物**，所有那些血液加起来炼化后**不及疯子真正血液的半滴**。
- 「他们在骗你，你也同样在骗他们」——疯子其实**早就看出了二人的想法与骗局**。
- 王林自陈：「我王林行事，求的是一个公平」，对二人的惩罚**已经足够**，让疯子不要再絮叨。

疯子被戳穿后眼珠一转、连忙摇头否认，随后面色微红嘿嘿傻笑，嘀咕承认「那许立国与刘金彪也的确有本事，还真是把本王给骗了」，但强调「好在本王明白自己血液很宝贵」。

此后疯子在王林身上，**再度感受到当年从幽冥兽体内刚出来时的那种感觉**。

## 三、朱雀星现状：圣地化与守护大阵

- 朱雀星是一颗**灵气极为浓郁、处于焕发状态**的修真星，在星空中只算小星。
- **星外新增浩荡阵法**：弥漫八方、随时运转，化作涟漪波纹回荡星空。王林当年临走时**没有此阵**，他判断**布置时间仅几十年**。
- 朱雀星如今被尊为**「封尊的故乡」**，是昆虚星域、甚至界内的**圣地**，**驻留很多大神通老怪为封尊守护此星**。
- 王林望星感慨：已不止是「物是人非」，而是**「物非人非」**。

## 四、朝圣者与进星规矩

远处四道长虹（三男一女、一老三少）如朝圣般掠过王林身旁直奔阵法：

- 领队老者为**召河明玫星·道德子**，叮嘱弟子在此不得惹是生非。
- 阵法开启前，从中走出**两名身影飘渺、目光如电的虚幻老者（圣使）**。
- **规矩**（圣使问、道德子答）：
  1. 朱雀星对界内所有修士开放；
  2. 不能带走朱雀星任何一物；
  3. 不能毁坏朱雀星任何一物；
  4. 在朱雀星上只能停留**三日**。
- 圣使掐诀挥手，阵法光芒散开，化出**一道云中阶梯**，深入阵法内部，遥遥与朱雀星连接——尽头正与**朱雀星上一处最高山峰**相连，如同天梯扶摇。

## 五、插曲与伏笔

- 疯子寂寞中竟怀念起许立国与刘金彪（「其实那两个家伙对本王也还不错」）。
- 疯子随即对道德子一行大喊，称其中「三个小娘子」要问芳名，惹得两名青年弟子面露寒光、女修回头误会；道德子抬手止住弟子，转而对王林道：「封尊故乡乃圣地，还望约束一下你的同伴，莫要失了体统」，说完再不看王林一眼。
- 王林拍了拍疯子肩膀，**没有直接迈入朱雀星，而是选择从阵法进入**——「既然回家了，他便要从正门进去，哪有避开的道理」。
- **伏笔**：两名圣使目送王林与疯子后皆觉此**白衣修士眼熟**，却怎么也想不起在何处见过，沉吟摇头后身影消散，阵法归于平静。
