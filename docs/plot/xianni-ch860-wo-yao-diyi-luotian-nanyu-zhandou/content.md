# 第七卷 名震罗天·第860章 我要第一（第二更）

## 一、场景与目的
- 地点：地炎星外围（十万里→三万里→千里光幕）。
- 王林（此时以化名「许木」行事）不融天地、不使缩地成寸，而是一步一步向前，用步行的过程平复心态、锤炼战意。
- 目的层级：
  1. 在罗天南域夺得一百零八仙的**资格**；
  2. 资格战中要的不是「七十二地煞」，而是「**三十六天罡**」；
  3. 只有赢得干净利落、名震罗天，才有与**向家**谈条件的分量。

## 二、王林不能败的三重执念
- **婉儿（李慕婉）**：他记得李慕婉最后一滴泪落下时，世界坍塌、星空虚无隔绝的悲哀与寂寞；问鼎之时为心中不舍，甘愿与天斗、逆修而上。
- **画轴女子之言**：当年画轴封印内那名**向家女子**关于让婉儿复活的话语，是他远赴罗天星域的最根本原因。
- **与清水的约定**：同样使他不能败。

## 三、战意压场
- 战意随行进疯狂攀升，于身后凝成风暴，风暴内浮现**黑白二色阴阳双鱼**，旋转散出波纹横扫数万里并持续扩大；王林黑发飘舞，白衣透出的不是雪白而是**骨色**，形如一尊魔仙。
- 冲入三万里时，千里光幕内正在厮杀的两名修士骇然停手；四周万里内几乎所有人色变。
- 无声的「**战**」字如音爆回荡万里，修为不高者当场喷血受创——他们败于心中升起的不可抵抗之念。

## 四、被激起战意的各方
| 人物 | 反应 |
| --- | --- |
| 申公虎 | 感到灵魂级压迫，并从战意中辨出**熟悉气息**，认出「尊主」；本已失望、疑心受骗，此刻重燃力量却带一丝不甘，咆哮化出**气息巨龙** |
| 战空烈 | 察觉不到许木来临，但辨出一丝熟悉；以战家族人不屈天地之势，爆出**剑气之龙** |

## 五、交手过程
1. 众人战意风暴与王林相撞，惊天巨响、数万里星空震颤；王林一身白衣，仍一步一步走来，众人战意被其目中寒芒、心神杀机、滔天战火一点点压下。
2. 唐言枫持**红色长剑**冲出，剑气惊人，神通化作片片**血色红莲**环身杀来，身后另有一批修士跟进。
3. 王林一步踏出、右手抬起，元力轰然化作崩溃风暴弥漫四周，**窥涅初期**修为尽显、横扫天地——唐言枫惊骇于其已突破阳实、达到窥涅。
4. **斩罗诀**闪出，落在红色长剑上，剑当场碎裂倒卷。
5. 王林临身，**双指成剑**破开对方一切神通，红莲尽溃；右手双指按上唐言枫前胸，其喷血倒卷、体内雷光宣泄、**元神重创**被远远抛出。
   - 关键判语：以窥涅之修击退阳实巅峰微不足道；若王林有心杀之，那一指足可致其身亡（**留手未杀**）。
6. 王林收指转身，**眉心第三目**一开、红芒爆闪，红光散开，随后而来的修士神通尽化本源、口喷鲜血重创倒卷。

## 六、结果与身份曝光
- 王林冷漠宣告：「这罗天南域一百零八资格，**许某，要第一**。」
- 四周惊呼：「许木」「**魔道子许木**」「他就是许木，我亲眼见过」——「许木」之名在罗天南域正式坐实并扩散。

- 李慕婉已于第188章身故，本章仅为**回忆与执念**，非其登场。
