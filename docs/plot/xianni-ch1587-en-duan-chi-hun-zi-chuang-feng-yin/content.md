# 第1587章 恩断！

## 一、封印崩裂
- 赤魂子自地府被放出后，狂笑撞开掌尊以太吉星辰凝成的「井中捞月」封印，封印出现巨大窟窿。
- 天空以窟窿边缘为中心向八方蔓延大片裂缝，下方水面倒映同现无数裂缝，天地剧震仿若崩溃。
- 赤魂子临去留言："小娃娃，你身上有道古气息，老夫本应杀你，但你将老夫放出，此事抵消"，随后消散离去；掌尊目露凝重却无法阻止。

## 二、王林的一失一得
- **失**：掌尊以太初之力＋井中捞月之术强行分开王林体内的「古」与「仙」，意在夺取仙体所凝的那滴金色血液；王林由此失去仙体与仙人血脉。
- **得**：
  - 赤魂子的冲撞使掌尊抓向王林天灵的手被逼退，血液未被夺走，王林亲手抓在手中；此物精纯至极，已无法收入储物裂缝。
  - 禁锢解除，王林身体可自由活动，随即直冲天空窟窿。
  - 古仙分离反而化解了体内的排斥之力（原本如悬梁之刀，身体持续崩溃、极为危险）；身体回归**古神之躯**，恢复之力弥漫全身，失去的五脏隐隐重现，伤势加速痊愈；元神虽萎靡，但那始终伴随全身的无尽剧痛消失。
- **后续打算**：不再强行融合古与仙（古往今来无人做到，强合如剧毒、结局唯有死亡），改为将这滴血液**炼化成一件仙体之宝**，融入身体以避开排斥之力同时爆发其威力。
- **心境**：当年疯子给予造化时他被动无从选择；如今掌尊所设的生死大劫，反而无形化解了这一危机——"天劫是劫，亦是造化"。

## 四、恩断
- 掌尊明知战老鬼、乃至"当年一吼的神秘人"可能瞬间感应，仍不肯放手。
- 掌尊对蓝梦道："蓝梦，莫要忘记我们的约定，你妻之体，我帮你取回。"
- 蓝梦一声叹息，在窟窿处化出巨大**蓝光之面**，生生阻断王林去路，并将其狠狠弹回。
- **他曾说不会出手，此刻仍出手**——自此他与王林之间再无恩义，一刀两断；王林眼中露出复杂之色。

## 五、死亡之枪（章末悬念）
- 掌尊右手指天：红光漫天 → 橙芒一闪 → 七彩光芒笼罩天空并交织。
- 凝成一把巨大的**七彩长枪**，掌尊一把抓住，冷冷看王林一眼后甩出。
- 此枪带毁灭天地之息，非王林可抗——章末定格于"这是，死亡之枪"。

## 六、要点索引
- 恩怨节点：赤魂子对王林"放出之恩"抵消"道古气息之仇"；蓝梦与王林恩义断绝。
- 伤情节点：掌尊本体第二口鲜血（第一口在捏箭时）。
- 体质节点：王林由"古仙共存（濒死排斥）"→"纯古神之躯 ＋ 手持仙血待炼之宝"。
