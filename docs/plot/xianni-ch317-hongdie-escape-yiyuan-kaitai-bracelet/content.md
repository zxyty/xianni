# 仙逆 第317章 闻道者，朝生夕死

## 一、红蝶开镯遁走
- 红蝶恨意极大，向「曾牛」（此处王林所用之名）放话：是你逼我以**降低一个境界为代价**开启一元开泰镯，「我们朱雀星再见」。
- **一元开泰镯**散发白光交锚成巨大黑洞，洞内可见一处祭坛之地，正是**朱雀国**所在。
- 镯之神通：除固有神通外，可**从仙界任何位置开启**，使持镯者安然回归。此镯本是朱雀国当年**得自仙界**之物，故红蝶有恃无恐。
- 代价：回到朱雀星后，红蝶修为将由**化神后期**跌为**化神中期**。

## 二、王林拦截：羽扇诱敌 + 元神出窍
1. 王林体内**绝情意境**已有些控制不住，但不甘心放走红蝶——若非此镯，今日此女必死。
2. 王林抬手取出**只剩两片羽毛的扇子**，红蝶目光一凝、脱口「师姐的扇子」，后退脚步不由自主一顿。
3. 王林抛扇，同时**元神自天灵飞出**，抓扇撕下一片羽毛。
4. 羽毛立刻燃烧，化作**与王林一模一样却无面貌的漆黑黑影**；王林元神大喝「爆」，黑影疯狂自爆，气息尽数轰向红蝶。
5. 红蝶已退入黑洞，遭爆炸冲击再喷一口鲜血；王林元神冲近，右手带一丝煞气狠狠一抓。
6. 红蝶抬右臂阻拦并散出**白芒之光**（对元神伤害极大），王林距离过近，元神飞快虚弱。

## 三、战果
- 王林一爪抓下**红蝶整条右臂**（带起一腔鲜血）。红蝶面色苍白、双眼紧闭，落入黑洞深处，黑洞迅速收拢。
- 王林元神抓住另一支羽毛，在黑洞合拢瞬间回体；收起手臂与羽毛。
- 全程战斗**仅数息**。
- 王林评估：
  - 「化神后期，太难杀」——几乎用尽手段、择其本命法宝被毁且身体最虚弱之时，仍未成功。
  - 「还是修为不够」——若自身达**化神中期**，今日结果不会如此。
  - **后手**：凭这条手臂有无数方法对红蝶进行**诅咒**，欲令其修为**永生止步化神**。

## 四、出口崩溃，转向下沉
- 王林正欲冲向半空入口时，**入口轰隆崩溃**。尸阴宗老头（刚扔下女尸）呆立满腹苦水，叱虎亦愣住。
- 叱虎摸储物袋中的**星罗盘**，损坏严重无法驱使，自己又不会修复，只得紧跟老头保命。
- 王林二话不说转身冲向地面：此地**多层碎片重叠**、上行无路，唯有**下沉**。他先前趁周佚与老头附体战斗时已用**神识暗查地面**，眨眼即到一处尚未崩溃的**深坑**并冲入。
- 尸阴宗老头神识一扫，随即追向王林下沉之处。

## 五、周佚的裂痕
- 周佚抱着女尸，对其说：「凡是抢你的人，都要死」，欲用生命最后一刻杀了抢「婷儿」之人，与她一同消散于虚无。
- 但他随即迷茫：**「我为何心中对你好像有了一丝陌生感？我好像想起了一些东西……婷儿」**。
- 他轻吻女尸唇边，皱眉抱尸追向尸阴宗老头方向。

## 六、章末态势
- 第三层崩溃之声渐远；崩溃虽会一直持续并波及所有碎片，但此刻**第四层无疑最安全**。
- 王林内心断定：**离开此地的唯一方法，就是叱虎的星罗盘**。
- 下沉许久，前方一亮，王林未冲出，紧贴石壁潜伏。

## 关键伏笔
- 红蝶手臂 → 诅咒 → 封死其化神以上前途。
- 朱雀星之约 → 后续恩怨。
- 星罗盘 → 唯一脱困钥匙，落在叱虎手中。
- 周佚记忆松动 → 其执念/身份或有反转。

## 一、出口之外：仙王寝宫现世

- 通道出口处，先有一道身影疾掠而过，路过王林时一顿、轻哼一声便冲向亮光；随后叱虎落下，见王林一怔。
- 王林飞出并传音：「叱虎兄，此地你我修为最低，小心那尸阴宗老者。」叱虎点头，二人几乎同时飞出出口。
- 出来瞬间所见：**极为宏伟的巨大宫殿群**，密密麻麻一眼望不到边际，**所有宫殿皆以灵石制作**。
  - 正中一座宫殿远看便**仙气逼人**。叱虎倒吸凉气，疑为**仙玉**打造。
  - 王林神识更强，一扫之下震惊，但看出中央宫殿**并非全仙玉，而是仙玉与灵石参半**——仅此已可见宫殿主人当年的大手笔。
- **尸阴宗老头**远处狂喜大喊「**仙王寝宫**」，大笑称不知是哪位仙王的寝宫竟保持如此完整，**其内定有仙人尸体**，随即身子前冲欲入宫殿群。

## 二、周佚拦路：痴与道心

- 周佚抱着女尸（婷儿）现身，一现身便向前踏步，**看似缓慢却三步即至**尸阴宗老头身前。
- 周佚对女尸低语：「婷儿，杀了他，我们就去**虚无之中**……我能感觉到，自己**已经开始虚弱**了……我好像记起了当年的一些事情……我好像知道了你是谁。」
- 老头变色后退，周佚以**婴变后期**实力直撞而去。老头怒吼：仙人尸体我都还给你了，宫殿内一定还有其他尸体，你尽管去找，何必阴魂不散追着我不放。
- 转折：周佚深望女尸一眼，在其**眉心一吻**，闭目再睁——眼中**再无半点痴情，而是前所未有的清明，黑白分明**（这种眼神在他身上本绝无可能出现）。
- 他向前一踏，天空霹雳，整个人**化作一道燃烧的流星**撞向老头。
  - 自陈：「我的意境，是**痴**；我的道心，是**婷儿**，为婷儿而死，我心甘情愿。」
  - 「我周佚一生，此刻走到了尽头，但，我无怨无悔。」
  - 「没想到，在我人生的尽头，借着**元神的燃烧**，我居然**悟了**。」
- 老头破口大骂后退，判断对方**已然末路**，只要多坚持少许对方就会消散。

## 三、悟道威压：天地崩摧

- 四周天空轰隆巨响，**崩溃再次开始**，且此次在天空尤为明显——好似无形大手撕扯，出现一个个巨大裂缝。
- 天空忽暗，**庞大威压自天而降**：
  - 王林毫无抵抗之力，被死死压落、深压在地面；
  - 叱虎更不堪，整个人被压入地底，毫无挣扎之力；
  - **地面上的宫殿尽数坍塌化为碎末**，唯有**正中间那座宫殿堪堪耸立**，但也出现崩溃裂缝。
- 王林内心大骇，脑中一片空白，**以其心志竟产生不可抗拒的颤抖**，惊觉：「原来，这才是**道**。」
- 周佚感叹遗憾：师父曾说「**闻道者，朝生夕死**」，原来是这个含义——并非病句，也**并非「朝闻道，夕死可矣」**，而是**日后的一个玄妙**。（伏笔）

## 四、第318章开篇：红珠融体，红芒光人

- 光人**左手随意一点**，尸阴宗老者便**无法移动身子**，面色苍白震惊，苦涩吐出两字：「**问鼎**」。

## 一、周佚往事回闪

- 借着痴情之意，其修为在不知不觉中越来越深，成为**婴变期**修士。
- 师尊冲击**问鼎**失败、寿元大限之日，他站在**五行宗**外跪了整整七天。
- 此后数年，他三次出手免去五行宗大劫，**但始终不再是五行宗弟子**。
- 这一幕幕在此刻于周佚心中闪过。

## 二、托妻：先叱虎，后王林

- 尸阴宗老头面对问鼎期已彻底放弃挣扎——「境界的差异，可以摧毁一切的反抗」。
- 周佚再次低头吻在女尸眉心，目光扫过叱虎与王林，先落在**叱虎**身上：「小兄弟，帮我照顾我的妻子，可好」。
- 叱虎被神奇之力从地底抓起，内心苦涩（尸体一事若被族内长老知晓，日后影响太大），但无人敢拒问鼎期修士的临终嘱托，只得低声答应。
- 周佚看穿其顾虑：「你身为**巨魔族的少族长**，自然会有所顾虑，担心会步入我的后尘，罢了」，遂作罢。
- 转向**王林**：「你，可愿意帮我」。王林身上压力一轻，从地上站起，沉默不语。
- 条件：**妻子需仙玉维持身体不变，每千年需千块仙玉**。王林答「我不敢保证会弄到那么多仙玉」，周佚仍微笑允下，称「数千年的嘱托，我不会让你白白帮我」。

## 三、仙玉宝塔

- 周佚大手向下一抓，尚未坍塌的宫殿崩溃，仙玉尽数飞起，于半空凝成一座**宝塔**。
- 女尸被抛入塔内消失；宝塔缩小后飞入王林手中。
- 接触瞬间，一丝奇异之力流入王林体内，其**元神中多了一个印记**。
- 禁制说明：宝塔上有周佚此刻问鼎期的**意境临身**；需寻**阴寒之地**放出；塔外百里之内，除非修为高过此刻的周佚，否则王林不愿之下无人可入。

## 四、第一个礼物：问鼎之晶

- 周佚右手点在眉心，一枚**指甲大小的红色玉石**飞出，弹向王林。
- 玉石一现，碎片崩溃为之一顿，时间似乎停止，其内散发**天道之威**。
- 王林由此感受到当年**化凡**时所悟轮回天道那般无法想象的法则之力。
- 周佚：「这是我给你的第一个礼物，**问鼎之晶**，此物你现在无用，但若你有朝一日可以达到问鼎期，此物可帮你」。

### 问鼎之晶设定要点

| 项 | 内容 |
|---|---|
| 来历 | 问鼎修士感悟天道、最终达到问鼎的一刻，天地之间自然酝化而成 |
| 神通 | 无任何神通之处 |
| 效用 | 获得者进入问鼎的把握立刻增加三成 |
| 唯一作用 | 使修士在问鼎的生死转变中，可以多一次选择 |
| 代价 | 问鼎修士失去此物，修为会永久退步，直至死亡——价值不亚于性命 |
| 时点 | 周佚此枚为刚刚才凝聚而成 |

- 旁观反应：尸阴宗老头直勾勾盯着玉石，露出强烈渴望；叱虎作为巨魔族少族长见识非凡，一眼认出此物，**悔意达到极致**——若早知如此，绝不会有半点犹豫；并推测「第一个礼物」之后还有第二、第三个。

## 五、第二个礼物：尸阴宗大长老为千年奴仆

- 周佚右手一点，尸阴宗老头不受控制上前被其抓在手中。
- 「我送你的第二个礼物，便是此人——**尸阴宗的大长老**，你可以不杀，但你要做**千年奴仆**，你可愿意」。
- 老头初时求死：「我寿元不足千年，如何能做千年奴仆，你索性杀了我吧」。
- 周佚回应：若寻死便成全，以剩余法力将其**炼成傀儡**，虽修为会降低一些，也算第二个礼物；随即抬手向其眉心点去。
- 老者额头泌汗，念及若修为突破至**婴变后期**可增寿，且**尸阴宗秘术**即便寿元不足亦有诸多续命之法，在指尖将至的瞬间答道：「我同意」。

## 六、要点提炼

1. 王林由此获得两大机缘：**载有女尸的仙玉宝塔**（附问鼎意境护持、元神印记）与**问鼎之晶**（未来冲击问鼎的保命/多一次选择之物）。
2. 王林同时背上长期负担：**每千年千块仙玉**的维持成本。
3. 尸阴宗大长老（婴变期）成为王林的千年奴仆。
4. 叱虎因怕族内非议而错失重宝，反衬其少族长身份的顾虑与短视。

# 第318–319章「噬主」：孙泰认主与女尸苏醒

## 一、周佚的最后馈赠：婴变期奴仆孙泰

- 周佚右手加速点在尸阴宗大长老眉心，另一手一点王林，王林身不由己前飞。
- 一道**奇异之光**自老者眉心而出，经周佚体内，沉入王林额头消失。
- 效果：王林可**随意感知该长老一切意念**，念头一动即可**令其元神破灭**——本质是主奴/元神掌控之术。
- 大长老暗叹一声，恭敬却极不自然地报名：「**老奴孙泰，参见主人**」，内心苦涩无法言表。

### 叱虎的悔恨
- 叱虎眼睁睁看完全程，悔意滔天。
- 其内心独白透露关键设定：得一名**婴变期奴仆**，回族内身份将由**少族长**直升**族长**；有此人在手，「**除了朱雀国，天下大可任意行走**」——侧证朱雀国为顶级势力。

## 二、周佚之死

- 周佚身躯燃烧至末路，渐不凝实，有消散之意。
- 留恋环顾四周后看向王林，轻声托付：「**照顾好她**」。王林深吸口气，重重点头（对结果尚有不敢置信之感）。
- 身体自双脚起渐渐消散，脸上**始终带着笑容**。
- 遗言：「**师父，若有来世，我还是你的弟子**」——点明周佚有一位「师父」，且此番守护出于师徒之义。

## 三、女尸（婷儿）苏醒

- 王林手中**宝塔**突然脱手变大，其内白光阵阵，**女尸自动飞出**，飘于半空，全场皆惊。
- 唯周佚毫无惊讶，平淡唤：「**婷儿，不要胡闹，回去**」。
- 女尸体内传出奇异之声：「**你不会死**」。

## 四、雨之仙剑与「仙剑之魂」

# 第319—320章 星罗盘

> 背景：周佚陨落后，王林（对外化名「曾牛」，化神初期）与巨魔族少族长叱虎乘星罗盘穿行虚无，同行者还有被周佚下了奴印的尸阴宗大长老孙泰。

## 一、孙泰的招揽与威胁

- 叱虎苦控星罗盘化电冲入虚无；孙泰点出「星罗盘，巨魔族重宝之一，可惜是个残次品」。
- 周佚在场时孙泰称王林「主人」只是做样子；周佚一死，身为婴变中期修士的他视为奇耻大辱，恨不得将王林练成千尸。
- **开出的条件**（换王林解开奴印）：
  1. 保王林平安回到朱雀星；
  2. 赠两个化神后期傀儡，保障日后安全；
  3. 任何功法都想办法弄来；
  4. 仙丹妙药。
- 王林当面点破：解封后孙泰第一件事必是杀他；且自己确实不会解印之法。
- 孙泰亮出底牌：自称非三魂而是**四魂**，第四魂藏于其棺材中的尸傀体内——纵使王林念动灭其元神，第四魂也会将王林杀死。
- 王林反将一军：孙泰所言另有目的，他心中早知这封印根本不是王林所能解。孙泰赞其「不愧是周佚选择之人」，改口要先把王林禁锢一地，发誓日后补偿。

## 二、宝塔逼退孙泰（言语与气势之战）

- 孙泰大手抓来，王林不闪不避——储物袋中白光传出，**宝塔**飞起，白光四散。
  - 白光中含**周佚问鼎期的痴情意境**；孙泰惨哼后退。
  - 该意境对旁人只能阻步、无伤力，唯独专克体内被封奴印的孙泰。
- 王林现场推理施压（此为虚实相间的心理战）：
  1. 尸阴宗棺中尸傀「绝不可能是你第四魂」，多半是别人的魂魄；即便真有，也只是**残魂**；
  2. 以周佚的修为，岂会为王林留下这等祸根，早已算计在内；
  3. 白衣女尸临走前把此塔交给王林，本身就有含义——「含义你自己慢慢体会，若最终不明白，只能说你命自该绝」。
- 孙泰心生怀疑、气势崩溃，远远退开，撂下「你若想灭我三魂，大可放手而为」后飞遁离去，再不提禁锢之事。

## 三、双方的真实内心（作者交代的底牌）

- **王林**：孙泰修为太高，以他的性子绝不会收这种奴仆；周佚怕是临死也没想到孙泰有第四魂。判断即便真有四魂，三魂一灭修为亦会大降、留下隐伤，否则不会被几句话吓走。「若能灭他第四魂，方可真正收之为奴。」并深知刚才看似平缓、实则内藏凶机，露出半点顾忌就会受制于人。
- **孙泰**：认定王林所言「八成是真」，否则以化神初期修为不会如此从容；推断周佚曾传音留他「有大用」，故王林不愿轻易灭其元神。自承四魂并未完全成长，主元神被灭则修为大降、本就不多的寿元大量损失——「这小辈杀不得、禁不得」。
- 王林对叱虎放话：若非周佚传音说留此人有大用，刚才就灭其元神、以宝塔收其四魂——此话是说给远处以神识探测的孙泰听的。

## 四、星罗盘易主

- 数个时辰后，星罗盘裂缝愈多、几近崩溃，停在虚无中无法前行。虚无凶险、无星路指航，且常有难以抵抗的诡异生物。
- 巨魔族仅此一个星罗盘，为无数年前迁移至朱雀星时所剩；报废后叱虎回族恐要被罚闭关。
- 王林坦言**自己会修复星罗盘**，但因材料贵重、祭炼耗损灵力巨大，修复成功后星罗盘须归其所有；随即又退一步：「若是叱虎兄为难，在下也会为你修复，权当交下叱虎兄这个朋友」，只求日后相借莫拒。
- 叱虎的权衡：若对方以计谋威逼或杀人夺宝，纵使得手他日后也必全力报复；而王林这般说话透着真诚，是真把他当朋友。且王林修为惊人、又得周佚的**问鼎之晶**，是同辈中最有机会成为问鼎之人，结交对巨魔族或有助益。
- 结果：叱虎当场抹去印记，将星罗盘赠予王林；王林抱拳道谢。

## 五、祭炼开始

- 王林请叱虎**护法**，当场盘膝坐于虚空祭炼。叱虎深深看他一眼后应允：「我叱虎真心交你这个朋友了。」
- 王林取出**金紫石**，双手连打印诀凝练**金紫液**，许久后金紫液在身前成团，金、紫双色交错。
- 戒备未松：他眉心暗涌大量**游魂**，外人无法看到，叱虎若突然出手必被游魂所阻——四百多年的杀戮让他不会轻易相信任何人。
- 设定补充：凭空打造星罗盘所需材料太多；此盘虽损坏严重，修复远比打造容易。

# 第320-321章 星罗盘修复出虚无 · 剑狂

> 【归属须知】本片段中以『曾牛』之名行事者为**王林**（化名，见其与叱虎、孙泰同行线）。

## 一、祭炼星罗盘（第320章后半）

- **手法来源**：王林右手点在金紫液上，使之与星罗盘融合，双手快速捏印，采用**吉神（涂司）记忆中的手法**开始祭炼。
- **过程**：罗盘古朴符号逐一亮起、闪烁愈快；数日后全部亮起而后熄灭，祭炼完成。
- **修复结论（王林暗叹）**：
  - 材料有限，只能**略作修复**；
  - 此盘原本就未完全祭炼，**缺少『碎星铁』**，故**无攻击性**——这正是它被称为「**次**星罗盘」的缘由；
  - 缺失的**一角**需另一种材料才能补全；
  - 但**使用无碍**，离开虚无没有问题。

### 叱虎的守护与克制
- 神识只散开**四周百丈**警戒（虚无之地危险物众多，神识散得太广如黑暗明灯，会给危险之物指路）。
- **主动回避**：对王林**二十丈内**的手诀印法，神识一概略过、一概不看。
- 内心独白（放弃出手的三条理由）：
  1. 「这曾牛既有这等胸襟，他相信我，我叱虎为人顶天立地，又岂能让人心寒」；
  2. **问鼎之晶是周佚送予此人**，其上定有禁制，得之日后是大麻烦，且**曾氏家族强者众多**，不能为本族惹祸；
  3. 最关键——即便动用**族内重宝**，也**只有五成把握**战胜此人，不如不出手。

### 孙泰的暗中窥伺
- 于远处二人察觉不到之地观望，惊讶「这曾牛居然会修补星罗盘，绝不简单」。
- 自估**七成把握**可在王林念起之前将其禁锢，但**奴印太过霸道**，王林只需心念一动即可毁其元神。
- **第三魂是他的本魂**，非万不得已不容有失 → 暗叹一声，放弃冒险。

## 二、改造后的星罗盘（重宝定位）

| 项 | 内容 |
|---|---|
| 放大 | 一点即可变大，比之前**大一倍有余** |

| 速度 | 神念一起即消失原地，**比之前快数倍**；王林全力飞行亦不可及，唯**不断瞬移**方可相比 |
| 操控 | 经改造后**不需指航**，王林一人即可操控（叱虎可安心打坐） |

- **仙界之行总收获**：星罗盘、**仙玉**、**战神车**，另加**仙玉宝塔**；以及一个「虽说有些逆反噬主的**婴变期奴仆**」（孙泰）。

## 三、雨之剑魂出世（第321章 剑狂）

### 场景：某处保存较好的仙界碎片
青草摇曳、白云山脉交错，依稀可见当年仙界一貌。

- **白衣绝美女子**无声出现半空，身下踩一条**散发凌厉剑气的金龙**；金龙**眉心紫雾**中时而现出**周佚**无奈的面貌（周佚元神寄于此）。
- **对话要点**：
  - 女子：若仙界仍在，去**洗仙池**一泡，元神只要不灭皆可恢复；但洗仙池已消失，仅凭**一把**雨之仙剑恢复太慢。
  - 周佚（无奈）：「婷儿，你这又是何必，这几年前的仙气积累，你想全部耗费一空不成？」
  - 女子（平淡）：「**你是我钦封的仙尊**，我不让你死，你便不能死；还有，**我不叫婷儿**。」
  - 周佚（痛苦）：既然你不是婷儿，我本就想起了一切，「就让我离开吧，我已经是死人了」。
  - 女子沉默后：「不过，**婷儿这个名字，我很喜欢**。」→ 周佚欣喜唤「婷儿」，女子应了一声。

### 引剑仪式
- 女子以玉手轻按碎片大地，吐出数个清脆咒语 → 大地裂缝、金光凝于一点、地下剑鸣洞穿天地。
- 喝「**雨之二剑，出**」→ 大地碎裂，第二条金龙冲出，与其脚下金龙交缠咆哮，如无数年不见之喜。
- 结**宝瓶状印法**宣告：「当年仙界劫难，雨之剑魂破损万千，融于无数仙剑之内，成为残魂。今曰，**周佚，本君封你为剑魂**，自当重新凝聚，剑魂，出世！」

### 「剑狂」全景效应
- 整个仙界**所有碎片**同颤，仙剑自地底飞出、自半空凝形，剑鸣自一片传至一片、连成一体——「在这一刻，整个仙界，只有一个声音：那是剑的声音」。
- **万剑齐断**：大罗剑宗弟子杀人夺宝之际，宝剑碎裂；御剑飞行者脚下之剑崩溃；刚落碎片的中年女子取出师门重宝**七彩飞剑**，一出储物袋即碎。凡在仙界寻仙气的修士，**无论修为，身边飞剑必碎**。
- 缘由三句：「剑碎，只为**自秽**／只为**祭魂**／只为**剑狂**」——雨之仙剑拥有新魂，新魂正是**周佚**。
- **万剑归一**：所有仙剑齐向同一方位飞去，「人挡杀人，地挡碎地，天挡灭天，兽挡屠兽」。

### 各方反应
- **大罗剑宗青衫老者**（坐麒麟兽）：睁眼两道电光，身前半透明强大生物惨哼逃走。判断「**雨之仙剑共有五把，当年破碎一把，还剩四把；四剑出其二**」，只待引动当年破碎万千的剑魂，则「仙界之内凡剑魂所在，将会万剑齐出」。自语「若是当年仙人仍在，以老夫的修为自然无法获得雨剑，但现在嘛……」，催麒麟兽提速，旋即面色一喜：「引动了！」
- **虚无中的中年文士**：任何异兽见之远避；闻剑鸣变色曰「引动了」，剑光袭来时亦不敢不退，闪身避过后立即追击——「只需顺着剑光，就可找到雨之仙剑」。
- **仙界众修士**：全部顺着身边剑群追击，想看是何宝可以让剑「狂」。
- **王林与叱虎**：罗盘中闻剑鸣立停。叱虎「曾兄，怕是出了大事」；远处一排排密密麻麻仙剑带强烈剑鸣呼啸而来，叱虎失声「这……全部都是仙剑！」王林倒吸口气，急控星罗盘闪避，仙剑呼啸而过；随即又见另一处剑光无数，方向与前者同。王林内心震惊：「发生了什么事情？」

## 四、要点提炼

1. 星罗盘由「次品代步」升格为王林手中的**高速重宝**，短板明确：无攻击性（缺碎星铁）、缺一角。
2. 王林对叱虎、孙泰形成**信任 + 奴印**的双轨掌控，二人各自权衡后均按兵不动。
3. **周佚正式成为雨之剑魂**，身份从「已死之人」转为仙界剑道核心；白衣女子默认了「婷儿」这一称呼。
4. **雨之仙剑：五把，已碎一把，现存四把，已出两把**——成为后续仙界碎片中各方争夺的最大焦点。
5. 万剑齐飞给所有势力指明了方向，仙界碎片进入**追剑**阶段。
