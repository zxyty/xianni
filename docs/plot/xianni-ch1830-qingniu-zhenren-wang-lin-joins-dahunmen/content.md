# 第1830章 把他克死！

## 一、青牛真人本尊降临，压制炎栾

- 一声低喝之下，风暴般强悍的神识笼罩四周，与王林「古道无仙」所化的九层波纹相撞，波纹无声无息层层崩溃、化作晶光四散。
- 炎栾被神识弹开，连退百丈方止；四周大魂门长老尽皆沉默，天地剧变平息。
- 王林与炎栾之间显出一名青衣白发老者——**青牛真人本尊**。其**本源真身**一步迈来与本尊融合，在身后化作模糊虚影。
- 王林判定：**空劫后期**。原文：这股气息「已然超过了全盛之时的七彩仙尊」。王林神色平静，瞳孔微不可查一缩。
- 众长老与炎栾皆躬身「参见老祖」，唯独王林不屈身，只平静打量。

## 二、青牛真人的裁决与馈赠

**对炎栾的裁定**
- 「王长老是老夫请来之人」，自此王林为大魂门长老之一。
- 补偿：为炎栾另辟一座山峰洞府；准其进入**藏魂阁**三天。
- 炎栾虽不甘，念及王林先前可怕神通，沉默点头。

**封口令**
- 有关王长老的一切事情为大魂门隐秘，不得外传，违者门规处置。

**给王林的待遇**
- 自选一处山峰为洞府，青牛可代为布置。
- 每位大魂门长老都有一次进入藏魂阁挑选神通功法的机会。
- **三份礼物**：「为你准备了很久很久」，由青牛代**先祖**转送，「对你应有大用」——约三日后青天峰相见。
- 赐一枚**玉简**，可随意进出大魂门绝大部分禁制。

## 三、王林的融入姿态

- 王林含笑抱拳：「王某初来乍到，若有鲁莽之处，还望诸位道友莫要放在心上。」
- 立威在先、姿态温和在后，众长老纷纷回礼示好（松云峰长老邀其饮仙茶论道），随后化虹散去。
- 王林对炎栾心存分寸：自认「主动招惹在先」，毁其洞府，换谁都难接受。

## 四、炎脉峰易主与重铸

- 王林主动放弃另择山峰，**要下已被打得黯淡残破的炎脉峰**，把新洞府让给炎栾。炎栾神色略缓，却仍冷哼瞪他。
- 炎脉峰因**地火主脉枯萎**近乎废弃，山体酥松、稍用力即可坍塌。
- 王林一踏之下，**火本源真身**幻化融入山峰：火海呼啸环山，烧毁山内一切旧禁制、重立新禁制；山色由黯淡重归**赤红如骄阳**，且更浓烈，火焰似可永恒燃烧、永不熄灭。
- 王林自语：「失去了火焰的力量，我便给你补充火焰；失去了火焰的意志，那便以我的意志成山。」
- 此幕令炎栾银牙紧咬，先前那点缓和烟消云散——「我和他势不两立」。

## 五、索要矾珊梦——一指「另有含义」

- 王林路过炎栾弟子群时脚步一顿，目光莫测看向**矾珊梦**（据世界状态须知：自第1606章起，此身份实为其妹**矾珊璐**伪装，第1698章已被王林当面揭穿），开口：「我洞府缺一个女侍，此女不错，炎栾，把她给我吧。」
- 炎栾暴怒拒绝「你休想」。王林大笑离去——原文点明**那一指实际另有含义**。
- 王林离去后，炎栾看向矾珊梦，目露奇异之芒，心思不明。

## 六、矾珊梦的背景补述（叙述者视角）

- 修为**玄劫七次**，与杜青同阶。
- 她与妹妹能成为**七彩仙尊**道侣，与修为无关，而在于她是大魂门弟子；且**与其一次机缘似有关联**——否则以七彩仙尊当年空劫初期的修为，断不会选她为道侣。
- 七彩仙尊一生多变、痴情与多情交织；即便后来修为升至**空劫中期**，对矾珊梦依旧如故——故而得知她与**连道非**似有暧昧时，怒意才如此之大。

## 七、炎栾的毒计：「把他克死」

- 青牛为炎栾重布山峰离去后，炎栾立召矾珊梦，命其去炎脉山给王林当女侍。
- 矾珊梦跪地颤抖、楚楚可怜，换来炎栾冷哼与斥责：
  - 认出王林即矾珊梦此前所提之人，「来自**洞府界**么」。
  - 「收起你的媚态，你这媚功对为师无用」。
  - 指控其**天性放荡，克死了道侣七彩仙尊**，更使**连道非因她失踪而入七道宗洞府界**。
  - 「你若能用好，用在那姓王的身上，**把他也给克死**，为师不会亏待你」。
- 「你去也得去，不去也得去」——大袖一甩，狂风将矾珊梦卷出山峰。

## 八、结尾：怨毒转内媚

- 山峰外，矾珊梦久久沉默，回望燃烧的山峰时**目露极深怨毒**（若非王林那番话，炎栾断不会把她送出）。
- 深吸口气后怨毒消散，取而代之的是**如水般的内媚**，神色平静，轻步走向那燃烧的山峰。

## 关键伏笔

3. 炎栾看矾珊梦时的「奇异之芒」，心思未明。
4. 矾珊梦（实为矾珊璐）奉命以媚功「克死」王林，双方各怀目的。
