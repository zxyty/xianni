# 第1373章 王林降服暗蝎族·颠落之地情报与炎火异晶之秘

## 一、一指定胜负：暗蝎族老者被震出元神

- 暗蝎族老者面色苍白、再喷鲜血急退，惊呼「天人第四衰」，懊悔暗蝎族招惹了这样的老怪。
- 王林大袖甩动、右手虚空一抓，四周天地之力被其操控化作无形牢笼，从四面八方挤压老者，老者体内砰砰作响、骨骼欲碎，生死危机弥漫。
- 老者一拍眉心族印，四尾蝎子自眉心脱离、迎风见长至百丈，四尾成残影抽击王林；又虚空一抓挥出上百具傀儡（各具阴虚/阳实气息）将王林包围，喝令「所有傀儡，给我爆」，随即后退。
- 王林对蝎子与傀儡看都不看，向前一步，波纹闪烁人影消失，直接出现在老者退路上；随意抬起食指按向其额头。
- 那一指尚未落下，仅指尖蕴含之气息便轰入老者体内：元神被震出体外悬于半空不敢动，四尾蝎子消散化幽光回归元神眉心成印记；失去元神的肉身倒卷抛飞、喷血砸落大地。
- 老者心神俱丧，断定「此人绝不是天人第四衰」——若被那一指点中必形神俱灭。

## 二、太古族盟之誓：收服第一个太古族落

- 王林条件：「从此之后，你暗蝎族尊我为主，听从一切号令，否则，全族灭。」
- 老者应允：颠落之地本就强者为尊，全族一百七十六人尽听号令。
- 钟大洪进言：不可只听一面之词，须以自身族印发下**太古族盟之誓**，违誓则族印反噬、死无葬身之地，万古岁月暗蝎族全部灭绝。
- 老者恶毒地看了钟大洪一眼旋即苦笑照办；立誓刹那族印散发幽光，四尾蝎子无声嘶吼萎靡，一道沧桑印记如烙印般浮现其身。
- 被封印的暗蝎族族人（含被称「少主」者）被王林放出，目睹全程后皆以族印发誓，尽皆恐惧。
- **结果**：暗蝎族成为王林收服的第一个太古族落；王林洞府成为暗蝎族圣地，洞府四周以法术化作沙漠，成为这颗修真星上新的暗蝎族领域。
- 章姓老者震动之下决意紧跟钟大洪攀关系；钟大洪则以化神修为在暗蝎族中横行、整个人抖了起来。

## 三、颠落之地格局（老者供述）

| 项目 | 内容 |
| --- | --- |
| 族落数量 | 三百七十二个小族；暗蝎族属末流，仅控一颗废弃修真星 |
| 上层机构 | 太古星辰有**长尊会**；颠落之地有**落生会**，十三位长老掌权 |
| 幕后主宰 | **颠落大帝**——落生会的操控者，极为神秘，传闻第三步大能；因其存在，此地不受长尊会管理 |
| 长老更替 | 每百年接受一次挑战，胜者可为长老 |
| 长尊会渗透 | 无数年来暗送众多修士争位，**无一次成功**，全部在挑战前莫名死亡；不争长老位则无性命之忧 |

## 四、傀儡体系

- 傀儡唯有在**落生会长老所属族落的修真星**上出售，唯颠落之地族落才有资格购买；修为越高越难买，寻常修士根本不卖。
- 制作之法传闻由颠落大帝传下，具体如何制成**只有十三位长老知晓**。
- 暗蝎族最高者为**净涅中期傀儡**一具（当场取出：神色麻木、几与真人无异却无生机，全身无数封印笼罩看不清内部），价值天价，拿出颠落之地可换大量法宝丹药。
- 王林追问层级：
  - 「颠落之地可有碎涅的傀儡？」——老者犹豫后答「有的」（王林心神一震，面上平静）。
  - 「可有天人衰劫傀儡？」——老者沉默更久，答据说有人见过，真假不知。
- 王林暗忖：既有天人衰劫傀儡，是否也有第三步大能傀儡？此念太过荒谬，未出口询问，自认绝不可信。

## 五、火雀族与炎火异晶

- **火雀族**：太古大族，在此地约数百人，初具规模；虽众所周知是火雀族派来，但**从未参与长老之争**故一直安全；结交各族落、参与傀儡交易，并**暗中搜集炎火异晶**，每隔一段日子送回火雀族。
- **炎火异晶**：颠落之地独有，传闻亦为颠落大帝带来，是**制作傀儡的材料之一**，为数不多极其罕见。老者献上米粒大小的白色沙石一块。
- 王林接过细看，**瞳孔骤缩**旋即恢复如常，遣退老者并命其搜集火雀族全部消息详报。
- 独处：洞府大门轰然闭合并被打出禁制，王林死盯白色沙石，双眼越亮、隐露震惊与掩饰不住的激动：
  - 「炎火异晶……原来它也叫炎火异晶。」
  - 当年**朱雀老圣皇**曾言：**四圣宗起源于界外太古星辰**，而后才进入界内——此言果然不假。
  - 疑问指向核心：炎火异晶由颠落大帝带来，**颠落大帝为何会有此物？莫非……莫非……**（悬念未解）

## 六、看点与伏笔

1. 王林在太古星辰立足的第一步：拿下暗蝎族，把废弃修真星变成自己的地盘与情报站。
2. 战力层级明示：仅指尖气息即可震出对方元神，实力已远超「天人第四衰」的猜测区间。
3. 傀儡线索链：净涅中期 → 碎涅 → 天人衰劫，指向颠落大帝这个第三步大能。
4. 炎火异晶把「四圣宗—朱雀老圣皇—界外太古星辰」的旧线与「颠落大帝」并联，构成本卷最大悬念。
5. 火雀族暗中收集炎火异晶，与王林形成潜在冲突/目标交叉。
