# 《仙逆》第八卷 联盟隐秘 第960章 初窥本源

## 一、场景与起点：以烛火问道
王林独处房中，以一盏烛火为参悟对象。

- 初始观察：“烛火因风而动”，如同风吹山峰、草木皆动，看似山动，实则山未动、动的是风。
- 第一步验证：王林右手一挥，房内所有窗户尽数关闭，隔绝外界山风。
- 结果反常：风已停，烛火却仍在动（随灯油燃耗轻轻摇动）。王林神色阴沉，认定“不对”。

## 二、暗线：他证的是天运子的道
- 此刻王林的状态**与证道极为相似**，但他所证并非自身之道，而是**天运子的道**。
- 王林与天运子相识数百年；以往修为不足看不出对方变化，如今可隐约看出端倪。
- 天运子身上秘密极多，最令王林忌惮的是**完全猜不出对方心思**。
- 王林以烛火喻天运子：“天运子就如同这烛火，千变万化”，想寻其最初的样子，即便隔绝了风也做不到。

## 三、紫峰夜空：从“风动山动”到“我心动”
时至三更，山风呜咽打在窗纸上。王林一步踏出，出现在天运宗**紫峰**上方的漆黑夜空。

- 天空乌云密布，月光难透。
- 王林抬右手向天一挥，这一挥**蕴含他当年感唤雨时的规则**：乌云风起云涌，化作细密雨滴落下，云层消散，皎洁月光照落大地。
- 月色下紫峰之后现出一片阴影；山风吹过草木皆动，唯独那片阴影变化不多。
- 顿悟：“这山，并没有动”——风只吹动表面，山看似在动，实际上**是我的心在动。我心动，所以此山动**。

## 四、初窥本源：火之规则与本源一瞥
王林回到房中，气息平复到**仿若绝迹**。外人眼中烛火依旧微晃，在王林眼中却经历剧烈摇晃后**彻底静止**，如被施了定身术。

身体层面的异象：
- 体内元力不受控急速运转，流遍全身每一处，体内不断传出砰砰之声，**如凡人武者打通全身经脉**。
- 眉心**第三目**无声无息出现，打开一道缝隙，却无红光散出，反而似在**吸收着什么**，令元力运转之速更快，却无任何痛楚。

所见之景（层层放大）：
1. 眼前所视并非普通烛火，而是**王林此前一指施展出的一个极弱火苗**。
2. 火苗看似静止，实则仍在“动”——一种逆转，似有力量环绕使其以未知方式迅速消散；准确说是**在不断放大、放大、再放大**。
3. 放大无数倍后现出深处奥秘：**一个个细微的元力点**彼此交错，以特定方式时而碰撞，每次碰撞传出一丝灼热。
4. 这些元力点看似杂乱，其交错与碰撞中**全部蕴含某种规则**——王林断定：“这，就是规则**火之规则**”。

中断：
- 王林心念“能不能再深入一些”，元力点再度剧烈放大成庞大无比，一丝丝**絮状之物**缭绕。
- 刹那间体内元力轰隆作响，眉心一震刺痛，王林被迫清醒；冷汗湿透衣衫，面色苍白无血色。
- 王林自语：“那是什么莫非是**本源**”，并总结：**规则可以去摸索，本源只看到一瞬间，身体便承受不住**。

## 五、收尾
- 王林沉默后盘膝闭目打坐，吐纳至窗外天蒙蒙亮。
- 睁眼时，一道**仿若可以看破一切**的目光落在房门处。
- 阁楼外传来低柔女声：“老七我可以进来么”（说话者本章未点名）。
- 作者附言：本章少写约1000字，次日补上。

## 六、要点提炼
- 认知阶梯：**风动 → 山动 → 心动 → 规则 → 本源**。
- 王林此番所得为“火之规则”的直观层次（元力点及其碰撞法则），而“本源”仅得一瞥，肉身承受不住。
- 第三目在此处呈现**吸收/内敛**而非攻击（无红光）的新表现。
- 悬念：天运子之“道”仍不可测；“老七”之称与门外女子身份为后续伏笔。
