# 第1191章 天运再现（第九卷 云海之巅）

## 一、七彩世界内：苍松子 vs 青衫老妪

- 青衫老妪不作解释，掐诀猛吸，磅礴吸力欲把苍松子全身生机吸出——即前文所称的**聚阴归祖之术**，苍松子虽震惊仍自信能走。
- 苍松子**右手始终按着玉瓶**：此物无法放入储物空间，否则早已收好（争夺焦点）。
- 苍松子出手：
  - 左手虚空一抓 → 金光闪烁，幻化**数千上万把飞剑**直扑老妪；
  - 左手拍额 → 天灵飞出**一道赤红之芒**，形似元婴小人，**细看绝非元婴**，卷血光凄厉长吼随剑光冲杀。
- 老妪见此小人**面色骤变**，抛出**古铜大碗**罩之；小人双目血光、一声撕金断铁的尖啸，**大碗崩溃成碎片**。

## 二、四祖境界偷袭：断臂之伤

- 苍松子不恋战，身前波动欲踏入离开，半只脚入波纹之际，**虚无中伸出干枯手臂**抓其右手（抢玉瓶）。
- 苍松子瞳孔一缩：「竟然是**四祖境界**」；对方亦道破其为「**碎涅中期巅峰**」。
- 硬拼一击后苍松子闷哼、面色苍白，**左臂发麻发黑、泌出黄水**——中了奇毒；借冲击之力踏入波纹。
- 出手者现身：一个更苍老、**头发尽失、身穿青衫、仿若从棺木爬出**的老妇人，双目幽光、嘴角流血。她挥手破开残留的金光剑雨，**一把捏住血色元婴并封印**，随即踏入波纹追击。

## 三、山峰内追逐：七彩长剑 vs 紫光大盾，三体元神合一

- 苍松子判断：只要出了裂缝、脱离时限，凭众多法宝老婆子必非敌手；但被老妇人立刻追上，二人神通对轰、惊天动地。
- 临近禁幕边缘时**裂缝仅剩两丈且愈合加速**。苍松子念奇异咒语 → 天空七彩之芒下贯，环身化作**七道不同颜色长剑**攻敌。
- 老妇人掐诀撑起**紫光大盾**（气息沧桑、隐带魔气）硬接，喷血但神色更凄厉，拍额**元神飞出**。
- 同一刹那，从石碑七彩世界踏出的**青衫老妪**与**青衫美妇**同时拍额飞出元神，三者元神**电光火石间完美融合**，化长虹扑杀苍松子。（三者实为同一存在的分身/同源之体，最后阶段更以「三个身子融合为一」的形态出现。）

## 四、召·逆行者 与 生死禁「生生死」

- 苍松子以浮肿左手接过玉瓶，右手取出一颗珠子抛出，大喝「**召，逆行者**」：珠子吸摄天地七彩之芒后轰然崩溃，射出**一道七彩闪电**。
- 老妇人元神尖啸，飞出**三道禁制**——**生死禁中的极高存在**；神念喝出「**生生死**」，三禁融合成毁天灭地之威，与七彩闪电对撞。
- 后果：
  - 地动山摇，山峰大片崩溃；
  - 外界雾气倒卷，雾中飘摇的**铭志者**虚影齐齐一顿，全部向巨响处飘来；
  - 三合元神被冲散、越加透明，迅速退回各自肉身；
  - 苍松子倒卷喷血，**中毒左臂血肉化黄水、骨头融化，整条左臂撕裂脱体、消散一空**；
  - **玉瓶脱手飞出**，直奔只剩一丈的裂缝。

## 五、王林（化名吕子浩）夺瓶而出

- 伏笔：王林先前进入裂缝后即**收紧心神、不露气息**，利用此地禁幕内**神识无法远散**的特性，隐藏在**裂缝出口边缘**伺机而动。
- 苍松子与老妇人同时扑向玉瓶时，一道**白色身影**以**堪比碎涅后期修士的速度**越过二人，一把抓住玉瓶，毫不停顿冲出裂缝；
- 冲出瞬间抬右手向裂缝一拍，**禁制融入禁幕，裂缝愈合速度暴增**（封路断后）。
- 苍松子一愣后怒吼「**吕子浩**」，冲出裂缝欲追，却一脚踩在**王林事先布置在外围的禁制**上，四周禁制神通弥漫，脚步一顿。
- 老妇人三身此刻**融合为一**，如闪电般穿过禁制追击王林。

## 六、雾海逃遁与天运一指

- 王林在雾气中疾驰穿梭，诡异呢喃回荡耳畔，虚影自身边穿过；**贴上两张速符**后速度快到无法想象，与追者渐渐拉开距离。
- 老妇人恶毒喝「抢老身之物，你该死」，挥手化出毒雾，凝成**数千丈大的毒蝎子虚影**甩尾扑杀；王林转身**左手握拳虚空一击**，蝎尾一震即崩溃。
- 苍松子追出，**不惜心痛再抛第二枚珠子**：「召，逆行者」。七彩之芒疯狂汇入、珠子崩溃，天空波纹凝聚出一根**巨大的手指**，吸走天空大半七彩之芒，天为之暗，向逃遁的王林碾落。
- 王林瞳孔收缩，认出：「**天运一指**——此地果然与**天运子**有关联」（关键情报：此秘境/石碑世界与天运子存在关联）。
- 老妇人同时再出三道**生死禁最高禁制变化**，喝「**生死生**」，融合成生死禁气冲向王林。（章末悬念）

## 七、要点与伏笔

1. **天运一指**由「逆行者」珠子召出 → 云海星域此地与天运子（第514章已死）存在直接关联，是王林追索的重大线索。
2. **生死禁**双式已现：「生生死」（对苍松子）、「生死生」（对王林），皆为生死禁中最高层次的三禁融合。
3. **四祖境界**首次点明，青衫老妪/美妇/老妇人三体可元神融合、亦可肉身融合，善奇毒与聚阴归祖之术。
4. 苍松子代价：血色元婴被封印夺走、左臂彻底毁去、两枚「逆行者」珠子耗尽，且玉瓶已失。
5. 王林全程以**吕子浩**之名被指认，其「伏于出口—抢瓶—封裂缝—外围预埋禁制」是一套完整的预谋算计。
