# 第641章 云仙道侣：王巍、胡娟（本片段主线：画轴指引与紫雾深坑）

> 注：章节标题点出“云仙道侣：王巍、胡娟”，但本片段正文尚未展开该二人情节，内容集中在回廊深坑、紫雾与金色大剑争夺。

## 一、画轴异动：娇影低语“下去”

- 王林瞳孔一缩，神识分出一道融入**储物袋**，发现当年得自**朱雀星**的**神秘画轴**自动打开。
- 画轴内紫光闪烁，映出一个**背对王林的妙曼虚幻女性身影**，如自语般不断轻声道：“下去。”
- 王林对此娇影并不陌生——当年在朱雀星面对**仙遗族三祖**时，对方释放符兽，娇影一召便将符兽收入画内。
- 画轴谜团：王林修为达**问鼎期**后曾在**炼魂部落**取出研究，始终毫无进展。该画轴**可留下烙印，却无法操控**。
- 王林传出神念试探：“下去这深坑？”娇影只是重复：“下去。”
- 王林收回神识，望向身旁**巨大深坑**：其内一片漆黑、阴森。略一沉吟后并未下坑，而是身形一晃追向周佚，心中生疑：“莫非这深坑内，有与那画轴有所牵连之物不成？”

## 二、深坑之险与周佚的告诫

- 周佚（身在仙剑内）警示：**深坑内有一股奇异之力，可影响心神，心志不坚者望之便会失足**，嘱王林莫要再看、一心飞行。
- 深入回廊过程中，深坑吸力**忽强忽弱**。

## 三、回廊东部·紫雾封识

- 行至**回廊东部**，前方一片黑暗看不清路径；周佚刚出言示警，深坑便蓦然散出**浓浓紫色雾气**弥漫四周。
- 紫雾特性：
  - 阻隔视线；
  - **神识只能散开不足三丈**，且模糊，再向外散即如被雾气吞噬般消失；
  - **不受深坑吸力影响**（此阶段），极为诡异。

## 四、仙幕护体与全速飞遁

- 周佚驾仙剑折返，令王林登剑：“罢了，王林你上来，我带你过去，这里雾气诡异，以你之力，怕是会有危险。”
- 王林踏上仙剑，**仙力自剑传入双脚、流遍全身**。
- 周佚口诀：**“定气凝神、开阖心府，含仙不吐”**。
  - 效果：仙力震荡透出经脉，在王林肉身之外形成**金光闪闪的仙幕**；
  - 仙幕**兼含仙力与剑威**，一散之下紫雾如被大手拨开、让出通道。
- 周佚化作长虹载王林冲入紫雾，剑气所过不散之雾亦立刻消失；王林只觉罡风扑面，紫雾如一条条紫龙数息掠过眼角。
- 仙剑猛地斜向上螺旋疾驰，王林运转仙力方能稳立不被甩落。

## 五、剑灵线索与王林的两处心念

- 周佚宣告：“**上一代雨之剑灵的气息，就在前面**”，予王林数息准备后展开**全速**。
- 全速表现：出现**残影**，如同凭空瞬移——但**并非瞬移，而是达到了瞬移的速度**；王林已不呼吸，闭住一口仙气；仙幕被压得扭曲变形紧贴其身；四周雾气因速差化作**雾海**。
- 心念其一（自比）：这种感觉是**数百年前刚踏入修真界时**才有，颇为感慨；并叹“这才是仙剑，这才是剑灵”——**自己那把仙剑亦有此威，但剑灵不强，无法发挥全部**。
- 心念其二（对许立国）：**许立国虽身有反骨，但此魔头欺软怕硬，翻不出我的手心**。

## 六、吸力暴涨·抢夺金色大剑

- 突变：紫雾蓦然翻滚如云涌般膨胀，深坑内涌出**极强吸力**。
  - 原本不受吸扯的**紫雾也被大量吸入深坑**；
  - 四周墙壁细小碎石纷纷颤动被吸走。
- 远处**刺入回廊墙壁的一把金色大剑**（王林极为熟悉）轻颤、一点点抽出，砰然脱壁，顺吸力直奔深坑。
- 周佚毫不犹豫剑身一转冲入深坑直追大剑；**坑内外吸力相差极大**，本身之速加吸力，其速**超过闪电**，瞬息追上金光大剑。
- 王林眼露果断，在仙剑临近刹那**右手虚空一抓，抓住金色大剑**。
- 后果：大剑之上缠绕深坑吸力，此抓等于**与深坑抢宝、与吸力对抗**，一股大力传来，王林身子不稳，**险些被拽落仙剑**（片段止于此，悬念未决）。

2. 深坑影响心神的奇异之力来源、紫雾本质与吸力周期性变化的机理。
3. 上一代雨之剑灵所在与周佚此行目的。
4. 金色大剑归属（王林“极为熟悉”）及争夺结局。

# 第600章前后：巨富出世与云仙道侣入火妖郡

## 一、深坑夺剑：巨富现世

- **危局**：王林身处深坑，强大吸力之下金光大剑不断下坠。
- **应对**：王林深吸口气催动 **道化黄泉**，黄泉在其身边徘徊，一指之下环绕成螺旋形剧烈转动，散出黄泉之风，吸力略缓。
- **抓剑**：吸力一缓，王林狠狠一抓，虚空扣住大剑，大剑停止下落、缓缓上提。其重量如无穷，王林肉身几欲撕裂，脸上青筋鼓起。
- **周佚助力**：仙剑内传出周佚一声低吼，吼声中似蕴含 **剑灵咒语**，剑光闪烁间带王林冲向深坑口；再度低吼，仙剑之力再增，生生提高数丈。
- **心念**：王林眼中露出坚定——一旦松手，此剑怕是永生再无拥有之日。
- **剑之真容**：上提过程中，剑身残存金色彻底脱落，露出金色之下 **漆黑剑身**；剑柄残余宝石一一碎裂化作飞灰被吸入深坑。
- **得手**：冲出深坑瞬间，王林大喝、右手狠狠一抓，大剑飞出被其抓在手中。漆黑剑身上刻着两个浅浅的字——**「巨富」**。
- **感触**：拿着巨富，往昔种种在王林心间一闪而过。

## 二、撤离潮汐深渊

- 周佚以极快速度带走王林，顺回廊疾驰。
- 王林以 **神念传音** 指引周佚飞向潮汐深渊内 **唯一的出口——火妖郡出口**。
- 王林仔细看了巨富一眼便收入储物袋：**这一眼已看出其内端倪**；此端倪若修为不够则无从看出，而他此刻修为已达 **问鼎**，故能看破。计划离开潮汐深渊后再细究。
- 王林自评：「潮汐一行，算是圆满」，唯憾 **神秘的令牌** 不知在何处。

## 三、储物袋内的异动（伏笔）

- 储物袋空间中的 **蚊兽** 睁开双目，露出疑惑：按理在储物袋内除非神通惊人否则无法感应外界，此刻却感到外面有 **很多极为熟悉的气息**。
- 一旁 **雷蛙** 始终沉睡，蚊兽犹豫后趴在雷蛙背上闭目。
- 对应外景：他们越接近火妖郡出口，也就越接近那片包围 **贪狼等人** 的雾气与大量蚊兽。

## 四、云仙道侣：王巍、胡娟登场

### 出场
- 妖灵之地南部飞来一片祥云，仙气缭绕、霞光阵阵，如仙界之物。
- **男修王巍**：身姿挺拔，水蓝色长衫绣片片青云并透出波纹，长发飘散，英俊刚毅，手持 **翠绿玉笛**，衣衫飘动如仙人。
- **女修胡娟**：淡紫色衣裙绣淡粉色小朵仙花，松髻斜插淡紫簪花，随意而典雅，略施粉黛，肌若凝脂气若幽兰；时而看向身边男修，眼露柔情。二人显系 **道侣**。

### 九霄仙云
- 寻常修士腾云驾雾借的是天空白云、抽离水气之雾，速度不快、无强法术，只是徒具美感糊弄凡人，属低阶神通。
- 二人所腾之云为 **九霄仙云** 炼化而成，当年在仙界亦极为少见；其神通之处在于 **云内天然蕴含仙雷**，威力不可小觑。
- **辨识标志**：老一辈修士一见此仙云便能认出身份——能如此轻描淡写腾九霄仙云者，唯有 **血祖、凌天候、天运子** 这个境界之人。

### 来历与实力评估
- 号称 **「云仙道侣」**：当年与天运子、凌天候等人 **首次进入妖灵之地**，占据一座洞府 **数万年未出**。
- 修为当年即与天运子等人相当，又擅长 **道侣合击**，故连天运子也极为忌惮。
- 更令天运子忌惮的是其 **来历神秘**：天运子始终查探不出，只知二人修道年月似 **比天运子自身还要久远**。
- 性格平淡、不喜争权结势，不主动招惹便无大碍。
- **旧怨伏笔**：王林 **十亿尊魂幡** 内的矮小老者若见此二人，定会咬牙切齿地认出——当年抢走他一个储物袋的正是这对道侣。

## 五、连锁反应

- 祥云直奔火妖郡。进入火妖郡的一刹那——
- **天妖郡帝部龙潭** 中，正在融合古妖残魂的 **古妖贝罗** 蓦然睁眼，眼中爆出极明亮精芒旋即消失。
- 贝罗心念：「他们居然离开了洞府，看来我要加快吞噬其他古妖残魂的速度了」，眼中露出 **隐藏极深的忌惮**。
- 祥云过处，天空云层全部逼退；城池内妖将妖兵心神震动，丝毫不敢飞出查探。

## 六、两线汇合前夕

- 祥云停在 **潮汐深渊出口上空**，云朵消散，二人自半空落下。
- 王巍笑言：「有趣，娟儿，这里居然还有一些禁制，恩，这些禁制倒也巧妙。」——显示他对此处 **禁制** 感兴趣。
- 胡娟笑答：「能让你感兴趣的禁制，倒是不多。」
- **张力**：王林正携巨富自内部赶往火妖郡出口，而两位与天运子同级的绝顶强者已守在出口之上。
