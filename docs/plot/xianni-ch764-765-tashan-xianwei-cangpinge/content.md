# 第七卷 名震罗天 第814-815章：塔山、仙卫 / 水晶棺材

## 一、清点雷之仙界收获（第814章前半）

### 封仙印
- 王林张口吞下封仙印，化作微弱金芒落入口中，在元神内受雷威凝炼。
- 判断：此物长久留在元神内，必会沾染雷霆之力。

### 三面紫色小旗与雷仙殿使者元神
- 从储物袋取出三面相互包裹、禁制之光闪烁的紫色小旗——当年雷仙殿使者即被连同此旗一并封印。
- 掐诀散去禁制，雷仙殿使者元神带着恐惧冲出，欲瞬移逃走。
- 王林祭出（十亿）尊魂幡，化作大片黑雾弥漫天地，瞬间吞噬其元神。
- 该元神求饶：「我以重宝换命」——供出**罗天石**，称知道何处可取，愿带路换命。
- 王林不置可否，掐诀一指，黑雾将其**封印于尊魂幡内**；对「罗天石」沉吟片刻后暂不深究。

### 小旗的鉴定
- 抹去旗上原有神识烙印，印下自身神识，琢磨半柱香。
- 结论：**罕见的防护类法宝**。祭出后三旗环身急旋，形成紫色雾气漩涡，具一定防护之力。
- 注入体内元力后剧变：漩涡转速快数倍，雾气大浓，几乎笼罩全身、彻底包裹身影。三息后雾散收旗。评价「此宝威力尚可」。

### 两张黄色纸符
- 至今仍看不出作用，收起备查。

### 藏品阁（最大收获）
- 神识散开方圆十里、确认无端倪后才敢取出。金光闪烁、仙气弥漫，为**巴掌大小的阁楼**，王林见之仍心跳加快。
- 自认「此次雷之仙界内最大的收获，当属此物藏品阁」，获得后一直不敢拿出。
- 内藏仙术，数量未知。限制：
  - 以自身修为**只能进入第四层**；
  - 曾借**白衣女尸**进入到**第九层**，但破不开禁制，无法取走其中仙术；
  - 疑心其上可能有进入次数限制，且当地并非绝对安全，故不轻易研究。
- 藏匿手法：按当年学到的印记令其不断缩小至**指甲大小**，装入一个空储物袋，解开上衣**划破胸口埋入肉内**，以元力使伤口愈合——「如此，没有人可以知道藏品阁在何处」。

### 仙玉
- 身上另有几个几乎装满的储物袋，全是**仙玉**，数目庞大，均得自雷之仙界。
- 整理这批收获耗时近两个月。

## 二、塔山之死局与仙选族觉醒（第814章后半）

- 王林决定离开，蚊兽欢啸而来将其托起；地面雷蛙一跃跟随，一同飞向建筑群。
- 临近仙选族聚居地即见异状：宽大广场上**全族跪伏**，连孩童与女眷在内。
- 广场中央三丈大小的木尊上躺着**塔山**：面如死灰、双目黯淡、死气浓郁，已届弥留。

### 奴符反噬
- 两个月前王林便看出塔山油尽灯枯。塔山身上奴符之力极强，此种奴符**由传承血脉中留下，容不得反抗**。
- 塔山是**第一个反抗者**，代价为全身符文印记反噬，无法存活；坚持两月，今日到尽头。
- 此刻他身上已无符文印记——印记尽数深入体内，成为致死杀手。

### 全族的悲恸与反抗
- 先祖老者悲戚落泪，轻唤「孙儿」——这个称呼已久未出口（确认二人为祖孙）。
- 族人低语汇成一片「塔山」之声：在他们心中塔山是英雄，以绝不屈服证明**奴符并非不可抵抗**。
- 塔山神智恍惚，忆起儿时族训「仙人是我族之主……我们是仙人在这世间的使者」，眼角落泪，恨天地不公、恨所有仙人。
- 老者转身向全族揭露：
  - 世世代代守护此地，换来的却是**雾兽**，是杀死无数族人的雾兽；这一切皆仙人所致，族人在仙人眼中「只是那喂养雾兽的食物」。
  - 塔山曾告知他「**仙人已经不再，当年的仙界已经崩溃**」，此事他一直隐瞒，今日公开。
- 老者向王林求证（自两月前王林杀死那仙人后，老者便以「恩公」相称）。王林点头确认：「仙界已然崩溃，仙人，已经不再，即便是有，也是极为稀少。」
- 老者激昂大喝「即便是死，也要如塔山一样，死的有尊严」，族人齐呼「反抗」，声浪成风暴。

### 王林的提议
- 王林轻声道：「我，可以让他不死。」
- 条件与代价说明：**有五成把握**；神通成功后塔山虽不死，但会成为**一具没有意识的傀儡**，能否最终恢复意识需靠他自己。
- 老者跪地泪下，求证此言可真。

## 三、塔山应允与三月之约（第815章）

- 塔山虚弱开口：「我，愿意。」
- 王林补充施法前提：**被炼化者需信念坚定、完完全全心甘情愿，绝不能有半点犹豫，否则此术必败**。塔山惨笑重申愿意。
- 王林一把抓起塔山踏空而去，远远传话：「**三个月内，莫要打扰**。」
- 老者望着王林消失处神色复杂，最终一咬牙对全族沉声宣布：**三个月后，无论塔山结果如何，全族都要冲击玄阴鼎、离开此地。**

## 四、待追踪线索
- **罗天石**：雷仙殿使者元神以此换命，地点未取，线索悬置（其元神仍封在尊魂幡内可再审）。
- **藏品阁**：层数≥9，第四层为当前上限，第九层禁制未破；可能存在进入次数限制。
- **两张黄色纸符**：用途未明。
- **塔山傀儡化**：五成把握，三个月后见分晓。
- **玄阴鼎**：仙选族三月后冲击的离开通道/目标。

# 第765章 塔山炼成仙卫 · 强启祭坛离去

## 一、炼制仙卫：三管齐下
王林带着塔山回到当初祭炼法宝之地，将塔山置于一旁，吐出一口元神之气包裹其身，开始炼制。

投入的三样资源：

| 资源 | 来历 | 作用 |
|---|---|---|
| 天鬼 | 王林在**雷之仙界**内获得的又一头天鬼，自尊魂幡中抖出 | 「以天鬼之魂助你成魄」 |
| 海量仙玉 | 另一储物袋中甩出，数目庞大，弥漫四周 | 「以仙玉之气滋养你身」 |
| 十多个仙遗族先祖头骨 | **朱雀星**上所获，眉心皆有复杂符文 | 「以你族先祖之头骨祖符助你完善符力」 |

天鬼一出现便咆哮挣扎，王林右手一指取出**因果昆极鞭**，连抽数下将其打得连连惨哼、就范。

王林之言：「塔山，我送你一场天大的造化。若如此还不成功，则是你福缘不足，非我之过。」

## 二、两个多月后：仙卫出世
- 平原内传出轰隆巨响，声势之大连建筑群内的**仙选族**族人也清晰察觉，纷纷飞出。当先的老者一脸憔悴，两个月如过数年，愈发苍老。
- 尘土中走出一名**两丈身高的大汉**：粗眉粗目、全身散发金光、仿若巨人，每一步落下大地颤动如奔雷。
- 其身上再无任何符文印记，**惟独眉心一个极为复杂到看一眼便眼花缭乱的符文**；双目蕴含灵动。
- 王林随后走出，神色带一丝疲惫，眼中露出遗憾。

### 王林的复盘（沉思要点）
1. **遗憾**：「可惜，最终只能达到**阳实巅峰**，没有办法突破达到**窥涅**。」
2. **仙玉效用**：消耗大量仙玉，不但使塔山身体恢复，更不知为何**体型增长了一倍**。
3. **天鬼关键**：若非天鬼，进行到**第二个环节**时便会立即失败。两次仙卫成功均融入了天鬼——王林怀疑天鬼可增加成功几率。
4. **头骨异象**：仙遗族先祖头骨在融入之际**彼此相互凝聚，成为一道符文**。

## 三、与仙选族老者的交待
- 老者激动飞前颤声唤「塔山」，大汉神色冰冷、看都不看一眼，在王林声音下停步不动。
- 王林平静道：成功后神智能否恢复，他没有把握，或许时间长了能有所恢复。
- **叙述明点**：王林没有撒谎——塔山的神智并未被抹去，而是**粉碎后存在于仙卫体内**。
- 王林打断追问，已滞留太久，语气不容置疑：「去开启祭坛大门，我要离开。」

## 四、开启祭坛与冲入通道
- 王林途中把跟来的**雷蛙**与**蚊兽**收入储物袋，塔山紧随其后；仙选族族人（含从房间走出的女眷与孩童）尽数跟随前往祭坛。
- 老者双手掐诀、眉心植物闪烁化作印记飞落大门，大门轰隆隆缓缓升起、全部打开。
- **音波袭击**：门开刹那传出尖锐之声，仿若一把把利剑冲出。王林一拍储物袋祭出**三面紫色小旗**，旋成紫色漩涡，尖锐之音一入即被搅碎消散。
- **塔山首战**：王林低喝「塔山，毁灵」，塔山双目爆金光，一步踏出冲入大门，一拳挥出化作音爆在通道中回荡，威力比其成为仙卫前强烈数倍；通道内零散黑雾如被狂风吹袭齐齐后退。
- 王林眼中寒光一闪，已下定决心说什么也要离去，整个人如闪电冲入大门，顺通道直奔前方。

## 五、看点
- 仙卫炼制方法论首次被系统交待（仙玉养身 / 天鬼成魄 / 祖符补符力），并给出失败节点（第二环节）与上限（阳实巅峰，未达窥涅）。
- 塔山从仙选族守护者转为王林麾下仙卫傀儡，神智以「粉碎保存」状态潜伏，埋下后续伏笔。
- 王林去意已决，祭坛通道内的黑雾与音波为其离开的第一道阻碍。

# 第765章 玄阴鼎碎·仙选族迁离·五分身与子母道枯

## 一、祭坛通道尽头：击碎玄阴鼎

- **场景**：仙选族族人一一走入通道，王林抵达通道尽头玄阴鼎所在之处。
- **敌**：一个黑雾化作的女子虚影，呈雾絮状急速绕塔山旋转，发出刺耳尖啸（伤元神的音波）。
- **双方免疫机制**：
  - 塔山：仙卫之身，元神早已崩溃融入肉身，肉身强度极高，尖啸无效。
  - 王林：元神内有**古神皮甲**守护，音波触及元神刹那即自行崩溃。
- **王林应对**：双手掐诀，体外**三面小旗**飞出，形成大片**紫气漩涡**对抗音波。
- **塔山出手**：与王林心念相同，临身一拳印在玄阴鼎上。此拳是他成为仙卫后最凌厉一击，掺入其残存本能中对玄阴鼎无数年的恨意；眉心复杂符文如活物般闪烁并幻化融入拳中，产生法术波动。
  - 一拳：祭坛震动落石，玄阴鼎现蛛网状大片裂缝。
  - 二拳：**玄阴鼎崩溃**，碎片四射，一团浓郁黑气环形散开后猛地收缩，尽数从鼎内**小型传送阵**中被吸走。
- **女子虚影**：绕过紫气漩涡冲来欲阻止，同样被传送阵吸走。

## 二、召回许立国与仙选族全族迁离

- 王林踏上阵法，喝道：「许立国，还不回来」——一名仙选族族人身子一颤，一团黑气自其眉心飞出化作许立国之形，带一丝回味飞向王林。（许立国此前藏身于族人体内）
- 王林先入阵消失，塔山紧随。
- **仙选族先祖老者**回望众族人后踏入传送阵，其后全族一一踏入，离开世世代代居住并守护之地。
- 祭坛尘土大片落下，随时可能崩溃。

## 三、幽冥兽体内：血阵、水晶棺与守棺黑衣人

- **地点**：幽冥兽体内一处漆黑虚无。
- **布置**：一座庞大阵法，以**暗红色血液**凝聚布成，飘于虚无；血中散出阵阵黑气，融入阵法中心的一座**水晶棺材**。
- **棺中**：一具男子尸体，相貌俊美、约二十多岁，仿若沉睡，持续吸收黑气。
- **守护者**：阵法外盘膝一黑衣男子，宽大衣袍除头部外裹住全身，闭目打坐，「仿佛恒久以来便存在于这里」。
- **其自语**：「果然来了……可惜我此刻之力，无法毁掉阵法，否则的话，也就不用担心了。」→ 说明其力量受限，且阵法非其所愿存在。
- **分身术**：黑光闪烁，自眉心飞出虚幻之影落于十丈外凝实成与其一模一样的分身；第一个分身挥手换上**蓝衫**，直奔远处；随后接连施法，连同第一个共**五个分身**尽数扑向远处。

## 四、数万里外：正面遭遇与「子母道枯」

- 五彩光芒形成巨大漩涡，王林走出，许立国如游魂般飘出盘旋，塔山紧随，仙选族族人陆续现身。
- 王林神识散开，见前方虚无中一蓝衫人急速飞来——正是分身之一。
- **关键情报**：王林瞬间明悟「原来之前所杀，只是一个分身」——此前所杀的黑衣人只是分身，本尊未死。
- 王林心念一动，塔山跨步一拳轰向蓝衫男子；蓝衫分身掐诀，晶光闪烁幻化出一把**长枪**迎击。
- 远处四道身影如长虹扑来（其余四分身）。王林眼中杀机一闪，身子晃出，右手向前一点，**手背兽骨图案蠕动，兽骨幻化而出**。
- **五分身同时惊呼**：「师尊的子母道枯」，眼中骇然与无法置信。
- 数万里外盘膝的黑衣人本尊，双目爆出精光。

## 五、要点与伏笔

1. 黑衣人一系与「子母道枯」之主（其口中「师尊」）有师承渊源——王林手背兽骨即子母道枯，来历与该势力上层直接挂钩。
2. 玄阴鼎被毁后黑气与女子虚影被传送阵吸走，去向疑与幽冥兽体内的血阵/水晶棺尸体（吸收黑气者）相关联。
3. 黑衣男子明确表示无力毁掉血阵，其「守护」身份可能是被迫或另有目的。
4. 王林所杀者仅为分身，本尊仍在，且尚有五个分身可用。
