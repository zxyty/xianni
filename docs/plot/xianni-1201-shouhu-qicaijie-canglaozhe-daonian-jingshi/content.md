# 第九卷 云海之巅 第1201章 守护（第二更）

## 一、场景与起因
- 王林（本期以化名『吕子浩』在云海星域行走，见第1063章起）在七彩界悟道后，心神从三名青年身上扫过，向远处弥漫。
- 心神发现一处**高耸山峰**：四周**没有任何禁制**，连七彩界的雾气也远远散开，「似乎不敢靠近这里」——异常之处即为伏笔。

## 二、冲突：白发老者截击心神
1. 王林心神将要探入山峰的刹那，峰内轰然冲出一股极为强悍的**神识**，与王林心神相撞；无声轰鸣中，王林原本迷茫的思绪骤然清醒。
2. 阴森神念传出：「**很久没有看到如此精纯的意境了**」。更磅礴的神识横扫而出，在半空化作**大手**抓向王林心神，天地色变，七彩之芒都为之避退。
3. 王林心神急速收缩，四周生出**大量虚幻**（幻术），天地为之模糊。
4. **白发老者**自山峰飞出，盯着虚空一晃冲出，右手向虚空一拍——轰轰声中王林四周虚幻**彻底崩溃消散**。
5. 老者喝道：「区区幻术也敢在老夫面前施展，你既然送上门来，就留下吧——这精纯的意境，比得过那些**铭志者**百倍。」右手抬起似可遮天，手掌蕴含极大吸力，王林心神扭曲中被迅速吸撤。

## 三、转折：驳杂道念结阵自保
- 王林一语不发，**右手向前一甩**：七彩界内**所有被他放弃的道念**轰然而动，从四面八方直奔而来。
- 道念无穷，疾驰中搅动七彩界雾气，天空七彩光芒都为之一暗；瞬息在王林身边凝聚到极为可怕的程度，形成**巨大漩涡**横扫，老者抓来的右手**立刻一顿**，神色凝重。
- 王林开口给台阶：「在下感悟意境，心神随意散开，故而打扰了道友修行，此乃无心。」此时其心神所化虚幻身影已被无穷道念严密防护。
- 老者双眼瞳孔收缩——**他从未见过这种心神神通**，竟能凝聚出如此多的驳杂道念。
- 沉默片刻，老者冷哼：「**只此一次，下不为例**」，大袖一甩退回山峰，收回神识。

## 四、结果：道念凝成黑色晶石
- 王林心神在无数道念环绕下越过大地，瞬息返回山谷肉身；睁眼时目中寒芒——**若老者执意留其心神，王林便会展开全部道念回击**。
- 王林起身右手指天，无数道念呼啸卷动天地涌入山谷，在其右手上凝成一个**黑色光团**；悟道时所有被废弃的道念尽数收入其中。
- 道念被收走的连锁反应：山谷外**迷失者**双目再度迷茫、四散离去；**铭志者**喃喃之声再起、渐渐飘走；**十二阶凶兽**恢复清醒、咆哮离开；山谷外一切恢复正常。**苍松子面色苍白，向后疾驰而退。**
- 王林右手一抓，黑色光团砰砰作响，化作一枚**黑色晶石**落于掌心。

## 五、关键设定：黑色晶石（废弃道念结晶）
- **来历**：王林从无数丹药内分离出的道念（悟道过程中被废弃的驳杂道念）凝聚而成。
- **威能**：堪比一件极强的法宝；即便是**碎涅期修士**，此物若爆开，冲击而出的道念也可令其**道心崩溃**。

## 六、悬念与伏笔
- 王林沉吟：「**他在守护什么？**」
- 判断依据：老者修为达**碎涅后期**，却滞留在那山峰处；且在最后关头显然**有所顾忌**而未强行出手——若非守护或图谋什么，王林绝不相信。
- 该山峰四周无禁制、雾气避退，与老者的滞留互为印证，指向峰中另有隐秘。

# 第1119章 意境突破与「换位」追杀苍松子

## 一、王林：意境突破，出谷追击

- 王林注意到三名青年修士中有一人他曾见过，因此地与「掌尊」有关，故认为此人出现可以理解。
- 心神平静、双目深幽如蕴天地之道；**在看到骸骨身上经文的一刻，意境突破**，只需一段时间凝聚，修为便可达**净涅中期**。
- 起身走出山谷，穿过谷外**岁月禁幕**（禁幕波纹回荡），望向苍松子逃离方向，身影如电追出。

### 追杀苍松子的三重目的
1. 苍松子伤势恢复后竟找到他所在之处，且恨他入骨，此次绝不能让其逃掉。
2. **玉瓶内液体到底是什么**，答案在此人身上。
3. **离开此地（七彩界）的方法**，要从其元神中搜出。

## 二、苍松子：判断失败与「封界」毒计

- 苍松子本以为伤愈后杀「那吕姓之人」手到擒来，最多在破开禁制上有些麻烦；却连对方身影都没看到，仅踏入**千丈之内**就被卷动道心、心神震动险些崩溃。
- 山谷外无尽驳杂道念中，他如怒浪孤舟；王林心神扫过时更觉震动，隐隐猜到对方意境明悟、修为即将提高。
- 结论：对方未突破时他拼尽一切也只是两败俱伤，如今再战**必死无疑**。多年准备宣告失败，再执着连性命都要送掉。

### 苍松子的怨与决断
- 对王林恨不能生啖其肉：「此人毁我心血」。
- 迁怒「那姓赵的婆子」——若非她抢夺在先，也不会给那姓吕之人机会。
- **毒计**：东西全不要了，任你们拿走；他将离开七彩界后**把此地彻底封死、毁去外界的七彩裂缝**，让众人从此被生生困在里面、永世不得出去，以此解恨。

### 关于庞德才与司马墨洞府
- 苍松子推断：姓吕之人杀了**庞德才**并对其**搜魂**，否则不可能如此巧合知晓**司马墨洞府真正所在**。
- 但庞德才并不知晓离开此地的真正方法——他所知道的，**只是苍松子想让其知晓的**（有意植入的假信息）。

### 逃遁路线
- 走一条**并非之前走过**、但他已走过两次极为熟悉的道路，直奔外围其往常离开之处；因担心遇到**迷失者**，速度未拉满。

## 三、交手：古神大鼎「换位」

1. 苍松子疾驰中身子一震回头，见王林身影闪烁而来，杀机笼罩，遂加速前行。
2. 王林右手掐诀，体外浮现虚幻的**古神大鼎**，遥遥一指苍松子，喝「**换位**」。
3. 苍松子体外光芒刺目、身形消失，与王林位置**瞬间颠倒对调**。
4. 王林现身后毫不停顿直奔苍松子，趁其被神通打乱之刹那拉近距离。
5. 王林**右手向前虚空一按、左手在右手背上连点**，磅礴元力轰隆隆化作疯狂冲击直扑苍松子。
6. 苍松子从未料到王林有此等法宝；反应过来时冲击已近，遂尖啸扭曲，幻化**七个血色元婴**快速凝聚于眉心**模糊的闪电印记**上，印记散发夺目之芒迎击。
7. 轰鸣惊天动地。

## 四、旁观者

- 不远处一座山峰洞府内，**役兽宗陈天军**走出，盯着王林与苍松子之战，倒吸口气。
- 注：世界状态须知记「陈天军」已于第1100章死亡；本章仍以其名出场目睹此战，存疑（可能为同名/记录冲突），此处照文本记录，置低置信度。

## 五、悬念 / 待解

- 玉瓶内液体的真相。
- 离开七彩界的真正方法（只在苍松子元神中）。
- 苍松子能否逃出并毁去七彩裂缝，将众人永困。
- 王林净涅中期何时凝聚完成。
