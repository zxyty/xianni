# 第八卷 联盟隐秘 第1136章 亡命天涯

## 一、场景与阵营
- 地点：空间裂缝内（承接拓森苏醒之战）；结尾切换至朱雀星外的月星、随后星空及一颗偏僻废弃星。
- 在场：古神拓森（敌）；黑衣老人（被无极子称作‘鲁夫子’）；炎雷子；尸阴宗八王；王林（此处为分身，本尊在月星山峰内闭目遥控/感应）。

## 二、无极子的示警与自陈
- 拓森眉心第四颗古神星点内，盘膝坐着一名中年文士——**无极子**：下半身已与地面融为一体，长在一起；不死也不能死，只能默默度过无数岁月。
- 星点内的晶光并非外来，而是从其体内飘出：每分出一丝晶光，他便苍白虚弱一分，最终枯萎如骷髅。
- 两度传声：先是苍桑苦意的“鲁夫子，老夫没有忘记约定，但已无能为力，你速速离开”；随第四星晶光渐盛而声音消失，随即化作怒吼“快走”。
- 后段自陈因果：“老夫错了，当年大错特错，不该贪图这王族古神之力以冲破**空涅初期**，结果落得如今下场。”
- 动机：他判断若鲁夫子也被吞，则自己此生再无脱困之机；唯有拼尽一切救鲁夫子，方有日后一线生机。
- 诡异处：黑衣老人神识扫过第四星点，毫无发现。

## 三、拓森的宣告与三轮交锋
1. **断剑一击**：黑衣老人虚空一抓取出**半截断剑**，咬破舌尖喷血于剑上甩出。断剑穿透古神拓森右脚、贯穿右腿（血光浮现），直奔其眉心第四星，速度远超碎涅修士乃至“天人衰”境界。
2. **第三星骷髅修士出手**：断剑逼近第四星不足十丈时，拓森眉心**第三星**中走出一名身若骷髅、披头散发者，一步而至，右手两指一捏——“仿佛天地规则随其动作而改变”。断剑被两指钳住，无法挣脱；此人自身亦受巨大冲击，全身砰砰欲崩，**空空的眉心浮现清晰的月牙印记**。随后甩剑改向，返回第三星内。王林见此一脸苦涩；黑衣老人当即挥手令断剑消散、转身破裂缝欲走。
3. **第五星追杀与灭神矛**：拓森驱动黯淡的**第五颗星点**脱离眉心，高速旋转如黑洞直扑黑衣老人；第四星内无极子爆出晶光笼罩阻挡。拓森遂虚空一握，紫色电光凝成数个星球长短的巨矛——**灭神矛**（真正的王族古神之器），掷出后一路崩溃空间裂缝。黑衣老人踏入自身掐诀开出的漩涡，再喷血催动断剑迎击，断剑倒卷化虚无，灭神矛一顿后续冲。

## 四、王林分身的阻矛与湮灭（本章转折）
- 王林眼中，灭神矛“只是一件法器”；他此刻唯一念头是不能让黑衣老者被拓森星点吞噬。
- 他极速冲至矛前，肉身轰然崩溃化作**一片碎石**（分身特征），残余一丝元神在湮灭瞬间掐诀，吐出只针对灭神矛的神念：
  > “以吾王林之念，阻你前行”
- 灭神矛骤然一颤；拓森代表其神念的暴虐气息随即撞碎王林元神。元神湮灭前听到最后一句：
  > “第一颗古神之星，我为你留着”

## 五、逃亡代价
- 那一顿一颤争得的时间足够：黑衣老人先入漩涡消失，炎雷子与尸阴宗八王随后冲入。
- 灭神矛撞上漩涡，惊天之力撕入其内：
  - **炎雷子**：喷血、双腿爆开化作血雾、元神被冲击不稳；一度欲弃肉身自爆保元神逃遁，被黑衣老人一把抓住带走。其对拓森之恨“仅次于当年的**重玄子**”。
  - **尸阴宗八王**：出漩涡后肉身尽碎，化作八道阴寒之气；余波下五道当场崩溃；剩三人取出棺材夺占肉身逃遁，肉身反复崩溃，又死一人；不足千丈之路如末日。
  - 最后二王绝望之际，身侧黑气波纹中伸出两只手臂将其拽入漩涡，二人狂喜呼“**主尊**”；漩涡内传出受伤闷哼但终究挺住，随漩涡消失。

## 六、尾声：本尊的抉择
- 朱雀星外**月星**一座极寻常山峰内，王林（本尊）睁眼，一瞬恍惚后起身：挥手收**银衣女尸**入储物裂缝、毁去地面阵法、缩地成寸离去。
- 出现在极遥远星空后不停歇疾驰，面色苍白阴沉，从未畏惧的他心神颤抖，脑中反复回响“第一颗古神之星，我为你留着”。
- 自评实力差距：“面对拓森，即便本尊度过了**三损七劫**，即便有**三叉戟**在手，也不是其一拳之敌。”
- 决断：**联盟星域不可再留，必须尽快离开且永远不要回来**，除非拥有对抗拓森之力。
- 去处：去四圣宗见青龙圣皇之前，为自己预留后路的一颗**偏僻废弃星**（其上已布阵法）。

## 七、可追踪的伏笔
- 拓森集齐古神星的进程：前三星已成 → 第四星（无极子）将成 → 第五星（目标鲁夫子）未成 → 已点名王林为“第一颗古神之星”。
- 第三星内“眉心月牙印记”的骷髅修士身份未明，实力可扭曲天地规则。
- 无极子与鲁夫子之间存在“当年的约定”。
- 尸阴宗二王口中的“主尊”出手救人，身份未明。
- 王林此前借涂司记忆对拓森已有一丝了解，但亲见与记忆不同。
