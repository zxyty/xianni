# 第1595章 炼魂宗的因

## 一、赵国科考制度与旅途
- 赵国科考分三级：先在祖籍所在的**四十九个县城**取得功名成为**秀才**；再赴**苏城**第二次科考，脱颖而出者称**苏举**；苏举须在规定时间内前往**赵国京都**，或一飞冲天，或黯然离去。
- **苏城**得名于赵国大儒**苏道**，因其存在，苏城近年成为赵国**文墨之都**。
- 王林带着父母的期望踏上官道，身后跟着换了干净衣衫、背竹排书箱、哼小曲的中年男子——王林为其取名「**大福**」，大福苦着脸表示不喜欢这个名字。
- 天阴无雨但官道泥泞，原本大半天的路程走到日落黄昏方见县城，夕阳橘光笼罩城池，透出「古道尽头黄昏落」之感。

## 二、投宿县城
- 县城内书生云集，王林与大福连走四五间客栈皆无空房；最后一间尚有一间高价空房，天色将雨，王林咬牙让大福取银。
- 大福掏银时肉痛喃喃：「银子可不多了…我以前好像经历过什么事情，知晓银两非常非常重要」——暗示其失落的前尘记忆。
- 伙计轻蔑相待，王林性格淳朴不以为意。客房不大、被褥潮霉，王林辗转难眠，起身就着油灯读书。

## 三、雷夜·白色飞鸟·因果之问
- 窗外雷霆轰鸣、闪电交错、狂风暴雨骤起，窗户被大力推开、烛火熄灭。
- 闪电强光照亮半座城池的一瞬，王林**再次看到一路上梦中与途中反复出现的白色飞鸟**，飞鸟盘旋回旋，低头与王林目光凝聚。
- 飞鸟化白芒落于窗上，与王林长久对视。王林脑中轰然，一个沧桑迷茫的声音在脑海回荡：「**因果…何为因果…因果，是什么**」。
- 王林喃喃：「是你，在和我说话么」「因果，是什么」；飞鸟深深看他一眼，飞起盘旋数圈，一声嘶鸣冲入乌云消失。

## 四、一指止雷·惊动赵国
- 雷霆扰其思绪，王林**下意识右手一指**：右目内闪过一道**闪电印记**，天空雷霆戛然而止，仿佛有一股**超越雷霆、如天地之雷君王的意志**号令无尽雷霆退去。
- 效果不止一城：**整个赵国的阴雨在这一瞬间全部停滞**——雷霆崩溃、闪电瓦解、乌云消散、风雨倒卷。
- 各方反应：
  - **恒岳派**修士王卓、徐飞、周蕊等人在空中心神齐震；同行一老者回头惊呼「这股气息…天啊，这是什么修为」。
  - 另一方向两道长虹消散，露出一男一女，女子正是**柳眉**，面色苍白、眼露迷茫；其身边男子神色大变险些惊呼。
  - **藤家城**老祖元婴老怪**藤化元**打坐中猛然睁眼，惊恐、心惊肉跳。
  - **恒岳山顶**黄袍老者**黄龙真人**掐算，右手猛颤、鲜血自指甲缝泌出，眼露古怪：「这…这怎么可能」。

## 五、炼魂宗的因（章名对应）
- 同一刻，远在**朱雀星·朱雀国**内，有一强大宗派——**炼魂宗**，其一宗之力足以横扫五级修真国。
- 山门**阴魂弥漫，呼啸如鬼神哀嚎，卷动天地，远看如一张巨大的幡**（呼应炼魂宗至宝十亿尊魂幡）。
- 阴魂弥漫的天空上盘膝坐着一名中年男子，他是**遁天的师兄**。其自语：「算不出来…老夫这一生算了三十七次，每次都没有成功，莫非我炼魂宗真的没有希望了么」。

## 六、要点与伏笔
- 「因果」母题在幻境书生线中被正面提出，成为本卷核心追问。
- 白色飞鸟贯穿梦境与现实，疑为引导者/因果象征。
- 王林纵在凡人幻境中失忆为书生，本能一指仍具号令雷霆之威（右目闪电印记，呼应其雷道成就）。
- 炼魂宗一脉（遁天师兄）三十七次推算皆败，暗示炼魂宗之「因」落于王林身上。
