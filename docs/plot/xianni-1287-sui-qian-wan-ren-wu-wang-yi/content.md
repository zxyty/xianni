# 第九卷 云海之巅 第1287章 虽千万人吾往矣！

> 归属提示：依《世界状态须知》，本章王林自第1063章起在云海星域以归元宗故人「吕子浩」之名行事（身份由吕烟菲奉上）。文中「白衣老妪／白发老妪」为同一人。

## 一、四个字：我去救她

- 白发老妪把李倩梅的十年付出和盘托出——字字如雷、如泪、如血，在王林心神中刻下血色烙印，这血无煞，只有悲与温。
- 王林呆立原地，剧痛自心、自血、自灵魂而来。回忆涌现：
  - 李倩梅当年离别前的「你答应过，要送我的」——她所求不过一次相送、一个离别的微笑、一份祝福、一个不要忘记她的约定。
  - 无极宗时的「如果有一天，我不在了，你会记得曾经在你的人生中，有一个叫做李倩梅的女子，匆匆而过么」「如果有一天，我再也没有回来……希望你，可以记得」。
- 叙事定位：李倩梅从不与李慕婉争，也从未奢求取代；她没有李慕婉数百年的等待与孤独，也没有柳眉那种撕开王林心的极端方式，却以让王林无法偿还的十年，让他心中起痛。
- 她本不愿说出——只因白发老妪明言「若让她送来魂血，必须要知晓一切」，加上老妪的详细逼问与见到李倩梅憔悴容颜，真相才被揭开。
- 王林的回应只有四个字：**「我去救她」**。这是决心、坚定、不畏万死。

## 二、被抛下的两重代价

1. **界外之险**：那战场裂缝很可能与界外相连，而拓森就在界外；一旦踏入界外，极可能被拓森察觉，面临危机。
2. **修行之急**：他此刻最需要的是时间与长久闭关打坐，提升道境内的感悟，以求达到堪比登天的**第三步**。

二者皆被抛在脑后——不去想，不去思，只知若不去救，一生难以心安。

## 三、老妪给出的最快路线（星域传送阵链）

| 段落 | 说明 |
| --- | --- |
| 三阶星域以下 | 没有传送阵 |
| 四阶星域·海魂宗 | 有去往**六阶星域**的阵法 |
| 六阶星域·仙音门（无极宗分宗） | 距六阶传送阵最近，可直达**八阶星域无极宗** |
| 八阶星域·无极宗 | 有传送阵，可最快去**九阶星域** |
| 九阶星域 | 抵达后老妪才会告知**妖宗**所在之处 |

难点：开启传送阵所需**元晶**过多，老妪身上不够；且各宗传送阵非寻常之时，怕是轻易不会借用。

王林对此一言不发。这种沉默形成强大压抑，令老妪心惊胆颤，甚至后悔告诉了他一切——她隐隐觉得，眼前青年在听完之后、说出那四个字之后，**好似从仙，变成了魔**。

## 四、横穿星域：一道劈开二阶星域的裂缝

- 一步迈出，星空轰隆巨响，王林如燃烧的流星呼啸而行，虚空抓着白发老妪同行。
- 老妪震惊于其速度：在星空中几乎形成撕裂，如一把大剑正在撕开星空；她从中感到「虽千万人吾往矣」的气势。
- 王林一头白发飘摇、面色铁青，爆发疯狂气息。二阶星域星雾倒卷不敢接近，其内凶兽立刻避开——它们感到有一尊杀神冲来，阻挡必死。
- 其身影一闪而过后，二阶星域出现一道**几乎把二阶星域一分为二**的巨大裂缝。
- 连续冲出二阶、三阶星域，踏入四阶星域海魂宗所在大陆。

## 五、海魂宗：破阵、索晶、毁阵而去

**海魂宗背景**：八阶星域**寂魂道**之分宗；因寂魂道为八阶最强，海魂宗在四阶星域一向霸道，罕有敢招惹者；宗主有**窥涅大圆满**修为，足以在四阶星域称雄。

经过：

1. 时值黑夜，海魂宗修士与宗主皆在入定，大陆突起轰鸣震动，惊醒全宗。
2. 众人出关即见大陆防护阵法刺目闪烁、轰轰崩溃——如有一双大手撕开阵法，来人踏入大陆。
3. 冷漠如万古寒风之声浩然回荡：**「打开传送阵，拿出所有元晶，否则死」**。现身者为一白发青年，一脸阴沉。
4. 宗主看不出对方修为，欲抱拳开口，目光与之一碰便心神轰鸣、喷血、面色苍白——系其自身太弱、心神不稳自伤，与王林出手无关。
5. 宗主毫不犹豫恭敬照办：亲率长老开启传送阵，并取出全部元晶恭敬献上。他毫不怀疑，稍慢半分对方必定杀人；在他感觉里，来者不像修士，倒像一只带着滔天杀机降临世间的远古凶兽。
6. 阵法即便宗主亲自出手，最快也需**半个时辰**，王林等不了：一步迈出，右手向下轰然一按，整个星空的天地元力疯狂凝聚涌入传送阵，几欲将其撑爆。
7. 以这种严重损坏阵法的方式，传送阵片刻间颤抖着轰然开启；王林踏入，白发老妪紧随，虚空取走海魂宗备好的元晶后一同消失。
8. 二人消失刹那，传送阵咔咔作响、现出数道裂缝，轰然崩溃。
9. 王林声音自虚无传出：**「王某急于离去，毁你阵法，取你元晶，来曰补偿十倍」**。

## 六、要点与伏笔

- 「我去救她」标志王林行事基调再度转向：由求道闭关转为不计代价的救人狂奔，气质近魔。
- 救人路线已明确到九阶星域**妖宗**为终点，但妖宗具体位置被老妪握为筹码（到九阶星域才说）。
- 界外**拓森**的威胁被明确点出，为后续埋雷。
- 王林承诺「来曰补偿十倍」，对海魂宗留下一笔未清的因果。
