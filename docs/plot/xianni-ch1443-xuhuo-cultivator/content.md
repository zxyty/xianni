# 第1443章 虚火修士！！（第九卷 云海之巅）

## 一、雾海疾驰
- 二十多个平台被一股无形之力牵引，以不可理解的方式与速度在雾气中疾驰，速度不弱于一个天人衰劫修士全力展开。
- 王林立于平台，长发被风吹起，自进入古之墓地后便一直观察，未摸清前不愿轻举妄动。
- 下方雾海无边无际、深不可知；王林隐隐感觉雾海内似有一双眼睛，死死盯着包括他在内的一切修士。
- 王林推测：进入古之墓地的修士数量不少，但被分开，其他人或许也如他们一般随平台而行。

## 二、万古封印之地
数个时辰后，前方雾气略有扭曲，平台轰然穿入，天地骤变。王林一行二十五人出现在一处似在万古岁月前被封印于古墓、无数万年无人踏入之地。

- **规模与结构**：范围约数十万丈，四周边缘全是阵阵扭曲的空间撕裂，形成巨大困牢将此地完全封死；王林等人的平台正是自其中一处空间撕裂闯入。
- **天地异象**：天为赤色，地面是真正的大地而非雾气，其上有一条条河流，河水尽是鲜红血液，血腥气弥漫。

### 中心三尊跪像
| 对象 | 体量 | 状态 |
| --- | --- | --- |
| 古神 | 约数千丈 | 单膝跪地，神色狰狞，眉心一个大洞血流不尽；膝盖崩溃露出漆黑骨头——不知多少年前他不想跪，却被人打碎膝骨不得不跪；背驮千丈大小通体血色的碎石平台 |
| 古魔（单角身影） | 约四百余丈 | 跪于古神右侧，头顶单角，左目残留疯狂与不甘，右目被人生生挖去，血自眼眶流出 |
| 古妖 | 约三百余丈 | 跪于古神左侧，左目空空，右眼残余浓浓恐惧 |

- 古神所驮的血色碎石平台上有无数血雾环绕，看不清深处，隐隐有暴虐的禁制在雾内闪烁，似在封印着什么。
- 「古神驮石，古妖、古魔跪在两旁，似膜拜那碎石一般」——这一幕震撼人心。

## 三、数万人形凶兽
- 大地上密密麻麻不下数万头人形凶兽，有的在血河中吞咽，有的彼此嘶斗，众人一到便齐齐抬头，以红色双眼死死盯住。
- 短暂死寂后数万凶兽同时嘶吼，声浪横扫上空：数名修为不高且带伤者被震得喷血，两人被抛落地面，遭数百上千凶兽扑上撕成血肉。
- 经历此前数千凶兽一战，修士们已知凶兽（生机）的好处，虽被数量所震却不甚畏惧，轰然散开直扑下方。

## 四、群修威胁王林
因王林此前独吞大半凶兽，众修士已生杀机，纷纷放话（皆限其杀兽不过十）：
- **员外袍肥胖修士**（手持算盘）：此地凶兽杀不可过十，否则「灭魂炼神」。
- **干瘦闭目黑袍修士**：多杀一只，今日便死在这里，谁也救不了。
- **紫袍男子**（身后有凶鱼幻化）：若犯众怒便滚出小组自行生死，不滚就让其尸体滚。
- **绿袍脓包老妪**：造化人人可得，再贪便出手杀他。
- **持酒壶中年修士**：讥其贪蠢，「莫非以为自己是三步大能不成」。
- 其余修士亦眼露杀机，已有出手决断；留在平台上的封灭族少女目露喜色，旋即想到王林可怕而喜色熄灭。

## 五、虚火焚天，身份揭晓
- 王林神色平静，眼中寒光一闪，左目有虚火隐隐燃烧；不退反进，一步跨越无尽距离，如流星般超越前方所有修士。
- 不见施展任何神通，仅右手一挥：跃至半空的近千凶兽体内轰然燃起火焰，凄厉惨叫中化作火球尽数死亡，一道道白色生机飞出钻入王林体内。
- 虚火自死亡凶兽体内爆出向四周疯狂扩散，更多凶兽体内同时爆发虚火，热浪滔天。计数递进：一千、三千、八千、一万三……转眼间此地所有凶兽体内皆有虚火汹汹而起。
- 无尽生机被王林元神迅猛吸收，其伤势以无法想象的速度急急恢复，最终**彻底恢复**；凶兽尽数死亡。
- 无数虚火在毁灭凶兽后自四面八方冲入王林**左目**，其左目内燃起一团**九色虚火**。
- 王林转身冷问「谁要杀我」。众修士目瞪口呆，惊呼「虚火修士」「传闻中数万年难得出现一次的虚火修士」，下意识急退数十丈，先前口出狂言者面无血色。
- 始终平静的白衣女子亦在此刻眼露震惊，更有奇异之芒闪烁。

## 六、要点
1. 王林借此地数万凶兽的生机一举将伤势完全治愈，战力恢复。
2. 「虚火修士」之名首次在此群体面前公开，威慑瞬间逆转小组内的杀机与话语权。
3. 古神驮血色碎石平台、古魔古妖跪拜、暴虐禁制封印之物——留下重大伏笔：碎石平台内封印着什么、这三尊为何被打断膝骨而跪。
