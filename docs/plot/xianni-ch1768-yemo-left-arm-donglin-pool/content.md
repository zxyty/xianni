# 第1768章 烨寞左臂

## 一、融合最后一滴道古鲜血后的状态

- 王林伤势恢复，体内如有乾坤之力，似握拳即可轰开虚无；道古之力回荡于五脏六腑、骨血每一寸，元神在震动中获得养分，散发柔和之光，随时可爆发与本源融合后的神通之术。
- 一滴鲜血作用本不强烈，但因是「达到圆满的最后一滴」，效果迥然。
- 眉心与双目的三族星点数量未变（依旧各八颗），但更为凝实，转动之下幽光更浓，如固本培元。
- 关键收获：感应力提升——此前未融合该滴鲜血时毫无发现，融合后才隐隐察觉冰封天地深处有一股若隐若现的呼唤，与当年在云海感受烨寞右臂的感觉相同。

## 二、与女古神的交割

- 王林平伏气息后，匍匐在地的女古神才坐起，目光透出敬畏——方才一瞬王林如同古之三族先祖，令其心神震动。
- 王林抱拳承诺：若能找到**真门**，定会帮她离开这里；并明言「我行事恩怨分明，之前怨消，恩且尚留」。
- 女古神指明呼唤方向为**东临宗后山、东临池所在**，并说明该池是按「主人」（即七彩仙尊）记忆创造，并不具备原有威力，其神色露出迷惑。

## 三、赴东临池：现象与判断

- 冰层寒气缭绕但不阻王林前行，冷意运转修为即散；冰面如镜倒影其身影，**身影后多出一缕模糊扭曲虚影**（王林扫视一眼，神色如常）。
- 半柱香后抵达：高山之后玄冰处处，山后有一处湖泊般的巨大池水，冰封而隐透仙气缭绕。
- 透过半透明冰层，王林看到池内封着一只**巨大的左手**——「烨寞左手」。他来时本猜测是烨寞左眼。
- 心动之处：融合右臂后撕天之术已足以撕开第三步修士的身体；若再融合左臂，**双手同时施展撕天之术**威力可期。

## 四、破冰过程

| 手段 | 结果 |
|---|---|
| 右脚下踏欲入 | 池内轰出反震之力，身晃，无法进入 |
| 右手按压 | 冰面震动出细密裂缝，寒气一散即恢复如常 |
| 血剑劈斩 | 巨响，血剑被震开抛飞，凹陷与裂缝刹那复原 |
| 「道古不灭」五指成爪扣拽 | 千万重残影叠加对抗愈合之力，扣出巴掌大小冰块；持续数个时辰形成凹坑 |

- **核心判断（王林低声自语，似说给自己、又似说给别人）**：此池之冰与烨寞左臂融合，故拥有烨寞的恢复之力，毁坏即瞬息愈合。玄罗在上空听闻后笑了笑，眼中露出古怪。

## 五、池冰的玄妙与东临池本体推断

- 扣出的冰块以火本源之力燃烧亦不能融化半点；其内蕴含一丝与「本源」相似却又不同的奇异力量，稀少且若隐若现。
- 推断：若此地未被冰封，浸泡其中修炼当对本源大有好处；**真正的东临池在仙罡大陆确实存在，功效很可能正是滋养本源**。七彩仙尊修为有限，凭记忆只能创造大概而无法复现其效果，且以自身生机滋养。
- 王林将冰块收入储物空间，不化，如水晶般散发寒气。

## 六、融合烨寞左臂

- 最后一击扣出寒冰后，脚下冰层内露出巴掌大小、一片死灰之色的烨寞左臂皮肤，浓浓道古气息与呼唤直涌心神。
- 王林盘膝而坐，左手按于其上：烨寞左臂散出幽光穿透冰层，**笼罩方圆数万里**后慢慢消散。
- 王林飞出部分神识环绕四周戒备，凭当年吸收右臂的经验驾轻就熟。
- **三天后**：冰层内烨寞左臂缓缓缩小，散开数万里的幽光收缩凝聚，完全回归的刹那，这只左手化作烟丝钻入王林左臂。

## 七、伏笔与待解

- 冰面倒影中王林身后的「模糊扭曲虚影」未作解释。
- 玄罗似能与王林目光交错对望，且对王林的自语反应古怪，其身份与立场存疑。
- 「真门」为王林在此界的目标，亦是兑现对女古神承诺的前提。
- 王林左臂与右臂皆得烨寞之体，双手撕天之术尚未施展。
