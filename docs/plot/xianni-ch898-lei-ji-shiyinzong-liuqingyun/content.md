# 仙逆 第898章 雷吉（第八卷 联盟隐秘）

## 一、重返尸阴宗总部
- 尸阴宗总部一片死寂阴森，王林循记忆穿过一处处溶洞，走向深处。
- 途中经过当年打坐修炼**黄泉升窍诀**之处：昔日洞口已被封死，墙壁小孔仍散寒气，但比当年弱了不少；王林神色惆怅。
- 凡王林行至之处，前方石壁自行裂开、层层崩溃，自动让出通道。文中点明：阴阳虚实修士勉强可为但艰难，**唯有踏入第二步、达到可窥涅、触摸规则边缘的大神通修士**才能如此轻松。

## 二、开棺：巨魔族老祖雷吉
- 最深处的巨大地下溶洞中，悬浮一具**数百丈大小的棺材**，表面平凡，实则层叠禁制、威压强大。
- 棺中传出「救我」之声——王林熟悉。对方认出王林，震骇于「几百年怎么会有这等修为」。
- **三次会面回顾**（雷吉视角）：
  1. 第一次，王林仅**筑基**，雷吉未加理会。
  2. 数百年后第二次，王林已接近**婴变**，为取其血液而来，对求救不予理会；雷吉曾以「甘愿成为坐骑」诱其相救以拖延，因王林过于谨慎而脱困失败，雷吉一直暗怒。
  3. 此次第三次，雷吉已完全看不透王林及其身后两名仆从的修为。
- 王林抬手随意一点，裂缝瞬间弥漫全棺，数百丈棺材崩溃，白雾涌出。
- **雷吉形貌**：庞大男尸，皮肤铁青、光滑如镜面（不同于古神的粗糙裂纹），眉心有一枚时而闪烁的**斧子印记**；周身长满紫青色植物，植物蠕动间其身体反复萎缩、复原，白色阴寒雾气不断散出。
- 雷吉态度全变，不再阴谋诡计，只余哀求：「我雷吉甘愿成为前辈坐骑。」
- 王林判断：紫青藤根部已生入其体内，再过数百年生机将被彻底吸干，沦为尸骸。

## 三、尸阴宗隐秘：完美夺舍
王林问「巨魔族有多少族人被尸阴宗抓住」，雷吉据实以告（实力决定一切）：
- 朱雀星上巨魔族**仅他一人**；但**联盟星域**内，巨魔族历代族人有很大一部分被尸阴宗抓走。
- 尸阴宗看中的是**巨魔族肉身**。难点在于：巨魔族肉身若正常夺舍，**天赋神通会消散**。
- 解法即**紫青藤**——尸阴宗寻到的奇异植物，只损耗生机、不影响天赋神通，从而实现**保留天赋神通的完美夺舍**。

王林由此明悟（尸阴宗经营链条）：
- 尸阴宗一向**以贩卖肉身为主**；世间最好的肉身是**古神**，但古神肉身太少，遂退而求其次盯上巨魔族。
- 「若一个**窥涅**修士拥有这样强度的肉身、且神通不损、还有天赋神通，即便是我，与之战斗也绝没有十足把握，**除非是与本尊合体**。」
- 王林尚不确定此事在尸阴宗内是否属重点隐秘；随**罗天修士大军**逼近，他相信尸阴宗全部秘密终将展露。

## 四、战紫青藤与怨殿副殿主刘青云
- 王林右手一抓抽出藤条，藤条聚成一株数十丈的狰狞植物：头部花朵内密排利刺、大量粘液，触手四出，一部分连着雷吉。其内**有神识存在**。
- 雷吉揭破：紫青藤内是一位**尸阴宗怨殿副殿主的神识**，自己的肉身正是为该副殿主准备。
- **王林出手**：
  - 张口吐出**封仙印**，瞬间放大，数十万金色符文飞出封印，本印轰然砸落；
  - 右手聚天地雷力成**紫色雷球**送出，二击之下植物多处破损，雷吉被抛落地面。
- 藤中黑袍虚影现身（弥漫黑雾），窥涅气息横扫震开封印金符。王林寒声：「区区窥涅元神，我倒要看看，你如何让王某付出生命的代价。」
- 王林掐诀祭出**子母道枯**（兽骨，双目幽光一闪，四周煞气浓郁、灰光自触手浮现）。黑袍人弃植物飞起，吸尽崩溃植物中的紫青之气，身形凝实。
- 王林双指成剑一点，化出雷霆风暴；黑袍人以圆形黑幕硬扛，溶洞大范围坍塌，其闷哼后退。
- 黑袍人自报家门：**老夫刘青云，尸阴宗怨殿副殿主**，改口称误会，愿将巨魔族肉身相赠交个朋友。

## 五、刘青云的判断与绝望
- 他看不透王林三人：
  - **大头童子**：窥涅修为，但身上**看不到半点意境**，体内却有**浓郁仙力**——他惊疑「这仙人？」
  - **塔山**（大汉傀儡）：非窥涅，但已达**阳实巅峰**。
  - 自身肉身已失，纵使肉身尚在，面对三人也必须立刻逃遁。
- 其潜伏逻辑：特意选**半废弃的朱雀星**，偏僻无价值、不引同层次修士注意，本打算安静度过数千年，夺舍成功后回**怨殿**争夺殿主之位；为避人耳目连护法手下都没派来，只暗中操纵。
- 他据此误判：这一定是怨殿内其他几个副殿主的阴谋，重金请人来破坏夺舍并趁其只剩元神时灭掉他。
- 王林心中盘算：「窥涅元神，而且还是虚弱中的窥涅元神——有这元神，我有把握让**塔山**的肉身达到**窥涅**。」

## 六、缩地成寸截杀与谈判
- 刘青云元神涣散化作无数晶光如银河倒卷向上狂逃；王林脚下波纹散开，身影消失——**缩地成寸**。
- 刘青云魂飞魄散，自忖在领悟缩地成寸的修士面前同阶不败、进退有余，与之为敌是噩梦。
- 王林于其前方一步走出，虚空一拍将其元神震回；大头童子痴笑着堵住退路，塔山呼啸赶至。
- 刘青云长叹抱拳求生路，允诺答谢。王林问「怎么答谢」，其一咬牙献出**一具窥涅修士的元神**——那是他的生死对头，多年前被他借尸阴宗之力破掉肉身、取出元神、本准备炼成傀儡，此刻极为肉痛地献出。
- 王林淡淡道「哦？拿来。」刘青云则反问：「若在下拿出后，你仍然不放过刘某？」——本段至此中断。

## 七、要点与伏笔
1. 尸阴宗产业链：贩卖肉身 → 古神肉身稀缺 → 猎取巨魔族 → 紫青藤保神通夺舍。
2. 怨殿内部倾轧：副殿主之间互相提防、争夺殿主之位。
3. 塔山傀儡升级线索：王林欲用窥涅元神把塔山肉身推到窥涅。
4. 大头童子体内「浓郁仙力、无半点意境」，被窥涅老怪疑为仙人。
5. 罗天修士大军逼近，尸阴宗秘密将进一步暴露。
