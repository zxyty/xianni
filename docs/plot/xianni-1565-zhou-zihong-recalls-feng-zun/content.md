# 第1565章 她是周紫虹

## 一、客栈：周紫虹追述「封尊」往事

某坊市修真星的客栈内，一名紫衣女子（后点明名为**周紫虹**，旁有粉衣女子师妹）向满堂修士追述关于**封尊**的旧事，众修士纷纷聆听、上前神往，中年文士亦感叹「朱雀星，封尊的故乡」。

所述内容（皆为对王林早年经历的回忆）：

- **朱雀星当年**：只是一个半废弃的修真星，火焚国修为最高者仅**元婴**。
- **周紫虹出身**：火焚国之修。火焚国遭遇剧变后众人欲入**宣武国**避难，宣武国不允，两个修真国因此爆发交战。
- **「马良」之名**：她称当年那人名为马良，「或许他真的是封尊」；彼时尚是**筑基**修士便已崭露头角，据说**死在其手中的同阶修士上百**。此语引发满堂哗然——众修士议论筑基可施展的神通法宝极为有限，斩杀同阶上百近乎不可能，遂更叹服「难怪云海之战中封尊可以逆转乾坤」。
- **最后一面**：交战之中此人便没了消息，她记得那应是他准备离开火焚国前，两人曾见过一面。
- **修魔海**：后来隐隐听说他救下了**李慕婉**，在一名**结丹修士**追杀下，逃入朱雀星极危险之地——**修魔海**。
- **赵国血案**：数百年后听人说起，朱雀星有一名叫**王林**的修士一鸣惊人；其本为**赵国**之修，早年筑基时招惹一名**藤姓元婴修士**，被其灭杀满门。此后他回赵国复仇，藤姓元婴修士全家老小尽死、无一活口，凡拥有**藤家血脉**者皆亡，「传闻中那时赵国的天空是血色的」。
- **未称星主**：他本有机会成为朱雀星之主，最终仍选择离去；朱雀星上立有他的**雕像**守护在那里。

**众修反应**：多数称快「这才叫报仇雪恨」；亦有人对灭其满门隐隐不赞同，随即被驳「你非封尊，岂能体会那种亲人全部死亡的绝望」。有修士扬言当年追杀封尊的结丹修士若还活着，「即便封尊不屑理会，老夫也要将他炼魂灭杀」，并称「他招惹了封尊，便是招惹了我界内四大星域所有道友」；有人追问那孽修姓名，周紫虹答「忘记了」。

## 二、王林现身与旁听

- **来由**：王林处理完**召河七彩界**的事情后，正欲前往**朱雀星祭奠父母**，并打算在那里**炼化因果、生死、真假三大本源**；途经此地时感受到**十三**与其**古妖分身**的气息，遂前来。
- **师徒重逢**：掀帘而入的白衣青年即王林。他虚空一按，将激动欲跪拜的黑衣修士（十三）按回椅上；十三唤「师尊」，脑中一片空白。王林摇头示意其勿开口。
- **王林心境**：见十三已成长至今，神色欣慰，回忆起当年**妖灵之地**初见十三的一幕幕——一千多年过去，其坚毅与忠心如旧；并觉「这孩子，越来越像我早年之时」，十三周身冰冷的气息与自己当年在朱雀星时颇为神似。
- **听故事**：王林饮酒旁听，忆起李慕婉被结丹修士追杀时无助求救的目光；听至赵国血案处沉默不语、眼中有悲哀，十三在旁一杯杯倒满——这是十三第一次听到王林的故事，同样沉默。十三曾愤言那结丹修士若活着必将其炼魂灭杀。
- **离去**：王林一口饮尽杯中酒，抬头远望，「他真的想家了」，想爹娘、想去祭拜、想送上一手土，遂起身离开；十三留下几枚灵石随之而去。

## 三、周紫虹的相认（未相认）

周紫虹正说到朱雀星雕像时忽有所察，转身望向门口，目光掠过十三、停在王林背影上，心道「此人，有些熟悉」。王林在门旁掀帘回头，与其对视，微微一笑、轻轻摇头后走出。

周紫虹身子一震、愣在原地，心神震动，那笑容与记忆中之人越来越重叠——「是他」。师妹推问，她只答「没什么」。**紫衣女子，她的名字，叫做周紫虹。**她将散落青丝挽于耳后，沉默片刻，嘴角浮起惆怅的微笑，继续讲述记忆中的故事。

## 四、山巅：王林放十三独行

地点：该坊市修真星一处至高山峰之巅，山风呼啸。十三单膝跪地，请「愿常伴左右」。

王林之言（要点）：

1. 十三是他收的**第一个弟子**，也是跟随时间最长的；对这个弟子他用心最多、情感也放得最多（王林如师如父）。
2. 「稚鸟若要成长，便需独自面对风雨」，要在风雨下成为踏在云端之上的天鹏——此前十三做得很好。
3. 「我王林的弟子，不能是那种在我庇护下只能望天之修」，要有**逆天而行之心**、战天撼地的坚定与决心；要如人中之龙、遨游九天，在万修敬仰下说出「他是我王林首徒」。
4. 「若是有人欺负你，那么为师也绝不允许」——自今日起，十三以**王林首徒**之名，去展开属于自己的道路。

王林说罢右手在十三头顶一拍。十三神色激动，重重点头。
