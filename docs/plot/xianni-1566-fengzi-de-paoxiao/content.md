# 仙逆 第1566章 疯子的咆哮

## 一、别十三：本源之种

- 王林与十三于山峰之上分别。一掌落下，无形波纹以二人与山峰为中心倒卷四方，轰鸣回荡，卷动天地成浩荡之威。
- 这一掌，王林把自己对**火**与**雷**的本源感悟，化作一颗**种子**深埋进十三魂中。
  - 「我不送你法宝，只送你这一颗本源之种。」
  - 十三脑海内凝聚出一颗**金色种子**，蕴含王林对火、对雷的大威感悟，是**属于第三步的气息**。
  - 其色为金，是因种子内蕴含了王林的**血脉仙力**。
  - 此种子足以堪比天地至宝，珍贵程度甚至能引起一场浩劫——王林把它给了自己的**第一个弟子**十三。
- 临别赠言：
  > 想做什么，就去做。只要你认为对得起自己的心，那么即便你闯下天大之祸，也有为师。你应该去找一个喜欢的女子，不要如我一样。
- 王林从十三身上**取走古妖雕像**，转身向天空迈步、渐渐消散；在完全无影的瞬间似回过头，带着如看子一般的目光向下方的十三轻轻点头。
- 十三咬唇落泪，望着师尊远去，跪地**磕了九个头**。

## 二、独行星空：古妖雕像与旧诺

- 王林独自走在星空中——独自来，也独自离去。**两千多年**的岁月，他已习惯这份孤独。
- **古妖雕像**：没有立刻吸入左目，而是收入储物空间。
  - 理由：眼下他还能维持那**排斥之力**的爆发，唯有最关键时刻吸收，才能让雕像发挥作用；能不吸，王林不愿吸。
  - 他想等这个古妖雕像**再成长一些**。
- **罗天所擒古妖**：当年在罗天抓到的那头古妖，仍封印在储物空间内，未到使用之时。王林当年曾答应给它**一线生机**，此事没有忘。
- 赶路方式：看似缓慢，实则每一步迈出都是无尽距离，与**缩地成寸**融入天地无异。
- **雨仙界**：王林没有去——不是不想，而是时间不够。从那隐藏起来的**雨仙界大门**走过，回头看了一眼，转身离去。他要先去把**疯子**接回。

## 三、昆虚星域边缘：疯子与两个骗子

### 场景

- 地点：**昆虚星域**另一边缘的空旷处，一颗**丁级修真星**（并非朱雀星），四周环绕些许小星，安静少人至。
- 星上一座凡间小城，正值秋天，街道萧条，行人稀少，残叶随秋风沙沙划过。

### 疯子的咆哮

- 疯子自称「**本王**」，大摇大摆行走，身后跟着阿谀谄笑的**许立国**与**刘金彪**。
- 一片秋叶糊脸，疯子拍下摔地，跳起连踩十余息，低声咆哮：「小小树叶，也敢来打本王的主意……看本王如何收拾你」，直至叶被风吹走方罢休。

### 二人合谋算计

- 许立国传音疑心疯子话中有话；刘金彪断言「此人是真的疯，他绝不会看出」，许立国深信其判断。
- 这些日子二人合谋算计疯子，**捞到了不少好处**。
- 许立国以「找到一个让王爷满意的小娘子」为饵：
  - 疯子未待其说完便**咬破右手、以血擦在许立国身上**充作报酬；许立国兴奋收起，刘金彪也双眼一亮、舔唇后强作平静。
  - 这一次许下的是「一个修为到了**阳实境界**的修士」，托词是对方「身份高贵、怕人知晓，自然要谨慎一些」，以此解释重重周折。
- 传送阵：城中街尾一家店铺，刘金彪先入、掐诀封死店门；后院有一座**粗糙的、新布不久的传送阵**。
  - 许立国以「阵法要开启，小的身上灵石不多」再骗，疯子不满地又咬破手指挤出鲜血扔给他：「本王的鲜血，可是很宝贵的，当年那谁谁谁……」
  - 刘金彪不知用了什么方法，在疯子未注意时开启传送阵，三人消失。
- **连环传送**：山谷 → 山峰、平原、盆地、岛屿……前后十多处地方陆续有传送之芒闪烁，疯子咆哮一次比一次剧烈：「怎么还有传送阵，本王不玩了」「到底有多少个传送阵……你们欺负人，你们太过分了。」

### 关键转折：「我要告诉我师父」

- 疯子最后一句「**我要告诉我师父**」立刻见效：岛屿传送阵旁，许立国身子一颤，刘金彪眼皮一跳，急急使眼色，似被吓破胆。
  - 二人这些日子已从疯子口中**套出了其拜师之事**。
  - 许立国「几乎忘记了煞星」，连忙改口：「最后一个，这是最后一个，这个不需要灵石，我们上去就可以看到那小娘子了。」

## 四、章末：王林降临

- 与此同时，该修真星外的星空中波纹回荡，**王林身影迈出**，扫了一眼前方修真星，突然眉头一皱、眼中露出寒光：
  > 「胡闹！」

## 五、要点提示

- 本章为王林**了结师徒之缘、收拢旧部**的过渡章：先别首徒十三（赠本源之种），再折向昆虚星域接回疯子。
- 埋线：①雨仙界未入（时间不够）；②古妖雕像待成长后吸收；③罗天所擒古妖的「一线生机」之诺；④疯子的师父身份，将由王林亲自现身揭穿许、刘二人的算计。

## 六、文本校勘

- 原文「吉妖雕像」「吉神」等为「古妖雕像」之误写；「夭大之祸」为「天大之祸」；「殷曰子」为「这些日子」之误；「t级修真星」为「丁级修真星」。
