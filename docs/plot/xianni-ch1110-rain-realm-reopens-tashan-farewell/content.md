# 仙逆 第八卷 联盟隐秘 第1110章 雨界再开！

## 一、震慑许立国，中止祭炼

- 王林正祭炼许立国（此时许立国以大剑之身存在，具剑魂）。许立国因一时冲动竟对王林出手，事后剑身颤抖、内心大骇，自责“竟敢对这煞星出手”。
- 王林一声“闭嘴”，随即宣告：**此番祭炼先告一段落**，视其之后表现而定；**若再逆反，直接抹去其剑魂**。
- 许立国惊慌尽去，转而阿谀奉承（“主子您真是英——”），王林未听完便右手一挥，将大剑送入**心念一动而现的储物裂缝**内。
- 收剑后，王林身子向旁一迈，消失无影。

## 二、塔山辞行

地点：朱雀圣宗辖下一颗修真星。

- 塔山盘膝而坐，身旁数张兽皮，**以鲜血配合体内符文之力刻画符箓**。数年来这是王林第一次与他见面。
- 塔山仍称王林“主人”；王林道其**已恢复神智，不必再称主人**。塔山苦涩答：“当年是主人让我残存至今，此恩，塔山不会忘记。”
- 王林直接问“何时走”。塔山震惊，问何以看出。王林答：**你自来此便一直制作符箓，若非心中有了打算，不会如此。**
- 塔山坦言：**想去罗天见一见族人**。所制符箓除自用外，另为王林备下三张：
  - **速**
  - **崩**
  - **封**
  三张皆以最稀少兽皮制作，所耗心神数倍于寻常符箓。
- 王林接过，叮嘱：“眼下**联盟星域很乱**，你一路小心。”并托付：**“若是在青灵星上看到了我当年收的弟子，代我照顾一二。”**
- 王林转身离去后，塔山跪地向其去向磕头，收起兽皮，飞向星空。

> 情绪线：王林看着这位“往昔自己的仙卫”，心中复杂；塔山面上是苦涩转坚毅。

## 三、司徒南随行的动机

- 此行往**雨之仙界**，目的是**救青龙圣皇**。
- 司徒南（按世界状态须知：即自第336章起自称“司徒南”的司徒南断臂所化人影）**体内毒素尚未完全逼出**，无解药始终是麻烦，故必随行。
- 不待王林去找，司徒南已自行来到**三十五个四圣宗长老**所在之处，站在**这些年为他驱毒的那位长老**身后，盘膝而坐，神色严肃。
- 其心中打算：若毒素得解，**定要拉王林同去凤栾星复仇**，把这些年所受痛苦“十倍百倍”从凤栾星那群女修身上讨回。

## 四、蛮荒星拜访云仙道侣

- 设定：朱雀圣宗范围内有**不适合修士存在的蛮荒星**，星上**充满有毒之气**，毒气在火焰燃烧下威力极大。
- 王林所至之星：无半点植物、生灵几乎断绝，唯一片**黑色荒漠**散发浓浓高温；黑漠并非一马平川，而是**如山峰般起伏、更有山涧**。踩上去可感毒气融入热浪弥漫而来。
- 王林立于一处山涧之上，涧内一片漆黑，唯有热浪掀起，吹动其**白发**。
- 王林朗声抱拳：**“王林拜见云仙道侣二位前辈”**。
- 话音方落，涧内射出一道剑芒直奔王林；王林不退反笑，剑芒化作人影——**周佚**：中年模样、相貌英俊、**面色苍白**。
- 周佚道：“两位前辈已知晓你来，随我下去吧。”二人相视一笑，王林迈步进入山涧，直奔下方。

# 第1025章前后 · 雨之仙界大门开启

## 一、山涧底部：说服王巍与胡娟

### 下行途中
- 山涧极深，一路热浪扑面。王林不以为意；周佚神色如常，自言初来时不适，如今已无碍。
- 周佚试探问王林此行是否为救**青龙圣皇**。
- 王林摇头补充：**除救青龙圣皇外，还有仙帝青霖之事——只有青霖苏醒，青霜仙君才有复活之机**。周佚闻言激动道谢。
- 周佚黯然自陈：“你与我，很像。只是我有你来帮助，你却没有帮助之人。周大哥无能，帮不上你。”王林沉默不语。

### 世外桃源
- 山涧底部被人以大神通之术**逆转乾坤**，隔开高温毒气，开辟出世外桃源：一条小河（下游流向不明）、河边几间木屋、一片青草与几簇花。
- **王巍**盘膝坐于河边，含笑望着对岸爱侣**胡娟**；胡娟如孩童般双脚戏水。
- 王林与周佚劈开隔热壁障后，王林恭敬抱拳自称“晚辈王林”。

### 偷袭烈云子的旧账
- 王巍开口便索要“让我去偷袭那烈云子”的原因，否则不轻饶。
- 胡娟笑言王巍很在意此事，觉得以其身份偷袭一个晚辈很丢人。
- 王林略作解释，王巍便不再追问。王林心知二人自**妖灵之地一战**后已不把他当外人，偷袭之事王巍恐怕并不很在意。

### 三个词与雨界尊殿
- 王林回忆：当年在妖灵之地，曾听**仙帝青霖**说出三个词——**雨界尊殿、元神结晶、青霜之血**。后两样王林都已拥有，唯独缺“雨界尊殿”。
- 王巍严肃确认：这几年回忆当年雨仙界，**确有尊殿，那是当年其师尊成帝之处**，此前已告知王林。
- 王林轻叹说出**朱雀老圣皇取来雨晶**之事，王巍与胡娟动容；胡娟起身穿鞋走到王巍身边。
- 二人对视后表态：**“朱雀圣皇之恩，我伉俪二人铭记在心，那青龙圣皇若真在雨界，我二人可帮助营救”**，以报答朱雀圣皇取雨晶之惠。
- 四人（王林、周佚、王巍、胡娟）随即离开，直奔星空。**青霖的肉身留存于王巍处**。

## 二、朱雀圣宗主星：开启雨界大门

### 开阵流程（自下而上的元力汇聚）
1. 四道长虹落于阵法之上，化作王林一行。
2. 王林踏入正中阵法盘膝而坐，双目精光一闪低喝“开阵”，右手虚空一抓撕开裂缝，取出**仙气缭绕的元神结晶**。
3. 外围**数万四圣宗弟子**闭目将修为涌入身下阵法，阵法亮起。
4. 亮光顺阵法连接汇聚至**三十五名（碎涅）长老**身下阵法；长老同时掐诀，将数万弟子的元力**融合为三十五份**，齐涌向中央的王林与结晶。
5. 结晶爆发至强晶光，弥漫不可思议的仙力，化光柱冲入云霄，波纹层层扩散。
6. 天空轰隆，**雨界大门在朱雀圣宗主星上空缓缓打开**。

### 连锁反应
- 整个**联盟星域**内修为达到一定程度者皆感受到星空波动，熟悉者一眼可辨：**雨之仙界，开启**。
- 联盟星域各个角落**自然幻化出一个个雨之仙鼎**。
- **罗天、尸阴宗及联盟各势力的重点已放在朱雀星上**，虽震惊于雨界突开，却无暇分神前往。

### 入界
- 王林留话：**“我等修为前往雨界，会使得雨界处于不稳之中，引起大范围的崩溃，此番营救青龙圣皇，必须要快。”**
- 王林化长虹先行，其后三十五名碎涅长老、司徒南（自第336章起自称司徒南者）、王巍、胡娟等随之而入。
- **另有一人连王林都无暇察觉——银衣女尸化作银光冲入雨界。**

## 三、暗线：天运子现身

- 同一时间，**联盟星域北部一处偏远蛮荒星**大地震动，成十字形裂开。
- 一名白发遮面的老者自裂缝飘起，身前晶光闪烁，**幻化出一个雨鼎**。
- 老者放言：**“王林，你逃不出老夫的计算。”** 风吹开乱发，露出相貌，**正是天运子**。

## 四、要点归纳

- 复活青霜仙君的链条：**唤醒青霖 → 青霜仙君才有复活机会**；而唤醒青霖需集齐**雨界尊殿 + 元神结晶 + 青霜之血**三项，前者的线索指向雨仙界中王巍师尊成帝之处的尊殿。
- 开界代价：需数万弟子 + 三十五名碎涅长老 + 元神结晶合力，且高修为者入界会致雨界不稳，营救有强时限压力。
- 悬念：银衣女尸的潜入未被察觉；天运子手持雨鼎、宣称一切在其计算之中——雨界之行已被预先算计。
