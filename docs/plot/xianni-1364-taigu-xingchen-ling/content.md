# 第九卷 云海之巅 第1364章 太古星辰令

## 一、场景：凡人城池的暴雨
- 修真星某都城暴雨倾盆，乌云遮天、雷霆咆哮；行人披蓑衣劳作，孩童爬窗嬉戏。
- 文中明点：**「这雨，因王林而来」**——异象源于王林体内雷之本源的炼化。
- 王林推门观雨、饮酒，见孩童触雨而起追忆：他幼时也曾在**朱雀星**家中爬窗接雨。
- 自语：「不知不觉，已经快两千年了吧修道者不闻岁月流逝真正能记住自己年纪者，不多我现在，已经记不起具体的年纪了。」

## 二、云上传讯：太古星辰令下
乌云之上，两道剑光——蓝衫英俊男子（修为隐隐**窥涅**）与彩衣女子**月萱**，因族中长老发出罕见的紧急召集而赶路。黑衣**周姓青年**驾黑风截住，冷声告知：

1. **闪雷族被灭全族，其大长老败亡失踪**，此事已被**长尊会**证实。
2. 长尊会发布**太古星辰令**，告知所有族落；各族紧急召集即为宣布长尊会封命。
3. 长尊会**大司云落**以推衍天地星辰之术，算出**灭闪雷族、杀其大长老之元凶的画像与神识印记**，分散开来，展开**太古万灵封杀**。
4. 事关重大，各族修士恐将外出搜寻，**连这颗修真星也要仔细搜索**；长尊会另派长老出动。
5. 封命明言：**闪雷族的不灭雷霆，已被那人吞噬**。

蓝衫男子与月萱震惊质疑：闪雷族大长老传闻修为已至**天人第五衰**，除**第三步大能**无人可灭；闪雷族数十万人、高手众多，且有万古以来存在的**不灭雷霆**，如何能被灭族。

## 三、王林的应对：炼化最后一条太古雷龙
- 王林收目关门盘坐，判断：「这么快就发现了长尊会看来我的时间不多了，要尽快炼化最后一条雷龙，再融合那不灭之雷。」
- 融入元神，以滔天火焰炼化最后一条太古雷龙；历大半天，雷龙惨叫崩溃、被元神吸收。
- **八条太古雷龙至此全部融合**，成为自身一部分：
  - 元神疯狂增长，其内**火焰消散，代之以无尽雷霆**；
  - 体内**五道本源**中的**雷之本源**疯狂膨胀壮大；
  - 元神形态由雷龙变为**一道连接天地的闪电**——「那天，就是王林的头；那地，就是王林的脚」，与闪雷族不灭雷霆一样**万古不灭**。
- 元神闪电成形刹那，外界云层雷霆发狂咆哮，整颗修真星皆闻。

## 四、修真星上的旁观者
### 都城东处·皇城阁楼
- 数名道袍老者，皆有相当于**净涅**的修为；另有一满头白发者已达**碎涅**。
- 众人观云听雷，觉此雨来得突然、雷霆过于剧烈，**联手神识横扫却未发现任何端倪**。
- 碎涅老者联想闪雷族灭族、大长老遭毒手之事，直言「总有心惊肉跳之感」，又自疑多心。
- 众人共识：太古星辰令下，此人只要被发现行踪，**必死无疑**。

### 修真星东部·真言族山门
- 东部连绵山脉为**真言族**山门；真言族为**小族**，占据一颗修真星，地位如界内宗派。
- 山峰顶一白发沧老者远望长叹：「为何总有一种要大祸临头的感觉」（大祸将至的伏笔）。

## 五、收束：融合不灭雷霆，「道术融」
- 王林知时间紧迫，放出封印于体内的**不灭雷霆**；不灭雷霆刚现即欲挣脱。
- 王林已成闪电之元神轰然迎上，直接展开**吞噬**。
- 不灭雷霆内蕴含**如修士神识般的意志**，剧烈挣扎，与王林在吞噬与挣扎中厮杀。
- 王林之意：「与我融合，成为我元神之物，让我**雷道本源大成**，在**伴随之雷**下，**破开苍穹**，修为增强。」神识如风暴撕裂其一切抵抗。
- **「道术融」**——王林双目猛睁，**右目瞳孔内两道不同的闪电本源印记急速旋转**，神情妖异。

## 六、要点与伏笔
- 王林已成全太古通缉对象：画像 + 神识印记双重通缉，藏身难度陡增（他此时正以本体在凡间修真星潜修）。
- 「不灭雷霆被吞噬」已成长尊会公开定性，等于坐实凶手身份特征。
- 真言族老者的不祥预感，与王林恰藏身此星，构成明显的祸至伏笔。
- 修为线索：八雷龙融合 → 元神化万古不灭之闪电 → 雷之本源大成 → 图谋「破开苍穹」。
