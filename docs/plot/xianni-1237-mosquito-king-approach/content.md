# 第九卷 云海之巅 第1237章 逼近（第一更）

## 一、王林的蚊兽王闯入陌生蚊群

- 王林元神凝聚的**规则之星**附着于一只蓝色蚊兽（蚊兽王）体内，可远程降下威压、引动**天地之力**，并以神念下令；本章多处它甚至在王林神念传出前自行抢攻。
- 蚊兽王飞向山脉：外围**赤红色蚊兽**因等阶差距齐齐让路；山脉附近数百**蓝色蚊兽**认出它非本族，敌意大盛。
- 四只蓝色蚊兽先后扑杀：
  1. 第一只被规则之星威压定身瞬间，口器贯体，精华血液被吸干，转眼化作骸骨。
  2. 其余三只连续被撞飞、穿透、吸干。电光火石间四只同阶蓝蚊尽死。
- 蚊兽王悬于半空，凶焰弥漫，隐露挑战数百蓝蚊之姿。

## 二、旁观者：寂魂道长老宋洛海

- 身份：**寂魂道长老**，修为仅**碎涅中期**，在长老中属末流。
- 抉择：八界星域盛典期间**未参与**，独自藏于此山脉下山石后，收敛全身气息。
- 目的：**抓获一只蚊兽王**，以验证心中的某个猜测。自评难度极高——穿越蚊群、潜入王座之地、必须一击成擒，稍有意外即惊动全群，届时自问难以生还。
- 进度：三个月前锁定此片蚊群，判断其中必有蚊兽王；用三个月不惊动红蓝蚊兽潜行至此。
- 变数：**半个月前两只白色蚊兽**飞来，气息威压**堪比碎涅**（他平生只见过一次此种白蚊）。他感觉对方隐隐察觉自己存在但未定位，遂半个月一动不敢动，内心苦涩绝望。
- 动机（利益盘算）：验证成功则名震整个**八阶星域**，修为更高的老怪也要退避；甚至可能得到**九阶星域**青睐。
- 转机：目睹陌生蓝蚊瞬息吸干四只同阶，心神震动，隐隐觉得「自己的机会来了」，并对随后现身的紫色蚊王闪过**贪婪之色**。

## 三、蚊兽王 vs 白色蚊兽

| 回合 | 经过 |
|---|---|
| 1 | 白蚊化白光冲入蓝蚊群（蓝蚊纷纷避让），直撞蚊兽王，蚊兽王退后数十丈 |
| 2 | 蚊兽王引动**天地之力**笼罩全身反撞，白蚊颤抖倒卷而退；四周数百蓝蚊被惊动，环绕死盯 |
| 3 | 白蚊倒钩须发瞬息延长、遍布全身如长毛，胀大冲杀；双方短时间内数十次撞击 |
| 4 | 白蚊多处破损流血倒退；蚊兽王虽萎靡，凶焰更浓，抢先扑出 |
| 5 | 白蚊须发**整体脱落**，如万剑呼啸、蕴含破天神通齐射 |
| 6 | **蚊兽王当场学习模仿**：蓝光暴闪中倒钩须发疯长至数十丈，同样断开如雨射出，两片须发之雨对撞 |
| 7 | 蚊兽王冲出撞击中心，如癫狂般连撞，口器不断寻隙刺向白蚊体内；白蚊急退 |

- 关键设定：蚊兽王**尚处于生长之中**，一生与同族极少厮杀，故在战斗中「仿若在学习」，能即时复制对手神通。

## 四、蚊王现身（本章收束）

- 白蚊急退之际，山脉内轰出一股极强气息，内含**蚊兽间的威压**，仿佛所有蚊兽都须屈从。
- 另一只白色蚊兽飞起嘶鸣，整座山脉轰轰颤抖，一道巨大裂缝自山脉顶部延伸至底部，山脉如被生生掰开。
- 裂缝中闪出**紫芒**，弥漫沧桑气息，涌出浓郁**紫色雾气**；雾气骤缩，缓缓飞出一只**百丈大小、通体紫色、须发凌乱狰狞的蚊兽**——**蚊王**。
- 其一出现，赤红、蓝色蚊兽全部安静。
- 蚊王目光横扫，随意看了一眼宋洛海藏身处，最终落在**王林的蚊兽**身上，许久，传出一声低嘶。（本章至此中断）

## 五、悬念与看点

- 蚊王是否已察觉宋洛海？其「随意一眼」暗示其感知远超两只白蚊。
- 蚊王锁定王林的蚊兽——王林的元神附体是否会被识破。
- 宋洛海的「猜测」内容未揭示，是本章埋下的最大伏笔。
- 蚊兽等级序列在本章明确：赤红 < 蓝色 < 白色（堪比碎涅）< 紫色蚊王。
