# 第七卷 名震罗天 第756章 陷阱

## 一、绝境脱身（碎片大陆）

- **第三眼破局**：生死关头，王林眉心第三眼红芒疯狂闪烁，扇形红芒并非扫向虚空，而是扫向**李元**，冲淡了李元身外的凝固之力。
- **破灭心禁**：李元右手按眉心，一条婴儿手臂粗的黑线飞出化作禁制烙印，低喝「破灭心禁」。禁制疯狂胀大后崩溃，化作成千上万道黑线组成奇异图案蔓延，再喝一声「封」向血祖凝聚；血祖血光爆闪闪出，禁制随即自爆，震得四周挤压松懈、整片碎片大陆不稳。
  - 代价：李元面色苍白、事后嘴角流血，需盘膝吐纳；自陈**破灭禁只修至第四层**，是不惜以心禁施展才有此效。
- **踏阵而逃**：挤压松懈之刻，王林抓着李元踏入即将崩溃的传送阵；消失瞬间左手狠拍传送阵，使其崩塌化作晶芒消散——断绝追踪。

## 二、血祖之怒：一脚崩灭一片雷之仙界碎片

- 血祖立于传送阵消失处沉默许久，抬脚**狠踏地面**：巨大裂缝如狂龙蔓延、反复分开，大地布满狰狞裂缝，天空亦现无数空间碎裂。
- 半个时辰后，**天不再是天，地也成为虚无**——雷之仙界永久崩溃了一个碎片。大陆上为数不多的**罗天星域修士**争相逃命，能逃出者不多。
- 崩溃引起漩涡，牵扯**雷光铁链**被拉直，连带各铁链另一端的大陆也被牵动，整个雷之仙界轰隆隆缓缓移动。
- **实力标定**：血祖修为「超过了窥涅期，冲破了雷之仙界的临界点」。
- **动机**：血祖来到雷之仙界后不寻宝、不寻仙术，只以最快速度在一处处碎片大陆游走，每到一处便散开神识横扫一圈即走——**他要的只是自己的女儿**。
- **放话**：「王林小儿，下一次，你跑不掉」，转身一步消失于虚无。

## 三、传送落点：吞噬神识的诡异空间

- 环境：天空低而昏暗、黑压压压迫感极强，时有禁制之光闪过；地面小山起伏成谷；天空弧形裂缝时开时合，散出阴寒并伴尖锐呼啸——**此地唯一的声音**。
- 落点为一处**十丈高褐色祭坛**，台阶破损、裂缝延伸至顶端。
- 王林神识略散即收，判明：**此地空间裂缝会吞噬神识**，神识一散便会把裂缝引出。
  - 反向结论：「虽说如此，但这里倒也安全」。

## 四、与姚惜雪的对峙

- 王林令**仙卫傀儡**为李元护法，隔绝四周，取出禁制光团——**姚惜雪**盘膝其内，被禁锢百多年，颇为憔悴。
- 姚惜雪开口：「我在你的身上，感受到了父亲**血术的残余**，而且，我还感受到了你的**害怕**。」
- 王林的两难被姚惜雪点破并封死：
  1. 放她 → 她只会求父亲**留王林一命**，好让自己亲手报复（目露深恨）。
  2. 杀她 → 「杀我，即是放我」。
  3. 封印 → 面对血祖永久追杀，终有一日血祖找到王林，她一样能脱困。
- 王林结论：「放还是不放，不取决我，而是在**血祖**」——打出数道禁制，光团收缩成光球，重新收入储物袋。

## 五、与李元的交底

- 王林向李元抱拳致歉（以化名**许木**行事，李元称其「许兄」），告知那人**道号血祖**、修为深不可测、与自己有纠隙，劝李元离开此地后先行，以免再受牵连。
- 李元评估血祖：**绝非寻常第二步修士，即便不是碎涅期，也应是净涅修士**，此等修为在罗天星域完全是顶尖存在；并叹「若我破灭禁可达第七层，便有点把握封印此人」。
- 李元态度：不去招惹、只做躲避，倒也不是没有办法；当下先听王林的**寻找出口**。

## 六、重大发现：此地是仙人的储物空间

1. 李元抓起泥土细看、折下树枝入口一舔，眼露异色。
2. 借王林**仙卫傀儡**护身升空（裂缝渐多，仙卫拳击虚空形成漩涡驱散裂缝，几成金色旋风）。
3. 半空远望时，李元露出震惊与不敢置信；下方骤现一道**数倍于常的巨大裂缝**如阴森之口吞来，裂缝激增令仙卫应接不暇。
4. 王林祭出**山河图屏风**化作山河铺展天空，盖住绝大部分裂缝，隔空一把抓回李元；画幕被撕开无数小口受损，收回储物袋。
5. 李元揭晓结论：
   - **仙人很少使用储物袋**，一般自行开辟一片空间；该空间在**仙人死后不会崩溃**，但很难再次开启。
   - 此处泥土、山脉、树木皆**非本地所生，而是自外界移入/收入**。
   - 因岁月久远、加之仙人所辟空间本就不算稳固，才出现裂缝，二人得以进来。

## 七、王林的杀机（章末转折）

- 王林试问：此地若崩溃，是否连同其内一切全部碎灭？
- 李元确认：这里并非外界碎片大陆，一旦崩溃，**庞大的力量瞬间会把其内一切瓦解，不留半点**；「若无外因干扰，此地不会崩……你莫非你」——倒吸口气。
- 王林眼中寒芒一闪：**「如此，或许我可以设置一个对付血祖的陷阱」**。

- 姚惜雪仍在储物袋中，成为诱饵与筹码的双重可能。
- 山河图屏风受损；李元的破灭禁层数（4/7）成为后续变量。
