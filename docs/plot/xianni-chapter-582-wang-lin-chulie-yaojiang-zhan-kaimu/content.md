# 仙逆 第582章 王林出列（1/2 之 1/3）

## 一、场景与开局
- 地点：妖灵之地广场；东方高架上设有帝君之位。
- 三声鼓鸣后余音回荡，**帝君始终未现身**，高架空位空悬，众人瞩目。
- 广场后方宫殿内走出一名**身穿金色铠甲的男子**，低喝「众妖将，出列」。
- 广场正前方的**天妖门**轰然打开，数百妖将鱼贯而出，分列两旁，战意弥漫天地；每名妖将身边**均有修士跟随（即『帮助者』）**。

## 二、在场关键人物
- **王林**：本章以妖将身份走在**莫厉海**旁边出列，抬头看了玄副帅一眼即收回目光，全程沉默观察。
- **玄副帅**：睁开双目凝视王林，眼露愤愤之色，轻哼一声（旧怨未消）。
- **莫厉海**：皱眉看向高架空位，喃喃「奇怪，帝君为何没来」。

## 三、妖将之战规则（金甲男子奉帝君之命宣布）
1. 规矩照旧，**以挑战为规则**。
2. **战败者**有权要求其帮助者出战；**战胜者**也可退避，换其帮助者出战。
3. **两次均胜则胜出**；**若一胜一负，则二人全部取消资格**。
4. 最终胜者，**本轮不可再挑战他人**。
5. 战中**可以出现死亡，但死者只能是帮助者**；**妖将不可死，杀死妖将者，斩**。
6. 竞战之人由**金甲男子点名**；每场留**十息**时间供人主动挑战，无人挑战则由其点名。

### 王林的判断
- 规则看似寻常，实则「蕴含腥风血雨」，关键在**一胜一负双双取消资格**：一旦首场落败即失去资格，落败者唯一能做的就是全力报复、拖战胜者一起出局。
- 结论：「**这不是比试，而是一场厮杀**」；在妖灵之地想获得职位，必须是从血雨中走出之人。他为此冷冷看了金甲男子一眼。

## 四、首战：妖将暮云 vs 妖将石萧

### 出场
- **暮云**（文中亦作「慕云」）被点名出列：身穿铠甲，面容消瘦、双目深凹、脸色蜡黄，站姿如古松。
  - 妖将中可名列**前三十**；修炼**九死九生之气**，三百年前已至**五死五生**之境。
- 第五息时，**石萧**主动走出应战，暮云双目爆出精芒。
  - 石萧相貌**妖异**，修为**可达三甲**（妖将前三），出战被众人视为「欺负人」。
  - 众人本以为石萧的对手该是**莫厉海**：三百年前莫厉海在石萧脸上留下**第一道疤痕**，是石萧此生最大的侮辱。
- 石萧于三十丈外停步，平淡道：「暮云，你不是我的敌手，下去吧。」

### 交手
- 暮云右手虚空一抓，五指间涌出**五道绿气（生死妖气）**，呲呲作响，如五条灵蛇缠指；石萧据此断定其**已突破九死九生诀第七层**，但仍言「还是不够」。
- 绿气延伸暴射，腥风弥漫，四周多名妖将目露惊异。
- 石萧身形未动，食指、中指、无名指连点，继而右手成掌前按，幻化出一道**菱形光图**：
  - 光图**绞碎五道绿气**，化作绿芒消散；
  - 光图旋即以不可思议之速印至暮云身前崩溃，气浪震得暮云**面色苍白、连退数丈**方稳住身形。
- 石萧收手：「我说了，你，还不够。你的帮助者，可以出场了。」

## 五、次战：石萧 vs 巨灵门天魁上人（暮云的帮助者）
- **天魁上人**自妖将阵中走出：身躯硕大、一身横肉重达数百斤、赤着上身，每步震地；自称「你家巨灵门天魁上人」。
- **巨灵门**：天运星上的一个大门派；神通**与巨魔族相似，皆为力降众法**（王林对此有认知）。
- 天魁上人发力：仙力顺汗毛冲出形成**仙雾**裹身，全身藏于雾中高速撞去；同时低吟咒语，令**方圆百丈空间形成一道禁锢**。
- 旁观细节：妖将中一名**身穿青衫、背负大剑的肥胖之人**目光一凝，喃喃「此人现在的样子，倒是与我剑魂有些相似」。
- 石萧应对：身形如扎根不动，右手五指连点虚空、最终成**锥形**刺出，一丝丝**黑色妖力细丝**融于五指之中。
  - 锥势破竹，直接破开仙雾，如怒龙出海按在雾内巨汉**眉心**。
- 结果：天魁上人冲势尽消，轻盈急退，地面碎裂、**连退三步跨过数丈**，血雾狂喷，最后一步身子一颤，**当场崩溃、化作块块血肉散落广场**。

## 六、要点归纳
- 帝君缺席但**战报仍会呈交帝君查看**，故首战获胜者必受重视——这是众人踊跃出战的动因。
- 石萧连胜两场（暮云 + 其帮助者天魁上人），按规则已具备本轮胜出之势且不可再挑战他人。
- 死亡限定在帮助者层面，天魁上人之死正是规则的第一次血证。

## 七、归属说明（据世界状态须知）
- 本章「王林」即主角本人，以妖将身份在妖灵之地行事，无冒名情形。
- 文中「慕云／暮云」为同一人的字面异写，统一归为**暮云**。

# 第583、584章 嚣张的许立国(二合一)——妖将之战片段

## 一、石萧收场与连环挑衅

- 妖将**石萧**战毕,五道黑色细线自地面血肉中飞出、融入其体内(吸取败者血肉之力)。
- 石萧宣称:“妖将之战不诀生死,你们这些外来者,便是陪葬”,随即点名挑战**莫厉海**。
- 莫厉海平淡拒绝:“我败于墨非,此次妖将之战,不会参加”。
- 石萧杀机转向莫厉海身边的**王林**:“你,下来和我玩玩”。王林回绝:“不杀人之战,王某,没兴趣”。
- 主持**金甲男子**裁定:石萧本轮已胜,按规则不可再挑战他人,喝令其退下。
- 石萧擦身而过时低声威胁王林:莫厉海不敢出战,他便杀王林**以泄“当年之愤”**(暗示二人早有旧怨)。

## 二、王林出列与看台评断

- 金甲男子点名王林出列,立于万丈广场中央,宣布“十息内,若无挑战者,由我点名”后闭目。
- 王林一身白衣长发飘逸,神色从容,“仿佛眼前一切只是过眼云烟,他只是一个过客”。
- 四周议论多为轻蔑:说他狂妄却不敢接石萧挑战、外来者不该在妖灵之地猖狂。

### 玄副帅 vs 黄副帅的赌约

| 项 | 内容 |
|---|---|
| 玄副帅判断 | 王林**必可名列三甲,甚至第一也非难事**;声称不认识王林(面色阴沉) |
| 黄副帅质疑 | 此人修士修为只是**婴变后期圆满**,想名列第一不易 |
| 赌注 | 王林未得第一 → 玄副帅输**天兆旗**;王林得第一 → 黄副帅输**玄玄丹** |
| 玄副帅内心 | “此人若是也把你打的重伤,你也会这么肯定”——暗示其本人曾被王林重伤 |

## 三、王林 vs 妖将熬迪

### 熬迪的算计
- 身穿土色铠甲,脚步未动即一晃出现在王林百丈外。
- 自称“承蒙列位同僚照顾,没人和我来抢这个挑战者的身份”:因莫厉海不能出战,**只需战胜其帮助者王林,即等于本轮胜出**,是绝佳便宜。
- 众妖将多作看热闹状,唯**墨非**等数人神色不同,冷冷旁观。
- 熬迪威胁王林认输保命,称即便平手他还有帮助者。王林只回一句:“你,不是我的对手”。

### 交手经过
1. 熬迪以妖力催动**土遁**、配合**本命妖兽**遁地消失。天妖门万丈广场处处禁制,此地崩塌地面难度比外界高十倍以上,他此前观石萧之战时已研究最佳遁行路线。
2. 王林神色不变,右脚向前一踏:大地轰鸣碎裂,波动横扫,**仙气化作利剑**自地缝冲天,如岩浆地狱。熬迪被生生逼出地底,满脸不可思议。
3. 熬迪速退并右手拍向额头(欲发保命/催动之术),王林一步数丈欺近,右手灰芒印记闪烁,一把攥住其右手,如炙热铁钳挣脱不得。
4. 熬迪咬破舌尖喷出血箭,化作虚幻**龙龟**吞向王林;血箭未及面门,便被层层无形**生之烙印**消融,在**第八百多道生之烙印**下消失无影。
5. 王林仙力灌入熬迪体内,**寸寸摧毁经脉**并将其甩出。
6. 金甲男子睁眼喝“住手”,王林不但不停,**反而再传一道仙力**摧毁已成残骸的经脉,然后松手。熬迪半空中体内砰砰作响、血雾四散,剧痛如在地狱。
7. 金甲男子怒喝“大胆”,虚空一探自天空太阳中凝聚金芒,化作**金色长枪**掷向王林。
8. 王林不看长枪,化作残影直奔半空的熬迪,**再抓其右手猛地一抖**——熬迪全身骨头与血肉瞬间分离、骨头碎裂,痛楚数倍于经脉之创。

(片段止于此处,金枪是否命中、熬迪生死未明。)

## 四、要点与伏笔

- 王林当众**藐视妖灵之地规则与主持者权威**,两度在喝止后加码出手,坐实“外来者嚣张”的姿态。
- **石萧“当年之愤”**指向未交代的旧怨,是后续冲突伏笔。
- **玄副帅曾败于王林并受重伤**,是其笃定押注的底气。
- 章节标题点名**许立国**,但本片段未出场,应在同章其他部分。
- 战斗手段体系:王林使用**仙力/仙气**(非单纯灵力)与**生之烙印**防御(数量以百道计),对妖将形成碾压级差距。
