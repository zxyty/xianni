# 第2044章 天地异象！

## 一、以三术自造天地，感悟太初与默灭

- 天幕漆黑之际，王林抓住**默灭本源**的雾气，一挥送入棚顶幻化的黑色天幕，融入不见。
- 王林掐诀轻喝「**流月**」——其自创神通**流月之术**，可逆转千年岁月变化于瞬息；此术不止用于斗法，此刻被用来**壮大本源**。
- 自化天地之法为三者叠加：
  1. **悼亡族开辟洞府之术**；
  2. **玄罗大天尊的无中生有神通**（可创造出属于自己的世界）；
  3. **王林自身的流月之力**（造出天地运转的轨迹）。
- 关键限制：王林言明「**我只炼这密室一壁，尚可以掌握**」——规模受限方能驾驭。
- 效果：短短时间内，棚顶昼夜交替已达**数十次**。
- 王林一拍额头，分出**一缕元神**融入天棚感悟黑白交替；此后不再理会，待**若干年后收回元神**，即可得这段岁月内的全部感悟。

## 二、五行真身代炼禁制本源

- **禁制本源**呈现不断浮现诡秘符文的雾气，自当年**吉神之地**起便伴随王林至今。
- 师尊**玄罗**曾带王林去过几处地方，他在那里获得**大量禁制阵法**，对壮大禁制本源有翻天覆地之助。
- 王林一指**五行真身**：五行真身睁眼起身，化作**五道光芒**融入禁制本源内，**代替王林**融合那些禁制阵法、壮大本源。

## 三、杀戮本源与二炼戮默

### 平衡体系（王林自述）

| 本源 | 来历/作用 |
|---|---|
| 杀戮本源 | 因**雷融**而诞生，代表毁灭，不死之身不可抹去；此时仅**大成**，尚不能凝聚真身 |
| 禁制本源 | 用以**压制/平衡**杀戮 |
| 默灭本源 | 感悟所得，使**杀戮增强** |
| 太初本源 | 配合禁制，再去平衡增强后的杀戮 |

- 结论：若诸本源皆成就本源真身，应仍可压制达到平衡；王林另称「我还有另外的办法」。
- 悬念：杀戮雷霆真身第一次出现时**自称「戮默」**，而**道古国师竟也认识此身**；王林目露复杂，内心有猜测但深埋心底。

### 融合过程

1. 王林下定决心的一瞬，**雷霆真身**猛睁双眼，张口一吸**吞下杀戮本源**，全身雷霆**齐齐转为黑色**——「杀戮雷霆，再次降临」。
2. 王林掐诀一指，杀戮雷霆之身直冲而来，与其身体瞬间重叠。此举意在**以自身无数年的杀戮壮大杀戮本源的成长**。
3. 融合中身上始终有重叠虚影，王林早有预料；不断掐诀点身，每点一次重叠消散一分，额头泌汗、神色凝重。
4. 最后一指落下，杀戮雷霆真身与其身体**完全融合、再无重叠之影**。
5. 王林咬破舌尖喷血，右手一挥将鲜血化作符文**倒卷贴身**，低吼「**血炼**」，双目闭合一动不动——为防日后意外，**再炼戮默**。
6. 这是他**第二次**炼此杀戮雷霆；**第一次**是在此杀戮雷霆因意外诞生之时。

## 四、余波：仙罡大陆局势

- 时间流逝，一年、一年、又一年。
- 仙罡大陆上，随着**太古神境**的出现，暗流越加沉寂；越是如此，越有一股**沉甸甸的压抑之感**笼罩整个仙罡大陆。

- 王林深埋心底的猜测所指为何。

# 第1954章 仙吉大战将至·始古传位之争与王林出关

## 一、大势：太吉将启，仙吉大战阴云

- 仙族各宗门罕见沉寂，不再争斗，纷纷凝聚力量，为**数百年后的太吉开启**蓄势。
- 稍有势力的宗门在压抑气氛中，都预感到数百年后将有一场**阔别已久的仙吉大战**。
- 对此战的预期：**或有大天尊陨落**；跃天尊、天尊及各宗门，有的将被除名，有的将一鸣惊人。
- 吉族大地同样如此：**三脉皇族**执行来自**古道大天尊**的命令，紧锣密鼓备战；各族大天尊均已闭关。

## 二、道古（道吉）一脉：新皇尊罗尘与玄罗的转世抉择

- **罗尘**成为道吉皇族新的皇尊，但作为新皇对整个道古一脉仍陌生，需要时间适应，才可真正拥有一切。
- 过渡期内，**圣皇祖烨微**暂时代替皇尊，处理道古一脉之事。
- **玄罗**在罗尘继位后闭关不出：
  - 其**转世时间已接近**；
  - 又面临**太古神境**当前；
  - 判断眼下并非转世的最佳时候，故**压制转世**，待一切平静后方可安心转世。

## 三、始古一脉：万年之期与传位危局

- 始古**老皇尊万年之期接近**。按古老约定：除非**古道大天尊**允许，否则必须退位，将皇尊之位传承于其后人。
- 距最后退位时间**还有一百多年**。这位始古皇尊始终沉默——他没有权利选择。
- 始古一脉诸皇子纷纷把目光投向**宋天大天尊**（宋尊），由其定夺新皇。
- **计都**多次拜访宋天大天尊，均被阻挡在**原始山**外，一次都未成功。时间越来越近，一旦宋尊做出决定，一切都将晚矣。

## 四、计都行宫三人议

座中三人：计都、当年跟在其身边的少女（今为少妇）、少妇的夫君（紫袍/紫衣青年）。

- **少妇**：几十年前嫁给始古一脉一位天骄，该人堪称始古一脉**新一辈最强者**，如今是计都心腹。她焦急进言：
  - 「王林前辈已经闭关了整整一百年」；
  - 按惯例**退位前一百年就要确定新皇**，预计**数年之内**便有确切消息；
  - 若再不去求王林帮助，恐怕一切都晚了。
- **计都**挣扎许久后果断拒绝：「**义父当年闭关前曾言，任何事情都不要去打扰他**。」
- **紫袍青年**（少妇夫君）从未见过王林，嘴角冷笑，不信传闻：
  - 提到传闻中这位前辈是「**仙罡第十阳**」的样子；
  - 但当年他从**道古一脉**离开后立刻在此闭关，「看来应该是受伤了」；
  - 质疑其能否让宋尊改变主意。
- **计都的杀心**：即便义父没有出关，凭这一百年的准备也要去博一把——欲对**蚩蛮**以及**自己的那位皇兄**下手，「不知若是他们死了，宋尊是否还会去选择一个死人为皇尊」。
  - 此言一出，大殿阴冷；少妇心神一颤，欲言又止，只觉这位皇兄百年来变化太大，已然陌生。

## 五、转折：王林出关，天地异象

- 紫袍青年正欲开口时，**一股莫大威压无声无息降临大殿**。
- 威压所至：天地色变、风云倒卷；一股无法形容的气息自**王林闭关的密室**冲天而起，直奔天幕。
- 原本风和日丽的天空好似崩溃，出现大量碎片，轰鸣向八方卷动。
- 计都猛然起身，神色激动：「是从义父闭关之地传出，**义父出关了**！」

## 六、要点与悬念

- 时间线锚点：太吉开启在**数百年后**；始古退位最后期限在**一百余年后**，新皇确定预计在**数年内**。
- 权力变量：宋天大天尊的选择 = 始古新皇归属；计都试图以刺杀竞争者（蚩蛮、皇兄）改变棋局。
- 王林出关的时机恰在计都动杀念之际，直接介入始古传位之争的可能性极高。
- 存疑：紫袍青年称王林当年离开道古一脉后立刻闭关「应该是受伤了」——王林闭关百年的真实原因（疗伤/突破）本章未明。
