# 第1556章 古怪的目光

## 一、血雾中的清水往事（王林旁观）

血雾内画面接连闪烁，完整重现清水（清水仙君）的一生：

1. **少年与故国之殇**：少年长大后回到此前覆灭的国土，七天红月、生灵涂炭、血流成河；画面中始终隐现**七彩之芒**。
2. **血河绝杀**：成河之血滔天而起，将远处来临的诸多修士轰然绝杀；一身青衣的男子（清水）转身带着悲伤离去。
3. **仙界的短暂安宁**：清水踏入仙界，脸上煞气不再、露出快乐之色。身边是一名相貌并非绝美却温柔甜蜜的女子，身前是神色慈祥、怜爱望着二人的老者**白凡**。
4. **古怪的目光（本章题眼）**：即便在这幅安宁画面中，天空依然隐隐现出七彩之芒，其冷漠而带一丝奇异的目光多次盯着清水。王林越看越觉古怪——**那目光仿若是在看镜子里的另一个自己**。
5. **一指入魔**：清水在山峰顶部盘膝吐纳，天空**七彩之人**伸出右手向下一点。清水身子一震、双目猛睁，神智被血光与杀戮取代，惊天动地的咆哮回荡仙界——**清水疯了**。远处白凡呆望天空，露出不敢置信之色，似隐隐感受到了什么。
6. **仙界屠戮**：停滞许久的杀戮随其疯癫降临仙界，诸多**雷仙界**之修惨死清水手中，他越杀越疯。
7. **爱侣之死与清醒**：那女子出现在清水面前，眼中悲伤却依然温柔，死在清水手中；她隐藏痛苦、柔和望着清水，抬起的玉手欲触摸爱人面孔却无力放下，闭眼前似说了一句话。正是这句话与她死前滚烫的鲜血，让疯狂的清水瞬息清醒，发出绝望至极的惊天悲嘶。

## 二、循环之刑与杀戮本源

随着悲嘶，画面崩溃，血雾运转下**从第一幅画重新循环**，永无止息。

- 似有冥冥之力以此残酷方式，逼清水不断重现记忆，令其永世处于杀戮、疯癫、悲哀之中不得脱离。
- 目的：**刺激清水，使其体内的『杀戮本源』慢慢壮大、越来越凝实**。
- 王林感同身受——此前仅略知清水故事，如今亲眼所见，悲其一生、哀其所遇。
- 誓言：「清水师兄，我王林今日拼了一切，也要把你救出。」随即转身不再看循环画面，如长虹直奔下方镇压清水之魂的**玄武真身**。

## 三、破阵判断：先解其魂

- 石化玄武之大**足有整个七彩界一般**；虽已石化，气息却强悍至极，王林临近时甚至产生错觉：**这玄武并非死亡，而是沉睡**。
- 以王林对阵法禁制的造诣，判定：**石化玄武是破此阵的关键**。若不先崩溃镇魂玄武，清水身上的**十根利刺**根本无法取下。

## 四、硬撼石化玄武

| 回合 | 手段 | 结果 |
|---|---|---|
| 第一击 | 体内道古之力凝成虚幻拳头砸玄武背 | 巨响，玄武全身一震却毫无伤损；倒卷大力将王林冲退数十丈 |
| 连续十拳 | 每拳皆七星古神全部之力，拳化卷动天地的风暴 | 玄武背部坚硬得无法想象，无半点碎裂；反震滔天，王林右臂咔咔作响、倒退百丈、嘴角溢血，神色更狰狞 |

## 五、十万死修与血肉之刀

- 轰鸣回音传遍七彩界之际，玄武体内传出**肉耳听不到、唯心神可感的闷闷嘶鸣**。
- 十万利刺所化十万大山上的**十万修士**随之嘶吼，自贯穿全身的利刺上生生拔起，伤口诡异蠕动、瞬息愈合，仅衣着破损，疯狂扑向王林，种种神通五光十色笼罩七彩界。
- 王林左目金色火焰（已成**仙火**，虚火仍在）挥出笼罩众修，**十万修士体内却无任何虚火诞生**——唯一解释：**他们早已死亡，只是被某种奇异力量操控**。
- 王林之仙火威力远胜当年云海第一战，配合金色雷霆（仙雷）横扫八方，天地雷音滔滔，死伤无数。
- 十万修士随即**自行崩溃爆开**，全部血肉凝聚蠕动，化作一把**与天地齐高的血肉之刀**：刀身内可见无数扭曲面孔与残肢断臂，抬起时遮天蔽日、投下巨大阴影，在十万修士凄厉哀嚎中向王林急速斩下。

## 六、千丈古神接刀与最终双拳

- 王林本可退走、弃清水生死不顾，但他做不到；双眼露出疯狂豪情。
- 右手拍眉心，**七个金色星点急速旋转**，身子膨胀化作**千丈古神**，右手向天猛撑，硬接血肉之刀。
- 刀中怨气与杀戮气息如风暴涌入体内；此乃十万修士肉身之力经奇异神通扩大数倍，**已能伤七星古神**。
- 王林不退半步，将冲击之力强行留在体内，低吼挥手把血肉之刀生生弹起数百丈，喝道：「力气还不够，再来」。血肉之刀连续斩下**数百次**。
- 最终一刀落下时，王林**放开全部排斥之力**，瞬息爆发十成之力——**仙与神短暂的融合**，此力足以轰杀空灵初期大能（此前**天兆上师**即死于王林十成之力）。
- 王林咽下欲喷之血，并将降临身上的冲击之力**尽数借走、融入自身**，借力以从未有过的速度向下方石化玄武倒退坠落。
- 临近玄武刹那猛地转身，**生平第一次在爆发古神之力后同时施展双手之力**，双手握拳咆哮砸向玄武背部：「给我碎」。
- 结果：整个七彩界骤然震动、大地颤抖、天地似要崩溃，坚硬的石化玄武背部发出**剧烈的咔咔之音**（章末悬念）。

## 七、要点与伏笔

- **七彩之人/七彩之芒**：贯穿清水一生的旁观者与真正的『点疯』元凶；其目光「仿若在看镜中的另一个自己」，暗示与清水存在同源/分身式关联。
- **清水之疯非本心**：其杀戮源于外力一指，且被循环画面持续豢养『杀戮本源』。
- **十根利刺 / 十万利刺**：分别镇压清水之身与化作十万大山，构成整座封印阵的层级结构。
- **玄武疑未死**：气息如沉睡，为后续变数埋线。
