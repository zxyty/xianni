# 第1478章 回家！（第十卷 叱咤界内）

## 一、归还记忆传承
- 涂司的记忆传承伴随王林一千多年，走到此刻已失去作用——涂司也仅是**八星巅峰古神**而已。
- 王林右手浮现传承所化光团，沉默片刻后猛地甩向拓森。一句「给你」。
- 半跪疗伤、胸口血肉模糊的拓森接住这件让他追出界外的**因果之物**，身子明显颤抖。
- 拓森的执念史：当年身为一丝魔念被封印无数万年，眼睁睁看着传承被王林取走；破封后占据涂司肉身，开始漫长寻找。他从未想过传承会有被王林**主动归还**的一天。
- 拓森抬头，复杂地看了王林一眼，说出一生中第一句「谢谢」——他的狂与傲在骨子里，本无「谢」这个词。

## 二、王林的态度与伏笔
- 王林：「涂司的传承，在完整的同时，他会不会苏醒，你会不会消散，我不知道。」
- **道古传承**具唯一性：王林已取走一部分，除他之外无人可继续获得。
- 伏笔：待修为足以再次承受之时，王林还会回到这里继续传承。

## 三、清场收物
- 灵动、周瑾（被这一幕震撼）被收入**天皇炉**。
- 古魔尸体放入储物空间；古息叶、血剑等一切之物一并收走。

## 四、擒极贤天、武东禅，收走望月
- 宫殿北部虚空波纹扩散成**虚幻大网**，网后现出巨大黑影：椭圆形身躯、无数触手摇曳、口喷古神气息冲击大网——正是**望月**。
- 望月头顶站着**极贤天**与**武东禅**，二人凭望月无需墓台便找到宫殿，正欲强行融化禁制入内，却估算需时极久，只能焦急等待。
- 王林一步跨至网外，抬手一抓一撕，大网裂开巨缝；狂风扑出，二人毫无抵抗之力，惨叫喷血，连王林身影都未看清便被卷入其储物空间。
- 望月被狂风震退，眉心**封印符文**剧烈闪烁；王林大袖一甩，望月身后现出巨缝，被吸入收走。
- 王林暗念：「**罗尘**应该还在这望月体内」——罗尘对他有恩，此事他始终记得。

## 五、拓森的身份之惑
- 残破宫殿只剩拓森一人，手握传承却无喜悦，只余犹豫与茫然：
  - 「涂司从我诞生之日起，我就知晓自己是你一丝魔念而生……只是这记忆，是真，是假？」
  - 「你是真的**墨流分神**失败而亡，还是我就是你**墨流分神术**的一部分？我，是拓森还是涂司？」
- 章末：拓森似下了决心，将记忆传承按在眉心。

## 六、封死古墓与取出「地府」
- 通往**太古星辰**的裂缝关闭后，古墓内雾气更浓如海翻卷。幸存者皆修为高深、心智极高，是太古星辰各部落的精髓。
- 王林于**第九张地图**空间乱流中现身，位置与宫殿处于不同之界，避开八妃中的风情女子。
- 他放弃了当年战掌尊式的「尽杀」念头：妙音道尊、九天魔尊、大荒等存活数万年必有神通，且古墓已被彻底封死，众人将被长久困住——这就足够。
- 王林凭**道古的部分记忆**，抓开虚空裂缝取出**地府**：巨大金色阁楼，三扇窗，大门死死封闭，窗内三个光影盘膝而坐，磅礴威压笼罩八方。地府为**烨寞**所留。
- 阁楼出现刹那全墓修士皆感应，妙音、九天、大荒察觉尤清；王林毫不耽搁，大袖横扫卷入储物空间后即离去。

## 七、封印之地与「临别礼物」
- 王林转至**第五张地图**古息叶封印之地外，此处如旧无损；他以一片古息叶印上开启入口，取叶而入。
- 地面漂浮的**漩涡**仍缓缓转动。王林感应到幸存修士正疾驰而来，数股极强神识已锁定自己。
- 王林掐印拍向天空，印记幻化消散——那是**打开古墓第二层的符文**。九副地图下的茫茫雾海轰然而动，尖锐厉啸如藏无数战魂。「临走前，送尔等一个礼物。」
- 王林一步迈入漩涡，同时反手一抓，将整个封印之地连同漩涡永久收走。妙音老道三人赶到时，眼前空无一物。

## 八、回家！
- 界内，**雷仙界**下、**罗天星域**边缘——当年**贪狼**被卷入之处——璀璨星空中无声裂开一道缝，白衣身影一步走出。
- 惊天气势化作威压席卷整个罗天星域，足令万灵心神颤抖；**鲁夫子**第一个从入定中惊醒。
- 白衣身影沉默少顷，嘴角浮出久违的微笑：「竟然不是界外太古星辰，而是回到了界内……罗天……回家了。」

## 待续线索
- 拓森融合传承后是否苏醒为涂司、拓森是否消散，未定。
- 罗尘仍在望月体内，尚未取出。
- 古墓第二层被强行开启，困守其中的妙音道尊、九天魔尊、大荒等人将面对未知。
- 王林承诺日后重回古墓续接道古传承。
