# 第1893章 各有图谋！

## 一、局面：雷霆本源真身反噬

- 与王林**一模一样**的雷霆本源真身悬于上方，全身轰鸣雷音，右手一拍，无数闪电向盘膝的王林镇压而来。
- 王林此刻苏醒，脑中立刻浮现**道魔宗宗主**的样子——真身的凝聚与此刻的突变，必与其有直接关联，真身上还隐隐有其气息。
- 王林推断对方图谋：**擒而不杀不伤 → 占据其雷霆、助其凝聚真身 → 以真身入体，令其神智心神大乱、生生磨灭**。

## 二、王林的对策：天逆藏神，以不变应万变

- 王林**当年便已算出这一幕**（尽管只是片面的一幕），震动极大，故早已想好应对之法。
- 镇压临身瞬间，他元神闭目，在魂内呼唤**天逆**。灵魂中凝聚的天逆珠子转动，元神与灵魂记忆等一切之物骤然**收缩**藏起。
- 战术要旨：**暂时退缩，留下肉身给雷霆本源融入；待真身完全融入后，才是反抗之时。**这是他当年想不通真身为何如此时，想到的唯一对抗方法。
- 真身临近时全身瓦解成更多闪电钻入其体，在道魔宗宗主意志驱使下横扫，欲抹掉王林一切神智心神。

## 三、一个月后：活死人状态与交割

- 一月之后，王林体外闪电尽散，盘膝不动，**无灵魂波动、无修为气息、生机几近熄灭，如活死人**。
- 一股强悍神识自外扫过后离去。
- 蝎子建筑外，道魔宗宗主睁开略显疲惫的双眼，告知祭祀：其神智、心神、记忆已全部抹掉，体内空空，可自行查看，满意则本宗离去。

## 四、祭祀的三重试探（本章核心博弈）

绿袍笼罩、脚步虚弱、不断咳嗽的老者（绿魔蝎庙祭祀）在两名绿魔使者护卫下现身，右手（**长满绿色毛发、不似人臂**）按上王林天灵。王林心神微起波动，被天逆掩住外人不察，随即自抑：「那道魔宗宗主还没走，此刻不是反抗的时候，再等等。」

祭祀明言：**能以凡人之躯成为绿魔蝎庙祭祀者心智极高，即便亲眼所见也不轻信，必须试探。**

1. **言语之探**：当着王林喃喃自语族史与图谋——「老夫一族一代代以凡人之体为祭祀，无数万年，终于等到与绿魔大人一样来自**天外之体**」，并点出还需抹掉雷霆本源上道魔宗宗主的记忆。
2. **绿血为饵**：咬破指尖，一滴绿血点在王林眉心，体内荡开绿色涟漪，**道魔宗宗主残留的意志烟消云散**。此时雷霆本源真身已无他人意志，王林心念一动即可不费吹灰之力占据——但他为**更大的造化**生生忍住这份冲动与诱惑。祭祀久候未诱出心神，方才略微放心。
3. **真杀之局**：祭祀退至数十丈外，忽以沙哑之声大喝「**绿魔卫，杀了他！此人心神还在，开启绿魔大阵，断然不能让他逃出！**」，双眼却死死盯着王林身体。两名绿魔使者双眼凶煞，**空劫中期**神通化作两只巨大绿魔蝎子扑杀而至——绝非虚招。
   - 换作旁人此刻只有一条路：心神散入雷霆本源、留下自身意志、以最快速度转换**天牛魂铠**，杀三人后遁走。
   - 王林心神一动即刻平静，古井不波。他**绝不信对方能察觉天逆**——这是一场计算的比拼。
   - 神通逼至七寸、六寸、五寸、三寸、一寸，生死危机疯狂弥漫，以其定力亦不由动摇，仍一动不动。
   - 轰然落体之际，王林身外荡起一层**绿色波纹**，柔和抵消并反弹了二人神通——正是祭祀先前那滴绿血所化，看似消失实则留存，是试探的关键一笔。

## 五、结论与后续图谋

- 祭祀彻底放心，沙哑大笑（笑中剧烈咳嗽）：「这具身体果然没有了意识与心神，只不过其修为还是太弱，还需培养一下，方可承受绿魔大人的降临。」
- **本源账目**：王林身具**八道本源，独缺土**；绿魔大人的本源为**大地之土**，补上即成**九道**，**九道本源归一即为本源之体**，完全吻合绿魔大人降临夺舍。
- 祭祀一族的使命：待绿魔大人夺舍复活，即可**回中州复命，福及族中后世**；对道魔宗宗主亦有承诺（「待绿魔大人复活后，承诺于你之事，不会少」）。
- **王林的判断**：眼下这场危机对他而言**并非生死劫，而是一次怦然心动的绝大造化**——故甘愿继续蛰伏，不夺真身、不动杀手。
