# 第1699章 幻中幻！！

## 一、幻中幻的破除

- **幻境场景**：七彩道人自魂魔舟第三层走上第四层甲板，神色冷漠，右手抬起间掌心浮现一轮掌心大小的骄阳，热浪如真日，向前一挥直奔王林。伪装成矾珊梦的女子（实为矾珊璐）急退数百丈，掐诀后七彩之光化作七把长剑绕身旋转，身后浮现巨大的七彩之花虚影，妖异绽放并透出迷人香气。
- **王林之应**：骄阳临身，头发燃烧、体内高温撕裂剧痛、神色扭曲，但双目始终平静不变，任由骄阳将自己淹没。下一息，他在万丈阳光下一步步走出——发未燃、衣未损、神色平静。
- **破幻**：王林闭目、右手前挥，判定「这一切，都是假的」。七彩光芒、骄阳、七彩道人、第四层甲板、第三层、第二层尽数消散，最后消散的是那名一脸不可置信与迷茫的女子。

## 二、幻境之外的真相

- 王林睁眼，所见是魂魔舟**第一层甲板**、船杆之上飘动的帆布，帆布上的鬼脸正诡异地微笑。他仍盘膝而坐，身外仍有**道古虚影**笼罩；不远处矾珊璐同样盘膝、同样睁眼，目露深深迷茫。
- 王林望向船外：防护光幕层层，其外**并无七彩之光、亦无七彩道人身影**——「就连他，也是假的」。他起身挥手散去道古虚影，目光最终落在船杆帆布上。
- 矾珊璐茫然消散后惊觉四周，神色大变，踉跄后退数步喷出一口鲜血，脱口而出：**「大魂真幻术！这是我姐姐的最强神通！她为了杀七彩，居然在这里连我也笼罩在这神通下！」**

## 三、王林的推演

1. **双层算计**：矾珊璐自以为一切是自己的算计——带王林来此地、以明暗两层威胁逼其交出**誓血**；而矾珊梦更为高明，从一开始就把整个局面化作幻境，幻化出「七彩追击」配合妹妹的算计，把王林引到此处。
2. **幻中幻**：矾珊梦连矾珊璐也一并隐瞒，在王林准备研究此地禁制的瞬间施展**幻中幻**，令王林无法看透，险些真的逼他交出誓血。
3. **忌惮之评**：「我王林一生所遇无数人，只有一人让我感觉神秘莫测、内心忌惮，眼下又多了一个，那就是你姐姐。」
4. **旧事存疑**：矾珊璐此前称姐姐在七彩仙尊手下死亡、后被师尊复活——王林判定为假，**矾珊梦根本没死过**，很可能是以幻术瞒过七彩仙尊；当年仙罡大陆那对道侣之间发生的事，也并非矾珊璐所述，只是王林「不感兴趣」。

## 四、大魂门幻术设定

- 王林推断：**仙罡大陆的大魂门以幻术著称**。
- 矾珊璐证实：大魂门最出名的的确是幻术，**此术并非人人可学**，其姐姐有学习此术的天资，已修炼到**双重幻**的境界（即王林所说的幻中幻）。
- **若再进一步达到三重幻术，王林与矾珊璐不可能走出。**

## 五、夺宝

- 王林一步跨至船杆旁，双目寒芒，右手狠狠一撕，把**鬼脸帆布**彻底撕下：**「此宝，我要了。」**

## 六、两处远景

- **仙罡大陆·冰封山脉**：一名在寒冰中打坐的女子（矾珊梦）猛然睁眼、一口鲜血喷出，眼露震惊：「他居然破开了我的大魂真幻术！」
- **魂魔舟所在奇异空间·另一方向**：七彩道人盘膝坐在一片凶兽尸骸之中，神色时而痛苦、时而兴奋，这种诡异表情在他身上很是罕见——他同样在进入此地一瞬沉浸幻觉。以其修为（虽不如矾珊梦）走出幻觉本不难，故疑为**自愿沉入不醒**，原因只有他自己知晓。

## 七、悬念与后续线索

- 矾珊梦本人真实实力与目的未明，其「大魂真幻术」目标之一为**杀七彩（七彩道人/七彩仙尊一系）**。
- 七彩道人自甘沉溺幻觉的动机未解。
- 誓血仍未交出；被撕下的鬼脸帆布归王林所有，其来历与用途待后文。
