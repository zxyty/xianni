# 第1825章 仙祖八极！（第三更）

## 一、局面
- 地点：天牛洲**地火主脉**深处。
- 三方：**王林本源真身**（正在凝聚火本源真身）、**王林本尊**（尾随）、**大魂门少妇**（全速赶来阻止）。
- 王林本尊修为远逊少妇，一路无法阻拦，唯余一式始终含而不发的神通，只待最关键一刻。

## 二、少妇识破本源真身
- 少妇神识扫到王林本源真身的刹那容颜大变，惊呼「他居然在这里，借地火脉凝聚其火本源真身」，藏在衣袖内的**右手**下意识抖动。
- 其震动甚至超过见到王林取出大天尊所赐法宝——大天尊她从未见过，本源真身却见过几次。
- 参照物：**大魂门老祖青牛真人**身上同样有本源真身。少妇深知其凝聚之艰难、成后之强大，本以为此生只能在老祖身上见到。
- 恍然：王林引她去别处、冒险深入地火主脉、有大天尊法宝仍要来此——皆因要凝聚这几乎是传说中的本源真身。
- 判断与动机：本源真身一旦凝成，**地火主脉即会崩溃**；加之内心滔天嫉妒，她决意阻止，遂喷出一口鲜血与之融合，速度暴增十倍不止，化作烟丝残影疾驰。

## 三、火龙魂崩溃与天牛幻象（远古闪回）
- 本源真身那一声反抗到底的咆哮后，降临体内的**火龙魂意志轰然崩溃**，王林意志占据主导并大量吞噬其残存零散意志。
- 吞噬之际脑海轰鸣，神识扩散，隐隐听到天牛洲**大地深处**传来一声凄厉咆哮，心神被牵引融合，坠入幻觉。

### 幻象所见
1. 无边星空中出现一头**天牛**：全身缭绕无尽冰寒，星空欲被冰封，身体庞大看不到尽头；气息之恐怖，比之**玄罗**都不遑多让。王林一生未见如此凶兽。
2. 金光笼罩星空，走出**穿皇袍、戴皇冠、看不清容貌**之人——即传说中的**仙祖**。庞大仙力充斥八方，与冰寒之气对抗。
3. 天牛再咆哮，以己为中心急速冰封星空。王林评估：此力莫说自己，纵是全盛时期的**七彩仙尊**也无法对抗，唯**玄罗**全力或可一拼。
4. 仙祖右手五指冲天，向下一指，喝道：**「八极仙道，极火道」**。指间散出**青色烟丝**，缭绕九圈化作**九个烟丝圆圈**层层压去，冲出中自行膨胀至无边无际。
   - 第一圈：撞散天牛冰封之力；第二圈：穿透冰封落于天牛之身；其余七圈一一印下。
   - 第九圈落下：天牛体内一切冰寒骤然消失，代之以滔天之火，天牛如同**火牛**。
5. 仙祖判词：**「汝侵吾仙族，惩汝身为大地，汝神为滋养万灵，如骨为地脉，镇压汝魂，悠悠岁月至仙罡」**。
6. 天牛凄厉嘶吼，身体轰然下沉化作无边大地，山脉起伏；其**骨为地脉**，体内无尽火焰散出，令地脉尽成**地火之脉**；其**魂被镇压于大地最下方**，唯余不甘咆哮时而自地底传出，仿佛无人可闻。

### 与传说的对照
- 传说：仙祖斩杀天外之牛，以其身体化作一洲，封印后赐名**天牛洲**；此洲从此诞生凡人，修士迁移布置山门，衍变无数年后，即**仙族七十二洲**中的**东州天牛洲**。
- 王林的疑问：**天牛传闻明明属火，为何所见是冰寒**（本章未解）。

## 四、定神术与本源真身凝聚成功
- 幻象散去，王林本源真身头发急速变换，**雀羽大范围转为黑发**，只差一丝即完全凝聚。
- 少妇裹血光临近，玉手抬起，欲一击毁掉将成未成的真身。
- 其身后波纹扭曲，**王林本尊**一步走出，右手抬起，蓄势一路的神通爆发：
  - **「定神术」**——定天定地、定一切神通、定思维、定万物，**而非定身**。
  - 效果：少妇娇躯骤顿，神通被生生打断，全部停顿。
  - 代价：王林喷出鲜血，全身怦怦爆出大片血雾。
- 王林**不攻击少妇**（断定其身上必有防护法宝），而是直接**瞬移**至本源真身所在，**与真身融合，元神完整**。同一瞬本源分身头发**完全化为黑发**，**火本源真身凝聚完成**，强悍气息爆发。
- 少妇恢复，内心震动：「即便你分身与本体融合了，也一样不行」；她从未见过这种定身神通，此术来历莫测。
- 少妇扑来之际，王林猛抬头、右手抬起，喝出：**「八极仙道，极火道」**——**他没有仙族血脉，但他另有手段**（章末悬念）。

## 五、要点
- 本章确立三条设定：①本源真身极难凝聚，大魂门老祖青牛真人亦有；②天牛洲的起源=仙祖以八极仙道·极火道镇压天外冰牛、化身为洲，地火脉即天牛之骨与火；③王林的杀手锏为**定神术**（定神通/思维/万物），来历莫测。
- 战力标尺：天牛冰封之力 > 全盛七彩仙尊，约与玄罗全力相当。
