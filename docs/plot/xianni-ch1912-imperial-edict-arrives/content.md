# 第1912章 圣旨到！！

## 一、王林 vs 红袍男子（道魔宗）

### 三道掌印与三重抵抗
1. **红雾双臂**：红袍男子以神通红雾所化的两只手臂闻名，曾杀戮无数修士；在王林修为爆发的掌印下如枯木般急速摧毁、轰然瓦解。
2. **道魔血身**：他咬破舌尖喷血，全身三万六千汗毛同时爆血覆体成「血身」，环绕精纯道魔气息，**左手蕴道、右手凝魔**，双臂轰出，崩溃了第一道掌印（喷出的血旋即被身体吸收）。
3. **聚血双臂**：面对第二道掌印，他神智似失、只剩不甘死亡的疯狂，双腿急速枯萎至皮包骨如骷髅，躯干亦干瘦，全部血肉精华融入双臂，双臂暴粗数倍轰去。第二道掌印崩溃，其**左臂直接爆开化作血雾**。
   - 王林曾在**大头**身上见过同类神通，但远不如此人精妙。
4. **燃烧生命跃升金尊**：第三道掌印临身之际，他冲天而起，燃耗灵魂、元神散发毁灭气息，修为自**空劫大尊**疯狂攀升，一跃成为**金尊**，硬撼第三道掌印（该掌印内不含杀戮之雷，仅为寻常雷霆）而不死，但生命仅余十息。

### 王林七成之力的一拳
- 王林不闪不躲，冷言：「你有资格，让我用出七成修为之力。」
- 骨刀缩回掌心肉内，握拳；**五行真身融体、雷霆真身融身**，一拳轰出。
- 这一拳是其**道古肉身**全部力量的七成，是空劫修为运转全身、与道古融合后体内那条**仙祖发丝**所散滔天仙气的七成。
- 效果：天地色变、苍穹震动，二人间虚空层层倒卷成褶皱般涟漪，拳头似超越空间距离与时间运转，直落红袍男子胸口。
- 结果：金尊修为的红袍男子苦笑中身体轰然爆开化作血肉，剩余七息不必再过。临死清晰知晓——即便燃魂燃命，也不是王林对手。
- 王林感受：「这就是金尊么」，眼中露出战意。

## 二、道魔宗灭门

- 下方三万修士与数十大能四散逃遁，但道魔宗四周早被王林封印，无处可逃。
- 王林接连瞬移斩杀数十大能：一指划过取头颅、一指穿透眉心，冷言「你们不该成为道魔宗门人」。
- **环形封印禁制阵法急速向内收缩**，触之即死；建筑被毁、夷为平地成废墟，三万修士大量死亡，惨叫声不绝。
- 立场：**说要灭门，就是灭门，寸草不留，一个不漏。**
- 王林最后立于中心湖泊外半空，喝问「你，还不现身么」「在试图突破么，我给你这个机会」；湖心岛屿鸦雀无声。
- 王林注意到**湖水下有隐隐游走的庞大暗影**。

## 三、道魔宗宗主的隐忍与算计

- 宗主在湖心岛屿闭关，神色扭曲、双目通红，却生生忍住不敢出手。
- 恐惧来源：亲见王林杀金袍老者、见红袍男子燃命成金尊仍被一拳轰杀。他在心神内**推衍一千余次**那一拳，其中约半数自己会死；且那还只是王林七成修为，另外**王林尚未穿上天牛魂铠**。
- 决断：「绝不能出去」；已**以秘术将此地之事传给道魔宗老祖**，盼其赶回。
- 冷酷算计：「死就死吧……只要我还活着，就还可以重新组建，且他们死的越多，道魔宗毁灭的越严重，越可以激发老祖的怒火。」
- **第二重准备（关键伏笔）**：天牛洲上，按其与**大魂门青牛老祖**的约定与计划，已到尾声，最终决战正在进行。
  - **天牛洲与绿魔洲的大战是两洲演了数万年的一场戏**；近一百年演得极为真实，两洲不惜大量死亡以增真实感。
  - 目的：以此代价吸引**皇族**目光，引起**一百多年前重新出关的仙皇**注意——「圣旨，必定会下」。

## 四、天牛洲：圣旨到

- 归一宗所在之地被无数绿魔洲修士围攻，双方**十八个崛起的天骄之辈**在大军中不顾一切厮杀。
- 归一宗内包括宗主在内的所有空劫修士、以及绿魔大军中留守的几位空劫大尊，同时抬头。
- 天空被滔天金光笼罩，金光中一道**金色身影**平静俯视大地，无上威压逼压而下，所有厮杀全部停止。
- 宣旨：「**天牛洲、绿魔洲，于此地归一宗内所有我仙族之民，接旨**」。
- 同样的身影另有两道：**一道出现在大魂门，一道以无法形容的速度直奔绿魔洲**。

## 五、要点与伏笔

- 王林当前实力标定：七成之力可轰杀燃命而成的金尊；尚有天牛魂铠未用。
- 道魔宗老祖已被通知，随时可能赶回——王林灭门行动的时间压力。
- 两洲百年血战的真相被揭穿为**做局引仙皇圣旨**，宗主与青牛老祖为共谋方。
- 湖心岛屿与水下巨大暗影仍是未解之谜。
