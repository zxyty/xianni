# 第九卷 云海之巅 第1192章 三叉戟

## 一、局势起点：手持玉瓶的逃亡
- 王林疾驰中试图将夺来的**玉瓶**收入储物空间，但此物诡秘无法收纳；他早有心理准备——若能收，苍松子早就收了，不会一直用手拿着。
- 王林以**两张速符**加持，速如电闪、如长虹疾驰。
- 身后是两路追杀：
  - **苍松子**：天空中以七彩之芒凝聚幻化的巨大手指「**天运一指**」轰然降临。
  - **青衫老妪**：三道**生死禁**化作的禁气不断追击。
- 二人皆为**碎涅中期**大神通修士。王林敢虎口夺食，是自认有把握对抗。

## 二、化身古神：一拳崩碎天运一指
- 王林猛地转身，身影瞬息膨胀，浓郁**古神气息**弥漫七彩界；身躯自十丈、五十丈、百丈直至**三百余丈**的擎天巨人。
- 标志：眉心**五个清晰的古神星点**快速环绕，**第六个星点模糊出现**；皮肤粗糙，隐隐密布符文般的纹理。
- 苍松子瞳孔骤缩，青衫老妪目露难以置信——从未见过如此炼体神通，且那巨人身影**丝毫不虚幻、极为真实**。
- 王林抬头以**古神一拳**（蕴含**逆天之意**）正面轰击天运一指，七彩巨指自指尖起迅速崩溃瓦解，化作无数七彩晶光彻底消散。
- 借力一跃，三百余丈之躯大步跨越无数距离，直抵墙壁般的山脉之下，再一踏跃起横跨山脉。

## 三、三叉戟出世
- 王林于山脉之上右手虚空一抓，撕开一道巨大裂缝，一把**通体漆黑、长约四百余丈**的**三叉戟**呼啸而出，如撑天利器，威压惊天，古神气息浓郁。
- 横扫之际，戟尖划出三道黑线，仿佛破开虚空，嘶嘶作响。
- 面对追来的三道生死禁气：王林体内古神之力疯狂灌入三叉戟，戟尖黑芒闪烁，一扫将三道禁气**拦腰斩断**；黑芒化作**三条黑龙**张口**吞噬禁气**，吞噬后戟身多出**三道印记**。
- 此时王林右手好似抓着一条三头黑龙，龙目凶光直盯苍松子与青衫老妪。

### 王林的警告
> 「天材地宝，人人均可得之，何来抢你宝物之说……你二人若再纠缠，则如那天空一指，如这生死禁气，休怪在下杀人。」

## 四、追击方的反应
- **苍松子**：震惊难平，自认修道久、知晓众多炼体之术，却从未见过能幻化如此庞大真实之躯者；但千年准备、耗费众多法宝才得之物被抢，绝不甘心，双目血丝再度追击，并**在追击中右手连点左肩，凝聚七彩之芒重生出一条崭新左臂**。
- **青衫老妪**：面色略白，咬牙疾驰追去。

## 五、反杀局：借敌之禁制困敌
- 王林跃过山脉，直奔**之前布置过禁制的山谷**处。
- 老妪眼露恶毒，掐诀点向自己先前留在山谷外的禁制：山谷外草地青草尽数枯萎化作黑灰冲天，形成巨大漩涡欲笼罩王林。
- 王林闷哼受阻，踉跄挣脱阵法，黑灰漩涡追袭其后。
- 老妪加速冲下山脉，**踏入山谷外阵法**；苍松子紧随其后，却在迈入刹那**略一停顿并未真正踏入**——并非看出破绽，而是出于谨慎、提防老妪。
- 王林猛地转身一指，黑色漩涡**倒卷**反扑老妪；同时阵法中**数万道禁制印记**幻化飘出，围绕老妪疯狂冲击。
- 该禁制系老妪自己布下，却已被王林**暗中操控**，融合**生死禁与破灭禁**，威力惊天。老妪陷入漩涡与禁制之中，怒吼渐远、隐有血光，处于难以脱离的**生死危机**。
- 苍松子面色大变，立刻推断出此为王林「引君入瓮」的杀局，惊觉「此人竟然也精通禁制之术」。

## 六、转入正面决战：对苍松子
- 苍松子的算计：「这赵老婆子被困，对老夫来说也是好事，只要杀了那姓吕的，玉瓶自可拿回，到时以老夫对这里的熟悉，谁也别想找的到我。」（王林此时以化名**吕子浩**行走，故被称「姓吕的」）
- 苍松子绕过山谷禁制，掐诀化出**上万金光**扑向王林。
- 王林正等此机：两个碎涅中期无法同时对抗，唯有**先伤或困一人**，才能与余下者放手一战；且苍松子在**蓬莱星**时便不怀好意。
- 王林三叉戟一挥，三条黑龙咆哮，将剑雨般的金光倒卷回天际，无法近身。
- 苍松子虚空一抓开启**储物裂缝**，取出一把**通体晶荧、仿若水晶的飞剑**，一股**次空涅法宝**气息弥漫七彩界，王林瞳孔收缩。
- 苍松子低喝甩剑，晶剑惊天呼啸直扑王林；王林战意升腾，**不退反进**，三叉戟横扫，三条黑龙**脱离戟身**直奔晶剑吞噬。
- 更诡异的是：戟身上因吞噬生死禁而生的**三道印记**骤然闪烁，与三条黑龙融合，方圆**千丈**内顿时弥漫**生死禁的气息**——这便是三叉戟的真正神通。（本章至此断章）

## 七、要点归纳
1. 王林古神炼体已至**第六星点模糊显现**的阶段，硬撼碎涅中期神通不落下风。
2. 新法宝**三叉戟**登场，核心能力为「**吞噬敌方禁法/神通并转化为自身印记**」，可将所吞禁法气息外放成域。
3. 王林的取胜路径是**禁制反制 + 分割战场**：夺取敌人已布之阵的控制权，先困碎涅中期的青衫老妪，再单挑苍松子。
4. 苍松子的实力细节暴露：可**瞬间再生断臂**，拥有**次空涅品阶的晶剑**，且对七彩界地形极为熟悉。

## 待续/悬念
- 青衫老妪（赵姓）能否脱困、生死如何未定。
- 王林与苍松子的正面碎涅中期之战胜负未分。
- 玉瓶的具体来历与功用本章仍未揭示。
