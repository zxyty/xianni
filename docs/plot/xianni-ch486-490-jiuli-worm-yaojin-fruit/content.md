# 仙逆 第509–510章：地魔北界耀金果与九黎虫

## 一、路途：压抑感与杀意（第509章）

- 大罗剑宗一行由**千琴**指路，全速直奔地魔北界耀金果所在，途中妖兽被两名**婴变初期长老**（石姓老者**石方**、一名矮个老者）一个印诀轻易灭杀。
- 千琴目睹本门费尽辛苦才能击败的妖兽被瞬杀，内心苦涩，隐生认命之意——此行能得一粒耀金果也就罢了。
- **郭邢佚**一路殷勤搭话，欲修复关系；千琴迫于大罗剑宗之威，虚与委蛇、忍辱负重。
- 郭邢佚的师伯（**化神期老者**）目光时而落在千琴身上，眼中渐露奇异之芒。

### 两名长老的私下传音（关键伏笔）
- 二人并非首次进入地魔北界，但这一次最为诡异：越深入，越有一股令人崩溃的压抑感无声笼罩。
- 始终觉得有一双眼睛在看着他们，神识查探却屡屡一无所获，仿佛幻觉。
- 二人判断：此处未入深处，按理不该有**荒兽**出现；且此感“并非专对你我二人”。
- 石方自陈：在此每多待一息便呼吸困难、如万山压顶，更有**想要出手杀人的冲动**——“自化神之后，便从未有过”。矮个老者亦然，杀**苦影兽**时险些失控。
- 矮个老者提议即刻离开，石方以“已走这么远、还有不到三天路程”为由，决定加快速度前行。前方带路诸人（含化神期老者）竟无一人察觉这两位“大神通者”的惊慌。

## 二、设定：耀金果与金灵根

| 项目 | 内容 |
| --- | --- |
| 性质 | 天地**之元金**所化，不可服食，为**炼器材料** |
| 功效 | 使一切金属性之物威力大增，用量越多威力越大 |
| 名例 | 大罗剑宗剑尊**凌天候**背后四把虚幻之剑，以海量耀金果炼化而成 |
| 生长 | 无特定之地，天下随时随处皆可生；初生与野果无异，成型后爆发金属性气息 |
| 周期 | 成熟后凋落周期可长可短，短则数息，长则数月，毫无规律 |
| 守护 | 成熟引来金属性灵兽窥伺，化身守护之兽，守护至果子自然凋落 |
| **金灵根** | 凋落之果融入根部形成；灵兽吞下可神智大开。守护期间果子被取走过多，金灵根便无法凝成 |

### 王林的判断（源自涂司记忆）
- 王林骑**蚊兽**，于千丈外无声无息尾随，无人察觉。
- 他初闻“耀金果”之名陌生，一见实物即从**古神涂司**的记忆中检出记载：此物既为五行元金所化，存在时间必悠久；其**最大好处是取金灵根吞下，使躯体更加坚硬**，对**幼年吉神**亦是不可多得的补品。
- 结论：“此物分明是金灵根，何来耀金果一词”——大罗剑宗诸人不知其真正用法，把果子当成最佳之处，实属舍本逐末。

### 蚊兽的异状
- 蚊兽身上乳白之芒微微闪烁，死死盯住千丈外的耀金果，露出**强烈渴望**。
- 王林拍其头，点头默许；蚊兽转身再盯，目光已是**志在必得**。
- 王林起疑：“此物，莫非对蚊兽有什么特殊的作用不成”——为后续埋伏笔。

## 三、现场：山谷与九黎虫

- 地点：两处山脉交错之地的一处山谷，幽静无声，地面腐叶堆积、气味难闻；谷内隐透金芒，谷口大树遮掩。千琴指认此处即两月前其师门发现耀金果之地，言毕退后不语。
- 高个长老掐诀虚空一按，浓郁**仙力**化作仙风扫过：腐叶尽消、树木化灰，露出直通山谷的笔直通道。
- 谷内西处杂草中，十余朵金色花朵怒放，花下缀着拇指大小的暗金色椭圆小果，带颗粒斑点、串连如葡萄，外表与野果无异——即**耀金果**（原文另称“百粒耀金果”）。
- 两名长老不急入谷，目光锁定距耀金果一丈外的枯黄草叶。微风一起、枯叶翻动，露出叶背**密密麻麻的红点**——**九黎虫**。
- 石方面色阴沉点破其名；矮个老者道：“百粒耀金果，自然会有凶兽守护，有九黎虫，不足为奇”，随即言明**对付此虫需要两个药引**，目光落向千琴与身边白衣青年，嘴角露出残忍之笑。

## 四、崩溃：以人为药引（第510章）

1. 两长老目光交接，矮个老者大手虚空一抓，将千琴的**白衣同门**直接掷入谷内。
2. 刺耳尖音四起，谷内枯叶杂草间涌出海量红点，聚为红云、剧烈呜鸣，扑向白衣青年。
3. 红点破衣钻入皮肤，**不到三息**，一身白衣尽成血色；此人惨叫翻滚，双手撕挠全身，抓痕深可见骨，双目露出深深绝望与怨恨，继而渐渐黯淡，惨叫转弱。
4. 千琴身躯剧震、声嘶力竭质问“前辈，这是为何”，终露惨笑。

### 旁观者反应（人物侧写）
- **郭邢佚**：握紧宝剑，目光扫向千琴闪过杀机，自忖“今日之事因我而起，若千琴师兄未死也就罢了……可眼下”——已在权衡灭口。
- 称郭邢佚为大师兄的**女子**：面色苍白、捂嘴欲呕、身子轻颤，显被吓坏。
- 奉承郭邢佚的**蓝衫男子**：非但无不适，反而隐现**陶醉**之意。
- **石方**：微笑称“此一人已把绝大部分九黎虫吸引入体”，二人不必再造杀孽。
- **矮个老者**：沙哑笑称“石兄禁法神通最适合此处，可莫要留手”，并催促取果回剑宗复命。

### 断章
石方拍储物袋取出一枚**红色玉简**，左手搓指成剑，向玉简蓦然一指、口中轻吐（文本至此中断）。

## 五、看点与伏笔

- **地魔北界之变异**：无形窥视感 + 强制杀意，连婴变初期长老都近乎崩溃，而普通修士无感——暗示该界出现重大变故，或与某种非荒兽之存在有关。
- **认知落差**：王林（借涂司记忆）识得金灵根之真价值，大罗剑宗只识果子——为其后来居上取利埋线。
- **蚊兽机缘**：蚊兽对耀金果/金灵根的渴望，指向其自身的进化机缘。
- **因果种子**：千琴同门惨死、郭邢佚起杀心，仇怨已成。

## 六、待观察
- 石方红色玉简所载“禁法神通”究竟为何。
- 王林何时出手，目标是耀金果还是金灵根。
- 那股压抑杀意之源是否会在取果时爆发。

# 第510-511章 地魔北界山谷：封印白衣男子与王林屠杀

## 一、封印与清场（第510章后半）

- **「剑封之禁开」**：大罗剑宗长老石方喝出口诀，玉简嗡鸣脱手化作红芒冲入山谷，随即蠕动融化为无数红色细丝。
- 红丝首尾相连铺展成**红色之网**，把地面上轻微挣扎的白衣男子连同身边数丈之地全部包裹；石方再喝「封」，网上密布红色电光符文，形成极为严密的封印。
- 矮个老者率先踏入谷内，枯草中再度冲出少量**九黎虫**红点；他抬手五指轻弹，每弹一指便有一道剑气破空，大量红点消散。
  - 内情注解：若九黎虫数量再多，以其修为对付也会麻烦；此时所剩无几，故显得轻易。
- 石方入谷相助，数息间除白衣男子体内被封之虫外，外界之虫尽灭。
- 入谷次序：矮个老者 → 石方 → 郭邢佚的师叔（化神期老者吕松义）→ 其余诸人。千琴愤愤之色已逝，只剩令人可怕的平静。
- 矮个老者以不容拒绝的威严命令：**「吕松义，你去把耀金果采来」**——目标是数丈外那一大片金色花朵。

## 二、清风示警与灰气临谷

- 一股清风自谷外吹来，本无出奇，却令石方与矮个老者**面色从未有过的大变**。
  - 石方的感受：自进入**地魔北界**后始终存在的、如远处有凶兽的感觉，在一刹那提高无数倍，仿佛凶兽已在眼前。
- 二人戒备引动谷内气机，萧杀之意笼罩四周；吕松义停步惊疑，众人皆惊，唯千琴平静旁观（白衣男子此时已死）。
- 一团**浓浓灰气**自谷外缓缓浮现、停滞不动，看不清其内细貌。石方自报「大罗剑宗长老石方」，请对方现身说话；矮个老者一字一字问「阁下是谁」。

## 三、第一次交手：铜镜与剑影俱溃

| 出手方 | 手段 | 结果 |
|---|---|---|
| 矮个老者 | 抹储物袋祭出**铜镜**，迎风见长至三尺，散青光笼罩灰气 | 青光顷刻崩溃化作无数青痕，铜镜咔咔崩碎 |
| 石方 | 掐诀，背后宝剑呼啸横立头顶，现虚幻十丈巨大剑影，大喝「斩」 | 剑势未落即被冲破，斩下之剑溃散 |

- 灰气一动如万马奔腾、怒浪滔天，瞬间弥漫整个山谷，内中传出冰寒之音：**「萤火之光，岂能于皓月争辉」**。
- 两名长老同时口喷鲜血、爆退，在地面踏出数个深深脚印，每一步地面轻颤。

## 四、吕松义之死

- 灰气扩散时另有一道剑芒般气息射出，目标并非两位长老，而是**趁机抢采耀金果的化神修士吕松义**。
- 吕松义自知后退不及，明知**地魔北界内瞬移危险极大**仍强行瞬移，身周现扭曲空间波纹。
- 灰气一声冷哼，直接穿透扭曲空间波纹破空而入，钻进其体内；吕松义身躯如球体般疯狂膨胀至极限，**砰然生生崩溃而死**，血肉洒落一地，血雾弥漫。

## 五、王林现身

- 形貌（本片段当时）：紫衣，一头长发随意垂在脑后，面色并非英俊却有股不俗之感；右手指尖两道灰气如两条小龙般在指缝穿梭盘旋；腰挂刻着「**七**」字的**紫色令牌**。
- **收灰气**：虚空一指，碎肉中飘散的灰气凝聚成灰色球体（内里云雾缭绕，观之易迷失），随手一捏缩至指甲盖大小，握入手心即消失无影。
- 石方看令牌后一字一字道破身份：「**天运宗，紫系老七，王林**」。
- 王林开价：「回答我一个问题，今日，我放你们离开一个。」

## 六、石方的赌局与反扑

- 石方狂笑，掐诀点天，背后空空剑鞘中冲起强烈青色剑气直冲天际。
- 石方喊话要点：
  1. 王林为**婴变中期**，己方两人为**婴变初期**；
  2. 另有**大罗剑宗剑宝**；
  3. 王林即便能杀，也必受伤，将影响**半个月后的东海妖灵之门**之行。
- 石方来前已听闻今年东海妖灵之门名单中，有天运宗新收弟子紫系王林——故赌王林投鼠忌器不会轻易出手。
- 矮个老者判断相反：此人绝非顾前顾后之辈，两名婴变初期战一个婴变中期本就机会不大，废话不如抢先机。遂：
  - 拍储物袋取出**血色小旗**，一抖之下血色气息笼罩全身；
  - 双手掐诀向前狠拍，幻化数个巨大**血红手印**呼啸攻向王林；
  - 咬破舌尖喷出透着一丝金光的**元神精血**，口念鬼魅般咒语，似有无形之力自天而降。

## 七、旁观者反应（伏笔）

- **郭邢佚**：面色苍白毫无血色，身子隐隐颤抖，右手死死抓住飞剑至指尖发白而不自知。
- **郭邢佚的师妹**：惊慌不能自抑，捂嘴蹲下呕吐，面白如纸。
- **蓝衫青年**（显然并非大罗剑宗弟子）：眼中陶醉之色大浓，甚至深吸几口血腥雾气——异常，值得留意。
- **千琴**：白衣男子死后由愤愤转为可怕的平静；王林现身后表情阴晴不定，眼露犹豫挣扎之色。

## 八、待解悬念

- 王林要问的「一个问题」是什么，会放走谁。
- 千琴的挣扎所指（似与死去的白衣男子相关）。
- 蓝衫青年嗜血异常的来历。
- 耀金果最终归属。
- 半个月后的**东海妖灵之门**之行。

# 第511-512章 破天鬼吞、鞭挞元神、蚊兽吸尸——王林诛杀石方

## 一、战局开场：两名婴变初期长老拼命
大罗剑宗两名婴变初期长老联手围攻婴变中期的王林。

- **矮个老者**：念「天鬼吞」咒语，身前金光元神精血蠕动消散，其身后浮现一颗十丈大小的虚幻头颅——通体青黑、头顶无发、目似实质、森森冷芒，恶鬼之状。鬼头咆哮扑向王林。
- **石方**：右手虚空掐诀下斩，身后剑鞘内青色剑光化作狰狞青龙撕向王林；犹嫌不足，又咬破舌尖喷元神精血，抹于掌心拍向额头，天灵青光爆闪、**元神离体**，张口吐出一指长的**柳叶飞剑**，元神凝于其上，紧追剑芒电射而来。

## 二、寂灭指反噬：血手印与天鬼头俱灭
王林神色如常，脚下前踏，右手抬起虚空一按，拇指黑芒阵阵——**寂灭指**。

- **一指之下，万灵枯荣**：山谷杂草尽数焦黄，连已枯之叶与土壤深处的根部也顷刻瓦解。
- 落下的数个血红手印撞上拇指即刻涣散崩溃；更关键的是，崩溃的红色碎片本欲倒卷而回，却被寂灭指内奇异之力牵引**反向回聚于王林拇指**，拇指血色大浓——等于**吸收了血手之力**。
- 王林拇指提速越过石方剑芒，直点鬼头眉心；鬼头张口吞下其拇指。王林笑道「你既然要吞，那便吞个饱」，将吸收的血手印之力连同寂灭指内**灭绝生灵的气息**尽数灌入。鬼头暴胀、内传呜咽，退不出三丈便轰然崩溃。

**结果**：矮个老者本命神通被毁，面色苍白、喷血、身晃，惊骇遁逃。其心理动因——他曾用天鬼吞对付一名婴变中期修士，虽最终被破却过程惊险，远不如王林这般轻描淡写。

## 三、许立国出手追击（第512章开篇）
王林一拍储物袋，**仙剑**呼啸而出，内传许立国嚣张之声：「孙子，别跑，你家许爷爷让小弟和你玩玩」。随即储物袋内与仙剑几乎形影不离的**弯刀**冲出，直追逃遁的矮个老者。

## 四、四转金仙之力 + 昆极鞭：击溃石方元神
1. **硬撼剑芒**：王林抬左手，金仙之力弥漫笼罩山谷，掌心凝成金色漩涡，轻吐「四转，金仙之力」，虚空一拍。金色漩涡与斩下剑芒对撞，山谷大地龟裂、山壁碎石纷落乃至坍塌。
2. **昆极鞭破元神**：石方元神所凝柳叶飞剑直奔眉心，速度极快——文中点明，若非有昆极鞭，婴变中期的王林也不愿与「拼命元神离体融于本命法器」之人硬撼。王林右手抹过储物袋放出黑影长鞭，「啪」的一鞭抽住飞剑令其骤缓；飞剑上凝出青色火焰破空跃至王林眉心三寸处拼命，王林后退中鞭影快过闪电连挥，「啪啪啪啪」打得飞剑惨哼、涌出大量黑气，掉头败退、光芒黯淡。黑气幻化出石方之形，虚弱如风吹即溃。
3. **蚊兽毁其肉身**：石方元神欲归体，王林右手一点放出青光化作巨大狰狞妖物——**蚊兽**，以锋利口器自石方肉身天灵破入，一吸之下将血肉精华、体内残存仙力及一切可吞噬之物尽数吸干，只余一具尸骸。

## 五、当场夺舍郭邢佚与求饶交易
- 石方元神恶毒回望后，直扑远处四名晚辈（两男两女），选中**郭邢佚**：柳叶飞剑穿透其眉心，郭邢佚目光黯淡旋即复明，只是虚弱浓重。
- **王林的惊奇**：夺舍绝非如此简单，即便**司徒南**夺舍也需时日融合，而石方当面强行夺舍后竟能迅速恢复神智，且已完成大半。
- **石方求饶条件**：以本命魂魄发誓今日之事绝不外泄，愿传授**快速夺舍禁法**；并演示灭口——右手向后一拍，除处子千琴外另两名晚辈当场暴毙；又称另有**借处子疗伤**之神通，指千琴尚是处子，一并奉上。
- **千琴的反应**：身子轻颤，复杂看王林一眼，跪地请前辈杀了石方与另一名大罗剑宗长老，愿此生为牛为马伺候左右。石方面色阴沉，眼露杀机。

## 六、剑魂情报（二百年前旧事）
王林发问：二百年前**剑尊凌天候**自**雨之仙界**归来时，可有异变？

石方失声：「莫非是那**剑魂**」，随后苦涩交代（自称仅是听闻）：
- 二百年前剑尊归来后**极为狼狈**；
- 此后不久大罗剑宗出现一系列**杀戮之事**；
- 最终不知从何处出现一道**剑魂**，与剑尊一战；
- 此后剑魂失去踪影，**结果未知**。

**王林判断：此人没有说实话。**

## 七、结局：三息炸体
王林不动声色索要拓印玉简，石方连同借处子疗伤之法一并印下抛出。王林神识一扫，略过疗伤之法，凝心细看夺舍之法。石方趁机疾驰欲逃出山谷，怒喝「王林，你妄为修道之人」。

王林看都未看，左手向前一点，**指上长年环绕的灰气**呼啸破空而出；石方刚夺舍虚弱、仙力方运便被两道灰气临身，灰气钻入体内顺经脉疯狂流转，**三息之后砰然炸体崩溃**，石方彻底身亡。

## 八、要点与伏笔
- 王林手段序列：寂灭指（吸力反噬）→ 四转金仙之力 → 昆极鞭（专克元神/本命法器）→ 蚊兽（吸干肉身）→ 指间灰气（无解杀招）。
- **新到手传承**：快速夺舍禁法玉简、借处子疗伤之法玉简。
- **剧情线索**：剑尊凌天候、雨之仙界、剑魂——剑魂下落未知，为后续伏笔。
- **人物存殁**：石方（夺舍郭邢佚后）死于王林灰气；郭邢佚肉身被夺舍后同归于尽；另两名晚辈被石方灭口；千琴存活并投效求庇；矮个老者重伤逃遁、遭许立国弯刀追杀（生死未叙）。

# 第512-513章 燿金果化金灵根·蚊兽演变

## 一、开场：收尾与玉简
- 碎肉血雨落下，丝丝灰气自碎肉中散出凝成**灰色球体**，自动飞至王林身前。
- 王林自玉简收回神识，评：「这**快速夺舍之法**，倒也有些价值」，收起玉简。
- 远处弯刀与仙剑所在处，**大罗剑宗矮个老者**被困，等待问询——王林并未立刻前去。

## 二、燿金果与天逆珠子金属性
- 王林至山谷西处金色花田，摘一颗**燿金果**嗅闻。刚吞下石方肉身的**蚊兽**在半空拍翅讨好；女修**千琴**目光一凝。
- 王林先试：将燿金果按入眉心融入 → **失望**，无法增益天逆珠子金属性。
- 内心自陈：
  - 天逆珠子经**朱雀墓一战**后，只剩**金属性**未圆满，还差接近一半。
  - **七百年修行**，以其机缘也只使**四属性圆满**，每一次圆满皆凶险莫名。
- 遂虚空一抓，取约三分之一燿金果尽数喂给蚊兽；蚊兽吞下后体外金光**剧烈闪烁九下**方复原。

## 三、以玉简代兽骨的催化阵法
- 王林打出灵光照射花田使其金芒刺眼，随后取出大把**玉简**逐一刻画、布于花田四周，形如布阵。千琴不解其意。
- 依据**古神涂司**的记忆：
  - 燿金果须待自然周期度过、自然枯萎，根部方成**金灵根**；周期可长可短，甚至需数年。
  - 王林无时间等待，只能采用涂司记忆中的**折中之法**（阵法催化）。
  - 古神原以**妖兽之骨**布阵，王林以**玉简**代之，效果「恐怕会有些不足」。
- 启阵：左手摆出古怪姿态（**非修士印诀**，乃涂司记忆中的古神催化神通，为开阵神通之首），口念咒言「**殁**」。
- 阵法过程：黄芒自左手扩散 → 触及玉简即令其刺耳崩溃 → 黄芒不灭反浓，连锁击碎所有玉简 → 最终黄芒转为**金黄**，与花朵同色 → 笼罩花田。
- 结果：金花、燿金果、枝干依次枯萎，化作**金色液体**顺枝干渗入地底，历时约**半柱香**，地面空空如洗。
- 旁观反应：蚊兽连连悲鸣、不舍却因依恋王林而未抢；千琴内心滴血；王林神色如常但目光凝重。

## 四、四须金灵根
- 王林蹲身探手入土，取出**金灵根**：四根须子、拇指大小、形似人参、金光浓郁，望之全身暖洋洋。
- 判断：「四须……若是自然蕴含，应该可以达到**五须以上**」。
- 试效：摘一须按眉心 → 确比燿金果有用，可增天逆金属性，但**增幅极少**；粗略估算整只金灵根全部融入也只能增加**约一成**。
- 蚊兽与千琴皆目瞪口呆；千琴始知燿金果真正用法在于**取其根部**，此前所知不过孤陋寡闻。
