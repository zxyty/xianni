# 第八卷 联盟隐秘 第1132章 无极子

## 一、岁月：从意境到规则
- 岁月是天地规则之一，万灵可掌握，但**能明悟者极罕见**；即便明悟，通常也只是「意境蕴含」，以此感悟。
- 回忆锚点：**当年在朱雀星**，王林曾遇到一人，其意境即为岁月。当时王林便感受到此意境之强，连**云雀子**也很在意。整个朱雀星上唯有那一人拥有这种意境。
- 本章的**血龙**：其身上浮现的岁月之力**超过岁月意境无数倍，无法相比，已然成为规则**，且这规则由施展神通的血龙而定。

## 二、岁月规则降临虚无之地：无差别老死
### 罗天修士小队的覆灭（细写样本）
- 虚无中一队**罗天修士**数十人正警惕飞行，本自认只要不遇太强的上古炼气士便可立足。
- 岁月之力穿身而过，修为最弱的青年最先发作：莫名颤抖 → 寒气自体内升起 → 皮肤生皱纹并不断叠加 → 身体疲惫、修为运转停滞 → 视线模糊如隔雾 → 见同伴远离并露出恐惧，连**暗定终身的师妹**也在远处一脸惊恐 → 见自己右手布满皱纹与褐色斑点 → 双眼失去生机，头发牙齿脱落、骨头酥碎，最终堆缩成一片碎末，**老死**。
- 随后一名女子出现衰老迹象，衰老仿若可传染，队中所有修士尽皆如此。

### 规则的性质
- 如同「苍天取消了他们身为修士的资格」，取消其存活数百、数千乃至数万年的权利，把那数百数千数万年的岁月在瞬息间尽数降临其身。
- 覆盖范围为**整个虚无之地**，不论修士来自何方，只要身处其中便逃不出。
- **唯一豁免：碎涅修士**可抵抗，但碎涅修士数量不多。
- 虚无之地**外**其余关卡中未进入虚无者侥幸存活。

## 三、血龙破封
- 每一名修士死于岁月，体内便散出一股无形气息，以非修士之速（仿若本就是天地的一部分）疾驰至虚无之地中心，融入血龙体内。
- 气息越聚越多 → 血龙身上**蓝色冰晶**咔咔撕裂、最终砰然全部崩溃 → 身躯抬起，向虚空咆哮 → 上方浮现万丈漩涡，轰鸣不断。
- 漩涡中传出冰冷之声：**「吾，等你们前来」**。此声蔑视规则、不屑天道，狂意滔天。

## 四、三方逼近者的反应
| 方位/角色 | 状态与反应 |
| --- | --- |
| **尸阴宗八王** | 岁月神通对其毫无影响，如虹身影距血龙越来越近；闻声同时停步沉默，双目现不同程度的**幽芒与贪婪** |
| **黑衣老人 + 炎雷子**（相对方向） | 老人步伐不快却每抬脚一次，脚下虚无疯狂收缩；闻声脚步一顿、目露凝重 |
| **王林**（月星岩石之身） | 身子一顿、抬头、双眼露出**不屈**之色，随即冷笑迈步继续前行 |

### 缩寸成空（黑衣老人神通）
- 与「缩地成寸」的区别：**缩地成寸需融入天地；缩寸成空不需融入天地**——他所在之处**就是天地**，哪怕一界也只不过是一寸。
- 老人不急于前去，一步步保持韵律，行云流水；炎雷子跟随其后自然被笼罩在该神通之下，眼中恭敬更浓。
- 炎雷子的判断：凭**朱雀星外一枪之威**，那声音的主人足以拥有这种狂，并非妄言。他已**第二次**听到此声，本次更为清晰。

## 五、王林：石头免疫与道之感悟
- 王林此行之身**由岩石组成，岩石生于月星诞生之时**，年代无法计算。岁月之力笼罩其身，但**若没有风吹，岩石还是岩石**，故安然无恙、急速前行。
- 内心独白（两条核心感悟）：
  1. 「若没有了修士的身份，没有了神通，我们终究还只是一个凡人。」
  2. 「若今日是**本体**前来，在这岁月规则下我也会与他们一样，成为这虚无的一部分」——修道数百数千上万年、明悟天地规则的修士，有时却比不上一块石头。
- 对**拓森**的态度：不管其多强、道路多艰辛，若拓森要杀他王林，他绝不低头。名句：**「要杀我的人很多，只是眼下，我还活的很好。」**
- 目睹这一切后，他对「道」之一字又有了新的感悟。

## 六、重大设定揭示：古神之地 = 八星古神的尸身内部
- 古神之地在**朱雀星上只有一个入口**；该入口通往的古神之地，是一处**不属于这片星域的空间裂缝**。
- 裂缝极大，足够躺下一具庞大无比的**八星古神肉身**。
- **虚无、关卡，实际上都在这具古神体内**。本章王林、尸阴宗八王、黑衣老人所处的位置，即**古神的胸腔之中**。
- 该古神躯体已躺在此处无数年。

## 七、无极子登场
- 古神**眉心有八颗黯淡的星点**。
- **第四颗星点**内，放大无数倍可见至深之处**盘膝坐着一人**：
  - 中年文士，相貌平凡中透出一股**狂傲**；
  - 坐在那里仿佛已经很久很久，**始终没有动过一下**；
  - 其名——**无极子**。

## 八、悬念与后续看点
- 血龙脱困后的「等你们前来」是邀战还是诱杀，尚未揭晓。
- 黑衣老人的身份与「朱雀星外一枪之威」的关联（炎雷子恭敬相随，暗示其极为强大）。
- 无极子与古神眉心八星、与血龙/拓森的关系尚待展开。
- 抵抗住岁月规则的碎涅修士正从各方向汇聚中心，中心处将有多方混战之势。
