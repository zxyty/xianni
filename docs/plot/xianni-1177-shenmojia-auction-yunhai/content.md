# 第九卷 云海之巅 第1177章 神魔甲

## 一、相忘于江湖（王林情感线总结）

- 李倩梅离去，王林未看她一眼。对这个「同样姓李」的女子，王林没有心动。
- 王林自述心已死：死在**月星之上的仰天怒吼与悲愤呐喊**；心已被撕裂：撕裂在**罗天柳眉拿出怨婴**的那一瞬间。
- 择「相濡以沫，不如相忘于江湖」。
- 生平所遇女子盘点：罗天红蝶、西子凤、柳眉、木冰眉、吕烟菲，以及诸多擦肩而过者。**真正走进心中的只有李慕婉与柳眉**。
  - 李慕婉：生前王林不知是情，直到她死后，在千年岁月与孤独修道路上不断追忆，才终于懂了，「很深，很深」。
  - 柳眉：路径迥然不同，「很痛，很痛」，但归根结底柳眉赢了——是在王林已死的心上生生穿透伤口、撕开血肉埋进去。
- 王林情感史注脚：少年未修道时只有懵懂想象（科考成举、衣锦还乡、娇妻在旁陪伴父母到老）；**藤家剧变后性情大变**，明悟「修道唯一个强字」，一度沦为杀戮魔头，血腥更甚许多自诩魔头者。

## 二、李倩梅的身份背书

- 李倩梅离去时散开一头**蓝发**——在云海星域，蓝发者唯有李倩梅一人，等于当众自曝身份。
- 她本可不这样做，却仍这么做了：以**九阶破天宗天之娇女**的身份，与王林同坐一处石碑、受赠画轴，公开为王林的「神宗门人」身份给出答案。
- 效果：四周修士此前藏在心中对王林神宗身份的疑惑，**消散大半**，看王林的目光隐隐不同。

## 三、拍卖品之一：山石残骸（山魂）

| 项 | 内容 |
|---|---|
| 来历 | 王林在罗天一处处厮杀中崩溃的山石，事后只能凝聚出这些残骸，成为储物空间内的废弃法宝 |
| 鉴定 | 美艳少妇认出是「**山魂**」，惋惜「可惜，已经残破了」；有人指其带仙气，疑为**仙界之山**炼化而成 |
| 异象 | 王林掐诀指出禁制解封后，山石波纹回荡，散出蕴含岁月痕迹的**沧桑气息**弥漫四周 |
| 反应 | 碎涅老怪尚可，**净涅与窥涅修士目光炯炯**、盯着沉思 |

**竞价过程**：一千仙玉（人群中）→ 五千（白衣文士）→ 一万（道法门长老）→ 两万（白衣文士）→ 三万（道法门长老）→ 四万（欧阳隆）→ **一千元晶（道法门长老，成交）**。

- 道法门长老的买入理由：对碎涅修士无用，但门中小辈可借以感悟其上神通；更重要的是此物很可能得自仙界。
- 旁注：众人早在王林与宝玉宗曹姓修士交谈取出两样宝物时就看清了物件，皆知这山石是王林的；一万仙玉在云海星域已不低，且能借此与王林交好。

## 四、拍卖品之二：散魔铠甲 → 神魔甲（全场沸腾）

- 出场：宝玉宗老者取出一团黑气，隐隐化作模糊铠甲之形；满脸坑洼的老者、白衣文士等人当即面色微变，请「吕道友」开禁制细看，并点明此物属王林。
- 解封异象：黑气沸腾云涌，封印禁制层层消散，收缩凝聚成一副**漆黑铠甲**，露出滔天魔气；魔气极浓致**天地色变，天空出现一个缓缓转动的巨大漆黑漩涡**。
- 认定：「神宗魔甲」「**神魔甲**」——传说中**唯有神宗之人才可拥有**，绝少外传；因魔气极浓，众人推断为**四品神魔甲**。
- 全场反应：在场皆见闻广博、定力极强的高修，此刻定力轰然崩溃；连左前方石碑上的碎涅老怪都双眼爆出精光，多人霍然起身、面露不可置信。
- **王林自己也没想到此甲能与神宗扯上关系**，因而对云海星域的神宗升起很浓的兴趣。
- 王林开价条件：「**我只要元晶**」。

**竞价过程（全部以元晶计）**：

1. 道法门长老 3000（斩钉截铁）
2. 老妪（此前与王林交易星图者）5000
3. 白衣文士 8000（称「势在必得」，众人买它多为研究神宗神通）
4. 道法门长老 10000 —— 咬牙，已是道法门元晶极限
5. **七阶秘洛宗**黄衣青年（手持折扇、阴阳怪调）13000
6. 欧阳隆 15000（声音带颤）
7. 黄衣青年 18000
8. 欧阳隆 20000（咬牙）
9. 黄衣青年 25000（眼中寒光）
10. 欧阳隆 30000（额头泌汗）

- 道法门长老在 13000 后长叹放弃，余者亦沉默——已超出他们元晶极限。
- 冲突伏笔：黄衣青年霍然起身盯住欧阳隆，认出其身份，喝问「**你区区五阶蓬莱宝玉宗，哪里能有如此多的元晶**」，眼中闪过**杀机**。（本章至此止）

## 五、势力阶位与货币尺度

- 阶位：破天宗（九阶）> 秘洛宗（七阶）> 宝玉宗／蓬莱宝玉宗（五阶）。
- 货币：**元晶 >> 仙玉**。山石以四万仙玉出价被一千元晶压过；云海星域中一万仙玉「已经不低」，而神魔甲直接叫到三万元晶。
