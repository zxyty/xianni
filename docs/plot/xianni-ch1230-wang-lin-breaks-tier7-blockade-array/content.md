# 第1230章 强！（第九卷 云海之巅·第三更）

## 一、赶路背景
- 王林目标：八阶星域中的**风之仙界**；路线为五阶 → 六阶 → 七阶 → 八阶星域。
- 本阶段王林**伤势未愈**，但仍将速度展开到极限，星雾在其身前如被利剑穿透般向两旁横扫。
- 战略选择：不绕行、不走上阶宗派传送阵，直线穿过各宗派所在大陆的星空，避免绕路耗时。

## 二、星域封锁规则（设定要点）
- **六阶星域**：不设封锁，可自由通行。
- **七阶星域**：处于**半封锁**状态，边缘有一道环形大阵弥漫整个星域外缘，由七阶星域各宗修士在多处位置替换防守。
- 通行需**通行玉简**；硬闯者先要冲破封锁阵，且冲阵刹那即会被守阵的七阶宗派修士出手斩杀。

## 三、横穿六阶星域（近十天）
- 王林速度之快令神识无法锁定、修为难以看清，六阶星域的神通老怪纷纷退避，抱着“多一事不如少一事”的心态放行。
- 数十名六阶星域各宗老怪远远跟随，想弄清这位大神通修士的来意；初时以为只是上阶老怪回归所属星域，只奇怪其为何不走传送阵。

## 四、撞碎七阶封锁大阵
- 王林无通行玉简，临阵速度不减反增，直奔封锁阵。
- **轰然撞阵**：幽光剧烈闪烁、咔咔作响，大阵浮现无数裂缝并蔓延成蛛网状，最终轰然崩溃、碎片横扫、星雾倒卷。
- 王林身影**全程无半点停顿**，穿过目瞪口呆的守阵修士身边扬长而去，无一人敢出声。
- 跟随的六阶老怪长笑称快——他们本就厌恶这道封锁阵；同时暗自推测破阵者“修道达到了**天人衰劫**”，并评价此人性格喜怒无常、根本看不上七阶星域。

## 五、七阶星域·役灵印显威
- 刚临近某宗派大陆，即有**四股碎涅气息**化作四道神识拦下盘问：“何方道友，闯入我宗派之地，莫非就想要这么离去”。
- 王林右手一挥，幻化出可笼罩整个大陆的**巨大掌印——役灵印**；天地之力疯狂凝聚，星空雾气颤抖扭曲，浩荡天威降临。
- 四道神识惊呼「**役灵印**」「**神宗修士**」，退避不及被横扫击溃。
- 后果：该宗派所在大陆被冲击**生生震移数百丈**；东西南北四角阁楼中打坐的四名老者**同时喷血**，飞出后心生后怕——“此人之强，足以横扫我七阶星域”“一掌之下就可让我等受伤，且此人明显没有全力”。

## 六、役灵印开道
- 役灵印**不断吸收天地元力而越来越大**，气息愈发惊天动地；文中明确对照：**若换成百年前，王林已无法操控此印，眼下却仍有余力**——是其修为增长的直接标尺。
- 掌印在前开道，虚空星雾齐齐避开；途中一处**蛮荒大陆**被掌印直接穿透，**一分为二**。
- 沿途宗派望风而遁，甚至有宗派算出自家大陆挡了路线后，倾全宗之力把大陆**移开数千上万丈**让道。
- 又行近十天，王林渐渐**临近八阶星域**。

## 七、要点提炼
1. 本章为纯粹的“实力展示章”，通过三级他者视角（六阶老怪、七阶守阵修士、四名碎涅老者）层层烘托王林当前战力。
2. 「役灵印」被点名为**神宗**标志性神通，是外人辨识王林出身的关键线索。
3. 星域等级制与封锁阵的设定在此章交代完整，可作为云海星域地理/秩序设定的锚点。
