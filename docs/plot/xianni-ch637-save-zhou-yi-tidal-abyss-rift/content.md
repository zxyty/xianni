# 第637章 救周佚（第三章，万字爆发完毕）

## 一、动机：王林为何入险
- 周佚与王林并无深交，但仙界那一刻——为痴情女子情愿燃烧灵魂、眼中却清明如黑夜明月——深刻在王林灵魂中。
- 周佚曾以极珍贵的**问鼎之晶**相赠，所求仅是让王林守护那具白衣女尸；此为周佚死前一生的全部。
- 周佚死后化作**雨之仙剑的剑灵**；然而白衣女尸体内因他而生的残魂却烟消云散，周佚闻听「全世界碎裂」之声，心死之下带无生机剑气追出虚空，誓斩凌天候——实为寻死。
- 王林一生见证修真界残酷，所遇多为各怀心思之人，真正记在心里的只有：**司徒南、遁天、叱虎、周佚**。
- 当年周佚面前，化神期的王林只是不起眼的小辈；今日王林已踏入**问鼎期**。
- 心念：「人之一生，该做之事，必须去做，若瞻前顾后，即便万年而亡，也是混沌一生。」对照当年**救十三、只身战妖将**。

## 二、闯裂缝：三波神念与三层消耗
裂缝内留有**剑尊凌天候的神念**，霸道蛮横、化实质如利剑，随王林每进一步而加剧。

| 波次 | 凌天候神念表现 | 王林所耗手段 |
|---|---|---|
| 第一波 | 利剑刺来 | **十亿尊魂幡**上亿魂魄凝成魂幕，被直接穿透；金色符文凝聚全身、白色电光在金符飞虫体内游走，大半飞虫僵硬掉落收回储物袋 |
| 第二波 | 奔雷回音相叠，如天威之怒横扫 | 魂幡再破，神念印在**魔甲**上，魔气崩溃；王林生压「不退即亡」之感 |
| 第三波 | 更浓，隐约传出凌天候低吟如咒语 | 十万**生之烙印**瞬间化百万硬抗，瞬息崩溃 |

### 散魔之魂首次放出
- 王林元神内**加深百年烙印的散魔之魂**第一次放出：头生单角、通体漆黑，魔音狞笑，眼中浑浊。
- 尚未把烙印完全稳固，**第二元神未成**。
- 魔甲上涌出前所未有的无穷魔气钻入魔魂，使其由虚化实；魔魂一口吞下凌天候神念，体内爆发风暴气息，霸道意境窜动，魔目闪过一丝挣扎的**清明**。
- 王林元神震动察觉不稳，神念透眉心牵引近百年的烙印，将魔魂吸回眉心；魔甲亦受牵引化作黑丝收入储物袋。此后王林一步迈出十丈。

### 转守为攻
- 祭出**射神车** → 化作**雷兽**，撞上神念，浑身雷光如雷球，边战边退，为王林争取补满百万生之烙印的时机。
- **寂灭指风**：黑芒如箭矢连发。
- **化魔指风**：仙力逆转为魔气，经元神内散魔之魂气息融入化为极精纯魔气，一次射出**十道**。
- **道化黄泉**：四周横卷，王林脚踏黄泉再进数步。
- **杀戮之气**：百万生之烙印转化，仅留一道藏于元神，其余尽数化作一道冲出。
- 最后雷兽化作巨大雷电，随诸神通一同冲向凌天候神念。

### 两个关键设定点
- 因当年**四滴仙液**，王林体内仙力多年来即便无仙玉补充亦如生之烙印般生生不息、从未减少。
- 王林**绝不动用**体内凌天候的剑气：面对凌天候神念时一出现便会被其夺走。

## 三、余波：三处观测
1. **潮汐深渊内**：整个深渊颤动，深渊之壁泥土碎石脱离漂浮；水妖郡入口处闷声连串、地面震动。
2. **深渊下方**：慕容卓与赵、徐二女感受到可怕波动；徐飞倒吸凉气，心底那丝「被王林毁去神识」的不忿消散，认定此人不可招惹。
3. **深渊底部回廊**：呈「回」字形，中央为通向未知去处的黑洞，外围为回廊之路。回廊一处插着一把**半截剑身入地的大剑**，波纹扩散时**略有松动**（伏笔）。
4. **火妖郡出口下**（大罗剑宗被蚊兽与黑雾困住的空地）：一直闭目的**贪狼**睁眼爆出精光，辨出「凌天候的气息，但只是一部分」，另有一股陌生气息，怀疑对方亦为**令牌**而来；扫视身边大罗剑宗弟子后佯装无事再度闭目。除他之外无人察觉。
5. **大罗剑宗**：一身道袍盘膝打坐的**凌天候本尊**，双眼蓦然开阖。

## 四、伏笔
- 回廊大剑松动 → 潮汐深渊底部的真正机缘/危险。
- 贪狼已警觉，且亦在争夺令牌。
- 凌天候本尊睁眼 → 其可能提前到来。
- 散魔之魂烙印未稳、第二元神未成 → 后续隐患。
