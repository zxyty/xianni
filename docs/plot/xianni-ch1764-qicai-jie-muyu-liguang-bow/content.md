# 第1764章 七彩劫！

## 一、目鱼出世

- 黄沙如雨落下形成沙幕，地底传出疯狂咆哮，修真星剧烈震动，王林前方数千丈黄沙凹陷，一条蛇状巨兽自地底冲出。
- 此兽身体数千丈粗细、通身覆土，形如巨大泥鳅，大口占据整个头部；双眼始终闭合，若身外再生触手则与「望月之丝」略似，但终究大不相同。
- 掌尊与玄武战将等人一眼认出：此为**目鱼**——「仙罡有兽，其名目鱼，此鱼初生直至死亡，双目永久闭合，没有睁开的一日；但有传言，一旦目鱼开眼，则天地色变。」
- 掌尊倒吸凉气：此地有凶兽早有察觉，但没想到是**未受任何限制、无数万年不断成长至今的目鱼**。

## 二、七彩道人对战目鱼

1. 目鱼张口扑向七彩道人，七彩掐诀一掌轰在其头部，将其轰开百丈。
2. 目鱼头部扭曲收缩后猛的一吸，**吸走七彩道人体内大片七彩光芒**（化作烟丝之物），七彩面色一变，三大战将等亦神色剧变。
3. 目鱼最为记仇，再次疯狂扑来。七彩道人杀机大盛，右手指天低喝「**力拔山兮**」，天幕内凭空出现一只七彩巨手，一把抓住目鱼向上猛拽，将其数万丈全身自地底彻底拔出，狠狠甩砸于地。
4. 修真星因此出现无数裂缝几近四分五裂；目鱼皮开肉绽、紫血喷洒，哀嚎中双眼颤抖欲睁却终未睁开——似有**一股无形之力限制其身**，令其无力开目。
5. 目鱼哀嚎引动全星震动：此星八方黄沙鼓起如八条山脉极速逼近，崩溃后飞出**八条数万丈目鱼**。至此确认：此星共有**九条目鱼**（含重伤趴伏的第一条），八条环绕七彩道人八方张口吞噬。

## 三、王林的李广弓——本章高潮

- 王林已收走**第三魂**，右手紧握**李广弓**端坐如石像，抬头盯天，一动不动——他在等一个「惊天地、泣鬼神」的出手机会。
- 八条目鱼吞噬七彩的刹那，王林起身拉弓如满月，箭矢幻化于弦上，毁天灭地之气爆发。
- **第一箭**：撕开虚空天地，直射七彩。掌尊面色苍白急退（他曾被此箭杀死两次，刻骨铭心）；三大战将头皮发麻。
- 七彩瞳孔收缩，全身七彩之芒疯狂笼罩护体，李广箭仍冲入光芒轰入其身；**修真星直接崩溃、四分五裂**，碎石倒卷。
- 王林后退、嘴角溢血，但死死握弓；三大战将被箭出波纹扫中，齐齐喷血后退于星空之中。
- 八条目鱼被逼退千丈、紫血弥漫；七彩身外光芒扭曲黯淡，胸口染血，李广箭刺入胸口但被其抓住箭尾未能穿体，七彩狰狞地将箭猛拽而出，鲜血喷洒。
- **转折**：正当七彩拽出箭的一刹，八条目鱼齐发震动星空的嘶吼，**始终闭合的双眼全部睁开了一丝**，露出黑芒；八兽如发狂般被黑芒环绕，气势如虹远超之前，再度扑向七彩。
- 王林不假思索，弓换左手，双目微弱金光一闪，**第二次拉开弓弦**（七彩手中之箭随即消散、重现于王林弦上），右手一松，第二箭如长虹而去。

## 四、旁观者：五行星一方

- 五行星以**马姓老者**为首的数人立于远处，未参与这场杀戮。
- 马姓老者首次目睹李广弓，瞳孔收缩露出骇然，悟到：「李广弓居然在他手——我明白了，他之前去五行星，除了依持天道外，更大的依持，就是此弓。」
- **云逸封**表面平静、右手紧握以掩内心惊恐，庆幸当初在五行星没有逼王林拿出此弓，自认对此弓**没有半点把握可以抵抗哪怕一弓之力**。
