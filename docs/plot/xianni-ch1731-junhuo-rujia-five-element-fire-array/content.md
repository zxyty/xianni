# 第1731章 君火如家！（第一更）

## 一、收走五行大地土灵

- 五行星外五道光环交错，外界只见五行光芒扭曲、波纹回荡，难窥其内。
- 王林立于光环深处，神色如常。右手手心一小撮沙土不断自行改变形状、幻化组合，试图挣脱；王林右手一握，沙土崩溃消散，被其收入储物空间。
- 该沙土为五行土属性所化，**隐隐直指本源**。收起后，王林储物空间内已存**两撮沙土**，另一撮**来自天运子**。
- 王林评价：此阵为**仙罡大陆来临之人**的手笔，把五行大地之灵凝固于此、融成阵法；若再过数万年，此灵成长之下或可成为**第三步五行土灵体**。他对该阵法兴趣更浓。

## 二、王林的图谋：五行归一

- 五行本源中，王林已拥有**火本源**。他盘算若能尽得其余四种，修为定会暴增；且一旦**五行归一**，或可诞生出新的本源。
- 行事逻辑：对敌人、尤其是非洞府界且包藏祸心者，王林从不讲道义——实力就是一切。对方若有留下他之力则罢，若无，则这群外来人在他家中便是强盗，而“对于强盗，王林要比他们更强盗”。

## 三、踏入五行火阵：君火如家

- 前行一步，眼前是一片火海世界：天红、地红，皆在燃烧，高温扭曲目光，毫无生命迹象。王林置身其中反比外面更舒服。
- **九头火焰麒麟**自火海幻化而出，高约数百丈，全身火焰，脚下各有数个火焰球，自九个方向咆哮扑来。
- 九麒麟临近王林身前**十丈**时齐齐停顿，目露疑惑，随即甩头匍匐于地、发出呜呜之声，如小猫般欢喜，仿若遇到主人。
- 王林右手抬起向下一按，全世界火焰疯狂凝聚，化作**数千丈大小的火焰巨人**：着火焰铠甲、披火海披风，发丝亦为火焰。巨人向王林**单膝跪地、双手放胸口**，面孔透出狂热崇敬。
- 全程王林**未说一句话、未施展任何神通**，只是站在那里——如君王来到自己的国土，一个目光便令子民尽皆跪拜。

## 四、五行星/归一宗一方的反应

- **信息盲区**：五行星之人早已内部封锁、轻易不外出，关于王林的身份与大致修为，多是从无意传入的界外修士处得知，事后才派人外出查探补全；**王林拥有火本源之事他们并不知晓**。
- **战前误判**：高塔中下端层的黑袍老者认为火焰足以焚烧一切修士身躯与元神，王林在火阵内绝不会轻松；中年女子眼露恶毒，断定王林必将受伤——她**恨司徒南，更恨一切与司徒南相识之人**。同层另二人沉默忌惮，不再置评。
- **观阵手段**：黑袍老者所在层有巨大镜子映照阵内；高塔外围天空有巨大漩涡回旋，折射阵内画面，归一宗散出的修士齐齐仰观。
- **结果**：火灵跪拜的一幕令黑袍老者面色苍白、脑中空白；中年女子面色惨白、张口无言，眼中只剩挥之不去的恐惧；塔外归一宗修士尽数愣住，一片死寂沉默。此事超出其想象与理解，引发强烈恐惧与不安。

## 五、纳多与中年男子的对策（高塔第十层）

- 纳多眼皮跳动、神色阴沉，与中年男子对视皆见忌惮。二人看出端倪：
  - “**火本源**”，且是**达到至极状态、成为万炎之主的火之大成本源**——否则已凝聚成人形的五行火灵断不会如此膜拜崇敬。
  - “**五行阵，困不住他**。”
  - 王林不会主动出阵，其打算是**收走五行全灵**。
- 中年男子：应将其引出，否则其余五行三阵损失不起。遂低吼“**请先祖战甲**”，第十层蓝光凝聚，一副**水蓝色铠甲**（散出水浪波纹）覆于其身；右手虚空一抓，水浪化作**巨大长枪**握于手中。
- 计划：下一阵为**五行水阵**，他先行前往，看能否将王林逼出阵法、**直接进入九转之内**；请纳多**压阵**。言毕化作水汽消散。
