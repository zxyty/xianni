# 第2023章 冲冠一怒！（二）

## 一、皇城宴：一句「婉儿」

- 凤袍女子（道古皇尊数百年选妃所定之妃**宋致**）不喜热闹场面，尤其不适王林的目光，内心却有说不清的**刺痛**，细想只余迷茫。
- 她起身，身侧幻化一道虚影恭敬递上酒杯并随行，二人走出大殿来到王林案几前。
- 王林低头已饮七八壶酒，抬头见她，眼前又有模糊。女子欲开口，王林先问：「你会弹琴么」——问罢自嘲摇头，起身以酒壶与其杯一碰，饮尽整壶，转身化长虹冲天而去。
- 洒落酒珠有一滴落在女子脸上，**很凉**。
- 王林远去时留声：「婉儿，你的魂，到底在何方」。此声悲切，广场、平台一部分人与殿中**道古皇尊**皆闻。
- 皇尊闻言，嘴角微笑更浓，举杯轻抿。
- 无人看见：宋致听到「婉儿」二字后身子蓦然一颤，眼中露出**挣扎与迷茫**，但挣扎很快消散，神情转为**空洞**，转身走回大殿。

## 二、木屋独坐：数千年的自我欺骗

- 王林在灯火通明的道古皇城中默默前行，泪水滴落。心中长年被冷漠与生存覆盖的哀，因那熟悉气质再也掩盖不住。
- 他回到**道吉殿**自己的木屋，关门呆坐，无心修炼，无心去看地底洞府中的**大天尊之阳**。
- 内心独白：「我有通天的修为又如何」「我有逆天的意志又怎样」「我即便是道古一脉的守护者，可我却找不到婉儿的魂」。
- 他承认：一直用修为提升麻醉、欺骗自己数千年；直到在皇宫第一次见到与婉儿神似的宋致，追忆再难自控。
- 自我压制：「这世间竟有气质如此神似之人……可她却不是婉儿，她是宋致，我曾经在**黑石城**外看到的那个女子」。平静之下，哀伤依旧缭绕。
- 他挥手显出**五行真身**重叠虚影，包裹中间**金本源**光团，光团内隐隐坐着金本源将要凝聚出的模糊真身，欲以修炼止忆。

## 三、四个疑点：不对劲

闭目刹那，王林猛然睁眼，目露滔天精光：

1. **前后差距**：黑石城外初见宋致时，此女寻常、平凡，虽有宁静但绝无今日之感；若她当时就如皇宫中那般，他不可能毫无察觉。
2. **选妃之谜**：道古皇尊选妃**数百年**，最终选中容颜并不绝美的宋致——皇尊到底在选什么样的妃子？
3. **心绪异常**：他前往皇宫后**心烦气躁**，看道古皇尊便起**杀机**；而宋致一出现，这种心烦刹那消失。
4. **神识无果**：他曾以神识查看此女，一切如常、毫无端倪，唯有神识气质令他熟悉。

王林心神颤抖、头发无风自动，激动、迟疑、不解与迷茫交融，内心火焰压抑欲爆。

**克制的理由**：他恨不能立刻冲入皇宫擒住皇尊搜魂拷问，但**不能**——他是**玄罗**的弟子，玄罗是道古一脉守护者，对他有大恩、有师尊之情；无证据便去擒杀皇尊，他过不了自己这一关。

## 四、推衍玉简：真相

- 王林虚空一抓取出一枚**黑色玉简**，散发幽暗之芒，看之一眼似会被吸摄心神。此简来自**大魂门老祖**（为族群算计一切、最终取出心脏与脑、跪在王林雕像前哀求原谅的悼亡族一代天骄），赠时言：「这玉简，可以帮您推衍一次未来的变化」。
- 王林不假思索捏碎玉简，念咒后掌心黑气化作黑色小人，向他跪下**磕头九次**，脑海轰鸣，推衍景象展开：
  1. **洞府界**中，一只**晶莹的手**自天道众生中**取走了李慕婉的残魂**。
  2. 密室内，一个全身**七彩笼罩**的模糊虚影两指捏着一枚珠子，珠内正是闭目颤抖的李慕婉残魂；虚影向身前一脸震惊的**皇袍男子**低语一番。
  3. 皇袍男子一脸惊喜带走此魂，用**数百年**时间不断选妃与之融合，均告失败；最终一名熟悉女子——**宋致**——与此魂融合成功。
  4. 宫殿内，皇袍男子右手捏着这女子的脸颊，昏迷中的她痛得流下泪水。
- 那皇袍男子，**正是道古皇尊**。

## 五、冲冠一怒

- 王林猛睁双眼，目通红、头发疯狂卷动，怒吼：「**烨道，我要杀了你**」。
- 此吼足以撕裂九天、轰灭皇权，蕴含不惜毁灭天地、不惜自身生死、不惜放弃一切的决然与愤怒，是王林出生以来最狂暴的一声生命之吼——**冲冠一怒**。

## 六、要点索引

- 宋致 = 融合了李慕婉残魂之体，故其气质令王林熟悉；其「空洞」反应与心烦感的消失，均为残魂所致。
- 李慕婉残魂链条：洞府界天道众生 → 晶莹之手取走 → 七彩虚影转交 → 道古皇尊数百年选妃融合 → 宋致。
- 王林当下身份：**道古一脉守护者**、玄罗弟子；因师恩而暂时克制，未即刻动手。
