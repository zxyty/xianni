# 仙逆 第1013章 魔影（第八卷 联盟隐秘）

> 语料位置：00939-00940 之2。

## 一、开篇设定：青霖的第五座洞府

- 仙灵天境第五座洞府 = 仙帝**青霖**闭关之处，其存在形态、乃至大小，均无人知晓。
- 当年**唯有青霖一人**可以进入，外人不得入内，**违者必死**。
- 连其女**青霜**此生都未踏入过半步——此地为青霖**绝密之处**。

## 二、传送与落地

1. 仙灵天境空中紫光消散，所有人失去踪影。
2. 王林在紫光中感到**身体被打散、化作无数碎片**，感觉诡异但毫无疼痛；仿若时间永恒，实则只是瞬息。
3. 落点为一处陌生之地：
   - 一片**黑沙**，一眼看不到尽头；风声呼啸，沙土无意识移动、相互旋转如旋风一扫而过。
   - 天空昏暗，**仿佛一道灰幕笼罩**，久看则心生压抑。
4. 王林散开神识——那可覆盖整个妖灵之地的神识，**在此探不到边缘**；范围内天地间只有他一人。
5. 判断：进入此地的所有人**全部被分散开**，彼此很难遇到。

## 三、灰气之战（愈打愈强的诡异之物）

### 交手过程

| 阶段 | 王林手段 | 灰气反应 |
|---|---|---|
| 飘升不足十丈 | 右目青光一闪，**青光盾**护前 | 一道灰气自天而降，撞盾将王林震退十丈 |
| 第一拳 | 右手握拳，**古神虚影**在身后幻化，蕴古神之威 | 灰气崩溃，却即刻化作**数十道**更磅礴灰气，自数十方向围攻 |
| 退至千丈外 | 口吐**元神之气** + 第二拳 | 十多道灰气崩溃，随即化作**数百道**，弥漫天地如条条苍龙 |

- 关键观察：第一拳反震之力不大，**第二拳反震极大**，右拳酸麻（虽很快消失），王林**不敢再出第三拳**。
- 转为纯守：青光盾环绕全身，在黑色沙漠中一路直线逃遁，身后沙地被划出长长痕迹。

### 此地的空间禁制

- **瞬移：完全无用。**
- **缩地成寸：可以施展，但无论如何施展，踏出之地都只有一寸。**

### 仙术神通「呼风」→ 灰色漩风成型

- 肉身之力无法摧毁此物，王林改用仙术神通，一指天空低喝「**呼风**」，浓密黑风化作**四头黑龙**。
- 黑龙一出，大半个天空涌出数之不尽的灰气，形成**连接天地的灰色漩风**，一扫便把四头黑龙卷入其内。
- 漩风持续吸纳灰气而膨胀，最终近**数千丈**大小，直追王林；
  - 王林能感到身后**丝丝吸力**；
  - 更骇人处：漩风**所过之处无时无刻都有灰气从天地间散出融入其内**——越追越大。

## 四、脱身尝试

1. **古神之鼎**：身外幻化古神大鼎，古神之力弥漫全身融入鼎内，一闪即出现在百丈外。
   - 判断：百丈对漩风而言只是刹那，即便连续施展、不惜消耗古神之力也不够。
   - 结论：**必须让漩风停止**，哪怕短暂停顿，才有一线希望。
2. **大剑剑阵 + 剑爆**：右手拍储物袋，放出数十把大剑结成剑阵迎向漩风；大喝「**剑爆**」，一把大剑散发毁灭性气息轰然炸开，四周所有大剑几乎同时崩溃。
   - 效果：无数碎片横扫冲入漩风，使**漩风之速略有一顿**（王林由不得心痛）。
3. **借停顿连闪九次**：古神大鼎在极短时间内连续九次闪烁，王林抵达近千丈外——但漩风一顿之后又再度追来。
4. **结尾**：王林一脸苦涩，咬牙右手虚空一抓，身前裂痕蓦然出现，随手抓去，**虚幻的灭神矛**在阵阵**黑色弧形电光**中幻化而出。

## 五、要点归纳

- 灰气的机制是**分裂式增殖 + 反震反噬**：物理/肉身打击越强，分化越多、反震越大，本质上不可强攻。
- 此地对空间类手段有针对性压制（瞬移废、缩地成寸被锁死一寸），只有**古神之宝**的百丈闪烁仍可用。
- 王林目前可动用的底牌层级：青光盾（右目）、古神虚影拳/古神之力、古神之鼎、元神之气、呼风、剑爆自爆流大剑、灭神矛。
- 本章为纯生存追逃章，未有他人现身，悬念落在灭神矛能否破局。

## 归属说明（据世界状态须知）

# 第1014-1015章 追！（二合一）·第八卷 联盟隐秘

## 一、灭神矛破旋风，反致旋风分裂
- 王林手握**灭神矛**向后猛抛，矛瞬息临近旋风并直接穿透，其上**毁灭性气息**轰然爆发，巨响中天地震动，**旋风崩溃**。
- 借此时机，王林毫不犹豫连续施展**古神之鼎**闪烁移动，一口气开启数十次。
- 但身后一幕使其面色苍白：崩溃的旋风与灰气一样，转眼化作**十多个同样大小的旋风**，呼啸追来。

## 二、王林的判断：这是无解之局
- 想尽一切方法都无法使旋风消散，**越攻击旋风越多**——王林一生征战无数，第一次遇到此种现象。
- 以其修为一眼看出：**这旋风不是虚幻，每一道都是真实**。
- 王林的内心结论（原文近似）：
  > “不能打散，更不能施展法宝，连神通都不能施展，一旦这旋风再次崩溃，立刻就会化作数百，到时候如何能避。”
- 旋风越追越近，且**不断吸收天地间涌现而出的灰气**，无时无刻不在壮大；即便以古神之鼎，也只能保持距离片刻，时间一长距离很快被拉近。

## 三、古神真身再现，硬抗旋风
- 决断：“既然不能避，就硬抗。”王林索性停下，不再给旋风继续壮大的时间。
- 停身刹那，**古神之力**轰然弥漫全身，体内传出砰砰之声，身体无限胀大——**古神真身，再次出现**。
- 形态：**数百丈的身子**，似乎可以一手支撑天地；**眉心之上五个古神星点环绕**。
- 十多道旋风呼啸而来之际，王林**一声怒吼惊天**，不去逃遁，反而迈步、身外古神大鼎一闪，整个人蓦然消失，出现在**最前方的一道旋风之前**。
- 关键选择：身子刚一出现，王林目光一闪，低吼中**索性并未调动青光盾**，而是**直接以肉身硬抗旋风**（此前已有“旋风不能以力毁灭”的教训）。

## 四、并线：仙灵天境第五座洞府深处
- 场景：**仙灵天境第五座洞府**深处，有一座**木制的桥**，**桥下流淌黑水**，水中时而有**狰狞的幽影**漂游而过。
- 桥上盘膝坐着一人：
  - 看不清相貌，隐约似**全身穿了一身铠甲**；
  - 被**浓郁至极的黑雾**弥漫，透出**阴森的魔气**，魔气之浓使其所在之处**仿若魔域**；
  - 身体一动不动，始终盘膝。
- 其身前漂浮着一个**小瓶**，**瓶口有木塞封住**，看不到其内所装之物。
- 该人影缓缓睁开双眼，露出近乎疯狂的**嗜血**之色，舔了舔嘴唇，以沙哑中仿若骨头摩擦的声音自语：
  > “到底谁，会是第一个出来……不知有多少年，没有品尝人的血肉了。”

## 五、要点与悬念
1. 旋风机制被明确为“分裂型不可破”：任何物理/法宝/神通打击都会使其倍增，唯一可行路径疑为**肉身承受**或另寻他法。
2. 王林的古神体系再度作为底牌登场：**古神之力 → 古神真身（数百丈、五个古神星点）+ 古神之鼎（瞬移）**。
3. 洞府魔气之人构成新的威胁伏笔：其等待“第一个出来的人”，暗示洞府试炼出口处有嗜血伏杀者，且其身前**封口小瓶**为未解之物。

# 第939章 黑沙荒漠旋风试力

## 场景
- 地点：四周平坦的**黑沙荒漠**（黑色沙土、天地可被扬沙遮盖），环境让王林联想到**当年的古神之地**，须极为谨慎，一个错误即引杀身之祸。
- 动机：王林欲比较「旋风之力」与自己「古神真身」的强弱，故**以身试力**。

## 过程
1. **单道试身**：旋风速度惊人，刹那临近并轰然卷在王林身上。近距离如被巨浪拍中，浪中更有磅礴狂风撕扯全身，欲将其四分五裂后融入旋风。整道旋风落体、不断撕扯中融入体内，砰砰巨响回荡，王林后退三步。
2. **古神之鼎闪避**：退后刹那，体外**古神之鼎**一闪，王林身形消失、出现在百丈外，避开**四道**旋风冲击。
   - 结论：寻常修士在此旋风下必定四分五裂，连元神都无法逃出；即便古神肉身也感到疼痛。旋风来历不明。
3. **青光盾迎击**：**青光盾**幻化百丈大小环身旋转，王林判断「古神肉身 + 青光盾应可化解」，主动冲向旋风。
   - **三道**最快旋风撞上青光盾，盾闪烁，无法想象的反震之力迫其后退。
   - **九道**旋风接续冲出撞盾，王林一退再退、仿若没有止境；九道全部消散时已不知退出多远。
   - 尽管有青光盾阻挡，身体剧痛仍让王林额头冷汗——他此时的古神肉身**仅是五星**。
4. **十五道连串的收尾**：最后**十五道**几乎连成一串直奔而来，速度之下即便以古神之鼎也无法将其分开躲避。十五道同时撞盾、全部消散，化作毁天灭地之威，青光盾被蓦然压下、几乎紧贴身体。

## 结果
- 王林身子一震，一口鲜血涌出但**生生压下未喷出**；如断线风筝向后猛抛，数千丈外轰然落地。
- 环形冲击掀起大片黑色沙土升空遮盖天地，许久方散；地面留下**巨大深坑**。
- **古神肉身缩小化作常人**，王林苦笑、挣扎站起走出深坑，望着黑沙荒漠深深呼出一口气，眼中**犹有余悸**。

## 王林的战力认知（本章定位，随后续章节可变）
- **五星古神肉身首次受到如此伤患**。
- 若旋风**再给它一次分裂的机会**，「今日，我抵抗不住」。
- **分身与本体融合后可与净涅修士一战**；原以为除**净涅后期**与**碎涅老怪**之外自身已足够安全，尤其古神肉身强悍至极——此刻这份安全感被打破，重新感受到危机。

## 悬念 / 待解
- 旋风的本质与来历未明（「这旋风，到底是什么」）。
- 旋风具备「分裂」机制（三→九→十五的递增分裂），分裂次数与威力上限未知。
- 黑沙荒漠与古神之地的关联性尚未揭示。

# 第940章前后：黑沙荒漠半年独行

## 一、自省与重拾谨慎

- 王林自承「最近有些太安逸了」——修为提升、**分身与本尊的融入**，使其谨慎不如以往。
- 经黑沙荒漠此番危机（灰气袭击）后，眼中重现久违的谨慎之芒。
- 定性所处之地：**仙帝青霖洞府**，「危机四伏，决不能有半点疏忽」。
- 行动调整：**神识不再全部散开**，只小心翼翼在身边缭绕，缓步前行。

## 二、灰光试探：以魂魄作替身

1. 推断：灰气的出现虽有偶然，但很大程度由**自己散开神识**引起。
2. 明悟：若再次散开神识，来的恐怕不是可抵抗的灰气，而是「另外之物」。此感来自一千多年修道中感悟天地而生的**一丝神念**。
3. 实验设计：
   - 拍储物袋取出**尊魂幡**，抖开幡布，从中抓出一个魂魄（一脸厉色、已被炼化无神智，恭敬飘于身侧）。
   - 右手点其眉心，**留下些许神识**。
   - 身形一晃远离，一炷香后距离已远。
4. 结果：神念一动，魂魄处的神识散开——**瞬间强烈危机涌入心神**，王林不假思索切断联系。断联一刻隐约见：天空风起云涌，**一道灰光从天而降**直落魂魄，魂飞魄散。
5. 评估：冷汗泌出、头皮发麻；那灰光虽瞬间消失，但「比数十道漩涡加在一起还要可怕无数倍」。所幸切断及时，自身所在未引起变化。

**结论（可复用规则）**：在此地散开神识 = 招引灭杀级天罚；升空同样禁止（魂魄升空过二十丈即无声崩溃）。

## 三、黑沙荒漠环境志

- 无昼夜之分，天空永远灰蒙蒙，仿若尘暴弥漫。
- 无植物、无任何有生命之物；一个月内未见一人。
- 满目光秃秃黑沙，久视则心境阴暗。
- **魔化效应**：长居者心神充满阴暗、渐染元神、性格戾气、近乎魔化；对魔修则如圣地，修为增长，但终将元神彻底魔化，沦为无意识的**魔人**。
- 王林面部隐有黑气流动，但**双眼一片清澈**（未被侵蚀神智）。
- 危机感不随时间消散，反随深入而愈浓。

## 四、魔气的发现与利用

- 王林抬右手在脸上一抓，抓出丝丝黑气融于掌中，辨明为**魔气**，并在其上感受到「当年散魔的气息」。
- 捏碎黑色气团，黑气弥漫方圆百丈后消散——王林双目转为灵动：「**或许可以这样**」，由此定下某种以魔气为凭的计划（本段未明言用途）。
- 随后不再驱散，任魔气浸染：两个月时全身黑气浓郁、略显消瘦如一尊魔神；半年后**魔气滔天，如黑色火焰在沙漠中燃烧**。

## 五、来自暗处的窥探：神识计数

- 数次感到轻微神识波动如风掠过，遍查不得其本体。
- 两个月内累计**九道神识**，且九道**各不相同**——即九个不同的人。第九次时神识三息后收回，王林佯装未觉，自语「**还不够**」。
- 半年后**第三十二道**神识扫来，王林猛然抬头、目露寒光：「第三十二道……我的魔气，也足够了。」
- 判读：王林在刻意**养魔气以伪装/融入**，等待「够」的时机，条件已成熟（下文将启动其计划）。

## 六、旁及

- 念及**司徒南**（文中称「司徒」）：其所修近乎魔道，若处此环境「定会有所收获」——暗示两人此刻分处不同区域。
- 孤独耐性：此地半年独行足令寻常修士发疯，而王林认为不及**数十年打坐**、更不及当年**古神之地的百年**。

# 第939章 半年蓄魔气·魔影吞神识与血遁追踪

## 一、局面：黑沙荒漠中的半年蛰伏

- 地点：黑沙荒漠。王林被困其中，欲离开，而**一道道扫来的神识就是关键**。
- 限制：在此地他**不能以神识去追踪**——虽不知为何对方散开神识不会引起变化，但王林不敢尝试（半年前实验时，有一道**灰光从天而降**，记忆犹新）。
- 于是只有忍、只有等：**蛰伏、积累、观察半年**，默默等待因环境自然形成的魔气积累，期间时刻谨慎，**不能让魔气融入元神**。
- 时间压力：他没有数十年可等——若真如此，「别说去帮助周佚，就连司徒南，王林也无力去解毒」。

## 二、半年前的关键发现（本章回述）

1. 王林发现体内凝聚出**一丝魔气**；
2. 魔气被捏碎后立刻**环绕百丈**；
3. 该百丈范围内当即处于一种**「空虚」状态**；
4. 他在这空虚中隐约明悟，尝试散开神识，竟**毫无阻挡弥漫百丈且未引起任何变化**。

→ 这一发现为茫然中的他「打开了一道大门」，成为整个计划的基石。

## 三、代价：以化魔指换速度

- 为积累更多魔气、缩短时间，王林毅然选择**化魔指**，**每天无数次施展**，使吸收魔气之速如同真正的魔修。
- 依据：他**本就不是正道修士**，一千多年修道**正魔兼具**；且**化魔指一出，会让自己在那一瞬间沦为魔修**——以极端之力，施展无上神通。
- 正常而言，欲得此等庞大魔气**最少要在此吐纳数十年**。
- 代价：
  - **形貌大变**：长发如墨、无风自动；容颜深深凹陷、乍看如皮包骨；眼眶凹陷且有**丝丝黑色血管**浮现；一股**戾气**缭绕气质之中，看去已不像正常修士，更像一尊魔修。
  - **身有魔念**。

## 四、三步计划的执行

### 第一步——爆发吞噬
数息后，**第三十二道神识**极快收缩，临近王林刹那，其全身魔焰轰然爆发：魔焰滚滚冲天，如黑焰吞天，在半空**化作巨大魔影**向缩回的神识狠狠一吞。
- 结果：神识**一部分被魔焰生生吞掉**；王林清晰感受到**一股冰冷的元力顺魔气涌入心神**。
- 残余神识急速收缩，以不知何种方法从魔焰下逃遁，眼看要远远离去。

### 第二步——魔气崩散、笼罩数十万里
王林双臂蓦然伸开，一声忍了半年的低吼轰出，体外全部黑雾魔气如风暴般轰出升空、疯狂凝聚，转眼弥漫方圆数百丈；随后爆喝一声，旋转的魔气**如半年前手中的魔气小球一样轰然崩溃**，向四周极速扩散，**瞬间弥漫方圆数十万里**，将那道神识笼罩其中。
- 附带效果：黑雾散尽，露出被掩盖半年的真容（见上「代价」）。

### 第三步——身随魔气、极速追踪
- 右脚狠踏，地面轰出深坑，王林如闪电、化作流星直奔前方，速度达到**此生最快**；
- 面部黑色血管蠕动，体内魔气不断散出，右手掐诀，**一指化魔**指向天空，**操控天空魔气**减缓其消散，使自己始终处于魔气环绕之下；
- 神识在魔气环绕内散开、弥漫数十万里锁定对方神念，随魔气消散与距离缩短而渐渐收缩；
- 俯视奇观：一片环形魔气笼罩数十万里向前极速移动、同时飞快消散，其下一道黑影如闪电，只见残影片片。
- 计时压力：短短数息，魔气尽管有化魔指操控仍大范围消散，**只剩不足一半**。

## 五、转折：对方自断神识 → 血遁

- 前方逃遁的神识蓦然一顿，不再逃离，转而直奔天空——王林判断：「**被切断了**」。对方**切断这一丝神识，以换取自身所在之地不被发现**（王林早已料到）。
- 王林当即**喷出一大口鲜血**，血光刺目，一头钻入血光——**血遁**。
  - 血遁之术：**自伤身体换取极端速度**，仅短时间爆发、无法长久。
  - 为何半年前面对旋风时未用：那旋风在追击中**不断吸收天地间涌现的灰气**，速度越来越快，血遁不能长久，最终仍逃不脱。
- 血光一闪，速度倍增；他不理被切断的神识，方向不改，借上空只剩一小半的魔气一冲而出，**循着被切断的一丝脉络紧追不舍**。

## 六、章末悬念

远处，**一个巨大的黑影**渐渐出现在王林的目光尽头。

## 关键点小结

- 母题呈现：以「沦为魔修」的极端手段换取破局，是典型的仙逆式代价交换（形貌、魔念皆为代价）。
- 目标动机链：离开黑沙荒漠 → 帮周佚、为司徒南解毒。
- 待续线索：巨大黑影的身份；魔念在身的后续影响；被吞神识那股冰冷元力的来源。
