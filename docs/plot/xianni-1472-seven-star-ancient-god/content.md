# 第1472章 七星古神！！（第二更）｜第九卷 云海之巅

## 一、拓森破禁与自伤
- 拓森在宫殿外费尽辛苦强行轰开禁制、探身而入，未及看清便被一尊巨大的古神肉身呼啸砸来。
- 他来不及闪躲，以强悍的**八星古神肉身**抬右手硬抗，却被骇人大力冲入体内，**右臂骨头断开**，身子倒卷喷血。
- 倒卷之际，他看清了破开的大网后、石台座椅之上的王林。

（原文作者更正：拓森星点记乱，**不是九星，而是八星**。）

## 二、第十七息与第十八息
- 借拓森这一撞之力，王林**以右臂为代价**使第十七息骤然而过，眉心**第七颗星点**旋转中已可见成型之相。
- 恐怖的**第十八息**降临：座椅反震之力暴增数倍，王林腰部先崩，蔓延至胸口，血肉撕裂、骨头爆开；仅剩的左臂亦开始崩溃。
- 崩溃仍在继续：胸口、左臂转眼消散，**唯余一颗头颅**凭意志与座椅隔空相连；随后下巴、双唇、鼻子、双眼尽数化碎片消散，只剩眉心六颗星点急旋。

## 三、拓森疯狂争夺传承
- 拓森看到王林眉心破茧而出的第七星，立刻明白王林正在经历他自认本该属于自己的**道古传承**。
- 其怒吼：“你夺走了我的记忆传承，眼下又要抢去道古传承”，遂不顾伤势疯狂前冲。

### 王林最后的部署
- 崩溃瞬间，王林左手点眉心，抬手放出**二十片古息叶**，挥手化乌光封印在被轰开的大网缺口上，与拓森身子直接碰在一起。
- 做完这最后一个动作，其**左臂崩溃成血肉四散**。
- 王林喝令：“**封灵动，周瑾，阻拦此人**”。

### 三方交手
| 出手方 | 神通 | 结果 |
|---|---|---|
| 拓森 | 右拳硬轰古息叶 | 二十片中**三片崩溃成碎末**，右手伸出欲撕开缺口 |
| 灵动 | **香火紫海**（滔天紫海含无尽香火之魂，化巨大海浪） | 落在拓森右拳上，逼其右手退回 |
| 周瑾（奉天狼族大汉） | **群狼拜月**（数十万虚幻之狼化狼烟融入凭空出现的**血色之月**，血月轰然砸落） | 与紫海合击，两尊**第三步空涅初期**大能同时出手 |
| 拓森 | **古神一吼**（古神之力融入吼声，化疯狂暴虐风暴） | 紫海崩溃、灵动喷血倒卷失战力；血月扭曲瓦解、周瑾胸前一凹喷血落地 |

- 古神一吼的风暴横扫宫殿：一具具修士肉身崩溃，**八座肉身化作飞灰**，**八条巨龙瓦解**；唯**古之三族尸体剩下一半**未崩。
- 灵动、周瑾失去阻拦之力后，拓森双臂同时伸入古息叶缺口，向外狠撕，欲冲入宫殿。

## 四、七星凝实：千丈王族七星古神
- 在崩溃即将毁灭王林隐藏元神的古神星点的刹那，**第七颗星点刺目闪烁**，浩荡古神之力如潮水爆发，第七星**由虚幻模糊瞬息凝实**，彻底成型。
- 七星成漩，转动一圈 → 重生完整头颅（双眼、鼻、双唇）；
- 转动第二圈 → 脖子、胸口、腹部、双臂等整个上半身凭空凝聚（先骨头、后血肉内府）；
- 转动第三圈 → 下半身轰然凝出。
- 重凝的古神肉身**不再是数百丈，而是千丈**——**千丈王族七星古神**。
- 每一根肌肉蕴含诸多古神之力，每一寸骨头皆有磅礴古神气息。王林睁眼，身子仍坐在椅上分毫未离；眉心七星由缓转急，自觉有**一拳打爆一颗修真星**的力量。

### 双重收获
1. **玄武最强一击的力道感悟**：大帝星上二代朱雀所传的一幕幕感悟在其心神弥漫贯通。
2. **座椅传承神通**：座椅内涌现一幕幕传承神通，如破损的神识般涌入王林脑海，化作他自身的深刻记忆。

## 五、神识与座椅（墓台）相连
- 因在椅上**坐满十八息**，七星古神之体重凝的刹那，王林神识与座椅产生一丝**说不清的诡异联系**（成因短时间内他也无法捉摸，且无暇琢磨）。
- 座椅仿若化作一座**墓台**：王林脑中浮现**整个古墓三层的全部画面**。
- 其神识被座椅**放大无数万倍**，并感受到古墓内的一股意志——那是**古墓的意志，也是道古烨寞残留的一股意念之力**——神识与之融合后，自宫殿向外疯狂蔓延。

## 六、震慑与悬念
- **拓森**：最先被神识接触，咆哮嘎然而止，身子猛震，双眼骇然。
- **粉衣女子（第九张地图，眉目挂着风情）**：
  - 神色阴沉前行，发现**自己操控拓森的禁制竟有松动**，极为不安；自忖“没想到让他小小古神抢先进入，但我有拓森，却也不是没了机会”。
  - 随即其前方第九张地图内的**一处处空间乱流如遭狂风横扫般齐齐散去**，她感到一股令她颤抖的神识擦身而过，愣了半晌方恢复。
  - 惊问：“**这是谁的神识？莫非那道古烨寞没有被仙尊杀死？**”

## 七、关键伏笔
- 拓森自称记忆传承被王林夺走，与王林结下不可解的传承之争。
- 王林与古墓意志/道古烨寞意念的融合，为其后化身“烨寞”埋线。
- 粉衣女子背后有“**仙尊**”，且仙尊曾（被认为）杀死道古烨寞——新的势力层级浮现。
