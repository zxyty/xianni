# 第1117章 五更（第八卷 联盟隐秘）

## 一、开场：周佚的苦涩
- 周佚的苦涩落在青霖眼中，青霖自己也不知为何起了一丝痛楚，但很快压下，再不看周佚一眼。
- 王巍早知会如此，只是不忍告知周佚；这些年随着了解周佚，他对当年的一幕幕已全部相信。
- 胡娟心软欲言，被突发的变故打断。

## 二、古魔塔珈现身
- 下方黑色海面怒浪滚滚，魔气滔天，凝聚成庞大古魔——正是塔珈。
- 形貌：身躯仿若支撑天地，魔气如魔龙环绕咆哮；双目通红，眉心有一块伤疤，魔气涌入时呲呲作响。
- 宣言：「即便是在青霖识海内，你们也一样要死」，抬起巨手抓向众人。

## 三、仙帝青霖破浪而出
- 海面翻滚，飞出一名中年青衣男子，相貌英俊、仙风道骨、不怒自威——正是仙帝青霖。
- 称谓关系：王巍、胡娟激动呼「师尊」；青霜恭敬称「父亲」。
- 出手：右手一挥化作风暴，与古魔右手对撞，古魔右手崩溃化黑气倒卷，但青霖的狂风也随之瓦解（虚弱之征）。
- 塔珈劝降：「你已虚弱到了现在，为何还不屈从本魔，本魔用你的身体，可以超越你当年威名，你我融合，有何不好」；其崩溃的右臂瞬息恢复。

## 四、传道：青霖择王林为最后弟子
- 青霖不理会古魔，以蕴含规则的目光看向王林，欲一眼看透其全部秘密；王林连思索都无法做到。
- 转折：一股王林熟悉的气息自眉心涌现流转周身，被看穿之感立刻消失。
- 青霖收目宣布：「你有资格，获得我青霖的传承，成为我最后一个弟子」，随即化作青芒冲入王林体内。
- 入体反应：王林全身砰砰作响、升空张臂、剧痛欲吼，身体不受控制——此感此生仅有一次可比，即当年散魔借其身躯一战，但强烈无数倍，如灵魂被不断拉伸。
- 青霖评语：「魂体不弱」「只是修为不够」。

### 四人献修为
1. 王巍：应「为师需要你的修为」，毫不犹豫化长虹融入王林体内，剧痛再增。
2. 胡娟、青霜、周佚：随后齐齐化三道长虹冲入王林体内。
- 王林痛至几近疯狂，怒吼惊天动地。

### 青霖的承诺（造化）
- 不占据王林身体；
- 给予力量、对规则的理解、一切仙术的记忆；
- 让王林亲自施展一次「空涅级别的战斗」；
- 定性：这是回报王林肯来相救的一场造化。
- 声音消散刹那，一股无法想象的力量自王林体内爆发：可令天地苍生颤抖、宇宙星空崩溃；碎涅修士在其眼中不值一提，一念可令其道消、一意可令其屈膝。掌控天地的意念在王林心中疯狂滋生，体内痛楚已不能引其注意。

## 五、塔珈的恐惧：后招竟是传道
- 塔珈呆望这一切，双眼恐惧——终于明白青霖的后招是「传道」。
- 传道之义：天地有灵，自修成道；一人得道，传遍万灵；此为传天地之道。

## 六、战斗过程
### 1. 王林「大地」
- 一指天空道「大地」，识海内风起云涌，规则之力撕碎此地一切，连海水都崩溃，战场化作黄土沙漠。

### 2. 塔珈黑风漩涡 + 数百丈黑刀
- 双臂前甩起黑风遮天，形成四面八方汇聚的漩涡风暴；
- 口吐古之语言，虚空一抓幻化数百丈长黑刀横扫王林。
- 王林右手一指，旋风与魔刀齐齐停滞半空。

### 3. 王林「呼风」——十三条黑龙
- 天地颤抖，黑雾散去化作无尽黑风，其中龙影交错，非九条而是十三条。
- 十三黑龙咆哮扑向古魔，塔珈后退，瞳内八个魔星环绕，吐出古之语言。

### 4. 塔珈古魔之术
- 「界限」：身前幻化黑线环绕，线内外如两个地域，外界一切神通不能踏入。
- 「吞天」：身后魔气云涌，幻化天地大小的森森巨口向前吞噬。

### 5. 至宝：黑色长枪（白凡仙术的封印传承）
- 十三条黑龙相互纠缠，化作通体黑色、散发仙气的长枪。
- 王林脑中浮现清水当年所封的一段话：白凡仙术修到极限时可化作师尊至宝——白凡每创一道仙术后，便以莫大神通祭祀一件法宝融入天地规则，凡后世弟子把其仙术修至极致，即可唤出至宝，使神通威力倍增。此段记忆为清水传授仙术时封印，本意待王林把一样神通修至巅峰才破封。
- 战果：黑枪一冲穿透「吞天」巨口，其崩溃散出无数魔气（可吞天地，却吞不下王林此刻短暂传道所得修为）；继而冲入「界限」，黑芒刺目，界限咔咔崩溃——分割两界、阻止一切神通亦无用，修为足够则世间没有界限。
- 黑枪穿透塔珈身子后未穿出，而在其体内轰然爆开，塔珈庞大身躯瓦解，化无数魔气向后重聚成形。

### 6. 收尾：塔珈欲逃被困
- 塔珈眼中恐惧更浓，转身欲逃，却如撞铁板：四周识海融入无数规则完美组合，形成牢笼。
- 王林一步迈出，从容道：「你逃不走，一切，只是刚刚开始接下来，你让我，来感受一些，真正的第三步神通」。
- 塔珈猛回身，眼露疯狂，瞳内八个古魔星点立即崩溃三个（章末悬停）。

## 七、要点与伏笔
- 战力标尺：白凡最多化出十一条黑龙，王林在传道状态下化出十三条——超越白凡本人的施法上限。
- 「第三步神通」＝碎涅之上/空涅层级的力量，本章由传道短暂赋予，非王林自身修为。
- 清水的封印记忆在此章破开，等于打通「白凡仙术→至宝」的完整用法，属长期可复用的战力增幅。
- 青霖与周佚的感情线在开场被明确否掉，但青霖心生痛楚，留有余韵。
