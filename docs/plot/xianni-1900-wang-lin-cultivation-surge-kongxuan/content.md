# 第1900章 修为暴增！！

## 一、闭关背景

- 地点：寂静的**蝎庙**内。王林盘膝而坐，四周有**四大本源真身**平静守护，得以静心提升修为。
- 入章状态：修为已达**空灵巅峰**，**八道本源大成**，其中一道本源已凝成真身。
- 新增造化：体内不但多出**三具本源真身**（共四具），更**获得第九道本源**——这第九道本源是修为提升的最关键之处。
- **九道本源清单**：生死、因果、真假、禁制、杀戮、雷、火、水、土。

## 二、突破空玄初期

- **空玄门槛**：空灵与空玄一字之差，区别极大。空玄修士需**明悟天地道理**，且**必须至少拥有一样虚本源**方可达到。
- **空玄地位**：一旦入空玄便踏入强者之列；即便在**仙罡大陆**上，除却**九宗十三门**外，空玄修士也有足够实力。且可施展一些玄妙神通之术（对王林用处不大，但可使修为大进）。
- **过程**：四大真身各散本源之气融入王林体内 → 九道本源急速旋转 → 王林上方浮现云雾漩涡（转速与体内本源同步）→ 元神蜕变、刺目之芒透出皮肤、通体透明如威严之像 → 修为自空灵巅峰**直接冲破至空玄初期**。
- **入境感受**：世界在感受中改变，许多以往模糊之处骤然清晰，目露睿智之芒。

## 三、王林的路线图（自述）

> "空玄对我来说，只是一个过渡，我的目标，是踏入**空劫**。"

- 手段：吸收体内积累的**绿魔炉内多年的天地之力**，可令修为再次暴增。
- 核心目标：**九道本源归一** → 得以面对**九次玄劫** → 度过玄劫即成**空劫大尊**。

## 四、五行三本源归一 → 空玄中期

1. 施展**「九大本源，归一之术」**，令火焰本源真身、大地土本源真身、水本源真身三者自天灵散出本源气息，在身前缭绕旋转。
2. 判断：三者同属**五行本源**，归一后可成为达到**空玄中期**的契机；且三者均已达本源真身程度，归一后威力更大。
3. 首次碰撞失败——三道本源未融合，反而骤然散开。
4. 破局法：**咬破舌尖喷出鲜血**为粘连之物，再控三大本源融合。原理自述——「水火本是相克之源，但我以**土本源作为媒介**，土可淹水，亦可淹火，再加上一口精纯的、蕴含我王林意志的元神之血」。
5. 过程：漩涡内交替浮现滔天洪水、焚烧火海，皆被卷动天地的沙土弥漫。历时**数月、累计喷出七口鲜血**后现凝聚迹象，又经数百上千次碰撞，**再过七天**惊天巨响中三大本源融合。
6. 结果：形成完整画幕——**大地居中，上为焚天火海，下为怒吼洪水**；三大本源真身凝聚成**一个身体**，近乎独立，已不称真身，更类似一具**天地五行分身**。（原文该处写作「蕴含了雷、火、土三大本源」，与前后文水火土三本源的叙述不一致，疑为原文笔误。）
7. 修为跃迁：新身出现刹那，元神疯狂吸收体内积累的天地之力，气息暴增，**持续一个月**后长啸声中修为达**空玄中期**。
8. 罕见程度：古往今来从未有人能在**短短数月**内从空玄初期达到中期，若传出王林必万众瞩目。

## 五、雷霆真身融杀戮、禁制 → 冲击空玄后期

- 判断：**杀戮本源**与**禁制本源**同属**特殊本源**，特殊本源极难彼此融合；但**雷霆本源已有真身**，强度超过这两者，可堪重任。融合成功即可再次攀升至**空玄后期**。
- **方案一（失败）**：以雷霆本源为引，**化作细丝**穿梭连接杀戮与禁制，令二者暂时融合。异象：瞳孔上血色细丝闪烁倒影化作禁制本源；体内爆发滔天杀戮致四周寒气逼人。雷霆真身睁眼、目内闪电弥漫，起身化作一道细长闪电交错穿梭。**一个月内数次尝试皆败**——杀戮极为霸道，禁制更与雷霆相克。王林感慨："可惜我只有两道特殊本源，若是能再有一道，或许会更容易一些。"
- **方案二（成功）**：不再以雷霆为辅助，而**以雷霆本源真身为主体**，去吸收融合那两道特殊本源。连喷数口**元神精血**笼罩雷霆真身；真身吸收含王林意志之血后雷霆轰鸣，伸开双手化作两道闪电扑向杀戮与禁制。
  - **以雷身，融杀戮；以雷身，融禁制。**
  - 预期：成功后这具雷本源真身将蕴含**三道本源**，突飞猛进，甚至连雷霆本身也会因此改变——此事古往今来极为罕见，王林亦不知会发生什么。
- **结果**：又过**数月**，雷霆本源真身成功融合杀戮与禁制，爆发惊天之威，轰隆巨响下发生**让王林为之一愣的惊人变化**——本章至此收束，变化内容留待下章。

## 六、本章时间线（章内）

1. 四大真身护法，冲击空玄 → 破入**空玄初期**。
2. 五行三本源归一：数月（七口血）+ 七天 → 成天地五行分身。
3. 吸收绿魔炉天地之力：一个月 → **空玄中期**。
4. 雷丝连接杀戮/禁制：一个月，失败。
5. 雷霆真身主体吞融：数月，成功，真身生异变。

## 七、设定要点提炼

- **境界序列**：空灵（巅峰）→ 空玄（初期/中期/后期）→ 空劫（度九次玄劫者为空劫大尊）。
- **本源体系**：本源分五行本源（水火土等）与特殊本源（杀戮、禁制等）；本源可升华为**本源真身**；多本源可**归一**融合，融合需契机、媒介与元神精血（承载意志）。
- **虚本源**：空玄境的硬性门槛之一。
- **九道本源归一**是通往空劫的关键路径。
