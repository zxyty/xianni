# 第八卷 联盟隐秘 · 第1119章 默默

## 场景

- **主战场**：青霖的识海之内（青霖元神被古魔侵占，识海大半为古魔所据）。
- **外界**：雨之仙界的漆黑虚无中，一座漂浮前行的青光大殿；王林肉身盘膝于殿内阵法中。

## 一、塔珈五星齐爆

- 五星齐爆之力与此前三星爆开之力融合，塔珈身上魔气疯狂攀升，**无限接近九星古魔**。
- 但此刻塔珈**已然输给青霖**：他再没有任何资格获得青霖的肉身，等待他的唯有死亡。
- 塔珈的不甘让他决意与王林同归于尽，并要在死前打出古魔一族最强的几式神通。
- **王林的选择**：他本可在塔珈爆发前将其扼杀，但无论为了自身证道，还是出于对「古之一族」的尊重，都选择给对方足够时间施展——他自己对此也有激动与期待。
- 塔珈身体重新凝实、缩至常人大小，漆黑躯体、头顶魔角、赤红双目，气息惊天动地。

## 二、神通对决：紫气魔劫 vs 山崩

### 塔珈「紫气·魔劫」

1. 「紫气」——全身黑色魔气大半化为紫色，环绕内外。
2. 双手抬起、身前十指交错结成菱形图案，紫气顺双手灌入，凝成紫色菱形。
3. 「魔劫」——眉心现漩涡，魔魂飞出冲入菱形，光芒大盛。
4. 双手推出，菱形自巴掌大小暴涨至遮天，笼罩王林四周，将其所在之地与外界彻底分割，并一路收缩，所过之处天地崩溃碎裂，逼至不足三寸。

### 王林「山崩」

- 一言「山崩」，身上崛起一峰直冲云霄，继而延伸出第二、第三峰，瞬息成**九座巍峨之山**，顶住菱形收缩，甚至有撑开之势。
- 紫气魔劫之威远超塔珈此前一切神通，九山出现碎裂。
- 王林轻声「崩」——九山齐溃、化作火山爆发，与紫气菱形对撞形成惊天冲击。王林自崩溃中缓步走出，安然无恙。
- **王林评语**：「可惜紫气不浓。」

## 三、青霖的算计（关键设定揭示）

塔珈绝望怒吼中道破真相：

- 王林此刻之力**非其自身之力**：是在青霖识海内，由青霖**心意配合随其幻化**，并**传道于他**，暂时给予他如今的修为。
- 青霖的算计**不是**寻强者来灭自身魔魂，而是**把救援者吸入自己的识海**。
- 识海归青霖所有、可随其心意幻化，但因古魔在内、元神被侵，这些幻化无法直接攻击古魔；于是青霖**以他人魂魄为体，不惜传下道念，放弃对识海的操控，转交王林**——几乎是把生死交到别人手上。
- 由此：识海随王林心动而变，可幻化天地万物、模拟一切规则，使王林**暂时拥有第三步的力量**。
- **限制**：魂魄不同，强控他人识海不能长久，过不了多久王林就会虚弱；一旦离开青霖识海到了外界，立刻打回原形。
- 塔珈自认：若非在此识海、若无青霖心意配合，「本魔要杀你，如捏死蚂蚁」——但他已撑不了太久。最终承认：「青霖，你赢了。」

## 四、古魔最强之术「初开，始魔道」

- 塔珈飞至天空自爆，以生命最后一刻施展古魔一族最强之术，「即便是死，吾也无悔」。
- 天空被浓浓魔气云涌遮盖，天地一片黑暗；黑雾中浮现**一双双一模一样的阴森眼睛**，齐齐凝视王林。这是全章唯一让王林面色**第一次有了变化**的攻击。
- 万古沧桑之声以规则攻心，逐句历数王林的因果（每一句都如一式神通落在其身）：
  - 「你名为王林」——十五岁修道，至今已有一千多年。
  - **命中有煞，踏上道途必毁亲族**：父死母亡，族亲殆尽，虽有余留也是沧海一粟，劫之不断。
  - 「你父母因你而死，你族人因你而亡」——天空众眼由迷茫转为痛苦，继而一片血红、部分爆开化血水而降。
  - 「你妻因你归天，你子因你成魂，你身边至亲，没有半人余留」。
  - **恩义清单**：遁天对他有恩却灭亡；朱雀圣皇对他有恩同样灭绝；周佚与他相遇后挚爱之尸不保；云仙道侣也因他出现，最终至今才尚有救下青霖之可能。
- 王林反应：身颤、双眼起血雾直至一片血色、面色苍白、后退数步、右手捂胸——魂体亦能感到心中之痛，如毒药侵蚀心神。

## 五、王林反击与道心宣言

- 王林猛然抬头，神色平静而极致冰寒，两度追问：「说够了么」「我问你，说够了么」，右手一撕，天空无数双眼轰然崩溃，血水尽落其身。
- **道心宣言**：「我王林一生，顶天立地，纵有错，但求对得起道心，足矣。」
- 「**仙术，陨星**」：一指天空，星光自天而降穿透层层黑雾；星光如剑自四方而来，海水中亦有星空冲出直上九霄。天地星光弥漫后，王林双臂一挥使星光倒卷，齐轰天空黑雾，形成粉碎一切的波纹冲击。

## 六、识海崩溃与回归

- 王林身体在这一刻崩溃，**王巍、胡娟、周佚、青霜**一一闪现，还有一身青衣、神色感叹的**青霖**；随识海崩溃，这些身影融入碎卷、一一消散。
- 镜头切至**雨之仙界**漆黑虚无中的青光大殿：司徒南（自第336章起断臂所化人影自称，真伪未定）谨慎望着殿门、时而看向阵法内众人，心中焦急；**银衣女尸**目光落在王林身上，仿若永恒。
- 王林盘膝之身一颤，缓缓睁眼，默默起身走到大殿门旁，静静看着外面的虚无。

## 要点归纳

1. 塔珈之败已成定局，其后所有出手都是「求死前尽兴」，王林亦以证道之心成全。
2. 「第三步之力」是青霖借出的、有明确时效与地域限制的临时增益，出识海即失效——为后续外界战力埋下伏笔。
3. 「初开·始魔道」是攻心而非攻身的规则级神通，直击王林最大的因果软肋（亲族、妻子、恩人皆亡）。
4. 王林以「顶天立地、对得起道心」破局，是本章的道心节点。
