# 第1313章 宿命第一战（第九卷 云海之巅）

## 一、王林的诛心之语：涂司是否真的死了

- 王林向拓森喝问式反击：**「你以为，涂司真的死亡了么」**——此声如雷霆划过夜空，直击拓森内心最脆弱处。
- 拓森一生狂妄、天地不惧，唯独最惧一人：**涂司**。
  - 拓森本是**涂司的一丝魔念所生**，对涂司有难以想象的畏惧。
  - 此刻他所操控的，正是**涂司的肉身**。
  - 无数万年来他始终存有一个不可思议的猜测：涂司到底死没死？尽管一切迹象都表明涂司已在**墨流分身术**中彻底灭亡。
- 王林咆哮式加码：**「你要吞噬我，大可去吞，我王林死亡之时，就是涂司苏醒的一刻，到时你拓森，也要飞灰湮灭」**。
- 效果立竿见影：拓森心神震动，**六星旋转骤然停顿半空**，眼中罕见地露出犹豫与震惊——吞噬王林之举中断。

## 二、月族异变：封神大阵开启

就在拓森心神大乱、出现「不该存在的犹豫」的片刻，月族所在之地骤生惊天异变。

- 一个**苍老、疯狂、兴奋又掩不住畏惧**的声音传遍星空：**「封神大阵，开」**。
- **封神大战，封的就是「神」——古神。**

### 阵法构成

| 要素 | 内容 |
|---|---|
| 人阵 | 不下**十万**月族之人幻化现身，男女皆有，眉心月牙印记闪烁月芒；每人方位经无数次计算 |
| 星阵 | 星域内**所有修真星**按大阵结构摆放 |
| 阵眼 | 四周**上百颗修真星**上各盘膝坐一名白发月族老者，掐印运转全身修为 |
| 空间 | 天地化为无尽月色，一颗巨大弯月现于天空；此乃月族历代先祖为封印古神而开辟的**虚幻空间**，入者绝难出去 |

### 月族的动机

- **死去的古神，远不如一尊活着的古神**，何况是**王族古神**。
- 若能封印一位活着的王族古神成为**月族之奴**，月族可借此**崛起**；任一月族之人想起都会兴奋到元神颤抖。
- 月族为此**准备了无数万年**。
- 拓森**数年前**到来后，月族畏惧兼兴奋，发动一切开启先祖阵法等待其来。原以为拓森身为古神必寻月族而来，结果**等了十多年拓森未至**。
- 就在月族欲继续等下去的今天，**在王林的吸引下，拓森来临**——且场中竟是**两个王族古神**（拓森与王林），令月族更为兴奋。

## 三、封神大阵的连环杀招（按出手顺序）

1. **月色化丝**：拓森右臂轰落四周，月色如绸却不崩溃，扭曲化作无数光线疯狂缠绕王林与拓森，如披无数丝绸。拓森仰天古神之吼欲崩此界，月色反而扭曲出更多月丝。
2. **月柔之杀·弑神躯**：苍老声音喝出，月色丝线暴增，化作一道道**锋利、坚韧、无始无终**的细线展开缠杀；崩溃大片后反而化作更多。
3. **月族至宝·神灭扇**：月光凝聚成**百丈大小的月色扇子**，一扇之下风暴滔天，内蕴无尽月色。
   - 关键：这月光中**蕴含如开天巨斧一般的气息，对古神有惊人伤害**。
   - 王林被狂风横扫后退，月光如利剑穿透其全身；拓森以拳轰碎风暴，风暴化无数利剑穿身，留下无数血痕。
   - 王林以体外**血剑**闪烁形成漩涡展开斩击细线，但细线无边无际、根本斩不完。
4. **大月灭神术**：阵外十万月族之人中，**逾万人喷血、肉身崩溃当场死亡**，承受不住阵法反震；死亡瞬间眉心**月牙印记飞出烙印于阵**，魂魄幻出并膨胀，化作**上万个月亮**，使月色达到巅峰。
   - 口诀：**「以吾族血，饲养神灵；以吾族魂，崩溃神灵」**。
   - 上万月亮**一大半直奔拓森，余下冲向王林**。
5. **月族至宝·血月之翼（血祭）**：**数千**月族修士幻化，各擒一头挣扎咆哮的凶兽并将其轰然崩碎，数千凶兽血肉尽落大阵并被瞬间吸收；此为第一波，其后又有数波修士如法炮制。血光凝聚出**两道血色长翼**直奔王林与拓森。
6. **月族至宝·古神九骨**：阵外虚空中一名**黑衣白发老者**幻化，双臂伸开、神色贪婪疯狂；其前方裂开巨大裂缝，飞出**九个巨大的古神头骨**——传出浓浓古神气息，其上布满月牙封印并被月色笼罩，入阵即化作风暴冲向二人。
7. **月族至宝·溃神液**：黑衣老者白发诡异飘动，咬破舌尖喷出一口**漆黑鲜血**；四周数百颗修真星上的月族修士同时咬舌喷出带浓浓恶臭的漆黑鲜血，血液似有灵性彼此凝聚成**恶臭血海**，卷动天地般冲入阵内。

## 四、立场与态度

- 拓森暴怒斥骂：**「大胆奴族，竟敢伤本神，你们，去死」**——在他眼中月族是**往昔奴族**、是蝼蚁。
- 值得注意的是：拓森虽与王林交战，却**认同王林是本族（古神）之人**。
- 拓森在月色世界中疯狂破坏，然而**月色越崩溃、化出的丝线越多**，转眼天地几乎被丝线弥漫至模糊不清。

## 五、悬念

- 涂司究竟是否真的在墨流分身术中灭亡？王林之言是实情还是攻心之策，本章未揭晓。
- 王林与拓森同被封入月色虚幻空间，二者是否会在共同的封印压力下产生变数，本章止于溃神液入阵。
