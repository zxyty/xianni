# 第七卷 名震罗天 · 第769章 信心（3/3）

## 一、李元败因自陈
- 李元喷血，脸上死气浓郁至顶峰，惨笑自语：**并非李家禁制不足**，而是先前**帮助「许兄」致心禁损耗太多**、又无时间恢复；若以完整心禁，那面**破禁古镜绝不会成功**。
- 李元表态：许兄对李家有大恩，纵使如此**「不悔死，便死吧」**。
- 说明：文中「许兄」即以化名**许木**行事的**王林**（自第711章起以「许木」之名行走，属自创化名）。

## 二、阴虚老者补刀，李元彻底失去反抗力
- 老者上前，看都不看李元一眼，**一脚踢中其身**，咔咔震响，李元再喷鲜血，**体内所有仙力全部崩溃**。
- 老者退后禀报：「少主，此人已经没有了危害，你可以出手了。」
- 值得注意：老者身为**阴虚修士**，对一个**问鼎**小辈出手毫无羞耻之感——阵营冷酷、以势压人。

## 三、仙剑易主与搜魂之危
- 姚姓青年此前才勉强禁锢三把飞剑；因**李元仙力崩溃、飞剑失去联系**，他将三剑抓在手中，**扔给身边女子**。
- 女子把玩仙剑、笑眯眯催促「表哥快一些哦」——二人为表兄妹关系。
- 青年踏至李元身前寒声逼问：「让我来看看，你到底是从什么地方，找到的那几把仙剑」，抬右手按向李元头顶欲**搜魂**。

## 四、王林现身：一指灭杀
- 就在右手按落的瞬间，**一道波纹**在李元身边出现；老者神色骤变，大喝「少主速退」。
- 波纹内爆出**无法想象的杀机**：天地瞬息冰寒、冰花飘落、雷鸣回荡。
- 王林一步迈出，**一指落在青年胸口**——全身骨头寸断，身子抛飞。
- 再一步踏来，**手指点在其眉心**，浓郁元力灌入，如怒浪般：
  1. 摧毁**仙力**；
  2. 摧毁**道基**；
  3. 逼血出汗毛孔，化作血人、血雾弥漫；
  4. 寸寸摧毁肌肉，粉碎五脏六腑；
  5. 冲入头部，崩溃头骨与大脑。
- 青年**肉身在半空尚未落地便彻底瓦解消散**。
- 元神显现之际，元力最后一次爆发，**生生撕裂其元神**——但未令其消散，而是**在元力中重新凝聚为拳头大小的光球**，飞回王林手中。

## 五、以敌之元神救友
- 王林抓住光球后**按在地面上李元的眉心**，**滋养其消散的元神**。
- 王林冷到极限的一句：**「是谁，给你们资格，伤我之友」**。
- 全过程在刹那间完成，老者脚步刚迈出、尚未临近，一切已结束。

## 六、阴虚老者的惊骇（关键情报）
- 从容、淡然、平静瞬息瓦解，露出惊骇乃至恐惧；冷汗罕见地渗出额头。
- 他**根本看不到对方身影**；波纹内蕴含的**天地元力**令其倒吸凉气。
- 最令其惊惧者：这青年**「整个人与天地融合在了一起」**。
- 心念：**「太可怕了，进入雷之仙界的阳实修士我都认识，此人到底是谁」**——侧证王林在雷之仙界属身份不明的变数，且其气息被评估至阳实层级之上/之外。
- 老者下意识退后数步，甚至生出立刻逃亡的冲动。

## 七、其余反应与钩子
- 女子彻底呆住，大脑一片空白。
- 李元望着王林，眼角激动，挣扎道：**「帮我杀了他们」**——为下文王林对老者与女子出手埋下引线。

## 关键转折
1. 李元由被搜魂的必死之局转为被救，且其濒散元神获得续命之资。
2. 王林首次在这批雷之仙界势力面前显威，身份成谜（老者认不出）。
3. 「伤我之友」确立王林对李元的护友立场，恩义线（李家—许木）由李元单方面报恩转为双向。
