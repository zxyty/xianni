# 第1891章 借雷抹神

## 一、场景：绿魔洲中心 · 绿魔蝎庙

- 时间：王林被擒后**数月**。
- 地点：绿魔洲中心，一片方圆数百万里的绿意沼泽。沼泽时时冒出气泡，散发腐烂气味；气泡破开散出的绿雾日夜年岁凝聚，弥漫此地。
- 建筑：沼泽上趴伏着一座**万丈大小、通体漆黑、栩栩如生的巨蝎形建筑**（绿魔蝎庙）。其内扩散滔天魔气，笼罩四周，绝大部分修士无法接近，否则魔气入体、心神癫狂。
- 道魔宗除宗主外的所有修士，已在数月内尽数赶回道魔宗山门。唯有擒住王林的宗主，凭修为不受魔气影响，独自来到庙外。

## 二、人物：祭祀与绿魔使者

- 蝎口中传出虚弱咳嗽，走出三人：
  - **祭祀**：全身被绿袍遮盖，佝偻苍老，看不清容颜，仅见绿袍内一双妖异之目；不断剧烈咳嗽。
  - **两名绿魔使者**：着绿色道袍、袍上刻画狰狞蝎子，貌似中年，散发**空劫中期**修为，神色冰冷无情绪，如护卫般护在祭祀身前，自始至终一语未发。
- 道魔宗宗主对祭祀极为客气，抱拳称其“祭祀”。

## 三、交易与命令

1. 宗主右手一挥，现出被黑白二气笼罩的王林——双目紧闭、盘膝不动。
2. 祭祀满意：此人**“应该会很适合用来镇压我绿魔洲的气运，使得绿魔大人满意”**。
3. 宗主提价：“为了擒他，我道魔宗付出了很大的代价。”
4. 祭祀承诺：绿魔大人复活后赏赐绝不会少；并抛出更重的许诺——**“未来的绿魔洲，只有道魔宗，一宗”**。
5. 祭祀的硬性要求：**抹掉王林的神智，摧毁其心神与记忆**，但不可强硬造成损伤——哪怕极微弱的一丝一毫损伤，都会日后影响绿魔蝎的复活。（宗主自忖：若非此要求，他有无数方法可瞬间抹掉王林心神。）

## 四、手段：道魔变 + 借雷

- 宗主答允“全力以道魔”，**在王林心底种下「道魔变」，让他自己摧毁自己的心神**：右手指尖穿透光团，点在王林眉心。
- 随后将包裹王林的黑白光团甩向巨蝎，蝎背浮现巨大漩涡，将王林吸入。
- 宗主道破王林底细：**体内本源极多，共有八道，其中一道已凝聚出本源真身**；八道之中有一道与自己相通，即**雷霆本源**。他遂以雷霆本源为“相通之点”，从内部摧毁王林心神与记忆。说罢盘膝闭目，一动不动。
- 祭祀与两名绿魔使者退回蝎腹，咳嗽声渐远。

## 五、蝎腹深处：天逆珠护主

- 蝎子建筑最深处是一片虚无空间，弥漫无尽绿色光芒，每道光中皆有大量**绿色蝎魂**，不断发出魂的嘶吼。
- 王林盘膝其中，身上慢慢凝聚无数绿色蝎子，覆盖大半身体；肉身不动，**右目内隐现闪电光芒**，体内雷霆本源疯狂游走弥漫，身体啪啪作响、弧形电光扩散全身。
- 王林已陷昏迷，心神、神智、灵魂俱沉寂。但**祭祀与宗主都看不到**：其灵魂内有一颗珠子（天逆珠）在缓缓转动，每转一圈，灵魂、心神、记忆等虚无之物便颤抖一些，被柔和光芒护住——**肉身与神魂仿佛分成两部分**。
- 其体内雷霆本源越发强大，很快超过其余几种本源；虽仍逊于已凝聚真身的**火本源**，但差距越来越近。
- 王林体内仿佛出现一条无形通道，直接连到外面盘膝的道魔宗宗主体内，与其**已然大威、尚未凝聚真身的雷霆本源**交融。

## 六、宗主失算与雷帝珠

- 数月流逝，王林体内轰鸣不断，疯狂吸收通道传来的、蕴含宗主意志的雷霆本源。
- 宗主原计划：一个月内以自身雷霆本源完全取代王林同类本源，借其中蕴含的自身意志从内部展开抹杀，如此既满足祭祀要求、又不造成损伤。
- **第四个月**某日，宗主皱眉传声求助：自身雷霆本源几乎全部涌入王林体内，仍未完成意志凝聚，“仿若在王林体内有一个漩涡，在吸收自己的意志”。
  - 真相：**天逆珠每次旋转，在护住王林灵魂的同时，也吸收其体内一切非王林意志**。
- 祭祀在咳嗽中回应：手中还有**两颗从雷帝洲换来的雷帝珠**，本要在绿魔大人复活后献给大人吸收，现分出一颗。
- 一道灰色闪电自蝎体射出，在宗主身前化作拳头大小珠子：珠内存在无数闪电，隐见闪电中有**战车虚影**，战车上站着一个模糊之人，形如**雷之帝王**。
- 宗主见之砰然心跳、眼露奇芒，似有挣扎（此物本献给复活的绿魔蝎，非他可碰触），终压下念头。

## 七、结果：反哺王林，雷霆真身之兆

- 宗主张口猛吸，雷帝珠化作无数相连闪电入其口中，一口吞噬的瞬间其体内雷霆本源轰然暴增。
- 但**尚未截留分毫，便全部顺着与王林相连的通道被疯狂吸走**。
- 蝎腹绿色空间内，王林身子剧烈颤抖，体内雷霆本源刹那暴增，**竟有了凝聚出雷霆真身的迹象**。

## 八、要点提示

- 敌方目标是“完好地抹除神智”而非杀死王林——王林的价值在于**镇压绿魔洲气运、助绿魔蝎复活**。
- 「借雷抹神」表面是宗主借雷霆本源抹王林之神，实为王林（借天逆珠）借敌之雷壮大自身本源，攻守反转。
