# 第1470章 传承（二）

## 一、传承画面的终章

- 王林端坐石台座椅，灵动上人与周谨跪于身前，感受到其身上惊天动地的威压，恐惧不敢抬头；二人未看见王林左目下正流出鲜红之血。
- 传承实际在王林坐上椅子的一瞬间即已开始。脑海画面中，石台四周修士寂静如故，唯渺渺人灯之火无止尽燃烧，将四周笼于虚幻。
- **七彩道袍修士登场**：不知从何处来临，先在撑伞的中年修士（中年文士）身前沉默良久，轻叹「吾一生收三子以你为最」。
- 随后走到保持生前动作、手中持弓的李广身前，言「与你约定之事，我会做到；此弓待天道成长后，我会送回你之宗门」，取走那张惊天之弓。
- **「古道，无仙」**：取弓瞬间，一句沧桑话语骤然响起，仅四字便令七彩修士面色再变，全身七彩之光环绕，后退中喷出一口鲜血，抛下「你没死」三字，一步之下消失无影。画面至此消散。

## 二、座椅意志苏醒与十息之争

王林清醒的刹那，体内借来的气势急速外涌，欲回归座椅、消散天地；座椅内沉睡的意志因「妖魔气息融入 + 画面浮现 + 画面崩溃」而苏醒，爆发排斥之力——既推人，也收气，仿佛除当年之人外再无第二人有资格坐于其上。

王林决意「入我体内，便是我王林之物，岂能说来就来，说走就走」，死死凝固自身：

| 时点 | 关键变化 |
|---|---|
| 一~三息 | 元力急速运转抗排斥，同时疯狂吸收借来气势；眉心古神星点恢复六个，第七颗隐隐将现；右目古魔之力环绕，现成魔星迹象 |
| 第四息 | 心神内九张地图（墓台升阶所得）全部崩溃，露出古墓下层真相 |
| 第五息 | 目露红光狰狞，第七颗古神星点疯狂吸收 |
| 第五~六息 | 一指点周谨眉心种下古奴符文；下令二人祭献香火封椅助传承；灵动即刻按椅、虚空按王林分担反震 |
| 第七息 | 周谨依令至右侧，展开全身香火之力冲入座椅，右脚后踏死死坚持 |
| 第八息 | 反震撼动天地，王林体内砰砰作响、嘴角溢血，仍以古神之力凝固己身 |
| 第九息 | 纵有两大三步之修相助，反震愈烈；体内古魔气息与古神之力如潮欲出体归椅 |
| 第十息 | 王林喷血；第七颗古神星点急速旋转、只差一些便成型 |

注：王林左目九颗妖星此前已崩溃，古妖气息不存；此刻他所阻止外泄的，是右目古魔气息与眉心古神之力。

## 三、古墓的真实结构（本章最大信息量）

- **古墓共三层**，眼下所有进入者仅在第一层。原九张地图之下，另有六幅地图组成的无边区域（第二层），其下再有三幅地图组成的天地（第三层）。
- **入口**：进入第二层的入口，就是座椅之上的那团椭圆形光团。
- **座椅地位**：若把第一层视作一座阵法，座椅便是阵法的正心与中枢；王林坐其上神识与阵法融合，方能下窥。
- **第二层**：弥漫无数凄厉之魂，其中数个威压堪比蓝梦道尊；深处另有一片模糊之地，沉睡着一股惊天气势，一旦有人进入第二层必引其苏醒，届时纵有蓝梦道尊修为亦生死难料。
- **第三层**：王林神识刚入即被一声压抑了无数万年的咆哮震崩。崩溃前他看到，三幅地图居中那幅之上有一颗巨大心脏，砰砰跳动，传出确凿的传承气息——**身体触碰之即可完整获得道古传承**。
- **气息来源**：此前涌入王林体内的气息，正是从这颗心脏以某种奇异方法经座椅连接传出。
- **推论（王林所定决心的根据）**：若借来气息尽数被收回，他就只能按「正常途径」闯第二层、第三层、踏入心脏所在天府，凶险不可想象——莫说是他，古墓内所有修士无一人能做到。故必须死守座椅、留住气息。

## 四、强征二仆

- 周谨在威压消散后欲抬头，被王林借尚未散尽的气势一指点在眉心，喷血倒卷，眉心浮现**古奴的符文**。
- 王林下令：「你二人左右，祭献香火化作全部之力，封此座椅，助我传承速」，随即闭目封锁自身、固定于座椅。
- 灵动上人毫不犹豫，居左，掐诀按椅、引香火之力入内，左手虚空按王林分担反震；头发无风自动、衣衫撕裂、口角溢血。
- 周谨面色苍白、眼中挣扎（挣扎越剧烈，眉心古奴符文越闪烁），最终仍依令居右，展开全身香火之力入椅，右脚后踏如长在地上，与灵动同担反震。

## 五、剧变：拓森杀至

第十息后剧变突生。石台所在宫殿尽头虚空扭曲，拓森的身影在扭曲之后一拳拳轰打，将扭曲如网拉成凸形，狂笑传来：「终于让本神凭着感应找到了这里，就是这里——那该死的涂司做梦都想要回来之地」。传承争夺进入白热化。

- 拓森与涂司之间就此地的旧怨；拓森闯入后王林能否守住座椅与第七颗古神星点。
