# 第八卷 联盟隐秘 · 第952章 净涅踪迹

## 一、夺剑：撒豆成兵与雷霆之下的强取

- 王林手中第一把仙剑：长七尺、宽三寸，银荧之芒如一道月光，凌厉之意四散。右手一拍，**神识烙印**深深留于剑内，剑鸣大震、剑气冲出，绕其身漂浮游走。王林评价「的确是一把好剑」。
- 随即虚空一抓夺得第二把。此剑挣扎极烈，如以在王林手中为屈辱。王林不再压制，左手掐诀落下**一道道禁制**封印，扔入储物袋。
- 战场环境：四周杀域界修士被**撒豆成兵**幻化的众多战魂围困，天地间无尽雷霆轰隆降临，无人能阻王林脚步。
- 剩余**九把长剑**同时剑鸣，飞来途中相互融合化作一把大剑，剑芒无尽、剑气阴寒，「扑面之风可破开肉身直接沉入元神」。

## 二、幻虚子现身：净涅修士的两大神通

- 远处平地暗红光闪，**红袍中年男子（幻虚子）** 一闪而出，速如闪电直入战场中心。
  - 右手虚空一引，牵动**四个白玉葫芦**幻化的妙曼身影破开阻碍，直扑王林；其人化作红烟紧随。
  - 心声：他已隐藏很久等待时机，**「那清水他不敢招惹，即便是这许木，他也有些忌惮」**；并暗道「神魔子也是与我一样抱着同样的打算，可惜当日联盟招引净涅修士，我没有参与，否则今日也不会如此提心吊胆」。
- 王林反击「**呼风**」：黑风呼啸化三头黑龙。一头被四个妙曼身影缠住，双目露出迷茫；另两头扑向红烟。幻虚子长笑现身，整个人虚幻透明，从两龙之间**穿透**而过。
- 幻虚子当面挑明：**「许木，不要隐藏修为了，能在这么多阴虚阳实窥涅道友中毫发无损，你，一定是净涅修士。」**
- 王林的判断：
  - 他此前便疑惑杀域界内竟无净涅修士，但**自身神识尚停留在窥涅初期**，无法察觉净涅存在。
  - 见此人瞬间感受到**有别于碎涅老怪、却远超窥涅修士**的气息 → 确认为净涅。
  - **此生第二次战净涅修士**（第一次是血祖）；「此人气息没有血祖强，应该是净涅初期」。
  - 战意起：「就以此人，来见证一下我此刻的真正实力。」
- 净涅修士的力量构成（本章明确设定）：
  1. **明悟规则**；
  2. **抽取天地元力**——天地之力在其身上不怕浪费，随时可抽取施展神通。

## 三、硬撼：古神之拳 VS 幻之则「洪泽荒沙」

- 幻虚子右手一甩，九剑合一之大剑**徘徊其身边、发出臣服的剑鸣**（十剑归其驱使的一部分）。
- 幻虚子掐诀指天，四周无数光点向手心凝聚 → 王林瞳孔一缩：「抽取天地之力」。
- 神通**「洪泽荒沙」**：晶光化作大片黑色沙土，每一粒都蕴含极强天地元力，**内含一道道阵法**，沙土所在一片洪泽。
- 王林应对：眉心**第三目**隐藏之下**古神星点**疾驰旋转，融入手臂，向前一拳 → **古神庞大手臂**幻化如巨人之拳横扫。
- 幻虚子的规则揭晓：长笑「**洪泽幻法，成真**」，沙土凝聚出一只与王林古神手臂**一模一样**的巨拳；并自陈：**「我明悟的规则，便是幻之则。」**
- 对轰结果：
  - 沙土巨臂**砰然崩溃**，化作大片沙土倒卷；
  - 王林身体一震，**右臂瞬间麻木、片刻后阵阵刺痛**，被磅礴冲击横扫连连后退，心道「这就是净涅修士」；
  - 风暴横扫四周，闪躲不及的修士被卷入，惨叫绝响、**化作血雾**成为风暴的一部分。
- 幻虚子的误判（对王林有利）：更确定许木**隐藏了修为**——「若是真正的窥涅修士，在这幻真之术下，定然没有可以分庭抗衡的道理」。他始终把王林当作同级修士对待，且觉察王林体内藏着一股**连他都非常忌惮的极强气息**。
- 幻虚子续攻：双手虚空一拍，倒卷沙土再凝成**庞大的沙土仙鹤**，惊天鹤唳中扇翅扑向后退的王林。

## 四、神魔子的算计与惊变

- **青衣老者神魔子**白光闪现，舔嘴唇、目光闪烁疾驰而来。
  - 心声：「老夫**放弃联盟招引机会**，就是不愿招惹麻烦，隐藏了这么久，若非顾忌那**清水**，说什么也不会现身，只会寻找机会离开此地躲避劫难，只是眼下既然**幻虚子与这许木斗法**，却是给了我神魔子一个**立功**的机会。」
  - 性格与前史：一生修道极为谨慎，绝不做没把握之事；当年在所属修真星**用数千年屠杀无数修士、抢夺众多丹药法宝**，直到最终离开都无人知晓是他所为。在杀域界更把谨慎发挥到极限，此刻时机堪称绝佳。
- 出手方式：化作一道残丝逼近，双手掐诀凝出**两团绿色火焰**；不惧被察觉，反而散出元力使四周天地之力**大范围剧变扭曲**，以封死王林的遁术——「我看你如何施展**缩地成寸**」。
- **惊变突生**（本章结尾悬念）：就在神魔子甩手的瞬间，天空**紫雾翻滚**，一声惨哼自其中传出，**七道紫色身影从天轰然摔落**，一一崩溃，最终**只剩下一个**。

## 五、要点与伏笔

- 「联盟招引净涅修士」被两名净涅先后提及——幻虚子与神魔子都**放弃/未参与**招引，故都想借立功脱身，指向联盟隐秘主线。
- 王林的实力标尺再次刷新：以窥涅初期之表象，凭**古神之力**与净涅初期正面对撞不落下风。
- 「幻之则」是本章新增的规则设定：幻化之物可**成真**。
- 结尾七道紫色身影崩溃只剩一个，来源与身份未明，是下一章的直接钩子。
