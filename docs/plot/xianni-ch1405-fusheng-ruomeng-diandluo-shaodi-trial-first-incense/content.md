# 第1405章 浮生若梦（第九卷 云海之巅）

## 一、试炼开启：起苍香

老朱雀一改玩世神色，转为极为严肃，不怒自威、霸道尽显，「仿若他所在之处、他所说之话，就是天理」。他双手一挥喝出「起苍香」——

- 千里巨龟背上骤现 **三支苍色巨香**：百丈粗细、数千丈之长，直指天际。
- 巨龟因此形同一座祭坛，「祭坛之上，三香惊天」。

## 二、少帝试炼的规则与凶险

老朱雀当众宣示颠落之地少帝试炼之法：

1. **三香 = 天、地、人三方幻界**，受试者须逐一「魂入」。
2. 程序不难，难在两点：
   - 第一，**点香艰难**；
   - 第二，香一旦点燃，虽有数千丈之长，**瞬息即焚尽成灰**。
3. 受试者要做的：**尽最大可能延缓其焚烧**，并**在焚毁前魂归肉身**。
4. 风险：若点不燃倒也罢了；一旦点燃却无法及时脱出，**魂将被困其内随香焚烧而死**。老朱雀言明有他在，王林不至真死，但会令他失望。

### 历史成绩
- 自古至今**仅两人成功**。
- **老朱雀为第一人**。
- 另有一人**天资绝伦**：第一香 **五息**、第二香 **九息**、第三香缓至 **十四息**；老朱雀自承「即便是老夫，也不如他」。

### 王林应战
老朱雀目光如炬相询「敢不敢」，王林神色平静答：「有何不敢。」老朱雀大笑，称「我期待你给我第三次惊喜」，右手一挥化狂风将王林卷向 **左首第一支香**。

## 四、第一关：人界幻境

王林立于第一支巨香旁，人影相形微不足道；香如山，散出使人精神一振的香气。他深吸口气、右手按上巨香，双目闭合、身躯不动——**魂随香走**，进入天地人中的「人界幻化」。

幻境所见：
- 蔚蓝天空如绢绸铺展、白云点缀，却**不太真实**。
- 王林立于一座桥上，桥下河水流淌，远处河中舟坊飘来曲乐；桥两旁街市喧闹、商贩叫卖络绎不绝。
- **除他自己之外，一切人事景物皆模糊飘渺**，连桥都似随时会消散，与他格格不入。

## 五、转折：舟上青年与「浮生若梦」

王林正欲下桥，忽身子一震回头望向河道：一艘大舟徐来，舟上青年手执酒杯，前有歌姬起舞，后立数名随从。青年长笑高吟：

> 「夫天地者，万物之逆旅也；光阴者，百代之过客也。而浮生若梦，为欢几何——又为几何欢」

青年一口饮尽杯中酒。**在王林望见他的瞬间，此人样貌骤然清晰**，与四周模糊形成极鲜明对比。王林当场呆立，心神轰轰如天崩地裂——**那青年的样子，他熟悉，非常熟悉**，「几乎就是昨天」。（本章至此断，未点明其人身份。）
