# 第1773章 困兽挣扎！

## 一、王林得金印

- 王林盘膝托起金印，冰冷之感入体游转一圈后，金印光芒万丈，与其产生奇异联系。
- 该金印乃玄罗**刚刚从虚幻中创造而出**，尚为无主之宝；王林修为烙印其内，成为**第一个主人**。
- 金印性能：
  - 内封**掌尊的灭神道之术**，且以**玄劫修为**施展，威力可比掌尊亲手发挥；
  - 因由玄罗所造，内蕴**一丝九阳之力**，堪称坚不可摧。
- 王林张口将金印吞入，于元神内祭炼。玄罗深意地看了王林一眼，忽然笑了。
- 云逸封的心思王林已略猜出几分——此人心机很深，所做之事必有原因，只是眼下不欲理会。

## 二、掌尊崩心

- 掌尊恐惧到极限，**放弃杀王林**，毫不犹豫疯狂后退。
- 他心智极高、算计惊人，却想不到玄罗在此；更倾向认为是**「主人的哥哥」**找到了这里，一念之下冷汗浸湿道袍，几乎魂飞魄散。

## 三、王林诘问托森

- 王林起身追击，声音回旋天地：「**当年你以生死劫欲杀我，今日王某便同样以生死劫降临你身托森**，你既早就来临，是要与我一战，还是要帮我同战此人。」
- 托森长笑现身于掌尊逃遁身影之后，一拳轰向掌尊。掌尊化身初阳硬撼，双方各退——掌尊退数步，托森退百丈，嘴角狞笑。
- 托森主张：「**吾等神族，便要以这强悍的肉身，踏破天地，与仙一战**」，身躯膨胀至数千丈、再至**数万丈古神**之形。
- 王林**第一次完全膨胀身躯**，化作与托森一般大小，二人如两座大山，一前一后封锁掌尊。

## 四、四人合围（古之墓地倒数第二层）

| 出手者 | 手段 | 效果 |
|---|---|---|
| 王林 | 巨身重拳 / 撕天 / 古息叶封路 / 血剑 | 逼退掌尊，血剑穿透其右肩 |
| 托森→涂司 | 古神巨身重拳；转为涂司后虚空幻化雷霆长矛 | 长矛被掌尊左手抓住，被掌印击退百丈但未伤 |
| 云逸封 | 仙罡大陆神通所化紫色凶猴 | 顺七窍钻入，眉心现猴影；后自身喷血倒卷落地 |
| 唐姗（第三妃） | 右腕金色珠子 → 七门归一 → 金色巨龙 | 咬中掌尊，被其一拍崩溃；自身喷血踉跄退千丈 |

- 掌尊在拍碎金龙时**第一次在此地喷出大口鲜血**，神色萎靡，眼中恐惧更浓。
- 掌尊评估：四人虽难缠、能让他重伤，但修为差距很大，代价必定不小；最令他恐惧的仍是金印一幕，总感觉**此地还有第五双眼睛**平静地望着他，几乎让他发狂。

## 五、托森 / 涂司的身份转换

- 托森身上出现重叠虚影，其**霸道之感消散，取而代之的是沉稳与冷静**，「仿若换了一个人，似成为了苏醒的涂司」。原文明言「眼下出现的，正是涂司」。
- （据世界状态须知：托森自第1385章起占据涂司肉身，本章言行归属【拓森】。）

## 六、定字诀与血剑

- 掌尊欲遁，王林虚空一抓打开**储物裂缝**，放出**数十片古息叶**环绕封死其一切退路。
- 王林再施最强之术**撕天**，撕开天地裂缝直奔掌尊。
- 掌尊披头散发，咬破舌尖喷出**金色元神之血**，穿透撕天裂缝直射王林——若被落下，王林定会危机。
- 王林神色冷静，口吐一字：「**定**」——定天、定地、定一切规则。血液如颗粒般停顿一瞬，王林从容避开并挥出**血剑**。
  - 代价：**反噬之力在其体内爆发**，被强压下后面色略显苍白。
- 定身术效果消散后，元神之血落地，滋滋作响，大地深深凹陷。
- 血剑极快，几乎在掌尊喷血同刹那便至，**从掌尊右肩穿透而过**。

## 七、局势与伏笔

- 掌尊另感受到**蓝芒道尊（蓝梦）**气息正急速而来，判断「若蓝梦再出手，他今日危矣」。
- 云逸封内心笃定：「这洞府核心内，王林没有失败的可能，这一计，我绝不会走错。」
- 章末：掌尊眼中血丝弥漫，抬手一指天空，怒吼「你们找死——井中捞月」。
  - **井中捞月**：掌尊道术，以大地为井、倒映天空一切，从井内捞出倒影、取魂杀之。王林曾见过几次，每次都带来极深震撼。
