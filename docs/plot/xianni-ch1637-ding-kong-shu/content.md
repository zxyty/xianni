# 第1637章 定空术

## 一、战斗经过

1. **追击入坑**：王林化作闪电直奔被砸出的深坑，坑内传出愤怒闷吼与万丈暗金光芒（色泽暗淡略带紫意、并不精纯），如风暴自坑口宣泄。
2. **对方现身**：一个干瘦身影自坑中冲出，怒喝「汝敢向吾出手，汝冒犯仙威，汝必须要死」。
3. **虚空一抓**：王林时为**空灵境中期**（已破开空门、轰碎天劫），随意向虚空一抓，天地规则扭曲、尽从其神意，老者反抗无效，被掐住脖颈。狠捏之下老者只喷血雾而未崩溃，其肉身坚韧令王林轻咦。
4. **老者自陈**：斥王林「下界之修」，称「本仙若非早年重伤，杀你如捏死蝼蚁」，神色高傲。
5. **掌印轰天**：王林将其抛向天空，掐诀一掌按去，巨大掌印吸收天地之力化作无穷之大，自地面轰向天空，一轰而过；老者喷血，**左手（左臂）崩溃成血肉消散**。
6. **一步瞬移**：王林大袖一甩，一步迈至老者身后拍出一掌，老者再度重伤、面色苍白、满目惊恐。
7. **保命被定**：老者咬破舌尖喷出散发金光的鲜血欲行保命手段，王林右手一指喝「定」——鲜血凝固半空，老者身体乃至岁月与天地的转动尽皆停滞。
8. **搜取记忆**：王林走上前，右手按其天灵：「让我来看看，当年的这里，到底发生了什么。」

## 二、干瘦老者的来历（本章披露）

- 身份：**仙尊百兵护卫之一**，恒古岁月之前曾随意喝斥、处置所谓「下界之修」。
- 现状：早年一场大战中重伤，**选择进入一尊八星半的吉神体内寄生借力疗伤**，存活至今，伤势历无数年已接近好转。
- 苏醒缘由：察觉自己寄生疗伤的**吉神胚体被人毁灭**，愤怒之下苏醒，一眼认出王林并非仙人，而是「这洞府界内诞生的蝼蚁」。
- 体质：体内蕴含**驳杂的仙人血脉**，样貌其貌不扬、看似虚弱，但肉身极为坚韧。

## 三、关键设定信息

### 1. 逆修与天劫
- 老者惊呼：「**逆修，你是下界逆修**」「当年**主人设置了天劫，就是为了防止逆修出现**，有天劫在，这世间不可能有**第三步逆修**」。
- 佐证范围：「莫说是主人这里，就算是**仙罡大陆**上的诸多大能洞府内，也从未听说有下界蝼蚁逆修成第三步者。」
- 推论：天劫的设置带有针对性——是仙人一方（老者之「主人」）用以压制下界逆修者的手段。

### 2. 定空术
- 归属：老者失声道「**定空术，这是仙尊大人的大神通**」，并连问「他怎么会此术，他如何学会，是谁传授给他」。
- 效果：一指定住目标肉身、已喷出的精血，**连岁月与天地的运转一并停滞**；被定者神魂尚有一瞬清明可思考。
- 悬念：王林习得仙尊大神通的来路，本章未给出答案。

## 四、看点与悬念

- 王林在空灵境中期已可**碾压等闲仙人**，且掌握仙尊级大神通。
- 「第三步逆修」被仙人一方视为绝不可能出现之事，天劫即为此设——王林恰是打破该禁忌者。
- 老者被搜魂前的最后画面，指向「**当年这里到底发生了什么**」的往事真相，为后文伏笔。
