# 仙逆 第1553章 重玄子

## 一、开场：王林拉弓逼问
- 王林左手所持之弓弓弦原本断开，与其血脉融合后重新恢复；但此弓弦一旦拉开，如同拉扯王林自身之筋。
- 王林不顾后果，右手抓弦猛拉，青筋鼓起、面色苍白、双眼血丝弥漫。其心智虽变，本性未改——**一旦决定之事绝不退缩**，为救清水不惜一切。
- 弓上传出莫大之力，仿若可崩溃天地。王林语出阴寒：「我之前所说，是真是假，你去问问你的徒弟。」

## 二、龙磐子苏醒与身份确认
- 白芒内老者抬头，称王林为「**封尊**」。
- 此老者即修真联盟**太上长老龙磐子**，为当年沉睡后**第一次苏醒**，苏醒原因是其徒**重玄子**的召唤。苏醒后不知前后之事，只见王林欲毁星而来。
- 龙磐子虽沉睡，仍记得自己是**界内之修**，记得当年**封尊之恩**，因而选择查证。

## 三、审判：三人被抓出
龙磐子挥手自修真星内抓出三人：
| 人物 | 身份 | 结局 |
|---|---|---|
| 重玄子 | 龙磐子亲传弟子，容颜由当年中年变为老者 | 被师尊以命换命保下 |
| 张夕 | 修真联盟现任大长老，龙磐子沉睡时的座下童子 | 因畏惧重玄子而犹豫不敢作证，被白芒轰杀，血肉四溅 |
| 另一大长老 | 修真联盟现任大长老 | 被按天灵搜魂后捏碎，形神俱灭 |

两名大长老初见龙磐子即跪地称「参见太上长老」；重玄子称「见过师尊」，被龙磐子一眼逼得噤声。

## 四、重玄子的供词（核心信息）
恐惧之下，重玄子把所有事情自行说出（龙磐子搜魂其实只是做样子，并未得到太多）：
1. **界外入侵**：界外太古星辰之修大肆入侵，界内根本不是对手，反抗无用。
2. **投诚交易**：为守护联盟、令其延续，与界外达成协议；界外**长尊会**承诺保修真联盟万载延续。
3. **旧怨**：近千年前**罗天星域**发动大军与联盟一战，联盟四分五裂，仅总部保存；当年他呼唤师尊而未获回应，自此对界内毫无感情——「他们既然能来攻打我联盟，凭什么我联盟就不能去帮界外之修」。
4. **七彩界来历**：七彩界为当年龙磐子所发现，其时已有界外之修出现，被龙磐子斩杀并将七彩界封印，**修真联盟总部即建于此地，目的就是镇压此界**。
5. **投降论**：界外**掌尊**之强，师尊怕也不是对手；界内败亡已成定局，不如投奔界外获取造化。
6. **推卸责任**：破开七彩界封印非其本意，是**清水仙君**杀入此地后逼他破封，七彩界是清水仙君打开的，「他才是罪魁祸首」。
   - 此言令王林双目一凝；身后的**炎雷子**眼中露出滔天仇恨，呼吸急促。

## 五、龙磐子的驳斥与旧事
- **联盟本意**：「老夫当年让你成立修真联盟的目的，不是为了控制**昆虚**，而是为了在那残酷的环境下，提高我昆虚修士的修为——为的，便是与界外一战。」
- **界内规则**：界内之事再如何厮杀也与界外无关，只要界外没有杀人到此地，老夫便不会苏醒；联盟兴衰自有天意。
- **看破交易**：界外之所以与重玄子勾结，是因看到龙磐子融入修真星；必是重玄子说出师尊的存在，**以师尊为资本换取造化**。
- **师徒往昔**：重玄子本是乞丐童子，故乡传闻爬上某山若有仙缘可见仙人；他用**十七天**、鲜血淋淋爬上山顶见到龙磐子。因其体弱不能修仙，龙磐子怜其坚毅，为其调养身子、取来**天地五脉人体**使其拥有**道骨**。龙磐子唤其乳名「**宋儿**」，忆其幼年愿望是**富贵还乡**。
- **痛惜结论**：「你如今却没有了一颗**道心**。」

## 六、以命偿罪
- 龙磐子大袖一甩掀起白色风暴，重玄子绝望闭眼待死——风暴却未伤他分毫，反将其卷到龙磐子身后，**避开王林拉开之弓的笼罩**。
- 龙磐子宣告：「你犯下了滔天之罪……但，你是我的弟子。弟子之罪，我有责任。你之过错，便让为师代你偿还吧。」转身向王林**深深一拜**：「封尊，他所犯的一切事情，我龙磐子，承受。」
- **自毁献祭**：一掌拍胸，喷出元神之气；其身下巨大修真星随之草木枯萎、山脉坍塌、河流蒸发、沟壑弥漫、四分五裂，一道道白气升起尽数融入龙磐子体内，其虚幻之身骤然燃起火焰。
- **交换条件**（龙磐子自述）：
  - 代价：断绝生机，换取元神燃耗，可爆发**空玄初期**实力。
  - 承诺：杀尽如今界内存在的所有界外修士；毁去除此地外所有七彩界；收回已沦陷的**召河**。
  - 所求：换取重玄子一命。
- 重玄子清醒后跪地磕头，悲伤悔恨；龙磐子轻叹一声，卷起重玄子远去。

## 七、结局：裂缝重开
- 龙磐子临去留言：「我了解我的徒儿，他行事会做两全的准备。那清水仙君之所以无碍，这是重玄为了活命，为自己留下的护身符。」
- 一股白色风暴凭空出现，直奔崩溃修真星下的**血色裂缝**，将其大范围撕裂，红光消散，露出其下**七彩之芒**——**清水，在那里**。

## 八、章末作者感言（非剧情）
耳根自述当月八十更承诺压力甚大，睡前扒手指计算还差多少章，女儿在幼儿园学会数数后在旁边说「还差100章，还差200章」。
