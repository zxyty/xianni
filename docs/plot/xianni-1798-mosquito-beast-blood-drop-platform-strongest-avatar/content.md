# 第1798章 未来最强分身！（第三更）

## 一、蚊兽寻主：舍命蜕变与十万分化
- 蚊兽不顾一切蜕变进化、甚至**吞噬同伴**，唯一目的是找到主人王林。
- 蜕变代价：已无身体，只余一片模糊雾气；速度极快，刹那弥漫无尽虚无。
- 寻主心急之下，其身崩溃，整团雾气**化作十万份、十万只烟丝蚊兽**，分向十万个方向搜寻，嘶鸣如呼唤主人。

## 二、找到「尸体」与棺材
- 虚无深处某片区域，漂浮着一具尸体与一具棺材，已数十年。
- 尸体右手死死扣住第十卷（卷轴），断臂也不松手。
- 尸身之上、尤其胸口，凝聚出一片**黯淡白芒**——与王林当年吸收的那两具尸体之光一模一样。
- 一只巴掌大的烟丝蚊兽掠过后猛然回头，激动惊天嘶吼；四周烟丝呼啸而来，十万蚊兽尽数汇聚，重新化作**王林的蚊王**。
- 蚊王双眼通红，以巨大口器数次轻碰王林，试图唤醒，屡试屡败，嘶吼沙哑，绝望悲哀。
- 性格简单的它无法接受主人已成尸体，遂卷起王林与棺材疾驰而去。

## 三、虚无层中的弧形平台
- 蚊兽经五次蜕变，对蕴含**仙罡法则**的虚无层毫无不适，且体内留有模糊记忆：虚无中似有一处可让主人苏醒的位置，但极为隐秘、须寻找许久。
- 所寻之物：虚无内第一处**略有弧形的大陆**，实为一片**巨大弧形平台**。
  - 形状不规则，仿若某种物品的一部分；大小约万丈；其上散发白色光芒，与王林先前吸收的两具尸体之光相同。
  - 台上空无一物，外覆**无形隔膜**（纯由仙罡法则凝聚），阻止一切外物踏入。
  - 强度：莫说王林，**连玄罗也很难破开**。
  - 唯有仙罡法则中诞生的**仙祖、吉祖**及伴随他们的**九种奇异之兽**可融入法则、进入其内。
  - 蚊兽模糊记忆中，其**先祖**似乎正诞生于这样的弧形平台内。

## 四、送血入台：蚊王的舍身之举
1. 卷着王林与棺材撞向隔膜——蚊兽独自进入，王林与棺材被挡在外。
2. 反复数次失败后，取王林一缕头发送入——蚊兽入内，头发被阻挡飘散。
3. 蚊王发狂，将巨大口器缩成针尖刺入王林近乎干枯的身体，小心吸出**一滴鲜血**，吞入体内、以雾气烟丝层层包裹。
4. 携血冲膜：身子刚入一半即痛苦嘶吼，如被卡住；不吐出鲜血便无法通过，挣扎无果。
5. 最终蚊王全身雾气急速收缩、身子骤缩，把全身精华凝聚包住那滴血，因口器在隔膜之内，猛地向外一吐——鲜血射入隔膜内部。
6. 隔膜内不容外来之物，鲜血入内即刻气化；蚊王冲入以身护血，身子迅速消散、缩小大半，终使**一丝鲜血落在平台地面**。

> 古往今来，这是第一滴不属于仙罡法则的外来之物落在这平台之上。

## 五、造化的成立条件（原文归纳）
1. **能踏入虚无并寻到平台**：能入此地者本就不多，多半死亡或迷失；平台位置不固定、不断漂浮，若非蚊兽多次蜕变后的模糊记忆感应，寻无数年也难得。
2. **有灵兽舍命送血**：平台阻止一切非仙罡法则所化之物进入，须有如蚊兽这般宁可自身死亡也要送血入内者；几乎从不认主的蚊兽做到这点，本身即是造化。
3. **血主须为虚无内已死亡或沉睡、且尸身能散发白芒者**：白芒实为仙罡法则的一部分，唯有极个别之人死后才会出现；具体条件无人知晓。

## 六、结果：新的「自己」与王林苏醒
- 鲜血被平台吸收，平台一震，无形波纹弥漫整个虚无层，四面八方白光急速幻化冲入平台。
- 平台轰鸣渐烈、蠕动柔软，边缘抬起如手掌握拳般收拢，化作**巨大空壳**；蚊兽兴奋飞出，在外守护王林。
- 空壳内弥漫血气，一边融合吸收白芒一边闪烁，最终凝出**人形虚影，样貌正是王林**。
- 虚影渐清之刹那：
  - 沉睡数十年的王林**缓缓睁眼**；
  - 感到一股力量自冥冥中传来，进入血脉滋养身体；
  - 体内**道古之力骤然恢复**；
  - **七道本源刹那达到巅峰**；
  - 隐隐感到「似有另外一个自己，存在于这天地之间」。
- 王林看到兴奋激动的蚊王，以及身旁如巨大果实一般的石壳，依稀看到其内另一个自己，心中一片迷茫：「这是什么？」
- 定性：此乃王林**修道两千多年来最大的一次造化**，标题点明其为「未来最强分身」。
