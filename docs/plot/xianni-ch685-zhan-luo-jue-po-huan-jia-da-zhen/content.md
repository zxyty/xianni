# 第七卷 名震罗天 第685章 斩罗诀！

## 一、斩罗诀的来历
- **巨富**：王林在**恒岳派**获得的第一把飞剑。文中点明当年那弱冠少年握剑一刹那便注定日后一切，其间失去、得到，是数百年因果一晃而过。
- 剑内蕴含**上一代雨之剑魂的一道魂技**：不是仙术、不是道术、更不是神通，而是**一剑式**——一道传承于远古剑意的极强之式。

## 二、一剑破阵
- 时机：仙卫（傀儡）与雷兽不断进攻打压幻家大阵，阵法不堪负重的一刹那。
- 施展：王林握**仙剑**，眼中平静之光化为剑光，**人与剑相融**；仙剑起、落。
- 表现：一落之下天地陷入虚幻黑暗，仙卫、雷兽仿佛尽数消失，世间只剩这一落；**无剑气、无仙力运转**，却给观者来自灵魂的震撼，好似开天辟地、把天地从混沌中撕裂。
- 结果：**幻家大阵在没有任何实质接触与打击下崩溃**，世间一切声音消失。收剑后王林**面色苍白**，眼中寒芒更浓。

## 三、各方反应
| 观者 | 反应 |
| --- | --- |
| 幻家老祖（幻无情） | 双眼睁大，失声：「这……这是规则」 |
| 幻封神（问鼎后期） | 倒吸凉气；滔天杀机烙于心神，身体一僵，退后数步；看不出规则，但感到剑中似蕴含天道、更有撕裂天道的凌厉；心跳急速加快，错觉天地崩溃 |
| 幻家嫡系族人 | 隔着大阵仍如身临其境，随剑势与天地一同被撕裂，汗湿衣衫，死亡恐惧蔓延 |
| 千葵子（千家密室，神识遥观） | 猛地站起：此剑蕴含**规则**，正是修道第二步所求（第一步感悟天道→第二步规则之力）；断定「此子若不是**雷仙殿**之人，怎么可能施展如此一剑」 |
| 许家苍发老者 | 原按与幻家老祖的协定欲出手相助，抬起的脚轻轻放下：剑式很强，且此人敢挑战幻家「定然还有后手」 |

## 四、斩罗诀的代价（设定）
- 影响极大，**与修为无关**：施展需要体内**与元神紧密融合的元气**。
- 问鼎修士元气与元神不分彼此，斩罗诀却能生生分离出一部分；问鼎修士元气固定，**一旦失去过甚，修为会大范围退步**。
- 王林因**周佚的问鼎之晶**，元气比寻常问鼎修士多出一些，故有余裕。

## 五、幻家请出福泽玉简
- 幻无情断言：修道第一步与第二步差距太大，此剑式若以第二步修为施展尚有看头，此刻无用；「今日，你破我幻家大阵，却是必死无疑」。
- 一声「请，祖玉」，幻家祖宅升起浩淼祥和之力；**祠堂内一枚金色玉简（福泽玉简）**飘起升空，在千幻星上隔绝出一片天地，**幻家祖宅自成一界**。
- 玉简内蕴**幻家那位雷之仙界先祖的仙法**。幻家正是凭此玉简与先祖留下的**一件仙宝**才有今日地位。
- **仙宝下落**：随**幻无相**于数千年前一同失踪。幻无情暗道，若仙宝还在便不必请出福泽玉简。
- 旁观补充：
  - 千葵子——幻家仙人玉简威力莫测，传闻那位仙人**修为堪比净涅期**；奇怪幻家老祖为何不拿先祖遗宝而请玉简。
  - 许家老者——幻家仙宝**应被（许家）宗族的长辈取走**，且因这仙宝**死去了幻家一个踏入第二步的修士**。
- 幻无情的算计暴露：他忌惮王林的剑气，故先请千葵子出面、再以幻家大阵消耗之，自己不到万不得已不亲自出手；不料千葵子不战而退，大阵又被雷兽＋仙卫傀儡＋规则一剑合力破除。

## 六、幻家分裂——幻封神退出
- 幻封神以**幻家族长**身份上前：「此事，我幻家绝不参与……老祖要保护这**幻眉**，那是私人恩怨，还望莫要把整个幻家拉下」，并向王林抱拳请其分清曲直。
- 幻家老祖环顾嫡系问「你们呢」，嫡系沉默片刻后**纷纷走到幻封神身边**。
- 老祖阴森一笑：「一群废物」，随即掐诀一指：「**福泽玉简，杀了此人**」。
- 玉简人影向前踏步走向王林，仙力爆发浓烈到**把千幻星天地灵力全部挤压**，整星皆响起砰砰碎响；其身四周隐约有仙音回荡，目光视世间如蝼蚁。
- 仙卫傀儡与雷兽一闪来到王林身边护持。

## 七、王林的底牌与因果之言
- 柳眉抬头望王林，眼中依然复杂，**摸了摸储物袋，随即放下了手**（欲有所动而止）。
- 王林敢独闯千幻星、杀入幻家祖宅，凭的是**当初那疯狂的念头**，也是此刻最强的杀手锏。
- 想起**仙逆内的怨婴**，王林心中一阵绞痛。
- 王林语：「这世间之事，逃不出因果，当曰之因，今曰之果，唯有把这因果了却，让尘归尘，土归土，才算平了一段轮回。」
- 闭目，元神中果断呼唤：**「此战结束，放你自由」**；一声厉啸自王林元神内疯狂传出——底牌出场，章节收束于此。

## 八、伏笔与待解
- 王林元神内被唤醒者（与「仙逆」中怨婴相关）的真面目与战力。
- 幻家先祖仙宝的下落：幻无相失踪、许家宗族长辈取走、并牵涉一名踏入第二步的幻家修士之死。
- 千葵子对「雷仙殿使者」身份的误判将如何延续。
- 王林是否会因斩罗诀元气损耗而在后续付出代价。
