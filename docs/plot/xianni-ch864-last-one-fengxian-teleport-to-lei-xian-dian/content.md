# 第七卷 名震罗天 · 第864章 最后一人

## 一、封仙之争中的窥涅期修士

- 参与封仙之争者中**有窥涅修士，但为数不多**。这类修士往往已是**一族老祖**，身负家族牵制，一言一行、每个决定都需谨慎。
- 在小辈修士云集的封仙之争中，老祖出手会落下「与小辈抢夺」的恶名，得不偿失。
- 众人已看出端倪：**雷仙殿要的这一百零八仙，重的是昂然战意，要的是小辈之中的强者**——雷仙殿虽未明言，但蛛丝马迹可辨。
- 罗天南域内窥涅者只有寥寥数人，皆不便与王林结仇：
  - **「许木」之名太大**；
  - **「魔道子」**这一称呼至今仍透着血腥味；
  - 许木一向低调，此番却高调出场，摆明是要资格中的第一位——既然如此，送他便是，不必结下仇隙。

## 二、七日静修与访客

王林在**地炎星**修真家族安排的居所盘膝打坐七日，调整元力、保持巅峰状态，以待罗天星域内的最终一战。

### 申公虎来访
- 七日内**第一个到来者**。
- 不再追问王林此前修为之事，转而**与王林论道**，事后略有收获，躬身离去。
- 其眼中恭敬虽不算浓，却确实存在——此刻的王林已得到他的认可。

### 陆续拜访
- 申公虎走后仍有人陆续来拜，直到**第四天**才安静下来。

### 南宫寒纠缠与许立国之厄
- **南宫寒**反复来访，目的只有一个：**求取「缩地成寸」神通**。
- 王林被扰烦，**直接放出许立国**，明言此神通许立国也会，随后甩袖离开，另寻地炎星一处安静之地打坐吐纳。
- 南宫寒虽不信王林之言，却发现与许立国「很是投机」，拉住不放、不断交谈。
- 许立国初时无所谓，时间一长渐渐受不了，最终极为痛苦：**打不过、不敢反抗、无法离开**，只能哼哈应付，内心煎熬，只盼七日快过、主子快回。
- 第七日王林睁眼，神识一扫寻到许立国，见状皱眉：**许立国魔头之身已然涣散，几乎就要崩溃**。
- 许立国不顾一切冲出哭诉：自称「**小许子**」，求主子开恩带其回去，称南宫寒「太可怕」。王林抬手将其收入储物袋。
- 南宫寒状态极佳却略显尴尬，搓手道：「许兄，你这**器魂**很好，我与他一见投缘，日后要好好亲近一下。」
- 王林皱眉转身离去；南宫寒一脸遗憾紧随其后，内心暗道：多好的器魂，可惜打不过这许木，不然一定抢来。

## 三、启程：星空外的传送阵法

- 罗天南域余下的**一百零七人全部选出**（合王林共一百零八人）。
- 星空外，**紫衣老者**从储物袋取出一枚**黑色石头**，捏碎之下晶光无数，星空下浮现一座**虚幻阵法**，占地方圆百丈。
- 紫衣老者当先踏入，**两名青袍雷仙殿使者**紧随其后，进入阵法即消失不见。
- 余下百余人陆续走入，王林亦在其中；一百零八人里，**战空烈、申公虎**等人一一在目。
- 阵法光芒闪烁，携一百零八人消失。

## 四、雷仙殿：设定与禁制

- **雷仙殿**是罗天星域内极为强大的势力，历经无数年、在一代代殿主扩张下，**隐隐成为罗天星域明面上的最强者**。
- **所在极为神秘，无人知晓具体位置**；即便雷仙殿使者回返，也须以**特殊传送阵**往来，除此再无其他通路。
- 此时雷仙殿**方圆十万里内处处禁制**，使者与仆从般的修士弥漫四方。
- 封仙之举是雷仙殿无数年来极重要之事，**十万里内禁止一切私斗**，违者雷仙殿立刻干涉。

### 四方传送阵
- 雷仙殿四周有**四个巨大传送阵**（东、南、西、北）。
- **北部之阵**先亮，一众修士在赴北域的使者带领下走出，神情平静、少有激动者，走出之际战意弥漫。
- **南、西两阵**几乎同时光芒大作，大量身影涌出，王林身在其中；走出后目光一扫，神色毫无变化。

### 王林对禁制的判断
- 雷仙殿庄严如凡人界帝王皇宫，其上有可怕的禁制波纹隐晦透出。
- 以王林对禁制的了解，清晰感到：**雷仙殿上的禁制几乎恐怖到极点，以他的修为若处其中，也是必死无疑**。
- 更甚者：**四周一草一木、乃至天空白云，全部蕴含极强禁制**。

## 五、转折：东部传送阵的「最后一人」

- 众人凝神观察之际，**东处传送阵**光芒一闪，吸引所有人目光。
- 阵中先露出**三个身影**——正是派往**罗天东域**的三名雷仙殿使者，此刻**面色极为阴沉**，迅速走出；其中一人走出几步后回头看向传送阵，目光中**露出一丝恐惧**。
- 随即一股**浓郁血腥味**从东部传送阵内透出，传送阵光芒闪烁之下，**只出现了一人**。
- 此人开口：「**不用等了，其余的一百零七人，全部被我杀了。**」
