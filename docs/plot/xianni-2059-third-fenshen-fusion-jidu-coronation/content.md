# 第2059章 曾见

## 一、祖庙内：第三次分神

### 心结
- 章首王林盘膝于祖庙内，默数已度过的六十八年，念及第二次分神时所见的**抱着尸体的身影**——「那身影属于谁，其抱着的尸体又是谁」，不敢想、不愿想、害怕去想。
- 自语「时间，不多了」。随后驱除杂念，全身心投入古道第三次分神。

### 皇城观感
- 古祖雕像上浮现**二十七道光环**，始古皇城哗然至顶点。
- 众人议论：第一次分神三年、第二次十五年，此番仍是彻底分裂、完美融合；第二次融合明显出过意外；普遍认为第三次极难度过，「我若是他，这第三次索性提前结束，以保万全」。

### 分神与融合过程（按年份）
| 时点 | 进展 |
|---|---|
| 第三次分神起 | 巨大元神光影自凝实中开始分裂，为最后一次 |
| 第7年 | 分神持续，始古族人日常仰望古祖雕像光环 |
| 第22年（入祖庙满90年） | 元神光影碎裂成无数碎片，进行最后粉碎 |
| 第95年 | 碎片彻底化为碎末，开始尝试融合 |
| 第96年 | 融合近三成，光影仅巴掌大小，元神强度已数倍于第二次分神时 |
| 第97年 | 凝聚五成，再强不少 |
| 第99年（即第100年前一年） | 实已可完成融合，融合极为顺利、无任何意外 |
| 第100年 | 光影恢复至与身体一般大小、光芒四射、看似完整，但双目紧闭 |

**关键改良**：吸取第二次意外教训，在身躯中预留一丝神识作「唤醒锚点」；融合不一次性完成，而是一部分一部分凝聚直至完美。

**预期收益**：若第三次成功，元神归位与肉身融合的一瞬，将达一种巅峰程度——**或许可以超越古道**。

**代价**：数十年元神分裂之痛被生生忍下，王林甚至对痛已生出一丝麻木。

## 二、祖庙外：始古新皇更替

- 始古皇尊与计都之间的权力过渡接近完成；距计都登基还有二十五年时，皇尊将无数始古军队交予计都，令其有足够时间熟悉，以迎接**数百年后或将出现的仙吉大战**。
- 至第90年前后，始古皇尊已退居幕后，计都全面主政：「还没有带上皇冠，但他却已经穿上了皇袍」。
- 计都保持每天清晨望向祖庙的习惯，坚信义父必定成功。
- 第97年，计都放弃所有事务，独坐祖庙外打坐，要在成为皇尊前的三年陪伴义父。
- 祖庙所在千丈范围早已划为禁区，禁止任何人踏入，四周由皇宫侍卫守护；与皇城的喧腾形成对照。

## 三、登基大典之日（第100年当日）

- 始古族人尽归皇城，另两族使团亦携厚礼隆重而来，领队皆为地位尊高的皇族。
- 广场中心设**巨鼎**，鼎内松软泥土上立一根未点燃的巨香——**皇权香**：唯计都有资格点燃；香火一起可幻化风云、凝聚出**震天鼓**；此鼓亦唯计都可敲，鼓声九下回旋天地时，计都将受全体始古族人一拜。
- 老者提醒「吉时将到」，始古皇尊沙哑道：**「等下去，我始古一脉没有什么吉时，当计都来临的那一刻，就是吉时」**。
- 黑甲侍卫至祖庙外跪禀「陛下，时间到了」，计都不动；半柱香后轻叹起身，单膝跪向祖庙磕三个头，道「**义父，孩儿去了**」，转身率众远去。

## 四、章末转折：曾见之世界

- 王林并未在能完成融合的第一时间收功，而是**刻意保留一丝缺陷**，整个人沉浸其中如沉睡。
- 深层动机：想再次进入第二次分神时所见那片模糊天地，去看那座**飘落七彩雪花的山**，去看那道身影，去听那身影**完整的话语**。
- 他自己也不知当时是如何进入那模糊世界，甚至不知那是何地；经一年尝试与思索——恰在计都带人远去之时，王林脑中有了模糊，他依稀似看到了**那曾见过的世界**（呼应章名「曾见」）。

## 五、时间线锚点
- 王林踏入祖庙至本章末，累计**一百年**；其中第三次分神占约二十七年（第73年起算）至圆满。
- 计都登基与王林第三次分神圆满**同日**发生。
