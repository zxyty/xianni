# 仙逆 第1977-1978章：册封白发跃天尊与风雪长街杀局

## 一、第1977章：祖城重逢失忆的疯子

### 相认失败
- 花衫青年（疯子/道非）在册封大典现场高喊寻找「恩公」，却认不出眼前的王林——王林看清其双眼内**没有丝毫对自己的记忆**。
- 王林落地轻唤「疯子」，反被对方怒斥「你才是疯子，本王可厉害了」。
- 疯子绕王林转了几圈，仍只勉强承认「就算你是」，随即质问是谁把「小花花的爷爷」打成那样，手指远处的国师。
- 仙皇自仙道殿内出声呵斥：**罗工挑战王林失败，与国师无关**，令道非退下，否则再次将其关起来。
- 疯子理不清头绪，抓过身后的青衣少年要其「捋顺分析」。

### 许立国的灵魂震颤（伏笔）
- 许立国目光与王林对视的一瞬，**身子自灵魂深处一颤**，呆望王林，恍如梦幻、似曾相识，下意识喃喃「**煞星主**」——似有记忆要苏醒。
- 记忆苏醒被疯子抓肩摇晃打断；许立国清醒后面色苍白，反指认「就是他打伤了小花花的爷爷」。
- 疯子当即上前双手掐住王林脖子扬言掐死他。王林闭目掩去悲伤，确认**疯子没有洞府界的记忆**。

### 仙皇出面与兄长之情
- 仙皇走出仙道殿，右手一挥将疯子如柳絮般震退，青衣少年与许立国连忙跟上。
- 令「黑甲禁兵」将疯子送出皇宫、不许再进；疯子远去时仍放话「这事本王记住了」。
- 疯子经传送阵离去后，仙皇轻叹：道非自回来后便是如此，**记忆时而模糊、时而清晰**，或许清晰时能认出王林；并说「我只有这一个弟弟」——此刻的他不像大天尊、不像仙族之皇，只像一个哥哥。

## 二、册封：仙族第四十九位跃天尊

- 挑战仪式取消。仙皇以王林**闯过十七层天尊涅**为由，册封其为**仙族第四十九位跃天尊**。
- 赐号依据：王林素有白发之称，又获得**天狮兽炼化后的白发**，故赐称号「**白发跃天尊**」。
- 跃天尊待遇：可进入**仙祖闭关之地**感悟一次，获巨大造化、修为亦会增长，为日后成为大天尊打基础。
  - 仙皇一脉：一生至多三次；
  - 非仙皇血脉之修：唯有成为跃天尊时才被赐予这一次机会。
- 仙皇希望借此化去与王林之前的误解，期许其早日成为仙族第六阳、栋梁之辈，「再塑仙祖之威」。
- 仙皇additionally透露：当年发现疯子时，其身边还有**一名女子**，如今已苏醒，正在仙祖闭关之地感悟；并愿让道非也去那里，或许王林能让他慢慢想起往事。

### 王林的拒绝
- 王林抱拳婉拒：「王某此来只为册封，如今册封结束，也到了该离去之时。」
- 内心独白：对仙皇的抵触**没有任何理由，只是一种直觉**；「误解也好，没有误解也罢，谨慎与提防，不能因几句话改变」，故那仙祖闭关之地不能去。
- 仙皇沉默点头，不再劝说。

## 三、离意与去向

- 大典于正午阳光最浓时结束，王林谢绝在皇宫居住，独自出宫、以传送阵离去。
- 未再留于李府，带着**海龙**与**刘金彪**回到东城酒楼房间，在窗前站了一下午。
- 心境：「见到了，即便他失去了记忆，但如今的他似很开心，也就足够了」；在仙族所得地位与修为，与往昔好友失忆相比都显得微不足道。
- 决定：**带上许立国，离开仙族祖城，去往古族**。

## 四、风雪夜访：海子天尊的邀约

- 入夜风雪起，敲门声温和不疾不徐。**海子天尊**长发散雪而立，奉师尊之命邀王林去**帝山**：「如今的帝山没有红叶，但有雪。」
- 王林应允：「久帝大天尊邀请，自然要去」，并言「从帝山下来，就会走」。
- 设定要点：**祖城除特定地点外因禁制不能随意传送**，帝山在祖城有一处专属传送阵。

## 五、第1978章：长街杀局

### 危机降临
- 长街两旁屋舍漆黑无火，阴森萧杀，雪中隐藏杀机。王林脚步骤停、目露寒光，感到强烈危机；海子天尊亦察觉「**有封印禁锢的波动**」，并立刻解释「没人知道我来找你」。

### 双向夹击
- **前方**：九千九百九十九片雪花受牵引凝聚成**四方形图案**，速度暴增、吸雪膨胀至近百丈，呼啸扑来。
- **后方**：长街末端同时凝成**三边形图案**，其内煞气滔天，吸收飘雪疾驰而至。

### 应对
- 王林道「**你后我前**」，未怀疑海子天尊——尽管此事表面与她关联极大，但他更信自己的直觉。
- 海子天尊愤怒：有人借她邀王林去帝山之机设局杀人，一旦成功必轰动仙族、牵连师尊久帝大天尊。她不作解释，转身把后背交给王林，化长虹迎击三边形图案。

### 王林的九十九道神通一拳（递增）
- 三步落下，**天牛魂**自面部瞬息弥漫全身，毫不犹豫展开最强力量。
- 一拳轰出，幻化**九十八个虚影**，各挥一拳与本体融合，相当于**九十九道神通**凝聚。
- 拳内本蕴含**二十三道神通**——以二十三道驱使九十九道，力量涣散无法发挥最强之力。
- 故这一拳在轰出中**三次停顿**：
  1. 第一顿：**五行真身**重叠本体，神通由二十三道暴增至**四十六道**；
  2. 第二顿：化作**六十九道**；
  3. （第三顿内容本片段未展开，章节在此中断。）

## 六、悬念与后续线索

- 布局者身份未明：能在祖城长街布下封印禁锢、雪化几何杀阵，且知晓海子天尊的邀约行程。
- 许立国的「煞星主」记忆是否会彻底苏醒。
- 疯子（道非）与那名已苏醒女子同在仙祖闭关之地，王林却拒绝前往，留下重逢的悬置。
- 王林下一步目标：携许立国离开祖城，前往古族。

# 第1978–1979章 长街血战

## 一、禁锢封印：四方形图案与「无」之力

- 王林一拳与四方形图案相触，拳劲第三次刹顿，神通剧增至**不动用虚无分身时最强的九十二道**；有魂铠配合，以九十道神通驱使九十九道，一拳浑然一体。
- 轰击之下天地色变、风雪倒卷，百丈内雪花尽碎如虚无黑洞；四方形图案被直接崩溃瓦解。
- 图案内藏一股诡异力量趁势钻入王林体内，化作**细密大网**，寄生于经脉血肉，形成覆盖全身的**禁锢封印**。
- 王林辨出这是**属于「无」的力量**——「因有了存在，故而失去后，方可称之为无」。此力他此前**只在国师上玄道身上见过**。
- 该禁锢王林一时无法全解，只能略作延迟；未破开则影响战力发挥。

## 二、第一波：十五名「天尊」五方围杀

方位与手法（皆被风雪笼罩、看不清相貌）：

| 方位 | 人数 | 手段 |
|---|---|---|
| 前方 | 3 | 右手掐诀，凝风雪化三掌 |
| 左侧 | 3 | 右手拇指点击 |
| 右侧 | 3 | 左手小指点击 |
| 后方 | 3 | 左手掐诀化掌 |
| 上方 | 3 | 右手持银剑刺天灵 |

- 十五人皆具天尊修为，专取王林被封印的一瞬发难。
- 王林展开魂铠全部之力，体内**道吉**弥漫使肉身坚韧，右脚踏地**后退借力**，以后背硬撞身后三掌。
- 三名后方者被肉身之力反震喷血、风雪散去，露出**三名陌生老者**面孔；王林穿过其间，双手各抓一颗头颅捏爆，**收取并吞入两枚元神**，第三人被再次撞散而死。
- 余下十二人不停，前方三人**咬破舌尖喷血、施展血遁**暴增速度逼近半丈内。
- 王林右臂独抗三掌；左右六指同时点在其身侧，**禁锢之力大增，修为被无限削弱，面色苍白**。
- 上方三剑齐至，王林左手一拳轰碎二人二剑，仍有一剑**刺入天灵三寸**，血自眉心流入双眼，眼前化作血色，而其冷静未失。
- 王林拖着身外十二人，向长街尽头急速冲去。

## 三、增援与反杀：天牛幻形

- 地底冲出**三道漆黑虚影**，掐诀点身、如元神般扑向王林（疑为夺舍）。
- 前方另**幻化九人**，以特殊方式合诀融合，上空凝出**狰狞冰龙**咆哮扑来。
- 后方海子天尊被九人围住（**对方无杀机，只围不放**），凄厉呼喊王林。
- 王林一顿之下幻化**巨大天牛（金牛）**，凝实如真牛复活，喝「汝等，死」，一头撞碎冰龙，龙体四分五裂，九人喷血倒卷。
- 三道黑影未及钻入即被金牛张口**吸吞**。
- 十二名围攻者受金牛出现的直接冲击：左右六人手指连手臂崩溃、前方三人爆出血雾、上空三人被牛首一晃喷血后退。
- 金牛前冲撞过化龙倒卷的九人，直冲长街尽头**轰然爆开**——威力足以撼天动地、令东城坍塌，却只掀起无尽风雪，**四周建筑纹丝未动**，证明此地禁锢无法从内撼动。

## 四、黑雾吞噬：三十余人尽灭

- 王林一步临前，化作**一团黑雾**吞噬前方三人的全部血肉精气与元神。
- 黑雾分作两股，吞噬左右退走的六人。
- 雾中现**骨阴刀**，向天一斩，空中三名重伤者化作六份，元神被吸入雾中。
- 黑雾横扫后直奔围困海子天尊的九人，九人放弃围困疯狂后退仍被追上，**只剩九具枯萎骸骨**。
- 王林现身于海子天尊身旁，面色苍白，喷出一口鲜血落在积雪上。

## 五、战后判断（王林的推演）

1. **敌方身份**：此杀劫出动三十余人，人人天尊修为；海子天尊交友众多、对天尊修士大多有印象，却对这批人**全然陌生**。
2. **假天尊**：王林由吞噬的元神判定，他们**并非真正天尊，而是被强行提升**，以包括生死在内的莫大代价换取**一个时辰**的修为爆发。
3. **神脉收益**：所得元神驳杂不纯，需时间炼化，**最多只能凝聚出一条神脉**。王林**现有五条神脉**，最多可展开最大速度的**九十八个分影**，再多一条则战力可观增加。
4. **幕后**：此局「**其内有园师的影子**」；四方图案之力尚无法全解。
5. **禁锢与外援**：此地被人扭转乾坤设局，**外人救援已被算到**——一则以禁锢封锁一切气息外泄，二则另派人限制**久帝大天尊**。王林直觉此局非久帝所设，且**布局者或就在此地，等待最终一击的杀招**。

## 六、第二波：魂铠使者与跃天尊

- 风雪中三道身影化长虹疾驰而来，未近即散发**接近跃天尊**的修为之力。
- 其后两名**黑衣人具跃天尊修为**，右手一抬，黑风化作**两条黑色巨蟒**盘踞天地。
- 王林一眼认出：「**魂铠使者**」。
- 推断依据：他在**紫阳宗见过跃天尊图谱**，余下四十八人**无人拥有魂铠**；此二人必是被特殊手段提升至跃天尊战力并被赐予魂铠——「在这祖城，能做到这一点的，**唯有仙皇**」。
- 王林左手推开海子天尊：「海子，你退后，他们不会伤你，此战，你不要出手。」

## 七、悬念

- 体内「无」之禁锢未破，战力受限。
- 布局者身份未明（涉及园师、仙皇），且可能就在现场等待最终杀招。

# 第1979-1980章 长街杀局：金色一指与残夜

## 场景
风雪长街，满地残骸，四周被无形护罩（如倒扣之碗）禁锢。海子天尊欲上前解释/相助，被王林左手一挥推出数十丈，其后又因轰鸣震动而双脚一颤无法前行。

## 一、第二波杀戮：三白二黑
- 五人化作五道长虹逼近，王林双目通红，右手骨阴刀幻化迎击。
- **三名白衣人**只施两式：
  1. 凝聚风雪之力成风雪之暴，化巨大卷风横扫；
  2. **自爆**。
- 王林一刀斩开风雪之暴，抬手放出**九十九个役灵印（九十二为真）**，如排山倒海硬撼三人自爆冲击——冲击虽惊天动地，仍无法使此地禁锢崩溃。
- **两名黑衣人**（上空盘踞黑色蟒蛇）疾驰而至，三人瞬息碰撞：一人全身爆开，另一人眉心一道血线、身躯分为两半。王林前冲十丈踉跄，骨阴刀支地，喷血于雪。

## 二、凭空之手指与「金色一指」
### 手指的诡异
- 王林身后风雪中无声无息凭空出现一只手，直点其后脑，「好似他本就是不存在的」，如大天尊的无中生有。
- **此手指之人即布置四方形图案、禁锢王林战力者。**

### 王林的隐忍与反制
- 王林不回头，前冲扭身以骨阴刀横扫，刀身崩裂——他早有准备。
- 刀片四散之际双目爆出**金光**，金光来自其**虚无中的最强分身**。他一直隐忍未用，等的就是这只手指的出现。
- 金光一出，体内禁锢脆弱如薄纸、瞬息摧毁，全部战力恢复。
- 骨刀碎片折射金光，就地**组成小范围阵法**（王林禁制本源大成，布阵随手可成），使虚无分身之力得以最大程度释放。

### 四波叠加的一指
王林左手抬起，迎金光与对方手指相点。这一指是其当下战力巅峰：
1. **第一波**：体内古祖魂血所化**道古之力**；
2. **第二波**：五条神脉凝聚的九十九个分影融合为一 + **天牛魂铠**之力；
3. **第三波**：**五行真身 + 雷霆真身 + 身后三大虚之本源漩涡**融合，内蕴其一生的道；
4. **第四波**：**虚无分身之力**自双目透出化金光，经四周骨刀碎片折射，指尖彻底化为金色——**金色一指**。

对方手指出现血丝脉络、隐隐难承，最终**轰然崩溃**。

### 对方之道：有与空
- 「因有了失去，故而重新凝聚后，便称之为有」→ 崩溃的手指肉眼可见地重新凝聚，仿佛未损。
- 「因有了存在，故而消失后，便称之为空」→ 王林指上道古之力、神脉神通、天牛魂铠之力，乃至五行真身、雷霆真身，尽数从存在化作虚无、烟消云散。
- **未能被驱散者**：三大虚之本源（王林一生对道、生死、因果、真假的感悟，是其一切本源的最初）与虚无分身所化金光。
- 王林喷血倒卷后退，挥手驱骨刀碎片再击碎第三次凝聚的手指——手指旋即又有第四次凝聚迹象。

## 三、百名死士与「残夜」
- 王林退近长街尽头（禁锢边缘），长街两旁屋舍虚无波动，浮现**近百个风雪模糊之影**，人手一弓。
- 百人齐拉弓弦，风雪化作一百支箭；同时喷血于箭，身躯当场枯萎、化为飞灰，连骸骨不留——**全为死士**。
- 王林判断：此次长街杀局中除手指之人外全为死士，一生所遇杀局无一可比——以往对手尚惜命，此番对手不在乎死亡。
- 王林仰天咆哮，掐诀外推，白发狂乱，身后幻化**金色太阳**，长街消散、天地化作漆黑大海，海尽头初阳升空：**残夜**。
  - 「我相信，一切黑暗都将在光明前毁灭」
  - 「我相信，一切存在都将在初阳下虚无」
  - 「我相信，一切空与无都将无法轮回」
- 百支血箭齐崩，第三次凝聚的手指在阳光下磁磁作响、冒出大量黑气，被太阳轰击即崩溃。
- **代价**：七片箭之碎片未被残夜毁灭，破开初阳穿透王林身体，衣衫留下七道缺口，王林嘴角溢血、踉跄后退。

## 四、禁锢的真相与新的杀招
- 王林一拳轰在长街禁锢边缘，虚空扭曲，护罩显形（如倒扣的碗）。
- 借瞬息扭曲波纹，王林看到长街外**一层层盘膝而坐的数万黑袍修士**，彼此被某种力量连接，正是他们组成此地禁锢。
- 平静之声回荡：**「你逃不掉」「为了杀你，这一次出动了我宗最强的力量」**，崩溃之指再度幻化而出。
- 外界画面模糊化虚无前，王林看到数万修士中**数百人抬头似吞下一粒丹药，肉身直接崩溃，元神化作烟丝直奔长街而来**——新一波以命换命的攻势将至。

## 关键判读
- 幕后势力为某「宗」，倾其最强力量、以数万修士结阵 + 成建制死士的方式设局刺杀王林，规模与决绝程度为王林生平之最。
- 神秘手指之人掌握「有/空」之道，可无限重凝并抹消他人力量，唯独无法抹消王林的三大虚之本源与虚无分身之金光——这是王林现阶段唯一的破局支点。

# 第1981章 黑发王林

## 场景与局势
- 地点：被杀局笼罩的长街（风雪之地），两旁屋舍林立。
- 敌方：凭空幻化的模糊风雪身影，一个个爆发天尊修为，是情绪被压制、以死亡完成任务的死士；数量三段递增——数百 → 数千 → 数万。
- 幕后：虚无中一根反复凝聚的手指，伴随「一切存在，都将成无」的声音，其后隐现两双震惊的双目；下令「所有人，全部进入此地，轰杀此人」。
- 旁观：海子天尊（全程见证并逐步陷入恐惧）。

## 转折一：杀戮雷霆本源夺得主导，黑发王林现世
- 王林宣告不走：「解开杀局的最好方法，就是将你们全部杀戮，此局自然破开。」
- 白发根部隐隐弥漫黑色，随后**杀戮雷霆本源第一次成为身体主导**；他松开禁制本源与太初本源的压制，任雷霆为引的杀戮与默灭爆发。
- 外形剧变：瞳孔化作一片漆黑，长发尽数转黑 —— **黑发、黑眼、黑袍的「黑发王林」**。
- 自语试探境界：「不知以我如今的状态，可以闯过天尊涅的第一层。」
- 海子天尊的反应是本章的情绪标尺：从通体冰冷、如见天敌般后退，到最后惊恐质问身份。

## 战斗推进
1. **数百死士**：黑色雷霆之网散作无数，触之即碎；前排数十人自爆之力在网前脆弱不堪。
2. **百人结阵**：地气喷发凝成巨大黑色手掌抓来；王林以数百黑色雷霆裹身化流星撞崩，阵中百人尽灭，自身嘴角溢血但更显疯狂。
3. **虚无手指点眉心**：王林一拳轰向虚空，扭曲中传出受伤闷哼，手指消散。
4. **数千死士**：黑发骤然延长化作无数扫向八方，敌方齐齐自爆形成毁灭漩涡，王林大口喷血但以周身杀戮雷霆硬抗。
5. **再抓手指**：王林一把抓住来袭手指拽出半只手臂，一头撞去令其崩溃，虚无中再传闷哼。
6. **数万死士齐至**：王林节节自剥（见下），最终闭眼再睁眼，数万人连同长街屋舍尽化尘埃废墟，风雪亦转黑。

## 自剥：层层卸去外物以纯化杀戮
王林为提纯杀戮毁灭之力，主动逐一逼出身外之物，每卸一层修为骤减、杀戮气息却更精纯：
1. 从胸口撕出**天牛魂铠**抛出 —— 疯狂化作死寂平静，残忍微笑仍在。
2. 一拍眉心震出**五行真身** —— 五行真身神色凝重退至海子天尊身边观战。
3. 依次逼出**禁制本源、太初本源、雷霆本源**。
4. 最后咆哮逼出**虚之生死、虚之因果、虚之真假**三大虚之本源。
- 终态：体内仅剩**默灭**与**杀戮**两道本源，无任何真身，只余本体；黑气收缩成黑色长袍，双目死寂，笑容尽消，「如同死亡的化身」。

## 收束
- 王林喃喃：「锁亡天之运，印冥朝，众生之所不能得真道者，常沉苦海，永失真道，奉至修真行。」
- 捏碎再度点来的手指，从虚无中拽出一个通体白光的身影，只道一句「**你不是国师**」，随即掐住其脖颈捏碎。
- 章末悬念：海子天尊惊恐嘶喊「你不是王林，你是谁」；黑发王林冷漠转头，一步步向她走去。

## 要点提示
- 本章确立「黑发王林」作为杀戮雷霆本源主导下的人格/形态表征，与常态白发王林形成对照。
- 虚无中的操盘者被王林明确排除为「国师」，指向幕后另有其人。
