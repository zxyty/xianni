# 仙逆 第九卷 云海之巅 第1388章 不要怕！（第三更）

## 一、场景与形势
- 地点：太古星辰（星空之上）。
- 对阵：王林 追杀 贪狼。贪狼法宝屡被王林所克，已至『克星』之惧。

## 二、弃宝引敌，故技被识破
- 贪狼急退中把右手紫色玉瓶向另一方向狠狠抛出，欲引王林改道。
- 此法他当年做过，并因心痛发狂而立誓：此生绝不再为逃命送出法宝（有些法宝被抢比杀他还难受）。
- 王林果然改道，却是径直奔玉瓶而去，大袖一甩直接收走，长笑转身、缩地成寸再追。
- 王林语：『这贪狼，当为我王林修道之福星。』

## 三、贪狼自述生平（关键前史）
- 自诩天地宠儿、受天道恩眷：
  - 八岁挖出五百年黄精吞下；
  - 十三岁坠崖，落在一株五百年朱果旁；
  - 十八岁筑基时，得到太古雷龙；
  - 结丹后与强敌厮杀不敌之际，天空掉下一尊大鼎将敌砸死。
- 此后山河图、抽魂山峰、炼神针等宝物一一入手，**唯独在追寻『天逆』一事上不顺**。
- 旁白点破因果反讽：那尊天降大鼎即**挪移大鼎**，后来数次帮王林躲过杀劫；那伴随贪狼长大的**太古雷龙**，才使王林有机会成为雷修、在罗天星域扬名赫赫，并最终诞生**雷霆本源**。若贪狼知晓，定当喷血。
- 贪狼被王林抢空后并未死，反另有奇遇，得更多法宝、修为更强，却仍被王林追至太古星辰。

## 四、已被王林夺走的贪狼法宝清单
浮惊剑、护骨碑、天皇炉、雾魔枪、万古木灵、古息叶、魔魂瓶——约为其身上法宝之半。

## 五、金幡遁逃与追击
- 贪狼取出一杆**金色大幡**：幡布绣一凶兽，身如龙而无爪、生众多翅膀、半身融云疾驰。
- 挥幡后凶兽厉啸幻化而出（约百丈长、近百对翅膀），卷住贪狼化作乌云疾遁，每扇一次速度暴增。
- 王林以波纹如浪之姿紧追，虽**雷霆本源大成**、以雷之力追寻，仍无法短时间追上，双方保持距离。
- 王林不急反喜：已看出贪狼所有法宝**都与古之三族有关**，由此**确定了贪狼获宝之地**——对旁人或无大用，对王林却是难以想象的造化。

## 六、贪狼转身死战：妖狼降世
- 贪狼因法宝被抢而胸闷剧痛、悲愤咆哮，索性不跑；其本为巨孽之辈、杀戮极重，只因被王林吓住加之**道心裂缝**才逃至今日。
- 掐诀撕开巨大**空间裂缝**，咆哮『**妖狼降世，罚灭道天**』。
- 裂缝中爆出滔天妖气（王林极熟悉的**古妖气息**），赤红雾气倒卷钻入贪狼七窍；其衣衫寸寸碎裂，露出**乌芒铠甲**。
- 身后星空逆转，浮现约**万丈大小的妖狼虚影**：赤红光芒、双目近紫，仰天狼嚎，摄人心魂。
- 妖气以贪狼为中心横扫**方圆十万里**化作巨大漩涡并疯狂收缩凝聚，形成巨大吸力，令人难以后退。

## 七、一剑斩妖狼
- 妖气冲击使王林自『融入天地』中显形；妖狼低头锁定王林，张口吞噬而来。
- 王林神色平静，体内砰砰作响，**身躯膨胀至近千丈，化作六星古神**，古神星点在眉心急速旋转。
- 后退一步，右手抬起，血光滔天，凝成一把**百丈沧桑血剑**。
- 在妖狼大口临身不足十丈之刹那，右手向下狠斩：百丈血剑落下，爆出**万丈赤红剑芒**（远观如甩动的巨鞭）。
- 剑芒正中妖狼头部，势如破竹撕开头颅、裂缝越扩越深，终**将妖狼一剑斩成两半**；两半身躯成八字形自王林左右掠过、消散星空，只余不甘咆哮回荡。

## 八、章末悬念
- 王林低头目光如炬看向贪狼；贪狼眼中浓浓恐惧，尖叫后退，**毫不犹豫取出其最强的一样法宝——一尊残破的木雕**。

## 九、待续要点

- 贪狼获得古之三族宝物之地，将成为王林的『大造化』目标。

# 第1389、1390章 雕像的身份与来历（二合一）

## 一、定身术锁死贪狼

- 就在残破木雕出现的刹那，王林平静吐出一字：「**定**」。
- 贪狼身子骤然一顿，再无法移动半点，目中惊恐暴增。
- 定身范围之广：**肉身、体内元神、元力，乃至神识**都无法挪动半点，只能眼睁睁看王林走近。
- 王林安抚：「不要怕，回答我几个问题，我不会杀你的。」
- 贪狼心神翻起大浪：「我居然忘记了他会施展这极为霸道的定身术」，并暗骂这「克星」卑鄙——明明拥有定身神通，偏偏不早出手，而是**等他拿出最强之宝时才施展**，断了他最后的希望。

## 二、王林夺取残破雕像

- 残破雕像**没有任何气息散出**，静静漂浮在贪狼右侧。
- 王林前行中身体渐渐缩小，站到贪狼身前时已化作常人大小；他不先理会贪狼，**右手虚空一抓**取走雕像。
- 贪狼见最强法宝被夺，心如被利剑穿透抽回千万次，怒气攻心，**嘴角流出鲜血**。
- 王林含笑取物之辞：「区区法宝之物，贪狼前辈想必也不会如此小气，当年前辈赠送在下不少法宝，今日相见，又送来这些，王某便却之不恭，收下就是。」——点明二人**旧有恩怨/前番夺宝往事**。

## 三、雕像的形貌与异变

### 外形
- 看似寻常，其上多处破损，样子较为诡异，**所刻是一个人**。
- 此人约**中年**，穿一身**流云道杉**，**相貌平凡**，却有一股说不出的威严隐隐散出——威严不浓，也不令人心惊胆颤。

### 对视引发的心神冲击
- 王林目光与雕像双眼接触的刹那，**整个人轰然一颤**。
- 星空在其目中瞬间崩溃、撕裂一切；一股无法形容的力量自雕像内爆发，**顺双眼直冲心神**。
- 耳中天地轰鸣，雷霆被生生撕碎，整个星空天地一切存在崩溃化作虚无；王林在虚无中失去心神，陷入迷茫。

## 四、无边大陆幻象

- 不知过去了**十年、百年、万年、十万年**——直至有一天，王林看到已不存在的天地星空内，似乎出现了**一处大陆**。
- 这大陆**无边无际**；王林隐隐明悟：其范围**超过整个太古星辰、超过界内**，即便两者相加，**也不足以成为这大陆的万中之一**。
- 幻象消散，王林一颤清醒。星空还是那片星空，贪狼仍被定身术定住、目露浓浓恐惧。

## 五、王林的判断与悬念

- 醒来一刻王林即明白：**无论心神中度过多少岁月，实际只是瞬息**；若论距离，就是双眼与雕像之目接触的那一刹那。
- 「是幻觉么」——王林神色复杂，想不明白，但所见**深深烙印心中，一生不会消散、更不会遗忘**。
- **第二次看去，感受截然不同**：看似平凡的雕像仿若换了个人，露出难以形容的威严。
- 这威严**可让一切修士在其面前成为蝼蚁**，就算天地在其面前也要屈服；王林隐隐感受到，**恐怕就算是第三步大能，在这雕像面前都要颤抖**。
- 悬念收束：「他，到底是谁」——雕像所刻之人身份未解。

# 第1300章 中年男子雕像与贪狼的古墓自述

## 一、雕像：超越青霖之像

- 王林一生所见雕像中，此前最震撼者为**仙帝青霖在妖灵之地的雕像**，望之几乎心神崩溃。
- 眼前这尊雕像的「心神崩溃」感虽不浓，王林却隐隐感到：与之相比，**青霖之像犹如蝼蚁**。
- 雕像形貌极为寻常：一名中年男子，抬着头，神色平静，无喜无悲，没有任何表情。

## 二、逼问：定身术松动与搜魂之胁

- 王林目不转睛望着雕像，未看贪狼，右手一挥令其身上**定身术**略有松动，可以说话。
- 王林声音冰冷、蕴含寒意侵入贪狼心神，追问两点：
  1. 雕像从何处得到？——贪狼答：**在一处古墓内**。
  2. 进入**太古星辰**必须破开**封界大阵**，以贪狼修为断无可能，他是如何进来的？
- 王林明言「莫要逼我搜魂」。贪狼放弃反抗，判断实话或有活路；且惧怕对方施展**搜神术**，即便不死也会沦为无智之人。

## 三、贪狼的全部法宝出处

贪狼交代，其所有法宝**皆出自同一处古墓**：

- 浮惊剑
- 护骨碑
- 雾魔枪
- 天皇炉
- 万古木灵
- 古息叶
- 魔魂瓶

## 四、贪狼自述往事线

1. **望月之下未死**：当年自望月之下逃遁后并未死亡，隐藏于**罗天星域**一处半废弃修真星，躲避王林追杀并全力疗伤。
2. **安心休养**：久不见王林追来，判断对方已认定自己死亡，遂安心休养直至伤势尽复才离开。
3. **罗天空虚**：其时王林已不在罗天，整个罗天星域极为空旷，绝大部分修士都赴**联盟星域**参战——这给了贪狼可乘之机。
4. **不归联盟**：一路安全，但思量后不愿回联盟；且被望月吞下后全身连元神都沾染挥之不去的臭味，距离很远即可被闻到，令其无法忍受。
5. **游历星空**：年复一年寻找消散臭气之法。
6. **遇漩涡**：某日在**罗天星域边缘**、隐隐靠近**闪界壁垒**所在之地，发现一处奇异漩涡，仿佛直接展开在其面前。
   - 心神当即生出一生中从未有过的强烈感觉（强过当年大鼎砸敌、强过初见望月）。
   - 毫不犹豫冲入，刚进去漩涡即消散；**从出现到结束不足三息**。

## 五、王林的怀疑与贪狼的「机缘体质」

王林目光渐冷：「听来，似乎这漩涡就是专门为你打开一样。」贪狼面色大变，急举一生离奇机缘自证（自称句句属实，连他自己都觉不可思议）：

| 时间/情境 | 机缘 |
| --- | --- |
| 八岁在村地里玩 | 踢到黄精 |
| 掉下山崖 | 得到朱果 |
| —— | 得到太古雷龙 |
| 结丹期与人厮杀、眼看不敌 | 挪移大鼎从天而降，直接砸死敌人 |
| 雨之仙界（他人需抢夺雨鼎） | 在外飞行时雨鼎自动飞到面前 |
| 初入仙界（他人苦寻仙玉且所得极少） | 第一次进去即被传送进一个仙王洞府 |
| 联盟星域早年一处上古遗迹（他人难寻入口） | 迈出三步即被传送进去 |

## 六、漩涡之内：一座坟墓

- 漩涡内**仿若另外一个世界**，极为混乱，空间乱流弥漫，稍走错一步便是万劫不复。
- 无数漂浮的**巨石碎片**环绕四周；**最深处被一片雾气笼罩**，看不清样子。
- 贪狼找不到出口，**被困数百年**；观察后发现此地死气极浓，仿佛是**一座坟墓**。
- 一处巨石碎片上有一颗**约百丈大小、极为狰狞的头颅**，其**眉心有星点**；**天皇炉**正是在此处被发现，当时炉内还有**燃香漂升，仿若在祭拜**。
- 继续深入，发现更多头颅，全部透出浓浓**怨气与不甘**；其中一些生着**单角或双角**；部分头颅面前**放着法宝**。
- 贪狼回忆至此，眼中隐隐透出恐惧。

## 七、悬念与要点

- 雕像来源指向该古墓，而古墓中巨大带角头颅、被祭拜的天皇炉，暗示墓主层次远超仙帝。
- 漩涡「专为贪狼而开」的疑点未解，与贪狼一生反常机缘构成同一谜团。
- 贪狼如何绕过封界大阵进入太古星辰，本片段尚未给出最终答案（叙述停在古墓见闻）。
