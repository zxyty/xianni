# 仙逆 第312-313章：虚无探路、金紫石与第一层仙界碎片

## 一、章鱼状异物与红色气浪之劫（第312章）

- **预警**：王林神识未散，但与放出的游魂间有微妙感应；他察觉前方十里有异常——一个巨大生物缓缓摇曳，形似巨大章鱼，拥有无数粗长须支。一只游魂刚接近便被须支触碰、消散一空。
- **首次受创**：叱虎立刻控罗盘绕行，仍被一条须支从罗盘边缘横扫而过。罗盘剧震、急速北抛。王林五脏六腑如受万斤撞击，一口鲜血涌上又咽下；叱虎嘴角流血、双目通红，稳住罗盘后虚脱服丹；红蝶亦颇狼狈，罕见地露出震惊。
- **不信与出走**：王林点明此物平时收起须支、觅食时才散开，觅食会散出**红色虚气**，非三人可挡，力劝向北疾飞。北去将彻底迷失方向，叱虎犹豫；红蝶冷言拆穿「谁知是真是假」，王林只回二字「无知」。王林不再多言，脚踏出罗盘，**禁幡**包裹全身独自北驰——他并不知红色气浪的威力，但**古神涂司的记忆**中对此气浪印象深刻。
- **验证**：叱虎冒险散开神识向南查探，见远处连绵红色气浪迅速扩散冲来，大惊后急控罗盘北逃；红蝶神识一扫，脸色难看。
- **脱困**：红色雾气瞬间扑上，罗盘一角触之即诡异消失，如被生生吞下。叱虎喷血，令红蝶出手——红蝶点于眉心唤出**玫瑰花**，摘两枚花瓣弹出，两声巨响使气浪一顿并炸开，红蝶反噬喷血。气浪裂口化作大口再度吞来，罗盘出现裂缝、叱虎几近脱力，红蝶咬牙摘下一条**花蕊**弹出，连番轰击后大口消散，罗盘化作流星北逃而出。
  - **代价与设定**：花瓣消失可自动补充，**花蕊仅三个**，失一难补。红蝶面色从未有过的难看。
  - 远处的王林清晰听见轰击声，嘴角露出一丝冷笑，速度更快。

## 二、地位反转与虚无航行

- 罗盘狼狈追上，叱虎苦笑请王林上盘。此刻王林在叱虎心中的作用**已超过红蝶**。叱虎认错并请教后续手段与方向选择；王林平淡答：气浪已过，短时无碍，按地图方向飞行即可。
- 王林落于罗盘**东首方位**盘膝而坐。罗盘缺一角，**只剩东、西、北三处**。叱虎暗忖此行须速，罗盘有损难以长时间飞行。
- 数日后叱虎找到地图一点，罗盘循图疾飞。红蝶一路不发一言，任由王林探路；叱虎对王林之言再无犹豫、全部听从。
- 虚无中异物众多，王林逐一遇到古神涂司记忆中的异物，见识增长数倍不止；在其提前指点下，罗盘有惊无险穿过危机四伏之地，连续十余日未再遇险。
- **论道**：王林与叱虎论道，彼此皆有收获。叱虎透露：**巨魔族本非朱雀星之人，无数年前先祖迁移而来**，故神通与朱雀星修士不同。

## 三、金紫石与星罗盘之志

- 王林遥感游魂时发现远处一数丈大小的漂浮物，形如大石、闪烁**紫金双芒**——**金紫石**。
- 该石是古神涂司记忆中**制作星罗盘的必须材料之一**。王林以「看到一炼器材料」为由离盘取之，收入储物袋；返回后叱虎追问所取何物，王林一笑避过。
- **动机（内心独白）**：当年化凡感悟天道时，王林曾遇一自称「**天运子**」的前辈，此人称若王林能走出朱雀星，可去**天运星**寻他，收其为**百年记名弟子**；此人修为定然通神。王林认定此机会不能放弃——**星罗盘必须要有**。
- 其后一个多月再无材料发现。

## 四、罗盘报废与抵达第一层仙界碎片

- 罗盘在飞行中剧烈颤动、裂缝迅速扩散，同时涌现强大阻力将三人抛起。叱虎苦笑收起罗盘，改为三人凭法力行走，称全速之下约**三日可到**。
- 三日后，王林远远看到一处陆地——**第一层仙界碎片**。

## 五、第一层实地与层数之辩（第313章）

- **地貌**：地面寸草不生、处处坑洼深不见底；天空裂缝众多，时而数个裂缝连接、随后又消失；地面时见坍塌建筑。
- **确认与寻址**：叱虎称巨魔族**习祖**曾详细描绘此第一层之地，遂低头默算、散开神识寻找某处位置。
- **层数之辩**：王林问玉简所拓印的碎片重叠之地是第几层。红蝶轻哼「废话，自然是第二层，此地仙界能出现两层重叠碎片已属不易」，被王林冷声再斥「无知」——红蝶眼露杀机。叱虎打圆场并证实：**确是第二层，但习祖也曾猜测其下或许还有第三层**。红蝶闻言一怔、沉吟不语。
- **暗流**：王林始终感觉不对劲，早前便发觉似有人在身后跟随；这种感觉与修为无关，而是**多年杀戮带来的危机直觉**。
- **落点**：叱虎在**东北方向**一处位置停下，找到习祖当年留下的**梅花记号**及其留下的探查计算之法，落在一处**深坑**旁边，面带喜色。

## 六、待展开的线索

- 身后跟随者身份未明（王林已生警觉）。
- 星罗盘尚缺其余材料；天运星、天运子为后续长线目标。
- 第三层碎片是否存在——红蝶已知晓此说并沉吟，恐生变数。
- 红蝶对王林已生杀机，同行关系脆弱。

# 第二层：梅花深坑尽头的空潭

## 一、入坑
- 王林低头察看，四周深坑果然**呈梅花状**，与玉简线索吻合。
- 叱虎先跃入坑中，红蝶看了王林一眼随后进入；王林神识一扫，此坑**深不见底**，略一沉吟后跳入。

## 二、坑外插曲：葫芦中年男子与尸阴宗老者

### 持葫芦中年男子（婴变中期）
- 三人入洞后不久现身坑旁，饮酒后手中一翻取出一座**宝塔**，白衣女尸自塔中飞出被其抱住。
- 自语透露关键设定：
  - **仙玉棺材早被他炼成了宝塔**——故三人所求的白玉棺材根本已不在原处。
  - 棺材中的仙玉**几千年前就被婷儿吸收得差不多了**。
  - 承诺去寻找更多仙玉，判断**第三层应该有仙玉**。
- 他在女尸眉心轻吻，随即神色一动，令女尸与宝塔立刻消失，抬头望天。

### 白发老者（尸阴宗，婴变中期）
- 天空轰鸣，**一道道裂缝连接处**走出一名白发苍苍、满脸皱纹的老者，速度极快。
- 抱怨：找了这么久，「几乎每个碎片都溜达了一遍」，仍没发现仙人尸体。
- 中年男子的判断：此人修为与自己同为**婴变中期**；朱雀星婴变期修士不多，自己本应个个知晓，却从未见过此人——因此在朱雀星来客中**最为忌惮此老头**，遂一语不发转身跳入深洞。
- 老者被冷落后耸鼻嗅探，认定是**死气**，是仙人尸体的气味，且断定「应该是个女尸，女尸更好」，立刻冲入深洞。
- 内心独白交代来历与动机：完成**宗主的任务**便可离开朱雀星；「我尸阴宗什么肉身没有」，却不知宗主为何非要仙人尸体，怀疑是「哪个星球的客人口味这么独特」。

## 三、下坠：万丈阻力
- 三人一路飞快下落，久久不见底，一股**自下而上的阻力**越来越强。
- 叱虎称下去后即可进入玉简拓印之地，那里有**封印禁制**，但以三人之力耗费时日定可解开。
- 王林估算下落已超过**万丈**仍未见底；下方有股神奇之力，令**神识只能在千丈内探查**。
- 抗压手段各异：
  - 王林：灵力运转全身硬抗，深吸口气。
  - 红蝶：身上散发**蓝光**，面无表情。
  - 叱虎：**眉心斧头痕迹**剧烈闪烁，每闪一次身外阻力便减少一分。
- 王林在冲出洞底前一拍储物袋取出**禁幡**，抖开包裹全身，挡住冲出瞬间的万丈刺目光芒。

## 四、第二层实况：一无所有
- 空间仅**百丈大小**，中央的确有一汪潭水，整体布局与玉简拓印一模一样。
- 但缺失了全部宝物：
  - **无白玉棺材**；
  - 自然也无棺材上的**三把仙剑**；
  - **灵草半点均无**。

## 五、三方反应与冲突

| 人物 | 代价 | 反应 |
|---|---|---|
| 叱虎 | 损耗**罗盘** | 大脑一片空白，怀疑有人在其族**习祖**发现此地后先行取走宝贝；抱拳认「鲁莽」 |
| 红蝶 | 耗费一枚**花蕊**才得以进入 | 冷笑愤怒，质问叱虎早知此地如此、故意借其之力前来「定有目的」，扬言「休怪我红蝶不顾世交之情」 |
| 王林（化名曾牛） | 无损失，反得一块**金紫石** | 苦笑而已，自认「还赚了」；不动声色四处细查 |

- 叱虎强忍怒意回应：自己身为**巨魔族少族长**，虽比不过红蝶金贵，却是**一言九鼎**的男儿；此事回朱雀星后必给交代，但绝无另有目的。
- 红蝶讽刺：「习祖？你族习祖还说这第二层有宝呢」。

## 六、转折：第三层入口与不速之客
- 王林搜寻一无所获后，目光落在水潭上——潭水**漆黑一片、深不见底**。
- 王林发问「你之前说，此地还有第三层」，叱虎双眼一亮，称族中习祖曾分析此地应有第三层（并称王林为「曾牛兄弟」）。
- **王林判断：若真有第三层，水潭就是入口。**
- 红蝶上前俯视潭水之际，忽有一人自上方通道飘落，向前一踏便站在水潭之上：
  - 一股大力自其体内散出，**叱虎面色一白、口吐鲜血倒飞**；
  - **红蝶娇喝退开，目露惊色**。
- 片段止于此，来人身份未明。

## 七、要点归纳
1. 「白玉棺材消失」之谜在本片段由坑外中年男子的自语提前向读者揭晓：棺材已被炼成宝塔，仙玉亦被婷儿吸尽——三人此行注定落空。
2. 引入新势力**尸阴宗**及其寻找仙人尸体的宗主任务，动机指向「某星球的客人」，为后续因果埋线。
3. 朱雀星此地为**碎片/裂缝结构**（老者称「每个碎片都溜达了一遍」，自天空裂缝连接处而出）。
4. 水潭被确认为通往**第三层**的可能入口，而中年男子亦称第三层应有仙玉——多方势力将在第三层交汇。

## 注
- 依据世界状态须知：本片段中「婷儿」为第289章已死之人，此处以**尸体**形态出现，不视为新行动。

# 第313-314章「附体」剧情梳理

## 一、遗迹第二层：周佚现身

- 王林一路警惕，早知有人尾随，在对方现身瞬间即向后退开；虽仍被力场波及，却未受伤，只面色略起红润，退出数丈之外。
- 来者为一中年男子，手持红色葫芦，出现即饮一大口。
- 叱虎失声道破其身份：「五行宗周佚」。中年男子露齿而笑，称其为「巨魔族的小家伙」。
- 叱虎恭敬见礼，自称巨魔族叱虎，言周佚之名自幼如雷贯耳。作为巨魔族少族长，他自小被重点培养，看遍朱雀星上婴变期修士画像，一见红色葫芦便认出对方。
- **红蝶反应**：听到「周佚」之名立刻面色一变，眼中闪过隐藏极深的恶心之色。

## 二、周佚其人（叱虎传音说明）

- 朱雀星上为数不多的**婴变期**老怪，修为深不可测。
- 有一极诡异嗜好——**恋尸**；此嗜好后来被认证为真。叱虎警告王林万勿说出口，被听到「必死无疑」。
- 周佚一眼看穿王林反应敏锐、一路早有察觉；王林恭敬应对，只说「略有感应，并非完全确定」，不动声色。此对答落在叱虎、红蝶耳中，令二人面色古怪。

## 三、关键情报：玉石棺材与第三层

- 周佚明言：**此地的玉石棺材早被他取走**，劝三人回去。
- 叱虎苦笑称是；红蝶目光一闪看向水潭，不语。
- 周佚似笑非笑点破：**此地确有第三层，入口就是这水潭**，「若不怕死，倒也可以一试」。

## 四、白发老者尾随

- 洞口传来破空声，白发苍苍的老者自上落下，笑称「好热闹」。
- 周佚目光阴沉质问其意图；老者称只是对第三层有些兴趣。
- 周佚冷哼，脚下一踏，水潭如炸开般四散，露出潭底洞穴，闪电般钻入；老者紧随其后。
- 后续对话揭示老者纠缠周佚的真正理由：「**你身上有死气，我自然要跟着你**」（周佚反问其为何不去收取仙界之气而一直跟着自己）。

## 五、三人入洞

- 红蝶银牙一咬——此行损失极大，若一无所获实在不甘心，遂钻入洞穴，明知龙潭虎穴亦要闯。
- 叱虎询问「曾兄」是探是走，王林未答，反问周佚来历；得知详情后，叱虎邀其同路，王林略一沉吟点头应允。
- 二人一前一后飞入水潭洞穴。

## 六、第三层：水晶世界

- 洞穴不深，二人极快穿透，出现在一处**好似水晶一样的世界**。
- 环境：遍地白色利剑状水晶，阵阵蓬勃的**仙界之气**自水晶散发弥漫四周。
- **收取仙气各显手段**：
  - 红蝶——手持葫芦飞快收集；
  - 叱虎——自储物袋取出**青布口袋**，一抖便有大量仙气涌入；
  - 王林——取出**吸灵木（洗灵之木）**吸收，速度逊于二人的宝贝。
- 叱虎落身一拍水晶，只闻金属撞击声，水晶纹丝未动（无法采撷）。
- 三人一语不发，竭尽全力吸收。

## 七、周佚与老者斗法

- 远处轰隆巨响，周佚喝斥老者「不要逼人太甚」，质问其为何弃仙气不取、一路紧随。
- 老者答「你身上有死气」。
- 两道长虹一前一后疾驰至王林三人近前：
  - **周佚**：右手抬起向后一抓，身后现出巨大漩涡，庞大吸扯之力爆发，四周水晶咔咔开裂、大量断折被吸入漩涡。
  - **老者**：面色微变，双手迅速变化法诀，身后浮现一具**通体紫红的巨大棺材**，跃上棺材方抵住漩涡吸力。
- 二人一施法，此地**仙界之气立刻混乱**。

## 八、要点与伏笔

1. 玉石棺材已落入周佚之手——王林一行第二层目标落空。
2. 「恋尸」嗜好 + 老者的紫红棺材 + 章节名「附体」，指向棺材/尸身相关的后续冲突。
3. 老者所言周佚「身上有死气」，是其尾随的核心动机，也暗示周佚身上藏有尸体或死物。
4. 王林此阶段以「曾」姓化名与巨魔族叱虎结伴，身份未暴露。
5. 水晶世界的仙界之气为此行主要收获来源，但强者斗法已使其混乱，采集受阻。

# 第314-315章「抢尸」：仙界碎片中的借体之战

## 一、身份揭破与首次交手

- 骑棺老者盯着漩涡大笑，认出中年男子即是**周佚**——「那个有恋尸癖的周佚」，依据是其身上死气极为浓厚。
- 老者拍击身下棺材：棺内传出指甲摩擦棺盖般的刺耳声响，黑气涌出化作**九幽巨大鬼爪**，抓向周佚的漩涡。
- 一声巨响，**第三层仙界碎片**剧震：大地碎裂、无数水晶化为飞灰、半空裂缝如森森之口张开，**此地仙界之气尽数消散**。

## 二、周佚的警告：六层碎片连锁崩溃

周佚判定对方是**尸阴宗大长老**，并抛出关键约束：

- 二人若全力动手，仙界碎片将全部崩溃；
- 若只是单一碎片崩溃，以二人修为尚可逃走；
- 但此地共有**六层碎片重叠**，只需其一彻底崩溃，其余全部连锁崩溃；
- 届时**即便问鼎期也无法逃命**。

### 红蝶的处境（本章当时）
- 修为虽有所恢复，但**法宝损失严重、体内暗伤**，修为已不再保持**化神后期**而无限跌落，是其有生以来最低谷。
- 身处裂缝包围：身后是裂缝、身边是裂缝，四面八方皆裂缝。**没有星罗盘、没有燃烧元神的勇气，落入其内只有必死**——故不能闪躲、不能瞬移、不敢不挡。
- 两度以势力施压：「你若杀我，朱雀国不会放过你」「我是朱雀国核心弟子，你若杀我，不得好死」。王林笑其「这威胁话语，可不像出自天之骄女口中」。

### 交手回合
1. **禁幡→禁气长枪**：王林一拍储物取出禁幡，一抖之下禁气轰然而出、如恶龙徘徊；一声「凝」融合成黑色禁气长枪。一枪前刺，将天空裂缝划开一道大口；三十丈一跃而至，枪直指红蝶头部。
2. **白色飞剑碎裂**：红蝶仓促自储物袋取出白色飞剑抵挡，飞剑碎裂、碎片散入无数裂缝；王林长枪缩小一大圈，去势更猛。
3. **绝情意境**：红蝶意境轰然而来，王林身体轻微一颤——无法阻止，但可抵抗数息；他判断只需数息内杀掉红蝶，意境自然崩溃。
4. **白玉镯硬挡**：红蝶一咬牙，抬右手以手腕白玉镯子挡在枪尖。一声「铛」，禁气长枪再次崩溃化作无数禁气且**无法重新凝形**；一股强大意境扑天而来，令王林神智一乱。红蝶自身被抛飞后退，喷出一口鲜血。
5. **九木雕·岁月意境**：王林心念坚定、身体没有半点停顿，右手一翻取出九个木雕，喝「岁月」——九木雕化作九个一模一样的人偶，其内有数条血经脉流转，岁月意境蓦然从天而降。红蝶面色再变，失声「岁月意境」。此意境**取自四派联盟青松**（化神中期，意境已具功效）。
6. **锁命之链**：岁月意境下红蝶身体不由自主慢上几分——未受伤前本不屑一顾，此刻却成锁命之链。王林右手两指如利刃，似雕刻木雕般向前划去。
7. **咒语反制**：红蝶眼露仇恨，抬右手念诵几声诡异咒语，白玉手镯散发刺眼光芒，**岁月意境立刻崩溃**，王林手指传来阵阵刺痛。

## 四、关键伏笔
- 王林被白玉镯光芒刺痛手指的感觉，**「就好像是当初摸到那仙剑一般」**——指向白玉镯来历不凡（疑与仙器/仙剑同源层次）。
- 红蝶的白玉镯需**咒语**催动，既能硬挡禁气长枪、又能正面破除意境，是其真正底牌。

## 五、人物心志侧写（王林）
- 资质一般，但心念心志「放眼整个朱雀星，也绝非寻常」。
- 溯源：童年在**恒岳派爬山测试**中、尚无任何法术之时，心志便已令人动容。
- 加成：四百多年无数经历磨练，已成铁打般坚定——故意境临身、神智一乱，身体仍无半点停顿。
