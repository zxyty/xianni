# 第1300章 古神祭坛（第九卷 云海之巅）

## 一、斩杀十三阶凶兽紫血

- 王林以『你伤了她，要付出代价』为由（指李倩梅受伤），抓住巨蝎两条尾巴狠狠砸下，尾部撕裂，蝎身多处断裂坠落虚无。
- 蚊王率先冲出，以巨大口器顺裂缝刺入吸噬；随后五千蚊兽尽出，环绕蝎身同时吸血。数息之间蝎身枯萎，血液尽失，**连其对天道的理解也被吸走**。
- 蚊王与五千蚊兽修为暴增，兴奋嘶鸣后四散，成群追杀溃逃凶兽。此景连王林都感到头皮发麻。

### 战利品
- 王林撕下余下七条蝎尾，凑齐**九条蝎尾**，喷出元气化蓝色火焰焚烧，其间禁制不断落下，片刻融合成**一条**，收入储物裂缝。
- 一拳轰爆蝎首，得**拳头大小的黑丹**，丹内有黑衣女子面孔（凶兽元神）闪烁惊恐。

> 设定：十三阶凶兽若能化作人形，等同拥有两条性命——兽身崩溃后元神仍凝聚体内。

## 二、搜魂所得：裂缝真相

王林神识破开黑丹搜索黑衣女子元神，读取其一生记忆：

1. **紫血的来历**：无数年前它本只有七阶，偶然被一名身影模糊的女子看到，女子右手点下烙印，说：『很有灵性的小兽，赐名紫血，成我麾下兽将之一，为我疗伤护法。』蝎子对该女子极其敬畏。
2. **十九头化形凶兽**：裂缝内共有十九只可化作人形的凶兽。
3. **裂缝之大**：无边无际，连凶兽也不知尽头；更深处有更强凶兽，轻易不出，一出则掀起惊天巨浪。
4. **裂缝来历**：连黑衣女子也不知，只知自诞生之日起便存在于此。
5. **禁锢之地**：裂缝深处有一片被禁锢之地，那位赐名者女子正在其中疗伤，岁月过去太久太久。

### 王林的两点推断
- 此地所通之处**或许并非妖宗所猜测的『界外』**，而是一处神秘之地。
- 收回神识刹那，脑中浮现当年在**风仙界深处**所见巨大蚊王挣扎而出的裂缝——其内一片混沌、隐有无数蚊兽。他自问：『这两个地方，是否会有一些联系？』随即按下不想。

## 三、疾驰出口与救人时限

- 攻守易势：初入时是凶兽围困王林，此刻是王林一路猎杀凶兽疾驰。血剑环绕四周，察觉凶兽立即冲出。
- **李倩梅**：王林岁月神通没有半息停顿地施于其体内，阻止生机灭绝——但只能**延缓**、不能**停止**，越慢则其生还可能越低，王林因此焦急。
- 此前收服的**九幽龙**已不知去向。
- **破阵思路**：封界大阵王林只见过一次，无多少把握破开；但他感到**裂缝内天劫不降，一出裂缝天劫必至**，或可借天劫之力破开封界大阵，出去寻找**蓝梦道尊**。

## 四、依月现身：远古仙皇妃子的交易

行至大半路途、将近出口时，一个轻柔平静的声音突兀响起（此前王林毫无察觉）：『杀我兽将，如此匆匆离去，你要给我一个交代不是？』

### 来者
- 一身**红衣**、相貌惊艳的女子，**双目内蕴含星辰**，似化作无形漩涡可吸引一切目光。
- 自陈：**远古仙皇妃子之一，名为依月**；本体正在疗伤，此来为**分身**，分身有**天人衰劫**修为，『未必能留得住你，且我也不想与你为敌』。
- 认得王林的**血剑**：『我认得这把剑，它曾伤过仙皇。你是王族古神，倒也可以发挥此剑威能。』

### 威胁与反威胁
- 依月：我留不下你，但可以**阻止你离去**，使那女子（李倩梅）生机彻底消散。
- 王林（神色如常、坚定）：『若她死，我也不会离开这里，而是杀上你所在禁锢疗伤之地，将你斩杀。你，可以一试。』

### 达成的条件（依月提出，王林未明确应诺即接玉佩）
| 依月付出 | 王林付出 |
|---|---|
| 立即送王林离开裂缝，为救李倩梅争取时间 | 救活李倩梅后**再来裂缝一次，帮依月疗伤** |
| 带王林去往裂缝深处所通之地的**古神祭坛** | — |
| 与王林**立下道誓结盟，互不为敌** | — |

### 依月选择王林的四条理由
1. 因为你是**王族古神**；
2. 因为你可以操控**当年曾伤过仙皇的血剑**；
3. 因为你身上有**我熟悉之人的气息**，你想必也获得了他的认可；
4. 因为你体内蕴含了**五道本源**，一旦大成，**甚至可与仙皇一战**。

王林并不知晓古神祭坛为何物，但看依月神态，似乎很有把握他会心动。

## 五、传送玉佩与离去

- 依月右手一挥，一片白光玉佩飘向王林：『持此玉佩，你可在任何地方来到这裂缝内，也可通过这玉佩瞬息去往出口。我等你到来。』言毕转身离去——其来临似乎只为送出此佩。
- 王林神识扫过玉佩：内中只有**一座传送阵**，结构极为复杂，但以其对禁制的了解看出**并无凶险**。
- 谨慎起见，先**分出一道神念**进入阵法，神念消失并出现在裂缝出口；确定无碍后，压下疑惑，随玉佩光芒消失离去。

## 六、结尾伏笔

王林离去的刹那，裂缝世界内部一片漆黑的天地中，有一枚**六角形红色结晶**，约**十丈大小**、好似冰块，其内盘膝坐着一个女子。女子睫毛颤抖，缓缓睁开双眼，目光透过结晶望向虚无，不知在想些什么。

## 七、待解疑问

- 古神祭坛究竟是什么存在？依月为何笃定王林会心动？
- 依月口中『我熟悉之人的气息』指谁（与王林获得认可者何人）？
- 风仙界深处蚊王所出裂缝，与此裂缝是否同源？
- 依月的真实目的；红色结晶内的女子是否即依月本体（或即赐名紫血者）？
