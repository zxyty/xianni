# 第八卷 联盟隐秘 第1016章 大漠孤烟

## 场景：黑沙荒漠中的黑塔

王林在荒无人烟的黑沙荒漠上，看到远处黑影渐大，最终显出真容——一座矗立的**黑色高塔**，阵阵魔气自内散出，未近便有令人发狂的气息。

王林瞳孔一缩：这黑塔他非常熟悉。他曾在**妖灵之地天妖郡**内见过一次同类黑塔：
- 塔中之物一声冷哼，当时的王林险些肉身崩溃；
- 即便躲入洞府，也无法逃过塔中之物的神通；
- 若非**升仙果**的刺激，他就会彻底迷失本质。

此塔即**散魔之塔**。

## 推理：古魔的下落

王林在见塔刹那脑中清明，串起数条旧线索：

1. **贝罗之言**：古妖贝罗当年曾说，**古魔座下有九散魔**；王林当年遇到的只是其中之一，也是唯一存在于外界妖灵之地的一个。
2. **花妃之言**：仙帝青霖于**仙界崩溃后**又遇到了**两个界外之物**，重伤后在此地闭关。
3. **推断**：这两个界外之物，应该就是**古妖贝罗**与**古魔**。
4. **旧谜**：妖灵之地内，古妖贝罗被人分成九份、封印在九个地方；原本应是仙境之地，却变成妖气弥漫。谁封印了贝罗？为何妖灵之地只有散魔、而无古魔？
5. **结论（王林猜测）**：古魔所在之处，定然就是这**第五座洞府**——仙帝青霖闭关之处。

> 此为王林的推断，文中尚未由他人证实。

## 状态：血遁之后

- 王林面色略有异红——这是施展**血遁**后的表现。
- 身子停下时，天空中环绕的魔气全部消散。
- 体内元力运转，将血遁造成的伤患压制下来。
- **半年多的隐忍** + 魔气侵袭 → 杀机毕露、脸露戾气、相貌狰狞。
- 他自问：「以我现在的修为，能否与散魔一战？」

## 战斗：数十沙土傀儡围攻

王林迈步向黑塔行去，黑沙荒漠平坦，距离迅速拉近。前行之际：

- **地面震动**，无数沙粒四面凝聚，在王林数十丈外浮现**数十个由沙土组成之人**，衣着古朴、仿若古人。
- 众傀儡魔气在半空相互凝聚，化作一个**诡异的虚幻老者**：双目幽光闪烁，虚幻右手向前一指，下方数十沙土人低吼齐冲。
- 一道道神通之术弥漫天地，五光十色临近王林。

王林的应对：

| 手段 | 效果 |
| --- | --- |
| 右手食指点在傀儡眉心 | 一声轰鸣，傀儡崩溃化作沙土散开 |
| 右手五指成掌、神通弥漫一扫 | 傀儡轰然崩溃 |
| 右目青光一闪，**青光盾**幻化而出横扫 | 一切神通全被阻在身体**一丈外**，无一入内 |
| 身如闪电前行、食指横扫交错点身 | 轰鸣不绝，每一声代表一个傀儡崩溃 |
| 跃起、右手抓最后一傀儡头部 | 整个人腾空，但**未超过二十丈的极限** |

王林一句「**区区傀儡，也能阻我**」，戾气更浓。

## 收束：呼风

起身的瞬间，王林右手掐诀，喝出「**呼风**」，蓦然向天空中由傀儡魔气幻化而出的老者一指——章节至此断。

## 待解疑点

- 谁把古妖贝罗分成九份封印在妖灵之地？
- 古魔是否真在第五座洞府 / 仙帝青霖闭关之处？
- 王林当前修为能否与散魔一战？
- 腾空「不超过二十丈」的限制来源（疑为此地禁制）未明言。

## 场景

- 地点：**黑沙荒漠**（黑色沙漠），远处有一座**黑塔**。
- 时点：王林入此荒漠已**半年**。
- 起因：荒漠中魔气凝聚，使王林**当年的魔性再次爆发**，战斗风格戾气极重——旁观老者惊觉「眼前这个充满戾气的青年，比之自己还要像是魔头」。

## 关键异变：呼风黑龙 → 魔龙

王林一句「呼风」，黑风骤起化作四头黑龙，但本次与以往完全不同：

1. **形貌魔化**：四头黑龙头顶各生出长长独角，龙口牙齿全部呲出，森森利齿骇人——「这哪里还是什么仙术黑龙，分明就是魔龙」。
2. **吞噬黑风**：不再如往常吹出阴风，而是猛地一吸，四周弥漫的黑风全部倒卷、被四龙吞噬。
3. **生出龙铠**：吞噬黑风后龙身砰砰作响，浮现四道**黑色龙铠**；铠甲并不完整，仅覆一小半，但狰狞铠身与无数利刺更添魔威。

此变化连王林本人也一愣，脑中只回荡一句判断：**「这哪里是什么仙术，这分明就是魔攻。」**

## 交战经过

- 王林一指，四头魔龙直奔**魔气所化的老者**。
- 老者面色大变，咬牙掐诀正要施展神通。
- 四头魔龙齐齐咆哮，化作惊天动地的声浪崛空而起，携**无上魔意**；老者身子颤抖，法术**生生被打断**，只得后退欲回远处黑塔。
- 魔龙在后疯狂追击，巨大龙口、狰狞牙齿、自天空落下的涎水皆惊人。
- 王林杀机弥漫，随黑龙向黑塔飘去，**高度始终保持在二十丈以下**，四头魔龙亦然（暗示此地二十丈以上存在某种限制/危险）。

## 结果与线索

- 老者修为**只相当于窥涅初期**，在变异呼风黑龙下毫无挣扎之力，眼中浓浓恐惧，疯狂向黑塔逃去。
- 老者绝望大吼：**「魔仆大人救我」**——引出黑塔一方存在名为「**魔仆**」的更高存在，此战未完，直接指向下一场冲突。

## 待跟进

- 「魔仆」是何身份、修为，是否即黑塔主人。
- 呼风黑龙的魔化是永久变异，还是仅限黑沙荒漠魔气环境下的表现。
- 王林飞行不敢超二十丈的原因（此前应有相关禁忌交代）。

# 第941章 黑塔屠敌·仆冥海现身

## 一、开场：偷袭老者被魔龙吞噬
- 一名老者声音刚传出，便眼前一黑、剧痛袭来，失去一切意识。
- 四头魔龙如争抢食物般险些彼此撕咬，最终由其中一头一口吞噬了该老者。

## 二、黑塔黑袍人现身
- 黑塔内数十人飞出，皆着黑袍、连头部一并遮盖，飘于半空，冷芒盯视四条魔龙。
- 王林清点：此地半年来神识扫过者共**三十二道**，方才死的老者是其一，尚余三十一人（他记得清清楚楚）。
- 判断：这些人修为都不弱；欲离开此地，玄机尽在此处；且「不杀他们，他们也绝不会放过自己」。王林脸露杀机，在四龙环绕中直冲而去。

## 三、正面交锋：魔尊屠念 vs 四魔龙+灭神矛
1. 黑衣人中一苍老声音喝出「**魔尊屠念**」，众人齐齐双手掐诀、一点眉心。
2. 魔气大范围冲出，在其上空迅速凝成一个虚幻魔影（尚未成型）。
3. 王林不假思索右手一指，四头魔龙咆哮直扑魔影；同时一步踏出如利剑前冲。
4. 冲出之时右手虚空一抓，**灭神矛**凝聚而出，携杀意抛出，如黑色闪电追上四龙，仿若化作第五条龙，撞入魔影。
5. 轰然巨响，大地颤抖、昏暗天空似要崩溃。

### 交换结果
- 我方：魔龙消散，灭神矛碎裂无形；王林被冲击倒退数步，阴沉望去。
- 敌方：魔影怒吼后扭曲、四分五裂；连召唤魔影的黑衣人也一一身子颤抖、崩溃。

## 四、收割：斩首取头
- 黑衣人崩溃刹那，王林一步迈出速度极快，直接欺至众人面前，右手横扫，一颗颗人头砰砰飞起。
- 人头样子各异，均有黑气缭绕。
- 王林语：「**你们的人头，我有大用**」——暗示后续用途（未在本段说明）。

## 五、悬念：塔顶之人
- 黑塔只有十丈高，王林目光落向顶端，那里无声无息站着一人。
- 此人自报：「**五行水散魔首仆冥海**，杀了我，你有机会得到**仙帝青霖山河图**之**大漠孤烟**。」

## 关键看点
- 灭神矛为王林随手虚空凝聚之杀伐手段，与四头魔龙可协同合击，威力足以撕碎「魔尊屠念」魔影，但一击即碎。
- 「三十二道神识」是王林半年观察所得的敌方总量计数，本章后仍需清算余数。
- 新线索：**仙帝青霖山河图**及其组成部分「大漠孤烟」，由仆冥海主动作为诱饵抛出。

# 第1017、1018、1019章 梵天（三合一）

## 一、场景与对手登场

- 地点：黑沙荒漠（第五座洞府相关区域内），场中有黑塔。
- 出场者：一名身穿灰色铠甲的男子，**自称冥海**。
  - 丝丝魔气飘出，身后凝聚狰狞魔影；铠甲遮蔽相貌，只露一双冰冷无情的眼睛。
  - 站立时仿佛与黑沙荒漠融为一体。
  - 王林判断：**修为不弱于净涅**；更奇异的是其身上除魔气外，**还隐隐有仙气缭绕**（魔仙并存）。
- 王林先右手一挥，把一地头颅全部收入储物袋，随后平静发问：「此地是否就我一人存在？」
- 冥海沉默片刻后摇头，答：「**战胜我，你会知道一切**」——随即开战。

## 二、交手过程

### 1. 五道黑烟 vs 唤雨
- 冥海自黑塔跃起，半空右手一抓，放出**五道黑烟**，锐啸割碎虚无，在天空划出五道狰狞痕迹。
- 黑烟砸落掀起数十丈**沙浪**向王林拍下。
- 王林掐诀低喝「**唤雨**」：天地色变，风起云涌，雨水蕴含天地之力，方圆数千丈尽被覆盖；双手一抖，雨水化作**万道利剑**冲垮沙浪。

### 2. 沙爆 vs 撒豆成兵
- 冥海穿透沙土近身，一指前方低喝「**沙爆**」：大地沙土齐震升空，四面八方与更远处无尽沙土蠕动汇来，如波浪欲吞噬王林。
- 王林张口喷出**十八地狱封仙印**，放大如小山，喝「**撒豆成兵**」，右手一挥。
  - 晶光化作魂魄，鬼泣回荡：其中有**血祖之魂**（血红双眼盯向王林，咆哮但**未反噬**，反而向外冲杀）、众多**仙人之魂**，以及**新加入者——杀域界之人**的魂魄，杀意浓郁。
  - 战魂分布四周，与飞卷沙粒激烈碰撞。

### 3. 方竹小剑 vs 古神虚影一拳、青光盾
- 冥海右手在眉心一点，射出一把通体白色的**三寸小剑**，剑气强到隐约可破开天空。
  - 冥海惆怅道：「**此剑当年仙帝所赐，名为方竹**」「此剑有灵，能死在其下，可算你造化。」
- 王林握拳，身后**古神虚影**幻化，一拳对撞白光，拳风化作旋风。
  - 结果：方竹剑气爆发，**凌天候的剑气与之相比大为不如**；王林的拳风漩涡从中崩溃、被生生切开。
  - 王林连打数拳后退百丈，才避过剑锋。冥海眼中露出**失望**，转身走向黑塔。
- 小剑再化白芒冲来，王林**右目青光**一闪，**青光盾**幻化环绕护身，与白芒碰撞。

## 三、关键转折：古神「功灵」之术

- 王林身后古神虚影更加凝实，眉心**古神星点**隐隐环绕，脑海中闪过**古神涂司的传承**。
- 双手十指交错结印，诵古神之语：「**夺天地之功，取乾坤之灵，结古之一族，永恒之念**」，古神虚影同步结出相同印诀。
- 设定要点：
  - 王林所承古神神通虽多，但**以五星之力可施展者极少**：**唤古之力**、凝聚**虚幻灭神矛**，以及此处的「**功灵**」。
  - 功灵是**五星古神可发挥的极限之力**。
  - 功灵之术在古神中极强，威力随修为不同而异：**九星古神**施展可抽取乾坤之魂、**抽出一界之规则为己用，改变天道、逆转乾坤**。
  - 王林仅五星做不到这点，但凭**王族古神**身份，仍使整片黑沙荒漠为之一颤。
- 施术目标：不止那把白色小剑，**更多是冲着冥海**。

### 「夺天地之功」的外界连锁反应
- 天空如被巨手撕裂，大地沙粒向四周倒卷，撒豆成兵的魂魄趁势冲击。
- **第五座洞府、妖灵之地外的无尽星空**中，天地之力凝聚，**破开东海的潮汐漩涡**融入其中，在妖灵之地内纵横破开一切，**顺着九龙阵法冲进第五座洞府**。

## 四、第五座洞府内：黑雾之人与白玉小瓶

- 洞府内一座**木桥**上，有**盘膝打坐的黑雾之人**，身前漂浮一只**白玉小瓶**（瓶口由**黑木塞**堵住）。
- 天地之力自黑色漩涡冲出直奔玉瓶，玉瓶剧烈颤抖。
- 黑雾之人双目爆出幽光，惊讶自语：
  - 「竟然可以引发外界天地之威」
  - 「**本以为这一次只有四人需要引起重视，没想到，现在又多了一个**」
- 其从雾中伸出**干枯手臂**，在白玉瓶外狠狠一捏，**捏碎**涌入的天地之力，使其大范围消散。
- 王林随即诵出「**取乾坤之灵**」：古神虚影咆哮冲击天地，如抽山魂、抽星魂般抽取乾坤之魂（乾坤本无魂，古神之术却能从中抽出一个意念、一股意志）。
- 洞府内白玉瓶震颤更剧，似有吸力自内传出，**堵口的黑木塞颤抖着向下收缩，仿佛要被吸入瓶中**；雾中人双目再度爆出幽光。（片段止于此，悬念未决）

## 五、待跟进/悬念

- 「战胜我，你会知道一切」所指的真相为何。
- 黑雾之人所说「需要重视的四人」是谁，王林成为第五人。
