# 第1732章 原来他叫王林！（第二更）

## 一、轰破五行火阵

- 五行火阵内，火焰巨人跪地膜拜，双手托起王林，王林脚步不停，踏上巨人头顶的火焰长发。
- 王林右手一指前方，火焰巨人起身长啸，四周九头匍匐的麒麟同时站起、神色狰狞低吼。
- 在五行星众人看来，天空漩涡镜中王林所指的方向，正是镜外所有观看之人——巨人与麒麟之吼，如同冲着塔外数百修士、塔内黑袍老者四人而来。塔外修为低弱者嘴角溢血、恐惧后退盘膝。
- 火焰巨人前踏一步、双手向前一挥，**五行火阵的世界轰然崩溃**。

## 二、第七阵：五行水阵与五仙水将

漩涡画面一变：无边大海、怒浪滔天，天空昏暗乌云密布，**无闪电雷霆而有暴雨**，海雨交错、天地颤抖。

- 蓝色铠甲、蓝色长枪、黑发飘舞的英俊中年男子自海中升起——归一宗**五仙水将（水将大人）**。
- 归一宗修士言其：常年闭关；本就是**完整的五行水灵体**，存在于水阵中即为**水阵之灵**，有他在此阵威力倍增。
- 五行中水火相克，九头麒麟在雨中阵阵低吼。

### 交手过程

1. 水将暴喝“王林”，腾空跃起，海面四方凝聚**四道高约万丈的海墙**将王林封死。
2. 水将握枪俯冲，身随枪走化作水蓝长虹；身后暴雨幻化出一把**雨水长枪**同至。
3. 九头麒麟抢先迎上，瞬间被滔滔海浪淹没；王林与火焰巨人亦被海水轰然埋葬，雨水长枪刺入海中。
4. 天地间只余水将，其冷傲道：“就只有这点修为么……在这里，我就是五行水灵，在这五行阵内，我就是仙神。”塔外归一宗修士齐声欢呼，称水将修为**已踏入传说中的第三步**。
5. 水将喝令“王林，你只是受伤，给我滚出来”，海水冲天遮其视线；**冰冷之声自其背后响起：“我在这里。”**
6. 王林自水幕中一步走出，右手一拍——**本源之力与道芒毁灭气息**直入水将体内，五脏崩溃、全身骨裂、血肉分离，喷血抛飞。

### 铠甲之道：反控其主

- 水将体内砰砰作响，铠甲现出细密裂缝却未溃散，反从裂缝涌出**大量生机**灌入其体，必死之伤顿时痊愈。
- 王林以**禁制本源化作自身规则**（双眼血丝弥漫，视界不同），看破隐秘并当面点破：
  - “很奇异的铠甲。你的修为没有到第三步，可穿上这个铠甲后，却是可以发挥出第三步的力量。”
  - “不过这铠甲的弊端也不少，穿上之后，是**它在操控你**，而不是你控制它了。”
- 水将闻言骇然。

## 三、塔外舆论：归一宗的煽动与污名

一名**净涅中期**老者带头，众修士接力控诉（均为归一宗一方说辞）：

- 王林硬闯归一宗六阵、抢夺**五行二灵**，是赤裸裸的入侵者。
- 称其“在五行宗外恶名昭昭，所到之处生灵涂炭、从不留活口”。
- 称其曾因看中某修真星上**藤姓修真家族**的宝物，屠其满门、连凡人老少也不放过，血流成河。
- 称当年**纳多长老**曾在王林屠杀凡人、歼淫女修时出手阻止，念其修为不易而放过；王林却恩将仇报，修为大增后杀入五行星，名为寻纳多长老、实为毁灭归一宗。
- 结论式动员：“杀他一人等于解救无数人”“我们修为不如他，但我们人多，他只一人”。
- 人云亦云之下，不了解、不认识王林之人也渐渐相信，目光充满愤怒痛恨。**王林听不到，即便听到也不会在意。**

## 四、界外旁观：玄罗大天尊记住了这个名字

- 五行星外五道光环包围，自**仙罡大陆**来临、曾于**洞府界**现身的黑发青年**玄罗大天尊**平静旁观。
- 听到王林点破铠甲弊端后，他嘴角露出开心的微笑：
  - “这孩子原来叫做王林，不错，很不错。”
  - “这归一宗的**铠甲之道**，在仙族也很有名气。他能看出端倪，非常不错。”
