# 第2047章 踏天路，空灭道！

## 一、计都的封印崩开

- 罗喉郡内，王林吞噬吸收罗喉大凶之魂、借来融合杀戮之魂的刹那——
- 大殿内的计都皇子浑身一颤，喷出一口鲜血；随血喷出，其体内**一道无形的封印蓦然崩溃打开**。
- 计都双眼流出奇异之芒，感到一股力量在体内苏醒、充斥全身，遂闭上双眼。

## 二、双真身归位

### 归位前

- 大殿外天地之间：**黑发杀戮真身**收回望向始古皇城原始山的目光，目内冷漠无情至极；旁侧是五色光芒转动的**五行真身**。
- 两具真身相貌相同，感觉迥异：
  - 五行真身 = 王林一生的**修为**，柔和却带强者威压；
  - 杀戮真身 = 王林一生的**血腥**，冰冷无情，望之心寒。
- 密室内传出「真身，归位」，五行真身化五色长虹坠地，杀戮真身化黑丝消散，齐归密室。

### 王林的盘算

> 「百年的修行，终凝成了这杀戮真身……眼下就要看看与我本体融合归位后，修为能否从之前的空劫大圆满，再攀升一步。」

- 目的：若修为再提高，**或可完全驱除仙皇连道真魂内的诅术之力，彻底操控此魂**。
- 密室半空中那被灵魂之火焚烧炼化百年的仙皇之魂：金光闪烁，内中灰败之感已不再蔓延，被凝成**婴儿拳头大小的一团**，仍无法最终驱除。

### 王林的境界观

- 「我的修行与旁人完全不同」：空劫大圆满后有**天尊**与**跃天尊**两个后人加的称号，实则二者皆属空劫大圆满范畴。
- 王林每一次修为提高**是按境界来划分**的。
- 期待：空劫大圆满后那一步，会是**大天尊**，还是**第四步**？——「莫非仙祖、古祖等人，就是第四步。」

### 融合过程

1. 五行真身先融：瞬间重叠盘坐、融为一体；王林白发无风自动，修为轰然运转，处空劫大圆满、百年闭关后的**身体巅峰**。
2. 杀戮真身继之：无情走来、重叠盘坐、缓缓融合。
3. 融合中王林目露迷茫，修为以无法形容之速暴增，似打破某个瓶颈：
   - 瞬息越过后人所谓的**天尊**；
   - 继而达到**跃天尊**；
   - 再向**大天尊之限**涌去，无停顿之迹象。
4. 迷茫渐浓、隐隐失神，处于虚幻感受之中。

## 三、灵魂脱壳：规则之天

- 融合完成大半、只剩不多重叠时，王林目露银光，脑海轰鸣，**灵魂如脱壳般飘离肉身**，穿透密室，现于天空之上。
- 所见之天地：
  - 无碧蓝、无日月星辰，苍茫间似只剩王林一魂；
  - 大地被**白雾**弥漫，看不透；
  - 天空被**一条条细密而各具规则的细线**缭绕，全力望去，线后仍有更多细线，无边无际。
- 王林迷茫：「这就是天？」并隐隐感到：**若能踏出这片无边线条，便可迈出空劫大圆满后的一步**——如化茧成蝶、破开飞出的生命飞跃，感觉埋藏于灵魂深处。
- 王林果断冲入线条之海，任线条缭绕身体，依旧前行。

## 四、踏天之桥（九桥）

### 桥之形制

- 线条之海中出现**九座桥**，如彩虹般挂排于苍茫之内，散发洪荒古老气息，似天地诞生之时便已存在。
- 第九座桥之后有**一片虚幻之幕**，其内似另有天地，隐可见人影，细看则一片模糊。
- 桥为**虚幻无实质**：可见，神识却无法感受；手可轻易穿透，掌中残留晶莹光粒，每粒内含磅礴生机，随后飞回桥内。

### 石碑铭文

- 第一桥下巨大石碑刻「**踏天之桥**」四个奇异大字，王林一生未见此字体，却在见字瞬间脑海诡异浮现其含义。
- 碑上另有一行小字：

> **「踏天路，空灭道，不朽魂，众生拜」**

- 王林恍惚忆起：当年隐隐听说过，**若这世间真有第四步存在，其名则为「踏天」**。

### 踏上第一桥

- 走近第一桥用了数个时辰（看似很近）；闭目半柱香后，抬步踏上。
- 踏桥一瞬：**灵魂之体如同升华**，大量天地法则被其清晰了解，前所未有。
- 走至第一桥尽头：那种天地规则的变化**已烙印心神，不可磨灭**。
- 再望第九桥后的虚幻之景：略有清晰，似是**鸟语花香之地**，其内人影依旧模糊，连有几人都看不出。

## 五、结论与走向

- 王林走下第一桥，缓步走向**踏天第二桥**。
- 强烈感觉：**走过九座桥、看清虚幻之景内的一切之时，即可突破第三步，踏入传说中的踏天之道。**
