# 第1812章 与王林比本源（第二更）

## 一、杜青的骇然与猜测

杜青修道多年、身为木体，见惯奇事，却接连被这白发修士（王林）震撼：

1. 先见一处处干枯死亡的地火脉；
2. 追上后，又从对方手中看到来自**世界宗**、**东临宗**、**松云道**三家的法术。

他无法判断王林身份来历，只觉神秘面纱层层不尽，遂生两种猜测：

- **其一：偷学而来**（拜入各宗窃取不传之法）——则此人狡猾多端、擅长隐匿，修为必不止表面，后招不少；虽难缠，杀之应无后患。
- **其二：背景极深**（各宗主动奉上神通）——能让东临宗、世界宗送上功法已属难得，而**松云道乃仙皇钦点三大道门之一**，竟肯传授**焚界古伞之术**，背景之恐怖不可招惹。

杜青最终自我说服倾向第一种：「此人或许只会这三宗之术，当面施展只为吓退我，应已是其极限。」遂长啸出手。

## 二、王林的第四宗神通：阴月宗「阴月有晴」

杜青喝道「我就不信，你还会第四种大宗之术」，王林大笑，坐镇火龙、操控十六条火龙所化铁链，右手一挥：

- **黑风弥漫天地**，十三条黑龙幻化穿梭，张口吐出**寂灭之风**；风中雨滴如龙王施雨，每一滴落下即化作虚幻之魂，凄厉嘶吼、铺天盖地扑向杜青。
- 冷喝「**呼风唤雨、撒豆成兵、地裂山崩**」——大地裂缝凭空而生，虚幻火山在蕴含**地火子脉**的土地上幻化爆发，黑烟滚滚、岩浆无尽。
- 低吼「**阴月有晴**」，白昼天穹诡异地升起一轮明月；手指落下点在杜青身上，杜青脸部立现月亮痕迹，急速扩散。

杜青脑中如雷霆崩鸣，认出这是**阴月宗**的**阴月起手式**——阴月宗同样是**东州九宗十三门**之一。至此王林已现四宗顶尖神通。

## 三、杜青三道本源出手

杜青双眼通红，自忖追了这么久无颜退去，且**至今只出过一招**，遂豁出去：

> 「老夫修为全靠自己，虽说没有你那么多神通，但本源却是有三道。老夫三道本源硬抗玄劫之苦，岂能被你这区区一道火本源之人吓退？老夫倒要看看，你如此嚣张，能有几道本源？」

- **火本源（紫火）**：右手火焰被体内紫气一冲化为紫火，映照天地、热浪轰起。
- **土之本源**：左手向大地一指，黄沙般晶光凝作烟丝状黄雾，气息一散，四周似化大漠荒沙。
- **重之本源**：感悟天地一切物质的重量，小至一粒沙土、大至一块陆地，明悟轻重变化、操控由心。此本源在**仙罡大陆**罕见，须特殊天资方可明悟；杜青本不具资格，全靠其**木头身体中蕴含的一丝重之本源**慢慢摸索感悟入体。

**重之本源的战术价值**：

- 使紫色火海**凭空拥有重量**，威力暴增无数——仙罡大陆自古对「火有无重量」分为两派（一派认为有，一派认为火只是现象），至今未分对错，杜青却以重之本源直接给火加了重量；
- 使左手土本源雾团重若一块大陆。

此外，杜青能成**空玄修士**、数度渡过**玄劫**，除肉身之故外与重之本源关系极深；其在**大魂门**受到庇护也与这道本源有联系。

## 四、正面对轰与结果

王林操控火龙急退，同时将先前神通尽数轰出，四种仙罡大陆顶尖神通齐爆最强之力：

| 神通 | 出处 |
| --- | --- |
| 七彩长枪 | 世界宗 |
| 役灵印 | 东临宗 |
| 焚界古伞（焚界吉伞） | 松云道 |
| 阴月有晴 | 阴月宗 |

因与火龙魂相连、由火龙帮助抵消余波，王林大可一战——他连**掌尊**都封过，连**战老鬼**与**七彩道人**都敢出手，岂会怕区区杜青。文中另点明：**若非储物空间无法全部打开，「已司之傀」一出，杜青必败**。

**结果**：杜青三道本源齐出、无招胜有招，王林四宗神通**全部崩溃**；本源余波仍压至王林身前，脚下火龙魂再难承受，凄厉惨叫中骤然崩溃，化作巨大火球将王林裹住。

## 五、章末悬念

杜青欲趁势迫近给出致命一击，火球内传出王林缓缓之声：

> 「你以为，我只有一道本源么？你以为，你的三道本源，就很多么？」

此话若出自旁人杜青大可不理，出自王林之口却令其心神一震。悬念指向王林所掌本源之数远超三道。

## 六、要点归纳

- 王林此战的核心战术是**以多宗神通制造身份恐惧**，逼退强敌而非硬拼；杜青识破意图后反以**本源纯度**碾压招式。
- 本章确立设定：**本源道数**是空玄层次修士的硬实力标尺，可硬抗玄劫；本源之间可叠加增益（重之本源为火、土加持）。
- 王林此时明面仅显**一道火本源**，正在吸收火龙魂的**地火本源**。
