# 第1927章 天尊涅

## 一、地点与前情：山海洲·山海北岸洞府

- 南州**山海洲**内有一片内陆海，名为**山海**，海面辽阔、海鸟盘旋。山海占据整个山海洲近七成，余下三成陆地环绕其外。
- 王林立于山海**北部**海岸的一片山峦峰顶，此处是**最接近海底山海树**的位置。
- 他并未立刻重返山海取树，而是遁入山峰内部自辟的**洞府**——已在此居住**三年**，布下大量禁制，可作一定防护。
- 洞府内另有一片若隐若现的蓝色雾气/武器之物，雾气弥漫，其内隐见一条**缩小了很多的海龙**。
- 王林的判断：「在取山海树之前，先去看看这天尊涅之地，到底有何玄妙。」

## 二、进入天尊涅之地的方法

1. 盘膝闭目，双手不断变化**特殊印决**——王林多次验证后方才知晓；
2. 神识自体内散出，凝聚于**天灵**之上，压缩成一道明亮神识之光；
3. 光芒暴起冲天，破开虚无直贯天幕；
4. 至最高点时，天幕化作巨大**漩涡**，将神识完全吸入。

- 此印决作用是**隐藏一切神识波动**，保护天尊修士进入时不被人察觉；**据说传自仙祖**。
- 全程外人看不到、也无法感受清楚。
- 王林是以**神识**而来，但所现身体与有肉身时一般无二，若非早知，极难看出不同。

## 三、天尊涅之地的形制

- **本体**：一片约有万里的小型大陆，漂浮于天幕之上。外围有无数呼啸狂风，更有**黑色丝线**闪烁游走，每条丝线蕴含恐怖力量，触之可**形神俱灭**。
- **落点**：一座极为复杂的古老**传送阵**，一眼看去似有神识被吞噬吸撤的错觉。
- **来历传闻**（王林五十余年了解所得）：此地为**仙祖当年的最强法宝所化**，存在于虚无内，**守护仙族**。
- **特性**：无论修士身在仙族区域何处，都可凭神识被吸引而来。故此地成为天尊修士最喜来之处——纵使天南海北，亦可在此相遇，是天尊彼此相识的最佳之地。
- **宫殿群**：大陆中心为第一座庞大古老宫殿，通体漆黑、狰狞威严；其上空另有一座座宫殿悬浮，**共十九座**，彼此相连如一条长龙；最顶几座深入天幕，只见模糊轮廓。
- **人流**：第一座宫殿外环绕盘坐着**二百多名天尊修士**，彼此隔得很远，似不愿相聚。

## 四、宫殿层数与战力标尺（本章给出的重要设定）

| 层数 | 意义 |
| --- | --- |
| 第一层 | 对在场修士「太过简单」，王林闯此未引起太多注意 |
| 第七层 | 闯过最起码需**融体六十三道神通** |
| 第八层 | 多数人止步于此（如竹林天尊）；「倒也没什么」 |
| 第九层 | 闯过者已**无限接近跃天尊**，只需再迈一步即可成仙族**第四十九名跃天尊**，会被所有大天尊重视 |
| 第十六层 | 跃天尊中最强的**冥道尊**在此止步，无法闯过 |
| 第十九层 | 传闻闯过者拥有**让大天尊也不愿轻易出手**的战力 |

## 五、竹林天尊闯关

- 第七座宫殿爆发夺目金光，黑衣中年男子**竹林天尊**自其内飞出，直冲第八座宫殿——即「闯过了第七层」。
- 众天尊议论：他当年并无此等能力；近**一千年跟随久帝大天尊**，显然收获不少。
- 结果：第八座宫殿内一声轰鸣，竹林天尊被蓦然弹出，化长虹坠落第一座宫殿的大地，神色阴沉，径自远处盘膝闭目。
- 其后三天内，他再度挑战第八座宫殿一次，**依旧失败**。
- 同期不断有人自各层失败降下，最多止于第八层，最少者在第二三层失败。

## 六、王林在此地的处境与声名

- 王林一到，近二百道天尊神念扫来，其中数人为这五十年内与他交过手者，当即认出：「王林」「**白发天尊**」「是他」。
- 相识者含笑抱拳，王林一一回礼。
- 众人评语：
  - 「此人很是古怪，**修为一般，但战力却是极为惊人**，我不是他的对手。」
  - 「王林这几十年在**南州**声名赫赫，据说**道一大天尊曾对其招揽，但被其拒绝**。」
  - 见其去闯第一层，判断他是**首次**来到这里。

## 七、结尾转折：踏入第一层宫殿

- 王林不急于闯关，盘膝观察**三天**；四周天尊来来去去，但绝大多数选择留下。
- **第四天**，王林双眼一闪，起身迈入第一座宫殿。
- 入殿刹那，有乾坤在眼前变化之感：宫殿内**赫然是一片星空**，浩瀚无限、星辰无数、星光璀璨，王林立于其中。
- 一阵**奇异的呼啸**自星空内蓦然而临，王林猛然抬头，双眼寒光骤起。（本章至此中断）

## 八、待解/悬念

- 山海树尚未取，只是暂缓。
- 第一层星空内的呼啸之物为何，未揭。
- 王林能闯至第几层，成为在场天尊共同的疑问。
