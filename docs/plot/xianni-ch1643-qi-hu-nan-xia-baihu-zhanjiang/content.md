# 第1643章 骑虎不下

## 一、场景与背景
- 地点：**远古仙域**，四座巨大雕像及其后无数**古之三族雕像**所在之地。
- 对手：**白虎战将**（白发老者），七彩仙尊麾下四大战将之一，来自**仙罡大陆**，真正的仙人，血脉蕴含仙力，层次远超王林；因当年重伤至今未愈，战力受限。
- 王林状态：修为**空灵中期**，凭**道古肉身**与神通可战空玄初期；本章**未动用李广之弓**（此弓一箭之力惊天动地）。

## 二、第一阶段：道古头颅撞碎白虎
- 道古头颅吼声成天地最强音，音浪超越王林直冲白虎，白虎扭曲欲溃、退势仓促。
- 王林右手前指，道古头颅穿过其身向白虎吞噬而去；天空似被一分为二，一半道古头颅、一半惊天白虎。
- 碰撞冲击震动整个远古仙域，大地大范围崩溃，部分古之三族雕像爆开。
- **结果**：白虎崩溃化白光消散；白虎老者喷血倒卷，撞在其疗伤的山峰般巨大雕像上，雕像裂缝蔓延全身、随时可碎。王林同样后退、面色略白，眼中寒光更浓；其身后古之三族虚影崩溃，道古头颅略有涣散但仍悬于天顶。

## 三、第二阶段：白虎大术「骑虎难下」
白虎老者虽生忌惮乃至恐惧，却因白虎战将的高傲尊严强行压下，不容下界蝼蚁之修胜己，遂施展族中大术：

> 「西方白虎之道，星空七宿之力，万物草木之金，吾白虎传承，凝无上之力化作吾白虎一族大术——封灭此人，术之骑虎难下！」

术法要点：
1. **重聚**：消散的白光刹那重凝为惊天白虎，恰在王林身下，王林如站虎背。
2. **封印**：白虎爆发威压化作巨大封印，封锁王林四周天地，身如沉泥、呼吸沉重；威压随时间递增，似有无形大手将其按死在虎身，无法离开半点。
3. **漩涡**：白虎全身符文密布，化身活着的封印，继而化作巨大白色漩涡——实为白虎高速环形奔跑所成，吸力惊人。
4. **摄魂**：老者喝令「白虎灵起，带此人之魂神，镇压在洞府之下，镇压在仙罡大陆七道天山之下」。数十丈**白虎灵**（如修士元神）自漩涡飞出，身形细长如蟒缠绕王林，虎口向其天灵吞去，欲拖回漩涡生生镇压致死。

## 四、第三阶段：大儒之威震慑虎灵
- 王林左手一把按住虎口，不施神通，闭目再睁——气息大变，**当代大儒之势**轰然而出。
- 此刻他不是修士，是明悟天地道理、知晓「这一切只是一座洞府」的大儒；目光平静透出浩然之力，视虎灵不过凡间之虎。
- 一句「你敢吞我？」，双目猛睁，不怒自威，浩然之气化作天地向虎灵镇压；此镇压蕴含王林一生感悟、**三道虚之本源**与无上之威。
- **虎灵反应**：心绪中浮现一次次轮回与因果，以及仙罡大陆天地初开时白虎灵族先祖跪地膜拜天空之景，生出源自灵魂的恐惧；呜咽一声，在白发老者不敢置信中松开王林、后退数步、虎头低下。

## 五、关键设定与看点
- 生死之斗不论势均力敌：「生就是生，死就是死」。
- 「骑虎难下」的破法并非以力破力，而是以**境界/道理层面的威压**（大儒浩然 + 三道虚本源 + 轮回因果）反向震慑术法之灵。
- 白虎灵族先祖跪拜之景，暗示王林所显之威触及仙罡大陆源头层次的因果。
