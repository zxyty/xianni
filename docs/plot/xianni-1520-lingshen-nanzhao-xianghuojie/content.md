# 第1520章 灵神！（第十卷 叱咤界内）

## 一、云海援军临阵

- 数万修士目睹星空中一道道长虹疾驰而来——这是**云海修士**赶赴战场，凡人不可见，唯参战的界内界外修士可见且永生难忘。
- 长虹之壮观十倍百倍于凡人百年难遇的流星雨；虽看不清其中修士容颜，却可感到**视死如归的决心与守护云海的疯狂**。
- 「**云海荣耀**」四字在此刻「活了」，化为一股悲壮而热血沸腾的气势，即便大凶大恶之人只要尚存一丝故乡眷恋，也被无限放大。
- **红杉子**：一身红衣，神色凝重。此前因**水道子**的金色风暴使战局生变（水道子最终被**幽冥兽**吞噬），他早已做好死战准备；面对界外突起的战火毫无畏惧，长笑前行，透出**第三步大能**不畏天地的气势。
- **南云子**：较为神秘，王林了解不多，此刻眼中寒光闪烁，与红杉子一同急急赶来。

## 二、设定详解：空之四境与「空灵」

- **空之四境**：境境之间差距极大。
- **空涅（第一境）**：所操控的香火之力，在此境中又称「**涅力**」——涅檗之力，生生不息，代表无尽香火；空涅修士以涅力施展种种惊天动地的神通。
- **空灵（本章重点）**：
  - 「灵」为**灵魂的升华**：魂魄成为灵动之物并与元神融合，体内元神不再称元神，而称「**灵神**」。
  - **香火界与自身融合**，成为其天地的根基；香火门徒成为子民。
  - 涅力经此转化为「**灵力**」：由香火→涅力→融入意志→改变元神→自身成为天地，最终诞生灵力，与第一步修士吸收的天地灵力截然不同。
  - 结论：**每个空灵修士堪比一个天地，本身即是单独的天地**；空灵初期一击也绝非空涅可比。
  - **摄入香火界**：空灵修士一击可将对手强行摄入自己的香火界。
- **例外·妙音**：因一些特殊原因与神通，妙音**未选择与香火界融合**——正因如此，当年王林与**大荒**二人联手，才得以抢走其部分香火，成就大造化。
- **王林的认知修正**：他此前在界外遇**蓝梦道尊**、战**掌尊**、又与大荒联手，心中隐隐轻视空灵大能；此战后那丝轻视烟消云散。灵动周堇对空灵亦一片模糊——非亲身修到此境无人为之讲解。

## 三、真正的危机：南诏上人一掌

危机并非来自**火雀族老祖**，而是修为已至**空灵境界**的**南诏上人**。

**香火界内所见**：
- 星空消失，置身黑天黑地、腥臭弥漫之处；无数黑袍人盘膝而坐，十万、百万、千万、一亿、十亿、百亿……无边无际——皆为南诏上人的香火之民，此地即其**香火界**。
- 整个黑色天空蠕动化作一只巨大漆黑手掌，向下方王林轰落；四周黑袍人喃喃低语，令王林烦躁不安，**几乎生出盘膝同诵的冲动**，冲动越来越强烈，压得他双眼通红、青筋鼓起。

**界外同时发生**：
- 王林肉身未消失，仍浮于星空，眼中锐利消散、一片空洞；黑色火鸟临近，南诏上人的右掌自火鸟内呼啸而出，直奔其眉心。
- 说是幻觉「既正确又不正确」：界外战场真实存在，而香火界中的天塌一掌对王林而言同样真实。

## 四、破局：古神庇佑与肉身一拳

1. 王林猛地抬头，右手前挥，高呼「**我是古神，我是道吉**」，毫不犹豫催动右臂**古神护腕**——选择**古神庇佑**。
2. 一尊庞大**古神**幻化而出，环抱王林、以背相挡；漆黑手掌落下，古神后背崩溃、不断下沉，似连它也无法抵抗。
3. 王林狰狞仰天大吼「**岂能向尔等膜拜**」，古神猛地转身、右手握拳向后轰击，一拳硬生生将漆黑手掌震开万丈之高。
4. 古神似传出一声轻叹，慢慢消散，重新化作护臂回到王林右臂，**咔咔声中再添数道裂缝**。
5. 同一刹那，王林整个人冲出，右手握拳前轰，**道吉头颅幻化融入这一拳**，其身似也融入拳中，伴火焰雷霆如流星直冲天空，与漆黑巨掌再撞——巨掌骤然崩溃，王林自掌心破开而出。

## 五、战果与余波

- **王林**：双目由空洞恢复神采（迷茫仅瞬息），面色苍白、喷出一口鲜血，身子急急后退。本章仍是一头白发，尚未踏入第三步。
- **南诏上人**：在临近王林不足三丈时右手一震，**手心渗出鲜血**，似被无形所伤，眼露震惊，身体被大力冲击而无法追击，蹬蹬蹬退后数步，**直接退出黑色火鸟体内**。
- **南诏上人的判断**（神色阴沉）：他终于明白王林为何被列入「**太古星辰必杀榜**」第一位——「他还没有第三步就可以在我一掌之下逃遁反击，若他到了第三步，此子将会极为恐怖。此人，绝不能留。」
