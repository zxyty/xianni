# 第八卷 联盟隐秘 第1099章 外人

## 一、赤红断剑的来历
- 断剑通体赤红，一现身便有滔天杀戮之气弥漫整颗主星并冲入星空，连星球外燃烧的火焰都为之一顿、向外散开。
- 此剑为**灰衣天运子一生杀戮之根源所化**，当年**妖灵之地一战**后留在王林体内。
- 三年间王林边疗伤修行边慢慢炼化：当初消散融于其元神的部分已然祭炼完毕，眼下只剩体内这柄断剑本体。

## 二、动机：为重修杀戮仙诀
- 王林判断：「炼化此物后，再修行杀戮仙诀，则万无一失，不会出现百万杀戮之气自爆的危险。」
- 回溯：王林当年修炼杀戮仙诀多年并达**大成**；正是在那时，结合**古妖贝罗**的感悟境界之助，得知此诀的危害——若继续修炼下去，自身会崩溃化作一道真正的杀戮之气，成为灰衣天运子之物，故不得不放弃，心中一直惋惜。
- 此刻惋惜烟消云散：杀戮仙诀被视为攻守兼备的强大神通，炼化断剑后可在体内形成自己的杀戮之剑。

## 三、祭炼手段（层层加码）
1. **右目火海**：右目火光一闪，凭空生出火海环绕断剑燃烧。
2. **双元神喷元神之气**：右手掐诀点眉心，太古雷龙元神透出喷元神之气；太古雷龙元神内、九玄变所化**第二元神**同时睁目喷出元神之气，雷火交错，火焰如添滚油般暴燃，雷鸣轰隆。
3. **对抗现象**：断剑边缘刚一融化，即有阴寒杀戮之气冒出与火焰对抗——王林对此并不陌生，每次祭炼皆如此；但今日他必须一举全部炼化，不再消磨。
4. **神通「炎凝」**：双手掐诀、右目火焰更浓，右手抬起指天，第二元神同步动作，爆发无法想象的火元力化火海冲天；喝出「炎凝」后，所在修真星内全部火元力乃至星球外燃烧星空的火元力齐齐奔涌汇聚，再一指断剑，融化速度暴增数倍（杀戮之气亦随之增强）。
5. **第二元神亲入**：第二元神穿透太古雷龙元神，顺右目化作红芒直入断剑。
6. **撒豆成兵·放出困魂**：喷出**十八地狱封仙印**，喝「撒豆成兵，虚空子，天运子，现」，晶光环绕封仙印凝成两道虚影之魂——即被困的**虚空子**与**两个分身融合在一起的天运子**，二魂环绕第二元神四周协助炼化。
7. **岩浆封壳**：左手按向身旁火山口，引出赤红岩浆如流水环绕断剑，化作约**十丈**大小的火岩之球，密封其内、温度更高、祭炼更快。

## 四、代价
- 王林身在十丈巨球之下，双手不断调动四周天地火元力融入球内，**时间流逝十二个时辰**。
- 消耗的不只是自身元力，还有这三年来**吞噬数十个仙人元神**凝聚起来的**仙力**；此等强度若持续过久，王林亦无法承受。
- 定性：此番「不惜代价」，动用第二元神、虚空子、天运子分身、天地火元力、岩浆外壳五重手段。

## 五、时序与状态锚点（本章）
- 距妖灵之地一战约三年；三年内王林持续疗伤、修行、炼化断剑并吞噬数十个仙人元神。
- 九玄变已成功（成功前无完全把握，现有七成把握）。
- 虚空子（第987章已死）与天运子（第514章已死）此处以**被封仙印所困之魂**的形态出现，非新生行动主体。

# 第1015章 剧情梳理

## 一、祭炼完成：杀戮赤剑成形
- 十二个时辰后，王林双目爆出精光，低喝甩手，身前巨大**火岩球**轰然崩溃，化作无数燃烧碎片四散。
- 其内**断剑**在崩溃刹那无法抵抗火焰之威，**全部融化**，被王林**第二元神**一口吞噬，迅速回到体内。
- **虚空子**与**天运子**之魂回到**封仙印**中（二人之魂受封仙印所拘，参与/见证祭炼）。
- 王林闭目打坐片刻，其第二元神外凝聚出一把**赤红之剑**，阵阵**杀戮之气**环绕，心念一动杀戮之气即可冲出。
- 王林自评：**「祭炼此剑消耗其上杀戮太多，眼下上面存留的杀戮之气，不足百万，还需我继续修炼，不断地添加。」** —— 明确了此剑以「杀戮之气数量」为威能计量，且当前远未圆满。

## 二、三叉戟与「一个交代」
- 王林一拍**储物袋**，飞出一道乌光，化作一把散发**沧桑之气**的**三叉戟**。
- 正凝视三叉戟时，王林神色一动，抬头看向星空，双目闪过**愧疚与黯淡**。
- 暗叹：**「此事，终究要去给他一个交代。」** 收起三叉戟，身子一晃消失。（三叉戟与「他」的身份为本章留白伏笔）

## 三、朱雀圣宗主星：石像、十三与灵儿
- 距王林所在修真星不远，另有一颗**朱雀圣宗**的修真星，此星为**主星**，山脉众多、火红一片，颇为壮观。
- 该星最高山峰顶：
  - 一尊**黑色石像**，所刻正是**王林**；石像之后是**山顶洞口**，内里一片漆黑。
  - 石像前跪着秀美而神色凄苦的女子**灵儿**，一动不动，含泪哀求「求求你，让我进去」。
  - 石像旁盘膝坐着神色冷峻的**黑衣青年**，闭目吐纳，看都不看灵儿一眼，只冷淡回一句「不行」。
- 王林自空中波纹迈出。黑衣青年立刻神色激动狂热，起身恭声：**「十三见过师尊。」**（确认此人乃王林弟子，序称「十三」，奉命守洞）
- 灵儿见王林后神色更凄苦，未言语。
- 王林向十三略一点头，柔声唤「**灵儿**，带我去见你**祖爷爷**」。
- 灵儿泪下：「祖爷爷他……他快不行了。」
- 王林愧疚更浓，大袖一甩卷起灵儿消失。二人走后，**洞口深处有两道精光闪烁**（洞中另有存在，伏笔）。

## 四、本尊异状：腰下只剩骸骨
- 与此同时，**王林本尊**睁开双眼，同样露出愧疚；**星痕貂**乖巧趴在其肩上，伸舌舔他脖子。
- **无人看到：本尊腰部以下此刻只剩一片骸骨，散发幽幽的气息。** —— 本尊伤势/代价的重大揭示。

## 五、城墙饮酒：白发老者的悔恨
- 朱雀圣宗一座**城池**上，一位满头白发、容颜极为沧桑的老者不断饮酒，神色癫狂。
- 老者狠灌一口酒，泪与酒混流：**「老二，老三，大哥对不起你们，对不起……」**（三兄弟中仅存的「大哥」，与前文「尘道三子」式的兄弟折损相呼应，具体身份本片段未点明）
- 叙述点睛：他喝下的是酒，也是泪；因泪而苦涩，与其说喝酒，不如说是喝下自己的眼泪。
- 王林与灵儿自其身后波纹中走出。灵儿见状泪更多，欲上前夺酒壶，被王林阻止。
- 王林长叹走近，与老者**一同坐在城墙上**，随意拿起旁边一个酒壶，同样喝了一大口。（无言的陪伴与愧疚偿还）

## 六、另一线：联盟星域中部的外来者与巨蚊兽
- 场景切至**修真联盟**所在的**联盟星域中部**。
- 数十只形若蚊子的凶兽——**巨蚊兽**——呼啸而过，双目通红。
- 一股若隐若无、**唯有蚊兽才可嗅到的香气**徐徐传出，使蚊兽仿若被香气操控。
- 蚊群前方有**三个身穿黄衣的青年**，各持一根**古怪的燃香**，小心翼翼引导蚊群前行。
- 其中一人眼露贪婪低声道：「没想到这联盟星域内，竟然会有巨蚊兽……此番去与**长老**汇合，带着这些巨蚊兽，我三人就可立下大功一件。」
- 关键伏笔：**三人语言声韵与联盟星域内修士有所不同，仿若是来自联盟星域之外。** —— 外域势力已渗入联盟星域。

## 七、本章要点与悬念
1. 杀戮赤剑初成，但杀戮之气不足百万，尚需长期蕴养 → 王林后续仍需持续「添加杀戮」。
2. 三叉戟 + 「要给他一个交代」 → 指向一位未点名的故人/亡者。
3. 王林本尊腰下成骸骨 → 本尊状态极端恶化，与其分身/第二元神活动形成对照。
4. 王林石像被立于朱雀圣宗主星最高峰，弟子「十三」守洞，洞内有两道精光 → 洞中封存之物/人待揭。
5. 灵儿的「祖爷爷」即城墙上的白发老者，行将就木，其失去的「老二、老三」构成王林愧疚的因由。
6. 联盟星域内出现操控巨蚊兽的外域黄衣修士与「长老」，为新的外敌线索。
