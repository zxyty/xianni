# 第1596章 炼魂宗的果

## 一、炼魂宗的推衍（开篇）

- 一名中年男子（炼魂宗**遁天**）近乎疯癫地凄笑：“莫非，我炼魂宗，再无崛起之日，再无延续的可能”。
- 忽然面色一变，猛地回头遥望远处，双目一凝，掐诀疯狂推衍计算。
- 短短一瞬消耗**大量寿元生机**，**连算九次**，九次结果**完全相同**——一个让他无法置信、甚至荒诞的结论。
- 沉默中身形一晃消散，以**挪移之术**直奔**赵国**。

## 二、凡人王林：因果之问与雨停

- 赵国某县城客栈二楼，王林（此时为凡人少年身份）立于窗前，喃喃“**因果，什么是因果**”。
- 一夜流逝，他回到桌旁望着熄灭的烛台发呆，脑中此前存在的**苍桑之声**不断回旋，渐渐取代全部思绪。
- 窗户忘关，此刻已无风无雨；天明日出，**大半个月的乌云在这个清晨全部消散**，万里无云。
- 大福醒来得意宣称自己昨夜梦到一指令雷霆消散，自诩“果然不是寻常之辈”。王林顺着他打趣：“你厉害，是你梦上天庭，让雷雨消失。”
- 王林一夜未睡却不觉疲惫，唯**眉心隐隐胀痛**。

## 三、五日备考

- 科考定在五日后，第六天清早开考。
- 这五日王林仅去县城衙门送**路引考贴**、排定考场，其余时间几乎不出客栈，抓紧读书。
- 心理动因：**不想失败**——不忍父母目光黯淡，不愿父母在眼高于顶的亲戚面前受“看似安慰、实则嘲笑”的目光；若败则须回村再等数年。
- 大福性子好动，五日间在县城四处转悠结识了一些人，并“学会了更加吝啬的本领”。

## 四、入场

- 第六天王林沐浴焚香、换白色文士衫，与背竹排书箱的大福出客栈，前往**县城之西的第三处考场**。
- 街道热闹，早摊林立；赶考书生行色匆匆。王林吃了几个包子后到达考场外。
- 两名锦袍官员冷漠注视考生，气氛凝重；大福因见别人书童多年纪不大、自觉格格不入而郁郁，只顾啃包子。
- 钟鸣响起，官员告诫“进考场若有小抄者，自行拿出”，逐一搜检后放入。王林同样受检后入场。

## 五、考题与破题（本章核心）

- 考题是一幅画：一座山、山上一棵**笔直大树**、天有风吹树晃、山下几笔勾勒的**守山人家屋舍**。立意明确为**“栋梁之材”**，绝大多数考生皆据此作文。
- 王林见画即想起五日前回荡的那句“因果，什么是因果”，久久不下笔；晌午有人交卷，夕阳渐落，全场最后只剩他一人。
- 一名监官敲桌催促“若是作不出来，便赶紧离开”。王林闭目数息后猛然睁眼，目露明亮之芒，蘸水化墨疾书：
  - “**何为因果，若觅屋木，然此山无木，吾独种一树，日初取枝，日中取木，日落取根**”
  - “**何为因果，种木为因，取木为果；然屋木成貌之日，同样也成了一桩因果**”
- 写罢目中明亮消散，重归**迷茫**，向身后唯一始终未走的监官老者抱拳，收拾竹排离场。

## 六、监官老者的评断

- 数名监官凑近看后：有人嗤笑甩袖而去，其余摇头走开。
- 唯那名老者在王林走后再次仔细通读，**眼中恍惚、似有所明悟**，记住了考卷上的名字。
- 评语：“这等对于因果的思索，居然会出现在一个少年身上，此人或许不能成朝廷的栋梁之才，可却能成**一代大儒**。”沉吟许久后提笔在王林名字上**画了一个圈**。

## 七、遁天现身（本章结尾转折）

- 王林出考场，见大福靠树等了一天已呼呼睡去，正欲推醒——
- **天地骤暗，狂风大作，鬼哭凄厉**，一股**黑风**自天而降笼罩王林与大福，将其所在与县城**分割开来**。
- 黑风中幻化走出**身穿黑袍、周身冰冷气息的中年男子**，凝望王林道：“**老夫不会伤害你，你只需回答一个问题。**”
- 其身份点明：**炼魂宗遁天师兄**。
- 背景交代：此地县城几乎所有科考书生，都在这数日间被他一一寻到，每人被问出**同样的问题**，问后**抹去此事记忆**，失望之下再找下一人。

## 八、要点与伏笔

- 章名“炼魂宗的果”呼应王林答卷中的“因/果”之辨：炼魂宗的推衍结果（果）与王林的因果之悟形成互文。
- 遁天的九次推衍指向王林，是他赶赴赵国、逐一盘问书生的直接动因。
- 王林凡人期的“因果之惑”与眉心胀痛，是其修真本相与转世凡身之间的裂隙征兆。
- 待解：遁天要问的“同一个问题”究竟为何，本章未揭示。
