# 第2088章 蓦然回首（结局）

## 一、太古神境·重逢与收局

- 地点：太古神境圆形大地正中心，一座飘着七彩雪花的山。人物：王林、李慕婉。
- 七彩雪不再带有悲哀含义，与王林当年在始吉祖庙分神中所见的那一幕已完全不同。
- 王林许诺：离开后寻一个平凡的地方，用一辈子给李慕婉讲这个漫长的故事，并带她见王平与其妻青宜。
- 王林牵起李慕婉的手，自她苏醒后从未松开——「怕一旦松开，就又找不到了」。

## 二、定界罗盘归一为天逆珠

将踏上踏天之桥时，王林左手向身后大地一挥，放出三道长虹：

1. **半个罗盘** —— 与大地融合，原本虚幻的另一半变得真实，大地上裂缝山脉所化的刻度符文爆发光芒，罗盘隐隐运转。
2. **巨大指针** —— 沉入七彩雪之山融合，于圆形大地转圈横扫，磅礴之力扩散。
3. **白色珠子（天逆珠）** —— 悬浮天地间，散发柔和光芒，使定界罗盘趋于完整。

王林一声「收」，大地、七彩雪山与此间一切（唯余那座桥）尽数缩小散去，化作巴掌大的罗盘，再缩，最终仍是那颗**天逆珠**。

> 天逆珠即定界罗盘最关键的部分，也与定界罗盘完整后所化之形毫无区别。

## 三、送别古道

- 回望时天地皆虚无，虚无尽头站着**古道**，他目睹了这一切与桥上二人，喃喃「这就是答案」，神色复杂。
- 王林右手一挥，古道身后现出通往**仙罡大陆**的巨大漩涡；古道深深一拜后走入消失。
- 此后仙罡大陆上，除古道外再无人知晓太古神境内的一切。
- 王林携李慕婉走入桥的尽头虚幻中；桥随之化作晶光，散入虚无。

## 四、桃园对弈·守护者的答案

场景：如桃园之地，亭榭内石桌石椅，一副黑白错落的残局。

- **仆从老者**：外貌为凌天侯，王林一眼认出并唤其名，老者摇头，答语出自灰衣人之口——「是，也不是」。
- **灰衣人**：相貌与天运子一模一样，自陈「天运子是器灵，我在它的身上留有一道神念，也就是你看到的灰衣天运子」。
- 灰衣人称：王林的分身当年与他下到一半便离开，他等了多年终于把王林等来，请王林续弈；并落下一粒黑子。

### 揭示的真相

| 议题 | 内容 |
|---|---|
| 守护者 | 「我是，你也是。」 |
| 七彩界来历 | 最早由王林的分身创造，后被器灵发现并借以利用 |
| 仿造天逆珠 | 是王林杀戮分身想知晓「缺少的那一个为何物」的猜测与一次次尝试的根源 |
| 铭志道经 / 劫经 | 正是王林一生的经历 |
| 「奉至修真行」 | 「真」代表轮回中的真我；意在令众生于轮回中寻找真我、走出轮回 |
| 踏天序列 | 灰衣人为逆尘界第一个踏天境，王林为第二个；除王林那具分身外，众生皆无人可踏天而来 |
| 更高之境 | 第四步踏天为逆尘界巅峰，但宇宙苍穹四大界中已有人走到第五步乃至第六步 |
| 棋盘来历 | 在灰衣人来到这里之前，棋盘就已存在（此问未被正面回答：定界罗盘是否为其所创、器灵是否由其封入） |

### 落子与「明白了」

王林以掌心白色天逆珠作白子落于棋盘。刹那间黑白诸子自行点落推衍，最终全部融合为**两子**：白子于王林一方，黑子于灰衣人一方。王林抬头问「明白了么」，灰衣人沉吟轻叹、点头称明白。王林起身携李慕婉前迈一步消失；棋盘白子随之虚幻消散，似随他而去。

## 五、杀戮分身归一

- 地点：仙罡大陆·古族大地一处山峰。王林盘坐数日，似在等待；李慕婉守于身后。
- 三日后黄昏，仙罡大陆外现出**黑衣黑发男子**（杀戮分身，戮默），周身充满杀戮与毁灭，样貌与王林一模一样。
- 分身冲入大陆、直抵山峰立于王林身前；见李慕婉时冷漠目光转柔和。
- 王林：「你本可以不来。」分身断下一丝黑发，松手后黑发渐化为白；同一瞬王林手中也现出一根白发，随即散去。
- 分身再看李慕婉一眼，闭目化作黑气，**抹去自身灵智**融入王林体内；王林吸收全部黑气，体内再次凝聚出**杀戮真身**。
- 王林由此明白戮默在拥有灵智后仍选择散去、选择重新融合的缘由：「对我来说，是五百年；对他来说，是无数次的轮回。」

## 六、归于平凡

- 王林问李慕婉「看到他了么」，李慕婉一怔——她什么也没看到。
- 决定：去一个没有人认识他们的地方，开始平凡生活，先去看王平和他的妻子。
- 关于是否还修行：「修行在心，找到了真我，哪里都是一样。」二人化作长虹飞向昏暗天空。
- 李慕婉留下未解之问：那棋局结束后你们说的「明白了什么」？

## 七、尾声·蓦然回首

- 山下不远的**黑石城**一角，一白衣女子背对万家灯火，仰望远去长虹，泪落衣衫。
- 自语：「忘记吧，一切都忘记吧……前一世的鱼儿，就是这样在那水中看着飞鸟渐渐远去的。」
- 身后柔和之声：「前一世，我们是飞鸟与鱼，但这一世，我们不是。」女子娇躯一震，**蓦然回首**，看到灯火阑珊处那个微笑望着自己的身影。

**全书终。**
