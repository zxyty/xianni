# 第八卷 联盟隐秘 第929章 王林之物

## 一、望月破封
- 地点：联盟星域北部战场。望月第一次展开其神通之术，怒意引爆的力量令北部所有修士感受到无法想象的强大，此前一切轻视尽数瓦解。
- 其体外黑色壳子大片龟裂、轰然震开，碎片横扫：有修士闪躲不及被撞得肉身崩溃、元神难逃；数人被碎片断口横扫斩为两半。
- 壳内传出仿若来自远古的咆哮，无限接近**古神之吼**，如穿透时空岁月，化作无尽冲击。

## 二、古神一指
- 咆哮之中，**古神一指**自壳内伸出，绚丽壮观，仿佛天地皆可在一指之下崩溃。
- 王林的观感：一指之后似立着一尊顶天立地的成年古神，挥舞粗大手臂向前不断破坏。
- 战果：
  - 追击王林的炼尸神智短暂空白，被一指正面命中——铁链寸寸碎裂、后背喷出黑血、紫青皮肤如被生生剥下，肉身骨骼四分五裂，仅数息之间。
  - 一指余势不停，横扫沿途修士，未及近身便肉身崩溃。
- 望月庞大椭圆身躯紧随其后冲出，触须摇动喷雾。**王林发现望月双目毫无迷茫、一片清晰，且似乎也在看自己**——神智清醒是关键异常。

## 三、战局与王林的判断
- 望月脱困给罗天修士带来磅礴战意；此战波折四起，联盟与罗天互有上风。
- 王林一生杀戮，但此战死者远超他所杀之人；当年**朱雀星与仙遗族之战**与之相比微不足道。
- 王林认定望月「应该算是罗天方面此次大战中的最强之物」，否则罗天不会费尽千辛万苦将其送入联盟星域。
- 王林望向远处漂浮的**参天巨木**，隐约感到「这巨木内另有一物」，其神通不止于此。
- 收获：此战如同一场神通与法宝的大展，王林修道时间远短于老怪们、见识不足，借此迅速吸收阅历，尤其**明白了净涅修士与碎涅修士之间的战斗与真正实力**——若无此战极难获知。

## 四、黑煞魔尊的抵挡
1. 喷雾掐诀，雾气化作一头**黑色大鹤**，鹤口所叼**黑色芝草**脱落后疯长至千丈并向两旁扩展成防护；古神一指撞上，芝草寸寸碎裂化作黑气。
2. 黑煞魔尊面色苍白喷血倒退，虚空一抓取出**诡异木雕**：所刻为全身被植物包裹、抱臂的人形，面目不清。
3. 木雕抛出后爆发吞噬光芒的黑光，凭空生出**五朵百丈黑花**，花心撕裂如巨口喷出极阴寒黑气；抱胸木人双目红光、真正活化，张臂扑上抱住古神指头，体内飞出黑色细线弥漫缠缚。
- 王林在远处冷笑：古神一指若这般轻易可破，望月便不值得罗天如此运送。
- 同时联盟剩余十多具炼尸疯狂扑近，两具**银色炼尸**速度最快，但合力仍不足以抗衡古神一指。

## 五、古神一指自爆
- 望月再次剧烈咆哮，声震星空，修为不足者被迫退避。**吼声在王林耳中意义不同**：他面色一变，立刻掐诀在身前凝聚无数禁制防护，并催动体外**古神大鼎**闪烁后退。
- 随吼声，被众炼尸与黑煞魔尊阻拦的古神一指**轰然自爆**：方圆万里星空被撕开巨大口子，大量修士被卷入碎裂虚无中消失无影，双方修士骇然溃退。
- 唯望月毫发无损，冲入其中以触须横扫展开疯狂屠杀。

## 六、战果与王林的目标
- **黑煞魔尊**：处于自爆中心，连喷鲜血被抛飞，血雾弥漫，数万年修为狼狈异常，肉身破损几近崩溃，一生修道未遇如此强大之物，魂飞魄散般疯狂逃遁。
- **炼尸**：十多具中除两具银尸外全部崩溃化作血肉，被卷入碎裂虚无。
- **两具银尸**：被生生震开，全身铁链崩溃、喷出大口黑色鲜血；其中**美艳女尸**竟直奔王林而来。
- **王林之物**：王林双目闪烁，看中的不只是这具女尸，还有远处那个**破损的半截木雕**——「这等法宝，就是我王林之物」。

## 七、悬念
- 望月神智清醒、且似能与王林对视，其真实来历与所属存疑。
- 参天巨木内疑另藏一物。
- 王林是否能同时取得银色女尸与黑煞魔尊的木雕法宝。
