# 第628章 百万杀戮（第三更！）

## 一、场景：死寂的火妖郡都城燕京

- 王林**未飞行**，一步一步走向火妖郡都城**燕京**，白衣长发在灰色雾气中飘动，身影「好似一个白衣游魂」，脚步嘎吱之声回荡。
- 雾中之城极为空旷。百年前此地繁华程度**丝毫不弱于天妖郡的天妖城**，如今却已死寂。
- **古妖对子民的态度**：在妖灵之地九郡古妖眼中，子民只是他们教化而出、用以恢复自身妖力的工具，即便全部死去也不会心生半点波澜。
- 火妖郡燕京中人——上至妖帝妖帅、下至妖兵平民——**全部上了战场**，化作骸骨洒落大地、化作鲜血染红土壤。
- 王林心中古井不波。

## 二、妖气封印（妖幕）

- 位置：**火妖郡燕京外十里**，由此地古妖布下的**妖气封印**。
- 性质：威力极强，是古妖保护自己的手段之一；**其他几郡的妖帅都无法破除**。
- 破除门槛：除**同为古妖**者外，只有**修为惊人的大神通修士**方可破之。
- **与古妖贝罗的约定**：贝罗曾预言，火妖郡内的古妖在都城空旷之后必会封印此城、阻止任何人踏入；他与王林约定的**第一个环节，就是打破这道封印**。

### 试探与对话

1. 王林抬右手，手指黑芒闪烁向妖幕点去 → 手指刚触及即被**庞大反弹之力**砰然弹起，酸麻之感顺手指流入筋脉；运转体内**仙力**后少顷恢复。评价：「的确很强」。
2. 城内传出**蛮横神识**与震撼元神的怒吼——「滚」，声如无数春雷炸响、开天辟地。
3. 王林右手掐出**极为诡异、带有妖气弥漫的印诀**，怒吼降临其身刹那即烟消云散。
4. 城内古妖据此认出来路，愤怒质问：「贝罗——你是贝罗派来的？」王林不予理会，只自语：「古妖贝罗，我与你的约定，这第一步，你且拭目以待。」

## 三、召聚：十万道杀戮之气

王林指天，平缓吐出五字：**「杀戮之气，聚」**。整个火妖郡随之掀起风暴。

| 位置 | 潜藏的炼魂部落族人 | 表现 |
|---|---|---|
| 火妖郡北部战场 | 混入双方**妖兵** | 通体一震，浓浓杀气穿透天地般飞出；面露兴奋高呼「**老祖临世**」，弃战迅速离场 |
| 火妖郡南部战场 | 神秘**黑衣人**群体 | 身影极快、体内蕴含浓浓杀气，行走间取妖兵性命、使妖兵化作灰气被其吸收；百年来双方已习惯其存在，来无影去无踪、不知何方势力，围剿往往得不偿失。此刻身子一颤、眼露狂喜，杀气冲出后彼此迅速离去 |
| 火妖郡各处 | 交战双方**大量将领** | 身子轻颤、杀气自头顶冒出，随即退后、各展手段迅速离去 |

- 结果：天空由蓝转灰，无数道杀戮之气冲天而起，**齐齐向燕京凝聚**；交战各方停战，惊疑迷茫地望天。
- **十万道**杀戮之气自四面八方向王林飞来，燕京上空呼啸不断，王林所在如**巨大旋涡的中心**。
- 每一道杀戮之气都比百年前浑厚无数倍，所含杀机远超当年——**百年滋养使之几乎凝化为实质**。

## 四、分裂：十万 → 百万

- 王林眼中闪过一丝红芒，**杀心与杀意融合，成为杀戮之气的根源**。
- 一字「**分**」：十万道杀戮之气**一分为二**，转眼二十万；再分、再分、再分。
- **十倍分裂**后，十万化作**百万**，天地被灰气弥漫（非雾，而是杀机、杀气、杀意与杀心凝化）。
- **瓶颈说明**：百万之气原本还可再分，但王林的**杀戮仙诀毕竟只是略有小成**，百万即是当前瓶颈——**这也正是他不亲自杀戮、而以炼魂部落族人「养杀」的重要原因**。

## 五、破封

- 王林长发飘动，右手蓦然指向妖幕封印，喝：「给我，**破**」。
- **百万杀戮之气**齐齐好似雨水般降临封印（本章止于此，结果未叙）。

## 六、伏笔

- 明确点出：**寻找周佚的路途将展开，这是王林进入妖灵之地的重要目的。**

## 关键要点

- 王林与古妖**贝罗**存在多环节约定，破燕京封印仅是**第一步**。
- **炼魂部落**百年潜伏于火妖郡战争双方（妖兵/将领/黑衣人）充当「养杀」容器，是王林杀戮之气的来源体系。
- 王林此时以**仙力**行功，杀戮仙诀评级为「**略有小成**」，威能上限=百万道杀戮之气。
