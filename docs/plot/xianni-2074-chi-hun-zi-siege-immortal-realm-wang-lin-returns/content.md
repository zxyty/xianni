# 第2074章 赤魂子！（第三更）

## 一、仙界城头：南云子的死战之言

- 南云子肉身已毁，**只剩元神存在**，死死盯着天空血光内的青年。
- 面对『两天后破阵』的威胁，南云子凄厉大笑，抛出仙界立身之语：
  - 「我仙界自王林创造以来，存在的全部都是与界外大战中存活之修。」
  - 「**我辈修士，何惜一战**」
- 大地上所有修士齐声应和，音浪轰鸣升空，**竟将天空血光隐隐冲淡**，露出血光后一群上万穿血袍的身影，以及其后一片翻滚血雾（内中似盘膝坐着一人）。
- 南云子断言：「仙界的创造者，王林必定有一天会回来，当他回来时，区区一个赤魂教、区区一个赤魂子，我看你们如何抵挡。」
- 蓝梦道尊在南云子旁盘膝而坐，**面色苍白、正疗伤吐纳**（已被赤魂子重创）。

## 二、血光青年：赤魂子的弟子

- 天空血光内的青年只是**虚影**，非本体。
- 放话：两天后阵法破开，要请师尊把南云子的元神赐给他，「尝尝第三步大能的元神是什么滋味」。
- 嘲讽王林：「王林此人幸亏当年离去，否则在师尊面前只是蝼蚁」；称仙界阵法虽为王林所布，一样要被师尊破开；若非要保仙界完整，师尊出手即可将此地完全粉碎。

## 三、阵法之外：赤魂子的来历与图谋

### 围城态势
- 仙界大陆外，**王林当年布置的阵法禁制**四周被血色笼罩，血色不断侵蚀，**已破损大半，再两天可完全打开**。
- **数万血色身影**如傀儡般安静漂浮于仙界外星空，散出大量红雾融入侵蚀大阵的血光。
- 血色雾气中盘膝坐一红袍红发老者，双手掐诀、时而打出印诀，加速阵法破损——此人正是**赤魂子**。

### 关于禁制的判断（关键伏笔）
- 「这王林的确有些手段，布置的禁制竟让我也需数日方可破开。」
- 禁制内**有一丝让人惊恐的气息**，赤魂子预感：若全力出手强行轰开粉碎仙界，会出现**惊变**。
- 应对：**不强行轰开，改以血色侵蚀**，即可避开这股气息、化解于无形；「好在这气息不多，只有一丝」。

### 身世揭底
- 当年王林在**掌尊的生死劫**中，释放出了**烨寞封印的一魂**；此魂破开生死劫封印后呼啸而去。
- 如今该魂**恢复修为、具备肉身**，并在王林离开多年后**创立赤魂教**，围困仙界，重创蓝梦道尊、毁南云子肉身。

### 野心路线图
1. 破阵后**吞噬界内几乎所有强者的精血**（强者尽集于仙界），修为再提高一层，**成为金尊**。
2. 成为金尊后，即便回到**仙罡大陆**也足以做一宗大长老。
3. 此生仍有机会进阶**天尊**（仙罡大陆天尊极少，只有几百的样子）。
4. 成为天尊后寻**大天尊**依附：首选**仙皇**（但其麾下强者如云，未必招揽），退求**道一大天尊**（对天尊修士极为在意，必定接受）。
5. 对王林的预案：若王林修为不如他，就吸其全身精血壮大自身；若相当或略高，则有道一大天尊庇护——「在大天尊眼中，一切修士皆为蝼蚁」。

## 四、师徒对话：王林后人与木冰眉

- 弟子来历：赤魂子在**洞府界**所遇、极合自身功法的弟子，天资不凡；**是在朱雀星遇到的**，据说是**王林不知多少辈的一个后人**，且**已获得烨寞的传承**。
- 弟子求索南云子元神折磨之，赤魂子欣赏其残忍，允诺：「区区一个南云子，给你了。」
- 关于**木冰眉**：
  - 弟子表示「师尊若是看重了此女，弟子双手奉上」。
  - 赤魂子嘲讽提醒：「**她可是你先祖的红颜**」，并设想若王林某日知晓此事会是什么表情。
  - 弟子答：虽姓王，但王林既已离开洞府界生死未知，留下的红颜由后人享用理所应当（「师尊不是一直这么告诉我的么」）。
  - 赤魂子大笑：「**烨寞死了，但你既获得了烨寞的传承，那么王林，你也将传承我对他的恨**」，眼中恶毒一闪。
  - 最终安排：木冰眉是赤魂子**亲自为弟子挑选的道侣**，他不去抢，但要先「调教一番，等腻了后，自会给你」。
- 谈毕，赤魂子掐诀，血雾剧烈翻滚，外面数万血色傀儡释放更多血光，仙界阵法**越加脆弱**。

## 五、仙界之内：木冰眉与晶剑

- 仙界一处至高山峰上立一白衣女子——容颜绝伦，「莫说是这洞府界，就算整个仙罡大陆上也没有任何一个女子能与她相比」，「她的美，几乎不属于这片天地」。
- 身后老者恭敬呼「**圣女殿下**」，焦虑禀报：「阵法最多坚持两天。」木冰眉令其退下，独自静一静。
- 木冰眉抬手，掌心是**一把晶剑**——**王林留给她的，王林本源所化，还存有其当时道古的气息**。
- 回忆王林离别之言：「**若我还在世间，会迎你**」；她哀伤续道：「若我不再了世间……」
- 「王林，你在哪里」——泪落剑上，顺剑刃流淌。

## 六、章末转折：王林归来

- 就在木冰眉呢喃之际，界内**原是罗天的方向**，平静漆黑的星空凭空出现刺目光芒，化作**光门**，从中走出一人。
- **白衣，白发。王林。**
- 王林环顾四周微笑：「罗天」——熟悉的气息让他知道**自己回家了**，神识下意识向八方扩散。
- 正喃喃『不知仙界那里现在是什么样子……那些故人』时，话语一顿，猛抬头死死盯住仙界方向。
- **笑容刹那被一片寒意与滔天杀机取代**——这是他成为**仙罡大陆最强的第一人**后，第一次完全爆发出杀机。

## 七、悬念与看点

- 倒计时：阵法**两天**后破开。
- 未爆弹：禁制内『一丝让人惊恐的气息』究竟为何（赤魂子不敢硬轰）。
- 因果闭环：烨寞封印之魂 → 赤魂子 → 收王林后人为徒并授烨寞传承 → 以『传承恨意』反噬王林。
- 王林归来落点在罗天，与仙界隔空对望，杀机已起。
