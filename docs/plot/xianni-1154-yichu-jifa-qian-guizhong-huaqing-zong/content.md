# 第九卷 云海之巅 第1154章 一触即发！

## 一、钱贵钟其人
- 华清宗长老，修为**碎涅初期**，神通惊人，性格以“狠”著称，在六阶星域内几乎无人不知。
- **前史（约一千多年前）**：一个六阶星域小宗派误杀其一名弟子，钱贵钟携数名同门杀上山门，毁其道统，血流成河，由此名声大振。
- 本章中他面色阴沉，盘膝坐于一头**龙形巨蟒**头部，率一众华清宗核心弟子穿行**五阶星域**，直奔**蛮荒大陆**。他只是第一批援军，后方华清宗几乎倾巢而出、陆续赶来。

## 二、回溯：一万八千年前的破天宗浩劫
（云海星域本土修士皆知的惊天大事）

1. **发现**：八阶宗派**破天宗**已具备搬迁进入九阶星域的资格，却在临搬迁前两个月偶然发现一处**空间裂缝**，其内满是禁制与凶险。
2. **深入**：破天宗集合大量修士，由数名**天人衰劫**境界长老带领闯入，一路破开，死伤无数。
3. **所得**：裂缝深处有一具骸骨，旁置三物——**一粒丹药、一把残剑、一块兽骨**。兽骨即传说中的**涅空丹丹方**载体。长老们为之疯狂，急欲带回宗门，认为此发现足以震惊云海星域，甚至令破天宗压过至高无上的**九阶神宗**、成为云海第一宗派。
4. **走漏**：宗内出了叛徒，消息外泄，整个八阶星域宗派疯狂出动，常年闭关的老怪纷纷出世参与争夺。七阶、六阶星域受牵引跟进，五阶星域亦略有波及，血雨腥风横扫云海星域。
5. **九阶出手**：几乎从不干涉下阶事务的九阶星域终于插手，破天宗形势急转直下。
6. **分裂与结局**：
   - **大部**：不愿再为三物血战，交出**丹药与残剑**换取生存资格并献出，保持原有宗派轨迹进入九阶星域。
   - **小部**：携**兽骨丹方**与各方抢夺者生死厮杀，最终消失在历史长河中。
   - **兽骨丹方就此失踪**，或猜被九阶星域修士取走，或猜藏于当年追杀者中某个八阶宗派手中，成为永恒隐秘。

## 三、华清宗的谋划（数月前起）
- 华清宗**数月前偶然得到线索**：关于传说中**涅空丹丹方**，以及一枚**可成为破天宗核心弟子的玉简**。
- 对内**彻底封锁消息**，不惜屠杀灭口部分知情弟子——破天宗当年血的教训在前，稍有不慎即引来灭门。
- **战略意图**：华清宗自知与昔日破天宗相比不过蝼蚁，无资格独吞；打算找到兽骨丹方后**献给某个八阶宗派**，换取庞大好处与长久庇护，并借其之力成为**六阶星域霸主**。
- **必须先求证**：线索若为假而贸然上献，承受不起八阶宗派怒火；线索指向**三阶星域**的一个宗派，大举出动又会招致猜疑。
- **执行**：派一向稳重的大弟子**施洛刑**，带**十九名弟子**秘密前往三阶星域。施洛刑修为在六阶星域内不算最高，出动不显眼——事实上直到抵达三阶星域都未生麻烦。
- **结果**：线索为真，且**极容易地取得了兽骨碎片与一枚玉简**。但返程途中不知何故消息败露，引来**五毒门**追杀，六阶星域各宗派亦得知此事。

## 四、途中遭遇：王林（伪装）
- 王林骑**百丈大小黑猿**行于星空。为避免修为古怪引人怀疑，他**元力时刻外散，把修为凝聚在窥涅中期左右**。
- 钱贵钟一行十余道长虹逼近，王林**装作被惊、面色苍白、停在半空**。
- 钱贵钟据星图判断此地附近另有几处蛮荒大陆，看其轨迹应是自另一处蛮荒大陆出来，未见端倪，遂**不予理会，穿身而过**，身后核心弟子亦一语不发掠过。王林暗中松气，判断这些是六阶星域修士，去向正是那座蛮荒大陆。

## 五、转折：玉简传书报丧
- **玉简传书设定**：宗派内部神通，玉简之速远超修士，不惧外人窥看；内有固有阵法禁制，无特定手印触之即崩溃；为防意外，往往一次不止发出一枚。
- 一道荧光破空而至，掠过王林身侧落入钱贵钟手中。钱贵钟左手掐诀、以独特手法捏住玉简，施展**宗派查看玉简传书的绝密心法**，神识一扫，浑身一震。
- **内容**：第二波援助同门传来——**施洛刑在宗派集英阁内的命简碎裂，施洛刑身亡**。

## 六、一触即发
- 钱贵钟面色阴沉，狠捏玉简，目光落向王林。**并非单独怀疑王林**：施洛刑死于何人之手未明，无论五毒门或他派出手，凡接近蛮荒大陆范围的一切修士皆是怀疑对象。
- 其念头是**“错杀一千，也不放过一个”**。
- 下令：“带着他，一起去蛮荒大陆”。身后**八名核心弟子**飞出直扑王林——其中**六人为阳实修士，一人达窥涅初期**。
- 王林面色一变，起身作恭敬中带恰到好处惊慌之态，抱拳问“诸位道友，这是何意”。对方喝令“莫要让我等出手，道友立刻随行”。
- 弟子们平日绝不敢如此（王林伪装修为仍高于他们），但钱长老在旁、又逢门派绝顶大事，故毫不客气。
