# 第1206章 我辈修士，何惜一战！

## 一、石像画面终结与雷电入目
- 石像双眼中的画面消散刹那，阵法中的闪电破开虚无、星空与时光，落在王林右目；王林脑中雷鸣轰响，退后数十丈，神色狰狞。
- 石像轰然坍塌化作碎石。王林口中吐出二字：「界外」。
- 心理转折：他看罗天与联盟之战、修士因宝厮杀的浩劫、联盟势力内斗，皆无所动；唯独看到阵法内外殉道的先辈，热血冲头。
- 耳边回荡仙人死前呐喊：「不甘心……终有一日，吾辈修之后人，必将破开阵法，让你等外民万灵灭绝殆尽，让你界外血流成河！」
- 王林右目闪电印记不断闪烁，随后转身飞向被岁月禁环绕的山峰。

## 二、界外三人的抉择
远处雾中三名界外青年（眉心分别为闪电印记、火焰图腾、月牙印记）：
- **闪电印记者**：感知到前方雷霆之战，一方与自己同源，另一方雷力震撼到他几乎控制不住体内雷力；见石像碎裂，认出那正是**自己的先祖**，先祖遗留的雷灵被人强行收走——先怒后惊。
- **火焰图腾者**：垂涎王林心神扫过时泄露的火之力，主张「若我三人打开封印，可借取一炷香时间的巅峰之力，杀此人不是没有可能」。
- **月牙印记者**：一路沉默阴沉，最终咬牙「富贵险中求」，定下追杀之议。
- 闪电印记者原提议离开、把空间裂缝禀告长老（「我总有一种不妙的预感」），沉默后仍双眼凶芒，循雷霆痕迹率先冲出。

## 三、重破岁月禁
- 地点：王林之前与**苍松子**抢夺玉瓶之处的岁月禁幕。
- 判断：若禁制完整或破开年代久远，强行打开需不惜崩溃法宝；但此禁刚被打开不足数月，且心神扫过时记得幕上有一道看不见的裂缝——即**苍松子与青衫老妪**当初破开处。
- **岁月禁弊端**：裂缝虽愈合，其上岁月禁只积累数月，除非再过无数年，破绽将长期留存。
- 手法：
  1. 掐诀放出**破灭禁**化作残影弥漫禁幕，神识散开密切观察，锁定旧裂缝位置；
  2. 祭出**水晶剑**横扫，剑光带起一股**次空涅**气息，剑芒直奔裂缝，剑气不断撕大；
  3. 跃起取**三叉戟**（散无尽黑芒），如流星刺入裂缝，以**古神之力**顶住反冲，一挑之下将愈合数月的裂缝豁开数丈。
- 王林收回水晶剑，穿入裂缝直奔山峰；对山峰中段的**闪电石门洞府**只扫一眼便收回目光。
- 至峰顶，以三叉戟前扫，虚无中现出**空间裂缝**——位置来自**苍松子的记忆**、王林首次到此的观察与心神蔓延所得。王林踏入。
- 不久后界外三人穿过王林撕开的禁幕裂缝，直奔山峰。

## 四、石碑、骸骨与「战」字道统
- 异空间内：巨大**石碑**，碑下方**半具骸骨**被**两根七彩钉子**钉在碑上。
- 骸骨黑芒流转，骨上**经文**散发莫名吸引力，可令人为之疯狂；王林凝元封神、避看经文，退后数步方恢复。
- 石碑不知何物所制，散沧桑与岁月痕迹；王林**觉其材质眼熟却想不起在何处见过相似之物**（伏笔）。
- 王林打开**储物裂缝**，放出金光**虚幻「战」字**：骸骨上金芒涌出，与黑芒交替变化，最终金光飞出与战字融合，天地笼罩万丈金光；战字疾冲入王林眉心。
- **战星野遗言（道统条件）**：「老夫战星野，知晓掌尊将来，欲让老夫屈服，但战某身为罗天修士，宁可道消，也不能与界外之民勾结。得我道统者，感悟战意，日后但有所成，杀界外之人为老夫祭灵。」
- 所得：滔天战意灌注心神，脑中浮现战星野与天地之斗的一路画面，以及对「战」之一字的极深感悟；**意境疯狂提升并与战意隐隐融合，出现惊人变化**。

## 五、三人围杀与全章高潮
- 感悟中空间扭曲，界外三人踏入：
  - 火焰者：贪其火焰之力，「吞了他，我就可以晋阶」；
  - 闪电者：感其雷霆之力，见其似处奇异状态，「天赐良机」；
  - 月牙者：见王林背影，遥远记忆浮现，「果然是他」（伏笔：曾见过王林）。
- 三人同时掐诀拍眉心解封：闪电者暴增至数十丈、全身闪电；火焰者生火焰双翼、头顶独角、火焰弥漫且神色痛苦狰狞；月牙者皮肤化作晶莹月色、可反衬金光。
- 临近刹那王林猛然转身，双目清明，露出**与当年界外之人嘲讽界内修士一模一样**的嘲讽目光。
- 收束：脑海中依稀传来战星野面对掌尊死前之语——「生为人杰，死亦鬼雄，我辈修士，何惜一战！」
