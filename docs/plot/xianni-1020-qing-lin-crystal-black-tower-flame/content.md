# 第八卷 联盟隐秘 第1020章 青霜？（王林以「许木」之名行事）

> 归属说明：本片段主角以自创化名「许木」行事（承第661/669/711/731/771/821/881章），所有言行归【王林】。文中「司徒」指自第336章起自称司徒南的【司徒南的断臂】所化人影（真伪未定）。

## 一、幽冥引路失控：通往魔之始祖

- **本意**：王林借「幽冥引路」之术，打开通往瓶中界的**外部通道**。
- **意外**：漩涡内魔气涌入，幽冥之路通向了**更深处**。此为王林第一次施展幽冥引路。
- **魔气之极**：王林仅感受半点便倒退数步、面色阴沉带震惊。他一生所遇魔气最浓者为当年的**散魔**，**冥海**次之；而此处魔气「至极精纯，仿若天下魔之极限，一切魔之始祖」，散魔、冥海与之相比如**萤火与皓月**。
- **神秘大殿与人影**：通道尽头有神秘大殿，宝座上坐着一人。王林只看一眼便头皮发麻、心神颤动，只听得到自己心跳加速、呼吸停顿，遂**毫不犹豫切断幽冥引路**，漩涡震动崩溃。

## 二、怨魂虚影与黄光赠晶

1. 漩涡崩溃中浮现**数十个被王林所杀之人的虚影**，怨毒尖叫、身影被扭曲拉长，欲冲出吞噬王林。
2. 宝座上的人影**缓缓抬头**，浑浊目光自迷雾透出，顺着崩溃的通道落在王林身上，**昏暗双目凝聚焦点**。
3. 焦点凝聚刹那，王林**右目青光一闪**，迅速后退并幻化出**青光盾**。
4. 人影抬起右手抛出一物，化作**一道黄光**射入漩涡：漩涡大范围崩溃瓦解，数十狰狞虚影惨叫爆开，**化作点点黑晶**消散。
5. 黄光冲出漩涡，**穿透青光盾如透明无物**，停在王林**鼻尖三寸外**。漩涡消散，黑塔恢复平静。

### 结晶与王林的推断

- 王林冷汗直流，看清黄光内是一枚**菱形结晶**；沉默许久后虚空一抓，结晶落入手心。
- 推断一：「幽冥引路我没有施展出错，而是**被人以大神通之术干扰**，从而脱离掌控，打开了一条不知通向何处的通道。」
- 推断二：干扰者应即大殿中的神秘人影，其笼罩黑暗看不清相貌，**这么做显然就是为了送出这个结晶**。
- 悬念：「那神秘人影，是否就是**青霖**？」「此人把这结晶送给我，到底有什么目的？」
- 处置：**不散神识查探**，将结晶放在一旁，自己退后盘膝吐纳。（后文再度确认：修为未达巅峰前不能随意探查该黄色晶体，也不能从黑塔离去。）
- 感慨：仙帝洞府内太过玄妙，很多事只能猜测，无法知晓真正答案。

## 三、伤势与仙力补充

**黑沙荒漠一战后的状态**：肉身有伤患、全身血液流逝大半、仍有眩晕之感；体内**元力所剩不多**，**仙力也几乎耗尽**。王林自评此战凶险程度「在我这一生中，也绝不多见」，对冥海所施展的**梵天之术**犹有余悸。

- 「当年**清水师兄**所赠的仙力，在这黑沙荒漠中消耗了太多，需要尽快补充。」
- 取出**当年玄宝上人的元神**——一团乳白色荧光，内有极为精纯的仙力缭绕；放于鼻间深吸，两道仙气自荧光团飘出，顺鼻孔钻入体内。
- **数日后**仙力恢复并略有增加。王林明白：**体内仙力不能留有太多，需保持在一定程度**，否则很可能引起**意境的消散**。
- **古神肉身**恢复能力极强，短短几天伤患尽消、眩晕不再出现。

## 四、元力困局：火中取粟

- 外界补元力对王林本非难事（打坐吐纳吸收天地元力即可），但黑沙荒漠中**天地元力本就不多，且仅有的部分全被塔外无尽火焰弥漫、与火焰融合**。
- 数日打坐，元力增长极为缓慢，吸收「不亚于火中取粟」。
- 打坐时神识曾散开缭绕整个黑塔，**未发现任何端倪**。
- 塔外景象：火焰始终燃烧、噼里啪啦作响；天空那面**白色的镜面**被火海升起的浓浓黑烟笼罩，黑压压如黑云涌动。热浪使视线扭曲，看不清太远。
- 王林在塔中暗叹：「也不知**司徒**等人现在如何。」

## 五、取火：踏出黑塔一步

1. 默默计算片刻后，王林咬牙迈出黑塔一步，身子下沉落地。
2. 双脚触地刹那，前方火焰仿若有所察觉，齐齐云涌而来直奔吞噬。
3. 王林抬右手**虚空一抓**，分离出**一丝火焰**握于手中，同时迅速后退踏入黑塔。
4. 火焰弥漫而来将整个黑塔吞没，许久后方如潮水般退去。
5. 结果：右手掌中一个**黄豆大小的火苗**，散发浓浓高温；王林右手出现干裂，面色苍白。

## 六、吞火与脱去古神皮甲（本章收束）

- **抉择**：盯着火苗，王林双目起了血丝，内心挣扎徘徊。半柱香后果断决定：「这火焰虽说危险，但其数量毕竟不多，我取之前也经过了一些计算，想必不会出现差错……索性一试。」
- **准备**：一拍身体令**储物袋**飞落塔内远处角落，并打出一些**禁制**落于其上。
- **吞服**：深吸口气，双指捏住豆大火苗，一口吞下。
- **反应**：高温自体内爆发，全身通红；痛苦咆哮化作音爆传出黑塔；大量火焰自汗毛孔冲出，**衣衫立刻燃成灰烬**，火焰向外扩张至**三丈内**；汗水刚泌出即化作白气缭绕。如同吞下火炭。
- **元神保护**：元神有**古神皮甲**护住，并未受伤；但体内不多的元力在火苗融入下化为一体，仿佛在体内燃烧。
- **关键推断**：「只有融入了元神，才可以真正的吸收其内蕴含的天地元力。」
- **最终动作**：双手掐诀在胸前一点，**元神之上的古神皮甲化作乌光脱离，从王林口中飞出**；失去皮甲后，融合了火苗的元力**涌入元神之中**——章节至此断在悬念处。
