# 第1294章 道术

## 一、两掌镇服九幽龙

九幽龙低吼屈从，因在王林身上感受到三股令其颤抖的气息：

1. **太古神灵之力** —— 来自其记忆传承中的神灵气息。
2. **魂魄克制之力** —— 王林之魂对它有生生克制且可吞噬之能。
3. **吉穷之气** —— 兽中之皇吉穷的气息，最令其恐惧。

再加上王林修为所化两掌蕴含惊天之力，九幽龙无从抵抗，遂屈服成为王林坐骑。

> 九幽龙虽非成年体，却是**天阶兽吉穷的伴生兽之一**。

### 外界反应

- 裂缝外数千修士目瞪口呆，此幕震撼更胜此前王林毁灭凶兽与骷髅。
- 三名被蓝色雾气弥漫的妖宗之人神色大变，雾气因心神震动而扭曲，自承「三人合击秘术可战胜九幽龙，但令其屈服绝无可能，更别说成为坐骑」。
- 六大高手元神震动，王林**白衣白发、如一尊战仙**的身影在其心中成为永恒。
- 那冷漠女子暗叹：与李倩梅暗斗百年，本以为其入裂缝必死，未料竟有这样的强者为救她而来。

## 二、妖宗长老三步临境与交手

王林正欲冲入裂缝深处寻李倩梅，妖宗六颗修真星之一爆发强悍气息，一道身影呼啸而至：

- **第一步**：在无法挪移的星空中挪移而出，踏在星空中；
- **第二步**：闪烁间出现在三个妖宗之人身边；
- **第三步**：几乎不见身影，直入裂缝内王林前方。

其温和之声震动裂缝内外：「道友莫急，既来此地，便让老夫看看是否有进入裂缝深处的资格」，随即抬右手向王林按下。

### 交手经过

| 回合 | 王林 | 妖宗长老 |
|---|---|---|
| 对掌 | 抬右手隔空一拍 | 右手按下 |
| 结果 | 闷哼，体内砰砰作响，连人带九幽龙退数丈 | 闷哼但不退，反向前再迈一步 |
| 古神拳 | 一跃而起，眉心弥漫**古神星点**，古神之力融入右拳轰出 | 身子一顿，向后退去 |
| 血剑斩 | 右手一挥血光弥漫，眉心飞出一滴鲜血化作**赤光血剑**，追击斩下 | 面色大变，掐诀喷出**龟甲**格挡 |
| 结果 | 血剑劈碎龟甲，血光穿透落入其体内 | 踉跄、嘴角溢血、再退 |
| 役灵印 | —— | 喝「**辰、皇、斗、仙、轰——役灵印现**」，五道符文交错成实质巨掌直取王林额头 |
| 身化血剑 | 双眼红芒一闪，血剑融入体内，**其人即血剑**；右手双指为剑尖，千万剑气化作剑之风暴撞上掌印，趁掌印停顿以双指点在掌心 | 掌印崩溃，天地元力暴虐四散 |
| 收束 | 一步迈出，双指点在其额头 | 震动喷血，疾退出裂缝 |

对掌余波卷退裂缝外数千修士，六大高手齐退面色苍白，唯三名妖宗之人不动。

### 求和

王林追出，左手按在眉心**似要撕开身上封印**。长老见状立即高呼「道友停手，此事老夫鲁莽」，退至三名妖宗之人身前，现出白发苍苍老者之形抱拳；三人恭敬称「参见长老」。老者坦承「道友修为极强，老夫自问不如」，尤对血剑法宝震骇难以形容。

## 三、玉简换道术

- 老者自陈：**当年怜才，曾欲收李倩梅为门下；李倩梅离去亦是他同意的**。
- 赠出一枚玉简，内含裂缝地图及其亲手标示，循标示以王林之速「或可追上」李倩梅。
- 王林神识一扫，面色阴冷略缓，沉声告诫：
  > 「回去闭关三日，莫要动用道念，心神归一。在第三日最后五个时辰，你道念会崩，谨慎承受，度过便无碍。」
- 王林转身踏入裂缝，踩在早已吓破心神、不敢逃遁的九幽龙背上，驶向裂缝深处一片漆黑之地。

### 老者的后怕

凝神自查后面色苍白：其**道念中的心神意境出现异变，似有一股外来之力轰入，使道念缓缓衰弱**——「这是**道术**」。

其内心庆幸：若非自己心存善念送出玉简，对方绝不会告知；否则即便发现道念受损而疗伤，第三日最后五个时辰措手不及，不死也会重伤。

结论三点：
1. 「此人或许真能救下李倩梅」；
2. 「以我**天人第二衰**的修为，与他对敌也没把握取胜，更暗中被此人所伤」；
3. 「最可怕的是**此人身上还有封印**，若是方才被他撕开封印……」

老者深看裂缝一眼，远遁回修真星山门，立刻闭关。

## 四、要点提炼

- 王林战力再上新阶：**古神之力 + 血剑 + 身化血剑剑指 + 道术**多层手段，且身上尚有未解封印。
- **道术**首次以「无形侵蚀道念、延时崩坏」的形态展现，杀人于三日之后而不见形迹。
- 九幽龙由敌转为坐骑，成为王林深入裂缝的载具。
- 妖宗长老由拦阻者转为示好者，提供李倩梅方位地图，为下一步救人铺路。

> 归属提示：本章王林在云海星域以化名「**吕子浩**」立足（自第1063章由吕烟菲奉上），本章未直接点名；李倩梅已于第1202章「死亡」记录在案，本章为王林入裂缝寻其踪迹之情节，众人仍以其在裂缝内为前提行事。
