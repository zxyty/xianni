# 第1948章 东临池

## 一、梦道苏醒：被篡改的记忆

- 王林猛然睁眼，目内血丝密布、衣衫被汗浸透、面色苍白，全身弥漫极度虚弱之感，呼吸受阻如同凡人，许久才抬起右手确认自己无碍。
- 刘金彪如实禀报：王林闭目的瞬间「似整个人不存在了一样」，他回头去看的一瞬王林就醒了——前后只有**一瞬间**。
- 王林一愣：他多次经历梦道，每次都会沉浸其中一段时间，绝不可能只有一瞬。
- 梦道所见：一道**模糊的虚影**，样貌与身体轮廓皆看不清，事后仔细回想反而更模糊，似自己记错了一般。这种「记忆被篡改」的感觉让王林心神一震。
- 王林之问：「若梦道所看是真实发生，那么他是谁？」
- 剧痛与濒死：结合梦道中的剧痛与苏醒后的无力虚弱，王林隐隐觉得那一瞬有种要死亡的错觉，且这种死亡**连三命之术都无法帮助**，若真死则是彻底死去。
- 王林望向东临宗，眼中露出精光：「总有一天，我会知晓，这里面到底蕴藏了什么隐秘。」

## 二、东临池的规则（东临宗老祖所言）

- 东临池与**大圣洲封印的天外修士之魂**有关。
- 在池中有一定机会**感悟出那天外修士特殊的本源**。
- 池水内感悟**只有两次机会，第三次必定暴毙而亡**。
- 王林的疑问：为何第三次会死？若能弄清此点，或可多感悟几次。

## 三、王林前三次感悟

| 次序 | 时长 | 结果 |
| --- | --- | --- |
| 第一次 | 三息 | 一无所获；仅体内诸多本源各增加一丝；池水少了近三成 |
| 第二次 | 五息 | **左目**看到一缕微弱的光，右目一片模糊；未及摸索到便被弹出；池水只剩不到三成 |
| 第三次 | —— | 池水之力化作排斥，凝成咆哮「连云决，你卑鄙」，无法沉浸感悟，被金尊海龙抓出 |

- 入池方式：踏入池中盘膝而坐，池水淹至腰部、透着阵阵冰冷；吐纳运转修为，与池水融为一体。
- 进入的状态类似当年创出**残夜神通**时的氛围，只是借池水中的奇异之力被强行瞬间推入。
- 该状态下神智不清、眼前模糊；可感受到一股奇异之力自外界传入体内，却抓不住痕迹。
- **左目见光、右目不见**的诡异分化，是本章的核心异象。
- 护法安排：王林放出**金尊海龙**（身形缩小、盘旋天空、神色高傲，恶狠狠盯着刘金彪），以神念嘱其见势不妙立刻救人；第三次危机时正是海龙以巨大爪子将其挪出。
- 池水机制：王林离池后，池内水位慢慢冒出、恢复如初，先前的消耗全部还原。

## 四、王林的推演

- 为何唯独第三次遭排斥？那声音是池水之力进入体内凝聚后所生；此力**先在体内流转一圈**，重点或在于此——这一圈是在检查进入此地的次数。
- 关键问题：它凭什么判断具体感悟的次数？
- 「连云决」姓连——**莫非是连道非的老祖、当年的仙祖之名**？（推测，未证实）

## 五、刘金彪入池与「太初本源」

- 王林命刘金彪下池试探，并预先告知自己遇到的危机，自信可护其第三次也安全。
- 第一次：四息，茫然睁眼，「我看到了一缕光」。
- 第二次：五息，睁眼刹那**左目有一缕明亮的光一闪而过**；自评「距离那光很近很近，但却还没有摸索到」。
- 第三次：坚持到十息后身子剧烈颤抖，王林不假思索抬手将其挪出；睁眼时**左目光芒万丈**，王林看一眼如同直视太阳。
- 收获：刘金彪触摸到那缕光，心神内有声音告知其名——**太初本源，一切万物之始**；但因修为不够，仅感悟一点便承受不住。
- 方法揭示：刘金彪认为自己能撑住第三次是靠**骗道**——瞬间欺骗自己「这是我第一次进来」，以此同时骗过池水的探查；并称自己**转世苏醒后，骗道也可以帮人施展**，主动提议为王林施展。

## 六、王林第四次入池

- 王林沉吟后摇头拒绝：他对骗道本有所了解，更在**梦道中有所感受**，既已知晓方法，凭修心的感悟即可自行施展，无需刘金彪帮助。
- 第四次沉浸：在池中奇异之力传入的瞬间骗过其检查，重入那种奇异状态。
- 左目中的光**越来越近**。
- 心神内渐渐浮现一个低沉的、喃喃自语般的声音：
  > 「杜某行走苍穹之间，观亿万初阳变化，明悟太初本源。」
- 该「杜某」当为东临池所系之天外修士（大圣洲被封印之魂）的自述，身份本章未明。

## 七、悬念

1. 梦道中那道模糊虚影是谁？为何王林记忆似被篡改、且沉浸时间被压缩为「一瞬」？
2. 「连云决」是何人？是否即连道非的老祖、当年的仙祖？他对咆哮者做了何等「卑鄙」之事？
3. 「杜某」与太初本源的完整传承，以及东临宗深藏的隐秘。
