# 第九卷 云海之巅 第1322章 门徒香火

## 一、异变：封仙印 × 呼风唤雨界

千丈界收缩消散、融入王林体内。王林怔立星空良久，神色古怪且难以置信，遂返回修真星山峰盘膝而坐。

半柱香后闭目内视，见元神之上漂浮一个**漩涡小球**，其内即是**呼风唤雨界**：

- 体外仅千丈大小，体内却无边无际，恍如一个世界，众多大陆漂浮其中；
- 这些大陆，**均为封仙印崩溃所化**；
- 大陆上一个个**战魂**不再凄厉嚎叫，而是盘膝而坐，头顶散出**乳白色气息**；
- 气息飘向上空被此界吸收，同时融入王林心神，**直奔其五道本源**；
- 王林**五道本源**在此气息环绕中枯木逢春，焕发磅礴生机。

## 二、认定：这就是「门徒香火」

王林之所以震撼剧烈，正因他认得这股气息。此前三次线索：

1. **妖灵之地**：其古妖分身所化雕像，受**十三等一族**不断膜拜，亦生此气息；
2. **云海星域水道子一战**：水道子最后施展的神通，所吸取的正是此气息；
3. **封界之主的交谈 + 蓝梦道尊的点化**：均指向让本源大成、成为**第三步大能**的关键——**门徒香火**。

王林仍不懂门徒香火究竟是什么、如何诞生，无意中的融合反而令他更为迷茫。这些战魂全是他**一生所杀**之人，如今却成了为他提供香火之人——既是造化，也是**封界之主的遗泽**，更是几乎不可再现的异变（连蓝梦道尊也料不到会在其所传「道之融合」下出现此变）。

## 三、成因链（本章交代的因果）

1. **封仙印由雷界大陆炼化而成**。雷界为四大仙界之一，无数年前**封界之主**设之，本意是阻止**封界大阵**吸收香火、让界内之人也能诞生香火。
2. 四大仙界虽终被毁，但**仙界内的大陆是天地间诞生香火的最好材料**。
3. 当年**天劫**之下，仙界碎片经天劫炼化，「就好像天道为王林炼宝」，把大陆碎片生生炼成一件至宝，其内诞生香火之种种被**重新祭炼**一次。
4. 王林无意中将此物用作**撒豆成兵**，其内自成生死、化作**十八地狱**，吸纳其一生所杀之魂，令其**不入轮回**、禁锢其中；日久天长渐被诞生香火之力弥漫。
5. 但若无契机开启，这一切也会慢慢消散，战魂不会散出半点香火之力。
6. **契机**＝蓝梦道尊助王林把呼风唤雨**融合成一界**（如无根之萍找到根）＋ 王林尝试把**撒豆成兵封仙印与此界融合** → 异变发生。

## 四、评估与取舍

- 眼下界内战魂不多、香火之力**很微弱**，比之**水道子二十亿门徒**相差太多太多；
- 但这是**真正的香火**，是成为第三步的关键，更是第三步修士疯狂争抢的**道宝**；
- 王林不再深想：**来自蓝丝族之外白衣女子的危机**尚未度过，纵有此宝，不解此危亦无用。

## 五、古神指骨：吞噬未果

王林右手虚空一抓，身前现**储物裂缝**，取出一块**巨大古神指骨**，飘在半空如同一块大陆。

- 古神**整只**指骨堪比一颗**修真星**；眼下虽只半个，威严依旧浓郁；
- 指骨内古神气息极重、几近实质，却**无法吸收**——气息内依稀有**一道意志**存在，不容他人吞噬；
- 王林眉心**古神星点**幻化旋转试图吸收，**最终失败**。

王林由此评断**拓森**：以星点吞噬指骨之术极强，其更可**吞第三步大能**壮大自身星点之力；但指骨内蕴含意志，拓森想吞也定然极为艰难。

## 六、章末：另辟蹊径

「而且，我并非没有办法吸收。」王林再抓空间裂缝，其内幽光一闪——**昆极鞭**卷着**月噬族白发老者的元神**直接飞出，落在他身前。（悬念收尾）

## 关键悬念/伏笔

- 门徒香火的诞生机理仍未明，王林手握微弱但真实的香火来源；
- 白衣女子（蓝丝族外）之危未解；
- 拟以月噬族白发老者元神为手段，另寻吸收古神指骨之法。

# 第1237章 血剑削魂·搜神取秘

> 归属提示：本章主角以化名『吕子浩』行世（自第1063章由吕烟菲奉上），文中言行归属【王林】。

## 一、擒获：元神落网的前因
- 月噬族白发老者元神紧闭，眉心月牙印记闪烁微弱月光，正与昆极鞭对抗。
- 老者修为极高，与当年从雨界脱困的青龙圣皇相当，隐隐达到**天人第四衰**；王林自忖单独遇上绝非其对手。
- 但老者在**拓森**的强悍攻击下明显不如，先被拓森重伤，又在**古神指骨**崩溃刹那被其内爆发的古神之力重创，**肉身消散**，元神亦受重创——这才给了王林抓捕的机会。
- 老者元神已**化作实质**，堪比肉身；若非**昆极鞭**诡异、专对元神魂体有致命一击，王林同样无法将其封印。
- 王林起意：“这古神指骨既然被月噬族拥有，想必他们定有一些方法，可以利用。”

## 二、拷问：昆极鞭 + 血剑的削魂之法
- 王林掐诀一指，昆极鞭瞬息收缩、散发暗金之光，老者元神颤抖痛苦。
- 老者冷笑：“区区六星古神，早年我月噬族杀了不少……老夫元神已然实质，不死不灭。”遂闭目欲运转元力，然一切皆被昆极鞭封印。
- 王林不答，挥手唤出**血剑**：
  - 血剑穿透元神，老者凄厉惨叫；一挑豁开，大量**元神精气**宣泄，被王林一吸吞入体内。
  - 王林冷声：“我无法杀你？奴族之人，也敢狂妄。”反复挥斩，老者惊问“这是什么剑”，王林神色冷漠、不予作答。
- 关键点：王林**并不杀他，而是不断削弱**。昆极鞭下元神无法恢复，连**自爆都做不到**，只能眼睁睁看着元神精气流逝。
- 数个时辰后，老者虚弱至极限，元力大范围流逝、伤口弥漫全身；血剑蕴含**吸力**，每次划过都吸走大量生机。

## 三、搜神与抹杀
- 王林收起血剑，右手按在老者元神之上，神识轰出，展开**搜神术**。
- 老者疯狂抵抗之际，王林左手挥出血剑再度穿透其元神，抵抗之力崩溃，双眼呆滞，全身渐渐透明。
- 许久之后王林抬手，神色**极为凝重**；老者元神消散刹那，血光一闪，血剑自其**天灵**落下贯穿全身，将其彻底毁灭。
- 其死亡刹那，王林体内**呼风唤雨界**一处大陆之上，此老者魂魄幻化盘膝而坐，头顶散发惊人的乳白气息。

## 四、搜神所得情报（本章核心收获）
1. **月噬族极为庞大**：王林与拓森所灭仅是**一个部落**；在**太古星辰**上，月噬族**还有三个部落**。
2. **正东方部落**中有一位月噬族**老祖宗**，为**第三步大能**。
3. **掌尊**：老者此生竟未见过掌尊，只知掌尊早年似乎**界内一行重伤逃回**，一直在某处**神秘之地闭关疗伤**。
4. **交叉印证**：结合**蓝梦道尊**的话语（掌尊被界内某个存在**一吼之力**便仓惶而逃），王林判定“掌尊重伤闭关”可信；**唯一未知**是其伤势到底恢复了多少。

## 五、章末动向
- 王林眼中寒光一闪，抬头看向天空：“该离开了……那白衣女子想必还在外面等待。”
