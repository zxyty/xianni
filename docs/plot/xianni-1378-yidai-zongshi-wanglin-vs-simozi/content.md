# 第九卷 云海之巅 第1378章 一代宗师

## 一、司墨子锁定王林

- 司墨子在大殿中神色骤变，目光穿透天地屏障，直接看到修真星中部山峰顶上傲然而立、目光投来的王林。
- 其评价：「小看了此人的心智，但在绝对的修为之下，一切都无用。」冷笑中一步迈出，消失无影，亲赴战场。

## 二、龙甲族父子的算计

大殿内只余龙甲族父子：

- **少族的顾虑**：那修士修为高深、绝非等闲，眼下躲避在颠落之地，这么做是否欠妥。
- **族长（落生会第九长老）的判断**：此人极可能就是——毁灭闪雷族、杀了闪雷族大长老、镇压数万修士而逃、被长尊会发出**太古星辰令**通缉之人。
- **选边理由**：若非如此，第三步大能司墨子不会突然来此；相比之下，毁灭闪雷族之人毕竟不是第三步大能，因此只能帮司墨子。
- **对「万一」的回应**：即便司墨子不成，王林也必身受重伤，逃遁疗伤尚且不及，无暇报复；何况自己代表落生会，「他，不敢的」。族长神色傲然，甩袖离去。

## 三、王林的心境与前尘（叙述者视角总结）

> 每临大事有静气。

- 白衫迎风、背手望天，与天地相融，已具**一代宗师**风范；平静容颜下藏着一股逆天的风暴与滔天杀机。
- 修道两千年，从往昔弱冠童子成长到站在修真界巅峰，敢挑战第三步大能——尽管此番来者只是**分身**，仅**天人第五衰**修为。
- 生平作注：
  - 天道下抢李慕婉之命，凶险中博一线生机；
  - 拥有凝聚**香火之界**的条件却放弃借外力攀升，只凭自身**五道本源**引动**空之大门**，走古往今来罕有人踏的证道之路；
  - 带领七百万天地之民冲破天地、回归星空；
  - 杀闪雷族大长老，以低弱修为屠天；
  - 凭一己之力来到太古星辰，只为送李倩梅；
  - 搅乱太古星辰、被整个太古追杀——「即便是当年的青霖，也要自叹不如」。
- 志向：不求留万古之名，但求一生无愧于心；不求磊落万年，但求一生无悔。

## 四、剑气凝指

- 天地之中剑气呼啸，**只差一道就足有四千万**，遮蔽天空、驱散云层，已分不清是天地中有剑气，还是剑气中含天地。
- 王林右手抬起一指，近四千万道剑气如遇漩涡般齐齐涌入其右手**食指**——一指落下，即四千万剑气同时攻击。

## 五、正面交锋：山崩之术 vs 天地漩涡

### 司墨子的攻势

- 一道连接天地的龙卷漩涡拔地而起，司墨子在风暴之中临近，喝道「敢主动挑战老夫司墨子，你胆子很大」，仿佛将天地吸摄化作漩涡，以天地之力施展神通。
- 王林回以「废话不少」。

### 王林的山崩九崩

1. **「山崩」**：四周天地涌现一座座虚幻火山；以王林当下修为施展，威力**超过当年受伤未愈的清水（清水仙君）**。
2. **「山，第一崩」**：火山爆出滚滚黑烟遮天弥漫，与漩涡风暴正面碰撞，整颗修真星轰然颤抖。
3. **「山，第二崩、第三崩」**：高温热浪与通红岩浆卷向漩涡；天空空间撕裂，大地裂出极深沟壑。
4. **「山，第四崩、第五崩」**：大量火焰重叠合为一座真正的火山，展开毁灭性爆发。

### 关键转折：抽星之山魂

- 王林判断此术**「虽极真却无魂」**，只是神通凝聚而出。
- 他一跃而起，右手向下方大地狠狠一抓，低喝：「山崩之术既然无魂，我便赐予此术之魂——抽这修真星，所有山脉之魂！」
- 整颗修真星通体震动，一座座山峰因脊梁（山魂）被抽走而崩溃成碎石；此后**全星再无一座真正的山峰，只余石头堆积**。
- 山魂与虚幻火山融合，火山自此有了极为浑厚之魂——**山崩之术至此彻底圆满大成**。

### 「山，第九崩」

- 越过前几崩直接施展最后一崩：山石、岩浆、黑烟、山魂融合成一道绝天地而出的山崩风暴，与司墨子的漩涡风暴展开最终碰撞。
- 毁灭性冲击爆发：王林衣衫狂舞、面色苍白，却不退反进，向前一步直奔司墨子；司墨子面色同样苍白，化作长虹冲出。

## 六、破天道现世与身份悬念

- 司墨子认出：「山崩之术，这是**白凡神通**！」
- 随即施展神通：
  - **「天为画」**——天空扭曲、多彩尽消，化为纯白之画，其上无尽虚影勾勒山水；
  - **「地为墨」**——大地扭曲漆黑如墨；
  - **「我为笔，一笔破天，成我破天道」**——右手化笔，挥舞间天地改变、如同自成一界。
- 王林瞳孔骤缩：他曾与**李倩梅**论道谈及神通之术，又获得**司马墨的玉简**，并去过**七彩界内司马墨的洞府**，因而知晓——
  - **破天道**是**破天宗**神通，**唯有历代宗主与大弟子才可修行**，威力无穷。
- 由此心生疑问：「司墨子，他莫非是……」（本章至此戛然而止，身份悬念留待下章）
