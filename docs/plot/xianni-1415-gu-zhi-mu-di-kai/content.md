# 第1415章 古之墓地……开！（第九卷 云海之巅·第四更）

## 一、虚火觉醒：王林睁眼

- 王林双目睁开的刹那，**左目内九色火焰成虚、急速旋转**，样貌极为诡异；一股**虚幻之火**自体内轰然爆发，向四面八方涌出。
- 王林发丝无风自动、衣衫舞动，缓缓收回按在**第一根香**上的手，转身环视四周。
- 老朱雀长笑，神色欣慰又震惊，评曰：「**轮回业障化九色，燃四次觉醒之炎，化实火入虚境**，好，好！」——继五道本源之事后，王林再一次给了他惊喜。

## 二、在场各方反应

| 人物 | 反应 |
| --- | --- |
| 云落大司 | 看清王林左眼九色旋转，瞳孔收缩、恐惧滔天，身子颤抖不断后退，面白如死人。她永远忘不掉此前画面中自己死亡一瞬，那模糊背影转身看向自己的目光——**其左眼正是九色旋转** |
| 司墨子 | 死死盯着王林，沉默不语 |
| 妙音道尊 | 目中闪过奇异之芒，嘴角露出微不可查的**冷笑** |
| 老朱雀 | 长笑、欣慰、震惊 |
| 兽皮老者（盘膝坐于蜥兽上） | 与老朱雀交战多次，深知虚火之力强大，见王林踏入虚火之境，开始**留意**其人 |
| 蓝梦道尊身后的女子（月儿） | 默默望着王林 |
| 蓝梦道尊 | 见那女子神情，暗叹，**第一次对当年之事生出悔意**：「若我当年，没有抹去月儿的记忆，而是把这王林留下，全力助其修炼，并非只传三式神通……」 |

- 王林扫视众人，在**每个人身上都看到一丝丝流转的情绪**——若他愿意，即可让这情绪化作虚火。看向云落大司时，对方立刻低头后退，而其体内情绪**比旁人浓郁无数倍**。

## 三、炎龙获释

- 王林向老朱雀抱拳：「晚辈幸不辱命，已然觉醒。」
- 老朱雀右手一挥，将手中抓着的**炎龙**抛向远处：「你这小龙自由了！」
- 炎龙已奄奄一息、**全身血液大都被释放出来**，闻言双目冒光，挣扎急速飞出，消失天边。冲出**大帝星**后咆哮激动、眼中弥漫水汽：「自由了，终于自由了……老龙我终于从魔掌内解脱……」
- **叙事者补白（炎龙不知情）**：它当年被**一代朱雀**骗了之后，又被**二代朱雀**直接送人。

## 四、天方香与试炼的最后一关

老朱雀以只有王林能听到的方式传音：

- 试炼尚未结束，**最后一根天方香内有人在等你**。
- **人方香会灭，地方香会断，唯天方香绝不会熄与断**——此香由朱雀族**一代老祖（颠落大帝）亲自把守**。
- 考验内容是**潜力**：维持时间越长，潜力越大。
  - 老朱雀当年：**十二息**
  - 四代朱雀：**十四息**
- **约定**：若王林能再给一次惊喜，老朱雀便把**炎龙体内的禁制方法**相送；凭此禁制，炎龙逃出颠落之地后王林可轻松寻到它，有此龙守护，王林离开这里老朱雀也就放心了。

## 五、王林登香前的四问（未解疑团）

1. 一代朱雀老祖乃朱雀一族之祖、**远古仙尊麾下四大战将**之一，此等人物怕是知晓太多隐秘。
2. **朱雀族既在太古星辰，为何还有火雀族存在？**
3. 朱雀一族既延续至今，**青龙、玄武、白虎三族**想必也在，他们在哪里？
4. **远古仙尊**与封界之尊所说的**远古仙皇**，是否同一人？若不是，二人是什么关系？

随后王林走到最后一根天方香下，深吸口气，抬右手按上，闭目。

## 六、天方界见闻

- 天方界与人方、地方两界完全不同：**一片弥漫白云的世界**，除云之外只有一物。
- 那是一尊**极为庞大的雕像**，几乎占据小半天地：所刻为一**貌如朱雀的老者**，鼻如喙，背生朱雀之翅，双目闭合，**眉心一团九色火焰熊熊燃烧**。
- 雕像右手伸开、掌心向上，王林的身影在光芒闪烁中**出现在这手掌之上**。

## 七、太古星辰：古之墓地开

- 太古星辰一片安静星空中波纹如浪缓缓蔓延——不久前有**一道幽光**自虚无闪烁而来，一闪而过。
- 幽光到来前，此处有一颗**蛮荒星**：无任何生灵、无灵气，属废弃存在，修士临近也不会看一眼。但它恰好位于幽光路线上，幽光穿透的刹那，**蛮荒星无声无息瓦解成灰**，只余波纹荡开。
- 瓦解处露出一道**十丈大小的裂缝**，散发阵阵**死气**，向外弥漫使裂缝越来越大，**至百丈大小时停止蔓延**，静静漂浮不动，似一张森森之口等待食物到来。
- 透过裂缝可模糊看到，其内**仿若另外一界**：弥漫无数漂浮的碎石，**每一块碎石上都有一个巨大的头颅——或古神、或古魔、或古妖**。
- 它的出现，将在太古星辰掀起一场震惊无数修士的风暴——**古之墓地，开！**

## 八、看点与伏笔

- 王林的虚火之境实力被兽皮老者、妙音道尊等外部势力重新评估，妙音道尊的冷笑埋下敌意伏笔。
- 云落大司在预见画面中死于左眼九色旋转之人手中——指向王林与其未来的因果。
- 蓝梦道尊「抹去月儿记忆、只传三式神通」的悔意，回溯了王林与蓝梦道尊、月儿的旧缘。
- 天方香息数将成为王林潜力的量化标尺（对照：老朱雀12息、四代14息）。
- 古之墓地与颠落之地试炼两线并行，即将交汇。
