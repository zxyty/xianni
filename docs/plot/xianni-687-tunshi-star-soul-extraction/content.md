# 仙逆 第687章 吞噬（第七卷 名震罗天）

## 一、抽魂神通的来历与设定
- **并非初见**：王林当年在**妖灵之地**曾亲眼见**贪狼**取出一座**仙山法宝**，并从中抽出**山魂**，当时已极为震惊，认定此神通非寻常修士可掌握。
- **本章规模**：散魔操控王林身体凝化魔爪抽取**千幻星之魂**，声势比当年贪狼抽山魂**浓烈千、万倍**。
- **魂的设定**：世间一切有生命之灵皆有魂，虚无缥缈不可见但可感应。凡人立于巨峰之下抬头所感的震撼与威压，正是**山魂**所致——只见山而不见魂，故只余威压感。一山一水尚且有魂，何况一颗充满灵力的修真星。

## 二、抽星魂过程
- 与此前灵力被转化不同，抽星魂时**千幻星并未半点颤动**，却有一股浓浓**沧桑气息**如苏醒般弥漫开来。
- 该气息非百年、千年、万年可成，是无数悠悠岁月酝酿而出的**无喜无悲**之气，其中只有一种**包容天地一切**的意味。
- 散魔控王林右手向下抓取，气息疯狂凝聚于手心，化作一团**灰色雾气**，随沧桑气息不断融入而剧烈压缩，内传砰砰之声如雷鸣。
- 王林（或为错觉）感到千幻星**失去生机**：大地青草瞬间枯萎、河流消散、山峰龟裂。

## 三、正面对轰
- 散魔桀笑中右手一抓，携千幻星之魂**其速如电**直奔**仙人虚影**。
- 此刻王林感觉自身与千幻星魂**融为一体**，这一击并非自身之力，而是**以整个千幻星的力量**进攻。
- 仙人虚影向前一踏，将手心之上**以整个千幻星灵力转化而成的仙力**一挥而出迎击。
- **碰撞结果**：
  - 剧烈声响回荡天地，**千幻星内灵脉刹那枯萎十之三四**；
  - 大地晃动，强烈气浪于天空咆哮般四散；
  - 四周**幻家族人纷纷退后**，急运体内灵力、仙力护体，否则身子将立刻崩溃。

## 四、仙人虚影崩溃与福泽玉简的最后一层保险
- 仙人虚影蓦然崩溃，化作阵阵烟丝消散；全部消散一刻**凝化出一枚玉简**。
- 玉简甫一出现即传出咔咔之声，当着所有幻家族人的面**碎裂成灰尘消散**。
- 碎裂瞬间一道白光闪出，化成**光幕笼罩方圆十里**。
- **幻家祖训**记载：福泽玉简碎裂后其内尚有一道**防御神通**，威力较弱，价值仅在于给危机中的幻家族人一个**短暂喘息**——或投降、或自绝、或留下后事之用。
- 幻家老祖见此**面色苍白**。
- 散魔右手轻颤，千幻星之魂消失，沧桑气息重新融入大地，渐渐不再。

## 五、真正的赢家：王林的第二步缺口
- 此战**最大受益者是王林**。此种层面的神通之战完全超脱他所在层次，以其修为本不可能经历。
- 仙人虚影与散魔之魂**均拥有踏入第二步的强大实力**，这一战好似为王林打开了一道原本紧闭之门的**缺口**，让他看到并亲身感受另一个层次的力量。
- 王林心神撼动的判断：
  > “这，便是修道第二步的实力么？与这相比，贪狼、幻家老祖、千葵子虽说也踏入第二步，但很显然，他们只是刚刚摸索进来而已。修道第二步，太可怕。”
- **借体运功之利**：散魔自始至终只用了一式神通，但该神通是**通过王林的身体运转**的。外人眼中隐秘之处，在王林看来清晰无比，包括：
  - 体内**仙力的走势**；
  - 抽魂时那种**号令天地**的气息。
- 这一切为王林**通向第二步打开了一个巨大的缺口**。

# 散魔破幕逼交柳眉，幻家老祖欲吞噬柳眉

## 一、王林的震撼与「修道第二步」之渴

- 目睹散魔（占据王林肉身者）与同等级大神通修士的一场全力之战后，王林**从未如现在这般渴望踏入第二步**。
- 王林的判断：
  - 与第二步神通相比，**自己的仙卫傀儡也不堪一击**。
  - 第二步**每一战可使一个修真星彻底崩溃**。
  - 这几乎已接近**当初传承古神时所见的那一幕幕神通的层次**。
- 机缘之稀有：世间几乎没有踏入第二步、修为相当于凌天候的大神通修士，会**降临在别人身上**与同级之人全力一战；若真要战，多是亲自前来。
- 幻家族人观战亦各有所悟、如开一片天地，但相较王林所获，微不足道。

## 二、光幕将破：幻家的困局

- 散魔操控王林肉身，低头看向仙力光幕，轻哼一声，右手握拳虚空一击——随意一击便有**破空奔雷之威**，更带浓浓魔气。
- 第一击：光幕出现裂纹但未崩溃；第二击：裂缝更多，眼看彻底崩溃，散魔桀傲笑声已传入幕内。
- **幻封神**（与老祖分裂者）劝谏：「老祖，把柳眉交出去吧。」其判断——对方虽只是**问鼎修士**，但法宝与神通强得无法想象，尤其此魔出现后，即便老祖修为未下降也难敌。
- 外援尽失：**千家不助**；**许家明明答应却迟迟未现**，显然生出变故。眼下一切只能靠幻家老祖自己。

## 三、设定揭秘：无相天魔道 / 天魔道 / 无相道

- 幻家那位**仙人祖先**留下两套意境神通：**天魔道**与**无相道**。
- 两者实为从同一道意境中分离而出，那一道本源意境即 **无相天魔道**。
- 来历：幻家先祖在**仙界未崩溃之前**的一次冥想中，与**域外天魔**纠缠，最终结合自身感悟顿化而出。因**仙人不修意境**，这道感悟便被留下赠予后人。
- 传承现状：仙界崩溃、失去庇护后，幻家后人凭**无相天魔道**牢牢站稳脚步；但**天魔道修炼太过艰难**，时至今日幻家族人**无人真正练成**，盛名不在。

## 四、幻无情的算计

1. 柳眉略微显露出一丝**万幻天魔道**意境 → 幻无情因此动了收徒之念。
2. 为便于**日后吞噬**，不惜**降低自身修为**为柳眉**换血**。
3. **催发其修为**，使柳眉修为虽不算止步，但**最高只能达到阴阳虚实**——如此牢牢掌控，日后吞噬不生麻烦。
4. 原定时机：待柳眉修为至阴阳虚实、意境经冲击**蜕变为真正的天魔道**时，再吞噬融合，修炼幻家真正的神通意境**无相天魔**。
5. **计划被王林的突然出现彻底打断**。权衡之下，幻无情决定：与其交出柳眉，**不如趁现在吞噬**，多少可得一丝无相天魔意境，日后勤加感悟，说不定也有成就大道之日。

- 逼迫之言：「柳眉，你出去也是必死，不如把你意境给老夫，成就老夫**无相天魔道**，如此，或许老夫真有一拼之力。」说罢盯着柳眉双目，露出奇异之芒。

## 五、柳眉的清醒与反制

- 老祖犹豫开口时，柳眉先行截断：「师尊，柳眉走出，**必死无疑**。」
- 柳眉的洞察时间线：
  - **联盟星域时**便看出端倪——世间除至亲外无平白无故的好，若有必是某种目的所使；因幻无情强大无法抵抗，只能**装作不知**，被带到**罗天星域**并接受换血。
  - **幻无情自损修为助她达到问鼎大圆满时**，心中已然全部确定其深深图谋。
  - 她曾为**朱雀子弟子**，深知修为如此**拔苗助长**式提升的危害。
- 结局悬置：柳眉目光平静，轻声道——「**你要答应我两件事情**」。（条件内容本片段未揭示）
