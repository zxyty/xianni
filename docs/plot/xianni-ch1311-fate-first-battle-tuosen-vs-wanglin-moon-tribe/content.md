# 第九卷 云海之巅 第1311章 宿命第一战

## 一、拓森 vs 三名第三步大能（十年追杀的了结）

- **对手构成**：自星空裂缝冲出的三名太古星辰第三步大能——一名**空灵境界**老者，另一男（**司墨子**）一女均为**空涅初期**。
- **战术僵局**：三人十年来始终不分开、彼此策应，拓森无从各个击破。三人各自一拍眉心，爆发三道妖异流光正面硬撼拓森一拳，星空被撕裂、几乎一分为二——「第三步大能之战，可以崩溃星河」。
- **拓森的疯狂抉择**：为尽快摆脱纠缠去追王林，拓森自曝「本神一生击杀数个第三步大能」，随即喝令「碎星」，引爆眉心一颗古神星点。

### 碎星的代价与战果
- 古神之星爆开，掀起以此地为中心的漩涡风暴，横扫万里→十万里→百万里→**千万里**星空。
- 范围内**无数修真星、无数修士与生灵灰飞烟灭**；小半个太古星辰都感受到震动，余波如海浪推涌。
- 空灵老者以掐诀层层消解碎星之力，面色苍白但伤势不重；司墨子与女修喷血急退，**三人就此被冲开**。

### 司墨子的诡异法诀
拓森星点漩涡罩下时，司墨子低吟一段囚天封道之诀（「囚封天之道，众生需渡无量劫……常沉苦海，永失真道，奉至修真行」）。**拓森闻声面色骤变，竟放弃击杀司墨子**，一拳阻住来援的空灵老者后交错而过，转攻已受伤的女修。

### 结果
- 女修被一拳轰得喷血，被星点漩涡卷回拓森眉心，**封印在第二颗星内**。
- 拓森撕开星空遁走，留下阴森之语：「本神还有几颗星没有碎开，等你二入追来。」

## 二、幕后：白衣女子与「王族古神」之秘

- 空灵老者与司墨子对视而笑，笑中**带着一丝羡慕**，随即离去——暗示此局本就有意放拓森走。
- 二人传音议论：
  - 被拓森追逐之人（**王林**）同样散出古神气息，**也是王族**。
  - 「这天地间的王族古神，怕是只剩下这两个了」；拓森已无碍，另一个则不是他们能猎取的。
  - 疑惑：王族古神对**「她们」**有何作用？为何费尽周折且**途中改变计划**。
  - 绝密传闻：**王族古神拥有太古天地初开的神性，可以让……**（话未说完即止）。
- **白衣女子登场**：相貌模糊、无声无息却似能跨越无尽距离，气息飘渺，「好似本不该存在于天地之中，而是**仙域**之人」。她道谢并递出两道白光——**承诺的六品道灵**，随后穿身而过，一步步中星河在脚下消散，**独自向拓森追寻之地走去**。

> 推断：三名第三步大能实为受白衣女子雇佣（酬劳=六品道灵）的猎手；「途中改变计划」与「她们」指向幕后另有更大布局。

## 三、王林：赶赴月族星域，反身迎战

- 王林以**缩地成寸**、多次**融入天地**赶路，逼近记忆中**月族**所在星域。此前察觉的古神气息波动令其隐隐有了猜测，但无暇细想。
- **月光星域**：四周一颗颗星球内透出柔和月光，弥漫整片星域，绚丽如梦幻。王林确认「就是此地了」。
- 神识散开，在星域前方察觉一处**弥漫古神气息之地**，冷笑「引君入瓮么」——识破陷阱仍前往。
- 拓森带着疲惫自星空裂缝迈出追至。**诡异之处：如此剧烈声响竟未引起月族半点注意，一片寂静。**

### 宿命第一战开打
- 拓森：「你逃不掉。」王林：「**我也不会再逃**。」
- 现场耸立**数个巨大古神雕像**，浓浓古神气息不断外溢。
- 王林反身，化作**千丈大小**，眉心**六个古神星点**急速旋转，古神之力轰然爆发。
- 右手一挥，**血剑**幻化为**百丈大剑**，迎着拓森隔空一拳斩下。

### 关键收益：逼出开天巨斧残力
- 王林一步踏在古神雕像四周，一吸之下此地古神气息疯狂涌入体内，尽数冲向胸前伤口。
- 伤口内残留的**开天巨斧之力**被磅礴古神气息与自身古神之力合击，**一把模糊斧影被生生逼出体外**。
- **胸前伤口顿时愈合，再无半点伤势**——王林在决战前恢复完整状态。

## 四、要点归纳

| 项 | 内容 |
|---|---|
| 拓森手段 | 眉心古神星点（可碎、可爆、可封印生灵）；剩余星数未明，自称「还有几颗星没有碎开」 |
| 拓森动机 | 对王林有「必吞之心」，不惜碎灭一星换取脱身 |
| 王林身份线索 | 亦散古神气息，被认定为**王族古神**；天地间王族仅余二人（另一为拓森） |
| 王林状态 | 六个古神星点；血剑；千丈化身；开天斧伤已愈 |
| 新登场 | 白衣女子（仙域气息，雇主）；司墨子；空灵老者；被封印的女修 |
| 悬念 | 王族古神的「太古天地初开神性」到底有何用；「她们」是谁；月族为何毫无反应 |

## 五、备注

- 按世界状态须知，王林自第1063章起对外以化名「吕子浩」立足云海星域；本章为太古星辰星空追杀线，文本直呼其本名，行为归属【王林】。
- 原文有「空涅」「空灵」等境界写法，以及「三入」「二入」等 OCR 讹字（应为「三人」「二人」），此处按文意理解。
