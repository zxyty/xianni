# 第七卷 名震罗天 · 第835章 皮甲气息

## 一、清场：把修士打入大地
- **黑袍男子**刹那出现，右手掐诀、虚空一抓，身前浮现**庞大漩涡**；漩涡如闪电般游走，凡被碰到的修士立刻**融入大地消失不见**。
- **炎雷子**与黑袍男子速度极快，趁**红袍老者以八角封印锁死望月**的刹那，将四周修士一一打入大地。
- 遇到**姚家族人**时，炎雷子寒芒一闪、**故意加一成力道**，使姚家族人纷纷重伤喷血后才消失——针对性极强。
- 待红袍老者被震退时，二人已把四周修士**全部送走**。

## 二、望月之怒：古神一指
- 八角封印名义上只封望月本体，但四周**小型望月**体外同样浮现八角封印，一并**暂时受阻**。
- 望月大怒："它不记得多少年了，没有这般被人封锁"。疯狂撞击，每撞一次虚无中便现一道八角封印，产生巨大反震。
- 望月**头部大嘴之上裂开两道裂缝**——即**望月之目**：目光浑浊、云烟缭绕，透出疯狂。
- 伴随模糊低语，其身前**无数晶点从虚无幻化**，凝成一根庞大而略粗糙的**手指**——「**望月之怒，如古神一指**」。
- 红袍老者心神剧震，双手按向阵法、衣发无风自动、体内元力如风暴运转，大喝"快"。
- **古神一指缓缓下按**：一指点在八角封印上，封印**毫无停滞、砰然崩溃**，碎片倒卷；红袍老者面色苍白，随碎片倒退，一晃直奔炎雷子与黑袍男子而去。

## 三、三人迎击：各以化形硬撼
- **炎雷子**：直勾勾盯着古神一指，眼露兴奋，大笑"好一头月兽——**若是把你送到了联盟星域，定会让玄重子大吃一惊**"。
  - 判断："这月兽的最强一击，我们无法抵抗，**除非是本体前来**，或许还能周旋一二；现在目的已然达到，不如去亲身感受一下月兽之威。"（暗示在场者亦非本体/目的已达成）
  - 出手：全身火光滔天包裹肉身 → 掐诀凝聚全部火焰**化作一条炎龙**撞向古神一指。炎龙即其此刻的全部，冲出后**肉身消失、元神似亦不在**。
  - 结果：轰然相撞，**炎龙崩溃**，化作无尽火焰包裹古神一指并疯狂燃烧。
- **红袍老者**：眼露奇异之芒，一步迈出，右手掐诀按在眉心，**整个人化作一把红色细剑**，趁古神一指被火焰围绕之际直接刺出。
- **黑袍中年男子**：暗道"**自己的这具分身可以不要**"，但月兽最强攻击必须体验，或另有收获；自忖修为到此境界**再要迈步极为艰难**，此月兽或是自己的一次机会。遂掐诀**化作一头黑鹰虚影**——虚影虽虚，却透出浓郁**沧桑气息**——直奔古神一指。

## 四、余波
- 整个**罗天北域**（原文作"罗大北域"）回荡起难以想象的巨响，仿若北域崩溃；**所有修真星上的修士**都感受到那股令其剧震的**神念之音**。
- 片段收束于"炎龙，崩溃"，胜负未分，属承接下一章的悬置。

## 五、要点提炼
1. 八角封印可同时压制望月本体与小型望月，但**挡不住古神一指**。
2. 古神一指=望月怒极的最强一击，形态为虚无晶点凝成的巨指，威势"如古神临世"。
3. 三名强者**均非本体**（至少黑袍男子明确为分身；炎雷子提到"除非本体前来"），此行带有**试探/取材/体验**性质。
4. 炎雷子提及**联盟星域**与**玄重子**，透露其欲把月兽送去的意图与背后势力线索。
5. 炎雷子对**姚家族人**明显加力——暗含额外恩怨或授意。

# 第776章 望月吞噬古神一指 · 雷仙殿密谋 · 魔道子凶名

## 一、望月收场：吞并古神一指

- 红剑碎裂，黑鹰消散——对望月的攻击尽数瓦解。
- **古神一指**在望月咆哮下更为黯淡，但**没有任何损伤**；残存部分被望月横扫一圈后化作晶光，融入望月体内。
- 望月双目冰冷，张口将四周**无数小型望月**尽数收回体内。
- 庞大的望月缓缓前移，触须摇曳间**渐渐消失在星空中**。

## 二、雷仙殿密室：生擒望月之谋

地点：**罗天星域·雷仙殿**某密室，地面为一**古老阵法**，三人分坐阵法关键之位共同推演/观察。

| 人物 | 表现 |
|---|---|
| 炎雷子 | 率先睁眼沉吟；目露疯狂，提出计划 |
| 红袍向姓老者 | “这月兽的确如老夫家族记录，轻易不可招惹” |
| 黑袍中年男子 | “很强” |

**决策**：炎雷子拍板——接下来要**联合多人，展开生擒望月的计划**。

## 三、姚家祠堂：血神子的追杀令

地点：**罗天东域**血红色星球·**姚家祠堂**。

- 血神子身后令牌接连碎裂**十多个**（族人阵亡的表征），化作白气被其大袖收起。
- 感叹：“不愧是来自联盟星域之人……比我姚家的这些三代族人，在杀伐上干脆利落，姓格上果断坚韧。”（暗指许木出身联盟星域）
- 沉默许久后虚空一抓，凝出**血色玉简**，留神念下令：
  > **派出二代族人姚云，去罗天北域取许木之命。**
- 玉简化作血光消失无影。

## 四、魔道子许木：凶名震动罗天星域

经罗天北域惨剧后，“魔道子许木”之名彻底为全星域修士所知：

- 在姚家族人与无数修士的追杀下不但没死，反而**巧借庞大凶兽（望月）之力发动可怕反击**。
- 结果：绝大部分修士灭亡，**震慑整个罗天星域**，再无任何修真家族敢参与其与姚家之事。
- 评价：“不到万不得已，不能招惹”；此人**极为疯狂、嗜血如魔**，屠杀低阶修士，更为反击唤醒庞大凶兽造成浩劫。
- 其凶名甚至可与**东临星**相比；当年在**雷之仙界**的种种传闻再度被翻起、深记于众修心中。
- **王林对此毫不知晓**。

## 五、王林在望月体内：弃甲、寻鼎、被锁定

1. **异常察觉**：此次入望月体内与上次截然不同——小型望月见他极为兴奋，甚至在姚冰云攻击他时**出手相助**。
2. **溯因与处置**：王林判定“定是**古神皮甲**的原因”，心念一动将元神之上的古神皮甲脱离、幻化于手中，**收入储物袋**，随即改变方向疾行。
3. **追兵反应**：身后小型望月如同心爱之物被夺，纷纷暴躁咆哮、相互散开融入四周不断寻找；王林松了口气。
4. **目标**：在望月体内谨慎游走，寻找当初的**贪狼大鼎**——“让他怦然心动之物”。
5. **被锁定**：望月体内忽然自四面八方传出震动，化作波纹横扫；王林后退避让，身后亦有波纹回荡，速度极快，**穿透其身而过**。波纹似为望月搜寻体内异物的神通，望月由此**找到王林所在**。
6. **危机**：望月发出可**震碎元神**的闷闷咆哮，初时微弱，瞬息剧烈，最终化作无数紧贴耳根的雷鸣轰隆响起。

## 六、悬念/后续线索

- 炎雷子一方的“联合多人生擒望月”计划将如何展开。
- 姚云奉命赴罗天北域刺杀许木（王林）。
- 王林能否在望月震魂神通下寻得贪狼大鼎并脱身。
