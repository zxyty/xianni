# 第1673章 烨寞无子！

## 一、战况：古族肉身的正面对轰

- 开场王林被中年男子一击直接震伤，气血翻滚、口溢鲜血、连退数步，每一步落下都如踏在星空脉搏上。对方右臂亦砰砰作响、嘴角溢血、蹬蹬退后。
- 叙事点明设定差异：修士之间要一击致此，需修为高出一大截；**古族之间凭恐怖肉身之力，以相近之力即可做到**——「这是古与仙的不同」。
- 二人瞬息间纯以拳头对轰**九次**，每次碰撞化作大量波纹横扫星空。九拳之后：
  - 数万界外修士齐齐后退至**十万丈外**，以神识远观。
  - **转轮阵法**承受余力冲击，出现大量扭曲。
  - 王林喷血后退，身如被九个修真星连成直线撞击，眼看要撞上转轮阵法时硬生生一顿，战意更烈；中年男子亦喷血退出数万丈。

## 二、关键细节：舔血分析

星空中弥漫二人鲜血，一滴属于对方的血倒卷溅在王林脸上。王林抹去后放在嘴角**舔了一下**，双眼露出奇异之芒——正是此举让他在战中完成对敌方来历的推演。

## 三、古神一指 vs 双拳合一

- 王林双掌相扣、双拳合一，踏空跃起万丈，形成上下之势，自上而下砸落。
- 中年男子掐诀上指，身后显化**眉心八个星点**的古神虚影，着完整铠甲，随其动作一指按出（因体量巨大，仅一指便有百丈）——**古神一指**。
- 结果：王林喷血却不退，咆哮下双拳穿透，将虚幻一指自中劈作两半，继而崩碎古神右臂、直接把整个古神虚影轰裂消散。
- 王林挟万钧凶煞逼近至几十丈（对古族之修如凡人间不足七尺），双拳与对方手指相触：**手指爆开、骨肉模糊**，双拳砸中其胸口，胸膛直接凹陷。
- 对方受创仍抬右脚横扫，正落在王林双拳之力将泄未泄的关键处，王林被抛出数千丈、双臂颤抖。
- 王林此击**未施展古神神通**，是其**传承古神与道古之后所能发挥的最强肉身之力**；威力评级：足令**空涅**修士直接崩溃、**空灵**修士无法对抗、**空玄中期**也须施展莫大神通方可阻挡。

## 四、「古族战印，生死斗」与王林的第一句话

- 文中定性此战为「古族战印，生死斗」，并给出准则：凡生死之杀，**勇者方胜**。
- 王林红眼狰狞、不顾伤势再冲，大吼一声「**杀**」——这是他本场战斗中吼出的第一句话、第一个字，令后退中的中年男子**面色第一次变了**。

## 五、中年男子的四重底牌

| 神通 | 来源 | 表现 |
| --- | --- | --- |
| 古妖番天 | 左目**三颗妖星**化三滴血液 | 化出巨大古妖虚影，其**左目有九颗妖星**，尖啸膨胀张口吞噬 |
| 古魔噬地 | 右目**三个魔星**化三滴血液 | 爆发精纯魔气，化巨大古魔虚影，天地色变、星空震动 |
| 古神一怒 | 眉心**两个古神星点**化两滴血液 | 再现古神虚影，带无边怒意低吼 |
| 父祖道古，凝化古影 | 高呼掐诀 | 于古之三族虚影之后显化**道古烨寞**身影，古之三族在其面前如孩童般微不足道 |

- 其宣称：「**我为道古之子，你得我父传承，今日我要收回你之传承**」，驱三族虚影与烨寞虚影齐攻王林。

## 六、王林的判定：烨寞无子

王林凭方才舔血所得，当场道破：

1. **烨寞无子**。
2. 烨寞**死前挥洒三千血液，化作古之三族**。
3. 这三千血液中，**或许有九滴是其心头之血**，内蕴古族气息极为浓郁。
4. 此人恐是**界外掌尊等人**在无尽岁月中**灭杀无数古之三族**后，自其身上**凝抽出那九滴心头血**所化。
5. **即便如此，此人如今也只凝聚了八滴而已**（对应其古神虚影眉心八星点）。

## 七、王林的应对与此战的赌注

- 王林眉心星点、左目古妖星点、右目古魔星点急速旋转，在体内不断融合，**属于他的道古气息骤然爆发**；身后显化出由道古烨寞传承而来、**没有左目的道古头颅**。
- 本质：这是一场**「道古传承」与「道古心头之血所化之子」之间的生死斗**。
- 胜负彩头：王林若胜，**可吸收对方一切，即那八滴道古精血**。
  - 很可能使王林凝出**第八个古神星点**；
  - 更可能令其**古妖、古魔星点再次增加**；
  - 这将是他**二次前往古之墓地、获取完整传承**的契机与造化。

## 八、备注

- 原文多处将「古神/古妖/古族」误写作「吉神/吉妖/吉族」，「今日」写作「今曰」，「千丈」写作「干丈」，属排版讹字，语义按「古」「今日」「千丈」理解。
- 据世界状态须知：王林自第1380章起以「烨寞（道古烨寞）」之名/身行事，属借势代入化身而非冒名行骗；本章体现为其身负道古传承、以道古气息与道古头颅应战。
