# 第1813章 太坑人了！（第三更）

## 一、场景：火球中的王林

- 地火子脉的火龙魂崩溃，化作一颗巨大火球，将王林整个掩盖在内。
- 火球外有**十六条火龙**咆哮环绕，与火球连接为一体；火球内隐隐可见**一尊朱雀身影**。
- 远看火球如同一枚蛋，其内似正发生惊人变化。
- 王林在火球正对杜青的一面幻化出**自己的冷酷面孔**，以此面孔说话、出手。

## 二、七道本源逐一出世

杜青先前以「区区三道本源」自矜，王林遂逐道亮出本源，形成层层递进的震慑。

| 序 | 本源 | 显化异象 |
|---|---|---|
| （前置） | 火本源 | 强行吸收地火脉、火龙魂化火球 |
| 1 | **雷之本源** | 右目闪电印记化天地雷霆；四面八方雷霆汇聚，引动**雷变**，现青铜色**雷帝战车**，六道巨大闪电拉车，车上立青色斗篷模糊身影 |
| 2 | **生死本源** | 天落白气、地钻黑气，黑白绞成漩涡，生机与死气完美共存 |
| 3 | **虚之本源** | 王林早经实验：虚之本源在仙罡大陆不受改变 |
| 4 | **真假本源** | 漩涡在虚幻与真实间急变，观者心神几被吸入幻觉 |
| 5 | **因果本源** | 漩涡内蕴因果大道，一片混沌，道之变化分辨不清 |
| 6 | **杀戮本源** | 眉心裂开一缝，萧杀天地之寒轰出，天降**红色雪花**，大地穿上雪衣 |
| 7 | **禁制本源** | 双目瞳孔弥漫血丝，血丝幻化笼罩八方，化作禁制 |

### 杜青的层层崩溃
- 见雷变：不意外两道本源，但震惊于**雷之本源竟引动雷变**（须修炼至极深方有）。
- 见虚之本源：「此人也和我一样，**两实一虚**」——这已是他预料的极限。
- 见因果、真假：改判为**三虚二实**，惊叹「能获得三道虚幻本源」的气运，「就算在**大魂门**也从未听说」；其双手中的土、火本源亦为之黯淡。
- 见杀戮本源：几乎尖叫。杀戮本源在仙罡大陆**比重之本源还罕见**，须双手沾满鲜血、杀戮无数生灵方可凝聚，单独一道即足以称雄——遂断定王林是「**绝代凶煞**」。
- 见禁制本源：「七道，不是六道」，头皮发麻、脑海轰鸣，逃念滋生。

## 三、转折：大天尊金印

- 杜青为存颜面叫阵：「七道本源又如何？你可敢出来与我痛快一战？」
- 王林反问「你真要战？」，火球内爆发**恐怖威压**，随后飘出一枚**头颅大小的金色大印**。
- 金印特征：
  - 金光万丈如骄阳，笼罩天地；
  - 散发**纯正仙人血脉之力**；
  - 更含一股**大天尊气息**，虽不多却**足以开天辟地**。
- 杜青的判断（仙罡大陆常识）：
  1. 此印为某位**大天尊**施展天地之术、将**神通实质化**后凝聚而出的法宝；
  2. 其价值不在战力，而在**震撼**——大魂门、归一宗乃至整个**天牛洲**的宗派强者见之都会心神颤抖；
  3. 此类法宝**除大天尊亲自赠予外，一旦易主立刻崩溃**；
  4. 大天尊多将其赠予最亲近门人弟子，等于昭告众生「此人谁也不能动」。
- 杜青修为不足以分辨这是**九阳**中哪一位大天尊之物——他无数年来根本没资格见到任何一位。

## 四、结局：杜青放弃追杀

- 杜青被金印气息**自行伤及心神**，喷血、连连后退至数十丈外，目光近乎幽怨。
- 其咆哮（本章标题出处）：
  > 「奶奶的，你有这样的法宝，你早点拿出啊！你要早点拿出，鬼才会追杀你，你就算把**苍龙宗**全都屠了，老子也当没看到……你这是坑人啊！太坑人了！」
- 王林自己也为之一怔，没想到一枚金印竟有如此震撼之力，能让杜青喷血后退、不顾身份说出这种话。

## 五、要点提炼

1. **王林本源确认为七道**：火、雷（实/半实）、生死、虚、真假、因果、杀戮、禁制——杜青所计的「三虚二实」只到第五道，最终以「七道」定论。
2. **杜青本源为两实一虚**（土、火为实），其境界与王林相当或稍高，但因不知王林底牌深浅而不敢战。
3. **仙罡大陆设定新增**：大天尊神通实质化法宝的「易主即崩溃」规则、九阳九位大天尊、杀戮本源比重之本源更罕见。
4. **退敌手段是威慑而非战力**：本章王林全程未出火球正面交战，纯以本源展示 + 金印身份威慑逼退追兵。
