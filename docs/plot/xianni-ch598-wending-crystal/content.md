# 第598章 问鼎之晶

## 一、天劫终章：天妖城毁于红云

- 天空红云不再一寸寸下压，而是一丈、两丈、三丈直至十丈骤降。
- 轰鸣中天妖城不但坍塌，且被整体拍进地底，尘土都掀不起来，原址化作**巨大盆地**。
- 盆地边缘裂纹疯狂蔓延，大地持续崩溃：十里→百里→千里→万里尽成碎片，碎片又被挤压成碎末尘土。
- 王林悬于天威压力中心，一动不动，如同沉睡。

## 二、古妖显形与「灭道」一掌

- 王林身后的古妖虚影与他一样双目紧闭；地面五个老头见之骇然恭敬：「真的是老祖宗」，并猜测王林即老祖宗找了很久的那个人。
- 王林猛然睁眼，古妖同时睁开妖目；王林缓缓抬起右手按向红云——**细看是古妖先动，王林随之而动**，身体似被某种奇异之力操控。
- 二者同声吐出「**灭道**」二字，声音却从王林口中传出，滔天妖气爆发。
- 王林如利剑冲天，一掌与古妖一掌同时落在红云上，云碎；王林被震退落地，双脚触地瞬间波动蔓延，**方圆十万里大地崩溃**。
- 古妖落地时身子涣散，但因其身为「**第二类逆修者**」、一生对抗天劫无数，少顷即再度凝实。

## 三、赤霄云芒：古妖代抗

- 红云消散瞬间，一道**十丈粗细的红芒**自天空尽头落下，威力远超此前红雷天劫，目标是**古妖虚影**而非王林。
- 古妖眼中爆出妖芒，言「**赤霄云芒**，我已经好久没有品尝它的味道了」，自王林身后一跃而出，一口吞下红芒。
- 红芒入体后古妖全身崩溃又重组，**数息内崩溃一万次、组合一万次**，最终被生生逼落地面；以其脚为中心三丈高环形波浪扩散，十里外地面尽碎，波及百万里，大地如被重新翻开。
- 天空红云彻底消散，恢复正常。古妖打了个饱嗝、眼露疲惫，化作青烟消失。
- 临去浩荡传音（非私密传音，广传开来）：「**三个月后，来龙潭见我**」。
- 王林随即踏步消失于原地。

## 四、五老与云沌：三月复城之约

- 五个老头从废墟爬出，齐声怒吼呼唤「云沌」，威胁扔进龙潭关一百年，接着加码二百年、五百年、一千年，最后一人轻哼「关他一辈子」。
- 云沌自远处废墟疾掠而来，现身**燕京广场**，苦笑行礼：「孙儿云沌，见过五位老祖爷爷。」——此人**正是此前画舫上与王林把酒整夜的青年**。
- 五老责令其**三个月内把天妖城（古妖城）恢复原样**；云沌应下。
- 五老另嘱：「那被老祖宗看中之人，你去找他，**三个月后带他去龙潭**」，随即消失。

## 五、王林返回洞府：问鼎的准备

- 王林于万里外现身，神识横扫后取出**令牌**——此为进入神秘洞府之物，凭此可随时进入。
- 依令牌内记录的口诀连打印记，令牌白光包裹，瞬间传送。
- 再现身于**由尊兽连接的石台**，急速跃过一个个平台，直入洞府，来到**曾发现酒壶的厅榭**盘膝坐下。

### 为何必须在洞府问鼎
- 天劫后王林察觉**意境彻底圆满、正与仙力融合**——问鼎将至，内心一惊。
- 「问鼎，朝闻道，夕死矣」：期间一旦有失，不仅一生修为断送，更会**元神崩溃**；虽不知是否波及外界的**古神之体**，王林不敢赌。
- 问鼎是一道关卡，必须在极安全之地驱除一切外界因素，洞府无疑是最佳之处。

## 六、吞服问鼎之晶

- 抖开储物袋，**剩余仙玉已不多**（天劫一战仙力损耗很重），尽数飞出铺满厅榭地面，堆积成一处处小山，大量仙气弥漫。
- 取出**指甲大小的红色玉石**——此物一出，四周仙气为之一顿，好似时间停止，其内散发**天道之威**。
- 王林语：「问鼎之晶，当年**周佚前辈**所赠，今日我若问鼎成功，前辈之恩，此生铭记」，一口吞下，闭目沉浸于意境与仙力融合的问鼎之中。
- 面色如古井不波，四周仙玉不断化作碎末，无数仙力被吸入体内。

### 设定要点：问鼎之晶
- 问鼎之人体内元神中会产生一枚**问鼎之晶**，此晶如同肉身中的心脏，是**元神的心脏**。
- 周佚的问鼎之晶，成了**王林的第二个心脏**。

## 七、暗处窥伺

- 天妖城开始紧锣密鼓恢复，天妖郡各城池大量**妖兵**集结重建。
- 不知多少万里外的**远古战场**中心，**黑塔最顶层**那副**漆黑铠甲**头部两道幽光闪烁，暗忖：连古妖都出现为你抗下天劫，若就这样把你吸了有些可惜；但错过这机会，再想吸你不知要等多久——**问鼎之力虽不多，也不能放过**。
