# 第八卷 联盟隐秘 · 第1008章 葬花

## 一、开场：仙界碎片崩溃
- 仙界碎片（天运子神通下已有裂痕、仍属极强防御法宝）在白衣女子一指之下**诡异崩溃**，一股奇香扑面直落王林身上。
- 王林体内砰砰作响、喷出一口鲜血急退。心中骇然：**幸亏自己是古神肉身**，寻常修士必死无疑。
- 王林暗忖：“她到底是谁，莫非真的是浮风子所说的**花仙**？”

## 二、二次试探与场上清场
- 女子再点虚空，王林胸口剧痛如利刺穿透——实为**一截植物根须幻化**，被王林眉心涌出的**古神之力**震断。
- 女子评价：“难怪敢擅闯洞府，的确有些资格。”（确认王林一行为擅闯者）
- 玉指一点旁侧：
  - **浮风子**周身开遍花朵、奇香扑面、面色苍白中毒，被迫盘膝逼毒，随即被花海彻底包围隐没。
  - **尘道三子**与**大头**等人未及施展神通，被花海瞬间覆盖。
  - **银尸**亦被花海奇香吞没。
- 场中半空只剩王林一人。

## 三、雕花钗与「葬花」
- 女子取下发间**雕刻着花朵的钗子**掷出，厉啸尖锐、可穿透肉身毁灭元神；速度快到王林看不到痕迹，全靠**青光盾**连续自行防御。
- 王林判断：此女可怕程度**隐约超过当初的炎雷子**。
- 女子捏诀轻声道「**葬花**」：目光所及尽数盛开无尽花朵，花蕊急速枯萎、花瓣如雨脱落，尽数向王林凝聚淹没。

## 四、王林反击：首次三大仙术齐出
- **呼风**：右手指天，花海中黑风弥漫化作四头黑龙，阴寒扩散。
- **唤雨**：黑龙咆哮引大雨，洞府仙气融入雨中，风雨共融后雨滴化作冰晶，形成风暴横扫。
- **撒豆成兵**：口中射出**十八地狱封仙印**（十八层光芒），大袖甩出无数战魂，其中**血祖**狰狞而现。
- 这是王林**第一次把白凡三个仙术同时施展**，三术融合成弥漫天地的风暴，硬在花海中破开缺口直逼女子。
- 王林踏前一步，身躯由常人化作**百丈古神**，青光盾扩至数十丈，**王族古神气息**毫无保留弥漫，融入风暴挥出一拳。

## 五、本源之力对决
- 女子神色微变，轻声道「**古神**」，手心青光一闪凝出**光团**。
- 光团与风暴一触即碎，却引发诡异变化：融合风暴**层层退化**——先分离回三个神通，再逐层消失；撒豆成兵的战魂尽数倒卷回十八地狱。
- 王林判明光团内蕴含**一丝本源之力**，若沾身即便古神肉身也会崩溃。
- 第二个光团袭来，王林眉心**第三目**骤开，红芒扇形散开笼罩光团，储存的本源之力丝丝缭绕。
  - 这是王林**第一次以第三目本源之力交战**：光团迅速消散，王林第三目中本就不多的本源之力**同样对消殆尽**。
  - 事后王林背部冷汗湿透，第三目红光黯淡回归眉心。
- 女子**第一次色变**，凝重发问：“**古神、白凡仙术、本源之力，你是谁？**”

## 六、王林的赌注：定身术与青霜
- 王林极为忌惮此女，但**妖灵仙府必须闯进去**。
- 其想起先前**青衫老者见到定身术时的奇异表情**，决定赌一次；预案是失败便逃命去寻**古妖贝罗**来破开此地。
- 施出**定身术**——白衣女子神色立变。
- 王林索性一拍储物袋取出**仙玉塔**，塔内荧光中**青霜**如沉睡尸体般显现于二人之间。
- **白衣女子如被雷电轰隆击中**（章末悬念）。

## 七、看点与待解
- 白衣女子疑为浮风子所说的「花仙」，修为深不可测，掌握本源之力与「葬花」神通。
- 女子对**定身术**与**青霜**接连出现强烈反应，暗示其与白凡（定身术/白凡仙术来源）及青霜存在旧缘。
