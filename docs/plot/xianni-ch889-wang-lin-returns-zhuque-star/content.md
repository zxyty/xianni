# 第八卷 联盟隐秘 第889章 回归

## 一、蛮荒星：吞噬生机复原

- 王林所在之处方圆数十万里枯萎龟裂，全部生机被其吞噬殆尽，用以弥补自身。
- 相貌恢复如常，睁眼时目中雷意闪烁。
- 自评：**「依靠寂灭指来恢复生机，有其弊端。」**——为寂灭指的代价埋下伏笔。
- 塔山一晃融入王林身影内消失不见（随行/收纳状态）。
- 王林一步踏出蛮荒星，脚下起波纹融入星空，口称「朱雀星」，直奔而去。

## 二、朱雀星外：大头童子的屠星令

- 两名罗天修士（族兄弟）奉命屠星却惊慌折返，报称「在这修真星内看到了一个雕像」。
- 大头童子打断呵斥：「让你们去屠星，不是去看什么雕像」，痴傻之笑下透出杀机。
- 族兄拉走族弟，只留一句「仙使大人，你亲自一看便知我二人为何回来」。
- 大头童子行事惯例：遇半废弃修真星，由手下屠杀干净后即走；唯七级修真星才值得他亲自施展神通——至今未遇。
- **修为披露**：窥涅初期；曾进入升仙池、化去意境、拥有仙元；暗中试过几次仙术，威力令他极为惊喜。

## 三、神识横扫朱雀星

神识化作风暴与黑云压下，全星层级式受创：

| 层级 | 受创程度 |
|---|---|
| 问鼎修士（数人） | 身子剧震，元神几乎崩溃 |
| 婴变修士 | 喷血，身子萎靡 |
| 金丹修士 | 金丹出现裂缝，面色苍白绝望 |
| 筑基/炼气 | 全身爆出血雾，气若悬丝 |
| 凡人 | 全部昏迷（大头童子不愿屠凡人，否则神识一扫生灵皆灭） |

**挣扎者两人：**

- **周武泰**：青龙血脉 + 传承问鼎之晶，青光化青鳞，幻化百丈青龙咆哮天际；随后被大头童子一指仙术（浓郁仙气化金光）穿透，守护朱雀星的青龙带着不甘崩溃，周武泰喷血但战意点燃。
- **云雀子**：金色符文弥漫，幻化参天巨树虚影，气息疯狂攀升，**在重压下有了突破**；但感到一股「来自灵魂深处烙印」的意念要他屈服，一声冷哼下符文尽碎、喷出大口鲜血——文中明指符文崩溃非对方之力，而是那股意念。

## 四、许木的雕像：从屠星到退意

- 大头童子神识特意寻找雕像，在一处宗派山门（云天宗）内看到庞大雕像，倒吸口气、骇然退步。
- 认定这是**许木**（即王林化名）的雕像：「魔道子，许木」——他曾在**一线天**毫无还手之力，死在许木的雷术神通下一次；事后即便入了升仙池也丝毫不敢招惹。
- 与雕像目光对视时全身毛发竖起，如真正面对王林，下意识退后数丈。
- 推断：此雕像已存在数百年 →「这许木不是我罗天星域之人，他是**联盟星域**的修士」。
- 自认掌握天大机密，可用以让许木身败名裂甚至丢命，狂笑不已。

## 五、毁像未遂与王林现身

- 大头童子不敢招惹许木，只欲拍碎雕像泄恨。
- **铁岩**盘膝坐在雕像下广场，嘴角带血、寿元将尽，毫无畏惧：「你毁恩公雕像，必死无疑」。
- 大头童子冷笑：「别说毁个雕像，即便是许木亲来，本仙也不放在眼里」。
- 话音落，一股冰封天地般的寒声回荡：**「你给我再说一遍」**。
- 大头童子面色刹那苍白、魂飞魄散，不假思索喷血自损修为展开**血遁**，喊「战不得，速退」。
- 王林自雕像旁波纹中走出：铁岩老泪纵横唤「恩公」；云雀子、周武泰及全星苏醒修士齐呼「王林」——**朱雀星真正的老祖**。
- 王林眼露滔天杀机，向前一步：**「你，跑不掉」**。

## 六、旁观者的猜测（伏笔）

- 云雀子看到罗天仙使在「当年那小娃王林」的雕像前呆住，心生一个连他自己都觉荒谬的猜测——罗天修士竟识得王林？
- 周武泰重伤仍死守，因当年在王林面前立下誓言：**朱雀在，人在；朱雀不再，人亡**。
