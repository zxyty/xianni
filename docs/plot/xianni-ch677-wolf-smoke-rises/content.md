# 第七卷 名震罗天 第677章 狼烟起

## 一、云霞星之谜：矿脉即望月之骨

### 疑点
王林在云霞星地底顺着金炎矿脉而行，心存三大疑团：望月为何出现于此、金炎矿脉为何如此鲜明、为何长久无人取走。多年谨慎令他压下立即收取的冲动，先行观察。

关键破绽：矿脉**大小粗细自始至终大致一样**，绝非天然形成，形如「一截截长长的骨头」。

### 揭晓
大地一颤，波动自四面八方向上传递。王林散开的神识看到——一根根触手自矿脉伸出，融入泥土急速延长，从大地裂缝中钻出、在地表摇曳摆动。

王林由此串起线索：
- 望月第二种状态＝全身须发收缩、进入沉睡。
- 整个云霞星「长满了毛发」。
- 结论：**云霞星本身就是一头庞大的望月，所谓金炎矿脉是望月之骨。**

### 后怕与推断
- 若方才直接收取金炎脉，会激醒望月；望月无需彻底苏醒，只需清醒一瞬便可杀死所有妄图取骨之人。
- 由此解释为何无大神通修士来取——不是不想，是不敢；此前来者恐已尽数身亡。
- 幻家那位死去的族人只在露出地面处取了一点便立刻离开，既精明又有运气成分；换个人哪怕只取一点也可能牵动望月。

## 二、王林的对策：升仙果迷药 + 古神印诀

王林不甘心只取零星，目标是**整条望月之骨**，但强取必死。他调阅**古神涂司**记忆中关于望月的一切：

| 情报 | 内容 |
|---|---|
| 本质 | 古神体内的寄生体，古神最了解它 |
| 食性 | 喜噬古神之血 |
| 弱点/敏感器官 | 触手须发 |
| 摄食限制 | 除非有**古神之印诀**牵引，否则不吸收古神血液以外的任何物质 |

灵感来源：王林当年吞下**升仙果**时曾有一股癫狂之感，那种状态下「即便有人取我之骨，怕是也感觉不到」。

**计划**：从升仙果中提炼可致昏迷/迷幻的药物，且量必须极大，方能让庞大的望月在沉睡中陷入昏迷；再以古神印诀为牵引令其吸收，然后抽骨。此法唯王林可行——古神印诀天下唯他拥有。

## 三、离去与心境

- 王林出地底、离云霞星，召出**星罗盘**（银龙游走）疾驰离开，回头一望，目露果断。
- 此行来回数月落空，原以为可令**天逆珠**圆满；他自我宽慰：天逆圆满已等了八百余年，不差这些时日。
- 惊叹：这望月之庞大，「到底是几星古神才可以拥有这等望月」；其上已有城池废墟，说明沉睡无数岁月。
- 力量评估：望月化作星球形态，一旦苏醒，恐怕连**凌天候、天运子**等人也会望风丧胆、立刻逃走。
- 遗憾：除寄生之主外无人可操控此物，「即便是本尊在这里，也是无用」；否则牵回联盟星域便是幸事。
- 去向：操控星罗盘，直奔**冉云星**。

## 四、冉云星危局：锁星大阵

### 三老议事
冉家老祖、逍遥散人、孙析散人遥望天际，面色阴沉。

- **孙析**认出天上是「锁星大阵」。
- **逍遥散人**分析：幻家出手绝不会如此拖沓，有布阵的时间早就直接降临了 → 另有用意。
- **冉家老祖**判断：此事恐怕是为**幻家老祖新收的义女幻眉**立威作准备。
- **孙析**：幻家意在灭族，布阵是防他们逃出。
- **冉家老祖**：灭族不至于——三家这几年早已暗中把资质较佳的嫡系送出，烟火不断。
- **逍遥散人**：根基都在冉云星，短期无法迁移；大量迁移反会使事情提前爆发。

### 对许木（王林化名）的怨恨
孙析提到「许木道友或许会赶回来」。冉家老祖咬牙：他若不回来，三人被擒后也要把他拖进来——冉云星的仙玉岂能白拿；当初答应庇护，却在危机时离开，是小人。
孙析暗叹：即便回来又如何？幻家老祖修为已达**修道第二步**，无人可挡。

### 幻家老祖的底细
传闻幻家一共只有两个踏入修道第二步的老祖，当年在**雷之仙界**的争夺中死去一人，只剩眼前这位；实力虽不比以往，但一人便可横扫众生。

### 因果
三人对**四年前之事**充满悔恨——「所谓因果，便是如此」。

## 五、燃元神决战，柳眉降临

- 天空波动扩散，无穷压力自天而降。
- **柳眉**一身白衣，穿过锁星大阵而来，神识一扫落在三人身上，神色平静如水。
- 冉家老祖（称对方「孙兄、赵兄」，可知逍遥散人姓赵）：三人斗了大半生，后事已安排，索性放手一战，即便死也此生无憾——目光看向虚空，其内火焰燃烧。
- 逍遥散人（赵某）大笑相陪，双目内点燃火焰。
- 孙析洒脱道「舍得一身修，敢上天庭斥仙君」，同样决然。
- 三团战意如火焰怒燃：凡火焚烧可起狼烟，修士点燃元神虽不起狼烟，战意却浓十倍百倍千倍——呼应回目「狼烟起」。
- 柳眉轻声一句「燃烧元神么」，其声婉转动听如春风拂地，内蕴奇异之力；**逍遥散人眼中火焰渐暗，取而代之的是一丝痴迷**——章节至此断。

## 六、要点归纳

1. 天逆珠圆满线暂时受阻，转为「筹集大量升仙果 → 提炼迷药 → 回云霞星抽望月之骨」的新支线。
2. 云霞星＝沉睡望月，为后续埋下一颗超级战略级伏笔（其苏醒实力凌驾凌天候、天运子之上）。
3. 冉云星线全面爆发：幻家以锁星大阵封锁，为幻眉立威；三老燃元神死战，柳眉为幻家一方出手且展现精神/魅惑类奇异之力。
4. 「许木」是王林化名，三老的怨恨对象实为王林本人。
