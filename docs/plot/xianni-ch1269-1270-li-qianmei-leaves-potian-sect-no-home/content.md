# 第1269章、第1270章 没有了家……

## 一、玉简与天逆珠消失，生机推衍落空

- 王林悬于半空沉吟：他推衍出的一线生机，重点在刘金彪的那枚玉简上，但此刻玉简竟诡异消失，同时消失的还有**天逆珠子**。
- 变化始料未及，王林更多是不解，隐隐生出不安：「推衍的生机既然与这玉佩有关，但眼下玉佩与天逆都消失了，又该如何化解？」
- 真相补叙：刘金彪所送玉简本身平常，其上的**碎涅气息**是借玉佩内的**蜈蚣器灵**炮制而成，故不露破绽；八条蜈蚣全灭后气息消散，玉简遂成寻常之物。

## 二、遣散归元宗：留在五阶星域独面死劫

- 王林返回归元宗，吕烟菲等恭候，他心事重重仅略一点头。
- 吕烟菲禀报：归元宗已全部整理完毕，随时可离去（迁往**七阶星域**）。
- 王林沉默后决定：「你们先走吧，我还有一些琐事要处理，日后若有机会，我会去七阶星域找你们。」
- 归元宗于他有情：这里是他云海最初的落脚处，也是他获得云海身份（吕子浩）之地。
- 吕烟菲黯然、咬唇欲言又止，最终一躬身，率全宗门人踏入传送阵离去；每名弟子临走皆向王林恭敬一拜。

## 三、王林的决断与两把短剑

- 独坐空无一人的归元宗广场，王林眼中寒光毕露，自述推衍结果：
  - 所有出路结果**全部都是死亡**；
  - 随归元宗去七阶星域亦死；现在就逃也逃不掉；
  - 「我王林一生逆修，眼下既然无路可走，那么就要拼出一条路来。」
- 立誓：「第三步大能——若我此番劫难不死，早晚有一日，我要让第三步大能，也要在我面前低头。」
- 取出得自**七彩界**的两把短剑，其上封印始终未破，此番危机决意强行破封增添战力。
- 祭炼破封过程：两剑一白一黑，剑芒交错幻化千万剑影，卷动天地；黑白剑影自一万 → 五万 → 十万 → 三十万 → 五十万 → **百万**，形成连接天地的剑之风暴，传出惊天动地剑啸。

## 四、九阶星域·破天宗：李倩梅的囚与问

### 困局
- 李倩梅被三名破天宗**刑罚长老**以阵法封困，无法离去；其师尊即**破天宗宗主**，沉默如失生机。
- 李倩梅只求重返**妖宗战场**，师尊却称已向妖宗传出玉简，命她**三个月后**再去。
- 李倩梅由此推断：出动三长老并非为封她（以她修为不必如此），三长老实为**监视与作证**，且监视的对象是**师尊本人**；而既允她三月后返战场，可见此事与妖宗无关。

### 揭示：因「吕子浩」而起
- 宗主不顾长老「还请宗主三思」的劝阻，冷斥「我自有分寸」，直问：「你可认识一个叫做吕子浩之人？」
- 李倩梅答：当年奉师命去**五阶星域**寻**司马师兄（司马墨）**的遗物与玉简，途中遇到吕子浩。
- 宗主：「这，就是我困你三个月的原因。」
- 李倩梅立刻意识到：一股连师尊都无法撼动的生死危机已笼罩王林，师尊看似封困，实为保护她。

### 神宗与水道子
- 宗主抛出重讯：**八阶宗派的大比被神宗取消了**；能取消八阶大比者唯有神宗。
- **早在数年前，神宗之人便在调查吕子浩，直至他出现。**
- 发出取消命令的是**神宗大长老水道子**；宗主直言：以李倩梅之修为在水道子面前无用，纵使整个破天宗所有修士加起来亦无用。

## 五、三叩九拜与决裂：「没有了家」

- 李倩梅跪地叩首三次谢恩：
  1. 自幼孤女，蒙师尊养大，教她诚仁与道理，「虽是师尊，但在倩梅心中，师尊如父」；
  2. 师尊传道、助其炼丹，动用大量宗派药材，使她**千年时间即达碎涅**，因此惹得部分长老不满；
  3. 长老们常因她**蓝色头发**疑其为异族，有「非我族类，其心必异」之说，师尊却始终温和如父，甚至消耗自身元力助她炼化丹药以巩固基础。
- 表明去意的理由：「他心中有别人，那个女子在他心中很深，无人可以取代」；「仿佛前生，我是水面下的鱼儿，而他是那天空过去的飞鸟」；不能用值得与不值得衡量，若知晓一切却不去，此生不会快乐。
- 师尊坚拒后，李倩梅气机崩乱喷血，以**道消**相逼：「你可以不让弟子离开，但你不能阻止弟子道消。」师尊抬手一指落下印记，强行压住其崩溃元力。
- 李倩梅凄笑：「你能阻止倩梅一时，能阻止倩梅三个月，但你不能阻止我一生……他还没回答我第三个问题，即便是他真的死了，倩梅也要去他所在的世界，等待他回答那第三个问题。」并引师尊昔日教诲——修士当有执着与挣扎追寻的勇气。
- 师尊终于让步，却以断绝为条件：「踏出阵法，你就不再是我破天宗门下，也不再是我弟子……你一旦踏出，你就没有了师尊。」随即大袖挥碎封困阵法，冲击横扫。
- 三名刑罚长老色变质问，宗主暴喝「滚」，以**度过天人第三衰**的气息横扫，三长老喷血倒退。
- 李倩梅再深深磕**六个头**（合计九叩），师尊转头望天、心如撕裂，道「你走吧」。李倩梅泪流不止，最终化作长虹向天际茫然飞去：「没有家了……值么？」

## 六、破天宗的余波

- 一名被卷走的长老嘶吼要禀告神宗，威胁宗主为此付出代价。
- 宗主转身咆哮，天人衰劫修为爆发，将其震得连连喷血、**肉身崩溃**、元神尖叫逃遁。
- 宗主宣言：「破天宗做了神宗一万八年前的奴才，就连你们的修身之姓，也都被完全的奴役……李倩梅一旦招惹了水道子，所犯下一切责任，老夫一人承担。」
- 叙事者感叹：其声如雷，却震不开被神宗震慑数万年、道心被奴役的破天宗众修；如云海星域的星雾，看透雾气者能有几人。

## 七、结局定格

- 李倩梅所做一切（妖宗战场擅离、与破天宗决断），王林皆不知晓。
- 失去家的李倩梅，儿时孤独重新弥漫，萧瑟柔弱，独自飞向**五阶星域**。
- 同一时刻的五阶星域归元宗内，王林身前两剑封印渐破，百万黑白剑影卷成剑之风暴。
