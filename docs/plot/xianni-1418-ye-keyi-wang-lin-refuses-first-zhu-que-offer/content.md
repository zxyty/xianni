# 第1418章 也可以（第九卷 云海之巅）

## 一、一代朱雀论王林之道

### 破空五指与空门
- 破空五指是「凝聚破空之力的过程」：唯有把这力量修至巅峰、修到**第二步的极限**，借**本源之力**，方可一举轰开**空门**。

### 古神之体
- 一代朱雀见王林修成古神之体，目露奇芒，惊叹「没想到我朱雀一族后人居然能成古神」，并看向眉心之前的**血剑**。
- 其自陈对古神之修了解不多，但在它的时代，古神之强足以惊天动地：**当年道古**，尽管并未名列**仙尊**，但其修为足令仙尊忌惮。
- 王林追问「道古」，一代朱雀以「碍于当年誓言，不能告知」推拒，让其莫要再问，「若你有机缘，或许能自行寻找出那流逝在岁月之中的答案」，神色没落。

### 五道本源之困
- 若只修古神之体、以力证道轰开空门，或许更简单；但王林体内**同时出现了古往今来极为惊人的五道本源**。
- 规则：**本源越多，踏入第三步涅空境越难**。破局方向只有三条——
  1. 放弃所有本源，以**古神证道**；
  2. 放弃古神肉身、放弃四种本源，只余留一种修至圆满巅峰，借此入涅；
  3. （常规路）本源大成 + **香火辅助** + **道灵吞噬**，机缘巧合下踏入涅空——但一代朱雀在王林身上「并未感受到半点香火气息」。
- 结论：王林所走是一条艰难之路，与二代、四代完全不同，一代朱雀「无法帮你」。

## 二、一代朱雀开出的条件（本章核心提案）

| 项 | 内容 |
|---|---|
| 王林须付出 | 放弃**古神肉身**；舍弃看似大成实有瑕疵的**雷之本源**；舍弃除火外其余所有本源，只留**朱雀之火**一道本源；留在**天方界** |
| 一代朱雀给予 | **百年之内**助其踏入**第三步**；成第三步后传授**森罗炎**；与**二代、四代朱雀**一同安心修炼 |
| 长远承诺 | 待一代朱雀破开封印，带**三人**离开天方界，回到「我所来的世界」 |
| 名额上限 | 三人已是极限，**最多再给一个名额**，再多「怕是就无法回去了」 |

### 关于「离开这里」
- 王林察觉「离开这里」四字有端倪；一代朱雀目露追忆：「回到我所来的世界」。
- 随即封口：**「不要问，不能说，说了，就会死」**——「他们想要斗，想要抢，老夫累了，不愿参与进去，只想回家」，声音透出疲惫。

### 关于三步之后能否重修本源
- 王林追问：舍弃后成三步涅空，可否重修本源？
- 一代朱雀答：**自然可以**。三步涅空修士所修同样是本源，本源越多感悟越深、修为也会增长；**只不过无法圆满，此生止于第三步中**。
- 一代朱雀强调此路对王林无危险，是「坦荡大路」，**更不需放弃执念**——「老夫当年便是**业火临身**，知晓对于你我这种无法割舍执念之人，这执念的重要」。

## 三、诱惑与挣扎
- 此诱惑对王林而言，**甚至比当年蓝梦道尊所说更大**——因蓝梦道尊毕竟不是朱雀一族，王林心里更倾向一代朱雀所说。
- 王林心中响起低语：留在这里，不用经历腥风血雨、不用考虑生死危机；百年成三步大能，就算舍了本源与古神肉身，仍可重修，纵不能圆满，此生达第三步「也值了」；两千年修道的一次次生与死，「还没有让你畏惧么」。
- 王林反问名额：能否多带几人，「晚辈还有一些无法割舍之友」。得到「最多再加一个名额」的答复后，其眼中浮现**李慕婉、司徒南、清水、周茹、李倩梅**等两千年修道中一个个让他挣扎的身影。

## 四、李慕婉的棺木与复活可能
- 王林右手虚空一抓开启储物空间，飘出**一具棺木**，李慕婉平静躺于其中，仿若沉睡。王林血丝满目地问：「前辈可能让她复活？」
- 一代朱雀的判定：
  - 此棺**应是后人祭炼而出**，一代朱雀未曾见过，但可感受到其作用；
  - 李慕婉是**寿元断绝后元婴又受重创**而死亡；王林以此棺葬其元婴，重新形成了肉身；
  - **但这女子的魂，已经崩溃**；
  - 棺木奇异之处：可隐隐使崩溃于天地中的魂短时间不散，**若能找到正确的操控方法，或许能把碎魂一一找回**；
  - 然而即便集齐全部魂，**一代朱雀本身也做不到让她复活**。
- 转机：**在一代朱雀的家乡，有三人能让此魂融合、使此女复活**，但三人全是极为尊高之辈，一代朱雀无法请动，只承诺「我会尽力」。
- 王林绝望、痛苦如潮，默默收回棺木入储物空间。

## 五、王林的选择：「也可以」
- 王林指出那三人能做到必与修为有关，「他们的修为，应是深不可测」。
- 他坦承确实想安逸此生、疲惫于修真界生死与人心险诈，「即便是此生修道止于第三步，又有何妨」；
- **但**：「晚辈做不到求人之事，太过飘渺，生死在别人一念之间，没有属于我的选择。既如此，我索性不去求人，**他们可以，我王林，也可以**」。
- 「也可以」三字出口，如有无法形容的力量融入全身，露出惊天峥嵘，声音在天地间回音传荡，连一代朱雀也双目一凝。

### 王林自创之道（本章立道纲领）
- 「古神之体，我不能放弃；除火之外四道本源，我不能舍弃；就算这条路再艰难，我也要走下去，**我不能让我的修为止步**。」
- 逻辑推演：
  - **天人五衰**、**破空五指**都是修士自行悟出的、破空前的积蓄与准备 → 我为何不能同样自行悟出？
  - 一代朱雀曾言「五衰如指，唯有五指齐全，方可只手遮天」；
  - **古神之体 = 修行之掌**；**五道本源 = 五指**；
  - **一道本源大成 = 修为到了一衰**；**五道本源全部大成 = 天人五衰圆满修士**；
  - 由此轰开空门，成**王某自身之道**。
- 王林明言：**这五衰，晚辈不想去度**。他向一代朱雀一拜，双脚向前虚空迈去，踏在天空之中。

## 六、悬留线索
- 「道古」的真相被一代朱雀以誓言封口，留待王林自行寻找。
- 一代朱雀的「家乡世界」、其中「想斗想抢」的势力、以及能复活李慕婉的三位尊高之辈，皆为后续伏笔。
- 一代朱雀破开封印后的「离开」与四个名额的归属，成为未定悬念。
