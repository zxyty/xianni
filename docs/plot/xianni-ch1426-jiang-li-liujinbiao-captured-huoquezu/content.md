# 第九卷 云海之巅 第1426章 将离

## 一、战后余波：王林威名崛起

- 司墨子与云落大司一同离开大帝星，在王林目光中远去。
- 此战没有结果，出乎此地所有修士预料；连老朱雀也未料到，但以其修为隐隐看出了一些端倪。
- 数万修士仅凭方才交战的一幕幕，已将王林视为**能与第三步大能对抗的强者**，王林威名在颠落之地崛起。
- 落生会的长老之选自中断处继续，但已与王林无关。

## 二、火雀族擒获刘金彪

### 搜捕
- 大帝星试炼期间，火雀族视为绝佳机会，仔细搜寻刘金彪与许立国所在的蛮荒星。
- 在蛮荒星最深处找到闭关吐纳的刘金彪与其守护之灵许立国；一番恶战后刘金彪被擒，秘密送出颠落之地，与外围的火雀族老祖会和。

### 三重验证（太古星辰内）
火雀族老祖修为通天、心智极高且多疑，始终小心谨慎不敢踏入颠落之地半步：
1. **火焰横扫**：右手化火焰拍向刘金彪，火焰之力冲入体内横扫，发现其体内火焰之力不多，皱眉生疑。
2. **取血吞服**：挥手割开刘金彪右臂，卷走鲜血化作血球吞入腹中。血入腹化作强悍火焰之力爆发，身后浮现虚幻之幕——一条浑身火焰的火鸟展翅长鸣，其前一尊模糊、重伤未愈、神采黯淡的朱雀与之纠缠，很快被火鸟一口吞噬；吞噬后火鸟火焰浓郁，形态越来越像朱雀。老祖大喜：“果然是朱雀”。
3. **搜魂术**：老祖认为“天地间一切都可虚假，唯有搜魂术最真实”，右手按刘金彪天灵施展搜魂，一幕幕记忆浮现，神色满意，虽仍有些疑惑但断定此人是**六代朱雀**绝不会错。

### 刘金彪的应对
- 一路面色阴沉、一语不发，身上有一代宗师之气势与长期掌权、一语可灭万人的无形之威。
- 面对老祖出手神色毫无慌乱，目光透出无尽沧桑，其平静目光令老祖心神一震，暗忖“这种气势与威压唯有常年居高位者才有，此人若真是朱雀，就该如此”。
- 冷笑开口：“火雀小族，在老夫重伤闭关未愈之时偷袭，如你等先祖一样，跳梁小丑而已”——正中老祖疑虑，消解其对体内火焰之力不足的怀疑。
- 最终老祖大袖一甩，卷着刘金彪以大神通之术虚空一晃，急赴火雀族总部。

> **实为设局**：王林在大帝星睁眼确认“刘金彪的骗道之术果然高明，连火雀族老祖都被骗过，没找出任何破绽”，计划只等刘金彪被带入**火雀族圣地**后动手。

## 三、王林的准备

- 王林盘膝坐于老朱雀钓龙的湖泊旁，双手掐诀化作片片印记弥漫身周，禁制越叠越多，最终在体外形成一座**具传送之效的阵法**，开启后可以特殊方式穿梭而走。
- 尚有几样法宝需祭炼，只等“那边开启”。
- 托付老朱雀照顾其留在颠落之地的仆从**钟大洪**。
- 老朱雀已先行传授**炎龙的操控之法**。

## 四、临别赠予

### 1. 古魂禁
- 王林主动索要**赛场之上的古魂禁修炼方法**。
- 老朱雀答：古魂禁是**一代老祖当年抢来**的，连他也没有修炼方法；遂将该禁制赠予王林防身，让其凭悟性自行钻研。

### 2. 龟甲法宝
- 老朱雀向天一抓，风云倒卷、幽光闪烁，召来一头目光冷漠的**巨大龟兽**。
- 掐诀一指，巨龟自万丈之身急剧缩小，幽光愈缩愈刺目，瞬息化作**巴掌大小的一片龟甲**，幽光如月笼罩天地，赠予王林。
- 老朱雀拒绝道谢：“自家长辈给晚辈东西，还要晚辈道谢不成”。

### 3. 朱雀一族最强三术之一
- 作为帮忙的回报所传的一式神通，**传自远古仙尊**，为朱雀一族最强三术之一。
- 王林元阳已破，只可略作修行；此术威力太大、**会燃烧寿元**，轻易不可使用，仅作**保命之术**。

## 五、老朱雀的请托：七代朱雀人选

- 前提：王林**朱雀四次觉醒**，早已可以送出**朱雀印记**给族人。
- 要求：选七代朱雀**不能是风流之辈，不能贪恋半点美色、不能去碰**，须**定力过人**；最好**从娃娃中挑选**，免得长大后**元神之阳（元阳）被破**，修不了老朱雀的功法。选定后下次见面送来。
- 理由：老朱雀的神通“唯有元阳保存完好之人才可发挥最大威力”，并非有特殊癖好；他自称无数万年从未与人双修，元神之阳半点未消散，每日精力旺盛。
- 插曲：王林起初误解，答“定会谨慎斟酌，绝不会让**三代朱雀**之事重现”，又答“绝不会去选风流之辈……贪恋美色于修道没有好处”，老朱雀几次搓手、咬牙、瞪眼才说明白；王林呆立半晌，苦笑点头。

## 六、离别之情

- 老朱雀放下钓竿饮酒，沉声道“此去危机重重，不知下次相见为何日”，问王林还有什么要求。
- 王林与其相交仅数日，但对方的无私帮助与护短行径给了他少见的温暖，将别之际心中隐有伤感。
- 老朱雀慈祥而笑：“以后若有机会，我们祖孙二人还有相见之日，可不要如小孩子一样不舍，老夫下一次看见你时，希望你可以再让我震惊一下。”

## 七、后续伏笔

- 刘金彪被押往火雀族总部/圣地，王林已备好传送阵与法宝，只待“那边开启”即行动。
- 古魂禁修炼法无人可授，留待王林自行参悟。
- 七代朱雀人选（元阳未破的娃娃）成为王林对老朱雀的承诺。
