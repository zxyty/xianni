# 第九卷 云海之巅 · 第1293章 成我坐骑，饶你一命！

> 归属提示：本章「吕子浩」即【王林】的化名（自第1063章由吕烟菲奉上）。本章王林以此身份在云海星域行事。

## 一、妖宗的六星大阵

- 妖宗拥有**六个修真星**，六星成环形排列成一个圆圈。
- 这个看似简单的圆圈实为**一座大阵**，环绕惊天气息，其强足以轰灭天地。
- 大阵由妖宗无数年前被派到此地后，**当时的妖宗之主亲自布下**，是阻挡凶兽进攻的**最后一道防线**。

## 二、六山门与祖制

- 妖宗有**六个山门**，分别耸立于六个修真星之上。
- 每个山门内有**数个妖宗长老坐镇**。
- 六山门之间**很少来往，大都独自行动**——此现象由妖宗成立时**第一代也是最后一代宗主**亲自定下，延续至今。

## 三、齐天石碑与妖宗宗主

六个山门内各有一座**一模一样的齐天石碑**，碑上刻画：

| 元素 | 描述 |
| --- | --- |
| 中年男子 | 衣衫飘动，脚下有祥云，抬头看向天空 |
| 天空九只眼 | 好似凝望大地，与男子对视 |
| 身后巨树 | 苍天巨树，太大，天地都无法阻其延伸 |

- 碑上中年男子 = **妖宗第一代、也是最后一代宗主**。
- **苍天巨树 = 妖宗宗主的本命法宝**。
- **九只眼的含义**：寻常弟子不知，唯长老知晓——代表**远古仙域**。

## 四、宗主封印裂缝的旧事（传闻）

- 传闻当年妖宗宗主之强足以撼动天地。
- **很早之前，此地裂缝战场比现在大百倍不止**：无穷凶兽、众多王兽，甚至**皇兽**与传说中的**化人之兽**出现。
- 这些均被妖宗宗主**一一击毙**，更几乎把裂缝**彻底封印**。
- **意外**：封印刹那，似有人在裂缝内施展无法想象的神通，**生生阻止了封印**。
- **结果**：封印仍起作用——裂缝大范围缩小，且在封印隐隐作用下，裂缝内**太过强大的凶兽无法大量冲出**。

## 五、妖宗与神宗的渊源（长老间传闻）

- 妖宗之所以从**神宗**分离，是因**第一代宗主的命令**：命一部分神宗之人驻守裂缝战场外，**世世代代、千千万万年**，死死守住，不许任何一只凶兽活着冲出。
- 据说**神宗宗主与妖宗宗主实为同一人**。
- 据说此人**来自远古仙域**。
- 据说此人**已然失踪，生死不知**；现在的神宗实际是被此人**当年的奴仆代为操控**。
- 故妖宗**不接受神宗的命令**，更隐隐有**对抗神宗的手段**。
- 作者按：这一切都是传闻，真正的历史已沉入岁月长河，罕有人知晓清楚。

## 六、王林抵达裂缝战场

- 场景：妖宗外的战场裂缝处，**星空红芒滔天**。
- 王林与白发老妪连续赶路终于抵达；这一路王林几乎疯狂地展开速度，**从二阶星域赶来只用了不到数日**。
- 在场者反应（六大高手等）：
  - 认出「白婆子」——她**半个月前离开**，据说是**受妖宗之命、应李倩梅之求**去办一件事。
  - 六大高手中的老者：此人修为看不透，在他面前**竟有心神颤抖之感**，太强、诡异之极，连凶兽都惊恐后退，黑气所化骷髅感受到其临近也露出惊恐。
  - 冷漠女子：目光一扫，心神一震——**自己的神识与目光在临近对方刹那无声无息崩溃**；并猜测「他莫非就是李倩梅受妖宗惩罚去往裂缝深处的原因所在」。
  - 三个被蓝色雾气弥漫之人立刻警惕，其中一人出声问「白婆子，他是谁」。

## 七、一挥灭尽凶兽

- 白衣老妪正要回答，王林已一步迈出，**直奔那缓缓打开、传出咆哮的裂缝**而去。
- 随其前行，退缩到裂缝旁、挣扎着要回去的**骷髅与凶兽发出惊恐尖叫**。
- 「**聒噪**」——王林身影太快，瞬息临近，**右手随意一挥**，轰然间掀起一股**蕴含无尽雷霆的风暴**，弥漫整个裂缝。
- 一只只凶兽惨叫中**全部崩溃而亡**，裂缝外凶兽齐齐化作血肉。
- 这一切对王林极为轻松；他之所以出手，是因**焦虑李倩梅此刻的状态**，凶兽刺耳尖叫令他心烦。
- 四周瞬息一片安静，连**裂缝内的九幽龙咆哮也不由一顿**。

## 八、悬念与看点

- 妖宗宗主 = 神宗宗主 = 来自远古仙域之人，且现神宗由其奴仆代掌——为后续神宗/妖宗对立埋线。
- 当年裂缝内阻止封印者身份不明。
- 李倩梅被罚往裂缝深处，王林此来为救她；章名「成我坐骑，饶你一命」指向下文与九幽龙的对决。

## 场景与背景

王林（本章以化名『吕子浩』行事，自第1063章由吕烟菲奉上此身份）随白衣老妪（白婆子）抵达一处正缓缓张开的裂缝之外。此地聚集数千修士，其中有六大强者，另有三名妖宗之人在场。裂缝外有大量由黑气所化的骷髅，见到王林如遇天敌般颤抖。

## 关键情节

### 一、吞噬骷髅魔头

- 王林早年在**朱雀星的域外战场**内成为**吞魂**，并吞噬过大量**寂灭界的魔头**，故一眼看出这些骷髅身上带有魔头气息。
- 王林张口一吸，全身化作巨大漩涡，此地骷髅（数量『不多但也不少』）连同最大的那具，皆在颤抖中不敢反抗，尽数崩溃化作黑气被吸入其口。
- 挥手崩溃凶兽、呼吸间瓦解全部骷髅——除白衣老妪外，在场所有人心神震撼。

### 二、旁观者的评估

- 六大强者瞳孔收缩，震撼失色。
- 三名妖宗之人传音评估：
  - 「最少是天人第一衰，只是为何他身上没有天人光环」
  - 猜测其有神通可隐藏天人光环。
  - 联想到白婆子此前是为**送李倩梅的命魂玉简**而去，遂怀疑此人与李倩梅命魂玉简有关，心生警惕。
- 白衣老妪已然麻木：她一路见识王林手段——**无极宗六位太上长老都不敢阻其脚步，其中二老更被王林崩溃了肉身**——眼下杀几只凶兽在她看来不算什么。

### 三、确认李倩梅去向并强撕裂缝

- 王林感受到裂缝内传出一股强大气息，「似乎在犹豫、在隐忍」。
- 王林转身平静发问：「李倩梅，就是进入了这里」，语气如火山爆发前的寂灭；白衣老妪立刻点头确认。
- 王林时间紧迫，不等裂缝自行张开，双手虚空一抓、体内爆发疯狂气息，低喝之下狠狠一撕，**生生把裂缝撕裂**。

### 四、降服九幽龙

- 撕裂之前，被蓝色雾气弥漫的妖宗之人急劝：「道友住手，那裂缝内有九幽龙，此龙极为强大，一旦出现，此地会死亡众多」，请求等众人**组成阵法**再开；三人更冲向裂缝阻拦。王林置若罔闻。
- 裂缝撕开刹那，**九幽龙**咆哮而出：身长数千丈，双目凶残疯狂，鳞片间隙与大口喷出大量黑气黑雾，直奔王林吞噬而来。
- 王林不闪不避，寒声「孽畜，也敢吞我」，右手向前一拍——无尽天地之力凝聚入掌，化作巨大掌印正落九幽龙面门。九幽龙惨叫，全身裂开无数口子、鲜血爆出、急退，龙目中的凶残被恐惧取代。
- 王林见其未死，一步踏入裂缝内，再抬右手一拍，**砸断九幽龙两根角**，此龙惊恐畏惧。
- 两下神通后龙仍未死，王林身子一晃踏在龙头上，开口：「**成我坐骑，饶你一命**」。

## 动机与后果

- 王林此行目的明确：追查进入裂缝的**李倩梅**（据世界状态须知，李倩梅已于第1202章死亡，白衣老妪送的正是其命魂玉简）。
- 收服九幽龙的直接理由：王林对裂缝内不熟悉，有此龙可「方便很多」，即用作坐骑兼向导。
- 王林的强横引发妖宗势力的猜疑与警惕，其身份（无天人光环却有天人级战力）成为在场修士的疑点。
