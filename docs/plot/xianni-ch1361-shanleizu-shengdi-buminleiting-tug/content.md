# 第1361章 给我下来！！（第九卷 云海之巅）

## 一、心理战：以大长老残神摧毁闪雷族军心

- 王林事先在防护大阵外放话「大长老已被擒」，料定以大长老威严无人肯信，实为埋下种子。
- 破阵瞬间族人心神一乱，王林随即取出**昆极鞭**——不必挥抽，仅凭鞭上卷着的大长老一缕残余元神，便如无形之鞭抽在所有目击者心上。
- 闪雷族哗然：大长老是全族精神支柱、视如神灵的先祖；亲见其残神后，众人确认「肉身崩溃、元神险些身亡、不灭圣雷虚弱而回」的说法为真，精神支柱彻底坍塌。

> 归属说明：本章行为主体为**王林**（自第1242章以一部分元神夺舍**于非**之身潜入闪雷族；第1275章元神飞出，身份已暴露）。

## 二、瞬杀天人第四衰修士

- 乱局瞬间，王林踏雷龙疾驰，右手挥出**血剑**横扫而去，直取人群中一名**天人第四衰**修士。
- 血剑自其眉心贯穿，肉身崩溃；元神尖叫逃遁，被血剑追上再度洞穿，当场身死。
- 战力标尺（本章明言）：王林眼下真正之力**可胜天人第三衰**；面对天人第四衰需有波折。此番近乎瞬杀，得益于①对方心神震乱 ②双方同为雷修（若非雷修，王林亦要苦战）。

## 三、撞破闪雷族圣地

- 圣地位置：**十六颗修真星中间**；此为王林第二次来临。
- 王林盘膝坐于雷龙头顶，双手掐诀，全身修为与雷龙融合不分彼此；雷龙咆哮撞向圣地。
- 结果：圣地防护大阵一撞爆碎；圣地大陆剧震，不规则边缘崩溃化作碎石消散，地面撕开道道巨大裂缝。
- 圣地中心的**闪雷族庙宇**：其上自虚无降临的**不灭雷霆**已明显虚弱，被撞破护阵瞬间自内爆出雷电之力，波及庙宇使其崩溃成粉末。
- 王林途中嘱托同伴：「这些人心神已乱，散灵道友，以你修为，足以」——分兵由**散灵上人**压制族人。

## 四、夺雷：与漩涡内未知存在的拉锯

1. 不灭雷霆察觉危机，收缩并向星空遁去；其上方虚无中浮现一个**闪电游走的巨大漩涡**，正是它的去向。
2. 王林飞至漩涡下方，此时雷霆大半已入漩涡，仅余部分在外。他双手虚空一抓，死死抓住并向下猛拽，大喝「给我下来」。
3. 漩涡内传出咆哮与巨力，王林喷血难抗，雷霆再入大半，外露不足几十丈，王林自身几乎被拖入漩涡。
4. 王林施展**古神之体**：眉心**古神星点**骤旋成风，身躯暴涨至近千丈化作**古神真身**，双臂无限粗大，血液狂涌、心脏巨震，古神之力自每一丝血肉骨头爆出，与心跳融合成「绝天地之吼」。
5. 第一次狠拽：将不灭雷霆自漩涡生生拽出**百丈**。漩涡内再传巨力争夺。
6. 第二次狠拽：再拽出**数百丈**，漩涡内传来愤怒吼声。圣地四周无数闪雷族修士目瞪口呆。

### 漩涡内的警告

> 「汝，立刻放手，此雷非一人可拥有之物，若再冥顽，吾会将你灭杀」

- 声如天威，落于星空使**太古星辰**为之一震，星辰内无数人清晰听到。
- 王林对漩涡内气息极为陌生并隐生惊惧、头皮发麻，自比「当年散灵上人在七百万天地内第一次走出、看到所谓仙界」时的感受。
- 王林的逆意：「这不灭雷霆是王某看中之物，谁也不能和我抢——抢仙抢杀仙，神夺弑神」；他刚经历七百万天地无数生灵为自由与生存的洗礼。
- 动机复盘：潜伏、拼杀、与散灵一同轰杀大长老，目的即为**吞噬闪雷族不灭雷霆**。

## 五、余波：蓝丝族的反应

- **蓝丝族·蓝山**之上，**李倩梅**平静远望，目中时而迷茫挣扎，一种她无法割舍与遗忘的记忆正在慢慢苏醒。
- 其身旁**蓝梦道尊**原在摩挲古琴，闻天威之声后面色大变，猛地自屋舍晃至天空，双目寒光直勾勾盯住无尽星空。

## 六、悬念

- 漩涡通往何处、其内自称能「灭杀」王林者为何方存在，均未揭示。
- 不灭雷霆归属未定，争夺仍在进行中。
- 李倩梅苏醒中的记忆与其旧身份的关联被再次点出（注：李倩梅本人已于第1202章身死，此处为蓝丝族中的其人，记忆苏醒线索待续）。
