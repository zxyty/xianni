# 第1143章 紫气西来

## 一、背景：雨季中的归元宗
- 雨季连绵数月不绝，乌云压顶，风穿山脉灌入归元宗所在盆地，形成呜咽漩涡。
- 王林（化名「曾牛」）入归元宗已十天，身份为负责照顾药草的凡人杂役。

## 二、孙芸的怀疑与试探
- 孙芸自师尊处归来后，暗中调查三十一名来自北部的凡人，一无所获；单独观察王林，也未发现任何端倪。
- 其师尊**吕烟菲**同样重视此事，亲自施展神通探查线索，结果依旧。
- 「白衣白发之影与那一指的风姿」在孙芸心中不但未淡，反而愈发深刻，午夜打坐醒来常浮现眼前；「他到底是谁」成为困扰。
- 午后孙芸推门而出（雨水在其身半丈外被无形罩子挡开），下意识走向王林屋舍，直接推门质问：让你来照顾药草，可曾做过一次？
- 王林正读典籍阁借来的木简，只平淡反问：「可有药草死过一支？」——这段时日药草反而更葱郁，连准备放弃的残根都活了。
- 孙芸强辩为「此地灵气充足＋水生药草吸收雨中天地之力」，王林敷衍一句「哦」，继续看简。
- 孙芸怒唤「曾牛」，与王林目光对视时却下意识咽下训斥，心神一怔；王林冷淡道「曾某的工作，是不让这些药草死去，若无他事，劳烦莫要打扰」。
- 孙芸芳心一颤，暗问「是他么」，沉默后深深看王林一眼，转身离去。
- 细节：孙芸走入屋内时清香弥漫，王林认出正是当日在其打坐处闻到的体香。

## 三、王林的读简与心思
- 木简为新入门弟子皆可借阅之物，内容是莫罗大陆历史与云海星域的简单介绍，用意在使新弟子明白「人外有人山外有山」而刻苦修行。
- 王林借此对云海有了不算清晰的了解；同时心神主要放在**炼丹与灵兽**上，结合四天前所看玉简已有收获。

## 四、夜探悬空道观
- 深夜，王林目光穿透屋舍直望盆地上空——由**八个巨大石柱撑起的悬空道观**，其中气息不弱。
- 王林身形一晃现于石柱顶部，风雨雷霆呼啸中推门而入。
- 道观正中是一个**巨大空间裂缝**，透出紫光将道观染成一片紫色；裂缝后的架子有禁制波动，放着三样物品：**一把长剑、一枚玉简、一颗丹药**（显为归元宗老祖所留传承之物）。
- **紫目蟒**（紫目莽）自裂缝探出硕大蟒头，通体紫黑、双目蕴紫，凡被注视者心神一震——对王林全无作用。
  - 修为可与**窥涅后期**修士一斗，但在王林眼中「杀之极易」。
  - 四天前王林已险些将其斩下，因要在归元宗住一段时日、刚来就杀护宗灵兽说不过去，才留其性命。
  - 本章紫目蟒低吼却露惧色，连连后退，任王林走过而不敢攻击。

## 五、云海炼丹体系的求证
- 王林右手一挥，架上禁制尽数消散。
- 重看玉简：对归元宗功法神通不感兴趣，唯重视其中**灵兽与炼丹**的记述。
- 结论（玉简所载 + 本章验证）：
  - 云海星域**灵兽共十三阶**；
  - **以灵兽之魂入药**，炼成之丹相应分为**十三阶**。
- 架上丹药为归元宗代代相传的**八阶离魂丹**，但**未融入八阶灵兽之魂**，是一枚**废丹**；王林四天前初见未看出端倪，经四日琢磨后此次前来正为求证，望之即已确定。
- 处置：**未取走**三样传承之物——「这种绝其门派之户的事情，在没有仇隙的情况下，以王林的修为，不屑去做」，「他只需看，就足以」。
- 定策：「眼下需要亲自以这云海炼丹的方法，炼化丹药」；**在云海星域的目标是尽一切可能提高修为**。

## 六、设定：莫罗大陆与黑塔、灵兽与凶兽
- 莫罗大陆漂浮于云海星域，其上有一座**黑塔**散发柔和之芒笼罩整个大陆：
  - 使**星雾**略有后退；
  - 提供防护，防外宗修士，更主要防云海无边际的**凶兽**。
- 兽分两类：被修士驯化者＝**灵兽**；在星雾内漂游、与修士不死不休者＝**凶兽**。

## 七、转折：西部黑塔防护崩溃
- 王林正欲离去时猛然抬头、目露奇芒：莫罗大陆**西部边缘**天空电光闪烁、闷响回荡，如有人自外界向内轰击。
- 西部黑塔防护之光不断扭曲，最终在一声惊天巨响下**轰然崩溃**，轰鸣压过雷霆与雨声传遍全大陆，清晰传入归元宗。
- 破界而入者：一头**身长百丈、通体漆黑、形如蝌蚪**的庞大灵兽，自破口一点点挤入莫罗大陆。
- 关键：仅凭该灵兽破不开大陆防护——其背上一名**一脸桀骜的老者**缓缓收回右手，**右手上有紫风环绕**（呼应回目「紫气西来」）。

## 八、悬念与看点
- 孙芸已接近怀疑「曾牛即那白发一指之人」，身份暴露风险上升。
- 王林掌握云海炼丹脉络，后续将亲自炼丹并猎取灵兽之魂。
- 紫风老者自西方破塔而入，为下一段冲突的直接引信。
