# 仙逆 第1646章 与司徒一醉

## 一、离开远古仙域

- 王林带着与**四大战将**的约定，一天后顺着来路离开远古仙域。
- **进出机制**：远古仙域只有在天劫下方才可开启，无论进出都要通过天劫产生的裂缝。
- **封印性质**：该裂缝即是远古仙域的封印。具有仙人血脉的**仙罡大陆**之人很难从裂缝走出，除非倾所有人之力相送——当年送出**上代封尊**便是如此。
- 王林判断：**天逆珠**或许才是通过此裂缝的最关键之物。
- 踏出裂缝后，裂缝在其身后慢慢收缩，直至完全消失无影。

## 二、王林的迷茫：星空第一次显得虚幻

- 王林进入远古仙域前对天地结构有诸多猜测，出来时已明白了很多。
- 望着星空，这星空第一次在他眼中如此虚幻，仿佛不存在一样。
- **界内界外只是一座仙尊洞府**这一事实，他无法与人言：说了少有人信，真有人信也只会疯狂。

### 对「封尊」的重估

王林心中所想：上代封尊也只是仙尊的手下，不是界内之人，来自仙罡大陆、拥有仙人血脉；他来到界内不是为了帮助，而是为其主仙尊布局。他是迂腐之人，或许在界内的岁月中对界内之民生出怜悯，故有之后的一些事，但归根结底，他终究是个外人。

### 与散灵上人的共鸣

王林想到**七百万天地**内的**散灵上人**，认为二人经历很像；但散灵上人要比自己幸福，因为他认为自己已经来到了真正的天地、走了出来。

## 三、朱雀星外的守候与沉默

- 天劫雾气早已消散，包括司徒南在内的**数千修士**仍等在朱雀星外，等王林回来。
- 王林身影一现，欢呼骤起，众修士狂热呼唤其名与「**封尊**」二字。
- 王林听到「封尊」更加沉默，隐隐迷茫；他的沉默被众人察觉，呼声渐消。
- 王林心中苦涩，想告诉众人：**我们只是生活在一座洞府内；所见之天不是天，所见之地不是真正的大地；界内界外的一次次战争只是别人眼中的一场游戏；所修神通、所追求的道路也都是虚假的。真实的唯有鲜血、痛苦，以及无数年来死亡的一具具骸骨。** 但他无法开口。
- 数千修士在朱雀星上盘膝吐纳，等王林下山，带他们去**罗天**、解罗天之危、守护界内。

## 四、无名山顶：与司徒一醉

司徒南察觉王林目中迷茫与疲惫，不解其入裂缝时豪情万丈、出来却如此低迷。王林开口：「司徒，有酒么，我想再醉一次，最后一次。」司徒南未多问，只答「有」「你要醉，我便陪你一醉」。二人坐于朱雀星一座**无名山顶**，默默喝酒直至天边泛白。

### 对话要点

| 议题 | 王林 | 司徒南 |
|---|---|---|
| 人为什么活着 | 迷茫、苦笑摇头 | 「为了喘息一口气」 |
| 长生 | 长生了又如何：看爱人死亡、亲人魂散、朋友闭眼，最后只剩一颗冷漠的心与疲惫的身子 | 世间没有长生；所谓长生只是活得更久、更强、更逍遥、无人可左右；人追求长生只因害怕死亡 |
| 七情六欲 | 当年（炼气期）舍不得父母与俗世之情，不想斩 | 修道之人可不斩七情六欲；斩不断又不想斩，便自然有此痛苦 |

### 王林自述的两千余年修道史

1. **年少为父母期望**，咬牙入**恒岳派**；
2. 命运弄人，为父母期望而修道，最终却成为导致**父母死亡**的根源；
3. 此后**为复仇而修道，成魔**，杀**藤家满门**，血流成河；
4. 复仇后迷茫：看着**大牛**长大、看着大牛父母死去、看着他的一生，不知道路在何方；
5. 直至**婉儿（李慕婉）**死亡，才为复活她而修道——要变强、要生存、不甘在婉儿苏醒前死去，要把她从命运中抢回；
6. 而后成为**封尊**，在界外界内的一次次战斗中名震天地。

王林结论：「这一切，不是我想要的，我也不想成为封尊，我依旧还是厌烦修道」「我从来就不想修道」。司徒南无言，长叹后闷酒，只道「你既然不愿和老子说在那裂缝看到了什么，老子不问了行不」。

## 五、天明吐真相

天边泛白、初阳将现时，王林终于开口：

1. **「那裂缝，是远古仙域。」** 司徒南猛然起身望天，震惊追问其中是否有真正的仙人。
2. **「看见了，我杀了一个仙人。」** 司徒南呆立后苦笑，并据王林性格推断其必定搜了那仙人的记忆。
3. 王林承认**搜索了这仙人的记忆**，由此知晓有关界内界外、这天地一切存在的秘密。
4. 王林连番反问式揭示：
   - 界内界外一切**全部都是虚假的**，就算真实存在也依旧虚幻；
   - 你我、所有道友、这个成长诞生的世界，**只是一个牢笼**；
   - 所谓修道，**所修的全部都是别人规定的**；
   - 我们存在的这个世界，**只是一个远古仙尊的洞府**，亦或说是其开辟出的**收集香火的香火界**。
5. 司徒南手中酒壶无意识松开，咣当落地——「你说什么？」

## 六、悬念与后续指向

- 数千修士仍在等王林带队前往**罗天**解危，王林尚未下山。
- 王林与四大战将的约定内容本章未展开。
- 真相已向司徒南揭开一角，司徒南的反应止于震惊，尚未回应。
