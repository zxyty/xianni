# 第1930章 非仙罡之灵！

## 一、九十八道定身术：定住海子天尊

- **战法**：王林体内五条神脉所化漩涡急速转动，速度快到一动之下幻化出 **九十七道残影**，与本体合为 **九十八身**，每一残影与本体一模一样、极为真实。
- **神通**：九十八身齐施 **定身术**，同时伸右手向下方绝美女子（海子天尊）一指；随后九十七残影凝聚回本体，天地间化出一根似可支撑天地的 **巨大手指虚影**，直点海子天尊。
- **战果**：一指之下海风停、海浪静、天地运转一顿；海子天尊全身一震，右手停在半空，连体内元神亦被定住。她首次见王林全力出手，心惊失色。
- **代价**：王林面色苍白，此一指爆发了全部力量。定身术叠至九十八次后，隐隐出现一种他说不出的变化，**与当年道一天尊神念分身出现时的一幕极为相似**。
- **态度**：「你我没有仇隙，我不想杀你」——定而不杀，随即遁向海底。

## 二、五十年前后的实力对比（关键设定）

| | 五十年前 | 如今（第1930章） |
|---|---|---|
| 是否需魂铠 | 需穿魂铠方能施展 | 不穿魂铠已可胜很多天尊，含当年的道魔宗天尊老祖 |
| 战绩 | 逼道魔宗天尊老祖骇然倒卷，触发道一大天尊所赐道袍；被道一大天尊一丝神念一拳轰开 | 修为完全融会贯通、达到足以操控的完美 |
| 神通结构 | 九十八道神通融为一体但无法凝成真正一道，**如同有兵而无将** | 以九道神通融入身体，凭真身之奇异压缩凝聚，达 **三十六道神通** 的程度，**如兵有将**，威力暴增 |

> 修为暴增来源：绿魔蝎庙（蝎庙）所得，再经五十年连续挑战打磨。

## 三、海底之行：山海树与山海树灵

- **时序（以「息」计）**：第4息抵海底最深处（重压足以挤爆寻常修士肉身，道古身躯无碍）→ 一拳轰开海底，海水化九十八道漩涡，轰出黑洞般入口 → 第6息海面章鱼海兽仍被定住 → 第8息抵达山海最下方 → 第10息取灵 → 第15息动手抓碎片。
- **前置**：王林在山海三年内早已勘察，知晓如何找到撑起山海的 **山海树**。
- **山海树**：黑洞之内是一片被海水淹没的虚无，巨树足有半个山海大小，树干枯萎，枝干蔓延支撑整个山海；弥漫死亡气息，笼罩层层封印，另有浓郁杀戮之气，仿若曾杀戮无数。
- **山海树灵**：山海树魂死亡后幻化，拳头大小的绿色光团，**可让修士诞生木本源**。古往今来被取走不少，如今仅剩七个；这些树灵全部透出封印漂浮在外，封印对其似不起作用。
- **收获**：王林大袖一甩，**七取其六**，收入储物空间。

## 四、转折：仙极剑碎片与「非仙罡之灵」

1. **异动**：转身瞬间王林双目刺痛、金光不受控闪烁，感到山海树内有奇异召唤。
2. **根源**：其双目曾被 **绿魔蝎庙的老者** 融入一枚 **仙极剑碎片**，使目光具威严如剑、拥镇压之力——同类相召。
3. **现身**：山海树内飞出一枚巴掌大小金色碎片，将穿封印时被爆发的封印之力卡住，只露出一半在外；王林双目金光更烈，似眼中碎片欲冲出。
4. **仙极剑传说（王林五十余年考据，真伪难辨）**：
   - 版本A：仙祖与 **绿魔蝎** 一战中被蝎尾撞碎——但几乎每一洲封印的天外之灵都有类似说法，王林已听到不下十个。
   - 版本B：仙祖失踪之后仙极剑自行崩溃爆开，化作数块碎片流散至仙族领域多处。
5. **决断**：判断「这封印是仙祖布置，要取此碎片很可能引动封印之力」，遂 **后退数步、不以本体犯险**，幻化 **雷霆真身** 前去抓取（自忖「绿魔庙也有封印，当年并无大碍，但眼下这封印似有些不同……不过富贵险中求」）。
6. **触发**：雷霆真身抓住碎片刹那，封印之力轰然爆发，卡住碎片处荡开圈圈波纹，化作一张充满威严的 **巨大面孔**，镇压直奔雷霆真身。
7. **判词**：古老之声回响海底——**「发现，非仙罡之灵，封印」**；王林目光一闪：「果然有问题」。

## 五、旁枝

## 六、悬念

- 「非仙罡之灵」意味着王林（或其体内之物 / 雷霆真身）被仙祖封印体系判定为**并非仙罡出身之灵**，直接触发封印镇压。
- 第七个山海树灵未取；仙极剑碎片尚未到手；封印面孔与王林雷霆真身的对抗结果待下章。
