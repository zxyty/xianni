# 第1749章 空灭初现！

## 场景
- **罗天星域东部**一颗寻常修真星：灵气不浓，历经数次大战后修士所剩极少，多为筑基、结丹之流，宗派荒废。
- 时值秋天，山峦间一处幽谷长满只在秋天开放的**秋兰**，花期不足一季，寒冬即枯萎覆雪。谷内兰花深处有一间悠久破旧的屋舍。
- 屋舍外坐着一位青衣皱纹老者——**谢青**，望兰恫怅，剧烈咳嗽、面色异样红润，手心有兰花状幽光**印记**。

## 师徒相见
- 秋风送来白衣**王林**。谢青跪拜：「弟子谢青，拜见师尊。」
- 谢青自陈身份：**「七彩仙尊第三魂，是我。但我，是谢青，不是他（苏道）。」** 记忆部分苏醒后他曾逃避、挣扎、不甘，最终认定自己是谢青。
- 王林心痛：与谢青相处虽不久，但在他心里对方与**十三**一样，都是他的弟子。王林重情。

## 谢青的推演与死志
- 第三魂**只有记忆，无神通、无感悟**，魂强而无自保之力，逃了多年已至末路。
- 追猎者：**第一魂、第二魂**，以及七彩仙尊旧部**四大战将**（心思已变、另有所图）。落入任何一方之手，结局都是被吞噬。
- 七魄局势：已有**五魄彻底分离**，余下**两魄**仍会凝聚而来，而那两魄「是师尊极为重要之人」。
- 死局逻辑（谢青原话）：
  - 我不死 → 第三魂不出；
  - 我不死 → 他们（两魄之人）会死；
  - 我不死 → 七彩三魂归一 → 师尊会死。
- 结论：「与其让别人吞噬，不如送给师尊。」

## 三道封印（谢青以魂修之力凝聚，代价是心魂重损）
1. **第一道**：不需外力、可自行引动。谢青一旦死亡，第三魂**不入轮回**，王林可将其收走；第三魂在其死后完全苏醒，会自行打开**洞府核心之地**、推开大门，让王林得以离开**洞府界**。
2. **第二、三道**：留给王林——在推开洞府通往**仙罡之地**大门的一刹那，借突然涌入的**仙罡大陆之力**配合两道封印，去封印其余两魂（原文写作「第二魂、第三魂」）。

> 谢青说到此处呕血洒于兰花之上，染红花朵——心魂损耗太大所致。

## 王林的两难与誓言
- 王林此前曾对**清水（清水仙君）**言明会杀这第三魂以保清水安全；此刻却做不到——「这不是妇人之仁，这是**杀子之择**」。
- 王林抬头向天咆哮：
  - 「我王林从**轮回天劫**内找回了自己的命运，我成为了**天道的主人**，但为什么，我还是无法决断自己的人生？」
  - 「无论是你洞府界的天，还是仙罡大陆的天……若天如此不仁，那我王林在此发誓，**我这一生，誓要灭天**！」

## 空灭初现
- 誓言刹那，王林全身气势如烟丝升空、旋即凝聚成一把**虚幻之剑**，爆发出碎空灭天的惊人气息。
- 随行的**玄罗大天尊**在洞府界**第一次神色大变**——只有他能看见那把剑：「**空灭之气**！这是空灭的气息！此子誓言，居然能幻化出空灭气息！」

## 谢青之死与第三魂苏醒
- 谢青流泪磕头：「我心魂损耗严重，一直在等师尊前来……不需师尊出手，我已是弥留之中。这是我最后一次，唤一声师尊。」眷恋看了一眼兰花，闭目、含笑、气绝身亡。
- 死时七窍弥漫无形**魂丝**＝第三魂，内含第三魂**一次次轮回中的记忆**及谢青一生；因封印不能重入轮回，记忆**急速消散**，散尽则「谢青此人将永久消失」。
- 王林低头怒道**「这不是最后一次」**，上前一步立于谢青身边，右手一挥抓住第三魂。
- 第三魂**完全苏醒**：天地色变，修真星剧烈轰鸣，星空被卷动，**四大星域齐齐一震**；**界外**同一瞬亦发生惊天变化。
