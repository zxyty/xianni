# 第1342章 雷修大能之路！（第九卷 云海之巅）

## 一、七百万天地的规则复述
- 七百万天地中存在七百万个世界，无边无际、似无尽头。
- 进入其中的闪雷族修士不必盲目寻找渡劫者：一旦有渡劫者出现，其所持**灵符**会自行察觉，使距离最近的闪雷族修士瞬移而去、**化身天道**。
- 王林在这片星空中疾驰，穿过一处处几乎无法与现实分清的世界，面色阴沉、内心复杂，长叹一声后开始清点收获。

## 二、族印清点与近千丝残缺念雷的融合
- 王林右手虚空一翻，取出**十多个闪雷族族印**，一一捏碎，从中爆出大量可换取雷晶之物，尽数收起。
- 族印内另有**丝丝幽光雷霆**——即**不完整的灵念之雷**，数目近千。
  - 来源：张景云等人多年来在七百万世界谋害众多新进入者后搜刮所得。
  - 数量足够：融合在一起可组成**一道完整的灵念之雷**。
- 融合结果的形态：不再像雷霆，而是**絮状气烟环绕成球**，其内隐现无数人之面孔、闪烁变换；散出一股与王林所修雷霆**完全不同**的奇异雷力。

## 三、太古记忆开启——雷之本源的真相
- 念雷出现刹那，王林右目雷光急闪；气烟球不受控制直奔右目，瞬息穿透，**融入元神**，并与元神中的**雷之本源**相融。
- 雷鸣在体内疯狂回荡，王林长发无风自动，浑身雷霆好似骄阳万丈，向星空四周宣泄。
- 元神轰鸣中，**来自太古的记忆碎片**如风暴般爆发：这是雷之本源蕴含的、传承至**天地初开第一道诞生的雷霆**的记忆，万古罕有开启；因吸收一道完整念雷而打开缺口，宣泄出一丝。

### 画面所示的完整雷之本源
- 一道无尽雷霆自虚无轰下，光芒万丈，蕴含无法形容的强大本源气息。
- 其四周有**九种各自不同的闪电雷霆**环绕，彼此形成奇异图案。
- **本源之雷在中、九种伴随之雷在外**，旋转之下自成天地，充满完美之感——此即真真正正的雷之本源。

### 天音法则
> 「九雷为限，伴本源而生，九之上为十，十为圆满，本源大成」

- 声音如雷霆、透出无尽沧桑，好似从上古破开时光岁月传来。

## 四、王林的所得与推论
- 清醒后仍立于星空，衣衫被汗水浸湿，眼露震惊。
- **右目变化**：原本仅有一道闪电印记，此刻印记旁多出**一丝略小的第二道闪电**；每环绕转动一圈，雷之本源便缓缓增长。一股对天地雷霆更深的明悟弥漫心中。
- 推论四条：
  1. 闪雷族称「雷分六道」是错的——连闪雷族自己也不知晓，雷实为**九道**，且九道皆为**伴随之雷**，所伴随者正是雷之本源；故真正圆满之雷共**十道**。
  2. 王林的雷之本源早已出现，与闪雷族的**不灭之雷**同等存在——不灭之雷同样由雷之本源而生，吸收可壮大本源。
  3. 若能陆续找到并吸收其余九种伴随之雷，**雷之本源可大成**。
  4. 甚至可以雷之本源**突破修道第二步的壁障，成为第三步雷修大能**。
- **进度**：九种伴随之雷中已得**灵念之雷**一种，**还差八道**。
- 王林感慨：这一切与闪雷族有千丝万缕关系；若非混入闪雷族并进入七百万天地，他极可能一生至死都无法明悟雷之真正圆满——**闪雷族在无意之下给了他一场夺天地的大造化**。
- 心神一动，右目瞳孔中雷霆呼啸而出飘于身前：本源雷霆印记在中、勃勃生机，外有一道略小念雷环绕，与所见画面极为相似，只缺另外八道；可惜这一道伴生灵念之雷仍太过弱小，虽说一道，看去却只有一丝。

## 五、择路：不杀渡劫者，只杀闪雷族
- 王林自语：「屠杀渡劫修士凝聚念雷，此事我不愿去做，但杀闪雷族之人，从他们身上获得念雷，却是可以。」
- 冷笑中身影消失，神识化作波纹散开——**一场噩梦在七百万天地内展开**。

## 六、雷霆风暴血洗
- 首战：数名闪雷族修士（最低问鼎、最高阳实）飞行搜寻，正议论「已连灭四个下界渡劫修士却无一人诞生念雷」「不急，实在没有就抢别人的」。
  - 一名问鼎修士发现前方异状，随即**范围万丈、如海浪般的雷霆风暴**呼啸而至，边缘银蛇电弧无数。
  - 众人欲退欲瞬移，速度太慢；风暴速度暴增瞬息临身，连阳实修士也被**生生从瞬移中吸出**，魂飞魄散卷入风暴，全部形神俱灭。
  - 风暴中隐现一张巨大脸孔，正是王林。
- 续战：一名**窥涅**修为的闪雷族老者独行，未及逃遁即被风暴自身后吞入。
- 战果统计：
  - 无论**阴虚、阳实、窥涅、净涅**，在雷霆风暴下皆无半点反抗之力，被一一吞噬。
  - 短短数日，死于王林手中的闪雷族修士**已近千**；其眉心印记内所有之物尽归王林。
  - 从这近千修士身上另得**四道完整念雷**，全部吸入右目，本源不断壮大。

## 七、章末转折
- 第四天，王林所化风暴横卷吞噬三个窥涅修士后正要前行，灵符感应到附近一处七百万天地内**有人渡劫**；但瞬息后灵符不再轻颤，显然已有人抢先前往那处天地。
- 雷霆风暴如被鲸吸般从无尽大小迅速收缩成磅礴漩涡，王林身影自漩涡中心显露，目光一闪，右手持灵符向前一步，消失在星空之中。
