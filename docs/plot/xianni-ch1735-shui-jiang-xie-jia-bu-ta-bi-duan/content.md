# 第1735章 步踏臂断！

## 一、第八道本源：水本源之种

- 水将喷血后退、一脸不可置信；王林闭目感受体内多出的「乾坤一滴水」。
- 这是王林的**第八道本源——水本源**，但并未大成，只是**种子**状态。
- **实之本源 vs 虚本源**：
  - 虚本源（王林已有：因果、生死、真假）全靠感悟，一朝明悟立刻成道，但明悟极难。
  - 实之本源（火、雷、水）相对容易些，需在获得「种子」后一次次融合、慢慢壮大，直至真正本源。
- **种子来历回溯**：
  - 雷霆种子——当年吞噬半条雷龙 + 吸收闪雷族不灭雷霆。
  - 火种——朱雀数次觉醒的火焰之力。
  - 水种——水将拱手送出的乾坤一滴。
- **土本源仍缺**：王林在五行大地土阵中吸收了一个土灵，但远远不够；除非再有人如水将般将第三步土本源感悟拱手送出、并有数百修士配合等条件齐备，方或可成种。此事可遇不可求。

## 二、水将卸甲：王林救敌

- 王林目光由寒转平静。水将惊醒欲逃，王林虚空一抓，巨大虚幻手掌将其擒回。
- 一指点在水将眉心：水将容颜早已油尽灯枯如干尸，其生机与灵魂已与体外铠甲融合——他借甲之力，甲以他为养分，虚弱时铠甲将吸尽其最后生机。
- 王林输入磅礴之力，化作隔膜将水将魂、神、身与铠甲彻底阻隔。
- 原则宣示：「无论如何，你送我水本源之种，我不会杀你，会救你一次，这是王某做人的原则。」
- 铠甲被强行剥离散成碎片，每片仍有血丝连接其身，诡异骇人；水将凄厉惨叫却无法昏迷，心知王林是在救他。
- 王林祭出**血剑**，连斩数次，尽碎血色细线，细线倒卷回各自碎片。
- 碎片八方凝聚，重组为一具布满细密裂缝的完整铠甲，落地散发**水蓝色光芒**，形如有人端坐；蓝光中幻化出一把**长枪**，横落双臂之上。
- 卸甲后水将喷出大量血雾、虚弱踉跄，目光复杂；王林道「你走吧，我不杀你」，水将欲言又止，黯然退出五行水阵。
- 归一宗修士目睹此幕，先前的骇然转为弥漫全身的寒意。

## 三、步踏臂断

- 王林欲收走铠甲研究之际，五行水阵在一股无法承受的强大威压下轰然崩溃。
- 铠甲后方波纹回旋出现**漩涡**，其中伸出一只**干枯右手**抓向铠甲，苍老阴森之声化作音浪轰入王林心神：「这不是你可以拥有之物，给老夫滚！」
- 王林早有察觉，于阵崩前瞬间迈出一大步：
  - 气势从平凡升华到巅峰；
  - **七道本源浑然融合**，爆发出**空灵后期**的强悍修为；
  - **道古血脉之力**融入每一寸血肉骨头，身体可撞碎修真星。
- 落脚不踏虚空，而是狠狠踏向那手臂。对方掐诀欲抗已然仓促——轰然一脚，骨裂声起，手臂扭曲红肿、内有淤血，缩回时肿处爆开血溅四方。
- 王林袖子一甩立于铠甲之后：「敢抢王某之物，你活腻了吧！」左手随意后挥，水蓝铠甲连同长枪化作蓝光入袖，行云流水、一代宗师气范。
- 漩涡内近乎扭曲之声传出：「古国之修……你是古族之人！」

## 四、旁观者：玄罗大天尊

- 玄罗大天尊在五行星外星空将全程看在眼里，露出得意笑容、霸意弥漫。
- 评价：「果然是我道古一族的孩子，就是要这么对付所有敢冒犯之人……要是换了我，会把他的爪子剁下来。」
- 随意扫了眼五行星上的高塔：「归一宗，这群仙人来到此地，倒也很有意思。」——若他愿意，挥手间此星生灵烟消云散。
