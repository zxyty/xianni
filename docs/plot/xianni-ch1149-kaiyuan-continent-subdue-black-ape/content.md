# 第九卷 云海之巅 第1149章 调动与操控（三更）

> 世界状态须知归属：本章白发身影即【王林】（此阶段其在云海星域以自创化名『许木』/借名『吕子浩』行事，本章文本直呼王林），文中明确「他现在没有融合本尊」，故行动主体为王林的分身之身。

## 一、场景：开猿蛮荒大陆

- 玉简内星图将此蛮荒大陆命名为**开猿**。
- 地貌：山峰众多、起伏如波，雾气缭绕；凶兽低吼不绝，有群居者亦有孤傲独行者。
- 遗迹：地面遍布似隐于岁月中的**城池废墟**，昭示无数年前此地曾有繁荣文明，如今只余破灭虚无。
- 事发山峰：通体青黑、峥嵘险峻，嶙峋如利剑穿地入霄；近十丈大小的黑色猿猴凶兽在峰上穿梭。

## 二、黑猿与紫色大树

- **百丈黑猿**：通体黑色，如人般盘膝坐于峰顶，身高不下百丈，手臂粗如千年老松需数人合抱；双目开阖如两盏骤亮长明灯，凶焰惊天。
- **紫色大树**（只到黑猿小腿高）：树干多处枯萎却未死，树枝茂密；**树叶雪白**、脉络清晰而晶莹；树上结**两枚拳头大小的黑白二色交错小果**。王林一拍将其连根收入储物裂缝——本章唯一被明确带走的异宝。

## 三、战斗经过

1. **开路**：黑猿目光锁定王林之际，王林右手一挥，黑风弥漫，惨叫中带走前方十余只凶兽之魂；随后一步化白虹直冲峰顶。
2. **剑阵**：虚空一抓，储物空间内飞出多把飞剑，环绕成旋转剑阵，凡阻挡者挥手间肉身崩溃化作血雨，一路无停。
3. **空中战场**：十多只**蚊兽**与环绕的鹰形凶兽展开生死之战。
4. **黑猿反扑**：黑猿站起、踏峰而跃，速度不比王林慢多少；一臂挥下落空——王林身影模糊闪现至峰顶大树旁。
5. **飓风 vs 杀戮风暴**：黑猿挥臂幻化连接天地的飓风横扫；王林左手掐诀一指，杀戮之气化作**杀戮风暴**，呜咽回荡，正面轰溃飓风并撞飞黑猿，使其血肉模糊抛入半空。
6. **双指成剑**：王林化流星迫近，右手双指成剑连点黑猿之身，每指一血洞，元力顺指入体**结成一道道封印**。
7. **首度招降**：王林冷声问「你可愿成我之灵兽」，黑猿以更剧烈怒吼与左臂一拳作答，拳风隐有**一丝古神之力的错觉**。

## 四、核心：明悟「操控天地元力」之掌

- **处境**：王林未融合本尊，肉身强度不及黑猿，本欲避开再施神通。
- **触机**：脑中忽然浮现当日在**罗天**，第三步修士**黑衣老人**面对**古神拓森**一臂时伸出的那一掌。
- **机缘叠加**：当年亲眼见到第三步 + **青霖造化**中亲身体验第三步 → 于蛮荒大陆、星雾之下、与当年几乎相同的情境中，对这显然属于第三步的一掌产生惊人明悟（如同当年明悟雨界巨大掌印一般）。
- **施展**：闭目回放至近乎本能 → 睁眼抬右手，轻放于砸来的巨猿手臂上，衣衫狂舞、白发后飘而**身子一动未动**；黑猿一臂如打入雾团，全无着力，反生莫名剧痛。
- **点掌**：左手在右掌上**连点三下**，每次点落皆有天地元力自四面八方凝聚指尖落入右掌；王林面色红润、双目精光，轻喝一声。
- **战果**：黑猿倒退，整臂喷血，其上清晰留下**一个掌印**，并自掌印三指延出**三道裂缝**，顺臂向全身蔓延，稍一用力便有四分五裂之危。
- **领悟要义（本章标题所指）**：不是以自身之力「**调动**」天地元力，而是**强行「操控」**天地元力，令其从四面八方迅速赶来，霸道化作自身攻击。王林**尚不知此神通名字**，只觉隐约把握住了什么。

## 五、收服：凝魂成神与控灵印

- 生死危机下，黑猿体内亮起白光，头颅上浮现**与猿猴同貌、略具人形的虚幻之魂**，欲脱体而去。
- 王林辨认：按玉简所载，「**凝魂成神**」乃**六阶凶兽**才具备的神通——此猿在濒死之际竟有突破。
- 王林瞬至猿顶，右手下拍，将猿魂**生生压回**体内；再问「成为我的灵兽」，黑猿灵觉大开、听懂人言，恐惧点头。
- 王林一拍化去三道裂缝（化作点点晶光消散），并打出玉简内记录的**控灵印**，落于黑猿眉心化作符文，闪烁数下后消失。
- 结局：蚊兽杀尽鹰形凶兽后盘旋于黑猿身外；王林盘膝坐于黑猿肩上，黑猿仰天咆哮，迈步流星而去。

## 六、要点提炼

- 战力刻画：分身状态、未融合本尊 → 肉身弱势，但神通（黑风取魂、飞剑剑阵、杀戮风暴、双指成剑）已可碾压五阶凶兽群。
- 修行突破：本章为王林第三步相关神通的**关键明悟节点**，将「见过 + 体验过」的第三步经验落地为可施展之掌。
- 资源收获：七日猎兽取魂 + 大量药草 + 紫叶白树（含两枚黑白小果）+ 一头准六阶灵兽坐骑。
- 悬留：新神通无名；黑猿凝魂成神已现端倪，后续晋阶六阶可期。
