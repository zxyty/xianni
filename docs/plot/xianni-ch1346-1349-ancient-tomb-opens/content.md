# 仙逆 第1436-1437章：古之墓地开启

## 一、古墓爆发与浓雾扩散

- 古之墓地裂缝内涌出旋转风暴，夹杂万古死息，以及一个个古神、古魔、古妖死前的愤怒——它们的头颅如今被摆放在一处处石台上，怨气与死息融为一体。
- 风暴冲出裂缝，撞击外围弥漫星空十万里的浓雾。浓雾发出由闷到震动整个星空的轰鸣，仿若其内有灵，带着无边愤怒横扫星辰。
- 自高空俯瞰，雾气崩溃化作巨大漩涡风暴，范围疯狂扩张：十万里 → 三十万 → 五十万 → 一百万 → 二百万 → 三百万 → 五百万 → 一千万 → 数千万里，且并未停止，似无尽头。
- 古墓开启引动整个太古星辰绝大部分大神通修士放下诸事赶来，此刻却被迫心神震动地后退。

## 二、雾气的筛选规则（本章核心设定）

1. **多数人死**：被雾气卷中者血肉转眼腐蚀成骨架、元神凄惨灭亡。一名天人第四衰老者退避不及即当场化为骷髅。诸多修士崩溃成灰，堪称浩劫。
2. **十中有一得选**：约每十人中有一人被雾气一冲毫发无伤，反而无尽生机弥漫、好似年轻千年，眉心印记旁浮现一个**数字标记**。
3. **数字标记＝入场券**：标记一出现，任何力量都无法抵抗的吸力便将其卷入数千万里漩涡中心的古之墓地裂缝。
4. **修为上限**：妙音道尊亲身试出——第三步修为可化解雾气之力，但**空涅初期是进入古墓的最高修为限制**；修为高于此者会被雾气强行削弱到该线以下方可入内。

## 三、古之墓地的传闻价值

- 传闻自开天辟地以来古墓只开启过一次。
- 入内可获无法想象的造化：法宝、丹药、诸多神通之术，甚至蕴含**让第三步修士踏入空劫大境的方法**。

# 第1438章 三姐、四妹（第九卷 云海之巅）

## 一、雾气之威与封灭族的「三命」

- 古之墓地外的雾气是一道普适考验：**无论何种修为都要承受，就连三步大能亦不例外**，遑论一名封灭族女子。
- 封灭族少女身影甫一出现便剧烈颤抖、全身急速枯萎，转眼被雾气腐蚀成**红颜枯骨**——在雾气中「再次死亡」。
- 枯骨未散，其内散出**灰色光芒**，瞬息生出血肉，少女**再度重生**。
- 计数：她先被**王林算计杀死一次**，再被雾气杀死一次——**封灭三命，至此死去其二**。
- 她真正恐惧的不是已死两次，而是**尚在雾气之中**：此雾杀人无形，纵有最后一命，再被冲击便是真正的死亡。

### 意外的转机：眉心数字

- 少女急退未及，雾气疯狂涌入其身——但雾气**在其体内一转便骤然离去**，非但未死，反有一股**生机滋生、涌入眉心，形成一个数字标示（29）**。
- 旋即被吸力笼罩，无法挣扎，**被吸入雾气深处**。
- **奉天狼族大汉**（眉心数字 **14**）先她一步被吸入深处。

## 二、王林的异状：古神之力与「清明」

- 王林被雾气一冲，**眉心并未形成数字标记**，雾气入体反而**化作一股古神之力**，被其**眉心星点**瞬息吸收。
- 该古神之力中**死气极重、怨息弥漫**：吸收后体内立刻滋生暴虐、化作狂暴之息在脑中轰鸣。若非压制得快并立即停止吸收，心神即被搅乱。
- 驱散后，王林脑中出现**前所未有的清明**，「就好似在夏冬两季穿越一般」。
- 因无标记，故不被吸力牵扯，得以自主行动。

## 三、王林的推演

1. **封灭族强悍但有限**：连死两次仍活，然观其最后绝望神色不似作假——**若再死一次，绝不可能又活**。
2. **数字即古之文字**：外人看不懂，但结合来此地的方位判断，**此处很可能就是贪狼所说的、其当年离开古之墓地的方向**。
3. **去与不去**：三息之后果断选择前往——「富贵险中求」；若放弃，此生或再无古之墓地开启之机。
4. **拒绝吸收雾气**：虽可壮大古神之力，但一旦吸收，神智恐被死气与怨息操控，沦为**活死人**。
5. **自恃身份**：「我身为古神，进入这里定然比之旁人要好处更多。」

## 四、核心转折：疑似有「冥冥之力」在操控王林

- 王林回顾自己近来最反常的一次鲁莽——**算计疑似掌尊之人一行**：
  - 该疯狂念头**毫无端倪地出现，且恰在与一代朱雀交谈之后突然滋生**；
  - 他随后为此生出许多「理所当然」的理由，甚至**融入天运子之魂推衍计算**；
  - 并预设退路：若掌尊重伤稍有恢复，**立即以玉简逃回界内**。
- **火雀族圣地逃出后**，当他开始怀疑那中年男子是否即掌尊时，脑中曾闪过一个令他身体发寒的疑惑——「我为什么会做出如此疯狂的事情、升起如此疯狂的念头？」——但该疑惑**刚一出现就立刻消散**，且总有其他事扰乱，使他几乎遗忘。
- **进入雾气后**，脑中骤然清明，仿佛雾内雾外是两个天地：**一股不知何时降临在他身上的冥冥之力，被生生阻断**。疑惑因而重燃并越来越浓，片刻间惊出一身冷汗。
- 他回头死盯雾气之外的太古星辰，眼中露出**此生从未有过的恐惧**；越回想抵达太古星辰后的一幕幕，越觉有力量在冥冥中操控自己。
- 恐惧终被寒光取代。沉吟许久，**确认「进古之墓地」是自行分析后的决定、而非冥冥所致**，方转身直奔深处。

## 五、抵达裂缝与神秘文士

- 途中不断有被吸力横卷的修士呼啸而过，**眉心皆有数字标示（37、45、71 等）**。
- 雾气至深处可见**一条狰狞裂缝**：其内无雾气但阵阵扭曲，漂浮碎石之上是**一尊尊狰狞头颅**——即**古之墓地**。
- 王林正要踏入，身后雾气轰鸣，走出一人：
  - **中年文士，极为俊美、隐隐似女性**，此刻面色略苍白，显然行至此处极为艰难；
  - 身外环绕**九块奇异雕像**：皆无头发，表情或怒、或喜、或悲等**九种各不相同**，散发**淡黄之芒**，硬生生护他穿雾而来；
  - **其眉心同样没有数字标记**。
- 二人对视，文士露出诧异；王林神色如常而心中大浪起伏，未开口便转身欲踏入裂缝。文士以**如女性般好听的声音**开口：「这位道友，能不能帮忙一下？」

## 六、暗线：太古星辰隐秘宫殿中的黑袍老者

- 太古星辰内一处**无边星空**中漂浮着一座**巨大宫殿**，这片星空似被隐藏，**无人可以找到**。

# 第1346章 井中蓝芒之约 · 王林入古之墓地

## 一、大殿密谈：黑袍老者 vs 井中蓝芒

**场景**：一处点着烛火的大殿，殿内有一“井”（水面）。

- 全身隐于黑袍中的老者手指将要落在水面刹那，水面骤然爆起浓浓蓝光，与其手指相触。
- 无声无息，却有环形波纹扩散成冲击，吹得黑袍啪啪作响。
- 蓝芒中传出平静声音：**“我可以不理会你在他身上的井中捞月……但你若杀他，我想……我会出手。”**
- 黑袍老者沙哑回应：**“你，不是老夫的对手。”**
- 蓝芒：**“我可以让你伤势加重。”**（暗示黑袍老者现有伤在身）

### 旧约与身份点破

- 黑袍老者叹息提及：**“我们有约定”“当年你让我出手，我已经出手了。”**

- 黑袍老者退让：**“只此一次”**，转身走向大殿深处；井中蓝光默默消散。

> 要点：蓝芒之主为**太古五尊之一**，妻子的躯体被夺（未夺回），且以“父亲”身份优先，为守护“他”而愿与黑袍老者翻脸。“井中捞月”是黑袍老者施加在“他”身上的手段（本片段未点明“他”是谁）。

- 地点：古之墓地裂缝外，浓雾弥漫。
- 中年文士（似女子）出声：“这位道友，能不能帮忙一下……”
- 王林步伐毫无停顿，置若罔闻，化作刺目长虹踏入裂缝外的扭曲之中——扭曲的是雾气，更是虚无。

- 王林并非孩童，无好奇心，亦无不明底细下助人为乐之念；对方能强行走到此处，在他看来**极为可怕**，即便许诺好处也会毫不犹豫离去。
- **关键异变**：眼下神智极为清明，与进入古之墓地雾气前有**细小差异**，而这差异让他嗅到危机。

## 三、中年文士：本体受阻，遣九雕像所化分身入墓

- 中年文士所在位置距裂缝**不足百丈**，凭强悍修为与法宝也只能到此，再往前无法做到；四周雾气翻滚越加暴躁。

  - 即：中年文士认定王林是**古神**（与拓森并列的另一个古神），且此古神曾灭其**七妹的分身**。

- 光芒中走出**白衣女子身影**：相貌绝伦、长发及臀、身子略有透明，**内部有九道光芒流转**。

3. 王林眉心无古墓标示却能直入裂缝，成为外人判定其“古神”身份的铁证；拓森被点名为另一个能做到者。
4. 中年文士的九雕像分身携带眉心印记入墓，为古墓内的后续冲突埋线。

# 第1346章 古墓裂缝内被偷袭

## 一、古墓外：中年文士的盘算

随着某道身影踏入，雾气中光芒消散，**中年文士**（白衣，被称「三姐」）身子从其内退出，面色略显苍白，直奔后方离去。

其内心独白透露的关键信息：

- 「唯有送出分身进入古墓那小古神身体上，隐隐有**井中捞月**的痕迹」——能施展此术者，在**太古星辰**除了「他」再无别人。
- 因此她判断：自己与这**小古神**或许存在**彼此合作**的可能。
- 处境盘点（姐妹/同伙格局）：
  - 大姐与八妹**失踪多年**；
  - 二姐**已找到合作之人**；
  - 狐猸子老四**不惜代价抢走了那莽夫拓森**；
  - 五妹**夺舍了躯体**；
  - **蓝梦道尊**自然与其一路；
  - 结论：「我若再不为自己寻找合作之人，怕是会被孤立起来。」

## 二、拓森出场与二人交锋

将要离开古墓雾气时，中年文士忽然驻足看向远处：雾气翻滚，低吼咆哮，暴虐而疯狂的气息轰然扩散。

- 一个庞大身影迈步而出，**几乎如一颗修真星般大**，前行中不断缩小——正是**拓森**。
- 此刻拓森双眼通红、仿若疯狂、神色狰狞，却有霸道气势散出，咆哮着：「你即便不要求，本神也会自行而来……你这娘们，给本神闭嘴闭嘴闭嘴！」
- 一阵**充满诱惑、如魔音般的笑声**自拓森**眉心**传出（女声）：「人家不说就是了……和你在一起，可比与那没用的仙尊要快活不少呢。」

## 三、王林踏入古之墓地裂缝

### 落地即遇袭

- 王林踏入裂缝一瞬即感受到**传送之力**，未及看清便身子一晃、斜退数丈，双手掐诀，体外光芒环绕，隐隐出现一个**与自身融合的光影（光影盾）**。
- 此为其谨慎性格使然：古墓凶险，且先入者众，必须防范。
- 光影出现刹那，轰然巨响——一股强悍之力骤落王林身上，与光影撞在一起。因盾已先展，光芒万丈而起，**来力被折射反震回去**，闷哼声起，有人急急后退。

### 环境勘察

- 此地与裂缝外所见虽大致相似，却显然**不是一处地方**——**所有人在入口刹那被分散传送到不同区域**。
- 天空昏暗；大地是**如海的浓雾**，深不可测、缓缓蠕动，时而张开如森森大口般的**黑洞**，仿若等待吞噬。
- 半空漂浮着无边无际的**碎石平台**，每个平台上**摆着一个头颅**，弥漫天际看不到尽头。
- 平台似有**奇异力量环绕**，任凭神通弥漫，**无人可破开进入**；更远处仍有零散修士在尝试踏上平台。

### 在场势态

- 偷袭者：正前方一名**身穿道袍的中年男子**，急急后退，面色苍白、嘴角溢血，目光骇然。
- 天空上此刻有**数十个修士**，神色震惊，在王林目光扫去时纷纷下意识退后。
- 四周弥漫血腥气息——王林判断这些人**不止一次联手出击**，专杀那些刚被卷入、尚处茫然与恐惧中的修士：**杀人夺宝**。

# 第1439章 情语、杀劫

## 一、场景与开局
- 卷次：第九卷 云海之巅。
- 地点：太古星辰雾气中的「古之墓地」内部。此地极大，容修士数百而无密麻之感。
- 空间结构：下方是翻滚的雾气构成的「大地」，半空浮着一座座千丈大小的平台，平台上放置古神／古妖头颅，平台外环绕排斥防护之力，阻止任何人踏入。

## 二、反杀偷袭者，狠辣立威
- **偷袭机制**：一批修士守在入口，专袭新被裂缝卷入者——任何人被吸入后都会有短暂茫然与恐慌，此刻出手足以致命或重伤；一旦受伤便被群起攻之。偷袭者彼此有约定，未遇强敌前有效。他们不怕误袭三步大能，因三步大能入场时威压浩然弥漫，可提前分辨。
- **失算之处**：王林是**自行踏入**而非被吸力卷入，毫无慌乱。
- **过程**：
  1. 一名天人第三衰（未达第五衰）的中年修士抢先施展神通，神通落到王林身上的刹那被**全部疯狂折射回来**，其人当场喷血倒卷、心神震骇。
  2. 该修士判断逃无可逃，果断拍胸喷出元神之血，施展对自身损伤极大的**血遁之术**，速度暴增冲向下方雾气——「进入雾气或许会死，但不进去一定会死」。
  3. 王林评其「倒也是个人物」，但**未暴露定身术、也未用血剑**（不轻易露底牌），只抬手一掌打出**役灵印**。虚幻掌印破空而至，穿透雾气，在雾面砸出巨大凹陷掌痕并留下掌印状黑洞，中年修士连人带元神崩溃而亡，只余小片血雾与残损元力。
- **效果**：一掌之威被四周修士尽收眼底；有人虽不惧但已生谨慎，另有人觉得王林**面善、似曾相识**。天空中十多个待袭修士自此胆寒，不敢再偷袭。

## 三、平台与古神头颅
- 王林接近身前一处千丈平台，其上是一颗**古神头颅**：双目睁着，透出愤怒与不甘，眉心有巨大血洞，**眉心印记被人生生挖走**。
- 头颅前方地面插着一杆**三丈大幡**，幡布垂着毫无舞动，似已无生机。
- 平台传出阵阵排斥之力，有防护弥漫，阻止踏入。

## 四、白衣女子登场与古墓关闭
- 又一人被传送入内：白衣女子，黑发披肩长可及臀，容颜绝伦而冰冷。**其样貌与王林先前在裂缝外看到的中年文士极为相似**，令王林瞳孔一缩。
- 二人目光交错的刹那，惊变骤起：昏暗天空闷雷般轰鸣传遍八方，下方雾气如恶龙游走般翻滚；天地如密室关窗般沉闷。
- 太古星辰雾气中的裂缝急速收拢、彻底愈合不见踪影——**古之墓地关闭**。

## 五、杀劫：九十九个平台的生死争夺
- 雾气骤然爆出旋转雾柱（十丈至千丈粗细），触之即死；死者**眉心的数字标示化作闪烁符文**飞出，飘在半空。
- 与此同时，半空平台中**恰有九十九个的防护之力消散**，可供踏入；其余平台防护如常，无法进入。
- 王林在雾柱临近不足十丈时一步踏上平台，雾柱贴着平台边缘冲天而去，未伤到他。
- **致命规则**：同一平台若同时踏入两人以上，平台下方会爆出千丈雾气，将平台、其上头颅与所有人一并湮灭。慌乱之中，**五十多个平台**同时出现两人以上而当场毁灭。该力量之强，「即便三步大能被冲击，也要死亡」。
- 王林随即双手掐诀，放出气浪环绕自己所在的千丈平台，**阻止任何人踏入**。

- 章末：十多个修士红着双眼，疯狂冲向王林的平台——「要么生，要么死便一起死」。
