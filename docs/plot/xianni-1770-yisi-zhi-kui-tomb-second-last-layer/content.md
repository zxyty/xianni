# 第1770章 已司之傀

## 一、下坠雾气层
- 王林身在古之墓地雾气中急速坠落，雾气如线条游走；他神色平静，神识散开环绕四周戒备。
- 雾中变化奇异、凶兽众多，王林大都见过，坠落中时快时慢，避开一群群临近凶兽，直向深处的**倒数第二层**而去。

## 二、已司之傀的推断
- 倒数第二层正是当年令王林感到可怕气息的所在。如今他越想越觉得这股气息，正是**第三魂记忆中七彩仙尊（原文作「t彩仙尊」）的最强杀招——已司之傀**。
- 进入洞府核心后，王林**每杀一人即按第三魂留下的方法祭魂**；每祭献一次，他与已司之傀便凭空多出一丝联系。
- 如今杀人不少，凭此奇异联系，王林已有**八成把握**断定倒数第二层的恐怖气息就是「已司」。
- 结合第三魂记忆，王林猜出大半底细：
  - 古之墓地的存在，**很可能就是七彩仙尊为滋养已司之傀而构成**；
  - 此物为七彩仙尊**毕生祭炼**而出；
  - 更在**杀死烨寞之后使这傀儡大成**。

## 三、黑色大地与古老传送阵
- 雾气渐薄至只剩一丝，下方现出**无边无际的黑色大地**：长满黑色藻类植被，摇曳中释放黑气升空，颇为诡异。
- 此地无阳光，仅靠植被体内幽光照明；一片寂静，王林到来时植被毫无变化。
- 前行半柱香，万丈之外见**千丈范围空旷无植被的地面**，其上是一座**古老传送阵**——不知存在多少岁月，仍在无声运转，光芒闪烁并散发威压。

## 四、咆哮与踏阵
- 王林刚一临近，传送阵内轰然传出**惊天动地的咆哮**，携极恐怖气息直贯心神，令其脚步一顿、心神震荡。
- 吼声之下，四周藻类植被剧烈晃动、大量黑气被逼出升空，地面颤抖起伏如海浪。
- 声音消散后，王林面色苍白，在阵外沉默许久，随即目露果断：「若我分析正确，这一次危机不会太大，相反，很有可能是我一大造化——已司之傀。」
- 王林**一旦决定绝不迟疑**，迈步踏入传送阵。阵法轰鸣，幽光万丈穿透八方，刺入天空雾气，弥漫数万里。

## 五、第三妃跟入
- 第三妃正在雾中急速前行寻找，只隐约知晓大概位置，忽见前方穿透雾气而来的幽光，遂小心谨慎循光而去。
- 一炷香后她抵达传送阵前，此时王林早已消失；她在阵外犹豫许久，终于银牙一咬，迈步走入阵中。

## 六、倒数第二层初探
- 该层雾气比上一层稀薄许多，光呈**一片红芒，如同鲜血地狱**。
- 雾气内时有凄厉嘶吼，幻化出一双双赤红双眼死死盯着王林；但在**王林散开的道古气息**下，这些凶兽不敢幻化现身——今日的王林早已不是当年。
- 疾驰中四周雾气疯狂卷动，前方轰然传出仿若就在耳边的低吼，震动八方，此层几乎崩溃、剧烈震动。
- 一股大力随吼声扑面，王林身不由己**连退百丈**，直至吼声消散方才停下。

## 关键悬念
- 已司之傀究竟是危机还是造化，尚待下层揭晓；第三妃亦已跟入同一传送阵。

# 古之墓地·赤雾山峰「已司」与第三妃来投

## 一、赤雾山峰与「已司」
- 王林循吼声深入古之墓地此层，前番一吼已震动其心神、险些受伤，但他动念：「此物若真是已司之傀，若能被我所用」，遂继续前行。
- 所见：一座不高的山峰，被一片红雾弥漫。王林临近的刹那，山外红雾蠕动，化作一颗巨大头颅——光秃无发、面目模糊，张口发出惊天之吼。
- 王林应对：双手掐诀于身前一挥，体内本源环绕，**道古之力**弥漫全身以抗吼威。
- 威能实测：彼时王林距山尚有**数万丈**，吼声仍如狂风扫中其身，砰砰之声中本源所化防护**倒卷入体**，王林面色苍白疾驰后退至**千丈外**，嘴角溢血，吼声方消散；雾气头颅随即融化般重新化作赤雾弥漫山峰。
- 判定：王林凭**心神内的一丝联系**极为确定——此物即是「已司」。

## 二、操控已司的前置条件（关键情报）
- 王林自省：「我尽管杀了不少人祭魂，但还是不够。」
- 结论：若想**操控已司**，**还需杀一个大神通修士**（取魂祭献）方可。此为其下一步行动目标。

## 三、第三妃现身求见
- 王林察觉「是她」，身形一晃隐匿。
- 第三妃自远处天地间金光中而来，盘膝坐于一扇巨大金门之后，**面色苍白、嘴角带血**，望向山峰时**眼露恐惧**——她未料古之墓地此层有这等恐怖存在。
- 她趁雾气未再吼的间隙起身传音四方：「王林，我知道你在这里，我没有恶意，我想以我的修为与神通，可以对你有所帮助，还请现身。」四周寂静无应，她神色黯淡，操控金门缓缓后退，欲改往别处寻他。

## 四、金门连碎与王林出手
- 山峰雾气再翻滚，幻出光头虚影，第二声咆哮惊天而起：天地色变、无形波纹横扫、大地颤抖、天空扭曲。
- 第三妃掐诀并**咬破舌尖喷出血箭**打在身前金门上，金门金光万丈相抗，**轰鸣中直接崩溃**；她后退再掐诀，连续幻化出**四道金门**，四门一一碎开，借这抵抗之力退出千丈之外。
- 正欲再施神通时，冷漠之声传出——「你找王某何事」。王林凭空现身于她身前，右手抬起向后一甩，**以身躯挡住吼声余波**（此等余波以其身躯足以抵抗）。

## 五、对话与馈赠
- 第三妃一愣，眼中喜悦一闪即被掩去，道：「你当年曾在这古墓内帮过我，这一次我想帮你。」
- 王林冷冷回绝：「不用，此地危险，你莫要留在这里」，转身欲去寻大神通修士取魂祭献。
- 第三妃咬唇再言「我能帮你」，抬起右手——腕上一串**金色珠子**，散发柔和光芒。
  - 来历：**师尊所赐**。
  - 能力：可化作（多面）**金门同出**；若王林想进入那山峰，此物可以帮他。

## 六、时间线定位（作者按语）
- 「王林道古圆满在即」。
- 本段情节为**去仙罡大陆之前的最后部分**，作者自述其重要性。

- [ ] 是否接受第三妃的金珠与随行相助，尚未表态。
- [ ] 「已司」与已司之傀的真实来历、与古之墓地的关系未明。
