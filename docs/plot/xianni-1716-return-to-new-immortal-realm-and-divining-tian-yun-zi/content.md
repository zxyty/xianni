# 第1716章 算天运！

## 一、出裂缝·归新仙界

- 云海星域裂缝外聚集大量凶兽，因数月前驱逐它们的禁制风暴而惊恐徘徊、不敢入内。
- 一白衣身影自裂缝走出——王林。凶兽感其气息齐齐后退；王林目光平静扫过，一晃即逝。他离去良久后，凶兽方才小心翼翼重新涌入裂缝。
- 王林穿梭星空，抵达云海星域边缘的**新仙界**：漂浮大陆、环绕四周的银河（由召河仙界所化）、禁制阵法波动守护仙界。
- 此地为王林亲手创造，是他在洞府界除朱雀星外的第二个家。

## 二、加固护界禁制

- 王林判断：召河仙界所化银河虽有守仙禁制，威力仍不足；从前无力增强，如今能做到。
- 手段一：双眼瞳孔中消散的**横纹血丝**再现红芒，一挥之下血丝幻化而出、尽数融入银河，使银河隐透血光。
- 手段二：目视星空中的**规则细线**，右手一掀，大量规则细线如浪舞动，自四面八方凝聚，密集环绕银河。
- 目的：让仙界在这场**寻找第三魂的浩劫**中保得平安。

## 三、故人重聚

- 入界一刻，红衫子等人自入定苏醒；**青霖、清水、司徒南、南云子**等立于天空迎接。
- 王林所见：清水身边站着**红蝶**，父女已然相认；青霖身后跟着**青霜**，人群远处的**周佚**以复杂、悲哀却更多是满足的神色望着青霜；**周茹**已成年（在王林心中仍是孩子），身旁老虎依旧相伴。
- 王林轻声道：「回家了。」全界欢呼。

## 四、定居与身边人

- 王林与**司徒南、周茹、大头、十三**等人居于新仙界**北部**连绵山峰上的简单屋舍。
- 周茹不愿离去，如女儿般陪伴，目光充满依恋；王林温暖之余亦感刺痛，因念及**李慕婉**与朱雀星旧事，自觉对不起婉儿——两千多年的岁月足以掩藏他的一切苦痛。
- **大头**：魂血早已归还、仆从封印已解、获得自由，却始终未走；时望天空追忆，因其家已不在，童年苦痛回忆反成珍贵。
- **十三**：心思单纯，唯一念头是修炼、成为师尊最强的弟子，必要时可为师尊放弃一切包括生命。
- **司徒南**：整曰与王林喝酒大笑；醉后感慨的不是王林的成长，而是自己已很久没做王爷。
- **周佚**：来访一次，与王林一杯杯喝完、未发一言，深看王林一眼后露出第一个笑容点头离去；仍打算等青霜认可或想起他，哪怕一辈子。

## 五、蓝丝族与李倩梅

- 仙界**西部**原本空旷之地，现为**太古星辰**族落**蓝丝族**繁衍生息之所。
- **蓝梦道尊**坐于自建茅屋外微笑；其女**李倩梅**（文中一处写作「李情梅」）因修为不足被安排闭关，领悟蓝梦道尊本源。
- 王林前往拜访，得知李倩梅闭关后**内心竟松了口气**——他不知再见时该说什么，也分不清与李倩梅之间到底是恩还是情。「恩，不等于情」这句话始终回荡耳边。

## 六、界外局势：第三魂之争

| 势力 | 手段 |
|---|---|
| 远古仙域四大战将 | 四人联手，与诸多仙人布置**仙人血脉阵法**持续搜寻；另有不为人知的特殊手段，连王林也无法知晓 |
| 战老鬼 | 无任何举动，仅以神识遥遥锁定四大战将、看其寻找；心思不加掩藏，四大战将明知却似有依持而不在乎 |
| 七彩道人 | 自云海离去后召集**掌尊**与界外几个仙妃齐入界内，直奔**昆虚**严密搜寻；隐隐施展某种神通——此神通正源于界内界外大战中无数修士死亡为其带来的机会 |

- 新仙界则如世外桃源，不理界内外纷争；王林归来使此地修士信心坚定。

## 七、王林一月间的作为

1. 取出当年自**雷仙界**所获**仙品阁**，将其中**全部仙术**取出赠予青霖等人，由其安排传授，以提升仙界整体力量。
2. 大部分时间研究**鬼脸帆**，欲掌握其内幻术；进展缓慢，虽焦急亦无捷径。

## 八、决意反算天运子

- 相比寻找第三魂，王林心中还有一根必须先拔的刺——**天运子**。
- 即便拔不出，也要弄明白这根刺刺在何处、以何种方式致命。
- 这不是王林第一次反算天运子，却是他第一次要**一举了结千年纠葛**。
- 做法：盘膝坐于屋舍外，闭目沉浸心神，进入他**始终保留的天运子之魂**，欲借此魂找出天运子**本尊所在**，前去杀之。
- 判断：天运不除难以心安，此人是除第三魂外**最大的变数**。
