# 第1518章 不能退！！（第十卷 叱咤界内）

## 一、开战地点与突发
- 界外太古星辰的第一战，破阵位置选在**云海星域**其欲破开的一点，恰是**王林此刻经过之处**。
- 界内**尚未备战完毕**，**七彩界还没有找到**，战争却突然来临。
- 封界大阵传来震动，王林目视前方如网大阵出现模糊混乱，一眼看出是阵外太古星辰之修施展手段要撕阵而入。

## 二、封界大阵：双刃剑
- **弊**：封死界内香火，使界内修士修为无法与界外相比，几乎断了界内修士的根本。
- **利**：无论进出都极为艰难，间接起到保护作用。
- 阵内有**万古岁月中诞生的阵魂**与众多**阵灵**，可自行反击。

## 三、王林的抉择：大义与杀戮本源的明悟
- 他自问无力阻止大阵被破，但要做**最坏的准备**；界内自有大能知晓变故，不需他去通知，而他是此地最接近之人。
- 杀水道子后消散的杀气再度轰起，**杀戮本源疯狂增长**。
- 心念：这是入侵，为了家园、故乡、为了身为界内修士的荣耀。他一生杀戮皆为个人，唯在**神宗外**感受云海修士荣耀的一刹那，才有了界内修士的荣耀。
- 明知或将战死、或将失去**复活婉儿（李慕婉）**的机会，仍**做好了战死的准备**（呼应**红杉子**此前之问：“你可做好了战死的准备”）。
- 悟道要点：**为己杀戮万万人，当不得杀戮二字，只是屠夫**；真正的杀戮本源，是为理想、为必须守护之人之物而疯狂反抗的**大义之杀戮**。

## 四、王林的战前布置（一人迎十万大军）
1. 右手抬起，**千万剑气**呼啸笼罩星空，直逼封界大阵。
2. 大袖一甩放出**灵动上人**与**周瑾**，二人不得不听命，“就算是死了，其魂也得听命”。
3. 掐诀一指天空，**无数禁制幻化**，展开疯狂封印。
4. 祭出**血剑**，血光滔天。
5. 双臂一挥，吸收星空一切光芒入体，化作**光影盾**。
6. **左眼九色火焰**结成风暴蓄势；**右眼雷图**旋转雷鸣。
- 形象：一头白发舞动、一身白衣飘摇，如**一尊战仙**，身上显出界内修士的荣耀。

## 五、界外破阵：六人合力
- 长尊会**天罚殿**巨大阁楼内苍老之声下令：“**破阵**”。
- 参与者：太古星辰**两个仙妃 + 三个大能 + 掌尊**，共六人全力出手。
- **掌尊**以一人之力，凭太古星辰星空伸出的诡异之力（化作大手）抽取阵魂；封界大阵在界外看去如**一口巨井**，要把井内之魂生生捞出。

### 五法宝 vs 五阵灵（对位厮杀）
| 界外法宝 | 封界大阵应对 |
|---|---|
| 晶剑（爆发香火之力） | 银白闪电凝成**闪电长枪** |
| 蓝梦道尊的**琴弦** | 紫光凝成**巨大鞭子** |
| 一位仙妃的**九片花瓣** | 红芒中的**九头流星锤**（九头甩动、凄厉吼叫） |
| 由寒冰组成的**三瞳之眼** | 万丈**投石车/战车**，抛出可燃万灵的火焰 |
| 另一仙妃以**三滴本命道血**化作的**三头鬼影** | 黑光中无声出现的**狼牙棒**（利刺、沾满黑色鲜血） |

## 六、撕魂、裂缝与自爆
1. 诡异大手捞魂，仅抬起数丈便显虚弱，遂**猛地向旁一撕**，把阵魂**生生撕开一道缺口**。
2. 封界大阵随之出现**一道裂缝**，阵法短暂停顿；一声苍老沙哑之音：“**老夫已经尽力**”。
3. 五处同时下令“**爆**”：
   - 裂缝内山顶之上的**宫妆妇人**（寒光急闪，平缓道“爆”）
   - 蓝丝族所在、蓝上之上呆望钗子的**蓝梦道尊**（口中有无奈之音）
   - 太古星辰极西、九颗被冰封的修真星内的**童子**（喃喃自语）
   - 另一处仙气弥漫裂缝中大陆上的**红衣女子**（似笑非笑轻吟）
   - 封界大阵外**长尊会天罚殿**内的一声低吼
4. 五样法宝（任一都足以引起浩劫）**齐齐自爆**，崩溃冲击疯狂涌入裂缝，化作莫大撕裂，震动界内界外一切星空。

## 七、结果
- **封界大阵被短暂打开一道巨大缺口**。
- **战争，开始了。**
