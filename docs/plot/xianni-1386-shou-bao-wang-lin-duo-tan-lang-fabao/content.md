# 第1386章 收宝（第九卷 云海之巅·第一更）

## 一、意外重逢：本该已死的贪狼

- 王林从未想过能在这太古星辰内看到**贪狼**——在他的记忆中，贪狼应已死在当年的**望月**之下，彻底灭绝。
- 见到贪狼的瞬间，以王林的定力也不由恍惚了一下；再看时贪狼已逃之夭夭，只剩下方近千目瞪口呆的修士。
- 王林判断：以贪狼的修为，**绝不可能冲出封界大阵**，如今却出现在此，颇为蹊跷。贪狼逃遁速度之快亦令王林一愣，转眼恐已逃出这修真星，连地面法宝都来不及收走。

## 二、遗落在地的五件法宝

| 法宝 | 形态与特征 |
| --- | --- |
| 葬天木灵（巨大树人） | 由森林组成，失去贪狼操控后呆立，再无毁灭之力；蕴含极强防护并可反击 |
| 天皇炉 | 庞大烘炉，散出沧桑气息，未近即感恐怖威压 |
| 雾魔枪 | 黑色雾气组成的长枪，未彻底凝形，一息间在雾与枪之间转化不下百次 |
| 护骨九碑 | 九块巨大石碑，如组成阵法，散发幽光形成细密防护 |
| 浮惊九十九剑 | 九十九把飞剑环绕旋转，剑气呼啸如无数剑龙游走 |

## 三、王林收宝过程

1. **收九十九飞剑**：右手向下一抓，化作虚幻遮天大手，如具磁力般把九十九把飞剑尽数吸去；张口喷出一道**元神精气**化狂风扫过，砰砰之声中贪狼的神识烙印全部崩溃。
2. **收护骨九碑**：贪狼远遁途中骤感九碑神识烙印亦被强行抹去——此物得自神秘古墓外围，数万年无神识留下，被其烙印后已融为一体，绝非寻常之人可轻易抹除。
3. **收雾魔枪**：三息之后贪狼体内砰响、喷出一口鲜血，惊觉雾魔枪被收。
4. **收天皇炉**：数息后贪狼再次喷血踉跄，天皇炉被收走。
5. **收葬天木灵**：遮天大手一拍树人，树人轰鸣却纹丝未动，反有青色气息散出，将王林幻化大手震得四分五裂。王林反露喜色——他方才那一掌足以拍死一个**碎涅**修士。遂喷元神精气化作巨大光网笼罩，大袖一甩把树人卷入储物空间。

## 四、王林对诸宝的判断

- 九十九把飞剑比当年**杀域界**内之物高出数筹。
- 九块碑文似**以骨所化**，蕴含极强气息。
- 雾魔枪最为重要，其上有**古魔气息**，沧桑透出，存在年月最少数万年，甚至更为遥远。
- 天皇炉绝非简单：贪狼留神识的方法根本不对，与当年那**古神大鼎**一样只操控了皮毛；此炉虽无妖气，但王林隐隐感到其**与古妖有莫大关联**。
- 王林自述：「我之法宝，绝大部分都是来自贪狼」，称贪狼是**拥有大机缘之人、天道宠儿**，其宝物之多足以让一切修士震撼。

## 五、贪狼的心理转折（三度回头未遂）

- **第一念：本能溃逃**——见王林时脑中无别的念头，连反抗之想都来不及升起，潜意识中对王林的恐惧占据身心，身体先于大脑展开全速逃遁，怕法宝像当年一样被一件件抢走。
- **第二念：愤而回身**——逃至远处星域后如梦初醒，自忖「修为比当年高出无数倍，可谓天地之差，法宝更多更强，就算是**天人衰劫**修士也敢一战」，怒的不是王林而是自己，决意回去杀王林报当年之恨。
- **第三念：彻底崩溃**——感知飞剑神识被抹，惊问「这王林现在到底什么修为」；迈出三步又觉九碑神识被抹而犹豫；仍想凭天皇炉、雾魔枪与葬天木灵「拼一把」；直至雾魔枪、天皇炉接连被收，恐惧如潮，再无回头之念，以**暴增九十多倍的速度**轰轰远遁，向颠落之地深处疾走。
- 悲鸣与悔恨：怒吼「克星啊，这该死的杀千刀的王林，就是我贪狼这一生的克星」；后悔「千不该万不该，方才当着那些**云遁族**修士的面，拿出那么多法宝」。
- 背景补述：贪狼当年好不容易逃出升天、九死一生，凭大机缘换了一身至强法宝，在**颠落之地**内确曾创出一番天地，好日子未过多久便撞上王林。

## 六、亮出帝令，安排后事

- 事发地为**暗蝎族修真星**。收宝毕，王林转身面对已被震慑、露出畏惧之色的近千修士，冷哼一声，手心现出一枚**玉佩**。
- 王林问「你等可有人认识此物」，一名老者上前细看后身子轰颤、面如死灰，失声道：「**帝令**」。
- 王林冰冷吩咐：「我没回来之时，你等不得离开一人，全部都在这里等着」，并指向满脸兴奋的**钟大洪**，命众人**听从此人号令**。
- 交代完毕，王林化作长虹直奔天际，迈步间波纹回荡，身影骤然消失。

## 七、要点提示

- 本章确立贪狼「未死且已大幅提升修为、却仍被王林一面倒压制」的设定，并把浮惊九十九剑、护骨九碑、雾魔枪、天皇炉、葬天木灵五件法宝转入王林之手。
- 雾魔枪（古魔）与天皇炉（古妖）指向更古老的势力线索，天皇炉更与当年古神大鼎的「只操控皮毛」情形对照。
- 帝令的震慑力在暗蝎族修真星修士中得到验证，钟大洪被王林授权临时统辖近千修士。
- 作者章末附言：身体不舒服，来不及修改，速度不快，会坚持写但会慢。
