# 第九卷 云海之巅 第1399章 古魂禁！

## 一、化名「许木」与名傀司术

- 某女子（与司墨子同行）两次询问王林名讳，引起王林警惕。
- 王林虽未听闻过「以名字施展的法术神通」，但知长尊会的**大司之术**在太古星辰极为神秘诡异；对方能推算出他先前躲藏之处，宛如亲见。
- 由此王林联想到 **天运子**——修道至今他最看不透、最为忌惮之人，忌惮程度更甚于水道子。
- 王林平静报出化名「**许木**」。他认为自己的名字若有心探查并非秘密，但「被人知晓」与「自己说出」隐隐不同。
- 女子默念三声「许木」后微皱眉：**「此人不亲口说出真实名字，无法在其身上施展名傀司术」**。
- 王林转身不再理会二人，与大帝使者向通道深处疾驰。

## 二、试探神秘大帝的底线

王林对颠落之地那位神秘大帝了解太少，对方突然送来好处使他生疑，故以连续试探摸清底线：

| 时点 | 试探动作 | 结果 |
|---|---|---|
| 数月前 | 对龙甲族的处置 | 未被阻 |
| 此前 | 对川河族与魂蛇族的做法 | 未被阻 |
| 本章 | 提出让**暗蝎族族长**成为落生会长老 | 大帝使者（疑似先行传音请示）应允：「既然是少帝钦点，自然不是问题」 |

- 王林盘点：已废弃两个落生会长老、取消两族长老之选，皆在底线之上。
- 结论：**神秘大帝根本不在乎落生会**，此会对其而言或许无关大小；「他到底是谁」仍是悬念。

## 三、初入大帝星

- 二人穿出通道进入大帝星范围，王林近距离目睹大帝星：星内自有强大威严，随其肉眼难察的转动向四周散去。
- 踏入后立即发现异状：
  - **无罡风层**——王林此生首次踏入修真星而未遇罡风层。
  - **全星无山**，尽是平原，遍生叶片极大的古怪植被（一叶可容数人躺卧），几乎覆盖全星。
  - 唯**西北区域**植被稀少、露出灰色地面，中有约**千里空地**，四周布满禁制。
- 大帝使者说明：该处即次日落生会长老之选的赛场；随后告退回去引导其他修士，并称明日一早自有人通知少帝前往。
- 王林待其客气故亦客气相送（其性格：别人对他客气，他自然客气相迎）。

## 四、试禁与古魂禁现形

1. **虚按试探**：王林在赛场禁制外抬右手虚按，磅礴禁制之力凝为仿若实质的龟甲，边缘无数漩涡在虚实间急转；反震之下他右手一麻，连退三步，反震中隐含**一丝沧桑之魂**。
2. **初步判断**：「不是破灭禁、也不是生死禁、更不是岁月禁……隐隐像是四大禁中已失传的**古魂禁**」。
3. **以雷图逼启全禁**：王林跃至半空，右目雷光一闪、瞳内雷霆印记急闪，双手掐诀化出巨大**雷图**，引动天地无尽闪电，天空如覆雷云；推动雷图随身直冲千里赛场。
4. **巨龟显形**：赛场灰色光芒如雾卷动，先凝出比先前大数倍的龟甲，继而四周急速延伸——**一尊千里大小的巨龟**浮现于大地：
   - 正西为巨大头颅，嘶鸣中钻出半根独角，弥漫水浪之气，令王林恍见大海；
   - 正东为一条不长的龟尾，尾上鼓包钻出翻着幽光的剧毒利刺；
   - 四条龟足弹出锋利指甲，似可撕开长空；
   - 通体灰色龟甲闪烁，仰天长嘶，音浪化作扭曲波纹，天地色变。
5. **收手**：王林本无意强攻，施雷图只为逼使禁制彻底开启；目的达成即散去雷图后退，巨龟随之低头消散，一切恢复如常。

## 五、古魂禁设定（四大禁）

- 四大禁：**破灭禁、生死禁、岁月禁、古魂禁**。
- **古魂禁**极为神秘，已失传于岁月之中；遗留线索指向：**与凶兽有关，拘凶兽之魂与肉身成禁**，配合种种特殊手段，威力极为强大。
- 王林最终确认：大帝星西北千里赛场之禁，正是古魂禁。

## 六、悬念与后续

- 神秘大帝的真实身份与图谋未明，落生会显然只是其棋盘上的小事。
- 那女子对「名字」的执着与名傀司术，构成对王林的潜在威胁。
- 次日一早，落生会长老之选将在这座由古魂禁守护的千里赛场举行。
