# 仙逆 第647-648章：鼎 / 太古雷龙

## 一、场景与三方
地点：火妖郡内深渊，近出口处（外界阳光已可晃入）。三方为王林（携周佚所在仙剑、蚊兽群）、辰龙（大罗剑宗、剑尊凌天候弟子）、贪狼（与凌天候同辈的老怪，法宝极多）。争夺目标：贪狼极为在意的一枚令牌。

## 二、第647章「鼎」

### 1. 辰龙抢牌，凌天候本命剑气现
- 辰龙掌中凝出凌天候的本命剑气，王林见之心惊肉跳；周佚传音提醒「这是凌天候的本命剑气，威力很强」。
- 王林因此止步，含术不发，冷眼旁观。

### 2. 贪狼放出第二元神
- 贪狼本体困于蚊兽群，七根银针绕体旋转，只能坚守一时。
- 蚊兽群特性：全身坚硬、口器如铁精；被杀则化红云退下再度凝形复活，虽略萎靡仍扑上——近乎不死。
- 贪狼咆哮「辰龙小辈，老夫杀了你！噬死三式」，声浪化实透出蚊兽群，凝成一晶莹剔透小人＝**第二元神**（相貌与贪狼不同，气息相同），掐诀降下黑色神雷群轰辰龙。
- 辰龙甩出凌天候剑气横扫，剑气逐一撞碎神雷，深渊之壁被扫得碎石尘土飞扬。剑气上附有辰龙一丝意识，可自主拦阻第二元神；第二元神不敢硬碰，只能待剑气消散。

### 3. 天迷香
- 贪狼取出手指长短的檀香——**仙界至宝「天迷香」**，心痛不已，点燃后青烟缥缈成雾，将所有蚊兽尽数包裹，贪狼踏烟冲出蚊兽群追向辰龙。

### 4. 王林两次「定」，夺牌
- 辰龙已见出口、出言告辞「这令牌，在下取走了」。
- 王林默吐「定」——下品仙术、锁天定地：虚空生细丝缠身，辰龙身体元神俱顿、体内仙力凝固，令牌脱手。
- 贪狼扑向令牌，王林再吐「定」，贪狼一顿即恢复、细线崩溃，但王林已借周佚仙剑之速临近，从贪狼身边一扫而过抢走令牌。贪狼双目通红。

### 5. 黑鼎：乾坤逆转
- 贪狼祭出一人多高的通体黑鼎，刻无数符文与兽形，散洪荒之气。喝「乾坤逆转，天地翻身」，黑光照耀天地，天地倒转。
- 王林与辰龙位置**瞬间对调**：王林落入烟雾包裹，辰龙落到出口方向，二话不说逃走。辰龙感受到无法抵抗的神威，认定贪狼不愧与师尊同辈。
- 旁白：贪狼无宝之地不去，万年所得宝贝不亚于一座仙府，只是许多自己也用不了；此人极机敏，不妙即逃。
- **王林认识这尊鼎**（伏笔），毫不犹豫把令牌收入储物袋。

### 6. 周佚出手与山河图屏风
- 周佚驱仙剑爆发剑气风暴，喝「开」，撑破烟雾缺口放王林冲出，随即一剑刺向贪狼，评「此人修为寻常，但一身法宝诡异莫测」。
- 贪狼自陈来历关键：「老夫要感激司徒南，若非为了他，老夫怎么可能在那废弃的朱雀星呆上万年」——正因这万年，他领悟了大量原本无法使用的法宝。
- 取出屏风，抛出化十丈大小，绘淡墨山水云雾。称未找到当年仙界的**山河图**，却在此屏风上发现了山河图的**投印**，喝「给我收」，屏风生大量吸力。
- 周佚幻化出仙剑之外，放出体内仅存两道本命剑气中的一道抗之。

## 三、第648章「太古雷龙」（开头部分）
- 王林判断：贪狼法宝太多，周佚即便能胜也需时间，自己当务之急是拉开距离、拖延等周佚归来。
- 王林运转体内凌天候剑气开道，全速冲向深渊下方；第二元神（水晶小人，体外黑色雷球环绕成圈）以雷球破开阻力紧追。
- 第二元神掐诀虚拍，分出九个雷球一字排开如九星连珠，箭矢般射向王林。
- 王林拍储物袋放出**射神车**，化电光雷球再扩为**雷兽**——天下雷之仙兽，鼻息喷两道青气，巨目含电一扫，九个雷球反而更快，却尽被雷兽张口吞下。
- 第二元神随即令周身黑雷如雨落下，又一拍眉心飞出一把闪电锤子，向下敲来。（章节在此处未完）

## 四、要点与伏笔
1. 贪狼与司徒南有旧，且因司徒南滞留废弃朱雀星万年——直接勾连王林体内司徒南一线。
2. 王林「认识」那尊黑鼎，未言明来历，为后续伏笔。
3. 「山河图」为仙界之物，贪狼只得其投印，暗示仙界遗宝线索。
4. 王林此时的战术资源：下品仙术「定」、凌天候剑气（体内运转）、蚊兽群、射神车／雷兽、周佚所在仙剑（周佚仅余一道本命剑气）。
5. 作者耳根在647章末自述首次感到写作瓶颈（作者感言，非剧情）。

# 第649章 富贵凶中求，道缘险中取！

## 一、场景与态势
- 地点：深渊内部，王林持凌天候剑气一路下沉，目标是深处回廊/深渊底部的深坑。
- 追兵：贪狼的第二元神（手持雷锥），紧迫不舍；同层深渊出口处，贪狼本人正与周佚斗法。
- 环境：越向下阻力越强，最终连王林与第二元神都被迫减速。

## 二、追逐战经过

### 1. 仙笔符文御雷
- 第二元神以雷锥放出电龙扑杀，王林取出**仙笔**，身前划出五笔金色符文，并分出**五股元神**融入其中。
- 符文光亮如太阳，与电龙对撞：深渊之壁崩溃、碎石上飞，连下方阻力都为之一缓。
- 代价：符文化作五道神识回体，王林踉跄、面色苍白。电龙随后龟裂崩溃，残余被**雷兽**吞食（雷兽以神雷为食，并挑衅第二元神）。

### 2. 灭仙雷与赤色电网
- 第二元神凝聚赤芒（透出血光），喝出神通**「灭仙雷」**，赤电不攻人，而是钻入深渊之壁。
- 危机临身，王林抓雷兽收入储物袋，全身叠加**生之烙印**，并捏碎大把**姚惜雪所赠的血色玉符**形成层层血光。
- 壁内爆出无数赤色闪电，交织成**电网**；血光被穿透作响，数道落体被生之烙印挡下。
- 王林内心结论：生之烙印对一般神通防御极强，但**面对修为高于己身的大神通无法长久抵抗**——疑因**杀戮仙诀不完善**，或当年灰衣天运子有所欺瞒。

### 3. 由逃转战
- 因下方阻力过大难以通过，加之第二元神如髓入骨，王林火起：「你要战，那便战」。
- 祭出**剑肖三剑 → 三才剑阵**（其上有子鼠、亥猪、末羊三兽邪魂，并融合凌天候剑气）。
- 第二元神全身晶光大闪，以雷锥敲出电龙群缠斗邪魂、阻挡剑阵，意在**消磨剑气**而不容剑气入体。
- 关键发现：第二元神**眉心浮现深刻印记**——即贪狼操控它的烙印。王林定策：击碎烙印。

### 4. 三段杀招
1. **仙术「定」**（定身）——定住第二元神挥舞的手臂；
2. **三才剑阵**——三剑穿过电龙、贯穿第二元神躯体，凌天候剑气毫无保留破坏其灵体；
3. **化魔指 + 一指黄泉**（黄泉指蕴含道化）——两道神通齐印其身，喝「给我爆」。
- 结果：烙印虽弥漫全身试图回天，仍在重击下崩溃；第二元神体表龟裂、随之崩溃。困住王林的电网同时溃散。
- 连锁：深渊出口处与周佚斗法的**贪狼面色大变、身子一晃、喷出一大口鲜血**。

## 三、太吉雷龙的来历与苏醒
- 龟裂缝隙中溢出**洪荒兽威**，三才剑阵上的三兽邪魂立刻颤抖。
- 崩溃瞬间，一道青光自其额头冲出，幻化为全身雷光游走的**青龙——太吉雷龙**（威名赫赫）。
- 来历（回溯）：
  - 贪狼**筑基期**掉下悬崖，于地穴发现**昏迷的雷龙幼体灵身**，小心藏起，遇险时其气息可护主；
  - 后在寻常坊市买到一件被当作废弃的法宝，实为**太古魔器**，贪狼借其化作**烙印封印雷龙**，使其无法彻底苏醒、永为己用；
  - 直至**问鼎之时**才拿来炼化，祭炼为**第二元神**，但始终不敢稍加刺激，唯恐其真正苏醒脱离掌控。
- 龙啸一起，天地色变、风云骤起，连深渊阻力都被疯狂推开。

## 四、王林的评价与贪狼的隐秘
- 王林苦笑：贪狼一身是宝——第二元神竟是一条龙，连**古神涂司当年炼出的鼎**也为其所有，修为又高，堪称「天运福泽之人」。
- 王林并不知情的旧事：贪狼**八岁尚未修道**时玩耍挖出**五百年黄精**，拿回家烤熟吃下，不但未被精气冲击而死，反而**奠定修道基础**。

## 五、坠入深坑（章末悬念）
- 青龙刚苏醒，脑中混沌只凭本能，但仍记得旧恨，化青光直扑王林。
- 王林冲进深渊底部，见前方**无边无际的深坑**，吸力化雾弥漫；咬牙纵身跳入（他并非第一次进入，深知须运转仙力紧靠边缘控速）。
- 青龙不知深坑之险，追入后察觉吸力，以水桶粗的闪电轰击坑壁抵抗，本可冲出，却因发现下方的王林而**放弃逃离机会**，转而扑杀。
- 王林顺势收力，任吸力加速下沉躲开扑击；一人一龙越陷越深。
- 危险升级：王林察觉**坑内吸力正以极快速度增强，好似在酝酿一股风暴**；青龙张口喷出**巨大雷球**直奔王林。

## 六、要点小结
- 战果：贪狼失去第二元神（并因此重伤吐血），王林付出元神与大量血色玉符、生之烙印的消耗。
- 新变量：太吉雷龙脱离封印、本能追杀；深坑吸力风暴将至。
- 设定补充：生之烙印的防御上限、太古魔器封印灵物之法、涂司之鼎流落于贪狼之手。

# 第649-650章 吞噬太古雷龙之灵 · 元神化雷

## 一、坑口对峙：吸力改变战局
- 太古雷龙的雷球挟万钧之势砸向王林，途中忽然一顿、脱离轨道向下——深坑底部涌出无法想象的吸力。
- 王林一拍储物袋放出**三才剑阵**，三剑刺入坑壁互相牵连，他双手死抓宝剑。雷球随即直线坠入坑底，电光短暂照亮下方：万丈绝壁，深不见底。
- 太古雷龙首次露出惊骇——其远古记忆传承中似曾见过类似一幕。它咆哮着冲开少许吸力上飞三丈，试图逃走。

## 二、以定身术锁死雷龙
- 王林恨其纠缠致自己被逼入此地，施展**仙术定身**。往日定身对雷龙只是刹那之事，此刻却成致命枷锁：每当雷龙挣出一丝，王林便再次施定，雷龙被吸力生生拖下十余丈。
- 雷龙射向王林的攻击尚未临近即被吸入深坑。
- 吸力再增数倍，王林手臂欲裂，三剑在坑壁磨出火花与深深剑痕，缓冲飞快消散。危急时他**分出一股元神融入储物袋以元神开启**，放出**仙剑**与**弯刀**刺入坑壁踩于脚下——坑壁上共留下五道下坠痕迹。

## 三、坑壁上的传送阵（伏笔）
- 雷龙被拉伸成极长青气，一端深深吸入坑内，微光照亮四周。
- 借此光，王林看到下方横插出一块**十丈大小的大石，其上有一座传送阵**。青光转弱，大石复没入黑雾。此处**神识无法外散**，未能看清全貌。
- 同时储物袋内那**诡异女音**再度响起：「下去」，回荡王林心神；王林面色阴沉。

## 四、遁入裂缝与雷龙自断
- 脚下仙剑、弯刀骤然一空——坑壁上有一个一丈大小的**裂缝口**。王林荡身入内，并以最快速度收回三才剑阵、仙剑与弯刀。
- 雷龙为躲吸力欲冲入裂缝，因吸力过大，**果断自断身体为二**：下半截被吸入深坑，上半截借势冲入裂缝。

## 五、吞魂：吞下太古雷龙半截灵体
- 王林判断雷龙自断身躯、又分大半气息抵抗吸力，正是其最虚弱之时。
- 他闭目，元神自眉心冲出——**昔日身为香魂（吞魂者），可吞天下一切魂魄，此神通因修为日久已被封尘**——此刻元神化作无穷大，在雷龙欲吐雷球的刹那一口吞噬。
- 设定说明：太古雷龙**自雷中蕴化而生，是天道的宠儿**，太古时期曾替天道行驶雷的力量；吞它不亚于吞下满天之雷，连**天运子**等人也不敢为。

## 六、第650章 变异的元神：多年封印吞噬
- 雷龙不屈，在元神内狂暴反击，电光愈挣扎愈浓，王林元神濒临崩溃，全凭坚定硬抗。
- 王林预感元神留在肉身会波及生机，遂令元神自天灵飞出，右手探入体内**一截截把雷龙拽出、逐段烙印禁制**，边封印边吞噬，周而复始。
- 肉身逐渐萎靡失去光泽，进入**归寂假死**状态以保生机；岁月流逝，年复一年。

## 七、结果：元神化雷
- 雷龙挣扎渐弱，其身覆满密密麻麻封印禁制，叠加如龙鳞。
- 王林元神缩至**三尺高、形似元婴**，通体电光如万条银蛇游走，不复晶莹剔透，眼中透出轮回般的冷漠与威压。
- 肉身已成皮包骨，仅眉心一点生机；元神回体时遇一丝膈膜，片刻消散，随即雷光游走，肌肉瞬息恢复，唯较当年消瘦。呼出的浊气为灰色，内含雷光。

## 八、收获评估（王林自述）
- **雷龙仅炼化五分之一**，其余被封印于元神内。
- 所有神通经测试皆可施展，**道化黄泉**亦如常；但细察可知其内已蕴含**极强雷威**。
- 修为**仍为问鼎初期**，然神通增幅巨大：自认在**问鼎中期**中可占鳌头，配合法宝**可与问鼎后期一战**。
- 右手可凝雷球，但不稳定、片刻崩溃，遂张口吞下，面泛红润后如常。
- 王林自评：「元神化雷倒也有趣，现在想要毁我元神，怕是等于毁了天雷一般」；同时迷茫于自己元神究竟为何物，此变化对修为提升不明显，却为未来道路展开无尽画卷。

## 九、伏笔与待续
- 深坑底部吸力来源不明，坑底深不见底。
- 坑壁大石上的**传送阵**未被查看，是明显伏笔。
- 储物袋内**诡异女音**再次出声干预，身份不明。
- 雷龙五分之四仍被封印在元神内，且未屈服。

# 第651章 灰衣

## 一、元神异变的代价

- 王林总觉「有什么事被遗忘」，回想起元神融入自身肉身时存在一层**膈膜**。
- 排除夺舍可能：散魔之魂同样被封印在其元神内，肉身外观也无夺舍痕迹 → 判定问题出在**元神**本身。
- 尝试出窍数次失败：**元神不能离窍**，仍被那层膈膜阻拦。王林冷静推断这是**元神变异后的代价**，暂且搁置。

## 二、紫色令牌之秘

### 形制
- 通体紫色，内透一丝金芒，交错呈紫金之感；触感**似木非木、似金非金**，材质不可辨。
- 表面分布支离破碎的符文。

### 功用
- 神识探入发现：这是一件**储物法器**，内有独立空间，空间中充斥紫色雾气。
- 内藏唯一物品：一把**剑肖十二剑**中的剑（非仙剑）。王林推断来自此前困于雾中、随雾消散而祭祀令牌的**大罗剑宗**之人，其剑不知何故被吸入令牌。
- 除材质外别无出奇之处；若非亲眼见其由雾气所化，难以想象这就是天运子、凌天候、血祖等人争夺之物。

### 战略价值
- 令牌是**开启洞府的关键**：四座虚府全部打开，方可开启进入最终洞府的大门。
- 据**姚惜雪**所说：天运子等人**不知**第四座虚府的存在，但**血祖知晓**。
- 局势判断：辰龙、贪狼皆知王林拿到令牌，但辰龙没看到全部过程，「若我是他，也定然会认为最终令牌会被贪狼抢走」。
- 处置：王林**张口吞下令牌**，以元神包裹、雷光覆盖，使人看不出端倪。

## 三、绝地困局

所处星空裂缝仅数丈大小，裂缝外一片漆黑，吸力之音如鬼哭狼嗥，越近出口越剧烈。王林逐一试探退路：

| 手段 | 结果 |
|---|---|
| 瞬移 | 不敢尝试（贪狼等人始终未施展，可见其中端倪） |
| 开启洞府（取出水晶） | 无法开启 |
| 土遁入壁岩 | 身子刚触壁岩即生生止住 |
| 抛魂魄试探壁岩 | 魂魄如烟丝飘入，瞬间被撕成无数份，齐齐向下方被大力吸去 |

结论：**绝地**。稍近裂缝口，身子便有被吸扯之感。

牵挂：不知**蚊兽**现状，也不知**周佚前辈**与贪狼一战胜负；即便周佚胜了，以其剑识也无法深入此处，不会知晓王林所在。

## 四、七星剑阵成型

- 从储物袋取出三把剑肖之剑 + 一只断臂 + 一个头颅。
- 本章现身的四把剑肖剑：**巳蛇、午马、酉鸡、戌狗**（其中一把出自紫色令牌）。
- 至此，剑肖十二剑在王林手中已有**七把**。
- 王林右手虚空一抓，七剑环身，喷出元神之气包裹。元神之气中比以往多了一道**雷光**，触及剑体后电光游走，七剑之间以电丝相连。
- 成阵：**七星剑阵**，因雷光交错连接，「此剑阵之威，更添三分」。三才剑阵亦一并取出置于旁侧。

## 五、炼神抽气的异常

- 断臂与头颅内封印着二人元神，且含**凌天候的剑气**。
- 王林以两口元神之气抽出剑气吞服。
- **对比变化**：以往吞服凌天候剑气，元神会有一丝镇痛，需慢慢温养才可恢复；此刻连吞两道，不但毫无不适，反而升起极为舒服的感觉。
- 王林苦笑自语：「这，还能叫做元神么」——再次印证元神变异。

## 六、逼供杜建：师尊的秘密

### 开场
- 取出**禁制之球**，迎风见长至半丈，掐诀一点，球如花朵盛开，露出**赤系杜建**——元神被封印，形同凡人。
- 王林开口：「杜师兄，师尊的秘密，你可以说了。」
- 杜建：「我即便说了，恐怕也难逃一死。」

### 王林之目
- 王林目中微不可查闪过**一丝电光**落入杜建眼中，杜建心神剧震、失声惊呼。
- 杜建的判断：他一生见过无数修士眼带电光，那些都是体内神通所致的**后天之电**；而王林目中这一闪，让他有一种**站在苍穹之下、仰望天雷霹雳而过、无法抵抗**的错觉。

### 刑讯
- 王林隔空抓住杜建伸向裂缝口，吸力之下，杜建以其修为竟感元神要被吸出体外，元神从身体透出、挣扎无用。
- 一字命令：「说」。杜建崩溃：「我说我说」。

### 交易
- 杜建：告诉你一切，但你要答应不杀我。
- 王林：「可以不杀你，你，我另有用处。」
- 杜建要求「以道念起誓」→ 王林皱眉抬手欲再扔，杜建立刻招供。

### 秘密内容
1. **天运子吞下了孙云**。
2. 来源并非亲眼所见：杜建入天运宗后所修功法可从奇兽体内吸收灵力；在后山发现一头寿元将绝的**山精**，吸取其灵力时意外抽出了山精的部分记忆。
3. 山精记忆画面：很久之前，**孙云与天运子曾经大战**，最终孙云被天运子施展神通、整个人被吞下，随后天运子离去。
4. 天运子当时神情：「好像是有些**遗憾**」。
5. **关键异常**：山精记忆中天运子身穿**灰衣**——杜建从未见过师尊穿灰衣。

### 王林的反应
- 听到「灰衣」，王林**双眼猛地爆出精芒**，一字一字追问：「你确定，是穿灰衣？」
- 杜建点头确认：「没错，是灰衣。」
- 此为本章章名「灰衣」之所指，为后续伏笔。

## 七、本章要点归纳

- **能力线**：元神变异 → 不能离窍（代价）+ 吞噬剑气无痛（增益）+ 目含天雷之威（威慑）。
- **法宝线**：紫色令牌=储物+开启最终洞府的钥匙之一；剑肖十二剑集齐七把 → 七星剑阵（雷光加持）。
- **情报线**：血祖知第四虚府 / 天运子等人不知（姚惜雪言）；天运子当年灰衣吞噬孙云。
- **处境线**：身陷绝地，一切遁法与传送皆废。
