# 第1720章 天运子，你能么？（第一更）

## 一、赴约前的推演

王林立于修真星天空，心中生寒，恍惚间似见远处星空中天运子的白袍巨影遥望自己——此为心寒所致的虚象。他自知与天运子之战「更多需要的是心智」，遂在赶路途中逐条推演：

- **天运子的手法**：引他去一个个地方、吸收一个个分身，令体内其魂壮大，最终达成某种目的。表面看是**夺舍**，但以天运子之莫测，很可能另有所图。
- **对拓印的怀疑**：千余年无数生死磨砺换来的本源，被天运子「不费吹灰之力」全部拓印，绝无这般容易；王林不信他能完美获得自己全部本源。
- **对轮回一体术的证伪思路**：若天运子真已完全掌握此术，则戮必非第一个与其分身融合者，此前当有多人遭遇相同，天运子本源应极多。而若真有这等神通，仙罡大陆的大天尊们必抢破头，修道、法术、感悟本源皆成多余，大天尊与仙族古国皆如蝼蚁。故王林断定：**此术必有致命破绽，甚至能否真正拓印本源都是两说**。
- **复盘**：他细察火、雷、因果三次本源对抗的记忆流，「没有端倪」，沉思后神色果断，一晃消失。

## 二、召河星域碎石区的对坐

天运子盘膝坐在一片漂浮星空的碎石上，嘴角挂着诡异微笑等候，笑称「这一次，来的有些慢了，徒儿」。王林长虹呼啸而至，临近不足百丈踏碎石而立，与之对望。

王林先是沉默，随即**转怒为笑**、盘膝坐下，阴沉尽消而代以平和：

- 王林：「天运子，王某的本源，可还满意。」
- 天运子：「还不错，只是有些少了，还无法让老夫完全满意。」
- 王林顺势索取：这些年只明悟了**七道本源**，「你若不满意，不如送我几道，待我明悟后再取走」。

王林的平静让天运子心生古怪与忌惮——他更想看到的是「莽夫一般」的王林。

### 天运子的两次赠予

| 赠物 | 来历/性质 | 说明 |
| --- | --- | --- |
| **水之本源**（一滴晶莹水珠） | 天运子早年在别人身上所获，只有一丝 | 不足以凭此突破进入**第三步**；已随天运子很久。若王林能完全感悟、诞生真正的水之本源，天运子「也会感谢一番」。飘于王林眉心 |
| **一撮泥土**（土之本源） | 天运子手心所出，如活物般蠕动变化 | 王林追问「还有么」后所赠 |

天运子随即抛出「游戏」之说：这场游戏很多年前就已开始，王林赢了便解此危机，还有「为师送你的造化」，不管他愿不愿意。

## 三、破局：以道古血脉戳穿伪装

天运子说罢抬手点向自己眉心欲再度自杀。王林挥手放出蕴含**道古血脉之力**的狂风，震碎四周碎石，打开天运子右手，指尖划过额头留下一道血痕。

王林当面拆穿：

1. 「你不要如此着急去死」——我要杀你很容易，你不必在我面前自杀。
2. 屡次诡异死亡、故作莫测**不是天运子的性格**，是怕被看出什么、要掩盖什么。
3. **核心质问**：「你就算偷走了王某的本源与神通、记忆，但你能偷走我的道古血脉么？」
4. **下战书**：「你若能现在施展出一式道古血脉神通，那么王某就此认输，听你摆布。你，能么？你敢么？」

天运子长久沉默、未施展——他自己知道**他不能**：道古血脉之力他无法拓印，这正是他以诡异死亡掩盖并扰乱王林心神的目的之一。

王林乘胜连番压制：
- 「你的种种神秘，也都是装出来的」；我不再是当年刚去天运星、也不是妖灵之地时的我。
- 修为超不过我、血脉没我高贵、身份与我相比如蝼蚁；我带领界内修士对抗界外时，你还躲在暗处。
- 我的雕像可放在仙界受万万年膜拜、我可组仙界被无数修士记住，「你能么」。
- 「我王林不喜阴谋，我喜阳谋。」

## 四、反客为主：改写游戏规则

王林由「你身上没有任何道古气息」推出关键判断：**轮回一体术拓印不了道古血脉；一次次死亡的都是分身——那么天运子的本尊在哪里？** 天运子面上不变，心神却骤然一震。

王林宣布新规则：

- **比什么**：是他先找到并杀死天运子的**本尊**，还是天运子先一步彻底占据王林的分身（以达成夺舍或其他不可告人之目的）。
- **赌注不对等**：王林只用一个**修士分身**参与，天运子赢也只赢一个分身；天运子输，就是**死亡**——「归根结底你是输不起的」。
- **强制入局**：「现在，就算你不想去进行这场游戏，都不行了。」并告知「我本尊会去寻找你的本尊，天运子，你要速度快一些，否则的话，你会输的」。

章末，王林抬手挥出，道古之力呼啸直奔天运子：「现在，你可以去死了。」

## 五、要点提炼

- **王林的破绽学**：以「若此术无破绽则世界观将崩坏」的反证法，断定轮回一体术必有致命破绽。
- **道古血脉是天运子拓印体系之外的变量**，成为王林翻盘的支点。
- **攻守易位**：从被引导者变为规则制定者；从被动被吸收分身，变为主动以分身为筹码换取本尊猎杀天运子本尊的时间差。
- **额外收获**：水之本源一丝 + 土之本源一撮，均为天运子主动奉上。
