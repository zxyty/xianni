# 第七卷 名震罗天 第734章 占了大便宜

## 一、交易：三道神通换「第三眼」

### 谈判起点
- 老者冷哼退后，自称「刚刚踏入阴虚只有两年」，若再给几年时间，王林纵有再多神通法宝也非其对手。
- 王林收起山魂散回仙山，表明来意：**要用神通交换（第三眼）**。老者初时拒绝，称雷鼎已被王林拿走，令其速离。

### 王林依次展示的三道神通
1. **寂灭指**：右手一指，黑芒直奔后方修真星，落在一处平原，植被瞬间枯萎、生机化出飞回融入王林体内。老者口称「鸡肋」（自称已达阴虚），实则暗惊其霸道，尤其看中**吸收生机**的能力。
2. **化魔指**：黑气绕指，一弹停于老者身前。王林说明其可**转化体内仙气为魔气**，与寂灭指同用效果更佳。老者抓取神识一扫后判断：「传闻东临星修士擅长使用魔气神通，原来你是东临星之人」，嘴上仍称鸡肋。
3. **杀戮仙诀**（压轴）：王林称此术「学自一位第二步碎涅期的前辈」，若仍看不上则作罢。

### 关于黄泉指的取舍
王林权衡后决定：**黄泉指乃当年司徒南最在意之术，即便有缺陷也不可拿来交换**。

### 杀戮仙诀的演示
- 心念一动，**仙卫傀儡**化金光流星奔向修真星（此举令老者面色阴沉），少顷抓回一头浑身利刺、嘴角还叼着半截凡人手臂的凶兽。
- 王林双指成剑，一道剑气入体，凶兽惨哼枯萎成骸骨；一道灰气自骸骨散出缠绕其指，被点化为**生之烙印**掷向老者。
- 王林解说（原话来自当年**灰衣天运子**）：「依靠杀戮获得生机之力，以生机之力徘徊身体四周，凝结生之烙印，烙印越多防守之威越强；若全身亿万烙印守护，即便修真星崩溃也可安然无恙。」
- 补充设定：杀戮仙诀在王林手中已修炼**百年以上**，感悟极深；当年凝聚的无数杀戮之气全部注入傀儡，已在一战中消耗殆尽。

### 老者的犹豫与成交
- 老者神识细查烙印后几乎双目冒光——烙印具防护、白气具攻击，且**可多次施展累计**。
- 顾虑：**第三眼是家族传承**，来历不明（疑为先祖无意所得），轻易不能外授；且他是家族得此神通以来**第一个练成之人**。
- 世界观补充：**罗天星域以家族为门派**，每个家族都拥有一些传承神通，故不易被夺；换作**联盟星域**，其家族不可能独自拥有此等神通。
- 王林假意作罢，踏雷兽离去；老者手中生之烙印崩溃消散，如同「本该属于他的神通被抢走」，遂咬牙喊停，同意以第三眼交换三道神通，**唯一条件：此术不得外传**。

### 交割与暗手
- 王林当即取三枚玉简详录三道神通，**不怕对方反悔直接掷出**（此举令老者暗自佩服）。
- 老者以玉简记下第三眼神通回赠，但**故意留下几处错误**，照此修炼即便成功也隐患极大。
- 王林以「看到第三步」的状态复看一遍，**一眼看破端倪却不点破**，只略一点头。
- 临别，王林罕见地心生过意不去，抱拳提醒：「**杀戮之气的数量最好不要超过十万，否则会有危险**」，随即急促离去。
- 老者面色微变，带族人返回修真星立刻闭关，**争取一个月后赶得及去雷之仙界**。

### 王林的盘算
- 自语：「以这三个**有问题的法术**，换取一个蕴含了一丝**第三步方向**的神通，却是有些过分了。」
- 第三眼在老者眼中寻常，在王林看来**极为强大，蕴含一丝回归本源的气息**；若非王林看到了第三步，也看不出其潜力。
- 玉简中的错误不足虑：给他一定时间即可扭转，**比之前修正三大神通简单很多**。

## 二、归返青灵星

- 雷兽速度极快，穿梭星空，目标是王林的修真星——**青灵星**。
- 青灵星修士刚庆幸那位「脾气古怪、有着特殊癖好的前辈」离开，几个月后他又回来了；**横云峰万里之内再次成为禁区**，无人敢踏入半步。
- 王林抓紧研究与修正第三眼神通，慢慢尝试掌握。

## 三、仙雷降临与惊人之举

- 大半个月后，晴空万里，王林立于**横云峰顶**，手托巴掌大小的**雷鼎**（其上雷光游走、声响清脆）。
- 王林**眉心一道细微缝隙若隐若现，散出一丝红芒**，气息邪异，怎么看都不像正道修士。
- 蔚蓝天际骤然阴暗，雷云突现，雷鸣游走；雷鼎内雷光随之更浓。
- 一道粗大闪电自云层直奔王林——**只要落在雷鼎，即可被牵引踏碎虚无、直奔雷之仙界**。
- **转折**：王林却在这一刹那**把雷鼎收起**，喃喃「这可是仙雷啊」，眼中奇异之芒更浓。

> 叙述明言：他接下来的举动，在雷之仙界开启的无数次中**前无古人**。雷之仙界篇由此开启（罗天星域第一个大副本）。

## 四、看点与伏笔

- **交易的双向欺瞒**：老者留错，王林识破不说破；王林拿有缺陷之术换取蕴含第三步方向的神通，自认占了天大便宜，却仍出言相赠「十万上限」的忠告。
- **第三眼已初步显形**：眉心缝隙散红芒，是王林后续修行与「看到第三步」能力的外显。
- **仙雷另有他用**：王林收鼎不上仙界，显然打算把仙雷用于别处——为雷之仙界篇埋下最大悬念。
- **老者的隐患**：其第三眼玉简被换走的三术皆有缺陷，加之杀戮之气上限风险，后续或有变数。
