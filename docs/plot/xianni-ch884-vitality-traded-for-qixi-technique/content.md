# 仙逆 第七卷 名震罗天 · 第884章 生机

## 一、地底应答与许可
- 东临星大地一震，波动自地底深处传出，引发全星剧震。
- 一个平静沧桑的声音回荡天地——向家先祖，其气息仿若穿透虚无与时间、自无数万年前的上古修真界传来。
- 向云东恭敬禀报：**罗天与联盟之战已然开始**；此人（王林，化名许木）在**封仙中名列第一**，已获得向家承诺，但所求之事非向云东之力可为，请先祖施展**七夕之术**。
- 先祖神识骤然锁定王林。该神识极强，但**无法看透王林全身**——王林眉心第三目内那来自本源的力量在此刻弥漫全身，神识一扫即收。
- 先祖令：「让他独自下来。」地面裂开一道深沟壑。
- 向云东心态：此行原本只有一半把握，先祖脾气古怪，纵是向家对封仙者的承诺也未必被放在眼里；先祖同意后他方才微笑，留在地面等候。
- **清水**（右目红芒闪烁）撂话：「若有人敢伤你，这东临星，一切姓氏，血流成河。」煞气令向云东皱眉苦笑。
- 王林心生感激。其一生感激之人不多：**司徒（司徒南）、周佚、遁天**，如今又多了**清水**。

## 二、沟壑下沉：死气与旧道根基
- 沟壑壁光滑，无任何生机，全是死气；越下沉死气越浓，几近化作实质，暴虐寒意疯狂钻入体内。
- 王林可抗的缘由：**修道第一步所修意境即生死轮回之道，早期所修功法为《黄泉升窍诀》**，对死气极熟悉。
- 手段：运转元力，体外幻化**阴阳双鱼之相**缓缓旋转，推开死气；同时打开**因果道念**融入四周。
- 半柱香后仍未落地，直至死气浓到阴阳双鱼旋转都变慢时方才踏地；再沿一条漆黑通道走半柱香抵达尽头。

## 三、人头海与土黄棺材
- 通道尽头是一片极庞大的空间：**密密麻麻、无边无际的人头白骨之海**，死气在人头海中心化作风暴。
- 饶是王林定力亦头皮发麻、后退两步、面露骇然，并有窒息之感。
- 风暴之内、人头搭建的平台上，放着一具**土黄色棺材**，木质溃烂，散出近乎疯狂的气息。声音自棺内传出。
- 王林答：「晚辈**许木**，参见前辈。」（许木为王林此期所用化名。）

## 四、交易：一半生机
- 先祖开价：「仅仅向家对你的承诺，不够，我要你**一半的生机**。」
- 话音落，四周无尽人头骨齐动、双目亮起幽光，尽数凝聚于王林身上。
- 第一次抽取：生机大范围崩溃 → 一头黑发半数苍白如雪，容颜以肉眼可见之速由**青年→中年**；**修为未损**，但前所未有的虚弱久久不散。

## 五、李慕婉残婴的判词
- 先祖令取出要救之人。王林一拍**储物袋**，包裹**李慕婉元婴**的**禁制光球**飞出。
- 光球未及落掌，即被霸道死气卷向中心风暴。王林瞬间忘却双方差距，双目通红、眉心**第三目**毫不犹豫打开，红光成扇形一闪，缠来的死气轰然崩溃，他速如闪电追去。
- 棺内冷哼：「聒噪！老夫取了你一半生机，便会施展七夕之术。」王林被迫停下，眼露寒光。
- 禁制光球崩溃，**李慕婉元婴毫无损伤**，平静飘于半空。
- 先祖判词：「原来是**生机全无、被强行留在世间的一缕残婴**，难怪要来这里求老夫施展七夕术。」
- 把握度：**若当年巅峰之时**施七夕术，可让残婴恢复、甚至勉强苏醒；**如今只有三成把握**。

## 六、代价兑现与天道召唤
- 第二轮抽取：人头海幽光大作，死气环绕，从王林体内抽出一道道生机——**这些生机就是王林的寿元**。
- 结果：发尽白且大片脱落，身躯枯萎，皮肤满是皱纹；容颜由中年数息内衰老为**沧桑老者**，依稀可见当年身影；双目黯淡，虚弱数倍临身。
- 王林隐约感受到虚空中的**一股召唤**——千年修道使他明白那是**天道轮回**：寿元不多，轮回天道已开始召唤，**一如当年李慕婉寿元断绝时神损而亡**。

## 七、要点与悬念
- 交易已成，代价已付（一半生机/寿元），七夕之术尚未施展，成功率仅三成。
- 王林当前外貌为苍老老者（寿元被抽所致，非伪装），修为未受损。
- 大背景：罗天与联盟之战已开打；王林为封仙第一，持有向家承诺。
