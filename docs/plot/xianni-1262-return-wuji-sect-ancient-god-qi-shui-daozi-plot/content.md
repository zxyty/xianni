# 《仙逆》第九卷 云海之巅 第1262章 回来了……

## 一、神宗：白发童子自曝身份与旧事

阴森宫殿内，白发童子的声音掀起风暴，连修真星外的星雾都剧烈云涌。

- **自报名号**：童子自称「**水道子**」，当年随主人征战天地，多次险些身亡，受过主人救命之恩，自认恩怨已消。
- **接管神宗**：主人死后神宗由其接管，他辩称「主既已亡，神宗自然要有新主」，做的没有过错。
- **当年围杀**：主人之死出自**水道子 + 掌尊 + 妙音道尊**三人全力合击，另有**来自远古仙域的几个神秘上修**暗中出手，「即便你修为通天，也必死无疑」。

## 二、数月前的气息与恐惧

- 数月前水道子感受到一丝主人的气息，心神一颤，数月来有**天塌之感**，惶惶度日。
- 他修道无数万年，自主人死后**第一次**再有此种恐惧——这恐惧在主人未亡前一直存在，主死才松口气，如今清晰归来。
- 反应：不惜一切代价发动**神宗**疯狂调查；即便接到**昆虚圣女**玉简、贪图**昆虚传承**，也不敢亲往，只**派弟子迎接**。

## 三、两种推断：转世重修 or 藏身天逆

- 疑点：若主人转世重修，当年搜其魂魄的远古仙域上修不可能没有察觉；但数月前的气息他绝不会感受错。
- 结论二选一：**主人转世重修**，或**天逆再现、主人隐藏在天逆之内**。
- 态度：「即便你真的转世重修，我也要再杀你一次。」当年远古仙域上修所寻的**天逆并未找到**；**天逆他不敢碰**，但**逼出藏于其中之魂**做得到。

## 四、破绽：定身术

水道子点评「吕子浩」（实为王林化名）：

- 「你种种神通没有露出任何让老夫怀疑之处，**唯独一样——定身术**。」
- 此术世间**仅主人、青霖、水道子**三人掌握，是主人**从远古仙域带来的远古仙术**。
- 青霖当年以为是偶得之术，未加重视，因跟随主人时间不如水道子长，不知此术之强足以惊天动地。
- 术之极致：**定身、定魂、定仙、定元、定天地运转、定星河流淌、定时光岁月、定空间变化**。主人死后，无人比水道子更懂「定」之一术。

## 五、水道子的计划（关键决定）

1. 暂**让吕子浩在无极宗继续存在一些时日**，不鲁莽前往。
2. 祭炼**九面万古轮回镜**，布下**轮回大阵**。
3. 无论主人是重修还是藏于天逆，「这一次，决不能让你再逃走」。

> 令其谨慎的不是王林本人，而是其背后的主。

## 六、无极宗鲁肃山：王林的暗中吸收

- 王林坐于鲁肃山阁楼，**古神气息顺双脚疯狂涌入体内，在眉心凝聚**。
- 无极宗宗主与太上长老借闲谈**试探其神通来历**；王林为分散注意力（因吸收会使此地变化越发剧烈）神色如常、含笑而谈。
- 王林所论：「**天地之道在乎于心，心中有道，自然可以幻化万物，更可凭此万物融入道念，转化成为自身神通之术**。」宗主听罢苦笑——等于什么都没说，又说了一些什么。
- **交割极阴之魂**：两名弟子取来**六面小旗**，王林神识一扫，每面旗内均有一个**极为精纯的极阴之魂**。
- **约定**：宗主请其**五日后八阶分宗大比**全力出手；王林应允，随即以「离开归元宗百年、要回去与晚辈叙旧」告辞。
- **收获**：仅一炷香，眉心**崩溃的第六星点**重新出现，化为一片**微弱的漩涡**，未彻底恢复但已是天地之差。王林盘算：日后仍有机会再来吸收，**那把被星点祭炼的剑也会落到我的手中**。
- **收尾**：其离开后山中古神气息渐弱、再次沉睡；全程谨慎吸收，未露破绽，最多有人觉得此山内外天地元力略有不同。

## 七、无极宗的评估

- 宗主：「此人，不凡——他一来到这里，便使得此地天地元力出现了一些变化。」
- 太上长老：他既是归元宗之人，也算无极宗门下，这种人物**莫要太过强压**；其能出战八阶宗派大比，对无极宗是盛事。
- 宗主大袖一甩，神念环绕鲁肃山：**召集所有太上长老商谈此事**。

## 八、归途与重逢

- 弟子**孙德**奉命引路，一路落后半步、不敢越前，送王林**破开星空**回到那颗被阵法禁制封印的修真星，再以玉简传音问明归元宗所在。
- 抵归元宗庭院，弟子告辞而退。王林看到远处的**木冰眉**与庭院内的**李倩梅**。
- 月色如银纱披在李倩梅身上；她抬首含笑：「回来了」；王林落于数丈外，沉默片刻后轻声：「回来了。」
- 月光将二人影子拉长，边缘似有一丝重叠，**很快又分开**；四周唯有风吹花草之声，二人皆沉默。

## 九、待办 / 伏笔

- 五日后**八阶分宗大比**，王林须为无极宗出战。
- 水道子的**九面万古轮回镜 + 轮回大阵**尚在祭炼准备中，为后续针对王林的杀局。
- **天逆**下落成谜，为远古仙域上修与水道子共同追寻之物。
- 鲁肃山**被星点祭炼的剑**为王林后续图谋目标。
