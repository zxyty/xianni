# 第七卷 名震罗天 第681章 王平

## 一、剑气追击：漩涡崩溃

- 王林祭出凌天候的剑气，剑气出现之刹那天地八荒剑气纵横，冲入幻家老祖遁走的漩涡。
- 漩涡在剑气冲击下当即崩溃，其内传来幻家老祖闷哼。
- 场景切至千幻星幻家祖宅闭关密室：幻家老祖盘膝而坐，身前巨大漩涡寸寸碎裂；一道白光卷着柳眉冲出，将柳眉甩到一旁后急钻入幻家老祖眉心（元神归体）。
- 幻家老祖睁眼骇然，隔空一拍喝「碎」，试图打散漩涡通道，把剑气困死在虚无中。

## 二、幻家老祖的心理与判断

1. **杀王林失手**：先前元神出窍跨星空救柳眉，那一指本欲取王林性命，却在落入其体内后于**元神处被生生震散**，只能伤人不能杀人——王林体内元神「明显有些诡异」。
2. **忌惮仙卫傀儡**：仙卫傀儡境界为**阴阳虚实**；老祖自身因虚弱修为降至阴阳虚实之境，判断即便能胜也会致修为再降。若修为未降，本会毫无顾忌直接杀戮。
3. **柳眉不可弃**：柳眉是他辛苦培养，除冠冕堂皇的说辞外另有**不可告人的大用**，绝不允许其在踏出第二步前被杀；一度动念交人，随即咬牙放弃。
4. **对剑气的评估**：从剑气上隐约察觉**净涅期**的可怕气息，「哪个净涅期的前辈这般疯狂，居然把剑气交给处于第一步的小辈」；推断剑气主人与王林关系极亲近，甚至可能是**嫡系传人**。若王林有**六道以上**此等剑气，除非恢复窥捏修为，否则必死无疑。
5. **地缘算计**：断定王林是**联盟星域**之人；无**罗天石**则外人不可能进入此地，除非对面亦有传送阵；即便其师尊到来，也将升级为两星域之战，自有**雷仙殿**高手出面。且若其在柳眉身上的计划成功，修为或可达净涅，至少窥捏大圆满。

## 三、密室崩塌与硬接一击

- 漩涡化作晶芒消散之际，一道金芒骤然冲出，密室内爆出千千万万道剑气，巨响震动整个千幻星。
- 幻家密室坍塌炸裂，老祖抓着柳眉狼狈化虹而逃。
- 剑气内蕴**凌天候的霸道意境**：天地一顿、风云倒卷如云海潮汐，天空为之一暗，千幻星所有大神通修士皆有所感；此意境「你越示弱，他便越强」——是为**天威**。
- 幻家老祖甩开柳眉、双手合十，以毕生道念**万幻无相道**（可迷幻一切）催白光，全身元力灌入手指一点迎击。白光消散，剑气顺其手指直入体内，身形一晃、面色苍白。
- 此刻他想起王林那七个字——**「你救她，幻家灭族」**，如七道奔雷炸响耳边，再不敢轻视。

## 四、设定要点：修道第一步 vs 第二步

- **第一步**：凭逆天法宝与强大神通，可挑战高出境界者，配合得当甚至能直接秒杀。
- **第二步**：绝无越级挑战之事，每一关卡皆天地之差；单是**窥捏初期与中期**便是不可跨越的沟壑，遑论窥捏与**净涅**之别。
- 净涅期修士的**一道剑气**便令窥捏期老祖不敢硬抗，可见一斑。

## 五、求援

幻家老祖打定主意后，神识散开传遍千幻星：「千家老友，许家兄弟，幻某有要事相求」。

## 六、冉云星：认子与改名

- 王林收回望向崩溃漩涡的目光，落在被**仙卫傀儡**围住的黑雾上；黑雾内稚嫩厉声阵阵，每一声都如利剑刺入王林心中。
- 黑雾中一双浑浊眼睛与王林对视，散发浓浓怨气。王林自问：「这，便是我的孩子么我王林在这世间的嫡亲」
- 王林走入傀儡包围圈，将右手伸入雾中；怨婴咬破其手指吸血，阴寒怨气顺伤口冲入王林体内，王林不收手，目光始终柔和。
- **改名**：「你的名字叫做厉儿么厉这个字，不好，换成平吧，从今以后，你的名字，叫做王平我希望你一辈子都平平安安，不要像我这样。」

## 七、后续伏笔

- 幻家老祖已联络千家、许家，冉云星/千幻星方面冲突将扩大。
- 王林手中凌天候剑气的数量成为关键未知（老祖以「六道以上」为生死线）。
- 柳眉被带回幻家，老祖在其身上的秘密计划仍未揭晓。
- 怨婴（王平）与王林的父子羁绊正式确立。
