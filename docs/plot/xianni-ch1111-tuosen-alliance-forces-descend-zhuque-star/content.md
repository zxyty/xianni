# 第八卷 联盟隐秘 第1111章 拓森！

## 一、凡间序幕：流云城曾家与“仙人”传说

- 清晨的朱雀星流云城，城西吃食小街人声鼎沸。年入五旬的**曾水山（曾老汉）**在此摆摊卖酒，曾家酒清淡爽口、早起饮之神清气爽。
- 一名中年汉子调侃酒味不如从前，曾老汉搬出祖训：曾家酒“千年来代代相传”，最早曾被一位仙人品尝赞叹。
- **曾家祖传传说**：曾家原非流云城之人，因一次雪灾迁移而来；先祖**曾大牛**与一位仙人共居六十余年，那位仙人是曾家迁来此地的大恩人。曾大牛活到一百三十七岁，临终仍念念不忘。
- 曾家至今供奉着有一千多年历史的木雕，刻的是第一代祖先与一位**面部模糊的仙人**。
- （叙事暗线：此“仙人”指向王林早年在凡俗的经历，本章仅以凡人视角侧写，未点名。）

## 二、万修降临：各方势力齐聚朱雀星

- 晴空骤变：肉眼可见的巨大波纹横扫天穹，雷鸣咆哮，一道道长虹如流星降临，破开罡风层化作修士。
- 凡人惊呼“仙人”，纷纷躲避；一个威严之声传令：**“不要惊扰了这些凡人，速去修魔海集合”**。此幕在**整个朱雀星**天空几乎同时上演，凡间帝国惊慌，但外来修士未伤及凡人，落地即远去。
- **本土修士的落差**：朱雀星化神、婴变修士无人敢飞起质问；连不多的**问鼎**修士也心神震撼。问鼎修士**周武泰**神色阴沉，自忖长虹中只有极少数他可对抗，更多者仅气息就令他倒吸凉气。
- **雷仙殿大殿**：一座座巨大殿宇的阴影遮天蔽日，大地半黑，但它们**未降临朱雀星地表**，而是环绕在朱雀星外星空——因朱雀星已半废弃，承受不住雷仙大殿降临掀起的天地波动。
- 随后**一座座大小不一的棺木**自天而降，四周跟随大量修士。

## 三、云天宗雕像风波（关键转折）

1. 一名性格桀骜的**罗天**修士路过云天宗，见小小修真星上竟有如此庞大雕像，冷哼抬手欲毁。
2. **西子凤**在其身后一声“住手”，冷冷令其看清雕像所刻之人，随后复杂地看了雕像一眼、内心幽叹而去。
3. 该修士凝神细看，脑中如雷霆划过，失声道：**“这是正品雷仙——许木！”**
4. 背景：罗天虽已取消王林正品雷仙的资格，但**当年争雷仙一战声威赫赫**，数百年不足以让人遗忘；且**许木道号魔道子、杀戮滔天**，非其能招惹。他自觉毁人雕像“阴损无聊”，转身疾驰而走。
5. **炎雷子**等人、**尸阴宗**之人同样认出雕像，各方号令传递之下，**再无人有破坏雕像的想法**。

> 归属说明：此处“许木”即王林在罗天星域所用之名（自第661/669/711/731/771/821/881章沿用），雕像亦为王林之像。

## 四、第一批探查：冲入修魔海古神之地

- **参与方**：尸阴宗、罗天、各方修真联盟等势力，齐聚朱雀星后直奔修魔海。
- **规模**：真正进入朱雀星的第一批查探者**加起来不到七千人**；更多修士弥漫朱雀星外星空，**彼此壁垒分明**，静待第一批的消息。
- **动因**：王林给出的玉简可信度极大，但**仍需验证**。
- **推进**：古神之地的所有禁制对这批高手形同虚设，势如破竹，越过碎星环外禁制，直抵古神之地入口的椭圆形光圈。

## 五、深渊血战与沉睡者苏醒

- 光圈内传出嘶厉咆哮：第一道关卡——**几乎没有尽头的漆黑深渊**（当年险些让王林丧命、**雷蛙**最早出现之地）——其中原本漂浮的一座座锥形巨石**尽数崩溃瓦解**，下方一双双凶焰之眼骤然闪烁，无数凶兽静待。
- 咆哮未能止步任何人，修士一冲而出踏入光圈。
- **首杀**：第一个现身的修士被下方射出的**赤红色电流**瞬间麻痹，随即被一头**长约万丈的巨大红莽**一口吞噬。
- 此举如同厮杀信号，凶兽疯狂冲出，与陆续涌入的修士生死搏杀，**鲜血如雨**，更激起凶兽凶焰。
- **惊动沉睡者**：厮杀引动的天地元力波动，惊扰了深渊至深之处——**连当年的王林也未曾探查过的地方**——一个沉睡的存在，**两道血红目光遥遥盯住上方修士群**。

## 六、章末定格：拓森

- 同一时间，**古神之地内部的血海**中，一块巨大锥形石块之上，**一头红发的拓森**手指在地面轻轻滑动、发出刺耳声响。
- 他慢慢抬头，狰狞面部透出一丝残笑，**缓缓抬起右手，向着旁边狠狠一抓**（章节在此戛然而止）。

## 七、伏笔与看点

- 曾家“仙人”传说 → 王林凡俗旧缘的余响，与其云天宗雕像形成呼应。
- 雕像未毁 → 王林“魔道子/正品雷仙”余威仍震慑罗天与各方势力。
- 玉简待验证 → 各方以七千人做第一批“试水”，主力在星空外观望，势力之间壁垒分明。
- 深渊至深处的血红目光 → 比雷蛙、凶兽更高层级的未知存在，尚未登场。
- 拓森抬手一抓 → 血海中的主导者开始行动。
