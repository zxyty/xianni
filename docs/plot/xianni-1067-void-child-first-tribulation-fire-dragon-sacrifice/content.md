# 《仙逆》第1067章（第八卷 联盟隐秘）剧情梳理

> 场景：妖灵之地内的仙帝洞府第七层，焚天煮海之中；外部同时波及整个联盟星域星空。

## 一、虚空子：以重伤之身强渡天人第一衰

- **抉择**：虚空子元神飞出，言「今日生死危机，老夫宁可去拼一下那天人第一衰，也不愿被煮死在这里」，双臂伸开主动引劫。
- **天象**：仙帝洞府所在妖灵之地外的无尽星空中（朱雀真灵与朱雀圣宗众人所在之处），骤然亮起五颗星星；联盟星域内任何地点、无论昼夜皆清晰可见。
- **坠星**：五星中最亮者光芒暴增掩盖其余四颗，随即如自天空坠落，直奔虚无，速度远超一切修士极限。
- **旁观**：星空中昆虚之境的老者与绝美女子同时抬头，老者神色如常，喃喃「有人经劫天人第一衰」。
- **贯穿**：星光穿透尘埃进入妖灵之地→引动魔气倒卷→穿透大地→连穿六层→入第七层焚天煮海之内→落于虚空子元神。
- **代价与收益**：修为疯狂暴增，但元神在星光下飞快消散，痛苦惨叫；借力一冲破开天空魔火向前遁去。
- **设定点**：对**碎涅**修士而言，天人第一衰**只是刚刚开始**。
- **塔珈的算计**：本欲隔空抓回，却放下手臂——「以重伤的状态提前经历天人第一衰，此人若是不死，成功的话，倒也可以成为我一个散魔」。

## 二、王林一方的绝境

- 被困魔海内的**贝罗、王林、火龙**已至生死存亡阶段。仙帝神通叠加古魔魔气，使焚天煮海威力可怖：海水大范围减少、温度更高。
- 王林虽有**朱雀之身与古神肉身**，仍感炙热痛苦，肉身酸软，无法冲出；天空魔火尽数落入海面，神通达到巅峰。
- **心境**：王林罕见地承认自己算错——若当初与**胡娟、王巍**一同离开，也只是延后，终会被追上，仍要面对古魔塔珈，「前与后，结局都是一样」。
- 回忆此前诸多凶险：面对**血祖**、遭**姚家**追杀、结丹时面对**古神之地**。此次现实残酷，但道心不崩：他还有**天逆**，还有**本源**。
- 火龙神色萎靡、身子渐缩；贝罗妖气纵横亦属徒劳。

## 三、火灵龙的选择——转折点

- 塔珈肩上盘坐着缩小的**黑衣人元神**（外绕一条炎龙），贪婪盯着火龙。
- 塔珈揭示来历并赐礼：「这头火灵龙是当年**青霖**炼化而出，对于青霖忠心耿耿，以它的灵智，自然分辨的出本魔并非青霖，**罗睺**你既然是掌尊弟子，这火龙便送你吞噬」，随手将其元神抛出。
- 黑衣人元神化炎龙扑向火龙；火龙昂首龙吼成音爆，震得魔火一顿，逼其暂退。黑衣人不急，断定火龙撑不久，同时觊觎王林的**朱雀**（「还有他的朱雀，也是我的」）。
- **火龙宁死不从**：庞大身躯骤缩至十丈，龙眼露死意与决心，直奔王林——宁可择在其身上能感到「一丝亲切」的此人，也不让黑衣人吞噬；最后一声咆哮后冲入王林眉心。

## 四、王林异变：本源火种将成

- 火焰之力顺眉心融入元神，萎靡的**朱雀图腾**苏醒幻化，响起朱雀之音。
- **同源相融**：火灵龙的火元力与朱雀之炎虽不同，但本源皆为天地之火；融合后王林体内火元力疯狂暴增并生**异变**。
- 王林猛然起身，在魔火下重获移动之力；双目火焰滔天，体外形成火焰风暴，其中朱雀环绕、火龙虚影弥漫，风暴化作巨大漩涡，反向吞吸焚天煮海的魔火。塔珈亦为之一怔。
- **贝罗的判断**（古妖身份亦倒吸口气）：
  - 王林体内正疯狂凝聚出**白色火种**，即**本源火种**；
  - 「只差一丝」即可完全凝聚；
  - 火种一旦凝成，**天下之火均在其操控之内**；
  - 魔火内**有意志存在**，但**塔珈夺舍尚未达到完美**，故仍有机会。

## 五、贝罗出手：古妖碎星

- 黑衣人元神骇然放弃吞噬、疾退，却因近漩涡被吸扯；塔珈抬手虚空一抓将其擒住欲收回。
- 贝罗于此刻咬牙施展**古妖碎星**：右目七颗妖星急速旋转，先崩碎一颗——化作大力涌入体内，使其挣脱束缚（虽仍受魔火焚烧、不能冲出，却可施展神通）；再崩碎第二颗——身形蓦然放大，一步来到黑衣人元神面前，整个人化作妖气漩涡横扫，与塔珈隔空抓取之力硬撼。
- 章节在此处中断（未见胜负）。

## 六、关键设定与伏笔

| 项 | 要点 |
|---|---|
| 天人第一衰 | 五星现于联盟星空、最亮一颗坠落加身；增修为、损元神；对碎涅修士只是衰劫之始 |
| 焚天煮海 | 仙帝神通 + 古魔魔气；魔火尽落海面为巅峰态；魔火内有意志 |
| 本源火种 | 白色火种；凝成则掌控天下之火；王林此刻「只差一丝」 |
| 古妖碎星 | 贝罗右目七妖星，可自碎换取爆发之力；本章已碎两颗（余五） |
| 火灵龙 | 青霖所炼化，忠于青霖，能辨塔珈非青霖 |
| 塔珈状态 | 夺舍尚未完美——被贝罗视为可乘之机 |

## 七、待跟进

- 王林能否补足「最后一丝」完全凝聚本源火种。
- 贝罗以自碎妖星硬撼塔珈的结果与后续代价。
- 昆虚之境老者与绝美女子的身份与去向。
