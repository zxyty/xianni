# 仙逆 第1460章 四喜（第九卷 云海之巅）

## 一、传道：灵动上人得融道术
- 王林将**融合之道术**赐予灵动上人，灵动全身一震，身形渐沉入（天皇炉内）海底。
- 灵动资质过人（否则不可能半只脚踏入第三步），数个时辰即完全了解此术；虽不如王林深透，但已可融合**无主的香火之魂**。
- 天皇炉内海洋卷成庞大漩涡，灵动居于漩涡中心，双目奇芒，展开迅猛融合。

## 二、审问封灭族少女封芷曼

### 取人与试探
- 王林在炉外盘膝，以**古神之力**滋养十九棵树木；随后撕开储物空间，抓出此前被禁制的封灭族少女。
- 少女黑发苍白、怯怯可怜；王林望之想起**姚惜雪**——同样的慌乱怯怯，不同的是姚惜雪眼中有**倔强与仇恨**。王林目光转冷。
- 少女自报姓名：**封芷曼**。王林问其“死了两次为何还能存活”。
- 少女以“我是妙音道尊侍女，道尊定会杀你”相胁；王林答：“他进不来古墓子。”

### 心防崩溃
- 王林掷出玉简贴其眉心，播放**妙音道尊死亡**全过程：其为分身且被压制修为，在王林与**大荒上人**联手下被杀，最后更被大荒上人**夺舍**。
- 少女熟知妙音神通，判定画面为真，幻想破灭，浑身颤抖。
- 王林明言“我的耐心有限，若不回答我会捏魂”——因知封灭族诡异，故先瓦解心神而不直接搜魂；并给出条件：双方本无深仇（追杀已被杀一次抵消），配合则不杀甚至可放。

### 供出封灭族秘密
1. **三命**：封灭族族人有三条命。
2. **来源非神通**：族人初生眉心无印记，由族中长老带去**祭祖**，祭祖后获**族印**，一生便有三命。（王林一度以为其隐瞒，抬手欲拍天灵，少女急声澄清）
3. **封印之术施法**：**祭献生命 → 开启族印 → 族印内溢出先祖之力 → 进行封印**。

### 搜魂与夺印
- 话音落时王林右手拍落天灵，神识冲入**搜魂**（其修为已可搜魂而不伤魂），少女记忆被一扫而空。
- 王林在其眉心一抹，**生生抓出族印**；再以封印弥漫其全身，收回储物空间。
- 处置：**不杀**，出古墓后放其离开。

## 三、封灭族设定（王林所知/所得）
- 族人**无血缘关系**：从他处抓来婴儿，祭祖后存活者才成族人，**死亡率极高**。
- **祭坛很久之前突然失踪**，故封灭族人时至今日极为罕见。
- 族印为**烙下**，失去族印**不死、修为不降**，只是不再属于封灭族。
- 最惊人者为**三命之术**，**可被他人夺走自用**；但须往**封灭族祭坛**施行，成功率低、失败反噬。妙音道尊正是为此才费尽周折收封灭族之人为侍女，因祭坛失踪而拖延至今。

## 四、古息叶：从失败到顿悟
- 十九棵树在古神之力滋养下生机磅礴、长满树叶，但**无一是古息叶**。
- 第一棵树如入秋般落尽树叶，独留一片；所有古神之力涌向该叶，光芒急闪却始终无古息叶气息，随后叶柄松动、彻底脱落化作平凡，树木枯萎化为飞灰。
- 其余十八棵也开始落叶，眼看数日心血与海量古神之力将付诸东流。
- 王林抓住“**古息**”二字的关键：起身向前吹气，**气息化风、乃古神之气**，横扫十八棵树。
- 杂叶哗哗齐落，唯**十八片叶**吸收其气息，散发万丈光芒——正是**古息叶**。王林虚空一抓，十八叶脱枝环绕身前。

## 五、四喜齐至
1. **一喜**：得**十八片古息叶**。
2. **二喜**：天皇炉内毒海界轰鸣，整片海水消散，化作**九滴毒液**，每滴蕴含无数香火之魂与**天地至毒**（足令大荒上人吃惊）。
3. **三喜**：灵动上人融合**四成紫海香火之魂**，长啸破关，冲出海漩涡，气势暴涨，身外浮现虚幻绸带般的无数香火——**真正的第三步大能**。
4. **四喜（伏笔）**：森林天地上空轰鸣扭曲，一座**五千丈墓台**冲入一半，台上一名**大汉**神色一怔，似没想到会在此见到王林。
