# 第九卷 云海之巅 第1301章 天劫来临

## 一、裂缝外的一个月：死寂与血腥

- 地点：云海星域内，妖宗所在裂缝（裂缝战场）之外。数千修士环绕四周盘膝恢复元力，已如此度过多年；三名被雾气包裹的妖宗之人在远处监视。
- 距王林（本卷以化名『吕子浩』行事）进入裂缝已近一个月。
- 异状一：裂缝内**太过安静**。往常凶兽不断冲出、低吼咆哮不绝，如今寂静无音，宛如寂灭死域，无数年来极为罕见。
- 异状二：**淡而不绝的血腥之气**持续溢出，似内中发生了一场覆盖整个裂缝世界的惊天杀戮。
- 二者合成无形压力，越来越浓，压得数千修士再无心思入定。

## 二、探查者归来：凶兽尸山与血海

数日前，外围数千修士中六大高手之一的老者决意潜入探查，无人阻拦。此刻他化绿芒冲出，面带震惊、骇然与恐惧，沙哑禀报：

- 裂缝内**全是凶兽尸体**，支离破碎，被一股冲击自深处推动飘出。
- 他未深入，内里血腥浓重；感知深处因凶兽死亡太多，**怕是已形成血海**。
- 死亡凶兽**各阶都有，甚至有王兽**，且**全部一击毙命、肉身崩溃**。

### 外围众修的三种推断

| 观点 | 内容 |
| --- | --- |
| 归因于入裂缝之人 | 定是一月前『寻李倩梅进入的那个修士』所为，此人修为莫测 |
| 反驳 | 连妖宗长老都不是其对手、被其留下暗伤，此人修为惊天；但凶兽太多，一人之力绝不可能杀戮如此之多 |
| 另说 | 或为裂缝内新诞生的**皇兽**，亦或新出现的**化人凶兽**，凶兽间本就常相互厮杀 |

> 归属提示：文中被议论的『寻李倩梅进入的修士』即王林（自第1063章起以归元宗故人『吕子浩』之名立足云海星域）。李倩梅已于第1202章身死，此处为他人追述。

妖宗三人神色凝重，其中一人正欲以玉简传音回宗——变故骤生。

## 三、天劫降临：紫云、雷鸣与白玉阁楼

1. **星空骤暗**：磅礴威压自四面八方疯狂凝聚，星空咔咔巨响，如被生生压缩。修为不高者面色苍白、周身骨骼摩擦作响、喷血重创心神。
2. **紫云凭空成形**：星空之上凝出通体紫色、密密麻麻无边无际的滚滚云层，蠕动凝聚，威压与轰鸣同步暴涨，星空为之颤抖。
3. **世界缺口**：云层内似被打开一个**通往另一个世界的缺口**，缺口中一座**通体白玉的巨大阁楼**不断向外挤出；雷霆闪电在云层内游走碰撞，惊天轰鸣。
4. **笼罩九阶星域**：云层疯狂扩散，转眼笼罩大半个九阶星域。
5. **溃逃**：数千修士灵魂深处爆发恐惧，疯狂倒卷后退，有人凄厉尖叫『天劫这是天劫』；妖宗三人亦毫不犹豫后退。
6. **一声雷鸣**：音浪扩散震动整个九阶星域，数百修士吐血栽落；九阶星域内浓浓雾气瞬息崩溃，其中隐藏的众多凶兽发出惊恐吼声，整个九阶星域宛如末日。

## 四、妖宗应对

- 妖宗内十六位长老尽数从入定中惊醒，冲出各自山门列于星空，瞳孔骤缩：『这是什么天劫？』
- **妖宗太上长老**现身：一道白虹化作身穿道袍的中年男子，看似年轻却沧桑弥漫，似存活极久。十六长老恭敬参见。

### 太上长老的判词（无量劫设定）

- 天劫多变，**不外乎雷、神、威种种**；
- **唯独『无量劫』最为可怕**，其内变化莫测，**传闻与天道齐平**，乃**必杀之劫**；
- 感慨：『不知是哪位道友，竟然引发了这种天劫。』
- 引述**妖宗宗主当年之言**：『众生需度无量劫。』

### 处置命令

1. **开打山门阵法**，命门下弟子飞出，将裂缝外各宗数千修士**全部指引进入妖宗修真星**——否则无量劫下必将灰飞烟灭。
2. 妖宗弟子如凡间军队，号令一下干净利落，尽数将外围修士接入。
3. 外围再无一人时，**妖宗阵法轰然开启**，笼罩妖宗所有修真星，似欲与天劫争威。
4. 太上长老判断：『我妖宗内并无应劫之人，以阵法之力，当可无碍』，并目光如炬穿透虚空，直望裂缝战场，欲看是谁引发此劫。

## 五、章末悬念：阁楼上的雕像与两把石剑

劫云持续扩散并笼罩整个九阶星域，云中通往异世界的缺口**大范围撕裂**，庞大的**白玉阁楼已挤出一半**。太上长老目光收缩，看清阁楼之上——

- 有一座**盘膝而坐的雕像**；
- **雕像身前，插着两把石剑**。

（章节至此戛然而止。）

## 六、要点提炼

- 王林在裂缝内完成了一场规模惊人的屠戮（外部只见结果，未正面描写），并由此引来天劫。
- 天劫层级被明确分类：雷劫／神劫／威劫等常见，**无量劫为最高、必杀**。
- 九阶星域作为凶兽渊薮，其浓雾在一声雷鸣下即崩溃，侧证无量劫威能之巨。
- 白玉阁楼＋盘膝雕像＋两把石剑，是本章埋下的核心悬念意象。
