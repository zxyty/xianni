# 第1202章 种道（第九卷 云海之巅）

## 一、雷电之争：王林反制苍松子最强神通
- 苍松子出手即最强神通，闪电如与王林第一战时般轰出，冲散王林的磅礴元力直取其身。
- 王林运转**古神之力**，身后浮现巨大古神虚影，随其挥拳击溃闪电印记。
- 印记崩溃后化作漫天雷霆降临。王林右目电光一闪，眉心漩涡中**太古雷龙元神**冲出咆哮，行使天地雷之权利，使方圆数百丈化为雷池。
- 天空雷霆尽数涌入与雷池融合，化作雷光地狱；王林立于其中「如同雷仙」，呼吸间雷霆向其右目凝聚。
- 吸收之后，王林右目内隐现一道闪电痕迹，可直接幻化出与苍松子攻击一模一样的闪电，反击其人。
- 王林自评：修为虽未真正提升，但**意境的突破**使神通较第一战时更强。

## 二、七彩钉子诛杀苍松子
- 苍松子后退掐诀，面部七个元婴尽出，掀起血光护体。
- 王林虚空一抓开启储物裂缝，取出**七彩钉子**（首次施展）抛出。闪电先冲入血光使其沸腾崩溃，七彩之芒随后穿透。
- 苍松子胸口爆裂化作七彩之雾，元神欲遁被七彩钉子钉在胸口。
- 王林瞬息出现在其身后，一掌拍其元神天灵，趁重创将狂之际**搜神**，尽取记忆；随后横扫其打开的储物空间，取走所有之物。
- 苍松子彻底疯狂：抱头、血光弥漫、目露兽性，身躯急速枯萎，元神消散，凝成一枚**血色珠子**。血珠光芒一闪遮盖七彩界之光，天地尽赤，血珠冲天欲逃。

## 三、天逆珠吞血珠（关键异变）
- 王林追上抓住血珠，血珠挣扎并以疯狂之力牵扯王林向虚空。
- 融入王林元神已久、毫无变化的**天逆珠子**骤然凝聚转动，一股吸力自其右手弥漫，血珠停止挣扎并被吸入天逆珠中。
- 七彩钉子随即在王林右手重新幻化凝出（可重复使用）。
- 王林原以为中钉者只是在疯狂中被吸干生机而死，未料死时会凝出血珠——心神震动但面不改色。

## 四、与陈天军的交易
- 陈天军全程目睹，面色苍白，抱拳称「吕兄修为惊天」，称苍松子罪有应得、死得好。
- 陈天军主动解释行踪：原路返回祭坛后**无法走出七彩界**，又遇一头**十二阶凶兽**，重伤后寻到此处疗伤；自称功法特殊、熟悉凶兽故能逃脱。
- 王林与其无仇隙、未争宝，本欲离去；陈天军咬牙求助，问其搜神是否知晓离开之法——王林沉默后点头。
- **交易达成**：陈天军以役兽宗神通，为王林取来此地（粗估数百头）化雾凶兽的**元晶**，事成后另有重谢；条件是王林离开时带其一同走。王林言明自己不打算很快离开，陈天军表示不急。
- 王林递出一枚**传音玉简**，约定取完元晶传音，随即离去。陈天军握着玉简如握希望，回洞府准备（自认取元晶极危险）。

## 五、王林的修炼与后续盘算
- 回山谷洞府后取出大量元晶环身布阵，吸收吐纳并引天地元力，向**净涅中期**迈进。
- 视七彩界虽凶险却为极好修炼之地。列出待办：
  1. 前往苍松子记忆中其**肉身重新凝聚之处的石像**，尝试吸收；
  2. 那**三个界外之人**身上有他需要的力量与界外信息；
  3. **青衫老妪的生死禁**；
  4. **司马墨的岁月禁**。

## 六、界外·太古星辰（世界观揭示）
- 茫茫星空中有一片无边星域，其大小远超罗天、昆虚、召河、云海，四大地域相加亦不及。
- 封界之人称此地为**界外**；界外之民称之为**太古星辰**。
- 太古星辰某处禁地星空中有一座神秘宫殿，殿内无生机，数个七彩光团漂浮，光团内为刻名玉简：**清水、天运子、重玄子、水道子、司马墨、苍松子**。
- 苍松子玉简砰然崩碎化作碎末，一声叹息回荡；叹息响起刹那**时光倒转**，碎末逆变重凝为玉简，仿佛崩溃从未发生。
- 重凝玉简上的名字**变成了「王林」**。喃喃之声回荡：「**种道之地，道临将成就以此人之魂，让道成矣。**」——似自语，又似传念星空。

## 七、结尾：白发老者
- 七彩界至深之处、王林心神曾到过的山峰上，**白发老者**盘膝而坐；身后洞府散出七彩之芒，其内隐隐传出众多凄厉哀嚎。
- 老者猛地抬头看向天空，许久后默默点头（似与宫殿传念呼应）。
