# 第1573章 青丝魂

## 一、雪域国遗址的发现

- 周武泰一句话让王林执杯的手一顿——话题转向当年的**红蝶**。王林追忆：那一缕骄傲的红魂，在朱雀星上绽放明亮光芒；红蝶一生短暂，但「但求一死也绝不愿屈从而活」，冷傲至极，令当时朱雀星小辈修士不敢正视，如其名，是天空中最璀璨红芒所化的蝴蝶。
- 周武泰交代现状：**雪域国已消散在岁月中，永久散去**，此事与王林当年的封印有关联；其内雪域修士纵有存活者，也已分散成为**九大宗门**之人。
- 周武泰在空旷的雪域国遗址中，发现了**红蝶师尊死后的一处封印之地**。他保留了该处阵法多年，等王林归来一看便知。

## 二、青丝阵法

### 现场
- 地点：朱雀星北部山脉中心的**巨大朱雀雕像**（当年之物，今为周武泰洞府），内部另有乾坤，是庞大府邸；阵法被挪移至其中一处石室。
- 形制：阵法约**十丈**大小，占满石室地面；四周泛起**蓝色寒冰**弥漫阵法；中心有**一缕青丝被冰封**；阵法已停滞多年，无运转迹象。
- 周武泰自陈对阵法了解不多，看不出端倪；并言「若非发现时已停滞，凭我的修为定会被此阵所伤」。

### 王林的推衍结论
- 王林踏入阵内、右手按上寒冰：寒冰闪烁刺目之芒、轰鸣隐传，阵法有了运转迹象；手一离开，阵法复归停滞。
- 结论一：**此为「分魂传送阵」**。
- 结论二：布阵者修为应到**净涅后期大圆满甚至更高**，确非红蝶之师（第一步修士布不出）；或其师隐藏修为，但若隐藏修为，红蝶后来之事便无法解释完整。
- 结论三：作用是以这一缕青丝分出一魂，借阵传出，去向不明；青丝上带**红蝶的气息**。
- 推断动机：红蝶师尊曾算出红蝶有一场**生死大劫**（此劫若过，则**五行之体大成**），料其极难避过，遂不知以何法找到此阵，在红蝶历劫前分出一缕魂送走——即便红蝶身亡，凭此魂亦可**夺舍重生**，以此避开生死大劫。
- 由此：**红蝶或许真的没死**。此事出乎王林意料。

### 附带隐秘
- 周武泰翻查历代朱雀星之主典籍，发现一个隐秘：**雪域修士与巨魔族一样，似都是外来之修**。

## 三、二人的心事

- 王林立于朱雀雕像之上望向星海：若红蝶尚在，或许此刻正在星海某处也望着朱雀星，只是不知她是否还有这里的记忆。
- 王林：「或许，我见过她」——细想两千余年，却无任何答案。
- 周武泰：故人不多了，希望余生能与她见一面；当年的仇恨已消散在岁月中。
- 王林辞别（「周兄，王某走了」）时，周武泰犹豫着问起**柳眉**。王林答：「见过，她已经道消。」周武泰面色苍白、苦涩摇头。
- 王林离去后，周武泰独坐痛饮至天暗，仰天大笑，笑声含悲哀与浓浓追忆——**当年的他一直倾慕柳眉**，近两千年心中身影不散。王林亦是此刻才从其神色中察觉，却无话可说。

## 四、赵国守孝七日

- 王林在赵国老房子父母坟前**守孝七天**，未离开半步，望着坟茔饮酒，看日升日落、黑夜白昼交替。
- 七天中他心境彻底平静，如老人般不去想任何事，也不去想**体内的排斥之力**，只沉浸于陪伴父母的温情与悲哀。
- 疯子睡醒后照旧喋喋不休，抢过酒壶后更絮叨，醉后唱起歌，令老房子的忧伤略有消散。
- **第八天**：王林在父母坟前磕头，深吸一口故乡气息，转身一步迈出——由「游荡回乡的凡人」重新成为**冷酷的修士**，自凡间回到血雨腥风的修真界。作者定调：修真道是不归路，踏上便须坚决走下去，回头也只是短暂一瞬。

## 五、下一站：符文族天坑

- 王林言：「朱雀星上，我还要去最后一个地方。」目标是**符文族当年的天坑**。
- 该处隐藏符文族的秘密，是当年**老圣皇的分身黄龙真人**一直想进去之地；**符文族第十九层**中究竟有何隐秘，困扰王林很久很久。
- 结尾：王林带着始终喋喋不休的疯子，化作两道长虹，直奔符文族天坑。

## 关键悬念
1. 分魂被传送到了何处？红蝶是否已夺舍重生、是否留有前世记忆？
2. 是谁真正布下这座净涅后期大圆满级别的分魂传送阵，红蝶师尊如何找到它？
3. 雪域修士与巨魔族的「外来之修」来历。
4. 符文族天坑第十九层的隐秘。
