# 第2016章 九曲三相(下)（第二更）

## 一、九曲三相：本章逐曲显化过程

王林于古道山台阶上继续攀登，随台阶推进依次引动天地之曲：

| 台阶 | 引动之曲 | 表现 |
|---|---|---|
| （此前） | 第一曲 苍穹风曲 | 风之曲 |
| （此前） | 第二曲 天道雷音 | 雷声如鼓 |
| 第240阶 | 第三曲 凡尘云笛 | 金色天空生白云，风穿云表小孔而成笛声，传人心神，令人放松欲睡 |
| 第250阶 | 第四曲 万物润雨 | 哗哗沙沙雨声自九天落地，似万物复苏、萌发生机 |
| 第260阶 | 第五曲 天音 | 天本无声，却有轻声喃呢自天空传来 |
| 第280阶 | 第六曲 大地葬音 | 黑色大地传出苍凉葬音，与天音交融即生与死，风云雷雨合成绝唱 |
| 第290阶 | 第七曲 体音 | 举头、挥臂、抬足、呼吸、汗毛孔张缩之声，外人不可闻，唯王林自闻 |
| 第300阶（遇袭时） | 第八曲 五脏曲 | 肺缩、心跳、脾震脉、肝抖颤、肾绷发，五脏之音如心跳砰砰 |

**相**：第270阶显化**银色双目**——四名灰衣人明言"九曲三相中，银目为共有之物，古祖九曲可转化，三相中第二相也为此目"，即此为**第二相**。高塔身影认定其时"五曲二相"，章末已达**八曲二相**。

## 二、王林体内力量的三阶段转化

1. **曲乐疗伤（第240阶）**：风、雷、云三曲交融，元神与灵魂似被温暖环绕慢慢滋养，登阶所受身体内外一切伤势"奇迹般恢复如初"；仙古融合之力增多但仍沉寂不运转。
2. **缓慢运转（第260阶起）**：第五曲下，古道山威压中融合出的仙古之力开始运转，唯极慢，或需数年乃至数十年方成一循环；古祖魂血亦有融化迹象。
3. **本源与古族之力分置（第270–290阶）**：
   - 第270阶：体内**所有本源蓦然融化**，双目转银，散出空灵俱灭之气息（即当年洞府界玄罗所感）。
   - 第280阶：**古族之力融化**。
   - 第290阶：二力并非失去，而是与身体深层融合——**本源存于元神，古族之力存于五脏六腑**，似融合又似未融合，循环速度略快。
4. **完全融合（第300阶）**：八曲同旋之下，五脏六腑中的古族之力轰然扩散融入血肉，元神中的本源之力弥漫各经脉，**首次以王林身体为中心完全融合**，化作庞大的"仙古融合之力"（不属于仙、亦不属于古），以无法想象的速度刹那转完一个循环。

## 三、旁观者与许诺

- **玄罗**：闭目沉浸曲乐，睁眼后心神起波澜；以其修为身份本不当动容。心中默念"古道大天尊你不认可他的存在……我的弟子，拥有魂血的王林，他是否会认可你的存在"。此前玄罗曾恳求古道大天尊出手唤醒王林魂血血脉，**被拒绝**。
- **高塔顶层迷雾身影**：闻曲乐先叹息、后闭目，面容似有惆怅追忆；随后冷漠开口——"九曲三相于你身上，出现了五曲二相……若你能走上三百台阶，**我可以为你唤醒魂血，并，召见于你**"。
- **四名灰衣人（高塔四周四柱上）**：先是听曲露惆怅追忆；见王林银目后目露迷茫空洞，似被摄心神——银目对其有奇异吸引。

## 四、冲突：两灰衣人合体来袭

王林一步跨十阶站上第三百台阶的刹那，柱上**两名灰衣人**眼中迷茫空洞被寒光取代（似恢复神智），齐齐飞出、**在半空身影重叠化作一人**，大步电闪扑至，一拳轰出。拳中蕴含灰色雾气，显露巨大头颅之影，带疯狂而无声咆哮。

王林以第八曲五脏曲相应，完成仙古之力融合循环后低吼："**滚开**"。（本章至此收束）

## 五、王林态度转变

- 第240阶前：神色狰狞、双目血丝。
- 曲乐洗礼后：神色平静、双目冷静，步履稳稳。
- 第290阶：双眼露峥嵘之芒，直视高塔反诘"你曾说，王某走不过三百台阶么"，随即一步跨十阶。
