# 第1708章 第一人！

## 一、仙罡大陆：道古一脉见证四滴之数

- 古祖撑天雕像眉心为王林（以「烨寞传承者」身份被认知）凝出 **四滴古脉苍穹血**，历时十三天；近百万道古一脉族人在场围观。
- **血滴数的参照体系**：
  - 渡「三损第一劫」的古国之民，绝大多数只得 **一滴**；
  - 凡道古一脉 **皇族** 者，均能得 **两滴以上**；
  - **烨寞** 当年得 **三滴**；
  - **皇袍男子**（道古一脉皇尊）当年得 **六滴**，被誉为道古一脉除玄罗外最强者；
  - **玄罗大天尊** 得 **八滴**，为仙罡大陆「九阳」之一、最强九人之一。
- 四周议论：「四滴鲜血，这种事情已经很久没有发生过了」「十三天的时间，四滴，还真不算很多」。红芒最终暗淡至眉心一点，此次血劫结束。

## 二、皇袍男子的心结与不服

- 皇袍男子虽得六滴、位居皇尊、受无数人尊仰，却 **始终未被玄罗收为弟子**，此事被其耿耿于怀而不敢明言。
- 听闻玄罗要收烨寞传承之人为弟子，心中阴沉，面上却作惋惜苦笑，对玄罗（称其「族叔」）说「四滴也已然不少了，这烨寞传承者，也算我道古一脉的骄子」。
- 内心独白：「道古一脉除了族叔，没有人能有我这样的天资，烨寞不行，他的传承者，更是不行」「若他仍决定收这烨寞传承者，我第一个不服」。
- 玄罗大天尊神色平淡，似未听见；注视四滴鲜血破开虚无飞往遥远之处消失后，只淡淡道 **「再等等。」**

## 三、洞府界：四血入体，古之血脉诞生

地点：洞府界 · 内府云海裂缝内的奇异空间 · 祭坛。

1. 王林 **分身** 盘坐祭坛边缘，注视祭坛中心其 **本尊所化的一滴鲜血**。
2. 上空星空凭空生出层层波纹，一股沧桑至极的气息降临——超越洞府界一切众生，连大天尊亦难比拟，且只有王林能感受到。
3. 巨大 **血光漩涡** 成形，蛮横之力把分身推退数百丈出祭坛；此力超过天地威严与王林此生所见一切威压，「莫说是他，就算是七彩在这祭坛上，也要被强行驱赶出去」。
4. 四滴鲜血依次自漩涡飞出、融入本尊血滴：
   - 第一滴：两血急速融合；分身心神剧痛，意识自分身消散、彻底存于血液中，如被焚烧。
   - 第二滴：痛苦倍增无数，无法吼出，只能忍。
   - 第三滴：血滴轰然爆开三丈，凝出 **一头白发、遍身诡异符文印记** 的王林身体虚影，闭目闷哼中渐渐凝实。
   - 第四滴：血光弥漫无尽星空，红芒直点其 **眉心**——王林猛然睁眼，瞳孔赤红，庞大力量在体内疯狂滋生。
5. **结果**：四滴古祖鲜血融合后，王林体内 **诞生古之血脉**，自此成为真正的古祖后人、正宗的古国之民。四滴仅比烨寞多一滴，文本称此几乎已是王林的极限。

## 四、命运对照与「第一人」

- 叙述作强烈对照：王林在一次次生死拼命中以命换造化、为复活李慕婉抱尸痛哭；同期皇袍男子在族人守护供奉下安逸修炼、把玩宝物、于被送上来的女子中挑选妃子。
- 王林所恃者：坚毅、不屈、不甘被人掌控的人生。
- 面对将散的漩涡，王林 **不满足**：「四滴鲜血，是我王林的极限么」「你既认可我古族血脉，那么只给我四滴鲜血，不够」——为的只是心神中那股 **永不屈服的逆天之意**。
- 他生于洞府界，心中从无对古祖的尊敬（连玄罗大天尊都仍极为尊敬这冥冥中的祖先），只信自己的力量。
- 遂一跃直冲将散的漩涡，**成为道古一脉在古脉苍穹血劫下获血后仍不满足、且反冲漩涡索血的第一人**。
