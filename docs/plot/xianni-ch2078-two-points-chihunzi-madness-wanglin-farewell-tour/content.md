# 第2078章 两个点……

## 一、赤魂子的崩溃与灭亡

### 1. 拒不信邪
赤魂子双眼通红、青筋暴起、披头散发，歇斯底里嘶吼：「假的，没有人可以凭空打开洞府界与仙罡大陆，形成如此漩涡将大天尊神识摄取而来。」他抓住最后一根稻草——自称当年曾与仙皇侍卫**罗明**为好友、救过其性命，而罗明是仙皇亲信。

### 2. 王林的三重碾压
- **撤漩涡**：王林右手一挥，天空漩涡消失，道一气息烟消云散。仙罡大陆道一宗内的**道一**身躯颤抖，清晰感受到方才一瞬自身的脆弱与王林的强大。
- **显仙皇残魂**：王林言明「仙皇我的确无法将其神识摄取而来，但可以让你亲眼看看其破碎的残魂」。其身后天空现**黑、白、金三色光芒**，瞬息凝作一轮巨日，大天尊威压轰然扩散；三色大天尊中清晰显露**仙皇连道真**的面孔——痛苦扭曲，却可让所有见过他的人一眼认出。
- **修为攀升至半步踏天**：展开大天尊威压后，王林修为仍在攀升，直至**半只脚迈入踏天境**，威压足以崩溃一片星域、轰灭众生。

### 3. 疯而后死
这股威压没有丝毫外溢，齐齐凝聚于赤魂子身周。赤魂子全身轰鸣、呆若木鸡，继而傻笑疯癫，**肉身骤然崩溃、元神灭亡**。

他疯的根由在于荒诞至极的现实：自己竟打一个「让道一恐惧、炼化了仙皇魂、自身就是大天尊」之人的主意——想调教其红颜、收其后人为弟子，甚至让这个大天尊的后人去反抗大天尊。文本明言：这种死法比直接摧毁肉身残忍无数倍，王林摧毁的除肉身外，还有其**理智与心神**，从内到外全部无情毁灭。

## 二、辞别仙界：留阵、留道统、留丹药

战后第二天，王林带着**木冰眉、十三、许立国**等人离开。临行安排：

1. **护界大阵**：重新为仙界布置阵法，其强悍程度——整个仙罡大陆上，除非**仙祖、古祖**重生，否则无人可破；**即便是古道也不行**。
2. **道统与神通**：留下自身部分道统与神通之术。
3. **丹药如山**：凝聚天地之力，化作如山一般的丹药。
4. **虚本源感悟**：留下自己对虚本源的感悟。

作者点明用意：这些足以让仙界以极快速度强大起来，日后强者如云，并会出现传承王林道统之人，不会再出现如赤魂子这样的事情。

5. **与蓝梦长谈**：走前王林与**蓝梦**长谈，除二人外无第三人知晓所谈内容。蓝梦目送王林离去后，选择**闭关**。

## 三、界内故地重游

- **朱雀星**：王林穿梭星海回到朱雀星，在自身雕像前盘膝打坐数日，随后独自一人离开。
- **天运星 → 妖灵之地**：前往在当年大战中已成废墟的天运星，散开神识找到去往妖灵之地的入口并进入。
- **仙帝青霖洞府 · 画轴女子**：在熟悉的仙帝青霖洞府中，王林将该处**复原**，找到当初被他封印在深渊内的**画轴**，解开其内女子的封印，**让其沉入轮回**。叙述点评：那女子当年的神秘，于如今的王林看去已然不重要。
- **四大星域了却旧事**：王林在界内四大星域去了很多地方，对当年一些未解之事**不刻意寻找答案，而是一一了却**。

## 四、走出界外

- **颠落之地**：界外第一站。见到对他有恩的**老朱雀**及很多故人。数日后王林**解开颠落之地的封印**，令老朱雀等人不再被永远困于其中、可随意走出；同时**带走了颠落之地最重要的物品——一个轮盘的指针**。
- **散灵上人**：王林在界外见到这位当年令他颇有感触的朋友。
- **酷似托森的婴儿（重要伏笔）**：在界外一颗修真星上，王林看到一个身体沉浸于星球核心、似在沉睡的**婴儿**，样貌与**托森**很是相似。王林不知发生了什么，但看出**托森或许就是涂司**，似在修炼某种**需将身躯重新化作婴儿、再次成长**的神通。

## 五、要点提炼

- 赤魂子之死是「诛心」式处决：先摧其信念（道一之惧、仙皇残魂、王林自身即大天尊），再以半步踏天境威压摧其肉身元神。
- 王林对仙界的安排具有「立种子」性质：阵法（防）＋道统神通（传）＋丹药（资）＋虚本源感悟（悟）。
- 本章为收束旧线的巡礼章：道一宗、朱雀星雕像、妖灵之地画轴女子、颠落之地老朱雀与轮盘指针、散灵上人，逐一了结。
- 唯一新开线索：轮盘指针 + 托森/涂司的婴儿化重修神通。

## 一、离开托森转世之地

- 王林在那星球上看着（托森转世的）婴儿，数日后选择离去。
- 临走前留下**一道给托森的神念**：当婴儿长大、苏醒时将会感受到这道神念。

## 二、洞府界再无秘密

- 对王林而言，洞府界已然没有秘密。
- 若说仍有，便是**神秘的天运子（原文作「夭运子」）**与**神秘的七彩**——但这两人在洞府界存在的痕迹已然消失。

## 三、重返朱雀星，揭晓最后的隐秘

王林游历诸地，一年后回到家乡**朱雀星**。此处还有最后一个隐秘等他揭晓：当年无实力去寻，离开洞府界前又处于迷茫与对未来的茫然中，无暇理会。

### 1. 修魔海 → 古神之地入口

- 王林来到当年的**修魔海**，来到进入**古神之地**的入口处。
- 古神之地虽因**托森**的离去而坍塌，其内却仍有一处存在了很久的空间，王林踏入其中。

### 2. 吉穷兽的骸骨

- 在往昔的古神之地，王林找到了那头**吉穷兽**。
- 此兽当年曾吞下王林的神识，长出了一个**与王林样子一模一样的头颅**。
- 王林找到时，此兽已不知死去多少年，只剩一具骸骨。王林站在骸骨旁沉默很久，目光始终望着诸多头颅中的一个。

### 3. 两个头骨的相遇（关键顿悟）

- 那是一个**属于人的头骨**，却不是正常大小，而是**似一个拳头**大。
- 王林储物袋内有一个**一模一样的头骨**；他取出后，两个头骨放在一起时——
- **其中一个化作一片幽色的光点，消失了。**
- 王林认出：消失的那个，是他**从道一那里获得的**。
- 脑海中似有一丝明悟一闪而过，无法清晰抓住。他抚摸头骨喃喃自语：
  > 「如果真有轮回，那么当过去与现在相遇时，过去会消散，不复存在，剩下的，只有现在。」

### 4. 关于王平的恐惧被解答

- 收起头骨后王林松了一口大气。他对这如婴儿头骨之物有来自心神的恐惧——恐惧的不是此物，而是**此物的来临**。
- 他曾迟疑：若真有轮回，此物是不是属于**王平**。如今他有了答案。

### 5. 头骨与白发的对应猜想

- 王林回想：与天运子相似的**道吉国师**曾言，说他「已经找到了头骨与白发」。
- 如今头骨有所变化，那么是否说明——**会有一天，那一丝白发也会如头骨一样**。
- 王林在沉默中离开这吉神（古神）之地所在的空间。

## 四、岁月流逝：第一个十年

### 许立国与刘金彪出走

- **许立国**的封印早就被解开，恢复自由后按耐不住锦衣还乡的得意，与**刘金彪**一起在**十年前离去**，不知去向。
- **海龙**伴随二人，可让他们在洞府界不受丝毫伤害——只有他们欺负别人，无人能欺负他们。
- 刘金彪临走前严肃告知许立国：他要**追寻骗道的终极**，但觉得与许立国的配合还差一些，需再找一人加入或可更完美。
- 许立国深感认同，二人商议后把目标放在当年的**钟大洪**身上，颇为怀念。**第一站便是寻找钟大洪。**

### 十三与蚊兽王护法

- **十三**一如既往未离开朱雀星，选择在此长久闭关，**等待师尊苏醒、为师尊护法**。
- 十年中修为有所精进；最主要的是他**传承了王林完整的道统与几乎所有神通**。
  - **五行本源**：已然凝聚。
  - **虚本源**：感悟上始终所获不多。
  - **八极道之术**：似有惊人天赋，感悟极深。
- 护法者还有**蚊兽王**：修为极高，在朱雀星几乎是霸主，每次外出都引起此星修士轰动。曾有修士想抓捕，吃到苦头、知晓差距后大都避开不敢招惹。此兽不伤人，时而外出星空玩耍，久之朱雀星修士也习惯了它的存在。

### 王林与木冰眉：梦道解心结

- 十年前，王林与**木冰眉**一同走入一处**山峰内的洞府**。
- 在其内，王林施展**梦道之术**，牵引木冰眉去了结那属于**柳眉**的心结与隔膜。
- 叙述者留白：或许解开柳眉的心结后，王林与木冰眉之间将会不同。

## 五、又一个十年：朱雀星上的「禁地」

- 时间流逝，转眼**又过去十年**（自王林归乡起共约二十年）。
- 朱雀星的修士**不知传闻中的王林早已回到家乡**；他们只知道：
  - **二十年前**，有一座山被一个**冷漠的修士**占据，化为**禁地**；
  - 那里不允许任何人踏入半步——**一次可以是警告，第二次则是杀戮**。

## 六、要点与伏笔

1. **轮回律的具象化**：两个同源头骨相遇，「过去」消散、只余「现在」——这是王林对自身来历/轮回的核心线索。
2. **道一之物的归宿**：从道一处所得的头骨即那个消散的「过去」。
3. **白发伏笔**：道吉国师所言「头骨与白发」，头骨既已变化，白发之变尚待。
4. **托森转世线**：神念留在婴儿身上，待其长大苏醒方启。
5. **道统交接**：十三承王林道统，五行本源已成、虚本源未通、八极道之术天赋极高。
6. **王林状态**：文中暗示王林处于需人护法的（闭关/沉睡）状态，十三与蚊兽王守候其苏醒。
