# 第1504章 猎幽冥（四）

## 一、七星魂封的最后争夺

- 王林以不容置疑之力喝出，旋转而出的**七颗星点**直接印在幽冥魂口。第一至第四颗星连续闪亮，一股沧桑魂力顺星点传入其心神。
- **时间告罄**：灵动与周瑾以「被吸入」为代价换来的时间已不够用，幽冥兽的**神通一界**再次打开，吸力横扫，王林身子已现被吸入之兆。
- **第一次续命 —— 古息叶**：王林右手一甩，所有古息叶尽数飞入旋转如黑洞的神通一界入口。轰鸣中吸力减弱，**第五颗星亮起**；随即古息叶被漩涡吸走，吸力再逼。
- **第二次续命 —— 望月**：王林大袖一甩，望月庞大身躯如冰山一角轰然而出，堵住黑洞漩涡，在被吸入的过程中为王林换来最后时间。
- **第六、第七颗星相继亮起**，七星急速旋转，**魂之封终成**。

> 封印进度：外部之封（已成）+ 魂封（本章成）= 两样；只余最后一步——古神七星全亮后留下烙印、回归王林眉心。

王林心态：为擒此兽已付出极大代价，若成则灵动等人无碍，若在关键处失败则后果惨重；但此事在决定之前已作详尽分析，一切仍在算计之内，最后两星他有把握点亮。

## 二、惊天变故：七彩之芒

- 烙印回归眉心的刹那，被封的幽冥魂口内爆起一道**七彩之芒**，浓郁滔天，数万丈扩散，笼罩星空。
- 连王林也愣了一下——「七彩？」
- **后果一**：印在幽冥兽本体外部的封印被冲散大半，只剩一丝且眼看将尽。
- **后果二**：刚烙下的七星魂印骤然黯淡，如七盏风中烛火，**瞬息间三个星点直接熄灭**。
- 七彩光芒暴增之际，一个个**虚幻影子**自幽冥魂口飘出，嗡嗡诵念：
  - 「铭志，囚封天之道，众生需渡无量劫，离开深狱一执念，奉至修真行。」
  - 「铭志，众生亦于无量前，解今茫世，脱困天之念，取来生道，奉至修真行。」
  - 「铭志，锁亡天之运，印冥朝，众生之所不得真道者，常沉苦海，永失真道，奉至修真行。」
- 身影越来越多，密密麻麻遍布幽冥兽四周八方。

## 三、王林的推断：它吞了一处七彩界

「铭志者」三字令王林瞬间贯通此前所有疑点：

| 疑点 | 解释 |
| --- | --- |
| 幽冥一反常态不逃、性格逆转 | 体内有七彩界之力 |
| 在雾气星域留下排泄之物 | 吞界之后所致 |
| 竟如此狡猾、目露睿智之光 | 非其本有灵智 |
| 封印大半后魂内爆发七彩之芒 | 所吞七彩界反噬 |

结论：**「它竟然在这千年内，吞噬了一处七彩界。」** 王林心神震动，几乎不敢相信。

## 四、幽冥兽吞界始末（回溯）

1. 当年王林惊鸿一瞥离去后，幽冥兽在**雾气星域**游荡。它性子胆小，虽实力强悍，遇雾气中任一凶兽都远远避开；却忘了自身威压之下，凶兽修士本就无人敢近，所过之处凶兽齐齐惊散。
2. 其神智浑浑噩噩、灵智不足，一生大半在沉睡中度过，偶尔苏醒也只是茫然游走。王林带**仙选族人**离去后，它苏醒时忽觉饥饿，又不敢离开雾气，只能绕来绕去。
3. 某日前方雾气中现出一道**巨大裂缝**，七彩之芒自内透出刺目。裂缝中狼狈踏出一个衣衫破损的身影，狂笑「终于出来了……老道终于自由——」话未说完便看见幽冥兽的庞大身躯与威压。
4. 一人一兽呆呆对视，那身影面白冷汗、发出凄厉尖叫；幽冥兽被吓，体内传出轰隆咆哮（实为惊恐之声）。身影毫不犹豫退回七彩界。
5. 幽冥兽急退极远，久候无人追来，胆子稍长，又因**极喜七彩之色**小心翼翼折回，对着裂缝发呆——**一发呆便是百年**。
6. 百年后仍未想明白裂缝为何物；又十年，它距裂缝不足一丈时，那身影（披发干瘦、样貌凄惨）鼓起勇气再度探头，正撞上近在咫尺的幽冥兽，惨叫「你居然还在——你居然在外面等了一百年！」再度缩回，不敢外出。
7. 幽冥兽这次只退数万丈，等久无人出，因贪恋七彩又回来继续发呆。第二个、第三个……第五个百年过去。
8. 终于有一天它再感饥饿，又不舍离去，**缓缓张口一吞**，吸力之下将整个七彩界所在空间彻底吞入体内的神通一界。

## 五、石碑现世

在铭志者喃喃之音回荡星空的刹那，幽冥魂口内轰隆巨响中升起一座**巨大石碑**，碑上以**赤红鲜血**清晰刻着一段段**道经**。

## 六、当前局势（章末未决）

- 王林两封已成其一（外部之封仅余一丝、魂封七星已熄三星），第三步烙印回归尚未稳固。
- 灵动、周瑾、望月、古息叶均已投入/被吸入神通一界，筹码消耗殆尽。
- 幽冥兽体内七彩界之力（铭志者、血经石碑）成为新的变数。
