# 第1363章 久违的平静（第九卷 云海之巅）

## 一、落脚凡间都城

- **地点**：一座极为庞大、人口稠密的凡间都城，**以西处为重**，居住人口远超其余三处。
- **货币**：此地凡间不以银两为钱物，而用一种名为 **矾晶** 之物，按大小充作钱币。矾晶对修士无用，但极为璀璨、产量不多，故可流通。
- **取财方式**：王林分出一丝元神顺双脚融入地底横扫一圈，无人察觉间找到地底深处的 **矾晶脉**，绕行时炼化一部分，元神归体时储物空间内已有大量矾晶。
- **落户**：一路未施展神通，步行至城西。此处屋舍密密麻麻、街道残破、房屋经久未修，**几乎每间屋舍房檐下都挂着穿成串的树叶**（当地奇特习俗）。王林在最密集处买下一间民居。

## 二、久违的凡间烟火

- 屋舍位于街道中段，门外大树下有面摊，除面还卖 **米酒**——穷苦人去不起酒庄，便在此吃面喝酒填肚。
- 黄昏时家家热闹，邻里谈笑、孩童以小石子嬉闹。王林坐门口含笑旁观，对前来攀谈的淳朴凡人十分温和。
- **对外身份**：自称 **赶考书生**，住不起客栈故租房读书，待明年大考。
- 收摊时，佝偻的面摊老者递来半壶米酒：「小娃娃，夜里寒气重……以后要是有了出头之日，再给我酒钱就好。」
- **心境**：王林心中平静——「与残酷的修真界相比，王林更喜欢这样的生活」「在这里，就连心境也平息下来」。这与其在云海星域/闪雷族的血腥杀伐形成强烈反差。

## 三、夜炼太古雷龙

### 起手

- 闭目盘膝，体内元神急运，元力在体内碰撞如风浪滔天，外界却半点不可闻，唯烛火晃动、身影扭曲。
- **心神中的战场**：八条太古雷龙魂魄怒吼挣扎欲冲破元神，但王林元神对它们而言如同困牢，撼动不了半丝。

### 手段

| 要素 | 说明 |
| --- | --- |
| 火焰之源 | 除雷之本源外另有的本源，化蓝色火海弥漫元神内部，包围焚炼八龙 |
| 朱雀虚影 | 于蓝色火海中绕八龙旋转，时而吐出大量火焰增加炼化火力 |
| 第九条雷龙 | 王林元神本由半条太古雷龙组成，此刻雷霆闪电弥漫化作自身第九条雷龙，在外游走候机吞噬 |
| 米酒精华 | 打更人过后王林隔空摄来酒壶猛饮，以元力驱除驳杂、逼出酒中精华化细密之雨落入火海，火海轰然爆开、高温暴增 |

### 战果推进

1. 米酒助燃后，**第一条**太古雷龙惨叫崩溃，第九条雷龙以雷霆之速一吸，彻底炼化为自身完整不可分割的一部分。
2. 吞噬时王林面色红润如吞大补之物，**右眼皮上闪电印记隐隐穿透并急速暴增**；桌上烛火剧震后「啪」的熄灭，屋内漆黑，唯闪电印记散发微光。
3. 八份火海改为七份，**落在每条雷龙身上的火力比之前强数倍**，炼化提速；不久第二条崩溃被吞噬。王林一鼓作气，驱元神雷龙冲入剩余六条中疯狂碰撞撕咬。
4. **一夜之后**：清晨初阳被沉甸甸乌云阻挡，雷声闷响、暴雨骤落——王林睁眼：「八条太古雷龙，被我吞噬融合了七条，只剩最后一条。」

## 四、氛围与细节（可作后续伏笔）

- 打更人夜巡喊话：「**寒潮来临，关灯关门**」——其声远去的刹那，正是王林开始加速祭炼的节点。
- 全章外静内动：屋内屋外一片安静，雷龙凄厉惨叫尽被隔绝在元神与肉身之内，无半点外泄，凸显王林对元神的绝对掌控。
- 结尾天象（乌云、闷雷、暴雨）与元神内雷龙祭炼形成呼应。

## 五、状态小结（截至本章）

- 太古雷龙魂魄：已吞噬融合 **7/8**，余 1。
- 已知本源：**雷之本源**、**火焰之源**（并有朱雀虚影相辅）。
- 身外标记：右眼皮闪电印记随雷龙吞噬而暴增。
- 世俗身份：凡间都城西城「赶考书生」（伪装）。
