# 仙逆 第八卷 联盟隐秘 第1036章 你叫，姚惜雪

## 一、露珠禁制中的决战：海之巨人

- **禁制开启**：仙帝洞府花丛中的禁制，被王林与风妖厮杀的冲击彻底激发。海水化作的大手抓住灭神矛向下拽。
- **崩**：王林低喝『崩』，灭神矛黑芒瞬间放大如黑色太阳，连抓矛的海水手臂也被映黑；随后毁灭性冲击横扫，海水手臂崩溃气化。
- **海之巨人现身**：整片大海的海水凝聚成人形，从平躺中缓缓坐起，大小无法估计，坐起即似撑破天空；五官浑浊，双耳庞大及肩，与修士毫无相似之处。海面因此露出深深海底——大海不在，只余巨人。

## 二、朱雀之火

1. 王林道『区区露水所化禁制，王某尚未看在眼中』，双目燃起两团火焰，体表**朱雀图腾**散发赤红之芒。
2. 双臂张开爆发火海，随元力运转弥漫天空，火雨从天而降压向海之巨人，蒸起环形白雾。
3. 海之巨人咆哮，全身海水沸腾散开卷向天空，化作连接天地的**浪墙**环形收缩，扑灭全部火海，逼近至王林身外不足百丈，并于浪墙中浮现巨脸张口吞噬。
4. 王林心念一动，体内响起高昂朱雀之音，一头火红朱雀从其身上冲出，展翅施展 **『朱雀之火』**：火海无边无际、无始无终。巨人大口惨痛咆哮急退，浪墙消融成雾、退速远快于来势，重新凝作海之巨人——但已缩至不足千丈，由坐转立。
5. 王林右手一指，朱雀化赤红流星穿透火海与海水，钻入巨人体内。内外同燃，海水持续气化，巨人身形不断缩小。

## 三、最后一击与世界崩溃

- 巨人临死将全身海水收缩为**一滴水**，冲破火海直取王林。
- 王林神色如常，右目青光一闪祭出**青光盾**，硬挡水滴，盾身被压后数寸而未碎裂。
- 朱雀随后卷火扫过，高温下水滴越来越小，最终在挣扎咆哮中彻底消散。
- 水滴一灭，天地崩溃、天空撕裂、海底瓦解，数息后化作碎片消散，碎片之下露出绿意——原来整片海之世界，只是洞府花丛中一片叶子上的一颗露珠。露珠消失，王林重回原先消失的花丛内。

## 四、花丛截杀：『你叫，姚惜雪』

- 风妖在海之世界崩溃刹那全速冲出，欲闯入另一处禁制逃遁，却被王林身影当面幻化拦下。
- 王林一声『定』，风妖身形一顿；虽片刻即复，已足够王林出手。
- 王林右手点在风妖脸上疤痕，疤痕呲然消散，露出白皙肤色。
- 王林言：**『姚惜雪，王某不会杀你，而是要救你以此了结这桩因果，让你与你父相见，从此之后，你我各自天涯，再无任何交接之日。』**
- 王林右手不停，每点一次收拢一道疤痕，快如残影；定身术效消散即续施新术。风妖眼露惊恐，已猜到王林意图。
- 疤痕尽消，风妖恢复当年容颜娇美之姿，肌肤白皙如玉。王林依稀看到当年妖灵之地的姚惜雪。

## 五、王林揭示的因果逻辑

- **最后一指点眉心**：风妖忆起第一次交战时，王林凭诡异传送神通本可令其瞬间重伤，却只一指点在其眉心。此刻同样一指再落，她隐约明悟。
- 王林自语：『第一指，是为了让你与姚惜雪的记忆融合，出现破绽，有了那一指，便有了解救的机会。』
- **判定**：若风妖真的履行对姚惜雪的承诺、替其复仇，则不算额外加入这场因果，而是因果的一部分，王林不会干扰；但风妖欺骗了姚惜雪——欺骗本身王林不管，问题在于**因此破坏了王林生死轮回与因果意境转化之际，唯一融入进来的因果变化**。
- **身份论断**：风妖的传承本就是一场记忆，实际上的『她』早已死去；如今说来是妖，实际仍是姚惜雪，没有死亡之说，有的只是记忆。

## 六、旁观与收束

- 风妖目睹朱雀之火焚海全程，一脸苦涩，真正认清与王林的差距而沉默，但双眼闪烁恶毒之芒，充斥不甘。
- 章末：王林双目奇异之芒更浓，缓缓张口，向风妖**狠狠一吸**（悬念未决）。

# 第1036-1037章（第八卷 联盟隐秘·第1037章「相见」）剧情梳理

## 一、吞噬风妖：清水仙术最霸道一式的首次施展

- 王林传承所得的**清水仙术**中最霸道的一式为「**吞噬**」，本章是他**第一次**施展，所吞之物为**姚惜雪体内的风妖妖气**。
- 一吸之下，风妖恐惧至极：妖气自姚惜雪体内疯狂钻出、尽数被王林吸入口中；最后一刹那，**风妖深深刻在姚惜雪魂魄内的记忆**也一并被吸入王林**元神**之中。
- 王林对风妖表态：「你不该把记忆留在姚惜雪魂魄中，你我无仇，我会为你另选一个载体。」

## 二、姚惜雪：失忆重生

- 妖气尽去后，姚惜雪恐惧消散、双目迷茫，极为虚弱，**完全丧失全部记忆**，连自己是谁都想不起，如凡人初见仙人施法般惧怕王林。
- 王林告知其名为「姚惜雪」，并自称「**我，是你的一位故人**」。
- 姚惜雪隐约听到一个属于自己（失忆前的自己）的声音在脑海回荡：「前尘已了，如同昨日的风、今日的土……尘归尘，土归土」，因而也不愿再去追想。

## 三、放出血祖：兑现承诺，因果两断

- 王林祭出**十八地狱封仙印**，指向**第十四层**——其内只有一魂，被血雾弥漫、透出滔天怨恨，正是**血祖**。
- 红雾扩散，血祖现身，见到姚惜雪后狰狞尽消、神色转柔。
- 王林解开操控血祖的禁制，宣告：
  - 「当年王某曾承诺，让你与你女儿一见，眼下此事王某做到了。」
  - 因果清算：姚惜雪当年**计算于他**、致其**被封印数百年**；血祖欲杀他而落得如此下场；此事王林也算其中一因；姚惜雪要复仇、丧失记忆成为风妖傀儡，他**救她一次**，算了却前尘。
  - 「从此之后你父女二人与我王林再无瓜葛，此因果已断，若再纠缠，休怪王某杀之，让你父女魂飞魄散永生不入轮回。」
  - 「封仙印内十四层，你血祖也不需再回，我放你自由，陪伴你女儿这一生。这里是妖灵之地仙帝洞府，你们可以寻找一处等待最终全部开启后，离开这里。」
- **血祖的转变**：禁制解开后神智完全恢复；虽为魂体，但以当年修为可延续下去，且另有方法重新修炼。他明白王林若要杀他父女不费吹灰之力，却给了自由与新生——仇恨已不重要，唯愿女儿平安。评价王林：「此人早已不是当年那我不放在眼中的小辈，在这几百年中，他已然成长至了如此程度。」
- 失忆的姚惜雪出于血缘的信任跟随血祖离去；父女最终隐入一处禁制内，等待洞府开启之日。

## 四、道心圆满与闭关突破

- 解决姚惜雪之事、超脱这桩因果后，**王林道心在现阶段达到圆满**，磅礴气息滔天而起，久滞的修为「仿若冰川融化」，出现突破迹象。
- **仙玉玉简与地图**：王林取出当年得自**妖灵之地**、由**仙玉**制成的玉简（内记**仙卫炼制方法**与**定身术**口诀），神识沉入后确认其内那副当年觉得陌生的**地图**，正是眼前的**仙帝洞府**；他将地图内容牢记于心，并未贸然行动。
- **选址闭关**：走到**葬仙池**崩溃后留下的庞大深坑（仍有丝丝阴寒之气）旁，踏入深坑缓降数十丈，以数把大剑横扫坑壁凿出洞口，钻入盘膝，布置许久禁制。
- **银衣女尸护法**：放出银衣女尸（千娇百媚的女子）于洞口边缘盘膝护法。王林感觉她自吸收花海之毒后「似有一丝不同」却说不出何处；以神识查验，体内**操控封印**与众多隐藏禁制皆完好无损，遂放心打坐吐纳。
  - 三天中银衣女尸目光时而长久停留在王林身上，眼中**迷惑之色**一现即被深深隐藏。
- **突破手段**：坐满三日纹丝不动，元力运转越来越快、几近无始无终；第四日睁眼，因「此地天地元力不够」，取出数个**所杀之人的元神**一口吞下助推。修为自**窥涅中期巅峰**向上冲击。目的：在危险的仙帝洞府内多一分保命把握。

## 五、洞府地形与外部惊变

- **洞府外围地形**：地面仍有葬仙池崩溃冲击形成的废墟与庞大深坑；正前方可见成片阁楼与众多建筑，相互环绕组成**不规则图案**；目光尽头的阁楼深处被**浓浓黑雾**弥漫，雾中一座**大殿房尖**若隐若现。
- **星空异象（与王林闭关同时发生）**：仙帝洞府外的星空中赤红火光弥漫，如无尽火海横扫而来；火海最前方是一头**通体由浓浓烈火组成、翅展约数百里的庞大朱雀**，傲行星空，尚未临近便有无法想象的高温弥漫。所过之处修士瞳孔骤缩、争相避让。
- 有见识的**大神通修士**在看到朱雀刹那，脑中轰然浮现一个古老的名字——「**朱雀圣宗**」。此幕让**修真联盟**所有目击者为之震撼。

## 要点与伏笔

1. 「吞噬」一式首秀，可连人带记忆吸入元神，属清水仙术最霸道之能。
2. 王林以「救一次+放自由」的方式主动斩断与姚惜雪、血祖的百年恩怨；其因果观：只要他认为该如此，这段因果便如此。
3. 因果了断→道心圆满→修为松动，构成本次突破的直接触发链。
4. 银衣女尸的「一丝不同」与被隐藏的迷惑神色，是明显伏笔。
5. 仙玉玉简中的地图对应仙帝洞府，为后续深入内部（黑雾大殿）提供路线。
6. 朱雀圣宗以火海朱雀之姿降临，为下一阶段冲突张本。
