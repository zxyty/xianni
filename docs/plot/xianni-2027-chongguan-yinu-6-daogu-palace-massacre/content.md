# 第2027章 冲冠一怒！（六）

## 一、局面：万丈之隔，只见婉儿

- 王林在道古皇宫广场发狂突进，每走一步轰出一拳，阻挡者少有一拳之敌，肉身爆裂而亡。
- 皇宫内传送阵光芒不断，道古族人自阵中闪出、四面八方化作长虹涌来，数以万计仍在增援——此处正逢道古皇尊大婚，族人本就云集。
- 此地**无法瞬移、无法缩地成寸**；皇宫内更留有无数大阵，甚至可能藏有吉祖遗物，于王林如龙潭虎穴。
- 王林目中只有前方万丈外大殿中的「婉儿」（此世名宋致）身影。

## 二、大天尊之阳：一击荡平数万

- 王林仰天咆哮跃起，**白发刹那有一半化为黑色**。
- 黑发浮现的瞬间，其身后幻化出**大天尊之阳的轮廓**——夜空中多出一个黑白二色的太阳。
- 道吉皇尊面色大变、失声惊呼「大天尊」；包围的数万道古族人心神轰鸣，惊呼「他竟然是大天尊」。
- 王林双手抬起如举太阳，向下方疯狂一挥：黑白光芒笼罩天地，冲击如流星撞击，轰鸣压过战鼓成天地绝响。
- 结果：大地崩溃、青石碎灭、苍穹震动、半空平台尽数瓦解，**数万道古族人消散大半**，触之者化为飞灰。

## 三、道古皇尊之父出手：以血脉开古族大禁

- 冲击直奔大殿时，一身穿皇袍、不怒自威的老者虚影幻化而出，站在**距大殿六千丈**处，抬右手一掌硬接。
- 老者身后是守护大殿的**近千皇宫强者**：七十二圣、三十六煞、十八王、九大不灭将——此前皆未参与杀戮。
- 老者出现时，近千人狂热恭敬，连道古皇尊亦神色恭敬。
- 硬接之下老者身传砰砰之声、喷血倒卷，低吼「**以吾血脉，开古族大禁**」：血中幽暗之光散开化作无边无际的光幕如墙。
- 光幕挡住冲击——幕外广场尽成废墟，幕后一切完好如常；但闪烁数下终究崩溃成碎片。
- 老者**右臂成灰**，再度喷血萎靡，被轰飞摔入大殿，落在道古皇尊身边。

## 四、父子决裂

- 道古皇尊上前搀扶，被老者咬牙推开，反手一巴掌扇出五指黑印。
- 老者怒斥：「为了一个女子，你为我道吉一脉招惹如此强敌……我定去**古道山**面见**古道大天尊**，**重立新皇**。」
- 道古皇尊目露寒光、吐出血痰，冷道：「朕的事情，不需你管，有古道大天尊守护，朕是死不了的。」

## 五、以宋致要挟与王林的誓言

- 老者走到宋致身边低吼：「站住！你若再临一步，老夫就杀了此女！」
- 宋致面色苍白却无惧色，双目迷茫，**内心似有记忆要苏醒，却被一股力量封印**。
- 王林目光柔和望向宋致，口出杀言：「她若死了，王某会转身离去。但王某余下的生命中，将会让**道古一脉寸草不生**，让**吉之三族从此只剩两族**。我能做到。」
- 老者相信其能做到，眼露杀机却放弃动手——留此女方有杀王林之机。
- 关键伏笔：老者来此前已**捏碎道古一脉传承于古道大天尊的玉简**，玉简一碎即代表皇室有危机，需古道大天尊保护。

## 六、破近千守卫：古族之吼与血剑

- 王林一步迈入千人守护圈，七十二圣暴发全力、率数百族人扑杀，身后浮现巨大道古之影齐齐轰击。
- 王林不出手，只**张口一吼**——身后道古身影同吼，是为**古族之吼**：蕴含其全部修为、古族之力与魂血传承，化作音浪，七十二圣一一崩溃。
- 王林随即杀入人群：右手抓碎头颅、左臂横扫轰杀，口吐红芒**血剑**煞气滔天，一路穿透数十人杀出血路。
- 距大殿已**不足三千丈**时，三十六道血光闪现——**三十六煞**狰狞围至。

## 七、结尾：极火道未出，叹息临世

- 王林右手掐诀，五指间涌出青色烟丝缭绕成圈，火焰滔天而起——**八极道中的极火道神通**。
- 神通欲出的一瞬，天地间传来一声叹息，透出悲伤、失望、苍凉与痛惜：「**王林**。」
- 王林身子一震。章末点明：**玄罗来临**，王林面临抉择。

## 八、要点与悬念

1. 王林「白发半黑」+ 大天尊之阳，等同当众自证大天尊之身，改变了道古一脉对局势的判断。
2. 计都皇子借刀杀人的意图外显：他等的就是道古皇尊因女子招祸这一天。
3. 古道大天尊的介入已被玉简触发，是后续更高层级冲突的引信。
4. 宋致（婉儿）的记忆被外力封印，苏醒线索埋下。
5. 玄罗的叹息打断极火道，构成本章最大转折悬念。
