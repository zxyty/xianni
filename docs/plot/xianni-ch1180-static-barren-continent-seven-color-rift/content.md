# 仙逆 第九卷 云海之巅 第1180章 峥嵘！（第二更）

> 归属提示：本章「吕子浩」即【王林】（自第1063章起以归元宗故人吕子浩之名行事，身份由吕烟菲奉上）。本章正文以「王林」称呼行文。

## 一、赶路：五阶星域最深处

- 星空雾气弥漫，六道长虹疾驰。苍松子（碎涅中期）不取玉简辨向，显然对路途极熟，速度越来越快。
- 众人各自催动修为跟进。王林修为并非真正的碎涅，速度被拖慢，遂**不动声色取出速符**，身外风暴环绕，一冲而出跟上。
- 数日后星雾渐浓，进入五阶星域最深处，前方隐现暗影——一座蛮荒大陆。

## 二、清场：庞姓老者屠尽岛上修士

- 大陆不算太大，其上凶兽众多，兽吼不断。
- 苍松子：「这蛮荒大陆知晓之人不多，即便有知晓者，也不会找到老夫隐藏在这里的秘密。」
- 命满脸坑洼的**庞姓老者**散开神识搜寻，**不论宗派与修为，将大陆上所有猎兽修士尽数斩杀**。庞姓老者办妥后返回，只点头未言。

## 四、四山之阵与大地符文

1. 苍松子掐诀挥手，天地元力呼啸盘旋，搅动雾气成巨大漩涡；白发无风自动，双手狠按大地。
2. 大地震动碎裂，巨大裂缝如游龙延伸。
3. **正东、正北、正南、正西**四座万丈高峰同时放出刺目光芒，光芒扩散彼此连接，形成**四山之阵**。
4. 阵内大地被「刮去一层」，碎石飘升，地面平整如镜，露出**以神通之术烙印于大地、占据大陆绝大部分面积的巨大符文印记**——碎石本是事后覆盖用以掩藏印记之物。

## 五、王林的关键发现：静止的蛮荒大陆

- 王林盯着碎石升空、移动、消散的轨迹，心神一震：
  - **云海星域的大陆并非静止，而是在星空中极缓慢漂行**，凡人无感，修为到一定程度的修士静心可察其轨迹。
  - 而**这座蛮荒大陆完全静止不动**——此即其诡异之处。
- 之所以由他看破：王林不是云海星域本地修士，**其原星域全为星球，没有漂浮大陆**，故对比最为清晰；本地修士在惯性思维下极易忽略。

## 六、开阵：数十万仙玉与「仙阵，开」

- 苍松子盘膝坐下，虚空一抓开储物裂缝，仙玉如晶光飞出，落地即仙力消散化为飞灰。
- 一炷香内**废掉仙玉足有数十万块**，大地吸饱仙力，符文印记越发明亮，最终照耀大陆如同白昼。
- 苍松子大吼「**仙阵，开**」，声如雷鸣。印记剧烈闪烁，仙力散入大陆内部，**整座蛮荒大陆开始向北方移动**，速度极快。
- 王林、大头童子、陈天军、青衫老妪均为之动容，纷纷散开神识观察。

## 七、七彩裂缝现世

- 大陆彻底移开原位，露出原本正下方正中之处：**一道仅半丈大小、七彩之光缭绕的裂缝**，虽小却在星空中极为璀璨显眼。
- 大头童子倒吸凉气、神色激动（其五官本就扭曲，激动时更为可怖）；陈天军叹「好大的手笔」。
- 苍松子自陈来历：**此地本无这座蛮荒大陆**。当年他无意路过，恰逢裂缝刚刚出现；为隐藏此处，**特从别处挪移来一座大陆将裂缝掩盖**，使外人无法发现。
- 青衫老妪问「这七彩裂缝通向何地」，苍松子只笑答「**去了便知**」——目的地本章未揭示。

## 八、撞缝入界之法

苍松子的解释（关键机制）：

- 裂缝**不稳定，不能直接进入**：若直接进入，**己方进去两人裂缝即会崩溃**——虽不会消散，但会缩小，导致**难以回归**。
- 故须**以蛮荒大陆为引撞入**，使裂缝变大，众人在瞬间进入；
- 有**大陆上的烙印牵制**，裂缝不会崩溃，返程时影响也会小得多。

执行：大陆先移远，骤停；苍松子双手掐诀齐按大地，大陆**以极速直撞七彩裂缝**——其冲击之速不弱于、甚至快过一名碎涅修士，大陆颤抖剧烈、边缘大片碎石崩落。轰然撞上时，七彩之光疯狂闪烁照亮四周星空，裂缝被**强行撕大**。

## 九、入口前的对峙（本章收尾）

- 苍松子喝「走」，率先冲入；余人全速紧随踏入裂缝。
- 场外**只剩云魂子与王林**。云魂子在王林身后冷冷注视，王林心中冷哼而速度不减。
- 将踏入裂缝的一刹那，**王林猛地回头**，双目寒光一闪；云魂子双眼一凝。
- 王林右手虚空一晃，取出一把**锈迹斑斑、却有惊天动地之威的铁剑**。（章末悬念，交手结果未叙）

## 十、要点小结

- 苍松子的「秘密」= 一道由整座挪移而来的蛮荒大陆掩盖的七彩裂缝；开启代价为数十万仙玉 + 一座大陆作撞击之引。
- 王林的信息优势来自「外来者视角」：静止 vs 漂移的大陆差异。
- 云魂子与王林的宿怨在入缝一刻正式摊牌，王林亮出锈铁剑。
