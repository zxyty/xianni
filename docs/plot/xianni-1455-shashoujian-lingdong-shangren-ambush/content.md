# 第九卷 云海之巅 第1455章 杀手锏！

## 一、背景：妙音道尊的道途
- 妙音道尊为**太古五尊**之一。
- 以**音之本源大成**震开**空夕大门**，成就**三步大能**。
- 其后炼化**太古千星之海**，期间偶遇莫大造化，使**水之本源**得以正果（未至圆满大成）。
- 音、水二本源融合后威力「足以撼仙」。

## 二、香火誓符之赌——大荒上人破局
- 妙音道尊后退中取出此前大荒上人香火誓言所化符文，狠狠捏碎，喝问「大荒老毒，你誓符在我手中，我看你如何应对香火之誓」。
- 大荒上人（分魂所在肉身）喷出一口鲜血，神色不萎，狞笑：其所修功法与众不同，**夺天地之造化**，香火誓符不足以令其重伤，「一口鲜血，足以」。
- **代价的转嫁**：同一刻，古之墓地外**太古星辰**中一处**蛮荒星**上，大荒上人本尊盘膝喷血；该星生灵连同山河之灵瞬息枯萎，化作黄沙废墟，整颗星辰走完无尽岁月，成为**死星**。

## 三、大荒上人的杀招
1. **五毒**：黑风滔天中，巨大掌印五指分化——
   - 食指→百丈漆黑蜈蚣（须极长、节节扭曲）
   - 其余四指→独角百丈黑蛇、巨大黑蜘蛛、庞大蝎子（蝎尾似可破开虚无）
   - 拇指→背生鼓包、蕴含无法想象毒力的蟾蛤
2. **还我本相**：喷出毒气倒卷融入面部，蜡黄发黑之容腐烂蠕动，转为**本尊之容**：满脸疤痕、双唇被三根针穿透、乱发下双目寒光。
3. **三仙，解印**：自陈「四万年前炼化**大荒三仙**成针印封双唇」，今日为杀妙音而解印；三针穿透唇肉飞出，化三道黑芒直取妙音，双唇随之张开。
4. **紫黑毒舌**：一条非人所应有的紫黑舌头自唇内射出，硬撼紫海。

## 四、妙音道尊的应对
- **海之啸·海之吼**：双手挥舞，轰鸣取代天地一切声音，身外幻化紫色海洋浪声拍击；音道水道融合成海，声音放大无数倍足以毁天灭地。
  - 后果：**封印之地骤然崩溃碎开**，外界雾气冲入与雾海融为一体；地面上近百修士无法避开，肉身砰砰崩溃惨叫而亡。
- **海民界开**：身后崩溃天地中裂开数万丈巨缝，缝内是一片没有修真星的星空紫海，其中生灵**全部是妙音道尊的香火海民**；双手猛撕使裂缝十倍暴增、几近无边无际，无尽紫海与亿万香火之灵如洪水拍向大荒上人。

## 五、二尊交锋结果——妙音惨胜
- 毒舌硬接紫海，大荒上人闷哼，紫海冲过拍在其身：喷血、**肉身直接崩溃**，仅余一缕**分魂**急急后退。
- 但紫海被毒舌触碰后由紫转墨、腥臭四起，**整个香火海彻底成了毒海**；五毒化五道黑气融入毒海直奔妙音。
- 妙音道尊喷血急退：**眉心刺入三根针（入一半）**，黑色大量扩散；胸口血肉模糊处五道黑气旋转化五毒，深深钻入体内。
- 战果评价：香火之海被污、自身中奇毒，却毁去对方肉身只剩分魂——「这一战，他妙音算是惨胜」。

## 六、王林的杀手锏（本章转折）
- **收兽与夹击**：妙音神通出现刹那，王林大袖甩动收走全部**蚊兽**，向前迈步与大荒上人一前一后再度形成**前后夹击**；以**燃烧雷目**横于身前抵消海吼。
- **妙音的困兽一击**：油尽灯枯下，妙音猛地转头、右臂与身体分开自爆，化血肉白骨碎末成狂风横扫王林，内蕴断臂杀人一击；其心中仍视未成第三步的王林为蝼蚁，怒喝「滚」。
- **天皇炉出**：王林右手点在眉心，眉心**古神星点**幻化，自**第一个星点**内浩荡而出**天皇炉**，虚幻转实质，硬接狂风。
- **灵动上人现身**：天皇炉面向妙音的外围如融化般裂开，一股**隐藏了很久很久**的杀气爆发，**灵动上人**冲出迎入狂风；随其显化一尊如魔神般双手抱胸的巨大黑色雕像，低吼中双臂松开，毁天灭地之力向妙音宣泄。
- **命中**：时机精准（妙音重伤且距离极近，避无可避）。妙音失声惊呼「灵动」，面色大变、眼露不可置信。灵动上人右手死死按在妙音眉心，把三根针再拍进额头一寸（未全部拍入）。
- **结果**：妙音凄厉尖叫，全身被黑色覆盖，体内毒素彻底爆发，在毁灭之力下**重伤濒死**，身子倒卷、全身爆出血雾向后飞去。
- **新变数**：肉身崩溃的大荒上人分魂急急临近，欲进入妙音体内**强行夺舍**。

## 七、要点提炼
- 王林的布局核心：把灵动上人长期藏于天皇炉，作为对妙音的「出其不意的最强一击」。
- 大荒上人的功法本质是**以本尊/星辰生灵为代价转嫁伤势**，香火誓约类手段对其效力有限。
- 战场环境变化：**封印之地已彻底崩溃**，三人此刻完全处于**古墓雾海**之中。
