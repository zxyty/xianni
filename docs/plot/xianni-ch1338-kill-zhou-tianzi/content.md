# 第九卷 云海之巅 第1338章 杀周天子（第一更）

## 一、开篇定调：王林的行事底线
- 王林修道两千年，一路凶险，凭睿智心机与不甘命运的挣扎在生死间游走，练就「敢摘天中明月」的胆量。
- 连第三步大能、神宗大长老水道子他都敢一战；之所以在闪雷族选择「伺机而动」，是因为在太古星辰先受拓森追击、又遇蓝梦道尊，对太古星辰生出深不可测之感。
- 但伺机而动有底线：一旦有人踏过，其无法无天的性格爆发就必然杀人。战星野的「战之本源之意」在其心神中已根深蒂固。
- 行为准则重申：人不犯我，我不犯人；人若犯我，我必杀人。

## 二、雷晶殿对峙
- 周天子以「天人第一衰」的姿态对王林（此时以「于非」之身）伸出獠牙，王林眼中寒光、嘴角冷笑。
- 周天子由王林神情生出隐隐危机感，但在他眼中王林只是「小小问鼎修士」，遂起杀意。
- 叙述点破：周天子想象不到有人能冒充闪雷族人进入此地、更进入雷晶殿；这个在他眼中不堪一击之人，实为「远古凶兽，凶焰滔天」。

## 三、六名守门修士与玉简放行
- 一触即发之际，负责此地的六名闪雷族修士齐齐睁眼，其中一人起身问：「你叫于非？」
- 王林立刻判断，此人知其名，应与之前在东门空间内赠他玉简的闪雷族「阳实」小辈有关。
- 王林二话不说甩出玉简；该修士查看后向周天子抱拳求情：此人受「故友嘱托」进入七百万天地试炼，该任务并非只可一人接取，不如放他一去。
- 周天子考量：这几人虽不堪一击，但族中有职务、背后有闪雷族长老，需斟酌。

## 四、周天子的算计：改在七百万天地灭口
- 内心决断：在雷晶殿杀人会让长老难做；让这「小爬虫」进入七百万天地，在那里击杀无人可察。
- 七百万天地的性质：有禁制存在，连老祖神识也不能探入；实为族中私怨的杀戮场，也是众人暗中交易之地，强者为尊。
- 周天子借玉简先行进入；随后任务玉简爆发刺目光芒，王林抓住、神识探入，随之进入。

## 五、守门六人的后续议论
- 不悦：帮了他，却连个谢字都没有。
- 一人本想劝阻：周天子眼中杀机此子看不到，他们却清晰明了，一旦进入怕有生死危机。
- 惋惜「浩然道友」的嘱托——传音中浩然似乎对此人很是赞赏。
- 结论：他之生死，自有天定。六人重新闭目打坐。

## 六、七百万天地通道
- 环境：细长通道，散发晶莹刺目之芒，人被光芒照落即变透明、五脏六腑清晰可见。
- 神识观察：通道内蕴含浑厚壁障之力，阻止外围一切神识延伸；且有肆虐的空间乱流隐隐流转。
- 王林元神太强，仅一瞬即恢复如常；判断「在这里杀人也不会有人察觉」，遂猛地前冲，速度轰然爆发。
- 空间乱流被搅动，时而出现巨大撕裂之口，却被王林一冲即轰然碎开、齐齐消散。

## 七、周天子在通道中的心思
- 二人前后脚进入。周天子雷光披风包裹全身，如一片雷云前行，须避开空间乱流裂缝而时快时慢。
- 神色由雷晶殿的冷漠转为阴沉跋扈；自恃窥涅修为有傲然资格。
- 盘算与「浩昆子」的交易：对方修为高出自己一些，若抱豪夺之念自己不是对手，故已约好友同往以使其有所顾忌。
- 对王林的定位：爬虫蝼蚁，等「于非」在七百万天地大广场一出现就轰杀。

## 八、通道反杀
- 临近出口时，周天子全身汗毛倒竖，爆发此生最强烈的危机感；身后传来冰冷至极之声：「你要杀我？」
- 他转身见王林缓步走来——一道道乱流在其身前轰轰崩溃，身后通道尽是残破裂缝碎片，宛如「崩溃天地而来」，给周天子一种此人破开天地来杀自己的意志。
- 周天子失声「你隐藏了修为」，面色苍白却杀机骤起，一拍眉心放出眉心印记，通道内无尽雷霆凭空出现，化作雷龙咆哮吞噬而来，雷霆与回音音浪融合，发挥出窥涅修士最大力量。
- 王林神色平静、目露讥讽，抬手一挥：「不自量力！这天地间一切雷霆，听我号令，崩！」雷龙自龙头开始崩溃，瞬息全身碎灭。
- 周天子现身喷血、面色苍白，惊骇判断：「碎涅？这是碎涅修为？不，这超过了碎涅，这是……」随即魂飞魄散、疯狂后退，心中只有一个「逃」字。
- 收尾：阴寒之声在通道内回荡——「你不是要杀我么？」

## 九、要点与伏笔
- 王林在闪雷族的「于非」身份至此仍未被识破，反因浩然（东门空间阳实小辈之关联）的玉简嘱托获得放行。
- 七百万天地=禁制屏蔽老祖神识的黑市兼私斗场，为后续行动提供了「杀人无人可察」的双向舞台——周天子想用来杀人，反被王林用来杀他。
- 周天子与浩昆子的交易线索、以及他所约的「好友」，为后文留下钩子。
- 王林真实修为被周天子判为「超过碎涅」，此为其实力在闪雷族语境下的首次侧写暴露（仅周天子一人所见）。
