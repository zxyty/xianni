# 第1925章 天门

## 一、离开地门：对周佚与青霜的愧意

- 王林在尘暴笼罩的地门外长叹：此事「或许对青霜不公，也对不住青霖」，但因周佚数千年的痴情，他做不到完美。
- 来之前他没想到会在地门遇到「他与她」（周佚与青霜/青霖相关的转世故人）。

## 二、故人追忆

盘膝坐于海龙头顶，王林抬头望天，心生惆怅，逐一念及当年之友：

- **司徒（南）**：不知有没有过上他喜欢的王爷生活。
- **清水师兄**：不知身在何处。
- **许立国**：狡猾多变，不知如今可好。
- **刘金彪**：自悟骗道，不知是否还在领悟。
- **李倩梅**：一并被念及。

这是他在仙罡大陆第一次见到转世故人之后泛起的追忆涟漪。

## 三、孟土宗一行

- 海龙疾驰前往此洲另一极强宗门 **孟土宗**，此宗以 **孟土洲** 为名，实力与地门不相上下。
- 以王林天尊修为 + 金尊程度的海龙，此行极为顺利：孟土宗老祖恭恭敬敬奉上 **地图玉简**，生怕惹王林不喜。
- 王林在宗内散开神识寻找当年故人，明知可能性不大，仍一无所获。
- 带着叹息与对周佚、青霜的祝福，离开孟土洲，转向东州境内的 **天洲**。

## 四、天洲与天门设定

- 整个东州内天尊层次修士只有数人，并不多见。
- **天洲**：云雾本应在九天之间，此地因奇异变化使云雾低垂至地面、似伸手可抓；全洲如仙境，常年笼罩飘渺云烟。
- **天峰**：天洲无数大山中最高之峰，白云缭绕、看不清完整山体，峰顶白雪皑皑。
- **天门**：天洲最强宗派，九宗十三门之一，是天洲唯一的一方霸主；与其他宗派不同，并非只有一个山门，而是在全洲设 **十九个分宗**，完全控制一洲资源。
- **天门老祖**（白发老者，王林称其「慕容道友」）：传闻与 **罗云海** 同代天骄，修为在天尊境界止步，曾跟随 **双子大天尊**，后似生变故而默默离开，回天门内数万年不曾外出。

## 五、天峰邀战

- 海龙在天峰外波纹扭曲中现身盘旋，释放相当于金尊的修为笼罩八方。
- 王林一身白衣、白发，踏白云而上天峰之巅，背手立于风雪中。
- 神念邀战：「在下王林，请天门老祖于天峰一见」——神识如万万雷霆轰鸣，化作真实雷音扩散，弥漫半个天洲；天门所有分宗及依附宗派修士心神震动皆闻；数千万里内云雾崩溃撕裂避开。
- 天门主宗山脉气息爆发，白发老者穿粗布麻衣一步走出，大袖一甩瞬移至天峰之巅。

## 六、目光交锋与切磋经过

| 阶段 | 内容 |
| --- | --- |
| 目光初触 | 老者目光如亿万之针欲刺入王林体内；王林双目金光闪烁，其目光在老者感受中如一把蕴含浓郁仙力、锋利冷冽并含天威镇压的金色之剑 |
| 缘由 | 王林言「初踏天尊之列，想询道友指点一番，别无他意」，客气抱拳；老者战意弥漫而应允（天尊稀少，切磋机会难得且互有裨益） |
| 首击 | 老者大袖一甩，天峰白雪尽起化作雪暴，内蕴九道神通；王林长笑一拳轰出，同样蕴含九道神通，且为九次同样的 **役灵印** |
| 首轮结果 | 轰鸣持续数个时辰，二人各自倒退数千丈站稳，互相抱拳致意、彼此称赞（老者赞其刚入天尊便能将九道神通融入一拳一脚，且年纪不大） |
| 拉锯 | 此战七天，共交手 **二十三次**；每隔几次二人散开盘膝恢复修为、思索所得并相互交谈；海龙心惊肉跳退避观战 |
| 全力一战 | 第二十三次后老者提议放开手脚全力一战。王林祭出 **五行本源真身**，只出一具分身战力暴增，可与融入十八道神通的天尊修士一战；老者惊觉其为「多种本源融合而成的真身」，随即爆发融入 **十七道神通** 的天尊之力 |
| 收尾 | 全力一战持续三天，王林长笑而起，踏海龙远去，留言「慕容道友，多谢」 |

## 七、战后余波

- 白发老者神色凝重，判断「他应该还没有出全力」，暗忖以王林修为「不知能闯过几层天尊涅之地」。
- 老者决定：「我仙族多了一个天尊修士，此事需禀告给大天尊。」十天交战对他自身亦有诸多感悟。

## 八、要点提炼

1. 王林天尊初期的战力标尺被明确量化：本体九道神通融入一拳一脚，出一具五行本源真身分身即可抗衡十八道神通级天尊。
2. 天门/天洲/孟土宗/孟土洲的地理与势力结构补全了东州版图。
3. 「天尊涅之地」作为新的试炼概念被提出，指向后续情节。
4. 王林行踪已上达仙族「大天尊」层面。
