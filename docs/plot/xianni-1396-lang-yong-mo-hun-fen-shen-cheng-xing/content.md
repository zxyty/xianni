# 第1396章 浪涌

## 一、魔气归洞：魔魂小人成形

- 时间锚点：距落生会之选之日的**第六天**。此前数日，暗蝎族修真星始终被魔气大雾笼罩，星上生灵隐隐暴躁。
- 当日星上魔雾剧变：魔气滚滚呼啸、急速收缩，尽数直奔**王林闭关的洞府**，自高空俯视如巨大漩涡，洞府即漩涡中心。片刻之间天地魔气消失无影。
- 洞府内魔气凝成神识都无法穿透的浓雾。雾深处王林盘膝而坐，身前浮着一个**暗红色小人**：身子模糊似元神又似魂体，容貌与王林**一模一样**，唯神色暴虐疯狂、狰狞弥漫。小人张口鲸吞，尽食洞府魔气。

## 二、镇压与炼入雾魔枪

1. **反噬**：小人身躯稍凝实仍不满足，转身直勾勾盯着王林，尖啸扑来，欲连王林一并吞噬。
2. **一声冷喝**：王林睁眼，目露阴寒，未见施展神通，只一声「滚」，小人便惨叫倒抛落地。
3. **宣示主权**：王林起身虚空一抓，喝道「我创造了你，也自然可以毁灭了你」。
4. **逃遁与召回**：小人崩解为雾四散避开王林手掌，于洞府外重凝成型疾驰而逃。王林掐印吹出一口气，远处天边即传来凄厉惨叫，魔魂小人自行飞回跪地磕头求饶，身形模糊几近消散。王林冷道：「我一口气，就可让你灰飞烟灭」。
5. **融器**：王林虚空一抓取出**雾魔枪**，一指魔魂；魔魂与其心意相通，虽有犹豫挣扎，在王林冷哼后化黑光融入枪中。雾魔枪如获灵魂，气息暴涨，化作**黑色魔蟒**破开洞府盘踞天空长啸，蕴含暴虐、疯狂与浓浓嗜血，视天地生灵皆为敌。
6. **收回**：黑蟒嘶吼中消散为黑芒，融回王林体内。王林元神旁自此多出一个**魔魂小人**，双目紧闭，被元神生生压制，无法反抗挣扎。

> 旁观反应：暗蝎族与云遁族修士目瞪口呆、骇然恐惧。**钟大洪**却兴奋跪拜大吼「主子法宝大成，神功无敌」——文中点明他与**许立国**心态不同：王林越强，他越觉荣耀。

## 三、王林的下一步谋划

- 魔魂分身**尚未大成，仅具雏形**，需**多次祭炼**方可成真正分身。
- 自语核心伏笔：「不知我**神、魔、妖三体合一**后，是否能如我预料那般，**返祖成古**」。
- 随即取出两样宝物：**一片枯黄的树叶**、**一个被封印的树人**。

## 四、设定：大帝星与落生会长老之选

### 大帝星
- 位于**颠落之地**内，最神秘莫测，是**落生会圣地**，亦是**颠落大帝洞府**所在，为**长尊会**重点研究之星，传言广布太古星辰。
- **旋转规则**（长尊会多年研究后宣布）：一切星球无时无刻不在旋转，万古岁月中任何不规则修真星终将成圆——这解释了太古星辰修真星大都成球的现象。
- **大帝星是唯一例外**：呈长条形，自无尽上空俯视如**罗盘上的指针**缓缓旋转，成因无人知晓。
- **禁制环境**：平日星外弥漫无法想象的**撕裂之力**与**元磁**，修士至此法宝失效、修为被压制；唯每次长老之选时二力大幅消散，露出**几条固定通道**可供入内。

### 长老之选的规矩
- 参与者：颠落之地**三百多个小族**中凡有资格争夺长老之位者。
- 观战者：太古星辰之人多受小族邀请前来，有时**还会助战**；颠落大帝从不理会，久之成默许规矩。
- **铁律**：非颠落之地的族落**不允许成为长老，否则必死无疑**。
- **长尊会**每次派人作为**宾者**出席：一为表露对落生会的认可、对颠落大帝的尊重，二为近距离观察甚至**扶持某族**。
- 落生会另发**邀请玉简**，请太古星辰强者来临。颠落大帝对这一切全然不理，似只当作一场热闹。

## 五、赴会与各方登场

- **王林**在暗蝎族与云遁族陪伴下，穿星空向大帝星前行。
- **长尊会一方**：颠落之地外的太古星辰中，**云落大司**（长发披肩女子）立于**八角形巨大轮盘**上凝望前方，秀眉紧皱；身旁神色阴沉的中年男子问「那颠落大帝杀我分身，此事长尊会可有什么说法」，云落大司轻答「会有补偿的」。其心中自语：能让颠落大帝庇护此人，真想亲眼见一见，**就是不知他是否是先祖卦象内所提之人**。
- **蓝梦道尊一方**：太古星辰另一方向，柔和蓝光中蓝梦道尊背手缓行，**李倩梅**默默跟随。
- **望月一方**：罕有人迹的星域内，一头可比修真星大小的椭圆**凶兽「望月」**缓缓飞行，体外无数数万丈**触手**徐徐摇曳。其背上立一**白袍老者**，相貌诡异，**半边脸为黑色**如阴阳阻隔；身后三名仆从若王林见到定觉极为眼熟——**一木子、武东禅**，以及**本已死亡的极贤天**。

## 六、伏笔与看点

- 魔魂分身是「神魔妖三体合一 → 返祖成古」计划的一环，尚需多次祭炼。
- 枯黄树叶与被封印的树人被同时取出，指向后续（疑与妖体一路相关）。
- 云落大司口中「先祖卦象内所提之人」将王林与某项古老预言挂钩。
- 极贤天「本已死亡」却作为白袍老者仆从出现，是明确的悬念点。
- 中年男子分身被颠落大帝所杀，长尊会以「补偿」搁置，埋下势力摩擦。
