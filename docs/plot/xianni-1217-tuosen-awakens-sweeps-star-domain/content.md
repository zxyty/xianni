# 第1217章 苏醒（第九卷 云海之巅·第四更）

## 时间锚点
- 以王林进入七彩界为起点，本章已过去 **九十九年**。
- 期间联盟星域发生惊天动地的变化。

## 一、九十九年间的星域格局

### 四圣宗横扫，逼压尸阴宗
- 四圣宗强势出手，一举横扫**修真联盟**残余的各个宗派。
- 并强行逼压**尸阴宗**出手，与其一同对抗**罗天**大军。

### 尸阴宗的算盘
- 尸阴宗原无参战之意，抱**渔翁得利**之念——其地处罗天与四圣宗之间，任何一方欲胜似都需其相助。
- 尸阴宗**不在意**罗天并非昆虚星域之人、而是外来入侵者这一点；他们在意的是战争带来的**大量肉身交易**。
- 尸阴宗甚至期望战争**永久进行、没有尽头**。

### 青龙圣皇一人破局
- 青龙圣皇**独自**踏入尸阴宗星域，一己之力连杀尸阴宗长老无数，更重伤尸阴宗残存的数王。
- 逼得尸阴宗**闭关多年的宗主（第一王）**出手，二人展开震惊整个星域的大战。
- 结局：**第一王彻底败落**；若非青龙圣皇另有目的，杀之不难。
- 影响：尸阴宗震撼，完全知晓四圣宗之强，对青龙圣皇产生前所未有的恐惧，**不得不听命于四圣宗**，与之一同向罗天开战。
- 这是一场**雨、云两界**的大战。

## 二、拓森苏醒与横扫

### 破阵而出
- 战争之中，**拓森苏醒**，破开阵法，从**朱雀星**上走了出来。
- 其出现立刻震惊罗天。拓森**行事全凭喜怒**。

### 屠戮罗天大军
- 刚现身即有罗天修士招惹，他一人冲入战场，横扫之下杀罗天修士**上万**。
- 杀人后冷漠而走，只留一句：**“你们，太弱。”**
- 无一罗天修士敢追；隐藏的**鲁夫子**骇然之下远远逃出联盟星域，不敢再踏入半步。

### 重创四圣宗
- 拓森先去四圣宗，施展**古神之力**配合**眉心星点**，一式神通**重创青龙圣皇**。
- 更崩溃了四圣宗的星域，使**整个东部遍布无数裂缝**，从此再无人可以进入。
- 未杀青龙圣皇，同样留下一句：**“你，太弱。”**

### 熄灭朱雀圣宗万古之火
- 朱雀圣宗所在之地那**万古不灭的火焰**，被拓森看到后挥手间消散、彻底熄灭。
- 拓森评语：**“这火，看着刺眼。”** 朱雀圣宗所有族人无敢怒言者。

### 崩溃昆虚圣地
- 拓森随后去了**昆虚之地**，与其内**老者**一战，将其**封印在眉心**。
- 更在**灭神矛**之下使整个昆虚崩溃——存在无数年的**昆虚圣地**从此烟消云散，成为记忆中的永恒。
- **木冰眉**于此战肉身崩溃、元神重伤失踪；拓森不屑去追，只在其身上留下**一道印记**，放其离开。

### 迁怒尸阴宗
- 因寻找不到**王林**，拓森怒火牵连尸阴宗，死伤无数后方离去。

## 三、雨之仙界前的收手

- 拓森最后所行是被封印的**雨之仙界**。面对封印大阵，他**第一次神色凝重**，但桀骜之色在凝重中更加浓郁。
- 将要出手的刹那，**青霖**出现在雨之仙界外。
- 二人不知有何交谈，事后拓森**沉默很久，点了点头**，转身离去。
- 拓森带着众多**被操控的上古炼气士**，消失在联盟星域，不知去向。

## 四、悬念
- 拓森茫然寻找那个**他必须要吞噬之人**（王林）。
- 但此人似乎消失在天地之间，任凭拓森如何感应，**都察觉不到半点气息**。

## 备注
- 依【世界状态须知】：青霖已于第576章死亡，本章其现身于雨之仙界外应按残念/化身/特殊存续处理，置于低置信度记录。
- 尸阴宗的“肉身交易”动机与其在罗天—四圣宗之间的中立地缘，是其被迫参战的关键背景。

# 第1133章（承第1132章后）百年之后

## 一、拓森一人终结联盟星域之战
- 拓森的出现使**联盟星域**格局大变，星域一时安静下来。
- **罗天修士**因拓森之故齐齐后退，离开联盟星域；持续数百年的战争，因他一人而结束。
- 拓森临走前发出震惊整个星域的咆哮：**「王林，你到底在哪」**——显示其寻找王林之意。

## 二、百年间的四处思念（同一意义的呼唤）
### 1. 吕烟菲 · 云海星域 · 莫罗大陆 · 归元宗
- 与拓森咆哮同一时刻，吕烟菲轻声道：「前辈，你在哪……还有一年，就是**主宗大比**，你能回来么」。
- 时间锚点：距归元宗主宗大比尚有一年。

### 2. 卢云从 · 云海星域 · 紫道宗
- 紫道宗近百年飞快发展，隐隐成为**五阶星域内排名前六**的宗派。
- 宗主卢云从常茫然望星空，被身旁老者偶然听到喃喃低语：当年与「吕兄」论道得益匪浅，百年过去却听不到其半点迹象；如今修为已提高，愿再相遇论道。
- 注：「吕兄」即王林化名**吕子浩**（自第1063章起，由吕烟菲奉上此身份）。

### 3. 李倩梅 · 九阶星域 · 妖宗奇异裂缝战场
- 蓝发的李倩梅在雾气至深处的裂缝战场斩杀凶兽，宁静而强悍，各宗修士敬畏，亦有不少暗生爱慕。
- 战场态势：兽潮持续百年且愈演愈烈，十二阶凶兽增多，甚至出现**十三阶凶兽**，每次出现皆为灾难浩劫；修士几乎每天都有道消战死；崭露头角者亦倍增。
- 妖宗之人是战场主力，视各宗来人不过是「分散凶兽的残力」；百年中仅**四人**获妖宗认可，李倩梅为其一。
- **金色的笔**：勾画可出符文、威力极强。任何人（含妖宗之人）欲借阅观详皆被她拒绝，宁静性子在此刻露出前所未有的坚定。
- 夺笔事件：一次被数只十二阶凶兽围攻，重伤昏迷、金笔遗失战场，被妖宗之人救下；片刻苏醒后不顾所有人劝阻，散发咬唇带伤冲出，只为取回金笔。此后众修士皆知此笔是她最珍贵之物。
- 她盘膝坐于简易修行台，面色苍白带伤，忘却厮杀与咆哮，抬首远望：「你，眼下在什么地方……不知不觉，近百年了」。

### 4. 木冰眉 · 云海星域 · 蛮荒大陆
- 当日被**拓森**重伤、肉身崩溃后，其元神以**昆虚秘术**破开壁垒，逃到云海星域内一片雾气中的蛮荒大陆，缓缓凝聚肉身。
- 肉身崩溃时，她脑中唯一存在的念头是**想再看王林一眼**。
- 在蛮荒大陆一处山峰洞穴内睁眼，怔怔望着前方，前所未有的孤独感弥漫；体内外皆寒，洞外寒风呜咽，令她更冷。低语：「王林，不知你现在，可安好」。

## 三、七彩界的百年黑暗与王林肉身
- 七彩界在光芒消失后，百年内一片黑暗。
- 一股**奇异力量**笼罩着王林元神与灵魂消散的那座山峰，外人无法进入。
- **云魂子**试图闯入失败，只得在附近寻一处洞府，默望漆黑世界度过百年。
- **陈天军**与**青衫老妇人**同样身处七彩界黑暗中，感受岁月流逝。
- 山峰顶部平静躺着王林的身体：百年过去，**古神肉身**丝毫未腐，保持百年前模样，唯落满灰尘。

## 四、界外：天逆珠成形与王林苏醒（本章核心转折）
- 场景：一片**为滋养七彩花而存在的奇异星域**，通体赤红的植物上，果实渐成数丈大小，将要彻底成熟。
- 就在这一天，果实内出现一道**残识**，吸收果实内的奇异之力渐渐壮大，最终凝聚成一个**珠子（天逆珠）**。
- 珠子出现的刹那，**王林好似做了一场梦，缓缓地苏醒了**。
- 关键点：因天逆珠的出现，王林的苏醒**没有引起任何人察觉**，连**养花人**都没注意到果实内的惊天之变。
- 叙述定性：这种变化「足以让乾坤颤抖，足以让这天地间的一切，改变轨迹，无论界内，还是界外」。

## 五、伏笔与母题
- 养花人曾自信「他不会被火旺之后焚烧了手指」——文末以「会么」「会的」的自问自答，直指其自信必被打破，呼应逆天/因果母题。
- 界内（七彩界、诸星域）与界外（养花人、七彩花星域）的双层结构在本章被并置点明。
- 全章结构为「百年群像 + 一处惊变」：所有人在寻找、思念一个已「死」之人，而此人正于界外悄然复苏。

## 六、时间线要点
- 拓森退敌 → 战争结束（本章起点）
- 其后约**百年**：紫道宗崛起、李倩梅立名妖宗战场、木冰眉凝聚肉身、七彩界陷入黑暗
- 距归元宗**主宗大比**尚有一年
- 百年终点：天逆珠成形，王林苏醒
