# 第1797章 奇异的白光（第二更）

## 一、仙罡大陆：玄罗的苦等

- 地点：仙罡大陆 → 东洲 → 天牛洲 → 七道宗所在黑山顶峰，雾气缭绕的大殿外。
- 玄罗盘膝坐守，一等便是数年；距其与王林约定的**十年之期**，已过去半年。
- 玄罗眉心那道当年黯淡的**红印**，此刻已完全消散、半点不剩。
  - 红印散去 = 王林归来之路**失去指引**，也或许代表**王林的死亡**。
- 玄罗眼中露出悲哀，长叹闭目：“他失败了么”，仍准备再多等一些时间，等一个希望渺茫的奇迹。

## 二、虚无层：王林的十年独行

### 处境
- 位置：**洞府与仙罡大陆之间的虚无层**。
- 形貌：披头散发，背负**避天棺**（棺内为其妻**李慕婉**）。
- 状态：已没有思绪，没有力气，推动他前行的只剩内心的一股**意志**——以自己的身体保护妻子，决不放弃。
- 半年前眉心红芒消失后，他感受不到前方的路，唯一能做的就是**不后退、保持方向**，直线前行以寻出路。
- 十年漆黑沉寂足以使人发狂；若无此意志，早已心神崩溃。其**道古修为**在十年消耗中已所剩不多。

### 转机：散发白光的尸体残骸
- 虚无前方忽现微弱之光，近看是一具**紫袍老者**尸体：双目紧闭、毫无生机，但周身白光在漆黑虚无中格外显眼，体内似有一股**奇异力量**凝聚。
- 王林黯淡双眼骤然爆芒，以极快速度挣扎冲去，右手深入白光按住尸体胸口，**一吸**——白光凝于掌中迅速消失，胸口那股奇异力量顺手钻入其体内。
- 力量特性（王林不知其为何物）：
  - 触感**冰凉**，令其头脑一清；
  - 使**枯萎的本源**有复苏迹象；
  - 连**道古之力**也慢慢恢复一些——王林认为这种变化“几乎不可能出现”。
- 松手后失去光芒的尸体向后飘去，王林面色略好。

### 稀缺性
- 半年前（红芒消散之时）曾遇到过**第一具**同样的残骸，吸收后才有继续坚持的动力——此即所谓“另有机缘”。
- **十年间总共只遇到两具**。
- 王林散开神识向八方弥漫寻找光芒，但遇到纯属偶然：在**不改变方向**的前提下有心去找也很难找到。

### 一年之后：油尽灯枯
- 又过一年，**再未遇到第三具**。
- 体内修为消耗到极限，**油尽灯枯**。
- 容颜极为消瘦，即便相熟之人也很难一眼认出；双目神采越来越淡，最后几乎没有任何光芒，**如同死人**。
- 前路还有多远未知，这种未知化作可怕情绪，连王林的意志在其中也**有了波折**。

## 四、伏笔与悬念

- 白光尸体来历不明：为何能同时补充本源与**道古之力**？虚无层中为何会有这类残骸？
- 玄罗红印与王林眉心红芒为同一指引体系，两端同时熄灭。
- 王林意志首次出现“波折”，为后续危机埋线。

> 归属说明：据世界状态须知，王林自第1380章起以「烨寞（道古烨寞）」之名/身行事，属借势代入化身而非冒名行骗；本章体现为其所持「道古之力/道古修为」。李慕婉本人已于第188章死亡，本章仅为棺中存在之感应，非其新行动。

# 王林昏迷漂流虚无 · 玄罗十五年守候终止 · 蚊王第五次蜕变

## 一、王林：三月坚持后昏迷，成为虚无中的残骸

- 每当手摸到身后的棺材，王林心中便爆发决心，推动他永不放弃。
- 但现实残酷，岁月流逝，**三个月后**王林最后一丝神智被磨灭，**昏迷**。
- 昏迷后体内再无任何气息传出，但他仍以身体护住身后的棺材；**棺材已充满裂缝**，若非他保护，早已崩溃瓦解。
- **关键转折**：王林昏迷的一瞬间，压迫他的**仙罡法则挤压骤然消散、不复存在**。这一诡异变化王林并不知晓。
- 此刻王林如同死人，**连三命术也失去作用**。他背着棺材在虚无中**改变了方向**，向另一位置漂去，如同他一路所见的一具具尸体残骸一样，成为虚无内永恒漂浮的残骸之一。
- 一年、两年、三年……不知过去多久，王林依旧闭目如死。

## 二、玄罗：七道宗外等了十五年，被迫返回道古一脉

- 地点：**仙罡大陆东洲黑山七道宗**雾气内。
- 玄罗长叹起身，**算上之前的时间已等了十五年**。
- 离开的原因不是不愿再等，而是远处传来一股**浩荡仙气**：尚未临近便引动天地轰鸣，天空幻化出一个**金色太阳**，其中站着一个高大身影；同一时刻另一方向也幻化出一个太阳，其内**道一**冷目凝望而来。
- 玄罗留言：「徒儿，你好自为之。若你没死，你应会来**道古一脉**寻我。」随后大袖一甩，**血阳滔天，化作一片血影**直奔天空而去。
- **后果**：七道宗外，从此再没有等王林到来之人。

## 三、岁月流逝：转世者与两个不凡孩童

- 又过数年，有些人已**转世投胎在仙罡大陆**；有些人还在迷茫的道路上，或许数百上千年才可转世而出。这时间差距之大，连玄罗也摸索不出原因。
- **西州凡间县城的男童**：某年诞生，很不寻常，六七岁与同伴玩耍时常自称「**王爷**」，不从者立刻拳脚相加，凶狠之状令玩伴害怕，众人渐渐都应着他玩「王爷」的游戏。
- **南州（仙族）的男童**：某年诞生，早年家破，**十岁已是所在城中很有名气的骗子**；因骗子有了名气便难以为继，遂早早离开家乡，带着行骗天赋不知去向。

## 四、被遗忘与被记得的名字

- 玄罗早已回到**道古一脉**，带着黯淡选择**闭关**。
- **道古皇尊**见玄罗一人回来，内心暗自冷笑；慢慢也不再去思索当年玄罗离开时要寻人回来的目的。
- 仙罡大陆与**洞府界**似乎都不再有人去想「王林」这个名字。
- 仍无法忘记王林的少数人：**木冰眉**、仙罡大陆的**唐姗**、以及在**归一宗**内渐渐如日中天、成为新一代骄子的**云逸封**。

## 五、蚊王：五次蜕变，化雾吞同伴，出发寻主

- 蚊王当年被王林阻止跟随，此后**发狂般带着九个同伴**在虚无中疯狂融合此处蕴含仙罡法则的气息。
- 数十年间**共蜕变四次**，每次蜕变强大数倍，仿佛它本就是法则所化；每蜕变一次，虚无的挤压对它便弱上不少，直至**不复存在**。
- **第五次蜕变**后：爆发出震动整个虚无的气息；身体不再如修真星一般，**彻底改变为一片烟丝雾气**——一片模糊，仿若水墨画上的蚊子走出，**不具备实体**，但凶煞达到巅峰。
- 随后蚊王**不再吸收仙罡无形法则**，身子轰然散开化作大量雾气，**将九个同伴吞噬融合为一体**，掀起无边无际的浓雾，向**虚无深处**急速飘去——**它要去寻找王林，寻找主人**。

## 六、时间线要点

1. 王林坚持三月 → 昏迷 → 仙罡法则挤压消散 → 背棺改向漂流（数年以上）。
2. 玄罗七道宗外累计等待十五年 → 仙气（金色太阳身影、道一）逼近 → 留言化血影离去 → 返道古一脉闭关。
3. 又数年：转世者陆续投生，西州「王爷」童、南州骗子童诞生。
4. 蚊王数十年四次蜕变 → 第五次蜕变化烟丝雾气 → 吞噬九同伴 → 奔赴虚无深处寻主。

## 七、悬念/伏笔

- 王林昏迷即压迫消失——挤压是否与「有神智/有抗争」相关，未解释。
- 玄罗指定的重逢地点：**道古一脉**。
- 两个不凡孩童（自称王爷者、名气骗子）疑为故人转世，身份未点明。
- 蚊王已脱离实体形态并统合九同伴，正向虚无深处寻找王林。
