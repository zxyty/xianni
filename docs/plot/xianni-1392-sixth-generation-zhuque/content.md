# 第九卷 云海之巅 第1392章 六代朱雀

## 一、刘金彪论骗道

失去玉佩、又被关入储物空间受许立国欺压的刘金彪，此刻衣衫依旧残破，气度却截然不同。他自陈「这就是老夫的道」——骗术的第二个境界：

- **第二境=骗自己**。骗自己一次容易，难在一辈子、无时无刻都在骗自己，直至影响元神、连记忆都被改变。
- **对抗搜神术**。达到第二境巅峰者，纵使神通再强的修士施展搜神术，也得不到真正的记忆——因为那记忆已完全崩溃。
- **两条出路**。第二境巅峰之人，要么无法自拔、成为另一个人；要么如涅槃重生、突破第二境而可随时清醒。后者极为罕见，也唯有此等人物才能触及**第三境「返璞归真」**。
- **止步之因**。刘金彪自承往昔依赖玉佩外物，致道心不坚、太过依赖外物，骗道因此止步；若非如此，「上仙想要抓我，也绝不会那么容易」。
- **祸福反转**。王林取走玉佩、毁其所依，反而给了他一次涅槃机会：在储物空间内，他的骗术达到第二境巅峰，**迈出了踏入第三境的半步**。

王林听后目光一闪，仅评「有点意思」。

## 二、许立国的问道与刘金彪的瞬间变脸

素来跋扈的许立国罕见地没有还口，反而抱拳沉声道：金彪子道友这番言论令他茅塞顿开——「三千大道中，可有骗道」，他也想知道自己所追寻的道是否亦在三千大道之中。

刘金彪闻言大喜，孤傲冷峻瞬间崩溃，弯腰赔笑、面带残余恐惧地巴结：「小小骗术，不值挂齿，许大爷以后莫要再欺负小的。」变脸之快令许立国再次发愣，只能低声咒骂。

## 三、王林的交易：骗一族

王林开出条件：

| 项 | 内容 |
|---|---|
| 报酬 | 事成之后**放其自由**，另**送一场造化** |
| 任务 | 从「骗一人或一宗」升级为**「骗一族」** |
| 期限 | 给三个月准备时间 |
| 助力 | 王林亲自「送你一场记忆」 |

刘金彪只提出布局须详细准备，并未拒绝。王林左目蓝色火焰骤然宣泄，化作炎浪将其卷入，形成不断外扩的巨大火球。许立国骇然后退，暗惊「这煞星修为，竟然又高了」。

## 四、一月炼成·六代朱雀出世

此后一个月，许立国数次试图离开洞府均被禁制弹回，只能望外发呆。

某日，燃烧一月的蓝色火球轰鸣爆开：火海冲天化作**巨大朱雀**，发出朱雀之鸣；火球内一道身影由模糊而清晰，一步步走出。

- 相貌仍是刘金彪的相貌，气质却天地之差——如一代宗师、大神通修士，无形威压扑面。
- 火焰环绕其身，化作朱雀之形；双目冷漠如炬，一扫之下令许立国倒吸凉气。
- **修为飘忽不定**，时而绝强、时而寻常，更添神秘。
- 眼底透出「存活了无数万年、看透人生」的沧桑与生命疲惫。

他缓缓自陈身份：

> 「老夫，朱雀圣宗六代朱雀。寻四代朱雀来太古星辰，因被阵法所创，此刻重伤未愈。」

此刻的他**早已忘记自己曾是骗子**，全部记忆已然改变，他真心相信自己就是朱雀圣宗之主、就是六代朱雀。即便大神通修士对其施展**搜魂术**，也找不出任何破绽——所得记忆全部「真实」。

火球内传出王林之令：「许立国，伺候在六代朱雀身边，听其一切号令，若有违反，上天入地，抹去存在。」许立国身子一颤连忙称是，随刘金彪走出洞府，禁制自动开启放二人远去。

**伏笔**：除刘金彪外，无人知晓这一个月内王林在他身上留下了什么。

## 五、第二个诱饵：火雀族

二人离去后，火海尽数收回王林左目。王林盘膝静坐，眼中睿智之芒一闪：

> 「第二个诱饵，也放出了。火雀族，你们可不要让我失望。」

## 六、贪狼遗产与两个坐标

王林翻手取出储物空间，飞出一尊得自**贪狼**的雕像。他的判断与规划：

- 贪狼送来的法宝甚多，需逐一留下**神识烙印**摸清威力，方能在日后之战中发挥最强之效。
- 这雕像显然是贪狼**最强大的法宝**——否则不会最后才拿出。
- 他曾搜寻贪狼记忆，确认其所说大都为真；并从中得知**两个点**：
  1. **罗天星域**内，接近**闪界壁垒**之处，出现**漩涡**的地方；
  2. **太古星辰**上，贪狼从那神秘**古墓**内走出之处。
- 王林认为两点皆对己有用，太古星辰那点需去探寻；并推测贪狼去过的古墓「很有可能，就是那传说中的**古之坟墓**」。
- 王林亦注意到：并非人人都能如刘金彪般在骗道上达到第二境、改变心神记忆——**最起码贪狼不能**（故其记忆可信）。

## 七、银衣女子的尖叫

面对「这雕像到底是谁、为何会出现在疑似古之坟墓之处」的疑问，王林百思不解。正欲以神识触碰雕像时，忽然目露精光——「或许，她会认识也说不定」。

他抬手挥出**第二道空间裂缝**——此裂缝是他当初单独开辟、只为一人准备。银光如月弥漫洞府，一名美丽至极、赤足的**银衣女子**（已苏醒部分记忆）自裂缝中走出。

王林沉声问：「你，可认识他？」

银衣女子挽发看向雕像，刹那间瞳孔猛缩、瞬息呆滞，随即**凄厉尖叫**起来。（章末悬念）

## 八、关键伏笔汇总

1. 刘金彪身上被王林留下的未知手段。
2. 「第二个诱饵」意味着此前已有第一个诱饵，两者共同指向针对火雀族的布局。
3. 太古星辰古墓＝疑似「古之坟墓」，与罗天星域闪界壁垒处漩涡并列为两个待探坐标。
4. 雕像身份成谜，银衣女子显然与之有极深渊源。

# 第1393、1394章 又是七彩

## 一、雕像引发的崩溃

- 王林向银衣女子出示一尊雕像，欲探明雕像之人身份。
- 银衣女子一见雕像即发出尖锐刺耳、蕴含极大恐惧的尖叫——即便她记忆尚未恢复，恐惧仍是本能反应，暗示雕像之人曾给予她莫大伤害。
- 王林瞳孔一缩，立即挥手收起雕像；女子已退至洞府尽头，面色煞白、浑身剧颤，厉声嘶喊「不要过来」，眼中是对天地一切生灵的不信任，连王林也无法取信。
- 王林心生悔意，低声道歉「对不起」，随后上前蹲下轻抚其发安慰：「不要怕，都已经过去了……既然已经忘记，就让它遗忘好了。」

## 二、破碎的记忆碎片（关键线索）

女子在恐惧中吐露的断续信息：

- 「门不是我打开的……真的不是我」——反复强调，是其恐惧核心。
- 「桃云死了……紫落也死了……都死了」——两个此前未出现的名字，疑为其昔日同伴。
- 「他认定了是我们打开的门……都死了，我也死了」——存在一个施加惩罚的「他」，很可能即雕像所刻之人。
- 王林追问「他，是谁」，成为触发下一阶段异变的导火索。

## 三、青气异变与交手

1. **印记浮现**：女子体内滋生剧痛，面部青气皮下游走，刹那形成诡异印记，占满容貌，美人化作罗刹；恐惧与迷茫尽数消散，只剩无情感的冷漠死寂。
2. **一掌撼星**：女子抬手按向王林。此掌不引动任何天地元力，却令整个修真星轰然一震，朗朗乾坤瞬间被墨色污染，天空全黑，遮蔽阳光、阻隔天地。
3. **异常裂缝**：黑暗天空中响起比雷霆更强的声音，天空被生生撕裂出巨大裂缝。此裂缝与寻常空间裂缝完全不同，其深处一切天地星空都无法蔓延，仿佛通往星域最底层的神秘空间。
4. **青气穿禁**：青气自裂缝呼啸而出直冲洞府，洞府禁制毫无阻挡之力被直接穿透，青气环绕女子右掌，凝成青色掌印追击王林。
5. **王林三段应对**：
   - 元力汇成巨大漩涡相撞 → 漩涡崩溃，掌印丝毫无损，穿透而来；王林借冲击退出洞府。
   - 右目雷霆闪烁，自右眼瞳孔幻化出巨大雷图，九道伴随之雷环绕，发出万丈雷霆 → 雷图倒卷，掌印上青气消散大半，仍追击而来。
   - 虚空一抓引出血光剑，狠狠一斩，血色剑芒劈开掌印一分为二 → 掌印崩溃。
6. **擒下青气**：掌印内青气未散，凝聚成球欲飞回天空裂缝。王林飞起，抬手化出巨大虚幻手掌，喝「给我下来」，将青气抓在手中；裂缝随即收拢消失，天光恢复。此时王林嗓中涌血（受创），强行忍住。

## 四、事后处置与推断

- 银衣女子昏倒在地，面色死灰、无意识颤抖，口中仍喃喃「不是我……不是我打开的门」。
- 王林以左手掐诀化作无数禁制，一一落在女子身上（封禁/保护）。
- 对青气的判定：**不是**灵力、不是仙力、不是天地元力、不是古魔之气、不是古妖之气、不是古神之力、不是香火之力、不是本源——**但与本源极其相似**，属天地元力之外的另一种力量。
- 身份猜测：王林怀疑银衣女子是「远古八妃」之一，但猜测不透。
- 对「香火有毒」的重新解读：此前王林判断她是修香火而后被香火所害；此刻则怀疑她在**尚未修香火之前**便已知晓香火有毒，事情远非那么简单。

## 五、章末动作

王林抬手按向女子天灵，施展了始终未在她身上用过的**搜神术**，并自陈：「你我无仇，我也无意伤你，但你知晓的隐秘，对我有大用，以我的修为，施展搜神术，谨慎之下可不伤你心神。」随即闭目，神识顺右手进入女子天灵。

## 六、悬念清单

- 雕像所刻之人是谁？是否即女子口中的「他」？
- 「门」是什么门？为何打开门是死罪？
- 桃云、紫落是谁，与银衣女子是何关系？
- 星域最底层的神秘空间与青气的本质是什么？
- 银衣女子是否为远古八妃之一？其面部青气印记是封印还是操控手段？
