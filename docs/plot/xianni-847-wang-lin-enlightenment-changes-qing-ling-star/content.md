# 仙逆 第847章 改变（第七卷 名震罗天）

## 一、悟道内容：河、网与「我即因果」

王林在梦道之中悟道，其明悟以「鱼—河—网」为喻：

- **河即天地**：鱼儿在河中生存，不违天地、不惹阴阳，安详自在；万物如鱼，存于天地之中。
- **网即道**：网是天地横生而出的**规则**，不管你存在天地何处，最终都逃不出这道。
- **两条路**：失去河水的鱼儿，在大道之下要么顺从入轮回，要么反抗破网。
- **修士即挣扎的鱼**：修道者就如鱼儿的挣扎，**挣扎越剧烈，便越是逆道**（点题「仙逆」）。

结论：

> 「这天地之道，人人皆可证，人人皆可成道。天，不是道；道，是天地之念所化，这念，每一个人都可拥有。」
>
> 「生死轮回也好，因果之境也罢，全部都是道念所化。**我，就是因果**。」

悟道之风狂卷天际而散，融入整个青灵星。

## 二、青灵星剧变：从「废星」到灵星

王林在梦道中与青灵星**融为一体**——他便是此星，此星就是他。故其悟道无形中引发全星随之「悟道」：

| 变化对象 | 变化 |
| --- | --- |
| 全星灵力 | 瞬间扩大无数倍 |
| 大地灵脉 | 条条轰动，喷出无尽灵气 |
| 河流 | 融入灵力，化作碧青之波 |
| 山峰 | 内部渐结灵石，凡山成灵山 |
| 横云山（悟道之巅） | 自山脚起寸寸改变，成为灵气浓郁到无法想象的真正灵山 |

**关键设定**：青灵星并非表面看去的「废弃」，而是一颗**幼星**；若给它时间，无数年后灵脉自可酝化而出，成为真正的灵气星。王林的悟道使此星提前**大成**，加快成长。

## 三、星魂：万物有灵皆可明道

王林借融入青灵之机，第一次如此接近、清晰地感受到**青灵星之魂**：

- 星魂是**虚幻之物**，却真实存在；
- **没有念头**，只有一团**本能的力量**；
- 其来源 = 无数年来所有修士吐纳 + 所有凡人生生死死所化 + 一切生灵种种念头所酝酿。

王林由此推演：「人有灵，故可明道；兽有神，也可悟道；这天地万物，凡是有灵神之物，全部都可以明悟天道。此星有魂，同样可以明悟。」

并回忆起旧闻：**「当年散魔可抽星魂之力，眼下，如是我想，则能。」**（伏笔：王林已具备抽取星魂之力的条件）

## 四、连锁影响：青灵星化神之禁被破

- 全星灵气疯狂浓郁，各修道门派中闭关冲击元婴、试图达到化神的无数修士，体内灵气如风暴般旋转。
- 那些**常年困于元婴、始终无法踏出一步**的修士，在王林明悟的一刻得到天大好处；其中本就半只脚徘徊者立刻**顿悟**，各自拥有意境，**成就化神**。
- 王林由此打破了青灵星**无数年来无人化神**的限制。
- 无数凡人在惊天雷鸣中膜拜，无数修士心神剧震、朝拜而落。

## 五、苏醒与自省

全星四面八方的虚无力量疯狂凝聚，最终尽数涌向横云山山顶、融入王林肉身，**王林苏醒**。

苏醒后的异状：

- 眼中不亮却有日月乾坤；神色不喜却有天威缭绕；面色苍白却蕴含明荧。
- 透出「明悟自身之道、全身琐念豁达」之意。
- **肉身在、元神在**，但若有修士前来闭目探查，却察觉不到半点王林的存在。
- 与以往「融入天地是肉身真正消失」不同，此次肉身元神俱在却有融入天地之感：**心之所动便没有距离，神念之处尽是因果**。

王林的警觉与杀机：

> 「天道无痕，我却是无意中陷入了自身的因果之内。若非明悟，怕是此生再无苏醒之日。此事透出一股诡异，仿若无声无息间便有众多念头涌入心中，取代我的神智，使得我按照某种念头所化。」

他抬头盯着天空，眼中寒光与杀机毕露。此刻青灵星上**每一个凡人、每一个修士、每一个草木生灵**的无穷之力疯狂向他凝聚、涌入体内，顺着他的目光轰隆冲出，直迎天空——若把青灵星天地比作河水，其上所有生灵便是一条条挣扎的鱼儿，融入王林之身，形成一股**反抗，破天而去**。

## 六、旁观者

- **谢姓老者**（凡人）：身体涌现丝丝暖意，怔在原地，喃喃「他是人，是鬼」；后灵魂颤动、仿若升华，心中浮现明悟「**他不是鬼物**」，沉默间毅然走出。
- **蓑衣老翁**：留在河道旁，一脸惊恐。

## 七、伏笔与看点

1. 「我，就是因果」——王林道之根基定型，为后续因果类神通张本。
2. 「散魔可抽星魂之力，如是我想，则能」——抽取星魂之力的能力伏笔。
3. 「有众多念头涌入心中、取代我的神智」——王林陷入自身因果的诡异经历，指向尚未揭明的幕后。
4. 谢姓老者受悟道波及而升华并「毅然走出」——凡人线伏笔。
