# 第1946章 天运子的气息！（第三更）

## 一、老者的追查：被抹去的因果

- 东临宗一向与世无争、门规森严，弟子极少外出，谈不上与人结仇；老者本人在仙族大陆交友甚多、一心修道，家门却仍遭灭门。
- 老者遍访**五大天尊**与**皇城国师**求推衍东临宗因果，全部无果。
- 唯一异常：国师推衍中**喷出一口鲜血**，神色露出恐惧（刹那消散），继而**迷茫三天**；三天后清醒，却忘记了此前推衍出的结果——似有一股无形力量抹去了他这几天的记忆。
- 老者研究不透那石碑，但**字迹已印在灵魂中**，是他找到凶手的唯一线索。

## 二、腐朽之风：东临宗的真相

老者右手向外一挥，一股腐朽死亡气息弥漫大殿并横扫全宗：

| 幻象 | 真相 |
|---|---|
| 辉煌大殿、三尊雕像 | 处处灰尘、柱子开裂、雕像残破、地面裂缝如废墟 |
| 宫殿阁楼、青山绿水、鸟语花香 | 广场碎裂、青山成死山、绿水干枯发出恶臭 |
| 众多门人弟子（含两名**金尊**修士） | 全部消失不复存在，遍地骷髅骸骨 |

- **刘金彪**在大殿外目睹全过程，瞳孔收缩、愣在原地——他终于明白自己先前那种奇异感觉的来源：身旁就倒着一具骸骨，空洞的骷髅双目似望着他、也似望着苍天。

## 三、石碑与血字

腐朽之风扫过后，东临殿外广场上**凭空屹立一座高不下百丈的巨大石碑**，其上一行血字：

> **“锁亡天之运，印冥朝，众生之所不能得真道者，常沉苦海，永失真道，奉至修真行”**

- 血字早已干枯成**暗褐色**；石碑扩散出说不出的恐怖气息，笼罩东临宗，天空化作幽暗——似有一只大手遮盖了天的双眼，令**苍天无眼**。

## 四、王林的震动：天运子的气息

- 王林转身望碑，脑海轰鸣：**这样的石碑，他在洞府界的七彩界见过**。此前他一直以为七彩界石碑是**掌尊**所弄，如今看来“完全不同，绝非如此”。
- 更大的震动来自字迹：**字迹可以模仿，字迹上的气息却绝难模仿**。王林辨出这气息属于**天运子**——他在洞府界这一生极为忌惮之人，是**天道的一部分**，已被王林毁灭，但王林当年便怀疑天运子没死。
- 王林连串自问：
  1. 谁毁去东临宗、留下这座石碑？
  2. 字迹与气息属于天运子，他为何会来到仙罡大陆、又为何毁去东临宗？
  3. 洞府界、仙罡大陆、东临宗三地唯一的联系者是**七彩仙尊**——但其分化三魂已被王林毁灭，第三魂便是**苏道**，王林当年还曾在幻境中来到过东临宗。他真的死了么？
  4. 洞府界绝非那么简单，其内到底还藏着什么秘密？
- 王林的自省（本章核心意象）：**“我站在了山上，以为看到了全世界，但却不知，在那山后的天空上，还有一双眼睛，看到了我的全世界。”** 通体冰冷。

## 五、老者的托付

- 老者请求：**“若你此生，见到同样的字迹与气息，请告诉我。”**
- 承诺：**“若我能复仇，从此了牵挂，为我提供线索者，老夫可为奴直至死亡。”**
- 王林平静应下：**“我会的。”**（心中惊涛骇浪不露分毫）
- 老者再一挥手，清风一扫，一切复原：大殿如初、青山依旧、绿水仍澈、鸟语花香，弟子一一幻化，**永不知他们已经死亡**，在昂然生机中“快乐地生活”；广场石碑与骸骨尽数消失。刘金彪呆望石碑原处，看向东临宗弟子时恐惧感更强：“这到底是什么鬼地方？”

## 六、东临池秘辛

王林说明来意：**想借东临池一用**。老者沉默片刻，点头应允，并道出内情：

### 来历
- 东临池内有**异水**，池水与大地连接，与封印在**大圣洲**下的**天外之灵**有关。
- 那被封印者**并非兽，而是一名天外修士**：当年败在**仙祖**手中，被封印于此，如今早已死亡；但其**魂散后没有消失，与地脉河流融合**，东临池正是该河流的一处流动之地。

### 规矩
- **一生只能进入两次；第三次进入立刻暴毙而亡。**
- 东临宗拥有此池，外人知晓不多；凡知晓者来宗后**给予足够代价，即被允许进入**。

### 辟谣与真正效用
- 传言“入池可凝聚**本源真身**”——老者明言**此事虚假**：若属实，东临宗早成仙族第一宗，且也守护不住此池，会被大天尊收走。
- 即便如此仍会引起大天尊关注，只因三点未被抢夺：①看在初代老祖**东临大天尊**的份上；②此池**不能移开**；③其效**随岁月流逝越来越弱**。
- **真正作用**：让进入者达到一种**奇异状态**，在该状态下**有一定机会感悟出那天外修士具备的特殊本源**；若失败，则只能让自身**本源更浓一些**。

## 七、东临大天尊（王林首次听闻）

- 仙族**五大天尊并非永恒，也有陨落**。
- 东临宗**第一代老祖**曾为大天尊（东临大天尊），已陨落，**尸体不知所在**。
- 很多人在找老祖尸体，连后来出现的几位大天尊也在找，无人找到。
- **传言**：若能找到老祖尸体，便有可能**不必进入太古神境的考验**，也可成为大天尊（仅为传闻）。
- 王林深吸口气：没想到东临宗竟有这般底蕴，更没想到此宗曾出过一位大天尊。

## 八、悬念清单

- 天运子是否真死？其气息为何出现在仙罡大陆的东临宗石碑上？
- 洞府界七彩界石碑与东临宗石碑同源，掌尊此前的“作者”身份被推翻——真正的书写者是谁？
- 七彩仙尊三魂（含苏道）被毁后是否仍存？
- 东临大天尊尸体何在？找到即可绕过太古神境考验成为大天尊的传闻真伪。
- 王林能否借东临池感悟天外修士的特殊本源。
