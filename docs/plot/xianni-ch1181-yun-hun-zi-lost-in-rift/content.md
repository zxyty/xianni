# 第1181章 血魂子丢了（第三更）

## 一、王林的战前判断

此行七彩裂缝王林另有图谋，势必与苍松子摩擦。他一路暗中观察，把队伍关系摸清：

| 人物 | 与苍松子关系 | 王林评断 |
|---|---|---|
| 云魂子 | 莫逆 | 一路隐隐监视王林，对其不善 |
| 庞姓老者 | 莫逆 | 三次来此地的老人 |
| 端木姓童子 | 相互利用 | 心狠手辣，另有图谋 |
| 役兽宗 陈天军 | 不甚亲密 | 有所图谋 |
| 青衫老妪 | 不明 | 眉头微皱，心思不明 |

结论：苍松子敢从容邀众人同行，是因有云魂子在，二人联手加庞姓老者在队中已然无敌。**毁掉云魂子＝断苍松子一臂**。王林决定绝不给对方联手机会，要先行出手，而踏入裂缝之际正是最好良机。他自评一个碎涅中期尚可一斗，两个亦无妨，只要对方与苍松子并非极为交好。

## 二、裂缝口偷袭战（关键手法）

1. **铁剑一斩**：回头抬起铁剑向下狠斩，次空涅法宝之威，滔天剑气直奔云魂子。
2. **云魂子两道防御**：先以体外魂火迎击 → 魂火瞬间崩溃、无法阻挡剑芒；再咬破舌尖喷精血化作红雾骷髅头，一口吞噬剑芒。云魂子身颤面白但未重伤（毕竟碎涅中期），反冲之力使王林后退数步、元神震动，眼看要没入裂缝。
3. **云魂子反扑**：低吼冲来，半只脚踏入裂缝，抬右手欲施神通。
4. **仙术定身**：王林在完全踏入裂缝的一刹那，体内仙力疯狂运转化作仙术『定身』，无形丝线笼罩云魂子，令其身形骤然一顿。以碎涅中期修为片刻即可震碎，但已然不及。
5. **补刀两击**：剑光直奔头颅（被避开）→ 斩落其**右臂**；同时右手握拳蕴含**古神之力**轰出，虽被神通阻挡，却令云魂子入裂缝的身子**大范围倾斜**。

### 制胜原理
王林多次穿梭空间裂缝，断定两界之裂缝皆同理：**在近乎传送的穿梭中绝不能胡乱改变位置，否则穿过裂缝的刹那会被传送去其他位置**；且七彩裂缝本身并不稳定。故其目的**不是**冒险斩杀一名碎涅中期，而是在受伤前提下**改变云魂子的方位**。

代价：定身术反噬，王林元神剧烈震荡，被强行压住。

## 三、七彩世界初见

- 天空闪烁七彩之芒，笼罩之下大地景物亦一片七彩。
- 世界并非清晰，多处雾气弥漫，只有不多几处无雾。
- 众人落点：一处样似**祭坛**之地，仅百丈大小。
- 王林扫视四周，确认**云魂子不在其中——赌赢了**。他自知方才极为凶险，若让云魂子神通出手，绝不会如此快捷。

各人反应：
- **庞姓老者**：感慨追忆。此为第三次来此，第一次身边众多老友全部死亡，第二次又死一部分，如今连自己在内只剩三人。
- **端木童子**：望雾舔唇，喃喃『那雾气并非星雾』。
- **陈天军（役兽宗）**：神色极为激动，深吸几口气，目露奇异之芒，后又对雾气露出狂热。
- **青衫老妪**：眉头略皱，心思不明。

## 四、当面对质

- 苍松子：『吕道友，云魂子呢？』——好心情尽消，隐起阴云。
- 王林（以吕子浩身份）：『吕某怎知他去了哪里』『外界有无意外在下不知，但我踏入这裂缝前，没有看到意外出现。』
- 庞姓老者：指出云魂子与王林距离不远，断没有道理你进来了他却失踪。
- 王林冷笑反威胁：『庞道友言辞慎重，话若乱口，恐有杀身之祸』——庞姓老者心神一震，**想起吴青之死**，暗悔多口，转看苍松子。
- 王林怒极而笑，摊牌：云魂子修为碎涅中期，吕某根本不是他的对手；他有腿有脑想去何处莫非要向吕某汇报？『你若想找个引子与吕某一战，吕某奉陪到底』。
- **端木童子**出言相帮：吕道友的话很有道理，或许人家不愿进来，或另去了此地其他位置。
- **苍松子的内心推演**：以云魂子修为，除非此姓吕之人隐匿了极高修为，否则不可能在如此短时间内被斩杀 → 否定被杀之说；又想到云魂子与自己一样极了解此地、已进入过两次，『莫非云魂子知晓另外的通道，以特殊方法改变方向传送走？』但也可能是斗法致其穿裂缝瞬间被传送去别处——若如此，为何这姓吕的却安然无恙？无法确定，只得压下。
- 收场：苍松子抱拳『此事是老夫鲁莽了，吕道友莫要介意』。王林冷哼，略一抱拳，不发一言。

## 五、云魂子的下落（伏笔）

七彩之芒笼罩的空间**至深之处**，一片雾气环绕的**山谷**中：云魂子面色苍白盘膝而坐，紧张四顾，右臂已不再流血，神色隐露恐惧——『该死的，居然传送到了这里！』他极为忌惮地望向山谷口的浓浓雾气，雾内隐隐传出**一声声嘶吼与阵阵腥风**。

## 关键伏笔
- 雾气并非星雾，是何物未明；陈天军对雾气的狂热暗示其另有所求。
- 七彩世界有『另外的通道』之说（苍松子推测）。
- 谷口雾中的嘶吼腥风生物，将威胁重伤断臂的云魂子。
- 王林与苍松子表面缓和，实则梁子已深。
