# 仙逆 第九卷 云海之巅 第1375章 初遇火雀

## 一、行程：暗蝎族 → 龙甲族主星

- 暗蝎族老者（称王林为“主人”）建议前往距离最近的落生会长老修真星——**第九长老龙甲族主星**，理由是“修士众多，且较为混乱”。
- 二人化作长虹跨越星空，数个时辰即至。王林一路少言，心神仍萦绕于此前**傀儡**的画面，似有思绪却隔着一层迷雾。
- 途中王林问及**炎火之晶（炎火异晶）**是否有售，老者答：有，但**火雀族**不惜代价搜集，旁人难与之争；且购买此物或傀儡，须去**龙甲族组成的坊市**。

## 二、龙甲族情报（暗蝎族老者口述）

- 龙甲族虽为小族，但**族人数千**。
- 族长即**落生会第九长老**，修为**天人第四衰**，施展**族印·龙甲神通**后寻常修士无法破其防护。
- 该长老在落生会中声名赫赫，暗蝎族这样的族落“不敢有半分不敬与招惹”。

## 三、迎接：礼遇与疑心

- 龙甲族主星为一颗**青色修真星**，生机蓬勃、灵力浓郁，远超暗蝎族修真星。
- 三道剑光出迎，为首**青衫老者**称“长老算出暗蝎族族长近日会来”，故在此等候。
- 暗蝎族是**三百七十二个族落之一**，虽非长老族，亦不可怠慢。
- 关键细节：暗蝎族族长**让王林先行、自己跟随在后**，令龙甲族三人惊奇，青衫老者暗中留意——“能让蝎族族长如此客气，此人绝不能小看”。

## 四、转折：司墨子现身

- 将入**罡风层**时，王林心神一动回头：星空波纹扭曲中走出一**中年男子**，对其露出阴森微笑。
- 王林认出：此人正是当初他**刚进入太古星辰**时，在**拓森**被追击的一瞥中所见的**三名大能之一**。
- 王林的判断：
  - 此人**绝非颠落之地族人，而是来自太古星辰**；
  - **身为第三步大能**，此时进入这里，目的即为杀他；
  - 所展露仅**天人第五衰**气息，故“应非本体”，或为**隐藏修为**，或**仅是分身前来**；
  - 对方**对颠落之地极为忌惮**，否则方才即已出手；
  - “长尊会追击的很快”。
- 王林眼中露出战意，冷笑穿过罡风层入星。

## 五、司墨子一方视角

- 该中年男子名**司墨子**。其“欲索之人”（王林）的**样貌与气息早被云落大司算出**并传到他手上，一眼便认出身份。
- 顾忌：此地动手会引起波折，**若把颠落大帝引出更为不妙**；打算“寻个恰当的理由，就可将其擒住”。
- 随后**龙甲族第九长老**（蓝袍、白发苍苍，天人第四衰）接其神念传音后出关相迎，笑称“当年若非司墨子前辈提点，老夫怕是早就**三衰而亡**”，请其去洞府。二人谈笑而去。

## 六、王林改变计划

- 原计划：收购**高阶傀儡**再作研究；若遇**炎火异晶**则购买一些。
  - 炎火异晶对其**朱雀第四变**有推进作用，大量吸收好处很多；
  - 且此物与其**获取火雀族本源**有关联。
- 见司墨子后改主意：**不逃遁，要在此地一战**。
  - 推断对方有顾忌是好事；
  - “若真是分身，追杀于我，我必让他分身灭亡，以儆效尤”；
  - 自评**雷之本源大成**，但天人第五衰不可小觑，战前仍需多作准备。
- 王林一把抓住暗蝎族老者提速直下东部城池，沉声令其带路；老者感其杀机，心神一颤。

## 七、东部坊市阁楼：初遇火雀

- 目的地为该星**东部大城**中一处古朴高耸阁楼，属**龙甲族直属店铺**。
- 接待者：**约三旬、风韵犹存的妩媚女子**，香风扑面，认得暗蝎族族长（称其“数月前才刚来过”）。其目光扫过王林时**闪过一丝惊讶**；见暗蝎族老者立于王林身后不坐，眼中**再度露出隐藏极深的奇异之光**。
- 王林上二楼落座，开口只两字：“**炎火异晶**”，目光却已移向二楼入口，眼中精光一闪。
- 话音方落，入口传来冰冷之声：“老夫也要炎火异晶”。
  - 来者**身穿火红之袍、白发散乱**，体内仿若蕴含火海，所过之处阁楼弥漫高温；
  - 脚踏楼梯**留下火焰脚印**，火焰凭空燃烧却不伤楼梯，渐渐消散；
  - **眉心有一栩栩如生的火焰印记**（火雀族标志）。
- 其与王林对视，索要炎火异晶。**王林，笑了。**（章末悬念，下接第1376、1377章《可敢一战！》）

## 八、悬置线索

- 傀儡画面的“隔雾之思”尚未明朗，王林仍欲购高阶傀儡研究。
- 司墨子欲寻“两全的理由”擒杀王林 —— 与龙甲族第九长老的旧交，正是可用的“理由”渠道。
- 火雀族对炎火异晶的垄断性搜集，与王林“获取火雀族本源”的目的直接冲突。

# 第1288章 天人第三衰与龙甲族三宝

## 一、设定铺垫：天人第三衰的地位

- 无论界内界外、无论族落还是宗派，**天人第三衰**修为足以成为强者，罕有人敢招惹，身份极为高贵，享有莫大权利。
- 界内标尺：云海八阶宗派若有天人第三衰者，足以成为巅峰之人；即便九阶宗派内，天人第三衰者也并不多。
- 总体格局：**界内实力远远不如界外**。
- 火雀族身为**太古星辰大族**，有资格派出一名天人第三衰族人，出任**颠落之地分族首领**——即眼前这位老者。

## 二、阁楼二层的对峙

### 王林的先手
- 早在进入阁楼之前，王林已察觉楼内有火雀族族人气息，对老者现身毫不意外；在颠落之地见到火雀族，他脸上反而露出微笑（暗示旧怨/图谋）。
- 老者踏上二楼后随意落座，目光如炬打量王林，实则心中极为警惕，原因有二：
  1. 王林身后的**暗蝎族族长**他认识，深知其修为，而这等人物在这青年面前竟无坐下资格，如仆从般侍立；
  2. **他看不透王林修为**——神识散开也感受不到半点气息，更看不出族落。（太古星辰之人族印未必在眉心，部分大神通者可隐藏族印。）

### 冷哼与目光两击
- 老者开口欲索要炎火异晶，自称「老夫」，话未说完，王林一声**冷哼**：如百万雷霆在二层炸开，化风暴横扫。
  - 妩媚女子面色骤变、退后数步、神色苍白。
  - 老者如被百万斤马车撞击，元神颤抖、瞳孔剧缩、喷出鲜血，全身火焰之力失控爆发，座椅焚为灰烬。
- 王林右手一挥，**无形之风**呼啸而至，将散开的火焰压熄，部分生生拍回老者体内。老者连退三步，每一步都在地面留下漆黑冒白烟的深深脚印。
- 老者运火想止住退势时，王林目光与之相撞：**目光化作无形利剑**，破开双目直入元神，其元力全然无法阻挡；利剑绕元神一转后渐渐消散——**未穿透，为示警**。对老者而言却是生死顷刻徘徊的噩梦。
- 王林收目冷道：「**在我面前，也敢自称老夫**」
- 老者全身被汗水打湿，改口自称「晚辈」，恭恭敬敬站立，不敢再寻座椅——似乎在这青年面前无人有资格坐下。妩媚女子看王林的眼神转为恭敬与深深敬畏。

## 三、炎火异晶交易

1. 王林令女子取出所有炎火异晶。女子捏碎一枚玉简，青光玉简没入墙壁，墙壁蠕动、泛起波纹后变得透明，内部五光十色中**三块拳头大小白色石块**缓缓旋转。
2. 女子说明：龙甲族内允许卖出的炎火异晶不多，眼下唯有这三块；且**火雀族老者（何道友）先来**，正为换取这三块而来，故她为难。
3. 火雀族老者暗叹，抱拳让步：「前辈既喜，晚辈怎敢争夺。」
4. 王林一眼看穿：墙内并无实物，只是**以神通之术折射而出供人观看**。
5. 王林取出**三粒丹药**，其内火焰之力环绕，形如火球——女子接过验看后失声：「这是**顶阶火兽之魂做成的魂丹**」，并确认换取三块炎火异晶**足够**。

### 火之本源的伏笔
- 老者借口请看丹药，王林闭目不理，女子递予一枚。
- 老者神识融入丹药，身子猛震：**丹药内蕴含一丝「火之本源」**。
  - 内心判断：此丹对旁人或许作用不大，但**对火雀族有难以想象的作用**；疑问在于「这本源到底来自何处」。
- 王林睁眼扫了老者一眼，**嘴角露出不可察觉的冷笑**——显然此局在其算中。

## 四、龙甲族少族现身与「三宝」

- 女子携丹药下楼，片刻后引一名**紫发、道袍、不怒自威的中年男子**上楼，态度恭敬。
- 暗蝎族族长弯腰低声提醒王林：此人是**龙甲族少族**，身份高贵，很少来此，反常。
- 少族对火雀族老者看都不看，直接向王林抱拳：「前辈丹药我龙甲族要了」，取出三块白色石块交予王林。
- 少族追问王林还有多少此类丹药、想换何物。王林答：「丹药不少，就是不知你能拿出什么来换。」
- 少族介绍筹码：**傀儡与炎晶在任何一个长老主星都可换到**，但龙甲族有**三宝**，别处没有：
  - **第一宝·龙甲鳞**：龙鳞，**三千九百八十二片为一套**，其上附有龙甲族族人血液；配合神通施展后可使防护倍增，寻常法宝无法破开半点，即便神通也可阻挡一些。
  - **第二宝·白骨龙**：由龙甲族**历代死去族人骸骨炼化**，数量不多；每一只都拥有惊天动地之力，且因本已死亡，故**永生不灭**。
  - **第三宝**：本片段未揭晓，王林笑问「那第三宝呢」，片段止于此。

## 五、要点与伏笔

- 王林战力与身份的侧写：一声冷哼重创天人第三衰、目光可入敌元神；随身有暗蝎族族长执仆礼；修为与族印皆无法被窥破。
- 交易杠杆：王林握有可批量拿出的**火本源魂丹**，正是火雀族的命门；老者的失态与少族的破例登场，均由此而来。
- 待续线索：火之本源的来源、火雀族老者后续动作、龙甲族第三宝为何物、王林收购炎火异晶的真实用途。
