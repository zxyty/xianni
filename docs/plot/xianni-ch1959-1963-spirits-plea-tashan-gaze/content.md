# 第2048章 一百零八灵的哀求！

## 一、王林：踏上第二座桥

- 第一座桥与第二座桥**看似很近**，实则王林一直飞出**数日**方至第二座桥下。
- 第二座桥**比第一座庞大数倍以上**。王林毫不犹豫一步迈上，脚步落下的瞬间**灵魂之体轰鸣、好似要崩溃**，仿佛以他此刻修为，尚**不够资格**踏上此桥。
- 轰鸣中王林脑海似被炸开，天旋地转间**神识与灵魂似被分离**。

> 时点：此章事发生于王林**闭关冲击空劫之后那传说中的境界**的过程中。

## 二、俯瞰所见：仙罡大陆的全貌与九柱之门

王林于雾气深处看到一片极熟悉的大陆（仙罡大陆），其格局为：

| 方位 | 内容 |
| --- | --- |
| 左侧 | 七十二洲 |
| 右侧 | 三十六郡 |
| 中间 | 苍茫盆地间，一个**竖起的海洋**在疯狂旋转 |
| 海洋深处 | **九个巨大柱子**连接成**一个门的形状**，门**紧闭未开** |

- 王林自问：“**踏天……我如今，是否就是在踏天**？”此刻他感受不到自己的存在。

## 三、七十二洲化凶兽：恐惧之外的哀求

- 王林看向仙族方向，**整个仙族七十二洲忽然化作七十二尊狰狞凶兽**，向天空咆哮。
- 其内可辨者：**天牛**、**绿魔蝎**，以及更多他**曾在天尊涅内见过的天外凶兽**。
- 凶兽似发觉了王林的存在与目光，嘶吼间王林清晰感到它们**在恐惧**——但恐惧中**还含有其他含义**（下文揭示为哀求）。

## 四、仙罡大陆同步剧变

1. **地动**：仙族大地七十二洲同时轻微震动，威压扩散，修士茫然。凡有**镇压之庙**存在之处，**庙宇正是各洲震动的中心**。
2. **魂现**：震动加剧，各洲被镇压的**天外之兽的魂**出现不稳、暴躁，进而**幻化现形**；连传说中**已成死魂**的存在也一一出现，虚影模糊，却同样**仰天嘶吼、恐惧中透出哀求**。
3. **首现者**：**天牛洲**上巨大天牛第一个出现，虚幻身影笼罩整洲，仰天咆哮，目露激动、恐惧，更多的是**哀求**——哀求那天空之上它所感受到的**奇异存在**，将其释放、还其自由。
4. **秩序动摇**：仙族几乎所有修士目睹此幕，惊慌之下，似要出现一场大乱。

## 五、各方强者反应

- **道一大天尊（道一宗）**：飞起观天地，神色阴沉兼一丝惊恐；见**山海洲**幻化出一颗参天**天外妖树**，枝条舞动嘶吼。惊疑：“这尊天外妖树不是已经死了么？竟还有魂在！……莫非是祖城皇宫的那连道非的镇压出了问题？”
- **武封（北洲）**：面对天地间一尊**巨大的冰川巨人**，一脸阴沉，蕴含惊恐。
- **紫阳宗双子大天尊**：齐齐飞出，望天皱眉。
- **久帝大天尊（祖城·帝山）**：背手望天，看似如常，**瞳孔收缩**泄露震惊。

## 六、海子推算：一道『踏天之目』

- 海子先报：**地宫没有出现问题，连道非依旧沉睡**，即便如此也**一直在镇压这七十二尊天外之魂**。
- 久帝追问：连那些**装死的天外之灵**都不惜一切扬天嘶吼哀求，它们感应到了什么？
- 海子掐诀，**右手心出现一个不断磕头的小人**，眉头紧皱、一无所获；遂**咬破舌尖喷出鲜血**落于小人之上，小人化作血色、发出凄厉低吼再度磕头。
- 海子身体一震、踉跄、面色苍白，得出结论：

> “**它们感受到了一道踏天之目，在我仙罡大陆的天空上，看向它们！**”

- 久帝面色大变，猛抬头只见天空，**毛骨悚然**，似能想象有一道目光自天外注视仙罡大陆、或许正注视自己；其体内修为竟一时无法操控，**身体在衰老与中年之间反复变化**，足见心惊。

## 七、要点与伏笔

- **哀求的性质**：天外之灵所求者非攻击而是**释放与自由**，对象是它们感应到的“奇异存在”——即踏桥中的王林之目光。
- **镇压体系**：仙罡大陆七十二洲各有**镇压之庙**；祖城地宫内**沉睡的连道非**为镇压七十二尊天外之魂的总枢。
- **九柱之门**：竖起旋转的海洋深处、九柱所成之门**紧闭**，为后续重要伏笔。
- **踏天**：王林第一次在正文中把自身当下的状态与“踏天”对应，并被仙罡大陆一侧以“踏天之目”反向确认。

# 王林俯瞰仙罡：天外凶兽异象与踏天之桥之问

## 一、仙族异象：七十二洲化兽哀求

王林以超越众生的视角俯瞰仙族大地，七十二尊由仙族七十二洲幻化的天外之兽在他目光下嘶吼哀求。他看到了众生的反应，众生却感受不到他的存在：

- **道一**：震撼。
- **武封**：惊恐。
- **双子**：不解。
- **久帝**（帝山中）：目光投来，在王林目光扫过其身侧的刹那，正是久帝望向天空毛骨悚然的一瞬。

久帝身子飞起向天蓦然一拜，口称「晚辈周洛久，参见前辈，前辈又何吩咐，晚辈必定全力完成」。他自成为大天尊后从未如此拜过人，此刻却被恐惧弥漫、神色极恭敬——但未得任何回音。

异象由嘶吼转为绝望、哀求渐深，最终一一消散，大地不再震动。海子身躯颤抖轻声道：「此人已经走了。」久帝仍保持恭敬拜姿一炷香，才苍白着面孔起身落下。

王林还看到了祖城皇宫下地宫中、已化作山峰的连道非。他此前看到天牛、连道非时曾动过救出他们的念头，**但他做不到**。

## 二、古族异象：三十六郡与罗喉

目光转向古族的刹那，古族大地爆发同样震动，三十六郡内幻化出三十六尊天外凶兽，其中包括**被王林吞噬了部分灵魂的罗喉**：

- 罗喉身影完全幻化，头颅为巨大肉球，形如一颗修真星；
- 尾部如龙尾，且多达**九条**；
- 仰天嘶吼，透出哀求之意。

各方反应：

| 人物 | 所属 | 反应 |
|---|---|---|
| 玄罗 | 古族 | 自闭关中惊醒飞出，倒吸口气 |
| 宋天 | 始古一脉 | 半空目瞪口呆，自我否定「绝不会与王林有丝毫关联」 |
| 神秘大天尊 | 极古一脉 | 在闭关处阴沉地感受这一幕 |

## 三、古道山：唯一看见王林的人

王林目光最终落在**古道山**高耸塔楼顶层，一片雾气缭绕的身影上。那身影叹息、睁眼，抬头看向天空的一瞬，**双方目光碰触**——王林确认：这位仙罡大陆的第一强者，的的确确看到了自己。以王林如今修为，仍看不清迷雾内古道大天尊的相貌。

## 四、核心设定：踏天之桥

二人以神念对答，抛出本章最重要的境界设定：

- 古道大天尊问：「你终到了这一层境界……现在，你是在第几座桥上？」
- **王林：第二桥**。
- **古道大天尊：多年前踏过第五桥，一直在第六桥止步**。
- 王林问：若度过第九桥，是否就是**第四步**？古道答：不知晓——**古往今来，没有人踏过第九桥**。
- 关于**古祖与仙祖**：二者**都踏过了第八桥，在第九桥止步**。
- 关于踏天之桥的本质：古道理解为「仙罡大陆很大，可在天外，还有更多的大陆」，**踏天之桥是对所有生灵共同的道路**；言语中带一丝迷茫——即便是他，也对此不解。

王林沉默，慢慢收回目光。

## 五、要点归纳

1. 王林修为已至可令整片大陆本源级凶兽虚影屈服哀求的层次，且被明确定位为踏天之桥「第二桥」。
2. 「桥」序列构成第三步之后通往「第四步」的阶梯，九桥为已知上限而无人踏过。
3. 仙罡大陆最强者（古道大天尊）位阶：第六桥止步；古祖、仙祖：第八桥止步。
4. 罗喉与王林存在吞噬因果（王林曾吞噬其部分灵魂），故其虚影一并显化哀求。
5. 王林对天牛、连道非有救援意愿但力有未逮，为后续伏笔。
