# 第2042章 魂完整！

## 一、送宋致归家（黑石城）

- 宋致独自走入黑石城，一路无守卫阻拦（城主已接到命令）；回到自己住所，见到守候的两人——满头白发的老妇人**常姨**与年纪不大的丫鬟**东梅**，她咬着下唇微笑道「常姨、东梅，我回来了」。
- 城外，王林收回神识，望着黑色城池。宋致体内藏有**李慕婉的残魂**，融合过程对她伤害极大，致其记忆错乱、分不清自己是谁。
- 王林本可不顾其生死直接抽离残魂，但那意味着宋致生机消匿、魂飞魄散。他修道数千年、素以心狠手辣冷酷无情示人，却「依旧还是一个人」，不忍如此。
- 因此这一年多近两年他刻意缓行，一路**不断送入修为之力融入宋致体内**，使最终分离时不伤其生机与灵魂。
- 王林留下**玉坠**，内有其神念，可保宋致一生平安。

## 二、计都皇子现身与安排

- 王林话音落下，**计都皇子**自波纹中走出，单膝跪地口称「谨遵义父之命」。
- 计都已通知黑石城城主守护宋致不容有丝毫损伤，并派遣侍卫居住此地守护。
- 计都回到始古后一直留守此地，判断王林必会来此，终于等到。王林对此毫无情绪波动——若此人分析不到，反倒说明难以大用、争夺皇尊之位更为艰难。
- 王林要求准备闭关之处，计都献上自己行宫密室。王林大袖一甩，携其瞬息至行宫，选定一间密室，吩咐「没有我的吩咐，任何人不得入内」。

## 三、始古皇尊之争

王林点破关键：

- **宋天**（始古一脉大天尊）的指认是重点，他若指认计都，一切就简单了。
- 计都的困境：宋天对其冷漠，平日拜见多不见；反倒重视其**皇弟蚩蛮**，蚩蛮已住上**原始山**，传闻将被宋天收为弟子；父皇亦看重蚩蛮，整个始古一脉隐隐要立蚩蛮为下一代皇尊。
- 另有**皇兄**：出生时现天地异象，引起道（吉）道大天尊注意并送来礼物，同样极有可能。
- 王林之言：「各族大天尊可以指定下一代皇尊人选，但也不是没有例外」——大有深意地看向计都，暗示其另有准备。
- 计都跪地陈情：不甘失败后被封王外放、一辈子再无第二次机会；自认才智心性均超蚩蛮，内心不服；恳请义父相助，承诺一旦成为皇尊必履行此前承诺，不敢有异心。
- 王林应允：「那宋天，我可以去会会」，但此事待其出关后再说。
- 王林识人：计都属**枭雄**之类，懂得掩饰情绪、知晓分寸。
- 计都狂喜，将此地化为禁区，擅闯者立杀，调侍卫日夜守护，暗忖「二百年后，我计都就是始古皇尊」。

## 四、王林的深层图谋：魂血与太古神境

- 王林布下大量禁制封锁密室，以其如今修为所知阵法禁制，即便大天尊来临也无法在其未察觉下进入。
- **核心难题**：一滴魂血无法让李慕婉的身躯进入**太古神境**。
- **太古神境**（据王林当年在紫珠宗所见双子大天尊典籍）：何时出现无人知晓；其内存在一股莫大压力，可遮蔽天地运转；死在其内之人即便不魂飞魄散，魂也不入轮回——**连轮回也可阻止**。这与**道古国师**所说颇多相似，故王林一年前才让对方运转阵法开启太古神境。
- **推断**：道古国师费尽心思开启太古神境，以真相为诱、以婉儿超越轮回为饵，欲诱王林前往；不论其目的为何，至少在李慕婉一事上应说的是实话——否则王林大可不去。
- **获取更多魂血的路径**：必须去古族**祖庙**，度**古族第三损之劫**；度劫后方有机会再获**古祖**认可，或如第二损劫那样获得魂血。
- **为何选始古**：祖庙开启之权不在大天尊手中，而握于**历代皇尊**之手，是皇尊的权利。王林已不能回**道古**，即便**罗尘**最终获认可成为道古皇尊，他也不愿再回道古；与**极古一脉**接触不多；始古最为合适，尤其计都虽有野心却不敢逆其意。
- 王林轻叹：「五百年，最后的五百年了。」

## 五、魂完整

- 王林一挥手，柔和之芒中现出一口**晶莹棺木**，李慕婉如沉睡般躺于其内。
- 他左手拍向额头，自眉心飞出一缕荧光，内有模糊虚影——正是**李慕婉的残魂**。
- 「婉儿，从此之后，你魂完整，我一定会让你苏醒，不仅仅是几十年，而是一辈子。」
- 荧光直奔李慕婉眉心缓缓融入，李慕婉睫毛轻颤似欲苏醒，随后归于平静，眼角却流下两行晶莹泪水。
