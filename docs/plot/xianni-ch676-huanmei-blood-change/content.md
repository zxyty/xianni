# 第七卷 名震罗天 第676章 幻眉临近

## 一、千幻星·幻月潭：幻家换血

**地点**：千幻星南部，幻家范围内的深潭「幻月潭」。潭水早被幻家老祖以神通取走，地面只余一处凹陷深坑。

**仪式流程**
1. 幻家族人多达数万，方圆数十里内一片死寂，族人依次上前在坑边割臂放血，面色苍白而退。
2. 最后由幻家老祖亲自割腕，放血最多，面色渐白。
3. 老祖掐诀吐出一字「融」，血潭起漩涡，数万人之血彻底融合、不分彼此。
4. **换血定义**：从数万血液中炼化出幻家至纯血脉，化作**一千血符**印在一人之身，并把此人自身之血抽离转化。

**受术者**：柳眉。一身白衣、颇具圣洁之感，称老祖为「义父」，被令「进入血池，凝神打坐」，踏入血池直至没顶，盘膝坐于池底。

**血脉来历**：老祖宣告——「幻家先祖乃悠悠岁月之前**雷之仙界**仙人，仙界虽毁，可血脉却在」，换血即是把此血脉炼化而出，为幻家日后荣耀再添一人。

**过程**：老祖印诀入池，血池沸腾；一声「血脉，现」，血池停转升空化作血柱，崩溃成漫天血色符文。柳眉现身盘膝，额头被点裂放血、面色愈白；血符纷纷落下印满其身、寸寸弥漫，最终尽数融入体内，化作幻家血脉流转，把她自身之血全部逼出。

## 二、幻家老祖的道与代价

- **万幻无相道**：老祖掌心神光千变万化，观之者刹那间可从中看到自己此生的一切变化——生老病死、爱恨情仇。
- 掌按柳眉天灵，将庞大**道念**打入其元神，同时毫无保留倾注**仙力**助其提升修为。
- **修为门槛说明**：提升至问鼎后期大圆满所需仙力极为庞大，修道第一步之人做不到，即便身处**阴阳虚实**境界者亦断然不能；唯有真正踏入**第二步**者方有此逆天神通。幻家老祖正是第二步中**窥捏初期**的大神通修士。
- **结果**：柳眉元神肉眼可见地疯狂强大，问鼎初期→中期→后期→大圆满，仅半柱香即达成许多修士穷尽一生（乃至修炼数千年）的追求，四周数万族人尽露嫉妒之色。
- **代价**：老祖手臂明显萎缩、整个人瞬间越加苍老、双眼神采暗淡——为把柳眉当作幻家未来接班人培养，不惜自损修为。

## 三、赐名幻眉与出战之命

- 老祖宣告：「从今天开始，你便是我幻家之人，你的体内流的是我幻家之血。」并令其在自己闭关期间好好修炼，争取早日踏入**阴阳虚实**境界。
- 柳眉只是静静回望、点头，不发一语，态度冷漠。
- 老祖笑言想知晓柳眉所修的**万幻天魔道**在第二步会有何种神通变化，随后大袖一甩身影消失。
- 临别之命：「去**冉云星**，幻眉，这是你身为幻家之人的第一战，杀出你的威名来。」
- 柳眉（幻眉）不看族人一眼，踏虚空而去，未带任何随从，独自奔赴冉云星。

## 四、云霞星地底：王林与望月、金炎脉

**望月（古神寄生之物）**——据古神涂司记忆：
- 体长千丈，实力不逊于初踏第二步的窥捏大神通修士。
- 三种形态：①第一形态——无攻击性，若无古神存在则保持不变，不主动招惹即安全（本章所见即此形态，化作红云望月远去）；②第二形态——全身须毛收缩、化作各种奇异形状，属沉睡，在古神体内较常见；③第三形态——攻击态，须发无限延长可达与身体同长，遇之须立刻逃离，慢一步即遭攻击。
- 王林判断此物非己所能招惹，「望月出现在这里，却是有些诡异」，决定不予理会，以寻金炎脉为重。

**探脉经过**
- 王林顺大地龟裂缝隙深入至尽头，融入岩壁，以**土遁之术**继续向地底探去。
- 地底泥土渗出黏液，若非仙力环绕体外即会被粘住；神识遇强大波动便主动绕开。
- 神识几乎覆盖云霞星地下全境，最终在最深处发现一条**延绵无数里的金炎矿脉**，形如巨龙蜿蜒；其中一段在云霞星另一面略有破土，**当年幻家族人正是在那里发现此脉**。

**王林的疑虑**
- 矿脉毫无掩饰，任一问鼎修士到此略查即可知晓，「如此一来，却是有些蹊跷」。
- 仔细查探后未看出任何端倪，最终果断撕开泥土直奔最深处炎脉。
- 自见望月之后，心中一片阴云弥漫、始终不散。

## 五、伏笔与走向

- 幻眉奉命赴冉云星立威，王林正在云霞星取金炎脉——两条线迅速合拢。
- 作者章末预告：次日起写**王林与柳眉的交锋**，并称此情节「有种淡淡的哀伤」。

## 注
- 本章「幻眉」即柳眉换血后的幻家身份/新名，非另一人。
- 「望月」在本章为妖兽/寄生生物，非月相。
