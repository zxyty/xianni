# 第八卷 联盟隐秘 第928章 五行金尸

## 一、唤雨破莲叶

- 水罗蓝裙女子放下左手，目色复杂散去，念「君既不识，便随虚而去」，天降莲花叶威压，压制王林体内元力运转。
- 王林先以黑色旋风与两头黑龙迎击：一龙撞击即崩、化作黑气被震回；另一龙吐出的阴风被莲花叶尽数吸收，叶上透出绿意，威压更重，黑色旋风瓦解成漫天黑气。
- 王林首次真正亲自施展 **仙帝白凡仙术第二式「唤雨」**：
  - 「唤雨」出口，天地元力如被大手搅动疯狂凝聚，身外浮现薄薄水雾。
  - 弥漫黑气被注入新力，形成百丈漩涡环绕王林剧转，转眼凝出万滴蕴含天地元力的雨水，每滴皆具极大威力。
  - 体内 **仙元之力** 分出些许弥漫全身、沟通天地，漩涡内更有一丝 **仙气** 缭绕，其状如仙人。
  - 双手前甩，漩涡逆转轰鸣冲天，如百丈漩涡拔地而起连接天地；万滴雨水随之冲出，天地逆转、雨自地生。
- 关键克制：王林双眼中有 **雷意** 闪烁，最终压下——不愿在此暴露真正修为。
- 结果：漩涡横扫使莲花叶一震，万滴雨水轰击之下莲花叶崩溃，王林脱压。

## 二、假意杀招与骸狱界登场

- 王林掐诀将唤雨漩涡雨滴指向水罗蓝裙女子，但见远处 **黑煞魔尊** 与 **血神子** 及 **罗浮血球所化血人** 交战不敌、节节败退并靠近己方位置，立刻后退。
- 心理动机：杀该女子并非真有杀机，而是做样子——「最起码，他许木在这场大战中，尽力了」，加上此前已有功劳，一切可以略过。
- 女子以右手 **七叶莲花台** 一点，幻化虚幻莲花挡下唤雨神通；她观战场判断联盟不利却毫不慌乱，认定「真正的大战尚未展开，眼下只是前奏」。
- 女子掐诀一指虚空，轻声道 **「请骸狱界」**：
  - 前方虚空无声出现弥漫百里的大阵，**倒挂星空**、出现即旋转，散出紫黑之气。
  - 一条紫色铁链落下，砸中一名躲闪不及的罗天修士，肉身立崩、元神被锁在铁链上无法挣脱。
  - 片刻间上百条铁链横扫四周。

## 三、炼尸设定与十八具之数

- 阵内传出撕裂感极强的咆哮（如元神被双手撕开），走出一具身高十丈、全身紫青的死尸，恶臭弥漫，身缠大量铁链（此前垂下的铁链即其身上之物）。
- **炼尸设定**：非自然生成，由无数尸骸以神通之法祭炼而成；修真联盟内称之为「炼尸」。**尸阴宗提供尸骸，骸狱界自行炼化**，数万年来 **一共只有十八具**，每一具都拥有相当于 **窥涅后期** 的修为。
- 第一具炼尸以缠身铁链为最凌厉法宝横扫，咆哮可穿透肉身直接影响元神，大量修士不敌后退；第二具随后杀入战场。
- 随一具具炼尸走出，**战场局势瞬息逆转**。

### 最后三具（异色）
- **两具银光炼尸**：一男一女，神情呆滞但身体如常人大小，身着银衫，仅两条铁链环身，出场即散发 **净涅初期** 威压。
- **一具龙袍金尸（五行金尸）**：中年男子，一身龙袍、头戴高冠，状若凡间帝王；身上无铁链，**惟天灵之上有五张黄色纸符盘旋，并有阵阵雷光闪烁形成连接**，与其紧密相连；身上弥漫 **天地五行之力**。
- 王林当即判定其为 **「五行灵体」**，脑中第一个想到的是 **当年遇到的红蝶**。

## 四、王林的自保方针与算计

- 明确原则：**「能有功，便取之，若无功，则自保」**；自知以其修为在两星域级别大战中起不了太大作用。
- 心念一转：「不知此刻清水师兄在何处，想来，应该也是在这附近」。
- 战力自评：面对 **窥涅中期**，凭此刻肉身与神通可胜；面对 **窥涅后期** 需展开全部神通方有胜机，且变数极多；大战中尽出神通不智，一旦受伤立刻身处险境。
- 真实目的：**浑水摸鱼，伺机不被注意地进入望月体内，抢夺古神幼子的力之传承。**

## 五、借势破封印（本章转折）

- 水罗女子玉手一指，派一具寻常炼尸（窥涅后期）死盯追击王林，铁链飞舞硬开通道。
- 王林借后退不断靠近被封印的望月所在的巨大黑壳；**申公老祖** 正率众多修士施展神通攻击黑壳。
- 王林判断：以联盟眼下这些修士根本困不住望月，「望月一怒，一切都会崩溃」。
- 铁链临身刹那，王林急退 **故意撞在黑壳上**，接触瞬间不假思索地 **散出一丝古神气息融入黑壳**。
- 壳内望月本能感应到古神气息，**发狂咆哮惊天动地**；「望月之怒，如古神一指，越怒神通越惊人」。
- 黑壳轰隆巨响、裂缝密布、**封印崩溃**，崩溃瞬间 **一根粗糙的古神手指直接从中伸出**。

## 六、要点归属提示

- 本章「许木」即 **王林** 的化名（自第661/669/711/731/771/821章沿用），言行归王林。
- 提及的 **红蝶** 仅为王林回忆当年所遇之人（用以类比五行灵体），非本章出场。
