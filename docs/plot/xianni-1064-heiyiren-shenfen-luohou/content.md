# 第八卷 联盟隐秘 第1064章 黑衣人的身份

## 一、青霜之血克古魔
- 王林抛出一滴青霜鲜血迎向从坍塌地面冲出的黑气魔龙。血滴触及魔龙口中游离黑气，黑气如清水泼炭火般呲呲消散。
- 血滴穿透黑气落在龙头，魔龙惨痛怒吼、扭曲横扫，此地建筑尽数坍塌成废墟。
- 王林再挤青霜之血，掐诀甩袖、元力磅礴，将血液化作殷红血雾前推。魔龙挣扎剧烈、急速收缩，**古魔本体**现身。
- 古魔漆黑铠甲沾上数滴鲜血，散出丝丝红气久久不散；挥手、以手抹拭皆无效，触之如穿透明。

## 二、青霖的「创造规则」后招（关键设定）
古魔当场揭破：
> 「青霖，这就是你计算了无数年为抵抗本魔夺舍都准备的后招么——凡占据你肉身者，若要杀你之后人，一切神通全部失效，就连非神通的攻击也没有任何作用，更是被你后人之血生生克制。这已然不是寻常的改变规则，而是**创造规则**。」

推论要点：
- 古魔现所占肉身 = 青霖之体（夺舍）。
- 青霜 = 青霖后人，受此规则庇护。
- 规则只护「青霖后人」，不护旁人——故古魔转而杀王林。

## 三、古魔出刀与「移形换位」
- 古魔虚空一抓，黑色厚背刀现于手中，狂斩王林：「杀不了这青霖后人，但却可以杀了你这小小古神。」
- 刀芒遮天，连葫芦老者都无法避过。王林心神一震而脑中前所未有清明，古神大鼎虚影一闪，指向远处观望的黑衣人。
  - **选择理由**：虚空子虽重伤，修为仍是**碎涅**，王林没有把握，而此刻必须一次成功。
- 第一次「换位」：黑衣人面色大变，不顾印记暴露，眉心**炎龙印记**幻化冲出，化作全身火焰的炎龙环绕护身，抵抗古神大鼎之力，换位被阻。
- 刀芒穿透青霜肉身却因青霖定下的肉身规则丝毫未伤，全部宣泄向王林。
- **青光盾开裂**：王林右目青光一闪挡在身前，青光盾中间咔的一声出现裂缝并不断扩大。此前即便虚空子也只能逼退青光盾，从未使其毁坏。
- 第二次「移形换位」：王林嘶哑咆哮，眉心**五个古神星点**幻化旋转如星光漩涡，古神之力灌入大鼎，光芒几乎照耀天地。炎龙无法承受，黑衣人转身逃遁未远即被强行换位。
- 结果：王林出现在黑衣人原位；黑衣人出现在刀芒之下，瞳孔被无尽刀芒取代，肉身砰砰碎裂、血肉爆开一分为二。

## 四、黑衣人身份揭晓：掌尊坐下第七弟子罗睺
- 黑衣人元神在炎龙环绕下黯淡疾退，刀芒穿透而出直追元神。
- 危急时其神念传出：**「古魔大人，我是掌尊坐下第七弟子罗睺」**。
- 刀芒骤然一顿，从其身边横扫而过、**绕开黑衣人**，再度直奔王林——古魔显然认此身份。
- 王巍与胡娟同时临近，各施神通对抗追击刀芒，王林侥幸逃过一劫，但神色狰狞死盯古魔。

## 五、古魔塔珈一吼（古之一族神通）
- 古魔塔珈一步至罗睺元神旁，一把抓住其元神；再一步来到王巍、胡娟身边，张口大吼。
- 设定：古之一族各有神通，形态各异；古魔之吼虽不如古神，但胜在**魔音入体、撼动心神**。
- 吼时其身后浮现**头生单角的巨大黑影**（如天下一切魔之根本），随之同吼。
- 战果：
  - 胡娟震得喷血；王巍喷血萎靡，仍抱住胡娟疾退，掐诀横扫幻化千万重**水幕**，无始无终，却刚现即崩。
  - 胡娟以双手打出禁制与水幕融合，仍持续崩溃，二人再度喷血，退向王林。
  - 虚空子喷血神色黯淡，沙土护体尚未成型即崩溃倒卷，身子抛出、鲜血不断。
  - **贝罗**同为古之一族，可勉强承受，疾驰后退。

## 六、王林暴露古神真身
- 王林体内砰砰作响、喷出鲜血，神色愈发狰狞，回以一声**古神的怒吼**。
- 身躯疯狂增长至**数百丈**，好似支撑天地；眉心五星急旋，古神之力云涌体外。
- **朱雀图腾**因与王林融合，随古神肉舍同步放大，如鲜血般印在上半身，尾部弥漫脸上——此刻的王林「既是古神，又是朱雀」。
- 注：王林的古神**只有五星**，若刀芒正面落下将一刀两半。

## 七、本章要点清单
1. 青霖血脉规则确认（创造规则级别）。
2. 青光盾首次出现裂缝，战力标尺被刷新。
3. 黑衣人 = 罗睺，掌尊坐下第七弟子，持炎龙印记，肉身被毁、元神被古魔塔珈擒获。
4. 古魔塔珈之名与「一吼」神通登场。
5. 王林公开五星古神之体 + 朱雀图腾融合形态。
