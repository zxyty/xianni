# 仙逆 第1249章 木冰眉（第九卷 云海之巅·第四更）

## 一、净涅之上的储物空间设定
- 修为到达**净涅**之后，无需储物袋，可凭自身神通开辟储物空间。
- 该储物空间在安全性上**远超储物袋**，因而颇受大神通修士钟爱。
- 王林当年已开辟出一道储物空间；本章开辟**第二道**，专用于容纳蚊兽。
- 要求：空间内需有充足的**仙力与元力**——王林存有不少**元晶**与**仙玉**，不缺此物。

## 二、开辟第二储物裂缝的全过程
1. 右手一抓，身前虚空撕裂，出现约**千丈大小**的缝隙，缝内有**阴风**吹出。
2. 眉心**规则之星**一转，雷霆呼啸而出环绕裂缝边缘，不断闪烁使裂缝**稳固**。
3. **蓝色火焰**冲出，进入裂缝内燃烧横扫，使其内**阴寒之气消散**，并**扩大了范围**。
4. 抛入**仙玉与元晶**，裂缝内骤然凝聚足够的**仙元之力**。
5. 全程刹那完成，未浪费半点时间。

## 三、蚊兽尽数收纳
- 随王林神念，身下**蚊王**发出嘶鸣。
- 四周**上万蚊兽**涌入裂缝，王林体外蚊兽越来越少，最终全部进入，**包括两只紫色蚊兽与一只金色蚊兽**。
- **蚊王最后一个进入**，进入前**回头看了王林一眼**，才沉入其中。
- 王林右手一挥，裂缝消散。此刻风仙界内**只剩他一人**。

## 四、脱身准备与对蚊王的疑惑
- 身后无边无际的蚊群疯狂追击、越来越近。
- 王林取出**收回的速符**毫不犹豫贴在身上；**不顾伤势未愈**运转体内元神，一股**碎涅**气息轰然弥漫全身，**与古神之力融合**。
- 心中疑惑：那庞大**蚊王**之强，若换成修士足以惊天动地，但**从未见其施展神通**，**速度上似乎也无出奇之处**（伏笔）。

## 五、缩地成寸：云海星域首次施展
- 王林身外大量波纹回荡，抬脚前迈，身子一片虚幻、瞬息消失——**缩地成寸**。
- 这是他**在云海星域第一次施展**此大神通之术。

### 环境限制（重要设定）
- 云海**充满星雾**，更有一股**奇异之力笼罩**，施展缩地成寸**几乎没有任何效果**。
- 因此，这门在其余星域大神通修士中也不多见的神通，在云海**几乎罕有人明悟**。
- 论断：**环境决定眼界、决定心神感应、决定神通发展方向**。若其余三大星域也充满星雾，恐怕缩地成寸也不会有人明悟——因为对他们而言无用。
- 即便明悟，对云海修士也无用处、无施展之地；即便在**风仙界**内，此术亦被**严重干扰**。

### 但它是风仙界唯一的存活手段
- 受干扰后：**无法挪移太远**、**无法随意融入天地**。
- 若无准确的**心神目标投影**作为方向，很可能出现在陌生地方；一旦出现在蚊群之内则**极为危险**。
- 最稳妥之法：**心中所想须是亲眼见过之地**，方可融入天地而去。
- 佐证：风仙界深处并非无人来过，凡来者**均以缩地成寸而来**且需极为谨慎；加之云海明悟此术者极少，真正踏入深处的人**极为罕有**。

### 本次施展
- 王林心中所想为**风仙界的出口裂缝**。
- 身影消失，天地之力弥漫，蚊群嘶鸣渐渐远去。
- 他仿佛进入奇异境界：**身化虚无，无存在之感，仿佛成为天地一部分**；心中出口裂缝越发清晰，最终取代心神全部——说来缓慢，实则瞬息。

## 七、伏笔/待跟进

# 第1165章 离风仙界返云海·无极宗分宗大比

## 一、离开风仙界

- 王林全身那种「似乎不存在」的感觉恢复正常后，一步走出，天地之力凝聚使其身形飞快幻化，落步瞬间重新凝聚肉身。
- 其前方即是**风界通向云海八阶星域的出口裂缝**。回望天空余波回荡，极远处传来隐隐好似隔绝了岁月的模糊咆哮。
- 王林神色平静，身子一晃冲入裂缝，离开风仙界。

### 石化雕像老者的伏笔

王林离开的刹那，风界深处被守护的三块大陆之一上，那**石化的雕像老者**眼中露出明亮之芒，说：

> 「这一次，我帮你；下一次，就需要你来帮我了。」

（明确交易/因果伏笔：此次相助以日后回报为条件。）

## 二、重回云海八阶星域

- 走出仙界裂缝后见到八阶星域外熟悉的**星雾**，王林略感不适——仙界内无雾气、目光可望极远，而云海中星雾难以穿透。
- 目标明确：「无极宗」。王林身子一晃冲入云海，按脑中大量玉简所指引的方向直奔无极宗。

### 王林的自我盘点（蚊兽与拓森）

- 此行风仙界获得**大量蚊兽**，但仍不够。
- 若伤势痊愈，配合蚊兽之下，**在拓森面前也不是没有逃遁之力**。
- 只要再给一些时间让**蚊王进化**，便可获得更多蚊兽。

（可见：王林当前带伤；拓森是其明确忌惮的强敌；蚊兽体系依赖蚊王进化扩军。）

## 三、无极宗：五阶星域分宗大比

- 地点：八阶星域无极宗内，占据了**小半个星球**的平台。
- 事件：五阶星域**分宗大比**正在进行，**紫道宗几乎横扫**，没有任何分宗能与其对抗。
- 场面：平台轰鸣回荡，吸引四周近**十万修士**围观，议论弥漫。

### 看台人物

要点：

- 存在一个「**神宗**」，正欲/可能将卢云从收走；白袍老者以玩笑口吻先行阻拦。
- 「王道友」为在场受话者（身份本片段未明）。

# 第1165章 云海星域分宗大比：木冰眉忆起故人

## 一、场景
- 地点：云海星域某分宗大比现场，平台上比斗、四周修士观战。
- 出场：紫道宗宗主**卢云从**（参战者）、其对手**黑衣老者**（某五阶分宗宗主，神色难看）、观战席的**白袍老者（某宗主）**、一名**中年男子**、**王珊珊**、**木冰眉**。

## 二、观战席对谈
- 王珊珊笑称：只是曾听**家师**提过卢云从一句，师尊对其似很赞赏；至于是否收其入**神宗**，非她能决定。
- 白袍老者不再提此事，转为闲谈，时而看向冷漠的木冰眉，**猜不出其身份**。
- 木冰眉本对云海星域分宗大比毫无兴趣，因王珊珊提议才来。

## 三、卢云从其人（本章设定）
- 身份：紫道宗宗主，紫袍飘逸，站立如山峰。
- 修行履历：修道**三千余年**，**不靠任何丹药**，千年问鼎、千年窥涅、千年净涅。
- 特点：身影隐隐**与天地融合**，意境极高，对**道**的理解造诣颇深。
- 旁证：**破天宗李倩梅**曾寻其论道。
- 木冰眉评价：「也算翘楚之辈。」

## 四、关键伏笔：木冰眉追忆之人
中年男子问：木道友所来之地，可有卢云从这等人？木冰眉沉默良久，追忆道——

| 阶段 | 用时 |
|---|---|
| 结丹 | 二百年 |
| 婴变 | 五百年 |
| 问鼎 | 八百年 |
| 阴阳虚实 | 千年 |
| 净涅初期 | 修道不足两千年（至其离开前） |

- 其人「一生悟道，看破生死，转化因果」，天下能与之相比者罕有。
- 结论：卢云从**修为或高于他，但论道不如**；即便生死之斗，也还是不如。
- 说明：文本未点名此人姓名，但履历与「看破生死、转化因果」高度指向**王林**（木冰眉离开原星域前的观测）。此为叙事伏笔，本条以低置信度关系标注。

## 五、要点
- 木冰眉「异地之客」的定位被反复渲染：无一物一人熟悉，冷漠而孤独，暗示其来自另一星域。
