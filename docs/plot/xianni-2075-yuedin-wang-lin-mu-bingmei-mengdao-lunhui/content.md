# 第2075章 约定

## 一、局势：赤魂子围界，两日破阵

- 王林（此时白衣白发青年之相）以神识清晰笼罩新仙界内外：看到赤魂子嚣张的嘴脸、其身边一名与之**隐隐有血脉关联的青年**，以及仙界外正被血光腐蚀的**护界阵法**。
- 依腐蚀程度判断：**阵法约两天左右便会消散**。
- 因果回溯：赤魂子当年是被王林解开封印放出的。那时对方虽虚弱，于当年的王林仍强悍惊人；如今赤魂子修为**全部恢复至巅峰**，在王林眼中却「脆弱如一只蝼蚁，一指可碾碎无数次」——双方实力对比已彻底逆转。

## 二、归界：一步自罗天星域踏入新仙界

- 王林于**罗天星域**冷哼一步迈出，身形消失，此地**光门随之散去**，仿若从未出现。
- 他并未现身于界外赤魂子四周，而是直接踏入**新仙界**（很多年未归）。**界内所有修士无人察觉**，界外赤魂子等人更不用说。
- 界内景象：天空不再是以往的水蓝，而是**赤红一片**，沉甸甸、压抑；地上宫殿、山峦、河流依旧勾勒出仙界之美。王林所见有熟悉处，亦有全然陌生处。
- 王林右手一挥，三道光芒幻化出三人：
  - **许立国**、**刘金彪**：环顾四周后贼眉鼠眼对视，隐隐趾高气昂——如同从大地方（仙罡大陆）回到小地方家乡的得意。
  - **十三**：王林唯一跟随其回到洞府界的弟子，非常人；出现后神色恍惚片刻即恢复，抱拳恭敬一拜后默立。对他而言仙罡也好洞府界也罢，只要能随师尊左右，皆无特殊意义。
- 王林留下一句「到家了，你们随意，我要去见一见故人」，化作长虹飞去。

## 三、重逢：王林与木冰眉

### 相遇前的木冰眉

- 木冰眉独立山峰，身影柔弱似要随风而去，咬唇轻叹，**抚摸手中晶剑，目露绝然**，似已下定某种决心（结合血色天空，指向以死或决战应对赤魂子之危）。
- 她猛然转身欲离去，却在转身刹那全身一震——身后不远处站着一个**白衣白发的青年**，陌生中透出熟悉。

### 旧约兑现

- 王林目中浮现层层记忆：**恒岳派**明媚少女 → **朱雀墓**中美得让人窒息的身影 → **罗天星域**王平凄厉尖嘶中的停顿与苦涩 → 离开**洞府界**那日细雨中撑伞而来的绝美女子。
- 对白（旧约）：
  - 王林：「**若我还在世间，会回来。**」
  - 木冰眉：「**若我还在世间，会迎你。**」（泪落；她自王林离开洞府界后从未如此脆弱）
- 木冰眉身为**昆虚圣女／仙界圣女**一向坚强，世间除王林外似只有**王平**能令她如此心慌。

### 了断与约定

- 王林开口称其「柳眉」，木冰眉即刻失态：剑落于地，踉跄后退，连声「我不要听」。
- 王林言明此行两事：
  1. **见一见故人**；
  2. **与木冰眉做一个了断**。
- 关键情报：**复活婉儿（李慕婉）的方法，王林已经找到**；待他再次离开此地，便是去复活她之时。
- 王林的提议（本章核心「约定」）：
  - 「过去的就让它过去，当年的错误我也有责任」，将一切封尘于记忆；
  - 木冰眉曾说想见一见**王平**，王林此番回来会了却她这心念；
  - **王平也需要一个母亲**——王林将施展**梦道之术**，让他、木冰眉与王平在梦中**度过一次百年轮回**，让平儿看见母亲，让木冰眉没有遗憾，也让王林自己没有遗憾。
- 木冰眉沉默良久，擦泪点头，喃喃确认：「陪我一世梦道入凡，经历百年轮回后结束……那么现在，你是我的丈夫，对么。」
- 王林闭上双眼，再睁开时**点头**。木冰眉含泪而笑，上前抱住王林——这是二人**真正意义上的第一次拥抱**，也是以一场百年轮回来终结这段「或错误、或孽缘」的异样之情。

## 四、收束：血天裂痕

- 二人在山峰上相拥，时间流逝。**一天之后**，天空血色更浓，并出现**一片片细密裂痕**，似随时可崩溃（对应界外阵法只余约两日）。
- 王林带着木冰眉离开山峰，向远处走去（指向梦道轮回之约的兑现与随后对赤魂子的清算）。
