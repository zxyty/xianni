# 第七卷 名震罗天 第674章 闻风听雨，魂忆知眉

## 一、寂灭指破幻东
- 王林（此期间化名**许木**）施展**寂灭指**，指风化作漆黑长虹，四周涌起带电波纹，雷鸣轰隆如天怒雷劫。
- 一指之下幻东护体光芒瞬间瓦解，面色苍白急退；幻东自储物袋取出金剑，掐诀大喝「金之威」抵挡，金剑寸寸碎裂消散。
- 幻东双手合十硬接，喷血倒飞，身上电光每闪一次伤重一分，且有部分电光钻入体内缠绕元神，令其元神痛苦挣扎。
- 幻东判断："此人绝非冉云星之人，不能战，速走，回去禀告小姐。"

## 二、七星剑阵擒拿
- 王林修为仍为**问鼎初期**，但体内仙力已无限接近**问鼎中期**，只需意境感悟便可突破；此前问鼎初期时神通已胜问鼎中期，故杀幻东易如反掌。
- 王林拍储物袋放出**七星剑阵**（**剑尊凌天候**所创），七剑化长虹追出，在幻东身形将融入虚无的刹那，七剑上的**七生肖之邪魂**幻化融合，兽爪抓破虚空，将幻东生生撕出。
- 全程仅数个呼吸。七剑横列其身周，剑芒紧贴，稍有异动便穿身灭神。

## 三、旁观三人的反应
| 人物 | 反应 |
| --- | --- |

| 逍遥散人 | 惊骇更甚，判断「此人修为，怕是到了问鼎后期大圆满」，自知若对方要杀他必死 |

## 四、幻东的口供与威胁
- 幻东厉声点名**冉学风、孙析、赵传文**三人，威胁幻家还会再派人，与幻家对抗必死无疑，欲以「求一个公正」换取释放。
- 幻东确认：**四年前幻家之人确为此三家所杀**，扬言三家血脉到了尽头。
- 冉家老祖一度犹豫，随即决然，向王林抱拳请求「此人交给我们」，王林点头应允。
- 幻东转而向王林求饶：称幻家老祖已回归，保证不在「小姐」面前提及王林一句。

## 五、关于幻家小姐与幻家老祖
- **孙析解释**：幻家老祖回归之际，从**联盟星域**带回一名女子并收为**义女**，不日将施展**换血**为其改变血脉。
- **幻东供称**：幻家老祖修为已进入**修道的第二步**，数千年前便已是**阴阳虚实**境界。
- 幻东绝望时喊出关键信息：**幻眉小姐是老祖唯一弟子，更是日后幻家家主**。

## 六、搜魂术与「幻眉即柳眉」
- 王林听到「幻眉」后止步回身，追问其原名；幻东欲以此交换活命。
- 王林虚空一抓将幻东摄至掌下，按其天灵，身后影子顺臂延伸弥漫其全身，施展**搜魂术**。
- 因幻东修为问鼎中期，**王林须借仙卫之力**方能施展搜魂。
- 记忆碎片翻看间，王林定格在一名绝色女子身上，面色渐沉——确认此女即**柳眉**。当年**朱雀星**及**朱雀墓**内的一幕幕浮现。
- 王林断言：「此女却是得到了一场造化，来到了这罗天星域。」
- 处置：一拍之下幻东**肉身崩溃化作血肉**，其**元神被抓入储物袋内的尊魂幡**中。冉家老祖三人一愣，各泛心思，再不敢阻拦。

## 七、离开冉云星与后续打算
- 王林留话「许某还有要事，**数月后回来**」，随后出**罡风层**，拍出**星罗盘**化作银龙没入星空。
- 银龙上盘膝自语，定下两条方针：
  1. **对柳眉**：与我并无深仇，若识趣便罢；若还如朱雀星般胡搅蛮缠，说不得只能杀了。
  2. **对幻家老祖**：没必要死战；有仙卫在手，对方出面大不了离开；我独自一人而他是一个家族，打不过他，却可以杀他几个族人作为回报。
- 随后不再思索柳眉之事，依脑中星图直奔**云霞星**。

## 八、云霞星与金炎矿脉
- 王林明言：「云霞星上的**金炎矿脉**，对我极为重要，是**天逆珠子圆满的契机**，此事决不允许任何人阻拦，谁和我抢，我便杀谁。」
- 一路全力赶路无半点停歇，**一个月后**，云霞星在其神识内出现。
