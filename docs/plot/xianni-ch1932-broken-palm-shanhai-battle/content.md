# 第1932章 断掌！！（第二更）

## 一、斩灭面孔与封印未破
- 海子天尊恢复之际，王林在**山海海底黑洞漩涡内的无尽之地**中，一刀斩断那面孔的脖子。面孔发出惊天嘶吼、完全转身，却在王林面前层层崩溃瓦解，化作飞灰融入海水。
- 王林右手与**骨阴刀**连接处滴血，骨阴刀在巨大痛苦中缓缓收缩，最终完全融入其右臂内；此刀几乎被反震之力崩溃。
- 王林喃喃「要封印我」。其修为之高，在海水中呼吸如常，海水无法入口，反吸取海水内蕴含的一丝丝可呼吸物质。
- 回望**山海树**上的层层封印：并未被这一刀破开，波纹渐散、隐隐恢复如常。

## 二、魂铠倒计时
- 王林查看体内伤势，同时估算**魂铠**时间：因之前几次全力施展而骤减，仅剩**约半柱香**。
- 判断「足够了」，遂身形一晃冲出黑洞，回到上方山海海水内；**海龙**自上方急速赶来，目露惊喜，被王林带着直奔海面。
- 王林已察觉：海子天尊身上的定身术已失效。

## 三、海子天尊出手·山海阵
- 咬牙切齿的「王林」二字回荡海中，深蓝海水尽化黑色，浓黑如墨，其内巨大触手甩动，卷起一个个漩涡扑向王林。
- 王林操控海龙避开，神色平静地劝告：**「你我无仇，山海树灵也不是你私有之物，若再纠缠，休怪王某心狠。」**
- 海子天尊反驳「整个山海都是我海子艺婷的洞府」，施展**山海阵**：八方海水尽黑，海面上下形成一片如干枯墨迹般的坚固「墨伽」，封锁大半个山海；自高空俯瞰，山海如同一片黑色大地。

## 四、身份与旧怨（关键设定）
- **海子天尊本名艺婷**，因常年居于山海、并在此得道成天尊，故在天尊层面被称「海子天尊」——正如王林被称「**白发天尊**」。
- **三年前**二人曾有一战，王林失败；海子天尊对他印象略深，却无波澜，事后即忽略。
- **三年后**王林一指便将她定住**十多息**，令身为女修、身份高贵的她极为羞怒，无法接受。
- 她本认为山海树灵凝聚的**木本源**对自己用处不大，若王林放低姿态相求，看在同为天尊的份上可赠几个；但王林前后皆一副冷漠，遂故作刁难。
- 其身份高贵，除有限几位跃天尊外不将寻常修士放在眼中，正因如此才能独占整个山海而无人干涉。

## 五、正面交锋（神通对照）
| 方 | 神通 | 描述 |
|---|---|---|
| 王林 | **役灵印** | 一步踏出化出九十七个残影，残影与本体同时抬掌，九十八道役灵印融合成巨大掌印 |
| 海子天尊 | 蓝光铃铛·蓝色飞鸟 | 铃铛急速膨胀，内出蓝色飞鸟，翅膀连煽七十下蕴含七十道神通 |
| 海子天尊 | **「吾命由身·第一道」** | 身前凝出椭圆形印记，由七十道笔画组成，蕴含七十道神通 |
| 海子天尊 | **「苍天不逆·第二道」** | 印记膨胀，七十道笔画中二十六道分裂暴增一倍，合成**九十六道笔画**（相当九十道神通融合）；推动极难，容颜苍白、嘴角溢血 |
| 王林 | **天牛撞** | 当年曾令道魔宗天尊老祖骇然之神通；九十七残影连同本体化作巨大天牛身，以双角蕴含九十八道神通迎击 |

- 交手结果：役灵印撞碎蓝色飞鸟（飞鸟重新化作铃铛倒卷弹开），但余势碰触椭圆形印记的刹那**无声无息直接瓦解**，令王林瞳孔收缩、感到极大危机。
- 兽战：海子天尊身下的**章鱼海兽**恨海龙入骨，率先冲出与海龙厮杀，海水如雷霆滚滚。
- 王林心态：魂铠时间有限，不愿耽搁；若对方纠缠不休，不介意以最快速度将其重伤。

## 六、暗线——断掌苏醒（章名所指）
- 海底黑洞内、山海树与层层封印之外，**被斩灭面孔消散之处**幻化出点点幽光，透出疯狂凶残嗜血与可怕气息，却**没有散出半点**，交战中的王林与海子天尊皆未察觉。
- 幽点片刻间密密麻麻**不下十万**，一一融合、完全凝聚。
- 未再形成先前的面孔，而是形成**一只断掌**（只有手掌、没有手臂，故称断掌）。
- 原本足有**百丈**，形成后急速缩小至寻常人手掌大小；通体**不是幽色而是透明**，不仔细看极难看清；掌心隐隐似有一个**看不清的印记**。
- 断掌内传出模糊之声：**「发现，非仙罡之灵，封印。」**随后海水波纹一晃，直奔上方而去。

## 七、悬念与后续看点
1. 断掌的判定标准是「是否仙罡之灵」——王林作为外来者被判定为需封印的对象。
2. 山海树封印未破，木本源仍未到手，而魂铠只剩约半柱香。
3. 王林与海子天尊的争斗尚未分出胜负，断掌上浮将成为打断二人交战的第三方变量。
