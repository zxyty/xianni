# 第2057章 失败

## 一、古祖信仰与分神光环之制

- 吉（古）族族人多信古祖未死，或虽死而灵仍在，庇护古族三脉；证据被归结为三脉皇城中古祖雕像的奇异、每一次的「古祖之赐」，以及渡古道三分神时雕像四周浮现的光环。
- **光环计数规则**（重要设定）：
  - 第一次分神成功 → 雕像外闪现 **九道光环**
  - 第二次分神 → **十八道光环**
  - 第三次分神 → 极致的 **二十七道光环**
- 此时始古皇城内，古祖雕像外十八道光环缭绕，光晕波纹弥漫全城，昼夜不分——即便黑夜也照耀整城。

## 二、第一次分神完成（耗时三年）

- 王林盘坐祖庙内，元神光影比之前庞大数倍；境界未升，但修为「强了几分」，以其修为哪怕强一点都足以惊人。
- 王林盘算：若此次渡吉族之劫全部圆满完成、且得到魂血，再去踏天之桥，或能走上当年无法迈过的**第四桥**。
- 复盘第一次分神：最后关头几乎如死亡，全靠意志尚在方能融合凝聚。他由此理解为何罕有人完美分神——**运气可降临一次两次，连续三次极为渺茫**。
- 决断：「运气固然重要，但若有强大可以凌驾于一切的意志，则也同样可以逆转。」遂掐诀一指光影，展开**古道二分神**。

## 三、护法者的进退

- **宋天**：三年前来此是为补偿当年之事、求心中平静；护法三年（并非独自一人护法），既来则决断在心——若过程中遇危及王林之事必出手。第一次分神结束后认为无留下必要，不回头离去，返原始山打坐。
- **玄罗**：在始古皇城天幕上盘膝为弟子护法。心中所念：道古一脉需他守护，这个弟子在分神虚弱中同样需他守护。玄罗到来宋天早已知晓，一直未点破。

## 四、第二次分神：十五年的煎熬

| 时点 | 状况 |
|---|---|
| 第3年 | 光环如旧，族人渐习惯 |
| 第6年 | 皇城天空无昼夜之别 |
| 第10年 | 新生孩童以为天本如此；十年分神传遍吉族，道古族人、极古族人前来观看。王林头顶光影四分五裂化作无形碎片，承受难以想象的痛苦 |
| 第13年 | 祖庙散出属于**古祖魂血**的奇异力量，笼罩四周、阻神识探寻、阻人踏入；玄罗神识无法沉入，自忖亲入亦不可得。宋天在原始山骤然睁眼惊疑 |
| 第14年 | 王林气息消失、不知死活，连第一次分神散出的意志都感受不到；唯一「或许没死」的凭据是那十八道光环仍在 |

- 内情（无人知晓）：半年前碎片已完全成末、完整分裂，但**分裂后无法融合**。王林凭莫大意志强行融合数次皆败，意志愈发微弱；身内生机全无。每次身躯外浮现大量光点、凝聚出光影轮廓后再度不稳、轰然崩溃、光点黯淡消散。**已失败十三次**；在无神智与意识的状态下展开第十四次融合。

## 五、第十五年：光环崩碎

- 一道光环急速暗淡，一炷香后崩溃成碎片消散 → 只剩**十七道**。
- 皇城哗然：始古皇尊出寝宫倒吸口气；计都飞至半空紧张握拳；宋天立于牛角山巅惊疑。
- 族人议论指出关键设定：**古道三分神每一次分神并非无休止，时间上有极限**；疑王林已达第二次分神的时间界限。
- 宋天判断：**若十八道光环全部消散前王林仍未完成融合，则魂飞魄散。**
- 玄罗神色大变，一眼看出缘由，从天空直奔祖庙，一步踏入即被莫大之力轰然反弹，闷鸣声中被生生挡在庙外。
- 章末：第二道、第三道、第四道……直至**第十一道**光环陆续破碎。

## 六、旁线：始古皇位交接

- 始古皇尊似放弃了一些不切实际的想法，不再理会光环，转而指导**计都**继承皇位；计都渐掌始古一脉诸多隐秘。距其继位之日**不到四十年**（对古族而言漫长却不遥远）。

## 七、悬念

1. 王林能否在剩余光环耗尽前完成第十四次（及以后）融合？
2. 古祖魂血之力为何既护持又隔绝，连玄罗亦不得入？
3. 若成功，能否叩关踏天之桥第四桥？
