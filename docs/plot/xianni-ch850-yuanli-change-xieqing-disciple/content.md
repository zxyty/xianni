# 第七卷 名震罗天 第850章 元力改变

## 一、横云山：拒绝姚冰云
- 王林已彻底看透姚冰云的道心——**其妹是姚冰云唯一的道心，同样也是唯一的破绽**。
- 王林未抬头，平淡回应：“以我之力，无法助你。”
- 姚冰云神色黯淡，沉默许久后自语“或许，是我听错了”，眼角含泪，转身走向天际消失。

## 二、因果小成，踏入第二步窥涅
- 王林闭目沉浸于**因果之道**，体外缓缓凝出**黑白二色阴阳双鱼虚影**，凝于身后缓慢旋转。
- 双鱼每转一次即生吸力，吸摄四周天地之力化作元力融入体内，并分出一股送入**天逆珠**被其吸收。
- **天逆珠表面亦形成阴阳之相**，在王林元神中缓缓旋转。
- 至此王林之道在因果上**小成**，因果意境凝为实质，标志其意境真正踏入**修道第二步——窥涅修士**。
- 若他愿意，**刹那间即可降临天劫，渡劫后便是窥涅初期**（本章尚未渡）。

### 王林对三步大道的推演
- 第二步含**窥涅、净涅、碎涅**，均带“涅”字。
- 结合他所见的第三步，唯有**完全理解、明悟涅意并掌握规则**，方能抵达第三步：**“天道无尽，大道无涯”**。
- 王林心中存疑：“证道之旅，真的，只有这三步么？”

### 异象
- 睁眼时**左眼含阳、右目蕴阴，仿若日月**，极为诡异。
- 阴阳双鱼旋转骤然加剧，以横云山为中心，**整个青灵星灵力剧变、形成无形风暴**，全星修士皆可清晰察觉，磅礴灵力疯狂向横云山凝聚。
- 王林收势并判断：**“元力正在改变，但却不能在这青灵星上，否则的话，此星将会崩溃。”**

## 三、谢青求道，成为唯一记名弟子
- 王林欲踏虚空离去时，目光穿透无数里，看到**谢姓老者以凡人之躯朝圣般走向横云山**。
- 王林遂重新盘膝闭目，静待**半个月**一动未动。
- 老者半月间越走越快：每逢疲惫不堪，体内便有**一股热流旋转弥漫全身**，疲劳顿消、精神大振。
- 抵达山下后，他**膝盖破碎、鲜血流出仍毫不停顿地爬上山顶**，心中有一股琢磨不透的信念支撑。
- 途中顿悟：**“人为鱼，天为水，道为网，执网者为造化。”**（自嘲“原来，我，就是一条水中之鱼”）
- 见到王林蕴含日月乾坤的双目，如春雷贯耳、几近灵魂出窍，恍惚见到黑白阴阳之相，当即跪拜：**“请传道于我。”**

### 王林的判断
- 此老者乃青灵星德高望重之凡人，**这类人自身便有道心，只是飘忽不定却真实存在**。
- 论适合修道，**心灵干净的童子反而更佳**；但此类人一旦得道，**修为往往不高，对道的理解与感悟却极深，未来之路更为绵长**。
- 障碍：**年纪老迈、身体经不起灵力冲击**，修道艰难。王林直言“你寿元不多，修道，绝非朝夕之事，可斟酌清晰”。
- 王林看其双眼，**隐约在老者身后看到一幕轮回**。

### 老者的自述与结果
- 三岁学词、六岁学诗、**十四岁名震皇城**，却始终茫然，总有被天地束缚之感；年迈辞官告老、教化学子。
- **“那一日的风入居室”**与河畔顿悟令他找到茫然的根源，遂哪怕死也要来求道。
- 自报姓名：**谢青**。
- 王林决定：**“我之一生，没有任何弟子，你之道，与我有因，可收你为记名弟子。”**
  - 将**横云山**暂送谢青修炼；
  - **不传任何道法神通，只送一场感悟**——抬右手一点，身后阴阳双鱼随之融入一指，隔空落在谢青眉心。
- 谢青身子一震、目露迷茫倒地；**一天后醒来**，盘膝于山顶闭目感悟。
- 王林大袖一甩，雾气弥漫脚下，直奔虚无消失于天际。

## 四、纸符线索：仙选族无果
- 王林未立刻离开青灵星，而是找到**仙选族**所在。
- 取出储物袋内**仅剩的那张纸符**询问，仙选族众人**只有一种极为熟悉的感觉，却没有任何印象**，线索中断。

## 五、荒星闭关：元力化黑白二气
- 王林化作长虹驰于星空，神识散开寻找理想打坐之处。
- **数日后**择定一颗**土黄色、荒无人烟、灵气几乎枯竭**的星球，冲入稀薄罡风层落地；四周充满**瘴气**（凡人吸一口必死，对王林无影响）。
- 右手虚空一指，**大地隆起凭空形成一座山峰**，山腰中出现一座刚成的洞府。
- **塔山自王林身后虚影现身**，坐于洞口护法；其**伤势有所好转**，目光如炬警惕四周。
- 王林运转元力，阴阳双鱼再现并高速旋转，**抽摄这蛮荒星球所有残存灵力**。
- 关键变化：**元力由无色一分为二，化成黑白二气**——
  - **白气留在体内**；
  - **黑气弥漫身外**；
  - 以其身体形成**一个完美的循环**。

## 六、伏笔：姚云持镜追至
- 星空中，一名**踏大片红云**的中年男子正直奔王林所在。
- 其右手持**一面铜镜，镜上有一条红线指点方向**（追踪法宝）。
- 此人相貌颇为英俊、目光平静，**正是姚冰云道境中试图救下姐妹二人的姚云**。
- 与道境中相比：**相貌未变，神色却见沧桑**；尤其双目平静之下**藏有一丝极深的妖异，如火苗忽明忽暗**。

## 七、待解伏笔
- 王林尚未渡劫，**窥涅初期**只差一念之间。
- **纸符**来历仍无解（仙选族只觉熟悉）。
- **谢青**身后的那一幕轮回来历未明。
- **姚云**双目中的妖异之芒、其追来的意图，以及与姚冰云之妹的关联，均为后续悬念。
