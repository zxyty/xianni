# 第1692章 当年的约定

## 一、太古星辰：七彩道人临场
- 七彩之色骤现星空，正仓惶后退的**掌尊**脚步一顿、停止逃遁，神色苦涩复杂地望向七彩之光。
- 先前在**李广弓**下以法宝抵抗、侥幸留命的**第七仙妃**，望向七彩之光的目光同样深深复杂。
- 王林瞳孔收缩，心道「他果然来了」，再无犹豫。

## 二、王林的退路：玉简·黑洞漩涡
- 王林连退数步，虚空一抓取出一枚**玉简**，一把捏碎。
- 玉简化作碎末，碎开处幻化出**拳头大小的黑洞**，爆发惊天吸力、散出幽光，笼罩王林要将其吸入。
- **七彩道人**（虚幻身影、中年男子、道袍、仙风道骨、七彩缭绕）见状双目奇异之色一闪：「想以这个方法离开，不行。」

## 三、七彩指风 vs 彩玉七手印
- 七彩道人随意一指，星空七彩光芒万丈齐聚身前、融入一指，化作**七彩指风**，速度超过肉眼，瞬息破开天地，临近王林不足七尺。
- 生死危机弥漫王林心神，但其神色毫无慌乱——一切在计算之内。
- 黑洞漩涡中**伸出一只女子玉手**，中指戴**翠绿色扳指**，径直迎上指风。
- 指风无声崩溃，却化作七彩之气如七条毒蛇钻入玉手；漩涡中传出受伤闷哼。
- 玉手一颤掐起印诀，一晃化作**七份**，七只一模一样的玉手重叠成圆，散出七彩之芒——即**彩玉七手印**，轻轻一拍便直奔七彩道人。
- 与此同时，王林身形一闪，被黑洞漩涡彻底吸走，消失在太古星辰星空内。

## 四、余波与身份揭示
- 七彩道人挥袖，身前星空荡起七彩波纹迎上手印，轰轰之声后一切烟消云散。
- 七彩道人闭目良久，睁眼望向王林消失的**东方**，眼露追忆：
  - 「彩玉七手印……应该是叫这个名字。可惜我获得的只是神通，没有全部记忆。」
  - 「不过，想要在我面前逃走，不行。」
  - 「**李广弓，也完成了其使命，也该到了收回的时候。**」
  - 随即向前一步，刹那消失无影（追踪王林）。
- 星空只留掌尊与第七妃，二人皆震惊于手印与玉手主人的身份：
  - 掌尊：眼露精光，「原来是她」。
  - 第七妃：面色苍白、后退数步，失声「**大姐……她没死**」。
- **玉手主人 = 仙尊第一妃，亦是七彩仙尊道侣的亲妹妹。**

## 五、场景切换：云海星域深处的裂缝
- 界内**云海星域**深处、当年**妖宗**之外，有一道**巨大裂缝**；罕有人知其通往何处，内中凶兽众多，时常冲出肆虐。
- 裂缝极深处为一片**漆黑的陌生星空**。
- 其中有一只**数千丈大小的巨兽**：形如狮子，头生一根**独角**。
- 独角前方，盘膝坐着一名**风华绝代、相貌绝美**的女子，此刻**面色苍白**，盘膝双手掐诀，不断在身前挥舞（与彩玉七手印的施法方相呼应）。

## 六、要点与悬念
1. 「当年的约定」指向第一妃与王林之间的旧约——王林的玉简即是召唤/接引之物。
2. 七彩道人自承记忆残缺、只得神通，暗示其身份非完整的七彩仙尊。
3. 李广弓「使命完成、该收回」，预示该弓归属将生变。
4. 第一妃「没死」这一事实对仙尊诸妃体系是重大冲击。

# 第1601章 洞府主人现身：矾姗璐自陈仙尊第一妃，与王林结盟谋七道宗山门

## 一、脱身与重逢
- 盘膝女子身前一个拳头大小的黑洞漩涡不断吞噬四周黑暗，膨胀至一丈大小时，**王林**自其中一步走出；王林走出刹那漩涡崩溃，化作点点晶光消散。
- 王林抱拳道谢。女子睁眼，目露疲惫，感慨「当年一别，你修为尚还低弱」，本以为王林已忘记约定，直到一年前收到玉简传来的神念才知他未忘。
- 王林答：当初她助其离开此地之事不会忘，只因琐事缠身来迟。随后他俯视身下这头在星空中奔跑的巨大**狮兽**，索性盘膝坐在一旁。

## 二、退路的谋划（回溯）
- 王林决定前往**太古星辰毁界外的远古仙域**时，已想好退路：
  - 一旦**两弓之力**用完，**掌尊**必定迫杀；
  - 即便他并非如掌尊所说只剩两弓之力，但界外是**七彩道人**的天下，此人一旦出手，以王林修为绝难逃走。
- 故一年前在**转轮阵法**吐纳时，以女子当年所赠玉简为介传出神念，与久未联系的女子达成共识。
- 寻求此女相助的原因：王林由种种蛛丝马迹与自身所知，有**六成信心**判定她就是失踪的**仙尊第一妃**。神识沟通后，女子确认了这一点。

## 三、身份揭示
女子自陈三重身份：
1. 曾是**七道宗七彩仙尊的第一妃**；
2. 是七彩仙尊道侣**矾珊梦的妹妹**；
3. 本名**矾姗璐**。

往事：当年**九阳之二相争**时，七彩仙尊为获宝物，歹毒地以其姐矾珊梦为诱饵，趁机得手，此后**封死了七道宗**。矾姗璐被七彩仙尊所伤，修为始终未能恢复。

## 四、洞府界的真相与合作基础
- 王林在神识交流时已知晓：此地的一切**只是一个洞府（洞府界）**，女子予以确认，表示不再隐瞒。
- 女子在此无法相信任何来自**仙罡大陆**的人；与王林之间**没有利益冲突**，故可合作。
- 她并直言：洞府界毕竟是虚幻而出之地，「这里的一切众生，实际上说它是假，也的确是假的」。

## 五、仙罡大陆的门槛
- **地理与格局**：仙罡大陆极大，战乱纷纷，各宗派之间少有和平；欲立足必须有一处**宗门山门**，稍好之地皆已被人占据，以王林当前修为「抢不到山门」。
- **走出洞府界**：古往今来极少听说有人从各宗派洞府界内走出到仙罡大陆。
- **仙罡入界之罚**：前往仙罡须付出极大代价、承受入界之罚；据女子所闻，**只有在洞府界内修为到了空劫之后，方有一些把握度过**。

## 六、合作条款（双方约定）
| 方向 | 内容 |
|---|---|
| 矾姗璐 → 王林 | 透露其姐**矾珊梦未死**，人在仙罡；由矾珊梦去求**师尊**出手，在仙罡**接引**王林，减少入界之罚 |
| 矾姗璐 → 王林 | 若王林杀**七彩仙尊**，**七道宗山门归王林**，姐妹二人半点不取（因二人本非七道宗之人） |
| 矾姗璐 → 王林 | 得山门后若欲继续修炼，姐妹二人可**引介王林入大魂门**（仙罡东部**九宗十三门**之一，二人为其核心弟子） |
| 王林 → 矾姗璐 | 帮她**带着洞府之修离开此地**，去往仙罡大陆 |

- 姐妹二人的动机：「当年我二人瞎了眼睛，一同心系于七彩仙尊」——银牙紧咬，满面怨恨。
- 王林全程神色平静不起波澜，只答「我在听」，这份定力令女子眼中露出一丝欣赏。

## 七、悬念收束
王林沉默半晌后追问：「除我之外，这洞府界内其他修士呢？」女子正要回答，忽然**面色一变猛地回头**，同时王林**神色骤然阴沉，直接转头看向身后**——本章在此处戛然而止。
