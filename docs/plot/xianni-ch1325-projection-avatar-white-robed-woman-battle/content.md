# 第九卷 云海之巅 第1325章 投影分身（第二更）

## 一、战前定性：王林主动求战以验猜测

王林并未选择逃遁，而是刻意与一路尾随的白衣女子一战，目的是验证自己长久以来的猜测——此女并非第三步大能本体。

- 若对方真是第三步大能，即便他用缩地成寸也难以逃脱；
- 若对方不是，「他王林也绝非好惹之辈」。

## 二、翻天印：逆转天地的开场

王林右手一翻，心神蕴含天地，于本无天地之分的星空中化出无尽虚影：云雾弥漫、一分为二，厚重之雾下沉成大地，轻灵之雾上升成天。随即右手下按，大地成天、天空成地，连白衣女子身体亦随之逆转。

白衣女子当场道破：「蓝梦道尊的翻天印——他竟然将此神通传你」。此为蓝梦道尊大神通之一。

- 女子掐诀低语，散出白光对抗，其所施展的裂缝随即崩溃、白光瓦解；
- 危急中吐出一枚**玉佩**，形成白色防护，星空大量碎裂，天地重叠后虚幻云雾消散，女子面色苍白但未死。

## 三、王林的当面拆穿（本章题眼）

王林冷笑列出三条判据，断定对方为「区区投影分身，只不过天人第三衰修为」：

1. 若真是第三步大能，岂会让他轻易走掉；
2. 若真是实体，近前之时他不会「没有闻到丝毫」；
3. 若真是本体，何须以法宝对抗翻天印。

并追加死罪一条：此女「没有血肉」，却吸他所谓**神性**，还用幻术化作他心神之人（对应第1237章兰妃分身以李慕婉容颜示人一线）——「单单这一点，你就必须要死」。

女子内心承认小看了对方：与王林相遇本是偶然，本以为万无一失，仅一次见面便被看出端倪，二次交手更处下风，并暗叹「可惜本体无法前来」。

## 四、法术交锋清单

| 出手方 | 手段 | 效果 |
|---|---|---|
| 王林 | 呼风唤雨界（十丈→千丈） | 其内碎片大陆战魂成千上万飞出，身带乳白色气息咆哮攻击 |
| 白衣女子 | 灭灵之光（黑光） | 黑光散开，呼风唤雨界随即涣散为成千上万份分护每一战魂，全部攻击被抵消、战魂无损 |
| 白衣女子 | 黑光凝成黑色长剑 | 天地色变，剑斩王林 |
| 王林 | 光影盾 | 聚星辰之光与星空一切光束成巨大光影，光影崩溃大半但将黑剑**折射反弹**回击女子 |
| 王林 | 血剑（虚空一抓，血光滔天） | 破其无数防护，击裂护体玉佩（咔咔裂开一道缝隙），女子喷血急退、身影模糊消失 |
| 王林 | 双目五道本源旋转扫视 | 重新看清隐匿的白衣女子 |

## 五、疑点与转折

- **喷血疑点**：王林判定其为无实质的投影分身，但女子竟能喷出鲜血，令他瞳孔一缩、心神一愣，来不及细想。
- **本尊救我**：女子转身念咒，自开裂玉佩的光芒中虚幻探出一只**洁白如玉的手臂**，向追来的王林轻轻一点。
  - 星空停顿、万物运转静止、一切光芒黯淡，手指按去的轨迹尽数崩溃；
  - 王林体内爆发的生死危机**超过了当年水道子**；
  - 王林合成千上万份呼风唤雨界为一，护于身外一丈，并再施光影盾。
- **抵挡进程**：光影盾一碰即颤抖崩溃，反射之力未能让手指有半点停顿，光影盾彻底瓦解；手指继而按在呼风唤雨界上，界身剧颤，战魂凄厉、以乳白色气息环绕对抗——本章在此中断。

## 六、承接与伏笔

- 白衣女子背后存在一位可远程降指、实力远超水道子的**本尊**（未现身、未具名）。
- 「吸神性 + 幻化心中之人」的手法与第1237章兰妃分身以李慕婉容颜乱王林心神一脉相承，可视为同一线索的延续（本章未明言二者关系）。
- 王林与蓝梦道尊的传承关系在此章由敌手之口坐实。
