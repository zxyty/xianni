# 第九卷 云海之巅 第1152章 山谷之内

## 一、战况：王林 vs 五毒门毒婆子

### 王林的优势来源
- 修为达到**净涅**后，**白凡六大仙术**威力渐显，不似窥涅时那般。
- **青霖所送造化**使王林对白凡仙术有更深层次的体会。

### 交手过程
1. **呼风仙术**化五条黑风黑龙 → 撕碎毒婆子第一口气所化**赤雾** → 五龙融合为一把**半透明黑色长枪**，锋锐惊天，不理黑雨与毒灵印，直逼老妇人。
2. 老妇人第三口气吹出、大袖甩出**带鸡冠角的小蛇**之际，黑枪已逼至不足十丈；她被迫疾退，双手掐诀，全身皮肤幻化**黑鳞**，形若人形凶兽。
3. 雕像目光所化**毒印**袭向王林胸口。王林不退：右掌前伸至距毒印不足七寸，左手成指**连点右掌背两下**，狂暴牵引方圆百丈、千丈天地元力入掌。
4. 掌心爆发巨响，**震动整个蛮荒大陆**，冲击横扫，第二口气所化黑雨被震散；王林亦双耳欲聋，后退数步。毒印崩碎，元力倒卷轰在虚幻雕像胸口，留下**黑色掌印**并使雕像四分五裂。
5. 鸡冠小蛇破开冲击袭来，王林虚空一抓开**储物裂缝**，放出**银衣女尸**迎战，自身越过战场直冲毒婆子。
6. 毒婆子咬破舌尖欲喷毒血，王林抬手一指喝“**定**”，无形丝线缠身（**一字定身**）；毒血未喷出而倒流入腹，加之神通被打断，毒血反噬，其身大片溃烂、惨叫不止。
7. **黑色长枪**自其胸口贯入后爆开，肉身崩溃化作血水，**元神欲逃被王林大袖收走**。

### 战后判断
- 王林心有余悸：毒婆子毒攻神通足以同阶纵横，修为高于她者若无防备中毒亦可能遭毒手。
- 王林所杀**净涅中期**者已非少数；此战对手修为略高于他。
- 王林**连老妇人的名字都不知道**，认为此杀莫名其妙——只因对方咄咄相逼、出手即欲取其性命。

## 二、收尾：兽潮、骷髅阵与入谷
- **黑猿**绕过战场、掠过八骷髅封锁的山谷，身后庞大兽群冲入山谷；八骷髅失去老妇人神识操控，相连闪电寸寸崩溃。
- 王林遥遥一望，黑猿会意继续向远处奔逃，凶兽尽数追去；少数扑向王林的凶兽被其**大袖一甩尽数击杀**。
- 王林逐一掐诀拍下，将八个骷髅头**封印**成拳头大小的灰色骷髅悬于半空。判断这是一套**阵法所用法器**，但不立刻收走——因不知山谷内有何物，且**神识在阴雾内无法穿透**；心念一动即可解印恢复围困。

## 三、山谷之内所见
- 入口处：一具全身溃烂、恶臭难闻的**男性骸骨**。
- 中心处：四具**全身溃烂、双目灰暗透出茫然**的尸体，同样恶臭。
- 盘膝而坐者：**中年男子**，面色苍白无血色，眉心隐现**一条黑线**，元神已处死亡之际，中的是绝顶剧毒。王林判定其修为为**净涅后期**，并想到——能毒死净涅后期修士的毒，可与**欲仙欲死之毒**相比。

## 四、中年男子（施某）的请求
- 开口“多谢阁下救命之恩”，虚弱不堪。
- 判断王林来此“无非也是为了**玉简与丹方**”，称即便自己不交，对方也有办法打开其储物空间；愿主动奉上，**只求痛快一死**，不再受**千紫虫线毒**折磨。
- 说明四具尸体是他的**弟子**，为护他而中**五毒门毒婆子**之毒暴毙；若无此劫，日后当为门派翘楚。
- 因毒发无法运转元力，请王林**借一丝元力**打开储物空间取物。

## 五、悬念（章末）
- 王林始终一言不发，抬起右手向前一拍，元力浩荡而出；在临近中年男子身体**三寸**的刹那，**元力突然一变**——章节至此中断。
