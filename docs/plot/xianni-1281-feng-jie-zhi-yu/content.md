# 第九卷 云海之巅 第1281章 封界之玉

## 一、水道子的杀意与判断

- 王林身上接二连三涌现的**本源之力**吓破了水道子的胆，其所见的三道本源已超出想象。
- 水道子推演：王林若不死，千年后三道本源大成、踏入第三步，足以对抗滞留空涅初期数万年的大能，且『根本不是他的对手』。
- 结论：「这种逆天的人物，必遭天嫉」——不杀王林，日后天上地下再无水道子半步生机。他更怀疑王林是**第四步传世之人**、是可比天地间最强法宝之人。

## 二、王林的五道本源（本章最大揭示）

水道子只看到三道，实为五道：

| 序 | 本源 | 由来 |
|---|---|---|
| 一 | 生死本源 | 崩溃了生机，明悟生死 |
| 二 | 因果本源 | 碎灭了古星，感受因果 |
| 三 | 真假本源 | 眉心意境之星消散，诞生真假 |
| 四 | 火焰本源（隐晦） | 体内**朱雀之火**三次蜕变所致 |
| 五 | 雷霆本源（深藏） | 吞半条太古雷龙、转化元神千年、吸收太古之族天雷 |

### 火焰之道的层级

- 第三次蜕变后，王林成为**世间火之掌控者**，一切火焰神通在其面前皆要屈服。
- 对修火者：可引动其体内火焰神通，杀人于挥手间。
- 对不修火者：可燃其**怒火**——「人之最强，便是怒火」，无形而存在，驾驭不住必死。
- **焚火**：燃烧火焰之火，威力惊天动地。
- **道火**：焚烧敌人意境，已非法术、非神通，而是**无限接近道术**。

### 五道本源的意义

- 四道即已超过**掌尊**、**青霖**、**封界之尊**，超过太古星辰界内界外一切修士。掌尊若知，「定会不惜一切代价收王林为弟子」。
- 雷霆一道若再进一步，可脱去「代替天道行使雷霆」的『代替』二字；若再吞噬天地初开诞生的**九种雷力**，则雷之本源大成，得**行道之力**——「别人是替天行道，而王林，则是自身行道」。
- 王林被喻为一粒『成为太古至尊、真正远古仙人、传说中第四步大能』的种子。
- 五道本源正是在水道子造成的生死危机下、**不破不立**的冲击中诞生的，反使一切逆转。

## 三、决战：修真星 vs. 五道本源一击

- 水道子神色疯狂、惊恐与兴奋交错成变态狰狞，挥动那颗承载**十五亿水道门徒**的巨大修真星，散发第三步惊天之力轰落。他明知此击后自己会受伤、需闭关数千年恢复、并毁掉所收集的十五亿门徒，仍不退缩。
- 王林眼中一片平静，「生也好，死也罢，一切都是过眼云烟」，唯割舍不断父母亲情、**婉儿**爱情、**司徒**与**清水**的友情，索性带着一切牵挂走向死亡。
  - 名句：「死亡的烟火，可比天地间最灿烂的星云……若心中有所牵挂，那么即便是死亡，也是璀璨如星，也是光芒万丈。」
- 王林喊出「你欲杀我，那么我们便一起同归于尽」，双臂外挥，三道漩涡疯狂而动，雷与火本源云涌轰出。

### 这一击的规格

- 超过一生的一百拳、超过射神车、超过其一生所施展的一切神通，是**最后一次神通**。
- 代价：毁灭自身五道本源，以「半只脚踏入碎涅的小小修士」之身，打出堪比**第三步空涅**的一击。
- 战果（地理级破坏）：
  - **五阶星域**整个轰轰碎灭；
  - **六阶星域**裂开五道巨大沟壑，生生分离，成为此后云海之永恒地貌；
  - **七阶星域**亦被撕开一道沟壑，一分为二。
- 威力足以毁灭一切碎涅修士、一切天人衰劫大神通，**青龙圣皇**在此一击下亦必死无疑。

## 四、惊变：封界之玉

- 伏笔回收：此战前，王林曾融合**天运子**不顾一切推衍、最终崩溃的**逆行者珠子**，撕开心神迷雾看到一线生机——那生机是**金彪子（刘金彪）**身上的一枚**玉佩**。
- 该玉佩融入王林体内后，连同**天逆**一起消失无影，水道子如何探查都毫无发现。
- 就在本源将爆、同归于尽的瞬间，玉佩自王林体内金光闪出，悬浮身前。
- 水道子反应：剧烈颤抖、无尽惊恐慌乱、面色瞬间惨白无血色；其神通所化修真星停顿于星空，十五亿门徒轰然颤抖。
- 水道子惊呼身份：「这是主人的气息……这是**封界之玉**，这是主人从**远古仙域**降临时带着的唯一之物」——其主死后他惶惶不安数万年，此刻旧日恐惧总爆发。

### 结局一击

- 玉佩金光中幻化出一只**通体如玉、金芒缠绕的手指**，速度不可想象，直按水道子眉心。
- 水道子因对其主的恐惧弥漫，「不敢反抗也没时间反抗」。
- 手指按在其眉心的**七彩钉子**上，下压两寸——本已深入头骨五寸的钉子，被彻底按进水道子头颅之中。

## 五、要点速记

1. 本章确立王林=古往今来拥有最多本源（五道）的至尊，且此为不破不立之果。
2. 火焰之道层级：怒火 < 焚火 < 道火（近道术）。
3. 王林以自毁五道本源换取一击，云海星域地貌被永久改写（五阶灭、六阶五沟、七阶一沟）。
4. 刘金彪的玉佩=封界之玉=封界之尊（水道子之主）自远古仙域携来之唯一物，由天运子逆行者珠子指出的『一线生机』。
5. 水道子眉心七彩钉子被彻底钉入，胜负逆转。
