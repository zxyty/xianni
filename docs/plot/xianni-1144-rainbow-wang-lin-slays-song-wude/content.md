# 第九卷 云海之巅 第1144章 彩虹

## 一、紫道宗压境

- 黑色庞大灵兽载着紫道宗**少宗（卢迪）**与老者**宋五德**，自西方全身没入**莫罗大陆**，直奔东部**归元宗**。
- 紫衣青年狂笑宣告：“从今以后，这归元宗，就归本少宗所有”；宋五德以苍老阴森之声弥漫全陆：“紫道宗少宗来此，归元宗，还不快来拜见”。
- 宋五德本不喜张扬，但认定归元宗生死尽在掌控，遂纵容少宗性子。其右手一挥化紫风飓风横扫，雨水倒卷、雷电被撕碎成弧形电光，如花绽放。
- 归元宗弟子自打坐中惊醒，皆感西来碾压之威。

## 二、归元宗四大长老赴死

| 人物 | 表态 |
| --- | --- |
| 李向东（东苑山脉之顶，中年男子长老） | “师尊刚离开人世……即便是死，也要死的顶天立地”，化长虹西向 |
| 西北山峰两位老者 | 叹息后相视咬牙，认定归元宗存亡之秋，“不能再忍” |
| 吕烟菲（南部山脉红色阁楼） | 红衣煞气凄苦，点破宋五德乃师尊当年手下败将，今师尊归墟故其亲至；立誓“卢迪，我吕烟菲宁死，也不会屈从于你” |

- 四大长老之后，嫡系弟子群起西向，**孙芸**在列，眼露誓死之色。
- 孙芸心念浮现两个身影：黑发消瘦、其貌不扬却平静如水者；白衣白发、一指扫去天地崩溃者。二者在她脑中重叠——即王林的两副面目。

## 三、王林的抉择

- 王林立于悬空道观，看长虹远去，冷静盘算“如果归元宗被灭，自己将要何去何从”，皱眉道：“真是麻烦”。
- 袖子一甩，脚下波纹回荡，瞬间空间挪移离去。
- 缩在裂缝中始终低吼却心怯的**紫目蟒**，待其离开方敢冲出朝其消失方向嘶吼。

## 四、拦路与瞬杀

1. **现身**：西部紫风之后，虚空波纹中走出白发男子，煞气惊天，黑色灵兽当即一顿。
2. **交涉**：宋五德自报“在下紫道宗宋五德”，请“给个薄面”让路。王林答：“给你薄面，立刻滚出这里，从此之后莫要踏入一步”。宋五德看不透其修为，面色阴沉；紫衣青年狂笑挑衅。
3. **杀戮之气**：王林抬手，杀戮之气滔天而出，冰寒使四周雨水咔咔化作冰晶。灵性极高的黑色灵兽感知危机，不待吩咐自行疾退。
4. **护主**：宋五德一巴掌把紫衣青年拍在灵兽背上，大袖卷灵兽后退，喝令“速走我杀了此人，再与你汇合”，随即冲向王林。
5. **唤雨**：王林左手指天喝“唤雨”，方圆百丈、千丈、万丈雨水尽被天地之力裹挟，疯狂冲击宋五德。宋五德震撼——这两种神通他“根本就前所未闻”。
6. **定**：一字“定”出，宋五德身形凝滞半空，无尽冰晶呼啸凝聚，将其封入巨大冰晶。
7. **斩**：王林虚空一抓，储物裂缝中取出**锈迹铁剑（次空涅剑）**，身随剑走一斩，天地被极光之芒笼罩；冰晶崩溃，内中一片血色，宋五德肉身四分五裂、元神同碎，化元力扩散。

> 数息瞬杀。作者评断：杀戮之气、唤雨仙术，任一都足以让人叱咤修真界，再加次空涅剑一击，即便净涅后期不死也要脱层皮；加上王林阅历经验，“这宋五德，死的不冤”。

## 五、彩虹收束

- 王林转身逼向未逃远的黑色灵兽与其上的紫衣青年，向前一步迈去。
- 紫衣青年极致恐惧的凄厉尖叫，清晰传入赶来的归元宗四大长老耳中，落入吕烟菲心神。
- 天晴雨散，初阳下长空挂起一道模糊彩虹；彩虹中追向黑色灵兽的白发身影，深深印在吕烟菲眸中。

## 六、要点与伏笔

- 归元宗老祖（吕烟菲师尊）新丧，是紫道宗趁虚而入的直接诱因。
- 王林出手动机是功利权衡（归元宗被灭则自身落脚成问题），而非侠义，符合其一贯冷硬作风。
- 孙芸完成对“黑发平凡者”与“白发强者”身份的心理重叠，为后续揭破身份埋线。
- 紫衣青年卢迪尚未伏诛，王林已起追杀之势；紫道宗后续报复为潜在因果。

## 归属说明

- 本片段中的“白发男子”“白发修士”即**王林**（此阶段对外多以化名『许木』行事，本章未直呼其名）。
