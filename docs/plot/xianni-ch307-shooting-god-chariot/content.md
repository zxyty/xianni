# 仙逆 第307章 射神战车

## 一、九间与第十间的矛盾

- 王林进入天宝上人洞府，内有石室九间，此刻全然一空。
- 天宝上人遗留的**金色铁片**中详细记录了开启此洞府的方法，并明确告知：洞府共**十间**石室，封印**射神车**的正是**第十间**。
- 王林神识数次横扫四周，未发现任何隐藏石室；亲手抚摸正中最大石室的内壁，触手冰凉、别无异处。

## 二、铁片化影，洞府下沉

1. 王林一拍储物袋取出金色铁片，铁片瞬间散发刺眼金光、传出炙热之感。
2. 王林松手上抛，铁片光芒更盛并开始融化——不落液体，而化作丝丝青烟，成**蘑菇形状**升起。
3. 青烟中凝出一个**虚幻人影**：仙风道骨、仙须无风自动、面貌英俊且具威严——王林判定此即天宝上人之貌。
4. 幻影双手掐诀，打出一道金光落在四周墙壁，整座洞府轰鸣**下沉**。
5. 下沉停止后，正中内壁方向出现一道**散发紫红色光芒的门**——加上此处，石室恰为十间。
6. 幻影再捏古怪印诀点向紫红门，随后连人带铁片彻底消散一空。

> 王林评价：天宝上人不愧是钻研炼器之术的高人，其洞府即便被人发现，也极难寻到真宝。

## 三、第十间石室：三辆射神战车

王林依样掐诀按门，门向两旁缓缓打开，神识扫入。

**石室**：约几十丈大小，除一些凌乱的炼器材料外，最显眼者为正中三座庞然大物。

**射神战车形制**：
- 上部：充满利刺的狰狞外表，其上披着好似兽皮一般的物质；利刺中最中间一根足有一人多粗，其上闪烁寒芒。
- 下部：形似凡人攻城掠池所用战车，有四个巨大轱辘。
- 尺寸：单车约十丈；三辆并排几乎占满整个石室。

## 四、三具兽魂与魂链之锁

- 王林踏入瞬间，三辆战车各涌现一具**虚幻兽魂**，比战车更为狰狞，幻化而出即咆哮，声具穿透力、震人心魂，连山峰都晃动落下青灰。
- **兽形**：头大如斗成三角形，身似牛，充满暴虐之力；身后一尾如蛟，尾端竟生口鼻眼，说其双头亦不为过。
- 三兽形貌相同、大小有别：**正中战车之魂体型略大**，另两只稍小。
- 王林搜索**吉神涂司**的记忆，未找到关于此兽的任何记录（天下之兽众多，涂司不识亦不足为奇）。
- 三兽红色巨眼齐盯王林，暴虐争先扑咬；王林神色如常，仅退后一步。
- 扑至身前三尺外时，三兽身上骤现**无数手臂粗细的铁链**贯穿全身，闪烁乌芒，将其硬生生拽回锁于战车之上。
- 唯中间大兽在拽动下仍硬冲出一尺，方被生生拽回。三兽剧烈挣扎，四周洞府随之颤动、好似随时塌陷。

**铁片记载的关键情报**：射神车上有兽魂，但已被天宝上人以**魂链**锁住，**逃不出三丈之外**；铁片同时详载操控此车之法。

## 五、王林起手炼车（章末进行时）

- 王林定气凝神，双手抬起，按铁片要求迅速打出一个个古怪法诀。
- 法诀脱手即化为**黑色光圈**；随其动作越来越快，光圈越来越多。
- 待石室内光圈已然上百，王林低喝一声，目光盯向**正中间那辆战车**（即三兽中体型最大者所在）。

## 六、要点小结

| 项 | 内容 |
|---|---|
| 触发钥匙 | 金色铁片（天宝上人遗物），用后彻底消失 |
| 机关形式 | 铁片化幻影→掐诀→洞府整体下沉→现紫红门 |
| 目标法宝 | 射神战车 ×3，约十丈，四轱辘、满身利刺 |
| 附带风险 | 三具兽魂，被魂链限制在三丈内 |
| 王林手段 | 依铁片法诀打出上百黑色光圈，锁定最大那辆 |
| 悬念 | 兽魂来历不明（涂司记忆无载）；炼服结果未定 |

# 第307-308章：射神车封印与「恋女尸」

## 一、天宝上人洞府收尾（承第307章）

### 1. 封印兽魂、收取射神车
- 王林喝「封」，上百道黑色光圈化作残影铺天盖地套向中间战车。
- 车上兽魂咆哮不甘，缩回车内被光圈一一套住；战车升空并逐渐缩小，最终只有巴掌大，落入王林手中，被收入储物袋。
- **关键限制**：要使用此车必须先收服兽魂，而兽魂之强非王林可操控，故只能依铁片上的手法**暂时封印**，令其处于睡眠状态。
- 以同法封印左侧战车兽魂。

### 2. 第三辆战车与驱兽圈的取舍
- 石室内最后一辆战车上的兽魂最小，但仍非王林当前可收服之物。
- 该兽目睹两同伴被封印后愤怒咆哮不止：若是**当年的天宝上人**它还会屈服，但面对「自己巅峰时期一巴掌就能拍死」的修士，自尊不容低头。
- 王林摸手腕上的**驱兽圈**权衡：按理可锁住兽魂，但
  1. 此兽生前定是**仙兽**之类，驱兽圈能否困住尚为两说；
  2. 即便困住，吸收的灵力自己能否承受也是问题。
- **决策**：放弃冒险，直接打出上百黑色光圈，将此兽连同战车一并封印。

### 3. 射神车的性能推断（王林视角）
- 天宝上人未料到战车会被**化神期**修士获得——他认为只有**婴变期**修士才勉强达到使用标准。
- 天宝上人对此车威能颇有自信，且封印兽魂极强，王林判断威力不会让自己失望，**惟现在无法使用**。
- 能源机制：**不需任何灵石开启，完全以兽魂魂力催发**，可省却大量灵石；王林推测若真需灵石，怕是只有**仙玉**才能满足。
- 风险推测：不存在无始无终用不完的能源，兽魂在开启数次后会有所损伤，超过一定次数**可能消散**。
- 资料缺口：铁片内未记录射神车详情，王林归因于天宝上人临死前活气不多、只能挑重点记录，需自行研究。

### 4. 离场与后续伏笔
- 王林风卷残云收走石室边缘所有炼器材料，反复检查后离开。
- 在紫红门外按天宝上人手诀使洞府缓缓升高、恢复原样，随后走出洞府。
- 心境总结：此次**仙界之行收获颇丰但风险极大**——碎片崩溃时稍有不慎便已身亡；「风险越大，收获越大」。
- **伏笔**：因此，**叱虎的邀请**「倒要仔细考虑一下了」。

## 二、第308章 恋女尸

### 1. 仙界南部碎片
- 南部一处碎片上，三人为争夺一枚**结晶颗粒**大打出手，各种法术波动层出不穷。
- 数万里外的一处平原上，出现一名手持葫芦饮酒的中年男子——**与王林同是来自朱雀星之人**。

### 2. 中年男子与「婷儿」
- 目的：为「婷儿」取得**仙玉**，让其身体**千年不变**。
- 行至平原某处停下，追忆「当年我就是在这里与你相遇」，感叹物是人非。
- 右脚轻踏地面，整个人下沉入地底，久之抵达一处巨大洞穴。
- 洞穴中有一座独立**三层阁楼**，外被**青色之气**笼罩；男子直接穿过青气入内。阁楼格局与寻常人家无异，却有典雅出尘韵味。

### 3. 女尸出场
- 男子自储物袋取出一座**宝塔**，右手一抹放出白光，白光过后一具**身穿白衣的女尸**出现在怀中。
- 女尸相貌极美、出尘如仙女，肤色雪白却有一丝红意，「若说她还活着，怕是也有不少人会相信」。
- 女尸一出现便与阁楼环境融为一体，好似此地本就属于她。
- 男子含笑称「婷儿，你看，我们回家了」，抚其面、吻其眉心。

### 4. 自述往事
- 「当年我看到你第一眼，便认定，你就是我此生的妻子」——**「婷儿」之名为男子所起**。
- 为她**放弃了门派的掌权之位**、**不惜叛出师门**，声称「我不后悔」；「谁让他们说我是疯子呢，我知道，我没疯」。
- 末了抱女尸上二楼，称楼上有她的梳妆台，要为她化妆。

# 仙界碎片：痴恋女尸的中年男子与叱虎的传送阵之约

## 一、阁楼中的痴恋者（中年男子与女尸「婷儿」）

- 场景：某阁楼二楼，梳妆台旁。中年男子将女尸放好，拿起眉笔为其描眉，眼中满是深情。
- 他不断追问「你开心么，婷儿」「你说话啊」，得不到回应后情绪崩溃，扔下画笔，抓着女尸剧烈摇晃、撕裂般嘶吼。
- 随即怔住、抱住女尸道歉：「对不起婷儿，你不要怪我，我错了，我再也不吼你了。」并放狠话：「谁也不能从我身边把你抢走，谁抢，我就杀谁，杀，杀，杀。」
- 他亲吻女尸并诉说：这阁楼当年本已快要塌陷，是他用法力维持至今，因为「这里是你的家——恩，是我们的家才对」。
- 关键来历自述：**他第一次来仙界，本是为了取得仙界之气**，但在此看到女尸后便认定「你是我的妻子」，在这里陪了她很长时间。当年他见到她时，她就是这样躺着，「一点也没变」。
- 价值排序：「和仙界之气相比，你才是我的珍宝。」
- 收尾：他躺到女尸旁，说「我们休息一晚，明天，为夫再去寻找仙玉」。
- 提示：此人同样在寻找**仙玉**，与叱虎之行的目标物重合，构成潜在冲突伏笔。

## 二、王林的决断（赴约动机）

- 时间压力：一个月的期限已然快要临近，王林打定主意前往叱虎所说之地。
- 三重诱因：
  1. **三把仙剑**；
  2. **巨大的仙玉**——王林相信有了大量仙玉，日后若达化神后期、冲击婴变会容易很多；
  3. **潭水中的仙草**——可送给李慕婉炼制极品丹药，服食后李慕婉修为可更上一层。
- 婴变期的特殊意义：**到了婴变期，司徒南就可以苏醒**。这是王林执着于突破的核心私因。
- 修为现状与心态：王林此时仅为**化神初期**，距化神后期极为遥远，但毫不焦急——「修仙之旅，切勿急躁，水到渠成」。
- 丹道观：以他现在的修为**首重感悟**，丹药之流并非大道，除非功效极大否则不愿轻易服食；但**以仙界之草炼制的仙丹则大有不同**。
- 行动：身形不断升高，冲出所在碎片的天空，飞向远处**巨大的漩涡**；在漩涡处开启玉简，即可前往叱虎所约之地。

## 三、叱虎的等待（仙界中央碎片·传送阵）

- 位置：仙界**中央之位**的一处碎片，叱虎盘膝打坐，身前有一座**传送阵**。
- 已在此坐了**七天**；七天中有宵小之辈前来，**均已成为他手下亡魂**。
- 他在等两个人，判断若这两人肯来，此行有**七成把握满载而归**；他相信看过玉简后的诱惑「任何人都难以抵抗」，故不急。
- 受邀二人（精挑细选）：
  - **第一人**：名气极大，且与巨魔族「还有一些渊源」（本章未点名）。
  - **第二人「曾牛」**：即化名的王林。叱虎自认看不透此人——**看去只是化神初期，却始终有种危机感**。权衡后仍决定邀请，理由是实力越强成功机会越大；即便对方行杀人夺宝之事，他自认修为足以应付。

## 四、第一位到场者：红蝶

- 阵法忽然闪烁、光芒大盛照亮四周（对叱虎无影响），达到极限后骤暗，走出一名妙曼身影。
- 此女相貌极美却带冰冷之色，令人望之怯步；现身后**冰寒之气弥漫四周，甚至天降雪花**。
- 身份：**雪域国天之骄女红蝶**。叱虎起身抱拳：「红蝶道友，在下等你多时了。」
- 红蝶态度：目光冰冷，冷淡放话——**若你所说是假，此事在下绝不会罢休**。
- 叱虎的凭据：这玉简是**巨魔族习语始祖（习祖）亲自拓印**，「他老人家应该不会说谎」。
- 红蝶闻「习祖」面色略缓：习祖是**她师傅的一个前辈**，双方略有世交。

## 五、设定要点（本章新增/确认）

- **朱雀星上，以部族形式存在的修真国只有两个：巨魔族与雪域族。**

- **仙界之气**为修士入仙界的常见图谋之一（中年男子初来仙界即为此）。
- **仙玉**被视为助力化神后期冲击婴变的重大资源。

# 第309章 战

## 一、战前：分宝之议

- **族群背景**：巨魔族与雪域国两族来往频繁，巨魔族可视为雪域国的**盟友**。
- **红蝶表态**：既是「习祖」亲眼所见，此事不会有错；她愿随叱虎同去，其余所获之物一概不要，**唯独玉石棺材必须归她**。
- **叱虎心思**：暗嫌红蝶霸道。玉石棺材他也有兴趣，但**三把仙剑**才是他志在必得之物；若只有二人尚可分，但还有第三人在。
- **第三人**：叱虎点明——**曾牛**也会参与此事，且「与你我一样，都来自**朱雀星**」。红蝶闻言一怔，脑中把其余四人一一闪过。

## 二、突袭：传送阵前的第一击

身前阵法再次光华大盛，一道挺拔身影自传送阵内出现——**正是王林**。

- 红蝶目光一闪，**二话不说**右手向前一指，白色灵诀快若闪电印向阵内（「印似奔雷，诀如闪电」）。
- 王林刚现身即察觉危机：脚下一瞪，大地震裂、**阵法崩溃**，整个人化作青烟后退。
- 同时甩出腕上**驱兽圈**，尖啸中化作**雷蛙**，吐出巨大雷球迎击印诀。
- 手中一抖祭出**禁幡**，无数禁气咆哮而出，声传数十里；王林身在禁幡之中，双眸凌厉，**锁定红蝶**，一声「去」，禁气化作条条恶龙悍然扑上。

## 三、红蝶的杀招：人首蛇身冰雕

- 红蝶后退，手中翻出一尊**冰雕**，样式与当年那**人首蛇身**之物一模一样，但双眼紧闭。
- 冰雕紧闭的双眼散发**蓝光**射出，带起幽芒。
- 蓝光效果：雷球被一晃即生无数冰凌、**整个冰封**（外表幽蓝、其内紫黑、隐有电光）；雷蛙欲再吐雷球，鼓腹之际被照中，**连同鼓荡的腹部一并冰封**，雷球胎死腹中；禁气恶龙亦被阻步、出现冰封迹象。
- **意图明确**：红蝶此次动用威力极大的法宝，目的是**一举杀了王林**。

## 四、王林反制：万魂出眉心

- 攻击被挡后，王林身子后送，**右手点在眉心**，道道黑影冲出化作一个个**游魂**，在其身边呼啸。
- 王林跃至半空，**好似魔神降世**，双目闪动诡异之芒；一字「香」（原文如此）之下，身边**上万游魂**化作厉鬼不畏生死扑向红蝶。
- 关键设定：**游魂本身对一切法术有一定抵抗力**，蓝光余波对其作用甚微。

- 叱虎一拍储物袋，飞出青光化作**巨大罗盘**，悬于前方十丈外的黑色虚无中。
- 红蝶冷声指认：「**巨魔族至宝，星罗盘**。」
- 罗盘上刻画无数复杂深奥图案，王林只看一眼便觉**整个神识被吸扯而进**，当即收回神识。
- 叱虎自承：以其修为根本无法驱使真正的星罗盘，「此物是**伪星罗盘**罢了，比真正的星罗盘，功效上差了不少。」
- **涂司记忆线索**：古神涂司的记忆中亦有星罗盘的描述，**甚至还有炼制的方法**，只是其中很多材料都已灭绝。王林因此对此盘颇有兴趣，认定其为「星空行走的必备法宝」，欲日后自寻/自炼。

## 五、三方位分工与虚无行的规矩

| 方位 | 人 | 职责 |
| --- | --- | --- |
| 正中 | 叱虎 | 全力把持罗盘方向，无暇出手 |
| 西首 | 红蝶 | 于罗盘自带**防御青色光幕**内打坐恢复修为 |
| 东首 | 「曾兄」（实为王林） | 散出**炼魂/游魂**观察未知异物，报告方位以便改向 |

- 叱虎明言此盘**应五人驱使才为最佳**，但「那些宝贝，却是不够五人来分」，故只三人成行。
- **巨魔族先祖叮嘱**：虚无之中千万不可轻易散发神识，否则会有大祸临身。
- 叱虎请托：「若是此盘崩溃，我三人无一可活……还望曾兄不要留手。」

## 六、王林的防备与神识共域

- 王林点头应下，同时**取出禁幡**令全身笼罩黑雾——若施法之中叱虎或红蝶对他出手，禁幡可阻挡一二，为他争取反击时间。叱虎目光一闪却并未着恼，反觉理所当然（换成他也会如此）。
- 叱虎闭目吐出灵力，罗盘一震骤动，转眼推出数千丈外——**并非瞬移，而是以极快速度生生滑过**。
- 启动瞬间，一股**奇异之力**笼罩罗盘，王林、红蝶、叱虎**三人神识同处其内**。叱虎解释：这是罗盘正常力量，虚无中行驶无法开口说话，唯有在此可作神识交流。
- 叱虎在异力中投出**由无数连点组成的星图**交王林记下。王林二话不说右手点在眉心，放出**三分之一的游魂**（数千）环绕四周向外探去；游魂在虚无中如鱼得水，慢慢扩散开来。
- 罗盘速度超乎想象，转眼失去踪影，消失在虚无之中。

## 七、要点与伏笔

- **身份提醒**：本段中叱虎称呼的「曾兄」即王林当前所用身份，其言行归属王林。
- **伏笔一**：王林掌握星罗盘炼制之法（源自涂司记忆），只缺已灭绝的材料。
- **伏笔二**：远处的葫芦中年男子与「婷儿」为独立并行线，其手段（酒喷散雾、无形阻力护体）远超三人所需之力。
- **伏笔三**：五人驱使方为最佳而仅三人成行，为虚无之行埋下风险。
- **伏笔四**：虚无中不可轻易散发神识——而王林恰以游魂（非自身神识）代行探路，规避了这一禁忌。
