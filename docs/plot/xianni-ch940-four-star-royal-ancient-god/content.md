# 第八卷 联盟隐秘 第940章 四星王族古神

## 一、抢星与晋阶四星
- 王林一吸之下紫星直奔其口，望月体内爆发强大古神气息并发出长吼；一木子、武东禅从两个方向抢夺紫星。
- 二人经前战元力所剩无几，能发挥的修为已跌至**窥涅期**，抢夺失败。
- 王林体内砰砰作响、身躯胀大一倍有余，**一口吞下古神一星**。磅礴之力爆发，身化数十丈巨人。
- 眉心隐藏的**古神之星由三星半直接凝为四星**——且是承自**古神涂司**的**古神一族王族四星**，强于寻常古神四星。
- 身躯再度膨胀至**百丈有余**，威压横扫虚无，一木子与武东禅骇然直视。

## 二、连破五行，重创龙袍男子
- 金龙连番受创、神通多施、又遭封印之利，元力大范围流逝，修为跌至**窥涅初期**，急剧收缩化作**龙袍中年男子**。
- 王林此时**分身之力全被封印殆尽**，所能施展的唯有古神之力；但四星古神足以灭杀金龙。
- 龙袍男子天灵之上**五张五行纸符**逐一施展，皆被王林**一拳**连破：
  1. **毒火**——绿色剧毒幽火，对修士可毙命，对古神微不足道，被一拳生生熄灭并倒卷绿烟。
  2. **贡水残金刑木葬土**（五符齐动）：
     - **贡化之水**：蓝色大海，万钧之力，拍来即崩碎成无数水滴倒卷（古神一拳之力数倍于它）。
     - **龙鳞之剑**：龙鳞组成的金光长剑，自剑尖寸寸碎裂、鳞片尽掀。
     - **刑罚之木**：黑色巨木，透血腥之气、内含无数仙人魂魄、发凄厉之啸，被一拳自中间劈开。
     - **葬土**：黑色风暴，随刑木被劈同时轰然崩溃。
- 一拳落于龙袍男子身前，其**喷出大口鲜血、倒卷而去、血雾喷散**。旁观者只见王林迈一步、出一拳而已。
- 叙述点明：若在外界、若其修为尚在，王林伤他极难；此地王林占尽优势且对方修为大范围被封。

## 三、龙尊五行冠收人
- 王林抬脚欲踢，龙袍男子面如死灰、心有不甘，催五张纸符化出**虚幻皇冠**，五行之力扑向王林。
- 王林虚空一抓（储物袋虽相对巨身微小仍可开启），取出**龙尊五行冠**。
- 龙袍男子失声：「**龙尊五行冠，你怎么可能会有此物**」，又惊觉「**竟然还有了魂**」，遂弃一切神通疾退，拍储物袋取出**木牌捏碎**，化浓烟在虚无中开出一条通道欲逃。
- 皇冠飞出，五彩之光中幻化**一朵玫瑰**，凭空现出**一名一身傲气、相貌绝伦的女子虚影**，玉手一指——龙袍男子惨叫、无法遁走，化作金光被吸入皇冠内。
- 女子虚影转身端详王林一眼，张口似欲言而终无声，渐渐消失；王林心神一震，不动声色收冠转身。
- 王林随即冷漠盯视一木子与武东禅——二人修为被严重封印且仍在持续，已构不成威胁。

## 四、古神成年挑战
- 王林转向远处散发古神气息的**望月**，张口发出**百丈巨身的咆哮**，即**古神之音**，引起无尽雷声与音爆；其古神之语含义只有两个字：**挑战**。
- **古神一族习俗（源自涂司「忆之传承」）**：
  - 每个幼年古神成年之时，须挑战族内一人。
  - 三星至四星必须借**成年古神之气**，别无他法。
  - 一旦达到四星，即表示该古神具备**成年资格**，而这资格就是**挑战**。
- 望月体内亦起大吼，大口张开伸出无数触手，其中缠绕**一人**：身量如寻常修士，**眉心有五个模糊星点旋转**——**五星古神**。
- 五星古神答：「**我的族人，我接受你的成年挑战**」，触手松开，踏步而出走三步：第一步身化三十丈、第二步化百丈（沧桑气息弥漫）、第三步暴增至**三百余丈**，如同天神。

## 五、要点与悬念
- 王林身份已由「修士」转为「获得力之传承且拥有忆之传承的真正古神——四星王族古神」。
- 龙尊五行冠内之「魂」（玫瑰女子虚影）来历不明，且其对王林似有话未说，为后文伏笔。
- 与五星古神的成年挑战即将展开，双方体量为百丈对三百余丈。
