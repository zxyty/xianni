# 第七卷 名震罗天 第670章 生死之上，可是因果

## 一、场景
黄昏，冉云星某城房府内（孙泰养老于冉家宝合楼）。王林与旧识孙泰对坐长谈，夕阳余晖贯穿全章，是本章的核心意象。

## 二、孙泰的心理落差
- 孙泰修为已跌至**化神期**，眼力仍在，却完全看不透王林修为。
- 他回忆当年的王林：仙界弱小的化神修士、被他逼得放弃艹控低阶修士的小人物、周佚与他一战中只能旁观者；在朱雀星也只是棋子，不被任何问鼎期修士看在眼中；甚至若无孙泰相助，早被巨魔族老祖杀死。
- 今日的王林：随意一眼即令孙泰元神震动、不敢直视、不敢大声说话，甚至觉得为其仆人也无怨言。
- 孙泰从王林气息中清晰察觉：**王林杀过同阶（问鼎期）修士**——这是一个可怕的概念。
- 他终于明白冉家老祖为何要以拍卖的性质，把八品灵丹送给王林。

## 三、问答实录（关键情报）

### 1. 王林当前修为
王林自答：「问鼎」。孙泰不信，认为若真只是问鼎自己应能感应到，且在他看来王林强过冉家老祖。

### 2. 孙泰这几百年的遭遇
- 被传送进罗天星域时落点在**东临星**旁边。
- 在东临星居住近百年，做**吕家**百年杂役，最终才得自由身离开。
- 身上（周佚种下的）**烙印**曾在东临星被吕家一人破除，但烙印最终仍然存在。

### 3. 东临星
- 三大最强家族：**许、吕、刘**。
- 强度：深不可测；任一家族随意派出一个长老，便可把**冉云星**屠灭。
- 性质：「一个混乱的地狱，一个血腥的世界」——孙泰回想时眼露畏惧。
- 王林特意追问「东临星可有**向家**」→ 孙泰称据其所知没有，但不排除自己身份太低而不知隐秘。

### 4. 尸阴宗与四圣宗（本章最重要的设定披露）
- **尸阴宗**：联盟星域两大宗派之一；是真正的「宗派」，不屈居一星一地，范围极大、波及整个联盟；内有众多大神通修士，势力已延伸至**修真联盟**内部。传闻**尸阴宗宗主即修真联盟内地位极高之人**，故尸阴宗得以长久存在。
- **四圣宗**：可与尸阴宗抗衡的另一大宗派。
- 传承链：**四圣宗 → 四圣星（分支）→ 第一代朱雀子从四圣星分离而出 → 朱雀星**。
- 由此推算，**王林都可算作四圣宗的最外围弟子**。
- 孙泰自陈：虽为朱雀星尸阴宗大长老，但这般身份之人很多，机密知晓不多。

### 5. 孙泰在冉家的处境
- 身份：**冉家客卿**，在此城**宝合楼**内养老。
- 缘由：冉家老祖见其在炼丹、炼器上有见解而收留。
- 警告：**那枚八品丹药王林不该拿，是冉家老祖的阴谋**——随后详述四年前之事，与孙析所说大致相同。

## 四、寿元将尽与落叶归根
- 夕阳映照下，孙泰身上透出一丝若有若无的**死气**；王林因意境为**生死轮回**，一眼看出端倪，平淡道「你的寿元，不多了」。
- 孙泰承认：**再有二十年**。
- 王林承诺：「二十年后，若我还在冉云星，会亲自送你。」
- 孙泰唯一请求：**把骨灰带回联盟星域的暗月星，那里有一处天山，山下有处村庄，送至那里**。王林轻叹点头应下。
- 赠礼：孙泰取出一个**储物袋**放在一旁，内有原本准备用于恢复修为的**仙玉**，以及他**炼丹、炼器的心得**，权作答谢。
- 王林的判断：孙泰失去了修真者该有的**道心**，被东临星百年岁月全部捏碎，此生即便恢复当年修为也将永久止步、再无法攀升。
- 孙泰蹒跚走出，橘黄余晖伴其远去；他直到离开都没有问当年被他放出的**魔童**（即王林）如何——象征他已全部放下、想开，只想静静平凡地度过余下二十年。送出储物袋即是打开心结，放弃恢复的可能、放弃来到罗天星域数百年一直不甘的心态。

## 五、因果之悟（章名题旨）
- 叙述点题：孙泰因王林而有此下场，又因王林放弃一切、解脱了数百年心灵痛苦——若真说有因果，这便是了。
- 王林闭目所悟：「**因果，便是生与死的本源，因为有了生，所以才会结出死亡的果**」——是**生死轮回意境之后的又一表现**。
- 状态：眼中有了一丝明悟，但**仍感生涩，好似能看到却摸不到**。
- 类比：生与死、因与果，有时只在一念之间，如同阴与阳、虚与实。

## 六、伏笔与待办
- 二十年之约：送孙泰最后一程 + 送骨灰至暗月星天山下村庄。
- 东临星三大家族（许、吕、刘）与「向家」之问，指向王林的后续目的地/寻人线索。
- 冉家老祖的八品灵丹之局（四年前之事）尚未解。
- 「因果」意境尚未圆满，仅得一丝明悟。
