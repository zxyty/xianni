# 第1229章 目标，风之仙界！

## 一、归来无声
王林自七彩界归来，落于云海蛮荒大陆偏僻处。此时正值云海八阶星域盛典（归元宗主宗大比）将临，此地更为人迹罕至。王林在云海几乎默默无闻，归来古井不波，无人知晓——但云海扬名的序幕自此渐开。

## 二、七彩界得失清点

### 收获
- 修为：入界时净涅初期，出界时「半只脚进入碎涅」。
- 法宝/秘法：七彩钉、岁月禁、两把刺在神秘鹿骨上的奇异短剑、仿造的天逆珠子。
- 灵兽：蚊兽蜕变。
- 其他：天逆开、吞道果、重创养花人。
- 见闻与情报：战星野骸骨、司马墨洞府、朱雀三次觉醒、吸收界外闪电、迷失者、铭志者、真假难辨的道之经文、隐隐发现天运子的秘密、知晓逆行者的存在。

### 代价
- 去时七人，回时唯余王林一人。
- 与苍松子一战：伴随多年的次空涅法宝铁剑一分为二。
- 与蓝梦道尊一战：水晶剑崩溃、战斧崩溃、古神大鼎崩溃。
- 最重：尚属模糊状态的古神第六星碎灭。所幸意境所化规则之星尚在；王林判断只要肉身经历古神第二损便可恢复，或另有机缘——曾达到过那个层次，恢复比首次攀升容易得多。

结论：与失去相比，此行收获实在太大。

## 三、搜魂疗伤与界外情报
王林取出七彩界带出的两道濒死元神（闪电印记青年、火焰图腾青年），强行搜忆后元神崩溃，被其一口吸入用于疗伤。加上此前在七彩界搜取的奴族青年元神，他对界外的了解渐多，念出关键词：「太古星辰」「太古五尊」。

随后吞服大量疗伤丹药、掐诀吐纳，神识散开警戒。三日后睁眼：肉身伤势未愈但不影响战斗；元神伤势极重，短期难以痊愈，时有刺痛——蓝梦道尊一掌之威令其至今心惊。王林由此确认那便是「第三步」的实力，暗誓早晚亦要达到。他低头看向手腕上的镯子，暗叹一声，摘下收入储物空间。

## 四、处置三道元神

| 对象 | 状态 | 处置 |
| --- | --- | --- |
| 陈天军 | 仅余半道元神，肉身崩溃，濒于消散 | 王林兑现承诺带其出界；陈天军请求送回役兽宗由师尊施救，王林答应并收起元神 |
| 青衫老妇人 | 元神受创不重，但四祖功法被破，修为跌至净涅中期 | 主动献出生死禁换命；王林搜魂取得生死禁后，以狂风将其元神推出数万里放走，老妇人遥拜而去 |
| 云魂子 | 已被王林收为奴 | 暂不疗伤，元神收入储物空间 |

注：老妇人称王林为「吕道友」——王林在归元宗一系仍以化名「吕子浩」行事。

## 五、仿造天逆珠子的启用（关键发现）
王林取出七彩界所得仿造天逆珠子，神识融入后确认：**珠子一旦离开七彩界便毫无用处**。正欲收起时心念一动，将神识融入元神内的十八地狱封仙印，锁定其中的**天运子战魂**并与之融合——全身气息骤变，宛如天运子，双目与身体隐隐透出七彩之芒。此时心神弥漫，珠子立即绽放刺目七彩，显出被运转之相。王林清晰感知：只要心念召唤，便可使珠内封印的**逆行者神通**降临天地。

散去融合后珠子光芒即灭、恢复原状。这批珠子由此成为他伤愈前的极强护身手段。

## 六、决策：目标风之仙界
- 首要：尽快疗伤。
- 其次：即刻前往**风之仙界**，获取**蚊兽群**——如此便可在云海纵横。
- 暂缓：归元宗主宗大比将进行数月，不急于赴会。

## 七、星空疾驰
王林凭百年前从蓬莱所得、已全部牢记的星图，自与六阶星域交错的边缘踏入六阶星域，全速穿行直奔风之仙界所在的八阶星域。加持速符后化作长虹，声势滔天，速度已超音速（身影过后许久方闻破空之声），沿途修士无一敢阻。六阶星域内一行十余名修士震骇，判断：「即便师尊也做不到；若非法宝加持，那定然是碎涅极限乃至天人衰劫的罕见老怪。」

- 古神第六星的恢复需「肉身经历古神第二损」或另寻机缘。
