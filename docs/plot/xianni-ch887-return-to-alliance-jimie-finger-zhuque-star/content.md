# 仙逆 第887章 朱雀（第七卷 名震罗天 · 卷终）

## 一、归返联盟星域
- 王林一头白发，行于联盟星域星空，步伐不快但每一步脚下波纹回荡、跨越无数。
- 离开时刚刚问鼎，归来时已然**窥涅**。心中默念：「天运子、凌天候——我王林，回来了。」
- 储物袋内仍完好保存**进入妖灵之地地下洞府的钥匙**。

## 二、谨慎的战略判断
- 当年他在联盟星域不入流，接触层次最高不过七级修真国；如今以窥涅之身，即便在罗天星域也足以被老怪重视，若愿意可立刻掀起风暴。
- 但他清楚：**联盟不比罗天，联盟星域的水太深**。此地不是罗天的家族修炼模式，而是弱肉强食、物竞天择的残酷修真；问鼎以上的老家伙个个老歼巨猾，稍有不慎便被连皮带骨吞下而不自知。
- 决定：**对罗天与联盟之战先行观望，不轻易插入其间**。
- 归来后立刻通过与**本尊**的联系确定彼此准确方位；自忖与本尊合体后，在联盟星域无需畏首畏尾。

## 三、生机的代价与后手
- 前情：得知救李慕婉需消耗自身生机时（向云东所言），王林毫不犹豫以生机换取施展**七夕术**——数百年等待，很可能是唯一一次机会。
- 结果**既成功也失败**：李慕婉未复活，但**已有肉身，有了希望**。
- 代价：生机被消耗绝大部分。**清水**送出**掩盖生机的符文**，却未想到王林另有后手。
- 现状：符文遮掩下，王林除白发外相貌不显苍老；若破除符文，实则**沧桑如千年老人**，那种**轮回天道召唤**的感觉更加浓郁。

## 四、寂灭指万里夺生机
- 王林寻得一颗无人居住、草木丛林弥漫的**蛮荒星**（灵力不多但生机盎然），落地盘膝。**塔山**一步走出，于数丈外盘膝护法，寒光凝视四周，有异动即出手。
- **寂灭指**：当年看到第三步后，因「长久施展不利于回归本源」而被王林放弃；此番为补生机重新启用。此神通以极霸道方式**吞噬万物生机为己用**，融入全身化作凌厉一击，指落生机崩溃。
- 施法过程：右手食指凝黑芒 → 按向大地 → 黑芒成环形外扩。
  - **千里**：参天大树枯萎粉碎，草木尽枯，生机化白气聚向王林。
  - 王林深深一吸，白气成漩涡自其**七窍**灌入，滋养全身、飞快弥补生机消耗；胸口血色符文透出**三寸**，仍有游走之光掩盖保护。
  - 半个时辰后千里内大地枯黄干裂，千里外一切正常，内外仿若两个世界。
  - 再度沸腾外扩：两千里、三千里、**五千里**（一头十多丈巨蟒亦被瓦解）→ 六千里、八千里 → **一万里**，万里内一切生灵尽数崩溃，生机化作以王林为中心的风暴。
  - 符文最终透出**十寸**，王林睁眼以左手将符文自胸口彻底扯出：身体光芒闪烁，化作沧桑老者、死气弥漫；旋即被四周磅礴生机逆转，干枯身躯重现光泽、迅速改变。
- 王林论断：**向家先祖**所修神通定与寂灭指类似，皆吸收生机融入自身之术，「此人太过托大，怕是没想到我能看透」；并放言「我王林一半的生机岂能是那么好吞，总有一日连本带利全部取回——吞噬生机，我也会」。

## 五、朱雀星危局（章末转场）
- 位置：**联盟星域西部深处**，距离**联盟南部交界处**较近；一颗**半废弃的修真星**，灵力不浓。
- 星外数道剑光巡守，修士修为仅**婴变期**，煞气浓重，神识散开密切注视，眼中透着担忧。
- 一道剑光自星内飞出，立于其上的是一个**老妇人**，面有皱纹但可见年轻时秀美；弟子恭敬称其**「白雪师叔」**。文中点明：**若是王林在此，定会觉得此女眼熟**。
- 白雪告诫众人谨慎、异常须第一时间禀告，「眼下战乱，我朱雀星距离罗天修士太近，可谓是生死存亡之际」。
- 骤变：远处星空剑光呼啸，约**数百修士**组成的队伍直奔朱雀星而来；当前一人是**背着手踏在星空、脸上露出痴傻之笑的大头童子**。

## 六、悬念与看点
1. 王林与本尊何时合体、以何姿态介入罗天—联盟之战。
2. 白雪的「眼熟」指向何人（疑与王林旧识/故人相关）。
3. 大头童子率众围攻朱雀星，罗天势力已压至联盟西部。
4. 王林对向家先祖「连本带利取回生机」的复仇伏笔。
