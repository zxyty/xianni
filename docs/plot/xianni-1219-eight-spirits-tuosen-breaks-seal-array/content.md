# 第九卷 云海之巅 第1219章 八灵现（第二更）

- **六灵齐出**：拓森明显不敌，生平**第一次后退**。
- **七灵合一**：生生阻断冲击，拓森面色首次苍白、嘴角泌血。

## 二、拓森的判断与决意

- 「除非是我吞了王林，成为真正的**王族八星古神**，方可有一些机会破开这个阵法。」
- 此阵所封锁者，**不仅是界内之修，显然还有封锁古神一族的打算**。
- 拓森自阵法内隐隐感受到**王林的气息**，断定王林在**阵外太古星辰**内。
- 拓森疑心：「莫非除了我之外，还隐藏着什么存在，否则不可能有这么强的阵法。」
- 决意：宁可拼尽全力冲出、失去回返之力，也要出阵寻王林吞噬之——「留在封界也是无用」。

## 三、燃星冲阵

1. 右手点在**眉心第三个星点**，爆发第三步修士本源，星点飞出化作流星开道；拓森缩小身形紧随其后。
2. 冲势被七灵与投石车火团所阻后，一指点在**第二个星点**，爆出更强本源，化作第二道流星，冲击力数倍于前。
3. 大斧现身、拓森呆立震撼后，**第一个星点**亦爆发本源，三道流星融合为一，拓森整个人融入流星，以灭神矛与弯刀为尖，不顾器灵与斧斩，直撞阵法。

**结果**：一撞震惊界内**四大仙界**，令界外赶来的**护阵者**目瞪口呆；阵法剧烈颤抖却终未毁。

## 四、墨流分神术破阵

- 大斧一次次落下、拓森反复喷血之际，他施展**涂司生前尚未彻底完成的「墨流分神术」**。
- 黑色迷雾弥漫拓森全身，大斧竟**一顿、似有犹豫**；迷雾趁隙侵入阵法。
- 拓森喝「爆爆爆」，环身流星轰然爆开，形成毁天之力落在阵法上——**这座自阵成以来从未被破开过的大阵，第一次出现裂缝**。
- 拓森自裂缝冲出，狂笑喷血；三个暗淡星点回到眉心，**其中一个当场崩溃**。
- 出阵宣言：「王林，本神来了，我看你这一次，还能往哪跑。」

## 五、关键伏笔

- **父祖王器为何成为此地阵灵**：拓森见斧后「彻彻底底完完全全楞了一下」，直呼「此物怎么会成为此地阵灵」，指向古神一族与布阵者之间的隐秘渊源。
- **布阵者身份未明**：拓森怒问「是哪个疯狂之人布置这该死的地方」。
- 拓森代价惨重（星点崩溃、无回返之力），却已锁定王林所在，直接推动其后与王林的正面冲突。
