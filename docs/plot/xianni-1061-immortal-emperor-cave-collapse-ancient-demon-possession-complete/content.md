# 《仙逆》第1061章 六更（第八卷 联盟隐秘）

## 一、三大强者神通齐落

- **场景**：仙帝洞府第九层，古魔盘踞的宫殿外被黑雾/魔雾笼罩。
- **王巍**：滔天海洋轰隆拍落，仿若要毁灭世间一切存在。
- **天运子**：于天空之海内，天运神通一指蓦然降临。
- **古妖贝罗**：伸开双臂，身后**古妖虚影脱离本体**，一晃之下幻化出**二十四杆小旗**环绕虚影；虚影向前一指，绿色小旗散发无法想象的威压，从旗内幻化出**一尊尊古神与古魔，乃至上古时期的凶兽**。（原文对旗数有“二十四杆/二十三杆”两处不一致表述，此处如实并记。）
- **结果**：大地砰砰颤抖、无数龟裂，随天运子一指彻底崩溃；仙帝洞府一到九层几乎全部受影响，第九层沦为废墟，震动波及整个**妖灵之地**。
- **古魔反击**：沙哑怒吼疯狂传出，宫殿外黑雾横扫天地，与三大强者神通直接碰撞，轰鸣中天地色变。

## 二、旁观者的算计

| 人物 | 行动 | 动机 |
|---|---|---|
| 虚空子 | 本欲出手，**察觉王林来临后立刻停止攻击** | 忌惮王林 |
| 虚空子身边的黑衣人 | 未出手，眼露贪念，打开这宫殿 | **获得三滴青霖之血**即可完成任务，“大人”将大范围提升其修为 |
| 葫芦老者 | 收起神通、悄然后退 | 一路跟在天运子身后而来，**不为第三步的秘密，只为青霖的神通仙术** |
| 王林、凌天候 | 立刻向前飞去 | 尚未临近即感受到无法想象的冲击之力 |

- 众人共识：即便宫内是重伤的**仙帝青霖**，且有古魔存在，但己方人数众多、不缺大神通修士，古魔怕也要饮恨于此。

## 三、转折：烛火熄灭，古魔夺舍成功

1. 神通与黑雾碰撞的瞬息，**第八层大殿内最后一盏烛台之火**剧烈闪烁挣扎数下后**缓缓熄灭**。
2. 烛火熄灭刹那，第九层黑雾中大殿**坐在椅子上的中年男子**，**眉心的光点立刻消散**，四周魔气轰然冲入，**占据其灵台全部位置**。
3. 男子猛地抬头：双眼浑浊瞬息消失，取而代之的是**无法形容的可怕魔焰**；**左目有八个星点急速旋转**；嘴角露出阴沉微笑。
4. 他坐在此处已**无数万年**，身体几乎无法移动半点——**此刻，他动了**，缓缓站起。

## 四、站起之后的连锁崩坏

- 滔天魔气轰然而出，**其所在大殿咔咔裂开、轰然全部崩溃**，向四周横扫。
- 宫殿外**魔雾瞬息倒卷，全部疯狂钻入男子体内**；一套**黑色铠甲**刹那间出现在他身上。
- **仙帝洞府一至八层的全部禁制**瞬息疯狂闪烁如欢呼般，轰轰崩溃。
- **妖灵之地**：原本被驱除妖气、成为**仙灵天境**之地，地面冲出**无尽魔气**横扫天地，片刻就重新掩盖整个仙灵天境。

## 五、三方反应（同一瞬间）

- **王巍**：眼睁睁看着宫殿崩溃与其中模糊身影，眼中震惊与痛苦，脱口喊出「**师尊**」——暗示椅上中年男子与王巍存在师徒渊源。
- **天运子**：双目内罕见露出一丝疯狂——「他等待这一天，已经等了很久很久」。
- **古妖贝罗**：倒吸口气，杀机浓浓——「**刚刚夺舍成功，尚未稳定，决不能让他巩固**」。

## 六、要点提炼

- 烛台之火 = 压制/维系那名中年男子灵台的关键；**灯灭即封印破**，为本章因果链核心机关。
- **眉心光点消散 → 魔气占据灵台**：古魔完成对该中年男子肉身的**夺舍**。
- 三大强者围攻的结果并非击杀古魔，反而恰好与夺舍完成同步，局面骤变：从「围猎重伤仙帝青霖」变为「面对刚夺舍、未稳定的古魔」。
- 战场空间从仙帝洞府第九层扩散至整个妖灵之地，仙灵天境被魔气重新覆盖。

## 七、待跟进（悬念）

- 王巍口中的「师尊」究竟是被夺舍的中年男子本人，还是古魔本体？
- 黑衣人背后的「大人」身份，及三滴青霖之血的用途。
- 古妖贝罗提出的「趁其未稳定」是否会促成三方短暂联手。

# 第978章 魔影长笑震星域

## 一、妖灵之地：魔气横扫，仙兽化凶兽

- 一切刚刚恢复不久的**仙兽**，刹那间被**魔气**横扫；魔气过后显露出来的，是一头头目光嗜血的**绝代凶兽**。
- 不只妖灵之地，其所在的**整片无尽星空**同时被魔气弥漫。
- 星空中幻化出一个**巨大的虚幻魔影**，仰天长笑。

## 二、无音长笑笼罩联盟星域

这笑声**无音**，却在一瞬间笼罩了**整个联盟星域**——一种不敢想象的强大。

### 1. 北部战场
- 联盟星域北部的战争已持续**半年**，仍在继续，大量双方修士沦为尘埃，双方已然杀红了眼。
- **罗天修士**从罗天星域大量涌来，**修真联盟**亦出动众多修士；整个北部似可闻到浓浓血腥。
- **炎雷子**杀得近乎疯狂，狂笑弥漫时身子一颤；与其交战的**联盟长老**眼中亦瞬间骇然。
- 四周寻常修士也莫名颤抖，茫然不知原因。

### 2. 修真联盟总部：残存仙人喊出“仙帝青霖”
- 总部内，**当年仙界崩溃**时如**王巍**、**胡娟**一般躲过劫难的残存仙人，是修真联盟的中坚之力，正准备离开、加入北部战乱。
- 无音狂笑穿耳而过，这些昔日仙人神色大变、滔天惊骇：“这……这声音是——” “**仙帝青霖**”。

### 3. 漩涡星球密室：铃铛崩溃
- 总部深处、漂浮在漩涡之上的星球内，密室中的**中年男子**猛地睁眼。
- 睁眼瞬间，密室顶部那个**铃铛**轰的一声崩溃。他亦低语：“仙帝……”

### 4. 昆虚之境：不是他
- 此前发现王林的**昆虚老者**蓦然抬头，目光似可穿透无数、望向妖灵之地，神色**从未有过的凝重**；旁边极为冰冷的**昆虚圣女木冰眉**一怔。
- 老者判断：“他苏醒了……不对，**不是他**”——神色似惆怅、似松了口气、又似有些失落。

## 三、火海星域：朱雀圣皇之叹

- **火海星域**为四圣宗之**朱雀圣宗**所在，对修真联盟而言属于**禁地**。
- 星域最深处、火海禁地火焰的**根源**：一块**十丈大小、形状不规则、颜色雪白**的石头。
  - 其高温浓郁到无法想象：此刻的**王林**接近百丈内会立刻肉身融化；**朱雀**亦将瞬间死亡；**五星古神**在这百丈范围内同样不行。
  - 正因其存在，火海星域仿若永恒，在悠久岁月下不断燃烧。
- 石块上盘膝坐着**朱雀圣皇**：样子太过沧桑，皮肤拉耷，死气浓浓，远看不似人，而似一团死肉。
  - 无人敢小看他：当年名震星空；若非特殊原因未进入仙界，仙界内也当有他一席之地。
  - 睁眼望向前方，神色惆怅：“莫非，我朱雀圣宗真的无法崛起……”

## 四、朱雀星古神之地：拓森的百年之期

- **朱雀星**：一颗不为修士所重视、甚至可被直接忽略的**六级修真星**。
- 星内当年**雾气化海**之处，即**古神之地**所在；其中有一片**血海**。
- 血海中一名**红发男子**缓缓抬头，目露轻蔑：
  > “八星古魔只是一个废物……再有百年，我**拓森**就可以走出这里，到时，这天下可有能阻我之辈出现？”
- 随其声音，血海轰然而动、齐齐卷起，血浪滔天。

### 涂司的肉身
- 朱雀星内古神之地所处位置，是当年**涂司**开辟出来的**单独虚无空间**，涂司的**肉身**存放于此。
- 肉身庞大到无法相容：即便一个修真星在其面前也如孩童玩具；皮肤粗糙，拳头庞大无比，惊天动地的威压不断弥漫。
- **本章收束**：随着血海滔天、随着拓森的话语，这庞大古神的**右手食指蓦然动了一下**。

## 五、要点与悬念

1. 星空魔影长笑 = 疑似**仙帝青霖**的气息，但昆虚老者明确否认“是他”——苏醒者另有其人（或为伪迹/继承者）。
2. 无音长笑同时惊动四方：联盟北部战场、联盟总部残存仙人、漩涡星球密室中年男子、昆虚之境老者与木冰眉、火海禁地朱雀圣皇。
3. 火海禁地的**雪白石头**被点明为整片火海星域的火焰根源，威力凌驾五星古神之上。
4. 拓森自称**百年后出关**，且轻蔑“八星古魔”——与涂司肉身食指微动并置，暗示血海/古神之地内另有变数。
