# 第1827章 四个字！

## 一、天山：青牛真人的本源真身现身

- 王林借天地挪移自地火主脉离开，出现在飘落青雪的天山，身后传来苍老之声，他毫无意外之色地转身。
- 来者为一名盘膝坐于雪地的白发道袍老者，似早已在此等候，仿佛能提前推算出王林的落点。
- 王林观其气息，察觉透出「本源的痕迹」——并非本体，而是一具**本源真身**。这是王林第一次见到除自己之外他人的本源真身，遂抱拳称「晚辈见过青牛真人」。

## 二、两具本源真身的对望

- 青牛真人要王林显化本源真身。王林左目火光一闪，身后虚影凝实为本源真身（火本源，得自吸收大魂门地火主脉）。
- 两具真身目光相对刹那，青牛真人真身起身，恐怖气息笼罩天山，青雪倒卷、狂风呼啸。
- 青牛真人确认：「你是老夫这一生，除了自己外，见过的**第三个**拥有真身之人。」并直呼王林之名——王林并不意外，既然矾珊梦知晓，大魂门老祖知晓亦属寻常。
- 青牛真人评价：「从**洞府界**走出之人果然不简单。」

### 寒与水之辨

- 王林问其真身以何本源凝聚，答：以**寒本源**凝聚，「是寒，不是水」。
- 王林思索后答：「**寒是气，水是物**」——青牛真人毫不掩饰赞赏。

## 三、招揽：大魂门长老之位

青牛真人自陈：自王林踏入大魂门阵法一刻起便已知晓，看着他进炎脉山、与矾珊璐叙旧、吸收地火主脉、在大魂门凝出火本源真身，称此为「与我大魂门有缘」。开出的条件：

1. 成为大魂门长老（大魂门为**东州九宗十三门之一**）；
2. 赐一座山峰作洞府；
3. 所需一切由大魂门全力供应；
4. 达到条件即可任意学习大魂门道法；
5. 最关键的诱饵——**告知本源真身的奥秘**（青牛真人自称是对王林最有帮助之人，因二人同有本源真身）。

并给出立足之论：在仙罡大陆，除非开宗立派，否则需与某一宗派达成同盟，才是成长与融入仙罡的最好方法；「你可以不同意，但你早晚也会有选择的一天」。

**软压力**：全程绝口不提威胁，对王林毁掉地火主脉、与炎脉峰少妇交手、引动地火燃烧等事只字不提——越是不提，王林越明白其中无形的压力。王林早在决意入大魂门夺地火主脉时便已对可能发生之事做出判断，其中自然包含对青牛真人的防范；见对方只来真身而本尊未至，便已猜到其目的：以真身为诱饵引动其心，先前种种不过预热。

## 四、魂衍道与一炷香

- 青牛真人挥手将青色雪花凝作一支**青色雪香**，无炎而燃，给王林一炷香时间思考。
- 香燃至一半，王林问：你如何知道我离开时必定出现在这里？
- 答：大魂门有神通道术「**魂衍道**」，以此推衍可算出诸多事情。
  - 仙罡大陆推衍之术流派众多，**以仙族皇城的上道玄国师为第一**，其一人之力可在推衍计算上对抗**古国三脉皇族**中的三位大国师。
  - 大魂门的魂衍道只是略窥门径，**重点不在推衍他人，而在改变自身，令人难以算到自己**。
  - 「你若想学，我可以传你。」
- 王林看了一眼将尽的雪香，向后迈出一步，本源真身同步迈步，脚下波纹一晃，身影消失于天山。

**青牛真人未加阻拦**，神色不变，喃喃道：香燃尽前，若你真是「先祖当年迁移到这天牛洲、选择地火主脉所在建造大魂门时所说之人」，你会归来的，因为我这里有你需要的神通与信息；可若你没有归来，说明你不是，既然不是，那么……随即闭目。雪香仍在缓缓融化。

## 五、三次挪移，三重印证

王林欲验证魂衍道是否真的存在。

### 1）翠林山峰——「王」字

- 落于距天山约一个月飞行路程的一片翠林山峰上空，此地山峰错落无边，为天牛洲典型地貌。神识扫过，四周虽有生灵却无一能威胁到他。
- 转身欲走之际，忽觉异样，低头俯视：抬手挥出狂风吹动山脉树木，摇摆的枝叶与整片山脉在瞬息间组成一个字——**「王」**。

### 2）近苍龙宗处——「林」字

- 王林特意选了一处**自己曾去过**的地方（吸收第一条子脉龙魂、与杜青相遇之地，接近苍龙宗范围），想看还能否出现奇迹。
- 一眼看去脑海轰鸣：大地山峦因**地火子脉枯萎**而裂开道道裂缝，这些裂缝生生组成一个**「林」**字，须在高空俯瞰方能察觉。
- 王林确定：每一条裂缝都是**当时自然产生**，并非后来被人勾勒。

### 3）随机挪移——「归来桥」

- 第三次不选目标，无意识挪移，落在自己也不知方位的天牛洲某处天空，下方是一条弯曲河流，河道寻常，不成字迹——内心似松一口气。
- 随即神色一凝：河上有一座古老**石桥残墟**，沧桑不知年月，已坍塌大半，仅余岸边部分，旁竖一块字迹模糊的石碑。
- 王林落至碑旁，一眼看去身子巨震——碑上三字：**「归来桥」**。

## 六、要点提炼

- 标题「四个字」= 「王」「林」「归来」，由大地异象与古碑分处三地拼出，指向大魂门先祖当年的预言。
- 本章确立本源真身为极稀有之物（青牛真人一生仅见三人有），并首次点出本源可分「寒/水」等气与物之别。
- 引入仙罡大陆推衍体系：魂衍道（大魂门）、上道玄国师（仙族皇城，推衍第一）、古国三脉皇族三位大国师。
- 王林未答应也未拒绝招揽，以离去作答；青牛真人则以「归来与否」作为验证其身份的试金石。
