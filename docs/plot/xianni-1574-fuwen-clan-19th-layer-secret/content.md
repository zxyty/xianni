# 第1574章 十九层的秘密

## 一、背景：朱雀星上的符文族深坑

- 朱雀星历经巨变，符文族深坑却未随之消散多少，依然保留原处，成为朱雀星内最神秘的一处所在。
- 时常有修士入内探秘，尤其近数十年随着外来修士进入朱雀星，不少人深入深坑，但**最终一无所获**——没有人能够进入最深的一层。

## 二、入坑：疯子留守，王林独行

- 王林与疯子瞬息出现在深坑外。王林正要迈入，疯子却大吼拒绝：「不去不去，本王才不去，本王在这里等你好了。」
- 王林目光如电扫去，疯子吼声顿小，仍大力捂头。王林知其心性不定、只想在朱雀星玩耍，不愿为难，点头后独自踏入深坑。
- 疯子见状面露兴奋，喃喃跑向远处：想再去找「那三个小娘子」，这次一定能问出芳名。

## 三、旧地重游：一路直下

王林对符文族每一层入口记忆犹新，一路不做停留，闪身直抵**第十六层**。

### 第十六层：十三棺与黑色水潭
- 十三口符文闪烁的棺材呈**圆形环绕**，中间是散发阵阵寒气的**黑色水潭**。
- 棺内躺着符文族**历代先祖的骸骨**，透出阴森气息。
- 通往第十七层的入口就在黑色水潭内，其中设有一道封印：**修为需到阳实之后才有可能破开**。
- 当年王林无法进入，是依靠**大头**的力量才到第十七层；此次他仅是临近，水潭封印便承受不住其身上无形威压，轰然崩溃，卷出巨大漩涡，露出下层入口。

### 第十七层：昔日恶战的残骸
- 当年此地弥漫大量铁链，无数**被封了魂与神的仙人干尸**充当守卫。
- 王林曾在此展开恶战，致使第十七层崩溃；如今一片残骸，唯有中心那巨大漩涡仍在——那正是当年崩溃后出现的、通往第十八层的入口。

### 第十八层：本源火苗
- 百丈大小的石室，四周漆黑，仅正中一团微弱火苗散出微光，昏暗中似有无数鬼魅飘动，幽魂如烟丝扑向火苗，一近便被火苗之芒震散。
- 当年王林在**黄龙（老朱雀的分身）**帮助下，吸收了其中一丝本源之力，几乎将他撑爆；彼时望向火苗满是忌惮。
- 回忆：当年打开第十八层时，黄龙先是阻止王林踏入，随后改变主意，在其守护下让王林进入感悟。
- 此番再看，火苗内的本源力量**渺小至极且极为驳杂，仿佛被人强行融合在一起**，对如今的王林已无任何吸引力。王林走近时幽魂惊惧退避、惨叫回荡。

## 四、破火苗，现第十九层之门

- 王林抬手直接捏住火苗；其内本源之力骤然爆发欲反抗，然力量微不足道。
- 右手狠狠一捏，火苗崩溃化作点点火光弥漫，**黑暗中的幽魂随之一一消散而亡**。
- 火苗崩溃之处，缓缓浮现出一道**环形的门**。

### 门上封印的构造
- 门透出万古沧桑，其上大量符文将门严密封死。
- 符文密密麻麻，**显然不是同一时间烙印**，而是无数年来时常被人打下、日积月累而成。
- 虽然驳杂，却诡异地融合为一股极强封印之力；这封印在防止外人进入的同时，**赫然也有封住其内之物的作用**——究竟是为了封内还是封外，无人知晓。

### 封印强度与旧谜解答
- 封印之力已达巅峰，**堪比天人第五衰的全部之力**；即便修为到天人第五衰也很难破开，**除非是第三步大能**。
- 由此，王林明白了当年**老朱雀分身（黄龙）始终无法进入第十九层的原因**。
- 王林右手金光一抹，门上无数符文层层崩溃，几乎尽数破开——「换了以往时候，那封印足以阻拦万修」。

## 五、最后一道符文：仙人血脉与道古气息

- 门上仅剩最后一道符文：**由一笔构成的圆圈**，看似寻常，实则蕴含奇异力量。
- 其封印的是**气息**——封死门内一切气息，使内中之物无论为何都无半点气息外传。
- 王林目光下，圆圈中透出**一丝金光**，以及一股**隐藏极深的仙力**。他断言：「这符文，它绝不是符文族可以拥有之物。」
- 王林神识中清晰感受到其内威压——**仙人血脉的威压**。他退后数步，运转体内之力化作一指按向该符文。
- 圆圈符文金光一闪，骤然逸出一股**让王林熟悉至极的气息**：那正是**道古**、是**道古烨寞的气息**。王林手指生生停住，面露无法置信。

## 六、王林的惊天推断：道古左眼在此

1. **道古烨寞被李广之箭射下的左眼**，当年消散于星空之中。
2. 此地既有道古气息，则门内所封极可能就是**那只道古左眼**。
3. 论证：天地间既蕴含仙人血脉之力、又拥有道古气息之物，除了那被箭带走的左眼，再无其他。
4. 左眼本无仙人血脉之力，但**被李广箭所伤，而李广箭中拥有仙人血脉气息**，二者由此融合。
5. 这种融合**与王林体内的情形一样，存在排斥之力**；符文族不知以何种手段，将这股排斥之力**化作了这一道封印**，遂使天地间无人知晓道古左眼藏于此处。

## 七、被推翻的旧说

- **云雀子**当年曾说第十九层有**符文族老祖的一丝残魂**。
- 王林否定此说：符文族老祖是**掌尊之女**，当年已**被青霖封印在妖灵之地**，故第十九层内「根本就不可能是她残魂」。

## 八、悬念

- 最后一道圆圈符文尚未破除，王林手指停在半空，第十九层门内之物尚未真正现身——道古左眼的猜测仍待验证。
