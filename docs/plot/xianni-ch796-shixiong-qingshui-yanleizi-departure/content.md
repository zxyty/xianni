# 仙逆 第七卷 名震罗天 第796章 师兄？

## 一、炎雷子劝说清水的三重理由

炎雷子目光凝重，向清水仙君提出同赴**雨之仙界的联盟星域**：

1. **恢复修为**：吞噬罗天星域修士不如去联盟星域，那里有更多大神通修士，用不了多久便可恢复当年巅峰。
2. **仙界崩溃之谜**：清水被封印后仙界遭遇浩劫，四大仙界全部崩溃；雨之仙界修真联盟内传闻有仙人存活，随他去便可知晓一切。
3. **远古卷宗**：炎雷子年轻时曾在雨之仙界修真联盟担任长老，联盟内藏有一卷宗——仙界崩溃后从天而降，其上有一丝**远古仙域的气息**，直至他离开仍无人能打开；传闻卷宗内有致使仙界崩溃的真正隐秘。

炎雷子的推论：清水屠杀仙人之后不到百年仙界便崩溃，「太巧合了」，二者必有莫大关联。

## 二、武力施压与极境制约

- 炎雷子放话「我们不是敌人……说不得，战吧」，宣称将不再留手，全力发挥**仙阵法宝**威力；其身外四十九个碎片大陆骤停旋转，透出极可怕气息。
- 清水目露红芒、阴寒之气弥漫，回应条件：「**若你虚言，我会引爆极境**」。
- 清水右目射出闪电，先令炎雷子身外冰晶尽消；随后**四十九道蕴含极境神通的红色闪电**依次射出，一一融入四十九个碎片。仙阵之宝自此散发阴寒气息、时而闪烁蕴含极境神通的红芒——等于给这件法宝上了一道致命保险。
- 炎雷子大笑称「绝无虚言」，掐诀一按，四十九碎片旋转，天空现出**巨大漩涡黑洞**。计划：先去见罗天星域众道友，再打开通往联盟星域的通道。

## 三、王林所得：雷兽未还，紫金角信物

- 王林远处高呼请归还**雷兽**。炎雷子答：雷兽还要用些时日，到了联盟星域自会归还。
- 炎雷子称王林是他的**有缘人**，拍储物袋掷出一根**三寸长短的紫金角**，立约：
  - 若王林能**凭自身之力**离开雷之仙界；
  - 且**一年之内**持此信物抵达**雷仙殿**；
  - 便再送一场造化，带其同去联盟星域。

## 四、清水的临别神念——师尊隔代传人

清水入漩涡前回头看王林一眼，目露奇异之芒，传下神念：

> 「在你的身上，本君能感受到熟悉的气息……你既学了**呼风之术**，也算本君师尊隔代传人，好好领悟，那是本君师尊一生**六大神通之一**，莫要在你手中，使其蒙尘。」

王林沉默收起紫金角，心中生疑：「那清水仙君，他莫非看出了我曾经拥有极境不成」——本章标题「师兄？」即指向这层由呼风之术牵出的同门辈分关系。

3. **第一撞**：百丈碎片随斩罗诀之后如流星轰然撞上光幕，惊天动地，光幕出现大片龟裂并蔓延；尾随修士全部顺缺口飞入。
4. **第二撞**：碎片后退数丈再瞬间增速撞击，光幕碎裂密密麻麻、光泽黯淡。
5. **使者出击**：一名全身雷光游走的雷仙殿使者踏出光幕怒斥「好大的胆子，敢闯入雷仙殿禁地」，未等王林出手即被碎片上数名修士飞出围战，其中一人大声道「前辈莫要理会此人，我等便可收拾」。王林略一点头。
6. **第三撞**：王林酝酿十息，碎片上及四周所有修士飞起环绕碎片边缘、按手其上，各自施展最大神通之力相互融合，在王林元力牵引下带着刺耳尖啸在碎片前方形成尖端；轰然撞击，光幕终于崩溃。

## 七、求生的力量（第800章主旨）
- 光幕碎片在暴风中倒卷，百丈碎片穿透进入大半，四周修士疯狂涌入千丈传送阵碎片。
- 主旨：比一切力量更强大的信念叫「求生」，世间屏障都无法阻挡的挣扎称为「生存」；如破茧之蝶，要么生，要么死。
- 问鼎修士敢向阳实修士怒视、主动出手，忘却原本不可跨越的差距与卑躬屈膝。
- 一个问鼎修士不足为道，但十个、二十个、五十个、上百个便成一股令阳实修士心惊的气势之力——尽管阳实修士屠杀这上百问鼎修士并不难。
- 上百疯狂问鼎修士中另有数个红了眼的阴虚修士，实力远非问鼎可比，带动之下极为惊人；传送阵外七名雷仙殿使者纷纷面色大变。

# 第800章 让道

## 一、开场态势

- 冲入光幕的上百修士中，隐藏着**两名阳实修士**——此前隐藏修为、留在百丈碎片上的那两人，入阵后立刻爆发修为。
- 但真正让阵法外的**七名雷仙殿使者**倒吸凉气的是**王林**：同为阳实修为，其身上却有一股「屠杀众多同阶之人后形成」的浓郁煞气。
- 四周疯狂的修士——问鼎、阴虚，乃至两名阳实——望向王林的目光中皆透着敬畏，此幕令七名使者心神剧震。

## 二、求生血战

一声「杀」点燃全场，千丈大小的传送阵碎片被法宝之光与神通之耀彻底覆盖：

| 攻击组 | 构成 | 目标 |
|---|---|---|
| 飞剑组 | 一名问鼎修士操控上百飞剑 + 十四五名问鼎修士 | 一名使者 |
| 融合组 | 一名阴虚修士领六七名问鼎修士，攻势合一 | 一名使者 |
| 阳实组 | 两名阳实修士各自散开，各领十多名问鼎修士助阵，施展元力神通 | 各一名使者 |
| 西子凤组 | 西子凤 + 两名阴虚修士 + 一众问鼎修士 | 一名使者 |
| 余部 | 分成两部分 | 最后两名使者 |

惨烈细节：
- 一名问鼎修士被使者一指按中眉心，肉身崩溃、元神消散，死前一瞬仍以崩溃中的头颅咬向使者手臂，双目红芒令使者心神剧震。
- 一名使者双手掐诀、以最简单的元力外放形成大片崩溃，众修士口喷鲜血却无人后退；部分重伤者索性靠近后**自爆**。
- 「让道」「杀」的呐喊汇成大浪，求生杀机化作实质般的信念。

## 三、王林出手：斩杀一名阳实境雷仙殿使者

1. 王林深吸口气，身影如电，一步来到一名使者身旁，**右手双指成剑，斩罗诀**一闪斩落。
2. 该阳实境使者倒退，掐诀凝聚无数**雷球**迎击，雷球撞上斩罗诀之威后一一崩溃。
3. 使者再退，张口喷出灰雾化作大手抓向王林。
4. 一道**银光**（比闪电还快数筹）自不远处袭至，直接穿透使者胸膛。
5. 王林不理灰雾大手，右手向前一指，放出一道**紫色狂雷**落于使者眉心，此人**连同元神一同灭亡**。
6. 银光化作一名**消瘦的中年男子**——即先前隐藏修为留在百丈碎片上的两名阳实修士之一；他向王林抱拳、眼露恭敬后转身助战。
7. 王林早看出这二人修为，因其**缴了仙玉**便未点破，任其留下。

## 四、「让道」与逼退

- 杀死一名使者后，全场修士气势暴增。
- 王林一晃至第二名使者身边，元力化指按出；该使者面色苍白，未还手而后退，**其余使者全部后退**。
- 退后之际银光划过一人身前，带起大片鲜血；该使者低喝「**追魂**」，喷洒的鲜血蠕动化作**虚幻血色长剑**追击银光。王林一步踏出，一把捏住血剑，元力一转将其化作红雾消散。
- 王林盯着退至阵法边缘的**六名**使者，沉声道「让道」；四周修士几乎同时低吼相和，「让道」之声交杂成天地之音、形成**音爆**，六名使者不由自主后退，仿佛所面对的是这天地。

## 五、传送阵开启

- 六名使者身后的**传送阵**闪烁开启，阵内包括**战空烈**在内的几名雷仙殿使者，在阵法开启过程中震惊地望着眼前一幕——他们无法外出，此幕却令其一生难忘。
- 众人身影扭曲，最终化作一道光柱直冲天际，消失不见。
