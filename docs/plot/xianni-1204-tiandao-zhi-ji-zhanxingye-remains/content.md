# 第1204章 天道之计（第九卷 云海之巅）

> 世界状态须知：本章王林在七彩界内独行，仍沿用自第1063章由吕烟菲奉上的化名「吕子浩」；本章无人当面称呼，行动一律归属【王林】本人。苍松子已于第1119章身死，庞德才、司马墨已于第1114章身死，本章仅以记忆/骸骨形式出现。

## 一、神识被卷入骸骨：远古一幕

- 王林右手所触的半具骸骨，与其说是骸骨，不如说是「充满不可思议之力的漩涡」，神识探入即被强吸，越陷越深，如怒浪孤舟，仿佛穿越时光去往从未接触过的岁月。
- 洞府外可见：王林身体剧颤、双目紧闭、面色苍白扭曲，右手死死黏在骸骨上。骸骨散发金光，骸骨上的经文立刻散发黑芒与金光拼杀。

### 幻象内容

1. 一处混沌世界，分不清天地，白衣模糊老者自虚无中走来。
2. 混沌天空骤现七彩之芒，如翻天之浪撕碎天地，混沌崩溃化作**七彩星空**。
3. 白衣老者右手一挥，一个「**战**」字虚幻环绕其身，散发无尽金光，硬生生逼退四周七彩。
4. 浩荡之声回荡：「天地之开为太，以天化初，地蕴成终，老夫所修，便是这天地之太，初之规则，**七彩为引，封**」。
5. 一字「封」出，无边七彩尽数向白衣老者疯狂凝聚，天地倒卷成七彩封印，将其彻底封死；七彩云涌中怒吼渐弱，最终消散。

### 「天道之计」的自述（关键情报）

> 「战星野，若非老夫当年送你战字贴，你岂能有今日空灵之境界，以你之战魂为引，老夫就可找到战老鬼空劫时埋骨之处，取其骸骨，逼出你隔代师徒二人的道髓毁其涅槃，圆**本尊天道之计**」——语声沧桑且**透出疲惫**，渐渐消失。

## 二、脱险：水晶剑救主

- 骸骨金光被黑芒彻底压过、逼至一角，黑芒直奔王林触碰的手指而去，将入其体。
- 王林预留心神的**水晶剑**晶光一闪，极速掠过指尖，在黑芒临近的刹那斩断人—骨接触。王林清醒退后，心神翻江倒海。

## 三、王林的推断链

| 结论 | 依据 |
|---|---|
| 白衣老者＝**战星野**，罗天战家先祖 | 战家先祖踏破星空而去、音信全无；战星野天资极高，早年无意得战字贴，自行琢磨感悟战之意境，为追寻更高境界而走，后代遍寻无果 |
| 杀他者疑为**掌尊** | 自称「本尊」，拥有太初之力；七彩神通与**残夜**类似但远超残夜之力，一式神通即令战星野无反抗之力 |
| 战星野未必真死 | 骨内留有**如此清晰的意志**，若完全死亡意志应消散；且疑似掌尊者最后声音明显疲惫 |
| 「空灵」「空劫」＝第三步中的两个境界 | 由对话中「今日空灵之境界」「战老鬼空劫时埋骨之处」推得 |
| 画战字贴的老者＝**战老鬼**，战星野隔代之师 | 王林感悟战字贴时曾见一老者，自言修为达到「空」之境界、要破开界线；疑似掌尊者对其颇有忌惮，故设局：赠战字图给战星野修炼，最后杀之取魂，只为寻其埋骨地 |
| 洞府第二具骸骨或即战老鬼 | 四个石碑、两具完整骸骨，第一具已确认是战星野 |
| 战字图＝战老鬼留下的**道统** | 同上推理 |

## 四、三张战字帖合一

- 王林储物空间内共有三张战字帖：前两张已开启，第三张自战家后人处获得后从未开启。
- 三个光团（三幅战字帖）一出现，骸骨上被逼至一角的金光骤然剧烈闪烁，脱离骸骨直奔战字帖融入其中，三帖相互融合。
- 融合完成后金光照满洞府，前方现出一个**金色虚幻的「战」字**，带浩荡气息扑向王林，被其一挥收入储物空间。
- 王林感叹因果：「你获得战字帖，无形之中成为了战老鬼的隔代传人，又因你，使得战老鬼埋骨之处被那疑似掌尊之人知晓……无数年后，王某又从你后人那里得到了战字帖……今日，又看到了你的骸骨」。随后转身离开，以山石封死洞府。

## 五、离开山谷前后的处置

- **第九座洞府**未开：其上禁制王林破不了，只见其内充满**七彩雾气**，看不清内容。
- 山谷内，王林对着司马墨的骸骨长久沉默。
- 临走前去了**蚊兽**所在的第一座洞府，留下更多**元晶**。

## 六、重返雾气：铭志者与石像

- 目的地：心神此前所见石碑之地，去查看**战星野的上半具骸骨**。
- 凭搜取**庞德才**与**苍松子**的记忆，王林对七彩界与其中路线已极为熟悉，贴地疾驰而非升空。
- 途经封印**青衫老妪**的阵法：阵法**已被打开**，青衫老妪**失去踪影**。
- 越过山脉进入雾气，耳边铭志者喃喃，数个铭志者从身边飘过。
- **铭志者本质**：古往今来的修士，生前必为天资绝佳、对道领悟极高之辈，因而被**道经**所困，在此成为**他人养道之物**。
- 雾气中见到巨大石像，王林跃至其头部停下。

## 七、苍松子功法情报（来自记忆）

- 功法名：**百世血元化婴之术**；其召唤的**封界第七灵**是在该石像内感悟出来的。
- 血元化婴可修出**九个类似元婴之物**，威力远超元婴，且**非元神之物**。
- 效果一：修炼神通速度**提高九倍**。
- 效果二：每个元婴可各自凝聚一样神通——常人有些神通不可同修（如青衫老妪的**取阳聚阴归祖之术**），苍松子九个血婴可分别修炼，不受限制。
- 与王林一战的实况：先被青衫老妪收走一婴，随后在王林神通连续打击下二人两败俱伤，九婴未能尽数施展。

3. 第二具完整骸骨是否为战老鬼？
4. 第九座洞府的七彩雾气与禁制。
