# 第2003章 道古使团

## 一、古族风土与政体

### 地貌
- 古族为苍茫大地、**黑土一片**，与仙族的细腻美丽截然不同，充满辽阔与粗犷；黑色大地令人初见压抑，而辽阔天地又在目光尽头将压抑释放。
- 建筑与族人皆带「粗放、庞大」之感，霸意似埋在每一个族人与建筑的核心。

### 三脉君主制
- 与仙族「五州唯一皇权」不同，古族是**完全彻底的君主制**，在大地上划分出 **道古、极古、始古** 三脉之国。
- 三位古皇之权非仙皇可比：皇权至高无上，如无形压力笼罩大地与所有族人心神。
- 对比：仙族皇宫遇难，宫内之人毫不犹豫避开；古族皇宫若遇此事，只有两个极端——**一，入侵者死亡；二，全族族人灭绝**。
- 古族之皇即是天，代表古祖，血脉最为高贵尊崇，任何力量都无法抹灭。

### 古皇 vs 大天尊
- 修为上：**大天尊最高**，为一脉的守护者。
- 权利上：**古皇可号令一脉所有族人**；若古皇与大天尊之命相左，听古皇之命者会远超大天尊。就算大天尊也无权罢劾古皇。
- 与仙族对比：仙族大天尊（如久帝）敢算计仙皇甚至出手杀戮；古族大天尊虽修为无上，却绝不因任何事伤害古皇——因为留下这道**万古封命**者，是圣地中的**仙罡最强大天尊**，他会保护「可以成为古皇的存在」，护佑古之三脉。

### 圣地
- 位于**三脉接壤之地**、古之三脉的中心，也是那位最强大天尊所在。

## 二、王林入古族

- 王林对古族的了解来自两处：**洞府界玄罗**处，以及**双子大天尊的紫阳宗**古卷。故此番到来，不似当年初踏仙族时的茫然。
- 障碍：古族范围太大，且他手中**没有前往道古的地图玉简**，须先寻得玉简方能准确前往**道古皇城**。
- 他对三脉的判断：「以**始古**一脉最强，以**极古**一脉最为齐心，**道古**一脉族人最多，可却也是最弱的一方。」
- 蹲身抓土嗅闻，感到这片土地上存在**令其体内古族血脉颤动**的力量；起身向前，心中默念：「**师尊，弟子来到了古族**」。

## 三、黑石城封城

- 城池概况：靠近大海，通体由**黑色巨石**构建，远看粗糙却有霸意扩散；属**始古一脉·木桑郡**边缘。
- 城门外原本人流如潮，皮甲大汉呼喝驱赶，众人见之惶恐避退。喝令内容：
  - 「半柱香后，将会**封城**」
  - 「进入黑石城后立刻各自散开，**禁城三天**，若无**城主之令**不允许外出」
- 不到半柱香，城门外已然空旷；近百名皮甲大汉分守城中关键角落，目光时而看城门、时而看向**城中心一座高耸建筑**。
- 王林在城外远处观望，第一次见到如此多古族之人：**古妖、古魔、古神**——身体大小如常，但**眉心、左目右眼中的星点**让他感到熟悉。

## 四、九星现身，被尊「神圣大人」

- 城门旁七八名皮甲大汉，眉心或双目星点为**五六星**。王林转身欲走时被喝止。
- 两名**五星古神之体**大汉上前盘问：「你是何人，来自何处」「把**身份令牌**拿来」「把你的**族印**露出来」。
- 王林答「**王林**」（自报本名），继而眉心慢慢浮现**九个星点**，闪烁幽光，看起来与古族族人无异。
- 二人瞳孔收缩、连退数步抱拳：「**参见神圣大人**，我等不知大人来临，之前言语不敬，还请神圣大人责罚」，神色恭敬且**带一丝狂热**；其余五人见九星后亦上前抱拳参拜。

### 王林的推测与自身根底
- 推测称谓体系：显露**九星古神**被称「神圣大人」，则**九星古妖=妖圣**，**九星古魔=魔圣**。
- 疑问：同时具备九星古神、古妖、古魔者，在古族又当有何称呼？（本章未解）
- 传承限制：他所得**烨寞的传承并不完整**，相关记忆知晓不多，只知古族无论哪一脉族人都由**古神、古妖、古魔**三者组成。
- 根底来源：在**洞府界古族第二劫**中，他获得了**魂血**与**古祖的认可**；这些年虽未强行修炼古族之体，随时间流逝已做到**三古全部九星**，只是极少显露。
- 观察：能达九星者在古族似**并不太多**，或因此地偏远。

## 五、地图玉简与古族疆域

- 王林随意开口索要地图玉简（用**古族特有语言**，仙族之人多半听不懂）。大汉右手拍胸口即幻化出玉简奉上，自陈「记录不全，只有大概的范围」。
- 玉简特征：仙、古两族通用，只是**记录与打开所需的气息不同**；此简仅对附近几郡详细，越远越模糊。
- 由玉简加此前了解，王林确定古族疆域格局：
  - 古族共 **三十六郡**；
  - **最上方十二郡**为**始古**一脉所在；
  - 其下**两个方向、成三角对列之地**，分别为**极古**与**道古**；
  - **黑石城**位于**始古一脉·木桑郡**边缘。

## 六、道古使团（本章题眼）

- 封城缘由：城主令众人在一炷香内清空黑石城四门，以迎接 **计都皇子** 与 **道古使团** 的到来。
- 使团来历（守城大汉所述，其自称知晓也不多）：
  - 由**道古皇族**派出；
  - **数百年**来不断在整个古族内**寻找貌美女子**；
  - 据说是**道古之皇要选妃**。
- 王林闻「道古使团」四字时「目光微不可查的一闪」，托词「我刚刚从闭关内走出，对此并不知晓」以套取详情。

## 七、本章要点小结

1. 完成古族政体/三脉/圣地/皇权与大天尊关系的设定铺陈。
2. 王林正式踏入古族，明确目标：取详细地图 → 前往**道古皇城**。
3. 九星身份成为其在古族的通行证与保护色。
4. 引出**计都皇子**与**道古使团**选妃线，为其潜入道古提供路径。
