# 第1628章 幻真劫

## 一、因果印碎四角祭坛

- **神通展开**：王林施展「因果印」——掌开为因，掌握为果。裂缝内的四角祭坛通体一震，延伸到裂缝外的两个角在震动中出现大量裂缝、骤然崩溃化作无数碎末爆开，波纹扩散后被火焰焚成黑烟。
- **抽剑之气**：更惊人的是祭坛中心环绕模糊身影的四把剑，也在这一抓之下颤抖哀鸣。四道飘渺如烟的气息被王林一掌自剑上抽出（肉眼不可见、神识可感），直奔其右手并被握入掌心。当年让王林颇为忌惮的四剑，就此失去一切光泽，如凡铁般再无半点灵气。
- **因果印之霸道**：因果在手，一切本源之物全部难逃掌控，寻常之辈连闪躲的资格都没有；文中回述连第三步大能青衣男子同样在此印下骇然失色。
- **碎灭**：王林右掌握住、双眼寒光一闪，口吐「碎灭」二字，尚未探出裂缝的半个祭坛骤然崩溃，碎片卷成旋风般的风暴，旋即被四周火海吞噬干净。

## 二、生死大印灭天劫使者

1. **身影出坛**：祭坛崩溃中一声低吼响起，盘膝而坐的模糊身影猛地抬头，迈步走出爆开的祭坛，自火海中一闪而出直奔王林。其形貌始终模糊虚幻，右手抬起、喃喃低语间弥漫黄色光芒，临近王林时一掌拍来。
2. **第一掌「生」**：王林冷哼不躲不闪，大袖一甩，左手伸出白气缭绕、生机无限，与之隔空对轰一掌，轰鸣滔天，身影蹬蹬后退数步。
   - 说明：单独的生机通常无实质伤害，但王林已明悟生死，这蕴含生机的一掌是生死印的一部分——第一掌「生」，是为送入一股会化作死亡的烙印。
3. **第二掌「死」**：王林道「如此修为，也敢向王某出手」，身子一晃出现在后退的身影面前，右手黑气弥漫按在其胸口，喝「死」。黑气顺右手疯狂钻入其体内，引动先前埋下的生机，在体内完成一次生死交汇，形成**生死大印**。
4. **结果**：身影体内剧烈轰鸣，连喷数口金色气息，身体被狠狠抛出，满身模糊消散了一些，露出充满骇然与不敢置信的双目，最终被体内生死印扰乱生死、身体崩溃。
5. **身份**：此即当年让王林狼狈的**天劫使者**；今日在王林面前已弱得不堪一击。

## 三、一指问天

- 王林话语平静却传遍八方，更传出百万雾气之外，落入**南云子**、**司徒南**（按世界状态须知：即自称司徒南的司徒南断臂所化人影）以及数千修士耳中：
  > 「天劫，你有何资格来降劫于我」
- 这一句极为狂傲，却在此刻无人质疑，界内修士热血沸腾。
- **积压千年**：这句话王林忍了一千多年——自当年在妖灵之地问鼎、第一次天劫降临时起，他就在忍；今日他有了这个资格。
- **四问**（一指问天）：
  - 问这天，是谁给你惩罚我王林的资格；
  - 问这天，是谁给你夺走**李慕婉**的资格；
  - 问这天，是谁给你惩罚众生的资格；
  - 问这天，又是谁给你成为天的资格。

## 四、天地回应（悬念）

- 星空轰轰作响，百万范围的雾气仿若暴怒般大范围蠕动，裂缝内传出阵阵闷闷低吼，震撼心神。
- 声音愈烈之际，百万雾气骤然旋转、发出更强轰鸣，随其转动，一股天地威压之力扩散，笼罩无尽——天劫的下一步反击将至。

## 五、要点归纳

- 王林对天劫的态度自「忍」转为「问」与「战」，标志其与天劫之争进入正面对决阶段。
- 因果印（碎本源）与生死印（生→死交汇）在本章各展一次完整用法，构成本章战斗骨架。
- 天劫的手段被逐层剥除：祭坛毁、四剑废、使者灭，但百万雾气与裂缝显示更大的威压仍在酝酿。

# 第1536章 幻真之劫与真假道回劫

## 一、天劫落幻——熟悉面孔的围拢

- 雾气旋转，其内浮出无数似魂的模糊身影，发出凄厉嘶吼，随后清晰化作王林熟悉的面孔。
- 出现者包括：**爹娘**（白发苍苍、相互搀扶、含泪伸出干枯之手欲抚其面）、**四叔**、**王卓**、**张虎**、**柳眉**、**李慕婉**（泪眼朦胧却带温馨微笑，擦泪安静走来），以及**藤厉**、**藤化元**等王林一生所遇的敌人、朋友、亲人。
- 柳眉幻象怀中抱着一个**被黑气缭绕的婴儿**，哭声尖锐、穿透心神。
- 伴随嘶吼与温柔呼唤弥漫雾中，冲击心神。

## 二、此劫之凶险：真假随时可转

- 此幕为天劫幻化，几乎难分真假，**相由心生**，给人真假随时可转化的错觉。
- 最险处在于：若你判定一切为假而动手毁灭，或会立刻发现这一切原本真实——**你毁灭的是亲人残留世间的最后之魂**。

## 三、王林破劫：明悟真假本源

- 王林沉默、轻叹，深看四周熟悉面孔后**闭上双眼**。
- 他**已明悟真假本源**：闭目刹那一切为假，睁眼所看一切再次成真。
- 再度闭目，右手抬起向前一挥——如同当初挥散空门——将这些或真或假的身影一并散去：*尘归尘，土归土，从何处来，回何处去*。

## 四、以劫还劫：真假之道所化的『指天怒吼』

- 王林大吼：「天地不仁，方以此劫于某，既如此，王某便同样如此天，睁开你的眼，去看一看，在这天地内，除了我王林外，还有多少人的指天之孔（吼）」，右手一指上空。
- 其**本源中真假所化神通「真假之道」**赫然而起，四周雾气内幻化出说真是真、说假是假的身影：
  - **周佚**：抱着女尸向天空凄厉怒吼、流泪；
  - **白凡**：指着苍天癫狂大笑；
  - **清水（清水仙君）**：苏醒之后想起记忆，望天在沉默中爆发；
  - **拓森**：狂傲至极，怒骂天空；
  - **散灵上人**：看到他所认为的「天的尽头」后心神错乱，哀嚎中双眼燃起疯狂；
  - 以及**闪雷族七百万天地**内无数子民、无数在劫难下死亡的修士。
- 这些身影的指天之吼形成一股特殊天劫——**天以幻真之劫加于王林，王林便以真假道化劫回敬于天**。
- 结果：无形之力冲入上空裂缝，但**裂缝毫无反应**，其内咆哮不曾间断。

## 五、加码：神识遍昆虚星域，取万古星魂之怨

- 「不够么」——王林闭目，**神识轰然扩散、转眼弥漫整个昆虚星域**，融入一处处修真星，融入其**星魂**与记忆。
- 设定要点：亘古以来生存于昆虚星域者，无论凡仙，在死亡、命运波折、凄惨之时抬头望天所喊出或憋在心中的怨气，纵然无人看到、目击者亦已死去，**其所生存的星球有魂，默默记住**。
- 王林以神识感受这些记忆，以真假道幻化转变，形成一股**针对天的劫**，轰然爆发。
- **成效：象征天劫的裂缝第一次颤抖，其内咆哮戛然而止。**

## 六、旁观者：战老鬼的判断

- 雾气外另一方向，**战老鬼**双眼露出从未有过的明亮之芒，目中毫不掩饰浓浓贪婪。
- 他舔了舔嘴唇：「**他有三威的可能，就是第三个**」——暗示王林具备成为「第三个（三威）」的可能，战老鬼对此心生觊觎。

## 七、要点归纳

1. 王林此劫为**心魔／幻真类天劫**，破法不在斗力而在**真假本源之悟**。
2. 王林首次将「真假之道」用于**主动向天回劫**，其素材为他人之「指天怒吼」。
3. 单凭个人记忆中的怨天者不足以撼动天劫，**汇聚整个昆虚星域亘古星魂之怨**方使裂缝颤抖。
4. 战老鬼的觊觎为后续埋线：王林被视作「三威」候选之一。
