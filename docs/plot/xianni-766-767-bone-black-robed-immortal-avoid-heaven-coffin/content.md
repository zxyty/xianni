# 仙逆 第816～819章｜第七卷 名震罗天：骨 / 避天棺

## 一、场景与阶段

本片段承接王林与塔山对阵敌方五个分身的战斗，最终推进至阵法与水晶棺材（避天棺）所在地，引出守棺的白骨黑衣人。

### 阶段1：五分身溃败（第816章）

- 子母道枯幽光一闪，煞气笼罩，与塔山厮杀的分身退后与其余四个分身汇合，合力掐诀布下光幕。
- 光幕被煞气石化并崩碎，五个分身面色苍白、眼露骇然，转身逃遁。
- 王林一步消失，出现在其中一分身旁，口喷金光——内含**三寸小印（封仙印）**，瞬间涨至十丈砸落。
  - 大印之下时间仿佛凝固，分身全身力量被彻底封印，更生出面对天威的错觉。
  - 肉身崩溃后元神欲逃，大印金光暴亮照耀千丈如太阳，金光穿透元神形成封印，将其吸入印内。

### 阶段2：识破诱敌与四连自爆（第816章）

- 王林追击片刻后停手冷笑：「想要把我引开么」，盘膝坐于虚空以神识搜索，塔山守护四周。
- 数息后王林睁眼直奔一个方向；同时四个远遁元神折返反扑。
- **第一次自爆**：为首者燃烧元神与肉身，修为疯狂暴增、速度快出数倍，逼近十丈自爆（阳实巅峰自爆）。
  - 王林急退，一拍储物袋放出**三面小旗**形成紫气漩涡，并取出**山河图屏风**化四周为山水画幕。
  - 画幕扭曲化解部分（毕竟非真正的山河图），紫气漩涡被打开缺口，毁灭力穿透肉身直奔元神。
  - 王林自评：「幸亏有**古神皮甲**，否则在这自爆下，我即便不死，也定然重创」。
- **第二个分身**：被子母道枯自双脚起灰光石化，王林双指成剑点其眉心，化作无数碎石崩溃。
- **第三个分身**：王林以**仙术定身**定住，塔山跃出抱住其冲向远处，硬扛自爆冲击，面色苍白但撑住。
- **第四个分身**：被体内力量撕碎成风暴波及王林；王林操控**封仙印**化百丈竖立如盾抵挡，连退三十余步，杀机至极限。

### 阶段3：抵达阵法与水晶棺（第816章末）

- 王林如燃烧流星前行：塔山紧随其后，子母道枯飘于上空，封仙印位于下方，数万里一闪而过。
- 见到庞大阵法及其内的**水晶棺材**，以及阵外目光阴沉、隐含震惊的**黑衣男子**。
- 狂风吹起黑袍，王林瞳孔一缩：黑袍下除头颅外，全身皆是**森森白骨**。

### 阶段4：白骨黑衣人交手（第817～819章「避天棺」）

**黑衣人手段（皆自眉心幻化）**

| 神通/法宝 | 效果 | 结果 |
|---|---|---|
| 十余把黑光短剑 | 如灵蛇缠身连击 | 被塔山以拳挡下，难伤其身 |
| 白羽之扇 | 生狂雷风暴 | 被王林太古雷龙元神一口吞下，王林反获雷力滋补 |
| 「鼎天」 | 聚方圆万里虚空奇异之力上顶 | 震停封仙印下落；余波震退仙选族族人，弱者七窍流血 |
| 双眼黑芒 | 消解斩罗诀 | 首波斩罗诀被破 |
| 「十龙鼎天」 | 眉心幻出十条黑龙撞击封仙印 | 撞击无功，反被震退 |
| 「十龙碎空」 | 十条黑龙依次自爆 | 冲散金符、掀开封仙印，成功脱出封印之地 |
| 仙幕 | 手骨掐诀向后一拍凝聚仙力 | 被两波（各十道融合）斩罗诀击碎 |

**王林手段**

- 仙卫塔山正面挡短剑与自爆冲击（后喷血神色黯淡）。
- 子母道枯放出煞气使黑衣人身现灰光——被其指骨掐印逼退。
- 太古雷龙元神吞噬狂雷风暴。
- 封仙印三段递进：砸落 → **「解印之封」**（数十万金色符文、金光万丈如虚空悬日）→ **「落」**（势不可阻）→ **「封」**（千丈金符向黑衣人凝聚层层封印）。
- 仙剑 + **斩罗诀**：连斩十次将十道斩罗诀融合为一，两波破仙幕。
- 抛剑喝**「定」**：黑衣人手骨停顿一瞬，仙剑斩落其整条右臂骨。

## 二、关键设定披露

- **子母道枯的来历**：黑衣人见之长叹「已经有很多年，没有见过师尊的法宝了」——子母道枯为黑衣人师尊之物；他据此认为王林「没资格拥有我师尊的法宝」。
- **黑衣人状态**：除头颅外全身为骨，修为高深绝非阴阳虚实境界，但因残缺，实际发挥不超过**窥涅初期**（王林判断）。
- **黑衣人在此守棺无数万年**，封仙印逼近不足十丈时是他「第一次站起身子」。
- **封仙印评价**：黑衣人称此宝「即便是在仙界，也足具威名」，出言索要。
- **仙选族**登场：族人赶来时被「鼎天」余波震退，修为低弱者七窍流血。

## 三、战果小结

- 五个分身全灭（1 被封仙印收元神，1 石化点碎，3 自爆但未杀王林）。
- 王林受自爆余波穿体，赖古神皮甲未重创。
- 塔山两度硬扛自爆，喷血受创但存活。
- 黑衣人破封逃出封仙印封印，但被斩去右臂骨（脱体后化作骨粉消散）。战斗未结束。

# 王林 vs 骨骸黑衣人：断臂、呼风与蓝丹

## 一、断臂之机
- 王林时机把握极准：定身术单独施展对黑衣人时效极短，难以成攻；因仙剑距黑衣人极近，定身瞬间恰好足以奏效。
- 结果：黑衣人右臂被毁，低头见空空右臂，眼中透出难以想象的愤怒与浓郁杀机。
- 黑衣人自述：「本仙在此地守护无数万年，这才恢复了完整的骨骸」——遂放弃封仙印，疯狂冲向王林。
- 其仅剩左臂抬起、双指成剑一指刺来，黑暗虚无被划开一道裂缝，可见威能。

## 二、呼风：仙帝白凡的旧梦魇
- 王林后退间右手指天，喝「呼风」，不惜元力消耗；黑风自右手生出，散开笼罩四周，寒气阵阵，直扑黑衣人。
- 黑衣人震惊程度**数倍于**此前见王林持有其师尊法宝之时，惊呼：「仙帝之术呼风你到底是什么人」「你是仙帝白凡的什么人」。
- **旧事（闪回）**：
  - 黑衣人当年违反仙条，师尊逍遥子求情，仙帝白凡仍施展一式神通，言明若能抵抗便饶性命——所施即「呼风」。
  - 呼风之下其肉身崩溃、骨头消散，若非逍遥子出手，连头颅都保不住。
  - 此后被逍遥子送入此地**守护那口棺材**，借大阵打坐无数万年，方才驱除元神内的呼风之法，得以重新形成骨骸。

## 三、蓝丹抗风
- 黑衣人吓得魂飞魄散，急退并张口喷出一枚**蓝色之丹**，蓝光柔和，将四周染成蓝色，使其在黑风中未受伤。
- 王林不答话，迈步前冲，身外黑风呼啸，仿若与黑风融为一体，瞬间临近，右手前按，黑风随之冲出。
- 黑衣人面色苍白再退，身前蓝光略黯；随即双手前推，蓝丹旋转如漩涡，将黑风吸入其内。
- 黑衣人内心判断：
  - 「此人呼风之术不强，但我却不能碰到一丝」——一旦沾染即引发体内残存呼风之法。
  - 呼风歹毒，入体几乎无法彻底驱除；再度入体立刻引发当年之伤。
  - 结论：「眼下就要靠师尊赠予的法宝了」。

## 四、射神车化蝶
- 王林杀机浓郁，一拍**储物袋**，射神车幻化而出，其上五彩光芒一闪，化作**五彩蝴蝶**。
- 蝶现身后翅膀微扇，散出一片五彩之粉，看去极为美丽。
- 王林双手掐诀，向后退中的黑衣人一指，蝴蝶缓缓前飞、翅膀一扇——片段止于此处（悬念）。

## 五、要点与伏笔
- 王林会「呼风」这一事实，直接把他与**仙帝白凡**的关联抛到台前，构成黑衣人认知崩塌的关键。
- 黑衣人身份链条清晰化：**逍遥子之徒 → 违仙条受罚于白凡 → 被送来守棺 → 无数万年打坐成骨骸 → 守护封仙印/棺材**。
- 待用底牌：黑衣人「师尊赠予的法宝」尚未出手。
- 王林持有「其师尊法宝」一事此前已被黑衣人察觉，本片段再次点出。

## 归属说明
- 依【世界状态须知】，「仙帝白凡」已于第746章死亡，本片段中白凡仅以**当年往事回忆**形式出现，不记新行动。


## 场景

地点为一处安放棺材、以血液布置的庞大阵法所在的密闭之地（王林明言「不杀此人，就无法离开这里」）。对阵双方：王林 vs. 一名以骨骸之躯行事的黑衣人。

## 战斗经过

1. **蝴蝶初现**：黑衣人后退中身子一顿，左臂手骨砰然碎裂化作飞灰，在其身前凝成一只灰色蝴蝶——即射神车所化。
2. **逐段崩解**：蝴蝶翅膀再扇，黑衣人双脚骨骸随即崩溃，面色苍白、惊色极浓。
3. **自毁求生**：眼看蝴蝶将再扇翅，黑衣人大吼一声，主动令半截身子崩溃，借爆发推力瞬间倒退极远，落在放置棺材的阵法之上。
4. **阵法反哺**：上半身落入阵法刹那，阵内血液中涌出道道黑气融入其体，下半身迅速凝成虚幻之体。蝴蝶再扇则再碎，黑气再涌则再生，如此往复。
5. **黑气转向**：庞大阵法的黑气不再涌入棺材，转而全部灌向黑衣人，其虚化之体渐渐凝实，最终仿佛已具血肉。
6. **王林出手**：王林目光闪烁，向前一冲，抬手再施呼风之术。连续两次施展致体内元力不足、面色苍白，但眼中杀机不断。黑风纵横化作大片尘埃，直出向阵法。
7. **左翅定局**：黑衣人正欲退后之际，蝴蝶单独左翅轻轻一扇——其虚幻身躯连同身外黑袍一并崩溃瓦解，半空中只剩一颗头颅，眼中惊骇浓郁到极限。
8. **绝望呼喊**：黑衣人失声道「破坏规则这是破坏规则之力的法宝」，毫不犹豫迅速后退，而黑风已呼啸吞噬而来，其眼中露出绝望。

## 关键设定信息

- **射神车 = 破坏规则之力的法宝**：由敌方以惊骇口吻直接点破，是本片段最重要的设定披露；其化形为灰色蝴蝶，可分别驱使左右翅，每扇一次即造成一次「崩溃」级破坏，虚幻之体亦不能免。
- **棺材血阵的黑气**：具备为受损之体重塑肉身/虚幻之体的功效，且黑气可在棺材与人之间改换灌注对象。
- **王林状态**：连施两次呼风之术后元力不足、面色苍白，属消耗吃紧但仍占上风的局面。

## 悬置未决

- 黑衣人身份、来历未在本片段交代；其言下之意为当前修为并非巅峰、且已失肉身。
- 头颅尚存，黑风正吞噬而来，最终生死在本片段结束时尚未落定。

# 龙道子破棺换身：避天棺秘辛与王林追击

## 一、绝境与自曝身份

黑衣人（仅余头颅之身）在黑风吞噬而来之际透露关键旧怨：

> “若非是我当年受白凡呼风侵害，此刻也不会如此畏惧那不成形的呼风之术，我不甘心。”

- 他猛吹一口**元神精气**与黑风相撞，借爆炸推力使头颅急速后退。
- 退至**阵法中心的棺材**旁，咬牙道：“师尊，不是弟子不守承诺，而是眼下，若不打开棺木，弟子必死无疑。”
- 由此揭示其名：**龙道子**。

## 二、避天棺秘辛（师尊遗言回响）

龙道子头颅落入棺中的一刻，师尊当年的话在其耳边回荡，交代了三件事：

### 1. 龙道子的处境
- 龙道子**犯了仙条**，被**仙帝**惩罚，师尊无法救他。
- 师尊只能将其**头颅连同元神封印**，存于此处，令其**守护此棺**。
- 师尊夜观天际，算出**仙界会有大劫**，认为“你离开，也未尝不是一件幸事”。

### 2. 避天棺的来历
- 名为**避天棺**，是**远古仙域之宝**，师尊历经凶险方才获得。

### 3. 棺中青年的身份与遗命
- 师尊**未成仙前，俗间有一子**，自觉亏欠太多。
- 师尊取其**一丝魂魄**，成仙后**放弃一切修炼时间与机缘**，只为寻到避天棺，将魂放入其中，可**重新凝聚魂魄肉身**，终有一日苏醒。
- 遗命：那子苏醒后，龙道子须**认他为主，此生不得背叛**；届时龙道子也可**以此棺凝聚肉身、恢复修为**。

## 三、破棺：青年消散、龙道子重凝肉身

- 龙道子以头颅狠撞棺材，砰的一声，**棺盖被撞开**。
- 棺内躺着的**青年肉身立刻消散**——似与外界一接触便崩溃，瞬息之间棺内**再无一物**。
- 龙道子低语“师尊，不要怪我”，头颅进入棺中。
- 棺盖**自动飞回紧扣**，一震之下**化作一道晶光**冲出阵法，向远处飞去。
- 王林亲眼目睹：青年在开棺一刻消散；黑衣人头颅入棺后，其**肉身以肉眼可见的速度迅速凝聚而出**。

## 四、王林追击

- 心神一震，双眼一凝。
- 右手掐诀：**射神车**化作的蝴蝶飞来落于脚下，载其直接追出。
- 左手虚空一抓：**封仙印**带着呼啸之声紧跟其后，直奔前方棺材追去。

## 五、要点与待续线索

1. **白凡呼风**成为龙道子的心理死穴——旧伤化作当下战力的破绽（按世界状态，仙帝白凡已于第746章身死，此为回忆性旧怨）。
2. **避天棺**具备“凝聚魂魄肉身”的能力，同时对棺内之人有“开棺即散”的脆弱性——开棺等于毁掉沉睡者。
3. 师尊之子（棺中青年）魂魄的去向与生死在本片段未明写，只写肉身消散。
4. 龙道子以背信换命，从守棺者变为夺棺者，避天棺随之带着他遁走。
5. 王林同时动用射神车（遁速）与封仙印（攻击/镇压），显示其志在必得。

# 第766章 龙道子出棺崩灭·避天棺入手与幽冥兽渡域

## 一、开场：塔山融入王林
- 塔山一晃化作虚影，融入王林身后消失不见。
- 王林眼中寒芒，紧追前方棺材不舍。

## 二、龙道子在避天棺内的复活与修为暴涨
- 晶石棺木（避天棺）内，龙道子肉身以极快速度凝聚而出，「拥有肉身」的感觉是他无数万年从未有过的。
- 心态转折：他自述在无肉身状态下为师尊**逍遥子**守护其子无数万年，宁可自身痛苦也从未打棺木的主意；如今发现只需躺入片刻即可恢复肉身，遂断定逍遥子欺骗自己——担心他恢复肉身后不再守棺。愧疚转为杀机。
- 修为阶梯（本章明确的仙界阶序）：
  1. 与王林一战时：**阳实与窥涅之间 = 一品天仙**；
  2. 稳入**窥涅初期 = 三品天仙**；
  3. 片刻间攀至**六品天仙**；
  4. 达到**九品天仙**——其当年在仙界的巅峰；
  5. 突破天仙级别，达到**仙王**，为**三品仙王**。
- 对比：逍遥子为**九品仙王**。
- 龙道子扬言：杀掉「区区上仙」王林、夺其法宝，此后不回仙界，天下之大逍遥子再难寻他。
- 王林在追击中察觉棺内仙力疯狂凝聚、越来越强，震惊倒吸口气，正要后退。

## 三、出棺即崩灭：龙道子之死
- 龙道子按飞棺盖冲出，磅礴仙力如风暴弥漫四周（强度虽不及血祖，仍极强）。
- 向前踏出一步的刹那**剧变突生**：双脚、双腿、上身、双臂无声无息消散，头颅与元神随之化作碎片崩溃——与此前他开棺时棺内那青年消散的一幕几乎一模一样。
- 临死质问（重要设定线索）：
  - 逍遥子曾说**避天棺内哪怕只有一丝残魂也可成型**；
  - 当年正是龙道子为逍遥子获得避天棺的线索，才**触犯仙条**；
  - 他推断即便按逍遥子所说、等其子苏醒后进入棺中修养，结果也一样——**逍遥子是想杀他**。

## 四、怨念与「道化·黄泉」
- 龙道子死时爆发出自仙界崩溃前直到此刻、无数万年累积的怨念，强度无法想象；若不驱散，恐将永恒存于虚空，甚至无数岁月后从中**再次诞生一个新的生命**。
- 王林右手指天，轻声道「道化，黄泉」，铺展一条黄泉；怨气如找到宣泄口直奔黄泉、融入其中，与黄泉内原有怨气融合并不断壮大。
- **一炷香**后怨气尽被吸入，王林转身离开之际黄泉消散。

## 五、避天棺入手与李慕婉线
- 王林虚空抓取棺材，凝重审视后判断：
  - 此物可**滋养魂魄、恢复肉身**；
  - 但**不能出棺**，一旦走出便烟消云散；
  - 「若非本该如此，那就一定是使用的方法不对。」
- 收起棺材远离。见其神通的刹那，王林想到了**李慕婉**。
- 目标确认：**东临星·向家**。
  - 王林来罗天星域有二事：躲避天运子等老怪；寻向家、找令李慕婉苏醒之法。
  - 线索源头：**潮汐深渊**内**画轴之上的女子**说出可令李慕婉苏醒之言，当时给王林以天地崩溃般的冲击。
  - 心念：无论真假、无论难度与危机，都必须去一趟——「有一些事情，是惊涛骇浪也无法阻止」。
  - 现状判断：以当下修为，应可去东临星一探究竟。

## 六、回溯：罗天西域·陌域·幽冥兽
- **陌域深处**：属罗天西域，灰雾弥漫、看不到十丈外，长久无修士身影，形同绝地，四周极静，雾气笼罩无尽头。
- 某日雾气自微弱波动转为剧烈翻滚，方圆数十万里灰雾如怒浪涌开。
- 现身之物：一头**鲸鱼状庞然大物**，粗看不下数万里长；头部**无眼，只有一张大口**；口中有一座**阵法**。
- 王林与其身后的**仙选族**族人自阵法中走出，被雾气冲力推出。族人面露茫然与对未知世界的胆怯，紧随王林。
- 王林据**涂司**记忆确认此为**幽冥兽**：
  - **古神时代**便已拥有，来历不详；
  - **无任何攻击性**，胆子极小；
  - **体内另有乾坤**，仿若蕴含另外一个世界，庞大程度远超本体大小；
  - 王林感叹涂司记忆中之物至今仍存。
- 幽冥兽发现王林等人后缓缓合嘴、慢慢退后，消失在雾中。
- 王林形貌：一身青衫、看似青年，却有浓郁至化不开的沧桑，仿若千年老者寄身青年体内。

## 七、章末悬念
- 王林**消失近大半年**后再次出现于罗天星域。
- 此时罗天星域已发生**两件翻天覆地、骇人听闻的惊天大事**，其中之一**矛头赫然指向王林**。
