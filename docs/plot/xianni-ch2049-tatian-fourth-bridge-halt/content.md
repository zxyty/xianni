# 第2049章 止步

## 一、临别一望：太吉神境之门

- 王林自「如踏天之上」收回目光，最后望向**古族与仙族之间**、竖起卷动的**苍茫之海**内，由**九根柱子**组成的**太吉神境之门**。
- 即便以他此刻站在**第二座踏天之桥**上的修为，仍看不清晰——此太古神境的存在远远超过王林当前能力。
- 闭目一瞬，其目光自仙罡大陆消失；再睁眼时，人已在那未知奇异空间的第二桥上，且位置由桥首变为**桥末**，之前迈出的几步如梦幻不真、分辨不清。

## 二、第二桥：自问道心

- 远眺第三、第四直至第九桥，以及第九桥后模糊虚幻的景物——看不清、很遥远，看久了连心也遥远起来，如一座座不可攀越的高峰，令人心生**止步**之念。
- 此念一生便无限放大弥漫全身，心底有声音低语：让他回头、离开、不要再走下去。
- 只需抬脚一步即可走完第二桥，但这最后一步始终难以抬起。时间流逝良久，王林神色平静轻叹一声，右脚抬起落下，**走完第二桥**。
- 王林悟语：「若道心不坚，若没有一股逆天之意，若没有需用生命守护的执着，或许在这一步中就应退缩了。」

## 三、通往第三桥：闭目乱步破局

- 第三桥「很遥远，又很近」：王林走三天未至，再三天如此，再三天依旧。
- **第九天**后停步，猛抬头目露奇异之芒，缓缓闭眼——不用肉眼看、不用神识感应，**闭目中封锁自身神识**，不看第三桥所在的位置与方向，凌空随意迈步。
- 走到**第九步**时，忽闻鸟鸣、柔光透过眼皮、鼻间雨后泥土芳香，以及熟悉的**木屑味道与烟草辛辣**。

## 四、第三桥：心魔与「睁眼」之选

### 幻境·爹娘
- 耳边响起爹娘声音：「铁柱，书读的怎么样了」「明年就是县里大考了……可别像我一样，这辈子就呆在村里」「我们家铁柱一定能考上」。
- 这声音**阔别数千年**，真实如回到数千年前的宁静山村。王林落泪。

### 桥的规则
- 第一桥：融天地规则于神识内。
- 第二桥：感受踏天之目，需**自问道心坚否**（王林此刻方明白第二桥末端为何会生迟疑）。
- 第三桥：或许就是**心魔**。若道心坚，一路走过、任凭一生如画面闪过而心绪不动，即可通过；一旦**睁眼**，则须直接面对心魔、面对自己的一生，通过把握无限减少。

### 王林的抉择
- 王林毫不迟疑地**睁开双眼**：看到熟悉屋舍院落、桌上饭菜；看到磕烟枪、满脸皱纹、严厉目光下藏着柔和亲情的**父亲**；看到端着热饭菜、黑发中藏着少许白发的**母亲**——外人看来或许不美，在王林心中却是最美、是永远的避风之地。
- 他尽情流泪，脸上却露出微笑；明知是假，也要去看一眼。这一幕随后消散化作虚无，王林仍站在第二桥下，距第三桥遥遥。
- 关于爹娘的定论：**他们不是修士，只是凡人，无法复活，轮回是凡人最好的归属**；但属于王林的记忆是永恒的，他不会抹去——「因为这比他的生命，还要重要」。
- 自省：「或许，如婉儿出现，我在知晓是假之后，我不知自己会不会继续睁开双眼。但爹娘的出现，我明知是假，也依旧会睁眼。」

### 反规则的道心
- 王林反问：「谁来制定……必须要闭着眼、不去理会，要保持坚定道心不被心魔影响？谁来规定必须坚定道心才可度过此第三桥，又是谁来肯定这是走过此桥的唯一方法？」
- 结论：「**亲情，爱情，友情，是我王林这一生最珍贵的存在，我何必要闭目不开，我要睁着眼，去看那一切，去打开道心，容纳一切！**」

### 一生的回廊（每九步一批）
1. 父母的身影；
2. 木冰眉、李倩梅、李慕婉；
3. 王平——那可怜的孩子拉着他的手认真说，他修道是为了陪伴父亲一辈子，不想这世界只留下父亲孤独的背影，若真要孤独下去，他希望父亲的背影旁还有他的存在；
4. 司徒南、清水、遁天、老朱雀等诸多有恩之人；
5. 大头、红蝶、青霜、周佚、青霖等等。
- 王林不控制情绪：哭了、笑了、痛了、悲了，不知走了多久，不知何时已走上第三桥。最终一切烟消云散，他立于第三桥末端，轻叹回头看了一眼身后，转身一步迈出，**走下第三桥**。

## 五、第四桥：一步落空，止步

- 走下第三桥后再望第九桥之后的虚幻，隐隐有了一丝清晰——王林仍无法看透，只能略看出**那虚幻内的身影是两个人**。
- 数日后抵达**踏天第四桥**：比之前更为庞大，如庞然大物存于这奇异空间，隐隐带出威压笼罩四周。
- 王林抬脚落下的一瞬，**右脚直接穿透此桥，一步落空**。
- 第四桥轰然一震，化作点点晶光消散，同时齐齐向王林卷来，在其体外回旋成漩涡，形成莫大吸扯之力，将王林**吞噬**，身影消失。

## 六、现实回归：罗喉郡计氏行宫密室

- 被吞噬一刹那，于**仙罡大陆古族大地、始吉一脉区域十二郡中的罗喉郡、计氏行宫密室**内，盘膝打坐的王林猛地睁眼，目露久久不散的迷茫。
- 身体状态：**杀戮真身已完全融合**，与身体不分彼此，再无丝毫重叠虚影。
- 身后：**虚本源**的光团漂浮；身前：**仙皇之魂**被其**灵魂之火**包裹焐化。密室一片安静，只有略微急促的呼吸声回旋。
- 收束之语：「**踏天路，空灭道，不朽魂，众生拜！**踏天九桥，我只走过了三桥，于第四桥，止步！」——目中迷茫渐渐消散，被坚定取代。

## 关键判读

- 王林通过第三桥的方式并非「守」而是「破」：不以闭目锁心过关，而是**睁眼容纳亲情/爱情/友情来打开道心**，是对既定规则的又一次「逆」。
- 第四桥不再是心性关隘而是**资格关隘**——右脚穿透、无法承载，直接被排除出局。
- 第九桥之后的「两个人」是本章埋下的新伏笔。
