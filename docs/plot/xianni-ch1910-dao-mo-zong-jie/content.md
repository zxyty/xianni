# 第1910章 道魔宗劫！

## 一、破阵：撕天
- 王林步伐不快，每步数百丈，直抵道魔宗护山迷雾大阵，不作停顿径直踏入。
- 入阵刹那迷雾内惊天轰鸣，声传道魔宗全宗；雾中幻化十八个巨大虚影，自十八个方向咆哮围攻王林。
- 王林右手前挥，平静吐出两字：「撕天」。
- 万里无云的天空骤然裂开巨缝，两只如数座山峰合抱般的巨手自缝中伸出，抓住本无实质的雾气使其如有形体，向外猛撕，将笼罩道魔宗的大阵在其上方生生撕成两半。
- 雾气向左右倒卷，残碎阳光直照失去雾气保护的道魔宗。

## 二、道魔宗方应对与损失
- 三万余修士（大半在打坐）被震出，齐望天空，目瞪口呆。
- 北部山峰红袍中年男子（空劫后期）驾红云现身，喝令「敌临！所有大能门人，布阵」。
- 宗内飞出数十道长虹，皆为在宗的第三步大能修士，融入迷雾主持阵法阻敌。
- 西方金光化作金袍老者（空劫后期大尊），神色阴沉，冲入迷雾要看是谁胆敢闯阵。
- 大阵被撕裂后：数十大能急速冲出，各自喷血，数人肉身当场爆开化作血肉；金袍老者狼狈逃出，目露恐惧。
- 此阵素来足以抵挡金尊强者全力一击，历史上虽被毁过几次，但从未以如此方式崩溃——意义之骇人令金袍老者心神颤抖，惊问「他是什么修为」。

## 三、身份揭破与旧怨
- 金袍老者厉声质问：阁下是谁、为何闯道魔宗毁其大阵；红袍中年男子强调「我道魔宗为东州九宗十三门之一，更有天尊老祖」。
- 王林答「忘了我么？可王某还记得你们」，掀开头顶白袍，露出阳光下的一头白发与冷漠面孔，目光最终落在远处湖泊中的岛屿。
- 王林点明：「一百多年而已，你们应该还记得孟土洲边界的杀戮，现在，认出王某了么。」
- 金袍老者一眼认出「王林」——一百多年前孟土洲边缘一战，道魔宗出动诸多修士被王林一人屠杀大半，最终由宗主出手方才擒下。
- 红袍中年男子亦为当年参战者，亲见王林之疯狂与杀戮。
- 众修士哗然：「他不是在一百多年前被宗主擒住，送入了蝎庙么？他竟然没死！」

## 四、复仇宣言与出手
- 王林重申当年之言：「若我有一天可以脱困……我将会让这道魔宗，从此在仙罡大陆，道统灭，满门斩，就此除名。」
- 右手掌心一阵刺痛，阴气自掌心散出，一把骨阴刀自血肉内延伸而出，先化一丈余，续延至近三丈，比王林身子还要巨大，散发惨白骨光与滔天阴气。
- 王林刻意不用大神通，而要以此刀杀戮满宗——目的是「重塑人头塔」。
- 王林自天幕直扑而下，速度超越闪电；金袍老者与红袍中年男子化两道长虹联手迎击。
- 以王林此时修为，不穿魂铠即可威胁空劫后期大尊；其骨阴刀横扫一斩，口中低吼「杀」。
- 身后五行真身幻化，抬起骨刀，首次发出与王林一样的低吼「杀」；五行真身之后雷霆真身幻化，缭绕闪电的骨刀抬起，第三声咆哮「杀」。
- 三声杀戮之音重叠成惊天音浪，取代天地之声，震动全宗心神。

## 五、要点归纳
- 本章为王林一百多年后归来清算道魔宗的开幕，因果链：孟土洲之战被擒 → 送入蝎庙 → 脱困归来 → 撕阵灭宗。
- 力量刻度：撕天可破抵挡金尊全力一击的护宗大阵；徒手（无穿魂铠）可威胁空劫后期大尊；五行真身、雷霆真身可同步作战。
