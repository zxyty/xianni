# 仙逆 第1774章「掌尊魂！」

## 一、开局态势
- 地点：古墓倒数第二层。掌尊施展**井中捞月**，大地轰鸣化作水面，王林四人身影倒映其中，似被井水淹没。
- 王林本不愿与掌尊一战：其真正敌人是**七彩**与**战老鬼**，再加掌尊则极为艰难；但掌尊此来就是为杀他，只能被迫接战。
- 王林手中的优势：
  1. 云逸封、唐姗、托森与他四人合击，掌尊已受伤；
  2. 此前的判断与试探、以及**获得金印之举**，摧毁了掌尊心神；
  3. 继掌尊、托森之后，他感应到第三人来临——**蓝梦道尊**。
- 掌尊已放弃逃遁，通红双眼露出杀机，自忖：「蓝梦到了又如何……战老鬼很快就会追来，他们不可能在战老鬼来临之前将老夫杀死。」

## 二、蓝梦三息封印
- 王林传出神念：「蓝梦前辈，能否封住掌尊三息？」蓝梦点头应下「三息时间，我可以做到」。
- 蓝梦大袖一甩，井水之地崩裂爆开，蓝光化蓝色之幕笼罩天地；其身与蓝光融合，另分三缕蓝芒把**云逸封、唐姗、托森**尽数卷入。
- 四人融入蓝光后化作**四道符文封印**，破开壁障轰然印在掌尊身上，将其全身如网禁锢。
- 蓝梦修为本就不弱，**即便没有玄劫，却可与玄劫一战**。
- 掌尊反应：被封的刹那全身覆上**金光护体**，远看如同金人，可保数息内不受重创。

## 三、三息之内的三步杀招
| 息 | 王林所为 |
| --- | --- |
| 第一息 | 一步迈至掌尊身前，右手食指幻化出**幻境鬼脸**，穿透蓝芒点在掌尊被金光覆盖的眉心 |
| 第二息 | 口诵「**梦道**」，梦道与鬼脸幻境融合轰入眉心，**不伤其身、只与其魂相融**，进入掌尊记忆并与其魂建立连接；未改其记忆，而是左手掐诀遥指远处黑气弥漫的山峰 |
| 第三息 | 喝出「**祭此魂，融已司之身**」——借刀杀人，所借之刀即「**已司**」；山峰雾气翻滚惊天之吼，掌尊之魂在体内凭空急速消散，如被无形吞噬 |

- 三息一过，四道封印消散，蓝梦、云逸封、唐姗、托森自蓝光中现身。
- 掌尊挣脱后抱头疯狂后退、凄厉惨叫，其魂正被冥冥中祭献，众人瞳孔收缩、触目惊心。
- 王林喷出鲜血、连退百丈，眼中冷酷寒芒。掌尊双目血丝、剧痛癫狂，「是你让本尊如此痛苦，杀了你，杀了你」，神智模糊只余杀王林一念，扑向王林。

## 四、已司之傀出世
- 王林疾退中掐诀低喝：「**已司之傀，我祭献了足够之魂，召你幻身而出。**」
- 远处山峰轰然崩溃，黑雾呼啸横卷，连冲来的掌尊一并笼罩，阻断众人目光。雾内传出两种咆哮：掌尊的痛苦嘶吼与另一道滔天凶煞之音。
- 片刻后掌尊身子被抛出，砰然落地，双目紧闭一动不动。
- 黑雾凝聚于王林**右侧**（非其体内），显出蹲地虚影，雾尽而形现——

### 已司之傀·形貌
- 皮肤一片**紫黑**的**侏儒**，赤身蹲地，头顶无一丝发，干瘦如柴；
- **舌头伸出口外足有七尺之长**，垂地随意摆动；
- 双眼一片漆黑，似可吸收四周光芒，身体看去隐隐扭曲；
- 凶煞之气惊天动地，如黄泉爬出的恶鬼，仅蹲伏即给人心神威压，四周唯闻其若有若无的呼吸声。

### 众人反应
- 唐姗面色苍白，连退数步；云逸封倒吸口气、眼露骇然；蓝梦道尊与托森稍好，亦心神一震。

## 五、王林与玄罗的两处判断
- **王林（操控问题）**：他在雾中目睹已司之傀与疯狂的掌尊一战。深知此傀与自己联系不深，「即便是操控也有些不足」；**想要完全操控，必须不断地杀戮祭魂于它**。
- **王林（修为不符之疑）**：按七彩仙尊记忆，第三魂一出应拥有**度过九次玄劫后、空劫初期巅峰**的修为；但眼下它虽极强，显然达不到真正的空劫，「怕是相当于几次玄劫的修为」。此疑他找不到答案。
- **玄罗（身份定性）**：远处大地上的玄罗认得此物——「之前我便感受到了它的气息，果然是**傀灵**，而且**已经转变了两次**！这七彩仙尊倒也心狠手辣。」摇头轻叹。

## 六、掌尊的处置
- 王林走向昏迷的掌尊，恶鬼侏儒无声跟随，移动时其身在**实质与雾气之间转换**。
- 王林看着掌尊内心感慨良久，大袖一甩将掌尊**收入储物空间**。
- 断语：「你魂还有一半，我不杀你，你是**疯子**当年之奴，就让他苏醒后来决定你的生死好了。」

## 七、悬念
1. 战老鬼随时可能追来，时间窗口有限。
2. 已司之傀修为未达七彩仙尊记载的空劫初期巅峰，原因未明。
3. 「傀灵已转变两次」的来历与代价。
4. 掌尊留半魂待「疯子」苏醒后发落，其命运与疯子的旧主从关系是后续伏笔。
