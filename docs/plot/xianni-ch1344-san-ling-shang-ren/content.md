# 第1344章 散灵上人（第九卷 云海之巅）

## 一、王林逼出尾随者真身

- 尾随王林的**光头青年**面带微笑而眼底凝重惊骇：他一路跟随，亲眼目睹王林屠杀仙人，以下方那名化神修士为饵，半个时辰内连杀上百；连强大无比的**碎涅**修士在王林面前亦不堪一击，令其心中反复自问「他到底什么修为」。
- 更令其震惊的是王林一语点破其隐藏之身，且话中之意表明早知其跟随。此人修为并非绝顶，但隐藏神通登峰造极、传承久远，无数年来如闪雷族一般游走七百万天地而从未被任何仙人发现；当年曾跟随一名**天人第四衰**之修数月，对方半点未察。
- 王林身前的红色闪电令其生出此生最大危机感，自知无法闪躲、一冲必死。其抱拳自报「下界之民散灵，无意冒犯」，话未说完，王林挥手，红色闪电化长虹穿透其眉心。
- 光头青年喷血却未死：一股浩荡之力自破开的眉心宣泄而出，化气浪环绕其身，全身修为散开，透出沧桑气息——体内似沉睡着一个震惊天地之魂，此魂之强，即便**极境**也无法一次杀死。王林道「果然如我所料」，上前抬手一抓。

## 二、散灵现身与交易提议

- 气浪环绕下的光头青年双眼清明、沧桑无尽，开口：「道友可想要**灵念之雷**？还请听我一言。」
- 自陈：「老夫名为**散灵**，至今已经存活了数万年之久，修为到了**天人第四衰**。」
- 关键交代：如眼前这具身体，散灵共有**九百七十一具**，每具体内蕴含其一道分神；故这些分身可如闪雷族修士一样踏入星空而不被任何人发觉。
- 散灵言明暗中跟随**并无恶意**，而是要向王林**求救**并做一笔交易，「此事对你我均都有利」。王林问「你知晓闪雷族？」，散灵神色复杂点头。
- 邀约目的地：**世界的尽头**。散灵挥手散去劫云，并打出一道印记落入下方渡劫男子眉心，隐藏其修为使其不再引发天劫；随后气浪收敛入体，抱拳转身一步踏破虚无离去，王林亦迈步同行。

## 三、散灵自述：万年追问与散灵之术

### 1. 疑惑的起点
- 百年化神，感悟天地，观数次天劫后渐觉「所谓仙人似乎并非祖辈所说一般」，遂**压制修为**不达化神巅峰，暗中寻找答案。
- 二百余岁再也压制不住，引动天劫。降临天劫者即**如今闪雷族的大长老**（当年修为只是**窥涅**）。散灵重伤频死，对方未杀他，只废其全部修为便离去。
- 散灵起初以为是「天道有好生之德」，多年后才明白：留他一命是给他继续修炼的机会，如此才有**诞生念雷**的可能。

### 2. 散灵之术的创立与叠加
- 那次天劫中他明悟天地变化，借**七百万天地**的存在压制修为，创出「修为越强却不引下天劫」的神通——**散灵之术**：把超过化神的修为融入他人体内，散灵于各个分身之中（此句由王林点破，散灵点头承认）。
- 一千年后修为达**问鼎**，分身达**九百七十一人**；九百七十一是散灵极限，无法超过。
- 遂以每一个分身为主体再次施展散灵之术：九百七十一个分身各自又拥有九百七十一个再分身，如此循环，修为增长至**净涅**。

### 3. 净涅之后的困局与真相
- 净涅之后开始追寻当年疑惑：「这天到底是不是天，这地又是不是地，这仙界是否真的是仙界，这仙人又到底是不是仙人。」
- 尽管修为到净涅、分身皆有不弱修为，仍**无法离开七百万天地进入星空**——有一层**无形隔膜**笼罩，当时修为破不开。
- 于是操控无数分身陆续越过化神巅峰界限、主动引动天劫，在旁观察（当时七百万天地中一小部分天劫皆由其分身引发），终于明白并被自己所明白的一切震撼：**他所存在的世界竟是别人制造而出，其众生的生命在制造者眼中只是蝼蚁，只为搜集念雷而存在**。

### 4. 迷茫、觉醒与破笼
- 曾把此事告诉一些人，无一人相信，连他自己都不愿相信，浑浑噩噩数千年。
- 转折：目睹两名仙人交战、一人死亡坠地，他站在尸体前直至其腐烂消散——那「仙人」哪里是仙人，分明是与他一样的**凡人修士**。他仰天大笑至流泪。
- 自此立誓破开天地、冲出去看天之外是什么。此后每一个分身之外的九百七十一个再分身同样施展散灵，愤意愈浓，修为达**碎涅**，一小部分分身也达**净涅、窥涅**，终于破开天空牢笼，**踏入星空**。
- 散灵言明这番话是第一次在别人面前说出。

## 四、要点与伏笔

- **世界观级揭示**：七百万天地是「别人制造」的养殖场，众生存在的意义是被搜集**念雷**——与闪雷族、王林此行目的直接相关。
- **闪雷族大长老**留散灵性命的动机被解释为「养念雷」，构成散灵数万年恩怨的源头。
- **灵念之雷**成为散灵与王林交易的筹码；「**世界的尽头**」为下一步行程目标。
- 王林战力刻画：半个时辰连杀上百仙人，碎涅修士不堪一击；且早已察觉散灵跟随并预判其真身不会被一击杀死。

## 五、境界序列（本章出现）

化神（百年化神→化神巅峰界限）→ 问鼎 → 净涅 → 碎涅；另有**窥涅**（闪雷族大长老当年修为）与**天人第四衰**（散灵现有修为）。注：本章散灵叙述中修为跃迁顺序为「问鼎→净涅→碎涅」，与叙述层次一并记录。
