# 第七卷 名震罗天 · 第845章 梦道

## 一、悬而未决的一指：吞，还是不吞

王林右手双指已碰在姚冰云眉心，却在刹那间一顿，盯着她苍白的脸沉默下来。他并非怜悯姚冰云，而是在此处撞上了自己的**证道之择**。

两难的两端：

- **吞**：吞噬意境即把对方之道尽数归为己用，以成全自身之道。但天道无尽、大道无涯，一旦开了吞噬先河，日后修道便会无止尽地吞噬——那正是**天运子走过的不归路**。
- **不吞**：因果意境便无法摸索，因果之道全部虚幻、无法真正存在；寻道而不知方向，无处去寻。

王林以天运子为镜作出推断：天运子自言有**三千六百化身**、每一化身皆属一道仙术，在王林看来，这三千六百化身实为其**吞噬的三千六百之道**；然而吞噬如此多道念，数万年过去，天运子**仍未踏入修道第三步**。这一判断，正是他迟迟按不下那一指的根由。

## 二、三日静止与元力异变

横云山洞府外白昼三易，王林身体一动未动，心却如怒浪起伏。三天于他如三百年，形容仿佛骤然苍老，口中无数次喃喃「道，什么是道」「到底什么才是道」，眼中迷茫更浓。

他自身未察的变化：

- 体内元力由缓慢运转渐次加速，第三日几成风暴，疯狂迅猛；
- 元力终至透出体外，在四周形成**黑白二色的元力漩涡**，二色仿若阴阳，融合而分明，越转越浓、越烈、越快；
- **元神**在不断寻觅、问证、追求中，从**太古雷龙**之相慢慢蜕变，重新化为与肉身一模一样的人体：同样盘膝、同样右手抬起、仿若指着某处，却始终没有放下——仿佛这一指，便是王林寻道的一生。

## 三、青灵星全星异象

清晨第一缕阳光落上青灵星，凡人照常醒来，修士照常吐纳，唯独今日天地灵气极为活跃，**比往日浓郁数倍不止**。

1. 修士渐渐发现，打坐时**面冲东北**则吐纳灵气大为浓郁，于是纷纷腾空直奔东北。
2. 青灵星东北方正是**横云山**。横云山万里之外已聚集不少修士，仿若朝拜般打坐吐纳，**一时三刻之修可抵寻常数日**。
3. 横云山顶天地之相幻化：山顶黑白二气弥漫交错，成**阴阳双鱼之相**，以蓝天为底，如人为勾勒之画；这份震撼自灵魂而来，传至元婴、融入元神、弥漫肉身，观者尽皆沉浸不能自拔。
4. 「什么是道」一句沧桑之音，蓦然自全星每一位修道者的灵魂中回荡——音中有历尽人生百态的沧桑、执着的追求与寻道之证的威严，闻者如遭雷击，怔在当场，心神不由自主随之自问。
5. 山顶洞府被风一吹化作灰迹、点点灰芒散为尘埃随风而去，整个山顶洞府尽数消失，只余王林与始终未苏醒的**姚冰云**；王林手指仍虚空按在她眉心。
6. 二人上空，黑白阴阳双鱼成圆如**太极**缓缓旋转，青灵星天地灵力随之而动，波及四周。自星空望去，整个青灵星笼罩在黑白二色之中。

## 四、「梦道」

- 此幕在**修道第二步**之人中被称为**梦道**；若有**血祖修为**者路过此地，定会为之心惊。
- 典故：传闻天地之初，有凡人名为**彭祖**，**一梦得道**，凝**远古仙品**，留万载道心，可鉴天地日月。
- 王林正在追寻、迷茫、印证之中沉浸于一股梦境：他仿若整个人脱离肉身缓缓升空，**但并非元神出窍——元神尚在肉身之内**。以此奇异状态，他感到身子缓缓消散，与青灵星融为一体，仿佛他就是此星。

## 五、余波一瞥：丛林大蟒

一处茂密丛林中，一条三丈大蟒卷杀路过小兽，骨碎声起、正要吞下时身子蓦然一颤，抬起大头望向远处天空，双眼冰冷尽褪、透出迷茫，叹出一声「这，不是道」；随后迷茫消散，重现无情冰冷，一口吞下小兽，游走消失于远处。此细节示意梦道之问已波及全星生灵，而非仅限修士。

## 六、悬念与作者附记

- 王林的那一指仍未落下，吞与不吞的抉择、姚冰云的生死，本章未有结论；作者于章末注明「这章没完，后续还有一些，明天更」。
