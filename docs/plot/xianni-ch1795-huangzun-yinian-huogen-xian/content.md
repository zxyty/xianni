# 第1795章 皇尊一念祸根现（第三更）

## 一、别玄罗，入虚无

- 王林激动地看着只剩十只的蚊兽与自己的蚊王，身外血龙环绕，踏上蚊王头顶。
- 向玄罗抱拳作别：**“师尊，我们仙罡见”**。蚊王仰天嘶吼，凶气惊天，带王林直奔虚无深处；身后九只万丈蚊兽如护卫般左右齐飞。
- 玄罗望着冰层缺口外远去的王林，闭目，右手一挥，冰层收缩封死缺口。

### 玄罗的推测
- 那如蚊子般的凶兽，可能是**传说中与古族、仙族同时诞生在法则中的九兽之一**。
- 若真如此，王林未来造化连玄罗也不敢预计——**很有可能凭自身成为仙罡大陆第十个太阳（第十个大天尊）**。
- “若他真的成为第十个大天尊，我道古一脉，万世永存。”
- 玄罗被蚊兽融合仙罡法则的一幕震撼，面色红润，随后顺龙身之路远去，体外隐隐幻化出**血色太阳**，光芒万丈笼罩四周，以一人之力对抗仙罡法则。

## 二、虚无之地的设定

- **位置与连通**：洞府界与仙罡大陆之间的一片无尽虚无；它并非只存在于一处，而是**仙罡大陆上所有洞府界外都与之连接**。
- **历史**：万古岁月以来，无数洞府界天骄以各种方式知晓一切、走出洞府大门踏入这里，**没有一个成功进入仙罡大陆，全部死在虚无内**。仙罡大陆强者也曾试图入内感悟法则、或借此进入其他宗门洞府界，成功者极少，且此地易迷失，故后来少有人再入。
- **环境**：一片死寂——没有声音、光芒、灵气、生命痕迹；常有不腐的残骸（修士的、凶兽的）漂浮而过。王林形容：“虚无如海，这里或许可以看成是一片蕴含了仙罡规则的海洋。”
- **心神之危**：极端的静会让人发狂，时间越长心神越躁动，心智坚定者亦难平静。
- **迷路之危**：一旦迷失便永远找不到出路；即使看到门户，也多是其他宗派之门，洞府界之修同样走不出。
- **法则压力的两个维度**：①越向深处越强；②**停留时间越长压力越大**（故不能以压力强弱辨向）。
- **本源损耗**：在此地本源之力萎靡且无法恢复，用多少少多少；再强的力量若迷失或滞留，终有烟消云散之日。
- **禁止吐纳**：有一股奇异力量阻止一切生灵沉浸吐纳打坐，只能数着时间流逝。

## 三、五年跋涉的时间线

| 时点 | 状态 |
| --- | --- |
| 起初一月 | 王林平静前行，能感受到残骸中的不甘 |
| 一年 | 未开口说过一句话，双眼似融于黑暗，睁闭皆是无尽的黑；四周无声，连速度呼啸都不存在 |
| 一年半 | 血龙更暗，九蚊兽速度减慢；王林沙哑喃喃“**还有八年半**” |
| 第二年 | 血龙几乎看不见，只余冥冥指引，抗法则作用尽失；王林首次清晰承受压力，如大山撞身 |
| 第二至第四年 | 四年无声流逝，王林感觉如同四百年；无法打坐，四年未遇一个活着的生灵 |
| 第五年 | 挤压之力使身体如沉淤泥，抬手即全身剧痛如被细丝缠绕；九只蚊兽被收入储物空间免受痛苦，蚊王独载王林且速度依旧极快 |

### 关键抉择：取出避天棺
- 王林认为储物空间内已不安全，**把避天棺取出背在身后**，以自身身躯保护才安心。
- 他明白：只要自己不死，这股力量就伤不到身后的李慕婉；其全部力量环绕体外，重点护住身后的李慕婉。

### 心境
- 王林已习惯孤独，且有蚊兽陪伴，自言不寂寞。
- 他能从血龙感受到玄罗正在虚无某处道路上**护送他的朋友转世投胎**、同时抵抗仙罡法则，使自己受法则不深——这让王林心中温暖。
- 时而回望走过的漆黑虚无，隐隐似看到家乡的大门在目送自己远离；依稀见到**木冰眉雨中撑伞的娇柔身影**，伞下容颜透出复杂之色。**对木冰眉，王林已经没有了恨。**

## 四、仙罡大陆·道古皇宫：祸根初现

- 场景：道古一脉所在大片区域**正中心**，一座漂浮于天地间的**巨大城池**，其中的**道古皇宫**最高阁楼。
- 人物：**道古皇尊**，穿皇袍的中年男子，望着阴沉似要落雨的天空。
- 手中持一枚**幽光闪烁的光珠**，其内一片模糊，可见一个女子的魂影在内沉睡（即李慕婉之魂）。

### 皇尊之念
- 不满玄罗：“大天尊已经离去了很久。哼，为了一个区区洞府蝼修，他居然如此尽力，实在是老糊涂了。”
- 自居守护者：“道古一脉的守护者，除了玄罗外，现在是本皇，以后，也是本皇。”并扬言要看看被老家伙带回来的人是什么样子，“他无论是什么身份，见到身为皇尊的朕，也要立刻给本皇跪下拜见。”
- 狠狠握住光珠，因用力过猛，珠内之魂立刻颤抖，似极为害怕。
- 疑问：“小小幽魂，为何国师会说，她会成为我叱咤仙罡大陆的重要之物。”
- **决定**：“也罢，你既然如此重要，那便真的立你为后好了。烨道，把所有寻找而来的女子，全部进行尝试，看看哪一个，可以（承载）她之魂。”
- 领旨者：身后一阵扭曲间出现的**被黑雾笼罩的男子烨道**，跪地低声应命：“遵旨。”

## 五、伏笔与看点

1. **蚊王疑为“九兽之一”**——与古族、仙族同时诞生于法则，关乎王林能否成为“第十个太阳/第十个大天尊”。
2. **十年之约**——王林自计此程约十年，眼下方过一年半至五年，压力仍在递增。
3. **李慕婉之魂已在皇尊之手**——玄罗护送转世投胎之举与皇尊“立后试魂”之命形成直接冲突，即标题所谓“皇尊一念祸根现”。
4. **国师之言**——李慕婉之魂被断言将成为皇尊叱咤仙罡大陆的重要之物，来历与用途未明。
5. **木冰眉线**——王林已释恨，情结暂了。
