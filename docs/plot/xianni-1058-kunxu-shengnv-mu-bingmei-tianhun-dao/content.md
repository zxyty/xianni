# 第八卷 联盟隐秘 第1058章（仙逆 00977-00981 之2）

## 一、岩浆中的对峙
- 王林神色冰冷，瞬息跨越数十丈，来到粉衣女子所在气泡外，冷视她与昏迷的村姑美妇。
- 粉衣女子眉心雪花痕迹不断闪烁——那是**大师姐所赐的防身之宝**，也是她在这诡异岩浆中唯一的依仗。
- 王林神念直问：「你是昆虚圣女？」神念一出即与岩浆相融、化作波纹回荡，气泡剧烈波动，仿佛随时崩溃。
- 粉衣女子面色苍白否认：「我不是昆虚圣女，我大师姐才是。」并答村姑美妇是「我昆虚之境的长辈」。
- 她刚提到「虚空子与你有过节，但我们却没有得罪你」，王林已一步穿透气泡站在她面前。

## 二、搜魂村姑美妇
- 王林蹲身，右手食指点向昏迷美妇眉心；粉衣女子欲阻，被王林反手一指**定身术**定住（口称「聒噪」），但其雪花仍化作无数环身死守。
- 村姑美妇修为高于王林，然此刻**身中火毒、元神虚弱、神智昏迷**，遂被王林神识横扫记忆。
- 王林的目的极明确：**昆虚之境的一切记忆势在必得**。动机来自此前修为提至**窥涅后期大圆满**、心神弥漫整个星空时，在昆虚之境内看到那个令他心为之剧痛的身影。
- 搜魂使美妇火毒无法压制、濒临爆发：全身妖异潮红、汗水泌出化作白气；再持续将成干尸、元神崩灭。旁侧被定住的粉衣女子目露焦急与恨意，却无力反抗。

### 记忆所得（关于昆虚圣女）
- 记忆中那个高傲身影，正是王林心神所见之人——**昆虚圣女木冰眉**。
- 美妇对圣女只有崇敬、了解不多：历代圣女几乎全修同一门**极为诡异的功法**，一旦圆满便可成昆虚之境最强者；然此功极难，除第一代圣女外几乎无人成功，唯第七代圣女木冰眉**略有小成**。

### 「柳眉—木冰眉」的心痛与王平
- 王林心神传出阵阵剧痛；**天逆珠内的王平**因其心神波动而有一丝苏醒迹象。
- 王平一生只提过一次、终生未再提起的愿望：**很想很想看自己的母亲一眼**。

## 三、交易：救人换搜魂
- 由美妇记忆得知：粉衣女子是**柳眉的师妹**，修同样功法；她与村姑美妇非寻常长辈关系——美妇是看着她长大的，之后她才成为柳眉师妹。
- 王林开出条件：「我若不救她，她一炷香内必死无疑」——我救她、并带你二人进入大殿、进入**第八层**，你要让我搜寻记忆。（若不同意，王林也会出手。）
- 粉衣女子冰雪聪明，看出王林所寻必与自己大师姐有关，惨笑点头，放弃反抗。

## 四、大殿驱浆与解毒
- 王林大袖卷起二女，一步穿透气泡直奔大殿，踏入殿内后掐诀一指，殿中岩浆尽数外涌，**殿门砰然关闭**（余温仍炽）。
- 王林虚空一抓提起美妇，在其身上连拍数下（毫不在意其为女子），每拍一次皮肤更红一分；半柱香后其身几近火红，遂按其天灵狠狠一吸，**火毒尽数顺天灵钻入王林手中**。美妇恢复正常，但极为虚弱倒在一旁。

## 五、搜魂粉衣女子：天魂道的真相
- 粉衣女子咬唇盘膝，右手点眉心散去全部雪花，闭目一动不动；王林点其眉心搜魂——**只要不反抗便不强行破开心神**，故伤害有限。
- **天魂道**（昆虚之境巅峰神通之术）：
  - 要义：「假象天道有魂」，修此魂道**分身无数**，历经众多经历、修行不同功法、获得无数意境而**始终保留本心**，最终**分身合一**，成就天魂道。
  - 古往今来只有**第一代圣女**成功；此后历代圣女**全部失败，迷失本心而亡**。
- **木冰眉的捷径（无情之道）**：
  - 分身出现后**不保留本心**，任其自行存活、另繁衍出新的意识，**丝毫不知本体存在**；唯有达到要求后，方可开启记忆传承、与本体融合。
  - 缘由：**天道无情，故而分身也需无情**。
  - 分身数量并非无数，而是**只有九个**；九个分身所落的修真星皆经**极深的计算**方才确定。
- **结果**：历经无数载，**前八个分身全部圆满，保留处子之身苏醒**；唯第九分身**在朱雀星出现意外**——此第九分身，名为**柳眉**。粉衣女子不知意外为何，只知大师姐因这第九分身而**陷入一场挣扎**。

## 六、要点归纳
- 柳眉 = 昆虚圣女木冰眉的第九分身（无本心、独立意识、不知本体存在），意外发生地为朱雀星。
- 王林寻昆虚之境的真正动因，是窥涅后期大圆满时心神所见的木冰眉身影（与柳眉同貌）。
- 王平（天逆珠内）与「看母亲一眼」的心愿，构成本章最重的因果情绪线。
- 本章尚未揭示「朱雀星意外」的具体内容与木冰眉挣扎的走向。
