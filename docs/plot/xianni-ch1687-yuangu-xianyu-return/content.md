# 第1687章 远古开启

## 一、时点：三年之期 = 开战百年
- 王林双目寒光：“时间到了”——他等这一天等了三年。
- 三年之期来临的这一天，也正是**界内界外开战整整一百年**之日。
- **界内远古仙域四大战将**没有让王林失望：他们与王林的**约定交易**在这一天展开。
- 凝聚在王林身边的诸多神识，丝毫没有察觉这一息过后整个界内界外的剧变。

## 二、剧变时序（以“息”为刻度）
| 时刻 | 现象 |
|---|---|
| 第1息 | 昆虚星域星空最先出现迹象，传出闷闷轰鸣，如巨人在门后疯狂轰击欲破门而出；召河、云海、罗天随之同响 |
| 第5息 | 轰鸣达到巅峰，传遍界内每一寸星空、每颗修真星、每个生灵耳中；凡人、凶兽、植被齐齐一颤，一片茫然 |
| 第8息 | 声响近乎疯狂，震得星空颤抖，化作无数波纹弥漫四大星域，似无数远古生灵在咆哮 |
| 第11息 | 轰鸣产生**远古威压**，带沧桑气息笼罩界内，似宣告“他们回来了” |
| 第16息 | 四大星域彻底失去光芒，所有修真星与大陆陷入黑暗 |
| 第17息 | 昆虚星幕无尽碎裂，撕开巨大裂缝；召河、罗天、云海同时裂开 |
| 第19息 | 四道裂缝横扫星空，于四大星域交界处、新仙界正上方重叠成巨大“十”字，界内之光尽被吸走 |

### 众生相
- **蛮荒星（无人）**：扑食的猛虎、卷住小兽的巨蟒齐齐一颤，骇然抬头望天；被捕的小兽也忘了挣扎。
- **召河星域某修真星**：不足几十人的留守修士（未去仙界，负责寻找可修仙凡人作为界内种子）面色苍白齐齐喷血，疑“莫非界外再次入侵”，欲飞起却被威压生生按在大地上。
- **罗天星域某凡人星**：城池死寂，卖酒老人与十几名喝酒凡人眼见明媚天空骤然阴暗，随即眼前一黑昏倒；天空彻底成为黑夜。

## 三、裂缝与远古仙域降临
- 裂缝内传出兴奋与疯狂的低吼，宣泄出远古仙域气息，伸出一双双**干枯的手**，似有诸多之人爆发全力欲撕开星幕。
- **战老鬼**自罗天星域雷仙界打坐中猛地起身，一步迈出雷仙界现身罗天星域，双目寒光，吐出四字：“远古仙域”。
- “十”字裂缝彻底撕开：被吸取的光凝成一个个巨大长条形光块，数百个光块上下环绕，铺成层层漂浮的**巨大阶梯**。
- 数十道**全身散发金光的身影**带着激动走出，其后仍有金影陆续飞出。每一个都具备**修士第三步**的气息，且这股气息**隐隐与洞府之修不同**，具体差异难以形容。
- 呼喝：“终于出来了”“如今修为恢复，我等仙人再次回归”。
- 远古仙域，在消失了亘古之后，再次降临于世。

## 四、新仙界一方的反应
- 银河与仙界发出嗡嗡巨响，界内诸多修士神色大变齐齐抬头。
- **青霖**面色苍白一晃而起直奔星空，召**红杉子、南云子、清水**同去拜见远古仙人；四人化作长虹冲出仙界银河。
- 仙界最高峰上耸立一尊**巨大雕像**——三天内自**朱雀星**挪移而来，摆放于此受万代膜拜。
- 站在星空中仰望十字裂缝时，即便是**清水**也露出恭敬之色；对青霖等老家伙而言，远古仙人**就是神灵**，不敢有丝毫不敬。
- 青霖上前抱拳：“**封尊弟子，青霖，拜见远古仙人**。”
- **无人理会**：仙人们狂笑化作金光从四人身边穿过，直奔新仙界。

## 五、关键伏笔：香火
- 仙人们的目的直白：“本仙已经很久没有吞噬香火了，这里的香火气息尽管不浓，但却可以略解万古之瘾”“香火，这里有香火气息”“没想到刚一苏醒，就有香火放在面前，那个封尊弟子，你很好”。
- 青霖四人闻言**心神一震**——恭迎神灵，换来的是自家香火被吞噬的开端。

## 六、异数：司徒南（断臂所化人影）
- 唯有司徒南在下方大地诸修士中死死盯着天空。
- 其脑海回荡**王林的话语**，此话他未曾对任何人说。
- 面对远古裂缝，他心中**没有丝毫敬畏**，只有一片复杂的茫然。——暗示王林早已向其交底远古仙域的真相/布局。

## 七、要点小结
1. 王林三年前埋下的局在开战百年之日引爆，执行方为界内远古仙域四大战将。
2. 远古仙域以撕裂四大星域星幕的方式归来，出口交汇点正对新仙界。
3. 归来者为第三步修士，气息异于洞府之修，以“吞噬香火”为需求。
4. 青霖代表的封尊一系将远古仙人奉若神灵，却在第一时间被无视并被觊觎香火。
5. 司徒南掌握王林未公开的内幕，是全场唯一不敬畏者。
