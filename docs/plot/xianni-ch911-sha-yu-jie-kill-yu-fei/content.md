# 第八卷 联盟隐秘 第911章 杀域界

## 一、战况延续：于非胆裂逃遁

- **于非的震骇**：他看出眼前的「许木」（实为王林化名）修为明明只是**窥涅初期**，肉身强度却不可思议，连自己以分身炼化的法宝都能硬抗。更令其几乎魂飞魄散的是，王林**一吼震死其四个分身**。
- **血遁逃命**：于非丧失战意，喷血后整个人融入血中疾遁。血遁本是自损修为的保命绝招，惊慌之下他不再考虑得失。
- **拖延手段**：逃遁刹那，其脚下所踩巨石轰然碎裂，无尽煞气弥漫形成大范围崩溃扩散，试图阻挡追击。
- **王林破解**：掐诀一指天地，狂风呼啸吹散崩溃；一步之下追出，于数万里外的虚空中提前现身，迎面一拳，震得于非喷血、血光瓦解、被生生逼出。

## 二、于非的三重反击

1. **本命法宝**：从天灵飞出一道浓郁血光，冲天成煞气，化作**十丈红色剑光**扑向王林。
2. **妖蟒**：以窥涅中期修为掐诀，身前凭空生大片血雾，翻滚凝化出**百丈妖蟒**，张开血盆大口吞噬。
3. **法宝群攻**：一拍储物袋放出大量法宝，喷精血落于每件法宝之上，低吼「杀」，法宝齐冲；随即毫不犹豫后退。

## 三、王林合体之威

- **合体化巨人**：王林身影散出浓郁灵气，肉身疯狂增长，瞬间化作**数十丈高的巨人**，庞大肉身透出沧桑与极强气息。
- **硬抗本命法宝**：不闪不躲，红色大剑落身即崩溃瓦解。作者点明：若未合体，王林**尚不敢正面硬接窥涅中期的本命法宝**；合体后体内浓郁元力游走，可将传入体内的法宝之气尽数消散。
- **碎蟒入黄泉**：一步上前徒手抓住巨蟒头部，一捏碎之；察觉此蟒**有魂**，遂放出**黄泉**（横扫之下四周怨气冲天），顺手将巨蟒扔入。
- **崩碎法宝群**：双手前挥，迎面法宝砰砰尽碎。本命法宝被毁，逃遁中的于非当场喷血、面色更白。

## 四、撕臂开门与「移形」追杀

- **于非的绝招**：忍痛**撕下自己左臂**，口诵复杂咒语，断臂崩溃形成**椭圆形漩涡之门**，一步踏入。
- **临走威胁**：「许木，杀域界中**魂杀二侍**，除了我外，还有一人，你肉身虽强，但在**魂侍神通**之下，也定然会灭亡」——眼中透出滔天恨意。
- **王林的行事准则**：人不犯我，我不犯人；人若犯我，我必杀人。既已动手便杀彻底，放对方走也阻止不了杀戮延续。
- **古神之鼎·移形**：王林身外传出鼎鸣，一尊**古神之鼎**幻化数十丈现身。设定要点：**王林分身单独使用古神之鼎需以当年贪狼的印决**，而此刻分身与本尊合体后施展，**威力更深**。一声「移形」，急速收缩的漩涡如被无形大手抓住，被生生转移到王林身前，王林之身亦被奇异之力推向前。
- **致命一指**：交错刹那，右手双指成剑，蕴含**斩罗诀 + 天地雷威 + 阴阳双鱼道念**，并凝聚**古神强悍肉身之力与破碎一切的神通**，穿透收缩中的漩涡，深入其内狠狠一点。

## 五、杀域界内：当众轰杀

- **地理定位**：联盟星域内，修真联盟**两殿四尊八方界**中的**杀域界**；界内建筑一处处仿若大剑刺在虚空。
- **于非现身**：面色苍白、左臂淌血，踏出漩涡，望见熟悉的高塔松了口气，正要说话。
- **高塔示警已晚**：高塔内爆出极强气息与怒吼「于非，离开那里」，一道红芒疾驰而至，仍晚一步。
- **形神俱灭**：漩涡内伸出**两根手指**，带滔天杀机按在于非后心。于非喷血抛飞，体内砰砰巨响，汗毛孔喷出大片血雾，整个身子轰然崩溃，**元神亦无法逃遁，形神俱灭**。临死惊呼「是许木」。
- **夺物**：连储物袋都瓦解，内中物品散出，**其中一根树枝立刻回缩，被漩涡内探出的双指捏住**。红芒飞扑，手指已收、漩涡消散；红光中探出干枯右手对着消散处一抓，咔的一声只抓出**半截树枝**。

## 六、杀域界的反应：追杀令

- **红发老者**：红芒化作一名年纪苍老、一头红发盖面之人，当场怒吼。
- **奇耻大辱**：杀域界无数万年来从未有自己人在他们眼睁睁之下被人直接轰杀，此事不亚于被杀上自家地域。
- **压抑的杀机**：各建筑上传出怒吼，众修士全身涌现浓郁杀机现身，直勾勾盯着于非身亡之处，许久渐渐沉默——沉默中酝酿着待爆发的杀机。
- **命令**：红发老者深吸口气，眼露阴森，甩袖回塔，许久后塔内传出冰冷声音：「**追杀，许木**」。

## 七、战后：王林的收获与去向

- 王林收回双指，身子缓缓缩小复为常人。
- 手中**半截树枝**是杀于非时**冒险取来**，「却是有大用」，收入储物袋，并自语：「**有此物，可保我在联盟西部平安**」。
- 身形一晃，出现在**雷吉**背上；**大头童子**（此处即雷吉一方）先前忐忑，见王林归来松气并露恭敬。
- **塔山**与于非分身一战略有受伤，正盘膝运功疗伤。
- 王林下令：「雷吉，寻找一个较为隐秘的**蛮荒星**，我要**闭关**」——雷吉速度一冲，远远消失。

## 八、伏笔与待解

- **魂杀二侍**尚存一人，于非死前断言魂侍神通可灭王林肉身。
- 杀域界（连同其高塔中的红发老者）已对「许木」发出追杀令，因果结下。
- 半截树枝的具体来历与「保平安于联盟西部」的机制未明。
- 树枝另半截落在杀域界红发老者手中，双方各执一半。
