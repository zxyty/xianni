# 第1521章 此衫，非杉！

## 一、王林重伤退走与吞噬突围

- 王林方才与空灵大能一触，看似寻常实则极为凶险，他第一次清晰感受到**空灵**大能的恐怖：空灵之数远少于**空涅**，地位亦尊贵得多。
- 后退中王林再次喷出数口鲜血，神色一狞，以后背撞在一名界外老者身上——老者未及惨叫便崩溃，血肉粉碎化作一缕生机被王林尽数吸入，连元神也无法遁走，被瞬息吸走。
- 王林退势不停，直接落入界外修士人群，所退之处成一道直线，凡被其碰到的修士**尽数死亡**（借撞击吞噬生机与元神脱身）。

## 二、红杉子出手：此衫，非杉

- 南诏上人杀机一闪欲追杀王林，红杉子一步迈来，南诏上人眼前一花被红色取代，面色大变急退。
- 红杉子放言：**「老夫数万年没开杀戒，你等或许已经忘了老夫红杉子当年的真正道号出处」**。
- 右手一挥，星空中凭空浮现无尽红光——非来自远方星空，而是自一个个界外修士体内透出，如皮肤下血液被倒映；约**数千修士**（含南诏上人）身上浮出「红衫」。
- 「此衫，非杉」：数千修士体内血液倒卷，自每一个汗毛孔被生生逼出体外，凝为真正的红色长衫；血衫出现即收缩，众修士惨叫中尽成干尸，齐齐死亡。
- 更狠处在后：这些修士元神被强行禁锢体内，肉身死后死气逼入元神，化为**活死人**。红杉子大袖一甩，数千血衫干尸双目爆出血光，如被操控般冲入界外大军中嗜血杀戮，口中痛苦低吼「把鲜血还给我」「我要鲜血……我的身体很痛，身体很干」。

## 三、血衫童子之名与五大能围攻

- 南诏上人身外亦有血衫，被迫喷出灵神之气、**自毁肉身**，元神凶险飞出，惊恐中想起界外流传数万年、有关**第二次封界大战**的可怕传闻——传闻中只说一个人：
  - **「血衫童子！你是血衫童子！」**
- 红杉子寒光毕露，迈步直取南诏上人欲杀之。此时：
  - 界外第二波大军中**两名第三步大能**咬牙冲来；
  - **东迪子**亦认出这传说中人，神色剧变，弃周瑾、灵动与开天斧不顾，一同扑向红杉子；
  - **南诏上人**退后中取出一具肉身融入灵神，挥手放出三个拳头大小的**毒液球**冲向红杉子；
  - **火雀族老祖**咬牙放弃王林，同样冲出。
- 合计**五名大能，共战红杉子**。

## 四、南云子抢修封界大阵

- 南云子不理会红杉子之战与界外大军，径直奔向**封界大阵**，任务是将其修复、重新闭合。
- 其焦急自语：**「界内还没有准备好，还需一些时间，这封界大阵，开不得」**。
- 南云子沙哑传音全星空：「王林，这二人借老夫一用」——王林在疗伤退后中传出神念，**灵动与周瑾**当即奔至南云子身前抱拳，受命**护法**；南云子迈入封界大阵，双手掐诀，大量禁制直奔封阵。

## 五、云落大司调兵：阻斧、杀王林

- 界外十余万修士中，被密密麻麻护卫的**云落大司**瞳孔收缩：她也未料到刚入界内就因封阵意外损失惨重，**短时间内界外已牺牲近两万修士**。
- **开天斧**无人阻挡，轰鸣斩下，一斧便令**五千修士**拦腰断开凄厉而亡。
- 云落大司下令：**「天罚殿，侍剑一族，破魂一剑，阻止此斧」**——封界外天罚殿四周数千黑衣修士化作游丝扑向开天斧，动作整齐划一，右手幻化黑剑向前一扫，数千剑气凝如开天之虹撞上斧头；斧势一顿，剑气崩溃，众修士齐喷鲜血却不停顿，左手一挥将自身鲜血化血光染剑，再斩剑气。
- 云落大司遥指王林下令：**「封灭族三老，此子，就拜托三位了，不惜一切，必须将其封印或者杀死」**——身后三道幽光扭曲，化作三个**紫袍人影**（如掌尊般全身笼罩紫袍、看不见容颜），无言化幽光直奔远处王林。

## 六、云海血战：云海荣耀

- 远处**云海修士数万**轰然杀至，与界外无尽入侵者接战，一触即极为惨重，血腥弥漫整个星空。
- 战场速写：
  - 一云海修士轰杀界外之民后被飞剑洞穿，临死挣扎望向家乡方向、惨笑自爆，「即便是死，也要死的轰轰烈烈」。
  - 一云海中年男子身中四剑、伤口遍布，长笑冲向界外修士，肉身爆开与其同归于尽。
  - 一名修为达**天人第三衰**的界外大神通修士乱战中穿梭屠戮，掏出并捏碎一名云海修士心脏；那修士生命最后一刻双臂死死抱住他，被震碎后头颅飞出、双眼仍带仇恨紧盯。因这短暂耽搁，大批云海修士红着眼冲上，不与之战斗，只在「云海荣耀」的大吼中轰然自爆——十个杀不了便一百个，一百个杀不了便三百个，终以毁灭之力将其摧毁，其至死耳边回荡的都是那四个字「云海荣耀」。
  - 那飞出的头颅慢慢闭上双眼，被界外修士神通余波震碎。

## 七、作者附言（章末感言）

- 耳根自陈从未写过大战，当年罗天与联盟一战因没有把握、犹豫许久而避开重点侧面带过，留下遗憾；此番要挑战自己，写一场真正的大战，请书友给予信心与香火。

## 关键看点

1. 红杉子真实身份揭破：**血衫童子**，与**第二次封界大战**传说直接挂钩，道号「红杉」实指「血衫」。
2. 界外阵营首次出现建制化战力调度：天罚殿侍剑一族（破魂一剑）、封灭族三老。
3. 王林成为云落大司点名必封必杀的目标，同时借撞击吞噬生机元神自保。
4. 封界大阵的开合是本役核心战略目标：界外要开，南云子要闭。
