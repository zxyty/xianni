# 第1698章 虚假么！（第三更）

## 一、局势：反客为主

- 前情：王林若破开魂魔舟第三层禁制，此舟将完全落入其手——即「反客为主」。
- 矾珊梦眼中寒光，抬手一指船外防护光幕，层层光幕黯淡；同时身形一晃自第一层甲板下沉入第二层。
- 七彩光芒轰然笼罩整个魂魔舟，**七彩道人**一步踏上甲板。
- 身在第三层的王林抬头，神色平静：「她果然这样做了。」——矾珊梦的算计被打破后，隐藏威胁失效，必转而借七彩之力威压。

## 二、王林的反制：玩火么，我也会

- 矾珊梦的算盘：第一层已被王林操控，王林须分心操控第一层禁制阻挡七彩，间接与七彩道人对抗。
- 王林反其道而行：掐诀一挥，**令第一层甲板所有禁制完全停止运转**，七彩之光毫不费力穿透第一层进入第二层。
- 矾珊梦踏入第三层后面色大变，斥其找死：「七彩第一魂如今就算你我联手也不是其对手」。
- 王林回应要点：
  1. 「你若再聒噪，我便打开第二层，让他完全下来。」
  2. 「你既然能打开船外光幕，让他省力不少，我为何不能放开第一层。」
  3. 「我与他之间没有深仇大恨，他要**李广弓**，我给他就是，可你则不一样。」
  4. 「不但要闭嘴，更不要再弄一些其他的小动作。」
- 矾珊梦被生生压制，心生寒意与极深忌惮：「他一步一步把主动一点点抢走……此人心机太深」「如此年纪就有这般心机，此人若是在**仙罡大陆**，定然是声名赫赫之辈」。她原本并未把这个「洞府界之修」看在眼里。

## 三、交易：三个时辰

- 第二层甲板轰鸣颤抖，禁制之光与七彩之芒对抗，眼看撑不了多久。
- 王林开出条件：「若不想死，你便要施展全力，为我争取到更多的时间，去破开这第三层。我知你还有最后的手段，可以保自己平安。但此刻在这魂魔舟的操控上，你我相当，若王某不配合，你也休想离去。」
  - 说毕即闭目，**道古虚影**在外，重新沉浸于第三层禁制的研究。
- 矾珊梦被说中要害——她确有最后手段，也正因如此先前才从容借七彩压迫王林；但如今施展该手段亦需王林配合。
- 她劝王林放弃操控以求脱身，话音刚落第二层禁制大范围崩溃、毁去三成。王林睁眼只道：「**我需要三个时辰**。」矾珊梦怒笑转身，掐诀引第二层七彩之光拖延。

## 四、王林的收获：四大禁制圆满

- 王林自陈：本不会如此对待矾氏姐妹，但**她们算计在先**，其一生修道原则是「人不犯我我不犯人」。
- 魂魔舟禁制对他大有用处：连破两层后，**四大禁制已达圆满，只差一点便可融合、诞生本源**。
- 第三层禁制中大半为他从未见过，研究之下禁制造诣突飞猛进。

## 五、崩溃与下沉：第四层

- 第二个时辰过后，第二层甲板裂缝蔓延、彻底崩溃；矾珊梦喷血后退，七彩之光急速扩散。
- 王林掐诀上掀，第三层甲板禁制化作大网直奔上方，随即身形下沉进入**第四层甲板**——其内**雾气弥漫，阻碍神识与视线**，矾珊梦同步跟入。
- 矾珊梦估算：她全力阻拦亦仅换来两个时辰；第三层即便解开，七彩轰开也只需一个时辰。她焦急提议**尽快交换誓血**，由她完全掌控此舟以求一拼。

## 六、揭穿：你不是矾珊梦；这里是幻界

- 王林大笑后平静指出两点：
  1. **「你，不是矾珊梦。你是矾珊璐。」** 自他踏入魂魔舟起就已被算计；对方担心他不肯交出誓血，遂**借喷出一口鲜血之际，以未知手段变换气息与神色**，令他误以为是矾珊梦；随后又说出**洞府界的隐秘**加深其误信。此后破禁过程中，她的反应「或许有真，但同样有假」。
  2. **「这里的一切，都是假的」**——第二层、第三层、第四层全是假的，眼前的「她」是假的，**七彩或许是真，但这船上的七彩道人是假的**，此处分明是一个**幻界**。王林评价：此生也曾遇到过类似法术神通，但从未有任何一个如此真实，「真实的让人可怕」。
- 该女子先皱眉称听不懂，继而苦笑后退，露出难以置信之色，斥王林疯了。
- 王林不再多言，眼中寒光一闪，**右手一掌轰向濒临崩溃的第三层**：第三层骤然崩溃，七彩之光穿透而下笼罩第四层，**七彩道人的身影一步迈来**。

## 七、悬念与待解

- 幻界的施术者与目的未明（是否出自七彩道人、矾氏姐妹或魂魔舟本身）。
- 矾珊璐所谓「最后的手段」具体为何，尚未施展。
- 誓血交换始终未成，双方互不信任。
- 王林四大禁制融合、诞生本源仅差一线，或将于破禁过程中完成。

> 归属说明：据世界状态须知，王林在不同时期以「许木」「吕子浩」「烨寞（道古）」等名/身行事；本章正文直呼其本名「王林」，其言行均归于王林本人。
