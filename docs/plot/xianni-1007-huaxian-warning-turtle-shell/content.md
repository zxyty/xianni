# 第八卷 联盟隐秘 · 第1007章 警告

## 一、开场：久违的危机感

- 王林今日修为远非当年，尤其**古神肉身达到王族五星**后，能让他生出危机感者极少；他自估**除非对方修为在净涅后期以上**，否则难以带来强烈压迫。
- 但大殿暗处传出的脚步声与随之显露的白色身影，令他危机感瞬息攀至巅峰：汗毛竖起、瞳孔骤缩、下意识后退、**右目青光乍现**死死盯住对方。

## 二、花仙现身：一瞥重创全场

那白色身影是一名相貌近乎妖孽的绝伦女子，秀发披肩，气质如「随天而生、随地而息」的奇异花朵——文中以昔日**柳眉**作比，言柳眉相貌不差却少了那种无法言明的感觉。她只露半身，目光在王林与浮风子众人身上一扫即退回暗处。

仅此一瞥造成的伤害：

| 对象 | 受创表现 |
|---|---|
| 王林 | 心神如被无形重锤敲击，脑中轰鸣，喷出一口鲜血，急退数丈，面色阴沉 |
| 浮风子 | 双目血丝弥漫、喷血，肉山般的身躯颤抖急缩至一半，天地元力涌入心神，退后数十丈，面白如纸；惊呼「**花仙**」 |
| 一尘子 | 双目涣散，胸口砰砰作响，鲜血流下，险些从半空栽落，惊恐至极 |
| 一星子、一龙子 | 心神如被利剑穿透，全身汗毛喷血染红衣衫，坠地立即打坐 |
| 大头、雷吉 | 同样受创；雷吉庞大身躯承受不住，半跪在地，面色死灰 |
| 银尸 | **唯一神色如常**，目中闪过一丝奇异之色 |

王林由此对仙府大为忌惮：**第四座仙府仅是外围便如此凶险**，全部打开后可进入的最终仙府必是处处杀机。他判断此行「恐怕将是我王林前半生最危险的地域」。

## 三、警告与抉择

- 王林以心智判明：那道目光的含义是**警告**——警告众人、尤其警告王林不要踏入。
- 换作寻常之时，面对如此警告与心神打击，王林会明智避开，何况自己所为属于**擅闯他人洞府**。
- 但妖灵之行必须来，理由有二：
  1. **为周佚**：周佚如今生死未知，其最大心愿是让**青霜**复活，而复活的希望系于青霜之父**青霖**。
  2. **为司徒南**：司徒南身上的毒虽暂时压制，若短时间无法解开，后果极为严重。
- 王林的恩义账：**司徒南带他走上修道人生；周佚在其修道路上起到关键作用**——若无当年的**问鼎之晶**，此刻的王林早已在闻道者的朝生夕死中化为白骨黄土。
- 对错的自陈（呼应「谁对谁错」母题）：为了周佚与司徒南，王林认为自己是对的；而对大殿内白衣身影而言，闯入洞府者就是错的。「既然选择了，就要走下去。」

## 四、破甲：灭神矛 + 金光石碑 + 五彩之烟

1. **召矛**：王林立于龟甲外，抬右手虚空一抓，洞府轰隆作响、虚空如被撕开巨缝，黑芒自缝中凝聚成一把虚幻长枪——**灭神矛**，黑色弧形闪电弥漫作响。
2. **古神虚影同步**：王林身后浮现一尊虚幻古神之影，随他握矛，虚影右手亦幻化出一柄灭神矛。
3. **威压异象**：磅礴天地之力充斥洞府，地面碎石飘起、小河流水停滞上浮、破损阁楼尘埃升空。
4. **表态**：王林言「王某不愿伤人」，之前的四个魂体只是残留此地的**分魂**并非本体，自己只想破开龟甲、打开洞府通道。同时**眉心第三目**缓缓浮现，第三目隐藏下**王族五星**急速旋转，古神之力融入全身。
5. **合击**：王林掠向龟甲并喝令「浮风子、银尸，助我破甲」——
   - 浮风子再度收缩身形化作常人，体内金光闪烁幻化出一块**印记众多的巨大石碑**，掐诀轰在龟壳上；
   - 银尸张口吐出**五彩之烟**，贴附龟壳不断消融；
   - 王林顺势抛下灭神矛，矛尖触甲激起环形波纹，龟甲现出细密裂痕，五彩烟渗入裂缝，石碑再撞，**龟甲彻底崩溃**。
6. 灭神矛之威达到王林手中所能发挥的巅峰，破甲后直奔下方大殿。

## 五、结局：花仙出手，仙界碎片崩碎

- 危机感再度出现且比之前更浓郁：一只洁白手掌自大殿暗处伸出，向灭神矛轻轻一点，**漫天姹紫嫣红的花朵凭空绽放**，生生阻住灭神矛；五彩之烟被一点即化作一朵**五彩之花**，静浮半空。
- 白衣身影走出，冷冷盯住王林，玉手前指。
- 王林瞳孔骤缩，张口吐出**炎雷子所赠的保命法宝——雷之仙界碎片**（碎片上的裂痕是当年天运子神通所致）。碎片飞出后竖起放大至百丈，形成盾牌般防护。
- 但碎片之上诡异地开满绚丽异香的花朵；随一声轻柔而冰冷的「**我已经警告过你**」，开满花朵的仙界碎片**轰然四分五裂**。

## 六、要点与伏笔

- **花仙** 是本章新登场的顶级威胁，实力远超在场所有人，且明显以「警告」而非灭杀为先手，态度是守护仙府、拒人踏入。
- **银尸不受心神一瞥所伤**，且目露奇异之色——暗示其体质/来历特殊。
- **雷之仙界碎片被毁**：王林失去炎雷子所赠的保命底牌。
- **青霖** 作为让青霜复活的关键，成为妖灵之地此行的核心目标之一。
- 王林仍在与「擅闯他人洞府是否不义」的因果自问中前行，呼应全书「谁对谁错」的母题。
