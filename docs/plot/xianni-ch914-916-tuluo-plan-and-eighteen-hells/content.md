# 第八卷 联盟隐秘 第914-916章：屠罗计划 / 十八地狱 / 联盟手笔

## 一、王林：从唤雨之术到「规则」（第914章）

### 1. 悟道路径
- 起点是清水传承中的**唤雨之术**（源出**仙帝白凡**）。王林最初试图将神识融入雨水，屡不得法。
- 转折在于换了角度：「不去管这雨水是生是死，我只记住，这水，是从天来」——神识不入雨，而**扶摇直上融入云层**，察觉云中大量天地元气急速碰撞，每一次碰撞即挤出大片雨滴。
- 王林踏雨登空入云，云中雷光游走亦无阻碍。出云一步即至星球另一端，见无形水汽升空凝成飘渺淡云，遂彻底贯通链条：**水汽→云→雨**，且「若是没有风，云无法形成」。
- 双手下按，操控水汽凝出丈许云层，神识一抖便雷鸣降雨；散手则云层透明消失。

### 2. 规则之力
- **窥涅期（第二步修士）的核心是摸索「规则」**，规则才是第二步修士真正强大的力量所在。
- 规则虚无缥缈、极难摸索，这也是第二步修士稀少的原因；部分修士虽也摸到规则、修为提高，最终仍止步且神通威力不强，**原因是他们对规则的摸索是被动而非主动**。
- 表征：雨水临近王林三寸即自行化作水汽，身外浮现云雾。此象与**炎雷子**踏空而来时一模一样，只是王林的云雾稀薄不稳（炎雷子心念一动，身外云雾即可崩溃天地）。关键差别在于——王林身外的云雾**并非元力运转的神通变化，而是规则之力无形改变身外空间**所致。
- 王林感叹：「仙帝白凡，真乃神人」——明悟此术的同时便自然摸到规则，众多仙术中能有此效者微乎其微。

### 3. 两处回照
- **司徒南**：当年司徒南自天逆珠子（石珠）中现身时天正落雨，其一声「给老子散」，雨水倒卷、雾气消散、云层崩溃，万物避退。彼时王林修为太低只觉冲击；如今回想，**司徒南当年分明已摸索到规则**。
- **天逆珠子**：千余年前初得时珠上便有云层，需吸收天地水汽方能增云。王林至此方明白，这是天逆珠子中**水之部分的规则**，且**只是天逆珠子最初级的展现**，他现在也未完全掌握，仅略有摸索。
- 感慨：很多东西一直在身边，未到那个层次则见而不悟。

### 4. 收束
- 右手一挥喝「散」，身外云雾顺臂飞出，天地雨水化雾倒卷，无边云层崩溃退散，还了个万里晴空、彩虹横天，凶兽低鸣、飞鸟盘旋。
- 再以黑风化两头黑龙，阴风与雾气融合成云、云中凝水、四周元力疯狂涌来，心念一动即可散雨天地——**唤雨之术，明悟**。
- 旁观反应：**大头童子**瞳孔收缩、更为敬畏；**雷吉**心掀巨浪，认出「这是规则之力，我曾经才一些大神通修士施法中看到过」，自此心服口服；**塔山**始终闭目打坐、视若无睹。
- 下一个目标：他最感兴趣的神通——**撒豆成兵**。

## 二、屠罗计划启动（第914章）

- 地点：**联盟星域西部与北部交界处**。星空中疾驰着密密麻麻的虚幻身影，行进时星空泛起大片波纹。
- **六指修士**作为罗天先锋，率上百人自已被占领的联盟西部前往北部开道，一路谨慎、神识散开。
- 遇袭：其右手第六根指头剧痛示警，捏碎传讯符后欲施神通已迟。虚幻之影分半围困六指、其余扑向其身后修士。
- 结果：**黑色虚影不断融入六指修士体内，将其夺舍**——此人双目诡异之芒闪烁后恢复正常，低头看身体，喃喃「这个身体，还算可以」；身后罗天修士亦一一走出，人人面带诡异笑容。
- 计划宣告（借六指之口）：
  - 名称：**屠罗计划**，由**地玄殿**展开。
  - 目标：在剧变之后，任务并非只有**许木**（王林化名），而是要把一切残余全部灭掉。
  - 出手者：**四尊**之中此番出动了**黑煞魔尊**与**道元天尊**。
  - 宣言：「这一次，罗天将会知晓，我联盟星域的大门，不是那么好进的。」

## 三、撒豆成兵与十八层地狱轮回界（第915-916章）

### 1. 神通定位
- 撒豆成兵为**仙帝白凡**呼风唤雨、撒豆成兵二术中**威力最强**者；**清水**亦钟爱有加，是清水当年名扬仙界的大神通之一。
- 施法三段：**先开轮回 → 从轮回内抽出所杀之人魂魄 → 自行凝聚神通玄空容纳杀魂**，方可撒豆成兵。
- 强弱因人而异：白凡一式弥漫天地少有可挡；清水施展则以滔天杀戮不战屈人。

### 2. 第一步——开轮回，重历一生杀戮
- 王林运转体内**婴儿拳头大小的仙元之晶（仙豆）**，元力隐匿、周身仙气缭绕如真仙，掐撒豆成兵印诀，身前凝成数丈快到看似静止的仙气漩涡。
- 代价约束：若非入过**仙遗族十七层**补充仙元，施展到一半就会仙豆崩溃、仙元尽散；即便此刻，维持漩涡**绝不超过三天**，逾时仙元断绝、漩涡崩溃。
- **太古雷龙元神**冲出入漩涡，漩涡缩小印于眉心旋转。此神通**以记忆为施法重点**，让施法者沉浸自生记忆、逐一抽出所杀之人魂魄；虽为记忆却极真实，所抽魂魄尚存生前部分修为，可为撒豆之兵。
- 记忆序列（元神所历一生）：
  1. 朱雀星**恒岳派**：少年挣扎施引力术控住持匕青年，另一少年抄斧砍下——魂魄飞出融入元神（王林沉吟「此人并非我杀，为何」）。
  2. 官道之上黑衣青年斗杀中年男子，旁有阴沉青年言「他是即墨老人弟子，我们要立刻离开」。
  3. 丛林洞穴中吞下**藤厉**筑基。
  4. 赵国 → 尸阴宗 → 决明谷 → 域外战场 → 火焚国 → 修魔海龙筋锁千尸 → 万魔百日诛杀令。
  5. 再回赵国血洗藤家无数 → 雪域国之战 → 雨之仙界 → 杀雪域老祖 → 灭巨魔老祖 → 仙遗族与朱雀国之争 → 入朱雀墓。
  6. 天运宗 → 妖灵之地（杀戮剑诀）→ 罗天星域 → 幻家老祖 → 雷之仙界 → 血祖身亡 → 幽冥兽内斩杀仙人 → 罗天西域灭杀姚家族人 → 雷仙殿一线天争夺封号之战（记忆定格）。
- 醒来时全身汗透，眉心漩涡停转化作仙元回体，**仙元之晶缩小近六成**。感慨一生杀戮如过眼云烟、恍如梦中未醒。
- 评价：仙帝白凡的仙术均由众多仙术融合、取精髓凝炼为一道神通，**修炼则需全部经历**。

### 3. 第二步——凝自身之界
- 王林早有决断：心神一动，上空幻化出**黄泉**，怨气滔天，操控之下首尾相融、自成一圆。
- 吐出**封仙印**入半空与黄泉融合，印上**数十万金色符文**扩散融入黄泉，黄泉沸腾后带着金符横扫天际，最终整体融入封仙印。
- 成品形态：封仙印外表再无金符、变为乌黑一片，威压笼罩整颗蛮荒星，内如无数怨魂咆哮挣扎；印上生出数道环痕，**分割为十八层**，每层怨气外溢、乌光封印闪烁，**越深怨气越浓、可纳魂魄越强**。
- 定名与对照：
  - 白凡 → **玄空界**
  - 清水 → **画地为牢杀戮界**
  - 王林 → **以封仙印为本体的十八层地狱轮回界**
  - 构造公式：以封仙印为大地、以金符为封印、以黄泉为轮回、以怨气充斥其内。
- 初始收容：
  - 第十五层以下：空无一魂。
  - 第十四层：**血祖**之魂，被血雾弥漫，透出滔天怨恨。
  - 第十三层：上百个仙遗族被杀的**仙人之魂**，凄厉吼叫欲出而被封；另有**姚家族人**，以及罗天星域中被王林所杀的**阳实以上**所有人之魂。
- 灌注：元神喷出一口精气，内含无数黑气（皆王林所杀之人），按强弱被各层吸收。

### 4. 尊魂幡清仓与善后（第916章）
- 王林抖开**尊魂幡**，幡内海量魂魄疯狂涌出、尽入十八层地狱，怨气更浓、凄厉呼啸笼罩星球——凡人闻之立昏，修士亦心神剧震。
- **尊魂幡内除几大主魂外全部一空**；王林收回幡，感怀「若非此番是遁天所赠，今日都想把此幡融入封仙印」。
- 星球反应：凶兽烦躁散开（若非王林压制将尽数崩溃）；驻守修士面色苍白、片刻不愿多留；大头童子倒吸口气看出此宝不凡；**雷吉从心底生出惊恐**。
- 两个元神的处置：储物袋中取出两个光团——一为**尸阴宗怨殿副殿主**元神，一为此人先前为保命所献之物。二者皆为**极为珍贵的窥涅初期元神**，对恢复修为大有好处，故**未投入地狱，重新收入储物袋**留作日后消耗。
- 王林掐诀将十八层地狱封仙印缩小、一口吞下，喝「离开这里」，雷吉等人紧随而去。

## 四、联盟手笔：自毁西部（第916章）

### 1. 战前疑云
- 罗天修士自撕开的通道涌入，已**全面占据联盟西部**，视之为罗天领域。
- 诡异之处：整个联盟西部**竟无一个七级修真国**，只有一些六级修真星——罗天大神通修士心中阴云越来越浓。
- 但久无变故，罗天终在**雷仙殿**号令下发动新一轮进攻，目标**联盟北域**。数万飞剑齐行，星空颤抖。
- **炎雷子**：脚踏一团青火，神色阴沉，掐算之下只见一片血光弥漫、看不真切，心生莫名深重危机。仍前行，因已停留太久、不能不战而退。其言「即便是再有阴谋，老夫也不畏惧……我罗天方面，同样也针对修真联盟可能出现的阴谋，进行了周密的准备」。

### 2. 引爆
- 大量罗天修士冲入北部之际，联盟西部一颗被占修真星突发沧桑气息，随即毁灭冲击爆发：星球如眨眼走完一生岁月、弥漫死气，并**疯狂收缩至原本一成之大**，继而崩溃成毁灭风暴。星上百余修士肉身消散、元神形神俱灭。
- **并非一颗，而是所有**——联盟西部内所有修真星在同一瞬间崩溃，风暴弥漫整个西部。四周数万里内凡被波及的罗天修士皆肉身消散、元神灭绝。
- 叙述定性：不惜西部所有修真星上一切生灵，此为修真联盟名为**屠罗**的惊天计划；这种灭绝一切生灵的行径，「唯有那种灭绝人姓的无情之辈，才会以如此方法，毁灭一个星球」。

### 3. 战略效果
- 崩溃引发**大片星空裂缝**，越来越多最终连成一片；裂缝中无尽寒风与风暴融合，形成**弥漫大半个西部星空的巨大漩涡**。
- 该漩涡**彻底隔绝了已冲入北部的罗天修士与其通向罗天的通道**——关门打狗成立。
- 风暴稍散，无数虚幻之影幻化而出，一处处**传送阵**扭曲显现，修真联盟凝聚的修士踏出，一声声「杀」回荡星空；联盟北部同样剑光呼啸，联盟修士带煞气扑向惊慌的罗天修士。

### 4. 两尊对阵
- **黑煞魔尊**：黑袍老者自波纹中一步踏出，带滔天杀机长笑：「炎雷子，好久不见，可还记得老夫黑煞魔尊」
- **炎雷子**：眼中红光浓郁却毫不慌乱——「这就是你们的计划么很好那么现在，也让你们看看，我罗天修士的神通」。抬手一指，星空一震，撕开铺展天地的巨大裂缝，**十八个赤色十丈血球**缓缓降临。
- 放话：「你修真联盟可以施展出毁掉西部的大手笔，我罗天岂能没有防范，且看看这第一次交锋，谁能胜你杀我罗天几人，此番，我就杀你联盟几人」。

## 五、要点与伏笔
- 王林修为路线：唤雨之术（规则入门）→ 撒豆成兵（十八层地狱轮回界成形），战力体系补齐一大块；仙元之晶消耗近六成为其代价。
- 天逆珠子（石珠）的规则属性首次被王林正面点破，且明言「水之部分」只是最初级展现——留有大量后续空间。
- 司徒南掌握规则的追认，抬高了这位早期存在的层级。
- 联盟西部「无七级修真国」的诡异现象在本卷得到解答：那是为屠罗计划预先清空的弃子战场。
- 十八个血球 vs 黑煞魔尊，为下阶段大战开局；四尊中另一位道元天尊尚未现身。
- 罗天方面对「许木」（王林）的追杀已并入更大的清剿任务序列。
