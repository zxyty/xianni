# 第1314章 宿命第一战（第九卷 云海之巅）

## 一、月族的倾族之围

月族为活捉古神，准备了无数万年，本章几乎倾尽老本。文中点明：天地间最了解古神一族者，除古神、古魔、古妖外，唯有月族——故其所有手段皆是「专门针对古神」，若换作其他第三步修士，这些法宝反而未必能发挥全部威力。

### 四大神通至宝（已入阵）

| 至宝 | 表现 | 备注 |
|---|---|---|
| 大月灭神术 | 无数月牙之芒、四周月色丝线弥漫 | 拓森双臂挥舞震碎临近月牙 |
| 血月之翼 | 被拓森一拳打爆后化作无数羽毛刺入其身；亦穿透王林身体 | 王林鲜血弥漫、无法后退 |
| 古神九头骨 | 九个头骨如九日般冲向拓森，临近刹那轰然崩溃 | 月族护族之宝；九骨皆为无数年前死亡的真正古神；每一个崩溃≈一名第三步修士自爆。拓森喷血 |
| 溃神液 | 化作血海形成巨大血色漩涡，卷住王林与拓森，令古神之力不断融化 | 月族之人出生时种入体内，来历不详；无数万年前叛变中曾成功杀死古神 |

### 白发老者续请三宝

- **古神之眼**：两颗血红眼珠现于星空，目光带血腥直勾勾锁定二人。
- **巨灵钟**：巨大古钟现世，钟鸣化作波纹冲入阵法。
- **灭世第九灵**：老者掐诀尖啸、七窍流血、白发诡异蠕动，身前幻化出看不清样貌的青色虚影。**王林认出该青光与妖灵之地古神头骨内的气息一模一样**，拓森见之瞳孔收缩。

## 二、拓森的吞噬与王林的反制

拓森一晃身震开血海，不再犹豫，眉心六个星点急闪冲向王林，欲吞之融合后杀出封印、令月族血流成河。

王林并不反抗，只冷冷道出两击要害：

1. **「我拥有涂司记忆传承，你若吞我，你体内传承合一，涂司立刻苏醒。」** 不信大可一试。
2. **「你只是要传承法则打开对神通不可施展的封印，此事并非虚吞才可，你我配合定然双赢；一意孤行则涂司苏醒，你必死无疑——在涂司面前，你可有逃遁之地？」**

补刀：「你我毕竟都是古神，岂能让这奴族欺辱封印。你若信我，我二人先灭奴族，而后我自然会给你一个答复。」

拓森的判断：哪怕一万份中九千九百九十九为假，只有一份是真，他也赌不起——一旦涂司复活，他必死。于是咬牙应「好」。其暗中盘算：灭了奴族后王林无处可逃，届时慢慢研究；**若王林所言为真，索性放弃成为九星的希望，毁其记忆传承，让涂司再无苏醒可能**。

## 三、古神八星之术·虚

王林掐诀前挥，诵古神之语：

> 「天地初开，有古之一族，古有三份，古神为一，逆道而行，于天地一战，悟宇宙洪荒，施毁灭天道，化开星空，破一切乾坤之术——古神八星之术，虚！」

- 王林眉心六个古神星点疯狂旋转，古神之力涌入双手，凝出**残缺符文**；其气息为毁灭、瓦解一切神通、瓦解天道。
- 拓森右手一挥，注入**比王林浓郁数倍**的古神之力，符文由残缺瞬间补全。
- 完整符文乃**八星古神神通**，无数万年来未曾出现于太古。光芒介乎黑白之间、呈灰色，以二人为中心疯狂扩散。

**战果**：溃神血倒卷；古神之眼轰然爆开；巨钟波纹消散；青色虚影（灭世第九灵）因「并非纯粹」，挣扎片刻后烟消云散；四周月色丝线碎开；**封神大阵组成的月色世界出现无形裂缝、剧烈颤抖**。

## 四、月族第一宝·古神残骨

白发老者神色凄厉，吼出「请月族第一宝——古神残骨！」天地裂开巨缝，一根**半个修真星大小、只有骨头没有血肉的中指之骨**缓缓探出。拓森大变色：**「这是九星古神的手指！」**

老者与四周十万月族修士、数百修真星上维持阵法的修士齐声大吼「**灭神**」。文中点出讽刺：月族无数年前判（叛）出古神、也曾灭过神；眼下他们要灭掉的，是那曾经帮助了他们无数年的神。

**结果**：
- 封神大阵在符文光芒穿透中轰然崩溃，崩溃瞬间与指骨相撞。
- 拓森喷血、身子一晃被抛向远处。
- 王林全身骨头尽碎、砰砰作响，鲜血弥漫，被抛向另一方向。
- 巨大指骨**毫发无损**，轰然落在大地。

## 五、王林反扑

被抛出的一刻，王林毫不犹豫再施**吞灵噬体绝天**，身化黑雾随巨力冲击直奔阵法人群，雾散之处凄厉惨叫四起，**所过之处月族之人尽数枯萎成尸骸、砰砰崩溃**。更远处，拓森的咆哮传来，同样展开反击。

## 六、要点归纳

- 王林本章的核心筹码始终是「涂司记忆传承」——既是拓森想吞他的原因，也是拓森不敢吞他的原因。
- 王林与拓森的联手是**纯粹互相威慑下的临时合作**：拓森已明说灭族后要擒/毁王林，王林则只承诺「而后我自然会给你一个答复」，未做实质让步。
- 月族至宝层级由低到高：四大神通至宝 → 古神之眼／巨灵钟／灭世第九灵 → 第一宝古神残骨（九星古神中指骨）。
- 伏笔：灭世第九灵的青光 = 妖灵之地古神头骨的气息；九星古神残骨的来历与主人未明。
