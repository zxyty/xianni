# 仙逆 第七卷 名震罗天 第806章 玄阴鼎

## 一、战斗：普通雾兽 → 人形雾兽

### 1. 击破普通雾兽
- 王林身形一晃至雾兽旁，**双指成剑**点其眉心，元力运转令其身躯崩溃。
- 雾兽崩溃后**不散**，化作飘渺雾气并有再次凝聚之势。
- 王林以**元神雷威**凝于指尖，化出雷球点入雾气；雷霆磅礴涌入，雾气崩为碎云般烟丝。
- 再掐诀一指，大片雷霆散出，**残存雾气全部瓦解**。

### 2. 道化黄泉·第三式「黄泉之力」
- 面对扑向众人的余下雾兽，王林飘于半空，一指天空：**「道化黄泉」**。
- 一道黄泉自天而落，**来于虚无、融入虚无**，散发浓郁怨气；王林踏于其上，「好似这世间黄泉轮回之主一般」。
- 喝出**「第三式，黄泉之力」**，黄泉生出无法想象的吸力，几乎所有雾兽被吸入，身躯崩溃化雾、挣扎不得。

### 3. 人形雾兽出世（先祖老者阻止）
- 仙选族**先祖老者**急呼「上仙不可」——被吸入的雾气**未被炼化**，反在黄泉内凝聚融合成**人形之物**。
- 该物仅有轮廓，内里雾气蠕动，**面部模糊、五官中唯有右目**，一步便从黄泉中踏出，黄泉之力对其失效。
- 老者说明特性与对策：
  - **「人形雾兽」**：任何法术落其身上，**若不能立刻杀死，第二次攻击便不受其伤**（法术免疫/适应）。
  - 族人通常只能**开启仙阵**将其杀死，故请王林速退。

### 4. 王林四段连破
1. **雷球合击**：虚无中幻化数十个拳头大小雷球，临近时喝「凝」合为一击，轰中人形雾兽——崩溃后一息重凝，且**吸收学去雷霆之力**，散出雷光与王林神通几乎一模一样，借雷光提速疾追。
2. **仙剑·斩罗诀**：右手拍储物袋取出**仙剑**，一斩之下「斩罗诀」临世，人形雾兽身子一分为二，露出骇然；王林踏步瞬移至雾气旁连续斩出，雾气渐生抗性、崩溃变慢并有重聚迹象。
3. **仙术「定」**：一指定身，凝聚中的雾气立止。
4. **兽骨煞气石化**：手背**兽骨图案**蠕动幻化而出，巨大兽骨双目幽光一闪，浓郁煞气弥漫，雾气泛灰**石化**；王林双指点上灌入元力，石化雾气崩为无数碎块，碎块散开时再度崩溃，**彻底瓦解**。

## 二、震慑与反应
- 仙选族族人睁大双眼直视王林：这是他们**第一次**见到只能被阵法杀死的人形雾兽，被人短时间内毁灭，且几乎毫无反抗之力、节节败退而亡。
- 先祖老者目瞪口呆，**喃喃自语「子母道枯」**（对王林手段的判断/所指未明）。
- 被王林**碎片大印**压入地底的大汉**塔山**挣扎爬出，呆住自语：「这就是仙人么」。

## 三、赴玄阴鼎
- 王林转身对先祖老者平静道：**「现在，带我去玄阴鼎」**，老者恭敬躬身引路，飞入建筑群。
- 塔山追上求随行；老者怒斥其纠缠，并点明「上仙之前已经手下留情」。
  - 旁白确认：王林确是手下留情——**初来此地诸事不明，若杀人恐有影响**，否则塔山必死无疑。
- 塔山称自己**熟悉玄阴鼎**，愿随行入内；王林准：「跟着吧，带路」。
- 三人缓行，**半柱香**后抵建筑群后方空地：
  - 一处**不大的祭坛**，四周多处裂缝；
  - 祭坛之下有一座**通体紫色的大门**，门上**符文印记时而闪烁**。

## 四、要点小结
- 王林本章展示的手段谱系：双指成剑/元力、元神雷威雷球与雷霆、道化黄泉（第三式·黄泉之力）、仙剑+斩罗诀、仙术定身、手背兽骨煞气石化。
- 人形雾兽的关键设定：由被吸/被杀的雾气**融合而生**，独目（唯右目），**对同一法术二次免疫**，可**习得对手神通**（雷霆），常规解法为仙阵。
- 剧情推进：王林在仙选族确立绝对威压 → 获得引路权 → 抵达**玄阴鼎入口**（祭坛+紫色符文大门），塔山作为熟悉玄阴鼎者随行。

# 第806–807章 玄阴鼎与仙选族的信仰崩塌

> 卷次：第七卷 名震罗天 · 第807章 传送小阵（含第806章末尾段落）

## 一、开启封印大门
- 仙选族老者（先祖）落于大门前，咬破指尖，以鲜血虚空画出与大门印记相同的符文。
- 符文红光一闪融入大门，轰隆声中大门升起，露出漆黑入口。
- 入口内透出丝丝阴寒之气，钻骨蚀体，修为不足者会被冲出暗伤。
- 老者恭敬告知王林：此处便是玄阴鼎所在。
- **王林神识察觉**：这阴寒之气中，藏有一股隐藏极深的**仙气**。

## 二、塔山抢做向导
- 塔山挡住老者去路，理由是「寒气太重，先祖年纪大了」，并自陈身份「我是这一代的祭坛守护者，有资格带你进入」。
- 王林目光如穿透内心般审视塔山，塔山毫不闪躲；王林应允「好」，嘴角露出一丝冷笑（已猜到对方另有所图）。
- 老者隐约看出塔山心思，长叹一声未跟随，盘膝坐于地上等候。
- 二人顺阶梯而下，阴寒愈浓，半柱香后抵达底部。

## 三、玄阴鼎实景
- 底部别有乾坤：约**百丈**大小的空间。
- 正中一尊**十丈**大小的巨鼎，鼎面刻满无数符文印记。
- 鼎口有阵阵黑气环绕、欲挣脱而出，被一股奇异力量封印，无法离开。
- 鼎四周有**九个头骨**——非兽骨而是**人骨**，每个眉心处刻有极复杂符文，乌光闪烁，宛如一个阵法。
- 塔山望鼎，眼中神色复杂。

## 四、神识探鼎受挫
- 王林神识顺目光绕鼎一周，犹豫片刻后猛地冲入鼎内，**没有任何阻挡**。
- 神识入内刹那，鼎中爆发**女音尖锐厉啸**：肉耳不可闻，唯神识可察，内蕴浓郁杀机，如一场风暴，几乎令王林神识崩溃。
- 王林身子一晃退后数步，面色略显苍白，但双目精光一闪。
- 王林决定：「我要在这里留下几日」，命塔山先出去。

## 五、塔山的信仰崩塌（本章核心）
### 塔山的自述
- 自幼被长辈灌输：我们是**仙选族**——仙人选择、眷宠的一族，生命要献给仙人，这是荣耀，是族人唯一信念。
- 长大后生疑：**从来没有人见过仙人**，唯有祠堂内一份「仙谕」。
- 族人守护的玄阴鼎**每隔一段时间喷出雾气**，雾气化作各种样子**屠杀族人**，一次次死亡累积成悲愤。
- 结论：「我塔山，不信有仙人存在，若真的存在，为何这么多年，把我们遗忘」

### 王林的回答
- 「我，不是仙人。」
- 「仙人，或许还有存在，但**仙界，在很久之前，便已经崩溃，没有了**。」
- 塔山惨笑退后：族人守护这里这些年，却是错了。

### 王林的推断
- 听到老者自称「仙选族」时内心一动，隐约分析出始末：
  - **「仙选族 → 仙遗族」「选择 → 遗弃」**

# 第807-808章 玄阴鼎灵封门与第三辆射神车的七个符文

## 一、鼎口试探与传送小阵

- 可穿透神识的厉啸再度爆发，强度数倍于前，直贯王林心神。王林全身元力运转守护元神对抗，仍被逼得面色苍白、收手后退**七步**，每一步落地都震动地面、留下深深脚印。
- 稳住后王林冷哼飞起，俯视鼎口：内里黝黑一片，只有缭绕黑气与阴森气息。
- 王林抬手，**体内雷威**凝出雷球抛入鼎口。黑气如吞噬般将雷球吞下，王林低喝「爆」，雷球崩溃、黑气外推，他趁刹那双目精光爆闪看穿至底部——
- **鼎底有一个传送小阵**。旋即黑气云涌重新覆盖阵法。

## 二、玄阴鼎灵出世与追击

- 黑气迅速凝聚化作人形：一名**全身由雾气组成、看不清样貌的女子虚影**，身下黑气弥漫，出场即尖啸。
- 此次尖啸**兼伤元神与肉身**，几近音爆、如同实质。
  - 塔山（非变异雷元神）虽距离稍远仍受波及，面无血色、双目黯淡、**元神受伤**。
  - 王林面色苍白、嘴角流血，抓起塔山顺出口飞出。
- 追击战三段：
  1. **血雾封印**：王林转身喷出元神精气化作大片血雾，低喝「封」，血雾化作一个个禁制封印贴附鼎灵全身。
  2. **因果昆极鞭**：右手虚空一指，鞭子幻化而出狠抽，鼎灵惨哼退后，随即身子一散化作**九道黑气**如箭矢再追。
  3. **第三眼神通**：王林退至出口大门，反手扔出塔山，一点眉心开启第三眼，红光环绕出口，九道黑气大范围消散——但**重新凝聚成一股后无视第三眼神通**直奔出口。

## 三、闭门与仙笔六符

- 门外仙选族先祖老者见状不待吩咐，双手掐诀，**眉心植物闪烁化作符文**印在大门上，大门缓缓合并；鼎灵厉啸反噬，老者一颤喷血、身形萎靡。
- 合门刹那，王林一拍储物袋取出**仙笔**，一勾之下**六笔符文**齐出，金光万丈如利剑印在虚影身上。砰的一声巨响，大门合拢，尖啸被隔绝。
- 塔山头皮发麻，问「那是什么」；老者答：**「玄阴鼎灵」**，眼露复杂之色。
- 王林神色阴沉，命二人退下、**此地百丈不许人踏入**，自己盘膝坐下。

## 四、本命符文与此地判断

- 王林看清老者是以**眉心植物化作符文**开门，判断那是**本命符文**。
- 他取出当年离开**朱雀星**时在**仙遗族**所得的大量族人头骨——每个头骨上都有一个复杂符文——细看数眼后收起（比对本命符文之意）。
- 抬头望天：一片蔚蓝，但以王林目力可隐约看到**白云尽头仍是肉壁**。
- 王林的判断：此地若真被彻底封印，为何自己能传送而来？此地并非善地，需尽快找到离开之法；但同时**此地虽险，却也是最好的藏身之处**。

## 五、第三辆射神车与七个符文

- 王林取出储物袋中**最后一辆、也是最强的一辆射神车**：
  - 尺寸：约**十五丈长、四丈多宽**；
  - 外形：遍布无数利刺，狰狞非常；
  - 威压：一出现便弥漫强烈威压，望之者心神被摄、恍惚生畏。
- 来历要点：**当年此物的制作者，目标便是制作出可以杀死仙神的器物**。
- 对照成长：王林当年面对此物**险些崩溃、不敢使用**，只能以传承之法封印；数百年岁月后，他今日站在车旁**古井不波、目光如炬**。
- 激活：闭目后睁眼，双手掐诀、口诵复杂咒文，左手按在右手腕上引出**黑光**凝于右手，齐齐虚空按向射神车。黑光融入车内如被吸收，射神车威压暴涨。
- **结果：车上所有利刺黑光闪烁彼此相连，形成浓郁黑光笼罩天地，融合幻化出七个若隐若现的黑色符文。**（即第808章标题「七个符文」）

# 第三射神车认主：元神吞炼七道封印符文（前五道）

## 一、仙简遗训：射神车的残缺与祭炼条件

王林望着黑光中的七个符文，回想当年射神车制作者留在仙简中的话：

- **威力定位**：「余第三射神车，威力之强，超过了初之所想，此物若发挥出全部之力，可杀仙神易如反掌。」
- **残缺**：此物并不完整，缺少三样材料——**玄玄翅、冥文木、仙蝶魂**。制作者终生未能取到此三物，引为憾事，望后世传承者代为寻找，以圆其憾。
- **认主之法**：需与**七道封印符文**融合，并炼之为**性命相修的本命之宝**，方可发挥真正作用；否则即便符文融合，若不祭炼，威力也无法展开。制作者特意叮嘱「谨之，慎之」。

王林当年看到这些话时并未放在心上——因为需要「谨慎再谨慎」才可决定祭炼的，正是性命相修的本命法宝。

## 二、设定要点：本命法宝（性命相修）

| 类别 | 被毁后果 | 收益 |
|---|---|---|
| 普通法宝（神识烙印） | 最多受伤，轻重有别，绝不致死 | — |
| 元神中滋养的法宝 | 波及更大，仍不伤性命（如百丈碎片、当年的几把剑） | — |
| **性命相修本命法宝** | 轻者重伤、元神分离；重者**魂飞魄散** | 法宝之威暴增数倍，且随修士成长而**同步增强** |

王林曾在典籍中读到：上古有一修士，本命法宝只是一把普通飞剑，随其修为不断高深，飞剑随之成长，最终达到可怕高度。

王林判断：**这第三个射神车，与之前两个不一样。**

## 三、护法布置

1. **蚊兽**出储物袋——久未现世，出即掀狂风、尖啸盘旋，极为兴奋。
2. **雷蛙**自储物袋幻化而出，落地趴伏，目露懒散，不愿挪动。
3. **许立国**被王林单指弹出仙剑；一脸阿谀欲言，被王林目光扫住而止。
   - 王林令：「我祭炼法宝，方圆百丈内，不要让人踏入。」
   - 许立国拍胸表忠：「除非踏着我的尸体……我许立国一生为忠而战，为忠而活。」被王林皱眉后收声退至百丈边缘。
   - 其内心独白：最近马屁拍少了，说起来不自然，才惹得「这煞星」不耐；日后要好好锻炼这门「最大的神通」，就算日后逃走也用得上。随后一边游走守护，一边低声演练奉承台词（「主子神通惊人，犹如真正的神仙」「小许子对您的敬仰滔滔」等），越练越流利、眉开眼笑。蚊兽飞过时听到几句，以其心智听不明白，反而好奇，时而故意飞来偷听。
4. 王林双手掐诀，在四周**布置数个禁制**。

## 四、炼化过程：元神化太古雷龙吞符文

王林右手点眉心，**元神离窍**，化身为一条**太古雷龙**，直奔射神车，在黑光外盘旋后张口吞符。

| 符文 | 耗时 | 经过 |
|---|---|---|
| 第一道 | 不足半柱香 | 狂躁之力在元神内咆哮抵抗；元神内砰砰响动，**每响一次雷威增强一倍**，瞬息间化作强悍力量冲击，符文崩溃，化为奇异之力融入元神 |
| 第二道 | 一炷香 | 比第一道强出很多，仍被彻底炼化 |

**境界对照**：若换作王林**问鼎期**之时，在符文抵抗下元神必承受不住，或陷入不断消耗的对抗漩涡；此刻已可强压。

炼完第五道后，王林**元神略有黯淡**，顺肉身眉心回缩，随即打坐吐纳静养。

## 五、静养五日与外围骚动

- 王林五日内身子一动未动，吐纳中元神渐复。
- **仙选族**的**塔山**、**先祖老祖**及大群族人两度来此，被蚊兽尖啸、雷蛙雷光、许立国的魔头狰狞震慑，只在百丈外徘徊。
- 众人望向射神车时**均极为震惊**，相互议论；连见识最广的先祖老者也**不识此为何物**，但射神车散发的威压令其心神剧震。
- 许立国望着仙选族族人舔嘴唇，想起当年在**青灵星**的「快乐往事」，趁王林打坐时在百丈边缘试图引诱几人进来，无一人理会。

## 六、本章收束

这一天王林睁眼，再点眉心放出元神直奔射神车——元神刚现，百丈外**立刻传来惊呼**。（第六、第七道符文的炼化尚未完成，射神车认主未竟。）
