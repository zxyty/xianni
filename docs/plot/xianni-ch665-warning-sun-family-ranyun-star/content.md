# 第七卷 名震罗天 第665章 警告

## 一、青竹阁售宝

- 地点：罗天星域·冉云星·孙家之城·青竹阁。
- 王林在此地**换了样貌**行事，即便有熟悉之人也无法从行事风格认出身份。
- 心态：他不主动抢人仙玉，但若对方来抢他的，便是「正当防卫」；有了道理，即便杀人也理直气壮，加之修为强大，冉云星无人敢出头。
- 八百年修行让王林兼具机智与阴险，只是阴险很少表现。

### 交易内容

| 物品 | 性质 | 价格/去向 |
|---|---|---|
| 铜镜 | 传承伪仙宝 | 王林开价五万仙玉，孙长老实付四万（拿出储物袋、取走一万后连袋给王林） |
| 记录传承的玉简 | 传承信息 | 王林交付孙长老，孙长老看后面露喜色 |
| 钗子 | 伪仙宝（非传承） | 孙长老失望，未买 |

- 孙长老的犹豫：五万仙玉是近百年积累，本为**日后问鼎**准备；但婴变修士若得传承伪仙宝，意义大不相同，威力足够甚至可与婴变大圆满一战。
- 他曾动过杀人夺宝之念，但见王林神态始终平静、又能拿出两件伪仙宝，判断其为某修真家族嫡系，遂作罢。

## 二、出城诱敌

- 王林离店后神识散开，察觉有一道神识始终锁定跟随，嘴角浮出讥讽。
- 「我便给你一个机会」——王林转向出城，御飞剑腾空，**刻意把速度保持在结丹期程度**。
- 出城数千里后，前方凭空涌现大片雾气，凝形化作大手抓来。
- 王林抬右手随意一挥，庞大**仙力**横扫：大手烟消云散，黑雾被吹散，传出惨哼。
- 伏击者现身：消瘦中年男子，**元婴中期**，喷血、周身电光游走，骇然遁走。他惊觉「你不是结丹」。
- 中年男子后悔听了**孙长老**之话，为些许灵石来找麻烦；元婴已涣散大半，若不及时回族必死。
- 王林踏步不紧不慢地追击，形成生死压迫。

## 三、孙家大宅对峙

- 中年男子逃入城中心孙家宅子，大吼求救后昏死；白衣男子接住并灌入大量丹药。
- 孙家众修士涌出，有人祭飞剑扑向王林；王林大袖一甩起风暴，百丈内孙家修士尽数被卷飞。
- 三名老者现身，其一即**孙长老**（面色阴沉）；红脸老者喝问「你是谁家的孩子」，斥闯孙家是滔天大祸。
- 王林指向孙长老：「我为他而来」，并指昏迷的中年男子说明自己刚出店铺便遭阻截。
- 另两位老者一看便猜出因果：孙某人眼红对方之物，不便自己出手而派族人；但既已发生，身为孙家长老须维护。
- 红脸老者放话「今日便留下吧，等你家族长辈来交涉后再论生死」。
- 王林眼中冷光一闪，抬手下按——天空轰鸣，**庞大威压**降临孙家大宅，孙家族人须全力运转灵力抵抗方不崩溃，三位老者亦目露惊骇。

## 四、黑衣老者与问鼎神识

- 黑衣老者踏出，威压略消。其修为为**婴变期大圆满**，距问鼎仅一步，似只差一丝感悟圆满。
- 关键细节：王林看到他身上**环绕着问鼎修士的神识**——并非其隐匿修为，而是外来神识加持（后揭示为本家老祖降临其身）。
- 黑衣老者认错：「此事确是我孙家不对」。
- 王林开价：「**二十万仙玉**，此事作罢」。
- 黑衣老者应允，但称此地只是**孙家分支**，数量太大不足量，请等待**三天**。
- 王林大有深意地扫过老者身上的问鼎神识，转身离开。

### 事后处置

- 王林远去后问鼎神识消散，黑衣老者松气并狠瞪孙长老。
- 红脸老者质疑二十万仙玉即便在本家也是大数目。
- 黑衣老者转述老祖之命：**一切要求全部应允**，「别说二十万，即便四十万也要给」；另行**家族封口令**，今日之事不得传出，更不要去打扰此人。

## 五、冉云星东部海洋——孙家老祖的判断

- 冉云星东部辽阔海洋深处，一长发男子（着半身）盘膝海底，睁目如两盏明灯。
- 内心判断：
  - 「此人莫非就是那突然出现的**问鼎修士**」；
  - 「他的修为，我看不透」，身上更让他隐约有**战栗之感**；
  - 「此人，不能招惹」；
  - 「他既在我孙家之城，或许正是我孙家的机缘来临」。
- 对王林最后那一眼的解读：**是警告**——告诉他不要去打扰自己；「此人，有这个资格，对我这般说话」。
- 随后他从海底飞出，踏步而去。

## 六、要点提炼

1. 王林以改换样貌 + 压制到结丹期的速度作双重伪装，钓出跟踪者，把「杀人夺宝」转为「正当防卫」的道理占位。
2. 王林当前实力已远超婴变/元婴层次，随手一挥即溃元婴中期、威压覆盖整座家族大宅，被外界推断为「突然出现的问鼎修士」。
3. 结果：孙家赔二十万仙玉（三日内交付），并对全族下封口令、主动示好，王林在冉云星立威。
4. 悬置线索：黑衣老者身上的问鼎神识 → 指向海底的孙家老祖；三天后的仙玉交割是后续钩子。
