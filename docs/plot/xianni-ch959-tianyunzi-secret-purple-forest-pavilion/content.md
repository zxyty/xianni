# 仙逆 第八卷 联盟隐秘 · 第959章 天运子的秘密

## 一、天运子的安排
- 天运子告知王林：**妖灵之地开启还需一些准备**，此次事关重大，**也要各自邀请一些好友入内，方可最终进入那洞府之中**；命王林在此地安心等待。
- 天运子神色如常、看不出喜怒，说罢袖子一甩，脚下现白云，踏云而去；远远传来飘忽之音：「**紫林阁始终还为你保留。**」

## 二、王林的两处疑虑
1. **凌天候**：剑尊凌天候的举动大有深意——此前与王林一战，**即便是最终的神通之术也并未展开全力**。王林猜不出其全部心思，但大致看出几分。
2. **天运子**：始终琢磨不清。即便察觉一丝端倪，转眼这端倪又似有别的解释，终成谜团。王林感觉「**每一次看到的天运子，似乎都不太一样**」，身上总笼罩一层迷雾。
3. **过于顺利**：天运子的安排虽与王林事先猜测一致，但真正面对时反觉不对劲——**一切仿佛全按王林心里所想而作**。

## 三、重回紫峰路上：偶遇李姓修士
- 天运宗广场通往紫系山峰只有一条深幽山道；夕阳、山风、树叶与远处流水声。王林阔别数百年重踏此路，感慨很深，「一切仿佛与当年没有任何变化」。
- 途遇一男一女两名**婴变期**蓝衫修士，二人交谈中的信息：
  - **鬼眼坊市七日后再次开启**，不少道友已赶去。
  - 该坊市**当年因拍卖一道罕见的完整仙术而一举成名**，轰动一时，数位修为高深莫测的老怪都曾亲自去过；以二人身份只能获得**不完整的下品仙术**。
  - **此次据说有一样神秘之物将展开拍卖**。
  - 拍卖处需**邀请资格**；男子取出**鬼眼邀请简**（通体漆黑玉简，中心有一仿若眼睛之物散发红芒，颇为诡异）。无资格者仍可进入**自由交易区**。
- 王林神色温和上前招呼「李师兄，别来无恙」。他不知此人姓名，只知姓李，当年在天运宗有一面之缘，记得对方当年目光**充满讽刺与不屑**；今观其修为已由**婴变初期→婴变中期**。
- 二人此前**丝毫未察觉王林存在**。李姓男子事后骇然低语：在王林身上**看不到丝毫灵力波动、整个人如同凡人**，但擦身而过刹那**心神一震、体内灵力颤抖惧怕、险些崩溃**。
- 身份揭破：王林是当年天运宗**紫系老七**；女修士忆起传闻——「当年在妖灵之地杀戮滔天、血流成河，被师尊及众多前辈追杀仍然逃走的**魔头王林**」。王林远处苦笑，叹人言可畏，数百年间关于他的事已渐渐走样。

## 四、紫林阁（旧名紫云阁）
- 紫峰高耸入云，峰顶云雾缭绕、紫光弥漫，为紫系弟子所居。上山一路未遇任何修士，唯风声呜咽。
- 王林恍惚看见当年那个**刚从朱雀星来到这里的青年**，一步一步走上山峰、站稳脚跟。
- 阁楼匾额「紫」字；王林忆及「还记得昔日，此地名为**紫云阁**」。
- 推门霉味扑面，摆设与当年一样，唯灰尘弥漫，桌上油灯早已油尽灯枯。
- **清尘手段**：王林挥手生柔风扫遍楼上楼下，只卷灰尘，**其他物件纹丝未动，纸窗亦无声响**；数息后手心向上虚空一握，风暴如时光倒流般凝入掌心，化作**深灰色漩涡**，随手挥出窗外——「好似把这数百年的光阴全部挥去」。
- 于**紫木柜**中取出当年存放的小半瓶**褐色灯油**，添入油灯，一指点燃。

## 五、核心顿悟：灯火即天运子
- 灯火亮起之际山风入窗，火光摇曳，王林影子如同扭曲。王林盯着摇曳之火，双目爆出精光：
  > 「风吹，灯火起了变化，在风中变化莫测，分不清哪一个才是其最初的样子……我明白了，**天运子就如同这灯火**，我之所以感觉每一次看见他都不太一样，正是因为此人**无时无刻都在变化**，就如同一个人有**数千分身**，这数千分身**同时在一具肉身内**，每时每刻这些分身都在**交替**——所以，天运子才会给我那种莫测之感。」

## 六、待办 / 伏笔
- 等待**妖灵之地开启**，其间需各自邀请好友，方能最终进入洞府。
- **七日后鬼眼坊市开启**，将拍卖一件神秘之物（需鬼眼邀请简方可入拍卖处）。
- 天运子「数千分身交替于一身」之秘尚待验证。
- 凌天候未尽全力的真实意图未明。
