# 仙逆 第八卷 联盟隐秘 第1079章 木冰眉

## 一、战场态势（妖灵之地）
- **古魔塔珈 vs 五老**：塔珈双臂伸开，身后浮现月牙般虚幻之相，一声「月葬」，五老身前空级法宝轰然崩溃，五人倒卷喷血。
- **火焰巨人被破**：近百族人元神凝化的火焰巨人被塔珈神通崩碎，元神各自返体，近百族人齐齐喷血。
- **其他战线**：司徒南（断臂所化人影，自第336章起自称司徒南）与天运子分身交战，浑身血迹；大头（元神状态）与粉尘子另处交战。

## 二、塔山现身与退场
- 塔山长期躲于下方，此战与他关联很小，本打算不出面。
- 见王林生死危机的一瞬，心中有声音怒吼呐喊，身子仿若不受操控冲出，扶住吐血的王林。
- 王林令其松手、转去助大头：因塔山虽得**符文圣祖传承**，仍远不足以阻天运子；其外表伤势不重，但**承受不了第二击**。
- 塔山犹豫后后退，目光与往昔有了一样的光泽，转身直奔大头与粉尘子方向。

## 三、王林的诀别与托付
- 捏碎剑鞘（崩碎成无数碎块），只留其内**锈迹斑斑的铁剑**。
- 宣言：「我王林身为逆修，即便是死，也要顶天立地。人之一生，没有任何畏惧，唯，一死尔。」
- 最后一次称天运子为**师尊**，并托付两事：
  1. 若死，送骸骨回**朱雀星**，「即便没有了轮回，也让我葬在故土」；
  2. 司徒等人与师尊无太大关联，若他死，请放过他们。
- 天运子神色平静，沉默片刻后**点头应允**。

## 四、三十三剑
| 节点 | 内容 |
|---|---|
| 1–19剑 | 元力尽灌铁剑，虚幻大剑横扫；至第十九剑王林吐血，赤红铠甲暗淡 |
| 23剑 | **当初王林能发挥的极限一剑**；落下瞬间全身铠甲消散，化作火元力融入铁剑 |
| 24剑 | 体内砰砰作响，双眼流下两行血水 |
| 25剑 | 旧伤口被撕开，胸口喷出血雾，以意志强撑不倒 |
| 26剑 | 天运子动容、露出沉吟 |
| — | 天运子断言：在其**「天人第一衰」**下，以王林此次**空涅法宝**之威，**达不到三十剑以上**便无法阻其脚步 |
| 27–29剑 | 王林七窍流血，铁剑抛出，临近天运子一卷连化三剑 |
| 30剑 | **元神大范围崩溃**（未消散但更萎靡）换取更多元力，剑芒更盛，逼出第三十剑 |
| 31–33剑 | 电闪雷鸣般接连出现；第三十三剑随最后一指乍现可穿透妖灵之地的剑芒，铁剑锈迹化片融入剑光 |

### 结果
- 剑之风暴连接天地，妖灵之地剧烈颤抖、大地崩溃、天空倒卷并**被撕裂露出外界无尽星空**，无穷天地之力宣泄而来。
- 全场（含塔珈）停止厮杀观望；塔山握拳颤抖唤「主子」，大头元神呆望唤「主人」，司徒南双眼撕裂唤「小林子」。
- **天运子**：气浪过后平静立于原地，手中出现一把**散发浓浓沧桑之气的三叉戟**；但衣衫风一吹碎裂大片，头发亦有不少碎裂消散——受损但未败。
- **王林**：带着不甘缓缓后倒，自高耸天际的百里地面向下坠落。

## 五、坠落中的走马灯
- 心念「就要去见爹娘了么」，在被撕裂天空外的星空中，依稀看到爹娘身影招手，露出**一千多年**未亲眼见过的慈祥微笑——他记忆深处最珍惜的画面。
- 爹娘身后还有**李慕婉**与「王林」的身影，他喃喃「你们是在等我么」。
- 最后遗憾：「只是司徒、周佚，我的承诺，无法完成了，对不起。」随即闭目。

## 六、木冰眉登场（本章题眼）
- 王林闭目刹那，妖灵之地星空中出现一男一女两道身影：**昆虚之境的老者**与**木冰眉**。
- 木冰眉绝世容颜、无尽冰冷，在看到王林坠落的一瞬「冰冷崩溃」，涌起不知为何的复杂心绪，身体仿若不受控制，一步化作长虹直奔王林。
- 老者皱眉暗叹，但**没有阻止**，转而看向妖灵之地众人。
- 木冰眉如飘舞蝴蝶般扶住王林——**这是她第一次与他面对面**。
- **救命丹药**：虚空一抓开出裂缝，取出玉瓶——通体**极品仙玉**打造，内蕴无数阵法禁制以永恒保存药物，其内**仅有一粒丹药**。丹药无需吞服，触及王林双唇即化作两道乳白色之气钻入其鼻间。
- **放话天运子**：抬首盯着上方的天运子，双眼寒芒：「这天地间，除了我，谁也不能提前将你杀死。」

## 七、要点与悬念
- 王林三十三剑虽未杀死天运子，却做到了「破其衣发」，为空涅法宝之威所能及的极限。
- 木冰眉对王林的态度显然另有渊源（「除了我，谁也不能提前将你杀死」），其与昆虚之境老者的来意成为后续伏笔。
- 章末为作者求月票的爆发预告（非正文情节）。

> 归属说明：本章「司徒南」的言行归于【司徒南的断臂】（自第336章起自称司徒南，真司徒南第61章已死，真伪未定）；王林弥留幻象中的「李慕婉」「王林」为回忆/幻象，非本人行动。
