# 仙逆 第1103章 云海（第八卷 联盟隐秘）

## 一、天门宗三青年劫走巨蚊兽

- 地点：联盟星域中部一处充满碎石的星域。
- 人物：三名黄衣青年（天门宗弟子，其中受伤最重、手持燃香者名 **苏辛**），皆带伤——一人右腿见骨、苏辛右胸被穿透。
- 战果：以 **蚊魂香** 引走并驱使 **十九只巨蚊兽**；出联盟东部时巨蚊王突然挣扎、引发全体蚊兽反抗，三人消耗两根蚊魂香才勉强压制，**巨蚊王重伤逃脱**。
- 动机：巨蚊王幼体可在 **暗星宗** 换 **天衰液** 一瓶；巨蚊兽在云海星域价值极大（常数百上千群居，六阶以上宗派抓捕都需大费周折），十九只足以让三人在天门宗地位骤升。
- 判断：三人认定巨蚊王有人圈养，主人当为联盟星域的大神通者，须速与长老汇合。

## 二、天门宗碎石星域据点

- **青光外阵**：淡青色光罩笼罩，八阶宗派赠予天门宗；持玉简咬破舌尖喷血可开启圆形漩涡进入。
- 阵内：近百名黄衣修士牵引四周碎石、按规律添入 **碎石大阵**；两名 **紫衣老者**（白发、目光如电）在阵上方主持。
- 众修士见到巨蚊兽哗然失色，云海星域出身者对蚊兽有心理阴影。
- 二老决策：
  - 明知蚊兽必有强主，仍因巨利选择贪下；
  - 判断“即便碎涅大圆满修士，破青光阵也需数日”，可拖延至撤回云海星域；
  - 若对方追入云海星域，则“定叫他有来无回”；
  - 下令 **加速阵法组建**。
- 提及 **风之仙界** 蚊兽成千上万，令云海修士恐惧。

## 三、王林：压住天劫，怒而追讨

- 王林右手抚过重伤蚊兽头顶，眼中阴寒——熟识者可知其已入 **愤怒**。原则：“人不犯我，我不犯人”；蚊兽未招惹对方却被引诱夺走并重伤，触及底线。（另提：拓森因脱困后必与其不死不休，故王林才先行算计。）
- **天劫压制**：达到 **净涅** 一刻已感天劫之力。因身处 **朱雀圣宗**，天劫降临会重创宗门；且他不需他人相助，欲借天劫见证自身 **雷火之力** 强弱。故以朱雀圣宗第一神通 **九玄变** 自我封印，修为停在净涅边缘与天劫僵持——心念一动即真正达净涅、天劫立至。
- 原计划：走出朱雀圣宗，于 **联盟东部** 寻偏僻之地独抗天劫；蚊兽被劫后改变主意。
- 行动：将重伤蚊兽收入 **空间裂缝**，凭蚊兽记忆中的路线，以 **缩地成寸** 一步跨出——于 **联盟星域东部边缘** 星空中现出波及百丈的扭曲涟漪，白发白衣走出。
- 随后放出巨蚊王，喂食 **仙丹**（王林丹药皆为仙丹，效果甚佳），蚊兽伤口止血、精神稍复，嘶鸣择向引路寻同伴气息。
- 王林随行前进，速度过快引起音爆奔雷，身周幻化出 **无数微缩火山虚影**，怒火滔天。

## 四、伏笔与看点

- 天门宗与王林的正面冲突即将爆发，青光阵能否挡住“净涅边缘 + 天劫在顶”的王林是关键悬念。
- 王林的净涅天劫尚未落下，可能在此战中被主动引下。
- 云海星域、暗星宗、天门宗、天衰液等构成新的地理与势力线索。
