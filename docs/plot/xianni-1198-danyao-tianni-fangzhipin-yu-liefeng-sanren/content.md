# 第1198章 丹药（第九卷 云海之巅）

> 世界状态须知：本章行动主体为**王林**（自第1063章起以归元宗故人『吕子浩』之名行事）。司马墨已于第1114章死亡，本章仅以「遗留洞府／丹药主人」身份出现。

## 一、第一间洞府：仿造天逆的失败石珠

- 王林手中珠子的大小、轻重、气息与随他一生的**天逆**一模一样，唯一区别：表面**没有五行图案**，只有模糊印记闪烁。
- 结合此前玉简所载——这些石珠**非天然所化，而是被人祭炼**，彼此大小轻重毫无差别——王林判定：**很久很久之前，有人在此地以特殊神通不断制作石珠，试图仿造／祭炼出天逆**。
- 推论链：
  1. 能造得如此相似，此人**必定亲眼见过，甚至掌握过天逆**；
  2. 怀疑此人**即是掌尊**；
  3. 预感自己与**界外／掌尊**不久后必有交集；
  4. 忧虑：当年虚无中所遇的**界外老者并未死亡**，界外之民或已知晓他的存在。
- 十枚珠子内**均有法术波动，各自封印了一道神通**。王林判断它们是**失败品**（故被随意丢弃），失败珠不知何故反而可封印神通。他在珠上**留下自身烙印**，收入储物空间。

### 与苍松子、七彩天空的疑点串联
- 之前与**苍松子**一战，苍松子最终召唤出的**封界第七阵之灵**，与当年那位**界外之人极为相似**。
- 走出洞府时，岁月禁幕外的**七彩天空**，令王林想起当初在虚无中遭遇界外之人时，那界外的世界也曾出现**七彩之芒**。
- 结果：接触越多，王林对此地**清晰中迷茫更重**，心神如压大山，面色阴沉。

## 二、第二间洞府：丹炉与海量药材

- 一座**巨大丹炉**占据洞府大半，四周堆放大量药草（多已干枯），旁有数个储物袋。
- 打开储物袋后王林动容：**全是药材，数量之多无法想象**。岁月久远，地面积尘，丹炉一抹即留痕。

## 三、第三间洞府：破阵夺丹

### 阵法结构
- 山门有**禁制**（非岁月禁），王林掐诀幻化禁制逐一落于山石，将其推开。
- 洞内地面为**圆形阵法**，边缘以**元晶**供能维持运转；阵法上空悬浮**三个药瓶**，以元晶之力滋养。
- 元晶久未更换，多已废弃，仅勉强维持运转。
- 阵法蕴含**一丝岁月禁痕迹**，威力倍增；作用有二：
  1. 使其内丹药**停留在丹成一刻**，不受岁月洗涤；
  2. **防护**——强行开启则立刻毁灭其内丹药。

### 王林的解法（冒险，容错为零）
1. 盘膝推衍，不动余下洞府。
2. 取一枚元晶捏碎，操控爆发的元力融入地面。
3. 在阵外地面上造出**一丈大小的菱形阵法**，并分出一道**细线**与丹药阵法连接。
4. 右手直探阵中抓向药瓶——阵法爆强光、毁灭性气息将起，却被细线**引导涌入菱形阵法**。
5. 趁毁灭气息顿滞一瞬，抓走三个玉瓶后退出洞府。
- 事后王林心脏怦怦跳动，自知稍有差错三瓶丹药便会尽数化为乌有。判断：**司马墨与其同门如此存放，显然是极贵重之物**。

## 四、三瓶丹药

| 药瓶 | 内容 | 判定 | 依据 |
|---|---|---|---|
| 第一瓶 | 三粒赤色丹药，剧烈**兽魂波动**，吸引元神 | **十一阶丹药**（凭感觉辨认） | 兽魂波动强度 |
| 第二瓶 | 一黑一白两团雾气，各含一颗丹药 | **十二阶化雾凶兽炼制的雾魂丹** | 特点鲜明，一眼认出 |
| 第三瓶 | 神识可感、双耳不闻的**惊天咆哮**，远超十二阶凶兽 | **十三阶丹药** | 波动无法想象，王林瞬间封死药瓶，面色苍白 |

- **雾魂丹罕见之由**：很少有人肯放弃**化雾凶兽长久产出元晶**的利益，去把抓到的化雾凶兽拿来炼丹。
- 王林谨慎收起第二、第三瓶，仅留第一瓶前往丹炉洞府。

## 五、服丹门槛与二次炼丹

- **云海星域共识**：十一阶丹药**唯有修为到碎涅中期方可服下**；否则元神无法与丹内凶兽之魂对抗，只能**元神消散、吞丹而亡**。丹药可帮助提升**意境**，但需极为谨慎。
- **王林实际修为**：抛除古神肉身后，只是**净涅初期**，无法直接吞服 → 必须再次炼化。
- **二次炼丹**：云海星域修士需掌握的炼丹方法，核心是**把高阶丹药之力分散开来**；与丹炉关联极大，**丹炉越好，药效消散越少**。
- 操作：王林**左眼火光一闪**引出火焰融入巨大丹炉，丹炉一震、其上幻化印记缓缓运转；投入一粒十一阶丹药，右手虚空一拍，炉火暴增，持续炼化。

## 六、同时刻：七彩界深处的祭坛与界外三人

- 地点：七彩界**至深之处**，远远超过苍松子疗伤所在之地，雾气更为浓郁、遮天盖地。
- 雾中有一处**祭坛**；此刻祭坛之上光芒闪烁，光芒穿透雾气将其向外推开，露出一片空旷。
- 一道**丈余长的裂缝**无声无息出现于祭坛之上，边缘**无数电光游走**，渐渐撕裂越大——从中走出**三人**。
- 三人衣着明显与云海修士不同；更诡异的是**眉心均有清晰印记**：
  - 为首男子——眉心蕴含**一道闪电**；
  - 其身后青年——眉心有**月牙印记**；
  - 最后一人——眉心有**火焰图腾**。
- 月牙印记青年环顾四周，眼露兴奋，问：“这里就是你发现的空间裂缝？”

## 七、伏笔与看点

1. **天逆非独一无二**——有人曾批量祭炼仿制品，指向掌尊／界外势力与天逆的渊源。
2. **失败石珠可封印神通**——十枚已被王林打上烙印，是待用底牌。
3. **苍松子身份存疑**——其「封界第七阵之灵」与界外之人相似。
4. **十三阶丹药**成为已知最高阶战利品，暂不可动。
5. **祭坛空间裂缝**放入三名眉心带印记的外来者，为下阶段冲突开场。
