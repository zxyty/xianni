# 仙逆 第1864-1865章 金蝉脱壳 · 困许

## 一、罗盘监控与追杀格局（第1864章）

- 极天草原边缘，被数千修士环绕的**空劫初期女修**以虚幻罗盘监控战场，可见代表王林的光点。
- 王林光点连续三次瞬间消失并出现在极远处，女修判断：
  - 王林必有**可挪移的法宝**；
  - 此类法宝「整个宗门只有一件，绿魔洲不超过三件，天牛洲怕也绝不多」。
- 每次瞬移后，王林光点旁的**绿点（绿魔洲修士）成片消失**。女修将异变以特殊方式通报所有空劫修士。

## 二、吞噬疗伤

- 王林与**许德才**一战中被连续神通打击，体内伤势加重、面色苍白。
- 遂重新采用**洞府界的方式**：吞噬修士血肉元神疗伤。
- 连吞两组绿魔洲修士（其中一组十余人，雾气弥漫、惨叫后化回王林形），一炷香后第三组队伍亦全部死亡。
- 疗伤后面色略转红润。
- 结果：草原中心仅剩**两名空劫中期老怪 + 两名空劫初期修士**，两两成组、彼此不离地逼来。

## 三、金蝉脱壳（核心手段）

1. 王林已摸清罗盘的**内部结构与禁制**，自言材料足够即可自制。
2. 取出从三组追兵中精选、修为饱满且未受伤的一个元神，**抹去其意志**，只余迷茫元神体。
3. 左手一捏令元神崩溃，趁其未散**融入自己一丝神识**，打入罗盘。
4. 元神化白色烟丝缭绕罗盘，**燃耗自身**驱动罗盘以极快速度奔向天地尽头；元神耗尽后罗盘将坠落不知何处。
5. 罗盘虽已脱手，王林仍可借那丝神识**感知罗盘上四名追兵的方位**——由猎物变为猎人。
6. 王林另择一地盘膝，因拥有**火本源**，身下泥水自然干燥。
7. 一个时辰后，两名空劫中期老怪加速追赶罗盘，与落后的两名空劫初期修士**拉开距离**（分割阵型达成）。

## 四、空间石与杀场布置

- 王林体内藏一枚**空间石**，一直不明其用。因**幽冥兽吞噬对方天道**的一幕而悟出：石内存在无数独立空间，可与幽冥兽融合，**大范围增强其吞噬**。
- 王林首次**以肉身**进入空间石，选定其中一处空间：约数十万里大小，有山、有光、有大地，**唯独无水**，故「看似真实、实则不完整」。
- 布置清单：
  | 物 | 化作 |
  | --- | --- |
  | 蓝色伞 | 取代天空，化作天幕 |
  | 蕴含三千万道魂的葫芦 | 融入大地，散死亡气息 |
  | 玄罗所赠金印 | 吹以元神之气，万丈金光，化作金色太阳 |
  | 自制鬼帆 | 化作可变化万物的云层 |
  | 蚊王 | 缩小隐于一片白云内 |
  | 已司 | 融入大地，气息被三千万道魂的死气掩盖 |
- 本源补全（王林自语「这世界还缺少……」）：
  - **因果**本源 → 长剑；
  - **生死**、**真假**本源 → 两把长剑；
  - **杀戮**（煞气滔天，白云转乌云）与**禁制**（黑色雪花，每片含禁制本源，薄覆大地）；
  - **火**（左眼火海化剑，剑起成火山）、**雷**（右目雷霆化剑，剑动成雷海——「那海不是水，而是雷霆闪电」）、**水**。
- 布置完成后，王林出石取回空间石：**「杀场已成，接下来就是强行带人进入杀场之中」**。

## 五、诱饵终结与困许德才（第1865章）

- 王林边行边等，至**第十九息**：罗盘崩溃、其内元神死亡、自己那一丝神识随之毁灭；隐约听到**两声愤怒咆哮**（两名空劫中期老怪扑空）。王林随即身影消失。
- **许德才**处境：与王林一战损失天道，天道与其心神相连，被吞后带伤，元神萎靡、短期难复。其恨意因此而生，且已得**张长老**许诺——擒获王林后交他虐杀数日。
- 许德才途中察觉波动，回望见王林自虚无迈出、改向疾驰，神色一变加速欲以奇异方式遁走。许德才冷笑追击，神识扫过四周**未察觉任何陷阱端倪**。
- 追出约千丈的一瞬，许德才身影骤然消失，「好似撞在一处看不到的空间裂缝中」——实为被引入空间石杀场。
- 王林随即临近，同样消失；地面杂草与泥水中只余那块空间石。
- 草原边缘女修见罗盘上**代表许德才的光点骤然消失**，汗毛耸立、面色苍白、无法置信，立刻将此消息传给尚在极天草原内的**三个空劫修士**。

## 六、要点与伏笔

- 王林手段序列：诱饵（元神+罗盘）→ 分割阵型 → 空间石杀场 → 逐个拖入。
- 空间石与幽冥兽的融合增幅，是本段新解锁的关键认知。
- 王林明确觊觎那名「施展神通极为快速」的空劫修士的神通。
- 罗盘已可自制（结构与禁制被参透），后续可复现监控能力。
- 悬念：许德才入杀场后的下场；剩余三名空劫修士的应对。

# 第1865-1866章 极天草原·空间石内截杀许德才

## 一、外场：金蝉脱壳后的连锁反应

- **绿魔洲张姓、赵姓长老**追击罗盘后发觉上当，恼羞成怒却无从宣泄；飞行途中忽收绿魔洲特殊方式传来的信息：「许德才明明跟在后面，竟然失踪」。
- 赵姓长老断言：「定是那王林，他金蝉脱壳，用那罗盘吸引你我的注意，实际上隐藏在这草原内，算计了许德才」，眼露杀机。
- 另一名**空劫初期女修**（此前盘膝打坐操控罗盘者）在远处亦收到同一讯息，神色震惊。

## 二、极天草原第二战

- 黎明散去、阳光初显，但雨势不减反增。大地升起**黑色雾气**，转眼滔天，遮盖八方、缭绕整个极天草原，雾内散出无形威压。
- 雾中，**吕文冉**率**地宫**数千**天牛洲**修士发动第二次攻击；三名欲冲出雾气的空劫修士被拦，吕文冉阴沉道：「道友，何必着急离去」，地宫所有空劫修士齐出厮杀。
- 草原边缘的空劫初期女修睁眼起身，大袖一甩带数千绿魔洲修士化作数千长虹驰援。

## 三、杀场：空间石内的一处空间

草原某处杂草泥泞中，一块无人留意的**寻常石头**——内蕴无数空间的**空间石**。许德才被卷入王林指定的空间，入内刹那便知落入算计，却毫不慌乱。

**杀场地貌（皆为王林法宝/本源所化）**：

| 景象 | 实为 |
|---|---|
| 蓝色天幕 | 王林**蓝伞**所化，可防护亦可攻击 |
| 滚滚乌云 | 王林**鬼帆**所化 |
| 飘落黑雪（已积厚层） | 王林**禁制本源**所化，每片雪花蕴含诸多禁制 |
| 远处火焰山 | 火本源载体，内有王林本源真身 |
| 另一方向雷池之海 | 雷本源载体 |
| 大地（充满死亡气息） | 融有**三千万道魂** |

此空间不完整，本无水。

本片段王林形貌：**一头白发飘散，换穿白衣**，冷冷盯着许德才。

## 四、第一轮：抢速度的本源对决

许德才喝问后，王林现身数千丈外，道：「你的神通很快，那么在这里，就看看，我们到底谁更快一些」。

- **王林**：因果 → 生死 → 真假，三道虚之本源各化长剑。
- **许德才**：数百万印记化红雾幽魂（数百上千铺天盖地）→ 近七百万印记化长枪、扭曲成巨蟒 → 第三神通未及完成。

胜负关键在**真假本源之剑提前了一瞬**：因果之剑以斩断因果之力斩溃幽魂；生死之剑斩杀巨蟒后自身崩溃；真假之剑直取胸口，逼许德才以未完成的神通硬推格挡，双双崩溃，许德才面色苍白倒卷。

## 五、第二轮：火、雷、水三本源合击

王林抓住节奏被打断的机会连指：

1. **火本源**——火焰山轰然爆发并挪移，笼罩许德才全身，山内藏王林本源真身。
2. **雷本源**——连人带火焰山挪移入雷池，天雷轰鸣、雷海沸腾。
3. **水本源**——咬破舌尖喷血，以自身血液在无水空间中凝出水本源，红色水汽落下，火海崩溃、雷海爆起。

三源融合成毁灭之力，此前消散的三道虚之本源再化长剑冲杀——**生死、因果、真假、火、水、雷六道本源**齐聚。

**结果**：许德才喷血狼狈，全身弥漫**灯火之光**——其头顶飘着一个**灯笼**，以此宝护体，故只受伤而未死。

## 六、王林的判断

- 杀空劫修士之艰难早有体会，逃过一轮在意料之中。
- **许德才比刘之源更难杀**；绝不能给其任何缓冲，否则以其恐怖的施法速度，王林将毫无还手之力，「这杀场就不是为对方准备，而是为自己准备的了」。
- 目的不止杀人，更要**夺取其可如此快速展开神通的秘密**。

## 七、第三轮：定身术 + 禁制黑雪 + 鬼魂幻人

- **两次「定」字定身术**：王林修为逊于对方，强行定身需承受极大反噬，连番喷出鲜血，神色更为狰狞。效果仅一瞬，却足以打断施法节奏；首次连许德才头顶灯笼都随之黯淡（与其联系亦被定住）。许德才骇然：此神通可凝固其行动、心神乃至思维，「我从未见过这样的神通」，第二次被定时**眼中第一次露出恐惧**。
- **禁制本源黑雪**：天空飘落之雪与地面积雪被狂风尽数掀起，围困封杀许德才。
- **鬼帆·鬼魂幻人之术**：鬼帆是**大魂门最强之术**，重点在于可无视修为、扰乱心神。天空乌云尽数降临凝成一个**只有背影、嘤嘤哭泣的白衣女子**（实为鬼魂），其身影同时映入许德才心神，令其双眼迷茫。
- **三千万道魂**：地面道魂尽出，化黑气卷起被黑雪弥漫的许德才直冲蓝色天幕，如同流星。临近天幕刹那，王林低吼——「杀」。

## 八、悬念

片段止于「杀」字，许德才生死未决；外场极天草原第二次交战（地宫/天牛洲 vs 绿魔洲）正同时展开。

## 一、战局收束：第二轮神通齐射

- 天空蓝色崩溃、三千万道魂撕咬、黑雪倒卷，崩溃之力汇成毁灭性力量涌向最深处的许德才；同时许德才体内白衣女子的嘤嘤哭泣将其牵入一场梦幻。
- 王林清醒判断：空劫初期修士极难杀死，不容半点松懈。身后火本源真身幻化，连环施展：
  - **七彩之术**——七彩凝作两把长枪，后一把被火焰环绕，一前一后直射天幕内的许德才。
  - **役灵印**——巨大掌印加身后的火焰掌印，同时轰下。
  - **焚界古伞**——两把巨大火焰古伞同时收缩，释放双份灭世火焰。
  - **呼风唤雨 / 撒豆成兵 / 山崩地裂**。
  - **阴月有晴**——由当年白凡的仙术推衍而来，暗月之中还含一轮暗月，双月轰鸣。
- 结果：许德才喷血、右臂炸开、油尽灯枯，全靠头顶灯笼法宝保命，烛火飘摇几欲熄灭，眼中现出久违的死亡危机与滔天恐惧，嘶喊「只要给我一个机会」并连退两步。

## 二、第三轮必杀：三方合围

- 王林喷血施展**第三次定身术**，定住正要迈出第三步的许德才，随即展开最后一轮杀机。
- 三个方向同时凝聚：
  1. **已司**（失去一条手臂）自地底带滔天凶煞冲出，修为堪比空劫初期，一抓之下重创许德才，第二击直接将其肉身抓得四分五裂。
  2. **蚊兽（蚊王）**远处幻化全速冲来，巨大口器扫中许德才逃出的元神并猛吸，几乎将其吞噬，被灯笼散开的光芒逼退；该光芒亦令已司浑身黑气、剧痛却更凶。
  3. **王林本人**临近，右手血光闪烁，握**血剑**斩向许德才头顶。
- **关键一斩**：王林在空间石内毫无顾忌施展道古一族之力，身后浮现披甲的、似支撑天地的巨大道古虚影，气息沧桑；血剑从元神之上、灯笼之下横扫斩过，斩断二者联系——许德才元神喷出大口元神之气彻底萎靡，灯笼倒卷飞起、烛火熄灭。
- 许德才留下「我不甘心」的最后嘶吼，被王林大袖再施毁灭性打击后卷入储物空间。

## 三、战后：调息与清点

- 王林喷血落地盘膝调息；蚊王回旋护法三天；已司取回许德才肉身的一条断臂，目露迷茫，旋即身外雾气散出笼罩自身。
- 三天将尽王林睁眼，目露深深疲惫——连杀两名空劫初期修士消耗极大。
- 王林摄来许德才肉身头颅（双目无神、残留绝望与恐惧），收起与**刘之源**的头颅放在一处，自语：「两个了，还差八个」。

### 隐匿身份的顾忌
- 在**仙罡大陆**的仙族之地，王林对自身道古神通施展极为谨慎，因其根源属道古一脉而非仙人，怕被认出后寸步难行；唯在空间石内可无顾忌全力施为。

## 四、战利品一：灯笼法宝

- 王林喷元神之气炼化，灯笼重燃柔和烛火。以禁制本源之目通查，判定其为**纯防护之宝**：
  - 无任何攻击之力，防护极强；
  - 烛火不灭则元神不灭，且可温养元神，如吞噬丹药般使元神壮大；
  - 炼化入体守护元神旁时，柔和烛光弥漫肉身，无形中多出一层肉身防护。
- 王林张口一吸将其缩小吞入，沉于体内元神之旁，暖洋洋之感浮现，露出兴奋之色，断言「若非此物，许德才在第二轮杀局中怕就很难度过」。

## 五、战利品二：速神诀（搜魂所得）

- 许德才元神仅三寸大小、双目紧闭似昏迷。王林右手一握施展**搜魂**——修为相差太多本难施展，须先将对方重创方可无顾忌使用。
- 翻查其驳杂记忆历时**三个时辰**，终得根源，狂喜：
  - **速神决**：许德才早年奇遇，从一颗**天外降临的陨石**上发现刻着的一段复杂印决，据此修炼而拥有恐怖施法速度。
  - 神通走极端路线，核心为**在体内开辟九条神脉**，每多开一条，施法速度快上不少。
- 王林深有体会：那种施法速度下，对手只要给他一个机会，便可能被连续神通打得毫无还手之力；掌握此法则战力大增。

## 六、意外收获：许德才自生鬼魂

- 许德才元神本将消散，却于其上生出一丝诡异幽光，散发滔天怨气（死前不甘所化）；怨气浓郁后反而回落并稳定，元神不再崩溃，睁开双目。
- 与王林对望的一瞬，王林脑海轰鸣陷入迷茫，鬼魂趁机疾遁。
- 王林修炼**多重幻术**，深知人或凶兽死后自行诞生鬼魂与修为无关、极为罕见；用**大魂门**手法所得鬼魂品质低，至多制成**中品鬼帆**。自生鬼魂对修炼多重幻术者是极大造化。
- 区区鬼魂逃不出王林抓捕，片刻即被擒回、死死抓在手中挣扎尖叫，收入储物空间「此物，对他有大用」。

## 七、后续动向

- 王林静心研究许德才记忆中的速神诀，目标为开辟九条神脉、提升施法速度。
- 猎杀名单尚余八名空劫初期修士。

# 第1867-1868章 速神决·神脉与张道宗追杀

## 一、速神决与神脉之理

- **许德才** 修炼至今已拥有 **七条神脉**。
- **神脉** 是《速神决》的说法，实质：以【封印修士元神】为代价，在体内构建一个加速循环的漩涡，使施法速度倍增。
- 封印的修士越多、修为越高，漩涡转动越快，施展神通时速度对应暴增。
- 王林参悟时的关键联想：「封印一个修士的元神在身体内，形成漩涡，此术怎么感觉与古族之修的某些神通很是相似」——他越看越清晰，判断此术**绝非只能用于施法**，若以**古族之修的身体**施展，威力更为恐怖。
- 当下限制：王林「没有多余的元神」，故先将口诀记于心中，感悟透彻后再行修炼。

## 二、战利收拢与撤离残破空间

王林在许德才处所得/收走：

| 物 | 状态 |
|---|---|
| 葫芦（内含三千万道魂） | 尚剩一大半，死亡不多 |
| 天空的蓝伞 | 收走 |
| 蚊王 | 收入储物空间 |
| 已司 | 被雾气笼罩、融合许德才手臂，似要恢复双臂健全，收入储物空间 |

随后王林眼露寒光：「是该回去的时候了」，身影消失于残破空间。

## 三、极天草原战况（数日后）

- 雾气翻滚、厮杀连天；越到后期存活者修为越高、越难杀死，厮杀漫长。
- 第二次厮杀规模小于第一次，波及**不到数百里**。
- 双方原本六七千修士，如今**只剩不到四千人**。
- 雾气深处：**张姓老者 + 赵姓老者**（绿魔洲空劫中期）共战 **吕文冉** 及数个空劫初期修士的联手围杀。
- 不远处：绿魔洲仅剩的两名空劫初期女修，对阵 **炎栾** 与大魂门长老 **许东德**。
- 绿魔洲连折两名空劫初期大尊后实力骤减，张、赵二人压力倍增，已极为狼狈、隐有不支之相。

## 四、王林返场：空间石之戒

- 距战场数万里的草原上，一块**空间石**幽光闪动，王林身影幻化而出。
- 天空昏暗雾锁，数日前的雨仍未停，只是小了不少，与雾气融合，潮湿一片。
- **关键判断**：「空间石在进入后，会落在原地，这样的话，实际上是很危险的，若非到万不得已，还是不要再使用的好。」
- 王林收起空间石，一步踏出，出现在距战场不足千里处。

## 五、心态与立场

- 王林对这种大规模厮杀已**厌倦**，不愿多参与：「这里，他没有归属感，也没有为之喊出『我辈修士，何惜一战』的热血。」
- 其所为只为：**完成青牛老祖交代的三个条件**、**回报大魂门的三样礼物**——「这是王林的性格，他重恩」。
- 现实盘算：眼下不宜与空劫修士正面交手，但若遇重伤的空劫修士，或可捡便宜；战场亦是「抓获元神、封印修炼速神决」的途径。

## 六、救苍发老者

- 王林在雾中见一天牛洲**苍发老者**被绿魔洲**空玄中期**老者追杀，面色惨白、嘴角溢血却神色坚定。
- 苍发老者已看淡生死，决意**自爆**作为身为天牛洲修士为家乡所做的最后一件事：「老夫生在天牛洲，一身修为是天牛洲的天与地，灵与物造就，如今便还给天牛洲，了无牵挂。」
- 自爆刹那，**白发白衣**的王林无声出现，随手一挥即震碎两尊巨大虚幻魔影。
- 绿魔洲修士骇然判断对方「最弱也是**玄劫**修士」，转身欲逃；王林一步跨出数千丈拦于其前，一掌如泰山压顶按其天灵。
- 该修士全身崩溃、血肉模糊，元神被生生抽出，王林掐诀打上大量印记后按入自己胸口——**体内多出一个漩涡，即第一条神脉的雏形**。
- 苍发老者曾在**地宫**见过王林，认出他是「那位大魂门的长老」；且对其白发白衣与冰冷气息生出**似曾相识**之感。

## 七、第一条神脉：九人上限

- 王林一路游走雾中，凡见**空玄**修为者立即轰杀、取元神封印体内，巩固第一条神脉。
- 至接近空劫修士战场边缘时，已封印 **九人**；此后再无法封印，也无法形成第二条神脉。
- 规律（速神决有载 + 王林自身明悟）：
  - 要形成第二道神脉，**必须封印修为更高的元神**。
  - 或如许德才那样**从空涅修士开始封印**，但威力会大减。
  - **对比**：王林以空玄修士封印而成的**一个漩涡**，胜过许德才当年的**四个漩涡**。
- 结论：「玄劫修士应可以使我体内出现第二条神脉，只是这战场中，玄劫修士很少。」

## 八、张道宗现身（第1868章）

- 王林观察发现：场中空劫修士一时半会难有重伤者；几个绿魔洲修士**疑似服用了某种丹药**，似可隐隐对抗雾气同时提升战力。
- 王林遂决定「索性先去寻找玄劫修士」，正欲悄然后退时神色骤变，全速前冲不到三丈，一道**绿芒**击中其原位，大地震动、雾气都现崩溃迹象，冲击将其推出老远——若非察觉及时，足以将其重伤。
- 王林被一股神念锁定，脚下起波纹欲融入天地，却被一声「定」封住天地，无法遁走。
- 王林判定对方为**空劫中期老怪**，遂放弃遁法，甩袖唤出**蚊兽**驮身疾驰。
- 追者正是此前与吕文冉等交战的**张姓老者**，此刻不顾战局追来，自报名号：
  > 「老夫**张道宗**等了你数日，终于把你这小狐狸等了出来，你杀了**刘之源**，便要去平息宗主的怒火。」
- 王林一言不发，借蚊兽速度刹那飞出万丈；张道宗更快，**距离缩至不足百丈**。

## 九、悬念/后续看点

1. 王林被空劫中期的张道宗贴身追杀，蚊兽速度不足以拉开距离。
2. 王林尚需玄劫修士元神以开辟第二条神脉——张道宗本身即是「高阶元神」的潜在来源。
3. 速神决用于「古族之修身体」的推测尚未验证。
4. 已司融合许德才手臂、似要恢复双臂健全，后续变化未明。
5. 青牛老祖的三个条件尚未完成。
