# 仙逆 第1442章 疗伤的契机！（第九卷 云海之巅）

## 一、局面：数千人形凶兽围杀二十五人
- 雾气之中，数千人形凶兽尖啸冲出，神色狰狞、速度极快，气势轰然临近。
- 王林一方仅二十五人，如沧海一粟。
- 凶兽修为不等：**最高近天人第三衰，最低亦有碎涅圆满**。单独不足为惧，但数千弥漫加之诡异速度，颇为难缠。
- 在场修士皆非弱者，纷纷展开神通法宝迎击。

## 二、凶兽的核心机制：自爆 vs. 生机
### 自爆
- 凶兽死亡瞬间身体红光急闪，即便肉身被绞碎仍爆发毁天之力自爆。
- 自爆威力为自身修为数倍不止；**数十头同时自爆 ≈ 天人第五衰修士全力一击**。
- 连锁效应：一波自爆的冲击会波及第二波凶兽，层层跌宕形成风暴。
- 已有数名修士被自爆波及、喷血后退，随即被凶兽围住二次自爆生生毁灭。

### 生机（本章题眼「疗伤的契机」）
- 并非所有凶兽都来得及自爆；**凡在自爆前被杀者，会有一股白气入体**。
- 该白气**不是古神之力，而是一股生机**。
- 生机被元神吸收后立刻转化为疗伤之力，**比吞噬修士疗伤还要快**；旁观修士判断其「不但可疗伤，更可凭添修为，相当于吐纳打坐数日」。

## 三、王林的应对与行动
1. **剑之风暴**：右手抬起，千万剑气于指尖呼啸，一扫化作剑之风暴横扫天地，将冲来凶兽尽数卷入绞杀。
2. **白光光影反射**：自爆冲击袭来时，身外生出无尽白光化作万丈巨大光影笼罩其身，不破反亮，将全部毁灭之力尽数反射八方。光芒亦掩住了他眼中一闪的神色。
3. **抢杀吸生机**：察觉生机之利后，第一个冲出杀入兽群；以千万剑气撕开凶兽肉身、冲入体内，在自爆前直接轰杀，白气尽收。
4. **顺手救人**：闪身至一群围人凶兽外，双指成剑点杀数十头，救下已绝望的修士，但转身即走、并未理会感激目光。
5. **天皇炉收千兽**：众修士看破玄机、二十多道长虹争抢最后近千凶兽时，王林眉心**古神星点第一颗星**中射出幽光，双手掐诀祭出**天皇炉**，虚幻巨炉笼罩全场、沧桑气息如惊天漩涡；一字低吼「**炼**」，近千凶兽未及自爆便凄厉惨叫、炉内一片浑浊、古神气息充斥，转眼巨炉缩小化幽光没入眉心，**半个不留**。

## 四、其余人物表现
- **白衣女子**：全场最轻松，不施神通，凶兽一近身即全身冒黑气、七窍流血惨叫而退；事后目露赞赏，向王林点头示意（全场唯一善意者）。
- **封灭族少女**：始终不敢离开平台；见众人对峙欲寻良机上前，被王林冷漠目光一扫，面色苍白、脚步生生停住。
- **持酒壶中年修士**：左手酒壶右手剑，仰天长笑迎战上百凶兽，尚未出手即被王林抢杀大半，皱眉嘀咕后率先看出生机端倪。
- **其余二十余修士**：抢食不成，目光不善但顾忌王林修为，无人先出手，各自返回平台，暂时略过此事。

## 五、结果与走向
- 王林独吞近千凶兽，天皇炉内磅礴生机持续冲入体内，**伤势以极快速度恢复**。
- 王林心中定下：「这人形凶兽对我疗伤有大用，谁也不能与我抢。」
- 短暂停顿后，二十多个平台轰然震动，急速冲入前方雾气消失不见（试炼继续推进）。
- 章末伏笔：王林暗道「**该立威了**」，左目内虚幻火苗微不可查地燃烧、渐渐旺盛。

## 六、要点提炼
- 本章确立了王林在此段试炼中的核心资源逻辑：**抢在自爆之前击杀凶兽 = 疗伤 + 增修为**。
- 天皇炉首次在本段试炼中作为「批量收取」手段公开亮相，直接把资源之争转为实力碾压，也为下一步「立威」埋线。
- 王林与同组二十余人的关系由「同组同行」转为**紧张对立**，唯白衣女子例外。
