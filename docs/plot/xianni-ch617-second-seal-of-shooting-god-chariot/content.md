# 第617章 第二道封印

## 一、妖灵之地的诡异与疑云
王林在妖灵之地滞留越久，越觉此地处处透着诡异，已累积三处异象：
- 黄龙的画像
- 两个一模一样的墨非
- 与凌天候极为相似的大汉

他喃喃推断：天运子奉行天运，执意要求自己进入此地，怕是另有目的。并回想当初在天运星时白薇的提点——**天运子所有修行超过万年的弟子，绝大部分都已消失**，遂怀疑那些师兄的失踪是否与妖灵之地有关。

王林摸储物袋，眼露寒芒，定心道：只要自身实力足够，此地再诡异也无法动摇其道心。

## 二、十年闭关的三条主线

### 1. 散魔之魂烙印
王林阖目，以元神在体内散魔之魂上继续加深烙印刻画，不断将烙印向散魔之魂深处缓缓凝固。

### 2. 禁幡与尊魂幡
- 十年内不断推衍打出禁制融入**禁幡**，**九千九百九十九组禁制**已慢慢临近（完成）。
- **十亿尊魂幡**早被散开，其内**一亿魂魄**化作黑云笼罩炼魂部落上空，魂啸不绝，成为部落一道特殊标志。

### 3. 炼魂部落的壮大
- 族人日增，越来越多人修炼**炼魂术**。
- 此地为**远古战场**，魂魄极多但绝大部分深藏地底；部落迁来后挖掘深坑，**在地底修炼**成为独特修行方式。
- 另一有效途径：赴**火妖郡**吸收死去妖兵之魂，仅限修行略有成效者，且须**欧阳华亲自考核**后决定去否。
- 部落如茧中吸取养分的幼蝶，终有一日破茧而出、震撼九郡。
- 中心十里空白界内的**离塔**被奉为圣地；塔中十年未出的王林被全族视为**老祖与守护者**。

## 三、射神车的五道封印

| 项 | 内容 |
|---|---|
| 来历 | 仙界之物，制作者称其为「至强之器」，赐名『射神』 |
| 封印总数 | 五道 |
| 婴变中期时 | 勉强可开第一道 |
| 问鼎修为时 | 开第一道游刃有余 |
| 第一道效果 | 可威胁**婴变后期大圆满**修士 |
| 第二道推断 | 封的是**魂兽雷**的力量；神识一扫即引出雷光反追，王林动用仙力数息才磨碎 |

王林对制作者的狂言「绝对是至强之器」，以数百年了解论，即便不全信也信了三分。

**兴趣来源**：当年魔塔下那位**问鼎后期老者**施展的风雨雷电神通极强，其中最强者为**黑雷**——若无此雷，威力削弱大半。故魂兽若拥有雷系之力，第二道封印价值巨大。

## 四、关键抉择：舍弃驱兽圈

**驱兽圈来历**：当年在**古神之地**内，**拓森**麾下上古修士为让王林协助而赠送。数百年来（尤其配合射神车）帮助极大，使王林修为不够时也能驱使射神车。

**外形**：古朴铜圈，遍布符文与上古凶兽雕画，其上有几道细微裂痕——当初魂兽反噬时留下。

**困境**：随修为提升与封印陆续解开，驱兽圈再也无法限制魂兽；一旦开启第二道封印，驱兽圈**定会崩溃**。

**决定**：王林眼中犹豫转为果断——不再依赖外物，须以自身之力**真正降伏魂兽**，按射神车制作者留下的方法进行**完完全全的传承**，否则此宝将不能再用。

## 五、万里平原上的镇压
1. 王林抓过驱兽圈，站起向前一迈，人即消失于塔中，现身于**距炼魂部落万里之外**的空旷平原。
2. 抛出驱兽圈，双手掐诀向前一指，铜圈散发乌芒，砰的一声化作**射神车**落地。
3. 充满狰狞利刺的射神车其上散发浓光，**魂兽**幻化而出——百丈大小，堪比一座小山，通红双眼死死盯住王林，发出不屈咆哮。
4. 魂兽如小山撞来，撕裂破空之声紧随。
5. 王林神色如常，抬右手随意向前一拍：仿若大手自天而降，轰隆巨响中将魂兽庞大身躯**死死按在地上**。

## 六、伏笔与待解
- 天运子的真实目的、其万年弟子集体失踪之谜，是否与妖灵之地相关。
- 黄龙画像 / 双墨非 / 类凌天候大汉三重异象未解。
- 第二道封印尚未正式开启，降伏魂兽与「完全传承」的过程仍在进行中。
- 禁幡九千九百九十九组禁制尚未最终完成。

## 一、炼化魂兽：血符与封印（射神车认主进程）

- **压制**：尘土环形散开、地面一震，魂兽抬头咆哮、眼露挣扎与不屈，死死盯住王林。王林以右手虚空捏住此兽使其无法挣脱。他自忖：当年面对**初始状态**的魂兽时根本无法抗衡，如今已可压制。
- **血符来历**：王林咬破舌尖，当空划出红色血符。此符文乃**当年制作射神车的仙人所留**，共**七道**；七道全部落下后，射神车才**真正认主**。其中**两道须在第四封印打开后**方可印下。
- **第一道血符**：血符化血光落于魂兽眉心，魂兽剧痛巨吼、疯狂挣扎。王林随即松手放其自由，此兽怒视王林，不屈更浓。
- **开第一道封印**：王林双手掐诀，乌光闪于印诀，喝道「**第一道封印，开**」。乌光落身，魂兽全身咔咋作响，庞大气息自体内涌现。
- **交锋**：魂兽拔地而起、血口噬来，王林抬右手一扇，狂风化掌击碎其大嘴；魂兽后退中化作无数黑芒四散，再疯狂扑向王林。
- **元神出窍**：王林双手虚划出两道血符；黑芒尽数自其皮肤钻入体内、直奔元神。王林冷笑，低喝「**元神，出窍**」，天灵处元神飞出，手中死死掐住魂兽脖子一并带出；两道血符飞来，被元神左手抓住，连续按在魂兽额头。
- **反噬**：魂兽身震，更强气息疯狂冲出，**竟震开了王林的神识**。王林神识入体、睁眼看向此兽。（本段合计已落三道血符）

## 二、白色城堡：老祖锁定王林

- **地点**：距王林所在无数里外，**火妖郡与金妖郡边界**的一大片山脉，常年瘴气笼罩，属两郡**均不管辖**之地；瘴气深处有一座**白色城堡**，四周以十丈高白色山石围绕，气息神秘。
- **禀报**：一道黑影飞入、半空单膝跪地，向「老祖」禀报：已查明**二十年前在古妖郡都城失踪的王林**所在之位。
- **情报缺口**：老祖问其修为，黑影称未查到——因**当初天妖郡内抓捕此人的小队全军覆灭**，无任何消息传出；但得知**王林现被任命为古妖使者**。
- **决策**：老祖大笑「老夫看中之人，果然非比寻常」，下令**派三个小队再带一个仙卫**前去，将王林**生擒**。
- **动机与判断**：城堡内一名**身材极为矮小的老者**自语：这王林若调教好了，又可为其**增加一个仙卫**；此人**即便修为再高，只要未达问鼎，仙卫足以擒拿**。

## 三、要点与伏笔

1. 射神车认主是一条分阶段的长线：七道血符 + 至少四道封印，进度受封印开启节奏限制。
2. 魂兽随封印开启而战力递增，已能震开王林神识，后续封印风险更高。
3. 王林「古妖使者」的公开身份已被外部势力掌握，成为被追踪的线索。
4. 白色城堡老祖以「仙卫」为核心力量，且对未达问鼎者有把握——间接标定了仙卫的战力档位在问鼎之下、问鼎之上则难制。
5. 天妖郡抓捕小队全军覆灭一事，成为王林修为的「信息黑洞」，使敌方低估其实力。
