# 第1458章 假设

## 一、枯林之下的凶兽（战斗）

- 王林先前查看枯萎树木，即察觉这片森林下方埋葬着一个巨大头颅，整片森林就长在头颅之上；神识扫过时引起该处之物攻击，遂先发制人。
- **血剑**呼啸落地，大地裂开紫光，一条数百丈长、无头、首端仅有一道裂缝的紫色蟒状凶兽冲出，喷紫色毒水；血剑穿透毒水并贯穿其身。
- 王林掐诀化出**巨大掌印**轰落地面，反震之力传入地底，地表崩塌形成天坑，露出一片灰白色头骨的**右目部分**。
- 右目窟窿内有四条交错的紫色蟒状凶兽，实为头颅内部一个**巨大肉瘤**的触手。此物与**望月**极像，恶臭弥漫，但体内**没有任何古神气息**，实力远弱于望月——王林曾一度疑其为变异望月。
- 王林**左眼九色火焰**燃烧，化火焰风暴笼罩四条须子，火焰顺须钻入头颅烧其本体；肉瘤缩小化紫光欲逃。
- 王林**右目雷图**一闪，整片天空化作巨大雷霆漩涡降临，三息后雷图尽落，肉瘤轰然崩溃、半点不留。

> 实力锚点：以王林此刻修为，即便当年罗天星域的**望月**他都有资格一战；连第三步**灵动**都已成为他的**古奴子**。

## 二、九星古神头颅

- 王林挥手抹去泥土，庞大森林近半消散，露出一颗**不知埋藏多少年的巨大头颅**（现出的仅是一半）。
- 头骨眉心有**九个星点烙印**，第九个星略有模糊 → **九星古神**。这是王林一生中第一次见到九星古神的尸骸。
- 王林一眼看出：**此前放置七彩雕像的位置，正是这头骨的「人中」部分**——以一点制约整个头颅，雕像的存在目的就是**封印这九星古神之头**。
- 头骨内古神气息几乎殆尽，尽数流逝于岁月。王林抚摸星点烙印，隐隐看到当年一幕：一尊战天的庞大古神，被一名**身穿七彩的修士**斩杀砍头，以雕像封印于此；岁月尘埃覆盖成大地，其上生出树木成林。
- 王林身为古神，进入古墓后见过诸多古神头颅，此刻再见九星古神之头，心神翻涌悲哀。
- **疑点**：九星古神之强无法想象，身躯庞大无比，头颅决不该只有这么大——除非其压制真身缩小，亦或另有隐情。王林由右目窟窿钻入颅内，许久后走出，手中多了一块**巴掌大小的骨头碎片**。
- **判断**：古神一生共**七劫**，这尊九星古神是在**渡第二劫**之时被人斩杀。

## 三、王林的核心假设（本章题眼）

### 起点：道灵中的那句话
> 「以道灵饲养天道确不是件易事，还需想一个别的法子，让这被我抢来的天道快速成长起来。」

- 由字面可知：天道是**七彩道人抢来之物**；从何处抢、从何人手中抢，王林无从知晓。
- 王林分析的重点落在「**需想一个别的法子**」——而他低头看向身下的九星古神头骨，心中浮现出一个极大胆的猜测。

### 假设主干

> **七彩道人 = 远古仙皇**：此人当年在得到**天逆罗盘**之前抢到了一个天道，因某种原因需饲养天道，又觉得以道灵饲养很难，故而**设局**（即造出这座古之墓地／以古神头颅为局）。

### 支撑线索

1. **一代朱雀之言**：其所在世界有古神存在；古神尽管非尊，但就算是那个世界的尊者，古神也可悍然对抗。一代朱雀提到一个名字——「**道古晔寞**」。
   - 王林之问：为什么不叫「古神晔寞」「古妖晔寞」「古魔晔寞」，而称「**道古**」？是否可推算出晔寞并非神／妖／魔，而是「**古**」。
2. **古妖塔伽之言**（王林当年在妖灵之地渡问鼎天劫时初见）：「**古**」为**第一代逆修、战天道而亡**，此后繁衍一族，为**第二代战天道之修**。
3. **天道使者**：
   - 婉儿（李慕婉）寿元断绝前出现的天道使者，分明就是**被封印的古神**；
   - 闪雷族中再次出现的天道使者，被王林**断去一臂**，其临走前看出王林是古神，称他为「**叛空灭道**一族」。

### 推论与未解之处

- **推论**：都说天道已死，天道使者却称王林为「灭道一族」——答案呼之欲出。但「**叛空**」的「空」是谁？王林怀疑：**「空」= 七彩道人 = 远古仙皇 = 一代朱雀的主子「仙尊」**。
- **说不通之处**（王林自陈）：
  - 天道使者为何会是古神？
  - 既然天道已死，那么天道**到底是什么**——不是问它的形体，而是问它的「存在」与这片星空有何关联？
  - 更迷茫的一问：**修道修道，莫非我等修士所修，就是这不知是否真的死亡的天道？**

## 四、悬念

- 古之墓地到底是什么地方？是谁制造？目的为何？王林至今摸索不清。
- 骨头碎片的用途未在本章揭示。
- 「空」的身份、天道的本质、古神与天道使者的关系，均留待后续。
