# 第1903章 弱！

## 一、玄劫设定（空玄 → 空劫的关口）

- **定位**：玄劫是「空玄」与「空劫」之间的一次蜕变，与天劫不同——不以雷为形态降临，而是以特殊方式落在修士身上，形成一次次的崩溃。度不过则形神俱灭。
- **次数与分类**：共九次。绿魔洲修士议论时点明：**前三次为外劫，中三次为内劫，最后三次为魂劫**。
- **造化（连续度过的收益）**：
  - 连续三次 → 元神暴增一倍；
  - 连续六次 → 元神暴增两倍；
  - 连续九次 → 元神增加数倍（具体不详）。
  - 古往今来只有两人连续度过九次，二人**日后皆成大天尊**；传闻其度完后纷纷重伤、闭关很久。
  - 寻常修士若能连续度过六次，可立刻成为**空劫初期中的强者**，抛开法宝也能与**空劫中期巅峰**一战不落下风。
- **常规做法**：绝大部分修士分开去度，往往耗数千年才慢慢度过九次；自觉不妙便强行断开，不去求那造化。分开度与连续度「完全不一样」。
- **凶险**：外人无法帮助，全靠自己；一旦踏入玄劫，时间一到，即便不想度，玄劫也会在想象不到的时刻突然降临，成为死亡的召唤。
- **死亡概率（仙罡大陆的粗略推算，非精确）**：第一劫约一成死亡机会，逐次递增，第九劫有九成死亡可能。能连续尽度者，除修为强悍外，运气亦占相当比重。
- **例证**：
  - **蓝梦道尊**当年停在空玄巅峰很久，始终不曾踏入玄劫；
  - **杜青**已分开度过数次，且越来越艰难，很可能一生止步——但因有准备时间，总比一次性连续度过容易。

## 二、王林引劫：蝎庙蝎尾之上

- 王林自蝎子建筑深处一步迈出，现身于蝎子庙宇之上，踏在弯起指天的**蝎尾**部，一头白发飘动，仰望天空等待玄劫。
- 自语期待：「玄劫，会是什么样的方式到来，我很期待」——他有面对一切玄劫的自信。
- 体内修为疾转，散出**空玄圆满巅峰**气息，凝聚后自体内轰出，化作环绕四周的风暴直冲天空，与天似连成一体，形成惊天风暴。
- **威压**：以王林为中心横扫，先笼罩方圆数百里，转眼扩至数千里；范围内一切生灵被迫后退，不得踏入半步——这是玄劫的规矩：有人度劫，四周不会有人，也无法相助。

## 三、旁观者：十余名绿魔洲修士的误判

- 威压逼近蝎庙边缘远处，惊动了十多个前来观「**绿魔复活**」的绿魔洲修士，齐齐后退。
- 他们不必动神识便知有人在度玄劫，却在此地遇见玄劫而困惑，猜测：
  - 「莫非是绿魔大人复活后，修为跌落，故而要重新经历玄劫恢复」；
  - 「绿魔大人当年能被**仙祖**亲自镇压，修为定然极为强悍，只不过被镇压太久，修为或许真的跌落了不少」。
- 神识无法深入威压，看不到其内究竟——王林的身份因此被误认为「绿魔大人」。

## 四、第一劫：雪劫

- 天空飘落大片白雪，很快占据整个天地，寒气弥漫，地面盖满一层。
- 数千里外的绿魔洲修士目睹后点评：「这玄劫第一劫，竟然是**雪劫**，此劫并不多见」，并借此说出「三外劫、三内劫、三魂劫」的划分，静观「绿魔大人」如何应对。
- 王林如赏雪般静观不动。忽然天地间的雪齐齐一顿、如时间静止，随即化作无数**锋利雪刃**，自四面八方呼啸扑向王林。
- **应对**：王林摇头露出失望，右手一挥——体内**五行真身**一散，自其身中一步走出。
- 王林索性坐在巨大蝎尾上，白发垂下，翻手取出酒壶（自**天牛洲**带来、内装凡间烈酒），仰头喝下一大口。其孤独、萧瑟、冷漠的身影，隐隐与远在仙罡大陆之外某片废墟中、曾坐在半截石像上的黑衣男子相似。
- **五行真身出手**：全身散出滔天火海，爆发化作**九十九条炎龙**咆哮冲出，与雪花相撞，热浪滔天、白气弥漫；雪花尽融之刻，九十九条炎龙凝聚成一条**万丈火龙**，如利剑冲入天幕焚烧天空——**雪劫直接崩溃**。
- 评语：王林喝酒摇头喃喃：「**太弱**」。

## 五、第二劫：九道飓风

- 天空燃烧后剧烈晃动，狂风呜咽中现出**九道惊天风暴（飓风）**，横扫天幕，令火海扩散，天空只剩此九风。
- 九道飓风散发极强天地之力，风中呜咽如同天怒，成为数千里内唯一声响，随后携疯狂撕扯之力直扑王林，欲将其生生撕裂。
- **五行真身没有动**，冷冷站在王林身后旁观。
- 第一道飓风笼罩王林之身，疯狂转动撕扯、天地轰鸣；王林仍坐在蝎尾饮酒，衣衫吹打、白发飘舞，神色丝毫不变。
- 第二至第九道飓风接连轰来，一一融入王林身体之外；九风合一，形成笼罩大半个蝎庙、与天地相连的风暴。
- 至此王林才抬起头，评：「**还是太弱**」。

## 六、要点提炼

1. 本章是**玄劫体系的设定章**，首次系统给出九劫结构、连续度劫的元神收益阶梯、逐劫递增的死亡率与「大天尊」典故。
2. 王林选择的是**连续度劫**路线（前两劫之间无间断），起点境界为空玄圆满巅峰，目标直指空劫。
3. 王林前两劫近乎「不设防」：雪劫交给五行真身，飓风劫连五行真身都不出手，纯以肉身承受，连饮酒姿态都未变。
4. 身份遮蔽：外界（绿魔洲修士）将度劫者误认为复活的「绿魔大人」，王林的真实身份未暴露。
