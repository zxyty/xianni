# 第1199章 闻道（第九卷 云海之巅）

## 一、苍松子重聚肉身

- 三个奇异之人进入七彩界之际，盘坐于石像头部的**苍松子**将环身七彩雾气收拢，彻底包裹元神。
- 石像内钻出**白色闪电**，融入七彩雾气并与其元神结合，苍松子身体渐次凝实，**重新凝聚出肉身**：肉身散发七彩之芒、电光闪烁，眉心浮现若隐若现的**闪电痕迹**。
- 睁眼即露阴沉，放言「逼的老夫不得不走出这一步，此仇老夫若不报，誓不为人」，化作闪电穿雾直奔山脉。

## 二、召「逆行者」定位王林

- 苍松子判断：被其**七彩钉**所伤的「这姓吕的」（即化名**吕子浩**的王林）即便未死，也当处弥留之际，只是不知藏身何处。
- 虚空一抓开启**储物裂缝**，取出一枚珠子；咬破舌尖喷血于珠上，喝道「**召，逆行者**」。珠子吸收天地七彩之芒后崩溃，一股浩荡之威中显出**虚幻之影**——看不清相貌，唯双目清明，对望如身上隐秘尽被知晓。
- 苍松子问「他在哪」。逆行者闭目良久后睁眼，一幅画面被硬生生挤入苍松子脑海：**司马墨的洞府**。苍松子讶异其重伤之下仍破开该洞府禁制，寒光一闪直奔而去。

## 三、王林封谷养蚊兽

王林并未把全部精力放在炼丹上：

1. 清理司马墨洞府中的**第一个洞府**，其内完整布置大量禁制并扩大洞府范围。
2. 打开储物空间放出**蚊兽**。紫蚊王模样更为狰狞，与王林心神相通、已知其计划，坚定嘶鸣一声后被王林一挥卷入禁制之内。
3. 投入资源：云海星域一路所获的**大量兽魂** + 莫罗大陆养成的**变异兽魂** + **数万元晶**（落在禁制上），把此地封死。
4. 计划说明：以**五毒门炼化变异兽魂之法**强行提升蚊兽实力，使其蜕变为更强的**蚊兽之王**，唯有如此才可操控**风之仙界**内的大量蚊兽。王林断言「有足够的元晶，它不会有事」。
5. 神识观测：紫蚊带暴虐之气冲向一头头兽魂厮杀吞噬；元晶经禁制阵法运转化作浓浓元力融入蚊兽体内。王林留一道神识时刻关注。

## 四、炼丹与闻道印证

### 成丹
- 王林于丹炉旁盘膝，操控火焰炼化丹药，历时**两天**；火焰消散、药香弥漫，掀开炉盖后现出**一滩金色液体**，被收入**三个小瓶**。

### 印证之法
- 饮下药液，清凉运转全身，耳边似有兽吼咆哮；王林闭目吐纳，感悟**丹药中兽魂对天地的明悟**，心神弥漫于追寻天地规则之中，仿佛化身凶兽历经种种生存挣扎。
- **关键取舍**：他本可随意选取一种凶兽的感悟以提升修为，但意境非自身所悟，会致**道心混乱**，这样的修为王林不要。
- 他要的是在兽魂明悟中**不断印证自身真假**，于真与假中感悟天道；他取的是凶兽魂内**那一丝感悟天地所生的思绪**（凶兽魂之精髓，蕴含越多越促其突破等阶、最终化作人形）。
- 悟语：「**无假不显真，无真何来假。真与假，其实没有必要完全的区分开来**」（饮第二瓶时）。

### 道念外溢
- 被分离放弃的**驳杂道念**在体外越积越多，山谷环境出现扭曲并加速，一切变得不真实；道念穿透禁幕，笼罩**千丈 → 万丈 → 十万丈 → 小半个七彩界**。
- 此象肉眼不可见，但**化神以上修士**瞬间可察：每一个道念皆为天地规则所化；看似真、细看是假，真假难分，陷入者如沦深渊无法脱离。
- 作者点明：**真与假的意境是王林「道」的第二次变化**，其追寻已超过同阶乃至修为高深于他者的意境。

### 铭志之言
第三瓶饮下后，王林心神中浮现呢喃并渐清晰：

> 「铭志，囚封天之道，众生需渡无量劫，离开深狱一执念，众生亦于无量前，解今茫世，脱困天念，取来生道，锁亡天运，印冥朝，众生之所不得真道者，常沉苦海，永失真道，奉至修真行」

其中「**众生之所不得真道者，常沉苦海，永失真道**」在王林心神中反复回响，与道念的爆发式扩散同步。

## 五、七彩界万物闻道

- **苍松子**：抵达山谷外**千丈处已是第二天**，面色极为苍白、身子一动不动；未及前行便感受到无尽驳杂道念——如巨大漩涡般吸收一切意境，将人卷入王林的印证之中。他只能盘膝坐地稳定心神，抵抗道念侵入与无形漩涡吸撤，**追杀因此被迫中止**。
- **迷失者**：无发、双目迷茫，步伐不快却**缩地成寸**，很快抵达但不近前，茫然望向前方如同闻道；双目越加迷茫，可见无形道念被其吸收。
- **铭志者**：尽数飘出雾气向山谷而来，悠久岁月的喃喃之声在此刻**停止**，飘于半空闭目感悟王林的道。
- **十二阶化雾凶兽**：由雾状化作样貌各异的实体凶兽，未发咆哮，披七彩之芒疾驰而至，环绕山谷外半空与铭志者一同感悟。
- 一切以王林山谷为中心，**一场卷动整个七彩界的「道之升华」**缓缓展开，整个七彩界似都扭曲起来。

## 六、伏笔与待解

- 苍松子的复仇尚未落地：他既知王林位置，却被道念漩涡拦在千丈外。
- 「逆行者」为一次性消耗的召唤/占卜之宝，其来历与代价未交代。
- 蚊兽蜕变在封闭洞府中进行，成败未见分晓；目标直指**风之仙界**的蚊兽群。
- 铭志之言与七彩界的「囚封天之道」「锁亡天运」等设定，指向本界更深层的秘密。
- 章末作者按语提及七彩界情节「承上启下」，为卷内关键一环。
