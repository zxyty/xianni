# 第608章 血魂丹

## 一、剑气对魔刀

- **魔刀来历**：黑甲老者的镰刀由其自身魔气凝化。他并非真正的魔人，魔气不精纯，故此刀并不完美；但其眉心的魔影是**实实在在的魔魂分体**，魔魂融入之下，凡铁亦可化作魔刃，何况本就由魔气所化的镰刀。魔魂融入后，镰刀变成魔刀，且**蕴含了魔道**。
- **凌天候剑气**：王林食指剑芒一闪，凌天候的剑气自指尖呼啸而出。剑气一出，天地一顿，如时间停流：
  - 天空黄泉**倒卷**，直接融入王林体内，其内**十三万杀戮之气崩溃**，**黄泉之魂由一化亿**；
  - 风雨雷电神通同破——黑雷崩溃、雨滴与电光碎灭、风之漩涡被穿透崩溃。
- **剑气之道 = 霸道**：凌天候一生傲然，以霸之道横走天地；剑气一现，天地间任何神通都要让位、不可抢其声势，这股霸道即是天威。
- **交锋**：魔刀化黑芒直奔王林，剑气横扫。相撞刹那，剑气之后浮现凌天候身影，魔刀之后幻化出**头生单角的巨大魔影**。大地崩裂成沟壑，天空云层尽消、天色黯淡。魔影脸露不甘而消散，魔刀随之崩溃；剑气几乎黯淡，只余一丝仍蕴霸道的金芒。

## 二、剑气伤塔与老者魔化

- 残余剑气直奔**黑塔**。塔内传出一声冷哼，剑气一颤却未散，凭霸道硬生生穿透哼声之力落在塔上。塔内又传一声轻咦，黑塔一震，虽未崩溃却生出**道道裂缝**。
- 塔内之人评价：「好强的剑气，发出这剑气之人，比我当年全盛时期还要强上几分。」
- 王林抓住甩出剑气的时机**果断后退**——他清醒后心有余悸：若任由升仙果的疯狂占据心神强行踏入塔中，必死无疑。
- 黑甲老者在魔刀崩溃瞬间喷血、身子萎靡，本欲追击王林，却因**黑塔对魔仆至关重要**而生生止步、改追剑气。
- 剑气消散后，黑塔传出浓浓魔气灌入老者体内：铠甲妖异之芒暴闪，老者胀大数倍成**三丈巨人**，额头钻出一根**黑角**，「已经不再是人」，痛苦咆哮后转身追杀王林。

## 三、储物袋内逼供姚惜雪

- 王林暗叹「成也升仙果，败也是升仙果」，决意拼一把，从储物袋取出一粒布满符文、随其心跳诡异闪烁的**蜡丸（血魂丹）**。
- **神识一分为二**：一道留在体内应敌，一道冲入储物袋，锁定袋中一个被无数禁制封印的**小球**——姚惜雪被囚其内，受奇异禁制折磨，面色绯红、痛苦与羞辱交织。
- **威胁**：「说出血魂丹的使用方法，若你不说，我死前捏碎储物袋，你将融入虚无，保持现在的样子直至寿元断绝。」姚惜雪求解禁制，王林先解其禁；她欲讨价还价，王林神念一动重现禁制，她随即毫不犹豫说出用法。王林在袋内又追问一遍才收回神识。
- **拖延手段**：老者一步追至时，王林掷出**巨魔族战斧**并喝「爆」，战斧碎裂成巨大风暴，被老者一甩大袖消散。

## 四、血魂丹的使用方法（关键设定）

1. 捏碎蜡丸，其内飘出**一滴蓝色血液**；
2. 咬破指尖，挤出鲜血于虚空化作**一个复杂符文**；
3. 符文与蓝色血液**融合**；
4. 抓住符文按在**自己眉心**之上；
5. 符文自眉心泌出后，一弹之下**飞至千里之外**，消散于天地之间。

## 五、自爆

- 做完布置，王林转身，眼中清明尽消，代之以**升仙果的疯狂战意与杀机**，大喝「老东西，你给我死」，不退反进迎面冲向老者。
- 王林体内爆出浓焰般火焰——**问鼎修士自爆**。老者面色剧变、一退再退：「你疯了」。
- 王林元神燃烧，体内**四滴仙液**随之沸腾。寻常问鼎修士自爆只能重伤老者，但有四滴仙液则是天地之差。
- 自爆横扫：老者首当其冲喷血，铠甲化细丝凝盾抵抗，**仅持续三息**；随后盾牌凝成**黑色魔影**一跃离开老者、飞向黑塔。失去铠甲护持的老者身体，瞬间被自爆之力波及**崩溃**。
- 王林身影消散刹那，冲黑塔打出**一拳**——此拳由其道念、生命、元神所化，其内更蕴含**本尊的古神之念**。拳化狂风轰上黑塔，塔上凌天候剑气所留裂痕蔓延，**整个黑塔崩溃**。

## 六、铠甲主人与塔下之人

- 半空中漂浮着一副**少了一个护腕**的铠甲，幽光爆闪，神念冲出：「你敢毁我魔塔，即便你与他有关系，我也要杀了你」。
- **魔塔功用**：是这副铠甲扩散神识的重要魔器；失去魔塔，其神识便无法横扫大半个**妖灵之地**。
- 黑塔原址露出一个**黑色阵法**，阵法内盘膝坐着一名**长发飘动、身有紫金色纹络的大汉**；铠甲落下化作道道黑线，在其身上穿好，大汉**睁开双眼**。

## 七、结尾：血魂丹重生

千里之外的虚空中出现那滴蓝色血液，一现即向远处疾驰，飞行中渐渐变化，最终**形成王林的身影**——血魂丹为自爆之后的续命/重生手段。

## 待解疑点

- 塔下阵法中紫金色纹络的大汉与铠甲、魔仆一系的关系。
- 自爆后王林肉身与四滴仙液的损耗程度、血魂丹重生后的境界跌落情况（本章未交代）。
