# 第1727章 阻拦！

## 一、幽冥兽即天道：绝对隐匿

- 幽冥兽在融合天运子之后，**它就是天道**。其气息与存在若不愿为人所知，外人极难察觉；在洞府界外或许还有端倪，**在洞府界内则是绝对隐匿**。
- 佐证：当年**连道非**都未能提前感受出天道的存在而被算计；**天运子在召河存在数百年**却无人察觉，同为此故。
- 眼下幽冥兽已现身**云海星域**，但**战老鬼**、**四大战将**及诸多仙人尽皆无察。他们神识足以覆盖整个云海星域，却看不到幽冥兽，连兽背上盘膝的王林也毫无察觉——神识中只是一片平静星空。
- 战老鬼跟随远古仙域仙人时曾眉头一皱、抬头远望，终无发现，只道『此事，有些奇异』。

## 二、王林重凝本源、本尊分身合一

- 幽冥兽背上：**王林本尊闭目打坐沉睡快速恢复**，**分身则重凝本源**。本源凝聚的痕迹在星空回荡，**无法隐瞒**，被云海的四大战将与诸多仙人察觉，但搜寻不到源头。
- **第三道虚之本源＝因果**：定义为「掌开为因，掌灭为果」。王林分身右手伸掌、握拳，因果本源自星空无形而出，凝于掌心并融入体内。
- 以同法，从消散中重凝**杀戮本源**与**禁制本源**。至此**七大本源**在体内缓缓运转。
- 运转之下，**元神自本源中幻化**，王林的一切**回到未崩溃前**——唯一区别是**没有了天运子分身之魂**。
- 分身完全恢复瞬间，本尊睁眼与分身对望；半响后分身一晃与本尊重叠，砰砰之声中**完全融合成为一体**，身体无任何不适。

## 三、王林的下一步筹划

- 判断：既已有**逐鹿的资格**，需去一趟**五行星**——那里藏着太多隐秘，是洞府界内**最后一股隐藏在暗处的力量**所在。
- 该势力抱着渔翁之利的念头，与天运子此前想法类似。王林要把他们从暗处逼到阳光下，让其知晓「这洞府界，不属于你们任何一个外来者」。
- **钉子论**：
  1. 第一根钉子＝**天运子**（变数已被王林毁灭）；
  2. 第二根钉子＝**群仙罡大陆归一宗的外来者**。
- 逼出最后一股力量后，**洞府界第三魂的争夺将正式展开**；王林视其为一场**逐鹿的游戏**，看谁能第一个找到**第三魂**。
- 行程：幽冥兽行至云海星域深处，王林心念一动，幽冥兽闭上双眼、改变方向，**正要去往昆虚**。

## 四、百余仙人围堵

- 远处星空出现**一百多道长虹**，直扑王林所在。最前方四人头顶漂浮**巨大葫芦**，青气弥漫、似化作风暴。
- 为首者为**青龙、白虎、玄武、朱雀四大战将**，后方另有百余远古仙人，更后方是**独自漂浮的道袍战老鬼**。
- **震惊之处**：四人神识始终散开却毫无预警，若非肉眼所见根本不信王林会在此；此刻以神识查看，仍只见一片平静星空，仿佛王林与其身下凶兽是虚幻不存在的。
- 青龙战将不识幽冥兽，心神蓦然一跳——**除七彩仙尊外无人见过天道真身**，众人记忆中天道只是一团庞大雾气。
- 战老鬼瞳孔收缩：**在王林身上没察觉任何危险，却从幽冥兽处清晰感受到汗毛耸立的危机**。
