# 第1212章 封灭族（第九卷 云海之巅·第三更）

## 一、战意与底气

- 对手为**碎涅后期修士**（即前文的**白发老者**），王林原本「根本没有半点把握」，往常只会选择逼退。
- 三项变化让他决意一战：
  1. **朱雀第三次苏醒**，使他可能且可操控天地雷霆之力；
  2. **吸收了闪雷族之人**后实力飞跃；
  3. **吸收了战空野（战星野）的战之意境**——虽未融合，仅略微感受便足以生出决战之心。
- 脑海中回荡战星野之言：「**我辈修士，何惜一战**」。

## 二、火焰之仙：蓝色火焰图腾

- 王林左目蓝色火焰轰然弥漫，自瞳孔散出、骤现于眉心。
- 自述：「**我放弃生死意境，在这一刻，由火焰取代心神，由火焰感悟取代道境……我，就是三次觉醒的朱雀**」。
- 眉心凝成**蓝色火焰印记（火焰图腾）**。此刻他已非修士，而是「火焰之仙，天地火之一切掌控者」。
- **与火雀族的异同**：形态极为相似，唯一区别在于王林眉心火焰为**蓝色**，火雀族族人为**红色**。
- 蓝色朱雀长啸后闪烁而动、**融入王林眉心**，形同「元神归窍」；王林体外随即浮现**通体蓝色的朱雀形铠甲**。

### 号令天地之火

- 一声「**号令天地之火，凝**」，弥漫整个七彩界的蓝色火焰沸腾并以不可思议之速向王林汇聚，自高空看去如天地火海疯狂收缩至中心。
- 白发老者掐诀降下**逆行者神通**（无数神通法术铺天盖地），恰与收缩完成的火海相撞；王林如火焰漩涡，将崩溃的火焰尽数吸入铠甲与眉心，眉心蓝光近乎妖异。
- 一声「**天地之火，皆听我之号令，焚化一切**」，蓝色火海横扫，逆行者神通全数崩溃；老者身外**九个兽骨砰砰碎裂化作灰迹**，无法承受火焰之力。

## 三、封灭族与封天之术

- 火焰吞噬将至，白发老者**不惜暴露自己并非修士的身份**，右手一点眉心，眉心裂开如**第三只眼**、散发黑芒。
- 喝道：「**封灭族后人，召唤我族大神通封印，封此人火焰图腾**」。黑芒于身前化作极复杂符文，符文吸收老者生机，令其瞬息变得无限苍老。
- 符文以不可思议之速穿透蓝色火海，直落王林眉心。王林蹬蹬蹬后退数丈，火焰图腾疯狂欲冲破而不得，双方一时不分胜负。

### 设定：封灭族（太古之族）

- 太古之中有一族拥有**封天之力**，曾一度成为**太古之民内的至强者**；因族人太过稀少，至今几乎灭绝。
- 传说凡此族之人，**皆有封印一切生灵之力**。
- **关键澄清**：这位白发老者**并非真正的封灭族后人**，而是**以特殊方法具备了一些血脉**，故能施展封天之术；每次施展都要耗费大量生机，且**生机永远不可能恢复**。
- 老者忌惮之言：「**你若真是修士倒也罢了，但却学我太古之族印记**」——封了火焰图腾便认定王林不堪一击。他自认无法终生封印（王林火焰太强），但**短暂封印**有自信可做到。
- 封印生效瞬间，四周蓝色火海骤然消散无影无踪，七彩界恢复如常，唯余地面残骸为证。

## 四、闪电图腾接续

- 王林：「**火焰，不是我唯一神通，让你封印一时，又有何妨**」。
- **右目幻化闪电印记**，随即移至眉心，散发天地至极的雷威；七彩界雷鸣大作、无尽闪电雷霆瞬息涌现。
- 「**我等你，再封我闪电图腾。天地雷霆，皆听我号令**」——右手指天，雷霆疯狂凝聚，其所在化为**雷池地狱**，如同天劫而他是操控天劫之人。
- 此刻的王林俨然成为**闪雷族之人**，甚至比闪雷族**更明悟雷霆、更可操控天地之雷**。
- 老者目瞪口呆：「**火雀族，闪雷族这不可能**」，并低吼「难怪**尊者**要取此人之魂，此人若不死，定然是我**太古之族**的祸端」——判定王林必须杀。

## 五、双役灵印对轰

- 老者升空，引动天地元力凝于右手，喝「**就让你死在，你们修士的一击至强神通之下**」，向前一拍化出与天齐高的巨大掌印。
- 王林瞳孔一缩，认出「**役灵印**」。老者坦言：「**老夫早年曾拜入神宗门下，学的此术**」——此术在**云海（云海星域）**有赫赫声名。
- 王林亦抬手一拍，**分走老者所吸收的部分天地元力**，凝出**第二个役灵印**。老者再度震惊，随即杀机更浓。
- 云海星域本就极少见役灵印，**两个役灵印相互残杀万年也几乎不会发生一次**。
- 两印对峙令七彩界近乎崩溃，大地咔咔裂开**巨大沟壑**，恰将王林与老者分在两半。章末两掌印高速逼近，**胜负未分**（悬念收尾）。
