# 仙逆 第1105章 山崩（第八卷 联盟隐秘·第三更）

## 场景与阵营
- **地点**：碎石星域（隶属联盟星域）。
- **王林一方**：王林（白发青年形貌）、蚊兽（先前被重伤掠走，本章见势不妙自行飞离）。
- **敌方**：两名紫衣老者（首领）、三名黄衣青年、近百名布阵修士；依托青光罩防护，并以碎石组成传送阵欲离开联盟星域。

## 战斗经过

### 一、引劫与捏碎红雷
- 碎石星域上空劫云疯狂凝聚，速度远超王林以往所历天劫，转眼遮盖星空。
- 首道天劫为水桶粗细红色闪电，落下时碎石纷崩、星空现大片裂缝。
- 王林神色如常，抬右手一捏，红雷当场崩溃化作四散弧光。
- 紫衣老者惊疑：“此人竟然在我们面前不知以何种方法引下天劫。”
- 王林挥手将四散电光重新凝于右手成红芒，抛向青光罩。青光罩剧烈晃动、二老面色苍白，但**一道天雷未能撼动**——其强度超出王林预料。
- 王林起杀机：“一道不行，就十道，十道不行，就百道。”

### 二、太古雷龙与吞噬九雷（本章高光）
- 九道红雷连成一片轰落，王林不避反迎，长笑跃向星空。
- 眉心漩涡幻化，**太古雷龙元神**冲出，向九道天雷怒吼。
- 设定点明：雷龙之吼，天下一切雷皆要听令；而**敢向天道劫雷怒吼者，整个天地唯王林一人**。九雷为之一顿。
- 王林冲入雷中，**左目雷光生出无穷吸力**，九道天雷尽数涌入左目消散。事后左目雷光浓郁、啪啪作响，雷电环身，**如同雷仙**。
- 王林仰头咆哮：“就只有这点威力么”
- 冲击：三名黄衣修士肝胆欲裂；两名紫衣老者惊呼“吞…吞噬天劫”，冷汗直冒，判定其**隐藏了修为**，急令组建阵法，并亲自不顾身份加入布阵，喊“尽快离开这该死的联盟星域”。

### 三、紫雷、七彩天雷与雷球
- 十丈粗细紫色天雷降临，先破开星空冲入虚无，又于王林身前三寸处穿出直取眉心；王林双臂环抱生生抱住，纹丝未动。
- 紫雷连绵轰落，身前雷电成球，渐至近百丈；王林渐被逼退，神色却愈发疯狂，大吼“再来一些”。
- 覆盖数十万里的劫云发出**仿若人声的怒吼**，降下**七彩天雷**，一现即化七道各色之雷。
- 雷球涨至数百丈，其内雷霆之力已让能掌握天地之雷的王林都有些承受不住。

### 四、雷球破阵，星域烟消
- 王林身子一晃，将数百丈雷球抛向下方青光罩。
- 敌方仓促开启尚未完成的阵法，近百修士分坐方位掐诀；两名紫衣老者盘膝坐下，元神融入青光罩以增其威。
- 雷球轰落：青光瞬息黯淡；二老同时喷血，其中一人**肉身崩溃、元神飞出**尖叫奔向阵法；穿透护罩的电光如游龙游走，十余名布阵修士身体瞬间焦黑、**元神都无法逃走当场死亡**。
- 青光大阵轰然崩溃，化作碎片，环形冲击向四周推开。
- **整片碎石星域的碎石尽化碎末**，除中间区域外再无半块碎石。蚊兽提前疾驰飞走，无恙。

### 五、结尾：山崩
- 王林带着杀机与蚊兽被重伤掠走的愤怒冲入其内；上百道七彩之雷随之追袭。
- 七彩雷后**首次出现火态天劫**——一片天火焚烧而落。
- 碎石传送阵终于开启，星光璀璨转动、浩然之威散出，已有距离近的修士落入阵内即将被传送。
- 王林绝不允其逃走：双目一闪，星空如起滔天之浪，一股似可崩溃星空之力自体外涌现；四周凭空幻化出一个个**虚幻火山**，热浪环绕、火山内闷吼不断。
- 王林眼露杀机，轻声道：“**山崩**。”（章末，未竟）

## 要点提炼
1. 王林可主动引劫、并以左目**吞噬天劫**，将天劫化为己用的攻击手段（雷球）。
2. 太古雷龙元神是其号令雷霆的根本，唯他敢向天道劫雷怒吼。
3. 本章天劫层级递进：红雷 → 九道红雷 → 十丈紫雷 → 七彩天雷 → **天火（首次出现的火态天劫）**。
4. 敌方战力评估：青光罩可扛单道天雷，但挡不住数百丈雷球；组阵传送是其唯一生路。
5. 悬念：“山崩”神通的威力，以及能否阻止阵内修士被传送逃走。
