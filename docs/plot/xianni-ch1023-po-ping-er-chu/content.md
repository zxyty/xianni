# 第八卷 联盟隐秘 · 第1023章 破瓶而出

## 一、火海破界与王林的收尾动作

- 火海之强超出王林想象；在火海崩溃瓶中一界、该界「限制瞬移」的禁制短暂失效的刹那，王林取回了此前放在黑塔内的**储物袋**，以及**大殿神秘人影送予的黄色结晶**。黄色结晶来不及查看，刚放入储物袋即被战局推进。
- 火海弥漫瓶中余下的**九十八界**，集九十八界之力化作不可操控的火焰之力，轰击**最后一界**壁垒，声响回荡瓶中每一处。
- 力量评级：此火海之强**已超过冥海施展的焚天仙术**。
- 代价与不可复制性：这是王林吸收海量火焰后、以自身身体为中转、把无法吸收的废火宣泄而成，**绝不可能再施展同样一式**——除非另有一处永不熄灭的火海，让他有足够时间吸收至巅峰后再次宣泄。

## 二、朱雀觉醒的实际收益（重要设定）

- 王林全身赤红渐平复，但身上**朱雀图腾鲜红如血**，尾部雀羽顺颈部烙印上行、止于眉心，仿若融入黑发，远看**如黑发燃起紫焰**。
- **朱雀觉醒不提升修为，而是改变元力**：体内元力蕴含高温，令其一切神通变得极为可怕。
- **古神肉身**在不断适应火焰后，举手投足即可宣泄火焰。
- 战力定位：修为仍是**窥涅中期**，却是「一切窥涅中期的最强者」；净涅后期修士遇到他也会为其肉身与火焰神通头痛。
- 上限约束：古神肉身**才是五星**，助力有限，**发挥出净涅中期的实力已是极限**；欲胜净涅后期，须自身修为达净涅以上。

## 三、境界体系补充：净涅→碎涅

- 修道第二步每个小境界差距极大，古神肉身也难以轻易越过「净涅中期 → 净涅后期」这道沟壑。
- 例证：**血祖**在净涅中期停滞许久仍无法进入后期。
- 除莫大机缘外，净涅后期乃至圆满极为艰难，关键有二：**意境的感悟**、**如何掌控天地规则**。
- **净涅后期 = 意境与规则的融合**；该融合在**净涅大圆满**时达到顶峰，随后可进军**碎涅**——「已知修为中，最高的一处境界」，为绝大部分修士梦想之境。

## 四、贝罗炼化画轴：仙气→妖气

- 最后一界在连续冲击下轰然崩溃，天空如撕碎纸片般向四周倒卷，**古妖贝罗**现身于崩溃之界。
- 贝罗右手持**灰色画轴**，浓浓**仙气**自画轴冲击其全身，画轴似有灵、不甘被古妖掌控而挣扎，隐有怒吼。
- 贝罗冷哼、右手猛捏，**右目七个妖星**一闪，磅礴妖力顺右手涌入画轴，破开画轴上一切封锁；一声不甘咆哮后，绿芒覆盖整个画轴。
- 结果：**仙气全消，代之以无尽妖气；颜色由灰变绿**（此后为「绿色画轴」）。
- 与此同时**瓶中九十九界瞬息瓦解**，天空全散，如天地初开、混沌重起，雾气弥漫；雾气与火海融合如添滚油，爆发出更强冲击，直奔九十九界之外的最顶方虚无。

## 五、仙帝洞府外景：白玉瓶爆塞

- 场景切换至**仙帝洞府木桥**：雾中之人身前的**白玉瓶**通体赤红、散发浓郁高温，**瓶口木塞剧烈颤抖**。
- 雾中人抬干枯右手一指，**魔气**呼啸融入木塞欲行镇压；魔气刚要入瓶之际，惊天巨响炸起，**木塞碎裂成无数碎末**如喷泉般向上扩散，狂风把雾中人身外雾气生生吹退三尺，其干枯手指被弹起。
- 露出真身：**漆黑（紫黑色）铠甲，甲上大量复杂花纹，阴森魔气缭绕，一头苍发飘荡**，头盔处两道阴沉目光落在白玉瓶上。
- 火焰喷发：赤红火焰与无法想象的高温自瓶口涌出，白玉瓶如火山爆发。
  - **木桥**瞬间入火海、燃成灰痕；
  - 桥下**小河**化大片白气升空，河床干裂，河中**狰狞之兽**惨叫化血雾；
  - 所在**庭院**（四周阁楼错落、不远处翠竹环绕）原本别致，因魔气侵染而阁楼阴森、翠竹变黑、青草变样；无论曾为仙境或此刻魔域，**尽被火海化灰**；
  - 雾中人本身也被火海冲击，身外雾气向后拉扯数十丈，身影腾空、双目阴森。

## 六、众人出瓶与「残刀」身份揭示

- 火焰尽头，**贝罗**自瓶内走出：光头、右手持绿色画轴，笑看铠甲之人并摇头点破其来历：
  > 「昔曰仙帝座下四大护卫之一的**残刀**，今曰却成了**古魔炼化散魔**之一，可悲。」
- 随后出瓶者（按原文次序）：**天运子、凌天候、虚空子、司徒南**（→ 按世界状态须知，此「司徒南」实为**司徒南的断臂**所化人影，自第336章起自称司徒南；真司徒南第61章已死）、**村姑美妇**；继而是**葫芦老者**、**暗藏黑龙印记的黑衣男子**、**尘道三子**与**大头**等人，以及**全身笼罩妖气的女子**、**拥有星痕貂的孙姓长老**。
- 覆盖判定：先前进入仙府的所有人中，**除云仙道侣与王林外全部现身**。
- 王林最后登场：瓶内火焰喷尽后又一股热浪轰然，**王林自其中一跃而起**，目光如火焰扫视四周。
