# 第1247章 蚊王变异（第九卷 云海之巅·第二更）

## 一、局势：蚊海围裂缝

- 场景为一处被无边蚊兽群环绕的**裂缝**，裂缝内有一只巨大蚊兽（蚊王）正挣扎欲冲出。
- 四周蚊兽数量多到无法计算，蓝、白、紫各色气息惊天动地，修士在此进退无门。
- 蚊兽按色阶排序：红 < 蓝 < 白 < 紫 < 金；裂缝最外圈由数百**金色蚊兽**环绕守护。

## 二、挑战：蚊王之间的嘶鸣

- 王林的蚊王察觉裂缝内巨大蚊王拥有**极为精纯的蚊族血液**，渴望吸食哪怕一滴，念头传递至王林心神。
- 王林咬牙决意相助，蚊王嘶鸣冲出——此为蚊王之间的挑战。
- **规矩**：蚊王之战，紫色以下（红、蓝、白）不得参与，此律刻在蚊兽灵魂中；故仅数千**紫色蚊兽**（气息堪比碎涅大圆满）呼啸参战。

## 三、王林出手

1. 王林原本收敛气息藏于蚊群，见紫色蚊兽出动，一步踏出蚊群，行走间雷鸣轰轰。
2. 第二步踏上自己蚊王背上，右手虚空一抓，**黑色闪电化作巨大三叉戟**。
3. 战斗手段：古神之力弥漫全身、眉心**规则之星**显现；三叉戟横扫引动天地雷霆与**蓝色火海**（火焰在戟尖化作大口吞噬紫色蚊兽）。
4. 评述：蚊兽虽有碎涅之力，却是兽而非人、不会使用法宝，真战起来不如碎涅修士。
5. 蚊王正面撞飞一只拦路紫色蚊兽（对方无伤，体外反有仙力凝聚，似修士将施神通）；蚊王自身多处破损、口器裂开、流血更狂。

## 四、古神之身与抛戟开道

- 王林跃起，体内雷鸣轰响，身躯胀大化作**数百丈巨人（古神之身）**，三叉戟同步暴涨至数百丈。
- 全力抛出三叉戟：戟内凝聚古神之力 + 规则之星意境 + 天地雷霆（化无数雷球）+ 蓝色火海（高温连紫色蚊兽亦避）+ 修士神通**白凡仙术**（卷动天地元力，天地如末日）。
- 蚊兽群为之一顿，王林趁机抓住自己的蚊王再次向前抛出，蚊王借力破阵而行，并以蚊王威压压制四周蚊兽无法围攻。
- **受阻点**：三叉戟冲入金色蚊兽区域时，前方骤现一片看不清的波纹，碰撞后浮出无数充满沧桑气息的**符文印记**，将三叉戟生生停住。

## 五、转折：蚊王变异（本章核心）

- 蚊王独自冲出，面对数百金色蚊兽阻拦，发出惊天动地嘶吼。
- 体内咔咔作响似全身崩溃，流出的**血液由红变金**；金色血液沾染伤口，透出惊天气息。
- 其身外浮现一个同样**数万丈大小、暗金色的巨大蚊兽虚影**。
- 全场反应：红、蓝、白、紫、金所有蚊兽通体一颤；金色蚊兽露出敬畏、迅速让路不敢再阻；裂缝内的巨大蚊王身子一震，**第一次真正正视**王林的蚊兽。
- 王林自身体外亦有金芒闪烁。

## 六、伏笔与联想

- 王林脑中轰鸣，回想起**当年在朱雀星第一次看到蚊兽**的画面，隐隐猜到：为何朱雀星会出现蚊兽，且只有这一只蚊兽。
- 章末：蚊王化作金色流星冲向裂缝；裂缝内巨大蚊王目露凝重，挣扎更为剧烈。
