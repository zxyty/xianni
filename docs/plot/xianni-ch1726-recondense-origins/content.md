# 第1726章 重凝本源（第一更）

## 一、星空同行：幽冥兽与天道之悟

- 王林疲惫地盘坐在幽冥兽背上。幽冥兽此刻收缩至约千丈，仍令观者心生压力——压力来自其庞大身躯，更来自双目中淡漠生死、轮回、岁月、众生的无情。
- 叙述点明：幽冥兽似是天道，是洞府界真正的神灵，界内一切（修士、凶兽）皆自它衍变而出，如飞灰。它在星空中的移动无声无息，与其说是它在动，不如说是星空在动——星空的一切皆属于它。
- 王林身负**道古血脉**，其高贵可比疯子的仙人血脉；因此他虽是洞府界之人，在仙罡大陆亦有资格俯视苍生，静坐时气势如同仙神。

### 王林的推演（内心独白）

1. 当年收服的幽冥兽竟是**天道的一部分**；**天运子也是天道的一部分**——天运子信奉的「天运」，实际上就是他自己。
2. **七彩仙尊**当年获得的、自**太古神境**飞出的碎片是**储物之用**；他从中发现了天道，想来连**天逆**也是由此发现，所以才会有那**罗盘**。
3. **七彩道人、战老鬼**及其余之辈寻找**第三魂**，除欲将其融合外，怕是也打着天道与七彩仙尊所得储物碎片的主意。
4. 结论：机缘巧合之下，**我成为了天道之主**。仙罡大陆之事无法确定，但在**洞府界**内，谁也无法从我身边抢走天道。天道眼下应已完整——它当年能吞**连道非**，如今谁敢招惹于我，便是万古岁月后被天道第一个吞噬的敌人。

## 二、重凝分身：以血为引

旧分身已消散，王林决意再凝一具，「以我血为引，成万古大道」。

| 步骤 | 做法 | 结果 |
| --- | --- | --- |
| 引血 | 咬破舌尖喷出一口鲜血，赤红沸腾、异香扑鼻，悬于身前与幽冥兽同步前行 | 血液蠕动扩张化作血人 |
| 抽道古之力 | 眉心与双眼内**三族星点**骤出旋转生吸力，笼罩血人 | 约一炷香，血人内**道古之力**尽被抽入三族之星，血中再无道古气息 |
| 成躯 | 血色内敛 | 现出与王林**一模一样**的分身，有成年之形而无魂，仿若初生之子 |
| 魂凝 | 右手点眉心，分出一部分魂自七窍散出、钻入分身七窍 | 魂与躯体水乳交融、不分彼此 |

完成后本尊神色疲惫，缓缓闭目如同沉睡；**本尊闭目的刹那，分身睁眼**，接手后续行动。

## 三、四道本源归来

### 1. 火焰本源（左目）

分身一指星空，喝令「消散在这星空内、被我感悟出的火焰本源，归来」。以幽冥兽为中心，星空中火苗成片、连成环形火海回旋，如大浪卷动。火海尽数涌入其**左目**（左目如吞噬火焰的黑洞），左目内亮起**火焰本源印记**。

### 2. 雷霆本源（右目）

「我为雷霆之主，以一次次的明悟，召唤你们归体。」右手一挥，星空震动，八方雷鸣渐近，闪电如天劫连成无边一片直奔王林，尽数轰入**右目**。每一道闪电融合，其身外便游走弧形电光如欢呼雀跃。右目内幻化出**不灭闪电印记**。

> 两道本源定位：**左目火焰，右目雷霆**。

### 3. 生死本源（虚之本源其一，凝于眉心）

虚之本源乃王林在**千年梦道**内感悟而出，承载其一生意境与大道；虽已消散，仍可凝聚归来。

- 誓语：「我左手为生，右手为死；岁月流逝，道心不变。」
- 左手散出白气缭绕、柔和白芒，是生机，也是其**两千年**感悟的生死本源之一部分；右手黑气缭绕成黝黑光团，内含腐朽与死亡，仿若可从地狱黄泉取出亡魂。
- 黑白二气顺手臂游走，汇聚于眉心彼此融合、缓缓旋转如阴阳。生死本源归来后，其体内气息**浑然暴增**。

### 4. 真假本源（虚之本源其二）

「真真假假，便是人生。」——说此话时王林脑中浮现天运子之事，颇为感慨。话出之际其身现虚幻不真实，双眼如同星空，观者会迷茫其中、分不清瞳与孔。「我闭目，则一切虚假；我睁开眼，一切是真。」闭目时天地、洞府界、第三魂乃至幽冥兽在其感受中全为虚幻；睁目之时，**真假本源凝聚而来**。

## 四、场景切换：云海星域的仙人队伍

- 凝本源期间，幽冥兽载王林渐渐离开**召河**，来到**云海星域**。
- 云海星域内约数百人在星空疾驰，波纹浩荡；以**四个老者**为首，四人气息最强，且以某种神通将**神识彼此连接**。
- 四人头顶幻化一个**巨大青色葫芦**，通体透出古老岁月痕迹，葫芦口内一团青气环绕，似在**指引方向**。四人每飞一段距离便停下，齐齐向葫芦一拜、神念交融与之沟通。
- 这四个老者正是**远古仙域的四大战将**。
- 队伍后方，身穿道袍的**战老鬼**神色从容、遥遥跟随；他不在乎前方那群仙人，那群仙人似也不在乎他的存在。

## 五、要点与伏笔

- 天道归属确立：王林自认成为天道之主，为后续与七彩道人、战老鬼等争夺第三魂/天道的冲突埋线。
- 天运子=天道一部分，与幽冥兽同源，解释了其「信奉天运即信奉自己」的悖论。
- 新分身以纯净（去道古之力）之血+分魂造就，与本尊一模一样，是本章后半段所有行动的主体。
- 四本源归位（火焰、雷霆、生死、真假），虚之本源尚未完全召回，暗示后续仍有本源待归。
- 远古仙域四大战将持青葫芦寻路进入云海星域，战老鬼尾随，两条线即将交汇。
