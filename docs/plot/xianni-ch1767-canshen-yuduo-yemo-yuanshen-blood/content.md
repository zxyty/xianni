# 第1767章 残神欲夺

## 一、场景与规则
- 地点：洞府界内一处无尽冰封之地（王林随第三魂线索行至此处，因未与第三魂完全融合，故诸多旧事在魂内未得，只能听女古神口述）。
- 洞府界规则（女古神口述）：**第一个进入此地者即为此地主人**；主人若愿意，此地可化作禁制阵法阻止一切后来者前行，但**闯入者修为太高则无法阻拦太久**。
- 天地内传来若隐若现的模糊波纹，说明另有数人踏入此地。王林略一点头示意后，女古神右手一挥，冰层凭空生出、以此地为中心横扫，**整界被无缝冰封**，如一块巨大冰块，半透明昏暗、寒气逼人。仅王林与女古神所在陆地无冰。
- 后至数人当场被冰封定住。女古神提醒：**冰封时间不长，来者中有修为高深者，也有带『主人气息』者。**

## 二、女古神的来历与请求
- 自述：**「我是主人凝烨寞之血所化」**，受命为主人看守**东临宗**，被赐**神长老**之位。
- 现状：年代久远，**妖、魔两位长老已在沉睡冰封中死亡**；其余之人若无主人生机滋养，也会陆续死去。
- 推断王林：既带主人之魂、能自洞府核心之地来此，必是闯过**五花八门阵**，欲寻**真门**离开洞府界。
- 请求：**若王林打开洞府大门，请带她离开此地**。低头一拜，青丝散落如瀑。王林沉默片刻后点头允诺。

## 三、烨寞元神之血
- 女古神右手点向眉心，眉心现漩涡、红芒闪烁，凝出**一滴鲜血**弹向王林，停于其身前七寸处，散发璀璨赤芒。凝血之后她自身**转为虚弱**。
- 此为**烨寞最后一滴元神之血**，吸收可令王林伤势恢复、道古传承「略有圆满」。
- 王林没有立刻收取，先追问「为何要帮我」，并在对话期间**一边疗伤、一边分神识细查此血端倪**，确认无害才动手。吸收时仍**分出一部分神识环绕体外戒备**：女子稍有异动即刻杀人。这是典型的王林式谨慎。

## 四、肉身与元神之变
- 血入眉心，散入全身，无任何排斥，急速与身体融合。
- **神、妖、魔三星点**在眉心与双目同时幻化旋转，吸收血中一切力量。
- 王林身体膨胀至**百丈之大**；**骨骼坚固数倍不止且更具韧性**，**血肉迸发更强肉身之力**，可怕气息扩散笼罩四周。
- 因元神之血补全，**烨寞的元神在王林体内完整**，其身后浮现出**凝实如真人的烨寞虚影**。
  - 与寻常斗法时的虚影不同：那是道古之力传承不完整、外散凝聚所致；**此影乃王林心神所化，本质就是烨寞元神本身**。
- 该气息对**一切以烨寞血液诞生的古之三族**构成灵魂与心神双重威压，如面对祖先。女古神虽已献出元神之血，体内仍有烨寞寻常之血，遂**面色苍白、匍匐在地**。

## 五、残神欲夺，反被溶解
- 烨寞当年挥洒鲜血，其中**元神之血数滴**；一旦所有元神之血凝聚，即可现出元神**夺舍**——被夺舍者必是其血液传承的后辈，**没有失败的可能**。
- 但王林例外：他**已获古祖认可、得到魂血**，比烨寞更为尊贵，因此烨寞无法成功。
- 烨寞之神蓦然化作**七缕云丝**，循王林**七窍**钻入。王林早已察觉，睁眼时目光一片平静——他明白烨寞夺不了自己。
- **三个时辰后**，王林长出一口气，身体缩回寻常大小，双眼深邃如星空。**烨寞元神在王林体内慢慢溶解，成为其道古传承的一部分。**
- 结果：**伤势完全恢复**（若无魂血与烨寞神影之助，需疗伤数月乃至更久）。

## 六、道古传承进度
- 已完成**大半**。
- 尚缺：**一颗左眼**、埋藏在**古之幕地**的**道古之心**，**或许还有一只左手**。

## 七、玄罗的暗中相助与算计
- 玄罗在远处冰封天地内含笑旁观，判定「此地对他来说是一场造化」，遂**向身旁冰层注入自身气息**，令冰层**百倍千倍万倍凝实**——「你想要多长时间，我就给你多长时间」。
- 随后其目光转向女古神，心念：**「不管来历如何，但终究是我道古一脉所化、我古族之人，古族女姓很少，此女倒可略加培养，成为我这唯一一个弟子的妾侍。」**
- 对烨寞：玄罗眼露怜悯，叹其「天资较佳，死后挥血在这洞府界化作三族，更机缘巧合出现了王林，烨寞有功」，但**已有选择**（选了王林），故不助烨寞夺舍。
- 收尾：王林目光「好似随意」扫过侧方冰层——那正是玄罗所在，暗示王林已有所觉。

## 八、要点提炼
1. 王林与女古神达成互利之约：血换出路。
2. 「残神欲夺」是本章题眼：烨寞残存元神谋夺舍，败于魂血之尊。
3. 玄罗以师者身份为王林护道，同时已在盘算女古神的归属。
4. 传承清单更新：左眼、道古之心（古之幕地）、疑似左手。
