# 第1887章 阻拦

## 一、雪城化凡：斩断与凡尘的最后一丝联系

- 冬日黄昏，落雪连绵，王林远远察觉一座凡间城池后无端生出前往之念，自陈『或许，我是为了寻找一种平凡的感觉』。
- 他自城池一端步行至另一端，脚下积雪嘎吱作响，足迹很快被落雪淹没无影；回头望见雪夜中冉冉点亮的万家灯火，却再无温馨之感——『他，不属于这里』。
- 这是王林**第一次**升起这种说不出的感觉：随着修为提升，他已与凡尘斩掉最后一丝联系。
- 隐隐知晓的规律：**三次化凡便是终点，三次之后则是断凡**。他依旧想在凡间城池休息、看凡俗生生死死，却已无法完全融入。
- 自问『是我的心，不静了么』，并盘点修行进度：
  - 本源**如今有了八道**，**还缺一道本源**，方可踏入**空玄境界**；
  - 此后一路有信心在极快时间内去度那**九次玄劫**；
  - 期许终有一日仍能如当年一样，平静地在凡间城市中默默感悟苍穹。
- 结论式感慨：『这是一种代价，成为强者的代价』。他带着惆怅穿过封闭城门离去，风雪呜咽似奏起一缕风雪琴音。

## 二、二入丹海：荒凉盆地与别离

- 数月后，王林身影出现在**崩溃的丹海**上空。此地已成一个巨大盆地，空旷、无生机，只余荒凉与死寂。
- 这是他**第二次**来到丹海；与上一次相比，此行心情**带着别离**。

## 三、横渡绿魔洲

- 越接近绿魔洲方向，王林神识散开、愈发谨慎。又过一个月，跨越整个丹海踏上绿魔洲大陆的刹那，感受到笼罩全洲的阴森气息——冷酷、嗜血、邪恶。
- 此地所生的凡人、凶兽、修士，**均带一股魔性**。
- **地貌**：与天牛洲不同，绿魔洲山峦极少，占据最多的是大地上无穷无尽、连绵不断的沼泽，走在其上令人心悸。王林很不喜欢此地。
- **修士分布**：当时全洲强者修士极少，大都是低阶修士，对王林毫无威胁；王林仍保持一定规律，以**缩地成寸之术**横渡。
- **绿魔蝎庙**：绿魔洲深处有一股神秘力量，带滔天魔气、极为庞大，按**龟甲地图**显示即绿魔蝎庙所在。其魔性极强，甚至可影响心神变化，王林选择绕开，直奔连接**孟土洲**的边界。
- **设定补充**：此类庙宇的修建**必须仙皇传诏方可**，无诏则不能修建——因此**天牛洲没有修建天牛庙**。

## 四、边界阻拦：两名绿魔使者自爆 + 山顶剑气

数月后，王林抵达绿魔洲边界。通往孟土洲处是一片绿魔洲少有的极高山脉，似与天空相连，翻越即入孟土洲。

**阻拦阵容（『三人』）**：

| 位置 | 表现 | 身份/修为 |
| --- | --- | --- |
| 前方山脉 | 两股滔天魔气凝成两只巨大蝎子虚影，盘踞天地间 | 两名**绿魔使者**，均为**空劫中期** |
| 山脉最顶峰 | 惊天剑气毁天而起，化作古朴剑影如山尖悬于空中 | 剑气中有**王林熟悉的波动**（文中后文提及『云空』） |

- 王林由此确认：选择从绿魔洲离开是正确的，其余方向的阻拦只会更多。
- 王林神色如常，讥言『三人么，未免太看得起王某了』，迈步向山脉走去。
- 两道绿魔气息如两尊绿魔蝎自山脉狰狞冲下；山顶古朴剑影随之传出惊天剑啸，以开天之威一剑斩落，其光似取代此地一切光芒。

### 反常的连环自爆

- 王林披甲近身第一名绿魔使者时，对方**未施展任何神通**，冷酷容颜露出疯狂之色，双手掐诀齐按眉心——**选择完整自爆**，毫无犹豫。
- 其身后第二名绿魔使者**同时自爆**。
- **威力级别**：空劫中期修士自爆足以撼动绿魔洲、形成毁天灭地之力，空劫后期修士面对亦要皱眉；两名空劫中期同时自爆，即便空劫后期也要退后避开。
- **王林的危机判断**：真正的危机不来自毁灭之力本身，而在于**他们为何要自爆**——尚未展开厮杀便自爆，且身后还有施展惊天剑气的云空，三人本有实力一战，根本无需自爆。
- **推论**：事出反常即为妖。以牺牲两名空劫中期绿魔使者为代价，绿魔洲**所图必定滔天**，看样子绝不让王林轻易离开此地。

## 五、王林的应对：双重铠甲 + 道古之力

1. **天牛魂铠**：右侧面孔上的**天牛图腾**闪烁幽光，化作无数黑色细丝弥漫全身，形成天牛魂铠，只余一头白色长发飘摇与铠甲中露出的寒冷双目。着甲瞬间气息轰然暴增，**达到空劫初期的巅峰**。
2. **人形土甲**：右手抬起虚空一抓取出人形土甲，一挥间土黄色光芒缭绕全身——构成**双重铠甲的第一重**。
3. **道古之力**：爆发此刻能运转的全部修为，毫无保留地将**道古之力**完全显露。道古气息散开瞬间，身后浮现一尊**似支撑天地的巨大身影**，方圆数万里内清晰可见，道古波动轰然扩散。道古巨影仰天咆哮，将王林笼罩其内硬抗自爆之力。

**结果**：
- 第一名绿魔使者的自爆之力疯狂落在道古巨影上，巨影通体一颤、现崩溃迹象；
- 紧接第二名绿魔使者的毁灭之力轰然而至，王林融合空劫初期修为暴增后的道古巨影**立刻崩溃**；
- 尚有部分毁灭之力卷向王林本身，落在其**双重铠甲的第一重——人形土甲**之上。

## 六、关键设定沉淀

- **化凡/断凡**：三次化凡是终点，三次之后为断凡。
- **本源与境界**：集齐九道本源方可踏入空玄境界；空玄之后需度九次玄劫。
- **庙宇制度**：绿魔蝎庙一类庙宇须仙皇传诏方可修建，无诏不建（天牛洲即无天牛庙）。
- **洲际地理链**：天牛洲 →（崩溃的丹海）→ 绿魔洲 →（边界高山山脉）→ 孟土洲。
