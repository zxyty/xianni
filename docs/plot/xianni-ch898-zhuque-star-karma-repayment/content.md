# 第898章 雷吉（之1/2·段3/3）：朱雀星了因果

## 一、开场：蜈蚣之疑
王林望着蜈蚣消失之处，眉梢皱起，觉此事透着诡异，不愿轻举妄动，沉默片刻后身形一晃，前往云天宗。

## 二、云天宗·铁岩之因果
- **铁岩的现状**：盘膝坐在广场上等待王林（笃定王林必来）。修为已由婴变退化至化神后期，无法再次突破，寿元被慢慢消耗殆尽。
- **退化之因**：一百年前的“意外”——周茹以自身修为不可能走出朱雀星，铁岩为成全她，以自身生机寿元为代价，配合能弄到的大部分仙玉，并在**朱雀子周武泰**的帮助下，使周茹的修为勉强达到婴变，从而离开朱雀星。铁岩称“心甘情愿”。
- **王林的了断**：斥一句“胡闹”后不再多言。
  1. 拍储物袋放出大量仙玉，虚空一抓将其尽数崩碎，化作无数仙气凝成絮状之球，按入铁岩体内，铁岩体内如火焰燃烧，修为飞快恢复。
  2. 再取出大量仙玉，堆积广场如小山。
  3. 赠九把长剑：九道长虹破空落地，剑气交错成风暴横扫天地，王林声音自虚空传来“此剑送你”。
- **王林的因果宣言**：“你因周茹修为退化，此为因，我帮你恢复修为，便是果；至于这些仙玉，权当王某感激你对我王家后人的照顾，从此之后，王家之事，莫要再理，安心修炼去吧。”

## 三、因果之道的明悟
- 了却云天宗因果后，王林天灵之上**阴阳双鱼之相**幻化并缓缓旋转，因果意境骤然生变，明悟更深。
- 王林所悟：“第二步修道，意境的明悟是重点。因果意境，一切有因必有果，只有因果产生循环，才可一次圆满，无数次的圆满，方可真正的自成因果。”此番回朱雀星，暗中契合了因果之道。
- 行事准则：“一切当年对我有恩者，要报答；一切当年我之过错者，要了却因果。”
- 随后神识如风暴般散开蔓延，**朱雀星所有位置皆有王林神识存在**。

## 四、报恩之一：赵国合欢宗·张虎血脉后人
- 地点：朱雀星，五级修真国**赵国**·合欢宗后山洞府（内门弟子专用打坐处，灵力高出外界数筹）。
- 处境：该女子为合欢宗**外围弟子**，外界灵气不足以支撑其达到练气第九层，唯有此地可突破；代价是被同门以“月前承诺”相胁——在其洞府修行一月，需做双修道侣三日（尚余四天满月）。
- 血脉：族谱载先祖**张虎**亦为修士，千年前拜入**恒岳派**；女子自叹“千年福泽至今日，我却只能成为合欢宗外围弟子”。
- 王林所为：白衣青年无声无息现身，拍储物袋放出灵石、仙玉，其中另有一把飞剑，留话“我与你先祖有旧，当年之因，今曰之果”后转身离去。张虎已死，王林是以神识横扫时察觉此女身上一丝张虎血脉。

## 五、报恩之二：火焚国战神殿·杨雄与周紫虹
- 地点：四级修真国**火焚国**·战神殿大殿。
- 情形：周紫虹（宫装美妇）与杨雄（相貌年轻却带沧桑）修为俱为化神后期。仙玉不足以供二人同时吸收，杨雄让与周紫虹冲击婴变——“若是你能达到婴变，我火焚国，就可晋级”。
- 情感线：周紫虹提出“若我能婴变成功，你我二人便做双修道侣”，说时心中幽叹，脑中浮现当年一人身影；杨雄以“寿元已经不多”推辞，并言“况且，我听说他已经回到了朱雀星”。
- 二人相貌数百年不变，源于**当年域外战场王林所赐灵液**。
- 王林现身，一句“杨雄、周紫虹，别来无恙”，随即散出大量仙玉弥漫大殿，又留下一些丹药，抱拳道“你二人能结成连理，这些仙玉，便是王某之礼”，转身踏空而去。

## 六、故人之三：巨魔族·叱虎
- 叱虎已成**巨魔族族长**，修为**婴变后期**，距问鼎只差一线；凭强悍肉身与觉醒的少量天赋神通，即便问鼎修士也敢一战。
- 巨魔族（五级修真国）数百年间已成为朱雀星的中坚之力，占据相当地位。
- 叱虎知晓王林归来，亦以神识看到了王林与大头童子一战，内心复杂；打坐中骤然睁眼，见王林身影“好似永恒的存在”。
- 本段以王林一句“叱虎兄，好久不见”收束。

## 七、要点提炼
- 本段是王林“第二步修道·因果意境”的实践章：以仙玉、法宝、丹药系统性偿还朱雀星旧恩，同时借此暗合因果之道而境界明悟加深。
- 仙玉在此被展示为可直接崩解为仙气、用以修补寿元与修为的顶级资源。
- 王林明确切割王家俗务：令铁岩自此不再理会王家之事。

# 第839章 了却因果

## 一、赠别叱虎（巨魔族）

- 「曾牛」这一称呼令叱虎苦涩，久久无言；王林只道**“往昔之事，莫要再提了。”**
- 王林一拍储物袋，**大量仙玉飞出，落在四周堆积如山**；又取出一个小瓶，内装**雷吉之血**。
- 交代：
  - 仙玉可供叱虎**修炼至问鼎期**；
  - 小瓶内为其**巨魔族先祖之血**，可助其**天赋神通之威**。
- 王林长叹离去，叱虎怔怔望着其消失之处，眼中复杂之色更浓。

## 二、修魔海：李奇庆的复仇与困境

- 地点：**修魔海**内一处充满骸骨之地。
- 人物：沧桑老者，**修为化神后期**，正打坐吐纳、吸入大量**阴气**。
  - 面部青筋鼓起、浮现**网状黑纹**（血纹），靠吸阴气生生压制；事毕疲惫、汗透全身。
  - 咬牙立誓：**“赤血老祖，此仇我李奇庆若不报，誓不为人”**，恨意滔天。
- 身外百丈有一圈**淡蓝色痕迹**（护身/禁制之属）：数头修魔海妖兽循气息而来，一触即凄厉惨叫、迅速枯萎。
- 李奇庆冲出，双手撕裂妖兽、咬住颈部**吸干精血**，数头妖兽尽成干尸，面色略有红润。
- 背景交代：
  - **李奇庆是李慕婉之兄**，李慕婉在这世间**唯一的亲人**。
  - **赤血老祖**即当年**追杀李慕婉**之修士；李奇庆不惜代价查到其藏身修魔海，潜伏欲报仇。
  - 因修为不如，**反被种下血纹**，生不如死；每次血纹爆发都会让赤血老祖知晓其方位，故须速离。

## 三、王林现身·避天棺见妹

- 王林一步走出，现身李奇庆身前数丈。李奇庆震骇退后，喝问**“你到底是谁”**——他久前见过王林，数百年中更见过王林的**雕像**，却不知王林已回到朱雀星。
- 王林一拍储物袋，**避天棺**在晶光闪烁中飘出：**李慕婉安静躺在里面，嘴角还带着一丝微笑**。
- 李奇庆身子颤抖，狠辣尽消，泪流唤“妹妹”，自责：**“爹娘走前，让我照顾你……是哥哥没用，没有照顾好你”**。王林默默站在一旁。

## 四、赤血老祖之死

- 三道剑光呼啸而至：当前赤红剑光上立一老者，**修为婴变后期**，一脸狂傲；身后两名中年男子敬畏随行。
- 老者冷笑“李奇庆，我看你能逃到那里”，旋即看见棺材、棺内李慕婉与王林：
  - 察觉**避天棺有浓郁仙气散出**，眼露贪婪；
  - 目光转到王林身上时觉眼熟，被王林冰冷一眼**震得剑光崩溃、退后数步、喷出一口鲜血**，随即认出“王……王林”。
- 老者魂飞魄散转身欲逃，抓起身边两名弟子抛向王林并低喝“爆”——其门下弟子体内皆种有**操控封印**，两人当场爆开化作大片血雾冲击王林。
- 其心中之刺（回忆）：当年在**火焚国与修魔海交界处**追杀一名女修（即李慕婉），一名小辈救人后被其追击、踏入修魔海；后来他认出**「曾牛」正是那小辈**。又见**仙遗族与朱雀国之战**中曾牛大放异彩，并知晓**朱雀子周武泰的位置系王林所赐**，故一直谨慎，好不容易等到王林离开朱雀星才松口气。
- 王林由其一句话即推知前因后果——此人前来是为追杀李慕婉之兄，二人仇隙极可能与当年之事有关——遂起杀机：
  - **大袖一甩，自爆血雾倒卷**，直奔赤血老祖，将其全身包裹；
  - 赤血老祖欲瞬移已晚，惨叫声中王林**右手向前一拍**，血雾内再涌血气，最终全部消散、**化作虚无**。
- 全程李奇庆未抬头，眼中只有李慕婉。

## 五、了却

- 赤血老祖死亡后，**李奇庆脸上的血纹被破除**。
- 李奇庆最后细看棺中妹妹一眼，起身**始终不看王林一眼**，转身远去——以冷漠表明**不愿与王林有任何瓜葛**；王林未阻拦、未言语。
- 王林收避天棺入储物袋，踏空而去，望着脚下**处于半废弃、灵力极少的朱雀星**，自语：**“一切的因果，已然了却。”**
