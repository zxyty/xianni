# 第2040章 不宣于口！

## 一、天下震动：太古神境提前且「完全」开启

仙罡大陆天空黑白八次交替之际，太古神境（原文多处误写为「太吉神境」）的开启迹象传遍诸族。

**仙族一侧**
- **祖城帝山·久帝大天尊**：出关悬空，断定此次开启「是从古族那里打开」，且时间大幅提前——「太古神境的开启本不会提前」。
- **海子**（白衣女子）：告知这是太古神境**第一次完全的打开**，与以往大为不同；她推衍不到全部，只推算出「此番开启需等待数百年」。久帝因「完全开启」而难掩激动：若完全开启，其中**或有超越大天尊、成为等同仙祖那一层次的方法**。
- **道一宗**：多年来阴森缭绕、强者莫名死亡、道一大天尊闭关不出，人烟稀少。本章山峰崩溃，一道**灰气缭绕、神色狰狞**的身影飞出，念着「太古神境那里或许有让我完全驱除诅术、且修为更进一步的办法」。
- **紫阳宗**：两个可爱小女孩闭关处，二人之间悬着**仙祖的眼珠**散发奇异之芒将其相连，此刻同时睁眼，目光穿墙望向同一方向。
- **冰封之地·武封**：仙族最早发现太古神境出现迹象者，立于冰山之上，目露期待。
- **祖城皇宫地底重叠空间**：一座由**疯子**所化的山峰，一动不动。

**古族一侧**
- 极古的大天尊、始古的大天尊同样有感。
- **玄罗**早已察觉端倪，望着王林去往的荒山与天空异常；沉入道古皇宫地下的**圣皇祖**再度飞出，立于玄罗身边，震惊看天。二人对视，**沉默不语**。

**吉族一侧**
- 三脉连接中心区域**古道山**高塔中，迷雾身影立于塔窗，叹息：「终于还是被完全打开了……当我知晓了一切的那一天，我就知道，我无力去改变」，罕见露出复杂苦涩，喃喃「数百年后无量劫」，并诵出偈语。

## 二、偈语（关键线索）

迷雾身影：「众生需度无量劫，离开深渊一执念，奉旨修真行」

道古国师（在无数喃喃杂音后化作清晰一句）：
> 「囚封天之道，众生需度无量劫，离开深狱一执念，众生亦于无量前，解今芒世，脱困天念，取来生道奉至修真行」

二者同源，指向「无量劫」与囚封天道之秘。

## 三、第九柱：阵法穿界与苍茫海竖起

1. **阵法穿界**：崩溃荒山下的阵法内，那「既像天运子，又如七彩」的**道古国师**掐诀按入阵中、诵出偈语。阵法大放光芒，先前阻拦王林的**隔界之网**一一破开裂缝——此阵竟从其所在空间**生生传入仙罡大陆**。
   - 对比：此前该阵只是**虚幻投影**，王林闯入时几乎动用全部修为与破界之力；如今它以同样方式挪移而来，**成为真实存在**。
2. **真身归位**：随阵法一同而来的还有王林的**杀戮真身**，与本体同处一空间；真身后退数步重回本体，融合完毕，王林闪身退至光芒之外。
3. **第九柱成形**：国师低吼，阵法爆发**十色光芒**冲天，远看如**第九根通天之柱**。国师嘶吼「第九柱，开太古神境」，光柱化长虹直奔仙古连接的**苍茫大海**。
4. **海上格局**：大海上已有**八根通天之柱**围成圆；圆内海水化为雾气，圆外仍是水。长虹至，第九柱于圆心上方凝聚，天地震动，波纹扩散至整个仙罡大陆天空。
5. **苍茫海升起竖立**：第九柱下沉落入圆心的一瞬，苍茫大海发出回荡全陆的巨响并**缓缓升起**，露出海底世界（淤泥、坑洼、歪倒海草）。海水升过仙族与吉族地面后仍在上升，继而**转动半圈、直接竖起**——原本的「范围」逆转为「深度」。
   - 力量层级：抬起此海之神通**绝非大天尊可施展，连古道大天尊都做不到**。
6. **门的成形**：竖起的海洋如巨墙，横亘于古祖（古族）与仙族之间；它环绕中心九柱旋转加速，化作连接天地的**海水风暴**。风暴内，九柱散发光芒**组成一座巨大的门**——**此门紧闭，尚未开启**。

## 四、五百年之约与临别问答

- 道古国师留言：「**可惜你杀戮不够**，否则可以立刻打开此门；如今需**五百年**时间酝养，才可拥有开启此门之力。那么，王林，我们五百年后，于这**太古神境**内再见——当我们再次相见之时，**你会知晓一切真相**。」
- 王林发问：「**东临宗，是你毁灭的吧。**」
- 国师**长笑不答**，身影烟消云散，阵法散去，此地依旧一片废墟。

## 五、王林的抉择与「不宣于口的师尊」

王林沉默许久，化虹而去。道古一脉于他已无任何留下的理由，一切成为过去；但**有一个人**，即便他曾以「死亡一次」报答恩情，内心却依旧将其当作自己的**师尊——不宣于口，却印在心中**。
