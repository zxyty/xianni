# 第1336章 晋升闪雷榜（第九卷 云海之巅）

> 世界状态须知：本章「于非」的一切言行归属【王林】——王林自第1242/1329章以一部分元神夺舍于非之身，冒其身份潜入闪雷族。闪雷族上下（钟大洪、雷晶殿三老者、榜单议论者）均认其为于非。

## 一、穿越雷雾裂缝：窥破「化雷为雾」

- **场景**：通往雷晶殿的入口是一道约十丈宽的青色雾气裂缝，雾内雷霆电光闪烁、轰鸣隐传。修士入内皆生敬畏，不敢近雾气边缘，只择裂缝中心飞行。钟大洪虽非首次前来，仍心惊谨慎。
- **王林的洞察**：他看出此雾并非真雾，而是充满闪电雷霆——是被人以大神通自**雷域**内摄来，在此捏碎成雷雾，配合独特神通起防护之用。心神一动即可令雷雾收缩、形成封困，变化无穷。
  - 感慨：闪雷族对雷道的钻研，已能「把雷化雾」，使有形之雷化作随意变形的无形之体，防护效果隐隐可比他的「呼风唤雨界」。
- **可乘之机**：闪雷族从未想过会有外人来临，雷雾常年摆放于此；裂缝开启即等于防护打开、核心展露人前，可任意查看。
- **动作**：王林神识骤然散开直冲雷雾，瞬息弥漫其内。因其神识太过强大，稳压雷雾使之无法反抗挣扎，任其摸索，很快**逆行推衍出施展此术的印记与变化**，学会了闪雷族秘传绝学之一「化雷为雾」。
  - 若非裂缝开启，他需谨慎且耗时甚久，才有机会看到其本源凝聚神通之法。
  - 因王林**神识本身也是雷**，以雷感悟雷，外界看不出半点破绽。
- **前提条件**：王林**元神即是一道雷霆，与不灭之雷同等**，故能破开外界雷域混入闪雷族。雷域之强，唯第三步大能可无损踏入，余者不可能进来。
- **结果**：穿出裂缝的瞬间，神识收回体内，双眼精光闪烁，隐现一个符文——**化雷为雾的精髓道义**。作者点明：古往今来，能在入雾过程中即侵入雾气、看破本源并逆推神通者，王林是第一个。

## 二、雷晶殿：格局与四层空间

出裂缝后，前方是一座高耸山峰，峰顶一座极为奢华的大殿，其上雷电游走组成三字——**「雷晶殿」**。

钟大洪介绍（王林早已从其记忆中知晓，故作不知）：

| 门 | 用途 | 准入 |
|---|---|---|
| 东门 | 换取雷晶 | 族人皆可，人流最多 |
| 南门 | 以雷晶换取法宝、丹药、功法 | 族人皆可 |
| 西门 | 族中发布任务处，完成可得大量雷晶 | 唯大神通修士可入 |

- 王林一眼看出大殿蕴含**空间之意**：看似一座，实为**四层空间**。东西南三门各通一处；另有第四处**并无进入之门**，神识扫过发现其内有**九股气息吐纳**——**窥涅五人、净涅三人、碎涅一人**。
- 王林令钟大洪留下，自己独往，临走时再通知。

## 三、东门兑换与人情世故

- 东门修士最多，出来者多有兴奋之色藏得很深、匆匆而走；亦有存活太久的老谋深算之辈，进出皆神色平静不露心思。
- 叙述点评：心机与性格、年纪相关；**王林两千年修道，看透一切，心机之深不弱于万年老怪，甚至更有超过**——在修真界，除修为外，心智是能否存活的重点。
- 王林在门外先观望半晌，神色冷漠作生人勿近状；此地无人识他，故无人搭讪。
- 入东门即进入一处开辟出的空间：前方一个**巨大黑色池子**，内有大量泥浆之物，时而鼓起气泡。池旁盘坐**三名老者**（一人**阳实**，两人**阴虚**），体内外弥漫雷霆之力。
- 王林右手在眉心印记一拍，大量换取雷晶之物宣泄而出，轰然落入池中被泥浆一口口吞噬。半晌未完，三老者睁目细看——极少见有人一次性拿出这么多。
- **修为伪装**：王林身上修为可随心神转动随时在人前变化，此刻三老者眼中他是一名**问鼎修士**。
- **记账**：取出**于非之物、有其命魂所在的记录雷晶玉简**抛入黑池；池中传出闷闷咆哮轰鸣，泥浆翻滚后玉简飞回其手。

## 四、闪雷榜剧变：「于非」入榜第799位

- 与此同时，闪雷族**所有修真星**上族人手中的**闪雷榜玉简**齐齐传出波纹，代表榜单发生变化。
- 规则：雷晶殿每年开启三天，是闪雷榜剧烈变化之日；但前八百名字极少更改，最多排名不同。此次波纹极为剧烈，只有一个解释——**有新人进榜**。
- 榜单变化：
  - 第一位仍是**云杉子**，雷晶数由**十九亿七千 → 二十四亿九千**。
  - **第七百九十九位：于非，雷晶四十六万四千**，仅比第八百位高出三千。
- 族中议论（十三颗试炼星各处）：
  - 「于非此人不知是哪个试炼星之人，一下子就进入了闪雷榜」
  - 「族人众多不可能都认识；能进榜必有过人之处，虽排名最后也不可小看」
  - 「这名字倒也好记，于非……不知能否稳定至三天后」
- 因闪雷榜只有 800 人，能入榜即刻成名，「于非」之名被众多闪雷族人记在心里。

## 五、要点与伏笔

1. **收获**：王林白得闪雷族秘传绝学「化雷为雾」，且无人知觉；若闪雷族知晓，定会震惊骇然。
2. **身份立足**：以「于非」之名成功登榜，从无名之辈变为全族皆知，为后续在闪雷族内部行动铺路。
3. **潜在风险**：入榜即出名，三天后排名能否稳住成为族人关注焦点；本尊真实身份仍未暴露。
4. **实力对比**：雷晶殿第四层空间坐镇九名强者（碎涅一、净涅三、窥涅五），是闪雷族重地的守御底牌。
