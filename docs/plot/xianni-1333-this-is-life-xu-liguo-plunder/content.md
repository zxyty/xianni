# 第九卷 云海之巅 第1333章 这才是生活

> 世界状态须知：王林自第1242/1329章起以一部分元神夺舍「于非」之身，冒其身份潜入闪雷族；本章「王林」在天雷宗内的行事即其本人（以于非之身/身份立足闪雷族）。

## 一、一月之期与雷晶积累

- 时间在闪雷族修真星缓缓流逝，王林已在闪雷族滞留**一个月**。
- 这一月中王林**未回原洞府**，而是选在**天雷宗山门**闭目打坐、盘膝吐纳。
- 许立国与钟大洪以**天雷宗为中心向四周横扫**，搜刮大量可换取雷晶之物。
- 结果：凭这些物品，王林**可换取近十万雷晶**。

## 二、许立国：极尽张扬的「这才是生活」

### 排场
- 许立国难得从**储物裂缝**内走出，兴奋激动之下在天雷宗外展开疯狂行动。
- 不喜独自行动，带十多个天雷宗**筑基弟子**，所过如蝗虫；以其独特手腕，**凡遇结丹修士就立刻收为麾下**。
- 短短一月，跟随的闪雷族人**已达近百**。
- 命族人以竹木造**约百丈大小的宝座**，其上光芒万丈；数十修士扛抬，前方数十修士开道，后方及左右亦然。
- 专选两个嗓子特别洪亮的结丹修士沿途大吼：**「许爷爷出行，气势如虹，气吞山河，盖世无双，英俊潇洒，无与伦比」**。
- 宝座上除**四名闪雷族女修**（陪伴、奉果、奉酒、揉捏其隐隐化作实质的身体）外，还有**四名俊俏男子**半跪伺候。

### 心声
- 「这才是生活……那煞星这两千年来东走西奔的，哪里有许爷爷我快活」——自认聪明，人生得意须尽欢。
- 承认若非被王林（煞星）抓住，也可能早已**寿元断绝而亡**。
- 目标：把这**两千年失去的人生全部补回来**——想要一百一千个女修、一千个男修、上万个抬宝座并大吼之人。

### 破陈硐风洞府
- 一名结丹修士来报：前方百里是**元婴后期老怪陈硐风**的洞府，对方已有察觉，洞府外禁制全开，另有**八只小旗**悬于山峰外急速旋转、化黑雾弥漫。
- 许立国当众抬手一挥：无尽剑影凭空幻化，剑啸惊天、剑气使风云倒卷、天空一暗；四周修士身颤如置身九天玄冰。
- **实力定位**：许立国身为**剑灵**，又获**远古剑意传承**；虽为人懒惰，但在**四圣宗时被王林封印**，不得不全力修炼。此刻神通「莫说这区区元婴小辈，就算是问鼎、阴阳虚实、乃至窥涅修士，也都不是其对手」。
- 剑气瞬息崩溃黑雾，八只小旗将爆之际被其**虚空一抓收下**——因「那煞星可是说了，任何一样法宝都不可损坏，这可全部都是换取雷晶之物」。
- 剑气横扫使整座山峰层层瓦解消散，只留一个没有墙壁的空洞府，陈硐风呆坐其中。
- 随从大吼「顺许爷爷者献上所有换取雷晶之物，逆许爷爷者废掉修为，禁锢终生」，陈硐风毫不犹豫抱拳：**「晚辈愿意献出一切。」**
- 许立国收其为麾下并追问何处有女修。

### 新目标：雷仙道
- 陈硐风告知：此地**数十万里外**有宗派名**雷仙道**，内中**均为女修**，宗主**美艳绝伦**、修为颇高，据说**与闪雷族一名内族族人有旧**。
- 许立国一听「美艳绝伦」眼中冒光，不顾修为高低，大手一挥：「带路，随许爷爷我去抢人抢宝」，一行人浩荡飞去。

## 三、钟大洪：谨慎搜刮与「无敌之术」之争

- 钟大洪修为只有**化神**；为让其完成任务，王林**赐其一把飞剑**。此剑寻常，但对修道第一步修士而言如至宝：可与**化神中期**修士一战，遇**化神后期**也可抵抗片刻。
- 行事远比许立国谨慎，虽也带一些修士，却没有那般快活。
- 优势：**熟悉闪雷族**，知何物换雷晶更多，且知晓不少洞府所在；获王林赐**丹药与法宝**后精神振奋，认定此生造化已至——只要把王林伺候好，说不定还会再得丹药。
- 暗自提防许立国，视其为**生平劲敌**：认为许立国无耻至极、也修炼**「无敌之术」**（即拍马屁奉承之术），修为更高想必是跟王林日久、靠此术换来。
- 自评在无敌之术上**天分很高、暗中钻研数百年**，之前尚未全部发挥，如今大敌当前要拿出十二分本事一斗。
- 行动中连毁数个洞府展开搜刮，并暗中酝酿见到王林时的种种说辞，以求随时施展无敌之术。

## 四、王林：参悟聚雷印，图谋族印与不灭之雷

- 王林平静盘膝坐于天雷宗内，面前一枚玉简，内印闪雷族族人修行的功法**聚雷印**。
- **聚雷印**：可把体内雷霆之力在**瞬息间压缩数倍**，以换取强悍爆发力；**需族印配合**，长期修行之下**可使族印缓缓开启**。
- 王林研究此功法的**目的**：把闪雷族的**族印**摸索清晰。
- 他**隐隐感觉，这对自己吸收「不灭之雷」极为重要**。
