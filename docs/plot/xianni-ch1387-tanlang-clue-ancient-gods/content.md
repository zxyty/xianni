# 第九卷 云海之巅 第1387章 线索（第二更）

## 一、场景与态势
- 地点：颠落之地星空。
- 局面：贪狼法宝再度被王林夺走后疯狂逃遁，王林紧追不舍，形成一路轰鸣的追逃战。
- 沿途惊动颠落之地诸多族落，但众族一看二人速度便知修为绝强，纷纷不去理会。

## 二、第一回合：一叶封天
- 贪狼察觉前方星空有波纹回荡（王林即将现身），立刻调头，抓出一片巴掌大小的枯黄树叶甩出，喝「一叶封天」。
- 树叶落处爆发黄芒与浩荡封印之力，放大无数倍印在星空，把波纹彻底封死，波纹无从挣脱。
- 贪狼随即双脚紫光一闪，化出两团紫雾、凝成两个**古魔样貌的紫色魔影**，脚踏两魔，速度更快，转眼消失。
- 王林自波纹中走出，右拳隔空轰击树叶封印：树叶纹丝未动，反震浩荡。王林瞳孔一缩，未硬抗，身融天地、以**缩地成寸**绕过树叶继续追。
- 贪狼自得：「老夫的这一叶封天，即便是天人第五衰修士想要破开也需一番周折」，并断定王林修为不至于天人第五衰。
- 贪狼能**提前知晓王林到来与准确方位**（手段未明），遂再度甩叶封印前方虚空。他自陈：逃遁之术为其最强神通，否则身上这些法宝早被人窥伺夺杀多次。

## 三、第二回合：血剑重创贪狼
- 远处星空血光惊天而起，转眼笼罩星空，如洪如大口般吞噬贪狼。
- 血光穿身而过，砰砰声与金石碰撞声大作——贪狼身上竟穿有一套**隐匿铠甲**（乌光），此刻胸口铠甲出现大片蔓延的裂缝。
- 贪狼被抛出、喷出大口鲜血、面色苍白；血剑被震退数十丈。
- 贪狼挥手将脚下两魔影化作两道黑气，绕身形成黑色风暴，卷着他急速逃遁。
- 王林自树叶封印处走出，重伤的贪狼已无法操控树叶——王林一抓夺得枯叶，**当即打上大量禁制封印，未及研究即收入储物空间**。

## 四、王林的判断与目的（本章「线索」之核）
- 兴奋所在：每次遇到贪狼都获极大造化、得众多法宝。当年贪狼一身法宝几乎被自己弄尽，本以为其已死，今日再见法宝反而更多。
- 对其性格的判断：不逼急了就不会像方才在修真星上那样一次拿出数样，只会**一样一样地挤出**。
- 两大待解之谜：
  1. 这些法宝究竟从何处得到；
  2. 贪狼**到底以何种方式进入的太古星辰**——王林认定这是自己必须知晓之事。

## 五、第三回合：三百古魔魂 vs 古神之吼
- 贪狼取出**黑色（紫色）玉瓶**：通体冰寒、魔气弥漫、瓶外雕满古魔图案。
- 献祭方式：喷血于瓶，大吼「借我三百魔魂，封杀此人后，奉还三万生灵之魄」；瓶身刺出两根利刺扎入其手指，大量吸取其血液，瓶内传出意犹未尽的叹息。
- 黑雾如火山喷发，化作**三百尊头生单角的古魔魂**，双目透出疯狂怨毒，似被压制万古；每尊修为相当于**天人第一衰**，绕贪狼旋成魔之风暴，扑向王林。
- 王林一眼认出：这些古魔样貌与**当年的塔珈**极为相似；唯一不同在于**左目瞳孔中没有星点，而是一团浑浊气流缭绕**。
- 王林眉心的**古神星点自动幻化旋转**，他确认那气流正是**古神之力**凝聚，电光石火间判定：「这三百古魔，是被某个强大的古神封印」。
- 王林体内砰砰作响，仰天发出**古神之吼**（非法术神通，而是以眉心古神星点引动磅礴古神之力）。魔之风暴生生停住，三百古魔从吼声中感受到古神的存在、忆起记忆深处当年一幕幕，恐惧至极，风暴自行崩溃、四散溃逃。
- 贪狼愣在原地，不解自家至宝为何被一吼崩溃离析。
- 王林狂喜：「我终于知道，你贪狼到底是在什么地方寻找到的这些法宝……没想到你竟然能去了那里」，一步迈向贪狼。

## 六、遗留悬念
- 贪狼进入太古星辰的方式、其法宝来源之地（王林已推断出，文中未点破地名）。
- 枯黄树叶「一叶封天」的来历与本质（王林已封印收起，尚未研究）。
- 贪狼预知王林方位的手段。
