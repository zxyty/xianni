# 第七卷 名震罗天 第838章 冰云

## 一、望月新生之秘（狭长空间内目击）

- 王林双手掐诀按于胸口，连点数下后**全身气息瞬间隐匿**，只留一丝神识观察外界。
- 不远处一名被触手缠绕的**干瘦老者**成为异变中心：原本毫无生机，此刻阴寒之气自体内散出，同时一股庞大生机狂猛涌现。
- 王林凭修为与**曾经的生死轮回意境**，察觉老者身上除生机外还藏着一股**死气**，被生机完全压制。
- 老者身躯急速膨胀，全身骨头砰砰碎裂，失去骨骼连接后更为庞大，终成肉球；双眼始终闭合，无苏醒迹象。
- 皮肉之下出现细长鼓包游走钻动，体内传出**尖锐闷啸**——此声王林极为耳熟，闻声面色立刻难看。
- 肉身裂开缝隙，狂猛阴寒之气冲出，四周无数触手摇曳，仿若欢迎同类新生。
- 一头**两丈大小的新生望月**自裂缝挤出，须发尚呈透明；老者肉身彻底崩溃，无任何血肉残留。
- 新生望月反身一吸，将老者肉身完全吞噬，又吞噬四周阴寒之气，**片刻间由两丈涨至十丈**，触须转为暗红色，样貌狰狞。
- 望月化作闪电直奔前方**漩涡出口**，无任何阻碍穿透而过消失；此后触手恢复原状，阴寒之气被吸收殆尽，四周复归平静，只是少了一个人。

### 王林的推断

> 按**涂司的记忆**，望月一旦离开古神之体，时间久了必死无疑。

王林由此推断：此地望月数量之多，是因为望月不但没死，反而**借修士与凡人的身体凝聚新生**，几乎形成了一个循环——无数年来必然发生过一场惊人剧变，否则绝无可能。王林自认对望月极为了解，此刻已猜出十之七八。

## 二、夺取大鼎控制权

- 待外界安静，王林神识散开，凝聚于大鼎外的**烙印符文**之上，与其上**贪狼神识**狠狠相撞。
- 贪狼修为即便巅峰也与如今王林伯仲之间，加之重伤，留在鼎上的烙印极为黯淡，被王林神识一冲便崩溃消散。
- 王林随即把**自己的神识烙印于符文之上**，夺得操控权。
- **贪狼的来历补充**：当年经历九死一生的危机得到大鼎，明知是宝却无法操控，费尽心机想到简易操控之法，历经上千年求得符文，仔细刻于鼎上方能操控——此刻凭白便宜了王林。
- 烙印落成刹那，一股奇异而**亲切**的感觉弥漫心间，并与其**元神外的古神皮甲**产生一丝联系；但如雾中花般模糊，中间似有隔膜。
- 原因：王林所用是**贪狼之法的捷径**而非正确操控方法，虽简单可用，却无法彻底发挥大鼎威力。
- 王林之志：「只要回到了**联盟星域**，此鼎在**本尊**操控下，定可发挥出其应有的威力。」

### 神通「移形」

- 掐诀神识一动，大鼎嗡然震动，波纹散开，鼎内涌出浓郁**白气**环绕全身，王林感到自身与大鼎融为一体，「仿佛他就是这鼎一般」。
- 低吟「**移形**」二字，大鼎一震消失原地，出现在缠绕的触手之外；诡异的是那些触手一动未动，仍保持原姿态，仿若鼎仍在其中。
- 王林自鼎内飘起，体外白气弥漫，如踏云雾之仙人。

## 三、对姚冰云的处置

- 王林此前神识蔓延大鼎时已察觉姚冰云，因专注烙印未细看；夺鼎后方有暇观察。
- 冰层中姚冰云半裸娇躯、相貌绝佳，闭目时褪去往日冰霜，反显楚楚动人；王林**毫无表情，眼中平静如水**。
- 判断：此女功法奇妙，**元力分离**情况下仍能保护自身、封锁体内一切，使望月无法吸收（施展的是**闭神仙术**）；但她太小看望月，王林断定这冰封过不了多久便会崩溃。
- **报复的因果理由**：「你追击王某这些时日，两次险些让我损命，若不报复，便不是王某因果之道。」
- 手段：以食指按冰层，庞大元力融入，冰层大片开裂，裂缝在其身体一寸外停止；王林反复运元力按压，冰层大片脱落，最终只剩一寸。
- 决断：「此女在姚家三代弟子中，也定然是佼佼者，姚家既然要杀我，那我便把此女**炼化成为仙卫**，即便失败，也没有关系。」——只要是敌人，不管男女，绝世女子亦无怜惜。
- 心中比较：此女虽美，**还是不如当年的柳眉**。
- 王林张口喷出**元神精气**环绕冰层不断消融，右手连续点按，一寸冰层开始碎裂。
- 若姚冰云元力恢复施展闭神仙术，绝不会如此轻易被破；**元力分离**给了王林机会。
- 姚冰云绝想不到此地除她之外还有王林，更想不到王林因**古神皮甲**之故体内元力未被封印、可自由行动。

## 四、章末转折

冰层大范围碎裂的刹那，**姚冰云缓缓睁开双眼，看向王林**——悬念留至下章。

## 关键要点

1. 望月生态之谜揭开：望月已能借修士/凡人肉身孕育新生，形成自持循环，与涂司记忆中的「离体久必死」形成对照。
2. 大鼎易主：贪狼千年心血的符文捷径反成王林的钥匙；但捷径限制了威力上限，埋下「回联盟星域后本尊正统操控」的伏笔。
3. 古神皮甲的双重作用：既使王林元力不被封印、可自由行动，又与大鼎产生联系。
4. 姚家恩怨升级：王林以「因果之道」为由，欲将姚冰云炼成仙卫。
