## 章节定位
《仙逆》第1807章「思念贪狼！（第三更）」，承前章王林在天牛洲以地火重创苍龙宗之事，本章为其藏身、悟本源与强开储物空间的过渡关键章。

## 一、苍龙宗之乱与全洲搜捕
- **事件扩散**：苍龙宗被一名「王姓的神秘修士」引动地火焚烧，牵动地火分支脉魂，横扫数万修士，重创四大长老——毁去三人肉身、断去一人双臂。消息如狂风般传开。
- **苍龙宗反应**：震怒，派出所有弟子疯狂搜寻；数日无线索后，老祖**杜青**怒火更盛，索性亲自外出，神识散开横扫八方，仍一无所获。
- **各宗态度**：
  - 大多数宗派素来不喜苍龙宗，但碍于杜青修为、碍于其身后的**大魂门**而始终退让；如今见苍龙宗损失惨重（数千门人被杀、四长老重伤），暗自高兴，配合寻人多是敷衍了事。
  - 亦有一些宗门全力配合，层层搜索王林藏身所在。
  - **归一宗**、**大魂门**这等庞大宗派，很少留意此等事。
- **地域尺度**：天牛洲太大，如此轰动的消息也只在一片区域内传开；一人若要躲藏，不亚于大海寻针。

## 二、王林的藏匿
- 苍龙宗弟子的神识曾横扫王林所在山峰，因距离很远、王林禁制不凡，未被发现任何端倪。
- 判断：除非杜青亲临查看，否则旁人不可能看出问题；而杜青在不知具体位置的前提下亲来的可能不大。
- 时间推移中，苍龙宗搜寻不减反增、愈发严密，王林在思考储物空间问题时对此有所察觉。

## 三、一月苦思：仙气吐纳与本源之辨
王林在洞府中用一个月时间做两件事：思考储物空间难题；吸收吐纳**仙罡大陆**的仙气滋养全身，同时寻找此地本源与自身本源的不同。所得：
- **虚之本源**：无碍。无论在洞府界还是仙罡大陆均未改变——因其乃王林感悟意境所化，属于他自己的诞生之源。
- **实之本源**：如火本源一般有所不同。**雷、火，以及小成的水本源**皆是如此。
- **杀戮、禁制**两道本源虽也有改变，但改变不多。

## 四、决断与开启储物空间
- **心态**：王林本非优柔寡断之人，唯因储物空间太过重要才久久犹豫；此刻「不能再犹豫下去」，目露果断。
- **决定**：「就算是毁掉，也要打开取出一些物品」——其内大都是身外之物，既然能获得积累，在仙罡大陆同样可重新得到新法宝；且若速度快些，或许空间不会完全崩溃。
- **手法**：
  1. 全身修为蓦然散开，全力凝聚于洞府内，不让其外泄散出；
  2. 修为波纹愈浓，四周出现如涟漪般缓缓回旋的扭曲，气息近乎凝固，洞府内一切流转隐隐变缓（如同把洞府变成淤泥）；
  3. 目的即为**延缓储物空间出现后的崩溃**，为自己争取时间；
  4. 左手抬起掐诀伸出食指，**定身术**弥漫指尖；
  5. 右手抬起，咬牙向前方虚空猛地一抓。
- **结果**：前方顿时幻化出一道裂缝——正是王林的**储物空间**。这一抓他曾无数次施展，却从未有一次像此刻这般心惊。

## 悬念
储物空间裂缝已开，能否在其彻底崩溃前取出法宝，留待下章。

# 第1715章 储物空间崩溃与血剑金印

## 一、定身术的进化
- 王林凝聚于左手的定身术，在无数次施展与感悟后已「蜕变进化」：不但可以定人，更能定住**时间、空间，甚至神通法宝**。
- 但他并不确定此术能否定住由洞府界带到仙罡大陆的**储物空间的崩溃**。

## 二、储物空间的崩溃与抢救
- 储物裂缝一出现即散发幽光、内部骤起粉碎迹象；四周凝固如淤泥的气息 + 定身术同施，使崩溃「蓦然一顿」。
- 一顿之后随即剧烈崩溃。王林神识疯狂融入裂缝内一卷，欲卷出全部物品，但时间不允许。
- **损失**：
  - 疯子与银衣女子距缝隙很近，直接被卷入其内消失不见；
  - 部分法宝当场崩溃；
  - 另有三样未崩溃的法宝被裂缝吞噬。
- **应对**：王林神识骤然分裂数份，顺裂缝散去，化作**神识烙印**一一印在那些消散的法宝上，为日后寻回留线索。
- 随后心念一动关闭尚未完全崩溃的储物空间，阻止继续崩溃。事毕全身被汗浸透、呼吸急促、双眼通红，长叹「疯子和那银衣女子……」，自认已尽力。
- **状态判断**：该储物空间「应该还能打开几次」，但每次打开崩溃都更剧烈，直至完全毁灭；**已司之傀仍在其内**，未被卷走。

## 三、抢出的两件法宝
| 物品 | 特征 |
| --- | --- |
| 血剑 | 煞气弥漫 |
| 金色大印 | 透出**空劫波动**，更有一丝**大天尊气息**，似证明为九阳以神通从虚幻中凝实而出 |

## 四、体内储物空间（仙罡大陆法门）
- 王林按**从康仁处得到的方法**，抬右手在腕上开出一道裂缝：内部漆黑、散出吸力，将血剑与金印收入后裂缝消失。
- 感悟：「以身体血脉开辟储物空间，这种方法，也就只有仙罡大陆的人才能完美的做到。」
- 连续数次演练取出/收回血剑与金印，确认斗法中不会因习惯而下意识打开旧储物裂缝，造成不可逆转的崩溃与错误，方才放心。

## 五、王林的盘算
1. **法宝**：丢失几件无妨，「仙罡大陆上的法宝，我可以获得更多」。
2. **贪狼**：推测贪狼也在仙罡大陆，只要他在，自己就永不缺法宝，期待「在仙罡大陆的第一次重逢」。
3. **疑问（久悬未解）**：贪狼同为**七彩魂魄之一**，为何不需如**清水、司徒**那样转世便可离开洞府界？即便有大天尊帮助，玄罗也同样出手了，此事无法解释。
4. **当务之急**：解决**地火**与自身**火本源**的问题。
5. **威胁预判**：苍龙宗老祖**杜青**修为不俗，若寻来必有一场恶战。
6. **方针转变**：本不愿初来仙罡就招惹麻烦，但「或许还需高调一些，如此方可站稳脚步」，目中露出寒芒。

## 六、另一线：仙族皇都
- 地点：仙罡大陆**仙族中州·皇都·皇城**，一座数万丈大、如同天宫的奢华大殿，其上金光万丈，远处可见刺目之光。
- 人物：龙椅上身穿**九龙皇袍**的中年男子，闭目假寐后骤然睁眼，瞳孔如太阳，散发尊贵至极的**血脉气息**与强大气势。
- 情节：**国师**曾算过，**道非**此次失踪不会有生命危险，反倒又会造化；如今其气息出现在**神葬之虚**，皇袍男子决意「接他回来」，抬右手向前方虚无一抓——并注意到「在他旁边还有一个女子」。

## 七、悬念
- 疯子与银衣女子被卷入崩溃的储物空间，生死去向未明。
- 三件被卷走的法宝带有王林神识烙印，留下日后寻回的伏笔。
- 道非与身旁女子将被皇族接引，与王林所在线索或将交汇。
