# 第十卷 叱咤界内·第1527章 罗天召河动

## 一、开天一斧：屠灭万军，斩落「云落大司」

- **斧芒开天**：王林一斧斩出，斧影几与星空齐大，轰鸣压下四周一切声息，震动无尽界外入侵修士心神；仿佛星空一切存在之力尽被此斧吸走，虚无中只剩巨大斧影。
- **屠戮层次**（自前而后，逐层崩溃）：
  1. 最前方一名黑衣中年男子（界外修士），双臂抬起掐诀欲挡，斧芒从其体内呼啸穿过，眉心现血线贯穿全身，身躯自胸口以下撕裂、鲜血喷涌、骤然分开。
  2. 其后数十修士如被定身，身颤停顿半空，斧头一闪即肉身撕开。
  3. 再之后数百上千名守护云落大司前方的界外修士，只觉眼前一花，身体随斧啸余音一一崩溃。
  4. 更后数千修士如雕像般保持原动作不动，直至斧光如流星而走，才一一眉心现血线、崩溃而亡。
- **血盾无用**：云落大司心神弥漫罕见的无助之感，瞳孔尽被斧影占据，只来得及咬破舌尖喷血，化作巴掌大小的八角血盾，其上无数细密符文凹凸闪烁；符文急变化作细密之网亦被直接斩开，盾身「咔」的一声碎裂。
- **一斩两断**：斧芒自其娇柔身躯上一斩而过，穿体而出后落在**封界大阵**被撕开的裂缝之上，整座大阵通体一震。云落大司嘴角喷血，身体从中一分为二。

## 二、真相：所斩为布偶分身

- 一分为二者落地化作**两团云布**，两半连接起来形如凡间孩童玩耍的布偶，有眼有鼻，容貌与云落大司一模一样。
- 王林迈步踏在云落原处，眼露疯狂杀机：「居然是分身」「就算是分身，我也能找到你本尊」——已存必杀之心。
- 处置手法：左手大袖一甩以火焰焚烧云布；掐诀一指令两半燃烧布偶崩溃；崩溃同时以神通抽出**两道幽丝**，交织如二蛇盘旋，刹那成漩涡。
- **以魂指引，通**：低吼之下，幽丝漩涡化作不断旋转的黑洞，内里漆黑，不知通往何处——此为循魂锁定本尊的通道。
- **投雷**：王林右眼**目雷图**一闪，雷图外九道伴生中被其所封的**极境之雷**化作红色闪电自右眼冲出，直贯黑洞；其后又有**火之本源**融入雷霆，雷火交织而去。

## 三、长尊会禁地：本尊圣岛遭雷火轰灭

- **地点**：界外**太古星辰**内，**长尊会三大禁地之一**——不存在于星空中的空间裂缝，湖水清澈、内有一岛，是云落大司先祖留下、代代传承的圣地。
- **本尊状态**：白衣黑发，盘膝坐于岛中阁楼之下，面色苍白双目紧闭；分身被斩刹那身子一震喷出鲜血，血雾飘散，数滴溅在白衣上。
- **雷火临岛**：其头顶天空凭空幻化漆黑漩涡（黑洞），红色雷霆轰隆而出、染天地为血光，红色闪电降临途中膨胀成百丈巨雷，如天怒灭世之雷落于岛上；雷后无尽火焰滔滔，湖水蒸成白气，岛屿在雷火交错中四分五裂、崩成无数碎石。
- **卦相应验（先祖之卦）**：云落大司坐于最中间碎石上，身后阁楼散出柔和之光笼罩其身，喷血、面色死灰，苦涩道——
  - 三相：天雷落下
  - 四相：火海焚烧
  - 五相：渺岛分离
  - 叹「先祖的卦相，已成五相」
- **护体破灭**：极境雷霆自四面八方如无数血蛇游走收缩，压迫柔和之芒内凝，抵抗不到数息即崩溃，红色闪电冲向其本尊肉身。

## 四、师尊之骨与「返族融魂」——云落大司肉身元神俱灭、魂遁

- 云落大司玉手一挥，唤出一具透着沧桑气息的**黑色骸骨**，正是**其师尊之骨**。
- 骸骨如磁石般引来四周红色闪电，巨响中震动崩溃，吸尽雷霆后化作**风暴**卷在云落大司身上。
- 结果：其**身体直接碎灭、彻底瓦解，元神亦轰然崩溃**；但**其魂融入骸骨所化风暴**，在一道幽光闪烁下随风暴消失于天地之中。
- 消散前续念卦相：「六相祖骸碎裂，七相返族融魂，八相秋兰念苏，九相……」——第九相未及道出即声音消散。

## 五、云海战场：罗天、召河援军来临

- 王林手持巨斧立于半空，目光如电横扫八方界外入侵修士，杀机一闪。
- **毒海**呼啸横卷星空，数万**蚊兽**狰狞嘶吼，随毒海卷动冲向四周十多万（界外）修士。
- 云海远处星空波纹涌现，一颗、两颗、三颗……共**近九百多颗修真星**浮现——**罗天修士援军来临**。
- 更远处漆黑星空被无数闪电凭空撕开、急速宣泄而出——**召河修士援军来临**。

## 关键判定与留痕

- 云落大司之死为「本尊肉身与元神俱灭、魂随祖骸风暴遁走」，非彻底身死道消，「七相返族融魂」暗示其魂另有归处（返族/融魂），后续存疑待续。
- 「九相」之卦仅报至八相，第九相内容为本章悬念。
- 王林「以魂指引」可循分身残魂反锁本尊所在——即便隔着不存在于星空的空间裂缝禁地，亦能投送极境之雷与火之本源。
