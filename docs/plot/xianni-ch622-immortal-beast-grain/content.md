# 第622章 仙兽之粮

## 一、上门问罪

王林亲至矮小老者的白色城堡，开口便是“你两次招惹王某，今日王某亲自来临”。老者以其修为一眼看穿：王林已是**问鼎初期**，且**拥有了自身的道**。

- 老者身前三女之一的**孙若南**（孙云山之妹）率先认出“他应该是王林”。
- 老者当年只是心念一动想抓捕此人炼成仙卫，未料对方有此修为，心中懊悔——若早知，以其性格绝不会主动招惹。
- 老者罕见示弱：“你杀我两个仙卫，也算抵消，今日我不难为你……从此各不相犯。”三女大为诧异，深知老祖心胸狭窄。
- 王林边踏步边摇头：“两个仙卫，只不过是两块碎玉罢了，如何能抵消你招惹之过。”

## 二、八仙卫召唤“仙帝”

老者恼羞成怒：“八仙卫，召唤仙帝，给我把此人杀了。”

- 八道身影飞出，有男有女，皆散发**问鼎期**威压。
- 八人盘膝而坐，座位间蕴含某种规则，双手不断变化印诀，仙力在半空诡异融合。
- 凝成一名**穿仙袍、长发飞舞、手持青色长剑的中年男子**虚影，气息堪比天威。四周修士尽皆跪拜：“下界修士，参见仙帝。”
- 老者自曝身世：**本是仙界之人，仙界破碎后机缘巧合来到此地**，其神通皆为真正仙术。

## 三、破幻与灭卫

1. 王林右手一抬，天地一暗，**黄泉**如倾斜黄河自天而降，绕身而后直冲虚影。
2. 八仙卫仙力如风暴崩发注入虚影；虚影双眼灵动，青剑前指——仅此一指，王林便生出“不退则元神崩溃”之感。此感与**当年天劫**同级。
3. 王林逆天而修、道心坚定，硬生生止住退势，反而再进一步。
4. 八仙卫口喷含**全部仙力与生命力**的鲜血注入虚影，虚影灵动更浓，张口吐出一个**无声之字**——王林耳中雷鸣轰隆。
5. 王林深吸一口气，闭目落步。落地刹那，八仙卫眼中神采尽失；黄泉横扫，虚影支离破碎。王林断言：“好厉害的**幻术**攻击。”
6. 王林身融黄泉，如黄龙穿过八仙卫身侧，八人身体一一崩溃**落入黄泉，永世逃不出轮回**。
7. 八块平淡无奇的**碎玉**飞出，被王林收入储物袋（印证其“两块碎玉”之语）。

## 四、城堡坍塌

- 老者怒吼，射出极为精纯、不断压缩的仙气，冲入王林周身黄泉即消失无影。
- 王林口吐一“开”字，黄泉散作漩涡横扫，白色城堡瞬间坍塌。
- 老者与三女飞出半空；老者相貌**贼眉鼠眼**，不似修士反似贼子，仍再三劝退王林。
- 王林不答，一道**寂灭指风**直冲老者；老者喷出浓浓仙气化仙雾环绕，二者相互消散。

## 五、仙种与仙兽之粮

- 老者一拍储物袋，取出**拳头大小的青色玉石**，掐诀点出，喝道：“**仙种**”。
- 玉石蠕动，化作无数长长的**青色细丝**，尖锐嗡鸣、群蛇乱舞般铺展。四周观望修士面色难看、眼露恐惧。
- 王林一语道破：“**仙兽之粮**”。老者失声：“你认识？”
- 王林的认知来源：此前在**孙云山**身上见过青丝，似曾相识；细想即是**当年在仙界与大罗剑宗弟子进入某洞府时所见的仙粮**（当时未向孙云山点明）。
- 老者虽为**问鼎中期**，却因“难言之苦”打算拼命；且其自得到仙粮后**始终无法完全操控**，此番全部祭出。

## 六、麒麟兽出场（章末）

- 成百上千条青丝直奔王林。王林毫不紧张——当年遇到过**多出百倍千倍的仙粮大军**。
- 王林来前已有怀疑、早有准备：拍储物袋取出**一杆普通魂幡**，一抖之下放出**在炼魂宗内发现的麒麟兽**。
- 此兽为**麒麟之魂**，但多少含有一丝传承；现身咆哮，硕大头颅直盯来袭仙粮，双目爆出奇异之芒，**如饿了无数万年的恶鬼终于见到食物**。

## 关键点

- 仙粮之于麒麟，似为“食物”——章名“仙兽之粮”与麒麟饥饿的目光形成呼应，暗示仙粮是喂养仙兽之物。
- 仙卫本质与“碎玉”绑定：杀死后遗留碎玉，共收八块。
- 老者的仙术体系（仙力/仙气/仙种/召唤仙帝）源自仙界破碎后的遗留。
