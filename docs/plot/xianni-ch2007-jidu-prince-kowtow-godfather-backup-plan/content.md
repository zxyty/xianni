# 仙逆 第2007章 后路！

## 一、王林的复盘：计都早已看破

- 王林手持玉简，回想黑石城之事：图录上的画像与自己样貌几乎一模一样，可让人一眼认出；计都第一眼便已起疑，却隐藏极深，连王林当时都未察觉。
- 计都故意让**大古妖**出手，实为验证猜疑；确认后又表露出「恰到好处的震骇」，随即对王林恭敬有加，意在留下王林。
- 王林的疑点：计都敢在此点破身份并下拜，说明其无敌意；但一个仙族跃天尊来到古格后，为何不会杀他这个皇子？——必有缘故。

## 二、身份被点破

计都当面道出：

- 王林 = **道古玄罗大天尊的唯一弟子**；
- 王林 = 仙族的**白发跃天尊**。

来龙去脉：当年玄罗大天尊自仙族归来后立刻闭关，始古一脉随即展开调查，在**幕天大天尊**帮助下猜出大半；但即便如此，其父皇与**宋天大天尊**也未能确定二者是同一人。计都本人是在黑石城见到王林后才恍然大悟。

计都在王林身边感受到的威压，甚至超过面对其父皇时，堪比面对宋天。其身后女子为其**一母同胞的皇妹**，容貌与他有几分相似，是他信任之人。

## 三、跪拜与请求

- 计都先劝：「道古一脉并非良木」，古皇没有容人之量，王林去必受郁——话未说完，王林目光一闪、冷哼一声，拂袖欲走。
- 计都咬牙**单膝跪地**，其皇妹犹豫后亦随之跪下。在皇权至上的古族，皇子向外人下跪足以震撼世人（他此生只跪父皇母后）。
- 请求内容：
  - 愿认王林为**义父**；
  - 若他能成为始古未来之皇，则王林在始古之国便是**国父**；
  - 父皇有子七人，他排行第五，父皇已年迈将退位、新皇从七子中择选；
  - 「若前辈助我，则我可满足前辈一切要求」。
- 随后计都以头触地，砰砰叩首，打破大殿寂静。

## 四、王林追问：背后是谁指点

王林不信此事无因果，连问三问：谁让你陪伴道古使团选妃？谁告诉你遇王某要不惜跪拜挽留？谁告诉你会在黑石城遇到王某？

计都不敢隐瞒，供出**国师**——其舅舅、母后的弟弟：

- 国师十年前出关，**以消耗生命为代价**为计都占了一卦；
- 卦示：务必陪同道古使团再次莅临之行，此行会遇一次**改变命运的机缘**；把握住则命运剧变、未来不可限量，把握不住则**活不过百年**；
- 国师看不清具体，只有模糊感觉；说完即**气绝身亡**；
- 临终抓着计都手臂之言：「我算不出此人是谁，但他若肯帮你，你日后可成始古之皇，甚至有一丝可能成为统领三族之地的真正古皇……若他不帮你，则你活不过百年。」这些话十年间字字烙印于计都心中。

王林反应：对「国师」一类**擅长推衍计算**者有很深忌惮（在仙族已领教其可怕），但判断古族国师远不能与仙族相比；以其修为观察，确认计都并未说谎。

## 五、赠礼：祖简与木本源之液

计都奉上玉盒一个，内有二物：

1. **祖简**（玉简）——始古一脉重宝，计都出生时父皇所赐；历代始古一脉唯皇子可得，且一生只有一个。其内封印着**古祖留下的一指之力**，威力极大，但最大作用在于**感悟**：若能明悟这一指之力内的变化，则有无限妙用。历代皇子乃至古皇从未有人感悟出来，此物已成皇子的最高信物。
2. **手指粗细的圆筒**——内有液体，来历已无法考察，为古祖所留，蕴含极为精纯的**木本源之力**。计都判断王林能在仙族声名赫赫，必定修本源之道，故特备此物。

计都承诺：他只是皇子而非古皇，但日后若成古皇，始古一脉万古储藏之物任王林选取，倾一族之力报答助位之恩。

## 六、王林的决断：留后路

- 王林沉吟良久，大殿寂静，计都紧张不加掩饰、连连叩首。
- 王林最终开口：「**给我一枚，可以找到你的玉简**。」
- 并言明：「**若王某真有离开道古的一天，你再称我为义父不迟**。」——即不当场认下名分，但接下联络之路。
- 王林内心决断：**不能把自己的未来都放在道古一脉中**，借此机会留下后路。
- 王林收起玉盒与计都递出的玉简，转身走出大殿，身影消失在天地迷雾中。

## 七、事后：计都的判断

- 计都全身被汗水打湿，却神色激动兴奋，握拳道：以其对道古之皇的了解，义父在那里必定不适，这样的强者根本不是区区一个道古之皇可以拴住——义父一定会来助他。
- 皇妹问「值么」，计都大笑：「值。义父重情，否则以他的身份，根本大可不去寻玄罗大天尊；我诚心敬他、当如亲父，他定不会害我。」

## 八、伏笔与待办

- 王林下一步：前往**道古**（本章前已索要去往道古的地图玉简）；章末预告「明天，见玄罗」。
- 祖简的一指之力感悟，为后续可能的收获埋线。
- 始古一脉新皇之争（七子夺位）与计都的百年之限，构成待兑现的因果。
