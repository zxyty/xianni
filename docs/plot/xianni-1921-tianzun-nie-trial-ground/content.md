# 第1921章 天尊涅试炼之地

## 一、道一大天尊的招揽与「我不朽，你不朽」

- 黑发青年（道一大天尊神念所化身影）话语蕴含奇异之力，闻者顿生无尽敬畏与信服，其声仿若天地规则、苍穹承诺。
- 招揽王林时给出重诺：**「我不朽，你不朽」**。
- 身后的道魔宗天尊老祖（赤发老者）闻言神色骤变：他跟随道一一万多年，深知此等承诺极其罕见——当年道一招揽他时，说的只是「我不朽，则**你十万年不朽**」。王林所得之诺**没有时间限定**，意义太大。
- 老祖暗叹其中缘由：此人获天牛魂高度认可，本身已具备接近天尊的战力，尤其**穿上魂铠后可无限接近跃天尊**，难怪大天尊看重。

## 二、王林的婉拒与大天尊的条件

- 王林抱拳：「此事对在下极为重要，无法立刻决断，还需考虑。」
- 拒绝的理由（内心）：
  1. 不愿只见过一个大天尊就定下归属；
  2. 与道魔宗天尊老祖一战后略有所悟，已知晓天尊的道；
  3. 名气还不够——需**声名赫赫**之后再择一大天尊跟随，如此进入**仙族皇城**才能骤减危机。
- 道一双眼似能看透王林心思，微微一笑，留下条件：**「给你时间，以你的战力，可去闯天尊涅，若能闯过第九层，我还会再来找你。」**
- 随后道一转身与道魔宗天尊老祖身体融合，化作之前的道袍，身影消失。四周静止之物恢复轨迹，尘土落下、风起，威压烟消云散，仿佛未曾发生。

## 三、与道魔宗天尊老祖的和解

- 老祖抱拳：「道魔宗之事，一笔勾销——不过你错失了即刻跟随道一大天尊的机会。」
- 王林罕见地解释：**毁道魔宗是因当年道魔宗以全宗之力陷他于生死之中，并非针对一人。**
- 老祖沉默半晌后长叹：「世间因果循环，此乃道魔宗之劫，你毁了此宗，也算斩断了我一桩凡事，从此之后，我再无任何牵挂，可以一心问道。」
- 强者之间相互尊重；老祖权衡后认为为已毁之宗与一位强大天尊交恶得不偿失，遂倾囊相告天尊层面的常识，以抹去不快。

## 五、天尊涅试炼之地（核心设定）

- **来历**：仙族**仙祖**当年在仙族领域内创造的奇异之地，专为天尊准备。
- **功用**：可让天尊修士在其中获得**准确的修为判断**。
- **层数**：共**十九层**，唯有天尊修士可闯。
- **难度参照**：道魔宗天尊老祖五百年前闯过一次，**只到第三层，第四层失败**。
- **原型与造化**：道一曾言天尊涅是仙祖**模仿太吉神境**创造；若能闯过**第十九层**，日后进入太吉神境时会有**超过旁人的几率成为大天尊**。当年**武封大天尊**正是闯过十九层后，在一次太吉神境开启时获得莫大造化而成大天尊。
- **进入之法**：得**仙罡法则认可为天尊修士**后，在仙族任何一处寻安全之地闭关，**元神离窍，向天空以最快速度飞行，超过六十息**，即可进入仙祖创造的天尊涅试炼之地。
- **旁支传闻**：
  - 吉族的**吉祖**当年亦模仿太吉神境，创造了适合吉族之人的同类试炼之地；
  - 在仙、吉两处试炼之地**之上**，还有当年**两位仙罡大陆最强者共同创造的「大天尊试炼之地」**（仅为传闻）。
- 老祖说完抱拳告辞，看都不看已成废墟的道魔宗，化长虹远去。

## 六、王林的盘算与一年闭坐

- 王林不后悔委婉拒绝招揽，盘算：五大天尊除仙皇与道一外还有三人；**与天尊交战次数越多，感悟越多，名气越大**；同时存疑——老祖所说的进入方法「是真是假」。
- 就地在道魔宗废墟盘膝坐下，反复回放与道魔宗天尊老祖一战及道一那**一拳**；那一拳看似轻柔却蕴含捉摸不透之力，最终占据王林全部心神。
- 数月至一年间，王林身外弥漫防护之力，四周无人可近。从**天牛洲**赶回的道魔宗修士见废墟震撼，认出王林身份却无法靠近，多带着恐惧散去，少数远远不敢临近。
- 一年后睁眼，长叹：**推衍不下百万次，无一次能抵抗——而这仅是道一大天尊的一丝神念。**修为提升的喜悦平静下来，自认与大天尊相比仍太弱。
- 收获：与道魔宗天尊老祖一战感触极大，其**「融道于身，一拳出蕴含二十七种神通」**可供模仿、学习；决定另寻一地好好明悟。
- 结尾：王林感受到归来的道魔宗门人，只道一声「罢了」，迈步身影刹那消失。
