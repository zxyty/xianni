# 仙逆 第432章 祖符头骨

## 场景与开局
- 王林暗中尾随一名六叶术咒师进入此地（仙遗族祖巢第四层）。对方落地化回人形的瞬间，王林隐去身形。
- 以王林当时修为，除了盘坐在轮回树上的**八叶术咒师**，此地无人有资格发现他。王林一眼看出该八叶术咒师**身受重伤、极为虚弱**。

## 轮回树献祭疗伤仪式
1. 轮回树四周的六叶术咒师尽数盘坐，诵念咒语，身上符文涌出、脱体飘于半空。
2. 术咒师身后**约数百名结丹期修士双目茫然**地走到树下盘膝而坐（明显受控）。
3. 六叶术咒师齐声大喝，符文尽数没入轮回树。
4. 三丈多高的轮回树剧震，长出无数如长蛇般的柔软枝条，眨眼间将所有修士捆缚拽向半空——整棵树宛如活物。
5. 树上浮现数个符文，被缚修士**血肉精华肉眼可见地萎缩**，体内灵力不受控地顺枝条涌入树中。
6. 血肉与灵力被转化为一股奇异力量，顺树体灌入八叶术咒师体内，其胸口伤口收拢、气息回升。

王林判断：**“他在疗伤。”**

## 王林出手
- 王林化作虚幻之影，在众六叶术咒师毫无察觉下瞬移至轮回树上八叶老者身旁，右手闪烁**乳白色光芒（仙力的表现）**，拍向包裹老者的光圈。
- **不出手则已，出手便毫不留情。**
- 一掌轰鸣响彻第四层，气浪将树下六叶术咒师生生吹出数百丈，各自喷血、体内符文之力不稳，短期难复、稍有不慎便死。
- 有六叶术咒师尖声惊呼「**婴变修士**」，众术咒师二话不说起身就逃。

### 关于这一掌的力量注解（设定要点）
- 若非已达婴变期，王林不可能**不用任何法宝**一掌打出这等威力；此掌几乎**与本尊三星古神的一拳相当**。
- 关键在于掌中**蕴含仙力**。婴变期修士之所以强大、可在任何修真星享受尊荣，正因仙力的存在。

## 八叶老者遁逃与轮回树被毁
- 光圈崩溃，老者喷血，头顶**沧桑祖符**闪现挡住仙力，传出浩淼之力令王林一掌稍缓，老者趁机如流星般爆退遁逃。
- 王林「你跑不掉」，反手一掌按在轮回树上，狂猛仙力灌入，**轮回树崩碎成一片片碎木**，枝条节节断裂，数百修士坠地。
- 落地瞬间，众修士**双目清明，迷茫尽去**。王林留下一句「离开这里」便追击而去。

## 蚊兽出手
- 王林一拍储物袋放出**蚊兽**。蚊兽随他多年、**灵智已开**，无需吩咐即知主人心意。
- 蚊兽化作黑色闪电，以巨大口器刺入一名六叶术咒师头部，一吸之下将其吸成皮包骨、彻底死亡，随即抛尸扑向下一个。以其速度，逃者无一能脱。
- 获救结丹修士中有一人认出王林，惊喜呼「**始师**」。王林回头看了一眼，觉此人陌生，未细问便离去。

## 八叶术咒师的来历（自述/旁白）
- 本是**五祖大人**身边的八叶术咒师，在**仙遗族**中身居**长老之位、享有大权**。
- 仙遗族临世以来，**死在他手中的修士数不胜数**。
- **一个月前**被**朱雀国一名婴变后期修士**所伤，险些死亡，被送回此地以轮回树疗伤。
- 逃亡时的盘算：只要逃到**第十一层**便有救——**三祖大人**在守护**祖灵树**时被**朱雀子**重伤，正在那里疗伤，必会出手救他。他遂朝进入**第五层**的入口疾驰。

## 斩杀与「祖符头骨」
- 王林拍出储物袋中**仙剑**，仙力涌入剑身，剑芒白芒刺眼，一斩之下如开天辟地，第四层大地震动。
- 老者已是强弩之末、油尽灯枯，转身疯狂拍额大喝「**祖符**」——即先前挡住王林一掌的那枚复杂沧桑符文。
- 剑芒与祖符对撞：巨响、三丈气浪、大地被刮出三尺，**祖符碎裂**，其后老者双目黯淡、气息飞速消失。
- 老者含毒嘶问「你，是谁」，王林答「**我是谁，不会告诉你**」，掐诀打出一道印记入其体内，仙剑一推斩下头颅抓在手中。
- 王林砍头瞬间已施展**炼魂宗秘术**（可使魂魄在身亡后凝聚于头颅内不散），但食指点其眉心后皱眉自语：「**没有魂魄**」。
- 王林以**一团幽火**包裹头颅，血肉尽被炼化，**头骨却毫无融化痕迹**——头骨上如烙印般刻着一个**破损的黑色符号，与老者释放的祖符一模一样**。

## 悬念与线索
- 术咒师体内**无魂魄**，且头骨天生（或被烙）祖符——暗示仙遗族术咒师可能非寻常生灵。
- **祖灵树 / 轮回树**同源体系：轮回树可夺人血肉灵力疗伤；祖灵树由三祖看守于第十一层。
- 三祖被朱雀子重伤、五祖有八叶随侍——仙遗族高层战力与层级线索。

> 归属说明：本章「王林」为本人行动（婴变期、持仙剑、御蚊兽），非化名或被夺舍状态。

# 第433章 三祖是她 — 王林横扫第五至第十层

## 一、承接：第四层收尾
- 王林将所得八叶术咒师头颅收入**储物袋**，动身疾驰。
- **蚊兽**破空归来，巨大口器鲜血淋淋、目露愉悦之色，被王林收起。
- 在第四层再横扫一圈，未发现其他**轮回树**，遂进入第五层。

## 二、第五层：海藻植物与元婴级人形生物
- 第五层范围比第四层大一圈；地面不再光秃，生长着王林曾在**楚国**见过的海藻类植物，绿油油密密麻麻连成一片。
- 这些植物叶子缓缓摇曳，**似蕴含某种规则**，久看会令观者身不由己随之而动。
- 神识探得**三颗轮回树**，每颗树上各有一名**八叶术咒师**疗伤，伤势极重、处于弥留之际。
- 王林瞬移接近轮回树时警觉遁走百丈，原地海藻植物诡异蔓延砸击。随即全层海藻盘绕成**人形生物**：下肢与海藻相连、蠕动升空，气息诡异，**每个相当于元婴期修为**。
- 生物齐声（分不清男女、带回音）：「外来者，离开这里。」

## 三、尊魂幡与问鼎初期之魂
- 王林判断此行须**快刀斩乱麻**，一出手即祭**十亿尊魂幡**。
- 「魂，散」——魂魄呼啸而出笼罩四周。**当前存量：魂魄六亿多，主魂二十六个（含遁天）。**
- 能力上限：现有魂魄**无法**融成问鼎后期或问鼎中期之魂，**可凝问鼎初期之魂**。
- 「融」——**五亿魂魄 + 十多个主魂**融合成问鼎初期之魂，威压使整个第五层轰然一颤；余下魂魄与主魂盘旋其身周，凄厉吼叫。
- 限制：**问鼎之魂无法长时间存在**，故王林全程抢时间。

## 四、屠戮与收获
- 王林喝「杀」，问鼎之魂随手一挥，大地震动，全层海藻类植物如被无形镰刀横扫般尽数碎灭。
- 王林亲自冲向轮回树，驱魂魄轰之，**轮回树崩溃**，其上八叶术咒师喷血身亡。
- 第五层三名疗伤咒师**全部被杀**；王林**割头颅、炼化血肉、收走刻有符文的头骨**。
- 态度：对**仙遗族**半点好感皆无，进入第六层后**遇仙遗族之人立杀**，如同凶魔；其真正目标是轮回树。

## 五、第六层至第十层
- 第六层仍是三颗轮回树，三名疗伤者在问鼎之魂威力下再度死亡。
- 一路势如破竹穿过第七层、第八层，**直冲第十层**。
- **转折**：抵达第十层时，**问鼎之魂溃散**，化作虚弱魂魄飞回尊魂幡内，**无法再次召唤而出**——王林失去此张底牌。

## 六、要点小结
- 战力资源账：尊魂幡魂魄从十亿级消耗至六亿余，再耗五亿凝魂；主魂二十六（含遁天）用去十多个。
- 问鼎之魂 = **一次性、限时**的越阶战力，本章用尽。
- 王林与仙遗族的敌对已成**见即杀**的状态。

# 第411章 仙遗之地十一层：九叶女尸与相同的画轴

## 一、尊魂幡与问鼎之魂的局限

王林收起尊魂幡。一路之上他仔细研究此幡，得出结论：

- 凝化而出的**问鼎之魂**虽然强大，但**存续时间太短**；
- 终究是凝化而成，与**真正的问鼎修士仍有差距**；
- **每凝化一次，对魂魄损害极大**，需要很长时间才能恢复。

这解释了当年**遁天**的用法：不到万不得已，只凝化而出**震慑敌人**，而不让问鼎之魂真正出手。

## 二、清剿战果：十九名八叶术咒师

- 连同此前的一并计算，王林在仙遗之地**共杀十九个八叶术咒师**；
- 这些术咒师**均是身受重伤后**才被王林杀死，死不瞑目；
- 仙遗之地**每一层**都有类似第六层那样的**奇异之物**作为防守；
- **若无问鼎之魂，王林在第六层便不得不止步**，无法再入内。

### 仙遗族的误判

即便是仙遗族也绝没想到，会有一个**问鼎修士**杀入巢穴之内。原因在于朱雀星上的问鼎修士稀少——

| 问鼎修士 | 当前状态 |
| --- | --- |
| 朱雀子 | 在朱雀山 |
| 楚云飞 | 被逼离开朱雀星 |
| 地魄门那位 | 受伤极重，在隐秘之地疗伤 |

（不计云雀子在内，朱雀星上仅此三个问鼎修士。）若无问鼎修士，以仙遗之地的防守本可**绝对无碍**。

## 三、六层到十层的收获

### 1. 灵石

- 数量**远超预期**：仙遗族竟存放了如此之多；
- 按理仙遗族用不到——他们使用**符文之力、吸收妖兽而威**，灵石内的灵力对其无用；
- 灵石在王林眼中已算不上宝物，但它是**修士间的货币**，多多益善；
- 王林一路搜刮的量，**足够一个四级修真国的宗派使用千年**。

### 2. 头骨（更有价值）

- 王林现得**十九个八叶术咒师头骨**；
- 每个头骨上的**符号都不相同**；
- 其散发的气息**几乎与一个婴变修士一模一样**；
- 王林直觉这些头骨**绝不简单，价值远超灵石**——他的感觉很准。

## 四、设定补充：力量精华与「圈养」

- 在**天运星**上，这类与修士截然不同的力量体系修炼者，其**力量精华价值惊人**；
- **头骨即是仙遗族的力量精华所在**；存在一种**秘术**，可把头骨上的符文逼出，从而获取**符文之力**；
- **九叶以上术咒师的头骨**，价值更是极大；
- 星空中有些星球的原住者拥有奇异之力，受到**修真联盟**注意。联盟不毁灭他们，而是以类似**圈养**的方式：一代一代养大，再一代一代灭杀，如此可取得**无限的力量精华**；圈养他族，自然要给一些食物。

## 五、下入第十一层前的布置

- 王林望着第十一层入口**犹豫**：不知仙遗族共有多少层，若无问鼎之魂根本到不了这里，**对十一层没有把握**；
- 站在入口处，他有奇异之感——**下面的十一层似有什么东西在呼唤他**；
- 王林嘴角露出**冷笑**，不急下去，先在地面**摆下一个小型传送阵**：
  - 来源：当年与**巨魔族老祖**一战之前，为抵抗其天赋神通，**从遁天手中拿到的玉简**所刻；
  - 王林**轻车熟路**摆下，并**放进一枚仙玉**（作为能源）；
- 入口特征：**其内漆黑一片，散发阵阵黑烟**，与其他几层不大一样；
- 王林右手持**仙剑**，**仙力凝聚**，纵身跃入。洞不深，很快穿透进入第十一层。

## 六、第十一层所见

进入瞬间，王林面色**古怪**起来。

- 空间**不大**；地面被挖出一道道**沟壑**，彼此连接构成一个**奇异符号**；
- 沟壑内**红色液体流动**，映入眼中的是**血红色的符号**；
- 一股**阴寒之气**从地面透出——此处是一**阴寒之地**。

### 符号中心的女子

- 一名女子**静静飘在半空**，头发**无风自动**，充满妖异之感；
- 身姿凹凸有致极为完美，**全身洁白、没有任何符文印记**；
- **唯有额头闪烁一个九叶植物**（九叶＝术咒师品阶远高于八叶）；
- 相貌极美：王林一生所见女子中，**除仙尸外唯有柳眉能与之相比**；
- 王林**从未见过此女**，却**莫名有种熟悉的感觉**。

### 上方的画轴（关键伏笔）

- 女子上方悬着一个**打开的画轴**，画幕内**九个晶芒环绕成圆形**；
- **丝丝黑气从画幕散出，钻入女子眉心**；
- 王林见之**内心一震**：此画轴与他**储物袋中那个自始至终都无法操控的画轴法宝一模一样**。

## 七、结尾悬念

地面上的血色符号**蓦然闪烁血红之芒**，飘在半空的女子**眼睫毛一颤，慢慢睁开双眼**。

## 八、遗留线索

1. 王林储物袋中无法操控的画轴，与仙遗之地核心处的画轴同源——画轴来历与九晶芒之谜；
2. 王林对陌生女尸的「熟悉感」来源未明；
3. 十九枚八叶头骨的秘术用法尚未施展；九叶头骨（此女）价值更大；
4. 十一层入口处已布下小型传送阵，为后路/撤退埋伏笔；
5. 仙遗族总层数未知。

# 第434章 你可愿（仙逆 · 剧情梳理）

## 一、场景与登场
- 地点：仙遗之地内部（本章自第十一层一路退至第一层）。
- 王林闯入某层，见到一名眼含幽光妖异之芒的女子，望之心生茫然与熟悉感。

## 二、剑魂许立国的旧怨
- 王林手中仙剑剑鸣，剑魂**许立国**幻化而出，直勾勾盯着女子，喃喃：「仙子小妹妹，谢谢你，把我当年化身成为修士、感悟出的一丝意境残魂送来。」
- 许立国脱离仙剑扑去，口称「你家许哥哥来了」；女子玉手一点其眉心之际，许立国身形一晃消失，实为剑芒突袭，怒喝「贱人，你家许爷爷吃过一次亏，岂能再吃第二次」。
- 女子轻吹一口气，剑芒当场崩溃消散。许立国大骇，一闪退回仙剑之内。
  - 关键信息：许立国**曾在此女手上吃过一次亏**；他当年曾**化身成为修士**并感悟意境，其一丝意境残魂现落在此女处。

## 三、魅姬的身份自陈
- 女子自述：「当年修士中，他们称我为**魅姬**，在仙遗族，我是**三祖**。」
- 她不喜「三祖大人」的称呼，要王林叫她魅姬。
- 她一点虚空，封死回第十层的入口，明言要王林「知晓人生的美妙」，称在王林身上闻到很干净的味道、想必尚未近女色。

## 四、对峙与交易
- 王林判定她**重伤未愈**，拍储物袋祭出**十亿尊魂幡**，幡上透出穿透灵魂的凄厉吼叫，魅姬一字一顿念出「十亿尊魂幡」。
- 王林注入一丝仙力，仙剑白芒暴涨，一斩在地面留下深深沟壑，并言「这一击，我只运用了一成的仙力」。魅姬认出：「原来是个仙宝。」
- 王林内心评估：对方**相当于问鼎老怪一般的存在**，即便重伤也有神通，不同于那些**八叶术咒师**（重伤之下王林以问鼎之魂杀之不难），故毫无把握，只求脱身。
- 魅姬抛出诱饵：**仙遗之地共十九层**，过了她这一层，下方藏有仙遗族力量的奥秘，更有**仙遗族第一代族长的残魂**守护；以王林有十亿尊魂幡，何不去收先祖残魂。
- 王林不为所动，给出**三息**时限：是战是走。魅姬轻叹，重新开启出口，条件是留下那丝意境残魂；王林答应「离开仙遗之地前自会把她放出」。

# 第435章 尸阴宗地下的巨人（本片段）
