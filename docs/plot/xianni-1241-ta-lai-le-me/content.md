# 第九卷 云海之巅 第1241章 他，来了么

## 一、场面失控与「禁空」镇场
- 冯海率无极宗六名长老随李倩梅前行，其后数百无极宗门人化作长虹跟随，引动平台上数万修士骚动，分宗大比一度混乱；台上对战的两名四阶星域修士也相视苦笑停手北望。
- 一名散发**碎涅**修为的**赤发老者**率十余名老者赶至，低喝「禁空」，两字化作滔天之雷与音浪推开四方，刚飞起的修士纷纷落地，全场立刻安静。

## 二、吕英杰自作多情，李倩梅当众冷落
- 吕英杰误以为李倩梅为自己而来，当众自称「百年一别」的旧识；七阶**寻栾宗赵龙**随之抱拳自报家门。
- 四周议论：传闻吕英杰风流成性，竟连破天宗李倩梅都与其相识，「仙音门尚未比试便已名声大振」。
- 李倩梅带着战场杀气冷冷一扫，吕英杰心神一寒止步；她径直从其身边走过，不置一词。吕英杰与赵龙笑容僵住，四周目光由惊讶转为嘲讽。
- 唯冯海等人疑惑更深——他们亲耳听到李倩梅问的是**归元宗**。

## 三、核心一问：「他，来了么」
- 李倩梅走向归元宗众人，目光落在擦去嘴角鲜血的**吕烟菲**身上，沉默良久后轻声问：「他，来了么」
- 吕烟菲虽从未见过李倩梅，却明白这个「他」是谁，摇头：「百年内，从未有他的消息。」
- 李倩梅轻叹「那算了」，蓝色秀发随风，神色惆怅落寞。
- 后经冯海追问，李倩梅点头承认「他」即**归元宗吕烟菲的师叔祖**；吕烟菲补充：「师叔祖百年前曾说，他会来。」

## 四、雷霆一击：轰杀赵龙肉身、留吕英杰
- 李倩梅察觉吕烟菲新伤，追问来由。吕烟菲平静指认：吕英杰言及归元宗解散后要她**做炉鼎**，并扬言要与师叔祖一战；赵龙则嫌其声音刺耳、认为其无资格交谈，「略作惩罚」。
- 吕英杰怒斥「满口胡言」——他确未把炉鼎之言宣之于口，但内心确有此意。
- 赵龙掐诀后退欲战，李倩梅以**碎涅后期**修为瞬息化残影掠至其身后，玉手一挥，滔天煞气内蕴兽吼咆哮、妖异雾气笼罩赵龙：其左臂、右手、双腿接连爆开，肉身瞬息崩毁，**元神**惊惧逃遁。
- 李倩梅向冯海与赤发老者表态：「二位若介意，此事我会给无极宗一个交代。」
- 对吕英杰宣判：「你既要与他一战，那么就留你性命。若他没来，我再取你与那赵姓之人命魂。」

## 五、暗线：卢云从的冷笑
- 赵龙于危机中看向**卢云从**，见其冷笑与毫不掩饰的嘲讽，心中咯噔——意识到此前卢云从口中的**神秘吕姓之人**（即王林化名吕子浩）绝非自己所想那般简单。

## 六、另一头：王林在风仙界收蚊兽
- 此刻被众人猜测的「他」，正在**风仙界**外围边缘：一身白衣、白发随风的王林，骑在一只**淡金色蚊王**背上，率近五千**赤红蚊兽**、数百**蓝色蚊兽**，如红云遮天呼啸而过；蚊王每次嘶鸣皆令群兽敬畏。
- 王林伤势略有恢复，但更关键的是大量蚊兽入手使其**实力大增**。
- 决定：「我要进一次风界内部，获得足够的蚊兽，去应与归元宗的承诺。」蚊王一声尖鸣，红云转向风仙界蚊兽大量聚集之地。

## 七、要点
- 李倩梅与吕烟菲之间的联结点是**王林（化名吕子浩·归元宗师叔祖）**的百年之约。
- 本章确立三方期待：无极宗/众修士的猜测、吕英杰与赵龙悬于头顶的死刑缓期、王林正在履约的路上。
