# 仙逆 第九卷 云海之巅 第1261章 来自神宗的杀劫

> 世界状态须知：本章「吕子浩」即王林（自第1063章起以归元宗故人吕子浩之名行事，身份由吕烟菲奉上）。本条目中「吕子浩」的言行一律归属王林。

## 一、鲁肃山峰：一把以星祭炼的剑

- 无极宗所在之山名「鲁肃」。宗主称传闻为天地初开时，一把外界之剑落下刺入此地，最终化作山峰。
- 此名由无极宗**第一代宗主周云松**所取：他晚年在此山**入梦得道**，梦见万丈大剑落下化作山峰，并有浩荡之声在梦中说出「鲁肃」二字。太上长老转述时眼含浓浓恭敬。
- 王林听出玄机：**「鲁肃」实为古神之语「箓窣」**，直白韵意为——**「一把以星祭炼的剑」**。

### 王林的震动来源
- 他震惊的不是山峰剑意，而是山中有一丝**当年涂司炼化三叉戟后随手一抛、化作山峰凝聚其魂**的同类感觉。
- 临近山峰时，他眉心隐藏的**古神星点急速旋转**。
- 山内藏着**王族古神的气息**，岁月之久似**比涂司更悠久**；气息在岁月中越来越弱，如今非王族古神近距离感悟不可察觉——**拓森当年来过云海，全无察觉**。
- 王林双脚踏上山峰刹那，此山轰然一震，一股**苍凉之魂**似因他到来而缓缓苏醒。此魂唯王林可察，旁人只觉四周元力与仙气变浓。

### 第六星复凝
- 阁楼内魂气愈浓，冲刷之下王林眉心古神之星旋转更快，**当年在七彩界碎灭的第六星隐隐有了凝聚迹象**，短短片刻已现**漩涡痕迹**。
- 王林立刻低头掩饰神色；宗主与太上长老因认可其修为（视作同辈）未加留意。
- 他感受到那祭剑之上蕴含**连他也感到惊恐可怕的强大**，暗自推测：能让古神星点片刻恢复者，**莫非是九星王族**。

### 隐患
- 此地苏醒气息如沸水般愈发剧烈，**逗留越久收益越大，但久留必露端倪**；修至**天人衰劫**后对天地变化尤为敏感，气息持续剧烈必引怀疑。

## 二、极阴之魂的交易

- 无极宗宗主坦白：极阴之魂**并非无极宗之物，而是神宗所赠**，且**八阶星域其余宗派也均获赠**，目的是**代神宗培养**；无极宗多将其分散给几个分宗吸纳培养。
- 二人对王林索要之意并非全无怀疑，但极阴/极阳之魂确有疗伤之效，且王林确有伤在身；加之亲见其神通，只觉高深莫测，怀疑遂淡。
- 太上长老先松口「可通融」，宗主拍板：**「这极阴之魂当年神宗所赠后从未来取，也积攒了不少，想必送给吕道友一些，神宗也不会知晓。」**——言下之意是无极宗**拿出了相当于给神宗的贡品**。
- 王林抱拳致谢，承诺**此番八阶大比全力以赴**。说话间山中古神气息正顺双脚疯狂涌入眉心，第六星极速凝聚。
- 宗主虚空取玉简、神念刻入抛出，玉简燃烧飞出传讯，命人取来极阴之魂，请王林**稍等片刻**——正中王林下怀（他本就想方设法多留）。

## 三、另一颗修真星：分宗大比之后

- 分宗大比结束，数万修士在冯海等长老负责下散归住处。
- **归元宗**在冯海**亲自相送**下，从偏远居所搬入**为七阶宗派准备的庭院**。
- 修真星上开启**浩荡阵法**：**无令牌不可外出，进入却无妨**。
- **李倩梅**随归元宗住进庭院，夜色渐深时立于院中望空等王林归来。
- **木冰眉**独自站在归元宗庭院千丈之外，月下身影孤独萧瑟，咬着下唇同样在等王林——**她有话要说，也必须说**。

## 四、神宗杀劫：白发童子锁定吕子浩

- 地点：八阶星域之外、**九阶星域中心星雾最浓处**的一颗巨大修真星，一座通体森然气息的宫殿。
- 人物：**白发童子**——肤色红润、头发花白，双目开阖精光逼人。身前浮着**七枚刻名玉简**，**第三枚刻的是「吕子浩」**。
- 动机：**自「主人」的气息散出之后**，他发动**神宗之力**搜索云海、排查一切可疑之人，最终筛出七人；逐一排除后，**唯余吕子浩**。
- 关键证物：他左手虚空一抓，得到一团火焰包裹的玉简——**正是王珊珊在无极宗内以特殊方法送出之物**。火焰融入其手，**王林在无极宗的一幕幕清晰浮现在其脑海**。
- 结果：童子猛然起身，**除「吕子浩」外其余六枚玉简尽数崩溃**；一股**与罗天星域鲁夫子一般强大的本源气息**自其体内爆发，卷动天地，连星外星雾也剧烈涌动。
- 断言：**「就是他了。错杀一千，也决不能放过一个可疑者。」**

## 五、看点与伏笔

1. **鲁肃=箓窣**：无极宗立宗之山其实是一位极古老王族古神以自身古神之星祭炼的剑，代价是废掉自己的星；疑为九星王族。
2. **第六星复原路径**：七彩界碎灭的第六星在此山可快速重凝——王林有强烈动机长留此地，与「久留必暴露」构成直接冲突。
3. **王珊珊传讯**成为杀劫触发点：她送出的玉简把王林在无极宗的画面直接递到神宗白发童子眼前。
4. **神宗—八阶星域的供养结构**：极阴之魂由神宗散发给各宗代培，无极宗赠予王林等同挪用贡品，埋下追责隐患。
5. **木冰眉「必须要说的话」**与李倩梅同夜等待，情线待发。
6. 作者按：进入云海星域后酝酿的、全书至今**最大的一系列**事件今日露出引线。
