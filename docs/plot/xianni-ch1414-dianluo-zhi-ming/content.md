# 第1414章 颠落之名！（第九卷 云海之巅）

## 一、虚火之变：王林成为古往今来第一个可吸收虚火之人

**虚火设定（朱雀一族）**
- 虚火无形，可燃一切情绪化作火焰，是朱雀一族的**灭世之炎**。
- 只能外放伤敌，对朱雀一族修士自身**不能提升修为**；无法从修士体内提炼而出。
- 因其无形，故数量永恒不灭；由实火转化而成，转化时成就多少，直至修士死亡也就只有这么多。

**异变**
- 王林的虚火在诞生一刹那被元磁雾气横扫，发生了连一代老祖都无法理解的诡异变化：虚火吸收了元磁雾气内的一丝元磁之力。
- 关键在于——这丝磁力由**天逆**释放而出，其元磁之力**永恒**，不会像寻常外力那样消散。
- 结果：虚火威力本身没有变化，但王林由此成为**古往今来第一个可以吸收虚火之人**。初生虚火不多，但随不断吸收，其强大程度足以骇然听闻。

## 二、元磁雾气外泄与地方香断裂

- 元磁雾气自王林体内疯狂扩散，转眼弥漫整个地方界，片刻后破界而出，从大帝星上的**地方香**内滚滚而起。
- 雾气冲出弥漫大帝星天空，扩散回到大帝星外，重新成为环绕四周的**元磁撕裂**。
- 前后差别：进入天逆前的元磁撕裂仿若死物、充满暴虐；此刻其内**化成一个整体，如同有了生机**。
- 地方香散尽元磁雾气后，香上咔咔作响、裂缝密布，**从中间骤然断开**；燃烧的那一截倾斜落下，穿透下方巨龟，砰然掉在赛场上。
- 试炼三香现状：**人方香熄灭 → 地方香断裂 → 唯余天方香高耸**。

## 四、地方界内：朱雀入体与拜别

- 元磁雾气尽出后，王林胸口的**天逆珠子**渐渐隐去消失。
- 王林张口一吸，朱雀嘶鸣着直奔而来，**融入其左目**；其体内轰然散出无形无色、带灭世之力的浓浓虚火。
- 王林并未离去，而是身影如梭跨越千万里，来到地方界尽头那座在火海中始终未被焚灭的**秃山**。

### 与四代朱雀的对话
1. 四代朱雀（中年男子）叮嘱：「朱雀四次觉醒后，虚火还需温养一段时日，你要切记。」
2. 王林确认其身份后，转述**五代朱雀**对自己有大恩，其死前念念不忘的是当年曾陪伴四代朱雀身边**做其药童**；四代朱雀目露悲伤，惆怅点头。
3. 王林从储物裂缝中取出一尊石像——**朱雀老圣皇死后尸骸所化**。

### 王林的评价与送归
- 「老圣皇一生为朱雀圣宗呕心沥血，没有谁比他更值得称为朱雀。」
- 当年局面：四代朱雀不在、二代朱雀不在四圣宗，**白虎圣皇战死、玄武圣皇叛逃、青龙圣皇被困**，数万年唯有朱雀老圣皇一人维持，直至死亡都不忘朱雀圣宗与其师尊。
- 王林将尸骸留在此处，让老圣皇陪伴「当年舍弃了他离去、始终没有回来的师尊」，称此处「或许就是他的家」。
- 王林退后跪下**磕三个头**：「今日送您回家……当年之恩无法报答，我的承诺，会继续下去。」
- 王林抱拳谢四代朱雀方才相助后告辞。心中态度：**可以接受二代朱雀，却无法接受四代朱雀**——若非四代当年离去，四次觉醒中定有老圣皇的位置，老圣皇也绝不会归墟而亡。

## 五、四代朱雀的独白：封印与「颠落之地」

- 四代朱雀抚摸弟子尸骸落泪：「**鲁云**，为师对不住你」——老圣皇本名鲁云。
- 四圣宗的一切他都知道，**只是回不去**：当年来到**太古星辰**后出现变故，被一个**神秘之人种下封印**。
- 这封印他数次尝试破解均告失败，**就算是一代老祖也无法解开**。
- 封印效果：他只能留在**地方界**内，走不出半步；一旦出去封印便会爆发，令其丧失心神、沦为疯狂。
- **二代朱雀身上也有同样封印**，其压制之下可以不必待在地方界内，但同样走不出**颠落之地**。
- 四代朱雀苦涩定义此地：「这里，就是我朱雀一族的**颠落之地**——**要么癫狂而亡，要么颠覆而出**。」（本章标题「颠落之名」所指）

## 六、结尾

王林身影向天际走去、消失无影的刹那，大帝星上那第一根熄灭的**人方香**下，其肉身闭着的双眼**骤然睁开**。
