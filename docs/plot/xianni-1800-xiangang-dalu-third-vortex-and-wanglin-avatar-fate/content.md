# 第1800章 仙罡大陆，我来了！（第二更）

## 一、风水与「命格」：王林分身的隐秘机缘

- 王林本不信风水：他是大神通修士，移山倒海、换天改地，甚至能创造星辰，在他看来风水也可由自己创造并掌控。
- 但仙罡大陆此刻的震撼一幕，恰可用风水诠释。文中给出的层级：
  - 葬吉穴者，后人富贵少灾；
  - 葬主吉穴者，富贵数代不止；
  - 葬龙脉者，后人大富大贵；
  - 葬主龙头穴者，可称王开国。
- **关键事实**：王林分身所在之地，是仙罡大陆初开时**仙祖、古祖诞生之地**——虽非同一片弧形石台，但那石台是其中的**一部分**。
- 由此，王林等于拥有了与仙祖、古祖**同样存在的命格**。此命格**不是修为**，却**远远超过一切修为所能达到的极限**。
- 命格此刻不会表露太多，将随时间流逝与分身成长而显现，王林的未来「无法想象」。
- 王林自身态度：并非完全清晰，只是懵懂猜测，且不完全相信；他更相信自己的努力与坚持，更期望分身走出后**轰出那最强的一拳**。

## 二、第三个漩涡：全大陆震动的预兆

- 第三个漩涡出现的一刹那，所有感应到之人无论修为身份皆心神震撼，**就算身为九阳，也神色凝重**。
- 该漩涡特征：仿若初生、尚不稳定、存在无数扭曲；位置在**古祖与仙祖的漩涡之外**；未崩溃，反而**急速膨胀**。
- 许久之后，无边天空中**三个漩涡同时慢慢消散**，似从未出现，无影无踪。
- 结果：一切恢复如常，但骇然如生根般在众人心中滋生；此事仿若一个**沉甸甸的预兆**，压得人喘不过气。

## 三、同一时刻，仙罡大陆上的两个孩童（伏笔）

### 1. 立志当王爷的孩童
- 地点：仙族一处县城。
- 十多岁，单手掐腰做王爷姿态，挥舞小木棍；在两名皱眉修士带领下，与一群孩童被送上附近宗派山门接受考核（天资优异者可入宗为弟子）。
- 内心执着回荡：「老子以后要当王爷」。

### 2. 自称转世老修的骗术少年
- 地点：距上者很远很远的另一处县城大户人家。
- 年纪略小，穿不知何处弄来的道袍，一副仙童模样，被人从**临县**请来。
- 自述台词：「老夫修行三千年，如今返老还童，需经历**九次转世**方可恢复神通……便在你这里居住一些时日，也算结个道缘。」
- 外显：神色沧桑，气息连凡人都能感受；目中灵动似看透人生；沧桑腐朽之感令整个房间**阴气森森**。
- 内心独白：骗术**无师自通**，自己都快信了；若真是转世，上辈子定然是个惊天动地的大骗子；此前曾在**墓地陪尸体待了几个月**，还在邻县有所花费，此番要「百倍转回来」。

## 四、虚无层：王林、蚊王与李慕婉

- 王林全身雾气缭绕，那雾气即**蚊王的身体**，蚊王覆盖其全身、向前呼啸疾行。
- 疾驰中此地**仙罡法则似消散不少**，作用在王林身上的压力已可承受；王林虽迷失方向，但蚊兽**隐隐能感受出口**，带其不断前飞。
- 蚊兽情绪：一路兴奋，时而回头看王林并发出喜悦嘶鸣；它喜欢待在王林身边，「仿佛跟在了父母身旁一样」。
- 隐忧：越深入虚无尽头，**仙罡法则挤压越强**。尽管石壳内的分身在成长中不断滋养本尊，时间一长仍显困难——**主要问题是要保护李慕婉不受半点伤害**。

## 五、要点与伏笔

1. 「命格」是本章设定核心：与修为并列的另一条超越性维度，为王林分身日后地位埋下最大伏笔。
2. 三漩涡并立又同时消散，被明确定性为「预兆」，指向仙罡大陆格局将变。
3. 两名孩童的插叙为典型耳根式伏笔（「当王爷」的执念与「九次转世」的骗术自陈），身份留白待后文揭示。
4. 王林在虚无层的负重前行：分身供养 vs 仙罡法则挤压 vs 护持李慕婉，三者构成当前主线张力。

## 归属说明（据世界状态须知）

- 「李慕婉」已于第188章死亡，本章其为王林一路护持之身（非新行动主体）。
- 王林自第1380章起亦以「烨寞（道古烨寞）」之名/身行事（借势代入化身），本章未直接体现。

# 王林负李慕婉穿越虚无层，破裂缝踏入仙罡大陆

## 一、处境：无血脉者的虚无层

- 王林因**分身与蚊兽的关系**，对**仙罡法则**已有适应，本属优势；但依旧举步维艰，足见虚无层之可怕。
- 王林自省：「难怪古往今来，从未有人可以在没有血脉的情况下走出这虚无层——我带着婉儿，就等于放弃了血脉。」
- 时间感已失，但他明白**十年一定过了**；此后又在追忆中流逝**三年**。

## 二、心念与筹划

### 关于师尊
- 判断师尊怕是无法再等，师尊若离开、回到**道古一脉**并进入**仙罡大陆**，此后一切须靠自己。
- 王林并不慌乱：当年独自从**朱雀星**离开进**昆虚**，由昆虚入**罗天**，此后**云海**、界外**太古星辰**，如今去陌生的仙罡大陆亦无妨。

### 到仙罡大陆后的两件事
1. **尽快提高修为**。
2. **必去东临宗一次**，若有机会进入**东临池**——他极为渴望，想把**五花八门**内的虚幻一幕变成现实，**拥有本源分身**，如此甚至可与**空劫**一战。

### 旧人追忆（仙罡大陆上的老朋友）
- 不知转世投胎之人如今是否有人成功诞生。
- **司徒南**有没有当威王爷；**刘金彪**是不是还会行骗；魔头**许立国**在仙罡大陆会有何造化；还有**清水**、**红蝶**、**李倩梅**。
- 有蚊兽陪伴、有记忆陪伴，他不孤独。

## 三、抵达出口

- 蚊兽速度大减，却凭**模糊记忆与感应**把王林带到虚无层尽头，距出口极近。
- 此出口**未必是玄罗当年所等的地方**：或通向**天牛洲**，或其他地方，甚至**古国三十六郡**也有可能。
- 三年中王林全部修为都护在身后的**李慕婉**身上；她在**避天棺**内如同睡下，十分安全。

## 四、收蚊兽入臂 · 储物空间之危

- 前方虚无中出现一片不浓的光，隐见一条**细长裂缝**，其外若隐若现是一片山峦大地，阵阵仙罡大陆特有的气息传来。
- 蚊兽疲惫不堪，挣扎欲冲入裂缝，最终身子涣散化作水墨、难以成型；王林心痛，右手一抓，使蚊兽化作**水墨图腾烙印在手臂上**。
- **储物空间告危**：上次开启时已察觉不稳、似要崩溃，王林不敢再开——怕爆开，也不知进入仙罡大陆后是否还存在。
- 空间内除丹药法宝外，还有**疯子**与**银衣女子**：二人显然具备**仙罡血脉**，纵有意外滞留虚无层亦无妨（除非如王林般去保护不被允许进入之人或物）。

## 五、横闯裂缝

- 王林背负李慕婉原地调息半晌，猛睁双眼，如同当年在**朱雀星域外战场化身香魂冲出**一般，爆发体内全部之力，化作长虹直奔裂缝。
- 为不伤李慕婉，除速度外几乎全部修为都放在身后，**只凭肉身横闯**。
- 百丈、五十丈、三十丈、十丈直至一丈——肉身如燃烧般剧痛，双眼却明亮至极。
- 最终一喝：「**仙罡大陆，我王林，来了**」。
