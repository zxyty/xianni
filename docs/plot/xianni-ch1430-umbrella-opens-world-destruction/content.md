# 第1430章 伞开灭世！！（第九卷 云海之巅）

## 一、时机：雀羽出手
掌尊（七彩火焰内的中年男子）法术失败的瞬间，王林抓住自己创造的机会，毫不犹豫取出**一代朱雀所赐、用以杀三代孽雀的至宝雀羽**，唤出「朱雀源灵」。

- 漫天火海沸腾，王林上空出现巨大火焰漩涡，如黑洞般似开启通往神秘世界的大门。
- 一声惊天朱雀之音自漩涡咆哮而出。
- 王林体外**四次觉醒的本命朱雀**幻化而出，眼露敬畏，存在本能恐惧；掌尊身后的七彩朱雀亦仰天嘶鸣、恐惧到不敢升空。
- 掌尊瞳孔收缩：「老家伙竟然把此物送你来杀我」。

## 二、朱雀源灵降临
- 此羽召来的**不是朱雀族修士所修的本命朱雀，而是存在于一代朱雀家乡、活生生的一尊真正朱雀**。此羽为一代朱雀至宝，王林仅有一根。
- 巨大朱雀喙自漩涡沉下，仅一喙即占据大半个天空，威压令此地温度骤升如成炎界。
- 整个天空化作朱雀源灵巨大头颅，双目露出疯狂怒火，**神色与一代老朱雀极为相似**。
- 威势评估：**堪比古神一指而声势远超，唯有八星以上成年古神亲自施展神通方可对抗**。

## 三、掌尊反击：地水火风·四大皆空
七彩火焰化朱雀迎击，一触即凄厉惨叫崩溃，掌尊喷血。随后掐诀低喝「地、水、火、风」：

| 次序 | 施展 | 结果 |
|---|---|---|
| 地 | 脚下现无边大地 | 最终穿透其身体，如补天之石向上封漩涡 |
| 水 | 大地之上滔滔之海 | 第三、四息拍向雀喙，化无尽水汽倒卷 |
| 火 | 海水燃烧、七色火焰冲天 | 第二息与雀喙碰撞，轰然崩溃 |
| 风 | 狂风横扫火焰 | 第一息临雀喙，风崩雀喙一震 |

王林判断：无论朱雀喙还是掌尊，眼下修为**绝非水道子、司墨子一流可比**；四大皆空与朱雀喙碰撞的冲击足以崩溃火雀族圣地，连他自己怕也无法存活，除非展开同级大神通对抗，或走预备后路离开界外回到界内。

## 四、抉择：不退，杀掌尊
王林一生险中求生，认定这是重伤或杀死掌尊的最好良机，错过几乎再无可能。他要在界外、继毁灭闪雷族之后，干出一件**震惊整个太古的绝天大事——杀掌尊**。

心中两点明悟：
1. 「好狠的一代朱雀」——一代朱雀存活太久、心机极深，王林虽已明悟其全部计划，仍差一步。
2. 「二代老祖突然传我那朱雀一族最强之术，显然是看透了这些，以此帮我」。

## 五、九息成伞
王林一边承受冲击一边掐诀，与朱雀喙/四大皆空的碰撞逐息并行：

- **第一息**：风崩雀喙、第一波冲击横扫 → 王林第一组印决打出，身前凭空出现一根巨大**火骨**。
- **第二息**：七彩火焰与雀喙碰撞崩溃、第二波冲击 → 第二组印决打出，火骨上出现**伞支**。
- **第三、四息**：海水拍向雀喙化水汽倒卷，雀喙前端崩溃，朱雀张口喷出腹中之气，直奔补天大地。
- 雀喙终告崩溃，第三波冲击扩散，星空撕裂，**火雀族圣地开始崩溃**；掌尊喷血化红雾推动布满裂缝的大地补天，盖住火海、封上漩涡。
- 掌尊面色苍白、转身狰狞迈步扑向王林。王林被冲击入体、嘴角溢血，四周已有一百多万印决疯狂出现。掌尊面色大变：「该死的，那老家伙竟然传你此术」。
- **万古木灵**被王林放出，挡在身前抱向掌尊，被掌尊如太阳般的巨大掌印穿透，掌印直奔王林。
- **第九息**：王林右手打出最后一道印记，双手血肉模糊几乎无法移动。近两百万印记化作火焰风暴，与火骨伞架融合，形成一张**尚未张开的巨大焚界古伞**。

## 六、焚界古伞
- 出处：朱雀一族最强之术，由二代老祖所传，王林刚刚学会。
- 施展条件：王林本身即是朱雀，且修行禁制练就了以极快速度打出印记的神通，故可施展；但明悟不多，此次威力略有逊色——即便逊色，仍足以惊天。
- 代价：施展中体内生机疯狂流逝，被古伞吸收，化作**撑伞之力**。
- 收束：王林双眼通红，一口鲜血喷出，仰天低吼「**伞开灭世**」，双手猛地一甩。

## 七、悬念
本章止于伞开的瞬间，掌尊掌印已至，胜负未揭。
