# 第1940章 瞒天过海！（第三更）

## 一、缘起：东临宗之行被打断

- 王林原定按地图玉简前往**东临宗**。东临宗名列**九宗十三门**，以神秘著称，门人极少外出交流，故王林的**龟甲**与所获**地图玉简**中关于此宗的信息极少。
- 王林心中评估：不知其内有无**天尊**修士，「即便是有天尊修士，也无妨」。
- 抬步之际，神识散开，从**数万里外一处凡间城池**感受到一股熟悉波动。

## 二、转世封印的感应机制

- 该波动来自王林当年在**洞府界**为**所有转世之人**统一封印下的印记。
- 特性：**距离远无法察觉，距离近则神识可感**；因是统一布置、无差别，**只能察觉、不能辨明身份**，必须亲眼见到方可确认。
- 先例：当年在**地门外**察觉到**周佚与青霜**时，亦是同样情形。
- 王林心情：难得的喜悦与期待，「无论是谁」都让他开心。

## 三、认出刘金彪

- 王林转瞬掠过万里，悬于城池上空，见城门内被近百凡人簇拥的**白发老者**——**仙风道骨、神色隐藏得意**。
- 不需波动，仅凭熟悉面孔即可一眼认出：**刘金彪**。
- 王林判断：刘金彪当年**自悟骗道**，转世之后**竟也走上同一条道路**；一扫之下即猜出其目的。
- 反差与苦笑：刘金彪在洞府界**能骗修士**，如今**修为已至金丹**，却在此地**骗凡人**。
- 王林选择**不立刻现身唤醒其记忆**，而是隐身天空旁观（他若不愿被察觉，极少有人能见其身影）。

## 四、刘金彪的「不妙之感」

- 入城行走间，刘金彪心神一颤，生出前所未有的、**似从灵魂内传出**的不妙感，形容为「如同小孩犯错时看见了自家大人」。
- 谨慎察看四周与天空后未见异常，感觉仅一瞬即逝。（实为王林在上方注视所致。）

## 五、选童三日与出城

- 入城后三天，当地有名望之人纷纷送自家子嗣前来，刘金彪以慈祥目光一一扫过。
- 第四天离城，带走**五个孩童**：三男二女，**最大十三岁，最小八岁**。
- 排场：坐**轿椅**，四名**筑基**大汉抬轿，随行**拿宝童子**多为**练气期**，其中大半是刘金彪传授修仙之法后自行修成。
- 孩童与其亲人的共同心愿：进入仙门、成为仙人。
- 王林三日皆皱眉观察：刘金彪**未骗取丝毫财物**，只带走五个「略可修仙」、难被任何仙族宗派看中的孩子。王林心中警戒：「若他有什么歹念，我定难饶他」。

## 六、山谷洞府：坦白与交易

地点：**大圣洲**一片山峦内的偏僻山谷，谷中有若干开辟出的洞府。刘金彪化黑风带五童入内，盘膝而坐。

### 1. 先抑：承认说谎
- 「之前在你们亲人面前，老夫并没有说实话」——五人资质其实**很一般**，只是**略能修仙**。
- 选中他们的真正理由：**心志坚定**。「资质寻常不怕，有一颗坚定的心，极为重要。」
- 直言：**「我是一个骗子」**，骗了你们的亲人，把你们带到这里。（此言令五童与旁观的王林同时一怔。）

### 2. 后扬：瞒天过海之法
- 现状判断：以其对**大圣宗**各宗门的了解，这些孩子的资质**无法通过宗门测试**，宗门不会收、也不会在他们身上浪费时间——「这一点，我没有骗你们」。
- 手段：有一法可使资质**如瞒天过海一般骗过考核修士**，甚至令资质**看起来极为优秀**。
- 风险披露：终究是假的，入门后若表现不佳被**再次探查会被发现**；但**不会有生命危险**，**大都不会被驱除宗门**，只是**沦为末流**。
- 他的获利方式：以孩童为依托送入宗门，凭其资质**换取所需之物**；资质越好→孩子初期待遇越好、他换得之物质地越佳→**但暴露可能也越大**。
- 自我定位：「我帮你们瞒天过海入仙门，进入后一切机缘造化就看你们自己」，从中赚取乃**本应之事**。

### 3. 选项与建议
- 资质档次三选一：**优异 / 上佳 / 寻常**。
- 刘金彪建议选**「寻常可入山门」**即可——因他准备**长期做买卖**，不想暴露次数过多**被人惦记追杀**。
- 不同意者：**抹去这段记忆**，送回亲人身边。
- 细节：说着从**储物袋**中取出花生，剥皮吃了起来。

## 七、五童的抉择

| 人数 | 选择 | 处置 |
|---|---|---|
| 3 人 | 害怕，选择回家 | 被抹去记忆，送出洞府交予随从，传音令送回城镇，告知亲人「入门失败」 |
| 1 女童 | 留下，选**寻常**资质 | 随刘金彪 |
| 1 男童 | 留下，坚定选**上佳** | 随刘金彪；系五人中**资质最好、心志颇坚**，出身寻常百姓之家，机缘巧合被选中，刘金彪为之深深看了他一眼 |

## 八、王林的态度变化

1. 初见：喜悦、期待 →
2. 见其骗凡人：神色古怪、苦笑、头痛 →
3. 见其带走孩童入山：**神色略有阴沉**，内心默语「你去骗修士，我可以不理会，但你若去骗这些孩子就太让我失望了」 →
4. 听完全程：若有所思，最终**露出苦笑**——「这刘金彪上辈子是个骗子，这辈子似乎骗术更高明了一些」。

## 九、遗留线索

- 王林尚**未唤醒**刘金彪的前世记忆，重逢尚未挑明。
- 东临宗之行被暂时搁置。
- 洞府界转世者封印仍在起作用，可作为王林寻找其余故人的线索。
