# 第1757章 棋局！

## 一、局势：白虎的棋盘

王林此前以神识扫过第三颗修真星，已看出此地端倪——

- **规则本质**：如同下棋。参与者各分出一丝神识，融入下方百万两军中的某个兵或将，以凡人身躯投入这场杀戮滔天的百万之战；本尊则盘坐星空之上操控。
- **棋盘**：下方百万两军，全部是白虎既定规则所化的虚假存在。
- **棋子**：三人各自神识所化的兵将。
- **压制**：入局者修为被完全压制，无法全面爆发。

## 二、兵与将之分——白虎自认的优势

王林的推演：

1. 此地三百残界本身封不了血脉，但**以整界之力集中作用于二三人**，却足以压制血脉，血脉一压，修为更不用说。
2. **白虎**是仙人且兼修肉身之力，血脉虽被压制，肉身凶悍犹存，故化「将」（白甲将领，骑马、马鞍旁可抽出长枪）。
3. **五行星中年男子**不修肉身，如文士一般，故化「兵」。
4. 白虎认定王林**无仙人血脉**——当年见王林施展李广弓，感受到那靠的是「仙人不灭体的血液」而非血脉本身。故认为王林即便分出神识化兵，也只是寻常凡人；且不会给此界规则增加负荷、不会稀释规则。

**白虎不知道的**：王林虽有道古传承与古神肉身（这点白虎或许知晓），但道古传承中**亦含血脉之力**——此血脉虽会被压制，配合修为却不弱于白虎，反而更强。这是王林果断入局的底牌。

## 三、入界：规则被冲散

王林向前一步迈入残界，残界立刻轰鸣、回荡星空，仿若撕开天地，强行融入一股力量，**略微冲散了白虎定下的规则**。

验证了王林的判断：整界之力压两人尚可压至九成以上，出现第三个同样具血脉之力者，压制便被分散、效力必减。

连锁反应：

- **五行星中年男子**双目精光，感到体内血脉压制松动；其神识所化士兵周身泛起淡淡金光，长枪如利刃，连斩数名扑来的敌兵。
- **白虎**神色骤变，露出无法置信之色：「他居然有血脉之力……不可能，在他体内我明明没有感受仙人血脉的存在，当年即便是有，也只是融于李广弓内而已。」

王林身形扭曲消散，现于第三颗修真星上空，与白虎、五行星男子成**三角之势**，本尊盘膝坐下，嘴角冷笑。

## 四、战场：从士兵到黑甲修罗

### 融入与首击

王林神识不受自控地分出一丝，直奔下方战场，融入白虎战将**敌对方**的一名普通士兵。该士兵一顿，**头发化作一片白色**，样貌模糊后瞬息变为王林。

白甲将领自马鞍抽枪掷来，王林转身一刀，将长枪劈成两半；断枪呼啸而过，**将其身后一名敌兵钉死在泥土中**。

### 白虎的应手

白虎索性闭目，全部心神沉入白甲将领。将领右手一指，身周黑气缭绕**化作十个黑甲之兵**，冷酷冲入战场直取王林。

### 杀戮与凝甲

- 王林每杀一人，死者化作一缕烟丝融入其体内，体外黑气渐浓如黑色火焰。
- 斩杀首名黑甲兵时，王林踏敌兵头顶腾空，一刀劈碎大盾、将其从头至身斩成两半；在那黑甲兵眼中，王林的身影**取代了昏暗天空上的血月**。
- **连杀近百人**并斩黑甲兵后，体外黑气凝聚收缩，化作**一套黑色铠甲**穿在身上，与其一头白发辉映；手中刀亦转黑、变长如弯月。
- 半柱香后，白甲将领所化的**十个黑甲之兵全部葬身刀下**，黑甲几乎包裹全身，只剩头部无盔。
- 同期，五行星男子的神识士兵也凝出**金色铠甲**，但形制简易，远逊王林。

### 黑马与追杀

白虎睁眼、青筋鼓起，再度闭目沉入白甲将领；将领抽出第二把长枪并后退拉开距离。

王林自知**入此界时间短暂，必须速战速决**，长刀震地借力腾起，连踏军兵头颅前掠；所踏之人尽化黑气融入其身。前行百丈后，黑气再凝，伴一声戾气马嘶，**化作一匹黑色骏马**。王林骑马如黑色旋风，所过之处无一活口，直扑千丈外的白甲将领。

## 五、支线：七彩道人逼近

另一残界内，七彩道人已**连续走过近百界**仍未寻到王林，焦急中撕开星空缺口穿行。忽然身形一顿、双眼狂喜——他感应到了王林的气息，虽不在此界，却距离不远。再撕一道缺口钻入后自语：「近了，我可以感受到，他就在前方不远。」

## 六、要点归纳

- 白虎的「优势」建立在对王林血脉的**错误判断**上，王林入界即以血脉冲散规则，优势反转。
- 王林在棋局中的成长路径：普通士兵 → 黑气缠身 → 黑甲黑刀 → 黑马冲阵，全部由**杀戮转化**而来。
- 三方入局者：王林（本尊+神识士兵）、白虎（神识白甲将领）、五行星中年男子（神识金甲士兵）。
- 悬念：王林时间有限、能否速斩白甲将领；七彩道人正在逼近。
