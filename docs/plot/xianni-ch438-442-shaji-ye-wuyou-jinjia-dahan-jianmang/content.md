# 仙逆 第461-462章《杀机》《叶无忧》剧情梳理

## 一、局面
- 地点：灵山所在海域，海面上空悬浮**金甲大汉**（金甲巨人），手持金剑，以百丈剑芒守关；海面之下有一座散发金芒的**巨大宫殿**，通往**修星之晶**。
- 金甲大汉的角色：守护者，只放行「符合要求者」进入宫殿。
- 先行者：**云雀子**与一名**陌生/阴森老者**已抗下一剑进入宫殿。
- 滞留者：王林（化名「曾牛」，婴变初期）、**乾风**、**柳眉**（玄道宗）。

## 二、三人心思（互相算计）
- **乾风**：忌惮王林极深，尤忌其**十亿尊魂幡**——认为那是能灭杀自己之宝；此前正是他派**红蝶**去拖住王林，以便自己独抢修星之晶，到灵山才发现还有几道关卡。他不敢轻视婴变初期的王林，但深藏傲意，认为「若无十亿尊魂幡，王林不足与自己相提并论」。他提出三人联手，本意是怕王林顾忌太多不出全力。
- **柳眉**：无情之人。她盼乾风能杀掉王林——如此她「最后一幻」中便不再有对方气息，日后成道时少一心魔。
- **王林**：自知硬抗剑芒必须祭出**问鼎之魂**，故不硬拼，转而算计规则与人心。

## 三、王林破解的关卡规则
王林由先前「小猴与阴森老者相距不足十丈，金甲大汉只挥出一道剑芒」推断：
1. **十丈之内的修士被判定为「一伙」**；
2. **剑芒攻击这伙人中距离剑芒最近者**。

据此他拒绝了乾风「二人先上、柳眉接应」的方案——那样虽也在十丈内，但距离太近，稍有小动作以乾风之机智必生防备。改为**主动请缨独自第一个接剑芒**，反倒把乾风诱来。他判断即便乾风不提联手，对方也必在自己危难时偷袭，只是引其入十丈会更麻烦；他另有八成把握的计策。

## 四、第461章 杀机：坑杀乾风
1. 三人成品字形飞向金甲大汉，金剑下斩，百丈剑芒开天辟地般落下，海面被压出深沟。
2. 王林亲身承受：**元神轻颤有不稳之象**，全身如被无数大山压住——与当年在**炼魂宗**地底深处灵脉中感受灵威的感觉相同，但强百倍千倍；剑芒未至已口角流血，眼中犹露不屈。
3. 乾风见状动摇，当场变卦：决定先杀王林夺魂幡，再以魂幡抗剑芒。为求一击必成，他佯装接应「曾道友莫慌，乾某来了」，疾驰近身。柳眉看破意图，故意不跟，留在后方。
4. 王林早已算定。待乾风进入**十丈**之内的一刹那，一拍储物袋祭出**宝塔**——塔上弥漫**周佚**「问鼎初期」的一丝神识，剑芒被冲得一缓；王林借这一缓收塔、下沉冲向海面，并**始终与乾风保持十丈**。
5. 金甲大汉不追王林，剑芒恢复威能，转而落向此刻距其最近的乾风。乾风面色大变，祭出**红色锥子**，锥上雷电狂涌迎击。

## 五、第462章：反手重创柳眉、闯入宫殿
1. 柳眉见转折心生明悟，疾驰追向王林；王林随即冲出乾风十丈之外，金甲大汉连挥两剑，两道剑芒分击王林与柳眉。
2. 王林不退反进，瞬移到**柳眉十丈之内**，抹储物袋放出数个**岁月木雕**并低吼「岁月」——木雕尽数自爆，岁月意境弥漫。柳眉虽**千幻意境大成**，木雕上的岁月意境虽伤不到她、迟滞亦短暂，但在此刻已是致命。
3. 柳眉一慢，王林立即下沉至其下方；天空两道剑芒**合二为一**斩向柳眉。王林更虚空一点，射出一道**禁气**追击。
4. 王林不看结果，直冲海中。海洋内笼罩着一股奇异之力，**限制瞬移类神通法术**（他曾在别的奇异之地感受过，故不试便知）。
5. 追杀：一道百丈剑芒从天而降直追王林，天灵刺痛、头顶滴血。距宫殿不足百丈时剑芒临身，王林喷血、取出**战斧**横挡硬扛一击，元神震荡；再拍出**宝塔**，周佚意境扩散令剑芒一缓，借势横渡五十丈冲入宫殿，剑芒随即消失无影。
6. 入殿后王林盘膝服下大把丹药仍全身刺痛，遂取出一块**仙玉**吞下，磅礴仙力回荡体内，压下伤势，起身向宫殿深处冲去。
7. 海面上柳眉自救：口喷白雾，雾中**白色丝带**飞舞，一抽破碎禁制，丝带裹身退出千丈之外，剑芒消散。金甲大汉未再追击。

## 六、要点与后续伏笔
- 王林首次成体系地「用规则杀人」：不拼修为，拼对守关判定机制的解析与对人心贪欲的预判。
- **周佚的问鼎神识（宝塔）**成为两次脱身的关键道具。
- 乾风、柳眉与王林之间的杀机已彻底摆到明面；乾风、柳眉本章均未确认死亡（柳眉明确脱险）。
- 王林已入海底宫殿，进入修星之晶争夺的下一关卡；云雀子与阴森老者先他入内。
- 第462章标题为「叶无忧」，但本段正文未出现该人物内容（叶无忧已于第414章死亡）。

# 第438章 海底宫殿：修星之晶与一代朱雀叶无忧

> 归属须知：本片段中的「曾牛」为王林自创化名（自第309/423章起），言行归【王林】。「一代朱雀叶无忧」已于第397/414章身死，此处为其尸身，非新行动。

## 一、宫殿外：乾风与柳眉的裂痕

- **入宫门槛**：进入海底宫殿的要求只有一个——能抵抗「一剑之芒」。乾风被剑芒逼得极为狼狈，闪躲而出；剑芒不追击，人一离开便停止攻击。
- **乾风立誓**：面色狰狞，疯狂咆哮：「曾牛，我乾风发誓，定要把你碎尸万段，如违此誓，定叫我乾风不得好死。」
- **柳眉斥责**：柳眉面色阴沉盯着海面，久之开口令其住口，指出若非乾风不怀好意、三人真正联手，此刻恐怕已进入宫殿内，不至落到眼下境地。
- **旧怨浮出**：乾风反咬柳眉与「那小子」（曾牛/王林）勾勾搭搭、眉来眼去，并提醒她「当年你答应我什么了」——暗示二人之间有旧约。
- **柳眉的判断**：有云雀子在，曾牛很难抽回命魂，云雀子不会那么轻易让他成功。

## 二、乾风的底牌

- 乾风摸了摸储物袋，提到「老家伙」给他的东西，**原本是准备对抗十亿尊魂幡的**。
- 他推断：既然此物可抗尊魂幡，想必对**问鼎修士**也能产生一些作用。
- 计划：等云雀子出来后祭出此物，**只要命魂**；若对方不给，「反正左右都是死，拼了」。

## 三、宫殿内：诡异通道

- 王林眼前是一处巨大通道，四周数盏忽明忽暗的灯几，其上散发妖异光芒——**并非火焰**，而是王林从未见过的奇异之物。
- 通道弯曲、看不见尽头，昏暗光芒映照下氛围诡异；王林走了许久，环境依然如故。
- **神识受制**：初进此地时神识一散便无声无息消失了一部分，似被某种虚无之物吞噬，故王林不敢将神识散得太广，小心翼翼前行。

## 四、巨塔、死尸与修星之晶

- 前方传来法术波动，王林停步小心放出神识，发现通道尽头是一处巨大空地。
- **巨塔**：空地中心一座数百丈高的巨塔，塔上有一张宝座。
- **宝座上的死人**：身穿暗红色长袍、头发披散脑后，年入中旬、相貌平淡无奇，却给人威严傲然之感；双目紧闭、全身没有任何生机，显然是死人。其身上散发滔天且浓密不散的气息，环绕此地四周。
- **无形威压**：王林神识见到此人瞬间，忽有控制不住想要叩拜的冲动，运转体内仙力方才压下——此地似有无形之力，使所有望及此人者心神震动。
- **紫色光团**：死尸身前飘着一个拳头大小、散发紫色光芒的光团；光芒映在中年男子身上，**在其身后留下一道黑色的影子**。此刻光芒略显黯淡、忽明忽暗，似随时可以熄灭。
- **神识被击退**：王林神识触到光芒的瞬间，一股庞大力量自其内挥舞而出，落在其神识上，神识疯狂撤回；通道内王林面色苍白、眼露惊骇。
- **身份判断**：「一代朱雀叶无忧」——王林几乎立刻猜出中年男子身份；紫光光团自然就是**修星之晶**。
- **关键疑点**：此修星之晶在王林眼中虽与**司徒南所说**一样，但神识触摸时，**没有那种命魂在内的心揪之感**。

## 五、云雀子的请托与王林爆退

- 云雀子出声：「既然来了，那便进来。」——王林先前神识只注意到一代朱雀与修星之晶，未看到早已进入此地的云雀子与阴森老者。
- 王林走入空地，与数百丈巨塔相比顿生渺小感；在远处角落见到云雀子。
- **云雀子状态**：面色苍白、盘膝而坐、嘴角流血、萎靡不振，自称已**油尽灯枯**；笑称「我果然没有看错你，你是第三个进来此地之人」。
- **对手处境**：云雀子以**阵法**困住「带着猴子的老者」（阴森老者），称其**绝非朱雀星之人**，法术神通极为诡异，自己只能困住不长时间；一旦脱困必抢走修星之晶，届时整个朱雀星之人都会面临危机。
- **请托**：「这修星之晶，你去帮我取来，为了我仙遗族也好，为了修士也好，我不能让这修星之晶崩溃。」并让王林以神识查看自己以确认其油尽灯枯。
- **王林的选择**：神色如常，抬头看了一眼塔上叶无忧身前那团紫光后，**没有任何犹豫，身子立刻爆退**，以比进来时数倍的速度向通道疯狂飞驰而去。

## 六、看点与伏笔

1. 修星之晶「无命魂心揪之感」——极可能是赝品/命魂已被转移，或另有玄机，直接引发王林弃取爆退。
2. 云雀子的请托与其「油尽灯枯」自证，动机可疑；王林的即时撤离说明他判定其中有诈。
3. 乾风手中「可抗十亿尊魂幡」之物成为宫殿外的悬置威胁，其目标同样是**命魂**。
4. 柳眉与乾风的「当年之约」为未点明的旧事伏笔。
5. 「带猴子的老者」非朱雀星之人，来历成谜，是抢夺修星之晶的第三方势力。

# 第463章 抢夺

## 一、拦路与摊牌

- 云雀子瞬移挡在通道前，喝问王林「你跑什么」。
- 王林退后数步，右手一挥凝聚**十亿尊魂幡**，平淡回应：「晚辈还不想死。」
- 云雀子冷笑问他是如何看破的。王林给出两条依据：
  1. 塔顶之物**不是修星之晶**；
  2. 云雀子**尚能瞬移**，说明伤势远没有他自称的那样严重。
- 云雀子露出赞赏之色，承认王林是「我选择的四人之一」，并坦白：此物是**星引**，他一来此地便已知晓——**只需触摸此物，便可把命魂抽回**。

## 二、利诱：仙遗族远古祭坛

- 云雀子自陈：利用星引抽回命魂**需付出很大代价**，故要王林代为动手。
- 许诺重宝：**仙遗族地下最深处有一处远古祭坛**，当年**仙遗族虚祖**便是在那里获得了**十一叶提升至十二叶**的力量；事成即送王林前往，助其修为更进一层。
- 云雀子渐显焦急，威胁「莫要逼老夫动手，你知道的，老夫不想杀你」。

## 三、定金：草帽使用之法

- 王林提出：若你食言，我岂非白做——要云雀子先交出**草帽的使用之法**作定金。
- 背景：王林储物袋内一直存有云雀子当年所赠**草帽**，其内阵法极多、颇为复杂，无使用之法则不能全部操控。
- 云雀子自认王林今日跑不掉，取出一枚**玉简**凝神数息后掷来；王林接住查验属实，收入储物袋，随即化作长虹直奔塔顶。

## 四、破局：无影之疑与影禁发动

- 王林行至**一代朱雀子（叶无忧）**身前，先扫视其身后的影子，再看向那**紫色光团**。
- **关键破绽**：王林立于紫光映照之下，地面上却诡异地**没有任何影子**。
- 王林当面摊牌：
  - 「曾经我以为你是我王林的恩人，一直到知晓你是仙遗族之人时，我也没想过与你作对，只想离开朱雀星，追寻我的道。」
  - 「今日，前辈，你令我很失望……如果按你的说法做了，恐怕不用你动手，我就会立刻身亡吧。」
- 王林事后判断：星引之效**应如云雀子所说**，但代价是**以命换命**；否则云雀子早已自取，不必等到今日——**第三个进入之人无论是谁，都会被驱去取命魂**。

### 影禁之术

- 王林抖动十亿尊魂幡，无数魂魄呼啸而出，直冲**一代朱雀子座椅后的影子**。
- 影子咔咔崩溃，桀然长笑与红芒暴闪中，**阴森老者**一步迈出，其肩上**小猴**一跃直扑云雀子。
- 阴森老者点破此局：
  - 王林借**已死之人（一代朱雀子）的残余之力**，加上自身修为，化作**影禁**，将其生生禁锢；
  - 此术「就算是在上古时期也极为少见」；
  - 「若是主人本体降临，一拳就可击碎」，此刻被困的只是**主人一丝分识夺舍**之身。
- 伏笔：王林此前**神识探查**时便注意到叶无忧身后影子有异，站定后又发现自身无影，遂决意一赌；**若失败则立刻遁入天逆空间隐藏**。

## 五、云雀子攻小猴

- 云雀子双手一挥，虚空中幻化出**金色符文**盘旋，目标却非阴森老者，而是那只**小猴**。
- 云雀子低喝：「区区傀儡之物，灭了你这分识真正藏匿之处，你即便本体再强，也无法现在赶来。」
- 由此确认：**小猴是傀儡，且是那一丝分识真正藏匿之处**。

## 六、脱身与塔崩

- 王林认定：此地既无修星之晶，被夺舍的老者与云雀子都不是他此刻愿意招惹之人，唯有尽快离开——遂以魂魄卷身，从一旁急退。
- 就在此时，此地剧烈震颤，如天崩地裂；宝塔之上咔咔作响，裂缝丛生。
- **修星之晶的又一次崩溃开始了**：一道裂缝如游龙自下而上疾驰，最终延伸至塔顶**一代朱雀叶无忧的坐下**。

# 第463-464章 修星之晶现世与朱雀传承

## 一、叶无忧身死，修星之晶出世
- 叶无忧坐下宝座清脆碎裂一分为二，从宝塔上落下；叶无忧身体一震后化作飞灰消散。
- 灰烬中飘起一枚**小半个拳头大小的白色结晶**——**修星之晶**。
- 王林瞳孔骤缩，立刻感受到晶内有**与灵魂相联系的波动**（其命魂在内）。
- 场中云雀子、阴森老者、小猴全部停止斗法，齐盯晶石。

## 二、争夺与异变
- 云雀子倒吸冷气脱口道破名字，欲冲出；小猴更快，与阴森老者一前一后疾驰而去。
- **王林的抉择**：自知在云雀子与「被拓森一丝分识夺舍之人」面前无资格争抢，即便到手也无时间抽回命魂，反招杀身之祸——**果断放弃，以尊魂幡包裹全身冲向通道**。
- **阴森老者之死**：抓住晶石，仰天长笑「主人脱困之日，就在眼前」，随即面色骤变，整个身子以肉眼可见速度化作丝丝烟气，尽数钻入白色晶石之内。

## 四、朱雀传承（第464章）
### 触发

### 传承画面
1. 一威严傲然男子脚踏**紫黑星罗盘**（其上诡异电光，星空中所过轰隆作响），前方为漂浮星空的巨大仙阁「**仙印府**」。
2. 仙阁内虚无之声喝「止步」；男子抱拳：「晚辈新晋六级修真国朱雀国**叶无忧**，奉**修真联盟**之命，前来领取**朱雀印诀**。」
3. 男子登至仙阁第三层止步；虚无之声定义：「**朱雀印，低阶神通之术，属于传承之法，需封号修士，才可施展而出**」。
4. 红芒印诀凝形，**依稀与仙遗族头骨符文相似，细看又完全不同**；印诀自眉心融入，王林眉心剧痛如魂魄被烙印，一度失去自我、化身为那威严男子，忍不住咆哮。

### 外显异象

### 关键抉择：拒绝封号

- **王林答「不愿」**——他的追求并非安于一地、成为一代朱雀。
- 一声叹息后，红芒与脑中印记如落潮般尽退，全部凝回右手白色晶石。

## 五、命魂取回之法
- 王林内心呐喊「命魂」，那声音留下一句「**一命换一命**」，并在其脑中留下一个散发幽光的诡异符文，令其福至心灵有所明悟。
- **两条路**：
  1. **一命换一命**——从修星之晶内换回命魂；
  2. 等命魂被灵物吸收融合后，**杀灵物取命魂**——但在浩淼命魂中遇到属于自己之物纯属机遇，无法强求。

## 六、抛晶石与后续
- 冲出海面时王林心神彻底清明，确认**纳多撒谎**：此物与**极境**毫无关系，更谈不上使极境进化。
- 王林毫不犹豫将白色晶石抛向**乾风与柳眉**所在之处，喝道：「这，便是修星之晶！」
- 乾风原本正要祭出朱雀子给他的最终法宝，见白芒飞来未立刻去抓，随即懊悔——云雀子加速穿过王林直扑晶石。
- 乾风一咬牙拍储物袋，取出**布满密密麻麻黑点、丝丝黑芒扩散的青铜人偶**。
- 拓森分识所隐匿的小猴，在冲出海面时已消失无踪。

## 七、要点归纳
- 修星之晶为吞魂之物：触之者（阴森老者）被吸成烟气，其残余红芒反成他人机缘。
- 「朱雀传承」正常需朱雀子认可 + 修星之心融合，王林以异常方式触发，属重大异数。
- 王林第二次拒绝安身立命式的大机缘（承接其「逆天」母题），代价是命魂仍陷晶中。
- 修星之晶与极境无关，纳多的说法被证伪。

## 四、第465章 战乾风——朱雀子夺寿计划的底细

### 乾风的处境与恨意
- 乾风喘着粗气，被朱雀子以奇异之法收走大量寿元，身子虚弱，**对朱雀子恨意滔天**。

- 但当下不是恨的时机，最重要是应付眼前杀机。

### 朱雀子的长期图谋
- 朱雀子打乾风的主意**不是一天两天**；若非**仙遗族突然出世**，再给他一些时间，或许真能想出躲避**天道轮回寿元断绝之劫**、从而**夺舍乾风寿元**而存在的办法。
- **自乾风年幼时**，朱雀子便一直推进此计划：让乾风**吞噬一个个意境**，感悟他人体悟天道时的经历——不是为了乾风，更多是为了他自己。

### 法术与铜人的来历（重要设定）
- 此手段是**历代朱雀子秘密研究的一个法术**，**尚未完全成功，成功率不足一成**。
- 即便真的成功，也**只能暂时缓和，多获得几十年寿元**；且为这几十年寿元需**耗费极大代价**。
- **铜人**是关键之物：**第四代朱雀子**所炼制，取材**天外之铁**，历经无数载并由后人不断祭炼，最终具备**收取寿元凝化而出**的神通。
- 铜人神通的根源：历代朱雀子通过对**修星之晶**的一些变化**感悟而出**。
- **致命破绽**：此物并未完善。朱雀子虽以此化形、看似充满生机，**实为强弩之末，只是暂时罢了**。

# 第438章 围杀乾风：青木刻像与秘留锈剑

> 归属说明：本章「曾牛」为王林自创化名（非冒用他人姓名），全部言行归于【王林】。

## 一、柳眉遁逃

- 柳眉忌惮十亿尊魂幡，银牙一咬吐出白芒，化作一条**白色丝带**，其上有金线绣出的图案。

## 二、乾风的反击手段

### 1. 红色扇子（克魂飓风）

### 2. 朱雀玄阵
- 主魂扑击之下乾风元神轰然一震、险些离体；危急时**胸口图案一闪，朱雀玄阵开启**，挡住扑击。

### 3. 青木（刻像杀人）
- 张口喷出青光化作一块**青木**，迎风放大成粗约十丈的巨木，散发诡异气息。
- 喝「刻」——青木碎末纷落，如无形之手雕刻，木上现出**王林的身影**。

## 三、王林的攻势

1. **四把剑鞘**：一拍储物袋，四把一模一样的剑鞘身前闪现，如流星呼啸，剑芒出鞘三尺余，剑意滔天；瞬间绞碎乾风抛出的扇子并紧追不舍。

4. **战斧劈木**：手中战斧一扫劈下，青色巨木一分为二，乾风口中一甜再喷鲜血。
5. **合击「死」**：战斧甩出，四把剑鞘内剑芒激射，四道剑意化作剑气自**东南西北四方**向中间的乾风冲击，气势毁天灭地。
