# 第1427章 铭志！（第九卷 云海之巅）

## 一、场景与人物
- 地点：大帝星（颠落之地内），一处湖泊之畔。
- 在场：老朱雀（一代朱雀，朱雀一族老祖辈存在，空玄中期）、王林（此时随老朱雀受传承）。

## 二、焚界古伞的演示
1. 老朱雀先叮嘱：**「不到万不得已，莫要施展此术」**。
2. 打出第一组印决：999 个印记，眉心虚火弥漫融入印决，凝成一把丈许长短、如棍笔直的「火骨」。
3. 打出第二组：9999 个印记，化作条条细线，笔直连接于火骨顶部并向外延伸——远看形似凡间雨伞的伞骨。
4. 第三、四组：各为「九十九万」之至极之数，双手同时掐诀，速度快到肉眼与神识皆无法看清（神识被一股奇异之力阻挡在外）。
5. 百万印记同时出现，卷动天地化作风暴，风暴裹挟火骨冲向天空。
6. 老朱雀低吼「**焚界古伞**」，天地一震，风暴停转、静悬半空，状如一把**未张开的大伞**，外绕无数咆哮火龙，整个大帝星清晰可见。

### 异象与威压
- 地面植被弯腰泌出水雾；湖水似沸腾爆出气泡；鱼儿急游；大地龟裂。
- 所有目睹修士体内血液有被燃烧干枯之兆。
- 星空扭曲蔓延，转眼几乎笼罩**小半个颠落之地**；被笼罩星球现出「大旱万年」般的毁灭前征兆。
- 老朱雀呼吸急促，显示仅是凝聚此术负荷已极大。

### 收势
老朱雀咬破舌尖，喷出一口空玄中期修为之血，化作燃烧滔天血雾卷向风暴融合，风暴渐散；**半柱香后**彻底消失，大帝星与星空恢复正常。

## 三、焚界古伞的设定要点
| 项 | 内容 |
|---|---|
| 归属 | 朱雀一族最强之术 |
| 印决 | 四组：999 / 9999 / 九十九万 / 九十九万（近两百万） |
| 时限 | **九息**之内全部打出 |
| 条件 | 每一印记须含**自身元神之阳**＋全身修为之力，配合特殊口诀 |
| 失误代价 | 一个印决出错即引不可想象反噬；空玄中期亦将重伤；非火修者可能道消 |
| 威力 | 「伞开九次，次次灭世」 |
| 来历 | 传自远古仙尊；老祖言其**并不完整**，似仙尊偷学而成 |

### 开伞次数的阶梯（重要参照）
- **远古仙尊（远古仙皇）**：毁灭一界万兆之人时开伞**八次**；第九次连他也不敢开。
- **一代老祖**（空劫初期）：只能开伞**五次**。
- **老朱雀**（空玄中期，数万年元神之阳从未被破，以本身之阳推动）：可开伞**两次**。

## 四、传授方式
- 老朱雀言「此术本不该传你」，因危险太大；但「你悟性惊人，可自行定夺」。
- 以一枚**玉简**载全部印决与「开伞之印」交予王林，令其记熟无半点差错后**毁去此简**。
- 王林心神融入玉简，将无尽印决与开伞之印刻入脑海；玉简随即碎成飞灰随风而去。

## 五、王林的反应与「铭志」
### 为何不惧第一道门槛
王林一生修炼**禁制**、更是禁制中的大师。结丹时便因布置/破解禁制而须在一刹那高负荷快速打出大量印决，故「九息内近两百万印决」对他虽难，却非绝对不可为。

### 真正的震撼
来自老朱雀话中的信息：
- 「似远古仙皇当年偷学而成，此术并不完整」——**仅仅是偷学来的不完整神通就足以灭世**。
- 由此追问：此术究竟是谁所创？远古仙皇又从何处偷学？若此术完整又当如何？
- 王林望天，如当年为凡人时般自觉渺小：「我眼下的修为，又算得了什么？这天，到底有多大？这天外，到底是什么？」

### 铭志（本章题眼）
知晓越多越觉渺小，但王林并未颓废，反被激发性格中的不甘（呼应其先前对一代朱雀所言）：
> 也可以。我王林，也可以。我王林，为什么不可以。

天生万物、物物不同，世间本存在极大的不公平，但同样也极为公平。既有人能创出此等神通、修炼到无法想象的地步，王林认为自己一样能行——「天资我或许不够，但却无法成为阻止我脚步的绊石」。

> **今日我去学这别人创出、后被仙皇偷学辗转留下的焚界神通；他日我要让别人，去学我王林之术。**

无长啸、无呐喊，只在心中默默低语，如同**铭志**。
