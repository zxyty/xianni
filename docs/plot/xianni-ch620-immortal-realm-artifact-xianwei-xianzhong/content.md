# 第620章 仙界之物

## 一、擒仙卫、灭金衣男子

- 黑衣男子落地，王林右手虚空一划，禁制幻化而出，将其体内各处隐藏经脉走向全部封印。
- 王林随意一抓用上**寂灭指风**——他一眼便看出此人体内古怪：元神中没有元气融合，而是被一块**小指甲盖大小的碎玉**代替。
- 结论：此人虽达问鼎修为，却无问鼎意境感悟，在王林眼中「只是一个莽汉」。即便王林未至问鼎，收拾他也不难。
- 修士联盟众人被震得呆滞。金衣男子面色苍白，因退路被黑雾淹没而无法逃离。
- 孙云山出言揭穿：「他们此行的目的，便是为了将你生擒。」金衣男子怒斥孙云山背叛老祖。
- 王林右手一挥，金衣男子整个人砰然化作一大片血肉，元神飞出后露出一刹那迷茫，随即被天空黑雾吞没消失无影。
- 四周修士惊恐：「问鼎后期，他一定是问鼎后期。」半空只剩十几名修士，不敢走也不敢出手。

## 二、宝塔内叙旧：孙云山的求救

- 王林抓起地上的黑衣男子走进宝塔，孙云山跟入。
- 孙云山震撼尤甚：他记得进入妖灵之地前王林不过**婴变中期**，短短数十年已至**问鼎**。
- 王林取出古朴圆桌与一坛美酒待客。孙云山一口喝干后又抓过酒坛大半坛下肚，才开口：
  - **仙卫**：此黑衣男子没有名字，身份是「仙卫」；孙云山与他同出一个自称「修士联盟」的组织。
  - **老祖**：联盟内有一人自称「仙界老祖」，修为高深莫测，「仙卫」之名由他自定；这样的仙卫共有**十个**，实力相差不多。
  - **旧因**：当年王林在**天妖郡古妖城**与妖将**莫厉海**一战引起老祖注意，老祖下令生擒王林；王林在天妖城听琴音时遇到的那批人即出自此处（其首脑被抓瞬间不惜自爆）。王林随后在天妖郡失踪，此事告一段落；**数月前**有人发现王林在此，禀告老祖，遂再派人来擒。
  - **私怨**：孙云山之妹不知以何方式来到妖灵之地，被老祖蛊惑加入联盟，又骗孙云山入伙；孙云山察觉不妙时老祖出现，一个神通制住其身边**四个师叔**，四人被抹去神智沦为**傀儡**；孙云山本人被种下**仙种**，身不由己。

## 三、仙种：仙界之物

- 王林一眼看去，孙云山元神一震几乎崩溃，如同内外一切隐秘全被看穿，大汗淋漓，敬畏顿生。
- 王林隔空一指其额头，青纹自眉心透出、脉络密布全身——此即「仙种」显形。王林凝重沉吟许久。
- 老祖之言：仙种是他在**仙界没崩溃前**带来的仙家之物，除他之外无人可破。
- 王林心中推断：仙卫之名、仙种之禁制、老祖自称来自仙界——「莫非是那仙帝**青霖**不成？」他认为可能性极小，但确认该禁制透出磅礴仙气，**应是仙界之物**。

## 四、搜魂与炼化

- 王林隔空抓起仙卫，右手按其天灵施展**搜魂术**。同阶搜魂本不敢大意，但此仙卫体内没有元气，问鼎修为全由元神中碎玉赐予，真实修为只是**婴变中期**。
- 搜魂结果：仙卫记忆极为短暂，只有成为仙卫之后的部分，之前一片空白。
- 王林一拍震出其元神，当着孙云山之面张口喷出**元神之火**炼化——目的是**震慑与防备**：老祖来历诡异，他不可能只凭只言片语全信孙云山。

## 五、碎玉的秘密（王林的推断）

- 元神炼化后，指甲盖大小的碎玉亮晶晶浮于王林身前。
- 碎玉不散仙力，但神识一扫可知其内蕴含**庞大到无法想象的仙力**，且这仙力**不可吸收**，因其内似乎蕴含**一道意念**。
- 修士元神与碎玉融合，可造就相当于**问鼎初期**的修士；但融合成功率极低，否则老祖不会只有十个仙卫。
- 关键判断：融合并非表面与碎玉相融那么简单，关键在于与其内那**一道意念相融**才能真正契合。
- 反讽点睛：老祖当年花费很长时间才慢慢琢磨出这一点，而王林仅凭判断便猜出十之七八。

## 六、结尾悬念

王林目透寒芒，缓缓开口：「修士联盟，所在何处？」——矛头已指向联盟本部。
