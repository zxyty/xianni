# 第1456章 三次杀机

## 一、雾海巨手中的对峙

- 雾海深处，一只数万丈的巨大手臂裹挟王林与大荒上人急速下降，速度快逾闪电，呼啸声被雾气吸收。
- 王林自胸口以下被掌指捏住，剧痛传来，但对方只是掐住而未再用力。
- 掌心内另吸入三处碎石平台：王林的墓台、妙音的墓台（大荒散人所属者），墓台仅出现裂缝，显然巨手无意捏碎。
- **大荒上人**此刻占据的是妙音道尊的**分身**肉身，已将其元神压住；其右手五指成爪、黑气环绕蕴含剧毒，正欲按向巨掌。

## 二、王林的判断与劝阻

王林出言「前辈且慢动手」，给出关键观察：

1. 巨手**并非直线下沉，而是倾斜落下**——若要擒拿应为直线。
2. 倾斜即蓄力，说明这是「巨人拿石头向后引臂再抛出」的动作，巨手的出现对二人未必是坏事。
3. 若此刻刺激它，它会立刻握实拳头，二人难以抵挡。

配合演示：王林右手抬起、向后倾斜、猛地前抛，血光弥漫，示意「这样」。

同时王林做了三件自保动作：
- 身形自数百丈**骤缩至常人大小**，落入五指未握实留下的巨大空隙（如一小片大陆）。
- 后退百丈之外盘膝而坐，与大荒上人拉开距离。
- 当着对方的面**收走自己与妙音的两座墓台**（大荒上人未阻止，只收走了自己那座）。

大荒上人心机深沉，瞬息明悟，面部扭曲中渐露本尊狰狞相貌，评曰：「你比老鸟聪明。」王林答：「与聪明无关，也只是一个猜测罢了。」

## 三、抛掷：脱困与借力

- 巨手倾斜到位后骤然一顿、四周死寂，随即雾海至深处传来闷闷咆哮，手臂化作弧形猛抛，五指松开。
- 二人如石块般被抛向古墓深处，速度**超越第三步大能**。
- 高速下无形雾气化作利刃；王林靠**古神肉身**、预先布置的层层禁制防御与体外**光影盾**硬扛，全身砰砰喷血却未被挤爆。
- 关键一手：被抛出临界之时，王林右脚狠踏掌心，施展**玄武一族的以力证道之法**，将对方之力与自身反震之力融合，速度骤增，比大荒上人快近小半，从其身边一闪而过先行没入雾中。若无此法，反震之力不能借为己用，后果毁灭。

王林的动机：大荒上人虽受伤、自己也有伤在身，且此人深浅难测，趁机脱离是最佳选择。他心中另存怀疑——对方极可能早看出巨手端倪，先前的攻击动作是故意为之的试探。

## 四、三次杀机（大荒上人视角）

大荒上人被抛出后如流星疾驰，见王林更快掠过，眼中异芒闪动，**缓缓松开了不知何时掐出的印记**，自语：

> 「此人性格谨慎，更是多谋之辈。方才我三次杀机都被此人巧妙地化解。本打算在被抛出时趁此人虚弱将其毒杀，但却被他看出了端倪，竟借力逃走。」

随后其身影亦消失于雾中。

## 五、墓台升阶：四阶 → 五阶

抛掷之力持续推动约**半个时辰**才消散。王林擦去嘴角鲜血、回望身后寒光闪烁，随后行事：

1. 取出自己的墓台盘膝坐上，再取出**妙音的墓台**，右手一拍将其上所有数字符文尽数震出，融入自身墓台。
2. 墓台剧震膨胀，自**三千丈**扩至**四千丈**，晋为**四阶墓台**，颜色彻底转黑，似要与雾气融为一体。
3. 王林虚空一抓，取出**近百个符文**——来自那崩溃的封印之地内死亡修士，被他不知何时巧妙收走。
4. 符文一一融入，墓台再度膨胀至**五千丈**，达**五阶墓台**（妙音墓台原本已近四阶，加上近百符文方成此数）。

升阶效果：一股股神识之物自墓台钻出涌入王林体内，其脑中地图**再开两片**，五张地图相连，古墓面纱被揭开近半。

## 六、位置揭晓与伏笔

- 短短半个时辰的一抛，使王林在雾中直接**跨越前三幅地图、穿梭第四幅**，出现在**第五张地图的尽头**。
- 此处已彻底离开**古墓外围**，进入**古墓内部**。
- 第五张地图上，王林前方不远标记有一片森林——正是当年**贪狼**得到**古息叶**之处；也正是在此，贪狼看到了那尊令**银衣女子**惊恐尖叫的**七彩雕像**。

## 七、看点小结

- 王林的胜负手在「观察轨迹—反推意图—借敌之力」，全程未与大荒上人正面交锋即化解三次杀机。
- 墓台体系再度确认：符文可并入升阶，阶位越高开启地图越多，是古墓中的导航兼实力凭证。
- 七彩雕像作为强伏笔被再次点出，指向古墓内部的核心秘密。
