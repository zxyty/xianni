# 第1728章 玄罗入府！

## 一、洞府界：王林道破“第三魂”

- 王林当众说出四大战将心中所想——**第三魂**。此事被四大战将视作最隐秘之事，放眼洞府界知晓者极其罕有，他们此前从未向王林提及。
- 四大战将（青龙、玄武、白虎、朱雀）面色齐变，后方的**战老鬼**亦神色一凝，盯向王林。

## 二、开天斧一斩：硬抗四大战将合击

- 王林左手抬起，**开天斧**急速膨胀化作数十丈，其身道古气息弥漫、气势暴增。
- 设定点：吉神（涂司）的开天斧，与王林的**道吉血脉之力**融合，天地间再无第二人比他更适合持有此斧。
- 一斩落下，星空轰鸣，王林身后幻化出**道古虚影**，同持斧同步斩下。
- 四大战将各显仙人血脉：青龙战将化万丈青龙迎斧（终被斩溃）、白虎、朱雀（火焰）、玄武（泥土大浪）三大虚影同扑。
- 王林不闪不避，以神通**道古不灭体**硬抗，肉身急速恢复；横扫一圈的斧芒震退四周一百多名仙人，四大战将的神通亦尽数落在他身上而未能伤及。
- 王林判词：“**你们的修为，还没有完全恢复，只是空玄后期**，这样的修为，伤不了我的身体。”

## 三、撕天屠仙

- 王林右臂为**烨寞之手**，施展「**撕天**」：一撕之下仙人无抵抗资格，肉身崩溃、元神被撕开。
- 连续三波：先撕杀身前及身后共三名仙人 → 钻入撕开的裂缝闪现至另一群仙人身后，一撕灭七八人 → 再次硬抗四大战将后闪现至第三方仙人身前，令其全身剧痛、无法抵抗地轰然崩溃。
- 青龙战将怒吼：“**王林，我要屠你仙界！**”，眼中更多是对王林手段与肉身强悍的难以置信。
- 王林冷语：“鲜血的教训，看来还是不够呢。”

## 四、幽冥兽·天道吞噬（本章高潮）

- 王林回到幽冥兽背上，甩去右手鲜血，拍了拍幽冥兽：“**把这些人，吞了吧。**”
- 战老鬼脚步骤停；幽冥兽睁眼，眼中无情冷漠令全场心神一震。
- **青龙战将的回忆**：这样的目光他一生只见过一次，是在很久很久之前，他亲眼看到这种目光的雾气**一口吞噬了连道非**。
- 幽冥兽张口一吞：星空色变、风云倒卷，凭空生出无尽雾气与古老沧桑气息，巨大吸力将剩余**七八十名仙人**尽数吸入口中，凄厉尖叫后一切归于平静，雾气不留半点痕迹。
- 场上除王林外只剩五人：四大战将 + 战老鬼。
- 王林平静发问：“这次的痛，能记住么？”

## 五、“天道”震怖与七彩之魂现身

- 青龙战将颤抖惊呼“**天道！这是天道！**”，恐惧甚于目睹王林开李广弓之时。
- 心机深沉的玄武战将神色呆滞，恐惧更浓且生彷徨，视王林为“主宰一切的恐怖存在”。白虎、朱雀战将如中定身术。
- 战老鬼震惊自语：“我之前看中的，竟然是天道”“难怪察觉不到气息”。其体内的**七彩之魂**呼啸而起，直接操控了战老鬼的身体，弥漫**七彩仙尊**气息，神色充满忌惮。
  - 心念：若不在洞府界他不怕天道，但**在洞府界，天道就是全部，掌控天道等于掌控一切**。
  - 同时自忖：天道吞噬**也有极限**，否则不会在**连道非的自爆**下分裂，自己也有手段抵抗。
- 七彩之魂借战老鬼之口苦涩问：“**你找到了第三魂？**” 王林摇头：“**我没有找到。**”

## 六、离场与王林的疑虑

- 幽冥兽冷扫五人一眼闭目漂游而去；四大战将身子一颤退后让路，不敢阻拦，久久无法平静——他们或有手段不惧同有七彩之魂的战老鬼，但对王林的天道只有沉默。
- 王林坐于幽冥兽背上向**昆虚**飘去，内心叹息：**莫非这天道还不完整？** 四大战将好说，但幽冥兽方才传达出“**很难吞噬战老鬼**”的意念。

## 七、并行线一：昆虚星域·彩道人集齐九玄血脉

- 昆虚星域内七彩之芒闪烁，**彩道人**手持九个拳头大小的**血球**前行。
- 其言：“**九玄血脉终于集全**，以这九玄血力，可**幻轮回道**，找出当年遁入轮回中的**第三魂**——他应该在昆虚。”
- 与王林一线形成同向奔赴：双方都在指向昆虚与第三魂。

## 八、并行线二：仙罡大陆·七道宗旧址，道古一族青年降临（“玄罗入府”）

- 地点：**仙罡大陆**仙族所在区域，山脉交错、林荫浓密如蛮荒之地，夜中时闻凶兽嘶吼。
- 设定：很久很久之前，这片山脉内存在过一个仙家宗派——**七道宗**。
- 高悬明月中泛起波纹、月影扭曲，一名**黑发青年**缓缓现身，神色疲惫却露出开怀微笑与浓浓期待，仿佛为来此付出再大代价也值得。
- 其言：“**我道古一族的孩子，我来接你回家！** 回去的路或许会艰辛，可我知道，你不会畏惧。”——随即走向山脉。

## 九、关键伏笔

1. **第三魂**：洞府界最隐秘之事；王林明言自己“没有找到”，彩道人则断言其遁入轮回、应在昆虚。
2. **天道之不完整**：幽冥兽吞噬有极限（曾在连道非自爆下分裂），且难吞战老鬼。
3. **道古一族来人**：疑与王林的道古传承（烨寞/道古）一线相关，落点在七道宗旧址。
