# 第1759章 七彩来临！

## 一、蓄势：以一界规则凝刀
- 王林举刀望天，黑气化作风暴漩涡如黑龙缭绕，刀却定在虚空，形成「一静一动」的对比，散出震慑心神的威压。
- 白虎战将因神识所化之身被王林吞噬、且以血脉发下誓言，在威压下颤抖低头屈服；对面五行星中年修士虽无血脉誓言，但神识之身同样被吞噬，受那丝神识牵引而生潮水般敬畏。
- 王林闭目，屏蔽一切声音，以刀代眼、代神识，将全部修为凝为惊天一刀。

## 二、七彩道人踏入残界
- 此界星域西方苍茫星海中骤现巨大漩涡，尚未成型即如被人自内撕开般轰然崩溃。
- 七彩光芒中，七彩道人迈步踏入残界，瞬间感应到王林气息，眼露杀机大笑：「王林，本尊找到你了，这一次，我看你怎么逃。」

## 三、惊天一刀
- 第三颗修真星上，王林睁眼、刀爆万丈幽光，一跃挥出最强一刀后急速后退。
- 刀芒吸收其身外风暴、全身铠甲、下方棋盘所化的全部军兵，**直接轰开白虎的规则**，白虎喷血萎靡。
- 刀芒破虚而出，瞬间出现在苍茫星域七彩道人所在之处，膨胀至万丈、似有实质，迎头斩落。
- 此刀为此地规则所化 + 王林全部修为，等同**以一界之力轰杀**。

## 四、七彩道莲与此界毁灭
- 七彩道人瞳孔一缩，罕见地感到危机——一生仅三次，其中两次皆因追杀王林（上次在**云海裂缝**，此次在残界）。
- 其心中评价：能想到借此地规则化刀，「其心智之高，实为少见；但越是这样，此人就越是要死」。
- 因忌惮**战老鬼**在场、不愿受伤，遂施「**七彩道莲，莲凝兵修**」：七色莲花绽放，其盘坐入内，花瓣收缩成花骨朵硬接一刀。
- 结果：刀芒轰然崩溃化作碎片；莲花骨朵剧颤，**两片花瓣直接碎灭**，令七彩道人心痛。
- 二者同溃的冲击以莲台为中心横扫，星空如绸缎起褶、寸寸崩裂；**九颗修真星中七颗爆开**，化作吞噬一切的黑洞漩涡——此界将永不存在。
- 第三颗修真星地面沟壑纵横、碎石升空，呈末世之貌，开始崩溃。

## 五、焚界火伞与遁走
- 王林嘴角溢血，自知「七彩道人太强」，毫不犹豫踏入凭空出现的漩涡欲走。
- 七彩道人以七彩光芒渗透，携残缺莲台现身第三颗修真星，花瓣绽开，抬手一指：「**七彩道莲，莲开夫故**」——剩余五片花瓣脱落成五彩封杀王林，其本人以空劫修为之力随后急追。
- 王林早有准备（谋定而动）：凝刀时已暗中左手在身后掐诀，先行幻化出**焚界火伞**（焚界古伞之术需禁制幻化、准备耗时并多耗生机，不宜危机关头临时施展）。
- 火伞撑开遮身，五彩莲瓣尽被阻隔；每片落伞都令王林心神巨震，但他借冲击之力连退三步，身影没入漩涡，离开此界。
- 七彩道人冲入漩涡，七彩掌印穿透漩涡一抓落空，怒吼：「你就算逃到天涯海角，也逃不出本尊的追杀！」随后身形一晃追入漩涡。

## 六、留局：白虎战将奉命擒人
- 王林与七彩道人离去后，第三颗修真星彻底崩溃，此界一同毁灭。
- 白虎战将因誓言已生效，虽神色复杂却不得不遵，挣扎起身直奔面色苍白的五行星中年修士。
- 王林临走前下达的第一道命令：「**擒住他，我有大用。**」

## 七、要点提炼
- 战力标尺：一界之力的一刀 = 崩碎七彩道莲两瓣，但仍不足以伤到七彩道人本体。
- 七彩道人行为逻辑受「战老鬼」牵制：宁可防御破财，不愿在此受伤。
- 王林的作战风格再次体现：谋定而动，出手前已备好退路（火伞）与后手（白虎誓言）。
