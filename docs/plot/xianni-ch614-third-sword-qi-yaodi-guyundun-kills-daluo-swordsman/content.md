# 仙逆 第614章 第三道剑气

## 一、场景：天妖郡左路大军行军

- 远处天地间尘土漫卷（雨水亦压不下），无数披甲妖兵持利刃骑马而来，杀气浓重。
- 妖兵半空浮着一座古香古色的阁楼，随大军而动，阁楼四周有妖兵分列护卫。

## 二、王林会晤妖帝古云沌

### 身份揭破
- 王林化长虹而至，阁楼内走出一衣着寻常却威严自生之人，笑称「王兄，别来无恙」。
- 此人正是当年与王林把酒彻夜的青年。王林当年只觉其体内无半点妖力却绝非等闲；今以**问鼎**修为再看，见其丹田内有一颗**仅拳头大小的妖晶**，不散妖力、看似平常，反引王林更为留意。
- 对方自陈：王林是**祖灵钦点的使者**，双方地位相当，可直呼其祖名——**古云沌**。他不解王林何以识破其妖帝身份；王林答「当日只是怀疑，今日见吉兄后才确定」。

### 许立国与帝剑剑灵的旧怨
- 许立国从储物袋内传出神念哀求（自称十年未见「小美人」），王林拍储物袋放其出来。
- 许立国学乖了：**未带仙剑，只离窍而出**，幻化成形四处寻帝剑不得，作寡欢文雅之叹。
- 王林向妖帝说明「这是王某剑灵，与你帝剑剑灵有些误会」。古云沌笑称早闻此剑灵之名（令其侄女十年内仍恨恨不已）。
- 古云沌右手虚空一抓，天空裂开缺口，**帝剑**闪出，立即向许立国削去；许立国以灵体状态闪躲勉强，口称「娘子」。
- 王林目光一冷：许立国是他之物，外人不可如此。大袖一挥怪风起，晃动帝剑剑芒。
- 帝剑剑灵少女现身，斥王林是「可恶的食物」，催动四周剑气攻来，被王林一声冷哼尽数震溃——**今非昔比：当年婴变后期忌惮此剑，如今问鼎已不放在眼里**。
- 古云沌抓回帝剑，说明剑灵**双儿**并非天生剑灵，而是其**至交好友之女**，因变故化为灵体，于他如同子女，不容恶徒银语调戏；随手一眼便让许立国身子一颤、几近崩溃。
- 王林由此察觉：**古云沌体内妖晶瞬间爆发的强度，不弱于问鼎后期大圆满修士**。随即抓许立国扔回储物袋。

### 情报与信物
- 王林问询：**妖将墨非何在**。
- 古云沌答：墨非已成**副帅**，与天帅等人同率**左路大军**，此刻应已兵临**火妖郡松涛城**。
- 古云沌已对外**宣布王林的祖灵使者身份**以便其行事；另赠**白色玉简**一枚（内含独特妖气、极难模仿），持之如妖帝亲临，**若有不敬者可调动天帅杀之**。
- 王林接简道谢即去。古云沌暗道：自琴音入耳那刻起便知你我同是一路之人，不愿与你交恶，故送善意。

## 三、松涛城前的斩杀

### 大军编制
- 天妖郡左路大军：妖兵千万，**夭（天）、宙、荒三位正帅**带队，**洪、玄、黄三位副帅**协管，直逼火妖郡边界**松涛城**。三位正帅各骑不同妖兽驰于中军，彼此不交谈，萧杀压抑。
- **右翼**：副帅墨非披甲骑一头似麟妖兽；其身后麟尾上立一中年男子，闭目、背负大剑、颇有仙风道骨——即**大罗剑宗**之人，能施**凌天候剑气**。

### 王林出手
- 王林在奔雷炸响中现身：**黑色铠甲、魔气纵横，如魔尊降临**，一踏化流星冲阵，神识锁定墨非。
- 战术判断：**先杀人夺势、快刀斩乱麻**；若先自报身份、亮出妖帝玉简，便失先机，等于给大罗剑宗之人思索施展凌天候剑气的时间。
- 大喝「奉妖帝之命，擒杀副帅墨非，其余人等避让」，右手抛出**妖帝玉简**，直奔正要出手的**宙、荒二帅**。
- **黄泉横扫**之下挪移消失，食指前点——**寂灭指**直奔墨非；指风临近墨非时**突然崩溃消失无影**（墨非一怔后色变，妖力爆发护体；中年男子亦楞了一下）。
- 王林借这一楞瞬移至中年男子身边，全身铠甲魔气凝作**魔焰**，一指点出，是为巅峰之击。
- 中年男子生死之际瞬移而出，欲施凌天候剑气；此时**大地黄泉轰然而起，道传天地、轮回幻化，无形之力降临，苍生为之一顿**。
- 就这一顿，中年男子眉心金芒刚闪，王林食指已点其眉心——**指落，人亡**。
- 王林**割下人头**，虚空抓住此人**大剑**，转身离去，行云流水、干净利落。

## 四、要点与伏笔

- 「第三道剑气」标题与大罗剑宗**凌天候剑气**的威胁相呼应：王林全程以速度与突然性剥夺其施展时机。
- **寂灭指对墨非无效**（临身崩溃）是本章异常点，暗示墨非身上另有蹊跷或护持。
- 王林获得两项资本：**妖帝玉简（可调天帅）**与**祖灵使者的公开身份**。
- 许立国与帝剑剑灵双儿的宿怨未了，且双儿受妖帝护佑，为后续埋线。
- 王林与墨非的正面清算尚未完成（本章只斩其护道者）。
