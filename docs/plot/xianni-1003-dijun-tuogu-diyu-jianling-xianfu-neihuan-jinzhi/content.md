# 第八卷 联盟隐秘 第1003章 帝君托孤

## 一、河畔通宵：似曾相识的琴音
- 王林手持酒壶坐于河畔，望着河道上缓行的舟船，耳边琴音仿若回到数百年前。
- 但琴音只是形似，失了当年神韵，弹琴之人也非昔日盲女。王林轻叹：“帝君有心了。”
- 王林与中年男子（帝君）默默对饮，一壶接一壶，日落至天明，无月之夜只有河上不断的琴音与舟船上明暗不定的灯火。天亮时王林身边尽是空酒壶。

## 二、古妖贝罗的条件（王林已应允）
- 帝君传话：**贝罗大人已知晓王兄到来**，派其前来传一句话。
- 条件：
  - 王林方面：**在进入第五座仙府的名额中留下一个**给贝罗。
  - 贝罗方面：**妖灵之地九郡之四**赠予炼魂部落；**绝不干涉炼魂部落任何事情**，包括**那残存的云妖之识**。
- 王林望着天边，平静答：“可以。”

### 背景判断（王林心中所想）
- 妖灵之地已是贝罗的天下：数百年来贝罗不断吞噬其他妖灵，**每吞一个便强大无数倍**。
- **黑石石像**可瞒过很多人，但**绝难瞒过古妖贝罗**；贝罗数百年按兵不动、任由炼魂部落发展、连那一丝云妖之识也不收走，所图正是今日这笔交易。

## 三、帝君托孤：帝剑之灵
- 帝君所求：其**帝剑之灵本是一位好友之女**，世事难料逃不出生死，最终成为其剑灵，困在妖灵之地无数年，**始终没有踏出妖灵之地**。
- 请求王林带此灵离开妖灵之地，**重入轮回，或另有造化**。
- 王林问“为何不寻别人”。帝君答：妖灵之地无数年来进入的修士众多，但**除有限几人外旁余之辈信不过**；而那几个信得过的，又因自己尚能守护此剑而错过了。
- 王林昨夜帝君来临一刻便已察觉：**帝君身上有淡淡死气，寿元将要枯竭**。妖灵之人寿元虽多于寻常修士，**若无意外不到半甲，帝君便会归墟而去**。相识一场，王林点头应下。
- 帝君虚空一指，帝剑自**燕京**方向化剑气呼啸而来；一挥之下剑化少女，少女眼中不舍（剑灵无泪）。帝君慈爱如待女儿：“听话，以后不要再任性了。”随后向王林抱拳深深一躬：“多谢王兄。”转身几步远去。
- 少女望着燕京露出诀别之色——她明白**待自己如女儿的帝君此生再无相见之日，寿元断绝无法改变**——悲哀中化青烟回入帝剑，发出一声悲鸣，随于王林身后。

## 四、返回第四座洞府
- 王林饮尽壶中酒，起身踏虚空而行；帝剑如银芒相随，最终被王林大袖一甩**收入储物袋**。
- 王林**神识开启仙府玉简**，金光闪烁中身形消失，出现在**妖灵之地第四座洞府**外的平台上，直接踏入洞府。
- 沿途处处可见被破解的残余禁制：少数为当年他人所破，**大部分是近日司徒南一行人破开**。

## 五、破禁现场：分工与僵局
| 人物 | 状态/职责 |
|---|---|
| 尘道三子 | 之前破解消耗过多，盘膝打坐、白气缭绕，正在恢复 |
| 大头 | 出乎王林意料地**对禁制颇有造诣**，带着雷吉计算破解之法（雷吉配合打出拳风冲入禁制） |
| 浮风子 | 亦研究过禁制之术，是**破禁主力** |
| 司徒南、银衣女子 | 负责禁制破开后出现的攻击与变故，以防万一 |
| 司徒南 | 憋闷已久，王林一回来便自行前往竹林探查其他地方是否另有宝贝 |

- 司徒南对禁制之术只是略有了解，认为修为足够即可破禁；因需负责突发变故而无法离开，否则早已甩袖独自强破。
- 王林不担心司徒南安危：其修为在此**最多被困**，届时自己去救即可；且其**体内毒素已在水灵星期间由二人想出暂时压制、不需女修随同的方法**。

## 六、内外环交界：石桥禁制
- 前方百步是一条流淌的小河，仙气弥漫、淡淡雾气；河上有一座**石桥横跨两岸，是唯一的入口**。
- 浮风子介绍：此仙人洞府呈**回字形**，当前位置是**内外两环的交界**，过河即入内环。
  - 已在此**被阻五个时辰**，任凭如何算计也算不出禁制端倪；
  - 直觉**强行破除必引起一系列无法想象的变故**，不到万不得已不能强开；
  - **大头的方案**：不走石桥，从**缘边破开禁制跨河而入**；
  - **司徒南的计划**：等尘道三子恢复后众人一同出手强行破开——**浮风子保留意见**。
- 浮风子内心暗忖：王林修道**一千多年**便有此修为已属不可思议，但应无时间掌握禁制之术，破解还得靠自己与大头；而他自知外环尚可，**自交界起已有些无力掌控**。

## 七、王林的判断与试探
- 王林看出：除浮风子所言外，这百步之内还有**潜在杀机**，此处与外环禁制**截然不同**。
- 结论：“这里，恐怕就是进入仙府内部的第一道关卡了。”
- 试探：王林唤“**银尸**”，银衣女子上前听命；王林目不转睛望着石桥，平静下令“**踏入十步**”。
- 浮风子皱眉，认为这是最不明智的举动、极可能就此开启禁制，但看了王林一眼后未发一言，退后几步观望。

- 帝君寿元不足半甲，帝剑之灵能否随王林出妖灵之地、重入轮回，尚待后文。
