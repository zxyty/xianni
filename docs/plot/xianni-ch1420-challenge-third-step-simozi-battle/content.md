# 第1420章 战！！（第九卷 云海之巅）

## 一、开局：向第三步发起挑战

- 王林（此时以「第三少帝」之名立于大帝星）在完成试炼之后，当众向第三步大能**司墨子**发起挑战，最后吐出一个「来」字，透出莫大自信。
- **设定基石**：古往今来，第三步大能对第二步修士而言如神灵，几乎不可战胜；第三步之间或有陨落，但第三步从不可能败在第二步手中。此近乎规则，烙印于一切修士心神。
- 司墨子虽刚被老朱雀羞辱，但其实力足以「跺一跺脚引起莫大浩劫」；其修为处于第三步**空之四境**中的第一境——**空涅初期**。

## 二、四周数万修士的舆论

- 主流质疑：修为差距极大、刚经试炼恐有内伤、挑战愚蠢、司墨子一式神通即可教训狂妄。
- 少数支持：王林借试炼震撼把气势提至最高，此刻不战便浪费机会；更有人反问「你等可敢上去也挑战一次」。
- 结果：舆论由几乎全部背向王林，转为分出一部分对其生出敬意。
- **云落大司**心神震动，将眼前的王林与画面中的可怕身影急速交换，几乎分不清彼此。
- **老朱雀**面露得意：他要的正是让自家晚辈做成所有人眼中不可能之事，并称此前扇司墨子那几巴掌「不是白扇」。

## 三、司墨子出手：破天九灭 → 破空九灭·九步灭天

司墨子眼神化作清明，无喜无悲、冷漠弥漫，威严外放使天地扭曲，扭曲中隐现无数凄厉虚魂。他言明「以为战胜我分身，就可以挑战第三步了么」，抱必杀之心出手。

九灭逐次施展，每喝一灭即前踏一步：

| 序 | 名 | 表现 |
|---|---|---|
| 一 | 灭天 | 天空震动，无数裂缝被强行撕开，如狰狞疤痕轰向王林 |
| 二 | 灭地 | 大地蠕动，无数几与天齐的山峰拔地而起、自根部碎裂升空砸下 |
| 三 | 灭生 | 凭空寒风吹灭一切生机之火，与王林的呼风之术极为相似 |
| 四 | 灭葬亡 | 虚幻坟墓弥漫天地，墓冢死气滔天 |
| 五 | 灭时光 | 时光岁月流转于其双脚，化作波光鳞鳞 |
| 六 | 灭虚无 | 模糊虚无笼罩，墓冢与其身影俱入虚雾 |
| 七 | 灭洪荒 | （随步而生的沧桑气息）|
| 八 | 灭轮回 | 沧桑化作一片轮回之相 |
| 九 | 灭破天 | 一步踏至王林身前三丈，右手狠拍 |

收束式：**「破空九灭，九步灭天」**——身后所有虚影轰然崩溃，化作无数碎片如长河尽数汇入其右掌，一掌碎开万物。

## 四、王林应对：九炎龙环身

- 掐诀高喝：**「虚火九色，以吾之名，化炎灵临世」**，自身外虚火风暴中猛甩而出。
- 风暴内龙吼疯狂：第一条**赤色**炎龙冲天，赤火灌满天空裂缝；第二条**橙色**炎龙数千丈，一卷焚尽下方山峰；随后第三至第九条（含**黑炎龙**）同时出现。
- 风暴消散，**九炎环身**，其**左目瞳孔九色火焰旋转**，气势轰然爆发，身影深深烙印在数万修士心中。
- 硬撼：王林**右手双指成剑**点出，九条炎龙龙头纠缠缠绕双指（远看似双指化作龙身），迎上司墨子那一掌。

## 五、碰撞结果

- 这是**破天之力**与**虚火焚世之力**的碰撞，更是一种**规则力量的对抗**。
- 余波传遍整个大帝星并向外无尽扩散，四周数万修士中**近万人喷出鲜血**、双耳轰鸣、心神受创、急急后退。
- 王林蹬蹬后退**百丈**，面色异样红润，抬头眼露寒光，心道「第三步，果然惊人」。
- 司墨子手掌一震，清晰感受到火焰之力倒卷；其可破天的一击竟无法熄灭这火焰，**平静神色刹那消散，眼中露出震惊**。

## 六、转折与悬念

- 关键机理：**与虚火修士交战首重心神**——心神一乱、情绪滋生，便会被对方燃起虚火。司墨子全程刻意保持平静，正为防此。
- 王林等的就是这一丝震惊：眼中精光一闪，右手骤然抬起指向司墨子，喝出**「虚火起」**。章节至此戛然而止。
