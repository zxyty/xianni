# 仙逆 第1422章 封香火界！（第九卷 云海之巅）

## 一、局势与动机
- 地点：大帝星，斗法赛场（赛场以一头巨龟为载体）。
- 司墨子话含杀机，却不敢在老朱雀面前于大帝星上真的击杀王林——一旦做出将面临灭顶之灾。
- 其身后有 **长尊会**，本人为 **掌尊之士**；因此选择「焚香一拜」将王林彻底打到失去抵抗之力、重伤而退，如此谁也说不出什么，他可全身而走。

## 二、香火一拜 vs 太古雷界
### 香火之力
- 无尽香火之魂一拜之力化作紫色狂风，四面八方直扑王林，天地皆成紫色，如同魔染。
- 此神通足以毁灭 **天人第五衰** 修士。

### 王林的底气
- 雷霆本源 **大成**；火焰本源达 **虚火之境**；当年曾与水道子一战。
- 关键转折：**这是王林第一次与第三步大能交战中「可以一拼」**——此前对水道子只能被动抵抗无法出手，而在太古星辰的这段日子里修为突飞猛进。

### 太古雷界与九龙融雷
- 王林右目雷光闪烁，退后一步、右手一挥：「**开，太古雷界**」，撕开千丈裂缝，内中雷霆轰鸣、透出万古沧桑气息，太古雷龙咆哮而出。
- 右目瞳孔 **雷图** 飞出直奔裂缝；一条条太古雷龙探出，与雷图外 **九道伴随之雷** 逐一融合，威力暴增。
- 王林宣言：「以太古雷界为我雷图之本，以九条太古雷龙融我伴雷之魂，展天地雷之极致」。
- 千丈裂缝外形本身即成一道雷霆之形，内外无尽闪电游走；九道伴雷在外化作雷霆风暴。
- 来历补白：王林**吞噬闪雷族不灭雷霆**、**搜索闪雷族大长老记忆**后，雷霆神通登峰造极，故能以雷霆本源令天地空门幻化并轰开一丝。

### 对撞结果
- 两道风暴碰撞，大帝星剧震；下方巨龟凄厉吼叫、身子一震轰然崩溃，赛场随之瓦解，四周观战修士纷纷喷血倒卷至极远。
- 王林方：雷霆风暴爆开，九道伴雷被卷回，太古雷界裂缝扭曲欲散。
- 司墨子方：紫色风暴崩溃大半，四周香火之魂大片消散。
- 王林嘴角溢血、面色苍白、蹬蹬后退；司墨子亦后退一步，喝道「老夫香火之魂无尽……**香火界内，门徒再出**」，其身后巨大的 **香火界裂缝** 中更多香火之魂欲冲出。

## 三、古息叶封界（本章高潮）
- 王林强行止住后退、迈前一步，手中出现一片 **枯黄的树叶**；眉心 **古神星点** 幻化，喷出一口 **古神之血** 滴落其上，树叶散发赤红之芒。
- **古息叶**：贪狼当年得自 **古之墓地** 的重宝之一，来历神秘莫测；以贪狼修为施展，即可封印王林的 **缩地成寸** 之术，使其无法强行破开只能避让。
- 王林身为 **古神**，又以古神鲜血滋润、操控方法正确，威力比在贪狼手中高出无数倍。
- 一叶遮天：叶子迎风见长，百丈→千丈→万丈，穿过司墨子身旁贴上香火界裂缝，王林吼「给我封封封」——如同封印符文，香火界剧烈颤抖，**香火之魂无一能出**。
- 反响：
  - 司墨子骇然：「这是什么法宝」——一生修道从未听说天地间有法宝可封印 **第三步修士的香火界**。
  - 老朱雀瞳孔猛缩、不可置信：「这小家伙身上，居然有这种宝物」。
  - 云落大司面色更白、恐惧无法遮掩、下意识退后数步——她记得所见画面中有一幕：眼前之人挥手间 **九十九片同样的叶子** 出现，封印天地，把太古星辰诸多修士的 **绝天道术** 一击彻底封死。（预示性伏笔）

## 四、古魔魂对紫道
- 王林双目通红、直奔司墨子，喝「古魔魂，给我出来」：胸口黑雾旋出，魔气纵横，化作一个 **与王林一模一样的小人**，即 **古魔魂**；其身外魔气翻滚，卷起一把 **处于虚实之间的长枪** 扑向司墨子。
- 司墨子体内 **虚火再次滋生**（旧伤），其不予理会，右手紫光疯狂闪烁：
  - 自陈：「老夫当年为掌尊大人立下功劳，被掌尊赐七彩之中 **紫彩本源之道**，这紫道一行，为 **癫之初始**，你这区区法宝，只要有灵，就要在老夫紫道下癫狂」。
- 结果：古魔魂反露兴奋之色——**古魔为天地魔之首**，身为魔何惧癫狂，越癫狂魔性越浓；它主动冲上张口吞噬部分紫色雾气，双目通红、提速穿透紫雾直奔司墨子。

## 五、要点归纳
- 战力刻度：王林已从「只能挨打」跨到「与第三步大能对拼不落下风」，且手握两大破局底牌（古息叶封界、古魔魂）。
- 势力线索：司墨子—掌尊—长尊会；紫彩本源之道属「七彩」体系之一。
- 伏笔：九十九片古息叶封天地、封死太古星辰修士绝天道术的未来画面。
