# 第1530–1531章 李广之弓（第十卷 叱咤界内）

## 一、场景
封界大阵的缺口正在愈合（先是不足百丈、后为不足五十丈）。王林目光一凝，转头看向缺口——那里立着一个白衣男子，手持一张弓，弓已开，遥遥指向自己。此人身份为「掌尊首徒」，名风羿。

## 二、此弓来历：李广之弓
- 弓主当年为「道亿李广」。
- 当年李广一箭破开道吉（道古）的无仙大神通道术，直接摘取其左目，并带走了道古对故乡的思念与半生记忆。
- 王林曾在古之墓地坐上那把椅子的刹那，于梦幻般的画面里清晰见过李广的绝代雄姿与此弓之威。他判断：那一箭足以撼动真空，封界大阵在其面前也要直接崩溃，毫无阻挡之力。
- 此弓不属于此界，是道古家乡的重宝。在王林一生所见中，除「天逆」与「颠落之地罗盘指针」外，此弓最强。

### 关键疑点：七彩道人与掌尊
此弓当年被「饲养天道的七彩道人」取走。如今却出现在掌尊首徒手中，王林由此心生寒意与怀疑：**掌尊莫非与七彩道人有什么关联？**

### 失踪的那一支箭
- 弓的唯一一支箭，在射下道古左眼后，带着左目破碎虚空，去向不明。
- 王林当年推测：找到此箭，或许就找到了道古左目所在。
- 但至今星空未有任何关于此箭的传闻，仿佛彻底消失。若一旦有人得之必名动星空，引发不亚于当年天逆珠之争的浩劫。

- **外人视角**：白衣青年修为不过空涅初期左右，手中弓平平无奇、无半点波动，如同凡物；因此众人对王林的凝重神色大为不解。

## 一、开篇：王林的隐忧与代价

- 王林眼中露出杀机。他因先前收**幽冥兽**为本命之兽、生机相通，方才开启**古伞**才未使寿元消散九成以上；但古伞消耗疯狂，幽冥兽生机再磅礴亦经不起，故不可多用。
- 王林暗忖：掌尊此举似有惧意，是要**以此弓为饵，引诱某个人出现**。（后文得到印证——引出的正是战老鬼。）

## 二、界内诸修散去与风羿挑衅

- 界内一时安静，与南云子、红杉子交战的**寒衣童子**等数个大能退出战势旁观。
- **红衣仙妃**神色阴沉：她事先并不知此弓会出现，听**风羿**（掌尊首徒）之言后，看出自己只是别人计划中的一枚棋子。冷哼中扫了**召河紫梦**一眼，转身直奔封阵缺口，踏入太古星辰而去，无人阻拦（南云子目光微不可查一闪）。
- 寒衣童子等人亦沉默退后，一一自缺口迈出。
- 风羿摇头相激：「界内诸位道友，竟无人敢来取此弓么？」

## 三、巨掌再撕缺口，界内大能合击

缺口愈合至不足十丈、再收至七丈时——

- 太古星辰星空中的**巨大手掌**再次幻化，抓向缺口猛地一撕，缺口崩溃并被扩开**数百丈**；莫大威压笼罩界内，红杉子等心神震动，王林面色苍白、退后数百丈。

界内合击阵容（几乎同时出手）：

| 出手者 | 手段 |
| --- | --- |
| 红杉子 | 右手一挥，红霞弥漫 |
| 南云子 | 拍额化出云朵般虚影，凝成一尊尊雕像排成庞大阵法 |
| 召河紫梦、中年美妇、鲁夫子、太阿罗 | 光芒万丈，种种神通齐出 |
| 灵动上人、周瑾 | 应王林心念一动，沉默展露神通 |
| 王林 | 眉心**吉神星点**旋转，**道古头颅**幻化为巨拳，拳周火海弥漫、雷霆闪烁 |
| 九星古妖 | 界内妖气云涌，妖容狰狞含仇恨，喷妖气化**巨大妖龙**；左目**九颗妖星**齐飞融入妖龙 |

结果：

- 诸神通融合成惊天风暴，在巨掌上爆开，横扫四方；红杉子等齐齐喷血后退，巨掌五指**四指崩溃**。
- 王林道古一拳落在最后一指上，巨响回荡——王林身子猛颤、嘴角溢血、右拳鲜血弥漫骨似碎裂，再次后退。
- 融合九颗妖星的妖龙撞来，最后一指骤然崩溃，只剩掌心，巨掌轰然倒卷。
- 冲击传入封界大阵，阵发刺目之芒，缺口被大范围扩展。
- **那把弓毫无变化**，仅其上柔和之芒略有扭曲——诸力于它微不足道。
- 倒卷的巨掌上有五道荧光闪烁，**五指隐隐再生**。

## 四、九颗燃烧修真星与掌尊现身

- 界内星空骤起颤抖波纹与呼啸，众人回头——**九颗如太阳般燃烧的修真星连成一字**，自远处星空疾驰而来，星空似被碎裂，直奔阵外之弓。王林称此为「此生无法忘记的画面」。
- 再生五指的巨掌挥出阻于弓前：
  - 第1颗：接触即爆，巨掌倒退。
  - 第2颗：退不足千丈即落其身，再退。
  - 第3颗：直撞其上，巨掌轰然爆开——一个**黑袍虚影**自内一步走出，正是王林在**古墓外**所见的**掌尊**。
  - 第4颗：掌尊抬起干枯右手，放出「似天地第一道不灭之光」隔空按下，星崩溃，但其亦退后数步、手中光芒崩溃。
  - 第5–8颗：同时爆开，热浪咆哮向太古星辰深处，星空碎灭；掌尊袍子卷动，喷出一口**元神之气**，身子似要被撕开。
- 掌尊沙哑而带震惊：「你没死？」
- 界内不知何处传出浩荡回应：「我没死。」第9颗修真星随之疯狂撞来。

## 五、井中弯月 vs 一字成战

- 掌尊低吼掐诀，身后现出**一口巨大的井**，井水中倒映**一道弯月**；其干枯左手探入井中猛地一捞，捞起大量井水与其中弯月（分不清捞的是井水还是弯月），向前挥出。
- 井水与第九颗修真星相碰：井水急速蒸发化白气消散，修真星四分五裂，星上现出**弯月印记**，砰砰声中穿透该星，直冲此星之后的空明处。
- 弯月落处，一个**看不清样貌的模糊虚影**浮现，抬手食指一挥，写下一个**「战」字**——**一字成战**，弯月顿时崩溃。

## 六、战老鬼的宣言

模糊之声苍老、霸气无尽，平静迈步走向阵外之弓，抛出三条关键信息：

1. **旧怨**：「当年老夫杀人界外，你**太古五尊**无人是老夫对手，被老夫抢走了**大量香火**；今日再遇，你还是那么弱不堪击。」
2. **内幕**：世人只知当年那位以**「吼之力」**将掌尊赶出，却不知那一吼之中的警告——**掌尊若敢再踏入「内府」半步，必死无疑**。
3. **弓的归属**：斥掌尊为「胆小如鼠的**掌印小厮**」，还敢称尊；此弓**除李族外，无人可以让其认主**，既然被拿出来做饵，「老夫代他收下就是」。

- 黑袍虚影猛地抬头：「**战老鬼，你竟然还没死！**」其头上黑袍化作碎片飘散四周，**露出黑袍下的容颜**（本章未描写具体样貌，悬念留至下文）。

## 七、要点与伏笔

- 掌尊以弓为饵，所引之人即战老鬼；王林开篇的推测得到验证。
- 弓的认主条件锁定**李族**，战老鬼自称「代他收下」，暗示其与李族/某人的渊源。
- 「内府」「吼之力」「太古五尊」「香火」构成一条更古老的因果线索。
- 王林付出实伤：右拳骨裂、喷血，古伞与幽冥兽的消耗机制被点明为限制条件。
- 掌尊真容揭晓在即。
