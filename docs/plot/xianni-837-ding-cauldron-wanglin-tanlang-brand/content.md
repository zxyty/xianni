# 仙逆 第七卷 名震罗天 · 第837章「鼎」

## 一、鼎内暂安：王林疗伤

- 王林身落望月体内的古神大鼎，鼎内空间有限；外界延伸而来的无数触手只绕鼎纠缠、在外徘徊摇曳，**并不深入鼎内**——此处遂成危险之地中的安全之处。
- 王林盘膝闭目吐纳，运转元力环绕滋养元神。**塔山**自其身后虚影中走出，同样盘膝坐于鼎内护法，随时准备出手。

### 疲惫的来源（回顾）

1. 进入**雷之仙界**后一直处于谨慎之中；
2. 走出雷之仙界即被传入**幽冥兽**体内，恶战后踏出，回到**罗天星域**；
3. 本欲送**仙选族**族人去**青灵星**，再寻**李元**学习**破灭心禁**并略作休息；
4. **姚家**追杀 + 一些修真家族参与，逼得他亡命天涯、不得不战、不得不心狠手辣。虽连消带打占据优势，但「稍不慎便重伤身亡」的疲惫越积越多。

### 伤势

- 肉身伤损不大，**唯元神受创**。
- **姚冰云**的神通对元神伤害极大，若非**古神皮甲**守护元神，王林早已身亡。
- 打坐疗养后，元神创伤**仅恢复八成**（元神伤不易复原）。
- 心境：修真界随时身灭神消的残酷无法动摇其道心——这种经历自联盟星域时便已习惯，伴其之前一生。

## 二、姚冰云：闭神仙术自封求生

- 她逃出望月所化修真星时被一头**万丈望月**追击吞噬，一股奇异力量令其**元力被分离**，刹那沦为凡人，随即失去知觉。
- 醒来发现身在此地，触手勒紧、寒意透体，**持续不断地抽走她被分离的元力**。
- 她一心向道、性格偏静，强自冷静；但看清四周触手上悬着**一个个干瘦之人**后，冷静险些崩溃——并发现触手吸的不只是元力，**还有生机**。

### 闭神仙术五重（本章明写）

| 次第 | 效果 |
|---|---|
| 闭目 | 合上双眼 |
| 闭耳 | 听力封闭，隔绝一切 |
| 闭息 | 口鼻之息消失 |
| 闭神 | 元神停止运转、自我封闭，沉入玄妙之境 |
| **闭念** | 封锁**生之念**，肉身生机仿若消失，形同死尸 |

- 设定要点：修炼闭神术**天资作用不大**，但对**道心要求极严**，道心不坚便无法沉入闭神之境；姚冰云修至**闭念**，境界可谓极高。
- 自封后其体内咔咔作响，薄冰晶蔓延成片，连同缠身触手一并封住；寒气愈重，最终结成**三尺厚冰层**，将其半封印于冰中，神色一片平静。

## 三、望月归位：罗天北域深处

- 望月庞大之躯在**罗天北域**内游荡，某日停于北域深处——四周星空极为稀薄，**无任何修真星存在**。
- 它卷起身子**首尾相接成圆**，再次化作一颗修真星；万丈触须收缩、喷出大片黑雾环绕星外；触须最终短至**不足百丈**，在所化修真星上飘摇，四周恢复宁静。
- 鼎内那狭长奇异空间中不知昼夜，好似没有时间的延续。

## 四、大鼎的秘密与贪狼未死

### 王林的推断

- 鼎上**古神气息极浓**，虽被望月无时无刻吸收，仍强得不可思议。
- 「望月并未杀我，而是把我扔入这里」→ 此地既是望月**吸收生机**之处，也是其**吸收古神之气**的所在；凡带古神气息的人或物皆被投入于此 → **此处一定还有其他与古神有关之物**。

### 神识烙印大鼎

- 「既然贪狼可以把此鼎收为己用，那么我，也可以」——王林双手按鼎壁，神识流入。
- 鼎内有庞大吸力（即大量触手所散之力）疯狂吸扯神识；王林神识如怒浪孤舟，一寸一寸艰难留印，**弥漫全鼎却毫无操控感**。

### 发现

- 鼎外一处角落有一道**后刻上去的复杂符文**：刻痕不深，肉眼绝不可察，寻常神识查看也不可能知晓，唯有他这般逐寸摸索才触及。
- 符文上残留**一丝贪狼的神识烙印** → 王林寒光大盛：「**贪狼，没死**」。
- 逻辑闭环：贪狼烙印仍在，所以王林无法操控大鼎；但他仍能在鼎上留印，说明贪狼**并未真正掌控此鼎本身**。
- 结论（王林对贪狼生出一丝佩服）：贪狼得鼎后同样不知用法、无法操控，于是**另辟蹊径**——不知从何处得到该符文并印于鼎上，把鼎内部分神通「连接」出来；**他实际操控的是符文**，却借符文施展此鼎的一些神通。
- 出处背景：此鼎为**古神涂司**扔掉之物；王林所继承的古神记忆传承**并不完整**，只有鼎的样子而无具体使用方法。

## 五、悬念（章末）

- 王林决意「**抹去贪狼的神识烙印，此鼎便是物归原主**」，神识自鼎身各处迅速向符文凝聚。
- 就在将要驱散烙印的刹那，王林**神色骤变**，神识蓦然停止、急速收缩，以极快速度顺鼎退回体内。（未言明缘由，悬念留至下章）
