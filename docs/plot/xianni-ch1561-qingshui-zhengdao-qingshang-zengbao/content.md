# 第1561章 情殇、赠宝！

## 一、王林的推演：七彩之人的真正目的

- 清水体内的杀戮本源，本是**七彩之人**种下，但最终并未取走，反而留下大半；因此清水封印一解，便直接引动了**空之大门**。
- 王林由此起疑：七彩之人若不为杀戮本源，那他想从清水身上得到什么？
- 关键线索——清水天灵（生死交汇之处）倾斜数寸的那根利刺，七彩之人曾说那里是**开启轮回之处**。王林推测其目的或是让清水在杀戮本源下**轮回**，但用意不明。
- 七彩之人曾确认「我与他没有关系」，王林反推：这是否说明**清水与七彩之人有关**。

### 迷雾线（界内界外的天大隐秘）

- 起点：当年王林去**颠落之地**遇**贪狼**，获**七彩雕像**，自此摸到一层迷雾。
- 深化：**云海第一战**中**战老鬼**出现，其与**掌尊**的数句对话，让王林生出无限猜测。
- 推论：界内界外的数次大战，皆是这迷雾背后的一部分，其中千丝万缕相关联。
- 相关物证：**七彩界**内**玄武背部的晶石**，已被王林取走。

## 二、王林的道途盘算

- 目标：成为**第三步大能**——修为足够方能知晓迷雾背后的隐秘，也才有资格**复活李慕婉**。
- 现状：已有**两个道果**；生死、因果、真假三道本源必须大成，「再有一个，我便有九成把握成功第三步」。

## 三、清水证道：一剑轰开空之大门

- 清水一头长发飘动，一指虚空点向空之大门，大门轰鸣颤抖，隐有开启迹象。
- 挥手间杀戮本源滔天而起，漫天黑色雪花凝聚成一把长剑，清水握剑仰天低吼：**「今日本仙君证道，开天门，入大道！」**
- 一剑斩下化作黑色杀戮风暴，震动蛮荒星与星空；空之大门裂缝密布，未及打开便被**强行轰崩小半**。
- 门内降下**无色柔和之光**，尽数融入清水体内，其气息轰然暴增，**空涅初期**气息笼罩天地。
- 王林评价：清水体内杀戮本源之强，超过了他所见的一切本源之力。

## 四、情殇：含烟残魂

- 清水身外浮现**无尽虚幻之影**——皆为其一生所杀之人。众魂无声尖叫、恐惧跪拜。
- 唯有一名女子未跪，含笑温柔望着清水，走入其臂弯被抱住。
- 此女为清水之妻**含烟**。清水为取回妻子故物，不惜**毁灭杀戮界**；对妻子之爱是其一生的全部，是快乐也是痛苦的根源。
- 一代仙君在十根利刺被抽出时都未落泪，此刻却如凡人般痛哭。二人彼此触碰不到——「魂无泪」，只见其哭而无泪痕，是为**魂悲**。
- 该残魂只是空之大门出现、杀戮本源大成时幻化出的**虚弱投影**，随即被吸力拉远、如烟丝般将散。清水凄厉嘶吼，宁可**不要第三步、放弃所有**，也要留住这个魂。

### 王林出手留魂

1. 虚空一抓开**储物裂缝**，取出**十多片古息叶**。
2. 双手掐诀打出**百万禁制**，增其威力。
3. 咬破舌尖喷出**淡金色血液**——其**血脉之力**，即**仙人之血**；仙力弥漫使古息叶尽数化金。
4. 金色古息叶穿过清水、环绕女子向内一封，化作**天地之印**，将含烟残魂**彻底凝固**。

- 清水抱住妻子喃喃倾诉，许久后取出**古朴的钗子**（即其灭界所取的故物），缓缓戴在含烟头上。

## 五、赠宝：杀戮本源黑剑

- 清水转身望向王林，目中感激无法形容。
- 他虚空一抓唤回轰开空门的**黑色长剑**，一抖之下将四周所有跪拜之魂（含烟除外）尽数吸入剑内，剑中爆发出浓郁至极的杀戮本源气息。
- 清水赠言：「此剑是我破空门凝聚，它助我轰开空门，蕴含了空境气息，蕴含了我一生杀戮，更有我之魂力，是由杀戮本源所化，我把它送你，你将之炼化感悟，便有了杀戮本源。」
- 该剑本身即**一道完整且大成的杀戮本源**，是清水如今最强之物，也是其身为三步大能的**第一件本源法宝**。
- **稀有度佐证**：三步大能破空门时并非人人能凝聚本源法宝——火雀族老祖、南诏上人、天兆上师、周瑾、灵动都无法做到，就连红杉子、南云子也未做到。

## 六、要点归纳

- 清水踏出第三步（空涅初期），代价与收获同在：得道果、失亡妻残魂之痛。
- 王林人情账：以古息叶＋仙人之血留下含烟残魂，换来一件完整大成的杀戮本源法宝，为其三道本源之外再添一道本源资粮。
- 悬念未解：七彩之人的真实目的、清水与七彩之人的关联、界内界外迷雾。
