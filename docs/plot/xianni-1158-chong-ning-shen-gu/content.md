# 第1158章 重凝神骨（第九卷 云海之巅）

## 一、地面线：四人下探地底声源

### 凶兽危机的判断
- 归元宗老者忧虑：若异动持续，被吸引来的将不止七阶凶兽——
  - **八阶凶兽**：可与**净涅圆满**修士一战；
  - **九阶凶兽**：与**碎涅**修士相差不多。
  - 若真到那一步，「我莫罗大陆将会陷入浩劫」。
- 李向东的宽慰：莫罗大陆所在位置**较居四阶星域边缘**，四周应该没有高阶凶兽。老者只答「但愿如此」。

### 下探过程
- 吕烟菲此前曾阻止三人前去探查，却始终不作解释，径直化虹穿透大地沉入地底，三人紧随。
- 越向下，轰鸣越盛，超过雷鸣，最终化作「惊天动地的咔咔之响」——如骨头崩溃之声，令四人全身骨头酥麻。
- 一股来自灵魂的威压弥漫，四人如蝼蚁；吕烟菲双目明亮、咬唇沉思，显然已有猜测。
- 吕烟菲首次开口传念建议立刻离开；李向东不甘心，带头继续下冲，两名老者与吕烟菲跟上。

### 被神识轰出
- 眼看临近声源，一股庞大神识如风暴横扫：「**离开这里**」。李向东当先吐血后退，两老者亦吐血倒退，吕烟菲嘴角带血但双眼更亮——猜测得到印证。
- 李向东试图抱拳自报「晚辈归元宗李——」，回应是更疯狂数倍的「**滚**」，地面剧震，四人被无形大力推出地底、抛上半空。
- 吕烟菲点评：「早就告诉你们，不要过去。好在**师叔祖**虽说发怒，但却没有太过伤及我们。」
- 关键揭示：「**师叔祖吕子浩**，你们应该有所听闻。」——此即王林自第1063章沿用的化名身份。

## 二、地底线：本尊渡骨劫，重凝神骨

### 崩溃到极致
- 王林本尊三百余丈的古神之身，几乎所有骨头寸寸碎裂，只留下人形骨灰痕迹。
- 头骨亦碎裂大半并持续崩溃，痛苦无法形容，燃烧着**本尊与王林分身**的全部心神。
- 剩余骨头递减：巴掌大小 → 指甲盖大小 → 在余波中彻底消散。

### 分身「定」字诀救场
- 骨灰四散的刹那，**王林分身**猛睁双眼，抬手一指喝「**定**」。
- 代价：分身立刻颤抖、体内轰鸣、喷血后倒——**不惜反噬重伤**施展定身术。
- 效果：消散中的骨灰骤然一顿，为本尊争得**一线反抗的生机**。

### 重凝与逆天之意
- 古神气息疯狂弥漫，莫罗大陆天地元力呼啸涌入地底；一阵无声却穿透灵魂的**咆哮**传遍每一个凡人、修士与生灵耳中，带着逆天之意。
- 骨灰以不可思议之速重聚为指甲盖大小的骨头，并在凝聚中融入天地元力，**坚硬程度远超往昔本尊之骨**。
- 体量递进：指甲盖 → 七寸（几乎耗尽莫罗大陆存有元力的一小半）→ 半丈弧形头骨 → 头骨彻底凝成 → 颈骨蔓延 → 上半身骨头全部重凝。
- **骨劫机制**：骨上阵阵黑芒即骨劫所在，专粉碎一切古神之骨；骨劫毁灭与本尊凝聚周而复始，如此循环反而使本尊之骨**坚毅到了巅峰**。
- 本尊宣言：「我身为敢与天战之古神，区区骨劫，毁不了我」，双眼红光滔天。

### 波及莫罗大陆
- 天地元力云涌翻滚冲垮莫罗大陆**防护层**（如同纸糊，轰然崩溃）。
- 磅礴元力化作漩涡风暴直灌**归元宗**地底，宗内修士早已远远散开，呆望风暴临近。
- 防护罩崩溃后，大陆外星空**星雾**亦被牵引吸扯，未及散开便随元力一同冲入归元宗地底；天空雾气翻滚如长河。
- 方圆百里成一巨大漩涡，漩涡中心即归元宗。外界凶兽被惊退，不敢靠近。

## 三、章末悬念
- 更远处，一头**全身长满利刺、身形超过二百丈的巨大狮形凶兽**目露贪婪，向莫罗大陆冲来，沿途所有凶兽为其让道不敢接近——**八阶凶兽**气息缭绕。
- 与开篇老者的担忧形成呼应：八阶凶兽已被引来。

## 四、要点归纳
1. 吕烟菲已认定地底之人是「师叔祖吕子浩」，并借此在归元宗一方确立王林的身份权威。
2. 骨劫的破解不是硬扛，而是**分身定身术拖住 + 本尊吸纳天地元力重铸**的配合，结果是骨骼品质跃升。
3. 代价外溢：莫罗大陆元力被抽干、防护层崩毁，直接导致高阶凶兽（八阶）来袭的危局。
