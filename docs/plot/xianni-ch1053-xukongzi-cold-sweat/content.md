# 第八卷 联盟隐秘 第1053章 虚空子的冷汗（第三更）

## 一、贝罗现身与短暂交锋

- 尖锐笑声中，**光头之人古妖贝罗**踏虚步来，数步临近仙帝洞府第六层，一眼看到王林，神色诧异：「你竟然也能走到这里」。
- 贝罗讥讽「好一个青霖弟子，竟然以禁制之术把本妖困住」——点明他此前被云仙道侣的禁制所困。
- **王巍**掐诀一指，幻化雨幕直取贝罗；**胡娟**踏入旁侧禁制，咬破右手指尖在虚空画出古怪符文。
- 符文一出，第六层所有禁制如活物般同时闪烁触发，漫天幽光自四方漂升，随胡娟一指齐齐凝聚压向贝罗。
- 贝罗双手四推，体内妖气冲霄而出结成妖气漩涡护身，声音经漩涡扭曲，听者身体震动。

## 二、合作提议：三方各取所需

贝罗主动罢手议和，理由：

1. 云仙道侣二人要救**青霖**（仙帝），他自己要寻杀**古魔塔珈**，目的不同但有可合作之处。
2. 仅凭二人之力恐无法打开古魔塔珈的封印，加上他成功机会更大。
3. 若继续厮杀，「你们救不出仙帝，本妖杀不了古魔塔珈，最终只会便宜了他」。

**贝罗的真实顾虑（心理）**：忌惮王巍与胡娟联手，且此地禁制尽由胡娟操控。他此前离开**葬仙池**后，在仙帝洞府**第四层**与云仙道侣遭遇恶斗，双方谁也杀不了谁，却因胡娟被禁制困了**数月**。此番前来非为厮杀，而为合作。

**结果**：胡娟目视王巍，王巍盯视良久后寒芒消散，挥手撤去水幕，平静应下「可以」。贝罗暗松一口气，落地但与云仙道侣保持距离。

## 三、贝罗对王林的挑拨试探

- 贝罗笑称王林修为又提高不少，但伤患若不速疗将影响日后修为发挥；又言「本妖毕竟是因你才进入这里」，愿以「说出伤你之人，本妖宰了他」作为偿还。
- 王林一眼识破其中挑拨与试探（贝罗诧异王林能到此，更不知王林与云仙道侣的关系），却顺势笑纳，抱拳道谢并预留伏笔：「那伤我之人，若是一会看到，王某自然会指出，到时古妖大人可不要食言」。

## 四、青丹：王巍的馈赠与贝罗的贪婪

- 青霜尸体不便当场取出；王巍自怀中取出一粒**青蜡包裹的青丹**，眼露怀念，递给王林。
- 青丹来历与功效：**恩师当年所赠**；无论修仙力还是元力，只要伤患源自天地之气，服下可**瞬间恢复**。
- 数量：王巍口称「剩下不多」，实为**总共三粒**——胡娟一粒，王巍两粒。
- 王巍嘱王林可现在服下，或留待日后危机之时；说话间冷冷扫了贝罗一眼。
- **贝罗的反应**：见青色蜡丸即起贪婪之色，因他太熟悉此丹——当年他与古魔偷袭青霖，青霖伤势诡异，服青丹作用已然不大但仍有几分，成了古魔与古妖的巨大阻力，也是**古妖最终失败的重要原因**。贝罗由此判断：王林与云仙道侣关系莫逆，且对方手中还有此丹，真斗起来是个麻烦，遂收回目光。
- 王林未即服用，收入**储物袋**。

## 五、进入第六层中心：黑雾宫殿与掌印石碑

- 胡娟引路，众人直奔第六层中心的**黑雾**。周佚始终飘在王林身边守护（王林此刻最为虚弱）。
- 临近黑雾时贝罗心中生恨：若非当年失败，不会让古魔塔珈抢了先机；又自我宽慰——青霖不好对付，塔珈至今怕是未成功，否则早已离开此地。
- 踏入黑雾中的宫殿，地面上有**高约两丈的巨大石碑**，其上**空无一字，唯有一个掌印**。
- 王巍表态：**后三层为恩师闭关之寝宫**，其内变化未知，为便于行动「还是多等一些人来此为好」，并建议王林先疗伤，以便在最后三层有自保之力。
- 王林看不透云仙道侣：不急进入、反要等人；古妖贝罗竟也不问，似抱同样想法。
- 周佚以**剑灵特殊方式传音**：「他二人行事诡异，这一点我早就看出，但却不会害你我」，劝王林安心疗伤。

## 六、二十七日等待与入场顺序

- 王林盘膝坐下，**未服青色蜡丸**，改服此前所得其他药物，闭目疗伤；但**神识不封闭**（虽拖慢疗伤速度），始终弥漫并锁定入口，等待虚空子——他推断虚空子三人应是第一批到第六层大殿者。
- **第7天**：王巍、胡娟、贝罗均已盘膝打坐；王林伤势略有恢复但仍有隐患，再服药物。
- **第27天正午**：王巍与胡娟几乎同时睁眼看向门口，贝罗更快一步；王林神识生波动。
  - **第一个入殿者**：并非虚空子三人，而是**疑似昆虚圣女的粉衣女子**——全身缭绕无数雪花翩翩起舞，神色平静，扫视时在王林身上多看一眼，未言语，盘坐角落。
  - **不到半柱香后**：**虚空子、村姑美妇、黑衣人**三人入殿。

## 七、指认与虚空子的冷汗

- 虚空子一眼看到王林，双目滔天杀机疯狂闪烁；王林同时看到他，寒芒毕露，平静开口：**「古妖大人，他，就是伤我之人」**。
- 话音落下瞬间，王巍、胡娟骤然盯向虚空子，贝罗似笑非笑望来；周佚杀机一闪，不动声色前飘数步拉近距离，只待机会便以刚修成的**不灭灵觉**出手为王林出气。
- **虚空子当前状态**：重伤未愈，**元神损失一半**，修为自**碎涅大圆满跌落至碎涅中期**。他自忖即便巅峰时面对云仙道侣与那古怪光头之人也需谨慎，何况此刻。
- 虚空子倒吸凉气、额头冷汗瞬出、心跳加速：想不通几个月未见，王林用什么方法让这些人为其出手。
- 他身子不敢有半点举动、更不敢后退，唯恐一个举动招来全殿雷霆一击，只得强自镇定，罕见地抬出势力背景：**「老夫联盟星域修真联盟长老虚空子，大长老重玄子师弟，各位道友这是何意」**。

## 八、要点与伏笔

- 王林以「借势」之法完成反击布局：早在贝罗许诺「说出伤你之人便宰了他」时便留下伏笔，二十七日不闭神识只为等这一刻。
- 三方临时同盟成立（云仙道侣＋古妖贝罗），共同目标是打开古魔塔珈处的封印；同盟脆弱且各怀目的。
- 悬念：后三层（恩师寝宫）内的变化；掌印石碑的用途；云仙道侣为何要等更多人来；虚空子抬出修真联盟能否解围。
