# 第九卷 云海之巅 第1282章 大造化的开始

> 世界状态须知归属：本章王林以化名『吕子浩』行事（自第1063章由吕烟菲奉上），本章未直接点名，言行归【王林】。

## 一、七彩神空钉之威

- **来历与规格**：七彩钉子是专杀第三步大能的利器，以太古时期从外部神秘星辰横渡而来的陨石炼化，内蕴一丝**连掌尊都弄不清晰**的外星辰之力，对第三步大能者的伤害达到不可思议的程度。
- **旧例**：当年的**封界之主**被九十多枚七彩钉钉住后，也要全身欲崩而亡，被那无法理解的力量冲击造成无法想象的伤害。
- **本章伤害链**：
  1. 王林施展，只能破开一寸——对水道子而言仅需消耗修为便可逼出，无生死危机；
  2. **风仙界石人老者分身**降临，出其不意一指而落，钉子生生下沉到**五寸**，水道子几欲发狂却凭第三步修为勉强压下，本欲杀王林后闭关疗伤；
  3. 神通降临欲毁灭王林的刹那，王林身上浮现**「其主」的玉佩**——震撼不亚于见到天逆、见到其主；
  4. 紧接着**「其主」的手指**降临，水道子一眼认出是他主人的手指，魂飞魄散、来不及求饶，钉子被彻底打入眉心刺破头骨、插入脑海。

## 二、水道子七窍爆芒与遁走

- 七彩钉完全没入后立刻融化成七彩液体，弥漫水道子脑内一切位置；其双眼、双鼻孔、双耳、口共七窍全部爆出七彩之芒，头部如布满七个小洞的筛子。
- 水道子疯狂后退抵抗，眼中挣扎越来越弱，几乎丧失心神。
- **对其主的控诉**：「主人，你赐我不灭符诏，免我三次危机，眼下三次已过，你来杀我……因果轮回，因果轮回」；「我不服……你死后我修成了第三步，我是天地大能，我是神宗之主，我要取你而代之」。
- **香火之力自救**：怒吼「十五亿水道门徒，给我爆」，令随行的巨大修真星内**十五亿水道门徒轰然爆开**，独属于第三步的香火之力冲入体内，与脑中七彩之芒对抗。
- 水道子破开虚空向**神宗**方向遁去，体内轰鸣不绝，一路疯癫压制毁灭，瞬息消散无影。五阶星域随之彻底寂静。

## 三、王林油尽灯枯，天逆化石

- 王林崩溃了一切；此战虽未与水道子展开最终毁灭，但伤势**远超当年妖灵之地**。
- **生机全部耗费**，白发苍苍成为老人；闭眼刹那身外**三道漩涡**收回体内，**五道本源**在体内旋转，仍无法弥补失去的生机。
- 眉心（原本空无一物）现出漩涡，**天逆珠子**飞出即融化，顺眉心蔓延至全身——王林化作一尊苍老的石制雕像。
- **其主的玉佩**一晃融化，再次进入王林眉心消失无影。
- **战场残器归体**：
  - 崩溃的三叉戟处一片晶光凝聚于王林右手中消失；
  - 第三辆**射神车蝴蝶器灵**崩溃之地凝出虚弱的七彩蝴蝶，挣扎飞近，化无数七彩晶光融入王林体内；
  - 崩溃的两把**黑白短剑**幻化而出，如自死亡中还形，化作两只**黑白小鹿**融入石像。
- 王林意识沉入黑暗沉睡，身体成石、失去一切神通法力，在充满裂缝、阴风与漩涡的崩溃五阶星域中漂浮：遇漩涡便急速旋转被甩远，遇裂缝则身上添一道道裂痕。

## 四、女子救人：苍老之声的指点

- 不知多少天前，一名女子来到五阶星域，赶至王林与水道子的战场，落泪咬破下唇，悲绝茫然，一股死气久久不散。
- 星空深处传来**苍老的声音**：「你，可想救他」「他没有死，但也是死了，你需找到他所化的石像，我教你一个方法，或许可以让他苏醒过来，只是这个方法，需要付出很大的代价」，声音随即虚弱如从未出现。
- 女子坚定点头，擦泪搜寻。三天、十天、十九天……**三十天后**在五阶星域一处角落找到满是伤痕的苍老石像，抱住石像落泪无声。

## 五、蛮荒大陆的血养一年

- **隐居地**：云海之内、深藏星雾、不知几阶星域的一个**蛮荒大陆**，无数年来极少有人发现；大陆凶兽众多，但一感受到女子身外弥漫的气息便颤抖噤声。女子在大陆**北部一座山谷**落下，整理山谷与石像同住。
- **方法（苍老之声所授）**：「他失去了生机，若是寻常生机，可以弥补，但他所失去的，是心神的生机，是元神的生机，更是灵魂的生机，若想让他苏醒，你要以生机滋养」。
- **日课**：每天咬破指尖，以蕴含元力的鲜血涂满石像全身，不容半点遗漏。石像粗糙，伤口手指抹过剧痛难当；血未涂完常已结珈，便撕下血珈再挤鲜血继续。一次次之后，痛楚堪比酷刑，一天天之后更胜天地一切酷刑。
- **进度曲线**：石像慢慢吸收血液，隐有光泽，似恢复一些生机，苍老之样也有细微变化。吸收耗时由**一整天**缩短至**十个时辰**；一年之后，女子每天需**两次**涂抹全身。
- **一年之后**：石像光泽越来越亮，样貌由老者略转年轻；女子容颜越来越苍白，因大量失去含元力的鲜血，如盛开的花朵正慢慢凋谢。目光如永恒。

## 六、伏笔与作者说明

- 沉睡中的王林做了一个梦——一个他此生**与天逆有关的、大造化的梦**。
- 作者耳根章末表示：这将是写到现在**最大的一次**（大造化），眼下**还未结束，只是上半部分**，还有下半部分。
- 章末另有 YY 活动与起点账号手机认证的公告（与剧情无关）。

## 关键转折

1. 水道子被其主亲手（手指）钉入七彩神空钉，从「胜利者」瞬间沦为逃命者，暴露其**背主**身份与不灭符诏三次已尽的因果。
2. 王林以生机耗尽为代价换取生还，天逆将其封为石像，进入长期沉睡。
3. 三叉戟、蝴蝶器灵、黑白短剑三样崩溃之物「自死亡中还形」融入石像，暗示天逆的收纳/复生之能。
4. 女子以血养石像一年，开启王林苏醒的漫长线索；「大造化」正式开局。
