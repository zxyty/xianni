# 第七卷 名震罗天 第664章 错过

## 一、宝合楼：拒收与错过

- 宝合楼中年男子向老者回报：王林拿来的是一把飞剑，「极为寻常」，纵有神通也不会太强，**不符合宝合楼的交易条例**，故拒收。
- 该中年男子对老者极为恭敬：老者虽只有**化神初期**，但在宝合楼身份超然；中年男子隐隐知晓，**老者曾修为达到婴变中期，因受伤太重才跌落至化神**。
- 老者望着王林渐渐消失的背影，浑浊双目露出疑惑，低语：「这背影有些熟悉。」随即摇头转身回楼。
- 回到楼内偏厅，老者坐在摇椅上，身影疲惫，**苦涩地摸了摸胸口**，长叹一声，望着地面沉默不语。
- 本章标题「错过」即指此处：两人擦肩，未能相认。（老者身份文中未点明，勿臆测。）

## 二、青竹阁：孙墨初鉴飞剑

### 店与人
- 青竹阁不大但素雅，木质格子紧靠墙壁，格内小盒以卷黄丝布盛放各式法宝与丹药。
- 店主为青年文士**孙墨**，修为**化神初期**，手捧古书，见客随和热情，无宝合楼式傲慢。

### 鉴定过程
1. 王林拍储物袋取出飞剑求售，孙墨初看眉头略皱，苦笑请求上手细看。
2. 神识扫入剑内，发现**剑内竟有一道神通烙印**，端倪看不出，但威压令其元神剧震。
3. 灵力融入剑体，剑爆出浓郁剑气，孙墨生出「**水乳交融**」般的融合错觉 → 判定单凭融合性即可归**中阶法宝/中阶灵宝**。
4. 未开神通先试锋：操剑一指店外巨大的**上品原灵石**，剑化长虹无声穿透灵石而回。评语：「如此融合姓，可称中阶灵宝；如此凌厉，高阶有余。但**此剑之速无法匹配**，可惜。」
5. 开启剑内神通 → 飞剑当场消失，**再现时已在十丈之外**；孙墨出店召回，再指灵石，飞剑**瞬移**入灵石内穿透而过。
6. 孙墨震撼失语：「这是瞬移」

### 设定要点：为何飞剑难载瞬移烙印
- 一般飞剑**无法留下瞬移烙印**——剑体承受不住瞬移时的迅猛摩擦。
- 没有通天（原文作「通大」）修为，也无法把瞬移烙印刻在剑体内。
- 即便有刻画之修为，**除非功法极高、意境特殊**，否则剑内烙印无法形成**生生不息**。
- **王林能成，因其意境是「生死轮回」**，使飞剑内的瞬移在某种程度上生生不息；但**平衡一旦被打破，也会失效**。

## 三、议价与长老定性

### 出价过程
| 出价方 | 价格 | 备注 |
|---|---|---|
| 孙墨 | 十万上品灵石 | 王林皱眉（因孙墨修为太低，灵力操控只发挥此剑十分之一威力） |
| 孙墨 | 追加至十五万上品灵石 | 咬牙，称「此剑虽是极品灵宝，价值已给到极高」 |
| 王林 | **三千仙玉** | 长老二话不说，拍储物袋当场倒出一堆仙玉，仙力弥漫全阁；王林袖子一甩收入储物袋 |

- 王林反问「你这里可有婴变修士」，孙墨一怔并露不悦，随即传音玉简请来长老。
- 等待期间孙墨屡屡侧目：眼前人修为明明是**结丹后期**，气度却像家族族长甚至长老。他考虑过对方隐匿修为，但**青竹阁内有家族长老所设阵法，修为未达问鼎者入内必无所遁形**，故确认其确为结丹期。

### 婴变后期长老验剑
- 清风入阁，青衣老者踏入，第一眼即盯向飞剑，目光开阖隐有精芒。
- 王林侧身一扫即知其修为**婴变后期**（未圆满），久经生死、心性磨练，远比路上遇到的四个小家伙深沉。
- 长老神识一扫即露震惊；瞪眼止住孙墨发言。
- 左手弹剑，剑鸣清脆如大籁；右手一挥，飞剑**直接挪移出千里之外**，再瞬现于其身周徘徊，剑上散出**仙气**化作凌厉剑气含而不发。
- 剑上更有**一道道电光游走**；长老以手指试触电光，「砰」一声轻响，**面色苍白、连退数步**，恢复后不怒反喜。
- 孙墨以其眼力看出剑上竟有**仙力**，脱口「仙宝」。
- 长老纠正定性：
  - **不是仙宝，是「伪仙宝」**；
  - 其上有**大挪移之术**；
  - **那奇异的雷电才是此宝最珍贵之处**——若无这一丝雷电，只算寻常伪仙宝，有了它则大为不同。
- 长老误判来历：「此物是你家族长辈赐予的吧，你可确定要出售」——王林不答，直接报价三千仙玉。

## 四、章末转折：铜镜

- 长老追问「你可还有其他伪仙宝」。
- 王林在储物袋上一摸，取出**一面铜镜**扔给长老。
- 长老只看一眼，面色**前所未有的大变**，比看飞剑时更震惊，失声道：「**传承伪仙宝**」——章节至此断，交易结果未叙。

## 五、本章新增设定小结

- **宝物层级链条（本章出现）**：中阶法宝/中阶灵宝 → 高阶 → 极品灵宝 → **伪仙宝** → （带特殊雷电的）伪仙宝 → **传承伪仙宝** → 仙宝。
- **货币层级**：上品灵石（十万、十五万级）远低于**仙玉**（三千仙玉即可成交），仙玉散发浓浓仙力。
- **鉴定阵法**：青竹阁阵法可识破问鼎期以下的修为隐匿。
- **王林状态**：表面结丹后期（受阵法验证），实为隐藏；心境达一代宗师；随身储物袋中尚有伪仙宝级藏品（铜镜）。
