# 第2036章 道吉国师！！

## 一、局面：十色雾玄阵
- 王林以六极道所化图腾试探十色雾气，雾气如沸腾般蠕动，内有凶兽嘶吼，图腾似被吞噬。
- 王林判断：此人在此已久，布下大阵并与皇宫连接，能在**仙祖的阵法禁制**中另布诡异阵法，所图极大；此刻未走而以十色雾气笼罩，必是处于**某种秘术的关键**。
- 雾中传出轻笑，自称「老夫」，点明此阵为**十色雾玄阵**：「若是仙祖的八极道神通，或许真可破开老夫的这十色雾玄阵，但如今只有六极，想要进来，你要努力了。」

### 王林动用的力量
- **六极道图腾**：镇压、爆开成大手擒杀。
- **五行真身**：与王林相貌一模一样，施展金木水火土五种本源神通。
- **杀戮雷霆真身**：踏出即黑发、滔天杀戮、残忍冷笑，化无数黑色细丝穿敌。
- **道古虚影 → 道古真身**：眉心与双眼二十七星幻化，虚影凝实如真人；随后本体膨胀至百丈、再至七八百丈，身覆细密暗纹，透沧桑之感。
- **本体**：两具真身外出时，本体蕴含**虚之本源**。

## 三、道古真身的设定要点
- 为**古族三脉族人最强的本命神通**，王林在仙罡大陆**首次展露**。
- 一旦此身受损，对修为影响太大，且不便，故古族之人非在战场不轻易显露。
- 皇宫内的道古族人连同**道吉皇尊**根本没机会展露，就被王林的毁灭之力摧毁。

## 四、结局：雾心老者现身
- 王林一拳将落时，雾中惊天嗡鸣，九兽尽数爆开化雾倒卷回收。
- 迷雾凝聚收缩，冲出一头同为七八百丈的**巨大苍蝇**（头有复眼），撞向王林右拳。
- 苍蝇倒卷之下，王林看到雾气扩散中心**盘膝而坐的老者**，且「他熟悉」。
- 结句：**「天运子，果然是你」**——道吉国师的身份被指认为天运子。

## 五、归属与存疑标注
- 据世界状态须知：**天运子已于第514章死亡**，且自第1631章起以四大星域之魂占据王林分身、容颜化作天运子。本章「道吉国师」被王林认作天运子，属**身份指认**，其真伪与延续关系（转世/寄魂/残魂/同名者）本章未明说，故相关关系置较低置信度备核。
- 本章雾中自称「老夫」者即道吉国师，其言行归入【道吉国师】实体；仅在结尾由王林指认为天运子。
