# 仙逆 第1648章 太静了

## 一、朱雀星集结：号召与出征

- 王林站在朱雀星上属于自己的雕像之上，目光横扫天地，看到无数长虹自大地呼啸而来，其中多是熟面孔：
  - 弟子 **十三**
  - 仆从 **大头**
  - 兄弟 **司徒**（按世界状态须知，即自第336章起自称「司徒南」的断臂所化人影，真司徒南第61章已死）
  - 前辈 **南云子**
  - 以及数千他认识、见过的界内修士。
- 数千人目光凝聚交融，作者点出「热血」母题：修道岁月不使其消散，只令其沉淀，到国之将灭一刹轰然爆发。
- 王林大袖一甩，自雕像上向天空迈步，喝出：**「与我一同，收服界内山河」**。白衣如雪、满头白发飘散，身化长虹直奔星空。
- 司徒（司徒南的断臂）、南云子等紧随，其后数千界内修士施展神通跟上，远看如无数流星自大地崛起，冲出朱雀星、冲向星空。

## 二、心境：从封尊到「走出洞府」

- 王林在最前方，神识散开，双眼寒芒，滔天杀机弥漫。
- 自陈：他不是英雄、也不想做英雄，只是一个赶上这场大战的平凡修士；但他明白了**担当**与**责任**，也知晓了**封尊**二字的含义。
- 关键决意：**他要做的并非封尊，而是要做自己——轰开这天地，走出这个洞府**。解决界内与界外之战只是第一步；第一步都做不到，就不必谈走出洞府。
- 誓言：**天若阻则灭天，地若阻则毁地，人若阻则杀人。**
- 杀心回溯：一生杀戮的巅峰是在**朱雀星赵国灭藤家满门**；**阔别两千年**，此等杀机再次涌现，这一次是为自己，更是为界内。

## 三、横扫昆虚星域

### 战场态势
- 昆虚星域此前已在王林**一箭**之下死了诸多界外修士，仍有残留。
- 王林神识笼罩整个昆虚，残存界外修士无所遁形；界外修士**眉心皆有不同印记**。
- 情报要点：此时进入界内的界外修士**绝大部分集中在罗天星域**，其余三个星域只有驻守之人 —— 故昆虚残修皆欲逃往罗天。

### 斩杀逃亡队
- 前方数百万里外有几十名界外修士仓皇逃往罗天。一名青年修士回头，只见白影一闪，随即目光旋转，看见队伍最后一具无头之身正是自己，方知已死。
- 王林右手一扫，四名界外修士头颅飞起；随后化作白芒于人群中穿梭，**手起头落，不足三息**，从血肉碎块中走出，一身白衣不染鲜血、神色不变。
- 王林语：**「这些头颅，还远远不够」**。随后数千界内修士赶到，只见满空鲜血残骸与不散的杀戮气息。

### 昆虚深处：太古星辰同胞兄弟之死
- 两名界外修士为罕见的**同胞兄弟修士**，出自**太古星辰**，小有名气：
  - 修为 **天人第二衰**，出手同时、彼此配合擅长合击，联手可令 **天人第三衰** 狼狈而退。
  - 身世：自幼失去父母、被野狼养大，形影不离；后被一名**狼族修士**看中，**赐予族印、收为族人**。
  - 性格残暴，嗜好**虐杀修为不如自己的敌人**，入界内后手上死了诸多界内修士。
- 二人被王林的威压远程锁定、无法脱出，如丧家之犬红眼狂逃。王林缓步走来（步伐超过闪电雷鸣），一步临近其一，右手一扫。另一人放弃逃遁反扑，兄弟二人头颅同时抛起。
- 王林评语：**「兄弟之情可敬，但杀我界内修者，必须要死」**。

### 战果
- 昆虚星域内**所有残存界外修士，再无任何一个活口**。
- 王林身后随行**数百个被封印元神、无法瞑目的头颅**，如沉地狱不得挣脱。
- 叙述评点：论杀人之多，王林称不上第一，但绝对不少，具体数量他自己都记不清；乱世修真界，不想被杀就必须杀人。

## 四、结尾伏笔

- 走出昆虚，进入 **召河星域** 边界处，王林缓缓开口：**「太静了」**。（章末伏笔，指向召河/后续战局的异常）
