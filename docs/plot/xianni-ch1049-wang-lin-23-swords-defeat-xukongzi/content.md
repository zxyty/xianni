# 第1049章 想要王某之宝，尽管来！（第八卷 联盟隐秘）

## 一、二十三剑的收尾

- 大殿内所有目光聚于虚空子分身元神之外的银光连招，剑势诡异，惊心动魄。
- 银光越来越快：第十九剑、第二十二剑……从第十七剑往后，每多一剑威力都是前者的数倍。
- 代价：王林皮肤大范围枯萎、神色黯淡，**体内的古神之力也承受不住这般吸收**。二十三剑已是他当时的极限。
- 第二十三剑落下刹那，王林猛然睁眼：银光由极速闪烁骤然静止，随即刺目而起照亮全殿，**二十三把银光大剑同时成形**。

## 二、破分身元神与次空涅法宝

- 二十三剑如银色流星尽数刺入并穿透虚空子的分身元神；分身元神毫无闪躲之力，当场四分五裂。
- 同时，分身元神体内的**紫色冰块**咔咔崩溃——那是虚空子的一件**次空涅法宝**。
- 分身元神被毁，虚空子本体立刻遭受严重伤势，喷血、面色苍白，骇然道：「这不是寻常的次空涅法宝」，没想到王林既有此等恐怖法宝，又如此难杀。

## 三、杀局的本质与虚空子的抉择

- 虚空子修道无数年、心智通灵，已猜到：**王林以本源为饵**，逼他无法发挥全部神通，绝大部分心力被牵在明悟本源上，从而被设下一个无法进退的杀局。
- 但他只需数息就能摸索出本源奥秘——让他躲避，不亚于直接杀他。故选择「拼了」，不退。

### 龟甲与旋风：两道防线
- 一拍储物袋取出**黑色龟甲**：巴掌大小、通体黝黑、威压外传，不知取自何物，同为**次空涅法宝**（虚空子身为修真联盟重要之人，不缺法宝）。抛出后即不再理会，散开心神近乎疯狂地感悟本源——他感到自己就要触及困扰无数年、梦寐以求的第三步之路。
- 龟甲黑光爆发，前三剑成一字撞上，龟甲不断后退却生生扛住；第四至第二十一剑连成一线轰来，龟甲遍布裂缝，**仅坚持三息便瓦解崩碎**。
- 第二十二、二十三剑蕴含毁灭之力最多，直取前胸。虚空子双手外挥，体内涌出**紫色之风**结成旋风——旋风刚现即被第二十二剑撞碎。
- **第二十三剑穿透落于虚空子胸前**：喷血、面色苍白、胸前衣衫破碎、血肉模糊。

## 四、锈迹一弹：真正的杀招

- 王林等的就是这一刻——杀局的结尾。
- 他抬起酸麻的左手，在**铁剑上的四处锈迹**飞快抹过，沾染锈迹后狠狠向前一弹。
- 锈迹内蕴含诡异之力，一弹之下融入虚无；就在虚空子将要明悟第三步本源道路的刹那，如一阵轻风吹过其身。
- 虚空子身躯剧震、**七窍流血**，不得不退开，一退便离开了本源所在的红芒，**功亏一篑**。他双目通红如野兽，身子却无法操控地向后抛去，血雾狂喷。
- 王林眉心**第三目**一闪，红芒消散——本源其内已几乎灭绝，**只剩一丝被收回第三目中**。

## 五、震慑与退场

- 王林手持铁剑，冷漠扫视：
  - **村姑美妇**心神一震，不敢与之对视，低下了头。
  - **黑衣人**眼中震惊与浓浓忌惮，同样不敢对望。此刻的王林，气势为其人生至今的巅峰。
- 无论阴谋还是诡计，**能击败一个碎涅修士**便足以说明一切——这样的敌人谁愿招惹。
- 王林撂话：「想要王某的本源，想要王某的法宝，你们，尽管来拿」，身影渐融入**由两个雕像双目分出的紫色漩涡**内消失。

### 三方心绪
- **黑衣人**：明知王林施完二十三剑已是强弩之末，却丝毫不敢赌；那连招让他失了信心。他断言「朱雀圣宗将因此人而重新崛起，在这联盟星域内不是重现昔日辉煌，而是会达到一个从未有过的高度」，并骇然自问：**此人有本源，是谁给的他本源？**
- **虚空子**：落地无血色、极为凄惨，肉身剧痛加元神毁去一半的重创使**修为大范围跌落**；在本源前的大起大落令其怒吼。平静后杀机更疯狂：「此子心机太深，更是胆大果断，决不能允许他成为日后的**朱雀圣皇**；为了杀他，老夫不惜**天人第一衰提前三千年**而来，也要杀了他，夺取本源。」
- **村姑美妇**：因了解更多，震撼犹胜二人。除本源外，更震撼于那把**铁剑**——如此强大的法宝，她记忆中只听闻过一次。

## 六、设定披露：天下至宝的等级

村姑美妇忆及在**昆虚之境**听长者论天下至宝：

- 天下之宝分为**灵、玄、仙、空、涅**五类；并非仅有五类，其上还有更高等级的法宝——但那位论宝的长者**自身最多也只见过涅极之宝**。
- **灵、玄之宝**：数量众多，为修道**第一步**修士常用；其中不多的一部分第一步修士拥有**仙宝**。
- **仙宝**对**第二步**修士已有些无法满足，尤其修至**碎涅**的老怪——仙宝除非顶级，否则帮助往往不如仙术神通。
- **空**：碎涅老怪转而寻找更高层次法宝，即超脱上古时期炼气士常用仙宝者；**追溯远古、寻找遗迹**，从远古遗迹内发现的这一类法宝便是「空」。（本章至此中断，未续讲「涅」。）

## 七、要点提炼

1. 王林的战法是**心理与因果层面的杀局**：以本源为饵锁死对手心力，再以剑阵消耗其法宝，最后用铁剑锈迹之力在明悟临界点上给出致命一击——目标不是杀死，而是**打断其明悟第三步**。
2. 铁剑连招的上限与代价明确：**23 剑**，第 17 剑后倍增，反噬到连古神之力都难以支撑，事后为强弩之末。
3. 虚空子代价惨重：分身元神毁、两件次空涅法宝（紫色冰块、黑色龟甲）尽毁、肉身重创、修为跌落、第三步明悟功亏一篑。
4. 王林在联盟星域的声望与威慑自此确立，朱雀圣宗的复兴与「朱雀圣皇」之说被外人提前点破。
5. 本源已近乎耗尽，**只剩一丝**存于第三目——后续隐患。
