# 第1454章 分！（第九卷 云海之巅）

## 一、开场：王林震慑全场

- 地点：封印之地（古墓）内。战斗结束得太快，四周近百修士心神撼动。
- 王林在人群中信步而走，无人敢阻：他此前擒下妙音道尊侍女，并展现**虚火之力**。
- 最骇人的是——来自半空风暴内、太古五尊之一**妙音道尊**的**香火一击**，王林**硬抗不伤**，无半点伤势。
- 众修议论：
  - “虚火修士”“连道尊一击都无法杀他”；
  - “他方才施展的神通，分明就是**本源**，此人就算不是**三步大能**，也是只差一步”；
  - “他是谁？”
- 黑压压的**蚊兽**群此刻方降临，四周修士急急后退，停止一切撕斗。

## 二、风暴撕裂：两大高手退场分立

- 王林寒目望向天空风暴，风暴仿若被两只无形巨手向外一撕、从中崩溃，两道人影左右退开：
  - **右侧：大荒上人**——寒光一闪，长笑称王林“不愧是那**老鸟**的后辈”，敢在五尊之一妙音道尊眼前擒其侍女，“这份胆量，这份果断，可为人杰”，并自陈“不枉老夫之前送你**毒甲**护身”。他已看出王林不凡，动了联手之念。
  - **左侧：妙音道尊**——形如翩翩少年，神色阴沉，低头盯王林后忽然冷笑。

## 三、道灵与誓符：妙音道尊的离间之计

1. 妙音道尊右手一挥，取出约千丈大小的**青蛇**，青蛇挣扎嘶吼；一捏之下惨叫、身子虚幻崩溃，化作**头颅大小的丹药**（即**道灵**）漂浮掌上，药香弥漫，闻之血液急速流转、精神一振。
2. 妙音道尊开价：“大荒老毒，在这古墓内你不是我的对手……本尊抢你道灵在先，便把这道灵还你，你我就此罢休，你可离去。”
3. **王林的判读**：这一句“逆转乾坤”。太古五尊心深智高、修炼数万年绝无愚者；妙音一眼看出王林与大荒上人有联手迹象，遂用还宝一语，在尚未成形的联手上劈出巨大裂缝。在妙音心中，与王林身上的**天逆**相比，道灵不算什么。
4. **王林的底气**：若在外界遇妙音必远遁，差距太大；但在此地他确定——妙音道尊虽是太古五尊，**只能发挥出空涅初期之力**。自己虽无胜算，对方要杀他也需极大波折。最重要的是，王林有一个**古奴子**。
5. **大荒上人应下**：眯眼沉吟后笑，看都不看王林，点头道“你把道灵拿来，老夫离去”。妙音不语，只等其立约。大荒遂**以香火起誓**：“老夫大荒，以香火起誓，拿到道灵，一去不回”，掐诀化出**誓符**飞向妙音。
   - 设定：以香火起誓化作誓符，是**第三步修士之间较为信服的立约方式**。
6. 妙音接符心松，甩出丹药；大荒袖子一甩收走，似笑非笑扫了王林一眼，转身直奔远处，踏入裂缝消失。

## 四、王林诈败

- 大荒消失一瞬，王林自地面轰然飞出，**雷图**幻化、火焰焚烧，直奔妙音。
- 妙音冷哼，**与虚火修士交战先行封死自身各种情绪**，掐诀下拍，香火之力化作手持玉剑的妙曼虚幻仙女，一剑扫向雷图。
- 剑芒滔天似可斩开这封印之地；剑气落在雷图上化作千万波，**雷图瞬息崩溃**，王林喷血急退、神色萎靡，似重伤欲遁。

## 五、大荒背誓：黑掌偷袭

- 妙音欲追，身后黑风呼啸，天空扭曲中探出**巨大漆黑手掌**，散发无尽腥风毒气按向其背。
- 妙音面色大变，果断放弃追杀王林，转身掐诀外拍，并喷出紫色雾气，其内冲出**古朴盾牌**横在身前。
- 黑掌落盾：盾牌裂纹无数却未碎，被大力倒卷砸在妙音身上，妙音喷血急退。
- 妙音厉声：“大荒老毒，你不守承诺！”
- 大荒长笑现身：
  - “笑话，老夫从来就是**分人来守承诺**。你能抢老夫之宝一次，在这古墓内定然还有第二次、第三次，岂能次次都让你来抢！”
  - “且这小道友是**老鸟后辈**，老夫一生就老鸟一个挚友，岂能离去？你这身体，老夫要定了！”
- 大荒右手一挥，黑掌五个指甲碎开，化作**五道弯刀般黑气**尖啸冲向妙音。

## 六、分赃约定（本章标题“分！”之眼）

- 王林萎靡之色顿消，杀机一闪，右手前挥，**血光滔天、血剑幻化**直奔妙音。
- 王林平静开口：“**我要他全部香火。**”
- 苍老阴森之声回荡天地（大荒上人）：“可以，**老夫便要他身，融入我魂。**”

## 七、血剑贯体

- 妙音并未把王林与血剑放在心上，认为王林最多只能分散其心神，真正敌人是身前的大荒老毒；因黑指甲飞来，他大半心神都在身前，盾内紫气弥漫如化紫海。
- 妙音后退中喝道：“小辈王林，给本尊滚开，待本尊腾出功夫再来杀你！”左手在身后一挥，海风之浪化出**高约百丈、紫色铠甲、手持三叉戟的模糊虚影**，挥戟迎向血剑与王林。
- **叙事者点破妙音的致命误判**：他未曾看到王林与**司墨子**一战，当初在**大帝星**急于离去前往这古墓外围、也未了解大帝星后来之事——否则绝不会小看王林。因为在他身后，是**一尊杀仙**，是**一尊炼化了灵动上人、实力大增的古神**。
- 血剑之锋天地间几无可挡：**穿透三叉戟 → 穿透百丈虚影 → 直奔妙音**。
- 妙音来不及闪躲，低吼挥手，全身浮现**紫色鳞片**、散发妖异紫芒护体。
- 五道指甲冲击盾牌，盾牌四分五裂崩溃，指甲穿透落在妙音身上；同时血剑冲入其体内。
- 惊天动地之声传遍整个封印之地，**天空被撕开巨大裂缝，外围雾气宣泄而来**。
- 结果：妙音喷血，身前血肉模糊、毒气弥漫，血剑自其胸口穿透后化作弧形返回王林身旁。

## 八、收尾悬念

- 妙音道尊神色狰狞、急急旁退，不得不承认自己小看了王林，嘶声厉啸：“**音之本源，水之本源，音浪灭道！**”
- 但他并不知道：**王林的最强一击，已然准备就绪。**

## 关键设定点

| 项 | 内容 |
|---|---|
| 誓符 | 以香火起誓化作符文，第三步修士间较可信的立约方式；可被“分人来守承诺”者背弃 |
| 封印之地压制 | 太古五尊之妙音道尊在此仅能发挥**空涅初期**之力 |
| 虚火克制 | 与虚火修士交战需**先行封死自身各种情绪** |
| 妙音道尊本源 | 音之本源、水之本源；杀招“音浪灭道”；护体紫色鳞片 |
| 王林战力评价 | 众修认为其“就算不是三步大能，也是只差一步” |
