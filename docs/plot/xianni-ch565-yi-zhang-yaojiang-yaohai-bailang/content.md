# 仙逆 第565章 一掌

## 一、战况起点：黄泉小指硬接

- 王林以化作黄泉的右手小指承接妖将来袭之力，指骨发出「咔咔」之声，力随指走波及全身。
- 王林身退三丈，脚下地面裂出两道深痕，右脚后踏止住。
- **余波**：十里波纹扩散——二门外被黄泉之气吸纳的妖兵肉身尽化飞灰；十里内建筑阁楼崩溃，碎末化气浪远扩；唯数个修为相当于婴变期之人全力抵抗方幸免。
- **杀戮灰气**：杀戮仙诀自碎末血肉中炼化出四道灰气，加上先前司马炎那道共五道，如五条苍龙环绕王林左手指缝。

## 二、妖将的神通谱

| 神通 | 形态 | 表现 |
| --- | --- | --- |
| 十崩拳意 | 拳意 | 前战所用，威力低于妖海百浪 |
| **妖海百浪** | 化无形妖力为实质妖海 | 一拍成浪，三十浪→六十浪；另可四十浪环身如四十海龙，人如「海之妖仙」 |
| 「甲，开」 | 身前七尺妖力之幕 | 无声无息成形，反弹三道灰气 |

- 妖将魁梧，赞王林「好一个指力神通」，喊话：「接下本将这式妖海百浪，你才有资格与我对话」。
- 妖将修为**相当于婴变后期大圆满**，与王林相当；但**神通远超王林**。

## 三、修魔海之谜的印证

王林由妖将「化无形妖气为实质妖海」联想到当年在**朱雀星修魔海**听闻的传说：无数年前有大神通修士，一式神通把**有形之海化作无形雾气**，才有了修魔海（雾海）的独特之貌。当年半信半疑，今日亲眼见到反向的化虚为实，震惊之余更多是沉思。

## 四、王林的三层应对

1. **禁制**：退后中双手掐诀连打禁制，在妖浪下如薄纸即溃，化点点黑芒消散。
2. **血色玉符**：取姚惜雪的血色玉符大把捏碎，血光裹身，抗住三十浪冲击仅数息即崩。
3. **符文神通（本章关键突破）**：
   - 危急时脑中鬼使神差浮现**从第二个石像体内吸收的金色符文**，剧烈闪烁欲挣脱飞出，干扰其百念与仙力运转。
   - 王林已达「仙力透体、空明顿来」的程度，战中本不应突生杂念——他判定「空穴来风未必无因，神念符文未必无果」，索性放开心神。
   - 打出一道禁制后散出指缝灰气，以右手食指连画：一笔（灰气苍龙扭曲成符）→百念通达；二笔→妖将有面对天地之威的错觉；三笔画成瞬间，脑中金色符文融化为金色之力融入符文，磅礴气息涌现。
   - 妖将被迫将三十浪提升至**六十浪**迎击。符文破三十浪后金芒黯淡，于第二个三十浪中消融为虚无；随即金芒内**三道灰气**激射穿透妖海直奔妖将，被「甲，开」妖力之幕反弹而回、略有黯淡。

## 五、对话与决断

- 妖将：「好一个符文神通，王林，我之前却是小看了你……你全部施展出来，与我酣然一战。」
- 王林冷问：「十三在哪」——妖将：「打完再说。」
- 王林警告：「我最后的杀招，一旦用出，你必死无疑」；妖将以四十浪回应，称若真能杀我则心服口服。
- 王林亦言：「杀了你，恐怕这天妖郡，我也无法容身。」

### 王林的内心权衡（取巧之心的由来）
- 妖将真正绝招是妖海百浪，十崩拳意仅其一；是否还有更深杀招不明，不愿尝试。
- 修为相当而神通不如，**即便配合法宝亦无十足把握取胜**——这是他修炼数百年来第一次面对同阶而无胜算，稍有不慎便会败落。
- 身在敌城、目的是**救十三**，一旦受伤救人之事即烟消云散。

## 六、一掌：仙界巨大手印

- 出处：当年在**破碎的仙界**一处见到的巨大手印，王林曾在旁感悟很久。
- 前例：与**红蝶**一战中曾凭感悟挥出此式，但**只具虚表、无任何攻击之力**；胜在气势无法思议、几乎无人能看透。
- 施展：王林拔地而起立于百丈高空，闭目凝实脑中手印、调整回当年感悟之心态；睁眼时眼中有莫名之色，俯视大地如俯视苍生，视妖将如蝼蚁。
- 妖将反应：心神**第一次剧震**，自述「只有在古妖大殿内第一次看向那古妖之像时，才有过类似的感觉，即便是妖燕京不具备」，身周妖浪不受控急速旋转。
- 结局：王林右手向下一按，天空一暗，奇异之气四面凝聚，身下形成巨大掌印——**一掌按下**，本章至此结束（悬念）。
