# 第1712章 三命术！

## 一、祭坛异常显露

- 王林抵达祭坛后一直无暇细察，注意力被祭坛上原先存在的（烨寞）手臂吸引；即便以其谨慎性格用神识扫过，也未发现端倪。
- 转折点：融合古祖鲜血（尤其一滴**魂血**）、吸纳**烨寞右臂**后，借**撕天之力**余波，隐隐掀开祭坛面纱，使其回荡波纹。
- 王林疑问：「这祭坛为何会出现在这里，烨寞的右手又为什么会被祭祀于此？」
- 撕天之术消散后，祭坛波纹转弱，复归平静。

## 二、分身归体与百万禁制轰坛

- 王林离开祭坛；**分身**在远处睁眼，一步迈出与本尊重叠，双影融合化作一体，活动身子确认无不适。
- 掐诀打出近百万道**禁制印记**，环绕落于祭坛：每落一印祭坛轻震，愈多愈烈，终至轰鸣、密布裂缝、碎石剥落。
- 半柱香后祭坛四周碎末如雾，祭坛缩小一大圈。
- 王林判断：祭坛古怪在其**内部**，有一股模糊力量使神识进入后被改变、无法看清。
- 再打出近百万禁制，祭坛快速粉碎，只剩原先一半大小。

## 三、赤红之芒与撕天定局

- 一道裂缝延伸至祭坛内部，赤红之芒成扇形透出；随后第二、第三……共十余道红芒滔天而起。
- 红芒所化**红色波纹**与禁制相触，如雪遇炭火，磁磁作响即刻消散——双方**仿若天敌**。
- 王林认出红芒「很眼熟」，在波纹逼近自身刹那，右手一扣，身后幻化**烨寞巨臂**，低吼「撕天」，倾尽烨寞右手之力并融合自身**八星吉神、古妖、吉魔**之力，一撕「足以开天」。
- 结果：红色波纹被撕碎崩溃，祭坛裂缝碎灭、整体瓦解，显露真容——**八角形状、散发刺目红芒、如血池一般之物**。

## 四、封灭族与三命术：三份祭坛齐聚

- **设定**：太古星辰有一族名「封灭」，其族有术名「**三命**」。修炼三命术需封灭族**完整祭坛**；该祭坛不知何故化作三份，消失于茫茫星海，无人知晓去向。
- **三份祭坛来历**：
  1. 第一份 = 当年机缘巧合所得**昆虚血祖的血阁**（由此知晓三命之术）；血阁内曾进去一名女子（王林故人），其肉身早已在阁内消散，只余一缕魂。
  2. 第二份 = 在**罗天**从**古妖**处所得的祭坛。
  3. 第三份 = 本章道古墓地祭坛所化的**八角血池**——王林曾遍寻不获，见血光刹那即有猜测，气息比对后完全确定同属封灭族。
- 王林挥手取出前两份祭坛，三坛同现星空，血光交融、彼此辉映，显然同出一处。
- 王林心态：狂喜；「此术若我学会，那么整体实力将会大增」，并权衡「修炼会有危险，但与成功后的好处相比，这点危险，值了」。

## 五、施术：族印入眉心，封冥刃斩三魂

- **法门来源**：在**道古墓地**从封灭族女子的**记忆**中获得。
- **封灭族族印**：散发幽光、沾有干枯褐色鲜血，为王林当年在道古墓地从欲杀自己的封灭族女子**眉心生生拽出**。
- 王林将族印一把按在自己眉心，眉心灼热，族印蔓延无数分支触手钻入，与身体紧密粘连；此等痛苦不足以令其动容。
- **咒言**：「以印开冥，我有封灭族族印，召唤长存于天地间的封灭你族祖灵，化作**封冥刃**，**斩三魂，斩三神，斩三身**」。
- 咬破舌尖喷出精血 → 精血悬浮蠕动，吸收三座祭坛红芒 → 化作一丈长刀，模糊重影，肉眼久视眼花；神识看去实为**三把刀重叠**，散发诡异气机。
- **斩三魂**：长刀自王林天灵无声斩下，贯穿全身。王林身体剧震、面色苍白，灵魂剧痛欲崩强行忍住，终从天灵漂出**两缕魂**。

## 六、封冥刀崩碎（关键后果）

- 王林灵魂融合古祖魂血后已是**道古之魂**，非封冥刀所能斩；若非此刀由王林**自身精血**所化，决然无法斩其魂。
- 一刀斩过，刀无法承受其灵魂之强大与反震：三刀重叠**只剩双影**，其后崩溃碎灭，**永久消散于天地，再无法幻化**。
- 悬念：三命术尚余「斩三神」「斩三身」未成，而封冥刃已毁。
