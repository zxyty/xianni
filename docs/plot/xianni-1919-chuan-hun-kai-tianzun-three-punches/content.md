# 第1919章 穿魂铠！

## 场景
绿魔洲·道魔宗废墟。王林与道魔宗天尊老祖（赤发）对峙，天尊老祖以三拳试探/了结因果。

## 一、第一拳：九种神通
- 王林拳头收回、身子一晃，蹬蹬蹬退出三步。
- 三步足迹各异：第一步赤红散发火焰；第二步墨绿、抬脚时被植被覆盖；第三步大地化作金色金铁足迹。
- 天尊老祖评：「可以在本尊一拳中不死不伤，且只退三步，逼出融入体内的三种神通，你确有毁道魔宗的实力。」
- 王林判断：对方拳内蕴含九种神通，自己只能抵消六种，退的三步即那无法抵消的三种所致。
- 王林心态：**他在学习**——脑海反复浮现这一拳，「原来天尊层次的修为，是这么战斗」。

## 二、第二拳：十八种神通·开辟虚无
- 天尊老祖赤发无风自动，全身处于虚幻与真实之间急速变化，打出第二拳。
- 效果：撕开天空大地，将王林四周化为一片无边无际的漆黑虚无，仿若另一个世界。
- 层次差：金尊修士见此拳只会绝望，十个金尊同时出手也拖延不了一息——**这是质的差距**。金尊仍在「施展神通」，天尊已是「融道于体、融神通于一拳一脚间」。
- 王林应对：自认做不到融道于体、法随身动，遂以**道古身躯 + 修为之力**凝成一拳——「它没有神通，有的只是信念与意志的一击」。
- 结果：虚无崩溃撕裂，场景回归道魔宗废墟；王林嘴角溢血，连退七步（每步脚印各不相同），体内轰鸣，右臂颤抖滴血。二人相距百丈。
- 天尊老祖评价：「你修为不高，但战力勉强可以达到天尊的层次，只不过你还不知晓天尊的道，我想我应该是你战的第一个天尊。」并暗赞「此人不凡」。

## 三、第三拳：二十七种神通·全力一击
- 天尊老祖走出十步，如一尊天地之灵，第三次抬手，并给出**约定**：
  - 「你若能接下我这最后一拳，道魔宗之事，一笔勾销。」
  - 「这一拳是全力的一击，若此拳杀不了你，那便真的无法杀你。」
  - 「你毁道魔宗，想来也必定是有因果，这因果我不问，第三拳，便是终结。」
- 王林自知：不穿魂铠接不下，此拳足以将其完全轰杀，连道古身躯也无法残存，将彻底形神俱灭。
- 王林心评：「天尊，不愧是整个仙罡大陆上，除了跃天尊外，最强的巅峰。」
- 拳出：二十七种神通化作莫大漩涡黑洞，吞噬一切气息——废墟碎片卷入即被吞噬，天空坍塌扭曲成弧形，大地成诡异半圆形被吸撤，携奇异呼啸直奔王林。

## 四、借天牛魂力·登金尊
- 王林闭眼，面孔浮现**天牛魂图腾**，瞬间蔓延全身，气息暴增。
- 魂力钻入其每一寸血肉、涌入元神与灵魂：修为**空劫初期 → 空劫中期 → 空劫后期巅峰（金尊程度）**后平静。
- 天尊老祖双目**第一次收缩**：「借魂力……这是天牛魂力，你获得了天牛魂的认可……能提高到这种程度，你能听到天牛魂音！」

### 设定：仙族七十二洲之魂（本章要点）
| 要点 | 内容 |
|---|---|
| 数量 | 仙族七十二洲内镇压七十二个魂 |
| 状态 | 镇压力度有强有弱，魂本身强弱有别；约一半已是死魂 |
| 绿魔蝎魂 | 原本极强，但镇压力度大、年代久远（早于天牛洲形成），今已被削弱太多 |
| 天牛魂 | 后来加入者，时间短，本身极强，七十二魂中**排第十八位** |
| 初步认可 | 凡活魂，每洲都会出现类似「使者」的存在；借魂力上限=空劫后期，达不到金尊 |
| 高度认可 | 极罕见，需机缘巧合听到**魂音/魂的咆哮**；借魂力可达**金尊**，金尊即极限 |
| 唯一例外 | 中州皇城下镇压的**仙族第一魂**的高度认可，或许可超越金尊 |
| 稀缺度 | 一洲同一时代最多只有两人可获高度认可；此类修士比天尊还少，几乎与跃天尊数量相当 |

- 天尊老祖的震动：从未听说有人身为天尊的同时还具备某洲魂的高度认可；此概率在他看来比出现跃天尊更低，**仅次于诞生新的大天尊**。并判断「任何一个大天尊看到，都会极为在意，立刻笼络于麾下」。

## 五、速神决·九十八身
- 王林睁眼，全身流转金尊修为，感受到从未有过的强大。
- 身子一晃，身旁出现第二个身体，继而第三、第四……直至**第九十八个**，其中**九十七为残，一个为真**。
- 王林宣言：「我做不到道融于身，做不到法随身动，但我可以用这**速神决**，在一瞬间轰出**九十八种神通**，与天尊一战！」

## 悬念
本章止于王林以九十八身迎击二十七种神通的漩涡黑洞；标题「穿魂铠」所指的魂铠尚未正式穿上（王林仅言「不穿魂铠的自己，接不下」）。
