# 第八卷 联盟隐秘 第905章 刑罚仙人

## 一、破封入十七层

- 第十六层水池上方的符文封印在雷光游走中脉络消散、层层崩溃。王林右手抬起，**子母道枯**幻化而出，兽骨现、幽光闪烁，四周煞气毕露。
- 崩溃中的符文一震现灰光欲石化自保，**塔山**一步踏出、右拳轰击，符文彻底化作无数黑色晶光消散。
- 水池地面显出**传送阵**，第十七层通道开启。

### 朱雀星上的旁观者

- 通道打开的瞬间，朱雀星一处宗派广场内、正与低阶弟子含笑交谈的**酷似黄龙的老道**神色一动，遥遥望来。
- 其心中判断：十七层没什么不可让人看到之处，王林修为已到可了解一些隐秘之事的程度；**但以其修为，十七层已是极限，第十八层进不去**。

### 进入次序

塔山先入阵消失 → 王林确认无危险后迈入 → 大头童子、雷吉、云雀子同时冲出随传送阵消失。

## 二、第十七层：刑堂

### 环境

- 约**百丈大小**，一片漆黑无光（但黑暗挡不住神识），**死气浓郁**。
- 四周墙壁垂下**铁链交错**，每一交错点吊着一具尸骸，数量**不下上百**。
- 尸骸散发**仙气**，却毫无灵动、死气沉沉，仿佛已吊在此处无数年。

### 酷刑细节

- 大都在**盆骨**处被铁链穿透，也有连**双肩琵琶骨**都被穿透者。
- 每具骸骨上都有生前**被鞭打的痕迹**，显系承受无法想象的酷刑后凄惨死去。
- 身上符文闪烁，每闪一次体内散出的仙气更浓。
- **元神被大神通之术生生禁锢体内**：肉身已死，无尽死气侵蚀元神，元神保持神智却无法离体，只能眼睁睁看着肉身干枯、最终被生生磨灭。
- 此刑透出对仙人的浓郁恨意，**此恨无绝**，给王林带来强烈冲击。

### 四人各自的异变

| 人物 | 反应 |
|---|---|
| 塔山 | 第一个进入，以其冷漠亦瞳孔一缩，双目精光打量四周 |
| 王林 | 神识一扫倒吸口气、面色阴沉；体内清水所送**仙豆**如沉水中，运转缓慢 |
| 大头童子 | 已入升仙池、化去意境凝聚仙元、已成仙人，故震撼最深；体内仙元颤抖被压制，耳边似闻凄厉吼叫，喷血；王林一掌拍其后心灌入磅礴元力方才清醒，此后目露浓浓敬畏 |
| 云雀子 | 感受到仙遗族气息，体外黑色印记符文自行蠕动、飞快收缩**退化**，如水液流转向胸口凝聚；灵魂中原本对大头童子的敬畏被一股力量生生压制 |

### 云雀子的辨认：刑堂传闻

> 仙遗族**最古老的先祖**来到朱雀星时，曾在**最后两层之外单独开辟出一层，命名为刑堂**；若有非仙遗族之人进入，立刻便被侍卫灭杀。

云雀子据此确认传闻属实。

## 三、干尸暴起与破敌

1. **首尸苏醒**：一具干尸身上符文急闪并穿透融入体内，干尸猛睁双眼、目内空洞却爆发无法想象的恨与杀机，低吼「**仙人死**」，铁链透明消散，携仙力风暴直扑大头童子。
2. **仙元失效**：大头童子掐诀欲施仙术，仙元竟在运转刹那自体内散出、急速消散流逝，仙术未成便全身仙力大范围流失，几乎魂飞魄散。
3. **王林出手**：踏出一步，右手虚空一按，元力涌现，虚空波纹回荡，将干尸震退数丈。
4. **塔山的威慑**：右手握拳，拳上现**符文印记**，干尸一见立刻神色恭敬、迅速后退，不敢与其交手。
5. **全场苏醒**：全层所有吊尸同时睁眼，铁链尽消，如凶兽般冲向王林、大头童子与雷吉。
6. **呼风**：王林掐诀低喝「呼风」，黑风自其右手涌现、瞬间弥漫全层，幻化**两头黑龙**怒吼咆哮，以王林为中心疯狂横扫；尸骸纷纷止步后退（死后被奇异力量操控，远不如生前），数具直接崩溃。
7. **符文封印**：众尸骸身上符文同时亮起，形成一幕**无形封印**压下。此封印王林并非首次遇到——**与姚家族人一战时**曾深受其困扰，故立即察觉，面色一变、身子前迈、脚下波纹回荡，瞬移消失。
8. **雷意点杀**：王林现身于一具尸骸旁，右手双指蕴含**天地雷意**，无尽雷光自虚无凝聚指端，点在尸骸头部；尸骸剧颤，空洞双眼现出片刻清醒与一丝**解脱**，砰然崩溃消散。

## 四、关键机缘：仙元融仙豆

- 尸骸消散刹那，一股**仙元之气**自其体内散出，顺王林身体钻入。
- 王林观察后发现：该仙元之气**未造成任何伤害**，反而在其体内**与清水仙君的仙豆融合**。
- 王林立刻**狂喜**——此地上百具仙人干尸，等同一片可供其吸纳仙元、壮大仙豆的机缘之地。

## 五、伏笔与看点

- **第十八层**：黄龙老道明言王林现有修为进不去，指向更深层隐秘。
- **对仙人的恨意**：仙遗族先祖以酷刑囚禁仙人元神磨灭，暗示仙遗族与仙界的宿怨。
- **仙遗族血脉压制**：云雀子符文退化、对大头童子敬畏被压，说明此层力量层级高于「新晋仙人」。
- **塔山身份**：其拳上符文印记能令刑堂侍卫恭敬退避，暗示其与仙遗族的渊源。
- **仙豆成长路径**：击溃受刑仙人干尸 → 仙元融入仙豆，为王林后续成长开出新线。
