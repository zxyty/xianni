# 第1564章 十三

## 一、红杉子脱困谢封尊

- 红杉子双眼神采越来越明，身体内传出砰砰之声，一片红雾自汗毛孔弥漫，化作**血衣**在身。
- 他向王林抱拳一拜：“**多谢封尊**。”——确认王林在界内的“封尊”身份被公开承认。
- 转身死死盯住天罚殿殿主，眼中露出睿智之芒，放话：“**秦九延**，你就算是燃烧修为，今日也逃不走，你不会死，老夫会被你炼成**血身**，成为我界内一大助力。”（原文如此，意即欲将秦九延炼作血身）

## 二、四人合围秦九延（黑衣老者）

| 出手者 | 手段 |
| --- | --- |
| 红杉子 | 化红影直奔前方，正面逼近 |
| 龙磐子 | 平静抬右手，**山河图**轰鸣，卷动八方（断其后路） |
| 清水 | 右手一指，面部五道裂缝再次撕裂，**阴月有晴之术**如髓入骨，以特殊方法持续爆发恐怖之力 |
| 王林 | 面色如常，双目金光一闪，金芒涌入右手指尖遥指，喝一字“**定**” |

- 黑衣老者面色苍白，虽为大能但终究是修士，面对四人根本无力去战，只能急速退后。
- **结果**：一场没有悬念的战斗。**七彩界崩溃**，天罚殿殿主秦九延败落，被红杉子**禁锢带走**。

## 三、战后各方去向

- **龙磐子**：燃烧的灵魂在红杉子帮助下有了熄灭迹象；带着伤势与弟子**重玄**默默离去，等待下一次界内界外大战。
- **王林**：红杉子邀其前往**云海战台**，以封尊之名成为余下战争之魂、带动界内之修进行最终反击——**王林没有去**。他已拿到**三个道果**，当务之急是在**体内排斥之力全部爆发前**，让三道本源大威**轰开空门证道**。
- **清水**：一席青衣在星空飘摇，带着悲伤与孤独默默离去，去寻找自己的**女儿**，或许能找到、或许一生也找不到。只要王林一句话，他即便在天涯海角也会回来；二人之间不需太多言语。星空中如今只剩两个人让清水在意，其中一个便是他的**师弟王林**。

## 四、界内局势与士气

- 利好叠加：红杉子脱困、**召河**收服、**天兆上师**死亡、龙磐子加入、天罚殿殿主被擒。
- 眼下界内**已然没有了七彩界**，再无任何破绽。
- 几十年大战之后，凡修士都已多少拥有视死如归的热血——必须战下去，一旦失败唯有死亡。
- 红杉子口中“**封尊再现**”一句，让界内之修一个个抬起低着的头，眼中战火更浓。

## 五、昆虚一灵：四大星域交融的坊市

- **昆虚星域**内、与**云海**、**召河**、**罗天**连接之处，有一颗修真星，战争中慢慢发展成庞大**交易坊市**，名为「**昆虚一灵**」。
- 四大星域**边界交错之地**出现了不少这样的修真星，各星域修士在其上交易所需资源，使四大星域**慢慢融合在了一起**。
- 坊市内各星域修士络绎不绝、鼎沸如潮。
- **召河女修**最为有名：召河虽沦陷、死亡众多，但当年反击中不少女修杀出重围；如今召河刚刚收复，大量女修从其余星域回归家园，召河燃起**复苏气息**。其余三大星域的单身修士常施展全身解数，寻求一生道侣或露水之缘。
- 坊市中还有**客栈**，为来往交易的修士提供打坐吐纳之处；每一个房间内都有**大量灵石与不多的仙玉**。

# 第1471章 客栈闲谈：封尊之名与朱雀星修的尊崇

## 场景与背景
- **地点**：某修真星坊市东部一家中等规模客栈；坊市弥漫整颗修真星。
- **时局**：**界外大战**正酣，四大星域（昆虚、罗天、云海、召河等提及）修士云集，客栈成为结识道友、切磋神通的场所，往往座无虚席。
- **细节**：背景深厚的客栈内备有 **元玉**，为老怪提供元力修养；修士虽可辟谷，但仙果美酒与凡间食物可勾起未修道时的记忆。

## 主线：封尊之名
- 客栈北部一桌，中年文士 **绉东德** 向同席道友吹嘘「我曾与封尊相识」。
  - 同席老者拆台：此人每遇 **召河女修** 便说同样的话，听得耳朵生茧。
  - 绉东德不以为意，称相识于 **朱雀星**，那时封尊「还是一个结丹小修」，未料他会成为今日封尊。
- 同席两名女子：年轻的粉色道袍披肩女子（被称「许姑娘」），与年长的紫衣妇人（被称「周师姐」）。

## 转折：朱雀星修士的身份
- 粉衣女子随口一句「师姐，我记得你当初曾说你来自朱雀星，你可曾遇到过封尊」，全场骤然寂静。
- **绉东德当即起身抱拳**：「在下绉东德，见过朱雀星道友，之前话语为虚，还望道友莫要介意。」
- 老者及四周罗天、昆虚修士齐齐起身见礼；几名 **云海** 修士更上前抱拳一拜。

### 「封尊」的地位设定
- 封尊之名并非个人荣耀，而是以**一次次振奋整个界内的大事件**换来；在界内修士心目中，**封尊即「界内之魂」**。
- 封尊来自 **昆虚**，昆虚修士因此在其他三大星域道友面前隐隐受到尊重。
- 封尊出身 **昆虚·朱雀星**，人人皆知，故朱雀星修士自然受敬。
- 朱雀星为弹丸之地，走出的修士极少，真正遇上者不多见；正因如此，一旦确认身份，受尊敬的程度极深。
- 叙述点题：「一人得道，鸡犬升天」——朱雀星因王林一人而受整个界内之修尊重。

## 关键追忆：马良 = 王林（据世界状态须知归属）
紫衣女子（周师姐）面色微红，一一还礼后回忆：
- 「我应该是见过他」，但不确定所见之人是否即封尊。
- **「他那个时候，叫做马良」** —— 那时他**应是刚刚筑基**，**很冷漠，有些无情**。
- 在**域外战场**内，他与她们一同回到了**火焚国**。
- 推论：若他真是封尊，则**他与李慕婉就是在火焚国认识的**。
- 补充关系：**李慕婉是周师姐的闺友**。

> **归属标注**：据世界状态须知，王林自第111章起冒用战神殿弟子「马良」的姓名身份行事（真马良已于第102章死亡）。故本章「马良」的言行应归【王林】。李慕婉已于第188章死亡，本章为回忆性提及。

## 结尾悬念
- 客栈远处，一名 **黑衣青年** 独占一桌默默饮酒，神色冷漠，冰冷气息弥漫，生人勿近。
- 他望着客栈外出神，心念「**师尊你在哪里**」，眼中露出思念。
- 刹那间身子一震——一名 **白衣男子** 掀帘从客栈外走入，青年双眼露出**不敢置信与激动**之色。
