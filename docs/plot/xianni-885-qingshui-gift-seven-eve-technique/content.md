# 第885章 清水的馈赠

## 一、七夕之术：四日之限

### 术法规则（向家先祖口述）
- **七夕之术**：上古时期「逆天改命第一术」，须坚持**七天**，元婴若能撑满七日即可恢复苏醒；此术之强，即便死亡之人也可完全复活，前提是**拥有足够的生机**。
- **生机传递完全不对等**：七夕代表七天，每增加一天所需生机为**前一日的百倍**，到最关键的第七天，所需生机庞大到无法想象。
- **代价**：向家先祖已先取王林**一半生机**作为出手要求；王林剩余生机「只能够坚持两曰」。

### 过程
1. 环绕王林周身的死气吸走其绝大部分生机，转投李慕婉元婴，以特殊方法融入其中；元婴逐渐凝实。
2. **第一天、第二天**顺利；**第三天**王林生机全部消失，输送中断，元婴开始更快、更剧烈地消散，随时可能彻底崩溃。
3. 王林明言「**继续吸我的生机**」，死气一端绕李慕婉、一端环王林，继续抽取。其容貌**再次衰老**、皱纹弥漫，仿若一瞬走过千年人生，并越发清晰地感受到**天道的召唤**。
4. 王林深吸一口气，体内爆发出更浓郁的生机，化作「生之风暴」横扫四周，令此地无数人头幽光骤闪。
5. **异动**：棺材盖倾斜，露出向家老祖干瘦如柴、仿若尸骸的躯体；其双目睁开，一道冰冷无情、透出浓浓死气的目光落在王林身上。

### 本尊接力
- 联盟星域内一颗修真星上，**王林本尊**正藏身某修真门派、**充当低阶弟子**，盘膝打坐。
- 本尊体内生机疯狂消散而**不加阻止**，平静望天沉默；恒久冰冷的目光此刻如分身一般透出柔和。
- 生机以特殊方法自本尊涌入分身，再灌入李慕婉元婴，元婴重新凝实。
- **第五天**时本尊全身黯淡无光、**一头红发转为暗色**——即便本尊为**古神之体**也无法承受。

### 结果
- **第四天结束**：李慕婉元婴**彻底凝实**，死气被彻底驱除，元婴内留一丝生机。
- 但无新生机融入，这一丝生机**无法稳定、无法苏醒**。「四天，便是极限」，第五天无法度过。
- 向家先祖：「老夫只能做到这一步，你的生机不够，自然就不能复活这元婴。」随即重新躺回棺内，以死气旋风卷起二人送出通道、顺裂缝离去。
- 王林在被送出的过程中立即掐诀，以**层层禁制**弥漫元婴之外，减缓那一丝生机的消散。

## 二、出沟壑：清水与向云东

- 出沟壑瞬间两道目光聚于王林之身：**清水**见其此刻模样一怔，沉默不语；**向云东**似早知会有此幕，看一眼便收回目光。
- 王林珍重地把李慕婉元婴放入**储物袋**，唤清水「师兄，我们走吧」，清水袖卷破空而去。
- 向云东自语：「许木，老夫虽说算计于你，但却没有任何隐瞒，以你的心智，自然也早就知晓，帮你恢复元婴，代价就是大量的生机，如此，我们倒也不相欠。」

## 三、避天棺鉴定（星空途中）

王林取出**避天棺**请教清水。清水身影一顿，**右目红芒一闪**，许久后判断：
- 此物他**未曾见过**；
- 内有**浓郁仙气**，显然是**仙界之物**；
- 其内另有一种**极为特殊的力量，好似某种规则**；
- 用途**应为疗伤**。

王林收起避天棺，仍**不知使用方法**。

## 四、清水的馈赠

### 传承二仙术
- 清水评价：王林**虽未入升仙池，但也通过了考验**；自己此行去**联盟**凶险很大，无法让王林伴随左右，在**联盟星域**内一切要靠他自己。
- 「呼风唤雨撒豆成兵」三仙术，王林**已会呼风**；清水双指成剑点其眉心，一股迅猛**仙元之力**融入王林体内，同时**唤雨**与**撒豆成兵**的全部信息直接出现在其脑中。
- **传承 ≠ 传授**：传承只在**嫡系师徒**之间进行，可保证所传之术**半点不丢**，减少不必要的弯路，使被传承者**感悟最深**。

### 仙元金豆
- 「你没有进入升仙池，这仙术无法完全发挥，师兄没什么送你，就送你一道**仙元之力融身**，助你施展仙术。」
- 传入的仙元**未被清水取走**，在王林体内运转后化作一颗**仙气缭绕的金豆**，落入**王林元神之内**。

### 清水的心结（追忆）
- 起初清水待王林只为**报答师尊**（师尊当年虽是戏言，却是他苏醒后唯一可报答之事），并不甚在意，救下亦是为了师尊。
- 王林未入升仙池令清水失望，他**已决定就此断了王林与师尊之缘**，从此再无关联，专心去寻**仙界崩溃之迷**与**当年自己癫狂之因**。
- 目睹王林为一女子甘愿舍尽几乎全部生机后，清水起了追忆：他从王林身上看到**当年的自己**——苏醒后望着一地鲜血、爱侣闭合的双目与凄美容颜，那一刻**他的心崩溃了**。
- 自此清水看王林的目光**不再只是报答师尊的途径**，而露出一丝柔和。
