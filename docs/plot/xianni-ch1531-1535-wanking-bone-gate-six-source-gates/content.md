# 仙逆 第1621-1623章 · 六道空门与第三步大能

## 一、连破三门（第1621章）

王林拒绝以吸收空门之力的方式取巧晋升——「这也仅仅是两道本源之力罢了」——而要空门爆发带来的修为突飞。星空崩溃的漩涡内传出愤怒咆哮，第三、第四、第五座空门接连同时幻化，三门并立震撼四周数万界外修士。

- **因果印**（此生第五式神通，源于七十多年梦道的因果感悟）：一掌按在第三门上，五指扣入握拳，向外一甩似拽出扭曲空门虚影，第三门裂而崩碎。气势由**空涅中期→空涅后期**。
- **生死印**：左手白气（生）、右手黑气（死）涌入第四门，双手向两旁一掰，第四门轰然崩溃。气势由空涅后期→**空涅大圆满**。此时眉心隐现一道漆黑裂缝。
- **真假道**（自真假本源悟出）：闭目则万物皆假，睁目则假亦成真。王林闭目挥手，第五门如拂尘般无声消散。

### 眉心裂缝与香火界
空灵修士本以自身成香火界，以香火之魂温养，可强令他人膜拜为香火之奴。王林全凭自身轰门、不借香火，故其眉心裂缝并非香火界，而是**其自身天地**，同样可令人强行膜拜。此时裂缝未完全打开（修为不足），五门尽开后方彻底幻化，内有近乎吞噬星空的无尽吸力。

### 界外修士反应
界外修士四散奔逃。空玄初期的青衣男子看出端倪：「因果，生死，真假——他居然去明悟这些大道虚源，此人惹不得。」点明**本源分实虚**：雷火为实，因果之属为虚，明悟虚源难度更大。

## 二、万空骨门现世

王林以清水送出、入体即大成的**杀戮本源**引动第六门。星空凭空飘落寒冷的红色雪花，第六座空门由白骨组成，形如巨大头骨之口，散出震动星空的波纹：被波及者瞬间衰老，近万人无声苍老而死，化为灰迹。

识得此门者仅南云子与虚神天尊两人：
- 虚神天尊转述**阴月仙妃**之言：万空骨门是她家乡的一道天壑，家乡中能引动此门者极为罕见，凡引动者若不夭折，日后必成**大尊**。
- 南云子转述**上代封尊**传道：能在第三步引动此门者未来无法想象；此门非府界之物，而是封尊家乡出现的天地之兆。

## 三、六道本源开门与晋升第三步（第1622章）

杀戮血掌一击仅令骨门数道裂缝，且爆出反震之力。王林退后数步，依次施出「雷」「火」「因果印」「生死印」「真假道」，真假道睁眼时更弥漫**当代大儒的浩然之气**，与空灵初期气势融合，最终喊出「本源六道，开空门」，一拳轰碎万空骨门。

作者笔法点明这一拳的三重份量：两千年修道的期望；六道本源大威的全力一击；**复活李慕婉**、让自己强大的决心。

### 破境路径（本源融合顺序）
1. 雷本源 + 火本源融合 → 空涅初期升**空涅中期**
2. 因果本源融入 → **空涅后期**
3. 生死本源 + 真假本源融入 → 突破空涅圆满 → **空灵境初期**（第三步空之四境）
4. 第六门崩后磅礴空门之力涌入 → 空灵初期升**空灵中期**，身体真正突破第二步巅峰，正式成为**第三步大能**

### 设定：第三步的意义
- 第一步炼气→问鼎，至窥涅完成**第一次脱胎换骨**，可吸收天地元力。
- 第三步为一生**第二次脱胎换骨**：身体无限扩张，与天地再无隔膜、再无区别。
- 逆天之处在于**融化资质**：第三步大能不再受资质限制，只论悟性。

## 四、三人围杀与反击（第1622-1623章）

王林融合本源之际，三方同时出手：
- **虚神天尊**：与王林为生死之仇，判断此刻不杀日后再无机会，不惜分身崩溃。
- **青衣男子**：本已后退，见状咬牙折返，全身弥漫寒冰。
- **周瑾**：奉天狼族老祖、第三步大能，身后随数万丈血狼。

南云子等人欲阻，被一个温和却不容置疑的声音（「无妨」）生生止住。

### 「定」
王林一指定住星空运转与岁月流逝，并将梦道中三个道果内未消化的**废弃道念**顺指而出。周瑾、青衣男子被彻底定住，唯虚神天尊尚能前行但速度骤降。

### 因果印取本源（第1623章）
王林先至青衣男子身前，真假道令其心神迷茫，随即因果印一按一扣，抓出一股虚幻雾气——即对方的**本源**。雾气数次化寒冰欲脱，终被握住。王林道破法理：「本源亦是因果，掌开为因，掌握为果」「人为因，修为缘，最终凝聚的第三步本源，就是果」，宣布不杀、取其本源、**封印千年**、逐出战场。一字「滚」（平淡出口却如天地崩溃）令青衣男子喷血溃逃。

青衣男子内心：本源被扣去大半，此术闻所未闻，但隐隐知晓**掌尊的「井中捞月」**有相似之力；其为空玄修为，因连年之战加旧伤未愈，实际只能发挥空灵巅峰，故被定身后毫无还手之力，心中不甘「老夫是空玄修为，老夫不服啊」。

### 对战虚神天尊
王林转身走向虚神天尊：「当年之事，今日了断好了。」
- 虚神天尊施**万霞虚神道**：身后裂缝涌出无尽香火之魂，化作万尊模糊巨大雕像与万丈霞光倒压，欲镇压王林入天地轮回、跌落星空深渊；王林下方另生神通漩涡，无数冤魂拉扯其身。上下两漩涡夹万尊雕像，声势骇人。天尊更以紫雾化长枪掷出。
- 王林闭目前行，万尊雕像尽数从其身体透明穿过，无一能阻半步。
- 近身后一记**生死印**（左手为生、右手为死），右掌黑气落于虚空，星空八荒瞬成**死域**，天尊四周星空裂而倒卷，天尊后退数十丈；王林再次抬手一指「定」。

## 五、要点速记

- 王林现有神通序列中，本章明确「因果印」为**此生第五式神通**。
- 六道本源清单：雷、火、因果、生死、真假、杀戮（杀戮本源由清水赠出）。
- 万空骨门为跨界（府界之外、封尊/阴月仙妃家乡）的顶级天地之兆，指向「大尊」之路。
- 战局未完：青衣男子已逐，周瑾被定，虚神天尊被定身待处置。

# 第1624章 三步开弓

## 一、定身术下的连环本源出手

虚神天尊挣扎欲破定身术之力，王林已欺身而至。凭定身术压制，「此刻的王林，如同天道」，不给对方任何反抗机会，连续施展诸道本源：

| 顺序 | 所用之道 | 效果 |
|---|---|---|
| 1 | **雷** | 右手食指化作不灭天雷，融合界内界外所有雷霆之力，一指可杀第三步大能；眉心银光爆开，数万银丝弥漫全身，虚神天尊吐血倒退 |
| 2 | **火** | 拇指按其眉心，灭世火焰扩散全身，更冲入心神灵魂焚烧，内外同焚 |
| 3 | **因果** | 五指狠扣成拳外拽，硬生生抽出一股**本源之气** |
| 4 | **生死** | 左手为生按其胸口令其返老还童，右手落下则青春崩溃，生机死气在体内爆发，七窍流血 |
| — | （虚神天尊咆哮破开定身术，全身修为尽数爆发） | 王林神色如常，右手一指再度「**定**」住 |
| 5 | **真假** | 闭目则天地一切皆假，睁眼则一切成真 |
| 6 | **杀戮** | 手掌如刀，赤红杀戮之芒自天灵斩下，将分身一分为二，化作两团紫色雾气 |

**关键设定**：虚神天尊虽为太古五尊之一、修为无上，但此番为**分身**来此，修为只是刚刚空玄，故雷霆之力可伤他。

## 二、虚神天尊的本质

- 分身被斩开后，雾气如衣服被剥开，露出核心——**一团无形之气**，一片虚幻，修士难以察觉，唯王林在真假道下可见。
- 「虚神」之名的由来：其身体**万古至今始终虚幻**，可以说他的身体就是一团气；这具分身实际上就是本体**呼出的一口气**。
- 定位：太古五尊中修为**不是最高**，却是**最难杀死**的一位。
- 无形之气趁人不觉向后飘散逃离，融入天地，消失于朱雀星外。

## 三、李广弓现世

- 王林闭目一指眉心，金光万丈，**一滴金色血液**自眉心泌出，握于右手；体内随即幻化出**李广弓**，萧杀之气弥漫星空。
- 来历补述：当年**仙人血脉**被逼出后，李广弓连同那支箭已与血液融合为一。金色血液是唤弓的唯一凭据——**「若没有那金色血液，王林无法再次使用」**，血液在手便可凭冥冥感应唤出并射出那一箭。
- 评价：**「这把弓，才是王林此刻最强大的手段」**，弓在手则不畏天地、不畏一切修士。
- 王林闭目张弓，弦上凝出**尖端为环形圆圈的箭**，声音平静：**「这一箭，我要收回昆虚」**。
- 拉弓即致星空崩溃瓦解，数万散于昆虚的修士虽不知朱雀星外之事，仍在同一刹那感到来自灵魂的死亡威胁。

## 四、一箭之威：青衣男子道消

- 青衣男子撕开裂缝遁走，仍被从遥远处**生生逼出**。
- **关键差异**：不比当年虚幻界他只是**投影**而去，这一次是**本尊前来**，一旦死亡便是真正道消。
- 其拼死抵挡的三重手段：
  1. 喷血掐诀，布下生命尽头全部**本源之力**；
  2. 撕开**香火界**，取出全部香火之魂融入血液，化作十万百万层冰封，凝成**堪比修真星的巨大冰块**；
  3. 拍碎眉心**族印**，化作更多之力抗劫。
- 结局：箭一触即崩冰层，穿透而过——肉身碎灭，元神欲逃亦一颤而亡。**这是这场战争交战至今死去的第一个空玄修士。**

## 五、环形波纹横扫昆虚星域

箭成直线而去，箭尖却扩散出一圈圈**环形波纹**，波及整个昆虚。凡被波纹碰触的**界外修士**皆一震而肉身崩溃，界内修士毫发无伤：

- **东部**：数百界外修士追杀几十名油尽灯枯的界内修士，一名中年男子绝望惨笑欲自爆——波纹穿身无伤，身后数百追兵尽数崩溃惨死。
- **南部**：两名**天人衰劫**界外修士狞笑追杀一名浴血青年，波纹回荡，二者轰然崩溃。
- **西部**：一颗沦陷修真星上，界外修士屠杀凡人城池、掳掠各宗有姿色女修欲炼为炉鼎贩卖至界外——波纹扫过，全星界外修士尽化血肉。
- **北部**：数千界外修士化长虹奔赴他域助战，触及波纹，千道长虹崩溃无一活人。
- 同样一幕在昆虚各地同时发生，界外修士死亡数量惊人。

## 六、尾声：虚神天尊的忌惮

昆虚星域与**云海**交接之处，虚神天尊所化无形之气重新凝化人影，满脸阴沉、双目惊恐，直奔前方，心中反复自问：

> 「有那把箭在，谁能杀他？该死的，若无此箭，我最多受伤，但也并非不能将其杀死，只是……只是为什么他要有这把弓箭！」

即：**李广弓是王林压制太古五尊级对手的决定性变量**。

## 七、要点归纳

1. 本章确立王林对**雷、火、因果、生死、真假、杀戮**六道本源的连贯实战运用，其中「真假」是识破虚神天尊无形本体的唯一钥匙。
2. 李广弓的唤出条件被明确：**金色仙血 = 弓与箭的载体与钥匙**。
3. 界战格局转折：**首名空玄级界外修士（青衣男子·本尊）阵亡**，昆虚星域界外势力被一箭近乎清场，王林兑现「收回昆虚」的宣告。
4. 虚神天尊未死，仅分身被毁、气体本体逃向云海方向，埋下后续伏笔。

# 第1624-1625章 一箭灭虚神天尊分身 · 六柄本源之剑

## 一、界外强者的溃退与陨落

- 虚神天尊（界外）对『掌尊』发出诛心之言：当年送出那把弓是**天大的错误**——「有此弓箭，这界内界外，谁能将其奈何」。
- 他宣布退出此战：这具**分身**若能活下来，便融入本尊、就此离去，并打定主意**再也不来界内**。
- 逃亡路线：目标是云海，欲从**云海缺口**离开界内、回到界外。

### 破空一箭
- 就在将入云海之刹那，虚神天尊面色大变猛地转身：身后星空轰鸣崩溃，一支箭**直接破开星空而出**。
- 速度与气势皆到了「根本无法闪躲、避开、抵抗」的程度，箭自其身体上呼啸而过。
- 结果：分身**身体崩溃、气息瓦解、烟消云散**。

### 界外本体的反噬
- 分身死亡刹那，界外**太古星辰**内一处被无边雾气弥漫的星域传出凄厉惨叫。
- 弥漫整片星域的雾气急速收缩，化作人影——即虚神天尊**本体**。
- 本体喷出一口鲜血、踉跄后退数步，抬头遥望界内，露出**深深的忌惮**。

## 二、战后：昆虚星域·朱雀星外

- 王林睁开双眼，手中之弓消散；那支箭亦自虚无中返回，**融入其右手内的金色血液**中。
- 王林抬手将血液按在眉心，随即直奔上空那尚未消散的**空门漩涡**。
- 此时其**第三步凝聚，还差最后一丝**。

### 旁观者反应
| 人物 | 立场 | 反应 |
|---|---|---|
| 周瑾 | 界外修士，此地唯一未被波纹杀死者 | 身子颤抖不敢动，脑中一片空白、面如死灰：「他居然变的如此强大」 |
| 南云子 | 界内 | 激动不已，认定「这才是封尊，我界内一战的希望」；为万空骨门与那一箭之威所震撼 |
| 司徒南（断臂所化人影） | 随王林一方 | 大笑，望着漩涡内的王林，眼露兴奋 |
| 朱雀星数千界内修士 | 界内 | 先是愣住难以置信，继而齐声呐喊「**封尊荣耀**」 |

- 众修士身后即朱雀星上的**王林雕像**，其抬头望向星空的双目透出「看天地如蝼蚁」的浩然之气。
- 反差：只有王林自己知道，**第三步天劫**将要来临。

## 三、第1625章「往昔宝复」：空门漩涡内的收获

### 1. 修为跃升
- 持续吸收空门之力后，体内**第六道杀戮本源与身体完成最终融合**。
- 融合一瞬，修为自**空灵初期 → 空灵中期**。

### 2. 六柄七寸本源之剑
借空门崩溃后漩涡内的奇异之力，王林把自身本源凝聚成法器（本源之宝），皆为**七寸短剑**：

1. **雷霆之剑** —— 空门之力凝聚、雷霆轰鸣闪电游走而成；即王林第一道雷霆本源本身。对照：如同当年**清水**的杀戮之剑。
2. **火本源之剑** —— 漩涡大量宣泄之力下现出。
3. **因果剑** —— 融合王林**这一生对因果的明悟**，浮于身前，散发柔和之芒。
4. **生死剑** —— 出现时天地震动，黑白二气缭绕。
5. **真假剑** —— 凝出四剑后空门之力已现消散之兆，王林上前一步、双手猛地**撕开**将散的漩涡逼出更多力量，方才凝成。
6. **杀戮剑** —— **并非清水所赠，而是王林自身凝聚**；此剑成形刹那，空门所化漩涡开始不可逆转地消失。

### 3. 关于「空门之力」的设定
- 可让修士**融合本源**，使身体如同凡人筑基般重塑根基；
- 可把**本源凝聚成法器**；
- 隐隐**可以修复法宝**（由其能在本源中凝聚法器推知）；
- 来历与本质王林皆不知晓；
- **极为难得**：修士一生怕是只能经历这一次，一旦消失很可能再无机会。

### 4. 收尾：定
- 漩涡将要消散的刹那，王林以**第三步空灵中期**修为，右手一指漩涡，施展**定身术**，平静低喝一声「**定**」。

## 四、悬念
- 轰开空门后引来的**第三步天劫**，将是王林前半生所遇天劫中**最强的一次**；王林毫无敬畏，平静迎之。

## 关键转折点
- 界外顶尖战力（虚神天尊）分身被一箭抹杀、本体重伤退避 → 界内士气逆转，「封尊」之名坐实。
- 王林由空灵初期入空灵中期，并一次性获得六柄本源之剑，战力体系完成质变。
- 天劫将至，为下一阶段冲突埋线。

# 王林定住空门漩涡·以空门之力修复诸宝

## 一、定身术的第三步之变
- 王林修为入第三步后，已明悟**定身术**的本质：不再只能定住人身，而是**天地万物、一切运转皆可一字定住**。
- 空门为古往今来修士共同敬畏之物，**当年的封尊亦对其存敬畏**；世间唯王林一人敢对空门漩涡施展定身术。
- 心境根源：**梦道之后**，王林具当代**大儒**气势，明悟天地道理，看天地众生如蝼蚁——文中特别注明「这不是傲，而是一种平等」，存在的与不存在的全无区别。故其再无敬畏，只余平静如水的目光。

## 二、强取空门之力
- 「一字定天」，巨大漩涡轰然一顿，但**仅定住刹那**便现崩溃之兆，可见定身术虽强却非万能。
- 王林踏入漩涡深处，右手一挥化作狂猛**吸撤之力**，将本不属于他、本不会散出的**无尽空门之力**硬生生吸出无数。漩涡传出更剧烈的轰鸣，似愤怒咆哮、含不满之意。

## 三、试验：空门之力能否修复法宝
### 射神车 → 器灵七彩蝶
- **射神车**：雨仙界玄宝所制，命名为「射神」，威力无穷，王林早年赖其渡过诸多危机；**直至毁灭也未完全打开最后的封印**。
- 毁灭时点：**早年在云海，王林与水道子的第一战**中崩溃；此宝曾令水道子大吃一惊，甚至将水道子所伤。
- 王林取出其崩溃所化光点，欲验证空门之力能否修复法宝——若能，他有太多法宝可望恢复。
- 过程：光点吸收涌来的空门之力 → 光芒明亮 → 数息间结成**茧**，光芒柔和 → 空门之力几乎耗尽时茧现裂缝碎开 → 飞出一只**七彩斑斓的蝴蝶**，落七彩之粉，绕王林舞动，透出喜悦与依恋，最终停在其肩。
- 结论：**此蝶即射神车之灵**。王林长笑，浮现与射神车的往昔经历，不想还有再见此蝶之日。

### 青光盾 → 完全恢复
- **青光盾**：王林早年所获至宝，**当年在妖灵之地爆发其最强之威**，令**天运子**、**古魔**等人无不骇然。
- 其最强处不在防御，而在盾内蕴含的一式神通——**梦回远古**。
- 修复取材不足，王林一抓祭出**六把本源之剑**（本源所化法器，每击皆第三步大能全力）冲击漩涡深处，搅乱漩涡后**以吞魂（香魂）本性张口猛吸**，再取出大量空门之力，青光盾终**完全恢复成型**。
- 王林预判：融合第三步空门之力、以其此刻修为施展，青光盾威力将惊天，并为他添**一式绝强保命神通**。

### 古神庇佑护腕 → 完整如初
- 王林取出**古神庇佑的护腕碎片**，吸收其余空门之力后，护腕亦一次性恢复完整。

## 四、漩涡崩溃与「第一个灵」的意志
- 王林握拳猛击漩涡深处，漩涡骤然崩溃。
- 崩溃刹那，一股**无法形容的意志**扩散而出，**无人可以察觉，唯独王林**能感。
- 该意志之强惊天：感觉上仿佛是**天地初开所诞生的第一个灵**，界内界外星空皆似自其中繁衍而出。
- 换作从前王林必骇然逼退，此刻却爆发**一代大儒的浩然之气**——视天地为蝼蚁，岂能输给这股意志。
- 王林发声：**「今日借你空门之力，日后王某定有所报」**；同时其**心神内的天逆珠**突然动了起来。

## 五、要点提炼
- 本片段确立新设定：**空门之力可修复（乃至重生）已毁法宝**——为王林后续恢复大量旧宝埋线。
- 器物线索回收：射神车器灵归位、青光盾（梦回远古）复原、古神护腕复原。
- 伏笔：空门深处的「第一个灵」级意志 + 天逆珠异动 + 王林许下的「日后必报」之诺。
