# 第1723章 天道！（第一更）

## 一、核心揭示：天道 = 天运子

王林在天运子第九十余次轮回的尽头，看到了天运子的**第一次觉醒**，并由此确认：被无数人苦寻至今的「天道」，竟然就是天运子本人。面对那个扯动脸皮、试图露出微笑的青年，王林心神如怒海孤舟，震撼久久难平。青年含笑转身、走向寂静星空，直至身影消失、星空模糊崩溃。

## 二、天道起源（轮回中所见的远古画面）

### 1. 齐天巨门崩裂
- 第二次觉醒的画面崩溃后，出现一扇**与星空齐高的巨门**，站其前如蝼蚁。
- 与天逆内当年那扇门不同：此门**不散发任何威严气息**，似与星空融为一体。
- 门内传出轰鸣，被一股不可思议的力量**自内部轰击**，中间裂开一道无尽延伸的裂缝，最终彻底裂作数份向四周横扫、直奔星空深处。

### 2. 门板 → 昆虚星域的空间裂缝 → 域外战场
- 一份门板穿梭星空，落入**日后被称为「昆虚」的星域**的空旷区域，爆散为无数碎片融入并撕裂虚空。
- 该星域因此不稳，被生生撕开一道**万古不变的空间裂缝**，门板碎片就存于其中。
- 多年后，一群**界外的四圣宗修士**以特殊方法来临，寻来一颗修真星挪移而至，**掩盖了星域不稳与空间裂缝，并将裂缝与这颗修真星连接**。
- 四圣宗修士后因种种事情渐渐离去；岁月流逝中裂缝时而显露，被星上天资惊人之辈发现并加以利用，遂得名 **「域外战场」**。

### 3. 雾气与「本王不服」
- 巨门崩裂之际，一团**如球的磅礴雾气**自门内撞出，雾内隐有人影。
- 人影震惊嘶吼：**「天道…你居然得到了一个天道…该死的，本王不服」**，末了化作凄厉嘶音，雾内传出滔天轰鸣。
- 雾气被自内大力撕扯，**分裂为一大一小两团**：
  - **大团**：裹着虚弱嘶吼的身影向远处倒卷，刹那消失于星空，不知去向。
  - **小团**：朝反方向一闪而逝。

### 4. 半个逆罗盘与灵智的诞生
- 小团雾气疾驰中不断蠕动收缩，其核心是一个**半圆碎片**——其上有古老符文印记，形如**半个罗盘**（或说某罗盘的一半）。
- 雾气最终尽数凝于碎片，化作**无色长虹**飞入一颗**无任何生命、只有低矮秃山**的修真星；碎片如流星砸山，秃山化颗粒崩溃，碎片穿透并**沉入该修真星最深处**。
- 不知多少岁月后（该星仍未诞生生命），半个罗盘上渐渐弥漫出**当年的雾气**，凝成一个模糊身影，最终化作一名**闭目青年**，双脚漂浮于罗盘之上。
- 青年睁眼迷茫自语：**「我有了灵智…我记得被主人召唤，吞噬那个仙人后，那仙人自爆神识，阻止我的吞噬…然后我被分裂开来…我是谁」**。
- 沉思后恍然：**「我是天道…我本不会有灵智，但那仙人的神识自爆，仍然还是被我吸收了一些…我产生了思绪」**。
- 青年低头看向身下罗盘：**「我的本尊，就是这半个逆罗盘，此物的气息无人可以感受到，放在这里，才是最安全的」**，随后身影前漂，消失于修真星内部。

## 三、连道非（疯子）之谜的解答

王林由此想通七彩道人幻境中所见的连道非——神色邪异、言辞嚣张、喜霸占看中修士道侣——为何与自己认识的「疯子」判若两人：

- 连道非本是**仙罡大陆上飞扬跋扈之人**，或许真有一个身份极高的哥哥，助长其性格诡异与嚣张。
- 其一生看中之物（法宝或人）必抢，抢不走则想尽办法、甚至灭对方满门，只为内心贪念；正因这贪念与性格，他才会前往**七彩仙尊洞府**试图强取所需之物。
- 他被天道吞噬后**自爆神识**，性格中**几乎大半的贪念与劣性被分离出的天道吸收**。
- 因此王林遇到的「疯子」才与当年的连道非完全不同——否则以其本性，绝不会赠予**仙人血脉**、传授神通，只会第一时间对王林不择手段。王林明言：相比之下，他更喜欢现在的疯子。

## 四、同一时间：召河星域的分身危局

- 王林**分身**盘膝于星空，面色苍白、隐现青色。
- 无数**天运子分身之魂**如烟丝直奔而来，逐一融入分身体内、不断占据其身。
- **召河、昆虚两大星域的一千多天运子之魂已全部融入**；**罗天、云海**方向的魂亦呼啸卷动、越来越近。
- 天运子阴森之声在分身脑海回旋：**「你拿什么和老夫比快，老夫现在就可以占据你的身体，你的本尊，可找到了老夫的本尊么」**。

## 五、结局：轮回终结与出手

- 王林牢牢记住半个罗盘所在与那颗**修真星的气息**后闭目，轮回随之无声崩溃——**天运子的九十多次轮回至此完全结束**。
- 睁眼后，他看到**蓝梦道尊、青霖、红衫子**，看到召河星域，感受到分身**只差一丝就要被完全占据**。
- 王林起身抱拳：**「我找到了他的本尊，三位前辈不需与我同去，还请你们帮我控制分身，为我争取更多的时间」**，猛然转身向星空一步迈去。
- 收束语：**「天运子，游戏要结束了」**
