# 第八卷 联盟隐秘 · 第1121章 无后顾之忧（第二更）

## 一、青霖的处境与承诺

- **伤势与纠缠**：青霖自述当年伤势严重，此后与贝罗塔珈一战被塔珈入体，纠缠至今。此刻虽非油尽灯枯，但必须闭关疗伤。
- **昆虚星域近况**：青霖已从王林师兄王巍处了解昆虚星域现状——「一团混乱」。
- **雨界归属**：雨之新界从此为青霖一脉之地，**雨界大门封印已然开启，此后再无任何人可以进来**。青霖邀王林将亲友接来雨界修生养息，待其修为恢复后「与我一同重现往昔仙界之尊」。
- **符文信物**：青霖挥手化出一道符文融入王林体内，嘱其「回来时，开启此符文」。

## 二、关于古神与一击之力

- 王林问青霖能否抵挡**八星古神王族**，青霖立刻点破所指为**朱雀星上的古神涂司**（涂司在仙界之前便已存在，仙帝青霖知晓合情合理）。
- 青霖称全盛时期未将涂司放在眼里，只因**一些特殊原因**始终不曾去朱雀星一看。
- 现状：**只有一击之力**。即便对涂司，一击之下也要败退——但王林听出弦外之音：此击只能威慑，一旦真用，日后必然危机四伏（只能败敌不能杀敌）。
- 青霖强调「**界外通道开启之日已然不远**」，若不尽快恢复巅峰修为，其封界内将会寂灭；但若王林需要，这一击可为王林施展。

## 三、仙界劫难的线索

- 王林追问当年仙界究竟经历了什么劫难（此疑问在其心中已上千年）。
- 青霖眼中寒光一闪、继而苦涩：「**一切，都是因为通天之门**」，不愿再说。
- 王林提及在青霖洞府内见到**符文族圣祖**，青霖只反问「你信她的话么」，并叹「**界外与封界之争，持续了太久**，这一切，你以后会全部知晓」。

## 四、避天棺（本章最重要的信息收获）

王林虚空一抓开出裂缝，取出晶光棺材求证。青霖辨认结果：

| 项 | 内容 |
|---|---|
| 名称 | **避天棺** |
| 来历 | 并非四大仙界之物，**来自远古仙域** |
| 传闻能力 | 可让死人复活（仅为传闻）；若知运转口诀，**复活残魂确可做到** |
| 口诀 | 青霖**不知**；线索指向闪仙界 |
| 最早出处 | 最早出现在**闪仙界**，是**仙帝紫霞**之物 |
| 紫霞其人 | 修为当年**仅次于青霖，尚在白凡之上**；闪界崩溃后或存活、或留有道统 |

- 王林一度面色苍白（连仙帝都不知口诀），又因紫霞线索重燃希望。
- 青霖补充承诺：即便寻不到紫霞也无妨，「为师修为恢复后，定会帮你」。
- **动机披露**：王林救青霖的三重目的——解司徒南之毒、了周佚之愿、以及**打探此棺信息**。

## 五、王林的决断：无后顾之忧

- 青霖苏醒与新雨界的出现并未解除王林的危机，但让他**没有了后顾之忧**：把亲近之人送入雨界即可。
- 王林明确**不请青霖出手对抗拓森**：青霖只能击败而不能杀死，暂时消危却无实效。「**一切，还是要靠自己**」。
- 王林在世间已无真正亲人，若说有，**唯有周茹一人**——当年在妖灵之地心神随天逆而开、弥漫整个星域时，他曾在昆虚之境内看到周茹。

## 六、昆虚之境传送阵前的冲突

- **地点**：一处外表极为寻常的**蛮荒星**，星上有通往**昆虚之境**的传送阵。此时联盟星域星空空荡，各势力修士几乎尽赴朱雀星。
- **王林的两个目的**：送出朱雀老圣皇的玉简、带走周茹；尽管他不愿面对**木冰眉**。
- **守阵者**：四道气息环绕逼停王林，皆为**窥涅修为**。王林由此判断昆虚之境底蕴之深不弱于联盟星域任何势力。
- **对话升级**：
  1. 王林表明替朱雀老圣皇送玉简 → 对方：「留下玉简，滚」。
  2. 王林要求见木冰眉 → 对方大笑，索要**邀简**；无邀简不得入内。
  3. 王林两次被打断，最终报出名号「就说**王林**来此」→ 对方：「你若有胆，可以自己闯来」。
- **爆发**：王林怒极而笑，一步迈出、右手一挥，**火海充斥天空、烧得一片赤红并如雨般降下**；一指之下虚空扭曲，逼出一名**白衣老者**，随即另外三人也同时幻化而出。
