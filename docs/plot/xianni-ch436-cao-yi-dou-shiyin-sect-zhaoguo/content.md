# 仙逆 第436章 曹一斗

## 一、地点：赵国尸阴宗

- **方位**：赵国极西之地，一片巨大平原。
- **环境**：常年阴寒气息笼罩；更有**九地之气**——元婴期高手也不愿轻触，元婴以下碰之即伤。故修仙者少至此地。
- **防护**：地面有强大阵法笼罩四周，外人不可入。以王林当下修为，一眼看穿阵法结构，破之不难。
- **形制**：王林于阵眼处踏地遁入，出现在地下——密密麻麻的洞穴通道彼此连接，构成迷宫般的宗门。
- **实力分布**：各洞穴中弟子打坐，修为不等，**大都筑基期，结丹不多，元婴罕见**。

## 二、人物：李青平（赵国分宗宗主）

- 修为**元婴后期**，这一代尸阴宗**赵国分宗宗主**，执掌赵国尸阴宗**二百余年**。
- 外貌：约四十许岁，鬓角苍白，相貌颇为英俊（年轻时应是风流俊俏之人）。
- 行事：兢兢业业，极少与外界来往，使赵国尸阴宗在外人眼中更加神秘。
- **动机链**：身后有黑雾尸傀将来要占据其肉身 → 故整日闭关抢时间冲**化神** → 一旦化神，**朱雀星尸阴宗总部**会赐一具上好肉身 → 跃为赵国尸阴宗**核心弟子**、享特权 → 表现良好或可**调往总部**。

## 三、新登场：曹一斗（尸傀元神）

- 形态：李青平身后一团黑雾，延伸出无数触手四散；头部可现两团幽光（此前一贯冷漠平淡，本章化为惊骇恐惧）。
- 修为：**化神中期元神**，无肉身。
- 出身：自称**天运星弥勒宗**弟子，**并非朱雀星之人**。
- 经历：肉身碎灭，花费极大代价从**尸阴宗**购得一具肉身；因在天运星调养所需**仙玉**太高昂，只能退而求其次在**朱雀星**调养——代价是**夺舍时间更漫长**。
- 特长：所修功法**对神识极为敏锐**，故能察觉王林神识扫过；这一点连王林也称『倒也有趣』。
- 感受：王林神识扫过如寒风吹袭，元神不稳、随时可崩溃；此种压迫感只有在宗内面对**长老级别**之人才有。据此判定王林必是**婴变老怪**。

## 四、事件经过

1. 王林身影如鬼魅掠过阴寒平原，看破护宗阵法，自阵眼遁入地下。
2. 神识一扫，整个尸阴宗尽入脑中；对**最中心洞穴**（李青平所在）多留意几眼。
3. 尸傀察觉神识，颤声唤『前辈』求饶；王林以神念问其门派、来历、姓名。
4. 对方答曰**曹一斗**——其小心翼翼之态令王林想起**当年的许立国**。
5. 王林目光一闪，神识化作**无形大手**抓向曹一斗；曹一斗大骇，自李青平身上飘散退避，尖声自陈『句句属实』。
6. 二者间存在**某种奇异联系**，曹一斗惊骇即惊醒李青平；李青平睁眼喝问『谁』。
7. 洞穴虚空波纹一闪，王林现身，冷冷一眼——李青平**元婴被凝固**、全身冰冷透明般再无秘密，冷汗直流。
8. 王林冷淡道『你，闭嘴』，转而看向缩在角落的曹一斗。李青平不敢动，暗忖当年在总部所遇**化神期前辈**亦不及此人万一。

## 五、设定要点

- **九地之气**：赵国极西平原特产异气，元婴以下触之即伤，构成尸阴宗天然屏障。
- **尸阴宗肉身交易**：宗门可对外**出售肉身**供无体元神购置、缓慢夺舍；调养地点档次不同（天运星 > 朱雀星），价格以**仙玉**计，档次低则夺舍耗时长。
- **尸阴宗晋升路径**：分宗宗主修至化神 → 总部赐肉身 → 核心弟子 → 特权 → 可能调入总部。
- **跨星域流动**：天运星（弥勒宗）之修士流落至朱雀星调养，说明星域间有人员往来渠道。

## 六、悬念

- 王林为何专程来赵国尸阴宗、对最中心洞穴格外留意（疑与其寻找李慕婉/尸阴宗旧因果相关，本章未明言）。
- 王林抓向曹一斗的意图未揭晓。
- 首次点出**天运星**与**弥勒宗**，为后续跨星域线索。

# 第436-437章 剧情梳理

## 一、收服曹一斗：百年奴仆换婴变肉身

- **威压立现**：李青平内心狂跳，判断来者是「婴变老怪」，惶恐不安。
- **抓取元神**：王林右手隔空一抓，将躲在角落的曹一斗元神生生抓来。
- **曹一斗自保**：搬出「我现在是尸阴宗的客人」，警告王林若抓他炼制法宝，尸阴宗不会放过。
- **王林回应**：冷笑「谁说我要把你炼制法宝，你，还不配」。曹一斗随即醒悟——婴变老怪犯不上为难一个化神修士，若要化神元神易如反掌，对方专程而来必有他求。

### 交易条款

| 项 | 内容 |
|---|---|
| 王林付出 | 百年之后送曹一斗一具**婴变肉身** |
| 曹一斗付出 | 作王林**百年奴仆** |
| 附加保证 | 曹一斗要求「百年之内保证我不会死」；王林答「只要我不死，你便不会」 |
| 王林承诺 | 不会让他做危险之事 |

### 婴变肉身的价值（曹一斗内心估值）

- 相当于**仙人的躯体**。
- 有之则修为提升至婴变期容易许多；即便升不上去，神通法术威力也会大增。
- 在尸阴宗价格几乎无法想象：以曹一斗的积蓄，寿元充足也需**千年以上积累**，或许才勉强买下半具。
- 结论：他深知对方所图极大，但「富贵险中求」，几乎没有犹豫便咬牙答应，恭敬拜见「主人」。

## 二、真实目的：天运星向导

- 王林说出目的前，**右手虚空一挥将李青平击昏**——他一向谨慎，不想让人知道自己将去天运星。
- 曹一斗自陈**从小在天运星长大**，对天运星极为熟悉，主动猜到王林是要他做向导。
- 协议达成。王林一拍储物袋取出一杆**魂幡**（即当年收了李元封的那杆、他自己制作之物），一抖之下将曹一斗收入其中，随后身形一闪离开洞穴。

## 三、重返当年闭关之地

- 王林并非第一次来，轻车熟路穿过尸阴宗**错综复杂的迷宫洞穴**，向当年闭关之地掠去。
- 一路上无任何尸阴宗弟子发现他，甚至未打坐者也全然不觉有人从身边走过。
- 闭关之地此刻有他人占用：一名**相貌寻常、神色坚定的女修**，正吸收四周墙壁密密麻麻小孔中散出的阴寒之气。
- 王林看她一眼，身子一晃化作**青烟**，钻入墙壁小孔。

### 今昔对比

| | 当年（筑基期） | 此刻（婴变期） |
|---|---|---|
| 进入方式 | 身子无法进入，只能以**神识**探入 | 整个身子化青烟直入 |
| 代价 | 费极大精力，需不断喝**天逆珠子炼化的露水**增长神识，一点点摸索延长 | 轻而易举，速度极快 |
| 结果 | 才勉强进入隐藏巨人之地 | 少顷即达 |

## 四、「救我」与隐藏巨人之地（第437章）

- 尚未探入太深，地下深处传来呼唤——**「救我」**，与当年那声呼唤**一模一样**，直接透入灵魂深处。王林不予理会，径直深入。
- **巨大溶洞**：四周遍布密密麻麻无数小孔，王林所化青烟从其中之一飘入。
- **巨大棺材**：位于溶洞中心，外表极为普通、无任何花纹装饰，却急剧散发磅礴阴寒之气，化作阵阵白气被四周墙壁小孔吸走（即此地阴寒之气的源头，也是尸阴宗弟子修炼所吸之气的来源）。
- **棺材底洞**：棺内空无一物，底部有一圆形大洞，阴寒之气自此散出。「救我」之声也自洞内传出，越发急切，在王林耳边环绕不散。
- **深入受阻**：王林钻入洞中下行，阴寒之气愈深愈烈，化作层层波浪阻其探入，但始终无法侵入他所化青烟之内。
- **门状封锁**：前方渐现一团**淡蓝色阴寒气团**，密密麻麻凝聚成好似门一般的物质，把入口封死。（片段止于此）

## 关键伏笔

1. 「救我」之声与当年完全相同，来源仍未揭示，指向棺材底洞深处的**隐藏巨人之地**。
2. 王林去**天运星**之事被刻意保密（击昏李青平），为后续行程埋线。
3. 婴变肉身的许诺意味着王林有获取/制造婴变肉身的渠道或计划。
4. 魂幡出自王林之手，且是当年收李元封的那一杆，收人如收物。

# 第437-438章 取巨魔族先祖之血 · 万夫候雷吉

## 一、重返尸阴宗地底
- 王林再入尸阴宗地底禁地。当年（体质孱弱时）遇阴寒气团只能以巧劲从旁钻过，稍有不慎便被阴寒之气入体、全身冻僵；如今一撞之下气团轰然崩溃。
- 一路势如破竹，连破由阴寒之气凝结而成的一道道「气门」。破门瞬间，「救我」的呼唤之声愈发清晰。
- 最深处是一个庞大溶洞，王林估算其规模与尸阴宗上方那片巨大平原相差不多；中心一团巨大白雾散出浓浓阴寒之气，占据洞穴约四分之三。白雾内幽光闪烁，紫色藤枝翻滚蠕动，雾气随之愈浓。

## 二、吹散白雾 · 「风动」
- 王林先以口吹散雾，白雾旋即再生。
- 遂取出**仙玉**握于手中，掐诀低吟，喝出「风动」——**筑基期修士即可掌握的低阶法术**，因蕴含仙力而威力非同凡响，狂风化作飓风将全部白雾生生卷扯吸尽，露出真貌。
- 要点：同一法术在仙力加持下威力天差地别，是本段的核心设定展示。

## 三、巨魔族先祖真身
- 一具庞大男尸悬浮半空：皮肤铁青色，光滑如镜面（不似古神那般有粗糙裂纹）；**眉心有一个淡淡的斧子印记，时而闪烁**。
- 王林据此确定：此人正是当年带领巨魔族从星空来到**朱雀星**的**巨魔族先祖**；当年他持巨斧闯入**仙遗族**大本营，直接斩杀三名**九叶术咒师**。
- 体型评估：比王林本尊释放身体后达到的**三星古神**还高大数倍，接近**五六星古神**。
- 身上生机蓬勃，却被某种神奇法术**禁锢至完全静止、不能流动**。

## 四、设定澄清：仙遗族术咒师 ↔ 修真境界对照
| 仙遗族 | 对应境界 |
|---|---|
| 七叶以下 | 不入流（不算） |
| 七叶、八叶术咒师 | 婴变期 |
| 九叶术咒师 | 问鼎初期 |

由此反推：巨魔族先祖能在仙遗族大本营内一举斩杀三名问鼎初期，威猛实属少见。

## 五、紫青色寄生植物
- 紫青色植物遍布巨尸全身，根部如利刺深深刺入体内**抽取生机**，在体内转化后以**阴寒雾气**形式释放；巨人身体随之萎缩→恢复，周而复始。
- 王林踩上巨尸时，植物呲呲作响，大量枝条带血抽出、如蟒蛇昂首指向他；巨人身躯不断抽搐，似极痛苦。
- 王林挥出蕴含仙力的火焰逼退植物，但**刻意不加伤害**——判断植物与巨人体内禁锢关联极深，毁之恐引禁制异变、放出巨人；全程仅捏碎两条藤枝。

## 六、取血过程
1. 仙剑直刺巨尸 → 金属撞击声、火花四溅、被反震退三寸，无法破防。
2. 捏折一条枝条察看，顶端有**绿色粘稠恶臭液体**；将枝条顶部按在巨尸皮肤上，如木头燃烧般冒黑气，枝条轻易深入——随即枝条挣脱王林之手钻入体内消失。
3. 王林取出当年在**仙界**无意所得的**玉瓶**（本身无神奇之处，惟能容纳大量液体，结构类似储物袋），按住伤口挤压滴血，但速度过慢。
4. 改攻颈部大血管：因巨人胸口紫青色植物过密无落脚处，祭出**禁幡**（自得魂幡后久未使用），一抖之下禁气化作黑芒禁制如网，喝「封」，将胸口植物一一封印。
5. 又虚空捏折一段枝条，落于巨人颈部，以枝条点刺——黑印一圈、穿透皮肤直入血管，血箭喷射，尽数收入玉瓶。大量**生机随鲜血消散、融入玉瓶**。

## 七、雷吉的交易与王林的拒绝
- 巨尸持续呼救，逐步加码：先称「我给你巨魔族重宝」，继而「甘愿此生成你**奴仆坐骑**，并送你巨魔族重宝**开天之铁**」。
- 补充设定：**巨魔族之人是修真联盟内那些大神通修士最喜欢的坐骑**。
- 王林不为所动，理由明确：
  - 他已**杀了巨魔族老祖**、**封印巨魔族一次**，先祖若归，第一个就要拿他开刀；
  - 不救自己控制不住之人；
  - 此行目标只是巨人鲜血，不愿多惹事端；
  - 「重宝」为何物对方起初也未说出口。
- 「坐骑」二字曾令王林一怔、手中枝条略停，但仍按下放血。
- 对话收尾：王林问「你是谁」，对方傲然自报——**巨魔族万夫候，雷吉**；王林续问「你为何会被封印在这里」。

## 八、悬念 / 后续线索
- 雷吉被封印的原因（下一段落即将揭示）。
- 「开天之铁」这一巨魔族重宝的下落与用途。
- 巨人鲜血（含蓬勃生机）的用途——王林此行的明确目标物。
- 紫青色植物与禁锢法术的关系、施术者身份未明。

# 第414章 巨魔血、祖藤反噬与红衣童子

## 一、雷吉的来历自述
- 被封印巨人自报姓名【雷吉】，巨魔族修士。
- 当年与【仙遗族】一战后，遭仙遗族两名【十一叶术咒师】追杀，逃出时身负重伤。
- 【尸阴宗】趁其重伤，从某个修真星请动一名大神通修士将其擒获，封印于此洞穴。

## 二、诱惑三连：坐骑 / 开天之铁 / 朱雀星巨魔族
1. **坐骑**：巨魔族轻易不做修士坐骑，一旦为坐骑则终生不叛。其身体与【星罗盘】同类而远强于之，为星空遨游最佳之物，且在修士无法通行之地畅通无阻；修真联盟的大神通修士愿以极大代价求一巨魔族人为坐骑。
2. **开天之铁**：巨魔族重宝，一代先祖遗留，共九十九块，集齐可铸【古神战甲】，穿之可得传说中古神之力，被其称为「超过仙宝之物」；愿告知藏匿之处换取解救。
3. **朱雀星归附**：可令朱雀星上所有巨魔族认王林为主。
4. **退而求其次**：愿赠精华更胜血液的【骨髓液体】，不求获救，只求把消息送到巨魔族或【这一代朱雀子】。

## 三、王林识破拖延
- 破绽：语气焦急却有问必答、条分缕析，不合急切求生者心态，形同刻意为之。
- 判断：对方借抽血时机进行某种变化，抽血时间越长对其越有利。
- 应对：
  - 右手按其颈部，仙力催动，使血液流出量与速度大增（先加速取血）。
  - 收满玉瓶后一点玉瓶抓取，跃身离开巨人身体。
  - 右手一召，将封印紫青色植物的【禁制】化作禁气收回【禁幡】。
  - 明言：救之无益，「留在这里，我随时可以过来取些鲜血，才是最佳」，化青烟原路返回。

## 四、祖藤反噬
- 失去禁制封印后，藤条蠕动，数根钻入巨人颈部伤口。
- 雷吉悔恨：只差半炷香——血液降至不足三分之一即可引出体内【祖藤】，祖藤一出便有办法【元神出窍】。

# 问鼎之上：碎涅三境与阴阳二意

> 场景：司徒南（意识/前辈形态）向王林讲解问鼎之上的境界体系与朱雀子的底细。

## 一、碎涅三境

- **序列**：问鼎 → 阴阳二意（关卡）→ 窥涅 → 净涅 → 碎涅。
- 司徒南原话：「碎涅三境，一境窥涅、二境净涅、三境碎涅，这三境，便是问鼎之后的无上之道。」
- **并非顶峰**：王林问「碎涅三境之后是否已达顶峰」，司徒南摇头——碎涅三境「只不过修仙之旅的第二步罢了」。
- **地位**：碎涅境大圆满修士，在修真联盟内可算一代强者，极少有人敢惹。
- **传闻**：修真联盟的一些老怪，也没有人真正突破碎涅境。

## 二、阴阳二意（问鼎与窥涅之间的两道关卡）

- 问鼎与窥涅之间尚有两关：**阴意**与**阳意**。
- 本质是**意境的变化**，并非「虚幻与实质」的区别，而是一种更高的体会；**每个人的道不同**，无法详说。
- 只有意境经历阴阳二意的洗涤，才拥有达到**窥涅初期**的资格。

### 司徒南自身进度
- 进入天逆珠子（夭逆珠子）前：意境摸索到**阴意的边缘**。
- 在珠内数万年：虽无法修炼，但感悟很深，**阴意达到圆满**。
- 下一步：只需意境感悟**阳意洗涤**，便可寻觅一地闭关，冲击**窥涅期**。
- 故司徒南尚未达到窥涅（对王林「你现在达到了窥涅？」的回答是苦笑摇头）。

## 三、封号问鼎与朱雀印

- **朱雀子修为**：问鼎后期。司徒南带着不屑评价：此生怕是没有资格感悟阴阳，更不用提窥涅期。

# 仙宝三阶与仙剑鉴定（司徒南解说）

## 一、修真联盟神通之术
- 修真联盟赐予的**神通之术**与仙宝一样分等级。
- **朱雀印**：一套**低阶神通**，仅此便使朱雀子封号修士实力大范围提升。
- 限制：**只有继承了修星之心后才可施展**。司徒南言，王林若能学会，实力定可大增（可惜受限于修星之心）。

## 二、朱雀诀的由来
- 历代朱雀修炼的**朱雀诀**，是**一代朱雀叶无忧**通过朱雀印**推衍**而出。
- 功效：
  1. 加快修炼速度；
  2. 拥有修星之心后，可**加固与此心的融合**，达到真正的**封号问鼎**实力。

## 三、仙宝等级体系（核心设定）
- 定义：仙宝＝以**仙力**施展的宝物。
- 分阶：**低阶 / 中阶 / 高阶**。
- 其上：传闻还有一类宝物，**只有碎涅期修士方可使用**，强大无比。司徒南**怀疑天逆珠子即属此类**。
- 炼制现状：
  - 低阶仙宝——尚有一些修士可炼制；
  - **中阶以上——根本无法炼制**，现存全部为**当年仙界的遗留之物**。
- 稀有度：绝大部分修士手中为低阶；中阶极为少见，**足以引起一场战争**；高阶更是少之又少，司徒南游历诸多修真星从未见过。

## 四、魂技（中阶仙宝的门槛）
- 仙宝一旦达到中阶，便有**魂技**。
- **魂技非修士之魂魄**，而是一种**独特的使用方式**；不掌握此法，便不可能发挥全部威力。
- 王林对仙剑魂技：**有线索，却无法找到**；被追问时以“往事，不提也罢”回避。

## 五、仙剑鉴定
- 王林一拍储物袋取出仙剑交司徒南查看（体现对其**极为信任**）。
- 司徒南以仙力催动，剑芒滔天，威力**比在王林手中强大无数倍**；随手一挥，虚空炸响后裂开一条望不到边际的巨大裂缝，寒风呼啸而出，大地几成冰洋。
- 鉴定结论：
  - 此剑为**中阶仙宝**（王林原以为是高阶，眉头微皱）；
  - **剑魂无法与剑彻底融合**，威力受限；
  - 挥舞时有**残缺感**——此剑应是**四把**，**四把合一**后可成极其少见的**高阶仙宝**。
- 来历：王林称“**仙界，故人之物**”，并明言“此剑不是我的”。
- 插曲：司徒南索要此剑，王林反问是否认真，司徒南叹气归还——“若是别人，老子直接抢走，你的东西，我这张老脸还真有些不好意思。”

## 六、旁证与人物侧写
- 王林由此忆及**当年仙界之行**：**剑尊凌天候**与几个老怪为夺仙剑疯狂抢夺，其修为**绝对超过问鼎**，反证仙剑之珍贵。
