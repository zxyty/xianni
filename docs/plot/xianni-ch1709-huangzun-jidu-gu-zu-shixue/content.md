# 第1709章 皇尊的嫉妒！

## 一、背景：古国三脉对古祖的绝对敬畏

- 仙罡大陆古国三脉之修，生存于三个大天尊的庇护、三个皇尊的统治与祖先光芒之下。
- 他们自出生起便被灌输对古祖的狂热敬仰——**古祖即古国之修的“天”**，再狂妄之人也不敢有半点不敬。
- 连玄罗大天尊亦是如此。**古往今来，从没有一人迈出王林这一步。**

## 二、王林逆冲漩涡，与冥冥古祖“谈条件”

- 得四滴苍穹血后王林并不满足：所谓“认可”，实质是古祖认同一人为后人、赐予其血脉，而**这种血脉王林并非必须获得**。
- **退路**：他可从**疯子**处获得**仙人血脉**（与古之血脉等同的存在），逼出体内四滴鲜血、放弃古族身份，转修**仙人不灭体**成为仙人。
- 于是他身影如长虹冲向将散的漩涡，低吼：
  - “你认可了我，但我还没有认可你，想要我认可这个血脉，你需要给我更多的血液与造化。”
  - “让我王林认可的血脉，王某一生都不会叛弃，但你以四滴鲜血就想让我接受，这未免太廉价了一些。”

### 排斥与举证

- 漩涡内涌出一股**沧桑、无情绪、如同死物**的神识气息，将王林笼罩并排斥在外。
- 王林右手一指点眉心，指尖凝乳白光芒，挥手幻化出**自身记忆画幕**为凭：
  1. 结丹期的黑衣青年，身处**朱雀星·古神之地**，历经种种最终获**涂司**记忆传承；
  2. 一生所获古神传承的全部经历；
  3. 直至最后——**太古星辰内的道古墓地**。
- 王林冰冷放话：“你既冥冥有灵，那便思索一下，让我选择接受你的血脉，需要多少鲜血；亦或者你将我毁灭，我放弃古族血脉，成为仙人。”
- 话毕，神识气息一卷退回漩涡。**沉默良久后，本欲消散的漩涡重新旋转、由虚转实，血光再度扩散。**

## 三、浮空城：从第五滴到第十滴

场景切至道古一脉漂浮天空的城池，近百万道吉族人围观，皇袍男子内心已不耐。

| 滴数 | 反应 |
|---|---|
| 第五滴 | 撑天雕像眉心暗淡血光骤爆红芒映照天地，第五滴飞出，掀起滔天巨浪；皇袍男子略松口气，暗道“我当年获六滴才成皇尊” |
| 第六滴 | 血光再起，**追平皇尊当年**，众呼“我道古一族的大幸” |
| 第七滴 | 皇袍男子面色紫青 |
| 第八滴 | **追平玄罗大天尊当年**；玄罗大天尊仰天大笑 |
| 第九滴 | 玄罗大天尊双眼喜悦之芒尽显；皇袍男子面色铁青、嫉妒近乎失控 |
| 第十滴 | 四周血光从八方被吸尽凝于眉心，化作**紫色**一滴——**古祖魂血** |

### 魂血之重

- 古往今来**从未有人得第十滴**；众修惊呼“岂不是说明此人才是真正的道古皇尊”“即便皇族也从未获得过十滴”。
- 皇袍男子退后数步，失态惊呼：“古祖魂血……这不可能！”
- 玄罗大天尊首次真正动容——第九滴未使其震惊，紫色魂血却使其震撼，并道出设定：
  > **自古至今只有九滴魂血出现，每三滴魂血造就古之一脉，九滴魂血便有了如今的吉（古）之三脉。**

## 四、封锁与嫉妒

- **封口令**：玄罗大天尊右手指天，凭空造出巨大红色太阳笼罩天地，以**玄阳之力**封锁此地气息，令道古一脉子民不得泄露半点，**违者不论身份，死**。说罢回头大有深意地扫了皇袍男子一眼：“你听到了么。”皇袍男子低头称“是”，内心嫉妒达到崩溃巅峰。
- **皇尊的嫉妒**（本章题眼）：皇袍男子暗恨“**烨寞的传承者**，怎么可能获得古祖如此认可程度、赐予八滴鲜血？我才是古祖真正的后人，我才是皇族血脉，我才是除了族叔外的古之天骄”。
- **笑里藏刀**：他压下嫉妒，抱拳笑贺——“恭喜族叔，看来此子日后必定成为族叔唯一弟子了，甚至说不定还会超越族叔，成为我道古一族新的大天尊。”话语看似恭维，实则暗藏凶险，神情却天衣无缝。黑发青年（玄罗大天尊）神色如常，只转身大有深意地扫他一眼——此一眼令皇袍男子心神一颤。

## 五、章末走向

- 玄罗大天尊抬头望向仙罡大陆远处**仙族占据的区域**，喃喃：“**我要去一趟仙族之地，把这孩子接回来。**”
- 章末为作者求月票与盟主鸣谢（非情节内容）。

## 六、关键设定沉淀

1. **古脉苍穹血**：古祖赐予认可者的血脉，历来一次送出即止；滴数=认可程度，六滴造就皇尊，八滴为玄罗大天尊当年之数。
2. **古祖魂血**：紫色，层级远高于普通苍穹血；史上仅九滴，每三滴成就一脉，构成古之三脉。
3. **两条血脉路线并立**：古之血脉（古族）与仙人血脉（仙族·仙人不灭体）等同，王林两路皆可选——这是他敢于要挟古祖的底气。

> 归属说明：据世界状态须知，王林自第1380章起以「烨寞（道古烨寞）」之名/身行事，属借势代入化身；本章道古皇尊口中的「烨寞的传承者」即指王林。「涂司」已于第168章死亡，本章仅为王林记忆画面中的传承回溯。
