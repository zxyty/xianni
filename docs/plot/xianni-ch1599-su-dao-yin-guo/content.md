# 第1599章 苏道

## 场景：六月苏城·画舫买醉

- 时节为六月，苏城百花盛开，柳絮漫天如夏日飞雪，河岸桃花点点落水随波。
- 王林以白衣青年之身立于画舫船头，左手酒壶，右手接住一缕柳絮，吟「夫天地者，万物之逆旅也；光阴者，百代之过客也。而浮生若梦，为欢几何」，饮尽后又笑吟「癫狂柳絮随风舞，轻薄桃花逐水流」。
- 柳絮意象贯穿全章：无根、随风、不知归处，与王林此刻的迷茫互文。
- 随行者：书童装束的中年男子**大福**（管钱，苦着脸），另有船家与三名女子（一人抚琴、二人歌舞）。

## 大福的抱怨（钱与凡俗）

- 一壶桂花酒七钱银子，「喝一口差不多半钱」。
- 私藏的钱已尽数取出，照此花销「再有七天就要去要饭」。
- 已在此逗留一个多月，反复追问王林到底在等谁。
- 王林答：「急什么，我要等的人，还没有来。」

## 琴音：悲魂之音

- 王林嫌琴女弹得「不对」，醉意中亲自上前抚琴，凭「梦中听过」的无名曲子弹奏。
- 起初生涩断续，心神融入后曲音连贯，一股极淡却直入灵魂的悲哀弥散全船。
- 二舞姬茫然、琴女迷失、大福忘却心痛，呆望自己右手腕出神。
- **关键设定**：此琴音是李慕婉当年所弹的神韵；同样的神韵也曾出现在妖灵之地的盲女手中——不同曲子，一样神韵。
- 王林闭目落泪，泪滴琴弦，随琴音飘散。
- 每夜入梦，梦中所见极多，但有几人始终模糊不清，模糊之中的悲哀感却极深。

## 桥上二老：苏道与监官老者

- 画舫穿过一座座石桥，黄昏入夜后，一座石桥上立着两位白发老者。
- 青衫者身直如青松、神色沧桑、双眼睿智，一股当代文豪大儒气息——即**苏道**。
- 身后老者为苏道学生，即当初考场上始终盯着王林考卷的**监官老者**（苏道唤其「苏三」）。他因觉王林考卷不凡，且日前见其游船，遂请恩师前来一见。
- 苏道评价：「好一曲悲魂之音……在那悲哀中，透出万古沧桑，如同经历了无数岁月后，回头看去，那记忆内的某个悲哀的画面，始终弥漫在心。苏三，这一趟，老夫没有白来。」

## 核心问答：因果

- 苏道按桥栏向下喊问：「少年人，告诉老夫，你觉得因果，是什么。」
- 此时夜色笼罩、明月当空，老者身影与桥四周皆在月光下朦胧模糊；王林所处角度只能看到苏道一人，看不到桥另一端的第二位老者。
- 王林的迷茫独白：
  - 「不应该是这样……若这一切是时光倒卷，若这一切是一场轮回，若这一切是一场梦，那么我应该遇到的，是那梦中的我……可为什么如今，我遇到的，却是这个老人？」
  - 他等了一个多月，等的正是梦中所见「另一个自己」在苏城河水上、石桥上出现的那一幕——那个梦曾让他醒来后茫然一整天、喝了一整天酒。
  - 「我知道炼魂宗的事情，甚至那炼魂宗数百年后出现的人，我隐隐能猜到，那是梦中的我。可是，这一切原本已经被我明悟，但为什么我在这里没有看到他？」
  - 随着迷茫加深，「就连他自己此刻都是越来越模糊了」。
- 苏道再问一次后，王林徐徐作答：**「因果……我是因，我是果。」** 声音随画舫远去而消散。

## 收尾

- 苏道含笑目送画舫消失，回头问学生：「他叫什么名字？」

## 要点与伏笔

1. 「时光倒卷/轮回/梦」三重假设并列，指向本卷「虚幻与真实」母题。
2. 梦中的「另一个自己」与炼魂宗数百年后出现之人被王林指认为同一存在，是本章最重要的线索。
3. 李慕婉琴韵 → 妖灵之地盲女 → 苏城画舫琴曲，三处神韵同源，是贯穿全书的悲哀锚点。
4. 王林入凡俗科场（考卷被监官老者注意）为本章前情，苏道之问由此而来。
5. 「我是因，我是果」是王林对因果的自定义，可视为其逆天道途的自证。
