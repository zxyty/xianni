# 第1449章 墓台之秘

## 一、定身术终结战局

- **定身术的原则**：一指定身伴随王林一千多年，每每出手皆有奇效。其要诀是「用在最关键之处、不能提前施展让人提防、必须一次就成」，方为出其不意的杀手锏。
- **计算与时机**：王林作战原则是「以最小的代价，换取最大的胜利」。他刻意先让灵动上人重伤到极限，再在最关键时刻取走玉简、施展定身术，给予致命重创。文中点明：若提前收走玉简，灵动上人伤势不至如此，说不定还有脱困可能。
- **效果**：灵动上人本已重伤濒死，身体骤震，红雾轰轰卷动封死最后一丝缺口，将其吞入雾中。王林双手掐诀打出无数禁制落于红雾，其内咆哮与虚弱怒吼不断，许久方息。

## 二、借刀与封锁

- **借道灵之力**：王林判断被禁制封印的那道灵极为强悍，「让它与重伤的灵动去拼，对我才是最有好处之事」——若灵动未伤，道灵未必是对手，交战难免损伤。眼下局面完全符合他的计算。
- **三重封锁**：
  1. 右目雷霆一动，**雷图**幻化飘于千丈雾气上方，闪电连接成网；
  2. 左眼火焰汹汹而出，环绕雾气形成火海，与雷霆融合严密封锁；
  3. 眉心古神星点旋转，放出**天皇炉**笼罩千丈雾气，掐诀打出印记开始炼化。
- **天皇炉定性**：古神王族法器，防御强悍，更重「炼」之一字——**不炼丹、不炼宝，炼的是古奴（古神之奴）**。

## 三、两片古息叶

- 王林直奔被封印在一起的两片古息叶，虚空一挥取来。
- 灵动上人亦得到一片古息叶，来历不明。王林神识轰出、蕴含古神之力，一卷冲散灵动的神识——「此物毕竟属于古之一族，外人根本不可能真正掌握」。
- 王林在叶上留下自己的古神气息后慎重收起。**此宝作用极大，某些时候可与定身术相比。**

## 四、墓台之秘（本章核心）

### 1. 二阶墓台的构造
- 墓台悬于半空，**两千丈大小、暗红色似血**；灵动上人此前曾称之为「二阶墓台」。
- 表面暗红之下刻有诸多行文，王林一眼看破：**它们正是进入此地修士眉心幻化的数字标示**。修士死亡、肉身崩溃后，眉心数字标示不会消散，而是化作符文漂浮于天地。
- 王林清点：台上已有 **589 个**符文印记。

### 2. 进阶过程
- 封印之地此前已死十多名修士，其符文未被红雾风暴毁灭；灵动上人与中年文士急于夺宝，也无暇收取。
- 王林大袖横扫收来这十多个符文，逐一挥向身下平台融合。**第十一个符文融入后**，平台轰然剧震。
- 四周无数尘埃急涌融入，更有尘埃破开虚无自无尽之地冲入封印之地。平台依次扩至 **2300丈 → 2500丈 → 2800丈 → 3000丈** 方止震动；颜色由暗红转为**紫色**，浮于半空如一小块大陆。

### 3. 传承：地图与「火道封地」
- 达三千丈刹那，一股神识气息自石台弥漫，顺双脚入体，化作一幕幕画面与王林记忆**极快融合，不给任何反应机会**，成为自身一部分。
- 闭目所见为一幅**地图**：绝大部分被黑雾笼罩，唯有**三块相连之地**黑雾消散，合占整幅地图近**三成**范围。
- 王林在图上找到自身位置，此地名为「**火道封地**」；这三块相连区域中共有**三处**这样的封地。
- 图上隐隐显出一条**深入古之墓地深处的路线**。

### 4. 墓台的第二重异象：裂缝
- 睁眼瞬间，王林发现封印之地存在**无数细密裂缝**，如伤口般忽张忽合，极为诡异。
- **离开墓台，裂缝立刻从眼中生生抹去；退回墓台，裂缝再度出现。**
- 王林沉默不得其解，但隐隐明悟：**在这古之墓地，墓台或许是一切的关键。**
- 他判断墓台「眼下应该是达到了三阶」，若阶位更高，或许地图可全部展开，墓台还会显现其他神通。

## 五、炼化红雾、逼出火道灵

- 天皇炉内雷火交加、古神气息弥漫，雾气已由千丈缩至八百余丈并持续收缩。
- 王林于炉外盘膝而坐，掐诀打出禁制穿透天皇炉、直印雾气。文中点明：**王林所拥有的禁制，除古魂禁外其余全部擅长**。变换削弱之下，半个时辰后雾气仅余**百丈**，露出下方**古神驮着的千丈平台**。
- 王林挥出得自中年文士的**三枚玉简**，透过天皇炉印在百丈雾气上，雾气一顿、停止蠕动。
- 王林双手按炉，古神之力疯狂涌出，炉内凄厉之声骤起，**无数魂魄幻化成两只大手**冲入雾内狠狠撕开。

## 六、结局：不杀灵动，炼作古奴

- 雾团撕开，**四品火道灵**（形似麒麟）怒吼冲出，似能察觉王林般直奔其方向，撞在天皇炉上倒卷而回。其满身伤痕、神采萎靡，可见在雾内与灵动上人交战艰辛，但凶光不减，后退中不断低吼。
- 其身后躺着血肉模糊的**灵动上人**。天皇炉是王林之物，灵动在其中无所遁形——王林一眼看出他并未死亡，而是元神收缩体内、装死疗伤。
- 王林掐诀一指天皇炉，炉内浑浊翻卷，火道灵不知去向，只余灵动上人。
- 王林冷声：「不用装死，我也没打算杀你，相比一个死去的灵动，我更想要一个**第三步古奴**。」
- 眉心**六个古神星点**旋转，古神之力疯狂涌入天皇炉，**残酷的炼奴**就此展开。
