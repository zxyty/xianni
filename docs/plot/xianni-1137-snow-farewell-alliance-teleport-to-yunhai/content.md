# 第九卷 云海之巅 第1137章 雪

## 一、雪夜辞乡（联盟星域·废弃星）

- 场景：联盟星域一颗废弃星，并非蛮荒，尚有不少凡人城池；因修士罕至而一派祥和。时值寒冬大雪，恰逢一个渊源已被遗忘、习俗却传承至今的重大节日，家家灯火。
- 王林一身白衣白发，单衣薄鞋、不畏严寒，独自踏雪穿过平原，脚印随落雪填平、痕迹尽消。
- 至一处四望无起伏的平原：「就是此地了。」右脚一踏，方圆千丈积雪冲天散去，露出一座复杂磅礴的阵法，多处以碎石压位。

## 二、传送阵的开启（以魂为引）

1. **补阵**：虚空一抓开启储物裂缝，取出一路寻来的数百块石块，挥手令其各归其位，补齐阵法。
2. **起阵**：阵法光芒弥漫、缓缓运转，落雪未近即被阵力推回升空。
3. **祭引**：盘膝坐地，自储物裂缝取出一枚**双目紧闭、已然昏迷的元神**；左手掐诀在其上连点数下，元神每次颤抖，随后被甩出，身形被无限拉长扭曲，旋成一个呼啸的漩涡，其内凄厉之声回荡。
4. **贯通**：阵法彻底开启，极亮光芒不冲天而是尽数灌入漩涡；王林双手掐诀轻声道：「**以魂为引**」。漩涡血光闪烁、砰砰如被打通。
5. **代价**：话落刹那，阵法被抽尽全力，咔咔崩溃化为碎末，压阵碎石亦成灰——一次性消耗。
6. **离去**：漩涡停旋，内里一片漆黑如通道。王林起身踏入，回望银色大地——此地虽陌生，呼吸的却是**联盟星域**的空气，有家的味道、朋友的气息、他的不舍与故事。

> 「这一走，不知何时还能回来……或许，永远也回不来了……所幸，我走时有雪相送，有风陪伴，足矣。」

长笑转身，没入漩涡深处。平原上漩涡消散，千丈空地重被雪填满，如同他一路走来的脚印，痕迹全无。

## 三、设定交代：风云雷电四大仙界之别

| 仙界 | 对应星域 | 体系特点 |
| --- | --- | --- |
| 雨界 | 联盟（联盟星域） | 以**一至九级修真国**为独特；制度森严 |
| 雷界 | 罗天（罗天星域） | 以**上古、远古等修真家族**为存在；风气自由，但面对家族荣誉可全部放弃自由——**荣耀胜于一切** |
| 风界 | 云海（云海星域） | 与雨雷两界截然不同；四大仙界中占据星域**最为广阔**，大于罗天星域 |

体系不同 → 修炼方式、主修方向乃至修士性格都大不相同。

## 四、云海星域格局

- **星雾**：整个云海绝大范围被薄薄星雾弥漫，星空看去如一片雾海，故名「云海」。神识在其中受阻；无人知其由来，据说远古仙域尚未消失时便已存在。
- **迷失风险**：没有准确星图，即便大神通修士深入亦会迷失方向、永远被困；**缩地成寸**在星雾干扰下效果甚微。
- **九阶制**：因星雾遮蔽难辨方位，云海不分东南西北，而按雾气浓度由内至外划为**九阶**——九个不规则环形，外围为第一阶，最内为第九阶。
- **修真星稀少**：总数不足一百，绝大部分集中在**七阶以上**；七阶以下最多的是漂浮星空的**大陆**，一片大陆即代表一个宗派。
- **莫罗大陆**：位于**第五阶**，浓雾中若隐若现；大陆中心一座高耸**黑塔**散发柔和之光，笼罩全陆、阻星雾入内并冲散周边雾气，令陆外有一片清明。

## 五、彼端伏笔（莫罗大陆北部）

- 莫罗大陆北部，丛林深处百丈空地上有一处清理布置好的接引阵法，雨水冲刷泥土后纹路清晰。
- 最后一批守护等待的修士已于**三个月前**离开、放弃此阵，但并未毁坏，似仍抱一线希望。
- 雷霆闪照的雨夜，阵法内忽传咔咔之声（被雷鸣压过），蓝色光芒亮起并环绕全阵；雨势骤急、雷霆愈密——一个**不属于云海、日后将在云海崛起并震惊四大仙界**的修士即将现身。

## 六、看点

- 「雪送风陪」的离乡意象，与《仙逆》一贯「痕迹尽消、寂寥前行」的基调呼应。
- 传送代价极大：一次性毁阵 + 以一枚活元神为引，侧写跨仙界星域传送之难。
- 本章完成从**联盟星域（雨界）**到**云海星域（风界）**的空间转场，正式开启第九卷「云海之巅」。
