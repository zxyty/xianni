# 第1843章 突破！

## 一、丹海追杀线：四方战将的末路

- **三人身份**：朱雀战将、白虎战将、玄武战将，即当年从洞府界离开之人。抵达仙罡大陆已多年，见七道宗已然不存，遂离去，来到丹海定居，成为此地散修。
- **心境**：当年曾风光叱咤，如今似人生末路，只剩一身疲惫。以三人修为本可在丹海做出一番大事，却选择沉寂、甘于平淡。
- **树欲静而风不止**：沉寂未换来安宁，如今在暴风雨般的追杀下逃遁。朱雀、玄武二人重伤，白虎伤势较轻，带二人不顾一切逃遁。
- **白虎之誓**：面对二人劝其独走，白虎惨笑低喝——「我岂能独自逃遁」。四人一起进入洞府界，如今青龙已死（其死可以理解），但三人一同出来时说好在此终老、寻三个天资不错的小辈传下道统，尚未做到，「我岂能独活」。
- **追击者**：手持扇子、面白如玉的青年，以及眼中阴毒的钱姓修士。二人追击并不焦急——丹海已被封，三人无论如何逃不出去；这般戏耍反让钱姓修士感觉酣畅。

## 二、绿魔洲女子：罗盘异状与提前投毒

### 罗盘读数
- 白色光点＝丹海内非绿魔洲修士；绿色光点＝绿魔洲一方。此刻绿点已近乎占满，白点不足一千。
- 三个最大的光点已然消失；略次一等的九个光点，先前消失四个，如今再消失两个，只剩三个凝聚一起缓慢移动（即三战将），其后两个醒目绿点疾驰追击（即青年与钱姓修士）。

### 决断
- 女子察觉异常：「这一天中，海水下降了数十丈，比之昨天要扩大了数倍不止」，两天减少太多，横扫一圈却无端倪。
- 原本还剩最后两天，她不再等待，银牙一咬，左手心现出**万净化污液**（一滴黑色液体），向海面弹出。
- 黑色水滴入海即化幽光没入，海面瞬即转黑，如墨般以无法想象的速度扩张蔓延。其判断：「不管这丹海内存在了什么样的端倪，在这万净化污中，也会死亡。」

### 效果
- 数个时辰后丹海海面大半成黑。被触及的天牛洲修士在逃遁中凄厉惨叫、身子颤抖、被腐蚀化作一片血水，元神亦无法逃出、生生消散。
- 成群绿衣修士在黑水中只是速度变慢，并未受伤——毒液具阵营选择性。
- 罗盘上丹海地图近半转黑，黑色所过之处白点尽数消散如被抹去。女子喃喃：「不管是谁在故弄玄虚，我倒要看看，这被污化的丹海，你如何再吸收。」

## 三、王林线：借黑水成就水本源

### 困局
- 两天来王林吸收磅礴海水入体，于体内挤压欲凝水本源，始终未成，遂沉默中加快吸收。

### 转机与瞬移
- 身子蓦然一震，睁眼：「水本源……我感受到了水本源的气息」。
- 一步迈出，脚下波纹回旋，整个人融入天地瞬间消失，再现时已在被黑液弥漫的另外半个丹海。

### 抗毒与吸收
- 黑水中蕴含足以腐蚀一切肉身、直接蚀化元神的恐怖力量；王林判定「这是水本源的另一种威力所在」。
- 因其身体正处**水本源大成的第九次循环**中，抗力远超寻常修士，短时不被腐蚀，且黑水中正含他极度渴求的水本源。
- 盘膝坐下，双手掐诀，全身**三万六千汗毛孔**尽开，疯狂吸收黑色海水。全身刺痛，心神却生舒适之感，如被滋润，第九次循环缓缓推进。

### 反噬绿魔洲
- 罗盘中弥漫的黑色以肉眼可见速度急速散去，女子瞳孔猛缩、右手颤抖、几近倒吸凉气，随即注意到这半片黑海中出现了唯一一个白色光点。
- 先前她已下令「正东九千七百万里外，三十组绿魔卫，去杀此（人）」，话未说完白点骤然消失（因王林瞬移）而被打断；此刻再指：「五十组绿魔卫，去杀此人」，四周数千修士走出一半化作长虹而去。罗盘上代表王林的白点四周涌现大量绿点，缓缓合围。

### 突破
1. 干枯双手迅速饱满、血肉蠕动，头颅与头发不再干桔，恢复浓浓生机；肉身完全恢复。
2. 该半区域海水骤减，片刻后**第九次循环彻底完整**。
3. 体内多出**第八道本源——水本源**。
4. 修为轰然增加，气息扩散，显露其真正修为：**空灵后期**；随即脑海轰鸣，当场**突破**。
5. 气息暴增攀升至**空灵巅峰**，距离**空玄**只差一步。体内翻天覆地、砰砰巨响，双眼露出如水般的晶光。
6. 宣言：「水本源，凝聚我全身血液之内，从此之后，我之血液，便是这天地五行之水本源。」

## 四、要点与伏笔

- 女子的杀招反成王林的燃料：万净化污液的水本源被王林直接吞化，构成本章最大反讽。
- 王林位置已彻底暴露，五十组绿魔卫合围在即，为下一章冲突埋线。
- 三战将（朱雀/白虎/玄武）与青龙的四方战将体系于此处收束：青龙已死，余三人被追杀，传下道统之愿未竟。
- 王林境界序列在此确立：空灵后期 → 空灵巅峰（本章），下一境为空玄。
