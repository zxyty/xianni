# 第1769章 再临古墓！

## 一、融合烨寞左臂
- 冰窟窿内烟丝般气息不绝涌出，钻入王林左臂；剧痛钻心，额头冷汗，神色不变。
- 左手渐变粗糙，复杂符文印记若隐若现；一炷香后最后一缕烟丝融合完毕。
- 得手感如当年获烨寞右手，「可以撕开天地」之感涌现心神。
- **异象**：眉心、双目内古之三族星点剧变，隐现模糊**星漩**——第九星将出之兆。

## 二、撕天破冰池
- 王林隔空双手扣虚空、向两旁一撕，喝「撕天」。
- 冰池巨震崩溃，冰块倒卷爆开；大地随之裂开，裂缝如地龙向深处蔓延。
- 连带影响：鼎内第二花（冰封之花）根茎被撕出巨缝并完全穿透。
- 王林一步迈入地裂，身影消失。

## 三、洞府核心大鼎的变化
- 黑气缭绕巨鼎，凡入鼎者面孔浮现其上。
- 此刻面孔消散大半，**七彩道人的面孔完全消散**。
- 鼎正反两面仅剩**王林**与**战老鬼**的面孔清晰，散黑光并吸引外围黑气 —— 只剩二人相争之势。

## 四、第三花：已死之空间
- 一片灰色死气，第三花叶枯花败、早于多年前毁灭。
- 王林原欲在此设伏杀战老鬼，权衡后放弃：**伏杀只能行一次，第二次战老鬼不会上当**。
- 对战老鬼的评估：性格谨慎且多疑，设计较难。

## 五、第四花：黑色死海与古之墓地
- 花通体黑色，黑液滴落经年成黑色死海，静无风浪，腐朽血腥。
- 临入花前，王林听到花内传出熟悉咆哮——**托森**。
- 入内后确认：此处正是他当年**获得道古传承的「古之墓地」**。
  - 推断：古之墓地为**七彩仙尊布置以埋葬烨寞**的墓地，同时充当洞府五花八门的第四重防护。
  - 环境：雾气遮天蔽地，浮空平台大小各异，部分平台上有血肉精华被吸尽的骷髅残骸。
- 约半个时辰后，此地尚存诸人陆续赶来，见黑色死海皆神色凝重，仍纷纷踏入。

## 六、烨寞传承的缺口与「九星古神」之谋
- 烨寞身躯已崩溃，唯**双臂**被砍下得以保留；王林已获双臂。
- 尚缺：**左眼** + **心脏**（心脏在古之墓地最底层）。
- 若吸收烨寞之心：即便无左眼，古神星点、乃至古魔星点亦极可能各成九颗 → **九星古神**，道古之力暴增。
- 王林自问：「九星古神，若我完全散开身躯，会有多大？」

## 七、决意下探
- 当年因感到倒数第二层有极恐怖气息而止步离开；此次结合**七彩第三魂**的部分记忆已有猜测。
- 「富贵险中求」——王林一生周游死亡之间，修为多靠挣扎拼命换来，决意再拼一次。
- 优势：此层**全部地图**已在脑中（含下一层入口），无须再升级平台换图。
- 头下脚上如游鱼坠入雾海，向深处落去。

## 八、旁支视角
- **玄罗**：同在石台，望雾轻叹「这里就是烨寞那孩子死亡之处了」。
- **第三妃**（仙罡大陆天门道圣女，至今处子）：
  - 对此地了解仅次于王林（当年亦获较大部分地图）。
  - 当年在此遇王林，受其相助被送出，免去被封困结局。
  - 一生喜静、不善交流；当年为宗派咬牙同意成为七彩仙尊妃子；在洞府界内亦独来独往。
  - 王林是她一生第一个出手相助之人，心底生出说不清的迷茫与涟漪，念及要回报；思念师尊与「比她优秀」的妹妹，想回家。

## 九、悬念
- 王林踏入墓地一刻，古之墓地内当年传承道古的大殿中，**托森（或涂司）睁开双眼**。

## 关键因果链
融合烨寞左臂 → 星漩显现（第九星前兆）→ 撕天破冰池、贯穿第二花 → 掠过已死的第三花（放弃设伏）→ 入第四花即古之墓地 → 定策下探最底层取烨寞之心 → 惊动沉睡的托森/涂司。
