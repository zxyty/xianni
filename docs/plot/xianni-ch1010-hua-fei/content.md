# 第八卷 联盟隐秘 · 第1010章 花妃

## 一、雕像考验：三步之逆

- 王林第二次与大殿雕像双眼对视，心神轰鸣、身形被威压逼退。眉心**古神星点**急速旋转，肉身在压缩中强度暴增，凝聚更多**古神之力**，如山峰般笔直站立与威压对抗。
- 王林厉言：「这天下间，没有可以让古神屈服之物，天道不行，规则不行，你，也不行。」
- **古神一吼**：惊天动地，殿外洞府大范围崩溃。
- **古神传承的判定逻辑**（本章核心设定）：
  - 后退十步百步 = 退缩、屈服；
  - 原地苦撑不败 = 中庸，所修之道只能**顺天承运**；
  - 向前迈出一步 = 反抗，即**逆**。
- 王林连踏三步，第一步身内碎裂、第二步背后毛孔喷血、全身成血人仍长笑，宣称「我王林身为逆修，连这天都敢逆，连命运都敢反抗」。
- 第三步落下，大殿威压瞬息消散如从未出现，考验通过。
- 因果照应：当年在妖灵**问鼎**时取「逆」，今日同样在妖灵之地，被世事封存、被罗天一行压制、被自身心神掩盖的「逆」再度绽放。
- 王林凭雕像相貌与**仙塔内青霜**的几分相似，断定雕像所刻为**仙帝青霖**；自忖若无古神之力，当场必暴毙。

## 二、花妃含烟的揭秘

- 白衣女子自陈身份：**仙帝八妃之一，花妃含烟**，望向雕像时目露柔和与浓浓依恋。
- 她挥手使大殿地砖尽数升空、组成传送阵；地砖下露出真实星空：黑暗中星云弥漫、星点缓慢移动。
- **关键设定**：
  1. 妖灵之地是一座**仙府**，以特殊方式漂行于星空；所见星空为真实景象。
  2. 走进传送阵可进入**封印之地**；若有能力打开，方可进入真正的仙府。
  3. 仙帝青霖当年归来时本已带伤，途中又被**两个界外之民**纠缠，遂开启仙府在内疗伤。
  4. 仙府原本无入口，他留下**四个入口**；四入口同时开启，妖灵之地内才会出现通往其闭关处的真正通道。
- **放行三理由**：王林拥有**定身术**、携带**青霜之尸**、且是**「王姓之人」**。同伴进入传送阵后也会随他心意出现。
- 王林追问「王姓之人」何意，花妃只答：「若有机缘，你会知晓的。」问她何不同去，她背身苦涩：「我去不了。」

## 三、花妃的真相

- 花妃走入王林感知不到的大殿深处，身上散白光却与黑暗融合；双脚泛起青色淹没全身，光芒一闪后化作一朵极美的花朵，凄色绽放于无人可见的黑暗中。
- 自述：「**花妃已死，残存的，只有一株花仙，一株踏不出这洞府的花仙。**」
- 王林临入阵前望向大殿黑暗深处，似有所见（未点破）。

## 四、开启第四洞府

- 传送阵后为一处**虚幻空间**：地面刻有庞大阵法，正中有一块**黑色石块**。
- 王林取出当初所得**仙府钥匙**，钥匙化丝丝青烟钻入石块，阵法符文升腾、缓缓运转。
- 阵法与王林心神微妙相连：整座第四洞府尽在其心神之中，一念可破任何禁制、操控一切——**唯独那大殿除外**。
- 王林看到司徒南，也看到被花海覆盖、原本已消失的浮风子、尘道三子、大头与雷吉；心念一动，众人尽数消失（收起/移位）。
- 司徒南自王林入殿起便时刻警惕，忽觉一股熟悉神识扫过，认出「王林」，身形随即出现在庞大阵法之上。
- 王林下令：「洞府已经彻底打开，雷吉你修为不足，留在这里，等我们回来。」阵法剧烈闪烁。
- **章末伏笔**：与此同时，妖灵之地内同样发生了惊人的变化。

## 五、归属与校勘说明

- 本片段中「司徒南」为**司徒南的断臂**所化人影（自第336章起自称司徒南，真伪未定）；真正的司徒南已于第61章身死。
- 「含烟」在第885章已记为死亡，本章的「花妃含烟」自陈**花妃已死、残存者仅为一株花仙**，二者应作区分核查：本章现身者为花仙残存体，非活人行动。
- 王林近数百章以自创化名**「许木」**行事，本章文本直呼其本名王林，按本尊记录。
- 「浮风子」于第934章记为死亡，本章其身处花海覆盖之中被王林一念收起，属既有状态处置，非新增行动。
