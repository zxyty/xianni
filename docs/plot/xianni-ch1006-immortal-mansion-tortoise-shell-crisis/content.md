# 第八卷 联盟隐秘 · 第1006章 危机

## 一、清场：十尊仙兵被制

- 一龙子暂时拖住两名仙兵；一星子掐诀神通化作大手，将冲向白雾的其中一名仙兵卷起拉入战团。
- 最后一名仙兵正要冲入白雾，浮风子眼露寒光、右手虚空一抓，将其隔空摄回，令其力战四仙。
- 仙兵身体强度惊人，但对浮风子一行而言「战之不难」。
- 王林由此暗呼侥幸：当年若未逃离妖灵之地、执意破开仙府禁制，即便走到这里，花灵与仙兵都不是那时的他能抵抗的。

## 二、内环变故：阁楼化龟甲，四青衣老者现

王林走向被四处阁楼环绕的内环大殿，未近身即生惊变：

- 四处阁楼虚幻、移位、成虚影，强光融合组成**龟甲之幻**，如巨大龟壳笼罩护住大殿。
- 龟壳飘出四道青烟，化作**四名青衣老者**：皆为**魂体**，修为介于**窥涅初期至中期**，仙风道骨、仙气浓郁。
- 苍发老者低喝「下界贱民，敢闯仙府，死罪」，不给解释机会即刻动手。

### 四老者的合击（仙术配合成绝杀之变）

| 老者 | 手段 |
|---|---|
| 苍发老者 | 引仙府仙气成气旋，崩溃中冲出数丈黑毛**巨猿**（手臂过膝）；本人化青光随猿穿透而来 |
| 第二人 | 沙土风暴卷身，化**百丈黑蟒**，血盆大口吞噬 |
| 第三人 | 双臂伸展、青烟云涌，仙气凝成**大雕**，厉啸快如闪电 |
| 第四人 | 掐诀上抬，低喝「**仙山布攻**」，仙府之顶幻化**庞大山峰**砸落 |

## 三、王林的反击（四招破四人）

1. **肉身一拳** — 不退反进，与巨猿交错刹那拳击其胸口，巨猿退三步后上半身轰然崩溃。
2. **子母道枯** — 升空下指，右手背图案散黑芒脱体放大，化阴森凶兽头骨，双目幽光一闪、煞气笼罩，将大雕生生定在半空并化作石雕。
3. **三九之剑** — 一拍储物袋，飞出**二十七把金光大剑**，急速交错成剑网剑阵，环绕穿透黑蟒，黑蟒凄厉惨叫。
4. **十八地狱封仙印** — 张口吐出，无限放大迎击砸落山峰，轰然相撞争取时间。
5. **呼风** — 抬手低喝，天地色变，可吹灭一切生息的黑风弥漫，风中幻化**四头黑龙**吞噬四老者。

### 关键反应：「白凡之术」

- 幻化巨猿的老者见黑龙面色大变，失声道「**白凡之术**」，欲退已晚，被一头黑龙一口吞噬。
- 另两名老者（除施山印者外）同样未能逃过，刹那被吞噬。
- 最后一名老者退踏龟壳，念奇异咒语抽取龟壳光芒如水流涌入体内，气息不断攀升。
- 王林右手一指喝「**定**」，无数无形细丝缠身，老者失神喃喃「**定身术**」，**脸上露出古怪神色正要说话**，即被最后一条黑龙吞噬。
- 该「古怪」神色被王林看在眼中，**令他心神一动**（伏笔：定身术／白凡之术的来历可能牵涉仙府一脉）。

## 四、龟甲不破

- 王林一步至龟壳外，握拳幻化**古神手臂虚影**狠砸而下：洞府颤抖、地面裂缝纵横，龟壳剧烈闪烁却**毫无崩溃迹象**。
- 此时浮风子等人各自处理完仙兵；天空白雾急速收缩，**银尸**吸收花灵后一脸红润，身上似有奇异变化。
- 王林下令「破开此阵」，浮风子等人联手神通齐落龟甲：轰响、地面震动，**远处石桥崩溃彻底坍塌**，而龟壳仅**光泽黯淡**，依旧完好。
- 王林暗惊：古神一拳加众多老怪合力仍破不开，防护程度超出想象。
- 疑问（重要线索）：「不知天运子与凌天候等人所拥有的仙府，是否也有这样的龟甲，如果也有，他们是如何破除？」

## 五、危机：脚步声与白衣身影

- 众人目光凝聚之际，龟甲**自行闪烁、光芒流盼**，渐渐显露其内一片暗色的大殿。
- 大殿深处传出**脚步声**，声弱而清晰，且与听者**心跳频率同步**，仿佛每一步都踏在心跳之上。
- 各人反应：
  - **浮风子**：急速运转元力弥漫全身，方隐隐将心跳与脚步声剥离。
  - **尘道三子 / 大头**：修为不及，面色苍白；大头额上青筋鼓起。
  - **雷吉**：修为最低，身颤退后数步，低吼中双目鼓起、身躯膨胀至数十丈，才有抵抗之力。
  - **银尸**：本为有灵性的尸体，**没有心跳**，故不受影响，神色如常。
  - **王林**：肉身为古神，可承受此等心神打击，但神色渐渐阴沉。
- 脚步声抵达殿口，**一个白衣身影**自大殿暗处显露，一道目光穿透龟甲落在王林身上。
- **王林全身汗毛瞬间竖起**——很久没有出现过的**生死危机**如风暴涌现全身。

## 六、要点与伏笔

- 仙府内环的守卫层级：花灵 → 十尊仙兵 → 四名窥涅期青衣魂体老者 → 龟甲护殿 → 殿内白衣身影。
- 龟甲乃四阁楼幻化而成，防御远超王林与一众老怪合力，为本卷重大关隘。
- 「白凡之术」与「定身术」引发老者异常反应，暗示王林所修之术与此仙府／上界渊源。
- 银尸吞噬花灵后产生「奇异变化」，为后续变化埋线。
- 章末作者附记月票仅3票之牢骚（非剧情内容）。
