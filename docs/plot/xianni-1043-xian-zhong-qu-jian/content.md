# 仙逆 第八卷 联盟隐秘 第1043章 险中取剑

## 一、抉择：取还是不取

- 王林在仙帝洞府深坑底，认出冰封古神头颅深处的**铁剑**——与当年所见并非同一物，但外形一模一样。
- 王林自省：自己获得的**记忆传承并不完整**，缺失的那块极重要的记忆在**托森**手中；铁剑来历托森或许知晓，他却不知。能让托森露出狂喜之色的铁剑，绝非凡物。
- 顾虑：铁剑被**红色细线**缠绕，线中透出可怕气息与持续危机感。就此离去可安全脱身，取剑必引红线攻击。
- 决断："富贵险中求"。此处是仙帝洞府，今日不取，日后再来极难，遇宝山不愿空手回。

## 二、破冰夺剑

1. 抬头观察：深坑上方无数冰川交错封死出口，仅余扭曲缝隙可通人。
2. 掐诀，眼中火焰之芒闪烁，**窥涅后期大圆满巅峰**修为爆发；眉心**古神星点**幻化急旋，全身砰砰作响，**古神之力融入四肢**。
3. 右手前伸，双目火焰呼啸而出，元力凝于右手，滔天**火海**弥漫，直扑古神头颅，火焰顺颈部伤口通道冲入冰层内部。
4. 红色细丝绷直分化无数分支，喷出大片**红雾**，一冲即令火海熄灭倒卷。
5. 王林当即喷出一口**元神精气**，火海如添火油暴增，古神头颅冰层大片裂纹、轰然崩溃。
6. 冰层一破，头颅由栩栩如生**急速腐烂**，恶臭弥漫，转眼化作深黑色巨大骷髅；颅内现出约**十丈大小的红雾**，散出无数摇曳细线，部分紧缠铁剑。
7. 王林化流光穿越冰块冲击，一把抓住铁剑：元力毫无保留冲出，在体外结成环形火海并顺剑冲入细线；左手挟古神之力一拳轰出，身后幻化**古神虚影**。
8. 火海+古神一拳合击，数条细丝断裂、其余收缩，王林右手向后一拽，**夺得铁剑**，剑上光芒一闪即收入**储物袋**，随即拔地而起直奔上方出口。

## 三、红线人形之物苏醒与尸群围杀

- 合击余波击散红雾，露出其内**人形虚影**：看不出男女，全身缠绕无数红线，双眼冰冷无情，半透明、无任何内脏，体内唯有一个旋转的**红色漩涡**；睁眼后怒吼咆哮。
- 咆哮之下，深坑壁四周冰块尽数碎裂，其内一具具**仙人尸体**被红光弥漫，红眼睁开，如凶兽般吼叫扑向王林，回音如风暴横扫。
- 王林一眼看穿：尸体眉心皆有一条**若隐若现的红线**；尸体不灵活、能发挥的修为仅相当于**阴阳虚实**左右。

## 四、火柱冲天，脱离深坑

- 王林全速上冲，与尸体擦肩时右手**双指成剑**点其眉心，尸体即被火焰包裹化作火球崩碎，眉心红线随之消散；连毁数十具。
- 人形之物紧追，全身细线化作一根根**利剑**脱体激射。王林右目一闪，祭出**青光盾**于身下抵挡，青光盾被冲击得不断后退。
- 危急中王林掐诀低喝"**呼风**"：黑风呼啸而出，此番不再阴寒而成**热浪**，幻化**五条黑龙**，龙身燃赤红火焰（望之近紫），势如破竹撕碎吞噬拦路尸体，四周冰川尽数融化成白气。
- 高温对王林毫无影响（双眼蕴含火焰）；**星痕貂**死死抓着他的衣衫、咬住头发，眼中满是害怕。
- 火焰越冲越快终成**火柱冲天**，瞬息穿透整个深坑，如火山爆发般自坑口喷出。王林身在火焰中、体外环绕五条火焰黑龙，脱离深坑后猛地向下望去。

## 五、伏笔与看点

- **铁剑来历成谜**：与旧剑同形而非同物，托森掌握的缺失记忆是解谜关键。
- **红线体系**：红雾人形之物以红线操控仙人尸体（眉心红线=控尸标记），断线即尸溃。
- 王林战斗序列本章齐备：古神肉身之力 + 火焰元力 + 元神精气助燃 + 青光盾 + 神通呼风（火焰化黑龙变体）。
