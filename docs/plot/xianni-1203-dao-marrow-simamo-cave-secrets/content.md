# 《仙逆》第九卷 云海之巅 第1203章 道髓

## 一、突破：净涅初期 → 净涅中期

- 地点：司马墨洞府所在山谷。谷中弥漫大量天地元力，回荡成漩涡悬于谷空，王林盘膝坐于漩涡正下方。
- 王林意境已突破，只需吸收足够元晶即可达净涅中期。
- 山谷磅礴元力尽数被吸入体内，体内元神同步打坐胀大，直至与肉身一般大小充斥体内；双目睁开时两道堪比星辰的目光破天而去。
- 四周大量元晶轰然崩溃化作碎灰倒卷，在其体外形成一道道环形印记——**净涅中期**成。
- 战力自评：
  - 净涅中期 + 古神肉身 → 杀碎涅中期「丝毫不难」；
  - 碎涅后期 → 仍是挑战；
  - 若达净涅大圆满 → 碎涅后期老怪「将不是对手」。

## 二、苍松子记忆：道髓之秘

王林手中玉瓶为抢夺苍松子之物。吸收其记忆后，王林已知七彩界底细、玉瓶内液体的作用，以及离开此地的方法。

**道髓的制取链条**：
1. 以**迷失者**吞道；
2. 以**铭志者**养道；
3. 融入此地**四座石碑**；
4. 再以石碑下骸骨上的**经文**转化，成为一股不可思议之力；
5. 以此力侵入骸骨，逼出「血液」——实为骸骨之人生前的**道髓**。

**关键推断（王林）**：
- 道髓重点在于那半具骸骨生前的身份。两座石碑各配半具骸骨，合为一人。此人生前必是声名赫赫之辈，或被人杀死、或死后被挖出骸骨，被以此惊天动地之法逼出其道。
- 骸骨上经文为**后刻**，出自某位大神通者——将自身神通化作经文，想出这种骇人听闻的方法。
- 饮道髓可得其道，但**入口即沉睡**，醒期不定。苍松子的计划正是携道髓寻一绝对安全处饮下沉睡；这也是他与青衫老妪厮杀时不当场服下的原因。
- 苍松子选定的沉睡地是**此地至深处的那座山峰**，但其记忆中找不到他前往那里的理由，也**没有白发老者的身影**（搜魂有破绽，记忆不全）。
- 七彩界一切存在（包括凶兽）似都为石碑提供「道之感悟」；此地无十三阶凶兽，盖因凡成十三阶者均被杀、道魂被吸走。
- 道髓对布下此界的大神通修士而言，恐非「喝下」那么简单；山峰上的白发老者必在守护某物，道髓或与其所守之物有莫大关联。

**疑点**：司马墨玉简称此地有**四座石碑**，王林心神扫过却只见两座，且其中一座空空——无骸骨亦无玉瓶。

## 三、九洞府探查（第四 ~ 第八座）

此前只开启前三座，本章续开：

| 洞府 | 禁制 | 内容 |
|---|---|---|
| 第四座 | 普通山石禁制，一按即溃 | 空旷，一无所有 |
| 第五座 | **岁月禁**，波动极强 | 四名**迷失者**：衣衫破损、无发、双目茫然如行尸走肉，在阵法中永不停歇地行走；地面阵法散柔和之芒钻入其体；阵法中心放一枚玉简 |
| 第六座 | 岁月禁 + 更多封死禁制 | 三名**铭志者**：失去肉身、只剩幽魂般元神漂游，口中似有声（被山石阻隔听不到）；禁制封死，除非其自行清醒开启；内亦置一枚玉简 |
| 第七座 | 禁制远超铭志者洞府，密密麻麻彻底封死 | 一盘膝老者，头发花白、面无血色。见王林即目露疯狂、咆哮如兽冲出，神通刚现即被洞府禁制瞬息吸走；双手拍山石毫无声息。久后力竭退回打坐。王林疑其为**逆行者** |
| 第八座 | 普通封印手段（非岁月禁），一挥即散 | **半具骸骨**（下半身），刻满无数经文，一片黝黑无光，被地面阵法死死锁住 |

**王林的判断**：这些人是司马墨的同门，被司马墨带回封印于洞府中，试图令其苏醒——但司马墨并未成功。洞府内的玉简应是**岁月禁**功法：若有人苏醒，学会后便可自内部打开封印阵法。

## 四、以神感悟：触碰骸骨

- 王林认出：**石碑失去的那半具骸骨就在第八洞府**。
- 骸骨散出强大吸力，似在吸撤心神；王林退后数步，毫不犹豫斩断这一丝心神联系。
- 骸骨**右腿骨上有一道极深的断裂伤口**（未全断）。
- 准备动作（层层防备）：
  1. 双手掐诀，在自身连点数下，打出大量禁制封锁心神；
  2. 虚空一抓取出苍松子的**水晶剑**，在剑上留下一丝心神，放于一旁作后手；
  3. 数丈距离，每一步都极为谨慎地走到骸骨旁。
- 蹲身，右手毅然按在腿骨伤口处，心神顺右手摊入——**以神感悟**。神识触碰刹那，脑中骤然轰的一声。（本章止）
