# 仙逆 第九卷 云海之巅 第1140章 归元宗

## 一、场景：归元宗南苑·山顶红阁

- 归元宗南苑不止盆地内的阁楼群，还向南部山脉蔓延。
- 山脉顶端有一片四季长红的林木，其中立着一处**红色阁楼**，其上雕刻众多舞动之凤，甚为美丽——此为吕烟菲居所。
- 吕烟菲喜红，宗内人尽皆知：所居为红，衣衫亦红。

## 二、吕烟菲的处境

### 修为与地位
- 修为：**窥涅后期大圆满**。
- 号称**归元宗第一美女**，名声在**五阶星域**内赫赫，觊觎者众。
- 同门三位师兄修为比她**低一阶**，故无资格近前欣赏。

### 靠山崩塌
- 此前诸多觊觎者碍于其师尊**净涅圆满**的修为，多年未起正面冲突。
- 如今**师尊归墟**，归元宗因此**处于最弱的时期**——这是本章矛盾的根源。

### 紫色玉简与卢迪之辱
- 吕烟菲手握一枚**通体紫色的玉简**，狠狠捏住，玉手隐隐发白。
- 眼中**屈辱**，有心捏碎玉简，但“想到后果”只能忍耐，屈辱更浓。
- 待弟子离去后，煞气一闪，整个人如**玉罗刹**，屈辱被煞气完全取代，立誓：
  > “卢迪，我吕烟菲即便是死，也绝不会与你双修。”
- 可推知：紫色玉简为**卢迪逼婚/逼迫双修**的传讯之物。

## 三、收徒与“伴灵之子”

- 吕烟菲一生**只收三名弟子，皆为女性**；二弟子**许芸**修为最高，**半只脚迈入阴虚之境**，相貌秀气、性格温和。
- 四名面色苍白、瑟瑟发抖的少年被引入房中。
- 吕烟菲吩咐“老大、老三”**各带二人收入门下**。
- 关键设定：这四人资质寻常，需在**一个月后**得到**吕烟菲师尊留下的紫目莽**的**认可**，才能成为**伴灵之子**；否则送回家。
- 许芸提到“还有三人年纪有些大了”，吕烟菲沉默后摇头：**不见了**，令许芸自行收入门下。
- 许芸欲言又止（意在那枚紫色玉简），最终幽叹退下。

## 四、王林一线：入宗与南苑院落

- 红阁外等候三人：
  1. **王林**（本章以新入宗弟子身份现身，神色平静）；
  2. 神色淳朴、衣衫朴素的青年；
  3. 相貌堂堂、眉目带淫亵之色的**蓝衫青年**。
- **孙芸**自阁楼走出，带着忧虑心事，扫视三人，看到蓝衫青年时**皱眉**。
- 孙芸玉手一挥化出祥云，托三人化作长虹从山脉落下，直奔盆地南部，抵达南苑边缘一处**精致院子**（内种花草，有数间房舍）。
- 落地后：蓝衫青年面色苍白、坐地呕吐（首次飞天，吓破胆）；淳朴青年面无血色、身颤但未吐；**王林神色平静**。
- 王林目光落在院内草木上，**仔细一一看去**；孙芸因其平静而不解，见其注视药草，遂问：“你认识？”

## 五、要点与伏笔

1. **卢迪**为新登场的对立者，手握逼迫吕烟菲的筹码，归元宗弱势期为其可乘之机。
2. **紫目莽**为吕烟菲师尊遗留之物，是“伴灵之子”选拔的认可者，后续可能与王林相关。
3. **伴灵之子**为归元宗的一项特殊身份/制度，需灵物认可而非单纯资质。
4. 王林对**药草**的辨识能力被孙芸注意到，是其在归元宗立足的切入点。

## 六、文本存疑

- 文中先写“许芸”从阁楼出来带三人，随即称其为“孙芸”，两名疑为同一人（或原文笔误）。此处按原文分列，实际很可能指**同一位吕烟菲的二弟子**。

# 归元派南苑：曾牛看药 · 本尊入地渡劫

## 一、入住南苑（化名「曾牛」）
- 王林对孙芸称自己「认识一部分」药材，自称「我是郎中」。
- 孙芸遂命其留下照看南苑药材；随后拍储物袋取出一枚玉简、凝神一挥传讯而出。
- 玉简传讯引来两道剑光，化作两名少年修士，称孙芸为「师尊」。孙芸吩咐：安排淳朴青年与蓝衫青年的居所，并传其**炼气口诀前三层**。
- 淳朴青年见修士神通激动不已，蓝衫青年亦露出向往之色。

## 二、药园的异常与孙芸的疑心
- 院内药香扑面，吸一口神清气爽。
- 王林心中惊讶：园中许多草药**在联盟星域已绝种，甚至在罗天星域亦已灭绝**。
- 孙芸一直暗中观察「曾牛」：此人过于平静，且**体内看不出半点灵力**，令她诧异，但未深究。她交代照顾药材之法、又说了几句炼气口诀后便自去打坐。

## 三、孙芸的处境（伏笔）
- 孙芸拼命修炼，想尽快进入**阳实之境**，以便多少帮到师尊。
- 想到师尊手中那**紫色玉简**，心中苦涩：师尊相貌被许多大神通修士惦记；**师祖归墟**后这些人蠢蠢欲动。
- **三位师伯不敢出面**，孙芸紧咬下唇。
- 退路：「若这一次还没有到达阳实，就唯有服下**入死离魂丹**了」——她深知此丹可怕。
- 近况：意境已有一丝突破，自觉距阳实不远。

## 四、王林的松弛与「真与假」之悟
- 木屋简陋：一床、一桌、一盏熄灭的油灯。
- 王林躺下，神色轻松——无论北水村还是此处，都让他难得感到心神缓和与平静。
- 到他这个程度，除打坐吐纳外最重要的是心灵感悟、对道与规则的理解。
- 顿悟片语：「真与假……我现在，或许就是处于真与假之间。」

## 五、分身与本尊分离
- 入夜后王林盘膝掐诀，连点身上数下，吐出一口浊气，身子一晃**一分为二**。
- 分身与本尊在归元派南苑木屋内分离开来。
- **本尊状态**：腹部以下一片骸骨，骨头漆黑、隐有红线交错；比朱雀圣宗时更凄惨，伤势更重。
- 背景：早在离开朱雀圣宗、去**雨之仙界**救**青龙圣皇**时，王林已再次与本尊融合；但本尊出了问题，即便融合，**往昔的古神之力所剩无多**。

## 六、古神「三损七劫」与提前到来的第一损
- 据**涂司的记忆**：古神一生有**三损七劫**，本应到**六星**之后才会遇上第一损中的两劫。
- 王林身上第一损**提前**降临。**第一损两劫 = 肉之劫 + 骨之劫**，「的确极强」。
- 应对：王林右手一抓开启**储物裂缝**，取出一枚枚拳头大小的**血晶**；血晶血光被限制在房间内不外泄，随手一挥尽数投向本尊，渐渐把本尊下半身完全融入其中。
- 本尊睁目、沉入地底，直入**莫罗大陆深处**，保持盘膝闭目，开始缓缓吸收身上血晶内的气息。
- 王林的猜测：他的**古神肉身与真正的古神相比并不完善**，欲度第一损，**必须拥有古神的心血**；但这只是猜测，本尊能否度过肉劫，他没有把握。

## 七、收束
- 时间流逝，窗外亮起清晨阳光，雨水哗哗落下，传入王林耳中。
