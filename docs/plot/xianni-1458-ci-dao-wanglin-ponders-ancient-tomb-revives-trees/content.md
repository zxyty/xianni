# 第1458章 赐道（第二更）

## 一、王林的谜团推演（古之墓地群疑）

王林在古神头骨上静思，将已知线索串联，得出一串仍无定论的推测：

- **仙皇设局与道古**：假设“古”即道古，则仙皇所想的“别的法子”很可能与道古有关——仙皇设局，从道古所在的那个世界将其引来，目的是算计道古、甚至算计三族，想用他们**代替道灵饲养天道**。
- **未解之处**：以仙皇这等人物出手必有十足把握，既能设局引来道古就理应成功，为何最终**天道会被杀**？
- **联盟星域的空间裂缝**：当年在联盟星域渡劫时，王林无意间打开一道空间裂缝，神识进入其中，看到一个奇异天地，内有**诸多古神、古魔、古妖的雕像**。那里是何处？是否与古之墓地、与七彩道人有关？
- **朱雀封印之谜**：代代朱雀几乎都被人封印，矛头直指**掌尊**；而掌尊之师的师傅又是谁？
- **“门”之谜**：银衣女子看到七彩道人雕像后尖叫发狂，不断声称“门不是她打开的”。此门是**饲养天道之门**？是**封印困住其敌之门**？还是**通往另一个世界之门**？为何门开之后七彩道人会愤怒屠杀？
- **地府之疑**：五阶墓台成型时，自称**道古烨雾**之人曾言——若是其族人可入**轮回门**获得传承，若非其族人则**取地府而去**。地府究竟是什么？
- **古之墓的本质**：此地定与七彩道人有莫大关联；究竟是其留下的**饲养天道之地**，还是**道古烨寞**死前留下的传承之枷？“古之墓”是否即指道古烨寞之墓？

王林亦自承：以上猜测也可能**全部都是错误**。越想越乱，终于暗叹一声，不再纠缠。

## 二、对枯树的判断

- 四周枯木**应是被人种下**，用途是在雕像封印古神头颅的同时，让树木**吸收头颅内的古神气息**。
- 头颅中的古神气息在悠久岁月下**消散殆尽**，树木失去养分故而全部枯萎。
- **贪狼**来此时只找到一颗木灵，想来也只剩这一个；若贪狼未来，再过一段时光最后一颗树也将枯死。
- 由此推知：除贪狼外，此地**极久无人来访**，包括当年种树之人，很可能种下后就再未回来。

## 四、以古神之力饲养头骨、复苏十九株枯树

1. 王林盘膝坐于**头骨眉心**，全身**古神之力**运转，顺身躯融入头骨。
2. 头骨**好似无底洞**，任古神之力涌入而无丝毫变化；王林不停不辍地持续输入。
3. 渐渐地，其**眉心古神星点闪烁，六个星点环绕**，古神之力更浓地涌出。
4. **数个时辰后**：身下古神头骨似有变化，四周枯木仿佛得到养分滋润，渐渐散出一丝丝生机。
5. **权衡取舍**：若要令所有枯木尽数焕发生机，不但耗时太多，王林体内古神之力也不够 → 放弃全部复活。
6. **集中供应**：通过头骨笼罩**十九颗枯萎之树**，全力供应。时间流逝，这十九棵树生机渐盛，**树干底部恢复本色并缓缓向上蔓延**。

# 第1371章 天皇炉炼毒海 · 赐术灵动上人

## 一、炼化黑色毒海
- 天皇炉内浑浊消散，显出一片**黑色毒海**：海水死寂无波澜，其中存在大量被毒染的**香火之魂**。
- 来历：此海为**大荒上人**诡异的舌头毒化而出，并蕴含**妙音道尊**的香火之魂。
- 王林右手一指喝「炼」，毒海如燃烧般轰鸣、卷起大浪与漩涡。王林判断：炼化之后当为一件**威力强大的毒宝**。
- 炼化异象（自循环增毒）：
  1. 海水炼化成气 → 黑雾弥漫整个天皇炉；
  2. 黑雾无法消散，积累成**黑云**；
  3. 黑云降下**黑色雨水**落回海中，似成循环；
  4. 但雨水远少于蒸发之量，减少的毒并未消散，而是凝聚起来，使海水**毒性更浓**。
- 无尽香火之魂发出凄厉尖叫，被天皇炉阻隔后传出已轻微。
- **三天后**：海面虽不断降雨仍下降**近半**，海水黝黑，**神识都无法穿透**，其毒更为可怕。
- 无异常发生，王林放心，右手一挥令毒海消散，幻出炉内另一界。

## 二、炉内另一界：紫色香火之海与灵动上人
- 此界弥漫**紫色海水**，内蕴诸多极为难得的香火之魂（属妙音道尊）。
- **灵动上人**盘膝坐于海底，双手掐诀疯狂炼化香火之魂，试图令其全部改变、为自己奉献香火。
- 其身后立一尊巨大的**灵动族魔神像**（双臂环绕），散发万丈光芒；被光芒笼罩的香火之魂神色迷茫与挣扎。
- 已有少部分香火之魂被改变，奉献香火为灵动上人吸收，其面色红润、隐藏激动。

## 三、王林赐术，催其踏第三步
- 王林皱眉：这些香火之魂属于妙音道尊，改变它们即便以灵动之能也需很长时间。王林不急，但若能在古墓内让灵动**加快吸收、成功踏入第三步**，对自己帮助极大。
- 王林分出**一丝元神**融入天皇炉，在紫色海洋上空幻化身影，威严唤「**古奴子**」。
- 灵动上人猛睁双目、狂热恭敬，飞出海面，于数十丈外双膝跪在半空：「古奴灵动参见主人。」
- 王林赐语：「我赐你一术，以你的修为，想必可以很快学会，以此术，尽快融此地香火，迈出真正的第三步。」
- 灵动上人一生修道所求即三步大能，碍于香火终身止步；纵无天皇炉与梦道炼化之缚，得此造化也必心甘情愿——**只要成道，不惜一切**。
- 王林一指打出一道**烙印**直入灵动眉心元神，灵动毫不闪躲。王林嘱：「道术，融此术你尽快感悟。」
- 王林对收服灵动极为满意：有天皇炉与种种手段在，不怕其叛变。

## 四、王林的盘算
- 心动之念：若再遇一个处于**空涅初期**的第三步大能，有灵动配合则战之不难；若可擒住炼化，便可再成一个**古奴**。
- 随后神识所化身影消失，元神回归本体。

## 五、同时·古墓外的奉天狼族大汉
- 奉天狼族大汉踏**五阶墓台**，一路势如破竹冲过无尽妖气，距目标越来越近。
- 自忖：再有**三天**即可抵达；若能得到**九片叶子**，配合本族神通，便可使**奉天狼道**永久留在身边、**封其归路**为己所用。
- 届时其修为虽仍是**空涅初期**，却将是「空涅初期中的最强者」。操控墓台速度越来越快。
