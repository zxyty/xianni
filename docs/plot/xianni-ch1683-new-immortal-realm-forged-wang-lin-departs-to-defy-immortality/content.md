# 第1683章 此去，逆仙！

## 一、走遍四大仙界搜集资源（不到半个月）

### 1. 召河·闪界
- 王林操控风仙界的庞大陆地，在呼啸轰鸣中冲出云海，进入召河。
- 召河收服三年内，原本在罗天的召河修士纷纷回归家乡疗伤。
- 召河的闪界与其他星域不同：入口完全开放，踏入召河北部深处即可见星空上一条璀璨银河——那银河就是闪界，由诸多细小大陆碎片散发的光芒组成。
- 王林此前数次来召河都是匆匆而来急急而走，从未踏入闪界。此番风仙界大陆停于召河北部银河之下，王林一步踏入银河。
- 第三天，王林略显疲惫地走出，右手向后一挥，整条银河震动着直奔风仙界大陆，环绕旋转，将大陆笼于银河光芒之中。
- 王林暗叹：「闪界的毁灭，已然无法弥补，只能作为未来仙界的守护之河存在。」

### 2. 罗天星域·雷仙界（作废）
- 王林对雷仙界极熟悉，风仙界大陆在银河环绕中现身罗天星域，威压波纹惊动了域内疗伤修士。
- 雷仙界入口那道恒古存在的雷霆闪电早已被王林数年前吸走。
- 雷仙界崩溃是毁灭性的：其内大陆当年被**炎雷子**取走不少，加之后来一次次事变，如今所剩无几，一片废墟荒凉，且极不稳定，似随时可能再度崩溃。
- 王林结论：「这里已经无法采用，雷仙界，已然作废了。」遂收回神识转身离去。

### 3. 战老鬼的窥视（暗线）
- 王林离去一刹那，雷仙界深处**战老鬼**双目露出奇异之芒——王林察觉不到他，他却能看到王林。
- 战老鬼沉吟：「重凝四大仙界，他到底知道了多少？他到底是不是第三个？」终未阻止。
- 关键反转：王林神识确实未察觉战老鬼，但体内**天逆珠**猛地一动，送出一股奇异力量，使王林顷刻察觉深处有人窥视。王林不露半点心绪，心道「原来他始终隐藏在这里」，转身离开。

### 4. 昆虚雨界
- 最后一处，取走大量碎裂尘埃备用。数日后王林立于四大仙界交接处的星空，资源已足。

## 二、凝聚新仙界（五步）

| 步骤 | 手段 | 作用 |
|---|---|---|
| 1 | 以风仙界大陆为根基 | 成新仙界之陆；选址在四大星域交接点，四分之下四大星域各占两成 |
| 2 | 以昆虚雨界碎裂尘埃铺展 | 大陆厚实 |
| 3 | 施展神通**役灵印**巨掌拍落 | 非毁灭之力，以威压令尘埃凝实、大陆震动膨胀扩张一大圈 |
| 4 | 闪界银河环绕包围 | 成护界之河；立规则：以此河分割仙凡，**化神之下修士不得入内** |
| 5 | 咬破舌尖喷元神精血激活**转轮阵法** | 以新仙界为阵法核心，上空浮现转轮虚影缓缓转动，持续吸收界外**太古星辰气息**涌入界内 |

## 三、星魂融合与飞升规则

- 王林盘坐于新仙界上空的虚幻转轮之上，元神自眉心飞出、化作数份散向四周。
- 界内残存的数万修士早接到王林传音，在**青霖**等人带领下散往四大星域每一颗修真星、每一处可诞生灵的漂浮大陆，抽取部分修真星之魂并辗转下一颗。
- 三年最后一个月的倒数第三天，最后一名修士归来，众修士祭献全部星魂，与新仙界彻底融合。
- **确立规则**：此后四大星域这些修真星上诞生的修士，化神之后将因血脉中的牵引，飞升进入新仙界。
- 王林明言：此界已成但只具雏形，日后变化不需他来完成。

## 四、王林的动机与洞府隐秘

- 新仙界的凝聚不是王林一人之事：造出雏形这一点**红杉子**等人也能做到，只是战后需疗伤，更因不知晓「这里的一切只是洞府」的隐秘，故无法看得更远。
- 唯有王林知晓一切，既明白「担当」二字，便必须去做一些事情。
- 王林判断：与界外太古星辰的战争或已即将结束、或已结束；但对界内而言**更大的一次考验即将来临**——
  - 胜：带这里的人走出洞府；
  - 败：洞府之修全部殒亡、众生毁灭，天道再繁衍数千数万年后重新诞生洞府生灵，如轮回一样重新开始。
- 轮回伏笔：「或许，在那无数年后的某一天，也会有一个叫做王林的婴儿，在哭泣中诞生。」

## 五、临别宣告：此去逆仙

- 王林起身向四周数万道友抱拳一拜，宣告：
  - 「王某此去，生死不知」；**封尊**之称、三年守护自此终结，新界凝聚是他所做的最后一件事；
  - 「接下来，我要去逆这个仙」；
  - **「若我胜，则仙破；若我败，则林亡。」**
- 对**司徒南**的嘱托：若我死去，望把我告诉你的事情告知天下，书写成玉简——留在每一颗修真星上、留在每一个法宝之中、留在这新仙界内；即便众生毁灭，也要让这件事成为天道无法磨灭的烙印，让后人有知晓的可能。
- 王林转身一步迈向远处，背影孤独绝然。青霖、红杉子、司徒南等数万修士向其抱拳一拜。

## 六、要点归纳

- 四大仙界现状：风仙界（大陆被取作根基）、闪界（毁灭不可弥补，转为护界银河）、雷仙界（彻底作废，废墟且不稳）、昆虚雨界（碎裂尘埃供扩张）。
- 新仙界结构 = 风仙界陆基 + 雨界尘埃 + 役灵印夯实膨胀 + 闪界银河护界分仙凡 + 转轮阵法吸太古星辰气息 + 四大星域全部修真星之魂。
- 悬念：战老鬼隐于雷仙界深处、口称「第三个」，与「重凝四大仙界」之秘相关；天逆珠主动示警，显示其自有意志。

> 注：文中「司徒南」按世界状态须知，实为自第336章起自称司徒南的**司徒南的断臂**所化人影（真司徒南第61章已死，真伪未定）。
