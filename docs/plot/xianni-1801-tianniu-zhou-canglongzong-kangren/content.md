# 第1801章 有古怪

## 一、天牛洲：地理与传说
- 天牛洲为**仙罡大陆东州**的内洲之一，地处偏僻，四周山脉众多环绕，自天空俯瞰几乎大地尽被山脉弥漫。
- 传闻天牛洲乃**仙祖所斩杀的一头天外凶煞**死后所化，处处山脉皆为凶煞骨头所化。
- 更大的传闻：仙罡大陆仙族的**七十二洲，每一洲都是一个庞大阵法**，各镇压一头天外凶煞；古国的**三十六郡**亦有类似说法。年代久远真假难考，或唯**九阳**这等至尊、或仙古两族皇族方知。
- 对寻常修士而言镇压与否无关紧要，他们感受不到凶煞存在。

## 二、天牛洲两大宗门
### 大魂门
- 极为诡异，所修功法五花八门，核心是**魂与幻**。
- 幻术修炼至极致可化**九重**，最终达到**幻真**的程度，极为可怕。
- **矾珊梦**（按世界状态须知，第1606章以来'矾珊梦'实为其妹矾珊璐伪装；此处作为大魂门弟子出身的说明）即出自大魂门，其多重幻术之强可略窥大魂门手段。

### 归一宗
- 讲究修炼**五行之术**，另有独特的**铠甲锻造之功**，声名赫赫。

两宗均列入**东洲九宗十三门**之二，占据天牛洲。天牛洲极大，几乎相当于数十个洞府界，故两宗弟子众多而摩擦不多。

### 附属小宗
- 两大宗之下有诸多零散小门小派，分属归一宗与大魂门操控，如朝拜般定期上供。
- **七彩仙尊当年的七道宗**即为此类门派之一，因其（弟子）与大魂门弟子结为双修道侣、且天资惊人受大魂门看重，得大魂门庇护。

## 三、云逸封与那个神秘之人
- 近数十年归一宗如日中天，核心弟子**云逸封**闭关多年后出关，修为不凡，连挑大魂门核心弟子数人全胜，寻常长老亦非其敌，隐为天牛洲**新一代第一人**。
- 有人将其与东洲原有的**四大天骄**并列，齐称**五岳**；云逸封对此摇头，非自谦，而是**轻蔑四大天骄**。
- **十年前**归一宗与大魂门比试，云逸封一剑横扫，连伤大魂门弟子九人、长老三人。
- 有人再以四大天骄相提并论时，他放言：
  > 我这一剑可重伤很多人，四大天骄我也敢一战、不退半步；可这天地间有一个**只修道两千多年**的修士，我站在他面前，我不敢出剑。莫说是我，四大天骄在其面前也配称骄？这天地新一代修士中，无人是他的对手。
- 此语哗然。质疑声四起，**却无一句来自大魂门**——大魂门弟子似知晓此人；归一宗对自家弟子此言亦无半点声音，如同同样知情。两宗沉默近乎默认，反把猜测推到极高。
- 云逸封关于此人的最后一句：**“他会出现的，他出现之后，你们会知道的。”**
- 数年过去传闻渐隐，成为一个无人给出答案的问题。

> 按世界状态须知：**云逸封已于第1685章死亡**，本章为回溯天牛洲近数十年旧闻的叙述，非其新行动。所谓'只修道两千多年、令其不敢出剑'的神秘之人，本章未点名。

## 四、苍龙宗
- 天牛洲内**中等层次**宗门，山门范围堪比**小半个昆虚星域**——对洞府界修士而言是庞然大物（虽仍不如雷仙殿或当年的修真联盟），但在仙罡大陆只算泛泛。
- 仙罡大陆号称有**三万仙门道统**，真假未知，但每个宗派大为不同确有其事。
- 宗名虽与龙有关，弟子所修功法却与龙毫无关联：**擅长机关傀儡**，以傀儡辅助施展神通。入门弟子须**自炼本命傀儡**方可外出行走；傀儡分等级，威力不同。上佳者除特殊木头机关外，还可用**凶兽或修士的身体**炼成傀儡。
- 傀儡术他宗多少会些，但苍龙宗之术另有神奇：**可与其身转换，以达万古不灭之目的**。
- **太上长老杜青**：宗内修为第一，达**空劫初期**；其本身是一具**木头人**，平时如常人，施展神通时可见木头身躯。杜青创立苍龙宗，并与大魂门关系极深，故苍龙宗在天牛洲横行肆虐少有人敢招惹。
- 宗风凶名在外：门下弟子乃至长老多以各种手段夺取所需，**杀人夺宝不在话下**；但择人而噬，避开不便招惹者，主要目标之一是**路过天牛洲的外洲修士**。弟子常年在外游荡搜集信息回报宗门，遇难以独吞之敌便召同门群起而攻。
- **门规第一句 = 三有之语：“有古怪、有问题、有宝贝。”** 由杜青立宗时留下，历代弟子奉为良言。

## 五、康仁的发现（本章事件）
- **康仁**：苍龙宗三代弟子，生性狡猾残忍，三代弟子中凶名很高，颇受宗门看重；眼光毒辣，一眼可判对方是否可下手、不给宗门惹麻烦；相貌如翩翩公子，连部分二代弟子也不愿招惹。
- 这一日康仁飞往**天牛洲边界**，欲寻外洲修士下手。飞行中，远处天空**骤然裂开一道缝隙**，幽光闪烁间，一个**背着棺材的身影**从中飞出，直坠远处；裂缝随即消散，如从未出现。
- 康仁一愣、揉眼，几疑幻觉，旋即兴奋——“**有古怪，有问题，有宝贝**”——祭出法宝护身，化长虹全速追去。
- 前方传来闷响：背棺身影一头撞在山峰上，**山峰崩溃大半**；碎石中露出**躺着一动不动的白发青年**。
- 康仁贪婪暗赞“**好强的肉身**”，小心接近。

> 归属说明：坠落的背棺白发青年，据前后文与世界状态须知应为**王林**（白发、背棺为其标志特征），本章未点名。
