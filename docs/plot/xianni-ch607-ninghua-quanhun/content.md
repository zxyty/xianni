# 第607章 凝化泉魂

## 一、开场：震慑而非交战

王林同时祭出两大绝技——**道化黄泉**与**凌天候剑气**，目的并非与黑甲老者对战，而是震慑。

黑甲老者的判断：
- 道念所化的黄泉「确有神通，但却只是雏形，威慑力不足」；
- 那道剑气「很强，非常强」，能发出者「定是绝代强者，其修为，怕是已经达到了**碎涅三境**的地步」。

此时王林已压下**升仙果**带来的癫狂，恢复心智。他清楚：眼下这老者不是他能对付之人，更不用说**黑塔**内的莫名存在。

## 二、黑塔神念：掌印来历与“活擒”令

黑甲老者身后塔内冲出一道庞大神念，化作奔雷回荡，大地砰砰碎裂却在王林身前十丈止步。

- 神念问：「你那掌印，从何处学来」
- 王林答：「学自仙界」
- 神念喃喃：「仙界？是了，他当年的确去过仙界」
- 随后下令：「把他擒住，要活的」，神念收回塔内。

王林认出：正是这个声音，使他一路上无数次重伤，若非**寂灭之气**与**杀戮之气**，怕早已死亡。

## 三、第一轮交手：风 / 雷 / 雨

黑甲老者以**问鼎后期**修为跃至半空掐诀施法：

1. **风**——凭空飓风横扫，大地寸寸碎裂卷起碎石。王林右手指天，道化黄泉如黄河自天倾泻，飓风被轮回之力生生扯入黄泉。老者评：「小小年纪便有了自己的道，的确不简单」。
2. **雷**——阴云密布形如魔脸，黑雷冲天而降。王林抬左手小拇指施**一指黄泉**：黄泉倒卷带轮回之力迎击。巨响之后黑雷消散，黄泉崩溃三分之一。（王林曾听**司徒南**提过：雷系神通最难练，雷是天威、是天之力，非大神通者难学。）
3. **雨**——黑色雨水如箭矢宣泄。王林一踏迈入黄泉：**身入黄泉，便化作黄泉；他就是道，就是黄泉**。残存黄泉化作黄龙，王林居龙头之位；龙头一吼，黑雨生生碎裂化作黑气弥天。

## 四、老者之道：铠甲即道，其道为魔

老者道：「好一个道念化身……老夫没有道，但老夫的这套铠甲，却是有自身的道」——**魔道**。

随即施展合击：
- **风**：狂风化作天际漩涡，吸尽满天黑气；
- **雨**：漩涡内落下黑雨，每一滴皆为魔气凝化；
- **雷**：黑雷出现，黑色闪电沿雨滴窜动，雷居中、雨为节点，结成密布天际的电网；
- **电**：雷、雨、漩涡以电速向大地降临。

## 五、核心突破：凝化泉魂

王林自知「以问鼎初期战问鼎后期，除非有逆天之事，否则必败无疑」，而他的逆天之物，正是**凌天候的剑气**。

关键动作：
1. 一拍储物袋取出**尊魂幡**，放出**一亿魂魄**，魂魄不升天际而尽数融入黄泉；
2. 王林自述：「在升仙果的刺激下，我可以把黄泉道化；现在我清醒，同样可以做到**凝化泉魂**」；
3. 一亿魂魄在黄泉内凝化为一，成为**黄泉之魂**；
4. 王林身在黄泉，元神散开、道念融入，元神低吼间黄泉拔地冲出，如黄龙欲吞风雨雷电；
5. 再自眉心冲出**十三万道杀戮之气**融入黄龙，黄泉自此带煞。

> 这才是真正属于王林的黄泉：蕴含十三万道杀戮之气 + 一亿强大魂魄 + 王林此生之道。

## 六、天与地之战

黄泉与黑雷、带电雨滴、风漩正面相撞：天地色变、巨响回荡、大地龟裂，整个**远古战场**好似被掀开，其上天空亦如被生生打碎。

大地掀起时，大量个体较强、**未被虎咆炼化**的魂魄飞出。王林抖动尊魂幡化作遮天黑布，横扫吸入无数魂魄，化作黑气送入黄泉。

## 七、收尾：魔焰镰刀出世

黑甲老者面色阴沉：「这风云雷电，是我神通中最弱的一个，接下来，你会看到我这身铠甲上的道」。

- 手抹胸前铠甲，铠甲诡异蠕动，黑色魔气飞出凝聚；
- 凝成一把**散发滔天魔焰的镰刀**，魔气浓郁且似含**超脱天地的规则**，一出现四周空间即现裂纹并迅速溃散；
- 镰刀未完全实质，在虚与实之间不断转化，伴呲呲之声；
- 老者面露痛苦，此前钻入其体内的**头生单角魔影**自眉心钻出（神情舒爽），化黑烟入刀；刀如活物，一闪直奔王林。

王林抬右手，指尖凝聚**剑尊凌天候的剑气**。

## 八、背景补注：凌天候

凌天候一生嗜剑，开辟四小天地炼化为**四道剑神**，是**天运星**上与**天运子**齐名的大神通者，其剑气威力无法想象。
