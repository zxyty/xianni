# 第1374章 司墨子来临（仙逆·第九卷 云海之巅）

## 一、炎火异晶：与朱雀圣宗白色石块同源

- 暗蝎族老者取出**炎火异晶**的刹那，王林立刻认出此物——准确说是**曾见过，且在其上疗伤数年**。
- 联盟星域朱雀圣宗所在，那片燃烧星空的深处，漂浮着一块巨大的**白色石块**，是**朱雀老圣皇打坐之地**。
- 颠落之地所称的"炎火异晶"，与那白色石块**一模一样**。
- 王林由此起疑：**颠落大帝是否与朱雀圣宗有关联**。

## 二、王林对朱雀老圣皇的情感与评价

- 对朱雀圣宗本身王林没有太多感情，但**朱雀老圣皇对他有再造之恩**，此恩终身难忘。
- 老圣皇的**气节**与**数万年默默付出**令王林心生敬意。
- 王林认为老圣皇与**封界之主**属同一类人：区别在于一个守护整个**四圣宗**，一个守护**全部界内**。

## 三、回忆：老圣皇归墟前的自述（重要闪回）

> "老夫鲁云，出生在上古炼气时代……"

| 时间节点 | 事件 |
|---|---|
| 上古炼气时代 | 鲁云出生；自幼在**第四代圣皇**身边为**药童**，蒙其不弃传授炼气之术 |
| 1372 岁 | 炼气小有成就，跟随圣皇左右，见证朱雀圣宗辉煌一刻 |
| 11463 岁 | **符文族自界外而来**扰乱天地，朱雀圣宗**助仙界、战符文族** |
| 此战之后 | **第四代圣皇连同其余三大圣皇远去界外**，从此销声匿迹；临行前指明鲁云为**第五代圣皇** |

## 四、王林的推断与保留

- 推断线：四代圣皇与三大圣皇去了界外再无消息 → 颠落大帝却拥有朱雀圣宗之物 → **莫非四代圣皇当年就是来到了颠落之地？**
- 保留："**但从时间上去看，似乎又有一些不对**"——王林压下激动，久思后仍无法确定，只道"此事早晚我会知晓"。

## 五、朱雀第四次觉醒的构想：实火 → 虚火

- 若颠落之地真与四代圣皇有关，王林认为**说不定可以在此让朱雀第四次觉醒**。
- **实火 → 虚火**的过渡效果：**引发一切与我为敌之人怒火，让其而亡**。
- 即便**火之本源尚未圆满**，虚火威力与现在的实火仍是**天地之差**。
- 当年王林尚无法看透炎火异晶；如今以**朱雀三次觉醒之力**，可令这米粒大小之物**瞬息爆发毁天灭地之力**。
- 行动：右手一翻，将炎火异晶收入**储物空间**。

## 六、储物空间中的石像

- 空间内另有一具**石像**，是**朱雀老圣皇肉身所化**，保持**手臂点在眉心**的动作，透出沧桑。
- 王林神识扫过石像，沉默片刻。

## 七、探查颠落傀儡（本章主要行动）

傀儡形貌与构造：

- 外形为一**中年男子**，麻木站立，一动不动。
- **体内无血肉**，化作某种奇异**结晶**，颗粒状、很是柔软，构成肉身。
- **骨头亦为晶体**，极为坚硬，隐隐散发**无尽元力**。
- 体内弥漫**一层柔和之光**，极为坚韧，形成防护。

探查过程：

1. 王林神识轰然散出笼罩傀儡，如无数细针穿透而入，寸寸搜索；神识融入缓慢，神色渐凝重。
2. 神识欲探入柔和之光，**立刻被轰然阻止在外**。
3. 王林展开**全部神识**化作风暴，破开傀儡肉身直奔内部防护——轰的一声巨响，傀儡颤抖，王林猛地站起。
4. 结论：他的全部神识**可以毁灭这傀儡，却无法延伸进入那防护之内**。
5. 险情：若非他立刻收回神识，**防护之光会立刻爆开，令其内部一切隐秘全部崩溃**——此防护**不容外人神识进入**。

## 八、章末转折

- **整个人一震，轻"咦"了一声**（悬念，留待下文）。

# 第1288章 傀儡即修士——古神颗粒之谜与司墨子潜入颠落之地

## 一、傀儡的真相：体内有经脉

- 王林以手触碰、弥漫神识近距离横扫暗蝎族傀儡，在取代血肉的颗粒之中，看到**一条条几乎彻底隐藏、已然干枯极难察觉的经脉**。
- 结论：「**这不是傀儡，这是修士**」——是不知以何种方法将修士生生**祭炼**后，才凝聚出的傀儡之物。
- 傀儡外表：面容麻木、无丝毫表情，双眼空洞，无任何生机与灵性。
- 王林另有一处直觉：**取代血肉的颗粒感觉熟悉，仿佛曾在何处见过**。

## 二、雷图 + 定身术，强破内部防护之光

1. 王林判断秘密藏在傀儡内部的防护之光之下，唯有看清其内方可知晓。
2. **展开雷图**：右目雷光闪烁，身后雷图轰轰而出；洞府内瞬息雷霆弥漫，闪电游走、雷鸣惊天，并顺大地外传——洞府外暗蝎族人面色苍白，齐齐看向洞府。
3. 雷图之下**修为暴增、神识疯狂**，神识化作雷霆风暴直冲傀儡体内，轰击防护之光。
4. 防护之光承受不住而崩溃，但崩溃刹那不给人看清内部的机会，内部同时展开崩溃。
5. 王林低喝「**定**」——一字定身，定住天地运转、定住一切变化，傀儡全身一震、体内一切停止；**唯独防护之光只略微一缓，瞬息恢复正常并轰然崩溃**。
6. 被定住的傀儡随之全身爆开，冲击在山峰内扩散、撞击四壁轰鸣。山峰震动、尘土掀起。
   - 后果评估：若非王林有禁制在上，此山峰立刻成为平地废墟，甚至这颗**修真星**也会剧烈震动、出现裂缝。
7. 洞府外暗蝎族修士畏惧观望；**暗蝎族老者**从崩溃冲击中感受到熟悉气息，苦笑着确认——暗蝎族的那具傀儡已毁灭。

## 三、关键发现：内部的元神 + 古神颗粒的关联

- 定身的短暂一瞬，王林看清傀儡内部**漂浮着一个元神**，且**元神的样子与傀儡外貌一模一样**——几乎不必猜测即可断言：这傀儡就是修士。
- 傀儡崩溃瞬间，代替血肉的颗粒瓦解四散，令王林脑中如闪电轰过，想起熟悉感的根源：
  - 他曾在**联盟星域·妖灵之地**内见过一具**古神头颅**，头颅被切下，伤口处留有一些**结晶颗粒**；
  - 那些颗粒与这傀儡的「血肉」颗粒**极为相似**；
  - 王林**储物袋内至今仍有一个小瓶**，装的正是当年从古神头颅伤口处所得的颗粒。
- 王林隐隐抓住一些思绪，但极为驳杂，暂时分析不出联系。
- 由此升起的核心疑问：「**颠落大帝此人到底是谁？**」

## 四、下一步行动：赴落生会长老所在修真星

- 王林迈步出洞府，命令：「**蝎长老，带路，去距离此地最近的落生会长老所在修真星**」。
- 暗蝎族老者恭敬称是，飞起指引带路。

## 五、暗线推进：司墨子入颠落之地

- 地点：**颠落之地外星空**，波纹扭曲扩散，走出一名中年男子——**司墨子**，正是追杀王林而来者。目光阴沉、透出奇异之芒，一身强悍修为环绕。
- 其前方这片星域由**不归长尊会**操控。
- 情报来源：**云落大司算出王林躲在了颠落之地**。
- 司墨子的潜入方案：此地龙蛇混杂需谨慎；他当年曾来过，与**落生会第九长老·龙甲族族长**有旧，**借龙甲族身份**当可无碍。
- 明确目的：**尽快找到王林，不论生死，将其搜魂，获取「不需香火引动空门」的秘密**。
- 司墨子随即身形一晃，直奔颠落之地而去。
