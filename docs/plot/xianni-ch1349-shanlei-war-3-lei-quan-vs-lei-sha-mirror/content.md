# 第九卷 云海之巅 第1349章 闪雷之战！（三）

> 归属说明：据【世界状态须知】，王林自第1242章以一部分元神夺舍于非之身潜入闪雷族，第1260章元神出窍脱离、身份暴露；本章为王林**本体**苏醒后亲身出手，正文直呼其本名。

## 一、本体苏醒，元神退入雷域

- 王林本体苏醒的刹那，闪雷族大长老身前追击王林元神的**数百雷龙**剧烈颤抖，部分直接崩溃；其余被雷域内散出的威压压迫，不敢前行。
- 大长老原本平静的神色出现变化，追击脚步一顿，罕见地露出凝重。
- 王林元神所化**太古雷龙**冲入雷域，转身化为人形，重申宣言：**「我王林，今日来此地，收不灭之雷，灭你闪雷一族」**，随后向后退入、融入雷域。
- 大长老冷笑追入雷域。原本咆哮惊天、滚滚如浪的雷域，在其踏入刹那被无形之势威压，瞬间安静；其神识所过之处，暴躁雷霆尽数平静并环绕其身，好似尊其为主。
- 大长老浩荡传音：「这就是你的帮手么，老夫倒要看看，你这帮手，如何灭我闪雷一族」——远处边缘传来王林冷漠四字回应：**「如你所愿」**。

## 二、雷拳成型：从十丈到两万余丈

- 自星空俯瞰：一个**满头白发的青年**（王林本体）成直线向大长老疾驰，前行中右手握拳不断向前轰击。
- 每一拳落下，雷域雷霆闪电疯狂凝聚于其前方，形成巨大虚幻拳头：**十丈 → 百丈 → 千丈 → 万丈 → 两万余丈**，几乎遮天。
- 轰鸣传遍闪雷族**十六颗修真星**，族外星空亦有余音。
- 大长老察觉：「这绝不仅仅是雷霆之力，这里面还蕴含了其他的神通」。
- 王林最后一拳的构成：**全部古神之力**（眉心古神星点疯狂闪烁旋转）＋ 全身修为加持 ＋ 操控天地雷霆之威势。

## 三、雷杀镜登场与破碎

- 大长老右手拍向眉心**族印**，从中飞出闪雷族至宝之一——**雷杀镜**：青色古镜，背面刻有与闪雷族不灭之雷一模一样的闪电印记，抛出后放大为万丈巨镜。
- **能力**：一切第三步下的神通在其面前会被立刻复制，威力与本体丝毫不差，可反击一切神通。
- **品阶评价**：文中称其当列**二品次空涅之宝**，远超当年玄宝上人的**九品次空涅箭**，超越「空」之范畴，无限接近罕见的**涅品法宝**。
- 镜中复制出与王林雷拳完全一致的巨拳（大小、雷霆、轨迹皆无差别），两拳在镜外相撞、如巨人厮杀般反复轰击。
- **破局关键**：雷杀镜可复制一切神通，却**无法复制古神之力**——古神乃太古生灵、万物仙神，法宝不能亦不敢复制。王林以古神之力推进，复制拳开始后退。
- 王林双手合握、身子抬起向下猛砸，将复制拳砸回镜内；同时张口喷出**血剑**，化血光笼罩天地后刺中雷杀镜，「咔」的一声镜片龟裂，古镜轰然四分五裂。
- 王林携残余雷拳穿透碎镜，落至大长老身前。

## 四、交手结果与大长老开封印

- 大长老怒吼后退，喷出一口气息与雷拳相撞，掀起惊天咆哮。
- **两败**：王林身子一震、蹬蹬退后数步，雷拳崩溃；大长老同样后退，衣衫多处碎裂，眼露精光，体内传出砰砰之声。
- 大长老定评：**「却有资格与老夫一战，但在我面前，你，必死无疑」**，并称已很久没有施展**天人四衰以上**修为，杀王林**不用天人第五衰**。
- 大长老右手在眉心一撕，撕开族印封印，骤强修为疯狂爆发：**天人第四衰大圆满巅峰之力**。星空一颤，四周雷霆退缩不敢接近。

## 五、设定要点

- **古神之力**：源自太古生灵「古神」，标志为王林眉心的**古神星点**；具有不可被复制的特殊性，是本章破局的核心。
- **法宝品阶序列（本章提及）**：九品次空涅（玄宝上人次空涅箭）< 二品次空涅（雷杀镜）< 涅品法宝（罕见）。
- **闪雷族力量层级**：大长老自持为「第三步下第一人」；族印内封印修为，可分级解封（天人第四衰大圆满巅峰 / 天人第五衰）。

## 六、悬念

- 大长老已解封天人第四衰大圆满巅峰之力，且尚留天人第五衰未出；王林已折损雷拳、至宝血剑虽建功但正面修为落于下风，战局进入下一阶段。
