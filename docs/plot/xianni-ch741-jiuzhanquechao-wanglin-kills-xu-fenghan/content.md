# 第七卷 名震罗天 第741章 鸠占鹊巢（第三更）

## 一、鞭击乱神：战局起点

- 许封寒被鞭子抽中的瞬间「身子一寒」，脑中种种纷杂念头如洪水齐涌，在心神内化作无数驳杂存在，几乎有身体被撕裂之痛。
- 其脚步不由自主缓下，**道念**在这一刻出现不稳。他完全无法想象这是何种鞭子，为何有如此不可思议的威力。
- 王林抓住这一顿的刹那冲出。

## 二、鸠占鹊巢：道念之战

- 王林**没有临近许封寒**，而是直接踏在半空中由许封寒道念所化的**莲花（道化魔莲）**之上——此即回目「鸠占鹊巢」之意。
- 此刻王林状态：黑发无风自动，衣衫啪啪作响，目光如电，面色苍白却透出非凡气息。
- 站在莲花上=站在对方道念之上。**无任何实质性攻击，但在象征与心神打击上无与伦比**。
- 许封寒强压驳杂心绪后，本已松动的道心，一见王林立于道化莲花之上，立刻面色苍白。
- 王林一语不发，一甩衣衫下摆**盘膝坐下**；此时**黄泉之力更加剧烈**，牵引之下黄泉来临，瞬间环绕整个莲花四周。
- **结果：道念之战，许封寒败。**他喷出一口鲜血，惨笑一声，果断后退。

## 三、元化魔神：许封寒的元力神通

- 许封寒双手掐诀，体内天地元力流转凝聚，喝出「我还有元力神通——元化魔神」，对这个**连名字都不知道的敌人**已恨之入骨。
- 神通形态：双手间幻化出一道**黑色魔焰**，如烛火忽明忽暗，火心内仿佛有一头吞噬心灵的魔物在挣扎。
- 魔焰吸足元力后疯狂涨大，冒起浓浓黑烟，在半空化作**生着单角的魔物**，样子与**散魔**很相似，但没有散魔强大。
- 关键异动：魔物一出现便**回身一口咬住许封寒肩膀，将其整个吞入腹内**；许封寒如胎儿般卷身沉睡于其腹中。

## 四、王林的三段破法

1. **第三眼（红芒）**
   - 王林右手拍莲花飞出，左手按眉心直奔魔物。
   - 眉心第三眼裂缝蓦然睁开，露出浓郁红芒，红芒不外泄而凝聚不散，其状极为妖异；随后第三眼张大，红芒爆闪成**扇形铺展**。
   - 效果：魔物笼罩其中后**身体隐约透明**，连腹中许封寒都历历在目；魔物身上大量黑烟散出、惨哼咆哮几欲疯狂，腹中许封寒也从沉睡中睁眼。
   - 限制：**对元力消耗极大**，王林面色苍白，仅维持**两息**便合眼、红芒消散。
2. **定身仙术**
   - 魔爪划来之际，王林右手向前一点喝「定」，如浩淼之力降临、天地挤压，魔物身子一顿，虽立刻恢复，却给了王林绝佳机会。
3. **仙剑·斩罗决**
   - 王林右手一拍**储物袋**取出**仙剑**，抬剑迅速落下，施展**斩罗决**。
   - 剑理：天地轰隆、如同开天辟地，**斩的不是肉身、不是元力，而是天地的规则；规则一断，神通自溃**。
   - 一剑斩下时，**许立国的作用也在此刻发挥**——浓郁剑气带着**来自远古的剑意**弥漫天地之间。

## 五、结局与收尾

- 仙剑落下瞬间，魔物身无损伤，腹内许封寒也只是眼中一明，但两者**同时一动不动**。
- 片刻后魔物身上出现裂纹，一道道魔气自内散出、消失于天地；魔气散尽后露出其内的许封寒——**已然气绝**。
- 王林嘴角流下一丝鲜血，心中确认：**杀阴虚修士实在极为艰难**。
- 收剑后，王林大手向不远处地面深坑一抓，**收走其内所有法宝碎片**，身子一晃迅速离开。

## 六、要点归纳

- 本章确立王林的「非实质攻击」战法：以占据道念载体（莲花）直接击溃对手道心，属心神层面的胜负手。
- 三段连招定型：**第三眼透视削弱 → 定身仙术定格 → 斩罗决斩规则**，其中斩罗决为破神通的终结手。
- 战果：许封寒（阴虚修士）殒命于王林之手；王林受伤（嘴角流血、元力大耗）并缴获法宝碎片。
- 情报状态：许封寒至死**不知王林姓名**。

# 章节梳理：雷之仙界闭关 与 血祖认祖归宗

## 一、王林线：远遁、闭关、炼化

### 1. 战后余波与魔莲
- 与许封寒一战结束后，黄泉内的魔莲诡异地没有消散，反被**黄泉之力**生生吸入其内，**开始了道念的炼化**。
- 王林由此若有所思：
  > “道念实质所化之物，不知能不能祭炼成为法宝”
- 后续验证：把魔莲取出黄泉，此物**黯淡无光**，离开黄泉后**立刻有消散迹象**；王林观察片刻，又把它**重新融入道念黄泉内**。

### 2. 远遁与碎片大陆
- 王林判断此地战后必引来修士，神识散开、加速远遁，直至远离交战之处**数万里**仍不停留。
- 该碎片大陆**极为辽阔**，稳固程度**远超雨之仙界**——换作雨之仙界，此战足以令碎片崩溃。
- 飞行**三天**后抵达大陆边缘，见前方一座**雷光闪烁的山峰**。

### 3. 洞府闭关
- 以**仙剑**在山峰内削出洞府，钻入盘膝打坐吐纳。
- **消耗**：与许封寒一战动用了**元力斩**与**第三眼神通**，元神内元力有损。
- **补充**：此前**吞下两道半仙雷**、未炼化而存于体内，此刻抓紧炼化，缓缓弥补元神元力。
- **地利**：雷之仙界一草一木、一山一石内皆蕴含雷力，于王林如同**圣地**，修炼速度远快于外界，“仿佛如鱼得水”。

### 4. 破碎源器的猜想
- 取出**通道深坑内所有法宝碎片**，拼看之下判断这原是一件**水壶样子的法器**。
- 其上**仙力波动很是奇异**：看似仙气，又好似不是，极为古怪。
- 王林双目一凝，喃喃：
  > “莫非，这是一个**破碎的源器**不成”
- （悬念：源器为何物、碎片可否复原，本片段未解。）

## 二、罗天星域线：血祖姚空认祖归宗

### 1. 场景
- 罗天星域内，一道**血色长虹**疾掠，尽头是一颗**巨大的暗红色星球**。
- 该星球散发诡异气息，**说不出是仙气、魔气还是妖气**；且**并非静止，而是缓缓移动**。

### 2. 血祖身份揭露
- 长虹散去露出一人：**红发红眉、一身红袍、相貌英俊、约四十岁**。
- 他望星空露出**追忆的惆怅**，抱拳恭敬道：
  > “**姚洛东之子姚空，认祖归宗**”
- **此人正是血祖**——即血祖真名姚空，父为姚洛东。

### 3. 被拒与恳求
- 星球骤停，传出**沙哑的声音**（姚空祖父）：
  > “你父亲判出家族之时，不是说了，世世代代，绝不回头么”
  > “离开这里，回到你父亲当年选择的**联盟星域**，我姚家的**祠堂内，没有姚洛东这个名字**”
- 姚空暗叹：若非万不得已，绝不愿回罗天星域，更不愿动用**父亲临死时留下的一颗罗天石**；一切只为**女儿姚惜雪**。
- 姚空握拳沉声：唯一女儿**姚惜雪被人从联盟星域擒来，生死未知、命在旦夕**，“她可是我们姚家的血脉”。

### 4. 转折：长辈松口
- 沉默良久后一声沧桑叹息，那声音道：
  > “我算出她在**雷之仙界**，你去把我的**曾孙女**带回来吧，**雷之仙界已经开启**，你持我**令牌**，去**雷仙殿**，让他们送你进去，**晚了的话，即便是他们，也无法把你送入**。”

## 三、关键伏笔
1. **道念可炼宝**：黄泉炼化魔莲，或开辟“以道念之物祭炼法宝”的新路。
2. **破碎源器**：水壶形法器碎片，气息似仙非仙，是后续重大机缘/线索。
3. **两线交汇**：姚惜雪身在**雷之仙界**，血祖姚空即将持姚家令牌经雷仙殿入界——与正在雷之仙界闭关的王林形成同域预期。
4. **姚家背景**：罗天星域姚家、叛族的姚洛东、可跨星域的罗天石，血祖出身自此揭开。
5. **时限压力**：雷之仙界开启有窗口期，逾期连雷仙殿也送不进人。
