# 仙逆 第七卷 名震罗天 第744章 剑尖

## 一、王林与李元的交易达成

- 王林（本片段在雷之仙界以「许某」之名行走，即化名「许木」）似笑非笑打量李元，目光如剑；李元神色坦然，主动解释自己为何知晓此地、又为何不擅自破禁而入。
- **李元的说辞**：早年偶得一份古图，所绘为雷之仙界尚未崩溃前的一处禁制之地；他研究多年，自信只要该地尚存便可寻到，且对那里的禁制有**七成把握**可破。此番入此界即为此地而来。
- **利益分配**：李元推测禁制之地内有**保存完整的源器**，破禁之后请王林**自行选取一半**。
- 旁边的葛姓女子张口欲言，最终沉默。

## 二、抽魂为质与索取禁制玉简

- 王林答应，但随即抬手虚空一抓——葛姓女子身子一颤，体内浮出**离体三寸的魂魄虚影**，眉心凝聚柔和之芒化作光球，被王林抓入储物袋。女子面色苍白，似失去大半精力。
- 王林明言：**「我要收取一魂，作为信物」**。
- 李元表面如常，内心警惕：此人心机与自己不相上下，**抽魂不取自己而取葛家女子**，莫非看出了什么？（伏笔：李元自身或有异常）
- 王林再索要李元**隐匿身形的禁制之法**。李元取出玉简、凝神烙印许久后奉上。

### 关于那门禁制（重要设定）

- 王林神识一扫即皱眉：该禁制**与他所学明显不同**，其内**并非仙禁之术**，种种神通看不清头绪。
- **参详代价**：一旦参详，脑中便浮现**十八尊巨大塑像**，彼此交错，令参详者心神剧震。
- 王林虽看不透，却从中找到**一丝眼熟的迹象**，隐忍不发，收起玉简只说「带路」。
- 李元余光捕捉到王林那微不可查的皱眉，笃定「即便此人再了解禁制，也不可能看破我的禁制之术」；忆及此禁制的**来历**时心中低落（暗示其身世/传承另有渊源）。

## 三、各怀心思

| 人物 | 心思 |
| --- | --- |
| 王林 | 性多疑；怀疑李元话中真假参半，甚至第一次见面时便已算计好一切。暗藏极深杀机：一旦发现虚假、图谋不轨，「说不得，只有先把这二人杀了」 |
| 李元 | 以禁制包裹神识暗中传音葛姓女子：王林已知其命魂在葛家手中，掌握了她便等于掌握二人；承诺「定会想办法，把你的魂索回」 |
| 葛姓女子 | 怨恨李元——若非其禁制有问题不会引来王林，害她刚养成、方与元神沟通的**仙灵**被擒；更不忿王林只取她魂不取李元之魂 |

- 李元欲搀扶女子被甩袖拒绝；经暗中传音解释后，女子内心多少平复，对其解释有了一定认可。

## 四、碎片大陆边缘：雷之仙界的地貌真相

数日飞行后抵达此片大陆边缘：

- 边缘自高空看呈**不规则锯齿形状**，如被一双大手生生撕裂；侧面是层层泥土断层，向下延伸不见尽头，唯有无尽虚无——整片大陆**飘在虚无之中**。
- 一条条**雷光如铁链**深钉在大陆上，交错延伸入漆黑虚无，另一头必连着另一片大陆。
- **核心设定**：整个雷之仙界在无数年前崩溃，其绝大部分碎片以这些**雷光铁链**如拉丝般彼此连接锁住，方得残存。自至高点向下望，所有碎片大陆缝隙间皆有无数雷光相连。
- 耳边轰隆雷鸣此起彼伏、时强时弱，令人产生不知身在何处、身处天地之间而脚踏虚无的错觉。
- **横向联想**：王林由此想起当年在**雨之仙界**看到的**巨大掌印**，猜测无数年前的仙界曾发生某种大变故才致此等崩溃；他曾疑心是**古神**所致，但觉得诸多不同之处，遂收起心思。
- **李元的判断**：他一直密切观察王林表情，见其望见裂缝与雷光铁链时**双目有一瞬恍惚**，由此确认——此人是**第一次来到雷之仙界**。

## 五、渡雷光层之法与「剑尖」

- 李元提醒：雷光层内拥有莫大威能，**即便一些大神通修士度过雷光层也需极为谨慎**。
- **关键在葛姓女子**：她拍储物袋飞出一把**漆黑铁剑**，外表极为平凡、毫无出奇之处。
- **铁剑出现瞬间**：李元眼中闪过**一丝没控制住的激动**，瞬息即隐；他随即状似随意地瞥向王林，确认对方未注意后暗松一口气。（强烈伏笔：此剑与李元大有渊源）
- **催动之法**：女子咬破舌尖喷出一口鲜血，右手在剑上绕出一个**符文**；其**眉心浮现同样的符文印记**，二者相互辉映数息、如在**核对**，随后落于铁剑之上。剑身一颤，散开**圆形光幕**。
- **站位**：
  - 李元强忍激荡**第一个踏入光幕**，落在**剑尖**（位置奇异），面部背对王林，**露出一丝追忆**。
  - 王林在李元双脚落下的瞬间**目光一凝、盯着其双脚、似有所查、目光如电、为之动容**（章名「剑尖」之眼）。
  - 葛姓女子眉头一皱，向前一踏，落于**剑柄**之上。
