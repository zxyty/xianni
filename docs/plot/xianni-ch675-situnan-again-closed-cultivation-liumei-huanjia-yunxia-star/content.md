# 仙逆 第七卷 名震罗天 · 第675章 司徒南再次闭关

> 本章实际内容为两线并行：幻家因幻东之死封锁冉云星、柳眉备战换血立威；王林深入云霞星迷雾。章名所指的“司徒南再次闭关”未在本片段正文展开。

## 一、幻家：幻东之死的后续处置

- 幻东死亡消息第一时间传回幻家。身为**主星之上的修真大家族**，族卫被杀掀起轩然大波。
- **刚刚回归的幻家老祖**听闻后勃然大怒，但目光闪烁之后作出两项决断：
  1. **压下**族中“去冉云星灭星”的提议；
  2. **把换血的日期提前**。
- 老祖定调：“被杀族卫，是幻眉之人，此事等换血结束后，由幻眉亲自处理。”——族中明知这是老祖借机**为幻眉立威**，却无人敢反对。
- 军事部署：**冉云星外布置锁星大阵**，自此刻起**冉云星不允许任何一人逃出**，等待幻眉换血之后处理。冉云星彻底成为笼中之物。

## 二、柳眉（幻眉）：立威之战与换血传功

- 得知幻东死讯，**柳眉神色毫无变化**，视其为“一介蝼蚁”。
- 自述计划：
  - 冉云星是她**在幻家的立威之战**；
  - 师尊（幻家老祖）将**在换血之时为她传功**，代价是**老祖二百年内修为降低一阶**，助她**一举达到问鼎后期大圆满**；
  - **如何踏进阴阳虚实境界，则需她自己领悟**。
- 对朱雀星那人（王林）的心态：层次差距越来越大，“若干年后我以**修道第二步**的修为再次看见此人”，在她眼中“他，与那蝼蚁幻东，没什么区别”。
- 功法显化：“**万幻天魔道，迷幻世间万物**”。其一笑令阁楼外巡逻的家族护卫**一呆、露出痴迷与狂热**，目光与幻东惊人相似——暗示幻东此前的痴迷源自此道。

### 储物袋中的怨气之物
- 柳眉储物袋内传出阵阵波动，被局限袋内无法透出，袋中弥漫**浓郁怨气**。
- 她抚摸储物袋令波动渐小，但怨气更浓；随后**咬破指尖、以血指探入储物袋**喂之，脸露痛苦，波动方才完全消散、怨气被强行压住。
- 台词：“听话，现在你还不能出来呢。”——暗示其中所养为一具有意识、被刻意豢养的恶毒之物。

### 师徒冲突
- 幻家老祖身影凝实现身，扫视储物袋皱眉，重申先前警告：“**此物太过恶毒，莫要再碰**。”
- 老祖厉声：立刻抹杀，莫要再养；**如此行事一旦坏了问道之心，便不可能踏出修道第一步、无法度过阴阳虚实境界**。
- 柳眉沉默后只答：“师尊，柳眉心中有数。莫要再说了，好么。”老祖久望，长叹“你这是何苦”，未再强逼。

## 三、王林线：深入云霞星迷雾

- 王林身下**银龙**一晃，直奔**云霞星**。
- 云霞星外观：**暗灰色**，其上有**一层浓雾弥漫**，**神识无法投入**；雾内传出**阵阵咆哮**，如在警告一切路过者莫要踏入。
- 突入方式：
  1. 拍储物袋放出**七星剑阵**环绕身周高速旋转，形成**强劲螺旋劲力**；
  2. **收起星罗盘**，身子前踏，以螺旋劲气如锥直刺迷雾，搅动拨开前方雾气；
  3. 雾浓无尽，身后雾气立刻相融，外人路过绝无法发现其中有人深入。
- 深入过程：螺旋劲气下无半点雾气透入，但四周灰蒙看不到外界、**神识被雾所阻**，只能**凭感觉继续向下飞**。
- 结局钩子：许久后前方雾气渐薄，王林加速化作流星冲出浓雾，**眼前一幕令其双眼瞳孔蓦然一缩**——本章至此收束。

## 四、关键伏笔

- 换血提前 + 锁星大阵 = 冉云星在**换血结束后**将迎来幻眉亲自出手的清算，构成明确倒计时威胁。
- 老祖“修为降低一阶”换柳眉问鼎后期大圆满，说明幻家对幻眉的重视程度与其在家族中的定位。
- 柳眉储物袋中的怨气之物，被老祖两度警告会“坏了问道之心”，为其日后境界瓶颈埋线。
- 云霞星雾中所见（未揭示）是王林此行的直接目标。

# 第632章 云霞星望月 · 司徒南亡命

## 一、云霞星：完全废弃的修真星

**环境**
- 天空被浓雾笼罩，无阳光透入，大地一片漆黑（对修士视线无碍）。
- 大地一片龟裂，如无数张大口张开欲吞噬一切。
- 浓郁死气弥漫天地——非某一人一物所发，而是整颗**云霞星**本身散发。
- 地面龟裂处伸出一条条近乎腐烂的触手，摇曳摆动，远看如大地长满毛发；触手把一处处城池废墟包裹，令人毛骨悚然。
- 地底不断透出低吼与咆哮。

**王林的行动**
- 王林感慨「这便是完全废弃的修真星么」，随后散开神识，目的是**寻找一条金炎脉**。
- 飞行途中掠过数处城池废墟——此地昔日曾极为繁华，今已迥然。

## 二、望月现身

**征兆与遭遇**
1. 地面触手原本摇曳，忽然全部瞬间一停，随即迅速收缩、眨眼消失于地下。
2. 远处天边传来惊天动地的咆哮，一片红云在黑暗中照亮一切，疯狂冲向王林。
3. 红云之上是一只巨大凶兽：身长约千丈，**似龙非龙**，三角头颅，**说似蛇却全身生满须发**；冲击之下连天空浓雾都如被无形大手拨弄般云涌后退。
4. 王林神识中看到此兽后**面色大变**，失声道：「望月」——此兽在**古神涂司**的记忆中属于印象极深的一类。
5. 王林二话不说立刻下沉，从地面一处龟裂钻入躲避。

**望月设定（源自古神涂司的记忆）**
- 望月**并非自然生成之物**，而是**古神一族体内特有的一种寄生体**。
- 古神活着时，望月吸收古神血液而活，但**无法冲出古神之体**；有些时候甚至可被古神当作**法宝**使用。
- 古神一旦死亡，此寄生体通常随之而死；但**有极少几率**不但不死，反而能冲出古神体内。
- **古神越强，则体内望月越强**。
- 古神涂司体内的望月**已全部死亡**，因此从未出现过。

**王林的推断（存疑）**
- 此地既有望月出现，「莫非此地有古神遗骸？」
- 但又说不过去：**罗天星域**内岂能无人认识此物？一旦被那些大神通修士看到，断然不会白白放过。
- 王林身在地缝内，望着红云呼啸、望月扭动身子穿梭远去，陷入沉思。

## 三、另一线：司徒南被通缉

**场景**：联盟星域内一颗**较为寻常的修真星**，其上一处凡人帝国的京都。

- 两名**身穿彩衣的女子**踏空而入，手上各自漂浮一个**红色光球**，散发凶煞之气弥漫四周。
- 一女厉声喝：「司徒南，滚出来」。
- **司徒南**（紫袍男子，神色狼狈）自京都内闪出，看都不看二女一眼，立刻就逃。
- 二女宣告：**鸾凤星宗主已下令，鸾凤星所有附属修真星全部通缉司徒南**，「你逃不出去」。

**司徒南的反击宣言**
- 回头大喝：去和那臭娘们说，若再逼他，就把「看她风搔的那一幕」**刻在十万个玉简上，洒遍整个修真联盟**。
- 抱怨对方「追了老子近百年，烦不烦」。

**交手过程**
1. 二女把两枚光球相互撞击、相融，化作一个**凹凸有致的红色女子虚影**。
2. 虚影道「这一次，本座不会让你逃走」，向前一踏、玉手轻抬——**整个天空蓦然一按，大地颤动，天与地迅速压缩**。
3. 司徒南怪叫一声，身内**似有火焰燃烧而出**，在天地压缩的瞬间冲出重围。
4. 代价：**喷出一大口鲜血、面色苍白**；逃遁中**再喷一口鲜血**。
5. 再度放话要让整个修真联盟的修士与凡人都看到那一幕，「老子言出必行」。

**决意**
- 「惹急了，老子大不了再闭关就是」——司徒南眼睛通红，打定主意**再次闭关**，且**不达窥捏期绝不出关**。

## 四、要点与伏笔

- 云霞星的死气、地底咆哮、缩回的触手，指向地下另有主宰；望月很可能是核心谜团。
- 「古神遗骸」假说与「罗天星域大神通修士不会放过」的反证并存，本章未有定论。
- 金炎脉尚未找到，云霞星之行仍在进行中。
- 司徒南线索：与鸾凤星的百年恩怨、通缉令、**窥捏期**这一新境界名目。
- 章末为作者耳根的求月票感言，非剧情内容。

## 五、归属说明

- 本章「司徒南」为**联盟星域被通缉的活跃行动者**，与石珠内那位「自称司徒南」的断臂人影是不同叙事线；世界状态须知记载真正的司徒南已于第61章死亡，此处按原文记录其独立行动，真伪/身份关系待后文确认，故不强行归并。
