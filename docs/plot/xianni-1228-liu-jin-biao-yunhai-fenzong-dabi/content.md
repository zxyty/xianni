# 仙逆 第1228章 老夫刘金彪！！（第九卷 云海之巅）

## 一、云海星域·八阶宗派分宗大比（设定交代）

### 大比机制
- 云海星域沉寂百年后，**千年一次**的八阶宗派分宗大比临近，是云海星域之盛典。
- 并非单一宗派举行，而是**所有八阶宗派同时进行**：各分宗赴主宗接受新一轮考核。
- **胜者**：优胜分宗获主宗赏赐与重视，其内优异弟子被主宗留下成为主宗弟子加以栽培。
- **败者**：未来千年地位再度低下，直至被主宗放弃、解散分宗，余留弟子分散送往其余分宗；主宗再挑选弟子重组新分宗以保持规模不变。
- 分宗**不敢拒绝**——一旦拒绝，下场是灭宗。
- 这种残酷机制使八阶宗派实力不断攀升；当某八阶宗派下大部分分宗都成长至极强，即可被**神宗**赐予**九阶宗派**身份。传闻当年的**破天宗**、**鬼宗**皆是如此。

### 八阶宗派名录
云海星域八阶宗派共五个：**无极宗、影风派、虹途宗、应天宗、寂魂道**。
- **归元宗**、**紫道宗** → 隶属八阶**无极宗**。
- **天罡宗** → 隶属八阶**应天宗**。

### 赛制与外部干预
- 按星域阶位展开，选出**四至七阶星域**中每个星域的最强分宗；允许**越阶挑战**。
  - 例：千年前**紫道宗**越阶战六阶星域至强之宗，虽败犹荣，颇受无极宗重视。
- **九阶星域**之人到场观礼，若看中弟子可开口索要，八阶宗派虽无奈却不能拒绝；所幸/可悲的是，万年来仅**三人**被看中。
- 大比后选出最强的**三个分宗弟子**，与其余四个八阶宗派展开真正厮杀。八阶宗派不得亲自出手，九阶星域严格盘查；此战是向九阶宗派展示各宗实力的窗口，最终获胜者若能**持续万年如此**，便拥有晋升九阶星域宗派的部分资格。
- 因事关重大，三个最终名额往往**早已内定**，虽未带回主宗，却给予主宗核心弟子待遇，更有主宗之人亲自传授。

### 战绩背景
- 破天宗离去后，八阶星域共进行**十七次**大比，各有胜负。
- 万年前**寂魂道**崛起，连续**九次**夺得第一。
- 眼下为**第十八次**大比，寂魂道若再胜，晋升九阶宗派指日可待。

## 二、归元宗的存亡关口
- 归元宗无数年来**次次末流**，此次是**最后一次机会**。
- 若再失败：归元宗被解散，包括**吕烟菲**在内的全部弟子被送入其他分宗，「归元宗」一词从此不存。
- 众人无法接受，却不敢拒绝。

## 三、云海盛典与「千年一换名」的老骗子
- 盛典热闹，往往持续数月；各处坊市与交易之地云集，自然滋生从中获利的骗子。
- 其中有一人**连续数次**在盛典中大获好处：**几乎每千年出现一次，一千年换一个名字**，化名无数。
- 其选择目标极为老辣：专挑**如归元宗一般、临近被解散且毫无胜出希望的弱宗**。
- 之所以屡屡得手：受害分宗大比后即被解散，无从寻仇；碍于颜面也不会声张，即便说出也只会被人嘲笑，不如不说；暗中调查亦往往一无所获。

## 四、天罡宗遇「劫」

### 宗内愁云
- 天罡宗是**五阶星域**内的弱小宗派，主宗为八阶应天宗，历来末流。
- 大殿内三名老者商议：**一个月后**分宗大比，需传送去八阶星域；应天宗在五阶星域除天罡宗外还有三个宗派，皆强于天罡宗，「根本没有半点希望」「除非可以出现奇迹」。
- 一旦解散，虽被送往他宗，但地位一落千丈，耻辱伴随余生。

### 玉简破阵
- 突有尖锐呼啸破空而至，一枚玉简**破开天罡宗护山大阵**、穿透大殿屋顶，飘于殿内。
- 玉简散出绝强气息，弥漫全宗，连天罡宗所在大陆都隐隐颤抖；三人清晰感受到**碎涅神通**的弥漫，心神俱震。

### 「生平点名」立威
桀骜之声自玉简传出，逐一报出三人来历（皆分毫不差，甚至含三人已遗忘之事）：

| 人物 | 出身 | 履历与境界 |
| --- | --- | --- |
| 祝允明 | 天海大陆 | 七岁修道拜入天罡宗，二百余年结丹，六百余年元婴，修道数千年至**窥涅初期**，任**天罡宗宗主** |
| 罗从刚 | 天海大陆，父为**罗海涛** | 以大量丹药强行提升，**止步窥涅初期** |
| 周晨 | **周武大陆**（非天海大陆） | 半道入天罡宗，于**阳实境界停滞七百三十五年** |

- 报名号：**「老夫刘金彪——道号金彪子」**。三人从未听过此名，但凭一枚玉简竟蕴碎涅气息、又知其一切，愈发恭敬。

### 勒索条件
- 声称**三天前**有人送来三人生平，**愿付六万元晶**买三人性命。
- 自称「与天罡宗无冤无仇，虽急需元晶炼丹，却不愿做这等事」，但「若真无办法，也唯有取三人之命」。
- 开价：天罡宗拿出**六万元晶或等价之物**，此事罢休；不但不杀，更许诺**帮天罡宗免去被解散之危**。
- 时限：**半柱香**；三人惊呼「我们没有那么多元晶」。

## 五、王林归来（同一时间线）
- 地点：云海**五阶星域**至深之处的一片**蛮荒大陆**。
- 轰然一声，大陆地面颤抖开裂，**白发身影**自地底冲出——王林落地，面色苍白，喷出一口鲜血。
- 神识立刻锁定蛮荒大陆下方**往昔的七彩裂缝**：裂缝已不再七彩，观察之下当场**收拢消失**。
- 目光落在手腕**玉镯**上：不再泛蓝芒，**重新变为翠绿色**。
- 望着云海星域喃喃：**「王某，回来了」**。
- 章末点出后续主线：**「刘金彪，看我怎么虐死你」**——王林与刘金彪的因果就此结下。

## 六、看点与伏笔
1. 归元宗解散危机 = 王林（吕子浩身份）在云海星域的现实牵绊，直接绑定分宗大比这一时间节点（一个月后）。
2. 「千年换一名的老骗子」画像与刘金彪高度吻合，且其手法（挑濒散弱宗、许诺助其免于解散）与本章天罡宗遭遇完全对应。
3. 玉简所载「碎涅气息」真伪存疑——骗子以气息与情报立威，是其行骗核心手段。
4. 王林白发、喷血、七彩裂缝闭合、玉镯由蓝转翠绿，均为其此前地底经历的结果性线索。
5. 「六万元晶买三人性命」的**幕后买家**未交代，是悬置伏笔。
