# 仙逆 第八卷 联盟隐秘 第1082-1083章（节选）

## 一、天运子撕开第二道封印
- 天运子于地面挣扎爬起、喷血，眼中平静崩溃，左手在眉心狠狠一撕，**彻底撕下第二道封印**。
- 外貌骤变：由五旬中年 → 约三旬壮年，头发全部转黑；气势强过先前数倍，连天地间的远古战场都似要崩溃。
- 此为**天人第二衰**的全部修为，已是其极限；**天人第三衰他轻易不敢打开**。
- 心理：他本以为"初之规则"已是王林终极之力，未料王林拼死之中仍有更强神通，故不惜代价。
- 怒吼："王林，给老夫出来"

## 二、远古巨影降临——王林的终极神通
- 回应声自天地间传来："我，就在你的面前"，声如雷鸣数万倍，修为不足者双耳爆血。
- **一具远超八星古神的庞大身影**迈步现身，高不可测，天运子只能看到其腰部。
- 巨影落拳：狂风先至，大地轰然碎裂，众多修真联盟修士当场崩溃身亡。
- **联盟仙君癫狂**：那位修为仅次于重玄子的仙君，见到巨影后瞳孔骤缩、冷汗淋漓、身子颤抖，似欲言又止，随即癫狂狂笑、喷血后退，消失于天地间不知去向（暗示其认出了什么骇人真相）。
- 天运子应对：全身气息达巅峰，三叉戟上抛，掐诀爆发天人第二衰全部修为，化长虹迎击。
- 结果：三叉戟被巨拳一把抓住包在掌中继续落下，与天运子撞在一起；冲击如风卷残云，**远古战场幻境被彻底撕裂消散**。

## 三、战后余波
- 天地恢复乾坤：妖灵之地外星空停止旋转，星球各归其位，妖灵之地一切如常。
- 唯二变化：多了一个癫狂之人，少了众多联盟修士，留下无尽震撼。
- 天运子体内砰砰作响，自空中摔落，喷出夹杂内脏碎块的鲜血；身后为**古魔塔珈**——二人同时抵抗才保住性命，天运子沙哑道谢。
- 王林坠地翻身喷血，右目残存青光刹那崩溃，**青光盾彻底碎裂**；但手中多了一物——**天运子的三叉戟**。
- 王林已无半点战斗之力，双腿颤抖，全靠"存在了一千多年的坚定"支撑站立。
- 木冰眉震撼未消；昆虚老者目光大变，忆起木冰眉此前之语"他不是寻常的修士"。
- 四周联盟修士忌惮惊骇，无人敢上前一步；王林身影在他们眼中与那庞大身影重叠，站着便有无形威严。
- **昆虚老者的类比**：想起当年四圣宗的白虎——同样以一己之力阻拦联盟与昆虚众多强者悍然不倒，死后敌人仍久久不敢上前。
- **定性**：妖灵之地此战，王林彻底成名，踏入联盟星域强者之列；修为不是最高，但无人敢轻易得罪。

## 四、朱雀圣皇现身
- 天运子盯着王林："王林，你，必须要死"，抬起右手。
- 神通未发，星空中踏出一人——**朱雀圣皇**，中年模样，**仅为元神之体**，威严浓郁。
- 随行数十人：青龙圣宗、玄武圣宗、白虎圣宗强者，其后是密密麻麻的四圣宗族人；来时如天雷轰过。
- 一句"**谁敢在老夫面前，杀我未来圣皇**"令妖灵之地颤抖，地面众人纷纷倒退。
- 又淡道"老朋友来了不少"。天运子神色阴沉——论辈分，天运子对朱雀圣皇算晚辈，联盟星域内除不多几人外无人能与朱雀圣皇齐平。
- **试炼真相**：朱雀圣皇其实早已到场，故意不现身，借此机会对王林进行一次试炼考核，结果**非常满意**，走到王林面前端详后赞道"好好"。

## 五、太古圣器出世（1083章开篇）
- 朱雀圣皇："现在，这场纷争，也该结束了"，抬起右手，掌中多出**一块白色的石头**。
- 异象：炙热的天地气息散出，四周虚空扭曲排斥，仿佛此物不该出现在这一界。
- 石块当即融化，化作**一滴燃烧中的鲜血**浮于掌心；凡目光落于其上者，心神如吞火焰。
- 昆虚老者沉声辨认："**朱雀宗太古圣器**"。
- 血中喷出不属于世间的火焰横扫天空，天地尽笼红芒，最终凝聚于**天空南方**，化作一头朱雀之形，雀音高贵，凝视下界。
- 与此同时，青龙圣宗几位老者对视，当前一位**衣衫绣有九条青龙的老者**深吸口气、双手掐诀置于胸口、低吼一声，庞大气息疯狂爆发——四圣器接连登场。

## 二、太古圣器三式印决（关键设定）

朱雀圣皇当着王林的面讲解：

> 「我朱雀圣宗太古圣器，实际上只有三式印决，但这三式，却是足以让我四圣宗，永恒存在。」

口诀总纲：**东方青龙甲乙木、西方白虎庚辛金、南方朱雀丙丁火、北方玄武壬葵水**。朱雀宗的「天地灵三式印决」即丙丁火一脉。

- **第一式（天）——甲灵 / 庚灵 / 丙灵 / 壬灵**：四圣化四把神通法器。青龙→青色长枪；白虎→金光大刀；朱雀→赤红长剑；玄武→黑色大斧。四器下击，秒破天运子三灵与古魔星月之光。
- **第二式（地）——乙地 / 辛地 / 丁地 / 葵地**：朱雀圣皇喝「以吾朱雀圣皇意志，太古圣器融一」，四器融入赤红长剑，剑身如开天辟地般暴涨，身后浮现青龙、白虎、玄武圣器虚影。
- **第三式（灵）**：本片段未施展（三式为「天地灵」，已出天、地两式）。

**本质**：古魔塔珈观察后确定，四圣器是**太古天道之宝**。

**瑕疵**：昆虚之境老者指出四圣器并不完美，缺陷在玄武圣器——真正的玄武圣器应在**修真联盟昔日玄武圣皇**手中。

## 三、天运子与古魔塔珈的抵抗

- 古魔塔珈见四圣器眼熟，那是**古魔自身的记忆而非青霖的记忆**，遂施青霖神通「**曰月星三葬之术**」：先落星光，再降月光（凭空幻化、无来历），最后是最强一式「**葬曰**」——星空中无数光芒向一点凝聚，成千丈刺目光球（凡人见之目爆，修为不足者双目刺痛），顺着被破开的天地冲入妖灵之地，将其全部笼罩。

# 第1002章 七芒归一·借运成道 vs 太古朱雀圣器第三重

## 一、天运子的道：七芒归一，借运成道
- 天运子低喝间，将体外赤、橙、黄、绿、青、蓝、紫七道之芒逐一抽出，直奔前方化作一道七彩之虹。
- 「七芒归一，成天运之卦」——七彩之芒旋转成七彩漩涡。
- 漩涡内浮起**三块木甲**，天运子抓在手中向前一抛，木甲彼此碰撞落成卦象；掐诀一指，低喝「**借运，成道**」。
- 木甲上传出一股无法形容的气息，连朱雀圣皇的赤红长剑都为之一顿，四周众人大惊。

### 昆虚老者的评断
> 「这天运子的道原来并非天之运，而是**借天运转动，自成道海**。此人竟然以这种意念修道，更是让他修成了如此意境，甚至已然**窥及了道**。」

古魔塔珈亦倒吸口气，目露震惊。

### 王林的发现（重要伏笔）
木甲上的气息，与王林储物袋中取自**洞府葬仙深渊内、八星古神头颅伤口处的结晶**所透出的气息**几乎一模一样**。

## 二、朱雀圣器第三重「火天」
- 朱雀圣皇右手前指，**单独开启四圣器中朱雀圣器的第三重**，低喝「火天」。
- 赤红长剑剑鸣，火焰外散弥漫天空，仿若天地之火以其为根源；火焰顺着妖灵破开的缺口融入星空，**几乎小半个星域尽起浓焰**。
- 长剑内亦涌现出与木甲**相同却更强**的那股气息。
- 一剑斩下：三块木甲崩溃、七彩漩涡碎裂，天运子喷血倒退。

## 三、古魔塔珈被封印
- 长剑破一切阻碍落在塔珈头顶，塔珈怒吼中眉心黑雾凝聚，**古魔真灵**冲出，带逆天之意迎剑。
- 古魔为**古之三族之一**，乃**逆天一族**。
- 长剑内**化作太古圣器的血液**飞出，红芒落于古魔真灵眉心。真灵惨叫：「这……这血液不是太古天道——」眉心融化被穿透。
- 真灵退回**青霖肉身**，血液落在其眉心形成**鲜红封印**，塔珈身子一颤倒地。

## 四、追杀天运子未果
- 朱雀圣皇本以**元神**而来，开第三重消耗极大；**四圣宗内唯有他能开启第三重**，代价难以想象，身形愈发模糊。
- 他仍挥手令赤红长剑追斩天运子，剑后幻化**青龙长枪、白虎之刀、玄武之戟**齐齐落下——动了杀机。
- 天运子右手在眉心狠狠一撕，**生生撕开第三道封印的一半**，气息十倍暴涨，硬抗太古四圣器；再喷一口血后撕开天空遁走。
- 朱雀圣皇叹：「老夫年迈……若是当年全盛之时，这天运子逃不出四圣器的第二重。」

## 五、昆虚老者退场
- 朱雀圣皇问：「老朋友，你今日要再次与我四圣宗为敌么？」
- 昆虚老者衡量：以其修为此时出手唯一需忌惮的是太古圣器；今日圣器之威虽与当年差距很大，但若把四圣宗逼急了行**血祭器**……

# 第1085章 两年（第八卷 联盟隐秘）

## 一、余波：仙帝洞府一役的代价

- 更震动的传闻：**四圣宗再次出现**——朱雀圣皇降临，施展太古四圣器，重创联盟长老团成员**天运子**，并**封印苏醒的仙帝**。
- 四圣宗如沉睡无数万年的凶兽重新苏醒；罗天修士方面亦罕见停止一切进攻，观望消息真假。

## 二、总部封阵与星域崩解（时间线）
| 时点 | 事件 |
|---|---|
| 消息起 +2月 | 全星域大都知晓仙帝洞府之事 |
| +5月 | 谣言攀升，众人被迫接受；四圣宗传闻扩散 |
| +8月 | 联盟总部滔天大阵启动，隔绝内外，哗然 |
| 大阵启动后即刻 | 罗天全面进攻，如潮水推进 |

| 总部消失 +1.5年 | 出云国、芦笛国彼此独立 |
| 近 +2年 | 联盟总部大阵重开（短暂），发布两道命令后再度封闭 |

- 联盟修真界惯例：**凡招惹修真联盟者必死无全尸**，故众人静待反击；但总部持续沉默，众人猜测唯二解释——大爆发前的酝酿，或总部遭到无法想象的打击。
- 总部封闭期间形同死域，谣言称联盟总部已被连根拔起、再无生还者。

## 三、割据格局：四方为尊
昔日联盟之人由期望→失望→绝望，各自结盟割据星空，新宗如雨后春笋（占三五个至十余个修真星不等；原七级修真国亦如尸阴宗般独立）。

最强四方：
1. **出云国**（八级修真国，力量保存完好）
2. **芦笛国**（八级修真国，力量保存完好）
   - 二者为尊，总部销声匿迹一年半后彼此独立。
3. **天人殿**（原联盟中坚凝聚吞噬而成的新势力）
4. **地邪门**（同上）

其余零散小势力，全部存在于联盟星域**中央**。

星域方位划分：
- **西部、北部** → 罗天占据（连成一片）
- **南部** → 尸阴宗封锁自立
- **东部** → 四圣宗（两年内彻底占据，扫除一切力量，唯余**昆虚之境**）
- **中央** → 联盟残存新宗 + 联盟总部

罗天的三个选择：尸阴宗（不到万不得已不碰）、中央联盟残存与总部（首选）、神秘东部（分析应已属四圣宗，无确证；对四圣宗忌惮更甚于尸阴宗）。

## 四、联盟总部的两道命令
短暂开启大阵期间发布：

**1）追杀令**
> “杀，王林此人在罗天星域曾化名许木，道号魔道子，正品雷仙，现今则是四圣宗朱雀圣宗族人。凡取此人元神者，可获修真联盟当年仙界传承。”

**2）封命（对各新宗原联盟修士）**
- 抵抗罗天修士**一甲子**、守护总部之势力 → 可进长老团，享仙界传承一切力量。
- 不战而逃者 → 修真联盟崩溃之时，即其命魂碎裂之刻。

**3）散宝**
- 大量法宝与仙术玉简流出，为联盟无数万年积累，被昔日联盟修士获得——可见总部内危机之深。

随后大阵再次开启，总部完全封闭。

## 五、命魂：联盟统治的根基
- 昔日联盟修士的**命魂大都不在自己手中**；修为越高，联盟收取越强硬，反抗即死。
- 正因如此，修真联盟得以统治星域无数载。此次封命一出，众修士心中皆寒。

## 六、微妙平衡与再战
- 明面上罗天最强，但尸阴宗神秘、四圣宗威名、联盟残余得法宝仙术、加之命魂胁迫下的被迫抵抗，多方达成微妙平衡。
- **罗天的炎雷子与修真联盟的仇隙**不会因平衡而消解，罗天再次进军中央联盟残余，战火弥漫，死伤持续。

## 七、王林：燃烧星域中的两年疗伤
- 地点：联盟东部四圣宗内一片**燃烧的星域**深处，一块白色庞大石块之上。
- 人物：一白衣青年，相貌寻常却有仙风道骨之异质气质（按世界状态须知，此即**王林**）。
- 状态：闭目打坐**已两年**，从未离开；吐纳间鼻中涌出**两条气龙**环绕数圈后从口鼻吸入；石块内涌出大量**白色火焰**随气龙入体——用以疗治**体内元神的伤势**。
- 身后**极苍老、几乎失去绝大部分生机的老者**，两年中时而以右手点其背部；每次落指老者身颤，磅礴元力顺指而入；青年随之一震，**一头白发无风自动**，体内高温更浓。
- 老者言：
  > “朱雀圣宗，历代圣皇必须要学习的神通，名为**朱雀九玄变**，此神通传承之太古，乃当今天下巅峰的神通之一。”
