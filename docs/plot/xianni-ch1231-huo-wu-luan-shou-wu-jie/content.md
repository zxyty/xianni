# 第1231章 火蜈

## 一、局势：役灵印满载，直逼八阶星域

- 役灵印吸收了海量天地之力后已「庞大惊天」，其威力足以让一切**碎涅**修士颤抖。
- 三天前该印达到王林操控极限，王林即切断其对天地之力的吸收，随后一路轰然前行，星雾翻滚退缩，距八阶星域越来越近。
- 连续近二十天赶路，王林疲惫但双目明亮；疾驰途中运转心神、不断吞服丹药，伤势渐渐恢复。
- 本日，八阶星域已遥遥在目。

## 二、设定：乱兽雾界

| 项 | 内容 |
| --- | --- |
| 位置 | 八阶星域与七阶星域之间，无封锁线，但有一片浓密雾气层 |
| 规模 | 极为辽阔，**环绕整个云海**，故以「界」字形容 |
| 凶兽 | 多为十阶以上，深处更藏十二阶凶兽，数量极多 |
| 名声 | 云海星域极为出名的凶险之地 |
| 异状 | 神宗以不明方法使雾内凶兽轻易不外出，始终在其内吸收天地之力，仿佛雾外有界线 |

### 四条路线
- 雾界内有**四条**被开辟出的较安全道路，传说由**神宗**于无数年前开辟，并以特殊方法维持其安全，途中不受凶兽攻击。
- 这四条路是八阶宗派弟子**不使用传送阵**时离开八阶星域的必选出口。
- 除八阶星域宗派弟子、或持**指引玉简**者外，余人根本不知路线所在；欲进八阶星域，只能闯入乱兽界，不死方或有机会冲出。

## 三、王林的抉择：放弃绕路，直线强闯

- 王林当年在**蓬莱**时对此已略有知晓，并从蛛丝马迹中隐隐察觉到一条路线所在。
- 顾虑：①知晓不完整，很可能迷失雾中不辨方向；②该路线距其现在位置需绕一个大圈，耗时倍增，且不稳妥。
- 决断：沉吟后放弃取道，**以直线强闯乱兽雾界**，以最短时间进入八阶星域。
- 执行：役灵印开道，轰然入雾；临近浓雾刹那前方雾气齐齐后退似不敢接近，任掌印融入，但雾气诡异，掌印如被无尽雾气包裹吞噬。
- 后果：掌印轰鸣如湖水投石，雾界骤起大片波纹剧烈翻滚，其内传出凶兽咆哮。王林神识散开，察知雾内凶兽大量存在。

## 四、遭遇：十一阶赤红火蜈

- 前方雾中冲出一头**赤红色、约百丈、全身长满须发**的狰狞蜈蚣，口角两枚巨大钳牙寒芒森森，未近先有腥风。
- 它一出现，四周凶兽立刻停止咆哮、纷纷散开——是这一小片雾气的**王者**。
- 王林一眼看出其为**十一阶**，相当于**碎涅中期**修士；此兽明知役灵印仍敢现身，令王林惊讶。
- 它死死盯住役灵印，露出**仇恨**之色，长嘶如雷，浑身红芒化作滔天火海直冲王林。
- 交手：火海化为火焰风暴笼罩役灵印意图阻其前行；但役灵印蕴含难以想象的威力，火焰一接近便轰然倒卷，大部分甚至在掌印呼啸而过时被**生生熄灭**。王林电光火石间从其身边闪过，毫不停顿。

## 五、升级：六头同类 + 十二阶火蜈灵

- 该火蜈不甘，浑身再燃火焰，仇恨追击王林，誓要将其撕碎。
- 远处雾中数声怒吼——**六头同样赤红百丈的蜈蚣**从各方向奔来。
- 更远处一声惊天吼叫压过一切咆哮，透出**十二阶凶兽**特有的威严：一头**千丈大小的蓝色狰狞蜈蚣**自浓雾深处疯狂冲来，雾气剧卷更添其速。

## 六、支线：无极宗老者与三弟子

- 地点：乱兽雾界**第三条路线**内，四人化虹穿梭。
- 领头老者：黑白道袍、银发苍苍，双目蕴电光，一眼扫过雾气退避数丈；气息为**碎涅大圆满**，行走间天地规则信手捏来。
- 弟子三人：两男一女，修为约**净涅**；女弟子道袍难掩妙曼身躯，相貌清纯风姿迷人，双眸流盼时两名男弟子眼露狂热。
- 老者训示：你等是**无极宗核心弟子**，但凭丹药提升修为，对天道感悟不深，遑论天地规则；感悟天道最好的方法就是**生死危机**之中。遂大袖一甩，狂风卷三人沉入四周雾气，令其与凶兽厮杀中慢慢感悟。
- 老者随后盘膝坐下、神识散开密切观察，**非真正生死一线不出手**。
- 变故：听到十二阶火蜈灵的愤怒吼声后猛然睁眼、面露惊讶——「十二阶**火蜈灵**此兽尽管生存在这片雾界内，但却很少出现，今日到底遇到了什么事情」；忧心弟子冲撞火蜈灵必难逃死劫，身形一晃直接进入雾气。

## 七、王林的判断与决意

- 看出这些蜈蚣对役灵印极为憎恨，自己因而受牵连。
- 识破战术：「距离我最近的这头凶兽不顾生死过来牵制我的行动，随后又有援兽来临助战，拖延我的速度，使得那十二阶凶兽可以有足够的时间赶来」。
- 不管蜈蚣与神宗有何深仇，招惹到他便唯有死路；且若不杀追兵，其不断咆哮会彻底暴露自己方位，咆哮亦极为刺耳。
- 章末动作：「你既找死，便怨不得我」——王林前行中猛地转身，**右手抬起隔空向身后凶兽一点**。（本章至此中断）

## 八、待续悬念

- 王林隔空一点的结果、能否在十二阶火蜈灵赶到前脱身。
- 无极宗老者与三名弟子是否与王林在雾中相遇。
- 蜈蚣族群与神宗之间的「深仇大恨」来由未明。
