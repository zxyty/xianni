# 第八卷 联盟隐秘 第1074章 掌尊的力量

## 一、骄阳现身与「残夜」爆发
- 三人（紫衣、黄衣、灰衣）神通同攻之际，骄阳内显出王林身影——**王林就是那骄阳**，金光自体内散出。
- 下方大海在波光中透出妖灵之地本相，一切处于虚幻与真实之间（幻境）。
- 王林抬右手一挥，平静吐出二字：**「残夜」**。骄阳彻底升起直冲九霄，撕碎黑夜之力再无保留地爆发，化作无尽万丈阳光横扫四周；**初之规则**随之而动，充斥天地。
- 引诗：**海曰生残夜**。

## 二、连灭三分身
| 对手 | 手段 | 结局 |
| --- | --- | --- |
| 紫衣（虚空子分身） | 融合成千上万残影迎面冲撞 | 双臂化血雾，双腿与大半身躯崩溃；冲出的残影在阳光下如雪融化，烟消云散 |
| 黄衣（分身） | 身躯化巨大手掌抓住骄阳 | 被**初阳之火**（可燃烧天地一切物质）横扫全身，数息化作火海，只剩残骸 |
| 灰衣天运子（天运子分身） | 赤红色**血剑**，先后自爆右目、左目换取暴增之力 | 血剑穿透骄阳、自王林胸口穿入一半；随后被骄阳自爆卷中，仅剩一缕残念回归天运子本尊 |

- 灰衣血剑逼近至距王林不足一丈时，被撕碎的黑夜一度有再次凝聚、反吞骄阳之势。
- 王林双手生生按住穿胸血剑，后退喷血，狰狞怒吼：**「老东西，当年你就害我修炼杀戮之气险些身亡，今曰，你给我去死」**——此为对天运子当年授杀戮之气的旧怨清算。

## 三、骄阳自爆
- 王林以自身为中心引爆骄阳：天空被刮开裂缝倒卷，海水呼啸而起，地面全部崩溃，天地之力达到恐怖程度。
- 灰衣天运子首当其冲，只来得及掐诀蜷缩即被卷中。
- 残存黑夜的凝聚之意被彻底击溃；片刻后大海、骄阳、天空碎裂尽数消失，重现**妖灵之地**——天空仍赤红火海弥漫，**朱雀之音**自火海内越来越近。
- 地面众人的震惊目光证明：方才一切真实发生，并非纯粹幻术。

## 四、各方反应
- **凌天候**：身子颤抖，由「忌惮」转为「惊骇」，惊呼不知王林究竟是何修为，此等神通前所未闻。
- **天运子**：三分身被灭二、灰衣只剩残念，无数年来罕见打击，面色苍白喷血退后数步，身体元神俱伤。真正令他颤抖的是**认出这是「初之规则」——天地一切规则的初始，绝非修士可掌握**。他在王林身上连错数次，信心遭重创，咬牙道：此生算得最错的一件事，就是当年收王林为徒、给了他离开朱雀星的机会。
- **司徒南（断臂所化人影）、大头童子、浮风子**：目瞪口呆；浮风子当年经历过残夜，重见之下头皮发麻、后怕不已。
- **王巍、胡娟**：同被拉入幻境，却如被分割出来，只能观看无法援手，倒吸凉气。
- **花妃含烟**：追忆与恐惧交织，断言夫君所说的「王姓之人」必是王林；点明该规则在**封界内称「初之规则」、界外称「太初之力」**，当年**仙帝青霖**险些死于此规则之下。
- **古魔塔珈**：夺舍后从未动过的心神首次颤动，感受到一股连他也恐惧的力量（此刻微弱，成长后古魔遇之亦要惊慌逼退），失声道：**「这是掌尊的力量」**，并隐约感觉王林是青霖被夺舍前为其苏醒准备的最后一招。

## 五、修真联盟总部·九响钟鸣
- 残夜消散瞬间，总部存放重要人物命牌处、最高一层的**三个紫玉灵牌之一**砰然崩碎——虚空子的命牌。
- 钟鸣回荡全总部。联盟规矩：不讲士气，凡杀联盟重要人物者，将成为整个联盟的敌人，遭疯狂报复。
- 与罗天交战至今，此类钟声只响过数次，最多敲响**五下**。
- 本次钟声不停：六下、七下、八下……**第九下**响起，全总部修士停下手中一切，抬头遥望，惊骇轰然而起。
- 密室中盘膝的中年男子眼露悲愤，风雷滚滚间瞬至命牌处，望着虚空子碎裂令牌发出惊天动地的咆哮（下章伏笔）。

## 六、关键伏笔
1. 「掌尊」称谓首次点明，与青霖、太初之力挂钩；王林疑为青霖苏醒的「最后一招」。
2. 天运子本尊已受实伤且信心崩塌，仅余灰衣残念。
3. 虚空子之死触发九响钟鸣，修真联盟将对王林展开体制性报复；密室中年男子（风雷之力）将出场。
4. 朱雀之音逼近，妖灵之地战局未了。
