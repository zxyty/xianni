# 第1602章 你敢！

## 一、讲学十年，震动赵国

- 王林以苏道门生之名传出「十年讲学，迎天下之士」的消息，自苏城扩散至整个赵国。
- 对照：苏道当年讲学仅以一年为期；十年之说被视为「狂妄之极」。讲学之制如武林挑战，十年内天下士人随时可来问难。
- 舆论剧烈反弹：质疑的学子、达官贵人，加上赵国皇帝暗中推动，凡自认有资格者纷纷启程赴苏城。
- 苏城千里外官道客栈中众人议论：有人贬其「区区秀才功名」，有人称数十名学子拜访后折服而回。

## 二、苏府问答（讲学第四个月）

苏道府邸大门长开、十年不关。王林坐于院中饮桂花酒，四个月内已有一千余人入府；本日又有数百文生涌入，府外更有诸多马车老者与赶来的赵国文人。

| 问者 | 所问 | 王林之答 |
|---|---|---|
| 董云（王林同届秀才、当朝殿臣） | 春夏秋冬之变有何韵意 | 生于春、长于夏、病老于秋、闭目于冬，即生老病死；之所以有生老病死，「因为你还活着」；临死回想一生，逃不出春夏秋冬 |
| 落魄老者 | 才华高人一等，为何三十年落魄 | 山有高低，高山未必成峰、低山未必不成脉；「山高山低，皆是山」 |
| 人群外少年 | 世间为何有雨，雨是什么 | 「雨生于天，死于大地，中间流淌的过程，就是一生」（自陈梦中所得之语） |
| 声望极高的老者 | 为何有仙人，为何视凡人为蝼蚁 | 仙人有力、力融其心使心无限之大，故视凡人为蝼蚁；凡人若思之无限、包容天地明悟一切道理，去了敬畏，看仙同如蝼蚁又何妨 |
| 某文士 | 引「耳根得所琴初畅」之文赋 | 打断：已忘所学文赋，所悟为天地道理、所有为自己的思想，莫再问 |
| 某文士 | 苏儒一生探寻的因果论可否明悟见告 | 因果便是因果，不需明悟，只能体会、说不出口；不懂者说十年仍不懂 |
| 苏一（苏道第一门生、当朝文臣，面色阴沉） | 你能否做到视仙人为蝼蚁 | 「有何不能」 |

- 「雨之一生」一语令院外马车中大半老者动容，数人下车遥拜后离去，认可其大儒之名绝非浪得虚名。
- 仆从大福数次奉上桂花酒，此时已不心痛。
- 越来越多文生一拜而去，目光透出前所未有的尊敬；但涌入者更多。

## 三、杀局：皇帝与两名道袍青年

- 府外酒楼中，一名华服中年男子（赵国皇帝）冷视王林，如见当年的苏道，身后有诸多侍卫，身旁坐着两名闭目道袍青年（仙修）。
- 皇帝之言：「苏道死了，他也一样要死，我赵国，不需要大儒。但他不能死在我等凡人之手」，许诺满足仙长一切要求。
- 道袍青年之一孤傲回应：「区区凡人，你要他死，他便死了。」

## 四、转折：一声「你敢」

- 王林答苏一「有何不能」出口刹那，那名道袍青年睁眼化作长虹破空，掠过人群直扑王林，持剑寒气逼人，喝「无知蝼蚁，不敬仙人，需以死论罪」。
- 下方书生学子骇然齐齐跪下，惊呼仙人降罚。
- 王林不怒自威、毫无畏惧，仰天低吼「你敢！」——浩然之气自体内轰然而出，化作无形威压笼罩天地；天地轰鸣，无数雷霆游走、闪电交错，朗朗乾坤瞬间风云色变。
- 反应：跪地书生神色剧变；酒楼中赵国皇帝酒杯一颤、面色苍白；另一名道袍青年猛然睁眼，露出「不可能」的骇然与难以置信。

## 五、要点与悬念

- 王林此时在凡人赵国以「秀才/苏道门生/大儒」的凡俗身份立世，饮酒论道，境界与修为对凡俗世界隐而不彰。
- 「浩然之气」在此以书生之气与雷霆天象结合的形式显化，是本章核心异象。
- 悬念：袭来的道袍青年结局未定；赵国皇帝的杀局与另一名仙修的下一步反应留待后文。
