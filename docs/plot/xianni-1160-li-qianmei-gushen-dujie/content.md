# 第1160章 李倩梅（第九卷 云海之巅）

> 本章王林以归元宗故人「吕子浩」之名行事（自第1063章起，身份由吕烟菲奉上），归元宗修士称其「师叔祖」。以下「师叔祖」「吕子浩」的言行均归属【王林】。

## 一、瞬杀八阶凶兽，震慑归元宗

- 王林一脚横扫，**瞬杀八阶凶兽**。
  - 八阶凶兽战力可与**净涅大圆满**一战，但并非修士，无法施展法宝，只能凭其所感悟的天地规则幻化神通。
  - 能瞬杀八阶凶兽者，**即便在云海星域也足以踏入强者之列**。
- 李向东、吕烟菲及另外两名老者目睹此幕，此前从未蒙面的「师叔祖」立刻充满神秘与威严；纵有身份怀疑，此刻也毫不犹豫地选择忽略。
- 李向东与二老心神振奋：「有这样的大神通修士在我归元宗，归元宗称霸**五阶星域**，指日可待。」
- 伏笔：他们并不知道，不久之前还有一名**云海六阶星域的碎涅修士**死在王林手中——若知，震撼当更重。

## 二、屠戮凶兽群

- 王林并不理会四周修士心思，全身缭绕八阶凶兽的**生机**，不断融入体内与**本尊血肉**融合，用以**抵抗肉劫**。
- 群兽贪婪尽消、恐惧代之，一哄而散，欲飞出莫罗大陆返回星域。
- 王林身化「收割生命的死亡之光」，一步临近、一冲穿透，每次闪烁便有一头凶兽崩溃；更追出莫罗大陆，在陆外星空中展开屠杀。
- 凡被**古神血晶**吸引而来的凶兽，尽遭屠戮。屠杀持续**一炷香**，莫罗大陆外**数十万里内再无凶兽**，仅少数带着恐惧记忆逃走——终生难忘莫罗大陆上有一修士「如天神一般」。
- 莫罗大陆**防护层修复重开**，表面一切如常，唯有归元宗修士心中的震惊永恒存在。

## 三、南苑药院与三日闭关

- 归元宗南苑药院外，李向东、吕烟菲与两名老者恭敬久候，毫无不耐。
- 南苑修士已全数迁往其他三院，除**孙芸**随吕烟菲外，南苑内再无弟子。
- 院内药草皆为王林带回，经孙芸确认后李向东神色激动。
- 院子地底深处：王林盘膝而坐，对面**本尊化作常人大小**默默吐纳；本尊身体已恢复大半，唯胸口一块血肉仍在生长，与**一损二劫**做最终抵抗。

## 四、渡过第一损二劫，古神第六星

- **三天后**，本尊胸口光芒闪烁，**肉劫消散**，成功度过**古神三损七劫中的第一损二劫**。
- 本尊睁眼，目露明亮之芒，无形威压散开；**皮肤更粗糙、骨头更坚硬**，至此**真正成为古神**，而非往昔的不完整。
- 吞噬无尽**元力**与**奇异星雾**后，度劫的本尊**修为大增**。
- 眉心**五个星点旁再现第六个星点**，虽尚模糊未完全成型，已令王林狂喜。
  - 古神每增一星难度极大：王林**一千多年**历经艰辛、多次奇遇，才使本尊达到**五星**。
  - 关键意义：**六星古神可从体内衍化出属于自己的「望月」**。
- 本尊留在地底继续盘膝吐纳、吸收天地之力，**开始衍化望月**；王林离开地底，现身药院屋舍内。

## 五、战力评估与下一步决断

- 王林自评：本尊渡劫成功为其在云海星域再添一份实力；凭**与本尊合体后的神通**，杀**碎涅初期**修士已不似之前艰难。
- 存疑：「碎涅修士初、中、后及大圆满之间差距极大，不知以我本尊合体之后，与**碎涅中期**修士之间孰强孰弱。」
- 药院内清风拂面，防护罩开启后天空蔚蓝、白云片片。
- **决断**：望着院内药草，王林决定**以最快时间，凭云海星域特有的炼丹之术提高自身修为**。

- 望月的衍化结果、云海炼丹之术的具体运用，均为后续伏笔。

# 第1078章 丹方风波扩散与九阶破天宗李倩梅奉命寻玉简

## 一、归元宗药院：王林安置与丹方研究

- 王林（本章以归元宗故人「吕子浩」之名行事，自第1063章起，身份由吕烟菲奉上）在药院外唤五人进来，声音平静却蕴含无形威严，众人紧张恭敬入院。
- 孙芸跟随吕烟菲入内；李向东等人一进院便恭声「参见师叔祖」，为「不知师叔祖回归、怠慢」请罪。
- 简短交谈后众人告退。孙芸不再居住药院，随吕烟菲迁往南部阁楼。
- **南苑全境被划为禁区**，设禁制，禁止任何弟子踏入。
- 王林吩咐送来大量丹方与高阶丹药：丹药已入不了他的眼，配合丹方略作观察后，只留丹方，丹药让人全部拿走。此后他整日研究丹方。

## 二、外界：因施洛刑之死引发的星域级搜寻

- 距莫罗大陆遥远之处，因施洛刑之死（第1068章）展开一场严密搜寻。
- **六阶星域**各宗派修士散布整个**五阶星域**，逐一排查漂浮大陆，部分甚至下探五阶以下星域。
- 随六阶星域举动，**玉简与丹方**的消息渐渐传开：惊动**七阶星域**，更引起**八阶星域**注意。
- 七、八阶星域各有长虹飞出，直奔五阶星域那处被封锁的**蛮荒大陆**。

## 三、云海九阶星域：星雾、凶兽与北斗七星

- 云海星域最深处星雾极浓，**碎涅修士神识展开也仅能环绕五十丈**，贸然闯入如同封眼，极易迷失。
- 此处栖息云海星域最强凶兽，有的以神通与星雾融为一体，**潜修天道规则**；修士不招惹则不主动攻击。
- 星雾内仅有的几颗修真星如同外来者，却蕴含足以惊天动地之力，令强大凶兽也极为忌惮、轻易不靠近。
- 此即**云海九阶星域**。其边缘有**七颗修真星成北斗排列**，彼此层层防护牵引，不分彼此。
- **北斗之首**的修真星：数百万层防护之下，大地中一片草原，草原中竖立高耸入云的建筑——一尊**修士指天怒目、似咒骂苍穹的雕像**，威严笼罩四野。草原安静，仅有少量小灵兽出没。

## 四、李倩梅：云海星域的传奇

- 一道长虹自天边而来，其内女子相貌秀丽，**一头蓝色秀发**——整个云海星域独此一人，即**九阶破天宗李倩梅**。
- 修行履历：
  - 5岁修道 → 7岁筑基 → 19岁结丹 → 26岁元婴 → 37岁化神 → 45岁婴变 → 61岁问鼎；
  - **百年修道即成阴虚巅峰**；
  - 破天宗倾全力栽培，修道四百余年达**窥涅圆满**；
  - 再三百年成**净涅中期**；
  - 又历练五百多年，成为破天宗碎涅修士中**年纪最小**的一位；
  - 至今修道**一千二百余年**，修为**碎涅后期**。

## 五、雕像内的老者与指令

- 李倩梅于雕像前现身：「弟子李倩梅，参见师祖。」
- 雕像内传出沧桑而带惆怅的声音，天地波纹回荡：
  > 「**司马墨的玉简出现**，你去一趟五阶星域，如有可能，就把获得那玉简之人找到，与玉简一同带回。」
- 李倩梅恭敬称是，转身离去。
- 雕像内部盘膝坐着一个**白发苍苍、全身多处溃烂**的老者，眼中露出追忆，许久摇头长叹：
  > 「**司马师兄，或许当年，是师尊错了。**」

## 六、要点与伏笔

1. 王林手握司马墨玉简与丹方，已成五、六、七、八阶星域共同追索的焦点，而他本人正安坐归元宗药院研究丹方。
2. 追索层级持续升格：六阶 → 七阶 → 八阶 → 九阶破天宗亲自派人。
3. 破天宗与司马墨渊源极深：雕像内老者称司马墨为「司马师兄」，并暗示当年师尊之决断有误，为旧事翻案埋下伏笔。
4. 李倩梅（碎涅后期）是目前追索者中明确点名的最强战力，其目标是「人与玉简一并带回」。
5. 云海九阶星域的空间特征（浓星雾、遮蔽神识、潜修天道的凶兽、北斗七星修真星群）首次系统交代。
