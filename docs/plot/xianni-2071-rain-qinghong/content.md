# 第2071章 雨中青虹（第三更）

## 一、轮回之悟：轮回是天，也是一面镜子

王林走在天幕上，脑海反复浮现周茹、司徒南与疯子的身影，推进其对「轮回」的领悟：

- **轮回是天**（先前已得的结论）之外，还有更多含义。
- **疯子的经历或许不是轮回**，但周茹与司徒南的选择却是轮回：他们没有选择离去，而是选择融入其中。
- 原因在于牵挂：**周茹不舍这一世的父母与亲情；司徒南不舍跟随他一辈子的军兵**。如司徒所言，每一次轮回都是一世，都存在诸多牵挂，怎能说断就断。
- 由此得出：**轮回的力量，可让人在其内无法自拔，亦或是不愿自拔**。
- 最终明悟：**「轮回，是天，也是一面镜子。这镜子里的自己，就是轮回。」**

王林目中茫然散去、露出清明，其轮回之道在周茹、司徒南两处渐向圆满接近。随后他想知道「其他人的选择又是怎样」，遂前去遍访。

## 二、遍访洞府界（七道宗门）故人转世

### 1. 北州·大头（洞府修士）

- 地点：仙族大地北州，一处山峦密林中，下方官道蜿蜒如一线天；多年前此地出现洞府后再无野兽敢来。
- 洞府内以无数夜明珠映照、极为奢华，却因过分安静而透出冷意。
- 主室内盘坐一名修士：年纪不大、形似侏儒、头颅硕大、身子瘦小，神色阴沉，人称「大头」。
- 王林现身唤其名，大头毫不迟疑吐出一条绿光狰狞蜈蚣（放在元神内炼化，寻常高他一线的修士也会被缠住）。王林右手一点，蜈蚣即凝固半空；大头连对方施展的是什么神通都看不出，大惊。
- 大头凄厉嘶吼「**马涛**，你非要赶尽杀绝不成」，全身雾气扩散欲逃 → 说明其今世与「马涛」结仇、正被追杀。
- 王林一怔于「马涛」之名，随即一点晶光穿透雾气印入其眉心，**唤醒前世记忆**。
- 王林虚空一抓，卷来四周山脉天地之力凝聚成一柄小剑（天地之力凝聚、王林道术所化，可谓至宝），刺入墙壁留下；又化出大量丹药注入葫芦置于一旁，转身离去。
- 雾气散后，大头一脸复杂茫然走出、发呆半晌，看到那柄剑与丹药葫芦，落泪轻唤「**主人**」。

### 2. 北州另一洲·红衫子

- 一行数位修士化长虹在天空呼啸而行，一道晶光自远处而来、在众修士错愣中消失。
- 无人察觉晶光落入人群中一名**红袍童子**眉心。
- 童子全身一震，封尘记忆缓慢苏醒；数个时辰后众人在山峰吐纳休息时，其迷茫散去化作复杂与恍惚，望天微笑：「**我是红衫子**」，内心激动地望着这片大地。

### 3. 东州南尼洲·申豹

- 王林当年曾一略而过的南尼洲内，有一规模很小的宗门，仅数千人，山门灵气不浓。
- 背景：**仙族几位大天尊与仙皇发布圣旨，令整个仙族宗门全力备战**，局势流转，小宗门无法平静，必须依附大宗才能存续，否则难在数百年后的**仙古大战**中传承下去。
- 宗主**申豹**修为不俗，好不容易爬到一宗宗主之位，不愿放弃；但依附对象的不同选择后果同样严重，宗内长老意见相左、已有分裂迹象，故内心焦虑。
- 这一天，一个身穿白衣、一头白发的青年自山下一步步走上此宗——正是**王林**。王林找到申豹，数个时辰后离去。
- 王林离开时，申豹立于大殿外望天，目中迷茫许久，最终**迷茫慢慢消失、化作坚定**。

### 4. 总结：故人尽访

- 这段时间内，王林几乎见遍了所有洞府界故人。
- 处理方式两种：**有的人他直接为其解开前世记忆；有的人他把选择的权利交给对方**。
- 但无论结果如何，王林都会**留下保命之物**，以了却那一段洞府同源之情——这些人都属于那个名为**七道**的宗门。

## 三、日月宗与青虹（红蝶）

### 宗门

- **日月宗**：天方洲最强宗门，门人数十万，为天方洲第一宗，亦是**东州九宗十三门**之一。

### 青虹其人

- 千年来日月宗天骄辈出，无一人及得上名为**青虹**的女子，其天资堪称万年难寻。
- 数百年前成为日月宗弟子，短短数百近千年即成**第三步大能**，达**空涅巅峰**，似只差一线便可成**空灵之修**。
- 日月宗全力栽培，视其为珍宝；宗内被称为**圣女**一般，绝美容颜使其成为弟子爱慕对象。
- 性格冷漠，惊鸿一般，数百近千年从未有择道侣之举，反而愈发被仰慕；长老子嗣与自觉有资格的弟子追求从未间断。

### 大长老

- 日月宗一位几乎常年闭关的大长老，具**尊者修为**，据说已拥有**天尊之力**，却始终未去闯**天尊涅之地**。
- 此人**亲自收青虹为徒**，每隔几年出关一次提点其修为，甚至曾将其带入自己的闭关之地一同闭关修行。

### 雨中出关

- 这一日青虹出关，外面乌云弥漫、雷声轰轰，雷声令她无法静心，似有事将发生。
- 她立于自己洞府外，望乌云、望山下雨中姹紫千红，目中迷茫。
- 一只美丽蝴蝶迎着狂风自远处飞来，绕其飞舞。她**喜欢红色**（宗门皆知）**与蝴蝶**（无人知晓）。
- 与其他转世之人一样，她梦中时常有朦胧存在，总觉得自己**不属于这一片天地**，这种感觉使她的冷漠与众不同。
- 雷霆轰隆、雨水如帘，她一身红色衣裙远看如同红蝶，与身前蝴蝶似要在山风雨水中随风而去。
- 身后传来一个柔和的声音：「**红蝶**」——即王林寻至并唤其前世之名。

## 四、关键线索与伏笔

1. 「轮回是镜子」是王林轮回大道趋于圆满的又一块拼图。
2. 「马涛」为大头今世的仇敌，尚未展开。
3. 青虹＝洞府界故人「红蝶」的转世身，且已修至空涅巅峰、拜尊者级大长老为师，是王林所访故人中修为最高者之一。
4. 仙皇与大天尊已下备战圣旨，**仙古大战**在数百年后爆发，构成本卷的时间压力。
