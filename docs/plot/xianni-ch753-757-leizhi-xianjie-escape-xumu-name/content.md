# 仙逆 第801-802章：破阵而出与雷之仙界冰封

> 世界状态须知：本片段主角以自创化名「许木」行事（自第661/669/711/731章沿用），所有「许木」的言行归【王林】。

## 一、气势压场：逼退六名雷仙殿使者（801）
- 上百冲入此地的修士齐喝「让道」，声浪如利剑，连窥涅修士都为之心神一震。
- 王林一声大喝后踏出一步，身后众修士同步踏虚，砰砰之声如踏碎天地，直奔阵法外的六名雷仙殿使者。
- 六名使者虽修为高绝、单人可屠杀其中大半修士，却在此前的死战冲击下胆怯：他们从未见过身子崩溃、头颅飞出仍要咬敌一口的问鼎修士，更未见过如此多人齐选自爆同归。
- 冲阵者中还有数名阴虚修士、两名阳实修士，以及甫一出手便杀一人的王林——骇然之下六人连退，直至传送阵中心，喊出「开启阵法，我们走，他们疯了」。

## 二、阵中厮杀
三人盘膝掐诀开阵，余下三人迎战：

| 对手 | 手段 | 结果 |
|---|---|---|
| 使者甲 | 喷元神精血放出金锁，施「锁元封神」，金锁崩为无数金光射向王林与众修士 | 王林掐诀引黑风化黑龙，阴风吹散全部金光；黑龙落下缩聚成金锁被王林一口吞下，以元神雷威包裹炼化，评「此宝，不错」 |
| 使者乙（放金锁者） | 拍储物袋放三面小旗，紫气成漩涡反震王林双指 | 王林挥手，手背兽骨图案蠕动放出灰光自其脚下升起，再以定身术定住，一脚踏碎其肉身；三面小旗卷元神飞出，求饶「莫要杀我，我以重宝」未果，被昆极鞭抽落，旗与元神一并被元神之气化禁制封印收入储物袋 |
| 使者丙 | 被众修士围攻 | 银光（阳实修士）一击胸口溅血，元神卷储物袋欲逃，被数十名问鼎修士红眼扑上并遭银光紧追，彻底身亡 |

## 三、破柱与传送（801 收束）
- 盘膝三人以「崩溃传送阵」为代价倍增开启速度，环形波纹冲天，三人化光珠带恶毒目光消散离去。
- 最后一名缠斗的使者退入光柱；王林一步迈出，双指成剑落下**斩罗诀**斩在光柱上，光柱崩溃，柱内四名雷仙殿使者面露恐惧、身影撕裂崩灭。
- 阵内波纹更浓，第二道光柱凝成，四周修士争相冲入。
- **申公虎**：全程唯一未出手者。雷仙殿对他有提携之恩（虽因献出道魂遭雷仙殿孤立），无法出手；且早在进入传送阵十里之内时便以神通改变相貌以避麻烦，此刻同样冲入光柱。
- **西子凤**：入柱前回头看王林，抿唇欲言又止。
- 阵法边缘崩溃疯狂蔓延至光柱外围，此番传送已超出传送阵极限。

## 四、「许木」之名（801 章题眼）
- 王林入柱时心念：传送阵此刻崩溃是好事——即便不崩，他也打算在传出一刻毁阵，使传出之地生变，从而避开直接出现在雷仙殿。
- 化作银光的阳实修士高呼：「前辈，请告知名讳，大恩永不忘」。
- 王林答二字：「**许木**」，身影随光柱消失。西子凤目光一亮，芳心默念此名。
- 柱内所有修士几乎同声轻道「**大恩，永不忘**」——此名此生未忘。

## 五、雷之仙界的终局（802 陌域篇开篇）
- 光柱消失刹那，其所在的碎片大地被四周吞噬而来的**千丈环形裂缝**吞没，半点不留。
- 裂缝中阴风大作，越来越浓、连绵成片，横卷整个雷之仙界。
- 雷之仙界残存碎片已**不足二十处**，阴风中黑色冰晶咔咔蔓延，将这不足二十处碎片全部冰封，黑晶透出诡异阴森。
- 连接碎片的**雷光铁链**自边缘起冰凝延伸，尽数化为冰链。
- 未及离开的修士被当场冰封，保持飞行、挣扎或闭目待死的姿态；身子已崩者，碎肉与血雾亦被刹那冰封。法宝无一幸免——某碎片上一名被冰封的中年修士，身前飞剑凝固半空。

## 六、要点
- 王林此役战果：夺得金锁法宝一件（已开始炼化）、三面小旗+一名使者元神（封印收袋）；亲手灭杀使者两名，另以斩罗诀连柱斩杀四名。
- 「许木」自此在这批幸存修士中成为传奇之名，为后续声名铺垫。
- 雷之仙界至此实质毁灭，故事转入「陌域篇」。

# 第803章 上仙（第七卷 名震罗天）

## 一、雷之仙界的终局

- 冰封定格：部分修士在施展神通法术时被阴风吹中，连人带术法凝固于黑色冰层内，冰层内犹有法宝之光微弱闪烁。
- 这些点点法宝之光，成为冰封后的雷之仙界中**唯一的光亮**，「好似繁星，看去美丽，但若接近，却是迥然」。
- 冰封之后，雷之仙界的**崩溃停止了**，只留黑色冰封作为此地变故的见证。

### 神秘剑光虚影

- 一道剑光虚影在冰封的雷之仙界内一闪而过，四周冰层对其毫无影响。
- 虚影形态：一把长剑，剑穗飞舞；剑尖之上站着一人，身子同样虚幻，平静望着前方，**嘴角带着微笑**，一闪即连同剑光消失在远处尽头。
- 身份未明，本章未点破（存疑，待后续印证）。

## 二、「许木」名震罗天

### 逃生者归返

- 罗天星域四大域内，**上百处同时**出现环形波纹（时间上没有先后）。
- 每道波纹中走出一名修士，皆是劫后余生、望着星空恍惚。
- 他们各自回归家族，雷之仙界内发生之事随之在罗天星域传开。

### 被反复传颂的四件事

1. 在雷之仙界大门前，白发怪人吞噬修士之际，挺身而出、力抗不败；
2. 危机之时以莫大神通驱散众修士，使其免于死亡；
3. 雷之仙界崩溃中给人求生信念，以百丈碎片救下众人；
4. 带众人冲入雷仙殿传送阵、轰击光幕杀入，一声「让道」无人敢挡，在传送阵坍塌瞬间带众人离开。

→ 这个名字：**许木**（按【世界状态须知】，「许木」为王林所用之名，本章言行归属王林）。

### 家族联合的政治算计

- 上百修士分属**数十个修真家族**，有大有小，联合起来已是一股不容小看的力量。
- 闯雷仙殿禁地传送阵是**可祸及全族**的险事，且瞒不住，雷仙殿必已知晓。
- 两条路：等雷仙殿杀伐，或自断逃出族人之命。但这些族人皆是各家**嫡系与未来尖端力量**，杀不得。
- 遂选择第三条：联合高调宣扬此事、大力推崇「许木」之名，**以理去争**，求一线生机。
- 结果：雷仙殿罕见地对传送阵之事只字未提，好似此事根本不存在——闯禁地之罪被成功抵消。
- 副产品：「许木」之名被彻底宣扬开，被救者口口相传下无限夸大，**最终几乎无人分得清许木究竟是什么修为**。
- 各家掌位者详询族人后，尤其听闻与白发怪人一战的种种不可思议神通，心中极为骇然。
- 「许木」在罗天星域成为一场风暴，却**再无人见过他**，如同凭空消失，成为谜团。

## 三、罗天西域与「陌域」设定

- 罗天星域分**东、西、南、北四域**。
- 西域：辽阔星空，大片星云璀璨、形态奇异，令人望之沉醉。
- 唯西域**凶兽最多**，修士反倒比其他三域少。
- 约**七成**的西域是修士无法踏入之地，星空本身即极危险，存在远超修士认知的凶兽——此地被罗天修士称为**「陌域」**。
- 唯有大神通者为取炼丹/炼宝材料才会进入，且只在外围移动，因**陌域深处有让人恐怖的存在**。

## 四、王林落入陌域中心深处

### 到达与初步交锋

- 位置：罗天西域·陌域中心深处（虽非最中心，但相差不远），一片黯淡无光、伸手不见五指、静得可怕的星空。
- 黑暗中出现晶点 → 骤然刺目 → 照亮四周 → 显出一片片**怕光的雾层**，雾气迅速收缩后退，形成方圆千丈的空白地。
- 晶光放大至十丈成环形波纹，其内浮现虚影凝实——**王林**现身。
- 波纹一消，千丈外雾气立刻蠕动，欲吞噬空白地；王林汗毛竖起、危机感涌起。
- 应对：**元神雷威**一动，运转全身双手掐诀，双手凝出两颗极亮雷球（伴闷雷之声）。雷光一出，已吞噬至百丈的雾气如遭攻击般剧烈蠕动、退回千丈外。

### 雾气的诡异

- 王林判断：「这雾气有些诡异，好似其内有生命一般。」
- 他**不敢散开神识**——隐约感到元神一散会引起雾气剧变，感觉飘渺却很深。
- 掷出右手雷球开路，雾气刹那分开通道，王林紧随其后深入。
- 飞行**三天**，雷球之光已黯淡，前方仍是无尽雾层，毫无变化。

### 融合天地脱困

- 王林平静心神，尝试融入天地：
  - 第一步落下，脚下现出圈圈波纹；
  - 第二步波纹更多，找到融入天地的感觉；
  - 第三步右脚落下，整个人消失在原地，只余波纹回荡，旋即被雾气吞没。
- 关键设定：这是他**有史以来最快的一次与天地融合**，全**归功于炎雷子**——此刻王林的元神乃至肉身，与天地之间的融合都已极为紧密。
- 融合时他心中所想的目的地是**自己的修真星**，却立刻感觉撞在一处壁垒之上，身子不由自主被从天地间挤出。

### 无限肉壁

- 落点：雾气的尽头（此处雾气明显稀薄不少）。
- 前方三丈外是一片**暗红色肉壁**：太大，延伸之下一眼看不到边缘，抬头上方亦尽是肉壁。
- 王林当即明白：融合状态中撞到的**壁垒就是这无限大小的肉壁**。
- 肉壁并非静止，而是蠕动，其上不断浮现、游走一个个鼓包。
- 王林顺壁上飞的刹那，肉壁剧烈蠕动、裂开无数缝隙，**喷出带巨大冲力的黑雾**，黑雾融入前方雾层——外界雾气之源即在此。
- 喷雾持续约**半柱香**后渐缓、终止，裂缝缓缓收缩。
- 王林果断从身边一处正在收拢的缝隙钻入，身后裂缝随即合拢并追着收缩。
- 通道狭窄但不长，王林极速前冲（几乎拉出残影），片刻即抵尽头，冲出出口。

## 五、肉壁之内：悬浮大陆与符文男子

- 出口之外并不黑暗：天空之上零散星光密密麻麻，照耀此地。
- 前方是一片**飘在半空中的大陆**，无边无际，一眼看不到尽头。
- 远处有一名**布衣男子**：
  - 相貌很是寻常；
  - 脸上有**符文印记，仿若枝条一般扭曲**；
  - 手持一件奇怪法器，形似长嘴水壶但大得多，几乎**半人多高**；
  - 见到王林冲出，发出惊呼，眼中露出恐惧、迅速后退，视王林如洪水猛兽。
- 章末悬念：此界为何？其人为何见王林即恐惧？（呼应章名「上仙」）

# 第803-804章 仙遗族（仙选族）与玄阴鼎

> 第七卷 名震罗天 · 第804章 章名「仙选族」

## 一、追擒符文男子

- 王林发现一名男子：体内**没有半点灵力**，仙力更不可能存在，却能飞行——绝非寻常。
- 男子脸上的**符文印记**让王林有一种极为熟悉的感觉。
- 男子后退时，符文蠕动延伸至眉心，浮现一株**七叶植物**；叶片伸展，奇异之力笼罩全身，速度倍增，闪烁如瞬移消失。
- 王林当即认定：**「仙遗族」**。
- 破解手段：右手掐诀，体内**元力**运转，虚空一拍，元力弥漫融入虚无，形成大片元力波动搅乱空间 → 前方半空扭曲，瞬移者身影被迫显形。
- 王林一步踏出与之面对面，随后虚空一抓，无形大手将其拽回身边。
- 王林身后的裂缝在他冲出后渐渐彻底收拢（退路已闭）。

## 二、仙遗族现身与「上仙」称呼

- 大陆上飞出**上百道长虹**，百丈外化作身穿粗布衣服的身影，**全为男子、绝大部分中年**，眼中隐藏畏惧。
- 其脸上、外露四肢皆有符文印记，**眉心有植物虚影**闪烁，多数叶子收缩、看不出具体几片（暗示叶数=等级）。
- 一白发老者出列，恭敬称王林「**上仙**」，目光直勾勾盯着王林右手的兽骨图案。
- 老者一眼道破：「**八品上仙**，下民可以认出。」——说明上仙分品阶。
- 王林内心震惊但不动声色（千年修道的定力）：在仙遗族口中，「上仙」并非单纯尊称；结合此前**藏品阁**的见闻，不容他不深想。
- 王林推断：**这些人并不知晓仙界已经崩溃**，若真如此，他们定是在无数年前便已存在于此。

## 三、逍遥仙王与子母道枯

- 王林问「有多久没有仙人来此了」，老者神色一暗：自**逍遥仙王最后一道仙谕**落下后已过去很多年，具体时间已无法计算。
- 王林抬起右手，露出手背**兽骨图案**。老者激动认出：这是**逍遥仙王的法宝「子母道枯」**，并推断王林定是逍遥仙王亲近之人，此番来此「可是为了**玄阴鼎**」。
- 王林未答，心中疑云：「逍遥子，仙遗族，还有那什么玄阴鼎——这里，到底是什么地方？」
- 老者殷勤款待：称**灵仙果**很早之前就已成熟，命人取来供上仙品尝。

## 四、族地与仙禁

- 大陆之上是一望无尽的**绿油油平原**，清风带青草香。
- 平原中心为一片**古老建筑群**，零散错落，不残破但弥漫**沧桑气息**——王林因摸索**抽魂之术**而对此气息敏感。
- 距建筑群尚有千丈时，王林一眼看出外围有**大型阵法禁制**。
  - 凭据：他对禁制的了解 + 在**雷之仙界**中**李元**的亲身指导，故对仙禁了解更多。
  - 老者解释：此阵是**仙王当年亲自布下**，确保我族不受**雾兽**侵害。
- 王林当时不知雾兽为何物，只略一点头。

## 五、整族聚居与恐惧之因（第804章 仙选族）

- 建筑内飞出大群人，男女皆有、衣着朴素，远远观望不敢临近；屋内还有小孩睁大眼睛张望——此处居住的是**仙遗族一整族**，繁衍存留至今。
- 带路老者以**一种奇异的语言**斥责族人，众人才沉默散开。
- 王林落于最高建筑外，神识一扫确定无碍，仍**拒绝进入**：「在这里就可，无需进去。」老者面露苦涩。
- 王林追问族人恐惧之因，老者长叹道出：
  1. 仙界之人已很久没来，仙王仿佛把他们遗弃；老者是族中最年长者，王林是他**此生见过的唯一一个仙人**。
  2. 若非**我仙选族的典籍**内有记录，他也认不出上仙身份。
  3. 本族奉**逍遥仙王之命，世代守护玄阴鼎**。
  4. **自三万年前起，玄阴鼎每隔百年打开一次**，每次开启喷出大片黑雾，黑雾化作妖兽，其中极强者可**化作人形**。
  5. 三万年来，死于人形雾兽者不计其数。
  6. 因此凡此地出现陌生人，几乎全是雾气所化；而本族之人**因有符文烙身，雾兽无法幻化**其形。
  7. 故除老者外，族人无法分辨王林，甚至不信老者之言，始终疑心王林是雾兽所化。
- 王林结合前后之事与四周神情，判断老者所言有几分可信。

## 六、转折：禁地之行被喝止

- 王林问「玄阴鼎在哪里」，老者答：在**我族禁地**，问上仙是否现在要去。王林点头，欲亲自看看玄阴鼎为何物。
- 此时天空人群中一声如惊雷大喝：「**先祖！不可带此人去玄阴鼎！**」
- 人群散开一条通道，一名**身高约一丈、赤着上半身的大汉**踏空而来；其上半身黑色符文印记密密麻麻几乎弥漫全身，**颈部与面貌亦被符文覆盖**（符文覆盖程度疑与地位/实力相关）。
- 该大汉称白发老者为「先祖」。

## 七、待解伏笔

- 玄阴鼎究竟为何物、为何被逍遥仙王命人世代看守。
- 三万年前玄阴鼎异变（每百年开启喷黑雾）的起因。
- 「上仙」品阶体系与八品上仙的位置。
- 此地与仙界崩溃的时间关系：仙遗族滞留于此已历无数年而不知外界剧变。
- 符文大汉阻拦的真实动机。

# 第805章 雾兽（第七卷 名震罗天）

## 一、对峙：十三叶符士塔山

- 一名大汉眉心生有**十三叶**植物，蠕动间显妖异。王林目光一凝——他所知的**朱雀星仙遗族**中，最多也只有**十一叶的一祖**。
- 王林判定：十三叶**相当于阳实修士**。
- 大汉现身，四周仙选族族人欢呼崇敬。王林身边的**先祖老者**厉喝「塔山，莫要对上仙不敬」。

## 二、信仰之争（族群设定要点）

- **塔山**：先祖老了、想仙人想得痴狂；世间根本无仙人，祖宗典籍皆是杜撰——无数万年来本族从未见过任何仙人来此。
- **先祖老者**：仙选族自古是**仙人在世间的使者**，若无仙人，本族如何存活；且**仙王当年的仙谕犹在**。
- **塔山**：所谓仙王，不过是一个强大之人的**残余神识**，无数万年前留下的神识不足信，「我更相信自己的力量」。
- 塔山控诉：本族在**幽冥兽体内**无数年，按仙谕**守护玄阴鼎**，换来的却是**玄阴鼎内的雾兽**不断残杀族人——雾兽杀人时仙人在哪？故曰「今日即便此人真的是仙人，我塔山，也要杀仙」。

## 三、三度交手

1. **第一拳**：符文凭空环形排列于拳周，如含阵法，一击封死王林四周退路。王林评「还算尚可，只是，不够」，右脚轻踏地面，地裂蔓延，禁锢如镜面破碎般瓦解，反震之力横扫，逼缓塔山。王林一步近身，右手一碰其前胸，塔山退出数十步，体内如有风暴，赖符文印记护体未受重创。
2. **第二击**：塔山拍出全身符文，十丈内密密麻麻符文弥漫，随身冲杀，符文一闪如一个个神通之法。王林一步跨越距离逼近，右手一指施**仙术定身**顿住塔山，随即**双指成剑**再按其胸口，塔山被抛飞喷血，眼露震惊；全场仙选族族人心神剧震、一片死寂。
3. **仙赐灵甲**：老者急求「留塔山一命」，塔山不受，退至十丈外掐诀拍胸，符文收缩鼓起，凝成一副**黑色铠甲**，阴森之气弥漫，身后隐现魔神般黑影。老者失声：「仙赐灵甲——你居然炼化出了灵甲！」
   - **王林的辨认**：此甲与**当年妖灵之地的散魔铠甲**极为相似，唯一不同是甲上**魔气不浓，似被另一股力量压制**。
   - 塔山披甲如远古巨人，魔影化万缕烟丝缠上右拳，拳前凝成骷髅黑影，欲吞噬王林。

## 四、百丈仙界碎片首现

- 王林张口吐出**一枚沙粒**，幻化出**百丈仙界碎片**——**这是百丈仙界碎片第一次出现在世间**。
- 碎片威压浓郁并带牵引封锁，磅礴**仙力**笼罩之下，仙选族老者激动匍匐膜拜。
- 塔山迟疑后仍全力轰击，碎片纹丝不动，回震之力令其喷血后退，拳上魔影几近涣散。
- 王林指挥碎片升空旋转成风暴，化大印砸落，一声「落」——大陆震颤，大片裂缝咔咔裂开。
- 塔山结局（本章）：全身多处破损、**七窍流血但未死**，双目仍露战意盯着王林。

## 五、雾兽暴走

- 裂缝中冲出大片**黑雾**，迅速相互凝聚，转眼在天空凝成**上百头形态各异的黑色凶兽**，阴森低吼可穿透心神。
- 仙选族应对：族人眉心植物闪烁，自天灵幻化出层层叶片，从中飞出**长嘴大壶**法器（先祖老者的约一丈大小），壶嘴生出庞大吸力，可将雾兽扭曲化烟丝吸入。
- **先祖老者军令**：各自为战，务必在**半柱香内**把雾兽全部驱除，**莫要让人形雾兽出现**。
- 初期雾兽尚未彻底清醒、只具身形，仙选族反应迅速、战斗经验丰富，一时吸入大片。
- **转折**：一头雾兽在被吸时**首次睁眼**——眼中无瞳孔，却有**六个黑点**，其余全为灰色，目光冰冷无情。它瞬息追上后退的族人，顺七窍钻入，族人惨叫、身躯崩溃化作血雾，雾兽自血雾中幻化而出，舔唇再扑下一人。
- 此后一头接一头雾兽睁眼，由不还手转为**极为嗜血、速如电光**。老者面露焦急，喝出「仙阵灭杀」；一头睁眼雾兽直扑王林，本章在此戛然。

## 六、作者注（元信息）

- 正文中夹有作者自述：这段情节**并非过渡**，而是**复活李慕婉**的一个很重要的情节。
