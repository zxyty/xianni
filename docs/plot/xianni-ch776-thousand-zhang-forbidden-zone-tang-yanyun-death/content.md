# 第七卷 名震罗天 · 第776章 千丈禁地，入者死！

## 一、场景与前情
王林（本片段以化名「许木」行事，自称「许某」）与李元在雷之仙界一处**仙阵暗洞（仙人遗洞）**处，以周身千丈为界，尘埃成环，外人不得入内。四周聚集大量第一步修士围观，包括**赵家兄弟**。

## 二、唐言云闯入
- 一道剑光载来**唐言云**：黄袍宽大、面貌约三十许、面部平凡、双眼狭长有寒光；天地元力浓郁，已达**阴虚巅峰**。
- 他明知千丈尘埃之意，速度不减直冲入内，元力掀得千丈尘埃倒卷。围观修士料定两名大神通修士必为暗洞而战，甚至有人存「二人重伤我取渔利」之念。
- 王林令李元先下暗洞，李元跃入。

## 三、交手过程
1. **紫雷 vs 五黑龙**：王林抬手向虚空一拍，紫色雷光并紫雾直奔唐言云。唐言云右手成爪化五道黑气，低喝「吞」，五道黑气化五条黑龙吞下雷霆，随即暴涨为**五条百丈巨龙**环身，气势暴增。
2. **招揽被拒**：唐言云自报家门，提议同探仙人遗洞。此举以其身份已属破例——只因判断王林修为高过自己、堪比其**阳实境界**的族兄。王林答：「你，不够资格。」唐言云神色阴沉后退，暗盘算等族兄到来再动手。围观者低呼「唐家莫非是罗天南域的唐家」。
3. **雷返自爆**：王林一步踏出，千丈内元力弥漫，平静步步逼近，口出「许某之雷，你同样没资格吞噬」。话音落，五条百丈黑龙体内雷光游走、砰砰作响，五龙尽数自爆。唐言云掐诀，**眉心黑龙印记**闪烁散黑气护体，方保无碍，冷汗涔涔且暗怒——他自认未露敌意。
4. **兽骨石化「元龙吞」**：王林右手一指，**手背兽骨之图**如活物蠕动幻化而出，成一具带四根利刺、散寒芒的巨大兽骨扑击。唐言云催动眉心印记，黑龙脱额而出——约千丈大小、龙鳞遍布符文、威压如吞天地，施展神通「**元龙吞**」。兽骨双目黑洞升起两团幽火，瞬间爆发极浓煞气旋即消散；黑龙龙目骇然凸起、身躯凝固，灰色自尾部疯狂蔓延，连体外元力一并化为石质，整条黑龙化作石雕轰然坠地碎裂。
5. **封锁瞬移与击杀**：全场骇然，众修士视千丈为雷池，纷纷再退；赵家兄弟暗自庆幸未入千丈。王林收回兽骨（重融入手背图案），一步到唐言云身前，右手双指含一丝元力按下。唐言云欲瞬移遁走，王林冷哼，**百丈内天地元力挤压，断绝一切瞬移**（此神通为王林自行研究而出）。远处四道长虹急飞而来，伴阴森低喝「杀了他，你会陪葬」，王林眉头微皱，手指落下——唐言云肉身崩溃化作血雾抛出，**元神亦崩溃**。

## 四、宣告与后续
- 王林转身走向暗洞，留下一句：「**千丈内，进入者，死**」。千丈自此成其禁地，此刻的王林有资格说这句话；众修士自此深深记住王林样貌。
- **李元**自暗洞惊呼冲出，看了一眼远处黑龙石雕碎石，传音王林：「许兄，下面的宝物被我收好，而且，我还发现了一条**密道**，不知通向何处。」（暗洞下另有密道，去向未明）
- 唐家四道长虹落地成四人，有男有女。其中相貌极英俊、双唇略薄、目光阴沉者为**唐言枫**——若申公虎在场必能认出，此人正是当初在雷之仙界大门前讥讽申公虎尊主者。
- 唐言枫身边一**中年男子**冷笑「千丈禁地，阁下以为自己是谁」并踏入千丈；四人中另有一**冷傲青年**同样踏入。王林神色平静，转身看向那中年男子——章末悬念。

## 五、要点提炼
- 势力线：**唐家**（疑罗天南域唐家）大举入雷之仙界，队伍同行不分散，唐言云仅为探路先锋；唐言枫一系与**申公虎**已有旧怨。
- 战力标尺：唐言云（阴虚巅峰）在王林手下毫无还手之力；王林被评估为可比阳实境界。
- 王林手段清单（本章可见）：紫雷（可远程引爆被吞噬之雷）、手背兽骨（石化一切，含法术与元力）、元力挤压禁绝瞬移、一指灭肉身元神。
