# 仙逆 第八卷 联盟隐秘 第978章《路窄》、第979/980章《浮风子》

## 一、大罗星上：破局与顿悟

### 1. 窥涅中期巅峰之威
- 王林修为已至**窥涅中期巅峰**，元力磅礴外放，在大罗星天地间形成以其为中心的庞大漩涡，呜呜作响弥漫全星。
- 大罗剑宗弟子如负山峰，须自行运转灵力抵抗。远望之下，漩涡之下长发飘动、背手望天的王林，成为诸弟子眼中「仿若永恒」的一幕。

### 2. 天逆大门外的「飞鸟与蟒」
- 王林沉淀此前感悟，反复思索天逆大门外抬脚落下一刹那所见之景。
- **初念**：「那飞鸟，莫非就是我的前生？」
- **修正结论**：飞鸟并非前生，而是**自己心神的象征、借此而生之物**；但「飞鸟最终葬身蟒口」的寓意仍未参透，只隐约把握到一丝脉络。
- **本源之问**：此次仅是天逆吸收**极阳**后的一次**小圆满**；须再吸收**极阴**、达成**阴阳大圆满**，方能真正明悟这一切。

### 3. 破天运子之局
- 王林断言：「不管那天运子计算者是我，还是凌天候，这一次，他在我身上，错了。此局，破。」
- **推理链**（凌天候遁走之谜）：
  1. 天逆珠子每次开启都需庞大无比的天地元力；
  2. 但此次开启，四周元力**没有任何变化**；
  3. 凌天候却仓惶而遁，其逃遁时间与珠内**外散的两道光团**几乎完全吻合；
  4. 故其中一道光团正是**直奔凌天候而去**。
- 凌天候原所在的巨塔侧面坍塌出大洞，内有残余元力波动。
- **悬念**：另一道光团奔谁而去？王林自语：「如果是天运子，就好了。」

### 4. 下一步计划
- 局已破，无需再留大罗星。
- 目标：**再赴妖灵之地**做准备。妖灵之地共有**四座仙府**，王林**占据其一**，可**带数人同行**——这是他接回属下的直接动机。

## 二、废弃蛮荒星：接回大头与雷吉

### 1. 星球环境
- 数个时辰飞行后（未用缩地成寸）抵达一颗废弃蛮荒星。
- 形态：**非圆形，如被吞了一口的月牙状**，漂浮星空，不时有碎石脱落飘走。
- 无半点灵力；罡风层脆弱不堪，王林一冲即连锁崩溃，星空尘埃倾灌而下化作风暴。
- 大地处处龟裂，无植物，生命绝迹，死气浓郁；据大头所言，**每隔一个时辰便出现大片崩溃**。

### 2. 主从会合
- **大头**：头颅硕大、身子瘦小、毛发稀少、青筋暗隐；先至，行礼「参见主人」。
- **雷吉**：巨魔族，后至，神色恭敬瓮声道「雷吉见过主人」。
- 二人是在**王林进入天运星之前**被安排在此等待召唤的。
- 王林报以「尚可，只是出了一些小问题」，并宣布：带二人另择一处修真星闭关修炼，此地环境恶劣不适合闭关。

### 3. 星空赶路的阵仗
- 雷吉化出巨魔族本相，**百丈大小**，四肢伏地；王林盘膝坐其背上。
- 大头如侍卫般侍立；王林身后虚影一晃，傀儡**塔山**走出，神色冷漠。
- 沿途天运星范围内的修士见此阵仗，纷纷自行让道；议论内容：「哪位大神通老怪，居然有这等巨魔族坐骑」「那盘膝坐下的修士有些眼熟」「那两个护卫，连宗派大长老都没有这种气息」。
- 点题：**在修真界，就是以强者为尊。**

### 4. 王林的战力自评（重要战力标尺）
- 当初窥涅初期 + 古神肉身 → 可战**净涅初期**。
- 此刻窥涅中期 → 战净涅初期**不在话下**；即便**净涅中期**，也有一拼之资。
- 参照：**当年天运星血祖为净涅中期**；以今日之修为若换作当年，可与之一战——「虽说胜之把握不大，但净涅中期修士想要杀我，却也没那么容易」。

## 三、路窄：狭路相逢肉山老者（浮风子）

### 1. 对方阵仗
- 前方星空万里外，一艘**长约三十丈、通体漆黑**的舟形法宝缓行，灵力浓郁、法宝波动明显。
- 舟上巨大靠椅斜躺一**肥大如肉山的老者**，七八名纱衣妖艳女子环侍（斟酒、奉果、揉捏、伏怀）。
- 外围立**七名黑衣人**，一动不动如死尸，气息凌厉，冷漠不语。
- 舟外另有**上百名青衣修士**踏剑光护行。

### 2. 身份与旧怨
- 此老者正是**当日王林回天运星时，言辞刻薄、对他很不客气的那名肉山修士**（本回标题「浮风子」）。
- 老者是全船唯一先行察觉王林者，遂佯装若无其事令女子斟酒，眼中已闪冰冷；见雷吉身影后确认：「果然是他。」
- 老者的算计：贪图**巨魔族坐骑**；评估王林身边「头大的护卫」也是窥涅修士、傀儡亦有实力；但认定「王林能与凌天候一战，虽说不简单，可却是占据了法宝之威——法宝，谁没有？」

### 3. 开战
- 七黑衣人同时踏出化七道长虹，喝道：**「前方来者，三息让道避过，违者，杀。」**
- 王林神识始终扩散，几乎同时发现对方；嘴角冷笑：**「就拿你，来看看我修为到底可不可以彻底战胜净涅初期。」**
- 大头请战「主人，可以杀么」，王林答**「随意」**，大头杀机毕露一步消失。
- **七黑衣人修为均超过问鼎，处于阴虚境**；面对大头，七人瞬间列阵，自末位起逐一将元力汇入当头之人，该人身躯胀大，元力顺右手印记轰出，幻化一头**黑虎**扑向大头。
- 肉山老者同时抬手一指，射出**一道黑芒**直奔大头——片段至此中断。

## 四、要点与伏笔
- **伏笔一**：天逆珠内第二道光团去向不明，王林期望其指向天运子。
- **伏笔二**：飞鸟葬身蟒口之意、「本源」之谜，须待吸收极阴、阴阳大圆满后方解。
- **伏笔三**：妖灵之地四仙府之一归王林，可带数人同行——大头、雷吉、塔山的随行安排即为此铺垫。
- **战力刻度**：窥涅初期(+古神肉身)≈净涅初期；窥涅中期>净涅初期，可搏净涅中期；问鼎期之上为阴虚境。

# 王林力挫肉山老者陈风，奴印收服（妖灵之地前夕·天运星）

## 开场：接战
- 王林盘膝坐于**雷吉**（巨魔族坐骑）背上，一步瞬移至**大头**身旁，随手一挥崩碎袭来黑芒。
- 王林主动挑战：「你，可敢于我一战」。肉山老者冷笑，讥其与**剑尊凌天候**一战后自觉可挑战自己。

## 交手过程
### 第一回合——仙碑灭神 vs 古神之拳
- 老者掐诀一指，身后幻化出散发金光的巨大**石碑虚影**，神通名「**仙碑灭神**」，直压王林。
- 王林一拳融合**窥涅中期巅峰**修为与**古神之力**，拳前幻化出近百丈**古神手臂虚影**，蛮荒之气弥漫，狂傲霸道、一切阻挡皆崩碎。
- 石碑未近身即被古神手臂之拳崩溃，四分五裂。
- 关键设定：此等**完整**幻化古神手臂之拳，王林此前唯全力施展方可略有幻化；如今信手拈来。

### 第二回合——九印爆裂
- 老者掐诀化出**九个印记**叠加迎击，喝「爆」。
- 剧烈震荡推开黑色舟船，连雷吉亦不得不后退，老者带领的修士纷纷退避。
- 王林一拳化解全部冲击，毫发无损自印记崩溃中一步走出，自评：「看来，我的确有杀**净涅初期**修士的资格」。

### 第三回合——涂罗浮尘 vs 灭神矛
- 老者杀心已起（贪念：**巨魔族坐骑** + **仙府钥匙**），喝令王林交出洞府钥匙与坐骑否则留命。
- 老者双手连点自身，肉山之躯诡异蠕动瘦缩至皮包骨如骷髅，将全身血肉精华收缩凝聚于眉心，爆出强光，喝「**涂罗浮尘**」。
- 王林虚空一抓，星空撕开缝隙，钻出红芒凝成**灭神矛**：「你有资格，让我使用它」。
- 灭神矛蛮荒气息达巅峰，与强光连续碰撞，数息内令强光崩溃瓦解，随即直取老者。

### 第四回合——青光小盾与缩地成寸
- 老者拍储物袋取出**青光小盾**挡下灭神矛，盾身颤抖倒退却无裂缝；王林察觉其上有**微弱古神气息**，判为「**古神法器**」。
- 老者喷血施展**血遁之术**疾退（净涅修士血遁速度极快）。
- 灭神矛渐虚幻消散后，王林一步踏出，**在天运星范围内第一次施展缩地成寸**，融入天地消失。
- 老者头皮发麻、再喷血加速，内心狂吼：「缩地成寸这王林竟然会缩地成寸」——设定要点：**拥有缩地成寸，等于在修为相差不多时立于不败之地**。
- 王林现身其身旁，一拳几乎抬起即抵至不足七寸，老者急呼「道友饶命」。王林拳停其鼻尖一寸。

## 议和与收服
- 老者判断：此拳落下必肉身崩溃，元神失去肉身亦难逃脱。遂舍弃身份求饶。
- 条件一：愿为王林去**妖灵之地**效犬马之劳。
- 条件二：献出自己**防护之力最强**的法宝盾牌（抹去烙印后交出），言其入洞府后必有大助。
- 王林收拳、验看后将盾收入储物袋；随即掐诀化出**奴印**（与当初操控**大头**的手法相同）按入老者眉心。
- 王林令：「把你的事情处理完，跟我走」。
- 同时段：大头趁两人交战杀入**七个黑衣人**中，尽数残杀，舔血。

## 身份揭示与心机封印
- 老者遣散舟船弟子后登上雷吉背，自报：**本名陈风，道号浮风子**，败得心服口服，承诺妖灵之地全力助力，要求归来后解封两清。
- 王林平静回应：「我的封印不深，你若想打开，自然可以做到。」
- 陈风心理：该封印只有**封窥涅修士**的程度，凭其净涅修为不久可破——但正因王林如此「大意」，反疑其内另有乾坤、暗自破封会触发更深层连锁反应，故**不敢冒险**，对王林更起忌惮，评其「太过阴险」「心机深沉，不可小看」。
- 作者点明：王林真实修为仅窥涅中期巅峰，根本无法封印净涅修士，唯有依靠心机——「**这心机化作无形的封印，若是用的好了，比之天地一切封印，都要犀利无数倍不止**」。
- 王林承诺：期间听令，出妖灵之地后还其自由。陈风点头，盘膝调息，干瘦身躯随吐纳又缓缓膨胀。

## 要点提炼
1. 王林战力刻度：窥涅中期巅峰 + 古神之体 ≈ 可杀净涅初期；化古神真身 ≈ 可战净涅中期。
2. 新增战力标签：随手完整幻化古神手臂之拳、灭神矛可召可散、天运星首次施展缩地成寸。
3. 新增战利品：古神法器**青光小盾**（防护最强）。
4. 新增部属：**陈风（浮风子）**，净涅初期，奴印在身，仅约束至妖灵之地之行结束。
5. 悬置线索：**仙府（洞府）钥匙**为多方觊觎之物，被认为对妖灵之地一行帮助极大。

# 第980-981章 水灵星落脚：尘道三子敬奉，重逢灵儿

## 一、途中：陈风示弱
- 陈风（浮风子）在王林面前打坐，摆出姿态表明毫无异心，只求随行妖灵之地后换回自由。
- 王林观其功法「很是奇异」，暗忖有此人助力，妖灵之地一行把握更大；同时仍叹「我这里的人还是不够」。
- 雷吉载众人在星空疾驰。

## 二、水灵星与尘道三子
- 远处出现一颗水蓝色修真星，如水球般绚丽，灵气浓郁——即**水灵星**，归属**尘道三子**。
- 星名来历：以尘道三子中一尘子的后辈小女「水灵」之名命名。
- 陈风目露银邪，坦言早想掳走水灵作炉鼎，只因顾忌尘道三子背后之人而作罢。
- 王林本欲绕行：此星虽宜闭关，但与尘道三子有交道，不好出手抢夺。

### 三子出迎
- 三道长虹自星内飞出，形若巨龙，风暴咆哮，一尘子喝问「何方道友」，旋即察觉来者不凡而止。
- 背景：三人因**鬼眼坊市**意外未开即被终止而离开返回；在星内打坐时感应到星外数股第二步修士气息，立刻飞出。
- 三人震动之因：
  1. 雷吉庞大身躯——在联盟星域，能以巨魔族族人为坐骑者，唯有与**凌天候**、**天运子**齐名的老怪；
  2. 看到王林——一尘子曾亲眼目睹天运星上的战斗，本以为王林必死，如今再见，心生恭敬，暗道「能引起天运子与凌天候为其交战，这魔道子，不简单」；
  3. 看到陈风——此人在天运星赫赫有名，虽不及当年血祖，也是成名老怪，好色如命，曾打灵儿主意，令三子担惊许久。

## 三、一句「聒噪」定尊卑
- 陈风嘿嘿一笑，向尘道三子索要水灵星。
- 王林皱眉平静吐出二字：「**聒噪**」。陈风心神一颤，听出不善，赔笑不敢再言。
- 王林向一尘子抱拳致意，表示不知此星属三人，愿另寻闭关之处。
- 一尘子问及王林与浮风子的关系，王林答：「**他是我的仆从。**」——此言落在三子耳中「不亚于数万天雷同时炸响」。
- 一尘子当即改口力邀：水灵星极大，方圆数十万里再无可比之星，绝不打扰王兄修行。
- 一尘子内心盘算：此人有巨魔族坐骑、是**净涅**修士、令浮风子为奴、随行大头亦为**窥涅**、傀儡（塔山）也不弱——「这种人，一定要结交」。
- 一星子、一龙子亦在旁劝说。王林应允致谢。

## 四、入星
- 一尘子引路，雷吉身形渐缩为一丈大汉，与大头、塔山并行于王林身后；浮风子不敢多言，跟在最后。
- 一路谈笑皆无关事宜，鬼眼城外之事三子闭口不问。
- 众人穿过**罡风层**——罡风于大神通修士而言微不足道——降临水灵星，灵气浓郁，王林赞叹。
- 一尘子暗自得意：水灵星是附近数十万里内最好的修真星，若非三人师尊的缘故根本轮不到他们占据。

## 五、重逢灵儿与赵雪
- 几只仙鹤自云中飞出：前一只坐蓝裙少女**灵儿**（笑声如银铃，正问师姐地下泉眼所在）；后一只坐紫衣女子**赵雪**，容颜冰冷、美貌惊人，唯对灵儿时缓和。
- 赵雪行礼：「弟子赵雪，见过师尊与各位师叔。」一龙子介绍其为自己弟子，命其参见「王前辈」。
- 灵儿娇笑问：「王前辈可还记得灵儿。」王林笑答：「当然记得，我那草帽与铃铛，不就是送给你了么。」灵儿俏脸微红。
- 赵雪奇怪：师妹归来这几日口中最多的就是这位王姓前辈，尤其对那对铃铛喜爱异常，常挂腕上把玩；她多看王林几眼，未看出与众不同。
- 一尘子含笑旁观，心中另生想法，嘱灵儿莫要打扰，引王林前行。

## 六、落脚与闭关部署
- 住处：水灵星**东部**山峦间的典雅宫殿群，古风仙姿，山顶皆有宫殿不下数十，绿树参天，亦是全星灵气最浓之处。
- 尘道三子含笑告辞，相约次日拜访。
- 王林令：「我要闭关数日，塔山护法，其余人各自选择住处，但不得离开我百里外。」
  - 塔山：随行至殿外盘膝护法。
  - 大头与雷吉：择近处宫殿，便于随召即到。
  - 浮风子：暗叹之下择稍远处，下意识不愿距王林太近，但牢记百里之限。
- 宫殿内景：奢华雕栏玉砌；地面巨大八卦图案（无灵气，纯装饰）；正中三人合抱铜炉，燃臂粗香支青烟；旁置紫玉蒲团；四壁浮雕相连，为「**众仙迎帝图**」。
- 王林评价：范围大、适合祭炼法宝，且颇为安静，可闭关静修。

# 第982章 青光盾！（第八卷 联盟隐秘）

## 一、闭关巩固：窥涅中期巅峰

- 地点：水灵星，王林所居宫殿；紫玉蒲团。
- 王林神识散开查看四周后闭目盘膝，一坐三天；期间尘道三子来访，等候片刻未打扰，告辞离去。
- 三日后深夜睁目，双目精光爆出，宫殿如被照亮。
- 自评：
  - 修为「真真正正巩固在窥涅中期的巅峰」；
  - 配合古神肉身，「应可与净涅中期一战」；
  - 但对于前往**妖灵之地仙府**，仍然不够。

## 二、青光小盾的来历与古神气息

- 王林拍储物袋取出一道青光——内为**巴掌大小的青色盾牌**，通体青色，不知名之物祭炼，内有云烟飘摇。
- 此盾来历：**浮风子**当年与一仇家厮杀后杀人所获；浮风子研究后隐约知晓其与四圣宗有关联，轻易不施展，此前是生死危机下才咬牙拿出。
- 王林早在浮风子取出时便感到其上**一丝被封印遮盖的古神气息**；因他自身即古神方能察觉，换作外人绝无可能。
- 王林判断：**古神涂司一生记忆中并未炼过此宝**，应是太古时期另一位古神祭炼遗留之物。

## 三、破青龙印记：第三目吞噬青龙分身

1. 盾侧有一**踏云青龙印记**（通体青色青龙），古神之气正是被此印记阻拦、禁锢在盾内无法外泄。
2. 王林右手点向印记，遭强大反震之力弹开；印记青光爆闪，化作一头**约十丈长的青龙**，张口吞来。
3. 王林虚空一抓，以狂风横扫并抓住青龙身子欲捏碎。
4. 青龙分出一道青气，化作**较小的青龙分身**直奔王林眉心吞噬。
5. 王林冷笑——全身最强处正是眉心，第三目若开，古神肉身亦有所不如，更兼有「天逆」。
6. **眉心第三目打开**：缝隙内刺目红芒，如黑洞般吸力，将青龙分身彻底吸入，唯余龙啸余音。
7. 手中青龙萎靡黯淡，一捏化作点点青光散去，掌中留下**指甲盖大小、刻有活灵活现青龙的碎片**。

### 四圣宗线索
- 王林在碎片上感到与自身**眉心朱雀印记**相似的气息。
- 推断：「四圣宗有朱雀、玄武、青龙、白虎四宗，莫非这碎片是属于**青龙圣宗**之物」——碎片收入储物袋。

## 四、气旋中的神念：青龙圣皇求救

- 印记消失后，原印记处露出一团**缓缓旋转的青色气旋**。
- 气旋内有一道元力，无攻击性，实为**一道神念**；此神念与古神气息诡异相融、几乎不分彼此，**除非拥有古神气息，否则任何修士都无法分离**（第三步修士能否分离，王林不知）。
- 这也正是浮风子以其修为始终无法破开、神念得以保留至今的原因。
- 王林判断：不驱除此神念，古神气息无法外泄，盾牌威力无法全部发挥。
- 做法：眉心**古神星点**浮现旋转，凝聚**王族古神之力**于右手食指，按向气旋；古神气息剧变，神念被分离。

### 神念内容（原话要点）
> 「老夫**青龙圣皇**，受困于**雨之仙界**，救我者，封**青龙第一序列**；把老夫消息送回**青龙圣宗**者，**四圣宗**也可为其做一件事情。老夫气息微弱，怕是坚持不了太久，望获得此神念者，速速来救。」

## 五、封印尽解：三百丈青光盾与顶天立地的古神虚影

- 神念消散，盾内被压制不知多少年的古神气息**疯狂爆发**，形成风暴横扫；王林抓盾遁出宫殿，立于星空之下。
- 气息宣泄化作**庞大古神虚影**，笼罩天地；其眉心一片模糊，星点急速旋转，**看不清到底是几星**。
- 盾牌由巴掌大→数丈→百丈→近**三百丈**，由小巧化作粗犷，做工粗糙如一片高墙，威压磅礴——「这，才是古神的法器」。

- 此刻王林双目爆出精光，**露出狂喜与震惊之色**：「这…这是…」（章末悬念，未揭示星数结果）。
