# 仙逆 第1350章 闪雷之战！（四）

> 归属说明：依据【世界状态须知】，王林自第1242章起以一部分元神夺舍「于非」之身、冒其身份潜入闪雷族；本章正文直呼「王林」本名，所有言行归属【王林】。

## 一、双聚雷印对峙

- 闪雷族大长老喝出「聚雷印」，撕开自身封印，爆发出**完整的天人第四衰圆满巅峰**修为，气息如换了一个人，星空在其威压下扭曲、崩出裂缝。
- 四周被压制退避的闪电尽数涌向大长老右手，凝成数万丈雷球，随后疯狂压缩：十倍→百倍→千倍→万倍→十万倍→百万倍，光芒笼罩全部星空，连大长老本人都被光淹没。
- 王林心神震动——此神通他**在闪雷族潜伏之时也曾修炼**。他同样抬手喝出「聚雷印」，右目浮现**闪电印记**，印记旁有**念雷**幻化环绕游走，右目光芒万丈、透出妖异。
- 星空雷霆之力**一分为二**，一半直奔王林右手凝成巨大雷球。大长老双目收缩，未曾开口。

## 二、雷霆压缩与对轰

| 一方 | 压缩倍数 | 雷霆渊源 |
|---|---|---|
| 闪雷族大长老 | 五百万倍 | **不灭之雷**——万古岁月之前天地降临的一道本源雷霆 |
| 王林 | 三百万倍 → 喝出「以我王林雷之本源之名」再压至**四百万倍**（其修为极限） | 全靠自身一步步走来，**以半条太古雷龙为引**自行明悟的雷霆本源；渊源不及，但层次同等 |

- 星空自二人中间被撕裂向两旁分开，两道雷霆之力自裂空中轰然爆发。
- **雷修交战的本质**：拼的是对雷霆的操控，拼的是雷霆的归属。雷修体内自有抗雷之力，寻常雷霆伤不了分毫，但**蕴含对方意志的操控之雷**可造成剧烈伤害。

## 三、余波：闪雷族十六星死伤无数

- 碰撞形成无法形容的雷霆冲击，如巨浪倒卷横扫四方，**波及闪雷族十六颗修真星，死伤无数**。
- 环绕闪雷族的**雷域沸腾外扩百倍不止**；附近修真星如降雷霆之雨。
- 剧变引起**太古星辰内诸多强者**注意，更有**第三步大能**察觉。

## 四、王林重伤与光影盾反击

- 第一波冲击：王林压缩的雷力崩溃，喷出大口鲜血夹带内脏碎片，全身骨头似碎，身子倒卷被抛飞。
- 第二波冲击将至，王林所虑不止自身生死，更在于**如何重创大长老**——其性格「越危险胆子越大」，凭精确算计与心机屡胜强敌。
- 王林掐诀一指，聚拢天地一切光：雷光、电光、星空之光、崩灭之光、星空裂缝的无形之光、极远处闪雷族修真星之光、无数闪雷族修士之光，以及**储物空间内七百万天地灵符之光**。
- 凝成**蓝梦道尊至强防护神通「光影盾」**，巨大光影裹住王林全身。
- 光影盾承受第二波冲击将溃时，王林咆哮喷血落于其上，血光弥漫，**将后续数波冲击尽数反射出去**，随后光影盾崩溃，王林面色苍白。
- 反射同时，王林祭出**无坚不摧的血剑**；**右目闪电印记携灵念之雷飞出**；双目红芒一闪，**极境**同时出现。反射冲击 + 血剑 + 本源闪电 + 极境，化作一场杀劫轰向前方。
- 大长老正后退挥手抵消冲击，见到光影盾如遭重锤：「这是蓝梦道尊的光影盾……莫非蓝梦道尊要杀我」。反射冲击与本就卷向他的冲击融合，他等于承受了雷霆崩溃的**全部之力**，久违的生死危机骤起，随即被吞噬。

## 五、大长老不死反强：预告太古雷龙

- 王林施展**呼风唤雨界**抵抗零散雷霆，退出很远。
- 大长老怒吼走出，气息比先前强大无数倍，**无限接近第三步**。
- 伤势清单：衣衫破损；右胸被**血剑**穿透、血肉模糊；眉心印记被**极境**崩出裂缝；全身多处伤痕为**王林本源闪电**所伤；体内元神略有萎靡（被雷霆之力冲击重创）。
- 宣告：「以我**天人第五衰无尽生机**，以我**不灭圣雷奴**之名，**开启太古雷界，召唤万古岁月中太古雷龙**」——为下一章战局埋线。

## 六、可延展的悬念

1. 大长老自称「不灭圣雷奴」，与「不灭之雷」本源的关系待明。
2. 太古雷界 / 太古雷龙的召唤，与王林「以半条太古雷龙为引」的本源同源，正面冲突值得关注。
3. 蓝梦道尊之名对闪雷族大长老具备强烈威慑，其立场与王林如何得其神通尚未交代。
4. 太古星辰第三步大能已被惊动，闪雷族之战恐外溢。
