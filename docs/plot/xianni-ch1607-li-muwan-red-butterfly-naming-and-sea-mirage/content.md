# 第1607章 李慕婉（仙逆 01516-01520 之2）

## 一、雨中亭榭：雪域女子求助

- 场景：雨幕、亭榭。王林此时为凡人身份的白发老者，在朱雀星以「先生」「当代大儒」之名闻世，被传「看透天地，明悟因果轮回，淡漠生死，走在真实与虚幻之间」，曾为诸多修士解惑。
- 来客：一名神色冰冷、目如寒风呼啸的雪域女子，怀抱棉被包裹的婴儿。她自称在遥远的雪域也听闻先生之名。
- 诉求：为这孩子「指出一条属于她的明路」，请王林相助避劫。

## 二、女婴的来历与命劫

| 项 | 内容 |
|---|---|
| 身世 | 出生之时父母双亡，被雪域女子偶然在雪中拾得，当时全身僵硬、濒死 |
| 天资 | 体内天生具备五行气息，为雪域女子此生仅见，「若能存活下去，必定是我朱雀星一代骄阳」 |
| 命劫 | 雪域女子擅推衍计算，算出此子命中有一劫，出生便显；越成长，冥冥中的生死大劫越会来临 |
| 应对 | 雪域女子自认已「轮入其劫之中」成为渡劫之人；因修为有限，只能以神通限制其成长，使其始终保持婴儿之状 |
| 特征 | 眉心一个红点，「仿若点在这女婴的灵魂」；清秀可爱 |

- 天地雨幕中一道闪电与惊天雷鸣将婴儿惊醒大哭；王林请求抱一下，接过后婴儿止泪，睁大无邪双目望着他。王林刮其鼻尖，女婴开心大笑。
- 王林隐隐在这孩子身上「感受到了一股熟悉的痕迹」。

## 三、取名「红蝶」

- 女子言其父母早死、自己也未起名，请王林赐名。
- 王林望向雨幕：远处林荫树叶下有一只色彩斑斓的蝴蝶避雨——翅膀若被雨水打湿便无法飞起，身子若被狂风吹到对人如同飓风临身。
- 王林目露明悟，定名：「就叫红蝶好了——雨中的蝴蝶，带着其娇艳的红芒，走完其孤傲明媚的一生。」女婴仿佛听懂，笑声更多。

## 四、解劫之法：梦中之阵 + 一缕青丝

- 王林自陈「王某不了解神通，不知晓如何能让这孩子避开生死大劫」，但「我梦中曾见过一物」，遂画出相授。
- 做法：闭目回忆，右手粘雨水在亭榭石桌上一笔笔画出一个复杂图案——实为一座极为深奥的阵法，令雪域女子动容并凝神强记。
- 嘱托：「待你明悟此阵后，取这女婴一缕青丝，放入其内」，可解其生死。
- 图案随风渐消。雪域女子闭目沉默半晌，深深一拜，抱女婴走入雨中。

## 五、王林的迷茫

- 未看去者背影，怔立亭中，眼中有迷茫：「因果……这因果到底是真，前世今生亦或者是假，是我自行去圆满……」
- 雨停，天现彩虹，避雨的蝴蝶扇翅飞起、飞向远方。王林走出亭榭，向大海方向一步步走去。

## 六、出海：离开赵国的第十五年

- 时间锚点：离开赵国的**第十五年**。王林已周游所在大陆，抵达海边，搭乘往来两片大陆之间的商船前往海的另一边。
- 海上：无边海面、风浪呼啸，白发飘动；这是王林第一次出海却毫无不适，看着大海「胸口一股气似贯穿全身」。一月、两月、三月……五个月后商船彻底进入无尽海洋，听水手唱歌谣，王林开怀而笑。

## 七、第六个月：东方海面的虚幻蜃景

- 清晨海中初阳金光万丈时，王林被惊呼扰醒，见随行半年的水手全部跪拜东方。
- 景象：东方海面朦胧中出现一处**虚幻画面**——火山正在爆发，山体震动中裂开**两道如龙蛇纠缠在一起的巨大裂缝，仿若一个标记**；无尽岩浆喷洒，滚滚黑烟遮天。画面无声，与天地相连，既极真实又朦胧，令人分不清真假。
- 凡人反应：颤声高呼「海灵息怒」，并抛下大量货物祭海，试图消解海灵怒意。古老传说：出海见虚幻之像即海灵有怒，要责罚以海存活的众生。
- 王林的判断：引书中之言「海内有灵，名为蜃，其吐气成幻，仿若仙境」；断定「这应该是假的……不是这天地下某一处地方真实发生的事情」，疑为「某个仙修之人，在那无尽海底修行，因其仙术造成」。

## 八、画中白衣女子——「是她」

- 正喃喃「假的，这是假的」时，王林声音戛然而止、双目猛睁、抬手指向海面虚幻火山，露出无法置信之色。
- 画面中黑云内走出一名**白衣女子**：样子并非绝伦之美，却秀丽温柔，长发与衣衫同舞，出尘之气弥漫，仿若仙子。她玉手抬起向下方一指，爆发的火山一震，隐有熄灭之迹象。
- 王林反应：仿佛失去一切力量，整个人完全呆住，说不出的悲伤如风暴席卷淹没，两行眼泪流下；本已苍老的身子更为老迈，靠着船壁望着那白衣女子，「目光似永恒」，喃喃「是她……」。

## 九、母题与伏笔

- **真与假**：蜃气成幻 vs 真实存在，与王林毕生「走在真实与虚幻之间」的道相呼应。
- **因果轮回**：女婴身上「熟悉的痕迹」、王林对「前世今生」的自问、章名「李慕婉」——三者互指，暗示女婴红蝶与王林旧缘、以及蜃景白衣女子的身份指向。
- **标记**：火山口两道如龙蛇纠缠的巨大裂缝被特意描述为「仿若一个标记」，为后文线索。
- **待解**：阵法 + 一缕青丝之法能否被雪域女子参透、红蝶生死大劫走向、蜃景是否真实存在于天地某处，本章均未交代。
