# 第2043章 岁月

## 一、送别李慕婉
- 王林凝望棺中李慕婉，见其睫毛轻颤、泪珠晶莹，为她擦去眼泪，将泪珠含入口中——很苦很涩，融于心后却有一丝甘甜。
- 久久注视之后，他闭目再睁，双目透出果断与坚定；俯身以脸碰触李慕婉苍白的唇，在其耳边说了唯有自己能听到的话语。
- 随后大袖一甩，棺木化作晶光消失无影，密室中只余王林一人。密室墙上一盏可燃数千年不灭的玄妙油灯忽明忽暗。

## 二、以灵魂之火焚炼仙皇之魂
- 王林虚手一抓取出仙皇之魂（止魂），其魂闭目、金光缭绕却带浓浓灰败之意。
- 略作迟疑后，他吐出青色灵魂之火笼罩此魂焚炼，目标是**驱除其上的诓术之力**——“此魂能否被我所用，就看可否驱除其诓术之力了，这一过程将会很缓慢。”
- 进度：三年后灰败之势隐隐止住；六年后灰败扩散更为缓慢。王林判断若有一天灰败完全停止扩散，便可慢慢将其炼化。

## 三、九年闭关与三具本源之身
| 年份 | 事件 |
| --- | --- |
| 第3年 | 五行真身自本体走出，盘膝对坐，与本体同修吐纳 |
| 第6年 | 杀戮雷霆真身走出，黑发飘摇、杀戮气息缭绕，三个相貌一致的王林成三角而坐 |
| 第9年 | 第三团虚影浮出，尚无法凝聚真身，化作模糊光团停于身后一丈 |

- 体内修为与古族之力完美流转；但于古道山形成的**一缕仙古融合之力**九年仅运转了极短一部分，尚未走完一个周天。
- **五行真身**：五行本源完整、均大成后凝聚成真身且融合为一，五行圆满，是王林本源极强的体现，几近极限——除非再进一步使其成为**真神**。当年在道古皇城将其补全，直接把王林修为推到**空劫大圆满**。

## 四、战力自评
- 有信心与**全盛之时的道一大天尊**一战而不落下风，隐隐觉得尚可力压道一。
- 大天尊中，仙族的道一最弱；自己仍比不过**久帝**，但可与**武封**近似。
- 对上始古一脉、与其师尊玄罗实力相差无几的**宋天大天尊**，也有一拼之力，胜负未知。
- 以上均为**未动用最强分身**的前提。

## 五、闭关的战略目的
1. 拥有战胜宋天大天尊的力量，从而**让宋天选择计都为皇尊**，进而使自己得以**进入祖庙**。
2. 在古族中不忌**古道之力**，不把生死系于他人一念。
3. 于**太古神境**内有力量破开一切迷雾，并应对**道古国师**的未知目的。
4. 观察：**吉道大天尊态度奇怪**，未因道古一脉之事寻他——但唯有自身强大才是解决一切的关键。
5. 心态：修行之路是自己摸索出的独有道路，唯有自己能指点自己；此番抱定“修为不增，绝不出关”。

## 六、下一步：杀戮雷霆真身大成
- 该真身由特殊本源凝聚：**雷霆**本源早已成真身，**杀戮、默灭、太初、禁制**四种仅止于大成。
- 王林右手一指，杀戮雷霆真身震动分裂，析出四团雾气：
  - **杀戮本源**——一出现密室骤寒，疯狂杀戮之意缭绕八方；
  - **禁制本源**——雾内诡秘符文不断增生；
  - **太初本源**——光芒扩散；
  - **默灭本源**——漆黑一片。
- 四本源若全部凝聚真身并融合，使杀戮雷霆之身大成，修为可自空劫大圆满再进一步。
- 关于那一步：或是**天尊**，或是**跃天尊**，也可能二者都不是而是踏入未知之境——或许即**大天尊**。王林认为天尊、跃天尊从根本上仍是空劫大圆满修士，只因成大天尊太难才作此划分。
- 此真身大成所需之物，其师尊（玄罗）当年带他走过古族多处已然取足。王林回望道古一脉方向的道古屏后山与“那不再年轻的老人”。

## 七、太初本源演化天幕
- 王林挥手将密室天棚化作天幕：蓝天白云、万里晴空，**独缺太阳**。
- 他抓起太初本源掷入天幕，本源融入其中散发万丈光芒，如同太阳。
- 天幕随之运转，如天地规则变换；约过一整天后，化作太阳的太初本源成为夕阳，渐渐消失。

## 八、外界·计都皇子
- 密室外围由诸多侍卫守护，不许任何人踏入。
- 三年中计都皇子未离行宫，于行宫内布置；时有人自外而来与其密谈后带着激动与恭敬匆匆离去。
- 计都皇子风雨无阻，每日清晨亲至密室外，望着密室目露狂热，停留半个时辰后恭敬离去。
