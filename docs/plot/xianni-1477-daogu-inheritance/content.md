# 第九卷 云海之巅·第1477章 道古传承！

## 一、开局：一拳一指的对决

- 王林双目开阖之间同时爆发**神震一拳**与**魔道一指**。
- **神震一拳**：以座椅为中心生出无边波纹，大地碎裂倒卷，宫殿地面崩溃、虚空撕裂，残余尸体尽碎，卷成巨大漩涡风暴直扑拓森。拓森体内砰砰作响，在风暴中挣扎前行。
- **魔道一指**：迎上呼啸而至的**灭神矛**矛尖。神震与魔道之力宣泄于矛身，矛体剧颤、表面浮现细密符文并急剧闪烁，冲击被迫停顿。
- 灭神矛来历：古神涂司一生最强**王族法器**；拓森身为最接近涂司之神，持之威力仅次于涂司。
- 代价：王林手指几乎崩溃，大力灌入体内，嘴角溢血，但神色平静——一切在其算计之内。

## 二、转折：借力接通第三层心脏

- 王林神识顺着**座椅与第三层跳动心脏的奇异联系**上溯，越近反震越强，凭自身之力无法触及。
- 灭神矛灌入的磅礴大力在体内爆发（座椅再裂数道、石台再崩一部分），被王林**强行转化为推动神识之力**。
- 神识如离弦之箭破开反震，进入第三层，与那颗跳动的心脏**连接成功**——真正的传承由此而起。

## 三、传承过程：涂司被抹去，道古降临

1. 心跳如雷回荡心神，王林心脏被牵引，与第三层之心保持**完全相同的跳动规律**。
2. 心脏剧痛，血管疯狂蠕动、大量鲜血挤出染红四周；杂乱如洪水的记忆强行冲入脑海，魂魄撕裂之痛**远超当年古神一损之劫无数倍**，王林凄厉长啸。
3. 第三层心脏似有一声叹息，爆发最后一股大力直冲王林心神：王林喷血、心脏现无数裂缝；身后浮现的**古神涂司虚影**满脸痛苦挣扎，随即四分五裂、如被生生从其古神传承中抹去。
4. 取代涂司出现的，是**一颗与涂司全身等大的巨大头颅**：面目模糊，**左目一片空旷、流下漆黑血液**，神色狰狞——即道古之相。
5. 同一瞬间，座椅下的**如山石台彻底崩溃**，座椅亦震碎大半，扶手碎裂、靠背半毁。

## 四、反击：血剑断矛、重创拓森

- 失去左手食指对抗后，灭神矛再度呼啸直取王林。
- 王林收回左手一甩，**血剑**幻化而出，夹带三重力量：体内足以毁身的大力 + 石台崩溃座椅残破的冲击 + **第三层心脏传承涌现的道古霸道气势**。
- 血剑势如破竹，**将灭神矛一分为二**（如削竹般），余势穿透拓森前胸，自后背而出，血箭四射。
- 拓森喷血倒卷数百丈，半跪于地，猛地抬头。
- 断为两截的灭神矛插在大地上，**矛上所有符文全部崩溃**。

## 五、收获

- **第八星气旋圆满**：王林眉心第八颗星点所形成的气旋由模糊转为完全凝聚，完成成为第八星古神前最艰难的一步，为日后成就**八星古神**打下牢固基础、免去数万年凝聚之苦。八星古神乃古神一族仅次于九星的最强体。
- **古魔尸体解封**：王林右手所按的古魔尸体浑身一震，石化全部崩溃、再无石质坚硬；其右目中急速现出**第五颗魔星、第六颗魔星**。

## 六、抉择：主动中断传承

- 王林左目已模糊大半并流血，继续下去将**彻底瞎掉**，且会如道古一般**失去半生记忆**。
- 失去父母、爱人、故乡的记忆——王林做不到。
- 他凄厉长啸中**第一次从座椅站起、离座**；心脏与第三层心脏的联系骤然中断，座椅彻底崩溃成碎石不复存在。
- 宫殿归于死寂，只余两人急促呼吸。身后巨大虚化头颅慢慢消散。

## 七、宣告与后续动作

> “从今以后，我不再是涂司传承古神，而是道古。”

- 王林右手自古魔尸体上抬起，点在眉心向外猛扯，幽芒闪烁——将当年在**古神之地**所得的**涂司记忆传承**，从心魂内缓缓取出。

## 八、关键结论

- 王林的古神传承路线**由“涂司传承”正式转为“道古传承”**，这是身份与力量根源的根本性切换。
- 传承虽被主动中断（未走完），但已换得第八星气旋圆满与古魔第五、六魔星，同时保住了记忆。
- 拓森重创但未死；灭神矛作为涂司最强王族法器**已被血剑斩断、符文尽毁**。
