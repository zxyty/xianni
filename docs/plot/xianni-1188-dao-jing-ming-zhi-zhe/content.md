# 第1188章 道经

## 一、谷外禁制：梅花十八禁 + 生死禁手法

- 王林（化名「吕子浩」）在青草遍地、无雾可视的区域一路疾驰，时而闭目感应道路，追踪苍松子二人。约一日后停在一处山谷外，此谷紧邻如墙壁般的磅礴山脉，穿谷即达山脚。
- 王林觉此谷诡异，右手掐诀幻化禁制，并一点眉心，射出一条黑线化作**破灭心禁**印记，散黑芒笼罩四周。黑芒下地面青草浮现荧光梅花状图案——**梅花十八禁**。
- 判定：
  - 梅花十八禁**蜕衍于上古四大禁中的破灭心禁**，属禁制阵法中极高的存在。
  - 若在去罗天星域之前，王林无法破解；但他在罗天一行中**传承了破灭心禁**，破之不难。
  - 此禁**一天前**才布下，出自**青衫老妪**之手，用途为**埋伏与示警**。
- 深层发现：王林展开神识寸寸搜索，在梅花十八禁中心处发现若隐若现的黑芒，联想到青衫老妪吸收蛟龙血肉与开启九步封天阵的手法，得出结论——
  - **「以万灵生机化作死禁」**，与上古四大禁中的**生死禁**极为相似。
  - 挖开泥土验证：青草根部已腐烂，生机将尽，**再过数个时辰**此地阵法即彻底开启。
  - 因有苍松子在旁，青衫老妪没时间详细布阵，只能留简单禁制吸收草木生机、待满自启。王林由此对其**高度警惕**。

## 二、王林的反制：鸠占鹊巢

- 决策：**不破阵，改阵**。趁阵法只完成一半、尚未彻底成形时——
  1. 令自己由破灭心禁化作的印诀一震崩溃，化点点黑光散落草地；
  2. 在阵中留下**自身烙印与禁制**；
  3. 使该阵在青衫老妪毫无察觉下**融合破灭心禁与生死禁**（上古四大禁中的两种）。
- 预期效果：**即便苍松子茫然无知中踏入，也会重伤**。
- 王林随后极为谨慎地穿过草地进入山谷，方松口气。

## 三、禁道设定（李元旧言的回忆）

> 攀山途中王林忆起当年离开罗天时李元所言：

- 天地初开即有规则，久化之下分出一道，称「**禁**」或「**阵**」，叫法不同、大意一样。
- 划分层级：**天地玄黄四品**为恒久以来的禁制划分；四品之上还有一层，称之为「**虚**」；**虚化四份，即四大禁术**。
- **上古四大禁**：破灭禁、生死禁、**古魂禁**、神秘莫测的**岁月禁**。即便仙界禁制，也大都由这四大禁繁衍流传至今。
- 传言：若能把四大禁**全部学会、融于一起**，凭莫大智慧可从中**感悟出「虚」**——禁制中的巅峰。但自天地初开分出禁道以来，**无数万年从未有一人做到**。

## 四、登顶与雾海

- 半日后，王林在天空七彩之芒笼罩下立于山脉最高处，遍体七彩，远望如仙神。
- 山脉如城墙般**成环形缭绕**，将内外分割为两个不同地域；环内弥漫浓雾，景物不可见，**仿若一片黑色海洋，波涛汹涌**。
- 王林清晰感应到**苍松子就在雾气内**，目中一片冰冷，顺山脉跃下潜入。

## 五、苍松子与青衫老妪：雾中石像

- 苍松子身穿**神魔甲**、神色谨慎，每一步都心神紧张；青衫老妪身外黑气环绕。
- 苍松子暗算时间，认定「**那姓吕之人**」此刻应已死亡，并寄望擅长**搜魂**的**庞德才**有所收获，尤其看重**役灵印**——「此术乃**神宗**大神通之术」；并推断庞德才此刻已在路上。（伏笔：王林未死，正尾随而来）
- 二人在雾中遇一**高约百丈的巨石雕像**：雕一男子抬头望天、目露沉吟，**眉心之上有一个闪电样子的印记**。青衫老妪见此印记**面色突变**（似有所识）。

## 六、铭志者与道经

雾中传来飘忽不定、蕴含穿透灵魂之力、分不清方向的诡异声音（「铭志」三段）：

1. 「铭志，囚封天之道，众生需渡无量劫，离开深狱一执念，奉至修真行」
2. 「铭志，众生亦于无量前，解今茫世，脱困天之念，取来生道，奉至修真行」
3. 「铭志，锁亡天之运，印冥朝，众生之所不得真道者，常沉苦海，永失真道，奉至修真行」

- 效果：话语停留心神不断回荡，**使青衫老妪元神震动、道心不稳**，苍松子面色苍白、恐惧四顾。一道虚幻之影自雾中飘出，速度极快，自二人中间穿过。
- 苍松子解释：
  - **迷失者**：失去了自己的道，在迷茫中寻找，不断飘荡在**七彩界**。
  - **铭志者**：拥有**道境**，却因**看了道经**而**道心崩溃、无法重新凝聚**，唯有飘摇雾中，无数万万年地追寻；他们或许已死，剩下的**只是因执念而生的道魂**。
- **道经**：苍松子双目狂热地称，在发现七彩界之前从未听闻此物，进入这里后从**无数蛛丝马迹**中知晓——天地间有一部道经，**传闻此经以「天道之血」所化**。
- 青衫老妪震骇：铭志者们始终诉说的，莫非就是那道经。

## 七、要点与伏线

- 王林手中已握上古四大禁之一（破灭心禁）的传承，并首次实操性地**逆用他人阵法**做成合成杀阵，直指苍松子。
- 苍松子/庞德才一方仍误判「吕子浩」已死，情报差成为王林的最大优势。
- 本章正式抛出本卷核心宝物线索：**道经（天道之血所化）**，及其代价——**看经者道心崩溃、沦为铭志者道魂**。
