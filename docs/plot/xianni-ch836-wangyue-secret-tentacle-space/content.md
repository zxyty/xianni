# 第836章 望月的秘密（第七卷 名震罗天）

## 一、皮甲两难：护元神与招望月
- 望月体内剧烈咆哮回荡，王林元神如被撕裂，七窍流血；先前有**古神皮甲**护持时感觉不明显，此刻不得不再拍储物袋取出皮甲，重新笼罩元神，方能承受轰鸣。
- 副作用立现：古神皮甲散出的气息，令望月体内暴躁的**小型望月**须发扭动、疯狂扑来。
- 设定要点：这股气息任何修士乃至上古凶兽都无法察觉，**世间除星痕貂等有限生灵外，唯有望月对古神之气极为敏感**。
- 两难：取下皮甲 → 元神在咆哮中崩溃；穿戴皮甲 → 引来望月群。王林千年修道，清醒地判断望月不会因古神之气认主，其大口是要连他一并吞下。

## 二、被围与被吞
1. 泥土裂开，一头十几丈望月冲出，吞噬王林体外散出的气息。
2. 更浓阴寒袭来，一头**百丈望月**自身后裂缝冲出，须发缠身、口流粘液。
3. 王林改向，四周十多处裂缝齐开，大小望月尽出追击。
4. 王林元力外放形成**漩涡般的坍塌之力**加速后退，仍被前方上百裂口涌出的望月合围。
5. 关键转折：望月体内一声剧烈咆哮，小望月尽数退后让开通道；一头**长约万丈的灰色望月**冲出，气势不弱于**血祖**，速度不可思议，一口吞下王林后钻入泥土，众望月随行。

## 三、望月脑部：月华与触手空间
- 万丈望月在母体内如鱼得水，半柱香后抵达一处无泥土之地：一个缓缓旋转、每转一次即散出阴寒之气的**巨大漩涡**——正是**望月脑部所在，即月华存在之处**。
- 万丈望月张口一吐，王林毫无反抗之力被推入漩涡，消失不见；漩涡外望月群尽数趴伏不动。
- **封修为的诡异气息**：被吞时一股气息冲入王林体内，令元力停转、仿佛与肉身分离，使其“从修士彻底变成凡人”；随后元神之上的古神皮甲传出吸力将其吸收，元力恢复运转。

## 四、鼎与人：望月的生命源泉
- 漩涡内是一处**狭长空间**，虚无中延伸出一根根缓缓蠕动的触手。
- **贪狼大鼎**：前方一个大鼎被无数触手缠绕吸收其内气息，触手上鼓包蠕动、把吸得之物传向虚无。此鼎**正是贪狼之物**，散发古朴沧桑气息，鼎内气息更浓。
- **被缠之人**：几乎每根触手上都缠着一人，干瘦如死尸、双目紧闭、生机全无，男女老幼皆有，且**不全是修士，还有凡人**；深处一望无际，可推想更多。
  - 其中一名约**六七岁男童**，皮包骨不成人形，脸上仍保留极致痛苦与绝望的表情。
- **王林的推断**：这些人是无数年来被望月吞噬积累的**生命源泉**；进而怀疑当年望月所化的**云霞星**上那些城池废墟——“他们真的是迁移走了么”。

## 五、躲入鼎中与姚冰云现身
- 虚空中无数触手以闪电之速缠来。王林判断：若无古神皮甲，他此刻如凡人般毫无抵抗、必被吸尽生机而亡。
- 王林**不愿破坏触手**（怕惊动望月引来新举动），选择闪避，身如飘渺烟丝直扑大鼎；发现触手只在鼎外缠绕，不愿延伸入鼎内，遂**钻入贪狼大鼎之内**。
- 就在其入鼎刹那，入口漩涡爆发喷力，吐出一名**面色苍白、双目紧闭失去知觉的女子**；触手分出一半将其卷起吸收生机。
- 该女正是**姚冰云**：衣衫被腐蚀破损、露出大片肌肤，连**储物袋都崩溃**。本章结尾，她**睫毛一颤，睁开了双眼**。

## 六、悬念/待续
- 姚冰云醒来后处境（正被触手吸取生机）与王林在鼎内的应对。
- 贪狼大鼎为何令触手不敢深入；鼎与月华、望月本体的关系。
- 云霞星原住修士与凡人下落的黑暗真相是否被坐实。
