# 第七卷 名震罗天 第689章 一生不要修道

## 一、场景：祁连峰下的落月村

- 天蓝云白，祁连峰下一条小河蜿蜒数里汇入大江，中游处有一山村，山青水秀如田园之地。
- 一名十四五岁虎头虎脑的少年（周家大汉之子）向七八个孩童讲述五年前旧事：河水曾是甜的，祁连峰上时有云雾，吸一口可强身健体、十年不生病；自五年前「老天爷发怒」后雾气消失。
- 少年提议众孩童天天练剑法、强身健体，长大持剑走江湖，并把这场聚会称作「武林大会」。炊烟起、家家呼唤，武林大会散场。

> 注：「五年前老天爷发怒」为凡人视角对冉云星大变（王林相关战事）的模糊记述，本章未点明具体因由。

## 二、王平：怨婴的新生

- 男孩王平约五、六岁，面色苍白、身子柔弱、个头矮小、相貌极为俊美，穿葛布小衫；被少年称「你最该去吸一口云雾」。
- 王平称父亲为「王大叔／木匠」，回家后向父亲提出想去祁连峰看看。
- **真实身份**：王平便是当年的**怨婴**。在服下**柳眉留下的丹药**与王林**雷系神通**调理下，体内怨气已消散很多，可如正常孩子一般。
- 若每日不服药、不梳理怨气，仍会复发，需一个过程才能完全驱除。
- 王林已**抹去王平的记忆**，给了他一个新生。
- 药为碗中白色液体、无任何气息，极苦；王平饮后需舀水漱口。问「什么时候才可以不喝药」，王林答「快了」。

## 三、王林的凡人生活

- 五年前王林回到**冉云星**，选择**落月村**定居，理由是此村与他当年的家乡极为相似。
- 外貌与身份：相貌平凡的青年，粗布衣衫，双手生满茧子，与俊俏的王平站在一起常被认为不像父子。
- 以**木匠手艺**为生，如同他父亲当年的愿望——若科举不行，便做木匠，子承父业地生活下去；院中摆满各种木匠工具，是五年生活的写照。
- 心境：远离杀戮与纷争，平静如水，「过的很踏实」。看王平出去玩耍时，常想起当年同样不到吃饭绝不回家的自己。

### 邻里：周家大汉

- 村口归来的猎户周家大汉，身材魁梧，持钢叉箭矢，肩扛獐鹿；称王平「王家小娃」，夸其俊俏知礼。
- 事由：其子年纪不小，两年后欲娶媳妇，近期要盖房，缺一套家中布置，请王林打造；以**獐鹿作定金**。

## 四、深夜：以雷光驱怨气

1. 王平熟睡，王林盘膝在旁，眉心雷光闪烁，雷光顺眉心游走至右手指尖。
2. 右手按在王平眉心，电光流转其全身，黑气自体内涌现凝于皮表。
3. 黑气浓郁翻滚、冲出体表，王林一抓将其尽数握住，凝成黑色雾球，握拳捏碎。
4. 王平脸色略有红润。王林为其盖好被角，走出房舍，月下轻声：「五年了」。

## 五、与孙泰的对话：核心抉择

- **孙泰**于王林定居第三年来到落月村，如同一个孤独老人，不愿临终前独自一人离去；此时更加苍老，满脸皱纹，**身上死气更浓**。他对王平极为喜爱，自己也不知为何。
- 孙泰问：「你打算陪这个孩子多久」——王林望月答：「**一世轮回**」。
- 孙泰劝说：以王林修为，可让这孩子在修道路途上比修真家族嫡系长子还有优势；并指出「这孩子的天资，很好」。
- 王林两度拒绝，态度决绝：「我不会让他去修道，一生都不会」「我不会让他修道——**永远**」。
- 王林内心自白：修道到最后剩下什么？自问一生**不幸福、寂寞**；修真界的残酷、杀戮与凶险他明白得太多，不愿孩子经历。
- 命名之意：「平儿经历了很多不该发生的事情，我给他起名王平，便是希望他这一生，平平安安，如一个凡人般娶妻生子」——「修道之事，从此之后，莫要再提」。
