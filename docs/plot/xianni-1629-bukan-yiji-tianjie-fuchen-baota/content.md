# 第1629章 不堪一击

## 一、场景与开局
- 地点：昆虚星域，王林所在的百万范围雾气之中；上空有万丈裂缝，为天劫来源。
- 王林以**真假道**化作**幻真之劫**，令百万雾气化出一个个带着挣扎咆哮的身影，直冲上空裂缝。
- 巨响回荡整个昆虚星域，裂缝在王林降劫之下剧烈颤抖。王林白发飘起、寒目直视，从容迈步而去，每一步落下皆有轰天之声，令裂缝颤抖更剧。
- 王林心境：不畏天劫，**有一颗大儒之心、一股浩荡之气**，认为天地万物皆平等，天劫亦不能超脱。其求索之问：“万物皆有本源……遇天劫因何而出，因何而起，因何会出现在这天地之间。”

## 二、第一件天劫法宝：三千拂尘
- 距裂缝不足万丈时，裂缝内射出光芒照亮漆黑星空雾气，飘出一把**极普通的拂尘**：七尺大小、紫色之木为杆、无名白发为拂丝，**拂丝三千，似象征三千大道**。
- 拂尘向王林轻甩，三千拂丝无风自动，一股无形之力化作法纹波纹扩散。王林脚步略顿即毫不犹豫落下，如流星直扑拂尘。
- 拂丝逐根从根部分离、化作法术神通：
  1. 第一丝 → **引力术**
  2. 第二丝 → **火球术**
  3. 第三丝 → **杀戮剑决**所化无尽杀戮剑气
  4. 第四至数百丝 → **寂灭指、黄寒指、化魔指**等王林第一步时所见的诸般神通（有的曾为其掌握，有的是他看过别人施展）
- 更深层的神通来源：**清水**的神通、**司徒**的神通、**白凡**的呼风唤雨山崩地裂；其内还有**青霖、水道子、鲁夫子**等人神通，甚至**太吉五尊、一代朱雀、二代朱雀**等人的神通亦在其中。
- 结果：三千拂丝化作三千种「王林一生所见」的神通，凡王林记忆内存在之术，大半在这一刻出现于星空，彼此完美融合，随拂尘一扫笼罩王林四周全部星空。

## 三、关键推断：天劫来自远古仙域
- 三千神通之所以致命，在于每一个都透出让王林熟悉的气息——**仙力**。
- 此仙气并非界内四大仙界所蕴含的**仙玉气息**，而是**真正的仙人之气**，即来自血脉的金色光芒。
- 王林能瞬间辨认，是因为：若非当年遇到**疯子**、若非其眉心有**仙人不灭体所化金色血液**，他无法辨识。
- 王林由此定论（本章重大信息）：
  - 「这天劫，来自远古仙域」；
  - 「那裂缝后的世界，就是远古仙域」；
  - 「这远古仙域，与**仙罡大陆**有极大的关联」。
- 淡金色光芒裹挟三千神通落下，轰击之下星空震颤，王林身影被金色光芒完全掩盖。

## 四、第二件天劫法宝：九层镇仙宝塔
- 裂缝内再飞出**九层宝塔**：通体金色，无上威压浩然，出裂缝后自行膨胀至**数万丈**，向被金光掩盖处轰隆镇压。
- 天劫构成总结：**三千拂尘为天劫，宝塔镇身又是天劫**，此番针对王林的**第三步天劫**前所未有地强大。
- 修为门槛（原文明示的强度标尺）：
  - 空涅初期 → 必死无疑；
  - 空涅大圆满 → 同样要在此劫下崩溃身亡；
  - 如今**空灵中期**，若如寻常大能那样只有**一道本源**，也断无生存可能。
- 宝塔落下后万物皆静，百万范围雾气中只剩这座「仿佛亘古以来就存在」的九层金色宝塔。

## 五、雾气外：司徒南与南云子的对峙
- 寂静令众人心神一震。**南云子**双眼盯雾气，面露焦虑。
- **司徒南**隐感不妙，二话不说欲冲入雾气，被南云子右手挥舞阻止。司徒南猛转头，双眼疯狂、话语蕴含滔天杀机质问「南云子，你要阻我」——他明知不敌，但依其性格，纵使师尊**青霖**在前也会毫不犹豫出手。
- 南云子沉声劝阻：「**封尊在渡劫**，我等不要干扰，你强行过去不但起不到作用，反而会让他分心。」
- 司徒南握拳沉默，沙哑给出期限：「我等**半柱香**，半柱香若里面还是如此安静，我一定要过去。」
- 数千界内修士人心浮动，疑「莫非封尊渡劫失败」，亦有人坚称「封尊绝不会失败」。

## 六、战老鬼的旁白：天劫的底细
- **战老鬼**神色越加兴奋、舔唇喃喃：「**三九拂尘、镇仙宝塔**，应该还有一物名为**封命环**——他当年设置府内天劫时，便把这三样法宝投入其中。」
- 含义：此「天劫」实为某位存在当年**以三件法宝人为布设的府内天劫**，共三件（拂尘、宝塔、封命环），本章仅出现前两件，封命环为伏笔。战老鬼看向雾气的目光越加诡异。

## 七、塔内破局：古神之力
- 塔内一片混沌：三千白色拂丝落在王林身上后**如回归本源**般重新化回拂丝，死死缠绕、仿佛封印；塔内金色光芒充满霸道意志，要以光炼化、以仙力融化王林。
- 天劫不知的变数：**王林眉心存在着这天地内最精纯的仙人血脉**。
- 王林摇头：「所谓天劫，就只有这些神通么？若真是如此，这天劫太弱。」
- 破法：**眉心古神星点急速转动**，阵阵**古神之力**流转全身，身体疯狂腾胀——十丈、三十丈、百丈直至**数百丈**，如同巨人；缠绕拂丝被绷直、部分碎开；在其身成**古神**的刹那，古神气息骤然扩散，**所有拂丝全部崩溃殆尽**。
- 王林再次摇头：「**不堪一击**」，向上迈步，右手一握拳，古神之力如大浪轰卷，**一拳轰向塔内之顶**。（章末悬置）

## 九、要点速览
- 天劫首次被王林定位来源：**远古仙域**，且与**仙罡大陆**强关联。
- 天劫非纯天道，而是人为投入三宝布设：**三九拂尘 / 镇仙宝塔 / 封命环**。
- 王林当前修为：**空灵中期**；破劫依仗：**仙人不灭体金色血液** + **眉心古神星点/古神之力**（非常规一道本源）。
- 界内众人称王林为**封尊**；司徒南对其忠诚到可对师尊青霖出手的程度。
