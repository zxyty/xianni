# 第七卷 名震罗天 第673章 云霞有金，五行缺一

## 一、遗物勘验（承接前章所得三物）

### 1. 火石（金属性火石）
- 天然形成，但杂质太多、金属性蕴含太少。
- 王林评价：若无此瑕疵，威力「不弱于顶阶伪仙宝」，若体积更大甚至可媲美「下阶仙宝」。
- 若强行炼化去杂，体积将不足眼下的十分之一。

### 2. 幻家身份令牌
- 神识扫入后令牌散发夺目之光、变幻三次后恢复正常。
- 表面看只是身份标示，反复神识探查无异；王林觉不对劲，唤出「仙卫」——影子延伸紧贴皮肤弥漫令牌，借其阴阳虚实变化看破端倪。
- 结论：**令牌内藏一个与「命魂」有关的神通**，故幻家应已知晓其族人死亡。

### 3. 玉简
- 玉简上无神识，只余死者一丝怨念——说明冉家老祖三人忌惮极深，连神识探入都不敢。
- 王林神识融入，怨念立散，同时触发一道**无形传讯波纹**；他双目射出闪电将波纹当场击碎抹灭。
- 内容其一：**幻家神通修炼之法**，确认此幻家即「千幻无情道」千幻星的幻家；关键处以特殊禁制遮掩，**破解之法为血脉**，外人得之亦看不出。
- 内容其二（真正让王林动容者）：四年前死去的幻家之人所记消息——**「在云霞星，发现一条金炎矿脉，取其一对」**。

## 二、王林的判断与决意

- 那对火石即出自云霞星金炎矿脉；此人被追杀重伤逃至冉云星，正因此等天才地宝任谁都会抢夺并封死消息。
- 由此推断：冉家老祖三人应不知此事，否则不会让王林参与（但不排除其中另有玄机）。
- **核心动机**：天逆珠子只差金属性；一整条金属性火石矿脉当可令其圆满。按**司徒南**所说，天逆圆满后便可认主——认主后有何神通，尚不可知。
- 立场宣示：消息一旦泄露，「这一次，谁和我抢，我便杀谁」。

## 三、索取星图与十日筹备

- 王林神识横扫冉云星，直接降临孙析所在（孙家祖宅），传音命其把**罗天星域所知一切星图刻于玉简送来**；孙析照办。
- 十天后：
  - 已在星图中找到**云霞星**，距冉云星甚远，即便不耽搁，一去一回也需数月。
  - 孙析注解：云霞星**无修士存在，是废弃星球**，遍布可致修士身亡的**毒雾与瘴气**。
  - 王林熟记星图，并整理自身法宝。

## 四、离星受阻：三人拦路

- 王林走出房府，瞬移至数万里外虚空，直冲罡风层；冉家老祖、逍遥散人、孙析挪移拦在前方。
- 三人态度：冉家老祖面色阴沉、逍遥散人隐怒、孙析苦笑（他早在王林索要星图时便觉不妙）。
- 王林（化名**许木**）冷淡表态：「许某答应之事，便不会反悔，此去多则一年，少则数月。」——若非看在仙玉份上，本不会解释。
- 三人猜疑之由：刚献出全部家底不到半个月，王林就要离开冉云星。

## 五、幻东降临与开战

- **幻东**踏星罗盘冲入冉云星罡风层，如流星降临，神识与仙力全开，造出「天神下凡」之势。
- 内心动机：「小姐把此事交给我来处理」，要做得干净利落——**所有参与之人全部杀死**，以求被小姐看中。
- 自报名号：**「在下千幻主星幻家二品族卫幻东，冉云星问鼎修士，速来见我」**；声如奔雷传遍全星，问鼎以下修士心神剧震，不少低阶修士被震得喷血（含孙家小城山石下的那名青年）。
- 冉家老祖、孙析、逍遥散人面色苍白，齐齐望向王林，绝望中见一丝生机。
- 王林「拿人钱财，替人消灾」，神识化奔雷锁定天际，凝成一字：**「滚」**。
- 幻东怒喝「找死」，右手掐诀化出白光，阴寒气息弥漫：
  - 其为幻家之人，但**资质受限无法修行千幻无情**，所修为幻家**二等道法「心意五行诀」**；
  - 所悟意境为五行诀中的**金诀**（无坚不摧），意境随神通而动化作右手白光，好似夺天之光，向下一按。
- 王林目中电光游走、波及全身，如掌雷霆之仙，右手一指——**寂灭指风**呼啸而出，其上蕴含浓郁电光，威力暴增数倍，观之如面临雷霆天劫。（章末，战斗未完）

## 六、线索与伏笔

- 令牌命魂神通 → 幻家已知族人身亡，追杀是必然，幻东只是先头。
- 幻家神通需**血脉**解禁 → 王林手中修炼之法暂难直接习得。
- 金炎矿脉 → 天逆珠圆满 → 认主（司徒南之言）。
- 云霞星毒雾瘴气 → 后续取矿的环境难题。
