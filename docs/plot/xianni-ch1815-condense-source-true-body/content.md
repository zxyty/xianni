# 第1815章 凝本源真身！

## 一、玄罗：闭关待徒（仙罡大陆·吉国一线）

- 玄罗判断：有其**金印**在王林身上，即便王林身处**仙族之地**亦应无碍；既然来了，就先不急于接回，让其磨练一番，则此子未来更是无限。
- 玄罗不亲往仙族之地：以其身份多次前往必引起没必要的波折——正如仙族的几个大天尊若总来**吉国**，也定会被驱赶甚至联手围攻。
- 之前的仙族之行虽得脱身，仍留有伤势，故而闭关；闭关另一原因是「等不到王林」的遗憾。如今**心疾已去，伤势也就无碍**。
- 玄罗慈祥而语：「王林徒儿，**仙罡大陆是你的家，道古一脉是你的故乡**，为师在这里等你归来。」言毕闭目吐纳。

## 二、天牛洲：本源真身，凝

### 起手
- 地点：**天牛洲**内，**杜青**护法之处。王林盘膝坐于一丈火球旁，双手掐诀，一道道印记融入火球，其内**朱雀**愈发清晰、嘶鸣愈发高昂。
- 数个时辰后，王林猛睁双眼低喝「**本源真身，凝**」，声如雷鸣落入杜青耳中。
- 火球轰鸣，旋转的朱雀一顿，尾部大量羽毛燃烧，红芒闪烁间隐隐化作**人形双腿**——似真身正慢慢凝聚。

### 凝真身的底气与代价
- 王林原本的**火本源不足以凝聚本源真身**。转机在于：
  1. 吸收了天牛洲的**十六条支脉**；
  2. 吞噬了**一条子脉地火魂**；
  3. 尤其吸收了**子脉魂内『火的意志』**。
- 由此其火本源**拥有了自己的意志**，可与天牛洲之火争夺**天地之火的操控**，方才萌生凝聚本源真身之念。
- 代价：压力滔天。王林额头汗水一出即化水汽，缭绕全身，人如藏于雾中若隐若现；拼尽全力也仅凝出**双腿**。

## 三、抽脉：一百七十二条支脉魂

- 火球渐暗、火焰将熄，其内朱雀肉眼可见地枯萎——**火焰本源不够**所致。
- 王林落于山峰，右手按地，**神识**顺大地疯狂蔓延：千里、万里、十万里、百万里、千万里，直至无尽。
  - 这是王林**第一次在仙罡大陆如此展开神识**；但对整个天牛洲而言覆盖不到一成，连半成都不到。
  - 该范围**无限接近整个洞府界的大小**；其内共有**一百七十二条地火支脉**与**两条地火子脉**。
- 王林咆哮「一百（七）十二条地火支脉魂，给我抽出来」，抬手之下天地轰轰：
  - 山峦崩溃，支脉龙魂呼啸；平原现裂缝、岩浆爆发、龙魂冲出；河流干枯、河道龟裂中龙魂飞舞。
  - 龙魂身形寻常修士看不到，唯大神通者可感。
- 一百七十二条龙魂虽狰狞反抗，终究无法摆脱冥冥中的**火之意志**——那正是王林吞子脉后所得、属于他自己的火本源意志；**除主脉外，其余支脉子脉全部要被此意志操控**。
- 龙魂冲入一丈火球，火球熊熊复燃，朱雀欢快嘶鸣狂吸火本源之力，**双翅化作充满火焰印记的双手**。至此**四肢齐备，只剩身躯与头颅**。

## 四、抽脉：两条子脉龙魂（东雪山 / 西内陆海）

王林咬牙双手同时按地，大地如浪起伏，神识范围内两个方向传来极强悍咆哮：

| 方位 | 地貌 | 龙魂显化 |
| --- | --- | --- |
| 王林之**东** | 数万年不化的**雪山** | 山体震动，积雪瞬融成海浪状，未流远即化白气升空，白气内凝出一条**地火子脉龙魂**，仰天咆哮直奔王林 |
| 王林之**西** | 被天牛洲包围的**内陆海** | 海底深处一条形如龙的**地底山脉**震动，海面成漩涡巨浪，魂之波动凝无数海水化**海龙**冲出大海；升空后身躯自蓝转红，化作**炎浆之龙**（每滴海水皆蕴无穷火本源） |

- 两条龙魂呼啸而来，似将天空燃出两道长痕，杜青面色大变。
- 分工：王林一跃直奔**海水所化炎浆之龙**；并抛话「**杜青，给你个机会，牵制一条龙魂半个时辰**」。
- 杜青咬牙跃起，全身紫光弥漫，**化作木头身躯**，走向另一条子脉龙魂。

## 五、杜青视角：造化与恐惧

- 杜青修为**未达空劫初期**，仍处**七次玄劫**之中，对第八、第九次玄劫无把握、不敢去度。
- 这是他**第一次亲眼看到本源真身的凝聚**：此等场面天地间罕有人见，对其**本源变化帮助巨大**，为其日后修炼「轰开了一条道路」——原本模糊的道路此刻愈发清晰。
- 他亦生恐惧：如此磅礴的火焰本源之力仍未能完全凝出真身，足见本源真身之罕见与「越往后困难越大」。
- 关键认知：**此人有七道本源**——若七道本源最终全部凝出真身，杜青不敢想象。

## 六、章末作者感言（非剧情）

- 王林名扬仙罡在即，「仙逆三百盟」奇迹将现；感谢爱在、西元前、湖蓝月漾杀入仙逆盟主之列，以第三步大能之身追随王林冲破洞府牢笼；耳根赠**七彩神枪仙术**以表谢意。

## 七、待续悬念

- 本源真身仍差**身躯与头颅**，两条子脉龙魂能否补足是下一步关键。
- 王林在仙罡大陆的神识覆盖仅及天牛洲不到一成，天牛洲**主脉**未被其意志所控，主脉归属仍是变量。
