# 第1791章 四灵铺路梦道在（第二更）

## 一、场景与目标

众人欲离开此界、转世投胎于**仙罡大陆**。此次转世**不在仙罡大陆本土进行**，因此重点在于**对抗仙罡规则**，另有「迷失之危」「迷障锁魂」等风险。玄罗遂连出四大灵兵，为众人铺出一条完整的转世之道。

通道入口为**洞府大门**，门内原为金色混沌模糊的雾气。

## 二、玄罗四大灵兵铺路

### 大一灵：龙皇鞭 → 龙身之路
- 玄罗右手挥出**龙皇鞭**，鞭出幽光如巨龙咆哮，一击轰碎门内金色混沌，撕开一道深不见底的漆黑裂缝。
- 门内有奇异压力自四周挤压，裂缝急速收缩。
- 玄罗连续抽出**九下**，第九下时龙鞭膨胀至**数万丈**，撕开全部雾气，**生生铺成一条龙身之路**——「此路幽幽，通往仙罡，如轮回之路」。
- 玄罗告诫：以龙身为引，方可去往转世之程。

### 大二灵：山妖 → 冰封守路
- 以「以老夫玄罗之名，命幻出」召出，显化为一座**通体白色、无边无际的巨大雪山**。
- 来历：玄罗当年**炼化仙罡大陆一处万古之山**，凝聚无数山魂，祭成**妖仙**。
- 作用：抵御转世的**迷障锁魂**，护魂不散。雪山散开后龙身之路四周尽数冰封，白色直没深处。
- 至此「轮回之路，守路之雪」齐备，转世之道方才完整。

### 大三灵：剑仙 → 剑气为锋
- 玄罗左手指眉心，眉心裂开一道缝隙，紫芒中飞出**一把巴掌大小的剑**。
- 来历：于仙罡大陆外碎星辰中**炼化九万九千九百九十九颗碎星辰**祭成；为使此剑开灵，更**杀入仙族取同等数量仙人之魂**。
- 特性：**大凶**，「出则大地避，仙族惊」。
- 作用：作转世者的护送之法，剑气弥漫全路，保一路安全。

### 大四灵：风魔 → 记忆封印
- 玄罗咬破舌尖喷出**珍贵精血**，赤血出现刹那转为黑色，黑血蠕动散出大量黑气，凝成一道被黑气缭绕的模糊身影。
- 魔气来源：**并非古魔之气**，而是大地间意志所化——众生邪念凝聚成魔。
- 来历：经玄罗**祭炼三次转世岁月**，收取**三十六亿至凶至恶之人的邪念**凝成，已具灵智，可称**魔灵**；在**道古一脉**设有其**魔牌**吸收供奉之力，为玄罗**最强三兵之一**。
- 作用（关键设定）：
  1. 化作封印，使转世者**记忆不损不缺**；
  2. 被点化的刹那即可**恢复全部记忆**；
  3. **除非转世后肉身被同为「大大尊」者仔细搜魂**，否则无人可知其前世身份。
- 黑雾弥漫全路的冰层与道路，最终平息成**如镜之貌**。

> 四兵齐出后玄罗神色不变——修为通大且早有准备，消耗瞬息恢复。

## 三、血色太阳与王林的梦道

- 玄罗捏拳松开，掌心浮起一轮**血色太阳**，为其**自身大大尊之力所化**；本为无形神通，经其目光一扫**咔咔化为实质**，可触摸、可握住。
- 交予王林时言：「可以让你的意境神通无限的扩展」，令王林以此**全力施展梦道之术**，向身边所有人封记忆于梦中，等待日后寻找点化。「对于他们来说，这一次转世，就是一场梦。」
- 王林触之心神一震，感到其中**令魂颤、无法理解的气息**，暗忖「这就是九阳大大尊的力量么」。
- **梦道**为王林自创神通，借此宝无限扩展后威力**暴增数倍，几乎达到「梦忆成真」**的地步。

### 封记过程
1. 无形波纹自王林体内散出，笼罩四周众人；包括**李倩梅**在内所有人闭目入梦。
2. 约**一炷香**后，王林眉心浮现模糊符文，众人眉心亦有符文若隐若现。
3. 诸符文**相互辉映、暗有联系**，可让王林**多年后循此寻到他们**。
4. 血色太阳「咔」的一声碎裂消散，众人睁眼，眉心符文由若隐若现转为**极为清晰**。
5. 众人彼此可隐隐感受存在，王林感受尤强。玄罗称：转世后此感觉会**虚弱**，但只要**距离不远仍可冥冥感受**。

## 四、依次踏入转世之路（离别）

| 顺序 | 人物 | 情形 |
| --- | --- | --- |
| 1 | **青霖** | 长叹前行，门外转身向王林抱拳：「王林，我们仙罡大陆见」，洒脱之下眼中透出不舍，步入如镜如墨的雾气消失。 |
| 2 | **青霜**（青霖之女） | 神色冷漠，踏入雾气前脚步一顿、回头扫向周佚，冷声：「希望以后，不要来烦我」——语似另有深意。 |
| 3 | **周佚** | 本欲随行，被王林以丝线般的力量拦住；王林传音：「周大哥稍等片刻，你的事情，我会想办法帮你在转世投胎时，完成。」最终背影萧瑟、带着迷茫与执着走入门内。 |
| 4 | **清水** | 唤王林「师弟」，笑言「我在仙罡大陆等你」，并托付：若先找到我的女儿，请代我照顾；望向红蝶时目中慈爱很浓。 |
| 5 | **红蝶** | 目送清水消失，泪水止不住，欲言又止，化作**如蝶般的红色长虹**没入洞府大门。 |

### 王林赠印助周佚
王林与周佚**相识已两千年**，深知其对青霜的痴情。见其苦涩，王林抬手在眉心一抹，**取出自己符文的一部分**（自身眉心符文因而略暗），按在周佚额头：

> 「我把青霜记忆封尘的印记，送到了你的身上，这样一来，你与她转世投胎后，或许会有些许的联系，或许，你们可以遇到。」

## 五、要点归纳

- 玄罗四灵构成完整转世之道：**以龙身为道，以雪山冰层为守，以凶剑剑气为锋，以魔灵黑雾为记忆封印**；除仙罡规则本身外，抵御了一切可能变故。
- 王林的**梦道**在此章升格为整个转世计划的枢纽——他是日后**唯一的点化者与寻回者**，众人眉心符文即为凭据。
- 本章为大规模离别章：青霖、青霜、周佚、清水、红蝶先后转世，情感线（周佚—青霜、清水—红蝶）留下明确的后续伏笔。

- 王林允诺**在转世投胎时帮周佚完成其事**（周佚与青霜之事），已先赠青霜封尘印记。
- 清水托王林**照顾其女红蝶**（若先找到她）。
- 青霖之约：**「仙罡大陆见」**。
