# 第八卷 联盟隐秘 第931章 次空涅

## 一、玄宝上人亮出底牌

### 雨之仙卫（金品）
- 玄宝上人望着被众多罗天修士环绕、咆哮前行的望月，笑称「没想到雨之仙界古籍所记录，居然是真」。
- 他右手虚空一挥，口称「雨之仙卫」，身前虚无被横撕出一道不下百丈的裂缝，如同伤口翻卷。
- 裂缝中先后走出**四个金甲大汉**，全身金芒刺目如金阳，身着绚丽铠甲，形如天兵，整个星空被四道金阳之光笼罩。
- **王林的判断**：这四人身上散发如塔山一般的气息，分明是以**仙帝青霖秘术**祭炼而出的**仙卫**；仙卫分**金、银、铜、铁**四级，这四人已达**金品**。王林当即退后，向万里漩涡崩溃的边缘避走。
- 交战表现：四仙卫直奔望月，分东西南北四方合围；血神子掐诀凭空生出血海拍去，冲击仙卫身上只略微一震，未能让其有半点停顿。后期四仙卫低吼胀大至**百丈之高**如同巨人，齐齐展开攻击，金光连成环形圈锁住望月。

### 九只黑色蝴蝶
- 玄宝上人再度虚空一抓，裂缝内散出磅礴威压，九只**通体黑色**的蝴蝶翩然而出，翅膀一扇即掀起无尽风暴。
- 风暴以望月为中心形成漩涡，仿佛与天地连接；后又有无数**黑线**弥漫交错，在望月体外形成包围。
- **王林的震撼**：他一眼认出这是**射神车幻化的蝴蝶**，但立刻发现不同——射神车之蝶五彩斑斓、极为美丽，这九只却通体黑色，「走的是另外一个极端」。
- 仙卫与蝴蝶这两样法宝王林自己都有，如今却见于他人之手，令他头皮发麻、震撼至巅峰：连清水、连那位阻止清水与血神子交战的神秘修士，都没让他如此无法置信。他反复自问「这老者，到底是什么身份」。

### 次空涅箭（章末悬念）
- 玄宝上人虚空一抓，裂缝中喷出一股**青气**，其中蕴含令方圆数万里内所有修士心神剧震的可怕气息。
- 青气宣泄中缓缓落下一支**箭矢**：长约三十多丈、七尺粗细、通体青色，箭尖成六棱之芒，箭尾四下排列紫色羽毛，箭体上带有**暗黑色血迹**。
- 真正令数万修士心神撼动的，正是那**暗黑色血迹**。
- 此箭一出，血神子等人面色大变，连星空中正与武东禅交战的**炎雷子**也身子一震、一眼看到。
- 章末点题：「**次空涅箭**」。

## 二、王林：浑水摸鱼夺木雕

### 王林之力的初端
- 王林判断此战已非自己可以参与，**浑水摸鱼**才是首选，直奔前方漂浮的**半截木雕**（黑煞魔尊此前拿出之物，此刻只剩半截，其上仍有威压弥漫）。
- 木雕外已有数名修士厮杀相争；王林到来后，罗天方面几人略一犹豫，联盟方面则立刻分出数人扑向王林。
- 王林掐诀挥出狂风法术，同时右手握拳狠狠一击，**拳风波纹与法术狂风融合**，形成一股独属于他的力量——其中**蕴含了法术的神通与古神的巨力**，此即「**王林之力**」的初端。
- 现阶段两股力量只是初步融合、尚未显露狰狞，但已非寻常修士可挡：数名联盟修士肉身颤抖、元神震撼，急速倒退，仿佛不退便会在这奇异之力下崩溃身亡——他们修道至今从未遇过如此神通之术。

### 古神大鼎换位 · 对上辰龙
- 王林体外**古神大鼎**幻化，瞬间与其中一人**位置逆转**；四周修士只觉眼前一花，他已冲至木雕旁。
- 临近刹那，一道**剑气**凭空而来，内蕴极端霸道意境（天地万物皆需避让，否则毁灭）。王林认得——正是**当年凌天候之物**。
- 随剑气而至者冷声宣称：「此宝，是我大罗剑宗**辰龙**之物」。
- 王林神色如常，一把抓住半截木雕，转身喷出**十八层地狱封仙印**挡在身前：剑气轰然撞击后崩溃，封仙印纹丝未动，被王林牵引后退。
- 王林留话：「**当年故人，手下逃出的未亡之魂，今日也敢在我面前抢宝**」，冷冷看了辰龙一眼，心知眼下不是杀人之时，远远离去。
- **辰龙反应**：战场修士太多、王林从不久留且闪烁游走，辰龙先前只觉此人眼熟，无论如何未把他与当年的王林重叠；听闻此话后如遭雷霆，身子一震、失声道「你」。

### 后续动向与伏笔
- 王林游走战场，不断捞取死去修士的法宝。
- **神识锁定望月**，一直在等一个机会：联盟星域修士大战望月，使他可以**进入望月体内获得传承**。
- 目光时而看向远处的**水罗蓝裙女子**——此女之前看他的神态很是古怪，王林谨慎游走中一直在思索：此女到底是谁。（悬念未解）

## 三、望月一方
- 望月咆哮中体外触须横扫，体外的血神子等人飞出迎击四仙卫。
- 两度被包围令望月怒火更浓、几近发狂，张口咆哮中传出**一道道古神之语**，展开了**古神神通**。
- 血神子等人在旋风中面色阴沉，各自施展神通法宝抵抗，轰鸣不断。
