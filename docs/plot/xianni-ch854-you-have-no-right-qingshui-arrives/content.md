# 第七卷 名震罗天 第854章 你，没有资格

## 一、王林力抗天劫与血神子（前半）

- **借鼎避雷**：血神子眉心妖物出现的刹那身体停顿，王林趁机后退；古神大鼎一震，带他横避百丈。红色天雷具灵性，转向再追。
- **呼风（第一次）**：右手黑风凭空而生，化作一头黑龙吐出阴风，「可吹熄一切生命之火」，崩溃数道天雷，但仍有天雷穿透。
- **元神吞雷**：王林元神冲出疯狂吞噬，连吞三道天雷后不得不回体。
- **蝴蝶与血燕**：始终环绕王林身外的蝴蝶与血燕挡在身前与天雷抵消，仍有三道天雷临身。
- **封仙印避雷**：王林融入封仙印内，三雷齐轰；印内一声「封雷」，此印剧震、雷光游走如雷海，王林被逼出、喷血，抓印后退，并向劫云而去——意图**借天劫之力脱身**（自知正面无法逃走，即便血神子已被古神碎星一击所伤）。

## 二、正面交锋：血神子随手破尽

- **呼风（第二次）**：黑风更浓，化出**两头黑龙**（窥涅之前王林最多化出一头，修为提升所致），双龙缠身吐阴风，星空震动。
- **封仙印放雷**：王林一指封仙印，凝聚出一道天雷轰向血神子。
- **斩罗诀连发**：一拍储物袋取出仙剑，不惜元力挥出上百道斩罗诀。
- **血神子回应**：神色平静，指天崩天雷、指下卷灭上百道斩罗诀、一指碎阴风并将两头黑龙拦腰斩断，冷言：「**仙帝白凡的呼风，不过如此**」，随即虚空一抓欲抽魂搜神。

## 三、清水仙君降临

> 「我清水师尊之名，你可敢再说一遍」

- **威压**：话音落，星空大片崩溃、劫云急速退缩；血神子融入规则的「言出法随」所成万丈规则之地刹那全灭。远处**姚云**喷血萎靡后退；**罗天南域**所有修士感受到天地之力中的杀机，许多人当场吐血受伤（未死）。
- **形貌**：一袭白衣青年，飘逸黑发，**右目殷红**，红芒透目而出，蕴毁天灭地之意，一步步走来。王林被斩断的黑龙随声恢复。
- **血神子面色第一次大变**，收手退后，称其「清水仙君」。

## 四、对峙与「师弟」之认

- **血神子求全**：称与清水并无仇隙，愿收回前言，他日同去**联盟星域**时再作弥补；但要求清水勿插手——「此子与我姚家有怨」。
- **清水定性**：「我这师弟学艺不精，招惹了你姚家之人，但，那又如何」——血神子一怔再变色。
- **六龙唤风**：清水一指天空，黑风浓郁远胜王林数倍，化出**六头万丈黑龙**齐吐阴风；劫云被逼退又更多凝聚，似在酝酿最强一击。
- **身份论断**：「他既学会了呼风，便是我师尊隔代传人，以他的身份，曼说你姚家，即便是当年你姚家的先祖，也不敢伤他半根毛发」。
- **血神子反驳**：直呼王林为「**许木**」，称「他杀我姚家众多三代族人，我来杀他天经地义」，并讥清水「沉睡时间太久，莫非糊涂了不成」，声称不怕清水。
- **九十九血燕**：血神子伸手化出九十九只血燕结成血色风暴迎击阴风，一声巨响后两人之间星空崩裂，裂缝延伸如巨大沟壑。

## 五、清水的心结（背景交代）

- 清水对其师尊**一直心怀愧疚**，且此愧疚再无机会报答。
- 苏醒之后见王林施展呼风、又在与**炎雷子**一战中被点醒记忆，对王林生出复杂情绪。

## 六、收束：唤雨

- 清水冷道：「即便他真的做错，也自由我来替师尊教训，**你，没有那个资格**」。
- 六条黑龙彼此纠缠合为一条巨龙，不再吹阴风，而是洒出大片雨水，方圆千里尽笼雨幕——「**唤雨**」。

## 七、要点与伏笔

1. 呼风/唤雨同源一脉，清水与王林同出「师尊」一门（王林为隔代传人）；血神子将呼风归于「仙帝白凡」。
2. 清水以「师弟」名分强行介入姚家与王林的因果，等于把王林纳入其师门庇护。
3. 血神子与清水日后将同赴**联盟星域**，此约成为潜在伏笔。
4. 王林此战的求生思路是「借天劫」而非硬拼，天劫尚未落尽（劫云仍在酝酿最强一击）。
