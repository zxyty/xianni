# 仙逆 第八卷 联盟隐秘 · 第1104章 天劫（第二更）

## 一、山崩之威与星空疾驰

- 王林一路走去，体外幻化连片**火山虚影**，身后如有火山群跟随；虚影引动星空天地元力疯狂凝聚。
- 此神通为**仙帝白凡后三式神通中的第一式——「山崩」**。其妙在真假之间：一眼明知是假，再看便如身临火山，足以牵动心神，撼动一切碎涅以下修士，碎涅修士亦受影响。
- 山崩所化，实为王林心中的**愤怒之意**。
- 王林随蚊兽而行。蚊兽间有同族独有气息，蚊兽王一脸狰狞，清晰察觉此地同族气息极为浓郁。

### 提速手段
- 半柱香后，因蚊兽带伤速度偏慢，王林出手：右手虚空一挥开出**半丈裂缝**，该裂缝随他急速前行同步游走星空（如海面小船滑行），从中取出一张**黄色纸符**。
- 纸符贴上蚊兽 → 土黄色旋风冲天、上方幻化庞大飞禽 → 蚊兽速度暴涨至**「碎涅修士之速」**，星光连成长线流淌。蚊兽从未有此速度，却无任何不适。
- 副作用（旁证）：一群自战场撤回的联盟修士被这股狂风当场冲散，惊骇远遁；蚊兽的嘶鸣传递速度**远远落后于**其飞行速度。

## 二、天劫将近与净涅体质

- 王林渐感**天劫降临越来越近**，体内以**九玄变**封印的修为已有松动。
- 环境对比：朱雀圣宗所在星域常年燃烧、**只有火元力**；此处为外界星空，**天地元力极为驳杂**。
- 因而尽管修为被封印，仍有众多天地元力顺其身体钻入、体内流转、改造经脉。
- 设定要点：**净涅修士体内会被天地元力改造，以便更适合明悟规则的变化。**

## 三、碎石星域：天门宗的偷运据点

- 位置：**联盟中部**极为偏僻之地，四周罕有星球，即便有也是无人的蛮荒星，几乎无修士前来。
- 布局：碎石深处有**青光大阵**，近百修士以碎石组建阵法，已近尾声。
- 图谋：两名**紫衣老者**眼露兴奋——阵成即可安心带**十多只巨蚊兽**回**云海星域**，其**天门宗**必因此换取极大好处。
- 身份与修为：二老修为仅**净涅后期**，连净涅大圆满都未到，更非碎涅；且**并非云海星域真正派来的使者**，而是以特殊方式偷偷到来。
- 异变：被封在不远处、原本在几只燃香下极安静的十多只蚊兽，突然齐齐红眼嘶吼挣扎，试图冲出燃香包围圈。
- 那三名带蚊兽回来的青年一听嘶鸣便认出是逃走的**蚊兽王**，以为有长老在此可趁机抓捕，主动飞出。

## 四、青光罩前的对峙

1. 蚊兽满腔怒火全速撞击青光罩 → 轰隆巨响，青光闪烁**纹丝未动**；蚊兽反震弹退数百丈，赖王林缓冲反震之力方免再度重伤。
2. 王林抬手虚空一拍，体内**火元力**宣泄化作火海包裹青光罩 → 阵阵燃烧声中，青光**无半点消散**。
3. 二老隔罩冷笑「不自量力」，见王林修为后心神放松。
4. 王林开条件：**「交出余下蚊兽与那三个胆大妄为的小辈，我可饶你们不死。」**
5. 二老讥讽其在联盟星域内狂妄至极；但极为谨慎，**不踏出青光罩半步**——他们判断王林可能只是巨蚊兽之主的弟子，是诱饵，罩外必藏真正的大神通修士；神识查探无果反而加深怀疑。

## 五、结尾：天劫落下

- 王林不再废话，抬手一指星空，深吸口气，**解开九玄变封印**——净涅气息疯狂扩散，大范围引动星空天地元力云涌而来，体内砰砰作响。
- 碎石星域上方**劫云**无声幻化、刹那连成一片，几乎弥漫整个碎石星域；一股**天地之威**降临，将这片碎石星域**生生分割出来**。
- 二老骇然认出「天劫」——以其净涅修为本对天劫见识不多，之所以能一眼认出，是因**来联盟星域前刚刚亲眼目睹过云海星域内的一次天劫**。

## 六、悬念

- 天劫已至，王林将在敌阵之前渡劫；青光大阵与天门宗一行是否会被天劫波及，尚未揭晓。
