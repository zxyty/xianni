# 第2032章 冲冠一怒！（结）

## 一、血路尽头：踏入大殿

- 通往大殿的血路上残尸处处，**近千人死亡**，四周之人望向殿内目光尽是恐惧。
- 王林踏入的一刹那，**道古皇尊**面色苍白、下意识后退，死死盯住王林。
- 皇尊出言威胁：「朕若死，则此女必死」「朕有古道大天尊守护，天下间谁也杀不了我古族皇尊」。
- 王林无视皇尊与其身侧阴沉的皇袍老者（古道大天尊），径直走向**宋致**——那个让他感到熟悉、追寻了数千年的气息。

## 二、阻拦者尽灭

- 王林前方出现一道道如烟丝般的虚幻之影，盲奔而来。
- 王林视若无睹，身前砰砰巨响，凭空逼出的身影**刚现即喷血、全身裂缝、瓦解**；转眼数十个，无一存活。
- 途中一道虚影趁机自身后袭来，王林右手向后一指，穿透头骨，倒卷立毙。

## 三、身份的挣扎：宋致 / 李慕婉 / 娠儿

- 宋致体内融有**娠儿残魂**；她抬头望着王林，张口却忘记了话语，目露记忆苏醒的挣扎。
- 她抱头痛苦自问：「他是谁？她是谁？我是谁？如果我是她，那么**常姨、东梅**又是谁？」
- 王林轻声道破：「我不知道常姨、东梅是谁，但我知道，**你是李慕婉，你是我王林这一生，寻找了数千年的妻子**。」
- 「李慕婉」三字入耳，她脑海中响起镜子破碎之声，隐觉此名才是自己真正的名字，剧痛落泪。

## 四、斩紫印锁

1. 道古皇尊眼露狠毒欲有所动，王林一声冷哼如雷鸣，令其七窍流血、抱头后退数步。
2. 王林右手点在女子眉心，体内融合的**古祖魂血**散出一丝，顺指入其体内。
3. 一缕若隐若现、似不存于此界的**细丝**自女子天灵散出，连向道古皇尊。
4. 王林左手一斩，细丝两断。皇尊喷血，骇然嘶吼：「这**紫印锁**……是我皇族的秘术，唯有**古道大天尊**才可以解除！」

## 五、旧语唤魂：「不要怕，我带你，去杀人」

- 王林抚其秀发，说出数千年前的那句话：**「不要怕，我带你，去杀人。」**
- 此语的冲击**远超「李慕婉」之名**——她梦中始终存在的那个声音，与这句话轰然重叠。
- 她想起：修魔洞府洞口，她苍白着脸坚定守护；身后有人盘膝而坐、炼化丹药之力正在**结丹**；她力竭倒下时被一个温暖胸怀接住，耳边是那句冷漠却温暖的话。
- 她沙哑唤出「**王林**」，迷茫消散大半。王林仰天长笑，一把搂住她。

> 时间线锚点：此段回忆为数千年前王林结丹期、与李慕婉在修魔之地洞府共患难的旧事（闪回）。

## 六、杀不得的皇尊：紫光护体与十万围杀

- 王林一掌按向道古皇尊，皇尊尖叫「古道大天尊救我」，体外**紫光一闪**，生生震开此掌。
- 王林再度一指，紫光二度闪烁，又一次抵住其神通。皇尊由惊慌转为镇定、狂笑：
  - 「朕是道古皇尊，朕是**古祖嫡系后人**，朕有古道大天尊守护，天下无人能杀朕！」
  - 下令：「**所有道古族人，轰杀此人，如有违抗，当叛族论！**」
  - 辱骂王林为「来自**洞府界**的蝼蚁」，扬言杀他后要宠幸此女，令其为王林殉葬。
- 广场上数万乃至陆续来临的**十多万族人**如黑云般轰然压来。

## 七、古祖九曲·血脉终曲与古祖虚影

- 王林发丝无风自动，身后幻化**大天尊之阳**，散发万丈黑白光芒；魂血急速运转涌遍全身。
- **古祖九曲**依次奏响：
  - 苍穹风曲（风的呜咽）
  - 天道雷音（雷霆轰轰）
  - 凡尘云笛（云随风动、随雷而卷）
  - 万物润雨（雨水纷淼）
  - 九曲第七音（余音缭绕）
  - 九曲第八音（五脏震鸣）
- 王林道出关键：「这穹宇内，除了古道大天尊外，**还有一人可以杀你——她就是古祖**。」
- 体内魂血爆发出**最后一曲：血脉之曲**。王林双目彻底化为**银色**，透出至高无上之意。
- 皇宫大殿之上，天地显化一尊**巨大虚影**：双手背负、长发飘摇、抬头望天、神色轻蔑——**与天空城中心的古祖雕像一模一样**。
- 道古皇城内所有**古之三脉**族人身子巨震，不知谁先跪下，转瞬**十多万族人尽数跪伏**：「吾等后辈子孙，拜见古祖！」
