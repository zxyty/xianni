# 仙逆 第1402章 朱雀老祖（第九卷 云海之巅）

## 一、五道本源现世

二代朱雀老者本已惋惜王林「元神之阳被破」——既修炼不了他的神通，日后修虚火之境也比元阳完整者难上许多。但察觉王林体内异样后，他抬右手按上王林天灵，一股奇异之力灌入体内爆发，并未伤王林分毫，却逐一逼出其体内本源：

1. **火之本源**：无形之火自天灵轰出，弥漫天地、高温莫名，随即收缩为一枚微弱却令人窒息的火苗。老者神色不变，显是早已知晓——「毕竟朱雀觉醒了几次」。
2. **雷之本源**：天灵内雷鸣轰起，冲出一道雷霆，化作雷霆印记，四周九道细雷环绕，天地色变、风云倒卷。老者倒吸凉气：此雷之本源**已然大成，到了可搏空门的程度**，疑心王林「莫非真吞了太古雷龙」。
3. **生死轮回本源（黄泉）**：黑白二色之光冲出，天空浮现一条首尾相连、内里浑浊的虚幻长河，即王林生死意境所化黄泉，生与死的气息骤然爆发。老者狂喜长笑，称这种喜悦已数万年未有。
4. **因果太极图**：一副虚幻太极图飞出，蕴含因果，仿若撕开天地、令天地混乱。所幸四周无旁的修士，否则会被因果之力缠住、遁入心魔难以自拔——此生所种一切因皆化为毁灭自身之果，瞬间形神俱灭。
5. **真假虚幻本源**：光芒极为诡异，看似存在又似不存在，处于真与假之间急速交替，浮现片片虚幻与真实的模糊画面，一眼难辨。

五道本源片刻后尽数回体。老者吞了口吐沫，半晌无言，看王林「如看妖物一般」：「五道本源……这小家伙比那四代朱雀还变态，这天地间怎么会出现这样的妖物」——口中如此说，眼中激动却无法形容。

## 二、一夜之后

- 月色渐浓、初阳升起，王林打坐一夜，体内火焰之力浑厚不少，但**距朱雀第四次觉醒仍差一道隔膜**，始终无法突破。
- 落生会**长老之选**于清晨开始进行。
- 近晌午时，王林吞下的几口龙血之力才慢慢消散，面色恢复正常、睁眼。呼出一股漆黑浊气，落地后地面咔咔作响、如遭烘烤、龟裂散开。

## 三、身份揭晓：二代朱雀与少帝之说

王林起身弯腰恭敬见礼：「晚辈王林，参见四代老祖」。老者干咳一声笑道：**「老夫可不是四代朱雀。」**

- 王林猜「一代朱雀」，亦被否认——**老者是二代朱雀**。
- 「这里面的岁月悠久，很多事情复杂，**四代朱雀也在这里**，你是他之后，我看到的第二个族人。」
- 王林问是否为「大帝」，老者答：**「和你一样，都是少帝」**——他与四代小家伙都是少帝。
- **关键设定**：「颠落大帝」是外人的称呼；在朱雀圣族内其只有一个称呼——**一代朱雀老祖**，也就是**远古仙尊麾下四大最强战将之一**。
- 有关朱雀圣族的具体之事，需王林**进行试炼之后**方可知晓。

## 四、试炼与立威之命

- 试炼**必须进行**，对王林而言「或许会是一场突破实虚火之转化的大造化」，但此事很难，不必有太多压力。
- 老者目光看向**西北方向**，不满王林未应**司墨子**的挑战：「我朱雀一族，莫非还怕了他不成」。
- 命王林试炼之后**放开手脚去战**，一切有他在，此地所有受邀之人「翻不出什么风浪」。
- **落生会长老之选只不过是儿戏**；此番邀请不少**第三步大能**来临，就是要让他们知晓——**颠落之地内又出现了新的少帝**。
- 族属宣言：「你是我朱雀族人，不管你来自界内还是哪里，这点不可改变。」离开此地他无法保护，但「在咱们家里，我看谁敢伤你」。
- 行事准则：**「我朱雀一族行事，就是要霸道，就是要护短」**，霸道到让所有人无法反抗，才能在混乱中立足，出去后动手者也会极为忌惮。与其藏头露尾，不如立威——**就拿第三步大能司墨子立威**。
- 王林沉默点头，眼中寒光一闪。

## 五、赐予：龙神血酒与「秘术」

- **龙神血酒**：那瓶酒，试炼时**酌情喝下**。
- **秘术真相**（老者说到「秘术」二字时表情古怪）：
  - 朱雀一族**从来就没什么秘术**；所谓秘术，实为一代朱雀老祖当年**还能动弹时**，从**青龙、玄武、白虎**三族**抢来**的三族大神通之术，拿回来后自称秘术。
  - **三族中玄武一族力气最大**。
  - 老者查看王林身体时发觉他**不知怎么成了古神**；**古神之力**以此术施展，威力自然更强。
  - 此术**不是神通，而是一种力的运用**。
- **演示**：老者行至湖边，右手抬起向湖面一挥，湖水颤抖凹陷；凹陷刚成，其右手已隔空拍在水面之上。（本章至此中断）

## 六、要点与伏笔

- 王林本源数量（5）已超四代朱雀，成为其在朱雀圣族地位与后续试炼的根基。
- 「元神之阳被破」是王林修虚火之境的先天障碍，而试炼被指为**突破实虚火转化**的机会。
- 「古神之力」（涂司一线的古神身份）与玄武系力术结合，构成王林新的战力方向。
- 与司墨子之战被预定为立威之战——注意：司墨子分身已于第1292章被灭，此处为其本尊/正主的挑战。
