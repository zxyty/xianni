# 仙逆 第303-304章：仙兽府黑色仙粮之战与孙雷的背叛

## 一、场景与前情
- 王林与孙雷（暂时同盟）达成共识后，一路直奔仙兽府深处的黑色洞穴，停在洞口**三十丈**外。
- 洞外躺着一具骸骨——正是此前被孙雷害死的**三师兄**（大罗剑宗三师兄，已于第281章死亡，此处为其尸骸）。

## 二、黑色仙粮的来历（孙雷之说 + 王林印证）
- **仙界之粮**：本是仙兽的食物，仙兽吞之可强壮身体，对修士**无用**。
- 此地仙粮数量惊人，孙雷判断皆为**黑色仙粮**繁殖出的后代。
- 王林指出黑色仙粮当与那具黑色骸骨有关：他第一次神识扫动时，即见黑色细丝在骸骨之中穿梭游走，每次游走骸骨都会颤动，诡异如随时可复活。
- 孙雷推论：无数年前**仙界劫难**之际，此物以各种方式吞噬了尸骸的肉身，连仙识元神也一并吞下，随后隐匿尸骸之中，日久天长而拥有道行。

## 三、第一次交手（第303章）
**约定**：孙雷以法术引出仙界之粮，二人尽量消灭；一旦黑色细丝现身立刻逃走，回先前洞穴会合。

**手段与过程**
1. 王林一甩**驱兽圈**，化作**雷蛙**落地。孙雷瞳孔一缩——雷蛙是极为稀少的**上品灵兽**，由此更确信王林**隐匿了修为**。
2. 孙雷背后宝剑化剑光刺入洞穴，引出一个巨大线团，其上飞出无数蠕动细线，密密麻麻扑来。
3. 孙雷预置地面的数枚**玉简**接连碎开，放出**七彩之烟**，钻入细丝令其扭曲坠地抽动；但细丝太多，几息后烟气散尽。
4. 孙雷退后放出粗大剑气，每道剺灭大片细线，仍不敌无穷无尽。
5. **雷蛙**腹部鼓起，吐出**雷球**（带天地之威），细线如被镰刀收割般成片消散，雷球推进十余丈方散。孙雷一怔，忌惮更深。
6. 雷蛙再吐第二枚雷球，细丝首次显出惧意欲退。

**转折**：一声尖锐咆哮，粗大的**黑色细丝**游出，悍然撞入雷球，雷球缩小并噼啪消失；黑色细丝随即**由纯黑转为略带紫色、隐有电光流动**（吸收了雷力），身缩前弹、速度极快，连神识都难锁定。

**撤退**
- 雷蛙连吐两球后现疲惫萎靡，王林当即收回驱兽圈，转身就逃，并**点眉心唤出许多游魂**四散而走（掩护/分散追击）。
- 孙雷本想留下、等细丝追击王林后自己入洞，权衡太险后放弃，朝另一方向逃走。
- **黑色细丝选择追击的是孙雷，而非王林。**

## 四、间歇：代价与试探
- **驱兽圈的弊端**：因雷蛙消耗过大，驱兽圈**提前半天**吸收灵力，王林被迫抖禁幡、盘膝吞丹供其吸取，面色难看，判定“此圈虽好用，弊端却也太大”。
- 游魂尽数归体、数量未少，王林由此确认黑线选了孙雷。
- 王林至约定洞穴放开神识，在**千丈**外发现孙雷：全身多处破损、内穿**银甲**（两次逃过追杀之凭），**右手少了一根手指**，脸色阴沉盘坐疗伤。
- 王林以**土遁术**穿洞壁前往；因洞府有奇异之力阻碍，千丈之距走了**半柱香**。
- 孙雷肉痛吞下数粒丹药，修为由虚弱不堪迅速恢复到**八成**。王林见状，**果断放弃了先前（趁虚下手）的念头**，改口“孙兄尽管吐纳，在下为你护法”。孙雷不信其言，口头道谢。
- **三炷香**后孙雷修为彻底恢复，目光转缓，提议再探。

## 五、第二次交手与孙雷的背叛（第303章末—第304章）
- 二人再至洞穴，细丝大量涌出，数量似毫无减少，且**黑色细丝飞在最前**，抱着灭杀之念。
- 孙雷声称“必报断指之仇”，一拍储物袋取出**黑色扇子**：扇现即弥漫阴寒之气，墙壁瞬间结出黑冰并不断扩散。
- 王林抖**禁幡**，身体弥漫黑雾，寒气绕行而过，只在他与孙雷之间形成一道防护。王林同时**悄然取出岁月木雕**（青衫老者所留）。
- 孙雷双手结诀按于眉心，**元神出体**一把捏住黑扇（元神露出痛苦之色，如握烙铁），向前狠扇，黑风吹出，细线尽数定住，黑冰弥漫，**连王林所在之地也被封入黑冰世界**。
- 孙雷元神回体，冲向洞口，笑称“法力有限只能封住十息，先行一步，再来救你”。王林嘴角浮起若有若无的**嘲讽**。

### 孙雷的真实盘算（第304章开篇揭示）
1. 忍到此刻才动用黑扇，正是要以**王林为诱饵**：细线恢复后追杀王林，自己借机脱身。
2. 取宝后细丝的疯狂追杀远非前两次可比，若无诱饵他也难逃。
3. 计划取宝后**把那具骸骨扔到王林身上**，使细丝舍远求近。

### 王林的反制
- 王林一直防备孙雷，岂能让其如愿——**黑冰临体封印四周的瞬间，木雕之上的岁月意境顿时散发出来**。
- **岁月意境**：流逝既为岁月，逆流也为岁月；在岁月意境中，**时间的改变、变换由心**——这正是其强大之处。

## 六、要点提炼
- 二人自始至终**各怀心思**：孙雷以合作换诱饵，王林以护法换观察，双方均未真心。
- 王林两大底牌在此显形：**驱兽圈+雷蛙**（威力大、代价高）与**岁月木雕的岁月意境**（应对时间/封印类禁锢的关键）。
- 黑色细丝具**吞噬并吸收所吞之物力量**的特性（吞雷球后转紫带电），且智能地择弱/择近而追。

# 第285章 剧情梳理：破封夺宝与仙界碎片崩溃

## 一、脱困：以岁月意境破黑冰
- 王林在**天逆空间**（石珠梦境空间）修炼多年，对**时间的逆变**了解极深，这是他能够模仿出**岁月意境**的重要原因之一。
- 面对孙雷以师门重宝放出的**黑冰封印**，王林不硬抗：先由**木雕**扩散出一丝奇异之光融入黑冰，再以岁月意境令其冰封略有松动。
- 结果：孙雷以为王林已被彻底禁锢并哈哈大笑口出狂言之际，王林一晃从中走出，且以快过孙雷一分的速度自被冰封的一根根细线旁穿梭而出，抢先出现在洞穴之外。

## 二、交易兑现与洞内夺宝
- 王林出洞后开口索要**洗灵之木**：「孙道友，那洗灵之木还没给在下，怎么就着急进入呢。」
- 孙雷面色难看但果断，一拍储物袋扔出洗灵之木；王林接过后转身进入洞穴。
- 洞内：
  - 王林取走**尸骸胸口处的金色铁片**。
  - 孙雷抓向**尸骸手中的仙剑**：初触即右手爆出无数血点；忍痛再抓虽握住，却被金光在右手刺出血粼粼的伤口，胸前亦被金光刺中，**贴身银甲当场融化**，只得放弃仙剑。
- 王林看也不看，转身冲出洞穴，手中**禁幡**化作黑雾，其内冲出条条**禁气之龙**包裹其身，轰隆向上冲破而去。

## 三、封印提前失效的两重原因
孙雷计算时间只过八息，本以为师门重宝「说是十息就绝对是十息」，却遭黑色细丝提前挣脱，原因有二：
1. **黑色细丝因吸收了雪球，已具备一些天地威能** —— 十息减少一息。
2. **王林的岁月意境使黑冰的冰封出现一丝缓慢** —— 再减一息。

## 四、孙雷自爆黑珠
- 黑色细丝自黑冰中冲出、尖啸扑向孙雷，孙雷闪躲不及，死亡阴影笼罩；抬头看到正在快速离开的王林，强烈不甘涌上心间。
- 孙雷双目疯狂，一拍额头放出一枚**黑色珠子**：
  - 该珠为其**修炼功法数百年所化**，**成功化神后凝结而出**；
  - 按其门派功法，此珠是**日后成就第二元神的重要之物**；
  - 失去此珠，修为立刻大跌 —— **由化神中期直降元婴期**。
- 一声「爆」，黑珠自爆，黑色环形波纹扩散：黑色细丝缩成一球堪堪抵挡；其身后刚从黑冰中恢复行动的细丝无任何挣扎地一一消散；四周洞壁亦如崩溃般消散一空。
- **孙雷在自爆瞬间整个人消失在原地，不知去向**（未明言生死）。

## 五、仙界碎片崩溃
自爆威能达到这处**仙界碎片的临界点**，碎片中的天与地轰然崩溃：
- 天空中数之不尽的**空间裂缝**出现，越来越多、越来越大；
- 地面岩浆爆发般冲天而起，整个天地剧烈晃动；
- 一道道**死亡之光**自天地间扩散；
- 大片天空与地面如被生吞活噬般开始消散。

## 六、王林的逃亡判断
- 逃遁中的王林察觉下方传来毁灭性力量，同时**四周束缚瞬移的奇异之力顿时崩溃**。
- 他本要瞬移，却强行止住 —— 感到四周大地震动轰鸣，立刻猜到「**仙界碎片崩溃**」，庆幸自己没用瞬移，否则**极有可能瞬移至可怕的仙界裂缝之内**。
- 王林全力运转禁幡，如闪电般疾驰而上，失去奇异之力限制后速度恢复正常；但地面崩溃更快，其神识察觉**四周百丈之外已是一片黑色虚无**。

## 关键转折点
1. 岁月意境成为破局关键（源自天逆空间的时间感悟）。
2. 金色铁片落入王林之手，仙剑无人能取。
3. 孙雷以「第二元神之基」换命，修为从化神中期跌至元婴期。
4. 仙界碎片整体崩溃，成为本段最大危机背景。

# 第304-305章 仙界碎片崩溃逃生 · 游魂荡威

## 一、虚无吞噬与绝境
- 仙界碎片开始整体崩溃，一片“虚无”如大口般不断吞噬大地。
- 崩溃自百丈外持续推进：百丈 → 五十丈 → 三十丈 → 二十丈 → 十丈 → 五丈 → 三丈。
- 王林面色苍白，距地面尚有距离，判断无法在吞噬临身前冲出。

## 二、吞服仙气结晶（关键转折）
- 王林一拍**储物袋**，取出一枚**米粒大小的结晶**——由**仙界之气**凝练而成。
- 三丈外虚无大口已张开时，他一口吞下结晶。
- 效果与代价：
  - **元神第一次感到疼痛**：仙气澎湃鼓胀带来的**元神燃烧巨痛**；
  - 身体剧痛的同时，滋生出**似可支撑天地的强大力量**；
  - 速度**比以往快上无数**，如流星自地底游走般冲出地面。
- 意识陷入一股“疯狂”之中——非清醒状态下的本能狂飙。

## 三、天空裂缝中的挣扎
- 冲出地面瞬间，此处仙界碎片大地几乎尽数沦为黑色虚无；地面仅余数处**似支撑天地之柱的石锥**，其中一些仍在缩小直至消失。
- 天空处处裂缝，且裂缝相互连接形成与大地一样的黑色虚无。
- 王林如“火焰中挣扎的凤凰”不断升空，一头冲进由裂缝连成的虚无：**四周暗黑、寒气汹涌**。
- 寒气刺激反而让他**脑中一清**，遂控制身体后退，从一道尚未合上的裂缝再次冲出。
- 借这一丝清醒迅速闪躲裂缝，在此处仙界碎片**完全崩溃的一刻**冲出，消失在高空。

## 四、返回漩涡平台
- 越飞越高，望见远处**巨大漩涡**——正是当初进入仙界碎片之地。
- 漩涡之下有一处**平台**，平台上数人正目瞪口呆望来。
- 王林闪身现于平台，**喷出一大口鲜血倒下**；落地瞬间以仅存力量**点在眉心**，放出游魂。

## 五、万魂荡威（第305章）
- **数量**：域外战场之行共收获**超过十万**游魂，受**寂灭法则**干扰，最终仅带出**一万**。此刻全部放出。
- **威势**：上万游魂呜咽呼啸、旋转徘徊，环绕王林形成**黑色飓风**，平台数人面色大变纷纷后退。
- **游魂特性（与魔头的区别）**：不论对方修为高低，**一律悍不畏死扑上**，哪怕自身被炼化亦然。
- **战力未知**：上万游魂能否杀死一名**化神期**修士，王林未曾试验。他不到万不得已不愿耗尽辛苦带出的游魂。
- **前例（闪回/传闻）**：当年**古帝**便是在无数游魂无始无终的围攻下**肉身被噬**。
- **许立国**：混在游魂之中，外表与游魂相同但**双眼有一丝灵动**。他心中得意，认为“主人还在意自己”——老三、老四、老五都已死，唯他安然无事，且身边多了众多“游魂前辈”，自觉日后安全。

## 六、疗伤与新变数
- 王林挣扎盘膝坐下，自储物袋取出**七八瓶丹药**一口气全部倒入口中，打坐吐纳。
- 平台上一人目光炯炯，**额头有一把斧子的印痕时而闪烁**——是与王林同来自**朱雀星**的**巨魔族**族人。
- 该巨魔族人**一眼认出王林**，双目一闪，**沉默不语**（伏笔：身份可能被揭破）。

## 七、伏笔与看点
1. 仙气结晶可短时爆发元神之力，代价是元神燃烧——一次性保命底牌。
2. 一万游魂成为王林的战略级威慑，但对化神期的实际杀伤仍是未知数。
3. 巨魔族族人的沉默，是本段最直接的悬念。

# 第305–306章 灰衣男子丧命游魂 · 叱虎邀约仙府洞天

## 一、灰衣男子偷袭殒命（承接仙界碎片崩溃后）

- 王林自仙界碎片崩溃中逃出，重伤停于漩涡外平台，身周有数千游魂盘旋护持。
- **灰衣中年男子**：双目阴森、鼻尖略弯，修为元婴后期大圆满。旁观的巨魔族男子眼露嘲讽——以元婴之身欲杀化神修士，无异以卵击石。
- 灰衣男子念咒凝出**黑色火焰**（热浪掀起）抛向王林。游魂骤然散开：约三分之一扑击火球，其余数千扑向灰衣男子。
- 游魂**非魔头，对法术神通有一定抵抗力**：飞剑横扫仅稍缓前排，后方大量游魂突入，七八只钻入其体内。
- 灰衣男子咬破舌尖喷血化火裹身，盘膝打坐逼魂；火焰渐弱。火球亦在游魂悍不畏死的扑击下于王林身前三丈外熄灭（游魂有死伤）。
- 灰衣男子自悔冒然出手：深知能入仙界者皆为各修真星翘楚，未料重伤之敌仍难对付；欲取**小鼎**（返回所属修真星的法器）遁走。
- 王林骤然睁眼，**隔空一抓夺走小鼎**，再一捏碎灭其护体火焰。灰衣男子瞬移至漩涡外欲逃入仙界碎片求活，被无穷游魂钻入体内，惨叫坠落平台，气绝身亡，血肉尽失只剩骷髅。
- 王林心念微动，游魂尽数飞回，钻入其额头消失。

## 二、结识巨魔族叱虎 · 化名「曾牛」

- **叱虎**：巨魔族，化神修为，全程旁观后上前寒暄，感叹「连元婴期修士都敢对你起了贪心」。
- 王林仅答四字：「仙界碎片崩溃」。叱虎大为震动——能自碎片崩溃中逃出者绝非等闲。
- 王林自称**「曾牛」**（化名）。叱虎推测其为朱雀星南部**五级修真国天魂国曾氏家族**之人；王林摇头不认。
- 叱虎判断：整个朱雀星姓曾的高阶修士只此一家，对方纵不承认也必是某五级修真国培养的核心弟子；巨魔族仅为**四级修真国**，故对同级以上天才尤为留意——态度随之转好（碍于修为不外露）。
- 王林暗自防备；叱虎挥手布下光幕隔绝，开门见山求助：「你我同属朱雀星，还请助我一臂之力。」

## 三、玉简所载：仙玉棺材之地（第306章「洞府所在」）

玉简为神念记录的画面：

- 鸟语花香、碧水青山之地，中有**水潭**；

- 棺上插着**三把仙剑**，形制与王林先前所见骸骨手中之剑极为相似；
- 潭上另漂浮**数株非凡植物**。

来历与条件：

- 此地为巨魔族一代天骄多年前进入仙界时无意闯入；有**仙兽守护**与**无数禁制**，其一人之力不敢妄动，仅悄悄记录后返回。
- 王林质疑「时隔多年怕已被人发现」；叱虎断言绝无可能，但称**内中原因暂不便说出**。

## 四、约定（行动项）

- 王林答复：以二人之力恐难进入；叱虎称**另约了一人，三人同去把握大增**。
- 王林未即答应，请求「容我考虑几日」。
- **叱虎之约：一个月后，持玉简至地图所标碎片集合；逾期不等。**
- 叱虎另赠**传送玉简**一枚：与大罗剑宗传送之物同类，是开启传送阵的关键；其上众多碎片中仅一处明亮，持之入漩涡即可直达指定之地。
- 叱虎抱拳而去，头也不回踏入漩涡消失。

## 五、仙气结晶与仙玉（设定要点）

- 王林以**禁幡**一抖覆盖四周，藏身黑雾，元神遁出、双手掐诀，痛苦地从元神眉心**生生逼出一粒米粒大小的仙气结晶**；元神随即萎靡如风吹可散，沉回肉身。收结晶入储物袋。
  - 若非当初不顾一切吞下仙气结晶，王林已葬身虚无。
- **仙气规则**：以王林修为根本无法融合仙气；仙气是**化神后期冲击婴变时**才可尝试吸收的重宝；**未到化神后期便融合仙界之气，非宝而是毒药**。
- **稀缺链条**：仙界之气稀少 → 朱雀星**婴变期修士不多** → **问鼎期修士罕见**。万年大派或有仙气结晶存货，但只有门派天资之辈或长老之流可定量使用。
- 王林元神受损严重，靠**吞噬部分游魂**略有恢复。
- **仙玉**：白色玉石，散发阵阵仙界之气；神识一扫可知其与修士灵石相仿——灵石散灵气，仙玉散仙气。

## 六、境界坐标（本片段所见）

元婴后期大圆满 < 化神 < 化神后期 → 婴变期 → 问鼎期。

# 第286章 金色铁片之秘：天宝上人与射神车

## 一、仙气与仙玉的价值判断

- 王林明确认知：**婴变期之后**的修炼，除领悟意境外，天地灵气已无法吐纳，**仙气（仙界之气）成为最重要之物**，越多越好。
- 手中所得**仙玉**极为珍贵——王林判断此物若出现在**朱雀星**，「怕是立刻会引起一番浩劫」，甚至**朱雀国**都会为之出手抢夺。
- 本次仙界之行：元神有所受损，但**收获颇丰**。

## 二、金色铁片的真相

### 来历与误判
- 铁片取自仙界一具尸骸胸前，**孙雷**曾称其为「防御类**仙器**」。
- 王林在抓取瞬间即察觉：**此物绝对不可能是仙器**。当时无暇细看，安顿后方以神识探查。

### 探查过程
- 神识融入铁片瞬间，**脑中轰鸣、一阵眩晕**，一道道信息涌入大脑。
- 许久之后，王林**目露骇然**，认定：若铁片所载为真，则此物是**三件所得物品中最有价值之物**。

### 铁片本质
- 实为**玉简般的存在**，记录了一种名为**「射神车」**的法宝炼制方法。

## 三、天宝上人其人其事

| 项 | 内容 |
|---|---|
| 身份 | 尸骸主人自称**天宝上人**，飞升仙界的**炼器痴人** |
| 取向 | 全部精力投于炼制法宝，**对修炼没有任何兴趣** |
| 修为动机 | 之所以修到飞升仙界之境，**只为多活几年**，好完成毕生理想 |
| 毕生理想 | 制作出**天地中威力最大的法宝** |
| 结局 | 理想随**仙界浩劫**而破灭；射神车未达其满意要求，被**封印于洞府之内** |
| 死因 | 浩劫前一刻离开洞府去收集材料以再次尝试，一去**生死两隔** |
| 遗留 | 临死前不愿毕生心血断绝，留下**金色铁片**，留待有缘人 |

## 四、射神车与洞府线索

- 铁片对射神车制法**大肆笔墨**，详述甚多，并**留下洞府地址**，嘱有缘人务必前往取车，若有能力则继续研究下去。
- **致命限制**：制法极为繁琐，所需材料**绝大部分已灭绝**，已不可能再行制作。
- **王林的心动点**：从描述推断，天宝上人洞府内**必有射神车存货**——取现成的车，而非自炼。
- **洞府坐标**：仙界**西部**，一座**虎形山峰之下**。
- **不确定性**：仙界现已破碎成片，洞府是否尚存、是否已被前人发现，均属未知。

## 五、反复出入漩涡的搜寻

1. 王林收回**禁幡**，起身走向平台上的**漩涡**。
2. **平台众修士生态**：修为大都是**元婴期**，不敢进入漩涡，只在平台守候，**打算夺取受伤归来修士**的所得。见王林走来**纷纷避开目光**，王林看都不看一眼，径直入涡。
3. **降落机制**：进入漩涡后身体不断下沉，降落碎片位置随机——首次落在**东部**一处碎片，遂重新升空回到平台，再次探入漩涡，如此**数次之后**才终于降临**西部**碎片。
4. **西部搜寻结果**：神识一扫，此地**并无任何虎形山峰**；仔细搜寻**数日一无所获**。期间遇见两名修士，**彼此打量后未动手，交错而过**。
5. **旁观者反应**：平台众人多日目睹王林反复出入漩涡，**纷纷猜测原因，却无一人敢上前贸然询问**。
6. **王林的判断**：若照此下去，不知何年何月才能搜遍西部所有碎片——**天宝上人洞府实在太难寻找**。

## 六、东部边缘的追杀（章末转折）

- 某次王林自漩涡落下，降临地并非西部而是**东部边缘**，正欲升空离开时，前方传来两道法力波动。
- **逃者**：身体四周**遍布无数黑云**，奔走如风；发现王林后立刻向其飞来，高呼「**道友，救我**」。

- **交手**：白衣男子合扇一指，虚空中骤现**一只大手**向逃者抓去；逃者似无法闪躲，被瞬间抓住——但诡异的是，大手一捏之下，**其身体立刻化作无数黑色小虫，从指缝间散开**。

## 七、要点与伏笔

- 铁片＝**炼器传承（射神车）+ 藏宝图（洞府坐标）**，其价值在王林眼中超过仙玉与其余所得。

- 章末**黑云化虫**之人与**白衣持扇**男子皆未具名，为下一段情节埋线。

# 第285章 仙界碎片：交换传送玉简，天宝上人洞府成空
