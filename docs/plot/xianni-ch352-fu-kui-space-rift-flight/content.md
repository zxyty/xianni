# 仙逆 第352章 符傀

## 一、开局：画轴退敌与撕裂虚空

- 王林祭炼画轴日久，却始终不知如何使用；因储物袋内再无克制野人驼背老者之物，才准备拼一把（或打开、或撕下、或抛出）。
- 老者见画轴的一刻动作一顿——王林立刻改变计划：收起画轴，借这一顿之势急退逃遁。
- 老者事后自语：「那画轴，与我族十一层内的圣物有些相似。」→ 暗示画轴来历与野人一族十一层圣物同源。
- 去往第一层的入口已被封死，王林判断只剩一条生路：以仙剑向虚空狠划，撕出空间裂缝钻入。

## 二、空间裂缝：反常的寒风与星罗盘

| 项 | 内容 |
| --- | --- |
| 裂缝常规危险 | 迷失方向、找不到出口 |
| 本处额外危险 | 有可令**元神**如烛火般忽明忽暗、乃至熄灭的寒风；风中夹带奇异微小物质，触体刺痛 |
| 老者反应 | 寒风对其毫无作用，吹在身上反而舒服（暗示其种族/来历与此处虚无相合） |
| 王林真正目的 | **唯有在虚无中才能使用星罗盘**，以速度压过野人老者、摆脱追杀 |

- 老者右手一抖，一道符文印在正快速收缩的裂缝上，阻止其合并，从容追入。
- 裂缝内飞行多日：不见任何物质，连一丝灵力波动都无，好似只是一块漆黑黑幕——反常之处令王林愈发警惕。
- 老者背手踏步，每一步跨越无数距离，仍无法彻底追上；他惊讶于王林宝物之多、每件皆不凡，推断其身份在上方修士中极为尊贵，**炼其为「符傀」的心思更重**。

## 三、射神车反击战

1. 王林甩出**驱兽圈**，砰然化作战车（射神车），落在星罗盘上。
2. 打出印诀按在战车上 → 兽魂咆哮而出，因距离极近当即一口吞来；王林印诀不变、灵力轻吐，战车铁链收缩硬生生把魂兽拽回。
3. 法诀再变，战车狰狞利刺闪耀黑芒；据上次经验，**开启需一炷香**。
4. 一炷香内黑芒被兽魂尽数吸收，兽身愈发庞大，期间数次欲吞王林皆被铁链锁住。
5. 完全开启后，王林停下星罗盘、掐诀留而不发；老者察觉其停步立刻追上、魂力充斥。
6. 王林按诀落下：兽魂身上铁链尽消，**唯独它与王林之间的铁链依旧存在**（闪烁妖异之芒），兽魂扑向老者。

## 四、老者的底牌：符文印记与启蒙符文

- **第一层防御**：双手一摸体上符文印记 → 印记透体升起三寸，将魂兽硬阻在体外三寸；饶是如此仍被推出百丈。
- **第二层加压**：双目充满血丝，大喝之下符文由三寸升至五寸，缓缓推动魂兽。
- **王林偷袭**（趁他病要他命）：持仙剑一跃斩下，剑芒融入暗黑宣泄而出，接连多次改向斩击 → 老者身前符文不断下沉，**胸口留下三道深可见骨的伤口**。
- **老者反击·七叶**：眉心出现**七叶植物**，全身符文疯狂蠕动，抬手向王林一点 → 一股寒气自王林腹部升起，极快钻入元神，凝聚如种子并开枝散叶；王林面色苍白、喷出鲜血。
- **老者底牌·启蒙符文**：右手骨头串成的手镯断裂脱落，散出绿色幽光，显出一道**残破不全、多处碎裂**的符文；黑色虚无尽被绿芒笼罩。
  - 老者原话：「这是老夫的启蒙符文，就是通过领悟此符文，老夫才达到了七叶。小辈，你有幸看到此符文，死也足以。」
  - 兽魂身涌绿意、回头怒视，自忖「若是当年全盛时期敢与之一斗，现在却不得不退」，震散绿意后迅速缩小消失。
  - 副作用：符文现身瞬间，**王林元神中的寒气种子生长速度骤然加快**。

## 五、收场与残局

- 王林毫不犹豫回到星罗盘，操控疾驰而去；射神车上兽魂再现却已虚弱，消失于战车内。
- 老者未追，先低头查看胸口三道剑伤，杀机浓郁；半跪于破碎绿色符文前，符文慢慢缩小融入体内，骨头手镯无声重现于手腕，随后化作流星继续追击。
- 王林状态：双目紧闭，眉心一株植物印记闪烁不定，黑纹自眉心蔓延过脸部至颈部并仍在扩散；口中低吼，睁眼时目露癫狂旋即合眼挣扎。**极端痛苦中仍保留一丝神智，分心操控罗盘持续逃遁。**

## 六、要点与伏笔

- 「符傀」= 野人老者欲将王林炼成的傀儡形态，本章标题所指。
- 「七叶」为野人一族/符文体系的境界标尺，由领悟启蒙符文而达成。
- 画轴 ↔ 野人族十一层圣物的相似性，是尚未揭晓的伏笔。
- 王林中的寒气种子（眉心七叶植物印记 + 黑纹蔓延）为遗留危机，未在本章解除。

# 第353章 木属性

## 一、危局：符种蚀神，将成符傀

- 王林眉心的妖异植物疯长，黑纹蔓延全身（手背可见），黑纹组成奇异图案，如扎根肉中并继续扩散。
- 本质：符文已在体内蔓延**整个元神**，如大网将元神罩住；皮肤黑纹只是元神符文的隐透。王林双眼时有符文闪过，红芒与清明交替。
- 王林评价该符文「太过歹毒」「好似有生命一般」，只能**暂时压制**，无法根除。
- 途中符种再度发作，压制后瞳中符文更重、手背几乎布满符文，外人见之会误认其为仙遗一族。
- 后果预期：一旦元神被黑纹完全包裹，王林将彻底沦为**符傀**——双眼红芒、气息暴虐、人不像人鬼不像鬼。

## 二、逃亡消耗战

- 王林将**射神车**一抹化为手镯收起，消耗一块**极品灵石**抵抗此车吸力。
- 改以**星罗盘**疾驰逃遁，已持续近一个月，直线飞行仍看不到虚无之地尽头，四周漆黑、无物质无生息。
- 心境：好似回到当年筑基期亡命天涯之时。
- 支撑点：储物袋今非昔比，灵丹妙药、各种灵石可随时恢复修为；每服一粒丹药都极为仔细不浪费药效。
- 死局条件：丹药灵石耗尽 → 灵力不足以催动星罗盘 → 死路一条。
- 战术判断：所有法宝（除**无法使用的画轴**外）对驼背老者全部无效，唯有跑；这是一场**消耗战**，看谁先耗不起。

## 三、驼背老者一方（仙遗族设定披露）

- 驼背老者始终紧追且越追越近，全靠星罗盘速度超乎想象才未被追上。
- 老者惊讶：此人身中符文仍能长时间催动法宝，实属罕见；推测其为上面外来者中的大派弟子，甚至是**朱雀国**弟子。
- 目的：将王林**炼成符傀**派遣上去，「定可收奇效」。
- **关键设定**：仙遗族碍于当年朱雀国的某种神通，无法从**仙遗第一层**离开前往地面；**只有符傀才能上去**。
  - 由此解释：仙遗族杀敌后必收取尸体（炼符傀之用）。
  - 反证：否则修魔海及所有仙遗之地临国早被仙遗族屠杀干净，也不必为争夺妖兽而本族之间大打出手。
  - 王林当年在仙遗山林外发现之人，正是**低阶符傀**。
- 老者自信：自己种下的符种，除非修为比他高出一个境界，否则无人可解。

## 四、破局：木属性与天逆珠

### 推理链
1. 危机核心是眉心那株植物所生黑纹。
2. 仙遗族所有野人眉心皆有此物。
3. 植物既是植物，纵为符文幻化，**亦属木属性**。
4. 类比先例：筑基期时于**火焚国**地下岩浆遭遇荒兽**火灵**，被吞噬瞬间**天逆珠**开启吸收火灵，完成**火属性大圆满**。

### 操作
- 右手点眉心，轻吐「天逆」，灰色珠子（其上有几片叶子图案，外表平平无奇）自眉心飘出。
- 见珠上叶子，王林猛灌灵力使星罗盘骤然提速，随即收回灵力——借滑行争取的短暂时间，全心沉入元神，将黑纹逼向眉心。
- 眉心植物显形，第一片叶子打开，第二片伸展；期间清明之色反复消散又凝聚，汗透衣衫。
- 这是一场**赌**：赌木属性成立则天逆珠可吸；若输则立刻全力压制黑纹。
- 结果：天逆珠闪起**青芒**，由弱转亮，眉心刚绽的叶子生生从额头钻出，被吸入珠内消失。王林双眼立刻清明。

### 收尾处置
- 时间紧迫，未继续吸收，立即收珠、全速逃遁；但心底不再焦急——已握有**解符傀之法**。
- 老者随后赶至原地，察觉异常大震：「这小辈身上的法宝怎么会这么多，居然有可以化解符种之物」，再次追出，决意必炼其为符傀。

# 第354-355章 余人：虚无中的八月消耗战

## 一、局面：追不上的猎物

- 驼背老者（七叶术咒师）追击王林已超过四个月。多次即将追上，王林身下的**星罗盘**便突然散发白光、瞬移而出。
- 老者**并非修士**，一身修为全靠身上的**符文**，符文之力会随出手与追击而消耗。追不上一个小辈，对堂堂七叶术咒师是耻辱。
- 老者心中动摇：不知对方还有多少法宝、多少丹药，遂放弃追击、转身向出口而去。

## 二、反转：王林由逃转为骚扰

- 王林察觉危机感消失，停下星罗盘。他判断：若对方只是**化神后期**，他早已反追一通；但对方相当于**婴变期**修士，故格外谨慎。
- 王林先是不紧不缓跟随、绕行试探。老者忍无可忍回头追击，王林即以星罗盘遁入虚无。
- 数轮拉锯后，王林确信对方是真的**无力追击**，遂主动出手：拍储物袋取出**仙剑**，脚踩罗盘，连斩四道黑色剑芒。老者一指点散剑芒，警告「此番放你一次，若再跟随休怪取你姓命」。
- 王林不退反进，持续以剑芒骚扰。一个月后老者烦躁至极：追则王林狂逃，停则王林复来。

## 三、心理战：丹药与灵石的虚实

- 老者咆哮质问，王林在远处笑答「晚辈口袋内的丹药已经不多，前辈若是再追，定有希望追上」——反向诱导。
- 王林的丹药**确实**将尽，但他仍有**极品灵石**，故有信心安然无恙。
- 老者由一丝疑虑演变为确信：王林丹药灵石极多，除非星罗盘损坏，否则永远追不上。他曾想攻击星罗盘，但王林极为谨慎，一到某距离便瞬移，始终没有机会。
- 关键转折：王林改变方向**朝出口挪移**，并放话要去毁灭出口，「你我二人从此在这虚无之中游荡」。老者被迫由「被骚扰方」变为「必须追」的一方，攻守易位——难受的换成了老者。

## 四、副产品：王林的法宝熟练度暴涨

数月后丹药用尽，王林改以**极品晶石**供能：取出四块晶石，在星罗盘上开出四个缺口放入，完全以晶石催动罗盘，本人只留一丝神念操控，其余精力全用于以法宝攻击老者。

借此难得的「可尽情使用法宝」机会，他轮番演练：

- **禁幡**化作的禁气之枪
- **岁月木雕**
- **黑印**
- 储物袋中的**三把剑鞘**
- **仙剑**——最重要的一项进境：通过剑内**许立国**的魂魄，可不用手持，如飞剑般在身体三丈之内挥舞。威力未增，但更为灵活。

结论：这一路修为未涨，但对自身法宝的了解「与之前好似天地之差」，再用出时威力更大。此皆「拜老者所赐」。

## 五、断绝后路：斩碎出口符文

- 王林远远看到出口：一个**巨大符文**闪动不停，凭其闪烁维持此处空间裂缝不合并。透过裂缝可见外面**无数野人层层围绕、目光炯炯**。
- 王林本就不打算从此处离开。他从星罗盘跃起，仙剑向下一斩，符文震颤出裂纹；老者惊慌瞬移冲来，王林再次一斩——**符文崩溃，空间裂缝合并，出口消失**。
- 王林大笑：「老匹夫，既然小爷无法离开，你也别走了，继续追啊」。老者双眼红芒：「疯子，你这个疯子，老夫死也不会放过你」。

## 六、结局：老者化作七叶植物

- 老者身上符文已黯淡无光，追了少许后握拳咆哮，盘膝坐下。
- 其**眉心钻出七叶植物**，叶片渐大将其身躯完全包住，最终只余一株巨大植物孤独开放于虚无之中。
- 老者闭目自语：「希望可以凭偌**族灵**，打开通道」。

### 第355章开篇

- 王林远远感应到植物，犹豫后**未再骚扰**，转身离开。全程分寸：以自保为前提才出手。
- 他清楚断人后路者必遭极恨，且相当于婴变修士的七叶术咒师即便虚弱也有杀死自己的手段，自认无法杀死对方；若非星罗盘之速，早已成其符傀。
- 王林离去后，老者在植物中睁眼，红芒一闪，感知王林急速远去，轻哼道：「可惜此子行事谨慎，若是他上前来，此次我定能杀了他」——印证王林判断正确。随后利用族灵渐渐与外界沟通。

# 第333章 虚无脱困之谋与本尊的搜寻

## 一、虚无之中：无出口的迷宫
- 虚无与外界不同，身处其中无法撕开裂缝；若无外界的牵引联系，如同迷宫，将被永久困住。
- 驼背老者（仙遗族一方）眼露焦急，已把王林抛在脑后，唯一念头是以**族灵**联系同族，请同族在外界撕开裂缝、留下牵引，好找到回去之路。

## 二、王林：吸尽符文植物，天逆珠子木属性将圆满
- 王林立于**星罗盘**上飞行许久，身后危机感尽消，仍谨慎再飞数日方缓。
- 盘膝罗盘，右手点眉心，**天逆珠子**（石珠/天逆珠）飞出。
- 体内灵力一动，黑纹再现，此时黑纹已不多，仅颈脖以上尚存——八个月飞行中他已多次以珠吸收体内**符文植物**，吸去大半。
- 低喝、面露痛苦，黑纹上涌尽聚眉心，奇异植物再现，天逆珠子散青芒吸收。
- 事毕自语：终于驱尽所有符文植物；断言**仙遗族咒法太过诡异，日后遇到定要小心谨慎**。
- 观珠：九片叶子在珠上散开，最后一叶亦散开一小半。判断「天逆珠子的木属性将要圆满」。

## 三、脱困之策：以本尊为牵引
- 回溯：王林此前**一剑斩碎出口上的符文**、断绝驼背老者出路，是早有打算——虚无中无外界牵引难出，而他有**本尊在外**。
- 当下最重要之事：想办法离开此地。遂盘膝罗盘，默默**感应本尊的存在**。

## 四、本尊出土（楚国·仙遗之地外山谷）
- 位置：楚国、仙遗之地外的山谷，**地下数千里**泥土之中，一团紫光闪烁。
- 形貌：紫光中盘膝的冷峻男子，**一头红发**，上身赤裸，古铜色皮肤略粗糙且有细小裂纹；**眉心两个星点呈阴阳状缓缓转动**。
- 睁眼即透煞气，化作奔雷升至地面；腰间一拍着黑衫，外观与寻常修士无异。

## 五、捶空成裂：上千道空间裂缝的搜寻
- 进入仙遗之地山林，于巨树下一拳轰击虚空，打出**不断旋转、四周带碎裂断痕的圆形空间裂缝**。
- 等候少许无果，继续前行；**每隔十步一拳一裂缝**，周而复始，速度越来越快，步步深入山林内部。
- 打出**上千个**空间裂缝后，抵达进入仙遗之地的巨大深坑外，低头一看即转身换向，照旧十步一裂缝。
- 全程神色如常，无半分不耐。（意图指向：为虚无中的分身/王林制造外界牵引与出路。）

## 六、仙遗山林北侧：拦杀青衫老者与白纱女子
- 北侧枯枝烂叶地面，本尊神色一动，身形一闪拦截远处二人。
- 二人：**白纱女子**（身材妙曼、脸带白纱，被称「小姐」）与**青衫老者**（身穿青衣，化神级手段）。
- 交手记录：
  1. 本尊落地处地面龟裂；一拳轰出。
  2. 老者放**山形法宝**化巨大山峰，闪金芒——一拳即崩，山峰化碎石反卷二人。
  3. 老者吐白光成飞剑，寒芒中有紫线，为**紫心铜**所炼；与本尊拳头相撞后**从中崩溃**成碎片。
  4. 飞剑携**化神修士的意境**顺拳入本尊体内；本尊「身为**吉神**，无意境却有**煞气**」，发梢一飘、体内血红之芒闪动数下，意境即崩溃。
  5. 本尊一拳布下**禁锢般的神通**围困二人；老者向白纱女子借「法刀」——一把**断刀**，咬破舌尖喷血祭刀，硬挡头顶一拳，断刀现裂纹、崩碎一角，二人借势挣脱禁锢。
- 对话与结局：
  - 老者厉喝「你我素不相识，这是为何」；称此生除**仙遗族的战咒士**外，从未见过能直接摧毁法宝、踏步即生空间裂缝之人，心惊肉跳，且遍搜记忆不知何时得罪对方。
  - 本尊冷问「你二人，从何处而来」。白纱女子答：晚辈**周国**之人，路过此地，想去**楚国**。
  - 本尊断为「一派胡言，找死」，右脚一踢，断刀彻底崩碎，老者如流星自半空轰落（重创，生死本章未明）。
  - 白纱女子泣问缘由，本尊神态冰冷看向她——本章止。

## 七、要点与伏笔
- 天逆珠子木属性接近圆满（九叶已散、末叶半散），为后续属性圆满埋线。
- 王林脱离虚无的关键路径 = 本尊在外制造牵引；本尊的「十步一裂缝」即在执行此事。
- 「吉神无意境、有煞气」明确了本尊（吉神之身）的战力性质。
- 白纱女子的来历自述被本尊当场识破为谎言，动机与其身份为后续悬念。
