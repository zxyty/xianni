# 第九卷 云海之巅 第1190章 骨下之瓶

## 一、时限：愈合中的禁幕裂缝

禁幕上那道长长的裂缝正蠕动中飞快愈合。一旦彻底恢复，除非再次以众多法宝的毁灭之威强行打开，否则将与「岁月禁」一同封印成永恒——这是本章一切行动的时间压力来源。

## 二、闪电石门与兽魂洞府

- 裂缝内是一处小山。苍松子与青衫女子（赵道友）先后疾驰而至。
- 山峰中段有一座约二十丈高的石门，其上刻有**闪电图腾**。
- 苍松子从储物空间取出一枚**银色闪电形状吊坠**抛出，吊坠银光与石门闪电图腾辉映，石门轰鸣中缓缓打开。
- 门内洞府立刻传出穿透灵魂的兽魂咆哮，化作疯狂扩散的神念——洞府内确实封印了大量**兽魂**。

## 三、苍松子的诱局

苍松子抱拳称「时间紧迫，赵道友先取兽魂，老夫要去看一眼那道经」，并顺势邀其同去「或有感悟」。青衫女子沉默摇头。

- 女子不信其言，但眼下一切无破绽，尤其兽魂波动为真，故在洞口留下一系列禁制后入内。
- 苍松子在峰顶余光看她进洞，冷笑：「老夫没有说谎，那里确实封印了兽魂，不怕你不进去，即便你暗中跟来，也无妨。」
- 随即掐诀，石门极速收拢严密关闭。其内传出女子怒喝与砰砰击打之声。

## 四、彩虹桥与七彩石碑世界

- 苍松子于峰顶跪地、双手撑天，诵出听不清内容的诡异之语。
- 七彩之芒骤然浓耀，穿透此地雾气落于山峰，盘旋后化作一道**彩虹之桥**，延伸入前方虚无。
- 彩虹尽头虚无中，七彩之芒组成漩涡；踏入后是一片混沌七彩世界，光源来自前方一座**万丈石碑**，威压逼人，来者皆欲跪拜。
- 苍松子跪地默诵，身上浮现印记，最终尽数凝聚于双目，好似封印（推测为防止「看」道经而中招的护目手段），方才抬头。

## 五、道经·黑骨·玉瓶

- 石碑最下方钉着一具**只有上半身的修士骸骨**，双臂被七彩之芒化作的石钉深钉碑上。
- 骸骨在七彩世界中不改色，散发扎眼黑色；漆黑骨头上遍布密密麻麻闪烁的文字——**这些文字就是道经**。
- 骸骨下方是数丈大小的圆形阵法，刻有无数符文；阵心（断裂脊骨正下方）放着一个**玉瓶**。
- 骸骨脊骨处黑光闪烁，渗出一滴**黑色如血液的水珠**，啪的一声落入玉瓶。

**关键设定（苍松子自述）**：「这道经看后就会成为**铭志者**，老夫活的好好，岂能冒险进来只为了找死。」——看道经只是幌子，他真正的目标始终是骸骨下的玉瓶。

## 六、夺瓶手法

1. 右手触瓶瞬间，全身散出无数白气被玉瓶迅速吸收（明显早有预料，神色不乱）。
2. 左手一挥开启储物空间，放出**近千个被封印的元神**，元神之间以细线相连。
3. 口诵诡异咒语，左手抓住一个元神；该元神颤抖消散，随后连锁触发，**仅十息**近千元神全部消散，化作白气被玉瓶吸收（以群体元神替他喂瓶）。
4. 咬破舌尖喷出鲜血成血雾，四道金光化作**四把手掌大小的金光小剑**，血雾融入剑内，砰砰插在阵法四个方向。
5. 低喝一声，右手上抬，生生抓起玉瓶，疾驰后退，口发狂笑。

## 七、灭口与反转

- 后退时收回四剑却不入袋，直接穿身而过射向虚无深处：「赵道友，你可看够」——原来青衫中年美妇已暗中跟来。
- 美妇幻化现身，掐诀布出无数禁制形成漩涡阻挡；四把金光小剑触之即**融化为金色液体穿透禁制**，继而崩溃化作无数金色雨水四面八方围攻。
- 苍松子狂笑：「虽说老夫不知你到底如何脱困，但你不该跟来。这就是那道经所在，你好好观摩吧。」
- **他的毒计**：自己顺彩虹回山峰即刻离开，裂缝愈合后美妇被永久困死此地；唯一生路是放弃肉身、元神入「铭志」而出——但那与死亡无异，只是沦为此地众多**铭志者**之一。
- **反转**：正欲迈出七彩世界时，前方幻化出一道身影——满脸皱纹的**青衫老妪**。她与四旬青衫美妇相貌惊人相似。苍松子为之一愣。

## 八、禁术揭示：取阳聚阴归祖之术

苍松子面色一变：「这不是分身，是**取阳聚阴归祖之术**。」

- 云海星域极为古老的传说中禁术，骇人听闻、有违常伦，修炼极为艰难，至今几乎罕有成功。
- **机制**：女修与人双修后孕化一女，此女在母体内长大，以特殊神通使母女**共用一体**；若干年后，这母女一体的女修再次与人双修又孕一女，祖孙三人再以特殊神通融为一体。
- **效果**：修为暴增；因**三魂一体**，神识极为强大。
- 苍松子据眼前之景断定：竟有人把此禁术练到了**三祖**的境界。

## 九、要点与悬念

- 苍松子对玉瓶（黑血）的觊觎远胜道经，说明黑血/玉瓶价值极高且他事先掌握内情（地图、吊坠、护目印记、备好近千元神）。
- 「铭志者」为观看道经的代价性归宿，是本地大量存在的存在形态。
- 赵姓女修并非一人一身，而是三祖同体；被关洞府的一体仍有其他「祖身」在外，苍松子的困杀之计已然落空。
