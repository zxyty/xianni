# 第1429章 井中捞月！（第九卷 云海之巅）

## 场景
火雀族圣地内。刘金彪被无数支线（触手）缠绕、发出凄厉之声，许立国吓破心神急急召唤王林。七彩火焰内盘膝的掌尊只说了三个字——「有意思」。

## 一、王林破空现身
- 掌尊三字出口刹那，许立国所化的剑之风暴内轰鸣惊天：一股力量自虚无浩荡而来，以许立国所在为定位，从茫茫星海中锁定其位置，如两只无形大手将风暴撕开、一分为二。
- 崩溃处出现巨大裂缝，雷光闪烁、火焰滔天，王林一步走出：**一头白发、一身白衣，双目隐藏残虐之色**。
- 王林称其为「掌尊」，掌尊道「我记得，你叫做王林」，王林答「正是」，**不再隐瞒身份**。
- 王林右手一挥，雷图与九色火焰幻化而出：先卷回许立国入储物空间；再化作雷霆与火焰交织的大手，将刘金彪从无数触手中生生拽出、送入储物空间。掌尊全程未阻止。

## 二、掌尊的自陈
- 「本尊在你身上，看到了**青霖、清水、还有那司马墨**的感觉。」
- 推断王林敢来，一是**一代老朱雀给了胆量**，二是觉得**本尊重伤多年未复**而起窥伺之心——王林答「正是」。
- 「本尊的确重伤未愈，但你送来**天逆**，却是让给了本尊痊愈的希望。」
- 「本尊修道至今，太多人恨我入骨，但最终，却没有人可以亡我。你虽优秀，但还没有资格。**本尊只出一术**。」

## 三、王林的全力一击（几乎倾尽所有）
- 左目：九色火焰暴增，化作九色虚幻之火风暴轰击。
- 右目：雷光一闪，**不灭雷图**再现，九色伴随之雷环绕化作**九条太古雷龙**；雷图内隐隐出现一道**通往太古雷界的裂缝**。
- 左手掐诀一指：草木之香弥漫，星空幻化无数森林，**万古木灵**凭空坐起低吼扑向七彩火焰。
- 血光滔天化作**血剑**急速冲去。
- 双手掐诀下全身修为轰然爆发，形成冲击临近。

## 四、井中捞月
- 掌尊右手抬起向天空一抓，道「**天地此界，可看成一井**」。
- 整个星空轰然一震，波纹涟漪扩散、水汽弥漫，星空化作水面；自至高处下看，此水面赫然是**一口井**。
- 「井中有万物，你之一切神通、一切法宝，即便是你的身体，也在这井内存在。」
- 水面平静瞬间倒映上方一切：火焰风暴、不灭雷图、万古木灵、正中的王林之身——**唯独不倒映七彩火焰**，几乎分不清水上为真还是水下为实。
- 王林与其所有法宝**当即停滞半空**，仿若魂被水面摄去；王林感到水中身影仿若就是自己，玄妙而真实。
- 掌尊道出术名「**井中捞月**」，右手隔空向水面随意一捞，捞起的不是水，而是一个正在挣扎、双眼充满暴虐的「王林」，死死握于掌心。
- 「老夫看那井中的月色很美，也想要拥有一个，现在，我拥有了。」「**他，就是你**」「你看，杀你，其实很容易」。
- **井中捞月，捞出的是魂**。此术之下被倒映者将失去全部肉身之力，绝不可能开口说话。

## 五、掌尊显形
七彩火焰轰然向四周弥漫，露出清晰相貌：**面色苍白、目中平静如水的英俊中年男子，仙风道骨**；身穿一套样子极为古怪的**灰色铠甲**，好似长在身上、与肉身不分彼此。

## 六、反转：以古魔魂代本魂
- 王林却开口说话：「看来，你真的受伤很重」——语出瞬间神色由暴虐转为一片平静，中年男子眼中立刻异芒一闪（因被倒映者本不该能开口）。
- 王林上前一步，翻手取出**朱雀之羽**，一挥之下惊天火焰横扫，笼罩整界天空化作火海，火海如愤怒般剧烈燃烧。
- 中年男子右手狠狠一捏，被抓的「王林」凄厉惨叫、全身崩溃彻底死亡；王林身子一颤、面色苍白，却毫无停顿。
- 王林右手一指天空，按**一代老朱雀**所传口诀低喝：「**吾六代朱雀，以泽留雀羽，唤我朱雀一族源灵，从那古老的太古界内，降临**」。
- 中年男子猛地起身：「本尊的确小看了你，你居然在来此之前，就准备到了如此程度，**以一缕魔魂代替本身**，好，好」。

## 七、伏笔回收与手段解析
- 王林来此前**与天运子之魂融合、展开疯狂推衍**（如当年与水道子一战前），隐隐看到一丝模糊迹象：一场**与魂有关**的生死危机。
- 因此他索性将**古魔魂抹去神智**，与自身魂魄替换，让其成为「本尊之魂」——井中捞月捞取并捏碎的正是此古魔魂。
- 关键前提：**古魔、古神本是同源**，唯有身为古神的王林才做得到完美替换；换作他人（哪怕修为高出王林）在此术下也必崩溃且被察觉。
- 另一前提：掌尊**重伤未愈且小看王林**，否则难以成功；即便失败，王林也早已备好诸多退路，绝不鲁莽赴险。
- 人物特质印证：「王林一生险阻，凭的就是**机敏与谨慎**」。
