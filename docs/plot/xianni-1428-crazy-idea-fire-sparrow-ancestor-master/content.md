# 第九卷 云海之巅 第1428章 疯狂的念头！（第三更）

## 一、火雀族老祖挟人归族

- **火雀族老祖**身为**三步大能**，境界为**空涅初期**，在星空中举手投足即可惊天动地；施展遁术**缩地成寸**，带着**刘金彪**直接回到**火雀族总部**所在的**火雀诸星**。
- 老祖一步迈出、星空扭曲，眼中露出浓浓狂喜，直奔修真星深处**被火焰环绕之地**——其**常年闭关所在**。
- 该地火温极为可怕，**半点火星即可令修士肉身焚灭而亡**，火雀老祖却毫无不适。

## 二、刘金彪的「骗道」状态

- 刘金彪一路神色阴沉如水，冷冷望着老祖，看不出心思。
- 他**已完全代入骗道**，忘记自己的过去、**把自己都骗过**，认定「他刘某便是六代朱雀」。
  - 自设身份逻辑：历经太久权势之后被火雀族偷袭所擒；身为六代朱雀自有尊高，纵有生死危机也**绝不开口求饶**。
  - 【据世界状态须知】真正的六代朱雀是**王林**；本章的「六代朱雀」言行归属刘金彪之伪装。

## 三、模糊之门与跪拜的三步大能

- 闭关之处有一扇**通体虚幻的模糊之门**，隐藏于火海之中，寻常之人根本无法踏入半步，加之老祖亲自把守，森严无比。
- 门上**禁制并非老祖所布，而是「其主人」留下**；强大程度**就算第三步大能也无法短时间破开**。
- 来到门外，老祖压下激动，**噗咚一声跪在门下**：
  > 「主人，老奴擒来了六代朱雀，特此献给主人，助主人伤势恢复。」
- 刘金彪双眼一凝、头皮发麻：**第三步大能的火雀族老祖，竟跪在门下自称「老奴」**。
- 门内长久无声，老祖始终恭恭敬敬、毫无不耐；这一幕使刘金彪震撼愈深，**隐隐有从骗道中苏醒的迹象——他是被吓醒的**。

## 四、门内之声的问答与验证

- 半晌后，一个**虚幻的声音**自门内徐徐飘出：「六代朱雀？」
- 老祖身子一震，神色更恭敬，激动禀报验证手段：
  - **吞了此人血液**；
  - **对其展开搜魂**；
  - 结论「绝不会错，此人就是那六代朱雀」；
  - 并强调是在**颠落之地**将此人擒来。
- 声音沉默，随之**一股无形威压渐渐笼罩**，刘金彪身子颤抖，高傲消散、代之以无尽恐惧——**彻底被吓醒**。

## 五、刘金彪的内心崩溃

- 口干舌燥、眼露惊恐，内心疯狂呐喊：
  - 「玩大了，这次玩大了！」
  - 「以第三步大能为奴，这到底是什么人？」
  - 「那**王林**安排我进来，说是能救我出去，但就算是他来，怕是也会身亡！」
- 此处点明：**刘金彪潜入火雀族是王林的安排**，且王林曾承诺能救他出去。

## 六、被送入门内：七彩火焰与蛛网星空

- 门内声音再次传出：「把他送进来。」
- 刘金彪张口欲解释，老祖已抓其身体直冲模糊之门；**门上禁制被压制下来，未曾爆发**，任由老祖进入。
- 进门所见（刘金彪一生无法忘记的场面）：
  - 一片**无天无地的星空**；
  - **一团巨大火焰占据星空七成**，弥漫之下传出轰轰燃烧巨响；
  - 火焰**颜色为七彩之色，没有黑白**；
  - 火焰外星空**没有任何星痕**，只有**一道道手臂粗细的支线**，似从虚无内延伸，弥漫整个星空，**一眼看去如同蛛网**；
  - **火焰位于蛛网正中心**；蛛网支线**仿若一条条通道**，其内**有无数鼓包蠕动**，自四面八方直奔中心火焰，**似被火焰吸收**；
  - **七彩火焰深处，隐隐可见盘膝坐着一个身影**。

## 七、悬念与要点

- 火雀族老祖之上另有**「主人」**，能令三步大能为奴、留下三步难破的禁制，且**身负伤势**、需吞噬「六代朱雀」恢复。
- 骗道之术可骗过**火焰探查、验血、搜魂**，却在绝对威压与认知冲击下被「吓醒」。
- 门内空间的「蛛网通道输送鼓包供养中心七彩火焰」结构，指向某种大规模的吸收/供养体系。

# 第1336章 剧情梳理

## 一、火雀族圣地：伪装被戳穿

- **场景**：火雀族圣地的诡异星空，四周布满「无数通道般的支线细丝」。
- **神秘身影**：立于火焰之中，全身似着铠甲，身后有一条**七彩朱雀**闪烁；声音虚幻，回荡星空。其威压足以将刘金彪「杀死千万次」，自称「本尊」。
- **打发火雀族老祖**：赐下一团拳头大小的**七彩火焰**，直入火雀老祖眉心，火雀老祖狂喜、恭声领命退去打坐消化，消失于星空。
- **戳破身份**：星空只剩刘金彪与火焰身影。虚幻之声道破——「**你不是六代朱雀**」。刘金彪头皮发麻、魂飞魄散，扑通跪地求饶，自报姓名，称自己只是小小修士，被歹人要挟，不来便要送命，愿伺候左右、效犬马之劳。
- **抽血夺机**：对方打断求饶，称「在你的身上，倒也有本尊感兴趣之物」。四周支线细丝骤然抬起卷住刘金彪，破开肉身钻入体内一吸——其肉身肉眼可见地枯萎，大量血液被抽出化作细丝上一个个鼓包直奔火焰；生机亦急速消散。
- **许立国现身**：刘金彪挣扎尖啸，喷出一口精气，滔天剑气轰出——许立国幻化成一把大剑，未刺向火焰虚影，而是旋转化作**剑之风暴**。
  - 许立国内心咆哮：「**主人，通道已经打开**」；并骂「都是那煞星害的，他以为这圣地有火之本源，却没想到这里有个活人，而且还是**以三步大能为奴**的活人」。
- 火焰中的声音似带微笑：「有意思」。

> 归属提示（依世界状态须知）：刘金彪自第1303/1336章以骗道之术伪称「六代朱雀」（真正的六代朱雀为王林），本章被当场识破。

## 二、大帝星：王林的推衍与决断

- **位置**：颠落之地·大帝星，王林闭目盘膝坐于传送阵内。
- **手段**：心神融入**呼风唤雨界**，寻到**天运子之魂**并融入其身，以极快速度不断推衍未来之事。推衍毕，双眼猛睁，其内暴虐之色一闪而过。
- **情报来源**：来大帝星前，王林并不知火雀族圣地内有人疗伤；与**一代朱雀**交谈后，方笃定其内定然有人。
- **一代朱雀的暗示与馈赠**：
  - 直言疗伤者很可能是**三代孽雀**，是其心中愤恨之人；若非无法离开**天方界**，必杀入火雀族亲手了结。
  - 虽未明言，却在交谈中告知会帮王林**完善计划、潜入火雀族圣地**，并赠**一片雀羽至宝**。
- **关键判断**：三代孽雀在**太古星辰**另有身份——王林心中已有**七成**、甚至可说**九成**的答案。七成已足以令他决定做一件惊天动地之事；九成之下，做完便可**离开太古、回到封界**。

### 王林对幕后者的推演（罪状链）

1. 被一代朱雀打伤，又在界内被**神秘修士一吼之力**重创，不得不闭关疗伤，数万年未露面；
2. 闭关期间仍**暗中操控太古**，施展一幕幕阴谋诡计；
3. **其女入界内引诱青霖**，毁灭**封界之尊**的四大仙界香火之力；
4. 联合诸人**逼封界之尊肉身崩溃**，险些死亡；
5. 凡被其看中的界内之人皆不择手段引诱——如**司马墨**、**青霖**，甚至当年的「**清水之疯**」（清水仙君）亦与此人有莫大关联；
6. 更恶毒者，欲行「**种道**」。

> 「眼下他重伤闭关，我岂能放弃这个机会。」——王林眼中露出疯狂之色。

- **动身**：阵法光芒急急闪烁，轰轰之声惊天而起，阵法急速旋转成漩涡，一声巨响后消散于大帝星，王林身影随之无踪。

## 三、湖边独白：老朱雀的私心

老朱雀坐在湖边，睁眼默望王林消失之处，许久后轻声道：

- 一代老祖始终认为王林**不是朱雀一族之人**，即便他通过了试炼；
- 但他本人相信王林是；
- 故**未听从一代老祖吩咐，擅自传授了王林「朱雀最强之术」**——理由是「这本就是他应该在试炼结束后获得的」。

## 四、要点与伏笔

- 火雀族圣地内的疗伤者 = 极可能为**三代朱雀（三代孽雀）**，且在太古星辰另有一重尚未点破的身份（王林九成把握，本章未揭晓）。
- 许立国口中「以三步大能为奴」暗示火焰身影的层次远高于三步。
- 刘金彪一线的「通道已经打开」与王林传送阵的启动，构成里应外合的时间点对位。
- 刘金彪重伤濒死（血液与生机被抽），生死未定。
