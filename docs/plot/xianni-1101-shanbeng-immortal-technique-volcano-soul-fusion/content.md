# 仙逆 第八卷 联盟隐秘 第1101章（二更）

## 一、山崩仙术的原理与关窍

引子偈语：「呼风唤雨撒豆成兵，山崩地裂阴月有晴」——对应仙帝白凡六大仙术。

- **进度**：前三式（呼风唤雨、撒豆成兵…）王林已全部明悟；清水（清水仙君）曾言后三式威力远超前三式，足以惊天动地。
- **山崩**为后三式中的**第一式**，取天地山峰崩溃之意。
- **层级一（浅）**：山有山魂。若只崩山体而魂不崩，威力寻常；须**魂崩体崩同时展开**，在山峦成片之地方可爆发山崩之威。这仅是第一步。
- **层级二（真法）**：如清水一般，**在无山之地以心神幻化成山**，以形为山、崩形而崩山；**以仙力融入神念化作山之魂**，崩山之际即仙力与神念崩溃之时。借此与天地融合，幻化无数山峰，**从虚假之中使其成真**，拥有崩溃天地之大神通。
- **真正关键 = 一个「真」字**：不是山与魂之裂、不是心神幻化、也不是仙力与神念之融，而是**如何让虚幻而出的一幕成为真实存在**。这是重点，也是最难处。
- **传承方式**：清水未明说此点，留在王林心神中的清水感悟亦模糊——似是有意让王林**自行明悟而非直接传承**。

## 二、王林的参悟过程

1. **迷茫**：观远处火山爆发、感身下火山崩意，睁眼仍茫然，低语「婉儿，到底什么是真，什么是假」（无人可答）。
2. **类比**：将真假类比于**生与死、因与果**。
3. **破题（心法）**：不去管真假——「世间若无真，自然也无假；真与假只是一种存在，都是相对而言」；如同无生则无死、无因则无果。并引**墨智**旧言：**一切意境都是心神的感悟，一切唯心动而出现**。
4. **入火山**：拍散身前棺材（化作流光消散），一跃钻入火山口，穿浓浓岩浆直抵火山深处底部，盘膝掐诀闭目。
5. **融合三重**：
   - 火元力冲出体外→与岩浆融合，「仿若这一刻他就是岩浆」；
   - 火元力再弥漫→与包裹岩浆的火山融合；
   - 继续散开→岩浆、火山、滚滚黑烟乃至**天地间的火元**尽数融为一体。
6. **触山魂**：感到火山内传来沧桑气息（即**火山之魂**），元神幻化而出与火山融合——「他就是这火山」。
7. **数万年幻象**：燃烧星球上山峰诞生→内蕴火元力化为岩浆→积至极限顶部崩溃喷发→平息→凶兽呼啸、昔日**朱雀圣宗弟子**飞驰→热浪送来种子化作漫山**赤红之草**，凋零复生、循环不息→大地震动，再一次爆发。数万年一晃而过，王林渐忘初衷与修士身份，仿若真成了火山与山中之魂。
8. **明悟**：「**我，就是火山；我之怒，就是山崩**」。
9. **扩张**：心神疯狂蔓延，四周一处处火山尽入心神，分散融入各山、与山体融合、与山魂触摸，更多画面涌入；元神再散，弥漫**整个星球所有火山**——「仿若分身数千，每一个都是一座火山」。

## 三、朱雀圣宗的反应：全宗弃星

- 一名**碎涅**修为的朱雀圣宗长老最先惊醒，辨出气息**属圣皇**，却极为震惊：气息之沧桑与记忆中那个「**仅是窥涅、修行不足两千年**」的小小修士截然不同，令他自感如小辈。
- 此修真星上**另外三名长老**同时现身，神识中透出相同震惊。（诸长老此前表面认同王林这位新圣皇，心中实有不忿。）
- 全星朱雀圣宗之人从打坐中惊醒，皆感到一股极沧桑的神念横扫而过。
- **异象**：神念弥漫全星→**全星火山同时爆发**，轰隆震颤，天空被黑雾笼罩，大地流淌赤红岩浆；神识中沧桑气息暴增，仿若集合全部火山而具「岁月之感」。
- **撤离令**：一名长老雷霆低吼「所有朱雀圣宗弟子，立刻离开这修真星」，四长老带全星族人冲入星空；众人面露惊慌，绝大部分不知发生何事，长老们**对新圣皇产生强烈不满**。
- **不满刚起，神识再扩**：越过一个个族人扩散入燃烧星域，逐一笼罩、融合**星域内所有修真星**，最终凝成一股**无法想象的庞大神识**。所有朱雀圣宗族人（包括王林熟识的**大头童子**等人）尽数飞出修真星。

## 四、星域外：炎雷子 vs 尸阴宗九王之一

- 地点：**联盟星域东部四圣宗**内，朱雀圣宗所在那片**燃烧的星域**之外。
- 波纹晃动，走出一名**苍发红袍老者**——即**炎雷子**。
- 随即另一处波纹回荡，走出**青衫中年男子**：极为英俊却面色苍白如死人，散发阴寒之气，修为波动令炎雷子**瞳孔一缩**。
- 对话：
  - 中年男子冷声：「**罗天炎雷子**」。
  - 炎雷子平静回应：「**尸阴宗九王之一**，就是不知尊下是第几王」。
- 悬念：新势力**尸阴宗**登场，其「九王」直指朱雀圣宗星域。

## 五、关键设定沉淀

- 白凡六大仙术＝呼风唤雨、撒豆成兵、山崩、地裂、阴月、有晴（偈语所列）；后三式远强于前三式。
- 「真/假」与「生/死」「因/果」在本书体系中同构：皆为相对之存在，唯心动而出现（墨智之论）。
- 王林作为朱雀圣宗**圣皇**，其威望在本章由「窥涅小辈」转为令碎涅长老骇然，但代价是全宗被迫弃星，长老团离心加剧。
