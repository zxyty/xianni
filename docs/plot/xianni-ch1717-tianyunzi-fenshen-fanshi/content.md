# 第1717章 天运子（第一更）

## 一、王林的算计：以分身反推本尊

- 王林打算**以天运子分身之魂，算出天运子所在**。他闭目心神内视被自己禁锢融合的天运子分身。
- 多年来王林借此分身**数次算出生死浩劫下的一线生机**，帮助极大。若非修为渐高后冥冥中感应到天运子的存在对自己是极大危机，他并不愿主动招惹天运子。
- 王林心中，天运子的神秘**从未在第二个人身上有过同样感觉**。
- 王林在屋舍外盘膝**五天**一动不动，心神与分身融合推衍，隐隐再度出现“自己化身成为天运子”的错觉——此感觉**当年面对水道子危机时即已有过**。
- 融合渐深时：心境平和，仙界大陆如在心中，日月乾坤在目内，苍穹万物皆逃不过心念一动的计算；“这种感觉，可以让一个人无限的膨胀”。王林一度**似忘记了自己的名字**，神识散开缠绕体外向四周扩散。
- 要通过本尊与分身的冥冥联系找到天运子，**必须彻底化身成为天运子分身**。此法非首次施展，此前思索并未发现危险端倪。

## 二、召河星域·陨石中的天运子

- 融合的一瞬间，**召河星域**内一颗数丈大小的陨石在星空缓缓飘动，天运子于内盘膝打坐，嘴角诡异微笑；白发飘动本有仙风道骨，被笑容冲散反显阴森莫测。
- 其目光穿透陨石、穿透星空，看到仙界中盘膝的王林：“**不愧是老夫的好徒儿，你逃不出我的手心。你的修为越高，对老夫的帮助就越大，好处也就越多——咦，七道本源了，好，好，好。**”

### 天运子当场显化的本源

| 部位 | 本源 |
| --- | --- |
| 右手握拳 | 因果本源 |
| 左手（置膝） | 生死本源（“左手掌生，右手控死，老夫也会”） |
| 双目开合 | 真假本源（“闭目为假，睁开为真”） |
| 左目瞳孔 | 火焰 |
| 右目瞳孔 | 闪电雷霆 |
| 眉心漩涡（内有一灰衣天运子） | 杀戮本源 |

- **尚差第七道：禁制本源**。其瞳孔涌出大量血丝并占满瞳孔，血丝内渐生禁制，短时间已占**双目三成血丝**且仍在扩展，“怕是用不了太久，就可明悟所有的禁制本源”。
- 天运子对王林之法的评价：“**以瞳丝化作天地规则，以自身意志成为天地法则**……这种方法，古往今来从未有人想到过”；称王林是自己**花费无数岁月推衍出的“逆天之子”**，“我的计划，将在你身上完成”。
- 关键隐喻：“**我有一木，种下两千年，已然开花，只是如今还未到取果之时，还需送出一些养料。**”

## 三、王林警觉与中止

- 五天后王林突然睁眼，**强行从融合中分离**，面色阴沉、满眼猜疑：“奇怪，我怎么感觉在与天运子分身融合时，本源似有流失。”
- 查验七道本源，**未减少半点**，略微放心但疑惑不散。
- 再次尝试融合，将要彻底融合的一刹那**再度强行阻断**，霍然起身，断言：“**不对，这感觉不可能是错觉，天运子分身有问题。**”
- 王林拍眉心向外一拽，抽出如烟丝般的魂，化作天运子模样（分身之魂盘膝不动）；神识入其魂内细搜，**无任何发现**。
- 王林的怀疑升级：分身与本尊的联系本是他寻找天运子的方法，如今却疑心**这联系乃至这分身本身，都在天运子的算计之内**；进而回忆——“**当年在妖灵之地，我以残夜之术杀天运子分身，并占为己有**，难道此事也是天运子故意的行为？”回忆之中仍看不出半点刻意痕迹。
- 与此同时，天运子那边笑容骤消、双目禁制的急速蔓延融合**立刻停顿**（与王林强行断开同时发生）。

## 四、雪山之巅·请青霖护法

- 王林身影出现在**新仙界南方**一处高耸入云、白雪覆盖的雪山之下，寒风呼啸，跃身直奔山顶。
- 近山腰处见**青霜**（一身白衣，望天地神色萧瑟，眼中似有挣扎与回忆）与身后低声说话的**周佚**（目光柔和爱恋）；二人未察觉，王林未打扰，径直而过。
- 山顶有**白色阁楼**，仙气缭绕于天空化作巨大漩涡横扫八方，极远可见。
- **青霖**着蓝衫如文士，含笑开门：“王兄难得来此，不知找青某何事？”——青霖当年曾言收王林为弟子，但随时间流逝不再提；因王林如今修为与身份，改以同道之礼相称。
- 王林抱拳、神色凝重：“早年听闻青霖前辈擅长计算，王某需请前辈护法，帮我推衍计算一番。”青霖当即收笑允诺全力相助。
- 王林说明：手中之魂为**昆虚天运子分身之魂**；天运子擅长计算、如今不知隐藏何处，担心其身上出现变故，故想借分身之魂寻找——并交代前情疑点。
- 青霖面色凝重：“竟有此事？我先看看此魂。”右手抓住天运子分身之魂凝神查看。**本章至此（第一更）**。

## 五、要点与悬念

1. **天运子的收割机制已明面化**：王林的本源修行并非自主成果的独占，天运子可通过分身通道单向“接收”，王林的“流失感”非错觉。
2. **只差禁制本源**：天运子若补齐第七道，王林的独创之法反成对方的最后一块拼图，时间窗紧迫（“用不了太久”）。
3. **“两千年之木”**：王林被定位为长期培育的果实，“送出养料”指向后续必有牺牲/献祭性布局。
4. **妖灵之地旧事重估**：残夜之术斩杀并夺取天运子分身，可能自始即是钓饵。
5. **青霖介入**：以擅长计算者查验分身之魂，是王林破局的第一步；青霜与周佚的感情线在雪山一带同时铺陈。
