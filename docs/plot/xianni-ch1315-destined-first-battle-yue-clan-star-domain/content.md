# 第1315章 宿命第一战（第九卷 云海之巅）

## 一、破阵后的吞噬回血
- 出阵后王林判断拓森绝不会放过自己，虽重伤仍咬牙疯狂吞噬月族族人。
- 月族十万族人中大部分不堪一击；王林一路呼啸，身法上「身子一晃融入天地」瞬移换位，避开围杀老者。
- 片刻之内吞噬超过三万人，体内碎骨融合、伤口快速痊愈，伤势恢复大半，随后主动扑杀。

## 二、月族的应对：模拟古神与献祭
- 阵法崩溃刹那，维持阵法的月族老者尽数喷血，红眼散开：一部分扑向王林化作的黑雾，一部分由白发老者率领冲向拓森。
- **模拟古神神通**：月族无数年研究、意在使自身成为古神之法，靠不断吸收古神之力，可令身体膨胀至数百丈、眉心月牙印记旋转，短时间内近似古神。本章共九人施展，力量极强但仍被拓森轰退。
- 一名模拟古神的老者被拓森一拳打爆，王林抢在其彻底消散前以黑雾卷中吞噬。
- 白发老者为月族在场身份最高者，看出王林绝非拓森之敌，认定两古神一旦决出胜负则月族必死，遂决定「帮王林」以求生机。
- 献祭：白发老者令数名同族崩溃自身月灵，众人眉心月牙印记飞出融入其体内，令其暴涨；随即召动**月族至宝·古神残骨**（深插地面的庞大古神指骨）锁定拓森压下。

## 三、王林 vs 拓森：宿命第一战
- 短暂默契随拓森抬手抓向王林而瓦解，拓森放话「不管你说的是真是假，今日你逃不掉」。
- **伏笔兑现**：此前在封神大阵内，王林施展古神虚之术时融合了拓森磅礴的古神之力，并在古神残骨来临瞬间截留了符文内一半古神之力留在体内——一为让拓森在古神指骨下受伤，二为今日施展古神之术。
- **古神之术·星神之璇**：王林双手点向眉心，六个星点旋转飞出化作巨大漩涡（与拓森以星点吞噬极相似）。漩涡吸走拓森拳中一部分古神之力反化作攻击，拓森右臂发麻停顿。
- 借这一停顿，王林血剑斩落，砍下拓森右手**食指**——为二人交战至今王林造成的最大伤害。十指连心，拓森杀机滔天，不再想吞噬，只想杀死这个同族。

## 四、斩断古神残骨与冲击横扫
- 拓森四面楚歌，双臂硬接古神残指，为撑住而**爆开眉心一颗星点内封印的第三步修士**补充力量；随后展开六星漩涡，欲把残骨当第三步大能吞入星点。
- 拓森判语：「原来这不是九星古神的指骨，而是无限接近九星」。此时其六星内除刚吞噬的太古星辰第三步女修外别无他人。
- 拓森的疯狂令王林震撼生惧（「见过疯子，没见过如拓森这样疯狂之人」）。
- 王林果断抢机会：化残影长虹突进，血剑狠斩指骨——指骨剧震生裂，在拓森吞噬之力下**一分为二**。
- 断裂冲击横扫：
  - 拓森被撞得惨叫喷血、远远抛飞，半截指骨被冲入其漩涡内一颗星中；
  - 白发老者肉身轰然崩溃，元神虚弱逃遁；
  - 未及远离的月族人成片爆碎，死亡无数；
  - 王林亦被波及，以**五道本源**（蓝色火焰、开天雷霆、因果循环、生死交替、真假莫测）同时化漩涡对抗，并催发**极境**（双眼红光）硬扛。

## 五、收尾：满载而归
- 拓森眉心封印太古星辰第三步女修的星点爆发刺目之芒，他整个人一怔后骤然大变，**舍弃王林**、化长虹喷血急急遁走（原因未言明）。
- 王林扛起近小半个修真星大小的半截古神指骨后退、融入天地，临走以**昆极鞭**幻化无限之长，卷住逃遁中虚弱的白发老者元神一拽，一并消失于月族星域。

## 六、要点与悬念
- 王林首次以「古神之术」正面对抗拓森，且所用古神之力来源正是拓森本人——算计早在封神大阵内布下。
- 血剑之锋可斩「无限接近九星」的古神残骨，锋锐等级再获实证。
- 拓森为何在星点异芒后突然放弃追杀、太古星辰第三步女修的星点异动为何，均未交代。
- 王林所获：半截古神指骨 + 白发老者元神（俘）。
