# 第1632章 本我劫

## 一、局面：水幕隔膜与「另一个我」

- 王林不理会白发青年，径直向广阔无边的奇异大陆前行，走出不足百丈即被无形阻力拦下。
- 王林抬手在虚空一拍，前方荡开波纹，化作一道**如水幕般的隔膜**；此膜蕴含浓郁**仙气**，消散其掌力之余更有反震之力自四面八方冲入王林体内。
- 白发青年立于隔膜内的**古妖雕像**上，对王林摇头：「你进不来。」

## 二、本我劫的规则

白发青年给出的信息（自称即王林本人）：

1. 「我，便是你。」——不必惊讶他知晓王林所想，因为二者同一。
2. 王林想知**天劫为何物**、想知**天劫的本源**，则须**打败他**，届时会知晓一切。
3. 「古往今来，你不是第一个第三步逆修，但没有一个可以在这本我劫下存活下去。」
4. 「我很期待，你，能不能行。」——随后一步跨出隔膜，立于王林十余丈外，指向王林发问：「敢，还是不敢？」

## 三、四轮同源对拼

### 1. 因果印（试探）
- 二人身影如流星对冲，右手五指成掌相击，巨响回荡如天地怒吼。
- 同时五指内扣成拳、猛地外拽，欲抽出对方**本源**。
- 白发青年喷血倒抛、七窍流血：**左目幻化火焰图腾，右目蕴含闪电印记**；体内**因果、生死、真假**三种本源自七窍弥漫而出，化作一团**混沌之气**被王林握住。
- 王林状态与之毫无区别，本源同样被对方握住；二人各退百丈，又同时把夺得的对方本源拍入眉心融入体内，以补损耗。
- 白发青年结论：「不用再来验证了……你想要以神通来试探，对别人或许有用，但对我来说，没用。」

### 2. 生死印
- 白发青年左手白气成雾（生，仿若蕴含天地万灵），右手黑气如墨（死，如掌控缘起缘灭）；双掌前按。
- 关键机制：白雾生机本身无害，但一旦入体，随死雾来临则**生死印成**。
- 王林同以生机白雾相迎，左手穿雾对碰，再同举右手相撞；二人同时低吼「生死印」。
- 结果：王林退出百步、面色苍白、体内一片混乱；因其**已明悟生死**，方免于重伤。白发青年撞穿水幕，踏在一尊古妖雕像顶，雕像自其脚下遍布裂缝而崩溃。
- 白发青年狂笑挑衅：「因果印、生死印，还有你所会的一切神通道术，我全部都会……你拿什么来杀我？」

### 3. 真假道
- 王林闭目，白发青年面色一变随即同闭。
- **真假道法则：闭目为假，开目为真**。闭目时天地一切在心中皆为虚假；睁眼刹那虚假复归真实；于真假转化中可看透一切。此种虚幻并非模糊，而是看透本源、明悟一切。
- 二人同时挥手施术：「真假道，一切极为虚假，随我之心动，尘归尘，土归土，全部烟消云散。」
- 此术单人施展威力极强，同时互施则两败俱伤：二人剧震喷血倒卷。王林仅退三步便**强行逆转体内之力**止住身形，再度冲出。

### 4. 定神术（僵局）
- 二人在隔膜外中心点相遇，同时伸右手食指对点，同吼「定神术」。
- **定神非定身**：定住的不只是彼此身体，更是**元神、体内一切运转，乃至天地岁月流逝与万古运转之道**。
- 二人身形静止，自天空向大地坠落。

## 四、王林的暗着

- 王林之前所做的一切，**早在最初与白发青年因果印相碰之时就已别有用心**。
- 他刻意**不去思索**自己的谋划——按其分析，一旦思索，对方极可能感应得到。
- 坠落过程中，王林在脑海内推衍计算，得出结论：**「应该就是这样了。」**（本章止于此，破局手段尚未施展。）
