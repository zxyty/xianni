# 仙逆 第1869-1870章：极天草原剧变与王林逃入地宫

## 一、实力对比：空劫中期意味着什么

- 空劫中期老怪在仙罡大陆足以称一方霸主，可开宗立派、成就万古宗门。**当年的七彩仙尊**便是空劫中期修为，自立宗门广收门徒，连大魂门对其也很礼待。
- 王林此时已有九道本源、修为达**空玄初期**：战空劫初期可胜，要杀艰难但并非不能；面对全盛期七彩仙尊之类的老怪则差距难以跨越，至多有了转折的资格。
- 真要力抗空劫中期，单论修为王林须达**空玄后期**，或其**道古传承**度过最后一次**损劫**。
- 但王林一生在危机中度过，杀人依靠的不仅是修为，还有其他因素——只是此刻他毫无准备。

## 二、绿魔洲的局：以万人死亡为饵

- 整场第二次大战的拖延，是绿魔洲**专门为王林制定的计划**：以大量修士死亡为代价使战事逼真，引王林现身。
- 绿魔洲**援军两天前已到**，却始终隐匿气息不现身，只为杀王林。
- 王林成为头号必杀之人的因果链：
  1. 在丹海杀绿魔天骄**云空的分身**；
  2. 毁掉**丹海仙丹计划**，致仙丹提前崩溃，绿魔洲大地被撼动、出现剧烈毁灭，绿魔洲在丹海的修士死亡大半；
  3. 杀**道魔宗刘之源**；
  4. **许德才**亦有可能被其残杀。
- 绿魔洲**三宗老祖**为之大怒，下达追杀令。
- 张道宗的私怨：上次被王林戏耍耿耿于怀，且王林杀刘之源使他无法向宗主交代。他不惜离开战场追杀，也不在意由此造成的战局影响。

## 三、剧变：四绿魔使者与绿色蝎子

- 张道宗封印此地天地，**挪移之术失效**，王林只能融入蚊兽体内暴增速度硬逃；张道宗紧追不足五十丈，故意不出手，要看王林在绝望中受死亡前的折磨。
- 万里之外**四道空劫中期气息**冲天而起；极天草原被雾气缭绕的天空涌入诡异绿色，凝成**巨大的绿色蝎子**，嘶鸣扩散绿雾压向战场。
- 加上两名空劫中期老者，合计**六名空劫中期**。丹海一役也只出现过三个绿魔使者——绿魔使者对绿魔洲极为珍贵，轻易不会出动太多。
- **绿魔使者的特点**：极为冷酷凶残，不看对方修为，哪怕筑基期小弟子也全力轰杀。

## 四、天牛洲溃退：地宫是最后一道防线

- 与赵姓老者交战的**吕文冉**曾亲身与绿魔使者交手，见状面色骤变，低吼「速回地宫，封死入口」，随即急退。
- 天牛洲修士脚落大地即可融入地底去往地宫；**绿魔洲修士无法进入大地**，因当地阵法依旧全力开启。
- 空劫级修士早被盯死：四道绿光疾驰、绿蝎下沉释放绿雾，阻止他们入地。炎栾喷血落地逃走，许东德面色苍白落地遁走，吕文冉喷出大口鲜血、**右臂直接爆开**才冲入大地。

## 五、王林的两次自爆与生死五十丈

1. **绿伞自爆**：距地面一百丈时，张道宗抬手一指射出绿芒，王林转身甩袖祭出绿伞喝「爆」，冲击之力震得他全身砰砰、口喷鲜血，身子下沉并收起蚊王，距地底不足五十丈。
2. **吕文冉见死不救**：吕文冉落地后一闪即逝，明明看到王林，却**没有丝毫犹豫与停顿，立刻启动封闭地宫大阵**——他本可在自身安全后略等片刻。
3. **三千万道魂葫芦自爆**：王林双眼通红，抛出装有近三千万道魂的葫芦喝「爆」，道魂呼啸而出、葫芦崩溃，惊天之音传遍整个极天草原。三千万道魂的崩溃**足以威胁一个空劫中期修士**：张道宗面色大变、骤停后退，绿魔使者眉头一皱脚步一缓。王林借此跨越五十丈，在阵法完全封闭的瞬间融入大地。

## 六、代价与记恨（第1870章）

- 入地瞬间王林面色苍白、忍不住喷血，化如烟丝直奔地底深处；身后地底封闭彻底闭合——**若慢一丝，便是三命齐陨也无生机**。
- 葫芦本可用于重创一个空劫中期老怪，如今只换来一线生机，王林极为心痛，自我宽解：「即便那葫芦极为强大，也只是身外之物……我终究还是有可能获得更强大的法宝。」
- **两笔账**：
  - 「张道宗，此仇王某记住了」——王林一向睚眦必报。
  - 「吕文冉」——其自私险置王林于死地，王林双眼通红露出杀机。
- **心态转折**：王林来仙罡大陆本无归属感，视此地人与物如陌路，谈不上仇；经此一瞬，他的想法有了改变。

## 七、地宫现状

- 地宫内**仅一千多修士**保住性命逃回，个个狼狈，无心打坐，抬头望着上空，神色忧虑绝望。
- 几名刚回来的空劫修士各自重伤，退在地宫的宫殿群中。
- 大地上方六名空劫中期老怪不断攻击试图轰开封闭；阵法虽强，若六人拼全力持续攻击，**早晚有被轰开的可能**。

## 八、悬念

- 地宫能撑多久？六名空劫中期合力破阵只是时间问题。
- 王林与张道宗、吕文冉的两笔仇怨已埋下伏笔。
- 王林尚未动用的底牌：仍在成长中的分身、尚未浪费的三命之术。

# 第1870-1871章 极天草原地宫召唤天牛之魂、吕文冉争夺魂铠

## 一、外压与人心崩溃

- 绿魔洲六名空劫中期老怪持续轰击天牛第三穴（极天草原地宫）的护阵，闷闷轰鸣不断，地宫颤抖、泥土落下。
- 阵法虽非短时间可破，但持续轰鸣形成无形压力，心志不坚者易发狂。
- 地宫内一千余修士渐生绝望：抱怨无援军、断言守护无用、主张立刻逃走。
- 除数百人保持沉默外，众人蜂拥围住宫殿群，逼问几位空劫大尊「给个说法」。
- 一名中年男子喊出「大不了投降绿魔洲」，话未说完即被无形之力扼颈提出人群，全身崩溃化作带热气的血雾洒落众人，全场噤声。

## 二、吕文冉一行现身

- **吕文冉**：失去一只手臂，面色苍白，双眼阴沉，为首出面弹压，警告「若再有乱我天牛洲军心者，休怪吕某狠辣杀人」。
- **炎栾**：面色惨白，衣衫带血，神色狼狈，默默跟随。
- **许东德**：神色萎靡，前战最后关头受到重创。
- 另有三名来自极天草原附近宗门的空劫修士，神色黯淡跟随。
- **周姓老者**：面色苍白随于最后，被吕文冉点名向众人宣讲。

## 三、天牛魂铠：最后的手段

周姓老者自陈为极天草原地宫负责人，正式身份为 **天牛侍仆**（类似绿魔洲的「绿魔使者」），因体质极适合与天牛魂沟通而被派驻此地、无需过多外出参战。

其宣布的最后手段：

1. 众人付出**全部修为之力**，神念浮现天牛，借此阵召唤 **天牛之魂**；
2. 天牛之魂幻化为 **魂铠**，穿上者被天牛魂俯身，修为短时间达到极为恐怖的程度；
3. 进可反杀回绿魔洲修士，退可保护众人平安离开。

此前天牛洲修士多对「天牛」是否存在存疑，此刻方知其真实可召。

## 四、魂铠的真实价值与规矩（炎栾视角）

- 穿魂铠相当于**一次莫大的造化**：不仅修为暂时暴增，更对自身修为的真正提高有难以想象的好处；日后再攀升进入这一境界会比常人容易不少。
- 前提是须与天牛魂产生一定联系方可做到；**联系越多，增长越恐怖**。
- 机会极难遇：必须天牛洲所有宗门之人在入侵危机下开启 **天牛七穴大阵** 才可开启。
- 此次连吕文冉在内，天牛七穴共有 **七人** 获此资格，七人日后在天牛洲地位必然声名赫赫。
- **禁忌**：召唤天牛魂次数决不能多，多则天牛魂大范围消散，动摇整个天牛洲根基、波及凡人。
- **皇族禁令**（整个仙族之地不容置疑、流传万万年）：除非到了一洲之修的生死存亡，否则不可伤封印天外之兽的魂。违者——**一人死，一宗死，一洲死**。
- 绿魔洲此次入侵，恰使这一恒古命令有了松懈的口子。

## 五、名额之争与作态

- 宫殿内商议结果：**一致同意由修为最高、贡献最大的吕文冉穿上魂铠**。
- 炎栾、许东德及三名空劫修士同样渴望，但即便吕文冉已因伤削弱，凭其此战贡献，他们无法开口争夺。
- 吕文冉当众作态：「越是危险之事，就越是需要吕某去做……若日后因这魂铠死亡，请诸位每年那一天为吕某送上一壶老酒便可。」内心兴奋几乎压不住，神色却透出悲凉。
- 炎栾目中微不可查地露出**鄙夷**。

## 六、王林的判断与谋划

王林盘膝坐在无门的洞府中，一眼可见外面一切，神色随众人绝望之语渐渐阴沉。

- 地宫毁灭与否他并不关心，他考虑的是地宫崩溃、绿魔洲修士杀入后，**如何在逃遁中出手对付张道宗**。
- 头痛之处：张道宗可以封印一次天地，就能封第二次、第三次、第四次，且这封印**重点针对自己**。
- 由此判断：**绿魔洲已留意到他**，丹海内的事情恐已知晓，此次前来的四名空劫中期老怪很可能就是为杀他而来。
- 结论：绿魔洲此行两大目的——轰开天牛第三穴 + 杀王林；计划必定周密，不给他丝毫避开机会。
- 决意：要在危机中保命并反击，**必须以最快速度、不择手段让自己强大起来**。他已很久没有如此，唯有不断的生死危机方能让他在两千多年间成长至今日程度。
- 听到周姓老者宣布由吕文冉穿魂铠时，王林双眼露出奇异之芒——他不信真有危险吕文冉会主动去穿，断定此事**必存在其他好处**。
- 全程**没有轻举妄动，选择等下去**。吕文冉扫视大地时内心兴奋，只下意识扫过四周洞府，并未留意王林。

## 七、召唤天牛之魂的仪式步骤

1. **第一步·血印引魂**：周姓老者咬破舌尖喷血，右手抓血捏成血色印决，念咒「**天牛圣魂，以吾之血，引魂归兮**」，印记爆发无尽赤芒笼罩整个地宫。
2. **第二步·献修为开漩涡**：一千余修士盘膝散尽全部修为之力，层层波纹扩散、被血芒吸走，众人痛苦萎靡；血光倒卷凝于印决，天地间出现灰蒙雾气，以血色印记为中心在地宫上方缭绕，形成巨大漩涡并越转越快。漩涡深处似通往一个**奇异空间**（天牛封印所在），传出带着滔天怨气的疯狂嘶吼。
3. **天牛之吼**：吼声一出地宫剧震，一千余修士心神被冲，齐齐喷血、面色苍白萎靡；炎栾等人亦面色大变。吕文冉狂笑，贪婪毕露。**王林称这个吼声他并不陌生。**
4. **第三步·九两九钱血**：周姓老者要求每人取 **九两九钱** 鲜血，不能多不能少，速速凝于右手食指。（片段止于此）

## 八、伏笔与待续

- 王林对天牛之吼「不陌生」——暗示其与天牛/天外之兽有既往渊源。
- 吕文冉独占魂铠的真实图谋、以及王林是否会出手截取，悬而未决。
- 张道宗的封印天地之能与那四名空劫中期老怪的针对性追杀，是王林接下来的核心危机。

# 第1871-1873章 天牛魂铠之争

## 一、请魂：血链拽出天牛魂

- 地宫下方一千余名修士按周姓老者要求，齐齐挤出鲜血化作血箭，汇聚成一条**血色链子**，一端深入漩涡内的奇异空间，猛力向外拽拉。
- 天牛之吼回荡，链子似要把其内天牛的魂生生锁出。吕文冉舔唇狂喜，自陈『有了这天牛魂铠，我就可以杀出这里，虽说时间短暂，但这魂铠……我绝不会轻易还回去』。
- 血链渐渐拽不动。周姓老者被迫拍开眉心，**元神飞出**抓住血链；在吕文冉威胁的目光下，三名来自极天草原附近宗门的**空劫初期**修士无奈跟进；炎栾与许东德最后暗叹出神。
- **五位空劫大尊**以周姓老者气息为引齐力一拽，天牛发出惊天嘶吼，巨大天牛虚影被拽出、急速收缩，化作一套**幽色魂铠**，散发浓烈灵魂气息，悬浮漩涡之上。

## 二、抢位：王林以言辞逼停吕文冉

- 吕文冉大笑迈步欲取，王林以蓄势已久的**缩地成寸**自洞府长虹而出，抢先挡在魂铠前：『魂铠归你，我不同意』。
- 吕文冉杀机毕露——他早前逃回大地时已见王林，故意在自己进入后封闭大地，本欲借刀杀人；此刻见王林未死且来搅局，不再掩饰。
- 王林不闪不避，朗声反将：自己同为**大魂门长老**、青牛老祖指派镇守此地之人，众目睽睽之下若被伤，吕文冉将背『战争中残杀同门』之名，遭大魂门追杀、青牛老祖之怒，在天牛洲再无立身之地。
- 吕文冉权衡后收手，改口称『误以为有奸细混入』，认错下台，转而倒打一耙，质问王林是否为一己私利、有无资格独占魂铠。
- 王林背靠魂铠试探，**毫无融合迹象**；吕文冉点破：魂铠尚未走完最后一步，故不能融合。

## 三、表态：炎栾、许东德支持王林

- **炎栾**率先开口『我认为王长老有资格』，不惧吕文冉阴冷警告。
- **许东德**随即附和（其动机是不喜吕文冉过于做作）。两位空劫大尊、且同为大魂门长老的表态令全场哗然。
- 三名附近宗门的空劫修士两边都不愿得罪，选择沉默；下方修士在吕文冉目光扫过时纷纷低头。

## 四、亮牌：两颗头颅与一缕鬼魂

1. **第一颗头颅——刘之源**：王林翻手取出绿魔洲空劫修士刘之源的人头，平淡道『我杀了他』。绿魔洲空劫修士之死此前是天牛洲修士间的悬案，全场骇然：『他的修为明显不到空玄，居然能杀空劫』。
2. **吕文冉的污蔑**：为独占魂铠（融合最后一步需绝大多数修士的意念认同），吕文冉声称亲眼见一位修为莫测的前辈出手杀人、抛尸而去，指王林砍头冒功、『侮辱近万英魂』，一度让舆论倒转，不少修士对王林露出鄙夷。
3. **第二颗头颅——许德才**：王林再挥手取出绿魔洲空劫初期大尊许德才的头颅，狼狈黯淡、七窍有干枯褐色血痕。许德才在绿魔洲声名赫赫、施法速度极快，连吕文冉也早有耳闻并在第一战中认出过他。三名空劫修士豁然起身，炎栾、许东德心神剧震，许东德对王林**第一次生出深深忌惮**；周姓老者忆起自己曾毁掉王林洞府大门、言辞不敬，冷汗淋漓。
4. **鬼魂佐证**：王林左手掌心浮出**许德才的鬼魂**，凄厉嘶吼。吕文冉此前笃定刘之源元神已崩溃、对方绝无元神可证，此刻所有说辞不攻自破，面色苍白、踉跄退后、哑口无言。

## 五、转折：意念选择与吕文冉暴起

- 王林当即催促周姓老者进入融合步骤。老者留了心思，只宣布规则而不指名：**由众修士的意念选择归属，绝大部分人选谁，铠甲便融于谁身**。
- 人群中一位极天草原**苍发老者**公开表态：『那王长老曾与我有救命之恩，老夫希望你们选择他』，影响一批极天草原修士。
- 吕文冉自忖若魂铠归王林、以二人积怨自己必被打压，遂豁出去，怒喝『大胆贼子，你冒充功劳，侮辱英魂，此事该杀』，暴起袭杀王林，盘算『他只要一死，就无法与我争夺魂铠』，大不了战后回宗受罚。
- 王林早有堤防，在其起身刹那即向后急退，右手抬起——体内**速神决**所成的**第一条神脉漩涡**急速旋转，赋予其极快施法速度。
- 与此同时，魂铠幽光大盛，下方一千余修士已在王林与吕文冉之间快速显露意志作出选择。
- **炎栾**银牙一咬直奔吕文冉，以行动押注王林；**许东德**略一犹豫亦同时出手。

## 六、关键点

- 王林由『始终低调、几乎被人遗忘的第四位大魂门长老』转为公开嚣张，是本段的身份转折点。
- 王林的核心筹码不是修为而是**证据 + 规则**：头颅与鬼魂证明战功，大魂门门规与青牛老祖之威压制吕文冉出手。
- 魂铠的归属机制（众修士意念投票）使舆论战成为胜负手，也解释了吕文冉为何必须污蔑而非硬夺。
