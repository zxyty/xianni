# 第1278章 一百拳（第九卷 云海之巅·第二更）

## 一、肉身重生
- 妖异红芒弥漫王林全身，源自被他融入元神的血液（血球）。肉身崩溃的王林借此力在片刻间重新凝聚身体。
- 王林清晰感受到：血球之力随此番身体重生正急速消散，用不了多久便会彻底消失。
- 他已不在意，疯狂意念充斥全身，死死盯住水道子冲出。

## 二、七星古神之躯与「灭生唤灵」
- 冲出中其身再化数百丈古神肉身，眉心六个星点旋转，更有意境所化规则之星转动，一眼看去好似**七星古神**。
- 疯狂气息散出，如同吞噬了无数升仙果；心念只有「不能死，要杀尽眼前一切生灵，不惜代价」。
- 咆哮如太古凶灵，右手握拳，口中传出复杂的**古神之语**。
- **古神术·灭生唤灵**：古神一族神通不多，但每一个都非修士可以理解；此术引爆体内磅礴生机（世间生灵生机无可与古神相比者），生机疯狂消散化作力量蕴于拳中。

## 四、关键转折
1. **决心之悟**：雾气临身欲吞噬的刹那，黯淡双眼骤爆精光——「我辈修士，何惜一战」；他明白此战并非战意，而是**明知必死仍要反抗的决心**（飞蛾扑火并非向往火焰，而是要扑灭火焰的绝心）。
2. **生平自述**：十六岁修道 → 入恒岳杀藤厉 → 逃修魔海结成金丹 → 成元婴、灭藤家满族、震朱雀、拜天运 → 阴阳虚实、碎涅三境，一生危机不屈天地，杀人无数，修道两千年至今日程度。
3. **生机真相**：早在第二十三拳，其生机就已消散，其后各拳全靠元神内融合的血球之威。
4. **流月逆转**：「生机断绝，我之将死，但这神通之拳，并未结束——流月之光，给我逆转五千年，给我五千年生机」。星空虚无化作大海，其上高大石门轰然耸立，万古苍凉逆转笼罩王林。

## 五、水道子一方
- 其**全部修为都在对抗眉心的七彩神空钉**（源自掌尊），分出对付王林的力量不多。
- 七彩钉旋转已无法冲破其头骨，但钻心之痛不断；他判断该钉太过诡异，所幸王林不知具体施展方法，仍需防其变化，遂爆发全部修为要将钉入一寸的钉子逼出。
- 论断：以生机换力乃**饮鸩止渴**；十九拳已是王林极限；不需他动手，王林片刻后也会自己消亡。
- 亦承认：**若王林能维持百拳以上的全力一击，倒有可能在其对抗七彩之钉时伤到他**——这恰是王林随后打满一百拳的伏笔。
- 眼中露出罕见凝重，第一次感觉到王林的惊艳不凡。

## 六、结局
王林在短短时间内消耗**全部血球之力**与**体内所有元力**（化作流月之术逆转五千年），打出了一百拳。文末定评：**这是王林此生最强的一百拳，这是他的一生。**
