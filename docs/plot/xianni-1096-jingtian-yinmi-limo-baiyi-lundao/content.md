# 第八卷 联盟隐秘 · 第1096章 惊天隐秘

## 一、玉简验尸：李莹芝的七日之约

- **场景**：朱雀圣宗大殿，王林以圣皇身份接见尸阴宗妖艳女子 **李莹芝**，闲适饮茶。
- **李莹芝的判词**：她斟酌半晌、强压震撼后表示——玉简中「此尸只是圣皇尊下神识烙印所化」，因未见真正尸身，无法定夺。心神中却仍不断浮现玉简内那具尸体，怦然心动。
- **王林的态度**：淡然表示「作罢就是，此尸王某本就没报太大希望，知与不知，无关大雅」。
- **关键确认**：李莹芝追问先前给 **烈云子** 的玉简是否同一物，王林答「没错」。
- **心机识破**：李莹芝看出玉简显然事先准备好、先送烈云子后送自己，绝非简单，定有深意。
- **结果**：她请求 **七日** 时间给出答复，并称怕是无法出席圣皇登基大典，先行告辞，化作长虹疾驰而去。
- **王林的说辞**：此尸系「无意中发现、无法取回」，故请李道友代为辨认。

### 王林的真实意图（内心）

> 「鱼饵已经放出，就看罗天与尸阴宗，是否会动心了。」——王林随后断定：**他们，一定会动心。**

即：玉简分送烈云子、李莹芝二人，是同一局中的双线诱饵，目标是撬动 **罗天** 与 **尸阴宗** 两方。

## 二、卸甲换白衣：与墨智的第三次重逢

- 王林转头看向 **墨智**，微笑起身，**全身铠甲连同披风立刻消失，换作一身白衣**，抱拳称「墨兄，多年未见，风采依旧」。
- 墨智感慨：「怕是有快千年没见了。」
- 二人一前一后踏出大殿，转往 **朱雀圣宗主星** 上、王林此前吐纳数日的 **火山口** 旁（虚空扭曲、一步踏出）。
- 王林拍储物袋取出两瓶酒，扔一瓶给墨智，望着火山口冒出的黑烟对饮。

### 三次相遇的回溯

1. **雨夜古庙（当年）**：墨智时为 **修真联盟** 一员，在师尊特意要求下被派往 **朱雀星** 驻扎；雨夜心有感悟外出行走，遇到王林，以「雨生于天，死于地，中间流淌的过程，就是人生」点悟其 **生死意境**。墨智谦称即便无他点化，王林日后也会自行明悟；王林摇头不认——「懂就是懂了，不懂则总隔一层窗纸」。
2. **朱雀墓中（第二次）**：墨智本想让王林成为 **朱雀星之主**，却「小看了王兄的雄志」。
3. **本章（第三次）**：王林已成 **朱雀圣宗圣皇**，墨智由衷高兴。

### 论道要点：意境与心境

- 墨智判断：王林 **生死意境已然圆满**，但其眼下的意境变化，墨智已看不透。
- 转述师门之言：**「这天下间一切意境，均与心境有关，心之所动，往往就是意之变化。」** ——作为对王林的启示。

## 三、收束

- 论道至 **清晨**，墨智告辞离去。
- 墨智 **未留下出席王林的登基仪式**，而是带着王林送出的 **四枚玉简** 以及 **嘱托之事**，远远离去。

## 四、待解伏笔

- 李莹芝七日内的答复、罗天与尸阴宗是否咬饵。

- 王林登基大典尚未举行；烈云子、李莹芝均已表态或实际缺席。

# 第1014章 鲁云托孤与四圣宗根源之秘

## 一、玉简外送与登基大典

- **四枚玉简**：内中所记之事足以震惊整个联盟星域。墨智要尽快交给其师尊，并送给其余三方联盟势力。
- **出云国的规避**：在王林的隐晦暗示下，墨智心中有了明悟与猜测，不会让其师尊参与进来。
- **登基**：送走墨智后数日陆续有人前来恭贺，王林不再亲自接见。登基大典之日，整个朱雀圣宗洋溢热闹，其余三圣宗长老与族人前来见证新圣皇登基。仪式繁琐但为传统，历时一整天完成后，三宗之人渐次告辞，朱雀圣宗恢复平静。
- **备战**：族人潜心修炼；众长老纷纷知晓救青龙圣皇之事，选择闭关吐纳，保持修为处于巅峰——因救青龙圣皇之事极为重要。

## 二、燃烧星域边缘的告别

王林出现在朱雀圣宗所在那一片**燃烧的星域**边缘，前方漂浮着一个元神——形貌为中年男子，望着王林神色慈祥满意。王林全程沉默。

### 鲁云的评价与交代

- **认可**："你虽非我见过天资最高的族人，但却是我最满意的，把朱雀圣宗交付你，我很放心。"若再给数甲子，他有信心让王林**完全传承**。
- **此行凶险**："我此番去联盟总部，怕是再也无法回来"，但**雨界仙晶**哪怕付出一切代价也要拿到。
- **元神分配**：九成元神分出，将去一一吸收当年散出的分身；肉身所在之处留有**一成元神**。取得仙晶后，会以元神秘法把雨界仙晶传送至肉身分神之处交给王林。
- **对青龙圣皇的指示**："能救则救，若是勉强，要以自身为重。"
- **肉身的用途**（后事嘱托）：
  1. 肉身有**白火石**在，三千年内不会腐烂，其内存有鲁云一生所修**火元**；
  2. 王林需**每隔一百年**在其肉身处修炼、吸收其中元力，对修为帮助极大；
  3. 若有生死存亡之危机，不必顾虑其亡魂，可以**九玄变**引爆其肉身，让王林或朱雀圣宗度过一次危机。
- **承诺**："你师兄**清水**的消息，老夫此番也会为你打探出来。"
- **临别**：抬右手放在王林天灵之上，轻声道"把这么一副残局放在你的身上，你，不要怨我"，留恋地看了一眼四周燃烧的星域与远处修真星上的朱雀圣宗，转身走向远处，身影带着无数万年压力下释放的洒脱。

## 四、惊天之秘：四圣宗的根源与归乡之路

就在成为五代圣皇之时，鲁云知晓了有关四圣宗的惊天之秘：

1. **四圣宗并非这封界之人**，而是在悠久岁月之前，自**界外**来到此界。
2. 包括朱雀圣宗在内的四圣宗**第一代圣皇与族人**，最早出现在**远古仙域尚存、四大仙界未分之时**的一颗小小的**修真星**内。
3. 那颗修真星是四圣宗的**根源**，也是**通往家乡的道路**。此星始终掌握在**朱雀圣宗**手中，其余三宗对此并无不同意见——因知晓此事者不多。
4. **最深的隐秘**：早在第一代圣皇之时，此事已是四圣宗内最深隐秘；**仙帝青霖也不知晓半点**。
5. **双重掩藏**：四大圣皇占据**昆虚星域**时，另开辟出众多与其相似之星以混淆，几乎无人能认出哪一个才是那颗**原始之星**；此外第一代四大圣皇更出手展开**隐匿的手段**，可保此星永久不被真正完全发现。

## 五、伏笔：仙界异象

此后数千年，仙界出现奇异之相——在那一刹那，整个天地所有生灵**全部有了刹那间的迷茫**，仿若被隔绝了一切感应，处于混沌之中。（叙述在此中断，为后续埋线。）
