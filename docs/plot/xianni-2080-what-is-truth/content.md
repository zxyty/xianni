# 第2080章 什么是真相

## 一、木冰眉之别：分身还是本体

- 木冰眉离开洞府、离开朱雀星，但并非独行——身边有一名**白发白衣、相貌寻常却气质温和**的男子，如梦道中那一次轮回般一直牵着她的手不松开。
- 木冰眉曾在天空中问：「你是分身，还是本体」。男子答：**「我是王林，我在你的身边。」** 木冰眉展颜微笑。
- 二人化虹远去时，大地上另一处，**王林站在那里望着他们远去，脸上露出微笑**。
- 文本明言：随木冰眉离去的或许是分身、留下的才是本体，也**或许恰恰相反**——「没有答案」，答案只有王林知晓。

## 二、十三独飞

- 十三一生都在追寻王林的脚步，此番王林让他独自去飞：鸟儿长大了要独自面对风雨，在风雨中看彩虹，才能成长为顶天立地之人。
- 此后十三曾数次回山谷，每次陪王林数月又再离去，继续自己的人生与修道。

## 三、山谷守婉：七十年与二百年

- 众人皆走，唯王林留在朱雀星。他再次祭拜父母（与柳眉入梦前已祭拜过一次），随后回到**当年与李慕婉居住、已被他恢复如初的山谷**。
- 在山谷中与李慕婉相伴，抱着她「一起数着轮回」，种花草，看春生夏雨秋风冬雪，耳边似有琴音回绕，如回到数千年前。
- **十年、十年、十年……王林在此居住了七十年**：不考虑修为、不考虑本源感悟、不考虑阴谋诡计与人生曲折，眼中只有李慕婉。

## 四、墨智来访：酒、劝、与定界罗盘

- **回到洞府界的第二百年**，一个光头男子提酒来访，相貌与当年毫无变化——**正是当年雨夜庙宇中对王林说出「心亡则忘」的墨智**。
- 对话要点：
  - 墨智：「忘不掉么」→ 王林：「**从没有想去忘，何来忘不掉。**」
  - 墨智：「你这是在折磨自己」「放弃吧，你不会成功的，这样下去，婉儿也累」。
  - 王林问该称其「墨智」还是别的名字 → 墨智：「**墨智，我一直都是这个名字。**」
  - 墨智欲将「这一切的答案」全部告知 → 王林拒绝：「**不要说，有些事情，让我自己去思索。**」转而邀其喝酒。
  - 二人对饮至天明，未再说一句话。
- 墨智临行背对王林留话：「**师尊让我问你，这逆尘量界的定界罗盘，你何时归还**」——王林不闻不问，照旧盘膝饮酒。

## 五、王林的判断：「你们，都错了」

- 王林早已明白一些事：**墨智、红蝶、墨智的师尊，甚至天运子，都认为洞府界、仙罡大陆乃至天地万物皆是虚幻**，是王林一次轮回梦道所化。
- 王林的反诘与自我确认：
  - 「只是，真的是这个样子么」——「**你们，都错了**」。
  - 「**我，就是我**」：他叫王林，出生在朱雀星的赵国、一个木匠家庭、在小山村长大，一步一步踏上修仙路走到今日。
  - **复活李慕婉是他自己的决定**，不是被某个意识、某次轮回干扰后的抉择。
- 天运子之谜：王林明言「天运子，你真的以为，我不知道你的来历么」。他隐约看到——**仙罡大陆之外的无边黑暗中，一个黑衣、极长黑发、带着毁灭与杀戮气息的身影，正朝仙罡大陆遥遥走来**。
- 王林立誓：**答案不是在太古神境里由天运子告诉他，而是他去那里告诉天运子，什么才是真正的真相**。
- 王林甩袖取出**吉穷的头骨**，其上一行小字一闪即逝。

## 六、复活之法：始古祖庙已经开始

- 王林对沉睡的李慕婉说：「**婉儿，你会醒来，因为我已经知道了真正的方法，且在始古的祖庙内，我已经开始了。**」
- 王林目中露出疯狂之色——文本评价：这个方法**的确极为疯狂**。

## 七、许立国三人组的洞府界传奇

- 许立国与刘金彪不知用了什么方法找到了**钟大洪**，三人配合在洞府界叱咤风云。
- 因三人**转世后的身体生长于仙罡大陆**，可通过**洞府大门**借王林之力随意进出；钟大洪亦得王林之助同样可行。
- 横扫洞府界后，三人连同一条同样爱上此道的**海龙（金尊海龙）**离开洞府界，赴仙罡大陆开始传奇经历。
- 临行前三人到王林处殷勤伺候、极尽阿谀，王林好笑之下**在他们身上留下自身气息与印记**保其平安；有王林这张虎皮加金尊海龙战力，三人自信可「行骗仙罡如入无人之境」。

## 八、启程：最后一站太古神境

- **许立国三人离去的第六十年**，王林带着李慕婉走出山谷、走出朱雀星、走出洞府界，前往仙罡大陆。
- 临走前神识所见：仙界修士正消化他留下的**道统**；看到十三，看到很多故人；最后看了一眼洞府界。
- **距仙罡大陆太古神境开启还有三个月**，那里将是**王林的最后一站**。
- 临别誓言：「**从太古神境走出时，婉儿，你会陪着我一起**」——一步迈出，踏入洞府界大门，消失无影。

## 九、悬念与伏笔

1. 随木冰眉离去者与留守者，孰为本体孰为分身——书中不予作答。
2. 逆尘量界「定界罗盘」的归还之问，指向墨智师尊一线的后续追索。
3. 「万物虚幻/梦道所化」之说被王林当面否定，真相待太古神境揭晓。
4. 黑衣长发、毁灭杀戮气息的身影正逼近仙罡大陆，与天运子来历相关。
5. 吉穷头骨上一闪而逝的小字。
6. 始古祖庙内已启动的疯狂复活之法。
