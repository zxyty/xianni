# 第七卷 名震罗天 · 第663章 孙老

## 一、伪仙宝的炼成

王林挥手，三件法宝化作晶光落于掌心，缓缓转动、光芒炫丽。

- **定名**：王林轻声称之为「**伪仙宝**」。
- **品阶**：比不上真正仙宝，甚至连下品都达不到。
- **特性**：
  1. 同样可用**仙力**驱使，并引出其上蕴含的**意境神通**；
  2. 即便无仙力，**婴变期以下**修士以自身灵力也可驱使，只是威力弱很多。
- **炼制底气**：王林对炼器只是粗略了解，所学大都来自**当年朱雀星火焚国的炼器玉简**。按说不该炼出此等法宝，之所以能成，靠三点——**自身道念**、**问鼎期修为**，尤其是**对禁制的掌握**。

王林对这三件法宝**并不满意**。

## 二、「伪传承」的推衍

### 传承之宝的设定

| 类型 | 机制 | 后果 |
|---|---|---|
| 寻常法宝 | 仅在其上印下神识，使用者操控自如 | 一旦被抢走，抹去神识便成对方之物 |
| 传承之宝 | 除自身神识外，还须有**传承之法诀** | 外人得到也无法操控，价值**远高于同阶** |

王林的**十亿尊魂幡**、**射神车**即属此类。但传承之宝的炼制法门唯有**炼器大宗师**才有，轻易不外传、不炼制，故世间罕见。

### 变通方案

王林闭目推衍，参悟传承不透，遂转念：

> 不去琢磨如何传承，而是给法宝加一道**特殊封印**，再把**打开封印的印诀**放在玉简内一同卖出。

虽非真正传承，却有传承之效。**重点在封印之强**——若强到无人可破，便等同真传承。

### 施为过程

1. 眼中禁制推衍之芒流转，左手掐诀，连续打出多道禁制落于**铜镜**；
2. 诸禁制相互组合，形成**闪烁黑芒的复杂符文**；
3. 目光落在房内**烛台**，一指点燃，趁烟丝将被屋顶珠子吸去时大手一抓取来，按在符文上；
4. 符文诡异融化，化作一缕**黑色烟丝**钻入铜镜；
5. 取出玉简，心神一动将**破解禁制的印诀**留于其内。

> 只在铜镜上设置伪传承，**其余两件法宝未设**。

随后天色渐亮，王林闭目打坐。

## 三、山石下的青年：轻蔑与指路

初阳驱散黑暗，天地灵力在清晨极为浓郁。王林出门，路过出口处山石下的青年——对方仍在打坐吐纳吸收精华。

- 青年目露轻蔑，认为外来修士来此无不整日吐纳抢灵气；断言王林**资质寻常又放弃清晨最浓一刻**，「他这一生，必定无法结婴」。
- 王林原打算去**城西自由坊市**（有修士交易法宝材料），但判断「此等坊市内婴变以上修士并不多见，不是最好的出售之地」。
- 遂折返向青年抱拳请教高阶法宝交换之地，青年翻眼皮、不耐冷声：「**城东宝合楼**」。
- 王林微笑离去后，青年冷笑：「小小结丹修士……那宝合楼，此人怕是连门槛都没资格踏入」，随即吐纳更急，仿佛灵力是从别人处抢来。

## 四、城东：灵石与店铺

王林出城北，向城东而行。城东凡人不多，多是修士往来，商铺大气、雕栏玉砌。

- **习俗**：铺外摆放**未炼化的巨大原灵石**，灵气浓郁四散，直白地宣示店铺实力——能从灵脉挖出这等灵石，寻常修士根本做不到。
- 灵石大小与店铺相关，有的高约两丈如小山，望之威严压身。
- **青竹阁**：二层小铺，无磅礴大气却极为典雅，牌匾龙飞凤舞；门外原灵石**品质为上品**，令王林起了兴趣，但他未入内。
- **宝合楼**：位于城东尽头，浑然天成的巨大阁楼，与四周融合、略显虚无缥缈；门外**八块三丈大小的上品原灵石**摆如阵法，灵威浓浓；匾为长条灵石刻「宝合楼」三字。楼内另有一层**隐藏防护阻止神识探入**，王林未强行探查，且对宝合楼「没有太大兴趣」。

## 五、宝合楼门前受阻

王林踏入即被一名中年男子（**卢峰**）拦下。卢峰见惯修士，惊讶于王林在宝合楼阵法威压下竟能如此镇定——除少数修为高深的老怪外罕有。

**宝合楼规矩「二不进一不出」**：

1. 修为低于**元婴**者，不进；
2. 无**十万上品灵石**者，不进；
3. 无交易所得者，不出。

王林眉头微皱——其储物袋内灵石并不多，因**自化神后便以仙玉为主**。卢峰笑称其不合规矩，即便进去也无法满足出来的条件，请回。

王林一拍储物袋取出所炼**飞剑**问「此宝，你们可收」。卢峰一扫便露嘲笑：手段极为低劣、并无出奇之处、剑光黯淡，不必神识、肉眼即可断定连下品法宝都不是；他已将王林归入「自以为有好法宝便来宝合楼交易的低阶修士」一类，遂摇头：「不收，请回」。

## 六、转折：一眼与孙老登场

王林冷冷看了卢峰一眼便转身离去。那一眼落入卢峰目中，如**冷水灌顶**、如**万年寒冰**，其**元婴为之一顿，几乎崩溃**；卢峰蹬蹬后退数步，面色苍白，怔望背影说不出话，内心隐约觉得那飞剑**似乎有些不同寻常**。

此时楼内传来苍老声音：「卢峰，怎么了」——卢峰躬身回禀有修士来售法宝。楼内走出一名**驼背、极为苍老、脸上满是岁月痕迹、双眼无太多神采**的老者（**孙老**），平淡问：「什么法宝」。

**本章至此结束**（作者附注：下一章要晚一些）。

## 七、要点与伏笔

- 王林当前对外呈现的修为被外人判读为「结丹」（青年语），实为**问鼎期**，属刻意收敛。
- 伪仙宝＋伪传承是王林在罗天筹措资源的手段，铜镜是唯一带伪传承的样品。
- 卢峰误判飞剑劣质，而孙老出场问询，为下章飞剑真价值被识破埋下伏笔。
