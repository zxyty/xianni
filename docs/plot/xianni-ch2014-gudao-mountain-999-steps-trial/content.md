# 第2014章 千载难逢！

## 一、古道山石台规则

- 石台共 **九百九十九阶**，每一百阶对应古道大天尊修为之一成。
- 古道大天尊自陈：古往今来所有大天尊中，**从未有人能在其意志下踏上第六百阶**。
- 历史最高纪录：来自 **仙族** 的大天尊 **东临**，止步于第六百阶失败，**留下一样东西**后被古道大天尊准许离开。
- 层级门槛：仙族的 **天尊**、**跃天尊** 都踏不上古道山，**唯有大天尊才可**。

## 二、王林登阶经过

### 第一百阶 —— 黑蛟龙

- 王林脚落第一百阶刹那，冷漠沧桑之声（古道大天尊）响起，宣告要看他能走多少阶。
- 通往山顶的台阶显形化作一头 **通体漆黑的真蛟龙**，卷狂风、带腥臭恶臭扑杀而来。
- 王林面色苍白却不退，虚空一抓，身后 **大天尊之阳轮廓缩小**，黑白光芒凝于右手：**掌心为白、掌背为黑**，一掌按下。
- 蛟龙头部崩溃并蔓延全身，化作飞灰消散；台阶恢复如常，如同幻觉。
- 代价：王林喷出一口鲜血，**右手随之溃散消失**，旋即在黑气缭绕下重生新臂；反震之力如无数山峰轰击，右脚被迫抬起欲落回第九十九阶。
- 关键：王林嘶吼中凭 **古族肉身** 硬抗，右脚猛然改向，**踏上第一百阶**。
- 收获：踏上百阶后，体内 **仙力与古族之力初现融合迹象**。

### 一百至二百阶 —— 燃烧大天尊之阳

- 百阶之后威压 **暴增一倍**，王林在 **第一百五十阶** 身躯颤抖、被迫停步。
- 王林主动令身后 **大天尊之阳轮廓急速收缩**，化作力量融入体内，连破 160/170/180/190 阶。
- 在大天尊之阳轮廓 **缩小到极限、完全消失** 的同时，王林踏上 **第二百阶**。
- 山顶迷雾身影轻咦；玄罗第一次露出微笑。迷雾身影评价：「燃烧大天尊之阳换取踏上第二百阶的力气，倒也是一种方法，只是最后的这一百阶，他又如何走过。」

### 灰衣人一指

- 高塔四周四根巨柱各有一盘膝 **灰衣人**；王林立于二百阶时，**北方柱** 上者睁眼（目内灰芒），瞬移至台阶。
- 其人面无表情如戴人皮面具，抬手 **一指** 点向王林眉心，苍穹如破窟窿、大地颤抖、古道山震动；王林判断 **此指堪比大天尊**，若被点中，纵有古族之身也必形神俱灭。
- 王林反击：
  1. 引爆自 150→200 阶间吸收的全部大天尊之阳之力；
  2. 修为运转、**本源显露**，化出 **九十九道虚影**；
  3. 身后浮现 **道古虚影**——古神、古妖、古魔齐齐轰拳；
  4. 道古虚影上空另现 **一尊模糊金色光影**，散发精纯仙气并与古族之力缭绕，同样成拳；
  5. 周身黑气透出杀戮与疯狂，更有雷霆，形成 **杀戮雷霆之拳**。
- 结果：灰衣人 **指尖崩溃**，身形一晃却未移动，**深意地看了王林一眼** 后返回北方柱盘膝闭目。王林嘴角喷血、虚影尽散，但 **站稳在第二百阶**。
- 此战后，王林明确感到体内 **古族之力与仙力在古道山威压下被强行凝聚、缓慢融合**。

## 三、玄罗求情

- 山顶高塔顶层，玄罗目露心痛，已下决断：**一旦王林失败，宁可冒犯古道大天尊也要带走他**（「他是我带来的，是为了我来到古族」）。
- 迷雾中身影冷言断定王林「走不过二百阶」，要玄罗留下这个弟子。
- 王林登上二百阶后，玄罗化长虹落于王林身旁，抬头一字一字恳求：自己 **一生为道古一脉、万古无怨、从未考虑个人得失**，今日只求带走弟子。
- 古道大天尊语气缓和，揭出旧事：**玄罗刚成为大天尊时，古道大天尊曾提出收其为弟子、随住古道山，玄罗因要守护道古一脉而拒绝**。
- 裁定：「这是你第一次恳求，本尊应允，**但这也是最后一次**。」玄罗神色复杂，向山顶高塔一拜，欲带走虚弱的王林。

## 四、王林执意续攀 —— 千载难逢的契机

- 王林站直身体拒绝离开：「师尊，这古道山台阶的威压，是弟子最好的修炼之地。」一拜后转身踏向 **第二百零一阶**，身体立传不堪承受之声，双目却极明亮。
- 其内心推演：
  - **古族之力因血脉而存在**；
  - **仙族修为因本源而存在**；
  - 二者格格不入，只能在体内分散；
  - **当年在洞府界曾试图融合，失败**。
- 判断：**古道大天尊是仙罡如今的第一人**，其威压是促成 **仙古融合** 的最佳助力，此契机 **千载难逢**。

## 五、悬念与后续看点

- 王林已具 **初步的大天尊之力**；古道大天尊点名要看他能否走上 **第三百阶**。
- **东临留下的那样东西** 是什么，未交代。
- 高塔四柱四灰衣人身份不明（王林亦不知其为谁），仅北方柱者出手。
- 那尊 **散发精纯仙气的金色光影** 来历未明，是仙古融合的重要线索。
