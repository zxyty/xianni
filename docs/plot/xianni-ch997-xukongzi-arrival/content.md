# 第八卷 联盟隐秘 第997章 虚空子（段1/2）

## 一、涂司三叉戟的来历（王林所继承的记忆）

- 这件三叉戟法宝当年是**涂司**极为满意的一件法器，唯一缺憾是**没有凝聚出器灵**。
- 为求完美，涂司把此物抛在一颗星球上，**化作三座山峰**，意图以**整个星球的山魂**为之凝聚宝魂。
- 涂司本准备待「王族神通分化而成」之后再来取宝，但**这一去再没有回来**。
- 王林目睹三叉戟随**天运子**进入黑洞，眼中露出惆怅——此惆怅源自**记忆中涂司的遗憾**，而非王林本人。

## 二、黑洞前的中断

- 凌天候与紫袍男子同时化作长虹直奔黑洞，旋即身子一顿。
- 王林正欲进入黑洞时猛地转身望向星空；葫芦上的老者与司徒南等人反应更快，先一步看向远处。
- 远处星空波纹扭曲，一名老者身影瞬息幻化而出，一步便至近前。

## 三、虚空子登场

### 身份确认
- 紫袍男子躬身：「**孙善**参见大长老。」——由此确认紫袍男子名为孙善。
- 孙善**虽为长老，却非联盟长老团成员**；其恭敬发自肺腑，毫无作假。
- 凌天候同样恭敬：「晚辈参见大长老」，其性格中能令他恭敬者极少。
- 章末凌天候直呼其名号：「多谢**虚空子**前辈。」

### 修为与气息
- 来临时所施展神通为**融入天地之间**。
- 王林感到其气息令己心惊，与天运子截然不同：
  - 天运子 ≈ 深不可测的**大海**；
  - 虚空子 ≈ 开天辟地直冲九霄的**巨大山峰**。
- 磅礴气势弥漫下，四周修为低弱者纷纷面色大变，不少人直接喷血后退。
- **司徒南**（此处为司徒南的断臂所化人影，自第336章起自称司徒南，真伪未定）目光一闪，喃喃道出其境界：「**碎涅**」，随后内心冷笑，桀骜之气尽显：「若想在这修真界好好地快活下去，就必须要有压过天地的修为，碎涅——老子以前还是太懒惰了。」

### 外貌
- 一身**金袍**，头发**半黑半白**，弥漫一股沧桑。神色平静。

## 四、虚空子与凌天候、天运子的旧事

- 虚空子看向凌天候，露出赞赏微笑：「你我有多长时间没见了。」
- 凌天候追忆感慨：「晚辈已经记不清，太久太久了。」
- 虚空子长叹道出关键往事：
  - **当年凌天候与天运子同时获得资格**，由虚空子**亲自送入昆虚圣地**；
  - **一晃数万年**：天运子已成为**联盟长老**，连虚空子「也有些忌惮」；凌天候修为亦达到「这种程度」。
- **数月前**凌天候以玉简相邀，虚空子本不想来：
  - **罗天那里战事吃紧**；
  - 其**师兄重玄子**又无法分身。
- 但想到凌天候与天运子之间的事情，虚空子仍决定来一次，「**终结了你二人之间的往事**」，目中透出果断与深意。

## 五、要点提示

- 本章首次点出**碎涅**这一境界层级（高于天运子所处层次的压制感）。
- 首次出现人物：**虚空子**（联盟大长老）、**重玄子**（虚空子师兄）；**孙善**为此前紫袍男子的姓名坐实。
- **昆虚圣地**作为数万年前授予「资格」的地点被提及，是凌天候与天运子共同的渊源。
- **罗天**（罗天星域）战事吃紧，与联盟当前局势呼应。

## 一、妖灵之门·入界名单与黑洞闭合

### 先后入洞顺序
1. **大袖老者**（自称“这妖灵之地老夫只是听说，还尚未来过”，应即夕萱所言的“虚空子前辈”）——入洞前特意看向村姑般的中年美妇及其身边粉衣女子，目露善意，随后直接走入黑洞。
2. **剑尊凌天候** 与 **紫袍男子** 左右跟随，踏入漩涡。
3. **王林** 沉默片刻、目光闪烁后，与 **司徒南** 同时起步；**浮风子** 与 **银衣女子** 跟随，**尘道三子** 及 **大头** 在后。
4. **雷吉** 将身躯缩小成丈许大汉，迈步踏入。
5. **葫芦上盘膝的老者**、**冷傲的黑衣男子** 一晃进入黑洞。
6. **中年美妇（霞姨）** 犹豫后，带 **四名女子** 一同入洞，其中有 **夕萱**（粉衣女子）与 **千琴**。

### 关键对话
- 夕萱笑如盛开玫瑰，宽慰道：“霞姨放心就是，这妖灵之地，夕萱有大师姐送予的法宝，自保有余。更何况，二师姐不是让虚空子前辈来了么。”——透露其门中有大师姐、二师姐，且虚空子为其护道者。
- 千琴自王林现身起便一直望着他，得知将同入妖灵之地后暗叹：“不知他是否还记得我。”——**伏笔：千琴与王林为旧识**。

### 黑洞骤闭
- 众人之后，四周大量修士蜂拥而入，但仅一部分刚进入，黑洞旋转之速一顿，**由逆向旋转骤然改变**，刹那间消失无影。
- 半身处于黑洞内的修士**肉身当场崩溃**，惨叫绝响；后方修士急退。
- 黑洞带着血腥气息消失，如同关门，阻绝一切进入者。
- 遗憾者等候数日后放弃离去，**东海潮汐再度恢复宁静**（此次开启的入界机会就此关闭）。

## 二、妖灵之地·火妖郡的战后惨象

- 火红赤阳高挂长空，热浪随风顺地而动。
- 地面死尸累累、腐烂发臭，吸引众多**秃鹰般的妖灵**在死尸上吸收死气。
- 这只是火妖郡一角；放眼全郡“死尸如瓢”，热浪加速腐烂，风过掀动衣衫，露出发黑皮肤。
- 随着**炼魂部落**冲击，本就四分五裂的火妖郡大小势力接连崩溃，规则是“**若不降，便是亡**”。

## 三、火妖都城与火妖灵军

- 都城为**昔日古妖九灵之一所在**，如今被火妖郡残留的最后一股势力占据。
- 该势力名为 **火妖灵军**，数百年前曾是火妖郡众多军士中的精锐。
- 编制：**两位妖帅 + 八个妖将** 统领。
- 火妖郡当年战败后火妖灵军损失严重，但相较其他势力仍最为强大，占据都城，为**火妖郡残存的正统**。

## 四、炼魂部落围城逼降

- 火妖城外，炼魂部落大军密密麻麻全数包围；天空中无数族人漂浮，各自身边环绕数杆大幡，黑雾浓郁弥漫天地。
- 雾中鬼哭尖锐、魂魄凄厉尖啸化作风暴横扫大地，成为天地间唯一的声音。
- 火妖都城正门外，数个族人扛起一尊**巨大黑色石像（老祖石像）**，神色狂热——能从数百万族人中被选为扛像者，是天大的荣耀、一生的辉煌。
- 天空中一位**黑色长袍威严老者**，身周数十杆大幡形成黑色旋风，喝问：“**妖帅木韵、蝎金，事到如今，你二人降还是不降**”，声如阴风，出口即引旋风尖啸直冲九霄。
- 随即**数百万炼魂族人同时咆哮“降不降”**，天地震颤，雷鸣不可比；火妖城内残存妖兵心神震撼，一部分直接**七窍流血、失去知觉**。

## 五、看点与伏笔

- 黑洞的“逆向旋转→骤变→关闭”并主动绞杀入侵者，暗示妖灵之地入口有其自身规律/限额，进入者已成定局。
- 王林与司徒南同时入洞，同行阵容中还有凌天候、虚空子、雷吉等各方巨头，妖灵之地内必有强者角力。
- 千琴的心声为后续王林与其重逢埋线。
- 炼魂部落以魂幡、老祖石像、数百万族人的规模碾压火妖郡，火妖灵军与两位妖帅木韵、蝎金的抉择是下一步剧情节点。

# 第997–999章 炼魂部落吞并火妖郡 · 妖灵之地天象剧变

## 一、火妖郡陷落：欧阳华与「魂灭」

- **最后抵抗**：火妖都城城墙上，一名身穿蝎形铠甲、双目血丝的大汉怒斥「欧阳华，你莫要逼人太甚」。他没有冲向天空中的欧阳华，而是化作残影直扑人群中的**黑色石像**，喊出「即便是死，也要毁了此物」。
- **炼魂部落的反应**：四周族人乃至欧阳华皆冷笑讥讽，无人阻止——因为石像有护卫。
- **十三出手**：石像旁一名相貌寻常、一身黑衣、气息极端冰冷的男子（**炼魂部落第一强者「十三」**）冷声「欲伤我主石像者，死」，一拳挥出，无数魂魄自体内涌出融入拳风成风暴。大汉喷血、铠甲寸断、骨碎，苦笑一声「炼魂部落第一强者，十三」后四分五裂身亡（本已油尽灯枯 + 重击致死）。
- **叙事伏笔**：此人气质与**王林**有六七分相似，且称石像为「我主」。
- **魂灭**：欧阳华指向火妖都城，喝「魂灭」。数百万族人齐祭大幡，无法想象数量的魂魄冲出，凝成遮蔽火妖郡全境的黑雾压向都城。
- **投降**：城墙上一名青色铠甲女子轻叹「降」。

## 二、势力格局变化

- 火妖郡自此**彻底成为炼魂部落的都城**。
- 炼魂部落跻身**妖灵之地九大势力之一**。
- 黑色石像将被安放到原**古妖之灵**所在之地，成为炼魂部落的精神寄托（地位等同当年的古妖）。

## 三、「老祖，回来了」

十三迈步走向都城的刹那，身子剧烈颤抖，数百年不变的冰冷神色轰然崩溃，取而代之的是从未有过的激动，猛地抬头喊出：**「老祖，回来了」**。——与随后的天象异变呼应，指向王林（石像之主／老祖）的归来。

## 四、妖灵之地天象剧变

- 全境天空风起云涌，层层漩涡出现并蔓延至所有天幕，急速旋转如风暴自九天而来，撕扯天地、风沙走石。
- 原住民心神惊恐，纷纷仰望。

## 五、木妖郡沟壑：水潭中的妖异面孔

- 地点：木妖郡境内一处偏僻峡谷沟壑，青苔遍布、潮湿多雾，最深处有一面镜般不起波澜的水潭。
- 天象出现刹那，水面泛起涟漪，中央缓缓浮出**一张极为妖异、英俊得非人所有、双目透出幽光的脸**，望天露出妖异微笑：「终于来了，等着一天，已经很久很久」。

## 六、青草平原：禁制区与仙界传送阵

- **表象**：一片青草野花遍地的平原，草香淡而奇异，闻之心旷神怡，四周因此聚起许多部落。
- **炼魂部落的挫败**：其分支曾延伸至此，但魂幡在此地威力大减——幡内魂魄如被镇压不敢外出，强行放出便诡异消散。故炼魂部落**放弃此地**。
- **真相**：此地实为庞大禁制区域，内含无数禁制，一旦开启拥有毁天灭地之威；禁制上的绝顶高手看一眼便会冷汗直冒。
- **地下秘密**：草原地下有一处极古老的**传送阵**，可追溯至**仙界尚未崩溃之前**——即「**仙界之阵**」。通过此阵，以特殊方式加上**信物**，可进入妖灵之地五座仙府之一。

## 八、仙府内的一对夫妇

- **环境**：仙府呈回字形，外围众多阁楼环绕，中央为高耸大殿；仙气缭绕、雕栏玉砌，却空旷、冰冷、孤独。
- **青年男子**：玉树临风、出尘气息，盘膝而坐手持竹简，旁有热茶，茶气化虚幻之花升空消散。天象出现时他放下书卷，目光穿透虚无看到外界异象。
- **女子**：相貌秀丽略瘦弱，瓜子脸美目流盼，青蓝色衣裙配纯白衣裤（蓝色刺绣花纹），双腿修长。入殿说「他们来了」。
- **对话要点**：
  - 男子：「我们等了这么多年，希望这一次可以成功。」
  - 女子：「计划了这么久，只要我们谨慎一些，想必不会出现意外。」
- **关系**：二人相视一笑，伉俪之情弥漫，空旷洞府因彼此而有了温暖。
