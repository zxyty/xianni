# 第1395章 风起（第九卷 云海之巅）

## 一、王林炼化三千古魔之魂

### 起手与压制
- 王林右手隔空虚点魔魂瓶，瓶内传出凄厉嘶吼，具穿透之力直冲心神。
- 王林冷哼「萤火之力，也敢与皓月争辉」，音化波纹与吼声对撞。
- 黑雾裹挟古魔之魂倒卷扑来，王林双手一挥，狂风横卷，将魔魂尽数困于双手之中，「双手如同天牢，纹丝不动」。

### 融之道术（七天）
- 王林喝「道术，融」，双目奇异之芒闪烁，施展**蓝梦道尊的融之道术**。
- 闭目全力融合，历时**七天**，魔魂化作一个絮状之团。

### 反噬与血炼
- 絮状之团骤然幽光大盛，映亮整个洞府，狂暴气息爆发。
- 群魔合鸣嘶吼：「想要炼化我古魔一族，不可能」。
- 王林不假思索咬破舌尖，喷出一口**古神心血**（蕴含本源之力）落于球上，喝「血炼」。
- 幽光几近瓦解，被血色取代，絮状小球最终**赤红一片**。

### 目的与后续
- 王林再引元力入瓶，更多魔魂涌出被血色小球疯狂吸收。
- 王林自陈：此古魔法宝内蕴含**三千古魔之魂**，融合三千之魂**即可成其古魔分身之魂**。
- 大袖一甩，洞府魔雾环身淹没身影，继续炼化，又过一个月。

### 时间坐标
- 王林在**暗蝎族**闭关已**两个多月**。
- 距**颠落之地落生会之选**尚有**不足月余**。

## 二、颠落之地大事：蛮荒星蓝焰

- 地点：颠落之地边缘一处**废弃的蛮荒星**。
- 现象：**蓝色火焰**骤然爆发并包裹整星，仅**半柱香**后消散归于平静。
- 影响：颠落之地内**所有火修**心神轰震，体内火焰之力欲脱体而出，隐隐**朝拜**该蛮荒星方向，如受召唤。
- **火雀族**感受最深：曾与王林交易的那位火雀族长老，打坐中全身火焰掀起**化作一头火鸟、展翅欲飞**，面色大变。
- 该长老急出关，率族人直奔蛮荒星，**查看一无所获**，但感受到**与当初魂丹内几乎一模一样的本源气息**。

## 三、太古星辰火雀族：朱雀之血现世

### 场景
- 火雀族占据辽阔星域，**火雀主星**遍布火雀雕像，其中一座**与天齐高、通体火焰燃烧**，雕像之下有大殿。
- 大殿内**火雀族族长**（满面红光、全身火焰弥漫的老者）接到自颠落之地护送回的一滴燃烧的鲜血，惊呼「这是本源」。

### 圣地与老祖
- 族长携血液瞬移至修真星**内部最深处**：此地被掏空、遍布火海，最深处火焰呈**深紫色**。
- 紫色火焰中心有阵法，阵中盘膝坐着**紫衣中年男子**——族中**老祖**，气息惊天。
- 老祖睁眼时，双目与眉心三角处显现**三个火焰印记**：
  - 眉心——**紫色**
  - 右目——**蓝色**
  - 左目——**一片虚影**，虚火尚未稳定、模糊不清（族长见之心神一震，不敢看第二眼）

### 训斥与惩罚
- 老祖斥：「圣地之中，即便你是族长，若无老夫召见，也不得踏入半步」。
- 判语：「这种小事也能让你乱了方寸，你这族长，我不满意」——命其**按族规第三条自行惩罚**。族长面色苍白，奉血退下。

### 认血：朱雀之血
- 老祖随手一扫血液，平静瞬间崩溃，神识散开在血中扫过**数百遍**，震惊更浓。
- 放至嘴边舔舐后确认：「**朱雀之血**……这里面的本源错不了」。
- 火海化巨掌将已近地面的族长抓回，激动追问血液来源；族长答**「族人从颠落之地带回」**。

### 决策（行动项）
1. 老祖大笑狂喜，三个火焰印记疯狂燃烧，赞族长「不愧是老夫选择的族长」。
2. **立刻发布族命：不惜一切代价，前往颠落之地寻找这血液的来源。**
3. 老祖称**自己不方便进入颠落之地**，将**在外围接应**。
4. 叮嘱族人到达后**仔细查看此事是否存在阴谋**。

## 四、伏笔与关联
- 蛮荒星蓝焰的本源气息 ≈ 火雀族长老当初所得**魂丹**内的气息，暗指同一本源来源。
- 朱雀之血指向颠落之地，火雀族倾族力搜寻，与临近的**落生会之选**形成交汇之势。
- 王林所炼**古魔分身之魂**为其后续战力伏笔。
