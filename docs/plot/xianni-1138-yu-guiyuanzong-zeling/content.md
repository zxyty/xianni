# 第九卷 云海之巅 第1138章 雨

## 一、场景：归元宗（莫罗大陆东部）

- 莫罗大陆东部有一片**环形山脉**，不似龙形蜿蜒，而是成环相连；环内是一片庞大盆地，阁楼处处、灯火明明。
- 盆地外山脉上有**八根十丈粗的巨柱**，均匀分插八方，斜插天际；在距盆地约万丈高处，八柱托起一座庞大**道观**，远看如悬于半空。道观古朴磅礴，蕴含威严。
- 本章雨夜，钟声庄严回荡，盆地内无数道袍修士冒雨而出，仰望上方道观，悲泣不已——宗门掌门大限将至。

## 二、掌门归墟与遗言

道观内，道袍老人面色苍白、死气缭绕，四名弟子（三男一女：一中年男、一中年女、两名老者）跪于身前。

交代事项：
1. **托孤**：「为师大限将至……为师走后，归元宗就要落在你们四人的肩上。」
2. **憾事**：自身修为**始终未踏入碎涅**，故此前**八阶灵元宗一行**被**主宗之人吸走全部寿元**，右手干枯如骨（数月前尚且完好），落得如此下场。
3. **疑局**：中年男弟子质问——**紫道宗**在莫罗大陆布置阵法、暗中进入**联盟星域**，为何回来后**主宗**要把怒火降在归元宗身上。老者沉默，只道「主宗如此，想必定有深意，你们还是不要揣摩了」。
4. **遗愿**：**千年一次的分宗大比**是云海星域盛典，全云海宗派参与，归元宗**每次皆末位**。愿百年后的大比能脱离数千年来的末位，「为师就可含笑九泉了」。
5. **留宝**：虚空一挥开出紫红色**储物裂缝**，放出一头**五阶紫目蟒**（头颅数丈，威压弥漫，神色疲惫、依依不舍），定为**归元宗镇宗之兽**。

## 三、传承神通「泽灵」

- 归元宗历代掌门，凡非客死异乡而得以**归墟**者，都会在生命最后一刻**燃烧一切**施展**泽灵**（文中亦写作「择灵」）。
- 作用：选出未来数百乃至数千年内、在莫罗大陆上**对归元宗有重大帮助者**，称为**伴灵之子**。
- 原理玄妙，无人能说清，连掌门本人也不明白，只知传承极久。
- 成功率极低：无数年来仅**成功两次**，其余皆失败——失败即表示彼时莫罗大陆上无符合条件之人。
- 老掌门自述：当年他就是被祖师以泽灵选中的，那时他还只是**山村少年**。
- 施展时状态：最后一丝生机与元神燃烧，身起**青色火焰**，神识**前所未有的空明**，隐约接触到某种**玄妙规则**，神识可弥漫整个莫罗大陆搜寻。

## 四、转折：临终窥见白发王林

- 一遍遍寻找无果，泽灵**失败**。身体在青焰中烧至只剩模糊头颅时——
- 神识忽然察觉**莫罗大陆北部丛林**雨夜中一片光芒；他之所以留意此处，因为那里正是**通往联盟星域的传送阵**所在。
- 传送阵亮起，一个**白色身影**缓缓现身：黑夜中一头**白发**飘动，天地雨水似都为之颤抖，轰鸣雷霆如畏惧此人般齐齐消散。
- 白衣青年抬头冰冷扫了一眼天空，雷霆轰轰退后。老者心神大震。
- 因身处泽灵、与天地规则融合，他**看到无数冤魂**环绕在白衣青年四周，密密麻麻、狰狞怨恨地盯着他，却无一敢近——**皆是王林一生死在他手中之人**。
- 老者顿生极端危机感，判断：**此人不是云海修士**。疯狂收回神识，欲令弟子立刻逃走、并通知主宗。
- 猛地睁眼，只来得及说出「**北部**」二字，大限临近、元神崩溃、神识化作虚无，其在世间的一切痕迹尽数消失；消散刹那，带着不甘再吼出两字——「**白发**」。

## 五、余波与王林登场收尾

- 四名弟子牢记这四个字，却不知师尊临终为何神色震惊。钟声回荡，哭声散开。
- 归元宗随即下令：**所有弟子赴莫罗北部，寻找一切有修道资质之人，不管年纪，尤其是白发**。
- 北部丛林中，王林收回望天目光。雨水浇在身上，把他衣衫上自**联盟星域**带来的积雪打湿，化作雪水滴落在他乡地面——「联盟的雪，云海的雨，在这一刻，不分彼此」。
- 王林深吸一口云海的空气：「**走时雪送，来时雨迎……似乎不错。**」随即走进丛林深处。

## 六、要点提示

- 本章为王林**初入云海星域**后的第一处外部视角侧写：其杀孽（冤魂）之重与威压之强，被一个连碎涅都未入的老者以规则视角直观呈现。
- 埋线：归元宗「泽灵」失败但意外锁定王林；「北部·白发」的遗言将驱动归元宗全宗搜寻，构成后续因果起点。
- 势力线索：**主宗**（对分宗强横，可吸人寿元）— **归元宗**（末位分宗）— **紫道宗**（潜入联盟星域）— **灵元宗**（八阶）同属云海星域体系；千年一次**分宗大比**为重要时间节点。
