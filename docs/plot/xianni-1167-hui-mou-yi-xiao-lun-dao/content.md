# 第九卷 云海之巅 第1167章 回眸一笑

## 一、场景
- 地点：莫罗大陆·归元宗·药院。
- 在场：王林（以化名『吕子浩』行事，自第1063章起）、李倩梅、卢云从（紫道宗宗主）。
- 时长：论道自白昼延至夜半明月，再至次日清晨，三人席地而谈忘却时间，原本的杀气被论道冲散。

## 二、王林论天意（第二问的答案）
### 雨水之喻
- 引『曾经有位友人』之言：雨生于天、死于地，中间过程即人生。
- 王林辨析：雨从虚无来，与天无关；雨落大地润万灵，与地也无关——此为雨水的命运。
- 雨由水汽而化，水汽由万灵而生，雨落后回归万灵，是为**因果循环**，也是命运所在。
- 结论：冥冥中有**命运规则**存在，无形，却缭绕在每一个生灵身边，悄然改变一切。

### 演法
- 王林右手一挥 → 雷霆轰响，水汽四面凝聚成乌云，降雨大地。
- 观雨如观人生：没有一滴雨能不改变轨迹地直线落下，它们因风、因云、因自身之重不断调整降临位置——此即雨水的**不甘**与对天意的默默对抗。
- 王林大袖一甩 → 雨水倒卷冲入乌云，乌云崩溃，雨化水汽消散。

### 核心论断
> 你改变了雨水的命运，你，就是天意。
- 飞蛾喜葬火而亡，你把火吹灭，就改变了飞蛾的命运。
- 天意命运让一个人死，你把她救活，你就是天意。
- 凡间语『王侯将相宁有种乎』、仙家语『一人得道鸡犬升天』，皆是此理。
- 对比：雨水一生很短，却因循环又很长；修士一生很长，却因天意命运又很短。雨水尚且拼死挣扎脱离命运掌控，修士中却少有人肯拼死对抗天命。

### 反响
- 卢云从心神如钟鸣回荡，向王林深深鞠躬抱拳，不发一言而敬佩尽显。
- 李倩梅望天茫然，长叹后目光大变，道『吕兄之道，小妹心服』。

## 三、李倩梅的第三问与「道如思想」
- 李倩梅赠礼：一枚**蕴含十阶凶兽之魂的半成品丹药**，另附**玉简**（内载具体药草与炼丹方法）。
- 第三个问题仍是『什么是天』。王林闭目半柱香后开口：**『你问的，不是天，而是道。』**
- 王林自陈：此问他也一直在思索，曾得到过答案，但如今看来并不完整。
  - 旧答案：**『我为鱼，道为网，河为天，那捞网的渔翁，就是执掌命运的造化。』**
- 李倩梅转述其师尊之语：**『人为蝼，道为山，意为天。若天怒，则道随天走；若蝼怒，则也有搬山之力。』**
- 王林新解（听李倩梅之言后眼中露出明亮之芒）：**道并非网，也并非山，而是一种思想；这思想因人而异，有的人把它看成网，有的人把它看成山。**
- 卢云从附和明悟：『道如思想。人之所以称人，就是因为有了想法，可以脱离肉身，融入天地，去思索一切未知所在。』
- 次日清晨，王林给出定论：『这第三个问题，我目前只能说，**道如思想**。』
- 李倩梅道谢，请王林**日后若有得道再告知**，并称『小妹以后，也就不问别人问题了』；王林一怔后点头应下。
- 叙事强调：王林是**第一个让李倩梅问出第三个问题的人**；这三个问题对她的重要与意义无人知晓。

## 四、卢云从：解怨与阴仙幡
- 卢云从借酒开怀（与王林分酒对饮），坦言『我那孩儿的确该死，能死于此人之手，也算他的造化了』，打开心结。
- 表态：『闻道一夜，往昔仇怨就此掀过。』
- 但索要**阴仙幡**，王林平静摇头拒绝。
- 卢云从关键情报：**阴仙幡并非紫道宗之物，而是主宗赐下寄养，百年后需要归还**；若王林执意不还，他不会强求，但百年后主宗索要时会如实告知。
  - 王林听闻『阴仙是主宗之物』，神色如常而心中一动。
- 卢云从已看出自己不是这白衣男子的对手，即便紫道宗倾巢而出亦无用。
- 卢云从见李倩梅无意同行，内心苦涩，抱拳告辞离去。

## 五、紫道宗援兵被喝退
- 莫罗大陆外，紫道宗一老者驾猛虎灵兽等候大半天，焦虑渐生，遂率三十余名核心弟子直奔莫罗大陆。
- 尚未破开防护，卢云从威严之声回荡：『退下，没有我的吩咐，不得进入莫罗大陆半步』——老者恭敬称是，操控猛虎灵兽迅速后退，心中仍不解。

## 六、笛音与回眸
- 卢云从离去后，李倩梅取**翠笛**吹奏：温润典雅、清丽飘逸，蕴含宁静韵味，如村落凡生、山涧流水，如七色彩虹桥连接人心。
- 王林闭目，恍惚看到**朱雀星上弹琴的女子**与**妖灵之地抚琴的盲女**，笛音与心中琴音交错难分（重要回忆闪回）。
- 远去的卢云从伴笛音而行，回望归元宗长叹，再不回头。
- 笛音散后，李倩梅走向药院门口，临出门**脚步一顿，回眸一笑**，王林恰在此时睁眼。
- 李倩梅相邀：『吕兄，**蓬莱大陆**上近日有**三十年一次的坊市与拍卖**，可有兴致一去？』
