# 第1931章 面孔！（第一更）

## 一、封印示警与面孔现世
- 王林心神内回荡古老苍桑之音：「发现，非仙罡之灵，封印」，此音似自无数万年前传来，回旋于层层封印内外，带着某种意志与使命，透出诡异。
- 王林本体闻声即刻后退，五行真身幻化直奔前方雷霆真身；同时封印上幻化出巨大模糊面孔，扑向雷霆真身。
- 面孔幻化之刹，卡在封印中的仙极剑金色碎片传出巨大吸撤之力，似封印在阻止碎片脱离。

## 二、三身合力·拽出仙极剑碎片
1. **雷霆真身抗面孔**：不松手则危、松手则前功尽弃。王林雷霆真身爆发轰鸣，散出蕴含杀戮的弧形闪电——即其真身所蕴的**杀戮之雷**，凝成巨大闪电手掌，一掌按在面孔上。面孔露出痛苦、动作一顿。
   - 注：此掌并未蕴含太多杀戮雷霆——该真身若动用过多，雷霆未散真身先崩；此雷为王林无意中从天地内诞生，连他自己都心惊忌惮。
2. **第一寸**：雷霆真身借面孔一顿之机，死死抓住金色碎片猛拽，与吸撤之力对抗，硬生生拽出一寸（似已到极限）。
3. **第二寸**：五行真身临近，拉住雷霆真身猛拽；雷霆真身如桥梁承接大力，碎片再出一寸，大半已在封印外，仅余一寸卡住。
4. **最后一拽**：王林本体临近，右拳轰向被闪电手掌按住的面孔，身后幻化**道古身影**随拳而出，与闪电手掌似融合共抗面孔；同时左手抓住五行真身，本体之力→五行真身→雷霆真身右手层层传导，雷霆真身一声嘶吼，终于拽出**完整的仙极剑碎片**。
5. **反噬**：碎片脱出瞬间大力如火海爆发，两具真身倒卷融回本体，王林急退仍被冲击，嘴角溢血。以其当下肉身强度与天尊战力尚且受伤，可见封印之强。

## 三、面孔追噬与最强一击
- 闪电手掌轰然崩溃，但组成手掌的杀戮雷霆只散不损，倒卷涌回王林体内。
- 面孔无声咆哮，紧追王林至不足十丈，誓要吞噬封印这「非仙罡之灵」；其与封印之间以模糊「脖子」相连，已延长百丈仍在急速蔓延，远看如巨大蟒蛇之身。古老之音再度回旋。
- 王林双眼血丝——自得天尊战力五十多年来从未如此惊险，但既已决定，绝不后悔。
- **最强一击**：右手握拳，体外幻化**九十七个残影**，齐齐掐诀按天，各吼四句后同轰一拳：
  - 「神震，兵修列位」
  - 「妖术，烽火成山」
  - 「魔道，生死逆动」
  - 「神、妖、魔，古道无仙」
  - 残影融入本体，形成灰色波纹扩散而出。此为借**魂铠**之力、毫无保留的最强一击，五十多年挑战中从未用过。
- 效果：面孔在王林身前三丈处连同脖颈急速石化，但石化尚未完成即开始松动恢复，数息内可复原——古道无仙亦无法彻底毁灭它。

## 四、决断不退·骨阴刀斩颈
- 王林权衡：顺先前轰开的洞口逃出山海乃至冲出海面有**八成把握**，但余下两成意外若遇海子天尊恢复、双方夹击则极为不利。他不赌，宁把生机握在自己手中——「不能退」。
- 身形一晃，直接出现在面孔之后。面孔石化层层破开欲扭转脖颈回噬，但脖子大半石化，转头尚需数息。
- 王林右手抬起，一阵钻心之痛间，掌心钻出一把狰狞的**骨阴刀**，足足三丈长；刀出四周海水如同冰封。
- 借魂铠之力，九十七残影再现，个个神色狰狞、双目通红，各持骨阴刀幻化；连同本体共**九十八刀**连成扇形刀光，斩向靠近面孔处的脖颈。
- 结果：一刀两断，脖颈崩溃，轰鸣震动整个山海。

## 五、余波与结尾
- 海底震动使整个山海化作漩涡、卷动海水咆哮。
- 海面上，正向章鱼海兽得意挑衅的海龙被震动波及，忽感莫大危机，立刻钻入海底急速逃离。
- 同一刻，章鱼海兽背上的**海子天尊身子一颤，双眼寒光，喝出「王林」——其已恢复**。

## 六、留待后续
- 王林已得完整仙极剑碎片，但仍身处山海树层层封印之地、且已受伤。
- 海子天尊恢复行动之力，冲突一触即发。
