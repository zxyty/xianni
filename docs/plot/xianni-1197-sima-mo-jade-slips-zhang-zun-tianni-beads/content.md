# 第1197章 掌尊（第一更）

## 一、场景
王林（此时于云海星域以化名「吕子浩」行事）立于七彩界山谷内的骸骨（司马墨）之前，以神识依次读取三枚玉简。

## 二、第一枚玉简：入界前百年
- **第三年**：二师弟死、老三死，二人成为「迷失者」，四天前司马墨见到他们，二人已不识故人，擦身而过。
- **第六年**：拾得一枚玉简，上载一种称为「岁月」的禁制，司马墨决意学会。
- **第十一年**：师叔前往此地深处，称那里「有一个声音在呼唤」；司马墨对岁月禁略有摸索。
- **约三十年**：铭志者再度攻击，司马墨在铭志者中分明看到师叔；此役带走六师弟、五师弟。
- **岁月禁大成**：司马墨与残余同门在一处山谷布下真正的岁月禁大阵；九师弟牺牲自身寿元加固阵法的岁月痕迹，临死请求把骸骨送回破天宗，司马墨答应，却自问「我能做到么」。
- 山谷自此被岁月禁阵法守护，成为「家」，但只见一张张熟悉面孔渐成陌生。

## 三、第二枚玉简：百年至百三十年
- **约一百年**（无昼夜，靠岁月禁阵法强度推算，主观感觉「好似过去了千年」）：十三弟不堪牢笼般的生存，自毁肉身道消。
- 同门或成迷失者、或成铭志者，仅剩司马墨、十六弟、四师叔三人。司马墨自认「我们是罪人，这就是惩罚」，但「不甘心」。
- **第一百三十余年**：逆行者第一次出现——四师叔化作了逆行者。
- 司马墨想到一个救回众人的方法，告别十六弟，独自走出山谷；先从迷失者中带回二师弟、三师弟及所有沦为迷失者的同门，再入山脉深处雾气中带回成为铭志者的五师弟、六师弟，又赴至深之处带回二师叔（称「那里的道路，我很熟悉」）。

## 四、第三枚玉简：三百年与掌尊
- 司马墨在此存在三百多年，走遍能去之处，发现一种**珠子可封印逆行者的神通**，为救四师叔搜罗了不少。
- **第四次深入至深之处**：用珠子封印了那里所有强大逆行者的神通，寻数年终于找到四师叔，却「没想到他竟然也在这里」，功败垂成，被一根**七彩钉子**钉入体内，钉子入体立刻融化。
- 逃回山谷后意识渐散，脑中不断浮现发狂念头——想杀光眼前所见一切生灵；而谷内除己之外唯一生灵是十六弟。
- 遂将**十六弟赶出山谷**，交付**身份令牌与兽骨丹方**，嘱其十年后再进来；自己坐守山谷，望着谷外七彩天空等待发狂。
- **关于石珠的推断**：石珠并非天然所化，而是被人祭炼而成；大小轻重一模一样毫无差别，似有人在极久之前于此地以特殊神通不断制作。
- **临终异变**：意识愈发模糊时，感到有一股力量在吸撤其元神；意识反而一瞬清醒，一个疯狂念头挤入脑中——「如果我成功了，我就不会发狂，我会重生」。意识随即离开此地、延伸至一片奇异星空，见到一个**身穿黑袍、眉心有圆形印记的中年男子**，对方自称名为**掌尊**。

## 五、王林的推演
- **掌尊之名的旧线索**：王林曾在仙帝青霖洞府内得知，界外之民中有一强大存在名为「掌尊」，属与青霖同时代的强者，本以为相隔悠久岁月，不料在云海星域、七彩界、这山谷的玉简中再次出现。
- **界外之民旧事**：当年与清水在虚无中战望月，虚无崩溃后出现一老一少两名神秘修士，即界外之民；若非天逆珠子出现，恐被生生擒走。那老者见天逆珠子后称王林为**「封界之尊」**。
- **发狂线索串联**：七彩钉子入体确可使人发狂、欲杀尽所见生灵；清水师兄曾自述仙界尚未崩溃前闭关时无故发狂，朱雀老圣皇亦言清水去修真联盟后再次发狂——同样是发狂，必与掌尊有莫大关联。王林由此并列出四个名字：**天运子、清水、司马墨、掌尊**。
- **司马墨结局判断**：骸骨在此、四周无半点破坏痕迹，说明司马墨最终**没有发狂**；既未发狂，则其脑中那与掌尊有关的念头，**应当成功了**。
- **地理与源流**：此处即**破天宗当年发现的那处空间裂缝**，也是**兽骨丹方最早出现的地方**；玉简与丹方之所以流落云海星域，王林推测是那「十六弟」最终离开了这里。
- **神秘的「他」**：按玉简所述，破天宗本不知此空间裂缝，是听「他」之言辞才找到；且司马墨在此数百年后，竟又在此地看见那个神秘的「他」。王林知道得越多越感迷茫。

## 六、洞府与「天逆」
- 山谷壁上有**九个被山石封闭的洞府**。王林开启第一个：山石向两旁移开，扑面而来一股岁月腐朽气味。
- 洞府仅十丈大小，半空一片灰芒中漂浮**十个婴儿拳头大小的珠子**，每颗珠上有一个黯淡符文印记，时而以灰色之光闪烁，不细看难以察觉。
- 王林一眼认出：此物**正是苍松子施展召唤逆行者神通所用的珠子**，玉简所载果然为真。
- 此前苍松子出手极快且斗法不便分心，王林只是目光扫过；此刻虚空抓来一颗、神识细查，面色骤变、心神剧震——
- **「天逆」**。

## 七、要点提示
- 本章为纯信息揭示章：无战斗，核心是三枚玉简的世界观揭底 + 结尾「珠子=天逆」的悬念反转。
- 关键谜团：掌尊身份与目的；七彩钉子致狂的机理；石珠（天逆）由何人祭炼、为何量产；神秘的「他」是谁；司马墨「重生」是否已经实现。
