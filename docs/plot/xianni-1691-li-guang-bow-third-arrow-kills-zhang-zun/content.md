# 第1691章 绝不会错？

## 一、硬撼掌尊：三度对拼皆败

战斗承接前情，王林右手食指仍在对抗掌尊威压，口喷鲜血、身体大量碎裂。

1. **役灵印**——王林左手掐诀挥出巨大掌印（役灵印），与掌尊大手印相撞，役灵印骤然崩溃，王林身子倒卷，**仅第一次对抗即已重伤**。
2. **七彩长枪**——右手一指星空，七彩之芒化作七彩长枪轰向手印；再度被压，退后数千丈，双手颤抖、双腿血涌。
3. 大手印虽略有消散却不瓦解，继续压落。

王林心中判定：「这就是空玄巅峰踏入玄劫修为的力量，**若没有李广弓，我无法对敌**。」

## 二、六大本源剑 + 撕天之术 + 道古之身

- 王林左目火焰、右目雷霆，体内**三大本源**及**杀戮本源**齐起，六大本源幻化体外，凝成**六把虚幻本源长剑**，尽数刺入掌印。
- 王林不退反进，吼出「撕天」——**首次施展从烨寞之子身上获得的撕天之术**，双手扣住星空猛地外撕，身前星空被直接撕出裂缝。
- 与此同时，其身后浮现**道古虚影**：与以往只有一个头颅不同，此次已有模糊身子，即**吸收八滴血液后自然生成、尚未炼化的「道古之身」**。虚影同步张臂前撕。
- 撕扯之力撕开星空、星幕、天地运转，**掌尊大手印崩溃**。
- 代价：六剑碎裂化片倒卷回体；王林双手十指血肉模糊（撕天全靠十指）；道古虚影亦轰然崩溃；王林被抛飞、大口喷血、血雾弥漫、元神模糊受反震之伤。

> 关键笔法：王林双眼疯狂**瞬间消散、转为冷静**——「仿若之前的一切，如同做戏一般」。

## 三、诱敌：四大强者齐至

- 掌尊确认对方再无第三弓之力，狞笑逼近：「王林，这一次我看你往哪逃，**这片星域已经被老夫封死**」，自陈**等这一天已经等了三年**。
- 远处星空波纹迭起：**第七妃**阴沉着脸走出；**妙音仙尊**、**九天魔尊**自另一方向现身，四人目标一致——杀王林。
- 阵容规格：**太古五尊其三 + 远古仙尊第七仙妃**，任一皆可名震界内界外。
- 王林眼中寒光：**他等的正是四人尽数现身**，唯有如此才能一劳永逸，完成「计划第一步」的收束。

### 王林计划第一步（明确交代）

> **毁界外远古仙域，搅乱洞府界，使势力不再平衡。**
> 且以其心机，早已算到一旦如此，自己将没有离去之路，会深陷太古星辰被人追杀。

## 四、第三弓：李广弓与李广箭

- 掌尊逼近刹那，王林左手虚空一抓，**李广弓**赫然在手。
- 掌尊面色大变、后退数百丈，反复嘶吼「不可能」「你只有两弓之力，我绝不会再算错」「你拉不开这把弓」——一次又一次的算计落空对其打击致命，**撼动了掌尊道心**。
- 第七妃花容色变止步，妙音仙尊、九天魔尊亦齐齐停身。
- 王林右手拉弦，嗡的一声令掌尊身颤，**三年前的死亡印象**无法压制地爆发。
- 掌尊改口：「你也没有仙力引动李广箭」——话音未落，弦上幽光一闪，**震慑众生的箭幻化而出**，直指掌尊。

### 掌尊的最后一赌

掌尊不退反进，连出三重手段：
1. 再起**巨大掌印**；
2. 掌印之后浮现**容纳星空的虚幻之井**，笼罩八方；
3. 井水内幻化**一轮赤红骄阳**，弥漫**太初规则之力**；
4. 又一拍头顶逼出**拳头大小的骨珠**（灰芒万丈、森森白骨气息），使自身修为神通**暴增数倍**。

### 一箭定局

- 王林**闭上双眼以掩目中金色**，凭**神识**拉弓，再拉开一些后猛地松手。
- 箭化惊天长虹：掌印崩溃被穿透 → 虚幻之井随灭 → 赤红骄阳被射穿 → 贯穿掌尊。

## 五、战果清算

| 对象 | 结果 |
| --- | --- |
| 掌尊 | 肉身被一箭穿体、轰然崩溃四分五裂，血肉化风暴吹出数万里；随后**重聚复活**，面色苍白、目露从未有过的恐惧，再不敢推算王林还有几弓，如三年前一样疯狂逃遁、头也不敢回 |
| 妙音仙尊 | 喷血、肉身爆开，**元神被王林大袖一甩笼罩收走** |
| 九天魔尊 | 喷血、肉身爆开，**元神被王林收走** |
| 第七妃 | 后退中喷出大口鲜血、**重伤**，因身为仙妃有**仙尊之宝**防身而侥幸生存 |

## 六、章末悬念

箭势散去后，这片星域内**七彩之芒滔天而起**，光芒弥漫把星空完全映照在内，**似有人随七彩光芒而来**。
