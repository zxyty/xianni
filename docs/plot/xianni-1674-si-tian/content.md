# 第1674章 撕天！

## 战场与对阵
- 地点：转轮阵法外的星空。
- 对阵双方：王林（千丈身影，承道古传承） vs 自称「烨寞之子」的黑发中年人（可召古之三族虚影与道古烨寞庞大虚幻之身）。
- 性质：生死斗——「不是他死，就是对方身亡，没有第三个选择」。

## 第一回合：化身道古左目
- 烨寞之子挥臂，古之三族虚影化三道长虹直扑王林，其后道古烨寞虚幻之身迈步逼近。
- 王林不退反进，右手掐诀一指，身后**没有左目的道古头颅**咆哮前冲，与其千丈身影融合。
- 融合后王林所在的位置正是**道古左目的空洞之处**，其体内光芒笼罩左目，使头颅看似完整。
  - 原话：「道古传承，烨寞既没有了左眼，今日我便化身成其左眼，使得这头颅略有完整。」
- 王林所化道古头颅吹出一口**道古之气**——道古传承的精髓、吉之一族神通之一。

### 互创结果
- 烨寞之子：古之三族虚影与烨寞虚身骤然崩溃，面色苍白、喷血倒退。
- 王林：三虚影如利剑刺中道古头颅眉心与双目、烨寞虚影一拳轰爆头颅；王林喷血后退，眉心留伤口，**双目流下两行血泪**，眼前一片血色模糊。

## 第二回合：星空为天 ⇄ 梦回远古
- 烨寞之子跃起掐诀，喝「**星空为天**」，星空扭曲、天外之力搅乱星域——此为其后续神通的**起手式**。
- 王林生出熟悉的生死危机感，抬手抓开**储物裂缝**，取出**已修复完整的青光盾**。
  - 青光盾未必坚不可摧，但内藏**古神神通「梦回远古」**。
  - 威能记录：以王林**当年**的修为施展，已足以轰杀**天人衰劫**修士；此番配合道古气息更具无上之力。
  - 该神通已被王林以**梦道之术**改变，与当年不同。
- 王林以**道吉之力**灌入盾中，青光暴增，召出梦回远古：星空被拉回远古，现苍天与大地，古神、古妖、古魔齐出。
  - 数量实录：古之三族**仅三千**，因身躯庞大而一眼望去几乎无边无际。
  - 远古之风蕴含沧桑，死气沉沉。
- 一只磅礴大脚自云层踏下，大地龟裂，脚印成坑，随即再迈向烨寞之子。

## 第三回合：撕天
- 烨寞之子完成起手式后双手扣住虚空，喝出神通来历：
  - 「父祖传承于我的最强之术，以万物为天，以我古族双手，撕开天地，此术，**撕天**。」
- 效果记录：
  - 一撕即在苍天上撕开巨大裂缝；
  - 将踏下的磅礴大脚**撕成两半**；
  - 沿途一切古之三族虚影尽被撕成两半，梦回远古无法令其停顿，撕出血路直逼王林百丈之内。
- 王林认知：撕天是烨寞神通中极强之术，他**只在道古传承内知晓其名，未得施展之法**。

### 王林的应对与伤势
- **因果印**：右掌五指并拢下拍、握拳外拽，抽出烨寞之子双手内的无形气息并一拳捏碎——仅令对方双手略一顿。
- 撕天临身：剧痛如两只大手要将其撕成两半；眉心现血线蔓延至胸口、小腹；鲜血长线喷洒；皮肤撕开露出头骨，鼻子、胸口处皮开骨露，骨头开始碎裂。
- **生死印**：左手蕴生机前拍、右手死气化黑雾直奔烨寞——仍无法阻止对方。
- 烨寞之子状态：疯狂、不在乎受伤与死亡，唯一念头是撕开王林身体。

## 王林的心念（伏笔）
- 「好一个撕天之术」——震惊之余生出渴望：**杀了烨寞之子，获得对方的一切，包括撕天之术**。

## 章末悬念
- 停在烨寞之子再次大吼「撕天」、双手向外狠狠一撕之际，胜负未分。
