# 第1481章 今昔横云有雨（第一更）

> 卷次：第十卷 叱咤界内 · 章节区间归档 01390-01394 之3

## 一、故人重逢：八百年后的横云山

- 风雨中，白衣王林现身罗天星域·青灵星·横云山顶，任雨水打湿白发衣衫而不避——与「当年明悟唤雨时刻意不愿雨水淋身」形成对照，此刻其人如山如地、如一草一木般自然。
- 石台上的老者激动跪地唤「师尊」，正是王林当年在青灵星寻道时收下的**记名弟子谢青**。一别八百年。
- 因果溯源：谢青于王林一生只是一闪而过的画面，但正因此人存在，王林当年得以**意境圆满**，遂生出一丝因果、动了收徒之心。

## 二、谢青之道：只修意境、以魂入命

谢青八百年枯坐横云山，凭其**俗世文人宗师**的智慧感悟王林所赠意境，走出一条与天地间所有修士（包括王林本人）都不同的路：

| 维度 | 王林之路 | 谢青之路 |
|---|---|---|
| 根基 | 道与神通融合，凭神通感悟大道意境 | 完全放弃神通，**只修意境** |
| 内神 | 元神／元婴等俱全 | **无元神、无元婴**，一切内神皆无 |
| 所存 | — | 只有磅礴生机弥漫的**魂** |
| 肉身 | — | 极脆弱，一把飞剑即可送命，似油尽灯枯；然生机磅礴，生命不灭 |
| 意境层级 | — | 窥涅修士亦不能匹敌，**直指净涅**，已达初窥规则 |

- 这是一种不存在于世间的修行方法，其极端程度堪比古神一族的极端炼体。
- 谢青自己也说不清缘由，不知任何修行法门，只是默默感悟了八百年。
- 王林断语：「修魂么」，并给出四路总纲——
  - **修仙者**：梦寐成仙，永世长生；
  - **修真者**：寻觅真我，洒脱世外；
  - **修道者**：印证本源，自身为道；
  - **修魂者**：以魂入命，天地君亲师。

## 三、点化：反朴归真的新解

1. 谢青因衣衫湿冷，下意识抬右手结印施展自悟小法术，令雨水在山顶改道、落向四周。
2. 王林摇头：「你还是没有完全的放弃一切神通」，并挥手破去法术，雨水复落。
3. 论道要点：
   - 山、河、大海、一草一木从不阻挡雨水，唯「万物之灵」才起排斥之心；
   - 既已修魂，何惜皮囊；
   - **反朴归真**不是王林当年自认明悟的那四个字——经历过往、回到罗天后他方才顿悟：真义是把自身融入一草一木、一山一河，**摆脱万灵限制、成为天地的一部分**；
   - 若化身为天为地，风、雨、雪、雷皆如自身无形血液，何来彼此、何来阻碍。
4. 期约：当谢青能舍弃这具肉身、忘却一切自悟法术，**只剩一缕道魂**之时，可去寻王林。

## 四、雨水化剑：镇星之礼

- 王林右手向天空虚无一抓，天地色变、风云倒卷，弥漫**小半个青灵星**的雨水呼啸汇聚，融为一把**高约万丈的巨大雨剑**。
- 挥手间雨剑自天而降，刺入横云山顶近三成，露出**六七千丈**，极远处亦清晰可见。
- 加持：眉心**古神星点**闪烁送入一股**古神之力**；双目射出**雷火本源**融入剑中。
- 结果：一把雨水所化之剑内蕴含**两道大成本源**与**道古战天之势**；气势未扩散太广，却足以震撼整个罗天。
- 王林定论：「有此剑在，罕有敢冒犯此星者」——即便空灵境界大能，感受其气息后也要掂量：为一颗修真星与近本源大成之修交战是否值得，何况其上还有道古威压。
- 定性：此剑是谢青**彻底明悟之后**的「入门之礼」。
- 王林转身踏入山外天地，身影在雨中渐远；谢青跪地磕三个头相送。
- 补记：青灵星上的**仙选族人**早已迁移而走，未留任何尘埃，好似从未来过。

## 五、四事之约与下一站

- 王林回罗天，**要去四个地方、做四件事**；青灵星是第一处，第一件事已了。
- 走在罗天星空中，其双目渐生寒意与杀机：「向家老祖当年之事，已到了断之时」——直奔当初以**七夕之术**令他失去全部生机的**向家修真星**。

## 六、余波（一）：雷仙殿搬星队伍被逼退

- 王林离去数个时辰后，距青灵星三千万里外星海中，一队数十名修士由一名**身穿雷袍的中年男子**带领直奔青灵星。
- 来历与目的：**雷仙殿**之人，奉命寻找符合**罗天老祖**要求的修真星，用以组成传说中威力惊天的**星损七劫阵**；青灵星符合要求，已下达强行搬迁的封命，此行即为挪走青灵星。
- 结果：刚踏入三千万里范围的刹那，即被如雨水般弥漫的滔天剑意所冲——剑意之强足以崩溃星空。领队雷袍中年男子面色大变、喷血倒卷而退，身后诸修士几乎同时喷血、骇然齐退。

## 七、余波（二）：鲁夫子暗探雨剑

- **鲁夫子**（一身道袍的老者）不愿立刻面对王林，感受到雨剑气势后，特意等王林离去才无声无息地在横云山顶扭曲显形。
- 他飘在半空皱眉沉默，抬右手隔空一指点触雨剑，一碰即身子一震、抬头骇然。
- 其判语：这股气息「与古神相似，但又完全不同」，在此气息下他竟心惊肉跳；更惊觉「这把剑内，居然有**两道本源**」。

## 八、看点与伏笔

- 「修魂」作为第四条道路被正式提出，谢青是其唯一实例，且以无神通、无内神之身触及净涅意境。
- 雨剑同时是护星法宝、师徒信物与实力宣告；它直接掐灭了雷仙殿对青灵星的搬迁计划，等于王林与罗天老祖的星损七劫阵布局产生正面冲突。
- 鲁夫子对「似古神而非古神」气息的骇然，指向王林道古（烨寞）之势与古神之力的复合来历尚未被人看破。
- 四事清单只完成其一，向家老祖的旧账为下一站。
