# 第1850章 仙丹崩！

## 一、云空凝丹：引子与压缩

- **背景设定**：丹海乃一枚仙丹所化，此事众所周知；古往今来有人想在此炼化出仙丹，却无人成功，症结在于缺少「引子」。
- **引子来历**：引子是一滴金色液体，封存于玉瓶中，与化作丹海的仙丹**曾属一体**，为绿魔洲无数年来才寻到之物。无此物，海水凝聚的极限只有万丈；到此便无法再缩，海水散开、吸收天地水汽后重新形成丹海。
- **凝聚过程**：云空双手掐诀，将三万丈海水凝为一万丈（自身负担极大，面色苍白），捏碎玉瓶投入金色液体后，海水沸腾翻滚，一举破万丈之限：
  - 万丈 → 五千丈 → 三千丈 → 一千丈
  - 云空闭目，一股惊天**剑意**扩散笼罩千丈海漩，神识**完全融入**丹海、毫无保留
  - 千丈 → 八百丈 → 五百丈 → 三百丈 → 急速向百丈收缩，其内隐现**半粒仙丹**迹象
- **关键脆弱点**：最后凝聚阶段极不稳定，稍一碰触便可能提前炸开，后果不堪设想。这也是绿魔洲先清洗整个丹海、确保万无一失后云空才出手的原因。
- **云空动机**：「我亲手凝聚出仙丹，以此炸开天牛壁障，这一点，足以名震仙罡。」

## 二、王林的伏击

- **隐匿条件**：丹海的**禁制阵法如今属于王林**，他在阵法内隐藏气息即无法被察觉，故绿魔洲清洗丹海后仍不知其存在。
- **出手**：万里外海底一处失水海草中气息骤然爆发，王林一步跨出，现身于云空那即将成型的百丈海水之外。
- **第一剑**：不假思索取出**血剑**，一斩——**目标不是云空，而是那百丈海水漩涡**。数万修士神识轰然凝聚，数百人化虹扑来，喝令「住手」。
- **云空应对**：他虽神识深融海中难以分神，仍猛然睁眼，咬破舌尖喷出一口鲜血化作剑影，硬接血剑。轰然对撞：王林嘴角溢血、血剑倒卷；云空面色苍白、血剑影崩溃。云空随即神识大范围收缩，只要完全抽离便可腾出身体牵制王林数息，届时数百长虹赶到，王林难逃。
- **王林的算计**：他谋而后动，连天空修士来临的时间都已算入。
  - 阵法被王林神识凝聚，数百修士**无法融入阵法**瞬移，只能飞行；
  - 待其临近不足数百丈，王林将阵法**由「只能进不能出」改为「能出不能进」**并大范围下沉，恰挡在众修士身前，令其连连后退（阵法虽现崩溃迹象，但王林要的只是时间）。
- **第二剑（真正杀机）**：王林身后现出**火本源真身**，一把抓住倒卷的血剑再度斩下，火海弥漫，与第一剑前后连贯——一剑穿透百丈海水漩涡，海漩骤停，不再旋转。

## 三、仙丹提前炸开与两洲之伤

- **毁灭气息扩散**：百丈海水被斩，散出「似可无数次毁天灭地」的毁灭气息，无视禁制阵法向八方传开。云空残留海中的神识被**重创**，喷血狂退——他此来是**分身**，分身若死、一道剑意崩溃，本尊亦受难以恢复的重创。
- **万修惊逃**：天空数万修士魂飞魄散，欲借阵法挪移，但阵法在王林手中，一个也走不了。
- **爆炸**：一声轰天之音传遍天牛、绿魔两洲，无数修士喷血耳鸣。云空绝望怒吼「我不会放过你」，随即百丈海水轰然炸开。
- **位置之变（本章核心转折）**：仙丹**本应**在靠近天牛洲处爆开，只崩天牛洲壁障并撼动其大地；因王林出手，改在**丹海正中间**炸开，**天牛洲与绿魔洲同时受创**。
- **后果清单**：
  - 云空（分身）距离太近，剑意再强亦无还手之力，**生生崩溃**；
  - 王林在毁灭之力吞来的刹那**提前一步消失**（正欲向天牛洲遁走）；
  - 大地层层瓦解全部轰开，露出下方**一片漆黑如星空的虚无**；
  - 丹海被毁灭之力笼罩而**消失**；
  - 毁灭之力几乎同时撞上天牛洲、绿魔洲两块大陆，**两洲壁垒（壁障）直接崩溃**，大地裂开、山峰倒塌。
- **异象收尾**：天牛洲上幻化出一头庞大无比的**巨牛虚影**，向绿魔洲方向无声咆哮；绿魔洲上则浮现一只**笼罩全洲的巨大绿色蝎子**，无声嘶鸣，与巨牛对吼。

## 四、要点提炼

1. 王林达成了「以敌之手段破敌之局」：不与四大天骄之一的云空正面斗法，而是斩其成果、借仙丹之威毁两洲壁障。
2. 胜负手在于**阵法归属**——王林掌阵法即掌隐匿、掌援兵抵达时间、掌全场逃生权。
3. 火本源真身承接倒卷血剑的第二剑，是全章真正的杀招设计。
4. 云空所失为分身与一道剑意，本尊未死但重创，「我不会放过你」埋下后续因果。
