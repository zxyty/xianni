# 第763章 半个元神的「报恩」与碎片大陆上的造化

## 一、老者截胡：以「相助」之名夺半元神半血身

### 识破神通
- 老者摸下巴细看那片血滴，一口道破：「这溶神化血之法，是老姚家的嫡系神通，今天可被老夫逮到了。」
- 他称王林是「老夫看中的有缘人」，赞其想出对付**净涅修士**的方法，遂决定「帮他一下」。

### 强行融合，坑掉血祖数境修为
- 老者大手一抓，所有血滴毫无反抗之力被擒；一捏之下瞬间融合，血祖元神刹那完成融合、苏醒。
- 血祖以神念致谢，语气平静无喜怒，并抬出「我姚家必有重谢」。
- 老者当面拆穿：「别装了，明明心底怕的要死……就算是姚家的**血神子**亲来，莫非老夫还能怕他不成」——一边拨弄坐下雷兽银角上的铁环。
- 老者「装傻」道：溶神化血神通不能强行融合，一旦如此修为会降低数个境界；「虽说你现在降至了**窥涅后期**，可我老人家不知道这点啊，你可怪不得我。」
- 血祖强压怒火，只求对方松开神通放其离去。

### 「现在就报恩」
- 老者抬手虚空一抓，生生把血祖元神从融合成片的血水中抽出，**一捏扯下一半元神**，又挥手**分走一半血水（半具血身）**。
- 自述用途：「老夫的大事，虽说一定会成功，但有了这姚家子孙的半个元神与血身，能多一分把握岂不能更好。」
- 随后把剩下半个元神打回血水、吹一口气：血水沸腾崩溃，化作无数血滴散开，血祖连一道神念都来不及散出便再次沉睡。
- 老者带雷兽扬长而去，看都不看那些血滴一眼。雷兽望向血祖时，一丝同情、更多幸灾乐祸。

## 二、虚无追杀：王林全力围杀血祖残身

### 红针异变
- 王林紧跟红针飞行时，红针忽然红芒大闪、气息暴涨，一举冲出王林的封印；随即更加黯淡虚弱，仿佛随时崩溃，直奔前方虚无。
- 王林咬牙：「必须要趁这个机会，杀了那血祖，以绝后患。」——此时他已忘却时日流逝，也忽略了肉身燃烧的痛楚正越来越弱。

### 血球现身
- 前方虚无中有十余个大小不一的血球相互环绕、正欲收拢；红针融入其中一个，该血球诡异蠕动并迅速吞噬旁边血球。

### 连环手段（出手顺序）
1. **山石之魂**：拍储物袋取出山石，抽魂后按出，血球颤动但力量不足，血球仍在急速融合。
2. **仙剑·斩罗诀**：一斩如电光，生生阻断其中两个正在融合的血球。
3. **雷霆之力**：元神内雷威爆发，道道雷霆疯狂冲击血球，毫无保留。
4. **仙剑再斩**：砰的一声击溃一个血球，虚无中传来惨哼；其余血球疯狂加速凝聚。
5. **定身术**：喝「定」，血祖元神太强定不住；王林全身仙力狂转、经脉剧痛，加之元神旧伤未曾静养，喷出一口鲜血，狰狞再喝「给我定」，血球仅停滞一刹那。
6. **因果昆极鞭 + 凌天候最后一道剑气**：因果昆极鞭蓦然出现狠抽，体内凌天候的最后一道剑气同时冲出，与无数雷霆凝作一股，在血祖苏醒的一刹那冲入血球。

### 结果：两败
- 凝聚的血球崩溃，分作两部：
  - 一部反卷血祖元神，以不可思议之速逃遁；
  - 一部倒卷冲向王林，弥漫其身、顺汗毛孔尽数钻入体内。
- 王林剧痛喷血，如遭大力撞击被抛出，消失于虚无，彻底昏迷。
- **许立国**操控仙剑卷起山石追去：他性格反叛，此刻第一个念头不是独自飞走、不是自由，而是追向王林并在其身边环绕同行。

## 三、祸变造化：肉身撞入碎片大陆，冲击阴虚

- 钻入王林体内的每一滴血中，都蕴含血祖无数年修炼所得的**庞大天地元力**，极为珍贵，本应是致其身亡的利剑。
- 隐患伏笔：当初索要雷兽的老者所喷那口气**无意中多出了很多**，将在王林肉身燃烧消失之刻爆发；届时王林很可能承受不住，连同元神一同崩溃。
- 血祖本意是「杀」，却无意间给了王林**自修道以来仅次于看到第三步方向的造化**。
- 王林身子轰然撞入雷之仙界一块**不由雷光炼铁连接、漂浮于虚无中的碎片大陆**，深入地下深处方止。（设定：雷之仙界并非所有碎片相互连接，过于微小者在虚无中漂游。）
- 昏迷中肉身迅速改变，元神被浓郁天地元力包裹，开始吸收，修为向**阴虚境界**迅速推动。
- 碎片陆地外的虚无中，本不应存在的**云层**幻化而出——与当年王林在**妖灵之地逆修问鼎**时的天劫云层一模一样。

## 四、血祖的处境与恨意

- 血祖血滴融合、元神苏醒，恢复意识，但身子没有实质，只是一片暗红血色。
- 自修道以来从未如此虚弱，虚弱到感到一股深深的寒意。
- 对王林的恨达到巅峰：「他从来没有这么恨过一个人，王林，是第一个。」
