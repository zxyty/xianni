# 第八卷 联盟隐秘 第1080章 不需她救（第三更）

## 一、场景与人物
- 地点：妖灵之地（此前剑之风暴已破开苍穹，浓郁天地之力大范围笼罩灌入）。
- 在场：天运子（持三叉戟）、昆虚圣女木冰眉（即柳眉）、昆虚之境老者「吕云道」、古魔塔珈、重伤的王林。

## 二、吕云道 vs 古魔塔珈
- 老者半空现身，天运子称其为「吕云道」，并质问「你昆虚之境，莫非也要参与进来不成」。
- 老者只答「老夫的目的，是他」，望向古魔塔珈时目露追忆。
- 古魔认出老者：「原来是你……没想到你竟然没死。」
- 老者自述：本该已死，幸得**青霖**当年援手；虽与青霖仇隙很深，但既受一次相救便欠一个人情，今日要在古魔身上还清。
- 塔珈掀起滔天黑雾化魔影、张口吞噬，二人陷入黑雾中激战，咆哮与轰鸣不绝。

## 三、木冰眉（柳眉）拦下天运子
### 对峙
- 木冰眉放下王林，飞身直奔天运子。
- 天运子：不愿与昆虚之境为敌，「这王林与你非亲非故，我要杀他，谁也无法阻止」。
- 木冰眉：「你没有资格杀他。」

### 神通展示
1. **八分身**：右手一挥化出一片虚幻之影，皆与其一模一样，共**八个分身**。
2. **灵虚锁元，炼天化气**：八分身同时掐诀，引天地之气化作元气之柱轰然降临。天运子以天运之术使元气柱颤抖，木冰眉直言「你的天运之术，对我无用」。
3. **七彩竹简**：虚空一抓凝聚天地之气化作竹简，展开后七彩光芒直冲云霄，无数印记飞出环绕全身，继而轰然散入天地——星空天地元力疯狂剧变，尽数向元气柱凝聚。
4. **封元**：「封，天运子一切外在元力。」天运子体外元力刹那被排斥殆尽；唯体内已炼化元力不受影响，天运之术自此在她身上完全无效。
5. **化剑**：玉指一点，支撑天地的元气柱缩为一把晶光闪烁的**短剑**；持剑身影如蝶，直扑天运子。天运子冷哼，三叉戟一扫化三道长虹迎击。

### 天运子口述的设定
- 历代昆虚圣女皆**传承于远古**；即便仙界存在之时，其身份也可与**仙宫齐平**。
- **四大仙界下有四大星域**，每个星域内各有一位圣女，属**远古仙域留下的一脉传承**，四位圣女所掌控能力各自不同。
- 天运子当年曾进入昆虚之境修炼，故早闻昆虚圣女传闻。
- 天运之术本质：一种与天地沟通之术，以沟通换取无形规则并为己所用——故一旦外在元力被封，此术即废。

## 四、木冰眉的心事
- 自始至终未再看王林一眼；面对这个「熟悉的陌生人」，她自己也在迷茫。
- 唯一确定：**无法眼睁睁看着王林死去**，无法在别人要杀王林时无动于衷。
- 心中另有一个「复杂的、让她心酸的念头」，徘徊已久；数年来常午夜打坐惊醒，独立昆虚之境最高山峰、望黑色苍穹，心酸滋生。为了这个念头，她更不会让任何人杀王林。
- 她不敢低头去看昏迷中的王林，唯有持剑冲向天运子来让心平静。

## 五、王林：燃星点，启青光盾
### 心境
- 醒来望见与天运子交战的木冰眉，目露浓浓复杂与无法磨灭的痛；每次想起柳眉，那种钻心之痛远超肉身伤害，忘不了**王平**身上的凄苦。
- 盘膝坐下，自认已是「神通的山穷水尽之境」，似再无神通可抗命运——「我，还有一样神通」。

### 青光盾的条件
- **青光盾**虽碎裂成二却未消失，内蕴**八星古神保命的一击**，威力不明但绝不弱。
- 此刻两半正在王林**右目**内迅速融合；即使不融合亦可施展，**前提是足够的古神之力**。
- 原计划（稳妥路）：分身与本尊分开，本尊沉寂、不断吸收，慢慢积攒古神之力，等离开妖灵之地后再办——太慢。
- 现被迫走捷径，而捷径必付代价，此代价王林必须承受。

### 决断与代价
- 「我，不需要她来救，更不想欠下此女之情。」
- 眉心**五颗古神星点**幻化而出、急速旋转，大量古神之力涌入右目融进青光盾。
- 代价：并未碎星，但第五颗星点先黯淡，接着第四、第三、第二，最终仅存的一颗也失去光泽——**五颗尽数黯淡**。文中留有余地：只要星点没有碎裂，就会有补充的一天。
- 结果：右目青光疯狂暴增，笼罩方圆千丈，连斗法中的木冰眉与天运子都注意到这诡异青光；青光如利剑冲天，其目光所落之处——被天运子神通掀起冲入云霄的**百里地面**——轰然坍塌。

## 六、悬念
- 青光盾（八星古神保命一击）尚未正式发动，古神之力刚刚灌注完毕。
- 木冰眉与天运子胜负未分；吕云道与古魔塔珈仍在黑雾中缠斗。
- 木冰眉心底那个「心酸的念头」始终未点明。
