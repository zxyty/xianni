# 《仙逆》第七卷 名震罗天 第833章 苏醒

## 一句话概括
王林在望月体内斩断关键红线，令这头伪装成修真星的远古凶兽彻底苏醒暴走，罗天北域群修陷入灭顶之灾。

## 场景一：望月体内——无人能逃
- 一声冲击元神的低语（承前文）传出，星外修士感受尚浅，**已进入望月体内的修士首当其冲**，包括姚家族人与其他修真家族之人，灵魂深处恐惧疯长。
- 众人第一反应是冲出体外，但地面上**无数摇曳的触手**骤然缠绕而来，形成紧密封锁；触手更散出黑雾弥漫，**没有一人能够离开**。
- 触手特性：**一切神通与法宝在其上全部失效**。有修士冲出之际被缠住，肉身被直接勒碎，元神一碰即被吸收。此幕令四周修士骇然。

## 场景二：姚冰云的发现
- 姚冰云以**冰遁**现身望月体内，一现身即喷出黑血、面色发青，脸上似有黑线游走；再喷一口，血色更黑。
- 病因：冰遁刹那被**黑风**吹袭，身子发寒（以她所修神通本不该有寒冷感）。黑风入体虽驱除大半，仍余一丝**始终无法驱散**，导致身体持续处于寒冷虚弱状态，更可怕的是**元力出现消散迹象**。
- 她直奔地面欲冲出，见无数触须横扫，半空无人能逃。
- **关键认知**：以其聪颖，立刻认出这些触须与此前攻击自己的那头奇异凶兽体外之须**一模一样**——她瞳孔骤缩、头皮发麻，确认「北域修士所说是真：**这修真星，就是我之前所遇凶兽放大了无数倍之后的样子**」。

## 场景三：王林撕断红线，望月苏醒
- 王林身处遍布红色丝线之处，**双手斩罗诀**不断施展，一根根红线崩溃；**每断一条，望月的震动便加剧一分**。
- 他横冲直撞、渐渐深入红线内部，越往里红线越密。
- 转折点：前方出现一根**一人多粗**、超过此前所见一切的巨型红线交错延伸。王林眼中寒光一闪，毫不犹豫冲出，双手抓住狠狠一撕——
- **红线被撕断**，望月体内回荡一声疯狂怒吼。大地大片崩溃化作尘埃，修真星中间裂开巨大缝隙，渐渐展开，**化作一头椭圆形的庞然大物**。沧桑与愤怒之气弥漫四周。
- **望月，苏醒。**
- 王林反应：苏醒刹那立刻**收紧全身气息、迅速隐藏身形**，在望月体内**盘膝坐下**，神情警惕。

## 场景四：望月之怒
- 一声咆哮如风暴、如万雷齐鸣，形成大片音爆散开；不论修为高低，所有修士面对望月都升起无法抵抗的恐惧，纷纷退后。
- 万丈长的巨大触须缓缓伸开在体外摇曳，头部慢慢裂开一个巨大裂口。
- **望月的心态**：体内痛楚并不严重，只够将其唤醒；它真正愤怒的是**这次沉睡这么快就被打扰**——几十年对它而言与眨眼无异，主观上「刚刚睡下就被弄醒」，因而极为暴躁。
- 它见弱小生命欲退，口中再发咆哮，**强上无数倍**：四周星空立刻大片碎裂、无数裂缝**弥漫整个罗天北域**；部分修士肉身当场震爆，**元神都无法逃出便告崩溃**。
- 章末：望月身躯一动（于它只是动了动身子），在前方修士看来却是庞大凶兽带着剧烈呼啸撞来，众人瞳孔猛缩。

## 群修反应与舆论
- 「这修真星，居然真的是一头凶兽所化，此物我们怎么可能杀之」
- 「此兽定然是早在**仙界没崩溃前**就存在之物」
- 「那**许木**把我们引到这里，是**借刀杀人**」——直指王林化名，王林的谋划已被部分修士看破。
- 「此兽决不可抵抗，速退」——在众人看来，**除非有第二步的巅峰修为，否则根本无法抵抗**；一大半修士毫不犹豫后撤。

## 归属说明
- 本片段中的「许木」即**王林**的自创化名（自第661/669/711/731/771章沿用），群修口中的「许木借刀杀人」应归到王林名下。
- 「望月」在本章确认为凶兽（beast），此前伪装/被认作修真星。
