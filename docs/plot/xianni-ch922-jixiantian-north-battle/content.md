# 第八卷 联盟隐秘 第922章 极贤天

## 一、望月受古神之语驱使，开道破封锁

- 古神之语内容：**“继续前行，毁了雨之下界星域后，我送你肉身助你脱困”**。望月双目迷茫褪去、恢复清醒，咆哮平息，一冲超越参天巨木，直奔前方。
- 望月庞大身躯、万丈触手如无边阴云笼罩星空；沿途遇联盟修士，触须一缠即令其萎缩成干尸，肉身落下后罗天修士飞去取储物袋与法宝。
- 望月在前、参天巨木在后，速度堪比瞬移、音爆不断，直奔**联盟北部**。

## 二、王林（化名许木）与两位老怪的周旋

- **烈云子起疑**：玉简碎裂发声后王林神色有变。王林修道千年、心机深沉，苦笑托辞：“此兽如此记仇，我当年只是借它躲避**姚家**追杀而已。”蒙混过关。
- 烈云子叮嘱：此番交战告一段落后，前去观看其余几幅**战字图**。王林恭敬应下。
- **申公老祖**开口索要“申公虎的道念”。王林沉默片刻后不假思索，右手一拍眉心，道念飞出被其抓取查看后收入体内，此后背手前视、不再理会王林。
- 结尾：王林望向望月，眼中微不可查地闪过寒光，心念**“古神幼子”**——伏笔指向望月的真实来历。

## 三、联盟北部战局

### 战前态势

- 联盟修士在**黑煞魔尊**（修真联盟四尊之一）带领下大占优势：毁掉西部星域、致大量罗天修士身亡，并隔绝退路，使冲入北部的罗天修士成为孤军。此为两域第一战联盟胜率最高之时。
- **转折两点**：①炎雷子以**十八罗浮**绝地反击，联盟修士受罗浮影响；②参天巨木打破联盟西部隔绝，罗天不再是孤军，只需坚持到后援便可占优。

### 高端战场

| 对阵 | 状况 |
| --- | --- |
| 黑煞魔尊 vs 血神子（血祖） | 血神子修为极高，二人斗法惊天动地，波及者立死；黑煞魔尊化腥风为巨鲸吞吸天地元气反击 |
| 云龙妖尊 vs 三名仙界传承家族老祖 | 云龙妖尊自紫色光柱降临，中年黄袍、相貌俊朗，身外幻化两条巨龙，自称“新晋联盟尊者”；炎雷子未出手，三名老祖同时踏出迎击 |
| 炎雷子 vs 极贤天 | 本章核心对决，见下 |

### 炎雷子的敌情判断

- 修真联盟四尊**均为碎涅中期**；血神子修为莫测，可与之一战；其余三尊修为**碎涅初期**，需联手方可勉强。
- 关键判断：**“这些人均都不是此战的最强者”**——四尊向来不单独出手，遂点名喝出隐藏者**极贤天**。

### 极贤天出场

- 炎雷子迈步至十八罗浮血球旁，双指前点；星空龟裂，裂缝中探出一只洁白如玉的手掌与之隔空相碰，砰然一震，双方各退。
- 极贤天尖啸：“炎雷子，你还有脸回来”——声波蕴含恐怖元力，罗天修士剧震、部分喷血身亡、元力脱体，并直接震溃**十八罗浮中的一个**；崩溃修士与罗浮溢出的天地元气尽数被其吸入。此后罗浮为**十七**。
- 外貌真相：看似千娇百媚的女子，实则胸部平平、咽喉有结，**乃是男子**。炎雷子讥讽：“多年不见，你还是如当年一样不男不女。”
- 旧怨：极贤天称**数万年前一战**让炎雷子逃掉，今日**不用重玄子出面**，自己即可斩杀他。
- 炎雷子誓言重申：“老夫当年离开曾说，若有一日回来，定让修真联盟灭绝，哪管我死后，血水滔天。”
- 对峙形态：极贤天寒气涌现、咔咔声中万丈冰川如剑刺天；炎雷子火焰滔天映照半个星空，虚空一抓凝出白色火球，冰火分庭抗礼。

### 乱战与罗浮吞噬

- 炎雷子大袖一甩化出火海，推力将罗天修士推开万丈（仍在罗浮范围内），双方数万修士随即陷入生死乱战。
- 罗天一方本非联盟对手（一方惊魂未定、一方蓄势以待），在罗浮作用下归于平衡，联盟仅于细微处占优。
- 每有修士身亡，血液上涌飞入十七罗浮血球，受损元神亦被吸扯；星空遍布裂缝、阴寒之风吹出仍难熄战火，罗浮血球愈发妖异。

## 四、伏笔与看点

1. **望月＝古神幼子**（王林的判断），其“脱困”与“肉身”交易是古神布局的一环。
2. 雨之下界星域被指定为下一个毁灭目标。
3. 极贤天之上仍有**重玄子**，暗示联盟真正底牌未出。
4. 王林交还申公虎道念，与申公老祖的关系再度微妙。
