# 第1614章 因果印

## 一、梦醒（漆黑虚无·血光内）

- 漆黑虚无中，血光数十年来一闪一闪，光芒隐隐黯淡，仿佛不久便会彻底消失。此地时光无人知晓、无人来临，唯有死寂。
- 血光内两具尸体之一的**白发青年**（王林）终于睁开双眼。
- 睁眼刹那，虚无中雷霆轰鸣骤起并迅速攀至巅峰，无数银蛇（闪电）交错游走，如巨大电网笼罩无尽虚无；同时一股**九色火焰风暴**轰然而出，旋转中**九色归一**，以王林为中心横扫扩散，与上方雷电争辉。
- 雷、电、火如同迎接其君王苏醒——这君王即王林。
- 苏醒时形貌：**左目火焰，右目闪电**，神色透出明悟，明悟中却藏着梦醒的悲哀。

### 梦的性质
- 这一梦历时**七十多年**；对王林而言已非梦，而是另一种人生。
- 该人生为其自己编造：**模仿骗道之术，把自己欺骗**（梦道方式）。
- 苏醒瞬间眼中尚有迷茫残留；其**左手抓着身边「疯子」的右手腕**，在那里留下一个**金色手印**。
- 许久后迷茫被强行挥散，代之以冰冷、坚定与无尽杀机。

### 苏醒宣言
- 「掌尊，虚神天尊，还有那几个仙妃……我王林，苏醒了」——点名复仇目标。
- 「我王林修道**两千多年**，今日，要破开**空门**，成为修道**第三步·大能**。」

## 二、凝雷之本源

- 王林右手一指，唤「雷之本源」。
- 虚无内所有闪电雷霆尽数凝聚，化作**一道不灭之雷**，临近并漂浮于血光外；王林**右目内的闪电印记**飞出，与不灭之雷融合。
- 成形为**天地本源之雷霆闪电不灭印记**：一个雷印，外有**九道伴随之雷旋转九圈**后与之融合，化为本源雷霆。
- 威能：印记散出的雷力足以轰开天地，虚空欲崩、涟漪扩散使虚无扭曲失真；**仅此一道雷，便足以撼动第三步空涅初期大能**。能操控此雷威者，便是**雷仙**。
- 形态：融合伴随之雷后失去闪电之形，化作**一团无色混沌之气**——即天地初开、混沌之中最终繁衍出雷霆闪电的本源之气，绕血光缓缓旋转。

## 三、凝火之本源

- 王林再一指，唤「火之本源」，声带沧桑与寒意。
- 四周无尽火海倒卷，**九色归一**成为**虚火**；虚火中蕴含**道念**而生，遂超越虚火，成为**道火**，爆发火之本源大威气息。
- 所有火焰凝为**一缕由无数火苗组成的火焰图腾**，立于王林身前：乍看似有实质，实则虚幻不定、模糊扭曲，气息缭绕；其高温**足以焚烧第三步空涅初期大能**。

### 雷火合评
- 雷、火两道本源彻底大成，**足以让王林轰开空门**，并**轰杀空涅境界中除后期圆满之外的一切修士**。

## 四、自创第四神通·因果印

- 王林道「因果，现」，眼中寒意消散、露出追忆之色。
- 其身上弥漫出**从未有过、只在梦中存在的浩荡大儒之气**。
  - 此气绝非修士可拥有；即便当代大儒，修道之后在弱肉强食中也都改变了自己、忘却了曾经的明悟天地，无人能保留此气至生命结束。
  - 唯独王林以**梦道**的方式，在苏醒一刻把梦中的自己感悟天地后所得、足以惊退鬼神的浩荡之气存于心中，随「因果」二字轰然爆发。
- **因果本源**无形无影，凝聚于王林**右手**中：**掌开为因，掌握为果**。
- 此右掌自今日起，成为王林一生的**第四道自创神通——因果印**。
