# 第八卷 联盟隐秘 第1005章 花仙

## 一、场景与前情
- 地点：剑尊凌天候的仙府，众人已过石桥抵达**仙府内环**（内环四座阁楼环绕一座大殿）。
- 浮风子转述旧闻：当年凌天候得知此仙府所在有**仙魂**把守，费了很大功夫将仙魂斩杀，方才打通并占据这座仙府。
- 王林目光一闪，不假思索踏出石桥走近内环，触发花海机关。

## 二、花海之毒：雨后毒香与花灵
- 王林临近刹那，前方无尽花海蓦然一动，奇异芳香扑面而来，香极浓且**蕴含异毒**。
- 浮风子据仙界典籍（其中一卷讲**雨之仙界的毒攻之术**，将天下之毒排出前一百）辨识：
  - **雨后毒香**：花朵搭配种植后自然而出之毒，榜列**第九十三**。闻之修为不顺，多闻几口甚至可直接废去一身修为。
  - **花灵**：同为花朵搭配自然而出之毒，榜列**第四十九**。
  - **花仙**：花灵融合后有机会酝化而出，**并非仙人**，而是拥有灵性、可幻化人形的毒，榜列**第十**。
- 尘道三子面色微变却不退（窥涅修士有所持防）；王林挥手放出怪风横扫，花毒却无形无体，未被吹散。

## 三、银尸破毒：以毒制毒
- 王林平淡唤出「**银尸**」，银衣女子越过尘道三子直扑花香。
- **祭炼所得认知**：银尸并非以神通惊人，法宝也仅是元神中一把奇异**剪刀**；其真正厉害之处是**毒**——体内毒素种类繁多、相互融合可化作种种可怕毒素，实为一具**毒尸**，配合**净涅初期**修为催化毒素。当年抢夺重伤银尸的修士被吸尽修为、血肉被吞噬成皮包骨，王林此前误判为神通。若非王林有**古神肉身**，也不愿招惹这样的毒尸。
- 银尸踏入花毒毫无所伤，张口如漩涡猛吸，无形花香显形为烟丝絮状之气涌入其口；其面色由雪白转为红润，与活人无异。

## 四、葬地真相：药人女童与怨
- 王林注意力不在银尸，而在诡异的花朵上。随后一朵花爆出浓郁絮丝，幻化出赤身抱膝、高高抬头的少女；随即满地花朵尽数幻出少女。
- 每朵花下泥土中埋着**细弱骸骨**——所谓花海，**分明是一片葬地**。
- 浮风子苦笑解说其手笔：「**葬仙成灵，以灵润花，自成花仙**」。花灵取自凡间女童，多年服食独特药物成为**药人**，集体葬于一处以特殊方法催化，若干年后成为花海，诸灵融合有机会酝化出花仙。
- 当年仙界视花仙为极珍贵的毒物，因其可变化外表，常被仙人买来**看守洞府**或作**喜乐之物**。
- 尘道三子与大头沉默——非出于怜悯，而是被**当年仙界的残忍**震惊。

## 五、王林的仙界观（内心）
- 王林神色阴沉却无惊容：自学会「**呼风唤雨撒豆成兵**」后，他已明白仙界绝非理想中的宁祥。
- 佐证：**仙帝白凡**能自创近乎魔道的仙术（血神子当年评：「这哪里是什么仙术，这分明就是魔攻」）；**青霖**玉简中的傀儡之法同样霸道，**生炼活人**。
- 结论：**修真所在之处，没有乐土，即便是仙界也同样如此。**

## 六、花灵反扑与仙兵出动
- 花灵少女神色麻木，双目幽光中压着长年累月浓郁的**怨**；它们环绕银尸爆发滔天怨气冲击，缠绕拉扯欲将其同化。
- 银尸本是尸体，张口吐出**白雾**，触雾花灵纷纷一颤后融入雾中消失；白雾扩散几乎遮盖仙府上方，地面花海渐渐枯萎。
- 大殿深处传出**尖锐厉啸**，地面一震，殿外**十尊玄金仙兵**化作十道金光冲天，欲阻止银尸吸收。
- **仙兵战力**：几乎每尊都有不弱于**阳实巅峰**的修为，身体坚硬可怕、不知疼痛，挥手金光蕴含神通之术，足以与**窥涅**一战。

## 八、悬念
- 花海虽枯，典籍所载真正的「**花仙**」（毒榜第十）是否存在于此仙府尚未揭晓。
- 内环大殿深处发出厉啸者身份未明。
