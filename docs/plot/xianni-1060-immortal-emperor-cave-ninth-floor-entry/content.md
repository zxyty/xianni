# 第1060章（第八卷 联盟隐秘）剧情梳理

## 一、前行与戒备
- 王林以一掌开出通路后言辞简练地下令“走”，内心却极不平静：他感觉这一掌只发挥了极小部分，**若全力施为可一掌击碎仙帝洞府一至九层**。
- 凌天候紧随其后，忌惮更深。他自认修为或许高于王林，但**真要厮杀自认必败无疑**；一生只对天运子用过“高深莫测”，如今又多了王林一人。
- 王林途中冷冷回望凌天候，吞下大把仙丹（**未用王巍所赠蜡丸**）补充元力——这一掌的元力流失不弱于施展铁剑。
- 一拍储物袋放出**银衣女子（女尸）**立于身侧，冰冷目光扫过凌天候，令其瞳孔再缩。

## 二、朱雀图腾的发现
- 王林刚自岩浆离开，体内除本身运转的火元力外尚有大量游离元力，数月吐纳中身上的**朱雀图腾**也吸收了不少。
- 关键发现：**朱雀图腾所吸收的火元力可以流转回王林体内**——这正是他在岩浆内滞留数月的原因。
- 本次恢复未动用图腾内火元力，仅靠吸收体内游离之力加丹药，略作恢复。

## 三、残殿见闻与凌天候的复述
抵达中心位置被毁去一半的巨大宫殿，殿内空无一人，唯烛台上一点烛火仍在挣扎燃烧。凌天候复述此前经过：
- 一行人自**第七层**进入此地时并无黑雾；
- 在大殿内**打开通往第九层入口的瞬间，三道魔影自入口冲出**，此地立刻充满黑雾，视线受阻、神识无法穿透；
- **虚空子**瞬间被重伤；
- **王巍**遭**贝罗**突然偷袭而厮杀，**天运子出手相助贝罗**；
- **胡娟**未及出手便被吸入第九层；
- **凌天候**本人亦被一只魔影所伤。

## 四、王林的推断（暗线）
- 天运子帮贝罗并不意外：妖灵之地天运子来过不下数次，与**古妖**必有联系。
- 佐证：当年在天运宗，紫系大师兄曾施展类似妖术的神通，王林记忆深刻，日后接触愈多愈确定此猜测。
- 更关键的一环：王林在妖灵之地所得的那具**散魔肉身，赫然就是年轻许多的凌天候**，此肉身现仍在王林储物袋内。王林相信一旦取出，凌天候必面色大变，天运子恐怕神色亦有变化。
- 结论：**古魔、古妖、天运子、凌天候之间必有诡异联系**。王林不动声色，只在那唯一燃烧的烛火上多看了一眼。

## 五、必下第九层的理由
- **周佚**在第九层；**司徒南**解毒的希望也在第九层。二人皆是王林生命中的恩人。
- 王林明知第九层危机，仍称“若因危机而放弃，王林就枉自为人了”。司徒南虽未进洞府，但以其修为在前几层绝无危险。

## 六、开启第九层
- 凌天候犹豫后眼露疯狂：**爱兽为魔物所毁**，一生所修**霸道意境**，加之“天运子敢入内，老夫还怕什么”，遂决意同行。
- 他按记忆中**胡娟**开启的方法拨弄地面烛台数下：**九十九个烛台**轰隆隆移动，摆成巨大阵法，幽光剧烈闪耀，现出**虚幻光圈**，浓浓黑雾自光圈疯狂散出。
- 凌天候率先冲入，王林收起银衣女尸后踏入光圈。

## 七、第九层内的战局
- 第九层内不大，除中间宫殿外再无他物；宫殿与前八层一模一样。
- 殿中椅上的**黑雾身影**蓦然抬头，双目挣扎，**眉心仅剩一个光点**，四周无尽黑气不断冲击，仿若要将光点吞噬。
- 殿外众人几乎全在，均都带伤，被无数嗜血魔影环绕缠斗；魔影不散，被逼急者直接崩溃形成毁灭性冲击向四周扩散。
  - **虚空子**面色苍白，喷出一口黑血，连点身前压制伤势；
  - 其旁**黑衣人**面无血色盘膝打坐，双眼死盯前方；
  - **天运子**大袖横扫，每次皆有惊天神通幻化，破开冲来的魔影；
  - **王巍**神色阴沉、水幕滔天疯狂进攻，疯狂之因有二：师尊**青霖**与**胡娟**（胡娟开启第九层后被吸入，导致王巍分神，才给了贝罗偷袭机会；天运子相助致王巍受伤，但王巍丹药太多，服食后不恋战而冲入第九层寻胡娟）；
  - **贝罗**全身妖气纵横化冲天妖焰，妖气内幻化出近乎实质的**古妖虚影**，抬手即神通；
  - **葫芦老者**施展神通化作无数法术直奔黑雾；
  - **周佚**身子更为虚弱、目透焦急——他身为**灵体**，在魔气不断渗透下已难抵抗。

## 八、塔珈的宣告与章末一击
- 贝罗大吼：“塔珈，你这魔影最为消耗魔力，我倒要看看，你还要多少可以消耗”。
- 回答是一道令四周所有人心神冰寒、飘渺虚无且蕴含魔威的沙哑声音：**“贝罗，待本魔完成了最后的夺舍，你就会知道，现在的我，有多少魔力”**。
- 王巍闻言双眼一红，掐诀化出一片蓝色，转眼成滔滔大海弥漫天空，一声低吼下自天而降，直奔殿外黑雾。
- 王林与凌天候恰在此时抵达，正见这前所未有的激烈之战。**天运子目露奇异之芒，右手一指天空低吟“天运一指”**，王巍神通所化的满天海水中现出磅礴漩涡，威压从天而降，一根巨大手指自海水内伸出，狠狠戳向下方被黑雾弥漫的宫殿。

## 九、悬念
- 塔珈所谓“最后的夺舍”对象、殿内眉心仅剩一光点的黑雾身影身份、胡娟下落，以及王林如何救出周佚、取得司徒南解毒之物，皆未揭晓。
