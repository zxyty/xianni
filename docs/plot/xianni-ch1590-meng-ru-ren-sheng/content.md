# 第1590章 梦如人生

## 一、场景：赵国官道旁的客栈

- 清晨阳光柔和，卷云透橘红，客栈炊烟与犬吠交织，一派凡尘人间气息。
- 数匹骏马载着身穿锦袍、神色严肃的大汉自官道疾驰而过，尘土掀起，地面震颤，带得老旧客栈嘎吱作响、二楼客房传出惊呼。
- 大厅角落里穿粗布小衫、手拿烟枪的老者（店家）安抚道：老夫这店在这里有了上百年，每次急马过去都会这样，塌不了。
- 小伙计肩搭毛巾、提烧开的水壶上楼，为各客房送热水。

## 二、宿醉醒来的书生「王林」

> 归属提示：本章为凡俗人间视角的一段「梦/人生」叙事，青年书生自报姓王、文末点名为「王林」。其经历与主角王林的仙途形成互文（梦中成仙、三年前四叔来时入恒岳派，正对应王林入恒岳派的起点），但本章文本呈现的是凡人书生的日常，未直接说明二者关系。

- 二楼右侧最末客房内满室酒气，青年和衣斜躺，被马蹄震动惊醒，头痛眩晕，连饮凉茶方缓。
- 自省：「贪杯误事」「以后要切记，莫要酒醉」，昨夜近乎不省人事，若遇歹人，丢银两事小、性命事大。
- 形貌：约十岁（原文表述），身子修长，相貌平凡，一股书卷之气；衣衫干净整齐，朝气蓬勃，令人生好感。
- 出身：山村长大，自幼聪明而性子淳朴，第一次走出家门，在父母慈祥注视与谆谆叮嘱中离乡，如雏鸟展翅。

## 三、伙计的调侃与「梦里成了仙人」

- 伙计送热水时笑言：我在这里做了三年伙计，从未见过有人喝我家米酒两杯就醉成这样；昨夜怎么推你都不成，是我把你背到这里歇息。
- 伙计临走戏谑：你是去县里赶考的书生吧，昨夜拉着我不断地说你做了个梦，梦里你成了仙人，挺好玩的，有时间再说说。
- 青年面红苦笑，向伙计抱拳道谢，自称「王某」，说第一杯还觉无碍，第二杯入腹便醉倒。

## 四、梦的内容与「引力术」试法

- 推窗自语：昨夜醉后做的梦很奇怪，醒来一点都没有淡忘，很真实，几乎让人分不清。
- 梦的起点：**三年前四叔来时**；梦中他**加入了恒岳派**。
- 梦未做完：只记得加入恒岳派，后面的就没有了。
- 理性否定：「恒岳派」这天地间怎会有这样的门派，又哪里来的仙人；我辈读书人不信鬼神之力，大都是谣传愚弄百姓。
- 少年心性发作：按记忆中的样子掐出印决，一指茶杯，喝「引力术」——茶杯一动不动，遂笑叹「这些法术神通很有意思」。

## 五、启程赶考

- 收拾行装：银两、干粮、衣衫、笔墨书籍俱在；仔细打扫房间、吹散酒气、换干净衣衫，不好意思让背他上楼的伙计代劳。
- 一楼简单用食、结清住宿账目，向伙计含笑抱拳，迎着阳光离去。
- 立志：「王林，你一定能行的待金榜题名时，把爹娘从山村里接出，伺候他们终老，让他们享享福。」
- 望向官道尽头，眼前隐隐可见那遥远的**赵国都城**。

## 六、途中：山云之斗与雨中吟诗

- 赵国有几条官道与水道同行，王林所行即是：左侧山峦弥漫，右侧不远是曲带般的河道，几艘船只顺流而走。
- 天色骤变：乌云凝聚、雷鸣闪电如银蛇；远望青山欲冲碎乌云、乌云欲吞噬山峦，如龙虎之斗。
- 大雨落下，王林自竹排书箱取出**父亲巧手做的大油伞**（可折叠存放，完全撑开可同时罩住书箱与人身）。
- 见雨珠溅上水面船只，朗声吟道：「古语曾有，黑云翻墨未遮山，白雨跳珠乱入船——果然如此。」
- 河道近岸船头一撑伞俏丽少女气闷瞪眼、玉手相指：「你这书生，莫非傻了不成，看见我家船只（浇）了雨水，还在那里哈哈大笑，实在是气人。」王林一愣，笑声戛然而止，挠头。

## 要点与悬念

- 「梦如人生」标题与内容互为镜像：凡俗书生梦见自己成仙，恰与主角王林由凡入道的起点（三年前四叔来时、加入恒岳派）重合，指向本书「虚幻/轮回」母题。
- 悬念：此凡俗书生与真正的王林是何关系（梦、心魔、幻境、重历人生抑或另一世），本章未作交代。
