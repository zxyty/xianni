# 第九卷 云海之巅 第1274章 色变（第三更，补欠）

> 归属说明：本章主角王林在云海星域以化名『吕子浩』立足（自第1063章由吕烟菲奉上），本章正面交战中以王林之名被叙述，言行均归【王林】。

## 一、开篇设定铺陈：第三步之威

- 第三步大能杀一个碎涅修士，竟在其剑气下留下小小伤口——此事若传出，王林之名足以震惊界内界外。
- 第三步是传说中的大能者，整个封界极为罕见，界外亦罕见至极；能修到第三步，足以横扫天地，就连天都敢一战，是所有修士中的皇者。
- 层级对比：碎涅修士可为一宗掌教，天人衰劫更可成太上长老；但在第三步眼中，这些仍是可随意杀死的蝼蚁。
- 假设推演：若王林此刻已是第三步，水道子必极为谨慎，甚至根本不会交战，而是奉王林为上宾、以利益换取各自所需答案；且无论联盟、云海、罗天皆可横扫，连鲁夫子也要客客气气、轻易不挑起战端。
- 主题句：实力就是一切，是在残酷修真界生存的根本。

## 二、水道子本体降临

- 苍老声音回荡如雷：“还是小看了你这小小蝼蚁，但你越是这样，老夫就越要杀你。”巨大手掌收回星雾，雾中走出一个**身穿道袍的童子**：一头白发、容颜白皙明净、目光森然。
- 关键设定：第三步修士**很少以本体出动**，寻常之战多是融入天地、于任意一处幻化分神而来；**唯有第三步大能之间的生死战才以本体出动**。
- 水道子竟以本体亲至 → 说明其杀王林之心极为迫切，也说明王林在其心中的重要与他的谨慎。
- 他真正担心的是两件事：
  1. 王林真为**其主转世重修**；
  2. 王林身上**确有天逆至宝**。

## 三、王林的心境：置之死地

- 王林等的就是对方露出真身这一刻，本体现身刹那双眼杀机爆闪。
- 内心决断：今日之战**绝不能去想推衍出的那一线生机**——心中有依托便失去锐气与逆意，如此必死无疑；唯有置之死地、抛却一切生机，拼出一个明日。
- 神色狰狞疯狂，斩断一切后退之路，把自己逼到绝地（而白发童子到来时，他实际已处绝地）。

## 四、交手三段

### 第一段：血色符箓 vs 大自在崩溃道

- 王林升空迎战，四周近百蛮荒大陆轰然而动，其上血光弥漫，涌出**无尽血色符箓**，密密麻麻无法计数。
- 符箓来历：每一道皆由**一头凶兽全身血液精华**凝聚而成，且内含**云海凶兽特有的道魂**，威力远超从其他星域炼化者。
- 水道子评：“你还会**符族之术**，不过这等符族神通，对老夫无用。”随手一挥，施展**「大自在崩溃道」**——声如天神怒吼，一切血色符文与之无形碰撞即崩溃，无法近身。
- 余波：整个**五阶星域**剧烈颤抖，一道巨大裂缝被生生撕开，**把五阶星域一分为二**。
- 王林反手掐诀喷出妖异鲜血，施「**符箓化血**」，吸尽崩溃符箓中的血光化作血球破开一切神通直取水道子——血球临近即崩溃；水道子抓下**一滴王林血液吞入口中**，双目骤闪，得出结论：“**不是转世**。”

### 第二段：禁道三禁归一（借血染魂）

- 王林早料到符箓必崩：千万剑气只是出其不意才伤其一分，第三步神通之下一切法术皆崩，血色符箓本身也是法术。但**他要的正是这样**——借符箓崩溃染红天地。
- 关键设定：**禁制不属于法术**，而是**太古天地初开气息所化，自成一道**；王林将三大禁制融合，几乎无限追溯禁道本源。
- 三禁归一喝令：“破灭禁封天地、生死禁封身、岁月禁封神——封你所在天地，封你肉身之力，封你元神之威。”
  - **破灭禁**：环绕天地，形成巨大困牢、封锁；
  - **生死禁**：化两道生死气息一前一后笼罩其肉身，成生死禁；
  - **岁月禁**：在王林的**流月神通**下**逆转五千年**而出，沧桑气息笼罩其元神。
- 近百蛮荒大陆在禁制下急速缩小，结成圆形阵法向水道子收缩。
- 水道子讥评：“三大禁术，可惜没有第四道禁术。”再挥一手，将大自在崩溃道推至巅峰，形成天地万灵的崩溃之幕——上百蛮荒大陆同时崩灭（此等威力唯第三步可为）。
- 但大陆虽灭，其上三大禁制骤然**吸收天地间血色符箓消散留下的血光**，环绕八方将白发童子彻底封入其内。
- 缺陷与破法：三禁能封天地、封肉身、封元神，**唯独无法封魂**（缺第四道禁制、无法真正归一）；王林以大智慧借无尽凶兽血光**染魂**，使禁制获得**畸形的圆满**。

### 第三段：一滞与射神车

- 水道子不再施法，**强行而走**：修至第三步一身规则已满，**所在之处便是规则**，一切神通不可阻步，天地为其诞路。
- 三禁依次瓦解：**岁月禁**先崩（不能封元神）→ **生死禁**瓦解（不能困身）→ **破灭禁**消散（不能封天地）。
- 但因禁制**不属法术、不属规则**，白发童子的身子出现了**一刹那的停滞**——这正是王林所等的一滞。
- 王林瞳孔收缩、头发散乱、双目血红，怒吼“**射神车**”：
  - 雷兽所化射神车上**万丈长矛**轰然而动，化长虹直取水道子，冲出时又划开一道裂缝、把五阶星域分开；
  - 长矛之后，**百丈大小的七彩战车**七根利刺骤闪，凝成一道彩虹蓦然冲出。
- 定性：这一刻**一切规则在两辆射神车面前全部崩溃**，规则无法阻止、天地无法阻止、没有任何力量可以阻止——这才是射神车能射下天空神灵的战车之威。
- **结局：水道子的面色，第一次，变了。**（章末，标题「色变」所指）
