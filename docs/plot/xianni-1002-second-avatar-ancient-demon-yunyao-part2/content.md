# 第八卷 联盟隐秘 第1002章 第二分身（下）

## 一、云妖妖识的流亡与「变成王林」的来历

### 逃亡
- 云妖自述：只要再给百年时间便可完成分妖，可惜分出的妖识太少；**本体被吞**后，这一丝妖识形同无根之木，随时消散。
- 云妖郡已崩溃、妖塔不再，无法停留；其他妖郡他又不敢轻易进入吸收妖力。
- 飞行本身即在损耗妖识，到最后几近崩溃，**记忆开始模糊**，处于消散之中。

### 坠入炼魂部落
- 濒灭之际，他感受到地面弥漫的一股妖力——下方正是**炼魂部落**。
- 当时炼魂部落族人仅数十万，大部分分散在外寻找拥有魂魄之地，留在部落者不足数万。
- 族人神色狂热，膜拜正中央一尊**粗糙的黑色石像**，阵阵淡淡妖气自天灵散出。
- 妖识几乎是下意识地直冲石像，融入刹那，石像便如活了一般，四周妖气立刻凝聚而来。

### 被信仰改写身份
- 妖识在石像内渐渐沉寂，逃遁中流失的记忆太多，认知模糊。
- 他本非本体，只是一丝微弱妖识；所吸收的膜拜妖力中，**大多充斥着一个叫做「王林」之人的身影**。
- 初时尚有抵触。当部落人数达**百万以上**，日日膜拜之下，他渐渐认为自己就叫王林、是这些人的老祖。
- 如此度过**数百年**，部落已有数百万人，他彻底遗弃过去，**真正认定自己就是王林**。
- 随之而变的还有石像：样貌渐渐变成了王林的相貌，他也在石像体内「变成」了王林。

## 二、王林的判断与「三分身·返祖成古」构想

- 王林抬手望着与自己一模一样的古妖，结合先前猜测，理清了整件事。
- 决断：「如此自己送上门来的古妖，不要的话未免太过可惜……现在就连他都认为自己就是我，那么就让他成为我的**第二分身**。」
- 更大的构想：
  - **本尊 = 古神**
  - **第一分身 = 修士**
  - **第二分身 = 古妖**
  - 若有机会再造 **第三分身 = 古魔**，一旦三者融合于一体，「不知能否**返祖成古**」。

## 三、祭炼第二分身的过程

### 分身祭炼的通则难关
- 要成为分身，须祭炼至与本人**心神统一**：信念一动即可操控自如，且不排斥本人元神、可融入自身元神取而代之。
- **强行祭炼**仅对远低于自己的傀儡可行，但这样的分身无大用；
- 若对方修为不低于自己，则**无法强行**施展；
- 只能日复一日祭炼，耗时极久才有一丝成功可能，且成功仍有破绽，**分身反叛**的可能性依然存在。

### 本次为何轻易
- 此古妖已彻底把自己当成王林，无需过多祭炼；唯一要做的是融入神识并让其明白**谁主谁次**。
- 王林修为高于此古妖，本尊更是古神，断不会主次不分。

### 王林的多重保险（生性谨慎的行事风格）
1. 数日祭炼中把神识融入古妖，与其彻底融合；
2. 烙印**分身印记**；
3. 另备**大量印记**——若他日分身背叛，王林信念一动即可令其立刻屈服；
4. 加施**仙帝青霖的傀儡操控法术**用于第二分身，直至彻底操控、没有半点遗漏，方才放心。
- 完成后，一种「水乳相融」之感油然而生。

### 第二分身的现状与潜力
- **短板**：没有肉身，完全存在于黑色石像上，**暂时不能分开**；即便发动攻击也以妖识为主，威力很弱，**相当于问鼎后期**。
- **潜力**：本质是一丝妖识，若有足够妖气便会**快速成长**，总有一日可达古妖程度。
- 王林认定此事不可操之过急，需慢慢进行。

### 安排
- 在炼魂宗交代一番后，**没有带走**第二分身；
- 在其所在之处设置**威力强大的禁制**；
- 嘱咐炼魂宗之人**继续保持每天的膜拜**；随后离开炼魂宗。
- 心中期许：「这第二分身是一个种子，现在对我帮助不大，可一旦他成长起来……」

## 四、重返天妖郡都城：数百年后的旧地

### 衰败的景象
- 天妖郡数百年前与**火妖郡**大战虽胜，死伤惨重；至今人口比之当年仍相差太多。
- 最繁华的**天妖郡都城**虽不算萧瑟，也远不如数百年前王林初到时热闹：街道店铺依旧，行人稀少。

### 河畔追忆
- 当年**洪城**内一条长河顺流与都城外河相接、自成循环。王林静坐河畔，位置与当年一模一样。
- 人还是当年的人，位置还是当年的位置，河也还是那条河——只是**河道上没了花船，没了琴音**。
- 王林对那弹琴**盲女**的印象，至今只有一个孤独的背影与充满悲哀的琴音；若非当年船上与帝君的一夜酒，怕是连面都未见过一次。
- 感慨：「正因为有了记忆，所以才有了岁月；如果一个人没有记忆，那么岁月也就不存在了。」——「这，或许就是人生的悲哀吧。」
- 心中一问：「不知当年的**莫厉海**，是否还在。」
- 他从当年同一间世代相传的酒铺打来酒，招牌依旧，喝一口却苦笑：「连味道也变了。」

### 帝君重逢
- 身后传来平静而带疲惫的声音，道破酒变味的缘由：酒铺老汉的后代没了先人手艺，做不出**岁月的味道**。
- 来者为一身穿紫衣的中年男子，极为英俊、依稀可见当年之貌，但**鬓发已有白丝、容颜沧桑**——王林叹「数百年未见，帝君也没了当年的洒脱」。
- 帝君取出酒壶递给王林，王林饮后微笑：「是当年之酒。」
- 帝君：「我知道你一定会回来，所以留了不少，准备与你再次痛饮一夜。」并大笑问王林可是惆怅没了当年琴音。

### 收束：琴音再起
- 一缕孤独悲哀的琴音自远处飘渺而来，河道上驶来一艘大船；船头同样坐着一个女子，**背对王林**弹琴——与数百年前的画面重合。

## 五、要点清单

- 云妖并未真正复生：石像中的「王林」只是其残余妖识被信仰改写后的产物。
- 王林分身谱系首次明确成形：古神本尊 + 修士第一分身 + 古妖第二分身，预留古魔第三分身。
- 第二分身受制于石像、依赖炼魂宗持续膜拜供给妖气，是长线「种子」投资。
- 仙帝青霖的傀儡操控法术被再度用于自保式控制手段。
- 天妖郡线：战后衰败 + 帝君重逢 + 琴音/盲女意象回环。
