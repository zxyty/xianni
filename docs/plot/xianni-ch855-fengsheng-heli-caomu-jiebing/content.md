# 第七卷 名震罗天 第855章 风声鹤唳草木皆兵

## 一、雨中的恩义回望

清水降下方圆千里雨滴，滴滴如水晶、萧杀之气浓郁；唯独落在王林身外的雨幕不带寒意，反而化作暖意涌入体内，让王林大量消耗的元力缓缓恢复。

王林沉默注视清水，心中涌起一股久违而陌生的感觉。他依稀记得，此生给过他这种感觉的只有四人：

- **遁天**：朱雀星上炼魂宗的师尊。遁天之恩，王林铭记于心，立志发扬炼魂宗。
- **司徒南**：如师如友。司徒之恩，珍贵如射神车亦可毫不犹豫送出；若司徒有难，纵粉身碎骨，但凡有一线可能王林都会去救而非退缩。
- **天运子**：化神之时第一次相遇者。正因这份恩，王林在察觉种种蛛丝马迹后仍未果断确定，直到一切摆在面前，才不得不真正走上反抗天运子的道路——心底因此留下一丝无法化解的悲。
- **周佚**：为报此恩，王林做出了太多太多。

王林一生秉承「人不犯我，我不犯人」，但凡有人于他有恩，哪怕只是半点，都会真正放在心中珍惜。

而眼下清水挡在他身前，为他拦下血神子与天劫，起因不过是一个「呼风」法术，以及一个**根本就不存在的师门传承**。

## 二、血神子的隐忧

血神子面色阴沉，千里雨滴令其心神震动。他的忌惮有两重：

1. **伤势**：数月前在望月体内，被古神幼子碎星一击重伤，虽强行压住并以传承秘术疗伤恢复了一些，但对上清水，伤势将成最大隐患。
2. **威名与出身**：他是传承至仙界的修真家族老祖，对仙人心情复杂；家族典籍中明载清水其人——那是即便当年先祖也要恭敬对待的存在。清水威名太大，即便他未受伤也无十足把握取胜。况且以他们的修为，要么不战，一战必然惊天动地。

## 三、仙术对决

### 1. 清水的雨滴攻势

千里雨滴蓦然而动，尖啸声中蕴含浓郁至无法想象的天地之力，其内更隐藏一丝**至精至纯的仙界之力**，如无数利剑冲向血神子。威力标尺：

| 数量 | 效果 |
| --- | --- |
| 一滴 | 问鼎圆满修士肉身崩溃 |
| 十滴 | 阴虚亡 |
| 百滴 | 阳实灭 |
| 千滴以上 | 窥涅不得不退 |

更兼冲来之际**仿若可穿透一切规则**，血神子亦心神剧震。

### 2. 血神子「仙术风声」

血神子双手一挥，体内滚滚雷声如可开天辟地，狂风凭空而起环绕四周，化成**雷风**。要诀为「以雷传音，以音动空，凭空起风」——此乃**雷之仙界**大名鼎鼎的雷风，仙术「风声」；王林的**藏品阁第八层**便藏有此术详细口诀。

雷风横扫，与雨滴碰撞，千里尽是雷鸣；雨滴倒卷凝成水幕弥漫血神子，风中之雷在雨间交错，千里之内几成雷光地狱。

### 3. 清水「雨封」

清水神色冷漠，只吐二字「雨封」。千里雨水立散极寒之气，一一化作冰晶蔓延冰封；连呼啸雷风也在触水刹那寸寸冰封，凝固如一条**漩涡冰龙**。

### 4. 血神子「仙术·鹤唳」

血神子不假思索掐诀，天地之力穿透冰层凝聚成拳头大小球体，一按化作仙鹤——**红顶鹤冠、赤金之足、如雪之羽**——转眼幻化出**九只**。九鹤双目变红，妖气如风暴冲出，冰层现崩溃之兆；血神子发丝飘起，眉心浮出红色漩涡急旋，透出更浓妖气，已然不似修士，**而似被占据肉身的古妖**。

他喝出「仙术，鹤唳」，九鹤盘旋唳鸣，形成音之风暴，千里冰晶尽数崩溃；随后九鹤一一自爆，化无数白羽四射，形成弥漫方圆千里的大神通之术。

清水评曰：「此术，不错。」

### 5. 「草木皆兵」与灾变风险

血神子言：姚家先祖神通属雷风，不如清水的呼风之术，但无数万年间世世代代创出这一式神通——「**风声鹤唳草木皆兵**」。

他红袍掀起、双手掐印向两旁一挥，天地为之一暗，喝出「草木皆兵」。此神通中**「兵」即兵器**：飞射的无数羽毛立散妖气，各自化作一件件完全不同的法宝。天地色变、风起云涌，星空仿若坍塌并疯狂蔓延——千里、万里、**十万里**，以血神子为中心迅速波及。若任其如此，**罗天南域将掀起一场浩劫**。

## 四、结尾转折：七彩天雷

就在血神子神通达到巅峰、直逼清水的刹那，星空上方的劫云完成最终收缩：大范围消散后全部向中心凝聚，化作**七彩天雷**。此雷未现已透出令人心颤之力，且**并非一道，而是七道**——赤、橙、黄、绿、青、蓝、紫，一一落下，其上蕴含浓郁的**毁灭**之力。
