# 第2060章 天地……

## 一、始古皇城：计都继位皇尊

### 皇权香
- 「皇权香燃」惊天之音回旋始古皇城，皇宫一片寂静，万众目光聚于广场中心大鼎前的皇袍之人——计都。
- 计都相貌已不再是青年，转为成熟。天空碧蓝万里无云，柔风徐来。
- 观礼范围空前：皇城内族人、始古一脉各城池中由城主组织的族人、乃至道吉与极吉两族皇城中都有目光遥遥望来。
- 计都望向远处古祖雕像，心中默念：「始古皇尊义父，孩儿就要成为皇尊了。」随即抬手燃起火焰点燃皇权香。

### 战鼓九拜
- 香燃青烟升空，天地色变、风云倒卷，天幕撕开巨大裂缝。
- 裂缝中走出高约万丈的巨大古神，身旁伴有古魔、古妖，共扛一面巨大战鼓，悬浮半空。
- 计都升空至战鼓旁，以右手挥拳击鼓，一击为一拜：
  - 第一拜——「拜见皇尊」，声浪由皇宫扩至皇城，再传遍整个始古一脉所有城池。
  - 第二拜——「参见皇尊」，音浪更烈，成为除鼓声外最强之声。
  - 第三拜——计都再念「义父，孩儿成为了皇尊」。
  - ……直至第九拜。
- 唯独计都之父始终站在大殿中未跪，只是看着计都。

## 二、祖庙：王林的幻境

### 所见景象
- 王林在祖庙内身躯干枯如腐朽，闭目不动，神游至一片天地：天昏地暗、雾气笼罩，是一片不知荒废了多少岁月的废墟。
- 不知走了多久（或一天、或一年、或一辈子），前方出现一座山，山上飘着七彩雪花。
- 雪中有一道**熟悉的身影**，抱着一具尸体仰天嘶吼，长发在七彩雪中辨不清颜色。
- 王林心神剧震，注意力全在那具尸体上——只见一头青丝垂落，看不清面目，甚至分不出男女。他不顾一切展开全速冲向山峰，却始终无法接近半点，如同隔着生命无法跨越的沟壑。

### 那道嘶吼（核心宣言）
- 「天地之巅，又有何用」
- 「众生皆拜，又有何用」
- 「无量劫经，又有何用」
- 「既这天地如此，何不毁灭」「既这众生如此，何不消散」「既这劫经如此，何不断传」
- 「我要以我的方式，让青天闭眼，让大地沉睡，让黄泉倒流，让轮回停止，让苍穹从此无念」

### 王林的反应
- 此声传入王林心神，令其心痛骤起——此痛本不及他所承受的古道三分神之痛的三分，但在他感觉中却是这世间至极之痛。
- 身影抱尸一步踏天，天崩之后携尸踏入；王林身躯以肉眼可见速度瓦解，被驱出此地。
- 睁眼后仍在祖庙，元神光影与他对望。他终究没看清尸体样貌，连那身影的声音也模糊——**熟悉中透着一缕陌生**。
- 王林目露迷茫许久，喃喃「不会的……不是的……不会的」，强行多次尝试才勉强不再思索——他必须去做别的事，否则思绪生根会让他崩溃。

## 三、古祖之赐：第二滴魂血

- 王林抬手一指身前元神，元神光芒万丈、急剧膨胀：占满祖庙 → 笼罩整个祖庙 → 继续扩散直奔古祖雕像。
- 元神虚影自雕像下方蔓延，最终与雕像等大重叠，使古祖相貌变得模糊陌生，**隐隐与王林有几分相似**（因元神包裹掩盖雕像所致）。
- 恰在第九拜之时，古祖雕像外二十七道光环爆发夺目光芒，一圈圈旋转冲入天幕，青天泛起层层波纹——**计都的登基被暂缓**，万众瞩目转向雕像。
- 计都在战鼓旁转头看见，惊喜激动喊出「义父」。
- 玄罗在天幕上欣慰微笑：「古道三分神，他终于成功了……不知在古祖之赐中，他能获得什么样的赏赐。」
- 宋天未参加登基大殿，独立于原始山半空遥望，同样期待王林能得何等造化。
- 最后一道光环冲上天幕后天地色变，**九曲之音**回旋皇城，天幕降下幽暗光芒，其中一缕红色由微弱转明亮，最终化幽光为血红——凝成**一滴鲜血**。

### 魂血的意义
- 该血透出灵魂气息，一现即令整个始古皇城死寂。
- 宋天心神巨震、面露不可置信：「魂血」
- 玄罗深吸口气：「竟还是魂血……三滴魂血就可创造古族一脉，他之前已经得到了一滴，如今是第二滴。」即便以玄罗之能，也没想到王林能得第二滴魂血。

## 四、要点与伏笔
- 七彩雪山抱尸嘶吼者身份未明，声音「熟悉中透着陌生」，且其誓言直指「无量劫经」与轮回——是本章最大伏笔；王林对其抱着的尸体反应极端，暗示与其至亲/至爱相关。
- 古道三分神修炼成功，是王林获得古祖之赐的直接前提。
- 魂血已集两滴，距「三滴创造古族一脉」尚差一滴。
