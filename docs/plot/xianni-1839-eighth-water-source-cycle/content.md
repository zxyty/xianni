# 第1839章 第八本源

## 一、取出己司之傀护法

- 王林储物空间中想取之物极多，但**无损打开储物空间的机会只有一次**。权衡后他判断：眼下最有用的，是一个**修为无限接近空劫初期的傀儡**。
- 他神识涌入空间石，在其中打开储物空间；空间石随即颤抖，其内一个空间取代王林储物空间后**轰然崩溃**。
- 崩溃瞬间，滔天煞气冲出，**己司之傀**（获自古之墓地深处）现身：干瘦如猴、四肢着地、猩红长舌拖地、双眼赤红。它一度死死盯住王林，想起主人身份后凶光才略消。
- 王林下令：「己司，为我护法。」己司转身盯住洞府大门，任何踏入者必遭疯狂攻击。

### 双重防护

| 层级 | 守护者 | 位置 |
| --- | --- | --- |
| 外层 | 王林的**本源真身**（由火组成） | 洞府外 |
| 内层 | **己司之傀** | 洞府内 |
| 最后一道 | **蚊兽**（手臂上的蚊王墨色图腾） | 王林己身 |

王林看向手臂图腾时，墨色蚊兽双眼露出寒光，似与他对望——这是他为闭关准备的最后一道防护。

## 二、水本源的凝散循环

- 王林将那水滴按入眉心，体内原藏的一滴**水本源之液**与之融合，全身血液沸腾。
- **凝聚阶段**：身体以肉眼可见速度枯萎，半柱香即如干尸——头发干枯、皮肤皱缩。原理是修士体内本就含水（血液亦是水的一部分），凝聚水本源时身体水份被牵引抽尽。
- 七天后（文中亦作「两天后」，叙述有出入）他睁眼，目内浑浊，沙哑喝出「散，水本源」，掐诀令水本源爆发，身体刹那恢复，皮肤晶莹剔透、内外异光流转，此状态维持**九天**。
- **一凝一散为一个循环**，两个九天完成一轮；每轮过后体内水滴缩小。
- 七次循环后水滴不足原先两成，时间已过数月；至第十九天后再算，八次循环后水滴已稀少到几乎不可见。

### 关于本源的设定要点

- 水本源属**实之本源**的一种，与火本源一样存在**意志的融合与吞噬**问题。
- 王林原有水本源仅**小成**，故融合仙罡大陆水本源时排斥之力不大，可以承受。
- 若这次吸收能让水本源**大威圆满**，其修为将立刻提升。

## 三、己司的暴躁与操控原理

- 己司久不沾鲜血，在洞府内不断低吼，时而带凶光回望王林，但「王林是其主人」的念头虽不深刻仍能压住吞血冲动。
- 更关键的是：它感到如今的主人与当年不同，身上多了一股**极淡却与魂融合、令它恐怖的气息**——源自王林分身神识内所蕴的那一缕气息，外人难察，己司却能感知。这正是王林敢用它护法的原因。
- 王林修为越高，对这凶残之傀的操控意志越强；只要时间不过长便无问题。

## 四、矾珊璐窥探被袭

- **矾珊璐**（自第1606章起伪装成姐姐**矾珊梦**，本章文本以「矾珊梦」称之）同在此山峰，观察王林闭关处已久。数月后念头愈强，遂出洞府走向峰顶。
- 她在**百丈外**停下，忌惮地看着洞府外由火组成的本源真身。她并非胆大到趁闭关出手，只是想近距离看出端倪，以完成师尊**炎栾**下达的**「慢慢克死王林」**之命。
- 本源真身骤然睁眼扫她一眼，如王林亲视，令她心神一颤、低头欲退。
- 此时己司嘶吼冲出洞府，化作浓黑雾气弥漫天地，雾中露出凶残双目与垂出的猩红长舌，直扑矾珊璐。
- 矾珊璐修为已达**玄劫第七次**，颇为不俗，但在己司目光下心神一震，加之忌惮王林，不假思索后退——速度却不及己司；巨舌横甩卷来，黑雾封锁其退路。

## 五、炎栾赶来·闭关功亏一篑

- 大魂门众人早已接到老祖之命，**禁止靠近王林所在山峰**，此刻纷纷察觉异变而凝神看去。
- **炎栾**打坐中骤然睁眼变色——她几乎已忘了自己曾派矾珊璐去克死王林——身形一晃直奔该山峰。
- 洞府内王林正进行**第九次（最后一次）循环**，一旦成功水本源即圆满、修为可提升。但身体枯萎成干尸的刹那，体内水本源水滴**完全耗费、半点不存**。
- 王林睁眼断言：「水本源不够……完成最后一次循环还差一些……**我需要大量的水**。」
- 察觉洞府外轰鸣与炎栾气息后，他喝令「己司，回来」，同时身影一晃走出洞府，以干枯如骸骨的恐怖之貌现于天地之间，炎栾见状化作一声惊呼。

## 六、悬念

1. 王林如何取得「大量的水」以完成第九次循环、令水本源圆满。
2. 炎栾目睹王林干尸之貌与己司出手后的反应，以及她与矾珊璐「克死王林」之谋的后续。
3. 「第八本源」的章名指向：水本源为王林所掌本源之一，其本源体系的进一步扩展。
