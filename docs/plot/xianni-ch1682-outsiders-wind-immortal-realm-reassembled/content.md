# 第1682章 外来者

## 一、通道非门：真相的起点

王林盯着百丈外的石门，断定此处并非七道宗仙尊洞府的大门，而是**被人开辟出的一条直通洞府的通道**。通道四周悬着一串串蚊兽卵，荧光映照忽明忽暗。他一面后退，一面在心神内排列已知线索，抽丝剥茧地推衍万古岁月前的真相。

## 二、推衍：外来者即仙罡之修

退至裂缝边缘将出未出之际，王林猛然忆起在**太古星辰闪雷族**的旧事：

- 很久以前曾有一批神秘之人出现，衣着奇异，所用法宝与神通前所未有；
- 他在闪雷族**吸收不灭雷霆**时，自雷霆记忆中模糊看到那群人的身影，以及他们的法宝**昆极鞭**；
- 那群人的首领**与纳多相貌一模一样**，他当年还曾思索要去**五行星**寻找纳多。

结论：闪雷族所谓的「外星辰」修士，天地间本无外星辰，他们**分明是从洞府外来临的仙罡之修**。（王林并未听到仙罡大陆归一宗几人的话语，此真相纯由自身推衍摸索而得。）

## 三、大胆猜测：通道来历与蚊兽由来

王林脑中幻化出一幕幕想象画面，串成如下推测链：

1. **七道宗七彩仙尊**当年获得天道，抛弃道侣、封锁七道宗，于洞府内参悟天道，并把洞府彻底封死。
2. 此举引起旁人猜测。仙罡大陆上**另一宗派**有天资惊艳之辈，以特殊方法开辟出直入七彩仙尊洞府的通道。
3. 这群人由通道来临，即闪雷族口中的神秘之修——他们**最早并非出现在界外太古星辰，而是这风仙界**，且未引起风仙界半点察觉。
4. 他们重新封死裂缝通道，或在界内寻找一番后**走出封界大阵去了界外**，此后无数年销声匿迹。
5. 恰逢**四大仙界崩溃**，裂缝受波及、或因通道不稳而打开了通往别处的道路，引来一群蚊兽。
6. 蚊兽在通道内繁衍，重新撕开被封印的裂缝冲出，进入崩溃后的风仙界并占据此地——此即**裂缝的第二次打开**。

**关键判断**：这群人至今仍存在于洞府之地、并未离去。理由是——若已离去，必会彻底封死石门与通道、抹去日后可被查出的一切线索。他们既未离去，或在五行星，或仍未寻得所求之物；而他们所求，**或与七彩道人和战老鬼所寻为同一物**。王林断定其打算是「螳螂捕蝉，黄雀在后」。

## 四、收卵、封缝

- 王林右手一抓，欲携蚊兽离去；蚊兽眼露不舍，望向蚊卵嘶鸣。
- 王林右手向通道一挥，狂风卷动**数以百万计的蚊兽卵**尽数消散，收入储物空间；蚊王欢呼嘶鸣，再无留恋，随其飞出裂缝。
- 裂缝外风仙界风声呜咽、雾气弥漫。王林双手掐诀向内一合，裂缝边缘震动、慢慢靠拢，最终彻底并拢。
- 继而右手掐诀，整只右手模糊，幻化出一个个**禁制**层层落下，无数禁制密密麻麻笼罩完整。
- 仍不放心，遂虚空一抓取出**得自古之墓地的头颅大陆**（其上多为干枯之树，但已生出诸多**古息叶**——那是他**三年前在远古仙域吸收古之三族雕像之力**后送入，历三年生长而成）。挥手放出**数十片催化完整的古息叶**，一指贴于并拢的裂缝上再次封印。
- 做完收起余下古息叶与头颅大陆，携蚊兽一步离开雾气。裂缝随封而消散无影，雾气渐薄至彻底消失。

## 五、重聚风仙界

王林身在天空，神识扩散笼罩无尽之地，将整个风仙界幻化于心神内：

- 风仙界的崩溃**并非不可逆转**——因蚊兽存在，此地大地碎片保存很是完整，**远胜雨界、雷界**；
- **闪界**他未曾去过，故不知其内变化；
- 定策：「便以这风仙界为根基好了，闪界若同样保存较好，也可融入进来。」

他以**空灵中期**修为浩然而出、神识笼罩全界，一声「凝」，双手向内狠并。诸多碎片大陆自恒久分裂中向中间凝聚，天地轰鸣，无尽之风崩溃，栖息已久的蚊兽大量惊飞。最终碎镜般的风仙界完全凝聚，化作**一块完整的大陆**。

> 空灵中期在第三步中亦属较高存在，整个界内界外数量很少。

余下蚊兽感受到王林的修为与强大而颤抖雌伏——百年内它们已被王林的**蚊王**杀戮众多，尤其强大者当年更不知为何纷纷死亡，剩余者不足以掀起大浪。

## 六、驾界远行，直奔闪界

- 王林落于大陆盘膝而坐，闭目、元神散开与大地融合，操控整块完整大陆呼啸前行；
- 他将风仙界**强行带出其原本存在的天地**，出现在云海的星空中；
- 远观这块星空大陆散发磅礴仙气，此仙气**由香火气息改变而出**，属**洞府界**的仙气，与仙罡气息不同——因当年**封尊开辟四大仙界本为凝聚香火**，故其大陆与寻常不同；
- 蚊兽被威压笼罩无法飞出，只能随大陆而走；
- 神识操控大陆**直奔召河星域**，目标是四大仙界中他唯一未去过的**闪界**——那里存在无数刺目光芒，如银河回旋，绚丽至极。
