# 第1250章 叱咤无极（一）

## 一、看台：木冰眉不肯言说的那个人

- 木冰眉追忆一位故人，语带惆怅，称「当年一别，回首时已然是天边」，认为此人来到云海的可能不大。
- 王珊珊表示想见一见能让木冰眉如此夸奖之人。
- 无极宗一位绉姓中年男子（身份极高，与宗主同坐）追问其名，语气无礼。木冰眉秀眉一皱，冷冷回绝：**「他之姓名，不需告知，你若此生遇到，未必是幸」**。
- 绉姓男子讥称「区区净涅初期的修士而已」，本欲赐其造化，既如此则罢。无极宗宗主（白袍老者）心中不喜，未发作。

> 据世界状态须知：木冰眉所忆之人即**王林**（其在云海以化名「吕子浩」行事）。绉姓男子所言「净涅初期」为其旧时所知的修为。

## 二、冯海讲述：吕子浩其人

王珊珊岔开话题问及李倩梅，由此引出归元宗一段公案，由长老冯海当众陈述：

- 李倩梅是**云海星域天之骄女**，修道千年，修为已达**碎涅大圆满**；她与无极宗五阶分宗**归元宗**有旧，来后未坐主宗看台，径去归元宗处。
- 众人不解：李倩梅声名赫赫，竟与区区五阶星域宗派有旧，且愿为其出手杀七阶宗派修士。
- 事由：仙音门**吕英杰**与寻栾宗**赵某**因私事与归元宗纠缠，李倩梅出手**毁去赵某肉身**，吕英杰亦险些遇劫。
- 冯海暗中调查并查阅**典命阁**：归元宗当年确有**吕子浩**其人——归元宗师祖之辈、**吕烟菲的亲族**，一生痴于炼丹，多年前外出寻药后下落不明。
- **卢云从**与此人有莫逆之交，为归元宗出面不惜得罪仙音门与寻栾宗；称吕子浩**对天道的理解在自己之上**，依稀有受其点化之意。
- 卢云从曾扬言：吕子浩若来无极宗，莫说五阶分宗第一，即便六阶分宗，归元宗只凭他一人便可横扫，杀吕英杰如捏死蝼蚁。李倩梅之所以未伤吕英杰，正是因他不信此言、扬言要与吕子浩比斗，李倩梅便给了他这个机会。
- 无极宗高层原本重点栽培卢云从，此刻心神却全落在被卢云从敬服的吕子浩身上。

## 三、擂台：卢云从的六步与拒战

- 卢云从对阵某五阶分宗宗主，**仅向前迈出六步**，脚步与意境融合、如踏对方心跳，对方未及出手已心神紊乱，苍白后退、抱拳认输。
- 五阶分宗大比至尾声，因李倩梅到来，归元宗始终未出场；此时未比试者仅剩归元宗。主持长老宣：「归元宗，出场」。
- 归元宗仍在**北部角落**，气氛压抑；李倩梅望天，神色迷茫追忆。
- **吕烟菲**为归元宗修为最高者，面色苍白却眼神坚定，起身赴台；弟子**孙芸**含泪相送，暗忖归元宗或将解散。
- 吕烟菲立于卢云从之前：「归元宗不需其他比试，就我一人便可。」并在心中笃信：**「他答应我，会来就一定会来」**，依稀见天空中有身影向她鼓励微笑。
- 数万目光凝聚，连六阶、七阶分宗也望了过来，众人皆在期待那个「神秘的他」是否出现。

## 四、转折：「此事，不公」

- 卢云从神色复杂，猛地转向主宗看台抱拳，以净涅修为化作雷鸣之声：**「主宗诸位前辈在上，弟子不愿与归元宗比试，此事，不公」**。
- 冯海（大神通老怪）喝声浩荡压过其声，斥问何意。
- 卢云从深吸口气再拜，陈明理由：归元宗有一人修为高深、天道之悟远非自己可比，他若来临，自己不如；在他未到之前与归元宗比试定音，对归元宗不公。**「弟子卢云从要战，便要与他一战印证道果，胜则真胜，败亦无悔」**。
- 四周哗然。吕子浩之名声望再攀，几达顶峰；王珊珊赞卢云从「磊落的汉子」。
- 最终由**无极宗宗主**（白袍老者）亲自开口：「卢云从，吕烟菲，你二人上前来」——他对神秘的吕子浩，已起了浓浓的兴趣。

## 五、要点/伏笔

- 王林（化名吕子浩）尚未现身，却已借李倩梅之威、卢云从之口，成为整场大比的焦点。
- 归元宗的存续（是否解散）悬于此战，吕烟菲以一人之力赌王林会守约赴约。
- 无极宗宗主亲自过问，为下一步王林登场铺垫。
