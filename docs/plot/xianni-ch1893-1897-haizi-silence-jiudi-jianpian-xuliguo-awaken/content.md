# 仙逆 第1982–1983章 · 海子的沉默 / 山有虎！

## 一、长街逼问：黑发王林自称「戮默」

- 祖城东城长街，夜。海子天尊面色苍白、惊恐后退，追问「你到底是谁」。
- 黑发王林答：「我不叫王林，我的名字应该叫做戮默。」神色冷酷无情，缓步逼近。
- 谶语式自陈：「杀戮降临世间，取代光明成为默灭，众生需度无量劫。」
- **五行真身溃散**：王林的五行真身携雷霆本源、太初本源及三大虚之本源挡在海子身前；黑发王林言「你只是我五行真身与本源的凝聚」，右手一挥即令其崩溃，化作数道本源与另五道本源一同没入黑发王林右手。

## 二、揭破杀局与海子身份

黑发王林连发四问，海子全程沉默不辩：

1. 久帝并没有邀请王林去帝山。
2. 此次杀局以海子为诱饵，引王林出来。
3. 海子天尊除久帝弟子身份外，还属于**国师一脉**。
4. 当年山海内那断掌并非发疯，它第一个攻击海子，是因海子与王林一样**不属于仙罡大陆**——王林来自**洞府界**，海子来自**天外**；或者说国师一脉的宗门本就来自天外。

黑发王林评价本尊：「我的本尊，还是有些太过心软了，他本该早就看出端倪，可却没有选择相信。」随即抬掌欲将海子肉身崩溃、元神灭尽，形神俱灭。海子闭眼落泪，不闪不避，不作一句解释。

## 三、久帝大天尊出手

- 掌落距海子天灵不足三寸时，一股锋利似可轰开天地、破灭虚无的力量凭空浮现，化作略有驼背的老者身影：**久帝大天尊**。左手抓住海子后拽，右手硬接一掌。
- 结果：黑发王林连退九步，第七步时黑袍崩溃化黑气、瞬间重凝；第九步止步，神色如常。
- 久帝震惊处：一直猜测王林凭什么闯过**天尊涅十七层**（单凭魂铠断不可能），此刻确认其身上存在代表杀戮与毁灭的力量。
- 黑发王林指出：此次杀局除国师一脉外还有久帝参与，久帝或是察觉杀局、想借局解心中疑惑。

### 交手（王林首次向大天尊出手）

| 回合 | 久帝 | 王林 |
|---|---|---|
| 1 | 漫天风雪凝成巨大雪剑横扫 | 握拳一击，雪剑崩溃，自身亦瓦解成黑气 |
| 2 | 双手结圆形印记，放出照耀天地的光芒笼罩 | 黑气改向直奔久帝，与光芒对撞如黑暗与光明之争 |
| 结果 | 脚步未挪半点，双目滔天精光，苍老容颜隐有转向中年之迹象 | 黑气遮盖光芒后重新凝聚成形 |

- 久帝：「你战不胜老夫。」王林：「你掩盖不住杀戮的毁灭。」

### 和解与馈赠

- 久帝道破「白发跃天尊、黑发跃天尊」，称「我小看了你」「海子是无辜的」，取出巴掌大小的**金色仙极剑碎片**相赠——称曾观察王林身上有此剑痕迹，此碎片可令其**金本源大威**——并宣布今日之事一笔勾销，随后带沉默的海子消失。
- 长街禁锢随之失效，四周废墟却永恒存在、不会改变。

## 四、黑白定局

- 初阳自东升起，光明波纹扫过祖城东城长街；波纹拂过王林身体，黑发渐化白发，冷酷神色转为疲惫与萧瑟。
- 王林未强行镇压：**杀戮降临之时，一切都无法改变**。
- 自此定局：**阳光下为白发王林，黑夜降临则为黑发戮默**，如日出日落难改；所幸有**虚无分身**之力可略作压制、保持清醒。黑与白在其身上永恒停顿。
- 王林收走仙极剑碎片，拾起被抛开的**天牛魂铠**，对海子不再追寻，决意「离开——这仙族的一切，隐秘也好，起源也罢，我都不想再去思索」。

## 五、两日后：东门唤醒许立国

- 大雪连下两日。清晨，王林带**刘金彪**与**海龙**立于祖城东城门外等待。
- **许立国**（大红色长衫）与**疯子**连日心神受呼唤所扰，同至东门。疯子远远见王林即撸袖欲冲。
- 王林问许立国：「我要走了，你是留在这里，还是跟随于我？」话语传入心神，许立国脑海如有封印松动，前尘往事尽数浮现——被王林炼成魔头、数千年的跟随、以及那「煞星主子」的言辞——身子颤抖，泪流满面。

## 未决线索

- 国师一脉与「天外」的关系、其宗门来历。
- 海子天尊自始至终未作解释，其真实立场与情感未明。
- 久帝「借局解疑」的真正目的；仙极剑碎片的深意（「大有深意的看了王林一眼」）。
- 许立国是否随王林离开（第1983章仅至记忆复苏）。

## 概要（第1983章末—第1984章初）

祖城清晨风雪连天。许立国记忆苏醒认主、疯子记忆短暂苏醒又被仙皇带走，王林由此断定仙皇以疯子为诱逼己入地宫，遂独自返城，捏碎玉简召来双子大天尊一方的援手。

## 一、许立国认主与争宠

- 许立国记忆恢复到「离开洞府界前转世的一瞬」后完全苏醒，越过疯子、一把推开正欲打招呼的刘金彪，抢占王林身侧位置。
- 其阿谀陈情：夜夜梦中与主子相见；忠诚不因岁月、不因前世今生改变；「上一辈子是，这一辈子也是，下一辈子还是」；愿上刀山下火海；强调自己跟随时间最长，胜过「运气好被主子提前找到」之人。并硬挤出几滴泪。
- 内心独白暴露实情：称王林为「煞星」（险些当面说漏），自居王林身边第一人，要「教育」刘金彪。
- 刘金彪的反制：肩上缩至手指粗细的海龙一听「许立国」之名便抬头咆哮敌视。刘金彪得意抚摸海龙、挑衅回视。许立国暗忖「我只有一双眼睛，他们有两双」，担心地位不保。

## 二、疯子（道非）：认主之争、告别与记忆苏醒

- 疯子唤许立国为「小红」，急问「到底谁是你的主子」，被许立国当面撇清并推开。
- 疯子怒指王林「打伤了小花花的爷爷，又抢走了我的小红」，上前掐王林脖子。
- 王林自陈：「我来到这祖城，就是为了与你一见」；既然疯子记不起，便当洞府界往事是一场梦。任其掐颈，半晌后以柔和之力将疯子推出数丈，转身离去。
- 王林、许立国、刘金彪三人远去后，疯子在遥望白衣背影时脑海封印松动，念出「王林」「洞府界，王林虚无苏醒」。
- 手臂上原本空空的皮肤浮现出掌印痕迹（似有人曾久握其臂不放），泪水不觉滑落。
- 忆起：在洞府界遇一具尸体，以自身鲜血令其复活；尸体名王林，复活后对自己很好；梦道的一幕幕；再度苏醒后见到「哥哥」，此后记忆一片模糊——似被兄长以某种神通封印，模糊记忆中兄长双目透出无情目光，令他恐惧并想求助王林。
- 疯子高呼「王林……王林……师尊」，声震天地，令远处王林心神轰鸣、猛然回身。

## 三、仙皇现身带走疯子

- 疯子身后骤现金色漩涡，穿皇袍、戴帝冠的仙皇迈步而出，右手按在疯子肩上——疯子双目转为迷茫，手臂掌印消失无踪。
- 仙皇之言：「王林，你欲离开，本皇不送，道非记忆似有所恢复，朕要带他去皇宫下的仙祖闭关之地，在那里或许他可以完全恢复过来。」随即带疯子退入金色漩涡消失。（此处点出疯子本名/道号为「道非」。）

## 四、王林的推断与抉择

王林当场复盘仙皇的连环谋算：

1. 先行册封赏赐 → 王林未选择去地宫；
2. 继而有「长街之杀」——若与杀局联系，仙皇必参与其中，欲以杀局擒拿王林；
3. 杀局失败、又因王林杀戮降临并与久帝一战，仙皇不愿亲自出手；
4. 遂再出一计，以疯子（记忆苏醒）为诱，逼王林前往地宫。

关键疑问：「仙祖闭关之地」到底藏着什么隐秘？仙皇为何几次三番要他去？王林沉默后神色果断——明知危险仍要走下去。

**行动**：右手一挥，将许立国、刘金彪与海龙一并收入储物空间；独自一人在清晨风雪中再临祖城，目标直指地宫。

## 五、第1984章 走来！——玉简与两名小女孩

- 王林手中一枚玉简，是当年与**双子大天尊**及**孤崖天尊**的约定：王林需要时，双子大天尊会亲自降临而来。这是二人对王林的承诺，也是王林明知有仙皇为敌仍敢入城的依持之一。
- 在东城城门阴影下（风雪被城墙阻挡），王林捏碎玉简。
- 紫红双芒骤闪，化作一个透出沧桑、极为复杂、隐隐似有传送之用的阵法。
- 阵法光芒中幻化出两个小女孩身影，睡眼惺忪似在睡梦中被召唤，其中一个怀抱玩偶。台词：「好困啊，咦，这里是什么地方」「小王林……是你啊」——以「小王林」相称，显示辈分/资历远高于王林。

# 第1984–1985章 黑雪覆祖城·王林逼宫与国师现身

## 一、城门之约：请双子大天尊困住仙皇

- 两个小女孩模样的**双子大天尊**在祖城城门现身，见王林即露惊喜，连声追问「小彪子」（刘金彪）在何处。
- 王林抱拳拜见，直言此地是**仙族祖城**，提起当年约定：「在需要的时候，要我们出手帮你一次。」
- 双子大天尊听闻有人招惹王林，立刻精神一振、热衷动手，答应「仙皇没问题」。
- 王林所求：**帮他困住仙皇一些时日，他要去一趟地宫**。
- 双子闻「仙皇」二字，纯真双眼中掠过一丝凝重，但未再多问，化两道长虹直奔皇宫。片刻后祖城中心皇宫轰鸣、大地震动。

## 二、黑发王林：以黑雪吞噬光明

- 王林闭目喃喃：「杀戮降临世间，取代光明成为毁灭……我王林，愿沉沦毁灭之中。」
- 白色长发自发根急速转黑；天空落雪同步变黑，形成呼啸九天的黑雪风暴。
- 设定要点：**黑发王林本应在黑天出现**，此刻他反以神通将雪染黑、以黑雪盖住天幕，主动把光明化作黑暗。
- 结果：祖城**东部为黑夜，其余方向仍是白天**，景象极为诡异；东城修士纷纷出屋仰望，骇然震惊。
- 其气息不霸道、不活跃，感受者却第一时间想到**死亡与末世**。

## 三、东城至皇宫：一路化为历史尘埃

- 白色长衫被黑气取代，外人只见一团越来越浓郁的黑气；每前行一步，天空黑暗随之扩散一步。
- 所过之处：黑雪融化带走万年不碎的青石，地面成黑色废墟；四周建筑如瞬息度过无数万年，腐朽化作飞灰。
- 修士见其黑气如见天敌，灵魂深处恐惧，无人敢阻。
- 抵达皇宫时，身后**不见城池，只有历史的尘埃**。

## 四、皇宫之战：龙鬼崩溃、数万禁兵尽灭

- 皇宫外：数万**黑甲禁兵**列方队，更有无数身影自皇宫各处飞出。
- 天空双日：**紫色太阳＝双子大天尊，金色太阳＝皇袍仙皇**；两大天尊交战轰鸣，短时难分胜负，但足以困住仙皇使其无法对王林出手。
- 仙皇喝斥：王林擅闯皇宫、不敬仙祖，是为**叛仙**，劝双子勿再执迷。
- 王林黑气凝聚成黑色衣袍，黑发变长，双目冷漠无波；天地在他与皇宫前「分成三半」：一半黑、一半金、中间紫阳。
- 王林自陈心迹：**长街杀劫本不愿再追究，只想离去、不愿让杀戮毁灭降临世间，是仙皇以「疯子」逼他来此**。
- **龙鬼**：数万禁兵铠甲黑光汇成滔天煞气，凝成龙头龙尾、龟身无角、烙满狰狞鬼物图腾之兽；仙族特有名号（龟／鬼同音），非玄武，为黑甲禁兵之魂，由无数年煞气而成。
- 王林化磅礴黑云横扫：龙鬼碰触即颤抖崩溃；禁兵喷血倒卷；皇宫城门瞬息腐朽坍塌；黑云掠过后于皇宫广场重凝为黑发王林，**数万黑甲兵齐齐死亡成残骸，被风一吹灰散**。

## 五、第1985章 国师

### 黑雪落皇宫与金光护阵
- 王林平静道「仙族的皇宫，或许没有下过黑雪」，右手一挥，天幕黑暗化作黑雪飘落皇宫内外，庞大皇宫肉眼可见地急速腐朽。
- 远处**耸立入天的仙祖雕像**扩散金光横扫八方——此为**皇宫最强阵法**，不允许破坏。
- 雕像头顶盘膝坐一白衣之人，正是**册封之时的国师**，微笑起身一步跨出，皇宫顿现重影、似与另一空间重叠，其落脚于王林前方千丈外大殿之顶：「我等你已很久，你终于来了。」

### 试探交手
- 王林一跺脚，大地崩裂，一道道裂缝如地龙直奔大殿；国师一挥手，「一切存在，都可成无」，裂缝如伤口愈合般消失。
- 四周修士立刻退避。作者借此点明**仙族与古族体制差异**：古族无宗门、只有古祖庙与三大皇国，族民疯狂效忠皇权；仙族皇权多为象征，真正势力在几个大天尊与诸多宗门手中。

### 魂衍道 vs 道衍魂
- 王林：「我在长街所杀，不是你。」国师：「你所杀之人，是我，但也不是我。」
- 国师握拳复开，掌心幻化白芒小人向其跪拜，称此为**魂衍道**；并指王林曾去过**大魂门**、当会「道衍魂」——**看似一样，实则不同**。
- 小人飞出膨胀成寻常身影扑向王林，王林如长街时一般抬手抓向右侧，一把捏碎。

### 洞府界秘辛（国师所述）
1. **开辟洞府界、创造一个世界的神通，是国师一族特有**；仙罡大陆上包括仙祖、古祖在内，皆是该族在追随仙祖之后传授而得，凡有资格的宗门都可自行创造洞府界。
2. 无数年来，无数洞府界为该族提供**庞大香火**；香火对旁人亦有用，对该族用处最大。
3. **吸收了本属于该族的香火者，可成为该族「外部族人」；若再无香火，则必死**——「香火，是毒，也是补」，此点并非太深的隐秘。
4. **唯有王林**穿过了虚无，且**不是以转世的方法，而是以他来自洞府界的身体走了出来**——这在该族历史中从未出现，是「不可能出现的事情」。
5. 结论：「你与我族一样，都不属于这仙罡大陆」，「你是我族神通在这仙罡大陆上创造出来的」。

### 空间转换：幽火大殿
- 国师掐诀一挥，皇宫扭曲、天空消散、宫殿消失——王林位置未变而空间转换，显然皇宫内早有人以大神通开辟出一个同样的空间。
- 新场景：**磅礴大殿，无数巨柱支撑，每根柱子上九团幽火环绕燃烧，每一火团内都有一张闭目的模糊人脸若隐若现。**

## 六、悬念与待解
- 王林此行真正目的地是**地宫**，双子拖住仙皇只是为此争取时间。
- 国师为何「等了很久」、其族究竟是谁、幽火中的无数张脸是什么，均未揭示。
- 「疯子」被仙皇用作逼王林前来的筹码。

> 归属说明：本片段中的黑发王林即王林本人（杀戮毁灭之道显化的形态），非分身或冒名。

# 第1985-1986章 地宫返祖之约

## 场景：祖城皇宫地宫

- **祭坛**：远处山形祭坛，即「皇宫之殿」，国师立于其上、身形不动，仿若处在另一空间。
- **血池**：祭坛正前方巨大的血红色水池，冥道尊盘膝其中，双目紧闭、神色狰狞、青筋鼓起、笼罩沧桑，正承受返祖之痛。
- **九柱九链**：祭坛四周九根柱子，各系褐色铁链，汇于祭坛上方中心，拴着身穿花色长衫、被九链贯穿而昏迷的**疯子（连道非）**。
- 地宫为当年仙祖请国师之族布置皇宫时开辟，其内构筑与皇宫建筑一一关联。

## 国师的自白：仙族的枷锁

王林一句「你走不出祖城，亦或者，你走不出这个皇宫」戳破对方处境，国师神色骤冷，随后坦然承认：

- 仙祖极强，其族被逼归顺；绝大部分香火须经族人身体炼化后奉献仙祖。
- 仙祖在族人身上留下**代代传承的封印**：永远无法离开祖城，言辞亦须极为谨慎，每代仙皇皆掌其族生死。
- 冒险离开者必死——**大魂门老祖**为其族天骄，离开后依旧难逃一死。
- 「我想要改变，而且如今，也有了改变的机会。」

## 局中局：仙皇的算计

- 国师最早知王林来自**洞府界**时，摸准仙皇**连道真**多疑冷酷的性子，主动进言「此人为大患，必须杀」，反令仙皇起疑，故王林初来仙族时未遭出手。
- 王林成长之快出乎仙皇预料，但仙皇另有打算：**借王林之力，在地宫成全冥道尊的返祖**。
- 仙皇忌惮**久帝**，不愿在祖城亲自出手引其怀疑 → 册封时的邀请 → 长街中的杀戮（王林杀戮降临一幕令其震惊）→ 借对**连道非记忆**的掌握，终于引王林入地宫。
- 国师直言：唯有在此地、唯有另一位大天尊与仙皇交战之时，他才能说出这番话而不被察觉。

## 返祖之法

- **返祖**：仙皇筹备多年之事，成功者可拥有仙祖修为，成为「第二个仙祖」。
- **人选**：冥道尊——仙族第一天骄，无仙祖血脉时已足以成为王林之后的跃天尊第一人；得血脉则修为暴增无数。
- **执念为薪**：其神智已被仙皇抹去，只剩对王林的恨与杀机，以此凝聚强大执念撑起无限生机，约有**四成把握**挺过返祖之痛、逼出血脉全部力量。
- **关键在血池**：此物极难获得，历代仙皇筹备至今方勉强达标，可提高返祖成功率。
- **隐忧**：国师不明仙皇以何手段控制返祖后的冥道尊，推衍一片模糊，隐约算出「不外乎夺舍以及傀儡之类」。
- **国师的方案**：由他亲自主持传承，趁仙皇被牵制、冥道尊未醒，将本该给冥道尊的修为**转移到王林身上**；王林须入血池、承受改血脉之痛且**不得反抗**，一旦反抗则前功尽弃。

## 交易条件与信物

| 项 | 内容 |
|---|---|
| 国师所求 | 王林成为第二代仙祖后，代仙祖**解开其族封印**，让族人自由离开仙罡大陆、回归天外故乡 |
| 允诺回报 | 王林成仙族第一人、超越大天尊，届时一句话即可救下连道非；再加全大陆洞府界的香火之力 |
| 国师信物一 | **誓符**：掐诀令誓言化作幽光符文图腾，有仙罡法则见证，违誓则身躯灰飞烟灭 |
| 国师信物二 | **命晶**：自眉心取出的拳头大小黑色晶体，仙罡大陆所有洞府界香火的中枢；取出后国师瞬间苍老腐朽，自言时日无多 |
| 王林回应 | 「在下不懂仙罡誓符，只知晓血誓」——划出一滴蕴含浓郁气息的鲜血为誓：**若你所说为真，则我可帮你一次** |

### 香火之力的门道
- 仙祖诞生于虚无，**无法自行吸收香火**，故需国师之族以身体转化。
- 世间他人吸收的香火不精纯，一旦吸收反而成为供奉香火的「种子」之一。
- 王林不同：**诞生于香火的洞府界**，灵魂与身体可**直接吸炼**，无须转化；长久之下修为、神通、寿元皆可蜕变，有机会达到**「空与灭」**的层次，足以站在宇内最巅峰。

## 未解之结：连道非

王林临入池前提出「连道非，我要先救下」。国师苦笑坦言：九条铁链为仙皇亲自布置，他**无法打开**，一旦碰触，仙皇即便正与那双子（另一大天尊）交战也会立刻察觉。只能反复恳求——「相信我一次，道友，相信我一次」，以全族性命与未来担保。

## 王林的暗手与转折

- 王林内心早有判断：**「那虚无缥缈的仙祖修为，获得者应是仙皇与这国师吧。」** 对方言辞真假莫测，但可确定「这所谓的传承，绝非这么简单之事」。
- 他收起命晶却**未立刻吸收**，点头应下，缓步踏入血池。
- **右脚入水刹那**：脚在池水中轻微一晃，借入水涟漪遮掩，散出**一丝杀戮气息**，顺池水直奔冥道尊，瞬间钻入其体内。
- 国师正抬手掐诀、运转仅剩一丝生机欲施秘术之际——**冥道尊猛然睁眼**，目中迷茫刹那后露出滔天疯狂，寒意自其身扩散，整座地宫骤寒，**血池以肉眼可见的速度迅速结冰**。

## 悬念

1. 王林那丝杀戮气息意在唤醒冥道尊、破坏返祖，还是另有布置？
2. 国师所言几分为真——他与仙皇是否本为一体两面的算计？
3. 命晶落入王林之手，其「直接吸炼香火」的独特资质将走向何处（空与灭）？
4. 连道非仍被九链贯穿，救人之约悬而未决。
