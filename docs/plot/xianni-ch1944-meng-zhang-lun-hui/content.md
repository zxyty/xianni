# 第1944章 梦障轮回（第一更）

## 一、场景与缘起

- 地点：**仙罡大陆·东临宗**一处小山，山上有大殿、广场，广场中置有鼎炉；天降急雨，弟子匆匆奔走。
- 异象：王林在**不同的时间、不同的空间、虚幻与真实**中踏在了同一处位置，自认这是极罕见之事。
- 感受：雨打青石板的声音与洞府界所见一幕幕高度熟悉；王林以己身为凭，似化作一道看不见的细线，**连接了洞府界与仙罡大陆**。
- 呼应：此番状态如同当年在**朱雀星的一场梦道**——闭目而天地在心、万物有神。
- 旁听者：**刘金彪**立于王林身后，王林此番明悟并未内心默语，而是喃喃出声，被刘金彪听到。

## 二、王林的道之梳理（三道虚之本源）

王林自陈曾以三种形态勾勒一个「人生如梦」的天地：

| 本源 | 形态表述 | 最终比喻 |
|---|---|---|
| 生死 | 以左手为生，右手为死 | 一条绳索，两端为生与死，连在一起便是一个圆圈 |
| 因果 | 以掌开为因，掌握为果 | 由无数生死组成的一张大网，众生在内难以挣脱 |
| 真假 | 以睁目为真，闭目为假 | 梦障——人以为苏醒时仍在梦中，圆圈层层环绕，走出一圈仍在另一圈内 |

核心思辨：

- 「人生如梦，梦如人生」是朱雀星梦道所得，但王林明确知道**这种感悟不是最终**。
- 「世界在我眼中，被我所看，**因我能看到，故我存在**。」
- 「我闭目，一切虚无；若**天闭目**，是否我则虚无？」
- 结论式的成仙设想：「我若睁眼，则天地闭目；我若不朽，则天地沉睡——这一种境界，则我成仙。」

## 三、刘金彪的骗道印证

- **骗道第二步（欺骗自己）的真意**：并非自己相信便算圆满，而是以**证道**的方式，在自己相信的同时让天地、轮回、岁月**全部都相信**；说是骗过自己，实为**欺骗轮回**——「我欺骗了轮回，则我逍遥自在，天地不可逆我之意，轮回不可阻我之神。」此明悟来自其**转世后的苏醒**。
- **前世夙愿**：骗道被众生唾弃视为不耻，但骗道唯心，「三千大道中，必有骗道之列」；此为刘金彪前世的梦想与追究，今生依旧如此。
- **骗道三步**：一骗别人 → 二骗自己 → 三为经历「看山不是山、看水不是水」后**返璞归真**，存在一心去骗「别人」，此「别人」统称天、地、岁月轮回与一切；**「连道都可以骗，我则成仙」**。
- **万道同宗**：刘金彪指出其第三步返璞归真，与王林所言「我闭目万物不知是否消散、天闭目你我不知能否存在」是一个道理。
- 刘金彪由此驱散转世苏醒后的迷茫，双目露出明亮之芒。

## 四、王林的关键突破：第四道虚之本源「轮回」

- 相互印证：「你以骗为道，去骗这天地；我则以人生为道，去颠逆这个世界，去摆正我的倒影——**你我之间，实际上都是修心**。」
- **明确提出**：「虚之本源，若有**第四道，则为轮回**。」并界定其非早年意境中的生死轮回、非黄泉取魂，而是**天地轮回、大道乾坤众生轮回**。
- **道经明悟**：王林迈步中，心神浮现当年在**洞府界**听闻的道经——「囚封天之道，众生需渡无量劫，离开深狱一执念，奉至修真行……锁亡天之运，印冥朝，众生之所不能得真道者，常沉苦海，永失真道，奉至修真行」。当年只是懵懂，如今在东临宗雨幕下**明悟了道经含义**。
- **证道意象**：把生死连接成圆 → 由生死织成因果大网 → 以真假自梦障中睁开双眼 → 挥出网，在众生梦障组成的轮回中**捞取一条鱼，那鱼就是他自己**。
- **旧账了结**：「当年**李倩梅**的三个问题，我如今有了答案。」
- **成因归属**：若非与刘金彪骗道的对证，王林仍将困于迷茫，无法把三道虚之本源看透看清。

## 五、异变：东临宗是一个死宗

- 刘金彪的观察：悟道后的王林与方才不同——之前身上似有一层看不清的迷雾、如人在梦中般不真实；**如今王林仿佛真正从梦中苏醒，一切都清晰了**。
- 王林原以为东临宗弟子几乎从不外出、只在宗内修行是门规习俗，如今判定：这与其心境有关，**更与此地有关**。
- 王林身形一晃出现在远处宫殿之顶，白发衣衫为山风所动，俯瞰大半个东临宗：弟子在雨中疾驰、更多修士在居所打坐、山色秀美、绿树生机。
- 眼中却露出**悲伤**，轻叹：「**苏道**，我不知那一年你在这里时，此宗是否如此。但如今，这东临宗却是一个**死宗**。这一切，都是一场**梦障**。」——由此解释了东临宗为何神秘、为何罕见其弟子外出。
- 章末：王林闭目后缓缓睁开，**看到了一幕外人看不到的东临宗**。
