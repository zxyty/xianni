# 第2072章 心亡，则忘（第一更）

## 一、雨中相认：青虹与「红蝶」

- 场景：雨幕之中，青虹身边有一只蝴蝶落于其手心，被她握住遮挡风雨。
- 王林撑一把油纸伞、白衣白发出现，是青虹眼中的「陌生人」。
- 王林说：「如果你喜欢，你可以成为红蝶。」此时他目中浮现洞府界朱雀星上的往昔一幕幕。
- 青虹称自己在成为**第三步**之时，曾在梦里见过王林。
- 关于轮回：王林点头说「我相信」；青虹答「如果连**白发跃天尊**都相信，那么我也信」。
- 青虹推论：喜欢红色、喜欢蝴蝶必有其因，若非今世之因，便是前尘 → 她认定自己前尘名为「红蝶」。

## 二、前世之前的那一世：一个问题与一句话

- 青虹自陈：在梦里、在前世之前还有**一世**，那一世里她也见过王林。
- 王林当时问她的问题：**「你愿意，保留今生的记忆，还是恢复前世的记忆？」**
- 青虹的理解：前世今生可以共存，但恢复前世记忆后今生会多出很多牵挂；「若不恢复，便不知道，若知道了，就成了忘记不掉」。
- 她当时的回答：**「遗忘前尘，只存今生」**——执着轮回下去，是一种痛，也是一种迷茫。
- 王林由此断定：红蝶想起了一些事，且他「知道了红蝶的选择」。
- 令王林心神震动的是「前世中的前世」这一层——他随即想到**朱雀星梦道**中同样雨幕下的亭榭内，一名女子抱着女婴前来求名，雨中树叶下有一只红色蝴蝶避雨，他遂取名「红蝶」。

## 三、「心亡，则忘」与墨智

- 青虹最后转述那一世中另一人对王林说过的话：**「心亡，则忘」**。
- 王林闻言身躯剧震、震撼源自灵魂，手中油纸伞无意识松开落地被雨淋湿。
- 他脱口而出：**「墨智。」**——回忆朱雀星上自己还是低阶修士时，同样一个雨夜、在庙宇内，一个光头大汉双目带着迷茫对他说：
  - 「这雨，生于天，死于地，中间的过程，就是人生。」
  - 「心亡，则忘。」
- 王林如今回想，那目光内是**清晰的痛与悯**（当时看不透）。
- 王林带着迷茫与「他不愿去想的答案」离去。
- 青虹目送良久，雨散后松手放飞蝴蝶，喃喃：「你什么时候会遗忘？或许，你永远也不会去这么选择。」随后带着落寞孤独走入洞府。

## 四、王林的自问与祖庙咆哮之声的回响

- 王林自问：「当我去开启别人轮回后前尘记忆的时候，我没有去想到，我，是不是也在一次轮回之中？如果我真的在这轮回中，那么谁来为我开启前世的记忆？」
- 他仰天大笑、双眼流泪，宣告：**即便身在轮回之内，也绝不会选择遗忘，绝不会，永远不会。**
- 同时忆起在**始古皇城祖庙内**经历**古道三分神**时，所见那向天咆哮凄吼的身影，其言：
  - 「天地之巅，又有何用？众生皆拜，又有何用？无量劫经，又有何用？」
  - 「既这天地如此，何不毁灭；既这众生如此，何不消散；既这劫经如此，何不断传。」
  - 「我要以我的方式，让青天闭眼，让大地沉睡，让黄泉倒流，**让轮回停止**，让苍穹从此无念。」
- 王林喃喃复述此声，声浪震动天幕大地，仙罡大陆如掀风暴。

## 五、青霖的今生：林化洲的铁匠一家

- 地点：**仙罡大陆·东州·林化洲**西南方向一座凡间城池（远看如巨兽趴伏，雄伟）。
- 城中偏僻角落一家铁匠铺，男主人约三十余岁、身体健壮，打铁认真负责，多年积下好口碑，生意不错。
- 家庭：贤惠美丽的妻子 + 八岁女儿；女儿常为父亲擦汗，父亲每每露出开心微笑。
- 他出生于此城，有一群自幼玩伴，如今各自成家，仍常聚饮回忆少年趣事。
- **梦境**：夜里时而梦见自己如仙帝般叱咤风云、率众与敌厮杀，梦中有离别、热血、悲哀，梦中也有一个女儿，似叫做**霜**——与今世女儿同名。
- 每次梦醒他望夜空发呆，内心亦有渴望，但一看熟睡的妻子与仍不敢独睡的女儿，便在微笑中忘记梦中一切。**若让他选择，他选家人，而非梦的人生。**
- 王林在夜空俯视这一家，感受到**青霖的幸福与满足**：当年的洞府界仙帝如今成为凡人，却得到了开心与温暖。王林很羡慕，看了许久后转身离去。

## 六、主题落点

- 王林结论：「与红蝶一样，他的选择，也是遗忘——遗忘了过去，遗忘了前世，全部身心沉浸在今生中，在那轮回内，一次次的遗忘，一次次的珍惜。」
- 「他们的选择，是正确的；我的选择，也是正确的。」
- 母题呼应：轮回 / 记忆与遗忘 / 虚幻与执着；本章为纯情绪与设定回溯章，无战斗。
