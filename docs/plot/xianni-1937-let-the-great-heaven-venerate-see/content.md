# 仙逆 第1937章 让大天尊看到！

## 一、破封计划（王林传音）
王林察觉上方光幕外断掌所化虚影正凝神看来，遂止住海子天尊说话，改以传音定计：

1. 光幕已近崩溃，由海子天尊操控封印即刻碎开；
2. 卷动封印崩溃之力环绕二人身体护身；
3. 以最快速度向外冲出；
4. 冲出的同时，二人同展最强神通。

王林并点出关键判断：「你师尊定早已来此」——即久帝已在外接应/观望。海子天尊沉默片刻后应下。

## 二、冲出封印
- 海子天尊双手掐诀向光幕一指，光幕上原有的细密裂缝骤然崩溃，碎片疯狂倒卷，余力笼罩二人将其猛推而出。
- 二人化作两道长虹冲出。
- 海子天尊依计幻化**椭圆形印记**（内蕴九十多道神通，光芒极亮），第一击轰在被碎片碰触的断掌虚影上，轰鸣中虚影倒退瓦解化作幽点，但转眼重新凝聚恢复。

## 三、山海上空：三位大天尊隐身观战
地点：南州山海洲，山海上空。三人隐匿至极，神识与肉眼皆不可察。

| 人物 | 外形 | 特点 |
| --- | --- | --- |
| 道一大天尊 | 道袍青年，二十余岁，黑发披肩、剑眉星目，双目如星空 | 岁月沧桑感；所在之处天地万物静止，似万物以静止膜拜 |
| 武封大天尊 | 高大中年男子（高道一一头），骨骼极大、无发、麻布褂子，相貌粗糙，双目惊天动地 | 以武成道、以道碎仙，轰开天地踏入大天尊；成大天尊时封印自身武道、返璞归真，与天地同在，故名「武封」；道一的静止气息对他完全无效（发丝衣衫仍飘动） |
| 久帝 | 青袍驼背老者，其貌不扬、满脸皱纹、目无神采、病恹恹 | 仙族五位大天尊中存在岁月最久者，据说是仙祖存在之时的修士；本名「九帝」，原本相貌英武不凡，无数年来多次转世、第九次成功后改九为久；对道一与武封的气势毫无所感 |

### 三人对话要点
- 道一：「久帝，你那弟子脱困了。」——确认**海子天尊是久帝弟子**。
- 久帝：「若非你二人意愿，我这弟子早可脱困。」——脱困之难源于道一与武封的默许/安排。
- 道一：此事与我无关，「这王林我很好看（看好）」。
- 武封：「此人我也很看重，不过其来历还有端倪，需以此地封印测试才可」——山海树封印是对王林来历的**试探**。
- 道一：「当年玄罗曾来到仙族，只要此人不与玄罗有关就可」——玄罗曾至仙族，是三人验证王林的核心疑点。

## 四、王林的最强一击：残阳之术化「信术」
断掌虚影重凝的瞬间，王林双手抬起：
- 脸上浮现**天牛魂**并蔓延全身，修为暴增，穿上**魂铠**；
- 心念：外面必有大天尊，武封、道一、久帝既然想看他的来历与实力，「那么就让你们清晰的看到」；
- 右手一挥，外界虚无化作**黑夜大海**，海平线上一轮**初阳**升起，万丈金光扩散撕开黑夜；
- 初阳内现出王林之身，闭目而后睁眼，金光中蕴含其**信念**——由此**残阳之术**升格为**信术**。

王林的信念（三句）：
> 我相信，一切黑暗都将散去；
> 我相信，光芒会穿透夜空，照耀大地；
> 我相信，一切与我为敌者，都将云散。

效果：
- 万丈阳光撕开黑夜，穿透断掌虚影，使其刚凝聚即崩溃、幽点散开黯淡（说明**并非全无伤势**），但仍倒卷向远处有再凝聚迹象；
- 金光延展至万万丈，撕开山海树内漆黑虚无，山海树内如藏太阳，金光穿出树干与层层封印，无视黑洞，自海底穿出；
- 漆黑海水一触即褪色，金光穿透海面成伽的黑墨冲上天空，**映入道一、武封、久帝三人眼中**。

三人反应：道一双目爆出精光——「信术」；武封目露凌厉——「天尊修为，竟有如此信念」；久帝则皱眉出手。

## 五、久帝出手与二人脱身
- 久帝右手向下方海水随意一指（无任何虚影幻化，如凡人指动），海面轰鸣沸腾翻滚，化作**巨大海指**向深处点去。
- 王林自海水中一闪而出，对天空三位大天尊视若无睹，化作长虹疾驰而走；海子天尊跟随。
- 其后海水化作漩涡，巨大断掌咆哮一掌欲遮天抓来，被海指一指戳中，去势一顿；海子天尊一脸苍白逃出海面。
- 断掌被一指点落海底，旋即凶残气息骤起，化作虚影向天空咆哮，**能看到道一三人**，遂放过海子天尊直奔三人而去（似不容一指践踏其威严）。
- 久帝上前一步，立于海子天尊与断掌之间，右手抬起。海子天尊唤「师尊」，目光却落向王林离去的方向，神色复杂，暗叹一声。

## 六、看点与伏笔
- **测试**：山海树封印是道一/武封对王林来历的刻意考验；王林选择反向利用——主动「让大天尊看到」自己的信术与实力。
- **玄罗线**：玄罗当年曾来仙族，是三大天尊对王林来历存疑的根源。
- **久帝身世**：仙祖时代的老人，九次转世方成，「九帝→久帝」。
- **断掌**：山海树封印中的存在，被信术所伤后仍能重凝，且敢直冲三位大天尊。
- **海子天尊**：脱困后与王林分道，神色复杂——师徒立场与王林之间的张力留待后文。
