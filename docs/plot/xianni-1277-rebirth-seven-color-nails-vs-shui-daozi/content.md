# 第九卷 云海之巅 第1277章 重生！（第一更）

## 一、七彩神空钉的来历（水道子回忆/设定披露）

- **炼制**：掌尊在**空灵后期**以大神通炼化一颗奇异陨石——该陨石通体由异金组成，在万古岁月中跨越不知多少距离冲入太古星辰。掌尊**生生炼化一万年**，炼成**一百零八根七彩钉**，赐名**七彩神空钉**。
- **窥探过去受阻**：掌尊曾推衍**时光道法**欲看清陨石过去，将成之际被一股**神秘之力打断**，险些重伤；因其为**第三步大能**，仍在打断刹那窥得一丝模糊景象。
- **掌尊的宣告**（宇宙观关键设定，未隐瞒而是宣告天下）：
  > 天地初开化作太古星辰，而后被一分为二，成有**界内界外**；但星空宇洪内并非只有太古星辰，天地初开似乎也并非只分出太古星辰——这神秘陨石来自星空宇洪内**另一处与太古星辰不相上下、隔绝了永恒沟壑的另一片星辰**。
- **威能与诡异**：
  - **专杀第三步大能**，而非为杀寻常修士而生。
  - **遇强则强，遇弱则弱**；修为越高、伤害越大。速度亦**遇快则快，出之无不中**。
  - 第三步修为体内会出现「力量升华」的奇异改变，此变化恰被七彩钉生生克制，故越是大能越难逼出。此理连掌尊也无法尽解。
  - **反例**：碎涅修士或可存活——**司马**当年想出方法解脱；**王林**因肉身之强也曾逼出钉子。

## 二、旧战回忆：掌尊 vs 其主（封界之尊）

- 水道子曾亲眼见掌尊以七彩神空钉与**其主**一战。
- 水道子在那一战**并非主力**：趁其主闭关参透**天逆**之时，以**远古仙域数个大能一同祭炼无数万年的恶毒法宝**偷袭，使其主受伤。
- 随后**太古星辰三尊**出手，与数名远古大能围绕其主**封界之尊**展开生死厮杀，掌尊所施展的正是那一百零八根七彩神空钉。

## 三、本章战况

### 1. 水道子的三重震动
1. 王林**储物空间内庞大的蚊兽群**；
2. 出现的**银衣女子**——水道子一见即认出其身份，**心神震动出现第三步大能罕有的大乱**；
3. 心神一乱之下，王林竟挣脱其**定神术**并祭出**七彩钉**。

### 2. 七彩钉入体
- 七彩钉在储物空间横扫，冲入水道子神识爆发七彩之芒，**搅碎其神识**，冲出储物裂缝直奔眉心。
- 破开星空苍穹，**刺入眉心一寸**，旋转成锥不断深入，欲破头骨钻入脑中**毁其道**。
- 水道子面色苍白，掐诀死死抵抗，**几乎全部修为都用于抵抗此钉**，无暇他顾。

### 3. 逆鳞被触：王林癫狂
- 水道子**妄图取出避天棺内的女子**——**李慕婉是王林此生的逆鳞**，触之必怒。
- 此已非生与死的选择，而是「比生死更为重要的唯一」，王林由「疯狂」转为**癫狂**。
- **铁剑内的血球被王林元神融合**：此血似**九星古神之血**、似**天道之血**，融入元神后其**全身燃烧、元神燃烧、灵魂燃烧**，**定神术全部崩溃**。
- 爆发之象：**眉心古神星点急速旋转**、**意境所化规则之星**出现；双目通红、红芒数丈；体内砰砰之声难辨心跳或骨骼碰撞。手持**三叉戟**直扑水道子。
- 水道子瞳孔收缩急速后退，**所畏惧的并非神通，而是王林体内的血煞红光**。

### 4. 大自在绝空道
- 王林将全力灌注三叉戟抛出，戟化**恶龙**咆哮而至。
- 水道子冷道「第三步与你等蝼蚁之间的差距」，掐诀施展**大自在绝空道**：气浪自星域四面八方来临，封锁**千万范围**星空，白色线条交错成**巨大菱形**并急速收缩。
- 喝出「**绝、灭、崩**」，菱形自千万→百万→十万→五万→三万→一万→八千→五千→三千→一千→五百→**百丈**，瞬息完成，形成毁天灭地的挤压，尽落王林与其三叉戟之上。
- 威力：约等于**数十个修真星同时崩溃**；轰鸣震动星域，**五阶、六阶、七阶乃至八阶星域**均可听闻。
- 结果：**王林身体轰然崩溃，血肉散开，头颅爆开**；**三叉戟碎灭**，其内传出似**戟魂死亡**的惨哼。

### 5. 重生
- 叙述强调：从古至今**从未有任何第二步修士战胜第三步**，几乎是与天地规则同样的至理。
- 但散开的血肉**妖异红光闪烁，好似一切逆转**，瞬息收缩重新凝聚出王林的身体——**新生**。
- 水道子愣住：「这……这不可能。」

## 四、要点提示

- 本章王林在云海星域以化名**吕子浩**立足（自第1063章，由吕烟菲奉上），水道子亦直呼其名；但**行为主体为王林本人**。
- 「重生」的机理未在本章解释，直接指向**铁剑血球（九星古神之血/天道之血）融入元神**这一伏笔。
- 未解之谜：银衣女子身份（水道子一眼认出并大乱）、异金陨石所来自的另一片星辰、七彩钉克制第三步的根源。
