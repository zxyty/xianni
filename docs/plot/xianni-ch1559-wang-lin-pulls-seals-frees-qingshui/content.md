# 第1559章 谢谢……

## 一、拔刺过程（第五至第八根）

七彩身影提示「还有六根封刺，你可以继续」。王林压下心中疑虑，逐一动手：

- **第五根（丹田）**：七彩身影称「封印的是其元」。王林体内仙力与道古之力同时运转，冲入右臂握刺猛拽。刺出，其右臂砰砰爆出血雾，身形连退数步。
- **第六、七根（双腿）**：不待对方开口，王林低吼一声，双臂金光闪烁、道古气息弥漫，双手同拽而出。坚毅如清水亦忍受不住，惨叫被咬牙化作嘶气之音。王林身体猛颤，嘴角溢血，体内排斥之力达到巅峰。
- **第八根（天灵旁数寸，倾斜）**：七彩身影道破——此刺「并非封印，而是打开其轮回」。此刺几乎全部没入天灵，外露仅两寸，位置为生死交汇之地，王林罕见地在一寸前停手。清水抬头，目光清澈，点头示意。王林抓住刺的一刹那，大量扭曲的记忆碎片涌入脑海，胀痛欲狂，但手不曾颤抖，一点点将刺完全拔出。

拔出瞬间，清水嘴角流血，脱离山峰倒入王林怀中，虚弱到几乎没有重量，只留下一句——

> 「谢谢。」

说完便昏迷。王林扔下利刺，扶住清水，眼中流下泪痕，唤其「师兄」。

## 二、道果之赠

拔完第七根后，七彩身影称最后三道封刺不易取出，若能做到便赠礼；随即右手向上一抓，自七彩雾气中幻化出一枚巨大黄色果实（**道果**），指尖一扫折断连接的枝条，果实落下。王林对此物与赠予者充满忌惮——「这一切绝不会是凭白无故」，其感觉如同当年面对**天运子**：猜不到，想不出。最终七彩身影言「余下两道封刺更难，你将其带走，离开这里吧」，并将道果送至王林手中。

## 三、临别问答：游戏与「仙尊」

王林将去未去时回身发问：

- **「为什么？」** —— 「他只不过是一场游戏，你想救出，索性让你带走。至于为什么……我想看看，造化之功下，在这里出现的灵修，会不会如那**战源小子**一样，出现美妙的变化……或许在这变化下，我能找到**他**。」
- **「你要找什么？」** —— 「如果你能遇到，你会知道。」随即挥手操控王林身体不由自主后退。
- **「你是不是仙尊？」** —— 「**是，也不是**。」

王林眼前一花，已立于**昆虚星域**星空，身后七彩界裂缝缓缓收缩、消失无踪，身体恢复自由。他心中疑问：七彩之人所说的「战源小修」若即**战老鬼**，那战老鬼身上究竟出现了什么「美妙的变化」？这种变化又如何能让对方找到其所寻之物？以及——「清水身上的事情，只是一场游戏么？」眼中寒光一闪。

## 四、退往蛮荒星继续解封

王林抱清水现身于**联盟总部**范围外一处**蛮荒星**：无修士、无灵气，唯有凶兽栖息，对王林而言却是为清水取下余下封印的最佳之地。他在一处山谷盘膝，将昏迷的清水置于身前，闭目吐纳欲压下体内排斥之力，却终难做到，只能在剧痛中略作缓和。其体内仍有无数如长在肉中的利刺，每次呼吸都在提醒其存在——**这一次救清水，代价很重**。

## 五、心境与主题

- 纵使代价极重、纵使「不符合他的心智」「很愚蠢」，若再选一次王林仍会毫不犹豫。
- 他此前等了多年才来，是因当时修为连一丝把握都没有；如今有了一丝把握，若再等到成为第三步大能，届时不知清水是否还活着。
- 若换成清水，王林相信对方也会做同样的选择去救他——「这一点，就足够了」。
- 篇末点题：王林不是君子，不是无情修，他是**有血有肉、至情至性**的人。

## 六、待解悬念

1. 清水身上最后两根封刺尚未取出，取出难度远超前八根。
2. 七彩之人所寻之「他」为何物/何人；「是，也不是」的仙尊身份。
3. 第八根刺「打开其轮回」的真正含义，以及涌入王林脑海的扭曲记忆碎片来源。
4. 道果的用途与代价——七彩之人赠礼动机不明。
5. 战老鬼（战源小子）身上所谓「美妙的变化」。
