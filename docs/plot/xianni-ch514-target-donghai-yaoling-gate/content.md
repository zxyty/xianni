# 仙逆 第514章 目标，东海

## 一、逼供：一刀一剑的压制

- 大罗剑宗矮个老者被王林两件法宝逼得放弃抵抗、原地等待王林到来，主动表示知无不言。
- **古怪飞剑**：剑芒威力不算大，但**坚固异常**，任何法术神通对其无效——老者动了夺来研究之心。
- **弯刀（许立国）**：老者形容其「如收割生命的远古魔神」，速度太快，自始至终死死贴住其眉心，如被无形之手掐住咽喉，只要一用力便必死。这是他彻底放弃逃遁的直接原因。
- 老者内心悔恨：不该与**石方**一同来**地星**，惹下王林这等煞星；此刻已无暇顾及石方死活，只求保命。

## 二、王林的问题与关键情报

王林右手数道灰气缓缓流动，给出「只一次机会：犹豫，死；答不出，死；与石方所说不同，死」的三死条件，问：**多年前剑尊自仙界归来时，可有异常之事？**

### 1. 剑魂之谜
- 剑尊归来时，有一道**极为可怕的剑魂**从天际破空追来。
- 双方斗法数日，剑魂最终崩溃、化作无数。
- 剑尊将其中**三分之一**封印、压制在**东海妖灵之门深处**。

### 2. 东海妖灵之门（天运星外三大禁地之一）
| 项目 | 内容 |
|---|---|
| 地位 | 天运星外三大禁地之一 |
| 掌控权 | 每万年一换，本次归**大罗剑宗** |
| 内部 | 有**古妖**存在；深处封印剑魂三分之一 |
| 开启 | 每**五千年**一次 |
| 参与 | 天运星各宗派派遣弟子进入抓捕古妖 |
| 实质 | 一场血腥试炼，凶险极高；出来的人越少，好处越大 |

### 3. 东海妖灵灌顶（真正的好处）
- 出门瞬间可获一次灌顶，**强行提升一个境界**。
- **问鼎之时**受灌顶：把「**闻道夕死之槛**」立刻降到最低，达到问鼎的机会无限增加。
- **已有问鼎修为**者：借灌顶可再迈一步。
- **问鼎后期**灌顶：或可踏破那一步，迈入「**阴阳虚实二意**」，成就**数万年寿元不灭之身**。

### 4. 传闻中的至高赏赐
若最终走出者**只有一人**，将得到妖灵之门自始至终从未出现过的赏赐：**一个完整的下品仙术**。

## 三、灭口与两度身死

1. 情报到手，王林沉默少顷，心念一动；**许立国**心有所感，弯刀突发幽芒，瞬间穿透老者头颅、自后脑穿出。老者喷血、指着王林倒地不动。
2. 王林右手一召，**弯刀与仙剑收回储物袋**，身形一闪消失。
3. **三柱香后**，老者忽然睁眼，眉心伤口诡异蠕动融合——自陈修炼「**三分神识之术**」，可保三次寿命，今日用掉最后一次。他神态萎靡，回头恶毒望向虚无，扬言回大罗剑宗后必设法置王林于死地。
4. 其身影一动的瞬间，**两道灰气**自山脉丛林中无声无息破空而出。老者喝出「散」字，身周扩散大片空气波纹阻挡，同时半身踏入虚空欲瞬移遁走——但仍晚了一步。
5. 灰气无视波纹直接穿透，如疯狂挥舞的锁链冲入其体内疯狂旋转，**每旋转一圈，生机便消失一片**。老者面白惨笑。

## 四、要点提炼

- 本章确立王林新的目标方向：**东海妖灵之门**（章名「目标，东海」），动因有二：剑尊封印的**剑魂三分之一**，以及可越阶提升的**妖灵灌顶**。
- 王林行事风格延续冷硬：先逼供、后灭口，且预先在丛林中埋下灰气伏杀，防的正是「假死/复活」一类保命手段。
- 新增设定：三分神识之术（三次保命）、闻道夕死之槛、阴阳虚实二意、下品仙术、天运星外三大禁地。

## 五、归属说明

- 「石方」已于第486章死亡，本章仅为矮个老者的回忆式提及，未有新行动。
- 弯刀的行动由许立国（化形魔头，被王林收服炼化为刀形态）执行，受王林心念驱使。

# 第514-515章 地魔北界杀戮仙诀小成 · 天运东海为何

## 一、地魔北界中的十天杀戮

- 王林穿梭于地魔北界深处，体外灰气时浓时稀，右手指尖数道灰气打旋窜动。
- 途中察觉身后有异，冷笑相待；一道浓灰气自丛林穿来，在其身前化作灰色球体静止；王林右手虚空一抓将其收去，球体消失无影。
- 最近十天，地魔北界几乎充满灰气，大量灰气自一处处之地升起，带走无穷生机。
- 关键分寸：灰气**从不接近三十万里之内**，加之持续仅十天便消散一空，故未惊动那些强大荒兽，未生变故。
- 地魔北界越向深处凶兽越强，三十万里内有相当于**问鼎**修士的荒兽不少。

## 二、杀戮仙诀小成与「生之烙印」

- 十天后王林走出地魔北界，身上多了一份**隐藏极深的杀机**：双目隐有灰芒，右手五指之间五道灰气飞快旋转，发出轻微呼啸。
- 该呼啸声似蕴含奇异之力，闻者心神会不由自主被吸引。
- 自评：「**杀戮仙诀，算是小成**」。
- 「转换生机为生之烙印，难度不小」——此番杀戮最终**只凝结出三份**。
- 生之烙印形态：眉心浮现灰色符文，构造不复杂但弥漫浓浓生机；一出现便无限延伸，转眼顺眉心弥漫全身。共三个符文先后延伸，将王林全身覆盖。
- 防御验证：王林搓指成剑轻轻一扫，接触处只传出摩擦之声，**指剑未能穿透**。

## 三、赴东海的三个理由（王林自述）

| 序 | 理由 |
|---|---|
| 一 | 东海妖灵之门正是适合修炼**杀戮仙诀**之处 |
| 二 | **报恩**：周佚前辈对己有恩，其被**剑尊**封印在东海妖灵内，「我王林一生，有恩者必报答」，须去尽力救助 |
| 三 | **顺运**：师尊天运子讲究一切天运而定，决不会做莫名之事，令其去东海必有原因；不去反是逆运而行，将难以在天运宗站稳脚 |

### 附带私愿

- 盼东海妖灵之门内另有机缘，寻得**增加金属姓**之物。
- 若**天逆圆满**，想必对婉儿大有好处，「使其苏醒，也说不定」。
- 摸眉心时眼中闪过追忆柔情；想到李慕婉，冰冷的心有一丝暖意。**李慕婉是唯一走进他心、伴随他来到天运星之人。**

## 四、时间线锚点

- 东海妖灵之期为三个月之约；王林走出地魔北界时**只剩六天**。

## 五、第515章 东海为何——天运东海设定

- 位置：**天运星之外**苍茫星空，地处天运星**外东部**，久而久之被称为「天运东海」。
- 形貌：一大片漂浮之物相互凝聚，形成密密麻麻看不到尽头的**漂浮之海**；单调的**青红二色**贯穿全境。
- 机制：每隔 **5000 年**散发一股奇异之力，将星空中大量奇异之物（尸骸、法宝，一切皆有可能）禁锢吸入其内。
- 特性：如同**聚宝盆**，只吸收、**从不释放**；若要寻宝，只能亲身进入一探。
- 来历：无人知晓如何形成；据说天运星出现之时，此地便已存在不知多少岁月。

### 两种主流传闻

1. **仙府说**：此地乃当年仙界一位强大**仙君**的界外仙府，仙界崩溃后不知为何受牵连，最终化为**归墟之状**；而归墟只是一种法术的保护，有机缘之人进入其内，定可令仙府恢复如初。
2. **通道说**：此地实为连接**不知名空间**的通道，说不定可在此寻到传说中**凌驾于仙界之上的另一个世界**。

> 种种传闻多不胜数，绝大部分言之凿凿，似有莫大根据。

## 六、要点提炼

- 王林战力结构新增一层：三份生之烙印构成的**符文护体**，指剑不可穿。
- 动机三合一（修炼 / 报恩 / 顺师门天运），凸显其「有恩必报」与在天运宗立足的现实考量。
- 李慕婉仍处未苏醒状态，是王林追求「天逆圆满 / 增加金属姓」的核心驱动。
- 天运东海被同时设定为**修炼场、寻宝地、囚牢（周佚被封印处）与疑似跨界通道**，为后续东海之行埋下多重伏笔。

# 东海妖灵之门：禁地由来与开启规则

## 一、由来：天运子三探东海

- 天运子**成道之日**，曾邀请至交好友数人同行，其中包括**尚未翻脸前的剑尊凌天候**。
- 一行数人对东海进行过**三次探索**：
  - 前两次：均空手而回。
  - 第三次：进入后，最终出来者**不足半数**。
- 第三次之后，**剑尊凌天候与天运子分裂**，多年来二人对第三次东海之内发生之事**始终闭口不谈**。

### 封禁与「古妖」之名

天运子留下一句话：

> 「这东海内，有古妖存在，此地，从此之后，便是我天运星禁地之一，东海妖灵之门。」

- **「古妖」一词自此流传而出**，被无数人记住。

## 二、外界态度与修真联盟的默许

- 修真联盟亦曾派人前来查看。
- 天运子、剑尊凌天候、以及四周其他修为高深的老怪，**态度罕见地一致**：决不允许任何外界之人进入，此地是天运星禁地。
- 这种状态持续很久后，东海妖灵之门**自然而然成为天运星的禁锢之处**。
- 星空之中如此类神秘之处**不算多但绝对不少**，修真联盟不愿为一处神秘之地与天运星众多修士交恶——在他们眼中**「不等值」**。

## 三、开启规则

| 项目 | 内容 |
| --- | --- |
| 周期 | 每 **5000 年**一次，为天运星头等大事 |
| 开启幅度 | **只开启一半**（此地为各宗派弟子准备，以削弱其内危险） |
| 潮汐之相 | 开启瞬间起，维持**数月** |
| 入内人数 | 少则成百，多则上千 |
| 修为下限 | 最次为**婴变** |
| 实际上限 | 最高者甚至有刚摸索到**阴阳虚实二意**之人 |
| 硬性禁令 | 修为**超过问鼎者，决不允许进入** |

### 潮汐之相

- 本质是东海妖灵内那**奇异之力扩散而出**，弥漫无数范围。
- 届时在此地的修士均可看到：无数**奇珍异宝、法诀仙术、妖兽尸骸、奇异之物**，好似被吞噬一般，从四面八方**生生吸入东海之内**。

### 变数

- 每逢开启，天运星外几乎所有老怪都会派出弟子前往——此行凶险莫名，但为 5000 年一次的机缘，错过太可惜，不如一搏。
- **世事无绝对**：若开启之日潮汐中出现**极为吸引人的逆天之物**，将立刻使老怪动心；老怪一旦动心，门内便会**极为热闹**。

## 四、开启前五日：东海之外群修云集

- 时点：**距离开启还有五日**。
- 东海之外虚空已密密麻麻来了无数准备入内的修士，身穿各种不同道服，彼此交错但**泾渭分明**，各宗派弟子相互聚在一起。
- 时有久不露面的老怪携弟子到来，每次出现都引起阵阵喧哗，绝大部分修士纷纷避让让路。

### 血星之祖到场

- 一道**红芒几乎笼罩星空**，浓浓血腥之味弥漫，无数范围内映照成**血色世界**。
- 有人认出「**血星之祖**」，四周绝大部分修士生生止住喧哗。
- 血色之光中，一尊**通体血色的巨大玉石（血玉）**自星空缓缓飘来，其上坐一女子。

#### 姚惜雪（血祖之女）

- 外貌：双目如凤、眉角带煞、身穿**白色衣衫**（与坐下血玉形成强烈视觉冲击）；苗条身姿、黑色青丝、嫩白若玉的瓜子脸、水晶样肌肤、精致鼻梁；**丹凤眼**表面如朝阳映水波潋滟绚丽，内里却隐着**深邃与幽寒**，「如若不小心陷进去，结果将是万劫不复」。
- 行止：一路飞来**一语不发**，所过之处修士纷纷散开让道；血玉一直进入到东海妖灵之外一处较为空旷之地停下，随即**双目一闭，就地打坐**。

#### 血祖姚星海（背景补述）

- 天运星范围内出了名的老怪，修为通天。
- **七次挑战天运子**，最终全部失败，但修为越来越高；尤其第七次与天运子之战，展现出一身**惊人的血功**。
- 在天运星外**独自占据一星**（血星），**圈养土著为其开荒纳血**，修炼**魔功**。
- 一生未收徒，只有一女，视为掌上明珠：把一身功法**尽数传授**，更为其**逆天改命、成就神通之术**。
- 父女二人常年居住血星，轻易不与外人接触；越是如此，越无人敢惹。

## 五、地星·玄渊派：传送阵待发

- 位置：**天运星外五颗副星之中的地星**之上，玄渊派范围内，一座**最大的传送阵法之外**。
- **玄渊派少宗许云山**（原文此处又写作「孙云山」）安静站立，手持**翠玉扇子**下意识敲打手心；目光平静，却时而看向远处，脸上没有半点不耐之色。
- 其身后跟着**三名白发苍苍的老者**，穿着朴素，但气息惊人，使四周空气似乎都变得稀薄。
- 外围：**数百玄渊派弟子**分坐传送阵各个角落，闭目吐纳、一语不发；只需一声令下，便会全力释放体内灵力，**配合阵法内的仙玉**开启阵法。

## 六、待解疑点

- 第三次东海探索中究竟发生何事——天运子与凌天候皆闭口不谈，且由此决裂。
- 东海内「古妖」的具体形态与来历未明。
- 本次开启的潮汐中是否会出现「逆天之物」，从而引来老怪入内——文中已埋伏笔。
- 人名歧异：同一人物先后作「许云山」「孙云山」，本条以**许云山**为规范名。

# 第515-516章 贪狼之行（东海妖灵之行启程）

## 一、地星传送阵前的等候

- 地点：地星之上的星空传送大阵外，阵外有数百弟子待命输灵。
- 孙云山手持折扇，率三名玄渊派长老在此等候多日。他原本昨日就要出发去**东海妖灵之门**，因听闻王林是**天运子**前辈钦点之人，便刻意多留几日，以求结伴同行。

## 二、孙若南求随行被拒

- 一道粉霞飞至，化作双十年华的粉衣少女——孙云山之妹**孙若南**。肌肤晶莹如水晶，幽香扑面，声如百灵。
- 她以“哥哥答应过我，只要赶上就让我去”相争；孙云山斥其胡闹，理由有二：
  1. 以她的修为根本不能去东海妖灵；
  2. 父亲虽在闭关，但已下令不许她去。
- 孙云山命长老**玄一**上前带她回宗派；孙若南搬出“娘答应了”，孙云山不为所动，最终仍以“不行”一口回绝。

## 三、王林抵达与结伴

- 远天一道紫虹如奔雷破空而来，落地化作**王林**。王林称“路上有些事情耽搁了时日”，抱拳致意。
- 孙云山说明：三名老者为**玄渊派长老**，此行负责其安全；他自陈修为远不如王林，东海一行危险太大，若非家父坚持并不愿去。
- 引见其妹：“这位是天运子前辈嫡系弟子王林王道友。”孙若南施礼称“王大哥”，暗中打量王林时**眼中闪过一丝诧异**（伏笔）。
- 王林含笑点头，未多看一眼，目光径直落向阵法——孙云山七窍玲珑，即刻会意提议启程。

## 四、星空大阵开启

- 王林与孙云山不分彼此并肩踏入阵心；玄一及另两名长老随入，孙若南被留在阵外。
- 此阵非寻常之阵，而是**星空之中的阵法**，开启所需**灵石与仙玉数量极大**。
- 开启景象：数百弟子同时运转灵力灌入阵中，面色苍白而身形不动；阵上轰鸣，浩淼之力化作气浪扩散；一道**百丈长虹冲天直插云霄**，光环波纹弥漫地星大半个天空，持续**半柱香**方缓缓消散。

## 五、孙若南偷渡

- 长虹贯空瞬间，阵外的孙若南眼中闪过得意，自储物之物中取出一枚**牵引传送玉简**——系从其父处偷来。
- 其盘算：“你不让我去，我便偷偷跟着……说不定这一次我能在那东海妖灵内，寻找到什么宝物呢。”

## 剑尊凌天候降临

距开启两天时：

- 剑芒中一头**巨大麒麟兽**呼啸而走，**剑尊凌天候**盘膝坐于其上，目光如炬，身后**四道剑光虚影**剧烈闪烁。

- 天运星上人尽皆知：**剑尊凌天候一生只与天运子作对**，二人之争持续不知多少年月，至今仍在继续。

- 对标关系：
  - 天运宗有**天运七子** → 凌天候便弄出大罗剑宗**剑肖十二子**；
  - 天运七子有**仙术传承** → 剑肖十二子便有**妖灵守护**。

## 凌天候的真实目的：处理仙界剑魂

凌天候本不愿提前来此，但此行妖灵之门对他极为重要。他望向前方漂浮之海，眼露追忆：

1. **当年从仙界回来**，有一道**剑魂**始终纠缠，其威力令他大吃一惊。
2. 他最终将剑魂**引入东海妖灵之内**，以**秘术**困于其中。
3. 此次他要借**5000年一次的潮汐之相**，把剑魂**彻底吸入东海深处**，使其永不回来。
4. 心中判断：「这剑魂是**仙界那女君**之物，此物虽非同小可，但老夫既然无法驱使，就决不能落在别人手中，**尤其是那天运老贼**。」

## 骷髅中年男子破空而至（转折）

凌天候沉思间神色一动，抬头望向远处虚无：

- 此人**一路横冲直闯、如入无人之境，直接破碎虚空**，出现在无人敢踏入的**剑尊凌天候百里之地**。

## 二、潮汐之相（第518章）

### 演化过程

1. **轰鸣**：东海之上传出轰隆之声，如平静水面投石，涟漪阵阵；声音越来越剧烈，上接天际、下传虚无，连成一片。上万修士目光尽聚于漂浮之海，四周极静。
2. **旋转**：漂浮之海中心突起刺耳呼啸，如鬼哭狼嚎；所有漂浮之物一颤后缓缓旋转，惊天动地，似整个星空都在旋转。修为不足者身不由己向前飘去，若无人拉住便会融入漩涡。王林**道心坚定**，不受此等旋转神通迷惑，身子一动未动。
3. **青气凝聚**：一股青色气体自漂浮之物上扩散，转眼包裹整片漂浮之海，随即疯狂沸腾并向中心凝聚。
4. **青色气柱**：星空一震，青气与漂浮之物尽聚一处，形成泉眼状奇物，不断增高增大，最终高达**千丈**，如支撑星空的擎天之臂，转眼延伸至神识可探索的范围之外。
5. **威压**：气柱散发出比天威浓郁无数倍的威压。王林如负十万大山，体内啪啪作响似将崩溃，**眉心灰气闪烁化作符文，自脸部覆盖全身**，方达其承受极限。四周修士面色苍白大量退开，甚者若无师门长辈相助便会当场崩溃而亡。
6. **崩溃化赤芒**：青色气柱轰然崩溃，红光自崩溃处疯狂宣泄四散，穿透修士身体直入星空深处。天运星东部三大禁地之一的东海妖灵之门处，青光渐散，取而代之的是无尽**骄阳般的艳红**（非血红），以门为中心向四周无穷散去。

### 覆盖范围

- 距天运星不知多少距离之外的蛮荒星球被赤芒笼罩。
- 更遥远的**朱雀星**亦被覆盖：朱雀子周武泰打坐中忽然睁眼，见整个朱雀星天空一片赤色。
- 更远处更多星球纷纷被赤色覆盖；具体散出多远，除有限几人外无人知晓，已无法清晰计算。

### 赤芒的效果（核心悬念）

赤芒蔓延至极限骤然停止，停止的瞬间，所有被赤芒笼罩之地发生惊天异变：星空中、星球中、虚无中，**一切无主之物**——法宝、玉简、灵石、仙玉、尸骸、古剑、残宝、仙诀、上古修宝等，无论残次与否，只要在赤芒范围之内，**尽皆颤动**。

## 三、伏笔与看点

- **命运之宝**：天运子明言潮汐间或有王林此行的命运之宝——赤芒引动无主之物，正是其机制铺垫。
