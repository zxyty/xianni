# 《仙逆》第921章 青色玉简（第八卷 联盟隐秘）

> 世界状态须知：本章「许木」为王林自创化名，所有言行归属【王林】。

## 一、古神震动与望月来历之疑

- 来自**本尊古神**的震动使王林双目一闪，眉心**古神之星**几乎若隐若现；王林深吸口气强行压下，古神之星复归平静。
- 王林盯着远处摇曳万丈触须的**望月**，内心震撼，回忆起：
  - 当年他曾借望月摆脱**姚家**追杀，藏身其体内；
  - 藏身期间便感觉到有**罗天星域**之人在打望月的主意。
- 疑问：是何人能将望月驱逐、当成法宝送至**修真联盟**？王林脑中浮现两次看到的神秘身影：
  1. 第一次：清水与**血神子**一战时；
  2. 第二次：封一百零八仙后，**撕开两个星域通道**之时。

## 二、参天巨木上的格局

参天巨木冲击星空、呼啸威压磅礴，无数修士踏法宝紧随左右，而**能站上巨木者不足百人**——这代表此地极为尊贵的身份。

| 位置 | 人物 | 说明 |
|---|---|---|
| 巨木首部 | **烈云子**（战家老祖）、**申公老祖** | 背手而立，长衫无风自动，目光如电，神色冰冷 |
| 其后 | 绝大部分为**一百零八仙**之人，另有若干陌生强者 | 修为多处于**阳实巅峰** |
| 其中 | 达**窥涅**者十余人 | — |
| 特别注目的三人 | 见下 | 修为王林**看不透**，实为**窥涅后期** |

### 王林看不透的三人

1. **黑袍疤痕老者**：盘坐巨木右侧，一身黑袍、白发苍苍，脸上数道疤痕并非静止而是隐约蠕动，诡异骇人。与王林对视后，嘴角露出充满寒意的微笑。
2. **宫装妇人**：约三十许岁，丰姿绰约，肤色奇白、鼻梁较高、眼中隐有海水之蓝；淡绿色繁花宫装外披金色薄纱，衣摆绣紫色花纹，额前垂一枚小红宝石。对王林婉约一笑，笑中自有高贵不可侵犯之意。
3. **三笛白衣青年**：一身缎素白衫，身前三支竹笛环绕，笛音如若实质，在其四周化作一片虚幻之相，看一眼便可迷失心神；一脸傲意，起初对王林看都不看。

## 三、王林踏上巨木

- 王林凝聚的修士队伍达**数百人**，远超沿途只有几十人且零散狼狈的罗天队伍；加之身后**飞天虎**咆哮远传，几乎所有修士都看向他。
- 众修士议论：「**雷仙许木**」——封仙之战中力压群雄，连**东临星的许霆**都甘拜下风，最终获得**正品雷仙封号**；多数人只在家族修真星的传音石上见过他，并未真正见面。
- 烈云子见到王林，冰冷之色融化，微笑招呼：「许木，到老夫这里来。」
- **踏木之法**：巨木冲击带起的呼啸形成极大阻力，王林行走如在云泥之中。他察觉后，令体内元力运转骤然**减速至几乎静止**，下一息又**疯狂爆发攀升至巅峰**；这一静一动爆发出极强气势，所在星空轰隆作响将崩，身外虚空扭曲，凝聚在他身上的所有目光尽数崩溃瓦解。他神色从容，无任何阻碍地踏上巨木。
- **意义**：这一路上除烈云子、申公老祖外，唯有三人能如此轻松踏上巨木，**王林是第四人**；巨木上近百人中，绝大部分是靠法宝与大神通之术费尽辛苦才勉强踏上的。
- **三位窥涅后期的判断**：他们眼力高出旁人，看出王林这一静一动爆发的不仅是元力，**还有一丝规则的明悟**——窥涅修士中主动明悟规则者并不多。因此虽知其修为不如自己，仍将王林视作**同一层次的修士**。白衣青年猛地睁眼细看王林并略一点头；宫装妇人笑容更盛；黑衣老者目光亦有不同。
- 修真界以实力至上，想获得认同唯有达到同一层次。
- 王林站到烈云子身边，恭敬抱拳：「许木，见过烈云子前辈。」随后转身向申公老祖抱拳。

## 四、望月暴怒与青色玉简

- 烈云子正要说话，面色骤变：一直跟在巨木后方的望月一震之下仿若发狂，剧烈吼叫，**双目露出迷茫与清醒交替之色**，死死盯着巨木上的王林。
- 音爆弥漫星空，巨木外修士首当其冲，面色大变、心神震动。
- 王林冷冷回看：**被望月认出并不出他意料**——他深知此物对惹怒它之物记忆最深，而他曾**两次招惹**望月。
- 望月触须疯狂延伸，直奔巨木而来。
- **烈云子出手**：皱眉，右手虚空一抓，前方虚空裂开一道缝隙，从中飞出一枚**青色玉简**（外表寻常、毫无出奇），向望月一抛。
- 玉简速度极快，刹那临近望月，在其咆哮中「砰」的一声崩溃；崩溃刹那有一个如雷鸣般的声音回荡——「**荀芸岣**」。
- **关键悬念**：此声极为古怪复杂难明，四周无人能知其含义，**唯有王林内心一震**——这声音是**古神之语**；在听懂其中含义后，以王林的定力也不由得面色一变。（章节至此中断）

## 五、要点小结

- 望月被人当作法宝送予联盟，幕后疑为王林两度撞见的神秘强者，线索指向罗天星域与星域通道之事。
- 王林（许木）正式以雷仙身份跻身巨木核心圈，获窥涅后期三强者的层次认可。
- 联盟高层（烈云子）手中握有能震慑望月、且承载**古神之语**的青色玉简，暗示联盟与古神体系存在隐秘关联，直指本卷「联盟隐秘」主题。
