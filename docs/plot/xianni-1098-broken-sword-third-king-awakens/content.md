# 仙逆 第八卷 联盟隐秘 第1098章 断剑

## 一、尸阴宗：玉简唤醒第三王

### 场景
- 地点：联盟星域南部、尸阴宗所在区域中心，一片**锁链棺木**所在之处。
- 李莹芝单膝跪地、双手放于胸前如膜拜，身前漂浮一枚散发乳白光芒的**寻常玉简**——但它足以让整个联盟星域陷入浩劫。

### 献简与手臂
- 李莹芝详述进入四圣宗后的一切前因后果，交出玉简。
- 玉简被无形之力卷向棺木群正中最大的一具棺木；一只干枯手臂探出抓住玉简：黑色为筋、红色为肉，散出上古沧桑之气。
- 手臂现身刹那，阴气环绕、阴寒风暴横扫，李莹芝连连后退却面露极端恭敬。

### 第三王的神识
- 棺内散出极庞大神识，狂暴嗜杀、令人自然生出血腥之感（实无血腥味，乃心神所致）。
- 李莹芝面色惨白、元神颤抖，跪称「弟子李莹芝，参见**第三王**」。
- 她原本预估此简最多能唤醒**第五王**，此刻方知低估了玉简内尸体的分量。
- 整个联盟南部所有修真星上的尸阴宗弟子同时感受到神识笼罩，尽皆弃事跪拜。

### 赏赐与判定
- 赏：李莹芝当立**首功**，可入**尸坑第六层**选一具尸傀（第六层藏有传说中的奇尸）。
- 李莹芝猜测该尸为**太古时期的古神**；第三王大笑确认——不仅是古神，更是**王族古神、王族八星古神**，语中贪婪足以引动星域天地元力变化。

### 第三王的命令（全宗动员）
1. 召集尸阴宗所有弟子，**以血祭天**；
2. **重灌尸坑**，打开**第九层**，取出其中**八具肉身**——此次**尸阴九王将出八人**；
3. 召回**所有长老**；
4. 定调：此王族古神肉身，尸阴宗**必须得到**；
5. 第三王本人**将亲赴四圣宗**一趟。
- 声如雷鸣传遍联盟星域南部，众人颤抖抬头恭敬称是，如同一场音爆。

### 真伪判断
- 李莹芝忧心：玉简由她带回，若内容为假，后果不堪设想。
- 第三王安抚：以**朱雀圣皇**的身份让她带回，此简**有七成为真**；以四圣宗的势力，不会轻易传出虚假消息同时戏弄**尸阴宗、罗天、修真联盟**三方。

## 二、联盟局势：暗流涌动

- 两枚玉简如两只无形大手牵动联盟星域无数人之心，暗流渐起。
- **墨智**回到**出云国**后，**三枚玉简**迅速传出，送往联盟势力最强的其余三方。
- **罗天战事停止**，大量修士离开战场。
- 尸阴宗**停止与各方交易尸体**，迅速撤离，诸般诡异变化引起联盟修士高度重视。

## 三、王林：阳谋与备战

### 处境与修炼
- 风云的创造者王林却平静居于**朱雀圣宗**，整日盘膝坐于火山边缘打坐。
- 大战在即，时间不多，他必须尽快提升神通以在大战中求得生存空间。
- 同时他在**等**——等尸阴宗与罗天之人再次来临；他有信心，送出的两枚**不同内容**的玉简会让两大势力蜂拥而来。

### 为何是阳谋
- 王林心智过人却少用计谋；以他从前的状态，计谋只是阴谋诡计。如今**有四圣宗在后**，他所用的是**阳谋**：
  - 明明白白告知所有人古神的消息，各方也都清楚王林必有图谋，但看破无用；
  - 若在他成为**朱雀圣皇**之前放出，非但无用，反会招来杀身之祸——罗天与尸阴宗的第一选择必是擒拿逼问；
  - 如今三方之外尚有水火不容的**修真联盟**牵制，加上四圣宗的神秘与当年霸主底蕴，一旦开战代价太高，故无人敢动手。
- 这是王林敢散布消息的真正原因。

### 身份已非秘密
- 王林自知「他是古神之身」在联盟星域大神通修士眼中已非秘密：**妖灵之地**一行他大放异彩，更曾施展**梦回远古**之神通。
- 这也是他当初痛快答应**朱雀老圣皇**前来朱雀圣宗的重要原因之一：以当时伤势，若无依托将在联盟星域寸步难行、终日被追杀，早晚被擒。
- 因此他散布**拓森**的消息可信性更高——此事无必要说谎，到**朱雀星古神之地**一见便知真假。

### 计中计
- 王林沉吟：「罗天、尸阴宗、修真联盟三方齐去古神之地，不知能否对付**拓森**」，随即不再深想。
- **引三方齐赴朱雀星只是计划第一环**，其后还有一个**计中计**。

### 雷蛙与蚊兽
- 当年到朱雀圣宗后，王林放**雷蛙**与**蚊兽**自行修炼。
- 雷蛙昨日自**玄武圣宗**而来，凭灵性找到王林，身上雷光游走、砰砰作响，已能承受此地高温，并有火元力缓缓钻入其体内。
- **青龙圣宗**长老曾言蚊兽在他们之前飞出，然而蚊兽迟迟未至。王林皱眉疑惑，最终以「许是顽皮耽搁」压下。

## 四、结尾：断剑出胸

- 王林双手掐诀，在身上连点数下：面色浮现异样红润，神色隐透痛苦；以他对火元力的操控本不至如此，此刻额头却渗出豆大汗珠。
- 许久后轻吐一口浊气，**胸口红光闪烁不断，一把断剑自其胸口一点点缓缓延伸而出**。
