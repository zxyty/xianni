# 第九卷 云海之巅 第1276章 反击！

## 一、风仙界·暗红大陆：石人苏醒

- 风仙界内恒古长风呜咽，弥漫全界，透出化不开的苍凉；成群蚊兽在风中呼啸，**蚊兽是风界唯一的主人**。
- 风仙界最深处漂浮**三块大陆**，其一为**暗红色大陆**：血腥味阵阵，天空无数蚊兽徘徊嗡鸣。
- 大陆上有一座**石质人像**，双目蠕动、缓缓睁开沧桑双眼；一股奇异气息散出，却诡异地不引起任何蚊兽注意，仿佛石人在它们眼中不存在。

### 石人的两句自语（关键情报）

1. 「老夫好不容易布置下的一个**棋子**，岂能就这样被那**水道子**所杀」——石人视王林（时以化名『吕子浩』行事）为自己的棋子。
2. 「不过借他之手，倒也可以看看这棋子，到底是不是**封界之尊**那老家伙的**转世**，又或者**天逆珠子**，真在此子手中」——石人有意坐观，借水道子之手试探王林底细。
- 仙界之风更浓，一缕吹出**风界之门**，在星空内消散。

## 二、云海战场：水道子的定神术

- 水道子**眉心漩涡**吞噬身前三道长虹，闭目吸收后睁眼，目内隐现**红黄蓝三色瞳孔**旋转，令人心神震动。
- **定神术 ≠ 王林的定身术**：定住天地，天地间好似只剩他一人，余者万物与一切神通全部停顿半空，却**诡异地不消散**——若无这白发童子的神念，将在此**永恒万年**。

### 被定住的一切

| 对象 | 状态 |
| --- | --- |
| 呼风之术所化黑龙长枪 | 悬停半空不动，其上寂灭之风亦停，停在前方一丈外 |
| 唤雨所化晶光冰剑 | 停顿天地间，远看如一片环绕成卷的冰凌 |
| 撒豆成兵的无尽战魂（含虚空子、天运子等强大战魂） | 保持方才动作，一动不动 |
| 王林行走间脚下的众多虚幻火山 | 黑烟静止、岩浆停顿，一切凝固 |
| 王林本人 | 踏于虚空一片黑烟之上，手中紧握**三叉戟**，被定 |

### 水道子对王林手段的评断

- 六道三重仙术源出**雷界白凡**。
- 若王林学到**三重术**，杀之尚有波折；即便只学会当年极为惊艳的**阴月有晴之术**，也会有麻烦。
- 但眼下王林所展六道术中，**除阴月有晴外，其余全部是「杂耍之技」**。
- 水道子为**第三步中属于入门阶段的空涅初期大能**，确有资格做到这一切。

## 三、射神车之毁

- 水道子一步来到**雷兽所化射神车**旁，扫视后冷哼，右手抬起狠狠下拍——射神车轰然崩溃，其内**雷兽在被静止中成为永恒**。
- 其言：「此宝瑕疵太多，我要之无用，索姓毁去」。
- **性情侧写**：水道子极为狂妄，且有古怪癖性——**喜好毁灭一切在别人眼中为至宝、但对他无用之物**；最喜看到持宝者宝物被毁后的憋怒之容，以此感受自身强大、找回**多年前失去的尊严**。
- 射神车**伴随王林大半生修道**。目睹其毁，王林心神刺痛，悲哀化作无边无形火焰在体内燃烧却被生生限制，双眼流下**两行血泪**。

### 王林的心誓（重大伏笔）

> 「我王林此劫若能不死，在此发下心誓，此生必杀此人，必杀此人，让他忍受万般折磨而亡；若违此誓，让我王林一生道消，死于所逆天道之下。」

- 王林心中呐喊如风暴掀起，望向水道子的目光却**阴沉如水**。
- 水道子已认定王林是**天逆的拥有者**，很可能是**当年主子的传人**，见其神色更为心悦。

## 四、七彩射神车与七彩蝴蝶

- 水道子转向**七彩射神车**，眼中露出奇异之光，大袖一挥欲将其收走。
- 车上七彩光芒一闪，出现一只**七彩蝴蝶**（器灵），翅膀一扇便轰然崩碎，化作点点七彩晶光消散。
- 随其消散，**七彩射神车沦为凡物**——水道子终究未能得手。

## 五、要点提炼

1. **幕后新线索**：暗红大陆石人是王林命运的隐藏布局者，并首次抛出「封界之尊转世」与「天逆珠」两条身份猜测。
2. **实力落差**：水道子空涅初期（第三步入门）以定神术单方面碾压，王林全部神通被凝固。
3. **代价**：雷兽射神车被毁（雷兽随之永恒静止），七彩射神车因器灵自碎而失效——王林两大交通/护道底牌同章折损。
4. **因果种下**：王林血泪心誓，以「道消、死于所逆天道之下」为赌注立誓必杀水道子。

### 归属说明

- 本章中「吕子浩」即**王林**（自第1063章起以归元宗故人『吕子浩』之名行事，身份由吕烟菲奉上）。
- 文中被定住的「天运子」为**撒豆成兵所化战魂**，非真身（天运子已于第514章死亡）。

# 第1191章 水道子搜魂夺宝 → 七彩神空钉反击

> 归属提示：本章「吕子浩」即【王林】的化名（自第1063章由吕烟菲奉上，冒用归元宗故人姓名身份）。本章水道子直呼「吕子浩」，其言行一律归于王林。

## 一、毁车立威
- 射神车宝灵宁可自毁也不愿被水道子收走。水道子冷言「宝灵自毁也不愿被老夫收走么」，右手下拍，失去宝灵的射神车轰然四分五裂。

## 二、穿透之目：查验「天逆」
- 水道子转身看向王林，天地轰震，其身外星空仿佛消散，天地间只剩二人。
- 其目光带强烈穿透力，王林全身如被撕开，元神与魂魄皆被穿透，体内一切隐秘尽显；王林青筋暴起、汗如雨下却发不出声音，被禁锢体内。
- **关键设定**：水道子自言「主人曾说过，天逆会与元神融合」。查遍王林元神后未见天逆，遂疑「他不是主人转世，也没有天逆，莫非是我找错了人不成」。

## 三、强开储物空间
- 水道子右手一斩，在王林体外直接裂开储物裂缝——以第三步修为轻松打开他人储物空间，神识散入横扫。
- 声明：「若储物空间也没有天逆，我便搜此人之魂。」
- 扫过之处，低阶宝物尽数崩碎化灰。

### 空间内所见三物
1. **许立国（剑魂）**——被讥为「有趣的剑魂，不过也是废物」。许立国正欲施展赖以生存的阿谀之术，毁灭神念已至；水道子却因下一发现而神念一转，**放过许立国**。
2. **巨蚊兽群**——另辟储物空间中无边无际的蚊兽群，因两空间有一丝相连而被神识穿透窥见，水道子惊讶「这么多的巨蚊兽」。
3. **避天棺**——散发荧光的棺材，内躺沉睡女子。水道子认出此为「闪界仙帝的至宝避天棺」，判定「对我有用」，分出神识欲连同棺内女子一并收走。

## 四、逆鳞被触
- 水道子欲收避天棺的刹那，王林剧烈颤抖，眼中现出从未有过的疯狂。
- **点题**：王林的逆鳞不是天逆、不是古神之体、更不是魂中的一切秘密，而是这口棺材与棺内的女子。
- 水道子察觉异常，嘲讽其为「痴情之人」，决定改变计划：本欲事后取出女尸，现要当着王林的面开棺——并援引传闻：避天棺内生灵若无正确方法取出，瞬息消散、彻底灭亡，「且看看这传闻是否为真」。
- 水道子神识分作多道：一道环绕避天棺准备开棺，其余继续横扫寻找天逆。

## 五、转折：银衣女子睁眼
- 开棺前一息，水道子另一道神识扫到**盘膝坐在储物空间内的银衣女子**。
- 银衣女子睁开双眼，与水道子神识相撞。
- 身为第三步大能的水道子竟当场神色大变、露出惊慌，「你、你、你是——」，心神一乱。

## 六、反击：铁剑血球 + 七彩神空钉
- 王林趁其心神大乱，**吞噬了元神内不知为何未被水道子发觉的「铁剑之血球」**，获得轰天毁地的大力，被禁锢之身骤然可动。
- 王林惊天大吼「七彩钉」：储物空间内未被神识扫过之处爆出七彩之芒，先在空间内冲穿水道子神识，再飞出直奔其眉心。
- 水道子此刻距王林极近，瞳孔猛缩，惊呼：「掌尊七彩神空钉，你竟有此物！」（章末悬念）

## 七、要点沉淀
- 天逆的判定标准首次明确：**与元神融合**；水道子的「主人」为其信息来源，其寻人目标是「主人转世之身」。
- 水道子实力刻画：第三步大能可徒手剖开他人储物空间、目光可洞穿元神魂魄、可分出多道神识并行。
- 银衣女子身份成谜，仅凭睁眼即震慑第三步大能——本章最大伏笔。
- 许立国因巨蚊兽群意外逃过一劫。
