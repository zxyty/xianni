# 第1831章 魂衍道雷

## 一、炎脉峰：本源真身与山合一
- 王林所居炎脉峰烈焰长燃而无烟，四周天地在火海中扭曲，望之如虚幻；峰内高温足以令临近者血液欲沸。
- 全峰只保留三个洞府（含炎栾旧洞府），余者尽毁，仅王林一人在此。
- 王林盘坐于炎栾旧洞府，身后本源真身幻化并融入山峰，与山合一——此山即其真身，峰外动静了如指掌。

## 二、魂衍道：入门易、大成绝望
- 紫色玉简为青牛老祖所赠，气息古老腐朽。神识入简，苍老之声回旋：「魂为道，道威魂，衍道寻命」。
- 王林修此术的两重动机：
  1. 推衍计算之能屡救性命——当年借天运子分身计算，数度应对生死危机；天运子是其平生所遇最擅计算者，青霖亦有类似道术。
  2. 更重要的是**隐藏自己的一切**，令他人难以算出，否则在仙罡大陆寸步难行。
- 阶次与代价：

| 程度 | 符文铭字数 | 所需时间 |
|---|---|---|
| 入门/小成 | 十万 | 三天（第三步修为十人有九可成） |
| 中等 | 二十七亿 | 九百九十九年不间断闭关 |
| 大成 | 四十九亿 | 十七万八千年闭关 |

- 越往后符文越复杂、烙印耗时越长。王林由此推知：此术**根本无法达到大成**，顶多中等——这正是青牛老祖爽快相赠的缘由。冷哼之后仍继续烙印。

## 三、魂人现世与四次磕头的推衍
- 第三日黄昏，十万符文铭字烙印于魂告成。掐诀点眉心，魂气自天灵散出，凝成三寸小人。
- 魂人形貌：由十万符文所化，**只有一双眼睛，无鼻、无嘴、无耳**；肉眼可见，神识扫过却空空如也；目光清澈，与之对视令王林恍惚。
- 王林开口「魂衍万千，寻自身玄妙」，欲算自身凶吉。魂人跪于掌心磕头：
  1. **第一磕**：眼前血光迷雾，无数身影模糊不可辨。
  2. **第二磕**：迷雾被强行冲开一线——见一座雷霆笼罩的「天地至极雷山」，山下镇压着一人；天空有闪电雷霆凝成的巨大战车，车上立着一道同为雷霆所组的身影，低头俯视大地。山下之人面目模糊。
  3. **第三磕**：看清山下被镇压者——**正是王林自己**。幻象随即崩溃，王林如被修真星砸中，神识急速收缩。
  4. **第四磕**（王林强令再运转）：巨雷轰鸣照亮天地，他**看清了战车上身影的相貌**。
- 看清的瞬间幻境彻底崩溃。王林久久无法忘却最后一眼所见之人，露出迷茫神色：「不可能……怎么会如此」。原文未点破此人身份。
- 魂人神色萎靡、目光黯淡不动，被王林握掌收回魂中滋养。

## 四、王林的后续盘算
- 判定「此事透着诡异」，但确认魂衍道**可推衍未来变化**。
- 待魂人休养后，拟用其推算 **司徒（南）、清水（仙君）、李倩梅** 等人的下落。
- 修为至此，纵天崩地裂之事亦可冷静压于心底。
- 记挂青牛老祖许下的**三样礼物**尚未兑现，以及可入**藏魂阁**挑选一样神通之诺；心中浮现大魂门的多重幻术与炎栾曾施展的「召引大魂门先祖之魂现身」。

## 五、矾珊梦峰外三日苦候
- 「弟子矾珊梦，奉师尊之命，应王长老之言，来此求见」——王林微微一笑，随即不再理会，专心研简。（据世界状态须知：此「矾珊梦」实为矾珊璐自第1606章起的伪装，第1698章已被王林当面揭穿。）
- 她低头立于峰外整整三日，热浪层层，衣衫被汗水浸湿贴身，形容虚弱；回想当年一幕幕，目中再闪怨毒，旋即隐去。
- 王林出关后身子一晃掠出炎脉峰，自她身边径过，不置一词。她怒意升起又生生压下，深吸口气继续等待——「她已经没有了退路」。

## 六、章末去向
- 王林化作长虹，离炎脉峰向大魂门深处疾驰。青牛老祖所留破禁玉简中载有大魂门各山峰地图，使他清楚知晓**青天峰**所在。

## 悬念
- 未来以雷山镇压王林者是谁？雷霆战车上那道被看清相貌的身影究竟为何人（王林反应为「不可能」，暗示是熟识或不该出现之人）。
