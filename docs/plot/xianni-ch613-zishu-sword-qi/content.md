# 第613章 子鼠剑气

## 一、藤云的冒名与试探
- 藤云自称是子鼠师兄，表情悲戚、言语周密，把可能的破绽全部弥补，寻常人易被骗过。
- 其真实盘算：看不透王林修为，忌惮王林身上骇人铠甲，遂故意不出声阻止，想等王林踏入尸体十丈内被金芒杀死后，自己再取宝，连铠甲一并夺来。
- 王林冷冷一瞥，未拆穿，径直前行。

## 二、破金芒、取剑气
- 王林踏入十丈内，子鼠尸体眉心射出金芒，如万道金针刺出。
- 王林因在末羊处已有一次收剑肖十二子剑气的经验，大手一挥横扫金芒，不慌不忙走到尸旁。
- 藤云欲逃，一声冷哼令其僵住，感到执意逃走必死。王林问「不要你师弟的尸体了」，藤云慌不择言，极力奉承求生。
- 王林右手一砍取下子鼠头颅，喷出元神精火（无色火焰）炼化，再喷元神之气使头颅消散，只余一道闪烁金芒，虚空抓来一口吞下。
- 藤云据此判断王林非妖人而是「心狠手辣、连死人都不放过的修魔之人」，惧被灭口。
- 王林左脚一勾把无头尸身踢还藤云，令其安葬。藤云逃出几十里后弃尸，放黑云将尸体连骨吞噬殆尽，自以为骗过王林；叙述点明：若王林真信他是子鼠师兄，等待他的将是另一种下场。

## 三、地底炼化一月
- 王林沉入地底盘膝炼化凌天候剑气，需较长时间方能彻底归为己用。
- 炼化中神识察觉前方另一股剑气，虚空一抓，剑气化作硕大鼠兽咆哮；王林散出问鼎修为，鼠兽哀嚎被生生抓来，现出一把古朴大剑——**子鼠之剑**，剑上一只黑色鼠兽转动黑目。
- 该剑本是当年王林杀子鼠时元神疯狂随手甩掉之物，事后颇觉可惜，今日失而复得；王林烙上神识收入储物袋。
- 王林心语：「剑尊凌天候，若是有一日，我王林把剑肖十二剑全部拿出，你会如何表情」。
- 一月后彻底炼化成功：
  - 与末羊剑气「只存于体内、一次性甩出」不同，此次**收发由心**；
  - 可分作十份、威力平均散开，十份合一即至强的凌天候剑气；
  - 即便剑肖十二子中，绝大部分弟子也只能一次性用出。
  - 成因：其一，王林修为已达**问鼎初期**；其二，凌天候为便于弟子操控，赠予剑气时已抹去自身神识，剑气近乎无主之物。

## 四、两条道的对照：凌天候 vs 天运子
| | 凌天候（大罗剑宗） | 天运子（天运宗） |
|---|---|---|
| 道 | 霸道，护短，己物不容外人触之 | 随天而运、随运而行，顺天修行 |
| 待弟子 | 赠极强剑气；曾安排贪狼入妖灵之地保护 | 只给勉强称之为保命之物；弟子生死随天、强弱随命，轻易不出手 |
| 结果 | 恶名远扬但弟子凝聚力极强；门内绝顶强者不多（「雏鹰若总在保护下，很难成为雄鹰」） | 门内高手众多，天运七子封号者无一不是强者，门人历经生死磨砺 |

## 五、妖灵之地大战爆发
- 王林闭关一月间，妖灵之地出大事：**天妖郡发兵三千万，向火妖郡正式宣战**，绝大部分外来修士纷纷离开寄身之处，齐奔火妖郡与天妖郡。
- 以往九郡只有小摩擦；即便每 5000 年一次修士进入也只引发一定程度的九郡大战，两郡生死大战极为罕见——因天妖九郡平衡一旦打破会引起无法想象的连锁反应。但对修士而言是天降机遇、获取战功的最快途径。
- 出战阵容：八大妖帅与八位副帅全部出列；副帅新添两位为**莫厉海**与当初的第一妖将**墨非**；**天妖郡妖帝御驾亲临**。
- 大军分三股，从三个方向杀入火妖郡，约定在**火妖燕京**集合。

## 六、王林出关与后续计划
- 王林从地底遁出之日，正是天妖大军踏上火妖领地之刻；天地间数千万人杀气弥漫，白云被阴雾取代，阵阵雨落。
- 王林判断：「吉妖行事倒也果断，或许这无数年来他的耐心已经快要失去，如此一来我却要小心一些」。
- 定下三项目标（战事与其关系不大）：
  1. 先把**剑尊弟子一一杀死**，取余下**十道剑气**；
  2. 炼化无数**杀戮之气**，以在妖灵之地立足；
  3. 继续探查**洞府**，或有不少宝贝。
- 目标锁定：当日在墨非身旁的两名剑尊弟子。
- 疑点：**墨非此人有些奇异——当年燕京牢狱内的黑发男子与其一模一样**，王林认为其中有诡异。
