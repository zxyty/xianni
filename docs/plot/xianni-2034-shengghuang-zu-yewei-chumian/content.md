# 第2034章 故……

## 一、紫棺出世：圣皇祖烨微

- 沙哑含恨之声自道古皇宫广场地底传出，地面轰鸣碎裂，数丈宽裂缝纵横，广场四分五裂，中心塌陷。
- 一道紫光冲天而起，如支撑天地的紫色巨柱；整座皇宫被紫芒笼罩——紫芒由无数阵法组成，即皇宫**万古大阵**开启。
- 紫色棺木自塌陷处浮出并竖起，棺盖寸寸碎裂，露出内中骷髅般的身躯：一名老妪，苍老如自黄泉爬出，发仅数根，身着岁月中褪色的皇袍，身躯漆黑。
- **三把匕首**分刺其眉心、胸口、丹田。
- 四周道古族人尽数跪拜，齐呼「拜见圣皇祖」，声浪轰鸣，目中狂热不亚于先前见到古祖虚影。
- 玄罗见之眼露追忆，轻叹一声，神色复杂，唤出其名：「烨微」。

## 二、烨微其人（王林的回溯）

- 数万年前，道古一脉历史上唯一以**女子之身**成为道古皇尊者。
- 继位当年引起哗然与轰动，族人质疑不断，最终**古道大天尊传出口讯认可**，风波方平。
- 同为皇族；其在位时道古一脉几乎达到巅峰，成为**三族最强**；其退位后数万年，道古一脉已沦为三脉最弱。
- 因其贡献，被后任皇尊称为**圣皇**，被后辈族人恭称**圣皇祖**——历代道古皇尊中，能称圣皇者仅她一人。
- 王林由记录历代皇尊的玉简得知：其师尊**玄罗，正是在烨微所在的年代成为大天尊**。

## 三、王林早有察觉的两条线索

1. 古祖虚影出现时，他已感应到皇宫地底存在一股**半生半死的气息**。
2. 此前夜宴中，距大殿最近处设有**四张案几**，分属大天尊、国师、上一代皇尊——三人却四席，显然尚有一位身份极高、纵不到场也需留席之人。见到老妪、听到「烨微」之名后，此谜解开。

## 四、对峙：不死之身 vs 六极道

**烨微的条件与筹码**
- 要求：留下**仙祖头颅**与**仙皇之魂**，可恕王林无罪。
- 威胁：王林纵能借古祖之力幻化古祖之身，亦不可随意进出道古皇宫。
- 底牌：皇宫有古祖当年布置的**十万大阵**；历代皇尊最多开启二三成，而她**已与阵法融为一体**，只要身在皇宫即为**不死之身**，可开启至**七成**。

**王林的应对**
- 身后**大天尊之阳**幻化，黑白二色缭绕，头发无风自动，阳下现出**与他相貌一模一样的道古虚影**（扛日冷视烨微）。
- 说明：真正的**古祖之影**须燃烧体内魂血方可施展，刚用过一次，魂血已散于体内，需时间重新凝聚才能再燃。
- 甩袖展开**仙祖八极道之六道**：极火道（青色烟丝）、极水道（蓝色波纹）、极金道（金色飘渺）、极木道、极土道，五行齐整之后是**第六道·死极生道**。第七**极发道**与最终**极穹道**虽无传承，但已能隐隐感受其变化，假以时日并非无法掌握。
- 右手食指银光缭绕，凝出**古祖一指**之术。
- 头发由半黑半白渐转**全黑**，散出惊天杀戮毁灭气息。

**烨微的动摇**
- 原本预计阵法绞杀之下，即便大天尊也只有三成生机，王林必九死一生。
- 见六极道中的毁灭之力、并发现古祖一指**并非玉简一次性攻击而可反复施展**后，瞳孔收缩、心生迟疑。

## 五、玄罗的斡旋与旧情

- 玄罗一叹使烨微抬起的枯手一颤，直言：「烨微，他是我的弟子。」目中有柔情，视眼前老妪一如当年美丽明媚的女子。
- 烨微回以：「他**曾经**是你的弟子。」目中同样复杂。
- 玄罗揭出烨道之所以被立为皇尊的旧因：烨道幼时无意闯入烨微闭关之地，烨微觉与其有缘；玄罗本不看好此子（性格跋扈、眼中容不下旁人），只因**其身上有烨微的气息**才选择了他。
- 玄罗痛陈：烨道逼得他**唯一的弟子与他斩断师情**、从此无法留在道古一脉；并质问身为皇尊是否该如此、大阵是否真能困住王林。他忘不了那如哭一般的微笑、一笑后的一拜一叩，以及那**一掌碎命斩断师恩**——师徒之情随王林身体崩溃而烟消云散。
- 玄罗最后自陈：「我当年答应过你，守护你一辈子、守护道古一脉一辈子……我很累，让他走吧，你不是他的对手，这大阵也困不住他，我这是在救你。」说话间容颜渐渐苍老。
- 烨微沉默后表态：烨道**的确该死**，但身为皇尊不能凭白被杀，本仍要发动大战；沉默许久后终究右手一挥，**紫芒大阵消散**。

## 六、离场与悬念

- 王林看玄罗一眼，暗叹一声，搂着**融入李慕婉残魂的宋致**（其见老妪极为害怕，王林将其抱得更紧）直奔天空。
- 将去未去之际，王林轻咦——下方道古族人中有一**大汉**抬头，目光炯炯，微笑感慨地看着他。
- 二人目光对望，王林身子一顿：「是你——」（悬念留至下章）

## 七、要点提炼

- 道古皇宫的最终底牌被揭开：地底沉睡的圣皇祖 + 古祖十万大阵（融合者可开七成）。
- 王林战力再上台阶：六极道成型（缺极发、极穹）、古祖一指可重复施展，令不死之身的圣皇祖亦生退意。
- 玄罗与烨微的数万年旧情，是本章化解死战的唯一变量；也补齐了「玄罗为何立烨道为皇尊」的因果。
- 王林与玄罗的师徒之情已在此前一掌之下断绝，本章由玄罗视角再度确认。
