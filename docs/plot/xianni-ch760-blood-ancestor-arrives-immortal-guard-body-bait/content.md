# 第七卷 名震罗天 第760章 终于来了

## 一、抵达与善后（雷之仙界·碎片大陆）

- 王林由李元储物空间内的传送阵走出，落到雷之仙界一处陌生碎片大陆：天空阴沉、雷光游走、地面无边。
- 王林罕见地佩服李元：**能在仙人开辟的储物空间内布设传送阵**，其禁制造诣王林自认难及。
- 王林一拍传送阵，将其缩为拳头大小晶体收入储物袋。
- 飞行数日后，于一处山脉遁入地底，把**姚惜雪那个打不开的储物袋**藏起并加设数道禁制。理由：随身携带太扎眼，不符合接下来的计划。
- 藏毕后地底远遁，于平原现身，回望山脉一眼，随即离开该碎片大陆，踏上虚空铁链。

## 二、一个月铁链飞行：钻研隐匿禁制

- 沿虚空铁链在虚无中谨慎飞行**一个月**，抵达另一处碎片大陆。
- 途中重点研究**李元留下的玉简**中「如何隐匿气息」的禁制；在血祖带来的巨大危机压迫下，进步极快。
- 结论：无法彻底瞒过血祖神识，只能略作隐藏；平常情况下仍难成功，**但配合其计划则有一丝藏身可能**。

## 三、核心布局：本体封印 + 仙卫为饵

1. 以土遁入地下深处，盘膝掐诀，布出一道道禁制组成**圆形禁制球**。
2. 禁制球将闭合之际，**仙卫傀儡**自其身后踏出。
3. 王林**分出一股元神，与本体断开连接，融入仙卫体内**——此为仙卫的神通之一：允许炼制者元神融入以进行操控。
4. 最后一道禁制补入球内，禁制球一闪收缩，化作光点消失不见（本体彻底隐去）。
5. 仙卫睁眼，吞下传送阵晶体，冲出地面。以仙卫为肉身的王林**神识扫过地下亦无法发现本体**——验证隐匿成功。

> 王林盘算：「若没有仙卫这具肉身，或许瞒不过血祖的寻找，可现在，我却是主动送上门，那血祖一旦察觉，定会被这具肉身内的元神吸引。」

## 四、五个月高调引敌

- 王林神识全部散开，如黑夜明灯，**主动暴露以供锁定**。
- 一改逃至罗天星域后的谨慎（联盟星域老怪随时可能追杀），此刻放开心神，睥睨而行，杀机浓郁：「血祖眼下，王某只等你来」。
- 仙卫肉身虽不及本尊，但远超普通修士与炼体者，气息达**阴虚**境界；肉身强悍可与法宝一拼。
- 五个月中横冲直撞，不主动惹事，遇不开眼者直接一拳轰出。已在雷之仙界修士中**略具威名**：问鼎修士连连避开，部分阴虚修士亦皱眉不理。
- **活动范围有意受限**：只绕本体所在碎片大陆四周移动。好处二：①避免与血祖错失；②间接保护本体，防止血祖先找到本体使自己落入被动。

## 五、血祖视角：破誓入罗天

- 血祖红袍行于虚无铁链，一步如瞬移；神色平静，**双目红芒日复一日浓郁**。
- 女儿**姚惜雪**是他此生唯一的女儿，也是**他仅有的破绽**。为她可与天斗、杀尽阻碍；若在**修道第三步**与女儿间抉择，纵有挣扎，最终仍选女儿。
- 与**凌天候、天运子**的根本差异：天运子会放弃一切去选第三步。
- 为女儿，他放弃尊严，违背父亲临死前令其发下的毒誓——**此生绝不踏入罗天星域半步**。
- 悬念伏笔：「父亲你既然让我发下毒誓，为何最终，还要留下一块**罗天石**？」此疑问在其心中盘桓极久。

## 六、正面相遇

- 血祖踏上碎片大陆，神识如狂风横扫，随即面孔阴寒，眼中杀机几乎化作实质，吐出二字：「王林」。仅目光杀机便震得前方一座山峰崩溃。
- 几乎同一息，王林自另一端虚空铁链冲出。天色骤暗、云层疯狂凝聚、大地颤抖；全大陆修士无论**阴虚**或**阳实**，皆感灵魂颤抖，如天威降临。
- 王林冷笑：「终于来了」。
- 云层被撕裂，血红霞光笼罩全陆；血祖的神识内**蕴含第二步神通**，强到令碎片大陆隐约开始崩溃。
- 王林前方百丈，红光凝成人影：**红发红眉、一身红袍的英俊中年男子**，当年的乾风与之相比亦黯然失色；平静双目内燃着可焚天地的红色火焰。
- 血祖不废话，抬手向前一点，天空如被戳开，直奔王林眉心。
- 王林在指劲将至的刹那缓缓开口：**「你若杀我，姚惜雪即便有血魂丹，也必死无疑」**——以姚惜雪的性命为筹码，硬接死局。
