# 第九卷 云海之巅 第1156章 离开漩涡

## 一、战况前提：分身之弱
- 在场的王林只是**修道分身**，本尊在归元宗地底闭关。
- 与当年青霖仙府相比，此刻缺失的底牌：巅峰本尊肉身（可硬捍神通）、无尽古神之力、残夜神通的施展契机、已在青霖仙府崩溃的青光盾（八星古神保命神通「梦回远古」）。
- 结论：**仅凭修道分身击杀碎涅修士极为艰难**。

## 二、伤情与保命底子
- 右腿血肉模糊，被钱贵钟神通所化白光穿透；碎涅元力蕴含某种**天地规则**在体内肆虐。
- 元神未溃：**古神皮甲**防护。
- 肉身抗住：在**朱雀圣宗**受天地之火炼化，蕴含**雷火规则之力**，故只伤未亡。

## 三、杀招三段
### 1）撒豆成兵——双魂缠斗
- 放出**虚空子之魂**（死前修为达「天人第一衰」，出手风雷轰轰）与**天运子之魂**（掐诀幻化模糊神通，调动天地规则）。
- 二魂本足以生生缠死钱贵钟，但王林**时间不足、仙力不足**（撒豆成兵耗仙力最大）。

### 2）次空涅铁剑·十九剑
- 锈迹铁剑为**次空涅法宝**，威力远超钱贵钟预估。
- 闭目放弃操控，任铁剑自行施展，剑光成弧、如剑之花绽放：先落**十三剑**，睁眼后再连斩**六剑**，共 **19 剑**。
- 代价：**耗去近六成元力**。机制限制：19 剑内尚可强行打断，超过则只能斩至力竭、全身元力尽失。
- 结果：十九把虚幻大剑同时落下，钱贵钟肉身被穿透**裂作十九份**，元神卷拂尘法宝出逃。

### 3）九玄变·白色朱雀 + 天运一指
- 左眼火光一闪，**九层火海**收缩凝聚全身，肉身消散化作**数十丈白色朱雀**追击。
- 钱贵钟应对：**可控的元神自爆**（双臂爆开成风暴）+ 拂尘法宝爆开化**无数白线**；仍被朱雀撞中，火焰笼罩。
- 钱贵钟逃遁中**吸收本命灵兽巨蟒之魂**续命。
- 王林令天运子之魂「**融我神念**」——获青霖造化后明悟白凡之术：撒豆成兵修至极限可融体成念。
- 以自身之力、天运魂之念为引，施展「**天运一指**」，巨掌降临云海星域，钱贵钟元神**绝望中崩溃**，化点点晶光消散。

## 四、脱离漩涡
- 收走一切后改道离去；**五日**后遥见**莫罗大陆**，全程绕大圈避开前方修士，未再遭遇任何人。
- 王林自语：「若本尊在，今日一战何苦会如此艰难，**三损七劫**不知本尊能否成功度过。」

## 五、外部余波（王林未知）
- 施洛刑之死被其他宗派赶到者知晓，消息传开，以**蛮荒大陆**为中心四周星域**严密封锁**。
- 钱贵钟之死震惊**华清宗**，封锁下疯狂寻凶。
- 六阶修士在施洛刑山谷发现骸骨与骷髅碎片 → 目标锁定**五毒门**，五毒门百口莫辩。
- **五阶星域**内一场隐动渐渐展开。
- 钱贵钟临终判断：白发修士知晓**破天宗与丹方之事**，与施洛刑之死大有关联，疑为**八阶星域**之人。

## 六、归元宗善后
- 判断六阶宗派将大范围搜索，**归元宗的身份尤为重要**，遂返回莫罗大陆归元宗。
- 瞬移现身**南苑药院**，见打坐的**孙芸**，挥手堆出小山般药草：「还你药草」——价值远超此前消耗。
- 孙芸背景：王林离开后被师尊训斥，整日彷徨，怕「曾牛前辈」一走了之，**紫道宗**来临时自己成千古罪人。
- 疗伤：连点胸口吐纳，将拂尘所化**白线**一根根逼出捏碎，**第三日**全部清除。

## 七、章末转折
- 取出**玉简**与**兽骨丹方**（一路未及细看）欲以神识研究。
- 骤然双目一凝，收起二物，身形一晃沉入地底直奔**本尊**所在——「**要度劫了**」。
