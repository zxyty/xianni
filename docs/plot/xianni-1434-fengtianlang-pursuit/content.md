# 第九卷 云海之巅 第1434章 奉天狼（第三更）

## 一、伏击：狼嚎断遁
- 废弃修真星上空骤现巨大裂缝，传出似狼嚎的惊天轰鸣，阴森至极。
- 该音波**将已融入天地、正欲缩地成寸的王林生生逼出**——伏击者的算计极为完美：找到王林 → 预判其以缩地成寸逃遁 → 以未知神通/法宝造出狼嚎阻断遁法 → 巨掌轰然抓来。
- 手臂气息中**蕴含香火之力**，充满暴虐。王林据此判定：来者非第二步修士，而是**刚踏入第三步、空涅初期**，与司墨子、水道子同阶。

## 二、反击：剧毒指甲与古息叶封裂缝
1. **剧毒指甲**：王林右手一挥取出一块漆黑指甲，阴森弥漫、月色下似有凄厉哀嚎——此物为**大荒上人看在老朱雀面上所赠的剧毒之物**。指甲掀起黑风，穿透巨掌掌心后崩溃，剧痛如墨蔓延整掌直上手臂，手臂颤动化作黑灰消失。其强度出乎王林意料。
2. **受创**：巨掌虽散，狂暴气息仍落在王林身上，王林喷出鲜血。
3. **古息叶封印**：王林再挥右手，古息叶如流星射向裂缝，喝一声「封」，叶片迎风见长——十丈、百丈、千丈——轰然封死裂缝。裂缝内传出低吼咆哮。
4. **遁走**：王林向前一步融入天地，缩地成寸而去。离开三息后，古息叶化作点点晶光消散。

## 三、太古星辰：召回法宝与既定方针
- 王林在太古星辰现身，神色阴沉，右手掐诀默念「**落叶归根**」，身前晶光凭空凝作古息叶落入手中——此为古息叶的召回之法。
- 王林自述当前决策：
  - 「眼下的状态，还不能回到**云海裂缝**内」；
  - 「**长尊会的追杀，再次开始**」，区区**太古追杀令**，倒要看看能引出多少大能；
  - 「在被追杀中，我便以**吞噬之术恢复修为**」。（冷笑，视凶险为常态）

## 四、追杀者现身：奉天狼族 + 封灭族
- **奉天狼族大汉**：古息叶消散后自裂缝走出，身高三丈，神色狰狞，双目无情寒光，**眉心一个可怕的青色狼头印记**；身属**长尊会麾下四大太古凶族之一的奉天狼族**。
- **封灭族红衣少女**：坐在大汉肩上，红衣、相貌妩媚、俏脸如桃、举手投足可吸人心神；**眉心为古怪符文印记，即太古星辰内极为神秘的封灭族标记**；修为未至第三步，仅**天人第三衰**。
  - 伏笔回照：当年在**七彩界**，王林曾遇一名封灭族老者，带来极其凶险的生死一劫，其**道术**令王林记忆犹新。
- **测位与解毒**：少女手持罗盘拨弄后轻笑报出方位——「**正东，十九万七千八百四十五里**」；并点明大汉**右臂中毒、战力下降三成**，若非她相助毒不好逼出（印证王林指甲之毒确实重创第三步修士）。
- **碾星追击**：大汉冷哼，虚空向前一步，天地震动，**整颗废弃修真星轰然瓦解、四分五裂**；他左手一挥将崩溃冲击凝成急速闪烁的虚幻光球甩向星空，光球令虚空扭曲撕裂形成明暗不定的黑洞，大汉一步踏入。

## 五、章末悬念
- 王林正在太古星辰以缩地成寸前行，刚一现身便猛地抬起右手，**将古息叶毫不犹豫向身后一甩**——追兵已至身后。

## 关键设定点
- 空涅初期＝第三步初阶；本章明确司墨子、水道子同属此阶。
- 香火之力为长尊会一系修士气息特征之一。
- 古息叶：可增长至千丈封印空间裂缝，用后消散，可以「落叶归根」诀召回复现。
- 太古追杀令：长尊会针对王林的追杀机制，可引来大能。

# 王林血雾屠奉天狼族分宗部落

## 一、古息叶封漩涡，惊鸿一瞥的眉心印记

- 奉天狼族大汉自王林身后星空撕裂出黑洞漩涡，身影随之幻化欲追。
- 王林以**古息叶**骤然落在漩涡之上，冷漠喝出一个「封」字。
- 封锁瞬间，王林瞳孔不可查地一闪：他隐隐看到黑洞内**大汉肩膀上的女子**，更看到那**让他心神一震的眉心印记**。（原文未点明印记来历，仅记王林反应。）
- 王林不动声色，向前一步迈出，身影消失遁走。
- 黑洞内咆哮与轰鸣疯狂传出，古息叶纹丝未动。片刻后大汉自另一处新撕裂的黑洞走出，目光扫过之际，叶片化作晶光消散。

## 二、大汉与妙音道尊侍女的交易

**大汉的疑虑**

- 「该死，这是什么法宝」——不识古息叶。
- 疑：**司墨子**与此人交战过，为何没有诉说此宝。
- 疑：**云落大司**回来后就立刻闭关。

**少女的身份与筹码**

- 少女为**太古五尊之一妙音道尊的侍女**，突然自行找来，帮大汉擒杀王林。
- 手持**罗盘**，可实时报出王林方位：先「西北，三十七万八千四百九十六里」，后「西北，二百七十九万八千四百六十一里」，并指出那是「你奉天狼族一处分宗部落」。
- 少女评：「此人若非是重伤，以你的修为，要将其抓住，并不容易呢」——王林处于重伤状态。

**古之墓地的线索**

- 大汉问：「你主子应是去了那古之墓地，你突然寻我，有何目的」。
- 少女答：是不是古之墓地还不一定，只是**根据一些古老的典籍依稀有几分确定**；且**太古星辰眼下诸多大能，大都去了那里**。

**交易条件**

- 擒住王林后，少女要**从他身上取一样东西**（未点明为何物）。
- 若大汉同意，事后**妙音道尊会赐一个六品道灵**作为答谢。
- 大汉沉默不语，直接迈步撕裂虚空追去（未明言答应）。

## 三、六星分宗部落与血雾屠戮

- 王林自扭曲中迈出，前方**六颗修真星排列成圆**，外罩阵法光芒，阵法上有**虚幻狼头狰狞闪烁**，昭示部落归属。
- 王林由此想起**之前那废弃星天空裂缝内传出的狼嚎**，确认「狼」的线索。
- 王林急速前冲中**轰然喷出血雾**，雾气弥漫全身，仿佛肉身消散、元神魂魄尽化作**吞天噬地的红雾**；转眼弥漫数万丈并疯狂扩大。
- 阵法剧烈闪烁却**无法阻挡血雾侵入**，血雾冲入其中一颗修真星。
- 凄厉惨叫惊天而起，片刻后归于死寂：**所有具备一定修为以上的修士被雾气一卷，全身化作血水，尽数被噬**。
- 红雾继续卷向余下几颗修真星。此部落是奉天狼族**新成立的分支**，其上**还没有凡人，只有族人**，此刻**死亡大半**。
- 单声惨叫本无法传出星空，但数量混合之下轰然传开。

## 四、大汉暴怒追杀

- 大汉自黑洞走出瞬间，混合的凄厉惨叫传入耳中，身子一震，**眼中爆出滔天杀机**。
- 低吼中疯狂前冲，星空随其迈步砰砰坍塌崩溃，身后浮现**一头巨大的虚幻青狼**，狰狞狰狞而出。

## 五、留待后续的悬念

4. 云落大司为何回来后立刻闭关、司墨子为何隐瞒古息叶之事。
