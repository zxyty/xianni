# 第1545章 三个宝

## 一、归乡：联盟星域的家的气息

- 场景承接：联盟星域内幽冥兽藏身的碎石区域，疯子在其中张牙舞爪、凄厉嚎叫，兴奋于「外面的世界」「外面的人好多」，似被憋了无数年。
- 王林已习惯疯子的聒噪，只默默望着这片星空，感受到熟悉的**家的气息**。
- 王林心境：
  - 「终于回家了」——家在**昆虚**，家在**朱雀**，但已没有家人，只有亡魂。
  - 他自己也说不清为何还要回家：不仅为了**清水**、为了**司徒南**等人，更因数千年漂泊之后，昆虚总有一股奇异的力量让他割舍不断。
  - 此次归来的悲伤**甚于当年从罗天星域返回**，或因这一次经历太多、走得太远。
  - 闭目良久，**没有泪，只有伤**。
- 疯子的反应：先是察觉王林身上的一丝「魂悲」，掐腰充大王要为「小娘子」做主；随即又忘却悲伤，操控碎石环绕玩耍。
- 王林羡慕疯子的快乐——什么事都转眼忘记，总能让自己快乐；这一点他做不到。他把悲伤埋葬、疲惫隐藏，还有很多事要做。

## 二、陌生的七级修真星

王林与疯子前行不久，星空前方出现一颗巨大修真星：

| 项目 | 内容 |
| --- | --- |
| 体量 | 与当年的**天运星**相差不多 |
| 护卫小星 | 数量远超天运星 |
| 外围 | 一圈圈波纹回荡，透出**禁制之力** |
| 氛围 | 一片寂静，仿若死域 |
| 王林是否来过 | 未曾来过，有些陌生 |

王林目光横扫（未惊动星上修士），探明详情：

- **等级**：七级修真星。
- **凡人**：诸多，密密麻麻分成近百个国家。
- **修士**：不少，但大都处于第一步，第二步修士数量不多；明面上修为最高者为**净涅**修士。
- **暗处**：星球中心地底有一处**溶洞**，内有四名常年闭关的老怪——
  - 一人为**天人第三衰**（最高）；
  - 两人为**天人第一衰**；
  - 一人为**碎涅**。
  - 溶洞内有**冰火之力交替**，四人借冰火气息压制体内**衰劫**，试图慢慢度过。

## 三、疯子留守与「三个宝」

- 疯子见到修真星大喜：「这么多人，这么多小娘子」，坚持要留下玩，还称当初跑出来就是为了寻找这样的地方。
- 王林先以「我有要事去做」推脱，继而不放心（疯子**心智如同孩童**，虽有**不灭体**但易被人欺骗），大袖一甩以金色光芒欲带其离开。
- 疯子怒火燃烧，施展不知名神通瞬间挣脱金光，得意咆哮：
  - 「就连我**哥**都管不了我」；
  - 「本王师尊有多少……一个、三个、八个……忘了」；
  - 自言自语中呼唤「**小红**」「**小银**」，说想家、要回家，还要小红去拿伞。
- 王林性格喜静、不惯着人，冷哼中抬手一抓打开**储物裂缝**，放出两道光芒：
  1. **许立国**（剑灵）——抱怨「每次需要老子的时候就把老子扔出，不需要时就又扔回去」，自陈虽是剑灵也立下汗马功劳。
  2. **刘金彪**——一脸小心翼翼，打量四周后，在疯子身上仔细看了几眼，干咳数声走出。
- 王林指令：「你二人陪着他，在这修真星等我，期间不要让他受到半点伤害。」王林话语一向很少，出口便有威严弥漫。
- 王林的判断：许立国修为尚可、刘金彪擅长察言观色，疯子在这没有威胁的修真星上应可无碍。
- 心理动因：王林**恩怨分明**，疯子对他有**恩德造化**，「他自己欺骗也就罢了，但却决不允许别人去欺骗这疯子」。

## 四、去向与伏笔

- 王林转身一步迈出，消失于星空，**直奔修真联盟总部**。
- 与此同时，另一处传出通报：「**清水师兄，王林来了**」——暗示清水一方已知其归来。
- 章末落点：许立国与刘金彪相互印证「疯子」「是个疯子，没错」，二人目光慢慢转动，笑眯眯地看向疯子——两人显然动了别的心思（呼应章名「三个宝」）。

## 五、要点提炼

1. 王林正式回到**联盟星域**（其家乡星域），情绪基调为归乡而无家的悲伤。
2. 疯子的背景线索增多：有「哥」、多位师尊、挂念小红与小银、身负不灭体、心智如童。
3. 引入一颗新的七级修真星，其地底藏有天人五衰境界的闭关老怪（天人第三衰 ×1、天人第一衰 ×2、碎涅 ×1）。
4. 王林下一步目标明确：**修真联盟总部**；清水一方已察觉。
