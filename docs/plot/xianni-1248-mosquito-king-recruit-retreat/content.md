# 第1248章 收（第三更）

## 一、蚊王吸血：卡在裂缝中的数万丈蚊王

- 裂缝内外笼罩着一股**无法理解的力量**，即便数万丈的蚊王也需不断挣扎才可能冲出；此刻它半身在内、半身在外被生生卡住，咆哮嘶鸣中裂缝震颤咔咔作响，有被再次撕开的痕迹。
- 王林的蚊王带金芒如流星扑至，不给对方挣脱机会，巨大口器横扫欲刺入。数万丈蚊王身外天地扭曲、涌出大量波纹阻挡。
- 关键一击：王林蚊兽身外幻化的**巨大暗金色蚊兽虚影**嘶鸣骤起，口器一扫直接破开无尽波纹；随后蚊兽本体与虚影**融合**，口器随虚影一动，砰然刺入裂缝内蚊王体内。
- **第一吸**：王林蚊兽全身破损伤势骤然消失、伤口愈合、金光更浓，眼中渴望更盛。
- **第二吸**：数万丈蚊王咆哮惊天，体内爆发大力横扫四周，将王林蚊兽生生震开；同时裂缝被疯狂撕开，其身大半冲出，惊天凶焰与**堪比本源的气息**弥漫天地。
- 王林蚊兽嘶鸣后退，虚影消散融回体内，四周蚊兽尽皆避开不敢阻止。王林虚空一抓取回三叉戟，身形缩回常人大小，踏上自家蚊王背部随之后退。

## 二、九块大陆崩溃与百万蚊群

- 环绕三块大陆外呈守护状态的九块大陆中，其余八块随数万丈蚊王嘶吼**轰然崩溃**，一只只蚊兽从中飞出——这九块大陆**全部由蚊兽组成**。
- 王林无法精确计算，凭感觉判断天地间蚊兽数量**超过百万**。

## 三、归附：本章标题「收」的核心收获

王林蚊王吸了两口血液后金光暴闪、仰天长嘶，蚊王威压比吸血前更为剧烈地降临四周，引发大规模归附：

| 蚊兽种类 | 归附数量 | 备注 |
|---|---|---|
| 红色蚊兽 | 近万 | 距离最近，先颤抖后敬畏，化作红云卷着王林与蚊王疾驰 |
| 蓝色蚊兽 | 近千 | 冲出蚊群进入红云，嘶鸣与蚊王辉映 |
| 白色蚊兽 | 近百 | 在裂缝与王林蚊王之间挣扎后，化作白云跟随 |
| 紫色蚊兽 | 2 只 | 其一为先前与王林蚊王撞击者；另有一只淡紫色蚊兽。**气息堪比碎涅大圆满** |
| 金色蚊兽 | 1 只 | 全场金色蚊兽仅数百只，此举令王林瞳孔一缩、不敢置信 |

- 王林大笑，认定「此行，值了」，在众蚊兽卷动下与蚊王一同疾驰而去。遮天红云内蓝、白、紫、金四色蚊兽极为显眼，沿途蚊群丝毫不敢阻拦。

## 四、追击与逃遁

- 许久后，数万丈蚊王终于撕开裂缝冲出，双目滔天怒火与凶焰，直勾勾盯向远方蚊群方向，率**身后百万蚊群**遮天盖地追击。
- 整个**风仙界**云涌、大地震动、天空裂缝丛生、波纹回荡，无边蚊群形成壮观画面疯狂蔓延。
- 王林蚊王带上万蚊兽全速逃遁，从风界深处渐至外围，直奔**通向云海八阶星域的出口**。
- **战术一·阵法拖延**：数个时辰后，王林在后方掐诀布下大量禁制阵法；一路布置无数，借阵法不断崩溃换取蚊群毫不停顿的疾驰。

## 五、召·逆行者

- 追兵渐近、腥风扑面之际，王林**心神沉入元神封仙印内，与天运子魂魄融合**，气息骤变、目露平淡之芒，好似一切尽在算计。
- 自储物裂缝取出**石珠**，捏珠右手七彩之芒暴涨至极限，前抛之下石珠吸走全部七彩之芒后砰然爆开。
- 王林平静喝出：**「召，逆行者」**。
- 风界天空骤暗如天黑，片刻后无尽七彩之芒骤出笼罩大地，浓浓威压从天而降——一个约**千丈大小的巨大罗盘**凭空幻化，七彩之芒刺目、急速旋转，阻挡在王林与追击蚊群之间，浩瀚之力弥漫。
- 王林随即与天运子魂魄分开，**面色略显苍白**（伤势太重尚未完全恢复），不去看逆行者神通的结果。
- **战术二·黑龙引路**：双臂散开、全身环绕黑气，横扫间数条**黑龙**咆哮而出，环绕上万蚊群引动天地之力继续疾驰。
- 身后传来轰隆闷响、天地颤抖、狂风倒卷，王林不回头，继续疯狂前行。

## 六、章末悬念

- 王林已至风界外围，距出口只需**数个时辰**；但施展诸多神通仍无法拖延到离开。
- 此刻身后百里外蚊兽无边无际，自上俯瞰几乎占据整个风仙界，如洪流般蔓延；蚊群中那只数万丈蚊王死死盯着前方，嘶吼惊天。
- 王林皱眉、眼中寒光一闪，踏着蚊王背部，右手抬起向前虚空一抓——（章节至此中断）

## 七、设定要点

1. **蚊兽色阶体系**（本章可见强弱序列）：红色 → 蓝色 → 白色 → 紫色（气息堪比碎涅大圆满） → 金色（数百只，最稀有）；蚊王为顶端，数万丈蚊王气息堪比本源。
2. **吸血强化**：王林蚊兽吸食更高阶蚊王血液可瞬间愈合伤势、增强金光与威压，威压提升直接带来低阶蚊兽的归附。
3. **虚影融合**：蚊兽可幻化暗金色巨大蚊兽虚影并与之融合，虚影口器能破开空间波纹防御。
4. **逆行者**：以石珠为引、耗七彩之芒发动的召唤类神通，召出千丈七彩罗盘御敌；本章由王林与元神封仙印内的天运子魂魄融合后施展。
