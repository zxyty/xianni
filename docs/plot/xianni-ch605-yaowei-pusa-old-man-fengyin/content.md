# 仙逆 第605章 妖卫

## 一、场景与状态
- **地点推进**：王林穿过万妖山后，循神识中「发出冷哼之人」的方位继续追踪，数日后前方出现一片连绵不绝的荒原。
- **荒原环境**：处处残骸、地面干裂、难闻气味随风而来，是妖卫据守之地。
- **王林状态（本章当时）**：升仙果的奇效已侵入其全部心神，双目充血、感官被提高无数倍，稍一刺激便爆发；脑中「杀」是唯一念头，早已没有自身意识，一切全凭本能而行。

## 二、伏击：泥刺与干瘦老者
1. 荒原地面砰砰作响，无数土黄色泥刺拔地而起，从四面八方刺向王林。
2. 王林不退，全身仙力爆发形成漩涡横扫，泥刺尽碎。
3. 一道漆黑干瘦老者跃出地面，趴伏于利刺之上，侧头阴森而视，舔唇挑衅。
4. 王林拇指一按，**寂灭指风**化黑芒击出；老者张口，身后浮现高约十丈、漆黑生脓包的**茧形虚影**，一吸之下将寂灭黑芒生生吞下，虚影腹部鼓胀、脓包撕裂喷出恶臭浓水。
5. 老者虚空一抓，将脓水凝成脓球，言「小娃娃，你那指风很美味，我也送你一个」。

## 三、神通「天脓地疮」
- **天脓（脓墙困杀）**：脓球砸地碎裂，脓液融入大地，方圆千丈震动，脓液自地裂涌出形成环形包围，升空成墙，上盖天下遮地、四周隔空，迅速收缩成巨大圆球，老者融入脓液隐匿。
- **地疮**：老者双手掐诀猛伸，以自身为中心方圆千丈地面浮起一个个环形光圈、鼓成疮胞，喝「爆」字令其碎裂，粗逾十丈的脓液冲天而起。
- 老者自信断言：「在我的天脓地疮之下，他绝然不可活命。」

## 四、风吟与「主人」
- 脸有纹体的女子**风吟**幻化而出，冷声道：「此人若是这么容易就被杀死，主人也不会让我们出来。」——点明二人受某位**主人**驱使，身份为**妖卫**。
- 风吟能化身成风、几近无影，速度极快；手持匕首，可与黑色弯刀正面碰撞并震退之。

## 五、王林破局与反杀
1. **破球**：脓球收缩至三丈时停滞，球内透出疯狂战意与杀气，使四周气候骤寒、阴风阵阵。一道剑芒劈开脓球，王林长发飘动一步步走出，双目通红、战意与杀机融合成异芒，连老者见之内心一颤。
2. **三把武器**：仙剑、隐有黑色邪羊之魂的宝剑、阴森黑色弯刀齐出。黑色弯刀追缠隐身的风吟，虚空中金属交鸣不断。
3. **许立国出手**：仙剑内的**许立国**幻化而出破口大骂「爆你的个鸟」，直接操控仙剑横扫；老者自恃修为欲以肉身抓剑，许立国故意放慢诱其抓握，仙剑一削斩掉其五指，血流不止，老者惊呼「这是什么剑」。
4. **拽爆茧影**：王林一踏破碎虚空至老者上空，右手放出杀戮之气灌入茧形虚影，一捏一扯将茧生生从老者身后拽出，抛向身后虚空后隔空狠抓捏爆。脓液爆开的冲击震出正与弯刀厮杀、恰好赶到的风吟——她面色苍白，不知这是王林早有察觉还是巧合。老者则喷出一口鲜血，眼露不可置信。
5. **二次寂灭指**：黑芒近距离骤出，老者张口欲吞却未能化解，黑芒自其背后穿透而出。
6. **昆极鞭破隐**：风吟甩出匕首缠住弯刀，化成阴风背袭王林。王林不回头，右手从储物中一拣取出通体漆黑、散发灵魂颤抖气息的**昆极鞭**，虚空「啪」的一抽，风吟惨哼现形，脸上留下红色鞭痕，首次露出惊色，转杀为退。
7. **无名掌印终结**：王林随手按出巨大的**无名掌印**（当年曾震惊莫厉海的那一式），掌印蕴含杀戮之气，以难以想象的速度追上退走的风吟并穿体而过，风吟化作血肉崩溃。

## 六、结局
- 地面留下**一堆碎肉（风吟）**与**一具干尸（干瘦老者）**，无尽死气弥漫。
- 王林长发飘起，携三把呼啸的武器继续向远处踏步而去，追杀未止。

## 七、要点提示
- 本章首次点出「妖卫」及其背后的**主人**，为后续追踪对象埋线。
- 王林此战几乎不用神智、纯凭本能与杀意，是升仙果药力副作用的直接体现。
- 战力序列展示：仙力漩涡 → 寂灭指 → 三武器合击 → 破碎虚空近身 → 昆极鞭破隐 → 无名掌印必杀。
