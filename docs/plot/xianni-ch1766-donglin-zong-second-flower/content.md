# 第1766章 东临宗

## 一、脱身三百界

- **挡灾**：王林藏身疯子体后，毁灭之力传入疯子身体时已被削弱大半，降至王林的**道古传承**可抵抗的程度。疯子随即重新呼呼大睡。
- **抢目鱼**：王林提着疯子急退至九条目鱼处，发现**九条只剩四条**，另五条失踪。他大袖一甩收走三条奄奄一息的目鱼，第四条在眼前凭空消失——实为**玄罗**收走，玄罗在旁得意微笑。
- **目鱼隐秘**（源自第三魂记忆，七彩仙尊当年取目鱼饲养于三百残界时所发现）：一只名目鱼，雌雄两只在一起则称**比目鱼**，彼此气息相连；即便收入储物空间、即便被强行阻隔，仍存一丝联系，**除非死亡**。王林念头一起，立刻转身急退（暗示可借此追踪玄罗手中那条）。

## 二、逼退战老鬼——七伏杀局的收官

战老鬼自鬼脸雾气中走出，面临两个选择：

| 选项 | 诱惑 | 顾虑 |
| --- | --- | --- |
| 追杀王林夺第三魂 | 得第三魂 | 忌惮**李广弓**，不知王林还剩几弓之力；耽搁则七彩恢复，得不偿失 |
| 追击重伤的七彩道人融魂 | 万载难逢时机，融纳后再无人与其争夺第三魂 | 无第三魂则只能「融纳」而非「融合」，不完整，修为不增 |

- 王林后退中沙哑开口：**「战老鬼，你认为我还有几弓之力？」**，随后踏入身后漩涡，冷冷盯着战老鬼直至身影消失。战老鬼性格谨慎、不愿去赌，终究没有追出。
- **王林的算计**：之所以选择重伤七彩而非战老鬼，是因七彩之魂只有神通之术、更偏执念；战老鬼获得了**意境本源**的感悟，更为理智，因此王林对其选择有**八成把握**。制造对七彩不利的局面 → 引战老鬼出手 → 一方面借与七彩一战敲打战老鬼使其不敢轻易动手，另一方面等于送战老鬼一份大礼。此为其**七伏杀局**中最满意的结果——王林并未狂妄到认为能杀七彩道人，而是**借势**。
- **战老鬼的选择**：待王林身影消失，双目一闪，转头盯向七彩逃遁方向，目露贪婪，晃身追去。
- **掌尊**在远处目睹一切，隐隐看出端倪，怦然心动却**不提醒战老鬼**，内心另起思绪与计划（伏笔）。

## 三、第一花崩溃

王林踏入漩涡的一瞬，三百残界完全崩溃、界界碎灭。洞府核心大鼎内众人所见的那朵**黄色大花**，其上**三百露水**轰然气化，大花随之急速枯萎凋落。其余之人生死，王林不知。

## 四、五花八门·第二花

王林现身另一处天地，嘴角溢血、面色苍白，先收走仍在大睡的疯子，无暇疗伤便观察四周：前方是一朵散发寒芒的**冰封之花**。

- **「五花八门」**：七彩仙尊洞府核心的**防护中枢**之名（王林由第三魂记忆知晓）。
  - 第一花 = 三百残界（已毁）
  - 第二花 = 眼前的冰封之花
  - 第五花 = 七彩仙尊当年的**封门之印**
  - **八门**藏于最后一花，**七假一真**，真门通往**仙罡大陆**；开启最后一花的重点，正是**第三魂的记忆**
- 王林略一犹豫即果断前扑，与冰封之花融合、没入冰层。因重伤未疗又被冰封之气弥漫，入内一瞬喷出鲜血，**血落地即化作冰血颗粒**，啪啪作响。

## 五、冰封世界·东临宗

- **景象**：大地、天空、云层尽被冰封；一个个漂浮大陆如巨大锥子悬挂。冰封天地内存有诸多**沉睡的生机**，并有一股**熟悉的古神气息**。
- 王林循左侧最浓郁的古神气息而去，一柱香后停在天空，望见万里外锥形石块上盘膝的**长发女子**——眉心有**七个古神星点**缓缓转动，散发古神气息，是一位**女古神**。（叙述中并出「东临星裂缝空间」之语）
- 女子睁眼与万里外的王林目光相触：**「欢迎来到东临宗。」**
- 王林记起这气息为何熟悉：**当年在罗天星域斩杀东临向家老祖时**曾感受过。他一步跨越万里，落于女子身前百丈，问「这里，是东临星？」——女子摇头：**「这里是东临宗，不是东临星。」**
- 王林自报姓名求教，女子答：**「云娜，仙尊麾下，东临宗神长老。」**

## 六、云娜之言（关键设定披露）

1. 王林是**第一个在此地被冰封后、从洞府核心入口进来之人**；她能从王林身上感受到「主人的魂」（第三魂）。
2. 此地是五花八门中的**第二花**，一切皆由主人**七彩仙尊**创造，**包括蕴含了烨寞心神之血的她自己**。
3. 此地完全按主人记忆中其早期宗派、**仙罡大陆上的东临宗**创造，应是一模一样。七彩仙尊**早年为东临宗弟子，后因一些事情被东临宗驱除**，遂造此界以怀念。
4. 此地一切以主人的**生机**滋养成型；主人若死去，此地失去生机便成冰封（——即王林所见之现状）。
5. **「你有主人的分魂，你就是这里的主人。」**
6. **「我体内有烨寞最后的心神之血，你融合后将会完整，应可疗伤。」**

## 七、伏笔与待解

- 五条目鱼去向不明；玄罗手中那条与王林所收之鱼可能存在比目鱼式的气息联系。
- 掌尊看破王林借势之局却按下不发，另有计划。
- 战老鬼追击七彩道人，融纳成败未知。
- 云娜提出的「融合烨寞最后的心神之血」尚未实行；此举与王林自第1380章起以「烨寞」之名/身行事的道古传承线直接呼应。
- 七彩仙尊被东临宗驱除的具体缘由未明。
