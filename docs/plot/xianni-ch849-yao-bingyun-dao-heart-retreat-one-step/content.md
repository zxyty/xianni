# 第七卷 名震罗天 第849章 退了一步

## 一、场景：王林神念入姚冰云道心幻境
王林以神念（道念）融入姚冰云的道心之中旁观，心中不起波澜、无喜无悲。所见为姚冰云记忆深处的姚家祠堂一幕。

## 二、姚家器魂之秘
- **至宝**：一盏古老油灯，上有蓝色火焰，自仙界存在以来从未熄灭，象征**生命之火**；火焰不散热，反而无尽冰冷。
- **危机**：五百年前火焰出现熄灭迹象。姚家老祖（血衣、赤眉赤发、极为苍老，目露夺魄之光）推算许久，查明原因是**灯内器魂将要消散**，器魂尽散之日即火焰彻底熄灭之时。
- **对策**：老祖耗费**三百年**将器魂缓缓抽出一部分，融入姚家最优秀族人体内，**孕化二百年**，诞下姚冰云、姚梦云姐妹。姐妹的出生本就是为了替补成为新的器魂。
- 老祖自空中虚抓，撕开三丈空间裂缝，阴寒之风中飞出油灯。

## 三、转折：退了一步
1. 油灯火焰暴涨成火云，幻化出**一头古妖**（头生双角、身躯庞大、周身火光），王林神念一震认出其为古妖。
2. 古妖张口扑吞两名女童。姐姐姚冰云在极度恐惧中**不由自主后退一步**，妹妹姚梦云因此暴露在前，被一口吞入。
3. 妹妹紧抓姐姐衣衫的双手扯裂衣物，惨呼“姐姐救我”戛然而止。古妖携妹返回油灯，灯火转盛，可见女孩在火中痛苦挣扎。
4. 老祖大喜：**“原来只需一人便可成为器魂”**，遂饶姚冰云不死。

## 四、姚冰云的哀求与誓言
- 姚冰云跪地磕头至**眉心流血**，痛陈“妈妈走前让我照顾妹妹，我没有做到，我不应该退”，愿以自身换妹妹，心甘情愿千年万年为器灵、绝无怨言。
- 老祖罕见地流露茫然，但随即压下，只道：**“这是姚梦云的命，我无意改变”**，将油灯放回裂缝，裂缝合拢消失。
- 祠堂外的**姚云**听到呼喊，双目通红、近乎咆哮地挣扎起身欲冲入，被祠堂内轰出的力量震得喷血抛飞。
- 姚冰云对妹妹许下承诺：“要坚强的等着姐姐……我还没有给你买糖人，还没有带你去找妈妈……姐姐一定会来救你，这是姐姐的承诺。”
- 幻境随其凄厉之声全面崩溃（祠堂、油灯、老者、裂缝皆化碎片成风暴），王林融入的道念受波及险些崩溃。
- 最终立誓：**“谁可以救我妹妹，我姚冰云生生世世侍其为主，哪怕让我丧尽天良，只要能救下妹妹，我甘愿无怨无悔。”** 王林在幻境中应了一声**“我可以”**；跪地的姚冰云似有所觉抬头，身影随即消散。

## 五、无情道之源：闭神仙诀
- 后续画面：长大后的姚冰云盘坐于一座**冰山之下**，目露浓郁悲哀，立誓纵然从此没有情感、心也冰冷，也绝不忘记妹妹。
- 她在此**第一次修炼姚家禁术「闭神仙诀」**——断绝情感、断绝一切，大成便冰冷至极，所修为**无情道**。
- 王林断语：**“以有情心，修无情道”**；“她的道心是其妹，所修是无情道，而非姚家的先祖耀荣”；“此女道心，我可破，但……”（未尽之语，随即身影消散）。

## 六、现实收束：横云山顶了结因果
- 王林在**横云山顶**睁眼，抬手挥袖，**解开姚冰云体内全部封印**，其身飞向天空。
- 王林定性：**“你追杀于我，又助我突破，算是了却了因果。”**
- 姚冰云半空醒转，眼露迷茫与复杂，沉默许久后问王林：**“你，信轮回么？当年我在姚家祠堂，耳边真切地听到有人对我说‘他可以’——是你么？”**（本章以此悬念作结，未给出回答。）

## 七、要点与伏笔
- 姚冰云的“道心=妹妹姚梦云”，是其无情道的根，也是王林判断“可破其道心”的依据。
- 姚梦云仍被封在姚家油灯（器魂）之中，是未解的钩子。
- “有人对我说‘他可以’”跨越幻境与现实，指向**轮回/因果**母题，与王林借此印证己道相呼应。
- 姚家老祖“姚家要亡”的心念与其为家族荣耀牺牲族人的行径，构成姚家倾覆的因果注脚。
