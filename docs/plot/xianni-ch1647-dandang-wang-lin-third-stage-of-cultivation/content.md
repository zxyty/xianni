# 第1647章 担当！

## 一、场景

朱雀星山上，夕阳西下。王林与自称「司徒南」者（据世界状态须知，实为**司徒南的断臂**所化人影，自第336章起自称司徒南；真司徒南已于第61章死亡）对坐饮酒。王林一头白发、一袭白衣，饮酒无醉意，思绪在过去两千多年中不断回放。

## 二、天地真相（王林自仙人记忆中所得）

王林把从那仙人记忆内知晓的一切和盘托出：

- **上一代封尊**来自**远古仙域**，不属于这里；他并非王林本人。
- 王林曾在**太古星辰**内见过的几个**仙妃**，以及神秘的**七彩道人**，都来自一个名为**仙罡**的大陆。
- **仙罡大陆**比界内界外大**数万倍不止**，那里是他们的家乡。
- 王林等众生所在的这片天地，**只是仙罡大陆上一个名为「七道宗」的宗门内、宗主「七彩仙尊」的一座洞府**。
- 「我们看到的天，是那洞府的天；我们看到的地，是那洞府的地。」所谓**界内界外，实为这座洞府的内府与外府**。
- 众生所修的**天道**，是那仙尊**抢到后饲养**在洞府内的。正因天道被抢来养在此处，才有众生之灵诞生演化，才有王林与司徒南的出现；若当年仙尊没有抢到天道，这洞府界不会有众生，它只是一个洞府。

### 天劫与逆修的本质

- 天道既是仙尊所饲养，**天劫自然亦为仙尊所创造**。
- 天劫的用途：**轰杀一切试图改变天道规划道路的存在**。
- 王林以庄稼作喻：凡人种下一片庄稼、规划好一切，总有长得不合心意的，便要将其改回轨迹；而随岁月流逝会出现**顽强的杂草**，生长极快、要破开这无形的规划，无法改变，只能被毁灭——**这就是逆修**。
- 「我，就是一根杂草。只不过这根杂草，天劫毁灭不了，反而**被我所灭**。」王林毁灭天劫、从天劫处**取回了自己的命运**，并因此知晓所在天地的秘密。

## 三、司徒南（断臂所化人影）的反应

- 沉默、神色茫然，默默坐下一口口喝酒，眼中有挣扎、有不信、也有相信。
- 若换任何人说这番话——哪怕是他师尊**青霖**——他都不会信；但说话的是王林，是他的兄弟，他几乎看着王林长大，不能不信。
- 罕见地生出**恐惧**：若这一切为真，自己算什么？自己的快乐真的是快乐么？自己只是一个戏子，认真表演人生，被天空之巅那奇异存在注视、摆布——如同自己看向大地时，看到泥土中蚂蚁窝里挣扎求生的蚂蚁。
- 追问：「一切都是一座洞府？那么**界内与界外的战争**，又是什么？」
- 感慨：看天想知天后是什么，有了修为看到星空以为已是尽头，却没想到**星空的后面，是洞府外**。

## 四、王林的回答与转折

### 界内界外之战

王林称对这场战争**已有猜测但尚未完全想明白**，然而他**留下了一个伏手**，**三年后**将会明白这战争的一切。

### 修道的三个过程

1. **第一个过程**：为了别人而修。
2. **第二个过程**：迷茫与厌烦，向往凡人的一生。他本以为一辈子就在此过程中走下去，直至有足够修为让**婉儿（李慕婉）**苏醒，二人一同走过余年、一同闭上双眼。
3. **第三个过程**：本章开启。

王林起身，任山风吹散白发，眼中迷茫被坚定与绝不屈服取代：

> 「我一生修道，从未在心里认同，但今天，我王林在这生我养我的**朱雀星**上，我要进入第三个过程中，我要修行。」

他向司徒南宣告：当年厌烦修道的念头此后再不会存在；他要**修行、变强、走出这片天地**，去看看**仙罡大陆的人是否有三头六臂**——「**即便是九死落尘埃，那又何妨**」。

### 「担当」——对封尊二字的自省与重新定义

- 自认一生缺少一个词语：**担当**。缺了这份担当，独自一人撑不起一片天空。
- **封尊**称号属于他，却是**别人给予**的：因他做了几件事，因**界内需要一个封尊**。他自认「不配称之为封尊」——本身对修道厌烦、本身为别人而修，之前根本扛不起这份责任。
- 曾幼稚地以为「为家乡、为界内拼命，抵抗界外入侵」就是封尊；如今明白**几乎所有界内修士都在这么做**，自己只是修为高深些才走到今天。真正值得尊敬的，是**那些死去的道友、为界内喷洒热血成为亡魂的同道**。
- 封尊的责任与担当，不仅是抵抗界外入侵，而是**带着界内修士走出这片天空、走出这个洞府，轰开一切阻挡在前之敌的决心**。这份决心与担当，他之前没有，今日之后会拥有——「这，或许就是我的道路，我的归宿」。

### 立誓

> 「我要**杀仙尊**！杀了他，我辈命回；杀了他，便可云开！但在这之前，司徒，我要去**守三年边疆**。」

## 五、齐天雕像与号召

- 王林一步踏入天空，低头看向大地，第一眼看到朱雀星上**自己的齐天雕像**。
- 雕像中的自己**手持开天之斧、怒视苍穹**，一股气势第一次被王林从雕像上清晰感受到：一往如前、绝不回头，任何力量阻挡在前都要被一斧轰开。
- 王林领悟：**这股气势才是封尊**，才是懂得担当与责任、自问之后有了决心的封尊之威。这也是他**曾在散灵上人身上感受到的决心**。
- 他一袭白衣舞动，踏在自己雕像的头顶，迎狂风与夕阳而立，浩荡开口：

> 「朱雀星上界内诸位道友，可愿随王某一同去往**罗天**，与界外一战！」

- 声音如雷鸣音浪回荡朱雀星八方。原本盘膝打坐、等待王林下山的一个个修士蓦然睁眼，目光透出同样的决心，齐声呼吼**「愿随左右」**，大地上无数长虹掘地而起、升空直奔王林与雕像所在。
- 这些修士屈辱多年、死伤无数同门好友，残存者已豁出性命，只需一个声音就能放弃一切去拼杀，哪怕付出生命代价。「国之将灭，必生勇士」，界内亦然。

## 六、关键节点

- **认知层**：世界观最大级别揭底——整个界内界外＝七彩仙尊的洞府；天道被饲养、天劫是除草工具、逆修即杂草。
- **心境层**：王林由「为别人修道 / 厌烦修道」转入「为担当而主动修行」的第三个过程。
- **行动层**：立下杀七彩仙尊之志；先守边疆三年；即刻号召朱雀星修士同赴罗天与界外一战；三年后揭晓界内界外战争真相的伏手。
