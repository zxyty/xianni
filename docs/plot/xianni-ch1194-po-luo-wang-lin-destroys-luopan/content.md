# 《仙逆》第九卷 云海之巅 第1194章 破罗

> 世界状态须知归属：本片段主角自第1063章起以归元宗故人「吕子浩」之名行走云海星域（身份由吕烟菲奉上），文中「王林」即本尊本人，无冒名问题。

## 一、开局态势：重伤脱离战场

- 王林面色苍白毫无血色，唯嘴角血痕触目惊心。
- 他收起了**所有法宝**，包括**半截铁剑**与**战魂**，随即向远处疾驰而退。
- **苍松子**的**血色元婴之物**来不及逃遁，被王林的战魂笼罩、一并收了回来（战利品收获）。
- 伤势细节：眼前模糊、行进中昏昏欲睡、**右肩之上刺痛钻心**，人在昏迷与清醒之间反复，前方道路出现重影。

## 二、危机：罗盘锁定与七彩印记轰击

- 天空中那**巨大的罗盘**移动并死死笼罩在王林上空，随其而动。
- 罗盘急速旋转，散出浓浓威压锁定下方的王林；威压越重，王林身子越虚弱，脚下踉跄。
- 罗盘内轰轰作响，转速再加快，**卷动天空的七彩之芒**疯狂凝聚于罗盘，骤然浮现**无数七彩印记**。
- 危机扩散之际，王林**狠咬舌尖**强行清醒。
- 印记如雨宣泄而下，王林左手虚空一抓取出**三叉戟**横扫抵挡。
- 结果：轰鸣中王林喷出鲜血，身体多处被印记烙印留下深深痕迹，每次撞击都令其身子一震。

## 三、王林的判断（决策点）

1. **罗盘如髓入骨**：若不将其毁灭，必被长久追击，且任何人欲寻找他都易如反掌 → 必须毁掉。
2. **时间急迫**：随着伤势加重，随时会再度意识模糊 → 须趁清醒期尽快破罗盘，然后寻一处疗伤之地。

> 性格刻画：王林越是危急、越是山崩于前，越是心神冷静中带有疯狂——「冷静的判断，疯狂的行为」。

## 四、破罗一击：三重叠加

| 层次 | 表现 | 来源/部位 |
| --- | --- | --- |
| 火 | 左目火光弥漫环绕全身，赤红**朱雀铠甲**瞬息穿身，身外朱雀幻化、火海弥漫，朱雀之音骤起 | 左目 |
| 雷 | 右目雷光轰出，身外方圆千丈大地化为**雷池**；雷霆轰隆、银蛇电芒游走、碎石漂浮 | 右目 |
| 力 | 体内残余的**古神之力**避过右臂，疯狂凝聚于左手并流入三叉戟 | 古神之力（避右臂） |

- 王林一声与天争鸣的低吼，自地面冲天而起直奔罗盘；雷光自地面卷起随之升空。
- 千丈雷池随其升空**渐成一座雷山**（以雷电形成的山），王林正处山之巅峰；雷山不断壮大，最终自地面彻底消散、齐齐凝聚于王林体外，宛如被王林吸收。
- 带雷火之力的王林如被雷光火海环绕的**流星**，持三叉戟疯狂前冲——「行走自己的修真逆天之路」。
- 临近罗盘时施展**「九玄变」**：双眼充满血丝，身影半空化作九份又立刻九份合一，一股远超之前的至强气息降临其身。

## 五、结果

- 王林身影耀眼刺目轰在罗盘之上，轰鸣向四面八方回荡。
- 罗盘通体一震轰然崩溃：先是数道裂缝，随即裂缝不断分裂，最终密密麻麻布满全盘。
- **砰的一声，罗盘四分五裂**（章名「破罗」由此而来）。

## 六、遗留线索 / 后续看点

- 王林伤势未愈（右肩刺痛、失血、意识不稳），下一步目标是寻找**疗伤之地**。
- 缴获**苍松子的血色元婴之物**，与苍松子的因果进一步加深。
- 古神之力**避过右臂**这一细节暗示右臂另有状况（承前文右肩伤/古神之力体系）。


# 第1111章 罗盘崩碎余波

## 一、罗盘破碎与逃遁
- 罗盘（苍松子三珠所化神通）崩溃，碎片向四周横扫、倒卷。
- 一道**赤红色身影**自罗盘中飞出，头也不回向远方疾驰，消失在天际——即重伤逃生的王林（本章以化名『吕子浩』行事）。
- 崩溃之声与波动回荡整个七彩界，成为全界共同的「异动信号」。

## 二、七彩界众生反应（同一声响，多方视角）
| 对象 | 位置 | 反应 |
|---|---|---|
| 化雾凶兽 | 七彩界外围 | 雾气飞快凝聚，化作样貌各异的凶兽，齐齐望向声源 |
| 迷失者（失发者） | 七彩界地面 | 停止茫然前行，抬头迷茫望去；**端木姓童子**为其一 |
| 陈天军 | 外围山峰隐秘洞府 | 疗伤中猛然睁眼；面色苍白、衣衫沾褐色血点，深吸口气 |
| 青衫老妇人 | 山谷外禁制中 | 抬头惊疑不定 |
| 铭志者 | 墙壁般山脉环绕之处的雾气内 | **第一次停止呢喃**，身子一顿，齐齐抬头 |
| 苍松子 | 巨大石像头顶七彩之雾中 | 猛地抬头，眼露震惊 |

## 三、青衫老妇人的困局
- 被禁制彻底困住，短时间无法脱身。
- 此地禁制威力远超其想象；**生死禁与破灭禁已融合、不分彼此**，根本不受她操控。
- 每时每刻遭受禁制印记攻击，体内已受伤且伤势渐重；面无血色，眼露不甘，掐诀化禁抵抗无效。

## 四、苍松子：损失清单与心态转折
### 战损
1. **三个珠子**（合化罗盘神通之物）——心中刺痛。
2. **水晶剑**——心如刀割。
3. **七彩钉子**——储物空间内最强法宝、保命杀手锏；动用后仍未杀死「那该死的吕姓之人」，打击最重，想起时有元神欲崩溃之感。
4. **肉身尽失**，险些丧命，仅余虚弱元神。

### 战前误判与战后畏惧
- 逃遁原因：一是身子虚弱无法再战；二是判定对方在那样的重伤下**必死于罗盘神通**。
- 原计划：待对方死亡后遥遥操控罗盘，把尸体与元神一并吸入，伤愈后「手到擒来」。
- 轰鸣传来 + 感应被切断 ⇒ 计划落空。「在那样的伤势下，此人竟然还能破开罗盘神通」——**苍松子第一次对王林升起畏惧**，整个人沉默。

## 五、地理揭示：七彩界真正的中心
- 苍松子所在的**山脉环绕之地并非**他所称的七彩界中心内部。
- 更深处，**七彩界中心深处边缘**另有一片淹没在雾气内的山谷群。
- **云魂子**面色苍白盘坐于其中一处山谷，一动不敢动。

## 六、王林昏迷与护法
- 疾驰中神识已模糊，咬牙勉强保持一丝神智不灭，双眼渐暗。
- 踏入一处山谷内**荒废洞府**，只来得及打开**储物裂缝**放出**银衣女子**与**许立国**护法，便一头栽倒昏迷。
- 许立国：此前已圆满完成王林交代的**击杀钱贵钟**任务（第1073章钱贵钟已死），事后被收走；出现后本欲邀功，见王林面如死灰昏迷，眼珠转动（心思浮动）。
- 银衣女子一声冷哼，许立国立刻露出阿谀之色——他在储物裂缝中已知此女尸厉害，丝毫不敢得罪。
- 银衣女子冷声「护法」，盘坐王林身旁；目光扫过王林面貌时，**眼中露出迷茫与一丝温柔**（暗指其与李慕婉之关联）。
- 许立国转作精忠护主状守护洞府，内心却自吹「风流倜傥、绝世美男」，嫌那「煞星」没什么好看。

## 七、要点提示
- 本章「吕姓之人」「那煞星」均指**王林**（自第1063章起以归元宗故人『吕子浩』之名行事）。
- 战斗结果定性：**两败俱伤**——王林重伤昏迷、苍松子失肉身失至宝。
- 悬念：苍松子与王林各自疗伤，云魂子潜伏中心深处，青衫老妇人与陈天军仍在局中。
