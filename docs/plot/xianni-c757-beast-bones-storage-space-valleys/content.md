# 第757章 兽骨（第七卷 名震罗天）

## 一、弑仙之议

- 李元对王林“反杀大神通修士”的计划既震撼又心动：换作常人（包括他自己），第一反应只会是逃，哪怕隐匿百年千年。
- 血祖之强：修为最低也是**净涅期**大神通修士；当年**雷之仙界**未毁灭时，血祖虽不及**仙君**，亦可为一方霸主，下界修士无人敢抗。故李元称此举“几乎相当于**弑仙**”。
- 李元表态：王林之恩救的不只是他本人，而是**李家世世代代子孙**，因此这等刺激之事必定奉陪。
- 王林态度：血祖不好杀，需仔细计划；**出手前李元可先行离去**，事成后必有重谢。
- 行动共识：先把这处储物空间搜寻一遍，勿遗落宝贝；李元同时在其内布置几个**禁制崩溃点**。

## 二、储物空间地貌

- 结构：两条山脉、三处山谷（此前李元升空所见）。
- 危险：天空有闪烁而过的裂缝，地面也时而裂开缝隙；**空间内无法瞬移**。
- 伏笔：王林抚山石、神识一扫，感到其上有与自己**储物袋内仙界山石**相同的气息，心底另有打算（未明言）。

## 三、第一处山谷：破禁与分宝

1. 谷口数丈宽，内弥漫薄雾，略显虚幻。
2. 李元掐诀打出禁制，雾气飞快消散——但这是**陷阱**：李元正要迈入时被王林拉住。
3. 王林遣**仙卫傀儡**先行入谷，雾气瞬间重聚化作箭矢尖啸攒射，仙卫以强悍肉身仍被震得连退出谷。李元苦笑，直言此禁制“阴损”，专为自恃禁制之术者所设。
4. 第二次尝试：仙卫全身金光、入谷一拳轰出，拳风成庞大漩涡卷住雾气；王林随即入谷，右手一拍，**元神内的雷电**冲出凝成雷球撞入漩涡，雷光游走使漩涡凝固自转，尽吸雾气。
5. 李元入谷后连打禁制印于石壁，并单指掐算逐一定位。得出结论：**东、南两角为禁眼，同时崩溃即可破谷禁**。
6. 执行：仙卫化残影奔南面，在李元禁制印上石壁的刹那一拳轰出；王林右手凝雷光虚空按向东面，**先于李元指点即准确命中隐藏禁眼**。两声巨响后旋风横扫，雾散谷平。
7. 现宝：**一把黑色短剑**插在地面，四周**八个凶兽头骨**散出雾气环绕成圈。
8. 分配：李元问王林取剑还是取骨；王林念李元相助甚大、不便夺人所爱，取**八个头骨**，李元取**短剑**并道谢。王林神识扫过头骨后**内心一震**，表面不动声色（重要伏笔——本章题名“兽骨”）。

## 四、第二处山谷：裂缝十里与血光九闪

- 第二谷入口远小于第一谷；越近裂缝越频繁，**十里之外已无通行之路**，裂缝密密麻麻。
- 李元判断：裂缝非禁制，他无法破除；且此空间不能瞬移。王林请其原地稍候，自称有法进入。
- 王林准备：盘膝而坐，双指成剑在全身数处急点，每点一次面色微红，**第九下后面部火红**，张口一吸，火红尽退（预凝神通于体）。
- 第一段：拍储物袋放出**山河图屏风**，一抛铺开千丈山水，所有裂缝仿佛被“打上补丁”消失；同时仙卫傀儡蹲身抱住王林，全身金光狠狠前抛，一抛冲出**五里**。
- 第二段：山河图很快被撕出众多缺口，如森森大口四面吞噬而来；王林在仙卫之力将竭前，全身血光一闪，展开预凝的**血光遁术**，连闪**九次**，速度快如瞬移，瞬间出现在第二谷口外。
- 神通来历与代价：该血光逃遁神通出自**妖灵之地老者魂魄**内众多神通，是其中**速度最快**者；**非问鼎大圆满不可使用，否则立刻爆体而亡**。
- 落地状态：王林面色苍白、略有踉跄，右手一召收回山河图屏风；回望十里之外仍可见李元身影。

## 五、要点小结

- 计划层面：弑血祖的行动进入准备期，李元入伙但预留“动手前撤离”的安全阀。
- 收获层面：八个凶兽头骨（王林，另有玄机）、黑色短剑（李元）；仙界山石气息埋下后续伏笔。
- 实力层面：王林已可动用问鼎大圆满门槛的血光遁术，且能自主辨识隐藏禁眼、以雷球制衡雾箭。
