# 第1562章 召河

## 一、空门破后的余波

- 空门破、涅力流出。清水一身青衣，将亡妻**含烟**之魂珍重地放入怀中，化作一个印记贴在心口。
- 并非不能收入储物空间，而是清水不舍。
- 天空中的空之大门（虚幻大门）在本章过程中渐渐消散，最终彻底消散。

## 二、杀戮之剑与六道本源

- 清水**执意相送**那把杀戮之剑，王林收走。
- 王林身上本就在**云海第一战前后**诞生过杀戮本源，但极微弱，仅仅是诞生而已，并未太过显露。
- 得此剑后，**王林的本源成为「六道」**。
- 并非本源的**战之印记**早在之前就化作**规则之星**，深深留在王林体内。

### 王林的证道计划

1. 暂不即刻炼化吸收杀戮本源——「还不是时候」。
2. 等**因果、生死、真假**三道本源全部大成。
3. 在**轰空门的一瞬间**去吸收杀戮本源。
4. 目标：一举打开空门，成为古往今来极为罕见的**六道本源证道者**。

## 三、蛮荒星共饮

- 清水从天空落下，虚空一抓取回**青色龙血酒壶**，饮下一口，辛辣感令其双眼露出寒光，随后把酒壶递给王林。
- 二人在蛮荒星上迎寒风、望着消散的空之大门默默饮酒，无人说话。
- 王林**没有去问**清水在修真联盟总部、在七彩界是否找到了当年想知晓的答案。
- 清水**亦没有说**。只有他自己明白发现了什么、明悟了什么；但了解越多，他越是沉默。
- 清水的结论：**「一场游戏」**——眼中寒芒一闪，脸上却是苦涩，随即大笑。

## 四、两个承诺（归葬之诺）

| 立约人 | 内容 |
| --- | --- |
| 清水请求王林 | 若他死后尚有完整尸体，带回**家乡**安葬；**墓碑不留名**，「一丈之土，便是我最好的归墟」 |
| 王林追问「若家也没了呢」 | 清水答：「那便葬在**天地之中**」 |
| 王林请求清水 | 若他先死，送他回**朱雀星、赵国、王家** |

> 「这是承诺。」龙血酒很烈可醉人，却醉不了王林，更醉不了清水。

## 五、子女与托付

- 清水问王林「你有后么」。
- **王林**：有一个儿子——眼中有悲哀，酒入腹已不辣，而化作刺痛。
- **清水**：有一个女儿，但**找不到她了**，「或许她已经永远的离去了」。
- 清水的追忆：当年他清醒的一刹那，抱着妻子的尸体恸哭；远处血液之中、一片残骸之后，有一个**七八岁大小的女童，抱着一只死亡的仙鹤**，空洞的双目望着他、望着她的妈妈。
- **识别信物**：清水在女儿出生时于其**左肩留下一个红印**，此印会永远伴随她。清水托王林：若见到这样一个女孩，替他照顾。
- 女儿可能已经**轮回/转世**。

## 六、章末转折：清水动了杀意

- 空之大门彻底消散后，清水站起身，长呼一口气，双眼寒光毕露。
- **「王林，我想杀人。」**
- 右手抬起，一股天地至极的**杀戮本源**自体内爆发、凝聚于右手，该手转瞬被**黑色寒气**弥漫；寒气如絮飘摇而起，整个蛮荒星在这一刹那冷意环绕。

## 七、设定要点：杀戮本源

- 极为特殊的一道本源，**古往今来拥有者极为罕见**。
- 一旦拥有，**一道本源就可轻易破开空门**。
- 定位：**杀之极限**。

## 八、伏笔/待跟进

- 清水要杀的是谁（章末未点明）。
- 清水在七彩界/修真联盟总部所明悟的「一场游戏」究竟指什么。
- 左肩带红印的女童（清水之女）日后是否出现。
- 王林何时凑齐因果、生死、真假三道大成并轰开空门。

# 第1471章 清水横扫三大星域·召河七彩界之战

## 一、清水的杀戮之威
- 清水修为虽仅**空涅初期**，但以**杀戮本源**为根基，加之数万年的神通之战积累，其可发挥的杀戮之力，**即便空涅后期修士遇到也会色变**。
- 王林一句「杀人么……好」后起身，向天空迈步，脚下泛起波纹，直接消失于天地内；清水全身冰冷弥漫，同样踏入王林消失的波纹，一并无影。

## 二、横扫三大星域
- 比喻：整个**昆虚星域**如一潭湖水，水中浮游为一颗颗修真星；此刻水面上出现两道并列波纹，如两条箭鱼水下疾行。
- 背景：昆虚星域内界外修士本就不多（修真联盟才是其暂时总部），且此前一场震动整个星空的杀戮几乎将其屠尽。
  - 那场杀戮由**一对师徒二人**掀起，在**龙磐子**绝对修为之下罕有界外修士存活。
  - 龙磐子目标是**召河**，昆虚未做停留，故留下漏网之鱼。
- 三名**眉心有印记**的界外修士惊慌逃遁，不敢提速以免波动引人注意，彼此传音：
  - 「消息玉简没有反应，怕是其他人都凶多吉少」
  - 「修真联盟总部不能回去，我担心那里也出现了变故，莫非是界内大肆反攻」——议定寻一处修真星隐藏，待大军杀来再出现。
  - 结局：两道波纹自其右侧星空掠过，其中一道弥漫滔天杀戮，穿透三人；无惨叫，三人身现无数细密裂纹骤然崩溃，**元神四分五裂道消而亡**。
- 同样一幕在**昆虚、罗天、云海**处处上演：三大星域残存的不多界外修士，在龙磐子横扫之后再次经历来自清水的疯狂。

## 三、冲入召河
- 两道波纹横扫三大星域后冲入**召河**——彻底被界外修士占据之地，存在诸多界外修士，一入即有浓浓血腥弥漫。
- 二人以融入天地的速度掠过一处处修真星，直奔召河深处**最后一个七彩界**。
- 该处为**红杉子本尊被封印所在**。
- 星空中一个巨大裂缝散发七彩之芒，裂缝外残肢断臂处处、大量界外修士惨死；界内不断传出轰鸣，显然正进行激烈厮杀。
- 清水临近时，身后星空一路冰封，裂缝外的残肢断臂与无数尸骸尽被冰封笼罩，寒气逼人。
- 波纹消散，一身**青衣**的清水毫不犹豫踏入七彩界；王林身形亦幻化而出，**略有疲惫**中随之进入。

## 四、召河七彩界内格局
- 此七彩界与王林先前所见两处不同：由**数块漂浮的大陆**组成。
- 此刻四周充满大陆崩溃的碎石，漂浮空中的**只剩三块**。
- 三块大陆之上：**龙磐子**与一**黑袍老者**斗法，挥手间地动天摇。
  - 黑袍老者身份：**长尊会天罚殿殿主**，即云海第一战中刚出现就被**封尊之灵**困住之人。
  - 修为：在**太古星辰**内次于五尊，已至**空玄初期**——且是**真正的空玄初期**，并非如龙磐子那样以毁灭生机换取。
- 三块漂浮大陆之下：**界外数万修士**盘膝而坐，喃喃咒语；头顶飘出一丝丝**香火之力**，在半空化作一个个样子诡异的生灵，嘶吼咆哮，环绕龙磐子与天罚殿殿主四周一同出手。

## 五、清水入场屠戮与道果现身
- 清水先王林一步来临，扫视天空二人后双眼寒光闪烁，迈步直奔四周数万修士。
- 王林入界时耳边的阵阵惊天惨叫，正是自这数万修士口中传出。
- 清水嗜杀，此刻**杀戮本源大成、轰开空门**后嗜杀达到巅峰——其一生皆在杀戮中度过，冲出后挥手间便是亡魂生灭。
- **关键发现**：王林双目一闪，抬头略过龙磐子与天罚殿殿主，看到二人上方的**七彩云雾中，有一个巨大的道果从云内垂下**。

## 六、要点梳理
| 项 | 内容 |
|---|---|
| 清水修为 | 空涅初期（战力越阶，可令空涅后期色变） |
| 龙磐子修为 | 空玄初期（以毁灭生机换取） |
| 天罚殿殿主修为 | 真正的空玄初期，太古星辰内次于五尊 |
| 被扫荡星域 | 昆虚、罗天、云海 |
| 目标地 | 召河 → 深处最后一个七彩界 |
| 七彩界意义 | 红杉子本尊封印所在；此界由数块漂浮大陆组成，仅余三块 |
| 悬念 | 七彩云雾中垂下的巨大道果 |
