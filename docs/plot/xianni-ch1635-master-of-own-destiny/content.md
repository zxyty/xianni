# 第1635章 主宰命运

## 一、看破真相后的心境

王林在轰开天劫、知晓天劫因何而生之后，对洞府世界的真相有了彻底明悟，却以疯狂笑声接纳：

- 他推断自己终有一日可以踏出这个洞府、踏入**仙罡大陆**，去看那些**大尊**之辈究竟有多强，质问他们「有什么资格去圈养众生、成为众生之主」。
- 由此反推通两处旧疑：**一代朱雀**曾说可以带有限的几人离开此地去其家乡——因为除他之外，其余人根本不是仙罡大陆之人，只是这洞府内诞生出来的修士；一代朱雀又说其家乡有人能复活**李慕婉**而他自己不能，亦得解释。
- 参照**散灵上人**能带七百万天地之人走出，王林认为自己日后也能做到。
- 心境结论：真相如何都不改变本心——他还是王林，还是逆修之人，还是要复活李慕婉，还是要独自面对这天地一切。只要有不屈之心与执念，就一直走下去。

## 二、连续轰开九个太阳（天劫本源）

王林逐一轰开远古仙域中的九个太阳，露出七彩男子所凝聚封印的天劫本源：

| 序位 | 内藏之物 |
|---|---|
| 第二阳 | 火劫（天劫之火） |
| 第三阳 | 威压之力，即可镇压众生的**天威** |
| 第四阳 | 四把剑，散发滔天剑气（王林毫不在意） |
| 第五阳 | 无数虚幻身影，融合变化莫测，为**幻真劫**根源 |
| 第六阳 | 三样法宝气息：**镇仙塔**、**封命环**等，气息缭绕不分彼此 |
| 第七阳 | 古之三族的魂力，封印无数古之三族灵魂，为**操控天道使者的最终手段** |
| 第八阳 | **本我劫**的气息，急速变幻难以分清 |
| 第九阳 | 天劫本源、命运总纲（详下） |

轰鸣持续回荡整个远古仙域，震动大地，使地面上的雕像不断颤抖。

## 三、第九阳：命运总纲

- 第九阳内蕴含王林从未见过的天劫之力，却有极熟悉的气息——有他自己的、李慕婉的、父母的，以及他一生见过的无数人的。
- 王林闭目静立许久（岁月不知过去多少）后明悟：**第九个天劫为天劫本源，如同总纲，包含古往今来、界内界外、无论生死一切众生的命；凡在这洞府内诞生之人，尽有记录。**
- 他一度动念毁去这天劫（以其修为有几分可能做到），但明白一旦毁掉，天地必陷大乱——这天地并非自然而成，而是**七彩男子以洞府创造**。
- 神识入内所见：一片混沌中有无数凡人的一生、无数修士的一辈子、许多穿着古老衣衫早已死去很久的面孔。此第九阳包含天地初开至今一切众生之命，如同轮回、如同法则，把种种不公与机缘统统沦为「命运」二字。

## 四、取回命运——成为主宰自身命运之人

1. **取己命**：王林找到属于自己那股极浓郁刺目的命运气息，以神识笼罩并吞噬融入神识中。融合刹那神识剧变，体外闭目之身剧烈颤抖，仿佛身体变得完整——从此天地间再无任何力量（包括天劫、包括七彩男子）能改变他的命运。文中评述：凡人自古在命运下挣扎，有阎王三更之说，终究无法超脱；唯有王林在这一刻把命运拿了回来，成为主宰自身命运之人。
2. **取亲友之命**：他并未收回神识，继续寻找亲人、朋友、爱人的命运一并取走，让他们即便已死也不再受天地左右、随他一同超脱。
   - 父母：二人命运气息虽已终结，却仍相依在一起、交错生生世世（王林为之心悲）。
   - 友朋：十三、大头、周佚、青霜、青霖、南云子、红杉子、王卓、对他有恩的老圣皇、遁天。
   - 亲眷：其子王平、周茹。
   - 红颜：红蝶、木冰眉、西子凤，以及一个个遇到又相忘的红颜；还有李倩梅。

## 五、三处缺席与一处被人先取（关键伏笔）

- **找不到**：清水（清水仙君）、司徒南、（曾试图寻找的失踪者）天运子——三人的命运仿佛从不曾出现在第九阳内。
- **被人提前取走**：李慕婉的命运有存在迹象，却在不知何时被人抢先一步取走。这与清水、司徒南等的「不曾出现」性质不同，成为本章最大悬念。
