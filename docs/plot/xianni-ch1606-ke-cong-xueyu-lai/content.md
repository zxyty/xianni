# 仙逆 第1606章 客从雪域来

## 一、缘起：收下丹药，开始周游

- 王林说完那番话后，自身仍处迷茫之中，沉默半晌拾起地上那粒丹药揣入怀中，轻叹转身离去。
- 他不拘一山一地，走过无数大山长河，带着对天地的明悟与自己的思想，走进一个又一个国度。
- 丹药被他吞下，给予无尽精力，使其有力气完成「周游列国」的心愿。

## 二、凡人之身，威压天下

- 途中依山而眠、遇河则歇，见善良者、凶狠者、茫然者、冥顽者无数。
- 遇强盗马匪，只需站立不动，其身上的浩荡气息即令众人退避——他连仙人都可一语惊退。
- 容颜愈老，双目愈明，蕴含无尽智慧感悟，思想上再度脱胎换骨、升华。
- 曾有人起加害之念，最终皆在面对王林时被一股说不出的感觉逼得敬畏倒退。

### 列国见闻（节点事件）

| 国度 | 事件 |
| --- | --- |
| 吴国 | 吴皇欲留王林为吴国大儒，成千上万禁军环绕待命；王林微笑摇头转身离去，天空雷霆滚滚、风云色变，上万禁军无一敢阻，待其离去后齐齐一拜 |
| 孙国 | 孙皇与无数臣子送王林千里 |
| 天狗国 | 恶民无数，王林离开时教化数万 |

- 他去过太多城池、太多京都，见过众多达官贵人乃至凡间皇帝；在他眼中「这些一切人，全部都是一样，没有区别」。

## 三、修真界的震动

- 朱雀星诸多修真国内宗派林立，或建于山峰灵秀之地，或处穷山恶水。
- 王林凭心中对天地的感悟随缘登山入门，**护山大阵强弱不同，却无一能影响其脚步**；闭关无数年的长老也会被其散出的天地浩荡从打坐中惊醒。
- 他从容而来、从容而走，只看山、只赏景、只悟天地，万物在其目中皆同。
- 连赵国修真界也传开「凡人大儒王林」之名。修士敬畏的**不是其力，而是其思**。
- 名言：「修士也好，凡人也罢，全部都是悠悠众生」。
- 与其长谈者中，多有感悟天地、明了意境、**化神有望**者；修为已过化神者亦在长谈中心神震动。

## 四、第十二年·雪中都城与曾家铁匠铺

- 十二年前独自离开赵国，十二年后仍独自行走于朱雀星。
- 冬日雪季，王林来到一处不知国名的都城，该国范围约相当于三个赵国。**这座都城，王林曾在梦中来过**。
- 城门外雪落，王林苍老容颜起了一丝惆怅；入城后行至一条安静街道。
- 循「铛铛」打铁声见一家铁匠铺：中年汉子赤上身抡锤，旁边小板凳上坐着七八岁男童，穿厚棉袄、小脸通红。
- 王林脱口「大牛」，随即摇头——**那孩子不是他梦中的大牛**。
- 汉子憨厚相邀入内暖身，唤妻子「秀娘」温酒；妇人贤惠，眼含怜悯为其斟酒。
- 汉子笑称：「我曾家的酒还不错吧」，并道祖父辈本是卖酒的，到他这代才开起铁匠铺。
- 王林喝着曾家的酒，**有些分不清是梦，亦或者不是梦了**。
- 雪小时王林告辞，汉子怜其年迈，赠一壶酒暖身；其身影在铁匠铺烛火与月下渐行渐远。

## 五、第十五年·亭榭听雨与最后的目的地

- 离开赵国第十五年，王林已七十出头：脊梁更弯，身透暮色，但双目明亮如阳，令人不敢对望——**那双眼内蕴含了因果、生死、真假**，连当年的师傅苏道也没有这种气质。
- 第十五年夏，在一个陌生国度的连绵雨中，王林立于官道旁亭榭内观雨；雨后极远处是一片大海，隔开两块大陆。
- **海的另一边诸国，是王林最后要去的地方**——那里有他梦中另一个人生的挚爱女子，他要去看一眼。

## 六、结尾悬念：客从雪域来

- 王林闭目一刹那，雨中远处一名女子一步步走来，全身散发无尽冷意，四周雨水在咔咔声中化为冰晶落地，其身后天空被冰封笼罩。
- 女子已入中年，容颜娇美，被冷意弥漫而显萧杀如罗刹；**怀中抱着一个婴儿**，婴儿裹在厚实棉被中，无一滴雨水沾身，睡得香甜。
- 亭榭内王林无雨，亭榭外女子亦无雨。女子问：「你可是大儒王林？」王林睁眼，平静点头。
- 女子言：**「我来自雪域，寻你问一事。」**（章末悬念）

## 七、看点与伏笔

1. 「梦中人生」线索延续：梦中的都城、梦中的大牛、梦中另一人生的挚爱女子——真假虚实母题贯穿本章。
2. 王林此程走的是「思想之道」而非力量之道，凡人身份与仙人威压并存，为其境界感悟铺垫。
3. 雪域来客与其怀中婴儿是新登场势力/线索，问事内容未揭示。
