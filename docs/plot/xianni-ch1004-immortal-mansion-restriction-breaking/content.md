# 第八卷 联盟隐秘 第1004章 仙府深处的存在

> 归属提示：本片段主角以「许木」之名行走于联盟星域（自第661/669/711/731/771/821/881章沿用），原文此处直呼「王林」，一切言行归【王林】。

## 一、场景与开局分歧

- 尘道三子结束吐纳，一尘子起身抱拳劝阻：己方对禁制了解不多，但看得出此地「平静之下蕴藏杀机」，若强行破解需众人一同出手方有几分把握。
- 王林一挥手打断，答「无妨」，直接以命令驱使银衣女子（银衣女尸）先行探路。对银衣女子而言，王林的命令即是使命，毫不犹豫踏入百步范围。

## 二、十步试探：确认「活禁」

1. 银衣女子右脚落地刹那，王林目不转睛爆出精光，全程观测。
2. 前九步无事；**第十步**落下瞬间，百步范围凭空泛起道道波纹，四散回荡并升起淡雾直扑银衣女子；观望者眼中该范围一阵扭曲，如被某种力量撕扯。
3. 王林心神中推衍不停，平静下令：「神通攻击**左侧乾位**，后退而回。」银衣女子右手光芒化印落于左侧，轰然一声，百丈范围如狂风掠过，雾气消散、波纹平息，她从容退出百步之外。
4. 此举震动全场：浮风子双目精光，尘道三子一呆，看向王林的目光变得古怪。

**王林的真实目的**：他第一眼便觉不对——外围禁制皆是「死禁」，无人操控，变化按固有存在而动；百步内的禁制却隐约有人操控的迹象。十步试探即为验证，结果几乎坐实猜测。

## 三、禁制推衍：破灭禁与心禁之术

王林踏上银衣女子第十步之位，得出判断：

- 此地靠近河流，百步内禁制虽变化无数，**最终只形成两种形态：泥土与水汽**。
- 推衍所见：百步范围内共 **39,714** 个禁制，彼此相连如一整体，**牵一发而动全身**。

### 出处与成长线
- 禁制之术学自当年**古神之地**；
- 一千多年修道中不断完善；
- 于**罗天星域**传承**破灭禁**，如今「始于大成」；
- 在罗天更得**心禁之术**——破灭禁中的最巅峰之术。

> 心禁要旨：「万物一切，天地所禁之处，在一心中就可包含乾坤，心之所动，禁衍无尽。」

### 王林的顿悟（本章重要设定）
- **修道天资 = 对灵气的敏感程度**，越敏感天资越高；
- **禁制造诣 ≠ 灵气敏感**，主要取决于**计算推衍能力**，而这取决于**心智**；
- 王林自小天资不足，但心智超人一等——否则也走不到今日。

对比：若是尚未学会破灭禁的王林，此刻必须在外盘膝冥思、耗费大量时间把三万多禁制全部推衍完毕才敢破解；如今可边走边衍。

## 四、以禁破禁：穿尘暴、破怒浪

| 阶段 | 禁制形态 | 王林应对 |
|---|---|---|
| 第 11–20 步 | 触动整体禁制，如湖面投石，爆发连浮风子也动容的天地之威 | 从容迈步，感叹「仙禁之术，果然巧妙」，并想到天运子与凌天候所拥有的仙府又是如何破解 |
| 尘暴阶段（泥土形态） | 百步内化作荒漠，风沙走石汇成黑色尘暴旋风怒吼吞噬而来 | 掐诀幻化一道禁制印记，令旋风**在其身前下方**崩溃，人直接从尘暴中穿透而过 |
| 九十步·怒浪阶段（水汽形态） | 水汽弥漫、波浪之音顿起，百步化作汪洋，怒浪拍落 | 取出**心禁罗盘**，左手划盘使其旋转，向左侧跨出数丈，罗盘前甩、双手掐诀，喝「破」，罗盘闪耀黑芒并被禁制环绕形成冲击推开四周，怒浪如画卷寸寸撕裂消散 |

- 那道穿透尘暴的印记「看似简单」，实为无数次推衍计算所得：**时间、方位、地点、禁制之力大小**任一有丝毫偏差都无法奏效。
- **心禁罗盘**：破灭禁传人必须拥有之物，自储物袋中拍出。
- 旁观反应：浮风子倒吸口气、露出骇然与敬佩，断言「他不是准备强行破解，而是要以禁破禁」，且「他的从容并未假装」；尘道三子相互对视，对王林更加敬畏。

## 五、尖啸与登桥

- 怒浪消失刹那，仙府内部传出一声尖啸，化作音浪回荡府内。王林目露寒光：「果然有操控这禁制者。」
- 王林手持罗盘直接踏上**石桥**，从容走向仙府内部，心中所思：仙人洞府绝非那么简单，不知内部到底有何物在操控禁制、阻止外人进入。
- 浮风子、尘道三子、大头等人随后临近。

## 六、仙府内景（章末悬念）

- 内部**如一处花园**，处处花团锦簇、万紫千红，一眼望去令人缭乱。
- **四座雕栏玉砌的阁楼**错落，中间是一处**庞大宫殿**，其上雕龙刻凤，更有王林从未见过的**仙兽之相**，充满仙威。
- 大殿外立有**十尊金像**，全部身着铠甲、状如**仙兵**。
- 王林目光一凝认出材质为**玄金**——**先帝青霖玉简**内记录的、增强**仙卫**肉身强度的主要材料之一。
- 一股可怕的威严，自漆黑的大殿深处缓缓传出、弥漫四周。

## 七、要点沉淀

1. 本章确立王林「禁制流」战力标签：禁制大成 + 破灭禁传承 + 心禁之术 + 心禁罗盘，可实时推衍数万相连禁制并以禁破禁。
2. 死禁 / 活禁（有人操控）之分，是本卷仙府探索的关键判据。
3. 玄金—仙卫—先帝青霖玉简的线索串联：仙府大殿外十尊玄金金像，指向仙卫傀儡体系。
4. 悬念：大殿深处「操控禁制的存在」尚未现身。
