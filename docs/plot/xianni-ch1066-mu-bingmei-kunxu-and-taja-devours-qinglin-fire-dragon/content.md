# 第八卷 联盟隐秘 第1066章（仙逆 00982-00986 之5）

## 一、昆虚之境：老者与昆虚圣女木冰眉

同一时间，联盟星域内的昆虚之境。此前察觉出王林心神的老者神色复杂，一步迈出后回望下方面色冷漠的昆虚圣女木冰眉。

**老者的规劝要点：**
- “你第九分身因劫而毁，此劫既然已经来临，你何必再躲。”
- 第九分身“因他（王林）而涅”，无论如何躲避终要面对。
- 当年木冰眉救下周茹小姑娘，老者便已明白其心神已因第九分身而乱。
- 身份训诫：“你是昆虚圣女木冰眉，不是朱雀星与那寻常修士诞下一子的柳眉。”
- 使命：光复昆虚之境；责任：对抗界外之民。
- 时限预警：“界内与界外，开启的时间，不久了。”

**木冰眉的回应：**
- 两度强调：“他，不是寻常修士。”
- 反诘老者：“你曾经，也只是一个修士。”（老者苦笑无言）
- 界限声明：昆虚圣女的责任与应做之事不会推却，但私事不容任何人干涉，“我与他的事情，不需要任何人去参与”，斩钉截铁毫不妥协。

**老者的轻视与其不知情之处（叙述者补白）：**
老者认为王林“终归也就是一个修士”，纵使修为可达第二步巅峰亦无妨。但老者并不知道：
1. 王林是朱雀圣宗倾全宗之力也要保护的**觉醒者**；
2. 王林拥有**古神血脉**——此血脉并非传承而来，而是王林肉身崩溃后，凭借**涂司**的记忆修行**古神诀**重新凝聚出的身体，该身体本身即为血脉根源；
3. 王林拥有**天逆**。

**行动决定：** 老者提出“老朋友的肉身被夺舍，我要去一趟”，问木冰眉是否同去；木冰眉神色复杂后坚定点头：“去。”

## 二、仙帝洞府第七层：火龙灵反噬

第七层内所有岩浆凝聚化作一头**火龙**——即当年看守此地洞府的火龙灵。硕大龙头抬起，无形威压弥漫，鼻间喷出高温热流，双角通体赤红，蟒身环绕，睥睨天下。

- 火龙首先注视王林，从其弱小身体上感受到一丝熟悉气息——**火元力**。王林心神一震却未低头，缓缓后退；片刻后火龙收回目光。
- 火龙转而怒吼扑向**虚空子**与**古妖贝罗**、**古魔塔珈**三人，第七层顿成火海。
- **古妖贝罗**：不再逃遁，转身掐诀，妖气化通体绿色妖头，反扑吞噬后方的古魔。
- **虚空子**：黄沙化风暴，结成约十丈黄沙壁垒挡火，但以其此刻修为无法久持，甫一触火便砰砰干裂崩溃。

## 三、古魔塔珈：以仙帝神通镇场

### 神通一·魔之焚天
古魔塔珈神色冰冷、魔芒嗜血，狂笑讥讽“区区一头当年看守此地洞府的火龙灵，竟然也敢噬主”，宣称“且让你等看看当年仙帝青霖的神通之术——**魔之焚天**”。
- 黑色魔火轰然横扫，充斥并覆盖第七层天空，天地尽黑。
- 魔火高温蕴含魔气：不但焚烧一切，更魔气入体致**元神崩溃**。
- 火龙散火对抗、庞大身躯撞来，塔珈一指点落，天空魔火如流星降临尽覆龙身；再右手前按，以**无形之力**在十丈之外生生抓住火龙，任其挣扎咆哮无法挣脱。

### 贝罗的判断
“你竟然已经可以施展青霖的神通，更是可以发挥其身体内的无形之力”——贝罗骇然，判定塔珈**夺舍青霖肉身已达心身归一的地步**。他随即苦涩放弃一切进攻打算再度后退，认定即便加上洞府内所有人，也绝无法改变青霖被夺舍的现实。

### 塔珈的图谋自述
- 当年不惜一切代价，与青霖在这肉身内斗了**无数万年**。
- 所图：青霖的**神识记忆**、**全身修为**，更重要的是这具**肉身**。
- 该肉身经青霖祭炼无数年，是可**破开一切规则**、天地间无处能阻拦脚步的**规则之体**。
- 与贝罗的旧怨：“古妖，你我当年在**界外**就是大敌。”如今视贝罗如蝼蚁。
- 终极目标：彻底融合肉身后追溯**古之先祖**的脚步 → 达到古魔一族真正的**九星境界** → 进入**古之先祖遗迹** → 获得**返古之力**。

### 神通二·魔之焚天煮海
塔珈双眼魔焰而动，第七层地面涌出浓郁如实质的魔气，转眼化作一片**魔海**，怒浪翻滚。王林、虚空子、古妖贝罗乃至火龙皆陷其中，火龙龙目亦现骇然。
- 海水沸腾、气泡无数、高温不可想象；
- “焚天煮海”取意：将整个海洋煮飞、彻底消散崩溃，令深陷者毫无挣扎可能；
- 天空魔火不断下沉，海内水汽大量升腾，海水越来越少，如同困牢。

## 四、王林的观察与虚空子的自爆

**王林的判断：** 与塔珈短暂接触后发现，此人**随时间推移似乎越来越强**——此等神通在之前第九层时怕是很难施展，眼下却已能用出当年仙帝的神通。想到仙帝青霖神通无数，王林头皮发麻。

**虚空子自爆：** 危机时刻，虚空子脸露惨笑，咬牙以右手一拍额头，肉身轰然崩溃。自爆冲击向四周一推，使海水出现漩涡，连下沉的魔火也被推得凹陷；自爆刹那，**虚空子元神一冲而出**。

## 五、结构性伏笔

1. **柳眉—木冰眉分身线**：老者一句“不是朱雀星与那寻常修士诞下一子的柳眉”，首次把柳眉线明确接到昆虚圣女木冰眉的分身体系上（第九分身因王林而涅）。
2. **界内界外将启**：昆虚之境的使命与“界外之民”对抗迫在眉睫。
3. **王林底牌未被外界知晓**：觉醒者身份、古神血脉（涂司记忆＋古神诀重凝之体）、天逆。
4. **塔珈威胁升级**：心身归一 → 规则之体 → 九星 → 返古之力，且实力仍在持续增长。
