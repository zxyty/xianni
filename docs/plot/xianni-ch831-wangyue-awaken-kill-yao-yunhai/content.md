# 第七卷 名震罗天 · 第831章 望月（第三更）

## 一、王林的谋划：借望月之威

- 被姚家族人与众多修真家族追杀之初，王林便定下**借望月之威**的计划：望月之强令他记忆极深，只要望月发怒，追兵不值一提。
- 王林在望月体内高速穿行，**丝毫不顾及是否刺激到望月**，直奔当年撬骨之地。
- 深处所见：**半截望月骨已重新凝聚**在原位。当年王林本欲取走全部，最终不得不放弃半截。

## 二、贪狼大鼎与古神涂司

- 王林忆起：**当年贪狼那件奇异无比的宝贝大鼎，被望月吞下**。
- 他仔细分析过，有**八成把握**认定该大鼎是**古神涂司炼化后不甚满意、随意丢弃之物**。
- 权衡：望月苏醒将是一场浩劫，换个时机他断不敢动此念；但眼下外面有大量修士替他消散望月怒火，遂一咬牙下定决断。
- 风险认知：望月体内并不安全，**随时会有小型望月出现**——当年撬骨时便遇到一头，费大力气才逃走。故此次一边游走一边散开神识戒备。

## 三、外围：追兵的轻视与涌入

- 望月所化星球外，无数修士密密麻麻包围四周。见王林（以「许木」之名行事）进入星球，第一反应是「此地有古怪」——一路追击中已彻底见识其狠辣，深入骨髓。
- 罗天北域修士的议论，让所有人知晓**此星球是一头奇异之兽**。
- 姚家一中年男子冷笑不屑：即便是凶兽，齐力之下也可杀之。
- 姚家典籍逻辑：记录过仙界时期诸多凶兽，甚至有比此物更庞大者，最终均被仙人联手杀死；而**眼前之物家族典籍毫无记录，故断定「根本不入流」**。
- **姚云海**（姚家三代族人，阳实巅峰，为人极为自傲）附和「杀之不难」。
- **姚冰云**率先一跃冲入黑雾，起到带头作用；随后自持修为高深者陆续冲入，姚云海踏飞剑化长虹跟进。
- 越来越多修士穿过黑雾登上星球表面，见到**地面无数摇曳触手**的诡异一幕，短暂一顿后四散寻找王林踪迹，部分选择深入星球内部。
- 姚冰云顺触手落地后直接沉入地底，越下沉越觉四周诡异不妙；姚云海亦沉入，毫无顾忌横冲直撞，身后跟着几名修士。
- 外部仍有大量修士（含姚家族人）留守包围、目光炯炯接应。

## 四、转折：望月现苏醒迹象

- 众多修士沉入体内，使望月所化星球出现**一丝极轻的震动**——体内感受为「四周压力一下子大了一点点」。
- 王林蓦然停止一切行动，嘴角阴森：「有了苏醒的迹象……这望月在沉睡状态下时间不长，稍一刺激便可苏醒……就让我帮你苏醒得更快一些吧。」
- 决断：直奔**望月之骨顶端的敏感之位**。对比当年——那时他想方设法不让望月苏醒，此刻一切改变。

## 五、战斗：小型望月出世与姚云海授首

1. 姚云海散开神识向下冲击时，**一股阴森之气骤然弥漫**，他立刻停身，身后几名修士赶到。
2. 泥土裂开缝隙，一头**百丈长短的小型望月**闪电般冲出，大量触须舞动：一口吞下一名修士；甩身撞得另一名修士喷血，该修士弃肉身、元神钻入泥土逃命。
3. 姚云海瞳孔一缩、汗毛倒竖，果断后退掐诀欲施神通——**王林恰在此刻自其身后泥土中钻出**，趁其全部精力都在前方望月的刹那，**双指成剑点在后心**。
4. 姚云海弃肉身、元神自天灵飞出欲遁；王林早有提防，右手弥漫元力一把抓去。
5. 姚云海欲反抗，**昆极鞭幻化而出一抽**，其惨哼中被王林擒住。
6. 王林一脚踢在姚云海肉身上，磅礴元力灌入，**肉身砰然崩溃化作大片血肉**，元力波动略作阻挡冲来的望月；王林借力退后，一闪消失无影。

## 六、要点归纳

- **战略层**：王林把追兵变成「替他消耗望月怒火的耗材」，一石二鸟——既报追杀之仇，又为夺取大鼎创造窗口。
- **伏笔**：望月体内的贪狼大鼎（疑为古神涂司弃器）；望月即将苏醒的浩劫。
- **战果**：姚云海肉身被毁、元神被擒（本片段未明写其最终生死，仅记「被抓住」）。
- 章末作者语：第三更，9000字爆发，求月票。
