# 第600章 升仙果

## 一、开场：黑塔铠甲的十年之约

- 地点：天妖郡内远古战场，黑塔（宝塔）内顶层。
- 铠甲中两道幽光亮起，自述判断：**「问鼎刚成，体内元气尚未完全融合，需要四十九天的时间进行最后的稳固，这个时间，便是我等了十年才等到」**。
- 幽光一闪，塔外天空闷雷阵阵，一个**巨大的黑色漩涡**瞬间成形，转动中似可吸尽世间之物，远古战场内无数魂魄为之颤抖。
- 一股霸道神识自塔内横扫覆盖整个远古战场；战场大地数处泥土松动，一根根黑色骨头自地底飞出，于半空迅速融合成**一只黑色枯骨手臂**，悬停于漩涡之下。

## 二、护甲加持与出手的限制

- 铠甲自陈：「我积攒的力量不多，不能轻易浪费，而且此人此刻所在之地，也是我不愿去之处之一。」
- 于是铠甲整体上**脱落一截手臂护甲**（此后其铠甲少了一截护腕），散发魔焰飞出，扣在枯骨手臂上，与之紧贴；枯骨随即截然不同，磅礴魔力疯狂凝聚。
- 命令：「去吧，把元气带来。」手臂冲入漩涡消失。
- 关键设定自述：**「只有问鼎修士，体内才会有元气存在，可惜我受伤太重，无法把远距离已经与元神融为一体的修士元气抽出，只能选择在其突破之际出手吸了元气。」**

## 三、第一次袭击：洞府脱身与传送偏移

- 王林盘膝洞府十年，起身时体内啪啪作响，久之方复正常——**刚刚问鼎**。
- 察觉仙府上空无声无息出现黑色漩涡；他在此洞府多年从未见过，且偏在他刚问鼎之际出现。
- 王林生性谨慎，立刻直奔洞府之门；他身子一动，漩涡转速加快、体积扩大。
- 王林一拍储物袋取出**洞府令牌**，掐诀化作虚无欲走；漩涡中伸出**套着铠甲的漆黑手骨**朝其狠狠一抓，王林身影一晃后仍消失原地。手骨略一停顿缩回，漩涡消失。
- 结果：**传送受干扰出现问题**，王林落于**火妖郡**一片连绵无数里的巨大平原，神识一扫此地一片陌生，面色阴沉。

## 四、第二次袭击：寂灭指试探与天魔风夺神

- 天空黑点疯狂旋转，几乎刹那形成巨大漩涡；**无声无息，神识都无法提前察觉，好似天下各处无处不在**。
- 王林这次不逃，要看清手臂的神通。带护腕的枯骨手臂探出，向其虚空一抓——风未起、云未动，毫无神通变化，简单如凡人挥臂。
- 王林右手抬起，**第一次以问鼎期实力施展寂灭指**：黑芒相当于此前十倍不止，其中有圈圈环形波纹划过，黑芒如奔雷落于枯骨。
- 护腕散出近乎化作实质的**魔气**挡住指风；但寂灭指内蕴含的**寂灭之气**无法被阻挡，魔气与之碰撞瞬间迅速消散，如被生生吸收。（作者点明：若在问鼎之前，寂灭指或已被这魔气冲散。）
- 随即一股**无形之力**如微风吹来，王林刚形成的**问鼎元神**竟欲随风飘离体外，心神升不起半点反抗，右手缓缓放下，身躯僵硬、知觉迅速流逝，困乏之感悠然而起。
- 王林心中无慌只有杀机——「他王林，连天都敢逆，连天都敢杀」；**杀心与杀意碰撞生出浓浓杀气**，一声低吼、双目透出滔天杀戮，将已脱离半个身子的元神生生逼回体内。
- 王林冷冷丢下一句「不管你是谁，不要来惹我」，身子后踏，**无数个挪移神通同时施展**，消失原地。
- 王林的判断：手臂不可怕，可怕的是其上的**护腕**；妖灵之地奇异人士众多，自己刚问鼎、元神尚需时日彻底结合，不愿此刻多惹是非。

## 五、黑塔的评语与设定交代

- 塔内传出轻咦：「不愧是**逆修者**，居然在我**天魔风**下，以杀心硬抗。但，你越是这样，我对你的元气，便兴趣更大。」
- 补充设定：**「在这妖灵之地，那些修炼古妖术之人，无法形成元气，唯有你们这些修士，才会在问鼎一刻，有元气出现；无数年来，几乎所有在这妖灵之地达到问鼎期的修士，在其突破的一刻，他们的元气都被我吞噬——你，也不会例外。」**

## 六、荒原禁制与升仙果田

- 王林挪移现身于一片荒凉之处：不见山水，枯草萎木，地面干裂。远处发现**大量禁制**。
- 禁制特征：并不巧妙，但**胜在量多，不下数千个**，且**一个个连锁反应，触发一个等于触发全部**；等闲之人乃至**妖将**都难以进入，即便进入也需耗费大量时间强行破解。
- 王林以其修为与对禁制的掌握，视之不入眼，本欲离开——**黑色漩涡第三次出现**。王林「阴魂不散」一声冷哼，眼中杀机涌现，身子下沉直接踏入禁制之中（以禁制为避身之所）。
- 王林此生破解禁制无数，所破多是**洞府内仙禁级别**之物；只略看几眼、目中无穷推演一闪，便在**未触发**的情况下穿过禁制。
- 禁制作用有二：阻止外人进入 + **以幻术隐藏内景**。穿过后所见与外界大不相同：仍是平原，却被人为分割成一片片**种植之地**，散发**诡异幽香**。
- 更奇异的是所种之物**全部只有一种**——**升仙果**。王林表情有些古怪。

## 七、章末悬念

- 四周禁制忽然崩溃，**黑色枯骨强行穿透无数禁制伸了进来**，追至升仙果田。

## 关键点归纳

1. 王林战力节点：问鼎期首战、寂灭指首次以问鼎修为施展（威力十倍以上）。
2. 新反派线索：远古战场黑塔铠甲存在——重伤、力量有限、有不愿去之地、专食问鼎修士元气、掌握「天魔风」，其护腕（手臂护甲）为魔气来源。
3. 王林凭『逆天杀心』抗住摄魂类神通，为其「逆修者」身份再添一笔。
4. 地理线：洞府（天妖郡方向）→ 传送失准 → 火妖郡巨大平原 → 荒凉禁制之地（升仙果园）。
