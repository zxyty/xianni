# 第十卷 叱咤界内 第1505章 炼！（第一更）

## 一、开局：七彩界石碑反制
- 幽冥魂之上幻化出巨大石碑，其上赤红道经铭文透出疯狂意念。
- 四周**铭志者**如发狂般齐声嘶吼、被操控急速旋转，化作一道蕴含**毁灭之力**的漩涡，向八方冲击，王林被冲退三步。
- 石碑赤红道经铭文尽数化作符文，直奔王林。王林曾去过一处七彩界，深知道经可怕；铭文临身时，其耳边响起幽幽低语，诉说道经内容——**「铭志，囚封天之道」**。
- 漩涡把疯狂意念随七彩之芒扩散，此刹那**幽冥魂上剩余四星点再熄两个**。

## 二、幽冥兽遁走：虚化芥子
- 幽冥魂大口融回幽冥兽本体。七彩界或许改了幽冥兽的性格，但本性难忘，加之魂身封印尚未全消，它对王林生出浓浓恐惧，急速后退。
- 幽冥兽展开另一神通**「虚化芥子」**：身形肉眼可见地模糊，仅退百丈便彻底消失于星空；旋转的铭志者与冲向王林的道经符文亦随之一同消失。
- 王林双眼血红仰天怒吼——**灵动、周瑾、望月、古息叶全在幽冥兽体内**，一旦逃走代价太大。
- 本次猎幽冥因幽冥兽吞噬一处七彩界而剧烈逆转；王林算尽众多，却没料到一处七彩界会出现在**雾气星域**并被其吞入体内。

## 三、炼化八千万丈星空
### 逐级扩张雷图
1. 右目**雷图**幻化，**九道伴随之雷**环绕外围，笼罩方圆千丈成雷域。
2. 爆发体内**雷霆本源** → 千丈暴涨至千丈、万丈、十万丈、百万丈。
3. 右手点眉心，**古神之力**云涌 → 百万丈至一千万丈。
4. 眉心第一颗星内**天皇炉**幻化，与雷图融合 → 两千万、三千万、五千万，直至**八千万丈**，整片星域化作滔天雷池。

### 火之本源加持
- 左目瞳孔燃起**九色火焰**，身后幻化**朱雀虚影**并发朱雀之音，标志火之本源尽出。
- 朱雀与九色火焰风暴融合，扑向八千万丈星空：**火中有雷、雷中有火**，加上天皇炉炼化气息，展开疯狂祭炼。

### 炼化的形态
- 该范围与外界崩溃分割，独立出来；为立体范围：**上至星之苍穹，下至空之黄泉**。
- 炼没的部分露出下方**细密的封界大阵之网**；被焚烧炼化处则成为**永恒存在于罗天的崩溃之洞**。

## 四、逼出：焚灭古伞与九滴毒液
- 王林借留在幽冥兽魂身上的封印感知其位置，但封印正急速消散，明亮星点由两个减至一个，时间紧迫。
- 王林反倒平静，双手打出**数十万禁制**（左手残影、几息之内无尽禁制）加速炼化，范围由八千万缩至七千万丈。
- 祭出**焚灭古伞（焚界古伞）**，喝「散开，灭界」，古伞仅**打开一成**，滔天火焰宣泄，炼化速度加快数百倍：七千万 → 六千万 → 四千万 → 三千万 → 一千万 → **六百万丈**。
- 判定幽冥兽就在六百万丈内，再祭天皇炉，隔空一抓取出**九滴毒液**融入雷火（此举不损耗珍贵毒液，只为争取时间），黑色毒雾腥气弥漫。
- 范围缩至**三百万丈**时，一处将被毒雾淹没之地传出焦急咆哮，幽冥兽庞大身躯轰然现身。
- 王林一步临近，未等其张口，**右手迅猛拍在其头部仅剩一丝的封印之上**，幽冥兽口中只余闷闷咆哮。

## 五、要点与伏笔
- 王林的目标不止是逼出：**「吞了七彩界，也要成为我王林本命之兽」**。
- 猎幽冥的三位关键人物（望月、灵动、周瑾）不可复制，王林言明「再没有第二个」，故必须速战。
- 遗留：幽冥兽头部封印仅剩一丝，此掌后的结果本章未交代；被炼化区域留下的崩溃之洞与封界大阵之网亦为后续伏笔。
