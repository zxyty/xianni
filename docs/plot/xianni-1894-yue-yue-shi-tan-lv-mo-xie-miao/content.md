# 第1894章 一场岁月年华（第一更）

## 一、开局：被留在绿色空间

- 绿袍老者与其两名绿魔守护使者离去后，王林肉身依旧盘膝坐在绿魔蝎庙内的绿色空间中，一动不动。
- 空间内无数绿色光线闪烁，每一道光线内都有一个绿蝎子的虚影，密密麻麻弥漫全场。
- 王林元神受**天逆**保护，静待他隐隐感受到的「造化」。

## 二、王林的判断与策略

- 绿袍老者极为多疑，绝不会轻信王林「丧失心神」的表象，之后必有数次试探，完全确定后才会给予莫大造化。
- 王林猜不出试探形式，遂定下方针：**以不变应万变**。任凭绿蝎覆盖全身，甚至有蝎子顺口鼻双耳钻入体内，也毫无变化。
- 支撑其信念的分析：
  - 绿袍老者虽为凡人身躯，却能让**道魔宗宗主**都很客气，轻举妄动必有大危机。
  - 绿魔蝎庙内藏有太多未知隐秘。
  - 老者是凡人，寿命有限——**这一局比的是彼此的耐心**。

## 三、时间线：肉身的崩坏

| 时点 | 情形 |
| --- | --- |
| 3 个月 | 王林平静静坐，绿蝎爬满全身，毫无生机与挪动 |
| 1 年 | 老者始终未现身，四周死寂；蝎子越来越多，王林形同「被蝎子覆盖的人形土包」 |
| 2 年 | 全身十万八千汗毛孔内出现卵状绿色光点 |
| 4 年 | 光点破碎，吸收王林血肉化作幼生蝎子；蝎数暴增一倍，地面厚厚一层；万年不腐的肉身开始生皱纹、枯萎 |
| 5 年 | 挣扎持续一年后消散，王林果断斩掉纷杂念头，带着疯狂与笃定继续等 |
| 6–8 年 | 身体大范围枯萎，心神不动 |
| 9–10 年 | 身体再无养分，干瘦如枯骨，风吹欲溃；仍在等 |
| 20 年 | 骨头开始脆弱；若非**道古身躯**，肉身数年前就已彻底废掉 |
| 40 年 | 王林罕见地一坐四十年，放弃肉身、元神如归寂；身体即便是道古身躯也现完全死亡迹象 |
| 80 年 | 王林仍未动；绿袍老者生出迟疑 |

## 四、王林的抉择困境（第4–5年）

- 若继续等：判断若错，肉身彻底枯萎、道陨于此。
- 若元神散开操控身体离去：判断若错，则错过一场极大的造化与机缘。
- 结果：第五年果断押注，「**我绝不会输**」这一句支撑他近二十年。

## 五、绿袍老者的视角（关键揭示）

- 位置：巨大蝎子建筑的**蝎子头内部洞府**。
- 手段：面前一面**绿色镜子**，折射王林所在绿色空间的一切；四十年间除正常生活外几乎都在看镜子。
- 动机自述：「时间，是最好的方式，可以看出真相……为了绿魔大人降临的安全，必须如此。我倒要看看，此人到底是真的丧失了心神，还是装的。」
- 寿元：其一族每代祭祀最多活三千年；他已 **2800 余岁**，距死已近。虽有秘术延寿，仍所剩无多。
- 他在这蝎子建筑内一住两千多年，数着岁月已成本能。

## 六、本章主旨与转折点

- 这是一场「**斗岁月**」的残酷斗法：无声无息、不见烟火，却凶险远超寻常修士厮杀。老者一族准备了无数万年输不起，王林同样输不起。
- 第八十年，攻守易位：**轮到绿袍老者面临王林当年的选择——等，还是不等**。
- 悬念：王林不知外界天牛洲与绿魔洲的交战是否仍在继续或已有结果。
