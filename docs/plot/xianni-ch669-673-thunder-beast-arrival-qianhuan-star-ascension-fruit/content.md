# 第709-710章 修道第四步·雷兽降临千幻星

## 一、修为节点：问鼎后期

- 经近一年吸收仙力，王林修为达到**问鼎后期**，九百多年修道路的阶段性巅峰。
- 文中明确对标：他已「成为了当年朱雀子一样的存在」。若朱雀子未死，见到这个曾被他无视、隐约当作棋子的小人物成长至此，不知作何感想。
- 问鼎后期修士在小型修真星上即是至尊，除非对方掌握逆天法宝，否则斗法必败。
- 再踏出一步，修为与意境达到圆满，便可向**修道第二步**进军。

## 二、修道三步（乃至第四步）的体系认知

| 阶段 | 王林的认知 |
| --- | --- |
| 第一步 | 已近圆满；回望九百年「危机处处，稍有不慎便会形神俱灭」；闻道者朝生夕死那一劫若非周佚前辈相救早已身死 |
| 第二步 | 对应**阴阳虚实境界**（阴虚境界）。达到者不多，难度远非第一步可想象；他与该境界修士为数不多的几次交战让他深知其强大；其中亦必有问鼎生死的关卡 |
| 第三步 | 连**天运子**等人也未达到，尚在苦苦追寻。「比之古神，又是如何？」他知此步虚无缥缈，恐一生至寿元断绝亦无法摸索 |
| 第四步 | 「修道三步，犹如爬山，一步比一步艰难……就是不知，是否还有第四步？」——**此界无人可以回答** |

> 道心宣言：「人之一生，顺为凡，逆则仙，只要道心在，一切险阻，都可闯上一闯。」（点题「逆天」母题）

## 三、雷兽与「雷仙殿使者」身份

- 雷兽已**解开第三道封印**，实力加上传承神通不弱于一个阴虚境界修士；头生银角却有金光散出，全身电光闪烁。
- 王林盘膝坐于其背，速度虽比星罗盘略慢但仍极快；半个月自千幻星外抵达。
- 降临姿态与**当年雷道子奔向冉云星**如出一辙，「恐怕即便同样是雷仙殿使者，遇到王林，也会一怔」。
- 临近千幻星即引动无数雷云，雷兽一声咆哮引下连绵雷霆，全星大部分修士灵力颤动、被雷威所震。王林不愿张扬，一拍兽头令其止声下落。

## 四、行动线：索取升仙果

### 幻家（千幻星）
- 幻家上下以**幻封神**为首飞起相迎，见到雷光中的王林皆惊呼——「幻家之人，对于王林，是永远也不会忘记。」
- 幻封神恭敬参见「雷仙殿使者」，并为此前不知其身份致歉；王林不辩解，直接索要大量升仙果。
- 幻封神苦涩后果断：「罢了，我幻家放弃百年后进入雷之仙界的机会，把搜集到的升仙果，全部送给使者。」
- **关键情报**：王林由此察觉升仙果或与**雷之仙界**相关；雷之仙界百年后开启，此事他当年从孙析口中听过。
- 幻家升仙果数量庞大，但仍不足所需 → 决定「借这雷仙殿的名头，在这罗天北域，四下索要一番」。

### 千家（千幻星第一家族）
- 千家城规模是幻家数倍；家族中几位踏入第二步的修士很久前已闭关，事务由**千葵子**独断。
- 千葵子亲率族人恭迎，谦称不敢当「前辈」，要求平辈论交。
- 其内心震撼：王林不到百年从**问鼎初期巅峰**升至**问鼎后期**，速度惊人，认定唯有雷仙殿神通可为；并从雷兽「目光扫来如遇同辈修士」的压迫感，判定当年幻家老祖所说荒谬，此人在雷仙殿另有身份的可能性有七成。
- 王林开门见山：讨要升仙果。

## 五、罗天星域的权力结构（重要设定）

- **雷仙殿**如庞然大物笼罩整个罗天星域，其操控方式「较为原始」，与**联盟星域**截然不同。
- 使者数量**永久不变，始终保持九十九人**。
- 除延续至上古的修真家族外，其余家族必须**依附**一位雷仙殿使者，否则等于失去雷仙殿庇护，后果极为严重。
- 依附具排他与终身性：一旦依附，在该使者死去之前，家族**绝不能另投**其它使者。
- 千家原依附的使者已于**数千年前在雷之仙界战死**，故须重新择主。
- 千葵子的算盘：以千家实力足可依附「踏入第二步」的使者，但那些人高傲且需缴纳太多物品；王林修为不足却未来无限，此时依附是押宝——「一旦押对了……」（章末未决）

## 六、伏线与待办

1. **云霞星·望月**：到了再探时机。望月是古神体内的**寄生体**，或残存**古神之气**。
2. **本尊状态**：本尊吸收了一个小星球的灵气，实力直追四星，唯缺**成年古神之气**；王林在琢磨罗天星域是否存在此物。
3. **星痕貂**：当年天运星上修真联盟使者所带，对古神之气极为敏感——是寻找古神之气的关键工具，可留意寻求。
4. **冉云星**：「记忆封沉之处」，王林不想再去——刻意回避的情感线。
5. **升仙果 × 雷之仙界**：百年后开启，升仙果疑为入场凭据类资源，王林正在大规模囤积。
6. **千家依附**：千葵子的抉择悬而未决。

## 七、归属说明

- 本片段中被众人称为「雷仙殿使者」者即**王林**本人，属泛指性的身份误认/默认，王林「自然不会辩解」，未冒用某具体已命名人物的姓名，故不作 impersonates 处理（仅与雷道子形象高度相似）。
- 雷道子已于第665章死亡，本章仅为对比性提及/回忆。

# 第710-711章「排泄」 千家升仙果与云霞星望月

## 一、罗天星域规则补述
- 九十九个雷仙使者，每一个都会有大量修真家族依附，发展出自己的势力——这是罗天星域内较为独特的行事风格。
- 雷道子的势力不在罗天北域，他是奉命前来调查，加之自信十足而独自前来，才有败落下场。叙述明言：若在其势力范围内交战，**王林必死**。

## 二、千家：验令牌与半数升仙果
- 千葵子考虑良久（其犹豫与升仙果无关，实因当年**幻家老祖的话**始终回荡耳边），最终提出条件：愿分出千家一半升仙果，但要求**查验雷仙令牌**。
- 王林不废话，一拍储物袋取出**雷道子的玉简**，一晃之下雷光闪烁、雷威弥漫。千葵子当年见过雷仙殿使者令牌，凝神感受后立刻恭敬，再无怀疑。
- 千葵子的承诺：**待王林修为达到「阴阳虚实之境」时，千家将成为其依附修真家族**；在此之前尽可能满足王林一切要求。但他仍选择暂时观望，未真正依附（未交出家族血脉传承）。
- 王林内心一动：使者竟可发展自己的势力，觉得雷仙殿「有些诡异」；表面平淡，只说「此事日后再谈，先把升仙果拿来」。
- 千家取来一储物袋升仙果，数量与幻家相仿。王林抱拳道谢，拍雷兽头化雷光离去。千葵子望其背影，隐隐后悔未果断依附。
- **进度**：此时所得升仙果只达到王林所想的**五分之一**。
- **旁笔**：千幻星近百年格局变化巨大，**许家神秘迁移而走**。

## 三、罗天北域横扫（数月—半年）
- 出千幻星后数月，王林借雷仙殿使者名头在罗天北域横扫，无论大小修真星皆有其身影。
- 「雷仙殿使者索要升仙果」之说谣传四起，被王林以使者名义压制，最终只在家族之间私下涌动。
- 许多家族一生未见过使者，对王林隆重欢迎；后期王林一降临便有家族主动奉上升仙果，小型家族甚至恳求依附。
- 王林**拒绝接受依附**：干系太大，这些家族与他无仇隙，一旦日后身份败露恐被牵连。
- 通过蛛丝马迹，王林渐渐了解到**升仙果在雷之仙界的用途**，以及**雷仙殿使者与依附家族的因果**。
- 数量已远超所需，王林仍持续搜集——此物对日后雷之仙界有大用。

## 四、赴云霞星
- 半年后，王林带雷兽化雷光直奔**云霞星**。
- 目的：**若成功，天逆的金属性便可圆满，届时便可认主**；并期待「天逆珠子圆满后会不会有什么神通」。
- 途中取出**尊魂幡**，抽出当年**妖灵之地那擅长逃遁的老者**魂魄，将其逃遁神通一一记在心里（此人神通当年让王林印象深刻，一直无暇研究）。
- 大半个月后抵达，云霞星特有浓雾**比第一次来时更浓**，闪电在雾上游走，雾内传出奇异闷响咆哮。

## 五、冲雾与七星剑阵之失
- 浓雾阻神识。雷兽散出奔雷瓦解雾气，王林放出**七星剑阵**在前旋转开道。
- 王林刻意放慢速度、阻止雷兽施展更剧烈雷电——稳定推进。
- 距冲出迷雾不足百丈时危机感骤生，雷兽先一步斜冲闪避；一条细长触手自原位穿过，回缩时**卷走七星剑阵**，王林神识竟无法操控。
- 王林认出：此触手与**望月第三种形态**惊人相似。

### 望月三形态（设定要点）
| 形态 | 状态 | 特征 |
|---|---|---|
| 第一种 | 游离 | 无进攻性，即王林首次来此时半空飘荡而过的那只 |
| 第二种 | 沉睡 | 全身须毛收缩，化作各种奇异形状；化作云霞星的庞大望月即处此态 |
| 第三种 | 攻击 | 全身须发无限延长，可达与身体同长；遇之须立刻逃离 |

## 六、地表异变与推断
- 冲出迷雾后：地面原本摇曳的植物消失，取而代之是一条条**千丈长短、暗红色**的触手，散发奇异之力。
- 王林判断：只有千丈长短，说明望月**正向第三形态过渡但未完全苏醒**；而若无外界刺激不会如此——「莫非近百年中有人来了不成？」但即便有人来，也不大可能刺激到这种程度，**此事有些诡异**。
- 王林劝雷兽逆变为**射神车**回储物袋以减少危机，雷兽晃头、扫了眼触手露出不屑，拒绝。

## 七、红雾醉触手
- 王林在触手间谨慎穿行，一根触手闪电抽来；他因始终观察**触手根部颜色微变**，提前几息预判，瞬移留残影躲过。
- 关键判断：「想使望月处于**升仙果的状态**，必须作用在其身上的**兴奋点**，但眼下触手太麻烦。」
- 手法：放出大量升仙果 → 虚空一抓轻吐「**炼**」→ 果碎成红色汁液融为一片 → 掐诀喷**元神之气**化火焰燃烧 → 凝出**红色雾气** → 抓雾下扑、右手下拍，红雾扩散**百丈**。
- 效果：红雾内蕴大量升仙果奇异之力，雾态更易被触手吸收；百丈内**几十根粗大触手**摇曳变缓、颜色由暗红转**鲜红**，如凡人醉酒，对王林视若无睹。王林安然落地。

## 八、未决线索
- 七星剑阵被触手卷走，尚未取回。
- 是谁/什么刺激望月向第三形态过渡？王林认为诡异，未有答案。
- 千家「阴阳虚实之境后依附」之约待兑现；许家迁移去向不明。
- 天逆金属性能否圆满、圆满后是否生神通，本章未定。

# 第711–712章 升仙果麻醉望月·望月之骨与贪狼的山石

## 一、以升仙果麻醉望月触手（承前）

- **情报来源**：古神涂司（原文写作“涂思”）的记忆传承片段记载——望月的兴奋点是其**触手根部**，稍加刺激即可影响望月全身。
- **手法**：王林自储物袋取出升仙果，数十枚融合为一滴红色液体，**留下自身封印/烙印**后融入每条触手根部；操作时神识散开、极为小心。
- **时限**：百丈内红雾极速消散，时间不多；最后一条触手融入后立刻飞出。
- **望月反应**：红雾散尽后触手复归暗红，触手内出现一节节鼓包向下蔓延、顺地面不知去向——王林认出这是望月在**排出升仙果毒素**，“如同凡人出恭”。

## 二、雷兽被缚与妥协

- 天空中雷兽不耐，眼露不屑，雷光缠身直冲地面，轰隆之声传遍云霞星。
- 王林急喝“孽畜，快回来”未及，大地如活物般所有触手瞬间延长扑向雷兽。
- 雷兽初时以电光反击，但触手随即散出刺目红芒、速度更快，铺天盖地将其团团包围；雷兽挣扎撕咬、施展神通，**连一根触手都未能弄断**。
- 关键设定：**望月在第三种状态下对声音极为敏感**——雷兽越咆哮，触手缠得越紧。王林传音“别再吼了”。
- 解围：王林取大量升仙果挥手碎裂成汁，经元神精气一燃化作红雾，踏至困兽处向下一击，红雾落下，触手松缓转为鲜红。
- 结果：雷兽趁隙电光浓郁、身形缩小，化作**射神车**冲出；王林虚空一抓收入储物袋。雷兽原本执着不愿逆变回储物袋，此次因**恐惧而妥协**。

## 三、大规模布置完成

- 此后王林独行，流程固定：先以红雾松缓触手 → 落地 → 以升仙果汁液加自身烙印融入触手根部，周而复始。
- 数日后，**云霞星上十之七八的触手**已融入升仙果汁液，“只需我心念一动，其上的烙印就会崩溃”。
- 升仙果虽储量庞大（超出原先所需）仍告耗尽。王林权衡后**放弃外出续找升仙果**：此地过于诡异，恐再来时又生变故；一旦望月真正苏醒，麻醉之计将全部落空。

## 四、地底探查：谁伤了望月

- 王林钻入地底，泥土中粘稠液体更多，以仙力推开。
- 发现四周泥土粘液中**凝固着细微的仙力波动**，而上次来时粘液浑浊、毫无仙力。
- 推断：近百年内**有人进入望月内部并施展大神通法术**，残留仙力，并促使望月由第二状态向第三状态过渡。

## 五、望月之骨与那道裂缝

- 目标：地底深处庞大的**金炎矿脉**，即**望月之骨**，炎光闪烁照亮深处。
- 王林右手按上正欲吸收，旋即停手起疑：能逼望月过渡状态者修为惊人，若此人未死而藏匿或被困于望月体内，自己吸骨时开启升仙果烙印很可能把此人引出，徒增变数。
- 决定先沿望月之骨搜索，确认此地是否另有修士。
- 自评凶险：“在望月体内取望月之骨，此行，却是我这一生凶险中，可以稳占前三。”
- 生涯总结（回顾）：**古神之地靠机智，雨之仙界靠谨慎，妖灵之地靠果断**。
- 发现：望月之骨上有一处**巨大裂缝**，几乎将骨砍断，表面覆一层干枯粘液（年代久远）；当年此骨绝无此裂缝。王林判断正是这种伤害带来的痛楚令望月发怒、转入第三形态，且**下手之人显然不识望月**，否则绝不敢如此。

## 六、贪狼的山石法宝

- 王林离开数步后觉不对，返回；察觉此处仙力比别处浓郁且源自裂缝，遂以仙力如仙风吹融干枯粘液，露出裂缝深处**卡着的一块巨大山石**。
- 山石四周已与望月之骨（金炎矿脉）几乎**同化**，甚至有金火石长入其内。
- 辨认：这正是当初在**妖灵之地**时贪狼取出、被其**抽出山魂**攻击的法宝。王林冷笑：“贪狼”“他们，果然追来了”，并推测来者是全部、数人，还是仅贪狼一人。
- 附带信息：**七星剑阵已被望月触手吸走**，不知去向；而山石不能放过——“以贪狼的身份与习姓（习性），他所拥有的法宝，绝非等闲之物”。
- 取石手法：两指成剑试硬度，蕴含仙力一指无痕；遂调动**一丝凌天候的剑气**，放弃取完整山石、**减少三尺**，绕开同化部分自边缘向下切割，一侧顺利脱离且未刺激望月。转至另一侧（同化更严重）时顺同化脉络缓移。

## 七、贪狼的处境（同期插叙）

- 地点：云霞星内部一处宽大洞穴——若王林在此，会认出**这是望月的排泄吸收之地**。

# 第713章 抽望月之骨（第七卷 名震罗天）

## 一、脱身：第三形态小望月的突袭

- 王林抓住山石飞出，第一时间将山石收入储物袋，头也不回冲入泥土，施展学自**妖灵之地老者**的逃遁神通之一。
- 神识一扫方知追袭者：一头**小望月**，大半身体埋于泥土，露出前端约十丈，**同样处于第三形态**。
- 该望月被**定身术**笼罩略一顿，给了王林逃遁的最佳时机；望月随后红目四扫、咆哮，缩回泥土消失。
- 王林最忌惮的一点：望月出现**极为诡异，事先毫无察觉**——这种情况他已很久未遇。
- 疑问抛出：「这里到底有多少头望月」「该死的贪狼到底做了什么」——他判断仅在望月之骨上插一座山石，断不会造成如此变化。

## 二、月华：古神涂司记忆传承中的禁忌

源自**古神涂司**的记忆传承：

| 要点 | 内容 |
|---|---|
| 名称 | 月华，存于望月体内 |
| 特性 | 拥有剧毒，除**古神之血**外万物不可破除 |
| 存在价值 | 望月死后发作，全身充满剧毒，形成膨胀球体**自爆** |
| 威力 | 使四周星域瞬间除古神外生灵灭绝；望月体型越大威力越强 |
| 推论 | 故世间找不到死去的望月遗骸 |
| 触发 | 月华是望月最在意之物，受威胁即令望月暴怒，磨灭一切危机 |
| 取出 | 根本不可能取出，一旦拿出立即提前自爆 |

- 王林推算：如此庞大的望月若月华自爆，范围恐怕**包裹大半个罗天北域**，令其头皮发麻。
- 常态：望月若无人招惹，再过无数万年也不死，只会处于**第二形态**直至自然灭亡。
- 王林态度：「此事若是那贪狼找死，与我无关」——继续搜寻。

## 三、贪狼的下落与百年囚困

王林推知：被望月所吞之物会凝聚在其**排泄吸收之处**（望月体内自有循环，排泄处不通外界，再次吸收化成养分回归体内），遂前往。

数日后抵达望月之骨最深处、临近排泄吸收之地，泥土带腥臭。王林**只在边缘观察，未深入**。此时传来微弱神念求救——正是**贪狼**。

**贪狼的经历（回忆）**：
1. 感应到云霞星有重宝，感应强度只有当年取那**神秘大鼎**时才有，心动潜入地底。
2. 途中见**金炎矿脉**，贪心之下以山石生生刺入，欲整截撬起分次带走 → 引起望月剧痛**刹那苏醒**；靠拿出大鼎见机快才免被抹杀。
3. 躲藏多年待望月平息后现身，不敢再打矿脉主意，直奔重宝。
4. 凭大半生寻宝经验找到望月体内存放**月华**之处，看出其中蕴含毁天灭地之力（在他看来**凌天候**遇到也一样灰飞烟灭），贪念爆发。
5. 触碰月华刹那，整个云霞星剧烈震动如同苏醒，**望月开始向第三形态过渡**；贪狼只来得及分出**一股神识融入月华内**，本体即被身前出现的森森大口一口吞下，出现在排泄之地。
6. 数次借大鼎变换方位逃离，每次都被吞回丢入此地；最后一次**大鼎被触手缠绕、神通如被吸收而失去作用**。
7. 近百年间，其血肉精华乃至仙力为抵抗此地吸力已流散很多，全身干瘦；若非倚靠大鼎早已化成污痕消散。
8. 他早已看出此处是庞大凶兽的排泄之地，却想不通为何凶兽每次不杀他，只把他丢回来。

**王林的抉择**：许以「大半生收集的全部法宝」，王林**自始至终一言未发，转身即走**。

判断依据：
- 以自身修为，进入排泄吸收之地容易，**出来根本不可能**。
- 贪狼被困至今无人来救 → 推算出**联盟星域内恐怕只来了贪狼一人**。
- 行事风格：明确此点后再作言语纠缠不合其风格；对法宝无半点贪念，「该取之时自然会取」，此刻枉顾贪婪便白费九百多年修行（对照：当年果断放弃云霞星之行、待搜集到升仙果后再来）。

## 四、引爆升仙果烙印 → 黄泉之力抽骨

- 王林返回此前被山石卡住之处，谨慎观察确认无望月寻来后盘膝坐下。
- **仙卫傀儡**自其身后幻化而出，警戒四周（经望月之险后不敢大意）。
- 双手掐诀，**崩溃**了心神相连、融入无数触手根部升仙果汁液上的**烙印**。
  - 自星空俯瞰：整个云霞星延伸而出的无数触手绝大部分蓦然一颤，根部鲜红光芒闪烁，汁液瞬间释放。
  - 机理：单根触手释放对望月如蚊叮；有先后吸收亦可自我清毒；但**绝大部分触手同时吸收**，则形成风暴般的强大。
  - 「百流成河，千河成川，万川成海」——磅礴之力顺触手传入望月体内，弥漫整个云霞星。
- 结果：大地剧震，一股**极为兴奋**的气息浓郁涌现，所有触手失去攻击性、如醉汉般缓缓摇动。
  - 王林能清晰察觉这股自望月之魂散出的兴奋气息，得益于其修为，以及当年**散魔操控其身子抽出千幻星之魂**的经历。
- **出手**：迅速伸开双臂，虚空按向两边断裂的望月之骨，仿佛以己身将其连接。
  - 「**道化黄泉第三式，黄泉之力**」——黄泉幻化而出，根源正是王林所在；自双臂分开如两条黄龙吞噬，顺望月之骨疯狂延伸，如刮骨而过、如刀锋般紧贴覆盖。
  - 低喝「**抽骨**」，磅礴吸力自黄泉内疯狂涌现。
- **黄泉第三式来历**：感悟于当年妖灵之地的**潮汐深渊**之内，取的是天地无形、**两个星域之间交错形成之力**；威力随王林**道念**攀升而永无尽头。
- **当前威势**：以**问鼎后期**修为施展，刹那间云霞星轰然剧震，连星外浓雾都疯狂向外散开；一声声充满沧桑味道的闷吼自大地颤抖中缓缓透出，传递极远。
