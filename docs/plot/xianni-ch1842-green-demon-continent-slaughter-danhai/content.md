# 第1842章 绿魔之修！（第三更）

## 一、丹海屠杀现场
- 大海深处一座座洞府被成群绿衣修士轰开，展开无情杀戮；有逃遁者，领头者即派数人追击，不死不休。
- 整个丹海已被封印，加之绿衣修士数量极多，被围者极难逃走。
- 血腥气息引来海中无数凶兽云涌而至。屠杀实力完全不对等，绿衣修士严格执行命令：**剿灭丹海内一切天牛洲之修**。

## 二、绿魔洲一侧的指挥中枢
- 靠近绿魔洲方向的海面上，三杆大旗插入海中，云雷卷动；旗下聚数千修士，沉默冷视前方。
- 正中为三名**白衣**修士（其余皆绿衣），两男一女，年约三旬：
  - **面白如玉的青年**：持折扇，自陈欲让人「看一看道魔宗的魔道」；负责统筹与助阵。
  - **钱姓青年**：相貌平凡，双眼时露毒辣之芒，寡言。
  - **赵姓女子**：相貌秀美，掌控丹海轮盘，实为调度核心。

### 丹海轮盘
- 巴掌大小，右掌托之散发幽光，浮现整个丹海轮廓地图。
- 数千**绿色光点**（绿魔洲修士）弥漫全图缓缓移动；大量**白色光点**（天牛洲修士）如烛火随时可熄——说话间即有数百白点被绿点吞噬消失。
- 白点大小不一：
  - 三个远超其余、光芒刺目 → 丹海内天牛洲最强的三名散修，修为已达**空劫中期**，由老祖派**绿魔使者**前去击杀，「不足为虑」。
  - 另有不到十个略小但仍出众的白点 → **玄劫七八次**的九名修士，是三名白衣主事者的目标。

## 三、时间表与作战计划
- 屠杀已耗时**七天**；面白青年担心延误老祖之命，钱姓青年断言**最多再四天**可尽屠。
- 赵姓女子：丹海是绿魔洲进入天牛洲的**门户**，存在不少强者，短时间难免遗漏，但四天应足够。
- **万净化污液**：赵姓女子取出的一滴黑色液体，晶莹剔透、幽光诡异，散出浓郁精纯水本源气息；为**毒魔宗至宝**。她以此断言丹海中天牛洲修士再无生机。
- 面白青年强调不可大意：**此次三宗联合**，不能出意外，也不能让天牛洲察觉；**三位老祖已展开神通干扰天地变化**，让人难以推算端倪。
- 终极目标链：屠尽丹海内天牛洲修士 → **把丹海炼化、还原成那半粒仙丹** → 用半粒仙丹**炸开天牛洲的无形壁障**。

## 四、调兵遣将
- 赵姓女子依轮盘发令，例：「东北方，距此三十九万里，一组绿魔卫」「东南方，一百九十八万里，五组绿魔卫」，数十至上百修士应声融入水中消失。
- **绿魔卫无法缩地成寸**，但丹海禁制既可封印，又可让绿魔洲修士融入阵法中挪移。
- 九名玄劫目标已死四人，余五人：两人分散不足为虑，三人聚集（疑交好、擅合击）向天牛洲方向移动，沿途接近的绿点纷纷熄灭。赵姓女子请钱、面白二人同时出手轰杀；钱姓青年先行融入阵法，面白青年含笑跟随。

## 五、王林的隐匿修炼
- 轮盘地图上，靠近天牛洲的大片海域有一个**极寻常、一动不动的白点**——正是王林；绿点时而经过却毫无察觉。
- 王林盘膝坐于大海深处海草珊瑚之中，**身体已与海水融合**，不断凝聚海水入体、压缩水本源以滋养身体。水本源极难压出，除非把整片海水尽数凝成一滴——他仍决意尝试。
- 神识与海水融合，察觉整个丹海杀机四伏、惨叫凄厉。
- **第一天**：数十群绿衣修士自其上方呼啸而过，无人发现；丹海**下沉十丈**，海水似凭空消失，已引起注意但屠杀中多不深究。王林睁开干枯双目，眉头皱起，决意「那便再多一些」。
- **第二天**：丹海持续下沉，一天**下沉八十多丈**，暗礁礁石完全露出海面。绿衣修士再无法忽略，纷纷动容：「这么多海水去了什么地方」「莫非有人在施展莫大神通」。
- 赵姓女子亦皱眉不解「这丹海的海水，怎么在一天中少了这么多」，目光扫过包括王林白点在内的诸多白点——因其太过寻常而未起疑，遂将此事埋在心里，继续调兵遣将。

## 六、支线：逃亡三人
- 距王林很远的海底，三个身影疾驰逃命，其中两人重伤，剩余一人不肯舍弃、带二人同逃。
- 重伤者劝：「白虎，你独自离去吧，我与朱雀重伤，你带着我们只会将你拖累。」并叹「没想到我们走出了**七道宗的洞府界**，在这里本欲平静地修炼下去，可却被这死劫临身」。

## 七、要点提炼
- 丹海之战本质：绿魔洲三宗以屠杀清场为手段，行「炼化丹海→复原半粒仙丹→炸开天牛洲壁障」之谋。
- 王林吞海凝练水本源的动静（两日近百丈海面下降）已成全场最大异象，却因白点平凡而未被锁定——伏笔明显。
