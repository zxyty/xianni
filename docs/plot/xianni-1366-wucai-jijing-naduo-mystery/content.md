# 第1366章 五彩极境

## 一、五彩极境的烙印

- 画面消散，但**说话之人转身的相貌**清晰留在王林心神内，如同烙印。此人相貌王林陌生，确信从未见过。
- 此人**左目内有一团五彩之光**闪烁——以王林对极境的熟悉，一眼便认出：这是**极境**，且是**五彩极境**。
- 王林一生只见过一次五彩极境：很久很久之前，在**朱雀星**上，属于几乎消失在记忆深处的**五行星纳多**之物。
- 看到画面中男子左目五彩极境的瞬间，王林骤然产生说不清的感觉：**此物与纳多的五彩极境，很可能是同一存在**。

## 二、纳多其人（回忆线）

- 与纳多的结识，为王林**获知自身极境**打开了一扇大门，更让他第一次知晓：**极境并非只有一种**。
- 纳多身份：**当年追杀司徒南的几人之一**。
- 纳多曾在**朱雀星**上化作尸骸疗伤，**其储物袋被王林取走**。
- 王林在**赵国复仇之后**，被纳多追上。

## 三、王林的推断：神秘修士去了界内

王林双目闪烁，隐隐发现一个巨大秘闻，其推理链为：

1. 画面中男子身体外环绕的金线，**正是昆极鞭**。
2. 结合**与闪雷族大长老一战中对方的话语** + **纳多的五彩极境**。
3. 推论：**这群神秘的修士莫非并没有走，而是去往了界内**。
4. 界内不知发生了什么变故，导致该男子的**五彩极境最终落到纳多手中**，甚至其法宝**昆极鞭也丢在了朱雀星**。
5. 结论：**纳多定然知晓很多**内情。

王林沉默中深深呼出口气，许久后把这一切疑惑压下——「目前不是思寻之时」。

## 四、修为异变：分化的碎涅

- 王林体内**元神雷霆比往昔强大数倍**，贯穿全身；蓬勃的**雷之本源**仿若巨大漩涡在体内轰轰转动。
- 每一次转动，都使王林全身血肉、每一寸肌肉与骨头都游走闪电之力。**此刻的他已不再是修士，而是一道雷霆——一道不甘心命运的逆天之雷**。
- **修为出现奇异改变**（界内界外几乎从未出现过）：
  | 施展方式 | 实际修为 |
  |---|---|
  | 单纯施展**雷霆之力** | 已突破碎涅中期，达到**碎涅后期** |
  | 不运转雷霆，凭火焰 / 本身意境 / 天地元力 | 依然是**碎涅中期** |
- 这种分化，与王林**体内五道本源**有直接关联。

## 五、雨夜出行

- 屋外雨水哗哗、闪电时而划过，仍是夜晚。王林起身，穿上房屋内之前留下的**残破蓑衣**，推门而出。
- 门开刹那闪电照亮漆黑街道：雨雾朦胧看不清远处，家家户户无灯火已沉睡，偶有孩童被雷惊醒的哭泣，很快被爹娘哄睡。
- 街道无人，唯王林独自在雨中前行，伴随他的除了雨还有呜咽的风。
- **城西尽头与城北连接之处**：平日夜晚人声鼎沸（青楼、赌坊聚集），大雨中却随之安静，唯有几间通宵不打烊的客栈酒楼门前幌子透出微弱荧光，在风雨中摇摆。
- 王林走过城西，来到一间酒楼外——内中灯火微弱，只三两人饮酒望雨夜低语，伙计趴在一旁打鼾、双眼惺忪。
- 王林走入酒楼，把**酒壶**放在趴桌的伙计面前，发出轻微声响：**「打一壶酒。」**

## 六、待解伏笔

- 画面中的神秘男子是谁？其五彩极境为何落入纳多之手？
- 昆极鞭为何遗落朱雀星？
- 「这群神秘修士去了界内」若成立，将牵连闪雷族大长老所言之旧事。
- 王林雷霆修为与非雷霆修为的分化，将如何随五道本源继续演化。

# 第1280章 雨夜割魂夺雷

## 一、买酒与雨夜北行
- 王林进入客栈，伙计以『矾晶三钱』收价，取来一壶烈酒。
- 酒极辛辣，入喉化热气入腹。王林认为此酒『适合杀人之时喝下』，很是喜欢。
- 他持酒壶走入风雨，未回城西住处，而是自城北向北缓行。雷霆轰鸣、闪电照路；其步伐不大，但每迈一步，连落下的雨水似乎都为之一顿。

## 二、太古星辰的搜捕
- 这颗修真星北部、距都城不远的天空中，先前施展神通搜索的**道袍老者**神色阴沉前行，身后七名修士面露疲惫。
- 他们已彻夜搜寻多处，毫无发现，属下判断『那让闪雷族毁灭之人』或许不在此地。
- 道袍老者断言：此人或许不在这颗修真星，但**一定在这片星域内**。
- 关键情报：**长尊会的云落大司**已算出此人在这片星域，用不了多久便可算出具体所在；老者意在抢先找到，以立大功。

## 三、无声割魂（本章核心手段）
- 天空雷电交错、大地骤明骤暗之际，蓑衣身影（王林）以无人可察的速度骤然出现在道袍老者身前不足三尺。
- 老者瞳孔骤缩、来不及反应：王林右手举壶饮酒，左手随意在其眉心一点。
- 一声雷鸣中，老者体内元神被生生撕开一部分、穿透身体从背后蔓延；王林上前一把抓住这团元神，携之远去。
- 雷声余音未散，七名修士毫无察觉；道袍老者眼中迷茫片刻即恢复，只面色微不可查地惨白，全然不记得刹那前的骇然一幕，仍道『定然是大功一件』，晃身走远。
- 王林左手所提残破元神呈老者之貌，张口欲呼救却发不出半点声息。八人只需回头便可看见，却毫无所知地渐行渐远。

## 四、搜取记忆的收获
- 王林返回城西屋舍，入门瞬间左手一捏，元神无声崩溃，记忆被顷刻抽出。
- 动机说明：王林不愿贸然杀此老者，只需知晓此刻**太古星辰的具体变化**，故以雷霆之术在对方无察中切割部分元神搜魂。
- 所得：
  - 太古星辰展开了极为严密的搜寻，并已对王林通缉；
  - 长尊会**云落大司**的神通可推算出王林所在之地；
  - 这片星域内的**全部布置**。

## 五、吞噬闪雷族大长老元神，夺五道伴随之雷
- 王林右手一挥，取出**闪雷族大长老**的元神——双目紧闭、气若游丝。
- 判断：除**念雷**之外的其余五道伴随之雷，需从此长老元神中获得。
- 设定要点：大长老当初施展的**六道伴随之雷**神通并非从自身体内凝聚，而是**召唤而出**；虽曾消散，但并未毁灭，可再次唤出。
- 隐忧：雷共有**九道**，如今尚不齐全，不知能否让**雷图**完整、跨越**天人衰劫**，以雷道证**第三步大能雷修**。
- 王林张口一吸，将大长老元神化流光吞入，雷霆元神轰鸣搅碎并吸收。
- 异变：吞噬后王林的雷霆元神蠕动变形，**化作大长老的样子**，双目睁开雷光剧闪。
- 收束：王林喝出六道雷名——『天酝之雷、地融之雷、元化之雷、磁含之雷、道意之雷、灵念之雷，给我出现』。

## 六、要点与伏笔
- 王林已从『被搜捕者』转为主动反向搜情报，行事更冷酷精细（不杀而割魂）。
- 未解之数：九雷尚缺（本章可数者为念雷 + 六道伴随之雷之名），雷图能否完整未知。
- 悬顶之刃：云落大司的推算随时可能锁定王林具体位置。
