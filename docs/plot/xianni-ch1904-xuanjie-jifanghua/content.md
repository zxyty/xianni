# 第1904章 玄劫几芳华！

## 场景
王林于绿魔洲境内渡玄劫。他坐在蝎尾之上，自始至终喝着酒；其**五行真身**站在身后，冷漠望天、一动不动。数千里外有十余名绿魔洲修士遥观，看不到王林本人，只能感受劫的起落。

## 一、玄劫前三次：次次崩溃

### 雪劫、风劫
- 雪劫破不了王林真身；风劫破不了其肉身之力。
- 王林肉身经**绿袍老者**改造，已非当年，兼具无法想象的韧性与强度；即便风劫持续数百年也撕不开这具身体。
- 王林左手向环绕的飓风一抓一撕，九道飓风自第一层连锁崩溃至第九层，尽数爆开横扫消散。

### 雷劫
- 劫云蔽天，雷霆闪电暴虐，王林平静饮酒，抬头一望而笑，只说一个「雷」字并再次摇头。
- 一道连接天地的雷霆直劈而下，王林猛抬头低吼「尔敢」——吼声压过天地雷音，体内爆发**雷霆意志**，其意为天地雷霆之主。
- 雷霆在距王林百丈处骤然一颤、倒卷，反奔劫云而去。
- 王林语：「自我雷霆大成起，雷劫，只有我施于人。」随即左手一抓，劫云内无数闪电被引出、于其左手前凝成巨大雷球，一甩轰入劫云，劫云骤然崩溃、四分五裂，天空阴暗一刹那消散。

### 旁观者反应
十余名绿魔洲修士鸦雀无声，议论断定「定是绿魔大人」——认为唯有当年经历过此劫者才会如此从容，恭敬等候其走出。

### 设定要点
- 玄劫头三次威力寻常，修士但凡有勇气冲击大都可度过，但需消耗极大实力，方能自三次连劫中走出。
- 报酬：**元神暴增一倍**的造化。
- 能如此轻易度过者极为少见。

## 二、第四次玄劫：内三劫开启

### 千丈苍鼓
- 平静天空泛起大量涟漪般波纹，威压散出，一面约**千丈大小**的苍鼓自天空凝聚降临，双面不知何物所组，无声却弥漫沧桑之感。
- 王林凝神看去：「有点意思。」
- 鼓面被无形之力碰撞，闷闷轰天之音掀起无数回音，如无数人在各个方向敲鼓，化作音浪。
- **关键异象**：鼓音并非自鼓面传出，而是自王林体内扩散，震得其血肉、骨头、经脉齐颤，酥痒之感浮现，身体一刹那被震得无法动弹。
- 此鼓是引动内三劫的关键，鼓出即内三劫展开。

### 内三劫第一劫：斩离劫
- 巨鼓外围雾气凭空凝成**巨大雾剑**，通体虚幻如不存在，滔天煞气缭绕如滚滚黑烟，自王林头顶向下斩落。
- 此剑不斩身体、不斩元神与魂，而斩**元神魂魄与肉身之间的联系**及体内血脉牵引；一旦斩落，神身彻底分裂且永不能融合，此后水火不容，魂魄被逼离体而出。
- 此劫诡异，古往今来失败者极多：神身一分离，肉身在鼓声中崩溃，元神魂魄在鼓声中烟消云散。无数年来此剑曾斩断诸多欲闯玄劫、踏入**空劫**的大能之辈。
- 常规度法：修士往往准备很久才敢渡内三劫，且多是一次一次、小心翼翼寻找生机。

### 王林的破法
1. **心动雷音**：鼓声可限制身体却禁锢不了心跳。王林令心跳骤然加速，怦怦之声化作心动雷音在体内轰然传开，与鼓声相撞，身体重获活动之力。
2. **阴骨刀**：右手松开酒壶抬起，掌心剌痛中蔓延出一把**骨状阴刀**，散发滔天寒气，如把天地化作阴森地狱。王林长笑「来的好」，坐而不起，横扫一刀。
3. **杀机压煞气**：刀剑相撞，雾剑裂开无数缝隙轰然崩溃；煞气欲趁碎剑冲出吞噬王林，王林抬头爆发出超过该煞气数倍的杀机气息，煞气似有灵，不敢面对，倒卷急急消散。

**结果**：内三劫第一劫「斩离劫」就此崩溃。

## 三、章末转折
- 斩离劫散开瞬间，天空大鼓轰然发出**第二声**鼓音，比先前剧烈数倍不止，音浪弥漫数千里并遥遥扩散，如天地战鼓发起毁灭号角。
- 王林**第一次站起**，左手抓回酒壶饮下一口，身形一晃直奔天空。
- 宣言：「**毁却此鼓，再看玄劫几芳华。**」

## 主题呼应
「楼台观那一场玄劫的刹那芳华」——不是言语，而是要去做到。王林以从容之姿去看玄劫的美丽；前三劫的寻常令他失望，故期待第四次玄劫是否璀璨。
