# 第七卷 名震罗天 第740章 绝伦，道念之战（第二更）

## 一、战前局势
- 王林的墨龙长枪消散，打断了许封寒的话语；许封寒自尘土中走出，面色苍白、狼狈，杀机疯狂。
- 许封寒被一个「第一步」修士逼到这般境地，视为奇耻大辱，已忘记来此本为地面深坑中的法宝碎片，只想杀王林。
- 王林暗叹：以自身修为想杀第二步修士难度极大。此前一系列计算与打击，都是为了给仙卫（傀儡）一拳的机会；换作任何第一步修士都抗不住，但许封寒身处阴虚境界（尚未真正踏入第二步），故只能伤而不能亡。
- 王林评价：「此人，比当年的雷道子，更加强大。」
- 王林右手一挥，将泥土中露出的法宝碎片尽数收入储物袋，同时紧盯许封寒头顶妖异的魔焰莲花。

## 二、许封寒的道念：道化魔莲
- 许封寒宣称：即便王林有傀儡、法宝再多，在他踏入阴虚境界的道念所化魔莲下一样灰飞烟灭。
- **第一转**：魔莲缓缓转动，魔焰瞬间浓郁，把大半个天空映照成黑色魔光。转动时「天地随之而转」，令人如天地中一粒尘埃被无情抹去——虚幻却极真实。
- **再转 / 魔焰，焚**：转速更快，魔焰滔天并形成巨大魔焰漩涡，炙热逼人；漩涡自莲花升起直扑王林，带起蕴含炙热的风暴。
- **魔莲，百转**：许封寒掐诀急转，天地随转之感再现，王林身不由己后退。

## 三、王林的道念：黄泉
- 王林心神一动，黑色天空奔雷乱响，半空幻化出一道极长的**黄泉**，如天上大江，怨气与凄厉呼啸充塞天地，硬生生挤入魔莲包围形成对抗，化解「天地转动」之感。
- **第二式·凝聚泉魂**：黄泉内怨气疯狂凝聚——这怨气是王林凝聚**整个青灵星所有凡人怨念**所化。怨气化作数之不尽的凡人虚影，再彼此融合成一个**只具人形、没有具体相貌的怨魂**。怨魂生于黄泉，环绕黄泉迎向魔焰风暴。
- **对撞结果**：撕裂之声回荡，天空如被撕裂，大地在王林与许封寒之间裂开一道迅速扩大的裂缝，仿佛大陆一分为二。怨魂消散化回怨气，**黄泉崩溃**——道念崩溃。魔焰经由怨魂→黄泉→王林元神的奇异联系传入，王林面色苍白后退数步、喷出一大口鲜血。
- **第三式·黄泉之力**：王林以不屈意念（「道念崩溃，便给我重新凝聚」）将入体魔焰自汗毛孔逼出化作黑气升空，并把不屈与自信之念灌入黄泉，使其**从崩溃状态逆转重聚**；黄泉内涌出仿佛要吸纳天地的巨大吸力，此力**感悟于两个星域交错之中产生，超脱了某种存在**，使转动的魔莲如陷水中，速度骤降。

## 四、许封寒的推断（对王林身份的误判）
- 由「抽山石之魂」的道念实质神通与法宝众多，推测王林**本是第二步修士，因变故修为跌落**至问鼎圆满。
- 进一步误判：**那傀儡（仙卫）才是本尊**，眼前这具身体是分身，因伤重元神无法回归本尊。

## 五、因果之鞭与转折
- 许封寒欲跃上莲花盘膝而坐，以自身之力转动莲花维持道念；王林不给机会，冲出并右手指天，喝道「**因果之鞭**」。
- 王林眉心浮现一道弯曲细线，幻化为长鞭，一抖啪啪作响、带起无数波纹，如无形之物隔空向许封寒抽去。鞭抽虚空，**抽的是因果**，许封寒身子一颤、面色苍白、身影一顿。
- 王林目光一凝：「此人道心有了破绽」，毫不犹豫冲出。

## 六、设定要点：道念之战
- 拥有道念且能实质化的修士极为可怕。
- 道念之战撼动的是修士的**根本**——既非元神，也非肉身，而是虚无缥缈的道念；道念一旦受损，后果极为可怕，**很难恢复**。
- 道念之战中**不能后退**，一旦后退后果极为严重。
- 双方均受创：许封寒魔莲虽未崩溃但魔焰熄灭大半，且被黄泉怨念侵蚀，脑中纷杂念头止不住涌现，凭高深修为多次压制方才稳固，否则会自行疯癫。此战后许封寒第一次把王林放在与自己相等的位置。

## 七、待续悬念
- 王林抓住「道心破绽」发动进攻，胜负未定。
