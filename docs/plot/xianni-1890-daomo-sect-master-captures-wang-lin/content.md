# 第1890章 劫？造化？

## 一、道魔宗宗主现身

- 第四个传送阵内走出中年男子：黑白道袍、身影挺拔、出尘之气，相貌极英俊但双唇略薄，透出冷酷刻薄之感——正是**道魔宗宗主**。
- 出阵刹那爆发**空劫后期巅峰**修为，天地色变、如无数魔神咆哮八方；距**空劫大圆满**仅一步。
- 四周道魔宗修士齐齐半跪低头，唯宗主冷漠注视疾驰中的王林。
- 王林自入此地便有的冥冥危机感在此刻轰然爆发，源头正是此人。

## 二、移山截道

- 王林不回头，施展极速化作连绵残影（此地无法缩地成寸），只需再飞不远即可脱出封天之力、融入天地。
- 宗主神色平静，一步跨过绿魔洲与孟土洲边界，径直踏入孟土洲，抬手一指天空，只说两字：**「道、魔」**。
- 两洲交界处那条如长龙横卧、约**数万里长**的磅礴山脉剧烈颤抖：
  - 山脉最左侧尽头幻化出**白色道袍白发老者**（仙风道骨、慈祥微笑），大袖一甩；
  - 山脉另一尽头幻化出**黑色长袍如魔青年**（魔气滔天、煞气逆天），右手一指山脉。
- 山脉被生生连根拔起升空，随宗主一指呼啸前冲，转眼横扫数千里，从王林上空掠过，落于其前方**两千里外的孟土洲沙漠**。
- 结果：若以山脉为两洲界限，则王林**依旧身处绿魔洲内**。宗主第二句话：「这样，你还是在绿魔洲」，随即一步跨至王林身旁不足百丈。

## 三、王林的抵抗

- 宗主：「不要怕，本宗不会杀你，你对本宗，有大用」——眼中蔑视如看蝼蚁，大袖甩出。
- 王林此刻状态：**魂铠消散**、修为回落**空灵后期**、连续施展神通后油尽灯枯，差距悬殊。
- 应对：闭目感应**虚无中的分身**，身体凭空多出一股气息，**双目化作金色**，转身掐诀向后一拍。
- 结果：天地轰鸣，王林身震喷血、身形倒卷向远处山脉，当即重伤、意识欲昏，咬舌尖强行清醒。
- 宗主轻咦，眼露诡异幽光：「不愧是指定的人啊……还能抵抗我一式攻击」。

## 四、仙魔七指印

- 宗主抬手一拍天空，天空崩溃如鱼鳞波纹：
  - **如仙老者**降临化作巨大**白色七指掌印**（手指为七而非五）；
  - **如魔青年**自虚无踏出化作巨大**黑色七指掌印**，魔气纵横。
- 二印于王林上空数千丈**融合为闪烁黑白双芒的仙魔印**，天地黑白颠倒、模糊朦胧。
- 王林不再逃，静立仰望，神色无绝望无悲哀，唯**一丝遗憾**：
  - 尚未复活**婉儿**；
  - 尚有诸多兄弟朋友，在**仙罡大陆**还未找到。
- 闭目之际并未放弃挣扎，而是在灵魂中呼唤久未使用的——**天逆（天逆珠）**。

## 五、转折：改杀为擒

- 掌印降临王林身躯的刹那，道魔宗宗主**突然心神一跳**，生出说不出的心惊，不假思索抬手一挥。
- 掌印遂未将王林拍死，而是**一把握住**，将其埋于掌心之中。
- 宗主跃起与掌印融合，直奔绿魔洲深处；地面道魔宗修士化长虹随行。
- 众人离去后，那条山脉**缓缓后退归位**；孟土洲对此事**未散出任何神念**，仿佛早已知晓并达成协议。

## 六、宗主的盘算

- 内心迟疑于方才的心惊：他甚至感觉「若方才欲杀王林，将有如大祸临头的不妙之事」——这种感觉在他身上极为罕见，不可忽略。
- 判断：「此人是**指定之人**，想来必有手段……他很是狡猾，若按照计划杀他，本不会付出如此代价。」
- 目的地：绿魔洲**中心**的**绿魔蝎庙**。
- 计划：**「将此人镇压在那绿魔蝎庙内，以其身体滋养绿魔，以其神魂使得绿魔复活」**。

## 七、遗留悬念

- 天逆珠被呼唤后是否响应、宗主心惊是否即源于此，本章未揭晓。
- 孟土洲与道魔宗之间疑似存在的协议，本章仅暗示。
- 「指定之人」的指定者与其计划，本章未明。
