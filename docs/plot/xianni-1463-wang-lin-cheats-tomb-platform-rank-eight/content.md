# 第1463章 作弊（第二更）

## 一、破解古墓印记规则

- 承前章：封灭族少女被雾气卷走消失，王林手中留有从其眉心摸下的**数字标示**，随手放在一旁，任墓台疾驰。
- 王林做实验：取出**古魔魂**捏碎化作古魔之力 → 与自身**古神之力**融合 → 再自**葫芦**取**古妖气息**，三族气息融合圆满之际，右手拍向自己眉心。
  - 体内元力急转、面色苍白，眉心三族气息成漩，剧痛如锥刺额；半晌后眉心**浮现数字标示**。
- 印记出现刹那，四周雾气轰然翻滚、咆哮弥漫，似要吞噬王林与其**六千丈墓台**——如同他搅乱了古墓固定规则，要像封灭族少女一样被抹杀带走。
- 王林当机立断，右手在眉心一抹，将刚诞生的符文印记**生生撕下**。面色更白、呼吸急促，戒备反抗——但雾气随即平复退开。

### 王林得出的结论（古墓规则真相）

1. 他身为**古神**，故本来眉心无印记；但印记可以由**古之三族气息融合**人为诞生。
2. 正因本就不该有印记，抹去后不会像封灭族少女那样被古墓抹杀。
3. 印记本质：古墓发给**所有非古之三族之人**的短时存在**封印**——此处是古之墓地，唯古之三族可入，外人须持印记；印记一失，立刻被古墓抹去存在。
4. 古墓以墓台升阶为重点，是要让**古之三族后人**在此杀戮外人、夺取印记。
5. **那些外人不是传承试炼者，而是试炼的一部分**；真正的试炼者只有王林自己；若**拓森**到来，他也将成为试炼者。
6. 王林评价拓森狂妄至极、脑子混乱，未必想得到这个关键。

## 二、作弊式升阶：自造符文喂墓台

- 思路：「杀人取印并非唯一道路」——王林无法与那些老怪比，时间上也来不及，遂改用**自体量产符文**。
- 手法：融合三族气息→按入眉心→烙印再现即刻挖出→融入墓台。一个、两个、十个、三十个……转眼近百。
- 雾气因其频繁举动愈发狂暴云涌，但王林**时机把握极巧**，不给雾气卷临的时间。
- 数个时辰内凝聚出**数百个数字符文**尽数融入墓台。

### 七阶墓台

- 墓台此前已吸收**奉天狼族大汉**全部符文而扩至六阶且有余量，加上王林的量产，直接达到七阶要求。
- 六千三百丈 → 六千七百丈 → **七千丈**，远看如一小块大陆；雾气齐齐逼退，金光万丈如阳，退慢的雾气被金光一扫即蒸发消散。

### 传承之声（第三次）

> 「地府为魂，本道一生共杀三仙尊，囚印其魂在地府，本欲炼成本道分身，后世之人可取。然此三魂极为强大，后世得者，若无十足把握莫要放出。这三魂生前，均都是赫赫之辈。」

- 王林由此知晓第一次话语中提及的**地府**为何物，并对地府内的**仁和剑**有了猜测。
- 同时脑海地图再开启一副。

## 四、八阶墓台·资源代价

- 消耗结构：**魔魂瓶**内古魔魂数量充裕、古神之力可再生，唯**古妖之力最少**，葫芦内古妖气息所剩不多。
- 应对：王林**不惜毁灭**进入古墓后所得的数件**古妖之宝**，抽取其中古妖气息，勉强跟上凝聚速度。
- 数个时辰后最后一件古妖之宝崩溃，抽出气息、融合圆满、按入眉心、化符融入墓台的刹那——
  - 墓台轰然一震，金光急闪，膨胀至**八千丈**，成为**八阶墓台**。
  - 这是古墓内**所有人中第一个八阶墓台**。
- 影响：雾海剧烈翻滚如海啸，惊天轰鸣传遍古墓内所有地图，**所有修士**都感受到身边雾气的剧烈波动。

## 五、伏笔与待验

- 地府三仙尊之魂：强大、可取但慎放；仁和剑疑与地府相关。
- 「枷」：烨寞未言明之物，妙曼女子与「老东西」皆觊觎。
- 九阶墓台之争：王林 vs 九天魔尊 vs 白衣女子 vs 拓森一行。
- 拓森亦为古之三族（自称「本神就是你之一族」），且被王林视作潜在的另一名真正试炼者。
