# 第777章 我叫许木！

## 一、李元布禁·守住后路
- 李元目光闪烁，退后数步回到暗洞内，盘膝坐下，左手掐诀按在眉心。
- 黑线飞出化作一个个禁制落于四周。他修为不足无法直接出手，但有把握短时间内外面无人能进来。
- 此举等于为王林打开（守住）后路。

## 二、一眼慑敌
- 王林望向来犯者的这一眼，不同于当年初看到第三步后望向申公虎时的目光；此刻因修为高出对方、封印了血祖、杀了两个阴虚修士，一股对修为的自信与对自身道的明悟，使这一眼好似饱含一切。
- 中年男子冷笑，非但不停，反而踏出一步跨过数十丈直奔王林，口出讥讽：“真是笑话，在雷之仙界内，居然也有人敢扬言千丈禁地”——话未说完便止住。
- 那目光中无杀机，只有冰冷的平静，如同在看一个死人。中年男子感到四周一切消失，只剩那道目光；全身元力不受控制运转以抵消危机。
- 他冷汗弥出，感到被一眼看透、如赤身裸体，继而皮肤、五脏六腑、元神层层消失，元神仿佛“神已不再”彻底化成一团元气，最终几乎感觉不到自身存在。
- 一口鲜血涌出，面色病态红润，喷出后眼中恢复清明，却透出惊惧。整个过程仅数息，旁人未及看清端倪。

## 三、十步压杀
- 王林平静迈出一步，落地无声，中年男子却觉如被踩在元神上，心神剧震，毫不犹豫迅速后退。
- 他原本因己方四人且有唐言枫在而不惧，此刻却如孤军面对一个**阳实**修为的大神通修士，似不退必死。
- 王林一连踏出十步，每一步在对方感受中如雷鸣，心神几近崩溃，后退已不受控制；心跳随步伐越来越快，最终连成一片。
- 十步后王林身子略停，在冰冷目光中落下最后一步（右脚）。中年男子早已退出千丈禁地之外，仍口喷鲜血、如发疯般后退。
- 最后一步落下刹那，其心脏跳动达到极限而瞬间崩溃；体内元力暴虐倒卷，冲入元神生生撕裂——身死。

## 四、唐言枫的忌惮
- 唐言枫眼中露出极谨慎之色：自修道以来，除有限几人外，同辈中罕有人令他如此。
- 他判断此死与元力有关：对方在元力运用上极为巧妙，以四周元力挤压造成威严，生生挤碎中年男子心脏。
- 他自问杀那中年男子容易，但仅凭一道目光与十几步便令人崩溃，这种神通令他倒吸口气。
- 其身边女子俏脸阴沉，站在千丈禁地前一步外却不敢迈出——千丈禁地此刻真正成了死亡之地。

## 五、青年断指求生
- 第二个踏入千丈禁地的青年修为更弱，刚刚踏入阴虚，元力不多且未稳定。
- 被王林目光一扫，立即退出千丈外抱拳：“前辈莫怪，晚辈知错，从此之后前辈所在千丈，晚辈绝不踏入半步，若违此言，犹如此指”，运转元力自爆左手小指化作血雾。
- 王林看了一眼便收回目光。青年内心大松，告诫自己日后行事务必谨慎，此前晋入阴虚的兴奋尽消。

## 六、报名·封洞
- 王林不看千丈外其余人，转身走入李元所在的暗洞。
- 唐言枫开口：“道友留下名讳”。
- 暗洞内传出王林的声音：“许木”，随即禁制光芒闪烁，暗洞彻底封死。
- 唐言枫暗道“许木，唐某记住了”；他自始至终想出手，最终忍住，因实无把握战胜。

## 七、要点与伏笔
- **化名归属**：本章“许木”为王林自创化名（自第711章起以此名行事），一切言行归属王林。
- **实力刻画**：王林的手段落在“元力运用”而非法宝斗法上——目光慑元神 + 步伐挤压元力 = 不战屈人。
- **因果伏笔**：唐言枫记下“许木”之名，为后续结怨/追查埋线；断指青年得活，亦是一笔。
- **境界参照**：本章出现阴虚（中年男子、青年）与阳实（比喻性提及大神通修士）两个层级。
