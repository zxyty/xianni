# 第九卷 云海之巅 第1218章 封界之阵（第一更）

## 一、拓森苏醒于罗天星域

- 星空深处一颗蛮荒星，无光无生机，唯死气环绕，其上坐着一个**身如数个星球大小**的存在——拓森。
- 外貌与标志：皮肤粗糙、遍布如印记般的裂纹并散发诡异光芒；身负与天地同寿的岁月痕迹，久远到自己都记不清年月。**眉心八个星点环绕，仅四亮，四黑干枯而未散**。
- 仅平静而坐，威压便笼罩整个罗天星域：星域修士灵魂颤抖、心惊肉跳；蛮荒之兽伏地不敢动。
- 他被形容为「这片星域的最强者、曾经的统治者」。

## 二、寻王林不得的咆哮与破坏

- 拓森自语：「雨界没有他的气息，雷界没有他的气息，闪界没有他的气息，他到底在哪」——遍搜四大仙界（风雨雷电体系中提及雨界/雷界/闪界）皆无王林踪迹。
- 判断依据：王林**未死**，否则他必能感受到王林消散于天地中的**记忆传承**。
- 一声惊天咆哮的后果：
  - 身下蛮荒星骤然崩溃、爆开，形成风暴横扫，牵动天地元力；
  - 撕开无数空间裂缝，寒风自裂缝吹出（对拓森毫无影响）；
  - 罗天星域众多蛮荒之兽身体爆开化作血雾；
  - 大量修士喷血，或重伤或死亡；
  - 无形音浪波纹弥漫星域，波及星球皆震动。

## 三、跨越壁垒，踏入云海星域

- **四大仙界的壁垒对拓森微不足道**；数步之下，身前出现巨大漩涡，漩涡内为充满雾气的星域——云海。
- 拓森庞大身躯消失于罗天，踏入云海。
- 入云海的震动：
  - 云海星域**一至九阶所有宗派修士**同时感受到令其心神剧震的气息；
  - 雾气内凶兽齐齐退缩不敢靠近；
  - **九阶星域裂缝中持续百年的兽潮**亦露恐惧疯狂后退，厮杀出现罕见空白；
  - 拓森神念如风暴横扫云海，雾气倒卷颤抖。
- 九阶星域内冲出数道神念撞击拓森神念，无声却如世界雷鸣。以拓森的性子本该厮杀，但他志在寻人，右脚一踏使云海震颤、身前星空大片崩塌，沉入裂缝消失。
- 那数道神念寻找无果后齐齐离去；**云海此日惊变，除个别老怪与极少数人外无人知其原因**。

## 四、虚无·封界大阵·太古星辰

- 地理层级：四大界星空之下是**一片虚无**，此处即**封界大阵**所在；突破此地便可踏出界外，进入**太古星辰**。
- 拓森记忆不完整，但从自身所得的那份记忆中知晓太古星辰的存在，并隐约记得**涂司似乎正是从太古星辰而来**——那个时候，还没有封界之阵。
- 他目光似能穿透虚无与大阵，看到外面**记忆中熟悉的家乡**。
- 推论：找遍所有地方无王林气息 → 王林必在太古星辰。宣言：「即便你躲到了太古星辰，本神也要将你吞噬」——**唯有吞噬王林，他才可以获得完整**。

## 五、古神一拳撼阵与阵灵反击

1. 拓森向前一迈，虚无浮现无数波纹，显出**密密麻麻如蛛网般的封锁阵法**。
2. 右拳轰出——「真真正正的古神一拳，王族古神的一拳」，直落封死界内界外的大阵之上。
3. 波纹掀起层层虚无后，整个虚无显形为**封锁整个界内的绝大之阵**，一眼看不到边际，隐透七彩之芒；**拓森在阵前都仿若凡人大小**。
4. 阵法纹丝未动，反弹之力与拳头碰撞，**强如拓森也不得不后退**。
5. 拓森身为王族古神有其骄傲，低吼再冲，拳如流星反复撞击；阵法出现罕见颤抖，但始终不崩、死死封锁，不容任何人踏出半步。
6. 惊动**太古星辰的守阵之人**，齐齐闪烁而来；但在他们抵达之前，阵法因承受攻击达到自动生成**阵灵**的条件：
   - 第一击：银白如闪电之光凝出**长枪**，四周散发无尽闪电、速度极快。拓森回头一扇，磅礴古神之力将长枪轰溃，长枪却自崩溃中**再度凝聚且气势更强**，刺入其右臂；粗大闪电自刺入处蔓延全身，如电网死死锁住拓森。
   - 第二击：阵法再凝蓝色光芒，幻化**蓝色短剑**，携滔天剑气与阴寒直奔拓森。

## 六、要点与悬念

- 拓森的目标明确且唯一：**吞噬王林以求完整**（与其眉心四明四暗的星点、记忆残缺相呼应）。
- 王林去向被外部势力锁定为「太古星辰」，封界大阵成为其与拓森之间的最后屏障。
- 太古星辰有**守阵之人**这一势力群体，首次被惊动登场。
- 章末作者杂谈（非剧情）：回应读者关于完结的疑问，称至少还要写大半年。
