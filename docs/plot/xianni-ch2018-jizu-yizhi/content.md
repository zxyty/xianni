# 仙逆 第2018章 吉祖一指

## 一、修炼进度：五行真身与推衍成败

- 王林放下道古皇尊封后大典的邀请玉简，判定大典远不如自身修炼重要。
- **金本源真身**预计数日内凝聚而出。届时五行（金木水火土）完全成为真身、融为一体，即可验证其此前的猜测与推算。
- **失败条件**：若五行真身完整后修为依旧停留在**空劫后期**，则推衍失败。
- **失败后的备选路径**：暂且放弃以其他本源凝聚真身之法，转而感悟继**生死、因果、真假**之后的第四道——**虚之本源**。此本源模糊一片，全凭机缘明悟，或数年可得，或千年无头绪。故王林踌躇。

## 二、地底洞府：大天尊之阳与仙祖之头

- 王林在木屋地面布下一座阵法：缓缓转动、无声无光，外看毫无异状，踏入即传送。
- **洞府位置**：木屋正下方地底约万丈深处，泥土之间开辟，数百丈之大，为王林闭关第五日所凝。
- **洞府布置**：四周布满阵法禁制。禁制中融入了王林体内那股**非仙非古的融合之力**一丝，威力极强——天尊、跃天尊完全无法感应，大天尊不仔细看也难以察觉。
- **核心之物**：
  - **大天尊之阳**：黑白两道光芒笼罩，中心悬浮一个巨大的黑白之阳，尚只是轮廓。
  - **仙祖之头**：十丈大小，无双目双耳，天灵有一道深深裂缝，悬于大天尊之阳之下。
- **滋养之法**：王林盘膝，张口吐出青气，青气自七窍钻入仙祖头颅，头颅震动散出大量金光，金光旋即被大天尊之阳吸收，化作黑白二芒滋养此阳。此举已持续**近三个月**，仙祖头颅难以炼化，尚未完全融合。
- **王林的判断**：大天尊之阳若能完全融化仙祖头颅，此阳便会完整。

## 三、仙皇连道真的灵魂与诅术

- 王林右手虚空一抓，暗金光芒中现出被其擒住的**仙皇连道真**之灵魂：闭目、虚弱、不时颤抖，无力睁眼。
- **灵魂特征**：仍散发大天尊级别的威压，任何强者一眼可辨；但缭绕的仙气并不精纯，极为驳杂并透出灰败之感，显然承受着极大痛苦。
- **诅术**：王林一路不断封印，配合自身修为与仙皇自身灵魂之力，仍无法驱除，只能维持平衡使此魂不散。
- **用途变更**：原打算借此灵魂威压强融体内仙古之力，如今已不需要；转而设想——若能驱除诅术，便可将此魂融入大天尊之阳，**以他魂为引，强吞仙祖头颅**。
- **尝试与结果**：
  1. 左手掐诀，一指点在仙皇灵魂头部，灵魂无声嘶吼、震动洞府禁制。
  2. 抽出一丝灰气，化作长丝，离体后蓦然化为**灰色恶鬼虚影**，张血盆大口反噬王林手指。
  3. 王林双瞳化为**银色**，银光一闪，恶鬼虚影恐惧收缩大半，被其一把握住捏散。
  4. 王林额头泌汗、苦笑：**仙古短暂融合可驱散诅术之力，但以当下修为无法坚持太久，做不到一次性驱除所有诅术**；被抽出的诅术随即重新滋生。
- **结论**：须待修为更高、融合时间更久、威力更大时，方可驱除此魂诅术并融入大天尊之阳。
- **保密考量**：此术诡异，仙皇身份又特殊，**不便寻玄罗师尊帮助**；王林习惯性不愿让任何人知晓自身隐秘。

## 四、明悟吉祖一指

- 王林取出**计都皇子**所赠玉简，其内蕴含**古祖（吉祖）一指**之力。此前研究总隔一层膜，看不清晰，只能当作一次性神通使用。
- **变数**：王林已融化体内那滴**魂血**，脑中多出大量破碎记忆——能感受其存在却无法翻看，因魂血不多之故。
- **突破手法**：闭目良久后猛然睁眼，双眸再次浮现**银光**，占据全眼，透出冷漠无情。以银目再看玉简，脑海中数片记忆碎片蓦然相连并展现。
- **记忆内容（吉祖出手）**：
  - 灰色衣衫、一头长发的男子，容颜**正是道古皇城内的雕像，即吉祖**。
  - 左手背负身后，悬于天空，抬头望天，神色轻蔑不屑、孤傲至极。
  - 一群凶兽呼啸而来：**人的头颅、狮子的身体，只有两肢，后肢与尾蜕化成鱼尾一般**；为首一只格外强壮，气息接近大天尊但略差一些。
  - 吉祖右手抬起向前一指：天地震动，凶兽所在的**方圆十万里天地被分裂出来、上下猛压**，轰鸣中凶兽尽数粉碎。
- **结局**：玉简「啪」地裂成两半，落地化作碎末。王林清醒，银色消散，目中精光闪动，叹道：「好一个古祖一指之力。」
