# 第1681章 进入仙罡的剑尖！

## 一、通道与石门

- 王林神识笼罩之下，看清此地并不大，而是**细长如一条通道**；通道四周脆弱、多处破损如裂缝，似随时崩溃。
- 通道一端为王林所在，另一端在**无尽深处**，神识无法蔓延进去，只能隐隐看到一座**巨大石门**，门上贴着**一张纸符封印**。
- 王林一步跨至通道尽头、石门百丈之外。此百丈之内：阻止一切神识探入，阵阵威压弥漫，阻止任何人靠近。
- 石门样式古老，其上有王林**从未见过的复杂文字**，透散沧桑之意。
- 关键判断：石门并非完美耸立于此，而更像**被人强行嵌入**，目的是**支撑这条通道，使其万古长存**；纸符则是封印石门，**外面进不来、里面出不去**。

## 二、第一次冲击（失败）

1. 王林踏入百丈内，极强威压自内轰出，脚步难落；他猛地踏下，通道轰鸣。
2. 连走十余步（每步数丈），至百丈距离的中点。此处身体内传出砰砰之声，似要崩溃——**此刻他并非古神肉身**，无法再以肉身承受挤压。
3. 遂盘膝掐诀、一指点眉心，眉心现漩涡，**元神在血光中离窍而出**，血光即其**血剑**。
4. 元神融入血剑，直奔最后五十丈。排斥之力惊人，抵近石门**十丈**时排斥达到恐怖程度。
5. 血剑颤抖，王林以心念令血剑**砰地刺入通道壁**固定己身，但仍不断被向后豁开。
6. 十丈近距离观察确认：石门为后置、用以支撑通道；**排斥威压正是自纸符散出**。
7. 最终血剑被挤出墙壁倒卷，元神被推回五十丈外，返归肉身。

## 三、第二次冲击（成功·六大本源）

- 王林自忖：若与**本尊**融合、凭**古神躯体**与**不灭之术**，这五十丈虽艰难亦可走到门旁；但回去融合**浪费不少时间**。
- 「他一生修道，从不屈服于任何力量」——遂选择硬冲，六大本源齐发：
  - **左目雷霆本源**（雷霆闪烁、轰鸣）
  - **右目火焰本源**（火光汹汹）
  - **左手为生，右手为死**（生死本源）
  - **掌开为因，掌握为果**（因果本源）
  - **双目闭合睁开，真假本源环绕**（真假/虚实本源）
  - **体内轰然爆发第六道本源——杀戮**
- 六大本源融入眉心，元神再度轰出、凝聚于血剑：雷光闪烁、火焰灼烧、真假本源缭绕、杀戮开道，血剑爆发剑之嘶鸣，向五十丈外石门轰去。
- 强行冲入十丈内，**血剑刺穿纸符，刺入石门三尺之深**；剑体剧震，排斥之力与六大本源相冲。

## 四、剑尖穿透之刹那——仙罡大陆

- 血剑穿符入门三尺的刹那，王林元神感受到一股**曾遇到、极为熟悉、不属于此洞府的气息**——**仙罡大陆的气息**，即他在**梦道**之后神识曾去往的那个天地。
- 仙罡大陆设定：
  - **恒久间就存在于苍凉天地的大陆**；
  - 其大小是**界内界外的无数倍**，即便**第三步大能**横渡整个大陆也往往需要很久；
  - 被称为「**天之边，地之极**」，是宇宙洪荒中最壮观之地。

## 五、镜头切换：仙罡大陆东部·归一宗分宗

- 仙罡大陆**东部**，一片连绵雄峰之间，雾气缭绕、仙气盎然、仙兽飞禽舞动；
  - 这片山脉**足有昆虚星域一般大小**，望不到尽头，但与整个仙罡大陆相比只是沧海一粟。
  - 山脉中一峰直插云霄，如利剑倒刺天幕，近看长度无尽、远望仍只是小山一座。
- 此峰上有庞大宫殿群，是**归一宗的分宗山门**。**归一宗在仙罡大陆与七道宗一样，算不得大宗**。
- 分宗大殿广场上空悬浮一口**千丈大钟——东丹钟**，庄严无比。

### 事发经过
1. 大钟突震，嗡鸣传遍整个分宗；数道长虹自远处宫殿呼啸而来。
2. 大钟上爆发惊天血光，光芒万丈——「似这光芒已经离开仙罡大陆太久太久，但今天，它再次回来了」。
3. 血光下，一把**赤红剑尖自钟上透出三寸**。
4. 最先赶到者：一名身穿奇异道袍的中年男子，**空玄巅峰**修为，其修为内**隐含一丝玄劫之力**（显然已度过不知几次玄劫），被众人称为「掌门师兄」。其后八人随至，共九人立于钟下。
5. 众人目光下，剑尖缓缓收回、血光一闪消失，**在大钟上只留下一道永恒存在的印记**。

### 归一宗众人的对话（重要信息）
- 「**烨寞之剑**」——有人当场认出。
- 有人提议：「要不要打开这**东丹钟**？」
- 掌门师兄答：「暂且不必。当年**马师兄**带人临走前曾说，**此钟决不能打开，他会自己回来**。」
- 「**烨寞血剑**，看来传闻中**烨寞被七道宗引入洞府**，此事是真。」
- 「那**七彩尊者抛弃了道侣、封锁了七道宗**，定是获得了极为贵重的宝物。**马师兄**研究了很久，这才以**我归一宗至宝，开辟了一条通往其洞府的通道**；以马师兄的手段与修为，我等不必多虑。」

## 六、收束

- 洞府一侧：血剑倒卷，王林元神带着**震撼**被推回五十丈，融入肉身，一把抓住血剑急急后退，转眼退出百丈。
- 王林神色**罕见凝重、铁青**，死死盯着石门，心跳加速，全身修为急速运转、警惕至极，口干舌燥。许久见石门无变化才松口气。
- 结论：「**仙罡大陆……那石门外，是仙罡大陆！**」——「我明白了。」
