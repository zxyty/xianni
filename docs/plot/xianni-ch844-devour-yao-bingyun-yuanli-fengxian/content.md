# 第七卷 名震罗天 · 第844章 吞噬（第三更）

## 一、罗天星域风暴：雷仙殿声威登顶

- 一场风暴横扫罗天星域：**罗天北域**内那头屠杀无数修士的庞大凶兽，被**雷仙殿**生擒。
- 过程鲜有人知，但结果震撼全部罗天修士。
- 雷仙殿名声达到巅峰，压过几个**传承至上古的修真家族**，成为罗天星域内极为强大的象征。

## 二、封一百零八仙：规则与时间表

借此声势，「**天罡三十六、地煞七十二、封一百零八仙**」的旷世之事正式展开。

雷仙殿宣称的封仙法理：

> 仙界崩溃、仙人损落，但后世之中还有真仙。此雷仙殿所封，便是**雷仙界**。后世仙人凡名列一百零八仙，其所在家族便是**仙之一族**，永久存在。与联盟星域一战，凡仙人者均可成为**一方统领**，其家族可获**单独修真星**。

具体规则：

| 项目 | 内容 |
| --- | --- |
| 分区 | 罗天**东、西、南、北**四大星域，各为一个**封仙区** |
| 选拔 | 每区由雷仙殿派人前往，选出 **108 名强者**赴雷仙殿参加最终封仙之战 |
| 禁斗域 | 雷仙殿**方圆十万里**内禁止一切私斗，违者**灭族** |
| 时间 | 封仙之日定在**四个月之后** |

各修真家族嫡系族人纷纷启程，整个罗天星域为之疯狂。

## 三、天崩地裂之举：开通道，战联盟

- 雷仙殿宣布：在一百零八仙选出之时，**打开通往联盟星域的通道**，与联盟之战就此展开。
- 罗天星域陷入狂热，所有修士都在准备封仙之后杀入联盟，浓郁杀机弥漫整个星域。
- **王林对这一切并不知晓**——他此刻正闭关洞府。

## 四、王林闭关：炼化姚冰云元力

- 闭关已过**十天**，几乎无时无刻不在吸收**姚冰云**体内元力。
- 姚冰云为**窥涅中期**，体内天地元力极为庞大，对王林如同「极好的补药」；十天只吸收了**三成**。
- 炼化三成之后，王林修为迈出一步，达到**阳实境界巅峰**，距**窥涅**只有一步之隔。
- 但这一步如同沟壑：**不是元力不足，而是差了对天道的感悟与意境的变化**。

## 五、因果意境之困

- 王林所参之意境为**因果之境**，自认「比之生死轮回要玄妙很多」，感悟起来无法捉摸、雾中风月。
- 他自陈的因果链条（自我复盘）：
  - 获**天逆珠**为因 → 遇**司徒南**为果；
  - 杀**藤厉**为因 → **藤化元**灭其双亲为果；
  - 藤化元所行为因 → 王林**屠藤族**为果。
  - 结论：「今日因，可能明日便成为了他人的果。」
- 感悟不能强求，若无顿悟很难摸到脉络；修炼到一定程度难以寸进，元力有关联，但更多在于自身感悟。
- 核心疑问：**如何让因果之道从「虚幻」变得「真实」**。

## 六、关键顿悟：吞噬他人之道

三条线索被王林串联起来：

1. **妖灵之地 · 古妖贝罗**：当年在贝罗帮助下进入奇异状态，推衍出**杀戮仙诀的弊端**；在该状态中他化作无数分身、隐约可看破世间一切道。
2. **天运子的神识空间**：天运子所修为「天之运」，其神识中有无数个天运子，每个各擅一种仙术；当年修为所限只看到此层，如今回想——**每个天运子身上不只有仙术，还有不同的「道」**。由此追问：天运子这些道从何而来？
3. **第一个仙卫的遗言**：被炼化之前曾说「我看到天运子师尊，把**孙云**吞了，是真正的吞下，全部吞了」。

结合「修道第三步感悟——一切天道最终要回归本源」，王林作出判断：

> 因果之道全是虚幻，本源为何尚不清楚；但若想让意境真正实质存在，**需要吞噬**——吞噬别人的意境，感悟他人的因果，明悟对方的道念，化作自身因果意境。
