# 第1804章 仙罡第一战！（第三更）

## 一、场景与前情
- 地点：仙罡大陆·天牛洲·苍龙宗，康仁的洞府。
- 王林被康仁当作「尸体造化」带回宗门，此刻正盘膝于洞府深处阵法上爆发的滔滔地火火柱之中，全身被火焰淹没、身后背负一口棺材，闭目炼化地火以滋养火本源。

## 二、赵长老试探与被震退
- 苍龙宗中年男子（赵长老）为空灵后期、已拥本源的**第三步大能**，宗内一人之上万人之下，于天牛洲亦名列前茅。
- 他隐约看见火柱中的背棺身影，认定「这哪里是什么尸体」，怒斥「何方野修，竟敢混入我苍龙宗内，不把你炼成傀儡，岂不是让天牛洲修士奚落」，护体气泡逼开火焰，半身踏入火中。
- 王林骤然睁目，寒芒暴射，气息之强令赵长老自觉如萤火之于皓月。
- 王林冷喝「**滚出去**」并挥手：洞府内外骤入寒冬、雨水欲结冰、地火为之一暗；赵长老护体气泡崩碎，连喷三口鲜血，如断线风筝被横扫出洞府、卷至千丈外，在数万宗门修士众目睽睽下重伤止步，凄厉发问「你是谁」。
- 王林再喝一声「**聒噪**」，四周刹那寂静，连从天而降的雨水都悬停半空。白发老者（虚云的师尊）骇然判定：「**语出规则，万物不动**」——这是修为到了空玄、甚至更高程度的表现。

## 三、搜魂康仁与王林的处境判断
- 王林隔空一抓，将被禁锢的康仁摄入火中掐住脖颈；康仁与其目光一触即如十万天雷轰鸣，毫无反抗之力，只能求饶「前辈饶命」。
- 王林神识入其心神横扫记忆，取得所需片段后将其抛出重新禁锢。
- 情报所得：**苍龙宗宗主为空玄初期，老祖杜青为空劫初期**。空玄初期王林不放在眼里，空劫初期则「有些难办」。
- 关键限制：在仙罡大陆**储物空间不方便打开**，一旦开启很可能出意外——法宝无法取出、**已司之傀**也无法出现，对抗空劫修士不利。
- 王林判断：仙罡大陆很可能与洞府界不同（苏醒时便有察觉），其余本源在此地亦有变化与不同，需要熟悉。
- 决断：**先行离开，另寻一地研究储物空间问题并熟悉本源**。以其性格，初来乍到不愿太过嚣张。

## 四、苍龙宗围堵：道喃术 vs 心动雷音
- 王林掐诀挥手，引更多地火自地底轰然爆发，笼罩整座洞府并向外扩散，准备遁走。
- 赵长老一眼看破「他要逃」——其真正恐惧的并非王林，而是**老祖归来后的勃然大怒**（曾见老祖将人炼成木头人）。
- 赵长老强压伤势下令：喝令**厉长天、孙梦得、韩芯**共同拦截，命全宗弟子**撤去天水阵、全部施展道喃术**。
- 云层中两条长龙扭曲化作一男一女；连同赵长老、白发老者，此地**四大长老（四位第三步大能）齐齐出手**封堵。
- **道喃术**：大魂门神通；苍龙宗老祖与大魂门关系极深，被赐下此术，遂成宗派阵法之术。数万弟子齐诵，所念仅「**道**」「**魂**」二字，音波融合成奇异之力，可**融化道念、分离灵魂**。
- 王林心神震动、心生烦躁，起身跨出一步，施展**学自古之墓地的「心动雷音」**——怦怦心跳自体内扩散，连成一片如雷鸣轰轰，与道喃术正面对抗。

## 五、章末悬念
- 四大长老冲入洞府欲封死此地之际，王林右手向大地虚空一抓，神色凶狠：「**抽，地火脉之魂**」。

## 六、境界与设定要点
- 本卷境界序列（仙罡大陆体系）：空灵后期 → 空玄（初期） → 空劫（初期）；「拥有本源」为第三步大能的标志。
- 火本源可借地火不断吸收炼化而增强。
- 天牛洲为仙罡大陆下辖大域，苍龙宗位于其中。
