# 第859章 来临（第七卷 名震罗天）

## 一、封仙大局

- **雷仙殿封罗天一百零八仙**：以东、西、南、北四大星域为封号之地，展开激烈争夺。
- **规格空前**：开创罗天自仙界崩溃以来之先河，附带三重重赏与背书——
  1. 当年的仙君**清水**传法；
  2. 两个**传承上古的修真家族**的承诺；
  3. 那**神秘的远古家族**送出**升仙池资格**。
- **真实动机**：在**进攻联盟星域**之前，借封仙把整个**罗天星域**的战意掀至高昂。
- **流程**：无数修真家族在罗天东西南北四大地域的指定场地，由雷仙殿派出的使者见证，各选出一百零八人，赴雷仙殿进行最终的封号之战。

## 二、罗天南域封号战场：地炎星外

- 地点：罗天南域三大主星之一**地炎星**之外的浩淼星空，方圆千里笼罩璨光光幕，即南域封号战场。
- 观战格局（自千里外向外铺开）：
  - **青石**（丈方，漂浮）：南域为观战者所备，上下左右修士不下**数万**，绝大多数只是修道第一步，为陪同家族争夺者与见证仙法而来。
  - **赤红之石**：约**三四百**个，坐者皆战意滔天，为南域发布的**争夺封号资格者**；一百零八个赴雷仙殿名额自其中选出。
  - **白石**：不足十几，坐者为南域各家族老祖，均有赫赫声名。
- **抉择人**：其中三人来自雷仙殿——两名**青袍使者**（神色冰冷、双目雷光闪烁），一名**紫袍老者**（面露沧桑、始终闭目、仿若毫不在意）；两名青袍使者及南域数位家族老祖，对紫袍老者极为恭敬。
- **缺席**：**申公家族老祖**与战家**烈云子**均未到场。
- **场中一战**：两名修士斗得旗鼓相当，终有一人被神通临身、吐血败退，出声认输；青袍雷仙殿使者现身宣布胜者——**李叶胜**。

## 三、南域三杰的心境（本章重头）

战空烈、申公虎、唐言枫合称**南域三杰**。

### 战空烈
- 战家小辈中最优秀者，家族对其本次要求为**前十**；其自评“前十若无意外，自属囊中之物”。
- 与申公虎相视一笑（旧识/同盟意味）。
- 心绪：目睹王林（许木）被姚家追杀的一幕幕后**改变判断**——认为自己此前“看不透许木修为”是错觉，其修为本就止于**阳实**，当是在**雷之仙界**得了奇遇才达阳实，而非隐藏修为。由此涌现**失望**。

### 申公虎
- 尊主（许木/王林）被**姚家**追杀时，本欲驰援，被**申公家族老祖亲自出面阻止**，虽不甘仍屈服，心中冷笑姚家招惹尊主是找死。
- 后续走向出乎其意料：尊主在追杀中一次次反击，致大量修士身亡，获**魔道子**之称；最终在**罗天北域**一场惊天动地之战，使“**许木**”之名彻底震响。
- 但声名赫赫与其印象不符，沉默良久后推测：“恐怕那许木，并非如我想象一般强大……怕是还不如我，即便再精进，也只是与我一样，都是**阳实巅峰**罢了。”（即申公虎自身亦为阳实巅峰）

### 唐言枫
- 坐于另一颗赤红之石，目光阴沉，见此一幕**冷哼**未语。

### 战芸
- 坐于战空烈身后青石，见表哥皱眉即知其又想到“前辈”。
- 认为**前辈之名近日彻底名扬罗天**；每忆**雷之仙界**一幕幕皆极为震撼，**若非前辈带头，自己已然身亡**。

## 四、王林来临

- 王林（本章以化名“**许木**”闻名于世）在距战场**数十万里**外自天地虚无中幻化而出，目光冰冷。
- 情报来源：“**李元**曾说”——南域封号争夺定在地炎星；参与者**须持罗天南域给予的资格令牌**，无令牌不得参战；**一旦开始将封锁方圆十万里**，去晚则不得入内。
- **封锁阵势**：地炎星十万里外每隔千里盘坐一名修士，成环形包围，灵力散出相互连接成紧密联系，一处有变全体立即察觉。
- **孟林**（地炎星孟家族人，婴变后期且停滞已久、始终无法踏入问鼎）被派驻封锁线，因错过观摩仙术而憋闷。
  - 王林于其前方百丈虚空波纹中走出：白衣、黑发无风自动、双目光彩难以言明。
  - 孟林与之目光一触，脑中如无数雷鸣炸响，**元神险些崩溃、灵力涣散欲脱体**，瞬间失去知觉。
  - 王林身影一晃自其身边走过；孟林回神后一无所见，只觉恍惚；此后吐纳却**前所未有地成功**，片刻即沉入修炼（隐有王林无意点化/威压洗炼之效）。

## 五、要点与伏笔

- 封仙 = 战前动员：终点指向**进攻联盟星域**（王林的家乡星域），王林入局的动机张力已埋下。
- “许木修为不过阳实”成为南域普遍误判，与王林一步跨越十万里、一眼近乎击溃婴变后期修士元神的实际战力形成强烈反差。
- 王林尚**无资格令牌**，而封锁已成、逾期不得入内——夺牌/破封为下一步冲突点。
- 紫袍老者身份未明，地位在青袍雷仙殿使者与南域家族老祖之上，为潜在变数。
