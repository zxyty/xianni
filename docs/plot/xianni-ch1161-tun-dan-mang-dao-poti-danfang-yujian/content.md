# 第九卷 云海之巅 第1161章 吞丹茫道

## 一、南苑闭关炼丹

- 莫罗大陆归于平静。王林（此时以化名「吕子浩」立足归元宗、被弟子尊为师叔祖）整日在归元宗南苑禁区炼丹。
- 归元宗弟子时常听到南苑禁区内传来砰砰丹炸之声，但无人敢入，路过时目光恭敬。

## 二、兽骨丹方（涅空丹）研究结论

王林详细研究兽骨丹方后神色阴晴不定，功效真伪暂且不论，仅药材一项就极端苛刻：

1. **药材灭绝**：丹方所列药草绝大部分前所未闻。查归元宗典籍得线索——星变木、龙腥草、碎灭花均为数万年前之物，即便当时也极稀少，如今基本灭绝。
   - 典籍另载：**八阶主宗内似乎还留有一小截星变木**。（后续取材方向）
2. **兽魂要求**：需**九只十三阶巅峰凶兽之魂**融合之后，方可开炉炼丹。
3. **兽骨为引 / 一次性消耗品**：
   - 炼制成功率极低；
   - 必须以刻下丹方的那块兽骨为引，融骨入丹；
   - **每失败一次，兽骨颜色加深一分**；当兽骨彻底漆黑，此丹再无炼成可能；
   - 一旦成功，兽骨消散，成为丹药的一部分。

**当前状态**：手中兽骨虽未漆黑，但已隐隐发暗——显然此前已被人炼制数次且皆失败（否则丹方早已消失），恐怕再用不了几次就会废弃。

**王林判断与决定**：与其说药草与兽魂珍贵，不如说这兽骨本身奇异；且不知究竟是何种凶兽之骨。即便功效为真只有一丝可能，也要尝试。随后将兽骨收入储物空间。

## 三、搜魂毒婆子

- 王林取出与丹方同时发现的玉简，神识扫过后神色古怪。
- 右手在储物裂缝一抓，取出**毒婆子元神**；手指在其元神上连点数下，每点一次毒婆子便颤抖、愈加虚弱。
- 随后右手按其元神头顶，神识横扫而出，施展**搜魂神通**。
- 所获记忆包括：**五毒门的炼毒之术**、毒婆子一生所遇之事，最终定位到有关丹方与玉简的记忆。
- 至黑夜降临，王林把虚弱但仍未死去的元神收回储物裂缝。

## 四、玉简真相：破天宗司马令牌

### 玉简性质
- 内无任何神通与功法，只是一块**破天宗身份令牌**；
- 其内有一个印记——**一万八千年前破天宗掌门大弟子司马墨**的印记。

### 一万八千年前的破天宗旧事
- 司马墨若无意外将是下一任破天宗掌门；
- 但正是他**携兽骨丹方与一部分门人分裂出破天宗**，消失在星域之内；
- 破天宗其时已进入九阶星域，对离去同门心绪极为复杂；得知这部分门人死伤惨重、最终失踪音讯全无后——
- **司马墨的师尊（当任掌门）留下一道传承数万年的封命：日后凡持司马令牌回归破天宗者，则被那一任掌门收为弟子。**

### 封命的后续影响
- 此封命传遍云海，一度引起众多修士关注，为「一步登天」的机会争相寻找失踪门人线索；
- 时间流逝始终无人有半点发现，此事渐渐平息；
- 直到**五毒门在华清宗的探子**汇报了**施洛刑**的举动与猜测。五毒门起初并不重视（时隔太久、线索可能虚假），只派出不多之人前去踏查，**毒婆子即为带队者**；
- 结果谁也没想到，这条线索竟是真的。

## 五、王林的处置

- 「此物，日后我或许会有大用」——王林将玉简收起。
- 不再多想玉简与丹方之事，静心沉浸于炼丹。

# 第1078章 兽魂丹悟道与变异炼兽之法

## 一、清点收获：兽魂与灵蛇

王林此前蛮荒大陆一行的所得：

- **药草**：足量，可供炼丹。
- **兽魂**：大量，多为**五阶**，融入丹药后较适合王林此刻修为。
- **灵兽之魂**：来自**银衣女子**在离开蛮荒大陆后所杀**华清宗弟子**身上收取的魂魄，存于王林储物空间。
- **灵蛇**：**毒婆子**的本命灵兽，已达**六阶巅峰**，同在储物空间内。
- **八阶凶兽之魂**：王林手中阶位最高者，为其瞬杀所得。此魂珍贵，王林当时未加破坏，并取走了**归元宗道观**内的那粒丹药以为配合。

**炼丹结果**：失败三次后，终将该八阶凶兽之魂与丹药融合，成**八阶离魂丹**一枚。

## 二、五毒门·变异炼兽之法（源自毒婆子记忆）

王林搜寻毒婆子记忆，于其炼毒之术中发现一门令他极感兴趣的**变异炼兽之法**。

### 出处与原理

- 由**五毒门**一代天骄呕心创出。
- 以**阵法禁制**形成困牢 → 放入兽魂 → **以毒催使** → 兽魂相互吞噬 → 诞生**变异而成的高阶魂魄**。

### 致命缺陷

1. **吞噬限制**：炼化出的变异兽魂**无法再吞噬普通之魂**，唯有同为炼化而出的变异兽魂之间才可互噬。此点给五毒门造成了很大打击。
2. **成功率低且指数级消耗**：阶位越高越难成。欲成一个**变异九阶**，需大量**变异八阶**不断炼化吞噬；每一个变异八阶又需大量七阶，以此类推。
3. **入药门槛**：偶成的高阶之魂仍需**大量天材地宝滋养**方可入药；入药炼丹亦会失败，**每失败一次兽魂便虚弱很多**。

> 王林亲身佐证：他当初炼成的第一枚丹药，失败十余次才成，其内兽魂已消散大半，丹药效果大降。

### 为何被废弃

五毒门最终因门派承受不住消耗而放弃。**七阶、八阶宗派**亦罕有能承受此消耗者；即便有，以其宗派本身之力**直接去抓**兽魂或许更省事。

## 三、王林的试炼部署

- 计算消耗后王林心惊，但琢磨之后决定**简单尝试**。
- 依毒婆子记忆内的炼毒方法，用**数日**勉强炼出**几份**毒药。
- **地点选择**：刻意避开归元宗，改在**莫罗大陆一处山脉内部**挖出洞府。
- **布置**：大量禁制 → 封印一批**五阶兽魂** → 洒出毒药。
- **观察数日**：兽魂果然开始相互吞噬 → 加持封印 → 返回归元宗。

（判断：此为长线埋设，本章未见成果。）

## 四、吞丹悟道

回归元宗后平静打坐数日，王林开始吞服自炼丹药，**由低阶向高阶**推进：

### 五阶丹药

- 其内兽魂在**王林元神**吞噬下毫无反抗之力，消散于心神并与元神融合。
- 王林进入**奇异状态**：依稀看到**一头头凶兽**自诞生起便膜拜天地、吸收天地精华、感悟规则变化。
- 助益有限，主要作用是**熟悉这种前所未闻的「借兽魂感悟天道」之法**。

### 六阶丹药

- 其内**六阶凶兽之魂**隐有修士**净涅初期**的修为。
- 吞服后王林**意境立起波动**：仿若自身化作一头头凶兽，在悠久岁月中渐渐明悟天地规则。
- 王林沉浸于这「仿若真实的虚幻」中，在无尽驳杂的感悟中寻找自己的道，寻找**真与假之间的存在与永恒**。

### 苏醒

手中只剩那枚**八阶丹药**时（本章未服），王林带着茫然苏醒。

## 五、王林的证道之悟（核心台词提炼）

> 「以一人之力证道，是为点；以众人之力证道，则为面。」

- **云海的丹药并非造化**，而是给修士**一次次追寻道的机会**——以兽魂、以另一种方式去摸索道、摸索天地规则。
- 比之**雷雨两界**，云海此法**缩减了悟道的过程**。
- **局限**：兽毕竟是兽，其所感天道**有所片面**，更**无法清晰追溯本源**。
  - 除非以**人魂**炼丹；
  - 或有那种**超脱了「兽」之一字的存在**，以其炼丹，方可使悟道更清晰直接；
  - 否则只能吞下**大量丹药**，方可寻到自己所需的意境感悟相互印证。
- **类比**：道如同一种思想，每个人的思想都不一样；充实自身思想除自身感悟外，更需**别人的感悟来印证**，取其精髓入自身。**云海修士选择了兽魂，就如同天运子选择了他众多的弟子一样。**

（此处对天运子「以众多弟子证道」的回望，与「点/面」之论互为注脚。）

## 六、章末危机：六阶星域修士压境

王林迷茫之际，**莫罗大陆外**：

- 长虹惯空，临近而来。
- 长虹内是**一个个六阶星域的修士**，展开**严密搜索**。
- 搜索范围蔓延至莫罗大陆，已**踏入防护光层**。

悬念指向：追索者疑与王林在云海星域（含施洛刑、毒婆子一系）的杀戮有关，归元宗恐被波及。
