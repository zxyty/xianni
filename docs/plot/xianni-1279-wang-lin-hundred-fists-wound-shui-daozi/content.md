# 第九卷 云海之巅 第1279章 伤！（第三更）

## 一、王林的一百拳

- 王林以**抱着必死之心**打出一生巅峰的一百拳，拳中蕴含：
  - 他**无尽的生机**（以命换力）；
  - **两千年修道**的全部积累；
  - **全部元力**；
  - **铁剑上那诡秘血球**的所有威能。
- 文本以「飞蛾扑火」作喻：一百拳连同王林在内，如飞蛾以己身去扑灭万古火焰。
- 此非寻常百拳，而是**一切精气神所化**，堪称绝艳，给了水道子巨大危机感。

## 二、水道子的应对与受伤

- 水道子面色凝重、眼露不敢置信——他无法相信「蝼蚁」竟能以生机打出百拳。
- 关键前提：水道子**全部修为都在对抗眉心的七彩神空钉**，否则以第三步大能之强本不会有危机。
- 迎击手段：胸口显化巨大水浪漩涡，化作大口吞噬——**「天地无极，水道吞虚之术」**。
- 交击结果：
  - **王林**：全身鲜血尽失，心脏微弱跳动后碎裂，整个人倒卷，双眼几乎无神。
  - **水道子**：衣衫爆开、道袍碎成碎片、头发散开、面色苍白、嘴角带血——**第三步大能，竟然受伤**。
  - **七彩神空钉**：趁其受伤瞬间无法压制，光芒万丈再度轰鸣，**生生钻入三寸，破开水道子头骨**；水道子喷出的鲜血化作无数符文落于眉心进行封印。
- 余波：轰鸣化作无边风暴横扫天地，六阶星域几近崩溃，星空再无星雾如被破开大洞；环形冲波横扫**云海星域**，星雾崩溃、凶兽死亡、众多**蛮荒大陆**灭绝瓦解。作者标注此威能「即便达到天人衰劫者，也必死无疑」。

## 三、大自在轮回道：灭百世轮回

- 水道子擦血，杀机滔天，宣称：「即便你再新生，老夫也要让你崩灭大自在轮回道，崩杀你前后百世轮回，让你死一百次，看你如何新生。」
- 手段：右手抬起如抽取天地内的**轮回规则**，自成一界轮回道，化作**巨大法轮**在星空幻出虚影，转动砸落——一旦砸中，王林将灭绝一百次，无生还可能。

## 四、神秘老者（风之分身）第一次出手

- 一道风撕开崩溃的战场吹入，苍老声音喝道：**「水道奴，你若杀他，我就杀你。」**
- 水道子的揭底（老者来历）：
  - 曾被**远古仙域大仙**封印全身、化作石头，欲困**十万年**并将其**炼成一件法宝**；
  - 眼下借**蚊兽所在太古外星辰之力**得以残存。
- 老者的反揭底（水道子来历）：
  - 水道子当年在**封界之尊**面前**只是奴从**，见到老夫也要恭恭敬敬；
  - 如今踏入第三步便狂妄至极；
  - 「远古凶仙都杀不死我，唯有封我十万年炼化」。
- 交手：风化巨手抓向法轮 → 水道子喝「**定神术**」，风臂仅一顿便轰鸣冲出，一捏之下**法轮崩溃消散**。
- 水道子瞳孔急缩，失声推断：老者**吸收了太古外星辰本源**，故能硬抗定神术。

## 五、水道子反击：香火献祭崩灭风臂分身

- 水道子后退掐诀，修为爆发，身后显化一颗**巨大修真星**：元力极浓、生机磅礴，**不下一个五星古神**，并有无尽低语嗡鸣化作奇异之力融入其体内。
- 喝出**「二十亿阴阳门徒」**，右手三点，三个**修真星虚影**（如修真星之魂形）冲向风臂。
- 老者冷笑讥讽：「与你本体一样，这二十亿阴阳门徒，也都是一群**不男不女的残缺之人**。」
- 风臂以风之印记硬撼三星崩溃之力，未散但破碎严重，仍冲向水道子眉心按下。
- 水道子似被触动心中脆弱之地，神色狰狞，抓起身后庞大修真星狠狠抛砸，宣称：**「老夫二十亿水道门徒，数万年祭献膜拜化作无穷香火，今日杀你分身，老夫就让五亿水道崩灭，化作我辈第三步香火之力」**，并放言**再去风仙界杀其本体**。
- 结果：五亿水道门徒崩溃身亡所化第三步之力轰出，**崩溃了残破风臂**；老者传出闷哼，**受了暗伤**，风臂烟消云散。

## 六、结尾转折

- 水道子得意：老者来阻，恰说明这蝼蚁重要，故更要杀他；此刻分身已死，无人可阻。
- 状态变化：眉心七彩钉虽只能刺入三寸无法再进，但**刺入头骨内的部分开始融化**，七彩之芒散开，使水道子生出**一丝疯狂**。
- 水道子转身扑向王林、五指张开临近之际——**一根由风组成的手指出现在其眉心之前，狠狠按向七彩钉**。
- 水道子神色剧变，身躯骤顿，无数虚影从体内幻化重叠挡在身前并急退，失声道：**「你竟然还是没死」**（章末悬念）。

## 七、要点与存疑

- **归属说明**：依据世界状态须知，本卷王林自第1063章起以归元宗故人**「吕子浩」**之名立足云海星域（身份由吕烟菲奉上）；本章直接以「王林」叙述，所有言行归**王林**本人。
- **神秘老者身份**：本章仅以「苍老的声音」「老家伙」出现，与**蚊兽 / 太古外星辰**深度绑定，本体在**风仙界**，本章出手者仅为其分身。
- **境界锚点**：水道子为**第三步大能**；王林以两千年修为与生机拼出百拳，重伤濒死但未死。
- **势力数据**：水道子座下**二十亿阴阳门徒／水道门徒**，数万年祭献香火可化作第三步之力，本章一次消耗**五亿**。
