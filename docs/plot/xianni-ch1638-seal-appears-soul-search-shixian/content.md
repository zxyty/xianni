# 第1638章 封印现（第一更）

## 一、搜魂士仙

- 王林右手落下，以磅礴修为凝聚神识如洪水轰入干瘦老者天灵，卷动其体内神识与血肉骨骼。
- 老者体内砰砰作响、七窍流血，在定身术下剧烈颤抖；片刻后定神术略散，痛苦化作凄厉惨叫。老者汗如雨下、面色惨白、双眼绝望，却因王林右手坚硬如山而无从挣脱。
- 老者厉声：「你犯下了弑仙之罪……我是仙尊大人麾下士仙，我有仙人血脉，你今日杀我，他日定会有劫。」
- 王林神色平静，只答「废话不少」，右手再扣，神识冲入其识海，欲获取全部记忆。

## 二、四座雕像的旁观议论

地点：远古仙域深处，大地弥漫诸多雕像，中心耸立**四座巨大的齐天古之三族雕像**。四个声音先后响起：

1. **白虎（嘲讽者）**：「朱雀，你这后裔修为倒也不弱，只是未免太自不量力」——士仙虽不如他们，但具仙人血脉，岂是小小蝼蚁后裔可搜。
2. **沧桑之声（反驳者）**：王林「渡第三步天劫而来，更是从天劫第九太阳内抽出了自己的命运」，此事不可思议却被他做到；反问白虎身为下界之修可能做到。
3. **白虎再言**：仙人记忆有**仙尊封印**，这是**七道宗核心门人**才可享有的造化；王林能杀重伤恢复中的士仙不意外，但去破仙尊封印是自寻死路。
4. **第三个声音**：劝止争吵，并问朱雀——若王林死在仙尊封印之下，对其计划是否有影响。
5. **朱雀**：沉默许久后答「他本就不是我计划中之人，对于他能第一个来到这里，我也有些意外」。
6. **第四个声音（遗憾）**：「此子不凡，他是我这一生见过第一个逆修第三步者，可惜，他是下界蝼修，若是他在我仙罡大陆，此子定会成名」；但他不该去搜魂，**仙尊的封印，我等联手也无法破开**，「他不出半柱香，怕是就会死亡」。

> 四声消散后重归平静。朱雀虽认识王林、知道对方，心中亦暗叹，同样不认为王林能破开仙尊封印。

## 三、识海之内：封印现

- 老者识海内神识自成一界，外围被浓浓雾气严密封锁，阻止王林神识探入。
- **与当年经历相同**：王林搜索**银衣女子**记忆时曾遇一样的雾气封锁，并在雾中见过**那七彩雕像之人**。
- 王林由此推断：「凡是属于那仙尊的手下之仙，全部都是如此。」
- 内外两景对照：外界远古仙域中，王林闭目、右手按住惨叫挣扎的老者天灵；识海内，其神识凝聚化作元神现身，**与肉身相貌一致，一身白衣、一头白发**。

### 王林当年放弃与今日动手的差别

- 当年放弃搜银衣女子记忆：一因修为不足，二因强行破开不论成败都会对银衣女子造成极大伤害。
- 今日对干瘦老者则「不会有半点愧疚」：老者与他并无仇恨、**罪不致死**，若是尚未知晓「界内界外只是一座洞府」真相的王林，本不会杀他；但眼下王林已明白一切，对**洞府仙尊及其麾下所有仙人**怀有难以言说的恨。
- **李慕婉的命运气息失踪**，使这份恨达到巅峰。

## 四、破封尝试：三寸界限

1. 王林一步走向雾气，身影如流星，右手前挥引出狂风化作风暴，卷开雾气破出缺口，一步迈入。
2. 雾中前行，雾气自行分开如通道；踏入深处时七彩之芒骤然闪烁，刺目难视。
3. 雾气深处、被七彩之芒穿透的稀薄处，**盘膝坐着一个中年男子**，闭目、全身缭绕七彩之光，滔天威压使万灵心神颤抖、无法踏出半步。
   - 身份认定：**并非王林在召河七彩界所遇之人，而是他储物裂缝内那七彩雕像的真身**；这是王林第二次见到对方。
   - 本质：**这男子本身就是一道封印**，一道阻止任何人搜寻仙尊麾下仙人的封印。
4. **第一击**：掐诀化出巨大掌印，穿透雾气拍向男子——掌印从其身体「穿过」却无声无息崩溃；细看可知掌印根本未真正碰到对方，而是在其**身体三寸外**瓦解。
5. **第二击**：右手一指，气浪成漩呼啸而至，同样在**三寸外**无声崩溃。王林这次看得很仔细。
6. **第三击（近身）**：亲至近前，双指成剑，眉心**古神星点**旋转，磅礴**吉神之力**融入双指——此时双指可轰开大地、足以轰碎一颗修真星。双指推进至三寸界限之内，即以无法想象的方式急速崩溃：**无痛苦，但可清晰看到瓦解**，瞬间瓦解小半。
   - 三寸之地如同一道界限，一切力量来临皆消散一空；若强行深入，未及碰到对方，右手将全部消散无踪。
   - 王林猛地抽手退后，神色平静，看那毫无伤口的男子与自己失去小半的双指，喃喃「好诡异的力量」。
7. **恢复**：体内古神之力运转融入双指，血肉蠕动，双指渐渐重新长出一截。

## 五、本章结论与悬念

- 有此中年男子身影所化的封印在，想获得干瘦老者的记忆**很是艰难，但并非没有可能**（王林沉吟犹豫，未言放弃）。
- 外部预期与主角判断对立：四座雕像中的仙罡大陆之修断言王林半柱香内必死；王林自己认为仍有可能。
