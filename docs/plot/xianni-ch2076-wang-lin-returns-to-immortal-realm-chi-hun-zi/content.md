# 第2076章 做梦

## 一、王林现身仙界

- 王林以**白衣白发**之身出现在仙界。当年见过他的修士（南云子、蓝梦道尊等）与后来入仙界、只听过其传闻的修士，此刻齐齐认出这位心目中的**封界至尊**。
- 整个仙界如沸腾一般，此前面对赤魂子攻打阵法的压抑与惊慌瞬息消散。
- 王林能在赤魂子未察觉的情况下出现在仙界，众人虽不知其具体修为，但已觉不俗。

## 二、施为：凝身与疗伤

1. **为南云子凝聚身躯**：南云子此前仅存元神；以王林如今修为，可凝聚天地之力化作一具身躯，元神归附后毫无不适。南云子由此确信王林之强，全无担忧。
2. **治愈蓝梦道尊**：蓝梦道尊面色苍白、伤势极重。王林右手虚空一指，四周天地之力齐涌入其体内，片刻即恢复。

## 三、王林与蓝梦道尊：关于李倩梅

- 蓝梦道尊开口问：「我的女儿还好么。」王林沉默、面露苦涩。
- 王林答：**没有找到转世后的李倩梅**。她的印记已消失，应是恢复了记忆；他找了很久始终未果。
- 王林的感觉：她在**仙罡大陆**某个角落，知道他的存在、知道他在找她；只要她散开哪怕一丝气息，纵使王林回到洞府界也能感应——但她**故意不想见他**。
- 蓝梦道尊闭目喃喃后大笑，笑声透出失望与愤怒：「她是为了你才去的仙罡大陆」。
- 王林心境：对李倩梅有特殊感情，此女与李慕婉不同，却是**第二个走入他心中的女子**；此痛与思念李慕婉之痛不同，却同样撕心。他始终记得李倩梅当年在耳边呢喃的一句：「王林，恩，不是情」。
- 王林即便身为仙罡大陆第一强者，因蓝梦道尊当年对他有恩、又是李倩梅之父，始终执晚辈之礼。

## 四、赤魂子破阵入侵

- 血色天空巨响，弥漫的裂缝崩溃，狂笑传来：斥仙界众人为「洞府修士」，扬言破阵后要将众人化作增进修为的**血食**。
- 赤魂子在**数日腐蚀**后终于在仙界阵法上打开一个缺口，其余阵法仍在不断消散，防护将尽。
- 先行涌出的是一道道**血影傀儡**，面无表情悬于天空。

## 五、红袍青年之死

- 一名**红袍青年**（赤魂子之徒）自窟窿迈出，狂言「区区阵法，如今还不是被本少师尊破开」，并扬言待师尊调教**木冰眉**后，要让她知道自己与「那什么王林」的差别。
- 他随即看到：具备身躯、冷笑相望的南云子；目光如看死人的木冰眉；以及盘坐在蓝梦道尊身前的白衣男子。
- 该青年自幼所见的**朱雀星雕像**与此人一模一样，灵魂颤抖使他惊呼「老祖」，仍强撑「就算真的是他又如何，他不是师尊的对手」。
- 王林抬头平静一眼，青年全身剧震。王林收回目光，只道：**「十三，杀了他。」**

## 六、十三出手：极道·极火道

- 十三平素喜独处，本章在空地盘膝打坐，望向王林时目露恭敬。
- 接令后毫不迟疑，踏空而起，右手一挥青烟缭绕——所施为**极道中的极火道**。
- 青烟化数个烟圈扩散，天空燃起汹汹烈火，**所有血影傀儡尽数崩溃、毫无抵抗之力**；一声惨叫后，十三提着红袍青年的头颅冷漠走出火海。火海随其离去瞬息消散，天幕虽仍血红但黯淡不少。
- 背景：王林与十三相遇后，为其择选适合的功法神通倾囊传授，更取天地之力使其修为大进。此举旁人无法做到，但王林**半只脚迈入踏天境**、堪比古祖仙祖，故不难。

## 七、赤魂子现身与金尊海龙

- 窟窿内露出老者身影，正是**赤魂子**，一脸无法置信地惊呼「王林」，旋即狰狞，**空劫**修为轰然爆发，震得天空颤抖、大地震动。
- 赤魂子放言：「你竟从洞府界回来，但就算是你回来了，在老夫面前，也依旧是蝼蚁」，化长虹直扑王林。
- 他看王林修为如一片迷雾，自以为对方不过以法宝遮掩修为（仙罡大陆常见手段），凭空劫之力十足自信。
- 王林神色平静，尚未出手——**刘金彪肩上那条手指粗细的小蛇**凶光暴起，惊天咆哮，震得众修双耳轰鸣，赤魂子身子一颤停在半空、呆若木鸡。
- 小蛇急速飞起，身躯膨胀恢复本体：一条**万丈之长的庞大海龙**，向赤魂子咆哮。
- 赤魂子失声：「金金尊海龙」——感觉自己似在做梦（点题）。

## 八、在场其他人物

- **许立国、刘金彪**：在远处拉着几个仙界修士说话；刘金彪肩上的海龙（小蛇形态）无精打采，被修士摸了一下呲牙，引人轻笑。二人抬头望天时目露轻蔑。
- **木冰眉**：为红袍青年觊觎的目标，本章冷漠视其如死人。
- **南云子**：得王林凝身，全程从容。

## 关键转折

1. 王林归来 → 仙界士气逆转。
2. 寻李倩梅无果 → 蓝梦道尊失望愤怒，此线悬而未决。
3. 阵法破 → 赤魂子势力入侵。
4. 十三一击定局 → 傀儡尽灭、红袍青年身死。
5. 金尊海龙现真身 → 赤魂子攻势戛然而止。
