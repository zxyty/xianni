# 第八卷 联盟隐秘 第891章 仆从

## 一、大头童子的生平回溯（本章插叙）

- **天生畸异**：头大身小，天生呆滞痴傻，脸上常挂痴傻之笑；童年遭同龄族人嘲笑欺辱，母亲对其厌恶异常、毫不理会。
- **被逐出族**：天资无法修道，十五岁被家族驱赶，不再纳入族谱。
- **五百年后归来**：样貌与当年变化不大、仍带痴傻之笑，修为却已达**问鼎**，家族高度重视，纳入族内精英。
- **千年精进**：此后千余年修为突飞猛进，达到**阳实巅峰**。
- **扭曲与虐杀**：童年印象令其性格扭曲，千年内虐杀多名族人，男女皆凄惨而死；出手极谨慎，不留端倪。
- **三十年前弑祖**：一次虐杀终致家族忍无可忍，**窥涅初期的家族老祖**亲自格杀。族人本以为十拿九稳，但大头童子爆发早已隐匿数十年的**窥涅**修为，**老祖亡，大头重伤而退**，从此音讯全无。
- **再出场**：直至**封仙之战**方才现身，在其家族内掀起大浪。

## 二、战斗经过

1. **大头童子出手**：硕大头颅中冲出交错之筋，霸道无匹，兼含仙气与魔气；肉柱前端崩溃化作无数细丝成网状向王林弥漫。
2. **封仙印反制**：王林吐出**封仙印**，金光大盛，数十万金符化作金色漩涡横扫，每落一符成一封印；其中数个**融入修士元神的金色符文**尤为凶猛，一次封印可抵寻常百倍。大头童子瞬间被彻底封印，但旋即以红光挣扎、符文崩溃。
3. **缩地成寸**：王林右脚迈出、脚下波纹荡漾，第二步虚空缩小，一步可至天地任何处，瞬现大头童子身旁。
4. **阴阳双鱼指**：右手双指成剑，**道念与元力融合**，幻化阴阳双鱼之相，黑白二气环绕，穿透层层金符（符文主动让道），按中眉心。大头童子头颅急速缩小，交错之筋收缩。
5. **仙血反击 vs 一字定身**：大头童子喷出直冲王林全身的鲜血，每滴蕴含浓郁仙气，沾身即令肉身崩溃（其修为为**第二步的窥涅**）。王林不闪不避，寒声吐出一字「**定**」——以窥涅初期施展定身仙术已超以往，更兼体内**清水留下化作仙豆的仙元**急速旋转、透出仙元之力融入天地，使定身术达到王林学会以来的最高高度。鲜血与后退中的大头童子一同被定在虚空。
6. **连击落地**：王林避开鲜血，双指再按眉心，大头童子被抛飞、多处爆出血雾；定身余威未散，王林一步追出，三度按下眉心，将其砸落大地，砸出深坑，四周震颤。

## 三、天虎旗喝退罗天修士

- 朱雀星外**数百罗天修士**察觉不妙，破开罡风齐齐降临朱雀星，威压骇人；一见王林即全部面色大变。
- 王林拍储物袋抛出**炎雷子所赐、代表正品雷仙身份的仙宝天虎旗**，虎啸震天、紫气化猛虎咆哮，喝道：「本仙与人切磋，你等在外守护，违令者，斩。」
- 罗天修士中机灵者率先后退，众人陆续谨慎退出朱雀星，不敢参与「两大仙使之间的战斗」，暗自叫苦。
- **影响**：朱雀星修士由此心底明悟——**朱雀老祖王林在罗天修士中地位极高**。

## 四、收服：奴印与仆从

- **威慑**：王林抬手引朱雀星天空雷云，雷光脱云汇入右手凝成雷球，仿若掌天地之雷。大头童子想起**一线天**的胆颤一幕，彻底怕了。
- **求饶**：「许兄，我近两千年修道不易，有话好说，莫要杀我，一切要求，我都同意。」他判断王林全程未施展大神通之术，杀心并未占据全部，知趣或可免劫。（王林此时对外用名「许木」，故称「许兄」）
- **王林的要求**：「我需要一个仆从。」
- **障碍**：大头童子称自己**入升仙池已化去意境，献不出道念**。
- **王林的解法**：另有一术——心甘情愿则不会有半点伤害；心底若有抵触，此术崩溃，施术者立刻身亡。

### 术法来历（关键设定澄清）

- 该封印之术出自**当年得自仙帝青霖的玉简**：玉简除记录**炼制仙卫的方法**外，还有一些**封印操控之术**，并隐约提及**李元的奴印**。
- 王林此前尝试施展，效果远不如玉简所载，事后分析始终无头绪；**直到知晓仙元的存在才豁然明悟**：此类封印之术**必须由仙人施展**，无仙元则无法彻底发挥威力。
- 王林调动体内**仙豆/仙元**，仙力顺右手融入印决，凝成**暗金色印决**，一闪落在大头童子眉心。

### 结果

- 印成之刻，王林感到**只需一个念头，便可让大头童子灭亡**。
- 王林略一沉吟，**知晓了这些封印之术与仙卫的区别**。

## 五、要点与伏笔

- 仙元加持是王林战力跃升的分水岭：同一门定身术在仙元催动下达到前所未有的高度。
- 青霖玉简的封印操控之术自此被真正开启，与李元奴印形成呼应。
- 大头童子由敌转仆，成为王林可随时格杀的战力，其窥涅（第二步）修为不容小觑。
- 朱雀星上罗天修士的退让，坐实了王林「朱雀老祖 / 正品雷仙使者」的双重威望。
