# 第2045章 真身融合

## 一、王林出关：威压笼罩罗眠郡

- 王林在始古一脉计都皇子行宫闭关一百年，本章出关，开始**融合五行真身**。
- 天空涌出雾气如蘑菇般扩散遮天，莫大威压从天而降，大地颤抖。
- 行宫内近千侍卫（皆具不弱古族之力，部分已**成圣、拥有二十七星**）面色苍白、身子颤抖、体内砰砰作响。
- **计都皇子**神色激动：闭关这一百年他从不敢打扰，即便遇生死危机也咬牙自熬；此刻他感受到义父王林的气息。
- **紫袍青年**（此前对王林心存不敬）汗湿衣袍、面如死灰，自陈曾拜见宋天大天尊亦未如此恐惧，认定此人足以与宋天大天尊一比，先前不敬之念烟消云散。
- 大殿中的**少妇**无法起身，额头冒汗。
- 雾气中幻化出一轮火红初阳，光芒扩散、八方雾气倒卷，整个罗眠郡尽被笼罩，郡内始古族人身如凝固。

## 二、原始山始古殿：宋天与董蛮

- 地点：始古一脉皇城外的**原始山**，山顶呈牛角之形；牛角一端建有**始古殿**——始古一脉仅次于祖庙的圣地，传授族人神通之地。今日全山散发磅礴压力，禁人入内。
- 人物：青袍及腰长发的中年男子 = **大天尊宋天**；其身后相貌粗狂的青年 = **皇子董蛮**（宋天弟子，本无法察觉远处威压，借宋天以奇异方式感知）。

### 宋天的判断与顾忌

1. 直指来者为「一百多年前大闹道古皇宫、杀了道古皇尊、来到我始古一脉被你那皇兄供奉、闭关不出的**王林**」。
2. 「这王林为师当年见过一次，还是其师尊**玄罗**带他来此」——评其修为不弱、战力非凡，但「还没有放在本尊眼中」。
3. 认为王林能闯道古皇宫全身而退，是因**玄罗没有出手**。
4. 关键疑点：王林杀了道古皇尊后，**古道大天尊始终没有丝毫言语传出**，令人费解——宋天正因此才没有匆匆选定未来皇尊（也因此始终未指认董蛮为皇尊）。「为师顾忌的，不是此人，而是古道大天尊的想法。」
5. 对真身的判断：「他是在**融合真身**，且这真身有些不凡，他想要完整融合，很是艰难。」
6. 出手理由：王林在始古范围内融合真身却未通知本尊，且已参与**始古皇尊之争**；宋天身为大天尊兼始古守护者，有权处理境内一切威胁 →「说不得，为师要给他一些教训了。」
7. 动作：右手抬起捏印，一指王林威压方向，喃喃**「解封」**，右手幽光一闪。

## 三、古道山的注视

- 古族大地**三脉连接的中心**、拥有近千台阶的**古道山**，其高耸塔楼最顶层，满身被迷雾遮掩的虚影自闭目中睁眼，看向始古方向。
- 良久，沙哑自语：「真身融合。」语气平静，不露喜怒。

## 四、真身融合的过程

1. 行宫上空初阳幻化后天地色变，雾气沸腾转化为黑夜；**黑夜与初阳交替九次**后，行宫内传出一声轻吟。
2. 所有雾气化作闪烁符文，每一符文皆蕴含**禁制本源之力**。
3. 数个时辰内符文越来越多、黑白交替越来越频繁，却始终不见融合，反出现**不稳迹象**：黑白交替减弱、隐隐欲崩溃，大量禁制出现涣散痕迹。
4. 惊天长啸中，行宫冲出**五道长虹**，五虹归一凝聚成王林的样貌——非其本体，而是**五行真身**。
5. 真身初为常人大小、身体虚幻；猛吸一口气，天地之力（即**天地五行之力**）疯狂倒卷入口，身体膨胀至**百丈**。
6. 再吸一口：大地震动、天火隐现、雨水朦胧、草木枯萎、金之本源随之而动，尽卷入口，化作**千丈巨人**屹立天地间。
7. 千丈五行真身双手伸开、五行本源缭绕，使黑白交替平稳、符文禁制不再涣散——**禁制、太初、默灭三大本源**由此暂被稳定。

## 五、凶兽罗眠解封

- 三大本源刚稳定的一瞬，郡地深处传来带着残暴与疯狂的嘶吼，全郡始古族人心神震动、惊慌恐惧。
- 计都皇子身子颤抖、喷出一口鲜血，震撼道：「是**罗眠**！」
- 背景（紫袍青年所忆传闻）：
  - 计都皇子出生时有天地异象，但为**代表大凶之意的虚影**，被皇族隐瞒，由当时的**国师**生生散去；知情者本不多，但近一百多年不知为何在始古一脉重新传开。
  - 计都之所以把行宫建在**罗眠郡**，正因此郡封印着当年**在古祖手中大败的凶兽罗眠**；计都居此可镇压罗眠、滋养自身气运——此为那位**已死的国师**在死前所安排。
- 罗眠现身：天空远处浮出巨大虚影，为一个**圆形肉球、其上只有一只巨大的眼睛**，凶残疯狂，全身虚幻，死死盯住行宫上空王林的五行真身与三大本源虚幻，独目内闪过**贪婪**之意。

## 六、看点与伏笔

- 宋天的「解封」直接把王林的真身融合推入危局：融合本已艰难，此刻又添凶兽罗眠觊觎本源。
- 古道大天尊对道古皇尊之死的沉默，仍是悬而未决的最大变量。
- 计都皇子的大凶异象、国师的临终布局、罗眠传闻的重新流传，三者疑似同一条暗线。
