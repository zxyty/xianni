# 第690章 卸甲（第七卷 名震罗天）

## 一、村庄十年：化凡的日常

- 时间跨度：本章开篇又过去五年（王林携婴儿王平入村已十年），后段再跨六年，收束于王平十六岁。
- 村庄五年内死三老、生三婴，叙事直言「好似轮回，在人们不知不觉中，转动起来」——呼应本卷生死轮回主题。
- **王林**：以木匠身份居于村中，相貌刻意衰老至中年（化凡时的惯常做法，避免惊世骇俗），眼中沧桑，气质奇异。清雪、做木工、熬药，完全凡人化。
- **王平**（柳眉之子）：十岁，体弱如七八岁孩童，但脸色由苍白转为略有血色（王林长年驱怨气+服药之功）。相貌俊俏，村中女童喜爱；周家二丫头来寻他，被他一句「我不在」躲开。
- **孙泰**：屋舍紧邻王林家，越发苍老，终日坐院中望天追忆昔日辉煌。他极喜王平，因王林曾言不让此子修道，故不敢倾囊相授。

## 二、说亲与父子情

- 村中少妇「张婶婶」三年内上门十二次为王林说亲（提及村口赵家女儿「保证待孩子如己出」），王林一律苦笑推拒：「此事，就此作罢。」
- 王平警惕后娘（以村中二虎子为例），王林当面允诺：不给他找后娘。王平饮药自觉甘甜——甜来自心里，来自对父亲的依恋。
- 王平四岁时曾问娘亲何在，看到父亲脸上「低落」的神情后，此生再未追问；他记忆力远超同龄人。
- 冬去春来，村中私塾开办，日子如清水般平淡温馨，洗涤王林疲惫的心灵。

## 三、核心设定与突破：意境升华（生死轮回 → 因果之道）

- **意境**：仙界破碎后修士感悟的一种独特神通；修士所修之「道」即意境所化，根源皆与意境深切关联。
- 意境对每个修士**几乎是固定的**，升华之事极为罕见。
- **回溯解释柳眉之死的动因**：幻家老祖看中柳眉，正因其意境有升华迹象；为此他放弃在修真联盟寻找天逆珠子，立刻带柳眉返回幻家——除了要吞噬，更怕这等人物被他人抢走。
- **王林的路径**：他对生死轮回中「死」的变化感悟极深，对「生」的气息体悟不足，故虽有向因果之道升华的迹象，却始终未彻底转化。
- 这十年他不再执着追求天道明悟，而以父亲的心态注视王平成长；在此过程中「生」的感悟无声凝形，道心走向圆满，生死完善后道念向**因果循环**缓缓升华。
- 评语：此过渡是王林一生修道中极关键、甚至决定日后成就的一环；旁观的大神通修士若见之必震惊，因这是意境的剧变而非简单积累。
- 王林态度：似懂非懂，且**若可选择，绝不愿以这样的代价换取**这个人人渴望的机会。

## 四、孙泰之死与未了之约

- 又六年后的秋天，孙泰大限提前到来，卧于自家房舍，送终者仅王林父子二人。
- 王平已十六岁，样貌与柳眉越来越像，绝世俊朗；双眼如王林般黑白分明。他察觉孙泰早就认识父亲，且骨子里对父亲极为恭敬（从未在言谈表面流露）。
- 王林更显苍老，平静地对床榻上的孙泰说：**「孙泰，当年答应你之事，我会做到。」**——留下待兑现的旧诺伏笔。

## 五、伏笔与看点

1. 王平的怨气仍需每夜驱散，体质问题未根除。
2. 王林承诺孙泰之事内容未揭示，构成后续因果。
3. 意境升华未彻底完成，是后文成就的关键铺垫。
4. 王林承诺不让王平修道，与孙泰想传授所学形成潜在张力。
