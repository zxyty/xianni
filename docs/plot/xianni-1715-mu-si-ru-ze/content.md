# 第1715章 目丝如则

## 一、王林的规则观：丝线即天地

- 规则与法则的区别，无数人冥思万万年而不得；王林亦迷茫，时而以为想通，更多时候在否定此前的猜测。
- 王林当下的答案：**规则、法则、天地的阵法**。洞府界的天地即天道，但天道凭什么决定规则法则、又如何诞生它们，王林不明白——即便他的**战之本源**已化作一道新的规则。
- 王林的具象化理解：规则法则皆无形，若视作有形，便是**缠绕在所有人、所有生灵、所有物体上的一条条线**，一如施展**定身术**时缠绕敌人的模糊丝线。
  - 每一道丝线各不相同，交错组成不一样的**规则**；
  - 容纳在这些规则上的某些**意志**，便是**法则**；
  - 这就是天地，就是天道。
- 对禁制起源的推演：天地初开时最早诞生的一批生灵，从膜拜天地到怀疑、乃至质疑，在这种狂热崇敬中**模仿规则、模仿法则**，诞生出一种术——此术即**阵法**、即**禁制**。
- 因此王林连日感悟的方向，不是禁制之间的差异，而是**追寻自己理解的禁制起源**：若想完美获得禁制本源，必须凝聚出**属于自己、以自身身体为依据**的一道道丝线。

## 二、以目血丝化则：禁制本源初成

触发时机：王林向鬼脸帆斩下一剑撕开帆布、被无穷禁制风暴笼罩的一瞬，他想到了方法——**以自己双目瞳孔内的血丝，化作天地规则法则的丝线**。

- 目标：血丝融入所有禁制后，在双目内诞生一个类似天地的存在——**双眼即禁制本源、即自身规则；思绪即这规则的意志、即法则**。
- 此法**古往今来从未有人想到过，王林是第一个**（胆大、心思缜密、一旦决定绝不轻易改变）。
- 施为过程：
  1. 身前虚幻右目浮现，瞳孔血丝清晰，一声低喝下血丝尽出、无限放大，笼罩崩溃中的大量禁制；
  2. 右手按在左目，左眼幻化而出，身前再成一巨大瞳孔；
  3. 双瞳血丝闪烁弥漫，禁制一一与血丝融合，**半柱香后此地再无半点禁制**，唯余两个缭绕无尽血丝的巨瞳漂浮星空；
  4. 心念一动，双瞳急速缩小消散回双目，王林闭目。
- 收束合体：**本尊三体一晃融合化作本尊**，前迈一步终融为一；散开四周的神识回归体内；与闭目的**分身**重叠凝聚；**六道本源所化长剑**回旋周身缓缓转动，本源气息弥漫使其身形略显模糊。

## 三、第七本源与突破空灵后期

- 星空归于平静，王林盘膝不动，随后一股**空灵中期**的强悍气息扩散并沸腾暴增。
- 六大本源长剑嗡鸣如欢呼——为**第七道本源**而欢呼。
- 王林蓦然睁眼：目光本无颜色，但与之对望者皆心神一震，错觉其目光血红；瞳孔上尽是血丝，交错似天地规则、更似天地法则，**每一道血丝内都蕴含禁制**。
- 规则视野与试手：
  - 王林在星空一扫，看见无数模糊细线（即规则）；
  - 右手一挑一线：远处星空凭空出现一片寒冰、瞬间冰封四周；松指后冰封轰然崩溃，碎冰卷向八方，一巨大冰块直奔王林，在其身前十丈消散无影；
  - 再挑另一条无形细丝拨弄：右侧极远星空轰然崩溃，出现巨大**黑洞**，传出无尽吸撤之力吞噬四周尘埃。
- 凝线成剑：王林掐诀一指点在双目之间眉心三寸外，双眼红芒滔天，血丝改变轨迹、由涣散凝聚，在剧痛中**一眼凝成一道**——红线并非如蟒蛇瞳孔般竖立，而是**横在瞳孔中间**；红芒凝于右手指尖，颜色由鲜红转为**禁制的幽光**。
- 前方一指，幽光闪烁中一把**虚幻长剑**成形，剑内似有无数禁制。
- 此剑出现刹那：王林长发无风自动，体内砰砰作响，全身气息浑然暴增，**自空灵中期直升空灵后期**。
- 修为增长之效：简单一握拳便令四周星空一颤，仿若星空被抓在掌心；起身大袖一甩，**七把本源所化之剑**一一融入体内消失。

## 四、鬼脸帆彻底归属

- 王林虚空一抓，先前被斩开缺口的**鬼脸帆**入手；目光一闪注视之下，帆布缺口以肉眼可见速度愈合，片刻完整无缺。
- 帆上鬼脸依旧狰狞诡异，在此刻的王林看去却略有亲切——**鬼脸帆已彻底成为王林之宝**。

## 五、王林的判词与去留

- 对幻术与禁制的定论：
  - **仙罡大陆大魂宗的幻术，也是禁制的一种，且属于禁制本源的一部分**；
  - 禁制本就是虚假的，如同规则：**你说它存在，它就存在；当你有能力忽略时，你说它不存在，它就不会存在**；
  - 幻与真假类似，却截然不同。
- 自评：以自身明悟的禁制本源**并未大成**，只是以自身为基础衍变而出；真正大成需**把自身化作天地，自身规则成为天地规则，自身意志成为天地法则**——“难，难，难”。
- 决意：鬼脸帆上的**幻禁**还需时间研究，但“是到了该离开这里的时候了”，白发飘摇中身影渐远。

## 六、同一时间：仙罡大陆·仙族之地九天之战

- 仙族之地范围内，九天之上爆发一场罕见大战并轰鸣而起。地面修士修为不够、没有资格知晓，只见这几个月来天空总是昏朦一片，似有雾气缓缓流动。
- 九天之上**血阳高照**，玄罗神色平静。
- 道一之言：“玄罗，你修为比之当年弱了不少，应该也快到了**转世**之时，不知有没有找到**守护之人**，若没有的话，本道可以送你一个。”
- 玄罗之言：“道一，从我进入仙族大陆你就始终纠缠，若再阻拦，我会**杀你道一宗满门**。”
- 道一追问：“杀我道一宗满门……你如此焦急，想来此番进入我仙族之地，必有重事。”
- 玄罗回应：“我玄罗要去的地方，处处都是重事，你让，还是不让”——其不屑耍阴谋诡计，眼中露出寒光。
