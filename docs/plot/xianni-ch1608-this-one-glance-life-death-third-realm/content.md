# 第1608章 这一眼

## 一、幻象散尽

- 一个时辰后，商船前方那虚幻画面渐渐消散。凡人船员心有余悸、纷纷沉默——画面中火山爆发、燃石四散，其中一大片直奔商船方向，仿若可从画面中冲出落于船上。众人分不清真假，只知这是**海灵发怒**。
- 王林靠在船壁上似失尽力气，两行老泪掠过褶皱浸湿衣衫，脑中一片空白，唯余画面中那道**白色的娇影**。
- 王林低头怔望海面：「这到底是真还是假……难道连这个，也是梦么」——扣「真假」「梦」母题。

## 二、出海第九月：海怒之夜

- 时间流逝，出海第九个月的夜里，王林看到大海真正的愤怒：乌云遮天、雷霆轰鸣、闪电交错（几道仿若要轰入海中）、狂风呼啸、海浪滔天，海天笼罩在忽明忽暗中。
- 每一次闪电照亮大海，可见海浪滔滔与剧烈拍击之声，似欲与天雷一争。水手船员在恐惧与生死间发狂般操控商船。
- 王林死抓长杆，衣衫尽湿、白发滴水，双眼却**明亮如辉**，心胸在这一刹那无限扩大直至足以包容天地。
  - 长笑：「这才是天地之力，这才是真正的道理……这才是无情的万象」
- 他从挣扎的凡人身上感受到一股**不甘心**，只是微弱，在风雨海啸下微不足道。
- 一次大浪拍击，商船**帆杆被折断**轰然落下，砸中一名躲闪不及的船员（伤势不重），该船员挣扎爬起继续拉船绳求生。船如孤叶，绝望气息弥漫，王林亦不再死抓船杆，不顾老迈与水手一同在怒海中反抗。

## 三、海谣：朱雀星恒古流传的逆音

中年船员起头，少年接续，众人汇成一股「生命的最强逆音」：

1. 「莫要放弃，我们还有力气」
2. 「莫要绝望，我们还有梦想」
3. 「莫要气馁，我们还有明天」
4. 「莫要屈服，我们还有不甘」
5. 「莫要闭目，我们还要去看骄阳」

附白：「天地浩荡，但却遮盖不住我们的求生之声，我们出海为生，我们何惧死亡。海灵之怒，可以让我们惊恐，可以将我们淹没，可却无法阻止我们的海谣。」

此为朱雀星的海中**恒古流传**的歌谣，透出不屈、对生的渴望与对死的无畏。

## 四、悟道：逆意之源与生死三境

王林心神一震，醍醐灌顶——他此前于**因果、生死、真假**始终迷茫，此刻明悟：

- **逆意之源**：逆意生于生与死之间，因有不甘心、有不屈服，才有逆；若无不甘、无不屈，便没有了生与死之别，「生则生，死则死」。
- **生死三境**（如山三看的变体）：
  - 第一境：**顺生顺死**——看生是生，看死是死。
  - 第二境：化作**逆意**——看生不是生，看死不是死；在逆意下轻蔑生死，方可说出「生亦何欢，死亦何惧」，此为置之死地的决心，但**绝不是看透**。
  - 第三境（王林所追寻的道理）：既非看透、也非超脱，而是**一句话**——此句在王林脑中弥漫，却似隔一层膜，说不出口。
- 关键判词：世人常言看透生死、看破生死，实则根本没有看透，生死也不可能看透，至多只是**看轻生死**。

风浪渐退，天雷消散，一夜漫长过去，初阳抬头，船上响起劫后余生的呼喊。王林坐在船头微笑，望见海天尽头初阳中那只**白色的飞鸟**飞舞嘶鸣（呼应前文白影意象）。

## 五、登陆异陆·十九年游历

- 出海第十一个月，海的尽头遥见大陆，船上欢呼。王林在黄昏中与相伴近一年的船员挥手告别，带着海谣离船登陆。
- 该大陆与其家乡（赵国一侧）隔着大海，其上有诸多凡人国度、众多宗派与「似曾相逢」的修士。其中一国名为**火焚国**。
- 王林此生未至此地，但其名在十多年内已传遍很多地方、亦传到这片大陆（虽不如家乡赫赫）。他如旅者般走过一处处山水、国度城池。
- **转眼三年**；自离开赵国已过去**十九年**。身体不如以往，升起疲惫，手拄拐棍仍坚持前行。
- 声名：不论哪国哪派，人们都知有一个叫**王林**的老人，为**当代大儒**，周游列国似在寻找什么。年愈老迈话愈少，往往不必说话——只用蕴含天地的睿智双目看人一眼，便令对方迷茫在那天地中不知苏醒时。

## 六、第十九年秋：这一眼

- 王林来到一处遍布火山之地，恰逢火山爆发，远处黑烟滚滚，热浪自远方扑来。他抬头望向天幕尽头黑烟，沧桑双目透出**从未有过的柔和**。
- 黑烟内走出一道白影：一名女子，**青丝披肩，样子很美**，手中拿着一个**玉瓶**，似正从火山爆发中收取某物。转身之中，她看到了远处地面上的王林。
- **这一眼**让王林难忘、身子一颤——仿若等这一眼等了一千多年，仿若等了一辈子，仿若来到这里就是为了等这女子如今的回眸一望。

## 七、伏笔与待解

- 生死第三境的「那一句话」尚未说出（隔膜未破），是后续悟道的直接钩子。
- 火焚国火山处的白衣持瓶女子身份未明；其形象与此前幻象中的「白色娇影」、初阳中的「白色飞鸟」构成同一意象链（疑指向李慕婉，正文未点破，不作断言）。
- 王林当前为凡人身老迈之躯，在朱雀星凡间行走第十九年，以「当代大儒」之名为世人所知。
