# 仙逆 第1073章「拼」（第八卷 联盟隐秘）

## 一、场景与前情
- 地点：海面之上，黑夜将尽、骄阳自海面尽头升起之处。
- 在场：王林（施法者，本章不直接露面而以神通显威）、虚空子、以及三具天运子分身（灰衣、黄衣、紫衣，另有蓝衣天运子登场）。
- 前情：王林在仙帝洞府内被一路追杀而出，最终落入**天运子与古魔塔珈的计算**，被迫成为其帮手；心中积压不甘与愤怒之火，本章借神通爆发。
- 虚空子状态：**天人第一衰**已失败，被打上不断消散的烙印，本已弥留，全靠**古魔塔珈**留在其眉心的**古魔印记**续命。

## 二、核心神通：海日生残夜
- 名目：**残夜之力／海日生残夜**（王林的残夜神通）。
- 机理：借海面骄阳真正升起的刹那，引动**初之规则**（天地一切规则之初始），万丈阳光摧毁一切阻挡之力，撕裂黑夜使其崩碎倒卷、天地被明亮取代。
- 加成：因**王林朱雀二次觉醒**，骄阳升起瞬间迸发至极炙热，热量**远超王林神通可释放的全部**，借骄阳本身蕴含的火热疯狂放大。
- 效果层级：不止撕裂黑夜，更要把黑夜、天空、大地一并粉碎，将天地一切**烘干成灰**。
- 附加：其中蕴含王林滔天杀机与压抑已久的愤怒。

## 三、虚空子之死（本章关键转折）
1. 首当其冲——距离最近。
2. 双腿在砰砰声中率先崩溃，化作元神之雾，雾气一现即被万丈阳光消散，半点不留。
3. 眉心古魔印记仅阻挡数息便轰然崩溃。
4. 惨叫回荡、拼命后退，但残夜之力下天地无退避之地。
5. 身子被阳光疯狂穿透，「整个人就如同一个筛子」，带着惨笑与绝望**烟消云散**。
- 定评：碎涅大圆满的至强神通者、修真联盟地位赫赫、重玄子师弟，一生叱咤风云、葬送英豪无数，终究**逃不出轮回、逃不出天人第一衰、逃不出亲手埋下的恶果**。

## 五、本章收束
- 三人（分身）神通尽被摧破，已至**困兽拼命**的程度：若不破开这足以令其形神俱灭的神通，便毫无生机。
- 灰衣天运子明确判断：今日若不拼命，将在此神通中形神俱灭。

## 六、设定要点提炼
- **初之规则**：天地一切规则之初始；日出（初阳诞生）为其显化契机。
- **天人第一衰**：失败者会被打上不断消散的烙印，本章直接导致虚空子无法幸免。
- **一指天运**：天运子本尊功法，本章由黄衣分身持有并施展为「天运一指」。
- **天运宗吞噬之人**：紫衣分身可召其化作煞气厉鬼作战，印证天运宗万年吞噬之实。
- **天运子分身体系**：至少四具（灰、黄、紫、蓝）分色分身，其中灰衣已具独立神智与独立元神。
