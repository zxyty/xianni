# 仙逆 第634章 自找苦吃

## 一、场景：潮汐深渊地缝下沉

- 五人小队（王林、杜建、慕容卓、赵依萱、徐飞）在地缝沟壑内小心向下飞行。王林不居最前，靠右侧下沉，一路观察缝壁。
- **缝壁特征**：极为光滑，如利器切开；手触之有冰冷顺指入体。
- 越向下越阴暗，但修士以仙力凝聚双目仍可视物。
- 越深，分支裂缝越多，形如树枝分部，每条支缝如洞穴般幽黑，部分连仙力凝目也看不清深处。

## 二、分头探宝，一无所获

- 杜建率先停下，提议：「这些缝隙内说不定有宝贝存留，越往下裂缝越多，各凭本事。」随即飞入一处裂口。
- 慕容卓略犹豫后飞向另一裂口；赵依萱笑问王林是否也去看看，王林摇头，径直向下。
- 赵依萱转身探入一旁裂口，徐飞紧随其后。王林回望二女，心中生疑：「此二人身上，为何我总是感觉一丝古怪。」
- 五人重聚，彼此皆无收获。

## 三、王林的情报优势（贝罗水晶）

王林独行下沉期间验证了两条关键情报：

1. **底部结构**：贝罗的水晶亦无法看透潮汐深渊底部，只知下方有一巨大**回廊**，与另外**五个入口**相连，**出口只有一个**。
2. **只进不出**：王林试着向上飞，立刻感到上方传来重压，验证「入口只能进不能出，强行外出阻力越来越大」。

他还判断：无数年来此地来客不少，那些分支缝隙即便曾有宝物，如今恐怕早已空空——因此对沿途裂缝只一扫而过。

另据水晶预查，下沉**百丈**处是他标记的「很难跨越之处」之一。

## 四、古树预警

- 慕容卓先行归来，向王林点头，忽道：「王道友，此地很熟悉。」
- 王林直言提醒：「下方百丈，有一处生长在石壁上的古树，此树很古怪，慕容道友要小心。」慕容卓一怔点头。
- 该树一人多粗、形如枯树，根须大半悬浮、部分深入缝壁，如帘幕般恰好盖住一道缝隙。沿途同类古树有七八处，**唯独此棵**让王林（水晶查看时即）生出危机感。

## 五、诱饵：假「天运佩剑」

- 缝隙内一抹紫光，来自一把刺入墙壁的古朴飞剑，锋利之气外露，不似凡物。
- **杜建失声**：「天运佩剑！」并解说来历：
  - 师尊**天运子**共有**七把佩剑**，分赠**天运七子**作为法宝；
  - 无数年来共有**三系佩剑随人失踪**；
  - 此剑应是**孙云**成为天运七子后天运子所赠的**紫系佩剑**；孙云叱咤之时，杜建还只是天运宗寻常弟子，尚未被收入**赤系**。
- **让剑**：杜建向慕容卓、赵依萱、徐飞抱拳讨面子，主张此剑归王林——「他是我天运宗紫系弟子，物归原主，且有此剑，他在紫系的身份立刻不同」。慕容卓（眼中掠过一丝古怪）只答「无妨」，二女亦无意见。
- 杜建更以谦辞铺垫真诚：「杜某修为比你低，但入门早，称呼你师弟，不要介意……此剑是你的，师兄不会去抢，也绝不允许任何人去抢，只希望此剑在你身上能发出与当年孙云一般的光芒。」

### 破绽
- **徐飞的眼神**：众人顺着紫光看向裂缝时，唯独徐飞看的是那棵**毫不起眼的古树**，眼中微不可查地闪过一丝冷意——被王林冷眼捕捉。
- 王林看杜建「就好似在看一个玩弄低劣诡计的幼童」，笑着道谢。这笑令杜建心生不妙。

### 杜建的算计与轻敌
- 杜建此前**曾独自来过一次**，但非亲身从入口下来，而是**操控一个融入神识的傀儡**进入；傀儡在此遭古树攻击，那一幕吓得他很久不敢踏入**云雾山海**。此番寻到慕容卓等人后才再度前来。
- 他自信王林看不穿：古树太寻常，且沿途同款古树均无攻击性。
- 他轻视王林出身：一个从**半废弃星球**来到**天运星**的土包子，若非运气好岂能被天运子收为弟子。

## 六、王林破局

1. **取剑**：一拍储物袋放出**弯刀**，黑芒一闪直入缝隙，速度快到古树似乎都未反应过来，一卷将飞剑取回手中。
2. **验伪**：一捏之下，飞剑砰然崩溃化作碎片，紫光随之消散——**分明是一块凡铁**，被人故意做成法宝模样扔在裂缝内，设成陷阱。
3. **反击**：王林心念「这里是残酷的修真界，过于软弱的下场是死亡」；他一生极少主动招惹别人，但被人招惹则毫不留情。
   - 脚步前踏，右手虚空一抓化作狂风扑向杜建。杜建大变色急退并喝问「王林，你这是何意！」
   - 此地并不宽阔，以杜建修为，纵使**瞬移**也无法在王林**问鼎道念融于神通**之下躲避。
   - 罡风一挥，虽因杜建身有**天运子所赐保命之物**而无法杀死他，却把他的身子直接卷向**古树旁**。
4. **古树真相**：刹那间古树发出刺耳嗡鸣并崩溃，化作**无数手指大小的飞虫**，如浓云般冲出——所谓古树，实为大量飞虫聚集幻化而成。

## 七、要点归纳

| 项 | 内容 |
|---|---|
| 地形 | 潮汐深渊地缝，壁滑如切，分支裂缝如树枝；底部有回廊连通五个入口，出口仅一 |
| 规则 | 入口只进不出，逆行阻力递增 |
| 诱饵 | 伪装成孙云紫系天运佩剑的凡铁 |
| 机关 | 伪装成古树的飞虫群（沿途另有七八棵无害同款） |
| 主谋 | 杜建（曾以神识傀儡踩点，知晓古树杀机） |
| 疑点 | 赵依萱、徐飞二人「古怪」；徐飞盯古树并露冷意，似知情 |
| 结果 | 王林识破验伪，反手将杜建卷入古树杀机，飞虫群爆发 |

## 八、遗留悬念

- 赵依萱、徐飞的真实身份与目的（王林两度察觉古怪，徐飞疑似知晓陷阱）。
- 慕容卓「此地很熟悉」的来由，及其听闻让剑时眼中掠过的古怪。
- 飞虫群爆发后的战局，以及杜建保命之物能否奏效。
- 深渊底部回廊、唯一出口的下一步探索。
