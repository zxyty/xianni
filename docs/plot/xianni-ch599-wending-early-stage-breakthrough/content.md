# 第599章 问鼎初期

## 一、问鼎境的原理设定

- **炼化机制**：意境与仙力的融合本质是一种"燃烧"——以仙力为燃品，炼化意境，凝成一粒"问鼎之晶"。
- **问鼎之悟**：问鼎之晶炼出的一刹那，会有化身虚无、神游天地的感悟，极为难得，称"问鼎之悟"。
- **抽回命魂**：修真星上的修士达到问鼎，惯例第一件事是以问鼎感悟之力抽回命魂，几率仅一半，却必须尝试。王林命魂早已收回，故跳过此步。
- **茧与火之喻**：元神＝巨茧，意境＝茧中之灵，仙气＝茧外烈火。火越盛，茧越具灵性，意境与之结合越深。最终目的是元神与意境融为一体——**此后元神即意境，意境即元神**。
- **生死关卡**："朝闻道，夕死矣"为所有问鼎共知之语。若过不了这一关，无形之火化为实质，从里到外将元神与肉身一瞬焚成灰烬。
- **意境人体**：问鼎期修士的元神就是意境，实质化、与肉身无异，问鼎之晶在其内散出元气流转，是"真正的意境人体"。

## 二、元气与练气士（远古设定）

- 意境融化后化作混沌之气，远古时期称之为**元气**。
- 远古无"修士"一词，修炼者自称**练气士**，所修即元气；**昆仑练气士**是远古修炼者的典型代表。
- 远古之法：元气不留元神内，而是抽离出来，取代全身仙力。
- 仙界在虚无中出现之后：修炼者为成仙求长生，改以元气为**本命真气**，外裹仙力——遂有"但凡一口真元尚在，便不会身亡"的上古修士与仙人之说。这"一口真元"即元气。

## 三、王林的突破经过

1. **焚玉聚气**：王林于洞府盘坐，身周铺开储物袋内全部仙玉；仙玉被榨出最后一丝仙力后化作碎末，此地无风，碎末如石灰铺地。大量仙气自汗毛钻入，渗入经脉，向元神内的**生死轮回**意境凝聚。
2. **仙火不熄**：火将黯淡即有新仙气涌入，如风吹火草。以神识观之，可见王林全身散发火焰的惊人画面（肉眼不可见）。
3. **卡在结晶**：意境全化元气，元气凝作一滴晶莹水液、变化各形，却始终无法结晶——不结晶便无问鼎之晶。
4. **孤注一掷**：王林深吸一口气，四周仙玉砰砰全碎，最后的仙力如烟丝自鼻而入，仙火烈度暴增数倍，仿佛七窍喷火；汗出即化水汽，头顶白汽越来越浓。元气水液终于开始结晶。
5. **险死还生**：结晶将成一刹那突然一颤，牵动元神之茧；茧动则外围仙火崩溃外散、不再炼化，无形之火转向实质化——**问鼎将要失败**。
6. **周佚之晶救场**：王林肉身丹田中、周佚此前赠送的另一粒问鼎之晶浮现，飞入仙火。仙火不但无法波及它，反因它靠近而略黯（似能熄火）。该晶无阻碍融入元神之茧，停在王林的问鼎之晶旁，绕行一圈后**蓦然崩溃**，其内元气尽数被吸入王林的问鼎之晶。
   - 两晶意境对照：王林＝**生死轮回**；周佚＝**至死痴意**。
7. **暴涨与包容**：王林的问鼎之晶从指甲盖大小暴涨至小手指大小；茧不再晃动，仙火不再实质化——看似轻描淡写，实为生死一线。茧随即收缩，将晶完全包容，内里酝酿新生气息。

## 四、十年闭关与出关

- 王林盘膝洞府，**十年一动未动**，好似石人。
- 温养结束，惊心动魄的气息自茧内散出；茧上裂缝渐生渐多，最终碎裂。灰色光芒中，一个**实质化的新元神**缓缓飘出，与肉身几无区别。
- 碎茧融化为滋润元神的养分，被元神吸收殆尽；元神盘膝坐下的刹那，王林肉身一震，**十年来第一次睁眼**。
- 王林轻声自语："问鼎。"双目闪烁明光。**修道七百年，终达问鼎修为。**
- 层级评价：问鼎放在任何一个六级修真国都是顶级存在；即便在更高级修真国内，问鼎修士亦是强者。
- **伏笔**：问鼎感悟静坐的这十年，王林"另有收获"（本章未展开）。

## 五、外界十年（妖灵之地侧写）

### 天妖郡·天妖城
- 天妖城已于十年前重建完毕，大小规模与当年之城一模一样；**帝部**依然耸立，天妖门下**万丈广场**仍在，广场上的**巨大妖鼓**还在。
- 十年前居民避过一场浩劫，情形终生难忘；城中关于"一个叫王林的修士"的传说遥遥流传不绝。

### 燕京·阁楼上的青年
- 当年的画舫已不在，画舫上的人也已消失（"许是不再弹琴了"）。
- 曾与王林把酒整夜的青年，此刻在**燕京**一处阁楼上遥望天边，身边站着一名相貌美丽、带调皮之色的少女（叙述打趣：许立国若在，定会扑上去大叫"小美人，你家许哥哥又回来了"）。
- 青年喃喃："十年了，那个小家伙彻底失踪，就连五个祖爷联手以神识查看，也无法找到此人的踪迹，好似……好似他离开了这妖灵之地一般。"

### 天妖郡·地城·地副帅府
- 地城新建后，东首临中之处有尊荣府邸，牌匾四字"**地副帅府**"；府内仆人无数、假山处处、幽静典雅。
- 一名身穿帅袍的大汉立于假山后院望天，身后三名妖将铠甲者恭立不动。大汉深叹："王兄，你到底去了何处……"

## 六、关键转折

- 周佚赠晶成为王林渡过问鼎生死关的决定性外因——此前的赠予在此章兑现因果。
- 王林境界正式踏入**问鼎初期**，且十年感悟另有所得，为后续埋线。
- 妖灵之地各方（燕京青年与五祖爷、地副帅府大汉）皆在寻找失踪十年的王林。
