# 第1583章 仙人不灭体！

## 一、二仙妃合击：琴音 + 占卜预测之术

- 一名仙妃施展**占卜预测之术**，此术与天运子的计算之术类似，但在其手中大不相同：话语一出，王林身上即浮现拳头大小的黑色圆圈并迅速溃烂。
- 三句预言，三重杀伐：
  1. 「我预测你第一息，**肉溃**」——黑圈深透体内，可见森森之骨，骨头亦转黑碎灭。
  2. 「我预测你第二息，**骨崩**」——全身骨骼（含头骨）现无数黑色裂缝，部分直接碎灭。
  3. 「我预测你第三息，**魂亡**」——魂在剧痛下隐隐要崩溃。
- 另一名仙妃以**古琴**弹奏，铮铮琴音与温柔话语融合，冲入溃烂黑圈中撕扭。
- 战法评述：一方乱心神、一方以奇异神通逼近，**环环相扣，显系提前计算**。

## 二、王林的处境与「那把弓」的克制

- 王林本已重伤，五脏消散（承前一仙妃的五脏奇术），体内**排斥之力**暴卷、仅勉强控制，此刻已处**弥留之际**。
- 他始终**未取出那把弓**：自知只有射出**一箭之力**，若这一箭不能重创掌尊及所有人，便是真正的死亡。
- 判断依据：**掌尊尚未现身**，他不信这两个仙妃就是最后之人。「不到最后关头，那弓，不能拿。」

## 三、转换：半成的仙人不灭体

- 魂将崩溃之际，王林**右手狠拍眉心**，全身轰鸣，金光万丈。
- 此身来历：在**幽冥兽体内之界**，其身是**道古与仙体的融合**，经不断交错、重新凝聚、多次转换而成；其仙体在**那疯子**的折腾下，已成**半成的仙人不灭体**——虽不完美，但这血脉仙力凝聚的不灭体已具**不灭之力**。
- **代价**：一旦古神之体与仙体转换，对排斥之力的压制就会崩溃，排斥之力将完全爆发，如脱缰野马再无法收服。非危急绝不为之。
- 转换后：**古神肉身消散，隐藏于眉心一颗星点之内**；身躯焕发无尽金芒。金光向八方凝聚笼罩天地，连远处的**朱雀星**都被照成一片金色。
- **不灭表现**：占卜之术在体内爆发，不灭体直接崩溃——但金光一闪，**再次凝聚**；如此连续数次。占卜女子的占卜之术反被摧毁，喷出虚幻鲜血、连退数步、波及其神。

## 四、身份震撼：万仙叩拜与「仙天皇」

- 占卜女子来自**仙尊的世界**，见王林之变想起**一个传说**，惊呼：「**仙人不灭体，万仙叩拜！**」
- 其连声追问：「你不是这里的**土人**，你到底是谁，你与**仙天皇**是什么关系？」
- 其恐惧之烈，**比当年面对仙尊还要浓郁无数倍**，脱口而出「不能杀，不能杀他」。
- 弹琴女子亦琴音戛然而止、双手一颤。

## 五、反击：残夜之术与流月之术

- 弹琴女子权衡后仍决意动手——其身上**阴月**之晴愈发扩散，若不杀王林，**阴月宗之术**不但会毁其投影，更会连累其**本尊**；并判定「他这仙人不灭体不完整，显然是偷学而来，杀！」
- 其喷血拽琴弦，化出**九把血色飞刀**（模糊飞刀与鲜血融合）直奔王林。
- 王林双目血红、掐诀挥手，身体再次崩溃却仍将神通打出：
  - **残夜之术**（王林自创第一式神通）：天地一暗如被阴森笼罩，远处水面有一轮**初阳抬头**，身体与初阳融合，金光一散，爆发撕碎黑夜之力。
  - **流月之术**（王林自创第二式神通）：水面内巨响回荡，浮出一扇**巨大石门**，弥漫**岁月流逝**的气息。
  - 二术在仙体不断崩溃重组中**融合仙力**，威力更大。
- 战果：九把血色飞刀直接崩溃四把，余五把被流月之术弥漫消磨，最终仅**三把**刺入王林体内，随其崩溃的身体一同粉碎。
- 占卜女子先被残夜之力笼罩、又被流月弥漫，本就心神震动、**道心有了破绽**，当即喷血后退，**无心再战**。

## 六、转折：虚神天尊现身

- 王林身后天地内走出一个**模糊身影**：看不出男女老少，全身由模糊雾气所化，雾气如烟丝般向外飘散。
- 其自报名号：「**老夫太古五尊之一，虚神天尊。**」
- 抬手一掌狠拍王林**后心**：王林剧震、喷出一口**金色鲜血**，化作金虹被抛飞，轰然落在**朱雀星**上。
- 该身影张口吸食王林喷出的金色血液，**双眼露出贪婪**，化作云雾追去，放言：「**仙人血脉，不管你是什么身份，你这不灭体，老夫要了！**」

## 七、旁支线索

- **冰封中的白衣男子**此章消散冰层走出，面色苍白，刚出便被王林的金光刺目，神色再变。
- 掌尊仍未现身，构成王林保留最后一箭的直接理由。

## 八、待验证/留疑
