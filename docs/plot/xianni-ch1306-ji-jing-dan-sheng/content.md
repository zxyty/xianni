# 第九卷 云海之巅 第1306章 极境诞生

## 一、极境的推演
王林面色苍白却目光愈亮，隐隐把握住封界之主所言——**天劫为劫，亦为造化**。

他推演天劫层级：

> 九为大限 → 九宫 → 八卦 → 七星 → 六合 → 五行 → 四 → 三 → 二 → 一

- 「四」「三」他当时尚不知为何（后文揭晓为四象、三才）；
- 「二」必是阴阳（两仪）；
- 从九至二层层衍变所化的「一」，王林怀疑即是**天之极劫，也就是极境所在**。

他不敢十分确定，但不甘心不拼一次、不亲眼看一看那「一」是否就是渴求已久的极境。

## 二、七星之劫：拒绝相助
远处妖宗太上长老神色变换——宗主临终未提应劫之人身份，但从遗言与那**玉佩**看，此人与宗主关系绝非寻常。他正欲出手替王林抗下七星劫难。

> 「前辈不需相助，此劫，在下一人对抗」

七星带滔天杀气轰然降临，七道星光落体，王林鲜血弥漫、元神震动、连连后退，却挣扎抬头长笑：七星入体刹那与体内**八卦、九宫**产生联系，彼此运转化作更毁灭之力，要崩溃其全身——但王林在这力量中**隐隐感受到一丝极境的气息**。他对极境颇为熟悉，早年极境曾伴随他数百年岁月。

## 三、六合龟甲与护住李倩梅
王林任由四面八方所化**龟甲**轰然撞击己身，全身血肉模糊，却**全力保护藏匿李倩梅之处**。

- 古神肉身、尤其是**六星古神肉身**强悍难以形容，在此打击下仍疯狂恢复；
- 龟甲融入体内，与七星、八卦、九宫融为一体，在元神内爆开；
- **元神崩溃，但被王林死死锁在体内，没有消散。**

## 四、五行掌印：吞火重塑元神
王林双眼涣散仍目光坚定，挥手吞下大量丹药。五行掌印来临之际，他**等的就是这一刻**——上前一步，张口直接吞噬滔天火掌印：

> 「天地之火，融我之身，塑我元神」

- 无尽火焰化热浪横扫其崩溃的元神，元神**重新凝聚**；
- 元神内更有**火之本源**出现，形成漩涡环绕，疯狂吸收火掌印之力；
- 金、木、水、土四掌印落体，留下四道痕迹，冲入体内展开崩溃。

王林低吼：「八卦离火，震雷，给我捍卫肉身」——此前一直隐藏于体内的**离火卦、震雷卦**被其操控爆发，弥漫肉身对抗掌印，**出乎天劫意料**。

在古神肉身恢复、王林修为、八卦两阵与五行火掌印之助下，他**生生抗住五行崩灭**，于九宫、八卦、七星、六合、五行中未死。擦去嘴角鲜血后向天劫漩涡咆哮：「还有没有」

## 五、四象无量：朱雀归位与第三次觉醒
模糊之声无喜无悲：「四象无量」。天劫漩涡内兽吼连连，**青龙、朱雀、白虎、玄武**——**天劫四灵**依次踏出。

王林长笑指向朱雀：「原来是四象——朱雀，归位」

- 朱雀通体一颤，冲出其余三灵直奔王林，环绕其身兴奋嘶吼；
- 王林**六星古神肉身上幻化出朱雀之纹**，相互辉映，朱雀冲入其体内，火焰轰天；
- 朱雀融体后滋润全身、修复元神，使其有力量迎接其余三灵。

### 火之道的层级（本章设定要点）
王林体内朱雀**已觉醒三次**，每次觉醒使其对火焰之力的明悟暴增：

| 项 | 内容 |
|---|---|
| 现状 | 对天地之火掌控达到不可思议境界，**诞生本源** |
| 效果 | 一切火焰神通在其面前屈服；可引动修士体内火焰神通，**杀人于挥手间** |
| 局限 | 这一极限**仅指实火** |

**火分两种**：
- **实火**：实质之火，包含众多；
- **虚火**：诡秘，远超实火；除非实火修至极限，否则断不可能摸索虚火境界。

**怒火**即虚火的一种：无实质形态，却可超过天地一切火焰之威——它是一种**道、一种精神、一种意境**。若朱雀第四次蜕变觉醒达虚火境界，即便不修火焰神通之人，也会被王林燃其怒火、自焚而亡。天下一切火焰中，人之最强便是怒火：人人都有、无形却存在，一旦被燃且驾驭不住，必死无疑。

> 吸收八卦离火 + 五行火印 + 天劫四灵朱雀之火后，王林**距第四次觉醒只差一丝**即可冲出实火范畴。

## 六、三才无量
三才 = 天、地、人，对应日、月、星（天为日、地为月、人为星）。虚无一变如同混沌：

- **天（日）→ 阳**：散发无尽「初」之规则，万灵之初；
- **地（月）→ 阴**：蕴含与初迥异的「末」之规则；
- **人（星）**：融入混沌，凝聚出王林从未见过、不属于初与末的第三种规则。

三道日月星光芒直奔王林：**天之光穿透眉心，地之光穿透胸口，人之光分成四份贯穿四肢。**

## 七、两仪无量
两仪 = 阴阳之力、生死之力、**亦是因果之力**，天地间一切存在无不包含在内。

> 两仪生四象，四象化九宫，更与三才相互映衬。

巨大**太极图案**以王林为中心幻化，疯狂旋转、骤然收缩覆盖其全身。六星古神肉身也承受不住这毁灭性力量，血肉模糊、鲜血弥漫。

**关键**：李倩梅未受丝毫伤害——**此天劫只对王林一人而杀，余者毫不理会**。

## 八、一劫无量：极的诞生
在王林肉身将崩溃之际，模糊之声缓缓回荡：

> 「一劫无量，劫之起」

虚无好似毁灭，光芒凭空出现——**九宫、八卦、七星、六合、五行、四象、三才、两仪统统出现**，彼此环绕，自其内诞生出一股**天道极端之力**。

**这，是极。**

王林虽重伤，但**道心、道念、意境**犹存，其体内随天劫同步幻化出九宫至两仪之相——

**在他的体内，也有「极」，诞生。**

## 九、待解伏笔
- 朱雀第四次觉醒（虚火/怒火境界）只差一丝，尚未完成；
- 天劫四灵中青龙、白虎、玄武三灵尚未落到王林身上；
- 妖宗宗主与王林的渊源（玉佩）在太上长老处仍是悬念；
- 体内诞生的「极」与封界之主口中「天劫亦为造化」的关系待验证。
