# 第2017章 来自皇宫的邀请！（第三更）

## 一、古道山顶的对峙与离去

### 1. 一吼震退灰衣人
- 王林出声（两字轰鸣），身上散发出**不弱于古道山**的威压。古道山威压来自古道大天尊——仙罡大陆第一强者，故此事含义骇人。
- 两名灰衣人重叠化出的一拳、拳外灰雾头颅，在王林三丈外惨叫崩溃：头颅化为虚无，拳骨肉碎裂，二人重新分立后齐齐喷血，被生生震退千丈。

### 2. 黑色五指山之击
- 古道山顶高塔中幻化出一只黑色大手，迎风见长化作百丈五指山压落。
- 该五指山与王林**体内非仙非古之力运转一个循环**所成的威压相撞，剧烈震动后倒卷消散。
- 碰撞后王林体内融合之力分离：本源与古族之力各归原位，那一缕仙古融合之力开始第二个循环，但速度大减，似需**数十年**方转一圈。
- 玄罗在后目睹，倒吸口气。

### 3. 魂血自融与拜别
- 高塔中传出冷漠声音：“上来吧，本尊为你唤醒魂血。”
- 王林面色苍白立于第三百台阶，未答话，只向前迈出一步，踏在**第三百零一处台阶**；落下瞬间体内那滴魂血骤然融化，与身体完整融合，**血脉传承渐渐显露**——不需古道大天尊出手。
- 王林向山顶抱拳一拜谢“成全”。心态记录：他与古道大天尊差距极大，虽有“三百阶可离开”之诺，仍把对古道的冷漠埋在心底；且仙古融合确实拜其威压所赐（或为偶然，或为默认）。
- 古道大天尊沉思良久后应诺放行：“你既过了，那便下山去吧。”

### 4. 玄罗的护持
- 王林行至玄罗身边，看到玄罗体外隐隐收起的波动——**若古道食言，玄罗会出手**。王林轻唤“师尊”，心中与古族的裂缝因此有了温暖。
- 玄罗深深看他一眼，压下对此前“八曲二相”的震动，大袖卷起王林化长虹离去。
- 二人走后：两名受伤灰衣人回柱闭目打坐；高塔中一声叹息，迷雾中的身影起身走到窗旁，遥望玄罗与王林离去的方向。

## 二、道古皇城闭关：本源与真身

### 1. 归来与沉默
- 数日后返回道古一脉所在的**道古皇城**，王林长居**道古殿山后木屋**。古道山之事玄罗不问、王林不释，被玄罗隐下，一月后似烟消云散。

### 2. 收获与状态
- 此行去处甚多，吸收本源极多，本源之力大增、修为精进。
- 一月后体内本源与古族之力回归原位：本源凝聚真身，古族之力化作**眉心与双目的二十七星**。
- 关键秘密：如今**心念一动即可令仙古瞬间融合**，化作短暂爆发之力，威压堪比古道山；随本源修为与古族之力增长，融合时间更久、爆发更强；**待某日完全融合，将拥有如古道大天尊一般的力量**。

### 3. 木本源真身大成
- 王林取出圆筒，内有少量散发精纯木本源之力的液体。
- 融入一滴 → 木本源疯狂暴增；三天后再融一滴 → 向真身程度快速推进；小半个月后液体尽吸 → 盘坐身躯现重叠之影，**五行真身**一闪而出。
- 五行真身所发无色光芒中，木、金二色原本暗淡；数日后木本源光芒大闪，达到与水火土三色相同的程度。
- 五行真身分化出**水、火、土、木四道本源真身**＋中间一团尚未凝出真身的**金色光团（金本源）**。

### 4. 冲击金本源（进行中）
- 王林取出**仙极剑碎片**（得自仙族祖城的长街），此前曾炼化但未完整融合。
- 做法：张口吐出金色之气，将仙极剑碎片与金本源光团一并笼罩包裹；配合数月间在玄罗指引下吸收的诸多金本源之力，贯穿一起冲击**五行真身大成圆满**。
- 验证目的：“**五行真身大成，若我修为可以增加，则我推测为真**”——印证其在苍茫大海上的分析与推测。

## 三、来自皇宫的邀请

- 时间线：自回道古皇城已过**两个半月**，王林未出木屋一步；玄罗曾来木屋外观察两次，确认其在凝聚本源、无危险后离去。
- 一日清晨，一枚玉简自道古殿方向飞来，绕木屋数圈落地，片刻后化虹入屋，被王林双指夹住。
- 内容：**传弃玉简**，道古皇宫送来，邀请王林参加**道古皇尊十日后的封后大典**。
- 王林判断：玉简能送来显然获得师尊玄罗认可，故此大典对**道古一脉**很是重要。
- 背景：道古皇尊**选妃数百年**，如今终于择定一位册封为皇后。
- 悬念/待决：王林融合金本源正到关键之时，本不欲参加——“**我是去，还是不去**”。

## 四、待办与后续看点
- 金本源真身能否凝成、五行真身大成后修为是否增加（验证苍茫大海上的推测）。
- 十日后封后大典去与不去的抉择及其对道古一脉关系的影响。
- 仙古融合从“短暂爆发”走向“完全融合”的长期路线。
