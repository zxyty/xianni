# 第2067章 找不到……（第三更）

## 一、重返仙族大地：神识扫遍七十二洲

- 在久帝等人以秘术神通观看那一战的同时，王林来到**仙族的大地·北州**，感慨「数百年前，我从这里离开，去往了吉族；今日，我又回到了这里」。
- 王林神识散开，片刻后**整个仙族七十二洲尽在神识之内**。他自陈：当年的修为无法以这种方式寻找故人，如今**身为仙罡大陆第一人**方能做到。

### 寻到的故人（按出现次序）

| 故人 | 本章所见 |
|---|---|
| 周佚、青霜 | 王林神识扫过未停留，念及「修为提高的那粒丹药，不知是否还留着」 |
| 司徒 | 红衫子转世之后，「还是那个样子」 |
| 周茹 | 未走上修仙之路，数百近千年间不知转世了多少次 |
| 十三 | 本就优秀，如今修为不俗，「看他的样子，似很快了」 |
| 大头 | 洞府界身世可怜之人，以凶狠掩饰内心脆弱，依旧如此 |
| 申公虎 | 竟已成为一宗宗主，王林露出诧异 |
| 红蝶 | 凭印记辨认（「那印记不会错」） |
| 青霖 | 未选择修仙，如凡人一般转世了数次 |
| 清水（清水师兄） | 在西方；身上印记**已淡不可查**，若非王林今日修为远非当年可比甚至无法察觉 |

> 关于印记：王林明言「若是清水师兄的印记全部消散，那么我即便神识扫过，也无法从无数人中寻找到他——好在，他的印记还有一丝。」这确立了本章的关键设定：**转世者靠王林所留印记方可被神识定位，印记消散即无从寻找。**

## 二、遍寻不得李倩梅

- 王林在吉族大地离开前也曾同样搜寻，**没有丝毫故人痕迹**。
- 内心那个「让他复杂的倩影」属于**李倩梅**。他在七十二洲一次次扫过，几乎找到了所有人，**唯独没有她**。
- 王林身子一晃，立于天地间，神识**轰然全力扩散**，覆盖仙族、苍茫盆地、古族大地；整整一天，几乎扫遍仙罡大陆每一寸土地，**一无所获**，面色苍白。
- 追忆：李倩梅**为了他才来到仙罡大陆**，为了他离开自己的父亲，孤独一人转世投胎，默默等待挚爱的男人有一天来寻她、来打开她的记忆。
- 悲怒之吼：
  > 「你让我找到了李慕婉的魂，却让我丢掉了李倩梅的身影，这就是造化么？这就是天意弄人么？我不信，我终究可以找到！」
- **王林的判断**：有师尊相助，转世出意外的可能性不大；最大可能是**她比清水师兄更早自行恢复了前世记忆，致印记消散**。他闭目中似见某个陌生地方，一名白衣女子抬头望天、眼中含泪——她早已想起前世，却避而不见，或是自己不愿去见王林。
- 王林目透悲哀与茫然，沉默前行，消失在黑暗中。

## 三、云涛洲炉金宗：王石其人

- 地点：**仙族大陆·西州云涛洲**北处，一个只算小宗的宗门——**炉金宗**，后山密室。
- **王石**：黑衣中年男子，一脸坚毅冷酷；修为已达**第二步巅峰**，距第三步只一线之隔。
  - 炉金宗**千年以来修行速度最快**的门人，千年即至此境，由**大长老**亲自传授神通，宗内声望极高。
  - 杀伐果断，云涛洲内颇有名气，曾**斩杀一名刚踏入第三步的大能**；与其交手者十中有九必死，煞气令寻常长老心惊，为宗内小辈第一人。
  - **孤儿**，不知父母，被炉金宗一老道捡来自幼养大；名字**是他自己起的**——「我觉得，我应该姓王」。
  - 打坐中常隐隐看到一个**高大、熟悉而温暖却看不清相貌的背影**，随修为提高渐渐清晰；他觉得若能达第三步或可看清——**这是他疯狂修炼的原因**。
- **拒称师尊**：大长老当年欲收其为徒，他沉默未允；多年虽有师徒之实，却始终不肯喊出「师尊」二字——他总觉得自己的师尊不是眼前之人，但到底是谁，他一片迷茫。
- 大长老（虚幻身影传讯）交代：**三天后下山，代其前往道云宗送贺礼**。

## 四、唤醒十三

- 虚影散去后，王石身后忽传来一声叹息；来人能在其与大长老皆无察觉时降临，修为极高。
- 那柔和之声先问：**「告诉我，你为什么叫做王石，是谁给你起的名字？」** 王石心神一颤，似有记忆将醒。
- 转身所见：**白衣、白发青年**，目光柔和如长辈看子侄——正是王林；王石脑海中梦里的背影与此人渐渐重叠。
- 王林轻叹，**右手虚空一点其眉心**，王石心神轰鸣，记忆蓦然恢复。
- 王石落泪跪拜：**「师……师尊！十三拜见师尊！」**

## 五、要点与悬念

1. 王林的寻人手段有明确边界：**依赖印记**，印记淡则难寻，印记消散则不可寻。
2. **李倩梅之谜**成为本卷新悬念：既非转世意外，则很可能她已自行醒忆并刻意回避。
3. 王林已开始**逐一唤醒/寻访故人**，十三是本章第一个被点开记忆者。
4. 待办线索：王石（十三）三天后奉命下山赴道云宗送贺礼；清水的印记仅余一丝，时间紧迫。
