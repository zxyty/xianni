# 第616章 仙帝青霖

## 一、审讯背景

- 姚惜雪落入王林之手已**二十多年**，本章处于被囚于塔中问询的**第十年**阶段。
- 她对王林的恨深埋心底，同时对王林的手段心惊肉跳；心神已被撬开一个缺口——**血魂丹的使用之法**。
- 王林十年间不断在**散魔**身上加深烙印，从散魔身上学到一门**小神通**：说话时可在声音中透出一道**魔念**，用以动摇对方心神。
- 交易条件：王林许诺离开妖灵之地后放她离开；姚惜雪要求以**道心起誓**，被王林拒绝——「你没资格与我讲条件，王某答应你之事，定不会食言。」

## 二、逼出的核心秘密

### 1. 妖灵之地的真身：四虚一实

- **妖灵之地本身就是一座洞府**，且大得不可思议。
- 实为**五个洞府**，格局是「**四虚一实**」。
- 姚惜雪带王林去的那座，正是**虚府**。
- 四座虚府实际上是**进入最后一座真洞府的大门**。

### 2. 最终洞府 = 第一仙帝青霖之府

- 最后一座洞府是**仙界未崩溃前、第一仙帝「青霖」**之府。
- **青霖仙帝**乃仙界第一强者；传闻仙界崩溃时他并未身亡，而是**力战之后负伤遁走**。
- 姚父等人发现的秘密：该洞府内**有青霖仙帝闭关的气息**。
- 姚父猜测：洞府内有**踏入道境第三步的契机**。
- 姚惜雪不知其父等人如何探知，亦不肯深究。

### 3. 王林信之七成的原因

- 与姚惜雪初入虚府、他**打出叠加符文的刹那**，耳边曾传来虚无之声：「**吾为青霖**」。
- 故「青霖」二字一出，王林内心掀起惊涛骇浪，但面上神色如常，仅瞳孔微不可查地一缩。

### 4. 四虚府的归属

| 虚府 | 占据者 |
|---|---|
| 一 | 天运子 |
| 二 | 凌天候（大罗剑宗） |
| 三 | **云仙道侣**（数万年前一对道修眷侣，当年未随天运子等人离开，选择留在洞府内修道，知者极少） |
| 四 | 无人占据；姚父当年修为不够无法争夺，却**奇缘巧合知晓其存在** |

- 除姚父外，**其余所有人都认为此地是「三虚一实」**。

### 5. 青霖仙令

- 潮汐中的**金色令牌**，名为「**青霖仙令**」。
- 作用：虚府通向真正洞府的**大门钥匙**，持此物方可进入。
- 关键限制：必须**四个令牌同时开启、四座虚府大门同时打开**，才可完整开启，**缺一不可**。
- 出现地点：令牌被吸入此地后，会出现在「**潮汐深渊**」，其**入口在火妖郡内**。
- 血祖的算计：只要虚府在手，即便自己没有令牌，也等于掌握主动——只需巧妙安排，一旦第四块令牌出现，便自然获得进入真洞府的资格。

## 三、局势推演：老怪将至

- 王林反推：数万年来妖灵之地开启多次，以血祖神通为女延寿不难；姚惜雪偏在这一次不惜暴露洞府秘密也要冒险入内，说明**是在为血祖的到来做准备**——血祖数万年来因某种原因始终无法进入。
- 姚惜雪承认：
  - 其父**血祖**即将到来；
  - 不止血祖——**天运子**、**大罗剑宗凌天候**，以及**天运星上的一些老怪**，都会很快来到此地；
  - 诱因正是**潮汐中的金色令牌（青霖仙令）**。
- 姚惜雪的心理评估：王林问题看似简单，一旦作答便步步落入算计；掌握大量繁琐信息后，说谎立刻会被识破——「此人太可怕了」。
- 叙述者补充：王林修炼**禁制之术**，心神推衍复杂十倍百倍，此番对答不算什么。他**不怕姚惜雪开口，只怕她闭口不言**。

## 四、结尾与王林的未解之问

- 王林右手虚空一抓，将姚惜雪**再次封印，收入储物袋**。
- 塔内独处时的自语与疑问：
  1. 妖灵之地内有**吉妖**（被人分成九份，彼此无法融合），有**散魔**（据其所言乃**古魔麾下之魔**）——莫非此地还有**古魔**存在？
  2. 「我修为与那些老怪相比差之太远，可**天运子为何一定要让我进入这妖灵之地**？」
- 王林感受：掌握的信息越多，眼前的迷雾越难撕开。
