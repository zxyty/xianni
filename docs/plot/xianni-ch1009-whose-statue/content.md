# 第八卷 联盟隐秘 · 第1009章 谁的雕像

## 一、对峙缓和：青霜尸体带来的震惊

- 白衣女子怔怔望着**青霜**的尸体，身子轻颤，闭目后睫毛仍在颤抖，掩不住心中震惊。
- 王林悬着心神紧盯其神色变化——他是在**赌**：赌此女一定认识**定身术**、一定认识**青霜**。
- 虽是偷袭最佳时机，王林却按兵不动：此女给他的危机感极强，尤其对方此前**完整施展出本源之力**。相较之下，即便**炎雷子**也只是身上略有本源气息，尚未能完整施展。面对这样的敌人，偷袭没有意义。
- 四周花香弥漫、花瓣铺地成海。沉默一炷香后，白衣女子睁眼望着青霜尸体，似欲开口。

## 二、司徒南的搅局：白玉小瓶与仙术空裂

- 远处轰然巨响与咒骂传来：**司徒南**「跑老子看上的宝贝，就没有能跑的了的」。
- 逃逸之宝为一只**羊脂白玉小瓶**，圆润生光。司徒南全身黑气缭绕紧追，掐诀化黑雾为**虚幻凶兽**吞噬小瓶；小瓶一顿后**砰然崩解为碎片**，带锋利劲气穿透凶兽身躯，于其后方**重新凝聚复原**并速度暴增。
- 小瓶径直飞向白衣女子，女子挥手将其托在掌中——刹那间小瓶**再度炸裂**，碎片直扑其面门。
- 司徒南趁机大吼：「**王林，走**」
  - 王林不假思索，**收起青霜与仙塔**，如电后退。
  - 司徒南掐诀下按，低喝「**仙术·空裂**」，前方天空扭曲，砰砰声连成一片，化作无数凭空漩涡直奔白衣女子；二人趁势同奔仙府出口。
- **失效**：倒卷的瓶片在白衣女子双目一闪下**停滞半空**；空裂漩涡则**直接穿透其身**，此女毫无停顿，步伐从容。

## 三、司徒南赶来的缘由

- 司徒南此前单独离开搜寻宝贝，不久便察觉王林所在之处的危机；
- 尤其**浮风子等人的败落与消失**令其震惊；
- 他不愿独自逃走，遂**冒险赶来制造一同逃遁的机会**。

## 四、受邀入殿

- 白衣女子开口：「你，不想进入洞府了么」——声音依旧冰冷，但**杀意已无**。
- 王林果断停步，抱拳：「前辈允许我们进去」；司徒南同步停下，评价「**此人有些诡异**」。
- 女子沉默良久，轻叹，转身飘向**洞府内环的大殿**：「随我来吧。」并留话：「**若不来，你二人就离去吧，你的那些同伴，也会在洞府外等你。**」
- 王林决断：「**司徒，我自己进去**」。司徒南明白二人同入则一旦有变毫无反抗之机，点头不多言——这是二人之间**不必言明的信任**。

## 五、殿内：黑暗、问名、九尊雕像

### 环境
- 殿内黑暗**既阻肉眼、又压神识**，王林神识只能环绕身外数丈。
- 模糊可见四周数个巨大黑影，形如雕像。

### 问名
- 脚步声骤停，幽幽发问：「你叫什么名字。」
- 王林沉声：「**王林**。」
- 女子喃喃自语：「姓王……**真的是姓王**」——暗示其对「王」姓另有渊源与关切。

### 王林的戒备与底牌
- 体内元力运转全身，随时反击；
- **眉心第三目显露**（未开启），其内**储存的本源之力**只需心念一动即可散开；
- 自评：修为达**窥涅**，配合**古神肉身**可发挥**净涅中期**实力，但仍非此女对手。「只是有些事情，即便是危险，也要去做，这，就是王林。」

### 九尊雕像
- 女子挥手放出晶光，殿内如凡间道观，共有**九尊巨大雕像**：四周八尊，**正前方一尊**隐透金光；金光刚散即被黑暗吞噬、只能蕴于像内，更显诡异。
- 正前方雕像所刻为一**英武中年男子**：相貌堂堂、双目深邃，身着**黄袍**，袍上**绣九条紫龙**，环绕露出狰狞之貌，静止仍见凶焰；身后雕有**滚滚黑云**，透出威严与贵气。

## 六、雕像之威：一眼几近屈服

- 王林与雕像双目相望的刹那，脑中轰鸣，一股难以想象的气息扑面而下。
- **强度排序（王林感受）**：远超**清水**、**炎雷子**，甚至**天运子**亦远远不及；就连**罗天星域内神秘的第三步老者**也**略逊**于它。
- 后果：
  1. 一眼即**身颤喷血**、急速倒退；
  2. 体内**元力龟缩**，刚动即被强行按住，挣扎无用——**天地元力在此雕像前都要屈服**；
  3. 只闻自身心跳狂响，全身血液先似停流、旋即**齐齐轰击心脏**；此现象为王林**修道一千三百多年从未遇到**；
  4. 一股无形压力欲逼其**跪地屈服**。
- 王林反应：**眼露红光，低吼中爆发古神之力**。
- 篇末点题：「**古神，不敬天地，不畏道则，逆天而行，是为古之一族**。」

## 七、悬念与看点

- 雕像所刻究竟何人（黄袍九紫龙 + 黑云，帝王气象），与「姓王」之问是否相关；
- 白衣女子与青霜、定身术的关系，及其突然收敛杀意的动机；
- 王林同伴（司徒南等）在洞府外的处境；
- 王林本源之力储于第三目这一底牌尚未动用。
