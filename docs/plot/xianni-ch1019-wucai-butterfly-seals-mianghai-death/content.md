# 第1019章 七彩蝴蝶·冥海之死·幽冥引路

## 一、五彩蝴蝶破冥海铠甲

- 五彩蝴蝶现身，翅膀扇动落下五彩之粉，起「一股无形之风，破灭一切规则之力」，横扫黑沙荒漠。
- 冥海身外雾气被狂风扫尽，露出灰色铠甲与挺拔身影。
- 冥海望蝴蝶时眼中迷茫恍惚，一度放弃抵抗；蝴蝶连扇之下，铠甲大半崩碎，头部铠甲尽裂，露出真容。

## 二、冥海真容与魔化之源

- 沧桑中年男子，粗糙黑发、容颜深凹。
- 右眉之上一道疤痕，几乎穿透头颅，深处嵌**黑色碎片**，黑气不断冒出融入其头部。
- 冥海摸疤自语：「我还没有死么」，随即双眼幽光，直取王林。

## 三、封印与斗法

### 射神车封印机制（王林自述设定）
- 每一辆射神车拥有**五道封印**。
- 第三辆射神车开启后，**魂兽化茧**成为五彩蝴蝶；蝴蝶身上同样有五道封印。
- 五道全开，方能发挥**天宝上人**当年所制、**可灭仙神**的无上法宝之威。
- 化蝶＝第一道封印已开。

### 解印过程
1. 咬破舌尖、血箭化血色符文落于蝴蝶 → **第二道封印解开**，五彩生第六色。
2. 再喷血箭 → **第三道封印开**，成**七彩蝴蝶**。
3. 王林明言：打开三道封印，是其修为极限。

### 交手细节
- 冥海掐诀召远处火焰疯狂凝聚，淹没推散火焰的菱形符文碎片，热浪呼啸。
- 王林以**古神大鼎**闪动瞬移绕后，右手现**子母道枯兽骨**图案、煞气弥漫，冥海脚下灰芒闪烁。
- 冥海爆发体内**仙魔之力**震散攻势，反冲王林。
- 七彩之粉可**穿透火焰并使其倒卷追随**；冥海掀起被焚熔的地面黑水作防护，蝴蝶化七彩之光融入风暴穿透黑水，黑水亦倒卷随风暴反扑。
- 王林第二次绕后佯攻，实为制造时机，大喝「**定身术**」——一字定身，以窥涅中期（不计古神肉身）定住相当于**净涅**的仙人，随即遭反噬，但已不在意。
- 七彩风暴不击其身，被操控**尽数灌入冥海右眉伤口**，半点不剩。

## 四、冥海之死

- 冥海抱头咆哮后退；伤口被七彩之粉封死，七彩之芒覆盖脑中魔气碎片，**阻断魔气流入**。
- 冥海如噩梦初醒，继而无尽痛苦，仰望上空白色镜面般虚无，惨笑：
  > 「仙帝，冥海不忠，为一己私念，魔化至今，当得一死」
- 随即身下无尽火焰疯狂掀起将其包裹，**化作灰痕自尽**。
- 七彩蝴蝶自火海飞回黑塔内王林身边。王林沉默轻叹，「隐约明白了一些」。

## 五、黑塔避火

- 焚天之火四面八方吞噬，王林衣衫自燃，靠**右目青光**熄灭；古神大鼎再闪，百丈外踏入**黑塔**。
- 择黑塔的理由：火焰弥漫下黑沙荒漠一切皆毁，唯黑塔纹丝未动、无火涌入。
- 入塔刹那火海扑过，热浪余波卷到后背，热气涌入体内；王林拍储物袋服下大把丹药。
- 入塔前已收起一切法宝，包括焚天之时收回的**撒豆成兵魂魄**与**封仙印**。
- 王林身体状态：皮肤裂口极多却少有血液（血化红气流失过多）、头部眩晕、元神萎靡；**古神皮甲**（来自八星古神）护住其仅五星的古神肉身未受损。
- 塔外景象：处处火海、天空成虚无，时而露出白色镜面般光滑之处。

## 六、幽冥引路与魔气大殿（章末悬念）

- 王林取出先前所获**人头**悬浮身前，自语：「没想到当初**清水师兄**传授的仙术**幽冥引路**，有了用武之地」。
- 原理：这些人体内均有魔气，以魔气为引，可开出离开此地的通道。
- 头颅崩碎、掐诀搅动化作**暗红色漩涡**，延伸成通道。
- 异变：漩涡随转动涌出浓郁魔气，在魔气指引下「轰」的一声似打通某处。
- 所见：一座**魔气缭绕的大殿**，大殿上方一张**巨大座椅**，其上**坐着一人**。
