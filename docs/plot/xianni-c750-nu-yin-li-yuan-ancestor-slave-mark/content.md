# 第七卷 名震罗天 第750章 奴印

## 一、剑尖之人的崩解与石像的自行凝聚

- 踏在剑尖之上飞向天际之人，在急速冲击中仿佛被一阵柔和之风吹过，身子一震后蓦然崩溃、化作碎片落向大地。
- 那把闪烁**紫色雷光**的剑仿若悲鸣一声自半空坠落，一剑刺入一座**山峰顶端**。
- 山峰自顶部掀起波纹蠕动，大量山石碎裂滑落至雷光之剑外，转眼凝聚成**石雕**；其旁，其主人的雕像亦由碎石凝聚而出，浑然天成；剑尖之上的**仆人身影**也随碎石凝聚缓缓成型。
- 这一组石像初时粗糙，随岁月流逝渐渐清晰，好似拥有了灵性。

## 二、奴印：一门传承「奴役」的仙术

- 石像所结**手印**占据了王林脑海全部，在他眼中散发绚丽多姿之光；依稀间石像仿佛活了，石质双目拥有灵动。
- 心神中传来烙印之语：
  > “拥有吾血脉的后世族人，打开禁道，让吾苏醒；若汝之力不足，则世世代代牢记此训。”
- 该烙印如生根般欲死死烙印在王林体内。
- **脱身机制**：王林此刻肉身燃烧带来的剧烈痛楚刺激身体，使他一震后退数步、闭目从异状中清醒；同时体内那令肉身燃烧的力量流转全身，驱散脑中残留烙印。
- **王林的判断**（凭千年修行阅历）：
  - 手印显然是一门**仙术**；
  - 其作用是一种**传承**，但传承的不是力量，而是**世世代代的奴印**；
  - 世间神通皆逃不过岁月洗涤，此印诀当年或许威力极大，如今随时间流逝越来越弱；
  - 疑惑处：脑中烙印方才的崩溃，肉身燃烧之力只是**推动**，真正令其崩溃的仿佛是**烙印本身**（自朽）。

## 三、李元的揭示：李家先祖已是此仙人之奴

- 李元怔怔望着石像问“感受到了么”，随后宽慰称化名「许木」的王林（称其“许兄”）：那烙印不会将其奴化、会自行消散，**因为它已经有了奴仆**。
- 李元先祖在很久之前曾来此地，**以其擅长的禁制破开了这山峰、登上顶端**，从此成为这仙人的奴仆。
- 自此之后，**先祖的后人世世代代脑中都会烙下奴印**。

## 四、打不碎的仙人石像

- 李元抬右手按于石像，体内**仙力**一吐，石像立现裂纹，如条条狰狞蜈蚣爬满全身，刹那崩溃为无数细小碎块。
- 崩溃瞬间，碎裂石块**再次凝聚**，以肉眼可见的速度立刻恢复如初——“这仙人的石像，打不碎”。
- 王林脸色凝重，点头确认。

## 五、李家旧事：破灭禁与罗天星域六大上古家族

- 李元苦涩叹息后自陈：
  - 李家在很久之前以**破灭禁**扬名**罗天星域**；
  - 是罗天星域**六大上古家族之一**；
  - 家中族人**修禁道，以禁修行**；
  - **每一代族人中，都有突破第一步、达到第二步者**；
  - 那时的李家，如日中天。
- （叙述在此处中断，为后续李家衰落之因埋下伏笔。）

## 六、要点归纳

| 事项 | 结论 |
| --- | --- |
| 手印性质 | 仙术；传承「奴印」而非力量 |
| 触发条件/诉求 | 呼唤「拥有吾血脉的后世族人」打开禁道、让其苏醒 |
| 王林为何脱身 | 烙印自身随岁月衰朽为主因；肉身燃烧之力为推动；且奴位已被李家先祖占据 |
| 石像特性 | 仙力可碎，但碎石瞬息自行复原，不可毁 |
| 李家 | 罗天星域六大上古家族之一，以破灭禁成名，世代修禁道，代代有第二步修士 |

## 归属提示

- 本片段中被称作「许兄」的即**王林**（自第661章起以「许木」之名行事），其言行归于王林。


# 李元自述：李家奴印之祸与先祖遗愿

## 场景
雷之仙界某山顶，石像（雕像）之下。李元向化名「许木」的王林揭示李家隐秘，随后以葛虹血祭族魂。

## 一、奴印之祸
- 自李家先祖在**雷之仙界第一次开启**时进入之后，世世代代族人**再无一人能突破修道第一步**，**问鼎圆满**即是极限。
- 族人潜力在**出生的一刻**便一点点被吸走；寿元亦无形消散，同境界中李家只有**旁人三成寿元**。
- 根源皆在**奴印**。李元回望雕像时眼中滔天恨意，旋即被惆怅冲散，神色挣扎。
- 李元情绪波动过大即控制不住奴印，须双手掐诀打出一道道由**无数禁制组成的烙印**按在眉心，层层叠加封印方能恢复清明；发作后浑身汗透、仿佛苍老许多。
- 因奴印，李家渐衰，族人一一夭折，修为停滞第一步，失去昔日尊严。

## 二、数万年前的先祖与三法器
- 数万年前李家出了一位**绝伦之才**：天资超越李家一切先祖，对**禁制之术**有可怕的推衍。若在李家未世代烙下奴印之前的年代，他将是李家最强之人。
- 其修为**只是问鼎大圆满**，但禁制造诣使一些**踏入第二步**的修士也不愿轻易招惹。
- 为破族中世代奴印，他在有限寿元内**走出罗天星域**，周游访求禁制高人、参悟破解之法：
  - 在**联盟星域**，以禁制之术向一位**大神通修士**换取一张**画轴**；
  - 在**风之仙界**下的**云尘星域**，以家族积蓄换取一个**罗盘**。
- 回到罗天星域李家后，仅剩族人中**有一半自愿放弃生命**，以其魂**模仿仙人之剑**，祭炼出一把**铁剑**。
- 破解之法：**以铁剑聚魂，以罗盘凝印，最终以画轴封解**。
- 生命将尽之时恰逢**雷之仙界开启**，先祖携三法器与全族期望入雷之仙界，**此后再无音信**。李家绝望没落，奴印如世世轮回的咒语。
- **时至今日，算李元在内，李家只剩三人。**

## 三、铁剑重现与葛家
- **一千年前**，李元之父在一个**偏远的修真星**上看到那把铁剑。因铁剑系李家一半族人魂魄祭炼，其父**一眼便感受到剑内族人魂魄的怨气与愤怒**，确认为先祖之物。
- 持剑家族**姓葛**。李家昔日强盛时灭葛家如弹灰，如今李家最高不过问鼎圆满，纵有禁制之术，亦难敌**有两个踏入第二步**的葛家。
- **数年前**，李元乔装潜入葛家，查明一切。葛家早知其身份，却对当年之事一字不说，只把**葛虹连同三样法器**一起带来雷之仙界。
- 李元自陈以其智慧亦可推知当年之事，决意完成先祖遗愿，但先要以葛虹之血赎李家数万年绝望中的祖魂。

## 四、血祭葛虹
- 李元虚空一抓，禁制之光化作漩涡，将葛虹从中抓出摔在石像下。
- 随后抓其天灵、体内仙力如狂龙涌入。葛虹绝望中挣扎回头看了石像一眼，**目中忽有明悟**，张口欲言却再无机会。
- 其身砰然化作**血雾**弥漫山顶、覆于石像，连同元神一并被石像吸收，魂魄于血雾中消散。
- 事后李元低头看手心，神色迷茫，长叹：「先祖，族人李元，继行您未完之事。」

## 五、对王林的交易
- 李元以禁制之术**全程看到**王林（化名许木）与**阴虚修士**一战，其中王林的**一个法术神通**对他有大用。
- 王林质疑：李、葛两家恩怨与许某无关，为何引我前来。
- 李元承诺：绝不平白让人相助，**事成之后以完整的「梅花十八禁」与李家嫡传「破灭禁」相赠**，请其稍安勿躁，先祭族魂。
