# 第1684章 仙龙显道

## 一、心境：强者与担当

- 幼年的王林只知邻家孩童比自己强壮，那便是强者；两千多年修为之后，直到数年前才真正明白「担当」的重量。
- 「封尊」这一称呼伴随王林时间不长，却促发他走向修道者真正意义上的成熟——这是一种心灵的感悟，是自我强大的过程。
- 王林感受中最直接的强者，是自己的父亲：一介凡人，却为他与母亲遮挡风雨，扛起一个家庭的重担，身影如山。
- 结论：**父在，则家在。这，就是强者。** 由小见大、有微观宏。
- 三年守护界内、凝聚新仙界，杀戮无数、双手染血；王林不回头看，只能向前——要么撞个头破血流身死道消，要么撞个石破天惊轰轰烈烈。

## 二、分身归体（云海星域·转轮阵法外）

- 地点：云海星域转轮阵法外，星空为背景。
- 第三年最后三天，王林**本尊**盘膝吐纳中睁开寒冷双目，转身望向界内。
- 王林**分身**白衣而来，一步一步不起波纹、不发轰鸣，每一步却极为沉重；行至本尊身旁站定，二人同望界内。
- 分身向本尊迈出一步，柔和光芒闪耀中**分身与本尊融合**，砰砰声下王林白发猛地一散，自盘膝中站起，收回目光直落界外太古星辰。

## 三、局势判断与决意

王林自陈的最后三天格局：

| 项 | 内容 |
| --- | --- |
| 时限 | 最后三天 |
| 触发 | 远古仙域四大战将降临 |
| 地点 | 界内界外那洞府 |
| 未知 | 「第三个」到底是何物，至今不知晓 |

最终之战预计参与方：

1. 七彩道人
2. 战老鬼
3. 为让**仙尊**苏醒而来的**四大战将**
4. 从**风仙界通道**内走出的那群**仙罡修士**

**决意**：「毁灭界外远古仙域」——在最终之战之前，由王林亲手掀开一场混乱的序幕。

## 四、公开踏入界外太古星辰

- 王林身影一晃，自转轮阵法内向界外太古星辰一步走去，眉目凝聚杀机。
- 姿态：**不隐藏气息、不隐匿身影**，散开全部修为化作长虹呼啸疾驰——直接告诉整个界外「他王林，来了」。
- 寻敌方法：不知界外远古仙域所在，也不盲目搜寻，而是直奔太古星辰深处；判断三天后界内远古仙域开启、四大战将降临之时，界外远古仙域会**同一时间开启**，届时可凭气息锁定。
- 效果：神识弥漫整个太古星辰，界外各部落修为高深者纷纷惊醒抬头，清晰感受到自界内而来的惊人杀戮气息。

## 五、掌尊的按兵不动

- 掌尊在其另一座漂浮星空的宫殿内死死盯着前方，干枯右手握住许久未松。
- 沉默良久，**最终未下定决心去阻杀王林**：他对王林的**弓**极为忌惮，在那**两弓之力**未全部用掉前不敢出手。
- 回溯：**两年前**掌尊本想趁混乱偷袭，却被身处阵法之中的王林察觉，在王林一句话下无奈退却。
- 猜疑：王林如此嚣张地出现在太古星辰，是挑衅？还是想引诱自己去阻杀？
- 决定：「老夫不去接近，倒要看看他能如何。」

## 六、伏笔与待解

- 「第三个」是何物——王林明言未知，为后续隐秘。
- 界外远古仙域的具体所在，需待三日后同步开启方能感知。
- 王林尚余「两弓之力」未用，构成对掌尊等人的战略威慑。

# 第1591章 太古星辰的等待——洞府界巨变前的最后十二个时辰

## 一、掌尊的憋闷
- 掌尊修为通天，双眼露出憋闷之色。
- 若非顾忌那可怕的**李广箭**，他将立刻出手杀人（指王林）。

## 二、七彩道人的盘算与血阵
地点：太古星辰内，数个修真星组成的漩涡黑洞内，七彩光芒凝聚出七彩道人身影。

- **李广弓与箭的来历**：是七彩道人让掌尊送出的，但他也承认「算是他（王林）的造化」。
- **对王林的判断**：
  - 「此人与**战老鬼**很像」；
  - 若非是**第三个**，那便是洞府界修士中的奇异存在；
  - 「这样的修士，若他最终不是那第三个，杀之很是可惜」；
  - 「不过此人也有破绽，最后若不死，可为我所用」。
- **血阵**：「血阵已成，正在推衍，用不了多久，我就会知晓，那轮回了无数次的第三个，你到底在哪。」
- 七彩道人称已寻找「第三个」达**万万年**，很想知道轮回至现在的他到底是谁。

## 三、仙尊八妃中的两位苏醒关注
### 第三妃
- 位于太古星辰一处修真星的山峰之上，盘膝而坐。
- 白衣、容颜绝美，一股寒冰之冷弥漫全身，整个人如同不化之雪。
- 当年从**古之墓地**离开后便一直在此，**未参与界内之战**，默默等待着什么。
- 此刻蓦然睁眼：「是他。」

### 第七妃
- 位于太古星辰星空某处一道**巨大裂缝**内，其中是一片鸟语花香的空间。
- 睁眼露出奇异之芒：「他要干什么？」

## 四、群雄侧目
- **妙音道尊、九天魔尊**等人全部从疗伤中苏醒，遥望星空，神色阴沉。
- 王林的出现，因其手中之弓，对他们造成不小压力。
- 几乎所有大能之辈的神识都遥遥锁定王林气息所在，因不知其意图而神色凝重。

## 五、王林的静坐等待
- 王林身影在星空中停下，位置在**太古星辰的略中心之处**——由此去四周任何地方都可瞬息而至。
- 盘膝坐于星空，双目闭合，默默吐纳等待，令观望众人大为诧异。
- 修炼要点：**默默运转眉心那「仙人不灭体」所化的血滴**，使自身气息保持在巅峰。

## 六、倒计时与洞府界巨变
- 第三年的最后三天转眼只剩**十二个时辰**；这十二个时辰一过，**洞府界将迎来一次惊天巨变**。
- 除王林外无人察觉此事，连**七彩道人与战老鬼**也无法掌控全部。
- 唯一略有感应者：**天运子**——盘膝坐在**召河星域**内一块碎石上（王林未发现他）。
  - 目露奇异之光，双手在身前不断变化急速推衍，眼中光芒越来越亮，最终露出振奋之色：「快了，最后十二个时辰。」
- 倒计时推进：十一个时辰、十个、九个……直至只剩**四个时辰**的一刹那，王林突然睁眼，目内精光一闪。
- 王林睁眼瞬间，太古星辰内所有凝望而来之辈纷纷心神一震，猜疑无数。

## 七、章末转折：仙龙信徒现身
- 王林转头看向**右侧星空**，神色渐渐露出一丝古怪：「是它。」
- 遥远星空中，一群**数百人**的太古星辰修士呼啸前行：头发散乱，脸上涂抹不明之物、花花绿绿，颇为奇特。
- 边行边高呼口号：
  - 「**仙龙显道，信奉我道，可避灭世之灾，不信我道，随众生归墟**！仙龙威武！仙龙威武！」
  - 「仙龙显道，信奉为徒，带尔等去往**无上仙界**，永生不朽！」
- 其后另有**近千修士**随之而来，同样发出一声声低吼。

## 八、悬念
1. 王林在太古星辰中心静候，究竟是在等洞府界巨变，还是另有布局？
2. 七彩道人血阵推衍的结果——「第三个」的身份是否指向王林？
3. 第三妃在此等待多年所候之人/之事为何？
4. 「仙龙」信徒大军与王林口中的「是它」有何关联？
