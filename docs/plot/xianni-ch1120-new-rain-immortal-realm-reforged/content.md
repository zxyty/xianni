# 第八卷 联盟隐秘 第1120章 新的雨界（第一更）

## 一、众人苏醒

- 大殿外的虚无一片漆黑，远处闷声回荡，残碎的雨界石块孤独飘荡于虚无，「没有了家」。
- 阵法内众人苏醒：
  - **青霖**：往昔仙帝，容颜中年却透出岁月沧桑与浓浓的**腐朽之味**。
  - **青霜**：醒来查看右臂伤口，秀眉皱起；沉睡太久，一时不适应肉身。
  - **王巍、胡娟**：面色苍白；王巍激动跪地叩拜，泪流满面。
  - **周佚**：怔怔望着青霜，心中虽有苦涩悲伤，更多的却是平静。

### 王巍的因果
王巍在仙界时只是默默无闻的小炼气士，是青霖收徒之恩给了他新生、给了他迈向巅峰的修为，也给了他一生的幸福（与胡娟结为伉俪）。为等师尊苏醒，他常年居住在妖灵之地，期盼等待了无数年。

## 二、司徒南拜师青霖

- 王林向青霖求告。青霖问：「你是以晚辈身份，还是以老夫弟子身份」——王林沉默后以**弟子**身份开口，指出司徒南是自己挚友，**身种仙毒**。
- 青霖一扫司徒南，赞「好惊人的资质」，问其是否愿拜师。
- 司徒南虽桀骜，面对青霖却极为敬畏（因未参与全部救青霖过程），怔了一下后恭敬拜师，并追加条件：「老弟子姓子随意，你可不能限制我自由。」
- 青霖哈哈大笑：「你解毒之后，一切随意」，应允。

## 三、重凝仙界

1. 青霖将右手放在女儿青霜肩上：「青霜，借你体内仙力一用。」抽走**一丝仙力**（此丝之少，王林先前体内不多的仙力都超出其无数倍），却在青霖手中化作刺目金光，瞬息把青光大殿映成太阳般的金芒。
2. 青霖走出大殿、悬于虚无，望着记忆中曾是仙境的家园，眼中满是感慨与苦涩。此时仙界已崩溃绝大部分，未全崩的碎片大陆亦四分五裂，眼看雨界将彻底消失，数万年后连记忆都会淡化。
3. 金光挥出，滔天金芒如真正的太阳笼罩整个虚无；金光中生出一条条**金线**，交错成网向四周散开——网内凝聚**天地间的一切规则**，光中蕴含**滋养万灵的生机**。
4. 效果：崩溃中的碎片大陆一震停止崩溃；飘动碎石静止；崩溃形成的漩涡停止旋转、无声无息消散。
5. 青霖低声道「**重凝仙界**」。金网骤缩，金光环绕，残破碎石相互凝聚、向仅存的几处碎片靠拢，组成**一个新的碎片大陆**。
6. 新陆之上：金线铺地，青草生、流水延伸、高山耸立、威严宫殿成片；**雨界尊殿**飘落、降临于该碎片大陆中心。
7. 青霖宣告：「从此之后，这里，就是新的雨之仙界。」

### 青霜的心境
自有记忆起，父亲便如支撑仙界的脊梁，无暇陪伴年幼的她。仙界崩溃那日，青霖不但没有悲伤，反有一丝**解脱**；如今亲见父亲重凝仙界，青霜心中却生出一丝**痛楚**——连她自己也说不清。周佚见其痛楚，心亦轻颤。

## 四、新雨界三日

- **格局**：新雨界仅此一片碎片大陆，仙气浓浓；天空蔚蓝，**没有任何空间裂缝，极为稳定**。
- **司徒南**：被青霖带入尊殿（疗仙毒）。
- **王巍、胡娟**：在四周择一处宫殿住下，王巍神情很是开心；王林羡慕这对伉俪的幸福。
- **青霜**：以神通化作一座散发寒气的冰山，独居其上，不欢迎任何人上去；性格极冰冷，对父亲话亦少，唯对胡娟话多些。
- **周佚**：静静盘膝于冰山之下，始终抬头望着冰山上模糊的身影，仿若守护，**如两千多年前守护尸身一样**。王林暗忖：「青霜的苏醒，或许对周大哥来说，未必是一种幸福。」
- **银衣女尸**：默默坐在王林身后，目光时而落在王林身上，又很快移开。

## 五、王林的造化：第三步之种

- 王林坐于高山，脑中回荡青霖金光之威——其中清晰体会到**规则的变化**与**本源之力**；同时不断牢记在青霖识海内的感悟。
- 离开识海后修为**并未一步登天，依旧是净涅初期**；但体内多了一个**第三步的种子**——对规则、对道、对追求的种子。这才是青霖送他的**造化**。
- 对照：当年天逆初开，王林在天逆大门下**看到**了第三步；此番青霖造化让他**感受**了第三步的神通，使前进方向更为清晰。

## 六、结尾：尊殿召见

一声疲惫的传音落入王林心神：「王林，来见我。」王林步入雨界尊殿，见盘膝老者依稀与青霖相似——正是仙帝青霖，只是**容颜不知为何苍老了下来**。青霖道「坐」，王林盘膝对坐，神色平静。（本章止）
