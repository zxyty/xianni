# 第1453章 寒目望天！

## 一、封印之地内的大能之争

- **起因**：古之墓地外围一处封印之地，原由**大荒上人**率先发现，并耗费不少时间解开其上禁制，眼看就要取得其内封印的**四品木道灵**。
- **变故**：将得手的瞬息，**妙音道尊**突然出现，偷袭之下抢走道灵，双方随即展开恶斗。
- **形势对比**：
  - 大荒上人此来是**分魂融入一具老者之身**，肉身强度、神通熟悉度皆不足；因身体非其自身凝练，连**香火之力**的调动也略有欠缺。
  - 妙音道尊则是**分身**到来，占尽优势。
  - 若对手是寻常第三步大能，这些劣势尚可，但对方是与自己齐名之辈，劣势便成致命。
  - 大荒上人为人孤傲、性格古怪，罕有交好之友，在古之墓地内**孤立无援**，被点破后除冷哼外无从反驳。
- **战况**：短时间内相互斗法百次；二人身后各有一个**四千丈的黑色平台**漂浮，威压弥漫；神通碰撞轰鸣回荡，震得下方厮杀的近百修士心神颤栗。战团被一片横扫天地的风暴笼罩，看不清其内。

## 二、王林抵近与试探

- 王林立于一座**三阶深紫色墓台**（三千丈）上，四周弥漫**数万蚊兽**，按脑中地图路线在雾气中疾驰，数个时辰后见前方雾气扭曲、隐隐似另有一界。
- **地图判断**：「果然有一处封印之地……从这里一直向北，就可离开外围，进入墓地深处。」
- 王林在扭曲之雾外万丈停下，谨慎起见，先放出一只蚊兽，并**分出一缕神识融入其体内**代为探路。
- 蚊兽一入扭曲之雾便消失，随即出现在封印之地天边角落。王林借神识瞬息看清全局，但下一刻一道**乌光**自风暴中激射而出，蚊兽肉身崩溃身亡，王林那缕神识亦被轰杀。
- 妙音道尊惊天之声：「此地不允许外人踏入，给本尊滚！」王林面色略苍，旋即恢复，眼露寒光。

## 三、王林的推断与决断

- **观察一**：与妙音道尊交战之人全身涌现腥毒，同为第三步大能，但时间太快未看清是谁（即大荒上人分魂，王林尚不知其身份）。
- **观察二**：王林早在初入古墓见到白衣女子时便觉其修为降低太多；此刻见妙音道尊亦然，**修为似与司墨子等人相差不多**，猜测更深。
- **风险权衡**：「赌不赌？」若猜错，封印之地绝不能踏入——**太古五尊**之名太大，王林根本无法对抗。
- **决断**：断定妙音道尊修为**在古墓中被压制**——否则身为太古五尊，岂会怕别人进入、只以灭神识驱赶，必是有所顾忌；且其正与人斗法，正是良机。「那封灭族少女尽管是其奴婢，但我势在必得。」遂率数万蚊兽直冲扭曲之雾。

## 四、强闯与夺人

1. **登场**：天空剧烈轰鸣，扭曲疯狂闪烁，狰狞蚊兽黑压压幻化而出，其后三千丈深紫墓台骤现，**王林白发飘动、目光如炬**。下方近百修士震动、议论其是否为某位大能与古墓之兽；**封灭族少女**抬头一见，面色骤白，转瞬化作杀机。
2. **驱兽**：王林毫不停顿，右手向下一指，蚊兽嗡鸣扑向下方修士。
3. **直取**：王林看都不看风暴中的妙音二人，一步迈出墓台，闪电般直奔封灭族少女。少女尖叫「主人救我」，四周数十名妙音道尊麾下修士神通弥漫护其后退。
4. **虚火开路**：
   - 一名中年修士挺身阻拦（已看出王林并非三步大能），王林虚空一指，其满腔杀机化作**虚火**自体内狂烧，几成火球，凄厉惨叫中骇然后退。
   - 前方七八名修士被此幕所慑而顿步，王林挥手，虚火再起，众人全身火海、急退不敢再拦。
   - 三十丈距离转眼成为空旷，众人齐齐逼退，**气势如虹**。
5. **少女自救**：掐诀按眉心，封灭族印记闪烁，接连喝出「封灭族后人，祭献我魂」「召唤我族大神通封印」「封印此人本源」，声音走调、惊恐尖锐。
6. **妙音道尊出手**：王林逼近三丈之际，风暴内传出妙音道尊低吼「小辈尔敢」，同时**一声沧桑长笑**似在阻拦（大荒上人牵制），风暴内轰鸣再起；妙音道尊哼了一声，一道**蕴含十万香火之力的乌光如剑**破开虚空、瞬移般逼近王林。
7. **雷火本源相抗**：王林右目雷光砰砰，身后幻化出**雷图**，**九道伴雷**旋转；左目**九色火焰**燃烧，融入九道伴雷，**雷火本源完美融合**，形成一副燃烧的雷图。雷图在背硬撼乌光之剑，轰鸣惊天，王林闷哼一声，**借力一步跨越三丈**。
8. **收人**：王林双指骤然点向少女眉心，少女一句话未及说完，瞳孔中已是王林双指倒影——砰的一下点中额头，嘴角溢血，双目弥漫无数禁制，整个人被无穷禁制之力内外封死，被王林大袖一甩**收入储物空间**。
9. **收束**：行云流水、干净利落，王林收手转身，白发飘动中，**寒目望天**。

## 五、关键设定点

- **古墓压制**：古之墓地对第三步大能存在压制，太古五尊级别的妙音道尊在此极限仅为**空涅初期**，与司墨子等人相差不多；这是王林敢于强闯的核心依据。
- **香火之力**：妙音道尊与大荒上人皆用香火之力；一击可凝**十万香火之力**化乌光剑。分魂占据非自身凝练的躯体时，香火之力调动会打折扣。
- **墓台阶位**：墓台有阶，三阶为深紫色（王林所乘三千丈）；第三步大能身后各有四千丈黑色平台。
- **王林手段**：虚空一指化人杀机为虚火焚身；雷图九道伴雷 + 左目九色火焰 = 雷火本源融合的燃烧雷图；神识分缕融入蚊兽代为探查（蚊兽死则该缕神识亦灭）。
- **地理线索**：此封印之地位于古之墓地外围，**一直向北**即可离开外围进入墓地深处。

## 六、遗留悬念

- 王林未看清与妙音道尊交战者身份（大荒上人）。
- 妙音道尊被大荒上人牵制，无法全力追击；王林已彻底与其结怨。
- 封灭族少女被封入储物空间，其「封灭族大神通」与作为妙音道尊奴婢的价值待解。
- 章末「寒目望天」，暗示王林下一步动作。
