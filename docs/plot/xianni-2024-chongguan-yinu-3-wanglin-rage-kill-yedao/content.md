# 第2024章 冲冠一怒！（三）

## 一、嘶吼震城
- 王林的嘶吼传遍四周，笼罩小半个**道古皇城**（天空之城）。城中大量无资格赴皇宫夜宴、需次日观礼大典的三脉族人尽在其中。
- 「**烨道，我要杀了你**」一声惊言过后，灯火通明中的曲乐嘎然而止，欢闹化作死寂，五彩灯光透出冷冽。
- 众人骇然议论：「烨道不正是**道古皇尊**的名讳么」「此人竟在道古皇城内口出如此狂言」。

## 二、玄罗闭关炼信宝
- 玄罗自觉**转世之期已不远**，欲在转世前为王林炼制一件威力无穷的**信宝**。
- 该宝为一柄**五彩小剑**：一个剑柄上生有四处剑身，形似四叉戟；边缘隐有第五个剑身闪烁，似随时可幻化而出。
- 玄罗每隔一段时间吐青气弥漫剑上；已炼制多年、如今“已出四身”，凑齐五身后可成王林极强之宝。
- 动机：他身为王林师尊，至今未给过王林一样重物，内心有欠意。
- 祭炼正值关键，其神识大半笼罩剑上，**收回需半柱香**，故无法立即赶到。
- 玄罗急传音道古殿九名麾下：**去询问原因、必要时稳住王林、等他前来，此事不得宣扬**。

## 三、山谷崩毁与本源合体
- 吼声波纹中蕴含毁天灭地之力：木床、木椅、木桌、整座木屋瓦解，山谷树木草地、石桌河流尽成碎末，掘地而起化作巨大风暴冲上九天。
- 王林披头散发、双目通红悬于风暴中心，「他疯狂了……心如刀割」。
- **金本源之光崩溃 → 金本源真身凝聚 → 五道长虹合成完整的五行真身**，五行真身睁眼同露疯狂，被王林右手一抓融入体内。
- **修为攀升：空劫后期 → 空劫境界大圆满**。此举证实了王林此前对自身修行之路的猜测与分析可成现实；但他毫无喜悦，唯一心思是「杀人皇宫，杀了道古皇尊，抢回婉儿」。

## 四、起出底牌
- 王林一掌拍地，道古山震动，地底深处所布洞府裂开：
  - **大天尊之阳**（一团黑白之芒）与身融合，轮廓比在古道山时**凝厚了一丝**；
  - **仙祖头颅**化金光收入储物空间。

## 五、破阵而出
- 玄罗麾下九人化九道长虹赶至，见废墟、风暴、煞气冲天的王林，抱拳称其「**少尊**」，请其息怒并告知缘由，自陈「奉**玄尊**之命前来问询」。
- 王林决断：要赶在师尊玄罗到来阻止之前先杀道古皇尊，如此不让师尊难做（道古皇尊当年为玄罗所指定）——这是他此刻唯一可选之路。
- 九人中七人掐诀开启**道古殿青气大阵**（连接天地的庞大阵法禁制）拦阻。
- 王林幻化出**大天尊之阳**，九人瞳孔齐缩惊呼「大天尊」「他竟是大天尊」。
- 王林右手一挥，青气大阵轰然崩溃，九人如怒海孤舟尽数喷血倒卷；**王林未杀他们**，径直化作惊天长虹冲出道古殿山峦，杀向皇宫。

## 归属说明
- 据世界状态须知：王林自第1380章起以「烨寞（道古烨寞）」之名/身行事，属借势代入化身；本章文本直呼王林本名。
- 「婉儿」即李慕婉（第188章已死），此处为王林执念中的抢回对象。
- 「烨道」为道古皇尊名讳，与「烨寞」为不同个体，勿混。
