# 第1829章 天牛死魂

## 一、场景与对阵
- 地点：仙罡大陆·天牛洲·大魂门。
- 对阵：王林（新任长老）VS 炎栾（炎脉峰一系）。
- 围观：大魂门诸多长老、原本以神识远观的老怪纷纷飞出观战；青牛真人本尊在最深处至高山峰中静观。

## 二、王林的神通序列（道古神通·多重组合）
1. **八条烽火通天烟柱**：凤凰虚影被一挥击溃后，天地扭曲中冲出燃烧烽火，化八柱环绕王林转动如风暴，妖气狼烟、内含凄厉嘶吼与无穷吸撇之力，笼罩炎栾，令其生死危机临身。
2. **道古虚影**：退后三步之际，道古气息升腾，身后幻化出穿古老铠甲的道古巨人，虚影凝实、容貌正是王林之容。
3. **魔道·生死逆动**：食指前指，将炎栾体内磅礴生机急转为死气；同时抽取大魂门无数年来一切死亡生灵之死气，化作笼罩八方的死海。
4. **死气天牛**：魔道逆转生死引动地底天牛之吼，大地深处爆发惊天死气，与死海融合，于王林身前化作狰狞通红双目的庞大天牛，带不甘死亡之咆哮。
5. **古道无仙一拳**：念「神、妖、魔，古道无仙」，体内古之三族之力融合为一，握拳轰出，道古巨人张口无形嘶吼相和；一拳打在虚空却起九层波纹，所过之处草木、阁楼、山峰与大魂门外一切闪灰光石化。

## 三、炎栾的应对：魂幻归
- 咬破舌尖喷精血，捏碎血液，血雾结成蔓延至无尽虚空的赤红血路。
- 咒言：「以吾精血，召引大魂门古往今来先祖英魂——破空魂幻归来」。
- 召出**第九先祖罗云海**：满身血煞、身外缭绕无尽凄厉冤魂，面目身形模糊不可辨。踏血路一步即天地色变、煞气威压令王林烽火风暴倒卷；后连迈三步，每一步炎栾面色更白（消耗巨大），威压随之递增。
- 众长老震动：炎栾竟能召来第九先祖，惊其何时具备如此强度的意志。

## 四、胜负结果
- 死气天牛与血煞身影未接触即以威压隔空对轰，天地似逆转，最终**双双崩溃消散**。
- 文本点明：死气牛影只是天牛**部分意志**所化，远不及真正的天外之牛，但力量依旧不弱。
- 王林随后一拳石化四野，炎栾喷血急退、花容失色。
- 一声低喝叫停：「够了炎栾，你退下，不得对新任长老无礼——至于你那炎脉峰，老夫自会有所补偿。」

## 五、设定要点
### 天牛
- 封印于天牛洲古老大地之下，似死非死：**身躯化作大地，其神化作滋养众生之灵，其魂被镇压**，不屈之意长存。
- 来自天外，非仙罡大陆之灵。

### 青牛真人本尊的判断（重大伏笔）
- 样貌与青牛真身一模一样，居大魂门最深处至高山峰。
- 「魂可引动天牛，先祖所说之人，就是他。」
- 先祖无数年前**迁移大魂门至天牛洲**、选**地火主脉**作一峰，一切都是为等此人。
- 此人**来自洞府界**，非仙罡大陆之人；在某种程度上与**仙族七十二洲下所封的七十二尊凶兽**极为相似——故能引动天牛之魂。

### 大魂门道术
- **魂衍道**、**魂幻归**（召先祖英魂降世作战）均被王林评为极强大，明确列为出任长老后必须学会的目标。
- 第九先祖罗云海：杀戮一生、拘禁十亿道魂；巅峰时挑战**道一大天尊**失败被灭杀，大天尊念其英勇未灭其魂，许其魂归宗门。

### 古道神通特征（长老口述）
- 与仙族神通「半点不一样」；大多并非一次施展完毕，而是**多重组合**，最后一刻爆发惊天之力。
- 古国之修肉身惊人，王林肉身之力必定不凡。
- 长老疑虑：「此人的身份太过敏感，老祖为何要把他带回。」

## 六、悬念
- 王林与七十二尊凶兽、与洞府界出身之间的关联尚未揭开。
- 大魂门老祖带回王林的真实目的、炎脉峰被夺后的后续矛盾未了。
