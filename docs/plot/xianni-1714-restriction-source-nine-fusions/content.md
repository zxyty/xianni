# 第1714章 禁制本源

## 一、场景：云海裂缝的禁制风暴

- 洞府界内府、外府乃至星空任何裂缝空间，都极少出现如此数量的禁制。
- 禁制原本只是一个个印记符文，因数量太多密密麻麻重叠，已看不清样子，只见一片雾朦朦的幽光，在呼啸中光芒扭曲旋转，形如无边际的风暴。
- 云海裂缝中的凶兽尽数避开，带着惊恐从四面八方向出口疯狂逃遁；数天之内，裂缝外弥漫数之不尽的凶兽，形如**兽潮**，却不敢远离，只在裂缝外颤抖张望。
- 兽潮引来外界关注，有人想闯入探究，但裂缝内的禁制风暴令所有试图进入者骇然怯步。
- 风暴回旋，呜呜之声如鬼哭狼嚎。王林盘膝坐于禁制深处，闭目而推衍在瞳中闪烁。

## 二、起因与心态

- 鬼脸帆布被王林斩开，遂形成此禁制风暴；这一切在王林预料之内，他毫无惊慌，身心平静地摸索禁制本源。

## 三、核心悟道：禁制的本源

- **禁制即阵法**；感悟其本源需极强神识。王林修为已至**空灵中期**，神识强大，足以感悟。
- 神识散开笼罩整个裂缝空间，随推衍不断，禁制数量渐减——不是凭空消失，而是**融合**：每两个禁制合为一个；后期融合速度越来越快，几乎每一息都有大量禁制消散、新禁制出现。
- 王林所得结论：
  > 「禁制的本源，就是一股**计算之力**，这种计算包罗天地，甚至以此推衍未来、改变自己命运走向，这需要极强的神识。」
- **天运子删除此术**。王林之前看不清楚，此刻判断天运子隐藏了其在禁制上的惊天造诣。他始终忌惮天运子——此人在暗处，仿若从虚无投来的目光，回头去寻却找不到来源。

## 四、融合进程（九次）

| 阶段 | 耗时/节点 | 结果 |
| --- | --- | --- |
| 第一/第二次融合 | 七天后 | 禁制风暴大范围缩小，原有禁制消散近一半 |
| 推进 | 又十天 | 神识笼罩范围再缩小一半，禁制数量递减，但分裂之力几达巅峰 |
| 第三次融合 | 又十天，部分禁制开始分裂之刹那 | 剩下**千万左右**，每个都极为完整、无缺陷、蕴含强悍气息，难以再融 |
| 第四次融合 | 本尊出体、三体合力 | 剩**不足五百万** |
| 第五至第八次融合 | 六道本源化六剑加持 | 剩**数千**（每个含四大禁、数十丈大小，部分不属于洞府界） |
| 第九次「血禁」融合 | 以三千一百七十二份血液为介子 | 剩**九个**千丈大小、如小山般的禁制 |

### 第三次融合的关键顿悟

> 「禁制为阵，阵法亦为大道。天地有阵，为规则，为法则；人也有阵，若命运，若轨迹。这阵法禁制，说白了就是修士自行拟定的自身规则——以这种自身规则，去撼动天地禁制，再融。」

- 三次融合已是王林神识极限，面色苍白；且不能有半点松懈，需分心神操控，疲惫更重。

### 第四次融合：本尊出体，古之三族分身合围

- 千万禁制强行融合至一半时，数个禁制崩溃，崩溃并非消失而是**分裂成数倍**，连锁引发更多崩溃，数息间近千万禁制暴增，逼得王林神识无法收缩、反向外膨胀。
- 王林身子一晃，**本尊自体内走出**，只留**分身**盘膝坐在原处。
- 本尊道古气息呼啸惊天，一晃之下化出**古妖之体**直奔一方、**吉魔之体**在滔天魔气中凝形去往另一方，剩下的**古神之体**向后疾驰，三体呈三角环绕四周。
- 分身神识疯狂挤压凝聚，本尊所化古之三族分身同时展开修为之力融入其神识，挤压融合瞬息暴增，正分裂与正融合的禁制被一并强行凝聚。
- 剩余五百万禁制如五百万匹不受操控的野马，各散惊天光芒，全靠神识笼罩与本尊三体限制才未崩溃四散。

### 血丝与瞳孔

- 王林双眼通红，大量血丝弥漫瞳子，细丝交错相连，似存在某种奇异规则。
- 每个人都有双眼、瞳子、血丝，但血丝的**形状与数量人人不同**。
- 这些血丝既是疲惫与连日推衍的痕迹，也是他**想出的配合诞生禁制本源的方法**。

### 第五至第八次融合：六道本源化剑

- 王林右手掐诀，体内**六道本源**豁然幻化，星空震动，化作六把长剑冲天而起后瞬息落下——本尊三体外各两把，包围最中间的王林分身。
- 五百万禁制被强行融合，连续进行第六、第七、第八次融合；有的禁制并非两两相融，而是三个、四个、五个等等相融。

### 第九次「血禁」融合

- 清点得「三千一百七十二个，够了」。王林起身，右手拍胸口，张口喷出鲜血。
- 大袖一甩，血液化作**三千一百七十二份**，直奔四周每一个禁制。
- 一声大吼「血禁，第九次融」，以血液为介子融合，血光滔天、禁制交错重叠，最终只剩**九个**千丈大小、散发沧桑气息、如小山般耸立星空的禁制。

## 五、转折：九禁崩裂与血瞳显化

- 九禁融成的一刹那，其中一个突然崩溃、分裂无数向四周横扫；紧接着另外几个禁制同时碎灭。
- 变故突然，王林来不及思索，右手抬起**直接点在右目上**。
- 右目喷出血雾，雾中赫然幻化出一个**巨大的瞳孔虚影**，瞳孔内充满数之不尽的血丝。

## 六、要点归纳

1. 王林当前修为：空灵中期；神识强度足以推衍禁制本源。
2. 禁制＝阵法＝计算之力，可推衍未来、改变命运走向。
3. 王林战力构成：分身（留守推衍）＋本尊（古妖之体／吉魔之体／古神之体三体）＋六道本源化六剑。
4. 天运子在禁制一道上的造诣被王林重新评估为「惊天」，并被列为暗处威胁。
5. 悬念：血丝瞳孔虚影的作用，以及九禁崩裂后的结局，留待后文。
