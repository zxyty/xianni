# 第601章 一滴

## 场景与背景
- 地点：一片一望无际、密密麻麻种满**升仙果**的种植之地（隶属王林此段历练所在秘境范围）。
- 王林当时修为：**问鼎期**；处于**杀戮之心**状态（双眼透红芒），元神屡遭魔音冲击。

## 升仙果设定
- 外形：婴孩拳头大小，通体紫红，散发诡异幽香。
- 效果：食之极为兴奋、飘飘欲仙般快感；**凡人依赖性较大**，对修士无成瘾作用，但也有修士以服食取乐、沉溺其中。
- 价值：并非珍奇草药，朱雀星不算极常见但可弄到；凡人界权贵往往花极大代价才能从修士手中换一颗。

## 战斗经过

### 1. 枯骨手臂来袭
- 带**护腕**的枯骨手臂冲破禁制闯入，黑芒化作浓浓魔气弥漫四周；虚空一抓，轻松夺走**天魔风**。
- 王林抹储物袋取出**仙剑**。剑内**许立国**（叛变计划失败后一直小心翼翼）打定主意要立功洗刷旧账，操控仙剑化剑龙斩向枯骨。
- 枯骨触及仙剑时如冰触烙铁，发出剧响；但护腕随即散出魔气顺枯骨冲入仙剑，铁钳般死死钳住，许立国无法挣脱。

### 2. 化魔指
- 王林食指前点，轻吐「**化魔**」。
- 要点：所化**并非体内仙气，而是天地之间游历的妖力**；以问鼎修为催发，将天地之力转化浓缩于一指。
- 与**寂灭指**对比：寂灭指散死气，化魔指散**魔气**。
- 指尖凝出可吞噬光亮的黑芒，一弹之下快若闪电，**枯骨崩溃**，许立国撤回剑身。

### 3. 护腕的两重反击
1. **困牢**：符文一闪，碎骨化灰扩散如波纹，弥漫方圆千丈形成黑色光环，以魔力禁锢成困牢。
2. **魔音**：符文再闪，护腕传出叮咚天籁之音，浓郁胜天魔风无数倍，王林的杀戮之心出现松动。
3. **黑影现形**：王林踏空掌拍护腕，护腕魔焰滔天，化作拳头大小、**头生单角、通体漆黑**的黑影，轻蔑而笑，连续历啸形成音爆，真正攻击落在**元神**上，王林元神再次欲飞离身体，杀戮之心将崩。

### 4. 一滴——本章题眼
- 王林咬舌尖、不退反进，右手抓住护腕灌入仙力；魔音消散，但黑影顺手臂钻入其体内，化魔气循经脉流转、生出幻觉（**天魔乱舞**），直撼元神。
- 王林落地盘膝，双手一挥，**方圆千丈内不下上万枚升仙果**尽数离枝飞空，几乎覆盖小半天空。
- 双手一合，万果尽碎，汁液挤出相融，**不断凝练、凝练、再凝练**，最终化作**一滴如鲜血般的红色液体**。
- 王林毫不犹豫吞下：奇异感觉无数倍增长，如雷霆在脑中炸响；他把巅峰兴奋压为身体动力，**将要离体的元神生生止步**。
- 痛苦与快感被同时强行压制、压缩，化成无法想象的爆发力；两声怒喝「给我滚」「滚」，黑影被生生逼出体外。

### 5. 黄泉指定胜负
- 黑影出体后被王林抓住、仙力疯狂灌入而崩溃，化细丝从指缝钻出，十丈外重新凝形并恶毒盯视。
- 王林以左手小指点出「**黄泉指**」：以问鼎修为施展，一指黄泉、引动元神意境，蕴含生死轮回与其全部意志。
- 在升仙果之力刺激下打出**巅峰**，此指**无限接近下品仙术**，天空大片空间坍塌碎裂，指过之处便是生死。
- 单角黑影露出不敢置信之色，正欲逃遁即被灭杀。

## 关键余波
- **远古战场黑塔**中，那**铠甲**内传出愤怒咆哮，一股强大意志疯狂冲出、融入虚无——暗示护腕黑影与黑塔铠甲主人同源。
- 一指收回，千丈魔气禁锢消散。
- 王林喷出一口**元神之气**落于护腕，化作蜘蛛网般禁制将其封印，顺手扔入储物袋。
- 升仙果之力未散：王林双眼仍通红，心中疯狂滋生**无法压制的浓烈战意**；召回仙剑时，许立国一声不敢吱，对其状态心颤。

## 本章新增设定要点
- 化魔指 = 转化天地妖力、散魔气的指诀，与寂灭指（死气）并列。
- 黄泉指在问鼎修为 + 极致状态下可**无限接近下品仙术**。
- 升仙果可万果凝一滴，以极致刺激作为**抗魔音/稳元神**的手段——王林的临场创举。
