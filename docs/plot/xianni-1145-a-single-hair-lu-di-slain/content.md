# 仙逆 第九卷 云海之巅 第1145章 一根汗毛

## 一、莫罗大陆：卢迪之死

- 承接上章，白发王林瞬杀净涅修士宋五德，元神亦被灭；赶来的归元宗四大长老只见血腥与元神崩溃的元力波动，呆若木鸡。
- 紫道宗少宗主**卢迪**（阴虚期）目睹靠山宋五德瞬间被斩，恐惧到极点，先后抬出两重威胁：
  1. 「我是紫道宗少宗，你若杀我，我父亲**卢云从**定会屠灭整个莫罗大陆」；
  2. 「你敢伤我半点，我紫道宗将上天入地，永生追杀于你」。
- 卢迪拍储物袋取出其父所赠保命法宝——**黑色荷花**（通体漆黑、妖异绽放、散发黑芒），尚未开启，王林一指点在其眉心。
- 结果：卢迪吐血、双目涣散流血，身躯抛飞后爆成碎肉血雨，元神与宋五德一样消散于天地。归元宗弟子赶到时正见「血人化作血色弧形抛出、化为碎肉」这一幕。
- 战利品：黑色荷花、储物袋、卢迪坐骑黑色灵兽（大袖一甩收走，灵兽不敢反抗）。

## 二、威胁为何无效——王林的身份层级

叙述明确对比：卢迪的威胁若对云海五阶星域本土修士尚有几分作用（不如紫道宗的门派多半只擒不杀），但对王林毫无意义。文中罗列王林身份：

- 罗天正品雷仙
- 联盟朱雀圣宗之主
- 仙帝白凡隔代传人
- 清水仙君师弟
- 苏醒的仙帝青霜弟子

加上一千多年的修道阅历，「区区一个卢云从，区区一个紫道宗」入不了王林之眼——**比不上拓森身上一根汗毛**（本章标题出处）。

## 三、归元宗众人的反应

- 天亮，彩虹清晰笼罩莫罗大陆；王林一步消失，全程无人看到正面，只留顶天立地的背影与白发。
- 四大长老心神由绝望转为震撼，连问三句：他是谁？为何帮归元宗？瞬杀宋五德是什么修为？
- **吕烟菲**轻声道「他有一头白发」，露出自师尊重伤直至身死后再未有过的笑容。
- 忧虑：宋五德、卢迪二人身亡，紫道宗绝不会善罢甘休。
- 关键线索：师尊归墟前曾说「**北部、白发**」四字 → 长老们认定白发前辈即师尊所指之人，归元宗未必是绝路。
- 吕烟菲曾观察过宗内**三十一个凡人**却无发现；她决定「查之无用……顺其自然」，并以暗力毁掉储物袋内**一幅古老的画轴**。
- 回山门后，吕烟菲未回南部山脉阁楼，而与**孙芸**同去**药院**；孙芸心跳剧烈，轻声道「师尊，他就住在这里」——指向王林（化名/凡人身份）藏身药院。

## 四、另一线：紫道宗与星虎兽

- 云海五阶星域星雾中，有一片**紫色大陆**，为莫罗大陆三倍有余，形如凶兽盘踞；其上有**四座黑塔**散发柔和之芒笼罩全陆，另有外层防护光芒。
- 一头百丈虎状凶兽（**星虎兽**）自星雾冲出，因感应到大陆上有母兽凄厉惨叫而怀恨撞击护罩。
- 紫光冲出，内为**紫金袍中年男子**（威严、目深眉淡、略显阴森），瞬息破罩至星空，右手一挥以紫光将凶兽包裹，冷喝「炼」——紫光化作巨大炼丹炉急旋，兽吼渐消。
- 身旁紫袍老者幻化现身道贺：「恭喜宗主又引来一头星虎兽，想必用不了多久，宗主的**虎骨魂刀**就可以彻底炼成」——由此确认该紫金袍男子即紫道宗宗主**卢云从**（卢迪之父）。

## 五、伏笔与看点

- 紫道宗报复线开启：宗主卢云从正在炼虎骨魂刀，其子卢迪已死于王林之手，双方因果已结。
- 归元宗对「白发前辈」的身份追查被吕烟菲主动叫停，但孙芸已锁定王林在药院的落脚处。
- 吕烟菲销毁古老画轴的动机未明，为后续伏笔。
