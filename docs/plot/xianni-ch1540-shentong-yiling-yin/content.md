# 第1540章 神通！

## 一、压制排斥之力（三天）

- 三天内，王林持续将体内排斥之力转入**右目中的六颗魔星**分担。
- 六颗魔星因此**尽数化为金色**，隐藏于金色闪电之下，外人极难看到。
- 效果：勉强压住愈发剧烈的排斥之力，使其增长速度**略有减缓**。
- 局限：**只是拖延**，无法根本解决；排斥之力如阴影般始终环绕心神。

## 二、处境与法宝

- 王林回忆：在战场拿到**李广之弓**后，幽冥兽在其意念传出下吐出金色风暴将其吞噬——由此判定**眼下所在的世界即幽冥兽体内**，且「想要离开这里，很容易」。
- **李广之弓**：苏醒时已融入血脉，与体内**元仙**融为一体；肉身崩溃亦无损；心念一动即可幻化而出。但**弓弦已断，无法使用**，王林望之目露复杂，暗叹收起。

## 三、疯子的纠缠

- 疯子严肃追问：「是谁传你的**仙族不灭体**」，怒称要看看是哪个敢这么做。
- 疯子自称**「本王」**，言辞惊人、来历极大；王林确认其确是疯子，且**记性极差**（转眼忘记前言）。
- 疯子调笑称王林「小娘子」，索要芳名、芳龄；又夸称**自己的鲜血一滴价值无数**。
- 王林以金色狂风（一挥之下震动整颗修真星）将其卷飞，疯子却每次极速跑回，如此**十余次**；第十六次归来时高呼「真刺激啊」，原来其惨叫中透着欢快。
- 王林改以**七成肉身之力**一脚踹飞（该力足以撼动一名**空涅中期**修士）；疯子第十七次归来后干脆翘臀求踢。

## 四、黑猿比吼

- 王林打开**储物裂缝**，放出一头**黑猿**——当年在**云海**一处大陆寻得，实力虽弱但极喜咆哮。
- 黑猿本畏惧疯子气息，在王林神念下转为愤怒，与疯子面对面持续对吼。
- 结果：黑猿声嘶力竭、恐惧退后，**认输不敢再吼**；疯子得意大笑，自称「从小吼着我哥长大」「**小红**都怕我去吼」「整个**仙罡大陆**谁不知本王声音最大」。

## 五、五道本源的解法推演（本章关键）

王林趁比吼之隙闭目沉思，得出头绪：

1. **生死本源** —— 看破生死，于转化之际将排斥之力**分成生死两股**。
2. **因果本源** —— 自成一道，让这两股排斥之力**彼此形成一个循环**。
3. **真假本源** —— 如**骗道**一般**欺骗**排斥之力，使**元仙与道古完整融合**。

延伸判断：
- 五道本源中最难者为**生死、因果、真假**三道。
- 三道大成、化作大道后，即可以此冥冥之术操控体内排斥之力。
- **五道本源大成 → 五指齐全 → 轰开空门 → 成为真正的第三步大能**。
- 眼下尚缺一样东西：**道果**，「我还需几个道果，越多越好」。

## 六、役灵印（本章标题所指）

- 疯子提议比完吼后再比神通道术，右手指天：修真星天空霞光闪烁，凝聚出一只掌纹清晰、威严浩荡的**巨大手掌**，化作巨大掌印轰然降临。
- 王林神色动容，认出此为**「役灵印」**。
- 王林由此想起：疯子先前在他无法移动时曾施展**诸多神通道术，每一个都正宗无比**。
- 定性：这是**继仙人血脉之后，疯子给王林的另一场莫大造化**。

## 七、看点与伏笔

- 排斥之力的根治路径已明确指向「五道本源大成」，并卡在**道果**这一硬性资源上——后续行动动机。
- 疯子的身份仍是谜：自称本王、出身**仙罡大陆**、有兄长与「小红」、鲜血极贵、神通正宗，来历极大。
- 王林所处世界为**幽冥兽体内**，离开不难，暂未离开。
