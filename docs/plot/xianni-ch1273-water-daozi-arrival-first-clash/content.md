# 第九卷 云海之巅 第1273章 来临！

## 一、三线并叙的开场

### 1. 李倩梅：孤身赴险
- 白衣、蓝色秀发的李倩梅独自穿行星空，脸上泪痕晶莹，咬唇加速。
- 心声：「这世间有些事情，是没有道理可讲，是需要执着的，不管值与不值，都要去做的。」
- 背景：她已与破天宗决裂离去（承前章），此刻带着迷茫与坚定疾驰前行。

### 2. 木冰眉：被困于神宗
- 地点：九阶星域，神宗所在，一处隐于雾气的修真星，外有连绵不绝的阵法，阵心为华丽宫殿。
- 木冰眉盘膝其中，被困，冷漠质问「为何将我困住」。
- 王珊珊盘坐宫殿外看守，答「师命难违」，推测神宗大长老此举是为让木冰眉尽快恢复修为，但她自己也不解。
- 木冰眉心中隐隐刺痛、无法入定，直觉有大事发生在熟悉之人身上。
- 她并不知晓三件事：八阶宗派大比被取消、李倩梅与破天宗决裂离去、王林正陷入此生最大危机、生死难料。

### 3. 王林：赴约前的最后准备
- 地点：蛮荒大陆。
- 以元神化作火焰弥漫两截铁剑，逼出剑上血迹，历时十个时辰。
- 成果：耗尽所有元晶，逼出三成血迹，凝为豆粒大小的暗黑色血丸，气息诡异，漂浮于元神中。
- 三成已是极限——若非此前生死危机使其全身状态达到巅峰，也逼不出这么多。
- 收铁剑、收银衣女子后入定，心跳数息一次，状若归寂，静待最后两个时辰。

## 二、来临：水道子降临五阶星域

- 最后一息过去的刹那，王林睁眼。星雾云涌，无法形容的威压自雾中传出。
- 大地震颤欲崩，弥漫五阶星域的所有雾气轰然倒卷，雾中凶兽尽数惊恐咆哮。
- 星空尽头出现巨大雾气漩涡，一只苍老多皱的巨手自漩涡伸出，直抓王林。
- **元力封印**：天地元力如被奇异之力封印，齐齐避开，五阶星域内再无半点元力存在。
- 手掌无言、无问、无生机，如抓蝼蚁般压下。王林认出这是第三步大能惯用手段——与他在七彩界所遇如出一辙；除非同为第三步大能，否则无人能让他们显出真身。

## 三、第一次交手：千万剑气 对 苍老巨掌

### 王林的反击
- 王林不认自己是蝼蚁：「即便真是蝼蚁，也欲要吞天灭地」，充满逆意。
- 主动跃起化作流星迎击，眉心意境所化规则之星疯狂旋转，大吼「第三步大能，也不能让我屈服！」
- 施展**千万剑气**：右手食指爆发剑气，一道→万道→百万→五百万→八百万→九百九十九万；最后以**自身右手食指化作第一千万道剑**，凑满千万，达到圆满。
- 圆满瞬间，两条**鹿兽虚影**自图腾幻化而出，环绕食指。
- 威力定级：千万剑气归一，可杀一切碎涅修士，天人衰劫者亦需狼狈抵挡。

### 碰撞过程
1. 指掌相撞，巨响震动八方，崩溃无边星雾，传遍五阶星域，所有五阶修士齐齐喷血、面色惨白。
2. 千万剑气冲入巨掌内部，鹿兽虚影化黑白二气融入掌心，砰砰如雷，天运运转似都停滞。
3. 巨掌下降之势骤然一顿，皮肤下如千万银蛇钻动，现出无数细线，随后皮肤爆开——**却无半点鲜血、无半点天地元力散出**。
4. 雾中传出苍老声音（水道子）：「倒也有一些本事……但萤火之光岂能与皓月争辉？在老夫面前也敢升空，给我下去！」气浪压下。
5. 该气浪之强，碎涅修士稍触即肉身崩溃；王林喷血、骨骼被死死压住，如被千万斤马车撞击、无数修真星砸身，被生生砸落，**毫无反抗之力**，全凭**古神肉身**扛住。
6. 王林狰狞下令「千万剑气，崩！崩！崩！」——融入巨臂的千万剑气同时自爆，如千万修士化飞剑在臂内自毁，轰鸣毁天灭地。
7. 巨臂猛震，传出一股奇异之力，千万剑气的崩溃骤然消散，手臂**毫发无损**。

### 结果
- 王林：喷血、骨骼剧痛、身有撕裂之感，被从天空压落。
- 水道子：手掌掌心出现一个**血点**，滴下**一滴鲜血**——即便伤口再小，也确实被伤，这是事实。
- 作者补注：王林此神通曾崩碎太古星辰蓝梦道尊的四根虚幻手指；此番解开短剑封印后神通大增，威力绝非寻常。
