# 第八卷 联盟隐秘 第1048章 至宝

## 一、拔剑：杀意入剑
- 王林右手握住铁剑剑柄的一瞬，眼中杀机寒芒全部收敛消失，目光平缓如清水——仿佛满腔杀意被铁剑吸收，而这种无杀意的平静比滔天杀气可怕无数倍。
- 王林隐约感到：**铁剑内有其自身之灵**，此刻正欲从沉睡中苏醒，一旦苏醒将发挥毁天灭地之威。
- 旁观者反应：村姑美妇见剑鞘时略皱眉、显然不识此物，但在王林双目转为平静的下一息猛地睁大双眼，露出不敢置信的骇然，**勾起一丝回忆**；黑衣人目光落在剑鞘上，瞳孔猛缩。
- 铁剑出鞘：无法形容的可怕气息自剑鞘疯狂冲出，大殿咔咔欲崩，王林身旁两尊巨大雕像瞬间龟裂欲四分五裂。

## 二、第一斩：重创虚空子
- 虚空子原本视王林为蝼蚁，正以神识分析四周**本源**，试图找出其产生的隐秘——他直觉认为找到答案便等于找到**第三步**的正确道路，故砰然心动、心跳加速。
- 探查将要摸到脉络之际，虚空子全身一寒，生死危机弥漫：比葬仙池崩溃时的冲击强数倍，且气息熟悉。他失声认出：**「次空涅法宝」**。
- 王林一斩，铁剑未脱手，却在两人之间幻化出万丈银光大剑虚影，速度远超碎涅修士所能施展，虚空子来不及闪躲，被斩中前胸。
- 虚空子元神以无法想象的速度扩出体外、包裹肉身硬抗（其元神通体紫色，强度远超肉身）——寻常修士元神脆弱全靠肉身保护，虚空子则相反。
- 结果：虚空子身子一颤，面色异样红润，喷出一口鲜血，体外元神颤抖着缩回肉身；体内砰砰作响，被冲得后退，却猛地抬头生生止住脚步，**坚持留在本源之内**，任本源之力渗透加重伤势。

## 三、僵持：本源与时间
- 虚空子放话：「小杂种，就凭你，即便有次空涅法宝，想要杀我，你还没有那个资格」，抬手隔空一抓，被王林第二斩的银光逼退，右手猛缩，神色阴沉。
- 虚空子的处境：身处本源之内时刻受冲击。本源之力总量不多（怕是连他体内元力的万一都不到），却迫使他绝大部分元力用于对抗，且须全部心神融入其中摸索。他自称**只需再半柱香**便有信心摸出本源奥秘，因而极不甘心放弃。
- 王林的处境：面色苍白、元力随剑疯狂流逝。他此前探查已知铁剑**不需祭炼、在手即可使用**，与传统法宝截然不同；对其吸收元力早有准备，故不慌乱。

## 四、虚空子的次空涅法宝：紫色冰块
- 虚空子一拍储物袋取出一枚**紫色冰块**，寒气弥漫，大殿笼罩冰寒。
- 他带着心痛**分出一半元神**，化作另一个虚空子飞出体外，一口吞下冰块，以闪电之速直奔王林。
- 王林在冰块出现瞬间感受到其气息与自己的铁剑、**玄宝上人的次空涅箭**相同——判定：紫色冰块同为次空涅法宝。
- 首次交锋：铁剑一扫幻化虚幻大剑迎击，分身元神双手掐诀一指对抗，轰然巨响后分身元神退后数步、光芒黯淡，虚幻大剑亦随之崩溃。

## 五、以宝御人：连斩十一剑
- 王林的取舍：杀局以本源为饵，已暴露本源与次空涅法宝；若就此放弃则是计算中的一次失败，唯有重伤或杀死虚空子，方能震慑村姑美妇与黑衣人。
- 王林**索性闭上双眼，放弃对铁剑的操控**——以其修为不足以发挥此宝真威，但此物无需祭炼，只需**以宝御人**即可。
- 铁剑立刻嗡鸣、如欢呼般发出惊天剑鸣，牵引王林抬手（非王林之力），元力疯狂流逝，幻化出的银光大剑**近乎实质**，再无半点虚幻。
- 剑势：一斩、横扫、下方划过再落，毫无停顿地连贯如凡人剑武者的剑招连锁，化作银虹如银龙环绕分身元神；速度越来越快，第一剑或许缓慢，第二剑快一分，转眼**七剑连成一片**，其后第八、九、十、十一剑不断落下。
- 代价：王林体内元力在**第六剑时全部消散**，第七剑起吸收的已属其血肉，好在**古神肉身**强悍、蕴含古神之力，方可坚持。

## 六、要点
- 「次空涅法宝」体系被点名三件：王林的铁剑、虚空子的紫色冰块、玄宝上人的次空涅箭（气息同源）。
- 铁剑特性：无需祭炼即可用、以元力（乃至血肉）为食、内蕴剑灵、可『以宝御人』发挥全威。
- 悬念：村姑美妇对王林平静目光/剑鞘的骇然回忆尚未揭示。
