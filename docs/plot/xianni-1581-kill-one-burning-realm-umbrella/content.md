# 第1581章 杀一人！

## 一、焚界古伞出世：灭世之火压场

- 古伞撑开的瞬息，滔滔**灭世之火**自伞下卷动而起，笼罩天空向下焚烧；天地扭曲，万物仿若支离破碎，浓烟随火海呼啸。
- 围杀王林的三人（灰衣老者、黑衣老妪、白衣男子）神色大变，来不及击杀王林便急速后退——火伞给他们带来强烈的生死危机。
- 三人皆是**投影而来**：投影死亡不连累本尊性命，但本尊同样会重伤调养，故仍不顾一切急退。
- 灰衣老者惊呼：「封尊此人不愧是封尊，以如此修为居然能施展这种灭绝天地的神通。」
- 黑衣老妪补充：「**上代封尊极为难杀，没想到这一代封尊同样如此**。」——点出封尊传承有上代与这一代之别。

## 二、代价：以生机祭献

- 焚界古伞的神通**不属于这一界**，王林修为不足且尚未完全感悟明了，施展消耗的生机庞大无比。
- 伞中宣泄的火海**全部由王林生机祭献而出**，其容颜因此急速枯老，但双眼寒芒反而更浓。
- 王林低吼：「想要逃，你们逃得了么？要杀我王林，不付出代价，不够！」全身生机疯狂释放注入古伞，火焰更浓、如大口吞噬而下。

## 三、白衣男子的「冰封万古」

- 白衣男子面色苍白，右手一拍眉心，眉心凸起**雪花样符文**，寒气弥漫天地。
- 他狠狠一抓将雪花印记完全抓出，抛向古伞，念诀：**「以老夫寿元为道，以冰雪之魂为天，以寒封虚无为引，冰封万古。」**
- 其身份显然高于另外二人，**即便在太古星辰，也是仅次于太古五尊之类的人物**。
- 效果：
  - 井状天地内地面的平静水面自中央被冰封，向八方蔓延成无边无际的巨大冰面，散出白色寒气升空。
  - 天幕之上浮现**数万丈大小的雪花印记**，整个天空随之冰封——天是冰封，地是冰封。
  - 无尽雪花化作雪之风暴轰入古伞；水面与天空的寒气合流直奔古伞。
  - 火海被大片冰封，**古伞本身也成冰雕**，其下凝聚无数巨大冰锥，天地间延伸出冰柱与冰雕相连。

## 四、反杀：火海爆开，三人各自结局

王林再指古伞，体内生机大范围流逝祭献，古伞内传出闷闷轰鸣：

1. **冰封崩溃**：冰内火海向外一散，先崩天空冰柱，再崩大地冰柱，最终古伞外全部冰层碎开，火海倒卷八方。
2. **黑衣老妪 —— 投影被轰杀**：王林一指，火焰分出一股直奔老妪；老妪掐诀似有神通弥漫，仍瞬间被火海吞噬，惨叫中投影之身直接崩溃。
3. **灰衣老者 —— 重伤遁走**：掐诀拍眉心，身外黄芒闪烁化作层层泥土护体，被火海淹没后化作巨大土球、裂缝密布轰然崩溃，露出老者本人；喷出大量（虚幻不见踪迹的）鲜血，身子萎靡但未死，苦叹中捏碎一枚玉简，身影渐渐消散无踪。
4. **白衣男子 —— 被封印**：最后一道火海卷向他，其身外大量冰层在持续巨响中不断崩溃又重新凝聚；身子倒卷数万丈后停下，冰层凝聚了火焰，成为**一道封印**。

## 五、太古星辰·漆黑阁楼与那口井

- 场景切换：太古星辰中有一座**永恒漂浮在星空的漆黑阁楼**，阁楼大殿内有一口**井**，数人盘膝坐于井旁。
- 井中映出的正是王林所在的那片天地——三人正是借此投影出手。
- 老妪投影被焚杀的瞬间，本体猛地睁眼喷出一口鲜血，死盯井面，许久后抬头向大殿深处索问：**「给我一个解释。」**
- 大殿深处传来悠悠苍老之声：**「没到时候，此子手中有一物。」**（暗示阁楼势力另有图谋，且盯上了王林手中之物）
- 灰衣老者本体亦睁眼、嘴角溢血，苦笑摇头：**「小看了他。」**

## 六、王林的绝境心境

- 施展焚界古伞祭献生机过多，王林**容颜衰老**，体内**排斥之力**令其全身颤抖；生机越来越弱，天空古伞威力渐失、似要消散。
- 王林已不再考虑能否渡过这场生死大劫：**「死，又何妨，老子本就厌烦了修道，能在死前多杀几人，足够了。」**
- 他头发散乱、豁出一切，迈步直奔被冰封的白衣男子——他要杀人。

## 七、转折：五脏仙道的模糊女子

- 王林临近白衣男子的一瞬，白衣男子冰层上空**从虚无中无声无息走出一人**：一名样子模糊、双眼清晰露出寒意的女子，玉手抬起五指伸开，遥遥按向王林。
- 其法门为**「五脏仙道」**，按手指弯曲次第施展：
  1. **小指触掌**——「五脏仙道其一为肾，肾衰而伤」：一股奇异之力弥漫天地，王林双肾剧痛并急速枯萎，**连古神的恢复之力都无法复原**；退至第三步时双肾化作一片血水在体内消散。
  2. **无名指触掌**——「其二为肺，肺死而终」。
  3. **中指触掌**——「其三为脾，脾溃而腐」。
- 王林喷血、双目通红、身子颤抖，但眼中杀机在剧痛中达到巅峰。（章节在此中断，五脏尚余其二未点）

## 八、悬念与看点

- 「此子手中有一物」——漆黑阁楼势力隐忍不出手的真正原因。
- 「上代封尊」与「这一代封尊」的对照，暗示封尊之位的传承脉络。
- 五脏仙道显然为专克肉身的绝杀之法，且能压制古神之躯的恢复力，是王林当前最大死劫。
