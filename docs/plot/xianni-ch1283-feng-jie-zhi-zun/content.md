# 第九卷 云海之巅 第1283章 封界之尊

## 一、王林：魂坠天逆世界

### 状态
- 与水道子决战后「崩溃了一切」，王林发现自己身处一片迷雾世界，只剩**无形魂魄**，寒意弥漫、魂魄缓缓消散。
- 此地无日月交替、时间近乎凝固，与外界不同。
- 迷雾中穿梭的长条形发光体蕴含**金木水火土**五种天地元力，王林倍感亲切——他忆起「这里的五行，是我搜集」，确认此处即**天逆的世界**，也是他近两千年前曾见过的世界。

### 血光滋养
- 无数岁月中，一股**温暖血光**从四面八方渗透而来，持续融入其魂魄，驱散寒冷。
- 效果：魂魄由消散→半透明凝形→渐如实质；迷茫消散、记忆逐步苏醒。
- 王林无法推断血光来历，只能勉强归因于「天逆内自身存在的滋养魂魄的奇异力量」，但**总觉不对劲**。
- 数年后察觉：血光从未断绝一息，但其中的温暖**正渐渐微弱、冰凉下去**。（伏笔——与下半章李倩梅以血养石像相呼应）
- 王林感慨「婉儿也在这里」，并困惑自己既已崩溃一切、为何仍出现于此，且回望已深入天逆世界，寻不到归路，「唯有等待永恒」。

### 呢喃与通天石门
- 远处传来「这里、这里」的呢喃，落耳即化作波动在魂魄内回荡，近距离下甚至令其**元神扭曲**。
- 王林以「我是天逆之主」自居，决意前往查看；以魂魄之体如风飘行，无元力消耗，在天逆内如鱼得水，速度超越闪电，破雾前行数年，雾气渐薄。
- 前方骤现**通天之门**：巨大石门无边无际，令人如蝼蚁；王林并不陌生，「他见过数次」，且知其为**当年因天逆而出现的巨大石门**。
- 石门轰隆开启一道巨大裂缝，呢喃正自其内传出。

## 二、关键推理：封界之尊的真相

随记忆苏醒，王林厘清了此前费解之事：

| 线索 | 王林的判断 |
| --- | --- |
| 与水道子一战时突然出现的玉佩，水道子失声称其名为**封界之玉**、是「其主人随身之物」 | 水道子之主 = **封界之尊** = **天逆前一代主人** |
| 白发童子为何要杀自己 | 童子感应到其主（封界之尊）的气息，故来杀王林 |
| 童子吞噬王林血液后说「并非转世」 | 印证童子在验证王林与其主的关系 |
| 童子搜魂寻找天逆 | 目的是找到其主、**杀死其主** |
| 童子见玉佩后惊慌、面色大变、无尽恐惧 | 玉佩上金光化作一指，将童子眉心**七彩钉子**彻底钉入，令其重伤惨叫逃遁 |
| 由此反推 | **封界之尊绝非真正死亡** |

## 三、入门

- 石门内声音自陈：「我是封界之主，封界之尊……进来吧，我没有恶意，不会害你。」语带迷茫。
- 王林判断门内藏着**与天逆有关的惊天秘密**，更是自己离开此处的**唯一道路**。
- 沉吟少顷，王林身子一晃，一步迈入石门缝隙，进入通天大门之内。

## 四、并线：李倩梅以血养石像（四年）

- **地点**：云海（二阶星域）内一处隐于无尽雾气、极为偏僻荒凉、罕有修士到来的**蛮荒大陆**，大陆上一处山谷。
- **所为**：李倩梅盘膝守着一尊**晶莹剔透的石像**，以自身鲜血反复涂抹全身；血光正渐渐消散，她便掀下手指未愈的血痂再涂。
- **代价**：
  - 已整整四年未离开此地一步。
  - 四年前：一日涂抹一次，可休息十个时辰。
  - 四年后：石像越发晶莹、需血越多，一日需涂抹四次，休息不足四个时辰。
  - 面色苍白无血色，蓝发失去光泽，右手五指尽是裂痕、干枯如老妪之手；眼角已无泪，只剩长久泪水所化的龟裂。
- **心念**：「我会让你醒来。」四年内多次自问值与不值，无法如当年回答其师尊那样回答自己；只隐隐觉前世有一个声音，在她百年战场厮杀中苏醒呢喃，让她依稀看到自己成了水面下的鱼儿，望着水面上天空中一只渐渐远去的飞鸟。

## 五、要点与伏笔

1. 天逆世界内滋养王林魂魄的「温暖血光」来历成谜且正在变冷——与李倩梅四年血养石像形成强对照，指向同一因果。
2. 「封界之尊」正式登场（以声音形态），身份定位为**天逆的前一代主人**、水道子之主；其随身之物为封界之玉。
3. 白发童子的动机链完整闭合：感应主人气息 → 杀王林 → 验血（并非转世）→ 搜魂寻天逆 → 意在弑主；被封界之玉一指钉入七彩钉子而重伤逃遁。
4. 王林踏入通天石门，卷入天逆前代主人的秘密。
