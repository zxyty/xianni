# 第938章「杀」剧情梳理

## 一、清水暴走：血丝细线与呼风八龙

- 清水一声咆哮冲出，全身红光弥漫，蕴含**无尽的极境**，双手未掐诀而神通自行呼啸。
- 其身前凭空出现一道**血丝般的细线**，仿若可撕裂空间，直奔那收回的（带望月气息的）手臂而去；细线每一次闪烁都让手臂一震。
- 清水疯狂攻击的场面震住了金龙、一木子（终于明白家族大长老临行前所言「清水，轻易不要去惹」）与武东禅——武东禅尤其被那细丝震动心神。
- 攻击中清水**右目砰然爆开**，化作大片血肉扩散，极境全部出击落于手臂之上，一震之下手臂松开了玄宝上人。
- 金龙见状立刻扑向玄宝上人，并甩龙尾抽向清水；带望月气息的手臂再度张开五指抓向清水。
- 清水左目红光弥漫、露出疯狂之色，右手掐诀施展**呼风之术**：黑风中咆哮出**八条黑龙**。
  - 八条黑龙仅次于白凡的**呼风九龙**，威力比之前的七龙高出数倍。
  - 呼风八龙并未毁灭玄宝上人元神，而是横扫掀起风暴使其虚弱至极、元神几近崩溃，并在其身上形成**呼风之印决**层层封印，使玄宝上人元神昏迷，顺通道飘向入口漩涡。

## 二、王林抢夺玄宝上人元神

- 本在望月之骨中盘膝的王林本体，见清水疯狂，咬牙起身：「我王林行走天地之间，虽不是正人君子，但清水有恩于我，此刻他焦急疯狂，我不能坐视不理。」
- 玄宝元神被吹向漩涡入口的瞬间，王林从漩涡内飞出，一把抓住元神急退回漩涡离开，行云流水、与清水配合极为默契。
- 临行前，王林看到清水左目疯狂中透出**一丝信任**；王林道：「清水师兄，我会尽全力。」
- 出漩涡后王林把玄宝上人元神**扔入储物袋**，随即眉心**第三目**张开，本源之力顺红芒成扇形散开对准漩涡。

## 三、金龙追击与古神肉身抗击

- 金龙改向穿梭钻入漩涡，迎面撞上第三目红光，身子一震——红芒内有**一丝令其心神深处极为震惊的力量**（虽微弱不足以威胁），庞大身躯不由自主一顿。
- 王林借这一顿钻入后方肉壁，全速**向上**（而非向下）游走逃遁，沿途掐诀感知先前留下的后手，面露狠辣阴沉。
- 金龙视王林为蝼蚁，认其抢走玄宝元神是「犯了天威」，追击中一声咆哮，蕴含极强元力震动肉壁，王林一颤喷血却借力加速。
- 王林自忖：若非**古神肉身**，方才一击立刻就会元神崩溃而亡；即便如此仍剧痛阵阵。

## 四、引爆飞剑：望月吐出所有人

- 王林低喝「爆」，引爆此前藏于望月体内**十多处敏感位置**的飞剑。
  - 望月身上有几处位置极为敏感，重创虽不致伤却带来难以想象的痛楚、令其怒火冲天。
  - 在庞大的望月体内找到这些位置几乎不可能——**除了王林**。
- 黑暗虚无中无目的飘荡的望月剧震怒吼，体内肉壁疯狂挤压扩散、乾坤颠覆般晃动；望月延展身躯、张口喷出体内之物。
- 被喷出的顺序与去向：
  1. **金龙**（第一个被吐出）
  2. **王林**（肉壁层层打开直通望月之口）
  3. **清水**（正在漩涡狭长通道中与手臂恶战，被冲击卷出）
  4. **一木子**
  5. **武东禅**

## 五、虚无中的元力压制

- 落入虚无瞬间，众人体内**元力与仙元**被层层无形封印、急速消散压制。王林试图自行封印元力仙元以延缓，毫无作用。
- 惟独**古神肉身**中蕴含的古神大力不受任何影响 → 王林最为轻松，索性不再理会体内元力，握拳盯着金龙冷笑，但按捺不动：「眼下还不是最好的时机，再等等。」（不断后退）
- 各方抗压制手段对比：

| 人物 | 手段 | 效果 |
| --- | --- | --- |
| 一木子 | 体外三根**紫色木条**环绕 | 面色苍白，消散略缓，无法彻底阻止 |
| 金龙 | 身体无形之光闪烁 | 勉强抵抗，明显不如一木子 |
| 武东禅 | 体外巨大**气泡**隔绝四周 | 最为轻松，但气泡持续消散需随时以元力补充 |
| 清水 | 右手一绕**画地为牢** | 硬生生抗住，但不能坚持太久 |
| 王林 | 古神肉身（不抗，无需抗） | 不受影响，最轻松 |

## 六、极贤天现身与「古神傀儡之术」

- 望月双目处浮现漩涡，从中露出人影——竟是**极贤天**。
- 此时的极贤天双目黯淡、时而闪过挣扎，随后一声尖锐之啸，整个人从双目间的漩涡内飞起。
- 王林以**古神之体**在极贤天身上察觉到**古神的气息**，判断：极贤天是一个**古神星点所化**，或者说被古神一星融合，成为**非仙、非修、非神**的存在。
- 王林脑中浮现**涂司记忆**中的一门神通——**古神傀儡之术**，唯有**成年古神**才可施展。
- 关键判断：「这极贤天身体内，有古神一星。吸了他，我就可以获得古神一部分的力之传承。」
- 实力评估：古神一星融合所成的古神傀儡，与寻常一星古神不可比——极贤天的一星**来自八星古神**。

## 七、埋线与看点

- 玄宝上人元神已在王林储物袋中（被呼风之印决封印、昏迷），成为后续筹码。
- 王林与清水的因果加深：清水有恩于王林 → 王林出手相救 → 清水报以信任。
- 虚无中元力压制的格局对王林最有利，他正在等「最好的时机」对金龙动手。
- 极贤天成为王林下一个目标：吞其古神一星以获取古神力之传承。
