# 仙逆 第1042章 铁剑（第八卷 联盟隐秘）

## 一、场景与前情
王林身处冰封之地，面对一颗眼神仍带痛惜与愤怒的**八星古神头颅**（承第960章「冰封古神头颅之主」相关线索）。他感慨：古神并非星空下永恒的存在，但确是最强的一族；当年古神一族至今几乎灭绝，若说是修士所为，王林绝不相信。

参照系：强如**雷之仙界**，为战一个虚弱的八星古神也要倾整个仙界之力、无数仙人围攻，最终惨胜。八星古神的**碎星之力**虽未至九星，却足以毁灭天地。

## 二、开路与验伤
- 王林以元力融入冰块，激发**火焰之力**，冰块内外火光弥漫化为白雾升空；冰内封着的一具**仙人尸体**被火焰一冲化为碎末四散。
- 打开通道后下沉至头颅底部**颈部断口**处。透过厚密冰层可见：伤口**极为整齐，没有半点齿状**。
- 结论令王林头皮发麻：这古神当年是被人**瞬间一刀砍断头颅**，毫无停滞。
- 首个猜测：「莫非是**青霖**？」——若青霖有此神通，则强得超出王林想象。

## 三、二十三粒暗红结晶
- 神识横扫头颅内部无异常；细看伤口深处边缘，发现**细小暗红色结晶颗粒**，极易与凝固血液混淆。
- 王林谨慎操控火焰之力，在冰块上溶出一条缺口通道直达伤口，吸出颗粒查看。
- **颗粒内含一团无形、无色之气**，缓缓运转，似随时可散。
- 神识融入的瞬间，遭遇**无法形容的威压**：仿佛脱离天地，世界只余暗色，唯余此气的威压。王林几乎下意识松手，强忍住继续观察。
- 此气的性质（一千多年修道从未见过）：
  - 非仙气、非灵气、亦与修士元气无关；
  - 但细究之下**同时包含仙气、灵气、元气**，还有王林看不出的气息；
  - 如同大杂烩，却**完美结合、如同归一**；
  - 其内**蕴含无数规则**——王林凭**天逆之力**所见的一切规则皆在其中，更有众多他前所未见的规则。
- 王林收回神识时面色苍白，直觉手中不是不起眼的颗粒，而是**一旦爆开便有莫大之力的「崩溃之源」**。
- 取用：连同第一粒在内，共**二十三个颗粒**，尽数谨慎收入**储物袋**。此后伤口内再无颗粒。

## 四、指向「天道」的推论
- 王林判定：正是这股力量砍下了古神的头颅，而**拥有这股力量的绝非青霖**。
- 记忆回闪：当年在**朱雀星**为救**李慕婉**与**天道**一战，天空幻化而出的**天道使者**竟是**被封印了古神星点的古神**。以今日修为回看，那一幕内藏惊天动地的隐秘。
- 呼之欲出的问题：**什么样的力量能封印古神、更能操控古神成为天道使者？** 王林心中浮出二字——「**天道**」。
- 疑难：天道是虚无飘渺之物，如何能做到这些事？他由此想起**古妖贝罗**曾说的「古之一族的隐秘」与有关「**逆修**」的话语。
- 王林脑中构想的画面（自承不知真假、只是据现有信息略作猜测）：
  1. 无尽星空中，一个八星古神叱咤天地；
  2. 突然有一股无法形容的力量从天而降；
  3. 古神为抵抗而**粉碎全部星点**，最终仍失败，**头颅被生生砍下**；
  4. 头颅后被**仙界**所得，不知为何放置于此；
  5. 残余在颈部的力量经岁月洗涤未散，**化作一个个颗粒**，残存一丝当年那力量的气息。

## 五、红线缠绕的铁剑
- 正欲离开时，王林瞥见颈部伤口深处**红光一闪**，神识扫过却毫无发现。
- 以火焰之力将冰层缺口通道向内大范围延伸，直至深处，终于看到：
  - 一把**铁剑**，其上被**无数红线包裹**，红线**缓缓蠕动**、死死缠绕。
  - 铁剑本身很是寻常、**几处锈迹斑斑，看起来仿若凡人之物**。
- 关键异常：**神识始终探测不到该铁剑与红线**（前后两次扫过皆「无异常」），唯有**肉眼**在打开缺口后可清晰看见。王林由此大为警惕。
- 王林从红线上感到**可怕的危机**，认定太过诡异，**不动声色缓缓后退，不轻易碰触**。

## 六、记忆解锁：朱雀墓的同一把铁剑
- 后退中王林猛然想起：当年在**朱雀星·朱雀墓**内，他曾见过**一模一样的铁剑**，只是**其上锈迹不同**。
- 当初那把铁剑**最终被托森使者夺走**；托森使者得剑一刻**眼中的狂喜**，王林至今记忆犹新。

## 七、悬念与待解
1. 一刀断古神之头的力量究竟为何？是否即「天道」本身或其背后之物。
2. 二十三粒结晶（含无数规则的无形之气）的用途与危险性。
3. 神识不可见、唯肉眼可见的铁剑与蠕动红线的本质。
4. 朱雀墓铁剑与此处铁剑的同源关系，以及托森使者夺剑的真实动机。
5. 古妖贝罗所言「古之一族的隐秘」与「逆修」如何与天道封印古神相扣。
