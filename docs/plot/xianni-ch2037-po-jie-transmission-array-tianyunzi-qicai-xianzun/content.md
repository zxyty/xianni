# 仙逆 第2037章 破界！

## 场景
成为废墟的荒山内，巨大阵法雾气消散，露出盘坐阵心、全身缭绕十色光芒（光芒不浓）的老者身影。

## 神秘老者的身份谜团
- 相貌与**天运子**极为相似，王林凝神再看，觉得更似**天运子与七彩仙尊相貌重叠**。
- 开场即道：「王林，我们又见了。」神色从容，笑容中似有贪婪、似有追忆，目中深处藏有**一丝忌惮**。
- 王林问：「我该称呼你为天运子，还是七彩仙尊？」老者答：「老夫的名字很多，但如今，还是喜欢天运子这个称呼。」
- 王林低吼质问「天运子已经死了，七彩仙尊也已经魂飞魄散，你到底是谁」，老者仰天大笑：「这天地间除了我自身外，就只有一个人知晓，而你，用不了太长的时间，也会有知晓的那一日。」
- 王林心中定性：不管是天运子还是七彩仙尊，此刻他**是道古皇尊，是取走婉儿（李慕婉）残魂的幕后之人，是王林要杀之修**。
- 老者看王林的目光复杂、贪婪且忌惮——这种目光王林昔日在天运子身上见过，如今因自身已成**大天尊**而看得远比当年清晰。

## 阵法：传送 + 破界
- 老者右手一拍阵法，阵法轰然运转，光芒刺目、引动天地之力并扩散推动之力，连数百丈之躯的王林都被推退数步。
- 王林凭阵法禁制造诣一眼看出：**这是传送阵**。
- 阵法运转至连大地都隐隐震动，王林质疑「这是什么传送阵，竟可以撼动大地」「此阵，不全是传送吧」。
- 老者承认：**「此阵的确不仅仅是传送，它还有一个作用，就是真正的打开一处古老的大门。」**（呼应章名「破界」）
- 老者两次叹息「可惜，你杀的人还不够」「可惜，你的杀戮不够」，暗示开门与**杀戮**相关。
- 老者称已为这一天「等了太久的岁月」，并邀王林坐下详谈、许诺解开不少疑惑；王林以「我不习惯隔着阵法与人交谈」拒绝。

## 王林的三次强攻（皆无效）
1. **一拳**：身高七八百丈，右手轰击阵法 → 遭莫大反震，右手被生生弹起，阵法无丝毫损伤。
2. **一脚**：身躯膨胀至千多丈，右脚踏落 → 再度被反弹之力震退。
3. **抽天地之力的巨拳**：青色血管、面部青筋鼓起，身躯膨胀至数千丈、隐隐近万丈，双目无尽银光；一拳抽来方圆十里→百里→千里→万里乃至十多万里天地之力，拳如黑洞。阵法光芒虽崩溃四散，但拳头**直接穿透老者之身、穿透阵法**落于大地，山峦爆开、地面现出巨大窟窿——而老者与阵法**依旧完好如初**，仿佛二者与王林**处于迥然不同的空间**。

王林随后收缩身躯（因缩得太快，巨影成虚），化作正常大小的白衣之身，迈步走入阵法——形同穿透，仍如处不同空间。

## 王林的终极准备
- 挥手凝聚**五行真身**，与本身重叠融合；**杀戮雷霆真身**化作大量黑气融入体内。
- 身后浮现**黑白二色的大天尊之阳**，内隐有**仙祖头颅**（此头颅为王林在道古皇宫取出又收走后重新融入阳中）。
- 修为不断攀升，达**空劫大圆满**后仍不止。
- 虚空一抓取出**仙皇之魂**，将全身修为之力涌入，令其睁眼爆发金芒（无神智），挥手送入大天尊之阳、融入仙祖头颅。
- 大天尊之阳随之暴涨——先扩大十倍，融魂后达到**最早之时的百倍**，再增数倍。
- 王林睁眼喝道：**「燃，大天尊之阳！」** 黑白火球骤然烧热，火海滔天。

## 老者的应对与章末悬念
- 老者神色骤变、面色阴沉，指点虚空驱使被阵法笼罩的**巨大苍蝇（苍蝇之兽）**扑向王林；该兽在王林前方数丈外被一层无形屏障阻挡，暴躁撞击不得寸进。
- 见大天尊之阳燃起，老者猛然站起身，急声低吼：**「你不想让李慕婉，真正的复活了么！」**（章末，以李慕婉复活为筹码要挟王林收手）

## 关键伏笔
- 老者的真实身份：唯一另一个知情者是谁？王林「不久后也会知晓」。
- 「古老的大门」是什么界、开门为何需要足够的杀戮。
- 李慕婉「真正的复活」——老者手握婉儿残魂，成为制衡王林的最大筹码。
