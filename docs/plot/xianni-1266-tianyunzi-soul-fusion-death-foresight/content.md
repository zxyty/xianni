# 第九卷 云海之巅 第1266章 一线生机！（第一更）

## 一、云海暗流：神宗的三重封锁

一股来自**神宗**的暗流在**云海星域**内急速流淌，干扰了一系列人与事。

- **李倩梅**被其宗门封困，三个月内不得走出半步。其师尊从万年闭关中现身，亲自阻止这个最重视的弟子；师尊自有苦衷——为了李倩梅的安危，不得不如此。
- **木冰眉**与**王珊珊**前往神宗，却始终未见到王珊珊之师、神宗最高权力者**大长老水道子**。木冰眉踏入神宗的瞬间即被限制自由，被安置在一处闭关之地：神宗可提供一切恢复修为的丹药，但不允许她踏出半步。
- **神宗取消了八阶宗派大比**。木冰眉与李倩梅均不知情——文中点明，若木冰眉知晓此事，以其心智必生猜疑，纵不能直悟本心，也会找出端倪。

## 二、归元宗迁移在即

**莫罗大陆**上，归元宗弟子在**吕烟菲**等人的匆匆召集下，用三天时间收拾完毕，准备迁离这生活了无数年的五阶星域与莫罗大陆，前往**无极宗**已为其开辟并修建好的**新归元宗山门**。

## 三、第一次推衍：融合天运子之魂

王林（此时在归元宗以化名「吕子浩」立足）盘膝于归元宗密室，将心神与元神内**封仙印**中的**天运子之魂**融合。融合刹那，他「便成为了天运子一般」，天地一切之事似乎尽在知晓——但这只是表面。

- 双手掐诀，心神弥漫直冲天际、与天地交融，历时一天终于做到「天就是他，他就是天」。
- 说明：若只是施展天运子的**神通攻击**，无需如此深度融合；此番深融，是为借天运子魂内蕴含的**一丝其本体知晓天地、预知之事的能力**，强行推衍那令他心惊肉跳的根源。
- 推衍极难——他毕竟不是天运子。心神内被无边迷雾遮掩，始终有一股力量遮盖天地。
- 王林全身元力运转、更深层融合，直至**遗忘自己正在修道、遗忘身在云海莫罗大陆归元宗**的刹那——迷雾骤然旋转成漩涡，心神内一声雷霆自天地降临劈落，漩涡崩溃四散。

**所见画面**：天空中隐隐现出**一双无情冰冷的眼睛**，冷漠俯视画面大地上一个**抬头看天之人**。王林心神剧震如百万天雷炸响，险些崩溃，迷雾随即重新凝聚遮蔽画面。

他猛地睁眼，面色苍白，断言：
> 「那大地，是莫罗大陆……那抬头看天的修士，是我……那双眼睛的主人，修为通天，在他面前，我必死无疑。」

此时莫罗大陆天空一片晴朗、风和日丽。

## 四、第二次推衍：撒豆成兵·魂魄归位

王林不甘心，欲再看一次。右手掐诀一指眉心，口中飞出幽光化作**封仙印**——印身急速旋转、呜呜作响，可令闻者心神震动。

他打出印记落在封印上，幽光大闪照亮密室，**天运子之魂**自封仙印内幻化而出、一步走到他身前。王林罕见地念出口诀：

> 「撒豆成兵，魂魄归位，天地无极，容纳奉天。」

此为**撒豆成兵之术**内蕴含的极深道意。口诀出口刹那，天运子之魂双目精光爆闪、猛地向前一迈，**穿透王林身体**与之重叠，随即转身与王林同一方位、缓缓盘膝坐下——宛如天运子之魂成为了王林的元神，元神归位、彻底融合。此已非先前心神融入封仙印的融合，而是真真正正、彻彻底底的融入，分不清王林与天运子的区别，其身体时而成为天运子、时而成为自身。

**上千幅必死画面**（迷雾更浓，仍被一声低吼震碎）：
1. 王林喷血，在莫罗大陆上肉身崩溃，元神刚飞出即轰然消散；
2. 面色苍白疾驰星空，前方现出一面**齐天巨镜**，镜中仍是那双眼睛——一眼之下全身崩溃、元神死亡；
3. 自归元宗密室抬头，毫不犹豫冲出、不理会收拾中的弟子，向星空疾驰；逃遁不知多久，星空轰鸣，**两道目光穿透无数星雾**直接落在他身上；
4. 王林**化作古神**咆哮与天相战，天空中一名**身穿道袍的老者**只是抬手向下一指，他便骤然失去一切行动，任由老者临近、按在眉心，轰然死亡。

画面不断转动，成百上千次想尽各种方法挣扎与逃遁，**最终皆是「死死死」**，无一种能活。

王林睁眼时冷汗浸透衣衫、全身冰寒，眼中露出疯狂与更多的不甘。

## 五、王林的判断：第三步大能亲身来杀

他至此确定：
- **李倩梅的离去**与自己有关；
- **木冰眉的离开**与自己有关；
- **八阶星域大比的终止**与自己有关。

结论：有一个极为强大的**第三步大能**要杀他——且**不是**七彩界内太古星辰的**道尊**那样隔着天地施展的一掌之力，而是**亲自、本体前来**索命。

> 「我王林一生逆修，生死危机无数……我不信找不出破局的方法，若真找不出，唯一死尔，何憾！」

## 六、召逆行者·算天地之术

- 王林右手虚空一抓，**储物裂缝**开启，飞出数颗**仿造的天逆珠子**。
- 取其一颗，双眼绽放**七彩之芒**笼罩全身并融入珠内；珠子吸收七彩之芒后轰然崩溃，化作**七彩漩涡**浮于身前。
- 王林咬牙猛吸，将漩涡吸入口中，心神轰隆。
- 低沉萧杀地喝出：**「召，逆行者，算天地之术！」**——以自身为天地，在体内召唤**逆行之术**，推衍未来生死的一线生机。

浩荡之力在体内爆发、冲入心神，**撕裂一切迷雾**，现出最后一幅画面：画面中有一个人，开口道——

> 「老夫刘金彪，道号金彪子。」

## 七、要点与悬念

- 神宗一系列反常举措（封困李倩梅、软禁木冰眉、取消八阶宗派大比）是同一因果的三个侧面，指向王林即将面临的杀局。
- 天运子之魂的价值被明确分层：**攻击神通**只需浅融合，**预知天地**需极深乃至「忘我」的融合，且仍只是借其本体能力的一丝。
- 仿造天逆珠 + 七彩之芒 → 「逆行者·算天地之术」，是王林手中层级更高的推衍手段，突破了天运子之魂的推衍极限。
- **刘金彪（道号金彪子）** 是本章揭出的唯一「一线生机」线索，身份与作用留待后文。
