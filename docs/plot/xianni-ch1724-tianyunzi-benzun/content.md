# 第1724章 天运本尊！

## 一、本尊线：撕裂星空，直取半个罗盘

### 撕空而行
- 本尊「道古」身影在星空疾驰，速度**比分身更迅猛**：既非依靠蛮力，也非如分身般融入天地，而是**生生撕开星空**。
- 手法：右手在双脚迈步刹那向前猛撕，星空轰鸣，巨大裂缝豁开，身子瞬息钻入，出现时已离开召河。
- 此法达到王林**肉身的巅峰速度**，整个洞府界仅他一人敢用。

### 为何唯他可行
- 空间裂缝内有**无数毁灭的风暴与乱流**，对寻常修士足以致命。
- 古妖、古魔在其中很难坚持；强悍如**古神**或可挺过几次，却无法长久。
- 唯有**比古神肉身还强悍无数倍的道古身躯**、唯有拥有**道古血脉**的王林可从容踏入。风暴卷在其身上反被撞得哀嚎崩溃。

### 昆虚星域·废弃蛮荒星
- 王林自昆虚星域星空裂缝中一步走出，闭目以**道古所修神识**横扫四周，旋即直奔远处。
- 自召河从天运子轮回中苏醒至此，**仅数息时间**。
- 目标星象：完全废弃的蛮荒星——无任何生命迹象；大地几乎尽为沙漠；河流干枯河道被沙掩埋；大海一片漆黑，内有无数海洋生命腐尸污秽；昏暗雾气遍布，含大量毒瘴，凡人吸一口即全身腐烂而死。
- 此星**半点灵气都没有**，故无修士来此；连毒修也不选此地——毒瘴对修士毒性并不强烈，令人皱眉的是那充满腐尸恶臭的气味。
- 认定依据：虽与轮回中所见的修真星多有不同，但**「此星之魂」的气息绝不会错**——当年之魂尚在初生阶段，眼下之魂已处于死亡之中。

### 取宝
1. 冲破脆弱罡风层，踏上沙漠大地；其入星刹那，狂风横扫毒雾，如掀开面纱。
2. 身形一晃直上黑色死海上空，向下方海洋直冲。
3. 黑海卷起巨大漩涡，直连海底，四散卷开，露出海底深处**厚厚的黑色淤泥**。
4. 淤泥沉淀不知多少万年、从未见天日，此刻散开，露出被淤泥与海洋掩盖万古的大地——遍布低矮秃山。
5. 王林穿透海底大地直下。海底无尽之处有一**万古岁月前形成的溶洞**，地面满是褐色尘土（历次大地震下的尘埃），尘土下埋藏着**半个罗盘**。
6. 一阵轻风掀动万古不移的尘土，露出罗盘一角；王林一手抓角提出，眼中光芒明亮，自语：「我们，谁快呢？」

## 二、分身线：天运子第九十九次觉醒

### 魂归与占据
- 召河星域内，来自**四大星域的所有天运子之魂**已全部来临；最后一缕魂进入王林分身刹那，盘膝的分身猛然睁眼。
- 分身双眼露出挣扎痛苦，体内天运子魂疯狂占据其全部心神；**因轮回一体术的存在，这种如同夺舍的方式任何人都无法干扰**。
- 异象：分身右眼扭曲消散、被幽光取代；左目瞳孔颤抖后平静散出幽光。苍老腐朽的阴森话语出口：「王林，你有老夫快么？」
- 天运子索性不走，要让三人「亲眼目睹我第九十九次觉醒」，遂盘膝闭目。

### 融合方式与野心
- 与以往**直接吞噬**不同，此次选择**从内部吞噬**，以求万无一失。
- 融合即沉睡，融合完毕即觉醒；短短时间内融合大半，瞬息后完全弥漫吸收。
- 觉醒后仰天大笑：「九十九次觉醒，老夫终于觉醒了这最后一次。天道，老夫就是天道！」白发飘动，古老气息扩散，身上弥漫一片雾气——正是王林在轮回中所见的**天道形态**。
- 后续图谋：找到**其当年分离出来的另一团雾气**，融合后**重掌轮回**，成为有自我神智、有超越许多人心智、且会神通术法、不需人喂养可自行成长的**与众不同的天道**。
- 危险性：无意识的天道艹控众生尚可，一旦有意识有灵智则极为可怕——他甚至可吞噬一切天道繁衍的众生；届时洞府界内剩下的一定是**非此地诞生之灵、三魂七魄、所有仙罡大陆之人**。

### 三人拦阻与隔空宣战
- 在场：蓝梦道尊（蓝光弥漫、神色平静）、青霖与红衫子（目光炯炯、神色紧张）。
- 天运子欲走，蓝梦道尊蓝光一闪拦在身前：「我答应了他，不会让你离开这里。」青霖与红衫子同时逼近。
- 天运子大袖一甩，张口向前一吞：星空震动、乾坤似逆转，无尽雾气遮盖三人视野，雾内幻化一张虚幻大口欲吞噬三人。
- 蓝光一闪，一股极强气息惊天而起，与雾气骤然轰击一处。
- 同一时刻，星空尽头传来冰冷透着杀机之语：**「天运子，王某取你本尊归来！」**

## 三、要点与看点
- 双线并行、以「谁更快」构成本章张力：本尊夺**半个罗盘**（对应天运子那另一团雾气/本尊线索） vs 分身内的天运子完成**第九十九次觉醒**。
- 分身的一切经历，**本尊可以感受**——是双线信息互通的设定基础。
- 天运子的败因伏笔：他自以为占据分身即胜局（「即便你本尊没死又如何」），却不知王林本尊已在昆虚星域直取其本尊所在。
