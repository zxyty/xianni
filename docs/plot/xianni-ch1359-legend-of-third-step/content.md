# 第1359章 传说……（第九卷 云海之巅）

## 一、擒拿大长老残魂

- 闪雷族大长老元神先受剑气所伤，再在**不灭雷霆**与**七尺长剑**碰撞的冲击之力下大半崩溃，仅余一缕残破元神：记忆消散大半、神智模糊，本将消散于天地之间。
- 王林祭出**昆极鞭**，金光闪烁横扫而至。昆极鞭化作金色光线后可长可短，一拽之下便将这位往昔高高在上的大长老残魂抓在手中。
- 王林的判断：这是**天人第五衰**、再迈一步即可成大能的元神。
  - 单单杀死炼成**撒豆成兵之魂**便极为强悍；
  - 更有元神内蕴的**天地之力**与**对雷霆的感悟**。
  - 对外人而言堪比天材地宝，在王林手中「比之天材地宝还要重要数倍不止，几乎堪比一次造化」。
- 王林原话：「此人元神，我有大用。」

## 二、七百万天地归墟

- 大战之后，七百万天地千疮百孔，世界尽头崩溃、风暴肆虐，毁灭气息吞噬一切。
- 此界本为他人制作而出，此刻尘归尘土归土，砰砰崩响如敲丧钟，为其消散画上休止。

## 三、大长老之死的余波（王林的形势判断）

王林在太古星辰吞噬大量修士、获得众多记忆碎片，由此得知：

| 事项 | 内容 |
|---|---|
| 闪雷族地位 | 太古星辰**大族** |
| 大长老地位 | 在族中如同**王皇**，有绝对权威；太古星辰内声名赫赫，除稀少的第三步大能外几无人敢惹 |
| 战略价值 | 闪雷族**族中圣器曾被送入封界大阵**，故大长老对太古星辰很是重要 |
| 对比拓森 | 拓森在太古星辰多年杀人无数，但从身份上从未遇到如大长老这般人物（明知不敌者多是族人先上、自身早遁） |
| 后果 | 其死足以震惊整个太古星辰，必掀起浩劫；七百万天地之人走出后闪雷族必将覆灭，一个大族全族瓦解会引起高度重视 |
| 未知数 | 王林不知太古星辰的第三步大能是否有神通可察觉此事；无论如何，等待他的将是绝大危机 |

王林目光一闪：危机滔天，但**不会退缩**。

此战的自评：比当年战**水道子**还要激烈——水道子一战他没有反抗之力，而大长老不然；若非与**散灵上人**联手，绝不可能杀死这天人第五衰的大神通。

## 四、仙族出世

- 散灵上人卷全族之人顺虚无缺口而出，踏入**太古星辰闪雷族星域**。
- 因在散灵神通保护下，残存的修士与凡人不因修为或身体原因死于星空。
- 散灵仰天长笑而后痛哭，宣言：
  > 「这就是仙界……既然这里有闪雷族，有各个族落，那么就应该有我们**仙族**。」
  > 「从现在开始，我们，自由了。」
- **代价**：七百万天地之民死亡九成，最终脱困者仅剩数百万。
- **报恩**：散灵抱拳立誓「我整个仙族，世世代代永不忘记，但凡道友任何要求，我仙族赴汤蹈火，无敢不从」，全族附和；并右手一挥幻化出**上万灵念之雷**尽数飞向王林。王林大袖一甩收走——这是他应得之物，而每一道念雷都代表一个**渡劫修士**的性命。

## 五、王林的心境：天地为圈

- 王林望着太古星辰星空，渴望有一道破开一切的目光去看星空之上是什么，喃喃「真的，脱困了么」。
- 脑中浮现当年在**云海星域**与**卢云从**、**李倩梅**三人一夜论道：**天地为圈**——即便走出一个圈子，外面还有一个个无形之圈，又如何走得出去。

## 六、决策：再攻闪雷族，吞不灭雷霆

- 王林提议：「闪雷族不灭雷霆之前受创，我要再攻闪雷族，吞那不灭雷霆。」
- 散灵眼露杀机应允：不趁现在彻底毁灭闪雷族，解不了九成族人死亡才得脱困之恨。
- **本体出手**：王林右目雷光闪烁，化作一道雷霆前行——此番是**本体**前往，比当初仅以一缕元神夺舍而去强大数倍不止。
- **敌情评估**：闪雷族唯大长老（天人第五衰）令其忌惮；余下尚有**两个天人第四衰**的修士，但因其所修是雷道，王林毫不畏惧——雷修之战比的是对雷霆的操控。
- **本源优势**：已吞噬**八条太古雷龙**，又得**上万念雷**，虽未及寻地彻底炼化，雷霆本源之强已惊天动地，两名天人第四衰的雷修绝对无法相比。
- **战术**：直奔闪雷族**十六颗修真星组成的防护大阵**——「此战要快，要尽最快的速度轰杀进去，吞噬那不灭雷霆，立刻离开。」
- **异象**：王林雷之本源太强，一路所过星空雷霆自行凝聚环绕，如帝王出行千军万马；片刻即成铺天盖地的**雷域**，无上雷威堪比天劫，即便第三步大能见之亦会双目一凝。

## 七、设定要点：成为第三步大能的两条路

1. **香火之路（较广为流传的传闻）**：依靠门徒香火之力不断壮大滋养本源，最终有可能打开**天地大门**，本源浑然大成、脱胎换骨、全身惊天之变，迈入第三步，从此不是修士，而是**大能**。
2. **更古老的传说（几乎无人知晓）**：不依靠任何香火与外力，凭自身感悟，以一种已无人知晓的方法**一己之力本源大成**，一举**轰碎天地大门**成为第三步大能。以此方式成就者，**将在第三步内自身成为传说**。

> 王林的修道，正在向着这个传说，一步步逼近。

## 八、归属提示（据世界状态须知）

- 王林自第1242章起以一部分元神夺舍**于非**之身潜入闪雷族；本章正文直呼王林本名，且明言此次为**本体**前往（与当初「一缕元神夺舍而去」相对照）。
- 「闪雷族大长老」为独立人物，本章其残破元神被王林擒获，非王林冒名。
