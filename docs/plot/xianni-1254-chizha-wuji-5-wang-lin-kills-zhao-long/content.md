# 第九卷 云海之巅 · 第1254章 叱咤无极（五）

> 主角王林本章以化名/冒用归元宗故人姓名「吕子浩」行事（自第1063章由吕烟菲奉上），文中「吕道友」「吕某」均指王林。

## 一、天运一指的原理与代价
- 天运一指**不是仙法**，消耗的**并非仙力**。
- 施展机理：王林**刹那间心神与元神内的天运子魂魄融合，借魂而出**。
- 消耗：**天运子的逆行者魂魄之力**，更多的是**王林自身的元力**；因修为增强方能随手施展。
- 威力：与**天运子亲自施展相比差之极大**（修为不同、施展方式不同）。
- 动机：王林**受伤未愈**，须表现神通高深莫测以震慑全场，达成其在无极宗的目的。
- 底牌：**蚊兽为保命杀手锏**，非万不得已不唤出。

## 二、震慑余波（承前情）
- 瞬息之间：毁**仙音门分宗宗主**肉身、杀**分宗大长老**、杀**分宗大弟子吕英杰**。
- 无极宗长老**冯海**出言欲阻，王林答：「**救他者，同罪**」。
- 数万（近十万）观望修士心神震撼；血腥气随风飘散，大地余震未歇。

## 三、逼杀赵龙
1. 王林转身走向**寻栾宗**方位，煞气渐弥漫，每一步都令寻栾宗门人心惊，如面对远古凶兽。
2. **寻栾宗宗主**（碎涅）与**寻栾宗大长老**（碎涅中期巅峰）认出王林即前段时日逼得本宗迁移大陆、横闯七阶星域之人，且大长老亲见其**役灵印**下绝代风华，自忖非敌。
3. 二人判断「为一长老与此人对抗，实为不智」，先后侧身避让 → 寻栾宗与他宗修士纷纷让开，**赵龙元神被孤立于空地**。
4. 王林指向赵龙元神：「**你，出来。**」
5. 赵龙绝路怒吼「老夫跟你拼了」，**燃烧元神**换取瞬间力量，修为由**碎涅初期巅峰暴增至碎涅中期**，化作数十丈燃烧流星直冲王林，喊出此生最后一吼「你要我死，也需付出代价」。

## 四、冯海求情与王林的回绝
- 冯海立场：身为无极宗长老、负责此番大比；**当年出身寻栾宗**，后成无极宗长老，故不能坐视赵龙死。七阶星域宗派对无极宗每人皆宝贵；若是背靠破天宗的李倩梅出手，他无话可说。
- 冯海出声「吕道友，还请给老夫一个薄面，莫要动寻栾宗之人」，一冲而出。
- 王林体内**滔天煞气骤然爆发**，风云色变、如无数冤魂幻化，冯海感到再进一步即入绝杀范围，身形一顿。

## 五、一脚踏灭
- 王林**不用神通、不闪不避**，向前一步、身如风转，**右脚扫在赵龙燃烧的元神上**。
- 白发飘动、白衣飞舞，轰鸣震天，流星崩溃化作点点晶光四散；**赵龙燃烧元神亦难免一死**。
- 王林收腿从容，冷视四周，对冯海道：「**这位道友，你的话语，晚了。**」冯海阴沉无言，转身走回无极宗看台。
- 全场死寂后哗然：**神通惊人，肉身更是惊人**。无极宗宗主眼露明亮之芒——区区仙音门、寻栾宗，与这大神通修士相比微不足道。

## 六、公开挑战
- 王林宣告：「**吕某代表归元宗，欲要挑战六、七阶星域所有分宗，何人，第一个出场**」。
- 卢云从深吸口气压下震惊，望向修士中的**袁飞**，露出似笑非笑之色；袁飞面色苍白，沉默不敢起身。
- **七阶青云道·云杉**平淡出声：「在下七阶青云道云杉，欲与吕道友切磋一番。」→ 下一战对手确定。

## 七、文本存疑点
- 结尾旁白作「杀寻栾宗**赵海**」，与全章「赵龙」不一致，疑为原文笔误，本条以**赵龙**为准。
