# 第九卷 云海之巅 第1326章 追杀（第三更）

## 一、危局：本尊一指压境

- 白衣女子召来的洁白如玉手臂食指，威力强大到崩溃光影盾后按向**呼风唤雨界**，令此界剧烈颤抖、随时可能瓦解；手指探入按出巨大凹形并不断深入，界内乳白色气息疯狂对抗欲抵消指力。
- 王林急退，心神清晰感知呼风唤雨界撑不了多久，双眼露出疯狂，右手一挥打开**储物裂缝**。
- 呼风唤雨界急速收缩、完全收入王林体内，手指再无阻碍直奔王林眉心；王林低吼间自储物裂缝取出**古神指骨**挡在身前。

## 二、以指骨换一击，血剑斩断手臂

- 食指按在古神指骨上，轰鸣回荡震得四周星空颤抖。
- 王林喷出一大口鲜血，随古神指骨齐齐后退；一道无形之光穿透指骨，从其胸口洞穿、后背透出，带起血雾。
- 手指亦在接触瞬间一顿并变得透明似要消散。
- 王林不顾剧痛（换旁人第一念必是逃遁），神色狰狞，抬右手凝血光化**血剑**狠斩。手臂欲抓血剑，血剑却径直穿透手臂并将其一分为二。
- 隐隐传出娇柔闷哼，手臂骤然消散如从未出现；白衣女子身前**玉佩**随之爆开化作碎末，她面色苍白再喷一口血，融入天地遁走。
- 王林胸前血肉模糊仍喝道「你逃不掉」。因身为**古神**恢复力强悍，片刻间伤口即现愈合迹象；他收起法宝，循白衣女子遁走时掀起的波纹余力追去。

## 三、攻守易位：太古星辰内的追杀

此前是白衣女子追杀王林，此刻完全相反——她仓惶而遁，王林狰狞死追。

王林的判断（内心独白）：

1. 此女修为诡异，**看似投影分身却拥有血肉、如真实存在**；若真如此，她必须死。
2. 不趁其重伤斩杀，日后麻烦不断。
3. 此女身上定有隐秘——方才神通分明是**将本尊之力召来**。
4. 若非自己在蓝丝族神通变得强大，此战必死无疑。
5. 此女比王林更熟悉**太古星辰**，必须尽快下手，否则被她逃往无法追寻之地则前功尽弃。

追逐细节：

- 白衣女子踉跄现身某处星空，罕见地露出惊慌，本要瞬移离开却神色一变、咬牙改为继续融入天地急走；她刚走，王林身影即自同地波纹中闪现，不现身、向前迈出一步再次消失。
- 不到半柱香已数次交错，间隔越来越短；王林如髓入骨般的追击给她带来极大压力，这在此前是不可能的事。

## 四、香火之力暴露

- 白衣女子自语「再有三次挪移，就可以安全，只有三次」；脚下刚起波纹，天地轰然一震——**无尽雷霆**环绕成巨大漩涡搅动天地之力，硬生生打断其离去。
- 王林自虚无一步走出，神色阴冷，二话不说以云雾弥漫星空化作天地，形成**翻天印**，逆转直下、天地重叠。
- 女子喷血急退，血光自其身后一闪，从后心直接穿透。惨叫中白衣成血，其体外出现大量扭曲，扭曲中隐现无数闪烁画面：
  > 一个女子跪在地上，身前虚无伸出一只洁白玉手，按在其眉心。
- 画面崩溃后，其天灵冒出极浓郁、几乎成实质的**乳白色门徒香火之力**，其内隐透**一道金线**。
- 王林大吃一惊：此女一人的门徒香火，竟抵得上他**呼风唤雨界内近三成**。
- 香火包裹之下，血剑贯穿的伤口瞬息止血，她不顾四周元力乱流再次融入天地消散。
- 王林怦然心动：「此女若能成为我呼风唤雨界内之魂……」当即再追。

## 五、魔蝎族修真星：亮出「兰妃分身」身份

- 地点：**太古星辰·西北星域**，一片修真星，为**魔蝎族**所在。魔蝎族在太古星辰并非大族，但凶残之名人尽皆知。
- 白衣女子虚弱现身某修真星外，嘴角不断吐血，自语「还有两次，两次之后我到了那里，就再无危险」。
- 血光自虚无穿透直奔其眉心，速度太快无从闪躲挪移；其天灵乳白气息轰然散开阻挡，血剑穿透气息但被改向，从她**右肩**穿过，整个右臂再也抬不起来。
- 王林自虚无走出，虚空一抓喝道「你往哪逃」；女子咬破舌尖喷血与乳白气息融合，惊天轰鸣与冲击将自身抛出，躲过一抓，直坠下方修真星。
- 她凄厉尖啸：**「魔蝎族何在，我乃兰妃分身之一，命尔等速速阻挡此人」**——数千修士自修真星飞出，直扑王林。
- 她趁机吞下丹药，回头恶毒一瞥，身子一晃又要挪移。

## 六、千丈古神真身破阵

- 王林右手一挥，身躯疯狂膨胀化作**千丈古神真身**，猛冲向前，握拳越过众人向虚空狠击。
- 一击之下星空似要崩溃，一道巨大裂缝呲呲延长，把已融入天地的白衣女子**生生逼出**，她面色苍白后退。
- 数千修士神通法宝轰击，王林看都不看；天地一切、星空万物光芒在其千丈身外化作**光影**，一切神通法宝落上即被**轰然反射**。
- 王林如千丈光人前行，四周惨叫不断：修士被自身神通反射所伤，更有直接被撞碎身体者。
- 电光火石间王林已临近，右手抬起，向下方后退的白衣女子一拳轰击而去。（章末悬停）

## 七、要点提示

- 白衣女子的真实归属在本章被点明为**兰妃分身之一**；按世界状态须知，其此前以与李慕婉一模一样的容颜示人乱王林心神，一切言行归【兰妃分身】，勿记入李慕婉。
- 王林在云海星域一线所用化名为「吕子浩」（自第1063章由吕烟菲奉上），本章为太古星辰内战斗，文本未使用该名。
- 本章新增设定线索：**门徒香火之力**可作战力/储备度量（王林呼风唤雨界香火总量的近三成 ≈ 此女一人）；香火亦有疗伤止血之效；其内金线来历未明。
