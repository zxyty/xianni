# 第595章 最简单的天劫？不！

## 一、天劫降临：宇宙尺度的红芒

- 地点起点：妖灵之地外、东海之门当初的入口处，四周一片漆黑虚无，点点繁星笼罩。
- 一道**红芒**自至高无上的宇宙星空而来，其速度超越极限，只能称为**「降临」**——天地玄黄、宇宙洪荒，一念之下皆可至，无人知晓其始点。
- 红芒降临时，一股令万千生灵、宇宙洪荒颤抖的气息瞬间蔓延。
- 东海妖灵之地虽未打开，仍被红芒直接穿透进入。

## 二、三方老怪的感应（同一时刻）

此外尚有众多老怪同时察觉。

## 三、问鼎境界设定：朝闻道，夕死矣

- **问鼎**要求：仙力圆满 + 道心圆满，二者达到圆满后开始**融合**，此融合即为问鼎。
- 这是道心与仙力的撞击、灵魂与肉身的碰撞，是**从人到仙的进化**。
- 问鼎最大死劫在此：撞击要么成功成为问鼎修士，要么死亡，**没有侥幸**——此即「朝闻道，夕死矣」。
- 即便散仙之流亦绝无法做到；唯一的规避方式是**始终停留在婴变后期大圆满，不迈出那一步**。

## 四、天劫成因与画舫青年的判断

- 王林在天妖郡天妖城燕京万丈广场敲响**第十五下鼓鸣**、把悲伤全部宣泄而出后，道心正以难以想象的速度向真正圆满蜕变——由此引来天劫。
- 天妖城河面画舫中的青年苦笑自陈：「怎么把这件事给忘了，这小家伙是修士，与我不同。**当年我是在龙潭内集合长辈、祭祀古妖数年，才把这逆心掩盖，没有引起天劫。**」
- 青年评价：这对王林是一次考验，**若抗住天劫，他在问鼎境界内将再不会有天道干扰**。
- 青年关于天之惩罚的判断：**以雷形出现的天之惩罚有两种**；「不可能是那传说中的第二种，我有九成把握，这次出现的是第一种，也是最简单的那种」——称王林运气不错。（章题反问「不！」暗示其判断有误）

## 五、天劫异象

1. 燕京天空雷霆电蛇顷刻消失，天地转为火烧般的红色，红芒无边无际笼罩天空。
2. 红芒极快凝化为沉甸甸的大片**红云**，以燕京广场为中心不断凝聚。
3. 红云中化形出一道**红色劫雷**，尚未落下、无气息散出，纯以景观而论极美。
4. 红云云涌如红色海洋，波浪冲向中心，红色雷光瞬间闪耀照耀天地；红云内传出好似来自远古的咆哮，大地砰砰作响。
5. 红雷如流星从天而降直奔王林，天之杀气（「比杀亿亿人还要浓郁」）疯狂弥漫。
6. **阳春之季的天妖城，漫天雪花飘落，每一片雪花都蕴含天的杀机。**

## 六、王林迎劫

- 心境独白：「天道，无法阻止我的道心，但却可以降下惩罚，抹去我的存在。」并对比——当年在**修魔海麒麟城**曾见过一次天劫，这一次威力更重。
- 回顾自身与天劫的渊源（一生七百余年）：
  1. 修魔海外炼化**禁幡**，引动天劫；
  2. 为**李慕婉**逆天改命，引动**天道使者**降临；
  3. 此次保留执念、逆天而修，再引天劫。
- **第一击**：全身**三千七百多道生之烙印**疯狂凝聚全身；一拍储物袋祭出**禁幡**，抖出大量黑雾、其内无数禁制妖异闪烁。长笑「天，即便再怒，也不能抹去我的存在」，右手一指，黑芒冲天化作**巨大的黑色旋风（飓风）**迎击天劫。
  - 结果：红雷与黑色飓风相撞，巨响震得天妖城无数人双耳流血、昏厥；万丈广场看客同样如此；妖将妖力失控运转；**唯有妖帅可面不改色抬头直视天劫**。飓风如被大手自内捏碎般崩溃，红雷如利剑穿过将其从中分开，禁制化作虚无。
- **第二击**：喝「天要杀人，我要灭天」，右手抬起施展**寂灭指**——不是一道，而是十道、百道；左手一拍储物袋，大量**仙玉**倾落脚下堆成小山，他立于山上、背靠巨大妖鼓，大量仙力顺双脚融入体内。百道寂灭指合为一道，化作粗越三丈的巨大黑芒直奔红雷。
- 宣言：「我敢逆天而行，敢保留执念，便是要与这天斗。天劫，你即便可以击碎我的身体，但我的道心，你，击不碎。」目光穿透红雷直入红云——天空随即响起更大的雷声，似在回答。

## 七、旁观者视角

- 万丈广场四周所有人沉默：短短一天时间王林带给他们太多不可思议，其身影注定烙印在每个人心中。

## 八、悬念

- 章题「最简单的天劫？不！」与画舫青年「九成把握是第一种」的判断构成明显反讽，指向此劫实为传说中的第二种。
