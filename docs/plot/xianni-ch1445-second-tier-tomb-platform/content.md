# 第1445章 二阶墓台

## 一、九座血色墓台升起

古之墓地的封印之地内，九个平台上站着九名修士——全为男修，其中七人是老者，另两人约四旬。平台几乎被鲜血染红，其上漂浮着大量扭曲的魂魄，发出凄厉惨叫，血腥气冲入封印之地。

九人修为构成：

- 五人为**天人第四衰**
- 两人为**天人第五衰**
- 一名中年文士，手持羽扇、双目眯起其内有光芒闪烁，修为仅**天人第三衰**（后由青袍老者点破其名为**萧靖**）
- 为首者为一名红发如血的老者，身上弥漫微弱**香火之力**，乃**半只脚踏入第三步**的「半能之辈」；因碍于外因、缺乏大量香火而无法迈出完整一步。此人身份在太古星辰内极为尊高，轻易不现身于世

## 二、二阶墓台

真正令众人瞳孔收缩的是平台本身：古之墓地的所有碎石平台几乎都是**千丈**大小，而这九人身下有一个平台竟足有**两千丈**，生生扩大一倍——即**二阶墓台**，归那半步第三步的红发老者所有。

他开口便是威压：「连二阶墓台都没有达到，就想贪图这葬地之宝。」

王林凝重盯着那平台没有说话；四周修士沉默中缓缓凝聚，隐隐以王林为首。此举立刻引来红发老者与其余八处平台修士的杀机，血战一触即发。

## 三、灵动上人驱使他人试禁

羽扇文士上前在红发老者耳边低语几句；老者看了一眼大地、又看了一眼古神背上托着的碎石平台，随即点名王林身旁一名修士（此前抢夺平台成功的「凶年」之一）。

该修士不敢不从，出列抱拳：「晚辈见过**灵动上人**」——由此点明红发老者名号，并称「灵动上人之名，在我太古赫赫」。

灵动上人下令：「你去破开这古神背上的封印，若能破开一成，我留你一命。」

结果：该修士以掐诀化虚幻之影按向红雾，触雾瞬间雾内传出咆哮，红雾延伸如大口，将其一口吞入，惨叫不绝。

## 四、道灵与古魂禁

灵动上人由此喜色一闪，判定雾中是**道灵**，亲自上前一掌拍去。红雾化作巨大魔影，向他吹出一口红雾，轰鸣之下逼得他连退数十丈才停。

- 灵动上人：「最少是**六品**，可惜其上有禁制。」
- 羽扇文士：「是**古魂禁**」，并自承只有**两成把握**破开。

王林视角的关键信息：他早在进入此地时便已隐隐看出红雾内确为古魂禁，**但其内还蕴含其余禁制之术**，外人要破绝非简单。他不动声色，冷眼旁观九人如何破解。

## 五、青袍老者殒命

九人中一名青袍老者主动请缨，条件谈成：

- **灵动上人许诺**：若能破开，除道灵外雾中法宝全归青袍老者，且此地那些小修所得的墓地之宝，他可拿走大半。
- **青袍老者自陈**：自幼学习禁制之术，钻研近万年，自认已看出大道端倪，自创**万禁破诀**；并断言禁制之术为阵法本源之道，「天下间没有老夫破除不了的」，公开压过萧靖一头。他更否认「古魂禁」之名，称从未听说。
- 萧靖脸上温和微笑，抱拳自谦「萧某在禁制上还是后学者」。

施法过程：青袍老者掐诀挥出禁制之芒，化作光芒万丈的巨大符文，一度与红雾隐隐对抗——雾内咆哮骤停、红雾如被狂风吹得后避。老者得意下令符文前冲，红雾却再次化作大口，一口吞噬符文，并连人一同吞入。话未说完便化为凄厉惨叫。

灵动上人脸上似起黑气，显然未料到这一结果。

## 六、许福自荐与告密未遂

王林身旁一名身子肥硕、身穿员外袍的修士发出轻笑，引来灵动上人阴森目光。此人当即出列自报名号：

- 自称「晚辈**许福**」
- 称对红雾禁制「有点把握可以破开」
- 撇清关系：与王林这些人「没有任何关联，只不过是凑巧被传送到了一起」
- 欲告密：「这群修士中有一人，他是虚——」**话未说完即被灵动上人打断**（灵动上人对秘闻毫无兴趣，只想要雾中道灵）

灵动上人给出条件：破开红雾便留其性命、赐予法宝、让他跟在身边。许福随即改口称「虽没有十足把握，但若前辈配合之下，还是有**七成信心**可以破开」。

许福回头冷冷扫了王林一眼、嘴角冷笑，转身直奔红雾，在十丈外停下，右手如打算盘般啪啪作响，最终算盘碎开、珠子飞舞化作一股**禁制漩涡**直扑雾气。

## 七、王林的判断与布局

- 对许福：神色平静，内心冷笑「找死」。
- 对萧靖：清晰看到其嘴角闪过嘲讽，判断「此人尽管只有天人三衰修为，但能与这些人在一起，定是心机深沉、谋多之辈，**或许此人也在打这雾气的主意**」。
- 行动：王林心智成妖，不动声色中已有**一道禁制在其脚下出现**。

## 八、待解悬念

1. 许福的禁制漩涡能否破雾，还是重蹈前两人覆辙。
2. 许福未说完的「他是虚——」指向王林一行中的谁、何种身份。
3. 萧靖的真实图谋与其对道灵的算计。
4. 王林脚下暗布禁制的用途。
