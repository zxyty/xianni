# 第1305章 天劫为劫，亦为造化（第二更）

## 一、背景：破阵的第二重依持
- 当年王林魂魄进入**天逆**的世界内，见到**封界之主**，并由其送入道境。
- 封界之主当时曾言：其**最后的归宿便是这封界大阵**。
- 正因如此，王林对破开封界大阵有一定把握——**除借天劫之力外的另一重依持**。

## 二、宗主玉佩现世
- 王林神念传递刹那，元神内**本已消散的天逆珠子突然重现**。
- 珠子出现瞬间，一枚**玉佩**自天逆内幻化而出，穿过王林身体飞出。
- 玉佩现世：天地轰鸣，整个虚无震颤，连**八卦天劫**都为之震动。

## 三、妖宗太上长老破阵而出
- 妖宗大阵内那位**修为莫测的中年太上长老**，神识本在同时观察天劫与应劫之人王林。
- 见玉佩瞬间身子骤颤、双眼睁大、面色红润，露出无法置信的震撼。
- 内心惊呼：「**宗主玉佩**……他竟然有宗主玉佩……莫非他是**宗主指定的传人**？」
- 修道无数万年罕有动容，此刻却不假思索，一步破开大阵现于星空，再一步冲至虚无封界大阵旁。

## 四、苍天巨树与妖尊人脸
- 玉佩光芒环绕、晶光弥漫，**一颗苍天巨树支撑天地幻化而出**，弥漫整个虚无。
- 巨树现世，虚无剧颤，**八卦被一股奇异之力笼罩，静止一切行动**（天劫暂停）。
- 巨树上渐渐浮现一张**苍老人脸**，气息沧桑，目光留念，最后望向封界大阵。

### 各方反应（云海星域九阶内轩然大浪）
| 对象 | 所在 | 反应 |
|---|---|---|
| 水道子 | 神宗闭关之地 | 原本神色狰狞咆哮，骤然一颤、面露恐惧，唤「**主人**」，随后跪地连连磕头 |
| 九星古妖 | 鬼宗阵法外（正暗中吞噬天劫之力） | 神色一变，阴晴不定，低呼「**封界之主**」 |
| 破天宗宗主 | 星空中正迈步而来 | 身形一顿，神色凝重，遥望远方沉思 |
| 妖宗太上长老 | 封界大阵旁 | 极端恭敬，唤「**宗主**」 |

## 五、妖尊的三道命令

### 1. 对玄炳（妖宗太上长老）
- 妖尊唤其名「**玄炳**」，玄炳恍若回到当年，恭声「属下在」。
- 命令一：**以妖尊当年道器整理云海星域**，凝聚全部力量迎接**数年后的界外大战**，「一切反抗者，杀」。
- 命令二：**以妖尊封命、借其道器**，整合云海后前往其余三大星域，寻**南云子、红杉子、战仙子**三人，转告「**当年的约定，可以履行了**」；以最快速度整合其余三大星域，使**风雨雷电四大仙界合一**，迎接数年后的大战。

### 2. 对水道子（道奴）
- 妖尊称其为「**道奴**」：「你若能全力助妖宗推行此事，老夫便不杀你。」
- 水道子于神宗密室颤抖冒汗，跪地磕头。

### 3. 对九星古妖
- 妖尊自述往事：**当年从界外逃来**，将**整个鬼宗送给对方为门徒**，并助其疗伤。
- 如今其伤势恢复、成为**九星古妖**，「你我约定之事，也该履行」。
- 古妖沉默片刻后点头，望向封界大阵外**太古星辰**的目光透出寒光与恨意。

## 六、妖尊对王林的临别点拨（关键设定）
- 「**天劫为劫，亦为造化**」——有些事碍于**远古仙规**无法直说，让王林好自为之。
- **天劫不是远古仙域之物**，即便是**仙皇，也有天劫**。
- 天劫**来自太古，来自天地初开，来自那死亡的天道**。
- 王林眼下所面对的天劫**只是小劫**，并非**大劫**，更不是那**可灭一切生灵的天之极劫**。

## 七、结局：玉佩入阵，器灵抵抗
- 言毕妖尊闭目，巨树轰然崩溃、消散于虚无。
- 唯有玉佩化作晶光**落入封界大阵之上**。
- 玉佩落下刹那，封界大阵轰然震动，其上光芒疯狂闪烁，**一个个器灵迅速幻化，似在不断抵抗**。

## 八、伏笔与看点
- 妖尊 = 封界之主 = 妖宗宗主，三重身份于此章合流；其「最后归宿是封界大阵」的旧言此刻应验为破阵之钥。
- 「数年后的界外大战」成为云海星域全局主线；四大星域整合、风雨雷电四大仙界合一为其前置。
- 天劫本源被上推至「太古／天地初开／死亡的天道」，并划出小劫—大劫—天之极劫三级阶梯。
- 王林被妖尊「大有深意」地看了一眼，且被误认为宗主指定传人，身份悬念留待后续。

# 第1218章 天劫连袭：九宫八卦、七星北斗、八荒无量、五行手印

> 承接前文：王林（此期以化名「吕子浩」立足云海星域，自第1063章起）正于封界大阵所在之处渡天劫，前一阶段为九宫之劫，八卦法轮曾被外力停顿于半空。

## 一、玉佩之力消散，八卦法轮重启

- 玉佩内蕴含的力量极为诡异，慢慢化作**无数青色丝线**，顺着磅礴的**封界大阵**不断蔓延，渐渐消失无影。
- 青色丝线消散的瞬间，虚无内那被停顿在半空的**八卦法轮**轰然一动，从静止状态中脱出，带着惊天呼啸再次临近王林，速度越来越快。

## 二、王林的顿悟与清水之言

- 王林目光闪烁，双眼越来越亮，隐隐把握到什么却不确定，心中念道：**「天劫为劫，亦为造化，天之极劫，极境」**。
- 耳边回荡起**清水仙君**当年的话语：「以你目前修为，莫要去摸索极境之力，等你修为到了**碎涅**，或许可以从天劫中有所感悟。」
- 这是本章最重要的设定线索：**天劫 ↔ 极境之力**存在感悟通道，门槛在碎涅。

## 三、放弃抵抗——八卦入体，九宫八卦成封印

- 八卦法轮临身刹那，王林眼中露出疯狂，低吼**「拼了」**，主动放弃抵抗。
- 法轮直接印在王林全身后立刻崩溃，化作**八个符文**穿透皮肤，融入其血脉之内。
- 八卦蕴含天地、自成世界，入体后化作八股强大至极的力量，王林全身几乎崩溃、喷出大口鲜血；八卦符文与**九宫**相互辉映，形成无法想象的**封印**，在体内展开疯狂破坏。
- 关键抗性：王林**身为古神，恢复力惊人**，狰狞低吼、全身青筋鼓起，快速恢复。

### 卦象演变链

1. 八卦
2. 八八**六十四卦**
3. 天地水火雷山风泽急速变换 → **一百二十八卦**
4. 再变 → **最终无尽**

- 砰砰之声从体内不断传出，王林**千丈身躯**被一道道卦印弥漫，鲜血从全身各处喷洒。

## 四、主动挑衅天劫

- 王林神色狰狞，仰天冲着虚无外星空裂缝内的**天劫漩涡**低吼：**「区区九宫八卦之力，还无法让我死亡，有没有更厉害的天劫」**。
- 此吼直接引来后续三重更强劫难，是本章转折点。

## 五、第三劫：七星无量（北斗杀劫）

- 天劫漩涡传出惊天轰鸣，**七道刺目星光**冲出，骤然化作**七个修真星**——强调是真正的修真星，并非如九宫那般的陨石。
- 七星组成**北斗之阵**：**天枢、天璇、天玑、天权、玉衡、开阳、摇光**。
- 天劫序列由此明确：**九宫 → 八卦 → 七星北斗**。
- 模糊的声音传出**「七星无量」**，七星之芒穿透虚无、穿透星空，**弥漫整个云海**，取代一切星光；天地星空所有光芒似被七星吸收，化作惊天动地的**煞气**。
- 性质定义：**七星为杀，北斗为煞**——此劫**不是封印，而是杀劫**。七星化作**七道星痕**，如七把杀剑向王林穿透而来。

## 六、第四劫：八荒无量（封天之阵）

- 模糊之声再起：**「（八荒）无量」**。
- **八荒 = 上下东西南北**，与「天下」并列，代表宇宙洪荒的一切方位。
- 其笼罩之下**天地之中没有任何退路，即便肉身崩溃、元神也无法逃遁**——这是**封天之阵**，唯有一战。
- 东西南北上下六个方位，各幻化出一面巨大**龟甲**，共**六面龟甲**向王林疯狂撞击。

## 七、第五劫：五行无量（五行手印）

- 模糊之声再传**「五行无量」**，虚无内凭空出现五道光芒，化作五个巨大手印，分别代表**金木水火土**。
- 设定说明：五行虽与八卦有所重叠但明显不同，五行是组成天地的一部分，**天地无五行则天崩地裂**。
- 五印各自特性：
  - **金掌印**：拥有开天之力，出现刹那即蕴含无坚不摧之力。
  - **木手印**：弥漫生命气息，在生与死中不断转化，形成无法形容的**生死之力**。
  - **水手印 / 火手印**：分属两个极端，蕴含水火两种五行之力的巅峰，化作滔天水浪与无尽火焰两个巨大掌印冲向王林。
  - **土手印**：好似大地，传出厚重之感，似把星空一切大地之力全部凝聚，给人不可摧毁的强大气息。

## 八、要点小结

- 天劫的完整递进（本章已知）：**九宫（陨石）→ 八卦（法轮/卦印封印）→ 七星北斗（杀劫）→ 八荒（封天之阵·六龟甲）→ 五行（金木水火土手印）**，且每重皆冠以「无量」之名，由天地间模糊之声喝出。
- 王林的应对策略从「抵抗」转为「以身承劫、以劫悟道」，赌的是**古神肉身恢复力**与**从天劫中触摸极境**。
- 清水仙君的旧言构成本卷伏笔：碎涅之境是感悟极境的门槛。
