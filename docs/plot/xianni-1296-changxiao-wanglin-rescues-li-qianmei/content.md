# 仙逆 第1296章 长啸！（第九卷 云海之巅）

> 归属提示：据《世界状态须知》，王林自第1063章起以归元宗故人「吕子浩」之名行事（身份由吕烟菲奉上）。本章直呼「王林」，为其本名叙述。李倩梅在第1202章被记为死亡，但本章其命魂寄于玉佩、本人在裂缝世界中挣扎求生——应视为「命魂尚存/未彻底身死」的延续状态，本章新行动仍归李倩梅本人。

## 一、确认：白衣女子即李倩梅

- 紫色裂缝深处，一名白衣女子面无血色、瘦弱如皮包骨、双目无神地疾驰逃命。
- 一道巨大如鞭的虚影轰然袭来，女子挥剑硬撼，轰鸣中喷血遁向虚无深处，鞭影紧追不舍。
- 扭曲虚无崩溃，残余神通波动一同瓦解。王林眼中爆出激动与疯狂之色——**尽管容颜变化、尽管瘦弱不堪，他一眼认出：她就是李倩梅**。
- 那瘦弱苍白如针刺心，王林剧痛中神念疯狂爆发。

## 二、九幽龙止步：裂缝深处的寒气禁地

- 王林神念化作巨浪穿透九幽龙体内，龙低吼咆哮、鼻喷气浪，颤抖中再度加速前行，快得仿若破开苍穹。
- 越深入，九幽龙颤抖越剧烈，**魂魄几乎崩溃**——此处仿若它的禁地、不敢踏入之地。
- 一股冰冷气息如气流般弥漫紫色世界；九幽龙察觉后咆哮凄厉，不顾神念刺激骤然停顿，连连发出恐惧叫声，反欲后退。

## 三、催命的玉佩：命魂再裂

- 王林正欲起身迈步，面色骤变，右手一翻现出玉佩——**那玉佩正是李倩梅命魂所在**。
- 咔咔刺耳声中，玉佩裂缝再次撕开，其内李倩梅命魂更为虚弱，几乎命悬一线。
- 王林心如被一拳打在胸口，全身弥漫可怕气息，弃九幽龙不顾，一跃直冲裂缝深处。

## 四、独闯：血战凶兽的手段清单

失去九幽龙的**王兽威压**庇护后，紫色世界本土凶兽自四面八方涌来。王林一路未停半步，手段依次为：

| 手段 | 战果 |
| --- | --- |
| 右手握拳一挥 | 数百丈龟形凶兽瞬息崩溃成血雾 |
| 双手挥舞 | 狮形凶兽崩溃成血肉 |
| 右脚一踏 | 千丈蟒蛇惨叫而亡 |
| 右手虚空一按 | 千丈人面蜘蛛崩溃死亡 |
| 右手掐诀，千万剑气横扫 | 扑来凶兽退中崩溃、四分五裂 |
| 体内爆发**蓝色火焰** | 以身为中心扩散数千丈，凶兽尽化飞灰，火海内再无凶兽 |
| 右手一挥引**雷** | 无数银蛇凭空化作雷球轰击凶兽 |
| **役灵印** | 巨大手印凝聚天地元力，撞之即亡，势如破竹 |

- 血腥引来更多凶兽，数百上千、似无穷尽；王林双眼红芒、全身煞气，低吼「滚滚滚滚」，速度越来越快，如一道掀起血雨的旋风。
- 凭役灵印开路，王林渐渐抵达**玉简通道所标示的尽头之处**。

## 五、尽头：极寒与白气凶兽

- 尽头之后已无所指之路，冰寒气息刺骨环绕、穿透身体，**连元神运转都缓慢下来**。
- 役灵印被寒气一冲，咔咔作响、结满冰凌，瞬息化作**巨大掌印冰雕**停留虚空。
- 同一刹那，寒冷世界内一道道白色气息凭空幻化，化作散发阴寒威压的凶兽——样子各异，凶光远超此前所杀者，数量无边无迹。
- 王林杀机一闪，右手向前一撕，储物裂缝出现，喝道：**「蚊兽，现」**。
- 一震惊天嗡鸣挤入兽吼，蚊兽自储物裂缝涌出：一只、两只、十只、百只、千只、上万——上万蚊兽狰狞冲向白气凶兽。
- 王林一声**长啸**惊天，绝强气息爆发，向前迈出一步。

## 六、另一端：李倩梅的油尽灯枯

- 李倩梅咬唇、面无血色，衣襟鲜血触目；**所有法宝已全部用尽**，连长剑也以自身崩溃为代价，为她换取了一次逃命机会。
- 她被无数凶兽团团围住，元力耗尽、丹药用完，身子虚弱到油尽灯枯，唯有一股坚定支撑至今。
- 战法：以**金色的笔**画出符文弥漫四周抵抗；但越虚弱符文之力越难伤敌。
- 保命：全靠十丈外一道**蓝光**阻挡凶兽冲入；蓝光不断颤抖、随时可能崩溃。
- 那道鞭状虚影时而破开虚无抽击蓝光，每次都令蓝光剧震并瞬间消散，几只凶兽趁隙突入，李倩梅须付出极大代价才能杀之。

## 七、绝望与转机

- 李倩梅落泪喃喃：「就要死去了么……不知他是否已经苏醒……我没有机会，去看他一眼……只是，这一切，**我不悔**」，随后慢慢闭眼，等待蓝光崩溃与死亡。
- 就在闭眼刹那，一声惊天动地、带着「虽千万人吾往矣」之气息的**长啸**自远处传来，颤动其心神。
- 李倩梅猛地张开双眼，不敢置信地望向声源，泪水再次流下。

## 八、要点与伏笔

1. **命魂玉佩=倒计时**：玉佩裂缝二度撕开，直接把救援推入「争秒」节奏，也解释王林为何弃龙独行。
2. **九幽龙的禁地**：连王兽级的九幽龙都因寒气魂魄欲崩、拒不前行，预示尽头处存在远超凶兽层级的存在或封禁。
3. **役灵印被冻成冰雕**：王林的强力手段在此处首次被环境直接压制，白气凶兽随即出现，战场规格陡然升级。
4. **上万蚊兽出手**：王林的老底牌被大规模投入，为长啸后的正面突进护住侧翼。
5. **「不知他是否已经苏醒」**：李倩梅所念之「他」指向王林此前的沉睡/石像状态，两条线在本章末以一声长啸交汇。
