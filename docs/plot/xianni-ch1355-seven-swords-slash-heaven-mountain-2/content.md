# 第1355章 七剑斩天山（二）

> 归属提示：本章王林自第1242章起以一部分元神夺舍「于非」之身潜入闪雷族，本章正文直呼王林本名，相关言行统一归于【王林】。

## 一、开局压制：翻天印 + 役灵印

- 散灵上人踏步而来，双手一挥，九百七十一个印记尽数落在闪雷族大长老身外滚滚云层内，云层崩溃。
- 云层一破，**翻天印**逆转天地的挤压再无阻碍，狠狠轰下，大长老疯狂后退、面色苍白。
- 王林的**役灵印**随后浩荡而至，速度快到无法想象，刹那命中大长老。
- 散灵上人如同发狂，带近千印记再次追击，与役灵印齐发，毁天灭地。大长老被抛飞喷血、再度受伤，披头散发、神色狰狞。

## 二、闪雷族六道神雷（重要设定）

大长老一拍眉心**族印**，怒吼「雷分六道」，六道粗约百丈、似连接天地的雷霆自族印轰出：

| 雷名 | 来历 / 凝聚方式 |
|---|---|
| 天酝之雷 | 「天」即星空；由星空酝酿而成，一颗雷便是一颗修真星，需配合闪雷族秘术凝聚 |
| 地融之雷 | 星空内无数尘埃、无数崩溃星球碎片，以祭祀之法融合而出 |
| 元化之雷 | 修士凝聚天地元力后破开元神，元神死亡刹那如黑洞般无尽吸收天地元力，以此为代价凝成（最为简单） |
| 磁含之雷 | 星空中雷磁之力区域（法宝、神通在此均失效），闪雷族以特有方法每三千年诞生一道 |
| 道意之雷 | 太古星辰罕见；闪雷族先祖杀入界内，搜集界内之人所修意境炼化道念而成 |
| 灵念之雷 | 六道之一（本章仅点名，未述来历） |

- 这是闪雷族**历代搜集至今凝聚出的全部六道神雷**，合成巨大的雷之漩涡由大长老推动前行。
- 效果：役灵印一碰即裂缝密布、轰然崩溃；散灵上人九百七十一印记亦被推得齐齐后退。
- 大长老放狠话：杀此二人后，还要屠杀一千万七百万天地生灵泄愤、血洗此地绝大部分修士，「保我闪雷族万年无忧」。

## 三、散灵上人：分身崩灭术

- 王林后退中低喝质问：「这就是你说的七成把握？」散灵上人面色阴沉不答。
- 散灵上人止步掐诀，低吼「**分身崩灭术**，九百七十一分身，给我崩」——近千印记同时崩溃爆开，形成灭天之力，威力**丝毫不弱于散灵自爆**。
- 六道神雷漩涡骤然一顿，大长老再次喷血，眼中疯狂更浓。

## 四、王林的反击：鹿兽剑雨与生灵光影盾

- 王林决意「不是大长老死，就是他王林亡」，右手一指，幻化**两条鹿兽虚影**，爆发千万剑气化作剑雨。
- 左手掐诀展开**光影盾**：七百万天地内一切生灵——凡人、修士、花草树木、野兽飞禽——尽数散发光芒破空汇聚王林之身，使光影数倍暴增至前所未有的程度。
- 千万剑气尽碎于漩涡；漩涡撞上光影盾，王林喷血、光影剧颤隐隐欲崩，但反射大量六道神雷之力回击，大长老又一次喷血、面色极为苍白。

## 五、散灵上人燃元力，僵持

- 散灵上人燃烧体内一切元力，速如火焰流星，双手虚空拍出片片风暴直奔大长老。
- 大长老一手推漩涡攻王林，一手化作闪电雷霆手臂隔空对轰散灵上人；其身负伤，一时难分胜负。
- 散灵上人仰天大吼（已不在乎被大长老听见）：「他受伤程度不够，只要让其再伤一次，我就可杀他」。

## 六、香火之力登场（关键转折）

王林光影盾将碎，果断打开**呼风唤雨界**：

- 心中盘算：想伤大长老不易，对方以一敌二不落下风，且其「祭出寿元生机化作神通」的法术蕴含无限可能；**若在七百万天地之外、大长老甘心祭出千年寿元，王林自认定然无法匹敌**。
- 结论：「此刻要伤他，唯有用香火——这香火有毒，对我无用，但用来杀人却是可以。」
- 神念传遍界内：「尔等被我所杀，膜拜于我，为我门徒，不惜灭魂，奉献一切香火之力，给我聚！」
- 界内一切被王林所杀、不入轮回的魂魄天灵之上冲出磅礴香火之力，不少魂魄更以**灭魂**为代价献出香火。其中**远古仙妃分身白衣女子**一人之香火，就足有全部香火的一部分（远超其他修为高深者）。
- 香火凝成絮状小球，无尽威压隐现。大长老瞳孔骤缩、难以置信：「香火？你竟然有香火！」
- 王林掷出香火小球，撞上六道神雷漩涡即崩溃——**香火之力乃第三步大能操控之力**——天地震动、星空层层瓦解，六道神雷颤抖。
- 香火消散大半后，王林再度神念传令「灭魂，祭出香火」，界内大量魂魄崩溃死亡，再送浓浓香火轰向大长老。
- 六道神雷漩涡轰然崩溃，残存香火倒卷直奔大长老；散灵上人攻势同时更为疯狂。

## 七、章末：不灭圣雷 vs 亿万生灵大阵

- 大长老连喷数口鲜血，身外不知何时凝出**青色雷光铠甲**，不断后退，双眼略显涣散、血丝弥漫、疯狂毕露。
- 大长老大吼「**祭献寿元生机，吾族不灭圣雷，降临七百万天地，雷罚众生**」——七百万天地外闪雷族圣地庙宇上的**不灭雷霆**如苏醒复活，彻底离开圣地、破开虚无，直奔七百万天地而来。
- 散灵上人深吸一口气，盘膝坐下，神色**悲哀但坚定**：「接下来，就是我之前所说的七成把握」——「**七百万天地亿万生灵大阵，开启！**」

## 八、悬念与看点

- 散灵上人的「七成把握」真身是「七百万天地亿万生灵大阵」，其悲哀而坚定的神色暗示此阵代价极大。
- 王林两度以灭魂换香火，界内魂魄大量消亡；香火对王林有毒、只可用于杀人这一限制被明确点出。
- 闪雷族不灭圣雷离开圣地，圣地防护空虚，且大长老已祭献寿元生机，双方均已下注全部筹码。
