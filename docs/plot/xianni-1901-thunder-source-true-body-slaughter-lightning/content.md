# 第1901章 雷！

## 一、雷霆本源的来历（回溯）

雷被描述为「天地至极之威，没有之一，而是唯一」，为天威。王林的雷本源脉络：

1. **根本**：半条太古雷龙——为天地行使雷霆之权，是天地雷霆于世间的化身，使王林拥有本源萌芽。
2. **攀升**：吸收闪雷族的**不灭雷霆**，本源距巅峰大成仅一步之遥。
3. **另辟新径**：自身凝聚**伴随之雷**，并以**雷蛙之魂**、自身**极境之雷**全部凝聚合一，令雷霆本源无限接近大成。
4. **临门一脚**：一百多年前，仙罡大陆蝎庙内，拥有不同雷本源的**道魔宗宗主**不惜一切代价，全力散开雷霆之力融入王林体内，并留下**两颗雷帝珠**。

以上种种积累，使王林体内雷霆本源翻天覆地地改变，**凝聚出真身**，成为**雷霆本源之体**。此真身存在意志，且这意志大都属于王林。

## 二、杀戮本源融入：天怒杀戮雷诞生

- **杀戮本源**属特殊本源之一：本是无形，由无边无际的杀戮组成，且非胡乱去杀，须**带着某种信念**完成滔天杀戮方可形成。蕴含无法形容的煞气，足以改变天地运转，威力远超寻常本源。
- 参照：当年**清水（清水仙君）**一道杀戮本源，即可奋战修为比之高深者。
- 此前杀戮本源在王林身上多作气势辅助品，使用不多。融入雷霆本源真身的刹那却骤然改变——**雷与杀戮融合，形成杀戮之雷**，凌驾九天之上，如毁灭众生。
- 关键：杀戮之雷**拥有使命**，从出现到结束的一生，就是其使命完成的过程。古老传说中「天一怒，以雷灭世」，雷最早即为惩罚众生、毁灭一切生灵，唯灭世之时才会出现杀戮之雷。
- 结果：诞生了一道**本不该出现、修士根本不可能掌握的「天怒杀戮雷」**。

### 危险征兆
- 真身四周肉眼看不到一丝雷霆闪电，但王林神识中清晰感受到真身内外有一道极可怕的雷霆之力缓缓运转。
- 一旦脱离真身牵引扩散，威力**惊天灭世**，连王林自身也会被毁灭；王林心悸，觉得此雷不该出现在这天地间，或说「还远远没有到它出现的时候」，一度冲动想立刻停止融合。
- 融合中出现不稳迹象，发出轻微啪啪声，并散出**一丝气息**，刹那间自蝎庙扩散、笼罩整个**绿魔洲**，洲内所有生灵心神一颤，生出仿若要毁灭的错觉。该气息刚出绿魔洲即消失，快得无法想象，**未引起任何一个大天尊的注意**。
- 王林自语：「一旦此雷爆开，这绿魔洲……」，后又沉默补一句「**或者并非是毁灭一洲**」——暗示其毁灭范围远不止一洲。

## 三、禁制本源融入：以己之法则驯服此雷

- 杀戮雷不稳的刹那，**禁制本源**（法则、规则）开始与雷霆本源真身融合，化作一层大网笼罩真身。
- 雷本有天地赋予的规则法则；但因真身内有王林的意志，加上禁制本源，这具雷霆真身**再无任何天地的笼罩**，彻底改变——拥有了**属于王林的规则与法则**。
- 该法则与杀戮之雷似**中和**一般，将其完美限制在真身内，不稳迹象缓和。
- 融合后：真身外表与之前毫无变化，平静站立，丝毫看不出雷霆痕迹；体内外禁制本源层层弥漫，包裹着最深处那一道**灭世杀戮雷霆**。
- 王林额头泌汗，看着本源真身如同做梦。

## 四、修为突破：空玄中期 → 空玄后期

- 随真身融合，王林体内已达**空玄中期**的修为自行运转、轰然爆发，形成风暴化作漩涡急速转动。
- 养分来源：吸摄四周天地之力 + 吸收其体内积累的**本属于绿魔蝎的力量**。
- 白发狂舞、体内轰轰巨响、双目光芒万丈，修为不断攀升至巅峰后心神轰鸣——**由空玄中期直入空玄后期**。
- 王林眼中的沉思消散，取而代之的是**果断的坚定**。

## 五、后续路线图（王林的盘算）

- 剩余三道**虚之本源**：**生死、因果、真假**。
- 三者融合为一 → **九道本源三三归一**（此前已完成两组），修为再次暴增，由空玄后期直冲**空玄圆满**，去经历**九次玄劫**。
- 突破九次玄劫 → 踏入**大尊之列**，成为**空劫**修士。
- 以其战力：修为若至**空劫初期**，足战空劫大圆满，甚至可成为天地间**大天尊之下第一人**，亦即「**半个大天尊**」，届时在仙罡大陆**再无任何地方不可去、再无任何人可随意算计揉捏**，将是**仙罡大陆第十强**。

## 六、无人可察的隐忧

王林隐隐感觉，此雷出现一刹那的心惊，小部分来自雷本身，**绝大部分来自此雷出现所繁衍出的一些变化**。这种变化**没有任何人可以感应到，即便大天尊也不行**，唯有王林能察觉——因此雷由他创造，雷霆本源中拥有他的意志与法则。他不再深思此事。

## 七、天外苏醒者（关键伏笔）

视角切至绿魔洲外→东州外→仙族外→仙罡大陆外：

- 若把仙罡大陆比作天，则**天外还有一片如星空般的虚无**。
- 虚无中距仙罡大陆极为遥远处，有一片**虚无的大陆**：不到仙罡十分之一大小，其上没有任何生命痕迹，一片死寂；遍布死亡废墟，仿佛很多年前曾有大量生灵，却在**一劫之中全部死亡**。
- 大陆正中央有一座**极为磅礴的废墟城**，其内竖立一尊**女子雕像**，此刻已坍塌大半、只剩半截身子。
- 雕像上盘膝坐着一名**中年男子**：相貌寻常，却有一头触目惊心的长发，垂下近百丈，顺着坍塌的雕像一直垂着。
- **就在杀戮灭世之雷诞生的一瞬间**，此人似从**无数万年的沉睡**中慢慢睁开双眼——双目**没有瞳孔，只有一片死寂的虚无**；他抬头望向远处，双目内渐渐有精光一闪而过。

## 八、要点速记

- 新神通/新造物：**天怒杀戮雷**（灭世杀戮雷），由「雷霆本源真身 + 杀戮本源」意外融合而生，再由「禁制本源」封束限制。
- 修为线：空玄中期 → **空玄后期**（本章）；下一步目标为三虚本源合一 → 空玄圆满 → 九次玄劫 → 空劫（大尊）。
- 新伏笔：天外死寂大陆、半截女子雕像、百丈长发无瞳中年男子于此刻苏醒。
