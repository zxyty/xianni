# 第1109章 圣皇归墟（第八卷 联盟隐秘）

## 一、王林赶至燃烧星域
- 老圣皇神念传出的刹那，正要踏入燃烧星域的王林身子一颤、面色骤变。
- 二人同为朱雀圣皇、同修**九玄变**神通，彼此之间有独特的神念传递方式。
- 王林借身上尚存的**速符**，如星空奔雷冲入燃烧星域，再以**缩地成寸**瞬息抵达老圣皇所在白色石块外十丈，踏出空间波纹。
- 老圣皇双目鲜血淋淋，死气自体内散开，不需神识便可感知其将死。

## 二、老圣皇临终遗言（本章核心情报）
1. **关于清水师兄**：清水确在修真联盟总部；数年前修真联盟大阵开启与他有直接关联；他没有死，但**疯了**。
2. **关于修真联盟总部之秘**：总部无数年来隐藏惊天之秘——当年**玄重子**等人第一次去**雨之仙界**，不但获得绝大部分传承，更发现了一些**神秘之物**，此后无数年始终在研究此事；恐怕连**昆虚之境**都不知晓；此物太过重大，甚至可以**波及四大仙界**。
3. **遗命**：王林速去**救青龙圣皇**，然后把**红色玉简**立刻送到**昆虚之境**；并告诫王林修为不够，万万不要牵扯进此事。

## 三、归墟
- 老圣皇右手点自身眉心，元神幻化飘离肉身，深深看王林一眼，露出慈祥之色，留下“好自为之，老夫不能再帮你了”。
- 元神散发柔和之芒转为刺目之光，穿透四周万丈，最终化作晶光消散；消散一刻，元神露出**解脱的惆怅**。
- 消散处遗下两样物品：
  - 一枚**红色玉简**（须送昆虚之境）；
  - 一颗**婴儿拳头大小的晶体**，内有**至纯仙气**缭绕散开。
- 失去元神的肉身燃起火焰，化作**燃烧的石像**，保留生前容颜与动作，右手始终点在眉心。
- 王林一生不拜天、不跪地，此刻双膝跪于石块，向石像重重磕**三个头**以谢。

## 四、四圣宗举哀
- 老圣皇死亡瞬间，朱雀圣宗长老几乎尽数感应到心神悲哀，飞出星球跪于其肉身所在处流泪，“恭送圣皇”。
- 全族随之跪拜，声浪自一颗颗修真星传出；几大主星的朱雀雕像发出凄悲嘶鸣；一只苍老疲惫的**虚幻朱雀**自石像飞出，远去消失于星空、化作虚无。
- 生平：在**白虎圣皇战死、玄武圣皇背叛、青龙圣皇失踪**之后，老圣皇带四圣宗度过危机、挺过无数万年，今归墟而去。
- 青龙、白虎、玄武三宗长老与族人心有所感，同向朱雀圣宗方向跪拜；悲哀笼罩**联盟东部**。

## 五、联盟星域风起云涌
- **罗天**召回联盟星域内所有修士，由**炎雷子**等人带领，另有自罗天赶来的**唯一传承至远古的修真家族**之人，向**朱雀星**而动；临近的一座座**雷仙殿大殿**随之而动，环绕众修散发威压。
- **尸阴宗**几乎倾巢而出直奔朱雀星，队伍中一具具棺木随弟子而行，远看如赶尸棺而行。
- 两方举动引起联盟各势力关注；各势力结合此前获得的玉简密谈后纷纷派出人马。整个联盟星域如**暴雨黎明前的黑暗**。
- 联盟星域东部**四圣宗**亦派部分长老带族人飞向朱雀星，**用以掩盖四圣宗内真正的举动**。

## 六、四圣宗大阵（暗线）
- 朱雀圣宗内集合四宗共**三十五名碎涅长老**，盘膝成阵、环绕成圈，各自身下有阵法图案，神色凝重等待。
- 正中为一**一丈大小的圆形阵法**，此刻空空，但有**三十五条分支**分别连接三十五名长老身下之阵。
- 外围为四圣宗族人，密密麻麻**不下数万**，皆盘膝而坐、身下阵法与长老之阵相连。
- 只待号令，族人将不顾一切释放体内元力顺阵涌入，**开启大阵**。

## 七、王林寻回许立国
- 燃烧星域内有一片**环形火海风暴**旋转，内传许立国怒吼。王林在风暴外低喝其名，火焰风暴分开露出贯穿内外的巨大缝隙。
- **许立国境况**：数年间在无数次生死危机下不得不感悟**远古剑意**，修为突飞猛进，寻常**窥涅**修士都敢与之一斗。
- 交手三合：
  1. 许立国化作数丈长短、形如**仙剑**的滔天大剑冲出 → 王林右手一挥凝聚无尽天地元力，一击崩溃之。
  2. 许立国化**九把大剑**结剑阵、剑意滔天 → 王林走入阵中，一抓一捏剑刃，其余八剑尽数崩溃。
  3. 八剑残余剑意化作**八个巨大骷髅头**吞噬而来 → 王林右目**雷光**一闪，无尽雷霆如万道银蛇横扫，骷髅头惨叫爆开。
- 王林捏住手中大剑用力，剑内传出许立国惊慌之声；其藏身剑中之魂濒临被捏碎。
- 许立国慌不择言，一口气堆砌溢美之词讨饶，自称“**小许子**”、唤王林“**主子**”。王林为之一怔。
- 王林态度：见其化九剑成阵时“略一点头”，认为**这样才符合他的要求**——暗示王林此番寻来是要用许立国办事。

## 八、待续与看点
- 红色玉简与仙气晶体的用途；送往昆虚之境一事。
- 救青龙圣皇。
- 修真联盟总部所藏、可波及四大仙界的神秘之物；清水疯癫与数年前联盟大阵开启的关联。
- 四圣宗数万族人合力大阵的真正目标（与各方汇聚朱雀星形成表里）。
