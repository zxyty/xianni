# 第1935章 谁的断掌！

## 一、光幕内的对谈

- **王林自述出身**：出定后被海子天尊问及宗门，答「我来自七道宗」「东州七道宗，一个很小的宗门」。海子天尊记忆中并无此宗。王林内心涌起思乡之绪。
- **海子天尊自述**：无宗门，自小跟随师尊在**帝山**长大；「帝山很美，每当这个季节，都会满山红叶，好像燃起了火焰一样」，邀王林有机会去看看。
- **招揽话题**：海子天尊问南州的**道一大天尊**是否招揽过王林（凭其天尊战力），王林答「没有」；海子天尊提议王林跟随自己师尊，王林委婉答「暂时还没有考虑」。
- **道侣话题**：海子天尊问王林修道多少年，王林答「应该没有你长」，引得她掩口娇笑——这是她这一年中第一次如此。她据王林被困而不急推断其无双修道侣，主动提出脱困后为其介绍，并点评：「相貌寻常，不过却有独特的气质，还不错。修为一般，但拥有天尊战力，非常好。」

## 二、王林的应对与疑心

- 王林冷声喝道「**收起你的魅惑神通**」，双目爆出金光，神色威严且带镇压之力，使海子天尊话语无法出口。
- 王林随即幻化出**杀戮雷霆真身**（分身），令其盘膝坐在自己与海子天尊之间：「与王某这分身交谈就可，莫要打扰我的修行」，本体退至最远角落闭目打坐，炼化第三颗山海树灵。海子天尊一愣，轻哼一声亦入定。
- **王林的推断**：「这海子天尊，有古怪。」其举止与此前印象迥然不同，仿若**一体两魂**之类的隐秘，但以**仙极剑**目光扫过仍无端倪。又联系到断掌出现后并未直奔自己，而是**第一个攻击海子天尊**，认为其中另有隐秘。

## 三、三年修行与光幕告急

- 三年间王林不理会海子天尊，专注吸收山海树灵，共吸收**四颗**，**木本源之力小成**；皮肤浮现若隐若现的**绿色植物脉络状花纹**，样貌略显诡异。
- 海子天尊三年一言不发，同样打坐，神色时有变化，不知修行何种功法神通。
- 光幕外闷闷轰鸣不断且日益频繁，百丈光幕隐有缩减之兆。
- **三年后第四个月**：轰鸣剧烈远超以往，光幕自百丈**骤缩一半至五十丈**，轰鸣持续约半个时辰方散。五十丈对二人已是极近距离。
- 海子天尊评估：光幕是她**凝聚收缩**（原近万丈）以抗断掌，若仍分散或已被打破；即便如此「怕是连一百年都无法坚持」，范围还会继续缩减直至崩溃。

## 四、直面断掌

- 王林望向光幕上方，再度看见黑暗中模糊身影与自己对望，那目光蕴含吸摄心神之力并化作躁动之意弥漫全身，王林**双目金光一闪**方才清醒。
- 海子天尊恐惧道：「它始终在盯着我们观察我们的一举一动，这数年来，一直如此。」
- 王林道「它是一个断掌」，随即抛出核心之问：「**那么它，到底是谁的断掌**」，遂飞身直奔上方。临行传音：「你不要上来，若发现我有什么不对劲，立刻将我震醒。」海子天尊由此背影忆起数年前王林挡在自己身前的一幕。
- **面对面**：王林面孔距光幕不足三寸，光幕外身影亦骤然临近，隔光幕与王林**不到六寸**。所见为——**一张没有皮的脸，血肉模糊，极为恐怖，却充满说不出的威严**，整体虚幻模糊，**唯独左手极为凝实，好似真实存在、拥有皮肤**。
- **摄魂**：王林双眼收缩、露出无法置信之色，心神如万万雷霆轰鸣；那双目射出奇异之芒欲穿透光幕冲入其眼，化作回荡心神之声「**来来来**」。王林体内骤然传出**怦怦如雷霆般的心跳之声**与之对抗，使其猛然惊醒；此时他距光幕仅剩**一寸**，再往前似就要穿透而出。海子天尊已焦急惊呼并迈步临近，王林道「我没事」。
- **收尾**：王林苏醒刹那，光幕外身影发出咆哮嘶吼，猛撞光幕，光幕剧烈闪烁而未破碎。王林目光落在那疯狂撞击的身影上，吐出二字——「**仙祖**」。

## 五、待解伏笔

1. 断掌究竟是谁的断掌？王林脱口而出的「仙祖」指向何人。
2. 海子天尊反常之因：是否「一体两魂」、断掌为何先攻击她。
3. 光幕百年内必崩，二人如何脱困。
