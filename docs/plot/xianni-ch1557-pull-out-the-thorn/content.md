# 仙逆 第1557章 拔刺！

## 一、场景与目标
- 地点：七彩界，十万大山（实为石化玄武背上十万利刺所化）。
- 王林唯一念头：打碎石化玄武，使其不能再镇压清水之魂，救出清水。

## 二、灰气突袭与玄武圣皇之危
1. 王林双拳落处，石化玄武背部出现五道细微裂缝，并向四周蔓延分叉。
2. 裂缝内喷出充满死亡气息的灰气，风暴般直卷王林；王林早有堤防，当即后退。
3. 一缕灰气顺玄武身躯直奔头部盘膝的玄武圣皇，涌入其体内，其气息绝强爆发、隐有咆哮，仿若复活。
4. 王林一生杀戮、心智极坚，早在见到玄武圣皇时便已有准备。他后退中右手一挥，血剑血光滔天而出，以破开虚无之势自玄武圣皇颈部掠过。
5. 头颅与肉身分离（无血），同时斩断了穿透其身、自天灵冒出三寸的利刺。灰气自颈部伤口大量宣泄，咆哮转为凄厉嘶吼继而虚弱；玄武圣皇肉身颤抖枯萎、最终崩溃。

## 三、轰碎血肉之刀
- 身后血肉之刀再度呼啸落下，其内哀嚎欲吞噬王林。
- 王林转身，眼中疯狂与睿智并存，右拳硬轰：一击退后数丈，刀内数千之魂崩溃，刀身略小。
- 随后连续对轰，刀被震得越来越高、体积急剧缩减；最终一拳将其崩碎，四分五裂，其内血肉尽化为灰。
- 代价：每一拳皆是全力，体内排斥之力滔天，剧痛下全身汗毛孔泌血。

## 四、数百拳 + 役灵印，玄武崩溃
- 王林升空至极限后如流星俯冲，双拳砸在有裂缝的玄武背部，裂缝被撕开为大范围断裂。
- 一拳接一拳、不下数百拳，拳中金光弥漫、火焰与雷霆交错，破坏力更烈；其身体喷出血雾，排斥之力全面爆发，剧痛被他化作疯癫与救清水的决心。
- 背部崩溃大半仍未全碎，王林卷身升空数千丈，右手指天，施展「役灵印」：天空一暗，巨大金色掌印显现、波纹笼罩天空，穿透其身向下降落。
- 掌印轰在玄武背部，留下掌印形凹陷、边缘尽裂；王林右掌紧随按下，玄武之背爆发至极之力，甲片全碎向四周倒卷——玄武崩溃。

## 五、十万利刺反噬，王林成「刺球」
- 玄武崩溃刹那，一缕带悲哀的魂自其体内飘出，直奔清水。
- 背部十万利刺齐齐断开：包裹清水的那根升空飞起；其余近十万根化作针刺，从四面八方瞬息穿击王林，无从闪躲。
- 一根自胸口穿透，数息间王林身影被十万利刺完全包裹，外界只见一个巨大的刺球。
- 战后景象：七彩界寂静，十万大山消失；清水所在处漂浮半空、被七彩云雾笼罩；山外天空漂浮长满利刺的巨大石球；地面上背部崩溃、头颅仍抬起的玄武遥望远方，破开甲壳内石化碎末隐有灰气飘散；其背部深处一枚**碎开的灰色晶石**散发幽光，一闪一闪。

## 六、撕球而出，走向清水
- 半柱香后刺球骤震，内传砰砰之声，如有人挥拳欲开。
- 一个金光淋血、被无数断刺穿透的拳头自缺口伸出，继而第二只；双手抓住缺口边缘猛地一撕，刺球被生生撕开裂缝，露出满身满发浸血的身影。
- 无数利刺穿透其全身，连双眼中都有数刺贯过。他喘息休整十息，抬手缓缓抓住刺入眼中的利刺猛地一拽，双目流血泪而闭；许久后猛睁双眼，一吼再撕，彻底掰开刺球。
- 撕开时部分利刺被生生抽出、鲜血喷洒，更多利刺折断后留在体内，如长在肉中无法取出。
- 「清水师兄，我来救你」——王林迈步走出刺球，身上有数万利刺穿透，每一步鲜血顺刺流下；身形自千丈渐缩恢复正常，途中体外部分利刺崩碎，刺身仍留体内。
- 「师兄，我来了」——王林走入七彩云雾，视线模糊，隐见前方低头、乱发遮面、身子颤抖的清水。

## 七、章末动作（拔刺）
- 王林行至清水七尺之外，抬起右手抓住清水胸前**第一根利刺**，深吸口气，向外猛地一拔。

## 八、人物注脚
- 「这世间，也唯有那么少数的几个人，可以让王林做到如此程度，清水，是其中一个」——确认清水在王林心中的地位等级。
