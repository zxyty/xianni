# 第1907章 天逆大门！

## 一、破劫入空劫

- 蝎庙崩溃所化的风暴中心，空劫气息浓郁、卷动天地，十多个绿魔洲修士误以为是「绿魔大人」复活而俯身参拜。
- 风暴中走出的是**王林**。他在毁灭第九次玄劫后，如同轰开了压制修为增长的隔膜，修为骤然攀升至**空劫初期**。
- 体内有巨大漩涡急速转动，散发惊天气息，王林生出「掌开即可握住天地」的奇妙感觉。
- 虽只是空劫初期威压，四周修士却感到面对的像是空劫最巅峰的无上大尊。右手一握即凝出超越空劫初期的恐怖之力，大地裂缝横扫蔓延。
- 众修士在王林身上感受不到任何绿魔蝎气息，心生疑惑。

## 二、天逆珠的躁动

- 成为空劫修士后，融合于灵魂中的**天逆珠子**赫然幻化运转，传出阵阵吸撤之力，似要向下方大地蔓延。
- 王林**第一次清晰感受到天逆珠子散出的意识波动**，其中透着强烈的**渴望**。此前未至空劫时无法如此清晰察觉——修为增长使「天逆」本身也大为不同。

## 三、轰开仙祖封印，放出绿魔蝎魂

- 王林右手一拳落下、化拳为掌拍向大地，毁灭之力造出约**数千丈范围**的凹形深坑，直贯大地最底部。
- 蝎庙底部正是**镇压绿魔蝎魂**之处；地面坍塌后深坑与封印之地直接连通，封印被强行轰开。
- 凄厉嘶吼与滔天怨气爆发，绿色雾气如气柱冲天，化作约**数万丈**的绿魔蝎，遮天蔽日。
- 蝎魂身上有**四道红色符文印记**，分封头部、尾部与前后身躯，是**当年仙祖**施展、用以镇压此魂并化作绿魔洲的力量。

## 四、身份败露

- 十多个修士惊呼「绿魔大人」，继而生疑：绿魔之魂既已现身，那么此人是谁？
- 其中一人来自**道魔宗**，正是**一百多年前**在**绿魔洲与孟土洲边缘**参与追杀王林者之一，当场认出：「王林——他是天牛洲的王林！」

## 五、白珠吞魂

- 王林白发披肩，一拳蕴含**道古之力**并爆发全部空劫修为轰向蝎魂；蝎魂身上四道符文封印骤闪，**生生抵消此拳**，蝎魂仅倒退数千丈，其身依旧。
- 王林由此判断：「仙祖的封印，这么多年来还是如此强大，可见当年仙祖的修为。」
- 蝎魂再度冲来，并散出神念「凡吾绿魔修士，斩杀此人」，十多个绿魔修士化虹齐攻。
- 王林祭出**天逆珠子**——这是他到仙罡大陆后此珠**第一次现世**。蝎魂一见白光即骇然惊呼「白珠」，疯狂倒退。
- 珠子瞬至，**穿透四道符文印记的防护**没入蝎魂深处，爆发恐怖吸撤之力；**三次呼吸**间数万丈蝎魂尽数被吸收。
- 失去镇压对象的四道仙祖印记一闪，化作飞灰消散。
- 十多个修士视王林如噩梦，四散奔逃；王林未追。

## 六、天逆大门现世

- 王林虚空一抓收回珠子，握住的一瞬身子震动：天逆珠子**似有了又一次的圆满**，其内正进行翻天覆地的变化。
- 王林左手一挥，布下笼罩**四周千里**的风暴防护，阻止一切生灵踏入。
- 神识轰入天逆珠内，眼前一花后置身**无边无际的浩荡虚无**；虚无天空中有一扇**似连接天地的巨大之门**。
- 门上有**一只青色的手臂**，散发毁灭气息。
- 章末点题：**天逆大门**。

## 七、待解伏笔

- 天逆珠「再次圆满」后的完整变化尚未揭示。
- 天逆大门上的青色手臂来历不明，毁灭气息指向何方未知。
- 逃走的十多个绿魔洲修士（含道魔宗一人）已确认王林身份，后续或引来追索。
