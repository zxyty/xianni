# 第683章 惊退千葵子

> 出处：《仙逆》第七卷 名震罗天 · 第683章（第三更）

## 一、拦路者：千葵子

- 身份：千家三祖之一，修道至今约万年；与幻家老祖幻无情是少年好友、交情莫逆。
- 外貌：看似四十许岁，面白无须、颇为英俊，一身白色道袍，仙风道骨。
- 境界：阴阳虚实中的**阴虚**境界（大神通修士）。
- 出手动机：**不代表千家**，以私人名义帮幻家老祖；报酬是幻家的一件宝物。他自觉幻无情素来吝啬，此次却如此大方，端倪太多。
- 出手前策略：先观察来人，可杀则杀取宝，不可杀便不为一件法宝埋下日后祸根。

他走出千幻星，盘膝坐于千幻星外星空静候。

## 二、对峙

数日后，王林踏银光如流星而至，神色冷峻，带着杀机望向变幻光彩的千幻星——“谁阻挡，谁便是他的敌人”。

- 千葵子喝“来人，止步”，声音出口化作法印般轰然扩散，如若奔雷——**言出法随**；王林由星罗盘化作的银龙光芒被压得黯淡。
- 王林因**融合了仙卫傀儡**，一眼看出对方为阴虚境界（若单以神识则看不出具体）。他也自知仙卫傀儡虽同为阴虚，却无法与真正修士媲美、略有不足，但仙卫有专用神通，实力不弱。
- 千葵子以长辈口吻劝其报出家族长者名讳以免杀劫，打量之下认为王林修为很弱、**尚未达到问鼎中期**；但目光落到王林脚下虚影时大惊——那是**阴虚境界的傀儡**。
- 王林表态：此事是他与幻家的私怨，请前辈莫要参与。

## 三、贪念与交手

千葵子内心挣扎：一面垂涎傀儡，一面顾忌对方家族。最终贪念压过理性——他盘算杀了王林后可将事推到幻家身上，届时千幻两家联手，对方家族也须掂量。遂开口索要傀儡。

交手三回合：

1. **仙卫出手**：王林身下虚影一晃，仙卫傀儡现身，一踏而出，双手撕开星空数道裂缝。
2. **符文压制**：千葵子端坐掐诀，口吐符文，大量符文散发庞大气息逼向仙卫。仙卫（仙帝青霖仿照古神炼制，神通多在肉身强度）掐诀起金光化作金人，一拳音爆连环、震出无数星空细缝，符文当场崩溃。千葵子见其**祭炼了肉身**，贪意更盛。
3. **符文之雷 vs 雷兽**：千葵子改换咒语语调，符文尽化成千上万道奔雷齐降。王林拍储物袋放出**射神车**，砰然化作**雷兽**；雷兽一声咆哮，符文之上雷光尽数脱离、聚向雷兽被其一口吞下，兽身暴涨一倍有余，打了个饱嗝，眼中雷光浓郁。

## 四、误认与退让（关键转折）

- 千葵子霍然起身、面色大变：**雷兽在罗天星域唯有雷仙殿拥有，是雷仙殿使者的标志**，这在他万年修行的认知中已是“死定”与“永恒”。
- 他据此串起前情：凌厉剑气、阴虚境傀儡护身——断定王林是**雷仙殿之人**，且在殿中另有身份（否则不会配阴虚傀儡护卫）。
- 立即收起所有符文，赔罪称“误会”，面色苍白。他可招惹罗天星域任何修真家族，唯独不敢对雷仙殿有丝毫不敬。
- 表态：不能帮王林对付幻家（同属一星），但**千家绝不参与此事，斩断与幻家一切联系**。
- 王林平静索要**仙玉**。千葵子苦笑，认定这是贪心的惩罚——雷仙殿之人各有一项保命神通，即便真杀了此人，不久罗天星域将无千家存留之地。他咬牙取出一个储物袋（自忖对方未说数量是让他自己拿捏），肉痛掷出，抱拳转身飞回千幻星。

## 五、余波：千葵子迁怒幻无情

返回千幻星后，千葵子神识横扫笼罩幻家，阴森传念：

- 千葵子：“幻无情，你让千某去招惹雷仙殿之人，此事，千某记住了。你幻家灭族之日，千某在你后人身上定会好好回报于你。”
- 幻老祖（幻无情）皱眉回念：“他不是雷仙殿中人，而是与我义女**幻眉**一样，来自**联盟星域**。”
- 千葵子大怒斥其隐瞒——“雷兽只在雷之仙界，是雷仙殿使者标志，此事谁人不知”，将此事记恨在心。

## 六、附带设定要点

- **凌天候剑气存量**：王林体内还剩两道。进潮汐深渊前本有两道，助古妖时用出一道，深渊内又得两道，合计三道。
- **仙卫傀儡来历**：仙帝青霖仿照古神炼制；本片段中已祭炼肉身。
- **阴阳虚实**：其中含“阴虚”境界，为大神通修士层次。
- **星罗盘**：王林脚踏之物，可化作银龙飞行。
- **雷仙殿（雷电殿）**：位于/关联雷之仙界，垄断雷兽，使者以雷兽为标志，每人拥有一项保命神通，为罗天星域不可招惹的存在。
- 王林真实来历是联盟星域（幻无情所述），本章被千葵子误认为雷仙殿之人——这是他全身而退并勒索到仙玉的直接原因。
