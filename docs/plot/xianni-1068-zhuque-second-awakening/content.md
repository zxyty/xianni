# 第1068章 三更｜朱雀二次觉醒

## 一、吞噬黑衣人元神
- 古妖贝罗喷出大量妖气拼命一冲，虽自身更虚弱，却使黑衣人元神脱离古魔塔珈操控。
- 黑衣人元神欲逃，王林自漩涡中探出右手擒住，无尽火焰顺右手涌出将其死死包裹，向后一拽拖入漩涡。
- 王林眼露杀机，二话不说将黑衣人元神一口吞下。

## 二、三火归一，火种凝聚
- 吸收火龙 + 吞噬炎龙 + 融合朱雀，三种天下之火令王林体内火元力达到从未有过的高度。
- 丹田处随火元力浓郁、高温剧烈，凝出**指甲盖大小的火种**。
- 火种一出，第七层所有魔火骤然一顿，齐齐涌入漩涡，几乎刹那融尽。
- 魔火、火龙、炎龙三力与朱雀融合，**以朱雀为主、其余为次**，展开火之变异。

## 三、朱雀觉醒规则（设定）
- 朱雀圣宗中，持朱雀印记者**一生觉醒次数决定其修为最高点**，也是成为朱雀圣皇的关键。
- 若印记者皆为一次觉醒 → 争斗定胜负，胜者为皇、败者为长老。
- 若有人达成**二次觉醒** → 无需争斗，圣皇必属此人。
- **三次觉醒**：朱雀圣宗有史以来从未有过。

## 四、洞府七层至一层连环崩塌
1. 火焰旋风自第七层火山口轰出，火山遍布裂缝、彻底瓦解。
2. 火焰风暴直冲九霄撞上层顶，第七层与**第六层**打通；第六层大地崩塌、建筑瓦解、禁制尽碎，**粉衣女子**与**村姑美妇**正在第六层大殿，惊骇目睹如末世之景。
3. 冲破**第五层**，全层轰然瓦解；苏醒的**王巍**与**胡娟**毫不犹豫紧随火焰冲出。
4. **第四层**崩——**司徒南**（自第336章起自称司徒南的断臂所化人影）呆望倒吸口气，随火焰而动。
5. **第三层**崩、**第二层**崩。
6. 至**第一层**火焰滔天而止，不散反而疯狂内缩，尽数融入王林体内。

## 五、二次觉醒之相
- 王林双目无火，但身外弥漫**无形之火**，四周空间扭曲、目光难以穿透。
- 头发彻底改变，**一头白发飘舞**。
- 身后幻化朱雀，通体**由赤红转为雪白**，白如雪却蕴含无法想象的可怕炙热；神色高傲，环绕王林仰天发出穿透天地的朱雀之音。
- **朱雀，二次觉醒。**

## 六、连锁反应
### 虚空子（第四层角落）
- 正隐匿盘膝苦撑**天人第一衰**，自忖一旦成功则伤势尽复、修为暴增数十倍，届时『杀那王林如捏死蚂蚁』。
- 闻二次觉醒之音，无法置信：一次觉醒尚可接受，二次觉醒与一次觉醒『天地之差』——一次觉醒令朱雀圣宗全力保护，二次觉醒则令其**不惜一切代价**；一次觉醒修真联盟虽必杀却不震撼，二次觉醒连修真联盟也会被震撼；且两次觉醒间隔短到几可忽略。
- 心神剧震下喷出一口元神精华，脑中错乱、体内元力疯狂，**天人第一衰出现失败的初步迹象**；此衰诡异莫测，一念波动即功亏一篑，失败则**形神俱灭**。

### 朱雀圣宗（星空）
- 妖灵之地尘埃外的**朱雀真灵**同时发出朱雀之音；周围朱雀圣宗之人尽皆睁大双眼，尤以**六名碎涅修士**倒吸凉气。
- 众议：『如此短的时间竟然二次觉醒』『我朱雀圣宗的希望将要来临，若此人平安，我朱雀圣宗将会崛起』。
- **燃烧星域**最深处、通体白色石块之上，存活无数年的**朱雀圣皇**苍老双目爆出前所未有精芒，挣扎欲起身而未能成功。
- 叹曰『我的时间已经不多了……为了这二次觉醒的族人再放弃一些残存的时间，也是值得』，闭目刹那火焰之力自体内轰出，整个燃烧星域震颤欲崩。
- 其体内飘起一个**中年男子模样的元神**（并不苍老），感慨『我已经很久很久，没有元神亲自出窍了』，前方星空火海现出漩涡，一步踏入消失。

### 古魔塔珈 vs 古妖贝罗（第七层）
- 塔珈望着冲天火焰旋风首次露出凝重：在意的不是朱雀觉醒，而是**王族古神与朱雀圣兽竟会融合**尚非重点，重点是方才他欲出手阻止的刹那，此人竟令他**心神一跳**——『他身上，到底还有什么』。
- 贝罗趁火焰风暴之机逃出魔火笼罩，损失惨重（半个妖身被吞、脱困时又遭魔火重创），无心再战，身影如电直奔上方，欲『迅速回到界外』，自认『这塔珈，我斗不过』。
- 塔珈对夺来身体的操控愈发灵活、威力与速度数倍于前，此地众人中最不能放过的就是古妖，遂弃王林一步直追贝罗，转眼拉近距离。

## 七、待续悬念
- 王林二次觉醒后的直接后果（朱雀圣宗必将不惜代价争夺/护持，修真联盟态度）。
- 虚空子天人第一衰能否挽回，抑或形神俱灭。
- 朱雀圣皇元神亲至的目的与去向。
- 塔珈追杀贝罗的结局，以及塔珈感知到的王林身上『另一样可怕之物』究竟为何。
