# 第626章 白衣女尸的身份（仙逆·王林线）

## 一、玉简第一部分：三件仙宝 + 一套仙术

玉简由青霜之父留下，语气为「为父」，逐件介绍所赠之宝：

| 名称 | 类型 | 要点 |
|---|---|---|
| 点仙笔 | 仙宝 | 蕴含太阴之力；采集十二星辰化作十二个蕴含太初之力的符文，以此笔点化而出，威力「尚可」 |
| 捆仙网 | 仙宝 | 威力寻常，但内部器魂已现神智初开之相，「颇为有趣」 |
| 祀灵鞘 | 仙宝 | 以洗仙池内的朔仙金制作；配合雨之仙剑使用，将仙剑融入其内可壮大剑灵 |
| 定身术 | 下品仙术 | 得自一处奇异的远古星球，原本残缺；其父整理后复原了「定身」神通，推测原属某个庞大组合神通的一部分，全貌无法复原 |

王林所得实物中只见到两件仙宝，祀灵鞘不在其列——因为它当年被赠予「青霜」。

## 二、玉简的三层封印

- **第一部分**：无禁制残留，神识一扫即明（岁月流逝已自行解封）。
- **第二部分**：混沌弥漫，只见只言片语，其中含**仙卫的制作方法**；封印已松动大半。矮小老者对「仙卫」的认知即来源于此。
- **第三部分**：封印完整。
- **总禁制**：血脉禁制——「若无你之血液，不能破解」。

## 三、王林的推断链

1. 祀灵鞘赠予名为**青霜**的女子 → 青霜是**雨之仙界的仙君**，持**雨之仙剑**。
2. 「青霜」之父 → 王林脱口而出：**仙帝青霖**。
3. 周佚所赠、痴情所系的白衣女尸，是否即仙帝青霖之女？

## 四、验证：取血破禁

1. 王林一拍储物袋放出周佚所赠宝塔，未变大即以掐诀引出白衣女尸。
2. 先以风刃划其右手腕——红痕瞬间消散、血未及流出，恢复如初。
3. 改以**凌天候的剑气**融入双指再挥——红痕再现，愈合速度明显放慢，滴落**一滴红血**。
4. 收回剑气，隔空摄血，女尸飞回宝塔收入储物袋。
5. 血按玉简 → 红雾融入，咔咔作响，蜕下一层青色碎末，露出**晶莹青色带一丝血线**的玉简。
6. **后两部分封印全开** → 王林轻叹：「她居然真的是青霜」，随即神识沉入玉简查看其余内容，不知时日。

## 五、支线：矮小老者与许立国

- 王林沉入玉简的第二天，矮小老者清醒。
- 身外**三才剑阵**紧逼，阴寒剑气自皮肤透体，他一动不敢动。
- 以其修为隐约看出：三才剑阵的玄妙不在宝剑本身，而在其内蕴含的**奇异之力**。
- **许立国**在旁看守，悠哉飘荡、时露阴森微笑，拿小黑刀在身前比划。

## 一、玉简所载：仙卫傀儡术与洞府地图

数日后王林收回神识，睁眼长舒一口气，对新得玉简作出评断：**“这仙人，比之修士还要冷酷。”**

### 第二部分——仙卫
- 详细记录名为**仙卫**的傀儡制作方法。
- 此术并非为仙人准备，而是**为修士准备**：抓取修士炼制傀儡。
- 成功炼成者实力极强。
- 在著述的仙人看来，**仙卫不是人，而是法宝**。
- 分**上品 / 中品 / 下品**三品：
  - 下品仙卫表现出的修为，相当于**问鼎后期大圆满**——即“修道第一步的极限”。
  - 中品、上品仙卫的实力，王林以目前修为**无法判断相当于碎涅三境中的哪一境**。

### 第三部分——地图
- 是一副地图，看其样子应为**某处洞府的地形图**。

## 二、清算矮小老者

1. 王林收起玉简，看向矮小老者，平淡道“拿来”。老者苦涩称储物袋都已在王林身边，内心咒骂：这姓王的比当年抢他一个储物袋的那对道侣还可恶，“是要给我绝户”。
2. 王林一拍储物袋，**十块碎玉**飞出——正是老者麾下十个仙卫体内之物；老者见之面色大变。
3. 王林右手虚空一捏，十块碎玉**相互融合化成一体**。
4. 大手一抓提起老者，右手拍在其天灵之上，**生生震出元神**。
5. 元神方离体，王林喷出一口**元神精气**将其包裹炼化，老者元神内凝聚出道道仙气，化作**手指大小的一块碎玉**。
6. 收了碎玉后，将老者元神抛出宝塔，被天空**尊魂幡黑雾吞噬**，成为其中一员；老者肉身被袖子一甩化为飞灰。

**留其元神的两个理由**：一是婴变后期修为的元神浪费可惜；二是王林对**老者所发现的那处洞府**略有兴趣。

## 三、王林的当下取舍与仙术之贵

- 眼下并非离开之时。最重要之事：**在剩下的数十年内，让修为与法宝全部达到巅峰**，以迎接与**古妖的百年之约**。
- 尤重新得的**两样法宝**与**一门下品仙术**。
- 王林对仙术兴奋：此生所修神通，**除杀戮仙诀外，其余全部从下品仙术繁衍而来**。
- 仙术之稀：即便天运子一流人物，对仙术渴求也极浓。
- **仙术，才是真正的法术**，比一切神通强大无数倍。
- 妖灵之地长年吸引无数修士杀戮、对妖灵之人卑躬屈膝，图的就是**最终与古妖融合而被赐予仙术**。
- **天运宗获取仙术的唯一途径**：连续无数年始终持有“天运七子”封号者才获赐一套仙术；且天运子断然不会赐最好之术，只会挑一个寻常之术送出。
- 王林深吸口气，脑中浮现**“定身术”**口诀，闭目沉浸其中。

## 四、二十余年后的天下大势

- 时间流逝，**转眼二十多年**。
- **天妖郡 vs 火妖郡**战争已持续很久，不断升温、越加激烈；其余各郡终于按捺不住，准备出击。
- **古妖的应对**：战火妖郡前已考虑到此问题，在其余各郡蠢蠢欲动之时，以自身之力**彻底封印天妖城**；放弃天妖郡内其他城池，**只收住都城与龙潭**，等待与王林的约定。
  - 他不怕王林反悔——若真反悔，他会立刻展开神通，上天入地也要击杀王林；他相信王林不是短视之人。
- **炼魂部落**在此情况下立即加大扩张程度，不断壮大。
- **火妖郡战场异象**：数十年间，一个个身穿黑衣、行迹诡异之人渐被交战双方注意——他们出现在战场上吸收大量魂魄的同时，也带去大量生机。
- 同时，一批在战场杀敌无数、表现优异、实力大范围提升的**妖兵被晋升为将领**，取代已死去者的名额。

## 五、待办 / 悬念

- 王林尚未前往老者发现的那处洞府（玉简第三部分地图所指）。
- 数十年内修为与法宝须达巅峰，赴古妖百年之约。
- 黑衣诡异之人（疑与炼魂部落相关）在火妖郡战场的渗透尚未被识破。
