# 第1824章 烛火意志！（第二更）

## 一、少妇识破缓兵之计

- 此前王林以「火焰包裹的人影急速逃遁潜入地底」诱敌，属缓兵之计。作者点明：换任何人（包括王林本人）第一反应都会追击，少妇能在短时间内察觉并回头直奔地火主脉深处，已属难得。
- 王林感应到其行动，嘴角冷笑——此刻地火主脉中充斥两种意志：**地火主龙魂的意志** 与 **王林本源真身的意志**。
- 王林绝不容许有人打扰本源真身的吞噬：此为**本源的改变**，对他这从洞府界来到仙罡大陆之人而言，成功即实力大增。

## 二、本尊出手：三宝阻敌

| 手段 | 表现 | 结果 |
|---|---|---|
| 血剑（血煞剑） | 滔天煞气，隐含道古一脉气息 | 擦身而过刺入鬼脸，少妇神色大变 |
| 七彩长枪 | 七彩之光自地火主脉凝聚 | 毫无抵抗之力，被鬼脸一口吞噬 |
| 玄罗金印 | 内蕴玄罗一丝力量，大天尊气息 | 轰散鬼脸，金光万丈逼停少妇 |

- 少妇惊呼：「**道古七剑中的血煞剑——你不是修士！**」
- 王林自己也是此刻方知此剑名。他获得**烨寞传承**但**缺少左眼、记忆不完整**，只知此剑为烨寞被**道古皇尊**所赐，不知其名。
- 逼退后王林即撤，留声：「莫要再追，在下对大魂门没有敌意，只是要修炼一门神通，需这地火主脉一用。」

## 三、少妇的推断与决意

- 她感受到金印中令其恐怖的**大天尊气息**，由血剑推断赐宝者为**古国的大天尊**。
- 其自我说服的逻辑：
  1. 古国大天尊再强，管不到我仙族；
  2. 即便判断失误、此人背后是仙族大天尊，他动我大魂门地火主脉，被我追杀理所当然；
  3. 我并非要杀他，只是阻止，「就算是大天尊，也不能如此不讲理」。
- 人物侧写：**姓格极烈**，轻易不放弃，其修为与性格大有关系，「远非那杜青可比」。
- 王林暗叹：「真正踏入空劫的修士，都是心志坚定之辈……既然她不退，那就看看到底谁的速度快吧。」——转为**与时间赛跑**。

## 四、本源真身的凝聚进度

- 位置：地火主脉深处，主龙魂头颅之内。
- 状态：龙魂咆哮挣扎明显虚弱；王林真身**唯有头发仍是朱雀之羽**，但此刻**自发根开始出现黑色**，乌光缭绕并缓缓延伸。
- 判定条件：**黑色全部延伸完成 = 本源真身完全彻底凝聚**。
- 风险：若少妇在真身未完全凝聚前抵达，此次**彻底失败、付之东流**，且再寻此机会极为艰难。
- 本尊虽一次次现身阻拦、施展各种神通，但少妇数次之后视若罔闻，全力疾驰；数个时辰后已越来越近。

## 五、主龙魂的最后疯狂：自压夺舍

1. 龙魂咆哮渐弱、扭动渐平——实为外在假象。
2. 双眼骤然凝聚夺目光芒，发出最强烈嘶吼。
3. 以**收缩挤压身躯**为代价：无边无尽 → 万丈 → 千丈 → 百丈 → 十丈 → 五丈 → 三丈 → 一丈。
4. 一丈时再度轰然挤压，**化作拳头大小的火焰光团**；意志同样被凝聚压缩。
5. 王林真身被强行挤出的刹那，光团直奔其**眉心**，轰然融合冲入体内。
6. 目的：**类似夺舍**，磨灭王林神识、占据本源真身，令真身成为龙魂的意志承载体。

## 六、烛火意志——火之本源的明悟

- 王林神识如凡人置身怒浪大海、一叶孤舟之上挣扎；龙魂意志化作大手欲将其捏碎，其中充满挣扎、不屈与向天地挑战的嘶吼。
- 王林于模糊中见光、感热，「光与热的结合，就化作了天地的火」；此火带着燃烧一切乃至燃烧自己的疯癫与逆天之意。
- **核心明悟**：
  > 我王林明悟之火的本源，并非是得自朱雀，而是那**烛火之心**。烛火在风中摇摆，风欲吹灭，烛火渺小、似随时化作青烟，但每一次风来，它都会反抗、都会剧烈摇晃，它不甘心死亡。
  >
  > 这是烛火的意志，是我王林修道的意志，更是我王林这一生**逆天挣扎**的意志。
- 结句：真身蓦然睁眼，目内火焰弥漫，嘶吼咆哮——「我的意志，你敢磨灭，你能磨灭？」神识在火龙魂意志下挣扎，同样不屈，**如同蜡烛，如同烛火**。

## 七、悬念

- 少妇仍在逼近，本源真身凝聚（黑发延伸）未完成。
- 龙魂意志与王林神识的夺舍之争尚未分出胜负。
