# 仙逆 第九卷 云海之巅 第1421章 香火一拜！

## 一、设定铺陈：虚火之理
- **虚火**不属天地五行之内，需在**实火巅峰**之后迈出**破碎虚空**那一步，方可将实火转化，彻底成为**灭世虚炎**。
- 一切**情绪**都是虚火燃烧之因。与虚火修士交战，情绪绝不能有波动。
- 司墨子身为**第三步大能**，对心绪的控制入微：若他不想怒则绝不会怒，刻意之下一切情绪如死水。

## 二、破局：老朱雀埋下的虚火之种
- 司墨子因一丝**震惊**而生情绪波动——本不可能发生之事却发生了。刹那间全身虚火自体内爆发、透出体外，滔天燃烧；面色一变，情绪再波动，虚火更为剧烈，形成恶性循环。
- 老朱雀嘴角阴笑，内心自道：**先前那几巴掌不仅是教训，更是在司墨子身上留下「虚火之种」**，否则要战一个第三步大能太过艰难。「小家伙，就看你能不能抓住这个机会了。」

## 三、王林出手：三万六千七百九十三条虚火炎龙
- 王林一生厮杀无数，从生死中走出，绝不浪费机会：压下此前在**破空九灭**下所受伤势，双手掐诀向前一指。
- **左目瞳孔中的九色火焰**轰然飞出，化作虚火直奔司墨子。
- 王林喝「虚火还不够，天地虚火，给我凝来」，大袖一甩，狂风带高温横扫四周数万观战修士——众人情绪剧烈波动，体内各生虚火，且一出现便化作**虚火炎龙**。
- 共**三万六千七百九十三条**炎龙咆哮冲出、弥漫天地，仿若数万修士的情绪共同参战。
- **独门之处**：王林虚火中有**天逆元磁之力**，可吸收凝聚他人虚火；四代朱雀、二代朱雀虚火虽强却有极限，只能外放、无法吸收凝聚。放眼修真界火焰之力，唯王林一人能做到。
- 以左目九条炎龙为首、数万炎龙在后，化作惊天虚火风暴，在**大帝星**上冲入司墨子体内。司墨子面色苍白急退、眼露骇然，旋即强行凝固情绪。

## 四、诛心：破天宗与司马墨
王林见「还差一点」，连番以言语与旧物攻心：
1. 「司墨子，你可还记得**破天宗**」——司墨子身子一震，眼露挣扎。
2. 「你可还记得你**二师弟、三师弟**还有那被你**赶出洞府的十六弟**」——面色刹那苍白，身子一晃。
3. 撕开储物裂缝取出一枚玉佩，即**司马墨的破天宗身份玉简**。
4. 再取出一块**巴掌大小的兽骨**——正是当年司马墨被驱出破天宗的**一切根源所在**。司墨子怒吼「住口」，眼中通红。
5. 致命一击：「**我是该叫你司墨子，还是司马墨**」

结果：司墨子全身虚火轰然焚天，体内砰砰作响，喷出的鲜血一出现即燃成灰；疯狂自双眼而起，体内闪烁**七彩之芒**，其中**紫色几乎压过其余六色**。他停止后退，狰狞怒吼：「老夫不是司马墨，老夫道号，**司墨子**！」

## 五、反击：炼化香火界与香火神通
- 司墨子虚空一抓，天地一暗，撕开一道**巨大裂缝**，内中仿若另一界：遍布修真星，每颗星上无数生灵跪拜，香火之力浩荡而出。
- 喝令「开老夫**炼化香火界**，门徒魂现」——裂缝内无数生灵齐齐低语如咒；司墨子四周成片幻化出虚幻魂魄，无边无际、数量无法计算，裂缝内尚有无数未幻出，个个眼露狂热、散出浓浓香火。
- 围观修士哗然退后：「**香火神通**，独属于第三步大能的香火神通」「香火神通之下，一切生灵俱灭」。老朱雀目中一闪，不露心思。
- 「老夫门徒，齐拜我身」——无数香火之魂齐齐一拜，紫色香火之风滔天涌向司墨子，**将其身上燃烧的虚火尽数熄灭、不存半点**；代价是众魂魄立刻模糊，仿佛一拜耗力太多。
- 王林面色大变，内心咆哮：「这就是第三步？如水道子一般的第三步？虚火都可被其香火熄灭，莫非真的不可战胜？」随即又道「**第三步又如何**」。

## 六、焚香一拜，逼向王林
- 司墨子冷声：无尽门徒燃香火之力，**这香火只可拜我**；没有达到第三步便承受不了这无尽门徒一拜之力。右手一指王林：「香火门徒，给老夫向他**焚香一拜**！」
- 无尽香火之魂齐齐转身面向王林并一拜，天地骤起紫色狂风；王林感到一股**规则**自四面八方疯狂挤压，全身剧痛，体内更有撕裂欲将其撕成碎片，且力量来自天地、**无处可退可躲**。

## 七、伏笔：司墨子眉心的萤火小人
- 司墨子双眼与全身弥漫紫色紫光，但**眉心之中有指甲大小一处露出微弱萤火**。
- 王林看到萤火内盘膝坐着一个**与司墨子一模一样的小人**，脸露痛苦、两行眼泪流出，依稀传出微弱的一声「**救我**」。（暗示司墨子本我被压制／被夺，与其否认「司马墨」之名相呼应。）

## 八、收束
- 老朱雀神色有变，惊于司墨子香火门徒之多，身子一晃就要上前出手。
- 就在其脚步迈出的刹那，王林的声音绝天地而起：「**老祖，晚辈可以！**」

## 关键看点
- 虚火体系的胜负手 = **情绪**；老朱雀的「虚火之种」+ 王林的攻心话术 = 让第三步大能自燃。
- 王林火焰之力的独特性：**天逆元磁**使其能吸收凝聚他人虚火，为全书唯一。
- 第三步大能的护身底牌：**炼化香火界 / 香火门徒一拜**，可熄虚火、亦可作攻杀手段。
- 悬念：司墨子眉心求救的萤火小人；王林能否以未至第三步之身承受无尽门徒一拜。
