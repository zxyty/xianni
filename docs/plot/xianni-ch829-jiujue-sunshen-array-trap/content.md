# 第829章 九绝损神阵（第七卷 名震罗天）

## 一、报复奏效：封锁线松动

- 王林（化名「许木」）连番屠星式报复上演，追杀他的修真家族心神剧震。
- 其规则明确：**不杀婴变以下修士**，但附带血腥警告——「若再参与此事，所杀就是婴变以下」。
- 反应分化：
  - 被屠星的家族修士愤怒如狂，誓言寻「许木」报仇；
  - **罗天西域本地家族**衡量再三后悄然退走、赶回各自修真星——为姚家的利益而让家族小辈面临灭顶之灾，超出其底线；更根本的是王林的手段让这些以家族为利益核心的修士心底生寒。
  - **其他三域修士**虽犹豫但多数未走，理由是其家族修真星不在罗天西域，认定「许木」已必死无疑，眼下不过是死前挣扎，且他无法离开此域、谈不上报复机会。
- 结果：弥漫罗天西域的封锁线稀薄，王林感到压力大减。

## 二、姚冰云的紧逼

- 一名同样能**融入天地**的女子（姚冰云）追击越来越近，数次险些追上。
- 王林判断：此女修为**至少窥涅中期**，以自身之力无法将其杀死，颇为麻烦。
- 王林另判断：对方除融入天地外，必还有一种**类似推衍**的方法可推算他的方位。
- 王林以长久融入天地、**损害自身**为代价，耗时**三天**才再次令姚冰云的锁定失效。
- 同期封锁线持续收缩如收拢之圈，浓郁杀机几成风暴，卷动大片星空尘埃；王林可移动范围急剧压缩，若不尽快冲出便有性命之危。

## 三、择地布阵：九绝损神阵

### 选址
- 甩开锁定后，王林出现在一处**无任何生命气息的废弃修真星**旁，当即定下：「就选择它了」。
- 该星特征：废墟众多、大地处处裂缝、江海干枯、死气浓郁。

### 布置过程
1. 双手掐诀散出元力波动，化作**无数烙印**打向修真星，绕星不断打下，历时**一个时辰**，面色略白。
2. 落星后一拍储物袋取出**十亿尊魂幡**，抖开化作黑雾弥漫天地（黑雾中血祖之魂双目紧闭、遍体封印，四周为幡内无数魂魄）。
3. 从幡中抓出**阴虚元神**捏碎，左手按出烙印，抛下使其融入大地。
4. 阴虚元神不足（绝大部分已被王林吞噬），改取**问鼎元神**，持续打烙印后放其入地，历时数个时辰，面色更加苍白。
5. 最后对**血祖元神**略一犹豫后取出，于眉心留下烙印，但**未抛出**，仍留在尊魂幡黑雾之内。

### 阵法来历（设定要点）
- 出自当年**李元临走前传授的破灭禁制**；王林未得**破灭心禁**传承，故无法全部施展且威力不足，但其中部分禁制不需心禁亦可施展。
- **九绝损神阵**即其一，且被称为李元所授禁制中的**三大禁术禁制之一**。
- 特点：不需破灭心禁，但**需要大量元神**；李元本人虽会此阵，因要求太严格而**从未布置过**。

## 四、潜伏：隐匿禁制之术

- 王林收紧一切气息，施展李元所授**隐匿之术（隐匿禁制之术）**，沉入修真星内部盘膝而坐，与星球仿若一体。
- 此术极为神奇——当年李元施展时王林毫无察觉；但**必须拥有破灭心禁才能完善**，否则仍可能被察觉，这正是王林此前被围困时没有施展的原因。
- 王林冷笑自语：「姚家，还有那些追杀我的修真家族，王某给你们准备了一份大礼，眼下，只不过是前奏罢了」。

## 五、追兵入局

- **三天后**，收缩的封锁线令第一波修士抵达该修真星外，为首者正是姚冰云。
- 姚冰云神色冰冷，右手掐诀推衍，目光落在星上：「那许木，就在这里」。
- 其身后有两名**姚家族人**（一男一女，身穿华服）。华服青年轻笑判断王林在此布了阵法，随即提议：请各位道友助姚家**毁掉这颗修真星**，让许木随星崩溃。
- 众家族修士纷纷应诺，各种元力神通齐轰修真星，星体剧震、大片碎石脱落，将要崩溃。
- **所有人（含姚家青年）都停在星外，无人真正踏上修真星**。
- 收尾伏笔：姚冰云皱眉，她追寻王林多日，深知对方极为机敏，**断然不会留下如此大的一个破绽**。

## 六、待续悬念

- 九绝损神阵尚未发动，王林所言「大礼」的正菜仍在后面。
- 血祖元神被留烙印而不投入大地，用途未明。
- 姚冰云已生疑，是否会阻止毁星、以及毁星是否正中王林算计，本章未揭晓。

# 第771章 血祖元神自爆·万丈碎石大阵

> 世界状态须知：本章「许木」为王林自创化名（自第661/669/711/731章沿用），全部言行归【王林】。

## 一、修真星彻底崩溃
- 追杀修士持续轰击残破修真星，姚家青年冲出后展开姚家仙术，崩溃陡然剧烈。
- 又有数波封锁线修士赶来，不问缘由直接对残星发起进攻。
- 最终一声惊天巨响，修真星彻底坍塌，毁灭性力量弥漫，天地之力扭曲、死气回荡；碎石四射，弥漫方圆万丈，几乎将所有修士包围。
- 姚冰云自始感觉“不对劲”，察觉包围之势欲出言提醒，已然来不及。

## 二、紫电碎石大阵成型
- 万丈最外一块碎石先散出紫色电光，游走连接邻近碎石；刹那间所有碎石电光闪烁、彼此相连。
- 噼啪声中形成一道**电光封锁**，瞬息成型，快到不可思议。
- 随后一块碎片散出**阴虚修为波动**并砰然崩溃——威力等同一名阴虚修士自爆：附近低于阴虚者尽数重伤，两人当场喷血、双目暗淡。
- 此爆如同信号，碎片陆续自爆，力量此起彼伏、相互融合，极为顽强。
- **阵法阴毒之处**：阵内身亡者元神无法逃出，立被风暴吸收，随即自爆，化为风暴的一部分。

## 三、姚冰云主导的反击
- 追杀队伍中阴虚、阳实境界者众多，短暂骚动后联手反击，强得难以想象。
- 以姚冰云为首，出手之际自爆之力大范围崩溃；风暴由“向内收缩吞噬”转为吞到一半无力再吞，反被推得向外扩张。

## 四、血祖元神引爆——一声“爆”
- 战局胶着之际，黑雾无声弥漫，凄厉嘶吼中**血祖的元神**缓缓凝聚。
- 万丈外唯一未崩溃的碎石内传出王林冰冷一声：“爆”。
- 血祖元神散发浓郁血光而崩溃，波纹疯狂外扩；触之者除修为极高者外立死。
  - 罗天北域某修真家族阴虚修士：身子碎裂，元神亦无法逃出，全部消散。
  - 罗天南域某修士：身僵、砰然化作血雾。
- 万丈之内死伤无数，血雾弥漫，**数名姚家族人**亦未逃出，死于阵中。
- 王林现身万丈外，右手虚空一抓，黑雾凝聚化作**尊魂幡**入手，收进储物袋，随即遁走。

## 五、损神印重创王林
- 姚冰云一步临近，玉手双指虚空一点——此指蓄势已久，专等王林现身之刻。
- 指中蕴含姚家仙术神通**损神印**，专伤元神；她断言“区区阳实修为，在损神印下断无活命之幸”。
- 王林身子一颤，于百丈外被逼出虚空，喷出一大口鲜血、面色苍白如死灰，但毫不停顿，头也不回再融虚空远遁。
- 姚冰云见其“没死”一怔，眼露精光，继续追杀。

## 六、余波：许木扬威罗天星域
- 阵内死者仅占追杀大军的一小半，进入罗天西域的修士陆续尽数汇聚于此，杀机更浓。
- 舆论定性转变：“已不是许木与姚家之战，而是一场**灭魔之战**”，“只有杀了这魔道子许木，我等才可安心”。
- 一人独抗无数修真家族与姚家追杀，不但未死反连杀数人，以奇异阵法屠戮无数，遂得**魔道子**称号。
- 部分修真家族胆颤心惊，**退出追杀行列**；许木成为罗天星域一颗新星，修为高深的老怪也把目光投向姚家与许木的纠纷。

## 七、雷仙殿视角
- 雷仙殿云阁之上，**清水**自打坐中睁眼，望向远处喃喃：“此子颇有我当年作风，很好。”

## 关键结论
1. 王林的“碎石雷阵 + 元神自爆循环 + 血祖元神引爆”是一套完整的预谋杀局：轰碎修真星本身就是布阵素材来源。
2. 王林当前修为标注为**阳实**（姚冰云语），却硬扛姚家仙术损神印未死。
3. 血祖元神被当作一次性引爆手段消耗，事后黑雾被收回化作尊魂幡。
4. “魔道子许木”名号自此传遍罗天星域，为后续因果埋线。
