# 仙逆 第298-299章：幻相 / 战红蝶

## 一、青衫修士遗物清点（第298章）

### 古朴宝剑
- 王林神识一扫即动容狂喜，慎重收入储物袋。
- 内部构造与**禁幡**有异曲同工之妙：其内刻画无数禁制。
- 这些禁制均为**单一攻击属性**，故威力极大。
- 数量：**每三个禁制为一组，共三百组**；绝大部分为王林前所未见，非短时间可参悟，王林压下立刻研究的念头。

### 储物袋（三类物品）
| 物品 | 说明 |
|---|---|
| 玉简 | 记载大罗派仙界布局与传送阵地图 |
| 回鼎 | 返回所属修真星（此鼎通向大罗派所在），王林与自己的回鼎分开收存，防止拿错误回敌方老巢 |
| 极品灵石 | 数百枚，连王林定力也内心狂跳，随即自嘲『定力还是不够』 |

> 王林感叹：「在仙界杀人夺宝，的确诱惑极大。」

**背景设定**：极品灵石在朱雀星极为少见，大罗派所在修真星亦不多见，唯因大罗派乃万年大派、底蕴深厚方有存货。

## 二、大罗派的仙界布局（玉简情报）

- 大罗派数次进出仙界，共找到 **37 个碎片之地**，并在每处秘密布置**传送阵**。
- 传送阵构架于仙界之内，**寻常灵石无法开启，唯有极品灵石可开**——这正是青衫修士随身携带数百极品灵石的原因。
- 王林由此推断：进入仙界的众多修士中，必有很多如大罗派一样拥有各自的传送阵；只有**首次来此者**或**虫行修士**，才会飞升后从漩涡内随机落下。

### 玉简使用方式
1. 抛出玉简，神念一动 → 半空浮现阵法，其上有两处凹槽。
2. 投入两枚极品灵石入凹槽 → 阵法运转，玉简光芒转盛。
3. 浮现地图状虚幻之画：即修士下降时所见「镜子摔碎」的画面，无数灰色碎片中有 **37 个颜色明亮**。
4. 王林回忆自身下降时所在碎片位置定位自己，右手点选目标碎片 → 阵法全开，身影消失传送。

## 三、抵达边缘碎片：玄风仙剑之地

- **环境**：狂风肆虐、无山无水、状若沙漠；天际有一道巨大裂缝，寒风自其内咆哮而出，威能笼罩整个世界。
- **成因**：无数年前此地本有山有水；劫难之后，一位仙人的至宝**玄风仙剑**被打落此地，划破空间形成裂缝；此剑在划破空间的一刻自身碎灭，化成暴虐之风，无始无终吹袭这片天地。
- **传送阵状态**：阵法有防范光幕隔绝狂风，但晃动剧烈似随时破碎；王林冲出后，阵法以特殊方法隐匿消失。
- **王林疑问**：此地毁坏程度远超他之前所在碎片（已完全毁灭），大罗派为何专门在此设阵？（未解）

## 四、幻相：当年仙界的覆灭一幕

### 察觉过程
- 王林落地时心生警觉，见狂风中黑影渐现，神识却毫无察觉 → 立刻取出**禁幡**戒备。
- 黑影显形：身穿七彩衣的妙龄女子队列，身后童子端托盘捧仙果美酒，有说有笑却**全无声音**（天地间只有风的呜咽）；上空另有脚踩祥云的青年似在护卫。
- 王林收起禁幡，任其穿身而过——一名童子**从其体内穿透**，确认是幻像非真人。
- **推断**：仙界碎片内有股奇异力量，可把当年仙界的画面幻化出来；这些人当年确有其人，如今随风逝去，只留幻相。王林由此再生疑问：当年仙界到底发生了什么，会毁灭至此？

### 幻相内容（王林尾随观看）
1. 队伍停下，幻相变为宫殿，众多案几陈列仙果美酒；案后坐着数名**仙风道骨之士**谈笑论证。
2. **关键观察**：这些仙人施法**根本不捏任何法诀**，一切法术神通信手而来极为自然，好似天地之力尽在掌心随意使用。
3. 一人愠怒起身，指人斥骂，抬手化出**紫色雷球**并向上抛出大殿。
4. 天空异变：黑色闪电划过并化作**巨大拳头**，撞碎雷球后去势不停、自天而降。
5. 一拳之下，宫殿内所有仙人身体崩溃化作乌有，宫殿坍塌消散；唯最先飞出的**两名仙人**身放七彩之光挡住拳头。
6. 一道**蓝色剑光**自远处虚空旋转而来，划破天际撕出巨大缝隙，黑气自缝内冲出。
7. 天空幻化出**巨大手掌**，轻捏蓝光中的宝剑，一捏即裂崩溃化作点点蓝芒没入裂缝；唯该仙剑的**剑鞘**未崩溃，出现众多断裂后顺天空裂缝一闪而逝。

> 剑鞘的去向为后文留下明确伏笔。

## 五、战红蝶（第299章）

### 偷袭
- 幻相再变：众多仙人自大地各处腾空、面露愤怒；捏碎仙剑的手掌一翻下按，大地颤抖，掌中飞出一道**银光**自天而降迅速刺来。
- 王林正沉浸幻相、心神剧震，凭警觉甩出**驱兽圈**化作**雷蛙**，吐雷球与银光对撞，轰隆震响，雷蛙低吼退出数百丈。
- **关键**：若非王林神识已达**化神后期**，必会误认银光是幻相的一部分，从而被当场斩杀。

### 对话
- 王林踩在雷蛙头顶，一字一字道：「红蝶。」
- 红蝶面容冰冷、眼露无情：「你果然认识我，说吧，你到底是谁。」
- 王林笑答：「雪域国天之娇女，谁人不识。」
- 红蝶：「不说……那么你今日，就留在此地吧。」抬手银光凝聚。
- 王林点破其底细并试探软肋：「听说红蝶姑娘百年便从凡人修炼至化神后期，百年虽短，但对凡人来说却是一生，不知红蝶你的父母，可还健在？」——红蝶眉头一皱，直接翻脸出手。

### 交手与脱身
- 红蝶挥银光，漫天银芒洒向王林。
- 王林拍雷蛙吐出雷球，喝一声「爆」，雷球自爆化作道道雷电与银光交错阻拦。
- 借阻拦之机，王林与雷蛙一同后退疾驰远遁。

## 六、要点归纳

- **收获层面**：王林获得攻击禁制型宝剑（900 道禁制）、敌方回鼎、数百极品灵石与仙界 37 碎片传送网地图，等于接管了大罗派在仙界的部分战略资产。
- **设定层面**：仙界碎片存在「幻相回放」现象；真仙施法无需法诀；仙界毁灭涉及远超仙人层次的黑色闪电巨拳与虚空巨手。
- **冲突层面**：红蝶（雪域国）已在仙界与王林正面对上，双方结怨升级；红蝶百年凡人至化神后期的天资与其父母被王林点破为潜在软肋。

## 待解伏笔

- 大罗派为何在这处彻底毁灭的碎片设置传送阵？
- 顺裂缝逃逸的仙剑**剑鞘**去向。
- 黑色闪电巨拳与虚空巨手的来历，即当年仙界毁灭的真凶。

# 第299-300章（仙玉）剧情梳理

## 一、意境交锋：王林 vs 红蝶（化神后期）

### 攻守经过
- 王林边退边以言语相激：「你父母除你之外可还有其他子女，若无，岂不是无人送终，人有不孝，此为其一」。
- 红蝶催动飞剑，剑带无情意境，穿梭间四周飘落无数雪花。
- 王林拍储物袋取出**禁幡**，抖出黑雾与禁气恶龙迎击，随即借黑雾瞬移至红蝶身后数十丈，掐诀在身前凝出黑白二气漩涡，**生死意境**扩散。
- 红蝶反手一抓，五道寒冰之气化作**五座雪峰**轰然降下；雪峰接触漩涡即融去大半。
- 碰撞刹那，一丝无情意境侵入王林体内：面色苍白、喷出的血当场结冰、脑中父母亲人的记忆开始衰退。

### 王林的破局
- 王林清醒判断：一旦亲情记忆尽散、被无情意境浸透，自己将沦为无感情的杀戮者，且脑中无情意境会化作种子，令**自己的生死系于红蝶一念之间**。
- 他以化凡的一幕幕、大牛爹娘的生死、凡人一生凝聚生死意境反冲，并大喝：「百年时间，凡人一生，父母至亲，岂能是天道可以抹灭……你爹娘即便进入轮回，也一直在你身后看着你，你可敢回头一看」。
- 红蝶神色如常，但无情意境**略有松动**；王林趁隙瞬移至数百丈外的**雷蛙**上遁走，同时抖禁幡放出上百条禁气恶龙断后。
- 数息后王林将那丝无情意境逼出体外，全身通达，暗惊化神后期意境之强，并意识到「从红蝶偷袭的一刻，战斗便已开始」。

### 破道心的谋算（关键设定）
- 王林当年看过**冰清决**：修炼要旨是把众多情感尽数散发后一一捏碎、炼化自身所有感情，达到心若冰清——这即是红蝶的**道心**。
- 王林的推断：红蝶修炼仅百年，天资虽强，但**缺乏长岁月凝练**，俗世情感必未彻底磨灭，此为不可磨灭的破绽。
- 因此父母之论意在勾起其一丝回忆以破道心。红蝶数次不为所动，直至生死意境临身时意境一顿——王林知言语已成功。
- 效果虽不明显，却在红蝶心中**埋下种子**；王林判定：只要种子不灭，红蝶**决然无法婴变**；若日后多次刺激并证明生死意境才是天之大道、无情意境并非真正无情，此女将不再可怕。

### 红蝶视角
- 她元神出窍，蓝色波纹一扩，禁气恶龙尽化冰雕坠落。
- 她一眼看穿王林目的，但承认其意境极为诡异——竟是**轮回天道的一丝生死感悟**；雪峰撞漩涡时她脑中浮现儿时记忆，虽即刻驱散，却因那句「即便进入轮回，父母也在看着你」而记忆散乱、为之一顿，**失去了杀死对方的机会**。
- 结论：「区区化神初期，倒也有趣，懂得坏我道心，此人绝不能留」，随即追击。

## 二、虚张声势的巨大掌印
- 红蝶挪移之法远胜化神初期，寒冰之气迫近。
- 王林脑中忽现空明，忆起**仙界碎片宫殿群内的巨大掌印**（曾尝试感悟而失败），又与幻相中**捏碎仙剑、向大地按下的一掌**结合，福至心灵下腾空高飞。
- 高空停驻，低头向下一按：天空一暗，奇异之气四面汇聚，身下凝成巨大掌印，向红蝶印落。
- 红蝶**第一次面色大变**，欲退不及，掌印穿体而过印在大地掀起气浪——但她体内毫无异常。
- 真相：此掌只是王林略有感悟、**徒具其形，毫无攻击力**。

## 三、遁入第三处仙界碎片
- 掌印耗尽王林全身灵力；他因受**驱兽圈**影响对此极有经验，立即吞服丹药，不待化开便抛出**玉简**打开阵法，随意选一处碎片消失。
- 红蝶抬头人已不见，判定：拥有传送阵法者身份绝不寻常，道法非凡、胆大心细、意境诡异、法宝层出不穷，「定是**朱雀星**上某个**五级修真国**全力培养的精英弟子」，随后转身另寻仙界之气。

### 碎片环境
- 遍地暗红色岩浆，气泡鼓起、刺鼻；天空昏暗，时有利刃般**空间裂缝**划过，仿佛随时可能崩溃坍塌。
- 王林下降至距地不足百丈时，一道裂缝在身旁**无声无息**裂开，神识毫无察觉，他凭反应硬移数丈，左侧衣衫仍被吞噬一大块。
- 王林评价：此地危险程度已可与**古神之地**媲美；他花一炷香才谨慎降至离地十丈的相对安全高度。
- 地貌：三处碎片中**最小**的一个；东南方向有一凹进去的**大洞**，一片漆黑，此外别无异常。
- 王林用数日搜遍全境确认无异后，重返洞口，疑惑大罗派为何总把传送阵设在险恶之地——莫非环境越恶劣仙界之气越多。

## 四、大罗派二弟子与仙兽府
- 正欲入洞时，半空传送阵亮起，走出两名背负宝剑的修士（均化神初期），无法察觉神识已达化神后期的王林；王林大喜，欲让人在前开道降低风险。
- 三师兄叮嘱六师弟：此地十分危险，须**时刻运转弥寻诀**以提前察觉裂缝——二人一路有惊无险，速度比王林快数倍。
- 对话要点：
  - 此大洞即当年**仙界十六座仙兽府之一**；
  - 由**大罗派始祖**进入仙界数次后偶然找到；
  - 知晓此处的人应该不少，三师兄上次来时见有**三组人**在此寻找**仙兽之灵**；
  - **进入此地后不能使用瞬移**。

## 五、要点归纳
- 王林首次以「言语+生死意境」正面动摇化神后期修士的道心，确立生死/轮回意境对无情意境的克制路径。
- 掌印是感悟仙界宫殿群遗迹后的初步成果，目前只有形无力，是后续神通的伏笔。
- 新地图节点：岩浆碎片（最小）+ 东南仙兽府大洞，规则为「禁瞬移、空间裂缝不可神识预警、需弥寻诀」。

# 第300-301章 仙兽府探秘与大罗剑宗同门相残

## 一、场景：仙兽府地底

王林隐匿身形，尾随大罗剑宗三师兄、六师弟自大洞下沉进入地底。洞不深，底部是一处极大洞府，四周如蜂窝般密布无数出入口，九转十八弯，若非神识锁定极易跟丢。

从二人对话中，王林推断此地为**仙界仙兽的栖息之地——仙兽府**。当年劫难并未使仙兽全部灭绝，尚有残存仙兽之灵在此酝化，这也解释了此地为何存在传送阵。

## 二、洗灵葫与仙界之气

- 大罗剑宗**始祖大人**当年正是在此获得一只**仙麒兽灵**，凭此统一**夭盾星**，成就大罗派千秋威名。
- 二人来到一座数十丈大小、刻有巨翼鸟兽的石雕前。三师兄以神通催动双手（青筋暴起、面色苍白），配合法诀强风，两次移开石雕，露出拳头大小黑洞，仙界之气自内溢出。
- 三师兄取出**青色小葫芦**将仙界之气尽数收入。六师弟点破其名——**洗灵葫**：始祖亲自炼制，全宗仅三个，有此宝便无需费力凝练，可以最快速度吸收仙界之气。
- 本次收获足以凝结两粒结晶，二人各分一粒，「算是完成了门派的最低要求」。

### 王林的算计
王林内心大动，认定洗灵葫必为异宝——有它可省去凝练时间、获取更多仙界之力。他冷笑：既已与大罗剑宗结怨，索性设法夺宝。但评估二人皆为化神（六师弟看似刚入化神、修为未稳），手中恐有强力法宝，夺取略有难度，故按兵不动，静待时机。

## 三、诱饵：灰白骸骨与「仙兽之粮」

二人转入他洞，途中发现一具斜靠洞壁的骸骨，手持散发融合之光的光团。

王林的观察（危机感来源）：
- 骸骨呈**灰白色**，年代久远却无变色、无侵蚀之态，极为蹊跷；
- 光团中弥漫一丝仙界之气，绝非凡物。

三师兄命六师弟上前查看。就在六师弟探身瞬间，三师兄突然喝「退」，挥剑劈出剑芒。骸骨化作碎末，光团中弹出一条细丝直扑六师弟眉心，被剑气逼退后钻入旁边洞口消失。

三师兄狂喜追击，并解释：此物是**仙兽之粮**，最受仙兽喜爱，其存在之地四周或许有仙兽之灵；先前那具骸骨想必就是被它偷袭、吞噬了全身血肉。其特性是**全靠攻击、无任何法术神通，且极畏法术神通**，只要不被钻入体内，一道剑气即可将其斩为两段。

### 王林的判断
以王林的世故，一眼看穿三师兄心怀叵测：其早已察觉异常，故意指使师弟上前查看，**以师弟为饵**引出仙兽之粮。同门情谊只是表象。

## 四、巢穴：数万细丝与神秘遗骸

追击中二人越入越深，三师兄虽曾来过仙兽府一次，却从未至如此深度，心生不安。

仙兽之粮钻入尽头一处拳头大小的洞。王林神识跟入，见到：
- 四周墙壁密密麻麻固定着**无数细线**，一头固定、一头缓缓摆动；
- 小洞中央一块**白色玉石**，散出浓郁仙界之气；
- 玉石旁一具**黝黑骸骨**，散发丝丝乌光，衣衫破碎，胸口有一枚**金色铁片**时而散发威压；手骨握有一把**飞剑**，其样式与王林当初在幻相内所见的飞剑极为相似；
- 一条**黑色细线**在骸骨上钻来钻去，每钻一次骸骨便颤动几下，好似复活。

王林毫不犹豫后退，寻一处凹地，取出**禁幡**一抖包裹全身，拟态成与四周墙壁一般无二。

## 五、反杀：三师兄之死

三师兄神识发现异常（洞内怕有不下数万仙界之粮），急停后退，六师弟亦然。但已太晚，细丝化作道道银光铺天盖地扑来。

1. 三师兄大喝「**双剑临世**」，二人双剑交错斩下，剑气如长龙，轰出三丈缺口，令本就不算坚固的仙兽府多处坍塌——缺口中却钻出更多细丝，其中一条**黑线**极为惹眼。
2. 退速不及细丝，三师兄二话不说一掌按向六师弟后心，欲以其为替死鬼。
3. 六师弟回头，目露嘲讽，反手抓住其手臂——气息骤变，由「刚入化神」暴涨至**化神中期**，一直隐藏实力。他夺过三师兄的**储物袋与宝剑**，将其掷向后方。
4. 三师兄肉身被细丝群从各处钻入，眨眼只剩尸骸；元神飞出时被六师弟隔空数道法诀阻拦，失去逃机，被那条黑色细线化作黑电钻入、游走一圈后生生吞噬吸收。
5. 六师弟留下一句「对不住了，师兄」，借师兄挡灾争得逃命时机，加速遁走。

## 六、要点归纳

- **新地理/设定**：仙兽府（仙界仙兽栖息地）、传送阵成因、夭盾星与大罗剑宗始祖来历。
- **新宝物线索**：洗灵葫（王林已列为夺取目标）、白色玉石（浓郁仙界之气源）、金色铁片、与幻相中相似的飞剑。
- **新生物**：仙兽之粮（细丝），黑色细线疑为其首领/异种，可吞噬元神。
- **人物动向**：王林全程隐匿观望，未出手；大罗剑宗内部同门相残，六师弟携双份战利品逃亡——为王林后续下手创造条件。

# 第302章 再探（仙兽府坍塌·孙雷结盟）

## 一、抢宝与撤离

- **伏击时机**：六师弟（孙雷）自王林藏身处一闪而过，大量细丝紧追其后。那条**黑色细丝**经过王林藏身处时**略微一顿**，随即继续追向前方——暗示其已隐约感知到王林。
- **闯洞**：细丝走后，王林冲入被剑气轰开的洞穴。洞壁细线扑来，王林**抖动禁幡**，以黑雾包裹己身阻拦。
- **取宝失败一半**：
  - 隔空抓**飞剑（仙剑）** → 剑上闪烁庞大威压，手如按刺，出现细小血点，惊而收手。
  - 黑色细丝掉头回返，王林**果断放弃仙剑与尸骸胸口的金色铁片**，隔空摄走**玉石（仙玉）**后夺路而出。
- **追杀与脱身**：王林全速穿行洞穴，**手指点在眉心唤出游魂**，各留一点神念四散以混淆追踪。黑色细丝发狂之下**穿壁而过**，逐一消灭游魂；待游魂数量不再减少，即证明其已彻底迷失王林位置。
- **挪移受阻**：王林数次尝试挪移，每次都被四周一股奇异之力打断，只能加速向上冲。

## 二、仙兽府崩塌

- 仙兽府洞穴众多，许多在**昔日那场浩劫**中已被深埋；两道剑气轰击又造成多处坍塌。
- 黑色细线横冲直撞、穿透性破坏 → 引发**连锁坍塌**，整个仙兽府**一大半位置被深深埋葬**。
- 王林退避后立于石壁前，摸着手腕上的**驱兽圈**，静候六师弟到来。

## 三、孙雷现身与谈判

### 双方底牌

| | 王林 | 孙雷 |
|---|---|---|
| 表面修为 | 化神初期 | 化神中期 |
| 对方判断 | 认定孙雷可能仍有隐匿 | 认定王林必然隐匿修为 |
| 底牌 | 禁幡、游魂、诡异神识 | 修有查看神识的功法、门派至宝 |

- 孙雷自曝身份：**并非大罗剑派之人，而是混进其中**。
- 孙雷之所以能找到王林：以**秘法记录了王林的神识波动**（王林神识诡异，寻常手段难以察觉）。
- 试探受挫：孙雷「看似随意」上前一步，王林露出似笑非笑之色并警告「再上前一步就出手」；同时四周墙壁内渗出让孙雷感到危险的气息，孙雷遂止步。

### 三宝估值（孙雷之说）

1. **仙玉**——无数年来仙界之气凝结而成，无价之宝。
2. **仙剑**——属性不明，但绝非凡物，三者中最珍贵。
3. **金色铁片**——孙雷猜测为某种防御类仙器。

> 孙雷的算式：仙剑 >> 仙玉 或 铁片单件；但 仙玉 + 铁片 ≈ 仙剑。

### 交易过程

1. 孙雷提议联手，先要仙剑、余两物归王林 → 王林摇头。
2. 孙雷改口「仙剑归你、余两物归我」→ 王林称三物皆无兴趣（**内情**：王林已知仙剑禁制极强，非长期祭炼无法拿起，短时间取不走）。
3. 王林点破孙雷似对**半空中的空间裂缝**预先有所察觉，索要相关法门 → 孙雷赠**玉简「弥寻诀」**（大罗剑宗神通之术）。
4. 王林进一步索要孙雷**三师兄储物袋内的青色葫芦「洗灵葫」** → 孙雷断然拒绝：洗灵葫正是他混入大罗剑派的**必得之物**。
5. 孙雷退让，出示**洗灵之木**（白色木块，可吸收仙界之气，功效逊于洗灵葫）作为报酬。
6. **成交条款**：王林助孙雷再探洞穴一次；取剑与否看孙雷造化；若取不到，洗灵之木同样归王林；木料**到洞口再交付**（孙雷防备）。

### 王林的权衡

- 为夺洗灵葫而杀孙雷需耗费法宝；仙界极为危险，**红蝶虎视眈眈**，法宝消耗过大则日后遇红蝶或其他强者必有危险 → 故选择交易而非动手。

### 孙雷的杀心（未发）

- 内心冷笑：即便王林隐匿修为，一旦到手仙剑便行强抢；大不了动用**门派至宝**，拼着立刻离开仙界的代价，也要一击杀之。这正是他明知忌惮仍邀王林同行的原因之一。

## 四、章末态势

- 二人一前一后向尚未坍塌的洞口行进，保持距离，彼此防备。
- 王林已入手：**仙玉**、**弥寻诀玉简**；待收：**洗灵之木**。
- 悬念：仙剑禁制、金色铁片归属、黑色细丝再遇、孙雷的背刺、红蝶的威胁。
