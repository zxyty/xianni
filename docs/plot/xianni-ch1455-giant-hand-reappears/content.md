# 第1455章 巨手再现！

## 一、灵动上人一击定局

- 王林收服的**古奴子灵动上人**因温养时间不长，无法长期唤出，**只有瞬息一击之力**，故王林一直隐忍，直到最关键时刻才放出。
- **妙音道尊**为太古五尊之一，此处仅是被压制修为的分身，仍强大得无法想象。王林能伤到他，靠的是层层叠加：先有血剑偷袭，再有大荒上人凶险厮杀，最终在大荒上人最强神通下重创。
- **最致命的关键**：妙音对王林的了解止步于大帝星，怎么也没想到王林已收服一个半只脚踏入第三步的灵动上人。
- 代价：灵动上人一掌拍出后被反震，喷血倒卷，其**雕像轰然崩溃瓦解**；王林嘴角溢血、双耳轰鸣，被妙音抛出的尖锐之音冲入体内，元神剧痛喷血后退。

## 二、王林的算计：给妙音留一线生机

王林对大荒上人毫无信任——“修道数万年的老怪，心思之深，绝不能小看，他能毁与妙音之誓，自然也可以毁与自己之约”。

因此他在灵动上人出手时**做了手脚**：

1. 使妙音倒卷的方向更远；
2. **未将妙音眉心的三根针全部拍下**，故意留一线生机。

结果：大荒上人分魂化黑气钻入妙音七窍夺舍，妙音仍有抵抗，二人在体内以神识厮杀 —— 时间被成功拖住。

## 三、天皇炉收毒海

- 被毒染的黑色海洋腥臭无比，其中无尽香火之魂皆成**毒魂**，再无法祭献半点香火之力。
- 但这整片毒海对王林而言是极为难得的法宝：在天皇炉内炼化后，**若能炼成一滴水，其杀伤力足以撼动第三步大能**，必须抢在大荒上人之前收走。
- 王林挥手将天皇炉扩至数万丈，把整片黑色海洋包容在内并尽数收走。
- **天皇炉内存在无数界**，以王林当时修为只能开两界：一界吸毒海，一界收回放出的古奴子。

## 四、香火海民界的争夺

- 妙音与大荒的夺舍之争，使古墓煞气内被撕出的庞大**香火海民界裂缝**急剧收缩，从数万丈缩至将要消失。
- 王林与大荒老毒联手，图的正是**妙音香火**。这香火王林自己用不上，但古奴子灵动只差香火便可彻底迈出第三步，**成为真正的第三步大能**。
- 裂缝内仍有无尽未被毒污的**紫海**与无法计算数量的**香火之民**——这是妙音道尊数万年搜集抢夺而来的根本。
- 战场余波：封印之地早已崩溃，其内一切修士均都死亡；四周雾气被推出极远，下方雾海露出大片空旷。

## 五、巨手再现

- 雾海内雾气井喷般狂暴喷出，下方伸出一条**数万丈粗细的巨大手臂**——这是王林**第二次**看到它。
- 手臂先抓中妙音道尊肉身：妙音喷血，体内元神被大荒趁机强行压下，肉身被吸在掌中无法挣脱。
- 随后五指如五根撑天之柱向王林握来，王林根本无法逃出其范围。
- **保命手段失效**：右手护臂内的古神保命神通「**古之庇佑**」不久前刚用过，此刻无法再开；且每用一次都会损伤护臂，直至最终崩溃。

## 六、古神真身撕裂缝、抢香火

1. 王林仰天咆哮，展露**古神真身**，身体暴涨至数百丈，硬生生在巨手中高出二百多丈，**抹去了与百丈裂缝之间的距离**。
2. 喝“封”——两片**古息叶**分左右印在裂缝两边，令收缩停顿片刻。
3. 古神右手伸进裂缝一抓，抓出无数香火之魂。
4. 巨手抓住其胸口以下猛地向下沉，剧痛欲将肉身捏爆；王林右臂被拽出裂缝的瞬间反手抓住古息叶封印边缘，左手亦抓住裂缝左侧，**数百丈古神双手死死抓着裂缝边缘**，身体被向下扯动数千丈，把百丈裂缝生生撕成两道数千丈竖裂。
5. 张口猛吸——一吸之下**吸走裂缝内全部香火的一成**。
6. 裂口一开，**天皇炉深入其内大半**，炉内变换出另外一界狂吸，紫海与香火之魂涌入，**再吸走两成**；两成紫海使天皇炉吸满，无法再吸。

**合计：王林从妙音香火界抢走约三成香火。**

## 七、结局与余波

- 王林忍痛松手，天皇炉化幽光没入眉心，两片古息叶一并收走。
- 其身子被巨手彻底拽入下方雾海，迅速消失不见；夺舍成功的大荒上人（占据妙音肉身）亦被一同拽下。
- 滚滚雾海从四面八方凝聚，填满因手臂出现形成的漩涡之洞，一切被雾气弥漫，**丝毫看不出异样**。
- 数个时辰后，一支二十多人的修士队伍乘平台从此地掠过，毫无察觉，只议论：“按照地图上显示，这里应该有一处封印之地才对……莫非是地图错误。”
