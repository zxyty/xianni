# 第1577章 域外

## 一、温养古妖雕像：左目七妖星

- **血源**：箭尖上残留的道古（道吉）左目干枯鲜血。其左目由**九星古妖**凝聚，虽历经岁月消散、血内之力不多，对王林而言仍是极大补品。
- **手法**：王林右手炼化血中古妖之力，于体内一转后经左手灌入所按的古妖雕像；雕像散发妖异红芒，如苏醒般不断吸收。
- **进度**：
  - 第1—10天：雕像左目渐次浮现妖星，累计**五颗**，妖异红芒几乎映照天地。
  - 第11天：箭尖干枯血液砰然崩溃，化作暗红色碎末脱离箭体。王林大袖一卷尽数收入掌心（手掌如暗褐色血掌），一掌拍在雕像天灵，血粉尽入，雕像妖气呼啸惊天，**第六颗妖星气旋**急速凝聚。
  - 追加血神子古妖：王林掐诀撕开储物裂缝，抓出当年从**血神子**身上擒获、被封印沉睡的古妖，撕开封印，趁其苏醒一瞬一掌拍下，其左目妖星崩溃化作磅礴妖力灌入雕像。
  - 最终：在道古左目血液余力与该古妖几乎全部妖力灌注下，雕像赤红如要滴血，**第六颗妖星凝聚成形，第七颗妖星亦成功凝聚**。
- **守诺**：王林未灭绝血神子古妖的生机，留其魂、封印后送入储物裂缝，准备离去后放走。
- **心境**：「既然找不到道古左目，那么我便自己养一个出来。」望着雕像升起**血浓于水**之感，随后将其收入储物裂缝。

## 二、道古之箭认主

- **显弓**：王林忍着体内排斥之力，运转**血脉仙力**，体内仙龙一动，全身之筋骤震、金光闪烁，身体近乎透明，体内现出一张弓——**此刻王林就是那弓（李广之弓）**。
- **箭魂苏醒**：巨箭轰然一颤，箭气弥漫扑向王林；一股沧桑之魂（箭之魂）自沉睡中苏醒，冲入王林体内与弓接触。
- **号令缩小**：
  1. 「小」——箭缩一圈，下滑数千丈，后段仍卡在天空窟窿外。
  2. 「再小一些」——再缩一大圈，彻底脱出窟窿坠地，箭尖深插大地，箭身嗡鸣；王林退立于**箭尾九片羽毛**之上，随箭身抖动起伏。此时箭仍有万丈之长、数百丈之宽，如巨柱斜插大地半截。
  3. 「小，小，小」——急速缩至正常大小，落入王林手中。
- **天空窟窿**：王林抬头见窟窿之后一片漆黑不知通往何处，其边缘正缓缓蠕动自行愈合，王林评曰「此地倒也奇异」。
- **归属宣告**：「此箭，从今以后，便是我王林之宝」，欲配合**李广之弓**试其一箭之威。

## 三、以魂加持箭身符文

- **符文**：箭身有**四道细长符文**，弥漫整个箭身，散发微弱幽光；王林判断其**与魂有关**，加持后可增此箭之威。当年李广一箭射落道古左目，所加持之魂不明。
- **动用天皇炉**：王林左手点额，额头浮现**古神星点**，**天皇炉**幻化而出并缓缓转动，炉内镇压着二人之魂——**南诏上人、天兆上师**。
- **加持**：王林遥指天皇炉，炉盖开启二魂飞出，未及逃遁即被虚空抓住按在箭上；符文幽光刺目一闪，二魂魂吼骤止，与四道符文中的**两道**融合，箭矢爆发出连王林也为之动容的惊天气息。
- **未动的备选**：另两道符文尚缺封印之魂。王林取出在**古神之地**所得的**道古烨寞的地府阁楼**（数扇窗，内封三个强大神魂，非万不得已绝不可放出）。凝视良久后判断「那三个神魂太过强大，是道古当年在其故乡封印的敌人，以我如今之力一旦放出会被反噬」，遂未轻举妄动，将阁楼收起。

## 四、看不透的箭尖圆环

箭尖处的**圆形之环**，是融合了道古与仙威所化**排斥之力**的重点。王林盯看数个时辰，始终看不透其结构与奇异，暗叹一声放弃观察。随后一挥手，箭矢化作金光消散、分为**七缕金芒**顺七窍钻入体内，收藏无踪。

## 五、返回符文族第十八层，窥见域外战场

- **归途**：王林一步踏入大地，循尚存的一层层环形圆圈疾行，回到石门后最后一个圆圈，右手一挥推开石门，出现时已回到**符文族第十八层**；随即大袖闭合石门，掐诀留下诸多封印。
- **下一步计划**：「要炼化道果，让我生死、因果、真假三道本源大成了。」
- **关键发现**：转身欲走时，王林目光落在先前破开石门封印时被冲击之力撞上的那面墙壁——墙壁满是裂缝、大量碎石脱落，其中一处裂缝极深、几近穿透，露出墙后景物：一片**漆黑空旷之地**，透缝传来的气息让王林**极为熟悉**。
- **收束**：王林喃喃——「**域外战场**」。
