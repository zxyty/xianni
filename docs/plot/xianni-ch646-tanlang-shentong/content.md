# 第646章 贪狼神通

## 一、蚊兽易主
- 一头紫色蚊兽（王林的蚊兽）如紫电穿过扑向王林的同类群，来到王林身边，以巨大口器轻蹭示亲，嘶鸣带兴奋。围攻的蚊兽群骤然一顿，凶芒中透出疑惑。贪狼目瞪口呆，远处辰龙眼中爆出精芒。
- 贪狼掐诀喝“七魔针，印”，蚊兽群深处那头头插七根银针的巨大蚊兽被逼飞出，银针齐齐下沉三寸，其目中挣扎更浓。
- 巨大蚊兽最终露出绝然与死意，长啸一声，目光投向王林的蚊兽——主动求死。王林的蚊兽飞至其背，口器刺入一吸而尽。巨大蚊兽枯萎，眼中挣扎化为解脱。
- 王林的蚊兽体型变大、紫色更浓，散出只有同类能察觉的浓郁气息；一声厉啸，全部蚊兽即掉头齐攻贪狼。**蚊兽群号令权就此易主。**

## 二、二打一：王林与辰龙夹击
- 贪狼头皮发麻，变化法诀收回七根银针化七道银芒结成银幕护身，踏步突围。
- 王林后退，食指一点，**寂灭指风**直取贪狼。
- 辰龙背后大剑飞出化作双目透邪气的黑龙，带凌厉剑气冲杀。二人素未配合，但修为眼力足够，出手时机皆卡在贪狼退路上。

## 三、贪狼神通：噬死一式 / 二式
### 噬死一式（抽壁中绿气）
- 贪狼右手成爪按深渊之壁，喝“噬死一式”，无数绿气自壁内涌出汇成绿色瀑布，向后一甩，长虹贯空。
- 寂灭指风触之即被吞噬，黑色指风瞬间转绿而崩溃；辰龙剑化龙魂对撞后龙魂崩溃，宝剑弯扭飞回。

### 二次强攻
- 辰龙喷元神精血于剑，剑身龟裂蜕皮，碎屑带血气再化黑龙，气势数倍于前。
- 王林右手触眉心，抽出如细丝般的杀戮之气，百万→十万→一千→唯一，压缩成一道（元神内另留一道以“生生不息”自我恢复），弹指射出。
- 贪狼一眼看破来历：“凌天候碎剑化神，天运子的杀戮仙诀”，并嘲讽二人所得神通皆不完整、是“别人施舍的神通”。

### 噬死二式·抽山魂
- 贪狼拍储物袋放出小山，迎风涨至百丈，山体刻满符文并诡异闪烁。
- 右手成爪按山，喝“噬死二式——抽，山魂”，一股沧桑如万年老修士的气息被生生抽出，山形虚影被抓出；山峰失魂后龟裂、化作无数碎石坍塌落下，山魂虚影仍存于贪狼手中。
- 山魂降临压中辰龙的黑龙，如压折龙腰，辰龙面色苍白、晃身喷血，惊问“这是什么神通”。
- 王林杀戮之气刺入山魂后喝“散”，一化百万纵横其内欲撕裂吞噬；山魂内却散出**浩淼仙力**，杀戮之气顷刻尽数崩溃。王林倒吸口气（幸有心神中留存一道可生生不息恢复）。
- 王林判断：山魂内的仙力绝非贪狼所有，更像山魂自身存在。
- 贪狼借势冲出蚊兽包围，大笑揭底：**此山乃仙界之山，为其数万年前生生拔起并封印。**

## 四、令牌现世与再度围困
- 远处紫雾持续收缩：百丈→一丈紫雾球→砰然缩至七尺。雾内始终无声息，但王林知其中有一名活着的**大罗剑宗弟子**。
- 雾气凝出一枚令牌，雾散后化为古朴令牌静浮半空，紫光中有金芒交错。
- 贪狼露出贪婪之色欲抢，身后蚊兽群突然癫狂冲刺，速度数倍于前；王林的蚊兽一声厉啸，所有蚊兽体表泛起浓浓红芒，近身者崩解为红芒包裹的血肉、瞬移般抵近贪狼身前再重新恢复成蚊兽形态——以此“崩溃—复原”的诡异神通把贪狼生生困住。

## 五、抢夺开始（章末悬念）
- 王林与辰龙目光同时锁定令牌，先后飞身抢夺。
- **空间规则**：出口处推力极重，无人敢在此瞬移，一旦瞬移身体会被生生卡在虚无中；故只能以身法飞掠。
- 王林飞出的同时右手掐诀，运起**仙术定身**。
- 蚊兽群内横扫出一声愤怒咆哮：“小辈尔敢”——未完待续。

## 关键看点
1. 王林的蚊兽通过吞噬前首领完成血脉/气息晋阶，正式取得蚊兽群号令权，成为战场变量。
2. 贪狼的“噬死”系神通本质是**抽取他物之魂/气为己用**（壁中绿气、山之山魂），被其自评为“没有破绽”。
3. 山魂内蕴含仙力，直接压制王林的杀戮仙诀与辰龙的碎剑化神——两大不完整传承神通在此吃瘪。
4. 令牌争夺三方（王林、辰龙、贪狼）+ 雾中未现身的大罗剑宗弟子，冲突尚未结算。
