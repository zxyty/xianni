# 第1700章 决断

## 一、魂魔舟甲板：鬼脸帆的真相

- 王林撕下鬼脸帆布，双手外展细看，帆布卷动使鬼脸似活了一般，狰狞回盯。
- **鬼脸帆 = 大魂门法宝 + 魂魔舟主魂帆**（矾珊璐亲口点明）。仙罡大陆的矾珊梦之所以能遥遥施展「大魂真幻术」并达到二重幻的可怕程度，主要便是借此帆之力。
- 王林回想：入幻中幻之前正是看了这鬼脸一眼，此后身不由己；破幻睁眼所见仍是这鬼脸帆布——**幻中一切似只发生在看向鬼脸的一刹那**。

## 二、王林的索取与条件

王林态度冷硬而明确：

1. 「你们姐妹之间的事情，王某不去理会」——不介入矾珊梦、矾珊璐姐妹恩怨。
2. **誓血不须交换**，因双方目的相同，只要彼此没有包藏祸心即可合作。
3. **鬼脸帆我取走，魂魔舟王某也要了**——作为矾珊梦此前行径（幻术算计）的赔偿。右手一甩即将鬼脸帆收入储物空间。
4. 矾珊璐不必离舟，**魂魔舟寄存其处**，王林需要时会传出召唤。
5. 追问：幻觉中所说的**道古祭坛**是否就在魂魔舟内？（眼中寒光一闪）

矾珊璐张口欲言，终究沉默，眼中复杂。

## 三、矾珊璐的交付：玉简（地图 + 神通）

矾珊璐摇头否认祭坛在舟内，抬手掷出一枚玉简，内含：

- **道古祭坛地图**：按图所去即可抵达祭坛。
- **一道可吞噬第三魂的神通术法**（即她在幻界中提过的法术），任王林斟酌修炼。

并交代此地空间的来历：

> 此空间存在无数凶兽；其形成**与当年洞府之战有关**，受波及撕裂而出；**却不知为何与一处奇异的世界连接在了一起**。

## 四、约定：「我想回家」

矾珊璐幽幽道出真实处境与请求：

- 姐姐矾珊梦为复仇已不顾一切，**连她自己也被姐姐利用于同王林的合作之中**。
- 她愿全力相助，只有一个要求：**王林打开洞府去往仙罡大陆时带她一起走**——「我想回家」。
- 开启洞府之法（关键情报链）：
  1. 洞府的打开极为艰难，**唯有第三魂出现**；
  2. **只有第三魂拥有记忆，知晓天道所在**；
  3. **唯有召唤出天道，在天道引路下**，方可进入**七道宗洞府界的仙尊府**；
  4. 仙尊府即**当年大战之地**，虽破损不堪，**其内有一扇通往仙罡大陆的门**；
  5. 打开此门，即打开这封闭的洞府。

王林脚步一顿，回身看了萧瑟的矾珊璐一眼，点头：「我答应你。」——**这是他修为到第三步后给出的第一个承诺**，与信任无关，只为「我想回家」四字。

矾珊璐咬破舌尖喷出鲜血，赤红转金色，射向王林；王林接住淡金色**誓血**融入体内，转身走向漆黑星空，再未回头。

## 五、二重幻术的性质（重要设定）

- 二重幻术**与真实无异**：王林在幻中的感悟与研究，出幻后**依旧存在**；
- 反之，矾珊璐在幻中受的伤，破幻后**伤势依旧**；
- 结论：大魂门神通诡异莫测，魂魔舟禁制王林已无需另行研究。

## 六、炼化鬼脸帆

- 鬼脸帆之上还有**包罗魂魔舟全部的诸多禁制**；
- **炼化此帆 → 掌握更多禁制 → 直接以帆操控魂魔舟**；
- 王林行于星空，神识融入储物空间缓缓炼化，已明悟部分操控之法，假以时日必彻底掌控。

## 七、王林的自我盘点

- **烨寞之子死在我手**，吸收其**八滴道吉之血**（其元神所化），若能全部融炼，可令**道古之身**更强。
- 祭坛必须一探，或有造化。
- 修为自评：**尽管空灵，可与那些空玄大能比较还是不如**。
- 时局：**远古仙域已开启，四大战将出现，其目的就是寻找第三魂**——省去王林一番算计，正是提高修为的最好时机。

## 八、发现幻中的七彩道人

- 星空漆黑，凶兽气息不断，但对王林毫无威胁，神识一扫即颤抖后退。
- 王林真正忌惮的是：**七彩道人是否也来到了此地**，故神识散开全神贯注，有异即遁。
- 数个时辰后，王林骤停欲退，随即轻咦：神识在**数十万里外**发现一片凶兽尸骸中盘膝的身影，**全身七彩光芒，一动不动**，神色时而复杂、迷茫、悲伤又兴奋——**正是七彩道人**。
- 王林刚经历幻觉，一眼看出：对方很可能**同样沉浸在幻觉中无法自拔**。
- 判断：「这幻术，很有可能就是那矾珊梦施展，以七彩道人的修为，居然也被笼罩……此事不对劲」——恐非矾珊梦一人之力，另有悬疑。

## 九、决断：富贵险中求

王林罕见地内心挣扎，两条路：

| 选择 | 后果 |
|---|---|
| 立刻离去 | 七彩此状态不会追击，去祭坛将没有危险 |
| 入其幻觉 | 可知晓真正的隐秘，但极险；放弃则日后必悔 |

挣扎半柱香后，寒光一闪：「**富贵险中求**」。

- 王林闪身出现在七彩道人万丈外，脚下皆是凶兽尸体，判断**这些凶兽死亡时间不长**。
- 试探：隔空托起一具数十丈大小的凶兽尸骸掷向七彩；尸骸入**百丈**内，七彩光芒一闪，尸骸颤抖、无声无息瓦解，**没有血肉、没有碎末，完全消失**。
- 「果然如此」——王林步步前行近万丈，在**百丈外**、尸骸消散处不远停下。

## 十、梦道之术失败

- 王林盘膝坐下，右手一点眉心（指似深入魂中），眼前出现模糊，猛然前指遥指百丈外的七彩道人：

> 「以我梦，入你幻，梦道之术」

- 结果：**身子一震，嘴角溢血，眼中模糊消散，人仍原地未变**。
- 原因：梦道之术并不需要身体直接碰触，但**七彩道人修为之高，更有禁制在外阻止一切**，王林无法以梦入其幻觉。
- 王林皱眉，神色露出不甘。

## 十一、遗留线索 / 后续钩子

- 鬼脸帆炼化进行中，尚未完全掌控魂魔舟。
- 道古祭坛未至；吞噬第三魂的神通未修炼。
- 七彩道人为何沉浸幻中——疑非矾珊梦一人之力。
- 八滴道吉之血尚未全部融炼。
- 对矾珊璐「带她回家」的承诺待兑现；开洞府仍卡在「第三魂—天道—仙尊府之门」这条链上。
