# 第1896章 疯狂的造化！（第三更）

## 场景
绿色空间内，王林肉身盘膝而坐，绿魔一族的绿袍老者（祭祀）当着两名绿魔使者的面，对其肉身进行一连串疯狂改造，为绿魔蝎（绿魔大人）的复活降临做准备。

## 一、族藏取出：封印在祭祀体内的万年积累
- 绿袍老者左手连拍身体多处，每拍一次便有数件奇异之物自体内散出，其身体如同储物袋。
- 这些是绿魔一族无数万年为复活绿魔蝎准备之物，以特殊方式封印在**一代代祭祀体内**。
- 除持有者本人意愿外，别人无法取出；或唯有修为达到**大天尊**方可做到。

## 二、四步改造

### 1. 仙树古枝 —— 补韧性
- 判断：此身显然是**道古一脉**之躯，坚度有余、韧性不够。
- 手段：取出生长了**九万年的仙树古枝**（黑色古老枝条，散发沧桑气息），此物在仙罡大陆极为少见，是其族以莫大代价换来。
- 效果：枝条爆开化黑色粉末，如有生命般化作虚幻丝线钻入王林汗毛孔，与血肉相连结成密集大网；肉身砰砰巨响、诡异蠕动，超出寻常古族之体，坚固且极具韧性、极难摧毁。

### 2. 仙极剑碎片 —— 凝天威
- 判断：此人双目不够犀利，缺少镇压他人的天威与天地至强之气。
- 来历：**仙祖末年与绿魔大人一战、被绿魔大人蝎尾崩溃的仙极剑碎片**，呈巴掌大小金片，似金像木、似木像金，其上有无数暗色符文，缭绕锋利至极的气息。
- 异象：金片一出，剑气弥漫横扫整个绿色空间，绿芒几乎全数崩溃，绿芒所化蝎子刺耳嘶鸣、显出畏惧。
- 效果：金片融入王林体内化作金色气息扩散全身，肉身轰然爆发实质般的天地之威，压得绿袍老者身子一震，两名绿魔使者神色凝重。
- 限定：此刻王林元神未操控身体，否则配合元神修为，此威压将惊天动地。

### 3. 开辟第二条经脉 —— 仙古并存
- 判断：王林经脉虽为古族之物，但绿魔大人身躯**强度超过古族、修为超过仙族**；且此身血脉越精纯越排斥仙力，需单独开辟一条经脉方可让绿魔大人降临后达到巅峰修为。
- 投入：四片树叶、六粒朦胧丹药、一条红色血丝、三块灰色石头，尽数甩向王林崩溃融入。
- 关键：红色血丝最为贵重，**传闻是仙祖发丝**，世间极难有锋利之物将其斩断；融入血肉后九曲数弯环成首尾相连的循环，遂成王林体内**第二条经脉**。
- 后果：王林只需元神离开**天逆**守护、操控肉身，即可同时施展**吉族神通与仙族神通**——古往今来从未有人做到。

### 4. 种下阴刀 —— 内神之宝
- 需求：绿魔大人复活后需一件可斩开天地的锋利法宝，且必须是**内神之宝**而非外物。
- 炼制：其族无数万年收集天地间**九万多种至阴至柔的材料**，并不惜代价弄来**仙罡二十个九洲镇压之灵各一丝魂**，合炼成一柄阴刀。
- 潜力：此刀尚未经历**仙罡灵劫**，渡劫成功即为足以让大天尊心动的**灭级之宝**。
- 载体：此级别法宝无任何储物空间可容纳，唯有与身体的一部分融合；老者以**王林右手手骨为根**种下阴刀。
- 结果：寒雾涌入王林右臂急速凝聚，右手转黑并覆万年玄冰般的黑色冰霜；咔的一声，一把**九尺长刀**自其掌心血肉内长出。刀形如一条弯弯的脊骨，触目惊心。老者断言此刀从此将名扬仙罡大陆。

## 三、要点与伏笔
- 绿袍老者全程神色疯狂、双目红芒，倾族藏而无丝毫心痛，其目的只有一个：把王林肉身改造成绿魔蝎降临后的完美载体。
- 这场造化之豪奢，连以定力著称的王林都被震撼；且文中明言“这一切还远远没有结束”，老者一族的准备不止于此。
- 客观上，被改造的正是王林自己的肉身：韧性、天威、双经脉（仙古神通并施）、右手阴刀，皆成其日后潜在战力。

## 归属说明
本章被改造的肉身为王林之身（其元神在天逆内受守护），故相关身体变化归于【王林】。
