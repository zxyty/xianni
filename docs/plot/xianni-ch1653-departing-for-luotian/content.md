# 第1653章 去往罗天（第一更）

## 一、生死大阵：碎片大陆的覆灭

**阵理**：生死大阵由漩涡衍变而来，凝固后化作「不动转轮」。其威在「不动」——不动则生死不动，若动则生死逆动，转动一圈即是一次生死决断。

- 转轮旋转，轰鸣自域外破空传入被雾气笼罩的星域，浑厚威压向已进入封阵缺口一半的碎片大陆镇压而下。
- 此镇压「镇的是生，压的是死」，在生死之间磨灭一切灵魂与元神，崩溃一切有形无形之物。
- 大陆边缘瞬间裂缝纵横、崩溃向内急速蔓延；大陆上界外修士面色苍白喷血，修为弱者肉身崩溃、元神被封于头颅抛起；大陆中心已具雏形的庞大庙宇通体裂缝，轰然崩塌成废墟。

## 二、第三步老者的困兽之斗与死亡

- 庙宇之上的老者嘴角溢血、眼露恐惧，掐诀催出黑风化作巨大森森之口，直扑不动转轮意图吞噬。其自知无法逃遁，左右是死，故拼死一搏——若侥幸得胜，既解生死劫难又可名声大振。
- 王林视之为「不自量力」：此阵岂是他配吞。冷哼间转轮再转一圈。
- 黑风巨口膨胀至数十万丈，勉强超过生死大阵，一口吞入；旋即口内爆发出蕴含生死与镇压的惊天之力，惨叫连连，黑雾巨口四分五裂倒卷，转轮再现。
- 老者被大力冲入身体，喷血坠地，砸入已成废墟的庙宇，地面现千丈深坑，全身伤裂、神色萎靡、恐惧到极限。
- 王林大袖一甩、抬手一指，转轮压下**九寸**——「九为劫，压下天崩地裂」。老者再喷鲜血，无力挣脱，再度被轰入大地。
- 王林闭目挥手，留下一句「**云海杀戮，结束了**」，转轮再沉**九寸**。老者发出最后惨叫，肉身爆开，血肉四溅，头颅内封印着元神与魂被冲击卷走升空。
- 老者一死，大陆上盘膝死守的高深界外修士全身崩溃而亡；大陆彻底四分五裂，碎块再碎为碎末，连延伸入封阵缺口的那一半也一同化为尘埃，永恒消失于星空。
- 王林睁眼之刻，数千头颅（含第三步老者的头颅）呼啸而来，并入其身后数万头颅之列。

## 三、因果阵成：双转轮加身

- 王林转身走向最终目的地——罗天。身后数万头颅凄厉惨叫传遍星空，身下生死不动转轮随行。
- 一声「**因果阵，成**」，数万头颅升空急旋成巨大漩涡；王林右手五指张开下按，漩涡加速、头颅连成一片已不可辨相貌；缓缓握拳，天地轰鸣中漩涡凝固，化作**因果不动转轮**，浮于其上方。
- 此时王林身体上下共有两个巨大转轮，人在中间，如掌握生死、因果的仙神，一头飞舞白发透出杀戮至极的冰寒。
- 身影一晃，携双轮踏入罗天。

## 四、罗天战场现状

### 界内一方
- 由四大星域挑选的**九百九十九个修真星**组成大阵，是界内最后的根基，被数十万界外修士层层包围。
- 残存界内之修神色悲壮，已认知到「这一战，界内败了」。
- 本章又一颗修真星承受不住轰然爆开：大陆碎裂、海水气化、星体分裂，**星魂烟消云散**。
- 数月来界外攻击已持续多次，虽未破阵，却令修真星大量崩溃——**至今日已不足三百个**。
- 界内曾多次尝试以毁灭星阵为代价与界外同归于尽，均被空玄大能压制，只能眼睁睁看星阵被一点点摧毁。

### 界外一方
- **出手攻阵者**：皆为空玄以下的第三步大能。
- **五名空玄大能**（不出手，浮于四周冷眼旁观，专职阻止界内毁星同灭）：
  - 仙妃三人，其中两人曾参与王林生死大劫一战，另一人身穿紫衣、状如贵妇；
  - 老妪一人、黑衣老者一人，皆为当年生死大劫中与王林交手者。
  - 当年生死大劫中出现之人，除掌尊、已死的中年文士与虚神天尊外，尽数聚于此。
- **七名领队**：修为自空涅至空灵不等，率界外修士自七个方向轰击星阵，轰鸣传遍罗天。
- **云落大司本尊**：相貌极美，立于界外修士环绕之中，冷视星阵，神色隐含忧虑；其分身此前已死。

## 五、要点判断
- 云海战场至此清空（「云海杀戮，结束了」），战线正式转移至罗天，罗天为本次界内界外之战的决战之处。
- 王林状态：白发，同时掌控生死、因果两大不动转轮，身后蓄有数万头颅（元神/魂被封）作为阵基。
- 界内颓势明显：星阵折损逾七成，空玄级战力全在界外一方。
