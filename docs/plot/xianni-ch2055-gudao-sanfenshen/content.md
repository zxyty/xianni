# 第2055章 古道三分神！

## 一、古祖遗言（回旋于王林脑海）

祖庙中的声音自称「吉」：

- 「我是吉，诞生在天地出现之前，存活在宇宙初开之前」；
- 在其之前仍有仙出现，仙欲奴役他，故他要毁灭此仙；
- 「若我失败，则我之后人，世世代代与仙为敌，世世代代，誓让天下无仙」；
- 「九滴魂血，送我三子，你等统领我古族万民，在九曲三相齐出之曰，等待我的轮回，等待我的传承者出现」。

此声音在王林脑海回旋整整五十年：起初若隐若现如喃呢，渐渐强烈如咆哮，至本章已似有人在耳边不断嘶吼，其中的逆天与不甘令王林全身热血沸腾燃烧。

## 二、王林现状：五十年枯坐

- 王林盘膝坐于始古皇城祖庙内，肉身枯萎如干尸，一身白衣松垮如披。
- 血液燃烧中血肉如被炼化般不断枯萎，已如残骸。
- 但毫无虚弱感，反隐含惊人生机与力量：待身躯恢复如初入祖庙时，其肉身之力将达到极恐怖的程度。

## 三、设定梳理：古族三损七劫 · 第三损

第三损含三劫：

1. **古脉苍穹血**（前劫）
2. **古道三分神**（三损第二劫，本章正在渡）
3. **古祖之赐**（第三劫）

渡劫门槛与场地：
- 具备**二十七星成圣**的古族三脉族人，一生中大都经历三损七劫；
- 第三损的**最后两劫必须在各族祖庙内**方可到来与渡过；
- 因个体不同，所获提升与造化各异。

### 古道三分神机制

- **不是**把元神分成三份，而是**三次分裂 + 每次分裂后的融合**。
- 每次分裂如同散功，需以莫大毅力慢慢融合；每次融合后元神与身躯突飞猛进。
- 三次全部完成 = 成功渡过三损第二劫。
- 此劫**本身不出现死亡**，重点在于**承受分裂的时间**：时间越久分裂越彻底，好处越大，痛苦也越大。
- 分神过程中**随时可以选择融合**。
- 风险：若分裂彻底且完全，融合会变得艰难，甚至出现**无法融合**的现象，此时才会有死亡发生。
- 现实选择：常人无法承受此痛，皇族亦坚持不久，大都在半途选择融合；有大毅力者**往往只在第一次分神时赌一次**，第二次也拿命赌者极为罕见，**第三次仍赌者绝少且几乎全部死亡**。
- 传闻：无数万年来，唯有**仙罡第一强·古道大天尊**在第三次中选择了完全分裂，并最终成功。

### 第三劫「古祖之赐」

- 实际已不能称之为劫难，而是渡过三损六劫后冥冥中获得的**古祖赏赐**。
- 可能形式：一丝记忆 / 一种不全的神通 / 极为精纯的古祖之血 / （传闻中）一丝可能是**魂血**。
- 「魂血」一说大都被认为是后人为希望而杜撰；据说连古道大天尊在古祖之赐中也未获得魂血，只是所获之物极为不凡，无人知晓是什么。

## 四、王林的抉择

- 五十年枯坐后，在计都皇子于庙前一拜离去之后，王林感受到三损第二劫来临的迹象：耳边咆哮剧烈、血液沸腾燃烧、燥热弥漫全身、元神渐现碎裂痕迹。
- 目的明确：**能否获得魂血、能否让李慕婉的身躯进入太古神境，就看这一次祖庙渡劫**。
- 决断：「想要获得魂血，在这三损第二劫中，就要尽最大的忍耐，去看看此劫的尽头在何方」——即选择第一次分神的彻底分裂路线。
- 剧痛降临，但对王林的毅力而言尚可承受，且这仅是开始。

## 五、异象与外界反应

- 渡劫一瞬，祖庙古祖雕像身躯外凭空浮现一圈圈环形波纹，向八方扩散，几乎笼罩整个始古皇城。
- 始古一脉族人辨识：
  - 「古祖像出光环之芒，这是有人在渡损劫」；
  - **九道光环 = 三损第二劫古道三分神的第一次分神**；若为第二次分神，则应出现**十八道光环**；
  - 疑惑：祖庙渡劫从不为个人而开，惯例由皇族组织、待人数够了统一开启一次，而这几年并未听说此事；
  - 预期：以往渡劫者大都数日后就结束。
- **始古皇尊**在皇宫中凝望：「五十年，他终于开始了第一次分神」，并回忆始吉一脉曾有人在第一次分神时**用了一年时间达到圆满**，不知王林能否如此。
- **计都**立于居所窗旁与妻子同望，喃喃「义父」，妻子拉住他的手柔和相看。

## 六、两位护法

### 宋天（皇城外原始山）

- 一身青衣出关，判断「以他的修为，第一次分神必定是会选择彻底分裂，如此一来，时间不会短」。
- 自陈因果：当年王林闭关时，宋天曾**两次暗中出手**；虽事后认可计都为皇尊，但毕竟冒犯在先，而王林来临后并未追寻此事。
- 遂瞬移至祖庙外，**背对祖庙盘膝而坐**，神念缭绕八方：「祖庙方圆千丈内，禁止任何人踏入，违者，死」。
- 与王林神念对答：王林「多谢」；宋天「不用，宋某只为你护法第一次分裂，化去当年出手之举。」

### 玄罗（师尊）

- 王林在分神不适中仍感应到天幕上有熟悉身影凝望此地，喃喃「师尊」。
- 玄罗自道古一脉专程赶来，隐隐感受到祖庙内属于王林的气息，面带微笑、目露柔和：「你已经比师尊强了，师尊唯一能做的，就是在你如今分神虚弱之时，来为你护法。」

## 七、看点与伏笔

- 王林走的是「几乎无人敢走」的彻底分裂路线，赌注是魂血与李慕婉入太古神境。
- 古祖「吉」的誓仙之言与「九滴魂血送三子」「等待我的轮回、我的传承者」构成古族命运主线，与王林的传承者身份呼应。
- 古道大天尊的先例（第三次完全分裂成功、古祖之赐所得之物无人知晓）为王林后续路径立标杆。
- 宋天以护法偿还旧日冒犯之因果；玄罗以师尊身份护法，师徒强弱已然倒转。
