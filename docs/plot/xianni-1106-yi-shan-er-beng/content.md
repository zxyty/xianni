# 第八卷 联盟隐秘 第1106章 一山二崩

## 一、山崩仙术成形

- 王林话音出口，星空中环绕其身的无数虚幻火山骤然相互重叠、融合为一。
- 融合结果：王林前方出现一座高**一千多丈**的山峰，与真实之物几乎没有区别，磅礴威压弥漫天地。
- 山峰出现的刹那，星空剧烈波纹如颤抖，敌方以碎石组成的阵法（传送阵）中大量碎石轰然崩溃。

## 二、第一波：山崩

王林喝出「山崩」，山体震动、山顶爆开，多重杀伐同时爆发：

| 手段 | 效果 |
| --- | --- |
| 飞射巨石 | 云海星域修士肉身被砸成碎泥 |
| 暗红色火焰 | 高温可抹灭一切生灵，化作散发黑烟的巨石砸落，火焰入体直接炼化元神 |
| 黑烟火毒粉尘 | 一名半只脚已踏入阵法欲逃者临身即化黑气崩溃，元神被生生烧死 |
| 七彩天雷 | 受黑烟火焰冲击提前轰鸣，修为不足者被雷鸣震碎元神，口喷鲜血、道消神陨 |
| 岩浆大浪 | 七八名修士逃离不及：二人死于火毒、一人被巨石砸成血水蒸发、最后四人被岩浆拍中，只剩保持前冲姿势的漆黑骨架，半息后碎裂成灰 |

- 修为略高者未死于第一波岩浆，却无法脱离，施展神通法宝仍在岩浆中挣扎，死状最为痛苦。

## 三、蚊兽复仇

- 蚊王借极快速度返回，飞入山崩神通范围——此地在山崩之术下已失去一切封印之力，十余只蚊兽亦不受火焰临近。
- 蚊兽群随蚊王起飞，组成蚊兽大军。文中点明「王林的蚊兽最是记仇」。
- 首个目标：此前引走蚊兽的三人之一、腿部受伤的黄衣青年，被蚊兽群撕碎身体。
- 蚊群尝到血腥后更加疯狂，继续寻另外两人复仇。

## 四、第一崩与阵法崩塌

- 王林双手上推，低喝「山，第一崩」。
- 山顶碎石滚落融入岩浆，四周岩浆冲天而起，形成弥漫星空的冲击，残余修士触之即化黑灰。
- 已然残破的碎石阵法承受不住毁天灭地之力，寸寸碎裂、全部崩塌，万丈之光穿透四散。
- 冲得最快、只剩元神的紫衣老者绝望停顿，被燃烧巨石砸中，元神燃烧；退后时又遭火毒粉尘风暴横扫，冲出后元神黯淡、其上生出如蛤蟆皮般布满火毒的脓包，内部亦有火焰燃烧。

## 五、定身术 + 昆极鞭：镇压自爆

1. 老者怒吼「老夫即便是死，也要与你同归于尽」，点燃心神自爆，天地元力狂暴涌向王林。
2. 王林抬右手一指，体内**仙力**顺右手散出，一字「定」——定身术令老者元神在星空中一顿。
3. 老者修为高于王林，施术同时王林体内**火元**运转以压下反噬。
4. 右手前挥，融入其**道念**中的**昆极鞭**幻化而出，如游龙一抽，「啪」一声将老者将要自爆的气息直接消散。
5. 昆极鞭连抽、一卷将老者元神拉至身边，王林抓住后抛入瞬间出现的**储物空间裂缝**，如被吞噬一般。
6. 全程行云流水，远处另一个肉身尚在的紫衣老者见状身子一颤，转身就逃。

## 六、第二崩

- 王林身形一晃追去，右手指向上空低喝「第二崩」。
- 山峰真正崩溃：不但山体崩溃，连王林意念与仙力凝聚而成的**山魂**也随之崩溃，化作无数燃烧碎石坍塌，岩浆与火毒之粉尽数喷出遮盖四周星空。
- 王林右手一挥，碎裂的燃烧碎石、岩浆、火毒粉尘化作一片**燃烧的长河**环绕其身；此刻的王林一头白发飘摇、容颜冰冷充满萧杀，如顶天立地的神人。

## 七、设定要点

- **一山二崩**＝王林此刻明悟山崩仙术后的**极限**。
- 对照：**清水**（清水仙君）的山崩为**六山十二崩**，可毁灭一界；王林做不到毁界，但毁灭这些修士绰绰有余。
- **天劫的底气**：若无天劫，王林绝不会独自一人前来；有天劫在身，别说这两个老者只是**净涅后期**，即便对手是**碎涅**，王林也敢以天劫一战。

## 八、势力与伤亡

- 受害方：**云海星域**修士群体（含两名紫衣老者及其门下弟子），起因是贪心打巨蚊兽的主意——其中一名紫衣老者悔恨门下三个弟子掠来巨蚊兽为自己惹下大祸。
- 王林态度：目中一片平静，毫无怜悯——「敢打蚊兽的主意，就要付出代价」。
- 结果：山崩之力下「没有伤，唯有死亡一片」。
