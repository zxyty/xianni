# 第八卷 联盟隐秘 · 第908章 离去

## 一、朱雀星密室：符族本源之力的考验通过

- 密室波纹闪烁，老道走出，特别留意王林眉心，平淡确认：“看到了”。王林起身抱拳答“看到了一些画面”。
- 老道抬手抓取火团，火团光亮大闪后被其握于手中。
- **火团来历**：符族一位达大圆满的**金叶符士**的**本源之力**所化。
  - 感悟此本源之力对修为有莫大好处。
  - 这是**四圣宗内朱雀一脉内门弟子必经的考验**；有感悟者即成内门弟子。
- 老道从火团中吸走一丝力量，面色略红润，许久恢复正常。
- 老道大袖一甩卷走王林，将其送出密室，并留话：“去做你该做的事情，这朱雀星，有老夫在，无人可以动其分毫。”
- **老道独白（关键伏笔）**：目露奇芒盯着脚下，“符族，这最后一层，老夫一定会打开”。

## 二、王林的判断与离意

王林现身于朱雀星一处高山之顶，面色略显苍白，望向仙遗族方向沉默：

1. 老道修为高深，**至少与炎雷子同级，甚至更强**，常年驻守朱雀星必有目的。
2. 可以肯定：**仙遗族的后两层是其目的之一**；未知其是否知晓**古神之地**所在。
3. 此人身份诡异，但确属**四圣宗朱雀一脉**；先前话语颇有深意，线索太少无法推测。
4. 朱雀星琐事已了，且此地尚有**托森**存在，不可久留 → 决定离去。

王林神识散开，向塔山等人传出神念，随即长叹，直冲天际。

## 四、以巨魔族为坐骑：星空启程

- 星空汇合：塔山融入王林身后虚影；大头童子略有恢复，恭敬侍立，一望即知是仆从身份。
- **雷吉**不待吩咐，砰砰巨响中化作**数百丈巨人**，磅礴威压笼罩星空，跪地道：“主人，雷吉心甘情愿，成为您的坐骑。”
- **设定·巨魔族坐骑**：巨魔族被大神通修士喜作坐骑，因其
  1. 强悍肉身；2. 磅礴威压（堪比一切妖兽）；3. 诡异的天赋神通。
- 雷吉背部近百丈、青色皮肤且平坦；王林盘膝坐于其上，大头童子随后。雷吉四肢前冲，速度虽不及**雷兽**但亦不慢，带起风雷阵阵。
- **大头童子的星域对比感受**：罗天星域没有这般数百丈巨人，更不用说以其为坐骑；他自问若见他人乘此坐骑必起杀机夺之，故断定“敢坐在这种坐骑上的修士，绝非寻常之人”。

## 五、遭遇战：修真联盟杀域界·杀侍于非

### 来敌形象
- 脚踏满布坑洼、远看如蜂窝的巨大石块，速度极快，呼啸如音爆，摩擦生出红色火焰。
- 一身红衣，年约三十许；身前环绕**七把赤红之剑**，煞气浓郁带血腥味，凝成蟒状凶兽张口咆哮。
- 自报身份：“**修真联盟杀域界，杀侍于非**，来去你**许木**人头”。（“许木”为王林在联盟所用之名）

### 交战过程
1. 雷吉欲避；**大头童子**抢先出手，运转**仙元**化仙气风浪，掐诀推出絮状仙气如柳丝迎击石块。
2. 于非放出第一道血剑，剑上涌红雾**化作与本人一模一样的分身**，持七道血光缠住大头童子，双方神通对轰、一时不分胜负。
3. 塔山自王林身后虚影走出，右拳轰出；于非第二道剑光化出第二个分身迎击塔山。
4. **王林判定**：分身为**窥涅初期**，本体为**窥涅中期**。
5. 王林于雷吉背上抬手，无尽雷光弥漫，雷霆凝成雷线，四周数万里刹那化作**雷之地狱**。
6. 于非停在王林百丈外，寒笑称赞：“不愧是**罗天星域正品雷仙**，这**雷仙**封号，你的确当得。”
7. 于非挥手，余下**五道血光飞剑**分五方散开，各化一个分身；**五分身 + 三十五把赤红飞剑**在其五十丈外结成包围。所有雷霆被飞剑吸引却只能在外盘旋，**无一道能进入五十丈内**。
8. 于非摇头失望：“你，就只有这些实力”“若你神通止于此，那么今日，你逃不出于某之手”。
9. 王林眉心浮现漩涡，**太古雷龙元神**冲出，向天咆哮——战斗升级，本章止于此。

## 六、要点与伏笔

- **符族最后一层**：老道明言必要打开，与仙遗族后两层、古神之地共同构成朱雀星未解线索。
- **托森**仍在朱雀星，是王林不宜久留的直接原因。
- **雷仙封号**已在联盟星域外流传，成为敌人锁定王林（许木）的标识。
- **杀域界杀侍**制度：修真联盟内部存在专司刺杀的“杀域界”，成员称“杀侍”。
- 于非的血剑分身之术：七剑各可化分身，分身修为低本体一阶（初期 vs 中期），飞剑阵可隔绝雷法。
