# 第七卷 名震罗天 第843章 回青灵星（第二更）

## 一、望月战场余波（王林离场后）

- 王林身影消失刹那，无数触手自虚无伸出缠住传送阵，吞噬之下阵法当场崩溃。
- 炎雷子借烈云子五人阻碍之机，双臂前缩成漩涡状，低喝“封”，驱动无数庞大仙界碎片从上下左右疯狂笼罩望月。
- 望月怒吼冲撞，尤其对上空炎雷子的一丝危机感几近发狂。
- 忽然望月全身一震，停止一切行动，双目露出极强惊惧，直勾勾看向前方崩溃的星空。
- **虚幻之人登场**：崩溃星空中寒风吹袭，走出一名全身极为模糊、看不清样貌的男子，虚幻之身从容一步步自虚无走出。
  - 重伤的烈云子等五人面色瞬变，即便以烈云子的狂傲也心中掀起巨浪，眼露极为恭敬之态：“是他”“炎雷子居然把他请来”。
  - 炎雷子眼中露出狂喜。
  - 该虚影向望月走出一步，庞大如望月竟出现颤抖，仿佛对方有让它惧怕的气息，望月缓缓退后。

## 二、王林脱身与对古神幼子的权衡

王林于距望月数百万里外星空的波纹中一跃而出，回头沉吟：

- 判断望月剧变必有原因，或是有人对其发起进攻。
- 望月体内的**古神幼子**曾让他带“可承受其传承者”进入；但**本尊远在联盟星域**，无法一试。
- 疑虑：古神幼子未必诚心传承，也可能是施展类似修士**夺舍**的神通——此事需慎重，绝不能鲁莽。
- 既已离开望月，短时间内当无人可察其踪迹。随后化作流星，脚下泛起波纹，身影融入天地消失。

## 三、回归青灵星

- **方位**：青灵星在**罗天北域**，与望月所在几乎两极分化、极为遥远。
- 王林现身青灵星外，望着熟悉的修真星感慨：“终于，回来了”。
- 临近时星上涌出数股带敌意的强大气息与神识锁定他，认出身份后立刻消散。
- **仙选族**十多人由**先祖老者**带头瞬移而来，老者激动称呼“恩公”。
  - 老者回报：一路顺利；途中听闻罗天星域有一**姚姓修真家族**正对恩公展开追杀。
  - 王林摆手称此事已过莫要再提，令其在青灵星好好居住、做好防护，自己要闭关数月。

## 四、横云峰洞府闭关

- 王林瞬移至**横云峰**，洞府与离开时一模一样、毫无变化。
- 进入洞府后开启四周阵法，**横云山万里内全部封锁**，盘膝吐纳。
- 数个时辰后深夜，王林睁眼吐出浊气：自**雷之仙界**离开后一路疲惫，即便在望月体内也只是勉强放松；此刻在自己的修真星上才彻底放松。
- 关键判断：“那姚家的追杀，不可能停止，留给我的时间，不多”。

### 祭炼大鼎

- 自储物袋取出**大鼎**，其上弥漫沧桑气息。
- 张口吐出**元神精气**弥漫大鼎，开始祭炼；祭炼时间越长，威力越大，但眼下仍需好好研究。
- 一吸之下大鼎缩小化作长虹，被王林吞入口中。

### 塔山疗伤

- 王林身后虚影一晃，**塔山**走出，身受重伤、神色黯淡，盘膝坐于一旁，在王林**心念操控**下自我疗伤。

## 五、抽取姚冰云元力

### 封印状态

| 层次 | 手段 |
| --- | --- |
| 体内 | **昆极鞭**环绕 |
| 体外 | **尊魂幡**包裹 |
| 最外 | 数十万**金色符文封印** |

- 王林掐诀一指，金色符文封印升起弥漫四周，洞府染成一片金色；再虚空一抓，大片黑雾（尊魂幡）自其身上泌出，露出姚冰云娇躯。
- 姚冰云衣衫多处破损、双目紧闭、面如死灰，生机仿佛随时断绝；体内仍有庞大元力，但处于**分离状态，无法与元神融合**。

### 王林的处置

- 盘算：“把此女炼成**仙卫**，是一选择，在这之前，我却是要借她之力”。
- 手法：双指成剑点其眉心 → 自身元力顺指进入其体内旋转成漩涡 → 吸收其被分离的元力使漩涡渐大 → 将失控之际猛地一吸。
- 姚冰云身躯剧震、残衣飘散，漩涡自其**七窍**透出，浓郁天地元力弥漫四周，被王林张口吞入化作烟丝。
- 结果：元力入体，王林双目明亮、面色红润，元神运转迅速融合壮大。

### 一夜之后

- 元神几乎不停顿地疯狂吞噬融合，天亮初阳落下时，**王林元神伤势彻底恢复，且因炼化姚冰云元力更为精进**。
- 吐出灰色浊气后，王林再次点指其眉心，继续第二轮抽取。
- 目标：“把此女全身元力都吸收一空……只需意境感悟，就可真正的踏入进第二步，达到**窥涅**”。

## 六、要点与伏笔

1. 炎雷子请来的神秘虚幻男子，连烈云子等人都极为恭敬、望月都畏惧退让——身份未明，为后续大伏笔。
2. 古神幼子的“传承”真伪未定，王林怀疑其为夺舍，暂时搁置。
3. 姚家追杀持续中，王林闭关时间有限。
4. 姚冰云的两种用途：短期作元力来源，长期或炼为仙卫。
5. 王林修为处于冲击“第二步·窥涅”的门槛，尚差意境感悟。
