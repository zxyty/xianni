# 第八卷 联盟隐秘 第953章 钗子

## 一、清水极境的碾压
- 紫发男子（杀域界界主）面色苍白、嘴角带血，眼露震惊——已在紫雾中吃了大亏。
- 一道红色闪电自天空紫雾降临，不冲界主，直取**神魔子**：极境之下神魔子毫无闪躲资格，闪电穿胸而过，双目暗淡、肉身崩溃。文中评其为净涅修士中死得最痛快者之一，至意识消散仍郁郁缭绕。
- 该闪电不停顿，四周横扫游走一圈，砰砰之声中四周绝大部分修士肉身崩溃。此即**清水极境之力**。
- 王林原已准备打开第三目施展本源之力应对神魔子，见清水相助，遂改扑向前方的**幻虚子**。

## 二、紫雾收拢与钗子现身
- 天空紫雾急剧收缩，化作拳头大小雾球飘于清水掌心。
- 清水身边另有一支**紫色雕凤钗子**徘徊；他望向钗子目光柔和，转看下方杀域界修士时只余无尽冷漠。
- 清水宣言：「我清水要屠之地，绝不会留任何活口」「把我留下陪伴亡妻的遗物作为法宝，你等，全部都该死」——屠界动机就此点明。

## 三、界主逃遁失败
- 紫发男子右臂掐诀虚空一指，整条右臂崩溃化作血肉旋转，生生撕开一道空间缝隙欲钻入。
- 山崩之力冲击下裂缝立刻崩溃瓦解，其面色惨白急退。
- 自评：**碎涅初期**修为，施展了残破的**次空涅**法宝仍无法对抗清水，只想速逃。
- 自述短板：杀域界内只有他一名碎涅修士，净涅修士绝大部分去了**联盟总部**，凑不齐协助施展**九十九剑之阵**之力；且判断即便施展也难抗此神通。

## 四、仙术·山崩（三崩）
1. **起势**：一指之下，杀域界大地颤抖，凭空出现六座高两千余丈巨峰，磅礴威压弥漫；六峰一晃**合六为一**，与真山无异。
2. **喷发**：山顶喷黑烟，暗红色火焰随之喷洒——高温可抹灭一切生灵，火焰化作散黑烟的巨石从天砸落；剧毒粉尘遮天蔽日；岩浆如波涛蔓延，内蕴天地之力，摧毁万物。修为不足者被毒尘临身，惨叫枯萎化虚无；挣扎于岩浆者虽施神通法宝亦难逃。
3. **「山，第一崩」**：火焰与岩浆沸腾拔地冲天，轰然崩溃化作冲击弥漫全界，十余修士被环身化黑灰。
4. **「第二崩」**：全界剧震，山峰顶部轰然崩溃，更多岩浆、火焰、粉尘喷出。
5. **「第三崩」**：山峰真正崩溃，碎石四散，火焰彻底覆盖天空；岩浆如炎海占据所有大地。天空只有火焰，大地弥漫岩浆，中间是浓浓剧毒粉尘。
- **结果**：除紫发男子与幻虚子外，杀域界一切修士全部灭亡；幻虚子亦元力涣散、骇然至极；所有建筑全部融化。王林呆望此幕，感慨「这就是仙术山崩」。

## 五、王林的收获
- 幻虚子面色苍白放弃斗法急退，见王林紧追不舍，暗骂后将身边的**九剑合一**向后抛出，欲以此撇开王林（他知王林在意此九剑）。
- 王林放弃追击，右手虚空一抓，把九把剑尽数抓入手中，九剑急剧挣扎。
- 清水大袖一甩，地面岩浆中飞出**八十八道银光**，虚空一抓涅成一团扔给王林：「你既喜欢此物，便送你」。王林抓住银团收入储物袋。

## 六、杀域界的毁灭与分别
- 清水化黑风卷起幻虚子与紫发男子，向前一踏，杀域界迎来最终崩溃。
- 设定披露：**杀域界本就建立在当年仙界的一处裂缝空间内**，空间坍塌后化作无数碎片被虚无吞噬。
- 清水脚下现巨大漩涡，沉入其内，向王林略一点头：「我还有事情要做，**许木**，今曰一别不知何时才会相见，你好自为之。」
- 王林沉默，亦踏入漩涡离开崩溃的杀域界；星空中现身，长叹回望，随后融入虚无，向**天运星**挪移而去。
- 远处：清水平静前行，虚幻子与紫发修士神色没落紧随其后，二人眉心闪烁**仙界独特之印——奴印**（已被清水收为仆从）。

## 七、钗子·含烟（清水回忆）
- 清水手持紫色钗子，目光柔和中蕴含悲伤与思念，喃喃「造化弄人」。
- **清水一生三次落泪**：
  1. 清水国被灭、父母身亡，他以小修士之身九死一生逃离时的悲愤欲绝之泪；
  2. 在**雷仙界**自身癫狂、亲手杀了挚爱之人后清醒时的悔恨之泪；
  3. 本章睹钗思人，眼角落下第三次泪——唤出名字「**含烟**」。
- 钗子来历：清水成为**白凡**弟子的当天，把这支钗子送给了她。
- 真相闪回：亡妻双目黯淡无神，右手一直握着这支钗子，钗尖深深刺入自己心口，鲜血流下。她言：「清水，我不是因你而逝，我，是死在了自己手中……你不要难过，不要一生悲哀，你没有伤害我。」——为不让清醒后的清水悲愤内疚，她在清水癫狂出手的瞬间当面**含笑自绝**，那柔和眷恋的目光与微笑化作让清水清醒的力量。
- 她的遗言期许：「我心目中的夫君，是一个顶天立地的男子，他不会因为一时之过而自弃一生，更不会浑浑噩噩茫然一世，而是会把所有的力量化作一个执着的信念，找出这一切的原因。」
- 清水目露悲哀立誓：「含烟，你放心，我会找出一切的原因。」——为其后续行动线埋下动机（追查雷仙界癫狂之因）。

## 八、要点提示
- 本章「许木」为王林自创化名（承第661/669/711/731/771/821/881章），言行归王林本人。
- 境界序列信息：净涅（神魔子）< 碎涅（紫发界主）< 清水所处之「极境」层级；九十九剑之阵需多名净涅协力方可施展。
- 杀域界至此在世界地图上消亡，其空间母体为「当年仙界的裂缝空间」。
