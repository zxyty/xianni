# 第八卷 联盟隐秘 第890章 大头童子

## 战场与背景
- 地点：朱雀星上空（近罡风层），凡人皇城上方不远处。
- 交战双方：王林（本章以自创化名「许木」行事）VS 大头童子（罗天三十六天罡仙之一）。
- 星外尚有数百罗天修士围观见证，构成王林出手的政治顾虑。

## 交锋过程
1. **血遁被超越**：大头童子喷血化血影后退，血遁无声无息、比闪电快数倍，为其家族最快神通，以自损修行换速、远超瞬移。王林脚踏波纹、身影融入天地，速度更快一分，直接拦在血影之前。
2. **阴阳双鱼掌**：王林右手蕴阴阳双鱼向前一拍，掌落虚空却起音爆风暴，内含道念与元力。神通分出黑白两气——白气穿虚空入体直冲元神，在体内崩溃并引动全身仙元瓦解；黑气环身游走，皮肤瞬间褶皱、生机疯狂流逝。大头童子如流星坠地，降数百丈方止。
3. **仙术·灭灵网**：大头童子暴发磅礴仙力化百丈大网笼罩王林，王林脚下波纹四起、消失无影，避开后现身，双指成剑，数十道斩罗诀合一斩入其喷出的白雾仙气漩涡。
4. **求饶与算计**：大头童子畏惧王林尚未动用的天雷神通，喊「我在这里没杀一人，你何必苦苦相逼」，趁王林停步直冲天际，心中却发誓逃回罗天在联盟的大本营揭露许木身份，要让他在罗天身败名裂、引血神子一般的前辈追杀，并断言其师兄清水也护不住他。
5. **古神大鼎·换位**：王林抬手，体内钟鼎之音回荡，身外幻化古神大鼎虚影，平静吐出「换位」二字，逃遁中的大头童子全身闪烁幽光，身形消散，与王林位置逆转天地。王林步步逼近：「我说了，在我这里，你，跑不掉。」
6. **仙魔术·筋动**：大头童子低吟古怪咒文，阴森符文钻入自身体内，肉身枯萎如骸骨、血肉精华尽聚头颅，头发尽脱，青筋暴起如蚯蚓蠕动。双手点在头颅两侧耳上，狂吼「仙魔术，筋动」，头上青筋冲出皮表化作青中带红的毒蛇，交错延长如肉柱轰向王林。

## 王林的克制与盘算
- **不施大神通的原因（明写）**：其一，大头童子「另有用处」，以王林修为施展大神通杀人容易，却无法做到精确；其二，对方是三十六天罡仙，王林尚未准备与罗天断绝，在朱雀星外数百罗天修士注视下杀天罡仙不智。
- **但以王林的性子，招惹到自己断无放过之理**——他心中「自有两全的想法」，为后文埋伏笔。

## 旁观者与伏笔
- 被大头童子神识震荡的朱雀星修士渐次苏醒，一道道剑光自各门派飞向战场边缘，其中有**周武泰**、**云雀子**。
- 凡人皇城密室中，一名双目黯淡（被大头童子神识所伤）的白发老者挣扎着散开神识观战。密室前方挂枯黄纸画，画中为慈祥老者；画下灵牌刻「王氏一族，先祖王卓之灵」——王林凡人祖脉「王氏一族」在朱雀星的延续，是本章的重要暗线。

## 待解伏笔
- 王林所谓「两全的想法」——既留大头童子之「用处」，又不与罗天决裂。
- 大头童子欲揭穿的「许木」身份，及其提到的师兄「清水」与罗天前辈「血神子」的关系网。
- 王卓灵位与朱雀星王氏一族同王林的血脉牵连。
