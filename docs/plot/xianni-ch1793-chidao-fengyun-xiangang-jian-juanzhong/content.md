# 第1793章 叱咤风云仙罡见（本卷终·第一更）

## 一、海底擒妙音道尊

- 妙音道尊藏于金色海洋海底，神色狰狞而瞳孔收缩，露出恐惧。其声传出，令整片金色海洋掀起滔天大浪并旋成通向海底的巨大漩涡；王林在上，妙音在下，隔漩涡对视。
- 妙音质问：「你已杀了我分身，取了我分神，足以抵消当年之仇，为何还要赶尽杀绝我辈修士……你今日如此对我，来日必定有人如此对你。」
- 妙音自知修为跌落太大，无逃走机会，故未如「九大」那样立即遁逃。九大听闻「投胎」以为是要杀他而骇然欲逃；妙音更了解王林，判断另有其意。
- 王林：「今日王某不杀你，只是送你投胎。」抬手化出巨掌下抓。妙音急问「投胎何处」，王林答「仙罡大陆」，巨掌穿透漩涡将其抓起。
- 妙音闭目放弃反抗，被封印后收入王林储物空间，**与其分神融合为一体**。海面复归平静。

## 二、太古星辰南部·虚神大尊

- **旧怨**：虚神大尊当年欲夺舍王林、亦曾想斩杀王林，全部失败，分身死亡、本尊重伤，此后未再进入界内半步。
- **处境**：沉寂在太古星辰南部一片修真星崩溃后化作无数碎石的死亡之地，盘坐碎石吐纳星空之力、感悟星辰变化，欲坐数千年恢复修为再出重掌星辰；对王林忌惮极深，只要来者不是王林便无所畏惧。
- **对峙**：无形压力降临，碎石崩溃如星辰光环四散。虚神大尊睁眼见白发白衣身影走来，如噩梦，露出绝望，起身抱拳求「你放我一次，可好」，并搬出「此生绝不踏入界内半步」的誓言。
- **王林的理由**：「你不适合存在于这里，我要离开此地去仙罡大陆，已经有很多人决定转世投胎去往仙罡，你也去吧，这样我才会安心。」
- **虚神的反问**：你离开太久，界外太古星辰仍会诞生无数天资之辈，未来可能有比我更让你不放心者，你还能全部杜绝不成？
- **王林的答复（本章核心宣言）**：「我做不到杜绝所有，但可以把界外太古星辰各个宗族，所有第三步修士，全部送去投胎；若不从者，那便杀了。」
- 虚神大尊惨笑「疯了……他逼人投胎，我还能有什么选择」，闭目就缚，被王林大袖卷入储物空间。

## 三、仓獴族·逼人投胎与封印全族

- 仓獴族为太古星辰族落之一，曾参与界内界外之战；族小但有一位第三步老祖，当年见势不妙即退避不出。族地为拥有近百修真星的区域。
- 王林步步轰鸣而至，踏入一颗修真星、冲入罡风层，直上星上最高山峰的大殿；殿内中年男子（老祖）惊骇欲起时，一只右手凭空按其肩，将其死死按住。
- 「王某送你去投胎。」——恐怖之力顺肩涌入，化作无法抵抗的封印，锁其全部心神。
- 出族后，王林于星空挥手放出**数十片古息叶**，旋成模糊旋风扑向仓獴族修真星，**封印星空、封印全族**：「从此之后，封此族修士入星空之力，但凡此族之修，永生修为止步碎涅，永世不得踏入星空。」

## 四、横扫太古星辰的收尾

- 凡存在第三步大能的族落，王林一律照此办理：**逼人投胎、封印全族**；即便没有第三步大能的族落，也全部被封印。
- 后果：太古星辰此后将极难出现第三步大能；此后无数年星空中将没有半个修士，所有太古星辰之修无法离开所在修真星（族落与修真星外皆有王林留下的奇异封印）。
- 动机：临走前为保界内万古平和；不愿把后患都交给蓝梦与留下的南云子等人，要自己解决。
- 王林于界内与界外的阵法旁回望星空，随后踏入阵法，离开太古星辰，返回界内、去往罗天星域。

## 五、罗天星域·洞府大门与离去

- 金色大门绽放夺目金光，门内漆黑如镜；玄罗盘膝坐于门前，见王林走出。
- 王林一拜：「晚辈已经做完了全部，又带来了几人，还望前辈施法，送他们去投胎。」大袖一甩，**八人**幻化而出，神色阴沉、内心不甘却无法反抗。
- 王林道「投胎之后，我等再无任何恩怨，望你们好自为之」，挥手起狂风，卷八人融入漆黑门内。
- 王林辞别：「前辈，晚辈也要离去了，我们仙罡大陆，见。」回望星空后化作长虹冲入洞府大门，瞬息消散。至此，他在洞府界做完了最后一件事。
- 玄罗神色凝重，随之迈入洞府大门。门轰鸣缓闭，**半个时辰后彻底关闭的一刹那，星空深处一道幽光急急而来，钻入将闭的大门内消失**——留作悬念。

## 六、要点与伏笔

1. 「送你投胎」成为王林清场的统一手段：不杀而转世，去处均为**仙罡大陆**，指向下一卷舞台。
2. 太古星辰被制度性降格：第三步大能被清空，全族封印，修为止步**碎涅**，星空断绝。
3. 妙音道尊被收入储物空间并与其分神合一；虚神大尊、仓獴族老祖等同样被收。
4. 玄罗亦入洞府大门，洞府界一方就此收束。
5. **未解**：最后钻入闭合门缝的那道幽光身份不明。
