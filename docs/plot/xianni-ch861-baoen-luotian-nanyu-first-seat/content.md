# 第七卷 名震罗天 第861章 报恩（第三更）

## 一、许木之名震动罗天

场中议论爆发，勾勒出「许木」（实为王林化名）在罗天星域的声望：

- 「在罗天西域屠星的许木」；
- 被姚家倾力追杀，最终却让姚家大败而回；
- **天穹令下仍完好无损的第一人**；
- 姚家因他损失惨重，众多族人被屠；
- 当初参与姚家之战的诸多修真家族至今忐忑，惧其报复。

此名在罗天星域几乎无人不知。

## 二、修为暴露引发的震惊

- **申公虎**：内心复杂，对王林窥涅初期修为大吃一惊，分不清眼前之人是否真如自己所想。
- **战空烈**：战意中熟悉的感觉竟是王林，彻底迷茫，回忆三次相见——
  1. 第一次：问鼎后期；
  2. 第二次：阳实境界；
  3. 第三次（本章）：窥涅初期。
  因而怀疑「他真的没有隐藏修为么」。
- **战芸**及地炎星万里内众多当年被王林带出雷仙界之人激动飞来，躬身拜见，王林略一点头。

## 三、唐家发难

远方白石上盘坐一唐姓老者（后被紫衣老者点名为**唐山**），身边是昏迷中的**唐言枫**。老者目露杀机质问：王林没有资格挑战罗天南域一百零八中的第一，此举等于无视南域所有修士。

其算计：许木虽未杀唐言枫，但重伤使其即便痊愈修为也将大幅退落，此次封仙之争已无半点机会。

## 四、报恩：集体举荐（本章核心）

被王林在雷仙界救出之人接连挺身，皆以「举荐许木前辈拥有参战资格，不知我某家可有这个资格」的句式反问唐山：

1. 罗天南域**陈家**中年修士（首个站出）
2. 罗天南域**赵家**苍老修士
3. 罗天南域**李家**藏蓝衣中年男子
4. **郑家**彩衣少妇
5. **苗家**嫡系黑衣冷漠青年（主星家族之一）

此四/五人此前受家族所阻不能相助，内心愧疚，此刻豁出去站到王林身旁。陈家老祖等家族带头人苦笑闭目、不闻不问（但若有人质疑其家族资格，他们会讨说法）。

随后声浪扩大：

- 地炎星**孟家**、雷云星**百里家**、水冥星**司空家族**、地炎星**周家**、天蓝星**宁家**（主星家族之一）……越来越多修士走出，**全部是当年在王林带领下冲出雷仙界活命之人**。
- **战空烈**代表战家举荐；**申公虎**亦表态举荐。

唐山大惊：小辈不算什么，但其家族长辈竟无一反驳而是闭目默许——这让他第一次对「许木」生出震惊。

## 五、罗天星域实力层级（设定要点）

- 寻常修真家族：**阴阳虚实**境者即可称一族老祖；
- **窥涅**修士唯主星之上的修真家族才有，且每族至多一人；
- 仅次于姚家的传承仙界级家族（如唐家）才拥有数位真正踏入**第二步**的修士，靠数万年积累，强求不得；
- 唐山本人为唐家第二步四人中**最弱**者，窥涅初期但已至初期巅峰（入窥涅时间远长于王林）。

## 六、紫衣老者定音与「爆」

- 雷仙殿使者三人中始终闭目的**紫衣老者**开口：「许木，有资格。」唐山面色彻底一变，不敢反驳，冷哼卷起唐言枫离去，临走以杀机瞪视王林。
- 王林平静吐出一字：「**爆**」——唐言枫身子一震，化作无数血肉崩溃，元神当场碎灭，老者毫无救援机会。
- 伏笔：王林**早在之前**便在唐言枫体内留下一道隐藏极深的力量，非修为高出一筹、达**窥涅中期**者不能短时发现；既然唐家生出杀机，便毫不犹豫引爆。
- 王林警告：「**你唐家，莫要成为第二个姚族**。」
- 唐山暴怒扑来，紫衣老者首次睁眼冷哼：「封号其间，不允许私斗，唐山，带着你唐家族人，给老夫滚。待结束了封号之后，你若要寻仇，可学那姚家自行解决。」唐山生生止步，怨毒离去。

## 七、南域第一之争

- 王林感应紫衣老者体内极强元力波动，看不出具体修为，推断**逊于血祖**，即便不是**净涅期**，也一定是**窥涅后期巅峰**。
- 紫衣老者问王林是否要南域一百零八资格的第一，王林果断答「正是」，战意涌现。老者露出赞赏：若此地无人挑战，便定他为南域资格第一人。
- 老者目光扫过南域赤红之石上的修士，最终落在一人身上：**黑衣、约四十许岁、鬓角略白、身前石上插着九把刀**；此人自始沉默打坐，唯在王林露出窥涅初期修为后抬头，眼中闪过一丝微不可查的战意。
- 但抢先出声挑战的是**战空烈**：深吸口气，眼中复杂迷茫却带战意，抱拳恭敬道「战空烈，向许木前辈挑战」，并加码：
  > 「若许木前辈让战某心服，战空烈愿送出**道念**，奉前辈为**尊主**，**征战联盟**。」
- 此言掀起弥天大浪，章末悬念。

## 八、因果与伏线

- **恩**：雷仙界救命之恩在本章集中兑现为政治资本，直接压过唐家的阻挠——「报恩」题眼。
- **仇**：唐言枫之死使唐家与王林结下死仇（唐山明言封号后寻仇），姚家之后的第二条家族仇线。
- **悬念**：九把刀黑衣人未出手；战空烈的「道念/尊主/征战联盟」之诺指向后续联盟战事。

## 备注（世界状态须知遵循）

- 本章「许木」即**王林**（自第661/669/711/731/771章沿用的化名，疑为自创化名而非冒用他人姓名），全部言行归属王林。
- 唐言枫已于第800章被记为死亡，本章为其死亡的正式落实（引爆致形神俱灭）。
