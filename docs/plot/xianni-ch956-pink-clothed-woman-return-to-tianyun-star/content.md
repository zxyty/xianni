# 第八卷 联盟隐秘 · 第956章 粉衣女子

## 一、五彩蝴蝶反卷自爆之力

- 五彩蝴蝶美丽，扇翅时落下五彩之粉；其旁跟随一只**血燕**——原为当年**血神子**之物，被五彩蝴蝶所摄。
- 三次扇翅，层层递进：
  1. 左翅一扇 → 前方横扫而来的自爆之力冲击一颤；
  2. 左翅再扇 → **规则之力**弥漫，毁灭冲击蓦然倒卷，如被无形大手拨弄而倒退；
  3. 第三次扇动 → 凭空多出**三只蝴蝶**同时闪翅，冲击以不可思议之速倒卷，轰向急速收缩的漩涡。
- 在漩涡将消的刹那，自爆之力夹杂五彩蝴蝶那**一丝规则的改变**彻底冲入漩涡内；漩涡中传出一声惨叫，随即消失。

## 二、魂海黑楼：阴沉老者救下蓝衫青年

- 场景切至**联盟星域**内一处不为外人所知的**魂海**：深处漂浮大片陆地，其中一处陆地阁楼四起，正中一座**通体黑色的巨大阁楼**。
- 黑楼外虚无中骤现漩涡，砰砰之声与大片血雾中，**蓝衫青年**的元神双目紧闭、随时可崩溃地飞出。
- 阁楼大门蓦开，一名**面色极为阴沉的老者**一步踏出，速度极快，直抓元神。
- 青年勉强睁眼道「**爷爷，救我**」，随即昏迷，元神渐散，最终未崩溃但极为虚弱。

### 王林的判断
- 五彩蝶之力落入漩涡攻击青年的刹那，青年身上有**一道乌光**闪烁，化解了大半之力；乌光终究崩溃，但青年只是**重伤未死**。
- 结论：「**保命法宝**」。

## 三、为雷吉清除残魂

- 王林转身走向**雷吉**，看其身上各骨缝处的**绿芒**，抬右手一一按去；每一次双指落下，绿芒即化作**一道残魂**消散。
- 片刻后绿芒尽除，雷吉松了口大气，看王林的目光**充满恭敬**。

## 四、十日星空行：重返天运星前的准备

- 雷吉化身坐骑向前飞奔，王林盘膝其上，旁为**疗伤中的大头**；距天运星越来越近。
- 十天后，前方不远即是**七级修真国天运星**的范围。
- 这十天王林除思索天运星一行如何行事外，更多在琢磨当日**罗天与联盟大战**时**玄宝上人**施展**四彩蝴蝶**的手诀——当日目不转睛全部记下，十日多次尝试**仍无任何感觉**。
- 分兵安排（对大头与雷吉）：
  - 在附近寻一处修真星**隐匿等候**；
  - **若我平安**，定会让你二人过去；
  - **若无我的消息**，速速离去。
- 王林一身白衣、黑发飘动，颇有仙风道骨，独自踏入天运星势力范围。

## 五、王林的独白：因果与底牌

### 祸根 = 仙府令牌
- 「此行福祸两半，只是有些事情，是一定要做的。」并判断危机或许并非如所想般难以化解。
- 所有人想要的就是那块**仙府令牌**；当年正因此物 + **血祖之事** + **天运子的算计**，他不得不离开。
- 当年修为太弱毫无自保之力，面对天运子无法抵抗；如今**仍无法抵抗，但想杀他也不那么简单**。

### 三张底牌
1. **眉心第三目**——真正的杀手锏，非法宝与神通。
2. **本源之力**——看过**第二幅战字帖**后多了一丝，「这才是我的保命之术」。
3. **身份缓冲**——与天运子**并未撕破脸面**，名义上仍是**天运宗弟子**；且**酷似黄龙之人**曾说他是**朱雀星之人、四圣宗内朱雀一脉弟子**，此点「很值得琢磨」。

### 眉心异象与赤红印记
- 王林右手不抬、单指一点眉心，眉心之上依次变化：
  **第三目** → **五个古神星点** → **一个虚幻珠子** → 全部消失，只余**一个赤红色印记**，缓缓散出一丝丝火热。
- 发现此印记的前提（两项前缘）：
  - 当初立下大功，获**炎雷子元力灌顶**，使其**只需意境达到便可成为窥涅中期修士**；
  - 获**罗尘的力之传承**，达到**五星王族古神**。

## 六、要点小结

- 敌方新增未解之谜：黑衣阴沉老者（蓝衫青年之「爷爷」）藏身联盟星域隐秘魂海，蓝衫青年重伤未死 → 后患已埋。
- 王林战力构成开始由「法宝神通」转向「本源之力 / 第三目 / 古神传承」体系。
- 主线推进：孤身重返天运星，直面天运子与仙府令牌的旧账。

# 第890章 紫青双霞漫天·天运宗聚首

## 一、朱雀印记的来历推断
- 王林眉心的**朱雀印记**明暗不断，具备**天地炎之力**；神识凝聚其上时，隐约有**凤鸣之声**在心神回荡。
- 王林判断：此物与**朱雀**有关；且自己回朱雀星时尚无此印记。
- 结论（王林推断）：印记**与黄龙掌门有很大关联**。
- 随后王林身形一晃直奔前方而去。

## 二、重返天运星的感慨
- 天运星远远出现在眼中，王林暗叹：当年从朱雀星离开后便直奔此地，被**天运子收为紫系弟子**。
- 「一晃数百年」。
- 实力对照（本章当时自评）：
  - 第一次来此：**婴变修士**；
  - 第二次（现在）：**可与净涅（窥涅）一战**。

## 三、天运宗外的剑之风暴
- 王林望见天运星上金光闪烁，无数剑光交错辉映，密密麻麻，全部凝聚在**天运宗**所在之处。
- 王林从剑光中感受到**凌天候**的气息，沉吟片刻后并未停顿，继续向前飞去。
- 每一道剑光上都立有一名修士，全为**大罗剑宗弟子**。

## 五、前情：潮汐之地与贪狼失踪
- 当年**王林取走令牌**（潮汐之地相关），事后天运子称「今日会有天机显露」。
- 几名老怪曾一同派出**贪狼**寻找王林，结果**再无任何消息传出**，贪狼身上的印记更**消散了大半**。
- **潮汐之地仙府**事关重大；因王林是天运宗之人，老怪们焦急中合力寻找天运子。
- 天运子当年只答一句：**「紫青双霞漫天之曰，你等来我天运宗，可见天机」**。

## 六、天机之日
- 本章清晨，天运星原本晴空碧波，转瞬被**青、紫双霞**弥漫，绚丽映照大地。
- 凌天候立刻带弟子前来，其余知晓当年之事的老怪也纷纷赶到天运宗。
- 天运子**神算之术**在联盟星域威名赫赫，是众人赴约的根本原因。
- 天运子一身白衣立于天运宗广场，身边天运宗弟子神色冰冷（目光多停留在那四名女子身上）。
- 天运子微笑道「**来了**」，目光落向天边；凌天候、三名老怪与村姑美妇立刻有所察觉，全场目光齐聚天边。
- 粉衣女子好奇道：「不知当年名震潮汐，使得天运星所有大神通修士关注的**王林**，是个什么样子」。

## 七、看点与伏笔
- **粉衣女子**被原文特别标注为重要人物，其登场值得追踪。
- 天运子的「天机」预言即将在王林抵达时兑现——王林本人即是天机。
- 朱雀印记与黄龙掌门的关联为后续伏笔。
- 贪狼下落与潮汐之地仙府的秘密仍未揭晓。
