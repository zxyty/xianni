## 一、破围与战后（现场）

- 王林以**不灭指**在身前连点数次，每点一次便消散一些冲击之力；最后食指猛地前斩，在不断崩溃重组下生生撕开一道缺口，一步迈出。
- 横扫之下以此地为中心方圆**数百万里**尽成废墟，尘土如尘暴遮盖大地，轰鸣许久方消。
- 王林白发飘动、衣衫吹打而神色极为平静，显出**第三步空灵中期**大能的一代宗师风姿。

## 二、记忆结晶与查看条件

- 干瘦老者一生的记忆凝为一枚**布满无数细密裂缝的淡金色结晶**。
- 限制：仙人的记忆必须**有血脉仙力之辈**方可翻看，纵是古族、修为更高亦不可，属层次差异（蝼蚁得象之忆亦看不懂）。
- 王林的凭恃：眉心中有**仙人不灭体所化的金色血液**，内蕴仙人血脉之力，精纯程度即便在**仙罡六陆**也极为罕见。金光之下血液幻化而出，王林将结晶按于眉心闭目查看。

## 三、记忆内容：仙罡大陆与九日传说

- 一片**极为广阔**的陌生大陆；记忆主人一生所走最远，相当于界内界外相加，尚不足此大陆万分之一。
- 天空高挂**九个太阳**，散发无尽光芒笼罩大地。
- 传说：九个太阳即**九座天宫**，代表九位至高无上的**大天尊**；连七彩雕像之人也未达此程度。
- 传闻：**九为极限**，若某日出现**第十个太阳**，则仙罡将起**无量量劫**。

## 四、七道宗与七彩仙尊

- 老者生于此大陆，成长后拜入宗派**七道宗**。
- 七道宗宗主是**一对道侣二人**，其中一位即七彩雕像之人，在仙罡大陆被称为**七彩仙尊**（即界内界外统称的**远古仙皇/远古仙尊**）。
- 其修为莫测，开宗立派广收门徒；开宗无数万年历经无数危机，皆被道侣二人一一化解，在该区域威望极高。
- 老者最终成为七彩仙尊的**百卫之一**，为宗内强者，仅次于**朱雀、玄武、青龙、白虎四大战将**，享有极高身份与权力，各类功法丹药可任意取用。

## 五、变故：夜现双日与洞府封死

1. 某夜七道宗外刺目之芒滔天而起，一股连老者也要颤抖的威压弥漫大地。
2. 本不该于黑夜出现的太阳，竟出现了**两个**；老者想起太阳所代表的身份，恐惧中听到七窍流血的轰鸣与低吼，随即昏迷。
3. 昏迷前一瞬，他感受到宗主七彩仙尊与其道侣冲出七道宗，直奔双日出现之处。
4. 数日后老者苏醒，苦涩发现自身**修为跌落数筹**。
5. 数月后七彩仙尊**独自归来**，神色阴沉但双眼极为明亮，绝口不提道侣为何未回。
6. 其带弟子、数个**仙妃**、**百卫**与**四大战将**进入洞府，将洞府彻底封死，留下无数封印烙印，更不惜取出几件老者从未见过的法宝用以封印洞府。

## 六、记忆断层与碎片

因结晶裂缝，记忆自此断层碎裂，仅余数个碎片：

- **碎片A**：一名身穿**银色衣衫**的女子，是仙尊侍女之一——王林认出即自己储物空间内那具**害怕七彩雕像的银衣女尸**，往事由此串联清晰。
- **碎片B**：七彩仙尊封印出入口后立刻离去，在洞府中不知忙碌何事；仙妃、百卫、四大战将虽不解却碍于仙尊之威不敢问询，各自寻处闭关等待召唤。
- **碎片C（对话）**：洞府外传来阴沉之声——“七彩道尊，你连自己的道侣都可以抛去，定是获得了莫大的造化之宝，你留下线索引我独自来此，本尊倒要看看你要耍些什么阴谋诡计”。七彩仙尊回应：“**道古烨寞**，本尊邀你来此，你偏说是阴谋诡计，到底是不是诡计，你一看就知”。老者对“道古烨寞”之名如雷贯耳，知其为**古国大尊**、名声显赫。
- **碎片D（终局）**：一场混乱大战，模糊金光中看不清参战者；只见**百卫、四大战将与数个仙妃围攻三个人**。战斗持续很久，死亡沉重之下三人中的一个在浓郁金光中大笑走出，一步迈去横扫前方七道宗之人，直奔一处**石门**。其笑声回荡：“本王亲自来此，你这小小七彩尊者还不出来跪见”。临近石门瞬间，石门内传出**惊天咆哮**——记忆至此完全结束。

查看结束后结晶彻底崩溃化作粉末随风消散。

## 七、王林的判断与新的疑团

- **认声**：那金光之人的声音是「**疯子**」的声音。王林神识进入储物空间，见疯子依旧沉睡、嘴角带傻笑。
- **已解之惑（推测性）**：
  - 银衣女子曾说“门不是她打开的”，此门或即**疯子来临之门**。
  - 那场大战的结果：疯子**失去神智**而癫狂；**远古仙域成为废墟**；当年七道宗残余之人纷纷闭关；洞府主人七彩仙尊同样**重伤**。
- **新的迷茫**：
  - 所争抢之物或许就是所谓的**天道**，也有可能是**天逆**。
  - 但天逆只是**法器罗盘**中的一样，不大可能是天道——那么天逆究竟是什么、来自何处？天逆与天道有何关联？
  - 当年在**闪雷族**得知：这场大战之后的某一年，有一批**外来的神秘修士**出现在界外，**昆极鞭**即其法宝之一——这群人又是谁？
- 王林隐隐感到自己掀开了一层神秘面纱，距离那无数年前之事的最终答案越来越近。
