# 第八卷 联盟隐秘 第1069章（四更）

## 一、贝罗逃入第六层

- 古妖贝罗被古魔塔珈追击，速度渐被拉开，眼看无法脱身。
- 贝罗咬牙崩溃**右目第三颗妖星**，借碎星之力直接冲入**仙帝洞府第六层**。
- 妖芒锁定前方两名同样逃遁的女子：**粉衣女子**与**村姑美妇**。

## 二、粉衣女子的雪花印记

- 贝罗右手妖爪直取粉衣女子。
- 粉衣女子面色苍白却无惊慌，**眉心雪花印记**闪烁，体外生出一道**雪花旋风**。
- 妖爪触及雪花风暴被砰砰弹起；粉衣女子喷血染红雪花，身子后抛。

## 三、妖灵变——村姑美妇形神俱灭

- 贝罗轻咦一声后毫不犹豫，横扫右手，闪电般抓住**村姑美妇天灵**。
- 美妇刚恢复没多久、尚带伤，全无反抗之力，被妖力一冲封锁全身经脉。
- 塔珈迈步逼近，贝罗后退中左手掐诀，在美妇身上连点数下，每次落下皆有一丝妖气融入。
- 美妇皮下**青色血管全部鼓起并诡异交错，形成巨大符文印记**。
- 贝罗将其向前一抛，大喝「**妖灵变**」：
  - 美妇全身血管轰然爆开，化作血雾，**形神俱灭**；
  - 崩溃刹那幻化出一个**符文**，符文生出吸力，转眼吸收全部爆开血肉，连**碎裂的元神**也不放过；
  - 吸尽无遗骸后，符文妖光刺目，**直奔第五层飞去**。

### 妖灵变（古妖一族保命神通）设定

| 项 | 内容 |
| --- | --- |
| 性质 | 古妖一族的保命神通，非万不得已绝不轻施 |
| 最大缺陷 | 必须以**性别相克之辈为炉鼎**方能成功 |
| 代价 | 即便成功也损失绝大部分修为，**只留神识残灵** |
| 本章触发原因 | 贝罗被逼绝路，又恰好遇见两名女子 |

## 四、贝罗自爆

- 施展妖灵变后贝罗妖力消耗颇多，右目**仅存的四颗妖星黯淡**。
- 贝罗未再逃走，猛地转身，带疯狂之色直勾勾盯住塔珈：「拼了，争取可以多阻拦一些时间，可以让妖灵逃出。」
- 右目四颗妖星急速旋转后**一颗接一颗全部崩溃碎裂**，身体疯狂膨胀。
- 贝罗狰狞大吼：「塔珈，本妖即便杀不了你，也要让你的**夺舍无法真正的成功**，这一切，都是你逼的。」
- 前冲中**由一化二、化四、化八**，天地间处处皆是贝罗身影，临近塔珈后**选择自爆**。
- 所有分身全部崩溃，形成疯狂冲击在**第七层**扩散，**整个第七层顿时崩溃**。
- 粉衣女子眼露悲愤，趁势冲入第六层，尚未走远即感受到身后冲击。

## 五、王林一线：第一层的布置

- 王林身在**仙帝洞府第一层**，身后**朱雀之音**回荡，一股**无形之火**弥漫。
- 他自之前火焰风暴冲撞而出的、**连接仙帝洞府所有层的深坑通道**向下望，双手不停打出无数印记。
- 每一印落下，深坑通道便脱落大量碎石。
- **王巍**与**胡娟**从通道内冲出，一眼看出王林打算，毫不犹豫在王林两旁同施神通落于地面。
- 大地不断震动，仿若牵引整个**妖灵之地**，妖灵之地内有如地震。
- **司徒南**（按世界状态须知：应归于「司徒南的断臂」所化人影）从深坑内一冲而出，口中咒骂不断。

## 六、要点提示

- 「村姑美妇」于本片段**形神俱灭**（与既有第977章死亡记录相印证/一致，本章为其被彻底湮灭的具体描写）。
- 贝罗自爆意在**破坏塔珈的夺舍**，暗示塔珈正处于夺舍进程中，尚未真正成功。
- 妖灵（符文）向**第五层**逃去，为后续埋线。


# 第987章 崩塌仙帝洞府封印古魔

## 一、局势：以塌洞封魔

- 王林决意轰塌仙帝洞府，以坍塌之土石与禁制封死下方古魔的出口。
- 司徒南（按世界状态须知：此处为「司徒南的断臂」所化人影，自第336章起自称司徒南，真司徒南已于第61章身亡）冲出后见到王林，吸了口气，不假思索便看出其打算，飞至半空向下方大地展开神通轰击。
- 其自嘲式抱怨「出去后解了毒，一定要去闭关」，点出其身中之毒尚未解。

## 二、众人自第二层逃出

地面震动加剧，仿若整座仙帝洞府将全面崩溃，原本进入第二层者纷纷飞出：

- 大头童子
- 尘道三子
- 雷吉
- 村姑美妇的两个弟子
- 浮沉子

这些人见到王林均是一呆，眼露骇然，纷纷散开。浮沉子眼中露出明悟，略猜到王林的打算，却不明其所以然——他们从未经历下方古魔的恐怖，甚至不知古魔的存在。

## 三、合力轰塌：朱雀开路

1. **王林**：双目奇异之芒，双手掐诀向下一指并低吼，身后庞大朱雀嘶鸣冲出体外，绕板块一圈直奔地面深坑，无尽火焰环绕其身，带疯狂冲击瞬息落下。
2. **王巍**：双眼透出血丝，掐诀之下沧海滔天、横卷紧随朱雀冲入深坑。
3. **胡娟、司徒南**：同样施展最强神通，随朱雀一并轰入深坑。

**插曲**：深坑中骤起寒气，粉衣女子全身被无数雪花包裹，从内挣扎冲出；重重攻击落下的刹那，其雪花急速旋转，险之又险地逃了出来。

**结果**：朱雀落入贯穿仙帝洞府的深坑通道，洞府自第二层起轰隆坍塌，地面深陷，一切出口尽数封死，其内更被诸般神通笼罩。下方传出闷闷之声与古魔的咆哮。

## 四、布禁成网 + 青霜之血

- 王林、胡娟、王巍三人速度飞快，各自掐诀落下大范围禁制于坍塌废墟之上，密密麻麻好似一张大网。
- 下方咆哮更疯狂，大地剧颤，仿若有一股力量、有一个人要破开一切、厮杀所有生灵；不知古魔者面色大变，浮沉子倒吸凉气，清晰感受到无尽凶焰、心神颤抖，毫不犹豫施展仅会的一些禁制不断落下；其余会禁制者亦纷纷出手献力。
- 「来不及了」——王林咬牙拍开储物袋，取出**青霜的肉身**置于身前，顾不得王巍与胡娟的感受，右手向青霜后心一拍。**此掌之力不为伤她，而是把她全身血液逼出到可使其不消散的极限。**
- 青霜喷出大口鲜血，被王林一挥化作血雾笼罩大地；掌心元力再吐，鲜血陆续喷出，被挥洒弥漫整个地面的所有禁制之上。

## 五、塔珈破土与关键发现

- 大地内传来轰轰惊天之声，一股滔天魔气呼啸而出，把所有碎石冲击成碎末，**古魔塔珈在魔气中缓缓飞起**。
- 但冲起的魔气一碰到上方密密麻麻的禁制，立刻**如雪融一般消散**——血禁之网确有奇效。
- 诡异之处：塔珈之后飘着**四人**——
  1. 天运子
  2. 凌天候（剑尊）
  3. 虚空子
  4. 从葬仙池古神头颅内走出的**人形之物**
- 该人形之物全身须发摇曳，**很是温顺地飘在塔珈身旁，仿若塔珈就是其主**。
- 王林见此瞬间脑中闪电划过：他此前一直未把这人形之物与古魔联系起来，此刻**心中有了猜测**（人形之物与古魔/塔珈之间存在从属或同源关系）。

## 六、伏笔与待解

- 天运子、凌天候、虚空子为何随塔珈飘出？是被擒、被控，还是另有隐情，本章未明。
- 人形之物与塔珈的主从关系为王林的猜测，尚未证实。
- 青霜肉身被逼血至「不消散的极限」，对其肉身保存的后续影响未交代。
- 司徒南所中之毒未解。
