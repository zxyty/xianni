# 第七卷 名震罗天 第862章 九曲天刀

## 一、格局：王林窥涅初期，俯视旧识

- 王林一式神通击退唐言枫，展露真正踏入第二步、**窥涅初期**的修为，四周修士心思各异。
- 战空烈进入千里光幕，凝重抱拳："许木前辈，请赐教"。
- 今昔对比：当年王林只能冒充前辈，即便在雷仙界也仅与战空烈修为相当，言谈需谨慎；如今突破阳实入窥涅初期，心神平静，目光俯视。
- 王林开口："你不是我的敌手，念你之前与我有旧，退下。"

## 二、战空烈问道：不屈战意的瓶颈

**战空烈自陈道途：**
1. 七百年前于**天雷星**感悟"雷中不屈之意"，将不屈天地之威融入自身。
2. 回到家族，静坐先祖遗物**战字帖**下冥想百年，自成意境——**不屈的战意**。
3. "战"既是其姓，亦是其意境，唯有战意。
4. 凭此意境修为突飞猛进，一路平坦，**四百年前达到阳实**；但时至今日寸步未进。

他曾问过战家老祖**烈云子**，答案反使其更加迷惑，故请王林解惑。此问一出四周皆静，连修真家族老祖也目露沉思——这是他们心中共同的疑问。

## 三、王林解道：战意的真伪

- 断语：**"你的战意，很脆弱。"**
- 王林点破烈云子的答案内核：**挑战星空下一切修为相近之人，在不断战斗中感悟战意、在不断胜利中巩固战意，直至进入类似"战狂"的状态，方可突破至窥涅**。战空烈震动——王林措辞不同，核心却惊人相似。
- 战空烈愿**送出道念**求指点，王林反诘："道念都可以随意送出，所谓的不屈，又有何用"。
- 核心开示：
  > 以不断战斗凝聚出的战意，很强，但这种强却是**有限**。真正的战意，是**心中有了信念，有了让你不得不战的道念**，有让你必须要胜、必须要赢、必须要战的决心。哪怕面对的是我，是你们战家老祖，是这天地——要敢说一句：**那又如何，惟一死尔**。
- 结果：战空烈心神剧震、连退数步，**眼中战意崩溃，取而代之一丝明悟**；王林大袖一甩将其送出千里光幕，他沉默许久后鞠躬致意，坐在**赤红之石**上默默感悟。

## 四、南宫氏挑战：九曲天刀现世

- 身前插着九把刀的**黑衣男子**沙哑开口："一语道出玄妙，兄台于道途感悟透彻，南宫，佩服。你有资格接受我的挑战。"——不问对方是否接受，仿佛被其挑战即是莫大荣耀。
- 他坐而不起，右手掐诀一挥，九把刀齐颤，九道刀气呼啸奔向王林；刀气蕴含某种**规则**，令四周星空扭曲，千里防护光幕亦为之颤抖。
- 一位家族老祖认出：**"九曲天刀"**。

### 南宫家背景（旁观者议论）
- 九曲天刀为**罗天南域南宫家**神通。
- 当年罗天南域四大家族：**南宫、唐、战、申公**，南宫家原本排名第一。
- **千年前南宫家神秘失踪**，所在修真星上半个南宫家人都无；此事曾引起**雷仙殿**注意，最终查不出任何原因。

## 五、王林出手：呼风·双黑龙

- 黑衣男子修为与王林相同，同为**窥涅初期**；九道刀气蕴含破坏规则的狂暴之力，封死王林前后左右退路，唯一选择是迎战。
- 王林前踏一步，右手抬起低吟"**呼风**"——出手即最强神通，意在争"第一"，不愿纠缠致气势削弱。
- 效果：黑风弥漫充斥星空，封锁的刀气毫无阻挡之力，尽数崩溃倒卷；黑风化作**两条千丈黑龙**，散无尽寒气，可吹熄一切生命之火。神通虽为呼风所化，却**取自王林元力，蕴含其此生煞气与此刻战意**。
- 两黑龙交错咆哮，阴风化风暴横扫，九道刀气未及临近便砰砰碎裂。
- 王林白衣、黑风绕身、双龙盘旋，一步步走向黑衣男子："**你要战，那便战。**"

### 旁观反应
- 众修士与家族老祖动容：隔着千里光幕仍心神微寒，如处寒冰，体内元力流转不便。
- "这许木不愧被称之为**魔道子**，一身道术充满了魔性，太强。"
- 有人称**姚家有雷风之术**与此神通相似，但威力稍有不足。
- 紫衣**雷仙殿老者**暗忖：听殿主说"**许木是清水仙君的隔代师弟**"或有可能；并盘算——接近大成的九曲天刀，与只能化出两头黑龙的**仙帝之术**，孰强？

## 六、反击：天刀斩灭

- 黑衣男子双眼精光更浓，仍未起身，掐诀令九刀中的**四把**飞起旋转，形成刀之风暴，星空大片裂缝仿佛承受不住。
- 沙哑开口："**天刀斩灭**"——四刀化作四把无边无际、仿若开天辟地的天刀，向两头黑龙狠狠斩下。九曲天刀即极致力量的展现，仿佛世间无物可抗。

## 七、王林的感悟伏笔

- 亲眼两次看见**清水**施展呼风后，王林感悟不少；此刻操控呼风时，脑中回想起**雷仙界藏品阁第九层**看到的**那幅画**。
- 他仿佛自身化成了画中**童子**，内心一阵明悟，双手抬起，好似与两头黑龙融合。（章节至此中断）

## 八、待续要点
- 呼风与九曲天刀的正面胜负未分。
- 王林"化身童子、与黑龙融合"的新感悟指向呼风神通的进阶。
- 南宫家千年前失踪之谜、黑衣男子来历未解。
- 战空烈坐于赤红之石上感悟，可能触发其突破窥涅。
