# 第1539章 吉国三姓！

## 一、疯子的絮叨（场景背景）

- 疯子围着闭目吐纳的王林反复搭话，问其姓名、许以赏赐，又讲「小红」被他拔光全身毛的旧事，讲到一半自己先大笑，随后忘了结局，敲头骂「怎么又忘了」。
- 他提到「本王那时候说话，就连李家听到都要立刻笑起来」「不笑者本王就去找我哥」，透露其身份与「哥」及「李家」的关联。
- 疯子一开口便是数日不停，王林半句未入耳；对疯子而言，有个活物听他说话已足够满足。

## 二、王林体内的仙神格局

### 三层结构

| 层次 | 内容 |
| --- | --- |
| 外 | 吉神之体（古神之体） |
| 内 | 元仙（取代元神） |
| 更深处 | 天逆珠子，缓缓转动，凡人时间一天十二时辰才转一圈 |

### 仙力取代元力

- 元力彻底崩溃消失，取而代之的是骨髓中造出的新血内所蕴的**仙力**。
- 数量对比：旧元力如大江大河，眼下仙力仅涓涓溪流，少了百倍千倍不止。
- 层次对比：仙力远超元力，内蕴一股极为可怕的惊天气息，令王林心神震动。

### 肉身暴涨

- 此前七星崩溃引动**第二损劫**，损劫尚未完全爆发便因**天逆**之故被肉身吸收。
- 结果：肉身所蕴**道古之力**比之前强悍数倍，心脏每跳一次似可引起天地轰鸣，化作无形之音传遍八方。

### 战力评估（本章当时）

- 受排斥所限，运转仙力只能发挥**两威**。
- 仅此两威已足以轰杀**空涅后期**大能，空涅后期在其面前没有逃遁资格。
- 全部爆发之下，如**南诏上人**之流亦非敌手；唯**空涅大圆满**或有一战之力。
- 王林自评：此刻的他是「仙与神的结合」，是诸多星海中罕见至极的变化。

## 三、致命隐患：仙神排斥之力

- 肉身与元仙虽处于融合状态，排斥依然存在；**天逆只能强行融合，无法消散剧痛的根源**。
- 双向掣肘：运转仙力→身体剧痛且被肉身道古之力阻止；施展肉身之力→被体内元仙阻止。
- 最大危险：排斥隐隐**越加剧烈**，随时可能爆到极致，轰碎肉身、毁灭元仙之体，连灵魂与一切在崩溃中彻底死亡——「如同一把悬在头顶的死亡之刀」。
- 王林盘膝苦思化解之法，最终没有半点思绪。

## 四、仙祖印记与金色吉星

- 眉心的**仙祖印记**看似崩溃，实则未溃：它如身体与元仙一样**融化**，与**七个吉神星点**融合。
- 由此，王林的古神星点成为吉之一族**从未有过的金色吉星**。
- 数日后王林睁眼，双目爆出两道金光落在疯子眼中。

## 五、疯子的金目与泄气

- 疯子认出这是「我族的金目」，但嫌其只是**淡金**，要示范给王林看。
- 疯子憋气鼓腮，身体膨胀，黯淡双目转为犀利，爆出金黄色光芒，浑身显出说不出的惊天威严——一开口威严又烟消云散。
- 再度加码时，身体咔咔增长、干瘦躯体血肉蠕动渐强壮，忽「噗」的一声雷鸣般放屁泄气，身体如泄气皮球瘪下，金色目光瞬间消散。
- 疯子尴尬捂臀后退，红脸辩称「意外，本王很少泄气的，莫非有人想念我了」，还摸了摸凑到鼻下嗅。

## 六、王林的判断：造化之恩与杀身之祸

- 王林暗叹：疯子对他有**造化之恩**，但这造化也险些将他杀死。
- 关键归因：**若没有那什么仙祖印，王林身体断然不会如此**——排斥仍会有，却绝不会如眼下这般激烈。
- 「罢了，与这疯子计较又有何用」——不再追究，转向解决排斥危机。

## 七、决策转折：古魔不作分身，改融右目

1. 王林右手虚空一抓，幻化出**储物裂缝**，魔气轰然爆发，取出**从古墓内所得的古魔**。
2. 古魔现状：肉身原本石化，在王林获得**道古传承**时改变，如今已如真正肉身；右目内**六个魔星**隐隐闪烁旋转；但无神，依然只是一具尸体。
3. **原计划**：凝炼一个魔魂，使这古魔成为**分身**。
4. **改变主意**（原因：体内排斥之力危机）：
   - 一指之下，古魔全身剧颤、身躯急速枯萎缩小，全身血肉尽化魔气直奔右目魔星；
   - 瞬息间古魔肉身彻底消失，全部凝聚在六个魔星内；
   - 王林右手一抓，六魔星直奔其右目，融入其中，**烙印在那金色闪电之下**；
   - 王林深吸口气、双手掐诀，眉心**七个金色古神星点**化道道金光融入右目，与六个魔星急速相融。

## 八、疯子揭示的设定：吉国（古国）三大王姓

疯子目睹全程后揭示：

| 王姓一脉 | 根本路数 |
| --- | --- |
| 道古 | 以**古神**为本，**古魔**为分（即王林此刻所行） |
| 极古 | 以**妖**为本 |
| 始古 | 以**魔**为本 |

（原文「吉国」与「古国」互用，为同一对象的书写变体。）

### 疯子的困惑与行动意向

- 「他明明是我**仙族**之人」，且拥有「我**皇族**唯有我与我哥两个人拥有的**不灭体**」，怎么会是**古国之修**？
- 判定此事极为反常：「到底是谁这么大的胆子，敢给古国之修我仙族不灭体」。
- 后果预判：「此事要是让我哥知晓了，定然会愤怒至极」。
- **决定**：一定要查出是哪个「王八羔子」如此胆大——神色首度转为严肃。

## 九、伏笔与待解

- 排斥之力未解，随时可能爆发致死，为后续主线悬念。
- 王林同时具备仙族不灭体 + 古国道古一脉修法，身份矛盾被疯子盯上。
- 疯子口中的「我哥」尚未露面，已两次被提及为威慑性存在。
- 六魔星 + 七金色吉神星点在右目相融的成果，本章未给出最终形态。
