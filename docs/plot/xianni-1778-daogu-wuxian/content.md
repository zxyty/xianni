# 第1778章 道古无仙！

## 一、战前状态
- 王林体内修为慢慢散去、本源收缩不再出现，身体内外全部弥漫浓郁**道古气息**。
- 王林自陈立场：「这是一场神与仙之战」；当年**七彩仙尊与烨寞**一战，烨寞身亡，此为遗憾，今日一战「可称宿命」，以王某之身续往昔。
- 实力评估（王林内心）：战老鬼吸收**七彩道人**后比以往强上不少；自己即便获得烨寞**除左眼外全部传承**，也依旧不是对手，但「可以拼一次，不管成败」。
- 助战：**已司之傀**化作黑雾扑向战老鬼，全程与其纠缠牵制。
- 旁观：**玄罗**在远处目睹全程。

## 二、神通序列（本章核心）
王林所用皆出自烨寞传承、属**道古一族**绝学，三族星点分列——眉心**古神九星**、右目/双目**妖魔十七星点**（左目**妖星八颗**）、**古魔九星**。

1. **心动，雷音起**：体内心跳如雷霆轰鸣连成一片，扰乱战老鬼心神，使其心脏剧痛。
2. **心乱，一步崩**：四周心脏回音尽数凝于战老鬼身上，引其心脏出现崩溃迹象；战老鬼以神通操控肉身、按凹胸口卡死心脏使其停跳解厄。
3. **道古一拳**：融眉心九颗古神星点与双目妖魔十七星点，隔空轰出开天辟地一拳。战老鬼连写**七个「战」字**硬接——六字崩溃、王林一拳消散，战老鬼退数步；余下一字在王林身前爆开，王林闷哼溢血。
4. **神震，兵修列位**：烨寞学自**道古一族神庙**的绝学，王林曾在古墓大殿传承幻术中亲见。此地虽无幻境中的无数仙兵，仍使崩溃的大地被一拳吸摄扭曲，以拳为中心旋转——「天旋地转，唯王林不动」。
5. **妖术，烽火成山**：左目八颗妖星融入手掌挥出，燃起**八条烽火烟柱**，内有妖气与凄厉嘶吼，幻化**八个古妖虚影**仰天咆哮，绕体旋转连成风暴护身。战老鬼欲强破风暴，被已司之傀再度缠住（战老鬼咬破舌尖喷血化大口吞咬逼退已司）。
6. **魔道，生死逆动**：一指点向战老鬼，其体内生机急速化作死气；同时引动古之墓地上下各层——含上层雾气世界——无数年来死亡生灵所化死气，如烟丝云涌汇向王林，沉积成「死海」，古魔气息轰起、鬼哭狼嚎。
7. **神、妖、魔，古道无仙 → 道古无仙**：古神九星、古魔九星、古妖八星三力融合为**道古之力**，一掌拍出，身前现与大地齐高的巨大**头颅虚影**。

## 三、道古无仙与古祖之谜
- 头颅容颜既非烨寞亦非王林，是一张陌生面孔，却令王林感到熟悉——这份熟悉**来自其血脉、来自体内古祖所赐的魂血**。
- 伏笔：若王林去到**仙罡大陆道古一脉之地**，见到**大空城**内那尊蔑视天地的巨大雕像，便会一眼认出，道古无仙所化头颅正是该雕像。
- 玄罗身子一震，目露崇敬，唤出「**古祖**」二字。
- 头颅双目模糊、张口喷出气息如狂风席卷，所过之处**天翻灰色、大地弥漫灰光顷刻石化**：本层、无心脏的最后一层、上一层雾气世界的雾气与平台——**整个古之墓地刹那全部石化**。

## 四、结局与转折
- 战老鬼瞳孔收缩、面色惨白疯狂后退，无暇顾及已司之傀，掐诀自七窍散出七彩烟丝凝成**七彩道人之魂**，又幻化体内**七彩第二魂**（披风笼罩）护体。
- 两魂先后石化，战老鬼肉身随之灰芒一闪彻底石化。
- 石化旋即出现大片裂缝崩溃，两魂齐齐**融回战老鬼体内**；战老鬼身颤喷血、一脸骇然急退——「他怕了」，与当初见到王林**李广弓**时一样心神被恐惧弥漫，最终遁走。
- **第四花**所在空间：黑色第四花砰然碎开，化作风暴卷动；整个古之墓地全面崩溃。
- 王林压不住伤势喷血，踉跄后退数百丈，眼露可惜与苦涩。

## 五、王林的结论与下一步计划
- 复盘：强行施展道古无仙仍被对方逃走；**短时间内已无力施展第二次**。
- 假设：若有**左眼**（古妖亦成九星），此战不会如此艰难。
- 判断：「我终究，还不是他的对手。」
- 行动计划：**前往第五花寻找真门，打开洞府大门，借仙罡之力将战老鬼封印**。随后王林身影在崩溃的古墓中消失。
