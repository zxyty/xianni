# 第1649章 还不够！

## 一、生死真假因果阵：本源之阵首次施展

- 王林话音落下的瞬间，身后数百个原本黯淡的头颅双目齐齐爆出明芒，凄厉惨叫如音浪风暴呼啸，七窍流出漆黑鲜血，血腥气浓浓弥漫。
- 这些头颅内封印着所有死亡修士的**元神与魂**——死的只是肉身，头颅未死，而是在经历一种**因果、生死、真假的轮回**。
- 头颅中蕴含王林的**虚之三大本源**，在本源弥漫下，他们如同置身**梦道**，要一次次经历或真实或虚幻的凄惨往事。
- 这并非单纯折磨，而是王林**杀戮第一步的开端**，涉及一个阵法：以三大本源之术融合后明悟而出的**本源之阵**，名曰「**生死真假因果阵**」。**从未施展过，本章是第一次**。

## 二、动机：世界只是一座洞府

- 此举惨绝人寰，唯滔天之恨方可毫不犹豫施展。
- 王林对界外的恨本不至于如此浓郁，但**自他知晓「这世界只是一座洞府」后，心神内挤压出一股滔滔怨气**。
- 这股怨气是他杀戮的根本：**恨天恨地，恨那操控众生命运的仙尊**。恰逢界外入侵，界外修士遂承载其怒火。
- 自述：「这场大战死亡了太多太多的人，那么我王林也就不在乎去杀更多之修……既然你们想凭借杀戮达到某种目的，那么我王林便帮你们一把，我倒要看看你们要寻找什么。界内已经死去太多，现在该轮到界外了。」

## 三、踏入召河星域

- **召河星域**曾**两度沦陷**为界外之地，境内驻守着大量来自**太古星辰**各族落的界外修士。
- 界外修士在此极为残忍：掠夺大量修真资源、将大量女修**残忍威为炉鼎**、无数修士鲜血洒满星空。
- 一入召河即扑面浓郁化不开的血腥气，王林杀机更浓。
- 体内**第六道本源——杀戮本源**自体内爆发笼罩全身，四周浮现无数处于虚幻与真实之间的**赤红之雪**；一路前行，咔咔声中身后星空被冰封成片、闪烁刺目红光、寒气滔天，双眼隐隐泛红。

## 四、惊动第三步空灵后期界外大能

- 王林神识骤散笼罩整个召河星域，召河深处一股**第三步空灵后期**的气息惊天而起，透出震惊与措手不及。
- 若是**没有梦道之前**的王林，定会皱眉；如今他看都不看一眼——「他连**空玄大能**都敢杀，区区空灵，他不放在眼里」。
- 该大能凝聚神识虚影、本尊一晃而起锁定王林急急赶来；文中点明**这是王林想要此人来临故而任其锁定**，否则对方根本没资格找到他所在之地。

## 五、因果印：一击拔尽一星数千修士

- 王林出现在一颗内有数千界外修士的修真星外。神识扫过，其内景象历历在目：大部分闭目打坐；另有寻欢作乐、与炉鼎强行双修、虐杀凡人、**吞噬被俘界内修士精血修为**者。
- 评语：「这些人，该死。」王林大袖一甩，右手五指并拢成掌，向修真星遥遥一按。
- 修真星惊天轰鸣、尘埃遮天如末世；镇压之力下大半界外修士喷血萎靡、面露恐惧，惊呼「界内大能都在**罗天**，谁能走过层层封锁来到这里」。
- 天空浮现遮天巨掌，大地骤暗如夜；掌印内有一时而模糊时而清晰、盯久便心神纷乱的印记——**由无尽白骨组成的万空骨门**，该门此前毁灭后**烙印在王林掌心成为永恒**。
- **因果印规则**：
  - 对**有本源的第三步大能**：抽出的是**本源**，不动及生死；
  - 对**修为未到第三步**者：抽出的是**灵魂、元神、生机等一切体内虚物**。
- 巨掌五指扣起如握拳，数千修士七窍中烟丝般气息被生生抽出；掌印化作巨拳猛地外拽，数千修士身体轰然崩溃，头颅与身体分离化作长虹飞至王林身后。
- 数千元神各归其头颅、被生生封印，沉浸于**生死、真假、因果**之中，惨叫再度滔滔而起。
- 王林转身走向下一颗修真星：「**区区数千，还是不够**。」「来一个，杀一个；来一群，杀一群。」

## 六、冥灵族的死气修真星与周紫虹

- 下一颗修真星内一片废墟、死气笼罩，死亡气息浓郁惊人。
- **冥灵族**：太古星辰的一个**小族**，**吸收死气而修**，聚居处往往死气最浓。因在这场大战中有功，被**长尊会**赏赐此星；其族大半自界外凝聚而来，以此为**新的部落**。
- 死气中漂浮无数散发灰芒的气泡，泡内囚禁界内俘虏，**大多是女性**——其中一人赫然是**周紫虹**：闭目昏迷、面色苍白，衣衫尚完整。
- 章末：死气弥漫的大地轰轰裂开一道巨大裂缝，裂缝内传出吸力，**卷动三百个气泡直奔裂缝**，周紫虹亦在其中。

## 七、悬念与后续线索

1. 生死真假因果阵的完整用途尚未揭晓——王林明言这只是「杀戮第一步的开端」。
2. 被王林故意引来的第三步空灵后期界外大能尚未交手。
3. 三百气泡（含周紫虹）被裂缝吸走，去向不明。
4. 「这世界只是一座洞府」与「操控众生命运的仙尊」是王林怨气之源，指向更高层的对抗。
