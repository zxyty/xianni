# 第1046章 虚空子的杀机

**卷次**：第八卷 联盟隐秘｜**章节**：第1046章（片段序 00963-00966 之4）

## 一、洞府第一层的追逐

- 王林依【地图玉简】指引，直奔仙帝洞府第一层**正中间的黑雾**区域，速如流星，一路穿越无数禁制而不触发。
- 阁楼禁制拦阻时，王林于半空以不可思议的角度**连踏七步**，直接沉入禁制又穿透而出。
- **黑衣男子**紧随其后，几乎踩着王林走过的同一处步伐，同样穿透而过——其观察与模仿能力极强。
- **村姑美妇**虽为大神通修士，但对禁制的了解不如王林，又居后方，被阁楼禁制困住，眼睁睁看二人远去。

## 二、虚空子救人

- 后方禁制被**葬仙池人形凶兽**（赤红之影）尽数轰碎，凶兽扑向村姑美妇，成爪横扫。
- 一声“孽畜尔敢”低喝，波纹凭空阻隔，**虚空子**踏步而来。他早已从葬仙池崩溃冲击推入的禁制中走出，在第一层转了很久且颇有收获。
- 虚空子与村姑美妇所属势力**有渊源**，不能见死不救，遂大袖卷起美妇，以修为硬冲阁楼禁制而去。凶兽紧追不舍。

## 三、黑雾与第一层大殿

- 黑雾**魔气浓郁**，王林无暇犹豫一步踏入，黑衣人瞳孔一缩紧随。
- 黑衣人提醒“此地魔气浓郁，王道友小心”，并追问追来之物为何。王林答：**“那是葬仙池内之兽”**。
- 黑雾内为一座**遮天盖日的巨大殿宇**，远超一切阁楼，雾中阴森如凶兽趴伏；殿门开有一道缝隙，**十人并排可过**。

## 四、两座雕像与黑龙印记

- 殿内有**两座巨大雕像**，彼此掐着印记、虚空点向前方、双目怒视，散发天地之威，见者心神被摄。
- 王林因**先前在花妃处有过类似经历**，受震慑但影响不大，迅速恢复。
- 黑衣人一见雕像即一顿，**眉心黑龙印记**刹那幻化而出。王林瞳孔一缩，随即收回目光、神色不露分毫。黑衣人事后察觉隐秘外泄，不确定王林是否看到，**神色阴沉**。
- 虚空子卷着村姑美妇破禁而入，同样被雕像一震，但恢复极快，几不可察；村姑美妇一度迷茫，在其相助下恢复。
- 王林在殿内**未找到通往第二层的入口**，但目光落在两座雕像上，**已有所猜测**。

## 五、撕破脸与碎涅一击

- 村姑美妇不再称“道友”，**直呼“王林”**，怒斥其招惹凶兽引祸；王林反问“阁下如何知晓那人形之物就是王某引来”，并解释是从禁制中走出遭遇、一战不敌只能逃。
- 王林说话间**不动声色地连连后退**，逼近雕像，右手按在储物袋上，目光实则始终盯着虚空子——他判断真正的压力来自虚空子。
- 实力对比：**虚空子是碎涅修士**；王林虽已达**窥涅巅峰**并配合**古神肉身**，仍绝非对手。
- 虚空子淡淡开口：“小辈……老夫给你一个机会，你出去引开那人形之物”，话中**裹挟神通**，脚步一迈即有**数道无形波纹**爆发碎涅之威直冲王林胸口。
- 王林右目青光一闪，**青光盾**幻化阻挡，却**第一次毫无阻挡之力**，被轰然压下撞在自己胸口；王林喷出大口鲜血如断线风筝被抛飞。
- 一股霸道波纹之力冲入体内，疯狂撕扯经脉，势如破竹欲毁其骨肉与元神。村姑美妇一怔，黑衣人瞳孔一缩。
- 虚空子轻咦一声：这一击并非全力，但杀一个窥涅修士本应易如反掌——他原以为这位**“未来的朱雀圣皇”**必定肉身崩溃、朱雀死亡。

## 六、悬念与看点

1. 王林后退逼近雕像是否为有意为之（雕像疑为通往第二层的关键）。
2. 黑衣人眉心**黑龙印记**的来历，以及他因隐秘外泄对王林起的杀意。
3. 虚空子对王林的杀机来源，以及“未来的朱雀圣皇”这一身份定位。
4. 王林是否真的被重创，还是另有后手（章末虚空子的“轻咦”暗示意外）。
