# 第七卷 名震罗云 第659章 离去

## 一、妖灵之地剧震：漩涡与古妖
- 凌天候的一掌印在**妖灵漩涡**上，撼动的却是整个**妖灵之地**——九郡轰然颤动。
- 妖灵之地内惊呼弥漫：天空由蔚蓝转为阴暗，云层翻滚形成一个不断扩散、弥漫天际的巨大漩涡。
- 漩涡旋转间，**一道道剑气**自内散出融入天地；同时传出**极为霸道、好似『他就是这个天』的气息**，并有**七道如虹光彩**散落天地。
- 妖灵之地内**所有古妖**刹那间从各自圣地凝化成形，阴沉抬头遥望漩涡。
- **贝罗**抬头看了一眼，大袖一甩，消失不见。

## 二、老怪入场
- 漩涡内走出数人。**凌天候**一身青衫踏虚空，喝道：「贪狼出来见老夫」——声如无数奔雷，地面咔咔碎裂蔓延，声音回荡整个妖灵之地。
- **天运子等人似乎早知贪狼在此**，并未惊讶。
- **血祖**赤袍，面沉如水，入内即神识横扫，一无所获，好似**姚惜雪彻底失踪**；再以秘术横扫，面色更加阴沉，不安更浓。
- **天运子**抬手掐指推算：在外界因**东海**阻拦，其推衍占卜总有一团迷雾；如今身在妖灵之地（即身在迷雾之内），占卜**不再受阻**。

## 三、王林同步动作（暗线）
- 就在老怪们踏入的瞬间，身在**潮汐入口外**的王林纵身跃入**潮汐深渊**，身如闪电流星直奔下方。
- 深渊吸力此刻化作无穷推力，令其速度更快，冲入**回廊**，直奔下方**深坑**。

## 四、云仙道侣现身：王巍、胡娟
- 凌天候神识横扫至**极北之处**时，迎面撞上两道神识，闷哼一声、身子微晃，眼中爆出精光。
- 前方无声出现一朵**虚幻祥云**（非实质），云上坐着一男一女——**云仙道侣王巍、胡娟**。
- 王巍平淡扫视众人，唯独看向**天运子**时瞳孔**微不可查地一缩**；而天运子始终闭目掐算，毫无神色变化。
- 王巍笑称「好久不见」；凌天候冷声索人：「我察觉到贪狼就在你这里，把他给我，我有要事问询」。
- 王巍与胡娟对答间调侃：这剑尊的脾气「不但没有减弱，反而更盛」；胡娟称「剑尊道友关心弟子，也是情理」。
- 凌天候神色更阴沉——**若非极为顾忌这二人，以他的性子早已出手**（一处重要实力/忌惮标尺）。

## 五、贪狼与辰龙的对质
- 王巍一拍**储物袋**，飞出二人：**辰龙**与**贪狼**。
- 辰龙见凌天候后一怔，随即狂喜，**噗通跪地**，眼中湿润大喊「师尊」，指认「是这贪狼，是他害了师弟们」。
- 贪狼神色如常，出现后**恭敬站在王巍与胡娟身后，好似一个老奴**。
- 凌天候不看辰龙，目光如剑盯住贪狼，阴森道：「贪狼，你好大的胆子」。
- 贪狼内心一跳但面不改色，眼皮一翻冷视辰龙：「小娃娃，老夫可亲手杀你大罗剑宗一人」。
- 辰龙有师尊撑腰，恶毒回喝：「你虽非亲自，但却把我们**困在紫雾内**，其心可诛，若非如此，师弟们怎会死去」。

## 六、要点与伏笔
1. 凌天候一击即可撼动九郡，且其入场伴随剑气与七道虹光，显示大罗剑宗剑尊层次的恐怖威压。
2. 妖灵之地是天运子占卜迷雾的**源头之内**——入内后推衍恢复，为后续找人/寻宝埋线。
3. 血祖遍寻不着**姚惜雪**，构成其后续行动的核心焦虑。
4. 王巍夫妇被凌天候「极为顾忌」，是当前场中实力天平的关键。
5. 贪狼以紫雾困死大罗剑宗弟子的旧账被当面掀开，贪狼此刻依附于王巍夫妇。
6. 王林借群雄入场之机潜入潮汐深渊回廊、直下深坑——本章明暗两线并行。

# 第619章 王林遁入漩涡·虚府第四座之言

## 一、贪狼受审：令牌不在我手

- 贪狼大笑辩解：困住辰龙等人确为洞府令牌，但未伤其一根汗毛；斥辰龙不去找杀其师弟的正主，反来找自己，荒谬。
- 凌天候大袖一甩喝止辰龙，眼露毫不掩饰的杀机，一字一字逼问：「贪狼，令牌呢」
- 贪狼以数万年修行起誓：令牌不在他手。
- 在场老怪（含血祖）目光如剑齐落贪狼身，唯天运子闭目掐算。贪狼自知除辰龙外修为最弱，心神剧震。

## 二、供词与作证

- 贪狼供出：**天运宗的王林**抢走令牌，且**正是此人杀了大罗剑宗之人**，辰龙可作证。
- 辰龙的证词有限：只看见得了令牌的王林被贪狼困住，此后不知；但王林杀了几个师弟属实。

## 三、天运子掐算·神识齐降深坑

- 天运子睁目望向东方，喝「想走」，手指掐动愈快，目光穿透无尽距离，落到**水妖郡潮汐入口** → 穿入**回廊** → 直奔回廊内**深坑**。
- 王林下落中立即察觉，身子一晃与吸力融为一体，速度更快。
- 天运子目光受深渊吸力吸扯，略一犹疑后强行再度深入。
- 此神通引起凌天候等人注意，连云仙道侣二人也现惊讶；众老怪神识顺天运子目光轰然散去，穿透潮汐深渊，进入深坑。

## 四、七星剑阵加速·踏入漩涡

- 王林神色如常，一拍储物袋放出**七星剑阵**，剑阵绕体旋转形成推力，与深坑吸力融合，速度更快。
- 一冲直抵深坑底部漩涡处，恰在此时天运子目光与众老怪神识降临。
- 凌天候一眼认出七星剑阵，愤怒顿时点燃。
- 天运子发现王林身上**再无任何杀戮仙诀的烙印**，目光透出寒意。
- 王林一脚踏在漩涡上，回头冷冷一望，整个人陷入漩涡渐渐沉去。
- 漩涡涌出浩淼之力，众老怪神识被迫齐齐退散——**这是两个星域之间连接的力量**，非不愿拦，实不能拦。

## 五、血祖的质问与王林的反击

- 王林身子融入瞬间，血祖神识化虚影死死盯住：他感应到王林身上有**姚惜雪的气息**，气息中透出挣扎与反抗，断定姚惜雪失踪与王林有莫大关联，甚至可能已被王林擒住。
- 血祖大喝：「王林，我女儿在哪」
- 王林消失前只留一句：**「虚府并非三座，而是四座」**。
- 关键点：第四个虚府只有血祖与姚惜雪知晓，姚惜雪断不会外泄——此言等于把血祖架在火上。
- 王林的算计：既然血祖已察觉姚惜雪之事，便主动搅浑水，让老怪们互相猜忌，使血祖无法因私事亲自追击。

## 六、老怪议定：以禁制驱贪狼入漩涡

- 王林消失后一片沉默，众老怪本就各怀心思，结合王林之言与血祖反应，纷纷看向血祖。
- 血祖如针芒在背，只得承认并给出方案：
  1. 确有第四座虚府，且显然已被王林占据；王林又持令牌，若不擒回此人，众人**再无进入真正洞府之日**。
  2. 此漩涡众人早知是**通向罗天星域的入口之一**，但内蕴力量太强；当年众人尝试进入皆未成功。王林不知得了什么奇遇竟能进入。
  3. 若众人联手，**只送一人进入**应可做到。
- 凌天候问：「谁进」
- 血祖答：自己去必招疑，最佳人选是**贪狼**——每人在其身上留下一道禁制，贪狼便逃不出掌心，只能乖乖入内擒王林；其修为也足以对付王林。
- 天运子默望漩涡，眼露奇异之芒，心思无人可看出。

## 七、伏笔与看点

- 王林已带令牌与「第四座虚府」的秘密进入罗天星域，追兵将至（贪狼，身负众老怪禁制）。
- 血祖与众老怪之间的信任已被王林一句话撕开裂口。
- 天运子的态度成谜：既锁定王林行踪、又对贪狼入漩涡一案默不作声。
- 王林身上杀戮仙诀烙印的消失，被天运子记在心上。
