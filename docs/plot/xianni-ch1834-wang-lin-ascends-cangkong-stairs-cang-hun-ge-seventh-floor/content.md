# 仙逆 第1834章 欲踏青天！（第一更）

## 一、赌约成立

- 王林右手一抬，血光一闪，将一把**血剑**掷落地面：「此剑，足已」。
- **炎栾**一眼认出此血剑乃**道古一族**之宝，作为与她**蓝色之伞**等值的赌注足够，遂答应赌约。
- 赌注对价：血剑（王林） ↔ 蓝色之伞（炎栾）；蓝伞防御之力极为惊人，是炎栾颇为强大的法宝。
- 赌题：王林能否成功踏入**藏魂阁第七层**（炎栾认为他必被第七层禁制弹回）。
- 炎栾心态：先是激将，随后隐隐后悔，并怀疑王林「狡猾多端、故作玄虚」，输了或会反悔。

## 二、藏魂阁第七层的门槛设定

- 第六层通往第七层的古老楼梯共 **十九个台阶**，看似一步可越，实则散发危险气息——意志不足者踏上如「怒海孤舟」。
- **天地异象**：有人踏阶时，大魂门上空浮现蔓延数百里、光芒万丈的巨大阶梯虚影，照亮黑夜，轰鸣回旋，惊动全门修士。
- 该异象是荣耀，也是压力：失败被弹回的狼狈同样被万众目睹，故多年难见一人尝试。
- **门槛频次**：距上次有人进入第七层约一百多年；除几位老怪外几乎无人敢入。
- **一次性豁免**：成功踏入第七层后，日后再进便不会再引动天变。

## 三、踏阶过程

1. 王林回头深意地看炎栾一眼，道「你看好了」，抬脚落于第一阶——大魂门天地色变，阶梯虚影现世。
2. 全门修士纷纷出关观望，普遍不看好：「他修为尽管不俗，但若想进入这第七层，怕是很难」；抱着看热闹与看狼狈的心态。
3. 王林闭目片刻后骤然睁眼，大步流星连走 **五个台阶**，每一步落下皆有雷霆般轰鸣。
4. **第五阶受阻**：一股庞大神识自阶梯横扫而出，轰入其心神，化作巨响「退下！退下！退下！」，回音如数百上千人齐吼，身体似要被撕开、不退则形神俱灭。炎栾据此断言「他走不出第七个台阶」。
5. **凝本源真身**：王林掐诀一指「本源真身，凝」——燃烧的**炎脉峰**爆发磅礴火海，火海中露出王林**本源真身**的巨大面孔，火海直奔天空虚幻阶梯并融入其虚影；藏魂阁第六层内，王林周身火海散开，本源真身于其身后凝现。
6. **连进至第十三阶**：得新力后，王林自第六、第七、第八阶不停脚步，刹那间踏上 **第十三台阶**。

## 四、各方反应

- **炎栾**：猛然起身，绝美容颜大变，眼露难以置信，身子轻颤，右手死死握至发白，脱口「不可能」。
- **大魂门修士/长老**：哗然如浪——「第五台阶一顿，直接走到第十三台阶」「那是本源真身！」「还有六个台阶，他就可以进入第七层」。王林拥有本源真身一事此前并非人人皆知，此番当众暴露引起巨大震动，全门几乎沸腾，连常年闭关的老怪也纷纷动容。
- **青牛老祖（青天峰）**：初判「他有些鲁莽了，与他的修为，不可能进入这第七层」，并想「挫挫他的锐气，莫要以为我大魂门内没有玄妙」；见十三阶后改口「我小看了他」，断言其本源真身已很接近**真仙**程度，并点明「本源真身」与「本源真仙」一字之差如天地沟壑；预计王林最多再走三个台阶。

## 五、转折与收束

- 第十三阶上，「退下」之声磅礴无数倍冲击其元神，王林双眼一度**恍惚**——炎栾露喜色，众修士暗自摇头，皆以为其将败。
- 刹那间恍惚尽散、取而代之滔天精光，王林开口：「**炎栾，你高兴的太早了，你的那把伞，王某要了**」。
- 章末为作者求月票语（非剧情内容）。

## 六、待观察线索

- 王林最终能否走完剩余六阶（第十四至十九阶）进入第七层，本章未揭晓。
- 血剑（道古一族之宝）与蓝色之伞的归属，取决于此赌结果。
- 王林「本源真身 → 本源真仙」的进阶差距，被点为其战力上限的关键指标。
