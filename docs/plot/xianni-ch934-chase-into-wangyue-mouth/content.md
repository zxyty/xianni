# 仙逆 第八卷 联盟隐秘 第934章 追入月口（第四更）

## 一、玄宝上人的绝境

- **神通「法力空涅」**：玄宝上人身外凝聚无数法宝，法宝轰然崩溃，每一件崩溃都逸出一丝白气；浓郁白气缭绕后被双臂前甩喝出，疯狂冲出与清水的「撒豆成兵」对轰。
- **连锁后果**：惊天震动引起星空更大范围崩溃，原本万里漩涡被硬生生撕裂蔓延，闪躲不及的修士被卷入虚无、消失无影。卷入漩涡虚无者生死难料。
- **三面夹击**：前有清水，后有望月（古神手臂），上有炎雷子。炎雷子甩开武东禅，掐诀之下身前数十块仙界碎片幻化弥漫千里，形成充满仙气的风暴漩涡直奔玄宝上人。武东禅高呼「清水仙君，老夫助你一臂之力」实为相助玄宝上人避险（原文语境为其紧跟其后、欲助玄宝上人）。
- **此战之危**：玄宝上人自认这是他一生中除「仙君崩溃逃离时」外最危机的一次，念「拼过这一次，老夫还可活命」，疯狂逼出体内仙元形成无数防护。

## 二、玄宝上人肉身崩溃

1. 望月古神手臂轰落，仙元防护层层瓦解。
2. 清水临近，数道红色闪电冲击，玄宝上人喷出鲜血。
3. 炎雷子仙界碎片之宝齐齐凝聚——砰的一声，**肉身轰然崩溃，元神出窍且几近崩溃**；元神上有一道金衣环绕抵消攻击，片刻后碎裂。
4. 剧变使撕裂星空大范围扩张至方圆数万里，形成破灭，无数修士被卷入。
5. 王林身外大鼎闪烁、不断变换方位自保，双目死死盯住望月交战处**等待时机**。

## 三、水罗蓝裙女子解封金尸

- 女子身外炼化台环绕，安然无恙；身边金尸神色冷漠如常。
- 其**莲花台**在大战中不断吸收死气，缭绕之下仿若雾中之物。
- 她望王林一眼，目中复杂，喃喃：「**不知下次相见，君可识妾**」——留下明确的后续伏笔。
- 抬手一指金尸，轻声道「**解封**」，二字化作实质般的两个诡异印诀落在金尸身上；金尸一震，头顶五张纸符停止旋转，双目放光，一声龙吟，身子延长化作**一头真正的有血有肉的金龙**（龙鳞闪金光）。
- 女子随即身影渐虚，消失不见。

## 四、金龙夺元神与一木子拦截

- 金龙头顶五张黄纸漂浮，散出牵制之力；临近时一个**沧桑的声音**喝出「**毒火**」，五符之一散发火光，金龙全身弥漫剧毒火海，横扫之下直接卷起玄宝上人将散的元神欲逃。
- **参天巨木裂开**：星空崩溃中那株一直无变化的参天巨木咔咔裂开巨大缝隙，一道青光中走出青衣苍老老者，长笑踏步，掐诀虚幻出一根巨木撞去。
- 老者自报家门：「**老夫罗天远古修真家族第九长老一木子**，此番，岂能让你逃掉」。
- 金龙张口散出充满浓郁死气的黑土——「**葬土**」。
- 一木子变诀为掌、虚空一拍，雷鸣风暴倒卷；大袖一甩，身后出现一排排**高与天齐的参天巨木**形成密集防护，挥手催木逼得金龙不断后退，笑称「你跑不掉」。
- 武东禅再度临近欲助，被清水冷哼中右目红光冲去阻拦；炎雷子趁机将仙界碎片漩涡放大无数倍。

## 五、望月吞龙、遁入虚无

- 望月怒火已失理智，不但恨玄宝上人，更把四周所有人一并牵连。
- 张开大口猛吸（吸力之大连自身都震动），古神手臂五指快若闪电扫开一切阻挡者，一把抓住金龙、迅速收缩并**扔入口中吞噬**——在望月看来，杀之不足泄愤，要把这个令它受伤的修士生生吞噬消化。
- 吞龙后望月不向前游，而是**一头钻入星空崩溃形成的漩涡虚无**。

## 六、四人追入望月口中

| 追入者 | 动机 |
|---|---|
| 清水 | 对玄宝上人元神志在必得，欲从其口中知晓**当年仙界剧变** |
| 武东禅 | 身为**地玄殿**之人，与玄宝上人关系密切 |
| 王林 | 「他等得，就是这个机会」；全身爆出雷鸣，借雷光之力速度快至不可思议 |
| 一木子 | 眼中精光闪烁，「也不知打着什么主意」——动机存疑 |

## 七、炎雷子赠仙界碎片

- 炎雷子略一犹豫后**放弃进入**，因罗天与联盟大战仍需他主持。
- 虚空一抓取出巴掌大小的仙界碎片扔给王林：「你立下大功，此物可让你此行安全，有此物在，老夫也知晓你的方位，可以救你与清水出来。」
- 王林接住后在碎片上感受到**一丝雷兽气息**，推测碎片内除强大的**碎片主魂**外还封印有雷兽。
- 王林答「多谢前辈」，随即钻入望月体内。
- 炎雷子看不明白王林入望月体内之因，只能归咎于清水，暗忖「**或许，此子另有所想**」。
- 望月身躯太大，沉入时把漩涡硬撑开不少，引发更大范围崩溃；炎雷子暗叹，转身去寻散开的罗天修士。

## 八、伏笔与待观察

- 玄宝上人元神是否仍存于金龙/望月体内，「当年仙界剧变」之秘尚未揭开。
- 水罗蓝裙女子的「君可识妾」——指向日后重逢与身份/形貌之变。
- 王林进入望月体内的真实目的（炎雷子未看破）。
- 一木子（罗天远古修真家族第九长老）追入望月的意图不明。
- 炎雷子所赠仙界碎片内封印的雷兽与碎片主魂，后续或有用。
