# 第九卷 云海之巅 · 第1353章 闪雷之战！（七）

> 归属提示：本章正文直呼「王林」本名；据世界状态须知，王林自第1242章起以一部分元神夺舍「于非」之身、冒其身份潜入闪雷族，本章一切言行归【王林】。

## 一、吞噬太古雷龙魂魄：雷之本源暴增

- 八条太古雷龙的魂魄被撕裂成数份、正飞快消散，王林元神一吞，先摄入其中**三成**。
- 残魂入体，王林元神内雷霆疯狂爆发，化作十丈粗、千丈长的银蛇之电，如抽打天地星空；一股难以形容的雷霆之威轰然扩散。
- 星空中一切闪电、雷霆与雷有关之物在其心神中飞快幻化，他**隐隐把握住了一些什么，却仍有些模糊**。
- 隐藏于元神内的**雷之本源**如心脏般怦怦跳动，每跳一次便暴增，诞生更多本源之力。
- 王林元神再化**吞魂**大口，天地色变、星空撕开无数裂缝，剩余全部太古雷龙魂魄尽数涌入。

## 二、元神进化：从雷龙之形到闪电图腾

| 阶段 | 元神形态 | 说明 |
|---|---|---|
| 妖灵之地 | 吞噬半条太古雷龙，化作雷龙模样 | 起点 |
| 岁月造化 | 渐渐转化形成本源，几乎化作一道雷霆 | **仅是「几乎」**，尚未真正成为天地雷霆 |
| 本章 | 颠倒乾坤般异变，向真正的雷霆元神进化 | 太古雷龙魂魄推其向圆满过渡 |
| 收缩后 | 雾气消逝，化作**巨大的闪电图腾**，外有灵念之雷旋转组成雷图 | 威压不弱于不灭之雷 |

- 此前其元神虽与闪雷族**不灭之雷**同层次，但同层次内仍分强弱；本章这一差距被飞快抹平。
- 雷之**半源**气息一散：环绕闪雷族的雷域齐齐后退，闪电颤抖、雷霆臣服；圣地庙宇上连接天地的不灭之雷发出**交战至今第一声轰天雷鸣**——仿若从太古传来，如庞大雷修察觉自身危险而发出挑战咆哮。

## 三、元神归位与七万雷层

- 大长老欲趁隙逼近，王林雷图后退印入眉心、元神归位，全身轰鸣，肌肉、骨头、五脏六腑尽数弥漫雷霆之力，**整个人如同化身雷霆**。
- 右目本源印记幻化，较方才**强十倍不止**。
- 抬手一挥，布下蕴含其意志的细密雷霆之网，坚不可破：除非在雷之半源上能与他对抗，否则同为雷修亦无法打开。层数由十、百、千、万迭至**七万层**，破而复原。
- 大长老以天人第五衰修为双手一撕，硬撕开上万层，旋即恢复；再喷血化血色雷光、眉心族印闪烁、凝血雷劈入，崩溃六万层，仍瞬息恢复。
- 战力分析：大长老一身修为全在雷上，与王林拼的是**雷霆操控**；换作其他天人第五衰修士轰杀王林要简单得多，正因同为雷修才如此麻烦。

## 四、天人第五衰的底牌：生命神通

- **天人第五衰**为第三步之下最强者，远超天人第四衰所有修士，前提是施展唯有该境界可发挥的独特神通——**生命神通**。
- 机理：牺牲自身寿元、挥散生机，强行推动神通之术，可发挥出**蕴含一丝第三步气息**的降临。
- 大长老此前从未施展：其寿元生机已然不多，须时刻封印修为以减缓流逝，如此挣扎生存、等待第三步机缘。
- 眼见王林后退加速且手持灵符，他不再顾惜。

### 祭祖通天

> 「祭祖通天，那万古前降临我族的不灭圣雷，以吾奴之身份，祭给年轮五百年寿元生机，换作圣体，请圣雷降于我身，化作混沌不灭雷」

- 咒语出口，眉心**族印**大放夺目之芒。
- 天地间浮现一个**无边无际的巨大罗盘**：弥漫万古沧桑、其上有残破，好似经历某场大战后险些崩溃；闪雷族星域之外亦可清晰得见。
- 罗盘威压一至，王林七万雷层即发出不堪承受之声；王林神色一变、死死盯住罗盘，捏灵符的右手动作一缓——他想看清这罗盘为何物、天人第五衰的神通到底多大。
- 罗盘**顺行转动小半圈**，好似岁月流逝、天地运转刹那度过无数。
- 代价：大长老面色苍白，魂魄似被切割一部分，脸上死气弥漫（瞬息即散）；罗盘吸足寿元生机后消失。

## 五、不灭之雷降临与王林遁走

- 罗盘消失刹那，圣地不灭之雷轰鸣，**分出一道**破开天地直奔战场，经大长老右手一指，如天劫般落在七万雷层上。
- 七万雷层瞬间全部崩溃，恢复亦再崩瓦解，可怕雷威弥漫。
- 王林瞳孔一缩，毫不犹豫捏碎手中**通往七百万天地的灵符**——身后现漩涡黑洞，一步踏入，身影消散。
- 不灭之雷闪烁中直接追入；闪雷族大长老略有犹豫，眼看漩涡将散，身子一晃亦冲入漩涡黑洞。

## 六、要点与悬念

1. 王林战略目标已由缠斗转为**寻安全之地闭关消化**（原话：不可与此人继续恋战）。
2. 闪雷族大长老与圣地不灭之雷对王林的成长同步产生「危机感」，暗示王林的雷之本源可能威胁闪雷族根本。
3. 万古罗盘的残破来历、「以吾奴之身份」措辞暗示闪雷族与不灭圣雷之间的主从/献祭旧约，为后续伏笔。
4. 三方（王林、不灭之雷、大长老）先后进入同一漩涡黑洞，战场将转往**七百万天地**。
