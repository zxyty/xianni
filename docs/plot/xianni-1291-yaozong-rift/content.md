# 第1291章 妖宗裂缝

**卷次**：第九卷 云海之巅

> 归属提示：本章「吕子浩」即王林化名（自第1063章由吕烟菲奉上）。本章主视角为王林本人行动。

## 一、离开无极宗

- 王林目光扫过下方无极宗六老后收回，右手血剑赤光一闪，化作一滴红色血液落入其眉心，深深刻印后渐渐消失（留印/烙印手段）。
- 右手一挥，风暴弥漫，卷着白发（白衣）老妪一同消失在无极宗众人视野中，急速穿行星空。

## 二、王林的自我评估：战力与目标

### 血剑（古神法器）
- 来历：不知是几星古神以「星点」祭炼的法器，有惊天之威。
- 王林现为**六星古神**之身，只能发挥此剑**三成之力**；但仅三成即可斩下世间任何一个**天人第一衰**神通修士。

### 战力阶梯自评
| 状态 | 可敌 |
|---|---|
| 与水道子一战前（半只脚踏入碎涅） | 苦战天人第一衰，需付出代价，取胜艰难 |
| 当下（未开封印 + 道境所悟第一个道术加持全身） | 足以战胜天人第一衰 |
| 当下 + 古神法器（血剑） | 可与天人第二衰一战 |
| 打开封印后（有望一举达碎涅中期） | 天人第二衰非其对手，应可战天人第三衰 |

### 设定：天人衰劫
- 分第一衰至第五衰，各衰之间差距极大。
- 每一衰若不成便会死亡，若成则获得难以想象的力量——**以生命换来之力**，很难跨越。

### 封印与时间差
- 王林尚未打开限制修为的封印。
- 外界十年，而他在**天逆**内的**道境**中感悟了许久；随封印打开，修为暴增，有望一举达到**碎涅中期**。

### 目标与心境
- 罕有地感受到自己的强大：「握住拳头，好似握住了整个天地一样」，自信弥漫。
- 立誓：**成为第三步大能，杀水道子，杀当年以七夕术骗我生机的罗天上古家族老祖**。
- 心境转折：与水道子一战前，第三步大能于王林如同真正的仙神、如大山压下无法反抗；经修为提升、与水道子一战、道境感悟这一切大造化后，第三步的神秘面纱被撕去、不可战胜的传说崩溃，存留下来的只有王林的**弑**。
- **弑之真义**：以弱杀强，蝼蚁咬死大象。

## 三、首入九阶星域

- 带着信心与去救**李倩梅**的坚定，王林一路破开**八阶星域**，第一次踏入云海**九阶星域**。
- 九阶星域雾气中存在**十二阶凶兽**；王林无暇斩杀、亦不愿被耽搁时间，一入雾中便全身修为轰然爆发，滔天煞气弥漫，雾气倒卷，其内化作雾气的凶兽纷纷避开。
- 神色阴沉、萧杀之气更浓，立誓：「神宗，水道子，我此生必杀你」。
- 白衣老妪立刻指路，二人破开雾气直奔**妖宗战场裂缝**疾驰。

## 四、神宗密室：水道子的十年之苦

- 王林踏入九阶星域的刹那，**九阶神宗**内一间密室中，正盘膝打坐的**白发童子水道子**发出凄厉惨叫。
- 状态：满脸青筋鼓起，全身散发无尽七彩之芒；容颜急速衰老，衰老到极限的刹那又逆转，周而复始，生机与死气交错之痛非常人可忍——这种痛苦他已承受**十年**。
- 双目已无瞳孔，彻底被七彩之芒取代。
- 誓言：「小杂种，老夫所受的痛苦，早晚有一日，要让你千万倍的偿还」。
- 推断其**主人**：即便没死，也定然极为虚弱，否则十年前他绝逃不了。

## 五、设定补充：妖宗

- 云海星域九阶中**最为神秘**的宗派。
- 门人弟子不多，但随便一人都是惊艳之辈。
- 长期无数万年驻守**裂缝战场**，抵抗一次次凶兽入侵，故而杀戮极重；且几乎从不离开妖宗。
- 在云海修士心目中隐隐可与**神宗**对抗。
- 传闻妖宗原本从神宗分离，却不听神宗之命，此事透着诡异——无论真假，都说明妖宗之强。
- 驻守战场无数年保得云海平安，受云海修士敬畏：**敬的是其德，畏的是其秘**。

## 六、伏笔与待续线索

- 王林封印何时打开、能否一举突破碎涅中期。
- 妖宗裂缝战场的具体形态与妖宗对王林（吕子浩）的态度。
- 水道子出关后的报复，及其「主人」的存殁与虚弱状态。
- 罗天上古家族老祖（以七夕术骗王林生机者）这条旧仇线。
- 救李倩梅之目的与其已死状态之间的张力。

# 妖宗裂缝战场：铁血守界与王兽现世

## 一、妖宗的性质与地位（云海视角）

- 在云海修士看来，妖宗之人已无法以「修士」形容，更像凡间皇朝的**军队**：铁血、无情。
- 其所作所为守护了整个云海。因妖宗存在，无数万年来云海修士得以安详平安、相互内斗、获取资源。
- 若有一日妖宗不在，从**裂缝战场**内冲出的凶兽便失去第一道防护，将给云海带来难以想象的崩溃。
- 因这份特殊使命，凡来到战场的云海修士对妖宗**极为恭敬且必须听命**；违令者妖宗立刻杀之。
- 例外：极为绝伦之人在获得妖宗认可后，有机会成为妖宗门人，受妖宗重视，妖宗对其起惜才之念。

## 二、李倩梅与妖宗的旧账

- **李倩梅是当年受妖宗认可的三人之一**——她与另两人一同斩杀了一头**王兽**，因而得到认可。
- 正因此，她明明违反命令离去，妖宗也未以杀阻止。
- 但李倩梅一走便是**十年**。在妖宗看来，没有任何理由可以离去十年；此事若不惩，妖宗也就不是妖宗了——妖宗定然愤怒。

## 三、战场现况

### 地形与规模
- 妖宗由**六个成环形排列的修真星**构成，其旁便是那一片如裂缝的沟壑。
- 裂缝外，**数千**来自云海各地的天才之辈正疯狂厮杀，种种神通宣泄、法宝之芒弥漫星空，轰隆巨响惊天。

### 裂缝凶兽
- 一头头样貌各异的凶兽嘶吼挣扎，欲冲出撕裂一切生灵。
- 其身上凶焰与云海雾气中的凶兽**有极大区别、远远超过**——它们是在无尽杀戮中存活下来的。
- 本次凶兽数量太多，数千修士中已有**数百人**肉身被撕裂，部分元神逃遁不及、惨叫中崩溃。

### 六名强者（四男二女）
- 所在之处凶兽刚现即死，血气散开，各自四周**数百丈内一片空旷**；四周修士远远避开，对其充满信心。
- **四名男子**：三人中年、一人老者，修为俱达**碎涅大圆满**；其中老者**隐隐有要达天人第一衰的迹象**。四人杀伐果断、出手狠辣，一击即可让凶兽惨亡。
- **两名女子**：一为中年美妇；另一约二十四五岁，神色冰冷、双眼无任何情感，手持**金色细剑**，出手时全身隐现无数金丝，凡被金丝碰到的凶兽立刻凄厉惨叫中四分五裂。

### 三名妖宗之人
- 立于数千修士身后的**星空虚无**中，全身充满蓝色雾气，看不清其内样子。
- 三人气息诡异地连接在一起，**凝聚成天人第一衰的威压**；其个人修为并非第一衰，但蓝色雾气连接下**合击可发挥第一衰之力**。
- 对修士死亡、凶兽崩溃视若无睹，只是望着裂缝，不知在想什么。
- 他们才是「真正的妖宗之人」；修士退下吞服丹药打坐时，偶尔望向三人的目光充满敬畏。

## 四、转折：王兽现世

- 厮杀正酣时，裂缝内凶兽**齐齐向后收缩**，嘶吼咆哮，一股强悍气息骤然爆发，四周凶兽纷纷散开凶焰。
- 众修士议论：
  - 今日凶兽数量超过以往，原来是**有王兽出现**。
  - 王兽出现次数不多，但每次出现都会造成大量修士死亡；同时王兽也代表**机缘**。
  - 「当年那李倩梅三人就是一同杀了一个王兽，故而被妖宗认可，今日又有王兽，却是我们的机会。」
- 所有修士神色大振、纷纷后退戒备；六名强者亦退后。
- 持金色细剑的冰冷女子目光一闪、露出煞气：**「王兽李倩梅能杀，我也能杀。」**
- 唯独三名蓝雾妖宗之人始终没有半点变化。

## 五、伏线

- 与此同时，**王林**（本阶段以化名「吕子浩」行事）在**白衣老妪**的指路下，距此地越来越近——王林、妖宗、王兽与李倩梅旧账即将交汇。
