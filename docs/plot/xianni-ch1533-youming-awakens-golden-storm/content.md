# 第十卷 叱咤界内 · 第1533章 幽冥醒！

## 一、战老鬼取弓，触发弓弦七彩

- 出场者外貌：一张极为苍老、皱纹如沟壑年轮的脸；眉心有一道形状模糊、似无数年前被生生烙下的印记；面上无任何须发，仿佛本就不该长出须发。
- 封界阵法外的**掌尊**（掌印小厮）死死盯着战老鬼，眼中滔天之恨却不敢再开口，携其首徒后退疾遁而走。
- 那身影模糊的老者（战老鬼）临近漂浮星空的巨弓，抬右手抓去，将抓之际轻咦一声，随即速度更快向前一抓。
- 弓弦末端闪过一道**七彩之芒**，弓弦骤然断开。老者眼露精光：「果然有七彩」。

## 二、断弦横扫，封阵被抽出缺口

- 断弦内传出凄厉咆哮，七彩之芒环绕下急速飞开，作半弧形猛甩；弦身骤然无限延伸，所过之处星空被直接分割。
- 战老鬼冷哼中抓住弓身甩向界内，自身后退仍被断弦抽及：
  1. 右手连写**七个「战」字**——七字被弓弦尽数崩溃碎灭；
  2. 喷出一口白色气息，挥舞成**一个白色战字**——与弓弦相碰略有一顿；
  3. 借这一顿从容退入**封界大阵**内。（入阵瞬间白色战字自动消散。）
- 战老鬼放话：「**七彩道人**，你果然还是出手了，这是你第三次机会，也是最后一次。**百万修灵印**既然你要主动破开此印，老夫便等着就是。」
- 弓弦落于封界大阵：全阵通体颤抖，阵灵未及幻化，巨大裂缝自封阵蔓延扭曲，弓弦在封阵上抽开一道**细长缺口**并直接穿透入界内。

## 三、数万界外修士尽灭

- 界内距封阵最近的并非召河、罗天修士，而是被**王林以古息叶封印**困住的数万界外入侵修士。
- 弓弦落在古息叶封印上呼啸破开，弧形一甩，无一声惨叫——数万界外修士肉身根本无法抵抗弦锋，全部被分割崩溃。
- 战老鬼在弓弦抽来刹那冷笑消散，来去皆突然，似只为见证某事并把弓取入界内；离去时看都未看那弓一眼，视此地修士（含王林）如蝼蚁。
- 留言（余音回荡后消散）：**此弓若认主则为至宝，但无人可以让其认主；以生机推动则弱不堪击。你们谁喜欢，可拿去玩耍。**

## 四、王林夺弓：被弓弦拦腰截断

- 断弦之弓被甩入界内，方向**正是王林所在之处**——「是巧合，亦或者不是」。
- 王林脑中瞬间浮现「拿，还是不拿」两个选择，果断决定：「此弓，我要了。」
- 夺弓代价：
  - 右手抓住弓的瞬间，大力涌入，**右手直接崩溃、血肉四溅**；
  - 左手再抓，左臂轰鸣、血肉模糊但未崩溃，死死抓住此弓；
  - 甩动的弓弦在弓内大力下猛地一扫，**从王林腰部直接穿透，将其身体一分为二**，腰部以下崩溃，只剩上半身，鲜血弥漫、身子被抛出。
- 王林感知弓内秘密：
  - 弓内有极强**排斥之力**，似天下间除某一人外无人可让其认主；
  - 想操控此弓，**必须祭献自己的生机请求**，否则纵然拿在手里也无法开弓。
- 此等伤势，除之前**道古墓地**外很少出现。

## 五、幽冥兽苏醒，喷出金色风暴

- **幽冥兽与王林本命相连**，腰斩剧痛传入其沉睡心神——吞噬金色风暴后一直沉睡的幽冥兽**骤然苏醒**。
- 一道幽光自王林体内飞出，转眼无限扩张，幽冥兽庞大身躯现于崩溃星空之中；巨痛之下它似忘记恐惧，发出惊天低吼。
- 张开大口并非吞噬，而是把**尚未消化的金色风暴**疯狂喷出，金光急速扩张直奔封界大阵。
- 金色风暴之强**足以崩溃一个星域**，罕有人可抵抗。

## 六、各方反应与战场终局

| 对象 | 结局 |
| --- | --- |
| 掌尊（阵外） | 见风暴与幽冥兽面色大变，双眼鼓起，露出激动与骇然之色 |
| 界内召河/罗天/云海数万修士 | 被红杉子等人不顾一切以神通强行挪移出战场，随后众人自身也急速离去 |
| 王林 | 红杉子等有心相救，但其所在正是金色风暴喷出之处，毁灭之力无法靠近 |
| 灵动上人、周瑾 | 在风暴爆发中不得不退去离开 |
| 封界大阵 | 大范围崩溃 |
| 封尊玉佩 | 光芒扭曲下急速消散，顺封阵隐入八方 |
| 天罚殿殿主 | 因玉佩离去而脱困，旋即被金色风暴吞噬，身体元神香火烟消云散 |
| 太古星辰（界外） | 被风暴波及，大范围崩溃 |

- 最终以战场与封界大阵为中心，一切尽被金色风暴笼罩：**封阵崩、界外区域崩、界内星空崩**；扩大到一定程度后发出震动界内界外的巨响，彻底爆开。
- 风暴过后，第一战战场化作一个**弥漫无尽星空的巨大黑洞**，阻隔在封阵之内；轰鸣余音在此漩涡黑洞内不断传出，未来十年、百年、千年、万年将永恒存在，似无消散之日。
- **幽冥兽**在风暴冲击弥漫而来的刹那，张口将**王林与那把弓一同吞入口内**，身子一散化作芥子消失。
- **第一战，就在这种奇异的结尾下结束。**

## 七、悬念与要点

1. 七彩道人为何第三次、也是最后一次出手破「百万修灵印」，战老鬼摆出等待姿态。
2. 此弓真正之主是谁——「除其任何之人，无人可以让其认主」。
3. 王林重伤断体、连人带弓被幽冥兽吞入，去向不明。
4. 掌尊见到幽冥兽时的激动与骇然，暗示其对幽冥兽来历知情。
