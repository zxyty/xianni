# 第1898章 气绝！！

## 一、两名绿魔使者力竭而亡
绿魔炉外，十年之间持续喷吐元神之气的两名绿魔使者元神极度萎靡黯淡。数日后其中一人喷出最后一口元神之气后元神消散、肉身失去光彩彻底死亡；不到半柱香，另一人元神亦黯淡消散。绿袍老者对陪伴自己多年的二人之死毫无侧目——他此刻全身散发腐朽气息，已处半死之中，全凭一股意念支撑，否则早已归墟。

## 二、绿袍老者召唤绿魔大人
老者由盘膝改为跪拜，以「我族代代绿魔祭祀」的身份诵念古老咒语，请绿魔大人苏醒降临、夺舍其献上的肉身。

- 蝎子建筑骤然颤抖，庞大魂息苏醒扩散。
- **九缕绿色之气自九个方向呼啸而至**，在绿魔炉上方凝聚成数千丈的绿色蝎子虚影，遍体伤痕、气息微弱，却有无上威压，整个绿魔洲为之一颤。
- 此虚影仅为绿魔蝎被镇压之魂的**分魂**；真魂困于镇压无法脱离。其复活路线：分魂夺舍得肉身 → 再设法吸收被镇压的真魂 → 真正复活。

## 三、极致谨慎的探查
蝎魂开口「是你召唤本尊」，声如法则却掩不住虚弱。绿袍老者叩拜禀报：肉身已按要求改造完毕，体内再无神智与元神。

- 老者深知：肉身内若残存元神，夺舍将生变故，可能功亏一篑、甚至令本已虚弱的绿魔蝎再受重创——这正是他此前反复试探的原因。
- 蝎魂目光**连续九次**扫过王林肉身并深入体内，仍**感受不到天逆**，更未发现被天逆隐藏的王林元神。
- 设定补充：**仙罡大陆本地诞生的修士，即便无元神绿魔蝎也无法夺舍**；它只能夺舍与自己同样来自天外的修士之体——这正是王林肉身「完美」的原因。

## 四、入体、蛰伏、开始夺舍
蝎魂化幽光穿透绿魔炉扑向王林，却仍不立即占据，而是在外弥漫、神识横扫多次后才从四面八方钻入。

| 时间 | 动作 |
|---|---|
| 入体后 | 不夺舍，先观察 |
| 三天 | 再降下部分蝎魂，缓慢扩散 |
| 七天 | 失去耐性，占据王林身体约七成 |
| 随后 | 魂影沸腾，直扑脑海，蝎影开始凝聚 |

## 五、王林的百年之赌：反吞噬
王林元神始终不动。他等的不只是肉身造化，更由绿袍老者的极端谨慎推断出：**肉身内一旦有元神，夺舍必败，绿魔蝎无法复活**。于是索性一赌到底，以己身为诱饵——「绿魔蝎要吞噬他，他同样要吞这个绿魔蝎」。

出手时机的判断：蝎魂未夺舍时抽身极易，唯有其真正开始夺舍才难以脱离，那才是最好的机会。

**爆发**：脑海中蝎影刚凝聚一半，王林元神自天逆内轰然扩散，直扑而上。没有神通、没有法术，只有纯粹的吞噬。

- 蝎魂猝不及防，尖叫反抗，凶焰骤起，双方在体内疯狂互噬。
- 一炷香后局面凶险，但蝎魂本就虚弱、又是分魂，而王林**准备了一百多年**，渐落下风。
- 吞噬不下数万次后，蝎魂大恐生退意——这一缕分魂是无数年才凝聚而成，一旦消散便再无苏醒机会。它对祭祀一族恨之入骨，认定一切皆因祭祀而起。
- 蝎魂急退，王林紧追不舍；其好不容易退出头部、将冲出身体时又被狠狠吞下一大口，惨叫中自王林天灵钻出，**身形已缩小近半**，仓惶遁向天空。

## 六、误判的旁观者
炉外绿袍老者只见绿魔剧烈颤抖，先是一愣，转而自我说服：「定是大人不太满意这个肉身的改造，要在夺舍中把这肉身再次改造一番。」越想越觉正确，笑容更盛——认为能被绿魔大人亲自改造，正说明此肉身价值。

## 七、王林出关：四大本源真身
蝎魂离体，王林元神笼罩全身，闭合一百多年的双目蓦然睁开——天地轰鸣，绿魔炉轰然崩溃化作碎片，王林一跃而起，连唤四身：

1. **火焰真身**：左目火海滔天，身后化出与其一模一样的火焰真身。
2. **雷霆真身**：右目闪电轰鸣，道魔宗宗主全力凝聚的雷霆本源真身在融入王林意志后凝聚现身。
3. **大地真身**：十万八千汗毛孔散出惊天黄芒，凝为第三具本源真身。
4. **水本源真身**：原融于血液之内，青筋血管鼓起、红芒刺目，虚影于身旁幻化凝实，成第四具本源真身。

四身齐出，气势惊天动地。此刻王林修为「还是如常」，但只需平静下来、心念一动即可暴增——眼下却不是平静之时。

## 八、金光镇压与九尺阴刀
- 王林双目爆出金光，蕴含惊天镇压之力，其中竟藏有**当年仙祖的仙极剑之威**；蝎魂被扫中，魂影立刻颤抖。
- 王林右手掌心一阵剧痛，一把带滔天阴气的骨刀直接伸出，化作**九尺阴刀**；四具本源真身右掌亦同时出现九尺阴刀，五者齐向逃遁的蝎魂轰然一斩。

## 九、结局：绿袍老者气绝
绿袍老者呆呆看着这一幕，喷出一口鲜血、怒睁双目，当场气绝——原文点明：**他是被自己生生气死的**。

## 关键转折
- 王林百年布局成功：从「被夺舍的祭品」翻转为「吞噬绿魔蝎分魂的猎手」。
- 绿魔蝎复活计划遭重创，分魂被吞噬大半后仓惶逃遁。
- 王林出炉即以四大本源真身完整状态现身，绿魔洲一方主事者（绿袍祭祀）当场毙命。
