# 第1183章 不要动（第二更）｜第九卷 云海之巅

## 一、场景
- 地点：七彩界深处一条两侧为山脉的**狭路**，先前被十二阶化雾凶兽的雾气封堵。
- 在场：苍松子、端木童子、青衫老妪、庞姓老者、陈天军、王林（此时以化名「吕子浩」行事）。
- 对手：一头**十二阶化雾凶兽·蛟龙**，身长约千丈，修为碎涅期大圆满，头生一根黑角，肉身之力远超多数炼体修士。

## 二、围杀经过
1. **封印阶段**：端木童子飞剑破开蛟龙肉身，以曰月印记结成的「轮回封印」镇压，倒数「还有五息」；庞姓老者降神雷，苍松子放上万道剑雨。童子两度喷血，青筋暴起、双目血丝密布。
2. **玄冰吸生机**：青衫老妪的玄冰蔓延覆体，黑气自蛟龙体内散出被冰层吸走——王林一眼看出此神通可**吸收生机**，暗自冷笑「这帮老怪到现在还要隐藏神通」。
3. **封印崩溃**：蛟龙抬头震碎曰月印记，童子再度喷血无以为继；蛟龙自雾中抽身，玄冰随之崩解倒卷回老妪体外，黑气融入其体，其双目更亮。
4. **蛟龙反扑**：黑角射出黑色电网扩散百丈，吸摄天地元力与七彩之芒，幻化出无数蛟龙虚影环绕成漩，逼退苍松子等人；蛟龙张口即吐腥风毒雾，虽重伤仍将升空。七彩界中众人无法高飞，蛟龙一旦飞起将是灾难。

## 三、王林的两手：先取利，再定局
### 1. 雾中掠夺元晶
- 判断：蛟龙一旦由雾化凝实，雾中元晶便会并入其体内元力而消散。
- 心态原话：「**拿多少东西，就做多少事情，取这些元晶，用不着我来拼命。**」
- 行动：无视厮杀直入雾中，大袖一甩先收数百，穿梭速取共**数千枚元晶**。
- 缘由：常规此类凶兽会被圈养门派定期收割元晶，而七彩界无人来盗，故积年累月数量极多。
- 收手：察觉雾气翻滚欲凝实并向一方收缩，果断放弃继续采集、侧向避开；片刻后雾尽，现出蛟龙之尾。

### 2. 古神之力摔龙
- 蛟龙尾部升空之际，王林双臂砰砰作响、**古神之力**爆发，一步跃起扣住蛟尾。
- 两声怒喝「给我下来」「下来」，如神灵之音，将千丈蛟龙整个轮起、狠摔向狭路。
- 蛟龙挣扎反噬反使其体内古神之力运转更为磅礴。
- 结果：地动山摇，碎石滚落；庞姓老者见天空一黑疯狂后退，唯恐被砸而肉身崩溃。
- 论断：**纵使脱去蛟皮化身成龙，在古神面前也休想升空。**

## 四、战果与分配
- **陈天军**：先前独自潜入蛟龙头颅内，蛟龙头融化后飞出——他收取了**蛟龙之魂**，实为本战收获最多者（需外界众人牵制方能成事）。
- **青衫老妪**：手抚兽尸吐纳，黑气尽入其右手，蛟龙尸只剩皮包骨；老妪面色红润，**依稀年轻了一些**。
- **端木童子**：得王林所抛**轮回丹**，神色激动，抱拳道谢；判断此刻非服食之机，收起后打坐疗伤。
- **庞姓老者**：胸口血肉模糊靠于山脉，苍松子拍背赠丹，数个时辰后恢复。
- **王林**：数千元晶 + 骸骨下的一枚**玉简**（丹药转赠童子）。

## 五、震慑效应（关系变化）
- 苍松子：倒吸凉气，望望蛟龙又望望王林，**心中升起寒意**，之后目光时而落在王林身上，露出奇异之芒。
- 端木童子：舔嘴唇，看王林的目光**有了忌惮**。
- 青衫老妪：倒吸凉气，沉默。
- 庞姓老者：最恐惧者，想起王林先前的威胁之语，**口中一片苦涩**。

## 六、玉简伏笔与章末悬念
- 王林靠山脉坐下，神识扫过玉简，其中**记录了一件有关七彩界的事情**。
- 苍松子提醒：此地十二阶化雾凶兽还有不少，危险越大收获越多；众人起身继续深入（童子略作犹豫后跟上）。
- 王林读至「**原来这里是**」思绪骤断，猛抬头看向众人身后，瞳孔收缩、汗毛倒竖。
- 苍松子、端木童子同时一顿，青衫老妪与陈天军随后察觉，庞姓老者最后。
- 苍松子眼露恐惧传出神念：「**千万不要动**」——章终。
