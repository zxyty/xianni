# 第1680章 意外的发现

## 一、风仙界重逢蚊王

- 王林左侧的风仙界中风声呜咽，远处一道黑线横卷而来——那是**上万蚊兽连成的惊天之幕**。
- 最前方是**百丈大小、狰狞无比的蚊王**，遥见王林含笑目光即浑身颤抖，尖啸顺风而至，兴奋地直接撞来。
- 王林此刻**是分身**，承受不住蚊兽这般激烈的“拥抱”，遂右手向前柔和一拍，**荡起波纹环绕其身**，令其速度缓下。
- 蚊王以巨大口器不断摩擦王林身体，目露深深依赖，发出呜咽之声，似埋怨王林为何这么久才来寻它。**王林是它的主人，更如父母，此念已刻入其灵魂**。
- 上万蚊群环绕：一部分认识王林，后加入的则目露疑惑。
- 王林感慨：一生孤独，陪伴自己的只有那几只凶兽，其中**以这蚊王时间最长**。他笑拍其大头：“好像比以前要威武了不少。”

## 二、蚊王的异常进境

- 蚊王速度**远超当年**。王林细看后目露奇芒：此刻的它**已无限接近修士的第三步，类似修士的天人第五衰**。
- 隐隐只差一步，便可蜕变进化为相当于修士第三步的恐怖之力。
- 王林惊奇：“它到底得到了什么样的造化，居然能有如此进展。”（答案在第四节揭晓）

## 三、风仙界深处：蚊尸与三指之谜

王林令蚊王带路，掠过无数碎片大陆抵达**风仙界最深处**（王林当年曾来过）：

| 现场要素 | 状况 |
|---|---|
| 浓浓雾气 | 其中隐有一道**巨大裂缝**，透出森森寒气，不知通往何处 |
| 雾气下诸大陆 | **保持当年的样子** |
| 正中大陆上的人形雕像 | **已消失无影**（与当年不同，重要变化） |
| 数千丈蚊兽尸体 | 双目睁开无光、死气缭绕，横倒大陆之上 |

**尸体检验要点：**

1. 死去多年却**不腐烂**，如同风干，干枯之下**仍蕴蚊兽精华**。
2. 尸身仍存一股极强威压，王林清晰感到**类似修士的第三步**。
3. 蚊王以口器刺入吸噬，身放金光；身后上万蚊兽**无一敢上前争食**（等级压制/领属秩序）。
4. 致命伤在**颈部**：三个手指大小的洞，不仔细看极难发现。王林将三根手指探入，确认**是三指完整穿透而出**。
5. 王林惊问：“**这是什么神通之术，三指杀死此兽？**”
6. 此兽正是**当年从裂缝内挣扎飞出的那只巨大蚊兽**——大小已与当年不同，但气息极为相似。
7. **核心伏笔**：“这残留在此兽尸体上的三指气息，我隐隐有些熟悉……似曾在什么地方感受过。”（本章未解）

## 四、玉简实验：裂缝“两次撕开”的推断

王林首次如此近距离观察这道巨大裂缝，发现**边缘呈锯齿状不规则，但部分位置似有曾经连接过的痕迹**。

**实验步骤（王林的验证手法）：**

1. 取出一枚玉简，掰断为二，观察边缘细密不规则的碎裂之口。
2. 将两半合拢，以柔和之光将修为融入，把玉简**粘连修补**，仅余细密裂纹。
3. **再次掰断**——断口中既有“之前碎裂粘合处被重新分开”的，也有**全新的碎开之处**。
4. 对照裂缝边缘：形态**很相似**。

**结论与新问题：**

- 结论：这裂缝**定是曾经被撕开过一次，事后被修补上；若干年后再次被撕开**，故有此边缘特征。
- 假设：**第二次撕开或在风仙界崩溃之时**，此后这里成为蚊兽的天下。
- 未解之问：**第一次撕开是在什么时候？是谁撕开的？**

## 五、踏入裂缝：蚊卵世界

- 蚊王在裂缝外徘徊、频频回头露出急切之色，显然**这百年中不止一次进去过**。王林顺其意：“罢了，进去看看就是。”
- 王林原本来风仙界**并非为研究此裂缝**，是因蚊尸与三指之异才改变主意。
- 入内：寒气逼人，王林**谨慎起见先不散神识，仅以目光横扫**——此谨慎伴随其一生，绝不因修为提高而减少；修为越高，越明白天地之奇异。
- 所见：**一片充满荧光的世界**，荧光自一枚枚巨大卵形之物内透出——此处**弥漫无数蚊兽卵**：
  - 密密麻麻一串串，其内诸多蚊兽正等待苏醒，**一眼看去怕超过数百万之多**；
  - **越深处卵越多、个头越大**，甚至有**百丈大小的卵**，其内蚊兽散发金光已完全成型，隐隐随时可醒。
- 王林的蚊王一入内即欢呼嘶鸣，口器刺入一串卵中**一吸而空**——王林由此明白：**蚊王实力暴涨的造化，正是来自此地**。

## 六、章末悬念

- 王林沉默中散开神识，谨慎缓慢地扩展，直至**完全笼罩整个空间**。
- 刹那间他看到了此地全貌，**双眼露出震撼，下意识退后几步，猛地抬头**——本章至此收束，所见为何未揭晓。

3. 正中大陆上的**人形雕像因何消失**？
4. 裂缝之外究竟通往何处？数百万蚊卵之地的来历与归属。
5. 王林散开神识后看到的、令其震撼后退的景象是什么。
