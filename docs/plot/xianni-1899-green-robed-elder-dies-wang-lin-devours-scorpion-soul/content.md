# 第1899章 奉献！

## 一、绿袍老者之死

- 绿袍老者以其眼力看穿全局：王林竟用**他亲手给予**的镇压目光与万古阴刀，反过来斩杀绿魔蝎。
- 本就寿元不多的他怒极攻心，喷出一口鲜血气绝身亡，死前最后一句话是「我恨啊」。
- 死后双目怒睁，恨意滔天弥漫全身，似要化作厉鬼。
- **他给予王林的一切（清单）**：
  1. 坚韧不断的肉身
  2. 镇压天地的目光
  3. 仙祖发丝形成的经脉
  4. 一把万古阴刀
  5. 大地本源——助王林凝聚出两具真身
- 王林态度：此人对他造化极大，但**一切用意都是为了陷自己于绝地**，故无半点感激。

## 二、五刀斩绿魔蝎魂

- 绿魔炉仍在崩溃，碎片倒卷化作风暴横扫四周。
- 绿魔蝎魂尖叫升空疯狂逃遁，心中亦恨绿袍老者（因其才落此下场），但老者已死、恨无从宣泄，化作愤怒。
- 王林一头白发飘舞，双目蕴含天地威严，手持骨刀/阴刀跃起一斩；**身后四大本源真身同时幻出阴刀紧随**。
- 五刀连环：第一刀使蝎魂扭曲，第二、三刀接踵，蝎魂喷绿雾欲挡，第四、五刀斩天而来。
- 结果：蝎魂被斩成**六部分**。下方四部分被王林一吸，化作丝丝魂气直奔七窍，四周云雾缭乱仿若仙人；余下两部分惨叫逃遁，消失在蝎子建筑内，去向不明。
- 魂雾最终收缩为**七条手臂粗细的魂气**，钻入王林七窍。

## 三、三位天牛魂铠拥有者的目击

- 来者：**云逸封、唐佳（庸佳）、边云**——天牛洲除王林外其余的天牛魂铠拥有者。
- 不知为何在阔别一百多年后同来绿魔蝎庙；入庙后一路平坦、几无阻拦，直达最深处，却撞见这震动灵魂的一刀。
- 反应：
  - 云逸封、唐佳愕然：「王林他竟然在这里」；边云瞳孔收缩：「他不是死了么」。
  - 王林目光一扫，云逸封如被看透、如遭天地镇压（旋即消失）；唐佳面色苍白，不敢相信百余年后王林目光如此恐怖。
  - **边云（曾与王林交战）** 受创最重：心神如雷霆轰鸣，蹬蹬蹬退后三步，面色煞白、汗透全身；隐隐感到镇压自己的苍穹即对方目光所化，**目光内似有一把尚未完全出现的剑**，一旦全现自己将被生生撕碎。
- 王林仅说二字：「**离开**」，如同天地法则。边云疯狂退出数千丈方缓过来。
- 三人虽退却未离庙——**任务未完成，蝎庙尚未完全毁灭**——只在远处停下，因忌惮王林不敢轻举妄动。

## 四、鬼魂与绿袍：彻底的「奉献」

- 绿袍老者尸体散出黑气，凝于头顶化作**巴掌大小黑雾**，含滔天恨意与至极冰寒，四周骤然阴冷。
- 王林神识触及的刹那，心神内回旋沙哑狰狞的疯狂嘶吼：「我恨啊」。
- **品质判定**：比王林在极天草原所杀空劫修士处获得的鬼魂强大无数倍不止，为**上品巅峰、无限接近绝品之魂**。
- 王林大袖一甩收走此魂。
- **用途规划**：此魂 + 极天草原所获鬼魂 → 炼制一杆**近似绝品的鬼帆**；配合手中**大魂门护山大阵副旗**，可发挥接近绝品的幻术。
- 王林神色古怪、心生复杂，长叹一声，大袖甩出将老者尸体化作飞灰。
- 地面只余那件绿袍：**神识无法穿透、探不到内部**，颇为奇异，王林一并收走。
- 至此绿袍老者「彻彻底底、全部奉献给了王林」——呼应章名。

## 五、章末伏笔

- 王林体内修为**隐隐有攀升迹象**，露出兴奋与激动：「我之前的修为还是太弱，希望这一次，可以站在这**仙罡大陆**的高处」。
- 杀机再起：「还有那**道魔宗**，我曾发誓，那誓言，在这一百多年中，永不忘」——闭眼即见极天草原上一个个熟悉的人头飞舞。
