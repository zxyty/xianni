# 第1889章 道魔宗主

## 一、局势
- 地点：**绿魔洲与孟土洲的边界**，王林距孟土洲边界约五百里。
- 道魔宗开启**六座（后文作七座）大型传送阵**，一波接一波传送修士（每波数百人）围杀王林一人；满地头颅说明其已不惜代价。
- 王林判断：时间越长生机越灭，必须速战速离。
- 制约：**魂铠**（天牛穴所得，提供空劫级战力）时效将尽。

## 二、四波围杀与王林的神通序列

### 第一波—「残夜」
- 残夜二字出口，虚幻海水弥漫遮盖天地，四周沦为黑夜；继而骄阳抬头，散发**撕开黑夜**的力量。
- 结果：冲来的数百道魔宗修士**尽数身死元神俱灭**；传送阵中正凝聚的第二波数百人身子未成形即崩溃。
- 王林面色苍白，欲毁六阵而不能——阵法在残夜之下仍完整，极为不凡。

### 第三波—神、妖、魔与「古道无仙」
- 组成：数百修，含**四名空劫中期**、**一名空劫后期**。
- 王林爆发**道古之力**，身后幻化撑天**道古虚影**（因先前绿魔使者自爆而略显模糊，仍具心神压迫）。
- 三连击：
  1. **神震·兵修列位**——数百修身不由己排成军阵，波纹回荡致半数七窍流血；
  2. **妖术·烽火成山**——天灵冒出狼烟凝作巨山下压；
  3. **魔道·生死逆动**——大半崩溃惨死。
- 收尾：**「神、妖、魔、古道无仙」**（道古修为＋魂铠空劫之力融合）灰色涟漪扩散，数百修齐灭；空劫后期老怪倒卷仍被涟漪擦中，面色苍白、双脚现**石化**，需连点自身以气息抗衡。
- 代价：王林嘴角溢血，道古之力几近耗尽，魂铠松软、部分化作黑色细丝。

### 第四波—神通倾泻
- 王林抢在魂铠散尽前倾泻所有神通：**役灵印**（巨大六指掌印）、**七彩之枪**（三变）、**阴月有晴**（化血暗之月行腐蚀杀戮）、**流月之术**（岁月逆转）、**本源凝散**。
- 结果：第四波数百修几乎全灭，仅三人生还且深怀忌惮；**七座传送阵中三座崩溃**。

### 拦截与突围—虚火、血剑、鬼帆
- 剩余**四座传送阵竟能瞬移**（此地修士做不到），一闪现于王林身前五十里，放出上百修士横向拦截；身后残存空劫修士合围，前后夹击。
- 王林以**火本源真身**扩散笼罩八方，低吼「虚火，焚烧」——以众人心中无穷思绪为薪，上百修士当场燃烧成幽光火海。
- 「挡我者，死」：咬舌驱疲，手持**血剑**，左手挥出**大魂门鬼帆副旗**化黑雾恶鬼，横冲百里；沿途上百修死亡大半，余者骇然倒退。

## 三、进入孟土洲
- 踏入孟土洲一瞬，**全部魂铠化细丝凝于右侧面孔，成天牛图腾**；虚弱感被强压。
- 身上仍存**归一宗人形土铠甲**（已崩一半，防御仍强）。
- 规则：两洲之间**散修可越，道魔宗弟子大量进入则大为不同**——故道魔宗此前才以绿魔修士自爆、云空出手拖延，力图把王林困死在绿魔洲。
- 如王林所料，追兵在孟土洲外停步犹豫。

## 四、道魔宗的动机与代价评估
- 以一宗之力杀一人，虽与私仇有关，但绝非只为私仇——九宗十三门级别的宗主老祖不会如此昏头（王林的推断）。
- 道魔宗修士的评估：杀这样的凶人，代价可能是**一次灭门**，是**九宗十三门从此变成八宗十三门**。

## 五、章末转折
- 四座传送阵再次闪烁：三座各出数十修士，**第四座只出一人**。
- 全场齐拜：「宗主」「参见宗主」——**道魔宗宗主亲临**。

## 待续悬念
- 道魔宗倾宗杀王林的真实缘由（非仅私仇）。
- 魂铠已尽、道古之力耗竭的王林如何应对道魔宗主。
