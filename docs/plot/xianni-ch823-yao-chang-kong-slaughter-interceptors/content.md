# 第七卷 名震罗天 第823章 姚长空（及824-826章开篇）

## 一、局面
- 地点：罗天星域星空之中，王林（化名「许木」）遭姚家重赏招募的散修群体阻截。
- 阻截者构成：三名阳实修士（含一名阳实巅峰老者）、多名问鼎大圆满、若干阴虚修士，初始尚余二十二人。
- 王林当时修为：阳实。其神出鬼没的身法被对手判定「绝对不是瞬移，更不是大挪移之术」。

## 二、屠杀过程（按数字倒计）
1. **二十二人** — 王林闪现至一名问鼎大圆满身后，斩罗诀无剑光而将其一分为二；元神以黑雾卷入十亿尊魂幡。
2. 阳实巅峰老者祭出**银色铃铛**，轻摇成波纹震动四周天地之力，对王林影响有限但久之会致停滞。
3. 王林以心念放出**塔山**（金身战体）缠住该老者；塔山不知痛楚、任何神通法宝落身皆不动容。
4. 王林张口吐出**封仙印**，化十丈大小砸落，轻吐「封」字，金符脱落封住两名欲逃修士，肉身成血肉模糊、元神破碎却被金符收入印内。此后印上两枚金符异常明亮、仿若活物——王林首次察觉封仙印此特性。
5. 七名问鼎大圆满因惧「许木」威名瞬移而逃，王林扭曲百丈天地之力将其逼出虚无，一闪掠过，七人尽亡。**剩十三个**。
6. 众修士齐齐原地瞬移制造波纹干扰，王林不受影响；一人弃肉身、元神先遁百丈，急呼「我灵冥星所有家族，绝不参与你与姚家之事」，王林未追。
7. 一名阳实修士放出黑针如雨，王林以**子母道枯**煞气化黑针为石针，并双指点破包括该阳实修士在内三人眉心，碎石落地而亡。**剩九个**。
8. 余下八人分八个方向溃逃。王林一步断其瞬移之路，以封仙印、子母道枯、仙剑（许立国附体）三宝分击三人；自身闪至一人身旁一指毙之。
9. **许立国**（远古剑意传承的剑灵）首次面对阴虚修士，心怯咒骂酣战，被对方元力崩溃逼开，未能建功。王林收尾击杀该阴虚修士，冷言：「我，不需要弱者。」

## 三、阳实巅峰老者之战
- 老者见姚家援兵将至而松懈后撤，塔山金光暴涨数十倍致其短暂失明，被逼全力迎战。
- 王林绕至其身后双指点中后心；塔山眉心符文融入右拳一击轰下，老者喷元神精气化盾，盾碎吐血。
- 老者化血影融入自身鲜血中**血遁**逃出合击，王林斩罗诀远程将血影一分为二，老者惨叫弃肉身、元神卷血光逃走。

## 四、姚长东登场
- 数丈粗剑光撕裂星空而至，剑光中白衣青年自报：「姚家三代族人，姚长东」。
- 身份线索：此人正是先前**玄尘星**上中年文士捏碎玉简后幻化而出的青年。
- 修为：已突破阴阳虚实，达**窥涅初期**；脚踏一把**三丈大剑**，剑气仿佛可破碎虚无（王林从未见过如此大的飞剑）。
- 姚长东剑光轰在竖起的封仙印上，王林气血翻涌、连退十丈方稳。
- 姚长东傲然放话「在我姚长东面前，你不要求饶，没用」，内心盘算须赶在**姚冰云**到来前斩杀许木，免得功劳被「那冰冷的女人」抢走。

## 五、王林的判断与决意
- 认定阻截者皆非姚家族人，只是受重赏诱惑：「这些人，即便杀的再多，姚家也不会痛。」
- 定策：「既然姚家要杀我，那我便先灭姚家族人。」
- 战意：自达阳实后从未真正与窥涅期一战，此刻战火点燃。
- 世情观察：罗天星域修士多有家族修炼模式养成的高高在上之傲意，与联盟星域整日厮杀勾心斗角明显不同。
