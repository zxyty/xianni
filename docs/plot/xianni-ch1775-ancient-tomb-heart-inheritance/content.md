# 第1775章 古墓传承！

## 一、掌尊落幕与因果之叹

- 王林借势取走掌尊半魂，未觉喜悦，反而伤感。掌尊之名在其修为第二步时便如雷贯耳，界外太古星辰中亦一次次交错。
- 王林评价掌尊：一代枭雄，其命却悲——先为**疯子**的奴从，疯子失踪后不得不拜**七彩**为师、听其号令，至今被取走半魂。
- 王林将此与当年掌尊纠集界外诸位大能围杀**封尊**、直至封尊只剩残魂入大逆内相类比，感『仿若轮回』『杀人者，人恒杀之』。

## 二、诸方表态与因果了结

| 人物 | 表态 |
|---|---|
| 蓝梦道尊 | 「我能帮你的，已然不多，但无论如何，我会尽最大之力，这是我对你的**承诺**」（末二字加重） |
| 涂司／托森 | 「你当年把传承还给我，让我**墨流分神**大成，帮你，也算了结这段因果」；身子化作常人大小 |
| 云逸封 | 战败即遵王林号令，即便无誓血也不屑反悔；苦笑未应谢 |
| 唐姗（第三妃） | 王林言「我之前帮你离开此地，今日你帮我迎战掌尊，算是两清」，唐姗沉默后点头 |

- 王林隐隐明白了发生在涂司／托森身上之事，但仍分不清眼前之人究竟是涂司还是托森。

## 三、入口显现与战老鬼追至

- 已司之傀所在山峰崩溃后露出**凹陷之地**，内散道古气息，即通往**古之墓地最后一层**的入口；进入即可抵达王林当年所见的烨寞心脏所在。
- 突然天空波纹扭曲、数道长虹与强大神识横扫——**战老鬼追来**。
- 断后阵容：
  - 蓝梦道尊：全身蓝光弥漫，迸发惊天战意。
  - 涂司：沉默不语，体内砰砰巨响，握拳抬头。
  - 云吞逸封：吞大把丹药，虚空一抓凝成五行铠甲，并称「马师伯」也会出手拖延。
  - 唐姗：右手一挥，众人身外浮现**七道金色光门**。
- 王林深深一拜后转身没入凹陷。其身影消失刹那，战老鬼现身半空，七彩光芒闪烁，怒喝「尔等蝼蚁，给老夫滚开」，音浪令大地崩溃、天空撕裂。
- **战老鬼战力评估**：吞噬七彩道人后，体内两魂虽未融合却获极大好处，可发挥修为更高；他既是七彩之魂又是战老鬼本身，感悟融合后已**无限接近当年的七彩仙尊**。
- 掣肘说明：已司之傀须跟随王林身边方可操控，故王林不能留下同战。

## 四、最后一层：血管与心脏之地

- 此地**没有天、没有地**，只有一条条百丈粗细、如血管之物交错八方；心脏每跳一次，青色血管尽数蠕动。
- 神识可见远处血管连接处有一颗**巨大心脏**，其每一次跳动都令王林心口剧痛，似心要碎裂。
- 与当年在传承大殿模糊一扫所见大致相同、细节略异。
- **心跳杀伤**：那怦怦之声搅乱王林心跳，两种心跳错乱回荡；越近越烈，最终连成一片，如针刺心。王林咳血、面色苍白、体内血管鼓起、血液流速时快时慢——这是心脏将崩之兆。作者明言：这不是神通、法术、道术，但连王林的**道古身躯**似也无法抵抗，除非他没有心脏。
- **例外**：化作黑雾跟随的**已司之傀**全无影响，舌头长伸、双眼凶煞更浓、隐现暴躁。
- 全层无凶兽，王林以最快速度穿梭，未遇阻碍。

## 五、传承对话：三个承诺

王林踉跄登上心脏、盘膝闭目，将全部精力凝于体内心脏，神念传入：

1. 陈述传承进度：「烨寞，我传承了你的**神**，传承了你的**血脉**，传承了你的**双臂**，如今我来传承你的**心脏**，让这一次传承，圆满。」——请求其停止错乱、与己一致。
2. 心脏反以暴虐排斥、跳动更烈。王林续言：自己已度过**大部分古神损劫**、获得**古祖认可**，传承已得大半；并许诺：
   - 替烨寞照顾其在**仙罡大陆**的亲人，保其安生；
   - 烨寞与**七彩仙尊**一战败落身亡，王林将与**七彩之魂**一战，无论胜败，延续当年之战。
3. 心脏一顿复又欲狂跳，一股滔天怨恨、极为凄厉的神念如幻觉冲入王林心神：「**把我的左眼，还给我**」。
4. 王林猛然睁眼应诺：「我必定帮你找回左眼，这是我王林对你烨寞的**承诺**」。

## 六、结果

- 话音落下，身下心脏轰然一震，不再错乱，渐与王林心跳保持一致。
- 磅礴**道古气息**轰然涌出，冲入王林体内，其白发急速飘动如遇狂风。
- 王林**眉心古神八颗星点骤然旋转，隐隐出现将成第九星的征兆**。

## 七、后续动向

- 王林目标：取得道古烨寞**除左眼外的最后传承**（心脏）→ 离开**第四花** → 进入**第五花**寻找**真门**。
- 悬念：上层蓝梦等人能拖延战老鬼多久；烨寞左眼下落。
