# 第九卷 云海之巅 · 第1238章 新王！（第二更）

## 一、局面与目标
- 地点：风仙界（风界）内的蚊兽山脉，紫色蚊王族群的巢穴所在。
- 王林的目的：让自己的蚊兽被紫色蚊王认可、接近，从而由自己出手重创蚊王，最终由自家蚊兽吞噬其精华，成为**新蚊王**。此为王林整体计划中至关重要的一环。
- 前提优势：王林的蚊兽虽实力不足，但已**蜕变为金色**，紫色蚊王难以看破其气息隐匿。

## 三、动手过程（全程约三息）
1. **诱近**：王林蚊兽低嘶作臣服状，三息内逼近至不足十丈；紫蚊王起疑再嘶，蚊兽回应之际骤然提速越过十丈。
2. **元神现身**：蚊兽身上藏元神的**规则之星**急旋飞出，散刺目之芒，王林元神直接幻化成型，引群蚊哗然冲击。
3. **第一击**：右手一挥凝天地之力化狂风，横扫轰出两只白色蚊兽。
4. **规则之手·四指**（右手点左手背，每点一次左手背浮现一枚规则之星印记）：
   - 第一指：无尽元力夹杂**仙力**涌入 → 印记移至食指；
   - 第二指：天空雷霆弥漫、大地震动 → 印记移至中指；
   - 第三指：大地龟裂，天地元力在天空聚成巨大漩涡 → 印记移至无名指；
   - 第四指：右手向天一抓，将漩涡抓握缩小化作第四指之力 → 第四印记幻化，**手印直接印在紫色蚊王眉心**。
5. **紫蚊王受创**：体内砰砰作响、口器开裂、掌印处狂喷鲜血；以紫色雾气**三次散开又收缩**的方式急速疗伤，须发全竖，现出碎涅修士施展神通前的征兆。
6. **金光·王者嘶鸣**：王林蚊兽体表蓝光炸碎，金光暴涌，成为方圆数万里唯一夺目之光，仰天发出蚊王咆哮。四周赤红蚊兽敬畏惊恐停冲，蓝色蚊兽挣扎不敢靠前，白色蚊兽通体一震止步，紫蚊王亦为之一怔。
   - **规则**：蚊王之战，所有蚊兽均不得参与、不敢参与、不能参与。战局遂由「修士 vs 蚊王」转为**两蚊王之间的厮杀与吞噬**。
7. **收官·定身术**：王林元神消散重化规则之星落回蚊兽之际，施出最后一式——元神右手一指，不引元力，而是**引动风仙界的无尽仙界之气/仙力**，化作巅峰定身一指，封死紫蚊王一切行动。
8. **吞噬**：王林蚊兽金光口器刺入紫蚊王体内疯狂吸吮，紫蚊王颤抖枯萎、彻底消散，连身体都化作精华被尽数吸收。新蚊王诞生，欢喜嘶鸣，威压笼罩四周。
