# 第1423章 人杰！（第九卷 云海之巅）

## 一、战局起点：虚火压制
- 古魔魂环绕的雾魔枪逼近司墨子。司墨子心中断定：王林尚未至第三步却能与自己一战，若被其破开空门自己非其对手；且王林知晓自己当年之事，「显然是来自界内」，此人必须死——但眼下身在**大帝星**，不能出杀招。
- 司墨子寒光一起即中招：**虚火**随情绪而燃、无法闪躲，他喷血倒退，忆及掌尊之语「一切虚火修士都该死」，判断久战不利。

## 二、白绢红雾与白纱女子
- 司墨子甩出一道白色绢绸，上有梅花状鲜血；血化红雾，雾中走出一名妙曼白纱身影，看不清相貌。
- 白纱女子抬手放出**岁月之力**，前方天地扭曲，将古魔魂笼罩。

## 三、天皇炉：王族古神法器
- 王林眉心**古神星点**急速旋转，第一颗星内射出幽光，化出巨大烘炉——**王族古神法器·天皇炉**，一出即把司墨子与红雾女影全部罩入炉内。
- 司墨子欲带女影脱出，王林双目红芒滔天，一指低吼「定定定」，喷出三口鲜血承受超出本身可承受的**反噬**，换来司墨子极短暂的一顿。
- 王林「王族法器，开炉」，转身坐于炉顶，双手按炉：**左目九色之火**顺左手环炉，**右目雷图**化雷霆顺右手入炉，雷助火威、火助雷势，疯狂炼化。

## 四、四方震动与老朱雀之评
- 远处观战修士哗然：「炼化第三步大能」「古往今来，从未听说有人可以炼化第三步大能」「这第三少帝疯了，他莫非以为是在炼丹」。
- 老朱雀原本的谋划：暗中相助 + 自身震慑使司墨子不敢出杀招，只求二人平手，王林立威即成；以第二步与第三步大能平手已足以震惊太古。
- 见王林竟要炼化司墨子，老朱雀倒吸口气后长笑：「不管能否炼化，能起这种心思，能有这种魄力，此子当为**人杰**」，眼中满是欣慰。

## 五、炉内攻防
1. 司墨子化两只紫色大手轰击炉壁，炉身震动，王林在炉上震动喷血，索性闭目继续炼化。
2. 炉中高温渐聚，浮现大量**虚幻之魂**——古魔、古妖，数量无法计算，皆为古往今来被炼死在此炉中的生灵；先前的古魔魂后闪，与之融为一体。
3. 红雾收缩，白纱女子默立司墨子身边不语，眼中温柔清晰可见。
4. 司墨子施**七彩神空钉**：二十九道七彩之芒钉穿炉壁，炉外鼓起二十九根七彩利刺，虚幻之魂皆避退惧之。
5. 王林取出**魔魂瓶**，咬破舌尖喷古神之血，喝「以吾王族古神之名，召三万古魔，助我炼化」，古魔虚影吸血后直扑天皇炉。
6. 司墨子取出一块不足三尺的**兽骨**，上有清晰掌印与掌纹，为当年**掌尊**所赐，内蕴掌尊一掌之力，正要按下破炉。

## 六、转折：白纱女子的劝语与「梦道」
- 兽骨将按之际，身后传来幽幽叹息：「司马，陪我回家好么」「我们把修为还给他，一起回家好么」。司墨子右手一颤、神色挣扎，眉心指甲盖大小的**萤火**剧烈晃动。
- 炉外王林双目奇光，掐诀呼出一口无形之气吹散于天皇炉上，施出——**道术·梦道**。
- 设定补记：王林一生自创三术，残夜、流月之后，「梦道」是他在**天逆**、**道境**内创出的此生第一个「道术」。

## 七、场景要点
- 整个天空中，除**古息叶**封印的**香火界**外，只剩这一个巨大烘炉与坐在其上的王林。

- 白纱女子称司墨子为「司马」，且提出「把修为还给他」，暗示司墨子修为来源与其旧事。
