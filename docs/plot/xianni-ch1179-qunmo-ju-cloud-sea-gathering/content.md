# 第1179章 群魔聚（第九卷 云海之巅）

## 一、云魂子试探：阴魂突袭

- 王林（化名「吕子浩」）临近时便一眼看出戴道冠老者的修为为**碎涅中期**，感受到其身上杀戮滔天的血腥之气，神通**以魂为主**，判定其为云海星域声名赫赫的魔孽之辈。
- 云魂子大袖挥舞，无尽阴魂铺天盖地直奔王林吞噬。
- 王林右手握拳隔空一击，磅礴之力轰散小部分阴魂，雷鸣般巨响卷动星雾；王林后退五步，每步落地大地轰鸣留下深深脚印，面色略白。
- **实情**：王林看似全力，实则留有后手——面对这些魔孽老怪，尽露实力当属不智。

### 苍松子出手拦阻

- 苍松子起身右手一挥，金光化作**数千把飞剑**，凝聚成一道剑幕，生生阻住阴魂攻势。
- 苍松子：「云魂子，这位吕道友是老夫邀请来的贵客，还请给老夫几分薄面。」
- 云魂子冷言王林「藏头露尾之辈，倒是却有碎涅神通」，虚空一抓收回阴魂，凝成**九个巨大魂火**燃烧环绕其身。
- 苍松子打圆场称云魂子只是试探修为，并无歹意；王林神色阴沉不语，盘膝坐在不远处，喜怒不露。

## 二、暗中传音：两人合谋再探

- 云魂子传音苍松子：「此人确有杀吴青的本事，但与我等碎涅中期修士还有不少差距；我一人出手杀他只需十息，你我联手可瞬杀此人。」
- 苍松子回传音（要点）：
  1. 最忌惮的**不是**王林疑似**神宗门人**的身份；
  2. 而是他明明看起来是**净涅**修士，神通却能斩杀吴青，显然**隐藏了修为**；
  3. 不知其真正修为，会对「我等余下之事」造成阻碍；
  4. 观二人（应指云魂子与另一位）出手后略有放心，但此人心机太深——命云魂子**途中再找机会试探几次**。
- 王林同时权衡：碎涅中期神通所蕴天地元力远非碎涅初期可抗（如少年与壮汉之别），但自己全力出手、配合法宝并非会败；**要防的是苍松子与云魂子联手偷袭**。

## 三、在场旁观者

| 人物 | 表现 |
|---|---|
| 庞姓老者（满脸坑洼） | 全程看在眼里，不动声色，转动手指上的戒指，目光时而扫过苍松子 |
| 青衣老妪 | 眼观鼻鼻观口，平静盘膝，仿若入定，看都不看一眼 |

## 四、端木到场（第五人）

- 蛮荒大陆星雾缭绕，昼夜不分；约过一个时辰，远处星空雾气内一道剑光呼啸而来。
- 剑光锋利，蕴凌厉剑气与唯我独尊的霸道剑威，穿透星雾而不使其变化，「铛」的一声刺在庞姓老者前方数丈外地面。
- **剑**：七尺长、二指宽、通体银白，流光缭绕仿若水痕流动，散森森寒气；剑柄金色剑穗飞舞搅动虚空，剑上空现出层层涟漪。
- 从涟漪中走出**端木**：身矮如童子（仅比剑高出半头），五官扭曲、面青如鬼，凡人见之可能吓死；声音尖锐，盘膝坐在剑旁。
- 端木抱怨苍松子给的**星图**难认，找了许久才到；看到王林时目光略有一顿，未说什么。
- 王林余光判断：**此童子亦是碎涅中期**。

### 轮回丹与化雾蛟龙

- 端木质问：「你说那地方有**轮回丹**，此言可真？」
- 苍松子确认：千真万确，他此前无法进入内部，只在外围便看到一枚轮回丹，可惜有凶兽在旁无法拿到。
- 凶兽为**十二阶化雾蛟龙**。端木闻言沉默，目光闪烁。
- 王林心中一动：**轮回丹他从未听过**；且看苍松子的样子，此丹似乎并非其此行重点。

## 五、陈天军到场（第六人）

- 大地轻微颤动，蛮荒大陆深处雾气中走出一个紫袍高大汉子，身后跟随**数百头凶兽**（品阶均不高）。
- 大汉平静道：「陈某早已来到。」话落，身后凶兽尽数咆哮崩溃、化血肉死亡，大地染红，血腥浓郁。
- 兽魂自尸体飞出，在其身前凝成一枚**黑色气旋**，被其右手一捏化作**黑色丹药**，一口吞下：「来的早了，顺便就把这里的凶兽炼化。」
- 云魂子神色凝重抱拳：「**役兽宗**？……老夫云魂子，与贵宗**卜天子**道友有旧。」端木亦神情一肃抱拳。
- 大汉自报：「卜天子是我师兄，在下**陈天军**。」神色略有倨傲。

### 王林的判断

- 陈天军为**碎涅初期**，却能让几个碎涅中期老怪慎重——除宗派之名外，更因**役兽宗神通有奇异之处**。
- 其早已来临却无人发觉，此点很是诡秘。苍松子赞叹：「役兽宗**借兽隐匿之术**果然高明，老夫竟然没有发现陈兄早已来临。」

## 六、启程与酬谢承诺

- 陈天军催促：受**九阶星域召唤**，要尽快赶回宗派与同门前往，时间不多，要苍松子加快。
- 苍松子致谢众人：「此行我等各有所获，断不会让诸位白走一趟。」
- 对王林额外承诺：「吕道友这里，除了**元晶**外，到时也可选上几样宝物，权当老夫感激相助之义。」王林点头未语。
- 苍松子称到了地方再详细介绍，率先化长虹冲入星雾；庞姓老者、青衫老妪、陈天军（脚下两团黑气化两条鹰状兽魂）相继跟上。
- 云魂子似笑非笑请王林先行，自己**殿后冷冷注视前方的王林**。
- **一行六人化作六道长虹，以苍松子引领方向，破空而去。**

## 七、要点提示

- 队伍构成（六人）：苍松子、云魂子（碎涅中期）、端木（碎涅中期）、陈天军（碎涅初期·役兽宗）、庞姓老者、青衣老妪，加王林（化名吕子浩，外显净涅、实为碎涅中期）——原文「一行六人」与列名人数存在出入，此处按原文记录。
- 悬念：苍松子此行真正目标未明（轮回丹非重点）；苍松子与云魂子已约定途中继续试探王林，并存在联手偷袭的可能。
