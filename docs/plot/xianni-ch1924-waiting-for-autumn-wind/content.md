# 第1924章 等到秋风起…

## 场景
地门。王林由金尊老祖郑天林与地门宗主陪同，在数千五等门人注视下，走向一名叫「青」的年轻男子与其爱人。

## 事件脉络

### 1. 立威
- 王林上前时，中间阻隔的地门弟子如不受控般向两旁散开，王林径直站到「青」身边。
- 地门宗主误判形势，指着青与其爱人喝令要将二人逐出宗门以示表现。
- 金尊老者郑天林急欲阻止（怒斥「愚蠢」），未及出手。
- 王林转身喝出一个「滚」字，如奔雷炸响、化作音浪，将空劫后期的地门宗主震得喷血倒飞。
- 郑天林当即抱拳请罪，自陈该宗主是其血脉后人、被自己宠坏，愿废其宗主位交王林处置、另立新人。
- 四周数千门人骇然。

### 2. 认出转世之人
- **青**：孤儿，名字为自取的一个「青」字。王林认定这一字取自其前世所痴恋的**青霜**。
  - 前生事迹（王林回忆）：燃烧身体守护白衣女尸；狂笑间取出**问鼎晶**交给王林；燃烧灵魂与敌死战；死后化为**剑灵**，在青霜苏醒失忆、陌路相望之后仍默默陪伴无数年，从未放弃。
  - 转世后仍带前生剑灵的**冷冽**（与清水的冷冽不同，与情无关）。
- **周忆婷**：青的爱人，即**青霜**的转世。王林点破「忆」字既是「忆」、也是「佚」。
  - 见到王林第一眼即从灵魂深处颤抖恐惧，死死抓住爱人的手。

### 3. 王林当年的隐秘作为
- 王林当年强行改变了周佚与青霜的转世，青霜虽是**青霖**之女亦不例外。
- 对青霜：不是封印，而是**生生抹去**前世记忆。抹除造成的灵魂剧痛烙印在魂中，故其转世后见王林即生莫名恐惧。
- 王林当时的内心独白：「我不信你当年没有恢复对周佚的记忆，但你却生生让自己选择冷漠……既你选择忘记，又选择了在我手中转世，那么我便认为你是有意如此，就帮你抹去。」此事从未对任何人说起，也未被他人看破。
- 对周佚：**未解开其记忆封印**——因为此人是他的朋友、恩人，王林要让他自己选择自己认为正确的人生。

### 4. 青的困惑与王林的答案
- 青自述：修道至今进境极快，如同曾经历过一样；数百年来反复做同一个梦，梦中白衣女子只见背影，熟悉而心痛、冷漠；他一直想看清她的容颜，隐隐觉得她像前世的妻子，觉得此生存在的目的就是等她转过身看他一眼。
- 王林的答案（秋风之喻）：春天在树下喜欢上一片绿叶，秋天再来却寻它不着，以为找不到了；转身惆怅离去时，秋风卷起一片枯叶伴其一路环绕——他要等、要找的，其实一直在身边。
- 王林留下一粒**枯黄如秋叶的丹药**漂浮在青面前：若有一天他认为这答案是对的，服下便可从此再无那个梦。

### 5. 托付与离去
- 王林以神念对郑天林交代：这对夫妻是他当年挚友转世，如今转世于地门是**地门的造化**；他可为地门**出手三次**；二人若有变故，唯郑天林是问。同时一枚带有王林印记的玉简飞向郑天林。
- 郑天林震动叩拜，尊称王林为「**天尊**」，视之为大礼。
- 风起，青与周忆婷两缕发丝在风中交错如蝴蝶双舞。
- 王林回头深深一望，乘海龙离去，轻叹：「周佚，周大哥，忘了我，忘了洞府，忘了你的前生一切，在这一生，珍惜身边的人。」

## 要点
- 本章是纯情感回收章：以「转世重逢而不相认」的方式收束周佚—青霜的千年痴情线。
- 王林的干预（抹去青霜记忆、不动周佚记忆）体现其一贯的「代人做主 + 留人选择」的矛盾行事。
- 王林在地门展现的威压层级：一字之音即可重伤空劫后期，被金尊老者尊为「天尊」。

## 章末
作者耳根求票语：「等到秋风起，票票已成灰，还是现在就落下吧。」
