# 第567章 二问姚惜雪

## 一、山谷内：第二次逼问

- **场景**：炼魂部落山谷。王林自储物袋取出禁制之球，打出印诀后球体如花绽放铺展，内中姚惜雪面色苍白、盘膝而坐。
- **生之烙印**：姚惜雪眉心生之烙印不停闪烁，每闪一次输入一道生机，令其永不会断生机而亡——即“求死不能”的封印形态。
- **时间感**：禁制内感受不到时间流逝；外界只过一年多，于她却如生生世世，无助感日增。
- **规则**：王林重申只给三次机会。本章为第二次；第三次若仍不答，“你我将再无相见之日”。每回答一个问题，少封印五十年。

### 双方交锋
- 姚惜雪以其父**血祖**的追杀相胁；王林坦承血祖修为远超自己，被追杀连逃走机会都没有。
- 王林的因果算计：**放与不放都已得罪血祖**——“你若不是计算于我，我也不会对你暗算”，故不如把人操控在手，或有一线生机。
- 姚惜雪提出发誓不告知其父、恩怨一笔勾销；王林只回一句“我不相信你”。
- 半柱香后姚惜雪抬头冷言：父亲必能找到她，届时要看着王林被击碎肉身、抽魂炼魄，锁在幽冥之地生不如死。第二次机会作废。

### 血针与“以恨入道”
- 王林一踏上前，捏开姚惜雪下巴，从其口中夹出一根**红色小针**——以其元神内仅存的一丝精气所化，若再给她时间，或可用此针阻断烙印生机而在禁制内身亡。王林一捏，针碎为血雾。
- 姚惜雪立誓将来必以天下最严酷之法折磨王林；此刻她眼中罕见地一片清明，恨意升华凝聚、转化，隐隐要以此**破开虚无**。
- 王林判断：此女天资惊人，竟把恨转化为明悟，**以恨入道**，单凭生机烙印将无法彻底封印她。
- 应对（冷酷手段）：挥手令其衣物化为虚无随风而去，以指尖仙力点其数处敏感之处，令其全身微红、眼中清明消散，重归屈辱与恶毒——**坏其人道心境**。
- 随后双手掐诀落下一道道禁制，尤其在几处敏感之处形成**循环**，使刺激无时无刻侵入其身心，令她无法静心、无法再入明悟。
- 收功：禁制之球收拢复为球体，重新收入储物袋。

### 王林的内心盘算
- “血祖之女却是一个麻烦，唯有找个隐秘之处封印，但前提是把所有秘密都知晓后。”
- **可惜修为不到问鼎**，否则可直接施展**搜魂术**尽取所知；此刻强行施展稍有不慎便令其身亡，反留后患。

## 二、离部落前的交代（两个多月后）

距与妖将之约还剩数日，王林走出山谷，欧阳华随行。

1. **扩张令**：派出数百族人向四周扩散，无论大小部落都要派人前去，以各种方法融入对方部落；以**魂魄守神**抵抗各部落的**灵汤乱神之术**；入部落后传授**炼魂术**，让更多人修炼此术，具体做法由欧阳华自行安排。
2. **抽魄术密传**：王林交予欧阳华一枚玉简，言明炼魂术实有两部分——炼魂只是其一，玉简内所记另一种神通名为**抽魄**，“若非嫡系，不能外传”。欧阳华看完即捏碎玉简，誓言只传炼魂部落嫡系族人。
3. **收幡**：王林右手向天一抓，部落上空由**十亿尊魂幡**化作的黑雾凝聚成三丈大幡，被其吞入元神；另取数杆**普通魂幡**抛向天际，重新化作黑雾笼罩天空（维持部落表象与防护）。
4. **临别之约**：身影消失前留言“我下次回来时，希望族人可以超过百万”。欧阳华跪地立誓不让老祖失望。

## 三、赴古妖城：与莫厉海会合

- **王林的行程盘算**：直奔古妖城，再往**天妖郡京都**——“不知是何处龙潭虎穴”。天运宗除他之外另有数人来到妖灵之地；**大罗剑宗**亦有十多人，若在京都遇到，定要抓住一个询问**周佚被封印的下落**。
- **莫厉海处**：青衫立于古妖城东门城墙，身后为都统、统领一行。他回望城内中心十里残骸，暗道“我这一走便不会回来，届时会另有妖将来此，这城内的残骸与我没有半点关联”。
- **交易背景**：十八妖魔身因“十三”被王林要走，只炼化了十七具；若王林真心相助，此次**妖将大比**他有把握进入前三，从而取得进入**古妖殿**修炼的资格，出关后即为**副帅**之一。他评价王林“倒是一个遵守约定之人”。
- **会合**：王林现身东门外天空，抱拳致意；莫厉海称此行对己较为重要，届时仰仗王林。二人动身——“此地距离京都需要走三个传送阵”，两道长虹直插天际远去。

## 四、要点与伏笔

- 王林与血祖的因果已成死结，姚惜雪成为其对抗血祖的唯一筹码，第三次问话将是生死节点。
- “以恨入道”被强行掐灭，暗示姚惜雪天资极高，封印并非万无一失。
- 搜魂术须问鼎期方可安全施展 → 成为王林修为目标的现实动机。
- 炼魂部落被王林设计为向外扩散的信仰/术法网络（炼魂 + 嫡系抽魄），百万族人之约为后续伏笔。
- 天妖郡京都之行同时承载三条线：助莫厉海妖将大比、天运宗同门、追查周佚下落。
