# 第1846章 第一次见面！

## 一、布置后手与识破大阵

- **留神识于海**：王林在丹海海面一按，留下一丝神识融入海水，极难被人察觉。为人谨慎的伏笔，预备日后起作用。
- **禁制本源之眼**：王林双眼弥漫血丝，瞳孔尽被细密血纹取代。以蕴藏**禁制本源**的双眼观天，看到肉眼与神识都无法察觉的层层稀薄雾气。
- **七层雾气**：雾气共七层，无边无际，如巨碗倒扣，将丹海与大地一并罩住。
- **虚幻罗盘**：七层之上有一虚幻罗盘缓慢旋转，散发威压并与雾气融合。王林判定罗盘非真物，其上一缕气息连向丹海远处——**阵法中枢已化作实物，位于丹海深处**。
- **动心与克制**：王林的禁制本源欲完成真身转化，需吸收大量不同禁制，此阵他从未见过，颇为心动，但很快压下。

## 二、逐层破阵

王林盘膝坐下推衍，身后浮现**两个虚幻的血丝巨大瞳孔**，与其双眼同步推衍。白虎三人在旁护法。

| 阶段 | 手法 | 结果 |
|---|---|---|
| 半个时辰推衍 | 双目与身后双瞳同推 | 血丝渐多，未破 |
| 又半柱香 | 右手向天连续**三指**，三道血丝 | 在第一层雾气缝隙交错成圆孔，足通一人 |
| 继续 | 双手同弹**九次**，九道红色细线 | 穿透第一层，四道构架第二层圆圈，五道构架第三层圆圈 |
| 再半刻 | 双手连弹**十七下** | 六道细丝构架第四层更细小圆圈，余者打通第五层 |

- 第四层往后稀薄小孔更为少见，纯推衍难寻；王林更多依赖**禁制本源的目光**——天地一切禁制在其目下无所遁形。
- 白虎三人看不到这一切，神色凝重焦急；且绿魔洲修士迟迟不现，如暴风雨前的平静，极为压抑。

## 三、海底一剑

- **突变**：丹海骤然轰鸣，海水以一条长线为中心分成两半，露出漆黑海底大地。
- **实为剑斩**：那并非细线，而是自海底斩出的一道剑影，**足有数万丈之长**，掘海而起，一剑斩天，直奔王林四人。
- **反应**：王林瞳孔骤缩，几无犹豫，站起、散去身后双瞳虚影、大袖一甩卷起白虎三人化长虹冲天，抢先一步。
- **重伤者**：朱雀与玄武本就重伤，感此剑意蓦然喷血，面色惨白。
- **玄武之判**（见多识广）：此为**剑道**——一生不修天地意境，只修一把剑，以意融剑、以身融剑，灭绝一切天性，甚至把自己都当作一把剑；感叹绿魔洲竟有这样的极端修士。

## 四、一剑毁四层与强闯第六层

- 剑影斩入阵法，前三层雾气瞬间崩溃，余波带着剑影意志卷至第四层，使第四层轰然瓦解——**一剑毁去四层禁制**，连王林都倒吸口气。
- 王林在第五层内感到雾气一震，一股「天上地下唯剑独尊」的霸道意志余念轰入心神。
- 王林断言：不论此人修为如何，只凭这一剑，**必定是绿魔洲内的赫赫之人**。
- 王林双眼红光弥漫、血丝占满双目，携白虎三人直冲第六层。第六层雾气浓郁、毫无缺口，他双手掐诀，一道道禁制血丝织成细密丝网撞上第六层，**强闯而入**。

## 五、第一次见面

- 一个低沉声音回旋海面：「**云空不才，远千山而来，这位道友何必着急离去**」
- **云空外貌**：青衣青年，衣衫朴素无点缀，长发披肩飘逸；相貌极为俊美却充满冷酷；手持七尺长剑，黑夜中流芒转动、寒光冷冽。
- **关键设定**：来者**并非云空本尊，而是其一道剑意分身**，却拥有本尊**近六成剑意**。
- 云空抬头轻步迈向第五层，右手挥剑一扫，一道**弯月剑影**轰鸣冲天，第五层雾气骤然崩溃。
- 由此，云空一眼看到了刚冲入第六层、回头冷冷与他目光对望的**白发王林**——双方第一次照面。
