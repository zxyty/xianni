# 第九卷 云海之巅 第1425章 或许会有这一天……

## 一、梦道之术：王林入司墨子记忆

王林盘膝坐于天皇炉顶，以【梦道之术】进入司墨子的记忆，四周远处有数万修士围观。整章主体即王林所见的司墨子生平回溯。

## 二、记忆·凡人少年司马墨的灭门之日

- 少年（司马墨）背药筐上山采药，忽生不祥预感，疯狂下山，一路数次摔倒、右腿被树枝划开血口而不顾。
- 抵达村外官路，望见滔天火光，隐闻凄厉惨叫。
- 十余匹烈马迎面而来，马上十多个恶汉衣衫凌乱、大笑议论村中女子姿色与“那新娘子”，自称奉“帮主之命”行事，自报门户为【马帮】。一人挥鞭将挡路少年抽飞路旁，昏死过去。
- 入夜方醒，少年踉跄回到已焚毁的村庄：满地尸首、血腥与残烟，皆是熟人。
- 唯一未焚的鲜艳【花轿】立于废墟之中，格外触目。
- 屋舍内：虎子的尸体，旁为其姐虹虹的女尸。
- 屋舍深处，未烧断的大梁上悬着一根白色绢绸，妹妹【小兰】衣衫凌乱、七窍流血，自缢而亡，双眼始终睁着望向远处。少年喷血痛呼。

### 闪回中的兄妹对话（少年记忆片段）
- 哄妹妹摘紫兰花、不睡觉陪她。
- 反复回答“爹娘去了很远很远的地方，会在那里看着兰兰长大、看着兰兰嫁人”。
- 妹妹不喜欢虎子，少年否认“看好了虎子他姐姐”。
- “哥哥的梦想，可是要去成为仙人……等哥哥回来后，让你与虎子长生。”
- “等你大婚的时候，哥哥为你准备很多嫁妆。”

## 三、记忆·葬妹与立誓

- 数日后，少年埋葬全村尸体，将妹妹单独葬在山上高处紫兰花丛中，那里可望见很远的天地。
- 妹妹并非死于凌辱，而是自缢；少年将那白色绢绸留在怀中，隐约觉得妹妹的魂就在绢绸内。
- 离村时咬破双唇，血滴落于绢绸，散作梅花状血迹；目露滔天杀机，口中只有“马帮”二字。

## 四、记忆·复仇之路（数十年→百年→数万年）

| 阶段 | 关键事件 |
|---|---|
| 数十年 | 天资出乎意料地惊人（非绝顶但极佳），拜入【破天宗】，凭坚毅成为小辈弟子翘楚 |
| 复仇 | 一个雨夜屠尽马帮一千四百余口，鸡犬不留，连马匹亦杀；七八名老者受尽凄厉、哀嚎近半月方死，魂魄被抽出受炼魂之苦、不入轮回 |
| 遗恨 | 当年侮辱其妹的元凶多年前已病逝，搜魂得知其死前未受太多痛苦，司马墨不甘心 |
| 又百年 | 修为达【元婴】，为小辈中最强者，被破天宗宗主收为弟子 |
| 转世追杀 | 某年冬再度下山，以神通推算元凶轮回转世之体，展开杀戮 |
| 数万年后 | 七彩界内目睹同门死去，身种【七彩钉】，被【掌尊】带走 |

## 五、记忆·掌尊的交易与“司墨子”之名

- 司马墨之言：“我司马墨尽管被驱出破天宗，但我为界内之人，即便是死，也不会成为界外走狗……死，便死矣。”
- 沧桑之声（掌尊）之诱：“老夫不但可以让你不死，还可以让你的妹妹凝化出形……无法复活，但可让她陪在你身边直至永恒；若你修为有成，或许可遇到让其复活之人；若你现在死去，则一切归墟。”
- 司马墨心神一颤，随之而去：“从此之后，你不是界内的司马墨，而是老夫掌尊之士，赐名【司墨子】。”
- 天皇炉内，司墨子泪流；其眉心指甲盖大小的【萤火】扩散开来，占据天灵。

## 六、当下·王林止战

- 王林睁眼，目中一片迷茫，轻叹起身，一挥手撤去天皇炉，炉体消散天地间，司墨子身影显露。
- 梦道之术中王林未刻意留下什么，但留下了一些思绪。
- 王林放弃炼化：判断炼化未必成功，且司墨子尚有诸多手段法宝未施展，此战继续已无意义。
- 司墨子沉默良久，挥手将身旁虚化的女子身影（其妹）收入袖中；以其修为隐隐知晓全部，望向王林目光复杂。

## 七、对话与主题

- 司墨子问：“请告诉我，她之前的话语，是你法术施展，还是——”
- 王林轻叹：“我也不知道。”
- 王林自问：“如果那一日，我换成了司马墨，其妹妹换做了婉儿，我该如何选择？”——他不敢去想答案；亦或如他先前回答司马墨的话语，亦或他已有了答案。
- 章名“或许会有这一天……”呼应掌尊之诺（或许可遇到让其妹复活之人），亦呼应王林对李慕婉的执念。
