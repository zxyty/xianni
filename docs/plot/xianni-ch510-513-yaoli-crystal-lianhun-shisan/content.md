# 仙逆 第533–534章：妖力结晶 / 十三

## 一、背景与场景
- 地点：天运星「妖灵之地」内某山谷（王林先前暗中跟随青年而找到的原住民聚居地）。
- 该地**无灵力、有妖力**；王林神识一扫覆盖全谷，发现原住民**资质普遍上佳**，远胜当年的自己，遂起意以妖力传授炼魂之术。
- 王林所掌握的炼魂宗神通，来自罗云一系；「妖简」一词亦出自**罗云记忆中先祖的记录**。

## 二、第533章 妖力结晶

### 1. 授简与提携欧阳华
- 王林传音召来正在筹划进攻其他山谷的**欧阳华**，抛出两枚玉简。欧阳华惊呼「妖简」，王林认可此称。
- 查看之法：**贴于眉心、凝神想象查看，心智坚定则可见**。欧阳华苦试一个时辰无果。
- 欧阳华底细（王林神识所见）：
  - 幼年赴**古妖城**开蒙时被验出**一星之力**，虽不得定居古妖城，回谷后地位大增，成为长老。
  - 丹田内有丝线般气息缓缓流动，但**经脉阻塞严重**，流转慢、范围受限。
  - 该气息可经**山谷阵法**稍加催化，故他能操控阵法，并借阵法之力幻化**虚幻之身**。
- 王林左手双指点其小腹，缓缓上移，每半寸痛苦倍增，最后骤然点上眉心——**强行打开一条经脉**。此法霸道、后遗症多，但为提升修为最快捷径。
- 数个时辰后欧阳华醒转，「入微查看」的**二星**境成，泣泪三叩首谢「上仙」；随即成功读取玉简口诀，自称由「老朽」改为「晚辈」。

### 2. 传授炼魂术
- 口诀名为**「炼魂」**。王林只讲解一遍，明令：**学会后要教给此地全体居民**。
- 妖灵之地功法为少数人垄断，此举对欧阳华与山谷是天大恩情；欧阳华执弟子礼，誓「此生不忘上仙之恩」。
- 炼魂宗神通特点：**入门容易，精深困难**。

### 3. 三月之功：妖晶与妖体
- 欧阳华全力修炼、强压攻打他族之事，三月小成；族中男丁在其教导下各有成就。
- 王林三月研究妖晶，使**两块妖晶融合为一**，判为**「三甲妖晶」**：内蕴磅礴妖力，外表散出烟雾般触手飘动。
- 王林**吞下妖晶**，其落于丹田，妖力顺经脉运转一周天：
  - 气息由仙风道骨转为**妖气纵横**，面部妖异，**双目化为竖立椭圆瞳孔**，望之心惊。
  - 局限：妖力数量不足，**全力运转仅相当于筑基期修士**。
  - 可心念收回妖力入妖晶、不露半丝，仙力随即恢复流转，外表复归超凡脱俗。
- 三月内王林三度出谷讲解，谷民由惧怕误会转为**无尽感激与尊敬**，见之皆放下手中活计恭敬问好。
- 除欧阳华外，另有一人引起王林注意：即当初被他暗中跟随、因而暴露山谷的**青年（十三）**，三月已修至第三阶段——可制作自己的魂幡。

## 三、第534章 十三

### 1. 仿制魂幡
- 妖灵之地材料匮乏，正统魂幡难制。王林以**此地独有的罡树之木 + 野兽之皮 + 妖力凝化 + 手印**，仿出代替品魂幡。
- 规格与权衡：
  - 只能封印**不足十魂**，「十魂幡」即极限；
  - 胜在数量多，**同施十杆约得百魂幡一半威力**；
  - 王林在其上**藏有致命破绽**，唯他一人知晓——炼魂宗系列神通在**天运星上唯王林掌握**。
- 魂幡层级序列：十魂幡 → 百魂幡 → 千魂幡 → 万魂幡 → 十万魂幡（十三闻之眼露狂热）。

### 2. 山谷格局的转移
- 欧阳华报：族中男丁**二十七人**全数修行炼魂妖术，除十三外多在第一阶段，**六人始终无法修成**。王林评：若此比例放在朱雀星上将极为轰动。
- 自传法之日起，山谷实际掌权者**由欧阳华过渡至王林**，众人皆知「王林才是此地之主」。
- 欧阳华请示：待十三制成魂幡，即发动全谷进攻**千里外地下溶洞**的另一族落（数十人）。王林答：「随意。」
- 王林将新魂幡制法拓印玉简先给十三；十三三叩首谢恩。欧阳华不敢擅取，经王林许可后方查看，并即刻去寻材料。

### 3. 十三成幡与反噬
- 一月后攻打溶洞的消息传开，全谷男丁昼夜苦修；十三外出一次取足材料，**三次失败后炼成第一杆七尺魂幡**。
- 欧阳华其实**早十三数日**炼成，却刻意藏拙，把出风头的机会让给王林看重的十三（人老成精，自知未来属于十三）。
- 十三当众演示：掐诀聚妖力化青芒，虚空一指，幡中黑气飞出化作**长翅狮形野兽（飞天狮子）**魂魄——此兽是他入丛林时遇到的重伤刚气绝之兽，冒险炼魂封入。
  - 一击撞裂崖壁，自身毫无损伤，众人惊呼羡慕。
- 收幡时**反噬**：狮魂回头凶芒毕露，直扑十三。欧阳华取三寸小幡放出**麻雀状魂魄**拦截，仅使其势一缓。
- 十三被无形之力禁锢无法动弹，血盆大口临面之际，山谷深处传来王林奔雷般冷哼：
  > 「孽畜，尔敢」
  - 此声于十三如天籁，于狮魂如惊天之雷，狮魂**险些崩溃**（未崩溃只因王林不愿），立刻呜咽掉头欲逃。
- 王林**一步横渡无数丈**，现身半空——片段止于此。

## 四、要点提炼
1. 王林在妖灵之地由「被畏惧的外来上仙」转为**实质统治者与传法之主**，手段是普惠式传功而非杀伐。
2. **三甲妖晶**为王林新增的妖力体系底牌，可随意切换仙／妖两种气息与外貌（竖瞳妖体），当前妖力上限仅筑基期。
3. 代替品十魂幡**内置破绽**，说明王林传法始终留有控制手段。
4. **十三**被树立为炼魂术传承的潜力苗子（悟性「遁天在世亦为之动容」），欧阳华主动让位其风头。
5. 悬念：狮魂反噬揭示炼魂术的失控风险；王林出手善后。

## 五、待续线索
- 攻打千里外地下溶洞族落之战尚未打响。
- 王林如何处置反噬的飞天狮子魂魄、是否借机点拨十三。
- 妖力数量不足的瓶颈——是否需更多／更高阶妖晶。

# 第535章 散养魂魄

## 一、狮子魂魄臣服与破绽的真相

- 十三所封印的狮子魂魄在王林面前身子颤抖，感到一股**无法抵抗的强大力量**，升不起任何反抗之力，恐惧弥漫至彻底淹没，最终呜咽一声趴伏半空作臣服状。
- 此幕震慑全谷：欧阳华目瞪口呆，对王林生出难以想象的敬畏（数百年内会一直持续）；十三眼中狂热崇敬。
- **根本原因**：王林在传下的**魂幡与改良炼魂术功法上留有破绽**——所有学习其改良炼魂术之人所炼化封印的魂兽/魂魄，王林皆可完全操控与震慑。
- 王林右手虚空一点，狮子魂魄化黑芒钻回十三的魂幡。留话：「此兽尚可，能做你十魂幡主魂。不过你要切记，炼魂术，没有取巧，此兽你虽封印，但它却反噬，这是一个教训。」十三羞愧沉思。

## 二、征讨地下溶洞部落（一月后）

- 山谷男丁于漆黑夜色中全副武装出发，**欧阳华与十三为主攻**，直奔地下溶洞。
- **王林未跟随，连神识都未散开**——视为一场历练；若这些人失败，说明他们不适合，他将离开转往**古妖城**另寻发展。
- 五日后大胜归来：长队蜿蜒，外族壮年男女俘虏双手被绑，每七人一组共扛一根水桶粗的圆木。欧阳华衣上血迹、面带兴奋；十三气质大变，由张扬转为沉稳坚毅，随行者皆保持距离并露敬畏。
- **十三的战功**：与欧阳华配合绕过对方阵法直入内部；第一时间唤出狮子主魂一口吞噬对方长老，又当众展开炼魂术生生炼出长老魂魄封入魂幡。欧阳华同时炼化封印此战所有死者魂魄。此举对外族之人打击极重。

## 三、离妖汤——部落的同化手段

- 谷内妇人取出装绿色液体（冒气泡、气味难闻）的木桶，强行给每名俘虏灌下几口，其人立即双目茫然，随后被带走由族人在耳边低语。
- **离妖汤**作用：使人忘却一切，再被告知新名字与部族之事，吸收后清醒即彻底成为本部族一员。
- 出处：**罗云的记忆**中，其先祖曾详述妖灵之地零散部落收纳新族人的唯一方法。
- 王林评价：并无出奇，与「术」之类神通相差太多；修道之人喝下几乎无任何作用。

## 四、妖晶献纳与口诀赏赐

- 欧阳华远远止步恭称「晚辈欧阳华，求见上仙」，获准后入谷献上一物：外表粗糙的黑色石头。
- 王林一捏碎裂，内藏拇指大小的**二甲妖晶**，当即吞下，与**丹田内原有妖晶融合为五甲妖晶**。
- 王林拍储物袋取出**玉简**（神识扫过后）掷给欧阳华，定下规矩：
  - 山谷之人只有炼魂术**前三阶段**口诀；
  - **除非立功，否则不给后续**；
  - 献妖晶算立功一件，赐**第四阶段口诀**；
  - 好好修炼、**不得外传，否则追回所有**。

## 五、「散养魂魄」的长线布局

王林自语确认此步走对：

1. 山谷部落渐强、蚕食四周 → 他能得到的**妖晶**越多；
2. 部落人数越多 → 修炼炼魂术者越多 → **重铸十亿尊魂幡之日越近**。

> 所有修炼其炼魂术者所炼化封印的魂魄，只要王林需要，**心念一动便尽成己物**；终有一日时机成熟便**收魂**，十亿尊魂幡重见天日。这即是「散养魂魄」。

## 六、半年间的部落变化

- 男丁数量增至**超过五十**（数倍增长）；外族女子被瓜分，欧阳华贪功送数名有姿色女子给王林，**吃了闭门羹**。
- 新族人纷纷修炼炼魂术，全谷掀起修行浪潮，除固定外出打猎者外绝大部分族人全心修炼。
- 女子修炼问题：欧阳华原本反对，**被王林传音喝斥后立刻改为大力提倡**；此后除孩童外无论男女皆疯狂修行。
- 炼魂术入门简单，加之十三与欧阳华展现的强大，成为全族梦寐以求的目标。
- 族人常外出，目标为**制作魂幡**或杀野兽炼化其魂魄。半年内除十三外另有**四人**达到第三阶段需制魂幡。

## 七、立功三法与当前进度

**立功三法（达成其一即赐第四阶段口诀）**：
1. 献上妖晶；
2. 找到**外来者**的踪迹；
3. 全凭自身本事炼化**十杆满魂的十魂幡**，且其中**至少四杆有主魂**。

第五阶段口诀要求更为严格。

**进度**：
- 欧阳华——唯一达标者，已得第四阶段口诀；
- 十三——仅炼化**七杆魂幡**，最难者为主魂，至今**只有两个主魂**，第二个即半年前地下溶洞的那名长老。

## 八、连锁后果与新一轮征讨

- 进攻其他部落的呼声半年内越来越强烈——**唯有进攻才能获得妖晶、主魂与大量魂魄**。
- 应验了欧阳华当年之言：妖灵之地**每5000年一次外来者降临**，均会带来无尽腥风血雨。
- 山谷因王林到来，从安静生活彻底变为充满侵略性、为求更强口诀而主动掀起杀戮的部落。
- 半年后**新的征讨再次开始**：族人不分男女倾巢而出（仅留少数照顾孩童），**分散成三部分同时攻击三个部落**。

## 九、看点

- 王林的「留破绽—散养—收魂」模式，是把整个部落文明作为魂幡耕作田的冷酷布局，呼应仙逆冷硬基调。
- 妖晶可食用并**逐级融合**（二甲 + 原有 → 五甲），是妖灵之地的修炼资源体系。
- 罗云虽已于第505章死亡，其**记忆**仍在为王林提供妖灵之地的关键情报。

# 第536章 战书

## 一、前情：外来者的选择与500年厮杀

- 妖灵之地内，无人注意到蛮荒部落中正有一股力量茁壮成长。
- 绝大多数外来者不像王林那样留在部落，而是各自前往不同的**郡**、获取不同身份，为**战功**与**古妖**展开一场**将持续500年**的厮杀。
- 攻击策略上有一条要点：需分散攻击而非统一攻一处，否则**妖晶与主魂无法均分**。

## 二、三路出击与十三失踪

山谷此番进攻准备极为充分，分三方队伍：

| 队伍 | 结果 |
|---|---|
| 欧阳华一组 | 半个月后凯旋，有伤亡但战果丰厚 |
| 十三一组 | **未归**，如阴云笼罩众人 |
| 其余第三阶段族人一组 | 半个月后凯旋，战果丰厚 |

唯有王林神色如常，不起波澜。

## 三、十三归来：狮子主魂与「凝魂」

三日后清晨，一道黑雾自天际飞来——实为一头**生着翅膀的狮子**（十三的**主魂**）。

- 狮身无伤痕却极度萎靡，时而散作黑雾、时而重新凝结，濒临崩溃。
- 背上躺着**十三**：一动不动、血迹斑斑，体内有一道**红线**钻来钻去，形似寄生。
- 数名族人出谷展开**魂幡**，放出魂魄融入狮子主魂，使其精神一振。
- 狮子主魂入谷后呜咽一声、化作点点黑芒即将崩溃。
- 王林一字令下——「**凝魂**」——黑芒骤亮，肉眼可见地迅速凝聚，转眼恢复如常。
- 王林虚空一点，狮子主魂化黑光没入其手指，成为指肚上的**黑色狮子印记**。四周族人早已习惯王林对魂魄的绝对控制，皆恭敬低头。

## 四、驱除红线与十三之废

1. 王林蹲身以右手轻点十三胸前，红线尖鸣破体而出、直扑王林。
2. 王林体内散出**无形之力**，红线如撞铁板被生生弹回。
3. 王林双指捏住红线一拽，将其自十三体内抽出——此线长约一丈，扭曲如长蛇，另一端再度扑来仍被阻拦。
4. 王林一捏之下**仙力**顺线冲击，咔咔声后三息，红线化作飞灰。

红线去后十三面色渐渐红润、无性命之忧，但王林面色更加阴沉——他一眼看出**十三算是废了**：

- 修行**炼魂术**所达**三星标准的妖力**全部尽失；
- **全身经脉被强行震碎**；
- 身上的**魂幡全部被取走**。

对方出手狠毒却不杀人，反放狮子主魂驮其离开，**显然另有目的**。

## 五、十三的口供

王林以右手双指成剑点在十三眉心，体内**妖晶**一震，妖力经经脉自双指注入十三额头，将其唤醒。十三挣扎欲拜见而不能动，脱口唤出一直默默使用的称呼——「**师尊**」；王林目光一闪，未答。

十三供述：

> 回程途中遇一大部族，虽绕道而行仍被攻击。其中有一**白衣老者**，收走了我的**魂幡**，在我体内**种下妖物**，并让我传话：若想要回魂幡，便直接去找他。

王林抬指，十三再度昏迷；王林令族人抬其回房照料，自身踏空化作青烟离去。

## 六、王林的判断：这是战书

- 王林修**生死轮回之道**，看透生死：十三主动进攻失败而死，他本不会出手相助。
- 但本次性质不同：十三是**押俘归途**经过对方部落而**被主动攻击**；对方**不杀人**、**夺魂幡**、**并留下挑战之言**——意义全变。
- 结论：**这是挑衅，是战书；十三便是对方的「活战书」**。
- 王林心机深沉，先做最坏打算：若对方修为远高于己，便不管此事，回去设法治好十三、避开该部落。
- 但他通过十三的伤势判断，施法者修为**至多相当于修士中的化神左右**，可能性不大。遂冷哼一声，速度更快，如流星划破天际而去。

## 七、天水部落：地理与阵法

- **方位**：妖灵之地**西北**，一片**平原**之上，四面空旷。
- **核心资产**：一座**远古阵法**，散开后护佑**方圆十里**；即便**妖灵之夜**来临，身在阵内亦可保绝对安全。
- **通则**：在妖灵之地，部落存活的关键在于能否寻到守护阵法。此类阵法较常见，但能覆盖十里者不多。
- **规模含义**：阵法覆盖越大 → 部落可容纳人口越多、发展空间越大。山谷范围有限，居住人数一旦超过定量便无法再纳新人；天水部落因十里平原阵法，居住者众。

## 八、天水部落内的密谈（白衣老者 × 灰衣老者）

简洁房舍中两老者对坐，中置紫色茶具。

- 白衣老者：外来者带进此地的东西里，惟独**茶水**最合心意。
- 白衣老者身份：**古妖城左翼将军麾下执事**；此次回部落**探亲已住一个月**，**明日**便返古妖城，否则不好向左翼将军交差。
- 灰衣老者的质疑与情报：
  - 「你打伤人家弟子、取了那奇怪的小旗，若对方寻来如何？」
  - 那群人**几乎个个达到一星以上妖力**，且**都掌握了功法神通**；
  - **带头之人**（十三）手中的**几杆小旗**竟可**唤出妖魂进攻**；
  - 对方本未招惹，白衣老者却看中小旗、**杀人夺宝**，还故意放带头之人离开以**间接下战书**、引出其背后之人——**做得过了**。
- 白衣老者的立场：
  - 「我是古妖城左翼将军麾下执事，杀几个野人何来过分。」
  - **断定背后之人实力不高**：真有本事岂会蜗居蛮荒部落，早该去古妖城谋职。
  - 目的：**从其口中得到小旗（魂幡）的真正使用方法**。
  - 若对方不来，**明日一早**即顺着**留在那青年（十三）身上的痕迹**，直接去其部落**强抢**。
- 关键伏笔：从十三脑中取得的**口诀不假，但不完整，应还有后续**——白衣老者对此阴森笃定。
