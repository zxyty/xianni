# 第609章 古妖血影

## 一、复生与取物
- 蓝血化作王林之身，他自虚无一抓取回**储物袋**，同时一套蓝衫套体，连施数个挪移瞬间消失。
- **血魂丹机制**（本章明写）：吸取一丝元神与血液后可极短时间内生效；死亡瞬间，凡与其元神相连之物皆融入虚无，复活后凭血魂之力从虚无取回。**姚惜雪当初便是如此**。
- 复活副作用（正向）：仙力**一经损耗即刻补充**，从此可连续施展最耗仙力的**大挪移**（以往需取**仙玉**耗时补充）。王林推断是自爆同时融入体内的**四滴仙液**以奇异方式在体内存续所致。

## 二、为何以血魂丹一搏（心理与推演）
- **天运子**当年所赠保命之物，上限只能承受**问鼎后期**修士之力。
- 化身三丈的**黑甲老者**修为相当于问鼎后期，但实力**远超**该境界；加上**黑塔内的存在**，保命之物纵然用出也难保一命。
- 真正的死劫是黑塔内的存在：清醒后回忆一路可谓心惊肉跳——**若非升仙果刺激，早在其神念攻击下死去无数次**。
- 妖灵之地余下**四百多年**，不可能天天服食升仙果，否则不待他人来杀，自己便会彻底疯癫失智。
- 结论：**必须搏**。不重创或杀死黑塔内的存在，纵使逃得再远、用出大挪移，也逃不过其神识攻击；升仙果效力一过，对方再展神识则必死无疑。
- 佐证：黑塔存在**从始至终不曾出来**，显然必须待在塔内 → 更坚定王林决心。
- 保险手段：**刻意不抹去元神中升仙果的余威**，以防黑塔并非关键、塔内存在仍能神识攻击；若真如此，「恐怕以后就要做好亡命天涯的准备了」。
- 心态注脚：他与黑塔存在无冤无仇、系对方主动招惹，但「修真界之事，没有对错，只有强弱」。

## 三、赶赴天妖城：两重准备
- 第一重（血魂丹一搏）已过；**第二重＝寻找古妖的帮助**。
- **十年前之约**：王林因冲击问鼎耽搁十年未赴；他判断所约之事极大，古妖应不会反悔。
- 一路以从未有过的速度疾驰，多次大挪移后逼近**天妖郡都城（燕京天妖城）**。
- 顺带心动的旧账：可惜当初被升仙果刺激失去神智，丢下了**子鼠的剑气**；他记得子鼠尸体所在，但「此刻不是去**火妖郡**之时」。

## 四、铠甲大汉追杀与「凌天候」之谜
- 最后一次大挪移前，身后千丈外踏出一名**身穿铠甲的大汉**：相貌威严、双目幽光闪烁、滔天魔气纵横，怒喝「我倒要看看，你能跑去哪里」。
- 王林回头一眼险些惊呼——大汉样貌**与大罗剑宗剑尊凌天候极为相似**。
- 于**古妖城外百里**再现身后，王林细辨：更为年轻、无凌天候之气势、并非完全一模一样 → 判定「不是凌天候」，但心生「莫非」之疑。
- 试探：王林突问「凌天候，是你什么人」。大汉右手一顿，魔气双眼闪过**迷茫**：「凌天候……好熟悉的名字」。
- 王林再喝「大罗剑宗，剑尊凌天候」，大汉迷茫更浓并现**挣扎**之色。
- **眉心浮出一个魔魂之影**，狠瞪王林并厉啸一声，大汉眼中迷茫立被魔焰取代（暗示大汉为被魔魂夺舍/操控之体）。

## 五、古妖出手：血影现世
- 王林迅速后退高呼「古妖」。一股强大意志自**天妖城**内横扫而出，直接降临其身前：「你晚来了十年」。
- 「借你血液一用」——话音落下，王林全身汗毛孔喷出大量鲜血，**血液流失大半**，面色苍白，只得服丹药、盘膝打坐吐纳。
- 血液凝聚化作人形，**古妖的意志降临其上**；血影蠕动，化作**头生双角之体**，眼中散出妖异之芒。
- 魔魂以一种**奇异的语言**尖声道：「**贝罗**，你敢阻我」——点出血影/古妖之名或旧称为「贝罗」。
- 血影平淡回应：「你只是**吉魔座下九散魔之一**，我如何不能阻你」。
- 王林睁目沉思，认出该语言为「**吉神语**」（与古神/吉神涂司体系呼应）。
