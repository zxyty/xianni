# 第十卷 叱咤界内 · 第1506章 本命之兽！

## 一、重固封印，阻其张口
- 王林一掌落下，将幽冥兽头部**将要消散的封印**重新灌注生机与力量，封印不但重凝，且**比最初还深固三分**。
- 幽冥兽大口正欲张开的一瞬被截断——其口一旦主动张开则「体内之界」随之开启，故王林全程不让其自主张口。

## 二、昆极鞭·百鞭逼魂
- 王林右手向天一抓，自其**炼化的八百万丈星空**中抓出一把数万丈长的巨鞭——**昆极鞭**（文中亦作「昆季鞭」）。
- 一甩之下鞭长暴增至**数十万丈**，几乎与幽冥兽身躯相当，舞动星空震撼心神。
- 第一鞭落体，幽冥兽怒吼闷响、身躯一震，隐现「魂飘」之兆但被其死死抵住。
- 连续抽出八鞭（合前共九鞭），金光扩散，幽冥兽露出**本性胆小恐惧**之色，其魂如冰山一角冒出一丝，随即疯狂挣扎欲把魂收归。
- 王林不停：十九鞭、三十鞭、五十鞭……直至九十九鞭。
- **第一百鞭**：昆极鞭金光万丈，鞭首崩溃数丈，爆出如太阳般的金光，幽冥兽被彻底掩盖，其魂**轰然完全飘出体外**，悬于星空。

## 三、魂封再成——七个古神星点
- 幽冥之魂形态：**一张足以吞噬天地的大口**（幽冥魂口）。
- 魂口未及张开，王林一步临近，眉心**七个古神星点**急速转动飞出，势如破竹穿透魂口。
- 以魂口内**仅剩的一颗明亮封印之星**为指引冲入，魂封自一星迅速恢复为**七星闪亮**——魂封再成。
- 王林右手一按，将魂送回幽冥兽体内。

## 四、血肉之封——三封齐全
- 三封 = 外部之封 + 灵魂之封 + **内部血肉之封**（此时尚差最后一道）。
- 设定要点：幽冥兽**主动张口则其体内之界开启；被人强行撕开则界无法出现**，只露出血肉之口。
- 王林借炼化八百万丈星空的余威，身沉而下，双手深扣其紧闭之口，双臂青筋鼓起、古神之力尽注双臂，**狠狠撕开**一道缝隙。
- 缝隙中憋出的咆哮如无尽之力撞击、吹动王林长发，欲将其推出，王林未退半步。
- 上下一掀之后双手收回，刹那打出数不清的**蕴含道古之力的禁制**，如禁制风暴涌入血肉大口，沿口直入脏器、血管、骨头等一切体内血肉，**数息之间彻底封印**。
- 完成后王林后退百丈，面色红润，隐有负荷。

## 五、封兽宣言与臣服
> 「今曰黄道，以吾王族七星古神、道古传承之身，封汝为吾本命之兽」
> 「幽冥，接封」

- 三封同时运转，化作幽光在幽冥兽体外闪烁，其眼中挣扎渐消、转为温和。
- **半柱香后**幽冥兽彻底不再挣扎，向王林低头。
- 王林心生**血肉相连**之感，幽冥兽似成为其生命的一部分。

## 六、生机灌体：千丈→六千丈古神真身
- 一股带**万古沧桑气息的磅礴生机**自幽冥兽涌入王林心神，同时对方**全部记忆**尽数弥漫其心神。
- 王林**千丈古神肉身**急速膨胀：千丈 → 一千五百丈 → 两千丈 → 三千丈 → **六千丈**方止，远看仿若太古巨人。
- 王林自忖（引涂司记忆）：**唯有拥有本命之兽、诞生望月，方可成为真正的古神**；他体内尚无望月，仅本命之兽便已使肉身至此。
- 收缩身形后外貌变化：依旧白发，但**更为年轻**，身上弥漫一片虚幻——**除第三步修士外，他人看去仿若没有实质身体、如朦胧之魂**。

## 七、幽冥兽的记忆与吐出之物
- 幽冥兽一生大都沉睡，记忆混乱浑噩，**连自己如何出生都不知道**；唯一清晰的是**数百年前七彩界的一幕幕**。
- 王林传出神念，幽冥兽张口如打嗝般依次吐出：
  1. **灵动上人**（狼狈，神色骇然）
  2. **周瑾**
  3. **古息叶**
  4. **望月**（大口张开如巨大黑洞，望月被吐出后不断膨胀恢复原本大小）
- 王林处置：将**周瑾与灵动上人收入天皇炉**，将**望月收回古神星点内**，并收走一切。

## 八、道果之谜
- 王林疑惑：幽冥兽当年吞下七彩界时**太过用力，吸撤之力打破了一些壁障，吸走了一个不该吸收之物——一枚道果**。
- 王林按其身，幽冥兽口中传出七彩之芒，飘出一枚**数十丈大小的橙色果实——道果**，随之弥漫纷杂的**道念**气息。
- 王林盘算：其**因果、生死、真假**三种意境本源大成极难，三者**全属道念**，「若有数个这样的道果，或许可以助我三道本源圆满」，遂挥手收走道果。

## 九、余波
- 失去道果后，幽冥兽眼中犀利不再，慢慢呆滞发呆，状态近似**当年在雾气星域望着七彩界裂缝时**；但因曾吸收部分道果，**神智有了灵性，比当年聪明不少**。

## 关键设定沉淀
- **本命之兽三封体系**：外部之封 / 灵魂之封（七星魂封，需七个古神星点） / 内部血肉之封（禁制封锁全部脏腑血肉）。
- **古神成道条件**（源自涂司记忆）：本命之兽 + 望月 = 真正的古神。
- **道果**：承载道念的果实，可助意境本源圆满。
