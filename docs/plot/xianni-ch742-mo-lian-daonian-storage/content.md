# 第七卷 名震罗天 第742章 魔莲

## 一、场景：雷之仙界·雷山洞府

- 雷之仙界远超联盟星域的**雨之仙界**，且保存更为完整；界体已碎片化为一块块大陆。
- 一处碎片大陆边缘立有终年雷光缭绕的山峰：雷电如银蛇游走，天雷不断落入峰内，仿佛与山峰连为一体。
- 王林在山峰中段洞府盘膝疗伤打坐，**仙卫傀儡**在洞口吐纳恢复。

## 二、源器碎片推演（未竟）

- 王林取出十余枚形态各异的碎片，判断**七成可能为雷之仙界源器碎裂所成**（他未见过雷之仙界源器原貌）。
- 逐片记忆入脑，以推衍禁制之法推演一个时辰，寻找正确组合。
- 结论：**碎片不足以组成完整法宝**。仙力驱使拼合后成「水壶」之形，碎片接缝如疤痕，壶身一侧缺失数片——残缺之美，功能不全。
- 拼完即散，全部收入储物袋。

## 三、核心发现：以道念为储物袋

### 疑点
许封寒身为**阴虚修士**，被王林所杀后肉身消散，神识一扫竟无储物袋——修为高深者不备法宝也当有丹药，有所收获亦需容器。王林百思不解，断定其储物之法不为外人所知。

### 破解过程
1. 念及**道化黄泉**中封存的许封寒**魔莲**；黄泉由道念所化，可大可小，缩小环绕己身。
2. 黄泉怨气上涌托出魔莲：魔焰早熄，只余黯淡莲花与坐台。此物离黄泉太久即消散，唯黄泉内可延缓。
3. 王林掐诀凝仙力于双目「一目看去」，见莲内一团浑浊气息缓缓转动，遇其目光转速骤增，隐有咆哮，欲顺目光延伸而来。
4. 王林故意不收目光，诱其化作黑气魔头扑吞；魔物临身即察觉不对，尖叫回逃。
5. 王林**元神自天灵冲出**，裹挟浓郁闪电追擒，将魔物生生拽回肉身，元神吞噬之。自评：「散魔我炼化不了，区区小魔，王某还没放在眼中。」

### 吞噬能力溯源与收益
- 此等吞噬之能寻常修士不具，多由魔道功法神通造就；王林能为之，是因**当年的吞魂身份**。
- 吞后目中一闪魔气，旋即被目中雷光驱散，恢复正常。
- 收益：元神内元力**完全恢复且略有精进**，似被压缩。

### 光珠与神通领悟
- 黑气去后魔莲内显出**另一处空间**，内浮四枚晶莹光珠，璀璨但已现崩溃之兆。
- 观看间一珠即崩；王林急伸右手抓住两枚，欲取第三枚时该珠溃散——**四得二**。
- 光珠离莲后崩溃停止。王林神识一扫动容：「好奇妙的神通法术，居然以**道念所化之物为储物袋**。」
- 评价该神通：以道念形成空间存放珍贵之物，保护性极佳，**很实用**。
- 失去光珠与黑气的魔莲如一瞬千年般枯萎成碎叶，彻底消散。

## 四、所获两物

| 光珠 | 内容 | 备注 |
|---|---|---|

## 五、雷之仙界搜寻与遭遇

- 出洞后仙卫傀儡化虚影融入王林身后影中。
- 大陆边缘外是**褐色雷光**，如根根生锈铁链延伸至遥远漆黑处。
- **关键设定**：雨之仙界有传送阵；雷之仙界雷霆之力太浓，传送阵无法布置，一切靠双脚（飞行）。
- 王林低空飞行、神识小心散开，寻找有仙力波动之地。
- 途遇二修：男约三旬、深蓝长衫、浅蓝丝带束发、目光凌厉；女约二十七八、相貌秀丽、凤目含煞、性子似乖戾。二人探得王林为**问鼎大圆满**后略松口气，未生事即远离。王林反探得二人同为问鼎大圆满、未突破，且**元神元力不多**（王林自身已饱和）。
- 规律：雷之仙界开启多次，越往后收获越少；但**一旦有收获，大概率是极品之物**。
- 王林凭雨之仙界经验搜寻，历时**月余**，途中仅遇三五人，多为问鼎期，另有一名婴变期，**未再遇阴虚修士**；全大陆搜遍无果。

## 六、回收钩子（章末）

- 王林原路返回途中，忽见远处地面**多出一处隐匿阵法禁制**——他记得先前路过时并无此物。
- 以其**禁制大师**之眼，隐匿禁制清晰无疑。悬念留至下章。
