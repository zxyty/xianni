# 第九卷 云海之巅 第1147章 孙芸的心痛

## 一、金色小旗与极阴之魂

### 极阴的正确法门
王林捏着卢迪遗留的金色小旗沉吟，得出判断：
- **以女子阴魂滋养极阴，大错特错。**
- 正确之法：当年**天运子借白微之身**，在其**极阴巅峰的瞬间**使其**自然过渡成极阳**。
- 若想获得**完整的极阴**，需在**极阳的顶峰**、以**破而立**的方式才可。

### 释放阴魂
以王林目力一眼看出，旗内众多女子阴魂皆为**后添入、时间不长**。这些女子生前都是各宗派极为优秀之人，被**卢迪虐杀而死、封印成魂**。

王林右手一挥，神识如利刃落在困魂法阵上，势如破竹尽数崩溃。魂魄飞出后目露茫然，很快恢复神智，带着苦涩、解脱与感激向王林**欠身鞠躬**，消散于天地之中——「或许有来生的轮回，或许，没有」。

### 封印极阴之魂
女魂散尽后旗内只剩极阴之魂，它趁机冲出欲逃。王林双眼寒光一闪，左手掐诀化作禁制落于旗上，青光闪烁将其生生弹回；随后印记变化，**层层禁制彻底封印金色小旗，收入储物裂缝**。

**推断**：这一丝极阴**不完整且饲养方法不对**；此物既属卢迪，则**紫道宗内定然有其线索**。

## 三、归元宗药院：认药

雨季消散，莫罗大陆风和日丽。王林以**曾牛**之名住在归元宗，整日研究炼丹之术。

- **孙芸**住在隔壁，对曾牛很是恭敬。尽管对方从未承认，她凭女性直觉认定**曾牛就是那白发之人**；一想到其在自己心神中的身影与**那一指的风姿**，便会紧张。
- 云海星域擅长炼丹，修士普遍认识不少药草；而曾牛连**凝碎草**这种常识都半点不知，令孙芸不解。
- 王林要炼丹，须先记住云海星域所有药草的名字与功效（部分药草他认识，但名字与联盟内不同），孙芸遂成询问对象。

**药草信息**
- **凝碎草**：炼丹辅药，归元宗大部分丹方都需要。
- **墨云芝**：炼制**缺云丹**的主药之一。
- **雾中花**：唯有外界星域中**被星雾包裹的蛮荒大陆**才生长，星雾越浓则越多。归元宗内据孙芸所知**仅李师叔处有三株干花**；李师叔炼丹之术在宗内**堪称绝伦**。
  - 王林问及雾中花，是因道观玉简中**六阶以上离魂丹**的丹方里，除凶兽之魂外，三味重要药草含雾中花。

王林很快记住药院全部草药，随即取药回屋。

## 四、孙芸的心痛

- 药院药草**大都属孙芸与其师尊私有**，部分由其师尊在外界凶兽遍布的蛮荒大陆取得后交她种植；宗内弟子皆知，绝不敢来此取药。
- 孙芸劝阻：炼丹须去**东苑丹房**——有丹炉、可引**地火**、有防护阵法，即便丹炸也无危险。王林头也不回：「**不需要。**」
- 王林离去后孙芸跺脚不忿：此人连药草名字都不知，显然是**首次炼丹**，一旦丹炸房屋与药院皆受连累。她不敢上前阻止，索性盘膝坐在一旁，准备丹炸时尽力护住药草。
- 心声：「炼丹不去丹房，显然是自己有丹炉了，仗着自己修为高，只会欺负我这样的小辈，仗势欺人」「狂妄，自大」——先前好感消散大半。
- 她的经验之谈：**炼丹与修为关联不大，更需经验与无数次尝试；修为再高，首次炼丹成功率也不高。**

## 五、王林的第一炉丹（云海星域首次炼丹）

**无炉炼丹的理由**：丹炉的作用是不让药气外泄、更好凝聚火焰、使丹药在高温中成型——对王林而言这些都不是问题，因**天地之火随他一心而控**。

**过程**
1. 盘膝于屋内，右手一挥令药草悬浮。
2. **左目火光一闪**，火焰在左眼中燃烧；白色火焰呼啸而出，在体外化作**火龙**环绕一圈，凝聚于身前并压缩成**火球**。
3. 虚空一抓，药草按不同分量分割，一部分留在半空，一部分融入火球。
4. 药草在火球内融化成碎末却不化飞灰，以特有方式互相吸收不同药性、开始融合。
5. 自储物裂缝取出**卢迪之兽**（蝌蚪状灵兽之魂）——它昔日随卢迪吞噬凡人与重伤修士，此刻却全身颤抖、目露恐惧、挣扎无用。
6. 兽魂被抛入火球，与丹药相融，药香弥漫。

**失败**：王林忽然眉头一皱，右手探入火球，将已融合大半的兽魂**生生抽出**；半成丹药一颤，散出一丝**毁灭性的力量**轰然崩溃，冲击被外层火球阻住，只传出闷响，未冲破火球。

**尽管只是一枚三阶丹药，王林依然神色凝重**——这是他在云海星域的第一次炼丹。

## 六、余波

孙芸听到闷响以为丹炸，紧张起身，却久等无冲击，只见**一脸阴沉的王林走出屋舍，又在药院取走不少药草回去**。她反应过来再度跺脚，有心理论却不敢上前，只在心里狠念：「仗势欺人哼，这次也一定丹炸」

## 待解线索
