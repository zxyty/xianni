# 第八卷 联盟隐秘 第1001章 第二分身（上）

## 一、试探黑色石像：符文对抗与元神中的黑墨

- 王林与火妖郡黑色石像对视，心中第一念是「此物，不祥」。
- 他右手食指直点石像眉心；石像双目黑芒闪烁，于眉心凝出黑雾缭绕的诡异符文阻挡，符文内蕴含一股奇异之力。
- 指尖与符文相触处泛起波纹扭曲，同时——此前神识散开时融入王林元神的那股奇异之力如苏醒般化作一片黑墨，瞬息弥漫其元神。这印证了王林早先对石像的警惕。

## 二、太古雷龙引雷：大半个妖灵之地天雷齐降

- 王林元神之上的**古神皮甲**散发青光；体内**太古雷龙元神**发出闷吼。
- 山谷天空瞬间雷霆幻化，继而整个火妖郡、乃至四周其他妖郡天空皆被无尽雷霆弥漫，大半个妖灵之地尽是雷霆。
- 妖灵之地原住民惊慌，连妖将、妖帅之辈都直勾勾望天，隐约判断这绝非自然雷霆，而是神通所致。
- 数息之后，弥漫的雷霆如银蛇齐动，全部汇向火妖郡都城山谷，尽数没入王林体内。

## 三、黑墨覆灭

- 雷光在太古雷龙元神上游走，与黑墨殊死相斗。
- 黑墨虽顽强，但其奇异之力融入王林元神者本就不多，且几乎一入元神便被王林以元神之力包裹，故节节败退。
- 黑墨欲凝成墨点脱离元神时，**古神皮甲青光形成封印堵死退路**；太古雷龙元神吸尽天地雷霆化作一击轰下，黑点崩溃消散。
- 王林随即再一指点碎眉心符文，手指终于按上黑色石像眉心。

## 四、石像内部：白雾海与「另一个王林」

- 王林以**窥涅中期巅峰**修为并庞大神识全部涌入石像，神识中现出一处奇异之地：白雾缭绕如雾海。
- 王林认出白雾正是炼魂部落族人数百年来膜拜时自天灵飘散而出的气息（即淡淡**妖气**）。
- 修为与神识融合化作王林的虚幻之影，行至此地中心（对应石像的「丹田」）。
- 中心盘膝坐着一个模糊身影：**除头顶双角外，样貌与王林一模一样**，连冰冷孤傲的气息、隐透的寂寞与一千多年修道见证的悲哀都难以分辨区别。四周白雾时而分出一丝融入其体内。
- 王林认定：**古妖**。挥手起怪风吹散其身外雾气。

## 五、王林的推断

- 古神可通过神奴吸取天地之力增强自身；同为古之一族分化的古妖亦有类似手段。整个**妖灵之地就是古妖吸收天地之力的场所**。
- 依古妖贝罗当年所说：他被分成九份，演化为妖灵九郡；九郡之人在古妖无数万年教导下改变体制、学会神通，终成妖灵九郡。
- 每一个古妖之灵都是所在郡最顶级的存在，借妖灵之人吸收妖气疗伤，图谋破开限制、吞噬其他妖灵，最终**九灵合一**化身真正古妖。
- 王林当年到来并与贝罗合作，使这本需无数年自然过渡的变化发生惊变：在王林帮助下贝罗离开所在妖郡、成功吞噬九妖之一的**火妖**，成为余下八妖中最强者，并获得离郡之能。若无意外，消化火妖完成融合后将逐一吞噬其余七妖。
- 但眼前这与自己一模一样的古妖并不完整，以王林**王族五星古神**之眼看去，甚至比当年九灵之一还弱小——只是**一次残存**。由此王林明白：**贝罗没有彻底成功**。
- 王林亦推断出：膜拜石像的炼魂族人天灵所散白气即妖气；炼魂部落所有人都是在妖灵之地出生的原住民。

## 六、搜魂所见：贝罗吞噬云妖（回忆）

王林右手按在古妖头上，神识融入搜取记忆，看到：

- 妖灵之地**云妖郡**原本风和日丽，天空骤暗、暴风凝聚，一道**血色身影**自天而落，直奔都城皇族**九层云妖塔**。
- 塔中传出尖锐厉啸，透着不敢置信。血影发出妖异之音：「九灵需再次合一，唯有古妖重生，才可以完成当年遗憾……云妖，你我本是一体，分开了太久太久，今日，需重新融合。古妖之名，还是我贝罗。」随即冲入塔内。
- 轰响片刻即止，代价是**云妖塔崩溃**；一道模糊妖影急速飞出未远，被血光弥漫吞没，最终融入血光化作贝罗的样子。
- 贝罗冷哼：「这么多年，这九灵之一的云妖，居然寸步未进，真是废物，有辱我古妖之名。」转身消失。
- **云妖郡从此崩裂，再无妖灵。**
- 贝罗离开后第三天，云妖塔废墟下飘出一道极为虚弱的残影，带着一丝仇恨与迷茫，向远处小心翼翼飞去。

## 七、关键伏笔

- 章名「第二分身」与石像内那个「与王林一模一样、只多双角」的古妖残魂直接呼应，指向王林可能借此获得第二具分身。
- 云妖塔废墟飘走的虚弱残影，极可能即是此刻栖身黑色石像、被炼魂部落供奉膜拜的古妖残存之灵。
