# 第639章 周佚的本命剑气

## 一、场景与开局：心死之人
- 地点：潮汐深渊内封印周佚的裂缝，地面布有阵法，东南西北四处插有元神之剑（第四把剑为关键）。
- 王林低声唤「周佚前辈」。他判断：周佚身上的死气除外界因素外，更重要的是**周佚没有了生念，一心求死**；此阵以王林修为破不了，**能破此阵者唯有周佚自己**。
- 周佚睁眼，目光空洞含极致哀伤，脸上茫然，只回三字：「你，走吧。」

## 二、王林的状态与自嘲
- 王林一路走到这里，**体内元神大伤**，连离体都做不到；元神萎靡至**婴儿般大小**，原本晶莹的身子**一片浑浊**。
- 他用尽所有神通抵达，只因周佚**对他有恩**；换来的却是平淡三字。王林露出针对自身的浓浓嘲笑，道「你心已死，我的确不该来」，转身欲走——在他踏入裂缝、**六道元神崩溃**的一刻，周佚之恩已算报答。
- 周佚内心独白：「在婷儿离去的一瞬，我的心，真的已经死了。」被凌天候封印数百年，一直茫然；**古妖残魂侵入他知晓却不阻止**，惟独眉心一道金光——那是对婷儿的痴意——不愿舍弃。

## 三、关键出手：一道本命剑气
- 王林身后凌天候的神念冲出金光困牢，化剑气再袭王林；周佚一声轻叹即令其崩溃，剑气凝成一枚**光球**，悬停第四把剑上空。
- 周佚抬起**完全化成紫色的右手**轻弹，射出裹挟剑气的金光——**雨之仙剑剑灵的本命剑气**。
  - 数量沿革：体内原有**九十九道**；当年追杀凌天候释放了大半；此时仅**剩四道**，弹出一道后**剩三道**。
  - 威力：当年凌天候面对此剑气也极为狼狈；凌天候神念虽强，仍不如本命剑气。
- 光球被穿透破碎，凌天候神念被绞碎成晶莹光点，**如银河般尽数飘入王林体内**：
  - 王林受损元神以疯狂速度恢复，**彻底复原且略有膨胀**后停下；
  - 剩余晶光自动寻到王林元神内原有的**凌天候剑气**并与之相融，该剑气**凌厉三分**。
- 周佚说明：「我的本命剑气，无法存你体内，给不了你。你因我受伤，我帮你恢复，你走吧，以后也不要再来。」

## 四、转折：婷儿即青霜
- 王林一拍储物袋抛还**含周佚神识的宝塔**：「当年的承诺，王某已经完成，这宝塔，不再守护。」周佚睁眼望塔，悲伤弥天，唤「婷儿」。
- 王林不回头道破：**「她不叫婷儿……她的名字，叫做青霜。」** 并抛出**青霖的玉简**；周佚接过凝神一扫，脸色剧变，苦涩自语「青霜」。
- 王林陈述（平淡、并注明未亲见）：
  - 青霜是**仙帝青霖之女**；
  - **青霖是仙界第一强者**；
  - 传闻**仙界破碎之时青霖逃出，隐藏在这妖灵之地的一处洞府内疗伤**。
- 周佚追问是否确定，王林摇头：「并未亲眼所见，不确定。」周佚自忖「这本就不是可以确定的事情」，但**若婷儿之父真在此，以其修为一定可让婷儿苏醒**。
- 叙事者点明的残酷：周佚口中的「婷儿」只是白衣女尸因他**千年痴情守护**而生的**一丝残魂**，且**已消散不复存在**——周佚此刻却似已忘却。

## 五、破封出困
- 生机渐生 → 身上紫气沸腾反扑、疯狂冲击其眉心金芒；周佚一喝「给我，散」，**紫气被彻底逼出**，顺地底阵法消散。
  - 注：若**水妖郡的古妖残魂**亲至，仅剩三道本命剑气的周佚或难抵抗；但仅驱散妖气并不难。
- 紫气散尽，周佚通体晶莹如水波流动。他召出宝塔内一道剑芒——**一把小巧、一看便是女修所用的仙剑，正是雨之仙剑之一**——化晶芒融入剑中，剑气纵横。
- 地面阵法四方漂浮的**三个神念光球**化神念扑来；剑内一声冷哼，本命剑气横扫，声震整个潮汐深渊：
  - 三个光球崩溃，被幻化而出的周佚**一口吞下**；
  - 地面四把元神之剑的投影涣散，**连同阵法一起崩溃**；
  - **封印裂缝刹那坍塌**，周佚携剑飞出，王林紧随，一剑一人出现于裂缝之外。
- 周佚对凌天候放话：数百年被困**非因封印之能，而因心死**；自陈「我是雨之仙剑剑灵，**与天地同寿，传承远古四大剑意**」，「我虽无法杀你，但你也别想在我不愿的情况下把我封印」；这几百年虽心死，却**无时无刻不在感受远古剑意的传承**，再见时且看修为是否如前。

## 六、出困后的交接
- 周佚在仙剑上幻化成形，**依旧是当年打扮，只是更添沧桑**，手持宝塔深深看了一眼，交予王林：「王林，帮我收好。」王林点头收入储物袋。
- 周佚欣慰道：「短短的几百年，你能走到这一步，可喜可贺。」
- 王林致谢当年的**问鼎之晶**；周佚言明那是**守护婷儿的报酬**，不必谢，反是周某该谢王林一意寻他，否则数百年后不会有今日相见。
- 周佚忆起当年宝塔内**有两把仙剑**，问另一把是否仍在王林处。王林拍储物袋放出**许立国寄身的仙剑**：
  - 许立国同为灵体，感应极深，觉周佚**如一切剑灵之主**，心生敬畏，甚至察觉**周佚才是自己寄身这把仙剑真正的剑灵，自己不过鹊巢鸠占**；
  - 周佚一点将许立国摄出，许立国讨好推诿：「小的是许立国，是我主子让我在这仙剑内的，可不是我自己强求的」——王林面色难看，冷冷瞪他一眼。
- 周佚提议（本章收尾）：「我之神通无法传承给你，但这灵体不错，我可使他与我感受**远古剑意**，催化其生长，**直至可以彻底操控你这把仙剑**。」

## 七、要点归纳
1. 本章是王林「报恩之行」的兑现：入裂缝、崩六道元神 → 恩情两清 → 反获周佚剑气疗愈，元神更胜从前，凌天候剑气亦被淬炼。
2. 周佚身份彻底揭明：**雨之仙剑剑灵**，本命剑气为其根本战力（九十九道 → 剩三道），传承远古四大剑意。
3. 关键情报链：青霜=仙帝青霖之女；青霖=仙界第一强者，仙界破碎后疑藏于妖灵之地洞府疗伤（未证实）——此情报正是周佚破心死之枷的钥匙。
4. 伏笔：残魂已散而周佚不知；许立国将由周佚以远古剑意催化，未来或成王林那把仙剑的合格操控者。
