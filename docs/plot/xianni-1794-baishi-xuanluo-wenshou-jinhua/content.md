# 第1794章 一声师尊守古脉（第二更）

## 一、抉择：龙身之路 vs 虚无之路

- 王林立于龙身之上，四周为寒冰防护。**龙身之路 = 转世投胎之路**，遥遥不知尽头，不适合王林走。
- 王林依稀看到**李倩梅等人**正在这条路上前行，去往投胎。
- 玄罗在其心神中告知：若要守护残魂平安、带她强行进入**仙罡大陆**，必须离开龙身之路，**从虚无中前行**，对抗**仙罡法则**——可能迷失，可能死亡。

### 仙罡法则的性质
- 无形，更多表现为**一股压力**；能坚持、抵抗得住，则有可能走出。
- 即便有玄罗出手相助，**成功率也只有一半**。
- 玄罗自陈：古往今来，**从未听说有大尊出手帮助洞府界之人对抗仙罡法则**，王林应是第一个——「此事是你的运道」。

### 洞府界设定（玄罗口述）
- 仙罡大陆**洞府无数**，几乎每个宗派都有各自的洞府界。
- 洞府界若要**繁衍众生，必须要有大道**；仙罡大陆大道尽管不多，却并不罕见。
- 自古无数洞府界生灵曾打开门试图走出，**均在仙罡法则下灭亡**。虚无中可见一个个门户（即各洞府），以及无数年来死者的**残骸**。
- 玄罗未知洞府生灵进入仙罡大陆会造成何种影响，但**希望王林成为第一个成功者**。

## 二、十年之约

- 玄罗在**仙罡大陆仙族之地无法逗留太久**，只能等王林**十年**。
- 仙罡法则中，玄罗**无法在王林身上留下印记**，无法知晓其平安与否；**唯一判断生死的依据就是时间**——十年内未走出，即视为死亡。
- 十年后玄罗离开时，其**法力会消散，仙罡法则将爆发到极致**；届时「**坚定的心，或许是唯一让自己不迷茫的根源**」。

## 三、拜师：一声师尊

- 玄罗坚持**在王林出发之前、而非成功抵达之后**收徒，问其愿不愿拜师。
- 王林心神一颤，唤出「**师尊**」。这一声代表：
  - 他与**道古一脉**从此有了无法割舍的责任与联系；
  - 他将为守护道古一脉**付出哪怕生命的代价**；
  - 这是**报恩**，回报玄罗为他所做的一切。
- 玄罗的深层打算：让王林**传承自己的衣钵**，守护道古一脉、守护自己转世的那一段时间；甚至考虑帮王林**进入太古神境、成为第十个太阳**（此事莫测、极为艰难，但他确曾这么想过）。

### 拜师之礼
- 玄罗右手一挥融开龙身路冰层，形成**缺口**，仙罡法则的**幽光**自外透入。
- 玄罗拍击眉心、**咬破舌尖喷出一口精血**，血化红芒成**血龙**，卷着王林直奔缺口。
- 自陈：「**为师九阳之一，一口精血守你一段路程**，再施法对抗仙罡法则，护你平安。」

## 四、蚊兽返祖：仙罡虚无中的蜕变

### 放出储物空间众生
王林临冲出前虚空一抓，放出**储物空间内几乎全部生灵与魂**（**除疯子外**）：许立国、刘金彪、蚊兽群等；**望月**因身子太大也有欲现之兆。王林请师尊将它们送去仙罡。

### 蚊兽异变
- 话未说完，**蚊兽群以王林的蚊王为首**，双眼疯狂、不顾一切挣脱飞出缺口——外面似有它们**极度渴望**的存在。王林与玄罗皆是一怔。
- 蚊兽在弥漫仙罡法则的虚无中**毫无不适**，身体急速膨胀、体内砰砰巨响、幽光闪烁，一副**回到家乡**的舒服模样。
- 旋即巨变：舒服的同时发出痛苦嘶吼，**大部分身体轰然爆开**，化血肉消散。未崩者继续膨胀，瞬息间有**百只如山峰**，很快又轰鸣崩溃。
- **蚊王**全身鲜血淋淋、凄厉嘶吼，似在对抗、又似在融合某种力量。

### 玄罗的判断（关键设定）
- 「莫要阻止，**你这群凶兽很是不凡**。」
- 它们**正在适应弥漫仙罡法则的虚无**；其**先祖似乎很久以前就生存在这里**，它们并非生于此，但**灵魂中有对此地的感应**，故**身与魂出现矛盾**，才会死亡。
- 比喻：**如同鱼儿适应了离水的生活，再回到水里反而可能溺死**。
- 结论：**这对它们是一次至关重要的蜕变**，不可阻止。

### 进化过程与结果
- 说话间蚊兽已死大半，**剩余不足一百**，个头极为惊人，仍在疯狂膨胀，**无一退避**——它们神智清醒，知这是**最关键的一次进化，一旦成功可如返祖一样**；**魂中先祖记忆在一次次膨胀中爆发**。
- **蚊王**身子最大，远看**足有数万丈**，与当年**风仙界**内王林所见的那只巨大蚊兽几乎一般大小，体内爆发出可怕气息。
- **半柱香后**，近百蚊兽再度轰轰崩溃。王林宁可蚊王进化失败也不愿其死亡（蚊王伴随他**两千多年**，如同亲人），**冲出冰层**扑向崩溃处。
- 临近刹那，**一声惊天动地的嘶吼 + 九声嘶吼**同起，连蕴含仙罡法则的虚无也似颤抖。
- 结果：
  - **蚊王**飞出，大小**足有一颗修真星**，巨大口器令众生头皮发麻；
  - 其后浮现**九只金色的万丈蚊兽**，每只都相当于风仙界裂缝中所见的那只蚊王，凶煞气息滔天。

## 五、玄罗的震撼：九种与古祖仙祖同生之兽

玄罗睁大双眼、无法置信地追述传闻：

1. **仙罡大陆初开时本是一片蛮荒之地**；
2. 此后**神境出现，开天辟地，衍变众生**；
3. 此后**星辰弥漫，但却在大陆之下**；
4. 此后**仙罡法则降临**，法则存在于虚无、**如同海水**；
5. 其内有**九种与古祖、仙祖同时诞生之兽**，这种凶兽**可以融合仙罡法则**——「莫非它们……」（章末悬念，指向蚊兽一族的真实来历）。
