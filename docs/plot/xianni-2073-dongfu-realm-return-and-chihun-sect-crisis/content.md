# 第2073章 洞府界（第二更）

## 一、辞别仙罡大陆

除清水与李倩梅外，王林已寻遍仙罡大陆上的所有故人——或为其解开前世记忆，或任其默默离去与遗忘。至此，他在仙罡大陆再无留念。

- **周佚与青霜**：王林远远看着，见周佚脸上幸福的笑容，亦露出微笑。数千年苦恋终得圆满，王林取出酒壶饮下一大口——此酒壶得自司徒南，此刻成了代替二人喜酒的祝贺。
- **祖城·海子**：王林前往祖城，远远一望后即转身离去，未曾相认。

## 二、天牛洲：解开天牛封印

天牛洲是王林当年初至仙罡大陆的落脚之地。他重走熟悉大地，路过大魂门、9j一宗，最终立于天牛洲正中心连绵山脉上空。

**王林之言**：天牛当年分魂所化铠甲曾助他数度渡过危机；他一生恩怨分明，今日为其解开仙祖留下的封印以作回报。但天牛身躯已化为大地无法收回，只能让其灵魂凝化元神、离开仙罡大陆。

**过程**：
1. 大地颤抖轰鸣，地气冲出，山脉模糊后浮出一尊庞大如可支撑天地的天牛虚影，向王林恭敬跪拜、道谢并愿意离去。
2. 王林右手一指——天牛身外闪烁大量符文，符文如生根般滋生无数细线，在魂体内连结成一个不断怦怦跳动的心脏状球体，此即封印核心。
3. 再一指——身外符文轰然崩溃，心脏状核心剧颤并肉眼可见地缩小；至指甲盖大小时化幽光飞入王林手心，被其一把捏碎。
4. 天牛魂仰天嘶吼，波纹回荡八方，直奔天空；在天地尽头回首再拜，如流星远去消失不见。

天牛魂离去后，天牛洲大地似有不同，却难以察觉究竟何处不一样。王林转身走向七道宗。

## 三、七道宗·洞府大门前：与清水重逢

七道宗即洞府界所在，山峰被迷雾笼罩，一片荒废废墟，久无人至。

- 一名青衫中年男子于山下仰望，喃喃“七道宗”“终于来到了这里”，沿破损山路缓行入雾，似要记住此地一草一木。
- 登顶后见山门与残殿，神色迷茫，长叹后于废墟之后寻到与山体相连、密封长满青苔、透出腐朽气息的巨大石门——**洞府界的大门**。
- 他闭眼再睁，苦涩自语：“这大门后，就是洞府界。我，就是从这里转世而出。”自恢复前世记忆后，他便离开所在宗门循感觉寻来。
- 抚门良久，神色绝然转身欲走，却见身后立着一身白衣、含笑的王林。王林轻唤：“师兄。”

此中年男子**正是清水**——他自行恢复了前世记忆，身上转世印记微不可查，再过些岁月将完全消散。二人大笑相拥，于洞府大门前对坐，王林取酒共醉，忘却时间流逝，互述经历，有说有笑亦有泪。

**关于红蝶与含烟**：王林提起红蝶时，清水怔了半晌，苦笑饮酒，道“前尘之事，遗忘就遗忘吧”，但他的选择是**不遗忘**——他相信仙罡大陆或许有让含烟复活的方法，“一定有”。王林深知对一个死去太久、连灵魂都已不存的人而言复活无从谈起，却没有说破：若一个人连希望都没有，就只剩绝望。

**分别**：清晨阳光透雾时清水离去。他既不遗忘，也不再回洞府界；来此只为看一眼七道宗、看一眼洞府界存在的宗门。心愿已了又见到王林，再无牵挂，此后要为他的梦去追寻——哪怕用一生，哪怕一次次轮回。

## 四、归返洞府界

- 所有故人中，**只有十三**选择跟随王林回洞府界，因为伴随师尊身边是其一生最大的满足；其余人各有责任、使命与羁绊，既已转世，大都选择遗忘、重新开始。
- 王林推开洞府大门，强光闪出，他步入其中随光消失，大门再次闭合。七道宗依旧迷雾笼罩、废弃无人问津。

## 五、洞府界现状

- **壁障**：界内与界外之间壁障极为牢固。这数百近千年中，界外力量曾发起一次冲击，未能破障闯入。
- **王林的传说**：其名在洞府界已成传说、成为不真实的存在；很多人记得，更多人忘记。界内修士亦然，唯**朱雀星上的雕像**被奉为圣地，仍偶被提起。
- **新仙界**：另一处王林故事延续之地。此界为王林当年创造，曾自界内四大星域迁来诸多修士——多为当年大战幸存者，其中不少人亲眼见过王林，少数曾与王林一同对抗界外。
  - **木冰眉**：当年未离去，留在新仙界，等着一个人有一天回来。
  - **蓝梦道尊**：未离去，作为整个仙界第一强者坐镇守护仙界平安。
  - **南云子**等人亦留下。

## 六、危机：赤魂教逼降

此刻新仙界一片压抑，如有乌云笼罩，众修士沉默：

- **蓝梦道尊，重伤。**
- **南云子，肉身崩溃，只剩元神。**
- 仙界之天一片血色，血色中无数虚影闪烁、时露狰狞相貌，如大量冤魂潜藏。

血色中一名**红袍青年**（自称“本少”，奉其“师尊”之命）向下方修士宣告：

1. 师尊给五天时间选择，**已过三天，仅剩两天**；限期内归顺**赤魂教**，否则死。
2. 对**木冰眉**：同样只剩两天。两天后仙界阵法被破之时，她若不成为其道侣，便**屠朱雀星、毁去那“叫什么林之人”的雕像**。

## 七、要点与悬念

- 王林返界的时机与新仙界五日之限的倒计时形成正面对撞：他归来时，尚余两天。
- 赤魂教威胁的两大标的（朱雀星雕像、木冰眉）恰是王林在洞府界最深的两处牵系。
- 清水选择留在仙罡大陆追寻复活含烟之法，与王林归界之路就此分道。
