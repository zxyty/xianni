# 第七卷 名震罗天 · 第820章 两件大事

## 一、大事之一：罗天令与备战联盟星域

### 起因
- 雷仙殿发布**罗天令**，号召罗天星域所有修真家族：待雷仙殿打开通往**联盟星域**之路后，齐入联盟星域。
- 背景：无数万年前四大仙界崩溃，相互连接的通道被阻断，四大仙界下属星域再无联系。此前只有极珍贵法宝可勉强开一道裂缝、渡一两名修士，从未有如此规模的备战。

### 罗天修士眼中的联盟星域（传闻）
- 没有修真家族，只有一个个**宗派**。
- 有从一至九级的修真国，与罗天截然不同。
- 法宝极多、丹药无数，每宗派如宝库，每修真星如宝藏。
- 最大势力是**修真联盟**。
- 修士嗜血、擅长厮杀，仿若魔头。

### 三大势力联合
- 雷仙殿获得两个**上古修真家族**支持——它们是罗天星域内除神秘的**远古修真家族**外最强力量，各自实力不弱于雷仙殿。
- 其中之一是**东临星向家**：并非雷仙殿寻上门，而是向家**主动**支持雷仙殿，并劝说另一上古家族共同谋划。
- 三大势力意志之下，其余家族不敢不从，备战风暴席卷罗天。

### 激励手段
1. **战功即赐星**：凡有战功者，其所攻下的修真星立刻赐予。罗天有灵气的修真星已饱和，欲得独属家族的修真星唯有去联盟星域抢夺。
2. **封仙**：雷仙殿拿出法宝、丹药、仙术，与两大上古家族联合封仙——仙界崩溃、雷仙下界后的第一次大规模封仙。
   - 名额：**天罡三十六人 + 地煞七十二人 = 一百零八人**。
   - 待遇：身份超过雷仙殿使者，受罗天所有修士敬仰；在联盟星域之战中成为一方首领。
3. **清水仙君指导**：雷仙殿宣布被封仙者可受当年雷之仙界的**清水仙君**亲自指导仙法。「居然还有仙君存活至今」——罗天星域为之沸腾，原本无意者纷纷调动族内精锐争夺封仙之位。
4. **天罡可提一愿**：包括向家在内的两大上古家族宣布，天罡三十六每人可提一个要求，由三大势力尽力满足。
5. **远古修真家族召书**（点燃备战之火的最后一击），全文仅一行：
   > 「封仙之举，大善。一百零八仙，可入**升仙池**，化**体元**为**仙元**，成就**真仙**。」

### 设定要点：仙元 vs 元力
- 仙人与后世修士的区别：体内并非只有元力，而是与仙力融合后产生的、独属仙人的力量——**仙元**。
- 仙术以元力施展再强也有限；以仙元施展方能发挥真正威力，**仙宝亦然**。

## 二、大事之二：姚家第四枚天穹令，目标「许木」

- **姚家**：罗天星域内仅次于上古修真家族的四个「传承之仙界的修真家族」中最强者，可与两大上古家族抗衡，连雷仙殿也不放在眼中。
- **天穹令**：自仙界崩溃无数万年来仅发过三次，「天穹一出，杀机四伏」，每次都是不死不休的腥风血雨。此为**第四枚**。
- 令上只刻一个名字：**许木**（王林在罗天所用之名）。含义不言而喻——姚家要杀许木。
- 许木之名声由来：当初在**雷之仙界**被许木救下之人及其家族广为宣扬，尤以获救者最为尊敬感激，使「许木」在东西南北四大域皆知；封仙风起时，很多人认为许木必是封仙之一。
- 舆论：几乎所有修士认为天穹令一出许木必死、昙花一现；惟**申公虎**、**战空烈**等寥寥数人冷笑，认为「姚家没有资格战尊主」。
- 当初被王林所救者纷纷沉默——非不愿助，而是背后家族无法反抗庞大的姚家。
- 姚家派出大量族人及有联系的修真家族，如撒网般弥漫整个罗天搜寻，搜寻强度达到前所未有的巅峰；但许木销声匿迹，仿佛凭空消失。

## 三、王林线：冲出陌域灰雾，重返罗天西域

- 王林正以加快速度在**罗天西域的陌域**灰雾内飞行，浓雾已阻不住他的脚步。
- **仙选族**族人随行数月，历经与灰雾凶兽的一场场血战：人数减少，杀气渐浓，茫然转为果断杀伐；队伍中间护着孩童与女眷。
- 王林的观察：仙选族天资聪颖、根骨极佳，**模仿能力可怕**，数月间学到他的果断、冷静与杀伐之气；且极擅联手出击，配合天衣无缝可发挥数倍实力（若非要护孩童女眷会更凌厉）。
- 王林施展神通之术笼罩女眷与孩童，冲出之速更快。
- 一日雾薄，王林冲出灰雾，眼前是璀璨星空——**罗天西域**。回望雷之仙界之行与被传送入幽冥兽的经历，恍若昨日之梦。
- 王林取出**申公虎**当年所赠的地图**玉简**查看，收回储物袋，需先找修真星确定方位。
- 对仙选族宣告：「此地便是雷之仙界下罗天星域，来到这里，你们便已然自由。」仙选族先祖老者请求暂时容身之地，王林略一点头——**青灵星**之大，容得下这些族人。

## 四、结尾悬念：土黄色星球的三名阴虚修士

- 飞行十日后，王林锁定一颗土黄色星球（灵力不浓但也不弱）。上百道长虹的波动惊动星上修士。
- 三人迎出：一中年文衫文士、两名老者，皆达**阴虚之境**。
- 三人惊疑：王林身后众人全无灵力波动，却弥漫从未见过的奇异之力，煞气浓郁、神色冰冷隐含杀机，队中却有孩童女眷，来历难猜。
- 关键转折：中年文士细看王林，**觉其样貌与姚家近日传出的天穹令画像有些相似**。
