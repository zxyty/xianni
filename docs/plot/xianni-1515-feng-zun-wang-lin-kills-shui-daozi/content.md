# 第十卷 叱咤界内 第1515章 封尊！！

## 一、幽冥兽的惊惧

- 幽冥兽反应迟钝，未察觉王林已然离去，仍独自对前方修士怒吼；待回头发现身后空空、王林已远赴水道子处时，瞳孔骤缩，怒吼转为惊恐之吼，绒毛拉耸、心跳怦怦作响。
- 它带着恐惧与委屈冲回王林身边，此后虽再度竖毛怒吼作威武状，却始终分出一部分目光紧盯王林——王林若退，它必立刻后退。此次经历成为它记忆犹新的教训。

## 二、六拳诛水道子

王林迈步临近，不再以虚幻拳影，而是直接以肉身拳轰击水道子元神，每一拳皆报出因由：

| 次序 | 王林所言 | 结果 |
|---|---|---|
| 第一拳 | 「这一拳，是代封尊」 | 水道子喷出元神之气，元神黯淡后退 |
| 第二拳 | 「这一拳，是为了李倩梅」 | 元神双腿爆开，化作元气四散 |
| 第三拳 | 「为了云海修士，为了你方才欲杀归元宗」 | 轰在胸口，元神近乎透明 |
| 第四拳 | 「是为了方才你那金色风暴」 | 元神左臂轰然爆开 |
| 第五拳 | 「是为了我王林」 | 右手如抓日月星辰苍穹，破开元神，胸口透出巨大窟窿 |
| 第六拳 | 「不为了什么，就是要杀你」 | 因木冰眉之事在身前三寸骤停，稍后落下，抹其魂 |

期间水道子两度求生：先自称「我是第三步大能」，再言「我是封尊之奴，你收我为奴，实力定然大增」，皆被王林冷漠无视。

## 三、水道子最后的杀手锏：木冰眉

- 水道子仰天大吼：「我与木冰眉姓命相连，你杀我，就是杀她——她是你的女人。」王林第六拳在其身前三寸骤停。
- 水道子狂笑揭破：他为木冰眉恢复修为、赠送丹药，目的就是让她的命魂与自己相连；「那金色铃铛又算得了什么，她，才是老夫的护身符」。
- 其右臂一甩，天地扭曲幻化出一座大阵，阵内盘膝女子白衣染血、面色苍白，正是木冰眉。

## 四、木冰眉的自白

- 「柳眉对不起你——柳眉是我，我就是柳眉」：随身子虚弱，她渐渐忘记自己是木冰眉，也想成为柳眉。
- 因平儿的存在，二人「只能成为最熟悉的陌生人」。
- 那丹药她本可不服：昆虚毁灭、家乡残破，只剩她一人，她「承受不住了」；修为恢复、身为圣女亦无意义，她只想看一眼自己的孩子却做不到。
- 她称二人是孽缘、是王林心里的一根刺，以此方式死在王林手中不会有怨言——她欠的不是王林，而是平儿。
- 遗言托付：若有一天平儿苏醒，请告诉他「李慕婉，才是他的母亲」；愿以自己的死了却两千年纠葛，「你解脱，我解脱」。
- 她闭目落泪，抬右手按向眉心自尽。

## 五、王林的抉择：一字定身 + 道古化命术

- 木冰眉抬手刹那，王林眼中精光一闪：右手毫不犹豫轰出杀拳，左手同时一指扭曲天幕内的木冰眉，施「一字定身」，其右手骤停。
- 那一拳崩溃水道子右臂并轰入其元神头部，直接抹杀其魂——**水道子，封界之尊奴仆、神宗大长老、云海第三步大能，就此死亡**。
- 水道子死亡瞬间，王林诵出复杂口诀，罕有人能懂，唯隐隐散去的鬼宗九星古妖动容认出：「道古化命术——传闻先祖古族一生只能施展三次的化命之术」。
- 道古化命术为王林在古墓所得传承中知晓：此术对李慕婉无用，但此刻可将水道子的全部生机转给与其性命相连的木冰眉。
- 关键手法：王林杀的是「魂」，却在最关键时刻放弃将其全部毁灭，刻意保留与木冰眉相连的本命生机——「若是换做当年，王林做不到这点，但如今，他可以做到」。
- 木冰眉被定身之身一震，水道子全部生机以特殊方式融入其体内，进行诡异融合。
- 王林道：「你不欠平儿，也不欠我。」随后挥手解开定身。

## 六、封尊之名传遍云海

战后四方修士齐拜：

- 妖宗诸人在宗主带领下齐拜：「妖宗修士，参见封尊」
- 神宗众人目睹全程，心情复杂纷纷抱拳：「神宗修士，参见封尊」
- 云海鬼宗由大虚上人带头抱拳：「云海鬼宗，参见封尊」
- 四面八方更多修士齐声：「云海修士，参见封尊」

幽冥兽的阵阵低吼冲散了水道子死亡的血腥，挤入四周修士的沉默之内。

## 七、要点与悬念

- 王林「封尊」名号自此正式为云海各宗所公认。
- 木冰眉获水道子全部生机，生死状态由必死转为存活（融合过程「诡异」，后续待观）。
- 「平儿」与李慕婉的母子归属被木冰眉亲口厘清。
- 道古化命术首次施展，且明言对李慕婉无用——与王林复活李慕婉的执念形成对照。
