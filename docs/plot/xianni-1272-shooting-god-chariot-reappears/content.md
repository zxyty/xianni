# 第九卷 云海之巅 第1272章 射神车再现

> 世界状态须知：本片段主角自第1063章起在云海星域以化名『吕子浩』行事（身份由吕烟菲奉上），文中「王林」即其本尊，言行归【王林】。

## 一、局势：杀劫倒计时

- 王林推衍得知有一名**第三步大能**要杀自己，几乎没有存活可能。
- 开篇距杀劫**还有两天**，中段缩至**一天**，收尾只剩**十二个时辰**。
- 心态基调：换作任何修士都会心神崩溃，但王林身为**逆修 / 王族古神**，骄傲与逆天之意不允许屈服——「我可以死，但却是战死，而不是屈辱任由宰杀，想要杀我，必须要付出代价」。连续五天准备，双眼充满血丝，战意达到巅峰。
- 这是王林一生中罕有的短时间疯狂备战：每多一分准备，交战时保命的可能就多一丝。

## 二、第二道反击：近百蛮荒大陆炼成阵之法宝

- 王林所在之地环绕**近百个蛮荒大陆**，按奇异方式排列，蕴含天地之力，规则隐现。
- 王林与**银衣女子**共同施展**三大禁制**笼罩这近百大陆，三禁制融合形成毁天灭地的风暴，被王林不断压缩，最终把上百大陆生生炼成一个巨大的**阵之法宝**。
- 对比：当年**炎雷子**借**雷仙界碎片**炼成通天法宝；王林此番阵法材料不如昔日炎雷子，但神通相当，因三大禁制隐隐有超越迹象——文中断言炎雷子此时与王林一战必败。
- 战术意图：压缩隐藏并非自认能瞒过第三步大能，而是**蓄势**，蓄到一定程度后展开最有力的爆发。

## 三、第三道反击：符族符文之术，凶兽化符箓

- 传承来源：**符族圣祖**曾传授王林符文之术；后来**塔山**又把自己领悟的符文之术暗中告知王林。
- 术法原理：以**兽皮**炼制，取兽全身精华而动，化作符文，成惊天动地之威。因所需生灵极多，王林本不愿使用，此刻不得不用。
- 施法过程：双手掐诀一挥，血色狂风横扫至所有蛮荒大陆并将其尽数包裹；王林诵出极复杂咒语，咒语化作符文融入血色风暴。
- 结果：搬移大陆时未驱赶凶兽，故陆上凶兽数量恐怖。血色风暴中凶兽血肉急速枯萎、骨骼融化，全身精血精华凝于眉心一块皮上，形成**血色符文**。
- 波及范围：无法计算数量的凶兽惨叫**传遍整个五阶星域**，全星域修士心惊肉跳，低修为者幻觉频生几近失控。
- 威能量级：遮天盖地的符箓所散威压，足以令一名**碎涅后期**修士瞬息肉身崩溃、元神难逃而道消。

## 四、四道反击的完整清单

| 序 | 杀招 | 性质 |
|---|---|---|
| 一 | 千万剑气化作**剑之一指** | 剑道极招 |
| 二 | 近百蛮荒大陆 + 三大禁制 | **毁天**之力 |
| 三 | 无数凶兽所化**符族符箓** | **灭地**之力 |
| 四 | 两辆**射神车**（第二、第三辆） | 仙界战车 |

- 备战代价：王林体外堆积的无数**元晶**随元力运转吸收而轰然崩溃，元力尽失、消散天地。
- 王林自评：这三大杀招即便**天人衰劫者**也必死无疑，但仍**并非我两千年修道的极限**。

## 五、第二辆射神车：雷兽解封成长矛战车

- 王林自储物裂缝取出由射神车开封所化的**雷兽**；此兽已通灵，知晓王林生死危机，双目精光凝重。
- 先挥手震碎炎雷子当年以古怪之物给它做的装饰，令其恢复当年雄姿。
- 王林指出：化作雷兽的射神车身上仍有数道封印，往常修为无法打开，眼下可以。
- 解封：向前一吹狂风，雷兽体内咔咔如镜裂；王林双目暴睁、喷出一口鲜血，喝令「这第二辆射神车，开全部封印之力」，封印一道道全部开启。
- 成形：雷兽膨胀至**数千丈**之高——下半身蠕动化作巨大**天地战车**，上半身化作长约**万丈**的巨大**长矛**，长矛与战车相连、雷霆电光无尽。气息扑面令王林呼吸一滞，大地与四周近百大陆同震。落定于王林**左侧**，万丈长矛带阴寒萧杀之气直指天际。
- 出处背景：射神车当年在仙界内并未叱咤，就随**仙界崩溃**而埋没。

## 六、第三辆射神车：五彩蝴蝶破茧成七刺战车

- 王林自储物裂缝放出**五彩蝴蝶**，环绕其身，蝴蝶四周有**血燕**伴随。
- 王林评价：这第三辆射神车**当为最强**；其上封印即便现在也无法**全部**打开，但除**最后一道**外其余有把握。
- 催化：掐诀一指并泌出鲜血落于蝴蝶，蝴蝶身颤、停止扇翅，四周结出巨**茧**——与当年破蝶之物同样，一出现便疯狂凝聚天地元力，连王林体内元力也被急速吸走。
- 茧涨至**千丈**大小方止，其内气息越来越犀利；王林闭目不断取出元晶、吸收天地之力补充。
- **一天之后**茧轰然崩溃，气浪把王林都吹出数千丈外，王林眼露狂喜。
- 成形：茧内是一辆**数百丈**大小、全身闪烁七彩光芒的战车；无长矛，而有**七道百丈狰狞利刺**，不断吸收天地之力，利刺上显出七彩之芒。轰然落地后，与长矛战车分列王林**左右**。

## 七、最后十二个时辰：祭炼断剑血锈

- 时间只剩一天、即十二个时辰；推衍显示十二个时辰后杀他之人将至。
- 最后一道准备：从储物裂缝取出**断成两截的铁剑**。
  - 铁剑即便修复也不足以抵抗此次杀劫，且时间来不及，王林根本没打算修复。
  - 他要的是剑上的**血迹（血锈）**。
- 血锈判断：王林察觉不出端倪，只感其内蕴含一股无法想象之力——**与古神之血类似但又不像**，甚至与**青龙圣皇**所说的**天道之血**也有一些相似。
- 行动：张口吐出吸力笼罩两截铁剑，直接吞入口中，在**元神内**开始祭炼。（章节收束于此）

## 八、关键伏笔 / 待验

- 第三辆射神车**最后一道封印**未开，留有后手空间。
- 断剑血锈的真正来历（古神之血？天道之血？）未解，正被祭炼。
- 第三步大能的身份、以及三大禁制蓄势爆发的实际效果，均待下章。
