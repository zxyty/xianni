# 第1639章 仙人忆

## 一、抉择：为洞府真相不惜代价

王林衡量夺取干瘦老者记忆的代价是否值得。脑海中浮现其一生对这片天地的种种怀疑，最终定格在方才的结论——**自己所在的天地，只是一座洞府**。他遂下定决心：「我想知道，这一切的缘由，这洞府当年的真相。」

## 二、古之三族同显：古族不灭指

- 王林眉心**七个古神星点**急速旋转，左目**古魔**、右目**古妖**星点同时转动，化作星光涌遍全身。
- 身后显化：中为虚幻**古神**，左为**古魔**虚影，右为**古妖**虚影——古之三族首次同一时间出现在其身后；三族虚影之后更有遮天蔽日的**道古头颅**。
- 元神急速膨胀，王林强行压缩凝聚，身体保持原大小而内蕴古族惊天之力，恢复之力可怕。
- 全部古族之力凝于**右手食指**，是为**古族不灭指（吉族不灭指）**：
  - 出处：王林在**梦道**之中，除本源神通外自行感悟的**第七式**；
  - 缘起：感受**仙人不灭体**后自行明悟；
  - 特性：不需仙力，全用古族之力；攻击强悍且恢复之力「不灭」——恢复速度快过无数次毁灭；
  - 局限：以其当时修为，只能令**一根手指**做到「天灭地灭指不灭」。

## 三、破仙尊封印

盘膝而坐的七彩之芒中年男子（雕像男子）身外**三寸**为封印之地，一切力量与物质进入即瓦解，此前不可逆转。

- 王林一指刺入，手指瞬间崩溃，却同时疯狂重凝；越深入崩溃越剧烈，瞬息间十万、百万乃至千万次崩溃与重凝循环。
- 最终恢复之力**超过崩溃速度**，手指完全凝聚成形，一指点中中年男子眉心。
- 爆发出足以毁灭星空的轰鸣：王林元神所处雾气崩溃，干瘦老者识海随之瓦解，牵动其全身崩溃；七彩中年男子身体扭曲消散。

## 四、定神之术夺取记忆结晶

- 中年男子消散后，识海内浮现**拳头大小的淡金色结晶**——干瘦老者一生的记忆。
- 该封印极为霸道：既阻止他人搜魂，消散后更会令被封者记忆一并崩溃，使搜寻者一无所获。
- 王林以**一式定神之术**喝出「**定**」字，结晶应声一顿；元神向前一卷笼罩结晶，冲出瓦解的识海，回归远古仙域中的肉身。

## 五、干瘦老者之死与波及

- 王林右手自老者天灵抬起、退后数步，老者惨叫至极致，身体自内部崩溃：识海被轰灭、元神被轰杀、骨骼粉碎、血肉撕裂，最终四分五裂爆开身亡。
- 爆开的冲击之力＝**王林古族不灭之力 × 老者仙人血脉之力 × 七彩雕像男子封印之力**三者对抗形成的毁灭之力。
- 波及：四周未被王林毁灭的雕像被直接粉碎，数名雕像内**沉睡疗伤的仙人**未及睁眼便凄厉死亡。

## 六、四座巨雕内的震骇与变计

远古仙域诸多雕像深处，四座高耸入天的巨大雕像先后有人现身：

- **白虎**（雕像漩涡内探出的白发老者）：不敢置信——三寸封印足以毁灭一切力量与物质，「就算是我们在巅峰之时一起出手，也绝不可能破开」。
- **玄武**：古往今来未闻仙尊封印被破，即便**仙罡大陆**其余**大尊**要破也极为艰难；此乃**仙尊自创神通**，是**七道宗核心弟子保护隐秘的终极手段**；震惊于「他只是下界蝼修」。
- **第三位老者**：断言此子不凡，「**我等要改变计划**」，认为其神通在仙罡大陆亦足以惊天。
- **朱雀**：沉默不语，望着前方天地，神色变化不定。

## 七、王林的反应

王林退后后神色如常，抬头隐隐扫向远处，嘴角冷笑——**他早就感受到了那四个人的存在**。
