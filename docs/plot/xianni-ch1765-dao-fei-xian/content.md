# 第1765章 道非现！

## 一、王林的最后两箭

- **第二箭**：出弓刹那，王林双目内由仙人血脉凝聚的金光崩溃、将散未散之际被他强行保留最后一丝。为免被人看破，王林在出箭瞬间闭眼。他自知只余最后一弓之力。
- **目鱼幻箭**：第二箭引动星空如绸布层层卷起。八条已睁开一丝双目的目鱼呼啸而来，临近时身形急速缩小，在黑光中化作八支与李广箭一模一样、连气息都相似无二的箭。七彩道人、掌尊、三大战将及所有目睹者皆为之一愣。
  - 五行星马姓老者猜测这是『目鱼开眼后的天赋神通』。
  - **玄罗大天尊**是此地唯一知晓者：目鱼睁眼即可幻化任何一物并具其部分威力，唯此兽极难开目，此洞府内数只极为少见。玄罗因此起了兴趣。
- **破幕重创**：九支李广箭交错难分真假，直奔七彩道人。七彩道人以七层不同颜色、内浮无数符文印记的光幕相抗，光幕与八支幻箭同归崩溃（幻箭复化为八条目鱼，连同修真星崩溃时卷出的第一条共九条，皆奄奄一息）；崩溃冲击化作遮蔽视线与神识的巨浪，而**第九支（王林本人的）李广箭穿透一切壁障命中七彩道人**，其胸口被洞穿一个拳头大小的窟窿，喷血重创。
- **第三箭**：七彩道人癫狂前扑，咆哮『老夫宁可不要第三魂，也要杀了你』。王林已油尽灯枯、面色苍白，仍咬牙第三次拉开李广弓——他知道这或许是最后一次开弓。第三箭出的刹那他再度闭眼，掩去瞳中已完全崩溃消散的金光。

## 二、李广弓的来历伏笔

七彩道人内心憋闷至极：**李广弓本是他当年要掌尊送出之物**。原本的算计是——让王林以此弓引出连道非，并在王林与战老鬼结怨后，以此弓伤战老鬼。因为此弓他与战老鬼二人『都不完整』，谁也无法施展使用。不料如今重伤自己的，正是这把弓。

## 三、九阳自爆与一界灭亡

- 七彩道人施展最强攻击神通**九个太阳**，九阳万丈光芒直撞第三箭。九阳陆续崩溃，第三箭亦现瓦解之象，最终轰然爆开。
- **青龙战将**因距离稍近，被冲击一碰全身崩溃，当场死亡。
- 此界星空齐齐碎开，**一界灭亡**；三百残界在冲击下陆续崩溃碎开。
- 玄武战将、朱雀战将惊恐后退欲逃；掌尊面色苍白化作长虹倒卷；第三妃、蓝梦道尊、五行星诸人齐齐后退，欲离第一花三百界。
- 处于毁灭核心的七彩道人被余波灌体，伤势更重，仍双眼疯狂，断言王林距离最近、以其修为必被形神俱灭。

## 四、王林的后手：抓出连道非

王林早已料到必有此毁灭冲击，做足准备：冲击临身刹那，双手掐诀、右手虚空一抓，暗叹一声『得罪』，抓出一个身穿邋遢长衫、打着呼噜沉睡的**疯子**挡在身前。

- 此疯子拥有**完整的仙人不灭体**，星空崩其身不伤，毁灭冲击卷身而过毫发无损。
- 疯子半睡半醒睁眼，向七彩道人怒吼：『谁打扰本王睡觉』『本王要告诉我哥哥』『居然在本王睡觉的时候给我挠痒痒』，说着说着又打起呼噜睡去。

## 五、身份揭破，全场震动

- **七彩道人**：重伤之下认出连道非，脑中刹那清醒。他猜不透王林还有几弓之力，若连道非出手加上李广弓，自己此番怕真会死在这里，于是倒退遁走——这是他与王林一战中**第一次选择逃遁避开**。
- **掌尊**：逃遁中身子一颤险些坠落，脱口喊出『主主人』。
- **玄武战将、朱雀战将**：猛然转身，滔天骇然，呆看被王林提着双肩的疯子，惊呼『连道非』。
- **第三妃**：面色苍白、刹那呆滞。
- **五行星马姓老者**：不知当年连道非来此之事，见之心神一片空白，透出无法形容的恐惧。
- **战老鬼**：早已在鬼脸雾气中睁眼目睹一切，却始终未走出雾气，目光闪烁不知在想什么。
- **玄罗大天尊**：正走向九条目鱼收取（已收走第五条），忽然驻足细看疯子，双目奇光：『连道非……连道真的弟弟……他居然也来到了这里。』

## 六、要点归纳

1. 王林三箭代价极大：仙人血脉之力至此彻底耗尽。
2. 目鱼开目神通首度全貌展现（幻化万物+部分威力），并被玄罗大天尊盯上。
3. 七彩道人首次败退，且其算计李广弓的旧谋被点破。
4. 连道非现身为本章最大转折，并牵出『连道真』其人与掌尊称其为主人的关系伏笔。
