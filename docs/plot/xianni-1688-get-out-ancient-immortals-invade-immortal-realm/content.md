# 第1688章 滚出去！（第三更）

## 一、界内仙界：远古仙人破门

- 数十名远古仙人狂笑中撕开银河，银河崩溃出巨大缺口，露出下方数万名恐惧的界外修士。
- 仙人扬言「敢阻止我等仙人吸收香火」，散开血脉之力镇压大地，数万修士不敢动弹；一人抓起一名召河女修欲当场吸为香火。

### 阻拦者

| 人物 | 反应 |
|---|---|
| 清水（清水仙君） | 双眼红光、杀戮本源凝聚全身；因女儿在仙界、仙界为众人亲手搭建，「哪怕是远古仙人也要杀」，率先冲出 |
| 红杉子、南云子 | 神色大变，犹豫一瞬后咬牙同时迈出 |
| 青霖 | 挣扎最剧烈，见银河缺口下修士恐惧之状后怒吼前行，高呼「住手诸位远古仙人，这里是我界内仙界」 |
| 水道子 | 同被金色风暴震退 |

- **关键设定**：仙人血脉之力对界内修士产生来自灵魂的天敌式镇压，青霖、水道子、南云子齐齐后退；**唯独对清水毫无作用**，清水径直冲出金色风暴。

## 二、转折：王林的雕像与玉简

1. 一名仙人散开神识，笑声戛然而止，惊恐尖叫：「他的雕像那里有他雕像」。
2. 数十仙人（含后续陆续而来者）神识散开，看清远处山峰雕像容颜后齐齐倒吸口气——他们忘不了**三年前远古仙域内的那一箭之威**。抓女修的仙人当场松手、面色苍白。
3. 司徒南惊醒，取出并捏碎玉简。玉简来历：三年前他与王林于**朱雀星**相遇、王林知晓**洞府界**之事后，离开前交予他，约定「远古仙人降临之日，若有仙人残杀界内修士，则捏碎此玉简」。
4. 玉简碎裂爆发王林气息，星空扭曲中幻化出白衣身影（玉简内一丝神识所化的虚幻之身），双目冰寒扩散。

> 「朱雀、玄武、青龙、白虎，这就是你们说的约定么」——「**滚出去**」

5. 一声杀戮低吼引动众仙记忆，数十仙人面色苍白齐齐后退，转眼离开仙界。

## 三、青龙赔罪

界外陆续来临的数十仙人中，一名老者正是**青龙**：阴沉地瞪了闯入者一眼，向仙界内抱拳沉声赔罪——「老夫管教不严，来晚了一步……好在没有造成伤亡……我等远古仙域之人，不会杀任何一个界内修士」，重申交易如旧。

## 四、界外太古星辰：王林的真正杀招

- 王林本体盘膝于**界外太古星辰**，早有预料故当年留下玉简；见仙人狼狈离去后正欲开口，忽有所觉，起身急速前往远处。
- **远古仙域设定**：本为一体，后分裂为界内、界外两部分，彼此仍有联系；**界内远古仙域开启，会使界外远古仙域随之开启**。
- 界内剧变虽有阵法阻隔，仍被太古星辰大能略有感受。**掌尊**面色大变，惊觉王林意图：「他居然是要以两界之力，去毁灭我界外远古仙域……他定是知道了一切，知道了这里只是**洞府界**」，随即直奔星空；其余大能亦同时醒悟。

## 五、裂缝星域：七道宗仙人出世

- 王林一瞬即至一处星空布满裂缝的星域；裂缝交错下星空轰然崩溃如天塌，出现巨大缺口，远古气息疯狂扩散，金色光影（远古仙人）鱼贯而出。
- **归属**：这些仙人均为**七道宗**弟子，但如今听命者并非七彩道尊，而是其仙妃——更准确说，是听命于**被七彩仙尊在危机时抛弃以保命的道侣**。当年若无该道侣受命，七道宗弟子断不会听命几位仙妃；**此亦为当年洞府大战根源之一**。他们是几位仙妃最后的杀手锏。
- **第七妃**神色剧变直奔王林；**第三妃**亦心神一震急急赶来。
- 出世仙人的宣言：「四大战将定然也走出，杀了他们、获得道统，我们就可组建新的七道宗」「不仅要杀光他们，更要毁灭这洞府界所有众生，只有这样才可以重开洞府」。

## 六、结尾：金光乍现

- 众仙不识王林，视其为可随手吸食的「蝼蚁」，一名仙人狞笑扑来欲将其吸作香火。
- 王林睁眼，目内轰出金光——**融合眉心仙人不灭体血液后凝聚而出的、精纯至极的仙人血脉之力**，并冷讥：「仙罡大陆的普通修士，七道宗的寻常弟子，也敢自称为仙么」。
- 来袭仙人一愣、面色大变、下意识后退，心惊肉跳中惊问：「你是谁」——章末悬念。
