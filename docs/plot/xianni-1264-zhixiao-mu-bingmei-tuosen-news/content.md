# 第1264章 知晓（第九卷 云海之巅）

## 一、云海重逢：王林与木冰眉

- 夜色下的云海神宗庭院，王林与木冰眉隔着一道打开的门相望，门如沟壑，二人沉默。
- 王林一生中，除李慕婉外，总有一个「柳眉」或「木冰眉」的身影相伴：朱雀星如此，罗天星域如此，如今到了云海仍是如此。
- 木冰眉迈过门槛走入庭院，立于王林数丈之外，沙哑开口：「没想到在这里，能遇到你。」王林平淡回应：「世间之事，大都难以预测。」
- 木冰眉容颜绝伦、气质高贵（昆虚圣女多年养成），是王林一生所遇女子中容貌之最。
- 柳眉是木冰眉的分身，柳眉的一切在木冰眉身上得到延续，王林有时都分辨不清她究竟是柳眉还是木冰眉。但王林离开联盟星域前已与此女了结一切恩怨——「让那风归去，再也吹不动心」。
- 王林此刻神色平静，望之如陌生友人，不复往昔复杂。

## 二、噩耗：拓森脱困后横扫联盟星域一带

木冰眉问王林是否认识一个叫**拓森**的古神，随后逐条道出：

| 对象 | 结局 |
|---|---|
| 罗天星域大军 | 崩溃，被杀无数，退回罗天再不敢踏入半步 |
| 鲁夫子（罗天大神通修士、第三步修士） | 避退星空，不敢与拓森一战 |
| 尸阴宗 | 所占星域被寻到，王者败落、死伤众多，几乎分崩离析 |
| 四圣宗 | 死伤惨重；青龙圣皇修为通天仍不敌，生死不明 |
| 修真联盟残余 | 全部瓦解、鸟散而走；唯总部阴差阳错未被注意，得以健全 |
| 雨仙界 | 未受破坏——拓森曾前去，在雨界外被**青霖**所阻，二人似有约定，拓森离去 |
| 昆虚之境 | 已然不存，其内修士全部战死；守护昆虚的**管家先生**死于拓森之手，换来木冰眉一线生机 |

- 王林听闻瞳孔收缩、气息凝聚如将喷的火山，完全没料到拓森苏醒会在联盟星域掀起如此惊涛骇浪。
- 木冰眉对王林说：「你是对的，若当年茹儿选择留在我身边，那么此番劫难，以她的修为，难逃生死。」

## 三、木冰眉的现状与来意

- 肉身已崩溃，现在这具身体是**近日重新凝聚**而出；修为大范围倒退，恢复巅峰需时间。
- 身为昆虚圣女、承昆虚传承；数万年前那一代昆虚圣女与**云海神宗**有旧，**神宗大长老**欠下情分，故她以秘术逃至云海，欲在神宗修炼、借神宗之力恢复修为。
- 她告知王林一切，本意是担心王林安危、要他早作准备并尽快离开。

## 四、古神烙印：发现与吞噬

- 王林骤然上前，右手双指成剑点向木冰眉眉心；木冰眉面色惨白、若有所悟，未闪躲。
- 其眉心浮出一团急速旋转的气息，内透浓浓**古神气息**——外人不可察，王林却清晰感受。
- 木冰眉崩溃流泪反复道歉：她来云海后多次探查身体与元神、身体更是重新凝聚、元神寸寸搜寻，从无发现。
- 王林温言宽慰：此事与她无关——连罗天第三步修士鲁夫子都被拓森击退险些身亡，以拓森之能留下的烙印，绝不会让她找出端倪。
- 王林随即断言「未尝不是给我送来了补品」：虚空一抓，古神气息相互吸引下烙印脱离木冰眉眉心直奔王林；王林眉心星点旋转吸收，融入**刚具雏形的第六星**。
- 心神中拓森虚影狰狞咆哮，王林的虚幻古神之身当即现于其前——一场吞噬与吸收，烙印气息不多，片刻被强行吞噬，**第六星更为稳固**。

## 五、推理：拓森已破封界大阵去了界外

- 木冰眉补充：拓森离开联盟星域前曾喊出王林之名欲寻，还来过云海星域，但似乎怎么也找不到；具体时间不清（她当时闭关恢复），**大致不超过百年**。
- 王林推演：
  1. 这百年他大多在奇异的**种道空间**内，而此处似与**封界大阵**有关联；
  2. 故拓森在封界内感应不到他的气息；
  3. 若拓森仍在封界内，自己离开**七彩界**已有数月，他断无不寻来之理；
  4. 至今未来 → 几乎可断定拓森已以某种方法**破开封界大阵、去了界外**。

## 六、界外同步：拓森的暴怒

- 界外**太古星辰**内，一个巨大古神带怒吼从一处太古之族中冲出，身后血腥弥漫、红光滔天——这已是他毁灭的**第九个太古之族**。
- 就在屠戮的刹那，拓森清晰感受到留在昆虚圣女身上的烙印，**发觉了王林的气息**。
- 拓森面色难看、疯狂咆哮：「你在界内你怎么可能在界内，我明明已经在界内寻找了无数遍」——但此刻的他已无实力，短时间内无法再破开一次封界大阵。

## 七、要点与伏笔

- 拓森已知王林在封界内，且短期内无力再度破界 → 王林获得一段缓冲期。
- 王林通过吞噬古神烙印获益（第六星稳固），是「他人之祸化为己身补品」的典型冷硬处理。
- 修真联盟总部与雨仙界的保全，青霖与拓森的「约定」，均为后续伏笔。
