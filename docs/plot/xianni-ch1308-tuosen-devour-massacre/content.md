# 第1308章 拓森！！（第九卷 云海之巅）

## 一、局面
王林（本期以化名『吕子浩』行走云海星域，自第1063章起）身受重伤，独身立于封界大阵之外，面对数百名前来守阵/阻杀的界外修士（太古星辰之民）。

## 二、黑雾吞噬开场
- 一名界外修士被撑爆，血液刚弥漫即凝回，与其元神一并被自其体内钻出的黑雾吞噬干净，惨叫响彻星空。
- 一名碎涅圆满的老者大喝「结阵」，众修后退掐诀、眉心浮现不同印记。
- 黑雾吞噬完前者后直扑该老者，随即消失无踪；老者以元力外爆掀起气浪自保。

## 三、红色闪电斩杀碎涅圆满老者
- 有人喊「此人重伤，我们散开修为，他不敢接」，话未说完，老者身后虚空黑雾骤现。
- 黑雾中射出两道目光，内蕴红色闪电与天地至极之力，星空阴寒如玄冬腊月。
- 老者掐诀连拍、以碎涅修为化出五光十色神通阻拦，触之即崩；又祭出巨大鬼脸盾牌，大吼「祖灵佑」。
- 盾上鬼脸幻化张口吞闪电，惨叫崩溃；盾牌四分五裂。
- 红色闪电入老者眉心：双眼黯淡、流出黑血，识海坍塌、元神灭绝、生机尽散。黑雾包裹其肉身，片刻后只余皮包骨尸骸，化作飞灰。
- 黑雾中传出阴森之语：「这就是界外修士么」。

## 四、界内/界外的立场翻转
- 界外修士原本视界内修士如绵羊困兽，自视每一个太古星辰之民都可称界内的「天道」，视界内如蛮荒野人。
- 此战瞬间崩塌其认知，滔天惊恐下一哄而散，只剩「逃」的念头，称王林为「魔」。

## 五、正面血腥屠杀
- 王林自黑雾中幻化现身：身子干瘦、周身絮状黑雾，如自地狱魔界走出。
- 吞灵噬体绝天连续吞噬数人后，其体内伤势极快恢复；吞噬时的舒服感如服下升仙果，令人着迷难舍。
- 左手掐住一名界外青年修士脖颈边冲边吸，元神、魂魄、元力、生机尽被吸走，身体爆开、血液亦被吸收。
- 随即追上一名面容娇好的女子，将其撞在胸口疾驰，女子迅速枯萎只剩枯骨。
- 配合缩地成寸，一闪即追上一人，男女不论皆为敌；「界内与界外之战，没有原因，只有杀戮」。

## 六、收网与清场
- 数百修士已死大半，余下近百修为最高者逃出很远。
- 王林旋身带动黑雾化作巨大漩涡，产生强大吸力将逃者向后吸撤。
- 忽然面色大变、转身望向远处，左手一挥令黑雾化作条条手臂扑向四周深处，缠绕近百修士展开吞噬。
- **结果：此地所有守阵界外之人全部死亡。**
- 吞噬后王林元神饱满、魂魄凝固，唯胸口伤势恢复较慢。

## 七、封界大阵的旧事（闪回）
无数万年前，界内仙人欲冲出封界大阵，被阵灵杀死，界外冷漠观望。该仙人死前怒吼：「终有一曰，吾辈修之后人，必将破开阵法，让你等外民万灵灭绝殆尽，让你界外血流成河」。本章的屠杀恰在封界大阵外上演，大阵为见证者。

## 八、章末悬念
王林吞噬完毕迈步消失的刹那，远处传来疯狂咆哮「王林」——一个堪比星空般巨大的身影轰轰而来。据章题，此来者当为『拓森』。

## 备注
- 归属：依世界状态须知，王林自第1063章起以归元宗故人『吕子浩』之名行走云海星域（身份由吕烟菲奉上）；本章文本直呼其本名「王林」，来者咆哮的也是「王林」，说明其真实身份在此已被界外一方知晓/点破。
