# 仙逆 第八卷 联盟隐秘 第893章 谢谢你们

## 一、归乡祭祖

- 王林一步跨入城墙之内，夕阳西下、夜色笼罩，望见后人修建的坟头，跪地流泪：**「爹，娘，铁柱，回来了。」**
- 同行者：**塔山**（神色冰冷，整夜站立不动）、**大头童子**（眼中复杂）。大头童子由王林举动推知此地是「许木的祖宅」——按世界状态须知，「许木」为王林在联盟星域所用化名。
- 王林推开院门，饭桌依旧、人已不在。脑中浮起千年前父母的叮咛：读书应考、别一辈子困在村里；父亲靠木雕换钱有赖**四叔**帮衬，嘱其日后报答四叔。
- 王林令二人在外等候，独自坐于祖宅内一夜，忘却修真界一切，只余童年记忆。文中点明其「快乐是孤独的，笑容是无声的悲与哀」。
- 大头童子在这一夜同样追忆备受欺辱的童年与嫌弃自己的母亲，心痛之中反有一丝解脱。

## 二、被守护者围堵

- 天亮后三人未隐身形，引来巡逻士兵与十余名修士，修为最低筑基、最高**化神**，怒斥擅闯皇家祖宅乃「株连九族的大罪」，并称除王家族人外任何人不得踏入半步。
- 王林淡问「这墓，是谁修建」，声音携天地威严，化神修士感到意境将被一句话吞噬，被迫后退作答：
  - 此地为**凡间皇族**修建，是皇族先祖旧居，**更是「我朱雀星老祖」童年之地**。
  - 该修士隐约觉得王林眼熟却想不起来。

## 三、玄道宗婴变老者与赵国现状

- 云中走出一名白发、双目精光毕露的**婴变初期**老者，喝斥擅闯者不把**玄道宗**放在眼里，自陈「我赵国玄道宗世代守护此地」；四周修士对其恭敬，威望极高。
- 关键信息（老者所述）：
  - **赵国早在三百年前便达到五级修真国**，朱雀星修士皆知（王林记忆中当年赵国仅为**三级修真国**，闻之欣慰）。
  - 守护王家祖宅**并非仅玄道宗**，朱雀星各门派弟子每隔一段时间交替轮守。
  - 能来守护者，均为各门派内**贡献极大或天资极佳、重点培养**之人；守护王族祖宅对朱雀星修士而言是**莫大的荣耀**。
- 老者在王林面前莫名感到亲切，怒火被强行压下，答话极为详细，连自己也不知缘由。

## 四、灵种伏笔回收与赐福

- 王林在老者身上察觉一丝极微弱、**属于王林自身**的气息，忆起**当年在赵国化神时曾留下十颗灵种**，判定此老者即十人之一。
- 王林长叹，带一丝感动说：**「谢谢你们了」**，大袖一甩，元力化作点点晶光落入四周每一名修士乃至地面士兵体内，众人体内涌起热流。
- 临行赠言：「你很不错，不枉我当年送你灵种」，随后三人消失于天边。

## 五、身份揭晓

- 「灵种」二字令婴变老者剧震醒悟，激动失声：**「王家老祖」**
- 四周修士震动，称其为「**朱雀星的守护者，无数年来的第一个人，王家老祖，王林**」。
