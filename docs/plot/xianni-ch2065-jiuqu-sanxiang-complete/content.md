# 第2065章 九曲三相全！（第一更）

## 一、完整踏天一步，古化天地崩灭

王林怒意宣泄，右脚落下踏天而去——「整个世界似在其脚下，众生也全部都在其脚下，规则也好，法则也罢，一切的一切，都在这一步中，灰飞烟灭」。天空大量裂缝、碎片倒卷，天崩地裂，古道以古化天地所形成的世界就此碎灭。

- 古道身子一颤、喷出鲜血、连退百丈，面色第一次苍白。
- 古道判定：「踏天境，这是完整的踏天境」，并感受到王林身上一股可怕的力量似正觉醒。
- 王林自述：踏天桥走过第七座，第八桥失败。
- 古道以自身修为，迈不出那一步。

## 二、古道的「道天」一式

古道虽承认「或许真的无法留下你」，但不肯放弃，祭出毕生所悟的一式神通「道天」。

**信念对比**

| | 信念 | 后果 |
|---|---|---|
| 古祖 | 化作天地 | 古道离不开古族大地太远；仙族范围非其所化，是他憎恨之地 |
| 古道 | 让天再拦不住眼、让地再阻不了身、让日月苍穹与仙罡大陆再迷不了心 | 以心为道，以道踏天，以天为阶 |

施展表现：天幕轰鸣，出现笼罩整个苍茫盆地的巨大漩涡，如末世降临；古道一指点向王林，喝道「你，就是天」，漩涡中幻化出一只大脚向王林狠狠踏来。这是二百年来王林再次感受到强烈的生死危机。

## 三、圈与踏天：王林的顿悟

王林想起踏天第八桥上所刻：「众生皆欲踏天而去，唯所不得者，无信，无怂。」并联想到当年在洞府界回答李倩梅三问时所说的「天地是一个圈，圈外还有圈」。

顿悟要点：
- 众生（人、兽、乃至灵）皆有踏天之意，皆有想与众不同、渴望自由不受拘束的念头。
- 凡间法则是圈，贫穷富贵中庸是圈，修真界弱肉强食是圈，整个天地是牢笼般的圈，宇中苍穹星空亦是圈。
- 走出一个个圈，直至踏天而起、踏苍穹星宇而起，从众生万物中走出最后一步，再无法遮眼、无法惑心——这才是道经中「奉至修真行」的本意。

## 四、第四道虚本源：轮回

**「生死、因果、真似」**——生死为绳，无数今生死连接成无数个圈，组成一张网，此网即因果；因果大网是从轮回河流内捞出真我的物品，轮回之河中虚幻与真实并存，需一双能看透真假的眼才能抛网捞出自我。

历程：
1. 真假本源大成后，王林在东临宗内开始感悟轮回，为第四道虚本源。
2. 数百年不能理解轮回究竟是什么，一度以为是掌管今生来世的法则之力。
3. 道古国师曾点露：李慕婉（婉儿）的真正复活，需在太古神境内施展轮回之力。
4. 本章终于明悟：**轮回，就是这天**——以手中因果网向天空抛去，捞出真我。

结果：体内原本的三大虚之本源，此刻多出一缕，正是明悟出的「轮回」。

## 五、九曲三相第三次显化

### 九曲
危急之际，风的声音挤入天地——**古脉苍穹曲**为九曲第一音，其后第二至第九音依次而出：天、地、风、雷、脏、身，最后是**血脉之曲**。曲音自天地、自王林身体、自苍穹回旋扩散，落下的大脚为之减缓。

### 三相
| 相 | 表现 |
|---|---|
| 第一相 | 金天黑地——金色天空、黑色大地，似虚幻不真却清晰可见，古道亦心神一震看到 |
| 第二相 | 王林双眼绽放无尽银色光芒 |
| 第三相 | 婴啼 |

### 三次出现
1. 第一次：古道上——九曲缺一、三相缺一。
2. 第二次：道古皇宫——九曲全，三相仍缺一。
3. 第三次：本章，苍茫盆地中心、海墙风暴一侧，古道「道天」降临之中——九曲全，第三相起初仍无法出现。

## 六、虚无分身完整降临与融合

王林目光穿透道天之术，看向天幕外的虚无，明悟自己所缺：与古祖、仙祖一样，**从虚无诞生的方式与认可**。

他喝出「虚无，分身，完整降临，与我相融」——

- 仙罡大陆充满法则的虚无中，一巨大圆形石块内盘膝坐着一个与王林一模一样的身影，已坐了数百近千年，此即**王林的虚无分身**。
- 分身睁眼刹那，石块轰然爆开，弧形碎石如蛋壳般向八方卷去；分身起身一步迈出，消失无影。
- 分身自天空漩涡中走出，迈出第三步，在古道震撼目光下走到王林身前，与王林身体重叠融合。

## 七、婴啼震动仙古

融合瞬间，王林仰天嘶吼，余音奇异变化，化作阵阵婴儿啼哭，回荡传遍苍茫盆地。

- 传至古族大地：古之三脉皇城的三座古祖雕像同时出现裂缝。
- 传至仙族大地：祖城内的仙祖雕像同样出现裂缝。
- 古族大地无数地气喷发，凝聚成古祖的莫大身影；仙族大地地气弥漫，凝聚出仙祖身影——此为仙罡大陆上的第一、第二个身影，寻常之人看不到，唯大天尊可感受。
- 苍茫盆地内蓦然出现**第三个身影**，超越仙古，冲天而起。

古道喃喃：「九曲，三相，第三相为婴啼。」
