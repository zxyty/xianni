# 第1719章 诡异！（第三更）

## 一、离开仙界：诸强反应

- 王林眼前景象崩溃、身外蓝光消散，身子一晃直奔天空，刹那消失于仙界，走出外围银河。
- **蓝芒道尊**：一生护短，视王林如自家侄子（称其为「蓝梦道尊的女婿」），言「敢算计我蓝梦道尊的女婿，这天运子，活不了多久」，大袖一甩化作蓝芒离开雪山。
- **青霖**：神色担忧，随即前行；离开前神念传遍仙界，邀「红衫子前辈、南云子前辈」同往。
- **红衫子**：气息冲天，身影幻化，毫不犹豫踏步直奔天空。
- **南云子**：略一思索后不去，选择留守——若大能尽离，仙界空虚不利。

## 二、王林的判断

- 冲出仙界银河后一步跨入 **召河星域**，神色冷静而目露杀机。
- 由蓝梦道尊之言明白：**天运子很早就在算计自己**——无论在**朱雀星**，还是在**妖灵之地**。
- 内心定论：当年被自己看破算计、失算一次后，天运子短时间内又生算计，**以分身做饵**。「此人我王林必须要杀……只要他死了，一切都结束。」

## 三、第一战：陨石之战（召河星域深处）

**天运子先觉**：陨石内的天运子察觉有神识窥来，对望刹那认出是王林，惊疑「以他的修为，不应该这么快找到这里——有人帮他，且此人不是青霖」。

**交手过程（本源对本源）**：

1. **崩陨石**：王林化长虹临近，一拳轰碎陨石，毁灭波纹几乎要把星空打出窟窿；天运子以七彩光芒现身，掐诀消去波纹。
2. **火焰本源**：天运子左眼燃火，化火海为**火焰朱雀**扑击。王林并不震惊（听蓝芒道尊言时已有准备），只是杀机更浓——**自己的火焰本源已被天运子掌握**。王林左目亦化火焰朱雀迎上，两只朱雀各占半个星空，对撞后同时崩溃。
3. **雷霆本源**：天运子处雷霆而起，四面八方闪电凝成**九头雷龙**，如雷劫般冲来。王林右目雷霆一闪，化作**开天之雷**对轰，面色苍白却不退缩，穿透雷霆逼至不足数十丈。
4. **同步一抓**：天运子虚空一抓、五指握拳、猛的外拽，**王林动作与之一模一样**，二人同时身震；天运子喷血后退，眼中依旧平静，道：「你的神通，你的本源，你的一切，我都会。」
5. **禁制本源·杀禁**：王林双目凝出大量血丝，右手在双目上一抹，左右幻化出两个巨大瞳孔虚影，血丝密布如规则。喝「**禁制本源，以我瞳丝，成规则降临**」，瞳孔膨胀至无尽之大，血丝弥漫星空如蛛网缠住天运子；一声「**杀禁**」，血丝锋利横扫，如绞肉般将天运子分割崩溃。

**诡异之处**：天运子临死微笑——「**你我已成一体，你就是我的分身，让你杀了，又如何**」。其死后有一股只有王林能看到的魂之气息飘出，不管王林愿不愿意，**强行融入王林体内**，与王林体内那道「天运子分身之魂」融合，使之**更强大了一些**。同一瞬间，王林感应到召河星域另一方向天运子气息再现。

## 四、第二处：修真星盆地·自尽引路

- 地点：召河星域另一方向的一颗**修真星**，星上一处**盆地**，四周枯萎。
- 一名**白发白衣老者**（天运子）盘膝而坐，睁眼时**双目血丝完整且蕴含禁制**——已得王林的**禁制本源**。
- 自评：「**送他一魂，换来禁制本源，倒也值得**……只是他的修为还不够，应该再强一些，这样的话，距离我的计划，就更近了。」眼中露出期待。
- **轮回一体术**：天运子自陈此术玄妙，随着记忆觉醒才知晓——「**原来我不是除了他们两个外第一个觉醒者，我已经觉醒了九十七次，这一次，是我第九十八次觉醒**」。
- 王林自虚无中踏出、盯住天运子；天运子微笑更浓，右手一指右侧方向：「**下一次，是在那个方向**」，随即手指画弧点在自己眉心、完全穿透头骨，**身体轰然崩溃自尽**，又一缕分魂在王林错愣中融入其体内。

## 五、结局与悬念

- 王林感到一阵心寒：「**他到底要做什么？**」
- 心神中，于天运子所指的方向再度感受到一股天运子气息——那气息似在**呼唤他、等待他的到来**。
- 悬念：天运子以「一魂换本源」的方式反复送死，借王林之手推进某个未明的计划；王林体内的天运子分身之魂随每次击杀而增强。
