# 第1671章 是左眼么！

## 一、幽冥兽出世：以恐惧压恐惧

- 十多个远古凶兽疯狂撞击三大转轮阵法，阵法扭曲不断。王林身前，久未出现、性格胆小至极的**幽冥兽**幻化而出。
- 幽冥兽体型难以形容，仅虚影便几乎占满整片阵法区域，对一切目睹者形成来自心神的至强威压。虚影一出，十多个远古凶兽之魂齐齐一顿，**灵魂记忆深处的战栗**让它们低吼咆哮着退后，不敢升起半点抵抗之心。
- 幽冥兽完全凝实后，半个身子延伸出阵法外，与一名元神受创的**界外中年修士**相距不足一丈。该修士呆滞、面色惨白，随后发出惨绝人寰的尖叫，忘记神通印诀只是胡乱挥手，最后不惜代价喷血施展**血遁**逃走。
- 讽刺的是：幽冥兽同样被这尖叫、被凶兽的狰狞样貌吓得剧烈颤抖，一颤即星空震动、波纹横扫。它的惊恐吼声化作惊天音浪，在远古凶兽听来是不可抗的威压，在数万界外修士（含五个大能）听来是骇然压迫，众人纷纷后退、面色大变。
- **只有王林知道**：这是幽冥兽被彻底吓坏的表现，它双眼隐现白色，已有被吓昏厥之兆。

## 二、王林驱使幽冥兽吞噬凶兽之魂

- 王林一步跨到幽冥兽身上，察觉其身躯**与往常不同：以往坚硬，此刻柔软了不少**（未及深思，留作伏笔）。
- 右手轻拍其身，传入心神安抚，并借彼此联系下达命令。幽冥兽先是摇头（不敢吞噬远古凶兽），退后的修士与凶兽反而误以为它要冲出，更加惊恐。
- 在王林强力命令下，幽冥兽咆哮壮胆，猛地一吞：上方出现**幽冥之口**，惊人吸摄之力将十多个远古凶兽之魂尽数倒卷吸入。
- 数万修士也有被吸入之势，被王林拍其身**制止**。

  **原因（关键设定）**：幽冥兽若吞噬这数万修士，将沉睡消化多年；而吞噬十多个远古凶兽之魂不会沉睡。不沉睡的幽冥兽对王林帮助更大——这也是**此前罗天战场王林没有召唤幽冥兽的原因**。
- 幽冥兽打了个颤抖的饱嗝，眼露委屈与害怕（它不喜欢吃这些凶兽，「不好吃、很可怕」），随后依王林心念化作**芥子**融入其眉心休息。

## 三、界外底牌：九棺唤太古皇神

- 战况盘点：界外一方以**十万元神**召唤的、存在于**远古诏曰**中的**远古之光**，以及**十多辆长尊会保存的至强战车**，均已一一毁在三大转轮阵法之前。
- 最后一物：与铁链连接的**巨大石碑**，铁链摇晃的末端拴着**九具巨大棺木**。
- 石碑上九道符文急速闪烁，化作九道气息顺铁链直奔九棺；棺盖轰然崩溃、四分五裂，**黑色长发**如杂草般妖异蔓延，转眼弥漫星空。
- 五个大能同时跪地膜拜、咬破舌尖喷出元神精血，星空内残存的数万修士亦齐喷精血，被九棺吸收殆尽。祷词：

  > 「守护我界外星辰悠悠岁月的**太古皇神**，你的身体分成了九份，今日九体归一，召唤你不灭之魂，轰开此阵，诛杀此人！」
- 九棺骤然一一爆开，**古神、古妖、古魔**三股气息交错，形成一股**道古之力**惊天而起。

## 四、悬念：是左眼么

- 这股气息**属于道古、属于烨寞**。王林双目极为凝重，没想到界外竟有如此精纯的道古气息。
- 王林心中判断：

  > 「不是左眼……若真是左眼，那气息会比眼下更强，但若不是左眼，这……这又是什么？」
- 章末悬念指向王林所寻的**道古烨寞之左眼**：太古皇神与道古/烨寞之间的关系尚未揭晓。
