# 第1510章 云海荣耀！！（第十卷 叱咤界内）

## 一、阵前对质：当众揭破水道子

- 神宗外，近万云海修士匆匆接令赶来布置**九灭黎天阵**，但王林来得太快，阵法仅成不足三成。
- 王林以巅峰之声笼罩八方，指控水道子：「勾结界外，叛主求荣」「获封界之尊依托，代其杀奴」。此声传遍星空，被四大星域诸多大神通修士与大能清晰听闻，众人纷纷动容。
- 水道子自神宗厉喝「满口胡言，九灭黎天阵，给我轰杀这掌尊歼细」，声化无形利剑直取王林心神，被王林一声冷哼震散。
- 王林右手在眉心一点，一道血光一闪即消，无人察觉（伏笔），随即迈步走向神宗，走向云海之巅，去战第三步大能水道子。

## 二、杀戮本源现世

- 王林身后数万丈滔天寒冰封住雾气，杀气自雾霜与其身体内散出，融合为**一丝杀戮本源**，令其如同一尊杀仙。
- 四大星域各方大能为之震动。水道子面色阴沉、无法置信：「他当年的本源本就已经不少，如今竟又多了一道……这是当年封界之尊也没有研究明悟的杀戮本源。」
- 水道子虽惊却狂，手中死死捏着一个**金色铃铛**，冷笑抬头。

## 三、一步压万人与今昔逆转

- 王林每迈一步，便如踏在近万修士心神之上，与其心跳同步，逼得他们不得不后退数步，元力不由自主急速运转，仿佛面对的是自远古、太古归来的魔神。
- 王林心中今昔对照：昨日他在**云海蛮荒星**以**天运子之魂**算尽天机、准备挣扎求生于水道子的天威之下；今日彻底逆转——王林成了昨日的天威，水道子成了昨日挣扎求生之人。
- 王林劝退：「王某与水道子的仇怨，与尔等无关，还不退下。」

## 四、云海荣耀：可悲可敬的死战

- 近万修士退无可退，身后即是神宗——数万年来云海修士崇敬赴死之所在。
- **水道子的真实算计**：让这些人死在王林手中，以其死激起整个云海修士的愤怒与其余三大星域的同悲，在界外入侵之前，再向界外立一大功。
- 恐惧与荣耀双重威逼下，众修士压住恐惧，齐呼「云海荣耀」，疯狂冲出，以血肉之躯驱动未成的九灭黎天阵。
- 他们守护的不是水道子，而是神宗；他们不知水道子的阴毒，只知神宗有命，绝不容王林踏入半步。
- 结果全然反转：这一幕被四方星域神识观战的大神通修士与大能尽收眼底，本欲摧毁界内修士之心、扰乱备战的谋划，反而成了唤起整个界内守护家乡的荣耀之战。**水道子亦目瞪口呆**，自承小看了云海修士与云海的那份荣耀。
- 王林动容，见其中有当年旧识、更多为陌生面孔，联想到当年在**七彩界**封界大阵旁不顾生死挣扎的仙人不屈之魂，于是再次后退，不忍出手。

## 五、由定身术到定神术的明悟

- 王林怒吼「水道子，你该死」，一指之下不惜损耗元力、试探自身极限，喝出「**定身术，定**」。
- 天地一震、星空颤抖：一切修士动作、星空运转、天地变化、阵法转动尽被定住；**不仅定住身体，更定住神念**。
- 这一变化因近万修士的荣耀而起、因王林**不杀之心**而动，从定身术转换为**定神术**——「唯拥有了神，方可真正的定神苍穹」。此「神」非神灵、非神识，而是一股意志、一股荣耀的思绪。
- 王林此前心中此「神」不多，见众修士爆发之力后隐隐有了明悟：一字定身，一字定神。
- 定住之后，王林大袖一甩，将近万修士强行融入天地挪开，**未伤半点**——「他们，可敬」。荣耀却挪不走，仍弥漫星空。

## 六、直上神宗修真星，约战水道子

- 王林一步踏破神宗修真星罡风，现身该星天空，大地崩溃、无数裂缝撕开；身后数万丈寒霜呼啸，天空如被冰封并向四周与大地扩散，所过之处万里冰霜。
- 目光锁定远处**五座山峰**中盘膝的水道子，喝问：「水道子，你可敢与我堂堂正正一战。」

## 七、道心之劫与突变

- 水道子尖声呼「王林小儿」，一指天空化出虚幻画面：**归元宗诸人**被数个黑衣修士围困于一处盆地，盆地之上悬着一座散发光芒的巨大山峰，似随时砸落轰杀盆地内所有人。
- 水道子狂笑：「他们将因你而亡，我看你道心会不会出现破绽。」
- 王林神色平静，答「你配么」——似一切早在预料之中。水道子一愣，**变故突生**（悬念，接下章）。

## 关键看点

1. 王林获得又一道本源：**杀戮本源**，连封界之尊都未明悟。
2. 神通升级：定身术 → **定神术**，可定神念，其触发条件是「神（意志/荣耀）」与不杀之心。
3. 阵营人心的战略反转：水道子的献祭式阳谋，被「云海荣耀」与王林的不杀反手转化为界内备战的士气来源。
4. 眉心血光的伏笔与「你配么」的从容，暗示王林对归元宗困局早有布置。
