# 第1193章 血战苍松子！（第九卷 云海之巅）

> 世界状态须知：本片段中王林自第1063章起以归元宗故人「吕子浩」之名行事（化名，由吕烟菲奉上）。本章战斗言行均归属【王林】。

## 一、三叉戟的来历（设定揭示）

- **本体**：古神涂司当年炼制的**古神之器**，核心神通为「吞噬天地万物为己之神通」。
- **缺憾**：炼成后涂司极为满意，唯独**其上无魂**，故抛入一座星球内**化作山峰**，欲以岁月凝聚其魂。
- **用途**：待其「**墨流分神术**」成功后，此物是涂司为自己分神准备的法器，堪比**灭神枪**。
- **结局**：涂司墨流分神**失败**，此物遗失于岁月之中。
- **持有链**：天运子得到后可发挥其威力，**但不能开启吞噬神通**——开启吞噬神通**必须是古神**。
- **王林的资格**：修为虽不及天运子，但经历「**一损二劫**」后全身血肉骨髓重新凝聚，**成为真正的古神一族**，故三叉戟在其手可施展吞噬神通。
- **附加神通**：先前被吞噬的**生死禁**已成为三叉戟自身神通，随三条吞噬之龙一同而出。

## 二、战斗经过

### 1. 首回合：吞噬晶剑
- 苍松子祭出**次空涅之宝晶剑**（其所获宝物中较高存在），意在速斩王林。
- 三条吞噬黑龙张口**吞噬晶剑**；一龙体内轰鸣、怒吼挣扎而未崩溃，三龙归位重化三叉戟，**晶光缓缓印在戟身之上**。

### 2. 苍松子连环杀招
- 掐诀指出，**漫天剑气**直奔王林。
- 从储物裂缝取出**三颗珠子**抛出，低喝「**召，逆行者**」，七彩之芒疯狂涌入：
  1. 第一珠崩溃 → 天空**模糊虚影**（相貌不清、剑威笼罩），指出**七彩剑气**。
  2. 第二珠崩溃 → 山脉大范围崩塌，走出**约百丈石人**，披七彩之芒冲来。
  3. 第三珠爆开 → 七彩之芒凝成**巨大虚幻轮盘**，飞转，磅礴之威笼罩。
- 掐诀点眉心，面色血红，眉心飞出**血光血婴**（与之前攻击青衫老妪的元婴一模一样），凄厉尖啸冲向王林。
- 苍松子修为：**碎涅中期**，元力浑厚。

### 3. 王林的应对
- 判定**罗盘威胁最大**，甩出三叉戟直击罗盘；黑龙在距罗盘七寸处被七彩电光阻隔，**疯狂吞噬电光**逼近。
- **呼风之术**：黑风遮天，数条黑龙凝聚成团冲向模糊剑影 → 剑影**渐渐消散**。
- **唤雨之术**：方圆数千丈雨滴幻化拦截剑气，分部化冰晶 → 石人**尚未临近即成巨大冰人**。
- **肉身硬撼**：右手握拳轰向七彩剑气，六色崩溃，**一道蓝光钻入其右手**，狂暴气息顺臂涌入体内，王林闷哼。
- **封仙印 + 撒豆成兵**：放出**虚空子、天运子、吴青**等战魂扑向血婴，另有大量**仙人、罗天星域修士、联盟星域修士**战魂铺天盖地，血婴连连尖叫无法脱困。
  - **异常**：天运子的战魂出现后**双目迷茫、不受撒豆成兵操控**，未去攻击，只呆望天空。（王林无暇理会）
- **灭神枪虚体**：虚空一抓，无尽雷霆凝成一杆虚幻长枪，抛向天空巨大罗盘。
- **巨大手印**：右手下按、左手双指点其手背，天地元力汇聚成虚幻巨手印压向苍松子。

### 4. 苍松子的底牌与互伤
- 苍松子咬破舌尖喷血挥手，头部幻化出**七个元婴**凄厉咆哮，身前浮现**闪电印记**，天地骤暗、光芒尽被吸收。
- 喝道：「**以百世血元化婴，唤封界第七阵之灵**」——王林掌印落下即崩溃，一道闪电射出，速度太快无从闪避，**正中王林胸口**；王林后退数步，**嘴角第一次流下古神血迹**，眼中凶焰滔天。
- 王林虚空一抓祭出**铁剑**，掌心环绕锁定后直取苍松子。
- 苍松子取出**七彩钉子**（与禁幕内钉住刻满道经骸骨之钉一模一样，**威压超过次空涅法宝**），喝「给老夫去死」抛出：
  - 铁剑**从中间断裂一分为二**；
  - 七彩钉**钉入王林右肩**，剧痛袭来，此钉**似可钉住元神**，王林眼前迷糊、身形迅速缩小几近常人；
  - 断剑剑尖部分**穿透苍松子胸口、自后背破出插入地面**，苍松子喷血重伤，化虹逃向墙壁般的山脉。

### 5. 收尾
- 王林咬牙抬左手，脑中浮现**役灵印**，隔空一拍，齐天掌印轰向苍松子。
- 临近刹那，苍松子施展不明神通，**肉身砰然崩溃化作一片七彩雾**，在役灵印下**竟未死**，七彩雾卷元神遁走，消失在山脉另一端。
- 王林喷血、身形恢复正常，收起所有法宝，**看都不看困住青衫老妇人的禁制**，化长虹迅速离去，右肩鲜血大量流出、面色苍白。
- **两败俱伤**。
- **悬念**：天空中的巨大罗盘缓缓移动，**追向王林**。
