# 第七卷 名震罗天·第735章 前无古人

## 一、设定：仙界之雷与雷鼎
- 雷之仙界开启之时会产生**仙界之雷**，此雷起「招引」之用：凡拥有**雷鼎**者，皆可被招引而去。
- 缘由恒久无解，历代大神通修士追查亦无答案，久而久之无人再究因果，只知「有雷鼎便可入雷之仙界」。
- 雷鼎**数量固定**、不会崩溃、不会丢失；每次雷之仙界关闭后如从虚无中来又回归虚无，下次出现仍是同一数量。即便踏入第二步的修士也很难毁灭雷鼎，且毁之于己于雷之仙界皆有大害，故无人为之。

## 二、青灵星上的吞雷
### 第一道仙雷
- 王林收起雷鼎，雷霆挟浓郁仙气而降。其体内元神疯狂运转，雷光游走并外溢至地面，宛若掌控雷电之人。
- 王林如流星冲出，张口将整道仙雷**一口吞下**，天地骤暗；随即如断线风筝坠地，被打入地底，方圆十里成圆形掀起雷的风暴。
- 双目紧闭，元神狂吸仙雷之力，并施展**雷元术**吸收天地元力——一如当年碎石层内的**雷池**。
- 此仙雷内天地元力比雷池之雷浓郁数倍；王林元神元力原本已饱和，因修为达**问鼎大圆满**而又生出余留空间，故能续吸。

### 第二道仙雷
- 王林冲出地底，再拍储物袋取出雷鼎，将散的雷云立刻重聚，第二道仙雷落下。
- 收鼎、迎击、再度吞下。震响传遍青灵星，落地即盘膝，全身剧烈颤抖；虽全身酸麻、元神有勉强承受之象，但元力充足得无法想象。
- 两道之后雷云不堪重负，消散速度数倍于前。

### 第三道仙雷（失控）
- 王林天灵散出青光化青雾，**元神离窍**，卷起飞出的雷鼎融入体内，冲向天际。
- 雷云如被激怒，几乎将全部雷云凝于一处，形成远强于前两道的第三道仙雷；整片天空的雷云如漏斗被吸入雷霆，远看是一个由雷云组成的**巨大漩涡**。
- 举星震怖：修士无人敢散神识；凡人乃至市井恶霸、不信仙人的武林枭雄，皆跪于家中祈求仙灵庇护。
- 王林元神苦笑「好像有些弄大了」，随即拉长变化，形貌**颇似太古雷龙**，咆哮吞雷——只吞一半便退，雷霆紧追不舍。
- 元神返回肉身，抛出雷鼎；追来的雷电连同漩涡尽数落向雷鼎。雷鼎电光狂闪，握鼎的王林右手发麻（握闪电亦无此感）。雷云漩涡铺展天际、急旋吸入鼎中，远看如「此鼎要把这天收了」。

## 三、转折：第一个崩溃的雷鼎
- 漩涡尽入鼎内的刹那，雷鼎**咔咔出现裂缝**——雷之仙界开启以来的头一遭。
- 裂缝增多，雷鼎**崩溃**，化作彼此以雷光牵引的碎片；王林尚以为「有碎片在还有弥补余地」，碎片旋即二次崩溃，化为**碎末**。
- 后果：这是雷之仙界开启以来第一个崩溃的雷鼎。自此日起，日后雷之仙界纵使再开启无数次，也将**永久少一个雷鼎、永恒失去一个进入名额**。无数岁月中此事首次发生，后续变故无人知晓。
- 王林苦笑更浓，忧心雷鼎崩溃是否会连累自己无法进入仙界，自我安慰「毕竟是雷仙界之物，应该不会崩溃吧」。

## 四、结果：破碎虚空、入界之路
- 雷鼎崩散之刹那，其内蕴含的狂雷爆发，环绕王林全身，连同碎末以极快速度直奔天空，快得「好似要撕裂肉身」。
- 狂雷瞬间粉碎虚空，卷着王林消失于天地之间。在与星空明显有别的空间内，王林一闪而过，几乎看不清身边一切，「好似岁月一瞬晃过」。
- 对比：他人持雷鼎受牵引入界速度柔和；王林因雷鼎吸尽整片降临雷云、承受不住的雷力，速度是他人无数倍。
- 同期：大量**罗天星域**修士从四面八方被自动牵引，不需自行飞行，前往**雷之仙界大门**等待开启。

## 五、要点归纳
1. 王林修为已至**问鼎大圆满**，是其能连吞仙雷、元神有余量容纳的前提。
2. 「吞噬仙雷」在修真界视角属疯狂之举，前无古人（呼应章名）。
3. 雷鼎的毁灭是设定级破例事件，为后续雷之仙界局势埋下变数。
4. 王林元神可化近似**太古雷龙**之形，为其雷道底蕴的体现。
