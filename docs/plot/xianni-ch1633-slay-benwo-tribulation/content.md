# 第1633章 斩本我

## 一、局面：与自己为敌

王林所面对的「本我劫」化身为一名白发青年，是彻头彻尾的镜像：

- **同为古神肉身**，恢复力与肉身强度一致。
- **同为第三步空灵中期**修为。
- **神通全同**：短时间内二人施展了十多道完全一样的神通，包括白凡仙术、清水之术、王林感悟的自创道术。
- **本源同出**：火之本源、雷之本源双方皆全力施展，结果两败俱伤，各喷数口鲜血，神色阴沉、气息萎靡。
- **法宝亦同**：王林取出法宝，对方立刻取出同样法宝——王林由此判断「对方的一切，都是因自己而起」，遂不再动用任何法宝。

白发青年狂笑宣称：「没用的，我就是你，你杀不了我。」

王林在这场战斗中隐隐体会到——**别人遇到自己时那种难缠的感觉**；与自己战斗，令他极不适应。

## 二、王林的破局：定神术 → 推衍 → 梦道化骗道

王林的取胜链条并非硬拼，而是分三层：

1. **定神术作掩护**：在一次次真实攻击中夹带施展定神术，定住彼此神识与思绪，实则是**封死自己的思绪不被对方感应**；且只维持一刹那便让脑中一片空白，不敢让思绪停留过久被对方获知。
2. **刹那推衍**：趁定神术的一瞬在脑中急速推衍，算出结果。但推衍本身不是重点。
3. **梦道化骗道（真正的杀招）**：在那瞬息间暗中施展梦道之术化作骗道，如同入眠一般，**先把定神术解除之后的自己欺骗过去**。

于是骗道之下，王林心神一分为二：

- 一个**被骗过的自己**：双眼通红、低吼「杀杀杀」，与白发青年疯狂对撞十余次，连疯狂本身都是虚假的诱饵。
- 一个**冷静从容的自己**：在旁伺机寻找唯一的杀人机会。

关键在于：白发青年能复制王林的记忆与思绪，「你的一切我都可以复制出来」；唯一的破法是**除非王林先把自己骗过**——这正是刘金彪的骗道。

## 三、杀招落点：真假道诱杀 + 因果印 + 生死印

第十九次碰撞后，双方以雷霆本源对轰，身子颤抖几近崩溃。随后：

1. 王林仰天大吼、闭上双眼，全身缭绕**真假之道**（双目一闭，则天地一切为虚假）。
2. 白发青年同样仰天一吼、闭眼弥漫真假之间——**这正是陷阱**。
3. 对方闭眼刹那，王林猛地睁眼，眼中一片冷静，此前的疯狂尽属伪装。白发青年感应尽失、面色第一次大变，急速后退欲睁眼。
4. **因果印**：王林右手成掌按其胸口，一扣一拽，抽出其本源，白发青年凄厉惨叫喷血。
5. **生死印**：左手蕴含「生」落于其眉心；右手吸收方才抽出的本源，再按眉心，此掌蕴含「死亡之气」。
6. 白发青年重创，苍白喷血、连退不止，惊呼「不可能」。

随后王林再次闭目睁目切换，目光冷静可怕，令白发青年**首次生出畏惧**并陷入两难：闭眼则对方或再度诡异消散于感应，不闭眼则真假道若为真自己同样重创。趁其犹豫，王林闭目挥手，白发青年全身轰鸣、白衣染血，在真假道下身形一片模糊近乎消散，只能强行忍住。

## 四、自伤断腿与终结

白发青年在惨叫中明悟：「该死的，这是刘金彪的骗道！」并判断——**只要王林没杀死自己，就绝然无法进入那如水幕波纹般的隔膜**，遂全速冲向隔膜。王林深知对方犯错只有一次，绝不会上第二次当，必须当场斩杀。

- 神通无法阻止（连定神术也不行），王林果断**一掌轰在自己右腿上**：其右腿血肉模糊、骨骼嘎吱欲断，同一刹那白发青年右腿出现一模一样的扭曲崩溃伤势，踉跄减速。
- 白发青年骇然：「你怎么会明白的这么快！」
- 王林身影如一道天雷冲入，从其身体一撞而过——白发青年身体崩溃、四分五裂、彻底消散。

## 五、后续：隔膜涣散与「他，看到了」

- 白发青年消散的同时，阻止王林前行的**水幕隔膜扭曲涣散**。
- 王林未急于前行，闭目运转修为，凝**古神之力**于右腿，凭第三步空灵中期修为与古神惊人恢复力急速疗伤。
- 片刻后睁眼迈步踏入涣散的水幕隔膜，**半只脚入内的一刹那身子猛地一顿：「他，看到了——」**（本章至此戛然而止，所见之物未揭示。）

## 六、要点提炼

- 本我劫的破解逻辑：镜像敌无法被常规手段击败，**自欺（骗道）是唯一超出复制范围的变量**。
- 骗道源流明确归于**刘金彪**，王林以梦道之术转化实现。
- 「因果印」「生死印」在本章连用：前者抽本源，后者以生、死二气双掌落眉心。
- 镜像同伤特性可反向利用：自伤即伤敌（自轰右腿→对方右腿同碎）。
- 遗留悬念：隔膜之内王林所见为何。
