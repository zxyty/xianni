# 第1444章 敌临（第九卷 云海之巅）

## 一、局势与王林的取舍

- 地点：古之墓地内的一处**封印之地**（有古神、古妖、古魔与千丈碎石平台）。
- 王林扫视退后数十丈的修士：这些人体内情绪剧烈变化，他**心念一动即可燃起对方虚火**造成重创。
- 但他判断：
  1. 古之墓地危机四伏，端倪未明，非必要不杀光此地之人；
  2. 在场有数人修为莫测，逼急了联手对他无益；
  3. 「没有好处，平白杀人，这种事情，王林很少去做」。
- 结论：**目的是立威**，索姓（索性）嚣张一把，若真有不开眼者，不介意单独杀人。
- 此时形貌：一头白发飘动，**左目虚火九色旋转**，妖异逼人；与其目光接触者皆心神震动、面色苍白。

## 二、逐一逼问、索取法宝

| 对象 | 先前狂言 | 结果献出之物 |
|---|---|---|
| 肥硕修士（员外袍、持算盘） | 若王林杀凶兽过十，便翻脸「灭魂炼神」 | 一枚巴掌大小的**鳞片**（得自古墓平台） |
| 黑衣修士（双目始终紧闭如瞎子） | 王林多杀一只凶兽，今日便要死在此地 | 一把弥漫**魔气的黑色飞剑** |
| 紫袍男子（身后有凶鱼幻化） | 让王林滚出去，不滚就让其尸体滚 | 一件**葫芦形状的宝物**（其在此地所得第一件重宝） |
| 绿袍老妪 | 王林不听话就杀他 | 战败后献出得自古墓的法宝 |
| 其余修士（含封灭族少女） | 口出不敬 | 一一献出法宝抵消 |

- 肥硕修士自忖：炼虚火修士之魂根本做不到，怕是未及炼魂自身先被虚火焚尽；被王林盯视时已感体内有火缓缓燃烧。
- 黑衣修士给王林的感觉古怪：**情绪波动存在却不明显**；双目眉心间有一股**如封印般的奇异力量**，似其一旦睁眼便会轰然爆发。

## 三、与封幻族老妪一战

1. 老妪体内**看不到任何情绪波动**，情绪被深深隐藏；神通诡异，王林一直看不出端倪——这是王林出手的主因。
2. 王林一步跨出如闪电临身；老妪掐诀引天地元力，四周陷入扭曲。
3. 双方在半空短时间内数十次元力碰撞，形成横扫四方的**元力风暴**；老妪喷血败退。
4. 王林白衣冲出风暴，右手双指成剑——**「一指岁月」**：心神内浮现**风仙界那苍凉石门**，一指卷动天地，使封印之地弥漫沧桑气息。
5. 老妪被迫动用底牌：双手掐诀点双耳太阳穴，张口喷出**粉色雾气**，异香扩散，幻象丛生——王林眼前浮现一连串**熟悉之人的虚影**；四周观战修士则看到老妪化作自己至亲、而王林正在屠戮至亲，怒火骤燃。
6. 封灭族少女惊呼指认：**「此人居然是太古三大奇族之一的封幻族」**，众修士随后齐称**「封幻之术」**。
7. 岁月一指轰上粉色雾气，雾气倒卷、灰飞烟灭；一指点中老妪眉心。
8. 后果：老妪被抛飞喷血；**体内被隐藏的情绪崩溃爆发，化作虚火汹汹燃烧**；眉心原有印记被毁，取而代之的是**若隐若现的女子背影图腾**。
9. 王林得到答案后**放弃杀机**，心念一动收回虚火，使其缩回老妪体内**化作火种，成为堪比禁制的存在**（等同留下钳制手段）。
10. 老妪面色惨白，目露深深恐惧与忌惮，沉默献宝。

> 老妪的误判：她已高估王林，却没想到对方不但是虚火修士，**修为更不弱于天人第五衰**，神通亦极为惊人。

## 四、白衣女子退场

- 唯有**长发及臀的白衣女子**未献宝，深深看王林一眼后展颜微笑。
- 其身下平台徐徐飞起直上天空，留言：**「此封印之地内应有奇宝，你既感兴趣，我便离去，想来在这古之墓地，你我还有相见之时」**。
- 平台自天际一处**撕裂的缝隙**内消失无影。王林目光一凝，未语。

## 五、封印之地的核心目标物

- 众人目光落向地面的**古神、古妖、古魔**。
- 尤其是**古神背部托着的千丈碎石平台**：其内**缭绕红雾、翻滚云涌，似封印了极为强大之物**。

## 六、章末转折：敌临

- 王林正欲看向地面古神时，神色骤变、猛抬头看向天边。
- 天地轰鸣，天际出现一片扭曲，隐见**九个巨大的平台**轰轰而来。
- 阴森之声与磅礴威压降临：**「这里居然有人也好，你等献出得自古墓平台的法宝，在旁候着」**。
- 四周天际的扭曲裂缝如被撕开，九个平台**无声冲破撕裂**，出现在封印之地天空。

## 七、要点提炼

- 王林「立威—索宝」的行事逻辑：以最小代价换取威慑与情报（看破封幻族神通），并埋下虚火火种作为长期钳制。
- 新势力信息：**封幻族**（太古三大奇族之一）、**封灭族**（少女在场）首次在本段并举。
- 悬念：九平台来者身份、古神背部红雾平台所封之物、黑衣修士眉心封印、白衣女子的后续相见。
