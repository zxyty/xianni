# 仙逆 第九卷 云海之巅 第1461章 制敌！（第四更）

## 一句话梗概
追杀王林进入古墓的奉天狼族三步大能周谨，被王林与暗伏于天皇炉内的灵动上人联手反制，十八片古息叶封死全部退路，九滴黑色水滴逼其不敢动弹。

## 战局经过

### 1. 开场压制
- 大汉（周谨）愣神刹那，王林右手一挥，隐藏于天空的**雷图**骤然幻化，轰天而降。
- 周谨反应极快：左手一挥幻化**古息叶**贴于胸口，**封住自身情绪波动**，防止被王林引动虚火；掐诀放出**奉天千丈狼身**迎击雷图。
- 雷图之后**九色火焰**化滔天火海围住奉天狼，火海内**血剑**冲出，直接穿透奉天狼杀向周谨。

### 2. 周谨的动机自陈（关键情报）
- 「既在这里遇到，便是你的死期，没想到你就是那**第五个墓台获得者**，杀了你，老夫墓台可成**六阶**。」
- 「要怪，就怪你的运气太差，在这里偷偷寻宝，竟被老夫撞到。」
- 其贪婪盯着王林身前的**十八个古息叶**，欲「杀你取叶，一举两得」。

### 3. 天皇炉与灵动上人现身（战局转折）
- 王林祭出**天皇炉**砸去，周谨随手一拍，天皇炉爆发**强大反震之力**顺其右手传入体内，周谨**喷出一口鲜血**。
- **灵动上人**嘴角带血痕，自天皇炉内于紫海诣天中冲出，踏紫海浪头，身外**无尽香火弥漫**、喃呢之声回荡，眼露杀机。
- 周谨瞳孔收缩，喝出对方名号「灵动」，震惊于其身外香火，更骇然于其为何帮王林出手——**对王林的把握出错**。
- 灵动上人喝破对方名讳「周谨」，双手挥舞紫海咆哮，唤出**巨大黑色雕像**，抱胸双臂散开，放出**毁灭之力**。

### 4. 周谨的旧怨与判断
- 周谨撕开暗色裂缝，血腥之气弥漫，一双赤红双眼与**数千丈红狼**冲出迎击雕像。
- 心声：「此战不能继续，要立刻走。那灵动上人**天人第五衰**时，我尚还是小辈，若非他不识好歹、没有足够的香火，他**早就成为三步大能**。」——即眼下灵动已**成功踏入第三步**，周谨遂放弃三步大能的尊严，急退欲走。

### 5. 古息叶封天（本章核心手段）
王林始终立于地面的**古神头骨**之上，半步未退，神色几乎无变，冷笑开口：「你看见我喜悦，却不知我看见你后，更喜悦。」随后以古息叶逐一封死方位：

| 顺序 | 用叶 | 封锁目标 |
|---|---|---|
| ① | 2 片 | 周谨身后**裂缝**（红狼冲出的刹那即被封上） |
| ② | 2 片 | 周谨**身后**天地（喝「后退」） |
| ③ | 2 片 | **左**方天地（喝「向左」） |
| ④ | 2 片 | **右**方天地（喝「向右」） |
| ⑤ | 4 片 | **上下**全部方位 |
| ⑥ | 余下全部 | 齐飞直取周谨，灵动上人同时冲出夹击 |

- 古息叶特性：速度快到无法想象、**可穿透一切空间**、**可封印天地一切之物**。
- 仅余前方一路，而前方正是灵动上人雕像与红狼厮杀的轰鸣战场——退路彻底断绝。

### 6. 群狼拜月被破 + 定身收官
- 危机关头周谨施展三步大能之术「**群狼拜月**」：大量**香火之魂**扩散成扭曲之相，双臂钻出无数狼牙，狼牙断开化作**不下数十万头凶狼**，天空浑浊，一轮**血色月亮**凭空幻化，威压弥漫。
- 王林迈步抬手一指，**天皇炉膨胀**将天地完全笼罩，遮住红月、困住众狼——神通未能彻底施展。
- 被灵动上人牵制的周谨面色骤变，欲不惜一切催动神通反抗，身子一震，掐诀右手竟无法落下：其身周浮现**九滴黑色水滴**，气息恐怖到令他头皮发麻。
- 周谨**不敢动**。王林寒声：「**动一下，便要死。**」

## 要点归纳
- **墓台线索**：周谨为墓台持有者，杀第五个墓台获得者（王林）可令自身墓台升至六阶——墓台可通过杀夺同类获得者而晋阶。
- **香火体系**：奉天狼族的狼身、群狼拜月皆以香火之力凝聚；灵动上人亦以香火为根基，其突破第三步曾卡在香火不足。
- **王林战力配置（本章）**：雷图、九色火焰、血剑、天皇炉、十八片古息叶、九滴黑色水滴，另立于古神头骨之上。
- **伏笔手段**：将灵动上人藏于天皇炉内伏击，是王林本战翻盘的关键。

- 灵动上人为何肯为王林出手（其与王林的交易/因果）本章未明说。
