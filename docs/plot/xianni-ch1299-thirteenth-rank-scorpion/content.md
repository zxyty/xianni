# 第九卷 云海之巅 第1299章 十三阶

## 一、局面

王林立于血海之内，面对身后浮现巨大蝎子虚影的黑衣女子。他一眼看破：此女并非修士，而是修为达到一定程度后由兽蜕变成人的存在——十三阶化人凶兽，其修为相当于修士中的“天人第二衰”。

此前崩溃李倩梅体外蓝光的鞭影，正是该女身后九尾蝎所为；若无此蝎，李倩梅不会重伤至此（也正因如此才撑到王林赶来）。王林目露杀机，不答其问，直接出手。

## 二、王林此刻的实力底牌

- **境界**：打开封印、消化道果后迈入**碎涅中期**，为碎涅中期大神通修士。
- **古神之身**：吸收无极宗内古神之气，古神之星恢复，成为真正的**六星古神**，第七星已有雏形。
- **法宝**：以古神鲜血祭炼的**诡异血剑**（此前已伤过黑衣女子）。
- **本源**：体内**五道本源**已苏醒，散发之力尚弱但无时无刻不在增强。
- **神通**：施展学自**鲁夫子**的神通（目光依次落于左手五指，凝聚天地元力）。
- 综合战力超过当年与**水道子**一战之时，被称作其两千年修道中最强之时；至此“才算真正踏入强者一列，无论界内界外足以成为一方霸主”。

## 三、战斗经过

1. **破九尾鞭影**：黑衣女子挥手催动九条实质蝎尾如鞭抽来。王林血剑横扫化血光剑芒，震溃三条、斩断四条；余下两条被其左手大袖引动天地元力并运转古神之力，化狂风撞碎。
2. **蝎尾鞭对掌印**：女子祭出实质蝎尾黑鞭（满布倒钩利刺、末端镰刀状倒钩）迎头抽下。王林左手挥出血剑斩鞭，同时以左手施鲁夫子神通，拍出蕴含毁灭之力与古神之力的掌印，光芒照亮四周数万里。
3. **护体与显形**：女子咬破舌尖喷血成血雾包体疾退，体内倒钩利刺狰狞而出、蝎子破体而出；掌印仍追印血雾之中，蝎尾鞭被血剑斩断爆开。此战王林呈压倒性强势，对方只能退、退、退。
4. **万丈本体**：血雾崩溃后现出黑色巨蝎，由数丈暴增至**万丈**，身后蝎影与其重叠（如修士元神归位），头部血肉蠕动化出黑衣女子人脸，九尾与双钳齐攻。
5. **古神化身**：王林左手拍向眉心，古神星点幻化旋转，古神之力灌注全身，骨骼延长血肉膨胀，身躯十丈、百丈直至**近千丈**，粗糙皮肤、沧桑气息、惊天威压——古神现世。女子见其眉心星点，骇然惊呼“古神”。
6. **碾压收尾**：王林掌心握着李倩梅，一步踏出左拳轰出，巨蝎被拨飞、蝎钳出现裂缝；他追上踏于蝎背狂砸，双钳崩溃；随后抓住两条蝎尾，借古神大力将万丈巨蝎生生拽起抡砸，先砸死远处观望的大群凶兽一片，再拖着巨蝎一路疾驰砸击，**破开无尽凶兽的包围**。巨蝎越发虚弱、惨叫微弱。

## 四、关键对白与线索

- 王林：“区区十三阶化人凶兽，你有什么资格阻我，有什么资格问我姓名”。
- 黑衣女子：“**吾乃远古依月帝妃麾下**，你敢杀我，帝妃定会杀你全族”——引出“远古依月帝妃”这一新势力/人物线索。
- 王林：“杀我全族？我全族已死，只剩孤身一人。你伤这女子，我就要取你性命，将你炼成法宝，承受无尽痛苦。”

## 五、旁证与伏笔

- 众凶兽望向王林的恐惧“几乎如同看到十三阶凶兽一般”。
- 环绕四周的**蚊兽**剧烈嗡鸣，**蚊王**直勾勾盯着巨蝎，露出渴望之色（暗示后续吞噬/进补）。
- 李倩梅全程重伤被王林右手/掌心抱持，王林只能以左手作战。

## 六、归属说明

据世界状态须知：本卷中王林在云海星域以化名『吕子浩』行事（自第1063章由吕烟菲奉上），本章未直接点名；文中“王林”言行均归【王林】本人。李倩梅在第1202章曾被记为死亡，本章仍以重伤者身份被王林抱持救护，以文本为准记录其重伤状态。
