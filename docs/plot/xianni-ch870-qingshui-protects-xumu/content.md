# 第七卷 名震罗天 第870章 清水护短

> 归属提示：本章“许木”为王林所用化名（自第661/669/711/731/771章沿用），其言行一律归属【王林】。

## 一、比斗被拆与清水出手
- 王林（许木）与罗素激战正酣，炎雷子出手拆开二人，未偏袒任何一方；二人均喷血被逼退，罗素落地后死死盯着王林、眼露浓郁杀机。
- 王林那一口鲜血激怒了清水——清水目中**极境**一闪而出，天地色变，冰寒之气笼罩四周，蒲团上的老怪们第一次感受到清水仙君最强大的神通。
- 清水语：“他，不是你可以杀之人，你没有这个资格。”
- 炎雷子喝“住手”已晚：一道**红色闪电**入罗素体内，其元神毫无抵抗之力瞬间崩溃、化作无数卷向肉身，肉身喷出大片血雾。罗素想转身看杀己之人，动作只到一半便双目黯淡、气绝身亡。
- 罗素尸上红光一闪，红芒卷着其破碎元神之力回到清水体内，清水面色略有红润（吞噬元神以补己身）。

## 二、清水的动机：护短
- 杀人无理由，若有因，那便是**护短**。
- 清水对师尊（仙帝白凡）之恩无法报答；师尊当年虽是戏言，他却极认真、极在意每一句话——在他心里，许木就是自己的师弟，有他在，许木不容人欺。
- 另一层原因：罗素眼中的杀机被清水看得一清二楚，这样的人他必须杀。

## 三、炎雷子的隐忍与妥协
- 炎雷子神色狰狞、勃然大怒：“老夫刚才没有半点偏袒……若不给一个交代，老夫今日，拼了封仙之事不办，也要与你一战。”
- 清水平淡回应：“失手而已，你若要战，那便战。”右目红光一闪——自吸收天劫后极境有所恢复，当年行事风格渐渐显露。
- 炎雷子沉默片刻后哈哈一笑，以“仙君失手误杀”掀过，只请仙君“莫要再失手”。清水闭目入定不语。
- 炎雷子忌惮之由：
  1. 清水是他打开封印请来的；修为虽一直未恢复，但其身上似隐藏一股**非极境**却同样令他忌惮的力量；
  2. 他极为尊敬的**那位收了月兽的前辈**曾言，不要轻易招惹清水——此人连当年的白凡都要收徒以恩安抚，而非强压屈服；
  3. 不愿为小事影响彼此关系，封仙大事在前。
- 炎雷子暗叹罗素太过自大、可惜其一身神识之术；并暗忖许木身上定有极强的守护元神之宝，说不定是清水所赠。

## 四、身份曝光的震动
- 王林沉默后恭敬开口：“多谢师兄。”全场由静转哗。
- 众修士推论链：清水之师是**仙帝白凡** → 许木是清水师弟 → 许木亦为白凡弟子；有人酸言“若是没有清水仙君，怕是这许木什么也不是”。
- 各方反应：
  - **许霆**：面色阴沉、舔唇盯着王林，念头百转，终因忌惮清水而内心有了决定；
  - **六指修士 / 大头童子**：一怔、皱眉，各有心思；
  - **西子凤**：张大嘴、不敢置信，高兴之余叹息“以我的身份，与他之间，怕是此生没有什么结果”；
  - **申公虎**：崇敬狂热更胜当年，仿若永恒；
  - **战空烈**：呆望，内心下定决心；
  - **南宫寒**：苦笑，暗定日后要多亲近许木；
  - **蒲团老怪**：目光闪动、极为震惊；惟独**血神子**内心冷笑。
- 炎雷子判定：“许木，合格。”

## 五、第一关收尾与第二关“地之关”
- 罗素身亡后，天地人第一关另换把守者接手余下考验；把守者许是被罗素之事所震——最终 **325 人中留下 196 人**，其余在传送阵内消失、被遣送出去。
- 炎雷子抬手掐诀向下方雷池广场一按，虚幻指印落地：千丈广场沸腾，雷鸣回荡，无数青色雷光如银蛇游走、相互凝聚后四下散开，于最中心留出**三丈见方空白地**；雷光凝形出一头虚幻**雷灵**。
- 规则：**坚持十五息便算通过，其余之人取消资格。**
- 旁观议论（雷池行情）：
  - 雷灵之威绝非常人可承受，有人估许木“最多也就是二十息”；
  - 即便修炼了雷术神通的雷仙殿使者，能超过二十息者也不多；
  - 雷池是**雷仙殿使者封号考核**环节之一：使者分四等，**二十息为四等，八十息为一等，过一百息可获雷仙殿内殿使者封号**；
  - 有人认为雷池考的是实实在在的修为，许木不可能出现奇迹，更看好来自**东临星**的许霆。

## 六、要点归纳
- 清水的极境在此章首次以杀招形态示于众人：红色闪电穿透元神，秒杀同场高手并回收其元神之力。
- 王林（许木）在罗天/雷仙殿一线的最大护身符正式公开——白凡弟子、清水师弟；红利是众人忌惮，代价是被视为“靠师兄”的靶子，且血神子等敌意者已在暗处。
- 悬念：地之关雷池能撑多少息（十五息通过，一百息内殿使者）。
