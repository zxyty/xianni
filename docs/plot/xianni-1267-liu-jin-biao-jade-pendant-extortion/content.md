# 第1267章 你就是刘金彪？（第九卷 云海之巅·第二更）

## 一、归元宗广场：天降玉简

- 时点：王林在密室内以**逆行者之珠**推算生机的同一刹那。
- 地点：**云海五阶星域 · 莫罗大陆 · 归元宗山门广场**。
- 状况：归元宗弟子已整理完毕，凝聚广场，只等王林出关便可离去。众人低声交谈，既迷茫又兴奋——他们已知晓归元宗不但没有解散，更要搬迁去往**七阶星域**。
- 变故：晴天骤暗，尖锐之声呼啸，一道金光临近广场，其内是一枚**玉简**，悬浮于广场之上。
- 气息：玉简散发的竟是**碎涅老怪**才有的气息，且是**碎涅大圆满**方可达到的层次——一枚玉简即令天地色变、风云倒卷、隐隐出现无数规则变化。连吕烟菲等人也面色一变，弟子哗然。

## 二、刘金彪（金彪子）的勒索

玉简中传出威严之声，笼罩归元宗乃至整个莫罗大陆：

> “老夫刘金彪，道号金彪子。”

吕烟菲抱拳询问来意（她在八阶无极宗见过世面，绝非寻常窥涅修士）。对方开出的“条件”层层递进：

1. **制造危机**：三日前有人找到他，要**买归元宗满门之命**。
2. **假意慈悲**：他与归元宗并无仇怨，虽急需**元晶炼丹**，却不愿做此事；但若真无办法，也唯有取归元宗满门之命。
3. **加码利诱**：他与**无极宗宗主**有旧，对方当年欠他一个人情；若归元宗让他满意，他可休书一封，免归元宗被解散之危。
4. **索价**：拿出足够的**元晶或等价之物**，此事就此罢休。
5. **限时**：只给**半柱香**考虑。
6. **终极开价**（后续自语传音）：将**所有储物袋、储物空间之物全部留下**，则免危并代为发书；否则半柱香后“归元宗一切生灵，将瞬间飞灰湮灭”。

话语借碎涅大圆满气息化作规则般的威压，融入所有听者心神。归元宗弟子多露惊恐，**吕烟菲则沉默中神色越加冰冷、目露寒光冷笑**。

## 三、王林出关与神识锁定

- 王林在密室睁眼，脸露冰冷，**与天运子之魂分离，将其收入封仙印，并一口吞下此印**，一步跨出密室，现身归元宗广场上空。
- **展开全部修为融入神识**，化作风暴扫过莫罗大陆，凭玉简气息锁定目标：**莫罗大陆南部边缘一座凡人都城**，城南一座**酒楼**的紧闭房间。

## 四、骗局揭底：老者与诡异玉佩

- **其人**：白发苍苍、身穿道袍、仙风道骨如仙人的盘膝老者。行骗多年，凭玉佩几乎从未失手，且谨慎小心到无人可察。
- **其宝**：身前漂浮一枚**玉佩**——晶莹剔透，其上幻化**日月星辰**，好似蕴含整个天地；诡异之处在于**毫无气息外露**，近距离亦感受不到奇异，唯肉眼看去才惊心动魄。
- **作案手法**：老者自语般说话，声音出口即被玉佩吸收，**传至数十万里外的归元宗**，伪造出碎涅大圆满的威压。
- **动机与情报差**：他早已获知归元宗此番大比难逃解散，专程守候，等归元宗修士归来、人心惶惶时一次性得手；但因**无极宗封锁消息**，他并不知晓归元宗在无极宗的惊艳表现与王林的存在。
- **心态**：得意冷笑，自诩“老夫出马，从未失败”；并垂涎被称为**五阶星域第一美女**的吕烟菲，可惜自己不能现身。

## 五、正面交手

1. 王林在房间角落现身，冷声：“**你就是刘金彪。**”
2. 老者惊跳、面色苍白，目光一对便心神轰鸣、喷出鲜血，失声惊呼“**碎涅老怪**”，转身冲向窗户欲逃。
3. 王林一迈步爆发威压，老者再喷鲜血。
4. 老者掐诀尖呼“**玉佩护身**”——玉佩速度快到连王林都眼前一花，护住其身撞碎窗户冲天遁走。
5. 王林右手虚空一拍，压力四面呼啸；**这一记足以杀死碎涅修士的攻击，被玉佩光芒外张直接崩溃**，老者毫发无损化虹远遁。

## 六、王林的判断与追击

- **推衍印证**：在逆行者之珠推衍生机的**最后一幅画面**中出现的，正是这个叫刘金彪的老者。
- **修为落差之谜**：王林极为费解——此人修为太低，看样子似乎**不久前刚突破问鼎、达到阴虚之境**；这样的修为“上百个加一起”也挡不住他方才一击，却在玉佩下毫发无损。
- **真正目标**：王林盯的**不是老者，而是那枚玉佩**，双目大亮：“这是什么玉佩？”
- **老者自曝**：逃遁中祈求玉佩，坦承“**老夫骗来的那些元晶，可是大部分都被你吸收**”，玉佩随即再度暴闪、加速。
- **拦截**：老者逃出数万里外时，王林自其前方天地波纹中一步走出，右手猛扫，**雷霆狂风化作风暴**撞上玉佩——轰鸣如天地欲裂，玉佩之光剧烈闪烁却**仍无丝毫损伤**，转向继续逃遁。
- **收网**：王林冷声“我看你往哪跑”，双手掐诀幻化**大量禁制**，一挥弥漫天地，**形成一处困牢**直奔玉佩而去。

## 七、悬念与后续看点

- 玉佩来历不明：能吸收元晶、能伪造碎涅大圆满气息、能硬扛王林可诛碎涅的一击，且无气息外露。
- 幕后仍有“三日前买归元宗满门之命”的委托者——真伪未定（可能是刘金彪的骗局话术，也可能确有其人）。
- 王林的困牢能否困住玉佩，尚未揭晓。

> 注（据世界状态须知）：本章王林在归元宗内以化名 **吕子浩**（自第1063章由吕烟菲奉上的归元宗故人身份）立足；本章其行动以王林本名叙述。
