# 第九卷 云海之巅 第1334章 一个可怕的猜测

## 一、参透聚雷印

王林以强悍神识，未耗费太多时日便把聚雷印的玄奥摸索得一清二楚。

- **施展门槛**：此印唯有雷修可施展。
- **威力机制**：威力随体内雷霆之力多寡而变，雷霆压缩得越多，威力越大。
- **化神层级示例**：钟大洪以化神修为，可在短时间内把体内雷霆压缩**十倍**，换取瞬间爆发。此等手段在闪雷族或许寻常，但若在界内王林出生的**朱雀星**上，足以成为一方强者。
- **真正上限**：真正发挥聚雷印，需修为超越修道第一步、达到**第二步**后，可从天地间摄取雷力，如此可使聚雷印疯狂压缩，直至**千倍万倍不止**，威力惊天动地。

### 闪雷族强盛之由

这种艹控雷霆的方法只是闪雷族神通之一。无数万年来闪雷族不断摸索与研究，衍生出种种艹控雷霆的法术——这正是闪雷族即便**没有第三步大能**，依然位列**太古星辰大族**的原因之一。

### 对闪雷族老祖的评估

王林判断：闪雷族最强者是一位达到**天人第五衰**的闪雷族老祖，距离第三步只差一步之遥。虽「一步如天地之隔」，但其强大无须质疑；若聚雷印在其手中施展，不知可压缩多少万倍，即便面对第三步大能，怕是也能周旋片刻。

## 二、当场实证：三万倍压缩

王林默记聚雷印，右手抬起掐出印记：

1. 大殿四周雷声轰鸣，无数闪电雷霆凭空出现，好似银蛇直奔其右手；
2. 凝聚片刻化作拳头大小雷球，球内砰砰作响，不断压缩：十倍、百倍、千倍、万倍；
3. 转眼压缩近**三万倍**，雷球消散，肉眼不可察觉，唯神识散开才可见其右手印记之上那几乎成为灰尘的三万倍雷霆之力；
4. 王林右手一挥，灰尘无声无息消散于殿内。

### 王林的自我判断（本体状态）

- 这副（于非的）身体尽管被其改造，**最多只能发挥化神修为**；
- 但其**元神庞大**，故不受身体影响，且外人看来也不可能察觉；
- 因为他的**元神已然成为雷霆，是与不灭之雷同等的存在**——即便是天人第五衰的老祖，只要修的是闪雷族印记、修的是不灭之雷，即便修为超过他，也**无法达到王林如今雷霆的高度**；
- **三万倍是这副肉身可承受的极限**，若再加剧，肉身立刻崩溃。

## 三、处境判断：不必过分低调

- **钟大洪**本就是闪雷族人，在此行事即便引人注意也无妨；
- **许立国**并非修士，而是**剑灵**，「由他快活去吧」；
- 闪雷族因外围**雷域**的存在，非本族之人根本无法进入，故族内**并无防范盘查身份**之举；
- 结论：王林认为自己（以于非之身）不必太过低调行事。

## 四、研究闪雷族族印 → 侧探不灭之雷

- 闪雷族**族印是不灭之雷的分支**，每一个印记都由不灭之雷一丝力量衍变而出；研究族印，即从侧面研究不灭之雷。
- 王林所研究的闪电印记是**于非的族印**：此印虽被于非撕下，但因**融入灵魂**，绝非肉身撕下可以破坏。
- 越研究越能感受到不灭之雷的古老与强大：仅一个分支印记内便蕴含种种雷霆变化，小小印记内**隐隐蕴含雷之本源**。
- **关键异常**：该本源无法吸收，其内蕴含**一股意志**；此意志好似在沉睡，却**无时无刻不从每一个分支印记内吸收闪雷族人修炼之力**，融入印记之内。

## 五、章末悬念

王林在大殿内滞留**一个多月**，在不断研究之下，**隐隐察觉出了一件诡异之事**。他双目缓缓睁开，露出疲惫，但有奇异之芒闪烁——即本章标题所指的「一个可怕的猜测」，本章未揭示其内容。

## 六、归属说明（据世界状态须知）

- 本片段行动主体为**王林**，自第1242/1329章起以一部分元神夺舍**于非**之身、冒其身份潜入闪雷族；文中所用肉身与族印皆属于非，言行归王林。

# 第1246章 不灭之雷即香火·太古星辰圈养猜想 / 钟大洪献宝

> 本章王林正以夺舍所得的「于非」之身潜伏于闪雷族/天雷宗（自第1242章起），文中言行均归属王林本人。

## 一、王林的推演：闪雷族=不灭之雷的门徒

- **观察**：所有闪雷族人均修「不灭之雷」，凭眉心族印的开启换来无尽雷霆之力；修为提高的同时，也在不断奉献自身的生命与所修雷霆。
- **类比**：此机制「与门徒香火极为相似」。
- **结论式假设**：若把不灭之雷看作一个**第三步大能**，则整个因它繁衍出的闪雷族就是它的**门徒**——
  1. 门徒拥有印记；
  2. 在不断修行中奉献出一切；
  3. 按奉献多少换来不同修为。
- **旁证**：这套「奉献换修为」的规则，与闪雷族族人中的**闪雷榜雷晶**制度亦相似。

## 二、放大到太古星辰：圈养之地的猜想

- 王林进一步推想：**整个太古星辰的所有种族都有印记**，且印记并非只固定在眉心——例如**蓝丝族的蓝色头发**也是一种印记。
- 若所有部落的族印均如闪雷族一样，那么太古星辰**莫非是某个修为无法想象的奇异存在构置成的「圈养之地」**。
- **参照物**：当年水道子与王林一战时打开了一界，其内有**二十亿水道门徒**与众多修真星；对那些门徒而言，水道子就如同神灵。
- 王林抬头望天，目光「破开大殿」落在天地，却**无法穿透，破不开迷雾**，心底发寒。

## 三、被串联起来的四条疑线

王林将以下线索怀疑为同一隐秘的不同侧面：

1. **封界大阵**的存在，似乎并非如**封界之主**所说那样，单纯为了困住界内之人；
2. **银衣女子**曾说：**香火有毒，是一个骗局**；
3. **蓝梦道尊**提及**掌尊**在界内被人**一吼之力重伤、仓惶而逃**；
4. **远古仙域**的存在，又起到了什么作用。

> 王林越想越感可怕，**罕见地出现心神的颤意**，深呼一口气后沉默，把猜测深深埋在心底。

## 四、王林的决断

- 「不管真假，这香火，我轻易绝不去修。」——目光坚定。

## 五、钟大洪归来献宝（数日后）

- **抢跑**：钟大洪**抢在许立国之前**回到天雷宗，一入山门便换上激动而恭敬的神色。
- **作态**：听闻王林闭关，赶到闭关大殿外，喝斥随行修士退下，独自背对大殿警戒四周，做出「即便问鼎修士来临也要从他尸体上迈过」的忠心护主之态。
- **献礼**：得召入殿，先拍衣掸尘、弓腰阿谀而入；一拍眉心印记，将数月来搜集的**众多换取雷晶之物**尽数取出，在殿内堆积如山。
- **马屁**：自称数月未见前辈，见到便神清气爽，闻前辈吐纳之息「修为都仿佛有了增长」，恨不能分身无数为前辈办事。
- **赏赐**：王林神色如常，挥手收走全部物资，食指一弹赐下**一枚丹药**；钟大洪心神一震、喜不自胜。

## 六、动身雷晶殿

- 钟大洪进言：还有数日便是**兑换雷晶之日**，**雷晶殿**也要开启，建议现在启程先去兑换一些。
- 王林略一沉吟，**似笑非笑**地看了钟大洪一眼，点头同意。

## 七、钟大洪的算计

- 抢先回来，为的是与王林**单独相处**以展开其「无敌之术」（谄媚奉承），并一路随行去雷晶殿，让**许立国**回来后无法遇到王林。
- 内心宣战：「许立国，我钟大洪眼下要与你开战了。」
- 判断王林**定是准备抢夺雷晶榜**，届时自己水涨船高，日后在闪雷族也有一席之地。
- **定性**：钟大洪**有野心**，这是他与许立国最大的区别。
