# 第1888章 誓言！

## 一、硬抗与破局：王林 vs 云空

### 战况推进
- 绿魔使者自爆的毁灭冲击，被王林以**道古**之力全力抵抗，辅以肉身与**人形铠甲（大地之土魂铠／天牛魂铠）**抵御。
- 结果：元神颤抖、倒退数千丈、嘴角溢血，铠甲胸口碎裂巴掌大小但未崩溃。
- 王林判断：**对方意在使其受伤以拖延时间**。此地已被封尘，即便穿魂铠也无法施展**缩地成寸**跨越。

### 云空的五剑与九剑影
1. 第一剑：天地剑影斩来 → 王林一拳轰碎，右臂铠甲粉碎，剑气入体被强行压下。
2. 第二剑（强三分）→ 一拳轰碎，右臂铠甲直接爆开。
3. 第三、四剑接连斩下 → 王林冲至距云空不足百丈，神色狰狞透出杀机。
4. 云空咬破舌尖，喷出**金色鲜血**化作**九道剑影**。
5. 云空虚空一抓，取出**古朴的、透出皇族气息之剑**，跃起斩出最后一剑。

### 关键设定：大天尊「无中生有」凝聚的法宝
- 王林一眼认出该剑上有**大天尊的神通痕迹**，与他的**金印**同级——皆由大天尊以「无中生有」神通凝聚而出。
- **胜负法则**：此类法宝相互对抗，重点不在法宝本质或神通，而在**制作它的大天尊为此宝凝聚了多少信念之力**。
- 王林左臂握拳，对九道剑影连轰九拳（“且看是你的剑锋，还是王某的拳硬”），剑影崩溃，左臂铠甲全碎，人已走出百丈，距云空不足二十丈。
- 金印出手与古朴长剑相撞：**剑崩溃成碎片，云空喷血被抛落大地**；金印出现一道深深裂痕、暗淡无光但未碎，被王林收起。
- 结论：云空之剑上的信念之力远少于王林金印。

### 残夜之术的限制
- 王林**未施展残夜之术**：以其披魂铠后的修为，也**不能连续施展两次**，必须留到最关键时刻（与云空真正一战）。
- 他看出云空与两名自爆绿魔使者的心思：**纯为拖延时间**。

### 击杀云空
- 云空承认“我输了”，并未提及王林穿天牛魂铠、亦未提大天尊法宝之事——“输，就是输”。
- 云空反将一军：“**你也输了**……你的魂铠时间也快过去了；他们两个的自爆、我的全力拖延，就是为让你在此停顿一时半刻。我们都没有想到、也没有算出，你居然从这里离开。”
- 王林不听废话，转身疾驰，右手向后一挥 → **一道血光（血剑）自云空眉心穿透头颅**，无惨叫无反抗，血剑回归。
- 王林**无暇查看死者是分身还是本尊**；他感到冥冥中的危机弥漫，如同**当年第一次面对水道子**的感觉。

## 二、孟土洲设定（龟甲记载）

- 王林所向方向是一片**沙漠**——孟土洲最常见的地面，**近七成大地为无尽沙漠**。
- **来历传闻**：早年有一不知来处的**天外修士**，拥有可怕的**土本源之力**，与**仙祖**一战败落后被封印于此，此地遂化为沙漠。此人传闻**姓孟**，故无数年后此地被称为**孟土洲**。
- 此地充满**土本源**气息；**绿魔洲实际上也是大地土本源**，**绿魔蝎**本就是生活在大地之中的**天外凶兽**，只是被魔气掩盖，难以看出。
- 这些传闻在王林的**龟甲**内有详细记录。
- 王林借魂铠速度疾驰，万里边界大半被瞬间跨越，只剩不到千里，孟土洲遥遥在目。

## 三、道魔宗围堵：六阵数百修士

### 传送阵登场
- 前方**六个位置**同时爆发刺目光芒，**六座传送阵**运转，每座送出**数十身影**，合计**数百人**，惊天修为气息扩散；后续仍有更多人陆续传送而来。
- **代价**：开启六阵、一次性传送这么多人，需付出绿魔洲极大代价——修为越高代价越重，若第三步修士传送而来代价更无法形容；此番**足以挖空绿魔洲十万年的积蓄**。
- 这些人原本埋伏在**天牛洲通往各洲的边界**内等王林，因判断失误而不得不强行挪移而来。

### 身份揭示
- 所有人穿着相似，衣上皆有**黑白日月图案**——王林由龟甲知晓，此为**绿魔洲第一大宗门·道魔宗**的标志。
- **结论**：这次针对王林的阻拦与杀戮，**不是整个绿魔洲，而是道魔一宗之力**。

### 人头之礼
- 数百修士呼啸而来，同时抛出一个个**黑影（人头）**砸向王林四周，阴冷报数：
  - “极天草原，修士九人之头”
  - “极天草原，修士六人之头”
  - “极天草原，玄劫散修之头”
- 这些面孔王林认得——正是**天牛第三穴内极天草原**与他共同奋战数月、最终生存下来的部分修士；**数百人头占极天草原最终幸存者的小半之多**。
- 阴毒之声：“你不是喜欢人头么，这些，便是我道魔宗，给你的第一份大礼。”

## 四、誓言（本章题眼）

> “道魔宗，若今日我王林能离开此地，日后必毁此宗满门！”

- 王林眼中露出**滔天红芒**，在内心发下毒誓。
- 文本明点：**这是他第一次，在仙罡大陆，如此强烈地要毁灭一宗**。
