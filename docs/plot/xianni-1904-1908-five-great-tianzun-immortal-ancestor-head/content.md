# 仙逆 第1992-1993章：五大天尊！／真正的国师！

## 一、开局：久帝现身，揭破仙皇之谋
- 久帝大天尊突现禁宫，仙皇毫不意外，仍踞坐于仙祖头颅之上。
- 久帝自述：当年曾追随仙祖麾下，历时无数万年，经历数代仙皇，评仙皇「雄才大略」。
- 久帝道破仙皇之谋：**利用国师的渴望**换取仙祖头颅的操控权；若给足时间完全吸收融合、化作自身之头，仙皇将成**仙族第一大天尊**——「但眼下，你没有这个机会」。

## 二、三人交手：仙祖头颅开口
- 久帝与双子（融体后的女子形态，紫意弥漫）同时逼近。
- 仙皇虚空一拍头颅，喝「八极道，极火道」，仙祖头颅竟以仙皇之声断续说出「八极道·仙火道」。
- 九道丈粗青烟凭空而起，绕头颅与仙皇转动九圈，直扑二人 —— 二人如同直面**仙祖本身的神通**，联手一击仍被逼退。
- 久帝当场判明：「不是完整的仙祖之力，只有一成左右。」
- 久帝修为大幅展开，容颜自沧桑老者化为英武霸道的中年男子（其常年保持苍老之样）。

## 三、引祖灵与仙极剑
- 仙皇盘膝坐于头颅，双手按其天灵，咬破舌尖喷血：**「以吾之血，影引祖灵」**。
- 金光凝成穿皇袍的仙祖巨大金色虚影——**头颅为真，身体为虚**；虚影虚空一抓，握出**仙极剑**。
- 关键伏笔：仙极剑现身刹那，藏在仙祖右目内的**王林立刻感受到一股深深的呼唤**。
- 仙皇借仙祖之口宣威：当年仙祖一剑之下，诸多**天外之灵形神俱灭**，唯有具备资格者才被封印于洲。

## 四、四大天尊合击
| 天尊 | 道／手段 |
|---|---|
| 久帝 | 幻化白色太阳，与紫阳相映，太阳内咆哮出白狼迎剑 |
| 双子 | 身后紫意滔天化紫竹林，竹如万剑同发冲天 |
| 道一 | 左侧天地不动、万物静止；其道为「万物化一」，一指点出蕴含巅峰之力 |
| 武封 | 右侧风云色变；当年闯过**天尊涅十九层**，以武入道，一拳尽全力与信念 |

- 结果：道一、武封被震退吐力，双子、久帝（修为高于前二人）亦后退，但**四人合击崩碎金剑**，仙祖虚影消散，仙皇嘴角溢血。
- 力量评级：除**古族那位最强大天尊**外，任何单一大天尊都无法对抗四人合力。

## 五、棋局意识（王林视角）
- 王林借国师所占肉身之眼、透过仙祖右目目睹全程，**按兵不动**：局势未明前绝不现身。
- 道一、武封的出现让王林顿悟：**地宫之变是一盘棋局**，自己乃至几位大天尊皆是棋子；对弈一方是仙皇，另一方是谁尚不可知。

## 六、四方索价与仙皇的不妥协
- 双子：**放开王林本尊离开**。
- 久帝：**让仙祖头颅重新封印**——此头颅镇压仙族**七十二洲之灵**，事关重大，非仙皇可拥有之物。
- 道一：保持**五位大天尊实力格局**，无需重新划分（内心颇为忌惮）。
- 武封：附议。
- 仙皇冷笑，喷金色鲜血，使仙祖头颅**七窍尽出金光**，化金色大浪逼退四人，意图趁隙强行吸收头颅之力——一旦成功便无惧四大天尊。

## 七、封印之障与「真正的国师」
- 强吸失败：头颅内有一层禁锢之力——**国师此前「使仙祖开口」是以神融合**，令头颅内蕴含悼亡族历代禁锢封印。
- 仙皇判断：身为仙皇，寻常时解不开，但如今能操控头颅便可解；且**「那国师将死，也翻不起大浪」**。
- 外界四大天尊全力轰击金光，时间紧迫，仙皇不甘前功尽弃。
- **自毁之咒**：右手一指点出即崩溃化血肉，念「以吾仙祖后人之血肉，引仙罡法则，解悼亡族，永恒封印」；崩溃自手指蔓延至手掌，语毕**半个右臂已然失去**，金血凝成符文自燃成灰。
- 结果：符文燃尽刹那，仙祖右目内**占据王林身躯的国师**一颤，束缚悼亡族代代的禁锢**消失**；国师落泪——这是他一生的追求，为之付出一切，只为让族人**摆脱一出生就被注定的命运**。
- 仙皇存疑：其计划连国师都看不透；久帝身在祖城故会前来，但**道一与武封为何来得如此之快**（暗指幕后另一位对弈者）。

# 第1993-1994章 悼亡族真相：国师之死与海子觉醒

## 一、国师之死与身世真相

- 禁锢封印开启的一刹，一股来自**仙皇**大天尊的力量自**仙祖头颅**外急速而来，冲入右目、轰入王林体内，横扫间抹去了占据王林身体的**国师**的存在痕迹，将其生生灭亡。
- 这是仙皇早备的最后杀招：**封印的解开，就是国师死亡之时**。
- 国师死亡一刻，尘封记忆苏醒：
  - 悼亡族传承至今几近灭绝，其初生后很久，连同他在内只有三人存在。
  - 他不知父母是谁，只见一名女子与一名女婴，母女二人相当于其亲人。
  - 那女子是**上一代国师**；**真正的国师是那名女婴**，女婴出生不久便失踪；女子把他当作国师传授本族神通。
  - 女子死后，他已成人，记忆被尘封，始终以为族人众多、皆在沉睡未死，使命是解开命运的封印。
  - 苏醒后方知：除失踪的女婴外，**全族只剩他一人**——「难怪仙皇敢解开封印」。
- 他至死不知真国师是谁，却**无丝毫怨恨**，认为保护真国师、解开一族封印是自出生就注定的使命。

## 二、仙皇的疏漏：天逆珠

- 仙皇之力横扫王林身躯，确认体内再无灵魂波动后退去。
- **即便是仙皇，也没有察觉王林体内天逆珠的存在，更没有察觉天逆珠笼罩下的王林灵魂**。
- 仙皇随即开始吸收仙祖头颅之力：金色烟气自头颅七窍散出钻入仙皇七窍，修为轰然暴增。

## 三、海子天尊觉醒 —— 真正的国师

- 封印散去瞬间，**海子天尊**身体剧烈颤抖，双眼露出迷茫与挣扎，记忆快速苏醒，体内觉醒一股来自悼亡族、属于**真正国师**的力量。
- 海子诵悼亡族之理：
  > 一切存在，因其本就存在，故而可以失去，此为「亡」；
  > 一切亡者，因生者思念，故而从无中有了思绪，此为「悼」；
  > 悼亡族，取生者思绪、取亡者存在、取追寻精神的寄托、取今生来世之力，凝威香火，以此化悼为亡——让存在的继续存在，让逝去的回归虚无。
- 指尖落下：漫天金光刹那收缩消失、全部重新凝回仙祖头颅；头颅金光一闪尽消、双目闭合、重弥死气，失去悬浮之力坠向大地；已钻入仙皇体内的金色气息失去依托，从其体内散出回流头颅。
- 仙皇愣住、近乎疯狂质问：「国师已经完全死了，你不是国师、不是悼亡族，怎么可能拥有国师的力量？仙祖封印下悼亡族不可能离开皇宫、离开祖城！」
- 海子答：「我是国师。」并叹：「死去的，是我族于这仙罡大陆除我之外最后一个族人。」
  - 能走出祖城之因：**灵魂属于悼亡族，身体却属于仙罡大陆**。

## 四、久帝揭示万年布局（第1994章）

- **久帝承认海子是自己的女儿**；自己能活至今、拥无穷寿元、成为大天尊，皆因悼亡族相助。
- 计划源起：悼亡族当年一位**天骄**想出此计，不惜做出看似分裂的迹象、寻法离开祖城，**创造了大魂门**；他虽死，却完善计划并传承下来。
- 关键之人 **王林**：来自**洞府界**的修士，只有他的身体可供悼亡族夺舍，计划方能完美进行。
- 姻缘之局：上一代仙皇归墟、现仙皇接位时，上一代国师依先祖计划与久帝结下姻缘，生下女婴（海子）——**身体属仙罡大陆，灵魂属悼亡族**。
- 突破封印之法：仙祖死亡多年封印力削弱；计划需**悼亡族全族牺牲、奉献灵魂融合**以对抗封印之力，故族人代代减少，至这一代只余两人。无数万年来所有死去的族人化作一层保护，存于海子灵魂内——**唯她一人能走出祖城而不亡**。
- 久帝因女儿之故毫无保留相助，甚至成为**悼亡族圣公**，获得当年唯有仙祖才有资格得到的**香火**。
- 悼亡族先祖算准仙皇对继承仙祖的渴望：在四大天尊逼迫下，他不会放弃而会一搏。计划关键在仙祖头颅内融合的悼亡族禁锢封印之力，故必须有一个可被夺舍之人被吸入头颅——**王林极为重要**。

## 五、后手与各方立场

- 仙皇问：若我放弃继承、让头颅重沉禁宫，你们岂非前功尽弃？
- 海子答「不会」：悼亡族代代准备的伏手会发动——**仙族七十二洲所有灵庙皆听悼亡族之命**，筹划让各洲**封印之灵苏醒**，以其苏醒为代价撼动此地仙祖头颅镇压之力；届时唯有仙祖可镇压，仙皇不继承则仙族大乱，要继承就必须解开融合了悼亡族的禁锢封印。
  - 仙皇瞳孔收缩：「如那**绿魔蝎庙**一样么？」海子点头。
- **道一**：久帝曾找他并告知悼亡族计划，未隐瞒；但有关王林之事久帝未说，道一此刻方知王林是关键人物。
- **武封**：沉默片刻，点头（知情）。
- **双子大天尊**（两个小女孩融合后的本体）：「本尊不知晓，也不想知晓，本尊来此只为带走王林——你也好、久帝也罢，今日若阻止，都将是本尊之敌。」
- 久帝补充：悼亡族仙祖只算出**模糊时间段内**会有一个走出洞府界之人出现，算不出具体在哪一个洞府界，无法精确寻找，只能等待。
- 仙皇心智极高，一言道破关键：悼亡族天骄在**天牛洲**创造大魂门，正是算出王林会在天牛洲出现，以此作为计划第一步去接触王林。

## 六、王林的动向

- 王林在仙祖头颅内听到了这一切；趁众人注意力集中于海子与久帝的对话，其**灵魂自天逆珠中散出，重新掌控了自己的身体**，双目一闪精光：「原来，这才是真相。」

2. 海子天尊觉醒为真国师，废掉仙皇继承仙祖修为的机会。
3. 悼亡族万年布局全盘曝光，王林被确认为该计划的核心工具人。
4. 王林悄然复得肉身，成为局中唯一未被察觉的变数。

仙皇更以言语反坑，点明道一、武封必是得了天大许诺，而双子「什么都没得到，只是被久帝与悼亡族利用」，试图争取双子倒戈。双子沉默——融体之后，她已看得明白。

另据大魂门老祖（悼亡族天骄）的推衍：王林被利用后，本应死在这禁宫内，成为解开封印的代价。

## 三、仙祖诅术与仙皇的两难

- 传说得证：仙祖若死，其体有诅，任何试图毁灭其身体者皆死。
- 唯一破法：其后人以血脉之力弑祖，承受诅术之力，就此断绝血脉，此后再无仙祖血脉传承之人。
- 久帝条件：仙皇照做则「依旧是仙皇、依旧是大天尊」，代价是八极封号自其一代而终；不做则当场必死。久帝坦言之所以商量而非直接杀，是顾忌仙皇死后与古族的格局变化。

## 四、王林在右目中的心声

王林藏于黯淡的仙祖头颅右目内，收敛全身气息，外界对话尽数听闻。他复盘：
- 大魂门的青牛真人当年曾言，让他三百年后去大魂门最顶层塔楼，那里创立大魂门的老祖为他留下了东西；
- 老祖出现在天牛洲、创立大魂门，就是为了等他；在其计划中王林本应已死——那既已推衍出他死在皇宫，为何还留物、还有三百年之约？
- 结论：「你既能算出我的到来，想必也能算出我的性格，此事，我岂能罢休。」

## 五、第1995章：仙皇反杀式自爆

1. 仙皇隔空摄起十丈大小的仙祖头颅，左手掌刃成刀，血脉沸腾一斩，头颅现出裂缝，金光外泄，仙皇痛苦、肉眼可见地急速苍老。
2. 关键转折：掌刃横下化作掌心，不再斩落而是猛拍——他从未打算妥协。此掌一举轰开海子国师之术（海子国师当场面色苍白、嘴角溢血），使头颅虽裂却仍可被强行吸收。
3. 头颅七窍喷出浓厚金色烟雾，仙皇张口疯狂吸收，长啸「死又何惧……不如一搏」。久帝、道一、武封齐齐扑至出手（道一掌印、武封一拳、久帝身外幻化白狼）。
4. 真相：吸收是假象，烟雾自七窍倒卷而出；仙皇肉身膨胀后轰然**自爆**——出乎所有人预料，他本未被逼至生死绝境。大天尊自爆后即便夺舍也再非大天尊。

## 六、连锁后果

- **皇宫与地宫俱毁**：自爆之力粉碎禁宫大地天空，上冲地宫瓦解祭坛与所有柱子；地宫消散使原本重叠而不同空间的两处与祖城皇宫相通，冲击自皇宫大殿广场爆开，横扫万万年不灭的皇宫，殿宇与宫内所有修士尽数烟消云散，震动整个祖城。
- **仙祖雕像护城**：冲击逼近皇宫深处仙祖雕像时，雕像爆发刺目金光对抗，轰鸣回荡中州。
- **四人同触诅术**：三人神通与仙皇爆开血肉相融（血肉带上三人气息），等同四人同时出手，最受波及的反而是已有裂缝的仙祖头颅；天灵裂缝大范围扩散，四人同时触犯诅术——道一修为最弱，黑气缠身、俊美面孔急速腐烂、惨叫连连；武封闷哼枯萎腐烂；久帝修为最高且诅力四人分担，皮肤浮现诡异符文硬抗。

## 七、仙皇的后手与王林出猎

- 仙皇仅肉身自爆、灵魂尚在，直奔头颅裂缝、目标**左目**——那里有昏迷的**连道非**。其盘算：夺舍连道非之身以分担诅力，且连道非已继承部分仙祖修为，可反败为胜。
- 就在其灵魂临近左目的刹那，右目金光一闪，**王林一步走出**：他等的正是这一刻，「就如同一个猎人，于此刻出手，开始捕猎」。
- 王林未沾染半点仙祖诅术之力，趁道一惨叫、武封退后、久帝抗诅无暇分神，直接冲入仙祖左目内。

## 八、悬念

- 王林与仙皇残魂将在左目内争夺连道非之身与仙祖修为。
- 大魂门顶层塔楼所留之物、三百年之约仍未兑现，王林已立意向大魂门老祖讨还因果。

# 第1995–1996章 王林现身仙祖头颅（第1996章标题：放肆！）

## 一、王林现身与截胡仙皇灵魂
- 双子（两个小女孩形态之外的大天尊本体）与海子天尊远远见到王林身影，一个惊喜、一个目内激动一闪。
- 王林出现极快，一闪进入**仙祖头颅左目**，时机正是仙皇被诅术环绕、燃烧的灵魂将要进入**连道非**身体的刹那。
- 仙皇虽为大天尊，但肉身自爆、灵魂受损又被诅术缭绕，此刻极虚弱。见王林后发出传人心神的尖叫：「你……你……」，透出无尽恐惧——他算尽一切、最后如枭雄般死拼，却没算到王林还活着。
- 久帝、道一、武封同样没想到王林未死。
- 王林大袖一甩，仙皇灵魂疯狂冲向连道非体内却再无机会，被吸来、虚空抓住，**收入储物空间**。
- 收走灵魂刹那，仙祖头颅因先前裂缝太大，震动中再次裂开一些。

## 二、黑发之相与宣告
- 王林扶着昏迷的连道非（疯子），一步走出头颅左目，立于崩溃天地之间，一步踏在仙祖头颅之上。
- 其满头白发再次以肉眼可见速度化为**黑发、黑衣、黑目**。
- 宣告：「此物，此人，王某要了。」四周瞬间安静。

## 三、三大天尊的处境（皆中诅术）
| 人物 | 状态 |
| --- | --- |
| 久帝 | 体内撕裂如燃烧的剧痛，以强悍修为生生压制；神色阴沉，双目露杀机 |
| 武封 | 容颜急速衰老，双目黯淡，身子颤抖，复杂望着王林 |
| 道一 | 全身黑气缭绕，剧痛似要融化身体与灵魂；四大天尊中修为最弱、诅术最重 |

- 久帝原本的算计：仙皇自爆虽出意料，但头颅已开，四人分散诅术不足致命，彼此无厮杀理由便不会引动诅术加重，分了所需之物各自回洞府闭关即可慢慢驱除。**唯一的失算是王林没死**，且修为更有增进，一举占据主动。

## 四、道一出手，被杀戮雷霆震退
- 道一嘶吼「放肆，找死」，把剧痛化作杀机，一步迈出，黑气缭绕之掌隔空落下，天地似静止、万物归一。
- 王林放下昏迷的疯子，右手一挥，幻化出**黑色杀戮雷霆大网**；满头黑发无风自动，杀戮与灭世气息轰然爆发，此刻的王林「就是那代表了杀戮的天灵」——杀戮出现，灭世之始。
- 碰撞结果：雷霆大网崩溃，王林身化无数黑气散开又瞬间重聚，目光冷漠——「杀戮，不可毁灭」。
- 道一倒退数步，感到一股奇异气息在体内撕裂且无法驱除，并使诅术暴躁：脸上烂肉成块脱落，再无当年俊美。这是他成为大天尊后**第一次在非大天尊面前被生生震退**。
- 王林冷言警告：「道一，你若还想出手，王某身上没有诅术，倒也不介意看你诅术越来越严重后，会不会就此陨落。」道一狰狞死盯却不再开口，内心第一次对王林生出忌惮。

## 五、久帝的招降与威胁
- 久帝承认再次小看王林，佩服其隐忍至今、现身占据主动。
- 开价：交出仙祖头颅 → 可安全离开，且众人发下誓言日后绝不伤他，更**全力助其成为大天尊**；若贪心，则「此地就是你的葬地」。
- 威慑理由：双子已极虚弱非久帝对手；武封与道一虽受限，略作拖延双子可以做到；还有**悼亡族国师海子**；任一大天尊燃烧大天尊之力都可将王林粉碎。

## 六、王林分赠：眼珠归双子，双耳归武封
- 双子大天尊移至王林身边后紫光弥漫、身体如融化，重新分为**两个小女孩**，面色煞白虚弱——融合为一体代价极大。
- 王林右脚在仙祖头颅上狠踏，震出两颗带金色残血的眼珠（本为一体之物），两小女孩各接一颗。
  - 王林：「此物，既对双子大天尊有用，还请双子大天尊收下，多谢之前相助。」
  - 判断依据：头颅诅术已被仙皇与久帝四人分担破开，收仙皇灵魂时已有所察觉，故不惧自身沾染。
- 久帝面色立变，怒吼扑向王林；道一双目通红、化残影再度逼近。久帝喝令「武封、海子，一起出手」「此子绝不能留」——身为存活太久的大天尊却需召唤他人合击，对他是罕见耻辱。
- 两小女孩接珠后果断再度融体，化作真正的双子大天尊，迎向久帝与道一。
- 趁双子挡住二人，王林右手化两道黑光斩在仙祖头颅双耳处，金色残血溅开，双耳化金光送向武封：「武封大天尊，这是你所需之物，不送。」
- **武封接下收走，退后数步，一言不发，深深看王林一眼，转身离去**——他已无参与必要，需尽快回洞府闭关驱除诅术。

## 七、久帝、道一全力出手与王林对海子的劝退
- 久帝不惜加重诅术施展太阳之力：全身白光弥漫，身后化出巨大白色太阳，一尊**白狼**咆哮而起、狼头穿透其躯直奔双子，硬撼双子大天尊。
- 久帝喝令「道一、海子，抢头颅」。道一亦全力出手，身后现出太阳但**黯淡无光**、随时可散，力量不多——杀跃天尊足够，但短时间无法灭杀「杀戮降临」的黑发王林，需与海子的悼亡族神通联手方有胜算。
- 王林携身下仙祖头颅后退，抬头向仍在挣扎的海子开条件：
  1. 「我不知是称呼你为海子天尊，还是海子国师」——点破其悼亡族国师身份；
  2. 悼亡族利用他解开封印；
  3. 海子即便与久帝联手，最多迫他放弃头颅，杀不死他 → 对悼亡族无好处；
  4. 若不参与，**先前被利用之事一笔勾销，当此事从未发生**。

## 八、本段格局要点
- 王林由「被认为已死」转为主动方：手握仙皇灵魂 + 仙祖头颅 + 昏迷的连道非。
- 分赃换盟：眼珠→双子（酬前助并促其再战）、双耳→武封（买其退场），成功从四打一削减为久帝+道一，并正在劝退海子。
- 诅术成为王林最大凭仗：他未沾诅术，而对手出手越重、诅术越烈。
