# 《仙逆》第八卷 联盟隐秘 第936章 渔翁

## 一、收拾行装：雷兽与许立国入袋

- 王林感慨射神车所化雷兽已全无当年『不屈目光与狂傲雷吼』之风姿，若非心神感应几乎认不出，随即挥手将雷兽化雷光收入储物袋。
- 许立国（自称『小许子』）阿谀求情，想在此地自由活动，被王林一句『此地远比你所想危险，给我回来』虚空一抓收回储物袋；许立国面上不敢露色，内心早已骂开。

## 二、致命发现：此地封印一切可吸收之气息

- 望月体内的小型望月已全部崩溃身亡，危机大减，王林凭对望月的熟悉几乎化作残影疾行。
- 异常：望月融入漩涡到此地后，体内**半点天地元力也感受不到**，且**自身元力正缓慢消失**。
- 内视查验后确认：并非真正消失，而是被一股**无形之力压制，如同封印**，时日一长必将全身元力尽数封印。
- 判断：**此现象与望月无关，源于望月当前所处之地**；且『在望月体内尚且如此，若离开望月到外界，封印速度恐怕更快』。
- 到望月之骨附近查验：骨上原本外散的大量灵力**全部消失** → 结论：**封印的不止元力，还有灵力，凡可被修士吸收的气息在此地都会被封印**。
- 关键优势：**古神肉身之力不受半点影响**。
- 联想：这种封印**与仙遗族的纸符有相似之处**。
- 战略结论：『在此地时间越长，我的优势就会越大』——众人元力越耗，王林越有机会**渔翁得利**。

## 三、洞口前的对峙：武东禅 vs 一木子

地点：望月体内一处百丈大小空旷，四周肉壁蠕动退开；其后即为**通往古神幼子的肉壁之口**。

- **武东禅**：紫袍多处破损、面色苍白，气息极强『如利剑出鞘』，守在洞口前。立场：『我不管玄宝上人如何，只是有我在这里，谁也不能进去。』
- **一木子**：青衫老者，面色略苍白但双目平静。称在这『虚无之地』二人元力并非无尽，自己此去『不是为了那狗屁仙人』，并质问武东禅不去助**玄宝**对抗**清水**、反在此阻拦，荒唐至极。内心盘算：不可在此浪费太多元力，速战速决，尽快进入望月深处**完成大长老交付的任务**。

### 交手过程

1. 一木子掐诀幻化**巨木**占据一切方位轰去。
2. 武东禅挥出手心**五光十色的气泡**，气泡砰然破开，巨木一震随之瓦解。
3. 一木子甩出**手指大小的青色木条**，低喝『**一木，一界**』——木条骤然放大、绿意浓郁扩散全场，如凭空隔绝另辟一界，形成封印环绕武东禅。
4. 一木子借机绕过武东禅，直奔身后洞口，消失不见。
5. 不到三息，武东禅体外绿气内**接连凭空出现并破碎的气泡**将绿气消解殆尽；他看了一眼洞口，嘴角微笑，迈步追入。

> 二人虽察觉王林伸出的一丝神识，但**都没把王林放在心上**。王林见状不假思索后退至望月之骨附近。

## 四、王林的应对：神识飞剑探路

- 盘膝坐于望月之骨旁，拍储物袋取出一把**短剑**，掐诀**分出一丝神识融入剑内**，操控其无声无息飞入洞口。
- 理由：『即便被发现毁掉，也没什么关系』；『此地之人哪一个不是跺跺脚可令星空崩溃之辈，除了**清水师兄**，在其余人眼中我只是蝼蚁』。
- 底牌：『他们却不知晓，我的古神之力在这里没有受到丝毫影响——且让他们先去乱战，等元力所剩不多后，我这个蝼蚁或许可以**渔翁得利**』。
- 洞内神通波动激荡，以王林修为操控飞剑颇为艰难，幸而此地压制元力，飞剑得以勉强前行。

## 五、结尾：古神幼子所在的巨大漩涡

- 飞剑冲出洞口，眼前是一个**缓缓旋转、散发无尽吸力的巨大漩涡**——王林知道，漩涡内即**古神幼子所在之处**。
- 此刻漩涡外**不见清水、一木子等人踪迹**；王林略一沉吟，操控飞剑**直奔漩涡而去**。
