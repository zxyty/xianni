# 第774章 子母道枯

## 一、疗伤与情报：李元冲击阴虚

- 李元修为本已至**问鼎大圆满**，迟迟未破阴虚，症结在于**元神内元力不足**。
- 王林以缴获的**三个元神**滋养李元，其中**阴虚老者的元神**蕴含庞大元力，使李元突破的几率大增。
- 王林在李元四周布下禁制护持，自身盘膝旁坐炼化元力。

## 二、王林的决断：血祖出自姚家

- 从阴虚老者的思绪/记忆中，王林确认：**血祖果然是姚家之人**，姚家极为强大，尤其其老祖**血神子**。
- 王林心态冷硬：「我王林修道以来，遇到的敌人不泛强者，多一个血神子，不多。」并自问即便早知一切，也不会因血神子强大而放任李元不救；且既已得罪血祖，心中已有决断。
- 底牌意识：**只要掌握「融入天地之中的神通」，即便拓森前来亦可全身而退**。
- 另判断：那老者神识内的一些记忆「有些有趣，或许对我有大用」（伏笔）。
- 修为展望：待体内元力**全部吸收**，即可**无限接近真正的第二步——窥涅初期**。

## 三、破解仙家法宝的开启之法

### 缴获与线索
- 王林召来三名死者的**三个储物袋**与**数把飞剑**。
- 这些飞剑（共九把）与自己储物袋中的**九个兽骨**，是他与李元一同在**仙人的储物空间**内发现之物。
- 此前王林曾以神识查看兽骨，其内另有一股**烙印**，令其神识无法彻底印下，更谈不上操控——由此怀疑存在**特殊开启方法**。

### 复原原始摆位
1. 九把剑飞起分散刺地：**八把成圈**，**一把单独刺入一旁地面**。
2. 九个兽骨飞出：**最大的兽骨落在八把飞剑中心**，**其余八个小兽骨环绕那把单独刺地的飞剑**。
3. 此即当初发现它们时的样子。

### 护法布置
- 双手掐诀在四周打下烙印；散开体内元力弥漫**方圆千丈**，化作**白雾**。
- 雾中元力充满威压，向外人宣告此处有**第二步修士**闭关，闯入即遭元力攻击；阴虚乃至**阳实**修士见之亦须谨慎。
- 又张口吐出**碎片大印**融入雾内，方才安心闭目。

## 四、元神穿行：三天的烙印历程

1. 天灵光芒闪烁，**太古雷龙般的元神**飞出，冲向八个小兽骨。
2. 兽骨生出**吸力**，元神被分作**八道**融入其中；吸力似无止境，王林先行试探后抽回元神（故有上述护法布置）。
3. 正式行功：八兽骨吸尽元神后散发**妖异之芒**，射出**八道蓝光**汇向中心飞剑；元神在兽骨中经历一种他看不明白的**转化**，随蓝光入剑。
4. 剑鸣阵阵，浓郁**剑气**疯狂冲击元神；王林以元神内元力化风暴横扫，剑气却**无始无终**。
5. 王林识破此为**禁制阵法**，遂盘膝以**禁制推衍**之芒不断推算，以元力护罩硬抗，终告看破，心念一动布下禁制向四面八方散开。
6. 被八兽骨包围的那把飞剑冲起，飞至被八把仙剑环绕的兽骨上空，剑尖冲下散出剑气，**剑气一分为八**融入八把仙剑，王林元神再分八份随之而入，重历同一考验（剑气更多）。
7. **三天后**，八把仙剑同时散出剑气凝聚中心兽骨，王林元神冲出，进入**最大的、生着四根利刺的兽骨**内融合为一，并留下**烙印**，随之生出明悟——对此兽骨了如自身肢体。
8. 元神归体，王林睁眼，面露惊容与兴奋。

## 五、子母道枯：法宝档案

- **名称**：子母道枯（兽骨形，最大者生四根利刺，配八小兽骨 + 九把仙剑构成子母体系）。
- **性质**：真真正正的**仙家法宝**，威力极大。
- **损伤来历**：当年其主**与古神一战**时受损，加之**其主身亡**，直至今日尚未完全修复。
- **现状评价**：即便受损未修复，仍是王林**现阶段最强大的法宝之一**。
- **收纳形态**：兽骨如复活般一口吞来，于王林手中消失；片刻后其**右手手背浮现栩栩如生的兽骨图案**。
- **机制要点**：无特定方法根本无法在其上留下神识；一旦成功烙印神识，便立刻掌握使用方法。

## 六、章末悬念

- 王林并未收起元力雾。
- 远处李元伤势已恢复很多，**元神正与元力融合进行最终突破**（冲击阴虚），能否成功王林亦无把握。

- 依【世界状态须知】：王林此阶段在外以自创化名「许木」行事，本章行为一律归属**王林**本人。
- 「李元」在第729章已被记为死亡、且第711章曾被王林指为占据其身的仆魂；本章李元仍存活并冲击阴虚，属剧情延续，行为归于本片段中的李元其人（存疑处已作低置信度处理）。

# 第731章 纸符与藏诀阁——王林收获破禁古镜、结盟李元同行雷之仙界

> 归属说明：本片段中王林以自创化名「许木」行事（李元称其「许兄」），所有「许兄/许某」的言行归【王林】。

## 一、搜取储物袋：第二张纸符

- **女修储物袋**：内有物品但入不了王林之眼，只取其中**仙玉**，储物袋随手丢弃。
- **姚姓少主储物袋**：内有一些物品，王林目光一凝，落在**一张纸符**上——与此物相比其他之物不值一提。
- 这是王林在**罗天星域**见到的**第二张纸符**。他取出先前那张对比：两张大小相差不多，但其上**以朱砂勾勒的符号却不同**。
- 王林神识扫过，察觉两张纸符上有**轻微的元力波动**——以他之前的修为察觉不到，说明其品阶不低。
- 判断：「莫非此物还是一样法宝不成」，遂谨慎收起，感觉此物**非比寻常**。

## 二、阴虚老者残魂情报：雷之仙界·藏诀阁

从最后一个储物袋主人（阴虚老者）的元神思绪中，王林读出——老者思绪凌乱，**惟独对这雷之仙界一行极为清晰**：

| 要点 | 内容 |
| --- | --- |
| 老者此行任务 | 奉**姚家**之命，带姚家族人前往雷之仙界的**藏诀阁**获取仙术 |
| 封印之地 | 雷之仙界有一处**碎片大陆**，无数年前被**罗天星域四大传承至仙界的修真家族**联手封印 |
| 藏诀阁来历 | 碎片大陆上是当年雷之仙界的藏诀阁；「藏诀」即储藏仙术，其内仙术**保存完整** |
| 机制 | 由当年**雷之仙界仙帝与手下共同打造**，另有**规则**在内，能否得到仙术**全凭机缘** |
| 现状 | 四大家族无法破解，只能封印碎片大陆，每次开启时送族人来碰撞机缘；藏诀阁几乎成为四大家族**专属之地，不允许外人踏入** |
| 规模 | 姚家此次来雷之仙界**并非一队，而是十组** |

王林眼露精光——「藏诀阁」成为其新目标。

## 三、李元苏醒：阴虚之疑与恩义

- 李元呼吸粗重、缓缓睁眼，低头看断臂，轻叹：**「多谢许兄，只是李某或许无缘阴虚，元神中无法容纳那么多的元力。」**
- 王林收去四周元气所化之雾，仔细端详后开解：**体内元力滋养元神，待元力全部吸收之日，自可达到阴虚**；这一日或快或慢，但**一定可以达到**。
- 李元起身深鞠一躬：**「许兄，你对李某有大恩，此恩，李元铭记在心，不忘。」**

## 四、物归原主与破禁古镜

- 王林将**唯一未搜的储物袋**（李元之物）神识一扫后扔还李元，地面上**九把仙剑**也在元力牵引下飞回李元身边：「物归原主。」
- 李元从储物袋中取出**破禁古镜**回赠王林：**「此物名为破禁古镜，流传至今已然不多，可破绝大部分禁制。」** 王林收入储物袋。

## 五、血祖之问

- 李元：「许兄此时修为，李某已经看不透……不知那**血祖**，可曾被储物空间所毁？」
- 王林轻描淡写：**「血祖之危，已然解除，虽说没死，但却也相差不多。」**
- 李元心神一震，以其心智从这一句便分析出：**王林修为的突飞猛进，与血祖绝对有所关联**。

## 六、结盟：走遍雷之仙界寻仙术

- 王林邀约：「李兄，许某要行走这雷之仙界，寻找一切能找到的仙术，你可愿帮我一路破解禁制？」
- **王林的盘算**：以他此刻实力，雷之仙界除有限几人外无人是对手，带上李元无碍其安全；而李元对雷之仙界（尤其**禁制**）的了解远胜自己，有此人在寻找仙术将容易很多。
- 李元豪情涌现应允：「许兄所愿，李某拼尽一切，也为你达成……只要给李某时间，一切禁制，李某都有把握破解。」

## 七、当场示范：破开仙人遗迹「引仙府」

- 李元指向前方一片**平淡无奇的平原**（杂草枯枝、风吹作响），称此地曾是一处**仙人遗迹**。
- 李元**单臂掐诀**（此刻体内元力充足，一些因**先人引奴印**所致原本无法使用的家族传承禁制此刻也能施展）。
- 天空一暗，平原如画布被掀起，在禁制印诀落下之际缓缓破碎，露出**一片废墟的城池**；废墟前立一块残破石碑，上书三个沧桑之字：**「引仙府」**。

## 八、李家绝学：破灭禁·心禁之术

- 李元自陈：**仙术并非掌握口诀才可施展**——以李家**破灭禁**的**心禁之术**，通过一些**仙术施展后的痕迹**，多少可以**逆推**出来。
- **代价**：此术**伤身**，李家绝不会轻易动用；但只要王林需要，李元必帮。
