# 仙逆 第1631章 远古仙域

## 一、天劫最后一关：十二尊被驱使的古之存在

王林置身百万雾气深处，面对四尊八星古神、四尊八星古魔、四尊八星古妖的围攻，全程闭目应战。

### 八星古神的来历线索
- 首个冲来的八星古神胸口有一道巨大疤痕，似在其被恒吉（原文如此）之前险些被人一斩破开胸膛；八星古神即便非王族，肉身亦极强，仍留此伤，可见当年出手者之强。
- 该古神出拳时身后浮现虚幻之影：一尊身穿铠甲、眉心九个星点的九星古神，杀戮气息无尽。
- **设定要点**：古神背后的虚影是传承或效忠者的象征，见证其身份与传承来源。故这尊八星古神的传承/效忠对象即那位九星古神。

### 战斗过程
1. **退古神**：王林闭目迈步，一掌接住八星古神全力一拳并轻柔推开，掌拍其身，古神喷血退万丈。三古神合围时，王林眉心七个星点闪烁旋转——王族古神之星显现；他半步向前，拍拳、按胸、双手抓拳猛推，刹那间退下四尊古神。
2. **收服光环**：交手同时，其额头金色光环的金光急速消散，金光尽失即等于被王林彻底掌握。
3. **灭古魔**：古魔以魔气神通、幻化古魔法器（巨大漆黑战斧）来袭。王林神色阴冷——「古神是同族，还可留手；古魔古妖同类不同族」。他一按崩碎战斧，魔气反被其闭着的右目吸尽；破空至古魔身前按胸五指一抓一拽，八星古魔崩溃成血肉，浓郁黑气被吸入右目。其后以背撞碎吞噬而来的古魔，左掌按出**因果印**吸魔气，最后一尊古魔的神通在其身前如透明般被穿透，一掌按胸化雾被吸入掌心。
4. **役灵印**：右手抹过闭着的右目，额头光环最后一丝金光消散、彻底无光；王林睁眼。眉心中仙人不灭体所化金色血液蔓延光圈，光环再度爆发更亮金光——**这一次的金光属于王林**。他白发无风自动、白衣如雪，杀气滔天喝「你们，找死」，右手一指上空，**役灵印**幻化巨大金色掌印（自梦道苏醒后第一次施展，威力远胜当年），一按之下四尊古妖尽数被穿透崩溃，妖气齐聚其左目被吸收。
5. **送同族解脱**：王林言四尊古神「身为我族古神，本应战死沙场，却被人抹去神智沦为傀儡」，以王者之身感其悲，遂将役灵印方向一改指向四古神，随即闭目不忍看。四古神烟消云散，死前面露解脱之色。

## 二、旁观者：战老鬼与「第三个」

百万雾气之外，战老鬼激动难抑：
- 「如此短的时间，他竟然真的收服了此宝」
- 判断王林是**第三个**的可能「不是三成，而是五成」
- 自述：我在**内府**找了无数年，**七彩**在**外府**同样找了无数年，始终没有找到第三个；若能被我先找到……

## 三、踏入万丈裂缝：远古仙域

王林言「天劫，该结束了」，走向并踏入万丈裂缝。裂缝内景象一如他当年所见：
- 一望无尽，天空昏暗；
- 地面耸立无数巨大石像，皆为古神、古魔、古妖；
- 弥漫真正的仙气，虽稀薄却明显与裂缝外不同，**这股仙气属于仙罡大陆**。

## 四、章末悬念：另一个「王林」

王林下方一处古妖雕像上站着一名青年：一头白发、一身白衣、双目寒芒、负手仰望天空。其样貌、神色、气息等一切**与王林一模一样，不分彼此**。王林瞳孔骤缩，双目恢复如常后缓缓开口：「你，是谁」——章毕。
