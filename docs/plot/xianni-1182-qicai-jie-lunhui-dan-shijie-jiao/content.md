# 第九卷 云海之巅 第1182章 七彩界（第一更）

## 一、开场余波
- 云魂子之事被搁置，无人再提。
- 庞姓老者因先前言语得罪王林（此时以化名「吕子浩」行事，自第1063章起），忆及王林冰冷话语而心中叫苦、始终提着心神。

## 二、七彩界的规矩与地貌
苍松子给出行动禁忌与背景：
- **神识不可散开太远**，否则引来凶兽攻击。
- **飞行不得超过百丈**。
- 此地虽是外围，却已有**十二阶化雾凶兽**。
- 「七彩界」是苍松子自取的称呼；他的**元晶**即得自这里，此前来过几次，但**每次都无法进入内部**。
- 地表无树，只有光秃秃的山脉，一片片雾气**各自独立存在、彼此互不干扰**。
- 天空七彩之芒诡异，王林感到其中**隐含某种无法理解的规则变化**。
- 此界**没有黑夜，只有七彩的白昼**。

## 三、遗迹线索
- **古人遗骸**：苍松子称其中**有仙人，也有一些奇异者**。
- **山中洞府**：右侧山峰中段有一石洞，非天然，明显是人工开辟的洞府；四周有十二阶凶兽守护。苍松子上次**引开凶兽进入并有所获**。陈天军盯看良久，心思不明。
- **上古禁制**：王林早已看出此地布有无数岁月久远的禁制，大半崩溃、仍有部分运转；其威力**强于青霖洞府内的禁制**不少——若非崩溃大半，此地寸步难行。
- 行进十多里后仍在**外围**，前方成片山脉未过，山后景象不明。苍松子越走越慢，需凝神回忆路线。

## 四、轮回丹
狭路尽头有雾气堵路，雾气边缘靠山倚着一具风化骸骨：
- 骸骨**盆骨上嵌着一枚散发七彩光芒的丹药**，有细微裂缝、部分融化，已非圆形而作**月牙状**——系被人吞服后尚未完全融化吸收、吞服者却身死留下。
- **药香诡异**：顺鼻入体使**元神一震、记忆倒流**，往昔记忆不受控浮现。
  - 王林咬舌尖强行清明；
  - 庞姓老者**早已封闭五感**（显然知晓此地诡异）；
  - 青衫老妪短暂迷茫后恢复；
  - 陈天军亦很快恢复。

### 轮回丹设定（苍松子讲述）
- 端木童子所修**曰月轮回道**，感悟意境即「轮回」，**需经历九次轮回方能成道**，但天道无迹，成功轮回难度极大。
- 传闻**上古修真界**有轮回丹，**拥有天地之威，服下者可进入轮回寻找天道**。
- 时至今日轮回丹已失传，**仅剩半副丹方**，炼不出成丹，**只能凝聚一些轮回之气**。

## 五、交易与分赃
端木童子当面点破：苍松子事先做足功课；若非骸骨旁有雾气（蛟龙），也不会「好心」相邀。

苍松子坦然承认：
> 端木的**轮回大自在神通**对余下行程很有帮助；我等帮你取丹，你为我们打开余下道路。

**战利品分配（战前口头约定）**：
| 人 | 所取 |
|---|---|
| 陈天军（役兽宗） | 蛟龙**魂魄** |
| 青衫老妪 | 蛟龙**肉身** |
| 王林（吕子浩） | 雾气内**所有元晶** |
| 苍松子、庞姓老者 | 不取物，只求**通过此地** |

## 六、围猎十二阶雾化蛟龙
- 苍松子定性：**十二阶雾化蛟龙，相当于碎涅大圆满修士**；凶兽终究是凶兽，配合得当＋端木轮回之术，并非没有可能。
- 端木童子**掐诀、发须无风自动，双眼化作曰月之瞳**，左手点眉心、右手前指，**曰月印记化漩涡**横扫入雾。
- 蛟龙巨头破雾而出，腥风狂扫，带**堪比碎涅大圆满**的威压。
- 端木以曰月幻化环绕龙头形成漩涡封印，明言：**「我轮回之术只能影响此兽十息」**，随即盘膝坐地维持，并放出一把**七尺飞剑**化剑光杀去。
- **陈天军**掐诀现幽光，瞬移至蛟龙头部盘膝而坐，全身幽光剧闪，**整个人融入蛟龙体内**（役兽宗手段）。
- **苍松子**一挥手幻化**数千上万把飞剑**，如剑雨压下。
- **青衫老妪**掐诀起寒风，狭路瞬间化作冰晶蔓延扑向蛟龙。
- **庞姓老者**跃起，双手雷光，降下**雷球**。
- **王林**瞬间近身，右手握拳**一击落在蛟龙庞大身躯上**。
- 蛟龙怒吼咆哮，欲挣脱童子的道境轮回封印——章末悬置。
