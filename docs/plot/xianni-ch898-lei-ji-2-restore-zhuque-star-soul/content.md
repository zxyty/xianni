# 仙逆 第898章 雷吉（之2/2）

## 一、以朱雀星了却因果

王林对周武泰言：「周武泰，你既是朱雀子，我便以朱雀星来与你了却因果」，随即脚下起波纹，消失原地。

## 二、抽星魂

- 王林出现在联盟星域一颗荒无人烟的星球外，以**窥涅初期**修为毫无保留弥漫，右手虚空一抓狠抽——此即「抽星魂」。
- 星球剧烈颤抖，沧桑气息散出，如被无形大手抓起。
- 王林**只取三成即松手**：对该星有影响，但不至过于剧烈。
- 一路在数个星球内抽取星魂，以其修为亦有些力不足；**大头童子不能融入天地**，此事只能王林亲为。
- 一日后，王林融入天地返回朱雀星，右手手心中**七个絮状光团**环绕，各有沧桑魂力。

## 三、朱雀星复苏（七魂入地）

| 次序 | 效应 |
|---|---|
| 第1团 | 朱雀之魂（非大地）震动；地底深处出现大片灵脉，半废弃状态缓缓有了生机 |
| 第2团 | 朱雀之魂震动更剧；灵脉疯狂凝聚，原有山峰透出大量灵气；凡人脚下暖意、神清气爽、疾病一扫而空 |
| 第3–5团 | 齐齐融入大地，整星传出**凤鸣**（唯极少数修士可闻）；耗尽的灵脉重现灵气，灵气浓郁达一定高度；所有修士感到天地灵气大范围活跃，体内灵力被牵引自行运转 |
| 第6团 | 青山更葱、绿水更波，盎然生机化作波纹回荡全星 |
| 第7团 | 朱雀之魂震动达巅峰；部分资质不明显的凡人资质立刻明显；无数低阶修士突破瓶颈，各门派修士放弃一切事务全力打坐吸收灵气 |

**结果**：朱雀星仍未达极品星球，但已不再半废弃，灵力**恢复到当年巅峰**。

## 四、旁观者反应

- **周武泰**立于朱雀山上望天，感慨呼气，喃喃：「王兄，多谢」。
- **朱雀国某宗派山门前的老道**（相貌与当年黄龙一模一样）微笑摇头评点：
  - 「以七个星球的星魂，来补充一星之力，不划算。」
  - 「不过此子能这么做，显然是故土难忘，这一点，倒是不错。」
  - 「此番**罗天之战**，就是不知此子，会做出如何选择了。」——为后续罗天之战埋伏笔。

## 五、王林的下一步

王林一步迈至一处山谷，谷内景物与当年离开时一模一样，自语：

- 「因果已了，是该离去了。」
- 「只是在离去之前，那**仙遗族之地**，却还是要去一趟。」
- 「可惜始终寻找不到让体内**仙豆仙元之力**增加的方法，否则的话，就可以研究**撒豆成兵之术**。」

## 六、杀域界的追杀令

- 联盟星域内一片**单独存在的星空**：黑色建筑风格迥异，形如一把把大剑刺入虚空；正中高塔高**不下千丈**，黑色铁链自塔身蔓延与四周建筑相连。
- 设定点明：**修真联盟分「两殿四尊八方界」**，此地即**杀域界**。
- 一道鬼魅身影幻化落于建筑之上半跪朝拜高塔——全身散发黑气的老者，禀报：「**罗天新封，正品雷仙许木**之踪影，已然找到。」
- 高塔内传出阴森冰冷之声：「**魂杀二侍**，把许木人头，给本座取来。算是我杀域界送给罗天修士的一件大礼。」

> 归属说明：「许木」系王林所用之名（自第661/669/711/731/771/821章沿用，疑为其自创化名而非冒用他人姓名）。故杀域界此番悬赏的目标实为**王林**。

## 七、伏笔与看点

1. 罗天之战将至，黄龙面貌老道关注王林的「选择」。
2. 仙遗族之地一行待启。
3. 仙豆／仙元之力上限未解，撒豆成兵之术受阻。
4. 杀域界魂杀二侍将追杀「许木」，与罗天修士的势力冲突交织。
