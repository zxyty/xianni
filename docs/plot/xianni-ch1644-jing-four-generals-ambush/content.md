# 第1644章 静！

## 一、白虎灵认主离去
- 虎灵向王林一拜，身子一晃冲入王林下方漩涡，与漩涡融合，漩涡消散、重化为庞大白虎。
- 白虎呜咽前冲，自王林身下离去，于远处天空回望王林一眼，**完全不理会白发老者（白虎战将）**，随即化作无尽白芒，白光映照天地，消散于远古仙域。
- 白虎战将面色苍白，恐惧不信：“这不可能”。

## 二、三将同时偷袭
四座如山巨大雕像，各有一位战将自眉心漩涡走出：

| 战将 | 装束 | 神兽虚影 | 出手方式 |
|---|---|---|---|
| 青龙战将 | 青衣老者 | 青龙（无尽之长） | 化青色长虹，食指直点王林眉心，青龙融入其指 |
| 玄武战将 | 黑衣老者 | 玄武（如龟，嘶吼惊天） | 身影如电，一拳轰来，拳上幻化无数利刺 |
| 白虎战将 | 白发老者（已受伤） | 无虚影 | 双手握**开天之刀**，一跃而起自上方斩落 |
| 朱雀战将 | 红袍 | — | **未出手**，认为三人联手足以轰杀王林 |

- 出手时机选在白虎白光刺目的瞬间，近乎偷袭；四将配合多年，心有灵犀。
- 王林生死危机感笼罩全身，却因“一生凶险”而越危越冷静，未把三个**疗伤中的残仙**放在眼里。

## 三、王林三招破三将

### 1. 古族不灭指 → 逼退青龙战将
- 构成：天空扭曲的**道古头颅**融入此指 + 眉心**古神星点** + 右目**古魔/古妖星点** → 化古之三族之力涌入右手食指。
- 定位：王林（道古）自创**最强一式大神通**，威力可破**七彩仙尊的封印**。
- 机制：不会彻底崩溃，**在崩溃中不断恢复**。青龙指仅令其指头毁灭数百次，远不足仙尊封印之力。
- 结果：青龙战将喷血，青龙虚影轰然崩溃，蹬蹬退后百丈，眼露骇然。
- 代价：王林嘴角溢血，体内轰鸣，五脏六腑如扭曲般剧痛（强行压下）。

### 2. 仙人不灭体金血 → 崩伤玄武战将
- 王林眉心幻化出**仙人不灭体所化的金色血液**，金光刺目，蕴含极精纯的仙人血脉之力，令四大战将恐惧。
- 玄武战将距离最近，被金光笼罩，身体如被气化，冒无数黑气、凄厉惨叫。
- 金血穿透其拳头 → 玄武虚影崩溃，玄武战将喷血急退，黑气缭绕、右拳血肉模糊。
- 其惊呼：“仙人血脉…这是**仙人不灭体**！”金血随后飞回王林眉心。

### 3. 六掌印 → 崩碎开天之刀、重创白虎战将
王林右手一掌，连成一串六个掌印（远观如残影）迎上斩落的开天之刀：
1. **九色火焰**掌印（火焰风暴）
2. **雷霆**掌印（天地八方雷霆）
3. **因果本源**掌印（混沌之气）
4. **生死本源**掌印（黑白二气）
5. **真假本源**掌印（虚幻实质转化）
6. **杀戮气息**掌印
- 结果：开天之刀一震即崩溃，六掌印尽落白虎战将胸口，其惨叫爆出血雾、仙力宣泄，倒卷中被青龙、玄武一左一右扶住。

## 四、白虎战将求撕封印
- 白虎战将神色萎靡、面白发散，却凶光更盛，推开青龙玄武狂吼：“**助我撕开疗伤封印，释放本源，我要杀了他**！”
- 其气息暴增，眉心幻化出一道**金色符文**。
- 其言：“若非我等为了恢复修为，岂能被这蝼修逼退…他只是**下界蝼蚁**，有什么资格逼退我等仙人！”

## 五、李广之弓，天地静
- 王林左手虚空一抓，金光刺目中现出一把**透出无尽苍凉的弓——李广之弓**。
- 左手持弓、右手拉弦，嗡的一声，弓弦拉满，一把**古老的箭**慢慢幻化于弦上。
- **弓弦嗡音一起，四周瞬息寂静**：白虎战将止吼呆立、面色大变露出惊恐；青龙战将下意识退后，眼露从未有过的恐惧；玄武战将面色由苍白转惨白，惊呼“李广之弓！”

## 六、朱雀战将现身求和
- 第四座雕像眉心漩涡中，走出**身穿红袍的朱雀战将**，神色略显尴尬，先行抱拳：
  > “王林仙友，莫要动怒，还请看在老夫的薄面上，我们一谈如何。”
- 本章至此收束于对峙与谈判的开端。

## 七、要点小结
- 三位战将虽为仙人级『残仙』，但均在**疗伤恢复修为**状态，被本源封印所限，故被王林逐一击退。
- 王林本章展示的底牌层级：古族不灭指（道吉/道古三族之力）＞仙人不灭体金血＞六本源掌印＞**李广之弓（威慑最强，四将闻名即惊）**。
