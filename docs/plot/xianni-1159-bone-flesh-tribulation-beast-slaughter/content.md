# 第九卷 云海之巅 第1159章 威！

## 一、骨劫落幕：百万里元力漩涡
- 王林本尊在莫罗大陆归元宗地底重聚骨骼，方圆百里天地元力疯狂涌入仍然不够。
- 莫罗大陆外星空的漩涡由百里 → 千里 → 三千里、五千里、一万、三万、十万、三十万 → **百万里**逐级扩散，搅动天地元力与星雾轰然灌入地底。
- 元力暴涌之下，下半身腿骨凝聚之速暴增，左腿、右腿先后成型，全身骨头完成一次重聚，**骨劫消散**。

## 二、星雾之谜（设定要点）
- 云海星域内极少有人知晓星雾来源，似乎自云海星域诞生时便已存在；若追溯，仙界未崩溃、远古仙域尚在之时星雾也依然存在。
- 修士只知：正因星雾存在，云海内才充满一头头凶兽。
- 王林同样不知星雾为何物，但凝骨时**融入星雾**，隐隐生出奇异之感，说不出缘由（伏笔）。

## 三、肉劫降临与血晶应对
- 骨头恢复刹那，血筋出现、血肉迅速长出，但刚长出便崩溃——**一损二劫中的「肉劫」**无声降临，目的是阻止血肉生长、磨散生机。
- 王林早有准备：分身抹去嘴角鲜血，虚空一抓开启储物裂缝，取出**拳头大小的血晶**（自古神之地所得）。此前已用掉一部分保本尊在一损中留存生机，余下正为此刻所备。
- 血晶融入本尊骨头，侵入骨中；本尊吸收**古神心血**后血线遍布骨上，血肉顺血线吸收星雾与天地元力而生长。

## 四、凶兽狂潮
- 血晶气味传出，莫罗大陆外原本后退的凶兽尽数停止、咆哮、兽眼疯狂，视血晶为天大补品，不惜一切调头直奔莫罗大陆。
- 来袭者中有**五阶、六阶乃至七阶凶兽**，铺天盖地。归元宗修士被震撼惊醒。

## 五、本尊分身融合，出土屠兽
- 咔咔声中，本尊三百余丈的身躯迅速缩小至常人大小；**分身向前一冲，与本尊再次融合**。
- 王林破土冲出，一拳轰爆八爪鱼状凶兽——身体化血雾、灵魂碎裂，一股**无形之气（生机）**融入其体内，正是他此刻最需之物。
- 生机入体后本尊血肉生长加快，王林身化残影连续出手，一拳轰碎巨蟒，天空降下血雨。
- 短时间内**百头凶兽死亡**，凶兽欲吞血晶而不得，反被逐一击溃。

## 六、一腿灭八阶剑狮兽
- 天边星雾内出现一头**近二百丈、全身长满利刺的狮形凶兽——八阶剑狮兽**，其余凶兽自动散开，不敢临近。
- 王林如流星冲天，速逾奔雷，临近瞬间**右腿一抽**，凶兽骤停后轰然爆开化作漫天血雨，庞大生机融入王林体内，其立于天空如同天神。
- 战后凶兽眼中贪婪化为恐惧；四周骤然安静。

## 七、旁观者反应
- 李向东呆望全场，其身边两名老者倒吸凉气：「师叔祖……那可是六阶凶兽，竟在师叔祖一拳神通下直接灭亡。」
- 见八阶剑狮兽被秒杀后，李向东脑中一片空白，二老愣怔原地。
- 吕烟菲因早有心理准备而稍好，但见八阶凶兽时仍紧张。

- 依【世界状态须知】：王林自第1063章起以归元宗故人「吕子浩」之名（由吕烟菲奉上）立足云海星域，本章归元宗修士口中的「师叔祖」即王林。
- 本章分身与本尊已融合，融合后的行动归王林本人。
