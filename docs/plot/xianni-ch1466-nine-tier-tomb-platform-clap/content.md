# 第1466章 拍手一次

## 一、王林抢先炼成九阶墓台

- **自制符文**：王林盘膝不动，双手不断将古妖、古魔气息融入，于眉心化作印记抹下——即当场自行制作符文。他不惧被人看破，因为「除了拓森也没人可以做到」。
- **三族之力合一**：待九天魔尊与粉衣女子逼近至数百丈内，王林右手一挥祭出**魔魂瓶**，其内轰然爆发大量古魔魂；同时眉心**古神星点**急速旋转，磅礴古神之力宣泄而出。古神、古魔与漩涡内本就弥漫的古妖气息三者融为一体，化作可成符文的奇异力量，急速收缩包裹王林全身，令其全身各处瞬间浮现无数符文。
- **墓台升阶**：王林身子一抖震开全身符文，双手外挥令先前所制符文尽数闪烁而出，同时跃身甩袖祭出**八千丈墓台**。墓台吸尽所有符文后剧烈震动、金光万丈横扫八方，随即由八千二百丈、八千四百丈一路膨胀至**九千丈——九阶墓台**。升阶后其上金光骤然消散，变得没有任何颜色，颤抖更为剧烈。王林第一时间一步迈上台去。

## 二、抢夺者的反应

| 人物 | 反应 |
|---|---|
| 九天魔尊 | 见王林自制符文瞳孔一缩，仍疾行；见九阶墓台后不顾一切冲去 |
| 粉衣女子（八妃之一） | 一愣即明白一切，摇头急急临近 |
| 大荒上人 | 后至，一步迈入漩涡，眼露贪婪疾驰 |
| 白衣女子 | 收起墓台走进漩涡，见状沉默后退，似退出抢夺 |

> 注：漩涡越向内越艰难，古妖气息呼啸使一切神通受影响，但二人修为高深仍疾驰七百余丈。

## 三、古墓巨手横扫——「拍手一次」

- **两只手臂**：一只自**第九张地图**雾海伸出，一只自**第一张地图**伸出，每只**数万丈粗**，如巨人张开双手在头顶自外向内并拢拍掌。
- **速度**：第一张地图那只比第九张地图的快出十倍不止，「如同一座齐天之山，以一种堪比第三步空玄大能的速度」横扫。
- **战果（沿途）**：
  - 拓森在第九张地图险险闪过，仍被气浪扫中倒卷喷血，罕见地目露骇然。
  - 第一张地图数十名修士连人带墓台无一存活，惨叫尽被轰鸣掩盖。
  - 手臂转眼横扫第二至第七张地图，轨迹内修士（含已达**四阶墓台**者）全部崩溃而亡，「如同末曰」。
- **抵达第八张地图**：两臂几乎在九阶墓台出现的刹那同时抵达，一触古妖漩涡，漩涡即刻崩溃、毫无抵抗之力。

## 四、四人受创结局

- **大荒上人**：位置最后、距手臂最近，无法闪躲，肉身当场被拍作肉泥——「就算是**妙音分身**的、**第三步**的肉身，在这手掌下也是不堪一击」；分魂飞出欲逃，被拍击余波气浪吹得烟消云散。
- **九天魔尊**：面色瞬息苍白，容颜自「青年与老者之间变化」凝固于老者，双手掐诀硬撼手臂；连喷两口血，形貌由老者→中年→少年；同时古墓内其道术神通所化的诸多分身一一崩溃死亡，以死换来一线生机。少年之身诡异消散，手臂挥过后原地重现，溢血远遁，眼露惊骇。
- **粉衣女子**：掐诀喷出粉色雾气，抓住其中一条**黑色丝带**绕身而卷，向旁避开千丈，仍被手指碰到，喷血受伤后退。
- **白衣女子**：因提前后退距离最远，身子一晃避开手臂，仅被气浪扫中喷出一口血，向后急抛。

## 五、古妖苏醒

自第九张地图而来的手臂扫过漩涡深处**混沌气旋**，直接**碾碎其上封印**。沉睡古妖猛然睁眼——**其左目内赫然有八个半星点旋转**，「他，醒了」。古妖仰天尖啸，身子立刻模糊透明，令手臂径直穿体而过，直奔九阶墓台。

## 六、虚无被撕开：裂缝中的奇异世界

两只手臂同时落在这第一个九阶墓台上，墓台层层崩溃化作无数碎石；手臂穿透一切，在**王林体外拍合**，轰鸣回荡后缓缓分开向外拉扯——如同这片虚无只是一张纸，被两只手掌**生生撕开一道巨大裂缝**，裂缝内是**一片奇异世界**。

王林面色苍白，但在那手掌下**没有受到丝毫损伤**，唯心神震动不已。

## 七、要点与悬念

1. 九阶墓台的出现直接触发了古墓的清场机制（「九阶墓台出现之后，来自这古墓的末曰」）。
2. 王林是古墓中第一个炼成九阶墓台者，且巨手对他本人无伤——因由存疑。
3. 古妖苏醒（左目八个半星点）与裂缝后的奇异世界，均为后续伏笔。
4. 王林的符文制作之法与拓森同源，为二人关系的又一佐证。
