# 第1755章 紫霞

## 一、来者身份

- 漩涡消散后现身者为**召河紫霞**，紫色长裙、青丝飘舞的美貌女子，即**七彩仙尊第七妃**。
- 与其余仙妃不同，她对七彩仙尊**极为忠诚**；当年曾喝斥王林，并在察觉与王林思绪不一致后起过杀心，只因忌惮**李广弓**而未出手。
- 性格：**心机深、极为谨慎，轻易不冒险**。

## 二、双方实力对比（本章当时）

- 当年：王林未感悟出禁制本源前与其交手**颇为艰难**，全靠李广弓形成威慑。
- 如今：王林已有**禁制本源**、**道吉传承**远强于当年、更有**烨寞右手**，再配合此地（残界）规则出其不意，**不施展李广弓也有杀此妃之力**。
- 情报动机：青霖前辈曾说，**避天棺**是紫霞当年之物；王林判断她身为仙妃必知此地隐秘。

## 三、残界规则（关键设定）

- 三百残界中，**只要不迈出那一步，规则便不作用其身**；一旦迈出，则**完全融入此界、被规则笼罩**。
- 紫霞知晓此规则甚于其他仙妃，故已去过十多处残界，**均进入后一动不动**，只以神识扫过后引人前来。
- 王林同样明白此规则——这正是本章杀局的基础。

## 四、交锋经过

1. **血剑虚攻**：王林挥手放出血剑，一反常态发出惊天呼啸、尖锐刺耳，破空万里直奔紫霞。
2. **紫凤格挡**：紫霞不退，抬手化出紫色云雾，凝成**紫色凤凰**迎击。二者相撞，星空震动崩溃，撕开大片裂缝。紫凤崩溃，血剑亦倒卷。
3. **欲传信引援**：紫霞身后漩涡再现，取出**传信玉简**准备先行退入漩涡（以漩涡阻碍王林**定身术**）再传信引人。
4. **佯退设饵**：王林现身讥其“不愧是七彩仙尊最宠爱的第七妃”，随即言“你既要离开，王某不送”，转身离去，背影**故意显出一瞬仓促**再迅速掩藏，收回血剑。
5. **紫霞试探**：她怀疑王林先前与人厮杀受伤、只以飞剑攻击且以声势吓人，遂放出一把带**空玄修为**的紫色飞剑试探。
6. **反向中计**：王林临机放弃示弱，体内修为轰然爆发，**除第七道禁制外的其余六道本源齐出环绕周身**，一指点碎紫剑，身形一晃却未退半步，气势如虹后冷笑转身。紫霞据此断定他“正因真受伤才刻意掩饰”，并见其身周隐现离界漩涡，更加确信。
7. **贪功入局**：紫霞判断杀王林、夺**第三魂**献给七彩道人或战老鬼，是大功一件、日后可在**仙罡大陆**得庇护，遂**收起玉简、放弃传信与撤离**，一步迈出漩涡（漩涡随之消散）。
8. **规则发动 + 斩杀**：迈出刹那她身子猛然向下坠落，面色大变。王林骤然转身，血光化长虹瞬至，血剑直逼眉心，紫霞连再取玉简都来不及，**胸口喷出一道血箭**，染紫裙呈**黑色**（暗示血非寻常红色）。

## 五、王林的内心判断（未决事项）

- 之前那七道宗弟子欲点香支、此刻紫霞欲捏玉简——说明**进入此地者之间已达成某种协议**（互相通报/召援），此事难办。
- 紫霞若逃走，以其修为王林短时间留不住；此后她警惕更深，再杀更难。
- 玉简传信对象存疑：可能是**七彩仙尊**、**战老鬼**，也可能是与她有联系的**四大战将**。王林已做好在此遇上强敌的准备。
- **李广弓“眼下不是使用的时候”**——刻意保留底牌。

## 六、要点提炼

- 本章是一次典型的**王林式心理诱杀**：以声势代替实攻 → 佯装重伤 → 面对试探反向“过度掩饰” → 逼对手用贪念自行踏入规则陷阱。
- 规则杀而非硬拼，是王林在残界内的核心战法。
