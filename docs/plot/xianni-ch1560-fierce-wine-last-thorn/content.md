# 第1560章 烈酒！

## 场景
- 地点：蛮荒星的一处山谷。
- 人物：王林、清水（清水仙君，王林当年的师兄）。
- 情境：王林为清水逐根拔除封印其身多年的利刺，本章处理第九根与最后（第十）根。

## 一、第九根刺：贯穿脊骨
- 该刺贯穿清水整条脊骨，全部深入其内，不冒出半寸，连伤口都看不到，仿若凭空长于其中。
- 王林诊断：**尚未与脊骨完全融合**，若再过些时日彻底融合便再也取不下；此刺所封「既是肉身，也是元神」，**即便换一具肉身也会如此**。
- 拔刺过程：王林食指刺入第一节脊骨，双指捏住柔软利刺，缓慢外拉，如同抽髓。清水咬牙不出声，双手抓地抓出深坑，将痛苦化作目中仇恨之火。
- 半柱香拽出大半后，依清水一句「一下子拽出」，王林猛地一拽拔尽：黑血喷洒落地呲呲作响，利刺通体黑色，清水喷血，鼓起的脊骨蠕动平复。
- 王林拔刺时**感同身受**，如抽自己骨髓，事后面色苍白，打坐半个时辰方恢复。

## 二、烈酒与师兄弟之情
- 清水挥手活动久禁之身，向王林讨酒；王林虚空一抓，**储物裂缝**中飞出酒壶。
- 二人轮饮辛辣烈酒，目光对视后同时大笑——这种爽朗豪迈的笑，二人都极少有。
- 清水评价王林：「你长大了」——不再是当年需要自己挡风雨的小小修士，已是**足以撼动星空的一代强者**。
- 清水自陈：此刺取出后可恢复修为，且**杀戮本源**更精进不少；提到「杀戮本源」时神色闪过一丝悲哀，随即深藏。

## 三、最后一根刺：藏于全身血管
- 位置：遍布清水全身血管之内，**是最长的一根**，当年自胸口心脏处进入。
- 清水自行一指剖开胸口，血肉分离露出青色血管，并生生将血管拽出伤口外。
- 王林挥手斩断血管，以印诀凝固一端，双指探入另一端捏住利刺外拽——拽出的是**紫色利刺**，柔软如蛇，仍在扭动，一度被拽出七尺之长。
- 清水面色发青、双唇颤抖、低吼不止，剧痛中**捏碎酒壶**。

## 四、炎龙血·烈酒
- 清水索要烈酒，王林左手虚空一抓取出**青色酒壶**，内装的并非酒，而是**老朱雀送予的炎龙血**。
- 清水饮后大笑：「一股腥臊，但也甘甜，这哪里是酒，这分明是血，但这血酒，够烈」，命王林把利刺全部拽出。

## 五、破封：杀戮本源轰杀利刺
- 拽动中清水体内**被凝固的修为出现松动**，煞气滔天而起，天空化作滚滚黑云，杀戮气息浓郁至极，**黑色的雪**自云中落下。
- 清水命王林休息，自行起身，左手一拽将紫色利刺**一拽成两半**；断截欲缩回血管隐藏。
- 清水寒声：「封印了本仙君这些年，今日，你给本君出来」「你既然不想出来，那便死在本君体内好了」——**双指成剑**按在胸口血管，杀戮本源与天降黑雪疯狂冲入体内，将活物般的利刺当场轰杀。

## 六、结果与转折
- 清水喷出大片黑血，干瘦身体膨胀、重生血肉，**恢复到当年的样子**。
- 其体内杀戮本源惊天爆发，天地一片漆黑，黑雪弥漫。
- **天空尽头出现一面虚幻的大门——「空之大门」**（章末悬念）。

## 关键伏笔
- 十根利刺封的是肉身+元神，换体无用 → 解释清水多年不能自解。
- 「杀戮本源」既是清水实力根基，也牵着他一闪而过的悲哀，来历未明。
- 炎龙血出自老朱雀所赠，此处被当作「烈酒」饮下。
- 空之大门随清水破封与杀戮本源爆发而现，为后文引子。
