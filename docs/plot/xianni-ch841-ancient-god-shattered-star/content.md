# 第841章 古神碎星

> 卷次：第七卷 名震罗天｜章节：第841章（世界状态须知截至第785章，本片段章节号更高）

## 一、罗天七强围攻望月

罗天星域内几乎站在巅峰的七人，与望月展开一场战争。望月从弯曲沉睡状态苏醒，形成战斗形态，万丈触手摇曳，**双目中第一次露出警惕之色**。

### 望月的远古记忆
- 它神智不同于人，却察觉到极强烈的危机感——这种感觉已很久很久未曾体会。
- 模糊记得不知多少岁月之前，飘行中似有一个**声音**警告它不要踏足某处地域，那声音中有难以想象的力量令它恐惧。
- 记忆虽悠久模糊，危机感却被牢记，至今影响其思维。眼下危机感虽弱于当年，仍使它必须发挥真正实力。
- 望月口中咆哮如大地开辟之时的太古声音，超越一切雷鸣，可击碎星空；此声在此前两次怒火中从未出现（面对弱小生命无需如此）。声中蕴含仿若人语的复杂之音，化作一处处使星空崩溃的神通向外扩散。

### 战场背景
为这一次行动，**雷仙殿在数月时间内已将整个罗天北域清空、全部占据**，目的就是一举拿下望月。

## 二、望月的反击：古神之语与古神一指

1. 望月剧痛几近发狂——记忆中除当年那个声音外，再无生灵能令它这般巨痛。
2. 张口喷出无数**小型望月**：其中八条万丈之物，其余千丈、百丈不等。
3. 母体与全部子体**同时发出古神之语**，每条望月前方亮起无数从虚无幻化的晶光，凝聚成**「古神一指」**，弥漫大地星空，以望月为中心向四周冲击，六人为之色变。此为望月极为强大的神通之一。
4. 望月身子疯狂收缩，仿佛抽尽体内生机；全身无数触须自根部断裂脱落，扭曲间冒出细微须发，转眼各自化作**一头头万丈望月**。
5. 除融入望月体内的血神子看不到外，其余六人心神剧震，连炎雷子也瞳孔骤缩、面露骇然：「这是什么月兽，古籍内根本就没有记录过月兽有如此神通」。

## 三、狭长之处：古神幼子被吞噬

- 望月施展此神通之时，正是王林所在狭长之处全部凡人与修士被吸尽生机崩溃的刹那；触手吸收完毕后迅速消失，此处触手大范围减少。
- 王林前方缠绕古神幼子的上百条触手，速度恐怖，**已非吸收而是吞噬**：每条触手涌现大量鼓包疯狂吞噬古神之力，并分化无数须发钻入古神幼子体内再次吞噬。
- 王林寒光一闪判断：**「这古神幼子，便是望月的生命之源」**，右手掐诀正欲出手。

### 古神的最后传音
那沧桑声音再度回荡王林元神，比之前更虚弱、仿佛随时消散：
- 「莫要出手，我与望月已成一体，你若出手，立刻便会被望月攻击」
- 「我的族人，速速离去，把可以承受我传承者带来，我的时间，不多了」
- 「以你之力，无法从这里出去，我送你一程」

## 四、古神碎星

- 古神幼子猛然睁眼，眉心旋转的**八个模糊星点崩溃其一**——是为**「古神碎星」**。
- 崩溃化作庞大不可思议的冲击风暴，自王林身边穿过，直奔狭长之处入口的漩涡。
- 血神子在望月体内破坏时寻到此处，身影刚在漩涡中凝聚，即被古神之力风暴轰中，整个身子崩溃。
- 一股妖异之力弥漫，在其身前化作**与其本命相连的妖异之物**代为阻挡；此物眼露震惊，刚成型便崩溃，连同血光被向后轰出、逼退漩涡外。
- 血神子重新凝聚身影：面色极为苍白，连续喷血，迅速萎靡，**元神重创**；若非妖异之物阻挡，必死无疑。
- 血神子眼中骇然、恐惧与不可置信，与身后重新幻化的妖异之物虚影**同时喊出「古神」**，连目光都一模一样。

## 六、要点与悬念

- 望月的真实层级远超「月兽」古籍记载，其生命之源疑为被其吞噬同化的古神（幼子形态）。
- 古神与望月「已成一体」，古神自损一星送王林离开，并托付「带可承受传承者前来」，为后续传承线埋伏。
- 血神子受古神一击即元神重创，反衬古神残力之强；其本命妖异之物为新披露的底牌。
- 雷仙殿清空罗天北域，为围猎望月的势力级布局。
