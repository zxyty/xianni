# 第十卷 叱咤界内 第1519章 反击！！（第四更）

## 一、破口：界外洪水涌入
- 封界大阵被打开缺口，界外九万修士双目透出滔天凶残，高呼「杀入界内」「杀入封界，抢夺一切」。
- 东迪子率先迈步冲入裂缝，南诏上人舔唇跟进，火雀族老祖杀机一闪急急前行。
- 大阵如堤坝裂口，界外之修如洪水滔天；转眼数万修士冲入界内，望见一身白衣、冷冷远观的王林。

## 二、王林的按兵不动
- 封界大阵的崩溃让王林隐隐觉得不对——似有东西被隐藏。他未立刻出手，只冷冷盯着如蝗虫般涌入者，**等一个猜测**。

## 三、封界之尊的后手：玉佩与开天斧
- 被撕裂的阵法上浮现一枚玉佩，其气息只属于一个人——**封界之尊**。
- 玉佩现世刹那，一把**开天之斧**轰轰幻化，出现时机恰是九万界外修士冲入一半之时。
- 第一斩：势如破竹，前方修士无法闪躲、无人能挡半点时间，肉身崩溃、血肉爆开、元神死亡，**约五千修士一斩而亡**。
- 东迪子、火雀族老祖、南诏上人三人面色大变，齐出阻斧，并喝令后续「加快冲入界内的速度」。
- 界外庞大黑色阁楼大门骤开，走出一名**身子干瘦如骷髅的老者**，临近开天斧欲阻，被玉佩所化柔和之光笼罩，脑中轰然：「封界老鬼你竟把自己融入阵法内！」
- 王林由此印证猜测：当年封界之尊融入阵法内，**或许为的就是这一刻**。
- 第二斩：开天斧再度落下横扫，**又近五千修士**被绞碎肉身凄厉而亡。
- 干瘦老者被玉佩之光困住，与封界之尊神识展开疯狂对抗，一时分不出力量。

## 四、王林独战数万：多重神通齐发
1. **千万剑气**：右手向前一挥，星空轰轰，剑气呼啸而去。
2. **禁制烙印**：无数禁制烙印紧随剑气之后。
3. **虚火·焚**：左眼九色火焰风暴放出虚火弥漫；每个界外修士体内浓浓情绪皆是虚火燃烧之引，近千人全身燃成火球。
4. **雷图天劫**：右目雷图飞出悬于星空，不断扩张化作无尽，四周九道伴随之雷咆哮旋转，无尽雷霆疯狂落下。
5. **血剑**：自星空隐藏中冲出，横扫间千颗燃烧的头颅飞起，一击杀千人。
- 王林「如一头守护家园的猛虎」直接冲出，杀红了眼，双指如剑一点即令修士肉身爆开。
- 代价与凭仗：无尽法宝、神通轰击其身，**光影盾片刻即轰然崩溃**；全赖**古神肉身**强悍，身上诸多伤痕急速愈合。
- 界外修士的杀戮反被激发凶性，燃烧者自知必死纷纷**自爆**，毁灭冲击扩散——王林若非古神肉身也必须退避。
- 悬赏喊话：「他就是王林，杀了他，可入**太古星辰榜**！」

## 五、其余战场
- **灵动上人 / 周瑾**：在王林神念下不得不出手，直奔阻斧的东迪子三人。周瑾眼中复杂却毫不犹豫，灵动一脸麻木，东迪子斥其「莫非要做叛徒不成」亦不能动其情绪。东迪子修为高深，一人战二人游刃有余，还能分力阻斧。
- **云落大司**：踏入阵法，一眼看到王林，眼中恐惧，玉手一指尖声下令「杀了王林」。
- **增援（界外）**：太古星辰内十多个族落接到**长尊会**封命，早已整顿完毕，经**掌尊会**传送阵出现在缺口外，计**八万修士**，其中有**两名第三步大能**，直奔缺口。

## 六、险境与转机
- 火雀族老祖眉心火雀族印一放，万丈**黑色火鸟**带一丝虚火之力扑向王林，蕴无尽香火与炙热，星空似被烘烤。
- **南诏上人**修为已至**空灵境**，身负与大荒齐名的毒攻——仅此一人便足以杀王林。其右手瞬间转黑蕴含剧毒，一步跨越一切距离，穿透火鸟直拍王林。
- 王林瞳孔收缩、抬右手急急后退之际——远处云海星空天地扭曲，**红杉子、南云子**神色凝重透出杀机迅速来临，身后星空传来数万修士齐呼：「**云海荣耀！**」轰轰而来。

## 七、要点判读
- 天平因封界之尊的存在向界内倾斜，但战争毫无结束迹象：界外首波九万＋后续八万（含两名第三步大能）持续压上。
- 本章战局峰值出现在开局：开天斧两斩约万人，为界内争得关键时间。
