# 仙逆 第582章（之1/2·再分2/3）王林出列

## 一、废熬迪：胜负只在电光火石间
- 王林松手，熬迪摔落在地掀起尘土，**气若游丝但尚未死亡**。
- 伤势判定：**全身经脉寸断、全身骨头寸断**，已然成为废人。
- 挽回之法：除非妖帝赐下**天妖丹**。但天妖丹极为珍贵，连**妖帅**欲得一粒也需无数战功，区区妖将熬迪不可能获得——等于宣判其修行生涯终结。
- 众人心理：若是激战之后败落尚可接受，但此战电光火石间便定胜负；且**历来妖将之战中妖将被打得如此之惨极少**，**被外来者所致更是第一次**，直接击碎了在场妖灵地之人的骄傲。

## 二、金色长枪与两掌推衍（本章战力关键）
1. 王林转身，右手掐诀，**一道道生之烙印**瞬间在右手凝聚。
2. 同一瞬间，**金甲男子**的**金色长枪**呼啸而来，其威『好似开天辟地』，飞出刹那即将王林**锁住**。
3. 王林眼露果断，**目中隐有推衍禁制时的光芒**，右手在枪上一拍→枪身嗡鸣；紧接**第二拍**，**两次所触位置均不相同**；身形一闪，长枪擦身而过。
4. 事后王林收手冷视金甲男子，平缓道：“大人这是何意，莫非要坏了规则不成”——神色如常，内心却警惕此枪威力很强。
5. 金甲男子深深看王林一眼，右手虚空一捏，长枪一颤，**化作阵阵阳光消失**。

| **陈涛**（立于石萧身边） | 怔怔而望，感到当年的师弟已强大得有些可怕 |

## 四、陈涛的判断：真正可怕的不是废人，而是那两掌
- 陈涛清楚那金色长枪的来历：**实实在在的太阳之光**。
- 他早年听**天运子**说过：世间有一种神通可**抽取太阳之光凝聚成力量，并把力量化作液体**，天运子对此赞叹不已；金甲男子修为**尚未到『化光为液』**那一步。
- 自我对比：陈涛自问也能把金枪**拍开少许**，但像王林这样**连拍两下彻底改变其方向**，很难。
- 关键结论：**这不是修为的问题，也不是仙力的问题，而是一种计算、一种推衍。**
- 实力重估：“若以他此刻的状态与我再次争夺**天运七子**的封号，我即便是胜，也会**重伤闭关百年**，甚至很有可能**修为跌落**。”看向王林的目光充满复杂。

## 五、伏笔与看点
- **七妖之术**（戒指黑发男子）被点名，为后续妖将战埋伏笔。
- **天妖丹**设定首度点明其稀缺度（妖帅级战功兑换）。
- 王林的**推衍**能力被明确定位为超越修为层面的胜负手，呼应其一贯『推衍禁制』之长。
- **莫厉海**被视为王林出场的所属/背景一方（『莫厉海居然还有这等后备之招』）。
- 陈涛与王林的旧日同门（师兄弟）关系与**天运七子**封号之争被再次提起。

# 妖将之战余波：判胜、剑灵与许立国

## 一、广场判定：王林此轮获胜

- **莫厉海的心思**：众人中最高兴者为莫厉海，庆幸自己当初与王林结交的决定“英明神武”——“我与此人有这一层关系，日后也不会成为敌人，这王林越强，我获胜的机会便越大”。同时腹诽金总管以大欺小，暗誓若有朝一日成为正帅，定要让此人好看。
- **金甲男子(金总管)的裁决**：一声冷哼如霹雳奔雷回荡广场，将众人目光重新聚拢。他右手一指王林喝道：“你可知晓，杀妖将者，斩此次妖将熬迪未死，便饶你一次”，并喝令**熬迪的帮助者出列**。
- **无人应战**：两旁人群安静少顷，其内传出一个弱弱的声音——“我弃权”。
- **结果**：金甲男子目光阴森，判“此轮，你胜，退下”。
- **威慑成型**：王林一言不发走向妖将之中，数个站其前方的妖将**下意识后退**，散开一条道路。
- **莫厉海的情报**：轻声告诉王林——“那金总管，只不过是个**阉人**，妖帝陛下若对你欣赏，这金总管，又算得了什么。”王林微微一笑未答。

## 二、燕京剑阁：帝剑的暴怒与剑灵化形

- **位置**：燕京宫殿深处的剑阁，其内有阵法，**帝剑**插在地面上，剑体嗡呜。
- **感应**：王林出手的一瞬间，同在燕京的帝剑立刻感应到那“让他愤愤的存在”，愤怒飞出地面，欲将此人像被它损坏了无数次的**洪牢**那样大卸八块。
- **禁令**：**帝君**曾言，让帝剑安静数日、妖将之战过程中不要外出，否则送去**龙潭**。帝剑因此在半空犹豫、剑鸣不甘，剑尖愤愤指向天妖门方向，挣扎良久。
- **化形泄愤**：帝剑一晃化作**双十年华的少女**——通体晶莹、相貌极为秀美。她落地双脚乱踢，每踢一下都有剑芒闪出，轰隆隆中剑阁内被毁坏多处，恶气方缓。
- **钻空子的逻辑**：“帝君不让**帝剑**外出，我是**剑灵**，出去应该没事……我不出手，只是去看看那个可恶的**食物**，记住他的气息，这样以后找起来也方便。”
- **潜入天妖门**：临近万丈广场时身化虚无，轻飘飘落于广场前方宫殿瓦片上向下望。

## 三、八妖帅的注视

- 剑灵少女现身宫殿的瞬间，广场之中立刻有**八道目光**看似随意飘来——来自南北两侧的**八个妖帅**。
- 八道目光一扫即收，其中数人嘴角露出微笑；少女身子一颤、吐了吐舌头。

## 四、许立国：剑灵感知与“老许的春天”

- **关系基础**：许立国是王林**炼化的魔头**，寄身**仙剑**之内，与王林**心神相连**。
- **异动**：许立国不老实待在仙剑里，以极为激动的语气在王林心神中吼：“主人让我出来，我老许的春天来了，你快让我出来。”
- **缘由**：他此前未把帝剑当回事，今日一看，帝剑的剑灵竟是“水灵灵、娇滴滴的小美人”。王林身子一震，打断其话追问“在这里？”
- **感知机制**：“在那宫殿上面，主人，你看不到她的，只有我能看到。”许立国得意后又想起王林**煞星**的名头，内心一哆嗦，忙补充：这与**修为无关**，是跟**小黑刀**学过一个**剑灵技巧**——像他们这样的**高阶剑灵**，即便身在**储物袋**内，也可以感受到四周同伴的存在，**但必须对方离开剑体之后才可以**。

## 五、要点提炼

1. 王林在妖将之战中已实质立威：金总管被迫判胜，同侪妖将主动避让。
2. 敌意伏笔：金总管(阉人、总管身份)公开针对王林；帝剑视王林为“食物”，只因帝君禁令暂缓动手，并已专程记下其气息。
3. 势力观察：八位妖帅对剑灵少女的出现心知肚明却默许，透露妖帝势力内部对帝剑的态度。
4. 设定补充：高阶剑灵之间存在“离体后可互相感知”的机制，来源为“小黑刀”所传剑灵技巧。

> 归属说明：本片段中「王林」即王林本人(乳名铁柱)，无化名情形。

# 第585、586、587章 许立国叛变计划失败（三合一）

## 一、许立国调戏剑灵少女

- **出场**：王林右手拍储物袋开一道缝隙，许立国飞出，如无形烟丝般直奔天妖门宫殿上方。全场无人察觉——因剑灵小黑有掩盖一切剑灵气息的绝招。
- **动机**：许立国自陈自当年那位「大美人」被煞星（王林）祸害后，再未开过荤，此番认定剑灵少女是「天赐姻缘」，坚决不放手。
- **交手**：
  - 少女一脚踢出无形剑气，许立国身子一散被剑气穿透，瞬间复原，再度扑上。
  - 少女无暇再寻「食物」，掉头飞走，许立国淫笑追赶，二剑灵消失于宫殿之上。
  - 少女怒斥「你主人也不是什么好东西，滚」，许立国以「她辱骂主人」为由唤小黑出手。
  - **战力对比**：单论剑灵本身，许立国不敌少女；有小黑相助后势均力敌，谁也奈何不了谁。许立国此时处于亢奋状态，超长发挥。
- **结局**：少女直接退回剑体，许立国怒吼「无耻！你居然回到剑体内，你等着，我许立国会再来的」。剑阁内蛇形帝剑愤怒四处破坏，几次想冲出斩了这无耻之徒，最终忍住，评价其「比那个食物还可恨」。
- **后续**：剑灵少女自此再未出来。

## 二、妖将之战第一天收尾

- 王林之后又进行六场比试，胜出三人；其中两场因妖将无帮助者，一战定输赢。
- 许立国很早便回到王林储物袋内。
- 夜幕降临，众妖将从天妖门走出各回居所。
- **赛制**：第一轮需七至十日结束，获胜者不必再来 → 王林获得短暂休息。
- 王林不愿每日观看妖将厮杀，索性不去，每日仍在河道旁闻琴饮酒。

## 三、莫厉海的押注

- 心境不及王林，每日必去燕京观战。
- 把认为对王林有威胁者的比赛，以**神通之术印下**，夜晚回来送给王林。
- 心态：全部希望已压在王林身上。

## 四、王林的悟道：问鼎那一步

### 云与琴的顿悟

> 「世人常把云比喻为虚无缥缈之物，这云如那琴音一样，并非虚无，而是人心缥缈。若心不缥，则云定；若心无痕，则琴消。」

王林听琴已有时日，始终以**过客心态**品琴音内的五味，借此触摸自己的道。

### 问鼎意境的阶序（重要设定）

| 境界 | 意境要求 |
|---|---|
| 元婴 | 以**感悟意境**化神 |
| 化神 | 以**意境实质**婴变 |
| 婴变 | 方可**意境融体** |
| 问鼎 | 以上皆不够，尚差一步 |

- 王林现状：早已意境入体；**道心已在婉儿（李慕婉）沉睡的一刻圆满**。
- 悬念：仍差一步，不知是什么。
- 王林的道论：每人感悟的意境不同，从而分出不同的道；**无法问询他人之道，即便知晓也无好处、反成羁绊；道之一途只能独自修行、独自感悟**。

## 五、许立国的僭越与王林起杀机

### 冲突起因

- 许立国自见剑灵少女后整日纠缠王林放他出去。前几日王林关闭与之的心神联系，清净数日，**许立国竟自行冲开封锁**再度叫喊。
- 出言指责：「王林，你当年把我和大美人拆散，现在又要强行拆散我和小美人……你一定是嫉妒我许立国有这些艳遇。」
- 进一步冒犯：提及大美人被王林抓走后，「成为了你与柳眉那小贱人歼情的道具」。

### 王林的判断（关键人物分析）

1. **忠心的前提是压制**：许立国虽忠心，但前提是王林比他强大很多倍；即便换新主人，新主人也不能强于王林太多，否则忠心立刻消失。
2. **前例**：当年的巨魔族老祖即是例子。若换成**天运子、凌天候、血祖**之流，许立国会在被抓的第一时间阿谀地把王林连头带脚全部卖掉。
3. **第二毛病**：一遇女性便立刻变了个人，多年磨练未改。
4. **反常推断**：许立国天生胆小，若无足够本钱断不敢如此说话 → **从朱雀星离开的这段日子里，许立国隐瞒了不少事情**（暗中学了神通，底气渐足）。

### 收束动作

- 王林平淡道「说够了么」，眼中寒芒渐浓；许立国隐约感到刺激到了煞星，但仗着新学神通底气又足。
- 王林右手一拍储物袋，**仙剑飞出**，许立国欢呼一声，瞬间从仙剑内幻化而出，化作浓浓黑气/黑雾的人形，正要直奔燕京。
- 此刻王林**眼中寒芒大浓，右手虚空一抓，仙剑顿时在手**——片段止于此，标题已点明「许立国叛变计划失败」。

## 六、伏笔与看点

- 许立国的「本钱」来源未明，是其叛变底气所在，也是本章标题所指之事的引线。
- 剑灵小黑的「掩盖一切剑灵气息」是可复用的隐匿手段。
- 蛇形帝剑口中的「食物」暗示其与某人（疑为王林）此前的敌对。
- 王林距问鼎的「最后一步」为长线悬念。
