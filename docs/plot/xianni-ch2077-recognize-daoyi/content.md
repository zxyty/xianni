# 第2077章 认识道一！

## 一、场景与前情
洞府界仙界，王林与破阵而入的赤魂子对峙。赤魂子来自仙罡大陆，破开仙界阵法意在吞噬仙界修士、吸取精血以突破修为。在场旁观者有许立国、刘金彪、南云子、蓝梦道尊及仙界诸多修士。

## 二、仙罡大陆等级体系（赤魂子视角）
- 修真等级远超洞府界：**金尊 → 天尊 → 跃天尊 → 九位大天尊**。
- 金尊为一方巅峰霸主，在大宗门中属「大长老」层次，可决定宗门的终极力量。
- 金尊凶兽比金尊修士更为稀少。
- 赤魂子毕生梦想即成为金尊修士。

## 三、金尊海龙现身
刘金彪肩上一条拇指粗细的小蛇骤然膨胀为万丈海龙，威压震动整个仙界，众修士心神颤抖甚至生出膜拜之感。海龙低吼一声即令赤魂子元神不稳、几近崩溃，坐实其金尊层次。

## 四、赤魂子的误判与求饶
### 误判链条
1. 海龙自刘金彪肩上飞出，非王林身边；
2. 王林毫无威压、修为波动稀少，虽有宝物掩气息，但在仙罡大陆「只有弱者才这么做」；
3. 故断定王林修为不高，是邀请刘金彪同行护道；
4. 刘金彪修为亦不高却得赐金尊海龙，必是某位天尊的嫡系弟子。

### 三段式求生
- **划清界限**：对刘金彪称「此事是我与王林的私事」，请其勿参与，事后重谢。
- **贿赂**：愿献出被封印前藏于**东洲**的一生积蓄（无数年搜集之物）。
- **威胁 + 招揽**：自称师叔**旬山青**为道一大天尊麾下天尊；若海龙杀他，师叔必知，不信对方师尊愿与同阶天尊交恶；且道一大天尊极为护短，代价「整个洞府界都要灭亡」。另许诺求师叔收王林入门，可在仙罡大陆一步登天。并发誓离开洞府界、再不打仙界主意。

刘金彪一愣，下意识看向王林——此反应反令赤魂子略觉笃定。许立国失笑，刘金彪似笑非笑摇头。

## 五、王林的回应
- 认可事实：「仙罡大陆原本有九个大天尊，其中这道一，为最弱的一个」「即便是最弱的大天尊，也拥有主宰众生的力量」。
- 话锋一转：「**就算是道一亲自来此，看到王某，也要立刻退避，甚至他恐怕都不敢来见王某**。」
- 赤魂子讥讽其疯癫、敢不敢当面去说；王林答「不用那么麻烦」。
- 王林并未急于出手——因赤魂子敢破仙界阵法，轻易杀之难解其怒。

## 六、隔空提审道一（本章高潮）
王林右手一挥：天地轰鸣，海龙退避，仙界天空浮现巨大漩涡，与星空连接、轰开仙罡法则所在的虚无，似与仙罡大陆连通。

仙罡大陆一侧：道一刚自**苍茫盆地**返回自身宗门（道一宗），脑中反复浮现在盆地海墙风暴外所见之景，内心被恐惧弥漫——他已认定**仙罡大陆第一强者不再是古道，而是王林**。此时道一宗上空风云倒卷，漩涡凭空出现，王林话语如雷霆传出，道一身体无法动弹，神识被奇异之力抽出体外直入漩涡。

漩涡中道一看到陌生大陆与王林，生出「生死一线、被王林一手掌控，若想杀他只是一念」的强烈感觉，苦涩答曰：「**本尊麾下，没有与此人认识的天尊，还请王尊息怒**」，语中透出恭敬与惊恐。

## 七、结果与影响
- 赤魂子清晰感受到漩涡内确属道一大天尊的气息，最后的靠山当场坍塌，呆滞嘶喊「假的、不可能」，濒临发疯。
- 王林被道一以「王尊」相称，其凌驾大天尊之上的地位在洞府界众人面前坐实。
- 蓝梦道尊皱眉不语；南云子神色阴沉，对王林实力的确信「隐隐有了动摇」，随后被现实反转。

## 八、待续/悬念
- 赤魂子的最终处置（王林明言不愿轻易杀之）。
- 东洲所藏积蓄的下落。
- 「旬山青」这一天尊是否真实存在（道一当面否认麾下有识得赤魂子之人）。
