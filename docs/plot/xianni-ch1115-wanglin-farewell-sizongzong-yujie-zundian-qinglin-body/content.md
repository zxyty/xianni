# 仙逆 第1115章（第八卷 联盟隐秘）｜别过四圣宗·雨界崩溃中寻尊殿

## 一、四圣宗人尽去，王林心结
四圣宗众人全部离去后，王林独立平台，下方雨界崩溃轰鸣不绝，而心绪之杂重于此声。

- **救青龙圣皇的动机**：报答朱雀老圣皇恩惠之一；更为四圣宗在将至的乱世中留下一个强者，使其得以延续。
- **朱雀圣宗内部**：除个别长老外，几乎无人真把王林当成圣皇；唯有小辈族人拥戴更诚。若有足够时间或可慢慢改变，但**来自拓森的不安不断逼近**，王林没有时间；再拖只会害了朱雀圣宗、辜负老圣皇之恩。

## 二、青龙圣皇的心机与索器
- 从青龙圣皇**未追杀天运子**那一幕起，王林便明白其心机之深非己可揣摩。
- 其后那番**天道之语**令王林极为震惊。
- 但最令王林在意的是临别之言：**“这个圣器，可以暂时放在你手里，但离开了雨界，你必须要送回四圣宗。”**
  - 王林苦涩自忖：若非四周长老太多、其又刚脱困，太古圣器恐怕当场就被收走。
  - 王林本无占为己有之意，此事本该如此——不做朱雀圣皇，自不该留圣器。
- **真正的芥蒂**：青龙圣皇自始至终**不问一句其余三圣皇当年之事**，反而以极平常的口吻说出三圣皇死亡之语。
  - 朱雀圣皇无数年忍受自身痛苦，一心延续四圣宗；
  - 白虎圣皇当年为四圣宗**生生战死，尸体至今未找到**；
  - 这一切在青龙圣皇眼中仿若平常，毫无知晓的必要。

## 三、旁人之言
- **司徒南**（自称司徒南者，实为断臂所化人影）上前拍肩：“什么鸟四圣宗，等青霖苏醒后，你我叱咤星空，岂不快哉。”王林苦笑点头。
- **王巍**轻叹解释青龙圣皇性情之变：师尊当年曾说，**天道之血为不祥之物，吞下者若有不死，定会性情大变**；他当年与青龙圣皇有一面之缘，记得是个豪爽汉子，今日阴沉，想必正因吞下天道之血。王巍虽急于在雨界崩溃前找到尊殿，却未催促王林。

## 四、三叩雨界之门，与四圣宗恩断
王林长叹：自青龙圣皇那最后一句话说出起，他与四圣宗**再无任何关系**，若说有，只剩心中对朱雀老圣皇的感恩。

他掀起下摆跪地，向**雨界之门**所在重重磕了三个头：
> “老圣皇，恩惠晚辈此生铭记，不敢有半点相忘，日后若朱雀圣宗有难，纵死，晚辈粉身碎骨也会去助一臂之力。”

耳边回荡老圣皇旧语：“若是压力太大，若是四圣宗再无辉煌的可能，若是真的这苍天要灭我四圣宗……那么，你就不要勉强了。”

随行者：王巍、胡娟、司徒南，以及始终静静跟随在王林身旁的**银衣女尸**。胡娟见状关切，王林只以微笑掩饰惆怅，转而道：“前辈，我们去找尊殿吧。”

## 五、雨界崩溃中的搜寻
- 雨界持续崩溃，随处可见坍塌碎片，部分碎片彻底消失、化作庞大漩涡撕扯残石。
- 众人化作数道长虹疾驰，如雷鸣贯空。王巍飞行中以脑中**当年仙界的记忆**印证方位，约一炷香后锁定一处。
- **地标印证**：王林认出此地正是当年**周佚燃烧灵魂与孙泰一战**之处。
- 王巍解释：雨界崩溃化作无数碎片，其中一些**重叠**；按当年雨界尊殿方位，就在这重叠碎片中的一处。
- 王巍右手下按，青色水雾幻化冲下，扫开崩溃碎片，露出下方重叠碎片，众人落于其上。
- 该碎片大陆亦在崩溃：地面颤抖，边缘不断脱落碎石，裂缝渐扩。王巍警告：**若整个雨界全部崩溃，此地将成巨大漩涡，一切被吸入其内**。
- 王巍右脚一踏，方圆百丈大地碎裂，众人下沉穿透一层，抵达第二层碎片（此处崩溃尚缓，但神识扫过未见尊殿）。
- 再踏第三次时，王巍面色骤变，大袖卷起众人急退——地面碎裂却无碎石散开，齐齐向下凹去，转瞬形成**巨大漩涡**。

## 六、雨界尊殿现世
- 漩涡内一片漆黑，却可透视其下虚无：一处碎片大陆彻底崩溃之中，一座**通体青色的大殿**毫无损坏，向虚无深处缓缓飘去。
- 王巍断定即**雨界尊殿**，激动飞出，众人紧随。
- 王林受漩涡庞大吸力，**左目一闪，全身弥漫火海如同火人，一步挣脱漩涡**（较之前已无需王巍相助）。
- 大殿虽不高，但青光环绕、威严逼人，殿门之上一个龙飞凤舞的**“青”字**透出浓浓压迫之力。
- 王巍推开殿门，青光透出染青虚无。殿内空旷，**唯有地面一座散发青光的阵法闪烁不断**。
- **胡娟**研究少顷变色：“我从未见过这种阵法，此阵有**逆魂之效**，可以让人魂魄离体。”
- 王林道：“把仙帝青霖肉身拿出。”王巍虚空一抓，前方裂缝出现，**青霖肉身**缓缓飞出——仍是那一身黑色铠甲，**眉心之上有一个赤红血点**，双目紧闭，没有任何声息。

## 七、要点归纳
1. 王林与四圣宗的因果在本章正式了断，只留对朱雀老圣皇的私恩与誓言。
2. 朱雀太古圣器归属明确：暂在王林手中，出雨界后须归还四圣宗。
3. 青龙圣皇性情阴沉的解释被点出：吞下天道之血。
4. 复活青霖的关键环节到位：雨界尊殿 + 逆魂阵法 + 青霖肉身三者齐聚，赤红血点为其肉身显著标志。
5. 时限压力：雨界全面崩溃在即，尊殿所在将化为吞噬一切的漩涡。
