# 仙逆 第九卷 云海之巅 第1380章 四息！

## 背景：五息之约
虚无中传出的声音给出「五息」之限——五次呼吸时间，比雷霆闪电划过天际略慢。要在五息内结束与司墨子的战斗，龙甲族长老、火雀族老者乃至司墨子本人都认为绝无可能，毕竟对手是司墨子（第三步大能所炼分身）。王林听到此言的刹那双眼爆出滔天精光，全力爆发。

## 第一息：天荒地老 vs 光影盾
- **司墨子出手**：施展「天荒地老」——其在岁月禁中自行感悟而出的神通，与王林的流月之术异曲同工。禁制风暴轰鸣扩散，天空枯黄生脓包破裂流出暗黄浓水，大地龟裂死气堆积褶皱，天地急速衰老并轰然崩溃，岁月禁漩涡卷动崩溃天地化作毁灭之力直轰王林。
- **王林应对**：星空、修真星、万灵一切存在散出光芒凝聚体外，形成**光影盾**迎撞风暴。碰撞使王林身上岁月流转之术数倍暴增。
- **石门**：王林右手一挥，身后浮现蕴含无尽苍凉气息的巨大石门并与其融合，远看如踏石门而立，被岁月笼罩而身不动半丝，唯长发衣衫无风自动。
- **司墨子反制**：光影盾折射之力掀起，司墨子上前一步虚空一按，掌印蕴含其眼下能发挥的**天人第五衰**全部之力，破开光影盾外的岁月禁落于光影之上。
- **三连盾**：光影盾崩溃即再成，一息之内连现三次；第三次崩溃同时把掌印之力与岁月之力折射大半，化作冲击反卷司墨子。

## 第二息—第三息：雷图破岁月
- 「二」字回荡时，王林受冲击喷血，仍仰天长啸前冲。
- 右目雷光闪烁，瞳孔内**雷霆印记**幻化，**九道伴随之雷**旋转，末三道——**极劫之雷、血脉之雷、逆命之雷**——爆发莫大威能，天地银蛇游走、雷霆闪电齐聚，凝成**万丈雷图**。
- 王林双手前推，如当初冲击第三步**空之大门**一般推动雷图攻向司墨子。
- 司墨子一路追击最忌惮的正是此雷霆之术（源于真言族修真星上目睹王林轰击空门一幕），遂掐诀以岁月禁化风暴紧密包裹自身，放言「且看看是你雷霆威强，还是老夫岁月更利」。
- 「三」字响起时王林与雷图融为一体撞入岁月风暴：风暴崩溃倒卷宣泄向司墨子，雷图印在其胸口，司墨子面色苍白、喷血急退，胸口闪电弥漫伤势加重，骇然于「岁月在那雷霆面前，都要崩溃」。
- **代价**：王林被岁月禁横扫，容颜刹那苍老如沧桑老人，下一息体内爆发无尽生机逆转岁月恢复如常，但面色极为苍白——与第三步大能分身一战对他亦极为艰难。

## 第四息：双重爆宝
- 「四」字未落，王林长啸如打断之，速如长虹追上退后的司墨子。
- 祭出**指甲盖大小的金色丹药**，逼近至不足十丈时大吼「爆」，轰鸣如一颗修真星自爆，音浪与毁灭之力将司墨子卷中，其再度喷血，血肉欲裂骨骼欲断。
- 紧接着王林祭出**被压缩无数倍的炎火异晶**，再喝「爆」，几乎与金丹爆炸同时展开第二次毁灭。

## 关键设定披露
- **司墨子分身来历**：其本尊为第三步大能；察觉自身修为在**空涅初期**几乎停滞不前，又缺乏足够**道灵**，故搜集大量材料、耗费极多心血炼化此分身，使分身亦达第三步大能，以此提高自身神通。该分身练就几近**不灭之身**的防护，故未在连环爆炸中肉身崩溃。
- **王林的岁月体系**：王林本身亦会岁月禁，并感悟出自身第二式神通**流月**，因而能正面抗衡司墨子的岁月神通。

## 旁观与收束
龙甲族族长以神识紧密查看这场旷世之战，见炎火异晶爆发一幕神色轰然大变，惊呼「不好」——本章至此断开。全修真星有资格以神识观战者，在「二」字响起时无人认为王林能在剩下三息内获胜。
