# 仙逆 第1041章 深坑之下（第八卷 联盟隐秘·第三更）

## 一、心绪压下：周茹与柳眉
王林压住因见到柳眉而起的复杂心绪，暗忖「周茹竟成了柳眉的弟子，这里面定有一些端倪」，并评价「柳眉此女心机太深」。眼下身处仙帝洞府，多想无用，遂转向眼前问题。

## 二、规则之道的推演（境界关键）
- 现状：王林体内元力磅礴，境界为**窥涅巅峰**。
- 认知：天、地、五行乃至世间一切都蕴含各自的**规则**；人力有限，穷尽一生也难以尽数明悟。
- 推论：所遇**净涅**修士乃至**碎涅**老怪，往往各有一样最了解、最能掌握的规则之力——如**炎雷子**掌握的是**火之规则**。
- 突破条件：欲达净涅，须彻底掌握一种或数种规则，凭之吸取天地之力，使体内元力生生不息；净涅修士的强弱与所掌规则关联极大。

### 两次「观规则」的实验
1. **雷**：右目雷光大范围散开，化作璀璨雷球，球内有与体内**太古雷龙**元神一模一样的模糊虚影。王林凝视之下，雷球只是略显透明，**始终未化作线条、未现规则**。
   - 原因自判：当年所得太古雷龙**只有一半**，另一半消失于那深渊之内，故雷之力不完整，其内规则亦不完善。
2. **火**：左眼火焰浓郁冲出，前方化作火海，火海中隐现**朱雀之影**。凝神看去，朱雀化作透明，无尽火海化为**清晰的红色线条**——规则显现。

### 决定
王林最了解的规则是**雷与火**；火之规则新得、尚未完全熟悉，仍需不断明悟方可据此突破窥涅。但仅以火突破则**少了雷之力**，纵入净涅亦有遗憾。故其打算：**把雷与火融合后再达净涅**，以求威力更大。

## 三、分身与本尊合一
王林踏入地面深坑，破开坑壁而入，来到盘膝端坐的**本尊**身旁。**银衣女子**依旧守护在侧，见到分身神色无变化。王林不予理会，一步之下与本尊融合；片刻后睁眼，**全身煞气收敛，恢复以往样子**。

走出碎裂洞口时，他忆起「借天逆之力在星空中所看的朱雀，与我身上的图腾一模一样，想必定有关联」。银衣女子在后默默跟随，目光时而落在他背上，露出**转瞬即逝的迷茫**。

## 四、星痕貂来投
- 一道幽芒自深坑下方射出直奔王林，正是**星痕貂**：黑色凌乱毛发、双目灵动、极为可爱。它咬住王林衣衫如荡秋千般打转，低吼清脆，随后落上王林肩头，爪子擦脸、湿鼻嗅个不停，赖着不走。
- **传承知识（源自涂司的记忆）**：
  - 星痕貂最喜**古神气息**，是古神时代少数被古神喜爱的灵兽之一；
  - 长久跟随古神吸收其气息，可大范围缩减其漫长生长期，并无形中促成**蜕变**；
  - 蜕变后即使在古神时代亦可算古神的一大助力，但蜕变**极为艰难**；
  - 凡拥有星痕貂的古神**皆极为爱护，视为禁脔**，不容外人伤及半点，甚至碰一下都会勃然大怒。
- 渊源：王林**当年第一次去天运星时**便见过此貂并有些喜好，没想到几百年后它主动前来。

## 五、下潜葬仙池深坑
王林本欲凭玉简地图继续探索仙帝洞府，星痕貂却抬头望向坑底、低吼后径直下潜。王林推测「星痕貂最喜古神之气，莫非当年**葬仙池**下有什么古神之物」，脑中浮现此前**锁住符族圣祖秋瑶的赤红色之筋**，遂随之下沉。

**下潜见闻（自上而下）**：
1. 深坑似无底，寒气不断上涌，坑壁渐结寒霜；
2. 越下寒气越重，呼吸成气龙；坑壁出现大片冰层，锋利**冰剑**成环形延伸；
3. 王林曾隐约察觉下方无尽之处**有一道目光穿透一切阻隔落在自己身上**，遂运转元力，双目喷出火海驱散连神识都无法查看的黑暗，加速下潜；
4. 约半柱香后抵达坑底：**冰的世界**，大片冰川环绕成各种狰狞形状，**每一块冰内都封着一具栩栩如生的尸体**，保留临死前的一幕。

## 六、章末重大发现：冰封古神头颅
透过冰川交错的间隙，坑底**正中心**封着一个高约**数百丈**的庞然大物——一颗**古神的头颅**。
- 头颅被冰封，表情清晰可见，**双目并非闭合而是怒睁**，蕴含**痛惜与愤怒**之色；
- 王林先前感受到的那道目光，正源自此头颅双目；
- 已过去**无数万年**，该古神早已死亡，身上再无任何古神之力，眉心亦无任何星点，**只余留八个崩溃的碎星痕迹**；
- 但其临死前的目光至今栩栩如生，令观者心惊。王林瞳孔猛缩。
