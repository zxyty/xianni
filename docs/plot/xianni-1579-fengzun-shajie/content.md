# 第1579章 封尊杀劫！

## 一、被剥离的朱雀星

- 朱雀星外的星空骤然被一片蓝光取代，不再是黑暗与星光，而如同天幕；整个朱雀星似被一道惊天道术笼罩，被拽离界内星域，出现在一片庞大无比的蓝色天地之中。
- 这片天地一片虚无，唯有朱雀星一颗修真星。地面并非泥土，而是一片没有波纹的平静水面，将蓝天完整倒映；远看仿若一口无限扩大、没有边缘的井。神识亦无法笼罩其边际。
- 王林神识横扫朱雀星，发现其上再无任何生灵——修士、凡人、草木凶兽尽数「蒸发」，只剩他一人。

### 镜像

- **真相**：并非朱雀星生灵死亡或失踪，失踪的是王林。界内的朱雀星依然完好如旧，周武泰仍坐在朱雀雕像上默默喝酒，诸多修士仍沉浸在「封尊回来了」的激动之中。
- **同一座山峰的两幅景象**：界内那座——天空蔚蓝、平静无风、空无一人；分出的这座——王林立于山巅，四周乌云滚滚、雷霆咆哮、雨水倾盆。
- 王林评此道术「堪称夺造化之功」，遂一步踏入滚滚乌云，如利剑穿透，走出被分出的朱雀星，进入那片蓝色天地。

## 二、蓝梦道尊的告知

蓝色天空中凝聚出一名蓝衫中年男子——蓝梦道尊。王林抱拳：「王林见过道尊。」道尊目中复杂渐散、转为坚定，说明如下：

1. 上一次封尊之死，他没有参与；这一次，他也不会对王林出手。
2. 这片天地是**太古星辰所有空玄大能联合布置**，更有**远古仙妃**出手，可短时间破开虚无，将王林封困于此而**不被界内任何一人察觉**。
3. 这片天地**只能存在三个时辰**；这三个时辰，王林难逃一死。
4. 因与王林有旧，故现身告知——「要怪，就怪你是封尊。而封尊，必须要死。」

言毕暗叹转身，化作点点蓝芒与天空融合，消散不见。

## 三、三人围杀

道尊消散一刹那，天空波纹回荡，围杀者依次现身。三人在此地修为受特殊原因压制，**仅能发挥空灵中期之力**，但三人合围，王林根本无法对抗。

| 围杀者 | 特征 | 手段 |
|---|---|---|
| 灰衣老者 | 身形模糊，目光如电带杀机 | 抬手一指化灰色长龙，龙内含庞杂**香火之力**，凝聚发出凄厉嘶吼；自陈「此地不能发挥全部修为，仅空灵中期之力，但今日你与当年的封尊一样，死定了」 |
| 黑衣老妪 | 一身黑衣，目光阴沉，干枯右手 | 自王林背后现身，右手食指狠指其背部；被王林回首一拳崩碎指尖，评「倒也有些手段」 |
| 白衣男子 | 目光冰冷、透无情之芒 | 御一把**蓝色短剑**，剑气滔天之寒化作冰锥；主张「速战速决」 |

## 四、交手经过

1. **呼风之术 vs 灰色长龙**：王林一指天空，呼风之术弥漫，化作**十三条到了极限的黑龙**，吹出**寂灭之风**，风中**透出金色**。灰衣老者惊呼「金色」。双方碰撞轰鸣，王林被震退数丈、面色苍白。
2. **回首一拳 vs 黑衣老妪**：王林后退中转身向后轰出一拳，与老妪一指相触；王林身躯剧震、喷血侧卷，老妪食指指尖崩溃化碎片。
3. **役灵印被打断**：王林一指天空引出金光巨大掌印（灰衣老者、黑衣老妪再度惊于「又是金光」），却被身后凭空而来的冰锥与蓝色短剑击中——光影盾瞬间冻成冰雕并被寒剑穿透，役灵印施展被打断，王林再喷血前抛。
4. **血剑破寒剑**：王林手中血光一闪向后甩出，血剑迎上寒剑；两剑相撞，剑鸣凄厉，寒剑碎成两半倒卷，血剑血光崩溃被王林抓回。白衣男子自断剑旁走出。
5. **三方合击与最正宗的役灵印**：三人化长虹合围，王林急退中再引役灵印，双眼露出金光与疯狂战意，掌印透出万丈金光、掌纹如山脉交错，威压先至。灰衣老者死死盯住金光：「这金光到底是什么？居然会让我有种隐隐颤骇之感。」

## 五、母题与心境

- **轮回式的劫**：上一代封尊便死于太古星辰数个大能的围杀，如今同样的劫难落在王林身上——此即「封尊之劫」。王林已不考虑生死：「这一次大劫，他生也要渡，死，也一样要渡。」
- **不认命**：「没人能左右我的命运，生死劫，也不行。」「你要战，那便战。」
- **心性**：越是危急越是疯狂，则心神越是冷静——这是他在两千多年生死中养成的习惯。

## 六、悬念

- 王林寂灭之风与役灵印中反复出现的**金色**，令空灵中期强者生出颤骇，来历未明。
- 三个时辰的期限如沟壑在前，王林能否渡过封尊杀劫未决。
