# 第1389章 贪狼的颠落之地见闻与王林的放归

## 一、贪狼自述：颠落之地的探索史

### 1. 外围拾宝的数百年
- 贪狼坦言：**除那雕像与万古木灵外，其余法宝皆得自颠落之地那些巨大头颅**。
- 他在外围谨慎挪移了几百年，**始终不敢进入内部**，对内部有何物一无所知。

### 2. 误入深处
- 一次在**两处巨石碎片之间**移动时遭遇大量**空间乱流**，以其修为撞上必死，危急中唯有后退，反而踏入了那里的深处。
- 进入深处边缘，四面八方传来**阵阵凄厉吼声**，落入耳中即引发**来自灵魂的颤抖**。
- 他不敢乱走，数年后才略有胆量欲返外围，隐隐判断：**深处非其可入之地，若继续前行必死无疑**。

### 3. 枯萎的磅礴森林
- 欲离开时被**一片风暴卷中**，重伤昏迷。
- 苏醒时身处**一片枯萎的磅礴森林**：一眼看不到尽头，**神识散开亦无法笼罩全部**，所见树木尽皆枯死、无一片树叶。
- 恐惧前行不知多少年，见到**唯一一棵尚未彻底枯萎的大树**，其上只有**一片枯黄树叶**——这是他在此处看到的第一片树叶。**树叶被取走，连未枯萎的大树也一并收入储物袋**。

### 4. 森林中心的雕像与归途
- 越向前枯萎越严重，最后草木**一碰即化为飞灰**。
- 终于抵达森林中心，见到**一尊雕像**。贪狼隐隐猜测：**正是这雕像使无边森林尽数枯萎死亡**。
- 感应到雕像是宝贝，遂取走；**取起的刹那身前出现漩涡**，与他当初进入时的一模一样。他狂喜之下冲入。
- 出现时已是**陌生星域**——后来才知，那是**封界之外**。

## 二、王林的处置：搜魂、洗魂、放归

- 贪狼讲到一半即察觉**定身术时效已过**，趁王林沉思悄然后退、猛地前冲欲逃。
- 王林右手随意一抓，**隔空擒回**贪狼；贪狼凄厉大吼“你答应了不杀我”。
- 王林右手落在其天灵：
  - **神识轰然进入其元神横扫一圈，搜寻记忆**；
  - 同时引动雷霆——闪电在星空游走凝聚于右手，**以雷霆本源之力将贪狼元神如洗涤般清扫一番**。
- 王林抛出贪狼，留下一句：**“我也不白拿你之法宝，你走吧。”**
- 贪狼咬破舌尖喷血提速，化长虹遁走，心中满是委屈与劫后余生之感。

## 三、贪狼的后续：恶臭尽去

- 贪狼发誓：**此生绝不让“被王林抢走所有法宝”之事发生第三次**（此为第二次）。
- 判断颠落之地太危险，决定**速回洞府取走留存之物、离开颠落之地**。
- 挪移无数次确认王林未追后，现身于一处**修真星**，破开山峰缝隙进入洞府。
- 一股**恶臭**扑面而来险些将其熏晕——他随即震惊发现：**自己身上的臭气已消失，嗅觉也恢复**（此前久处其中已闻不到洞府臭味）。
- 他数百年梦寐以求解决臭气，遇王林后失去获得**万古蝎尸**的机会本已绝望，不料臭味自行消失。想起王林那句“我也不白拿你之法宝”，神色复杂。

## 四、王林的内心账：贪狼是福星

王林之所以不杀：
1. 贪狼**不远界内界外阻隔，提前一步赶到太古星辰等待**自己；
2. **把辛苦弄到的法宝尽数交上**；
3. **他乡遇故知的喜悦**。

结论：“这贪狼是我的福星，不能杀，必须要放，我还期待能与他的第三次见面，到时候，想必又会送上一些法宝。”

## 五、暗蝎族修真星：钟大洪的威风

- 王林返回**暗蝎族所在修真星**。
- **云遁族近千修士不敢离开**，仍在原地等待。
- **钟大洪**趾高气昂，指使数名修为高深的云遁族修士为自己疗伤，斜躺冷哼——每哼一声四周修士心神一颤。
- 众人敬畏的并非钟大洪本人，而是其背后的主人；尤其**族长见到玉佩后的神情与话语**，让全族意识到招惹了不可招惹之人、大祸临头。
- 云遁族恭敬请回**被驱散的暗蝎族族人**及钟大洪的随从**章姓老者**，并奉上丹药疗伤。
- 钟大洪狂言：“早知如此，何必当初”“你等修为，莫说我主人，就算是我，也丝毫看不入眼”。
- 云遁族族长（修为远高于钟大洪）忍痛献上**一个玉瓶**为厚礼，求其美言；钟大洪收入怀中，干咳道“老夫便试试吧”。
- 天空波纹回荡，**王林一步走出**。钟大洪神色骤变，推开揉肩女修，弓腰阿谀：“恭迎主人凯旋归来”，自陈思念、需念一百遍主人名字方能入定云云，并抢在王林之前推开云遁族修士为主人开道。
- 云遁族上下**目瞪口呆**，难以想象一人瞬息间可有如此反差。

## 六、待解疑点

- 颠落之地深处的凄厉吼声来源、内部真容仍未揭示。
- 森林中心雕像的来历与其致万物枯死之能，以及它与万古木灵、那片枯黄树叶的关系待考。
- 贪狼两次进出所遇“一模一样的漩涡”是否为固定通道，未明。
