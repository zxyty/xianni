# 第917章 罗天反击

## 一、第一波：十八罗浮

- 十八个十丈血球降临星空，威压弥漫。罗天修士身上红芒闪烁，不受影响；联盟修士则天地上下挤压之感袭来，血液急速流动、耳绝外声只闻心跳、眼前模糊。
- **来历**：罗天星域内两个上古修真家族，集合无数族人、于数万年间不断献血，并以传承秘法牺牲极大而一点点祭炼，是两家护族至宝之一，上古修真界威名极大。
- **罗浮起源**：罗浮本为上古修真名山，一夜之间奇异崩溃，山中所有修士鲜血脱体、暴毙而亡，血液凝聚罗浮山化作一颗十丈血球。后世上古修士研究观察虽查不出原因，却由此明悟，渐成罗浮血球神通。
- **限制**：血球太过歹毒且凝炼成功率不高，无法大量祭炼。
- **效果**：威力重在威压，一球即一重威压，十八球同临则威压达到不可思议的程度；提前将鲜血融入其中者不但不受威压，反可在其下短暂提升修为。

## 二、罗天高层的调度

- 黑煞魔尊面色阴沉，欲冲出毁掉十八罗浮，被**血神子**自星空一步走出、长笑阻拦。
- **炎雷子**面无表情，右手一指身后——此指似可穿透虚空，自联盟北域穿过撕裂的空间裂缝，落入联盟西部与罗天星域相通的**两域通道**，引出第二波。

## 三、第二波：远古仙域参天巨木

- 罗天星域内上万修士全身修为运转环绕，正中之物为一木：长数万丈、粗近千丈的参天巨木。
- **来历**：三万年前被**雷仙殿**寻到，是传说中远古仙域存在时支撑仙域的仙界巨木。四大仙界中唯有罗天此木保存较为完整，其余在仙界崩溃时瓦解。一直收藏，此战始取出作攻击手段。
- **推动**：上万修士齐声大喝推木前撞，其后另有罗天几个老怪，以及向家老者、公孙复姓中年男子齐力；巨木渐加速，几成风暴，天地颤抖。
- **战果**：冲入两域通道后瞬出，抵达联盟西部；由无数裂缝连接而成的壁垒毫无作用，波纹扩散中被生生撞开一道裂口。大量罗天修士随巨木后杀入联盟星域。壁垒外幻化虚影与传送阵而来的联盟修士躲闪不及，远者亦被风暴漩涡吸扯，被撞中者肉身崩溃、元神瓦解化作血雾。

## 四、第三波：望月出关

- 通道深处传出震动整个联盟西部的吼叫，联盟修士身躯剧震，部分七窍流血。
- 一颗巨大修真星缓缓飘出，外裹诡异雾气；雾气骤缩消失后自中裂开、舒展成椭圆形，无数万丈须发飘散——正是**望月**。
- 望月双目通红、怒火无尽近乎发狂，须发挥舞、庞大身躯冲出；嘴裂深口咆哮，冲击化作风暴，身前星空裂缝如被撕开的纸张倒卷。
- 咆哮临近巨木时，一道**黄光**如蛋壳笼罩巨木，冲击自两侧无阻而过（罗天一方对巨木的护持）。
- 望月似能识别罗天修士，攻击时少有波及己方，绝大部分杀向联盟。

## 五、道元天尊被逼现身

- 望月吼声引发星空崩溃，巨木前方虚无扭曲，一名白色道袍老者被生生逼出身影——**修真联盟四尊之一的道元天尊**。
- 其面色阴沉，目光穿透星空看到望月，内心暗叹、摇头后加速后退。
- 后退刹那，巨木上的向家老祖与公孙姓男子化作两道长虹直奔而去；向家老者长笑“联盟道友，何必如此匆忙而走”，大袖一甩，红风弥漫方圆万里。

## 六、战场态势

- 大战以**联盟西部与北部**为战场，厮杀之声呼啸，法宝之光五光十色，法力波动波及无尽之处。双方修士稍有不慎便身亡。
- 因望月不断前行，**联盟星域一时处于弱势**。

## 七、王林一行在联盟西域

- 阵容：**雷吉**身子缩小化作三丈大汉在前开道；**大头童子**紧随王林身后；**塔山**在旁双目寒芒密切观察。
- 王林目光平静。沿途遇数个联盟修士，见其一行修为即变色转身逃走；少数自持修为或人数众多者杀来，无一例外被王林直接灭杀。越向前遇修士越多，但敢上前者仍少。
- 王林身上并无半点杀机，雷吉、塔山、大头童子三人却杀机弥漫，如一把利剑直奔前方。

## 八、王林的境界迹象（重要设定点）

- 联盟西部彻底废弃：熟悉的星空已崩溃，时有撕裂缝隙呼啸而过。
- 这些缝隙在王林面前，好似被一股奇异力量移开、向旁边滑去。
- 若有踏入**第二步净涅**以上的老怪见此，必然双目凝重——这是**初步掌握规则**的迹象。
- 设定辨析：**窥涅期只是“接触”规则，“初步掌握”须净涅方可做到**。王林未达净涅，但凭**天逆**的明悟，在这一点上已有一丝净涅气息，虽仍很淡很淡。

## 九、章末钩子

- 远处星空，一名身穿紫衣的妙曼女子脸露苦涩、抿着下唇，脚下剑光微弱似随时涣散；身后数名联盟星域修士疾驰追击，其中一名中年男子一脸冷笑。
- 王林以神识一眼看到，心中道：“是她”——身份本章未点明。

## 十、待跟进

- 紫衣女子究竟为何人（与王林旧识关联）。
- 道元天尊能否脱身、联盟四尊其余人的应对。
- 望月为何暴怒发狂、由谁驱使。

# 第918、919、920章 周天（三章合一）

## 一、背景：联盟星域大崩溃余波
- 西子凤本与家族一同来到**联盟星域**，却在此前的**大崩溃**中被不可思议的冲击波及，整个人倒卷而去，与家族失散。
- 她稳住身形后所见，是**如地狱般的杀戮**——联盟修士对罗天修士的屠戮。

## 二、西子凤遇险
- 西子凤美貌引起联盟修士注意，立刻有人追来。
- 她此前心神已受损，急速逃遁导致**伤上加伤**。
- 追击者为一**中年男子**（修为略高于西子凤，但有限），拍储物袋取出**金针**掷出，金光尖啸直取其后心。
- 该男子扬言：「这罗天的女修，将成为我**第九个炉鼎**……从未尝过罗天女修的滋味。」
- 西子凤转身掐诀放出荧光相阻，金针之力过大，她当场喷血倒退，面色苍白无血色。

## 三、王林出手：言出法随 × 新明悟的规则
- 中年男子将抓向西子凤之际，冰冷两字「**退下**」回荡四周。
- **手段构成**：王林把刚刚明悟的**一丝规则**，与当年感悟的**言出法随**融合，化作一股**意志之力**。
- **效果**：
  - 声音如数万雷鸣、如利剑穿体，中年男子双耳嗡鸣、如被隔绝天地，喷血倒退，身体彻底不受自己操控；
  - 那意志之力**波动了星空下的规则**，同行追击的其余修士同样无法反抗；
  - 后退过程中砰砰连响，多名修士肉身承受不住意志降临，**当场崩溃而亡**，血雾弥漫；
  - 连元神也逃不出——**魂魄不入轮回，被生生挤出，化作道道乌光融入王林体内，被十八层地狱封印**。
- **实力定位**：文本明言，此刻的王林已达到当年在**妖灵之地**那**散魔**（一声冷哼即可令王林肉身崩溃）的程度；这种级别的修士在王林面前微不足道。
- 中年男子内心断定：对方是**罗天修士中的大神通强者**——但话未出口，肉身已崩。

## 四、周天登场与星空斗法
- 中年男子元神飞出、即将瓦解之际，虚无中传出**阴柔声音**：「不愧是**罗天正品雷仙许木**」。
- 来者即此前出现的**六指修士**：蓝衫、看似中年、一脸土黄之色，身后**黑色虚幻之影**如长披风铺展星空。
- 其声音融入虚无，助那元神摆脱王林意志、止住瓦解（但元神已涣散大半，极为虚弱）。
- **斗法回合**：
  1. 王林右手一挥，狂风凝聚化无数**斩罗诀**融为一道，直追逃遁元神；
  2. 六指修士分出部分虚影迎击——**斩罗诀斩灭一切规则**，在王林明悟规则后威力暴增（此前只是无意识施展，未尽其威），虚影一触即溃、转眼全灭；
  3. 六指修士变色，掐诀将身后全部虚影凝聚收缩成一枚**散发黑芒的小球**，气息可震撼心神，小球穿透虚无撞上斩罗诀后自爆，化无数黑气将斩罗诀层层包裹；
  4. 六指修士再一挥手，大力推动那元神疾退，眼看要消失在星空尽头。
- **自报名号**：「我**魂侍周天**要救之人，谁也不可杀之。」
- **王林收官**：看都不看周天一眼，抬脚一踏，脚下波纹泛起，**融入虚无**（空间遁法）；瞬息出现在远处元神身旁，右手握拳**一拳击中星空**，星空震颤波纹四起；口吐一字「**碎**」，元神如沙人般在狂风中消散。

## 五、转折与悬置
- 周天双目诡异之芒更浓，直勾勾盯着王林，随即抬手一指西子凤，放出数道虚影直扑而去。
- 台词：「你要救这个女子，**我偏不让你成功**。」
- 西子凤面色苍白后退——章节在此处悬停，救人之局转为王林与周天的直接对抗。

## 六、要点归纳
- **新战力节点**：规则明悟 + 言出法随 = 意志之力；同时使斩罗诀威力质变。
- **新敌人**：周天，自称「魂侍」，六指修士，本领为操控黑色虚影（可聚为爆裂黑球），且能干涉/救援他人元神。
- **化名信息**：周天口称王林为「许木」，印证王林此阶段仍以**许木**之名（自创化名）在罗天/联盟一线行事，并被认作「罗天正品雷仙」。

# 第853章 撒豆成兵斩周天·天虎旗聚众·望月现身

## 一、周天之战

### 交手过程
1. 周天微笑观察王林表情，王林平静如水、目露杀机一步踏出；周天瞳孔一缩立刻后退。
2. 王林于西子凤身旁破波纹而出，一拳轰碎数道虚影，言：「你要杀她，许某不管，可在我面前，不行」。
3. 周天掐诀凝虚影为黑色大斧，喝「万魂吞神」抛向王林；王林一拳震碎，大斧化无数虚影四面围聚。
4. 王林一指天空，自方圆数万里星空抽出雷霆，雷落之下上万道虚影尽灭。
5. 周天一指眉心，脸生黑纹，喝「魂，杀」，天灵现环形黑圈疯狂蔓延；黑圈化细线钻入王林体内，未深即被王林一动尽数破灭。
6. 周天退中捏碎紫色光球（护身之物），紫光被砰砰击溃；王林融入天地瞬移至其身旁一脚踢碎其肉身。

### 夺舍失败
- 周天肉身崩溃化血雾，长笑中化紫红色虚影钻入王林体内，直奔元神，欲夺舍：「这具肉身，我周天要了」。
- 王林元神睁眼，元神外的**古神皮甲**透出沧桑之气与元神融合，形成无法想象的反震之力，紫红虚影如遇天敌纷纷溃退（周天因此受轻伤）。
- 王林元神即**太古雷龙**之形，张口一吸，生生吞噬部分逃不出的虚影。

### 撒豆成兵（首次施展）
- 王林道「就拿你，来测试下许某的神通威力」，掐诀曰「撒豆成兵」。
- 机制：体内**仙元**分出一股运转凝于右手，化金色之光抛出如金豆弥漫星空，幻化出**王林亲手所杀之人**的魂魄——这些魂魄不入轮回，被禁锢于其元神内的**十八层地狱**。
- 周天判断：此类魂魄必须亲自所杀，方能以特殊手法禁锢为己用；斥为「魔道手段」。
- 放出的魂魄阵容：
  - 一名一脸阴沉、黑雾缠身的**窥涅修士**；
  - **上百个仙人之魂**（仙气与怨气结合，周天一生钻研魂道，一眼认出）；
  - **姚家族人**的魂魄；
  - 压轴者：**天运星血祖**（赤雾冲出、红发中年、面部狰狞），众魂避让让出通道。
- 周天见血祖当场骇然：「血祖是净涅修士，居然都被这许木所杀」，收起一切杀心，只求速逃。

### 结局
- 王林令「把此人，拉入十八层地狱」。周天炼化肉身、元神融入魂魄，化无数虚影四散逃遁。
- 血祖之魂如远古凶兽双爪抓拽，上百仙人之魂与姚家魂魄封死前后左右上下，周天分散虚影无一逃出。
- 王林一指天空开出巨大漩涡收魂；唯血祖冲出反扑王林，被王林一拳打顿后强行吸回。
- 漩涡化晶光被王林吞下，**周天落入十八层地狱第十三层，且处该层巅峰**。

## 二、天虎旗与声望经营

### 王林的盘算
- 罗天与联盟交战正烈，王林决意「拿出一些成绩安抚炎雷子之心」，并在罗天修士中获取更多声望。
- 目的：日后若遇**天运子**等人，或**拓森走出古神之地**，炎雷子就必须出手相助。
- 但王林内心**并不看好罗天此番进攻联盟**。

### 天虎旗立威
- 王林拍储物袋取出绘飞天虎图案的**天虎旗**，祭起放出飞天虎，虎啸震惊星空——等同在联盟西部公开自己的名声。
- 沿途连续救援：
  - 七八名重伤罗天修士被围杀，虎啸与磅礴神识横扫，联盟老者从家族资料中认出「许木修为达到了窥涅」，喝令速退；
  - 三名阴虚修士混战处，一名罗天修士认出许木——此人正是**王林在雷仙界内曾救下之人**；另一联盟修士依修真联盟资料把罗天修士分七级（一级最弱、七级最强），忆起许木列在**第五级**，立刻后退。
- 罗天修士纷纷高呼「参见雷仙」「是正品雷仙许木」，视其为彷徨中的明灯、定神之针（此前西部崩溃、死伤极多、幸存者被冲散）。
- 王林一改此前态度，遇厮杀即出手横扫；追随者渐多后往往不需其亲自动手。
- 最终数百道剑光随行，如一把利剑刺入联盟西部。联盟西部同类队伍还有其他**雷仙殿使者**、**一百零八仙**及若干修真家族，但王林这一支**人数最多**，声望一时达到相当高度。

## 三、章末转折：参天巨木与望月

- 冲入联盟西部中心时星空异震，波纹传来，随行修士剑光不稳。
- 远处一根**万丈长、千丈粗的参天巨木**呼啸而来，四周罗天修士密密麻麻近乎无数；巨木血腥气极浓，一路撞死者无数。王林判断自己若被撞击也会重伤，稍有不慎恐形神俱灭，除非提前融入天地逃走。
- 真正让王林呆住的是巨木之后的**望月**：身躯如一颗修真星，无数万丈触手摇曳，愤怒吼叫弥漫星空。
- 见望月刹那，王林身体一震——**这震动来自古神**。

## 四、随行人员
- 塔山、大头童子、雷吉紧随王林；大头童子对这一切已见怪不怪。
- 西子凤被救后沉默跟随于后。
