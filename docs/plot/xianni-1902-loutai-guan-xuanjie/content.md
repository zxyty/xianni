# 第1902章 楼台观玄劫

## 一、废墟大陆：黑袍长发男子提前苏醒

- **提前一量劫醒来**：一中年男子于废墟之上喃喃「我提前了一量劫苏醒」。按其计算本应在五量劫后苏醒。
- **神识之强**：神识一散，刹那笼罩整个废墟大陆的每一寸土地。
- **此地来历**：他隐约记得很久之前来到这里，将此地全部毁灭、杀死所有生灵，吸收此地死气后沉浸闭关。
- **苏醒之因**：某个方向传来「深入我灵魂的悸动」，他判定为**同类的气息**，疑「有同类诞生」。其悠久记忆中对该方向有模糊思绪——「那里，应该是**守护者一脉**所在」。
- **形貌与启程**：起身时身上幽光闪烁化作黑色长袍，长袍笼罩面孔，唯有惊人长发以特殊方式穿透长袍深深垂下。升空时长发飘舞如黑龙，身外真有一条**黑龙虚影**缭绕，如化作惊天黑龙直奔天空尽头。
- **目的地与路程**：前行方向正是极为遥远的**仙罡大陆**；以其速度前往亦需**数百年**。

## 二、绿魔洲蝎庙：三道虚之本源融合归一

### 本源来历
三道虚之本源——**生死、因果、真假**——并非王林凭外力获得，而是自其体内、其意境中自行诞生：

| 阶段 | 状态 |
| --- | --- |
| 第一次化凡 | 诞生萌芽 |
| 第二次化凡 | 凝聚 |
| 第三次化凡 | 大成 |

### 本源中所见的一生
- **生死**：朱雀星、大牛三代人。
- **因果**：柳眉、王平，以及自己身为父亲的一幕幕。
- **真假**：苏道、六十年的一梦，以及许多熟悉的事情与面孔。
- 融合过程中另见：跪拜父母坟前泪流嘶吼；抱着李慕婉的身体仰天怒吼、其眼角闭上刹那落泪（依稀似见一年后泪落之地开出一朵「梦的花」）；得知柳眉有子、见那怨气冲天的孩子而心死至痛喷血；李倩梅在他所化石像上十年的血抹之泪。
- 王林轻叹：「我的一生」；容颜在融合中似有了沧桑。

### 王林的道之总纲（原话要点）
> 以生死意境**离凡**，以因果意境**明道**，以真假意境**感悟**。生死中迷茫思绪出现了因果，在因果内不断印证我的道最终化作真假，在真假中找出道之所在。**生死之后是因果，因果之后是真假，真假之后便是人道。**

三种虚本源融合不难——「它们因我而生，因我而凝，因我融为道」。

### 归一结果
三道本源无声无息完全融合，归一后形成**一缕充满王林记忆的丝线，组成环形，飘向王林印在额头**。烙印刹那，王林眼中追忆消散、代之以一片精光。

## 三、修为暴增：空玄后期 → 空玄巅峰圆满

1. **第一波**：烙印成形时修为暴增，体内积累的**绿魔蝎天地之力**被全部吸收殆尽；此前吞噬的绿魔蝎分魂（夺舍失败后残留的大半魂体）也被暴增的元神疯狂吸收。
   - 结果：只能无限接近**空玄圆满**，无法突破、无法迈入玄劫之境面对九次玄劫。
2. **第二波·吞吸天地**：王林张口猛吸，蝎庙内外天地之力轰然涌入，外围雾气被牵扯化作巨大漩涡，在绿魔洲凝聚成**天地异相**，持续**数月**。
3. **突破**：数月后修为气息轰然爆发，自**空玄后期**直接攀升至**空玄巅峰圆满**。因异相掩护、周围修士不敢散开神识，至今无人察觉。

### 两大真身归体
- **五行真身**：一晃融入体内，修为再增数倍。
- **雷霆本源真身**：迈步一跃与王林身体重叠，在啪啪雷霆闪电中融入，成为身体一部分。
- **战力评估**：此刻即便不穿**天牛魂铠**，也可与**空劫后期**一战；且这还是**未使用杀戮雷霆**的前提。杀戮雷霆为王林无意中创造，他自己无法掌握、亦不知其毁灭之力有多大。
- 强大的信念改变其气质，令见者未等出手先心神一震。

## 四、外界反应：绿魔洲群修误以为绿魔复活

- 绿魔洲与**天牛洲**交战已至尾声，大量修士死亡，残存者虽少却绝大部分修为高深。
- **道魔宗**：百余年间虽死伤不少弟子，仍有近三千门人留下；**道魔宗宗主一百多年前闭关，至今未出**。
- 绿魔蝎庙异相引来绿魔洲各处**十多道长虹**，道魔宗亦飞出**两道长虹**，皆奔绿魔庙，欲见证「绿魔蝎复活」。
- 众修不敢靠近、不敢散开神识（怕影响绿魔复活、承受不起绿魔怒火），只随异相扩大而后退观察。

## 五、立誓与守望

- **云逸封三人**因等待太久已离去；对王林而言**边云**已如过往云烟。
- **血誓**：「若我王林能一举度过九次玄劫，成为**空劫大尊**，则屠**道魔宗**满门上下，即便是空劫后期修士，也一样形神俱灭，以报如此百年造化之恩。」
- 王林背手仰望，神识稍动即可弥漫整个蝎庙，静**等玄劫来临**。
- **对照**：古往今来有资格面对玄劫者无不胆颤心惊、小心翼翼，即便大天尊未成之时亦大都如此；能如王林这般「站在楼台上看玄劫刹那芳华与美丽」者，罕见至极。
