# 第886章 司徒南出关（第七卷 名震罗天）

## 一、清水的临别传承

### 1. 赠礼与神通
- **仙元之力**：清水此前赠予王林，量有限，属防身之物。
- **唤雨之晶**：与仙元之力配合施展；清水断言，只要不陷入大神通修士之战，王林在**联盟星域**内当可自保。
- 王林此刻仍沉浸于脑中弥漫的**唤雨**与**撒豆成兵**两大神通，不断消化明悟。
- **吞噬**：清水眼露诀别之色，坦言自己所修尽是征战之术、无调养之法，唯有师尊当年传授的「吞噬」——王林曾在**雷之仙界**亲眼见过——遂以右手按王林眉心尽数灌入。
  - 告诫：「此术弊端很大」，当年师尊传他时亦极犹豫；**不到万不得已不可轻易使用**。

### 2. 血色符文
- 清水咬破手指画出诡异符文，血腥之气一现，星空尘埃尽数退避。
- 符文一挥印入王林胸口，一闪即隐。
- **效果**：王林苍老容颜刹那恢复如初，仅余一头白发；生机损伤之相被完全隐藏保护。
- **限制**（清水明言）：
  1. 起不到恢复作用，只作遮掩保护；
  2. **无法在元婴之体上使用**——否则王林不至于落到今日境地。

### 3. 最后的告诫
> 「师弟，从此之后，好自为之。极境恢复的方法，与**天劫**有关，只是，若你修为没有踏入**碎涅**，莫要钻营极境之事，切忌。」

清水转身走向星空，身影渐渐消失。王林恢复神志后望着其远去方向沉默良久，轻声道「谢谢」。

## 二、避天棺重塑李慕婉肉身

### 1. 择地闭关
- 王林**没有**走雷仙殿的裂缝回联盟星域，而是融入天地寻到最近一颗**废弃修真星**，探查安全后开辟洞府盘膝。
- **塔山**自其背后一步走出，盘膝坐镇洞口守护。

### 2. 天逆珠的失败
- 王林取出封印李慕婉的**禁制球**，抚开层层禁制，露出内里**已拥有一丝生机的李慕婉元婴**。
- 自白：「婉儿，哪怕我消耗了几乎全部的生机，能换来你的这一丝可能，我也愿意的。」
- 李慕婉元婴轻颤，无力苏醒，却流下两行本不该存在的眼泪，一现即散。
- 王林眉心**天逆珠子**凝出，将元婴置于其内——却发现元婴在天逆内**仍在缓慢消散**，从未停止。

### 3. 避天棺的奇效
- 王林果断取出**避天棺**（水晶般透出晶光的棺材），却在把元婴伸入棺内前再度犹豫——放，还是不放。
- 元婴一落棺中即由盘膝转为躺下；棺内涌出奇异之力，元婴**先现崩溃之兆**，随后体内那一丝生机在元婴内游走，崩溃缓缓消散，棺中现出**五彩之光**。
- **关键结论**（王林当场推断）：*此棺只对尚有生机之人有效，哪怕生机只剩一丝*；若李慕婉体内无那一丝生机，入棺必然崩溃。
- **重塑过程**：红色丝线自元婴外幻化，游走勾出身体轮廓 → 五彩光中无数晶光顺红线凝聚成女子骨架 → 数息内肉身凝成，安静躺卧仿若沉睡，**连呼吸都已存在**。
- 王林落泪：「婉儿。」为了这一眼，一切都值得。

### 4. 归途
- 三天后，王林带李慕婉走出废弃修真星，直奔**雷仙殿**。
- 星空中传出其忧伤之语：「婉儿，咱们回家。」

## 三、联盟星域战局：罗天西侵与联盟的沉默

### 战况（半个月内）
- 罗天修士大军自**联盟星域西部**冲入，横冲直撞，接连占领一颗颗修真星，星上修士各自撤离，仿若末世。

### 三处诡异
1. **修真联盟毫无行动、毫无焦虑**，如同观望，任由对方杀入深处、占据根基修养。罗天方猜疑不定，连**炎雷子**等人也满心疑惑。
   - 对照：同样的事若发生在罗天星域，**雷仙殿**必第一时间组织反击。
2. **七级以上修真星集体缺席**：罗天占下的全是六级修真星，七级修真星「仿佛消失了一半」，遍寻不到。
3. 面对未知与无法预判的对手，罗天众多老怪心底升起不安。

### 战力对比的震撼
- 联盟星域**六级修真国**的战斗力令大批罗天修士大吃一惊：嗜杀的双目、狡猾的行事作风、难缠的法宝，令罗天损失不小。
- 罗天修士得出结论：**同等修为开战，罗天必败**。
- 联盟修士人人杀戮果断、战斗经验极丰，「好似每一个修士都来自**东临星**」。

## 四、司徒南出关（章末伏笔）

- 地点：联盟星域西部一颗较为**蛮荒、无人居住**的星球。
- 异象：冲天气息爆发，星球内轰隆巨响、大地颤抖、江海倒卷，星球大范围崩溃，濒临死亡边缘。
- 出关者形貌：衣衫破损、皮肤黝黑、满身污垢、极为邋遢，**目光明亮如虹**，散发摄人心魄的奇异之芒。
- 狂放宣言（要点）：
  - 「老子出关了」——被逼闭关这么久、东躲西藏憋在鸟不拉屎的地方，与**凤栾星**的女修「没完」。
  - 已不记得此次闭关多久，念及自己那些王妃**多年下来一定早就死了**。
  - 「老子这次真怒了，一口气修炼到了**净涅初期**，去你凤栾星做王爷去。」
- 依章节标题「司徒南出关」，此狂放邋遢者即**司徒南**。（注：正文本段未直呼其名，属标题点破。）

## 五、可追踪的设定要点
- **境界序列**：净涅（此章出现「净涅初期」）、碎涅（清水以之为钻营极境的门槛）——极境恢复之法与天劫相关。
- **避天棺**新特性：只能对尚存一丝生机者重塑肉身；对无生机者反致崩溃。
- **天逆珠**局限：无法止住李慕婉元婴的消散。
- **血符**局限：只掩不治，且不可施于元婴之体。
- 王林代价：为换李慕婉一丝生机，几乎耗尽自身生机，白发未复。
