# 第1816章 真身憾

## 一、镇压两条子脉龙魂

- **杜青出手**：其修为已度过七次玄劫，虽非真正的空劫初期却深不可测；为巴结王林直接祭出最强神通——体内紫光一闪，**重之本源**扩散而出。龙魂一近即似增重无数倍，凄厉惨叫着坠地，挣扎难脱。
  - 副作用：随子脉龙魂咆哮，杜青体内火焰似不受控制地扩散，仿若反噬。王林由此对重之本源有了新认识。
- **王林出手**：另一条子脉火龙因与天地气息摩擦燃烧，外裹黑烟滚滚，形似仙罡妖龙。王林白发飘动、上前一步，掐诀挥手祭出**血剑**，化作开天血光自上而下一斩——火龙魂后退不及，被横扫斩下一截身子。
- **金印擒龙**：王林右手抬起，金光万丈中现出**金印**。火龙魂见印即生恐惧、一晃万丈欲逃；王林遥指，金印呼啸追去，一声巨响后携缩小无数倍的火龙返回。杜青心惊肉跳，赞其为「大天尊制作的法宝」，并暗判王林**尚未尽全力**。

## 二、本源真身的凝聚进度

| 投入 | 结果 |
|---|---|
| 血剑斩下的一截龙魂 | 火球火焰再炽，已有四肢的真身现出凝聚躯体之兆 |
| 金印中的完整子脉龙魂 | 躯体肉眼可见地凝聚，至半途火焰转黯将熄 |
| 杜青驱入的第三条子脉龙魂 | 火球爆发吸力尽吸其火焰本源，半柱香后躯体完全凝出 |

- 最终形态：**四肢俱全、躯体完整，唯头颅仍是朱雀模样**，颇为诡异。
- 火焰力量到极限，一丈火球轰然崩溃化作点点火星，被这尚未完全转化的真身吸回。
- 半成真身即散发强悍威压笼罩八方，以杜青修为亦有退避冲动；杜青心生渴望，也想凝聚自己的本源真身。

## 三、王林的感慨与代价

- 已耗：**一百八十八条支脉 + 三条子脉龙魂**，仍未能完全凝聚。
- 结论：「越是往后，需要的火焰本源就越多」——单一个头颅不知还需多少火焰。
- 推论：以洞府界的资源，**根本无法完成哪怕一具本源真身**，故洞府界中从未见过本源真身。

## 四、真身入体的异变

1. **双瞳**：半成火本源真身化作火海融入王林**左眼**，左眼原有的火焰印记消失，代之以妖异双瞳。
2. **影随身动**：行走时身后浮现一个与其同步、看不清相貌的虚影。王林忆及在**大魂门**曾见其老祖如此，尤其施展神通时更明显；略一沉吟便令虚影渐淡直至消失。

## 五、后续动向

- 王林决定前往**苍龙宗**居住一段时间。杜青大喜，允诺发动全宗弟子寻找**地火龙脉**、派长老抽出龙魂相赠。
- 二人化虹离去，身后山峦下的**地火子脉渐渐枯萎**。
- **天牛洲赶路试探**：杜青自恃速度更快，暗中提速超出王林以判其修为（暗忖「看似空灵巅峰」，又思及仍需借此人接触**大天尊**，不敢过分）。王林冰冷目光落下，挥手放出黑雾中的**蚊王**——嘶吼刺耳震魂，杜青几有身体崩溃之感，惊问「什么凶兽」。王林一句「杜道友，你速度太慢」，踏蚊王一冲，眨眼无踪，其速再令杜青骇然。

## 六、要点提炼

- 本源真身 = 需海量火焰本源（支脉/子脉龙魂）逐步凝聚四肢→躯体→头颅，且凝成后有「影随身动」的共通异象。
- 王林对杜青始终是**利用兼镇慑**：既用其重之本源补位，也在其试探时以蚊王立威。
- 杜青对王林的核心图谋：借其接触**大天尊**。
