# 第八卷 联盟隐秘 · 第1123章 对不起（第四更）

## 一、交付玉简：朱雀老圣皇的临终之托

- 王林打量昆虚之境接待的紫金袍男子，只看出其修为为**碎涅**，未多言，直接虚空抓出玉简甩去。
- 该男子接过后神识内扫，轻咦一声、神色凝重：**以碎涅修为竟看不了玉简内容**；但他看出玉简材质绝非寻常，**其内蕴含一丝天地炙热**，结合王林的身份，判断此物大不简单。
- 王林说明来历：**朱雀老圣皇从联盟总部内察知了一个秘闻，临归墟前，让他务必把这玉简送到昆虚之境**。男子抱拳道谢，神色更凝重。

## 二、强闯传送阵的交代与追责

- 王林甩出**三个被禁锢的元神**（双目紧闭），坦承此前「没有邀简，心急玉简内所记之事重要，故而出手强行进入传送阵」。
- 又递上第二枚玉简：内为清晰画面，记录他在外与**四个看守者**冲突的前因后果。
- 男子看罢平静表态：「有劳圣皇代为教训了，只是教训可以，但**杀我昆虚一人**，就有些说不过去了。」
- 王林答：「**失手而已。**」
- 男子欲以「此事事关重大」为由，请王林在昆虚**暂住数日**，话未说完即被打断。

## 三、木冰眉现身：一句「让他走」

- 天地间传来冰冷女声「**让他走**」，四周修士神色立刻恭敬，连紫袍男子也怔了一下后恭敬称是——显示**木冰眉在昆虚之境地位极高**。
- 木冰眉神色复杂，自虚无中迈出，看向王林。

## 四、师徒离别：翠玉钗与三个头

- 远处两道长虹落下，化作**周茹与小白**。周茹见到王林激动落泪；王林微笑道：「**叔叔来接你走。**」
- 周茹已长大，看出场面不寻常，未多言即走到王林身边；见王林**一头白发**，心中作痛。
- 王林向木冰眉沉声：「我要把周茹带走。」木冰眉屏退所有修士，紫袍男子临走前**大有深意地看了王林一眼**。
- 木冰眉目光避开王林，叮嘱周茹：走后修为不要荒废，每日打坐吐纳不要忘记。
- 周茹回忆：这些年师傅待自己很好，**当年若非师傅相救，便无今日与叔叔相见之日**；她以为日后仍可随时回来，木冰眉却苦涩地明白——**这一走将再无回来的机会，因为王林不会同意**。
- 赠别：木冰眉取下发髻上的**翠玉钗**，珍惜地看了一眼后挥向周茹。周茹隐约记得师傅曾说此钗是**一件极强的法宝，似为师祖传下之物**。木冰眉唤她过来，亲手盘起秀发为其戴上，神色一改往昔冰冷，柔声道：「以后要记得，你永远都是我的弟子，唯一的弟子……昆虚之境，也是你的第二个家，你走吧。」
- 王林本欲阻止周茹靠近，犹豫之后没有开口。
- 周茹泪下，退后几步跪地**重重磕了三个头**：「师尊，弟子走了。」木冰眉咬唇、心中空痛，挤出微笑点头。
- 周茹隐约感到：师傅与叔叔相识，且并非朋友而是**敌对**，此去恐再无相见之日。

## 五、道心之痛：「对不起」

- 王林以阅历看出木冰眉与周茹的师徒情分**不似为假**，却因想到**柳眉的无情道**而不敢轻信。
- 王林携周茹踏入传送阵将行，木冰眉仿若鼓起全部勇气，望着他的背影轻声道：「**王林，对不起……**」
- 王林**身子一颤**，站在阵中久久未开启阵法。木冰眉泪流、身子颤抖，反复呢喃「对不起」。
- 交代木冰眉状态：这些年心中痛苦几乎将她折磨垮，每一个夜里打坐中的苏醒都涌现说不清道不明的复杂与迷茫。
- 王林未回头，扶着胸口，心中绞痛，脑海不断浮现**记忆中第一次看见王平的画面——怨气缠绕的怨婴，凄厉中带着怨毒盯着他父亲的双眼**，是他一生无法遗忘的噩梦。
- 王林回应：「**柳眉已经死了，你不是她，不需要说对不起。**」
- 作者点题：柳眉要在王林的道心中留下自己的身影，**她做到了，一直到今天，都做到了**。

## 六、结尾转折

- 王林默默开启阵法，光芒弥漫、将要离去的瞬间，他仿若下了一个决心，**停止了继续运转的阵法**，轻声说了一句：
  > 「**你，真的想看看他么？**」
- 章末作者附言：精疲力尽，第四章只有两千字，致歉。（非情节内容）

## 七、关键线索与伏笔

1. **朱雀老圣皇的秘闻玉简**：出自联盟总部、内蕴天地炙热、碎涅不可读，指向「联盟隐秘」主线。
2. **昆虚之境欠账**：王林杀昆虚一人，以「失手」轻描淡写带过，紫袍男子留下的深意目光暗示后续追究。
3. **木冰眉与柳眉的身份纠葛**：木冰眉道歉、王林以「柳眉已经死了，你不是她」相答，二者关系（转世/残念/道心投影）在本章未挑明。
4. **「他」是谁**：王林末句所问的「他」，结合前文王平的怨婴记忆，指向王平；此为下一章的直接钩子。
5. **翠玉钗**：木冰眉师祖传下的极强法宝，转入周茹之手。
