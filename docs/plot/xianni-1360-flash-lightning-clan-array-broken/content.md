# 第1360章 精神支柱坍塌！（第九卷 云海之巅·第一更）

## 一、雷域凝聚，兵临闪雷族
- 王林自七百万天地走出后前行，身动即引天地雷霆共鸣，四周雷霆越聚越多，形成磅礴雷域。
- 随行的散灵上人两度侧目：先前与闪雷族大长老一战已让他认清王林之强，其神通“堪比夺造化之功”。
- 闪雷族十六颗修真星组成的防护大阵开启，青光由虚化实，如蛋壳般笼罩全族。

## 二、九龙归位，毁阵吞雷
- 王林在阵外千丈顿住，双手虚空一抓、猛然上掀，将平铺如镜面/海洋的雷域整个竖立于星空之中；其眉心古神星点旋转，双臂青筋鼓起。
- 号令原文：“融入我元神的太古雷龙魂魄，以我王林之名，命你等，八龙合一再加上我之元神雷龙，给我九龙归位，毁阵吞雷。”
- 王林化电冲入雷域，一条近十万丈的青鳞雷龙自雷域内咆哮而出，雷域随之消散。
  - 来历：王林吞噬八条太古雷龙魂魄融入元神后虚幻而成。
  - 虚幻而蕴含难以想象的雷霆之力；神识可见其内九条魂魄相互厮杀吞咬，一条最强、八条被压制。
- 王林踏于龙头，一指之下雷龙连撞大阵，蛋壳般的护阵裂缝密布，终告崩溃，破开巨大缺口，龙头径直探入。

## 三、心理战：精神支柱坍塌
- 破阵同时，王林冷声宣告：大长老已肉身崩溃、元神被其生擒，闪雷族不灭雷霆亦受创逃回。
- 闪雷族一方的反应（不信 → 自我说服）：
  - “大长老修为通天，绝不会有事”，猜测是被引开或另有帮手。
  - “在我太古星辰除了第三步大能外，无人可以对抗”；即便第三步大能来临，大长老神通法宝众多亦性命无忧。
  - 有人放言：若大长老败落，不需王林动手，立刻自毁修为而亡。
  - 唯一的裂痕：方才不灭圣雷突然离去、归来时虚弱不少，且防护大阵不受控地自行开启。
- 章名所指：大长老即全族精神支柱；王林随后挥出昆极鞭，金光万丈，鞭上卷着闭目的大长老残破一缕元神——实物证据摆出，信念根基崩塌。

## 四、战场分割
- 闪雷族天人衰劫修士共十一人，含两位天人第四衰。
  - 七人（由一位天人第四衰带头）直奔散灵上人——族人称“那天人第四衰的光头修士才是劲敌”。
  - 另一位天人第四衰带人阻拦王林。
- 闪雷族修士双目通红、不畏生死，甚至展开自爆族印意图困杀。
- 王林不愿纠缠，摇头道“没有了大长老，闪雷族无人能阻我半步”，目标是以最快速度去吞噬不灭之雷。
- 敌方对王林的判断：“此人修为只不过碎涅，不知以何方法可以发挥出天人衰劫之力。”

## 五、伏笔与承接
- 承前：王林夺舍于非肉身潜入闪雷族，破圣地防护时元神飞出露出本体，已被闪雷族看见，故此刻现身即被认出。
- 待续：王林下一步直取不灭之雷（不灭圣雷）；散灵上人怀仇恨入族，其恩怨未了。
