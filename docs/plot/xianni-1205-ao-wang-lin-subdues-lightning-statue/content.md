# 仙逆 第九卷 云海之巅 第1205章 傲！

## 一、前情与因果

- **苍松子的传承来源**：王林盘坐石像头顶时确认，苍松子肉身恢复、眉心出现闪电印记，皆与此石像密切相关。苍松子的其中一个**血婴**在感悟中修炼石像眉心闪电印记留下的感悟，凭**九倍领悟之力**勉强得到印记的**一部分传承**。
- **战利品的转移**：这部分传承在**王林与苍松子第二战**中，被王林以操控天地雷霆的神通吸收绝大部分，凝聚于**右目**。

## 二、两条道路的对立（本章主题：傲）

| | 苍松子之路 | 王林之路 |
|---|---|---|
| 姿态 | 视石像为神灵，膜拜中修行 | 逆天而行，要闪电屈服 |
| 方法 | 以元婴感悟其功法、顺应闪电含义、借取雷霆 | 拒绝感悟，直接吞噬、压服、剥夺 |
| 风险 | 无危险，资质足够即可获得 | 与雷灵正面对撞 |
| 定位 | 如仆人般哀求施舍 | 古神的尊严与逆修的骄傲 |

王林的心念：他连天道都敢逆，一生与天斗、逆修成道、与天劫争辉，绝不膜拜区区石像——纵然其中闪电之力足以惊天动地、更可引动**封界第七灵**（该灵即便对王林的古神肉身也有伤害力）。

**古神的依据**：太古万族无可与古神一族相比者。王林从**灵儿**处知晓，强如**月噬族**，早年也不过是古神一族的仆从之流；月噬族尚且如此，这拥有闪电印记的界外之族，同样要向他屈服。

## 三、夺雷之战

1. 王林散开心神笼罩石像，右目电光离体，石像眉心闪电印记剧烈闪烁、电光弥漫、雷鸣轰响。
2. 王林以**太古雷龙元神**号令天地之雷，但石像之雷沧桑桀骜、不受号令，与其操控之雷不断撞击，石像四周遍布雷球与弧形电光——这是一场**雷与雷之间的操控权之争**。
3. 王林抬手一拍石像头部：石像不碎，反爆发出直冲天际的闪电，化作**雷光之龙**吸尽四周雷霆，疯狂扑来。
4. 王林右目电光冲出，太古雷龙元神自眉心显现，与雷光之龙撞击并疯狂吞噬；眉心漩涡露出**古神星点**，古神之力充斥全身，右手一抓幻化出**巨大古神手臂**扣住雷龙、狠狠一捏逼出其体内雷霆，随即元神一口吞下。
5. 右目雷光暴增数倍，王林全身模糊、唯右目光芒逼人，宣告：「但凡存在于天地之雷，皆需听我之号令」，四散雷电尽归右目，凝成**闪电印记**。
6. 石像自双脚起遍布裂缝、缝中闪电游走直扑头顶，在王林体外形成**方圆百丈的巨大雷光电球**并疯狂收缩；王林以元神咆哮相抗，雷球在其身外一丈处生生停顿，再不能进一寸。
7. 王林起身踏空，「屈服，或者毁灭」——他判明这些雷电是石像之人死后**意念所化的雷灵**（有意志便是灵）。在其雷威与古神气息冲击下，雷灵屈服，化闪电汇入太古雷龙元神，元神骤然庞大，石像颤抖欲崩。
8. 王林宣判：「你之一族，从此之后在我面前，剥夺行使雷之权利」——元神与右目雷光融为闪电印记，打入石像眉心图腾。

## 四、石像来历（设定）

- 石像为**太古之民闪雷族先祖**，虽死而一生与雷为伴、自身几乎已然成雷，化作眉心闪电印记，不会轻言屈服。
- 传闻闪雷族先祖本为**一道雷霆所化**，此雷逆天，不受天道屈服。
- 规则：世人**膜拜**于他，可有资格获雷之权利；**反抗**于他，则被雷霆灭灵。
- 王林之所以能以修为不足之身相抗，因其元神为**太古雷龙**——替天道行使雷之权利者；而王林不信天道，抢雷权，以自身为道。

## 五、石像双目中的上古异象（关键伏笔）

闪电印记落下瞬间，石像双目发亮，王林于其中看到一片星空：

- 一座**磅礴大阵**，其大足以弥漫星域，死死封锁。
- 阵外：**密密麻麻无数奇异之人**，穿着古怪、显然并非修士，冷漠中带着嘲讽与不屑地俯瞰阵内，如高贵者看蝼蚁。
- 阵内：仙气缭绕、元力回荡，**无数上古炼气士与仙人**疯狂攻击阵法试图破阵；阵法诡异坚不可破，有仙人不惜自爆亦无法撼动半点，绝望悲哀笼罩。
- 阵中有**九道光芒**：其一为**开天之斧**，所过之处闯阵者一一崩溃死亡（众多炼气士自爆试图封住此斧仍失败）；其一为**闪电**，所过之处修士、仙人全部死亡。
- 一名被闪电击中的仙人临死疯狂咆哮：「不甘心！吾不甘心！终有一日，吾辈修之后人，必将破开阵法，让你等外民万灵灭绝殆尽！让你界外血流成河！」

## 六、要点归纳

- 王林由此获得完整的闪电印记（右目），并在雷之权柄上凌驾闪雷族传承之上。
- 本章确立三条设定线：**古神一族凌驾太古万族**（月噬族亦为仆从）、**闪雷族为界外之族**、**上古仙人与炼气士曾被界外之民以大阵封锁屠戮**——为后续界外/封印母题埋线。
- 王林当前行走云海星域时使用化名『吕子浩』（自第1063章由吕烟菲奉上），本章文本内以王林本名叙述。
