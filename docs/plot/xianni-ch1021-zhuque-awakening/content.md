# 第1021章 朱雀觉醒（第八卷 联盟隐秘）

## 一、以火补元：黑塔内的吸收循环

- 火焰般的元力弥漫王林元神之上，太古雷龙般的元神在其操控下强行吸收，剧痛涌现，王林咬牙忍受、忘却时间。
- 痛楚渐消后，化作火焰的元力与元神融合并重新流转；王林睁眼，身外三丈火海顺汗毛孔收缩入体，与运转的元力融为一体。
- 结论：“元力增长了一些，这个方法虽说危险，但却可行。”
- 此后进入循环：踏出黑塔 → 从火海中抽取火焰 → 退入黑塔盘膝吸收/吞服 → 与体内元力融合。
- 摄取量级递增：火苗 → 婴儿拳头大小火焰 → 人头般大的火球（不再吞下，改为深吸尽收）→ 身体般大小的火球。

## 二、外貌与体质的剧变

- 先前魔气侵蚀使面部消瘦；吸收焚天火海元力后，全身皮肤密密麻麻龟裂，极为可怕，熟人难以辨认。
- 头发干枯无光；唯双目越来越亮，与之对望者心中自生高温火焰、如被焚成灰。
- 两个月前龟裂碎开露出新肉，之后又再次密布裂痕。
- 关键异变：数日前眉心出现惊人变化，源自**当年的朱雀印记**。
- 王林自察：体内因火焰而蕴含一股炙热之力，且“似乎与青霖焚天之力有些不太一样”；并意识到“吸收越多的火焰，对我的好处就越多”。

## 三、深入火海：四个月的极限推进

- 王林能在焚燃整个黑沙荒漠的火海中行走如常、神色平静——文中明言**即便凌天候也无法做到**。
- 推进法：行至可承受极限即盘膝坐下，双手引出两道火焰交缠成身体大小火球一口吸尽；三日后火焰外爆、皮肤干裂更多、双目更亮，气息与四周火海相融、蕴含难以想象的高温。
- 每次自语“还是差了一些”，随后继续前行；如此往复，**四个月**后已远离黑塔，所在处火海滔天无边、热浪可焚化一切生命。

## 四、朱雀觉醒

1. 判断“这里的热度，应该够了”，深吸一口气引火海涌入口中。
2. 与此前不同——火焰不再融入元力、不与元神融合，而是**尽数灌入眉心**。
3. 数月来渐渐栩栩如生的朱雀印记，正从印记之形飞快化作一头朱雀，如火焰朱雀成长酝化、将要破印而出。
4. 三次加码（皆因“不够”）：
   - 双臂横扫拨动四周火海，火焰顺汗毛钻入并全部冲向眉心，印记散发浓郁红光；
   - 一跃升空，地面火海随之涌入其身，惊天动地；
   - 双手向大地一抓如环抱火海，体内元力轰然而出在天空造出一片火海，与地面火焰互映吸撤，四周无尽火海如遇黑洞般把黑沙荒漠的焚天之火全部吸来。
5. 眉心红芒达到无法想象的程度，一头**火红色朱雀**幻化而出，发出可破开一切虚空的惊天嘶鸣——凤鸣、朱雀惊天之音，即王林**本名朱雀觉醒**之鸣吼。
6. 朱雀出现的一刻，黑沙荒漠内所有焚天之火沸腾般疯狂，无边火焰瞬息直奔王林身前的朱雀。

## 五、设定要点：朱雀圣宗序列与四圣

- 王林身为**朱雀圣宗**之人、**朱雀序列**之一。
- 印记觉醒、朱雀本灵幻化，在昔日**四圣宗**内亦属惊天动地的绝顶大事。
- 规则：任何圣宗内但凡有序列者可以朱雀觉醒，此人若无意外**一定是未来的四圣之一**。
- 唯一性：此刻的王林“就是朱雀序列，没有之一”——在他之前、在他之后、在他尚未成为四圣的时间内，其余序列者皆无印记觉醒。

## 六、外界震动

- 朱雀之音传遍整个瓶中界，**瓶中另外一界**所有进入此地者无不心神震撼、尽皆听闻。
- **凌天候**：正在其所在之界的黑塔内闭目打坐，天地轰然震动乃至颤抖，猛然睁眼、目露难以想象的震撼：“朱雀之音——”
- **天运子**：一身白衣浮于半空，仰望天空右手掐算，目光越来越亮、嘴角含笑，喃喃“原来是这样”；话未说完即被朱雀之音撕裂回荡，**推算轰然崩溃**，所在之界剧烈震动、天地色变风云骤散，面色极其罕见地一变：“不可能！”

## 七、脉络意义

- 王林把“被迫吸火续元力”转化为主动的朱雀本源修炼路径，元力恢复之外额外获得炙热之力与印记觉醒。
- 朱雀觉醒确立其“未来四圣之一”的伏笔，同时惊动同处瓶中界的凌天候与天运子，天运子的“原来是这样→不可能”暗示其推算之外出现了变数。
