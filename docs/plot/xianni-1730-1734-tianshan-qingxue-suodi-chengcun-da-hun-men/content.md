# 仙逆 第1819-1820章：天山的雪 / 大魂门

## 一、分身苏醒：破仙罡法则，重得缩地成寸

- 王林在**苍龙宗后山洞府**盘膝**七个月**后，终于**唤醒了虚无层内的分身**。
- 分身苏醒的刹那，一股说不出的**明悟**经由心神从遥远的分身处传来，笼罩王林：
  - 困扰他的**天地隔膜骤然松动**，其内的**仙罡法则**被清晰破开，如同消失。
  - 明悟看似清晰、细想却模糊——因为**分身尚在成长之中**；一旦分身完全壮大，仙罡法则的一切他都能清晰无误。
  - 那股磅礴压力如冰层融化、裂开无形缝隙，**神识眨眼间完全融入天地**，不再是强行挤入。
- 神识融天的同时，**肉身也消失、与天地融为一体**，王林由此找回了在**洞府界**时的**缩地成寸**之感（久违之能）。
- 王林自评：「分身刚刚成长了这些日子，就可以带给我如此强大的助力……若是时间再长一些，我的这具分身，将是最强之体。」

## 二、天山一往返：青雪落地，杜青破胆

- 第一次缩地成寸时王林并无方向，随意迈步熟悉，出现在**天牛洲极西的天山**，见漫天飘落的**青色雪**。
- 归来时心存苍龙宗之象，直接现身于**苍龙宗后山、杜青身后**；**一来一回不足半柱香**。
- 杜青视角的经过：
  1. 王林缭绕七个月的神识**骤然无影无踪**（非收回，而似与天地融合），杜青全无心理准备。
  2. 冲至后山遍寻不着，洞府内打坐七个月的王林如同蒸发；杜青反复散开神识，一无所获。
  3. 杜青断言「唯有**空劫巅峰**的老怪才能神识融入天地」，故认定王林做不到。
  4. 王林自其身后现身：白衣、从容、身后波纹回荡，身上散出天地寒气，被苍龙宗气息一冲才慢慢消散。
  5. 杜青自我说服为「**瞬移**」「必是屡败后脸面挂不住而收场」，正要离去，却看见王林所站草地上有**青色的积雪**在阳光下晶光闪烁、缓缓融化。
  6. 全天牛洲唯极西天山有此青雪，而杜青**全力疾驰往返天山也需约数月**。杜青面色惨白，沉默良久喃喃：「天山之雪……此人天骄。」
- 结果：杜青七个月来的不屑与轻蔑烟消云散，转为**无尽的神秘莫测与恐惧**——这恐惧与修为无关，而源于未知。王林离去时脚下波纹回旋、身形骤然消失，比任何威胁更具震撼。

## 三、地火收割与旧事牵念

- 杜青半个时辰后来拜见，奉上两样东西：
  - 宗门弟子取回并封印的一些**地火（支脉）魂**——因蕴含意志不多，王林吸收后对本源真身凝聚帮助不大。
  - 一张**完整的天牛洲地图玉简**，标记了多处地火支脉、子脉所在——对王林极为有用。
- 王林明言火本源真身「越是后面越艰难」：**头颅的凝聚所需已非单纯火本源，而更多是一股火的意志**。
- 杜青知王林所谋却不参与、也不通风报信（对王林仍有所图）；王林留言：「杜道友所帮之事，王某记住了，日后若有机会，定回报于你。」
- **王林离去第七天起**，天牛洲各处**地火子脉接连轰鸣崩溃**，火焰波动弥漫全洲，天地气息炙热，吸入令人烦躁；各宗派派出弟子长老查探，赶到时**尽是废墟**，毫无线索。
- **半个月后**，王林走出天牛洲一处**被黑雾缭绕的山峰**——此地曾有一宗派名为「道宗」。他神色惆怅，说此处「一定要来」，因为在这里似能感受到**洞府界的气息**，以及**玄罗多年的等待**。回望黑雾山峰、沉默半晌、轻叹离去。
- 离去背影萧瑟孤独，心中自问：「**司徒、清水、还有李倩梅，还有那些转世投胎的……你们如今在哪里**」

## 四、天山之巅遥望大魂门

- 一天后，天牛洲极西之地、**大魂门笼罩范围内**的天山之上，一个**白衣白发青年**（王林）立于山顶，目光穿透青雪望向**天牛之西**：山峦无数，最深处**一座赤红色山峰直插云霄**。
- **大魂门**形貌与实力：
  - 坐落群山之间，山峰弥漫赤红光芒，远看如一座**燃烧的火焰山**。
  - 外围天地波纹回荡，内蕴**灵魂之力**，幻化出无数凄厉之魂无声嘶吼。
  - 是**天牛洲最强的两个宗派之一**。
  - 群山中藏有**不下十万修士**，隐匿不见踪影；另有多股极强本源气息，代表**一个个踏入第三步的大能**。
  - 因天山之高与大魂门波纹造成视觉差，看似不远，实则飞行也需数日。
- 王林评价：「仙罡大陆的……大魂门的确很强，此门一宗之力，就可横扫**洞府界**了。」

## 五、地火主脉的秘密与王林的决断

- 王林闭目散开神识，感知到：
  - 大魂门群山之下藏着**整个天牛洲的地火主脉**，此脉散出无数支脉铺展全洲地底深处。
  - 主脉之上存在**惊人的火的意志**，不容半点侵犯；**唯独在大魂门山峰所在，这股意志削弱了大半**。
  - 大魂门山峰下，主脉从地底深处**透出地表**——与其说山峰是大魂门山门，不如说那里是**露出地面的地火主脉所化**；此乃天地造化自然衍变而非人为，只能说大魂门选址极为巧妙。
- 决断动机：王林近日吸收大量子脉，体内**火焰本源已达一定程度的饱和**，再吸收对真身已无作用（如同同品质丹药服多则效减至无）。
- 故即便对方是庞然大物，为了**火本源真身**，王林也要**虎口拔牙**，前往大魂门吸收**地火主脉**。原定步骤：先吸尽其余支脉子脉，看火本源真身最终能凝聚到何种程度，再动主脉。

## 概览

第1820–1821章：王林为地火主脉（乃至其意志）而潜入大魂门，全程以隐匿、观察、破禁的方式无声推进，最终在赤红山峰顶洞府与旧识矾珊璐重逢。

## 一、抵达与踩点

- 王林自天山飘落，行走间身影闪烁、每闪一次即跨无尽距离，数个时辰走完寻常修士数日路程。
- 大魂门所在群山之外，天地间魂的波动极密集，隐现无数排斥之力阻人入内。
- 王林叹惋：鬼脸帆困于储物空间无法取出，否则或可借之入大魂门。
- 遂完全隐匿气息（形同凡人），盘膝坐下后身体模糊化作一道烟丝，飘忽缭绕等待。

## 二、破阵思路的取舍

- 大魂门山门禁制大阵极厉害，非本门弟子一触即被察觉；唯有弟子进出、阵法波动的一刹那可乘。
- 常规做法是融入外出弟子体内随之入阵，但大魂门以『魂』立宗、对魂理解透彻（多重幻术神通即为明证），极可能在王林察出端倪前先识破其身份。
- 此法只能试一次，王林不愿冒险，宁可依仗自身修为与对禁制的理解。

## 三、二十天的观察

| 时段 | 观察所得 |
| --- | --- |
| 前3天 | 阵法波动314次（314名弟子进出），只看不动 |
| 至第10天 | 近千次进出；看出阵法波动随弟子身份而变；一千多名不同修为弟子的共性——灵魂如旺盛之火，轻易不起波动 |
| 至第20天 | 仍不出手，继续观察 |

凭借身上罕见的**禁制本源**，王林有足够时间与耐心寻找阵阵破绽。

## 四、入阵

- 第二十天，一名外出弟子身子融入群山阵法、阵纹回荡之际，王林所化烟丝骤然冲出。
- 钻入的一瞬：禁制本源扩散抵消阵法，同时以二十天所见为本，数息内模拟变化数百次弟子形态。
- 结果：入阵不引起阵法丝毫变化，所有变化都被藏进前一弟子入阵的波纹里。

## 五、赤红山峰的神识扫描（惊险一幕）

- 越近赤红山峰，地火主脉气息越清晰。
- 远处三道长虹（两女一男）直奔赤红山峰而来。
- 赤红山峰内骤起一道极强神识，扇形铺展横扫；其气息**略显阴柔** → 王林判定为**女修**，修为已度九次玄劫、真正踏入**空劫初期**。
- 神识扫来同时，群山大阵立刻波纹回荡、封锁全山，王林大惊疑似暴露。
- 应对：向后倒卷与神识同速堪堪避开，随即果断冲入三人中的**男子**体内——理由是散神识者为女修，此等修为的女子大多高傲，细搜男性弟子身体与看其赤身无异，故不会仔细搜寻。
- 神识自该男子体内一扫而过、未做停留；扫遍群山后散去，大阵解除封锁恢复运转。
- 王林结论：**并非被察觉，而是大魂门有大能之辈不定时散出神识防范的习惯**。此后他在男子体内凝聚成气旋、以禁制包裹藏身。

## 六、借宋英之身入赤红山峰

- 三名弟子的差事：为诸位师姐送**解魂果**，先送『炎栾老祖』处，再赴其他主峰，不得耽搁。
- 分派：女修**宋英**独往赤红山峰；另一女与王林藏身的男子绕开赤红山峰去往远处。
- 王林散出烟丝离开男子，转而缭绕在宋英衣衫上同往。
- 山峰外有模糊光幕防护；宋英取**红色玉简**按向光幕时，王林分出一部分烟丝直扑玉简，全力急研其内禁制（玉简内传出咔咔轻响），旋即收回神识。
- 宋英踏入光幕的刹那，王林所化烟丝以禁制本源**模拟出一枚玉简的样子**，无声无息随之入内。
- 光幕内弥漫大量**火本源之力**，一个呼吸即可让王林本源壮大一丝——王林心中兴奋；但因内有空劫初期女修，仍忌惮不去，继续栖息于宋英衣衫。

## 七、十九洞府与顶峰粉衣女子

- 宋英不适应此地火热之力，一进来便香汗淋漓。
- 山峰共**十九个洞府**，每个洞府内皆有一股生机弥漫（各住一名大魂门弟子）；除最顶峰洞府外，宋英逐一送去仙果。
- 最后至顶峰洞府外恭敬禀报『解魂果送来了』，内传轻柔声音『放下吧』——此声一入耳，王林心神一动：**「是她」**。
- 宋英放下九枚青白色、散寒气的解魂果后离去；王林趁机自其衣衫转附于一枚仙果的**叶片**上，随吸力被卷入洞府，落于石桌。

## 八、重逢矾珊璐

- 洞府内荧光缭绕，粉衣女子盘膝而坐，相貌极美、气质风华绝代，此刻眉头微皱、心事低沉，并未吐纳。
- 她欲闭目打坐之际，心神中响起一个平静的声音：**「矾珊璐」**。
- 矾珊璐猛然睁眼，衣衫下右手隐隐一颤，抬手一挥凭空生出**朦胧雾气**封死整个洞府，喝问：「王林，你在哪里」——神色镇定，但右手的颤抖已泄露内心震动。
- 王林不急现身，先审视那雾气：作用是封死一切气息、使外界无从感知，且是矾珊璐的**下意识行为**（王林习惯从细节看全面）。
- 略一沉吟后，王林自仙果叶片散出烟丝，在矾珊璐身前凝聚成身，微笑道：**「好久不见。」**余光随意扫过那朦胧雾气。

## 关键判断与手法小结

1. 以时间换情报：二十天不动手，只为吃透阵法波动与弟子共性。
2. 一切依托**禁制本源**：抵消阵法、模拟弟子、模拟玉简。
3. 由细节反推对手：从神识阴柔判性别修为，从雾气判断下意识与心境。
4. 目标未改：地火主脉（及其意志）用以炼制更高品质丹药；赤红山峰的火本源之力是意外之喜。

# 第1821-1823章 大魂门炎脉山：地火主脉之争

## 一、洞府重逢（第1821章）
- 王林在大魂门炎脉峰矾珊璐洞府中与其重逢。洞府朦胧雾气为大魂门核心弟子闭关时所散，雾气一出，其师尊短时间不会神识扫来，故此处安全。
- 矾珊璐对王林心怀感激与钦佩：洞府界一幕幕已成其人生一部分，若非王林，她无法回到家乡仙罡大陆。
- 矾珊璐提及三年前与归一宗云逸封见面时曾谈起王林，奇怪王林早该进入仙罡大陆却毫无音讯；王林答「途中出了一些意外」。
- 王林虽略放心，仍保持谨慎：若矾珊璐另有心思，他会毫不留情出手。

## 二、潜入地火闭关石室
- **王林所求**：借此地「地火主脉」修炼一门神通，可能对主脉造成影响。
- **矾珊璐的安排**：带王林前往最接近地火脉的地火闭关之地，对外宣称自己闭关；师尊长期闭关、只不定时散开神识且不查闭关弟子；顾虑在于姐姐矾珊梦亦在炎脉山且被师尊看重。
- **潜入方式**：王林化作烟丝融入矾珊璐衣袖、缭绕其皮肤，既隐藏行迹又可随时察觉其异动。
- 矾珊璐一路畅通无阻——同门皆不信有外人能在师尊眼皮下进入，且她身为核心弟子地位尊高。

## 三、地火闭关石室设定（第1822章）
- 由师尊自**地火主脉**内生生开辟，赤红石门散发无尽高温，寻常修士近之血液如燃。
- 在其内打坐等同于在地火主脉体内打坐。
- 除**水本源**外，其他一切虚实本源皆可在此修炼。
- 火焰意志挤压形成压力，产生**类似时间改变**的效果：内修一日常抵外界多日。
- 长条形，共**三十七丈**，一丈为一种程度，越深越骇人；为炎脉峰最宝贵之地，仅核心弟子可入。
- 开门时火海化火龙扑来，矾珊璐发一奇异之音「**斫**」将其击溃。
- 王林一口吞下热浪即化火本源滋养全身，感叹「仅这一口就相当于十多条支脉」，直入第三十七丈最深处盘膝掐诀，双手按地。
- 约定：矾珊璐三天后自行离去，王林留驻更久，以免变故牵连她。

## 四、吞噬地火主脉意志
- 三天后王林气息尽消、与地火主脉融为一体，神识穿透石室直入主脉深处。
- **目的**：火本源已饱和，须**吞噬地火主脉的意志**、成为**天牛洲地火之主**，本源真身方可彻底凝聚。
- 王林神识化作本源真身（头颅仍为朱雀之形），迎着意志展开急速吞噬。
- 主脉真相：一条无尽范围、盘卧大地深处的庞大火龙龙魂，气息沧桑腐朽，无灵智，唯有如天威般的意志。
- **真身凝聚进度**：下巴 → 口唇 → 鼻子 → 双眼 → 额头依次化为真正皮肤，最终仅余朱雀雀羽般的长发未变——「只剩下头发，我的本源真身就可以完全凝聚出来」。
- 又三天后黄昏，王林寻到数万丈大小的苍老炎龙之头，本源真身冲入龙魂头颅内盘坐吞噬。

## 五、惊动大魂门（第1822-1823章）
- 龙魂惊天咆哮，炎脉山剧烈震动、山石脱落、山顶崩溃、火海冲天。
- 炎脉峰顶白袍少妇（矾珊璐与矾珊梦之师尊，**空劫初期**，额贴五星晶片，容颜惊艳）睁眼察觉，瞬移至山下轰开石室赤红大门。
- 王林早有准备：留在体内的部分元神借火焰卷身与大地融合，顺地火主脉遁向本源真身所在。之所以拖到少妇临门才遁，是因本源真身未吞噬足够火意志前，肉身无法承受主脉炙热。
- 大魂门内数道强者气息升起，神识笼罩炎脉山；弟子纷纷出关观望。**大魂门共有四十九座主峰**，炎脉山仅其一。

## 六、地底追逐与调虎离山（第1823章）
- 少妇入地追击。地火主脉内缭绕王林本源真身之意志，王林如鱼得水越行越快，少妇反受干扰难尽全力。
- 少妇祭青铜古镜，喝「**古镜道纹，化天地之影，追杀此人**」，镜中黑气化巨大**鬼脸**（大魂门鬼脸神通）暴追而至，逼近至三十丈内。
- 王林前踏一步、身前起波纹而**瞬移**遁走。少妇震惊——她自己曾试而不能在充满地火意志的主脉内瞬移，但判断王林瞬移耗仙力巨大，欲耗其力。
- **王林的算计**：心神一分为二（一份在本源真身吞噬，一份操控肉身），逃遁方向暗中细微偏移，并非通往真身所在，从而以本尊肉身吸引追击、为真身争取时间。
- 少妇终因「追击上了震动却不减反增」而醒悟：「此人还有分身在更深处」，遂放弃追击肉身，直奔地火主脉深处本源真身而去。王林发觉后从容一笑——已成功拖延了片刻时间。

## 七、姐妹对峙
- 山外围观弟子中，矾珊梦传音质问矾珊璐是否带外人进入石室。
- 矾珊璐冷然反驳：洞府界中被姐姐利用如此岁月（矾珊梦为操控王林连亲妹也一并设计），如今还要被诬陷。矾珊梦沉默不再开口。
- 矾珊璐心中苦笑：王林无论去哪都会引起惊天动地的变故。

## 待观察
- 少妇转向本源真身，王林能否在被截住前完成头发（雀羽）部分的最后凝聚。
- 矾珊璐是否会因此事暴露受牵连。
