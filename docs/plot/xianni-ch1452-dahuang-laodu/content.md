# 第1452章 大荒老毒

## 一、蚊兽饮血河，军团壮大
- 十万蚊兽呼啸弥漫，带头者为王林的**蚊王（虹王）**。此蚊王极忠诚，视王林如父；口器在王林身上摩挲，凶焰之外独对王林流露依恋欣喜。
- 王林一指下方血河，蚊兽俯冲吸血：身躯砰砰暴涨一倍、血光缭绕。**血河之血对凶兽有大益，可促生长**，全部吸收可令十万蚊兽战力大增。
- 半个时辰后地面河流干枯、半滴不剩。

## 二、古之三族尸骸与古魔分身之念
- 古神、古妖、古魔三具尸骸**已彻底死亡，只剩躯壳**，内部完全死亡。
- 王林手按古魔尸身，元力流转后自语：**“若能发现没有彻底死亡的古魔躯体，或许我古魔分身将会成功”**——点明其古魔分身尚未成的目标。
- 此地一切被搜刮殆尽，连**古神背部托着的千丈平台**也被强行搬起收入储物空间；但王林**未收走古之三族尸骸**，任其保持万古不变的狰狞跪姿。

## 三、离开封印之地，循三图路线深入
- 王林回到**抢自灵动上人的紫色三阶碎石墓台**，十万膨胀后的蚊兽环绕。
- 踏墓台冲天，从一道隐藏裂缝撕开离去，外面是**浓雾之地**。
- 脑中浮现**三幅连接在一起的地图**，据此寻得通往**古墓深处**的路线，全速前行。
- 雾中藏有大量**人形凶兽**，未及近身即被蚊兽撕裂。

## 四、强夺二阶墓台，符文逼近四阶
- 遇一支约三十余人的修士队伍：除一人为二阶墓台外，余皆千丈平台，正被近万人形凶兽围攻苦战。
- 王林三千丈巨大墓台现身，**一头白发、一身白衣**；持二阶墓台的老者见“三阶墓台”瞳孔猛缩。
- 王林挥手放蚊兽：十蚊攻一兽，瞬息屠尽万头凶兽；**蚊兽死伤近万**，存活者分噬凶兽、生机大涨。
- 蚊兽转而围困三十余修士。王林条件：**“帮你等消灭了凶兽，需把二阶墓台给我”**。老者衡量后弃台跃走。
- 二阶墓台上共有**符印312个**，王林隔空一拍尽数震出、融入自身三阶墓台；空台缩小崩溃。
- 王林墓台符文已达**九百多个**，紫色近黑，**隐有向四阶进化之象**。王林自忖“堪为三阶，四阶不知需要多少，应该快了”。

## 五、古之墓枷：万丈巨手掳人
- 王林去而未远，忽觉异动回身，四周蚊兽齐齐颤抖后退、嘶鸣带惧。
- 那群修士身下雾浪翻涌，一只**万丈粗细的巨大手臂**破雾而出，五指如山，一把抓碎平台、将三十余人尽数攥走，缩回雾中，前后仅瞬息。
- 王林在巨手内感到**类似古神的气息**，因其出现太快无法细析；判断**其一抓之力无法抵抗**。
- 王林定名：**“古之墓枷”**。此地诡异与神秘愈发浓重，他更加谨慎前行。

## 六、目标：下一处封印之地与封灭族女子
- 依地图，前方尚有一处**已被人打开的封印之地**，内封同为**四品道灵**；找到即验证方向无误，可续往墓地深处。
- **封灭族女子**：王林曾在其身上暗留印记，可感其位置，她亦在前方。王林明言“此女我有大用，定要找出其**两次不死的隐秘**，若能加在我身”。

## 七、前方战场：大荒老毒 vs 妙音
- 该封印之地内阴森狂风，半空两道人影交错厮杀，下方近百修士混战；**封灭族女子**满脸煞气，身边死伤近十。
- **大荒老毒**：“妙音，今日你敢抢老夫道灵，老夫本尊便立刻杀入**音海**，与你本尊决战。”
- **妙音**回击要点：
  - **大荒老毒是分魂来此，妙音是分身来此**，故在此地大荒老毒非其对手；杀其分魂，其本尊未必敢去音海。
  - 大荒老毒性格古怪，**太古星辰内除了那走不出颠落的老鸟外，再无第二个交好道友**，古墓内更无人相帮，无从争夺道灵。

## 关键悬念
1. 古魔分身需一具未彻底死亡的古魔躯体——后续取向。
2. 墓台四阶进化的门槛与效用。
3. “古之墓枷”的本质及其与古神气息的关联。
4. 封灭族女子“两次不死”的隐秘。
5. 四品道灵归属：大荒老毒分魂 vs 妙音分身。
