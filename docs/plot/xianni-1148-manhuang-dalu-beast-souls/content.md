# 第九卷 云海之巅 · 第1148章 蛮荒大陆

## 一、三日炼丹：废尽一院药草，只得一枚三阶丹

- 孙芸此前的预言应验：**三天内王林炼丹十六次，除最后一次外全部失败**。每次失败后他默默寻找原因，随后走出屋舍继续摘取药草。
- 生机勃勃的药院三日间几乎成了荒凉之地。这片药院凝聚孙芸多年心血，她平日自行炼丹都极为节省地摘取。孙芸眼圈发红，宁可发生丹炸毁掉大半药院，也好过如今这般被生生折磨。
- 孙芸终于忍不住推门而入，见「曾牛」盘膝坐地、手拿一粒成品丹药**微笑**，怒火腾起；但顾及自己对其修为的猜测，强压怒意、婉容柔声道贺，请求一观丹药。
- **炼丹要诀**：云海炼丹之术需与兽魂融合，其中诸多注意事项**玉简上并无说明**，须炼丹者自行明悟。那道兽魂在十五次失败中经历十多次反复融合，痛苦甚至超过死亡，恨不得王林立刻成功。
- 王林摸了摸鼻子，余光扫过近乎荒废的药院，**「以他一千多年的脸面」**也有些挂不住，遂挥手把丹药抛给孙芸。
- **结果**：仅是一枚**三阶丹药**（阳实境界修士所需，本身已属珍贵）。而孙芸认为，这一整院药草足以炼出**四阶丹药**，若交由**李师叔**炼制，甚至有一丝可能成功炼出**五阶丹药**。
- 孙芸尖叫怒喊「曾牛，你还我药草」，抬头时屋内已空——王林已不告而别。

## 二、离开莫罗：星图与「蛮荒大陆」设定

- 王林身影在**莫罗大陆上空**幻化而出，苦笑摇头（「罢了，不就是一院子药草么」），化作长虹直冲天际，破开莫罗大陆的防护光层，眼前是一片充满星雾的**云海**。
- **归元宗道观玉简**中除炼丹术、灵兽之术外，还藏有莫罗大陆所在**云海五阶星域的星图**。
- **蛮荒大陆（设定要点）**：
  - 存在于云海五阶星域浓浓星雾之内，区别于可供修士居住的大陆；
  - 与**雷、雨两域的蛮荒星**类似，但**没有黑塔防护**，完全被星雾弥漫；
  - 是凶兽的巢穴聚集地，凶兽众多；
  - 极为珍贵的药草往往就生长于此。
- **取舍**：距莫罗较近的蛮荒大陆凶兽渐稀（多为低阶乃至不入阶），药草已被采尽，且已沦为**归元宗弟子的试炼之地**，不入王林之眼。王林的目标是**更远、修士罕至、保留大量药草、凶兽更强**的蛮荒大陆。

## 三、星雾行路：神识压制与蚊兽群

- 星雾如云，既遮视线又使神识无法广布；王林对云海星域不熟，前行速度一度放慢。
- **神识标尺（重要设定）**：此地**窥涅修士**神识只能散开**百丈**左右；**千丈**之距**唯有净涅修士**方可做到。王林此时神识散开**不到千丈**。
- 途中所见奇异凶兽（皆阴森诡异）：
  1. 长满鳞片、巨口利齿、腥气弥漫的**鱼形凶兽**；
  2. 形似龙但身长仅数十丈、速快如闪电的**红色群居凶兽**（一出现数十上百，如红色电闪穿梭）；
  3. 形似王林在**罗天**所见**幽冥兽**、但缩小无数倍（仅数百丈）的凶兽，速度不快，红色闪电凶兽亦要避让；
  4. 形如**卢迪灵兽**般的**蝌蚪状黑色凶兽**，若隐若现，散发威压。
- 这些凶兽闯入王林神识范围便身子一震、连忙退开远避。
- 王林右手一挥幻化**储物裂缝**，放出**十几只蚊兽**；蚊兽嘶鸣雀跃，尤其他的**紫色蚊兽（紫蚊兽王）**四下飞舞。王林坐上紫蚊兽王背，蚊兽不待吩咐即带同伴穿梭星雾。
- **时间感**：星域内无昼夜交替，只有朦朦星雾缓缓飘动，时间流逝如永恒，不留意便难察觉。

## 四、抵达蛮荒大陆：废墟、黑猿与收魂

- 约**三日后**，王林已远离莫罗大陆，接近星图上**被标注为危险**的一处蛮荒大陆。庞大暗影仿若遮盖星空，接近瞬间便有嘶吼隐隐传出。
- 王林跃下蚊兽背、破开星雾落地：地面是**黑色沙土**，四处皆雾，若非神识所见与脚踏大地，几乎无法区分此处与星域；远处凶兽嘶鸣咆哮隐隐传来。
- **凡人城池废墟**：房舍坍塌，墙面留有大量**已风干的褐红色血迹**，无任何生命迹象。
- 一道数丈大小的黑影自废墟房屋冲出、速快如闪电扑向王林；王林未出手，身边蚊兽化残影迎上，**巨大口器自其头部贯穿全身**，一吸之下黑影萎缩化作血水。蚊兽飞回，目露不屑。
- 王林拍蚊兽大头、一指前方，紫蚊兽王率十多同族飞向废墟；废墟中冲出**数十道黑影**——全部是**黑色猿猴凶兽**，与**当年孙芸所吞离魂丹内的兽魂一模一样**。
- 王林平静下令：**「把魂留下」**。双方不在一个等级，战斗迅速结束，猿猴凶兽凄厉而死化作血水，蚊兽归来吐出**一个个兽魂**，被王林收走。
- 血腥之气引得远处凶兽咆哮增多、地面震动、狂风翻滚雾气。王林神色如常，神识扫过废墟**未发现任何药草**，转身离去。
- **收尾意象**：他行于雾中似与雾气融为一体，煞气浓浓、**凶焰比任何凶兽都要浓郁**，十几只蚊兽在上空盘旋呼啸；在此凶焰煞气下，远处咆哮渐稀直至消失，地面不再震动，天空的风也停了下来。

## 五、关键线索与伏笔

- **化名归属**：本章「曾牛」即王林自创化名（承第309/423/1063章），其言行一律归于王林。
- **兽魂用途**：云海炼丹之术以兽魂融合为核心，王林此行赴蛮荒大陆的直接目的即为补充兽魂（与药草）。
- **黑猿兽魂与离魂丹**：废墟黑猿与孙芸当年所服离魂丹内的兽魂同种，指向离魂丹的兽魂来源。
- **未竟事项**：此处废墟无药草，王林的采药目标尚未达成，须继续深入。
- **人情账**：王林毁掉孙芸整院药草且不告而别，为后续与孙芸/归元宗的关系埋下伏笔。
