# 第八卷 联盟隐秘 第933章 清水来临（第三更）

## 一、望月：古神一臂碎次空涅箭

- 望月之音响起，其体外无数万丈触须**从根部全部断裂**，齐齐凝聚身前、相互交错，化成一只**万丈古神之臂**，握拳如古神。
- 文中定式：**望月一怒，如古神一指；望月怒之极限，就是古神一臂。**
- 这一拳令远处的王林恍惚，仿佛穿梭回无数万年前的远古，见到古神挥臂怒吼——星球崩溃、星空坍塌、一切敌人尽尽瓦解。
- 古神一拳落在**次空涅箭**上，箭矢震动、砰然崩溃。**次空涅法宝在古神一拳下也要碎灭。**
- 玄宝上人当即喷血、面色苍白，毫不犹豫迅速后退。

## 二、清水登场：抓住心神震动的刹那

- 玄宝上人后退刹那，星空弥漫极端阴寒，一道**红色闪电**如开天辟地之雷临近——时机精准，正卡在他法宝被毁、心神一震之时。
- 红色闪电蕴极端寒意与一股「极」的韵意，玄宝上人来不及闪躲，被冲入体内，喷血、双目片刻涣散。
- **一身白衣的清水**一步走出，神色冷漠，右目红光闪烁，再射出数道红色闪电紧追不舍。
- 「**极境临世**」——玄宝上人体内砰然一声，背部喷出大片血雾。
- 清水掐诀一指天空：黑风呼啸、**七头黑龙**幻化，咆哮中喷出**熄灭一切生灵之火**的阴风吞向玄宝上人。

## 三、旧怨曝光：雷界本君 vs 天宝上人的师弟

- 清水寒声：「**玄宝，你可还认得雷界本君**」——清水早已到场，但全场无人值得他出手，**惟独玄宝上人**。
- 玄宝上人惊呼：「**清水，你竟然没死**」。
- 关键身份揭露：**玄宝上人是当年雨之仙界仙人、制作出射神车的天宝上人的师弟**。他的身份在旁人面前是谜团，在清水面前无所遁形。
- 清水评价其法宝：「若是你师兄天宝上人所制作的法宝，我清水还会有所顾忌，**但你，不够这个资格**」。

## 四、玄宝上人的三张底牌

### 1. 九蝶归一 → 四彩蝴蝶
- 玄宝上人掐诀，将环绕望月的**九只黑色蝴蝶**瞬移至身边，喝「**九蝶归一**」。
- 九蝶融合为一，身体散发**四彩之光**，翅动落下四色彩粉，在其身外形成**四彩漩涡**，横扫挡下七条黑龙。
- 清水随即令七条黑龙化出**数十万近百万雨滴**（呼风唤雨）密集轰击。

### 2. 解封仙元 + 规则空涅
- 玄宝上人大喝「**仙界已经不再，这里是联盟星域**」，将**被压制隐藏无数万年的仙元**轰然解封，无尽仙气弥漫，星空如同仙境。
- 四彩蝴蝶脱落一片翅膀，化四道色芒气焰成漩涡，喝「**规则空涅**」——漩涡碎裂化四彩粉末散开，**四周一切神通法术（含清水的呼风唤雨）尽数消失**。
- 另一片翅膀脱落、蝴蝶消散：消失的神通**重新出现，但呼风唤雨已变成玄宝上人自己的神通**；他双臂伸开令其倒卷，一面阻望月临近，一面轰击清水，借机后退。
- 红色闪电仍紧追不舍，令他极为头痛，暗道「若是次空涅箭尚在，也可与这清水一战而不畏惧」。

### 3. 法宝本源之力（全场夺宝）
- 清水虚空一抓凝无数晶光向前一撒——「**撒豆成兵**」，刹那身前化出**数千虚幻之兵**，气息强大，直奔倒卷的呼风唤雨。
- 玄宝上人瞳孔收缩：这些虚幻之影中**有一些是他当年的故友**。他长叹后退，眼中狰狞，亮出研究万年的成果。
- 自述心法：「**这天地间一切法宝，均都有一股本源之力**，老夫数万年研究，略窥门径。」
- 双臂印记一甩，无形波纹弥漫**方圆数万里**：
  - 所有存活修士身边的法宝**生生脱离掌控，甚至自行切断与心神的连接**；
  - 星空中**无数死去修士的法宝**也一并飘起，齐齐向他凝聚；
  - 他俨然成了「天地之间一切法宝之祖」，召唤之下任何法宝不得反抗。

## 五、王林：保住储物袋 + 死记手印

- **储物袋也算是法宝之类**——所有人的储物袋脱控飞去，且在飞行中**自行打开**，内中法宝一件件飞出。
- 抓住储物袋者会被一股奇异之力笼罩，**燃烧心神的灼热**延伸入体，不松手则**元神俱灭**；四周修士只能苦涩松手，眼睁睁看储物袋飞走。
- 王林储物袋内之物太过贵重、不能松手：**眉心第三目蓦然打开，红光笼罩投在储物袋上**，红光内散出**一丝本源**与之对抗，奇异之力渐渐消散。王林面色苍白但牢牢抓住储物袋。
- 心神剧震之际，王林**死死记住玄宝上人施展本源之力的手印**：心跳怦怦，目不转睛，暗忖「原来此人居然是天宝上人的师弟，这四彩蝴蝶是此人制作，但明显不及天宝上人之力……只是这手印，若是能被我琢磨透彻」。

## 六、玄宝上人的战局评估（本章结）

- 望月之强**与古籍记录区别太大**，否则他根本不会来。
- 此番不但未成功，还**损失了唯一的次空涅法宝**，预料自己在**长老团内的地位定会大范围跌落**。
- 又撞上当年的煞星清水（不知其为何未死，但推想「自己既然可以存活至今，想必这清水自然也有方法」）。
- 危机之下无暇细想，脑中唯一念头：**速速逃走**。

## 七、看点与伏笔

1. **古神一臂**为望月怒之极限形态，直接碎灭次空涅法宝——次空涅并非无解。
2. **仙界残党谱系补完**：天宝上人（射神车制作者，雨之仙界仙人）→ 师弟玄宝上人；清水自称雷界本君，与玄宝上人有当年旧怨。
3. **法宝本源之力**是本章最大的功法伏笔：储物袋属法宝、可被夺控；王林以第三目本源硬抗，并记下手印，为后续参悟埋线。
4. 「规则空涅」展现出**消去并转夺他人神通**的规则级能力。
