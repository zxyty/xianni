# 仙逆 第347章 仙遗族

## 一、与仙遗族卡莫的会面（符文星·第二层）

- **符文仪式**：野人老者的少年弟子以妖兽之血在身上画下符文，符文散发妖异之芒并瞬间刺眼，随后黯淡，印记在少年身上延伸少许后停下。少年兴奋地以一种奇异语言与老者交谈。
- **关键联想**：王林听到该语言的一刻立刻确定——当年他夺取藤厉筑基时进入的那片废墟之地中所见的**蓝色皮肤怪人**，与这些人必有关系，因为语言相同。
- **通名**：老者看了王林右手的**驱兽圈**一眼，双手放胸前、略微弯腰行礼，自报「外来者，我是仙遗族的**卡莫**，**六叶术咒师**」。王林抱拳回应「在下王林，化神修士」。

## 二、卡莫的警告（信息要点）

1. **百年之期未到，凡来仙遗之地的修士均都要死**。
2. 因王林未趁其弟子血录（画符）时出手，卡莫不为难他，劝其**不要进入第三层**，尚有一线生机。
3. **第三层有仙遗族七叶术咒师**，实力相当于修士的**婴变期**；王林的同伴即便进入第三层，也无法活着离开。
4. **仙遗族秘术**：以符文吸收妖兽之力，**妖兽越强大，赋予的力量越大**。

## 三、师徒对话（王林离去后）

- 少年欲擒下王林交给族长，卡莫摇头，指出少年**符力不够，看不到王林身后的符魂**；那符魂**属于「默墨」**。
- 卡莫判断王林「能杀五叶术咒师而不受伤」，自己**也无十足把握留下他**，一旦动手少年危矣。
- 卡莫另感知到王林**手腕铜圈（驱兽圈）内有一股强大的魂力**，故不宜招惹。
- 少年态度：「我不怕死，死亡只不过是回归符文之中」「早晚有一天，我们会杀上去，把这些外来者驱出**符文星**」。
- 部族自陈实力不够，斩杀外来者「自有那些强大的部族去做」。

## 四、转向第三层入口

- 王林此行目的是**轮回果**，就此离开心有不甘，遂飞向第三层入口。
- 一天后抵达此地**极北之处**，远远看到下入第三层的入口。
- 现场：遍地尸体、血腥味四散，与第二层令人暴躁的气息融合成好似煞气般的物质。

## 五、胡老失控

- **状态**：胡老盘膝坐在入口处，双目紧闭、面露痛苦。身后**许罗**满身狼狈，银甲下鲜血流下，头发散乱，脸上有三道似被兽爪抓出的血痕；**邱四平**稍好但气息不稳，也受了伤。三人皆小心翼翼、目露惊恐地看着胡老。
- **原因（邱四平传音）**：胡老一路杀了两个五叶术咒师，在入口处又杀一个，最后这个术咒师**临死前施出不知名法术**，胡老被法术伤害，**变得神智不清**。
- **饕兽发难**：胡老的妖兽饕兽（形似玄武、身带伤痕）率先咆哮，大口一吸凝聚四面八方吸力，在身前形成巨大**风球**射向王林。
- **王林应对**：一拍储物袋放出**蚊兽**与**雷蛙**；雷蛙腹部鼓起吐出雷球撞散风团（轰然掀起风浪），蚊兽厉啸绕空、以巨大锋利口器刺向饕兽。
- **胡老暴起**：巨响下胡老睁眼，**双目红芒、瞳孔上透出符文印记**，大喝一声如野兽般扑向王林。
- **收束**：王林一拍储物袋取出**禁幡**，禁气如龙在身前凝聚，形成牢笼把胡老困在其内。

## 六、设定沉淀

- **术咒师阶序**：以「叶」计数，五叶 < 六叶 < 七叶；七叶约当修士婴变期。
- **符魂**：仙遗族可视之物，需足够「符力」方能看见；王林身后符魂属于「默墨」。
- **符文星**：仙遗族视修士为「外来者」，有驱逐外来者的族群意志；仙遗之地存在「百年之期」的时限规则。

## 七、悬念 / 后续看点

- 王林是否会硬闯第三层夺**轮回果**，并直面七叶术咒师。
- 神智不清的胡老如何处置（被禁幡困住后）。
- 「默墨」符魂之谜与驱兽圈内魂力的来历。

# 第347-348章 剑破符文·轮回树之行

## 一、救治被催化的胡老

- 胡老双目红芒大闪、狞笑抓向身前想要挣脱。王林右手一点，口吐「困」字，禁幡内涌出更多禁气，结成一圈圈极坚韧的困牢——胡老每撕下一层，便有更多禁气涌入补位。
- 王林大喝「胡道友，还不清醒」，声如雷透过禁气灌入胡老耳中，胡老手上一顿、目露挣扎，但眼中那一丝符文疯狂闪烁，红芒再现。
- **胡老自陈原委**：他最终所杀的那个野人，临死前竟晋升至**六叶术咒师**，以一种奇异神通欲将他催化成傀儡。此术极为霸道，若在**修魔海**他需数年即可化解；但此地（仙遗之地第二层）暴虐之气不断入侵，他无法静心驱散，**唯有在生死危机的一刻，该符咒神通才会崩溃**。故请王林出手。
- **王林出手**：右手在储物袋上一抹，取出**黑色仙剑**——此剑被游魂凝聚后，即便当年见过此剑之人也很难一眼认出。仙剑黑芒一闪，剑身好似无形中无限延长，开天辟地般挥出，禁气瞬间散开。
- **结果**：胡老眼中符文眨眼崩溃、碎散而出，额头流下一丝鲜血顺鼻尖滴地；剑芒在其头顶三寸处停下，王林右手一召收回仙剑。
- 胡老取丹药服下、盘膝打坐，半柱香后目光清明，起身抱拳道谢。表面神色如常，内心忌惮极浓：刚才那一剑若再下沉三分，他必饮血当场；虽因自己未反抗、未用法宝所致，但那种生死危机感刻骨铭心。暗道「盛名之下无虚士，**这王林的化名曾牛**，能够如日中天，却是有其原因所在」。
- 旁观者反应：邱四平等人骇然浓郁到极点，屏气凝神不敢出声；连饕兽也身子一颤、不再咆哮。**蚊兽**趁机庞大身躯一冲，口器钻入饕兽脖子狠吸一大口鲜血，才满足地与**雷蛙**一同回到王林身边。

## 二、决定不再等待，进入第三层

- 一天后，白纱女子与青衣老者仍未前来。胡老沉吟后与王林商量不再等待——他手中虽无轮回树的具体位置，但知道大概方位，索性下去边找边等。王林点头同意。
- **第三层环境**：一处火红色的世界，泥土之中有种奇异物质可散发红芒，放眼望去四周尽红。
- **危险评估（胡老）**：仙遗之地目前极为危险，二层已有**五叶术咒师**，第三层怕是**六叶术咒师**也会存在，须尽快赶路，寻到轮回树后立刻离开。

## 三、胡老摊牌：许罗、韵萌是催化轮回果的关键

- 胡老对王林「实不相瞒」：**许罗与韵萌二人，是从轮回树上催化出轮回果的关键**。二人寿元尚有百年，**各自损失一甲子，便能使轮回果现**，所以他才会带二人来此。
- 提议赶路时**你我二人各带一个**，以最快速度争取尽早赶到轮回树所在。
- 邱四平内心叫苦却不敢多言——他知自己在胡老眼中微不足道，只能咬牙跟上，否则一旦落下在此地必死无疑。

## 四、第348章 轮回树：西行赶路

- 胡老一把抓住许罗，身子一晃挪移，**向西方飞去**；邱四平咬牙瞬移跟上。
- 韵萌来到王林身边轻声道谢，王林右手搂其腰肢，命其闭眼后一踏消失原地。少女耳边风声呼啸、凌厉如刀，随即一团柔和**青光**在其体外浮现，阻拦狂风。
- 韵萌偷看王林：其面貌并不英俊，却充满一股奇异气质——文中点明这是**化神修士**身体被天地灵力融合后，根据所领悟的**天道意境**展现出的奇异变化。
- 飞行中王林察觉少女目光但未低头，目光凝向前方：邱四平与胡老已拉开距离，以其速度根本无法与化神修士相比。
- 邱四平眼露焦急，见王林追上后高声求助：「王兄，帮我，弹我一把，我愿以宝物相赠」——章节在此悬停。

## 五、要点与伏笔

1. 王林的化名「曾牛」在此界已「如日中天」，胡老以此评价其实力，说明化名声望已成气候。
2. 黑色仙剑经游魂凝聚后改变形貌，具备「无限延长、开天辟地」的斩击表现，且难被旧识认出——兼具战力与隐匿身份的作用。
3. 术咒师体系按「叶」分级：野人临死可晋升六叶，二层已见五叶，三层疑有六叶。
4. 轮回果的催化代价是活人寿元（各损一甲子），许罗、韵萌实为胡老备好的「祭品/耗材」，王林对此已知情并配合带人。
5. 邱四平以宝物换命的求助，为后续人物取舍埋线。

# 第327章 轮回树下：献铃、弃兽与折枝对峙

## 一、邱四平的交易：一对禁制铃铛

- 王林本不愿理会邱四平（二人并无深交），但一是听说对方有宝物相赠，二是想起当年暗中跟随此人在修魔海平原上时，看到过其洞府内古籍众多，绝非等闲之辈可得，遂改变态度。
- 王林拍储物袋放出**蚊兽**，托载邱四平赶路。蚊兽速度略逊于化神修士但勉强能跟上；此兽眼中露出不情愿之色，认为邱四平没资格坐在它身上。
- 邱四平献出**一对铃铛**：多年前偶然于一只妖兽腹内所得，自称应是上吉之宝，但自己能力有限无法参透，发誓此物绝非寻常。
- **交换条件**：只求王林帮他争取一次在轮回树下感悟的机会。
- 王林接过后只看一眼——铃铛上有一层禁制，不破禁制便看不出端倪——未细看即收入储物袋。

## 二、术咒师野人截杀与饕兽之弃

### 战况
- 远处射来两道黑芒，化作两个巨大面孔：一个追胡老，一个冲王林。
- 王林右手一翻取出**仙剑**，虚空一挥，剑芒快若闪电斩在面孔上；面孔炸开黑雾，雾气交错组成巨大**符文**迎击，结果剑芒消散、符文碎裂。王林斩后不停留，反而提速。
- 雾中走出一名**白发老者**：头发花白、目光阴森，右眼有一道血淋淋伤口，鲜血顺颊而下，他伸舌舔血继续追击。
- 王林判断："只伤不死，定是**六叶术咒师**，怕是与化神后期的修士相当。"
- 前方胡老颇为狼狈：一要保护许罗，二则修为只有**化神中期**，与老妪面孔斗法节节败退、多次遇险。

### 饕兽登场与被舍弃
- 胡老大喝"饕兽"，唤出一头**类似玄武之兽**的存在，与其共战老妪。
- 老妪见饕兽瞬间眼放异光，竟不与胡老斗法，直扑饕兽。
- 追击王林的白发老者也双目一凝、露出贪婪，犹豫后撇下王林扑向饕兽——在他看来，追杀外来修士不如夺取此兽鲜血，或可使符文之力更强三分。
- **蚊兽被两人自动忽略**，显然在野人眼中毫无价值。
- 王林疾驰超过胡老，喝道："胡道友，莫要犹豫，此地野人定不止两个，再纠缠下去，只会更糟，走！"
- 胡老望着被两名野人抓挠撕扯的饕兽，眼中闪过不舍，但强行驱除，头也不回地疾驰而去——因为他看到远处又有**三道黑芒**快速飞来。

## 三、抵达第三层极西：枯萎的轮回树

- 胡老在王林身后沉声指路："西方，那轮回树的大概位置，就在西方。"
- **第三层比前两层小很多**，数个时辰后众人抵达此地极西，胡老神识扫动后确认位置。
- **轮回树形貌**：树不大，仅手臂粗细，无任何树叶，孤零零生长在地面上，看起来极为平凡，与寻常之树无异——但它是这第三层**唯一的树木存在**。
- 胡老自陈：当年来第三层时也曾来过这里，却并未发现任何树木；若非**紫芯**拿出托印的玉简，他也不会相信第三层竟有轮回树出现。

## 四、机缘分配与护法安排

### 邱四平的机缘
- 邱四平赶到，尚未临近，蚊兽便身子一翻直接把他扔下，回到王林身边；邱四平不介意，瞬移至树下，激动地就要盘膝打坐。
- 胡老皱眉看向邱四平；邱四平内心一颤，转看王林。
- **王林裁定**："让他打坐吧，修行本是逆天之事，他既有此机缘，我等还是不要干涉了。"（呼应《仙逆》逆天母题）
- 邱四平感激深吸口气开始吐纳——他知道时间短暂，日后能否化神全在今日。

### 催化轮回树
- 许罗与**韵萌**（文中亦作"韵荫"）连忙来到树下，相对盘膝坐下，中间即是轮回树。
- 胡老告知：许罗与韵萌需**三个时辰**才可完成催化轮回树，这三个时辰内由王林与胡老二人护法。

### 轮回果分配约定
| 情形 | 分配方案 |
|---|---|
| 两颗轮回果 | 王林、胡老一人一颗 |
| 三颗轮回果 | 胡老（炼器阁）多拿一颗，理由：炼器阁之人牺牲寿元所致 |

- 王林答应，但追加条件："不过这轮回树的**枝干**，要归我。"
- 胡老大笑答应，内心冷笑：轮回树现已枯萎，催化之后更无任何用处，给他也无妨。

## 五、折枝翻脸：本章收尾冲突

- 王林点头后上前一步，直接**抓向枝干**。
- 胡老面色一变喝止："王道友，你这是干什么！"
- 王林反问："这枝干既然归我，我现在取下一段，又有何妨，胡道友，我倒要问问你，你这是干什么！"
- 悬念：胡老的失态说明枝干另有玄机（或催化过程不容扰动），双方就地对峙，护法同盟出现裂痕。

## 六、要点提炼

1. **术咒师体系**：以"叶"分级（本章出现六叶术咒师≈化神后期），战法特征为黑芒化面孔、黑雾组符文；对灵兽鲜血极度贪婪，可增强符文之力。
2. **饕兽**成为脱身代价——胡老以之换取撤退时间。
3. **轮回树**位于禁山（催化之地）第三层极西，枯萎无叶，需人牺牲寿元催化，产出轮回果（数量未定，至少两颗），且可在树下感悟（邱四平求的正是化神机缘）。
4. **王林的算计**：从一开始就点名要"看似无用"的枝干，胡老轻视答应，随后王林立刻动手取枝——王林显然知道枝干的价值，这是本章最大的伏笔。
5. 王林另获一对**待解禁制的铃铛**，来源为妖兽腹内，尚未参透。

# 第348–349章 轮回树结果与守树之战

## 一、掰取与结阵

- **开场摩擦**：王林手不停，已掰下一大截（轮回树上的部分），神色如常收入储物袋。胡老一怔欲言又止——顾忌王林的名气与那把令他心惊的宝剑，最终只笑劝：取下一段无妨，但轮回果的数量可能会减少。
- **王林布禁**：双手结印，禁制之圈接连成形，一点即落于四周；手法越来越快，最终共 **九十九个禁制** 落定。随后取出 **禁幡** 向前一抛，化作黑幕笼罩四周。
- **胡老助阵**：
  - 取出 **十六面小旗** 甩落四周，旗一落地即闪烁紫光、相互辉映。
  - 一拍储物袋放出 **五把黑色镰刀**，其上血腥气弥漫，出现瞬间有无数魂魄凄厉吼叫欲从镰刀中冲出；五刀成环形飞入黑幕。

## 二、以寿元催树（第349章 半个时辰）

- 许罗与韵萌身上散出 **乳白色之气**，自头顶飘起钻入轮回树，二人面色忽红忽白、时露痛苦，白气越来越浓。
- 轮回树表面毫无变化，融入的白气 **即便以神识去看也查不到去向**。
- 二人容颜急速衰老：许罗额生皱纹、黑发转灰；韵萌娇媚容颜消逝，变为妇人模样（但更添成熟韵味）。皮肤黯淡无光，**寿元似随乳白之光流逝**。
- 树顶渐现 **三个黄点**，越来越亮，似蕴含无穷神秘之力。胡老沉声道：“**三个轮回果**”。

## 四、王林的抉择

- 两条路：**趁早离开、不等轮回果** vs **留下等果、迎接大战**。

## 六、援敌再至与胡老受伤

# 第349–350章 轮回果到手·力战六叶战咒士齿木

## 一、禁制外的遭遇战（章前半）

王林走出禁制时，两名野人老者正以铁链般的符文猛撞十六面旗帜组成的飓风。

战后王林收仙剑与黑印，扛回阵法。四周只余残尸血骸。

# 第350–351章 射神车斩齿木 · 逃出仙遗之地受阻
