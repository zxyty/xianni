# 第九卷 云海之巅 第1233章 风动（致歉）

## 一、王林：出乱兽雾界，抵风仙界入口

- **脱离乱兽雾界**：王林冲出乱兽雾界，踏入八阶星域，眼中露出喜悦。回望时确认——方才放弃追杀蜈蚣，是因感受到一股**十三阶凶兽**的气息。他判断眼下最重要之事是**前往风之仙界**，遂不再纠缠。
- **对乱兽雾界的评价**：『这乱兽雾界，声名赫赫，确有其因。』
- **行事转谨慎**：八阶星域大神通老怪不少（如先前在雾气中观察他与蜈蚣交战的老者）。以王林修为，虽伤势未愈，凭种种神通法宝在**六七阶星域**嚣张尚有资格；但在**八阶星域**必须谨慎。故收敛身形、放缓速度，仔细研究去往风仙界的路线，**不再横冲宗派而是绕开避过**，身影如海中之鱼隐于浓雾。
- **时间跨度**：自五阶星域出发至今，已过去**近一个月**。这一日，他在无人知晓的情况下接近了存在于八阶星域内的**风仙界残破入口**。

## 二、风仙界入口设定

| 要点 | 内容 |
|---|---|
| 破坏程度 | 云海的风仙界当年被破坏较为严重 |
| 保存原因 | 因**蚊兽**占据，界内残骸保存极为完整 |
| 进入方式 | **不需风鼎**；入口如一道被撕裂的巨大裂缝，只要有胆量在密密麻麻的蚊兽群下冲入便可进入 |
| 门槛 | 真正能做到者极少，唯有人数众多且有大神通修士在内方可尝试，或数个大神通老怪结伴 |
| 外围生态 | 多数修士只在外围活动，试图抓获落单蚊兽；裂缝外偶有凶兽出现，体内蕴含极少见的仙气，时间长了可诞生**蕴含仙气的晶石**——不多，但胜于没有 |

**当下场面**：裂缝外有十几个修士似在等人，准备结伴闯入。王林自雾气中渐渐走出，**一头白发极为显眼**，出现瞬间便吸引了这十多人的目光凝聚而来。

## 三、归元宗：吕烟菲的等待与决断（五阶星域·莫罗大陆）

- **等候**：吕烟菲立于**当初与王林第一次交谈的山峰**，青丝迎风，绝美脸上一丝惆怅。她已站了一个时辰，望着天空期望看到那**百年前的身影**——等了十年、五十年、一百年，始终未见。内心独白：『为什么你曾答应过，你说过，你会来。』
- **背景事件**：**主宗盛典、各分宗大比**临近，归元宗参与大比之人已准备完毕，只待主宗传送阵开启。设定：**建于各分宗的传送阵，若非主宗主动开启，分宗无使用权限**。
- **传送阵开启**：大地轻震，刺目光芒自归元宗传出，天地之力浩荡凝聚，吕烟菲却毫无留意。
- **断绝师徒**：弟子**许芸**踏风而来传话（师叔请师尊过去，众人要走了）。吕烟菲收回目光，惆怅转为坚毅，柔声道：『此行之后，你我便不再是师徒。你天资很好，想必在任何一个分宗，也会很快成为核心弟子。』许芸落泪欲言，被『不必多说，我意已决』止住。
- **离宗**：传送阵外，吕烟菲的**三个师兄**沉默而立，气息压抑，留恋地想再看四周最后一眼。众人踏入阵法，传送前往**八阶星域的主宗——无极宗**。传送消散瞬间，吕烟菲眼角落泪，心念：『或许等你回来时，会发现，归元宗已经没了。』

## 四、妖宗战场：李倩梅告假三月（九阶星域）

- 九阶星域妖宗外那奇异的**裂缝战场**中，一凶兽被厮杀阻止在外后，**兽潮暂时停歇**，云海修士得以短暂休息。
- **蓝发的李倩梅**是所有人目光的焦点，擦去剑上兽血，神色疲惫却依然宁静。
- 她沉默中离开战场，走向妖宗此地分宗山门。在山门大殿内，望着盘膝坐于大殿深处的模糊身影，轻声却坚定地道：『**我要离开三个月。**』

## 五、伏笔与看点

1. 王林一头白发在裂缝外十余修士面前暴露，是否引来试探或结伴闯界，尚未揭晓。
2. 吕烟菲『归元宗已经没了』的预感，暗示无极宗主宗盛典/分宗大比背后另有凶险。
3. 李倩梅三个月的去向，与王林的风仙界之行存在时间线呼应。

> 归属说明：本章王林以化名『吕子浩』的身份体系活动于云海（自第1063章由吕烟菲奉上），本章未直接点名该化名；相关言行一律归于**王林**本人。

# 第1151章 剧情梳理

## 一、破天宗大殿：李倩梅执意离宗三月

- **场景**：破天宗大殿，殿中只有一道「模糊的身影」（宗内最高话事者），两道精光落在李倩梅身上；李倩梅神色宁静毫无变化，令对方暗自赞赏。
- **冲突**：
  - 模糊身影答「不行」，李倩梅答「我只是通知你」，转身外走。
  - 对方施压：更大范围的**兽潮在即**，此时离开是破天宗的耻辱；再走出半步便以**叛逃论罪**，声音使天地一片阴寒。
  - 李倩梅停步不转身，只轻声道「我要离开三个月」，随即毫不犹豫前行。
  - 对方带怒质问：有什么事比对抗兽潮、使云海不受荼毒更重要？李倩梅答：「有一件事，对我来说，比你说的，更重要。」
- **让步**：李倩梅走后许久，殿内一声叹息，阴寒与怒意尽消，赐下一道柔和之芒（玉佩）落入已走出**妖宗山门**的李倩梅手中，许其借**传送阵**离去以节省时间。
- **动机揭示**：李倩梅拿着玉简望向远处，轻声自语——「消失了百年的他，此番应该会帮助归元宗参与分宗大比，他会去么」。指向王林（化名吕子浩，自第1063章起以归元宗故人吕子浩之名行事）。

## 二、云海星域·严寒蛮荒大陆：木冰眉的独处与追忆

- **地点**：云海星域内一处漂浮在雾气中的蛮荒大陆，严寒弥漫，生灵至此皆会冻僵；大陆**东方**有一处山峰洞府。
- **状态**：木冰眉盘膝于此，伤势很重，肉身短期无法恢复，在异乡独自咽下寂寞与孤独。她在**等**——等她初到云海星域时抛出的那枚**昆虚古老传承、唯独历代圣女可以拥有的玉简**带来的回应。
- **追忆（分身体系关键）**：
  - 她的一生枯燥，几乎都在昆虚度过；最快乐之事是**一个个分身的经历**，让她每每沉入其中，好似在看自己另外的人生。
  - **柳眉是她分身中最特殊的存在**——「因为一个人而特殊」（指向王林一线因缘）。在那一刻，木冰眉分不清自己是柳眉还是木冰眉：她本是局外人，看着柳眉的一幕幕后渐渐迷失，从局外走进了局内。
  - 眼泪从**元神**眼角流下，泪非真泪，而是心在绞痛。

## 三、接引者王姗姗登场

- 洞府外传来轻柔女声询问「府内可是昆虚圣女木冰眉木姐姐」，木冰眉神色无异，似早有预料，请其入内。
- 来者：身穿**鹅黄衫裙**、相貌清秀的女子，与绝色的木冰眉并立亦不显平庸。自报名号 **王姗姗**（文中另作「王珊珊」）。
- 来意：接到玉简后，**家师本欲亲自赶来，但出了一些意外**，故遣其前来接木冰眉回**神宗**。
- 细节：木冰眉听「姓王」时眼中露出一丝孤寞（呼应王林），只道有劳。王姗姗赠丹药，称赞木冰眉容貌，木冰眉笑容苦涩。
- **约定**：王姗姗提议，此番回神宗恰逢**云海星域八阶宗派盛典大比**，不妨途中同去一观；木冰眉点头应允。

## 四、伏笔与看点

1. 李倩梅与木冰眉两条线均在向同一场**云海星域宗派大比 / 归元宗分宗大比**汇聚，且都因王林（吕子浩）而动。
2. 「消失了百年的他」= 王林一线；李倩梅不惜担叛逃之名也要三个月离宗，动机即在于此。
3. 木冰眉与柳眉的「本尊—分身」界限模糊，是其情感线的核心设定；柳眉之特殊源于王林。
4. 破天宗面临更大范围兽潮，为后续云海星域大势埋线。
5. 「姓王」的孤寞与王姗姗的出现，构成微妙的名字呼应（不等于血缘关联）。
