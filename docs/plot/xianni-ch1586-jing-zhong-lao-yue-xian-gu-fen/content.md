# 第1586章 仙古分！

## 一、掌尊现身

- 王林抬头望见自天幕走出的黑袍人——**掌尊**，太古五尊之首，拥有莫大心智、计算天地之人。
- 王林回溯掌尊的幕后布局：杀上代封尊、毁灭四大仙界、计算青霖仙帝、派符文族探寻李广之箭、水道子的反叛、司墨子的归降、战家老祖之死，背后都有掌尊身影；甚至太古星辰时王林隐隐感到心神被操控，事后想来亦是掌尊所为。
- 掌尊忌惮李广之箭的一箭之力，故迟迟不出，待王林射出后才现身。他右手一捏，箭矢一颤消散——此箭已与王林体内之弓有联系，消散后以奇异方式回到王林魂中（当年若非李广身亡，此箭亦会回到李广体内）。

## 二、井中捞月的确认

- 「井中捞月」是王林记忆中无法抹灭的神通：他曾在**火雀族**于疑似掌尊分身之人身上见过。
- 看到这片大地如井面后，王林心中确定：此处恐怕也是一场井中捞月，**要捞出的是朱雀星与他王林**。
- 掌尊语：「若非是蓝梦怜你，在太古星辰时，你便已然成为了老夫掌心之物。」
- 掌尊索问：「告诉我，你的仙人血脉，从何而来。」王林不答。

## 三、太初之力·古与仙分离

- 掌尊步步走来，每一步都令王林心神一震；**水面上同时倒映出一个黑袍人**同步走向王林，形成一天一地两个掌尊，压力翻倍，王林如被定身术凝固，无法移动半点，面色苍白但双眼冷静。
- 掌尊遥遥一指：蓝色天空光芒尽消，天空突兀出现一轮**骄阳**，弥漫太初本源气息。掌尊自陈：「天地之初，便有光，这光，就是老夫感悟的本源之一，太初规则之源。在这太初之力下，汝之一切，古与仙，分离。」
- 金色光柱笼罩王林：
  - 太初之力对游魂伤害极大，王林体内一切投影而来的**游魂瞬息烟消云散**；
  - 失去游魂后王林身体在排斥之力下骤然崩溃，太初之力深入其崩溃血肉，强行分离其「古」与「仙」；
  - 分离之痛远超当初融合之时，王林神色扭曲却不发一声，死死盯住掌尊，立誓若不死或有来生，要十倍百倍千倍万倍偿还。
- 王林尚有一个**杀手锏**未用，且很可能不受其操控，他在等掌尊靠得更近。

## 四、捞出仙人血脉

- 掌尊五指伸开，随距离拉近向王林一捞，水面倒影同步出手：「井中，捞月。」欲捞出的是被强行分离的**仙人血脉之力**。
- 王林体内撕裂剧痛，金光与金色鲜血自全身汗毛孔弥漫；骨髓中的**髓液**亦被捞得穿透骨头、自骨上细密裂缝与缺口挤出。
- 喷洒的金血在体外凝成一个王林形状的人形，升到其身七尺之上，金线相连渐少；掌尊向上狠狠一捞，金线全断，**仙人血脉被完全分离**，金色身影蠕动凝聚成一滴金光万丈的血液。
- 这一滴血液内有**「仙人不灭体」的半成符文**闪烁，即当年「疯子」给王林的造化之凝炼。
- 分离后果：王林眉心**古神星点**、右目**古魔星点**均失去金光；体内不再有排斥之力，砰砰之声中**再次成为古神肉身**，仿佛回到遇见疯子之前。
- 掌尊望着那滴金血，双目狂热激动却夹带浓浓忌惮——他可知晓王林的一切，唯独不知王林在**幽冥兽体内**所遇之事。动容中他上前一步，抬手就要去抓那滴血。

## 五、杀手锏：黑色阁楼与赤魂子

- 就在此时王林咬破舌尖，喷出一口**道古鲜血**；血如血刃打开其**储物裂缝**，飞出一座**巨大的黑色阁楼**，天地顿暗。
- 道古血洒在阁楼三个阁窗之一上，将其染红。王林喝道：「以吾遵古王林之名，解你封印，给你自由，助吾杀敌。」——以其修为只能开启一窗、释放一个被**烨寞**封印的至强之魂。
- 阁窗崩溃，一道红影（一片鲜血、看不清容颜）冲出，怒吼：「该死的烨寞，你封印老夫**赤魂子**万古无尽，今日老夫自由了。」
- 赤魂子出世即撞在距离过近的掌尊身上，**掌尊后退数十丈，头部黑袍倒卷、露出黑袍下容颜**（王林惊呼「赤魂子」）。
- 赤魂子不理会掌尊与王林，直奔那唯一未在箭下死亡的**仙妃**，一卷之下其娇躯被血液融化、**生生吞噬**。
- 赤魂子狂笑冲入天幕，一撞之下天幕蓝光一闪、崩出巨大窟窿，其自窟窿冲出离去。

## 六、界内一幕（朱雀星）

- 同一时刻，界内真正的**朱雀星**一座凡人都城内，**疯子**手拿半截油腻鸡腿坐在一群乞丐之中，得意咬了一口后望天发呆：「奶奶的，他居然不在这里了，他不管本王了不行，我要去找他，他不能不管我了……咦——」

## 关键转折

1. 掌尊正面出手，太初之光成为其本源之一的具象。
2. 王林失去仙人血脉，退回纯粹古神肉身，造化被凝为一滴金血落于掌尊眼前。
3. 烨寞阁楼首次开窗，赤魂子这一被封万古的至强之魂脱困，成为局面唯一变数。
4. 阴月仙妃被赤魂子吞噬身亡；天幕被撞破，界外通路已开。
