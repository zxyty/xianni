# 第八卷 联盟隐秘 第935章 委屈的雷兽

## 一、战后格局：北部战场化为禁区

- 联盟北部战场经此一战几乎全部撕裂，**方圆数万里成为禁区**。
- 战场中间的**庞大漩涡**不断旋转，大量尘埃被吸入其内消失不见。
- 此战**无胜负之分**：对罗天与联盟而言只是一次试探，但代价极高——**上万修士灭亡**。
- 两星域因此短暂休止，似在酝酿下一次大战。
  - 罗天：大量修士撤退，于**联盟西部与北部之间**凝聚休养生息。
  - 联盟：表面安静，但此战信息如雪花般传遍整个联盟。

## 二、黄龙现身：四圣宗的算计

漩涡处无声无息出现一人——白发苍苍、仙风道骨、一身黄袍的**黄龙**（王林旧识）。漩涡的无尽吸力在其体外立刻崩溃，半点不能缠身。

黄龙的判断与盘算：

1. **胜负判定**："这双方试探的一战，看似不分胜负，但实际上，却是修真联盟败了。"
2. **因果溯源**：此战因**当年炎雷子旧事**而起；黄龙自陈"当年无意中帮了那炎雷子一次"，未想今日成了**四圣宗的良机**。
3. **待议之事**：要与**其他三人**（四圣宗另三位）仔细琢磨。
4. **最大变数**：修真联盟身后的**九级修真星**是否干预——毕竟修真联盟才是他们**唯一认可**的一方。
5. **同类竞争者**：想必**尸阴宗**也在琢磨此事；罗天来临，把**联盟的平衡**就此打破。
6. **对王林的定位**："那王林，此子很不错"，让他参与战事，"倒也算是我四圣星的一个先锋"；**以炎雷子的修为不会看不出王林身上的印记**，此即四圣星对罗天方面的一个**暗示**。
7. **终极意图**："这场大战，还是不够啊，再激烈一些，再消耗一些修真联盟的势力"——四圣宗已忍太久，积蓄之力将到爆发之时。

## 三、设定：星空漩涡内的虚无之界

漩涡内另有乾坤，是一片**无边无际的黑暗世界**。

**基本特性**
- 没有任何光明、任何声息，**连灵气与天地元力都半点不存**；生命几乎绝迹。
- 此地是**星空碎裂的虚无之界**：若把无尽星空比作一层纱，这里就是纱层下的无尽黑暗。
- 无数万年来，曾有大神通修士探寻其根源，**无一人明悟其奥秘**。

**对修士的压制**
- 身体无止尽虚弱，好似有无形之力不断封印、限制，修士很难存活。
- 隔绝一切天地元力，体内元力即便自成循环，也**终有用尽的一日**。
- 奇异之力削弱与封印下，能发挥出来的实在太少——"仿佛此地就是修士的禁区"。
- 即便**碎涅大圆满**的修士，在此也无法探查太久；靠飞行摸索尽头根本不现实。

**结构猜想**
- 虚无之地仿佛一个**天然而成的绝元大阵**，把所有星空生生包围环绕、彻底封死，使任何修士无法像崩溃星空来到此地那样，再崩溃此地去往更深处。
- 极少数人心中藏着一个不敢碰触的猜测：**这虚无之地并非天然，而是人为**。

**尘封秘辛**
- 整个联盟星域内，只有身份、地位与修为达到一定程度者才知晓：很久很久之前、**仙界尚未崩溃之时**，此地曾发生一件惊天动地、**使仙界险些崩溃、修士几乎灭绝**的大事。

## 四、望月遁入虚无

- 望月庞大的身子在此黑暗中都显得微不足道。
- 入此地后望月**身子立刻收缩**，所有神通凝聚体内，形成大量威压与吞噬，试图把体内一切异物全部吸收。
- 四周虚无的奇异之力对望月影响不大，望月几乎未受限制，在黑暗中缓缓漂游、毫无目的地向前。

## 五、雷兽出世

王林身在望月体内，取出**炎雷子所送的仙界碎片**，神识一扫留下**自身印记**。

- 碎片内一声咆哮，雷光冲出，散作无数弧形电光游走，化出一头**生着银角的雷兽**。
- 该碎片所封印者，**除主魂外就是这雷兽**。
- 雷兽形貌：脖上拴铁链、全身挂满凌乱纸符、**银角被穿了个小洞栓上铁环**。
- 雷兽见王林后几乎泪眼朦胧，多年委屈一时爆发；王林拨弄铁环，反使其委屈更浓、低吼不断。

**安慰失败**
- 王林苦笑道"这些年，委屈你了"，又拍其大头说"其实，你这个样子，还是很不错了，挺好"。
- 雷兽甩头（铁链叮当、纸符晃动），**露出怀疑之色**——同样的话它从**炎雷子**口中听过太多次。
- 王林同情其遭遇，可想见这些年它受了很多折磨；同时惊讶于**雷兽实力明显比当年高出不少**。

## 六、许立国出场救场

- 王林一拍**储物袋**，**仙剑**飞出，弹剑后黑雾弥漫，**许立国**幻化而出。
- 许立国不待吩咐，通过与王林的联系已知晓缘由。
- 他上前拨弄雷兽银角铁环并哈哈大笑，激得雷兽全身雷光闪烁、银角瞬间凝出雷霆冲击；许立国尖叫后退，仍被一丝雷霆击中，忙辩解"我是实在太喜欢这个铁环了"。
- 王林则散开神识观察四周，不理会二者——叫出许立国正是为了让他去安慰雷兽。
- 数语之后：雷兽神色略缓、怀疑消失，继而**得意**，与许立国交流甚欢；最终让许立国**坐在其身上**，连拨弄铁环也不再介意，反抖了抖身子，对自己现在的样子**极为满意**，当年狂妄高傲之态烟消云散。

**旧事印证**
- 王林由此对许立国不得不升起佩服：当年在**朱雀星朱雀墓**内遇到**黑刀之魂**时，就发现了许立国这一长处——黑刀之魂被其说动，好一段时间形影不离。
- 许立国内心得意："还是你家许爷爷厉害吧，这种事情，一下子就把那煞星比下去了。"

## 七、伏笔与看点

- 四圣宗（四圣星）欲借罗天入侵消耗修真联盟，静待爆发；变数在**九级修真星**是否下场，竞争者是**尸阴宗**。
- 王林身上有**四圣星的印记**，被黄龙当作对罗天的暗示与先锋棋子，王林本人未必知情。
- 虚无之界"人为而非天然"的猜测，以及仙界未崩溃时那件近乎灭绝修士的大事，属重大远古伏笔。
- 雷兽已远强于当年，成为王林新的战力来源。
