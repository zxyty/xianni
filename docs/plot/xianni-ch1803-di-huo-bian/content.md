# 第1803章 地火变！（第二更）

## 一、王林在仙罡大陆的初次睁眼

- 这是王林在仙罡大陆第一次睁开双眼、第一次以自己的肉眼看到仙罡大陆，也是第一次在苏醒中体会仙罡的气息。
- 苏醒第一时间，他先查看身后的**避天棺**，确认无碍后才放心，转而看向身边的地火。
- 「区区地火，岂能焚烧王林，岂敢焚烧」——王林本就拥有火本源，被抽出的地火对他微不足道。

## 二、火之本源的蜕变：外来火 vs 仙罡本土火

地火不但未伤王林，反而**加快了他的苏醒**；更因这地火是仙罡大陆之物，使得王林自**洞府界**修炼而来的火之本源在与之融合中出现惊人蜕变。

此蜕变为古往今来仙罡大陆从未发生之事，本质是一场战争：

| 结果 | 后果 |
| --- | --- |
| 仙罡火本源胜 | 王林火源被吞、被同化为仙罡大陆的一部分；修为不变、依旧拥有火之本源，但无法成为天地之火的主人（主人是仙罡大陆） |
| 王林胜 | 其火之本源凌驾于仙罡大陆之上，自身成为真正的**火中帝王** |

## 三、识破炼傀儡之谋

- 王林感知到外面有一个弱小修士绕着自己转圈，不断抛入从未见过的物品，加速火焰燃烧并引动身下阵法运转；一股股奇异力量自阵法传出，似要钻入其体内进行改造。
- 王林略一思索便猜出大概：「昏迷时被此人寻到，将我带入这里进行炼化……看这阵法的样子，应该是与傀儡有关……这是要将我炼成傀儡」，眼中寒光一闪。
- 对比：在洞府界，无人敢做出将王林炼成傀儡的举动，**即便是掌尊等人也决然不敢，忌惮很深**。
- 阵法虽有玄妙，王林并未看在眼里；他真正感兴趣的是**地火**。

## 四、神识下探地火脉

- 王林不理会仍在兴奋游走祭炼、毫未察觉他已苏醒的**康仁**，散出一丝神识融入地底，顺地火来向直奔深处。
- 所见：方圆数万里内所有山峰下全是地火；此片山峦是一条**地火脉的分支**——看似很大实则很细，与主干相连，主干深入地底不知通向何处。
- 再次扩散神识后震惊发现：大地下方地火脉极多且复杂，越向下温度越高。
- 结论：「此地火脉，看起来，好似一个**庞大的火阵**。」因刚苏醒、尚未摸清环境，不便强行深探。

## 五、一掌拍地，地火倒灌

- 王林决定「多抽一些地火出来炼化，滋养我的火本源」，右手在阵法地面轻轻一拍。
- 整个苍龙宗轰然一震，数万里范围山峦下的地火疯狂呼啸而来，齐涌入康仁洞府。
- 康仁一愣、尖叫后退，掐诀布下无数防护，并召出**九具傀儡与两个木头人**挡在身前。
- 阵法内火海滔滔，形成巨大火焰柱直接焚尽雾气；洞府裂缝密布似要崩溃，**九具傀儡尽数爆开，两个木头人同样崩溃，毫无抵抗之力**。
- 死亡临头之际，一道**幽光**自火焰内飞出落于康仁身上，缭绕全身，使热浪掠过而不伤其分毫。康仁瘫倒在地，呆望火海，内心被恐惧填满：「我……我带回来了一个什么人？」

## 六、苍龙宗应变：天水大阵

- 洞府大门轰然崩溃，热浪横扫，整个山谷阁楼烟消云散化作火海，四周山峰颤抖似要爆发。
- **虚云与其师尊**（白发老者·厉长老）恰在此时来临，白发老者面色大变，抓着弟子急退数百丈。
- 苍龙宗弟子纷纷冲出洞府，在半空骇然望去。
- 三道第三步气息现身于虚云师尊身边：一男一女白发苍苍，另一人为中年男子，其中**中年男子（赵长老）修为达空灵后期**。
- 赵长老仰天低喝，声如雷鸣传遍数万里：「苍龙宗弟子听令，地火万年一次异变，这一次提前，莫要慌乱，速速布置**天水大阵**！」
- 数万弟子盘膝坐于天空掐诀，全身升起云丝雾气，最快速度布出大阵——远看化作一片笼罩数万里的漆黑沉甸乌云层，数万弟子弥漫其中。
- 另两名第三步长老（一男一女）不待吩咐冲入乌云，施展神通化作**两条约数万丈长的长龙**穿梭云中，露出巨大龙头向地面火海张口，天地轰鸣间大雨倾盆，龙头喷出大量水汽如狂风压下大地。

## 七、追责与下探

- 赵长老质问厉长老：「你是第一个到来者，这里到底发生了什么事情？」并点明「地火明明万年一次异变，眼下本应在**三千年后**才出现为对，这一次提前，必有缘故」，目光扫向**驼背青年（虚云）**，青年心神一颤几乎站立不稳。
- 厉长老禀报：若非正常地火变，则可能与**三代弟子康仁**有关——此人不知从何处带回两具尸体，异火变正是在他炼制傀儡时发生。
- 赵长老一时想不起「康仁」这个名字。
- 情报：宗主与老祖外出前往**大魂门**，厉长老已传出玉简，二人正在赶回路上。
- 损失评估：此次地火爆发苍龙宗毫无准备，虽无死亡，却毁掉不少建筑，更毁灭诸多**仙草与宗派储留之物**，代价太大——赵长老双眼杀机一闪。
- 赵长老以水汽结成三丈气泡护体，冲入被雨水洒落的火海大地，直奔燃烧山峰中的康仁洞府；表面极快，实则暗自谨慎（觉此事诡异），但对自身修为很是自傲。
- 入洞府一眼看到穿苍龙宗道袍的青年（康仁）神色呆滞、身子颤抖、双眼恐惧至极，望着洞府深处冲出的火焰柱。

## 八、要点小结

1. 王林在仙罡大陆的「第一击」并非战斗，而是一掌抽调地火——却已足以震动整个苍龙宗。
2. 火之本源与仙罡地火之争，是王林在此界能否称「火中帝王」的伏笔。
3. 康仁的傀儡计划彻底破产（九傀儡＋两木人全毁），但被神秘幽光救下一命。
4. 苍龙宗至此仍将此事误判为「地火异变提前」，尚未意识到棺中之人的真实分量。
