# 第1926章 五十年！

## 一、五十年的空白与「白发天尊」传说

时间一晃便是五十年。对凡人是大半生，对修士不过一次短暂闭关，但这五十年间，仙族大陆东州、南州之间崛起了一个传说。

传说中的主角是一名天尊修士：**一身白衣、一头白发，身边跟随一条金尊海龙**。他走过两州三十多个大小之洲，专门寻找天尊修士一战。

- 两州天尊（含未被大天尊招揽者与常年闭关者）近百之多，其中南州数量远超东州。
- 东州原在仙族五州中名列第二，但自**双子大天尊当年转世灵魂再次分裂**后，渐渐成为天尊最少的一州。
- 因无人知其名，修士只据蛛丝马迹知其白发，遂称之为「**白发天尊**」。真名王林知者不多。

### 已知战绩

| 地点 | 对手 |
|---|---|
| 诺云洲 | 诺云宗天尊老祖 |
| 海洛洲 | 道德门天尊老祖 |
| 九魔洲 | 魔天道天尊老祖 |
| 灵龙洲 | 道一大天尊麾下·航涛天尊 |
| 山凌洲 | 武封大天尊麾下·赤峰天尊 |
| 山海洲（南州，最后一战） | 海子天尊 —— **败** |

传闻近百战只败二十多次，余者连连获胜，声名传至北州、西州乃至中州，几乎所有仙族天尊都知晓有这么一个战力极强的无名白发天尊。山海一战败后，他数年音信全无。

## 二、山海洲酒楼：传说的回音

山海洲一处专供各宗修士的交易城池，酒楼只卖醇酒不卖食物。数名修士议论：

- 道袍老者：曾在山海边缘目睹那一战，海水崩溃、天地欲坍，隐见白发天尊身影，可惜败了。
- 青年修士冷笑：海子天尊已极为接近传说中的**跃天尊**，白发天尊纵是无上存在也必败。
- 持扇中年男子推测：白发天尊如此挑战是为引起**道一大天尊**注意以求招揽。（南州天尊多，因道一大天尊从不勉强天尊入麾下，且南州天尊皆可去**道一宗**听其百年一次讲道，故不少东州天尊迁来。）
- 黑袍老者反驳：五十多年前道一大天尊便已招揽白发天尊，被拒。

角落里，白衣白发的王林正一口口喝酒听着这些议论。因传说之故，酒楼里白发修士已有三五个之多。

## 三、王林的自我盘点

五十年连续与多个天尊交手，目的有三：凝聚名气、于交战中感悟、熟悉天尊神通并使自己更强。

- **山海之败（三年前）**：出动了所有分身依旧失败。海子天尊「已可融七十道神通在一指内」，王林自认根本不是对手——除非穿上**魂铠**；但穿魂铠则起不到历练作用，故未用。
- **当前战力**：两个分身全部出现后，可把如今极限的**九道神通压缩近三次**，达到堪比**三十六道神通**的效果。
- **变强路线**：搜寻**金、木两种本源之物** → 一具达到凝聚出真身的程度 → **五行真身完全融合** → 本体可融**十八道神通于一拳**，加以时日压缩可堪比**七十二道神通**的天尊 → 届时可与海子再战。

## 四、山海树：木本源的目标

据赤峰天尊所言：

- 山海最底部有一颗**山海树**，整个山海乃至整个山海洲的封印，皆由此树（之魂）支撑。
- 此树极为强大，当年被**仙祖**封印，仙祖甚至因此受伤。
- 岁月太久，山海树魂早已成为**死魂**，只留躯干；但躯干内仍有足够的**木本源之力**。

王林与海子一战后一直在山海洲观察，判断「十有为真」，遂下定决心：**必要时动用魂铠，击败海子天尊的守护，进入山海树吸收木本源之力**，以此凝聚木本源并直接化作真身。

## 五、赤峰天尊再至：武封大天尊的条件

王林出城遁走时，身后天地扭曲，幻化出一个高约十丈、紫袍罩体、面戴金色面具的身影，威压使四周虚空荡出波纹——武封大天尊麾下**赤峰天尊**。

- 当年二人一战，王林未穿魂铠而**平手**，王林明显感到对方亦有所保留。事后赤峰天尊传达**武封大天尊**的招揽口讯，这是继道一大天尊后第二个招揽王林的大天尊。
- 王林对武封大天尊的评价：极为超然，很少看重天尊修士，唯有跃天尊之修才被其看重招揽；麾下天尊皆极优异之辈。但其只遣人传口讯，连一丝神念之体都未现，显然认为以王林战力「只配让他传出口讯」——这一点不如曾亲自现身的道一大天尊（道一或因见过王林穿魂铠后的战力才现身）。
- 王林委婉拒绝：「此事还需考虑，如今我还没有决定。」
- 赤峰天尊不以为意，转达关键条件：**大天尊要招揽必须亲自出面**；武封大天尊交代——**若王林能闯过「天尊涅」九层，他将本体亲至，绝非神念化身**；且届时五位大天尊中任何一个都会大力招揽。

## 六、转折：决定前往天尊涅之地

道一大天尊此前也说过，王林若闯过九层会再次来临。两位大天尊口径一致，王林生疑：「莫非这九层，有什么玄妙不成？」

他这五十多年已**多次验证了进入天尊涅之地的方法**，却从未去过。本章结尾，他双眼一闪，下定决心：**「应该去看看。」**

## 七、待解伏笔

1. 天尊涅九层究竟有何玄妙，值得两位大天尊以「本体亲至」为诺。
2. 金、木两种本源之物的下落——木本源锁定山海树，金本源尚未着落。
3. 与海子天尊的再战（须先破其守护方能入山海树）。
4. 王林最终会否接受道一或武封任一大天尊的招揽。
