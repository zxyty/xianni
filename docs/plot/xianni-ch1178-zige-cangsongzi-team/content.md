# 第1178章 资格（第九卷 云海之巅）

> 世界状态提示：本章「吕子浩／吕道友」即【王林】以归元宗故人之名行事（化名自第1063章，由吕烟菲奉上）。天运子仅为王林心中比较，非实际出场。

## 一、拍卖场：苍松子力压秘洛宗

- 秘洛宗黄衣青年质问元晶来路，苍松子现身（长虹落于欧阳隆身边），回以「元晶是老夫私人之物，莫非还要向你秘洛宗汇报不成」。
- 竞价过程：黄衣青年 3.5 万 → 苍松子 4 万 → 黄衣青年 5 万 → 苍松子 6 万 → 苍松子 7 万，并附带威胁：「你秘洛宗来人不多，七阶星域路途遥远，回去时一路可要小心。」
- 敢威胁七阶星域之人，全场哗然；黄衣青年冷哼后化虹而去。
- **苍松子背景**：宝玉宗大长老，嫡系众多，足与宗主对抗，却素来低调；其暗中收购仙玉、坐拥大量元晶之事，宗主不敢过问。
- **苍松子心态**：不惧暴露、不惧上阶星域注意——今日之后便离开蓬莱、此生难返；且此行「把握极大，一旦成功修为暴增」。
- **成交**：苍松子甩出储物袋（含定金共 **八万元晶**），虚空取走铠甲，笑邀「吕道友，咱们，走吧」。王林神识一扫，不动声色收起。
- 王林心中判断：苍松子修为高深、心智老练、为人狠辣，但比不过天运子——连天运子都敢一斗，不惧此人。
- 拍卖会因此事失去继续的心绪，众人散去。

## 二、星雾送别：李倩梅与王林的互赠与推拒

- 出蓬莱大陆后，王林与苍松子疾驰星雾，笛音传来，蓝发李倩梅自雾中走出。
- 王林请苍松子先行；苍松子递出**标记星图的玉简**，约在图中之地与几位同行老友等候，扫了李倩梅一眼便走，**丝毫不担心王林会不去**。
- 对话要点：
  - 李倩梅本已走，因「你曾说要送我」而折返。
  - 王林：就在此处送；以你的修为在那里当无太多危险，仍要谨慎。
  - 李倩梅：或许此去再无相见之日；**听师尊语气，这次的兽乱似乎有些严重**。
  - 李倩梅提及「那苍松子行径很是诡秘，我之前本打算与你同去」。
- **三问三物之约**：李倩梅取下右手**翠绿色玉镯（防护法宝）**作第三件物品，王林以「太过贵重，承受不起」推还。
- 李倩梅回以「你既不要，我也不要」，将玉镯甩入星雾化青光消失；并**退还画轴**，称「画上的江湖很美，只是缺少了一些生气，我在上面也画了几笔」。
- **王林的回礼**：自储物裂缝取出一道金光化作的**笔**，挥笔勾勒并反复叠加至符文极为复杂，留笔于虚空，言：「此笔为**仙宝**，配合这些符文施展，以你的修为，足以发挥至强之威。」随后化虹离去。
- 李倩梅笑言「回答出了我三个问题，我不会让你跑掉」，吹笛相送，笛音回荡星雾；许久后收起金笔，踏虚而去。
- **画轴内容**：王林途中展开，见江河湖泊尽成干枯，河道上**两条鱼紧贴一起、相濡以沫**；他皱眉苦笑收起，在笛音陪伴中远去。

## 三、玉镯的巧合

- 王林循星图疾驰，忽见前方星雾中一团翠绿之光——正是李倩梅随手抛出的玉镯，抛出方向竟与星图路线同在一条线上。
- 星雾广阔，即便同向，能看见此镯亦如大海捞针。王林默望许久，虚空一抓收下，轻叹而去。

## 四、蛮荒大陆会合：同行者阵容与试探

**地点**：五阶星域蓬莱不远处星雾内，一处很小的蛮荒大陆，凶兽不多、平日罕见修士。

**先到三人盘膝而坐**：
1. 苍松子；
2. 满脸坑洼的老者（云魂子唤其「庞道友」），曾在苍松子私人聚会中与王林相见；
3. 青衣老妪（苍松子称「赵道友」），亦为王林熟悉者。

**分工与分成**：
- 坑洼老者质疑：那地方所在是我等最隐秘之事，为何让吕某人同往。
- 苍松子答：**此人可以施展役灵印**，有他在，成功把握**再添两成**；另需**赵道友的神通开路**，事成之后按约定，所得之物**任由赵道友先选三样**。

**云魂子登场**：
- 黑白双色道袍、头戴道冠的老者破雾而出，缩地成寸般数步即至；刺耳笑声回荡。
- 特征：浓浓血腥气弥漫，身后雾中**无数阴魂**时而露头、传出无声凄厉；面色极为苍白，双眼炯炯、露阴森幽光。
- 自陈「途中遇到仇家，来的晚了一些」；与庞道友显是旧识（「咱们又见面了」）。
- 问「这一次就我们四人」，苍松子答「还有三位想必应该快到了」——即此行共约**七人**。

**冲突起点**：
- 王林一身白衣、黑发飘动、双目冷漠自雾中走出。
- 云魂子皱眉：「**净涅小辈**苍松子，你让一个净涅小辈参与此事」
- 苍松子微笑：「**他可不是净涅**」
- 云魂子目光一闪，趁王林走近瞬间右手前挥，**身后无数阴魂骤然呼啸直扑王林**（章末悬念）。

## 五、要点归纳

- 交易落定：铠甲 → 苍松子；八万元晶 + 星图玉简 → 王林。王林借此取得随苍松子前往秘地的「资格」。
- 情感线推进：三问三物之约收束于「互不受赠」，却各自留下了对方之物（王林拾回玉镯、李倩梅收起金笔）；画中干枯河道与相濡以沫双鱼为本章意象。
- 伏笔：兽乱严重（李倩梅师尊之言）、苍松子秘地之行的巨大收益、王林境界被误判为净涅、云魂子的阴魂手段与其对王林的敌意试探。
