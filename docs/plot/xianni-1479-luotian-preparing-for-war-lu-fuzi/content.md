# 第十卷 叱咤界内 第1479章 备战中的罗天

## 一、罗天备战：西北星阵

- 罗天星域气氛紧张，**西北部**有一处由 **四百三十九颗修真星** 组成的磅礴星阵。
- 星阵外诸多修士往来穿梭，不断**凝固此阵威力、打下印记**；更远处修士成组在领队指挥下，从茫茫星海挑选并**强行拖来**大量修真星。
- 星阵内部有一片**云雾漩涡**，雾中盘膝坐着一位道袍老者——**鲁夫子**。

## 二、鲁夫子其人

- 罗天星域内的**第三步大能，空涅初期**；界内数万年难得一遇，地位如同仙神，视一切修士如蝼蚁。
- 被称为**整个罗天星域的守护者**，更是**当年发起与（修真）联盟大战的真正之人**。
- 面色略显苍白，吐纳之中**雷鸣轰轰**，如同体内蕴含无数天地之雷。
- **生平唯一狼狈**：败于**拓森**面前，逃之夭夭；事后拓森出现在罗天星域时，他施秘术急急隐藏，待拓森离开才重新现身。此后行事更为谨慎。
- 疗伤：虽无足够**香火**，但另有特殊方法，与拓森一战的伤势渐渐恢复。

## 三、王林踏入罗天，威压横扫

- **触发点**：王林从古墓走出、踏入罗天星域的一刹那，打坐的鲁夫子猛地睁眼，精光一闪。
- 未及细究，便感受到王林散发、**横扫整个罗天星域的威压**，鲁夫子面色大变、霍然起身，以目光远眺欲穿透一切。
- 然而尚未看清，即被**冥冥之中的大力轰入神识**，心神瞬息绞乱，眼前一花，一切模糊。
- 鲁夫子判断：
  - “此人是谁看不清样子”；
  - 其**神识有些似曾相识**；
  - **应该没有达到第三步**，却令自己**心惊肉跳**。

## 四、漩涡内的四位旧识

星阵漩涡内还有四位老者盘膝而坐——若王林在此，一眼便可认出皆是当年熟悉之修：

| 人物 | 身份 | 与王林的旧因果 |
| --- | --- | --- |
| **炎雷子** | 雷仙殿 | 跟随鲁夫子最久；自问对王林**没有出格之处，且还有一些小恩** |
| **烈云子** | 战家老祖 | 当年被**王巍**重伤；与王林接触次数最多，最后一次在**朱雀圣宗**被王林逼压 |
| **血神子** | 姚家老祖 | 曾**追杀王林**，被**清水**所阻，事后在联盟重伤恢复 |
| **向云东** | 向家 | 当年带王林去**向家祖星**，令其承受**七夕之术**；向家老祖借“为其妻治疗”之名，吸走王林几乎全部生机 |

- 四人见鲁夫子失态而心神一震；随后那股威压自遥远星空横扫而来，如大力撞击，四人面色大变、几有崩溃之错觉，威压一闪即逝后仍面色苍白。

## 五、罗天幻镜与“滚开”

- 鲁夫子性格谨慎，不愿在不明所以前亲自查探，遂令四人**布“罗天幻镜”**。
- 施法过程：四人分坐**东南西北**四方，双手掐诀，施展**鲁夫子所授、如今已修行圆满的同一神通**；白光在四人中间越来越亮，化作一幕**如水面的白色镜子**，其上扭曲波纹、略有模糊。
- 鲁夫子右手掐诀，**食指如剑隔空点入镜面**，波纹骤顿平息，镜中浮现星空与一名**白衣白发之人**缓步而行。
- 王林于罗天缓行，四周熟悉，轻叹：“**不知当年之人，今时是否还在**”；旋即皱眉抬头，**右目瞳孔内雷图一闪**，喝道：“**滚开**”。
- 雷图自瞳孔呼啸幻化，星空轰鸣，**破开虚无**而去，不知去向。
- 幻镜端：镜面爆起惊天雷霆，万丈闪电横扫天地，镜子**四分五裂**；鲁夫子大袖一甩把崩溃冲击卷起推向天空，无尽雷霆升空持续轰鸣，**整个星空似被雷霆取代，如同雷劫降临**，震动八方修士。

## 六、四人反应

- **炎雷子**：喷血急退，心中疯狂呐喊“**王林——他是王林**”，永难忘其身影；后渐渐平静笃定，但震惊永久不散。
- **烈云子**：同样喷血后退，骇然滔天，一时呆立说不出话。
- **血神子**：面色刹那苍白，不敢相信当年那个如蝼蚁般被自己追杀、若非清水阻止便会死在自己手中的小人物，如今竟有此威压。
- **向云东**：修为最弱，元神弥漫王林冥冥中的雷霆之威，**道心留下一道深深裂缝**；第一时间想到向家老祖借治病之名夺走王林全部生机所结的大仇。向家原本仗着老祖闭关数万年而不以为意。

## 七、鲁夫子的定性与决断

- 回忆确认：“**当年在那联盟内，古神之地，此人老夫见过**。”
- 判语：“**此人修为，没到第三步——但老夫没有把握可以战胜。**”
- 表态：“**你们与他之间的事情，老夫不会理会，留在这里，可保平安。**”言毕走向漩涡深处。

## 八、后续动向

- **向云东**：恭敬抱拳后转身急走，要把消息尽快传回**向家**以作万全准备——连鲁夫子都没把握战胜的敌人，向家拿什么来战，心神恐慌。
- **血神子**：沉吟后默默盘膝坐下，**不敢出去**。
