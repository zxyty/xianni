# 仙逆 第399-400章 · 老祖现 / 许立国

## 一、开场：老祖闭关与剑魂许立国

- **地点**：巨魔族北边一片平原地下千丈，一座通体晶莹的洞府。
- **人物**：巨魔族老祖，盘膝吐纳，相貌堂堂、棱角分明的中年人形（夺舍所得肉身）。
- **心态**：听闻王林声音回荡巨魔族全境，自语『且让你再嚣张一会，待老夫彻底与肉身融合后，再去杀你不迟』；并称王林虽封印了巨魔族，但他夺舍成功后『解开就是』。

### 剑魂许立国出场
- 老祖储物袋散出黑芒，飞出**当年夺自王林的仙剑**；剑上黑气化作**许立国**之形。
- 许立国双眼通红请战，口称『主人』，痛骂王林『杀千刀的』，要求日后杀王林时『让小的去捅最后一刀』。
- 许立国对老祖列举王林之『恶』：强迫干活、时常唤出打骂、一点好处不给；反赞老祖时常赏灵石让他吸收，还索要女修赏赐。
- 关键台词：许立国索要『仙子小妹妹』——即**凤栾之魂**。
- **叙事点破**：许立国脸上讨好，**内心却是暗骂**——其忠顺是伪装。

### 老祖的控魂之术
- 老祖判断此剑魂『充满人性贪念』，故『灵石、女修老夫全部送他』，自信其不会叛。
- **凤栾之魂**：老祖当年无意中所得一件法宝内的**法魂**，千娇百媚、散发媚惑之气；当年险些令老祖自身迷失，幸而该法魂有所破碎方逃过一劫，故老祖对其极为忌惮。
- 老祖曾唤出凤栾之魂控制许立国，许立国一见便如野狼扑上，被迷得神魂颠倒——此即老祖认定『跑不出我手心』的筹码。

## 二、王林寻敌

- 王林在巨魔族上空久候不见老祖现身，面色阴沉；巨魔族地域广大山峰众多，藏匿难寻。
- **伏笔**：神识扫过时，目光落在**极东处巨魔族最高的一座山峰**，看向此山的一刻『内心升起一股奇异之感』；正要查看却转念察觉北方，遂搁置（未探）。
- 王林口呼『许立国』，身影一动向北疾驰——是感应到自己的仙剑/剑魂所在。
- 以**三星吉神（古神）之躯**飞行，速度快若奔雷，几个瞬移抵达北面平原。

### 破土逼战
- 神识发现地下千丈有一层薄薄阻碍，神识扫过会被『轻轻斜移开来』，非近距离难以察觉。
- 王林右拳三击地面：
  1. 第一拳：大地碎裂纹蔓延方圆百丈并向下延伸。
  2. 第二拳：大地如地龙翻滚咆哮。
  3. 第三拳伴喝『巨魔族老祖，滚出来』：平原坍塌成深坑，一道青影冲出。

## 三、正面交锋

### 第一阶段：纯肉身对拳
- 老祖现身自称/被称『曾牛』，喝『本不想这么快了解你，但你既然找来，便是在找死』。
- 首次对拳：老祖退后数丈、**右拳骨头出现裂纹**，大惊；王林退后数步，庞大力道冲入体内疯狂撕扯，被**元神压制化解**。
- 王林评价：『巨魔族的炼体之术，果然玄妙』。
- 老祖内心叫苦：肉身未完全融合，**实力只能发挥八成**；但巨魔族天赋肉身强悍，甚至不畏一些法宝。
- 王林一拳形成**类似困牢的气场**并幻化无数韧性灵丝捆缚，被老祖大喝震溃；老祖横踢再撞王林拳头。
- 王林判断：老祖此刻肉身『只比三星古神弱上一筹』，若完全融合则与三星古神躯体相差无几。
- 老祖之所以此前不愿现身，正因看到**王林毁灭十二巨魔天**。

### 第二阶段：仙力全力一击
- 老祖身躯胀至十丈巨人，调用体内**仙力**，金芒扩散如太阳。
- 设定要点：老祖仙力凝聚程度**远非李元封可比**，因其完全凭自身一步步修炼至**婴变初期**。
- 一动之下四周虚空空间碎裂，大量**寂灭寒风**吹出扫向大地。
- 与常规修士以法术神通释放仙力不同，巨魔族以肉身为最佳武器：一拳兼具仙力 + 巨魔族冲击力 + 肉身爆发力，整个北方平原崩溃坍塌。
- **代价**：一旦以此未融合肉身动用仙力，该肉身即报废，须另寻肉身；除非修为达**婴变中期**，否则无法再融合被仙力冲击过的躯体。

### 王林的应对（三星古神之力）
- 王林感到危机感——这是**本尊与分身融合后，除天道轮回之外的第二次危机感**。
- 眉心闪现**三个星点**迅速转动，散出紫色气息笼罩全身；身后**古神虚影**再现。
- 王林轻轻一拳，古神虚影同步击出巨拳，与老祖隔空三声巨响硬撼。
- 结果：老祖面色苍白喷出大口鲜血、身子萎靡；王林被远远抛开，**整只右臂酸麻失去知觉**，身躯从十丈缩回常人大小，但目光明亮。

## 四、转折：仙剑反噬

- 老祖一拍储物袋祭出**仙剑**，双手隔空虚点，喝『斩』，狞笑称『且看老夫以你法宝，来斩杀你』。
- 仙剑黑芒化出许立国虚影，尖叫『王林，老子来报仇了』。
- 王林嘴角嘲讽，**不闪不避，虚空一点仙剑**——仙剑斩势骤然转向，以迅雷不及掩耳之势反扫其主。
- 老祖闪避不及，仅来得及挪移半分，**左臂被彻底斩落**，惨哼中化作血光疯狂后退。
- 老祖怒吼：『许立国，老夫定要把你炼魂抽魄，把你封印在阳火之地生生炼化』。
- 退走原因：肉身未融合 + 强行动用仙力已受伤，王林一拳威能不弱于其仙力一击，令其伤上加伤。

# 许立国倒戈与巨魔族极东之战

## 一、关键转折：许立国临阵倒戈

- 巨魔族老祖判断王林此刻亦受伤，取出**仙剑**欲趁机一剑斩杀王林。
- 就在此关键时刻，附于仙剑之上的**许立国**突然倒戈，一击之下老祖闪躲不及，**当场断臂**。
- 许立国大笑尖声：“孙子，任你再厉害，也比不过你家许爷爷，老子许立国一向衷心不二，哪能那么轻易让你制服。”随即转身向王林讨好邀功。
- 王林微笑允诺：“立功了，等杀了此人，我送你去**域外战场**，让你**吸收游魂增加魂力**。”

### 倒戈动因（三重）
1. **惧怕王林**：这两年许立国多次动摇（巨魔族老祖待他不错），但每想到王林对付游魂以及“老二、老三”的手段，惧意压过一切。
2. **趋利避害的判断**：在他看来王林一路杀戮极重，凡惹此人者无一幸免，巨魔族老祖也难逃此命运，故绝不能站错队。
3. **对凤栾法魂的承诺**：他与该法魂勾搭时，亲自答应过**时方**，定要把她从巨魔族老祖手中救走（心中念着“仙子小妹妹”，欲“救她出火海”）。

### 情报：法轮内的魂魄
- 许立国提醒王林：巨魔族老祖**储物袋**中有一法宝——**法轮**，其内**封印着一个魂魄**；请王林杀老祖后把该魂魄救出。王林点头应允。

## 二、追击与巨魔族极东之地的决战

- 巨魔族老祖咆哮愤怒，怒火大半源自许立国背叛——他自认两年待其极好，更把自己封印的**银欲魂魄**取出相赠，扬言“老夫定要把你生生炼死”。
- 王林持仙剑一斩，剑气呼啸；老祖闪避后疾驰至**巨魔族极东之地**，转身停步迎战。

### 老祖手段：黑色火把与黑炎之兽
- 一拍储物袋取出**黑色木棍**，一晃生出黑色火焰，木棍化为**火把**。
- 放言：“王林，今日此地便是你葬身之处，你的身体，将是老夫下一个**夺舍**之物。”
- 火把一挥，方圆千丈在王林踏入后化作**黑色火海**。
- 火把插地，双手掐诀、仙力环绕打出仙诀，四周火焰向火把中央凝聚，化出高约**十丈**的**黑炎之兽**：头大如斗，遍身利刺、每根利刺燃火，形似巨熊而非熊。

### 王林的破法（三段）
1. **仙剑剑芒**：一斩之下黑炎兽退后数步、胸口现深伤，但伤口**立刻愈合**。
2. **禁幡·封与爆**：一拍储物袋取出**禁幡**，一抖化无数禁气，喝“封”，禁气化作**黑色长枪雨**钉入四周封死此兽前后左右；再右手一点喝“爆”，长枪尽爆，热浪四推。
3. **千魂幡·灭**：储物袋飞出一杆魂幡——**并非十亿尊魂幡，而是王林自炼的千魂幡**，因有**李元封**魂魄作**主幡**而威力极强。幡出数千魂魄，当头即李元封（神智已被王林抹去，全凭本能行事，为受封主魂、婴变层次），王林喝“灭”，众魂凄厉冲向刚从禁气自爆中逃出的黑炎兽。

## 三、悬念：先祖遗留之物出世

- 王林判断：以对方**婴变初期**的神通，绝不止这些手段，必有杀手锏未出，且退到此地**定有用意**。
- 巨魔族老祖深吸口气，掐诀凝出巨大**法印**推上天空，化作无数细小法诀消散于天地。
- 其人飘于半空、**双膝跪地向天拜下**，喝道：“巨魔族**第六十七代族人**，取出**先祖遗留之物**，解我巨魔族一劫。”
- 天空黯淡，整个巨魔族大地颤抖；巨魔族极东之地那座**最高之峰**（高插云端）轰隆声中**从中一分为二**，一把**闪烁红光的巨大斧头**缓缓升空。

## 四、要点与后续看点
- 王林与许立国的关系确立为“主子—走狗”，以恐惧+利益（游魂/魂力）维系，非忠诚。
- 待办伏笔：①杀老祖后取法轮、救出其中魂魄（凤栾法魂/时方线）；②送许立国去域外战场吸收游魂；③红光巨斧作为巨魔族先祖遗物的威力与来历未明。


# 第400–401章 红色巨斧 vs 十亿尊魂幡

## 一、巨魔族老祖祭出先祖红斧

- 巨魔族老祖双目露出**从未有过的崇敬之色**，大手一伸，将散发红光的巨大斧头抓入手中。
- 红色电光自斧上流转全身，头发无风自动，气息暴涨。
- **来历自述（对王林）**：当年巨魔族迁移至**朱雀星**时，先祖以此斧**破开天地**，去**仙遗族**斩杀**两个九叶术咒师**，换取了脚下这片**巨魔族之地**永久居住的权利。先祖今已失踪，此斧却留存。
- **王林的联想伏笔**：望着红色巨斧，王林脑中不知为何忽然想起曾在**赵国尸阴宗地下**看到的那具身体。（暗示巨斧与那具身体/其主人有关）

## 二、红气循环与断臂重生

- 握斧之后，老祖「好似化身另外一人」。
- **红气循环机制**：红气从斧内流入身体 → 再自五官七窍散出 → 被斧子吸收，形成闭环。每持续一息，气势便增强一分；远看极为狰狞。
- 此前被**许立国**砍掉的**左臂**处红气涌现，**募然化作一只红色手臂**，并抓住抛出的斧子。

## 三、第一次交锋：斧剑对撞

| 一方 | 结果 |
|---|---|
| 王林（横抬**仙剑**接斧） | 嘴角流血，身子后退**百丈** |
| 巨魔族老祖 | 喷出一口鲜血，**一步未退**，但肉身肉眼可见萎缩约**三分之一**，不复之前强壮 |

- 老祖随即如远古凶兽般咆哮，双眼刺目红芒，化作红色闪电再度冲击劈斩。

## 四、十亿尊魂幡首次施展

- 王林后退中右手掐诀、向前虚握，轻吐二字：**「尊魂幡」**。
- **形制**：高三丈、幡布更宽，通体**紫色**，其上**十二个金芒**闪动，发紫金之光；通体虚幻如闪烁明火。
- **异象**：天空骤暗，光亮尽凝于王林身前；大地无数孤魂野鬼哀嚎，黑气自地面升起争先逃离；天空昏暗如黑沙瞒天、日月损落。
- **效果**：老жи…巨魔族老祖冲势立缓，手中红斧剧烈嗡鸣；其双眼红芒中露出**惊骇与隐藏极深的畏惧**，隐约认出「这是炼魂宗的——」，但不敢相信记忆中的那杆魂幡会出现在王林手中。
- 明确记述：**十亿尊魂幡，第一次被王林召唤施展**。

## 五、边界观战者：柳眉与传承真相

- 巨魔族边界处一直观望此战的**紫衣女子（柳眉）**秀眉一皱，自语点破关键：
  - **遁天把她赶出炼魂宗，原来是想让王林继承十亿尊魂幡的传承**。
  - 王林所召仅是**虚幻分幡**，但威力已非巨魔族老祖可抵抗。
- 柳眉长期**探寻王林道心**而始终发现不出端倪；判断唯有趁王林**昏迷**时施展秘术，或许可成。
- 她抬步欲往，忽然顿住。

## 六、周武泰登场（第401章标题人物）

- 一名**头戴草帽的紫袍大汉**自远处一步步走来，人未到声先至：「**柳眉姑娘，你的对手，是我**」。
- 柳眉辨认：对方持有**云雀师叔（云雀子）的离冥草帽**，应是云雀子**选取的四人中的一个**；但其修为仅**化神中期**，不足以拦下自己。
- 大汉自称「**周某**」，坦承不敌，只因**云雀子有命不敢不听**，提议与柳眉**把酒言谈**，少顷之后回去复命，如此也算有了借口。

# 第401-402章 十亿尊魂幡战巨魔族老祖

## 一、支线：紫衣女子与大汉的「斩情道」对峙

- 紫衣女子欲先去援助**巨魔族老祖**，再回来与大汉把酒；大汉以「王林是我故交」为由拒绝放行。
- 女子言明不想伤他，转身欲走；大汉盘膝坐地、双手掐诀，**元神一动，意境临身**——身后浮现一名**弱冠少年虚影**，眉清目秀，望向大汉时满是孺慕之情。
- 女子驻足，妩媚尽收，双目透出深藏的冰冷无情，点破其道：**「斩情道」**，并称他因感悟此意境而被**自己的师叔**看中，赞其「好大的毅力，好狠的心肠」。

### 斩情道意境（设定要点）

- 修行路径：感悟师徒之情——**以意动念、以念收徒、以情育子、以恩施惠、以心威爱、以悲入神**，一举一动皆为使自己全身心投入这段师徒之情。

# 第403章 魅姬 — 剧情梳理

## 一、祭炼红芒巨斧

## 二、清点巨魔族老祖的储物袋
王林取出巨魔族老祖的储物袋，右手一抹留下自己神识，内中物品尽现：

| 类别 | 内容 |

| 灵石 | 一些极品灵石 |
| 法宝 | 若干，威力尚可但不出众 |

- 其中**两样物品**格外引起王林注意（见下）。

## 三、红色玉瓶：一丝古神血液
- 形制：红色玉瓶，内装**半瓶血液般的液体**，在储物袋内被**单独放置于一处角落**（说明持有者极为看重）。
- 王林闻后确定确为血液，并生出「仿佛以前见过」之感。
- **回忆锚点**：当年在**赵国灭藤家满门**时，曾从**藤一**身上发现过同样之物。
- 结论：「此物之内蕴含了**一丝古神的血液**，当年以此血液，曾施展出**古神一族的神通之术**。」
- 王林自身处境的关键交代：
  - 他**修炼吉神诀成为古神，完全凭自身修炼而成**；
  - 当年**只传承了古神涂司的记忆，没有传承力量**；
  - 因此**一些古神神通之术无法施展**。
- 价值判断：无论是本尊吸收，还是以此施展神通，都是不可多得之物；**「能得到此物，这一战即便付出再多代价，也值了」**。
- 处置：深吸口气，将小瓶**谨慎放入自己的储物袋**。

## 四、锈迹法轮与许立国的异常
### 4.1 法轮外观
- 寸余大小，表面平淡无奇，**没有任何光泽与灵力**，甚至有些地方**带有锈迹**。

  - 许立国身上有着**游魂所欠缺的灵动**；
  - 这份灵动源于**当年他由元婴转化为魔头**；
  - 此后神智慢慢恢复，最终形成如今的**魔头剑魂**；

- 正因如此，许立国的反常执念构成疑点。
- 王林略一沉吟便猜出大半：**巨魔族老祖定是以法轮内的魂魄诱惑许立国**，使他即便回到王林身边也始终惦记。

  - 女子加码：「他欺负我，你们帮我把他杀了，好么……杀了他后，大不了奴家好好陪陪你们就是。」
  - **李元封连同众魂魄转身狰狞扑向王林**。
- 与此同时，**许立国在王林身后受诱欲偷袭**；王林右手向身后一点，许立国惨叫受伤、**全身黑气呲呲消散**，远远退开。
  - 这一次令其清醒的是**内心深处对王林的恐惧与畏惧战胜了迷惑**。
  - 其内心懊恼：「之前**斩杀巨魔族老祖**的功劳，此刻付之东流」，转而怒骂女子「贱人，都是你把老子迷惑的」。
- 王林神色如常，看都不看扑来魂魄，右手隔空一点、心神一动，**包括李元封在内的魂魄尽数惨哼散开**。

## 四、擒魅姬·意境之魂

- 王林喝「够了，你过来」，右手虚空一抓，女子如被无形大手抓住般被擒至身前。
- 王林打量后看出端倪：**该女子魂魄中蕴含一丝意境，且意境极强，可迷惑世间万物**。
- 王林眼中寒芒一闪：「**有意境的魂魄，有意思**」，随即追问姓名。
- 女子娇喘周旋不答，王林右手**点在其眉心**，其脸露痛苦、惨叫、全身散发黑烟似随时可消散。
- 女子屈服：「**魅姬，我叫魅姬**」，望向王林目露惊惧。
