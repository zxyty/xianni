# 第1343章 诱饵（第九卷 云海之巅）

## 场景
- 冬季清晨，天地银装素裹，鹅毛大雪覆盖草木、结出冰凌；凡人城池村庄升起炊烟，犬吠隐隐。
- 天地东方有一片平原，夏季为凡人放牧之地，此时白茫茫刺目、无任何足迹。平原深处，唯有一人盘膝坐于雪上。

## 一、渡劫者登场
- 该人为中年男子，相貌英俊、一脸正气，神色平静而复杂。
- 自言「修为压制不住了」，留恋地望着雪景，静待天劫。
- 劫云成形，云中立一浑身仙气缭绕、威严无尽之人，喝道：「下界修士，渡劫成仙。」
- 中年男子毫无喜色，只重复「成仙」二字，嘲讽之意更浓。
- 第一道天雷落下，他抬手一按硬接，面色苍白而头颅始终抬起。

## 二、王林撕劫云、劫杀云端仙人
- 第二道天雷酝酿之际，一股力量化作两只大手撕开劫云，白衣青年王林自裂缝走出。
- 云端仙人（老者）怒喝「你是何人此地老夫先来」；王林答：**「我为你等天劫，来此地，灭天道，收念雷。」**
- 王林抬手一指，老者体内雷霆失控狂暴；老者不退反进，爆发**窥涅后期大圆满**修为（隐隐将入净涅），吐出一粒由**五道念雷**组成的雷光珠子。
- 王林言「这珠子，我要了」，一步之下瞬移至其身后，未回头随手向后一指点在后脑：老者喷血、血丝裂纹蔓延全身，肉身崩溃、形神俱灭，**族印被收**。
- 王林捏爆珠子，五道念雷被**右目**吸收，在其右眼瞳孔中旋转，令其显出妖异之感。

## 三、以渡劫者为诱饵的批量猎杀
- 王林命地面的中年男子「散开全部修为，继续渡劫」；男子压下不安照做，**化神巅峰**之力充斥天地。
- 十息后劫云缺口再开，一人狂笑而出（「终于被我碰到了一次渡劫者」），话未落即被王林一挥手轰爆。
- 又一人极为谨慎、掐诀环绕大量防护冲出，防护连同肉身在惨叫中崩溃、形神俱灭。
- **一炷香**内十多名闪雷族之人陆续前来，无一例外一现身即灭。
- 中年男子由目瞪口呆到麻木，明白自己成了白衣青年的**诱饵**，惊道「他竟然击杀仙人」，索性闭目不看。
- 又过**半个时辰**，死在王林手中的闪雷族人**不下上百**。作者点明：此法比王林自己去寻找快上不少。

## 四、诛杀闪雷族碎涅老者
- 一名黑袍老者自缺口走出，一眼看到王林与弥漫的血腥气息，杀机毕露，怒斥：「以这种方法残杀同族，你，该死。」
- 该老者果断非常：身子一分为二，一道化雷霆冲向王林，另一道惊慌后退并施**挪移之术**逃离——以毁一具分身为代价换取遁走。
- 关键设定披露：**王林眼下并非本体**；若无**极境**在身，仅凭碎涅修为想留下此人还须周折。
- 王林双目红光一闪，**极境**闪烁化作红色闪电，轰隆间穿透阻路的分身（分身双目黯淡、崩溃），再冲入即将挪移的老者本体：老者喷血、眼中光芒崩溃、元神毁灭，尸体坠落，**眉心族印被收**。

## 五、逼出散灵上人
- 杀碎涅老者后，王林转身望向远处虚空，极境所化红色闪电对准彼处，发出啪啪雷霆交错之音，随时可毁天灭地。
- 虚空波纹扭曲，先前拿走尸体、被这**七百万天地**修士称为**散灵上人**的光头青年显形。
- 王林平静开口：「你一路跟随至今，我只给你一句话解释，若无法让我满意，你，会死。」——本章于此收束，构成悬念。

## 归属与身份说明（据世界状态须知）
- 本片段以本名「王林」直呼，但按世界状态须知，王林自第1242章起以一部分元神**夺舍于非**之身、冒其身份潜入闪雷族；本章文中亦明言「王林眼下毕竟不是本体」，与该设定一致。
- 「渡劫的中年男子」「云端仙人（窥涅后期大圆满老者）」「黑袍碎涅老者」「散灵上人（光头青年）」在本片段中均未给出正式姓名。

## 要点提炼
- 手段：撕开劫云 → 逼渡劫者持续散功引雷 → 守缺口对进入者逐一秒杀，实为**以天劫做陷阱的批量收割**。
- 收获：五道念雷入右目；上百闪雷族族印；碎涅老者族印。
- 战力刻画：随手灭窥涅大圆满；极境红电可穿分身直取碎涅本体、断其挪移。
- 悬念：散灵上人为何一路尾随。
- 作者附言：连续两天爆发，当日状态不佳休息一次，次日继续爆发（非正文内容）。
