# 第1906章 空劫！！！

## 一、第七劫：十息枯神劫（承前）

- **蝎魂补元神**：王林吸入由浓浓天地之力组成的蝎魂，枯萎元神如吞大补之物疯狂逆转恢复。第六息元神再度枯萎，与蝎魂之力达成平衡，但此平衡无法久持，除非持续补入更多天地之力。
- **常规度劫法**：其余修士度此劫皆靠不断吞噬丹药硬撑——挺过第七息元神不灭，再硬挺三息、满十息即过。但最后三息远比之前可怕数倍，丹药消化速度远追不上枯萎速度，故丹药品质极为关键，纵有最好丹药亦生死难料。此劫度劫者完全被动，连大天尊、乃至传说中无数年来仅有的两位连度九次玄劫的大天尊，也都是咬牙硬挺至十息自散。
- **王林的判断**：他一眼看穿关键，也想到可去寻绿魔蝎真魂被镇压之处吸其力度劫，但耗时不知多久；更重要的是——「让自己屈服于此劫、在其下苟且存活」的方式，他不要。
- **信念不灭**：「劫，也是造化。」第八息后元神仅余一丝，其中蕴含他一生修道从不屈服的信念与复活李慕婉的决心；第九、第十息皆无法磨灭这一丝信念元神。三段自誓：「我相信我的元神天地不朽／我的存在无法磨灭／我的人生在自己手中」「我相信这一切之劫都将烟消云散／我可以复活婉儿／我可以踏入天地之巅」。
- **撕劫**：十息过后信念元神轰然爆发，王林向天迈步、双手抬起撕向虚幻符文印记，印记隐隐化作实质后崩溃；其元神之力骤然攀升至巅峰后再度暴增。**第七劫在王林面前崩溃。**

## 二、第八劫：十息寿魂劫（魂三劫第二劫）

设定要点：

- 第二个符文印记更复杂，散发无尽沧桑之味。
- 此劫**不伤元神，唯索魂寿**，可化岁月流转；魂寿归时则魂亡，一息万年，悠悠岁月一呼吸间消散。
- 目的不在轰杀修士，而在令度劫者**自行祭献寿元**——修士掌握主动，自行决定祭献多少。
- 与第九劫息息相关：祭献十万年寿元则第九劫迈步可过；不送寿元则第九劫九死一生。空玄境中寿元逾十万年者，非有莫大机缘造化不可能拥有。
- 常规做法：自行计算够修炼所需后，把余下寿元忍痛全部祭献，以换取度第九劫的把握。
- **踏入空劫后寿元不再增加**（除非修至大天尊或另有造化），祭献后剩多少，整个空劫境界内就只剩多少。
- 祭献后即可选择退出，哪怕只献一年也算完成第八劫——只是第九劫将难上加难。

王林的选择与推论：

- 看到印记的刹那，其脑海凭空多出奇异思绪，令他瞬间明悟此劫全貌。
- 他意识到自己以往的判断不准：许多他以为在高次玄劫的修士，其实大都止步于第八劫。
- 他不知**七彩仙尊**当年如何度过此劫，猜测其或另有造化。
- 沉默许久后按向符文：**「祭献，一年。」** 身子微颤，第八劫符文消散。
- 他没有退出，抬头等待最后一劫——因为他早已打定主意：第九劫不度，而**毁**。

## 三、第九劫：轮回劫——毁劫

- **第九劫名「轮回」**，是阻止修士成为空劫大尊的最后门槛，威能似可改变岁月、令人沉浸轮回无法自拔而死。
- **三身齐射**：
  - 王林本尊：虚空一抓取出许久未现的**李广弓**，拉成满月，**李广箭**现；体内**仙祖发丝形成的经脉**透出仙力涌入双臂，弓绽万丈金光，化作仰天咆哮的**金龙**。
  - **五行真身**（左侧）：手持虚幻李广弓箭，散蓝、红、黄三色光，对应**水、火、土**三种本源，化作三条狰狞长龙。
  - **雷霆本源真身**（右侧）：自王林眉心雷霆闪烁中出现，持游走闪电的虚幻李广弓箭，化作**雷龙**，带毁灭之息与禁制规则之息，其力甚至压过五行真身与王林本尊。
- **五龙撕天之印 / 五箭索天之命**：金箭先入印记令其欲崩，三色箭随后三声巨响轰出大量裂缝，最后雷霆一箭（其中杀戮之雷之力仅一丝却足以惊天）冲入，轮回印记四分五裂化作碎片卷向天空。
- **信术之近**：此箭蕴含王林憎恨天劫、毁灭玄劫的坚定信念，令本可无形的印记「无中生有、凝固成形」——已无限接近大天尊的**信术**。
- **恨之根源**：王林对天劫之恨，可追溯到**朱雀星洞府**上他抱着李慕婉、面对天道索命时绝望愤怒的嘶吼。

## 四、结果与影响

- **绿魔蝎庙**（巨大蝎子形建筑）无法承受震动，轰然坍塌瓦解，碎石卷向八方。
- 尘雾中升起一股让苍穹色变的**空劫气息**，形成风暴漩涡，屹立于**绿魔洲**最中心（原蝎庙之地）——王林**修为突破空玄，踏入空劫初期（大尊）**。
- 数千里外十余名绿魔洲修士先被「毁劫」二字震得面色苍白（「这等狂妄之事，唯有绿魔大人才可以做到」），玄劫威压散去后快速接近下拜：**「参见绿魔大人」「恭贺绿魔大人复活」**——王林在绿魔洲的「绿魔大人」身份就此坐实。
