# 第九卷 云海之巅 第1288章 十年前的威名！

## 一、开场：仙音门守阵弟子的闲谈

六阶星域一处大陆的传送阵外，十余名仙音门弟子盘膝看守。一男一女低声交谈，话题正是『吕子浩』（即王林化名）：

- 女修不信：能杀死仙音门上任宗主、长老与大师兄的人物，无极宗必全力保护，怎会已死。
- 男修转述传闻：吕子浩得罪神宗，十年前被神宗追杀，**毙于五阶星域**。
- 男修评价：此人『也算云海天骄』，只是狂妄自大，招惹了神宗。

补充设定：下阶星域来人须向守阵者奉上晶石，是**云海的规矩**。

## 二、强行加速传送，撕裂阵法而出

传送阵光芒骤然暴增至巅峰，天地轰鸣、无尽元力疯狂灌入，阵体裂缝迭生。守阵男修怒斥『强行加速』并祭出飞剑，随即阵法轰然崩溃，两道身影冲出直奔星空——那男修一眼认出王林相貌，脱口『吕子浩』。他当年正是去过无极宗、亲眼目睹王林战斗与其宗主长老三人死亡之人。

白发老妪心有余悸地道破手法之凶险：**为省半刻钟等待，在传送途中强凝天地之力使传送瞬息完成，稍有差错便死于空间撕裂**——『只有疯子才会去做』。

## 三、一掌崩碎仙音门护派大阵

白发老妪指路：最近者为仙音门，可由此传送去无极宗。王林几乎全速踏破星空，直奔仙音门三座大陆。

- 仙音门作为六阶星域宗派，护派阵法**即便碎涅修士也需一段时间方能破开**；若有碎涅修士出手巩固则更强。
- 王林至阵外抬手下按，掌心五指处生出五道裂缝，如五道恶龙覆盖全阵，**一掌之下大阵轰然瓦解**，碎片如镜裂倒卷，冲击横扫，仙音门修士纷纷后退。
- 原文定评：『一人，一掌，一步之力，震撼天地。』

## 四、十年前的威名：仙音门的惊恐

仙音门上下哗然：

- 『是吕子浩！杀了上任宗主与大长老的吕子浩！』
- 『此人不是已被神宗斩杀了么？』『连神宗都杀不死他？』
- 当年仙音门**宗主、长老、弟子（大师兄）三人全部死在王林之手**。

新任宗主额头出汗，判断：此人当年可瞬杀三人，十年后修为更恐怖，**绝不能招惹**，只求尽快送走这个『煞星』。

## 五、索取元晶与开启传送阵

王林冷声下令：『开启去往无极宗传送阵，拿出全部元晶。』语如天威，无人敢说半个『不』字。仙音门全宗运转、迅速开阵，并取来**全宗所有元晶的储物袋**奉上。

本章交代的传送规则：

| 阵法 | 规则 |
| --- | --- |
| 海魂派传送阵 | **双向通行**，不需另一方打开，在海魂派即可传送 |
| 仙音门（六阶）→ 无极宗（八阶） | 凭六阶身份可**自行开启**，无需无极宗那边打开；限制：**一次传送不超过三人**，抵达后受严加审核，无要事必受严惩 |
| 通往八阶星域之阵 | 无等待过程，几乎转眼即达 |

白发老妪的旁观视角：她常年在**妖宗战场**，不知十年前之事，见仙音门长老与宗主对王林『似送神一般』的惊恐畏惧，先前对元晶的担忧化作苦笑——『恐怕即便是无极宗来要元晶，这仙音门也不会如此快速，更有可能隐藏一些。』

王林离去后，仙音门宗主望着空阵与崩溃的护派大阵：『他莫说是要元晶，就算是要整个仙音门，老夫也拱手相送，只求他能尽快离去。』

## 六、抵达无极宗与下一步

八阶星域无极宗一处修真星内，阵光大盛，王林走出——**时隔十年重返无极宗**。

> 『在这无极宗，我还要取一样法宝。』

## 七、关键动向 / 后续伏笔

- 王林十年前的威名随目击者散播，本章重现使整个云海掀起风暴。
- 与**神宗**的旧怨（十年前追杀、传其死于五阶星域）成为本章反差核心：他不但未死，修为更强。
- 王林在无极宗欲取『一样法宝』，为后续情节埋线。

## 八、归属说明（据世界状态须知）

本章所有『吕子浩』的言行**均归属王林**：吕子浩为归元宗故人之名，自第1063章由吕烟菲主动奉上，王林以此化名/冒用身份立足云海星域。
