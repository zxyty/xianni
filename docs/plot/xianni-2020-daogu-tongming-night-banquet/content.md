# 第2020章 夜宴

## 一、通明夜宴的规制

- 道古一脉皇族历代古皇，都会在**封后大典前一天夜里**举行**通明夜宴**：夕阳落时开始，清晨结束，宴罢众人随即参加大典。
- 夜宴上，**道古皇尊会带着其册封之后出临**——这是被册封皇后第一次于此种场合出现在众人面前。
- 流程：皇后接受夜宴众人祝福后先行离去；皇尊则与众人同至夜宴结束，再展开大典。

## 二、宴场布置

- 地点：**皇宫正殿外的庞大广场**。夕阳下，宫中仆从摆置大量**青松案几**，密密麻麻竟有数千之多，**成扇形朝向皇宫正殿，如向正殿一拜**。
- 皇宫天空另有**数百座小型漂浮平台**，每座平台放近百案几，用以招待来客。

## 三、九声鼓鸣与出场序列

**巨鼓**：皇宫中心一面约**数百丈大小**的巨鼓，不知何种兽皮制成，散发沧桑之气兼有凶煞弥漫。鼓上漂浮**九名黑衣人**，每人修为**堪比天尊**；每次鼓鸣皆由九人同时出手，在天空以九人之力凝聚出巨大虚化手掌拍击巨鼓。鼓声不散，如波纹扩散，笼罩整个**天空之城**与城外近千个巨大平台，使所有古族族人尽闻。每隔一刻掀起一次，将虚弱时新鼓再起。

## 四、道古一族的五等武力体系

原文借旁观议论点明：**道古（原文作「道吉」）一脉，分禁、圣、煞、王、不灭将**。

### 1. 道古一百零八禁
- 一百零八人，身穿**白色铠甲**，齐向正殿一拜后盘膝而坐。
- 传闻**每人都是杀戮滔天之辈、满身煞气**，故而封为「禁」。
- 出现后引来羡慕、阴沉、审视与观察等各色目光。

### 2. 七十二圣（七十二圣脉）
- 以七十二道旋风降临，有男有女、有老有少。
- 皆有**神、妖、魔圣一般的气息**，**双目与眉心竟都有二十七星**。
- 曾为道古一族立下赫赫战功；**七十二圣脉代代均为七十二人，不多不少**，已传承守护道古无数岁月。

### 3. 三十六杖（被讥为「三十六煞」）
- **道古皇族亲卫**，集整个道古一族的资源与力量，为历代皇尊打造出三十六尊强者。
- 传闻**如同死士，只需道古皇尊一声令下便可自爆**。
- 三十六名大汉**通体红雾、看不清相貌**，出现后向正殿一拜，落座七十二圣前方。

### 4. 道古十八王
- 皇尊之下、**同属皇族的十八位王**，据说每人皆拥有强大力量；**其中十二人平时不得回京，在外镇守十二郡**。
- 坐骑为**十八条黑红妖龙**：以十八双黑红手爪撕裂天幕而出，妖气惊人，**十八双银色瞳孔**，神色狰狞；回旋连成巨大漩涡，形如风暴，**可阻止神识目光的凝聚**。
- 十八王相貌各不相同却隐隐有相似之处，**衣着蟒袍**，颇有威严；落座后妖龙嘶吼钻回裂缝，裂缝散去，夕阳恢复如常。

### 5. 九大不灭将
- 九道黑芒如支撑天地的巨柱降下，层层黑色波纹扩散，化作**九名黑色铠甲巨汉**。
- 煞气浓郁，身周**隐见无数冤魂缭绕**；他们**不拜正殿**，只彼此对视一眼便走向十八王前方的九处案几。
- 王林的评估：九人**堪比仙族闯过天尊涅十三层的越天尊**，**其中一人可达闯过十四层一般的波动**。
- **不灭将席位之前仍空着四个案几**——位次犹在九大不灭将之上，悬念留白。

## 五、王林线

- 王林远远站在距皇宫尚有一段路程的天空上观礼。他来到道吉一脉后停留不久，**回来又闭关三个月**，故一直没抽出时间去寻**烨寞后人**，但此事始终记在心里。
- 见十八王现身，他摸着下巴暗忖：「**不知烨寞当年，是否也是这十八王之一**——或许在这夜宴中，可以看到。」
- 赴宴途中，**越临近皇宫，凭空而生的心悸之感越强烈**。他判断这**不是危机使然**，而是以其修为已能在**有关自身的大事上提前有所感应**；但他反复思索，仍想不出夜宴上究竟会发生什么。
- **第九声鼓鸣**与前八声余音融合，化作罕见轰隆之声，**足以震死修士，连古族身躯也难免创伤**，诡异的是在场所有人只闻其声、身体毫无影响。
- 王林踏着第九声鼓音登上皇宫上空，向最前方走去，**立刻吸引了此地上下众多目光**——章节至此收束，悬念指向他即将落座的位置与那四个空案几。

## 六、伏笔与看点

1. **四个空案几**：位次高于九大不灭将，主人未现。
2. **王林的心悸预感**：明言与危机无关，而是「有关自身的大事」将至。
3. **烨寞与十八王的可能关联**：王林查访烨寞后人的线索或在夜宴上兑现。
4. **封后大典**：夜宴结束即行大典，皇后身份此夜首度公开。

> 归属说明：据世界状态须知，王林自第1380章起以「烨寞（道古烨寞）」之名/身行事，属借势代入化身而非冒名行骗；本章文本直呼王林本名，烨寞在本章仅作为被追查的往昔人物出现。
