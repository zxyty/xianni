# 仙逆 第773章「十三天」

> 卷次：第七卷 名震罗天｜地点：雷之仙界｜视角：王林（化名「许木」）

## 一、背景

李元被姚家一行人（姚姓青年、一名女修、一名阴虚境老者）追杀凌辱，其仙剑被那女修夺去。王林赶至，先一指崩碎姚姓青年肉身、抹去其元神神识化为元力。李元声音中恨意刺骨。

## 二、诛杀持剑女修

- 王林一步数十丈，瞬移至女修身前。
- 女修因目睹姚姓青年被一指抹杀而心神崩溃，视王林为「噬魂之魔」，只知逃、不敢反抗；恐惧在其**道心留下裂痕**——即便逃脱，日后修为亦将大幅降低且再无提升可能。
- 阴虚老者见状不救，转身自逃。
- 王林一指点在女修眉心，元力如暴龙冲入，其体内砰砰爆响与姚姓青年临死时一模一样，肉身当场崩溃消散。
- 其元神化光球被王林虚空抓出，抛入李元体内：一化元力滋养李元元神，二略修复其伤势。
- 女修临死仍不解：被三人凌辱之人为何不早说，他在雷之仙界有这等修为的友人。
- 其飞剑与储物袋尽数落地。

## 三、截杀阴虚老者

1. **拦截**：王林一步与天地相融消失，从老者前方虚空推开波纹踏出，喝「下一个，该你了」。
2. **交手**：紫色雷霆出手即令方圆百丈紫气弥漫，电光凝成手臂粗细的雷霆；老者掐诀升起红色火焰之盾抵挡，盾破，雷霆入体，喷血面白。老者自度**距阳实仅一线之差**，仍无把握战胜王林（王林此时为**阳实**修为）。
3. **审问**：王林寒声问「你等追杀我友几日」，老者答「**十三天**」，并推卸称「全部都是那姚家少主所为，老夫也曾劝说，但身份不同，无法阻拦」。

## 四、行刑：一天一指

王林口吐一字「**定**」，浓郁天地元力弥漫，老者身体乃至元神皆被定住、行动如在水中。随后按「十三天」逐日计数施刑：

| 计数 | 手段 | 结果 |
|---|---|---|
| 第一天 | 双指成剑点左臂 | 左臂崩溃，血肉扇形喷洒后再度粉碎 |
| 第二天 | 双指虚按左腿 | 左腿炸开大半 |
| 第三天 | 抬脚踢右腿 | 右腿崩溃，四肢已废其三 |
| 第四天 | 右手点右臂 | 仅存一肢瓦解 |
| —— | 定身术消散、老者刚恢复行动欲退 | 王林再喝「定」，二度定身 |
| 第五~第七天 | 右手连点胸口 | 每点身躯剧震、口角流血 |
| 最后一天 | 右掌拍天灵 | 全身骨断、血肉模糊，肉身彻底崩溃化血雾 |

老者心神恍惚间反复回响王林现身时那句：「**是谁，给你资格，伤我之友**」，并悔恨「早知如此，绝不会动那李元一根毛发」。

## 五、血祖之疑与搜魂

- 元神冲出后厉啸：「**姚家，不会放过你**」。
- 王林拍储物袋取出**十亿尊魂幡**，一抖化十丈大幡，露出幡上**血祖**不甘的画面，问「你，可认识他」。
- 老者虽认不出此人是谁，却见其相貌与**姚家老祖有七分相似**，双目凸起骇然——王林由其表情已得答案。
- 王林元力锁住并虚空捏住其元神，运转**搜魂神通**读取后抹去神识，一揉化作元力球。

## 六、赠造化与驱虫

- 王林落至李元身边，将元力球按入其眉心：「**李兄，许某也送你一场造化，能否达到阴虚，就看你的机缘了**」。
- 复以「**收**」字诀逼出李元体内一只只白色狰狞小虫（相互蠕动、腥臭扑鼻），一捏之下尽数崩溃。

## 七、要点与伏笔

- 王林「许某」= 自创化名**许木**，非冒用他人姓名。
- **血祖与姚家老祖相貌七分相似**，为姚家与血祖渊源的关键线索，接续第721章血祖之父线索。
- 追杀李元的三人（姚姓青年、女修、阴虚老者）本章全部身死，姚家结仇正式坐实。
- 老者所供「姚家少主」为幕后主使，尚未出场。
- 章末为作者耳根推荐新书《烈空》的广告文字，与剧情无关，已剔除。
