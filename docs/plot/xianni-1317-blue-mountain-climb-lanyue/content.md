# 第九卷 云海之巅 第1317章 续……

## 一、蓝梦道尊现身，夺回李倩梅

- 蓝芒之中走出一名蓝衫中年男子，目不斜视，只望着王林怀中的李倩梅，神色透出**亲情与心痛**。
- 王林听声即震：这声音**当年在七彩界曾给他几乎灭顶之灾**，他永不会忘。此人即**蓝梦道尊**。
- 该男子相貌与李倩梅**极为相似**，一看便是至亲。
- 十多年前七彩界的间接一战，十多年后竟在**太古星辰**真正照面——世事莫测。
- 蓝梦道尊大袖一甩，风暴轰出，将王林撞退数步，同时以柔和大力把李倩梅摄入怀中，转身抱其没入星空，**自始至终未看王林一眼**。

## 二、王林的选择：不走，要看她醒来

- 王林判断蓝梦道尊与李倩梅必有亲情，自有办法令其苏醒。
- 按原计划此时该离开蓝丝族、离开这片星域；但他沉默后没有走——**「我送李倩梅来此，一定要看到最后」**。
- 深入蓝丝族修真星群，无需散开神识即可见一颗修真星散发笼罩星空的蓝芒，那便是蓝梦道尊所在。

## 三、蓝色修真星与蓝山禁制

- 该修真星内蓝光弥漫，如同一片海洋；海面有船只，风送欢乐曲乐；**没有任何防护阵法**。
- 山峦丛林之间矗立一座「蓝山」——山本身非蓝，而是山内无尽蓝芒环绕。
- 距山不足千丈处，蓝光入体即化作无穷阻力，阻止一切接近者。王林以自身禁制修为断定：**非人为布置，乃蓝山内蓝光所致**。
- 一条蜿蜒台阶自峰顶铺下，是唯一上行之路。

## 四、登山：三日九成台阶

| 进度 | 状态 |
|---|---|
| 入蓝光→山脚 | 阻力如铜墙铁壁，全身砰砰作响 |
| 近三成台阶 | 元力急速运转，硬抗上行 |
| 近五成台阶 | 神色疲惫、双眼血丝；阻力如数个修真星压身；粉衣女子笛音传来 |
| 三天/近八成 | 体内如敲鼓，身子颤抖；**上下双重阻力**，须分一半力气站稳 |
| 九成→登顶 | 喷出数口鲜血、血管几欲爆开，汗中带血；仍神色坚毅 |

- 支撑手段：**元力 + 古神之力**双重运转至巅峰，并大口吸纳天地之力入体。
- 心理映照：依稀回到当年尚未修道时，在**恒岳派山门经历入门测试**的那种「整个天地压下来」之感。

## 五、峰顶屋舍：唤醒与抹忆

- 屋舍内，李倩梅盘膝闭目、周身蓝光；蓝梦道尊在后掐诀，时而虚空一指。
- 每一指落下，李倩梅身子一颤，一股**黑气自七窍散出**。
- 最后一道黑气散出后，其枯萎容颜迅速恢复，睫毛轻颤，睁眼苏醒。
- 粉衣女子入内，欲言又止：「他快要上来了……是不是应该……」
- 蓝梦道尊抚摸身旁**古琴**，只吩咐：**「月儿，你去吧……告诉他，你的名字。」**
- 苏醒后的李倩梅**眼中迷茫**，显然记忆已被处理。

## 六、山顶相见：我叫蓝月，你是谁

- 王林踏上峰顶最后一阶，阻力骤然暴增化作无声咆哮，他却一动不动——只因看到了正望初阳的她。
- 她转头：**「父亲让我来告诉你我的名字……我，叫做蓝月，你，是谁？」**
- 王林怔住，苦涩轻声：**「我叫王林。」**
- 说罢松开抵抗，阻力轰然压下，身体被抛向远处，二人距离瞬息拉远，连目光都被空间阻隔。
- 王林心绪复杂：**「相忘于江湖，也好……也好……」** 转身离去。

## 七、蓝月的余痛与蓝梦道尊的独白

- 蓝月迷茫更浓，心中很痛、有窒息之感；恍惚间如身在水下，看天空一只飞鸟越飞越远。
- 她问父亲：为何见他时有一种**很熟悉、好似原本就在记忆中且很重要**的感觉。
- 蓝梦道尊未答，闭目抚琴：
  - 「世间最远的距离，不是天涯海角，更不是阴阳相隔，而是**忘记**。」
  - 认定这是「错误的时间、错误的地方、错误的情感，最开始就是错误的」。
  - 但也承诺：**若忘记之后二人还能有一段开始，为父绝不会再阻止——即便他被「远古仙域」选中，为父也敢于为你与仙域一战。**
  - 末句自语：「最远的距离是忘记……梦儿，你何时能想起我。」

## 八、要点与伏笔

1. **蓝梦道尊 = 李倩梅之父**，且是七彩界旧仇的源头，恩怨与亲情叠加。
2. 李倩梅身份改写为**蓝丝族·蓝月**，记忆被抹但情感残留（熟悉感、心痛）——为日后相认埋线。
3. **「远古仙域选中王林」** 被蓝梦道尊点破，是重要外部势力伏笔。
4. 蓝梦道尊自语「梦儿，你何时能想起我」，暗示他与另一位失忆者（疑为妻/亡妻「梦儿」）亦有同样的「忘记」之痛。
5. 蓝山蓝光为**天然禁制**而非人布，可视为蓝丝族/蓝梦道尊居地的天然守护。
