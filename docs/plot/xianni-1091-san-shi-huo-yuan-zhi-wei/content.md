# 仙逆 第1091章 三世火元之威

## 一、巡星受拥：圣皇之名传遍朱雀圣宗

- 王林因老圣皇（第1006章已死）的一幕想起当年的遁天，心情沉重。
- 所过朱雀圣宗诸修真星，修士尽出，“圣皇”之声惊天动地，透出该族隐忍无数年的激动与期望；随行族人不断增加，小辈目光尤为恭敬。
- **归附与重逢**：
  - 雷吉、大头化作长虹赶来，呼“主人”，王林微笑点头。
  - 司徒南（按世界状态须知，此为**司徒南的断臂**所化人影，自第336章起自称司徒南）大笑走来与王林相拥；其伤势已彻底痊愈，修为精进，毒素亦被压制。
  - 银衣女子无言跟随；浮风子恭敬，眼中喜色发自肺腑。

## 二、最后一颗主星：任涛发难

- 最后一主星即任涛所在星球。任涛闻欢呼神色阴沉、目露怨毒。
- **廖云**侧目不屑扫过任涛，飞身遥迎，狂热抱拳：“廖云恭迎圣皇”——当年同赴妖灵之地者最知王林神通，早被彻底折服。**凤姗**犹豫后同迎，主星绝大部分族人纷纷恭迎，任涛与其死忠形成鲜明对比。
- 任涛高呼挑战。其动机：若任王林继位，他再无成为圣皇的希望。
- **族规依据**：朱雀圣宗历代法则——两代圣皇交任之日，一切族人均有挑战圣皇的资格。任涛以此质问周长老，周长老冷笑“不知死活的东西”却不出手，退后旁观。
- 老圣皇留有死命令：长老团负责保王林顺利成为圣皇，不许出现反对声音。
- 数万族人中，凡当年去过妖灵之地者，看任涛的目光皆是讥讽，甚至怜悯。
- 任涛三年来听闻王林战绩却始终不信，且亲眼探得王林修为仅**窥涅圆满**，故更不信传闻。

## 三、王林的底牌与战力评估

- 本章王林为**分身**状态，与本尊分开，无本尊强悍肉身；但自评“本尊在不在，效果几乎没有差距”，唯一差别是有本尊肉身时**战斗持久力**会超出所有人意料。
- 一式**撒豆成兵**即可斩杀一切净涅修士，对碎涅亦敢一战。
- **残夜**需特殊时机方可施展。三年内，妖灵之地修真联盟残存者口口相传，“残夜一出，虚空子亡，天运子三大分身二死一重伤”的战绩已在联盟星域掀起风暴，令王林一跃成为顶尖修士（王林本人尚不知情）。

## 四、一战：火焚 → 启三世火元

1. 王林冷声：“与我挑战，没有活口，你可还愿意”——见过妖灵之地一战者尽起寒意（记忆点：撕碎天地黑暗的力量、梦回远古击碎长空的一拳）。任涛狰狞应战。
2. 王林言“无论如何，你都是朱雀圣宗族人，我可以让你火葬”，右手一挥，身后浮现**虚幻灵体**——族人哗然：**九玄变**，唯历代圣皇可学的神通。任涛面色苍白仍不甘。
3. 任涛掐诀，全身火焰狂涌成热浪，环身化作模糊铠甲。
4. 王林令灵体虚影融入右臂，虚空一点：**“火焚”**——凡是火便受其操控，任涛体外火焰倒卷反噬。
5. 任涛借铠甲冲出、如飞剑扑向王林，欲以一剑重伤或击杀求生。
6. 王林再指，**九玄变首次在其体内真正施展**，右手感到炙热，平淡吐出**“启三世火元”**：任涛骤顿喷血，体内轰响，倒卷而退，血雾迸溅、肉身四分五裂；元神惊慌逃出瞬间，被一股**融含火与雷**的毁灭性力量轰灭。
7. 旁观者所见：王林只向前两指，任涛即告灭绝。王林至始至终神色如常，评价：“许是与雷融合的原因，威力比之我预料，强大了不少”。

## 五、章末悬念

- 任涛身旁三老：一人**碎涅初期**，二人**净涅后期**。
- 王林右眼瞳孔中浮现一团**白色火焰**，盯向三老：“你三人，也要挑战么。”

## 关键点

- 九玄变确认为朱雀圣宗圣皇专属传承，“火焚”“三世火元”为其术式；三世火元威力因与雷之力融合而超出预期。
- 王林的圣皇继位在族内近乎全面获认，反对派仅剩任涛残党，且随任涛之死被彻底震慑。
- 王林当前公开修为窥涅圆满，实际战力远超境界表象；此为分身行事。
