# 第1828章 大魂门长老！

## 一、残桥石碑之局：王林的决断

- 「王林归来」四字在王林心神中如雷霆闪烁、隐有轰鸣，令其在残桥旁一震退后数步，双眼涌出寒芒。
- 王林判断：这是**推衍计算、拟化岁月**的神通道法，出自大魂门；对方（青牛真人也好、门中无数年前的强者也罢）早已算出他会来大魂门、会去吸收地火主脉、会在此等他。
- 目的判定：**大魂门想与他「有缘」，欲让他成为长老**。
- 关键决断：「此局想要破开很简单，可我为何要破呢」——**将计就计**，借大魂门更多了解仙罡大陆。随即脚下波纹回旋，挪移离去。

## 二、天山授法：魂衍道玉简

- 场景：天山青雪永恒飘落，泛青素气与天地相连。青牛真人**真身**盘膝雪中，白发在风中一丝不动，颇为奇异。
- 计时之物：以雪凝成的「雪香」缓缓融化，仅剩一小节。
- 雪香融尽的一刹那，青雪凝成漩涡，王林一步走出；踏上山顶积雪时雪香恰好消失。
- 青牛真身虚空一抓取出**紫色玉简**（气息沧桑，仿若存在极久的古老之物），言明「这就是那**魂衍道**的功法」，**根本不问王林的选择**便甩出。
- 王林接住、神识一扫，神色平静收起。
- 启程：青牛真身脚下浮现**三尺云轮**（气所化，形如急速转动的气团），速度骤增；王林并未融入天地，而是化作长虹随行。

## 三、大魂门概貌

- **三百六十主峰**组成大魂门道统宗门；山峦无尽，部分山峰雾气缭绕、阴气森森，更有巨大鬼脸弥漫、发出无声嘶吼形成波纹。
- 峰与峰间的山谷内遍布华丽阁楼、大殿、广场与洞府。
- **弟子十万**。神通众多：除本门传承外，无数年来在毁灭与争夺其他宗派的过程中夺得大量道法传承，如今成为门下弟子所学。
- **炎脉峰**（此前连接地火主脉者）现已由赤红转为暗紫，遍布裂缝破损，残破不堪。

## 四、炎栾拦路：一场精心计算的逼宫

炎脉峰主炎栾（少妇，绝美，大魂门长老之一）神色阴沉、发丝散乱、怒意欲爆。她在王林与青牛真身临近的一刹那便察觉，率众迎击。其举动层层含机心：

1. **扣住因果**：不给青牛真身开口机会，抢先定性「小贼毁我山峰」，令老祖若要阻止亦须给出解释。
2. **携众弟子同行**：带十余核心弟子（含**矾珊璐**与**矾珊梦**，皆女子，飞行时身影连成一条凤凰），若老祖袒护对方即等于放弃其一脉，且当着弟子的面，等于逼她无法再留大魂门——近乎撕破脸。
3. **凤凰虚影造势**：化出极庞大的凤凰虚影、威压扩散，意在引动其余主峰长老与交好者出峰围观，令自己站在道理上、众目睽睽下老祖难以取舍。

- 围观长老修为不等：**最高空劫初期，最低空灵**。
- 炎栾自身修为空劫初期，但爆发时气息不稳、隐有跌落——因先前与王林一战被重创，又见山峰狼狈而怒火攻心，尚未来得及疗伤。

## 五、王林立威

- 心理：此次归来与首次「潜入」不同，是**堂堂正正走入**。既要加入大魂门、成为长老，**便需立威**。
- 判断：老祖既已知其来自**洞府界**、且必知其**道古血脉**，故不再隐藏，尽管爆发，善后交由老祖考虑。
- 面对凤凰巨喙扑来，王林不退反大笑，笑声传遍八方；一步向前，右手握拳猛击虚空：
  - **「神震，兵修列位」**（无仙神通）——一拳轰空，天空轰鸣回音、大范围扭曲成巨大漩涡；天地在转、万物在转，唯王林不动。炎栾所化凤凰被牵扯扭曲、似要崩溃。
  - 此术当初曾用于迎战同为空劫初期的**战老鬼**；炎栾与王林非首次交手，却从未见过此术。
- **身份暴露危机**：四周长老神色骤变，惊呼「道古气息」「这是古国之修的气息」「此人不是我仙族之修」「他是古国之修」。
- **青牛真身出手遮掩**：眉头一皱、暗叹中右手抬起向天一挥，浩荡之力自天地幻化笼罩四周，**将王林的道古气息完全遮盖**，使外界无法感受。
- 王林续招：白发飘动、身影挺拔立于天空，拳向后收、**拳开威掌**向前一挥——**「妖术，烽火成山」**。

## 六、要点

- 王林与大魂门的关系由「潜入者/仇敌」转向「将被延揽的长老」，主动权在其自愿入局。
- 魂衍道功法（紫玉简）已到手。
- 道古血脉/古国之修的身份在大魂门公开层面险些坐实，被青牛真身压下——这条线索留有后患。
