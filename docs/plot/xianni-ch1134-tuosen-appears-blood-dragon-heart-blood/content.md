# 第八卷 联盟隐秘 第1134章 拓森现（第五更）

## 一、残夜破黑夜：初与末的规则之争

- 血龙视王林为蝼蚁，认定其在黑夜神通下未近身即亡。王林冲至血龙体外百丈时，虚无再度被黑暗笼罩。
- **王林的明悟（与修为无关，来自残夜神通）**：
  - 残夜神通拥有一丝**太初之力**，太初是天地一切光芒之法则，光芒之下一切黑暗消散。
  - 万物相对：有「初之规则」，必有「末之规则」；**血龙的黑夜，正是末之规则所化**。
- 在体内罕见地没有日初之力弥漫的情况下，王林**以自身修为强行推动残夜**——不求杀敌，只求在黑暗中活下去。
- 永恒般的黑暗中出现了第一次、也是唯一一次的光，如初阳。代价：**元力燃烧、元神燃烧、连岩石之躯也熊熊燃烧**。

## 二、夺取古神心血

- 王林借光破开黑暗，穿过百丈，冲入血龙目露震惊的身体伤口。
- 右手一挥，**前方大片血龙血晶尽数收入储物空间**。
- 心情双重：
  - **狂喜**——竟在此处获得古神心血。他深知古神体内心头之血全被拓森取走，从拓森手中取血几无可能。
  - **遗憾**——为取心血，不得不放弃观察拓森之威。
- 黑夜散去时，王林元神燃烧到尽头、行将崩溃，几乎「再次死亡」（强推残夜远超当前修为）。

## 三、黑衣老人出手

- 黑暗中骤现的那道光引起黑衣老人注意，他抬头看向王林，**目露奇异之芒**——脑中一直想不明白的事，此刻似被触动而想通。
- 一步迈出至血龙旁，右手随意一点：血龙剧震、咆哮着疯狂后退，体内轰鸣，将要崩溃。
- 虚空一抓将王林从血龙体内摄出，落于身前；右手拍其眉心，**浩渺之力灌入**：元力瞬补、消散的元神以逆天方式生生重聚、燃烧欲碎之身如岁月逆转重获生机。仅一刹那。
- 评语：「很不错的小伙子」「也很聪明」，并**一口道破王林是以分身前来、想见识暗古神**，允其心愿。王林瞳孔一缩旋即恢复，老人赞赏更浓。
- **实力锚点**：王林由老人一指想起当初在罗天星域，此老一拳轰塌罗天与联盟的空间壁垒。老人修为为**空涅**、已明悟规则。

## 四、拓森现身

- 老人右手一指天空漩涡，漩涡骤停、不再旋转、渐渐散开，露出内里**一片没有了血海但仍是血色的世界**；世界中有一座**锥形孤峰**，峰上立一人。
- **拓森形貌**：红发无风散动，双眼一片赤红，红中充满杀戮、蕴含顶天立地的狂傲；无人会去注意其相貌，目光尽被双眼吸走。
- **王林与拓森的宿命纠缠**（王林心中所想）：
  - 若无王林出现，拓森早已取回全部记忆、脱困而出，以**涂司的身体**纵横星空。
  - **拓森即涂司**——为涂司修炼**墨流分神术**失败、体内所生**魔念**；但无论是否魔念，**拓森才是真正的古神、真正的王族古神**。
  - 对照之下，王林的**古神本尊**虽靠古神决凝聚肉身、凭一系列机缘达到**五星**，但本尊**提前经历三损七劫**，并不完美。
  - 王林目光由复杂转为冰冷平淡；人与神隔着漩涡、隔着两个世界有了交集。

## 五、威压全场

- 拓森一步跨出锥形山峰，踏在漩涡之上，目光四扫。
- **炎雷子**：心神震动，罕见地听到自己的心跳，口干舌燥、面色苍白无血、下意识后退，不敢与之对视，只觉眼前之人**如同天道**。
- **尸阴宗八王**（宗内地位至高无上）：被拓森目光扫过，比炎雷子更不堪，面色苍白连连后退，如遭实质目光、魂飞魄散之感。
- 拓森评：「废物」；对八王：「废物最起码还是人，你们，连废物都不如」。
- 缘由：**拓森是神、八星古神；而他们只是凡人、只是修士**。
- 唯黑衣老者神色平静，缓缓道出其身份：「**王族古神之魂**」。拓森回以：「总算有一个不是废物的存在」。

## 六、老人与拓森交手

1. 老人右手随意向前一指 → 二人之间虚无骤然崩溃，掀起无尽虚无化作无形风暴直扑拓森。
2. 拓森抬手一拳 → 天地一颤，虚无剧震；赶来的碎涅修士遥见此拳皆面色大变、恐惧惊慌；王林面色苍白，清晰感受此拳之威。虚无**如白纸从中划开，被一分为二**，巨大裂缝不断延伸。
3. 老人一步跨至虚无另一半，不需掐诀、大袖一甩 → **冰川山峰幻化，方圆万里尽成冰封**，片片冰峰崩溃直扑拓森。
4. 拓森狂傲道：「区区神通，即便你修为达到了空涅，明悟了规则，那又如何」「**吾古神一族，不修规则，因为这规则，本就是吾族将要破开之物**」，再一拳落下 → 冲来的冰峰与万里冰层尽数崩溃。老人一晃而出，**面色凝重**。

## 七、转入涂司肉身所在的空间裂缝

- 万里冰层崩溃化风暴冲天，拓森身体漂升，双目不看老人而**落在王林身上**：「就让你等，亲眼目睹吾族之威」，随后红发之身渐渐消散于虚无。
- 虚无再震，裂缝道道，暴虐之力欲撕碎虚无；拓森消失处骤现**巨大漩涡**，传出磅礴吸力。
- 老人目光平静一步踏入，声音回荡：「你等跟来吧，接下来，才是这暗古神，真正的力量」。
- 王林毫不犹豫踏入，神色复杂——**隐隐知晓此漩涡通往涂司肉身之外的空间裂缝**。

## 八、章末伏笔：涂司睁眼

- 存放涂司肉身的那处空间裂缝内，**足有数个修真星大小**的磅礴古神身体：手指动了一下，慢慢握成拳；粗糙面孔上那闭合了永恒岁月、隔绝无数载的双眼，**第一次缓缓睁开**。

## 关键推进

- 王林首次因「黑暗中的一道光」而被黑衣老人**重点注目**，并被点破分身来历。
- 王林意外获得**古神心血（血龙血晶）**，绕开了「心血尽在拓森手中」的死结。
- 拓森正式现身并展示八星古神之力，压制空涅境黑衣老人的两轮攻势。
- 战场从血龙所在虚无转入**涂司肉身所在的空间裂缝**，涂司本体苏醒。
