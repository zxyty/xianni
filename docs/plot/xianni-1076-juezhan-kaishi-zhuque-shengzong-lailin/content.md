# 仙逆 第八卷 联盟隐秘 · 第1076章 决战开始

## 一、王林的伤势与状态

- **外观**：身披赤红色铠甲，甲上有白色朱雀图腾，一头白发随风而动，气质奇异；面色苍白。
- **朱雀真灵融入**：体内蕴藏浓浓火元力，但因元神虚弱，火元力未带来温暖，反而是冰天雪地般的寒冷渐渐笼罩全身。
- **「海曰生残夜」的代价**：此神通涉及「初之规则」，王林仅略微摸索便超负荷施展，后果严重。本次施展是**初之规则融入 + 朱雀真灵之火 + 二次觉醒 + 拼死反击**共同作用下的巅峰，属空前神通；日后即便能再施展，威力也无法与之相比。
- **血剑穿心**：灰衣天运子拼命一击所化的血剑，体外部分虽已不见，但在王林体内仿若穿心而过，更穿透元神，始终存在；连呼吸都会引发胸口钻心刺痛。
- **杀戮之根本**：血剑上的阴寒杀戮之气绝非寻常，而是「杀戮之根本」——其一身神通之始。
- **古神之体的极限**：若非古神之体、有惊人恢复力，换了他人必立刻暴毙；但即便以**五星古神**的恢复力，也始终无法平复体内伤势。
- **意志**：剧痛之下咬牙不倒，连哼都未哼一声，目光越过身前朱雀圣宗族人，落在天运子与古魔塔珈身上。

## 二、朱雀圣宗来援

- 之前低喝的朱雀圣宗老者向王林抱拳表态：
  - 他们是**第一批「指引方向来临者」**；
  - 之后朱雀圣宗**几乎倾族全出**，会陆续来临；
  - 保证王林**绝对的平安**。
- 王林只回以点头（这一动作就引发胸口阵痛，被他忍住）。心中判断：**不管朱雀圣宗出于何种目的，他们能来到这里，这个恩，王林记下了。**
- 但在朱雀圣宗众人环绕下，王林**没有任何安全的感觉**——不远处半空的古魔塔珈阴森扫来的目光，透出极为诡异的光芒。

## 三、阵营划分

- **王林一方**：朱雀圣宗众人环绕；花妃、司徒南（自称司徒南者，实为断臂所化人影）、王巍、胡娟等人迅速靠拢。
- **敌方**：古魔塔珈（及随其而动的「人形之物」）、天运子（本尊 + 六个分身）。
- 双方**泾渭分明**。

## 四、塔珈的杀意与动机

- 塔珈舔嘴唇、双眼红芒，盯住被众人环绕的王林——**这个人，他要杀**。
- 此前塔珈并不重视王林：即便是王族古神之体，在他看来也比不过计划中前往**古之遗迹**获得「古」的传承。
- 转变原因：
  1. 王林一路上的惊人变化；
  2. 方才那令其心神一震的神通；
  3. 隐约感觉王林的出现**也在青霖的计算之中**——若不杀此人，总有不安之感。这种感觉玄妙却清晰。
- 天运子的声音在天地间回荡，进一步坚定塔珈：王林**屡次破其计算**，更在**仙帝洞府**内成为了**异数**；杀了他，没了异数，则**青霖的种种计算就等于无根之木**。

## 五、决战开局

1. 塔珈带嗜血残笑、仰天咆哮，迈步而出；不远处那**人形之物**随古魔而动，迅速冲去。
2. 天运子双手掐诀，剩余的**六个分身**从四面八方直奔众人。
3. 天运子**本尊**右手虚空一晃，衣袍无风而动，**黑白两色光芒**在身上闪烁，直奔九霄。
4. 黑白二色在高空相互纠缠搅动，形成**仿若混沌般的奇异之相**。
5. 本尊左手掐诀、盘膝坐地、闭目念念有词（声音低弱难辨）。
6. 随其念动，混沌内传出**仿若从远古传来的沧桑呢喃之声**——听不清晰，却令每个人心底生出**遇到天敌般的惊慌**。
7. 威压随声从天而降：四周大地轰隆巨响，震动达到巅峰，**无数裂缝骤然出现**，并在**百里外**不断蔓延、彼此连接。

## 六、要点与悬念

- 王林处于「战力巅峰刚过、重伤未复」的最危险窗口：无法复现海曰生残夜，体内血剑持续伤害元神。
- 朱雀圣宗的援助目的未明（王林自己也存疑），但已被王林视为「恩」。
- 天运子高空黑白混沌 + 远古沧桑之声，是本章尚未揭晓的大杀招起手式。
- 「青霖」的计算与「异数」王林之间的对立，被明确点为塔珈与天运子必杀王林的核心理由。

# 第993章（承第992章）百里大地升空·火焰巨人战塔珈·无头之人袭王林

## 一、战场剧变：百里大地整块升空

- 几乎瞬息之间，地面方圆百里的边缘齐齐碎裂。
- 百里大地在轰隆声中升空，如同一根「粗百里」的巨柱冲入天空，直接落入天空那一片**黑白混沌**之内。
- 地面仍在轻微颤抖；四周百里外弥漫黑白交错的迷雾，**目光与神识均无法穿透**。
- 王林面色阴沉。

## 二、正面战线：朱雀圣宗 vs 古魔塔珈

### 1. 六大碎涅老者受挫
- 古魔塔珈踏步而来，速度极快，转眼临近。
- 朱雀圣宗六个**碎涅期**老者神色凝重，冲出掐诀，火海弥漫横扫而去。
- 塔珈冷笑，右手**厚背刀**一挥，刀芒乍现——火海一滞后轰然倒卷，并从中间被一分为二。

### 2. 近百族人元神融合成火焰巨人（本章最重要的设定展示）
- 除六老外的**近百朱雀圣宗族人**不待指挥，齐齐盘膝掐诀，天灵之上火光闪烁，元神同时飞出。
- 元神出现刹那，浓浓高温弥漫。
- **反常之处**：元神乃修士一生所修精华，各人道念不同，本不可能融合；一旦融合即意味着吞噬，若非有逆天法器存在绝无共存之理。大头等人因此觉得不可思议。
- 但近百元神飞快融合，转眼化作一个**数十丈大小的火焰巨人**，咆哮着直奔古魔塔珈。
- 王林见此瞳孔一缩，对朱雀圣宗生出一丝好奇（暗示朱雀圣宗另有秘法/秘宝）。

## 三、侧翼战线：合战天运子六大分身

- 天运子的分身临近，**王巍**与**胡娟**咬牙冲出，**花妃**轻叹起身迎上周旋。
- 参战阵容：王巍、胡娟、花妃为主，**浮风子**、强行压下毒发的**司徒南**（按世界状态：即自称司徒南的「司徒南的断臂」所化人影）、**大头童子**等人助战。
- 花妃压力最大：既战天运子分身，又要应对那**人形之物**的攻击。
- 百里大地上轰鸣不断，各种神通光芒剧烈闪烁，战况激烈。

## 四、王林一线：重伤中遭无头之人突袭

### 1. 王林状态
- 盘膝坐地，**体内伤势太重**，胸口阵痛不断袭来，面色更加苍白。
- 战事连绵，无法疗伤，只能**吞下大把丹药强行压制**。

### 2. 天运子放出无头之人
- 远处盘膝的天运子猛地睁眼盯住王林，抬起右手一指天空。
- 百里外黑白混沌轰然怒吼咆哮，其内走出一个**无头之人**：
  - 身躯强壮，右手持**红色长枪**；
  - 充满凶煞之气；
  - 出现瞬间体内冒出浓浓黑雾环绕全身，化作一套**黑色铠甲**。

### 3. 青光盾硬撼
- 无头之人无声无息冲出直奔王林，刹那临近，黑风扑面，长枪瞬息刺出。
- 王林虽是强弩之末，仍不易杀：双眼阴冷，**右眼青光闪烁**，幻化出**青光盾**挡在身前。
- 轰的一声，红色枪尖撞上青光盾——青光盾本就有裂缝，此次未再碎裂，但被向后压下数寸。
- 无头之人蹬蹬蹬退后三步，铠甲黑光闪烁，再度冲来。

### 4. 十八地狱封仙印·撒豆成兵
- 趁其退后的机会，王林张口吐出**十八地狱封仙印**。
- 王林右手虚空一抓，手心出现一片晶光，向前狠狠挥出，晶光如繁星点点弥漫身前。
- 大喝：**「撒豆成兵」**。
- 效果：晶光散发刺目之芒；十八地狱封仙印内凄厉声骤起，一个个**被困住、入不了轮回之魂**挣扎冲出，融入一个个晶光之中，仿若有了实质，阴气缭绕。
- 更可怕的是：封仙印**第十八层**中，**虚空子的魂魄**一步走出，双眼带着疯狂红芒，发出野兽般的咆哮，冲出后直奔无头之人而去。（虚空子已于第987章死亡，此处为其魂魄被收入封仙印后驱使）

## 五、要点与待续

- 朱雀圣宗掌握「近百族人元神可融合而不相互吞噬」的手段，本章未解释原理，王林已起好奇——后文可查。
- 天运子（分身/本体）可自黑白混沌中召出无头之人，说明黑白混沌内另有存在。
- 王林重伤未愈，主要战力依赖法宝（青光盾、十八地狱封仙印）与所收魂魄，而非自身修为。
- 十八地狱封仙印的「撒豆成兵」用法：以晶光为躯壳、以印内不得轮回之魂为兵。
