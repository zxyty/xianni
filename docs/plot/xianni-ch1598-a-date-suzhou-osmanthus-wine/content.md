# 第1598章 一次约会

## 一、念天之死与最后的发现（炼魂宗线）

- 弥留之际，念天不断回想数百年前那个**不知名字的儒生**的一句话，那句话在他心中回绕如永恒。
- 直至双目闭合、寿元断绝、**投身进入炼魂幡内成为其内主魂**的一瞬，他的神识做了生命中最后一次扩散，向炼魂宗弥漫开来。
- 就在这一刻，他看到一个**从远处逃遁而来、混入欲拜入炼魂宗山门人群中的平凡之人**——神识泛起无法想象的波纹：震惊、骇然地发现，那人**正是数百年前他曾问过话的那个儒生**。
- 带着迷茫与想不出的猜测，念天神识消散，其**元婴成为十万大幡（炼魂幡）的魂**。

> 叙事作用：把「凡人梦境中的儒生（王林）」与「数百年前炼魂宗旧事」在因果上扣合，暗示梦境与真实的交叠。

## 二、王林梦醒回县城：因果初悟

- 王林被送回**赵国县城考场外的大树旁**，面前大福仍在沉睡，之前的一切似只是一场梦。
- 他望天，**再次看到那只白色飞鸟**，飞鸟回旋后慢慢消失在云层内。
- 王林自语：「**因果我有些明白了**。」
- 推醒大福后二人返回客栈，明月当空，身影拉得很长。

## 三、科考放榜：得秀才功名

- 数日后大榜放下，上榜即得**秀才功名**。
- 功名的意义链条：秀才 → 有资格赴**苏城**科举 → 中举 → 赴**赵国京都**作最后一搏。
- 更高的机遇：获苏城当代大儒**苏道**赏识可名扬天下，若能拜入其门成为门生，荣耀无法形容——这是赵国学子几乎梦寐以求的渴望。
- 结果：全县**不足五十人**得秀才功名，王林名列其中（非前茅）。
- 王林见榜心境**平静**，无兴奋之感；到县衙以路引名刺认证身份，取得凭证与**朝廷犒赏银两**后远远离去。大福兴奋的其实是那笔银两。

## 四、心境之变：得之依然，失之依然

- 一个多月的经历（以及**每夜始终存在、已渐渐适应的梦境**）在无形中改变了王林：不再有得失之念，不再彷徨于落榜之忧。
- 「一切都算不了什么，只有本心如旧，则心若静水，古井不波」——如「看山是山／看山不是山／看山还是山」的三重意境。
- 一代**大儒的气息**在他身上峥嵘起来，挺直的脊梁与平静目光在书生中如明珠独立。
- 点题句：「**为仙，则冷看众修；为凡，同是人杰**」；「**人生如梦，这场梦，我不愿醒来**」。

## 五、离城饮酒：由书卷气转洒脱

- 出城前王林忽然很想喝酒（他曾两杯即醉），命大福去买；大福心痛银子，讨价还价甚至耍无赖，以极低价买得两壶。
- 王林大口饮酒、任酒水顺嘴角流下，长笑出城，背影中孤独寂寞消散，代之以**洒脱与不羁**。
- 王林道明去向：「**苏城，听说那里的桂花酒不错，我要去那里，等一个人来。**」随即散开束发，笑声回荡。

## 六、苏城：地理与风物

- 位置：**赵国京都南侧五百里外**；城大如雄城，内里却似江南水月，婉约水乡。
- 水系：几条**银龙小溪**蜿蜒穿城，其上常年有**画舫**，日夜歌舞升平，才子吟诗、佳人起舞、曲乐琴弦弥漫，全城笼罩绯色。
- 得名：源于大儒**苏道**；城中聚集了几乎赵国所有才子。
- 特产：**桂花酒**极负盛名，京都达官贵人常派人来买；苏道早年即喜爱此酒，饮酒感悟天地浩荡，其名赫赫后桂花酒更为人知。

## 七、两月路途与抵城

- 王林与大福乘简陋马车，行两个月抵苏城；一路王林饮酒不断，路费银子大半化作酒水，大福带哭腔絮叨心痛。
- 王林笑称：书童管家没钱就去赚一些回来。大福的絮叨反让王林生出「似曾相识、很是亲切」之感。
- 王林**酒量不知不觉大进**，不再是当初两杯即醉之人。
- 下车时王林一身白衣、长发披散、手持酒壶，满脸书卷之气已消散，代之以洒脱；相貌寻常而气质特殊，走在街上引来诸多目光（含不少女子）。

## 八、等一个人：本章题眼

- 黄昏月色中，王林立于桥头看河中画舫，琴音绕耳。
- 大福问等谁，王林答：「**等一个我梦中的人，他会来，送我壶酒。若他真的出现，则印证了我的一个猜测。**」
- 王林点破大福私藏银两，命其取出去买**桂花酒**、**租一艘小画舫**，二人此后住在船上。
- 风起吹动其发，风柔而暖，携琴音而来。王林喃喃：「**你，会来么**」——全章收束于这场「约会」的等待。
