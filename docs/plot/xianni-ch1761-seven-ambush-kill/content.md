# 第1761章 七伏杀

## 一、目鱼设定（仙罡大陆凶兽）

- **形貌**：千丈之身，头若凹口，体若泥蛇。
- **习性**：喜香泥土，取大地之精华滋养其身，吸天地之灵气润养其神。幼体栖息江河淤泥，久不现身；成年后钻透江河淤泥，自地底前行去往四周仙山，入山而眠。
- **危害**：目鱼入山则与山相融，会使仙山有灵，但时间不长该山即化为一片黄沙（抢夺仙气）。
- **处置**：因此不受修士喜爱，仙罡大陆上的目鱼多被封印为宗派护山之兽；凡被发现者均立刻封印。

## 二、王林如何认出目鱼

- 知识来源：**第三魂**内**七彩仙尊**的记忆——七彩仙尊当年曾把一条幼年目鱼带入**三百残界**，本欲饲养一段时间再取出，却身死魂散，成为遗憾。
- 触发：王林此前逃遁中察觉此地凶兽气息，又见这修真星的黄沙大漠，遂折返回此地。
- 验证：抓黄沙见其内隐透灵气；神识散开发现凶兽气息存在于修真星**内部**。
- 推断：一条未受任何限制的目鱼在残界内生存久远必生异变；此界星域**只剩这一颗修真星**，其余之星显然已被目鱼吞噬吸收。

## 三、七伏布局（顺序与手段）

| 序 | 手段 | 布置方式与代价 |
|---|---|---|
| 第一伏 | **焚界古伞** | 掐诀由无数禁制虚影重叠化出；伞开后热浪滔天、伞骨如天地连接之柱；咬破舌尖喷血燃入天幕，使伞与虚无融合、彻底隐形。凡踏入此星天地者尽被笼罩。 |
| （增幅） | **火焰朱雀** | 一指左目，瞳孔内火焰本源燃起，挥手宣泄成火海，化巨大火焰朱雀（尾羽四散如凤凰），游走天空数圈后融入天地，用以再增古伞威力。 |
| 第二伏 | **七彩道枪** | 双手掐诀低语，七彩之芒（与七彩道入神通一模一样）几乎笼罩全星，升空凝成七彩长枪，嗡鸣后刺入王林盘膝处右侧大地。 |
| 第三伏 | **道古传承·开天斧全力一击** | 掐诀点眉心，本尊与修士分身分离；**道古传承的本尊**升空虚空一抓，天地色变中取出巨大开天斧，握住后隐没一旁。 |
| 第四伏 | **鬼脸帆布幻术** | 该物来自仙罡大陆，当为重宝，王林研究未尽，但可借之施幻术。咬破左手食指点入鬼脸口中，三息被吸走近一半鲜血（面色苍白），第四息鬼脸双眼红芒、膨胀笼罩整星后消失，天地遂生难辨之异。 |
| 第五伏 | **幽冥兽** | 一指天空，幽光小点扩大成幽冥兽（仅撑至百丈大小，双眼冷酷无情）；一指落下，其闭目化雾飘散，笼罩天地，使全星如雾中模糊。 |
| 第六伏 | **目鱼** | 撕开已结痂的指尖，以鲜血绕身画圆圈，喷出元神精气融入；血腥与天地元气一散，全星震颤、地心传出震动，地面黄沙如海浪起伏。随即掐诀使双目瞳孔弥漫血丝，以血丝融入圆圈**深深掩盖气息**。良久大地起伏消散。 |
| 第七伏 | **李广弓** | 双目浮现微弱金光——身上**仅剩的精纯仙人血脉之力**——右手虚空一抓取出李广弓，死死握在手中，闭目推衍此局变化。 |

> 王林自评：连续施展这些大神通是他此生从未有过之举；若在厮杀斗法中根本没有时间完全发挥，但眼下可以。空灵后期修为施展焚界古伞已属艰难，欲发挥更大威力则消耗更多。

## 四、诱饵与目的

1. **燃香**：左手一挥取出未点燃的黑色香支，空中一甩点燃，黑气如狼烟急升；前抛插入三丈外黄沙，火光忽明忽暗、黑气更浓。
2. **紫霞与传音玉简**：取出双目紧闭的**紫霞**，左手一指点其眉心；紫霞全身一震、面露痛苦挣扎却无法自控，右手不受控地取出传音玉简，传出一道神念后玉简碎裂。

**战略意图**：王林不奢望杀死**七彩道人**或**战老鬼**，所求是**重伤一方**——因为二人中任一方重伤，就等于给了另一方莫大机会，可从侧面达到将其毁灭的程度。
