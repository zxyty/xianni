# 第858章 目标，一百零八仙

## 一、清水赠冰晶而去

- 清水对王林立约：**若能成，便传唤雨与撒豆成兵两大仙术；若未成，则与此二仙术无缘**。他自言救王林一次，也算了却王林因「呼风」与其师尊结下的一丝机缘。
- 清水虚空一抓，凝出一滴晶莹剔透的**雨滴冰晶**，内蕴**三次唤雨仙术**，赠予王林留作防身。
- 转身走入虚空、渐渐远去，消失之际眼中惆怅更浓，喃喃：「此人，比师尊强……只是，在他的身上，我却总是有一种很熟悉的感觉，我一定见过他。」
- 王林望其背影沉默许久，略一鞠躬后抓住冰晶而去。

### 王林的判断
- 清水**一定是第三步的修士**，罗天星域内竟有这等存在。
- 疑问：联盟星域内是否也有第三步修士？此人太强，碎涅修士在其面前也无任何反抗之力。
- 但王林已**从天逆珠内看到了第三步的方向**，「终有一日」。
- 随即缩地成寸，融入天地，赶往李元家族所在。

## 二、破灭星与李家背景

- **位置**：罗天南域内一处偏僻星域，修真星名为**破灭**。
- **过往**：李家为传承自上古的**禁制家族**，掌握**破灭禁**，实力极强，曾一度名震罗天。
- **没落**：无数年后，破灭禁外流，李家从顶峰一落千丈；族人凋零，辉煌只存于记忆且被尘埃覆盖。
- **现状**：破灭星荒无人烟，无修士来此；若非李家无数年来留下的**禁制大阵**，连此星也难以保留。

## 三、李元的心境

- 李元在李家祖宅中一脸没落，回想雷之仙界一行，对**许木**（即王林化名）极为感激——尤其最后许木送他脱身、自己却留了下来。
- 苦涩自语：「许兄，姚家对你的追杀，非我李元不帮，而是我无能为力。」以其修为面对姚家，不但无用反成拖累。
- 曾发愿：「许兄，若你能来，我将毫不保留，把破灭心禁传你。」
- 话音未落，天空泛起波纹涟漪，王林一步走出，二人重逢。

## 四、破灭心禁传承（九天）

**规则**：破灭禁唯有拥有**心禁**才可完全发挥威力；心禁传承**只能在李家祠堂进行**，否则无法传承；家族惯例是先辈临归西前才传给指定族人。

**过程**：
1. 祠堂内一座**黑色水池**，池水刺骨之寒；二人于池中盘膝对坐，已吐纳三天（王林到破灭星与李元叙旧后应邀而来）。
2. 李元眉心黑光散出，化作条条黑线融入池水，黑线入水如蛟龙入海，掀起漩涡。
3. 黑色池水顺王林身体上蔓，最终在其眉心凝固。
4. **第五天**：李元疲惫苍老，仿佛五天如五十年；眉心黑光暗淡微弱，大半已化黑线入水。他走出池水打坐，喃喃「许兄，你之恩，李某报答了」——为报恩付出太多，心禁送出大半，**禁制修为跌落不少**。
5. **第六天**：漩涡成风暴，池水上涨弥漫王林全身，寒气四散，四周霜寒结冰。黑线不断融入王林眉心，组成复杂花纹层层烙印。王林进入奇异状态，破灭禁的一切与其此前所学禁制**一一印证、对比、融合**，对禁制阵法玄妙越加深刻明悟。
6. **第九天**：王林睁眼，黑水漩涡轰然崩溃四散，寒气爆发；其双目奇异之光透出无数禁制闪烁，**仿若可看穿天地一切禁制**。

**炼制心禁罗盘**：
- 王林一指将散出的黑水尽数凝聚于掌心，融合成一枚黑光闪耀、透出诡异寒芒的**黑色小球**（映得祠堂阴森）。
- 拍储物袋放出大片**泥土**（此前在雷之仙界经李元指点所收取），尽数融入小球。
- 张口喷出**元神精气**冲击小球，黑光大浓，小球收缩变形，最终成为一个**八角罗盘**。
- 李元道贺：「每一代破灭心禁传人，都要拥有自己的心禁罗盘。」
- 罗盘融入王林手心、散及眉心，一闪消失。

## 五、临别互赠与决断

- 王林抱拳道谢；李元称「你对我李家有恩，这本是我该做之事」。
- 王林多日前叙旧时已从李元处听闻诸多外界之事，**包括自己「魔道子」的称呼**。
- **李元的打算**：以其修为参与争夺无用，准备**闭关潜修，争取突破达到阴虚**；为家族重新辉煌下了大决心。
- **王林回赠**：取出一枚玉简，刻入当年的**雷元诀**（雷仙殿功法），称「谨慎修炼之下，突破之机可增大不少」。李元动容——李家虽传承上古，但典籍多已流失，剩下的唯有破灭心禁，实则连普通修真家族都不如；雷元术虽非至珍却绝对少见。
- 李元允诺：不提谢字，若有一日突破，定会寻王林，「我二人如雷仙界般啸傲星空」。
- 王林告辞，脚下波纹散开，融入其内消失。

## 六、目标：一百零八仙

- **赛制**：雷仙殿的**一百零八仙**争夺战展开，以**四大星域为赛场**。
- **彩头**：**三十六天罡仙**可获得雷仙殿以及两个传承上古的修真家族的**各一件承诺**。
- **王林的动机**：不仅为清水所许的两大仙术，最重要的是**来自东临星向家的承诺**。
- 王林邀李元同争，李元婉拒（修为不足，选择闭关）。
