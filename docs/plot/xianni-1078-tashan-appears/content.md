# 第八卷 联盟隐秘 第1078章 塔山现身

## 一、青龙圣宗：朱雀圣皇借太古圣器（双线之一）

**地点设定**：修真联盟星域中有一片被划为禁地的奇异星域——星空中拔地而起苍天巨木、青草弥漫连绵不绝，仿若万古之林；浓浓木属性元力弥漫成青色薄雾久久不散。修士临近此地会全身元力停滞，甚者元力无形消失。连修真联盟也颇为忌惮，划为禁地；唯有少数存在悠久的老怪记忆深处还留有对这片青雾之地的模糊回忆。此地即**四圣宗之一·青龙圣宗**所在。

**事件**：
- 一名神色透出追忆与惆怅的中年男子出现于星域远处，望着青龙圣宗叹气——此人正是**朱雀圣皇的元神**。
- 他抬右手一指，幻化出虚幻朱雀之影，带嘶鸣冲入青雾、缭绕天地作为召唤。
- 青雾内闪出九名老者：当前三人白发苍苍、身负岁月痕迹，其后另有六名老者。九人抱拳恭敬：「见过朱雀圣皇。」
- 朱雀圣皇开门见山：「**朱雀宗觉醒者出现**，需借你青龙圣宗**太古圣器**一用，还需你等随之前往。」
- 为求此行万无一失，他这一路已先去**玄武圣宗**与**白虎圣宗**，青龙圣宗是最后一站。
- 九老对视后未多犹豫，当前三名沧桑老者之一点头：「朱雀圣皇吩咐，我等从命。」

> 要点：四圣宗（朱雀/青龙/玄武/白虎）体系被明确串联；朱雀圣皇正在集齐三宗太古圣器与人手，目标指向「朱雀宗觉醒者」。

## 二、妖灵之地：天运子碾压王林（双线之二）

### 战场态势
- 王林借**朱雀圣宗六老之一的自爆**（第997章事件）脱离天运子身边，急退中双目通红，体内伤势剧痛穿心。
- **朱雀圣宗剩余五老**修为多为碎涅初中期、并非碎涅圆满，本就难敌**古魔塔珈**；他们身外火焰弥漫，各持朱雀圣宗无数年储存的**空级之宝**（比不过次空涅）；再加上以奇异方式化作的**火焰巨人**、以及越过人形之物参战的**花妃**，勉强对抗，但随古魔神通幻化已处绝对下风，无暇回援王林。

### 天运子 vs 王林（三连击）
天运子已**撕开眉心第一道封印**，全身气息强大到难以想象。他神色平静迈步逼近，人未到而风雷先至，吹在王林身上如刀割，王林体内砰砰作响、连连后退。

> 「死在老夫**天人第一衰**下，你当可含笑九泉。」

1. **数十大剑 → 剑片巨龙**：王林拍储物袋放出数十把大剑直取天运子。天运子只双唇微动似念咒语，大剑悬停崩溃，碎片倒卷并彼此凝聚化作一条通体锋利剑片的巨龙反扑王林。
2. **第三辆射神车 → 蝴蝶**：王林及时取出**第三辆射神车**，砰然化作蝴蝶，翅膀扇动间规则幻化，将剑片之龙震得咔咔作响、轰然崩溃成粉末四散。此处点明：这是王林**第一次与人斗法**，连对方神通都不知所以，若非射神车拿得及时必然措手不及、险些身亡。
3. **开第三封印 → 四片花瓣被卷走**：蝴蝶送出蕴含规则的无形之风，天运子神色不变、双唇微动，蝴蝶前方轰然响起惊天之音、波纹散开，蝴蝶震颤欲溃。王林掐诀喷血落于蝴蝶之上，大喝「**开第三封印**」，蝴蝶上空浮现**四片残缺的花瓣**旋转前飘。天运子轻咦一声挥手，前方虚空大片碎裂，天空被生生掀起倒卷而去，蝴蝶与四片花瓣威力未及展开便被卷走，不知去向。
4. **剑鞘挡指**：天运子临近，食指点向王林眉心——此指若落，王林的**古神肉身**也会立刻崩溃，萎靡元神刹那湮灭，「从此之后，再无王林此人」。绝望如巨峰压顶，王林瞬息压下，怒吼「**我不甘心**」，自储物袋取出一把**剑鞘**竖于身前。轰然相撞，剑鞘碎裂但未崩溃，王林被震飞、大口喷血、眼前模糊、元神几乎四分五裂、肉身如散架，仅凭逆天意志支撑。
5. **反震生疑**：剑鞘传来的反震让天运子暗自心惊，双眼露出杀机，一步瞬移般到王林身前，右手抬起欲狠狠拍下。

### 转折：塔山现身
- 妖灵之地**地底深处**骤然爆发疯狂杀意，大地轰颤，一道**符文闪烁的身影**冲出，速度数倍于天运子。
- 阴沉低喝回荡天地：「**伤我主者，便是我塔山死敌**」。
- 塔山右手一挥取出**一张兽皮**并立刻点燃，化作灰烟环绕全身，速度骤然再快数倍，一闪至王林身前挡下天运子一掌。
- 结果：塔山抱王林急速后退，喷血、全身符文大范围崩溃，神色狰狞；环绕身外的灰气迅速钻入其体内疗伤，**一部分融入王林体内**。

### 同场其他伤亡（天运子分身战线）
- **大头童子**：肉身被天运子分身一击轰然崩溃，元神重创，眼看将被分身击溃。
- **雷吉**：本已重伤，因距离最近怒吼冲出，以肉身挡在大头元神之后硬接分身一击 → 肉身崩溃、元神几乎消散。
- **浮风子**：大袖一甩卷起雷吉残魂救下，代价是被天运子**另一个分身**一剑从胸口穿透，喷血惨笑后退，与同样重伤的**尘道子**靠拢。

## 三、结构与看点
- **双线并行**：宇宙尺度上的「四圣宗集器」布局，与妖灵之地一线的濒死死斗交叉推进，暗示朱雀圣皇的动作与妖灵之地战局互为伏笔。
- **实力刻画**：天运子撕一道封印即可念咒破法、掀翻天空、瞬移欺身，且多具分身同时碾压碎涅级战力；王林三件底牌（大剑群、第三辆射神车、剑鞘）依次被破。
- **新登场**：塔山（符文之身，自称王林为「主」，从妖灵之地地底而出，燃兽皮提速）——本章标题人物。
