# 第七卷 名震罗天 第732章 大圆满与许立国的恶趣

## 一、昆极鞭融于意境

- 昆极鞭所化的“圆”略微一松，化作一道光芒消失于天地之间。
- 此物**已融入意境**，没有了形体，与意境一样融于虚无：**看不见，感受得到**。

## 二、许立国被震慑，转为谄媚

- 许立国险些崩溃，退后数步，眼中惊恐浓郁，先前的霸道全部消散。
- 改口阿谀：自称“小许子”，称“主子的神通又厉害了”，辩称先前挑衅只是为让王林多练几次神通，表忠心“苍天可鉴，绝无半点反意”。
- 王林平淡吩咐：既已出来，**暂时不用回储物袋**，可在**山峰万里内自行领悟远古剑意**。
- 许立国意外于“煞星老魔”这次好说话，眼珠一转反说舍不得主子、在身边才踏实；王林顺势允其留下。
- 许立国表面得意（自认识破“这里面一定有假”），内心苦涩忐忑，凝化身形盘膝坐下，不时打量王林想看端倪。

## 三、群兽出袋

| 出场 | 表现 |
| --- | --- |
| 蚊兽 | 极舒服地趴在雷蛙身上，嘶鸣一声应过王林后又趴下，说什么也不愿离开 |
| 蚊兽幼体（当初跟随的一批） | 尚未长大，但看起来已极为狰狞 |
| 雷蛙 | 已习惯背上蚊兽，现身后腹内雷鸣阵阵，寻位置趴着如睡 |
| 雷兽（射神车所化） | 射神车飞出，砰的一下在半空化作雷兽，一眼看到雷蛙即低声咆哮 |

- 雷蛙瞬间一扫懒散，睁目直盯雷兽，腹部雷鸣滚滚；背上蚊兽精神一振，颇有兴趣地看向雷兽。
- 许立国旁观暗道王林“真有畜生缘”，自愧不如，但自称有“美人缘”，恍惚间想起**妖灵之地的小美人**，感慨“自古多情空余恨”，认为煞星王老魔不能明白。

## 四、王林推演调整三式神通

### 神通盘点（本章当时）

- **最强可施展之术：斩罗诀**——因修为未突破修道第一步、未达**阴虚境界**，每次施展都消耗其不多的元力。
- **定身术**——强大不弱于斩罗诀，特殊时刻常起决定作用。
- 其余：**寂灭、化魔、黄泉三指**。
- **生死轮回意境所化三式道念**：道化黄泉、凝化泉魂、黄泉之力。

### 调整动因与方法

- 待调整者为**寂灭、化魔、黄泉三指**：三式神通**不完整**，继续修炼对**修道第三步危害极大**，且会引起身体不适；具体缘由王林亦不清晰，全凭感觉。
- 方法：右手食指弹出，将三式一一施展、不断循环，凭内心模糊感觉寻找端倪并渐渐改善。
- 此过程极耗精力，不久便生疲惫，略作休息后继续。
- **意义**：这种改善几乎等同于**从一个神通推演出其本源仙术**——别说是他，即便**天运子**等人也很难做到；若被第二步**净涅／碎涅期**修士看到定会大吃一惊。

### 两年之后

- 两年春秋过去，王林绝大部分心神都放在推敲神通上，不断改善，**最终仍未达到满意**。
- 王林明白是自己心急了，但没有放弃，尽最大能力慢慢改善。
- 法宝的祭炼仍在持续，但此时已非重点（时间有限）。

## 五、两年间的旁支

- 雷蛙与雷兽彼此敌视但未厮斗：雷蛙修为不够不敢攻击，雷兽则是不屑，尽管感到对方带来的一丝潜在威胁。
- 蚊兽兴趣从雷蛙转移到雷兽，时而环绕飞舞想趴其背，屡次不成功，兴趣反而越大。
- 许立国看不上眼，见王林似已忘记自己，小心退后，终于离开王林百丈外，化作黑雾在山峰万里内欢快呼啸。

## 六、看点

1. 许立国“恶趣”定型：对王林的极端畏惧与自作聪明式的自我安慰并存，为后续插科打诨基调。
2. 王林修行方向从“祭炼法宝”转向“神通重构”，并以“第三步”为标尺反向筛除不完整神通。
3. 灵兽阵容成型：蚊兽（含幼体）＋雷蛙＋射神车所化雷兽，三方微妙的敌视/依附关系。

# 第693章 怨气玉简与生死轮回意境大圆满

## 一、许立国的百无聊赖与戏弄
- 许立国谨记王林之命，不敢走出横云峰万里之外；万里内荒无人烟，外界修士远远绕行，令其极为郁闷。
- 一年半前，他曾以幻术把几名不敢进来的修士骗入雾中，戏弄一番后放出。那几人多年后回想仍心中发寒，自此再无修士敢来。
- 他日日在万里内飘荡，期待有凡人误入。

## 二、张新海父子求见
- 黑雾边缘，张新海一脸憔悴透着死气；随行者为其子，黑袍中年男子，修为同为**元婴大圆满**。
- 张新海的两个目的：
  1. 完成王林交托之事（收集怨气）；
  2. 把儿子引荐给王林——自己寿元将失，日后归墟，由儿子代其为王林行事，以保张家香火永存。
- 其子忌惮：听道友说这位前辈“有些怪癖”，一年多前就有几位道友被……话未说完即被父亲瞪视噤声。
- 许立国隐于黑雾中窥探，兴奋自语：老的快死了经不起折腾，就放过；小的“嘿嘿”——目光透出银邪。随后以正气凌然的口吻喝问“来者何人，报上名来”。
- 许立国先送张新海入雾（狂风裹送至山峰），再折返诱骗其子入雾。

## 三、献怨气与王林的三项交代
- 张新海奉上**上千枚玉简**，称已收齐青灵星所有凡人的怨气。王林神识扫过，感知其怨气惊人、庞大如怨气风暴。
- 王林三项处置：
  1. **立使者**：张新海带来之人（其子）日后为“老夫在横云峰外的使者”。
  2. **赐丹**：取一粒丹药予张新海，令其子服下，若天资足够，或可凭丹药灵气有**一丝化神的可能**。张新海狂喜称谢。
  3. **续采与种植**：怨气虚无缥缈且会再生，张家日后每隔数年须再收取一次；另交付数粒红色**升仙果**种子，令族人以修士灵力催发，接下来**十年内尽可能多种**。（此种子出自当初**千葵子**的储物袋。）

## 四、许立国夺舍戏弄的后果
- 张家父子离去时，其子一脸恍惚、透出奇异，似还有些回味。
- 王林严厉**禁足许立国于百丈之内**；若非其所为尚不算太过不堪，王林甚至想将其炼化。
- 许立国委屈自辩：“不就是暂时融入其肉身内，占据之后感受了一下有了肉身的感觉么，多大的事啊。”

## 五、怨气入黄泉与意境圆满
- 王林将怨气一一吸收，尽数融入**黄泉**之内；怨气彼此融合，黄泉渐有一丝**泉魂**的影子。
- 神通的完善耗费大量精力，虽未全部成功，但在改善中不断体会**第三步**的方向，意境渐高。
- 至其抵达青灵星**第十八年**，**生死轮回意境彻底大圆满、再无半点瑕疵**——只需仙力足够，便可真正成为**第一步巅峰**的修士。

## 六、冲关规划与天罚之虑
- 储物袋内**仙玉**尚有一些，但未必够用；即便不够，王林也打算**喝下仙液**，此次必须达到**问鼎后期大圆满**，攀登修道第一步巅峰。
- 回忆：当年问鼎之时，**古妖贝罗**曾言“逆修之人会引动天罚”。王林抬头望天，冷冽自问：若有朝一日突破问鼎第一步、达到**阴虚之境**，是否一样会有天罚降临。
