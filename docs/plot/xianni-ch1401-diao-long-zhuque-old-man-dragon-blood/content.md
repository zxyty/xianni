# 第九卷 云海之巅 · 第1401章 钓龙

## 一、饮血悟火

- 王林随手拿起湖畔酒壶大饮一口。酒液入腹化作辛辣火线，自喉烧至腹，汗珠一出即化白气飘散。
- 火热之力弥漫全身，王林体内元力如得生机急速运转，**凭空多出一丝元力**。
- 火焰倍增，连发丝亦燃，热浪自汗毛孔外散；王林**左眼浮现朱雀印记**，蓝色火焰自左目爆发，与体内火热融合。
- 一声嘶鸣中，蓝色朱雀自左目飞出盘旋体外，状极舒适，约**一炷香**后方归左目。
- 王林体感：**火之本源浓厚一丝**，且酒中火焰之力令**朱雀下一次觉醒更近一步**。
- 老者揭底：「这不是酒，是血。」并称此物「即便是第三步，也要犹豫一下」才敢喝。

## 二、钓龙

1. 湖面骤起剧烈波纹，湖底传出闷雷般咆哮，湖水浑浊到**神识无法延伸半寸**。
2. 老者猛拽鱼竿，银线鱼绳绷直，拽出一颗**百丈大小的龙头**——龙头正中有一处颜色更深的**褐红鼓包**。
3. 龙身出水即达**千丈**，赤红遮天盖月；王林在其面前如蝼蚁。
4. 巨龙挣脱无望，转而张口吞噬老者，腥风与**惊天动地的威压**爆发。王林被威压一冲面色苍白、下意识后退，判定其为「**第三步**」——威压**丝毫不弱于当年水道子**带给他的感觉，堪比第三步修士的绝强凶兽。
5. 老者左手覆一层**仿若虚幻的火雾（虚火）**，随手一挥即将巨龙抽飞倒卷，火雾蔓延龙身，啪啪燃烧，龙欲缩回湖底被鱼绳硬生生再拉出数百丈。
6. 老者喝斥「你这小小炎龙也敢逃」，踏上龙头，左手抬起——其身后浮现**一尊巨大朱雀虚影**：遮盖天空，气息沧桑，虚火弥漫，仰天长嘶。
   - 王林震撼：此朱雀的大小与火焰之力**远超当年的朱雀老圣皇**，二者根本无法相比，「如同幼雀与其祖之间的差距」。
7. 朱雀虚影凝入老者左手化为**锋利尖喙**，一击轰穿龙头鼓包，燃烧的**血箭**喷涌而出。

## 三、取血与验身

- 老者喝令王林取壶装酒（血）。王林抓壶飞起收血；壶满后另取**药瓶**去接，药瓶一触血液**当场融化**，无法容纳。
- 王林不及思索，张口猛吸，将残余龙血**尽数吞入口中**，约合方才三大口之多。
- 老者眉开眼笑，收绳、右脚一踏离开龙头；巨龙愤怒却不敢咆哮，借力钻入湖底逃逸。
- 老者赞：「好，不愧是我朱雀族人，知晓浪费可耻」。
- 王林体内火焰滔天、面色红润，当即盘膝炼化龙血。

## 四、老者的判语（关键设定）

- 本以为再见不到族中小辈，如今又见一个；观其朱雀觉醒，**只差一步即可达到「虚火之境」**，此子不凡。
- 判定王林「应该是我族的**第六代朱雀**」。
- 亲手捏脸、探怀、遍身拍查后确认：**的确是朱雀族人，不是仇家造出**；且惊觉「这小家伙的**肉身居然是古神**」，兴奋称奇。
- 对比族中前辈：「**四代小朱雀风流成性，修不了老夫的神通**；这六代小家伙看起来冷冰冰的，应该能。」
- 拍查中忽然一愣：「**元神之阳居然也被破了**」——面露恨色，长叹罢手，自道「还是老夫当年有定力，元神之阳至今还是完整」。

## 五、要点提炼

- **龙血功用**：增厚火之本源，推进朱雀觉醒进度；凡物（药瓶）不可盛，须以特制酒壶承装。
- **境界锚点**：炎龙威压 ≈ 第三步 ≈ 当年水道子；老者可徒手戏耍之，实力远在其上。
- **朱雀谱系**：老者（辈分极高，虚火大成）→ 四代朱雀 → 五代（未提）→ 第六代朱雀＝王林。
- **王林新设定**：肉身为古神之体；元神之阳已破（老者视为憾事，暗示与其神通传承相关）。

> 归属说明：据【世界状态须知】，本卷王林于云海星域一线曾以化名行事，本章正文直呼其本名「王林」，故所有言行归于【王林】本人。
