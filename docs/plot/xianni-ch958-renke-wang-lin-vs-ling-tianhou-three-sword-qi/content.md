# 第八卷 联盟隐秘 · 第958章 认可

## 一、局面：天运子力保，剑尊索债
- **天运子**神色一沉、语气平静表态：王林“只要一天没有真正叛出师门，就是我天运宗弟子”，摆明护短立场。
- **凌天候（道号剑尊，大罗剑宗）**反驳：自家弟子“剑肖十二子”除**辰龙**一人活下来外，其余全部为王林所杀。
- 剑尊开出条件：**不以大欺小，王林只要接下他三道剑气，当年之事一笔勾销**；若天运子再阻拦，他“拼了一切，也要与天运子再续前战”。
- 凌天候一脸煞气，话对天运子说，目光却死盯王林。

## 二、王林的反将一军
- 王林先向此前放话“他没有拥有令牌的资格”的**肉山般老者**发问：“前辈你可以在剑尊剑气下，抵抗多少道？”
- 肉山老者面色阴沉、冷哼不语，目中杀机闪过。
- 王林随即微笑面向凌天候：“请剑尊赐教。”

## 三、第一道剑气：古神一拳硬撼
- 凌天候身前有**四把元神之剑**，挥手放出其中一把明暗不定、散发幽光之剑，剑气化作剑龙呼啸而至，天空砰砰作响似承受不住。
- 王林眼中爆出精光，右手握拳向虚空一击，拳前天空出现**坍塌迹象**，与剑气对撞，连续巨响。
- 结果：王林身子一晃、**退后两步**，平静道：“第一道。”
- 剑气崩溃形成的风暴被**天运子**大袖一扫化去；天运子看了王林一眼，嘴角露出微笑。

## 四、第二击：三九之剑二十七剑成阵
- 凌天候不作停顿，那把元神之剑剑鸣直冲九霄，本体疯狂冲向王林。
- 王林长笑握拳，**眉心传出磅礴之力入手，晶点弥漫**（古神一拳），拳出后晶点紧随冲击。
- 同时左手拍**储物袋**，低喝“**三九之剑**”：二十七道银色长虹冲出，每道内散发刺目银光、**无数魂魄幻化而出**，凄厉之吼瞬息弥漫天地。
- 王林一指之下，**二十七把飞剑**直奔凌天候，融合成蕴含**无数阵法**的剑阵，由**神识操控**。

## 五、旁观诸强的震动
| 观者 | 反应 |
| --- | --- |
| 天运子 | 大吃一惊。他“可以算出一切结果，但过程无法算出”——只算出王林修为大增后于**紫青双霞漫天之日**回来，算不出真实修为。看出王林眉心几股力量，其中**三股连他也颇为忌惮**；判断**眉心的朱雀印记**是王林敢回天运星的依持之一。 |
| 村姑般的中年美妇（炼器宗师） | 一眼看出二十七剑不凡：材质已然不凡，蕴含无尽杀机，显然在**杀戮滔天之地祭炼无数年**，任何一把都可成**绝代凶器**；见其融合成剑阵后深吸一口气。 |
| 坐在葫芦上的老者 | 猛地站起，直勾勾盯着王林，心底掀起大浪：“**绝不是窥涅初期**”。 |
| 肉山般的老者 | 心神一震，呆望剑阵与冷漠的王林，额头泌出冷汗：“小看了此人”。 |

## 六、剑阵对元神之剑：分庭抗衡
- 凌天候对剑之造诣惊人，见二十七大剑眼露精光，认可道：“**如此飞剑，如此剑阵，王林你有资格与我一战**”，余下三把元神之剑尽出，剑气贯空结成**剑网**笼罩而下。
- 二十七剑追上先前拳风，以其为核心化作**剑之风暴**，与四把旋转元神之剑对撞。
- 过程：飞剑一把把倒卷而飞、复徘徊王林身周；二十七剑全部倒卷之际，**古神一拳的磅礴之力爆发**，轰得凌天候四把元神之剑一震倒退。
- 外人看来是**分庭抗衡之势**。

## 七、王林的清醒判断与动机
- 王林知道：凌天候**未施展神通，只用寻常剑技**，并非手下留情，而是在剑尊看来“即便你是窥涅初期，也没有资格让我使用神通”。
- 王林回天运星**没打算低调**——“在这里，一切都需要以实力说话”。以其心机，路上已分析透彻：
  1. 若想**重新去妖灵之地**；
  2. 若想**获得拥有令牌的资格**；
  3. 若想**得到天运星老怪的认同**；
  **这一切，都看今日这一战**。

## 八、要点归属说明
- 本章“王林”即主角本人（此阶段在联盟一方多以自创化名『许木』行事，此处于天运星以本名王林现身），言行归【王林】。
- 章节标题“认可”对应凌天候由索债转为承认王林“有资格与我一战”，以及诸老怪对其实力的重新估量。

# 第891章 明剑对五九剑阵：凌天候罢手与朱雀序列伏笔

## 一、凌天候破约施展成名神通

- 凌天候眼中闪过古怪之色旋即消失，长笑中**早已把三剑之约抛掉**，双手掐诀成弧形一晃，苍发无风自动，目露奇异之芒。
- 自陈：「你有资格让老夫施展神通，老夫一身神通只有三个字——**明、洞、破**。」随即低喝「**明剑，第一式，以血铸剑**」。
- 四周修士哗然。众所周知：凌天候声名赫赫、一宗之主，神通惊天地泣鬼神；**一生只有一个死敌，即天运子**，其神通极少施展，几乎每次施展都是与天运子之战。
- 因此，凌天候肯对王林施展神通，本身即意味着**王林即便败也立即扬名**。
- 神通表现：右手前指，**四把元神之剑相互融合**，化作一把虚幻剑影，散发炙热气息，由虚幻转为液体状，在阳光下展露多彩之芒，直奔王林。

## 二、王林五九剑阵 + 斩罗诀正面对撞

- 王林神色平静，退后数步拍储物袋，低喝「**五九剑阵**」：储物袋内飞出道道银光，与四周二十七剑交错，**共四十五把七尺长剑**疯狂旋转，形成**剑之漩涡**。
- 王林双手掐诀并拢，向前狠指，喝「**斩罗诀**」；体内元力运转之速几乎达到巅峰，斩罗诀融入剑漩，剑漩轰然一震齐齐凝聚前冲。
- **来源交代**：这批飞剑得自**杀域界**，王林在来天运宗的路上已祭炼成五九之数，且**彻底改变了外在样子**，若非杀域界之人很难发现来源。
- 对撞：剑气漩涡蕴含无数斩罗诀之威，与凌天候神通交错，天地色变、乾坤逆转，巨响回荡、砰砰之声取代天地一切声息。
- **天运子双臂横扫阻拦冲击外泄**，否则天运星都会因此坍塌无数。

### 结果

| 一方 | 结果 |
| --- | --- |
| 王林 | 身子疾驰后退；四十五把飞剑**无一损坏**但**有了黯淡**，环绕其身随之后退 |
| 凌天候 | 四合一的多姿之剑一震崩溃，**重现化作四把**；**身子纹丝未动**，眼露精光 |

## 三、凌天候罢手：恩怨勾销 + 仙府许诺

- 凌天候长笑：「王林，你与我**大罗剑宗恩怨一笔勾销**，那**令牌老夫不要了**，你既获得便是你之机缘，**到时去仙府，有你一份**。」
- 转身一步踏出，身后大罗剑宗弟子虽仍迷茫，仍立刻跟随，剑光疾驰远去。
- 王林望其背影沉思：「**凌天候，此举大有深意**。」

## 四、旁观者反应

- **白薇**：眼露激动，至今仍有些不敢相信——「王林竟然有与凌天候一战之力」。
- **赵星煞**：面如死灰，目光充满惊惧，再不敢有半点邪心。
- **紫系老四**（始终无动于衷的女子）：眼中迷茫消散，望着王林有了奇异神采，紧咬下唇内心作出决断——「**他若能帮我**」。
- 几乎所有当年与王林相识之人，皆在震惊中恍惚，当年的王林与此刻这白衣身影**渐渐融合为一**。

## 五、四方老怪相继示好离去

王林未收飞剑，目光落在肉山般的老者身上，平静发问：「前辈，我可有资格？」

1. **肉山老者（李某）**：沉默、哼了一声，向天运子抱拳称「还有一炉丹药正炼，不打扰了」，喝令抬着他的四名弟子「回山」。（暗示其为炼丹之人）
2. **葫芦上的老者——奇梦谭**：大有深意地看王林一眼，笑称「王道友隐藏的好深」，自报名号并邀请「若你有暇，欢迎来我**梦星**一聚」，向天运子抱拳告辞。
3. **干瘦如尸般的老者**：至始至终一脸冷漠，离开时未与天运子告别，直接踏空而走。
4. **村姑般的美妇**：点评「王道友的这些飞剑**煞气很足**，只是煞气太足未免**难以操控**」，邀其有空去**紫霞星**，向天运子躬身后带四名女子离去。
   - 其**粉衣女子**弟子回身轻笑：「我师尊**擅长炼器**，费用不贵的。」美妇与其余三女掩口而笑。
   - 随行**绿衣女子千琴**临走望向王林的眼神很是不同，轻叹：「他或许已经忘记了我的名字……毕竟当年对他来说只是很细微的一件小事，但对我来说，却是**救命之恩**。」粉衣女子问其何事，千琴摇头不语。

## 六、师徒独对：妖灵之地与朱雀序列

- 天运子吩咐下，天运宗之人相继散开；整个广场只余王林与天运子。**师徒二人阔别数百年后再次单独面对**。
- 天运子沉默良久后问：「你有何打算。」
- 王林恭敬答：「**弟子想进入妖灵之地。**」
- 天运子背手徐徐道：「你有这个资格，无论是**罗天的正品雷仙**，亦或者是**四圣宗朱雀一脉这一代序列之一**；据我所知，**这一代朱雀序列，算你在内，可是只有三人**。」
- 王林沉默——他**此前并不知晓朱雀序列之事**，此刻听闻心神一动，但神色上未露半点。
