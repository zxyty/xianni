# 第七卷 名震罗天 · 第828章 魔道子

> 世界状态须知：本片段主角以化名「许木」行事（自第661/669/711/731章沿用），言行归属【王林】。塔山虽在第753章有死亡记录，但本章其自王林身后虚影踏出参战，应作为王林所控之虚影／存在形态理解。

## 一、与姚冰云的收尾交手

- 王林所布雷球尽数崩溃，姚冰云的冰封蔓延而至，仅略有停顿。
- **塔山**自王林身后虚影踏出，以未受伤的左拳硬撼冰封。
- 王林右手抬起施展**呼风之术**，近距离黑风吹袭，冰封瞬间崩碎成无数碎片。
- 姚冰云神色冰冷，轻吐二字：「**血，崩**」——塔山浑身一震，大片鲜血自体内喷出结成血雾，一拳未出便被大力轰退，迅速缩回王林身后虚影。
- 王林同时感到一股奇异力量自四面八方凝聚，带某种波动，使其**全身血液流转加速、仿若沸腾欲冲出体外**。
- 王林杀机一闪，右手一握，四散黑风凝为**黑龙**，龙口咆哮喷出大片阴风扑向姚冰云。姚冰云**面色第一次微变**，双手掐诀。

## 二、王林判断与撤离

- 关键认知：**姚冰云同样可以融入天地**，王林原本依赖的战斗方式对她失效。
- 王林目露果断：「这女子，他打不过」，索性迅速逃遁——身子后退，融入虚无，脚下波纹散开，身影消失。
- 姚冰云欲追，却被黑龙阴风所阻（融入天地亦避不过），只得祭出**蓝色元丹**：元丹色泽鲜艳绚丽，迎向阴风，咔咔声中阴风消散，而**元丹颜色随即黯淡，仿若失去灵动**。
- 姚冰云抓丹继续追，神识融入天地散开寻找波动。她自出道以来从未遇过如此难缠之人。

## 三、罗天西域封锁网

- 王林目标：直奔**罗天北域**，心中有一个大计划。
- 地理关键：**罗天西域与北域之间隔着一片星河**，穿过星河即可进入北域。
- 星河外无数修士密密麻麻几乎连成一片，齐齐向罗天西域压来；整个罗天西域内亦聚集大量修士。
- 构成分析：
  - 除姚家族人外，绝大部分是**姚家各自联系的修真家族**；
  - **罗天西域本域修士占一大半**；
  - **真正的姚家族人反倒不多**，且冷眼待在后方。
- 手段：封锁所有出路，并**不断干扰四周天地之力使其处于扭曲之中**，令融入天地者无法安然通过。
- 双方算计：姚家以重赏利益换取家族助战省力；各修真家族认定许木必死无疑、出战即有好处，故踊跃参与。

## 四、被逼选择「屠星」

- 王林在交界星河万里外现身，感受到阵阵强大波纹，判断：一旦半途被逼出身影，在如此多修士围攻下**必死无疑**。
- 「许木，他在这里」「许木在这，杀」——数道神识横扫、大量修士疯狂冲来，王林被迫向后遁逃（**向后退不受天地之力扭曲干扰**）。
- 王林将追击者相貌一一刻入脑海，冷笑立誓：「姚家，既然你们展开如此行动，王某若不好好地报复一番，就妄自称为**逆修**。」
- 战略推演：
  1. 若不震慑，会有越来越多修真家族被重赏吸引加入，活动范围只会越来越小；
  2. **最有利的震慑就是屠星**——参照**东临星**：每一代传人出现，但凡有招惹者必会屠星，以血腥为代价让所有人记住；
  3. 更大的焦虑在于姚家及各家族中**踏入净涅期的大神通修士**随时可能赶来，哪怕一个都足以让他无法抵抗。

## 五、屠星执行准则（王林自订）

- **目标筛选**：神识一扫，若某修真星以其灵气程度本不该缺少阴虚以上修士，却连**问鼎大圆满以上修士**都没有，即断定该星修士已参与追杀 → 展开屠杀；若阴虚修士都在，则转身离开。
- **杀戮边界**：凡**婴变以上**修士，见即一指弹出；**凡人一个未伤**；**化神以下修士**不足以牵连此事，未曾出手。
- **署名**：临走右手向大地虚空一按，地面剧震后浮现两个大字「**许木**」。
- **效率**：首战不到半柱香即扫清，随即融入天地消失。
- 姚冰云随后自虚空波纹中走出，见此惨状面色阴沉，继续追击。

## 六、结果与影响

- **三十天内**，血腥风暴横扫整个罗天西域，**超过数十个修真星**被屠尽所有婴变以上修士，血流成河，皆留「许木」刻字。
- 消息疯狂传开，令所有修士愤怒而又极为惊惧。
- 「这种行为，是魔道之行」——**「魔道子」**这一称号不知从何人口中首传，落在王林（许木）头上。
- 王林的因果宣言：「无冤无仇之下，你们为姚家重赏追杀于我，这便是**因**；我屠星之事，便是**果**。你等因果，自入轮回。」（并注明「王林并不嗜杀，但此刻被逼」）
