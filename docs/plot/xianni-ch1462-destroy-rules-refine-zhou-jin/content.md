# 第1462章 破坏规则（第九卷 云海之巅）

## 一、九滴毒液锁死周谨

- 王林言语冰冷，九滴黑色毒液环绕封住奉天狼族大汉**周谨**的一切动作。
- 毒液之毒：以周谨修为可清晰感知，**一滴即可将肉身元神全部腐蚀，半点不留**。
- 更骇人处：九滴毒液内弥漫大量**香火之魂**，已被毒污化为**毒魂**，被强行炼化封印于毒液内，散发无尽怨气与毁灭天地的冲动。
- 周谨皮表起细微疙瘩，不敢动分毫。

### 此战的三重意外（自周谨视角）
1. 没料到**灵动**会出现；
2. 更没想到灵动竟迈出了**那半步**；
3. 被**古息叶**封印大半方向后尚有反抗之力，唯独九滴毒液令其心神几近崩溃。

## 二、灵动上人称主，王林定“炼”

- 灵动上人上前至王林身外十丈，**单膝跪于虚空**，目露狂热恭敬，问：“主人是要杀他，还是炼化。”
- “主人”二字令周谨震骇：第三步大能为星空最强存在、数量稀少个个声名赫赫，**岂能认人为主，更何况认一个尚未达到第三步之人为主**。
- 王林答“**炼**”：天皇炉变化，十八片古息叶急速而来封印炉上，其内魂魄弥漫，展开炼化。
- 灵动上人在王林帮助下**从香火界踏入毒海界**，盘膝半空协助炼奴。

### 炼奴难度与把握
- 周谨与当初的灵动不同，是**真正踏入第三步的大能**，炼奴不易；即便**梦道之术**，也需先把对方心神耗尽才能增加成功把握。
- 当下压制格局：天皇炉内压制 + 灵动上人看守 + 古息叶封印 + 九滴毒液环绕 ⇒ 王林有十足把握对方逃不出手心。
- 毒液仅九滴，王林不愿浪费，此时威逼围困已发挥最大作用；亦**不打算毒杀周谨**。
- 图谋：若炼成**古奴**，回界内后身边有**两大第三步大能奴仆**，当年大敌**水道子**见了必魂飞魄散逃遁。

## 三、收炉与森林处置

- 王林眉心闪出**古神星点**，旋转间将天皇炉收入眉心之内。
- 地面景象：弥漫枯萎树木的森林内部已空旷，仅外围尚存近百树木；森林中心，**贪狼离开古墓的传送漩涡**未受任何影响，依旧漂浮。
- 取舍：王林本欲把整片森林连同埋葬的**古神头骨**一并收走，但担心收走后传送漩涡消散，得不偿失。
  - 该漩涡对王林很重要；神识扫过确认**确有传送作用**，但不确定通过它是否会被传送到**太古星辰**。
- 决定：不轻举妄动，改为**封死**。

### 封印工程
1. 掐诀幻化大量禁制直奔天空，层层封印，**耗时数日**将该天地内部彻底封死。
2. 一步迈出离开森林天地，出现在**古墓雾气**内，再施禁制从外围封印。
3. 效果：内外均烙印诸多禁制、完全封死，**即便有人无意中得到古息叶而来，也无法短时间破开，且有诸多凶险**。
4. 加固：双目光芒一闪，**流月石门**轰然幻化，岁月流逝为封印上的**岁月禁**添入光阴，封印威力再增。

## 四、夺墓台，己身墓台暴涨六千丈

- 王林目光落在周谨的**五阶墓台**上，右手虚空一拍，墓台轰鸣震动，大量符文飘出直奔王林。
- 王林取出自己的**五阶墓台**吸收符文，墓台剧烈震动、骤然膨胀，**转眼达到六千丈大小**。
- 站在墓台上的王林，顿时感受到那**熟悉的神识**冲入心神。

## 五、关键点小结

- 王林已实际驱使一名第三步大能（灵动上人）为奴，并着手炼制第二名（周谨）。
- 王林尚未达第三步，却令第三步大能称“主人”——本章“破坏规则”之题眼。
- 贪狼传送漩涡被封存待用，疑与太古星辰相关，是后续伏笔。
- 墓台达六千丈，为墓台体系中的重大跃升节点。

# 第1371章 三族之力合一·抹去数字标示

## 一、仁和剑传承讯息
- 王林脑海中的地图再次多出一面。
- 一个威严声音回荡其心：「九阶为终，本道有天地人三府，人府有仁和剑，此剑随本道杀戮一生，为天下至凶之剑，因其杀戮成魔，故而本道在其上留有三道封印。」
- 声音消散后王林神色平静，操控身下六千丈大小的墓台直奔前方，消失于雾气中。

## 二、竞速判断：目标是九阶墓台而非最快到第九图
- 疾驰途中王林感受到前方还有数道墓台气息，均为五阶以上，位置远超自己。
- 其中最前方一位，按王林分析方位已到第八幅地图。
- 王林推断：古之声音的要求并非「谁最快进入第九幅地图」，而是「第一个成为九阶墓台」。
- 结论：按当前速度无法快过前面几人 → 转变思路，研究古墓规则本身。

## 三、数字标示之谜
- 关键异常：古墓内人人均有数字标示，唯独王林没有。
- 王林自解：自己是古神，故进入此地不需数字标示；并推断若拓森也来此，同样不会有此标示。
- 心态动因：进古墓后他始终被动，受此地冥冥之力操控指引而行，连巨手的出现都似有人操控，令其极不舒服。
- 研究方式：在墓台上一拍震起数字符文抓在手中细看；任墓台前行，穿过第五张地图进入第六张地图，前后换过数百个符文。
- 观察结论：符文内蕴含一股古怪力量，其作用似乎是**让人可以短时间存在于此地**。

## 四、试验对象：封灭族少女
- 王林虚空一抓，取出封灭族少女（族印已被其取走），双目紧闭似沉睡，眉心仍隐有数字标示烙印。
- 第一次尝试：以古神之力弥漫手掌抹其眉心 → 少女身子一颤，但标示仍在。

## 五、古之三族之力的融合
1. 取出**古魂瓶**，一拍放出一尊古魔之魂，抓住狠捏令其凄厉而亡，化作古魔之力环绕右手。
2. 引动体内**古神之力**与古魔之力融合 —— 始终无法圆满，似缺少什么。
3. 顿悟缺的是**古妖之力**：取出在第一处封印之地由身边修士为保命所赠的古妖葫芦（内蕴不多古妖之力），一敲放出妖气，笼罩取出一部分按于右手。
4. 古神、古魔、古妖三种气息齐聚，刹那完全融合，形成远超三者的独特力量 —— 王林「有种抓住天地的感觉」。

## 六、结果与突变
- 王林以该融合之力在少女眉心一抹，眉心数字标示被一掌抹去。
- 少女猛然睁眼惨叫、身子剧烈颤抖。
- 四周雾气瞬间如沸腾般从四面八方疯狂冲来，直奔少女 —— 似其眼下的存在与古墓规则产生强烈冲突，引动古墓一系列剧变，要将这不该存在的变化生生抹去。
- 少女被雾气笼罩，消失在王林身前。变化太过突然，连王林也未料到。

## 七、要点归纳
- 规则解读升级：古墓通关判定 = 第一个成为九阶墓台。
- 力量体系线索：古神 + 古魔 + 古妖三族之力可合一，威能远超单族。
- 数字标示 = 在古墓中「短时间存在」的凭证；无标示者（古神，如王林、疑似拓森）不受此限；被强行抹去标示者会被古墓规则清除。
