# 第1512章 金色铃铛！（第十卷 叱咤界内）

## 一、王林两拳压制水道子

**开场判定**：王林平静审视水道子——仍是**空涅初期**，与当年一般无二，且神通威力比当年**更弱**，显然伤势并未痊愈。王林摇头：「这样的你，我杀之，不够酣畅。」

**第一拳·破形**
- 拳意：「这一拳，代封尊，破你叛奴门徒之形。」
- 简单一拳，蕴含莫大自信，此刻的王林「如同掌握天地生死之神」。
- 效果：水道子香火所化长枪自枪尖崩溃、势如破竹整枪碎灭，无数香火之魂凄厉惨叫中大量消散。
- 水道子连退**九步**、喷**九口鲜血**，每退一步天都轰鸣；体内反震之力疯狂破坏，**童子样貌骤然苍老**。
- 水道子骇然：「不可能……你到底有了什么造化，竟有如此可怕之力？」
- 终被抛飞撞入五座山峰之一的中段，山峰裂如蛛网、自中间分裂崩塌。

**第二拳·毁身**
- 拳意：「这一拳，代封尊，毁你奴之肉身。」
- 王林身后**道古头颅**幻化融入拳内，化作遮天大手握拳降临，拳影占据整个天地。
- 水道子拼死三重防御：①**本源之力·阴阳仙龙**（黑白两股本源之力凝成交错双龙）；②喷血甩袖放出黑白细丝所织的毁灭大网；③撕开储物裂缝倾泻大量法宝形成万丈光芒风暴。
- 结果：双龙惨叫崩溃、大网层层撕开、所有法宝尽数爆开，皆无法抵抗**七星古神**一拳。
- 虚幻拳头砸中水道子，**前胸爆开**、血雾喷涌，被推落大地；水道子双脚踏地、双手死死撑住巨拳，鲜血染红衣衫。

## 二、旁观者的恐惧与算计

- **黑衣老者**（与灵动上人缠斗、节节后退）：面色苍白，对看都不看自己一眼的王林生出恐惧——「此人是谁，竟然有第三步大能为奴这种人物，岂能得罪？都是这水道子害人！」
- **云峰子**（与周瑾交手）：自忖与周瑾修为相当，但周瑾香火远超己方，被迫后退并动用法宝；心中懊悔——「为了那定神术得罪了这种以第三步为奴之人，这笔买卖，我云峰子要赔了。」
- **水道子的失算**：放弃了以破灭宗宗主破坏王林道心的念头；**鬼宗妖圣**似乎完全不在意其数亿门徒香火，毫无来临出手的迹象，逼得水道子只能另寻援手。

## 三、化形之修·大阿罗现身

水道子仰天低吼「太阿罗！」，一声叹息自天地回荡，扭曲近乎碎灭的天空中缓缓走出一人：
- **形貌**：身子模糊、赤着双脚，一步步走来，身上**没有半点元力波动**，出现方式诡异莫测，「仿若本就存在于那里」。
- 王林之前已发现周德、云锋子，却**没有感应到此人的存在**，故瞳孔微缩。
- 此人并未看向水道子，而是**遥遥向王林抱拳**：「化形之修，大阿罗，见过此代封尊。」
- **提议**：「我无意与您为敌，若您解开我身封印，我可率**云海裂缝所有族类**，为界内一战——甚至为您杀此人，也可。」（水道子闻言面色一变）
- **王林回应**：「你之事，稍后再说。」旋即迈步逼近水道子，出第二拳。

## 四、金色铃铛与封界大阵显形（本章高潮）

水达至绝境，双眼疯狂，**口中喷出一道金光，金光内是一个铃铛**：
- 极为精纯的**仙气**弥漫天地，铃铛清脆作响，与王林拳头相撞刹那爆发**金色之浪**。
- 金色之浪蕴含**来自远古仙域的道术神通**，以该修真星为中心以不可思议之速向四周扩散，**扫去星空内一切隐藏**。

**四大星域同步异象**（界内几乎所有修士同时目睹）：
| 星域 | 当时情形 | 所见 |
|---|---|---|
| 云海星域 | 一队队修士在雾气内前行 | 金色波纹刮去雾气与星空，露出星空下的大阵 |
| 召河星域 | 无数修士备战、星空游走 | 星空如被剥去神秘面纱，露出下方封界大阵 |
| 罗天星域 | 挪移修真星的队伍比比皆是 | 全部呆在星空，怔怔望着下方封界大阵 |
| 联盟星域 | 诸多小势力备战中 | 骇然停止一切行动，望见金色波纹过后出现的巨大之网 |

**封界大阵**：封锁界内无数年、几乎自遥远岁月就存在，**数万年来第一次幻化显形**；其无边无际、包含整个界内，细密网纹触目惊心。绝大部分修士一生第一次得见，如失去呼吸般呆望。

**认知冲击（修士群体反应）**：
- 「原来我们生存的星空，真的如云海所说，是被人封印之地。」
- 「原来一切都是真的，封界大阵外，有**太古星辰之民**。」

## 五、界内高层的即时反应

- **红杉子**（云海一阶星雾内山谷）：面色大变，猛地起身破开星空，**直奔神宗**——「该死的，这是远古仙域的气息，这水道子竟有此物！」
- **尸阴宗**（联盟星域）：传出震惊呼吼，一全身虚幻的老者身影急速幻化、破空**直奔神宗**，并道破关键情报——「远古仙域之物……此物似与封阵融合之物，在没融合前极为脆弱，**毁不得**。」

## 六、关键伏笔 / 待续线索

1. **大阿罗的封印**未解，其「率云海裂缝所有族类为界内一战」的许诺悬而未决——王林明言「稍后再说」。
2. **金色铃铛**为远古仙域之物、与封界大阵融合之物，**未融合前极为脆弱、毁不得**——这句判断很可能左右后续对铃铛的处置。
3. 封界大阵显形后，界内修真格局与人心（对太古星辰、对云海之说的态度）势必剧变。
4. 红杉子与尸阴宗虚幻老者双双奔向**神宗**，两大势力即将介入此局。
5. **鬼宗妖圣**对水道子数亿香火见死不救，水道子的靠山已实质崩塌。
6. 云峰子为**定神术**而来，其得失去留待观。

> 注：据世界状态须知，王林自第1063章起以「吕子浩」之名立足云海星域（身份由吕烟菲奉上）；本章正文直呼王林本名，其言行均归于王林本人。另据须知，「水道子」曾记于第1242章死亡，本章其活跃出场且被王林指认「还是如当年一样，空涅初期」，本章按其在场行动如实记录。
