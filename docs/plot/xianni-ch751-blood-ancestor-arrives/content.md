# 第751章 血祖来临

## 一、交易：定身术换禁制传承

- 葛姓女子已死（承接前章），王林认为她自随李元踏入雷之仙界起命运便已注定，故未出手相助。
- 王林评断李元：**心机极深**，一路隐忍到山峰才和盘托出；山峰上下充满禁制，疑与李元先祖大有关联；但所言真假尚未确定。
- 疑点：葛姓女子**死前双目奇异，回头去看那石像**。
- 李元请求：借王林那道“可使阴虚修士神通静止”的法术（定身术）相助，以彻底打碎石像、令李家恢复自由。
- 李元评价此术：“生平仅见”“世间万物在那一刹那都将被永恒的凝固”。
- 报酬：**破灭禁 + 梅花十八禁**。李元先交玉简（梅花十八禁剩余几尊禁制石像），破灭禁待破封后再给。
- 王林动机：梅花十八禁若全部参悟，不但增强禁制威力，与神通法术亦有相通之处 → 口头应下“许某可以出手相助”，内心更为谨慎，觉得李元身上始终笼罩一层迷雾。
- 关键伏笔：王林扫视石像时心神一动——**仙人石像的样子与葛姓女子相貌略有相似**。

## 二、祭炼石像的完整流程（李元手段）

1. 取出铁剑，划破左手，血顺剑身流下，散发妖异红芒。
2. 低语咒诀，血痕中涌出**众多怨气**汇聚，化作一张张虚幻人脸，**每张人脸眉心有相同烙印**。
3. 铁剑腾起红焰；李元咬破舌尖喷血融入，红焰大涨，内传哀嚎低吼，山顶如九幽鬼境。
4. 抛入**罗盘**，指针急转，每转一圈散出波纹使火焰暴涨；罗盘随后碎裂，红焰更浓。
5. **铁剑崩溃化为铁水**被红焰吸收，红焰涨至十余丈，腾空扑向石像。
6. 红焰包裹石像（连同石剑与剑尖之上的仆从），怨气疯狂钻入，石像遍布裂纹。
7. 抛出**玉瓶**，白芒飞出融入红焰、顺裂缝钻入石像。
8. 最后抛出**画轴**铺展，石像剧震，其内“苏醒”之感越来越浓。

> 怨气与白芒如同养分，使石像似有脱困之力；但另有一层封印阻止其脱困，欲与之一同崩溃。

- 李元大喝：请王林施展神通，好让他以画轴“把这仙人石像残存的**不灭之魂**封印”。

## 三、翻脸：王林识破退避

- 王林不但不施术，反而冷笑急退，隐约看明白此事真正因果。
- 王林点破：“你的目的怕不是解脱李家封印，而是想要把这仙人石像**复活**吧。”
- 李元修为**问鼎大圆满**，但气息中另含一丝可怕气息；一冲如瞬移追上王林。
- 王林召出背后虚影中的**仙卫傀儡**出拳（轰隆巨响）；李元掐诀现出一条黑线延长成**三角图案**，如软线般贴身缠满仙卫全身，散发黑芒，仙卫挣扎无用。
- 李元语出惊人：“**区区下品仙卫**，也敢在我面前放肆”——透露仙卫有品阶之分。
- 李元称王林的定身术“**传承至雨之仙界**”，劝其乖乖同回，事成不少其报酬。
- 王林拒绝理由：“**你连主子后人都敢杀**，让我如何能信你的承诺”（呼应石像与葛姓女子相貌相似的伏笔——葛姓女子疑为石像仙人的后人，而李家为其仆从/属下）。
- 王林瞬移遁走 → 李元眉心飞出一道禁制，云层齐齐推开，远处空间扭曲，**王林被逼现身**；但王林毫无慌乱，似胸有成竹另有打算。

## 四、场景切换：血祖降临

- 地点：**雷之仙界正中心的一处碎片大陆**（碎片不大，化作的大陆亦小），四周边缘一道道**雷霆如铁栏般包围**。
- 大陆中心有一座**庞大阵法**，阵外盘膝坐着**四名白发老者**，全身有庞大元力笼罩。
- 阵法剧烈闪烁，四老者纹丝未动；片刻后阵内浮现**红色虚影**，血气浓郁弥漫，四老者齐齐睁眼露出凝重之色。
- 虚影凝实：**红袍、红发、红眉的中年男子**——**血祖**。
- 台词：“**王林小儿，老夫来了**”。
