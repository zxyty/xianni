# 仙逆 第2064章 踏天一步！

## 一、全大陆震动：七位大天尊齐赴苍茫盆地

- 仙罡大陆的大天尊几乎全部惊动，化作**七道长虹**从各地直奔苍茫盆地。
- **古族**：三道长虹呼啸，速度极快。
- **仙族**：四人闭口不言疾驰，但以其速度即便全力也需**约半个月**才能赶到——一因仙罡大陆太大，二因他们没有王林与古道的修为。

## 二、战况：雾散见真容

- 苍茫盆地中心、海墙风暴卷动中靠近**吉（古）族**一侧：
  - **王林**：身外近万雾球弥漫爆开，嘴角溢血，蓦然后退数百丈，再喷一口鲜血，身外**幽色光环崩溃**。
  - **古道**：身外**雾兽**四分五裂、凄厉嘶吼中消散；雾兽既散，其四周雾气急速减少，遮面之雾将尽。
- 古道："你为了看清我的相貌，竟不惜受伤……你既想要看到，那么就看吧。你是从无数年来，第一个，看到了我容颜之人。"
- **古道外貌**：身子消瘦，一身青袍，**右臂无袖**，头发灰色，神情沧桑。

## 三、核心揭秘：古道即古祖

### 1. 相貌之谜
王林看清后毫无意外，只长叹"果然是你"——古道的相貌与他在**古祖三座城池内的古祖雕像**一模一样。王林问："我该称呼你为古祖，还是古道？"又问：是雕像照你所刻，还是你的相貌属于古祖？

### 2. 古道自陈
- "**我是古道，也是古祖。**"
- 他获得了**古祖的一部分记忆与意志**，用以**守护古族、守护其嫡系皇族的后人**；相貌也随着吸收这部分记忆与意志而**慢慢改变**。

### 3. 造化与限制
- 王林推断：得造化的同时必有限制——古道能离开的最大距离，大约就是此地。
- 古道确认："当完全改变的那一天，我感受到了一股限制的存在。**我无法走出古族大地太远，一旦出去，我的修为会全部丧失。**"神色平静，无奈苦涩皆无。

### 4. 由此澄清的旧传闻
- 传闻古道曾在**仙族大地**上击杀仙族大天尊——王林判定此事有误：应是**仙族入侵越过苍茫大海中心线**，古道才得以击杀。
- 这也解答了王林长久的困惑：以古道修为本可轻易灭尽仙族、令仙罡大陆从此无仙，但无数年来仙族始终存在。

### 5. 未答之问
王林再问"为什么要阻止我离去"。古道只道：获得古祖记忆后，无数年来慢慢感受到一些**"我无法理解、无法相信，但却很真实的事情"**，"或许是真的，也或许是我的错觉"——望着大地与古族方向摇头，终未正面作答。

## 四、约战：两式对决

古道双目露出果断："**战吧，胜了我，我没有力量去阻拦你的脚步，你大可离去。**我能感受到，你还没有全力，接下来，我也不会留手。"

### 古道之术
- 最强之术有**两种**：
  1. **古化天地**——源自古祖记忆：古祖自认从虚无内诞生，坚信双眼可化日月、血液可成江河大海、骨头可变山脉、双手相遮即是天、身躯倒下便成大地。因这信念与思绪，他**用毕生之力创造此术**。古道自传承后**从未施展过，今日是第一次**。
  2. **道天**——古道自己钻研**无数万年**摸索而出的一式；条件是王林须先接下古化天地，方"有资格见证"。

### 王林之术：踏天一步
- 来历一：在**始古皇城祖庙**内见到一个身影向天空走出一步，给了王林极大震撼。
- 来历二：在**踏天第五桥**上沉浸于如轮回一般的世界，不知过去多久，除**八极道**的感悟外，**感悟最多的正是这一步**；本无法走过第五桥，凭此步走过。
- 王林亦露果断：此战无法避免，那便**一战到底**。

## 五、古化天地：顶天立地的信术

- 古道右手抬起向天一挥，身后凭空生出无数光芒，刹那凝聚成**巨大光影**（全身被光笼罩，看不清样子）。
- 光影张口猛吸：天地之力自四面八方轰卷而来，范围急速扩至十万、百万乃至更广，覆盖整个苍茫盆地，继而越过盆地向古族与仙族方向轰鸣扩散。
- **全大陆连锁反应**：
  - 仙族靠近苍茫大海处，**久帝**等大天尊的四道长虹蓦然一顿，震惊远望，几有魂飞魄散之感。
  - 古族大地上**宋天**三人同样感受到那股来自苍茫大海中心的恐怖吸摄之力。
- 光影随吞噬天地之力疯狂膨胀，转眼数万丈之高仍不停止；王林抬头已看不到其上半身，只能看到双腿。直至**整个仙罡大陆的天地之力全部卷来**，膨胀才慢慢停止——若在仙罡大陆外看，必见一巨人**顶天立地**站在大陆之上。王林揣测：若给足天地之力，这光影或可堪比一片星域。
- **神识所见之景**：光影双眼脱落，一颗化作太阳、一颗化作月亮；流出的血液形成河流与海洋；双手抬起遮盖化作蓝色天幕；身躯轰然倒下成为大地；骨头化作一条条山脉。
- **对王林的侵蚀**：双眼突然刺痛渗血，似有莫大力量要将其双目生生取出作日月；双手颤抖被牵引欲抬起化天幕；身躯亦似要成为大地。
- **本质定义**：这是一种**信术**——信念强烈到极限后可以改变世界、改变时间与空间，凡被其信念笼罩之人，都会成为其信念之一。

## 六、踏天一步落下

- 王林深吸口气，双眼渐平，**不去考虑如何破术**，而是闭目——脑海浮现那**抱着尸体、站在飘落七彩雪花的山峰上仰天凄吼**的身影，以及那身影向天迈出的一步。
- 此步在脑海内反复浮现不知多少遍后，王林右脚缓缓抬起，向着这被**古祖信念创造的世界**的天空一步走去。
- 走出这一步时，王林生出错觉：**自己就是那个身影，就是那抱着尸体仰天凄吼之人**。无法形容的悲伤滋生，如同心被挖走之痛；他似忘记了正在与古道斗法，忘记了要回洞府界的方向，脑海中只余**无尽的哀伤、绝望与愤怒**。
- 正是这股**怒**，让王林这一步**蓦然落下**——**踏天一步**。

- 古道第二式"**道天**"尚未施展。
- 祖庙中抱尸凄吼、踏天一步的身影身份未明，与王林感悟高度共鸣。
