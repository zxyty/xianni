# 第1808章 大补！(第一更)

## 一、皇宫大殿：九龙皇袍男子唤醒「道非」

- **取人出漩涡**：身着九龙皇袍的中年男子一抓之下，大殿前方半空凭空出现急速旋转的漩涡，其内幽光漆黑、不知通往何处；呼啸声回旋中，漩涡内浮出两道模糊虚影，被其一把抓出——正是昏迷的**疯子**与**银衣女子**。
- **首次施救**：皇袍男子未理会银衣女子，只盯着疯子皱眉。疯子身体自行漂浮，被其右手按在胸口，一股浩荡仙力轰然涌入，体内砰砰巨响如雷鸣，磅礴仙力如江河咆哮，**打通了一条条闭塞经脉，并激起了疯子的血脉之力**，然而疯子仍旧昏迷未醒。
- **太阳虚影**：皇袍男子一甩大袖，身后现出巨大太阳虚影，笼罩大殿并向外弥漫天地——远处亦可清晰看到皇宫天空悬着一轮金色太阳，散发无尽光芒。
- **点名唤醒**：其口呼「**道非，醒来**」，右手再按疯子胸口，金色仙力直奔头颅，瞬间轰开头部闭塞的经脉与血管，**冲散了沉积无数年的郁气**。
- **短暂苏醒**：疯子面色红润，骤然睁眼，惊喜喊出一声「**哥**」，随即喷出一口鲜血，再次昏迷。
- **善后与疑问**：皇袍男子眉头舒展，太阳虚影消散，命大殿内两道金色烟丝所化女子「送**道非亲王**去休息」，银衣女子一同送去。其后坐回龙椅沉思：道非失踪多年，不知发生何事，伤势如此之重，**且血脉之力也少了一些**，待其醒来定要问个清楚。

## 二、天牛洲闭关：火焰本源的水土不服

- **闭关状态**：王林盘膝于其神通在天牛洲十万大山山峰内部开辟的洞府中，吐纳掐诀，全身弥漫火海；火海中身后隐现一尊巨大**火焰朱雀**环绕，火势愈烈。
- **避天棺入体**：他来仙罡大陆后一直背着的**避天棺**，此刻已被收入其在体内开辟出的**储物空间**中。
- **火焰烙印**：掐诀之下体外火焰扭曲化作七缕火龙，尽数没入左目，在**左目中化作一个一闪一闪的火焰烙印**，于漆黑洞府内极为显眼。
- **困境判断**（王林来仙罡大陆已一个多月的体悟）：
  - 自身火焰本源已**凝固**，比在**洞府界**时更浓；
  - 但与仙罡大陆天牛洲的**地火格格不入**，两种火焰必须决出主从；
  - 否则遇到同样拥有火焰本源者，会被一眼看出端倪；
  - 在洞府界他可艹控天地星空一切火、如同**火焰帝王**，一个呼吸即可补充；在仙罡大陆他与其火焰本源皆是**外来者**，大量补充极难，遇强者甚至会致命。
- **苍龙宗的试探**：先前在苍龙宗抽地火支脉魂看似从容，实则他本可不抽即能走出，之所以出手是**为试验此地地火的排斥程度**；结果排斥力极强，那地火魂离开苍龙宗后即欲反噬，被王林镇压后融入大地消失不见。
- **既定方针**：「既然这仙罡大陆的火焰不认同我，那么我也就不需让其认同，**镇压融合，壮大自身**就是。」

## 三、地底之战：朱雀吞龙

- **元神下地**：王林元神融入左目，化作一条火焰朱雀自左目冲出，瞬息钻入地面，深入大地。整个天牛洲地下遍布一条条**地火支脉**，山峰之下皆地火汹汹。
- **元神视角**：以元神入地，所见并非泥土，而是点点火光构成的**火焰世界**；炙热气息对寻常元神伤害极大，对王林却无碍。
- **遭遇矿脉之魂**：远处传来肉耳不可闻、元神却极清晰的咆哮，热浪蕴含可融法宝、焚元神的高温。王林所化朱雀以朱雀之鸣如利剑回应，直扑根源，见到一条**身长数万丈、赤红暴躁的火龙**——神识所见为火龙，肉眼所见则是一条蔓延不知多远、赤红高温、藏于地底泥土中的**巨大火焰矿脉**，即此地**地火分支矿脉之魂**；同理，肉眼亦看不到王林所化朱雀，只见一片与此地格格不入的另一种火焰。
- **火之道理**（本章设定点睛）：「这天地间，只有一个字，叫做**火**」——炎、焰皆可在某些时候代表火，却永远不能在文字上用「火」字；**火是霸道的，是不能共存的，是只能融合归一的**。
- **反吞噬**：火龙火海扩张、张口欲吞，王林所化朱雀毫不退缩（区区地火支脉之魂没有资格让他退缩），顺其口冲入体内。王林神识带着火焰的霸道回荡地底：「这天地一切火，要听我王林号令，要拜我王林为主，就算是仙罡大陆的火焰，也同样要如此。」
- **同化过程**：火龙痛苦扭曲，体内散出的火焰慢慢凝成闭目的巨大朱雀虚影将其笼罩，由模糊转清晰，边吸收火龙火焰边壮大自身；火龙咆哮渐弱而挣扎渐烈。
- **地表异象**：王林所在十万大山地动山摇、轰隆巨响，地面起伏出现巨大裂缝，地火喷出焚烧一切；**约一炷香后**地火收缩、顺裂缝消散无影，地底火龙停止挣扎，被清晰的朱雀掩住，朱雀猛睁双目露出寒芒。
- **收功**：朱雀化火海上冲，回到洞府冲入王林左目，王林全身一震、元神入体睁眼——「**吸收了一条地火支脉的魂，我的火焰本源居然壮大了这么多**」「这对我来说，是**罕见的大补**」。
