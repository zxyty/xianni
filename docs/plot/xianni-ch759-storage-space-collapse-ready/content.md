# 第七卷 名震罗天 · 第759章 准确就绪

## 一、庙宇二层：仙人遗迹的最后线索
- 王林执画笔闭目良久，右手依字迹在纸上虚写，渐渐捕捉到当年那位仙人坐于此处时的感觉。
- 心神在书写中焦急起来——彷徨与迷茫交错，是至今仍滞留于房间内的气息。
- 王林停笔望向窗外，判断：**仙人刚刚画完却更为迷茫，留下此话后生了变故，应该是有人来访**。
- 摸索出迹象后，王林一挥手焚毁纸张，收起镇尺下楼。
- 看到纸上内容后，他对**仙界的崩溃**有了更多谜团；结合第二个山谷，判断此地即便有残留之物也很有限——因为最重要的法宝**兽骨**已被他取走。
- 王林认定：这兽骨就是那仙人所说**正在祭炼中的破损法宝**。

## 二、与李元的分工与告别
### 1. 一个月的布置
- 李元取走第一层的画收入储物袋。王林叮嘱：**此画务必小心存放，莫让外人看到，否则将引起大祸**。李元若有所思点头。
- 李元提议王林再找找法宝玉简，王林摇头婉拒，让李元自行寻找。
- 李元的三件事：布置崩溃禁制、搜寻残留、寻找/连接离开此地的出口。
- 王林则盘膝庙外，取出储物袋中**九个兽骨**研究，转眼一月。
- 李元一月收获不多，但**掌握了当初进攻王林的八把短剑**（方法不明），王林颇为吃惊，联想其禁制便有所悟。

### 2. 破灭禁与禁制球
- 李元在储物空间推算出**全部崩溃点共 1465 个**，尽数设下禁制。
- 交付一枚**水晶般的禁制球**：王林仙力一吐即可引爆全部禁制，一瞬间令储物空间彻底崩溃。王林神识扫过确认无误，抱拳致谢。
- 李元对算计血祖的劲头甚至比王林更浓——**一想到在自己禁制帮助下有机会弑仙便呼吸急促**；其弱点即对自家禁制的盲目自信。

### 3. 李元的决断与馈赠
- 考虑到血祖万一不死的后果，李元决定：**只暗中帮助，绝不参与其内**，布置完成即与王林分开——即便王林于他有恩。
- 备选方案：李元提出可让王林藏于一处洞府、不外出直至血祖遗忘仇恨。王林淡笑心领，言若最终实在无法对抗再来相扰。
- 赠礼：记录**李家破灭禁**的玉简。虽不入其传承祠堂无法分心禁，但研究有助于禁制，其中尤有**数种隐藏气息之法**。
- 离别：李元掐诀开出一座**不稳定、只能开启三次的传送阵**，踏入前叹道「若李某没有牵挂，定会留下，见证我李家禁制下，如何算计了一位**净涅修士**」，随后消失。

## 三、王林的收尾与决意
- 目标宣言：「血祖、姚惜雪，即便你们有**血魂丹**，在这储物空间的崩溃下，那毁灭一切的力量之中，我王林便赌一次，你们能否完整的复活。」
- **姚惜雪的储物袋**：王林身上有一个来自姚惜雪的储物袋，**打不开**，只能施加禁制封印使其内烙印气息不外散太远。
- **血魂丹存量推断**：王林原有一粒真药，已在**妖灵之地与散魔一战**中用出；他明知姚惜雪储物袋内必还有真血魂丹却无法取出。判断这种逆天之药即便血祖也不可能多，加上多年消耗，**至多一两粒**。
- **处置姚惜雪**：取出禁锢姚惜雪的禁制球，已无继续询问的兴趣，右手一抛将其深深打进远处山脉之内。
- 收束：王林踏入传送阵，与阵法光芒一同消失，自语「血祖，既然你不会放过王某，那么王某便来一次李元口中的**弑仙**」。

## 四、要点与伏笔
- 兽骨（九个）为此地最重要的收获，其性质=仙人祭炼中的破损法宝，待后续祭炼。
- 储物空间已成一枚可引爆的「陷阱」，引爆开关在王林手中（禁制球）。
- 李元退场：暗助已是极限，未来若需藏身仍是可求之人。
- 姚惜雪被弃于崩溃将至的储物空间山脉内，其打不开的储物袋（内有真血魂丹）仍在王林身上，是后续变数。

> 注：本片段中王林以自创化名「许木」行事（李元称其「许兄」），所有言行归属王林本人。
