# 第615章 贪狼的去向

## 一、亥猪的下场与情报榨取

- 前章被王林砍下头颅的中年男子（大罗剑宗）名为**亥猪**，修为**婴变后期**。王林以**问鼎**修为封印其元神，「毫不费力」。
- 王林提头而走，如清风吹扫，转眼失踪；奔走间未回头看那千万妖兵一眼，踏空而去。
- **妖帝的玉简**王林没有收走——他认为此物于己无用，当初接下只是因为那是妖帝表达善意之物，不接反显跋扈。
- 处置：亥猪头颅被王林**炼化**，剑气吞入体内；对亥猪元神施展**搜魂术**，取得所需信息后，元神几近崩溃，被直接扔入**魂幡**内，化为一个**主魂**。

## 二、核心情报：贪狼

- 大罗剑宗之人在妖灵之地，除各自持有**凌天候剑气**外，还有一名叫**贪狼**的人在暗中保护。
- 王林自忖「贪狼」这名字如此特殊，应未听说过；但亥猪记忆中贪狼的**相貌有些眼熟**——而他可以肯定**绝未见过此人**。
- 修为：按亥猪记忆，贪狼**已超过问鼎，达到阴虚之境**，比之**司徒南的阳实之境**只差一步。

## 三、由「司徒南」引出的旧账与天逆珠之忧

- 一想到司徒南，王林身子蓦然一震、停在半空。他拍开储物袋取出一枚玉简，神识一扫后**面色难看**。
- 该玉简为**当年司徒南所赠**，内有司徒南印下的几张画像，画中人正是**当年害司徒南肉身崩溃者**。赠简时司徒南并不指望王林真会遇到，只是让他记住：这些人，不要招惹。
- 王林亦未想到自己真能遇上画中人——修士改换相貌极为简单，仅凭画像寻人难度不次于大海捞针。
- 推论：**若贪狼真是司徒南当年的仇家，他必定知晓天逆珠之事**。而天逆珠是王林最大的秘密。

### 天逆珠现状（本章自述）

| 项 | 内容 |
|---|---|
| 相伴时长 | 已随王林**七百多年** |
| 属性进度 | 当年仅一些雨水便使**水属性大圆满**；此后越来越难，如今**只剩金属性未圆满** |
| 王林预感 | 最后一个属性的难度「怕是达到了一个令人发指的高度」 |
| 分离性 | 珠子**已与元神融合，根本无法分离**；除非抽出元神、如炼化凌天候剑气一般炼化，方能自元神内炼出 |
| 神通评价 | 除**内部时间可逆变**外几乎别无神通；藏身其内若遇大神通者仍会被察觉，无法遁形 |
| 结论 | 「怎么看都是**鸡肋**一般之物」；时间逆变对低阶修士效果极大，对高阶修士**还不如足量的仙玉**有吸引力 |

- 悬念：这天逆珠到底是什么来历？为何**修真联盟**会对这珠子如此在意？

## 四、大罗剑宗在两郡的动向推演

- 天妖郡内大罗剑宗弟子**原本五人，以辰龙为首**。
- **末羊**死后，众人虽未确定，但多少对王林产生怀疑；按大罗剑宗行事方式本应立刻派人询问，**但他们并未行动**——反常。
- 亥猪记忆显示：当时**贪狼在火妖郡**，好似**发现了什么隐秘之处**。十年过去，天妖郡内只留下亥猪，其余三人已**陆续赴火妖郡与贪狼会合**。
- 由此回推：当初**子鼠**也一定是去会合，半路上却因对王林产生杀机而身亡。
- 王林之问：「这贪狼，到底发现了什么？」

## 五、王林的决断

1. **暂停搜集凌天候剑气**——有贪狼在，没了继续搜集的机会；「此事却也急不得」，嘴角露出冷笑。
2. **主攻杀戮之气**——眼下这场战争是搜集杀戮之气的最佳时机，不能放过；但自忖一人之力有限，心中已有安排（「此事应该这么做」），眼中寒芒一闪，身影消失。
3. **不参与火妖郡大战**——一路大挪移，数日后返回天妖郡内的**炼魂部落**。

## 六、炼魂部落现状

- 经十多年发展，炼魂部落势力已初具规模，成为**天妖蛮荒之地内四个最大的部落之一**。
- 王林归来使整个部落沸腾。许多族人虽未见过王林，却在口口相传下把他视为**与古妖一般的存在**，无不膜拜；他所居的**那处山谷**更被奉为**圣地**。

## 七、留待后续的伏笔

- 贪狼在火妖郡发现的「隐秘之处」为何？
- 贪狼是否即司徒南画像中的仇家？其是否知晓天逆珠？
- 天逆珠的真实来历，以及修真联盟对其在意的原因。
- 天逆珠金属性圆满之法。
- 王林借战争大规模搜集杀戮之气的具体手段（「一人之力有限」，暗示将驱使部落/他人）。

# 以杀养杀：炼魂部落十万杀戮之气布局与塔中十年

## 一、杀戮之气：第一波一万人
王林回归后，立刻召集**十三**与**欧阳华**，挑选出上万族人，逐一送出一道**杀戮之气**。

机制要点：
- 杀戮之气驻于族人体内，凡其所杀之人的**生机**皆被吸入杀戮之气中。
- 杀戮越多，体内杀戮之气越强大。
- 危机之际，杀戮之气可**自动转化为生之烙印**，保护宿主安全。

这一万人被派入**火妖郡**战场。王林特意**不让他们加入天妖军**，而是散开各自发展；唯一要求：不断以杀戮壮养体内杀戮之气。

王林自知一万人在数千万妖兵参战的大战中微不足道，故另作安排。

## 二、三个月吞并三部落
王林给十三与欧阳华各送出法宝，限期**三个月**，令二人率余下族人吞噬天妖郡内**另外三个部落**。

三个月后：
- 三部落被一一吞噬，大量外族之人被喝下**妖汤**，成为**炼魂部落**一员。
- 对未修炼**炼魂术**的新族人，王林取出**尊魂幡**一抖，放出大量魂魄，在其操控下逐一进入新族人体内——不伤其魂魄，而取**共存**之法。
- 王林再散出杀戮之气分别融入这些人体内，**第二波三万人大军**随即派入火妖郡。

## 三、举族迁徙：远古战场立新塔
王林施展**大挪移之术**，多次往返，将炼魂部落所有人从**蛮荒**全部迁走。

迁往地点：**散魔当年所在的远古战场**。在当初**魔塔**之处，王林以神通凝化出一座**高塔**，盘膝其内；族人在此营建大量简单屋舍，繁衍生息，很快形成一个新的部落。

十年后的格局：塔外方圆十里空白地，向外屋舍建筑密密麻麻绵延**数百里**，即**新炼魂部落**。每个月都有族人带着大量火妖郡部落俘虏回归，部落规模月月壮大。

## 四、塔中十年
王林十年未出塔半步，日常三事：
1. 盘膝**吐纳**——使**问鼎初期**修为更加稳固；
2. 于**元神**上不断**刻画/加深散魔烙印**；
3. 以余下时间**修炼禁幡**。

目的明确：在**百年期限**之前令自身实力更强，唯有如此才能完成与**古妖**的约定。

同期战局：天妖郡**三路大军**杀入火妖郡境内，火妖郡自有对应之策，各处战场厮杀不断。十年之战，只是刚刚开始。火妖郡内的蛮荒部落，则始终是炼魂部落外浸吞并的目标。

## 五、十万杀戮之气
十年间陆续有族人携杀戮之气加入战场。杀戮之气虽有消散，但每日更多的是成长。至此，王林散出的杀戮之气总数已达**十万**，融入十万族人体内不断壮大。

王林塔中睁目，目光如电似奔雷，浩荡之力自塔中扩散：
> “以杀养杀，这场战争之后，我倒要看看，一道杀戮之气，可以分成几道。”

## 六、再问姚惜雪
王林一拍**储物袋**，取出封印**姚惜雪**的**禁制之球**，右手虚空一捏，球碎，姚惜雪现身塔中。

- 姚惜雪已换上一套**蓝色衣衫**。
- 王林神态冷漠：“你，思考的怎么样了。”
- 姚惜雪美眸瞪视、咬牙反问：“你的心里，到底在想些什么，这十年，该说的我已经都告诉你了，你还想怎么样。”

## 七、时间线
- 王林归来 → 分发第一波一万道杀戮之气，派入火妖郡。
- 三个月：十三、欧阳华吞并另外三部落 → 第二波三万人大军派出。
- 大挪移举族迁至远古战场魔塔旧址，凝化高塔。
- 闭关十年：稳固问鼎初期、加深散魔烙印、修炼禁幡；杀戮之气累积至十万。
- 十年期满出关（未离塔），唤出姚惜雪问话。
