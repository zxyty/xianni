# 第1321章 第三步的隔膜

> 第九卷 云海之巅。承第1320章明悟翻天印之后。

## 一、时序与环境：蓝丝族修真星的雨季与冬

- 蓝丝族所在星域，其上修真星大都有梅雨季节，雨季往往持续半年方止。
- 王林感悟神通的这颗修真星，在近七个月雨季后迎来冬天：大地刚湿透即被雪与寒气冰封，寒气顺双脚钻体，血液流转都为之缓慢。
- 凡人已习惯此气候，且有蓝丝族修士年年相助，并不艰辛；一些粮食反在冬季生长，越冷收成越好。
- 王林盘坐山巅为雪所覆，半空的冰剑与漩涡小球始终漂浮，雪一近即被绕开。

## 二、第二式神通·光影盾：从推衍不得到万物之光

### 困局
- 明悟翻天印后，王林又在此峰滞留四个月，直至入冬。
- 光影盾中蕴含的「凝聚光芒之力」极为模糊，反复推衍不得头绪，蓝梦道尊施展的一幕幕在脑中回荡。
- 关键自问：「我残夜之中也有光、有初之规则，只是那种光是从骄阳上散出；而蓝梦道尊的神通与初之规则没有任何联系，凝聚的是这天地万物、一切生灵的光——这种光到底是什么？」

### 观照：以神识化身千万
王林神识以山峰为中心弥漫全星，好似化身千万走向四面八方，所见依次为：
- 白色山峰、积雪大地、冰封河流、浮冰之海；
- 凡人都城、屋舍灯火与火炉旁的温馨人生；
- 富贵者的锦衣玉食、皇族奢华、蓝丝族修士奏出的美妙音律；
- 飘雪、冰下喜寒游鱼、寒地冬生植被；
- 朦胧天地中的无尽星空、寒风、雪的晶莹；
- 冬季颤抖的小兽与冻死的枯骨。

整颗修真星尽入其心神，他默默望、默默观察、默默成为天地的一部分，直至冬去雪融。

### 见光
- 先从凡间一个三口之家的亲情中，看到一种温暖之光——很弱，风一吹似要暗去，却真实存在。
- 继而从恩爱之人、富贵之人身上见光；连死去的骸骨身上也有光，那光透出悲哀、不甘与挣扎；小兽身上亦有光。
- 万物生灵——山、河、海、大地、天空、万灵，乃至星空星光，皆散微光，星星之火燎原般弥漫其全部心神。

### 隔膜
- 睁眼刹那，四面八方之光疯狂来临环绕其身，大地、天空、草木、山河、星空乃至其所坐山峰皆散光芒，王林如化骄阳，外裹一个巨大光影。
- 眼中露出明悟，但明悟中仍有迷茫：「是生机么？」右手一挥，光影消散，一切恢复如常。
- 他始终未彻底明悟：**隐隐总有一股隔膜阻止其继续明悟，不破此膜便永远无法知晓。**
- **旁白点破（王林本人不知）：这隔膜正是修士通向第三步的大门；能感受到者极为少见，感受到后有生之年能打破者更是凤毛麟角。**
- 由此可见，蓝梦道尊传授的三大神通自有其深意。

## 三、第三式·道术：漩涡小球的传承

### 得授
- 漩涡小球是蓝梦道尊以道术融合、凝聚出的一种比「呼风唤雨」更强大的神通——化作一界；其中所载凝聚融合之力，即传给王林的道术。
- 王林两指持球凝望，眼中现出其**五道本源彼此循环**、在瞳孔内旋转；无形之气自球内散出直奔其双目，小球越来越小，数日后彻底消散。

### 道术之辨
- 神通、法术皆是**可说清、可道明、可化作形态**之术，攻守皆可见（如翻天印、光影盾）。
- 道术则**无形无影、说不清道不明**；「懂，就是懂了；不懂，一千年、一万年也不会懂」。
- 相比前两式神通，此道术于王林并不需太久明悟。

### 王林一生三次接触道术
| 次序 | 出处 | 内容 |
|---|---|---|
| 一 | 七彩界内那老者 | 「道消」之术，无法抵抗；若非极境与天逆，王林无法抵挡 |
| 二 | 封界之主相助下进入道境数年 | 自悟出属于自己的道术，难以说清且并不完整，可令道念化作诡异波纹伤敌于无形；妖宗裂缝战场外，妖宗长老皆在不知不觉中受创 |
| 三 | 本章·蓝梦道尊所授 | 心神沉浸奇异状态，隐隐有了**可把任何神通、任何物质改变**的意识 |

### 验证：冰剑化云
王林虚空一抓取来冰剑，闭目而感——手中握的不是剑，而是一片云。于是冰晶咔咔生裂、砰然爆开→旋转中诡异融化为雨水→雨水成漩涡急旋而散为雾气→雾气如小型风暴呼啸后消失→化作一片白云。他托云前挥，白云升空远去；王林睁眼含笑。

## 四、王林的后续计划（本章明确列出）

1. **融合缩地成寸**：缩地成寸虽可瞬息无尽星空，却有致命缺陷——天地元力一旦被搅乱便无法施展。用道术融合改造之，方能彻底甩开在蓝丝族外停留的**白衣女子**，从而在太古星辰内叱咤。
2. **大成五道本源**：吸收足够香火；**火雀族之火、闪雷族之雷**皆是本源大成的养分。
3. **探究印记之秘**：太古星辰之民眉心的印记颇有诡秘之处，似乎相互之间可以吞噬，不断向着某种完美进化。
4. **查掌尊来历**：最想知道那**擅使阴谋的掌尊**属于太古哪一族——答案将从其储物空间内的**月噬族白发长老元神**中寻找。
