# 第七卷 名震罗天 第678章 来临

## 一、柳眉降临冉云星：万幻天魔道的第二步

- 柳眉自天空如仙子般走来，声音如天籁仙曲，直接融入敌方心神。逍遥散人与孙析战意瞬间消散、陷入挣扎。
- 只有修为达**问鼎中期**的冉家老祖勉强保持心神不乱，但无法维持太久——他感觉柳眉之声勾起了「凡人时的涟漪」。
- 冉家老祖施展「**千幻无情道**」，元神与天地元气结合迸发火焰，修为突飞猛进，大喝如奔雷震动天地，才使孙析短暂恢复清明。孙析惊骇于自己方才竟对柳眉生出「面对至亲族人」般不忍出手之感。
- 柳眉劝降：「你三人，不是我的对手，与我一同回到幻家，或许还有一线生机。」

### 万幻天魔道的本质
- **世间万物，皆可被其所用**——柳眉不需带任何人助战，只要她在，便有无尽修士为她而战。
- 幻家老祖当初毫不犹豫给柳眉**换血**，正是想知道万幻天魔道**达到第二步**后究竟具备何种威力。

## 二、同门相残：三名问鼎修士的覆灭

1. **冉家老祖出手**：双手结印、一掌按虚空，施展冉家神通「**掌心雷**」轰向柳眉。柳眉婉了一下发丝，玉手向前一点，指尖触雷，雷即消散，并轻声道：「燃烧元神，那就燃烧的彻底一些吧。」
2. **逍遥散人倒戈**：眼中痴迷转为狂热，眼里天地尽失只剩柳眉身影，径直挡在冉家老祖身前，**同时燃烧元神与肉身**。
3. **孙析倒戈**：被柳眉一眼看破心防，同样燃烧元神与肉身，双指成剑自冉家老祖身后刺去。
4. 冉家老祖惨笑：「**赵传文、孙析**，冉某为你二人感到悲哀」——由此点明逍遥散人本名赵传文。二人置若罔闻，肉身飞快消散、修为却随之攀升，与冉家老祖死斗。
5. **冉家老祖亦自燃**：绝望之下同燃元神与肉身，修为疯狂攀升至**问鼎后期**，但因提升过快意境跟不上，只是「没有意境的伪后期」。他不施神通，直接将元神内天地元气化作金芒，如万丈利剑向四面八方咆哮而出。
6. **双双自爆**：孙析与逍遥散人肉身只剩半截时选择最终自爆。问鼎修士在燃尽元神肉身、燃尽在世间一切痕迹的状态下自爆，威力使**整个冉云星陷入浩劫**——天空似崩、大地翻滚、海洋齐齐拔高百丈拍向大地、星内灵脉在元力引动下齐齐爆开。二人至死未曾清醒。

## 三、冉学风之死：诅咒与遗言

- 冉家老祖处于自爆中心，凭修为硬抗但全身鲜血淋漓，怒斥柳眉：「好恶毒的贱人，你我之战，为何要波及凡人，波及这冉云星」
- 柳眉答：「我可曾出过手你们三人彼此争斗，与我又有什么关联呢」
- 冉学风仰天大笑、眼角落泪，见冉云星处处废墟——他明白若自己再自爆伤敌，冉云星将彻底沦为**废弃的修真星**。
- **临终三事**（自报姓名「冉学风」）：
  1. **诅咒**：「我冉学风以此刻的修为诅咒，你，将会死无葬身之地」
  2. **供出许木**：「杀死幻东者，并非是我三人，还有一人叫做**许木**」（按世界状态，许木即王林此期间所用化名）
  3. **自尽护星**：右手拍额，元神崩溃波及肉身，在柳眉平静注视下化为尘埃落地。留言：「生在冉云，死在冉云……我冉学风死前能做的，便是尽最大的可能，保护冉云星。还有许木，你这个小人，老夫诅咒你与这幻眉同归于尽」

## 四、柳眉的后续目标

- 自语：「**冉家、赵家、孙家，却是要灭族的，这是师尊的要求，与我无关。还有那许木，此人倒是有些陌生**」——灭族令出自其师尊（幻家老祖）。
- 神识散开，在**冉云星极南**停留，察觉「**还有一具分身**」，并推断：既然许姓修士有分身，冉家老祖与赵姓修士恐怕也定然有分身。
- 该分身隐藏极隐蔽，柳眉之所以能找到，是因为**本尊死亡之时分身传出了一丝波动**；平日神识一扫并不会注意。

## 五、三人的保命分身（背景交代）

- **起因**：四年前三人知道闯下大祸（杀幻东）后，纷纷展开一切手段祭炼分身。虽无特殊功法、分身极弱无法助战，但总归是保命手段。
- **冉家老祖**：分身早在数百年前便偷偷祭炼，已达可进入星空的标准，**两年前已随族人一同离开**冉云星。
- **逍遥散人（赵传文）**：功法有缺陷、元神无法分化，分身始终炼不出，但**另有手段，不为外人知晓**。
- **孙析**：分身炼出但只有**结丹修为**，无法走出星空，此刻盘膝坐在冉云星极南一处城池的民房中，面露苦涩。
  - 孙析此前**寻找王林所求之事，正是有关这分身**，但还未开口就被王林拒绝。
  - 他犹豫后没再开口：一旦让许木（王林）知晓三人各有保命手段、拉他入伙只是为了**替罪**、以免外人怀疑有分身存在，恐怕给再多**仙玉**许木也不会答应，甚至可能一怒之下反过来对三人出手。

## 六、王林来临

- 王林**收了冉家老祖三人的仙玉，便要尽心意**，否则大可不必回来。
- 一道银虹贯空，王林**盘膝坐在星罗盘上**抵达冉云星外，发现星外**充满了一层厉害的禁制**（「我离开之时，没有这禁制」）。
- 王林对禁制了解极多：虽无法短时间彻底破解，但**无损进入可以做到**。星罗盘银芒一闪，冲入禁制、穿透后直奔冉云星。
- 柳眉在星内抬头，眼中奇异之芒更浓，眉头紧皱：「**这气息，有些熟悉**」——双方即将正面相遇。

## 七、关键伏笔
- 冉学风的临终诅咒指向柳眉与「许木」（王林）**同归于尽**。
- 孙析的结丹分身尚存于极南，正处柳眉搜寻与王林降临的交汇点。
- 柳眉对王林气息的「熟悉」感，暗示与其过往（换血前的柳眉身份）存在关联。
