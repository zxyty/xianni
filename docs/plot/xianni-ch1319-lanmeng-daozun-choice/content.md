# 第1319章 抉择

## 一、场景
山峰之顶，蓝梦道尊背手而立，等待王林答复。文中以极致笔法状其威压：山峰在其面前如消失，修真星一切气息皆隐，天地为之低矮；立于星空则星空光芒避让——「他，就是山，就是天，就是星空」。

## 二、蓝梦道尊开出的筹码（层层加码）
1. **法术传承**：一生法术大都自创——九式神通、六式仙法、三式道术，更有**一式生死**，可全部传授。
2. **香火与感悟**：两千亿门徒香火，外加一身**对空之境的感悟**。
3. **道器**：五把以**天外陨石**炼成的道器，即便**掌尊**也忌惮不已，五把齐出则天崩地裂。
4. **道统**：一身**第三步道统**，至今未有任何传人。
5. **游历太古**：可带王林游历太古，从其余四尊处换来**道灵**，成就无上神通。
6. **古之墓地**：可为其破开虚无，前往传说中埋葬**古**的墓地，助其吸收**古魂**，令**古神之体**大成。
7. **本源**：王林体内有**五道本源**（古往今来从未听闻有人诞生五道本源），可一一助其大成；再继承其道统，则拥有**七道本源**。
8. **庇护**：蓝丝族外的危机（那来历极大的女子）由蓝梦道尊一人扛下。

王林反应逐级升级：沉默 → 呼吸急促 → 眼中光芒骤闪、呼吸粗重 → 双眼露出血丝。文本明言：**他，极为动心**。

## 三、两个条件
- **其一（叛界内）**：从此不再是界内之人，而是**太古星辰蓝丝族少宗**；服下**忘心果**，发下**本源誓言**，脱离界内。界内界外之战可不参与，但也不能再帮界内。
- **其二（绝情缘）**：了结界内一切情感牵挂；蓝梦道尊只有一女，王林与她结双修，一生只能有她一人。

## 四、王林的拒绝与反诘
- 拒绝理由（内心）：他生于界内、长于界内，答应即等同**叛国**；仙人在**封界大阵**死亡时的话语、**封界之主**不惜牺牲所做之事，在其心神中回荡。第二条放弃**李慕婉**，等于放弃道、放弃一生追求与承诺。
- 明言：「我，可以不要，不学。」
- 反诘蓝梦道尊：前辈一生可有比自己生命还重要之人？（答：有。）若换作是你，放弃那重要之人换无上修为，且再放弃整个蓝丝族，你可同意？——蓝梦道尊未答。
- 旁白伏笔：多年前**雨界青霖**也承受过同样的天大诱惑，只是诱惑青霖的是**掌尊**。

## 五、蓝梦道尊透露的设定（重要）
### 修道第三步：空之四境
| 层次 | 定位 |
|---|---|
| 空涅 | 最初 |
| 空灵 | 门槛 |
| 空玄 | 大道 |
| 空劫 | 巅峰 |

- 古往今来只听说有人达到**空劫后期大圆满**，但从未听闻有人**渡劫成功**。
- 传说中的**第四步：踏天**，从无一人达到，连**远古仙域八妃**也未达到。

### 蓝梦道尊自身修为
- 体内**两道本源**：一道达**空玄中期**，另一道被其**封印**、无限接近**空劫初期**；两道融合可发挥**空玄之境巅峰之力**。
- 界外与他同等层次者：**不算远古八妃，至少有七人**。

### 界内界外格局
- 界内**没有香火**，被**封界大阵**围困万万年。
- **掌尊擅使阴谋**，在界内埋下大量界外之种，界内几乎分崩离析。
- 界外不发动直接大战、而以**岁月之力**慢慢瓦解界内的原因：界内确有让界外极为顾忌的存在——**当年一吼之力，可让掌尊仓皇而逃**。（王林原本只是猜测，得证后心神一震。）

## 六、传授三式神通
蓝梦道尊因王林送其女（月儿）至此，不论之前因果；道统香火无法给，改传三式神通，「能学多少，就看你自身悟性」。

### 第一式：翻天印（攻）
- 抬手向天一抓，风云倒卷，天空弥漫无尽蓝芒，凝出巨大漩涡；天地之力四方汇聚，化作一尊由**元气**组成的巨大**帝王之印**。
- 一印落下，**天地逆转**：天变成地、地变成天，王林所在山峰完全倒立成巨锥，却无一石落下。
- 释义：「翻天为地，这大地成为了天，便是这世间最强之印。」右手下挥，成为天的大地便直砸下方天空。
- 施展要诀：**若在星空施展，你需心存天地**。威力评价：放在星空足以**屠灭万灵**。
- 收招时天地轰鸣如时光倒流，瞬间恢复如常。

### 第二式：光之防御术（防）
- 立论：「这天地星空宇宙全部，存在最多之物，就是**光**——光无处不在，处处都在。」
- 效果：天地间草木、生灵、屋舍，乃至天空之外的星空，一切存在之物尽放光芒；蓝梦道尊成为天地光之源泉，光芒刺目至王林亦难睁眼；其身外浮现一尊**与天地齐高的光芒巨大虚影**。
- 来历：并非道术，乃蓝梦道尊**达到空灵境界时**所悟；学会后「在这太古星辰，自保有余」。

### 第三式（本章仅预告）
- 乃蓝梦道尊修为在**空灵巅峰**时明悟，为其**此生三大道术之一**。
