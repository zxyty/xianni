# 第1337章 闪雷族的隐秘（第九卷 云海之巅·第四更）

> 归属须知：本章中的「于非」为王林以一部分元神夺舍于非之身后冒用的身份（自第1242/1329章起，潜入闪雷族）。本章「于非」的一切言行归属【王林】。

## 一、雷晶殿东门：踏入闪雷榜

- 王林收起从池中飞出的玉简正欲离去，池旁盘膝的三老之一开口确认其身份：「你就是于非」。
- 老者评价：能在其威压下保持镇静，是心念坚定之人；累计数年而在今日才一次性全部换取雷晶，是心思深沉之辈。
- 结论：王林**有资格进入西门**接取族中任务——只有低阶修士才以资源换雷晶，进入闪雷榜后做族中任务所得雷晶更多。

## 二、三份见面礼（东门惯例：遇新入闪雷榜者须赠造化）

| 赠者 | 礼物 | 说明 |
|---|---|---|
| 老者甲 | **聚雷丸** | 亲自炼化，压缩了 8900 倍，拇指大小雷球，赠以防身 |
| 老者乙 | **闪雷族功法玉简** | 「对我虽无用，你修炼之下却可开启族印更多」 |
| 老者丙（阳实修为） | **一句话 + 雷光玉简** | 「去西门，选念雷任务」——最快获取雷晶之法；持其玉简可顺利接过此任务 |

## 三、闪雷族的隐秘：雷之六道

闪雷族历代先祖研究雷霆之道，至今发现天地间共有六种雷霆，若全部吸收炼化，可拥有神鬼莫测的雷霆之力：

1. 天酝之雷
2. 地融之雷
3. 元化之雷
4. 磁含之雷
5. 道意之雷
6. **灵念之雷**（即「念雷」）

老者点明：让其接任务不仅为换取雷晶，**更重要的是接触雷之六道**。

## 四、王林的判断

- 「念雷」一词在其**吞噬与搜索过的闪雷族族人记忆中并未出现**——属闪雷榜以上层级才知的隐秘。
- 自评：闪雷族**操控**雷霆不如自己，但对雷的**研究**已登峰造极。
- 对「灵念之雷」生出强烈好奇，艺高人胆大，**临时改变原定去南门的路线，转向西门**。
- 出东门时门外修士议论纷纷，所谈尽是「于非」二字，王林神色如常穿行而过。

## 五、雷晶殿西门：任务之地

- 门外修士极为稀少、一片空旷；偶有人从内走出，神色虽如常却蕴含沮丧（未接到满意任务）。
- 一步跨过西门，进入一处**如虚无般的广大空间**：四周弥漫雷霆闪电、隐有轰鸣，但大部分声音被隔绝，雷声听来遥远。
- **六名阴虚阳实修为老者**盘膝坐于六个角落，目光冷漠，负责此地。
- 半空漂浮**上百枚青光玉简**，即任务本体；光弱者柔和、光强者刺目。

### 任务规则

- 玉简**光芒越亮 → 难度越高 → 所得雷晶越多**。
- 任务种类：离开闪雷族追杀某修、采集极为独特的材料等，种种均有。

### 在场人物

- 十余名修士抬头放开神识逐一扫过玉简。
- **黑魔法王**赫然在内。
- **周天子**（此前在裂缝外极受尊重者）神色平静不露喜怒，盯着一枚**光芒最强**的玉简沉吟。
- 王林进入未引起任何人注意，神识不引人留意地散开摸清全场。

## 六、章末悬念

王林最后的目光落在一枚散发刺目光芒的玉简上——**恰恰正是周天子所看的那一枚**。

## 一、任务玉简：一条「天道」差事

王林（此时以夺舍所得之「于非」身份潜伏闪雷族）在雷晶殿见到一枚任务玉简，内容为：

- 「前往七百万天地，化作天道，降临天劫」
- 「降临天劫，惩罚七百万个天地内，修炼至化神巅峰、欲破开天地飞升仙界之修，搜集灵念之雷」

初时不以为意，细看之下心神震撼，掀起轩然大浪。

## 二、七百万天地的来历

- 闪雷族内有一处地方，由闪雷族先祖布置：此人号称古往今来闪雷族第一强者，第三步大能，带领闪雷族步入巅峰，更有幸把族宗至宝融入封界大阵。
- 并非其独自布置，而是在**一些神秘修士**的帮助下完成。
- 后人称之为「七百万天地」——其内有七百万个天地，如同七百万个世界，无数生灵同样修仙。

## 三、真相：一座信仰养殖场

1. **伪造的仙界**：七百万天地的生灵无数万年来始终认为有仙界存在——「或者说是有人让他们认为」——而这个仙界，就是闪雷族。
2. **修为封顶**：在闪雷族眼中这些生灵是蝼蚁；因某些特殊原因，绝不允许出现高阶修士。一旦有人达到化神巅峰，便有「天道」出现，降下雷霆将其毁灭。
3. **收割灵念之雷**：部分修士天资惊人或因特别原因，体内诞生一股奇异力量；此力在天劫降临下异变，凝聚出闪雷族**雷之六道**中的**灵念之雷**。
4. **传说与真相的反差**：凡能凝聚灵念之雷者，均被本世界传为「渡劫成功、进入仙界」，留下无数佳话、被后人歌颂敬仰、传承不断；真相是他们**形神俱灭**，成为闪雷族的灵念之雷。
5. **天道即族人**：所谓天道、所谓降临天劫之仙，都是闪雷族族人；对闪雷族而言，这不过是放在不同**雷晶殿**内的一个任务而已。

## 四、设定补注：飞升与「灵」

- 「灵念之雷」的「灵」代表**万灵**：天地间一切草木、凶兽、修士等生灵，皆可修炼神通。
- 常态法则：修为达化神巅峰即应飞升仙界成为仙人。王林早年在**朱雀星**即知此事——若非**雨仙界**崩溃，化神巅峰便可渡劫飞升。
- 由此推知：后来的**婴变期**实际上已属仙人一流，故婴变修士需要**仙玉**修行。

## 五、王林的震动与立志

- 踏入太古星辰以来，王林多次感受其强大，蓝梦道尊也曾点出，但直到此刻才真正体会「太古星辰之强」。
- 回忆：当年与**望月**之战，他在虚无中第一次看到的太古星辰之人，就自称「天道」。
- 感慨：区区一个闪雷族，只是太古星辰种族之一，竟有如此秘密、如此大手笔；他承认自己**小看了闪雷族**。
- 立志：「即便如此，这闪雷族的不灭之雷，我也一样要收，闪雷族，也一样要灭。」——一生逆境中攀升，朱雀子不行、天运子不行、修真联盟不行、罗天不行，就连水道子也一样不行。接触闪雷族与太古星辰隐秘，反而激起其不屈。

## 六、冲突：与周天子争玉简

- 王林决定取玉简一探灵念之雷究竟，右手抬起抓去。
- 一直沉吟的**周天子**同时下定决心，因距玉简更近（就在其下方）且出手更快，抢先抓到玉简。
- 周天子冷冷扫王林一眼，只说一个字：「滚」。神情冷漠，不需倨傲便有威压弥漫——这是身为**窥涅**修士万万人之上的傲然；在他眼中王林是挥手可死成百上千次、一指可捏碎的蝼蚁。
- 王林神色冰冷，眼中寒光微不可察一闪——**这是他要杀人的前兆**。伏笔已埋。
