# 第1934章 一男一女

## 一、断掌吞噬光幕

- 万丈光幕外，原本不断轰击的断掌**贴附于光幕之上**，形如海星，掌心奇异印记清晰展露于王林与海子天尊面前。
- 断掌随即**急速膨胀**：百丈→千丈→万丈，将整个半圆形光幕笼罩吞入。
- 光幕剧烈闪烁、回荡波纹，随后内部**彻底漆黑**，不见半点光明；二人以修为凝聚双目仍可视物。王林察觉自己头发无风自动、微微上浮（暗示移动/环境异常）。
- 海子天尊判断：「它吞了我玉简的防护光幕，正在快速移动。」并追问其为何物。
- 王林低头望着自己**新长出的右手**，答曰：**「山海树的封印」**。海子天尊面色苍白、苦笑盘坐。

## 二、被困之初的对话

- 王林身上**魂铠慢慢消散**，深深疲惫弥漫心神。
- 王林判断：断掌吞噬光幕后**阻隔了一切外在联系，如同封印**，海子天尊的师尊短时间内难以找到此处。
- 海子天尊质问：取山海树灵即可，为何还要去招惹当年**仙祖布置**的山海树封印。
- 王林回应：**「我若不是救你，此刻已经离开山海。」** 海子天尊沉默。

## 三、三个月至四个月：修炼与僵持

- 三天内二人无交谈；王林闭目打坐，取出所获山海树灵，**融一颗入体**。
- 海子天尊评点王林修为古怪：**明明只是空劫初期，却拥有天尊的战力**；并称山海树灵虽可助修士凝聚**实之本源中的木本源**，但空劫修士纵得再多本源也难修至大成。王林仅答「我与你不一样」，不作解释。
- 海子天尊因王林沉默寡言而气闷，退至数千丈外独处。
- **海龙 vs 章鱼海兽**：二兽不嘶吼，纯以目光对峙「相互咒骂」，一连四个月；海龙精神抖擞，章鱼海兽略显疲惫却毫不退缩。
- 四个月间王林一言不发，专注吸收山海树灵，**皮肤上慢慢浮现一抹绿意**。

## 四、时间流速之疑与久帝大天尊

海子天尊憔悴现身，忧虑师尊四个月仍未寻至。王林给出**三种可能**：

1. 断掌去了无人可察、推衍亦算不出的地方；
2. 其师尊并非如她所想会即刻来救；
3. **断掌体内时间流逝与外界不同**——此处数百年，外界或仅一天。

- 海子天尊否定前两条，并主动点明：**「你应该也猜到了，我师尊是久帝大天尊。」**
- 王林神色如常——他早前见海子天尊所取丹药上有「帝」字，又推知能收天尊为弟子者修为惊人，故推断为**中州**的**久帝大天尊**（大天尊中以「帝」为名者，除仙皇外即此人）。
- 结论落在第三种可能，海子天尊面色苍白，忧心**防护光幕维持不了数百年**。

## 五、幕外身影与光幕缩至百丈

- 交谈间光幕骤震轰鸣，由万丈**缩减为九千丈**。
- 幕外漆黑虚无中浮现一个模糊身影，凶残气息隐隐散出，喃喃：**「发现，非仙罡之灵，封印」**。
- 王林建议**将光幕缩至百丈**以延长抵抗时间。二人各自收走海龙与章鱼海兽，海子天尊掐诀将光幕由九千丈凝为百丈。
- 自此百丈之内，只剩王林与海子天尊**一男一女**。

## 六、一年之期

- 时间流逝，第四月、第六月……**一年过去**。
- 王林习惯孤独，一年内**融合两颗山海树灵**，五行本源中多出**木本源的萌芽**，正快速成长。
- 海子天尊沉默八个月后睁眼，对王林**既恨又复杂**，开口：「我修道至今，从未与陌生人，在百丈范围内，一住一年。你我只知道你叫做王林，还是当年你自己说的，你来自哪个宗门？」（章末悬念）
