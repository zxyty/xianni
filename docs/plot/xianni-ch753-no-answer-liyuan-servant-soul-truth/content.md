# 仙逆 第七卷 名震罗天 第753章 没有答案

## 场景
- 地点：雷之仙界内的仙人石像所在之地；王林身在山河（山河扇所化空间）内旁观。
- 承接：葛虹已死（第711章世界状态标注其死亡），其血化红焰。

## 一、石像异变
- 李元回头瞬间，石像之上红焰被石像**全部吸收**。
- 石像裂缝越来越多，裂缝内散出带**血腥味**的红芒（即葛虹之血），红芒仿佛蕴含强大气息，向前方铺展开的**画轴**凝聚。
- 石像**双眼下**同样出现众多裂缝，红芒透出时远看有种错觉——仿若这仙人石像留下了**两行血泪**。
- 李元怔怔望着石像，喃喃自语：“我我错了么”，眼中迷茫。

## 二、王林对李元的判断
- 李元本身只是**问鼎大圆满**，王林战之容易，**并不可怕**。
- 真正可怕的是李元体内一股**极强的气息**，来自其**奴印**；正因这气息，此人始终给人神秘感。
- 首次察觉时机：李元在石像下**道出因果**时突然**抽搐**、短短瞬间**全身湿透**——王林当时只记在心中。
- 明悟契机：**葛虹死前目光落在石像之上**，王林脑中电光划过，一举贯通。

## 三、王林推演出的“葛李两家”因果
1. **葛家是那仙人之后**。
2. **李家或许真的无辜**：因其先祖的一次**冒失**，整个家族衰败，成为世世代代的**奴仆**，贡献**寿元与修为**，缓缓使那**不灭的仙魂**慢慢恢复。
3. 李家历代或曾反抗，但每次都失败——直到**数万年前那位李家先祖**，此人给了李家希望。
4. 但**奴印经数万年积累**，在滋养其主的同时，隐藏其内的**仆魂**同样苏醒，于是有了那位“**李家天资绝伦之人**”。
5. 故：**明里解开李家奴印，实际上是复活其主**。

## 四、第一次轮回失败的真因（核心翻案）
- 王林**此前**以为：数万年前那次失败是**葛家之人**出了变故。
- **重新推断**：失败之因**不在他（葛家某人）、不在法器、不在葛家**，而在于——**那仙人石像的不愿**。仙人不愿以**断绝血脉**为代价复活被封印的魂。这，便是“果”。
- 由此定义此局的因果结构：
  - **因** = 仙人石像的复活；
  - **果** = 抽去其魂内那**抵抗的不愿**。

## 五、李元为何非找王林不可
- 对方准备本应充足，也不可能预先算到进入**雷之仙界**后会遇到王林。
- 关键：李元**看到王林与阴虚修士一战时使用的“因果之鞭”**——因果之鞭，抽的就是**因果**。
- 因此李元选择了王林。
- 风险评估：**仙人之魂岂能那么简单**，以因果之鞭抽之，恐怕**连王林自身也会陷入其内，生死未知**。
- 把握度对照：若无王林出现，李元凭第一次失败的经验也当有办法，但他自己也不确定能否成功——故此前说**七成把握**；有了因果之鞭则为**九成**。
- 附带猜测：**李元储物袋内说不定也有一件类似“因果意境”法器的宝物**。

## 六、葛家的角色：等待与献祭
- 复活仙人**绝非葛虹一人血脉就足够**——王林判断此刻**雷之仙界外的葛家**也正在进行某种**以死亡为代价的祭献**。
- 这解释了葛家自数万年前失败后：
  - 以各种方法**保留三件法器**；
  - **丝毫不隐藏**这个消息，反而换了一种说法让**全族之人皆知**。
- 目的：**等待李家奴印仆魂的第二次轮回**。
- 也因此，李元去葛家之后一切才会如此顺利。

## 七、李元“一魂两念”的结论
- 一路上李元对待葛虹的种种，前后多次给王林“**好似换了个人**”的感觉。
- 结合石像下道出因果时的异变，王林证实猜测：**真正的李元之魂并没有消亡，依然存在**。
- 精确表述：李元体内**只有一个魂**，但这魂内有**两种意念**——
  - 其一是**真正的李元**；
  - 其二是**奴印内的残魂（仆魂）**。
- 后果：两念**相互冲突**，导致**李家的禁制没有发挥出应有的全部威力**——每次施展禁制都会有些**崩溃**，**梅花十八禁**如此，**破灭禁化作的黑线**也如此。

## 八、收束：没有答案
- 王林身在山河内，盯着一脸茫然的李元，**没有说话**。
- 他觉得这李元**有些可怜**：他是一个**忠仆**，为让主人复活，可以不惜一切代价。
- 呼应意象：石像手印中虚幻画面里，**主人身亡，站在剑尖之上的仆从**，回头时那**悲伤茫然的双眼**。

## 归属说明（据世界状态须知）
- 本片段主角以「许木」之名行于雷之仙界，实为**王林**，本条目一律归于王林。
- 「李元」此身之言行，据王林推断为**真李元之魂与奴印仆魂两种意念共处一体**；本片段的迷茫自问倾向于真李元本我的一面。
- 葛虹已于第711章死亡，本章仅涉其血与死前一瞥的回溯。

# 第712章 石像崩碎、画轴自焚——李元执念坍塌与青烟仙剑

## 一、开场：剑柄空悬，李元跪问
- 剑柄之上的主人已经不再，世间仿佛只剩下仆从一人；站在剑尖无数年的等待、两次轮回之身的祭献，最终仍逃不出因果。
- 李元怔怔望着石像跪地，喃喃：「主人我我真的错了么」「为什么你不愿意苏醒我只是想，剑柄之上不再空，主人永远可以站在其上，我站在剑尖，为您征战天地」，眼中悲伤化不开。
- 石像裂缝越来越密，红芒浓郁，眼下血光凝聚如真的血泪。

## 二、王林的旁观与判定
- 王林（本片段以「许木」之名行走雷之仙界，参见世界状态须知；下同）站在山水之中默默观看。
- 与李元并无生死之仇，遂**收起了因果之鞭**。
- 内心断语：「因其极端的偏执，造成深深的迷失，此人信念在数万年前第一次失败后，便已经有了不稳，眼下这第二次，破损的信念，已然坍塌。」

## 三、红芒尽入画轴：石像失魂
- 石像连同石剑、剑尖仆从石像全部龟裂，红芒透出映照半个天空成霞光。
- 石像光芒缓缓延伸，被前方铺展开的画轴吸收；起初少，其后越来越多，最终红光连成一片急涌入画轴，无一外泄。
- 最后一道红光入画轴时，石像一颤，如同其内失去了魂，不再灵动，变得极为平凡。
- 李元呆滞的双目蓦然爆出兴奋精芒，唤「主人」。

## 四、画轴自焚与青烟化剑
- 吸满红光的画幕四周**全部边缘在同一时刻**燃起红焰，青烟飞向天空弥漫不散。
- 火焰由外缘向中间蔓延，画上踏剑柄的仙人似拥有魂魄，在火中忽明忽暗；最终整幅画轴化作尘埃，随风落下大地。
- 青烟不散，于半空飘摇化作一人形：相貌模糊不可辨；其脚下青烟化作一把剑的形状，此人所踏之处正是**剑柄**。剑柄旁一抹飘摇之烟晃动，分不清是剑穗还是青烟。

## 五、奴印归剑尖：仆从残魂随主而去
- 青烟人影升空之际侧身抬起右手，向地面的李元轻轻召唤。
- 李元身子一震，眉心浮现复杂印记——正是**奴印**；此印闪烁中脱离额头，化作一丝残魂追上天际，落在青烟之剑的**剑尖**上。
- 青烟飘摇直奔天际，远远消失无影。一切如同虚幻，好似只是那青烟之梦。

## 六、王林的迷茫：真假不辨
- 王林目光落在失去灵动的石像右手印诀上，眼前恍惚重现远古仙界、腾空仙剑、剑柄与剑尖之上的两人；唯一不同的，是当年剑柄仙人死亡时传入心神的声音——**「吾亡，魂灭」**。
- 山峰石像崩溃，化作无数碎石残骸。
- 悬而未决的疑问：仙人当年是否便已身亡魂灭，一切只是仆从残魂的独殇之梦？还是如王林此前猜测那般？没有答案。王林原以为已得结果、知晓一切，但见青烟一刻却又迷茫，好似一切又是虚假。
- 结论性感慨：**或许只有那仆从的残魂，才是真实的，才是唯一一个知道全部答案之人。**

## 七、结果与余波
- 自这一天起，**雷之仙界内多了一把由青烟化作的剑，剑尖之上总站着一个身影，仿若永恒**。
- 地面上的李元虚弱出声：「这里，是哪」，茫然四顾，目光最终落在王林身上——奴印剥离后，占据其身之魂与本人身份关系仍待厘清（承接第711章王林指其为占据李元之身的仆魂一说）。

## 八、母题呼应
- 因果：等待无数年、两次轮回祭献仍「逃不出因果」；王林手持因果之鞭却选择收起。
- 虚幻：青烟之梦、画轴之焚、真假难辨，正合《仙逆》虚幻母题。
