# 第1307章 吞灵噬体绝天大法！（第四更）

## 一、无量劫的结构与「极境」诞生

无量劫并非单一雷劫，而是八层嵌套的天劫图案：

- 最外层：**九宫**——九颗星空陨石排成图案
- 其内：**八卦**闪烁旋转
- 八卦内：**七星**弥漫，散发惊天煞气
- 七星之内：**龟甲**扩散
- 更深处：**五行**流转
- 五行内部：**四灵**咆哮嘶鸣、彼此环绕，每转一下带动外圈同转
- 四灵深处：**天地人三才**之光滔天
- 三才最中心：**两仪**阴阳，成太极之图

两仪太极缓缓转动，带动所有外围天劫轰轰旋转；八层天劫各自旋转轨迹不同，却化作八个漩涡诡异融合。最终在两仪太极中心，轰出一道**无色却「极」的光芒**——「一切天地之极，一切万灵之极」，是为**极境**。

与此同时，融入王林体内的天劫也组成了与外界一模一样的图案，同样在中心太极处诞生极境。

**代价与决心**：以莫大的牺牲、置之死地的决心，在无量劫下以身体吸收种种天劫，抓住天劫出现极境的唯一刹那，王林体内再次诞生出失去已久的极境。

## 二、极境降临的异象（本章王林状态）

- 肉身停止崩溃，元神停止消散，一切静止，王林睁眼
- 瞳孔内**红色闪电**疯狂闪烁——此乃极境标志，**已一千多年未出现于王林眼中**
- 满头白发自发根泛起赤芒，顺发丝蔓延，**瞬间转为血红**
- 体内滔天煞气轰然而出

## 三、双极境轰破封界大阵

1. 天劫之极化红色闪电扑向王林；王林仰天长笑，右手抓住天劫之极。
2. 王林身子后退靠上**封界大阵**，以自身「已然熟悉极境的身体」为媒介，把毁灭性的天劫之力全部导入阵法。
3. 阵法器灵欲反击，却被阵上骤然出现的**大量青色丝线**缠住，无法幻出。
4. 王林右手轰出，体内诞生的极境离体直击大阵——**天劫之极 + 王林之极**两道极境合击。
5. 青色丝线暴增如片片波纹，对阵法展开大范围破坏。
6. 网状大阵在王林后退中被拉出极长距离、鼓起巨包，终于崩出一道细微缺口。

## 四、开天大斧现身与封界之主放行

- 缺口出现瞬间，阵中传出尖啸，**被拓森认出的古神一族父祖之器「开天大斧」**幻化而出；青色丝线一度崩溃、倒卷与大斧对抗。
- **封界之主**沧桑之声自阵内传出：「还不快走，等待何时」——缺口被再撕开成可通人的裂缝。
- 王林毫不犹豫，**古神躯体缩小化作常人**，右手抱着**李倩梅**化作长虹冲出。

## 五、界外初临与噬主一斩

冲出后所见：陌生星空、**太古星辰**、远处数百衣着奇异、目瞪口呆的**太古星辰之民**。

开天巨斧在无数青丝纠缠中仍轰然一震，遥指王林方向隔空一斩：

- 王林怒吼：「你是我古神一族法器，竟敢噬主」
- 斧芒临近时一颤、似在挣扎，最终仍穿透王林胸口
- 后果：胸口巨大伤口、鲜血狂喷、五脏六腑尽碎、双眼涣散、元神崩溃将散；因斧芒蕴含**古神气息**，**伤口无法愈合**

随后缺口迅速愈合、再无破绽，青色丝线疯狂涌入缺口处如扎根一般；开天巨斧遥望王林许久后消散、融回封界大阵。

## 六、界外围杀：不问原因的种族之战

- 太古星辰守阵之修从震惊中惊醒，杀机毕露：「杀了他，此人从界内冲出，已然重伤」「送去族中定有赏赐」。
- 设定要点：**界外与界内之间的杀戮，不问原因**，这是两个种族之间不死不休的杀戮。
- 来袭者：**数百修士**，修为最低**净涅**，最高**碎涅后期大圆满**。
- 王林心中回荡起在**七彩界**所见仙人死前的怒吼：「终有一曰，吾辈修之后人，必将破开阵法，让你等外民万灵灭绝殆尽，让你界外血流成河」——一阵之隔，对界内之人而言就是生生世世。

## 七、吞灵噬体绝天：仙术还是魔功

**来历**：清水（清水仙君）当年初现**雷仙界**时如疯狂般杀戮，凡被其所杀者元神被吞、血肉被噬，全身一切化为其疗伤恢复修为的养分。此术为清水自创，一生除王林外从未传给任何人；整个天地界内界外，会此术者唯王林与清水二人。文中评语：「这哪里是什么仙术，分明就是至极的魔功」。

**本章首次施展**（王林此生第一次）：

- 左手掐诀，在胸口连点数下，喃语「仙术·吞灵噬体绝天」
- 全身瞬息枯萎如人形骷髅，疯狂气息爆发，胸口伤痕蠕动、血液不再流出
- 化作**黑雾**卷人；配合界外可施展的**缩地成寸**瞬移

**战果**：

- 首名被卷界外修士惨叫连天，成皮包骨、双眼灰败残存惊恐、全身精华尽散、肉身崩溃
- 一名**净涅中期**界外修士被身后黑雾冲入体内，身体疯狂膨胀、片刻被彻底撑爆

> 「对于这些界外守阵的修士来说，噩梦，只是刚刚将起。」
