# 第1790章 龙皇一现仙罡开（第一更）

## 一、雨中送别：木冰眉留下

- 洞府界连绵半月的雨中，木冰眉撑伞立于地上，隔雨幕望向王林，轻声道「愿君一路平安」。她终究没有选择随行离开，来此只为看王林最后一眼。
- 王林猜不透她的心思，只道「这木冰眉本就不是一个简单的女子，她既然选择留下，便一定有留下的理由」，因而不强求。
- 离别在最后一日黄昏，雨水浓如珠帘。王林起身踏空，身后所有欲离开之人化作道道长虹升起。
- 对答：
  - 王林：「若我还在世间，会回来」
  - 木冰眉（伞略低遮住容颜）：「若我还在世间，会迎你」
- **赠剑**：王林右手虚空一抓，体内**七道本源**同时运转凝聚于掌心，幻化出一把**晶光之剑**——融合本源之力、更有**道古气息**弥漫，威力惊人。他言：「我不知何时能回洞府界内，或许千年，或许万年，或许更久，或许是直至生死。这把剑送你，保重。」
- 众人随长虹疾驰而去，李倩梅回头看了一眼地上的木冰眉。木冰眉两行泪下，如同送丈夫出门的妻子，取剑轻声道「保重」，向雨中远处走去。

## 二、王林的悬念清单（离界前的独白）

王林隐隐预感洞府界之事远未结束，逐条盘点未解之谜：

1. **界内安危**：有阵法在，界内与界外除非再有**掌尊**之类人物，否则无法再起战争；即便尚有几尊在世也均重伤，更有**蓝梦道尊**与**南云子**等人坐镇，不会出事。
2. **朱雀之谜**：朱雀战将离去，界外**颠落之地**内存在的**一代朱雀**——若二人真是分身关系，则一代朱雀必定也已消散；只是不知**二代老朱雀**等人是否还在那里。王林**没有**前去颠落之地寻找。
3. **颠落之地与大逆罗盘**：「颠落之地，不会这么简单——大逆的罗盘指针」，他内心始终有一个猜测，但眼下并非探寻之时。
4. **两个失踪者**：被他放出来的**赤魂子**；以及当年在他与**水道子**一战中出手相助、似被封印在**风仙界**的**神秘人**（此人后来应已离开风仙界）。二人去向不明，或许洞府之门开启也会把他们引出。

他刻意把这些疑问留到「从仙罡大陆归来之时」再一一知晓，作为对家的回忆与执念——「因这些未解之事的存在，使得他哪怕在岁月中遗忘了一切，也永远不会忘记家乡」。

> 「仙罡大陆，不是我的家，我的家，在这里。此番离去，如游子外出，终有回来的一天。」
> 「若我没死，当再次回来这洞府界之时，这里余留的一切隐秘，都将被我掀起面纱。」

## 三、抵达罗天星域·洞府大门

- 几十道长虹以王林为首驰向出现在**罗天星域**的洞府大门；李倩梅速度本略慢，在王林照顾下无碍。
- 在一个月期限尚差数日时抵达。金色大门屹立星空，散发柔和金芒，其大似支撑星空。
- **玄罗**盘膝坐于门旁金光内，威压笼罩四周，睁眼扫视众人后道：「提前了几天，倒也没有关系，这些人，都具备可以转世投胎的资格。」
- 人数**不到二十**，玄罗内心略松——他本以为会有数百乃至数千同时转世，那样他会很勉强；人数越多困难越大。
- 王林**未大张旗鼓**通告可离开之事（否则会有更多人尝试离开），原因有二：不愿再欠玄罗人情（这一次已是他的极限）；不想因人数过多给玄罗造成负荷与伤害。

## 四、龙皇天一现世

- 玄罗起身掐诀向两旁一挥：星空震动，波纹横扫八方，轰鸣由渐强至如雷霆，最终取代星空一切声音；其衣衫舞动、头发飘摇，身后模糊浮出**一轮巨大的血色太阳**，星空金色为之黯淡。
- 喝令：**「龙皇天一灵，以老夫玄罗之名，命幻而出」**——星空出现急速转动的巨大漩涡，深处漆黑如另一世界，龙吼自内疯狂传出，众人面色大变、充满恐惧，王林心神一震但身子不动。
- 一颗**近千丈**的龙头强行冲出，漩涡承受不住而崩溃化作点点幽光扩散。龙头特征：
  - 一根**独角**在上，角尖**不锋利而成方形**，远看**仿若帝王之冠**
  - 两条长约**数百丈**的龙须飘摇
  - **紫黑色鳞片**、狰狞神色、阴寒冷酷的双目
- 龙身自虚无冲出，两千丈→三千丈→五千丈→万丈→**数万丈**，直奔玄罗，在其手中急速缩小，最终化作一条**百丈之长的血色龙鞭**。

### 龙皇天一来历（玄罗自述）

- 系玄罗**九兵**之一；
- 取自**仙罡大陆东郊蛮荒**——那里存在无数凶悍至极的凶兽，此龙为巅峰之一；
- 生前拥有**空劫中期修士之力**；
- 当年被玄罗所杀，**取其魂、炼其身、抽其骨**祭成此兵；
- 此兵为**鞭**，玄罗要以此龙鞭**抽开仙罡规则**，为众人转世投胎**打开一道缺口**。

### 王林的评估

此鞭传出惊人威压，王林见之瞳孔收缩、暗自心惊，「他有种感觉，即便是自己，也无法承受一鞭之力」——此物强大程度已无法想象。
