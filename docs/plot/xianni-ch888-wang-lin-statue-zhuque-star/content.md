# 第888章 王林的雕像

## 一、局势：罗天星域第一波探路

- **大头童子**（被罗天修士敬称「仙使」）率数百罗天修士，作为罗天星域进入**联盟南域**的第一波探查力量，途经**朱雀星**。
- 朱雀星在其眼中是一颗半废弃的六级修真星；以他对联盟星域的了解，此等星球「随便一个阴虚修士踏入即可屠灭」。
- 朱雀星外围警戒的老妇人（白雪）见势立刻率众后撤回星，引来大头童子与罗天修士的哄笑。

## 二、屠星令

- 一名**问鼎大圆满**中年修士自请出战，身旁另有一名相貌相似的兄弟（族兄弟二人）。
- 大头童子下令：「给你们一炷香的时间，把此地所有修士，全部给我杀了。」兄弟答「半时既够」，化流星突破朱雀星罡风层降临。

## 三、朱雀星的迎战阵容（数百年后的旧识）

| 人物 | 状态 |
| --- | --- |
| 周武泰 | 现任朱雀子（王林当年禅让），立誓与朱雀星共存亡，御一把细长之剑立于朱雀山顶 |
| 白雪 | 人仙道长老，老妇人，以朱雀星为家，落下参战 |
| 云雀子 | 结束数百年闭关，相貌更苍老、眉心符文闪烁，率仙遗族族人凝聚；朱雀星资格最老者 |
| 黄龙真人 | 当年恒岳派掌门，黄袍背剑，站位靠后（资格不够）；神色凝重但目中时而闪过一丝玩味，无人看破 |
| 铁岩 | 云天宗，年迈、双目昏暗、死气缭绕、寿元将尽，仍立于云天宗广场 |
| 两名问鼎老者 | 立于周武泰身后，王林若在当可认出；已知这是两星域之战，且已有后招 |

- 五级、四级、三级修真国的众多宗派修士俱抬头望天，全星笼罩在「灭星之劫」的压抑中。

## 四、转折：云天宗的王林雕像

- 罗天兄弟之一放开神识如风暴横扫朱雀星，扫过**云天宗**山门时如遭电击、双目凸起、几欲站立不稳，恐惧蔓延全身。
- 山门处耸立一座巨大雕像，把**王林**的样貌完完全全刻画出来，尤以**双目的冰寒入骨三分**。
- 另一人神识锁定雕像后颤抖更甚，脱口而出：「魔——魔道子许木」

### 「魔道子许木」在罗天星域的分量

- 清水仙君的师弟
- 正品雷仙（封仙一役所得），可号令三千修士
- 罗天小辈修士中第一人
- 拥有无数感恩的修真家族
- 曾在姚家追杀之下反使姚家遭受重创

> 二人自认眼力绝不会看错；与此人作对必死无疑。连他们的家族老祖见到许木都要恭恭敬敬，甚至带队仙使大头童子怕也要心神剧震。

## 五、不战而退

- 兄弟二人杀气嚣张尽失，毫不犹豫落荒而逃；连「许木雕像为何在此、且明显被人供奉」都不想知道，只余滔天悔意——早知如此绝不冒然出头，此事必然得罪许木。
- 朱雀星一方大为愕然：周武泰已做恶战准备而一怔；仙遗族惊奇；**云雀子**注意到二人神识凝聚云天宗的刹那才生异变，神识一扫锁定王林雕像，双目猛睁：「莫非——」
- 周武泰及数名机敏老怪随之以神识锁定云天宗，纷纷察觉症结所在。
- **铁岩**望着雕像振奋，喃喃：「恩公，一定是恩公的原因。」

## 六、收尾伏笔

- 兄弟二人惊慌飞出朱雀星，远远看到大头童子与众修士。
- 大头童子本在闭目，此刻睁眼皱眉：「出了什么问题？」——悬念留至下章。

## 归属说明（据世界状态须知）

- **「许木」为王林在罗天星域行走所用之名**（自第661/669/711/731/771/821章沿用），疑为王林自创化名而非冒用他人姓名。本章中「魔道子许木」的所有事迹（正品雷仙、清水仙君师弟、姚家之事）均归属**王林**。
- 本章王林本人并未出场，仅以雕像与名声影响局势。
