# 第九卷 云海之巅 第1150章 惊变

## 一、云海五阶星域：外来者压境

- **环境**：辽阔星域内充满星雾，看似安静，雾气中却蕴含无限杀机。星域内漂浮着一处处大陆，**近四成属于一个个五阶宗派**。
- **阶位落差**：对一至四阶星域来说，五阶宗派已是不可攀登的存在——五阶宗派门人若前往四阶星域，必受一片恭迎。
- **惊变**：平静雾海骤起呼啸，一道长虹穿透而过，长虹内是一头如龙般的灵兽，灵兽头部站着一名威严修士。其后星雾翻滚更剧，凶兽惊慌避散，又有数道长虹呼啸而过。
- **规模**：**短短一炷香时间，不下数十道长虹**破开星雾在五阶星域内疾驰；长虹内是样子各异的灵兽，灵兽头背上均站着修士。
- **来历**：这些修士**没有一人属于五阶星域，全部来自六阶星域**，其出现顿时使五阶星域为之撼动。
- **广度**：并非孤例——五阶星域内**超过六处星空**同时上演同样一幕。
- **神态与目的**：来者神色阴沉中隐藏着狂喜与兴奋，更有无尽的贪婪；**目标完全一致：五阶星域内的一处蛮荒大陆**。

## 二、蛮荒大陆北部：黑猿夺草，兽潮追击

- **异动**：蛮荒大陆北部大地震动，远处轰轰之声如重物不断落地，雾气翻滚涌动；飞鸟凶兽尖啸避走，地面凶兽四散躲开。
- **黑猿现身**：雾气中现出一个**百丈大小**、极为粗壮的巨型身影——一头庞大的黑猿。轰轰之声正是其脚步声。
- **追兵**：黑猿身后，如牛样凶兽红着双眼疯狂追击，其四周另有**超过七种**不同凶兽群交错成长队，如兽潮般不死不弃地追逐；天空更有飞鸟凶兽同样疯狂追击。
- **威胁度**：凶兽数量之多，换作任何人看一眼也要头皮发麻，**即使大神通修士也要瞳孔一缩**；其中还有明显是**五阶的凶兽**，一道道神通直奔黑猿。
- **黑猿之能**：身子极为灵活、皮糙肉厚，除躲开的以外，神通落在其身也没有太大作用。奔跑时狂风呼啸，右脚一踏大地仿佛碎裂，一跃跨过山涧。
- **登峰破巢**：几个呼吸间冲上山峰顶部；峰上盘旋无数鹰形凶兽扑来，尚未临近便在其双臂挥舞中化作血花崩溃。峰顶有一处**数十丈大小的巢穴**，黑猿右手一击将其轰得四分五裂，露出生长其内的**一株红色小草**。
- **取草**：黑猿顺手抓住小草附近数丈大小的山石，咔咔声中直接拽出，仰天一声带着欢快的咆哮，迈步远去。
- **后果**：巢穴被毁，**不下千只鹰兽**尖啸冲天、疯狂融入兽潮大军追击。
- **交付王林**：奔跑中黑猿捏碎手中石块，露出红色小草，向肩膀一甩；**盘膝坐在其肩上的王林**一把抓住，看了一眼后收入储物空间。

## 三、要点与伏笔

1. 六阶星域修士**多点、同时、大规模**涌入云海五阶星域，目标锁定同一处蛮荒大陆——正是本章「惊变」之名所指，预示大陆将成争夺焦点。
2. 王林当下正在该蛮荒大陆北部活动，与外来者的目标地重合，冲突几乎不可避免。
3. 王林与黑猿已是协作关系：黑猿负责冲阵夺宝、承受兽潮，王林盘坐其肩收取所得（红色小草）。
4. 本章明确了星域分阶（至少一至六阶）与宗派分阶（五阶宗派）的地位序列，可作势力体系锚点。

# 蛮荒大陆：黑猿抢药引凶兽潮 / 施洛刑被围山谷

## 一、王林与黑猿横扫药草（蛮荒大陆）

- 王林轻拍黑猿身子，黑猿仰天咆哮、透出欢快之声，速度更快。
- 黑猿跳跃奔行，大地震动，身后尘土漫天与雾气交融，成群凶兽吼叫追击。
- 叙述强调：蛮荒大陆上极少有修士敢如此招惹凶兽、如此嚣张抢夺药草；一头凶兽或不足为惧，但成千上万乃至超过十万时的场面足以震骇任何人。
- 旁观者：另有七名同样来自**五阶宗派**的修士远远呆望，如木鸡般说不出话。他们来此极为谨慎，生怕引出太多凶兽，所获药草不多。
- 黑猿一跃跨过数百丈，登上一座**如剑般陡峭的山峰**顶部，弯腰伸右手，摘走山峰后仿若一团雾气的花朵——**雾中花**数朵。

### 空中截击
- 一头近**五十丈**大小的**鹰形五阶凶兽**破雾尖啸直扑，转眼临近不足百丈。
- 王林**神色如常，仿若未见**（未出手）。
- 黑猿双目一凝，左手抓住峰顶，身子如荡秋千般绕峰尖画圆，粗壮右脚横扫，与黑鹰硬撼。
- 结果：轰然一声，黑鹰惨痛喷血后退；黑猿借力一跃，不缠斗，继续向远处奔跑，身后追击凶兽更多。

## 二、施洛刑困局（幽暗山谷）

### 处境
- 施洛刑闭目盘膝坐于幽暗山谷，面色苍白、嘴角血迹未干、黑发散乱，样子狼狈。
- 四周鬼哭般呜咽之声时近时远，夹杂阵阵砰砰之声。
- 四名踉跄青年弟子（白衫满是血迹）自前方走回，临近三丈时其中一人喷出一口鲜血，禀报：「师尊，老三战死，我们闯不出去。」
- 施洛刑沉默未睁眼，脸上露出悲伤。

### 死魂骷髅大阵
- 山谷内充满雾气，雾中死魂弥漫、发出刺耳尖啸。
- 山谷外漂浮**八个巨大骷髅头**，缭绕**绿色闪电**、彼此连接成阵。
- 阵法机理：引动蛮荒大陆内无数万年来的死亡之魂凝聚、化作有形之物，融合阵法，成为凌厉神通手段。
- **设定辨析**：死魂**不可炼化成丹**；炼丹所需兽魂是**生魂**，而死魂大都来自人或兽死前一瞬间的怨念，怨念融入天地久久不散。

### 毒婆子
- 阵上一个骷髅头顶盘膝坐着一名老妇人：皮肤干皱、皮包骨、神色狰狞如厉鬼，双目开阖间隐有幽光，阴森之意逼人；凡人见之定会吓死。
- 出身**五毒门**（六阶星域势力）。
- 喊话：「施道友，你十九个弟子只剩下四人，何苦继续害了这些弟子的姓命，若你现在交出那样东西，老婆子立刻离开。」
- 又称：施洛刑虽修为高，但中了五毒门之毒，短时间内**若施展神通定会暴毙而亡**。

### 施洛刑来历与因果
- 身份：**六阶华清宗大弟子**，修为**净涅后期**。
- 此行：根据线索，带弟子**秘密潜入三阶星域**寻找一样物品；本以为线索真实性不大，未料线索属实，取物顺利。
- 变故：取物后行踪不知为何暴露，连所取之物也被人得知，一路被围攻，弟子死伤惨重（十九人→四人），自身中奇毒，逃至此谷毒发，被迫躲藏驱毒。
- 毒未驱散即被五毒门毒婆子追上，以门派大阵困于山谷。
- 自救：已用秘法将消息传出，但宗派营救之人需一些时间才能赶来。

### 争夺的核心之物
- 毒婆子直言：即便华清宗派人来也无用——六阶星域此次除五毒门外，**岳魂宗、道法门、遁行派、魔丛道**几乎都出动了。
- 众势力所图之物：**八阶星域破天宗的玉简**，以及**传说中存在的涅空丹的丹方**。

## 三、要点归纳

1. 两条线索并行：王林（黑猿）在蛮荒大陆的高调掠夺 vs 施洛刑被围的死局。
2. 星域阶序线索：三阶星域（藏物之地）< 五阶宗派 < 六阶星域/六阶华清宗、五毒门 < 八阶星域破天宗。
3. 「涅空丹」丹方与破天宗玉简是引爆六阶星域多派出动的诱因，为后续冲突埋线。
