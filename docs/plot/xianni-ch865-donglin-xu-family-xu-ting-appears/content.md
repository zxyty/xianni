# 第七卷 名震罗天 第865章 东临许家

## 场景
地点：罗天星域 · 雷仙殿外（东部传送阵）。时值封仙之争资格者汇集之际。

## 事件脉络

### 1. 白衣青年出阵
- 东部传送阵光芒闪烁，一道刺骨寒声携血腥味传出，煞气弥漫全场。
- 走出者为一约三十许岁的白衣修长男子，白衣却无飘逸之感，反显阴森；双目冰冷狂傲，杀机浓郁。
- 开口即道「一群废物」，声如天雷炸响回荡雷仙殿外，激起四周罗天星域佼佼者的敌意。

### 2. 神识交锋
- 王林（本片段以化名「许木」行事）判断此人修为与自己同为**窥涅初期**，却在其身上生出奇异之感，并确定从未见过此人。
- 白衣青年一眼锁定王林，舔唇露出阴森笑容；二人目光在半空碰撞，实为神识如利剑交错厮杀，一触即收。
- **结果**：白衣青年非但未压过王林，反有被王林神识穿透之感；王林亦察觉对方神识中有一股**诡异的力量**。

### 3. 四位察觉者
短暂交锋，全场仅四人察觉：
| 出处 | 特征 |
|---|---|
| 罗天北域 | 中年男子，面白无须，右手**六指**（拇指上衍生出一指） |
| 罗天北域 | 头颅硕大的**童子**，痴傻之笑，四周三丈无人敢近；扫过王林后重点看向白衣青年，傻笑更浓 |
| 罗天西域 | 蓝衫男子，相貌极为英俊，双目开阖有精光，盯着王林沉吟 |
| 王林身侧 | **南宫寒** |

### 4. 雷仙殿接引使问名
- 远处天际红霞弥漫，云层凝聚化作白发苍苍、仙风道骨的老者，脚踏雷光现身，修为**窥涅中期**。
- 自称「雷仙殿接引使」，质问：是否是你杀了罗天东域其他资格者。
- 白衣青年平静承认「没错」。
- 报出身份：**东临星许家这一代入世历练者，许霆**。

### 5. 「许家」之威名
- 「东临星许家」五字一出，四周修士面色大变、倒吸冷气、后退数步。
- 设定要点：东临星或许**向家**才是最强大的势力，但论**名气**唯有许家。
- 许家每一代入世者都会掀起一场杀戮浩劫；凡招惹者立刻**屠星，寸草不留**。许家威名即由此一次次血腥风暴铸就。
- 众修士议论：难怪此人敢同时得罪一百多个修真家族；封仙之争若遇此人，必死无疑。

## 伏笔与看点
- 许霆神识中的「诡异力量」来历未明。
- 许霆姓「许」，与王林当前化名「许木」同姓，构成潜在的身份风险/冲突张力。
- 六指中年、大头童子、蓝衫俊美男子三名罗天北/西域高手被点出，均为封仙之争的潜在强敌。
- 许霆对王林已显露明确杀意（阴森微笑、锁定注视）。

# 第806章 许木自曝身份·雷仙殿内殿召见

## 一、封号之战安排
- 雷仙殿接引使（老者）当众宣布：**三日后正午**，展开「罗天雷仙一百零八封号之战」。
- 片刻后将有雷仙殿之人发放**令牌**，并安排各方修士的**住宿之处**。

## 二、东临星许家的威名与「许木」现身
- 会场议论纷纷：东临星许家名头极大，**心狠手辣、血腥杀戮**的作风令人心寒，有修士当场表态「若见机不妙，我便弃权」。
- 接引使扫视四周后发问：「你们之中，可有许木」。
- 除罗天南域外，**西、北二域**修士皆双目一凝——「许木」之名在他们心中不亚于东临星许家，许多人**怀疑许木就是东临星许家之人**。
- 王林沉吟片刻，抬头平静应道：「在下许木」。（按世界状态须知：本片段「许木」为王林所用之名，言行归属王林。）

### 众人反应
| 人物 | 反应 |
| --- | --- |
| 罗天南域修士 | 表情复杂 |
| 西、北二域修士 | 目光刹那间齐聚 |
| 六指修士 | 眼中寒芒，仔细打量王林 |
| 大头童子 | 痴傻之笑一顿、收起，再度浮现笑容 |
| 蓝衫青年（极英俊） | 仿若出鞘之剑，锋芒毕露锁定王林，因「子凤表妹」对许木念念不忘而**闪过杀机** |

### 场中传言（未证实）
- 「魔道子许木」竟真的参与此次封号之争。
- 「许木、许霆，这二人不知是否有什么关联。」
- 「这许木在**姚家追杀**下不但没死，反而能来到这里，不简单。」

## 三、殿主召见·入内殿
- 接引使罕见地露出和善微笑：「你跟我来，**殿主召见**」，随即飞向远处。
- 王林一步踏至半空从容跟随，**一路不发一问**，老者眼中露出赞赏。
- 老者说明：先前所在只是**外殿**，此行前往的是雷仙殿**内殿**。

## 四、雷仙殿见闻
- 云层散开后，展现大片**极为庄严的宫殿群**：数量极多但分散零落，一眼望不到尽头，凡人皇城远远不如。
- 浓郁**仙气**弥漫天地，仿若仙界，且仙气正是自这些宫殿散出——宫殿绝非凡物。
- 老者自豪介绍：雷仙殿共有**一千三百七十二座大殿**，**全部由历代雷仙殿殿主从雷之仙界取来**。
- 王林顺势称赞「雷仙殿，不愧是**罗天星域第一殿**」——千年修道，看得透彻，捧人无伤大雅；老者回赞其日后成就定然不低，雷仙殿内必有其一处位置。
- 殿中多处薄雾缭绕，其内**银光闪烁**，显是雷电神通。
- **禁制遍布**：整个雷之仙界几乎所有位置都有禁制，沿途亦然；若非跟随老者，单是这些禁制便足以阻挡一切。

## 五、内殿中心广场与雷灵分身
- 内殿中心为**巨大青石广场**，规模不下千丈，雷光不断闪烁，仿若由雷组成的池水。
- 二人临近时，广场雷光掀起**化作大口吞噬**而来。
- 老者拍储物袋取出大把**赤红色小果——升仙果**，抛入大口；果子尽数消失、化作汁液融入雷光，广场传出一声低吼后雷光平息，不再阻拦。
- 老者揭示：此地封印的是**雷之仙界内守护门户的雷灵之分身**。
  - 凡欲进入雷仙界者，都要拿出**大量升仙果喂食雷灵**，否则不得入内。
  - **上一代雷仙殿殿主**以莫大神通、历时无数载，从那雷灵身上**分离出一丝**置于此地，成为雷仙殿的**护殿神兽之一**。

## 六、伏笔与看点
- 王林以「许木」之名公开亮相，同时被误认与东临星许家/许霆相关，敌意与关注度骤升。
- 蓝衫青年（子凤之表兄）已生杀机，六指修士、大头童子亦已锁定，封号之战前的对手格局初成。
- 雷仙殿殿主主动召见，动机未明。
- 「升仙果—雷灵—雷之仙界门户」的设定，为日后进入雷之仙界埋下门槛。
