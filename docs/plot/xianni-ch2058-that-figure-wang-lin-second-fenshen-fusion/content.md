# 第2058章 那个身影……

## 一、局面：光环递减，分神濒临失败

- 王林在始古一脉祖庙深处闭关，进行**古道三分神**中的**第二次分神融合**，已持续近二十年。
- 外部指示器：**古祖雕像外的光环**。本章开篇仅剩**七道**，其中一道正快速黯淡。
- 祖庙深处：王林身躯完全干枯如骷髅，四周无一光点，意志暗淡到几乎不可察觉；无数次融合尝试全部失败。
- 唯一的生机迹象：其体内**魂血**化作红芒一闪一闪，映动漆黑的祖庙深处。
- 光环递减节奏：七道 → 三道 → 两道 → 一道，最后一道亦在慢慢黯淡。

## 二、玄罗护法：屡踏屡退，以声唤魂

- 玄罗被祖庙禁制阻挡在外，传出神念如泥牛入海。
- 其掐诀，身外浮现**如太阳光晕般的明亮之芒**，强行踏入祖庙，仅数步即被轰鸣反弹之力卷退，反复多次。
- **关键设定（玄罗自述，源于其亲历古道三分神）**：
  - 分神过程中，只要光环不灭，纵然没有生机、没有意识，也**不是死亡**，而是一种**灵魂的沉睡**；
  - 这种沉睡**若能被唤醒，仍有生存可能**；
  - **一旦光环全部消失，沉睡即等于真正的死亡**。
  - 这正是玄罗选择前来为王林护法的原因。
- 玄罗一拳轰向祖庙，嘶吼「王林，我是师尊玄罗，你快快醒来」，声音回旋整个始古皇城。

## 三、身份曝光：始古皇城哗然

玄罗的嘶吼使十多年来的疑问有了答案——祖庙内渡劫者即**王林**。族人议论：

- 「这王林不就是一百多年前，杀了**道古皇尊**之人么」
- 「传闻这王林已然是**仙罡大陆第十阳**」

始古皇城几乎无人打坐，全部凝望古祖雕像，呼吸凝固。

## 四、伏笔核心：迷雾废墟中的那个身影

沉睡中的王林处于一个奇异之地：

- 天昏暗、地朦胧、雾气缭绕，是**一片废墟**；大地无生气，山峰灰败，似废弃了不知多少岁月。
- 王林**遗失记忆**：想不起自己是谁、为何在此、此为何地。
- 迷雾前方现出**一座山，山上飘落七彩色的雪，很美**。
- 山上有一**模糊男子人影**，**双手托着一具尸体，尸体长发垂落被风吹动**，透出苍凉与悲哀。
- 王林对该身影有**极为熟悉**之感，身子颤抖。
- 该人影仰天发出**悲哀至极的嘶吼**，声音带穿透之力冲入王林心中；昏暗天空震动、波纹回荡、出现碎裂迹象，似连天也要在其吼声中崩溃。
- 人影开口只说出两个字：**「天地」**——话音刹那，玄罗「王林，醒来」的呼唤凭空而至，山与身影同时消失。

> 该身影身份未明，为本章最大伏笔；王林苏醒后脑海仍不由再次浮现「那抱着尸体，仰天凄吼的身影」，并自认此番凶险「丝毫无法与他在迷茫中看到的一切比较」。

## 五、苏醒与反转：光环暴涨至二十七道

1. 王林转头的一瞬脑海轰鸣，记起自己是王林、正在始古祖庙渡劫、正处第二次分神融合，迷茫尽去、双眼清明。
2. 同时，祖庙深处王林身前十丈外，出现一个**满头白发的老者**，衣衫属于玄罗，但与青年模样的玄罗相比已有**岁月的差距**——玄罗为闯入祖庙唤醒王林付出了苍老白发的代价。
3. 老者嘶吼「王林，醒来」，声音已嘶哑；见王林睁眼后露出惊喜，随即再难抵御反弹之力，被轰出祖庙。
4. 王林喃喃「师尊」，自知此生无法忘记这股恩情。
5. 王林掐诀，体外再现大量光点，凝聚于头顶形成光影轮廓。
6. 古祖雕像最后一道光环在将散之际**重新凝聚**，随即第二至第十二道同时出现，继而第十三至第十八道，最终一路增至**第二十七道**，光芒四射、波纹八方扩散，笼罩始古皇城并延及外面的**原始山**范围。
7. 始古皇城由瞬息寂静转为滔天哗然。

## 六、结果与后续

- **第二次分神成功**：祖庙内王林上空漂浮的巨大光影几乎占据全部空间，体积是**第一次分神后的数十倍**。
- 王林抬头，光影同抬头，似穿透祖庙看到天幕上玄罗的微笑；王林心念「师尊」。
- 玄罗未在祖庙外停留，重新出现在天幕盘膝坐下——**护法未结束，王林还需经历最后一次（第三次）分神**。
