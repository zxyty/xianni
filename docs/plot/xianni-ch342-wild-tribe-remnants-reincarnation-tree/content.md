# 仙逆 第342章 野人余孽

## 一、场景与人物

王林（现以化名「曾牛」行世）于朱雀星以茶待客，来客包括：

- **胡姓老者（胡老）**：化神修士，正欲冲击婴变；言谈中对王林的称呼由「王道友」渐变为「王兄」。
- **邱四平**：跟随胡老，自叹「化神难」；王林点破其若舍弃全部、孑然一身，或有进军天道的可能。
- **许罗**：随行，听到「轮回树」时目露火热。
- **白纱女子（紫芯）**：持有仙遗之地地图玉简，此行的引路人。
- **青衫老者**：紫芯一方随行。
- 跟随胡老的少女：侍茶，时而偷看王林。

## 二、茶与仙界之气

- 王林所奉之茶非朱雀星所产，乃**多年前仙界之行**时于其他修真星偶得。
- 胡老提及传闻：**王林曾在仙界断红蝶一臂**，遂问是否获得**仙气**。王林答「偶有所得」。
- 胡老恳请不惜代价换取一点仙界之气；王林轻描淡写推开：「待道友婴变之时再说不晚」，并顺势把话题转向仙遗之地。胡老暗评王林「修炼时日不长，却是个老狐狸」。

## 三、仙遗之地与轮回树

- 紫芯称仙遗之地深处有一颗**轮回树**，她手上有去往那里的地图。
- 卖点：**在轮回树下打坐，可多得一次轮回的感悟**，尤利化神修士的意境。
- 王林当场戳破：化神的意境乃自身感悟，轮回树对**元婴后期大圆满或刚化神者**或有帮助，对**化神中期以上**帮助甚微——断定胡老「另有所取」。
- 全程王林神色如常，紫芯捉摸不透，暗叹化神修士除修为外心机也远超元婴；胡老则因此更确信外界关于「曾牛」的传闻。

## 四、真正的目标：轮回果

胡老坦承此行目标是**轮回果**：

| 项 | 内容 |
|---|---|
| 外形 | 拳头大小，每两个时辰换一次颜色（王林凭此辨认法一语道破）|
| 功效 | 化神后期大圆满服下，**婴变成功率 +30% 以上** |
| 出处 | 由轮回树结出；胡老有秘术可令树在**三个时辰内**结果 |
| 考据 | 胡老曾于古籍上看过描述 |

**成算**：无王林参与，此行把握仅三成；王林同行则可达**六成以上**。

## 五、王林的暗线：古神洗体（涂司记忆）

王林听到「轮回果」内心一动，其依据来自**吉神涂司**的记忆：

- 古神体制受限，寻常之果乃至仙果灵物服下也只增灵力，效果不佳。
- 唯有**为数不多的一些灵果**，虽不增灵力，但**以汁液涂抹全身**，可起到类似修士筑基的强大效果——古神称之为**洗体**。
- 惯例：幼年古神由成年古神寻此类灵果洗体，随后才被扔入星球之中。
- 洗体之效：**经脉隐匿、彻底融入血肉**，吸收天地灵力速度大增；成年后经脉再现，届时吸灵力已极为恐怖。
- 定性：**只有洗体之后，本尊才能真正算是一个古神**。
- 远古背景：古神所在之处四周再无灵力，故每一个古神都遭所有生物追杀；但因古神强大，试图击杀者往往未成先亡。

## 六、野人余孽的由来（胡老转述）

- **野人**是无数年前朱雀星上的**土著**。
- 朱雀国升级为**六级修真国**后，被**修真联盟**送予此星，与野人爆发一场大战。
- 战果：原本生机盎然的朱雀星险些崩溃，如今**半废弃状态**；野人**死亡九成**，余孽退入**仙遗之地地下**不再外出。
- 朱雀国**每百年**派大量修士入内剿灭，始终无法彻底杀绝。
- **轮回树并非一颗，而是共有九颗**，皆长于地下，是野人的圣物——正因如此，此行才有机会。
- 风险：仙遗之地有连朱雀国都忌惮的力量；胡老判断只要不进太深，野人不会派出太多。
- 地理：王林仅从地图玉简知其大概——仙遗之地地面很大，**地下更大**，究竟有几层除朱雀国外无人知晓。

## 七、悬念/后续钩子

- 胡老婴变临近时将来讨要仙界之气（未来人情债）。
- 王林答应与否本章未定，但其真实动机是为「洗体」寻灵果，与同行者所求（轮回果助婴变）不同。
- 九棵轮回树、仙遗之地地下的层数、野人余孽的实力，均为后续伏笔。

# 第343章 朱雀国（第二更）

## 一、送客与仙遗之地的邀约

- 王林询问白纱女子：当年其父为何前往仙遗之地。答曰：**为给我取一块轮回之木**。（白纱女子自称“紫芯”）

## 二、王林独处：盘点与谋划

### 轮回果
- 王林心中权衡：“**轮回果对本尊有大用**，若是能得到，本尊的实力可以增强不少。”——这是他考虑赴约的核心动机。

### 岁月木雕
- 取出三个木雕清点：**已毁去六个，仅剩三个**。
- 剩余木雕所能形成的**岁月意境比之前差上不少**。
- 补充受限：缺少**百年以上木料**，否则尚可补足。

### 红蝶断臂与战帖疑云
- 神识扫过储物袋，取出**一截断臂**：保存完好，其上覆一层薄冰，散发寒气。
- 疑点：“**朱雀国没有为红蝶出头，而是送来战帖**，此事透着古怪。”王林百思不得其解。
- 判断：与红蝶一战在所难免，“**只要这红蝶没有踏入婴变**，我便有取胜的希望”，而这截断臂“现在有了用武之处”。

## 三、祭炼断臂（关键操作步骤）

1. 隔空一抓摄来**石椅**，令其如融化般蠕动，变形为**石盆**；将红蝶断臂投入其中。
2. 掐诀打出**一道黑芒**，落入盆内，钻入断臂。
3. 取出**两个白玉小瓶**——内为**妖兽丹毒所化**之物，是他数百年内偶然所得；弹碎两瓶，红色如血的液体融入断臂。
4. 双手掐诀打出幽光，化作**骷髅头**钻入断臂；连续打出**九十九个骷髅头**，一一融入。
5. 效果：断臂**由雪白变为黑红交错**，极为可怖，腥臭扑面。
6. 收尾：右手隔空一抓，石盆蠕动收缩，**密封**起来。

## 四、朱雀国·红蝶一方

### 场景
- 朱雀国内一处山水如画之地：碧水青山如仙境，灵兽时隐时现；潭中数条长须鲤鱼双目露轻灵之光，**已具灵智**。
- 红蝶身着红色衣纱，盘膝坐于潭水之上的荷叶，**右臂只余一条空袖**。

### 红蝶与师兄的对话
- 三丈外荷叶上坐着一名**中年男子**（红蝶师兄，相貌堂堂、英武不凡，望向红蝶时眼露柔情）。
- 师兄已为她取来**东海之灵**，可使断臂重生，问她为何不用。
- 红蝶答：“每次看到右臂空袖，我杀曾牛之心就浓上三分，**不杀曾牛，此臂永不恢复**。”
- 红蝶自陈：曾牛欲坏其道心，反因断臂之恨令其**道心更加圆满**；此次**朱雀山要她与曾牛一战，以整合其意**。
- 师兄称：若非朱雀山的命令，早已出山擒曾牛交由师妹处置。

### 祭炼反噬的即时呼应
- 红蝶忽然面色一变，**眉心浮现一丝透着红芒的黑线**并蔓延；她左手点在眉心，面色青红不定，许久黑线才退去。
- 红蝶醒悟：“**这曾牛居然拿我断臂祭炼，想以此伤我**。”遂掐诀连打数个法印落入眉心镇压，起身挣扎少许后又重新坐下。

### 师兄的变通手段
- 师兄欲亲往杀曾牛，自忖“最多罚我闭关百年而已”。
- 红蝶阻止：**朱雀山已连续两次传出讯息**，师兄若执意，后果不止闭关百年；要杀曾牛，只能由她自己去。
- 师兄退而求其次：取出**一枚玉简**，在眉心拓印少许后甩出，声称“我不出面，但**派一些低级修真国出手**，这样的话，朱雀山也不能拿我如何。”

# 第322章 朱雀山之议与驱兽圈炼战车

## 二、朱雀山：战帖回报与“等他十年”

### 场景设定
- **朱雀山**位于朱雀国东部，山形如朱雀，故名。
- 朱雀山是整个朱雀国的**圣地**：朱雀国的一切决定，都需经朱雀山认同方可实施。

### 事件经过
1. 一名白衣青年在山下面带难色徘徊许久，咬牙登上台阶，于山中断处一座宫殿外单膝跪地：“弟子白衣执事孙玉山，求见长老。”（原文用字混乱，作“刊玉山”“孙玉白”“孙玉山”，实为同一人。）
2. 他一五一十回报：此前受命前往**楚国**寻**曾牛**送**战帖**，曾牛并未接帖，而是**推迟了十年**。
3. 宫殿内声音阴森：“这曾牛不识抬举，你退下吧，自有人会把他擒来。”孙玉山额头见汗，起身告退。
4. 长老唤出**子午**：“你去把这曾牛拿来。”子午身体被一层迷雾掩盖、看不清面貌，懒洋洋问“要生，要死”，得答“随意”。
5. 子午转身欲走之际，一道**火红之芒**自朱雀山顶蓦然射入宫殿。
6. 宫殿内声音带诧异道“等一下”，许久后轻哼：“罢了，你不用去了，**等他十年**。”子午耸肩，身影一闪消失。
7. 宫殿内是一名**头发眉毛全部花白的老者**，手捏一枚**火红玉简**，喃喃自语：“这曾牛到底什么身份，居然让他连续**三次**出面干涉。”

### 要点
- 曾牛（王林化名）已引起朱雀山高层注意，但被山顶某位存在**连续三次**出手庇护/干涉，擒拿令因此撤销。
- “等他十年”把十年之约正式确立为朱雀国一方的既定安排。

## 三、山谷：王林炼化战车魂兽

### 1）解放雷蛙、归还灵力
- 王林盘膝坐于山谷，身前是那辆**充满利刺的战车**。
- 甩出右手**驱兽圈**，放出**雷蛙**；雷蛙伤势已完全好转，目露感激（若非王林相助必死无疑）。
- 王林言明要收回驱兽圈，愿留则随侍身侧，不愿可自行离去；雷蛙点头**选择追随**。
- 王林掐诀，驱兽圈上符号飞出、由外及内层层缩小结成圆形阵（圈居中心）；一声“放”，符号急旋，一缕青气自圈内穿符号而出，融入雷蛙体内，雷蛙咆哮颤身、双目大亮。符号不散，继续旋转。

### 2）解封并炼化战车魂兽
- 王林指向战车，黑雾升起，露出**三只魂兽中最小的一只**（原被王林封印）。
- 该魂兽外形：**头成三角、身似牛、尾如蛟龙，尾端另生口鼻眼之物**；苏醒即锁定王林，暴虐凶狠。
- 王林咬破指尖，一滴鲜血落入驱兽圈，再一指战车之灵——驱兽圈一震，外围符号涌出化作**符号长虹**绕魂兽旋转。
- 战车内飞出**黑色铁链**捆缚魂兽；魂兽挣扎致部分铁链断裂，更多铁链续出将其牢锁。
- 符号落下印在兽身、闪烁金光，魂兽咆哮渐止，眼中凶芒更浓。
- 王林道“收”：兽身符号剧烈闪动，由**金色转为黑色**，逐一飞回沉入驱兽圈。
- 最后一枚符号沉入后，铜圈上**多出一兽纹**，与战车之魂一模一样；同时战车化作黑芒被吸入驱兽圈。

### 3）佩戴代价
- 王林拍储物袋取出**八块极品灵石**置于身侧，咬牙召来驱兽圈套在手上。
- 吸力比当年（收雷蛙时）**庞大无数倍**，王林身体眨眼萎缩如**干尸**，唯目光始终明亮；八块极品灵石光亮大放，磅礴灵力涌入其体又宣泄入圈。
- 过程持续**三天**，之后吸力消散，身体自枯萎状恢复；**一块极品灵石碎裂化为飞灰**。
- 王林睁眼，面露心有余悸，低头看手腕铜圈，眼中一丝寒芒。

## 四、伏笔与影响
- **十年之期**成为朱雀国与曾牛（王林）之间的明确倒计时；朱雀山已放弃即时强擒。
- **山顶存在的三次干涉**指向王林身上不为朱雀山所知的背景，是重大悬念。
- **驱兽圈**升级：现已收纳雷蛙、战车及战车魂兽，代价是佩戴时对本体灵力的恐怖抽取（三天+一块极品灵石）。
- **子午**作为朱雀山可随召随至的执行者登场，暂未出手。

- 随即拍储物袋放出**蚊兽**：多年不见，此兽身子比当初更大，好似一座大山，巨大口器寒芒闪现、极为可怖。

## 三、借剑：宝塔顶层的白衣女尸

- 塔外，王林神情凝重、抱拳陈情：**受周佚前辈所托照顾女尸**；因**仙遗之地**凶险异常、自身法宝不多，故求借仙剑一用，并深深鞠躬后入塔。
- 塔内最顶层：白衣女尸平躺于**仙玉床**上，双目闭合、毫无气息；身边放着**一大一小两把仙剑**，散发阵阵剑气。
- 王林目光多停留在大剑上——自仙界第一眼见到它便觉眼熟，当时形势危急无暇细想，回朱雀星后又陪在李慕婉身边，一直搁置。

## 四、伏笔回收：这把仙剑与「巨富」

- 右手按剑无任何不适，王林顺利持起。此剑实已不能算剑，**而是一个长方形的门板**。「门板」二字让他失声道出：**巨富**。
- 四百多年前的往事：王林在**恒岳派**、玄道宗来临之前，持其师玉简去**剑阁**选飞剑，选中的正是号称**整个赵国最夸张的飞剑——巨富**。
- 巨富的真相：
  - 通体金光并非剑芒，而是表面涂了一层金子；
  - 金子之下并非绝世宝剑的伪装，**真正材质就是最普通的生铁**；

- 王林收起雷蛙北行，数个时辰后神识察觉异动，转向查看。
- 场景：一处淤泥潭前立有两名野人——白发老者（全身约**三分之二**布满符文）与少年（符文不足四分之一）。老者目光清明，见王林并不理会。
- 潭中钻出一条形似蛟龙的巨物扑向老者。
- 老者拍身，符文蠕动汇聚于右手凝成**符文长刀**，跃身斩去；蛟龙甩头避锋撞来，老者身体砰然**化作无数符文**四散，随即猛地一收钻入蛟龙体内。
- 蛟龙痛吼冲出泥潭，很快虚弱；符文自其体内钻出重聚成老者之形（如从蛟龙体内长出），最后一符融入后老者跃下，右手斩开蛟龙头部，鲜血喷涌。
- 少年欢呼冲入血中沐浴，身上黑色符文蠕动如吸血；随后盘膝坐下，以蘸取的**蛟龙血**顺着自身符文描画，**新符文取代旧符文**。
- 见此一幕，**王林脑中忽然想起了一人**（悬念未点名）。

## 七、要点与伏笔

- 叶子=实力标尺：一叶（普通）→ 两叶≈结丹后期 → 三叶≈元婴期 → 五叶≈化神。

- 「咒符星」与「百年之期」的约定，暗示仙遗之地与外来修士间存在既定协议。
- 紫芯入内后凭空得到记忆，其来历存疑。
- 王林战力刻度：仙剑一击可破化神后期防御；雷蛙雷球为终结手段。
