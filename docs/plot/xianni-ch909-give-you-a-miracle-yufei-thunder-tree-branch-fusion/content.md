# 第八卷 联盟隐秘 · 第909章 给你一场奇迹

## 一、雷池压杀：王林 vs 红衣人于非

- 王林施展**行使天地雷之权利**：雷音之下星空骤变，无数雷霆凭空浮现向他凝聚，声势仿若天劫，并引动更多雷霆弥漫。
- 于非（红衣人）仰天长笑，语带寒意，称这才有些「**罗天正品雷仙**」的气势，扬言被他亲自所杀之人皆大名鼎鼎。
- 王林斥其狂妄，右手一指，方圆数万里雷霆数倍浓郁，整片星空化为**雷池**，并以于非所在为中心疯狂收缩。
  - 收缩极快，引动更惊人的雷鸣，星空出现大片裂缝，裂缝内吹出无尽寒风。
  - 数万里雷霆压缩为一点，其威力可比天劫。
  - 正与**大头童子**、**塔山**交战的王林另两个分身也立刻退后，神色谨慎凝重。
- 雷池如巨浪撞入于非以三十五把飞剑与五个分身构成的五十丈地界：
  - 一把**赤红飞剑**率先崩溃，随后三十五把飞剑尽数碎裂，化作雷光碎片倒卷。
  - 五个分身齐齐化作**五把赤红大剑**，刺在于非身外十丈处阻挡，旋即剧烈颤抖、隐有碎裂之声。

## 二、转折：天地雷树残枝

- 于非神色如常，一拍储物袋取出一根看似寻常、却透出浓浓沧桑的树枝。
- 自陈其来历与效用：「**我杀域界至宝之一，天地雷树残枝**，**界主**曾言，此物可遏制你的雷霆」。
- 树枝抛出的同时，十丈外五把赤红之剑一缩后退，让开雷霆。
- 所有雷霆仿若脱离王林操控，齐齐改向涌入树枝，被其**全部吸收**；于非立于枝旁，雷霆对他视若无睹，未伤分毫。
- 王林面色阴沉。于非断言：「以你**窥涅初期**的修为，除非出现奇迹，否则在我面前什么都不是」，随即一步穿透雷霆，五剑呼啸直逼王林。
- 王林后退，平淡道：「**我，给你一场奇迹**」，脚下泛起波纹，身影骤然消失。于非元力冲出、数十丈内形成风暴崩溃，仍寻不到王林踪迹。

## 三、落月宗丹房：红发本尊的隐居

- 地点：**联盟星域**内距**朱雀星**极远处的一颗修真星，灵气较浓，为一处**六级修真国**；其上有六个五级修真国。
- 其中五级修真国门派**落月宗**后山炼丹房内，盘坐着一名红发如血、神色冷峻、约三十许岁的男子——王林**本尊**，对外身份是丹房**外门杂役「王林」**。
- 其身周「寒气」的真相：并非真寒气，而是**古神吞噬灵气**时自然吸引来的游离灵气；因药院丹房本就灵气浓郁，故不甚显眼。
- **宋莹**：落月宗女修，粉色蝶衣、年纪不大、右眉上有点点晶片，肤如白玉、发似流云。
  - 所修功法与寒气有关，原本停滞不前；师门内可修炼寒气之地以她的身份进不去，偶然来此取丹药时发现体内寒气大增，从此几乎每日来丹房外盘膝吐纳。
  - 察觉异常：王林名为杂役却从不做事，负责丹房的师叔反而对他极为恭敬——她断定王林身上有很多秘密，越冷越想解开，整日脑中都是那道冰冷身影。
  - 本章她心跳加速，摸着怀中之物（亲手采摘灵草缝入的**荷包**，可定气凝神）鼓勇欲言，话未出口，王林推门而出、腾空消失，她神色黯淡。

## 四、本尊与分身融合

- 本尊一步冲出修真星，现身星空；前方波纹回荡，面无表情的王林（分身）走出。
- 二人相碰、彼此走进对方，青光闪烁中化作一人——**阔别数百年后，分身与本尊再次融合**。
- 融合效果：
  - 极强气息弥漫星空，全身砰砰巨响，仿若无数雷霆在体内回荡，大量雷光游走全身。
  - **左目含日，右目蕴月**；红发与分身黑发融合成**紫发无风自动**。
  - 眉心**古神之星**被**第三目本源**隐藏，丝毫看不出端倪。
  - 意义：本尊与分身之合，亦是**古神与炼气士**之凝聚。
- 王林冰冷之声化作无尽巨响回荡星空：「我给你一场奇迹」，一步之下身影消失（悬念转下章）。

## 五、要点与伏笔

1. 于非的底牌来自**杀域界**，且其**界主**对王林雷霆之力有预判——外域势力已针对性布局。
2. 王林此时境界为**窥涅初期**，被于非以修为压制；「奇迹」即本尊回归、双身融合。
3. 落月宗一线埋下宋莹这条线索人物（爱慕 + 追寻秘密 + 未送出的荷包）。
4. 王林同时存在多个分身：与大头童子、塔山交战的两个分身仍在场，本章融合的是隐居落月宗的红发本尊。
