# 仙逆 第423章 聪明莫若帝王

## 一、朱雀玄印硬接九剑

遁天以云所化的九把飞剑（比闪电更快）杀至，朱雀子右手掐诀在身前虚空画出奇异印诀，庞大气息笼罩全身。一声洞彻整个**朱雀大陆**的轰鸣后：

- 朱雀子如流星般连连倒退，印诀崩溃消散；身子未伤，但面色苍白，先前的飘逸之色一扫而空。
- 九把飞剑消失，重新化作一道道魂魄弥漫天地。
- 遁天苦涩认出：**朱雀玄印**。

### 朱雀玄印设定（重要 lore）

| 项 | 内容 |
|---|---|
| 来历 | 并非一代朱雀所创；朱雀星成为**六级修真国**后由**修真联盟**赐予的神通 |
| 获取方式 | 非修炼而成，每一代朱雀子在**一代朱雀之墓**内，从一代朱雀遗物中感悟而出 |
| 印诀数 | 只有两个：一**攻**、一**守** |
| 威能 | 攻——无坚不摧；守——比朱雀奇阵笼罩一人还要强一分 |
| 限制 | 修炼不提升修为；一个六级修真星上每代仅一人可掌握，一旦掌握除非此人死亡绝无第二人学会；上一代朱雀子在下一代掌握后会丧失此神通 |
| 代价 | 传闻使用会造成某种损耗，具体只有修炼者自知 |

此战朱雀子所用为**守字印诀**。他不到万不得已不愿动用朱雀玄印，尤其攻字诀——他要保持巅峰状态与**仙遗族**一战。

## 二、劝降与拒绝

遁天大笑：「老夫寿元断尽之前，能看到你这老贼如此狼狈的一幕，倒也痛快。」

**朱雀子的招揽**：
- 炼魂宗本是朱雀一脉；数万年前炼魂宗先祖曾与一代朱雀共同迎战仙遗族。
- 条件：交出**尊魂幡**；回报为重建山门、重新招纳弟子，甚至可让炼魂宗自成一国。

**遁天的反制判断**：朱雀子是怕受伤；仙遗族大战已经开始，他不去战场坐镇跑来此地，待不了多久。

**朱雀子的底牌宣示**：仙遗族**十一叶老祖**虽强，但他还有一个「绝杀之法」，一出则仙遗族必死无疑。最后一次逼问尊魂幡交与不交。

遁天虚晃右手，十亿尊魂幡上闪起一点明暗不定的紫金之芒，警告「不要逼我用出**第四魂**」。

## 三、朱雀子的真实算计（本章题眼）

- 他此行等的**就是第四魂出现**；与尊魂幡相比，所图正是第四魂本身。
- 历代朱雀子都曾暗中研究尊魂幡内的第四魂、想尽方法破幡；朱雀子此刻已有**八成把握**收取它。
- 更深一层：他要的不是「现在的第四魂」，而是让其**吞噬完尊魂幡内全部魂魄**后、强上数倍的第四魂。
- 因此他口头示弱又激将（「你若到问鼎初期我立刻掉头就走／现在速度不够杀我」），实为诱使四魂继续吞噬。
- 作者点题：在算计上，**遁天不如朱雀**——所谓「聪明莫若帝王」。

## 四、第四魂·三金灵魂

### 召出代价
遁天左手点眉心取出一团晶莹白光按在尊魂幡上——那是他**最后一点寿元**，作为祭品。第四魂非寻常之法可调动，必须以寿元祭出。此后遁天双目黯淡无光。

### 五行灵根等阶（朱雀山典籍所载）
> 人分五行，五行相生相克，成就各自不同的五行灵根：
> **得一者可修仙，得二者为聪颖，得三者为天资，得四者为绝世，得五者为圆满。**
> 同一属性得两份少见，三份罕见，得四份从未听说，得五份同一属性绝无仅有。

### 第四魂身世与威能
- 身份：罕见的**同一属性得三份者**——「三金灵魂」。
- 生前平庸，未展现属性之强，与常人一样在**婴变后期**身亡。
- 死后被**炼魂宗以秘法炼制**，成就可威胁**问鼎后期**修士的绝代四魂。
- 形态：拇指长短、细线般的**紫金之针**，锋利气息远在朱雀剑之上。
- 特性：三金之魂为天下至坚之物，一切物质皆可穿透；其上魂气可伤**元神**。
- 收取条件（典籍）：需有**大毅力**，且须在**寿元将要断绝之时开启「修星之心」**。

## 五、交锋经过

1. 遁天喝「四魂，杀」，紫金针原地消失。朱雀子召**朱雀剑**挡在身前，铛的一声，剑上被穿出一个**针眼**。
2. 朱雀子右手食指前点，仙力涌动凝聚四周，狠狠一弹，退后三步；紫金之芒再次隐去，但仍在四周。
3. 朱雀子出言激将后，遁天连点数下，弥漫四周的魂魄开始一个个诡异破碎——每一点紫芒闪动即碎一魂，紫光越来越快，最终只见一道连成一线的紫线。
4. **吞噬战果**：短时间内十亿魂魄被吞掉**三分之一**，另有**十个婴变主魂**被吞；此等损失数万年未有。四魂速度快到不可思议。
5. 遁天心痛喝「四魂，停」，四魂一顿嗡鸣后转扑朱雀子——朱雀子暗叹目的落空，却不便再劝，恐暴露意图。
6. 朱雀子边退边点，身上被穿出多处针眼伤口流血，每中一针面色更难看、气息更弱。
7. **关键伏笔**：交锋中，朱雀子的**一丝诡异鲜血**留在了第四魂之上。
8. 朱雀子拍储物取出巴掌大小的红色小壶——**仙宝火壶**，打入法诀喝「炼」，白色火焰宣泄，百丈内化作火海，温度比先前朱雀羽毛更浓郁，扬言要生生炼化第四魂。
9. 火海中紫金之芒通红而不消融；那一丝朱雀子的鲜血却在炼化中**悄然无息融入第四魂之内**。
10. 第四魂迅速转动，生出旋风把火海吹出一道缺口；遁天大喝「魂，遁」，紫金针一闪消失，再次冲向朱雀子。

## 六、待观察的线索

- 朱雀子融入四魂的「诡异鲜血」用途未明——极可能是历代朱雀子收取第四魂之法的关键步骤。
- 朱雀子所称对付仙遗族的「绝杀之法」尚未揭示，疑与第四魂相关。
- 遁天寿元已尽，第四魂被停在吞噬三分之一处，结局未定。

# 第423-424章 朱雀子夺第四魂 / 仙遗族祖灵树合围朱雀大陆

## 一、朱雀子与遁天：魂幡与第四魂

- 朱雀子目光一闪、哈哈大笑，表示遁天不愿交出魂幡则不强求，**但第四魂必须拿走**。
- 施法流程：
  1. 拍储物袋取出**巴掌大小的黑泥**；
  2. 咬破舌尖，喷血落于黑泥之上，泥上飘出一道**黑烟**；
  3. 右手虚空绕黑烟牵引虚画，形成一个**诡异符号**；
  4. 口宣：「老夫以这一代朱雀子的名义，**祭献所剩十分之九的寿元，开启修星之心**，我要一瞬间修真联盟赐予的**停止意境**」；
  5. 符号极速射向身前三丈虚空并消失。
- 效果：**方圆百丈之内一切生灵瞬间凝固停止**。符号消失处**紫金之芒**一闪，**第四魂**现身，被朱雀子一抓入手，时间随即恢复流动。

### 转折：闭关处的一声喝斥
- 朱雀子踏步、面露狰狞，抓向遁天；遁天苦涩回望被火焰炼化的洞府禁地，闭上双眼待死。
- 就在此刻，**王林之前闭关之处**传来阴森笑声：「**给老子滚**」。
- 朱雀子**面色大变、元神刺痛**，眼中露出成为朱雀子以来**从未有过的惊骇**。（第424章标题为「司徒南」，暗示此声与石珠/司徒南体系相关，正文未点明。）

## 二、朱雀大陆东部：仙遗族的祖灵树大阵

### 布阵场景
- 地点：**朱雀大陆东部**，连绵不绝的**黑雾**之中；四面八方的仙遗族族人向此凝聚。
- 黑雾中心：无数族人盘膝而坐，口诵诡异咒语，**催动体内符文之力**，符文离体聚合、绕四周高速盘旋，一圈圈向上蔓延。
- 轮换机制：**每过两个时辰**族人符文之力耗尽，退下换新一批继续咒语运行；**已持续数月**。

### 仙遗族五祖
- 外形：灰衣中年男子，**全身几乎无任何符文印记**，惟左脸颊有一枚**紫色树叶烙印**，时而闪烁紫光。
- 随行：三名老者，气息与**当年追杀王林的八叶驼背老者**一模一样（后文称「八叶术咒师」）。
- 关键台词：
  - 「**祖灵树乃是虚祖放弃生命，以肉身破除五剑封印释放而出**，此番绝不容失败。」
  - 对二祖：「不用管他了，他在朱雀国时间太久，一些想法与我们不大一样……**若非他从中作梗，几年前那次战争就完全可以把朱雀国抹杀**。」
  - 「朱雀国的**修星之晶**，我就不信，此物能有他说的那般威力。」
- 部下判断：「**四颗祖灵分树包围朱雀大陆**，这一次，**朱雀国必灭**。」四祖处的祖灵树已开启，时辰已到。

## 三、尸阴宗来客

- 自朱雀大陆东部之外驰来一座**长约几十丈的巨大棺木**，上坐三人，皆头发花白：
  - 为首者：**尸阴宗朱雀星长老（司马长老）**，修为**婴变初期**；
  - 另二人：**守尸执事**，修为**化神后期**。
- 黑雾外符文闪烁形成阻力拦阻，司马长老自报身份后，符阵开出通道放棺木飞入。
- 会面于黑雾中心：司马长老对五祖及三名八叶术咒师称「途中遇到些阻拦，所以来的稍晚」，并言明此行**除送尸体外，还要告诉仙遗族一件事**（内容本片段未展开）。

## 四、要点与悬念

- 朱雀子为一魂之得付出**九成剩余寿元**，代价极重，可见「第四魂」与修星之心/修真联盟体系的分量。
- **停止意境**为修真联盟赐予、需以修星之心开启的一次性时间停滞手段，作用范围方圆百丈。
- 仙遗族对朱雀国的围杀是**族级、跨数月的战略布局**（四祖灵分树 + 祖灵树本体），且内部存在**二祖与五祖的路线分歧**。
- **尸阴宗与仙遗族已有往来**（送尸、通报消息），两方结成事实上的合作关系。
- 王林出关之声惊退朱雀子，为遁天解围埋下伏笔。

# 王林异变震慑十四代朱雀子：叶无忧与第四魂之约

## 一、前情铺垫：尸阴宗透露朱雀子夺幡

- 尸阴宗长老似笑非笑地对仙遗族一方的中年男子说：**朱雀子已去炼魂宗，与遁天老鬼大战，准备抢夺「十亿尊魂幡」**。
- 中年男子神色如常，只问「结果如何」。
- 尸阴宗长老称结果未知，但以尸阴宗对朱雀子的了解，**此人绝不做无把握之事，想必有八成把握成功**，并顺势警告：「你们仙遗族，要小心了。」

> 注：本段落对话末尾，叙述随即切到「元神的刺痛，这种感觉朱雀子已经早就忘记」——该中年男子的视角与后续言行在文中即为**朱雀子**本人。

## 二、异象降临：毗卢国方向的可怕气息

- 中年男子（朱雀子）忽然面色大变，猛地抬头**遥望朱雀大陆北部毗卢国方向**，感受到令他颤栗的气息。
- 元神刺痛之感，让他仿佛回到尚未成为朱雀之前、面对上一代朱雀时那种**面对天威般的惊骇**。
- 他强压震惊，沉着脸喝问：「阁下是谁？」

## 三、王林登场：狂到极致的异变姿态

七彩光芒闪动间，王林现身半空，形貌与气息全变：

| 特征 | 描述 |
| --- | --- |
| 头发 | 一头长发无风自动，飘散中露出诡异到极点的气息 |
| 光环 | 全身散发**深蓝色光圈** |
| 寒气 | 阴寒至极、可冰封天地的寒气自体内散出 |
| 身体 | 通体透出晶莹光泽 |
| 双目 | 不再黑白分明，而是**带着邪气**；与乾风的邪气相比，如皓月之于萤火 |
| 气质 | 邪气只代表一个字——**狂**：天上地下唯我独尊、不把任何人放在眼中的无法无天 |

- 王林随意一瞥朱雀子，这一眼「比闪电还要明亮数倍」；朱雀子身子一震，如同当年面对上一代朱雀子，**双腿蹬蹬蹬退后数步，额头无数年来第一次沁出冷汗**。
- 朱雀子失声：「你……你是王林？不，你不是王林，阁下到底是谁？」
- **遁天的旁证**：他与王林接触时间不短，一眼看出眼前之人绝对不是（平常的）王林——王林绝不会有如此可怕的气息与桀骜，「这种气息与桀骜，只有那些修炼了无数年的老怪，才可以拥有」。

## 四、关键信息：「几代朱雀」与「叶无忧」

1. 王林以不容拒绝的语气问：「老子问你，你是几代朱雀？」朱雀子有心不答，却不由自主地回答：**「十四代朱雀。」**（文中作者夹注：之前写的是八代，有误，后修改。）
2. 王林沉默少顷，冷冷道：**「看在叶无忧的份上，老子今日不杀你，滚吧。」**
3. 遁天对「叶无忧」一名毫无印象、从未听过。
4. 朱雀子闻此名**面色从未有过的大变**，退后数丈，惊骇彻底暴露。

### 「叶无忧」的设定要点（本片段确立）

- **叶无忧 = 一代朱雀的本名。**
- 整个**朱雀星只有历代朱雀子知晓此名**，外人绝不会知道；即便当年其他门派的老祖也无一人知晓，只知有一人道号「朱雀子」。
- 朱雀子结合王林体外扩散的一圈圈**蓝色光环**，与脑中回荡的历代朱雀子传承资料，最终**锁定在一个身份之上**（文中未明写该身份名号，仅以「老祖」「传说中那人」指代）。

## 五、结果：跪拜「老祖」与第四魂借三年

- 朱雀子几乎毫不犹豫，恭敬鞠躬苦涩道：**「参见老祖，晚辈这就离开。」**随即后退。
- 遁天眼中精芒一闪，喝道：**「把第四魂留下！」** 朱雀子脚步一顿，眼露挣扎，猛地转身看向王林。
- 王林眼中露出追忆的惆怅，裁决道：
  > 「当年叶无忧对老子有大恩，罢了，你要这第四魂，也是为了对抗仙遗族，我便借你三年，三年后给我。」
- 遁天欲争，被王林目光一扫生生止住——那目光中他看不到任何「王林」的感觉，只有陌生气息，仿佛再多言便会被毫不犹豫抹杀。遁天心神一颤，不敢再言。
- 朱雀子松了口气：若对方强行索取第四魂，他真不知如何抉择，很可能要斗上一斗，但**与「传说中那人」斗法，他半点自信都欠缺**。

## 六、要点归纳

- **人物状态**：王林此刻处于某种异变/被古老意志主导的状态（狂傲、蓝色光环、阴寒、邪目），连熟人遁天与老怪朱雀子都判定「不是王林」。
- **实力位阶**：一眼之威即可压制十四代朱雀子，令其冷汗跪拜；朱雀子对其斗法毫无信心。
- **因果线索**：王林（或其此刻所承载的存在）与**一代朱雀叶无忧**有旧，且受过叶无忧「大恩」，因此对十四代朱雀子网开一面。
- **待兑现的约定（时限）**：**第四魂借给遁天三年，三年后归还王林**；用途是对抗仙遗族。
- **未决悬念**：朱雀子夺取十亿尊魂幡的最终结果未在本片段交代；王林所被锁定的具体身份未明写。

# 第424-425章「童子」剧情梳理

## 一、司徒南冒名王林之身吓退朱雀子

- **背景**：朱雀火降临前，王林已元神归体、成就婴变大道，但无力参战，遂躲入天逆珠内避火；司徒南恰在珠内苏醒。
- **虚张声势**：刚苏醒的司徒南空有威严、实则极度虚弱，二人来不及叙旧，他便察觉外界危局，径直进入王林肉身，以桀骜之态对朱雀子发难。
- **断指之辱**：朱雀子已猜出对方是二代朱雀，抱拳欲走被喝住；先自削两指，司徒南仍不满，「再留下一个」，朱雀子咬牙再断一指，方被一声「滚吧」放走。
- **王林视角**：全程极为紧张，而司徒南毫不担心。事后王林问其为何不惧反噬，答曰：「因为老子是司徒南。」

## 二、朱雀子的疑心与去向

- 逃至十万里外咆哮：「二代朱雀，他怎么会还活着，怎么会还在朱雀星」——点明当年三代朱雀算计二代朱雀、引来域外修士之事。
- 飞至朱雀国上空时回望毗卢国方向起疑：以典籍所载二代朱雀的性格，绝不会对他心慈手软，怀疑对方是刚苏醒的虚张声势。
- 终究无胆回头试探，一跺脚撕开巨大空间裂缝，恶毒盯着毗卢国方向，飞向朱雀山。

## 三、遁天识破身份与炼魂宗道统之诺

- 王林（司徒南退出前）自半空栽落，遁天接住，见其状大骇失声「夺舍」，欲点眉心相助，被王林/司徒南制止。
- 司徒南以青芒自王林眉心飞出，化作中年粗犷魁梧身影；气息一现天空云聚电走、落雨，其一吼之下云散雨收。
- 司徒南斥遁天鲁莽，称若依旧日脾气一掌拍死；言若被「小麻雀崽子」（朱雀子）看出端倪，他刚苏醒便要再次沉睡。
- 王林代为道明身份：「他是司徒南」「二代朱雀」——遁天修道千年闻所未闻「司徒南」之名，闻「二代朱雀」则连退数步、震惊至极，遂深深一拜自称「晚辈炼魂宗遁天」。
- **承诺**：看在遁天为王林护法、并送出十亿尊魂幡的份上，司徒南答应若有机会必助炼魂宗重新恢复道统。此诺夹带真切追忆——当年若非炼魂宗好友相助，他在域外修士的那场战争中连藏入天逆的机会都没有。

## 四、遁天坐化

- **半生因由（闪回）**：夜雨宫道，强盗屠杀，少年于雨中哭泣；一老者抚其头，只问一句「你可愿随我」。少年入炼魂宗后天资聪颖、刻苦修行，成就化神之境方拜那老者为师，赐道号「遁天」，追随左右。恩师之魂入尊魂幡前，他立誓以此生守护炼魂宗。
- **心愿了结**：寿元断绝之前不惜血本结交王林、寄以厚望，只为给炼魂宗留下一丝香火。朱雀子来临本已令其绝望，二代朱雀亲允道统不灭，遁天知足。
- **结局**：盘膝含笑坐化，自陈「甘愿抹去神智，成为尊魂幡之魄」，一道紫金之芒自眉心飞出没入尊魂幡；尸体随风消散，有关此人的一切被全部抹掉，只余王林记忆中的身影。

## 五、尊魂幡归属与王林之誓

- 尊魂幡虽失三分之一魂魄、十个主魂、失去第四魂，仍是尊魂幡，代表炼魂宗道统；三丈大幡似有灵性，主动飘向王林，被其抬手握住。
- 王林跪地磕三头：「前辈虽非我师，但对我却有师徒之实，王林此生，绝不忘。」
- 望向朱雀国方向立誓：「朱雀子，灭炼魂宗之事，我王林终有一日，会去找你。」
- 司徒南轻叹：「你能遇到此人，是你的机缘，他值得你记在心中。」

## 六、司徒南的下一步打算

- 找一具匹配自己灵根的肉身，恢复修为。
- 而后把当年那几个算计他的人一一杀光；若已死，便拿其后人泄愤。
- 对第四魂不急：待肉身与修为恢复，直接杀上朱雀山抢回。
- 明言不要天逆珠——「就是那珠子害的老子如此狼狈，你给我，我都不要」；王林则称天逆珠已与其神识融合、无法取出。

## 七、要点提示

- 本片段中「以王林之身行事、逼朱雀子断指」的桀骜言行，实为**司徒南**所为，不应记作王林本人的行为。
- 司徒南的近乎魔道的思想灌输，被点明是王林日后杀戮滔天的重要成因。

# 第426章 修星之晶（剧情梳理）

## 一、谢与拒：天逆珠子不能要
- 王林轻声向司徒南道谢。司徒南表面桀骜（「干什么」眼皮一翻），实则沉默。
- 司徒南这些年已略有猜测：**天逆珠子（石珠）是天地之间的重宝，甚至可能超越仙宝**。
- 但他为人虽桀骜霸道，**对「恩」极重**：当年一代朱雀对他有恩，他便放弃离开的机会，留下守护朱雀星。
- 与王林关系复杂，也正因此愈发密不可分——在他眼中王林几乎是他看着长大的，**是他的弟子**。因此天逆珠子他不能要。

## 二、报答条件：给老子找个肉身
- 司徒南提出的报答：**替他找一具肉身**。自称如今虽无法与人为敌，但神通犹在，找到合适肉身夺舍「易如翻掌」。
- 当即双目精芒一闪、**神识横扫朱雀星**寻找目标。
- 王林建议：朱雀子有个弟子名**乾风**，肉身不错。
- 司徒南拒绝动朱雀子门下：一代朱雀对他有恩，「你杀他我不管，不过我要杀他，有些说不过去」。
- 转而在**朱雀星极北**发现异常：一具**童子肉身**，虽是童子，却是**上等的夺舍之躯**，且断定「这童子就是为了夺舍准备之物」，露出惊喜。
- 指明地点：**朱雀星「小北炎极之地」**，随即先行飞去。

## 三、赶路：蚊兽被镇与蚊兽星域玉简
- 王林一拍储物袋放出**蚊兽**为坐骑，盘膝坐其背追赶司徒南。
- 司徒南对蚊兽起兴，说「老子也去抓一只玩玩」。
- 蚊兽一向霸道，但感受到司徒南气息后**远远避开**，回头向王林求救。司徒南干脆落到蚊兽背上骂它。
- 王林取出一枚**玉简**（内容出自**古神涂司记忆**中那片遍布蚊兽的**陌生星域**），言「你若是敢去这里，多少蚊兽都能抓到」。
- 司徒南一扫玉简即**色变**、心神一震，尴尬作罢：「算了，不要了」，看蚊兽的目光转为古怪。

## 四、旧恩逼借：王林让步
- 司徒南改口商量：等他有了肉身，**借蚊兽研究一段时日**，保证不弄死它，甚至说研究后蚊兽可能更强大。王林连续两次拒绝。
- 司徒南先强硬威胁：他看中的东西从无人敢拒绝，当年看中**一代朱雀的小妾**也直接抢来，不给就一掌拍死。王林不语静视。
- 强硬无效后转为诉苦，历数旧恩（构成王林修仙路的关键因果）：
  1. 王林幼时是他**帮其调整身体**，使之可以修仙；
  2. 是他**出主意让王林学会夺基**；
  3. 多次帮王林避险，包括**藤家小儿（藤化元一方）追击**之时；
  4. **决明谷外**拼命差点身亡，才救下王林。
- 字字落在王林心头，王林头大苦笑，**无奈答应出借蚊兽**。
- 司徒南立刻恢复桀骜大笑「这才是老夫看中之人」，随后望向蚊兽露出阴森森的微笑；蚊兽身子一颤险些坠落，嘶鸣不止。

## 五、要点提示
- 本章确立后续线索：**司徒南的夺舍目标 = 小北炎极之地的童子肉身**（疑为他人预备的夺舍容器，来历可疑）。
- 本章的「司徒南」按世界状态须知：自第336章起以司徒南之名行事者实为**司徒南的断臂**幻化之人影（真伪未定），本章言行归其名下。
- 「一代朱雀」已于第397章死亡，本章为**回忆/旧事**提及。

# 第401章 极境之秘与仙遗族祭献

## 一、极境坦白

飞行途中，王林向司徒南问起「极境」。司徒南目光一凝，点明极境属于**极道始三境**之一，反问王林为何问起。

叙述指出：除李慕婉之外，司徒南是王林在这世上唯一可以完全信任之人。

- 王林一拍储物袋，取出一团**利刺般的白芒**——散发天劫般威压，对王林本人不算强烈，但其内蕴含的物质足以令**元婴期修士触之必亡**。
- 司徒南轻咦一声接过细看，面色大变，**立刻神识扫视四周**，随后抓住白芒拍向王林储物袋，直接突破王林神识将其收回。
- 司徒南惊问：「你怎么会拥有极境」

### 极境来历（王林自述）

1. 当年在**决明谷**内，王林体内产生一丝极境——彼时司徒南沉睡，故未察觉；
2. 后王林**肉身破碎**，被司徒南救走，司徒南再次沉睡；
3. 王林**离开域外战场**后，神识中的极境**大成**。

## 二、司徒南的警告

- 极境是**极霸道的物质**，司徒南对此并无研究。
- **修真联盟几乎常年搜寻极境修士**，一旦被其知晓，**立刻抹杀**。
- 告诫：此物**绝不能在任何人眼中露出**，尤其要防**朱雀子**。

### 极境与黄泉升窍决

王林怀疑极境与司徒南的**黄泉升窍决**有关。司徒南一怔后认为「倒也有些可能」，但断言其中一定还有未知原因——否则他自己为何没有极境。他补充：极境出现**几率极小**，且**修炼太难、得不偿失**；王林能将其从体内取出、不为此物所动，殊为难得（露出赞赏之色）。

## 三、修星之晶

王林问出**藏在心底数百年**的疑问：修星之晶能否使极境进化？此物究竟为何？

司徒南目露复杂，长叹：

- 修星之晶**不是个好东西**；
- 但王林**若想离开朱雀星，必须得到此物**，否则日后是隐患；
- 修星之晶是**修真联盟控制修真星最歹毒之物**。

（话未说尽，司徒南被远处动静打断，称「此事一会再说」。）

## 四、司徒南出手：借祖灵树

司徒南察觉前方**仙遗族正在祭献祖灵**，回忆当年**一代朱雀**研究过一门神通之术，可借**仙遗族祖灵树**吸收一些奇异之力（司徒南自称人老记忆衰退，「好像是这么回事」）。

- 向王林索要一块**仙玉**；王林自储物袋取出递上。
- 司徒南一吸之下，**仙玉碎裂成灰**，双目闪动仙力之芒。
- 提及该神通有一个**致命破绽**，但以他此刻之能「虽麻烦，应该可以避过」。
- 嘱王林原地等候，身影一闪消失。

## 五、朱雀星各方反应（司徒南对峙朱雀子的余波）

此前司徒南现身与朱雀子对峙时，**朱雀星上所有问鼎修士**都察觉到那股桀骜强大的气息。

| 势力 | 人物 | 动向 |
|---|---|---|
| 天玉宗 | 楚云飞（唯一的问鼎初期老怪，白发老者） | 现身朱雀国东部天空，面色阴晴不定，叹「很强的气息」，目露寒芒继续向东飞；随行数十修士（绝大部分化神期、三人婴变期），其后另有上百元婴期 |
| 地魄门 | 问鼎初期老怪（中年男子） | 率数百人修士大军疾飞朱雀大陆南部，遥望司徒南方位摇头苦笑：「倒霉，偏偏让我赶上这么个战乱时机」 |
| 朱雀国 | 朱雀子 | 回朱雀山略作休息后再次离开，目标为**朱雀大陆西方** |

## 六、朱雀大陆东部：尸阴宗交尸予仙遗族

地点：朱雀大陆东部，浓密黑雾之中。

- **仙遗族五祖**面色阴沉地收回目光（因察觉司徒南气息）；**尸阴宗司马长老**修为不足以察觉气息变化，只觉五祖神色难看而心生惊奇，正欲试探。
- 五祖袖子一甩，冷声令「开始吧」。司马长老大笑称此行「本就是为了送这尸体，希望可以让你仙遗族的祖灵树更加茂盛」。

### 开棺

1. 两名**守尸执事**自十几丈大小的巨棺上跃下，盘膝而坐，双手结出奇异法诀，道道灵光落于棺木；
2. 二人全身散发诡异幽光，齐喝「开」——棺盖缓缓移开，缝隙渐大，夹杂腐烂恶臭的**黑气**涌出；
3. 再喝「起」，棺盖如被无形大手推开，从半空砸落于地；黑气更浓，几要包裹整个棺木。
4. 五祖身后三名**八叶术咒师**面露紧张、暗自提防；五祖本人目光平静一动未动，冷声问「这就是你们说的尸体」。

### 尸体来历（司马长老所述）

- 这是**「上面」吩咐并决定**的事情，司马长老无权干涉；
- 尸阴宗在朱雀星上**婴变期的巨魔族尸体不多**，这一具是**从其他修真星转移而来**；
- **另有四具**，此时估计也已送到仙遗族的其他地方。

## 七、伏笔与看点

- **修星之晶**成为王林离开朱雀星的关键前置条件，且牵涉修真联盟对修真星的控制手段——话未说完，留待后续。
- 极境=修真联盟必杀的禁忌，朱雀子被特别点名为最大风险。
- 一代朱雀的遗留神通、仙遗族祖灵树、尸阴宗输送巨魔族尸体三条线在此交汇。
- 天玉宗、地魄门等问鼎势力尽数出动，朱雀星战乱格局成形。
