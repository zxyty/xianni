# 第1836章 分身镇压！！（第三更）

## 一、登阶入第八层

- 天地八荒抖动，幻化出通往天之尽头的巨大阶梯，王林白发飘动立于第一级台阶，如同仙神。
- 王林低头一望，目光所及者（附身女弟子的炎栾神识、大魂门全体弟子长老、走出闭关的老怪、青天峰洞府中的青牛老祖）皆脑海轰鸣、元神似要出鞘，纷纷后退低头。
  - 炎栾感觉：只要王林目光再停留片刻，其神识便会被生生轰出女弟子之体；同一个人却给了她两种截然不同的震撼，「此刻的王林已不是她之前所见的王林」。
  - 青牛老祖：面色大变，身后青气弥漫化作本源真身，随即走出洞府立于半空。他未去过道吉一脉皇城，若见过那漂浮半空城池内撑天的古祖雕像，便会认出王林虚影与古祖睥睨天下之势惊人相似（细节仍有不同），因而断言「此人绝不是王林，他是谁」。
- **隐秘**：此气势实来自王林的**分身**，出现之人仍是王林本人，外人不知。
- 王林闭目从容迈步，一步一阶，中途毫无停滞连走十五级；第十六至十八级时双目蓦然睁开，天地威压笼罩大地；第十九步落下，踏入**藏魂阁第八层**。
- 王林平静宣告：「炎栾，我赢了」。话音落时，附身女弟子的炎栾神识骤然消散，女弟子退后数步、眼露迷茫。大魂门先死寂后哗然：「连闯七八两层，这王长老竟然真的进入到了第八层」。

## 二、炎栾反悔与分身镇压

- 藏魂阁第六层的炎栾面无血色，立于通往第七层的入口处；手中葫芦被一股大力缭绕欲带走，她银牙一咬、狠狠握住葫芦不放（反悔）。
- 王林之声自第八层传出「恩？你要反悔？」，随即转身沿阶而下。
  - **规则补充**：藏魂阁只要有一次成功进入七八层，第二次无论上下都不会再于大魂门内出现天变；外人无从知晓。
  - 炎栾只能先看到楼梯尽头王林落下的右脚，便生出如面对浩瀚太阳般的错觉。
- 王林逐级下行，声音蕴含天威般的威严，「似凌驾在藏魂阁的禁制之上，似超越了仙罡法则」，追问「既然赌了，又要反悔……这赌约并非王某提出，是你自行提起」「你确定要反悔么」「你确定么？回答我」。第九级台阶上露出完整身体，炎栾连退数步、眼露慌乱血丝，嘶哑质问「你是谁」。
- **王林的真实用意**：以分身气势镇压炎栾、完全镇住其心神，在其道心内留下一道裂缝，使其日后再遇自己便心生畏惧、不敢与之对敌，从此对他再无威胁；彼此并无深仇大恨，不坏其道念，其日后修行如常。
- 王林再落两步、随意抬手道「拿来」。炎栾无法承受心神威压，右手松开，葫芦飞入王林掌中。
- 王林自评：这是他**第一次完全调动分身气势**、第一次用来镇压对方，其强大令他自己也心惊。
- 王林离去后，恐惧气息才散，炎栾身子一软退后数步，内心苦涩、神色复杂。

## 三、第八层所见

- 王林握葫芦转身，重新拾级而上，前往第七、第八层挑选神通功法。
- 第八层：地面满是灰尘，仿佛久无人至；层不大，漂浮着**九个七寸魂体**，散发柔和光芒。
- 九个魂体各蕴含大魂门一种极为强悍的道法神通，任意一个都可毁天灭地。
