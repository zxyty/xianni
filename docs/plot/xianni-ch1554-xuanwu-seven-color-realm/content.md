# 仙逆 第1554章 玄武

## 一、炎雷子与重玄子的旧怨（送别）

- 重玄子临走时回头复杂地看了炎雷子一眼，声音带着**对其师尊的悔意与悲伤**：“炎雷子，当年之事，不是如你所见。”
- 炎雷子目光始终追随重玄子二人离去的方向，眼中仇恨极浓。
- 王林并不知晓二人因果，但由**炎雷子逃到罗天后拼尽一切、最终发动罗天与联盟大战**这一结果，判断此仇深如海。王林暗叹：“此事，我无法帮你。”
- 炎雷子将仇恨深深隐藏，向王林抱拳道：
  - 与重玄子之间是**私事**，请封尊不要放在心上；
  - **眼下大局为重**；
  - 若此番大战结束时自己死、或重玄子战死，则一切烟消云散；
  - **若二人最终都没死，那便是索仇之日**。
  - 他修道多年，能忍万古，不在乎多忍耐些时日。

### 回忆：二人交恶之前

- 炎雷子与重玄子本是**至交道友**。
- 正是因**重玄子的邀请**，炎雷子才与**其道侣**二人一同加入**修真联盟**。
- 三人时常论道；炎雷子相惜于重玄子的博闻与见解，**甘心听命于他**；重玄子对其也极为客气，二人如君子之交，淡如水却随岁月醇浓如酒。
- 这一切因**一件事情**彻底改变。炎雷子时常在打坐中惊醒，那深刻在记忆中的画面成为他心中之刺——刺已糜烂腐朽，染黑血肉，成为其一生之痛。（原文未言明具体何事）

### 分别

- 王林提点：“你若能**吸收那香火黑龙之力**，也是造化一番。”并言明自己要进入七彩界，**其内危机诸多，让炎雷子莫要跟随**。
- 炎雷子点头一拜告辞，背影没落苍老、萧瑟孤独，渐渐远去。
- 王林不去猜、也不愿猜二人恩怨的内情。

## 二、王林步入七彩界

- 王林转身走向七彩界，步伐不快但每一步都很坚定，**没有回头、没有犹豫，三步之下踏入**——这是他**一生中进入的第二个七彩界**。
- 七彩之芒弥漫天地，映照一切，绚丽多姿，极易令人迷失。

## 三、十万大山：血祭大阵

| 观察 | 内容 |
|---|---|
| 阵法规模 | 近**十万座大山**错落有致组成一个庞大阵法，浩荡无比 |
| 结构 | 每座山峰都是阵法的一部分；越深处山峰越雄壮，最深处山峰直插天际，七彩云雾缭绕只露半个山身 |
| 山顶之人 | 每座山峰顶部各有一名修士盘膝，身上有数根尖锐石刺自体内穿透而出，被强行禁锢在那里 |
| 状态 | 并非吐纳，而是**痛苦哀嚎**；抬头、无神双眼望天，发出无意识哀音，汇成惨绝人寰的凄厉之音（界外听不到，界内直冲心神，如十万冤魂咆哮） |
| 血 | 鲜血似流不尽，顺石刺蔓延流下山峰；单人之血虽微，但岁月流逝下汇成渭流；只要修士不死、体内仍造血，血便不绝 |
| 汇聚 | 一缕缕红烟自每座山峰升起，扭曲着直奔最深处**至高山峰**之尽、那七彩云雾之内 |
| 身份构成 | 十万修士中**一半眉心有印记，为界外修士；另一半来自联盟**，被凝固在此不知挣扎多少春秋 |
| 其他存在 | 漂浮如幽魂的虚影（**铭志者**）在山间飘荡、口诵喃喃道经；还有一个个**行尸走肉**衣衫破损、双目灰色，在山间迷茫走动、始终走不出去 |

## 四、禁制触发与突进

1. 王林迈入十万大山的刹那，仿佛触发某种**禁制**：无尽哀嚎骤然停顿。
2. 十万山顶修士齐齐转目，怨气取代迷茫，目光如利剑死死盯住王林；漂浮的铭志者也同时止住诵经、无神双目一一盯来。
3. 如同死人堆里突兀出现一个活人，被所有死修感应。
4. 距王林最近山峰的一名界外修士率先呜咽“**血……血……**”，继而十万修士同声呜咽、双眼通红、咆哮渐厉。
5. 一名山顶修士喷出鲜血化作血雾，雾内幽影闪烁；随后更多修士同时喷血，血雾弥漫十万大山顶部并**不断相互融合**。
6. 王林眼中寒光一闪，不再犹豫，一步迈出，**其速足以破开一切虚无天地**，赶在红雾完全融合前冲出颇远，踏入十万大山深处，直奔最高山峰。

## 五、真相：石化玄武

- 临近最高山峰时，王林深吸一口气：**此地十万大山并非与大地相连，而是被一只巨大的石化玄武巨兽托起**——十万大山压在玄武背上。
- 更确切地说：**这十万大山根本不是山，而是这庞大无比的玄武的背部之刺**。
- 玄武之大**占据了整个七彩界**。
- 在玄武狰狞的头部上，盘膝坐着一人：
  - 看似中年，体内散出**万古气息**；
  - 盘膝于此，**没有半点生机**；
  - 身体似与玄武连接在一起；
  - 一根利刺自其身下凸起，穿透其身、贯穿其体、破开头骨，于**天灵冒出三寸**。
