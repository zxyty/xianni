# 第1303章 封界大阵（第九卷 云海之巅）

## 一、血剑对四把天劫之剑

- **血剑登场**：此剑在裂缝世界内吸收众多凶兽血液，又于血海中滋养。一出鞘血光滔天弥漫天地，映照穿透星空上方滚滚云层。
- **一斩破空**：石剑裂缝中射出青色长剑扑向王林，王林血剑迎斩，星空被生生破开一道裂纹；青剑青光崩溃、缠满血丝败退，血剑无损追击。
- **二剑、三剑、四剑**：云层内白玉阁楼雕像旁的石剑接连爆开——蓝色长剑、黑色长剑、金色大剑先后杀出。血剑来历莫测、蕴含无尽之威，独抗两剑不落下风，三剑合围方渐渐后退，四剑齐出再被逼退。
- **阁楼露形**：云层深处裂缝中原只挤出一半的白玉阁楼随威压宣泄又露出一些，盘膝雕像身后所插石剑因此显现。

## 二、古神之血喂剑

- 王林一步迈出，眉心**古神星点**急旋至极限，右手食指点破眉心逼出一滴鲜血。
- 此血**并非元神精血**，而是古神星点内**古神之力**所化。
- 血剑吸血后爆发惊天威压，血光浓郁数倍，剑上幻化出模糊人形的**巨大血色虚影**，横扫之下三色之剑急退。
- 血剑有灵，尖啸如吼，对不如自己的三色之剑充满愤怒。

## 三、彼岸召唤（无量劫）

四剑漂浮环绕、高速旋转，凝成一个巨大漩涡，漩涡内一片混沌，隐见一个世界：无数星球，星球上无边无际的凡人，呢喃之声化作诡异声音，令闻者心神震动。

**召唤内容要点**（浩荡威压之声，落耳生温暖信任感）：

- 「彼岸之地，一量劫开启，一量劫合闭」；
- 入彼岸者：可得永生、可获大道、可摆脱世间一切痛苦纷争、可成其门徒；
- 入彼岸者：当为天地之骄、可取天道；
- 入彼岸者：**亡亲故朋皆可复活、皆可重生**，自在圆满，成就无上修真道；
- 入彼岸者：**轮回崩灭，无生无死**；
- 「心念彼岸，念之则来」。

**波及范围与后果**：

- 声音迅速弥漫整个**九阶星域**，穿透一切宗派防护大阵，传入每一个修士、每一头凶兽魂内。
- 妖宗大阵内避劫的数千修士眼神迷茫；一青年瞳孔涣散被漩涡取代，诡异咧笑后周身光芒一闪即消失；随后数百人以同样方式消失。
- **妖宗太上长老（中年男子）**神色凝重，喝破此为「无量劫中的彼岸召唤」，须凝定心神，否则道心不稳即被召入漩涡世界。其雷霆之声惊醒众人，但众人苏醒刹那又再度沦入迷茫。
- 失踪者不限妖宗：**鬼宗、神宗、破天宗**乃至**星雾**内众多凶兽，均有失踪。

**王林的抗性**：

- 身为**应劫者**，感受比外人清晰数倍；声音在其耳中并非苍老，而是不断变化为其母、其父、**李慕婉**、**王平**，甚至**朱雀老圣皇**的声音，交错成诡异音调回荡心神。
- 王林道心之坚胜过许多修道多年的老怪，「一生凶险，区区幻术，动不了他半点心神」。
- 冷声「有彼岸么」，持血剑斩向漩涡，剑光落处巨响回荡，漩涡反震大力撞来，王林退出数步。

## 四、紫色云山镇压

- 漩涡骤然加速旋转，升空消散于滚滚云层。
- 星空云层被牵引，从四面八方疯狂凝聚，化作一座**无限之高、通体紫色的云山**；山上大量符文烙印交错组成一个「**道**」字。
- 所有云层融入，云山几乎成为支撑星空的巨山，向王林狠狠压下，欲将其碾碎。
- 威压之强使距离最近的**妖宗大阵**咔咔崩裂、裂缝弥漫。
- 王林全身砰砰作响，被四面八方压力挤压，双脚所踏星空发出不堪承受之声，面色略显红润。

## 五、破开星空，直入封界大阵

**王林的算计**：他等的正是**天劫之力全部展开的一刻**。

1. 云山压下刹那，王林体内元力轰然爆发，血剑向下方一扫，脚下星空裂开巨缝；
2. 借自身修为弥漫 + 云山降临的强大威压，裂缝层层撕开、崩溃加剧，片刻后彻底打开，露出这片星域之下的**一片虚无之地**——**封界大阵所在**；
3. 阴寒气息冲出，王林一闪踏入虚无；已锁定他的云山随之轰然降下、撕缝跟入；
4. 虚无中网状之物闪烁而出，阻挡一切生灵破开；
5. 王林后退靠近网状封界大阵，双手掐诀化作一片烙印；云山落在其身上，王林如托山峰般双手抬起，身子一震喷出鲜血，将这股无法形容的大力**传递至封界大阵上**；
6. 整个虚无蓦然明亮，显出连成一片、无边无际看不到尽头的大网。

**封界大阵设定**：

- 包裹整个界内所有天地；
- 无数年来任凭界内修士如何冲击，**从未有一次可以大范围破开阵法冲入界外**；
- 唯有极个别惊艳之辈可凭强悍修为**破阵一人走出**；
- **古往今来借天劫之力欲破封界大阵者，从未有过——王林是第一个**。
