# 第1446章 螳螂捕蝉

## 场景
古神背部平台的红雾封印之地。众修士（灵动上人一方及散修）云集，争夺红雾内的**道灵**。天空布有一个个扭曲的裂缝，为进出此地的通道。

## 一、许姓肥硕修士破禁失败身死
- 手段：以算盘法宝，双手掐诀令算盘珠子急旋，化作**棋盘残局**般的图形，珠子如棋子星罗密布。每颗珠子内蕴含诸多禁制，可彼此组合，颇为奇妙。
- 首轮交锋：红雾冲出吞噬棋局时，棋局五光十色，浮现掐印记的虚幻身影，将红雾逼得倒卷，一度占优。
- 王林观察：此人破禁之法有可取之处，法宝非凡物；但红雾禁制含**古魂禁**与**岁月禁**，二者交合威力惊天，这等小巧手段绝无可能破开。
- 结局：棋局二次逼近即消失于红雾内，法宝被毁、与元神连接被生生切断，肥硕修士喷血欲退，被红云般扩散的红雾裹住拽入雾内，惨叫与咬碎骨头声中身亡。
- 灵动上人斥其“废物”，起意**索性强行打开，得不到便毁掉**（明知强开会重创道灵）。

## 二、中年文士萧靖的“破禁”与红雾风暴
- 萧靖以“先试一试、破开一点可减轻道灵损伤”为由请缨，灵动上人对其颇为信任，叮嘱谨慎。
- 表现：临雾推衍计算，一指点出令冲来的红雾触手在近身前崩溃消散；随后如游龙绕雾游走，不断掐诀点雾，雾内咆哮渐趋暴躁。
- **王林识破**：瞳孔一缩、嘴角冷笑——此人隐藏很深，看似破解，实则另有手段与含义。
- 关键一击：萧靖低吼请援“上人助我，展开香火之力可破开这禁制一半”。灵动上人毫不犹豫催动体内**香火之力**凝成浩然掌印，与萧靖双手几乎同时轰在红雾上。
- 后果：红雾外围环形崩溃、雾气消散小半；旋即红雾化狂风大口“吞噬”萧靖（表演性死亡），并吸收香火掌印后自内部爆发毁灭之力，形成席卷整个封印天地的**红雾风暴**，天地开始崩溃。

## 三、溃逃与封印闭合
- 多名修士闪躲不及，触及风暴即肉身崩溃、元神爆开。
- 灵动上人退至两千丈墓台后化虹冲天；**王林退速最快，甚至快过灵动上人一丝**，同时释放脚下酝酿已久的禁制直奔下方大地，随后化虹冲天，自一处扭曲裂缝离去。
- 伤亡：十多人被红雾风暴毁灭，**逃出者不足十一人**。
- 众人离去瞬间红雾弥漫全境无缝可寻；许久后雾气缩回古神背部平台，天空成暗红色，扭曲裂缝消失干净，入口被彻底封印。

## 四、螳螂捕蝉，黄雀在后
- 半个时辰后，萧靖自雾中走出，阴森得意：“灵动上人又如何……我萧靖看中的宝物，谁也无法与我抢夺”——**略施小计赶走所有人，独占雾内道灵**。
- 取出**九枚玉简**：自陈虽无法全破古魂禁、岁月禁，却能令二者**停止运行二十息**。玉简排成圆圈落在红雾上，雾气被幽光定住。
- 萧靖踏入圆圈，双手前撕，硬生生撕开红雾一道裂缝，探身欲入。
- **反转**：惨叫骤起——“不可能，竟还有禁制”。仅退三丈，面部血肉模糊、全身急速腐烂，轰然成一具腐尸。
- 二十息将尽，玉简光芒消散，红雾重新活跃。
- 一炷香后，腐尸睁眼、样貌急速变化，重新化回文士模样，目光一闪：“看来没人潜入这里”，再次走向红雾。（其“死亡”亦具伪装/复生性质，真正意图未止）

## 关键点
1. 红雾禁制的真正难度在于**古魂禁＋岁月禁复合**，且**尚有隐藏禁制**未被任何人算到。
2. 香火之力反被红雾吸收并转化为毁灭性反噬，是本章天地崩溃的直接导火索。
3. 萧靖以自身“被吞噬”作局，是标准的**螳螂捕蝉**局面；而他自己也被隐藏禁制反制，章末仍未得手。
4. 王林全程冷眼旁观、暗中布禁，既保命最先撤出，也留下了后手（下方大地上的禁制）。
