# 仙逆 第1853章 闹鬼

## 一、青天峰对话：藏魂阁第十层与三个条件

### 藏魂阁的隐秘
- 青牛真人道出：藏魂阁第九层的多重幻术为大魂门内最强之术，本可传王林，但一代老祖曾说王林要**三百年后**才进第九层。
- 藏魂阁另有**第十层**——连青牛真人自己也进不去，大魂门历代唯有**一代老祖**可踏入，那里是一代老祖的**坐化之地**。

### 玉简验功
- 青牛真人称王林功劳不足以换取第九层的完整多重幻术。
- 王林当即取出一枚玉简：其中记录了自己在**丹海斩仙丹**的全部情形。
- 青牛真人神识涌入后动容，以其修为判定内容全真；结合自身推衍的天地变化、暗子回报，以及王林伤势虽复十之八九却仍余一丝、短期难愈的事实，将丹海一切串联印证。
- 青牛真人连道三声「好」，一挥左手以磅礴天地之力入体，**瞬息治愈王林残伤**，并暗叹一代老祖选人不愧有魄力胆量。

### 三个离门条件
青牛真人许诺给出第九层完整多重幻术，但附一条件（实为三事），做到方可离开大魂门：
1. 击杀**十个绿魔洲空劫初期修士**；
2. 击杀**三个绿魔洲空劫中期修士**；
3. 进入**藏魂阁第九层、第十层**。

### 王林的抉择
- 王林归途已生离意：目标是**东临宗**与遥远的**道古一脉**，不能久留天牛洲；对此次战乱心有猜测，更不愿深卷。
- 青牛真人看出其意却不强留，改以三条件相约，令王林联想到那**三份礼物**。
- 王林沉默良久后凝重点头——大魂门于他有恩在先，以其性格必要报答；三事虽难，自认有完成可能。

### 赐术与赐材
- 青牛真人抛出古朴玉简：**多重幻术一至九重的完整口诀**。
- 修炼此术需炼制**鬼帆**，青牛真人索性送出全部炼器材料（品质绝佳），唯**鬼帆所需之魂**须王林自择，若无合适可去**鬼峰**寻找。
- 临别叮嘱：**七天后**将派王林与几位长老，前往**天牛七穴**中的某一穴镇守。

## 二、回峰：火海重燃与矾珊梦
- 王林离峰期间，其山峰火焰如熄、通体赤红；他脚步一踏，山峰立刻再燃火海，隐有轰鸣。
- 闭目的矾珊梦骤然睁眼，目露慌乱，咬唇久候不见王林召唤，内心不安。（按世界状态须知，此「矾珊梦」实为**矾珊璐**伪装，自第1606章起，第1698章已被王林揭穿。）
- 王林无暇理会，径入洞府盘膝，破开光团，炼制鬼脸帆的材料一样样悬浮于洞府之中。

## 三、鬼帆与死魂：多重幻术的设定

### 鬼帆品阶
- 正名**鬼帆**（鬼脸帆），品质分 **初、中、上、极、绝** 五档，每档对应**两重幻术**。
- 门中弟子大都只有初品；**中品**唯长老或各峰受重视的核心弟子由师尊赠予防身。矾珊梦当年那杆中品鬼帆，即**炎栾**所赠。
- 中品鬼帆施展得当便可**无视修为**（矾珊梦手中可为见证）；上品乃至极品配合多重幻术则恐怖至极。
- **绝品**极难炼制，整个大魂门仅有一杆——即**大魂门护山大阵**；王林所见此阵尚未开至极致，只发挥了部分威力。

### 死魂
- 鬼帆需魂方成，但所需并非修士之魂、亦非修为越高越好，而**必须是「死魂」**（王林首次听闻此词）。
- 定义：人或兽在**死亡一瞬**，因执念、不甘或怨气所形成的、外人看不到甚至感受不到的另一种存在。
- 极难获取：**多一丝成无用冤魂，少一丝则无法凝聚**。
- 大魂门古往今来无数人研究，终得一种在人或兽**死亡前**炼制死魂之法；但此法所得死魂少了岁月磨砺，无论取自何等修为之人或兽，都只能制**初品**鬼帆、至多中品——因其最多只能承受**三四重**幻术叠加，多则自身崩溃。

### 王林的推演
- 死魂可看作一种**意志**；意志强大且经岁月磨砺者，方能承受四重以上叠加。
- 多重幻术的原理：以这股意志为**养料**，层层产生幻术，令人迷失其中；**意志越强，幻术越强**。
- 王林赞叹此术巧妙玄奥，非见完整术法难以琢磨，断言「创造此术之人必定是天资惊艳之辈」。

## 四、闹鬼之悟（本章题眼）
- 术理引动王林幼年记忆：未入修道时，村中大人常谈某家「闹鬼」，需去县城请人驱鬼图个心安；他自家亦曾有此事。
- 王林之解：所谓闹鬼多是迷幻一类，令人看到奇怪画面沉浸难拔；「闹」意味不安静、动与乱，也是心理不安烦躁的表现。
- 修道后回想，那怨气实为天地间存在之物，某一刻左右人之心神，使其内心不安动乱，自然生出「鬼」与一系列幻觉。
- 结论：**这正是多重幻术最深的核心，也是幻术的由来——所谓多重幻术，说穿了是「以鬼幻人」之法**。说来简单，但能将此现象化作法术神通乃至道术者，当敬。

- 待办：自寻死魂炼鬼帆（可往鬼峰）、完成三条件（十名空劫初期 + 三名空劫中期绿魔洲修士、入藏魂阁九层十层）方能离开大魂门，之后再图东临宗与道古一脉。
