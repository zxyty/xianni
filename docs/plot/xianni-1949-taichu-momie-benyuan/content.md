# 第1949章 太初与默灭

## 一、东临池的本质
- 东临池并非传授传承，而是把**完整的太初本源**直接展现于修士面前；能看出多少、明白多少全凭个人，与池本身无关。
- 三种结果：一次即见光而留下太初本源『萌芽』；如王林前几次那样一无所获、仅本源略增一丝；也有人在仅两次机会中获得大半感悟，带走萌芽之外还有『悟懂』。
- 古往今来是否有人完整带走全部太初本源，王林不知。

## 二、王林的连续沉浸
- 第四次结束后仍觉『还差一些』，遂行第五次。
- **第五次以骗道之术避开池水气息的检查**，瞬息间左目即见无尽光芒。
- 沉浸中听到低沉声音自述（自称『杜某』）讲述太初由来。
- 第六次继续沉浸；随沉浸次数增多，奇异状态持续时间渐长。

## 三、太初本源的来历（杜某之述）
- 太初本源从虚无中诞生。上古天地无仙，古人望阳而拜，以虔诚膜拜求取太阳光热，遂生**太初之力**——古人膜拜天阳的第一缕力量，初阳抬头的第一次展现。
- 岁月变迁、奇异之人出现，天地运转规则中遂有**太初规则**，使天阳升落。
- 杜某观察后明悟：天阳升落实为**心动所致**——因心动，故大地动、苍穹动，那不动的天阳也有了起伏。
- 一次次观看无数次初阳后，杜某明悟**太初本源为一切光热之开端**。
- 初阳之气含**浩然正气**，刚正不阿、顶天立地；长久沉浸初阳破晓者，性格必有所担当、不愧于心。

## 四、王林与太初之力的旧缘
- 当年在**洞府界**自创**残夜神通**，正是太初之力的展现。
- 感悟渐多后摸索到**太初规则**，更在**仙罡大陆**使残夜之术具备了**信念**。
- 本章方知太初亦可产生『本源』。王林对本源的定义：对一物的了解感悟深奥到看透其一切变化，甚至抬手可施展。

## 五、化身初阳（关键转折）
- 次日黎明破晓前、天地一片漆黑（距真正初阳升起尚有约一炷香）时，王林睁眼——左目散出万丈之光，瞳孔中出现一个太阳。
- 王林**整个人化作初阳**，自东临池飘起升空；黑幕层层消散后退，大地漆黑如融化般被驱散，**提前半个时辰**照亮天地，历时约一炷香。
- 阳光扫过东临殿时，**东临宗老祖**睁眼沉默，叹『即便是我，也分不清这驱散黑夜的力量到底是真正的初阳，还是神通变化——他明悟了』。
- 随后真正的初阳升起，天空**赫然出现两个太阳**。
- 王林闭目立于天空一整日，直至夕阳落、天地复暗，才下沉重回池中盘膝。
- 旁观者反应：刘金彪心神一颤不敢直视；金尊海龙连连避开。

## 六、转向默灭本源
- 王林推论：太初本源代表**日出**，则必有一种特殊本源掌控**日落**。
- 左目一片光明、右目始终模糊；他判断『左目看到的是日升的光明，右目将看到的必定是日落的黑夜』。
- 深夜万物寂静时再度沉浸，右目所见由模糊转为**一片漆黑**，与左目光明鲜明对比，心神似被分成两份（日升之光 / 日落之暗）。
- 杜某之声再现：『杜某在归虚之间行走，看那日落后的一处处黑夜，明悟了太初之后，则为**默灭**。这默灭本源，代表了一切黑暗。』

## 七、滞留与岁月
- 在东临池共滞留**三个月**：初阳时化身天阳升空驱散黑暗，夕阳时默观黑夜吞噬光明，四次观看加多次池中感悟，对默灭本源渐有深刻了解。
- 结果对比：**太初本源已初步掌握且越来越深刻**（因早已了解并使用太初之力）；**默灭本源仍在感悟摸索中**，三个月远远不够。
- 王林不急离开，索性居住于此，整日观看昼夜变化、时而入池感悟。
- **八年**过去：东临宗再无新客，老祖也未来打扰，王林平静度过。期间刘金彪不知用何法与金尊海龙相处融洽，甚至可坐其背外出遨游。
- 八年之后，**又过了五年**。
