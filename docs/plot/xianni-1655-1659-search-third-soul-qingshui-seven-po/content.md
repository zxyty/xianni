# 仙逆 第1744–1745章：寻找，第三魂！／七魄所属！

## 一、第1744章 前段：月夜与李慕婉
- 王林在山峰上守着避天棺中的李慕婉过了一夜，清风吹动其白发与棺内青丝，「一如千年」。有李慕婉陪伴，心中平静不孤单。
- 远处山峰月色中出现两道身影：一个被蓝色弥漫的苍老身影，及其女李倩梅。二人似早已到来，目睹了王林入梦与落泪，见王林望来便转身走远，背影孤独（李倩梅尤甚）。
- 王林闭目不语，「这一夜，属于他和李慕婉，没有别人」。
- 天将破晓，王林望棺中人「一眼，千年」，喃喃「婉儿，等着我」，挥手将避天棺化作幽光收走。
- 定策：「到了寻找第三魂的时候了」，并料定七彩道人、战老鬼等人也已各自找到线索。

## 二、四大战将与雾兽的追踪线（云海 → 罗天）
- 四大战将经历天道之险后未放弃寻找第三魂，此刻在云海星域内结成阵法。
- **仙尊本命雾兽**：头顶巨大葫芦喷发大量雾气，雾气蠕动指引前行；后雾气轰然凝成一头似犬似麒麟而有别的凶兽，全身由雾组成，以鼻嗅气息追踪。
- 路径：穿过一片片星空与漂浮大陆，在云海内向罗天方向移动，最终临近**云海边缘**——那里通往罗天。
- **废弃大陆一幕**：雾兽在一处废弃漂浮大陆外停下低吼。该大陆满是废墟，昔日曾有生灵与大量凡人居住，如今死寂，仅余少量凶兽。四大战将掐诀放出毁灭波纹化作风暴，将陆上所有生命尽数毁灭；烟丝般气息飘出，涌入雾兽口中被吸收。
- **机制**：雾兽吸收第三魂的轮回气息越多，越能判断第三魂所在。此陆虽非目的地，但雾兽停留吸噬说明第三魂岁月中曾在此轮回。一路已吞噬数次，「应该快了」。
- **战老鬼**：一路阴沉默默跟随，与四大战将保持互不干预的平衡；见雾兽走势暗忖第三魂莫非在罗天（他在罗天待的时间最多），并疑惑第三魂「会是人，还是兽」。

## 三、七彩道人的搜寻线（昆虚 → 召河）
- 在罗天星域另一方向的**昆虚**，七彩道人立于翻滚的七彩云雾前，凝视手心一滴晶莹血液。
- 已几乎搜遍整个昆虚星域（除五行星外），每一寸星空、每颗修真星乃至尘埃都未放过，仍无半点线索。
- **旧线索的断裂**：他曾在云海裂缝的幻中幻内看到第三魂飞向昆虚，但关键时刻被王林打断幻术、强行唤出，故无法判断第三魂是在昆虚停留还是穿透而过。由此对王林恨意更深。
- **众生血脉之血**：由数次界内界外大战凝聚的众生血脉所成，仅剩一滴。遇洞府界轮回众生无变化；一旦遇非洞府界生灵的轮回，立刻发出刺目红芒。缺点是范围不大，需耗费大量时间。
- 决断：昆虚没有，便转往**召河星域**，直至把四大星域全部找完——「我就不信这第三魂还能离开这洞府界」。

## 四、王林与清水：七魄身份的挑明
- 王林盘膝放开神识笼罩仙界，在**西北方向一处山谷的木质阁楼**中找到清水。
- 清水与红蝶以父女身份在此平静生活。清水正含笑指点红蝶修为不通之处，言「修道之人，重意，重心，切唯心」；红蝶天资聪颖，体会颇多。
- 清水感应到王林，托言有事，化虚影离去；红蝶眼露忧虑，轻叹后闭目打坐。
- **对话要点**：
  - 王林抱拳：「清水师兄，助我寻找一魂」。
  - 清水确认王林已知其身份，并坦白：当年在七彩界，他其实已找到答案——**自己只是（七彩仙尊的）一魄所化**；此前无法开口，也不想承认。
  - 清水盘膝坐下：「动手吧，我不知你会用什么方法，但我会尽全力帮你」。
  - 王林表态：只知七魄中有清水师兄，其余六人猜测不到；**绝不允许三魂归一吞噬七魄**；找到第三魂后，将出手灭杀、取魂封印。
- **施法**：王林点眉心，此前融入眉心的**鬼脸**幻化而出，急速膨胀成数十丈大小漂浮上空，狰狞无声咆哮，张口将王林与清水一并吞噬；二人脑中雷霆轰鸣，神识被卷入万古岁月之前**七彩仙尊三魂七魄分裂的那一刹那**。

## 五、第1745章 幻境：清水的血色往事
- **施法结构**：与当年七彩道人的幻中幻类似，此次以**清水为引**、王林借鬼脸施展并自身融入，追寻隐藏在古老岁月中的真相。
- **幻境景象**：天空血色、大地褐色如被鲜血浸透，血腥刺鼻，王林一入即觉胸口淤闷如压大石。遍地零碎尸骸、残肢断臂；完整头颅的双目仍留生前恐惧，瞳孔中定格着一个模糊身影的倒影。
- **地点**：一座凡间皇宫，本应金碧辉煌，此刻成了死亡的宫殿。
- **关键一幕**：远处宫殿崩塌，一名身穿血衣的男子右手掐住一位穿皇袍的老者，神色冰冷透出疯狂杀机，道「当年你之一族带给我全家的祸乱，今日，清水如数奉还」，随手一捏，皇袍老者全身爆裂，鲜血溅满其身与脸。
- **章末悬念**：天空尽头骤现数百道长虹剑光——数百修士踏剑呼啸而来，刹那临近皇宫上空。

# 第1745-1746章 幻境重演：七彩仙尊三魂七魄归位之秘

## 一、第一重幻境：当年的清水国

- **场景**：血流成河的清水国皇宫一带，地面鲜血粘稠，残肢断臂遍地。
- **清水出手**：数百修士来袭之际，血衣男子（清水）猛地抬头，双目射出妖异红芒，化作红色闪电轰鸣穿透众修士身体，瞬息间数百人身躯颤抖崩溃。
- **王林判断**：喃喃「极境」，并断定「这只是第一重幻境，是在当年的清水国」。
- **清水之誓**：「天若阻我，我来灭天，仙若阻我，我来弑仙」；「我要让这天地血流成河，我要让这一切负我之众生轮回杀劫」——心神已近疯狂。

### 王林与清水的对照
- 王林看清水背影，如同看到**当年在藤家的自己**：大仇得报却无半点快乐，只有悲哀、惆怅与对天地生灵的厌倦与恨。
- 清水充满血丝的杀戮之目震慑不了王林——「他们，归根结底是一类人」，这正是二人深厚友情、肯为对方战死的根源。
- 王林在清水眼中看到的不只是杀戮，还有痛苦、悲哀与思念。
- 王林轻唤「师兄」，劝其坐下；清水闭目落泪，泪痕冲开脸上血痕，滴落与血相融，最终盘膝坐下。
- 清水目光落在皇宫内一颗**未被毁灭的槐树**（悠久岁月、干枯中挣扎求生）上，杀意慢慢消散，轻叹一声：「进入第二重幻境吧。」

### 幻境切换手法
王林掐诀、双手向两旁伸开、大袖一甩 → 幻境天地扭曲，鲜血与残肢中飘出黑气 → 黑气于二人上空凝成巨大鬼脸 → 鬼脸无声咆哮吞噬二人 → 神识与魂魄被漩涡完全抽离，卷向**万古岁月之前**。

## 二、第二重幻境：洞府界核心的崩溃之幕

- **地点**：天地初开、一片混沌中的**洞府界核心之地**，即洞府界中枢、洞府中的真正府邸，此处存在**通往仙罡的洞府之门**。
- **事件**：天道大口张开吞噬**连道非**，轰鸣传遍整个洞府界；王林正是此时幻化而出。此幕与他此前在云海裂缝七彩道人处所见**一模一样**。
- **结果**：连道非怒吼咆哮中，天道重伤崩溃、分离消散；同时身着七彩道袍的**七彩仙尊**神色悲哀、身躯轰然瓦解，肉身被完全撕碎，体内元神魂魄交错，化作**三魂七魄**四散而去。
- **差异**：这一次是王林**主动施展**幻术、身为幻术源泉，所见比上一次清晰得多。

## 三、七魄归属（赤橙黄绿青蓝紫）

| 魄 | 颜色 | 所承载 | 轮回之人 |
|---|---|---|---|
| 第一魄 | 赤（红） | 一生惊天杀戮，吞噬其所杀无数冤魂 | **清水** |
| 第二魄 | 青 | 修仙资质（天骄之资，可修至空劫） | **司徒南** |
| 第三魄 | 橙 | 良知所化之正气，护其在意之人/物、万般诱惑不动心 | **青霖** |
| 第四魄 | 黄 | 一生机缘与气运（光芒几可与三魂争辉；法宝自来、敌人自毙） | **贪狼** |
| 第五魄 | 绿 | 本能所化，开枝散叶之意，擅**分身之术** | **散灵上人** |
| 第六魄 | 蓝 | 一生之情（如水温柔＋如冰寒冷，爱恨交错），化为女子 | **木冰眉** |
| 第七魄 | 紫 | 崩溃前的愤怒、疯狂与不甘；最先消散、其内浑浊 | 看不清，王林**隐隐觉得见过此人** |

### 由七魄反推的旧事解释
- **司徒南**天资惊人、修为时刻变化 → 因其为七彩仙尊「天资一魄」所化。
- **青霖**身为雨界仙帝，一次次抵住掌尊诱惑、重伤濒死也要守护雨界 → 因其为「正气第三魄」。
- **木冰眉**一生（一次次轮回）冷漠与温柔交错、与王林之情复杂 → 因蓝魄源于七彩仙尊对唯一道侣**矾珊梦**的爱恨交织；七彩仙尊虽有诸多妃子，道侣唯矾珊梦一人。
- 王林对木冰眉之真相「面色苍白」「不敢相信」，心神震撼不亚于寻得真正的第三魂；此震撼似两千多年积累于一处。

### 魂魄设定
七魄分离后各成**独立个体**，彼此联系极淡、几不可察；**若三魂不融，七魄永不消散**，只会如常人一般一次次轮回千载。

## 四、三魂去向

1. **第一魂**：一出现即闪烁七彩光芒，去向为**万古岁月之后的界外**，在那里化作**七彩道人**，承载七彩仙尊一生神通。
2. **第二魂**：向相反方向呼啸入轮回，一次次轮回后，某日成为**罗天星域**内某颗修真星上一只极为寻常的**凶兽**；其记忆慢慢苏醒。
   - 记忆完全苏醒后的一日，**战老鬼**渡**玄劫**失败、全身腐烂、元神崩溃，处于死亡弥留之中，轰然自半空坠落该星；他惨笑间看到一只双眼露出奇异之芒的凶兽扑向自己。（第二魂与战老鬼的因果由此起）
3. **第三魂**：本章未直接交代（章节标题为「三魂归位！」，王林此前正在寻找真正的第三魂）。

## 五、要点提示

- 幻境为王林主导的两重推演，目的在于让清水（赤魄）与自身一同回溯本源，指向「三魂归位」。
- 本片段是《仙逆》后期最重要的身份揭底之一：清水、司徒南、青霖、贪狼、散灵上人、木冰眉六人皆为七彩仙尊七魄轮回所化，七彩道人为其一魂。
- 紫魄之人身份留白，为后文伏笔。

# 第1746–1747章 追溯第三魂轮回，真相为谢青

## 一、追击缘起
- 战老鬼的仙缘显化中，三魂飞散，其中**第三魂**飞得最远，自洞府核心之地直奔星空尽头。
- 王林毫不犹豫全速追击。这是他**第二次追击**：此次无七彩道人、无人打扰，目的只有一个——查明第三魂究竟是谁。
- 王林已感到第三魂的身份与所在「呼之欲出」。

## 二、第三魂的形态
- 魂内**一片浑浊，无任何虚影**，与魄及其余两魂不同；未经轮回前无法显出样子。

## 三、路线与轮回历程

### 1. 昆虚星域（经召河而至）
- 入昆虚后速度渐缓，隐隐似在寻找轮回栖息之地。
- 曾于一处蛮荒修真星外略作停留，却不知为何未选此地，一闪而过。
- 在昆虚**游走一圈**后骤然加速，离开昆虚前往**云海星域**。
- **王林的推断**：当年七彩道人跟随此魂，绝对没有看到它去往云海，而是在昆虚游走阶段就被自己打断、将其唤醒。
- **王林生出的寒意**：第三魂在昆虚游走，是在找什么？还是冥冥中感受到万古岁月后七彩道人会以此法寻它，故而**刻意拖延时间**？——他自觉匪夷所思，将念头压下。

### 2. 云海星域
- 第三魂落于云海一颗蛮荒修真星，一闪而逝。
- 岁月流逝后该修真星崩溃，化作大量碎片大陆四散，崩溃处散出阵阵雾气弥漫四周。
- 其中一碎片上，一条**蟒蛇**死亡，一缕白芒升空、奔星域而去。王林全速锁定白芒继续追击。

### 3. 四大星域中的历次轮回（择要）
| 轮回身份 | 结局 |
|---|---|
| 凡人书生（仿佛呆子，只懂读书） | 获取功名、洞房花烛，直至老死 |
| 参天大树 | 千年岁月中由幼苗至枯萎死亡 |
| 修士 | 修为不高，一生止步**结丹**，寿元断绝而死 |
- 其间有男有女，轮回无数次。

### 4. 朱雀星 · 赵国大儒苏道
- 第三魂择昆虚星域的**朱雀星**轮回，化作一名**凡人**，一生未修道，却极为闪耀，成为**赵国的大儒——苏道**。
- 王林心神震动：在苏道一生中**没有看到自己**，却不知为何自己会在**梦道**中存在于对方之中、被对方收为弟子。
- 他断定二人之间「存在一股轮回岁月的因果」，然而**只见果，不见因**；本已达成的因果，在此刻反而使他迷茫。
- 苏道喜爱柳絮，含笑老死；白芒飘起，转向**罗天星域**。

### 5. 罗天星域 · 青灵星的数百次鱼身轮回
- 第三魂进入罗天深处的修真星**青灵星**，轮回成河中鱼儿，由鱼苗长大、嬉戏游走直至死亡。
- **异常之处**：死后不离此星，而是在**同一条河流内**再度轮回成另一条鱼，如此往复**数百次**，似在等待什么。
- 王林看着这颗「熟悉的」修真星，内心已有模糊猜测。
- 最后一次：河上有渔翁垂钓，第三魂所化之鱼**主动一口咬住鱼钩**，被渔翁笑声中拽起。
- 渔翁语：「内子临产，今日只钓这一条就回家。」——它轮回数百次，等的就是这个渔翁、这一口鱼饵。

## 四、谢东明与谢青降生（第1747章）
- **渔翁真容**：拽下斗笠，是三十许岁的汉子，身材不魁梧甚至羸弱，神色洒脱，不像渔人，更像文人书生。阳光照在鱼腹上折出白芒，依稀不凡。
- 男子将鱼放入盛水瓦罐，提罐步行约一炷香，至河岸竹林中的简朴屋舍；竹木围院，家禽争食，妻子挺着大肚在院中喂食等他归来。
- 「素儿，我钓了一条鱼给你。」——妻名**素儿**，温柔应之。
- **三日后深夜**：天地色变、风云倒卷、雷霆暴雨。素儿难产，稳婆在侧；男子在房外强作沉稳，双拳紧握。
- 男子对天陈词：「我**谢东明**自幼读书，明道理，知万物，为官时造福一方百姓，罢官后亦从不与人结怨，此生区区**三十三年**，自问没有做过任何愧对良心之事……老天，如今我子将出，你何苦为难于内子」，右手狠击竹壁，鲜血滴落地面被雨水冲淡。
- **血融于水的刹那**，雷霆轰鸣中婴儿啼哭传出，稳婆报：母子平安，是个男孩。
- 取名之言：「名字我已经想好了，男孩的话，就叫**谢青**，我希望他长大后，如青竹般，挺拔中出尘不俗，成大儒风姿。」
- 婴儿于笑声中止哭睁眼，**隐有奇异之芒闪烁**。

## 五、真相与后果

# 第1747–1748章 第三魂即谢青·天道「变数」之悟

## 一、幻境终局：第三魂身份揭破

### 青灵星的旧事
- 王林当年在青灵星寻道迷茫，遍问此地大儒「何为道」，最终问到**谢青**，因其一言而有明悟与突破。
- 谢青虽已老迈，仍以凡躯攀上山峰，在王林面前跪下一心求道，开口第一句：
  > 「我这一生，自问知晓天地人伦，在学术上明悟一切，以教化世人为己任，此时，到了知天命的年纪，却是突然顿悟，原来，我，就是一条水中之鱼。」
- 当年王林只懂前几句，未曾细究最后一句。

### 此刻的彻悟
- 追寻第三魂的一次次轮回中，王林在青灵星河道内看到第三魂**数百次轮回为鱼儿**；确认第三魂即谢青的一刹那，「我就是一条水中之鱼」一句豁然贯通。
- **因果轮回闭环**：
  - 现实中：王林无意点化谢青、收其为弟子 → 与七彩仙尊第三魂结下因果（此为「因」）。
  - 梦道中：**苏道**出现并指引王林，使其成为赵国乃至朱雀星上的大儒 → 梦道内王林是他弟子。
  - 王林感叹：即便自认因果大成之后，因果依旧「看得到，摸不到」。

### 幻境崩溃（三步）
1. 第一步退后：天空撕裂崩碎，大地起伏、竹林粉碎，雨水气化雷霆骤灭，只剩那间透出温馨火光的屋舍。
2. 第二步退后：屋舍扭曲重影、渐渐模糊，被虚无吞噬；王林身影随之模糊，现身于**清水第一重幻境**内，清水睁眼轻叹。
3. 第三步退后：往昔清水国皇宫、血色染红的天地轰然崩溃，血迹碎末卷成巨大漩涡、化作狰狞鬼脸无声咆哮，将王林与清水一并吞噬——幻境彻底崩灭。
- 二人在**洞府界·仙界**山峰之顶同时睁眼。王林面色苍白，眼露挣扎：「第三魂，是他。」

## 二、杀，还是不杀

- 清水起身回望，沉默离去——他已知第三魂身份及其与王林的关系，明白王林的挣扎。
- 王林的两难：
  - 若第三魂是不相干之人 → 出手、封印、毁灭，无所不用，阻止**三魂融合后七魄被吸**的命运。
  - 但第三魂是自己的弟子谢青 → 要他亲手杀死弟子，心在痛。
- 长叹后，王林仍未做决定，但**内心隐隐已有答案**。

## 三、两大困扰

### 困扰一：失踪的第七魄
- 天运子是天道的一部分；此前一战中王林入其轮回，见岁月最初之前天运子**吞噬了七彩仙尊第七魄**。
- 但在七彩仙尊崩溃、三魂七魄刚分离时，王林又见到过第七魄 → 推测第七魄的确轮回过（如第三魂多次轮回），在某次死亡重寻轮回之地时被天道分裂所化的天运子吞噬。
- 第七魄为**紫色**，代表七彩的愤怒与疯狂；本应与天运子融为一体，但王林在吞噬天运子后所得的**幽冥兽**体内，隐隐感觉**其内没有第七魄**。
- 若感觉为真 → 天道内没有第七魄 → 印证天道不完整（此前天道亦无法吞噬四大战将与战老鬼）。
- 疑点指向：「难道天运子还有分身没死？」「我险些忘记了——**灰衣天运子**。」随即又自我否定「或许并非是他」。此问题无解。

### 困扰二：命运之魂的自相矛盾
- 已知**六魄**：清水、司徒、贪狼、青霖、木冰眉、散灵上人。
- 清水与司徒的**命运之魂不在天劫轮回内** → 符合王林判断七彩之魄的标准。
- 但青霖、贪狼、木冰眉、散灵上人的命运之魂**在天劫轮回内存在** → 说明其本身是洞府界内繁衍的众生，与「七彩之魄」身份自相矛盾。
- 王林隐约觉得此事至关重要，甚至可能是**解决七彩三魂融合的最终方法**，却陷入死结。

## 四、玄罗一指与「变数」之悟

- **玄罗大天尊**一直在王林身后不远处观察（梦回朱雀、寻找第三魂全程参与），判断王林「进入了思绪的循环」，抬右手向王林蓦然一指。
- 王林身子一震（未察觉玄罗存在），脑中如雷霆撕开思绪，得一奇异念头：**「变数！这是变数！」**，随即前所未有的清明。

### 变数的内容
- 青霖、贪狼、木冰眉、散灵上人四人最早或与司徒、清水一样，天劫轮回中没有命运之魂；但在一次次轮回转世中，因**一个奇异的变化**成为真正的个体。
- 一次次轮回、一次次改变、一次次融合 → 他们**曾经是七彩之魄，但如今不是**，已成为真正的洞府界之人。
- 这是**造化之力**，是最接近天道最核心的力量，即「变数」。
- 清水与司徒尚未在变数下完全转变为独立个体；或再过几万年、再经几次死亡轮回，也终将如四人一般与七彩仙尊彻底分离。

### 由此推出的解法方向
- 既然此力能改变七魄，**应也能改变三魂**；若掌控此力使**第三魂独立**，则三魂无法融合，一切迎刃而解。
- 障碍：王林仍无法想象这天道核心究竟是什么——他的天道还不完整，也尚不了解自己掌控的天道因何出现、因何能繁衍众生、衍变规则法则。

### 玄罗的独白（天道背景）
- 天道之玄妙，「莫说是他，就算是我也有很多地方无法明悟」；玄罗当年机缘巧合成为**大天尊**时才略懂一些，欲完全看透除非修为再进一步。
- **九阳**都在寻找再进一步的道路，至今无人做到，只能凭一次次不得不转世之时思索天道。
- **天道此物最早来自太古神境**，其玄奥不知何年何月才会有人完全明白。
- 玄罗右手食指上有一个黑色圆形印记，仿若黑洞缓缓旋转，散发属于天道的气息。
