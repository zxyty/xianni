# 仙逆 第七卷 名震罗天 · 第775章 暗洞

## 一、引仙府：雷之仙界的仙人交易废墟
- 王林与李元抵达残破石碑处。李元察看石碑与废墟后判断：所谓“引仙府”，是当年**雷之仙界尚未崩溃前**的一处**仙人交易地点**。
- 府邸极大，几乎相当于凡人一座城池；遍地阁楼残骸，风过残壁如呜咽哭泣，部分地方仍残余禁制波动。
- 王林细搜一番、神识横扫，未见出奇之处——显然此地在雷之仙界历次开启中早被人搜掠过。

## 二、东首暗格与“死阵”
- 李元断言：此类交易府中**最大的店铺必在东首**。东部残骸最重，仅余断壁。
- 李元抬石推算后，指定一点请王林出手。王林抬手放出一道**紫色雷电**化作狂龙轰下，掀开残壁，露出刻于地面、毫无波动的**阵法图案**。
- 李元判定：仙人店铺内必有**暗格**；王林指出此暗格阵法年代太久，维持运转的**仙力已消失**，故无波动。
- 李元由灰尘判断此处久无人至，确认此阵为**死阵**——失去生机后无法破解，但他自称有办法令其“恢复生机”，需要时间。

## 三、以血复阵 → 首次异法开启 → 泄灵光柱
1. 李元盘膝坐下，**咬破左手指尖**，以元力催动血液渗入阵法，缓缓蔓延；耗时渐久，面色苍白。
2. 血覆全阵后，阵法出现细微波纹，如被注入活力。
3. 李元左手点在眉心，射出**一道黑线化作禁制**落入阵中（心禁之术路数）。
4. 禁制入阵刹那，阵法骤然喷出**直插云霄的光柱**；李元手中后续禁制未及打出便消散，愕然道“仙阵首次开启”。
5. **泄灵规则（李元解释）**：仙阵若以正确方法开启，不会有此变故；若以其他方法开启，**第一次会出现“泄灵”**，须把阵内灵性宣泄干净，方可入内。
6. 王林神识扫入光柱，发现其内有**一股被压抑的仙力**迸发而出。此光突兀无兆，无法阻止，且显然出乎李元意料。

## 四、群修云集与“进入者，死”
- 首至者：两名**问鼎中期**修士，御双剑光而来，自称**罗天西域赵家**族人。
- 王林右手一抓，掀起大片断壁捏为碎末甩出，方圆**千丈**内形成环形碎灰隔绝带，平淡道：**“进入者，死。”**声淡如奔雷，二人剑光不稳、大骇止步，抱拳称“谨遵前辈之命，绝不踏入”，退在圈外围观。
- 泄灵动静过大，碎片大陆上修士尽见，皆以为有宝出世，四面八方长虹疾来。来者修为不等、**大都问鼎圆满，无一人达到阴虚**；见王林身上元力后纷纷后退，无人踏入千丈。
- 光柱在众目睽睽下彻底消散，地面阵法处**露出一个暗洞**，仙力波动外溢，千丈外亦可清晰感知；未知带来的诱惑令众人贪念暗涌——若无王林在场，早已一拥而入。

## 五、章末悬念：第二步修士到来
- 远处天边一道疯狂剑气呼啸，天地元力波动直奔此地，**视千丈屏障如无物**。
- 群修哗然：来者是**踏入第二步**的修士。元力弥漫中，一道**黄色身影踏剑光迅速飞来**。（章末，未接战）

## 六、王林的内心线
- 立于废墟，王林感慨当年雷之仙界之壮观：仙人无数，踏法宝仙兽而来，如凡人般在此交换所需，从未料到仙界会崩溃。
- 忆起在**雨之仙界**所见的**巨大手印**——一掌之印令大地碎裂的神通；暗叹“可惜李元无法去雨之仙界，否则凭其**心禁之术**，不知是否可把那掌印的神通逆推出来”。

## 七、设定要点提炼
- **死阵**：仙阵失去维持仙力后无生机，常规手段无法破解；可以血/生机重新“激活”。
- **泄灵**：非正法开启仙阵的首次代价，须宣泄阵内灵性后方可入内。
- **本地修为分层**：问鼎中期 < 问鼎圆满 < 阴虚 < 踏入第二步（本章群修最高仅问鼎圆满，第二步者被视为压倒性存在）。
