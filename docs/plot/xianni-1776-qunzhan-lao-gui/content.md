# 第1776章 群战老鬼！

## 一、最后一层：王林与烨寞心脏传承融合

- 下方巨大心脏的磅礴气息顺着心脏冲入王林体内，如雷霆轰鸣卷动全身，王林如身处狂风暴雨。
- 其**眉心与双目的三族星点**疯狂回旋，隐隐**有了要成为第九星的迹象**。
- 心脏跳动与王林心跳逐渐一致，最终他耳边只余「怦怦」之音，全身暖洋洋、心脏刺痛散去，产生与心脏融为一体的错觉。

### 明悟：心动神通的推衍

王林回顾在古之墓地最后一层被心跳所扰、心如针刺几近崩溃的经历，摸出痕迹：

> 「以自身心动引起旁人心跳，改变对方心跳的规律，从而心脏崩溃而亡；亦或使对方心跳与自己一致后，间接艹控产生杀伤之力——这种手段防不胜防。」

此法**非神通、非法术、非道术**。王林决定借此明悟创造属于自己的又一式神通，构想三层融合：

1. **雷霆本源**——心跳如音，声音扩散需辅助；以本源中的雷霆轰鸣之声为载体，把本源凝聚在心脏处，将心跳放大无数倍从体内传散出去。
2. **梦道之术**——心跳之声与梦道融合，传入对方耳中时令其出现幻觉，引起心跳改变。
3. **虚火之术（火焰本源）**——同样融入心跳之声；对方心跳被改变、生出烦躁之意的同时，虚火燃烧。

- 王林闭目在脑海中不断推衍其可行性。
- 身旁的**已司之傀**蹲踞，双眼凶煞更浓，暴躁之意显露，连连无意识嘶吼。

## 二、倒数第二层入口外：群战战老鬼

### 战场伤亡与格局

| 人物 | 状态 |
|---|---|
| 第三妃唐姗 | 被轰出天空摔落崩溃大地，面色苍白、嘴角大量溢血，心神震动，已然重伤 |
| 云逸封 | 面如死灰、闭目不动；先前受伤，在战老鬼甩袖间伤势爆发，险些身亡 |
| 托森（拓森） | 全身被三个黑色「战」字环绕，生生封印，无法走出 |
| 玄武战将、朱雀战将 | 与五行星两名中年修士交战，神通轰鸣，彼此难分胜负 |
| 蓝梦道尊、五行星马姓老者 | 合击围困战老鬼 |

### 各方动机

- **战老鬼**：若非二人阻拦，早已进入古墓最后一层**击杀王林、获得第三魂**；二人不顾受伤也要拖住他，令他一时无法追入。
- **马姓老者**：带五行星同宗来此是**玄罗**的要求；若再不出手，恐惹玄罗不喜，**此生再无离开洞府界的可能**——不得不战。
- **战老鬼的取舍**：不在乎蓝梦（蓝梦**没有去度玄劫**），而马姓老者**已度玄劫**，故必须先重创马姓老者以摆脱纠缠。
- **蓝梦道尊**：神色阴沉、脚步踉跄，神通多为防御，无法太过近身。

## 三、蓝梦道尊的古琴

- 马姓老者传音「老夫要施展大神通之术」；蓝梦道尊甩袖，蓝光笼罩八方直奔战老鬼。
- 战老鬼右手一挥现出**「战」字**，急速膨胀化作滔天之力轰向八方，蓝光扭曲崩溃。冷哼：「米粒之光，也敢与皓月争辉」，径直越过蓝梦扑向马姓老者。
- 但二人都**小看了蓝梦道尊**——蓝梦为**太古五尊之一**，连**掌尊**都忌惮，纵未历玄劫必有手段。

### 古琴的来历与分量

- 蓝梦咬破舌尖喷出鲜血，血与四周崩溃蓝光融合，身前化作一张**古琴**。
- 此琴散出沧桑气息，似存在了无数岁月；**本无形，融入蓝梦血液之内**，封尘无数年后再取出，绽放最强之力。
- 是蓝梦道尊的**至宝与最终杀手锏**，也是**掌尊忌惮他的真正原因**。
- 一生只用过一次——**成名之战**：「一缕琴音葬万骨，回首一望是千年」。
- 他虽未历玄劫，但在此琴上花费了**比度玄劫更多的心思与祭炼**；来历极为神秘，**隐隐似不是这洞府界之物**。
- 抚琴前，蓝梦目露悲哀，思念**其妻**——妻子在他储物空间内，却无法让其恢复。

### 交锋

- 蓝梦盘膝坐于琴后，双手按弦轻拨——「铮」。战老鬼脚步一顿，刹那退出三丈，猛然回头。
- 铮铮之音此起彼伏，一道道波纹弥漫，瞬间**封死战老鬼前后左右一切方位**。

## 四、马姓老者的五行仙术

- **「五行金仙凝拟金天」**：无尽金光自其体内冲天，崩溃碎裂的天空被一片金光覆盖，天成金色，如同九曲三相。
- **「五行土仙凝拟黑地」**：左手一指大地，地面被黑暗取代并疯狂蔓延，大地尽成黑色，淹没掩盖所有景物。
- 连施二仙之术后神色极为疲惫，不愿再多施展。
- 琴音化作煞气完全封死战老鬼；战老鬼划出**战字**向外一拍，战字崩溃震动琴音封锁，琴音随即高昂、波纹大浪回旋生生抵抗。
- 趁此，马姓老者神通指向战老鬼：**金天中伸出金色大手，黑地上伸出黑色大手，一上一下齐齐按下**。

## 五、战老鬼的反制：七彩仙尊之魂

- 战老鬼右手拍向眉心，轰然一声，体内散出一片模糊虚影如魂。
- 该虚影现于战老鬼身后：**似穿披风，遮盖眼部以下，只露阴森双目与一头长发**——正是**七彩仙尊之魂**，与战老鬼身体**直接分离**。
- 披风之魂双手迅速伸开如十字，继而一上一下，与金天黑地所化的两只大手**轰然碰撞**。

## 六、章末悬念

古墓最后一层入口处，道古气息隐隐散出的同时，阵阵**怦怦、怦怦如雷霆一般的心脏跳动之音**回荡而起——那是**王林的心跳**。
