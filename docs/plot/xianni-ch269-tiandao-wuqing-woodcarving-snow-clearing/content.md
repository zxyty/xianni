# 仙逆 第269章 天道无情

## 一、老头夜谈：雨鼎、天道与仙门法则

- **雨鼎将起**：老头告知王林，朱雀星附近的**所有星域**全部都在「蕴化雨鼎」，用不了多久便会陆续有雨鼎出现。
- **王林发问**：「这天道开启之日，是何时？」老头未正面作答，反问其是否动心。
- **仙门可去**：以王林当前修为进入仙门虽有危险，但只要小心谨慎，倒也不必太过担心——因为**仙门之内对实力有极大限制，修为越高，束缚越大**。

### 古仙界碎片的法则限制（本章核心设定）

| 要点 | 内容 |
|---|---|
| 现状 | 古仙界已然支离破碎，化作无数碎片存在 |
| 关键 | 碎片内的**天地法则完全混乱** |
| 触发条件 | 其内若出现**化神后期以上**的法力波动 |
| 后果 | 所在的那一小部分仙界碎片**立刻崩溃坍塌** |
| 例外 | 视碎片大小，有些地方可承受更高级别的法力波动 |
| 结论 | 高修为修士进入后，只要不是为了自杀，都会把法力波动**限制在化神期** |

## 二、木雕之约与草帽法宝

1. **来意**：老头深夜来访，真正目的是宣告「我要走了」，临走前要王林制一个木雕，声称要送给**红粉楼的小翠**「睹物思人」。
2. **第一版·写实**：王林右指成刀雕出全身干瘦、仿若猴子的老者，与老头本人一模一样，连脸上皱纹也丝毫不差，唯独未刻出其狂暴肆虐的意境。
3. **翻脸**：老头怒掷木雕，直勾勾盯着王林一字一字说「不像」——**眼中不再是嬉戏，而是从未有过的认真，其中略闪狂暴**。此刻四周天地灵力似按某种规律变化，王林蓦然生出危险感。
   - **信息点**：王林数十年来一直猜测老头修为，此时**再次上调**对其修为的评价。
4. **第二版·美化**：王林以快一倍的时间雕出英俊潇洒、风流倜傥、双眼炯炯有神的绝世美男，与老头形象相差极远，明眼人一看便知非同一人。老头却双眼冒光大赞「这才是我」，塞入怀中。
5. **报酬**：老头借出**草帽法宝**给王林「用段日子」。
6. **自我说辞**：老头称美男木雕「与我老人家现在的样子只有那么轻微的一点点差距，可以忽略」，且「与我年轻时候几乎一模一样」，要求以后照此雕刻。
7. **临别之约**：「还剩下**九十九个木雕**，等你**化神**之后可别忘了，不然你走到哪里，我老人家都能找到。」
8. **王林反应**：目送老头离开，拿起第一个写实木雕看了一眼，微微一笑，随手放在架子上。

## 三、王林的两项决断

- **仙门**：目前不打算参与；若真能修至化神，去一趟倒也无妨——但现在念之为时尚早。
- **四派联盟 vs 雪域修士之战**：打定主意不参与，因「涉及范围太广，稍有不慎便是后果严重」。

## 四、四派联盟的雪灾治理

- **天象**：大雪下到一个月后渐少，天空之上修士法宝之光越加频繁，似在修补什么。
- **阻雪大阵**：王林观察后确定，众修士正在天空组成**一道阻止降雪的阵法**。
- **人力清雪**：雪花对法力波动有奇妙的敏感性，**以法力清雪效果甚微**，于是各派与各修真家族的修士行走于城池平原之间，凭人力清雪。
- **举国动员**：凡人皇帝接到仙长旨意，大量凡人军士开始高强度清雪；因四派联盟境内极大，城池百姓乃至**妇女孩童**亦被强行征集。
- **持续时间**：清雪工作持续**数月**，京都乃至整个四派联盟各城池为之一空，除少数身份尊贵者外皆被征往各地。

## 五、凡俗线：大牛

- 大牛也在被征之列，已被征集去了**南方**。
- 王林已处暮年，但在**一直孝敬他的王爷**发话下，无人前来打扰。
- 大牛临走前，王林**念在三十多年的情感**上，送给他**一小块木雕**，让他贴身放好。（伏笔：护身之物）

## 六、伏笔清单

- 雨鼎将在朱雀星附近星域陆续出现 → 天道开启。
- 王林尚欠老头九十九个木雕，兑现节点为「化神之后」。
- 草帽法宝暂借王林使用，期限为「一段日子」。
- 赠予大牛的贴身小木雕。
- 老头修为深不可测，怒时天地灵力随之变化。

# 第269-270章 天之娇女：雪域灭国之战的真相

## 一、凡人之劫：持续四个月的雪灾

- 王林除赠木雕给邻人外，也送了其妻子一小块木雕；木雕作用是**散发暖意、防止身体冻僵**。
- 这场原本属于修士之间的战斗，**前期最先受苦的是四派联盟的凡人**。他们甚至不知道降雪的原因，为保家园免于雪灾，义无反顾踏入风雪。
- 全境每隔一段距离便堆起一座**巨大雪峰**，所有积雪汇聚其下，由大神通修士出手不断增高。
- 灾情：田地庄稼颗粒不收、全被大雪淹没；每天都有无数凡人冻死、房舍被雪压塌。
- 王林于某日清晨走出店铺，街面积雪虽被清除仍有残雪，高空风雪略小却依旧不停。

## 二、周武泰的玉简：这是「灭国之战」

此次玉简中周武泰**不再邀请王林加入四派联盟**，而是通报近日举措与一则惊天秘闻。

1. **现状**：举国清雪后境内积雪大减，但多出无数高耸入云的雪峰；境内绝大部分修士已被四派联盟邀请加入，共抗大战。
2. **疑点**：按雪域修士惯例，降雪**最多十日**，十日后便会亲至；如今已四个月，高空风雪毫不减少，只是被阵法掩盖。
3. **前提**：朱雀国规定修士大战尽量克制、不干扰凡人界。持续数月的雪灾直接违背此规。
4. **结论**：雪域修士意在**灭四派联盟根基，进行灭国之战**。
5. **先例**：四派联盟典籍载，朱雀星上共发生四次灭国之战——三次在四级修真国、一次在五级修真国。**无一例外，背后都有朱雀国的影子**。故此次很可能是雪域修士以某种方式打动朱雀国，在其默认下进行的绝户之战。

## 三、三路使者与外交的全面失败

为查证是否真为灭国之态，四派联盟派出数名修士，分三组：

| 组别 | 目的地 | 结果 |
|---|---|---|
| 一 | 四周交好的四级修真国 | 客气迎入却绝口不提参战，一味拖延；甚至有直接闭国不见者 |
| 二 | 所属的五级修真国 | 满脸阴沉而归：**雨鼎不用上缴，此事五级修真国不参与** |
| 三 | 朱雀国 | 发玉简之日尚未返回 |

- 一个世代交好的邻国出于同情隐约点破：**各自所属的五级修真国已传下声音，禁止参与其中。**
- 第二组花费极大代价，终于从五级修真国一名**婴变期修士**口中获得震惊消息（见下）。

## 四、惊天秘闻：雪域「天之娇女」

- 雪域出了一名女子，**天资惊人，连朱雀国都为之侧目**。
- **只用一百年便达化神后期的巅峰**，被誉为整个朱雀星**万年来天资第一人**。
- 更骇人的是：修炼这一百年**从未服食任何丹药**。
- 朱雀国派修士查证属实后，**隆重邀请其加入**。

### 朱雀国的动机
- 朱雀星上天资绝顶之辈在人生最闪亮之时常被朱雀国注意并收为本国修士，此事不算罕见；但新入者身份地位通常不高。
- 对这名雪域少女，朱雀国**下了狠心，给予极高身份**。
- 原因：朱雀国要冲击**无数年来再无进步的沟壑，争取晋升七级修真国**。晋级除需修士修为达到更高一层外，还需一系列其他准备，难度极大——而朱雀国**连第一个要求都尚未达到**。

### 少女开出的唯一条件
> 让**雪域国攀升至五级修真国**，并**离开贫瘠的雪域之地，在朱雀星上另选国址**。

## 五、因果串联：雨鼎之争的真正性质

- 恰逢此时，四派联盟境内出现**雨鼎**。四派联盟最终分析：雨鼎本属**雪域国一名修士之物**。
- 于是有了这场战事——但**四派联盟真正被看中的是「地」**：雪域国准备以此处作为新国址。
- 至于雨鼎为何出现在四派联盟、为何落在世子手中，四派联盟分析认为**这是一个阴谋**。

## 六、要点判断

- 雨鼎只是导火索与借口，**真实目标是四派联盟这块国土**。
- 五级修真国的集体缄默 + 邻国的禁令 → 指向朱雀国的默许，四派联盟外援已断。
- 王林的立场：四派联盟非其家乡，但京都城这条街道他已住了三十多年——其牵挂在此。

# 第254章 雪原取木——离开前的最后一次雕刻

## 一、玉简内幕与凡尘感慨

- 周武泰所赠玉简，王林已全部看完。心情沉重：**看似简单的「雨鼎之争」背后藏着极深的内幕**。
- 相关消息被那组修士带回后，**整个四派联盟为之震动**。
- 王林所在京城街道，几个月前还行人众多、清晨家家开张，如今店铺几乎全空——**两国之争使凡人受到极大波及**。
- 王林之叹：修士眼中凡人比蝼蚁更低微，却忘了当初自己也是从凡人中走出。
- 大道无情。体会**轮回天道**之后，王林心境已悄然改变：他无法阻止，也不愿参与。

## 二、决意离开

- 王林自语：「是该离开了，做完最后一步，就离开吧。」
- 关上店铺门，穿厚棉衣、戴皮帽，身影消失在天地白雪之中。
- 一路飞行所见：无数修士面色阴沉，相熟者擦肩仅轻点头，风雪如大石压在心头。

## 三、四派联盟极东·雪原取木

### 地点变迁
- 目的地为**四派联盟极东之地**，当年是一片茂密丛林；现今树木尽无，只余白花花雪原。
- 雪原与旁侧清理出的空地相比，如同一座巨大山脉；寒气散出，带**绝望的味道**。

### 取木手法
1. 双手掐诀，起**怪风**吹动平原，风声如哭泣呜咽，天地间充满悲声。
2. 雪极诡异，风虽强却吹不动多少积雪；王林目的不是清理整片丛林，故不焦急。
3. 渐成**方圆百丈的漩涡**，积雪向两旁扫动，形成巨大深坑，坑下是密密麻麻的树干。
4. 落入漩涡，神识一扫锁定树枝，折断后收入**储物袋**。
5. 反复施法，一个个百丈漩涡出现，木料越积越多。

### 木料要求
- 三十多年前收取的木段已用得差不多，不足以支撑临走前最后一次雕刻。
- 本次要求：**必须百年以上木料为佳，若得千年木料效果更好**。
- 冰雪覆盖之地寻此等木料，如大海捞针。

## 四、周武泰的相助与告别

- 王林久立半空，被途经修士留意；有人前来探查，**一发现王林修为便立刻恭敬**。
- 消息传到四派联盟，**周武泰展开职权把此事压下**，并亲自带人前来，一言不发默默帮忙。
- 若无相助，**仅七日根本不够采集足够木料**，也不可能扫开整片平原。
- 七日后木料采足，王林转身离开。
- 临走时**周武泰没有再邀王林加入四派**，只苦涩一抱拳带人离去。
  - 原因：他知四派联盟已走到末路，此时拉人入伙等于拉人送死；**他本人也在为自己的出路做详细考虑**。
- 王林对周武泰点头致意，离开此地。

## 五、归返京城·最后的雕刻

- 王林直奔京城店铺，城外身形一闪即消失，再现时已在店铺之内。
- 深吸一口气，环视四周，坐于椅上；左手翻出尚带白雪的木段，右手食指中指并拢，挥动雕刻。
- **此次雕刻并非只雕一物，而是无数。**

## 六、修为意图（关键伏笔）

- 王林的**化凡之境已走到末路**。
- 目的：以这最终的雕刻，争取让修为达到**化神**。
- 退一步的收益：即便失败，也要在**心境上提高一步**——如此距化神更近，**甚至只需选择一个天道去领悟，便可达到化神**。

# 第271章 十年化神

## 一、场景：雕刻所杀的每一个人

王林在店铺中开始雕刻——对象是**从修道之日起，一直到化凡之日止，所杀的每一个人**，一个不落。

随着木雕逐一成形并堆放在地面：
- 杀气由若有若无渐渐浓郁，**木雕每多一个，店铺内杀气便重一分**；
- 店铺之上除风雪外，已凝出一层寒冰（若有修士路过可清晰看到）；
- 王林对此视若无睹，完全沉浸于回忆。

## 二、亡魂木雕清单（按被杀先后）

### 第一人：孙大柱（王林的师父）
- 手起指落、木屑飞落，木雕再现其**临死前绝望中带恐惧**的表情。
- 王林心底一片平静，想的是：当年若非孙大柱**贪恋他身上的葫芦**，也断然不会落得身亡下场。
- 定论：**因果循环，有生自然有死。**

### 第二人：即墨老人的弟子（张虎之师）
- 中年男子，目光嗜血、嘴唇略薄，看起来极为刻薄；右手飞剑隐带寒芒，萧杀之气扩散。
- 当日此人对王林心生杀意，最终成为王林手中第二个亡魂。

### 第三人：藤厉
- 当年追杀王林之人。忆及藤厉，王林心境**略起波澜**，但很快再次平静。
- 指尖化刀、半柱香雕成：相貌英俊而面带桀骜，右手掐诀、目光阴沉、藏极深贪婪，嘴角已露势在必得的微笑。
- 作者点睛：这微笑已成过去；**与这微笑一同逝去的，还有整个藤家血脉**。

## 三、四百年人生回溯（王林以陌生人视角审视自己）

1. **恒岳派时期**：弱冠少年入门，天资不足、修炼缓慢 → 天逆空间 → 司徒南出现 → 恒岳派被玄道宗驱赶而出。
2. **散修与结仇**：离开恒岳派独自修炼 → 遇张虎 → 杀张虎之师（即墨老人弟子）→ 去藤家城，偏遇藤厉 → 与张虎分开，**至今不知张虎生死**。
3. **纷争开端**：藤厉追杀，最终死在王林手中；此后一路纷争，历经**尸阴宗、决明谷**。
4. **晴天霹雳**：父母死亡、藤化元狰狞的表情 —— 彻底改变王林一生；王林**肉身碎灭**，在司徒南帮助下**逃入域外战场**。
5. **四百年杀戮**：为提高修为、为回去复仇，不惜一切代价，让自己变得**无情、绝情、乃至冷血**。足迹：火焚国、修魔海、吉神之地。
   - **万魔百日诛杀令**：除藤家之外，杀人最多的一次。
   - **古神之地/吉神之地**：孟驼子等人刻骨铭心；此地多年是心神与身体的一次**完整蜕变**，但危机同样巨大，稍不谨慎便难以出来。
6. **结婴与复仇**：在**楚国结婴**，再次遇到李慕婉；结婴成功后，期盼四百年的复仇终于展开——在**赵国**，凡藤家血脉全部死在王林手中，了却这一恩怨因果。
7. **化凡三十余年**：生老病死，人生缩影一幕幕融入心神。

雕刻中王林的手越来越快，只见一片残影；脑中记忆画面同样越来越快。

## 四、顿悟：只剩「生、死」二字

- 许久之后，王林脑中不再有任何记忆画面，**有的只是两个字：生、死**。
- 生与死，是**轮回天道**的一种变化。
- **四百年的杀戮 → 明白「死」的含义；三十年的化凡 → 知晓「生」的意义。**
- 此前感悟轮回天道虽最终失败，却留下深刻的印象与意境，如同捅破一层纸，使王林在此刻一瞬间产生顿悟。
- 关键限定：**只是顿悟，并不代表看破。**

# 第272章 大牛

# 第273章 雪域降临

## 一、了却大牛之因

- **定位救人**：王林一挥右手以柔和之光护住大牛，随后飞至三万里外的凡人聚集地，在女眷房舍中找到大牛之妻。当年赠予二人的木雕上留有一道神念，使他可随时察觉、关键时救命。

- **破界送行**：带二人疾驰至邻国边界，此处有本国与邻国两道光幕阻拦。王林右手按上光幕、灵力倾吐，硬生生撕开一条可通人的通道。

- **大牛醒来**：以为做了一梦，梦中“王叔”样貌与当年年轻时一模一样；夫妻相拥痛哭。大牛抬头望天良久，明白那不是梦而是真实，却什么也没说，只拉着妻子朝京都方向重重叩首，默念“王叔谢谢”。

- **生死之叹**：三十多年前大牛还是弱冠少年，如今娶妻生子步入中年。与王林所悟**生死意境**相同——世间之事，始终难逃生死。

## 二、留下的理由：雨鼎

王林合上光幕后没有立刻离开四派联盟，因为还有一个目标未达成——**雨鼎**。

- **雨鼎定性**：对四派联盟而言既是祸端也是宝物；对修士而言，是**化神修士进军婴变的有效途径**；对王林而言是未来修真的契机。
- **灵气驳杂之困**：越接近化神，王林越察觉天地灵力不再干净、充满污浊。这不是灵气近年变了，而是他修为与意境提高后，身体能察觉到其中的问题。
  - 化神期以下吐纳无伤大雅——那种修为根本察觉不到驳杂。
  - 一旦达到化神想再进一步，**灵气品质将是首重之物**。
- **天逆珠露水的局限**：天逆珠子采集的灵力露水或因**五行不全**，虽略精纯仍差一些。
- **五行难补**：除水属性外，其余属性各需对应的**荒兽之灵**方可补满（如火属性需一只火系荒兽）。正因如此，王林**四百多年**一直无法补全。
- **战略结论**：进入**仙门**获取**仙灵之气**王林志在必得，故把目标锁在雨鼎上；而此刻并非取鼎时机，真正的关键时刻是**雪域修士与四派联盟开战之时**。

## 三、雪峰闭关一年

- 王林寻一处高耸入云的雪峰，整个人慢慢沉入其中；同时自储物袋取出**禁幡**祭起笼罩四周，身形彻底消失于雪峰之上。
- 目的：不知雪域修士何时会来，故抓紧一切时间加快**化神的最终一步**，以增大夺取雨鼎的把握。

## 四、一年后的四派联盟：死狱

- 大雪渐小（或因天空阵法起效，或因雪域修士将至）。
- 全境被冰雪覆盖，一年中大量凡人死亡；地面看不见尸体，脚下所踩却是冰雪与死尸所筑，**凡间已成死狱**。
- **四派分裂为两派**：一部分打算躲避风头，一部分坚决反抗到底。原因在于并非势均力敌——雪域国只是**四级修真国**。

## 五、雪域降临

1. 这一日，天空万里之上的巨大裂缝内散出大量**深蓝色寒气**。
2. 四派联盟正中间位置的裂缝内，走出一名**白衣女子**：衣白胜雪，相貌并非绝美，却有股仿若寒冬般的冰冷，似乎冰雪都不及她寒冷的万一。

- 王林的下一阶段目标明确：借雪域—四派之战夺**雨鼎**，冲**化神**、进而入**仙门**取仙灵之气。
- 四派联盟的护罩阵法被一击破去，雪域大军全面入侵开启。
