# 第907章 朱雀序列（第八卷 联盟隐秘）

## 一、十八层禁入：黄龙老道现身
- 场景：朱雀星仙遗族遗迹**第十七层**。塔山（仙遗族之人）刚要踏入**第十八层**。
- 一道浩荡威严之声响起：「十八层，不能进入」。
  - 塔山被震退数十丈、喷血；大头童子被震退；雷吉脑中空白不断后退；云雀子修为最低，被抛至尽头墙壁、喷血萎靡。
  - 王林运转体内元力，蹬退数丈稳住，面色苍白。
- 虚空波纹中走出一名**酷似黄龙的老道**：仙风道骨、不怒自威；高温疯狂弥漫，地面裂缝被生生凝固，**通往第十八层的道路全部被封死**。其气息一散即收、凝于体内，整个人充满危险感。
- 老道大袖一甩，**将云雀子、雷吉、塔山、大头童子四人直接送出仙遗族**，独留王林。

## 二、掌门问答：身份与归属的试探
- 王林判断留他必有深意，遂躬身抱拳：「恒岳派弟子王林，参见掌门」。
- 老道反问「谁是你的掌门」，王林答「前辈若不承认，权当晚辈认错了人」。
- 王林说明依据：曾去过**妖灵之地**，在那里的一幕画卷上见过老道之相。
- 老道点破关键：「堂堂**罗天星域的正品雷仙许木**，我哪里有这样的弟子。」——王林心神一震而神色不变。
- 老道追问「那雷仙殿正品雷仙之名，又是如何」，王林答：**「时事所逼」**，目光清澈无闪烁。
- 王林表态：**恒岳派是他第一个门派、踏入修真界的第一个台阶；朱雀星是他的家乡。**
- 老道定论（关键设定）：
  - 「我不管你在罗天是何身份、拜入过多少个门派」；
  - 「你虽说是**联盟星域**修士，但你是**朱雀星之人**，是**四圣宗内朱雀一脉弟子**」；
  - 「只要你不忘记这一点，**我永远都是你的掌门**」。
- 老道另一句要紧的"随意"之言：**「此番罗天之战，是修真联盟之战，与我四圣宗无关」**——四圣宗对罗天之战的立场划界。

## 三、警告：仙遗族本源之险
- 老道斥王林差点犯弥天大错：十八层非其可入；且身边跟着**仙遗族之人**（指塔山），
- **若被仙遗族之人取得本源，「别说这朱雀星，即便是联盟星域，也会有一场浩劫」。**

## 四、第十八层：符族本源与远古幻象
- 老道大袖卷起王林（不问其愿否），脚下地面成圆形现似岩浆之物、其内黑色火焰升空裹身，二人自第十七层消失。
- **第十八层**实况：百丈大小密室，四周漆黑，唯中间一团火光忽明忽暗；黑暗中仿若无数鬼魅之物欲吞噬，每次皆被火光震散。
- 老道明言：「此地就是**符族十八层**，那火团是**符族一丝本源之力**，你可尝试感悟。」
- 王林目光落上的刹那，奇异之力冲出融入心神；火团中含**对生的渴望、对力量的理解与明悟**，并有一丝血腥气息。
- 海量杂乱信息涌入王林头部，几欲轰碎其头：
  - 王林**左目为曰、右目含月**，**因果道念**在体内弥漫；
  - 脑中出现**阴阳双鱼**旋转，驱除大量杂念，最终显出震撼画面。

### 幻象内容（远古仙人 vs 符族之战）
- 浩淼星空中，无数**仙人**踏祥云与各种法宝；对面是数丈、数十丈乃至数百丈大小的**黄色纸符**，每张纸符上站着众多奇异之人。
- 符族之人：衣着与修士相仿，衣上有**仙遗族植物图腾**，以**图腾叶子数量**区分（等阶/地位）；**眉心均有符文闪烁**；神通诡异莫测、以符文为主，出手可**封印天地**、震动天地元力。
- 一名图腾叶片众多、其内**还有一片金叶**的符族老者立于数百丈纸符上，张开双臂放出体外符文冲击，星空震颤，众多仙人被符文笼罩、**失去仙元**。
- 关键时刻一道**黑光**闪来，其内有人影但看不清相貌；此人与符文老者交战，片刻后**右手双指抓入老者眉心，狠狠拽出一团充满生机的火团**。
- 火团被抓出即崩溃，化作无数火点四散；**其中一个火点直奔王林，印在其眉心**。
- 王林额头灼热、身子后退，退速快得仿若穿透岁月，随后清醒。

## 五、余波与"朱雀序列"
- 清醒后王林看那密室火团，越看越觉与幻象中**符族老者眉心的火团一模一样**；下意识摸眉心，却什么都没有——但眉心灼热感提示刚才一切极为真实。
- 老道在旁观察，目露赞赏，自语：**「不错，这小家伙可以从这种程度的符族本源上获得感悟，是个可造之人，再观察一番后，可以让其列入朱雀序列」**。

## 六、镜头切换：赤衣冰寒之人奔赴联盟西部
- 同一时刻，联盟星域内一块巨大石块急速穿行星空，**直奔联盟西部**；石上立一人，**衣着赤红、双目无情冰寒**。
- 其喃喃自语：**「罗天正品雷仙许木，你可不要太弱」**——为后续冲突埋线。

## 七、伏笔与待解
- 黄龙老道身份：作者按语称"可明白是谁"但未直接写出（自称/默认为昔日**恒岳派掌门**，且属**四圣宗朱雀一脉**体系）。
- "朱雀序列"具体为何、入列条件与待遇未明。
- 王林眉心所受符族本源火点的后续作用未明。
- 四圣宗置身罗天之战之外的立场，与王林"罗天正品雷仙许木"身份之间的张力。

## 归属说明（世界状态须知）
- 本章王林以**「许木」**之名在罗天/雷仙殿行事（自第661/669/711/731/771/821章沿用）。据须知，「许木」疑为王林**自创化名**而非冒用他人姓名，故按化名处理，言行归**王林**本人。
