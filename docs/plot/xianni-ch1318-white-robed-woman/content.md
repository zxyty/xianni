# 第1318章 白衣女子（第九卷 云海之巅）

## 一、别蓝山，独行星海
- 王林带李倩梅而来、独自一人而归，回望蓝色山峰似见山上隐隐身影，心中悲伤很淡却始终缭绕不散。
- 近两千年修道，看破世事，于孤独中学会寂寞，背影萧瑟。
- 蓝丝族星域范围极大，王林以挪移之术缓缓行至星域边缘，将出蓝丝族范围。

## 二、心惊肉跳：太古星辰第一次
- 身影闪出挪移的刹那骤然停顿：前方星空璀璨安静，美丽中透出诡异。
- 心惊肉跳之感，两千年修道中每次出现皆为生死危机，**最近一次是水道子来临前**。
- 这是进入太古星辰后的第一次，连拓森出现时都不曾如此。
- 先以神识扫过——星空寂静，一无所获。

## 三、五道本源破迷障
- 王林闭目，瞳孔深处运转：**蓝色火焰 → 外围闪电 → 生死太极（转动形成因果）→ 真假之变**，共五道本源急速旋转。
- 睁眼一望，可破开天地一切迷障、看出本源万物，**已无限接近当年在罗天星域无意施展出的「道魇之瞳」**。

## 四、白衣女子
- 所见：白衣女子飘在星空，好似幽魂，**没有半点生机与迹象，神识亦无法发现**；黑色长发披肩，微光笼罩其身使相貌无法看清；似有奇异之力，令一切落在她身上的目光都穿透而过。
- 王林脑中骤然浮现：**「她不是人」**。
- 二人对望，寂灭般宁静，谁也未开口。王林缓慢后退，双目微合，右手随意垂放、其上**血光隐现**（戒备），直至消失在星空尽头。
- 女子一动未动，事后轻声自语：**「他，竟然能看到我」**。

## 五、七日戒备与月余静修
- 退远后心惊之感转弱却始终存在，王林面色阴沉；联想到拓森此前眉心散出刺目之光、神色大变急急退走，隐隐觉得其中有联系。
- 进入最近一颗蓝丝族修真星（蓝色星球，海洋占据大半），落于一处山峰之顶，瞳内五道本源反复查看无果后盘膝吐纳。
- **七天**一动未动，白衣女子再未出现。

## 六、王林的推衍（心智已然成妖）
1. 该女所处位置**恰在蓝丝族星域之外**——蓝丝族有**蓝梦道尊**，修为无法估量，故其不敢入内。
2. 复盘全程：遇拓森后心惊之感便隐隐出现，带李倩梅赶路时亦有、微弱到几乎不可察觉，当时因忧心李倩梅生死而忽略；**此女一路跟随多日，直至他进入蓝丝族才停止**。
3. 疑点：若无临出境时骤然倍增的心惊感，他不会耗费不多的本源去查看——为何偏偏在此刻倍增？
4. 自查身体：元力比以往多了一些；古神之力未增却更为浑厚、好似被压缩；**元神与灵魂经历某种变化，更为敏锐**。
5. 结论：**数日攀登蓝山的无尽阻力带来翻天覆地的变化**——修为未提升，敏锐度提升无数倍，才使他能察觉微弱心惊。这一切若是蓝梦道尊故意使然，便是以此**暗示他离开蓝丝族的危险**；而该女来头之大，竟令蓝梦道尊无法直言，只能暗示，且蓝梦道尊定然算出王林会选择留在蓝丝族。

## 七、蓝梦道尊现身：九大神通
- 王林遂放弃立刻离开，山峰打坐吐纳共**一月**，天地元力融入其身，攀蓝山所受伤势全部好转，**修为恢复巅峰**。
- 一日，天空骤现无尽柔和蓝芒笼罩天地，中年男子身影凝实走出——**蓝梦道尊**。
- 开口即问：**「我有九大神通，你，学不学」**（章节收束于此，王林回应未叙）。

## 八、悬念与伏笔
- 白衣女子身份未明：非人、无生机、神识不可察、来头极大。
- 拓森的异常退走 ↔ 白衣女子，疑有关联。
- 蓝梦道尊的九大神通传授，构成下章走向。
