# 仙逆 第834章 炎雷子再现（第七卷 名震罗天）

> 归属说明：本章「许木」即王林（自创化名，自661/669/711章沿用），其言行归【王林】。

## 一、望月暴走：罗天北域星空屠杀

- **撞击**：望月庞大身躯高速前撞，星空似要坍塌，砰砰巨响；被撞者肉身崩溃化作血肉，元神亦被震碎无法逃脱。
- **音爆咆哮**：头部巨大裂口猛张（似要把身子一分为二），尖锐咆哮形成极强穿透力，以其身为中心扩散，如无数奔雷炸响，未逃远者当场肉身元神俱碎；咆哮更使四周星空碎裂，修士心神剧震而**无法瞬移**。
- **万丈触须**：无数长触须晃动，触之者面色苍白，连续被触则元神消散而亡。
- **小型望月**：乌光闪烁间，从口中冲出千丈、百丈、数十丈的小型望月群，四散吞噬后退修士，屠杀达到顶峰。
- **疑似神通**：望月口中传出复杂仿若人语之声，残存修士魂飞魄散——若此兽施展神通，四周恐被毁灭一空。

### 修士心声（信息点）

- 「为了姚家的赏赐，丢了性命却是不划算」——姚家悬赏追杀许木。
- 「这许木居然可以借此物之力」——外界认为是许木引动/借用了月兽之力。
- 「家族老祖说的对，此番追杀这许木，家族中只允许阴虚以下修士参与」——姚家老祖的限令。
- 共识警语：**「望月苏醒，便是浩劫」**。

## 二、十万里外：三人观兽与「一百零八仙」计划

**在场三人**（身影模糊、年龄各异、气息可怕）：

1. **炎雷子**——计划主导者，来自联盟星域，出身上古修真家族。
2. **公孙姓中年男子**——紫黑大袍，胸口绣阴阳图案，态度冷峻质疑。
3. **向姓红袍老者**——慈眉善目而目露寒光，属**东临星**，态度支持。

### 计划要点

- 炎雷子筹划**多年**，核心目标便是这头**月兽**；此行是让二人亲眼验证其实力以取得认同。
- 公孙评价：「你的计划，很疯狂」；向姓老者：「虽说疯狂，可一旦成功，却是足添了一成胜算」。
- 战略判断：罗天星域欲与**联盟星域**开战，但罗天修士**经历生死劫难者太少**——此为**家族修炼之弊**；反观联盟星域门派师徒亦勾心斗角、稍有不慎便被算计身亡，故一个个老奸巨猾、凶狠果断。
- **一百零八仙**：所寻正是许木这类**杀伐果断者**，以他们为带头人，使罗天星域修士经历**一场血的洗礼**。
- **血神子案例**：不惜拿出一件**只剩一次功效**的宝贝，换取一次**家族族人的血祭**，让族人适应接下来的联盟之战。炎雷子评其意在联盟之战中获取更多好处，但对其果断亦有一丝佩服。
- **反叛之虑**：公孙质疑许木来自联盟星域，恐其归去后反叛；炎雷子反诘「老夫也是来自联盟星域，你莫非就不怕我反叛」，公孙不再追问。炎雷子内心：已查明许木来历，其被追杀至此**与自己当年处境极为相似**，以其性子反叛可能性不大，即便反了「老夫出手杀了就是」。
- **月兽用途**：三人联手再加上「那几个老怪」，在**通道打开后**把月兽**赶入联盟星域**。

## 三、收尾：困兽与救人

- 向姓红袍老者立于凭空浮现的**血色八角图案法阵**之上，随阵而下，波纹散开如困牢包围望月；波纹令触者升起无法抵抗的错觉。老者神色凝重，大喝「你们快些，我阻拦不了多久」。
- 阵下望月怒气瞬间攀至巅峰，低吼咆哮不断，身躯疯狂。
- **炎雷子**自虚空一步踏出，大袖一甩，大量修士被生生卷入星空消失（救走）。
