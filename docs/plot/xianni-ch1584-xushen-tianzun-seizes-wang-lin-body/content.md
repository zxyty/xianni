# 第1584章 天尊夺舍！

## 一、坠落朱雀星，重回符文族第十八层

- 王林身体落入朱雀星，轰鸣骤起，星辰通体一震；其身如流星撞碎山峰，又被裂缝带入更深处，一路在**不断崩溃重组**中贯穿大地，直入朱雀星地底，与符文族洞穴连通。
- 此朱雀星虽由**掌尊以「井中捞月之术」**捞出，除其上没有任何生灵外，**一切依旧存在**：符文族地底洞穴如旧，第十八层百丈石室一侧墙壁坍塌，缺口外便是**域外战场**。
- 井中捞月连域外战场也一并捞出。域外战场虽为投影，但其内**无尽幽魂、无数骸骨一一存在**；唯独原战场那道「奇异的法则」无法幻化而出——**这成为后文游魂能够冲出的关键伏笔**。
- 王林落地再喷鲜血，全身金光弥漫，痛苦几近昏迷，死死咬牙承受一次次崩溃。虚神天尊那一掌蕴含极霸道气息，打在其背部，使**本就不完美的不灭体出现不稳迹象**。

## 二、虚神天尊夺舍

- 太古五尊之一的**虚神天尊**自贯穿地面的巨大窟窿一步走出：身子完全由**雾气**组成，双目贪婪。
- 其抬手抓向王林，恰逢王林身体又一次轰然崩溃——天尊双眼一凝，狞笑收手，化作雾气**冲入崩溃的血肉之内**。
  - 原话：「天赐良机，看来就连这天道也要让我夺舍你的仙体。」
- 不灭仙体再度凝聚时，金光下泛起**一片黑色**，弥漫全身并冲入心神脑海，狂笑不止：「这具身体，从此之后是老夫的了……享受那被夺舍前的滋味吧。」
- **夺舍进度**：王林先失双腿操控，继而右手与上半身尽失，**唯左手尚可移动**却渐渐麻木；体内记忆出现碎灭迹象，一股霸道神识欲尽知其一生并抹去记忆。
- 王林咆哮挣扎渐弱，身体不受控地起身飞出朱雀星。天尊借其口宣称：**只需最终炼化，连「天逆珠」都将是老夫之物**。

## 三、以吞魂之力反击——游魂风暴

- 飞出途中，王林**唯一可控的左手掐出印记**，一指下方符文族第十八层的域外战场。
- 王林**曾是吞魂**，对游魂有极强操控之力：整个域外战场投影内**无法计算数量的游魂**沸腾，呼啸成风暴，更卷动骸骨中栖息的游魂，**数个同为吞魂的存在**亦融入其中。
- 因此处**没有那道奇异法则的阻挡**，这是游魂第一次从域外战场冲出、第一次冲入外界。风暴顺缺口轰出，朱雀星剧烈震动，**如无穷恶魂解封**，星辰开始崩溃。
- 天尊虽修为远高于王林、强行把肉身崩溃压制为小范围重组，却仍无法根除崩溃。他转身面对两位仙妃与自冰层走出的白衣男子，口称「这场杀戮，结束了」——话未说完，**朱雀星轰然爆开**，黑色游魂风暴滔天而起，笼罩天地。
- 风暴以无法想象的速度直奔天尊而来：**似王林体内有个声音在召唤，仿佛那是它们的「王皇」**。无数游魂顺其身体疯狂涌入，转眼尽数进入王林体内。
- 王林身体再度崩溃，**波及数千丈**；游魂之力与王林自身力量融合，爆发滔天气息，在不甘的咆哮中把虚神天尊**生生从崩溃的血肉内逼出**，重新在半空凝为模糊雾身。

## 四、李广弓现世，四方溃退

- 天尊不甘，一步迈出欲再度夺舍；身后阴月快要弥漫全身的仙妃、以及带着冰寒萧杀的白衣男子同时逼近。
- 王林肉身在游魂相助下**重新凝聚且短时间不再崩溃**，双眼睁开射出万丈金光。此刻他已无法再顾及掌尊尚未现身，直言「你们找死」。
- **李广弓**：左手一伸，散发金光之弓现于掌中；右手握弦猛拉，弓弦被完整拉开，身体绷直，杀机疯狂。
- **环形箭**：弓上现出尖端为环形的箭，箭身有复杂符文，其内隐有**南诏与天兆的魂**发出凄厉咆哮，箭气缭绕，万古沧桑弥漫。
- 虚神天尊全身一颤、面色大变，扭曲惊呼：「**李广弓……你居然找到了这支箭！**」骇然疯狂后退，并道破：「**该死的，我知道那掌尊为何始终不出现了**，掌尊，此事老夫与你没完」「老夫不参与了」。
- 天尊捏碎手中玉简求援，**毫无反应**；两位仙妃比他更了解此弓箭威力——阴月女子无尽惊恐急退，另一仙妃面色苍白、再无往日高傲，颤抖后退并同样捏碎玉简，**同样没有反应**。
- 收束：「这一弓开，天地色变；这一箭现，风云倒卷。」

## 五、要点与伏笔

1. **井中捞月的漏洞**成为翻盘关键：法则未被复制 → 游魂无束缚 → 反噬夺舍者。
2. **吞魂身份**（王林旧日经历）在此章成为决定性底牌，游魂视其为「王皇」。
3. **李广弓 + 环形符文箭**为压制太古五尊级别存在的杀器；箭内封有南诏、天兆之魂。
4. **掌尊迟迟不现身**被天尊解读为「早知李广弓在王林手中」的算计，双方就此结怨。
5. 玉简求援皆无反应，暗示外部通讯/援手已被隔绝（疑与掌尊有关）。
6. **朱雀星（投影）就此爆碎**，符文族第十八层与域外战场投影随之消亡。
