# 第九卷 云海之巅 第1398章 黄毛丫头

## 一、少帝身份公开

- 元磁撕裂通道开启后，大帝使者疾驰至王林十丈外抱拳躬身，称『属下见过少帝大人』；其身后所有出通道的修士齐声『参见少帝大人』。
- 整个星空死寂，此地数百族落、数万修士震撼失色。
- 少帝之事数月前由**颠落大帝**以玉简发布通告所有族落，但未点名，故众修士此刻才第一次见到真身。
- 大帝使者解释：因元磁撕裂开启通道需时，故让少帝久等——但众人反应过来，实为**提前数个时辰开启通道**，以往从未有过。
- 舆论要点：
  - 颠落之地原只有两位少帝，王林是第三位，且显然更受大帝重视。
  - 少帝须通过**少帝试炼**方为真正少帝；试炼极艰难，历来有资格参与者无一成功。
  - 少帝职责极大，可代大帝统领颠落之地全部修士，连太古星辰的**长尊会**也要对少帝客气。
  - 亦有人不屑，认为王林是狐假虎威、『若非少帝岂能如此嚣张』。

## 二、当众立威：三桩处置

| 对象 | 前情 | 王林裁决 |
|---|---|---|
| 魂蛇族中年男子（魂蛇族大长老一系） | 先前得罪王林 | 大帝使者本欲拿下；王林道『罪不至死，但取消魂蛇族长老之选』——其人惨笑称『比杀了他还严重无数倍』，成为全族罪人 |
| 川河族族长 / 落生会第十三长老 | 曾拿王林立威 | 取消落生会长老之名，去**暗蝎族修真星长跪百年**；大帝使者略一犹豫，见王林目中冷漠即点头照办 |
| 云遁族族长 | 有意扫视王林、把矛头引向他，借刀杀人 | **自断一臂，下不为例**——该族长双指成剑点左肩，左臂经脉俱断，谢『少帝开恩』 |

- 第十三长老先前的心理转折：先侥幸『此人宅心仁厚、是个可欺之人』，随即被处置击碎；并回想到落生会**第九长老**正是因得罪王林而被大帝罢免（龙甲族之事）。

## 三、入元磁撕裂通道

- 王林在万众瞩目下步入元磁撕裂雾气所开通道。
- 通道内环境：充斥撕裂之力，并有阵阵**元磁吸撤**，体内元力略有涣散、仿佛要被吸出；但通道内吸力尚不算强，通道外的元磁撕裂则极为恐怖。

## 四、长尊会云落与司墨子来临

- 王林行出十多丈时，远处惊天呼啸传来：一座约数百丈、其上符文闪烁的**八角形巨大轮盘**轰隆临近大帝星，上立二人。
- **云落**：长发披肩、青丝飞扬、相貌秀美，双目如月色，状若仙女；自称『小女子云落，代长尊会拜见大帝，应邀观落生会长老之礼』。王林视其微笑充满做作之态。
- **司墨子**：神色阴沉、身影如山，威压如风暴迫退四周修士；体外环绕圈圈模糊烟丝，内蕴不下数百万扭曲虚幻容颜、发出无声凄吼——被认出是**香火之力第三步大能**。

## 五、王林与司墨子的对峙

- 二人目光相撞如剑芒。司墨子从牙缝挤出『小杂种』，煞气浓浓——其最记恨之事即**分身被杀**。
- 王林：『手下败将只会逞口舌之利，妄为大能』。
- 司墨子邀战，王林反激：『你可敢进入这元磁撕裂之雾，自毁修为于天人第五衰，与我一战』——四周哗然，司墨子言语一顿、面色阴沉至极：**他不敢**。

## 六、王林斥云落（章名由来）

- 云落笑问王林名讳。
- 王林冷斥：**长尊会大司不论修为、自古代代传承**；你这『乳臭未干的黄毛丫头』修炼怕是不足千年，也敢与我平辈称道友，长幼无尊，你师父就是这样教你询问前辈名讳的么。

## 七、要点归纳

- 王林的少帝身份自本章起在颠落之地公开化，并以三桩处置立威，确立其可号令族落、长老的实权地位。
- 引出后续线索：**少帝试炼**（尚未通过）、落生会长老之礼、长尊会（太古星辰）与颠落之地的往来。
- 司墨子与王林的旧怨（分身被杀）在此当众激化，但因实力/环境限制未能开战。
