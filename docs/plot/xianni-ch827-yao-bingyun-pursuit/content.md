# 第七卷 名震罗天 · 第827章 姚冰云

## 一、脱身与自评
- 王林（此期间以化名「许木」行事）自与姚长东一战后踏出星空，脚步踉跄、面色苍白，自评此战极凶险。
- 自我判断：姚长东不愧是窥涅初期的**真正第二步修士**，自己与之仍有很大差距；若自身达到窥涅期，杀之不会如此艰难。
- 他无法长时间融入天地，现身后急速前飞，数息后再度融入天地消失。
- 打算先找地方疗伤，伤愈后再寻姚家霉头。

## 二、寒凤姚冰云登场
- 王林消失刹那，一名冰冷绝美女子现身，评价：「连续两次施展缩地成寸，这许木对于天地之力的掌握，很强。」
- 身份：**姚冰云**，罗天东域尊称「三凤之一」，号**寒凤**；姚家三代族人中修为稳列前三，为人冰冷，对族人亦冷漠少言。
- 道途：天资仅算尚好，但对道的追求极坚。自问鼎之后改修家族**闭神仙术**——姚家三大禁术之一，自锁神识七窍（目不可查、嘴不可言、耳不可听、鼻不可闻），修炼者稍有不慎便彻底沉入神识自锁而亡；历代姚家均有死于此术者，修者日少。
- 经历：以此状态在姚家禁地之一的**寒冰星**闭关五百年，出关后仿若万年寒冰。
- 神通：姚家三代仅两人摸索到**缩地成寸**，姚冰云为其一，且是二人中感悟最深者。

## 三、出手动机（关键因果）
- 以她的性子本不会参与家族天穹令之事，宁可闭关感悟天道。
- **姚家老祖血神子**发布天穹令时明言：凡亲手杀许木者，可用**姚家全族之力**为其做一件事。
- 这是她动念出手的根源；心中默念「妹妹我一定要救你」——为救其妹。

## 四、二十八人阻截的余波
- 数个家族联合形成的二十八人阻截，被许木杀二十六，仅两人逃出。
- 阵容规格：3 名阳实修士、9 名阴虚修士、16 名问鼎大圆满——仍被轻易屠杀。
- 逃生者一人回修真星后宣布：此生其家族与修真星**绝不参与**许木与姚家之事；另一名阳实修士元神受损、更为狼狈，回族后立即闭关并发布同样声明。
- 「许木」之名在罗天星域被彻底唤醒，修士纷纷想起其在**雷之仙界**的种种行为。
- 几乎同时，**姚长东（窥涅初期）死于许木之手**的消息不知被何人传出，横扫罗天星域：天穹令下追杀者反被杀，震撼全域。

## 五、封锁与十六日的天地之争
- 姚家反应迅速：众多族人与各自联系的修真家族向**罗天西域**凝聚，密密麻麻形成封锁线，不断缩紧包围。
- 王林不做大范围挪移，而是持续融入天地、频繁变换方位，意在甩开同样能融入天地的追击者（未见其面，但感觉如髓入骨）。
- 比拼实质：谁对**天道**感悟更深，谁能在天地中停留更久；先出来者失主动。
- 王林曾经历**炎雷子的融身**，在那种环境下元神与肉身长时间融入天地，因此硬撑得住。
- 第十六天，姚冰云终于忍受不住现身，神识锁定随即失去踪影。她一拍储物袋取出一面**小镜**，左手掐诀推衍，休息片刻后再度融入天地。

## 六、废弃修真星疗伤
- 地点：**罗天西域与北域交界处**的一颗废弃修真星——无灵力、处处废墟，昔年曾有辉煌。
- 王林现身时已无血色（战伤 + 逃遁 + 长时间融天所致），确认被甩开后择一盆地盘膝。
- 手段：放出**尊魂幡**化黑雾弥漫四周，打出一系列禁制，闭目吐纳。
- **塔山**自其身后虚影中走出盘坐一旁：整条右臂碎裂、身多伤痕、神态萎靡。
- 疗伤方式一：自黑雾中抓出**阴虚元神**，不待求饶直接捏碎吞下化元力；六个时辰连吞四个，浩荡元力弥漫体外。
- 疗伤方式二：取出所杀二十八人的众多储物袋，一一抹去烙印，取出其内所有法宝**统统捏碎化液**，融入塔山体内修补；两日后塔山骨头恢复，虽仍萎靡但已无大碍。
- 起飞时右手向下一抓，黑雾凝于掌心化作**十丈大幡**，抖手收入储物袋。

## 七、正面交锋：雷球 vs 冰破
- 王林飞起同时，姚冰云娇影在星外幻化而出，翻转小镜，镜中正是跃起的王林。
- 她玉指向镜面按下，镜面却**先她一步碎裂崩溃**——王林的杀气自星内冲出。
- 王林如出鞘利剑冲出，身周无数**紫色雷球**轰隆雷鸣，速度更快，直奔姚冰云。
- 姚冰云神色平静，指上凝蓝色冰晶、散丝丝絮状之气，轻声道：「**冰破**」。
- 一指之下寒气疯狂弥漫，咔咔声中其前方大片星空虚无刹那冰封并迅速蔓延。
- 王林瞳孔一缩却不退，全身雷球迅猛冲出，在身前呼啸，与蔓延而来的冰封相撞——本章至此。
