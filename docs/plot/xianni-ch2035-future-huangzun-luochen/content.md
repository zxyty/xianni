# 第2035章 未来皇尊

## 一、故人罗尘现身

- 王林身影在天空一顿，引起道古族人与圣皇祖烨微注意。众人目光所聚者，是人群中一个极普通的大汉，修为仅**八星古神**，尚未称圣。
- 此人是**罗尘**——当年与**望月**融合、赠王林**古神之星**、见证王林古族成年礼的洞府界故人。
- 罗尘体内有一丝**道古皇族血脉**，来自**烨寞**：烨寞为皇族中人，其鲜血所化的洞府界后人或多或少都具皇族血脉。
- 罗尘自述：随**玄罗**回到道古一脉时，由玄罗助其与望月分离。
- 罗尘早知王林来到道古皇城，也想过相见，但王林身为玄罗唯一弟子、道古一脉未来守护者，而自己只是族中微不足道的小人物，差距使他却步。
- 罗尘眼中的沧海桑田：当年那个弱小青年，如今已是大天尊，杀了道古皇尊，连圣皇祖都无法阻止，只能开阵放行。

## 二、托付与赠血报恩

- 王林所托之事：**照顾烨寞的后人**。
  - 罗尘应「遵命」，并言自己本就住在烨寞大人的府邸——当年从道古殿走下后，他凭血脉感应找到烨寞后人；后人虽属皇族却已落魄，只余一座府邸，并接纳了罗尘。
- 王林左手银光一闪按在罗尘胸口，散出自身**一丝魂血之力**融入其身：
  - 罗尘全身银光剧闪，刺目至旁观者双眼生痛而收回目光；
  - 暖流涌入并与血脉融合，血脉刹那无比精纯，爆发出**堪比先前道古皇尊的血脉之威**；
  - 结果：罗尘在血脉上达到了**成为道古皇尊的资格**。
- 圣皇祖烨微失色惊呼「**魂血**」；玄罗目露复杂，轻叹。
- 王林留言：「当年赠送古神之星，今日守护烨寞后人，赠你皇族血脉，以报昔恩」，随即大袖一甩，携融入**李慕婉残魂**的**宋致**化长虹冲天而去。

## 三、玄罗定下未来皇尊

- 玄罗久望王林离去方向，惘怅化作一叹，转而看向罗尘：「我记得，你叫做罗尘。」罗尘单膝跪拜「参见玄尊」，体表银光渐凝入体内。
- 玄罗沉吟后果断一指罗尘，向烨微宣告：「**我选择他**。」
- 烨微迟疑良久，叹气道自己要继续闭关，皇尊人选请玄尊定夺，随后转身走入紫光棺木，棺木重沉地底。

## 四、吉道大天尊的缺席之谜

- 整个道古皇宫事件中，**吉道（古道）大天尊**始终未现身，连其送贺礼的使者也从未露面，仿佛有意避开。
- 身为皇族一脉守护者，即便道古皇尊死亡，古道大天尊依旧毫无动作；在场道古族人无人交谈，各自把疑惑深埋心底。
- 王林同样生疑，并已做**最坏打算**：若吉道大天尊来阻，他准备豁出去召唤**虚无分身**一战——明知败率很大，但必须战。结果对方未至，王林强压疑惑，先解眼前之谜。

## 五、荒山破雾，直面道古国师

- 目标：被**古祖一指劈成两半的荒山**，谜团核心是「**这神秘的道古一脉国师，到底是谁**」。
- 途中王林将宋致（融李慕婉残魂之女子）**送入储物空间**，因此行危机重重，不愿其受半点伤害。
- 王林一掌下压，巨大掌印轰击荒山，山体大范围崩塌如被抹去大半，露出下方**巨大阵法**；阵法上十色光芒闪烁形成**十色雾气**，王林掌力触之化作无数气泡一一破灭，阵法毫发无伤。
- 雾中传出沙哑飘忽之声：「你还是来了」。王林觉此声**似曾相识又陌生**，一时难以印证心中猜测。
- 王林冷声质问：国师藏头露尾；取走其妻**李慕婉**之命魂、让道古皇尊寻人融合，目的就是针对自己；以雾遮身，莫非怕被认出，或本就是他的**故人**。
- 沙哑之声笑答：你疑惑我是谁、如何带走李慕婉的魂并带入**仙罡大陆**、以及我这么做的目的——「进来吧，若你能破开这雾气，看到我的真容，你的疑惑，我可以为你解开一些。」
- 王林心神一震而神色如常，右手抬起：青色烟丝缭绕成圈直扑雾气；同时**金木水土四色极道**幻化体外，**第六道生死极道**一闪，在身前凝成含五行极道的**黑白二色六极道图腾**，旋转散发幽光，随手一挥轰向十色雾气。

## 六、悬念

1. 道古国师身份未揭——王林怀疑是自己的「故人」。
2. 吉道大天尊为何全程缺席、放任皇尊被杀。
3. 十色雾气/巨大阵法的来历与是否可破。
4. 罗尘作为「未来皇尊」的后续走向。
