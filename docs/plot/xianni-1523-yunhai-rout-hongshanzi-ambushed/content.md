# 第1523章 溃败！（第十卷 叱咤界内）

## 一、王林震场：肉身逼退数万界外修士

- 战场因王林一句话骤然安静。数万方才围攻的界外修士被其肉身之强震撼，眼露骇然——在他们疯狂攻击下竟不死。
- 手臂断开的老者率先毫不犹豫后退，带动数万界外修士疯狂退却。
- 云海修士欢呼「云海荣耀，封尊荣耀」，士气如服强心散，继续杀戮。
- 王林走出风暴，右手一挥崩溃风暴，虚火弥漫、雷霆咆哮，直冲八方修士。

### 王林的真实状态
- 方才的**万人神通**已令其**重伤**，伤势远重于外表所见。
- **七星古神**的恢复速度在这场持续战争中已隐隐跟不上消耗。
- 他杀红了眼，清楚此战远未结束——「他，不能退」。

## 二、阵法之困：云落大司的推衍压制

- 受鼓舞的云海残余近三万修士，依托红杉子所传的一套套阵法齐齐布阵。
- 但每次阵法将成即被界外修士提前冲杀打断，三次、四次、五次六次后已绝非巧合。
- **根源=云落大司**：她在界外修士深处被大量修士护卫，玉手掐诀推衍，一指之下一道道封命传出，操控大军分四个方向杀向界内；界外大军因她而「拥有了灵魂」。
- 她仿佛可知一切先机，令云海始终无法成阵。每有阵法萌芽，一指之下便有大量界外修士狰狞扑去扼杀。

## 三、红杉子的关键作用与决断

- 红杉子修为已至**空玄中期**，距后期仅半步，面对五个界外大能完全占上风，但被暂时限制了活动范围。
- 其战略价值：**一人拖住除被封尊玉佩困住的天罚殿殿主外的所有大能**，使无人干扰王林、无人阻止南云子修补封界大阵。
- 他与王林同时望向云落大司，杀机闪烁，大袖一甩身外弥漫红云，卷着五个大能破开星空，出现在封界大阵旁。
- 宣言：**「此女不死，此战长殆」**。

## 四、陷阱：寒冰风暴 + 仙妃偷袭

- 云落大司神色如常、眼中嘲讽——她心高气傲，放眼界内界外除三人外无人入其目，**她等的就是红杉子或南云子的到来**。
- 红杉子临近瞬间：封界大阵一震，冰寒之气冲出。太古星辰内**九颗被冰封的修真星**骤然一颤，其内**童子**（寒衣童子/寒冰童子）微笑迈步——动的不是身体，而是那巨大寒冰。
- 寒冰瞬移至封界大阵外，撞破大阵撕开巨大缺口进入界内，随即崩解为无法形容的**寒冰风暴**，直奔三万云海修士。
- 童子一步迈出逼近红杉子，冷言：**「血衫童子，当年你我二人全是童子之样，战之多次，不够酣畅……恢复你的本体出来，这区区分身，老夫战之不酣」**——点破当前红杉子为**分身**。
- 红杉子未答，后退一步入寒冰风暴，大袖一甩震散风暴——却面色大变。
- 风暴内藏着一道**红影**，扭曲妙曼，快至不可思议，临近不足十丈即触及红杉子，一触即退，娇笑中化作**红衣女子**——即以三滴本命鲜血化作三头鬼影的**仙妃之一**。
- 红杉子面色苍白、后退数步，胸口现**鬼头状血痕**，狰狞扩散。红杉子怒斥：「你如当年一样卑鄙，半点也没有改变」。

## 五、云海荣耀的崩溃

- 被震散的寒冰风暴因红衣女子出现而未完全瓦解，残存之力极速笼罩云海修士：修士身起寒霜、化为冰雕、轰轰崩溃，**转眼近万修士齐齐死亡**。
- 红衣女子当众揭破全局算计：
  > 「云落那丫头早就算出了一切，此番开战，就是为了杀你与南云子；寒衣童子猜出你会为了救云海这些蝼蚁而阻止寒冰风暴，云落算出你在这紧迫之中无法看得清晰，我便隐藏在内，给你一次重击。」
- 残存云海修士眼露绝望：一切都在对方算计中；连红杉子都被算计，他们拿什么维持荣耀、拿什么死战下去。**荣耀如天塌般崩溃。**

## 六、决战与新一波大军

- 云落大司讥讽更浓，玉手一指下达封命，界外修士发起**决战**，无数修士狞笑冲出，死亡惨重。
- 红衣女子不理红杉子，秀步直奔正在修补封界大阵的**南云子**；南云子长叹放弃修复，转身与**灵动周瑾**一同迎战。
- **寒衣童子**不给红杉子疗伤机会，如万古不化之寒冰，与五个大能**同战红杉子**。
- 界外太古星辰**第三波大军**：十多个部落组成的**六万修士**列阵，直奔封界大阵。

## 七、收束

- 星空震动，云海似再无援军，此战将败。
- 王林沉默后退至云海修士之前，眼露滔天战意，在绝望中发出惊天怒吼：
  > **「我辈修士，何惜一战唯死尔！」**

## 关键转折清单

1. 王林肉身逼退数万界外修士（士气正向峰值）。
2. 云落大司推衍压制，云海布阵全废（技术性绝境）。
3. 红杉子出击斩首失败，反落入预设陷阱（战略支点被撬）。
4. 寒冰风暴 + 仙妃偷袭：近万云海修士死、红杉子重伤（战力与士气双崩）。
5. 荣耀崩溃 → 界外发起决战 + 第三波六万大军压境（局势逆转）。
6. 王林以死战之吼收束本章（悬念留至下章）。
