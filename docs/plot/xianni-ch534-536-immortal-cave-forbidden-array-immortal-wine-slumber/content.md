# 仙逆 第560-561章 沉睡 / 收获

## 一、最后四丈仙禁（第560章）

- 王林行至六丈处停步，退后三步、侧方走出九步，再退三步改向直奔正前——绕小圈只为贴着**移动中的生机**行进，始终保持距离生机仅一步。
- **仙禁特点**：禁制内始终留有一线生机，危机时踏入可保命；但生机方位随禁制变化时刻改变，非固定。
- 两个月的推衍重点有二：禁制本身 + 生机方位。前六丈尚可，最后四丈以他的修为一步走错便万劫不复。
- 七丈处掐指计算后连踏两个一丈；第二步落下瞬间他察觉**阵法禁制反方向颠倒运转**，当机立断向左迈出半步。
- 厅榭十丈内随即爆发**黑色飓风**，内有黑色闪电如游龙横扫，毁灭之力即便问鼎修士在其中超过三息也会身亡。王林在闪电间穿行，步步踏生机，十息后飓风与闪电尽消，他一晃踏入厅榭，额头大量汗水。

## 二、洞府之资格与洞府之令

- 踏入瞬间厅榭四周十丈光芒万丈，景物大变：拨云见雾般显出假山之地、青草、竹林，与原有竹林相连。
- 虚无中传来平淡声音：「破开禁制，便暂时获得了拥有这洞府的资格，只要你不死，便不会有人再进入这里。」
- 一枚手指大小、散发七彩之光的**水晶令牌**飞来：「此为洞府之令，持此令，可进洞府。」令牌上另刻有进入与离开洞府的口诀及简短信息。
- 厅榭内石桌石椅皆有禁制守护，但威力远弱于十丈大禁。

## 三、仙酒与一年沉睡

- 目标锁定圆桌上的**酒壶**。壶外禁制精妙但难不倒王林：手指点在三寸外泛起的水波纹上，弹出一道禁制残影，水波中心成漩涡扩为圆孔，右手探入抓壶而出。
- 壶略沉却只余**约十滴美酒**，清香扑面。王林判断绝非凡物、疑为仙人之酒，挣扎后一咬牙倒出一滴吸入口中。
- 入口即全身通红，狂猛**仙力**洪流般走遍经脉，丹田火热直冲天灵；微醺渐浓，双目由清明转浑浊，最终歪头沉睡。

### 沉睡期间（整整一年）
- 王林数百年修道以来最长一次睡眠，鼾声远传。
- 体内仙力疯狂增长，速度连**天运子**在旁看到也会一惊。
- 仙力达到一定程度后，丹田内的**妖晶**无声碎裂、融化，妖力弥漫旋即被仙力吞噬同化为自身一部分。
- 一丝丝游离仙气自体内散出，一年后厅榭方圆十丈仙气极为浓郁。
- 右手始终握着酒壶。

## 四、醒来：修为直逼问鼎

- 醒来打了个酒嗝，迷茫瞬转清明，警惕四顾后内视，露出罕见的震惊：
  - **体内仙力已远超婴变后期大圆满**，只需**意境感悟**成功，便可一举达到**问鼎生死**之境。
- 后怕：幸亏意境未至问鼎；否则沉睡中若仙力足够自行冲击，因无法取出**周佚的问鼎之晶**，一旦失败便死得太冤枉。
- 处置酒壶：放入储物袋 → 觉得不放心 → 取出打下数个强力禁制封印 → 再放回。
- 决意：「此地，我要彻彻底底的全部搜刮一番」；并定下计划——**待意境达到，就在这最隐秘的洞府内冲击问鼎**。
- 感慨：祸兮福所倚，若非机缘进入此地，纵有足够仙玉也不知需多少年月才能达此程度，「这莫非就是凡人口中的奇遇」。
- 隐忧：不知睡了多久，若是数十年乃至百年，外界必已大变。
- 新发现：竹林内露出一处雕栏一角，是一处阁楼，形似**凡人庭院内的祠堂**。王林未去查看，判断洞府是个大宝藏、蕴含很多秘密，打算出去后再回来慢慢挖。
- 以水晶小令心神融入，身影消失于洞府。

## 五、出洞与返程（第561章 收获）

- 洞府外平台上光芒闪烁中现身：**洞府之灵已消失，原本的石门也消失无影**，仅地面上姚惜雪喷出的几处鲜血痕迹仍在，可证方位无误。
- 顺平台外的**尊龙之路**疾驰，途经十一个平台，各平台石像**仍保持被姚惜雪封印的状态**，无任何变化。
- 修为提升至**婴变后期大圆满**后速度质变，比奔雷闪电还快几分，仅半个月便回到**第一处平台**。
- 第一处平台空无一物，但凭此刻修为与连续两个月破禁的提升，有心查看之下**察觉到血祖留下的传送阵法**。

## 六、开姚惜雪的储物袋（悬念收束）

- 取出四个**姚惜雪的储物袋**；此前以婴变中期修为开启颇有难度，如今修为**甚至比姚惜雪还高出一些**。

- 正欲一鼓作气抹去第四个时，**神色一变，右手蓦然而止，停在第四个储物袋三寸之上**（本片段止于此）。

# 第561-562章 姚惜雪战利品清点与返回古妖城军营

## 一、四个储物袋的清点

王林此前夺得姚惜雪的四个储物袋，因修为不足一直未细看，此刻方以神识逐一查验。

### 1. 带血祖神识的储物袋（陷阱）
- 表面寻常，但血光中隐有一道**紫线**，非神识查看、肉眼绝难发现。
- 王林试图抹去其上神识时立生心惊肉跳之感，判断此非姚惜雪的烙印，**恐为其父血祖所留**。
- 常理下外人不抹神识无法开袋；血祖修为通天，另有法门让女儿在不抹神识的前提下取用袋中之物——外人若大意抹除，立刻被袋上神识杀死。
- 王林由此对血祖既敬佩又忌惮（他从未见过血祖本人，只凭血魂丹辨认之法与此陷阱推知其人）。此袋被小心收起。

### 2. 仙玉袋
- 满袋**仙玉**，数量无法估计，粗略一扫约为姚惜雪此前所赠的**十倍以上**。
- 王林感慨：问鼎所需仙玉极大，甚至远超此前修行总耗；问鼎之后每提升一阶用量更不可想象，储备不足只能止步。此为一笔横财。

### 3. 血色玉符袋
- **不下上千块血色玉符**。碎裂后释出血光，封印之力极强，兼具强大防护。
- 王林猜测其亦可攻击，但无对应口诀心法则无法发挥。
- 他当场捏碎一枚试验，确认自己只能用其防护之效；并暗道"有姚惜雪在手，一切都可以得到"（口诀可后续逼问）。

### 4. 杂物袋（含真血魂丹与罗盘）
- 女儿家衣物、香料、首饰、玩偶等被直接无视。
- **十多枚血魂丹蜡丸**整齐放置一处，符文黯淡无闪烁。
- 角落另有**一枚单独存放**的血魂丹，符文轻微闪烁——王林据存放位置推断其**八成为真**，其余多为假丹。
- 王林取走真丹收入自己储物袋，把自己那枚假丹丢回姚惜雪袋中（掉包）。
- 另有**血色罗盘**一枚，为王林此行目标。
- 结论：姚惜雪袋中除血色玉符外别无法宝，法宝应尽在血祖神识那袋内。

## 二、血色罗盘与传送阵改造

- 罗盘通体血色，材质不明，入手冰凉；姚惜雪当初正是以此进入此地，**与此地阵法有"对点"之效**。
- 罗盘内仅有姚惜雪神识烙印（若是血祖烙印，王林只能被迫改动平台阵法离开），王林轻易抹去并留下自己的神识。
- 罗盘内藏**小型阵法**，随指针摆动无时不在变化；传送阵须**罗盘与平台两端同时改动**方能生效。
- 洞府东北角虽另有传送阵（王林得水晶小令后已知），但一路禁制封印难以抵达，故只能走罗盘这条路。

### 布下杀局
- **三天**改动平台传送阵：改动虽小但换了一个关键位置——除他之外，外人进入即被反复来回传送，往返之下必致**空间壁破碎**，进入者卷入其中。
- **三十天**在阵上增设无数禁制，理由是"进入空间裂缝并非会死，还需要额外加一些变化"。布置过程中他不但不烦，反而颇为开怀，暗道"若真有人传送而来，定会大吃一惊"。

## 三、返回古妖城军营

- 王林开启罗盘阵法，血光裹身，数息后消失，出现在**古妖城（吉妖城）军营千里外的鼓山**之上。
- 远望古妖城轮廓如初，王林有隔世之感，化长虹直奔军营，速度远胜离开之时。
- 临近时军营内一股浓浓杀机锁定他。

## 四、第562章 婴变期圆满的实力——闯营立威

### 军营阵容
- 上万黑甲妖兵列于正中，前方一名**黑甲大汉**背手冷视营外（妖力相当婴变后期，未达大圆满）。
- 大汉身侧**司马炎**恭敬侍立，满脸敬畏；另有三名统领同样恭敬列于身后。
- 四名统领中三人修为相当**婴变初期**，一人相当**婴变中期**。

### 交锋过程
1. 营墙释出黑雾状防护屏障；王林毫不停顿，仙力一散，黑雾消融退开露出通道，从容踏入。
2. 黑甲大汉喝"闯营者，杀无赦"，三统领化黑芒冲出，司马炎认出王林后犹豫、咬牙跟上；四人妖力化作四头虚幻巨兽助势。
3. 王林原地不动，只说"**退下**"二字，声中蕴含**婴变后期大圆满**仙力，如奔雷炸响：三名婴变初期统领面色苍白、心神震动而止步，唯婴变中期者勉强抵住但随即退避不敢阻拦。
4. 王林缓步前行，万名妖兵自动让出通道；老兵忆及当年、复杂敬畏，新兵见统领不敢阻也不由自主退开。
5. 王林目光冰寒如万年不化之冰，气势步步凝聚，**地面随其脚步蔓延大片寒霜**；黑甲大汉踏前一步放出气息，落在王林身上即刻消散。
6. 大汉气势转弱，欲退而强忍（知一退即失势、对方必出手），那压力只在面对**妖将**时才有过。至相距二十步，其额头沁汗，喝问"王统领，你意欲何为"。

### 关键对话
- 王林："这是我的军营，你说我意欲何为。"脚步未停。
- 黑甲大汉："你失踪一年多，早就被**妖将大人**罢免了统领之职。"
- 王林内心："一年？原来只过了一年。"松了口气，气势更浓。
- 王林开口追问："我的两个随从，身在何处"——他入营时神识横扫，未发现**十三**与**虎咆**。
- 司马炎此时正因想到十三与虎咆的遭遇而心底叫苦、极为后悔当年招惹王林。

## 五、要点与伏笔
- 血祖之能已借储物袋陷阱侧写，为后续大敌埋线。
- 真血魂丹被掉包，姚惜雪即便取回储物袋亦是假丹。
- 洞府传送阵已被改成"卷入空间裂缝"的杀局，静待来客。
- 十三与虎咆下落不明，司马炎的反应暗示二人已遭不测，是紧接的冲突引信。
- 时间锚点：王林入洞府至此仅过一年（外界），统领之职已被妖将罢免。

# 第563、564章 救十三（两章合一）

## 一、镇压黑甲大汉都统

- 王林与黑甲大汉相距十几步，以气势相压。大汉身为**都统**，若被一名**统领**（王林现职）的气势所震，职位不保，故强行抵抗——尽管王林修为已超过他。
- 王林看出对方濒临崩溃，骤然连踏七步，气势如万丈山峰平地而起；大汉被迫退后一步，气势一泻千里，反使王林气势瞬间攀至顶峰。
- 王林**婴变后期大圆满**修为迅猛展露，如闪电踏空而至。
- 大汉双拳身前相击，化出声之波纹；同时体内妖力迸发，身后幻化出约百丈大小的**玄武**——背生无数利刺，长尾利刺更多，甩动可破开空间，留下数道黑色划纹。

## 二、寂灭指破玄武

- 王林抬拇指施**寂灭指**。因修为达婴变后期大圆满，此指威力较此前增加数倍不止。
- 一指之下天地妖力疯狂融入其拇指；四周妖兵虽已散开，仍有妖力被吸；几名不认识王林的妖兵全身血肉翻滚，化作精华自七窍散出，幸得同伴拉开才免于死劫。
- 军营陷入昏暗，大汉的声之波纹当场崩溃。
- 大汉遁入所化玄武之内，双目露妖异之芒——这是王林在**妖灵之地**第一次真正见识本地妖民的**妖力神通**。玄武仰天咆哮，长尾抽向王林。
- 寂灭指按下，玄武之尾无声无息寸寸崩溃并波及全身。叙述指出：婴变大圆满与相当于婴变后期之间差距如沟壑；且王林神通本就强大，**这一指已无限接近问鼎**。
- 大汉黑甲碎裂、喷血退后数步、单膝跪地，但**未伤根基**——王林评价：若换作修士，此指不死也要修为跌宕，遂叹“妖力神通却有过人之处”。

## 三、搜魂与杀司马炎

- 王林隔空抓来**司马炎**，问“我的随从，在哪”。司马炎称王林走后半年二人失踪、不知去向。
- 王林左手双指成剑点其眉心，再度施展**搜魂术**。司马炎剧烈抽搐、七窍流血、双眼鼓出，一年多的记忆尽数展现。

### 搜出的真相
- 王林走后半年，**十三**与**虎咆**争执：虎咆不愿再等，欲回部落；十三坚持在营中等王林归来。
- 虎咆离开未成，司马炎轻易将其擒住，以**违反军规**为由废掉其全身修为，扔入**黑牢**；入黑牢三个月后，虎咆**神秘失踪**——黑牢守卫森严，连司马炎也不知其如何失踪。
- 十三出手相助虎咆，不敌司马炎，被**捏碎全身筋骨**，本也要扔入黑牢，却被**黑甲大汉都统**看到并把濒死的十三带走。

### 处决
- 王林怒极反笑，连说三个“好”字，运转**杀戮仙诀**：司马炎肉眼可见地枯萎，数息后身躯砰然崩溃、化作血肉散落，丝丝灰气自血肉飘出凝于王林右手指缝。
- 设定要点：**杀戮仙诀很难炼化而出**，此次是在王林怒火之下自司马炎身上炼化成功。

## 四、十三的下落与放过大汉

- 黑甲大汉自陈：**妖将**多年前有令，寻找身体强度足够之人；十三（“蛮子”）全身妖气凝集于体，以奇异方式炼体，身体强度符合要求。大汉为其疗伤后，将其**送给了妖将**。
- 大汉冷笑激将：“你若有本事，不必在我这里卖弄，你可敢去找妖将大人索要”，并保证事涉妖将不会撒谎。
- 王林判词：“**你救下十三，又把他送给妖将，功过相抵，我不杀你**”，随即化作青烟直奔古妖城中心妖将宫殿。
- 大汉本已抱死志，闻言一怔，仍提醒关键情报：**妖将半年前闭关，一切传送阵都被封死，你若要去，唯有闯宫**。随后带伤返回寝宫闭关疗伤。

## 五、王林的道心自省

- 神识横扫全城，确认凡通往妖将处的传送阵**皆从内部锁死**，与阵法禁制无关，非妖将自内开启无法传送。
- 王林暗叹十三、虎咆是被自己牵连——他临走时未料到会在洞府内沉睡（阴差阳错）。
- 内心独白（核心道心宣言）：
  - 修道求长生、求脱离天命牵引，本应避祸端、迎天运；为非亲非故的二人闯宫，是**逆了妖将，等于逆了这天妖郡**，从利害看“是为不值”。
  - “但，我王林行走天地之间，不求循规蹈矩迎天向道，但求**一生无愧于心**……只是天地之事，有一些，为了执念，必须要做。”
  - “从这一点上看，我，**不适合成为一个修道之人**。”
  - “若不救十三，我王林一生求道，求的是什么道”

## 六、闯宫：破第六门、第五门

- 布局：从军营至妖将宫殿共有**六门**，无传送阵时须逐一闯过；六门内外把守森严，**此地有阵法笼罩，一切瞬移无法施展**。
- **第六门**：高约十丈，四周连接外墙，阵法禁制之光闪烁。守卫喝令止步，再进半步杀无赦。王林一抹储物袋放出**仙剑**（剑内传出**许立国**的连连吼叫），剑绕身前；踏步前行，剑芒开路，妖兵惨哼；王林踏剑而上，剑芒化作十丈光芒轰碎第六门。
- **五、六门之间广场**：数千妖兵受碎片冲击退后。王林平淡而威严地说“我要见妖将”，妖兵齐吼“杀”（其使命为妖将闭关时杀死一切闯入者）。王林掐诀挥手，凭空生出飓风漩涡弥漫广场，硬吹出一条通道，径直横渡广场。
- **第五门**：王林右手掐诀凝聚仙力一按，第五门崩溃，碎片如风暴四散。
- **第五门后**：上万妖兵早已严阵以待，妖力以奇异方式凝结成一股逼人妖气疯狂冲来；以王林修为亦须退后数步暂避锋芒。王林一拍储物袋，取出**三把得自朱雀星的无名剑鞘**，三道剑气如三条怒龙涌出，撞向那股妖气。（片段止于此）

## 七、待续线索

- 虎咆在黑牢中神秘失踪之谜未解。
- 十三现落于闭关中的妖将之手，生死与用途（“身体强度足够之人”）未明。
- 第四门至第一门尚未闯过，妖将本人未出场。

## 场景

王林闯入妖将驻地的层层门户（六门→一门），目标只有一个：见到妖将。全程以「先礼后兵」推进——先通名求见，妖将闭关不应，遂展开杀戮。

## 推进过程（按门序）

### 五门 → 四门
- 上万妖兵结成「妖力之墙」阻路，王林以仙剑开道、拿出**禁幡**抖出无数禁制化作黑色游龙护身，势如破竹。
- 通名「妖将大人，王林求见」，笃定闭关中的妖将亦能听见，但妖将毫无反应。
- 数千妖兵自五门外杀入形成前后包围，王林被迫出手：抬起拇指施**寂灭指**，方圆百丈妖兵瞬间枯萎，血肉妖力尽数被吸入拇指。
- 一指按塌第四门。

### 四门内：苍发老者
- 四门崩溃瞬间，一名**苍发老者**踏出，妖力化巨蟒扑咬并喝令「给我退下」。此人即一年多前与管事参军同去黑甲军营者。
- 交锋结果：王林退一步，巨蟒寸寸崩溃，老者闷哼退后数丈。老者骇然——一年多前双方修为相仿，如今王林修为暴增；此番若非借妖兵之势、打开体内全部封印近乎偷袭，对方根本不会退这一步。

### 四门 → 三门：杀戮仙诀 + 化魔指
- 王林宣告「既然妖将大人不见，那便莫怪王某展开杀戮」，指缝灰气散开融入四周，双目涌现红芒，施展**杀戮仙诀**。
- 数万妖兵结阵，将妖力凝聚为妖兽、妖器轮番轰击。王林操控**仙剑、弯刀、禁幡、剑鞘**四宝屠戮；杀戮仙诀每杀一人便增一丝威力（约百人中方能凝出一丝灰气）。
- 仙力飞速损耗，王林一拍储物袋放出大量**仙玉**，吸成飞灰补充仙力，周而复始，仙玉大量损耗。
- 施第二式杀招**化魔指**（未引动体内魔念，纯以婴变后期大圆满修为施展）：魔气推开妖力，一指之下百丈内妖兵被魔气钻体自爆。
- 地面鲜血化作**血龙**顺化魔指冲出；化巨蟒的苍发老者阻拦血龙时身体砰然崩溃——**死于化魔指下**。血龙轰塌第三门。

### 三门内：五个婴变后期级老者
- 三门崩溃后涌出上万妖兵，另有**五名苍发老者**，修为各自不弱于婴变后期，目光锁定王林。
- 王林自知以一己之力至此已是极限，欲破第二门唯有动用最后一招。

### 黄泉指（第三式杀招）
- 来历：**司徒南传授的必杀之击**，王林所有神通中威力最大，惊天动地，**无限接近下品仙术**；司徒南当年传授时也曾大为犹豫。
- 异象：小指横扫一圈，轻吐「黄泉」二字——天空骤暗、奔雷划过，天幕如被人一手拨开，现出**巨大山水画轴横铺天际**；灰气自画幕疯狂扩散融合，在天空幻化出**另一个由灰气组成的黄泉指**与王林相辉映。
- 效果：一指之下，包围的数万妖兵齐齐一顿，灰气自其头顶散出汇入天空黄泉指；王林升空与黄泉指相融，天地间只剩这一指。**每一道灰气便是一条性命**，灰气入体使威力攀至巅峰。
- 战力标尺：婴变中期时凭此指曾与**问鼎中期的孙涛**一战（虽败但令孙涛极大震撼）；如今婴变后期大圆满施展，足以**威胁问鼎修士**。
- 结果：五名老者咬牙阻拦，尽数口喷鲜血、不由自主退后，无法阻其半步；**第二门在王林尚未临近时即被黄泉冲势轰塌**。

### 二门内：妖将麾下第一都统
- 第二门内无妖兵，只立一**身材矮小、目光如电**之人。其如修士般掐诀、双手叠加前推，在掌前三寸凝出**拳头大小的白色小球，内有无数黑色闪电闪烁**，硬接黄泉指。
- 坚持**三息**后被生生推退，地面留下两道深深划痕，一退百丈；黄泉指如漩涡般不断吸他生机。
- 对话：「王统领，我乃妖将大人麾下第一都统，你到底想要干什么？」王林答：「我要见妖将。」
- 话音方落，二门外数万妖兵再次散出大量灰气自四面八方涌入王林体内，黄泉指威力登顶。矮小之人面色大变再退，直接被推撞**第一门**——第一门崩溃，其口喷鲜血被远远抛飞。

### 一门内：十崩拳意
- 第一门内踏出一个**高大身影**，二话不说一拳挥起迎向黄泉指。
- 王林瞬间感受到拳中战意：**十崩拳意**——一崩、二崩、三崩……七崩、八崩、九崩，如洪水滔天、一波强过一波。
- 第十崩落下，轰隆巨响中大地如被掀起，向四周扩散成海面般的波浪，**波及十里**。片段止于此，胜负未分。

## 王林的核心感悟：妖灵之地以兵权为重

- 「在妖灵之地，一人之力，无法逆天。」除非神通滔天，否则面对无数妖兵以阵法凝聚妖力，突围极难——可杀一人、十人、百人、千人、万人，但杀完后体内仙力也已耗尽。
- 若有数十万不弱于结丹的妖兵，即便问鼎修士也一样要败。
- 若有千万不弱于结丹的妖兵，再加上一些**统领、都统**程度的将领，配合阵法，即便**问鼎后期**修士也敢一战。
- 若有**妖帝之郡**、集合亿万妖兵，配合**妖帅、妖将**，则纵有达到**问鼎虚实阴阳二意**的修士，又有何惧。

## 设定要点归纳

- **三式杀招**（司徒南所传体系）：寂灭指（吸摄血肉妖力）→ 化魔指（魔气钻体自爆、可催血龙）→ 黄泉指（抽命化灰气、无限接近下品仙术）。
- **灰气**贯穿杀戮仙诀与黄泉指：杀人可凝灰气，灰气即性命，反哺神通威力。
- **妖灵之地军制层级**（本章可见）：妖兵 → 统领 →（都统）→ 妖将 → 妖帅 → 妖帝（妖帝之郡）。王林在此被称「王统领」。
- 王林此时身份带「王统领」之称，说明其已在妖灵之地军制中任统领之职。
