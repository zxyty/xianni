# 第1697章 帆布的鬼脸

## 一、场景与开局

王林静心沉浸于魂魔舟甲板禁制的研究，船外七彩道人轰击禁制光幕之声仿佛被隔绝。

**帆布鬼脸异象**：一阵诡异之风凭空出现，吹到魂魔舟船杆上掀起帆布，帆布上森森鬼脸双目露出妖异之芒，嘴角隐隐露出诡异微笑，如同活了一般，似盯着王林。王林眉头一皱，心中不安、无法静心，抬头与鬼脸目光对望；半晌后心神渐渐平静，重新低头沉入禁制。（此异象未再解释，为悬念伏笔。）

## 二、禁制体系：四大禁与古魂禁

王林自述对四大禁的掌握程度：

- **破灭禁**：了解最多
- **生死禁**、**岁月禁**：也还可以
- **古魂禁**（原文多处误写作「吉魂禁」）：所见很少，仅在**颠落之地**内见过那庞大的**隹兽**

而这甲板上存在诸多古魂禁。王林右手所指的一枚符文即是缩小的古魂禁，其内隐隐有嘶吼咆哮，可模糊看到一条庞大巨蟒，凶残至极地向王林咆哮，仿若要冲出禁制吞噬他。

**参悟所得**：「古魂禁与魂为引，融入禁制内，使得禁制变成活物，如此一来就可以千变万化，所封之魂越强，则禁制威力更大。此禁，不难。」

## 三、破禁过程（时间线）

| 时长 | 进展 |
|---|---|
| 前三个时辰 | 王林几乎一动不动，矾珊梦判定其陷入瓶颈，出言劝其放弃（「已经三个时辰了，你现在去……或许还来得及」），王林置若罔闻 |
| 第五个时辰 | 骤然闭目、右手一点，符文崩溃，巨蟒虚影化黑气冲出，被王林一把抓住捏碎，再掐诀一指令黑气重化禁制落回原处——「这是第一个」 |
| 随后数息 | 一挥手崩九个 → 八十个 → 几百 → 几千 → 几万；黑气汇成黑色风暴卷起，四周百丈内再无禁制，风暴四分五裂后重化符文印记落回原处 |
| 接着 | 取出**破灭禁**化作乌光弥漫全甲板，数百万破灭禁同时崩溃，魂魔舟剧烈颤抖；**生死禁、岁月禁**两种禁链在右手幻化横扫甲板 |
| 半柱香 | 无数禁制崩溃化黑气旋转，黑气消散后数千万禁制大半归王林所有 |
| 第一层告破 | 甲板所有禁制被王林操控，「站在这甲板上，王林就是这甲板的主人」 |
| 又七个时辰（合计约一整天） | 第二层甲板内爆发惊天气息，魂魔舟猛震，第二层告破 |

**关键点**：五个时辰看似只研究一个禁制，实则是彻底吃透古魂禁——甲板上的古魂禁「极为完整」，不像颠落之地那个虽看似完整却有诸多缺陷。今日之王林已非当年在禁制山研究数年的他，如今**空灵中期、六大本源在身**，五个时辰足以看透一切。

**取舍**：对从未见过的奇异禁制，王林只略看记下增长见识便强行毁灭。此法会削弱甲板禁制威力，但能让他最快打开缺口。他的手段并非单纯破解，而是**破解后反向操控**。

## 四、矾珊梦的心理与处境

- 起初冷笑轻蔑：「这魂魔舟岂能是那么好研究明白……王林啊王林，你实在太自大了」
- 目睹九个齐溃→数万齐溃后震惊呆立，强挤微笑改口称「道友禁制上的造诣果然非凡」，仍强调甲板禁制足有数千万、他只解开百中之一
- 全甲板告破后脑中一片空白：「五个时辰？这怎么可能……且他不是单纯的破解，而是破解后将其反向操控」
- **实力对比逆转**：她因**本体无法进入此地**，对魂魔舟操控本就不多，只能发挥不足三成之力；第一层破开时操控被抢走一部分，如同一件法宝出现两个主人；第二层破开后，她的操控只比王林多一丝而已
- 面色苍白、眼露寒光，暗自不服：「破开了第一层又能如何，此舟禁制越是后面就越艰难，我就不信，他这区区洞府界修士，能完全操控这魂魔舟」

## 五、约定与悬置问题

王林破开第一层后直接讨约：「此舟有九层禁制，甲板为第一层，以下还有八层。道友，你方才曾说，若王某破开禁制，此舟你要送我」——矾珊梦沉默不答。王林含笑摇头，身影一晃消失，转入魂魔舟内部第二层甲板。

## 六、外部压力

七彩道人始终在船外轰击外围禁制光幕，光幕剧烈闪烁、七彩之光穿透照在甲板上；一整天过去，外围光幕已被其破开大半，魂魔舟颤抖愈发剧烈——构成王林抢时间破禁的倒计时。
