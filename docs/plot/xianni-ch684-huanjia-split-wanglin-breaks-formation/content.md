# 第七卷 名震罗天 · 第684章 幻家分裂

## 一、进入千幻星
- 「雷仙殿」之名王林已不止一次听闻，他看了一眼身边雷兽，若有所思，随后踏入千幻星。
- 收起**星罗盘**，穿透千幻星罡风，神识一扫锁定**南方**，身如流星奔雷而去。

## 二、幻家祖宅的对峙
- **地点**：千幻星南部，幻家祖宅——极大，远看如一座城池，通体黑色，仿若远古栖息的凶兽；外有**幻家大阵**。
- **在场**：幻家老祖**幻无情**背手望天、神色阴沉；嫡系族人分列两行、隐忍不满；**柳眉**立于老祖身边沉默望天。其余族人安排在四周房舍，尚有部分族人未及赶回。
- 幻无情再次确认：柳眉（在幻家名**幻眉**）确认来者与她同样来自**联盟星域**，但幻无情费解「联盟星域之人怎么会有雷兽」。
  - **旁白揭秘**：当年**射神车**的制作者交友广阔，为炼出车内兽魂，跑到**雷之仙界**，从**雷之仙君**手中生生弄来数头雷兽。
- 王林踏星光而出，冰冷开口：「**交出柳眉**」。柳眉眼中复杂，转头回避对视。
- 幻无情斥其不自量力：「老夫幻家大阵，你若破了，再说此话。」

## 三、破阵：雷兽 + 仙卫傀儡
1. **第一波**——王林拍雷兽头，雷兽仰天咆哮，天空阴云密布、电光游走，雷霆狂落大阵；大阵泛起水波纹将雷霆吸收消散。
2. **解封**——王林咬破右手指尖，一滴鲜血落于雷兽眉心，喝「**封印，开**」。雷兽爆发雷威化作**雷之风暴**，方圆百里沙石飘起。
   - 幻家族人中见识广者认出雷兽身份，面色大变。此前**千葵子**的神念只针对幻无情一人，故众人此前不知情。
3. **冲阵**——雷兽将天雷融于一体，如锋锥撞击大阵，光幕被生生凹下，剧响传遍整个千幻星。
4. **仙卫出手**——王林身下虚影一闪，**仙卫傀儡**幻化而出，一拳金光盖过雷电；随后身影化作无数，拳如雨点连轰大阵。
5. **结果**——大阵光芒闪烁至极限、波纹遍布、内外视线模糊如隔水，渐现颓势但始终未破。
- **幻无情心机**：暗盼王林出剑气，「只有不断消耗你的剑气，老夫才会出手杀你」。
- **千葵子**在千家远观，嘴角冷笑。

## 四、幻家分裂（本章核心转折）
- **族人心态**：罗天星域属**雷之仙界**之下，族人对雷之神通有无法想象的执着与敬畏；面对代表**雷仙殿**的雷兽，慌乱的「不是修为，而是心」。
- **不满时间线**：柳眉到来时萌生 → 为柳眉**换血**时攀升 → 雷兽风暴出现时爆发。族人接连进谏「老祖三思」「为一个外人引起幻家浩劫不妥」，被幻无情喝止。
- **族长幻封神出面**（身份特殊，老祖不得不理会）：
  - 质问：此人拥有雷兽、拥有处于**阴阳虚实**境界的傀儡，幻家该**结交**还是**死战**？结交多一友，死战有何好处？
  - 揭露：柳眉修为被老祖**强行提升至问鼎后期大圆满**，意境无法跟上，此生即便突破也**止步阴阳虚实**；「老祖的心思，封神明白」，为一己之欲风险太大。
  - 柳眉对此毫无表情，眼中一片平淡。
  - 幻无情断然：「此事，老夫自有分寸。」
  - 幻封神长叹表态：**一旦此阵破除，立刻选择退避**——「封神的性格，求的是稳，而不是险」。→ 幻家实质分裂。

## 五、收尾：雨之仙剑与斩罗诀
- 雷兽咆哮与仙卫拳击达到顶峰之际，王林一拍**储物袋**，取出一把大剑——**雨之仙剑**。
- 该剑由**周佚**分离而出，**独属王林、传承万世**；剑芒吐出三寸含而不发，握在王林手中「好似融入天地，因为王林是它真正的主人」。
- 王林眼中平静，手持仙剑斜倾而起，喝出：「**斩罗诀**」。（章末）

## 六、要点提示
- 幻家的裂痕来源不是修为差距，而是**雷仙殿的名号**与老祖为柳眉一人开罪外势力的私心。
- 柳眉的「问鼎后期大圆满」是老祖强提的结果，代价是意境断绝、终身封顶阴阳虚实。
- 千葵子/千家在幕后乐见幻家受创。
