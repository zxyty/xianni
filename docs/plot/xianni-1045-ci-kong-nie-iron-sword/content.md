# 第八卷 联盟隐秘 第1045章 次空涅

## 一、仙帝洞府第一层：禁制迷宫
- 小路两旁花丛遍植，色彩绚烂但内藏无数禁制，触碰即触发：或攻击、或围困、或传送他处。连路面铺设的**仙玉**也含禁制，行走方位与落脚顺序有误即开启。
- 不明就里者在此**寸步难行**。
- 王林凭**地图玉简**（详载禁制细节，但无破解之法）通行无碍——他本身是**禁制大师**，得知细节即可一眼看破虚实。以其性格并不全信玉简，行进中不断印证记载真伪。
- 洞府禁制密布，组合成**互相隔绝的「无数个世界」**：距离很近若分处两片禁制之内便无法察觉对方，连视线都会扭曲。故除非疯狂，无人敢散开神识——王林认为**即便天运子**也会有很大顾虑，不到万不得已不会散神识。

## 二、铁剑锈迹之秘（本章核心发现）
从**人形之物**身边抢来的铁剑：
1. **神识受阻**：剑身有一股力量阻止任何神识探入，剑上**四处锈迹**阻力尤浓，剑内另有一股**无形之气**环绕流动。
2. **锈灰试验**：王林以左手指抹取锈迹，闻之有淡淡腥气，判为「寻常铁锈」——但左手放下刹那，指尖划过的**虚空呲然裂开一道裂缝**；身侧整片花海暗红光起、顺序枯萎成废墟，**其上禁制无声无息崩溃**。退后再以沾灰之指点向另一方向花丛，同样轰然枯萎成废土，锈灰随之消散。
3. **第三目探查**：王林开启眉心**第三目**，红芒含**本源之力**照向锈迹——剑身在其眼中渐渐透明，**唯锈迹毫无变化**；剑内无形之气一顿后直冲而出**欲吞噬本源**。王林果断切断神通、收回本源、闭合第三目，无形之气才缓缓收回继续流转。
4. **剑鞘验证**：取出当年在**朱雀星**所得的**五把剑鞘**（原只知飞剑融入可使剑威更烈，未明其用）。铁剑融入第一把大小分毫不差却无变化；逐一试至**第三把剑鞘**时，鞘上雕刻符文爆发刺目之光，一股可怕气息自剑鞘中疯狂传出，仿佛封印着无法想象的力量，一旦拔剑便会冲天而起。
5. **定名「次空涅」**：此气息王林曾在**玄宝上人**的法宝**次空涅箭**中感受过（玄宝上人已成亡魂）。王林由此认定铁剑关联**次空涅**，遂不拔剑、连鞘收起，带一丝兴奋继续疾行。

> 旁证回忆：当年**托森使者**拿到一把**一模一样的铁剑**时神情如获至宝，而他所看重的并非铁剑本身，**正是剑上的锈迹**。

## 三、禁眼与「有人先行」
- 第一层总禁制共**八处禁眼**，须全部打开方有机会踏入中心黑雾。
- 路边一座平平无奇的**二层阁楼**为第一处禁眼，王林一眼看出其禁制**早已被人破开，且破开时间不长**。
- 沿途八处禁眼**全部已被打开**——已有人抢先一步进入**第二层**。
- 王林推断：**葬仙池崩溃**众人冲散后，必有提前破禁而出者，但不知具体是谁。

## 四、亭榭之争：黑衣男子 vs 村姑美妇
地点：第一层**东北角**一处亭榭。
- **黑衣男子**：一身黑衣，眉心隐藏**黑龙印记**。手段：掐诀放出黑雾化**龙形**吞噬；大袖甩出**散发黑气的飞剑**。
- **村姑般美妇**：声音略沙哑却极动听。曾被葬仙池冲入一处弱禁制，自行破开后见远处黑雾而前行，一路凶险方至此地。手段：扯断头上**三根发丝**，咒语中化作**三条黑色巨蟒**（吐血红信）；双手掐诀放**五彩之芒**化五道利剑横扫。她带来的**粉衣女子**有其大师姐所赠之物防身，故未担心其安危。
- **争夺缘由**：亭榭内有一座**传送阵，通往一处储物空间**，二人各自看破。
- **克制斗法**：二人皆为**大神通修士**，都不愿惊动此地他人，刻意压制斗法波动，轰鸣只在百丈内回荡。
- **暂时结盟**：村姑美妇提出「修为相当、未分胜负先被察觉」，不如**同入传送阵、所得一人一半**，黑衣男子点头，二人收法宝同踏入亭榭。

## 五、王林现身与局势骤变
- 二人入亭榭刹那，同时望见远处阁楼林立中走出**王林**。黑衣男子露出古怪微笑；村姑美妇内心一震。
- **村姑美妇对王林修为的判断**：最早见他时有**净涅期**实力而修为看似只是**窥涅**；之前不过**窥涅中期**；如今竟已**窥涅大圆满**——疑其隐藏真实修为或近期突破。
- 村姑美妇提议：**三人同进，所获三分**。
- 王林其实早已看出亭榭端倪（地图玉简亦有记载，且他一眼即可看出传送阵）；他来此只因**此地是通往中心黑雾宫殿路上禁制最少的一处**。
- **突变**：地面震动，远处传来愤怒咆哮。表象平静，实为远处**竹林红雾滔天**——**人形之物已生生破开竹林禁制脱困**，比王林预料更早。
- **人形之物的可怕之处**：一路触发无数禁制，或被攻击、或被强制传送，却往往数息内即破禁踏出，**且越破越快，如同在学习这些禁制**，最后几乎沿直线冲向王林方向。
- **各方反应**：王林不答话，身形一晃直奔中心**黑雾宫殿**；黑衣男子见状不假思索**放弃亭榭传送阵**追随王林；村姑美妇犹豫之际，咆哮已越来越近。

## 六、悬念
1. 铁剑锈迹的真实本质（枯萎万物、崩解禁制、抗本源、与「次空涅」同源）与托森使者手中同款铁剑的来历。
2. 五把剑鞘中唯第三把与铁剑共鸣的原因。
3. 先一步进入第二层者是谁（可能与葬仙池崩溃后提前脱困者相关）。
4. 人形之物「学习禁制」的能力与其追击王林的目的。
