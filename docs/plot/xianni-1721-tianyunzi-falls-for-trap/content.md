# 第1721章 天运中计！（第二更）

## 一、本尊分身分离与布局

- 道吉血脉之力所化风暴消散后，星空一片寂静，仅余王林身下石块。
- 王林于东方再度感知天运子气息，身体幻化重叠、分离，**本尊一步走出**，形成本尊与分身并立之局。
- 分身虚空一抓取出**鬼脸帆**，一挥膨胀，将此地一切笼罩于虚幻之中。

### 王林的判断
> 「三命神通，此术也绝非可以拓印之术，若我不惜一切废掉自己的分身，亦或者以三命术死亡一次，那么这天运子的一切算计都会崩溃。」

- 结论：此法代价太大、**不值**。王林选择接下天运子的『游戏』，正面斗算计。

### 施术与护法

- 分身一指点在本尊眉心，指尖仿若深入本尊魂中；四周鬼脸帆布齐齐卷动化作雾气，凝成巨大鬼脸向本尊眉心收缩——**大半没入眉心，余者弥漫覆盖本尊全身**。
- 分身面色略显苍白，转身向星空一拜，请**蓝梦道尊、青霖、红衫子**三位前辈为本尊护法。
- 三人实早已到来，目睹王林与天运子数次交锋。蓝梦道尊盘膝坐于本尊前方，允诺：「有老夫在，你放心就是，若你能找到他的本尊，他即便本尊修为再高，也逃不掉。」
- 王林抱拳后独行向东，途中收起手心的**一滴水与一小撮泥土**（其本源）。

## 二、王林的自我准备：吞魂与本源

- 王林之魂**当年已成吞魂**，可吞噬一切，也包括自己。
- 分身之魂凝聚其一切本源，元神亦与其魂千丝万缕相连；**一旦分身之魂死亡，则一切烟消云散**。
- 王林的底气：记忆由本尊完整拥有；本源来自感悟，而感悟存在于本尊之魂中，故本源纵失亦可重得。
- 遂右手掐诀按胸口、印记融入体内，心神与体内壮大的**天运子分身之魂**彻底融合，向东而去。
- 王林预期：天运子一旦着急，怕是会把所有分身同时幻化出来——「我期待他这么做。」

## 三、天运子的决断（召河星域东方）

- 天运子嘴角诡异微笑消失，神色阴沉如水。
- 自陈：**「我自己都忘了本尊在哪」**，不信王林能找到；但忌惮王林诡计多端、非寻常手段。
- 决定不再浪费时间，**立刻完成计划**，即便尚有瑕疵也无所谓。
- 计划完成后他将沉睡，等待**第九十九次觉醒**，并称此次觉醒将彻底达成所愿；又称王林的修为足以让这次沉睡在刹那结束。

### 三千分身尽出

- 天运子闭目，召河星域各处幻化出**数百个一模一样的天运子**。
- 昆虚星域诸修真星与星空中，一个个天运子随波纹扭曲现身，齐齐望向召河。
- 罗天、云海两大星域同样波纹回荡，无数分身出现。
- **四大星域分身合计接近三千**——这正是天运子九十多次觉醒中不断吞噬而来的所有身体。

## 四、中计！——三千魂息为引

- 三千分身尽出的刹那，王林身形一顿，双眼露出明亮之芒：**「他中计了」**。
- 王林体内的天运子之魂沸腾苏醒、在其体内蔓延，与界内三千分身彼此呼应，**仿佛王林成了天运子真正的分身**。
- 王林心神中三千分身全部感应：知晓每一个分身所在、感受每一道气息。

### 谋算复盘

- 王林原本毫无把握找到天运子本尊；他先前那些「看似寻常、每一句都蕴含乾坤」的话语，**逼天运子改变计划**——为了在极短时间内占据王林分身取胜，将三千分身尽数召出。
- 结果：**信心是天运子给的**。借对方三千分身之气息，王林可彻底锁定天运子全部分身，进而循气息溯源找本尊。
- 比喻：单凭一条路线在错综复杂中寻源头很难；此刻天运子亲手给了王林**三千条路**，全部展现在王林眼中。

### 施术口诀
> 「以这三千魂息为引，以梦道为路，借鬼帆入幻，梦入三千身，幻回轮回道，追寻天运本尊。」

- 召河星域深处，被蓝梦道尊三人守护的**王林本尊**骤然睁眼：「我知晓了，找到其本尊的道路。」
- 本尊借三千魂息**打开梦回千年的道路**，岁月在目中逆转，沿三千魂息线路进入梦中幻境。
- 术理：以**梦道之术**，借**鬼脸帆布的幻禁**，以天运子三千分身为指引，沉浸于三千分身的世界／天运子的轮回觉醒之中，去追寻其根源与本尊所在。这是王林反击天运子的方法。

## 五、梦回所见：天运子吞噬凌天侯

- 幻境清晰后，王林所见依旧是**召河星空**，一颗漂浮的陨石。
- 陨石内：天运子盘膝而坐，对面盘坐着**昏迷的老者凌天侯**（剑尊凌天候）。
- 天运子右手残存血液——**从青龙圣皇手中抢走的、被改变的天道之血**。
- 天运子痛苦剧烈、阵阵低吼，猛然睁眼，双目内一道道分身虚影急速闪烁。
- 随即张口无尽放大，**一口吞噬凌天侯**；吞噬瞬间双目迷茫，缓缓闭眼。
- 岁月流转，**数百年后**天运子睁眼恍惚：「我又苏醒了……下一次沉睡与苏醒的力量，我也准备好了，他就是王林。」
- 王林生疑：「他吞噬了凌天侯，为何要说又苏醒？这天运子到底苏醒了几次？」画面消散，新的画面随即幻化而出。

## 六、要点与悬念

1. 攻守易势：天运子由算计者变为被算计者，三千分身从杀招变成暴露自身的路标。
2. 王林的核心手段链：**吞魂 → 融合天运子分身之魂 → 鬼脸帆幻禁 → 梦道梦回 → 溯源本尊**。
3. 天运子的本质被进一步揭示：以吞噬他人身体积累分身，反复沉睡—觉醒，已近**第九十九次**。
4. 悬念：天运子究竟苏醒过几次？其本尊在何处？王林能否在被占据分身前找到本尊？
