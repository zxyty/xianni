# 第1546章 我，回来了

## 一、独行星空：三步至昆虚

- 王林脱离幽冥兽后独自一人在星空疾驰，**没有了疯子跟着**，速度达到巅峰。
- 肉身强悍：一路遇空间裂缝往往不避，裂缝一碰即崩溃，无法伤他分毫；体内隐有**一片淡金之光**闪烁，行走间星空似在脚下缩小。
- 距修真联盟总部路途遥远，但他**仅三步便横扫星空**。

### 第一步：昆虚布阵处，掠过鲁夫子

- 落点为一片密集修真星，大量昆虚星域修士正在布置阵法。
- **鲁夫子**受**红杉子**邀请来昆虚布阵——昆虚第三步大能稀少，通晓上古阵法者更少。
- 王林经过时无人察觉，众修只觉星空微弱波纹旋即消散；鲁夫子仅「眼前一花」，感到一股**很熟悉的气息**，前望良久后摇头：「这气息与他很像……只是几十年过去，他一直音讯全无」，神色落寞。
- 王林看见鲁夫子，但**时间紧迫，未做停留**，直接迈出第二步。

### 第二步：昆虚近中心「禁识之空」

- 此地空旷，**无数空间裂缝如疤痕浮现**；数年前曾有一场极烈大战，导致大范围星空崩溃。
- 裂缝撕裂 + 环绕的隐隐波纹扭曲，双重作用彻底封锁神识探入 → 此地成为**禁识之空**，仿若从昆虚被分割出去。
- 空气中仍有**淡淡血腥之气久久不散**，见证当年惨烈。

### 王林的推断

> 罗夭（罗天星域）与联盟交战时，从未达到这种大范围星空崩溃的程度。

- 结论：**界外之战已再度开打，且不止一次**。
- 内心自问：「我在幽冥兽体内的这些日子，不知过去了多少年……那几处**七彩界**，按道理应该已经被找到破坏了才对。」

## 二、炎雷子被追杀

### 三道遁光

- 前方为**界内修士炎雷子**：老者、面色苍白、不断喷血，神色狰狞咬牙飞遁。
- 追击者为两名**眉心有印记的界外修士**（太古星辰一方），修为皆**碎涅圆满**，与炎雷子同阶：
  - **火雀族修士**
  - **奉天狼族修士**
- 二人合力追杀之下炎雷子能撑到此处，足见其强悍。

### 交手过程

1. 火雀族修士眉心喷出火焰化火海压来；炎雷子掐诀拍出**十几块碎片大陆**层层抵挡，被烧毁三块，借冲击之力前冲，余者倒卷随行。
2. 奉天狼族修士指出**数百丈青狼**吞噬而来；炎雷子咬破舌尖喷血于碎片之上，怒吼「爆」，十余碎片同时炸开化毁灭之力，轰碎青狼——但自身亦剧震、面色惨白、踉跄后退。
3. 二人再度合击：奉天狼族修士右臂长满青色毛发、蔓延大半身，**右臂脱体化作一条巨狼**；火雀族修士身后**黑色火鸟**扇翅卷起黑焰滔天，一同扑向炎雷子。

### 炎雷子的处境与选择

- 他知道只要逃出这片禁识之空，外围星空可**缩地成寸**而走，对方便有顾忌不会再追；但距边缘尚有一段路程。
- 眼见必死，**放弃逃遁**，眼中露出疯狂与豪迈：「死，老夫不怕！就算是死，也要死的轰轰烈烈」，全身燃烧以换取一瞬爆发之力。

## 三、双方口舌：界内界外的三重旧账

### 界内的窘境（炎雷子之叹）

> 「若非红杉子大人被困、若非南云子大人出关、若非我界内封尊失踪，你们如何能这般嚣张！」

- 现状三条：**红杉子被困**、**南云子尚未出关**、**封尊失踪**。

### 界外的态度

- 奉天狼族修士：若非**太古星辰长尊会副会长天兆上师**与界内有约、彼此暂缓交战，**整个昆虚星域早已尽归太古星辰**。
- 火雀族修士：封尊当年只是侥幸且已送上性命，「明明已经死亡，你们却还坚持去说失踪」。
- 奉天狼族修士：**第二次、第三次大战**中封尊皆未现身，红杉子被困时也不见其出手 →「封尊只是你们一个虚假称呼，在老夫看来，他只不过是一个娃娃」。

### 炎雷子的反击（两笔血债）

- 「我封尊杀你**火雀族老祖**，如探囊取物，斩之于你界外十多万修士面前！他死前那凄厉的惨叫，你可曾听到？」→ 火雀族修士杀机滔天，此为**全族之痛**。
- 「你**奉天狼族**，你族老祖为我封尊之奴，他虽逃走，但你可见他有一日不怕、有一日不惊？」→ 奉天狼族修士面色骤变。

## 四、封尊归来

- 巨狼与黑焰临近的刹那，**一只平凡右手**出现在炎雷子身后，轻抓其身柔和一带，**熄灭其燃烧之火**并将其引到一旁。
- 一个**身穿白衣的人影**现身，神色阴沉，猛地抬头，**双眼射出两道万丈金光**，整个星空被映照成金色世界。
- 一声冰冷至极的「**滚开**」响起——这声音是两名界外修士当年身为「**第三波修**」时耳中磨灭不掉的恐惧之源，令其头皮发麻、几近魂飞魄散，内心最后的侥幸轰然崩溃。
- 二人凄厉惊呼：「**封尊！**」「**封尊！**」
- 茫然中的炎雷子不敢置信、透出难以想象的惊喜：「**封尊王林！**」
- 全章收束于王林一句：

> 「我，回来了。」
