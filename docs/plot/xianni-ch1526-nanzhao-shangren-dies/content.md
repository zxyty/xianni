# 第1526章 南诏亡

## 一、封尊第一战的战果与士气逆转

- 火雀族老祖之死并非死于卑鄙手段，也非死于红杉子这类界内大能之手，而是被王林以「堂堂正正、光明磊落的一斧斩断」——这是战争中斩下对方一员大将的赫赫战功。
- 对比：水道子之死「只是一场杀奴」，火雀族老祖之死才是真正的战功。
- 效果：界外十多万修士默默退缩，望向王林的目光兼有惊恐与敬畏；寒衣童子与仙妃亦眼中精光一闪。
- 那把斩杀火雀族老祖的开天斧在王林手中隐隐呼啸，带着杀音与疯狂决心，彻底崩溃界外修士战意。
- 红杉子长笑：「封尊斩杀界外大能，此战，我们没有输」，随即体内红光闪烁扑向寒衣童子，死死困住其四周界外大能；南云子笑声中拦住仙妃开战。

## 二、王林突进与云落大司失态

- 王林持开天斧一路破空，如利剑刺入界外大军腹部，势如破竹；前方修士避让不及者体内虚火燃烧、凄厉惨叫而崩溃。
- 云落大司面色苍白，下意识后退，右手掐诀模糊成残影，试图算出一线生机；发出本场战争中第一次尖锐失态、走音扭曲的吼声：「阻止他」。
- 距离递减：五百丈 → 四百丈 → 三百丈 → 二百丈。

## 三、寒衣童子的判断

- 寒衣童子与红杉子神通不相上下，右手一挥爆开一片冰寒之气，将南诏上人以及第二波大军中赶来的白勒族蓝袍老者一并震开。
- 其低吼「杀封尊」，判断：界外之民战心已被崩溃并生出恐惧，此事在大战中极为致命；若王林真杀入军中斩了云落大司，界外「就算是胜，实际上也是大败」。解法在他看来很简单——杀了王林即可。

## 四、毒道对决：南诏上人之死

- **南诏上人出手**：被震开的刹那化作黑芒，带着比之前更浓郁的杀念直扑王林，容颜阴沉；于百丈之外抬手前抓，身后幻化出五色毒烟，如五条龙卷向王林扑去。
  - 五色毒烟是其本命之毒，在南诏万年收集炼化而成的不朽之宝，足以媲美大荒上人的毒攻。
- **王林反击**：前行中猛地转身，双眼血红杀机弥漫；眉心星点旋转，天皇炉轰轰幻化，身前凭空出现**九滴毒液**。
  - 王林道：「毒，王某也有杀你，三滴足够」，左手一挥掷出三滴。
- **交锋**：三滴毒液碰上五条龙卷即刻爆开，化作似幻非幻、虚实变化的滔天毒海，如巨掌拍在龙卷之上；五色毒烟中的惊天之毒遇到更强之物，被吞噬融合——先崩一条，再崩两条，最终五条尽数溃散被毒海吸收。
- **南诏上人的辨认**：其一生与毒为伴，知天下之毒甚详，却从未见过此毒。此毒与大荒上人的毒源很相似，却有诡异不同，正因这诡异变化他先前未能看透。惊呼：「这不是大荒之毒」「这是什么毒？就算是大荒上人也绝不可能炼出这种毒」。
- **结局**：双方相距不足几十丈，无法完全避开。毒海从其身上呼啸而过，皮肤溃烂、毒烟涌出；后退瞬息间双脚化为血水，骨头亦化血液，下半身消散，双臂抬起即化血水滴落，上半身随毒海一卷而走。最后一声「救我」戛然而止。其不知死活之魂被王林收入天皇炉。
- **余波**：凄厉余音回荡在十多万修士心神，化作极限恐惧。白勒族蓝袍老者前行的脚步骇然停止，被王林回头一看即额头冒汗、急速后退。

## 五、群战杀手锏尽出

- 王林沉默中将剩余**六滴毒液**全部融入毒海，环绕自身形成巨大漩涡；左手向上一指，毒海漩涡骤然向八方轰去（顾不得心痛此宝）。
- 左手虚空一抓，撕出空间裂缝，无数蚊兽带着狰狞疯狂冲出。
- **战术说明**：毒海与蚊兽是王林预留的群战杀手锏。此前不用，是因界外大能尚有余力，若未找准最关键时机，一旦施展很可能尚未发挥全力便被人生生阻止。眼下虽非最好时机，但他无法继续等待。
- **异常**：幽冥兽自吞噬金色风暴后如一片死水，本战中王林多次想要唤出，它却失去了一切反应。

## 六、章末悬念

毒海滔天四散、蚊兽呼啸嗡鸣之中，王林手持开天斧直奔神色惨白的云落大司，间隔百丈，右手抬起，在震天低吼中直接一斧斩下。
