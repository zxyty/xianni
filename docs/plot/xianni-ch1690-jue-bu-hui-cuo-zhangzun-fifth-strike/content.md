# 第1690章 绝不会错

## 一、掌尊登场：时机与底气

- 掌尊几乎在**王林开出第二弓的刹那**出现在这片星域，对王林抱**必杀之心**。
- **修为**：已入**玄劫**，除有限几人外无人是其对手。
- **身份**：在仙罡大陆虽为奴才（疯子之奴），外人却视其为**王侯门下**；在**洞府界**为**界外五尊之首**，万万年来为无数修士敬畏、被诸多族落奉若神灵。
- **权柄**：掌有**长尊会**，一言足以在界外掀起浩劫，连一些仙妃在其面前也无法强势。
- **界内声威**：知其名者多半心怀恐惧，其心机之深难以捉摸。

## 二、掌尊的旧账（背景闪回）

历数其手笔：

1. 当年**强势围杀封尊**；
2. **符文族来临引动青霖**；
3. **参与毁灭四大仙界**；
4. 在界内**留下诸多种子**——**战星野**、云海**破天宗大弟子**、**水道子**，身后皆有掌尊身影；
5. 一次次掀起界内界外大战，为战争主导，死于其手的修士足以铺展一片星空。

### 遇王林前的三次狼狈

| 次序 | 事由 | 结果 |
|---|---|---|
| 一 | 被**七彩（七彩道人）**所逼 | 不得不拜其为师；反证掌尊拥有大才 |
| 二 | 在**太古星辰**（原文作「太吉星辰」）首遇闯入掠夺香火的**战老鬼** | 掌尊战败，深记「战老鬼」三字 |
| 三 | 进入界内寻**李广箭** | 被**一吼之力**震成重伤，狼狈逃遁 |

## 三、掌尊算计王林的五次失手

1. **第一次**：王林首次踏入太古星辰，掌尊欲以**井中捞月**取王林之魂，被**蓝梦道尊**阻止，又因**吉之墓地**开启而失去王林气息。——尚算意外。
2. **第二次**：吉之墓地入口，王林封印界外数尊之力；掌尊正要出手，王林借**古之墓地最底层之力**发出一声大吼，如利剑呼啸，与掌尊直接碰撞，掌尊喷血急走。——勉强称意外。
3. **第三次**：**云海战场**，掌尊弟子奉命将**李广弓**送入界内以引出战老鬼，二人交战之下**弓落入王林手中**；其后王林更拿到**李广箭**，掌尊心神略沉。此时他仍认为王林因血脉无法发挥全力，杀之易如反掌。
4. **第四次**：掌尊与界外诸多大能以井中捞月之术造出**幻真界**诱王林入局，算无遗漏，更逼得王林尽出全力；纵使王林放出被**道古烨寞**封印的**仙罡之魂**，仍难改死亡轨迹——却因**疯子**出现而彻底崩溃，不但没杀成，反成王林**修为暴增**之因。
5. **第五次**：**王林一箭将掌尊轰杀**，掌尊以**三命之术**重生。至此他才彻底清醒：这不是意外，**王林就是他的克星**，如刺入心的一根刺，念及便近乎发狂。

> 掌尊几乎在潜意识里认为王林「不可杀死」——每到最后关头，总有一股无形力量令其逆转乾坤。

## 四、本章交手

### 掌尊的判断与誓言

- 「老夫算定了他只有**两弓之力**……此刻两弓已开，在他身上我已察觉不到任何**仙人血脉之力**，李广弓，他开不了。」
- 判断依据：掌尊身为**疯子的奴才**，当年在**幻真阵**内**亲手逼出王林仙人不灭体的血液**，独知该血脉之力可开几次弓——此点旁人难以算准。
- 誓言：「若杀不死他，老夫日后随他姓。」「就算是他把主人请出，我也一定要杀了这王林。」

### 出手方式

- **不作任何交谈**便直接施展大神通——忌惮与王林交谈后又生意外；这一掌亦含**试探**之意。
- 玄劫修为轰然爆发，星空震动、无形波纹横扫，王林如孤叶般连连后退。
- 一个**百丈凝实掌印**成形，直奔王林。

### 王林的应对

- 神色平静，对掌尊出现**毫无意外**——若对方不出，反倒要多思索一番。
- 右手抬起：**眉心古神星点**亮，**左目右目妖魔之星**全部闪烁，**道古之力**尽凝于右手食指。
- 施展以**仙人不灭体为灵感自创的神通「古族不灭指」**，一指点出。
- 同时体内爆发青光：**青光盾**幻化缭绕，身后浮现巨大的**光影盾**；光影盾后彩芒闪烁，一只**五彩蝴蝶**扇翅而出停于其肩，落下彩粉。
- 心念：**「还不到时机」**。

### 结果

- 甫一碰触，王林全身几欲崩溃、喷出一口鲜血、连连后退。
- 右手食指骤然瓦解又瞬间凝聚，数息间**毁灭重组千次以上**。
- 修为差距如天地沟壑：食指尚可坚持，肉身却不行——道道伤口豁然出现，剧痛袭来，肉身似要毁灭。
- **光影盾**扭曲崩溃；**青光盾**光芒万丈后倒卷、被轰回体内；**五彩蝴蝶**一颤化作五彩之芒消散。

## 五、看点与悬念

- 掌尊的全部自信建立在「血脉只够两弓」的精算上，而王林的平静与「还不到时机」暗示尚有后手。
- 第六次交锋的胜负，将验证「意外」究竟是运气还是必然。
