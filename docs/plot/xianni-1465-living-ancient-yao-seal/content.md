# 第1465章 活着的古妖

## 一、古伞灭世火海：二人暂退，王林脱身
- 旧焚界古伞虽仅开两成，灭世之火「天地任何之力都无法抵抗与阻挡」；火海自伞下宣泄向八方推动，四周雾气被点燃倒卷成风暴。
- **九天魔尊**神色凝重：若本尊来临尚可，但眼下是**被压制了修为的分身**，只得后退暂避。
- **白衣女子**神色瞬息数变，低头后退。
- 王林擦去嘴角鲜血，借火海冲击之力向前疾驰，穿过第七张地图，将要迈入**第八张地图**。

## 二、隔山指 vs 开星门
### 隔山指（九天魔尊）
- 右手点眉心，喃喃：「只要让我看见你就可以……只要你的身影曾出现在我的目中就可以……不管你距离本尊多远，哪怕你我之间阻隔了一座不可跨越与毁灭的界山，本尊也能杀你。」
- 施展时其双目瞳孔内幻化出王林身影（保持施展古伞的动作），一指点去，目中之影立刻扭曲欲被撕裂。
- 定位：在**太古星辰**中**仅次于「井中捞月」**、声名赫赫的大道术。

### 开星门（白衣女子/仙妃）
- 猛地抬头，美目露出果断，玉手虚空一拍、右手掐诀甩出，轻吟：「**天门三道，日月星三门，开星门**」。
- 无数星光交错化作**与天齐高的巨门**，样子与**第三步空之大门**极为相似，但实质绝不相同。

### 结果
- 两种道术之力相撞，**无声无息、不起半点波澜**：星门一震，化作星光崩溃倒卷、消散于古墓内。
- 九天魔尊喷出一口鲜血、面色苍白，连退数百丈，怒问：「仙妃为何阻本尊？」
- 白衣女子面色略苍白、后退百丈，神色平静如水：「本宫做事，还需向你解释么？你，算什么东西。」
- 九天魔尊盯视半晌后神色平复，**丝毫不露怒意**，反而嘴角浮出微笑，摇头转身**绕过对方**直追第八张地图。
- 白衣女子皱眉，望向王林消失之处，暗叹一声，迈步前行。

## 三、第八张地图：三处封印之地
- 王林踏入瞬间**全身寒气一闪、强烈危机弥漫心神**，不假思索点眉心唤出**天皇炉**包裹全身，冲入其内后危机骤消。
- 第八张地图内有**三处被封印之地**，地图标示均为古之文字：**神、妖、魔**。
- 换作往常王林必选「古神」封印之地，此番却不假思索**直奔古妖封印之地**（有明确目标，未浪费时间与路线，一个时辰后临近）。
- 追兵：九天魔尊凭冥冥感应摸索追入；八妃中的**风情（粉衣）女子**自第九张地图进入第八张。王林估算敌方约**半个时辰后**寻来。
- 熟悉度：古墓内所有人中，**无人比王林更熟悉第八张地图**。

## 四、活着的古妖
- 前方现**约数万丈大小的漩涡**，内有轰鸣，浓浓妖气弥漫，未近已令人心神颤抖。
- 临近后察觉妖气中有**磅礴生机** —— 王林倒吸口气：「活着的古妖！」
- 漩涡最深处为**混沌气旋**，其内似有一身影盘膝打坐；气旋外有**一道封印**，使古妖无法出来、似在沉睡。
- 王林判断：该古妖不但活着，且极为强大，**即便不是九星古妖，也定是八星**。
- 王林皱眉旋即舒展，露出阴沉之笑，收起墓台跃入漩涡。

## 五、漩涡内制符
- 妖气如坚韧绸缎缠身欲撕裂肉身，仅入百丈便难以再进（距中心不足数百分之一）。
- 眉心**古神星点**幻化，古神之力融入全身，咬牙每步数百丈，推进至**千丈处**——几乎是极限（尚有余力但未再进）。
- 盘膝调息后掐诀取出**魔魂瓶**，开始循环作业：
  1. 抽取瓶内**古魔魂**；
  2. 左手抓住呼啸而过的**古妖气息**；
  3. 融入自身**古神之力**；
  4. 三者融合出的奇异力量按于眉心，符文闪烁幻化即抹下收好。
- 动作越来越快近乎残影，漩涡内古妖气息被一丝丝抽走，魔魂瓶内古魔魂渐减。
- 半个时辰过去大半时，符文已达**数千枚**，但**距九阶墓台所需数量仍差很多**。
- 王林感应到**四道气息**自远处急急而来，似已锁定其位置，速度越来越快。

## 六、粉衣女子来袭
- 一座**七千丈墓台**破空而现，上立粉衣妙曼女子，眉目带风情，人未到娇笑先至。
- 其笑声似呻吟、别有韵味，**实含道术**：传入王林耳中令其心神一震，脑海幻化出当年**朱雀墓与柳眉**的曼妙往事。
- 王林面色苍白、目光冰寒，凭**两千年修道的坚定之心**与朱雀墓之事引发的一系列后果所带来的痛苦，硬压下这丝莫名情绪，双眼愈发阴冷。
- 女子掩口娇笑：「原来是你这个小家伙，可惜姐姐已经有了**拓森**，不然的话，还真舍不得伤你呢。」
  - 双眼掠过诧异；微不可查地扫了一眼漩涡深处的古妖气旋，目露**凝重**。
  - 见王林仅短暂迷茫便立刻清醒，心生奇异想法：「莫非这小家伙一生未近女色不成？」
- 王林在其临近刹那**再退入漩涡深处百丈**，盘膝闭目、看都不看，继续制符。
- 粉衣女子香舌抹唇、笑声更娇柔，身子一晃踏入漩涡向王林疾驰；远处虚无中**九天魔尊收起墓台一步迈来**，神色阴沉，转瞬临近并踏入漩涡。

## 七、看点与伏笔
- 白衣女子（仙妃）**第二次**在关键时刻回护王林却拒绝解释，其立场与心思成谜。
- 「天门三道·日月星三门」暗示尚有**日门、月门**未出。
- 星门与「第三步空之大门」形似而质异，指向第三步层次的对照。
- 王林改选古妖封印之地，说明其目标已从「古神传承」转向**古妖气息制符 / 九阶墓台**。
- 活着的八星或九星古妖被封印于此，为后续变数。
- 粉衣女子与**拓森**（血海主人）的关系被点明。
