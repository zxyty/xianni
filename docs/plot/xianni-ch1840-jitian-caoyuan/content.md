# 第1840章 极天草原（第一更）

## 一、干尸之相的王林

- 王林出关后形貌骇人：身子干枯、毫无血色，似豁开伤口也流不出血；头发干燥欲落；体内没有半点水份，若非元神依旧强悍，与死人无异。
- 一袭宽松白衣在身，如同裹尸；周身散出的恐怖气息逼得炎栾连退数步。
- 双目似已死亡，瞳孔无法转动，只能转头视物，反而凭添可怕威压。
- 已司化作一片黑雾回到王林身旁，雾中凶残双眼猩红、垂下扭曲舌头，与王林形貌相衬，使其如同天地魔修之煞。

## 二、与炎栾的交涉

- 炎栾以“矾珊梦被王长老的奇异傀儡攻击，我只为营救”为由现身。
- 王林答：“此女是我的女侍，不需炎栾长老代劳。”干枯面孔上的微笑显出狰狞，矾珊梦颤抖退到师尊身旁。
- 王林随即转问正事：“这天牛洲，王某不熟悉，你可知什么地方有大量的水？最好是一片大海？”
- 炎栾一眼看破：他不是在修炼功法，而是在**吸收水本源**。
- 炎栾据实相告：**天牛洲与绿魔洲的交界处有一片无边无际的内陆海**，距此地约九个月路程；并当场取出玉简，神识烙印去往内陆海的地图，掷予王林。
- 王林凝神一扫后道谢，看都不看矾珊梦一眼，化作雾气直奔天空尽头。已司之傀随后融入雾气被收起；山峰洞府外的**火本源真身**目内火光一闪，亦极速跟随而去。
- 炎栾事后沉默暗叹：玉简内**并未作假**，所说所给全部是真。

## 三、极天草原

- 王林离开大魂门后施展**缩地成寸融入天地之术**，脚下波纹回荡即消失，一步跨至**大魂门十万里外**的一片草原。
- 该地为天牛洲罕见的无尽草原，青草弥漫透出仙气（虽不及某些山川但也不弱），地底深处遍布洞府，聚居大量散修。
- 按炎栾地图：抵达极天草原后，**再有六个月路程**即可到达与绿魔洲相连的内陆海。
- **术法限制**：在仙罡大陆上，王林即便借分身之力明悟缩地成寸，也无法连续不断大范围施展；一次挪移抵近三个月路程后，须间隔一段时间方可再用（本章为七天）。
- 赶路方式：抬手令腕上**蚊王水墨图腾**嘶吼幻化，蚊兽如墨画般托起王林疾驰；王林盘膝其上闭目凝神。
- **自身隐患**：此刻修为处于巅峰、神识强大、元神饱满，唯肉身干枯为患，必须尽快吸收大量水本源，**完成第九次循环**。

## 四、三修觊觎与反杀

- 蚊兽横穿草原引来诸多神识窥探，三日后大半散去，唯余三股如髓入骨般紧随：**其二为空玄中期，一人为空灵后期**。这三人的跟随反而打消了其他窥探。
- 七日后草原将尽，王林缩地成寸恢复可用，起身欲行；三修出声拦截，索要其飞行凶兽，扬言“留下你的飞行凶兽，老夫饶你不死”。
- 三人合力化出一只黑色巨手自天而降抓向王林。
- **王林反击**：干枯右手向天猛地一撕，身后幻化出巨大**道吉手臂**随之撕天，巨大裂缝似吞噬一切，黑色手臂当场崩溃被生生撕开，三人倒卷退出、骇然震撼——“他不是空灵修为”“如此强悍的肉身之力，此人足以堪比**古国之修**”。
- 三人分三个方向急速逃遁，王林出手绝不罢休：
  1. **已司之傀**幻化，双目露出兴奋残忍，瞬间追上第一人，黑雾笼罩，凄厉惨叫慢慢消散。
  2. **蚊王**仰天嘶吼冲向空灵后期修士，巨大口器刺入其体猛吸；其欲反抗之际，远处王林随意一指将其定住，眼睁睁看着死亡临近。
  3. 王林离开蚊王背部，身后**火本源真身**化作火海冲出，似燃烧天地，化作一张吞噬一切的大口扑向第三人。
- 第三人身上骤然爆发**翠绿光芒**抵抗火口，高呼“师尊救我”；话音同时大地草原轰然一震，一个闷闷之声自地底回旋而起：“**住手**”——章末悬念。

## 五、待续线索

- 矾珊梦（实为矾珊璐伪装）与炎栾留在大魂门，双方关系仍未了结。
