# 第2087章 婉儿，醒来吧

## 一、天运子的真相与其崩溃

### 器灵身份
- 天运子是**定界罗盘的器灵**。他没有自己的来历记忆：无数岁月前第一次苏醒时，就已经是这罗盘的器灵；也不知定界罗盘为谁所造。
- 他隐隐觉得，自己除器灵外，似乎也还是**此盘的守护者**。
- 他曾在盘内亲眼看到王林借此盘而来，一次次在轮回中消散；直至最后一次王林轰开罗盘、消散之后，他才从盘内走出，走出的刹那狂喜仰天大笑。

### 夺舍图谋
- 他认定**仙罡大陆一切众生皆虚假，唯有王林是真实的、有真实身躯**，故要夺舍王林。
- 其推算：夺舍成功、得王林肉身后，他将**完整地成为踏天境之修**，从此真正自由，不必再如囚徒般困于罗盘。
- 后续打算：获自由后去追查自己的来历——究竟是谁让他成了器灵；并将定界罗盘据为至强法宝。
- 他深知定界罗盘之强，尤其其**最重要作用之一：可让人离开逆尘界**。

### 崩溃
- 王林一番话戳破：**这一切不是王林的梦，而是戮默的道**。天运子内心充满荒诞感，计划尽毁，只剩绝望、愤怒、恐惧与不甘。

## 二、王林诛杀天运子

- 天运子化滔天黑雾疯狂扑来；王林面露淡笑，抬右手轻轻一挥。
- **王林语：「当我掌握了轮回时，我已然踏天。」** 黑雾当即发出磁磁之声、大范围肉眼可见地消散。
- 天运子凄厉惨叫「我不甘心」，残雾凝成一颗**硕大头颅**：相貌堂堂的中年男子，与天运子平日相貌迥然；**眉心有五角星图案闪烁，图案内隐有一只鹤的虚影在挣扎**。
- 头颅旋即散开，卷动残存黑气化作**巨大黑鹤**再度冲来。
- 王林上前一步，右手掐住鹤颈狠狠一握——轰然巨响，黑鹤全身崩溃；整个太古神境大地剧颤，天空浑浊。
- 天运子神识随之瓦解，**彻底死亡**。临灭前忆起自以为不存在的往事，喃喃：**「道展界……我的家乡」**。

### 遁走的灰气（伏笔）
- 鹤身散作无数黑气，其中**一道灰气**飞出直奔后方，冲入那与天连接的桥，融入桥后虚幻之内不见踪影。
- **这灰气上没有天运子的气息**。王林毫无意外之色，仿佛早已知晓其存在，只看一眼便不再理会。

## 三、一界本源与李慕婉苏醒

- 王林向散开黑气使劲一握，黑气倒卷凝聚，在其手心缩成**拳头大小、九色缭绕**的气团。
- 王林认出：**「一界本源」**——他目露罕见的激动。
- 左手虚空一挥取出**棺木**，其内沉睡着李慕婉（相貌非绝美，却透出温柔）。
- 王林抚其脸落泪：「婉儿……我曾说过，天让你死，我也要把你抢回来」「我做到了，数千年的时间，我做到了」。
- 将九色气团按在李慕婉眉心，看其融入体内；王林神色现出罕见的紧张，咬唇守望。
- 提及**「平儿」也会苏醒**，「你会喜欢这孩子的」。
- 长久无应，王林仰天凄吼「我是你的丈夫，我要你睁开眼」——一只温暖玉手抬起抚上他的脸，**李慕婉睫毛轻颤、睁开双眼**，眸中仍是数千年依旧的温柔与怜惜。

## 四、二人往事回溯（闪回）

- **修魔海外相遇**：李慕婉一次呼救的柔弱与彷徨双眸，令地底遁走隐匿的王林犹豫后抬头——「如果他没有抬头，或许一切都不一样了」。
- **修魔海中数年**：洞口处娇弱却坚韧的身影，王林心颤，自然而然说出「不要怕，我带你去杀人」。
- **青龙大阵**：李慕婉以心血刻着鳞片、化作保命玉简；苍白的脸让王林心痛，但背负血海深仇的他只能闭眼令自己忘记。
- **云天宗**：阁楼琴音与身影中的萧瑟，让王林明白自己忘不掉。
- **山谷温馨**与回头时的身影，直至李慕婉红颜白发、渐渐衰老走完余生；她闭眼那一瞬，王林心痛欲狂，立誓要将其抢回来。
- 王林自述之志：「我颠覆了整个天地，只为了摆正你的倒影／我逆转了整个苍穹，只为了那天遮不住你要睁开的双眼／我轰开了无穷虚无，只为了打开一条路让你找到回家的方向。」
