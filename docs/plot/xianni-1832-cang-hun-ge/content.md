# 第1832章 藏魂！

## 一、青天峰会见青牛真人

- **地点**：大魂门深处一座直冲云霄的翠青山峰——青天峰，是大魂门禁地，亦是青牛真人（青牛老祖）闭关所在。
- 王林一路疾驰，大魂门诸多禁制在其面前化作层层波纹，毫无作用。至峰外抱拳：「晚辈王林，青牛前辈可在？」峰体一震，禁制尽散，苍老声音传来：「最顶峰，我在这里等你。」
- 王林神识一扫，察觉此峰看似寻常，实则内蕴极强气息，暗判**「这是一件法宝所化之山」**，但不动声色，直上山尖。
- 峰顶青牛真人青衣白发盘膝而坐，王林于其对面坐下。

## 二、关于魂衍道的交锋

- 王林先以话锋试探：「魂衍道之术的确不凡，十七万八千年的修炼，说不定可以比得过仙皇国师。大魂门底蕴之深，王某佩服。」
- 青牛真人从容大笑，反赞王林「刚进大魂门就以大魂门为荣」。
- 王林直指其荒谬：修行一种神通十七万八千年、修为不增、生机寿元皆不够，这样的人有么？
- 青牛真人承认：**大魂门内从无人将魂衍道修至大威，即便第一代老祖也只烙印了四十一亿符文铭字**；又抬举王林天资惊人、机缘不少，或许能修至大成。
- 王林罕见地怒斥「放屁」。青牛真人愣住、眨眼、心虚干笑，遂岔开话题。

## 三、三个锦盒

- 青牛真人右手一挥，三道光芒化作三个锦盒飞向王林；王林大袖一甩收入袖内，看都不看。
- 王林讽刺：「不会又是打开锦盒的时间，需要十七万八千年吧。」
- 青牛真人声明：**这三样礼物是一代老祖当年为王林准备、大魂门一代代代为保管**，内中何物他并不知情，「就算是出了问题，你也别来找我」。

## 四、藏魂阁

### 入口与规矩
- 青牛真人指天，青天峰外裂开一道巨大裂缝，其内似另一处空间，中有一座巨大九层阁楼，雾气缭绕，灵魂威压弥漫，人在裂缝外即可感其压力。
- **规矩：历代只能选择一样神通；若想选第二种，须完成门派任务。**
- 青牛老祖借口「还有一炉丹药正炼」，瞬移匆匆离去。

### 空间与守门凶兽
- 裂缝内是模糊空间，无天无地，唯有那座九层阁楼与弥漫雾气。
- 阁楼外两尊巨大凶兽雕像盘踞，栩栩如生；大门上方竖着三个大字：**藏魂阁**——大魂门圣地、历代功法神通储存之处，王林隐隐看出此地杀机四伏。
- 右侧石像形似麒麟而有别，被王林目光注视时蠕动咆哮，心神内传音：「玉简拿来。」王林取出青牛真人所赠玉简，眼前一花、红芒一闪，玉简被卷走咀嚼后吐回，石像传念：「可入藏魂阁，选一样神通功法。」
- 王林瞳孔一缩，判断那红芒即是凶兽的舌头，速度之快他竟未看清；并看出石像实为封印一头极强凶兽之魂，魂与像融合后可变化种种神通。

### 逐层探查
| 层数 | 所见 | 王林评断 |
| --- | --- | --- |
| 一层 | 数千丈大房间，数千个七尺魂体盘膝漂浮闭目，男女老少皆有，全为魂体，各蕴一种神通功法 | 见到藏魂阁的秘密 |
| 二层 | 同有数千魂体，功法气息强于一层数倍 | 多为**空涅**修为可明悟施展，「对我来说已然无用」；未找到所求的两种神通 |
| 三~四层 | 一路停顿不久 | 略 |
| 五层 | 魂体骤减至约五百个，功法气息隐达**空玄**境界 | 任一魂体若放到洞府界，足以引起一场莫大浩劫 |

- 楼梯散发幽光、设有禁制，**可阻止一切非第三步大能上行**；对王林而言微不足道，他从容拾级而上。
- **王林此行目标**：寻找两种神通——**多重幻术**、**召引大魂门先祖之魂的术法**；至第五层仍未寻得。

## 五、转折：第六层的阻力与炎栾

- 王林脚步踏上通往第六层的台阶一瞬，**脑海轰的一声如遭重创，身子蓦然一震，止步不动**。
- 第六层中，**炎栾**盘膝而坐，头顶漂浮一个魂体，丝丝魂气自魂体钻入其天灵（正借魂体修炼）；此前自阁外望去，第六层雾中即有灯火之光闪烁、似有人走动。
- 炎栾骤然睁眼，心念：此时能来藏魂阁的很可能是王林；**「此人修为诡异，不可能只是空灵后期的样子，且看看他能不能上来，就可判断他的真正修为」**——以登楼与否试探王林真实修为。

## 六、要点与伏笔

1. 三个锦盒为一代老祖专为王林预留，来历与内容未明，是明确伏笔。
2. 青天峰疑为法宝所化，王林已看破却未点破。
3. 王林对外示人的修为为「空灵后期」，实为伪装，炎栾已起疑并设试。
4. 藏魂阁选神通「一次」的限制，与王林所求二术（多重幻术、召引先祖之魂）构成后续矛盾。
5. 楼层与境界对应：二层≈空涅、五层≈空玄，六层及以上更高，第三步大能为登楼门槛。
