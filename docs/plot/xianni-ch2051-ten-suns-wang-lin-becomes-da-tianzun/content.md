# 第2051章 十阳！

## 一、境界层次之辨：借用规则 vs 操控规则
- **大天尊常态**：可摸索到天地规则的边缘变化，凭强大信念把感受到的变化凝聚成实质，即『无中生有』——将虚幻化为真实。
- **王林所为**：直接一把抓住天地规则，蛮横强行令其为己所用。这已非借用，而是更高层次的**操控天地规则**。
- **参照**：宋天做不到；其记忆中唯有**古道大天尊**曾在他拜见时展现过类似一幕。

## 二、宋天神念古魔的怯退与被定身
1. 宋天一丝神念融入的庞大古魔自天幕裂缝走出，正撞见王林向天一抓、八方天地规则卷来之景，当场愣住、脑海空白。
2. 王林看都未看一眼，全部心神在融化中的仙祖头颅上。
3. 古魔缓过神后毫不犹豫后退，直奔自己先前嚣张撕开的天幕裂缝欲逃——身为大天尊未战先怯，与来时嚣张身影反差极大。
4. 临近裂缝时，王林冰冷一句「就这么走了么」，随即目光落下：古魔四周天地幻化出一道道细丝，缠绕之下将其**静止凝固**。
   - **定身术**：王林早年即猜测此术与天地规则有关；以其如今修为与感悟，已**无需掐诀**，一道目光即可瞬现。
   - 连古魔体内的宋天神念也一并凝固，神念一颤而无法运转。

## 三、原始山：宋天本体的应对
- 远在**始古一脉皇城外的原始山**上盘膝的宋天猛然睁眼，面色苍白、眼露骇然——神念被凝固竟隐隐牵动其元神。
- 宋天当即低吼「**开启原始阵**」，原始山上追随他的始古一脉强者纷纷错愣飞起，各就阵位全力布置。
- 其身后**蚩蛮**在侧（唤「师尊」）。

## 四、成就大天尊之阳
1. **仙祖头颅融化**：先前王林一口鲜血与天地规则缭绕之下，头颅已融大半，融化部分尽被其**三色大天尊之阳**吸收，阳内金光愈亮。头颅缩至拳头大小的金色光团。
2. **本源归位**：王林右手向下方行宫虚空一抓，存于行宫密室中的**生死、因果、真假三大虚之本源**穿透密室飞出，融入其体内；本源全部归位后，其体内轰轰作响，头发无风自动，气势惊天，不怒自威。
3. **最后一击**：王林向仙祖残颅吐出一口本源气息（无形，唯其自身可感）；残颅剧烈颤抖后**彻底融化消失**，被三色大天尊之阳完全吸收，此阳自此**成为真实存在之物**，且比其他大天尊之尊阳更为凝实。
4. **送阳入天**：王林双手抬起，三色尊阳如被托起般缓缓升向天幕至高处，爆发三色强光。
   - 追忆：当年他在**洞府界**以一丝神识来到仙罡大陆，第一次望见天空九个太阳的奇异。

## 五、十阳同现的天地异象
王林尊阳入空，牵动仙族、古族全境所有大天尊之尊阳自行幻化升空（并非各自操控，而是如相互牵引）：

| 阵营 | 尊阳出处 |
| --- | --- |
| 仙族 | 道一宗、北州、紫阳宗、祖城帝山各起一阳；祖城皇宫另现一轮金阳，为仙族第五阳 |
| 古族 | 玄罗闭关处之阳；极古一脉皇城内神秘极古大天尊之阳；始古一脉宋天之阳（不受自身操控地幻化而出）；古道山上古道大天尊之阳 |
| 新生 | 王林三色大天尊之阳 |

- 合计**十个太阳**悬于仙罡大陆天幕。
- **异象规则**：除仙祖一脉仙皇传承外，他人成就大天尊时便有此象；诸阳同现使全大陆天地之力卷动，其余大天尊可清晰感受到新生大天尊的气息。
- **大小排序**：古道之阳最大，几乎等于除王林外其余八阳之总和；王林三色尊阳次之，约为古道之阳的近一半，但光芒不弱于古道尊阳。

## 六、结果与影响
- 王林**成为真正的大天尊**——此前只能算不完整的大天尊。
- 王林跃居**整个仙罡大陆上除古道之外的大天尊第二强**。
- 罗喉郡行宫中，**计都皇子**愣立当场，眼露从未有过的强烈激动，大笑呼「义父大天尊！」
- 悬念：宋天全力开启原始阵，与王林的正面冲突已箭在弦上。
