## 三、仙术设定（司徒南此前一个月讲授 + 本章印证）

王林暗中将**司徒南**与天运子比较，不得不承认司徒南远非天运子对手：司徒南做不到

1. 一声之下使人元神崩溃；
2. 一语之下使万物恢复如初。

这已属**仙术**范畴，而非修士神通。

### 仙术的定义与分阶

| 要点 | 内容 |
| --- | --- |
| 常见误解 | 并非“用仙力施展的法术”就叫仙术 |
| 真正定义 | 与**修真联盟**赐予**修真星**的**天道印诀**同级的巨大神通 |
| 与印诀之别 | 印诀需要**传承**；仙术只需**口诀与印法** |
| 存量 | **仙界崩溃**后大量仙术失踪，随时间推移越来越少 |
| 分阶 | 下品仙术 → 中品仙术 → 上品仙术；另有一层**极品仙术**，太过罕见，司徒南也只是听人提过 |

### 三式杀招的来历（重要溯源）

- 司徒南多年前从**一代朱雀叶无忧**处得到一个**残次的下品仙术**。
- 因无法将其恢复，只能模仿，经无数年琢磨，终于模仿出**三式杀招**。
- 司徒南修的是魔道，故这三式模仿之招**拥有魔姓**。

# 天运七子封号的实利与紫系一脉的内斗

## 场景
白薇（三师兄）在与王林（紫系"老七"）茶叙中，系统揭示天运宗封号"天运七子"的价值与紫系一脉的权力格局。谈毕王林返回紫林阁独自权衡，随后换弟子衣衫、携令牌外出。

## 一、悬案：师尊的弟子都去哪了
- 师尊在天运星已历无数万年，但弟子中除极少数外，**大都只修炼千年左右，鲜有超过万年者**。
- 白薇称：紫系一脉中，唯有**大师兄**（跟随师尊最早之人）必然知情；老二、老四、老五乃至白薇本人皆捉摸不透。
- 白薇怀疑当年的**老七孙云**亦知内情，**叛出师门的原因可能正在于此**。
- 王林态度：沉默，劝"此事既无定论，莫要乱猜"——但心中已动念。

## 二、紫系一脉的封号之争
- 紫系是师尊**七系弟子中最弱的一系**，但内争不少。
- 大师兄窥伺天运七子封号已久：
  1. 当年与**六师弟**争夺封号失败，受**不可恢复的伤势**，修为大跌；
  2. 极为坚韧，硬闭关数百年准备雪耻；
  3. 结果被**孙云**击败老六与大师兄，夺走封号。
- **时间点：三个月后师尊大寿**，即紫系再次出现天运七子封号之日。
- **对王林的威胁**：这一次大师兄势在必得，除非老六外出历练归来，否则"外来者"王林将是他**必铲除之人**。

## 三、天运七子封号的四重实利（白薇口述）
1. **地位与追随者**：整个天运星上数人之下、万人之上，任何修真国无不遵从，并有大量追随者。
2. **封地**：各拥**一国之地**作单独修炼之处，天运星内任意选取，甚至有机会取得**星外之星**。
3. **问鼎助力**：婴变修士此生最大心愿即"问鼎"（"朝问道，夕死矣"），问鼎风险莫大、九死一生，甚至连失解重修的可能都没有；成为天运七子后**师尊出手相助，可将成功希望提高三成**。
4. **仙玉无限供应**：修炼所需仙玉无法想象，弟子月例份额随修为提高日益不敷；七子可获**整个天运宗仙玉的无限供应**。
5. **传道之机（最重）**：师尊传道并非虚幻，而是真正传授仙术——
   - **千年天运七子** → 传授一个**完整的下品仙术**；
   - **万年天运七子** → 再传授一个下品仙术；
   - 更有甚者 → 被师尊送往**修真联盟**深造，成为整个修真界真正的**大神通修士**。
   - 例证：**青系一脉李胜男**，千年天运子封号，百年前获赠一个完整下品仙术，至今闭关参悟，出关后实力将达可怕程度。

## 四、白薇的真实动机
辞别转身的一瞬，笑容消失、面露阴森：
> "大师兄，你想成为天运七子，只要我白薇活着的一天，就绝不可能让你成功，我要让你每次都失败——如此，才可报复你当年对我所做之事。"

判断：白薇向王林"交底"实为借刀，意在阻断大师兄夺封号，而非单纯提携新师弟。

## 五、王林的内心权衡：仙术的分量
- 若在从前，王林不知"完整下品仙术"之珍贵；但与**司徒南**相处一月、尤其掌握**三式杀招**后，对仙术有了很深理解。
- 司徒南仅凭**残卷仙术模仿**而出的三式杀招已具如此威力 → 完整仙术威力无法想象。
- **仙人强大的两大根源**：其一**仙宝**，其二**仙术**；拥有上品仙宝与上品仙术者近乎恐怖，修为越高实力越大。
- 可与仙术比拟者，王林所知**唯有古神一族的神通**。
- 王林从**涂司记忆传承**中得古神神通记载甚多，但须**吉神一族**方可施展且要求极严，**以本尊修为无法运用**。
- 结论："天运七子，有趣"——王林起了争夺之心，换上弟子衣衫、带令牌走出紫林阁。

## 要点提炼
- 封号 = 地位 + 封国 + 仙玉 + 问鼎助力 + 完整仙术传授，是天运宗内一切争斗的根本诱因。

# 第486-487章 紫宗七师祖 · 品灵阁前的剑意

- 正中巨大座椅上躺着**金魔子**：身子极为肥大如圆球，肤色晶莹剔透好似水晶，望之炫目。
- **金魔子来历与凶名**：
  - 天运星外一单独小星的**尊者**，独霸一星，横行跋扈；
  - 极为护短、脾气古怪，一言不合便出杀手，死其手者数之不尽；有人招惹必遭疯狂报复；
  - 修为通天，除有限几人外无人可制；**传闻其修为已超过虚实二意，达到传说中的那一步**。
- **交锋细节**：战车在赵星煞百丈外停下，强大威压锁定赵星煞；四妖兽凶目盯人、口水滴落；十名银衫者齐齐冷视不发一语。赵星煞脸角冷汗直流，仍恭敬见礼自称“晚辈天运宗紫系赵星煞”。金魔子皱眉喝斥“你这小娃愣什么，还不带路”，赵星煞深吸口气恢复温和，右手一挥令紫色雾带从中分开，露出长长通道，引战车缓缓飞向天运星。
- 此类场面几乎每天都在天运星上演，四周各修真星的大神通修士陆续到来，天运宗议论纷纷。

## 五、寿宴当日的席位等级

- 寿辰之日：万里无云、碧波浩淼、轻风花香。
- **寿宴共八处**：
  - 赤、橙、黄、绿、青、蓝、紫**七宗各一处**；
  - **天运宗总宗**一处，为天运子真正的祝寿之宴。
- 能在总宗之宴坐下者绝非等闲：**最终进入总宗之山者不超过百人，有时仅数十人**。
- **金魔子亦无资格参与总宗之宴**，以其身份仅能坐于**赤宗寿宴**——反衬总宗席位之贵重。

## 六、看点与伏笔

- 天运七子封号之争已成明线：赵星煞的“温和”是伪装，对老四暗含威胁手段，对七师弟已生杀机式敌意。
- 金魔子“超过虚实二意、达到传说中的那一步”，为本星域修为层级给出上限参照，却仍进不了总宗之宴——暗示总宗宾客层次更高。
- 寿宴八处、总宗百人以内的门槛设定，为后续矛盾集中爆发预设了舞台。
