# 仙逆 第638章 心死

## 一、开场：凌天候的自信

凌天候（一身道袍）抬头，眼中深邃，念及“剑灵封印”：

- 认为自己封印剑灵之处**极为隐秘**，不该被人发现；
- 更关键的一层保险——**只要那剑灵心存死念，便无法解脱封印**。
- 沉吟片刻后闭目。（本体不在场，裂缝处只有其留守神念）

## 二、潮汐深渊裂缝内：王林的强闯

### 1. 前情代价
- 王林先前一击化解了凌天候的**第三波神念**，代价极大：**雷兽涣散**，化作片片雷芒退回**射神车**内。
- 凌天候神念被打开一个缺口，但瞬间收拢。
- 王林体内气血云涌、多处经脉受阻、仙力流转不顺，仍不做调整，全速自缺口冲入裂缝深处。

### 2. 裂缝不长，一冲即达
- 裂缝并不如想象中狭长，王林一冲即入深处，感应到**周佚若有若无的一丝气息**。
- 凌天候神念再次降临，霸道之声“**擅闯者，死**”直落王林耳中：整个裂缝咔咔作响、泥壁遍布细纹；王林**元神被震萎靡，喷出一口鲜血，面色刹那苍白**。
- 王林判断：仅留守封印的神识便有如此神通，**凌天候本体来此将不可想象**。

### 3. 仙笔七笔符文（本章核心神通）
- 王林一拍储物袋，取出**晶莹剔透的毛笔（仙笔）**。
- 此前用仙笔仅单独划一笔（如吸引飞虫时十余个单笔简单符文），**本章首次叠加符文**。
- 连划七笔，**每一笔抽出一股元神融入符文**。
- **七笔即极限**：得笔后在炼魂部落祭炼时已试过，画不出第八笔——元神无法分成九份；肉身内须留一份，七笔各一份。**除非放弃肉身、全部元神融入符文，方可画出第八笔**。
- 第七笔落下后，体内仙力如脱缰野马尽数透体而出，全灌入七笔符文。
- 七笔融合为一个**圆形符文**，其内似蕴乾坤，如太阳落入裂缝，金芒刺眼且刺痛元神——**彻彻底底的仙人神通（仙家之笔＋仙文符咒）**。
- 金芒穿透深渊之壁，把无数年来始终阴暗的**水妖郡潮汐裂缝全部映亮**。
- 符文内含七道神识，王林操控之如同肉身般灵活，直逼裂缝深处。

### 4. 符文 vs 剑气
- 凌天候神念在金光穿刺下一度有消散迹象，随即低吼冲出，**幻化成凌天候本人的样子**（道袍、双目霸道），踏步间身影再虚幻，**化作一道剑气**扑向符文。
- 符文与剑气相撞：潮汐深渊剧烈回荡，无数裂缝坍塌，波动强到**水妖郡内多处颤动，妖灵地之人纷纷震惊**。
- 结果：
  - 王林**连喷六口鲜血**，血中蕴含大量仙力，落地形成深痕；
  - 符文碎裂，**七股元神六道崩溃**，最后一道回归王林体内（元神受损＝修道者大伤）；
  - 剑气大为黯淡但锋芒不减，碎裂符文化作无数金光点点，把剑气围成**金光困牢**——**困不久，但能困一时**。
- 王林眼中通红、杀戮之心涌现，已无退路，纵身跃过被困神念，直奔裂缝最深处。

## 三、封印现场：炼仙化魔大阵

### 1. 周佚的状态
- 前方地面之上悬着**通体紫色的灵体**——周佚。
- 双目紧闭、面露茫然；除眉心外全身皆紫，紫色如有灵性般蠕动，在脸部化作片片紫丝，**试图吞噬其眉心的一点金芒**。
- 眉心金芒若消散，周佚将**彻底沦为凌天候之物，再无清醒的一刻**（并将成为水妖郡古妖的身体）。
- 周佚身上散出浓浓**死气**。王林呼之为“**周佚前辈**”，阔别多年再度相见。

### 2. 阵法结构
- 周佚下方地面有**三丈大小的阵法**，即凌天候**自创**的“**炼仙化魔大阵**”。
- 阵上丝丝紫气升起、化作一个个符文，令阵威更大。
- **重点在四把宝剑**：插于阵法东南西北四方，电光自剑上散出融入地底。
  - 四剑乃凌天候**炼化四小天地所成“元神之剑”的投影**；
  - 其中**三把剑上各飘一个拳头大小的光球**，散出庞大神念（凌天候分出四道神念以增威力）。

### 3. 妖气来源与暗脉
- 阵中紫气本质是**妖气**，来源于**水妖郡的古妖残魂**。
- 裂缝所在是一条**地底暗脉**，直接连通**水妖郡燕京的古妖之庙**；古妖残魂的妖气顺暗脉不断被阵法吸收，转化为“炼仙化魔”的封印，侵蚀周佚灵体。
- 该过程**较为缓慢，但很稳定**。

## 四、旧账：凌天候、周佚、白衣女尸与水妖郡古妖

- **交易**：凌天候多年前偷偷进入妖灵之地，正因当年曾与水妖郡古妖残魂打过交道、关系微妙；把周佚封印于此，即算达成双方约定。
- **古妖的算盘**：妖灵九郡九个天妖残魂各怀心思，水妖郡古妖意在寻一个能承受自身（妖）融入的躯壳——周佚的灵体，借以彻底走出。
- **周佚来历**：被**白衣女尸**以仙力强行提升至**仙剑之灵**（雨之剑灵），拥有莫大神通；自仙界追出凌天候后一路纠缠，**一心求死**，不惜一切代价疯狂散出仙剑剑灵有限的**本命剑气**。
- **雨之仙剑**：雨之仙界第一宝。凌天候虽拿到一把，却**不敢在周佚面前拿出**——一旦拿出立刻会被周佚操控。
- **仙指印**：凌天候受白衣女尸仙指印所伤，一指便令其受伤；以其见识事后断定，此印**绝非仙君可施展**，是**唯有仙帝才可施展的上品仙术**。
- **狼狈与反制**：受伤＋周佚不顾生死的本命剑气，才使凌天候极为狼狈；但其强大无需置疑，只是“狼狈”而已。此后他把周佚引至妖灵之地，借此地奇异彻底擒住周佚，一举两得。
- **变数**：当初凌天候没算到，**几百年后王林的出现，把这一切全部改变**。

## 五、章题解读

“心死”——周佚的心，**在当年“婷儿”身逝的一刻，已经死了**。这既解释了凌天候“心存死念便无法解脱封印”的判断，也点明周佚甘愿求死的根由。
