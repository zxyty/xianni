# 第九卷 云海之巅 第1214章 铁柱（第一更）

## 一、设定：法术 / 神通 / 道术 三层之分
- **法术**：操控天地之力，以特殊方法幻化而出；强弱取决于修为与功法。
- **神通**：把幻化而出的法术威力暴增的方法——「通，变则通」，本质是元力的变化与凝聚。
- **道术**：罕有人可掌握，传闻唯有在**道境**中感悟方可领悟。其攻击与意境之战类似但本源不同：意境之战比的是相互感悟、是心神之争；道术是一种升华的力量，**针对灵魂的抹杀**。

### 三境之力的定位
| 境 | 代表之力 |
| --- | --- |
| 极境 | 极端之力 |
| 始境 | 创造之力 |
| 道境 | 不灭之威 |

## 二、白发老者的道境感悟与自尽一击
- 白发老者在**成为封灭族之时**，曾有幸短暂进入道境，在其中感悟出一个关于**人之本源**的道理。
- 其感悟：人之本源即**灵魂中的记忆**。人活一生实为一场记忆；记忆不灭，则人纵死亦可无止尽地活下去。反之，若把记忆中**有关意境的感悟**尽数抹去、使之如从未有过，记忆便残缺——残缺者「**仙落凡尘**」。
- 本章他施展的正是这门自道境感悟而出的道术：黄色光芒弥漫，柔和却足以穿透世间一切之物，笼罩者会生**踏入轮回之感**，前生今世在眼前闪过、难分真幻。
- 该光芒穿过王林体外环绕的**战之意境**，直接透体降临于其**灵魂记忆**。
- 老者言「**三息的时间，足够**」，随即双目骤闭、**生机全消，好似归墟**（以自身为代价施术）。

## 三、幻境：回到赵国山村的「铁柱」
- 七彩天空风卷残云而散，化作清澈蓝天白云；大地层层消失、山峰节节缩小，最终成为一片翠绿木林与乡村土道。
- 王林醒来时是山村少年**铁柱**：捡起书简，望见远处云雾缭绕的山峰与宗派阁楼；村中炊烟、孩童嬉闹、犬吠。
- 猎户中年汉子与几名青年招呼他「铁柱，你爹正找你呢」「好好读书，考上一个状元」。
- 王林自认「**似乎做了一个梦**」——梦里成为仙人、经历了一千多年的人生。

### 幻境中模糊记起的「梦中人事」
- **人物**：红蝶、李慕婉、柳眉、木冰眉、吕烟菲、李倩梅、云雀子、朱雀子、司徒南、天运子、朱雀圣皇、青龙圣皇、拓森、涂司。
- **弟子**：自述收了两个弟子——**十三**、**谢青**。
- **地理/势力**：朱雀星有古神；朱雀星外有尸阴宗、修真联盟、四圣宗；自己所在为**联盟星域**；去过**罗天星域**、**云海星域**，甚至**去过仙界**。
- 一处刺点：「梦中，爹娘已经死去了」。

### 家中一幕
- 父亲磕烟灰、训他好好读书，明年便是县里大考，「可别跟爹一样，一辈子呆在这里」。母亲埋怨父亲、端饭菜，一家人院中吃饭。
- 马车声与敲门声传来——王林**记得梦中「好似是四叔来了」**，下意识开门，果然是精壮虎目的四叔。
- 四叔提议：**恒岳派今年收取弟子**，让铁柱去试试，一旦入门便成仙人。父亲激动而犹豫。

## 四、记忆被牵引：一生关键节点重演
1. **走出山村**：考验失败，在亲人嘲讽中独自离开。
2. **山崖坠落**：歇息时身后猛虎扑来，摔落山崖，被吸入一处奇怪山洞。
3. **拾得珠子**：洞中捡起一个珠子（石珠）。右手触珠刹那，耳边响起一声极其熟悉的惊呼——「**天……天逆**」，随即被承受无法想象痛苦的**惨叫**取代。此时时间似在崩溃，隐隐有七彩之芒——**说明道术对记忆的操控已出现紊乱**。
4. **跳跃数年·藤厉追杀**：王林疾遁逃命，青年**藤厉**从容追来，冷声「在我藤厉手中，你逃不掉的」。
5. **山谷立誓·极之力诞生**：巨大山谷中，悲愤与心神剧痛如潮，王林仰天怒吼、跪地泣血：
   > 「藤家之人，但凡我王林有一线生机，终有一日，我要你藤家全族血流成河，染红赵国……让你藤家满门俱灭，不留哪怕一个活口。若违此誓，让我王林千刀万剐，不得好死，永沉地狱。」
   - 结果：**一夜白发**，四周如入寒冬，体内诞生不属于凡人的至极之力——「**极**」，世间一切杀戮的巅峰、力量的极限。

## 五、神秘声音的震撼与幻境崩塌
- 极之力诞生刹那，那惨叫的声音再次传来，充满无法置信的震惊：
  > 「极……竟然是极……此人一生到底都经历了什么……竟然出现了极……**天逆在他手中，极之力也在他手中**……此人……此人……」
- 声音越来越清晰，最终回荡天地，致使幻境中天空崩溃、大地坍塌、一切倒卷，**七彩之光充斥而来**——记忆幻境瓦解，王林即将回到现实战场。

## 六、要点提示
- 白发老者付出的是**生机全消**的代价，而其道术并未成功抹除王林记忆——反被王林一生的极致因果（天逆、极之力）冲垮。
- 「天……天逆」这一熟悉声音的主人，是本章埋下的最大悬念：王林反复思索却想不起在何处听过。
- 本章为回忆/幻境章，凡人期「铁柱」的赵国山村、恒岳派收徒、藤家血仇均属**故事早期的世内时序**，与第1214章的叙事位置不一致。
