# 第2068章 快乐与责任

## 一、山岳洲山村：周茹的转世与选择

### 场景
- 山岳洲东北方向，连绵山脉之下、距官道不远处，有一座「桃园般」的村庄。
- 村民仅数百，多为猎户，靠猎捕山脉丛林野兽为生。
- 由来：最早只是猎人休息的荒地，后有一行自京城避难的官人携家眷至此，岁月流逝乃成村落。

### 一家三口
- **少女（周茹转世）**：十几岁，穿带补丁麻布衣衫，喂养鸡鸭；相貌并非特别美丽，但清纯可爱。
- **少妇（其母）**：衣衫朴素而难掩美丽，屋内做饭，笑称自己在少女这个年纪已嫁人。
- **中年汉子（其父）**：村中最厉害的猎人，背弓箭、扛豹兽归来，腿上有一道不深的抓痕，因追寻豹兽为女儿做皮袄而耽误了归期。
- **小白**：黑色大狗，样貌却如猛虎，在山中学虎叫，护主使「山里的野兽伤不到我姓命」；被少女抓痒时发出似虎的咕咕声。

### 关键对话
- 少女反复梦见自己成为仙人，却说：「我总觉得，自己好像在梦里做了一辈子的仙人，可是不快乐，一直都不快乐……我要和爹娘在一起一辈子。」

### 王林的观察与决定
- 王林白衣悬于天幕，俯视这一家人的快乐，尤其看着少女的笑容而微笑。
- 认出少女即**周茹转世**；亦意识到**小白**当年被一同带来，转世为大狗，**已然成精、具备不俗修为**。
- 小白双目一转似看到天空的王林，愣怔转为恐惧，连咕咕声也停下——全场唯一察觉者。
- 听少女之言后王林一顿、目露复杂，深深看过山村与笑容，一晃消失，心道：「或许，这样的生活，才是她想要的。」

### 当夜双梦（王林的安排）
- **少女梦**：梦中自己另有名字「周茹」，身边有名唤小白的黑色老虎（常被她欺负、罚其倒立），还有一位如至亲的叔叔；叔叔问她是否同去，她沉默考虑很久，答：想留在这里。
- **土狗梦**：梦见自己成为老虎，在凶兽界叱咤风云、被母老虎母凶兽伺候；又梦见当年抓它来的白衣男子给了它一些好吃的丹药、在头上拍了一下后离去。
- **留言（缭绕心神久久不散）**：「当有一天，周茹想要追寻自己梦的时候，你将其记忆开启。」

## 二、仙族中州祖城：唤醒疯子

### 祖城与皇宫
- 仙族中州的祖城范围太大，城中时刻可见**日月交替同时出现**之景。
- 此刻皇宫为黑夜笼罩，灯火点点，一片寂静。
- 王林自黑暗中走出、一步走下，灯火在其降临中闪烁朦胧，**似有不同空间重叠成影**，待其踏上大殿广场方恢复如常。

### 旧誓
- 王林当年在此几乎九死一生，且无法带走疯子，只能看着疯子化作山峰，成为**镇压七十二洲天外之灵**的存在，沉睡永恒。
- 离开时立誓：「当我再次来到这里时，我要让疯子苏醒，任何人将无法再阻拦。」

### 破封
- 王林一踏，皇宫地面微颤——颤的不是真正的大地，而是**与之重叠的空间**；随即身影闪烁，至地宫。
- 地宫朦胧如昔，地面诸多山峰此刻**只剩一座**，直插天际、极为磅礴；山峰内外无数禁制封印，**即便大天尊修为也往往需要很久才能破开**。
- 王林右手一挥，山峰轰鸣崩溃、碎石脱落、迅速缩小，**一切封印禁制烟消云散**，露出沉睡的疯子——其身上有**大天尊修为的波动**。

### 唤醒与尊重
- 王林蹲身，右手点其眉心，疯子身体一震；王林闭目，神识顺指入体唤醒，历时**半个时辰**。
- 王林睁眼、面露复杂，沉默片刻后道：「你如果真的这么决定，我选择尊重你，保重。」随即向天空迈去，消失于地宫。

### 疯子的抉择（本章题眼）
- 王林走后疯子睁眼，望着其消失处许久，喃喃：
  - 「我迷糊了一辈子，疯了一辈子，可是我终究还是仙祖的后人。」
  - 「**连道真已经死了，若我再离去，仙族将无皇。**」
  - 「我也想离开这里，离开仙罡大陆，可是，我既有了仙祖的传承，我就有应该担负的脊梁，这是我的责任。我在这沉睡中，想明白了。」
  - 「守护仙族，代代传承下去，**当我有一天不需为了责任去勉强自己时，王林，我会去寻找你**。」
- 疯子起身：身穿皇袍、头戴帝冠，神色**再无丝毫疯癫**，代之以属于**仙皇**的威严。

## 三、要点提炼

| 线索 | 结果 |
|---|---|
| 周茹转世 | 选择凡俗亲情，不愿再做仙人；记忆封存，待其自己想追梦时由小白开启 |
| 小白转世 | 化作黑色土狗，已成精、有不俗修为；受托为「记忆钥匙」，获赐丹药 |
| 疯子 | 被王林破封唤醒，却自愿留下继任仙族之责，从疯癫化为仙皇威严 |
| 王林 | 两处皆「尊重他人选择」——不强留周茹，不强带疯子；旧誓已践 |

## 四、悬留伏笔
- 周茹何时会「想要追寻自己的梦」，从而由小白开启记忆。
- 疯子何日不必为责任勉强自己，将去寻找王林。
- 连道真已死后仙族的格局与七十二洲天外之灵镇压的后续（山峰已被王林崩碎）。
