# 第1052章 云仙道侣的身份（第八卷 联盟隐秘）

## 一、重逢周佚：恩人之谊与伤势
- 王林再见周佚，恭执后辈礼：“当年承诺之事，怎敢相忘，即便是这里再危机，王某也一定要送来青霜之肉身。”周佚是他一生不多的恩人之一。
- 周佚欣慰，请其不必称前辈，改唤“周大哥”。
- 周佚一眼看破王林伤势：**元神黯淡不清，恢复过慢导致隐患更重**。
- 王林简述与**虚空子**冲突：只说朱雀觉醒，**隐去本源之事**（非不信任，而是本源太过重要）。
- 周佚将虚空子记入心中——伤了为他送青霜而来的王林，等同触其逆鳞，有机会必让其付出惨痛代价。

## 二、索丹：周佚向云仙道侣层层加码
- 背景：此层丹药大部分当年已被**云仙道侣（王巍、胡娟）**取走，余下者只对灵体有效，因储存方式复杂而留存。
- 周佚化剑芒穿透丹房禁制求丹；王巍、胡娟自紫林禁制走出，**三步即至**。
- 王巍挥手抹去丹房外禁制“好似从未出现过”，王林瞳孔骤缩。
- 赠丹三阶递进：
  1. **六瓶五品凝仙丹**（浓郁仙气，王林未服，收入储物袋）；
  2. 周佚道出“王林曾救被封印于此的自己”→ 加赠**五瓶藏天丹（四品仙丹）**，五彩之芒，**可大范围缓解元神之伤**；
  3. 周佚点破自身为**雨之仙剑剑灵**并提及**雨之仙君青霜**→ 再抛**三瓶**仙气更浓的丹药（未介绍功效）；
  4. 讲述往事期间 → **数十个各色药瓶**一次性挥予王林。
- 王林此时才明白周佚先前“丹药我来想办法”的用意。

## 三、周佚自述：青霜往事（重度闪回）
- 当年在**雨之仙界**迷恋一具女尸，以**仙玉塔**存放，使其肉身不腐、永恒存在。
- 起初以为她是“**婷儿**”，后来才知她是**仙君青霜**。
- 最后一次带“婷儿”去雨之仙界时，**遇到了王林**。
- 有人欲抢夺青霜之尸——胡娟闻之杀机顿现，王巍威压弥漫。
- 为护尸**燃烧魂魄**，代价是达到问鼎后神智清醒，仍言“**我为她甘愿燃烧一切，我无悔**”。
- 青霜体内因其**千年痴迷**而生的**残魂苏醒**，救活濒死的周佚，使其成为**新的雨之剑灵**。
- 王巍以修为阅历一眼辨其真假，暗叹“**孽缘**”；此前他因担心搜魂毁其灵而一直隐忍未问，此刻始知全貌。

## 四、身份揭晓：仙帝青霖旧部
- 王巍、胡娟躬身致谢：“周兄大恩，王某代青霜先谢”“我夫妇二人绝不会忘”。
- 王巍称赞王林重义，并因王林的谨慎追问而更为欣赏。
- **王巍**：当年**仙帝青霖座下第一侍卫**，同时是**恩师二弟子**；自陈身份刹那，气势冲天，透出惊天动地的傲意。
- **胡娟**：**恩师第七弟子**，自幼与**青霜妹妹**一起长大。
- 仙界大劫崩溃时二人外出行事，侥幸避劫；后得知**恩师未死，重伤隐匿闭关**，多年寻访无数洞府，最终确定恩师就在**仙灵天境**内。
- 王巍抬头望向**仙帝洞府第六层中心位置的黑雾**，神色惆怅。

## 五、禁制之秘
- 胡娟挥手令身边禁制威力更胜原本，向王林点明：**仙帝洞府内建筑与全部禁制皆为她一人为师尊布置**，故其后加的改动才能完美融合。
- 王林苦笑：“原来是你，我还以为是王巍前辈。”
- 王巍摇头自承禁制之术不如胡娟，“当年与她因你之事打赌，也就不会输了”。
- 胡娟曾问王林是否“**破灭禁的传人**”，王林答：“不是传人，只是略知一些。”

## 六、悬念收束
- 王林一拍储物袋，正欲取出**仙玉塔**（交还青霜肉身）——
- 王巍神色骤变回头，**一声尖锐之笑回荡第六层内**。章末悬停。
