# 第2083章 踏入的资格

## 一、场景与局势
- 地点：苍茫盆地，海墙风暴处。风暴中心是由**九个通天柱子**组成的大门，门间缝隙随时间推移不断变大。
- 时间锚点：太古神境（文中亦作「太吉神境」）开启**倒计时十二天**起，至开启前**最后一天**。
- 在场两方：
  - **古族（三脉）**：宋天、玄罗、极古大天尊三位大天尊 + 数百三脉族人；王林在侧。
  - **仙族**：久帝、武封、道一三位大天尊 + 数百修士。

## 二、异变：轰鸣远超以往
- 十二天前，海墙风暴轰鸣以数倍方式轰然而起，空间大量开裂，声如鬼哭，蕴含震碎心神与身躯之力。
- 六位大天尊判断：**此时的烈度相当于以往太古神境开启前最后两天**，因此「这一次的太古神境，有古怪，与以往大为迥异」。
- 王林对此声完全无视——「修道到了他如今的程度，莫说仙罡大陆，就算是仙罡大陆外的无穷天地间，能让他心惊之事之物，已然极为罕见」。

## 三、护持与三次撤退

### 1. 六大天尊出手护持
- 宋天身后浮现一轮巨大太阳，玄罗、极古大天尊同时出手，护住古族数百族人。
- 仙族由久帝三人同时布下防护。
- **王林未出手帮助任何人**——「这没有意义」，因为他已明白十二天后的结果。

### 2. 第九天：第一次撤退
- 轰鸣传遍整个苍茫盆地，连仙族与古族靠近盆地的边缘郡洲亦隐隐可闻。
- 第九天黄昏，天空破碎、大地龟裂，被护数百人七窍流血；武封直言「明天将会出现死亡，甚至我等也会在没进入太古神境前就受伤」。
- 久帝下令：**金尊以下修士全部后退，传送离开苍茫盆地**；古族令未度过**三损七劫**的族人退走。
- 结果：两侧各余不足百人，六大天尊压力骤减大半。

### 3. 第六天：王林出手与断言
- 轰鸣再强数倍，六人再度承受不住。**玄罗首次向王林开口**（宋天与极古大天尊早已把希望寄托在王林身上，同时疑惑古道为何迟迟不来）。
- 王林称玄罗为「师尊」，起身叹息后抬手一挥：玄罗三人压力尽消，近百族人从痛苦中恢复如常。
- **核心断言**：「他们最终也无法踏入太古神境，甚至就连你们也无法踏入」；并推断「古道应该也察觉到了这一点，所以他没有现身，强行干预」。
- 仙族一侧无此助力，久帝再次下令天尊、金尊修士全部退下，**仅剩十一名跃天尊**（并非所有跃天尊都选择来临，这十一人是自愿来此者）。

### 4. 第三天：仙族十一跃天尊离去
- 轰鸣已是以往开启时的数倍不止，十一名跃天尊在不甘中默默传送离开苍茫大地。
- 久帝三人盘膝而坐，无需再庇护他人，可全力抵抗以求坚持更久。
- 玄罗三人内心苦涩，预感王林所言为真——若非王林出手，古族一侧也会只剩他们三人。

## 四、终局前夜
- **开启前第二天**：风暴以恐怖程度**暴增百倍**，天地崩溃化为无数碎片，天与地成为虚无。
  - 仙族：久帝三人面色瞬间苍白，迅速将神识连接一起合力对抗。
  - 古族：因王林之力，玄罗等人似毫无所觉，对王林的强大有了新的认识。
- **古道现身**：无声无息，仿佛本就存在于此，自虚无内走出，盘膝坐在王林身旁，看了一眼海墙风暴后长叹。
  - 下令：「玄罗，你们三人留下，其余人，离开吧。」抬手一挥，近百族人身影虚幻消失。
  - 此后海墙风暴外**只余八人**（王林、古道、玄罗、宋天、极古大天尊 + 仙族久帝、武封、道一）。
- 王林看了古道一眼未言语，继续注视风暴内石门缝隙——缝隙更大了，**目中隐隐露出期待**。
- **最后一天**：风暴卷动虚无形成磅礴漩涡，急速转动之下久帝三人齐齐喷血、身躯倒卷退后千丈，已至极限。
  - 道一第一个咬牙离去，随后是无奈的武封；唯久帝神色扭曲、青筋鼓起、低吼中仍想坚持。

## 五、要点提炼
- 本章确立：**此次太古神境开启的门槛远高于历次**，「踏入的资格」被风暴本身筛选——先是金尊以下、再是天尊/跃天尊、最后连大天尊也被逼退。
- 王林已是全场唯一从容者，实力层次明显高于仙古六大天尊；古道与其并坐，且认同其判断。
- 悬念：石门缝隙渐大与王林目中的期待，指向他对此次异变另有所图。

> 注：原文中「太吉神境／吉族／吉道」为「太古神境／古族／古道」之误写，「大夭尊」为「大天尊」之误写，已按正名处理。
