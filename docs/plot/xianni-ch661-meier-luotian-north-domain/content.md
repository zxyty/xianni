# 第七卷 名震罗天 · 第661章 眉儿

## 一、王林线：化名「许木」，借路摸底罗天星域

### 误认与试探
- 冉月等四人（含孙雪山）称王林为「雷仙使者」，王林**既不承认也不否认**。
- 冉月心惊后迅速平复：法术虽相似，但雷仙使者地位超然；更关键的是她**看不出王林修为**，因此对其身份犹豫不定。
- 孙雪山则完全笃定，态度恭敬近乎狂热，主动请缨为王林带路前往冉云星。

### 化名「许木」
- 冉月问名讳，王林答「许木」——**隐瞒真名**，理由是料定天运子等人不知何时便会追来。
- 冉月心神震动：「许」是北域千幻星大姓，许家之势如苍天大树，遂疑王林为许家之人；孙雪山闻之瞳孔一缩，更加恭敬。
- 冉月追问「前辈从何处而来」，出口即悔，连忙告罪。王林评价此女聪慧、如大家闺秀，是四人之首。

### 借问路了解罗天星域（关键地理情报）
- 王林嫌四人速度慢（照此需七天），主动**放缓星罗盘速度与四人同步**，借机了解罗天星域，方便日后行事。
- 孙雪山答：冉云星隶属**北域五大主星之一的千幻星**，附近还有很多同样的隶属星。
- 王林由此推得：**罗天星域分东、西、南、北四域**，自己身处北域。
- 王林内心一动：「千幻」之名很熟——当年朱雀弟子柳眉修炼的正是**千幻无情道**；但他判断两个星域应无关联。

### 「东临星」三字的威慑
- 王林问「东临星，你可知晓」，孙雪山面色大变、后退数步、面色苍白；冉家二男子亦无血色；冉月倒吸冷气，此前对王林身份的种种猜测一扫而空。
- 冉月介绍：**东临星是罗天东域第一星，又名「东临杀星」**，诡异之处在于虚无缥缈、时而出现时而消失。
- 冉月未说出口的一句：凡东临星走出之人皆狠辣，曾有东临星修士**生生屠尽一个修真星上所有家族**。东临星是罗天星域大部分人的梦魇。
- 此后无人敢直视王林；四人心生疑惧、速度越来越慢、隐约不愿带路，但每欲改向即迎上王林冰冷目光，只能硬着头皮前行。

### 王林的观察
- 四人表现与修为不符：他所见婴变期修士虽不及问鼎老怪老奸巨猾，也都心机深沉不轻易动容。
- 结论：**家族形式的修真势力，族人多半少经血雨腥风**；未经无数生死考验者，修为再高也成不了啸傲天际的雄鹰。

### 抵达冉云星
- 数日后，水蓝色星球现于神识中：海洋占大半，灵力自海面涌出、浓郁滋润万物，**远超王林家乡朱雀星**。
- 王林当先踏出，星罗盘化作刺眼银芒直入冉云星，随后身形一晃消失无影。
- 领路四人面如死灰，回星后立刻赶往家族，把一路所见统统上报以备万一。

## 二、眉儿线：幻家大长老带徒返罗天

### 场景
- 与王林入冉云星同时，**罗天星域另一端的联盟星域**内，一道漆黑长虹呼啸而过，气息恐怖、所过如奔雷游走。
- 长虹内是一位**一脸桀骜、消瘦、狠毒之色闪过的老者**；奇处在于他星空飞行**不用任何星罗盘之类法宝**，踏步间如挪移。

### 眉儿
- 随行女子相貌绝伦：朱唇不点而赤、细眉凤眼、青丝三股一盘一散、簪双蝶戏云白玉钗、淡彩锦绣描花宫装配碧烟撒花绫裙。
- 评价：**姿容比之当年红蝶亦丝毫不差**，堪称天资国色；另有一股**内媚之气息**。
- 修为**已至问鼎期**，但仍需老者以仙力牵引方能跟上其速度。
- 她自幼在联盟星域长大，临别回望星空，眼中追忆、叹息与复杂交织，轻叹「就要离开了」。

### 收徒缘由与此行成败
- 老者称她「眉儿」，目露和蔼，安慰道：待修为有成再回来便是；此行联盟星域**虽未找到那样宝贝，但收了你为弟子，也算值了**。
- 老者身份：**罗天星域北域主星千幻星「幻家」大长老**。
- 数百年前偶遇眉儿，一眼认出她修炼的竟是**千幻无情道**，且隐约**向万幻天魔道发展**，大吃一惊。
- 设定说明：无情道修炼不分星域、功法很多，主在心态感悟；能凭自身修炼至「千幻」程度已属少见，而向万幻天魔道发展的迹象才是真正让老者动收徒之念的原因。
- 老者见过很多家族晚辈，除有限几人外无人可比眉儿天资，且那几人潜力亦有不足。
- 数百年相处使他更加爱护此徒，**为她放弃继续在联盟星域寻找天逆珠**，带其回罗天星域。

## 三、要点与伏笔
1. 王林在罗天星域的公开身份 = 「许木」（化名）+ 被误认的「雷仙使者」，两重伪装同时生效。
2. 罗天星域框架首次成形：**四域（东西南北）→ 主星（如北域五大主星之千幻星）→ 隶属星（如冉云星）**。
3. 「千幻无情道」在朱雀星（柳眉）与罗天北域千幻星（眉儿之师门）两处同时出现，王林已注意到却主动否定关联——明显伏笔。
4. 东临星（东临杀星）作为罗天东域第一星、时隐时现的杀星，被立为全域梦魇级设定。
5. 天逆珠（对应石珠一线）成为罗天强者跨星域搜寻的目标，幻家大长老即为搜寻者之一而无功。
6. 眉儿出场即问鼎修为、绝色、内媚、修千幻无情道向万幻天魔道演化，是本卷重量级新角色。
