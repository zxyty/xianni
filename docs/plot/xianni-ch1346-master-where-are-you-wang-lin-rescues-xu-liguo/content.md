# 第1346章 主人在哪！（第九卷 云海之巅·第三更）

## 场景
- 地点：被无尽雷域包围的**闪雷族**领地，十六颗修真星中的一处修真星。
- 事件性质：许立国被闪雷族强者追杀 → 王林现身救援并当场击杀一名净涅长老。

## 追逃过程
1. **许立国**化身黑雾，卷着一名**绝艳女子**急急逃遁，面露惊慌与恶毒。
   - 女子讥讽：当初被许立国擒住已惹下滔天大祸；眼下只出动一位长老就让他落荒而逃；待其父出关，必将许立国炼成**一道魂雷**，承受万年折磨。
   - 许立国自称「你家许爷爷」，扇其耳光，恶语不断。
2. **青衣老者**（净涅修为）踏空而来，一步跨越无数，掐诀引动漫天银蛇电光轰击。
   - 许立国双手并拢一斩，**无尽剑气**自体外爆发、散发阴寒，与雷霆对撞；许立国喷出魂体精气，萎靡后退。
3. 许立国当着老者的面猥亵、撕扯女子衣衫以激怒对方，并反复嘲讽「以你净涅修为怎么可能追不上我」「一百遍啊一百遍」，令老者几乎七窍生烟。
4. 老者眉心**族印**闪烁，拍出**黑色雷球**；雷球轰爆后有**三道黑丝**射出，每道蕴含近乎毁天灭地之力。许立国以女子为挡，黑丝顿了一下改变方向，其灵体已然重伤、全身模糊。
5. 许立国威胁：「我是灵体，夺舍你身体非常容易」，女子面色惨白，闭口不敢言。心中却苦涩连连，暗呼主人快回来。

## 转折：碎涅圆满出场
- 一名**蓝衣道袍中年男子**凭空显现，拦在许立国前方，温和道要将其灵体抽干、封入猪狗体内。
- 绝艳女子惊喜唤其「**干爹**」。许立国瞳孔收缩，认出对方修为**碎涅圆满**。
- 中年男子随手一挥，许立国被震得四五分裂化作黑雾，女子被柔和之力卷回其身边；此后许立国凝形—崩溃—再凝形，周而复始，急速虚弱，濒临彻底灭亡。
- 中年男子扬言：不会一下子杀死他，要让他在不断瓦解中一次次品尝死亡的恐惧；并追问其主人是族中何人，要让其陪葬。

## 高潮：王林现身
- 一个冷漠如无数利刃、蕴含无尽寒意的声音传来：「**我，就是他的主人**」。
- 天空刹那被雷霆闪电彻底取代，好似有人把外界雷域生生搬来；**王林**自雷霆中一步步走出。
- 中年男子笑容僵硬——他一直神识散开，直至声音出现才察觉，眼中震惊。
- 许立国惊喜委屈，欲飞向王林；青衫老者因恨其入骨，下意识抬手阻拦。
- **代价即死亡**：王林袖子随意一甩，瞬息出现在老者身旁，右手随意点在其眉心——老者肉身轰轰崩溃，元神亦随之灭亡。
- 蓝衫中年男子瞳孔骤缩、额头冒汗，露出骇然，后退数步，抓着女子就要遁走（本章至此收束）。

## 要点提炼
- 许立国身份定性：**剑灵**、灵体，由王林放出，具备极快速度与精妙神通，可爆发剑气，且能轻易夺舍他人。
- 闪雷族战力刻画：净涅长老（族印、黑色雷球、三道黑丝）在王林手下一指即灭；碎涅圆满者亦感骇然。
- 王林此时于闪雷族中以夺舍**于非**之身潜行（依世界状态须知，自第1242章起），本章正文直呼其本名「王林」。

## 待续悬念
- 碎涅圆满的蓝衫中年男子与绝艳女子能否遁走；女子之父（出关后欲炼许立国为魂雷者）尚未登场。
