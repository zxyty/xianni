# 第十卷 叱咤界内 第1483章 此事，无碍！（第三更）

## 一、开场：一句「此事，无碍」

某苍老之声（东临星内）自信地说出「此事，无碍」四字，却全然不知王林已经来了。叙述明言：若他知晓，这四个字怎也无法再说出口。

## 二、旧怨回溯（千年前因果）

- 王林当年满怀复活李慕婉之望，自联盟星域来到界内，一路拼杀，于**封仙一战**中获**雷仙封号**，并取得上古修真家族**向家的一次承诺**。
- 当年王林本无意与向家为敌，只求李慕婉苏醒。在**向云东**引路下第一次来到东临星，拜见**向家老祖**。
- 结果：向家老祖卑鄙阴毒，不但未使李慕婉苏醒，反**夺走王林全部生机**；王林**依靠寂灭指**才未当场身死。
- 千年后回首，王林看清：
  - 向家老祖所言一切皆虚假，其根本无能力复活李慕婉，纵用**七夕之术**亦不可能；
  - 所谓「七夕之术生机注入」，实为导致**李慕婉魂飞魄散**的重要原因之一；
  - 对方是在抢夺王林生机之余，**蓄意灭绝李慕婉**；
  - 若非**避天棺**，李慕婉复活之望恐被此事彻底毁灭。
- 王林之恨滔天，且他更想知道「**为什么**」——向家老祖为何要以复活李慕婉之名行此事。
- 对照：王林早年面对**藤家**时亦曾忍耐数百年；当年的他没有资格发问，今日他有了。

## 三、临门：一步与一吼

1. **一步**：王林自东临星数万丈外向前一步，星空轰鸣，直接跨越至东临星千丈之外；波纹如海浪横扫，如踏在星空脉搏之上。东临星外数十小星上的数千修士心脏狂跳，被迫急速运转元力方能不崩。
2. **一吼**：「**你知道我是谁，给王某滚出来**」——回音三叠，星空化作雷池地狱。这一吼宣泄了他隐藏千年的愤怒、被夺生机之恨、被欺骗之绝望。

### 一吼之果

| 范围 | 后果 |
|---|---|
| 东临星外小星 | **九颗修真星当场瓦解**，其上驻守修士肉身崩溃、元神搅碎；**二十七名把持阵法的老者**无抵抗之力尽死，连逃走资格都无 |
| 其余小星 | 数千修士喷血，心神震动，生出无法抵抗的恐惧 |
| 罗天东部 | 巨响传遍罗天东部所有星域 |
| 东临星地表 | 大地无数裂缝、山峰崩碎、河流倒卷；北部大海形成漩涡与海啸，千丈大浪淹向陆地 |
| 极西之地 | 两名黑衣老者倒退百丈喷血，**其中一人肉身崩溃而亡** |
| 地底人头之海 | 地面裂出沟壑；**大半头颅爆开**；弥漫数万年的死气倒卷外退；**土黄色棺材**盖被震飞四分五裂，棺内传出低吼咆哮，一只**干枯右手**伸出扣住旁边棺木 |

## 四、向家应对：三处大阵与漩涡封星

幸存的黑衣老者以**黑色玉简**急传：「布阵，不惜一切代价，阻止此人进入东临星。」东临星上现修士不下数万，占据东、南、北三处方向：

- **北部·吕姓家族**：上万修士坐地组成庞大阵法禁制，几十名老者盘膝半空掐诀、连连喷血，血液凝聚化作一个**血影**浮现。
- **南部·许姓家族**：近万修士环绕，正中为**千丈血池**，池内煞气疯狂冲出，众修士神色凝重逐一走入血池。
- **东部·刘姓家族**：每七人一组，占据数千里，每组旁有一件数十丈高、样式各异却均散发**黄芒**的法宝；自空中俯瞰，整体组成一个**巨大的葵花图案**。
- **星外**：剩余几十颗小星禁制之芒急闪并轰然旋转，环绕东临星急速转动，形成巨大**漩涡**将东临星深深包裹。

## 五、收束

王林冷冷望着这一切，眼中精光一闪，再度一步迈出：「既然你不滚出来，那就让王某去把你拽出——一切阻挡者，陪葬。」

## 六、待解伏笔

- 说出「此事，无碍」的苍老之声身份未明（疑为向家老祖或其同辈）。
- 地底土黄色棺材内伸出干枯右手的存在为何，与人头之海、死气有何关联。
- 向家老祖当年欺骗王林、夺其生机的真正动机仍未揭晓——这正是王林此行要问的「千年一问」。
