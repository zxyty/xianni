# 第636章 封印之处（第二更）

## 一、青丝残识：徐飞才是本体

- 王林捏碎藏有对方一抹极隐蔽神识的青丝，判定**尸阴宗隐匿神识的神通惊人**，若非事先留意徐飞，几乎会被避开。
- 结论：**能以神识寄于发丝的徐飞才是本体，赵依萱则是尸傀**。
- 王林告诫自己日后须多加留意尸阴宗手段。

## 二、由尸傀勾起的旧事（回忆）

- 王林能识破此局，与当年被**周佚**强行塞来的奴仆**孙泰**有关。
- 孙泰有一具小童模样的尸傀，灵动且修为极强，二者关系特殊，**并非单纯操控，更像两个独立个体**。
- **司徒南**当年正是占据了这具小童肉身。王林追忆：「司徒不知现在何处，应该是在某个修真星上，过着他凡人王爷的生活吧」——此刻的他不是杀人煞星，而是想起好友的凡人。
- 孙泰身份：**朱雀星尸阴宗大长老**，被**巨魔族老祖**的神通抛入星空，下落不明。

## 三、遍寻不获：明面裂缝全无周佚气息

1. 此地深渊分支裂缝不下数十条，无任何周佚气息，需逐一寻找。
2. 判断依据：**周佚为剑尊凌天候所封印**，故封印之处必留凌天候气息。
3. 第一轮：神识逐一查看所有裂缝 → 无果。
4. 复核情报：取出**古妖贝罗**所赠水晶，神识融入验证，贝罗所指周佚方位确为此地。
5. 动机推演：贝罗当前要务是**吞噬其余七妖**，无必要在此小事上欺骗；若要害他可直接动手。唯一可疑是**借刀杀人**，但若真如此，说「周佚在潮汐深渊最底部」可能性更大，而此处极为寻常。
6. 第二轮：更细致的神识搜索 → 依然无果。
7. 第三轮：祭出**十亿尊魂幡**，放出上千强大魂魄钻入每条裂缝，王林元神寄于魂魄亲自查看；一炷香后魂魄归返，仍无所获，面色难看。

## 四、以凌天候之心度凌天候之行

- 转念：「若我是凌天候，也不会把人封印在这个明显的裂缝内。」
- 王林调动体内**凌天候剑气**，借其蕴含的**霸道意境**代入推演：
  - 凌天候之意境为**霸道**——以自身霸道对抗天道，一生我行我素。
  - 推演所得：封印一个纠缠许久的剑灵，不会简单封印，而是**要它屈服**——不屈服便封一千年、一万年，再不屈，毁其灵体、炼作法宝也要它屈服。
  - 故不会选择明显裂缝，除非有必须在此的原因。
- 代价：仅借之感悟少许，便汗如豆下、身形一晃、面色苍白，**险些受伤**。

## 五、崩壁掘缝

- 取出**仙剑**与**弯刀**；右手持仙剑旋身横扫，成**剑气漩涡**，喝「破」——漩涡炸开，两侧深渊之壁裂纹弥漫上下百丈。
- 再喝「裂」——壁体碎裂，碎石泥土脱落，**百丈之内深渊生生被震下一寸**。
- 周而复始，半柱香后，在一处「空白」处露出细微缺口，透出一丝**极端霸道**的气息（非周佚气息）。
- 驱仙剑与弯刀削凿，掘出**深埋壁下三丈的隐藏分支裂缝**：缺口高仅半丈，内中漆黑。

## 六、凌天候残念一撞

- 王林神识刚探入，即被一股无比霸道的神念狠狠撞回：身体抛飞撞入对面石壁并深陷其中，口角溢血，**元神几近崩溃**。
- 判断：**若未入问鼎，此一撞便可当场震碎元神**；该神念只属于凌天候，故**周佚必在其中**。

## 七、境界体系披露（重要设定）

- **修道第一步**以**问鼎大圆满**为结束；须度过**阴阳虚实二境**的考验，方踏入**第二步：碎涅三境**。
- **碎涅三境** = 窥涅 → 净涅 → 碎涅，每境各分初期、中期、后期、大圆满四阶段。
- **天运子**曾言自身处于第二步末尾，王林姑且算其为**三境碎涅初期**。
- **凌天候**与天运子是数万年的对手，王林推测其**很可能是二境净涅大圆满**。
- 王林自评：修为微不足道，第一步都未圆满；但在第一步中，**问鼎即等于一方诸侯**；其执着在于自少年踏入修真界起几乎全凭自身努力走到今日。

## 八、入洞前的全副武装

1. 一点眉心，**十万杀戮之气**化**生之烙印**弥漫全身——实为差一道（九万九千九百九十九），最后一道被抽出**融入心神**，使烙印生生不息；除非一击连元神内最后一道也震碎。
2. **魔甲**化黑丝游走体表，魔气外散化作铠甲笼罩全身。
3. 十余个**被飞虫包围的金符**在四周漂动，再添防护。
4. 再取**十亿尊魂幡**，黑幡一卷成黑云裹身，**上亿魂魄**在其内咆哮。
5. 王林眼露果断，迈步直奔那一丈大小的缺口而去。（章末）

## 九、悬念

- 隐藏裂缝深不可测，凌天候封印是否仍在、周佚（剑灵）状态如何、王林能否承受封印本体的霸道之力，留待下章。
