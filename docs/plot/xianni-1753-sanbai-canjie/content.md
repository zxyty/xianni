# 第1753章 三百残界

## 一、洞府核心：黑气大鼎

- 王林身影消失的瞬间，被黑气缭绕的巨鼎黑气卷动如黑龙咆哮，黑色波纹扩散，四周天地扭曲、生出无数重影。
- 鼎正面缓缓浮现一张极大的模糊人脸，占据近一半位置，隐约可辨是王林的面孔。
- **机制**：大鼎是洞府核心所在，凡进入其内者都会在鼎上幻化出各自相貌，**如同神魂的封印**。

## 二、第一花与三百露水

进入大鼎后所见：一片昏暗、一望无际的天地，看似很远却又有「一步可跨越」的错觉。其中只有一物——

- 一朵**黄色大花**：以大地为根，以天为枝叶，盛开弥漫乾坤；只有五片花瓣，无香气；凝视之下会有一瞬「此花不存在」的错觉。
- 花上细密露水，数目**正正好好三百滴**，晶莹而隐有梦幻之意。
- 王林由体内**七彩第三魂**（尚未完全融合）的记忆认出：「这里，想必就是三百残原界了。」

### 三百残原界的来历

| 项 | 内容 |
|---|---|
| 成因 | 七彩仙尊当年创造洞府界，失败了三百次 |
| 缺陷 | 三百界皆不完整，缺少很多必须的物质存在，故未被选用 |
| 成品 | 第三百零一界＝如今的洞府界 |
| 去向 | 七彩仙尊不舍抛弃，将其炼化为守护闭关之地的防护之力，衍变成三百滴露水 |
| 权柄 | 七彩仙尊若未死、坐镇大鼎，神识散入三百界可改变部分界内既定法则 |

**每一滴露水，都是一界。**

### 防护之力的变化（王林的顾忌）

洞府核心本是七彩闭关所在，设计上一旦封锁便自行开启防护、阻止一切人从外踏入。但由于：

1. 七彩仙尊的死亡；
2. 连道非的踏入；
3. 七道宗弟子与仙妃的背叛。

防护之力被破坏不少，也出现了一些变化——这正是王林所忌惮的、与第三魂记忆不符之处。见到三百露水俱在，他松了口气：「看来这第一花，如第三魂记忆一样，这里没有出现变化。」

## 三、王林的计划改动：以三百残界为猎场

- **决定**：既然三百残界尚存，计划略作改动——把这里先当作一次**猎场**。
- **取舍**：七彩道人与战老鬼等人目前无法猎杀；其余之辈配合三百残界则有把握杀死一些。
- **收益逻辑**：杀的越多，最终与其余两魂之战的力量就越大。
- **隐秘杀招**：七彩仙尊在洞府界留有最终杀招，外人绝不知晓——没有记忆的七彩、战老鬼、乃至仙妃与四大战将都不知道，只有第三魂记忆中有。
  - 开启条件：**必须在此地有足够的杀戮**。
  - 历史反事实：当年连道非来得太突然、七彩仙尊重伤闭关，无时间开启此杀招，不得不用**天道吞噬**；否则当年一战结果会不同。

## 四、三百残界的三种分类（据第三魂记忆）

1. **仙兽界**：七彩仙尊自**仙罡大陆**带来的仙兽被放入其中，无数年来或死亡、或变异成强大存在；变化无人知晓，**杀机最重**。
2. **凡人界**：掳来仙罡大陆的一群凡人在此繁衍，作长久观察，试图从繁衍中找出**天道的秘密**。
3. **无生机残界**：无人无兽，连法则都未划分；一旦有敌闯入，七彩仙尊可依敌人不同**临时既定法则**。
   - 第一类：无数万年来从未在内既定法则；
   - 第二类：当年曾定下法则，保存至今、依旧运转。

> 除非如连道非般拥有**仙人不灭体**可硬闯，否则入内者需费尽心思，稍不谨慎便身陨道消。王林因未与第三魂完全融合，对三百残原界只知晓**十之七八**。

## 五、王林试探第一滴露水

- 踏入一滴露水，其内另有乾坤：一片璀璨星空，充满星云，寂静无生灵。
- 规模相当于**当年的昆虚**，并不太大；整个星域只有**九颗修真星**，无人、无物、无生机。
- 判断：「这里应该是第三种残界，就是不知是第一类还是第二类。」
- 逐一掠过九颗修真星，一无所获。
- 时间压力：提前进入的半个时辰，在布置外围禁制时已消耗一部分，所剩不多。
- 神识反复笼罩星域后，察觉一层**极隐晦的无形波纹**；在半个时辰全部消散的刹那，锁定其来自**第五颗修真星**。
- 第五星上有一座**光秃如利剑插入云霄的山峰**，波纹自此山传出；神识细查却极为寻常。
- **试探**：王林传出神念——「我为此界第一个到来者，既定规则，此规则禁制一切仙人血脉。」
  - 结果：天地轰鸣，星域剧烈扭曲似要崩溃，规则将要完全出现的刹那却轰鸣回旋、一切平息。
  - 结论：「这一处残界没有力量凝聚出这样的规则，那么就换一个好了。」

## 六、外界：众修士踏入大鼎

洞府大门彻底打开、风暴消散，所有修士自外踏入：

| 次序 | 人物 | 表现 |
|---|---|---|
| 1 | 七彩道人 | 扫视皱眉，直奔大鼎，下方废墟毫无反应，消失于鼎内 |
| 2 | 战老鬼 | 同样迈步，融入大鼎消失 |
| — | — | 大鼎左右两侧浮现七彩道人与战老鬼的面孔，隐被黑气环绕，狰狞恐怖 |
| 3 | 掌尊 | 将踏过下方大片废墟时神色一变、立刻止步，右手掐诀化为无形隐藏 |
| 4 | 蓝梦道尊 | 双目一凝看着废墟，嘴角微笑，索性迈步而过直至融入大鼎；废墟毫无变化 |

- 隐藏在一旁的掌尊，因蓝梦道尊安然踏过废墟而**皱起眉头**（其对废墟的警惕似落空或另有隐情）。

## 七、待办 / 悬念

- 王林将换一处残界继续尝试既定规则。
- 「足够的杀戮」是开启七彩仙尊最终杀招的前提，猎杀行动即将展开。
- 下方废墟的机制不明：掌尊警惕、蓝梦道尊无视且安然通过。
- 三百残界中的仙兽界变异情况仍是未知杀机。
