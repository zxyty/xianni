# 第1686章 小红！

## 一、炎龙败退与被印决压服

- **实力对比**：炎龙全力施展火焰急退，因清晰感受到王林身上的**火之本源**气息，而自身火之本源明显稀薄，故毫无战意。王林随手凝聚其火焰神通，一捏即碎，热浪滚滚。
- **操控之印**：王林不追击，右手不疾不徐掐出印决——此印为**二代朱雀送予**的操控此炎龙之印。印一出，远遁的炎龙眉心浮现一模一样的印记，深烙骨骼与灵魂，痛得龙目流泪、全身火焰崩溃，现出**万丈龙身**。
- **认输**：炎龙抱怨「你们朱雀都不是好东西……说是放我离开，结果还留下了这个该死的印记」，随即认输不再逃。王林收起印决，踏上其龙头盘膝而坐；炎龙遥望仙龙宗方向落泪，叹「我不该走这条路」。

## 二、王林为何雷霆出手

若在不知晓**洞府界**之前，王林见此龙或也会收服，但不会如此毫不浪费时间。其非同寻常之处：

1. 可**口出人言**，灵智极高，连**幽冥兽**都不如；
2. 自称仙龙，且创出**仙龙宗**，奴役修士为其服务；
3. 体内隐有一股极轻微的**仙人血脉之力**——因王林眉心融合了**仙人不灭体**鲜血，方能看出端倪。

旁观的太古星辰数人神识仍笼罩此片星空；在他们看来，炎龙虽相当于修士**第三步空涅初期**，仍脆弱不堪，王林收服毫无意外。

## 三、逼问与搜魂的克制

- 王林问「仙罡大陆，是你的故乡吧」，炎龙摇头否认；王林右手泛起**搜魂**气息再问，炎龙惊恐地扫了一眼远处一千多仙龙宗修士后，咬牙再度摇头。
- **王林选择不施展搜魂**：此处是太古星辰，四周数个大能神识凝望，一旦出手便予人可乘之机，会影响**三个时辰后的计划**。他索性散去搜神之术，欲先将炎龙收入储物裂缝，待解决**远古仙域**之事后再逼问。

## 四、「给点面子」——副宗主闹剧

- 炎龙哀求：当着门徒的面给它留面子，配合演一场，事后有问必答。王林神色古怪，许久后点头。
- 炎龙飞起做威严状，宣布「网开一面」让王林加入仙龙宗，见王林眉头微皱，慌忙改口封其为**副宗主**；又大吼遣散一千余修士，称要「指点副宗主修炼」。
- 修士们虽满腹疑惑，仍作敬畏之色抱拳退去，化虹而散。人一走，炎龙威严尽失，转为尴尬，改口称王林「主子」，自称「小龙」。

## 五、关键情报：小红与连道非

- **来历**：炎龙承认确实来自**仙罡大陆**；是随「以前的主人」及「一个该死的家伙」一同进来的。那家伙因不满主人更宠信它，谎称**七道宗有宝物**，将其主人骗来。炎龙先称「忠心护主」同行，被王林盯得发毛后改口：实为「被以前的主人骑着来的」。
- **姓名**：炎龙自报小名——**小红**。
- **王林的震动**：脑中轰响，回荡起当年**疯子**的话语：「小红，小红你在哪里」「本王的东西都在小红那里，你去找小红要吧」「小红，快去找我哥，告诉我，我被欺负了」。
- **确认**：王林问「连道非，是你什么人」，炎龙愣住：「你认识我主子？连道非就是我以前的主子啊，可惜他死了。」王林心道「果然如此」。

## 六、收束与静心

- 王林不再追问（再问则难以静心），大袖一甩将炎龙卷入**储物裂缝**。
- 距三年之期最后一天过去仅余三个时辰；王林需心境平和方可发挥全部修为之力，遂盘膝星空、双目闭合平复心浪。
- 太古星辰数人神识笼罩、内心诸多猜测之中，三个时辰全部流走——**最后一刻，王林双眼猛然睁开**。

## 悬念 / 待解

- 「那个该死的家伙」是谁？其以七道宗宝物设局骗连道非入此地，与连道非之死有无因果。
- 炎龙为何在一千多门徒注视下不敢承认来自仙罡大陆。
- 炎龙体内仙人血脉之力的来源。
- 三个时辰之后王林的「计划」与远古仙域之事。
