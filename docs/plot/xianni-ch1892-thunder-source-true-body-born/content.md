# 第1892章 昔梦成真

## 一、局面：天逆珠 vs 道魔宗宗主的意志

- 前情：王林体内雷霆本源在这段日子里持续吸收、愈发庞大；但因**天逆珠子**存在，道魔宗宗主的意志始终无法在王林体内完全凝聚，做不到抹去王林神智。
- 宗主吞下**第一颗雷帝珠**：体内雷霆本源轰然暴增，顺无形通道疯狂被抽撤入王林体内。
- 王林身躯剧颤、长发无风自动、电光环绕，雷威震动其所处的**绿色空间**，无数绿芒化作绿色蝎子无声嘶吼。
- 关键转折：庞大雷霆本源入体、正要凝出宗主意志的瞬间，**天逆珠子蓦然一转，抽丝般将那意志不断吸来化去**——如满溢的水潭在溢出刹那忽失一分，达成平衡后又慢慢减少。
- 宗主在蝎子建筑外雾气中盘膝睁眼，露出难以置信之色：他看不到天逆珠子，感受王林身体一切如常，**找不到自己失去的意志去了哪里**。

## 二、最后一颗雷帝珠与「尽散」

- 蝎子内**祭祀老者**（苍老沙哑、伴咳嗽）皱眉沉吟，大袖一甩，又一道闪电雷霆化作与前一模一样的雷帝珠奔宗主而去。
- 祭祀老者的最后通牒：「最后一颗雷帝珠，此物即便是**雷帝洲**，也只剩下不足三粒，若你还不能成功，则之前一切承诺，全部作废。」
- 宗主青筋鼓起，张口吞珠；随即双手掐诀按于眉心，仰天低吼——
  > 「雷霆本源，尽散」
- 其**体内全部雷霆本源被毫无保留释放**，携其**全部意志**冲入王林体内；其中更有第二颗雷帝珠所化的磅礴雷霆之力推动意志疯狂前冲。

## 三、雷霆本源真身的凝聚过程（分步）

1. **地狱化**：王林体外弧形闪电骤增数十倍，外扩百丈，方圆百丈成为天地雷霆地狱。
2. **九闪出目**：王林头颅不受控抬起，闭着的**右目**内闪电印记连闪九次后冲出。
3. **符文成形**：该闪电在头顶数百丈外化作巨大闪电符号，狂吸四周百丈雷霆之力，外围浮现**人形轮廓**（本源真身雏形）。
4. **毛孔涌电**：王林昏迷之身**十万八千汗毛孔**，每孔至少冲出十道以上闪电，尽数轰入人形轮廓；闪电弥漫整个绿色空间，几乎取代绿色，化为雷霆空间；轰鸣弥漫方圆近百万里，绿魔洲震动。
5. **成骨成肉**：轮廓内先凝出一根根由无数闪电紧密排列的**雷霆骨骼**，继而闪电细丝化经脉、化血肉。
6. **真身立**：最后一道闪电吸收完毕，昏迷王林上空浮现「**另一个王林**」——双目紧闭、内外电光穿梭，仿若从雷霆内诞生。

> **归属倒错**：这是王林梦寐以求的雷霆真身，但其内凝聚的**全部是道魔宗宗主的意志**，故此真身不属于王林，而属于宗主。

## 四、宗主的两难与抉择

- 震撼：宗主**再次对王林预料失败**——他没想到王林对本源的感悟，除**火本源真身**外还有诞生第二具真身的潜力。
- 两难：渴望据有雷霆本源真身 ↔ 一旦如此便无法完成祭司要求。
- 蝎子建筑内传出咳嗽声传入其心神，他即刻果断：
  > 「以曰后**绿魔蝎复活**后承诺的好处相比，这真身尽管珍贵，但也不是不可以放弃」
- 决断：双手抬起眉心一点，闭目，全部心神凝入绿色空间中王林上空的雷霆本源真身内。

## 五、七窍夺源与帝冠、战车

- 真身闭目抬右手，五指向下方王林骤然一按；王林巨震，被昂起的头颅**七窍**（双目、双耳、双鼻孔、口）冲出体内**最后七道本源雷霆**，与真身七窍一一对应冲入。
- 真身睁眼：双眼阴森，缭绕道魔宗宗主气息。
- 身子一晃，**大半个绿魔洲**无数地方天空现惊天雷霆，以快过一切修士、如缩地成寸般的速度从四面八方直奔**中心蝎庙**、涌入绿色空间。
- 凝聚出三件象征：
  - 体外**雷霆铠甲**
  - 头顶**雷帝之冠**（帝冠）
  - 身后**雷霆战车**
- 至此，雷霆本源真身**彻底凝聚完毕**。

## 六、昔梦成真（题眼）

- 王林体内天逆珠子并未隐藏，运转中**保护其元神及一切**；他因心中一丝悸动而苏醒，睁眼即见上空雷霆本源真身。
- 短暂茫然后彻底明白：当年在**大魂门**第一次施展**魂衍道之术**时，他在未来变幻中曾见到令其心惊的一幕——
  > 自己的雷霆本源真身，要以雷霆之力来镇压自己。
- 当年不解：真身乃自身凝聚、属于自己、是身体一部分，怎会如此。眼下画面成真。
- 收束：「大造化，大〇，即将展开」。
