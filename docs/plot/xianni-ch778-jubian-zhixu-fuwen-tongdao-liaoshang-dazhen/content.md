# 仙逆 第778章《剧变之序》（第七卷 名震罗天）

## 一、场外：唐言枫退走，「许木」之名传开

- 千丈内外尚处第一步的修士，瞬间记住了「许木」这个名字，「直至一生，都不会忘记」。
- 唐言枫身边女子对「姓许」神色阴沉，指出：**罗天星域内许姓虽多但大都默默无闻，能出现阳实境界且如此强悍者，惟独东临星的许家**——而东临星现世的传人已多年未再出现。
- 唐言枫判断：「他很强，即便不是东临星传人，也绝对相差不远，此人，我唐家不要轻易招惹。」
- 对死去的两名唐家族人，唐言枫只冷声「死便死了」，随即**连阵法暗洞都放弃**，转身离去；女子与那名刚进入阴虚的青年跟随。青年暗自庆幸自己先前退让的决断正确：「能让少主如此忌惮之人，可不是我能招惹。」
- 其余修士虽知王林已入暗洞，仍视这千丈为死亡之地，无人敢冒险，最终各自散去；「许木」之名随之在各自道友圈中慢慢散开。
- 地面阵法烙印的禁制光芒渐渐暗淡，最终成为**死阵**——这正是李元布阵时的预设：以自然消散后的死阵防止外人进入。

## 二、通道深入：仙力余波与眉心异感

- 暗洞不大，深处有一条通道，漆黑但修士可视。李元在前，王林在后。
- 李元判断：**仙界崩溃后他们绝对是第一批进入者**，证据是墙壁上仍存仙力余波（若进来的人多、通道长久打开，余波不会留存）。
- 李元透露：先前暗洞内他得到**三样有些奇怪的宝贝**，约定稍后取出与王林共同分析。
- 王林神识谨慎散开、不敢放太远（仙人遗留之地，易引禁制发作）。通道无分支，弯曲向下深入，急行半个时辰不见底，李元疑为「重叠碎片」。
- **异感**：越往下行，王林眉心如被手指虚空按住，双目之间传出说不清的胀痛。半柱香后他抓住李元停步询问。
- 李元初称无感；依王林之言散去眉心**心禁**的刹那，立刻面色苍白、双目鼓起充血，急忙重起心禁才平复，骇然道「感觉到了」。

## 三、关键推演：通道即符文，九阵成疗伤

- 王林抬右手食指、以元力在虚空勾勒荧光线条，组成一个下方线条尚有断头的**未完成符号**。
- 李元盘膝回忆所学与古籍，半柱香后称有四个符文与其相似，但因不完整无法判定是哪一个。
- 王林揭示：**这符文就是我们所在的通道**——他一路神识散开勾勒而出；随后顺断头续画完整。
- 李元震惊认出：此为**仙禁**中的一种符文印记，且在仙禁中极为冷僻，**无法单独使用**，须与其他符文组合才能形成禁制阵法；不到通道尽头看到最后一笔，无法算出效用。
- 二人继续下行（王林在前带路，李元掐诀推衍）。又过半个时辰，王林神识察觉尽头。
- 李元推衍完成，给出结论：
  - 该符文组成的禁制**只有一个效用：疗伤**；
  - 类似的符文通道**共有九处**，九个符文印记组成**一个庞大的疗伤大阵**；
  - 「这在雷之仙界内，可以算是绝大的手笔了。」
- 王林顺势点破弦外之音：**阵眼之中有一个人，无数年来始终以此阵疗伤**。李元附和称只有这一个答案可解释一切；王林道出那人身份猜测——**仙人**。

## 四、冲突与钩子：李元起贪念，漩涡睁眼

- 通道尽头是一人多高、散发五彩光芒的旋转漩涡，通向阵眼，却**被人从内部封死**。李元称自己有把握打开。
- 李元目露诡异之芒，游说王林：「你不是想要仙术么，有什么，比一个仙人，更了解仙术呢，说不定这仙人此刻极为虚弱，我们进去后，便可一举擒住。」左手凝聚禁制直接拍出。
- **王林出手压制**：捏碎其打出的禁制，右手元力涌入李元体内，将其打昏；随后抓着李元缓缓后退。
- 退出不到三丈时，漩涡骤停、透出阴森气息，中心浮现出**一个眼球**；一个诡异之声在王林心神中回荡：
  > 「你，想学什么仙术」

## 五、要点与悬念

1. 「许木」在罗天星域正式扬名，并被唐家高层误认/疑为东临星许家传人——为后续身份误判与势力互动埋线。
2. 王林对眉心异感的敏锐（阳实修为与神识远超李元）是识破符文通道的关键。
3. 李元的贪婪与诡异之芒再度显露（其身份本就存疑——王林曾指其为占据李元之身的仆魂）。
4. 阵眼中的存在主动开口发问，本章以「想学什么仙术」收束，为下一章的交易/试炼定调。
