# 第1634章 一个洞府

## 一、远古仙域：界内界外最古之地

- **定位**：远古仙域存在于界内界外之中，比四大仙界久远无数，几乎在**界内初开之时**便已存在；无数万年来只有『远古仙域』这一个称呼。
- **地位**：封尊自这里出来，仙妃自这里走出；一切与远古有关的事，全部从这里展开。是修士心目中**至高无上的圣地**。
- **天象**：大地苍茫清晰，天空昏暗，无数风暴恒古以来在九天横扫、周而复始回旋不休；迷雾风暴中赫然高悬**九个太阳（九阳）**，只露轮廓。
- **地貌**：大地一片安静，耸立**无数雕像**，形如活人被石化，或站立、或跪倒、或仰天怒吼、或神色狰狞，如千军万马般沉寂了无数万年。

## 二、九阳与仙罡大陆的关联

王林见九阳时瞳孔一缩——他此前**在仙罡大陆的一望中曾见天空九阳高挂**。由此他得出呼之欲出的推测：

> 「要么这里就是我之前所看的仙罡大陆的一部分；即便不是如此，这里也一定与仙罡大陆有极深的关联。」

作者借此点出：随着修为提高、知晓越多，掩盖真相的层层面纱正被王林揭开，他就要碰触到有关界内界外、有关这天地一切的**最终隐秘**——「或许很是残酷，或许是一切的终止，亦或者仅仅是另一个开始」。

## 三、击碎第一个太阳，取出九色天劫之雷

1. 王林身影如长虹而起，直奔第一个太阳；立于其旁如一粒灰尘，却散出惊天动地的至强气息，「就连这第一个太阳，也不够资格」与其争辉。
2. 一甩大袖，卷动的雾气齐齐倒卷散开，太阳清晰落入目中。
3. 再一挥，太阳光芒暗淡、震动数次后开始崩溃；数次挥手后太阳不断缩小。
4. 最后一甩，太阳发出惊天之鸣，四分五裂彻底崩溃。

**关键判定**（王林原话意）：

> 「这哪里是什么太阳，这分明就是以神通法术凝练而出之物！这里面蕴含了一股天劫之力，此物就是引动天地之劫的根本缘由。」

太阳崩溃后现出一道**九色雷霆**，被封印其中；因其存在，故**天劫之中第一劫往往大都是天雷**。王林虚空一抓将其擒于手中，雷霆不断扭曲、永不屈服——除非王林强过当年制造它的那个存在。

王林由此推演出一条世界观定律：

> 「这天地万物绝没有平白出现的道理，一切生灵、一切万物之生皆有因果；即便是天劫，也绝非自行出现，而是被某种奇异的力量、亦或者某个强大的存在制造出来。」

## 四、神识入雷，回溯造劫往昔

王林犹豫『到底要不要去印证那个猜测』，最终果断放出磅礴神识探入雷霆，眼前岁月逆转无数万年，看到一段画面：

- **场景**：一片七彩之芒笼罩、无边无际、如梦幻般的世界。
- **人物**：一名**身穿七彩道袍的中年男子**，神色孤傲、双眼炯炯、威压至强，似天地在其脚下、万物皆要臣服；双唇不厚，严肃刻薄、寡恩绝义。
- **重大对应**：此人与王林**储物裂缝内的那个雕像**几乎一模一样，完全就是一个人。
- **与七彩界之人区别**：王林当年在七彩界救清水时也曾遇一个七彩之人，但与此人相比如星光之于皓月，且任何人都不会认为二者是同一人。

**七彩男子自语（造劫之由）**：

> 「本尊这洞府，自成一界，蕴含了天地造化，万物在手，由吾一心而变。尽管比不上森道大尊的森罗界，但却也相差无几。唯独可惜没有天道在内，无法进行岁月衍化，诞生不了众灵，取不出香火。不过这一切今日之后将会改变，**本尊抢到了一个天道**。有了天道，从此之后本尊这洞府便可出现众生、出现岁月、出现修士。既有了众生，那么就必须要有劫——这第一劫，便是雷。」

随后他右手一挥引来雷霆、掐诀凝聚成一道**天劫之雷**，并下令：

> 「从此之后，你便是为老夫看守洞府的天劫之雷，惩罚众生有逆意之修。」

## 五、真相：界内界外只是一个洞府

画面消散、神识归体，王林神色复杂，狂笑指天，串起全部线索：

- **战老鬼曾说『界内是内府』**——早已明朗，只是王林不愿相信。
- 类比**七百万天地的散灵上人**：散灵上人发现了一切隐秘，却险些疯掉；而这里的布局『要比七百万天地的一幕高明了太多太多』。
- **结论**：「原来我王林生存的世界，原来这界内界外，只不过是**仙罡大陆一个大尊的洞府所化**；原来这界内界外的一切众生，都是因此而诞生。」
- **逆修与天劫的因果**：天劫之所以惩罚逆修，是因为**逆修自身存在一股逆天之意**，他们最终大都会去明悟『这天地到底是什么』，故天劫要惩罚这群人。

## 六、本章意义

- 王林两千多年修道、无数次生死，今日踏入远古仙域这一圣地。
- 「洞府 = 界内界外」这一设定被正面坐实，天劫由『自然规律』降格为『看门人造物』。
- 储物裂缝内雕像的身份指向该洞府主人（七彩道袍大尊），成为后续追索的核心线索。
- 章末为作者杂谈（酷6访谈、又胖几斤），非正文内容。
