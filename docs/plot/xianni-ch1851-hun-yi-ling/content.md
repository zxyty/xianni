# 第1851章 魂一令

## 一、丹海崩灭的余波
- 半粒仙丹在丹海正中炸开，毁灭之力横扫：丹海内数万修士死亡众多。
- **云空分身**因距仙丹最近，成为第一个直接瓦解者——「无论其拥有多强的剑意，在这半粒仙丹的炸开中，也脆弱的如同一张宣纸」。
- 丹海完完全全消失，化作虚无。
- 绿魔洲修士死亡上万后，残余者本无法幸免，天空忽现一巨大虚影（看不清样貌），大袖一卷将全部残存绿魔洲修士笼罩入袖，急退避开冲击而消失；但其消失一瞬仍已受创。
- 天牛洲靠近丹海处大地层层崩溃，大片陆地被掀起横扫内部，形成不知持续多久的遮天尘暴；绿魔洲陆地同样碎开卷上天空，化作阴沉土雾如乌云弥漫。
- 幸而炸点在丹海正中：若临近天牛洲位置崩溃，天牛洲的损毁将极为严重。由此可见此仙丹之不凡与来历之秘。
- 三天后毁灭之力衰弱大半，两洲边缘的尘暴仍在。

## 二、王林：道古身躯只伤不灭
- 王林（白发青年）盘坐于天牛洲靠丹海一片崩塌山峦的山峰上，面色苍白，身前地面有三日间喷出的干枯暗红鲜血。
- 他以**缩地成寸**离开，仍被毁灭余波扫中一下：一瞬间似听到骨头碎裂、血肉崩溃、元神毁灭之声。
- 关键点：**寻常修士即便不死也需另行夺舍，而王林肉身是道古身躯，故只伤不灭。**
- 第三日黄昏首次睁眼，此地尘雾苦涩、日月难辨，天地间有如冤魂嘶吼的呼啸呜咽。

## 三、王林的盘点与算计
1. **值了**：云空临死前放言「绝不会放过我」，表露其很可能是分身而来；但这具分身彻底死亡，分身一死本尊必受影响，且影响估计不小。
2. **罗盘**：右手翻出一古朴罗盘，其上原有的丹海地图已消失，取而代之的是王林当下所处天牛洲大地，其上无任何光点。王林评「这套禁制倒也玄妙」，吞噬融合后禁制本源必增，但眼下仍有大用，不必急于融合。
3. **护身禁制**：疗伤前已把收走的禁制在此扩散笼罩四周，逆转之下范围缩小而威力更强，**只能出、不能进**——这是他敢在此地疗伤的凭仗。
4. **玉简献功**：取出一枚平凡玉简，内录第二次进入丹海、一路杀人抢罗盘、毁三杆大旗、出手斩仙丹使其提前崩溃、云空死亡、毁灭冲击八方的全过程（其离开后之事未录）。
   - 王林深知门派中「功劳是获得法宝、丹药、功法的重点」，而口说必遭猜疑，玉简影射真伪一看便知。
   - 略作沉吟，**抹去自己获得罗盘的一幕**，只留斩仙丹一系列事情。
   - 目的：凭此向**青牛老祖**索要**大魂门第九层的多重幻术**。
5. 自评伤势已复七八成，**水本源大成**，需赶回大魂门；推测自己所发玉简大魂门应尚未收到，但三日前天牛洲大地的震动必已引起注意。

## 四、归途与「魂一令」
- 撤销禁制后化长虹直奔天牛洲深处，飞出万丈即以缩地成寸瞬移至远离丹海的内陆。
- 大半月后已距大魂门不算太远（纯飞行则需数月）；内陆山峦翠绿，全然未受丹海冲击波及——足见天牛洲之大。
- 途中坐于**蚊兽**背上打坐疗伤，伤势恢复到可忽略不计。
- 忽见数道幽光中的**黑色纸鹤**分向不同方向疾驰，速度甚至快过王林；王林以**定身术**定住其中一只，卷来握于手中。
- 神识融入后听到威严之声：
  > 「绿魔洲入侵，毁丹海，炸开我天牛洲壁障，不日大军来临。大魂门、归一宗，发布**魂一令**，召集所有宗门，速速封山，门内一切可战修士，去往万古岁月前开辟出的**天牛七穴**所在，遇近速临。」
- 王林松手放纸鹤离去，望天沉思良久，皱眉压下脑中滋生的奇异念头，定气凝神继续疾驰。

## 五、绿魔洲大军压境
- 绿魔洲沉默三日后未改入侵计划：三大宗门联合，长老带队，凝聚**七万修士大军**，走向已成虚无的丹海、走向门户大开、壁障已失的天牛洲。
- 三大宗门中修为达空劫者数十人，化作几十道长虹居于队伍最前，是本次战局的第一批杀戮者，亦是一洲中作用极大的势力。
- 王林归途第二十日，这数十名**空劫先遣队**已呼啸抵达丹海虚无，任务是「不论一切手段，消耗天牛洲的第三步修士」——杀得越多，胜算越大。
- 其身后约一个月路程处，七万大军化七万道长虹连接天地而来。

## 六、云空本尊登场
- 七万大军后方，一道恐怖剑影裹挟滔天剑意缓缓跟随：一把**金色古剑**，剑上盘膝坐着青衫青年，长发披肩、相貌近乎妖异的英俊，神色平静而面容苍白。
- 其细长双目望向天牛洲方向，露出冷酷寒光，言：「毁我分身，让我修为跌落至**空劫初期**，此仇，我们慢慢去算。」
- 金色古剑气息极为尊高，剑后隐隐幻化出一个高大无比、透出沧桑的**皇袍金甲身影**——此剑不凡。

## 七、后续看点

- 罗盘禁制的融合时机与「禁制本源」增长。
- 天牛七穴的来历（万古岁月前开辟）与两洲决战。
- 卷走绿魔洲残存修士的神秘巨大虚影身份未明。
