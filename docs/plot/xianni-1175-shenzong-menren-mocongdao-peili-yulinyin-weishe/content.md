# 第1175章 神宗门人

> 所属：《仙逆》第九卷 云海之巅（章节区间 01091-01094 之3）
> 归属提醒：本章「吕子浩」「吕道友」均为**王林**自第1063章起沿用的化名（归元宗故人之名，由吕烟菲奉上）；此处言行一律归王林。

## 一、魔丛道赔礼

- 碎涅中期中年男子自报「魔丛道商琦」，面色苍白、神色苦涩地向王林抱拳赔礼。
- 商琦声明：两天前已将**吴青**驱逐出魔丛道，其一切言行与魔丛道无关，「招惹神宗阁下，是他自身之祸，死便死了」。
- 王林全程冷眼不语——他判断这种冷漠最符合「神宗门人」的身份：傲视一个区区六阶星域宗派。
- 王林另有私心：他一直想知道**与本尊合体后能否与碎涅中期一战**。
- 赔礼层层加码：
  1. 七瓶共 **46 粒七阶离魂丹**；
  2. 一瓶 **9 粒八阶离魂丹**；
  3. **两粒十阶蜡丸丹药**（商琦自称已是极限）；
  4. 王林点出「吴青花费数万仙玉刁难我、争抢一宝」，商琦遂再取出一个**储物袋**。
- 王林看都不看内容便大袖卷走全部，点头离去，化长虹奔蓬莱东部坊市。
- 商琦事后暗恨吴青不听劝阻、连累魔丛道。

## 二、役灵印与神宗名头

- 王林之所以能压住场面，源于**曾任朱雀圣宗圣尊**的威严：不需刻意，回想旧日情景便自然流露；此等威严非寻常修士（哪怕碎涅）可有，唯极强宗派之主才具备。
- **役灵印**是神宗第一神通，掌印在云海星域极好辨认；见其威力后，怀疑者也不再怀疑。
- **李倩梅**在蓬莱东部一处山峰顶部暗中评估：
  - 神宗门人已很多年没走出**九阶星域**；
  - 能施展役灵印者属神宗**极为核心的弟子**，不该轻易外出；
  - 王林先前那「第一掌」有些诡异——霸道操控天地元力而来，**隐隐露出奴役之蕴**，来路不明。
- 效果：王林展露出可轻松杀死碎涅初期修士的修为，**五阶星域内已无人敢招惹**；连**宝玉宗**都不敢追究他毁去半个坊市之责。返程时修士纷纷让路、面露敬畏，六阶宗派长老出面示意，苍松子亦掩饰震撼欲攀谈。

## 三、朱雀之羽入左眼

- 清点战利品（商琦赠礼 + 吴青储物空间）后，王林取出**赤色朱雀羽毛**。
- 羽毛在手，**左眼火光弥漫**，与羽内火元力相互辉映。
- 王林感叹：「若是能朱雀**第三次觉醒**，定可让我实力再增——可惜只有一个羽毛，还有些不够。」
- 羽毛化作**朱雀形火焰**环绕其身，最终没入左眼；全身散出火海却诡异地虚空燃烧，未损房中任何物品。

## 四、访客与线索

### 杜德（朱雀之羽原主）
- 黑衣枯瘦老者，碎涅初期，绝口不谈旧怨，自报姓名 **杜德**，**无宗无派的六阶星域散修**，性喜静故不入宗派，此番受老友相邀来蓬莱，大型拍卖后即离去，并邀王林日后到其洞府做客。
- 应王林之问，透露朱雀之羽来历：得自**六阶星域一处蛮荒大陆**，外人并不知晓，杜某偶然发现；其内**凶兽大都擅长火焰神通**，危险，故未深入。
- 刻录玉简相赠，并告诫「切记莫要深入，据观察那里应该有**十一阶凶兽**」。

### 其他访客
- 余下数日，六阶宗派、苍松子聚会中的老怪、**道法门**修士络绎来访，皆携礼恭敬。
- 众人心态：身份无从验证（唯神宗之人可辨真伪）——假的最多损失些礼物，真的则结交价值无量。

## 五、星图搜集

- 王林隐隐放出**要买星图玉简**之意，坊市立刻有人暗中收购，两天内整个坊市的星图几乎被买空。
- 这些星图经仔细核查验证后被送到**苍松子**手中；苍松子踌躇后亲赴王林客栈，以一**装着众多星图的储物袋**相赠，并提醒「星图虚假太多，要仔细辨认」。

## 六、苍松子的密约（本章关键交易）

- 苍松子递上玉简：知晓一处**隐秘之地**，或有王林感兴趣之物，请王林助其进入。
- 苍松子原开价：事成赠 **一万元晶**（他注意到王林在大量换取元晶）。
- 王林神识扫过玉简后开价：**两万元晶，一万先付**。苍松子应允，约定**明日拍卖结束后即送元晶、随即同往**。
- 苍松子出门后收起笑容冷哼：「神宗门人岂能缺少元晶？此人身份极为可疑……若他听话也就罢了，只要我能进入那里，修为定可攀升。」——他为此事**已准备近千年**。

## 七、待续悬念

- 王林打算借神宗名头「开始搜刮」。
- 明日大型拍卖 → 拍卖后与苍松子同赴隐秘之地（双方各怀心思）。
- 蛮荒大陆（朱雀羽产地）为后续朱雀第三次觉醒的潜在目标。
- 李倩梅已对「第一掌」的奴役之蕴起疑，身份存在被追查风险。
