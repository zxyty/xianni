# 仙逆 第2002章《路》

## 一、场景：海上行舟
- 苍茫大海之上，日夜交替、海啸呜咽，海水渐不再冰冷、潮气渐生、浪涛翻滚，似海下栖息强大海兽欲以海之蓝取代天之青。
- 万丈海龙于海面呼啸游走，身形极灵活，速度似比飞行更快；其头顶盘膝坐着白衣的王林。
- 王林未展开缩地成寸以最快速度赶往古族三十六郡，而是任海龙前行，自己盘膝运转体内修为调息。

## 二、王林的心事与前路盘算
### 1. 古族之行的安全判断
- 「这一次去古族，应该不会有生死危机，毕竟玄罗师尊在那里。」

### 2. 对师尊的承诺
- 在古族要静下来默默修行，完成对玄罗师尊的承诺：**守护道古一脉**，**守护师尊的转世**。
- 自我认定：「我毕竟，是属于古族之修。」

### 3. 仙族之憾
- 离开仙族前曾展开神识寻找，仍未找到 **清水（清水仙君）**、**司徒（司徒南）**、**李倩梅** 三人。
- 自我宽解：等再次来到仙族之时，或许可以找到。

### 4. 目的地选择
- 不去 **始古一脉**、不去 **极古一脉**，而是直奔 **道古皇城**。
- 心中悬念：道古皇城与仙族祖城相比如何。

### 5. 长远目标：大天尊与婉儿之魂
- 修为尚不够，要在古族闭关修行，争取早日成为 **大天尊**。
- 待完成与师尊的约定后，去寻找 **李慕婉** 的那一丝魂；只有让其魂完整，才能设法令她苏醒。想起李慕婉时眼中露出哀伤。

## 三、血剑：破封印与归属
- 王林右手虚空一抓撕开裂缝——此为其**储物空间**。当年他无法不损地打开，如今轻易做到：洞府界与仙罡大陆之间的撕裂之力已能被他彻底抵消，不再损灭储物空间。
- 取出当年在**洞府界为其扬名的血剑**，血光一闪、悬浮身前，阳光下弥漫冰冷煞气；王林抚摸时煞气如欢快般环绕其指缝。
- **归属**：
  - 「此物，属于道古一族。」
  - 「它也属于烨寞。」王林在最后的**烨寞头颅传承**时曾答应烨寞善待其后人 → **本次道古之行要找到烨寞的后人**。
- **破封**：以今日修为可轻松发挥血剑全部之力。一抖之下砰砰巨响，剑身似生无数裂缝、如蜕皮般褪下一层——王林当年只是悟懂此剑，如今一眼看出其上尚有一层淡淡封印，挥手破开。
- **异象**：破封后血光色泽更娇艳，煞气向八方轰轰扩散、笼罩方圆千里海面，化作煞气风暴；风暴中隐现一个**巨大虚影**，一看便是古族——全身披铠甲，右手持一把缭绕煞气的细长血剑，似欲斩开天幕。收剑后虚影散去。

## 四、修为进境盘点
- **修行路径特殊**：王林所修之路与旁人完全不同，他需要的是**本源**，本源的出现即可让修为增加。
- **本次提升**：吸收**仙极剑碎片**后**金本源大成、五行归一**，修为由 **空劫中期 → 空劫后期**。
- **禁宫之战的解释**：空劫后期 + **仙祖修为的部分传承**，才使其在禁宫内爆发全部之力后，身后出现**大天尊之阳的轮廓**。
- **现状清单**：
  - 杀戮雷霆真身：五道本源饱和。
  - 五行本源真身：已完整。
  - 虚之本源：一生仅感悟出**三个**。
- **下一步**：若能再感悟出**另外两个虚之本源**，则修为可达 **空劫圆满**；但虚本源的感悟极难。

## 五、后续看点（本章埋线）
1. 道古皇城之行与玄罗师尊转世的守护。
2. 寻找烨寞的后人（对烨寞的承诺）。
3. 再入仙族寻清水仙君、司徒南、李倩梅。
4. 感悟另外两个虚之本源以冲击空劫圆满，进而成大天尊。
5. 集齐李慕婉的残魂使其苏醒。

## 场景

王林骑乘海龙横渡大海，向古族（吉族）而去；蚊兽被放出，化作天空一黑点欢快嘶鸣，一路跟随。海面波涛渐剧，其中存在一股「似仙罡法则之力」——这股力量正是阻止仙古穿梭的关键，但与仙罡虚无内的压力相比相差太多，王林可不予理会，反以气息笼罩海龙加速前行。

## 核心：王林对未来修行之路的推衍

### 1. 否定「唯虚本源」路线

王林皱眉判断：若只能依靠虚本源的感悟来提高修为，日后进境将极难，「怕是需要很多岁月后方可再次提高」，不知何时才能拥有再次回到仙族之力。他自认修行与旁人不同，遂决意另寻他途。

数日思索后定案：**把虚本源作为长久感悟之路，修行重点转向五行真身与杀戮雷霆之体**。

### 2. 五行真身（金、木待补）

- 现状：水、火、土三大本源已凝聚出真身，尚缺**金**与**木**。
- 推衍结论：若金、木本源亦凝成真身，五行真身彻底名副其实，**约有五成可能**让修为避开虚本源感悟而再次攀升，成为**空劫圆满**。
- 代价与补偿：因虚本源不完整，战力会削弱不少；但一旦虚本源最终补全，可形成一次**大的战力爆发**。

### 3. 杀戮雷霆之体（五本源）

- 已凝真身：**雷霆本源**。
- 仅为大成：**杀戮、太初、默灭、禁制**四本源。
- 若四者亦全部凝出真身，则杀戮雷霆之体完美，**修为应可超越空劫**。
- 前提：此路可行与否，需待金、木真身出现后方能确知。

### 4. 大天尊之阳与仙祖传承

- 大天尊之阳的轮廓之所以出现，与王林所传承的**仙祖部分修为**关联极深。
- 仙祖传承未使其修为增加，却令其全力爆发后凝聚出此阳，**战力大增**，弥补了**天牛魂铠碎开**后的落差。
- 战力自评（本片段当时）：**当为大天尊之下第一人**；大天尊在不燃烧本阳之力的情况下，他可一战。
- 前瞻：五行真身全凝 + 修为提高 → 可与**燃烧本阳之力的大天尊**交手；杀戮雷霆之体全凝 → 大天尊中能胜他者不多。

### 5. 第四、第五道虚本源

据其在**东临宗**的明悟：**轮回为第四道虚本源**；此本源大成后，「从无数梦障内寻找真正的自己」，便可使虚本源出现**第五道**。到那时，「大天尊，不是我的对手」。

### 6. 对天尊/跃天尊层次的判断

天尊也好、跃天尊也罢，只是**空劫与大天尊之间的一个过渡**，「可以有，也可以没有」。

### 7. 底牌与谜团

- **仙罡虚无内的分身**：正在成长，非到不得已不能动用。
- **仙祖头颅**：一路上始终研究。隐隐明白——当能将仙祖头颅完全融入自身的大天尊之阳轮廓时，模糊轮廓将变得凝实；一旦凝实，即可凭此阳成为**真正的仙罡第十大天尊**。
- **两件熟悉之物**：储物空间内另有 ① 一丝白发、② 一个拳头大小、充满死气的头颅。两样都给王林非常熟悉的感觉，但他始终琢磨不透这熟悉的来源（伏笔未解）。

## 结局：初临古族

数月后王林睁眼，望见远处海面尽头一片**黑色大地**——古族之地透出**苍凉与莽莽**，与仙族的仙灵之气弥漫全然不同。新卷「初临古族」由此展开。
