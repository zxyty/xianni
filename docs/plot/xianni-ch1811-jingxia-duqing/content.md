# 第1811章 惊吓杜青！（第一更）

## 一、开局：杜青择机出手

- 杜青判断此处地火与寻常不同，王林吞噬不易，正是出手杀他的最好时机，遂身形一晃直奔火焰而去。
- 杜青身上回旋起「无限接近空劫」的修为气息，尤其在其变成木头人的一刹那，这种气息被火海中的王林清晰感知。
- 王林神色如常——他早知杜青一路追击，被追上在意料之中，甚至没有理会来临的杜青。

## 二、锁龙、驭雀、吞噬地火子脉

1. 王林脚踏朱雀、身周环绕十六条火龙，直奔下方冲来的地火子脉之魂所化巨大火龙。
2. 双方刹那相撞，十六条火龙如铁链般缠绕锁住地火子脉龙魂，龙魂挣扎咆哮。
3. 朱雀嘶鸣冲出，与龙魂庞大身躯重叠，展开疯狂的融合与吞噬。
4. 王林白发飘动立于龙角之间，左手抬起操控十六条火龙铁链，如同亲手抓住龙魂——「如同火中的帝王」，龙魂似要屈服为其坐骑。

## 三、对撞：借杜青之力反创龙魂

- 杜青临近之际，王林牵动铁链令龙魂仰天咆哮，火焰之力顺十六条铁链爆发融入其身，朱雀嘶鸣传导磅礴火力。
- 王林右手虚空一拍：四周火海急速收缩凝聚成百丈大小、指纹清晰的火焰手印，焚烧一切生命痕迹推向杜青。
  - 此拍凝聚了**暴增数倍的火本源**，强度堪比王林在洞府界所有本源合并全力爆发；**一道本源足抵之前七道**（此为王林一路振奋之事）。
- 杜青掐诀，四周天空扭曲化作漩涡，一条巨大木头手臂自漩涡伸出迎击。
- 结果：手印崩溃，木臂被崩溃手印所化火海环绕燃烧；杜青闷哼退三步。
- 王林纹丝未动——他把来自杜青的全部力量尽数推入身下火龙体内，**借杜青之力重创至今无法吞噬的龙魂**。龙魂大范围崩溃、皮开肉绽，每崩一处，体内朱雀虚影便清晰一分。

## 四、相互试探：双方的修为判断

| 视角 | 判断 |
| --- | --- |
| 王林看杜青 | 绝未达空劫初期，尚在**玄劫**；一击威力比**掌尊**略强，但无法与**七彩**、**战老鬼**相比 |
| 杜青看王林 | 气息上最多**空灵巅峰**、未达空玄；但如此修为绝不可能接下自己神通、更不可能吞噬地火，判定其**必定隐藏了修为**（否则在苍龙宗不可能逃走） |

- 杜青为人谨慎，一路追来所遇令其已生犹豫，一击退后便目光闪烁，不再轻举妄动。

## 五、对话：毁山门之争

- 杜青：「你是何人，为何要毁我苍龙宗山门？此事若不给杜某一个交代，今日你便留下吧。」
- 王林：「你苍龙宗弟子欲把王林炼制成傀儡，王某只是毁你宗山门，没杀一人已经是留下余地。」
- 杜青冷笑：「杀了我苍龙宗数千弟子，居然还说没杀一人。」（双方说法不一，冲突焦点在苍龙宗山门被毁与弟子死伤）
- 王林索性不再开口，继续操控火本源吞噬龙魂。
- 龙魂凄厉焦急咆哮时，杜青全身火焰不受控地轰然而起，地火的呼唤令其体内火本源躁动——再不出手恐生排斥，遂再度出手。

## 六、三大神通连施——惊吓杜青

1. **役灵印**：王林右手一指天空，云层滚滚间巨掌凭空出现。杜青面色大变：「世界宗大手印，役灵印——你是魂云洲世界宗之人？」
2. **七彩术（七彩长枪）**：王林心神一动、再指天空，七彩光芒笼罩四周并收缩凝成一把七彩长枪。杜青瞳孔收缩、连退数步：「东临宗七彩术……你到底是世界宗之人还是东临宗弟子？」
3. **焚界古伞**：王林右手握拳，掌开之间百万禁制呼啸冲天，化作一把撑开的巨大古伞。杜青全身一震、退后数步：「仙罡七十二洲，仙皇钦点，最强三道宗松云道不传道术——焚界古伞！」

- 杜青面色苍白、头皮发麻，认定这种种神通**看起来极为正宗，绝非偷学可会**，看向王林的目光已蕴含极深忌惮，最终失声追问：「你到底是谁？」

## 七、要点提炼

- 王林此战的核心战术是「以敌之力破敌之敌」：把杜青的攻击力转嫁给尚未吞下的地火子脉龙魂。
- 火本源的质变（一道抵七道）是本章明确点出的实力增长节点。
- 王林身兼世界宗、东临宗、松云道三家正宗神通，成为其身份最大的迷雾，也是震慑杜青的关键。
- 悬念：杜青因摸不透王林虚实而停手忌惮，冲突暂缓于「你到底是谁」的追问。
