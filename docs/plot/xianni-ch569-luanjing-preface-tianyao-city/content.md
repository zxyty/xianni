# 仙逆 第569章 乱京之篇，序

## 一、军道对撞：莫厉海 vs 石萧

王林随莫厉海一行赴京，军道之上与迎面十多骑相撞，两队皆不减速。

- **石萧**：青色铠甲、紫发飘动、面孔妖异俊美，右脸一道翻起疤痕破坏整体相貌，俊美转为邪凶之气。外号「六指妖剑」，神通为**六指剑诀**。
- **莫厉海**：马上右手握拳直轰，拳如风咆哮、似虚无崩溃，拳未至已有砰砰之声、拳意破空——此即其神通第一式**十崩拳意**。
- **石萧**应对：右手抬起，食指、中指依次向前点，转眼五指点完，随后五指并拢成锥再点。
- **结果**：一道波纹在二人间扩散三丈即消，未损及任何建筑（双方皆刻意将波及压至最低）。石萧坐骑悲鸣、四腿碎裂化作血肉，石萧借势退后三步，步步震地；莫厉海身震退数步但**坐骑毫发未损**，高下立判。
- **关键**：王林目光一闪，右手虚空向莫厉海一点，巧妙替其卸去不少对方之力。莫厉海笑称「六指妖剑不过如此」。

## 二、同门重逢：王林与孙涛

石萧身边消瘦苍白、目光如炬之人，正是王林的**同系师兄孙涛**（第111章之外的旧识线），主动向石萧点破王林姓名与同门关系。

**双方的相互观察：**

| 人物 | 观察到的对方 |
|---|---|
| 王林 → 孙涛 | 体内有极重之伤，波及元神，虽被强行压制，修为已由**问鼎中期跌落至婴变圆满** |
| 孙涛 → 王林 | 修为从**婴变中期连跃两阶至婴变圆满**，内心震惊 |

- 孙涛示警：「在这天妖城内，你要小心**大罗剑宗**之人，我的伤势，便是他们所赐」，语带隐怒（怒指大罗剑宗，非王林）。
- 王林沉默后一拍储物袋，取出一瓶丹药抛给孙涛，不发一言骑马前行。此丹对孙涛无大用，**主要目的是传达善意**。
- 王林内心判断：孙涛问鼎中期被伤成这样，大罗剑宗十多人已进入妖灵之地，除非多人联手，单独一人不可能造成此等伤势；同门虽有磨合，但面对大罗剑宗**不能内杠**。

## 三、石萧与孙涛的密议

王林一行离开后：

- 孙涛评莫厉海：「若是我没受伤前，可杀此人。」
- 石萧提醒：莫厉海有**神通三式**——第一式十崩拳意，第二式**妖海百浪**，第三式**乃妖帝亲传，威力极大**。并称若孙涛未伤，此番妖将之争「我有十足把握」。
- 孙涛提出：若有足够材料，可炼制一炉**天元丹**，短时间内恢复到**问鼎初期**。石萧已派人搜集材料。
- 石萧问及王林，孙涛神色复杂、轻叹：「强，很强。即便此人修为不是婴变圆满，哪怕只是婴变中期，也不要轻易招惹。」——石萧与孙涛相识已久，第一次听孙涛以这种方式评价一个人。

## 四、莫府四日：修炼与参悟

- 一炷香后一行人停于一处府邸（莫府），庭院具备、假山幽水、颇为典雅；王林居**南阁**，穿过假山即是。莫厉海安排两名军士照料，随后赴**燕京面见妖帝述职**，约定归来后「以酒迎风」。
- **王林的京都目的**：一是与莫厉海之约；二是**妖将之位**——此地是整个天妖郡都城，高手如云，唯有脱颖而出方能受妖帝侧目，谋取妖将之位便容易许多。
- 黄昏莫厉海归来，眼中隐有喜色，与王林把酒论神通，将天妖郡内几个与他实力相仿的妖将神通一一告知。
- 四日间王林几乎全部沉浸修炼：**吐纳妖力转化为仙力，固本培元**；余暇在院中假山间沉思**杀戮仙诀**——经历古妖城杀戮后理解更为精深（此前在炼魂部落山谷的三个月亦如此度过）。他不问妖将之战日期，笃定「需要出手时莫厉海自会说」。
- 两名军士暗自留意王林的从容，渐生佩服，认为其日后必成妖将之一。
- 莫厉海连日早出晚归，拜访各妖帅与副帅、与交好妖将交换信息，感到整个天妖城风云际会、笼罩沉闷压抑，**这压抑将在妖将之战一刻爆发**。
- **章末**：四天后王林不再修炼，盘膝坐于院中，双手掐诀迅速变化，每一变化皆蕴含杀戮仙诀的烙印。

## 五、伏线与看点

1. **妖将之争**格局初显：莫厉海（神通三式，第三式妖帝亲传）vs 石萧（六指剑诀）+ 孙涛（若服天元丹可回问鼎初期）。
2. **大罗剑宗**成为王林在天妖城的明确外部威胁，且已与同门孙涛结下血仇。
3. 王林与孙涛的同门关系由旧日磨合转为**对外一致的默契**（赠丹为契）。
4. 王林修为已达婴变圆满，且以妖力转仙力之法在妖界稳步固本。
5. 杀戮仙诀的参悟进入掐诀外化阶段，暗示妖将之战中将有出手。

# 第570章 琴音

## 一、七日闭关：推衍杀戮仙诀受阻

### 修炼外泄伤及军士
- 王林在莫府院中一坐又是七天。
- 负责其起居的两名军士初时尚安定观望，随其修炼深入，一股杀戮之气在二人心中疯狂滋生：心神剧震、双目通红、杀机浓浓，神智已然消散。
- 杀戮之气浓郁到极限、二人欲爆发之际，王林睁开双目，目中一片清明；二人接触其目光如冷水灌顶般立刻清醒。
- 代价：二人体内**妖力消失大半**，惊恐远退，此后再不敢观王林修炼。

### 王林的困惑与推衍
- 疑问：“杀戮仙诀，取杀戮、化生机融为烙印。所杀生灵数量不少，为何杀戮之气却是不多？”
- 方法：把每次成功炼化杀戮之气的经历在脑中无限放慢，寻找共同契机。
- 结论：**几乎没有任何相同之处**，好似都是偶然获得，并无必然性。
  - 唯一蹊跷：杀司马炎时含怒出手，居然炼化出一道杀戮之气。
  - 但被自我否定：此前也有心绪无波动时成功炼化；另有几道是从妖兵中炼化，具体来自哪个妖兵无法知晓。
- 所想出的每一个原因“都只是唯一，没有共通”。

### 战略定位
- 杀戮仙诀是此行进入**妖灵之地的重点之一**。
- 当年修习目的：**抵御拓森**——拓森之强，唯有拥有大量生机烙印才可抵抗。
- 现状：已有**血魂丹**，与杀戮仙诀配合“保命有余”，但血魂丹有限，重点仍在杀戮仙诀。
- 进境：修炼数年，炼化出第一道杀戮之气即代表**此术小成**，若要大威“实在太难”。
- 存量：右手指缝内五道灰气急速旋转 → **现存五道**；算上**姚惜雪身上的那一道**，共**六道**。
- 决断：“我需要大量的尝试，大量的推衍，方可有机会领悟这杀戮仙诀的奥秘”——眼中寒芒一闪，杀机涌现。

## 二、出府游洪城

- 王林以神识扫过院外，传念召来两名军士；二人入院三丈外恭敬称“参见王将”。
- 命二人带路出府，拒备战马，绕假山出院。
- **莫府位于洪城东角**，较为安静；穿过东角后抵达洪城中心街道，此处临河道，行人众多、商铺林立、鼎沸热闹。
- 妖灵之地风俗：衣着较为开放，女子衣着鲜艳、露出大半肌肤。
- 王林体内仙力不知不觉隐匿，如凡人般踱步；时而在店铺外停下，滞留皆很短，“好似一个过客”。
- 观感：一身白衣、相貌非英俊但气质出尘脱俗，被行人视作手无缚鸡之力的书生，身后两名军士被视作护卫。
- 心境：身上气息与此地截然不同，无法真正融入；四周成对男女谈笑，愈显其身影孤单没落——“四周的喧闹，好似另一个世界”。

## 三、河畔琴音与婉儿之忆

### 琴音出处
- 天色渐晚，王林正要转身离去，耳边传来琴声——很淡，蕴含一丝清淡的悲伤，奇异地契合其心绪，遂停下脚步。
- 循声而至街道旁的清淡长河：**此河环绕洪城，是天妖城的内河之一**，河上有画舫数个，琴音出自其一。
- 画舫上一女子背对弹琴，背影透出淡淡悲伤与孤独；其身前不远数个年轻人欢笑对饮，笑声与琴音格格不入。

### 触动的记忆
- 琴音让王林寻到熟悉感：回到**朱雀星上那个安宁的山谷**——他与**李慕婉**的家，那段平淡日子里婉儿的琴音始终相伴。
- 婉儿琴音中同样有淡淡悲伤，当时王林听得出却不很懂，“太过虚无，太过飘渺”。
- **感情的迟来**：李慕婉在世时，王林对她的感觉“始终停留在一份数百年等待的感动与责任”，并非情；婉儿离去后，余生却一次次不知不觉浮现与她的一幕幕，每念及此心便很痛。
- 幻觉般的感受：明知是假，仍似见婉儿从虚无中一步步走来、依在怀里，如同当年山谷夕阳中同看日落、等待日出。
- 主题句：“总是在失去后，才会想再拥有；总是在离别中，才会想再回头。”
- 妖灵之地的星光映在眼中，琴音渐远，心绪凝成二字——**寂寞**，久久不散。

### 承诺
- 王林抬起右手**摸着眉心**，好似触摸到**天逆珠内的李慕婉**，喃喃道：
  > “婉儿，我们会再相聚，这是我对你的一个承诺。”

### 盲女琴师
- 画舫远去、女子背影将消之际，她似有所察，轻轻转身看向远处河道旁。
- 在她眼中那里“一般黑暗，没有半点光亮”，但黑暗中她好似看到一个孤独慢慢远去的背影。
- 她轻叹，玉手再拨琴弦，一曲悲伤琴音回荡两岸。
- **关键设定**：河道两旁画舫灯火通明，落在她眼中却始终是一片黑色，**无论白天还是黑夜**——此女为盲。
- 形象：坐在船头，双眼无半点光明，人如莲花，身在淤泥半点不染，独自绽放；而这绽放无人可懂、无人在意。
- 收束句：“琴音始终在回荡，可认真听闻者，却是没有。即便真有，她，能看么？”
