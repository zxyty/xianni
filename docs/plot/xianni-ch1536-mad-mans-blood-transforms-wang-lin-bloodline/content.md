# 第1536章 你等本王歇会

## 一、王林的处境：清醒的酷刑

- 王林体内**古神之力**每次要恢复，都被疯子的鲜血阻止，伤势更重，体内翻江倒海。
- 他其实**很早之前就已苏醒**，只是苏醒时体内已充斥疯子鲜血：身体无法动弹，眼皮睁不开，**元神被血液凝固在体内**，一动不能动。
- 这份痛苦**比当年的古神星劫还浓厚无数倍**。
- 唯一的缓解来自右手所抓的**弓**：弓内传来一阵阵雀跃欢呼，送入温暖。

## 二、疯子之血的本质

- 血中蕴含**极为精纯的力量**，王林一生仅见过一次可比者：在**吉之墓地**座椅上所见幻幕中，**道古烨寞**施展大神通道术「**无仙之术**」时爆发的气息。
- 此力**不能为王林所用**，只在他体内与古神之力厮杀，并与其骨、血逐渐互融。
- **骨为造血之根本**：血液融入骨髓 → 改变骨髓 → 即改变血脉。若成，王林此后所流之血将如疯子一般纯正高贵。
- 王林隐隐感到血中传出一股「足以令苍生跪拜」的思绪；更震撼的是，血液涌入时**他的元神竟在颤抖**，仿佛此血对他而言是无法想象的高端存在——**如天下修士之巅**。
- 长久之后，此血将使王林身体发生**由凡人成为仙人**的巨大蜕变。

## 三、弓的认主真相

- 王林渐觉手中之弓**已与自己融为一体**，仿若成为血脉的一部分。
- 关键发现：这把**原本绝不认主**的弓，眼下所认的**并不是王林本人，而是他体内正被改变的血脉**——仿佛唯有拥有此种血脉才可让其认主。

## 四、疯子的言行与线索

- 喃喃自语提及：「本王的鲜血非常非常飞飞……好像有个叫**飞飞**的小妖女给我吃了什么东西」（记忆迷茫、语句断裂）。
- 提及「**我哥**告诉过我，本王的鲜血，一滴就可以……」（话未说完）；又称「**我族的鲜血，天下一切伤势大都可以恢复**」。
- 呼唤「**小红**，你死哪去了，本王在这里这么多年了，你也不来找本王……等本王回家，本王要吃了你」。
- **重要设定**：疯子明言「本王鲜血若非本命自愿送出，就算是被人抽干了，也没有任何用处」。
- 因王林身体只恢复成「当初被他搬来时的半截样子」而暴怒，绕行、踢踹、在王林身上蹦跳，状如愤怒的孩子/猴子。

## 五、三度献血：从指血到本命之血

| 次序 | 方式 | 结果 |
|---|---|---|
| 1 | 之前手指滴血（如溪流） | 量小，缓慢改造 |
| 2 | 右手拍胸（浮现诡异印记）喷出一大口浓金色鲜血 | 如江河对溪流；王林汗毛伸张片刻吸尽，血化风暴与古神之力厮杀，部分融入骨髓 |
| 3 | 连拍胸口三下，连喷三口鲜血化作血雨 | 疯子面色苍白、退后两步 |
| 4 | 咬破舌尖喷出**本命之血**血箭 | 比寻常血液珍贵无数倍；疯子失血过多当场昏厥，昏迷前仍念叨「好晕……小红，过来给爷揉揉」 |

## 六、蜕变结果：血脉重造与双目异变

1. **威压压制**：本命之血入体瞬间爆发无法形容的威压，王林体内的**道古之力**与**古神之力**轰然崩溃、被生生压制，但**始终没有大范围融合**。
2. **骨髓融合**：道古之力受压后，鲜血直奔全身骨头，瞬息与骨髓相融（非方寸小范围）。王林身子剧震，全身弥漫红点——那是他**本身旧血被疯狂逼出体外**。
3. **新血诞生**：骨髓造出新血，出现一瞬即从体内轰出**高贵气息**——如天下修士之首，天地在其面前也要低头。
4. **左目**：九色火焰轰然燃烧、被新血一冲而崩溃成无数火苗，随即再度融合，幻化出一道**金色之火**——蕴含一股天地失道，但**并非道火**。
5. **右目**：雷图轰鸣，被新血一冲**直接碎灭**，包裹其外的**九道伴随之雷**同样崩溃碎灭；随后一道**金色闪电**出现在右目瞳孔中。
6. **定性**：金色虽仅是淡金，却足以让一切知晓此金色奥秘者为之恐惧——「**金色，仙之颜色，真正的仙**」。若王林此刻睁眼，所有看到其瞳孔的修士都将感受到从其双目爆发的无法形容的威压。

## 七、待解疑点

- 疯子所属之「族」为何？其「哥」、「小红」、「飞飞」分别为谁？
- 王林清醒中看到了疯子施展的种种神通与其喋喋不休的话语，「心神如有百万千万雷霆同时轰鸣，久久无法平复」，但因剧痛无法细究——内容本章未揭示。
- 弓认血脉不认人，暗示该弓与疯子一族同源。
