# 第1589章 梦仙，还是仙梦！

## 一、杀劫余波：尘埃崩溃，众人赶至

- 朱雀星在星海中散发柔和之芒；其外远处一粒看不见的尘埃——**王林封尊杀劫之地**——在战老鬼消失后轻响崩碎。
- 尘埃碎裂处波纹持续回荡、弥漫整个星空，一个个身影自波纹内**陆续**（并非同时）走出：红杉子、南云子、青霖、清水等。
- 磅礴神识一层层横扫，最终锁定尘埃崩溃之处。众人沉默——**感应不到王林的气息，如同当年王林失踪时一样，仿若死亡**。

### 各人反应

| 人物 | 言行 |
| --- | --- |
| 红杉子 | 眼露悲哀，许久后开口：「他，没有死。」并道「大战将起，此事界外定会大肆传出。」 |
| 青霖 | 轻叹，望着崩溃的尘埃，眼前浮现与王林当年的一幕幕 |
| 清水 | 目露寒光，杀戮气息弥漫笼罩四周 |

### 清水的决定（本章关键转折）

- 清水闭目，容颜渐变，**化作王林的样子**，冷漠气质与王林有几分神似。
- 宣言：「**我，代他在云海战台闭关。**」
- 代价：**放弃了去寻找女儿，放弃了自由**，选择化作王林模样在战台闭关，**成为一个象征**。
- 誓言：「师弟，此事我会给你一个交代……所有参与此事之人，但凡我清水有一丝机会，我都会豁出一切，代你复仇。」

### 共识

- 众人心中清楚：**这次杀戮是界外准备了很久的计划**，刻意避开了他们的感应才掀起杀劫；王林绝难躲过，如今凶多吉少。
- 众人渐渐散去，憋在心里的怒火却如燃烧的火焰越来越烈。

## 二、朱雀星上的凭吊（数日一节，层层递进）

朱雀星依旧柔和，星上熟悉的人沉浸各自天地，**并不知道外面发生的一切**。

- **周武泰**：依然坐在朱雀雕像上，默默喝酒。
- **赵国皇祖城**：古老院子与屋舍中，那坟墓孤独伫立，**墓前已没有了那痛哭悲魂的身影**；地上只有几个空酒壶，其内也没有了曾家的酒。
- 巨大雕像手持**开天之斧**，无神望天，似成永恒。

随后数日、数日、数日……陆续有人来到雕像下：

1. **神色冷峻的青年（十三）**：跪下磕头，泪流。「师尊，十三会在万众瞩目下，会在最巅峰之时，说出是您的弟子。」
2. **相貌秀美的女子（周茹）**：带着一头**有些苍老的虎**，抚摸雕像山体，泪落于地。「叔叔……我是周茹……我是小茹儿……」
3. **魁梧的大汉**：拿两壶酒在雕像前长笑，笑着哭出来，似要与雕像同醉，悔恨道：「若当年我没有指引你修道……若当年我们没有遇到……若当年，我拿走你的天逆珠……若当年，你还是一个懵懂少年……」
4. **木冰眉**：绝艳女子，怔怔站在雕像前，历经数番日出日落，默默离去，转身时两滴泪水落地碎开。
5. **身穿粉色水罗裙的女子**：带着疲惫来到朱雀星，望着雕像追忆：「君不识妾，然妾识君……」

> 时间流逝的过程被刻意模糊——「数日后，数月后……如同那虚无里的时光，没有尽头，也找不到终点。」

## 三、虚无深处：王林与疯子

- 场景：**一片漆黑的虚无**，没有生灵、没有一切，死寂万古；其中只有两具破散的身体。
- **血色光圈**：一道黯淡血色透出金芒，笼罩成光圈，正是王林之前手中那滴**金色血液**所化，柔和地包裹王林与疯子二人。
- **王林状态**：身体大范围崩溃，处处伤痕；不知沉睡多久，且明白自己的苏醒**仅仅是片刻**。
- **疯子状态**：双目紧闭、面如纸灰，**身上没有半点伤势**；但眉心有一团七彩光芒（**长枪所化**）——它伤不了疯子的**不灭体**，却能伤其当年重创之后**失去保护的魂**。

### 王林的最后手段

1. 勉强抬起右手挥数下，打开一道**储物裂缝**。
2. **三个道果**飞出，被他一吸缩小、化作三道光芒，带着庞大到无法想象的**驳杂道念**融入其口。
3. 双眼露出生命最后的至强之芒；左手抓着疯子，似与对方连在一起。
4. 抬起食指点向自己眉心，运转最后一丝力量化作道念，施展**其一生第三个自创神通——「梦道」**。
5. 目的：**以梦道之术落在己身，梦回千年，在梦中让他的生死、因果、真假三道本源彻底大成。**
6. 右手无力垂下，王林闭上双眼。

## 四、梦中开场：醉书生

- 场景切换：官路旁一间简陋客栈，穿青布小褂的伙计推着趴在桌上的醉青年：「小哥，小哥，醒醒……我这客栈可要打烊了。」
- 伙计评价：「这真是书生，喝了两杯就如此大醉。」
- 青年醉眼朦胧吟诵：「**夫天地者，万物之逆旅也；光阴者，百代之过客也；而浮生若梦，为欢几何……**」自赞「好诗，好诗」。
- 收尾点题：「呵呵，我告诉你，我刚才做了一个梦……**我梦见自己成了仙**」——说罢倒地呼呼大睡。

## 五、要点归纳

- **明面结局**：外界（含最亲近的强者）判定王林凶多吉少、气息断绝；界外将大肆宣扬。
- **实际真相**：王林未死，在虚无中以梦道自封入梦，用千年梦境冲击三道本源大成——是一次以「假死」为代价的破境豪赌。
- **象征替身**：清水化作王林之貌代其在云海战台闭关，令「王林」这一符号在云海继续存在。
- **人物线索回收**：十三（弟子）、周茹（侄辈，携老虎）、指引其修道并曾欲夺天逆珠的大汉、木冰眉、粉色水罗裙女子，构成一轮群像凭吊。
- **母题呼应**：「梦仙，还是仙梦」——真假、虚幻母题在梦道与醉书生之梦上双重叠合。
