# 第八卷 联盟隐秘 第1051章 周佚再现

## 一、假山之后：与云仙道侣的短暂照面

- 王林前方假山后走出一男一女：男子仙风道骨、相貌英俊，名 **王巍**；女子目光柔和、掩口而笑双目如月牙，名 **胡娟**。二人为道侣，被称「云仙道侣」「云仙前辈」。
- 王林神色平静、心中警惕：此刻**修为尚未恢复、身有伤患**，是其进入仙帝洞府以来最低之时，稍有不慎便可能送命。
- 王林不动声色退后一步，临近旁边禁制边缘，抱拳行礼「见过云仙前辈」，同时扫视二人身后——**未见周佚身影，内心一沉**。
- 王巍笑赞王林禁制之术玄妙，直言「之前王某还是低估了」；他对王林所知不多，**周佚从未向他提过王林一句**。王林身上的伤患亦被王巍看破。
- 王林心中的疑点：仙帝洞府开启时众人一同进入，理应全部被吸入瓶中界，可**直到瓶中界崩溃这二人都未出现**，此刻却现身第六层。
- 王林借口告辞，向后大步退去，绕道而行；王巍笑而不阻，任其身影消失于层层禁制中。

## 二、王巍与胡娟的推断

- 王巍：王林并非被吓走，而是「另有所去之处」；其踏入禁制行云流水、毫不停滞且未触发禁制，**要么对此地极为了解，要么禁制之术再度超出想象**。
- 胡娟：以王林的年纪，「我宁愿相信是他对于这里极为了解」。
- 王巍进一步推断：此前二人便猜测**剑灵并非独自来到此地、必有同伴**，若无猜错，那同伴就是王林。胡娟遂道「若真如此，他倒也不是敌人」。
- 决策：依王林去向判断其奔仙帝**储存丹药之处**，剑灵也在那里，「他二人之间定有一些秘密」——二人随即动身前往查看。
- 胡娟对王巍的分析与计算大都极为相信，目光温柔，随其同行。

## 三、七日绕行与丹房外的禁制异常

- **第六层禁制复杂程度更甚前五层**：有的可瞬间通过，有的须仔细分析计算方敢落步；王林绕半圆行走，**耗时七天**接近药物储存之地。
- 据地图玉简：此处是一座**炼丹房**，内部有**传送点**可进入储存丹药之处；丹房旁另有一处**种植园**，眼下只剩枯枝杂草。
- 行走时王林神识弥漫四周但不散远，专注观察禁制波动以判断有无人临近。
- 将入种植园时王林骤停：**此处禁制与地图玉简的介绍有偏差**。前五层玉简记载全部准确，唯独此地有异——唯一解释是**禁制被人做过手脚**。

### 禁制之术的推论（本章设定要点）

- 禁制千变万化，施术者的**性格、阅历、修为、对禁制的理解**各不相同，同一禁制百人施展，落在明眼人眼中细节绝无一模一样。
- 丹房外禁制系在**原有禁制基础上添加、略作变化**，但新添部分与原有禁制**结合得不可思议地完美**，已不可用「完美」形容，「根本就是一模一样，仿佛同一个人在不同时间完善自己布置的禁制」。
- 王林自忖：以自身了解加上**破灭禁的传承**，世间无人能在他人禁制基础上强改而如此完美；即便有，也只能是对初学者的禁制如此。而此处是**仙帝洞府第六层**，禁制世间少见。
- 若真有这样的人，仙帝洞府全部禁制在其眼中形同儿戏，**穿梭九层极为轻松**。

### 关键猜测

> 「这仙帝洞府当年布置了全部禁制者，与如今在这里把禁制略作改动者，是同一人不成？」

- 该答案可解释一切，却太过匪夷所思。王林隐约感到自己**发现了一个巨大的网**，只是不知布网者是谁。
- **王林脑中第一个浮现的怀疑对象，就是云仙道侣。**

## 四、破禁：没有第五步

- 丹药对王林太过重要，他不甘放弃，索性盘膝坐地推演：眼中禁制之芒飞闪，**自储物袋取出罗盘**辅助计算。
- **推演三天**，双目渐生血丝，脑中无数禁制变化不断闪烁，寻找最正确的破解之法。
- **第四天**起身，毫不犹豫踏入丹房外禁制，一步落下不停，再进三步。
- **第五步陷入犹豫**：按其计算，无论怎么落下似乎都是错的。沉吟许久后王林露出微笑——「**没有第五步**」：他将第五步踏在虚空、直接一跃而去落于前方地面，于是那一步成了**第六步**。
- 落地后观察四周确认未触发禁制，松了口气，行云流水般左右穿梭，不久便走出这片禁制，出现在**丹房门外**。

## 五、周佚再现

- 王林正要推门，神色骤变猛地后退；退后刹那**丹房门自内打开**，一道剑光闪电般呼啸而来，看清王林后传出「轻咦」一声。
- 剑光蓦然一散，化作一个**白衣身影，玉树临风，正是周佚**。王林停步、放下右手掐着的印诀。
- 王林先看那扇开着的门：**门内门外好似两个隔绝的世界，神识无法透出**——由此解释了周佚不知王林前来、王林也未察觉周佚的原因。
- 周佚望着王林，脸上露出**感慨与微笑，依稀带着惆怅的追忆**，说：「我知道，你一定能来到这里。」
- 王林所见：**周佚的变化很大**；更令其诧异的是，周佚身上竟有**一丝与那次空涅法宝极为相似的气息**。

## 六、悬念与线索

1. 云仙道侣为何未被吸入瓶中界，却直接现身第六层？
2. 布置仙帝洞府禁制者与改动禁制者是否同一人？「布网者」身份未明，王林首疑云仙道侣。
3. 周佚为何身负次空涅法宝的气息？其「变化很大」指向何种际遇？
4. 王巍所言「剑灵的同伴」是否确为王林，剑灵与周佚、与丹药储存之地的关系待揭。
