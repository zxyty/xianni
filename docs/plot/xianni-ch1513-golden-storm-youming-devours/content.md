# 第十卷 叱咤界内 · 第1513章 金色风暴！（第三更）

## 一、铃铛的来历与突袭

- 水道子此前召唤远古仙域之仙、被赐下**金色铃铛**，施展的是**传自封尊的秘术**，且身上有**龟甲**护持。整个天地变化与远古仙域气息，**除他本人外无人可感应**，因此他此刻取出铃铛硬抗王林一拳，完全出乎所有人意料。
- 红杉子等人虽欲赶来，此刻已**无法阻止**。
- 王林感受到极精纯的仙气与整个界内封界大阵的幻化，神色凝重，虽不知全貌，仍凭心智迅速判断出几分——在拳头即将碰上铃铛的一刹那**右手猛地后缩**，与铃铛略分开一丝。

## 二、水道子自爆：以云海陪葬

- 水道子疯狂大吼「给我爆」，喷出一口鲜血落在铃铛上。**此铃铛唯有他一人可操控**，在他控制下铃铛裂开无数缝隙，**轰然自爆**。
- 这枚**可为界内拖延百年时间**的远古仙域之物，就此崩溃。原本它若融入**封界大阵**，可使这个「对界内界外都是双刃剑」的阵法更为凝聚，足以抵抗百年；如今这股力量被水道子全部引出，专用于攻击王林。
- 威力评估：风暴若彻底爆开，**王林、周德、云烽子、灵动上人、周瑾、整个神宗、乃至整个云海星域皆成死地，无人可活**；唯独**金色灵动之主水道子**可在崩溃中毫发无损。

### 水道子的盘算

1. 爆开金色灵动，毁灭整个云海；
2. 料定这股金色力量会**冲击封界大阵**，很可能令其出现**漏洞**；
3. 借漏洞**逃入太古星辰**，凭莫大功劳在太古逍遥。

### 水道子的宣言

- 「谁敢杀我？谁能杀我？」——自恃**第三步大能**，称「当年**封界之尊**那老家伙都不行」。
- 对王林诛心：「你要杀我，却连累了整个云海……我看你道心有没有破绽，我看你日后怎么留在界内——你，就是**界内万古罪人**。」

## 三、末日景象与六大能合力

- 云海星域所有漂浮大陆震动，此为**星域崩溃前兆**；星雾散开，无数凶兽因灵性察觉灭顶之灾而齐齐悲鸣；修真星震动，其内凡人生灵皆将瞬息死亡；修士面色苍白，如临末日。
- 云海星云出现**数千万丈长的巨大裂缝**；星空下的**封界大阵**光芒闪烁、沧桑气息弥漫，**隐隐出现封界阵灵**。

**六个大能同时出手**，仍不足以阻止。随后：

- **妖宗数十名天人衰劫修士**纷纷幻化，面色苍白急急来临，要贡献全部之力；
- **神宗内原本心向水道子的长老**，此刻也不顾一切前来阻拦；
- 天空中的**太阿罗**面色大变，长发舞动、双手前按死死抵抗；
- **鬼宗大虚上人**破空来临加入；其现身后滔天妖气弥漫，天空浮现一尊**古妖面孔**，**左眼九颗妖星旋转后急速飞出、分成九个方向**，欲困住风暴。

结果：风暴仍越来越大、越来越磅礴，众人不断后退，已到无法控制的地步。

## 四、放弃云海的判定

- 尸阴宗老者沉声劝：「红杉子，云海放弃吧。」红杉子先是咬牙催动本源之力挣扎抵抗，终于惨笑退走：
  - 「诸位速退，能带走几人就带走几人。**云海完了**。**封界大阵一旦打开，战争，开始了**。但在这之前，我要杀了这水道子。」
- 众人苦涩后退，公论已成：**从今以后界内再无四大星域，而是三个**；云海大量修士与无尽生灵尽毁。

## 五、转折：幽冥兽吞噬金色风暴

- 王林默然。他找水道子复仇本是个人之事，却波及整个云海，代价之大令其沉默，只道一句：「**不应该是这个样子**。」
- 在众人退后、风暴再无抵抗而疯狂蔓延的刹那，王林**抬右手点在眉心**，**眉心第二颗古神星点急速一闪**，喝出「**幽冥**」——天空一暗，一头庞大无比的**幽冥兽**幻化而出。
- 幽冥兽神色呆滞，呆呆望着风暴似在思考「这是个什么玩意」。**此地无人知晓王林收了幽冥兽**，众人（含红杉子）目光尽是震惊。
- 王林双臂猛挥，暴喝「**幽冥，吞**」。幽冥兽眨眼缓过神，张开大口，身上现出**足以吞噬星空的巨大幽冥魂口**，猛地一吸。
- 水道子先是狂笑「幽冥兽没用，它可以吞天吞地，但却吞不了这金色风暴」，笑声戛然而止，眼中骇然——**金色风暴与幽冥大口相比实在太小，被生生吞入口中**，吞下后幽冥兽还咀嚼几下，似在回味。

## 六、余波

- 四周一片死寂，包括水道子在内所有人怔怔望着幽冥兽，等待它吞下这股不可想象之力后的反应。
- 许久，幽冥兽仍只是发呆看着王林，眼中渐渐由**不解、茫然转为恐惧**——它不明白这些让它害怕的人为何这样看自己，身子颤抖，体内传出**如雷霆般震动天地的闷吼**。

## 七、遗留悬念

1. 幽冥兽吞下金色风暴后的真实反应/变化尚未揭晓（本章以其惊惧闷吼收尾）。
2. 封界大阵已被冲击、出现封界阵灵，「封界大阵一旦打开，战争开始」的判词悬置。
3. 红杉子退走前立誓先杀水道子，水道子生死未定。
4. 水道子欲借漏洞逃入太古星辰的图谋是否落空未明。
