# 第1153章 每临大事有静气

（第九卷 云海之巅；承第1068章后云海星域·蛮荒大陆线。本章王林在云海星域对外化名「吕子浩」，自第1063章起沿用。）

## 一、斩杀净涅中年男子

- 王林打出的元力毫无温和之意，化作「如山压」般浑厚，近距离落向中年男子。
- 中年男子在元力将落之瞬抬头，神色狰狞，体内毁灭性气息闪烁，欲自爆。
- 王林神色冰冷，右手虚空一抓开启**储物裂缝**，取出**铁剑**向前横扫。剑光呼啸，中年男子脖颈现血痕，头颅落地滚出数丈；死去的不仅是肉身，还有其虚弱的**元神**。

### 王林识破谎言的推理链
- 山谷内第一具尸体是**真正毒发而亡**；其后四具则是**先被人杀死、肉身才毒发溃烂**，且摆放位置有异。
- 由此断定中年男子所称「元力尽失」是说谎；临死之人说谎必有所图 → 毫不犹豫斩杀。
- 四人来历（是中年男子的弟子、还是毒婆子的弟子、为何被杀）王林**不打算深究**，因果不问。

## 二、由线索推演出的局势判断

- 毒婆子（已被王林所杀的老妇人）围困中年男子，所图即**玉简与丹方**。
- 中年男子误以为王林代表某个宗派而非独身散修；毒婆子见王林即出杀招，同样作此判断 → 此事是**宗派与宗派之间的厮杀**。
- 毒婆子出手前一句「来的好快」，暗示**大量各宗派修士正赶往此地**。
- 关于藏物：修为足够者可打开死者封闭的储物空间，故中年男子若在意此物，**不会放在储物空间内** → 王林将目光转向地上四具弟子骸骨。

## 三、焚骨得宝：玉简与兽骨碎片

- 神识扫过骸骨无所获，王林**左眼火光一闪**，以火焰包围焚化四具剧毒骸骨（燃烧中毒素闪出幽光），骸骨尽成灰痕。
- 灰痕中现出：**一枚玉简** + **一片手掌大小的兽骨碎片**。
  - 玉简：神识一扫，王林骤然变色 —— 「**八阶破天宗**」。
  - 兽骨碎片：刻有「**涅空丹**」丹方。王林虽不知涅空丹为何物，却深知「涅」「空」二字对大神通修士的含义。

### 涅空丹丹方附言（震撼王林心神的三句）
1. 服下此丹，有**一成**把握**规则化本源**，成为我辈修道**第三步**。
2. 服下此丹，有**五成**把握度过**天人一次衰劫**。
3. 服下此丹，有**八成**把握进入**神之始境**。

- 王林一度心跳加速、口干舌燥、不敢置信，眼露滔天凶焰——此刻谁抢碎片，必遭其疯狂攻击。
- 判断：此物价值足以引起**修真界浩劫**；消息一旦扩散，必震撼整个**云海星域**；若泄露在他身上，他在云海乃至**雷、雨两界**都将遭无休止追杀。
- 最危险的觊觎者：长久闭关、极少外出、已入**天人衰劫**的**碎涅后期大圆满**老怪。
- 王林当即将玉简与兽骨碎片一同收起，不做细看。

## 四、反侦察布局（栽赃毒婆子）

目的：让外界认为是**毒婆子取走丹方后欲独吞而躲藏**，而非外人所为。

- 仔细清理山谷内自己的一切痕迹。
- 取走中年男子尸身与另一具骸骨。
- 八个骷髅头：先炸毁其中**一个**（化作无数碎片洒落山谷内外），再收走余下**七个**；随后清理碎片，**只在隐秘处留下一片**作为「毒婆子法宝碎片」的伪证。
- 从储物空间取出一具毒发身亡的弟子骸骨**放回原位**。
- 收走**银衣女尸**与七个骷髅头。
- 关键前提：被擒住的**毒婆子元神决不能死**——她不死，今日之事便不会被认定为外人所为。
- 王林自知时间匆忙、随时有各宗修士抵达蛮荒大陆，只能做到眼下程度。

## 五、撤离与「每临大事有静气」

- 放弃继续抢夺药草；一步迈出，以**缩地成寸**瞬移至正引着凶兽奔跑的**黑猿**身旁。
- 黑猿兴奋指向侧方山峰（示意还有药草），王林不予理会，取下黑猿身上的**黄色纸符**并将黑猿收入储物空间。
- 王林将黄色纸符贴身，又取出一张**兽皮速符**同贴，速度达到巅峰，穿透星雾冲出蛮荒大陆，踏入星空。
- 心态：仍心跳狂跳、有梦幻般不真实感，随即压下激动。
- 在这片**五阶星域**中疾驰，神识不敢散开；他判断此刻域内修士众多、齐向蛮荒大陆赶去，若被人撞见自己匆忙疾驰，事后必成重点怀疑对象。
- **章旨**：「越是面临大事，越是心中有隐秘，就越需要冷静与平静。」
- 遂唤出黑猿，盘膝坐在黑猿肩上平复心绪，令其飞向**归元宗**所在的**莫罗大陆**（路程需数日），装作一个寻常云海星域修士。
- 数个时辰后已远离蛮荒大陆；附近另有几处蛮荒大陆，使人无法分辨其来处。

## 六、章末悬念

王林平静的双目突然瞳孔一缩，旋即恢复如常——**远处一道道长虹呼啸，越来越近**。

## 附：本章新增设定要点

- **涅空丹**：与「修道第三步」「天人衰劫」「神之始境」三重关隘直接挂钩的丹药，丹方刻于兽骨碎片。
- **八阶破天宗**：玉简所指宗门，八阶级别（云海星域中的高阶势力量级）。
- **天人衰劫 / 规则化本源 / 神之始境**：碎涅之上的进阶关口与门槛概念。
