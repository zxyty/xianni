# 第九卷 云海之巅 第1239章 归元宗（第三更）

## 一、风界：蚊王登位与两只白色蚊兽自爆

- 王林元神融合的蚊兽体内散出淡金光芒、威压弥漫，四周数千蚊兽亲见「新王诞生」。
- **赤红色蚊兽**（数千）：第一批服从者，充满敬畏，嘶鸣认同。
- **蓝色蚊兽**（数百）：眼中先有挣扎，威压之下很快顺从，盘旋四周。
- **白色蚊兽**（两只，相当于碎涅修士）：死死盯住蚊王，任凭威压神色阴冷。王林蚊兽低嘶，群蚊目光凝聚其身、露出凶焰。
  - 先前与王林蚊兽交战者双目露妖异红芒，散出毁灭性气息，轰然自爆成血雾；另一只随即同样崩亡。
  - **它们宁死也不顺从**——自爆形成疯狂冲击向四周横扫，蓝色、红色蚊兽退避。

## 二、寂魂道长老宋洛海的偷袭

### 动机与算计
- 宋洛海藏于山石之后，见新蚊王身上竟有**修士元神**，判断并非元神出窍，而是某修士在风界失去肉身后以某种方法与蚊王融合，形成极特殊的存在——此生首见。
- 逻辑：控制蚊王难度太大，但控制一个与蚊王融合的修士元神并非太难，且判断「这元神不强，最多碎涅初期」。
- 顾忌白色蚊兽与蚊群不敢冒头；待两只白色蚊兽崩溃、群蚊退避，视为「绝伦良机」，贪念压过理智而出手。

### 出手手段
- 身破山石化作闪电，借自爆冲击直奔蚊王。
- 双手掐诀，碎涅气息疯狂爆发，双手幻化**日月虚影**，出手即最强神通。
- **寂魂道宗派神通特点：与魂、与元神有关，伤人不伤身，专伤神魂。**
- 另发低吼咆哮，内蕴针对元神的神通，令元神受震荡而短暂眩晕。

### 王林的反制
- 王林早已察觉宋洛海却不理会；对方现身刹那，**元神所在的规则之星**立刻闪烁。
- 蚊兽群同时后退；宋洛海身影如虹追击将至时，规则之星旋转，王林元神幻化而出，**目露嘲讽**，右手前挥。
- 狂风化作漩涡风暴与其神通碰撞，惊天动地。宋洛海面色苍白、喷血退后数丈：横扫**威力并不大，却蕴含道念意境与规则弥漫**，瞬息搅乱其心神，意境险些崩溃。
- 王林元神抬手一指、蚊兽长嘶，四周所有蚊兽疯狂冲入，将宋洛海前后左右一切方位封死、深深围困。
- 数千红色 + 数百蓝色蚊兽展现的**群体之力**，王林亦是首次亲见。
- 宋洛海惊恐求饶：「宋某知错……宋某是寂魂道长老，道友放我一次，日后定有厚报。」王林神色如常，神念一出蚊王再嘶，蚊群进攻更为疯狂。

## 三、八阶星域：无极宗千年分宗大比

### 场面
- 无极宗所在之地有**三颗巨大修真星**，盛典在**第二颗修真星**上举行，已进行多日。
- 千年一次的分宗大比，人数众多密密麻麻，占据整个修真星；另邀大神通修士、宗派之人观礼，散修亦来观看。
- 战场为占据小半个修真星的巨大平台，四周有无数登天而起的台阶作坐席，满座修士。

### 归元宗的处境
- 席位在**北部边缘一小块区域**，不足十人，与他宗动辄百人规模相比极为萧瑟。
- 门人目透茫然与悲哀，似觉归元宗命运无法改变。
- 四阶宗派比试结束后**数日**便轮到**五阶分宗**比试。
- 吕烟菲称身体不适先回主宗赐予的居住之地（更偏僻萧瑟）。

### 仙音门吕英杰的羞辱
- 蓝衫中年男子、温和微笑登场，众人认出后色变让开，归元宗所在之地被空出而更显刺眼；孙芸咬唇几乎出血。
- 身后随两名白发老者，神色阴冷、目光如电，对望者心神一颤。
- 身份与传闻（旁观众议）：
  - 六阶星域**仙音门宗主大弟子**吕英杰。
  - 仙音门连续多次在六阶星域分宗排列第一，颇受主宗器重；传无极宗八阶星域最终盛典的**三个内定名额**中有一人出自仙音门。
  - 吕英杰**修炼功法极为歹毒，需大量炉鼎**，被其看中者即便修为高深似乎也无人逃脱。
  - 传其与无极宗**吕长老（碎涅大圆满）**有血脉关联，故行事霸道。
- 言语：称吕烟菲为「艳名远播、暗中被称五阶星域第一炉鼎的吕美人」，称已打点不少**元晶**，要在归元宗解散后将其纳入仙音门；后又以「好心」「炉鼎之说乃听人所述」轻描淡写。
- 吕烟菲美目寒芒，平静回应：**「归元宗，还没有散，也不会散。」**

### 紫道宗卢云从的维护
- 紫衣男子卢云从冷扫吕英杰，抱拳客气称「卢某见过吕道友」，令吕烟菲一怔。
- 表态：「莫说归元宗不会散，即便真的散了，我紫道宗也会全部接纳归元门人。」
- 追忆「吕兄」（即王林化名**吕子浩**）：只有一面之缘，但**一夜论道终生难忘**；若他回来，归元宗别说不会解散，甚至**分宗第一也不是没有可能**。
- 吕英杰试探「那个吕兄又是何方之流，莫非说的是我」，卢云从怒斥：**「住口，你算什么东西，也配提起吕兄二字，他若来临，杀你一人，如捏死蝼蚁。」**

## 四、要点与伏笔

1. 王林的元神+蚊王融合形态已被外人（宋洛海）判定为「一个修士」，且被低估为碎涅初期——道念意境与规则之力是其真正底牌。
2. 蚊群的**群体之力**首次完整展现，成为王林在风界的新战力基础。
3. 寂魂道与王林结下新因果（宋洛海被围杀，生死在王林一念间）。
4. 归元宗存续压力具体化：解散在即、门人被明码觊觎（仙音门元晶打点）、吕英杰背后有无极宗吕长老。
5. 卢云从对「吕子浩」的极高评价，与吕烟菲「归元宗不会散」的坚持，共同为王林回归归元宗、参加分宗大比铺垫。
