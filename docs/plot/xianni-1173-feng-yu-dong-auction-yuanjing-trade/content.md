# 第九卷 云海之巅 第1173章 风欲动

## 场景
苍松子私人交易聚会（蓬莱主城内的阁楼/密室），参与者多为碎涅期老怪：苍松子、吴青、青衣老妪、美艳少妇、满脸坑洼的老者、青年文士、枯瘦黑衣老者，以及净涅期的王林（化名『吕子浩』）。欧阳隆负责引路陪同。

## 一、兽魂与星图之易
- 黑衣老者取出两样重宝：气泡内封的**十二阶凶兽兽魂**（因『半化雾』之故价值倍增）与一根**朱雀羽毛**。
- 传音谈价者众，老者始终不点头；苍松子沉吟后传音议价，老者摇头，苍松子遂罢。
- **青衣老妪**掷出玉简，老者神色骤变却仍不点头；老妪再加一张**六阶星域星图**（自称收集已久，涵盖至少三成六阶星域，其上有几处只有她知晓的蛮荒大陆）。
- 黑衣老者斩钉截铁：「星图老夫不要，你再加一万仙玉。」老妪无仙玉，僵持。
- **王林出手**：以**一万仙玉**买下老妪的星图。老妪深看王林一眼，成交；随即老妪与黑衣老者的兽魂交易顺利完成。
- 一万仙玉的手笔引起在场碎涅老怪注意，但未至震惊。

## 二、朱雀羽毛竞价与吴青的戏耍
- 满脸坑洼的老者判定：**当年朱雀已死，死时全身之羽尽数自燃**，故此羽非真品——出价三千仙玉。
- 竞价过程：三千（坑洼老者）→五千（吴青）→八千（美艳少妇）→**一万（王林，势在必得）**→一万三千（坑洼老者）→一万五千（吴青）→两万（少妇）→**三万（王林）**。
- 三万一出，全场安静。美艳少妇与坑洼老者判断王林非等闲（能出三万仙玉、又能进苍松子私人聚会），先后摇头退出。
- 青年文士注意到：王林面对满室碎涅修士神色平静毫无不适，断定其必有底牌与资格。
- **吴青**原不需此物，见王林出价便起心试探其仙玉底细，无视客栈中年男子「勿招惹王林」的提醒，接连喊价：三万五千→四万五千→**五万五千**（对王林的五万），戏耍之意人人可见，众老怪与苍松子皆现不悦。
- 王林不怒反笑，声称「此物在下不要了」，**闭目掩盖眼中杀机**。吴青以「承让了」取走羽毛。
- 此后交易平淡收场，王林亦拿出几样物品换卖。斗兽赌注结果尚需等待。

## 三、五千元晶交易与混元丹被拒
- 众人散去后房中只余王林与苍松子。苍松子表示吴青亦是首次受邀，其心性恐日后给王林带来麻烦；提议王林**暂勿离开主城**，待拍卖结束后随其与几位上域老友外出，顺路护送离开，以震慑吴青。
- 苍松子自储物裂缝取出储物袋交予王林，内确有**五千元晶**（元晶在云海星域极为稀少，五千为庞大数目）；王林则递上早已备好的仙玉储物袋，苍松子查看后目露奇异之芒。
- 王林询问**混元丹**，苍松子婉拒：偶然自一处遗迹得九粒，现存八粒，另有大用。

## 四、双方心思：互存歹念
- 苍松子于王林离去后收起笑容，自语：「我苍松子的元晶，可不是那么好拿之物。」
- 王林出门后冷哼：苍松子不过宝玉宗之人却拥有如此多元晶，各有秘密；心中暗道「我王林的歹念，比他更多」。
- **王林的元晶动机**：五千元晶仍不够——需以元晶滋养变异灵兽、令**蚊兽**借此法升级，方足以护他成功**进入风仙界**。

## 五、青衣老妪示警与王林的将计就计
- 回阁楼与欧阳隆告辞后，天色朦亮。街上王林身后波纹回荡，**青衣老妪**现身，冷冷一瞥，掷来一枚玉简：**「之前星图有虚假，此图是真。小心吴青。」** 随即消失。
- 王林扫过玉简收好，面露阴冷，定策：修真界以强者为尊，一味缩头藏拙反而不好，**索性反其道而行、张扬一番以打消猜疑**；「吴青你既然找死，我就成全了你」。
- 王林化虹离城，出**蓬莱东部坊市**，直奔**西部一片荒原**。不久吴青化虹追出。
- 吴青离去引起坊市内众多知情大神通修士关注；主城内青衣老妪感慨摇头：「可惜了。」

## 要点
- 王林在云海星域首次公开展露财力（连出一万、三万仙玉），主动完成从藏拙到张扬的策略转向。
- 与吴青的梁子由竞价戏耍结成，本章结尾进入诱杀局。
- 苍松子表面示好、实则觊觎，交易之外埋下隐患。
