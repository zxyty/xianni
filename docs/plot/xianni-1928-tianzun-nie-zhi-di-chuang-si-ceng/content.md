# 仙逆 第1928章 闯！！

## 一、场景与规则
- 地点：天尊涅之地——一片大陆上层层叠起的漆黑宫殿，逐层向天空延伸。
- 闯关方式：进入宫殿后眼前一花，人被置入一片星空，若干修真星被无形之力改变运转轨迹，自四面八方砸向闯关者。
- 通关判定：**必须一招同时毁灭所有来袭的修真星**；若如王林第一次那样连续轰开，则算失败。通关时宫殿爆发夺目金光，失败则宫殿无光并将人强行弹出。
- 观战：宫殿外盘膝坐着约两百多名仙族天尊修士，包括远处的竹林天尊。

## 二、第一层：首战失利
- 九颗修真星从九个方向呼啸而来。
- 王林迎上第一颗，右手一拳，一拳中蕴含**九次呼风之术**，化作一条极为真实的黑龙撞碎该星；随后回旋一脚踢碎第二颗，身影残影般连续出拳，将第三至第九颗尽数轰碎。
- 星空内突生大力灌体，将其推出星空，人被强行弹出第一层宫殿，退出数百丈方才站稳。宫殿无金光——**失败**。
- 四周天尊哗然：仙族天尊中过不了第一层者极为少见；目光中夹杂诧异、轻蔑与冷漠。竹林天尊看了一眼即闭目不再观。

## 三、第一层：二度闯关成功
- 王林毫无恼羞，随即再次冲入宫殿。
- 这一次他按兵不动，散开神识笼罩四周，待九星逼近至不足数百丈、威压临身的刹那，右手抬起一握，**九次呼风之术融于一拳**打向星空虚无。
- 其身仿佛化作一条**九头黑龙**，九个头颅同时向九颗修真星吞噬撞击，九星在同一时间齐齐崩溃，金光自内散出，笼罩星空并弥漫至宫殿外大陆。
- 王林自宫殿顶部冲出，白衣白发，直奔第二座宫殿。外界评价："第一次失败，第二次应该是侥幸成功"。

## 四、连破第二、三、四层
- **第二层**：第一层金光未散，第二层金光骤起，两光交映照亮大陆。众天尊愕然于其速度——第一层失败过一次，第二层却一次即过。
- **第三层**：
  - 关卡设定：需**二十七道神通融体**；二十七颗修真星中有**一颗金色修真星**，一颗堪比全部修真星，是重点与难点。
  - 旁观者证言：有天尊体内可融三十道神通，仍因金色修真星而止步第三层。
  - 王林进入后**不到数息**即爆发金光通过。三层金光相连，如一条长龙渐生其身。
- **第四层**：
  - 关卡定位：**分水岭**。整个仙族一千多天尊中，能度过第四层者不超过二百人，绝大部分止步于此；能踏入第四层者在天尊中已算强者。
  - 关卡设定：三十六颗修真星，其中**两颗金色修真星**。
  - 耗时超过第三层，久到第一座宫殿金光将散；就在其将尽的一瞬，第四层爆发出压过前三座的金光，四座宫殿完美相连，隐现小半截龙尾之形。
  - 数十名天尊自盘膝中起身直视天空；竹林天尊睁眼、瞳孔一缩，从走出金光的身影上**感受到了威胁**。

## 五、王林的自我评估与后续打算
- 前三层对他"没有太多的挑战性"。
- 第四层："我出动了所有分身，在不穿魂铠下，这第四层是极限。"
- 若穿上**魂铠**，尚不知能再闯几层。
- 暂止原因：**眼下要去山海取树，不便暴露实力**；计划取完山海树后再来闯一闯。

## 六、要点提炼
1. 通关的关键不是总输出，而是"一招同时毁灭全部"的爆发与手法——王林两次同用呼风之术，差别只在于分打与合击。
2. 呼风之术可叠加倍数施展（九次融入一拳），外显异象为黑龙／九头黑龙。
3. 金色修真星是层数难度的核心变量：第三层一颗，第四层两颗。
4. 王林此时的战力天花板被两项条件锁定：分身全出 + 不穿魂铠 = 第四层。
5. 伏笔：山海树、魂铠、后续再闯更高层。
