# 第1196章 司马墨的秘密（第九卷 云海之巅）

> 视角人物：王林（本卷以化名『吕子浩』立足云海星域，本章独自行动）

## 一、脱身与复原

- 王林一把抓住射向自己的七彩钉子，借冲击之力疾退落于山峰之下；三头鹰兽化黑芒追来。
- 王林冲入通道，鹰兽不敢入内，在外徘徊露出暴虐之态，许久后化雾气重新弥漫山峰顶部。
- 通道内择隐蔽处盘膝，布置大量禁制，服丹吐纳。**古神之体**除力量外另有难以想象的恢复之力，数个时辰伤势好转。
- 王林不急离去，持续运转古神之力遍布全身，元力急速流转。七彩钉子既除，恢复再无阻力。
- 两天后睁目，双眼如电光照亮漆黑通道：伤势尽复、元神不再萎靡、元力全满，**再度巅峰**。自忖即便苍松子未受伤，也能再战一场。

## 二、战利品清点

| 物品 | 来历 | 评价 |
|---|---|---|
| 七彩钉子 | 山峰顶部机缘/袭击所得 | 一击碎断铁剑并破肉身钉入骨头；若非铁剑阻挡可穿骨化七彩之光融入全身骨内。神识留印后收入储物空间，定为**日后杀手锏**——碎涅后期修士被钉亦必死 |
| 庞德才的指环 | 取自庞德才 | 防御之力绝佳，戴于左手拇指，七彩界内护身利器 |
| 鹿骨短剑 | 洞府内插于鹿骨之上 | 其上封印以现有修为无法打开，暂且收起 |
| 血色元婴小人 | 得自苍松子 | 萎靡却仍有凶焰，似元婴又似法宝，来历不明。王林喷元气包裹吞下，以元神祭炼，欲抹去苍松子烙印后据为己有 |
| 水晶小剑 | 由三叉戟中抖出 | 散发**次空涅法宝**气息，不及铁剑但威力非凡 |
| 玉瓶液体 | 前章苍松子处所得 | 本战主要收获之一 |

**代价与得失**：铁剑虽断，却换来更凌厉的七彩钉子——「一失一得」。此战与苍松子两败俱伤，损失极大而收获不小。

## 三、七彩界的判断

- 由苍松子身上宝物（尤其可召唤神通的珠子）多与此地相关，王林断定七彩界内藏有大量法宝。
- **战略结论**：日后交战实为比拼谁能在此地获得利器与丹药、谁能提升修为。

## 四、破司马墨洞府

### 目标来源
庞德才的记忆：司马墨洞府被他们发现后**并未彻底打开**，只开启了一部分；原计划炼兽魂成丹、修为提升后再全力破开。故王林第一目标即此「保存完整的洞府」。

### 路线与勘察
- 依庞德才记忆路线穿梭群谷，速度极快而未触发任何禁制。
- 此地辽阔，谷中禁制绝大部分已崩溃，洞府多为空谷。
- 一天后停于一寻常山谷外：杂草丛生、有禁制被破坏的痕迹，闭目则觉阴森之意入心神——正是司马墨洞府。

### 两层禁制
1. **第一层：虚幻**。任凭如何破解也无法真正进入，庞德才等人所破即此层。
2. **第二层：真容**。王林以推衍之芒观之、掐诀幻化禁制前挥，山谷如画幕撕裂倒卷：通体成紫、杂草尽消、地面化作黑色泥土、入口处一道黑色光幕阻断前行。

### 岁月禁与钥匙
- 光幕为**岁月禁**，与苍松子取玉瓶处的禁幕同类；王林略算其存在近两万年，不及玉瓶之地的禁幕，但破解极难，除非不惜消耗法宝强行轰开。
- 王林取出**蛮荒大陆所得的司马墨玉简**——「我在蛮荒大陆得到司马墨的遗物，又在这里看到司马墨的洞府，有趣」。
- 玉简缓缓伸入光幕，光幕剧烈波动、无数波纹向玉简凝聚，砰然以玉简为中心裂开可通行的缝隙。王林入内后裂缝收拢、波纹消散，山谷外观再度幻化如初，与他来临前一模一样。

## 五、洞府内景与七彩骸骨

- 穿透光幕后：约百丈大小的青草山谷，四周谷壁有**九个洞口**，各以石门关闭。
- 草地上一具**盘膝骸骨**靠在正前方谷壁，头骨低垂，右手食指点在地面，身前放着**三枚玉简**。
- 骸骨全身骨头隐隐透出七彩之色，散发微弱光芒（与七彩钉子致人骨化的效果呼应）。
- 王林蹲身细看后，取起第一枚玉简，神识探入。

## 六、第一枚玉简：司马墨的自述

- 「没想到，我竟然又回到了这里」——司马墨最终重返此地。
- 当年他与**师叔**及众多同门，按**「他」**（未言明何人）的要求，找到了那处散发七彩之芒的神秘**空间裂缝**。
- 私人线索：**师妹喜欢彩虹**，司马墨曾答应为她取来彩虹漫天挂满房间——遂进入裂缝，坠入梦魇。
- 众人进入**最深处**，发现了**可怕的存在**，知晓一个震惊整个修真界的巨大隐秘：不仅祸及**云海**，更可祸及**罗天、召河、昆虚**。
- 「我们亲手毁去了希望，我们是罪人」——师尊将司马墨逐出门派（自陈师尊亦无可奈何），他与同门离去，迷茫于云海雾气之中，因那个秘密而恐惧雾气。
- 绝望之际，**无量劫**再次出现；逃避一圈后，最终仍要回到这里。「或许，我一生都无法出去了这是命运么我相信命运的，我信奉命运的」。

## 七、悬念与后续线索

- 三枚玉简中仅读第一枚，余下两枚待启。
- 九个石门洞口尚未开启。
- 「祸及云海、罗天、召河、昆虚」的隐秘、「可怕的存在」、「无量劫」为本卷核心伏笔。
- 司马墨骸骨骨透七彩，暗示其结局与七彩钉子/七彩界之力直接相关。
