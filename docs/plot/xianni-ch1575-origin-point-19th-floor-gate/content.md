# 第1575章 原点

## 一、开门前的推衍：轮回之圈

王林盯着朱雀星地底石室中石门上的最后一道符文封印，心惊于其巧妙诡异：

- 该封印**融合了仙人之力与道古气息**，其内充满排斥之力；因这一道圆形符文，排斥之力非但没有爆发崩溃此门，反被其所用，成为封印。
- 这符文等于为王林打开一道大门——**一条让体内排斥之力消散的另一条道路**。
- 天地间能打开者「太少太少，除非如我眼下这个样子」。

王林由此推衍出一个**层层相扣的轮回之圈**（原文因果链）：

1. 当年从**朱雀星**离开；
2. 去了**妖灵之地**，方能由那里的裂缝到**罗天星域**；
3. 到罗天星域，才知晓**幽冥兽**并进入其体内；
4. 知晓幽冥兽，才有日后将其祭炼为**本命兽**的念头；
5. 有本命兽，**云海第一战**中才会被吞入幽冥兽体内疗伤；
6. 才会遇到**那疯子**，才得到**仙人血脉**；
7. 有仙人血脉，方有体内的**排斥之力**。

如今他回到朱雀星，回到迈出第一步的地方——**回到原点**。任何一个环节出错，他都绝不可能打开符文族第十九层；天地间只有他一人可开此封印。此事让他感慨、荒谬，亦有迷茫。

## 二、以排斥之力勾勒符文

王林不运转血脉仙力，也不调动道古之力，而是把体内**仙与古的排斥之力**慢慢从体内蔓延到右手食指。

- 剧痛如一把软剑在体内扭曲刺动，自体内穿入右臂，绞碎血肉经脉，连骨头都在颤抖，最终凝聚于食指。
- 凭莫大坚毅，硬使食指在剧痛下平稳不颤，点在门上的圆圈符文之上。
- 手指落下瞬间，体内排斥之力仿若感受到同伴，轰然爆发呼啸而起；面色苍白而食指不颤。
- 他要**完整勾勒圆形符文一遍**，方可将其打开。每移动一点，圆圈内便有排斥之力顺手指冲入体内，排斥之力暴增。

**过程与代价**：数息即汗流浃背；嘴角溢血、五脏似被卷动欲崩；仙体与肉身撕裂如生生抽魂。半柱香勾勒大半，双眼泛血丝，右臂青筋鼓起如藤条缠绕，脸上身上亦青筋鼓动；到最后体内砰砰巨响如雷霆回荡石室。最后一小块用了整整**一炷香**，其艰难更甚于与第三步大能恶战一场。

**开启条件（原文明示）**：此符文只能用这种方法打开——只具备仙力开启不了，只具备道古气息也无法开启；两者都不具备的话，就算把朱雀星毁灭炼化，也不会伤及符文半点。

## 三、石门开启与反震

食指完美勾出一个圆圈、**回到原点**的刹那，一股莫大之力自符文轰然而出直奔其右手：

- **光影盾**瞬息开启，转瞬即崩溃碎裂；
- 眉心**古神星点**一闪，**天皇炉**幻化体外，刚出现便立刻扭曲，略作阻挡即被弹回，化作幽光重回眉心星点；
- 两者抵消后余力仍令王林嘴角再溢血、后退数十丈撞在石室之壁，石室剧震，墙壁以其身为中心向八方撕开无数裂缝。

石门上圆形符文爆发强光笼罩石室，符文自中间裂开一道裂纹，石门向后轰轰打开，吹出**沧桑气息**并夹杂**道古气息**。门后一片漆黑，如另一个世界的入口——即符文族最大的隐秘之地、**第十九层**。王林不假思索双手拍向身后墙壁，借力如闪电飞入；其进入刹那，石门缓缓闭合关上。这里自**万古之前封印之后从未有人进入**。

## 四、环形圆圈通道

石门之后并非真正的第十九层，而是一条通往十九层的**奇异通道**：

- 通道由一个个**越来越大的环形之圈**构成，圈与圈之间有所隔距，蔓延向前；
- 这些环形之圈**全部都是与石门圆形符文一样的印记**，皆由仙力与道古气息融合构成；正因它们与石门相连，石门外才会有圆形符文隐现；
- 越向前圆圈越大，内蕴排斥之力越疯狂，并融有一股**凌厉之气**，令王林有全身被利剑锁定的错觉，散发无尽冰寒而四周却无冰封迹象；
- 圈外一片漆黑，**神识也无法冲出**查看，但王林肉眼隐隐察觉——**通道外居然是泥土**。他本就在朱雀星地底深处，见泥土本属自然，然迈入石门后恍若身处另一个世界，再见泥土便说不出的怪异。

王林一晃身向前急驰，不知过去多久，前方圆圈几达数百丈方圆，道古气息与仙力更浓。直至通道尽头，最后一个环形圆圈已达**数千丈大小，如同一片天**；回头已看不到通往石门的位置，所见尽是越来越小的层层环形之圈。

沉默中王林转身，向最后一个环形圆圈一步迈去，轰的一声，**自圆圈中心直接走了进去**。

## 五、要点小结

- 主题呼应「原点」：因果轮回之圈 + 勾勒符文回到起点 + 回到朱雀星这一起步之地，三重叠合。
- 王林当前底牌显影：血脉仙力、道古之力、仙古排斥之力、光影盾、眉心古神星点所化天皇炉。
- 悬念：第十九层内为何物；环形圆圈通道如何形成；通道外的泥土意味着什么。
