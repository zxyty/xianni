# 仙逆 第八卷 联盟隐秘 第923章 投名状

## 一、战场与格局
- 地点：**联盟北部**星空（联盟星域境内），整个北部陷入乱战。
- 主线对决：**炎雷子 vs 极贤天**。
- 侧线：**黑煞魔尊**、**云龙妖尊**与**血神子**等人交战中。
- 援兵：**望月**、**参天巨木**（巨木之上载有**申公老祖**、**烈云子**、**王林**）。

## 二、神通交锋（前半段）
1. 炎雷子右手白色火球一捏崩溃，化作无数火凤直奔极贤天。
2. 极贤天双臂前甩，身后幻化的无尽万丈冰刃拔地而起激射。
3. 炎雷子虚空一挥，数个**仙界碎片**横空而出，低喝「**仙界转轮**」——碎片相互环绕转动成风暴，横扫震退四周修士。
4. 极贤天一指天空喝「**寒冰规则**」——无尽寒气扩散，万丈冰川蔓延；再隔空一指喝「冰」，寒气自带规则凝成大片冰层，将炎雷子生生困住。
5. 极贤天不退反进，右手按在冰层上，注入毁灭性力量并在内以奇异方式叠加冲击。

## 三、转折：炎雷子爆发（疑似突破）
- 冰层内炎雷子双目寒光，长笑中把**从始至终一直隐匿的修为**疯狂爆发，**自碎涅后期无限增长**，几乎到不可思议的程度。
- 极贤天面色大变：「你你突破了」——欲退。
- 冰层崩溃后炎雷子的连环手段：
  - 一步迈出融入天地却不前行，全身元力疯狂散开 → **天地元力剧烈波动，直接影响「缩地成寸」**（封锁遁法）。
  - 双手掐诀，赤色火焰如火龙咆哮，**生生阻死极贤天退路**。
  - 喷出一口**元神精气**落在旋转的仙界碎片上 → 旋转之速**加快十倍不止**，反把极贤天困于其内。
  - 近身以火焰环绕并融入风暴，使风暴仿若化作一条火龙。

## 四、望月与参天巨木临场
- 远处星空一声**望月**咆哮化作无数音爆，震得星空似在晃动；联盟方面所有人面色一变。
- 望月以近乎瞬移之速而来，庞大身躯、无数万丈触手摇曳，极为狰狞。
- **黑煞魔尊**看一眼便头皮发麻苦笑后退；**云龙妖尊**睁大眼睛露出不敢置信之色；北部战场双方修士几乎同时收手散开呆望。
- **参天巨木**紧随望月，行进中改变方向，直奔被围困的极贤天撞击而来；未至已有奇异之力笼罩天地，速度越来越快。
- 巨木设定重述：**当年可以支撑远古仙域的降临**；任何人、任何法宝、任何事物哪怕一颗修真星都无法阻止其冲击、不能使其破损半点，横扫之下星空都要崩溃。

## 五、极贤天的规则之力：十三道蓝意
- 危机之下极贤天双手掐诀，身前连点数下，每点一下现一个**蓝色漩涡**，共**十三个**，湛蓝如大海。
- 漩涡放大后逐一钻入体内，全部入体后其身外凝成**十三层蓝意**，散发刺目蓝光——此即极贤天的**规则之力**。
- 设定：**冰寒的极限便是蓝**；极贤天一生只凝聚出这十三道蓝意；他一直认为，若最终能凭自身之力把十三道蓝意化作一道，修为或许就可突破。

## 六、九层蓝意崩碎与四层自爆
1. 巨木直撞旋转的仙界碎片 → 一个碎片崩溃并瞬间连锁蔓延，撞击处数个碎片一一崩溃（碎片崩溃**不弱于一颗修真星的崩溃**），碎块倒卷全数砸在被困的极贤天身上。
2. 巨木紧接着直撞极贤天：先破一层蓝意，随后无尽冲击如大浪不断涌入体内，瞬息中**六层瓦解**，身子被巨木推着急速后退。
3. 炎雷子眼中杀机一闪，全身火焰凝聚狠狠一按 → **再破三层**（合计九层瓦解）。
4. 巨木之上的**申公老祖**与**烈云子**同时向前迈出一步，神通临世落在极贤天身上。
5. 战力对比：炎雷子爆发真正实力后**修为已超过极贤天**；但极贤天毕竟是成名数万年、一生杀戮的老怪，不易在此殒命。
6. 极贤天厉啸一声，眼露果断，将**仅存四层蓝意轰然自爆**：
   - 烈云子被冲击倒卷而退，申公老祖同退。
   - 炎雷子略一犹豫、暗叹后退——考虑到即便能杀极贤天自己也会受伤，**在联盟星域内受伤不利**。

## 七、极贤天遁走与章末悬念
- 极贤天面色苍白喷出一口鲜血，借蓝意自爆之力迅速后退，尖声放话：「**炎雷子，此仇若不报，老夫誓不为人**」。
- 其身后正是望月所在；极贤天虚空一抓现出**一道裂缝**，**不在乎进入后会否迷失其内**，抬步便要踏入。
- **王林**此刻同样站在参天巨木之上，距前方有些距离，刚才的冲击亦波及到他，**体内元力不稳**。
- 王林盯着迅速后退的极贤天，又看了看炎雷子，**咬牙之下右手向前一点，轻喝：「定」**——章节至此中断，结果未交代。

## 八、要点提示
- 章名「**投名状**」与王林在此刻对极贤天出手形成呼应：出手即等于向炎雷子（雷仙殿一方）纳投名状，态度与立场就此表明。
- 炎雷子的"隐匿修为"与"你突破了"是本章最大信息点，其真实境界高于此前示人的碎涅后期。
- 极贤天"十三道蓝意合一即可突破"是其修为体系的关键设定，本章一战九破、四自爆，损失惨重。
