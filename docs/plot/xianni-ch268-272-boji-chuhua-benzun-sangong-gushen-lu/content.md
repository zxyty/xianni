# 仙逆 第284-285章 剥极 / 处化

## 一、化神两条路（设定铺陈）

修士达到化神有两个方法：

1. **模仿他人意境**——感受别人开放的意境从而模仿。简单得多，但很少有化神修士愿意打开自己的意境供人体悟，因此一般只有各门派内的**元婴大圆满**才享有此待遇。
2. **自悟天道心境**——完全靠自己感悟天道、体会心境，最终获得**自己的意境**。极难，需要极大的毅力与机缘，但一旦成功，等级远高于前者。

二者差距无论开始还是以后都是**难以超越的沟壑**——这也是为什么同为化神期，有人可被杀死、有人却能安然存在。绝大部分修士因无法自悟，只能无奈选择第一种。

- 例证：当年赵国那位**四级修真国使者大人**便是第一种方法化神，故在面对王林、看到其强力法宝后选择逃避。
- 例外：少数第一法化神者最终能突破到**婴变期**，但此类人极少，且即便到婴变也属低阶。
- 因此第一法化神者往往把目标放在**丹药**上，寄望丹药提升自身；然而蕴含**仙界之气**的丹药极难获得。

## 二、重返赵国

- 王林雨夜飞入古传送阵，此后毫不停留、全速在各古传送阵间转送。
- **一个月后**，赵国边陲山谷灵力光圈升空，王林现身。
- **赵国现状（杀劫之后）**：修真者大为凋零，数位元婴后期强者死亡，打击严重；几十年来余下门派几乎**全部闭派不再外出**。关于王林的谣传至今不断，无数修士闻之丧胆，亲眼见过他的人时而梦中惊醒、冷汗全身。赵国中心的**通天塔**人去塔空。
- 王林飞向昔日**恒岳派**所在，即如今的**玄道宗**：白雾笼罩整座山峰，入山小径消失，玄道宗多年前便闭门锁派、不问世事。
- 他未惊动任何人，瞬身至**玄道宗后山**。后山修士不多，个个无精打采、寡欢之态，无人能察觉他。
- 王林找到**当年闭关四年的旧洞府**（此时无人占据），进入后石壁轰然落下封闭。

> 立意：「他在这里初入修真，就要在这里成功化神。」

## 三、本尊与分身化开（第284章·剥极）

十天调息后，王林双手掐诀按于胸口，身体一分为二，**本尊自分身内走出**：

| | 本尊 | 分身 |
|---|---|---|
| 外貌 | 白发披肩、冷峻、眉心星点妖异之芒 | 青年（王林常态） |
| 修为 | 结丹后期 | 将要化神 |
| 缺陷 | 极境不进化则修为无法提升 | 半甲子缺陷早在结婴时已消失，与本尊无异 |

- 本尊与分身结合可令**极境达到元婴之效**，但有弊端缺陷，非长久之计。
- 化神在即，若本尊仍与分身融合会有影响，故先化开。
- 经**古庙顿悟**与**生死意境**感悟，王林多年犹豫的心终于坚定：本尊不能走与分身相同的路，**极境必须分离出来**，本尊选择**古神之路**。

## 四、散功与剥离极境（步骤）

1. 青色雾气包裹本尊与分身，本尊开始**散功**。
2. 灵力外散，汗毛泌出血珠，越来越多，本尊面色苍白。
3. 十天后本尊全身隐现老态，修为跌至**结丹初期边缘**；体外血珠连成一片**血色光环**。
4. 金丹「咔咔」碎裂，灵力如脱缰野马乱窜；分身点其**眉心**，将灵力自眉心宣泄而出，凝为**一团金色液体**（金丹所化）抽离。
5. 本尊骨骼肉身余存灵力聚于丹田，凝成**花瓣状光圈**（筑基期标志）；分身点其**丹田**，光圈崩溃，灵力被收至指尖。
6. 本尊修为急剧跌落：凝气**十四层→十三层→十二层→八层→六层→一层**，经脉灵力全部消失，斜靠石壁急喘，目光始终平静。
7. 双目中一道**红色闪电**飞快闪烁；分身点其双眼之间，红电狂泄欲从墙壁遁走，被分身双手化作光幕锁住、大力抓取，红电发出不甘的无声呐喊后不动；分session搓成**血滴**扔入储物袋。
8. **此血滴即「极境」**——本尊放弃修为终将其逼出，彻底化作**法宝一般的存在**。
9. 分身将筑基光圈所化灵力、金丹金色液体先后弹入本尊体内。
10. 本尊不再重修，改运**古神诀**：磅礴灵力如经磨盘，全被骨骼、肌肉吸收；体外红色光环的红气亦丝丝钻入体内。

> 注：原文步骤7末尾为「分身……搓成血滴」，此处「分session」为誊写笔误，应为「分身」。

## 五、两条道路定型

- **本尊炼体 → 求古神之道**
- **分身修内 → 图仙天之道**
- 二者同为王林的身体、并无区别；但在未达**大成**之前，只能**短时间融合**，无法长久同融。一旦融合，实力提高**数倍不止**。

## 六、处化：金茧成形（第285章）

- 本尊身体此前**已达古神的一星标准**，实则早已踏上古神之路，只因王林一直未下决心才走得艰难；古庙顿悟与生死意境让他决心已定。
- 王林拍储物袋放出**数个血煞球**，落于本尊头顶：本尊**白发瞬间变红**，煞气攀至顶峰，此刻样貌与**古神之地的拓森**有一丝神似。
- 本尊睁眼：**无瞳孔，唯两团红芒**，配合红发，宛如**上古魔尊**，望而生畏。
- 王林与本尊同时微笑，观感迥异：**分身的微笑尔雅，本尊的微笑嗜血**。
- 王林取出**上百玉瓶**——**李慕婉当年所赠丹药的大半**；本尊张口一吸，玉瓶纷纷自爆，丹药尽数入口化作灵力。
- 古神诀疯狂运转，把所有丹药灵力凝结为身体的一部分：本尊身体更加坚硬，甚至露出**金属之色**。
- 金色丝线自本尊全身汗毛孔钻出，衣服烟消云散；金丝随丹药与古神诀运转越来越多，最终在体外交错缠绕，形成一个**巨大的金茧**。
- 金茧内传出磅礴威压，威压中有**强悍生机**，如心脏跳动般砰砰作响。

## 七、要点小结

- 极境由「修为附属」变为「可携带的法宝（血滴）」，代价是本尊修为归零。
- 本尊路线自此明确为**炼体/古神诀**，其外相（红发赤瞳、金属身、金茧）向古神拓森靠拢。
- 化神之地选在初入修真的旧洞府，呼应「始于此，成于此」。

# 第285-286章 古神二次蜕变与王林赵国化神（始化）

## 一、本尊：古神炼体第二次蜕变

- 本尊结金茧闭关，分身在旁吐纳打坐护法（金茧内的声音外人听不到，唯分身可清晰感受）。
- 十三日后，金茧内心跳如擂鼓，至顶峰时金茧现裂纹，紫色光芒自裂缝射出，古铜色手臂探出，本尊破茧而出。
- **出关形貌**：一头血红长发披肩；眉心两枚紫色星点如太极般相互环绕缓转；目光不再通红而深深内敛，细看似蕴含血海。
- 成因：吸收无数丹药与自身修为，终达古神炼体第二次蜕变。
- 设定：**古神蜕变每一次所需灵力都是之前的无数倍，越往上难度越大**。

### 肉身试炼
分身拍储物袋放出飞剑击向本尊 → 撞击处发出金属碰撞声并闪火花 → 本尊右手一抓、轻轻一掰，飞剑一分为二失去光泽成为废铁。二人同露满意笑容。

## 二、本尊入朱雀星地心

- 依据**古神涂司**的记忆：新生古神若不经历**星球地心的考验**，无法成为真正的古神。王林在决定本尊走古神之道时已有此决断。
- 本尊配合**古神诀**不断下沉，地压对他人极恐怖，对本尊尚可忍受。
- 下沉极远后仍未至朱雀星中心，王林粗略计算**不到六分之一**；此处已是本尊承受极限，再下会身体崩溃。
- 原因：远古时新生古神进入星球中心前，都由成年古神打出一滴鲜血相助，方能安然入内并抗住压力（王林无此助力）。
- 本尊就此在地底深处盘膝吐纳长眠：**除非分身有生死危机，否则不动**；即便动也只向下，最终目标是朱雀星最中心点、成就古神大道。

### 古神之道的代价
- **三损七劫**：每一次都是考验、都是生死危机。
- 需**悠久岁月**方可完成。
- 最难忍者是孤独：独自修炼，忍受寂寞 → 习惯寂寞 → 最终享受寂寞。

## 三、悬念：古神消失之谜与王林的隐秘

- 远古时期涂司身亡之后，发生了难以想象的事情，导致：**仙界不存、古仙断绝、古神灭亡**；浩劫牵连上界修真，天地异变，**修真联盟**因此出现。
- 王林判断：一旦有人知道他的本尊正在修行古神之道，这段遥远的因果将不再遥远。
- **决定**：绝不能让任何人知道自己还有一个本尊在修行古神之道，否则将有灭顶之灾。

## 四、分身（王林本体行动线）：赵国化神

### 生死意境笼罩赵国
- 王林盘坐玄道宗后山洞府，吐出二字「化神」，伸开手臂散开**生死意境**，自后山 → 玄道宗 → 覆盖整个赵国。

- 王林在此刻映照众生百态：恐慌、茫然、迷惑、震惊。
- 随后云层散尽，无风无云，一片祥和安宁；凡人与修士心态平静，上至皇帝下至百姓不受控制地朝一个方向跪拜。

# 第287章 转世：元神成就与境界体系总纲

## 一、元婴蜕变为元神（王林化神）

- 最后一股灵力化作长龙自天而降，与元婴瞬间融合，元婴体内散发出一丝异样气息。
- 元婴由半透明转为凝实，身体渐大，最终长成一人多高，细看与王林肉身**已无半点区别**。
- 元婴睁眼，眼中无任何常人情感，唯有冷漠之光；观者皆有错觉：它在升华中变成了**超脱修士的神秘存在**，目光俯瞰大地，视凡人与修士皆冷漠，似世间无一事可令其感兴趣。
- 判词：**修士化神的关键，在于元婴升华形成元神；元神不灭，则肉身永存，此乃天道。**
- 王林的元婴在灵力改造中终得蜕变，**退去婴体、成就元神**。

## 二、境界体系原理（本章设定总纲）

### 1. 凡人 → 筑基
- 凡人吞吐天地灵力改造体质，使之更适合吐纳；体内灵力累积到一定程度产生质变，称为**筑基**。
- 按天道，筑基**不可借外力**，须凭自身修为不断冲击，方合逆天修真之道。
- 因难度过大，遂有**筑基丹**这一“逆天之物”；轮回无数之后，如今修真界**极少有人不用筑基丹而自行凝结筑基**。
- 修真联盟的言论是「**天道已死，自当逆天**」，久之无人再深究其不合天道之处。

### 2. 筑基 → 结丹
- 筑基后身体获得更适合吐纳的平台，吸收更多灵力，达一定程度再遇瓶颈。
- **结丹**的目的是把体内灵力反复压缩：无形→有形→液体→凝固成**金丹**。此过程有难度但非绝对，天资足够可省事不少。
- 金丹一出，缓解身体压力，可继续吐纳，且所吸灵力全部向金丹凝聚，金丹愈发坚硬、内蕴灵力超乎想象。
- 故结丹修士对筑基修士而言“好似天一般的存在”，根本无法抵抗——根本原因即在其灵力已庞大到难以想象。

### 3. 结丹后期 → 元婴（第二次质变）
- 常年吐纳后身体再遇瓶颈，即结丹后期；单纯吐纳已无法解决，遂有修士**第二次质变**——虽不彻底，却是天翻地覆的变化，是**真正逆天修真的第一步**。
- **金丹碎裂，元婴诞生。**
- 「元」为道之第一字，又称**玄**，乃一切道之始；这个“玄”字正是金丹碎裂、元婴诞生的根本——一个玄妙的变化、升华的改变。
- 此过程取自凡人怀胎生子（天道常伦）：金丹好比十月怀胎之盘，经蕴化始出生命，此生命即“婴儿”，故有“元婴”一词。道家修此取**生生不息、转世重生**之意。
- 元婴吸收天地灵力之量，比之结丹完全不是一个境界；**拥有元婴之体 = 有了逃脱轮回的可能、与天斗的本钱、行逆天之事的资格**。

### 4. 元婴 → 化神（重感悟而非天资）
- 化神对**天资要求反倒不如以往那么高**，注重的是**对天道的感悟**。
- 结婴只是取得“与天斗的资格”；要与天斗、超脱轮回，必须了解天道与轮回，从天地法则中找出逆天之法——“懂便是懂，不懂始终不懂”。
- 比喻：不悟天道，纵吸再多灵力也沦入下乘，如**婴儿手持神兵利器却挥舞不动**；强行挥舞纵能伤敌，最终也必被利器所伤。
- **意境**＝让婴儿能拿起利器的力量，是挥动利器的唯一选择；悟得天道方能挥舞自如，故名**化神**。
- 此“神”非典籍所载神灵，而是一种思想、一种内心变化、一种玄妙境界，因与典籍神灵有相似处，遂有“化神”之称。

### 5. 元神与天地之力
- 光有力量不够：婴孩之体储存不了太多这种力量，故有**元神**——婴孩长大，身体可储存更多力量。
- **凝结元神 = 意境 + 神识**，二者结合化作元婴的一部分，“神”自然出现，此乃元神。
- 元神以元婴为根本、受天地灵力滋补而凝练成威；化神修士法术神通中蕴含意境，正因元神存在。
- 可被挥舞的“利器”即**天地之力**：化神修士能挥舞元婴修士无法掌控的天地之力，这是其被称为“神”的原因之一。天地之力究其根本正是**天道意境**，各人感悟的意境/法则不同，展现的天地之力也不同。
- 因元神存在，化神修士之强远超元婴修士，如同元婴之于结丹——**境界之别是不可横渡的沟壑**。

## 三、王林出关

- 元神明悟上述一切后，缓缓落下沉入山崖，回到洞府，自王林肉身头顶融入，与肉身完美结合；体内所有灵力尽数消失、与元神融合。
- 王林睁眼，眼如初生婴儿般黑白分明，带一丝若有若无的灵气。
- **随手撕开空间裂缝**：抬右手虚空一抓，裂缝现于身前，内吹阵阵寒风，似可吹灭生机。
  - 化神前：除非在古神体内，否则纵能做到也需运转全身灵力才勉强。
  - **灭生之风**：元婴修士或可抵抗但要用尽全力；结丹修士根本无法抵抗，见之即须远避（除非有克制的法宝）。
  - 化神前的王林不畏此风但会不适，且进入裂缝内一样承受不住——**这正是当年交战者撕裂缝遁走时他不敢追击的原因**。
  - 化神后：寒风对他毫无影响，整个人进入其内亦无伤害。
- 他伸手入裂缝，收回时手中出现**一些细碎的亮点**，沉吟少许后**一一捏碎**。
- 推开封住洞府的石壁走出，只见远处**玄道宗所有修士尽数跪地**仰望，更远处距此较近的门派修士也跪在地上。

## 四、重逢旧识与赵国升级之请

- 王林目光扫过众人，看到许多当年熟悉的人；忽然停在远处一名**身穿白衫、相貌颇为英俊的中年人**身上，嘴角露出开心的微笑，细看后笑容更盛，喃喃：「**四十年，达到筑基后期，挺好**」。
- 该中年人只觉此人极为熟悉却想不起是谁；脑中一震似有什么苏醒，眼前闪过“自己与此人曾经同门”的画面，旋即摇头觉得荒谬，深吸口气连忙低头。
- 王林如今样貌与当年“煞星”外表有差异、气息更迥然，众人认不出；即便有人猜疑也只埋在心中不敢出口。
- 一名**年迈的元婴期修士**咬牙飞起，在百丈之外跪下，颤声问：「前辈可是我赵国之人？」四周立刻屏息安静，众人目光带着狂热望向王林，连那中年男子也再次抬头。

### 三级修真国升四级的规则（本章设定）
1. 须有一名**化神修士**，且此人**必须生在此国**。
2. 四级修真国有一门**传自朱雀国的神通之术**可探查出身根本；除非修为超过朱雀国修士，否则很难作假。
3. 最关键：该化神修士需**在此国一直居住，直至百年之后**，方可上报四级修真国、重新评定等级。

- 王林沉默少许，淡淡答：「**是此国人，但无法定居百年，抱歉**」——条件为其所不能接受，赵国升级之望落空。

# 第268章 空间裂缝夺回剑鞘

## 一、裂缝行进与发现剑鞘

- 王林在空间裂缝内一路行走，身边时而闪过月牙形裂口，每个裂口都有吸力，但对裂缝内的固有之物似乎无效。
- 速度渐快，往往一闪而过。不知多久后，前方一块巨大黑石之上，插着一把**剑鞘**——正是王林当年之物。
- 剑鞘四周有**四个黑影**，呈人形盘膝状对着剑鞘吐纳，一道道亮晶之丝从剑鞘散出被其吸收。

## 二、四执念之战

### 1. 召剑鞘引冲突
- 王林目光平静，右手一召，剑鞘颤抖松动、向上抽起并发出剑鸣。四个黑影转头，双目闪烁蓝芒，口部裂开吸取更多细丝。
- 一黑影暴起化作黑云笼罩而来。王林冷笑「区区鬼魅之物，不自量力」。

### 2. 指气·死灭之意
- 左手隔空一点射出**指气**，其内蕴含王林的意境，散出**死灭之意**；黑影体内生机在意境变化下失去活力，身外笼罩奇异之芒，身体越缩越小，几息彻底消散。

### 3. 魔神之像（化神神通首用）
- 黑影消散瞬间，王林右手再点一道指气沉入其消散之处，四散黑气凝结成一尊巨大**魔神之像**。
- 此像按**古神涂司**记忆中一个名为「**幽**」的敌人所化，以**生死意境**转变、自「生之境」引出的一丝变化。
- 王林身子未动，元神沉浸生死意境，遥控这由生死意境在死与生之间抽离出的奇异力量所化之物。
- **设定要点**：这是王林第一次以真正的化神神通操控天地之力。对化神修士而言，除少数具相当威力的神通外，固定法术已极少，所有攻击手段皆以自身感悟的天道意境为基础各自创造。

### 4. 三黑影的应对
- 一黑影融入剑鞘，卷着剑鞘自黑岩冲出向远处疾驰逃走。
- 一黑影化作成千上万黑丝，从四面八方钻入魔神之像内（后被魔神消灭，魔神随之崩溃化作一道灵力消散）。
- 最后一黑影趁机扑向王林。

### 5. 元神出窍吞噬
- 王林右手点于眉心，元神自头顶遁出，冷漠一瞥后隔空一抓。黑影惊叫欲逃但速度远逊元神，被抓住后被王林元神**一口吞下**。

### 6. 挪移之术截剑鞘
- 逃遁的剑鞘不走直线、左右闪烁以防王林**瞬移**。
- 王林元神原地消失，化作空间裂缝的一部分，自虚空幻化而出按住剑鞘，随后元神回体。
- **设定要点**：此为化神融入天地之中的**挪移之术**，并非所有化神修士都能掌握，取决于意境领悟，比瞬移强出数倍不止。
- 躲在剑鞘中的黑影被王林一抖震出，一手捏住、灵力轻吐即崩溃消失。

## 三、执念来历（抽离记忆所得）

- 四道黑影是一位**大神通修士**从身体上分离而出的**执念**。
- 该修士将执念送入空间裂缝，经**死灭之风**吹袭历练，以求形成**死灭之体**，进而化作**法宝之魂**。
- 执念神智不高，在裂缝内飘荡许久后偶然发现剑鞘、感到其上奇异波动，福至心灵便一直吐纳。
- **王林的决策**：杀尽这四个执念，免得执念被收回后使那位大神通之士知晓（灭口以防因果暴露）。
