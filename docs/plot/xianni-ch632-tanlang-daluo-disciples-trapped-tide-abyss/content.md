# 第632章 与天运子决裂的萌芽

（《仙逆》正文章节梳理；标题所指的'与天运子决裂'在本章尚未发生，本章为其铺垫萌芽。）

## 一、潮汐之地：贪狼与大罗剑宗弟子的百年困局

### 人员构成
- 大罗剑宗**剑肖十二子**中：未羊已死、子鼠与亥猪被留在妖灵之地外，其余**九人**随贪狼进入潮汐之地。
- 辰龙出于谨慎，另**分出三人由丑牛带队**从另一方向进入，彼此保持联系。

### 入局动机
- 贪狼称经其观察，潮汐之地是**整个妖灵之地最大的宝藏**。
- 众弟子亲眼见过东海外潮汐把无数法宝与奇异之物生生吸入妖灵之地，因此除**吉妖承传**外，寻宝正是他们进入此地的目的。除辰龙外皆动心。

### 变故与围困
- 入潮汐之地初期一路顺利，**直到贪狼从一个山洞内取出某物**，局面骤变。
- 众人被突然出现的奇异妖兽围攻并困在原地，**至今近百年**。
- 深渊无日夜，众人藏身黑雾之内；一旦外出即遭无数妖兽围攻。
- **申猴（申候）**在一次强行攻击中身亡：死前施展出师尊的剑气、杀死部分妖兽，但妖兽太多；其**肉身被妖兽吞噬，元神亦未能逃脱**（由午马向辰龙告知）。
- 辰龙判断：即便集合所有剑气，也无法从这里走出。

### 对峙：辰龙逼问贪狼
- 辰龙起身，其余四名大罗剑宗弟子随之起身，以包围姿态围住贪狼。
- 辰龙沉声追问：**在那洞穴内得到了什么？**
- 贪狼一拍储物袋，取出一枚**椭圆形的蛋**：无生机，只笼罩一片死气。
- 辰龙的判断：贪狼功法应与**死气**有关，借此修炼说得过去；但**贪狼所发现的是否真是此物，仍两说**。
- 贪狼反压：'看在你们师尊**凌天候（原文作凌夭候）**的面子上'免此次不敬，再有下次'休怪老夫无情'；语气虽淡，落在弟子耳中却如奔雷，除辰龙外众人纷纷后退。
- 贪狼安抚兼拖延：'你师尊**再有百年**，定然会来到这里，到时候，自会把你们救出。'

### 辰龙的隐忧
- 辰龙低头恭敬认错，**眼中杀机一闪而过**。
- 他早看出贪狼古怪：**对方似乎有意留在这里，并不着急外出**，其中一定有原因。

## 二、王林线：奔赴火妖郡潮汐出口

- 王林正以**大挪移**极速飞向水晶内所留下的**火妖郡（原文作火娠郡）潮汐出口**。
- 情报来源：
  - **姚惜雪**处听闻潮汐深渊；据其说法，**让天运子等人眼红的令牌此刻就在潮汐深渊内**。
  - 王林另知贪狼与大罗剑宗弟子**百年前神秘失踪**，因而大胆猜测他们也进了潮汐之地。
- 王林的打算：若对方已出来便罢；一旦对方至今未出，他就要在**火妖郡这唯一的出口**好好布置一番，以求万全。

## 三、回忆：吉妖传承中的融合与杀戮之气暴涨

- 在**吉妖传承的奇异空间**中，王林与一道**灰色身影**融合。
- 灰色身影所施展的神通是**杀戮仙诀**。
- 融合刹那，王林生出**顿悟般的虚幻感**，其**杀戮之气从百万瞬间变成千万**。
- 杀戮之气达到千万的一刹那，其化作的**生之烙印彼此相互融合**，形成了一个**诡异的印诀**。

## 四、伏笔与看点

1. 贪狼'不急于外出'的动机成谜，其死气之蛋很可能并非洞中真正所得。
2. 辰龙对贪狼已生杀机，师门与外来强者的联盟正在瓦解。
3. 潮汐深渊内的令牌是天运子势力所觊觎之物，与章节标题'与天运子决裂的萌芽'呼应——王林抢先布置火妖郡唯一出口。
4. 王林新得诡异印诀（生之烙印融合产物），战力体系再升级。

## 五、原文用字校勘
- 凌夭候 = **凌天候**（剑尊）
- 火娠郡 = **火妖郡**
- 申候 = **申猴**
- 曰夜 = 日夜；限中 = 眼中；威（包围/千万）= 成/呈；吉妖 = 吉妖（古妖）承传

# 第592章 杀戮仙诀真相与天运子疑云

## 一、千万杀戮印诀的反噬全过程

王林在古妖传承的奇异空间感悟中，以「第三方角度」亲眼旁观并亲身体验了杀戮仙诀最终印诀的真相：

1. **失控**：这个蕴含千万杀戮的印诀，在出现的瞬息便不受王林操控，直接印在其额头眉心。
2. **入元神**：烙印穿透肉身，印在元神深处，勾起元神内与之融合的天地元气，在一种奇异转化下切断了元神与肉身的联系。
3. **吞噬**：元神在三息内融化，被烙印全部吸收；紧接着肉身生机化作一道灰气，同样被吸收。
4. **破体**：烙印如寄生体内吸尽养分的虫豸一般破体而出，带着血腥味徐徐飞出，砰的一下化作一道杀戮之气。

> 这，才是真正的杀戮之气。

事后已过数日、正在飞行途中的王林回想此幕，仍有心悸之感，眼中寒芒与滔天杀机几欲爆发，却被他深深隐藏。他无法辨别奇异空间中所见真假，但凭对杀戮仙诀的了解，隐约判断——**这一幕不假**。

## 二、古妖传承感悟的机制

- 感悟中的状态「好似岁月临身」，可让人**瞬间把一样神通推衍至大成**，从此加深感悟。
- 天资绝顶者甚至能在感悟中**自行创造独属于自己的神通**，并在无数次推衍中反复修正，最终达到阶段性的完美。
- **孙云**即属此类人，连古妖都为之惊艳。

### 王林与孙云的对比

| 维度 | 孙云 | 王林 |
|---|---|---|
| 天资 | 绝顶，古妖惊艳 | 经近八百年变化 + 仙体，改变很多，但仍差之太多 |
| 自创神通 | 能 | 不能 |
| 清醒时机 | 幻影消失大半后才清醒 | 以最短时间清醒 |
| 关键抉择 | — | 果断与**消失最快的灰色身影**融合 |

王林的果断绝非常人可媲美。正因如此，他在古妖传承感悟中**获得了杀戮仙诀的奥秘**——这是连天运子都绝对没有想到的。

## 三、王林对天运子的怀疑与自我克制

王林的独白（声寒如九幽之风）：

- 重申旧誓：「天运子，我曾经说过，若你不负我，王某此生绝不负你。」
- 指控：「杀戮仙诀，神通的确惊人，只是你未免太过狠毒。所幸我感悟有限，最多只有**百万**；若感悟再深达到**千万杀戮**，恐怕我早就变成了一个烙印、变成一道真正的杀戮之气，被你吸收。」
- 推理链：当年灰衣天运子说「因为我的意境，所以传我这杀戮仙诀」→ 联系前后之事 → 几百年前**王林在朱雀星化神时感悟生死轮回被天运子看到**，天运子这才动了收徒之念。

### 王林当场作出的决定

1. 承认「此事我有些偏执了」，眼下**不能立刻定论**。
2. 天运子毕竟有**知遇之恩**；当初选择杀戮仙诀是王林自己的决定，天运子虽有**推波之意**。
3. **日后谨慎观察**。
4. 天运子修为太高，**无对抗把握前绝不能让其发现王林已知晓这一切**。
5. **仔细研究杀戮仙诀，看能否破解**。

## 四、行动：潮汐深渊出口布置与南下寻人

### 火妖郡外·潮汐深渊出口

- 王林在此逗留**数日**。
- **反其道而行**：不布置强大阵法与封印，只留下一些**简单却隐蔽的禁制**。
- 禁制性质：**无攻击力，作追踪之用**。有人从此出来，除非修为极高，否则稍有不慎便会被留下印记，王林即可察觉。

### 目标清单

1. **救周佚**——周佚对他有恩，必须要救。计划全力赶往**水妖郡**，从那里的入口进入，展开神识全力寻找。
2. **找巨富**——当年在东海外潮汐中，王林清晰记得看到巨富一晃而过。

## 五、场景转换：水妖郡西部·云海

- 数日后，**水妖郡内西部**一处被称为**云海**之地，常年被云气缭绕。
- 云海**深部**有一处**蔓延无数里的地下裂缝**，即**潮汐深渊的通道之一**。
- **两男两女四个修士**此刻站在云海外，向内看去。（悬念收尾）
