# 第八卷 联盟隐秘 第1011章 仙灵天境

## 一、四道光柱依次升起

### 正北（第一道）
- 妖灵之地正北一片辽阔平原，云海从四面八方凝聚，一道光柱自地面拔起直入九霄，顶端化作一圈圈光环散开。
- 光柱升空伴雷鸣轰响、波纹回荡，磅礴冲击之力迫使云层退缩。
- 刹那间浓浓仙气散出，弥漫近三成妖灵之地。云中几只丑陋黑鸟被仙风扫过，体内黑气尽去，化作白色仙鹤清啸远去。
- 妖气过浓，单柱仙气被压制，最终在**方圆百里内**形成平衡：百里内尽是仙气，百里外仍是妖气天下。

### 正西（第二道）——灵妖郡境内
- 第三座洞府内，**凌天候**与**紫袍男子**、来头极大的**空虚子**三人盘膝坐于阵法处。
- 凌天候右手虚空一抓，前方虚空裂开缝隙，飞出大片青烟，其内隐约闪现洞府钥匙；他一指身下阵法中心黑色石块，青烟环绕融入，黑石一震、阵法开启。
- 灵妖郡上空光柱拔地而起，仙气再与妖气碰撞。正北、正西两柱辉映，仙气疯狂暴增，试图冲出百里封锁。

### 正南（第三道）
- 仙气与妖气纠缠之际，正南又一道光柱冲霄，喷出更多仙气，妖灵之地展开一场「仙妖之战」。
- 第二座洞府内，**天运子**望着开启的阵法，神色平静，眼中一道奇异之芒微不可查地闪过，只沉默吐出「七天」二字，看不出喜怒心思。
- 三柱之下，除东部外妖灵之地天空几乎尽陷五光十色；但万年积累的妖气太厚，三柱仙气不足以撼动全境。

### 正东（第四道）——第一座洞府
- 第一座洞府内，**云仙道侣**王巍与胡娟平静立于封印处，脚下是庞大阵法。王巍神色如常但眼中难掩激动，喃喃「这一天终于等到了」；胡娟握住其手说「这一次，我们会成功的」。王巍点头：「筹划了这么久，这一次必须要成。」
- 二人身后有一团**紫色虚影**，其内弥漫凌厉之气，隐约透出**一个让王林极为熟悉的气息**（身份未明，重要伏笔）。
- 王巍轻叹道出关键设定：「妖灵之地有谁知道，这里，当年的名字，是**仙灵天境**」，随即抬手向阵法黑石虚空一拍，黑石闪光牵引阵法运转，喝道「妖气荼毒，今日就让乾坤再现」。
- 正东光柱叱咤天地、与九霄连接。

## 二、四柱成阵与仙气风暴

- 东南西北四道光柱彼此交错，**仿若形成一个巨大的阵法**，仙气浓郁程度较之前暴增无数倍，化作风暴横扫全境。
- 大地与生灵的「复原」（并非改造，而是揭去妖气面纱、露出本貌）：
  - 暗红色大地褪成带泥土芳香的黑色，妖异植物抽出嫩绿新芽；
  - 妖树复为挺直巨木，红色青草复为青色；
  - 一头独角黑虎欲扑食紫色互噬小鹿，风暴一扫，黑虎独角崩溃消散、通体转白、凶焰化为灵动，小鹿褪紫伏地透出仙意；
  - 小河洗去妖气变得清澈甘甜，其内长着利齿、能撕碎凡人的巴掌大鱼儿化作七彩之色嬉戏。
- 人群层面：一处处妖郡都城、一个个妖灵部落之人面露痛苦、站立不稳纷纷倒地，妖气自体内钻出被仙风扫去，重新苏醒后身上再无妖气，唯余轻灵仙息与**迷茫**。
- 天空渐渐清明，青山绿水、仙鹤飞舞、灵兽嘶鸣，大地再无妖灵——**仙灵天境**重现。
- 世界观澄清：此地本该是仙境，只因无数年前一场**变故**才沦为妖域；四柱全开等于把覆盖其上的妖气面纱狠狠掀起。

## 三、王林的进度与旁人的评价

- 凌天候：「用了不到七天，就把第四座洞府开通，这王林，老夫原本已经高估，但现在看来，还是低了。」——并自陈当年开第三座洞府用了**近一个月**。
- 天运子亦只以「七天」二字作评，态度隐晦。
- 由此可确认：第四座洞府的开通者是王林，耗时不到七天，为四柱齐开的直接前提。

## 四、悬念与未解

1. 仍有**几处地方妖气坚如磐石**，任仙气冲击巍然不动——妖气并未被完全清除。
2. 仙灵天境内一处山谷水潭中，浮现出一张**妖异之脸**，盯着天空横扫而过的仙气，目露幽光（疑为妖气本源/幕后存在）。
3. 王巍夫妇身后紫色虚影内「王林极为熟悉的气息」属于谁，本章未揭示。
4. 王巍夫妇「筹划了这么久」的真正目的、与封印之间的关系未明。
