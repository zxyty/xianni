# 第1763章 伏杀动！

## 一、焚界古伞收至八成
- 王林喊出「八成，收」——这已是他推动焚界古伞的极限。代价立现：面色苍白、体内生机疯狂流逝，整个人瞬间衰老大半。
- 古伞轰鸣收拢，惨叫回荡，不知死了几人。
- 三大战将心神震动、嘴角溢血，全力抵抗火威并全速外冲。
- 七彩道人与战老鬼虽修为高，但肉身不如古族强悍，亦须抵抗火海。
- 七彩道人传承仙尊神通于一体，其中便含焚界古伞之术（与王林施展不尽相同，但了解更多），故第一个冲出火海，带滔天杀机直奔王林。
- 王林自知无法推至十成，但既有此效果，已然知足。

## 二、七彩长枪破莲花台
- 王林左手向天一掀，七彩光芒自大地掀起冲天，与天上七彩相映，天地尽是七彩之光。
- 一把七彩长枪如七彩长龙冲天而起，直奔七彩道人。
- 七彩道人以失去两瓣的五彩莲花台收拢护身，此次却挡不住——五片花瓣一片片崩溃化作碎末，莲花台轰然爆开。
- 七彩道人随即幻化一把一模一样的七彩长枪硬撼。
- 设定要点：七彩之枪与焚界古伞同为「不属于这洞府界之术」，只要发挥大半力量便极为惊人。

## 三、第三伏——道古本尊·碎兵一斧
- 两枪相撞的冲击中，王林本尊幻化而出：眉心与双目星点成漩，身后凝聚道古虚影，本尊膨胀千丈与虚影融合不分彼此，手持开天巨斧仰天低吼、挥斧而出。
- 王林明白单纯本尊之力伤不到七彩，故宁可碎兵：开天巨斧崩溃化作碎片，爆发全部威力。
- 反噬之下王林本尊亦骤然崩溃、血肉横飞，凭提前准备的**道古不灭术**在后退中不断恢复，直至与盘膝而坐的分身融合，伤势完全恢复；但仍有鲜血自嘴角溢落白衫，触目惊心。

## 四、第四伏——鬼脸血帆困战老鬼
- 战老鬼自火海走出，眼露贪婪，趁本尊挥斧之际冲向王林身前漂浮的**第三魂**。
- 王林左手抬起五指一扣，喝出「第四伏，鬼脸血帆」。
- 血色雾气翻滚化作巨大红色鬼脸，无声咆哮间一口吞下战老鬼；此幻术连七彩道人都能困住一段时间。战老鬼被吞刹那立刻盘膝而坐，神色变化不定。

## 五、旁观者的震骇
- 三大战将与掌尊等人冲出火海，只见结果不见过程：战老鬼被红雾裹住、僵立于王林百丈之处；七彩道人披头散发、狼狈疯狂。
- 掌尊清楚二人修为，见此心神大震；青龙战将露出从未有过的忌惮；玄武战将面色苍白、四下张望，想到王林的天道而生恐惧，后悔来此；朱雀战将心绪最为复杂。
- 第六仙妃刚出火海已然受伤，对王林的恐惧再被勾起。
- 实情：王林此刻已五劳七伤，修身分身与道古本尊皆重伤，若非一口气不卸定然昏迷——占主场且设伏尚且如此，足见七彩道人之强。

## 六、第五伏——幽冥兽·天道幽冥
- 七彩道人杀机达到巅峰，不再抓第三魂而是直杀王林。
- 王林右手仍握**李广弓**，左手一指，喝「天道幽冥，吞天噬地」。
- 天地裂开如巨口，幽冥兽幻化而出，双目睁开冷酷无情，蓦然一吞：数名刚出火海的远古仙域七道宗弟子被吸卷吞噬，连天空火海也被吞去一部分。
- 三大战将凝固身体抵抗；第六仙妃尖叫中被卷入幽冥大口。
- 掌尊看到幽冥兽冷酷目光，与当年其主被吞的记忆对上，再无怀疑，惊恐后退。
- 战术意图：幽冥兽并不完整，吞不了太强之人；王林所要的只是七彩道人骇然停顿的一刹——因为定身术若施于七彩道人，其反噬王林承受不住，故以幽冥换取「如定身一般」的效果。

## 七、第六伏——唤醒地底变异目鱼
- 王林嘴角露出虚弱而阴森的笑，宣告「第六伏」。
- 左手猛拍大地，以学自**二代朱雀**的**白虎密术**力量操控之法化作层层震动之力涌入地底，刺激沉睡在此、已然变异的**目鱼**。
- 同时，先前以鲜血画出的血色圆圈禁制消散、轰然升空，血腥与天地元气完全爆发，直奔七彩道人身周崩溃爆开。
- 大量气息环绕七彩道人之刹，修真星大地轰轰巨震，地底传来沉睡无数万年、睥睨天地的嘶吼，黄沙滔天而起。
