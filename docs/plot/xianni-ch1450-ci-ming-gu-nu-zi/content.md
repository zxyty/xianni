# 仙逆 第1450章 赐名古奴子

## 一、开局：炉中对峙

- 天皇炉内，灵动上人猛地睁眼，神色狰狞、面色苍白如油尽灯枯，盘膝坐起，目光穿透炉体盯向外面吐纳炼化的王林。
- 灵动嘶哑质问：「能让老夫落得如此狼狈，你定非无名，你，到底是谁」，恨意滔天。
- 王林不答，以古神之力冲入回应，炉内炼化之力急转，浑浊中凄厉之声起伏。
- 灵动冷笑断言：**「想要炼化老夫，绝不可能」**——他中计被暗算，但数万年修道的坚定道心非王林可炼化。遂闭目疗伤，只待修为略复便破炉而出。
- 【客观形势】以王林当时修为，纵有天皇炉，炼化三步大能亦需耗费大量时间；而古墓之内，王林没有这个时间。

## 二、天皇王炉·十斧炼奴

1. 王林眼中嘲讽一闪，加大古神之力融入，炉内魂魄暴增，几成浑浊风暴环绕灵动。
2. 风暴化作巨大虚影——**一尊古神**：通体赤红，手持巨斧，甫一幻化即抬斧下斩。
3. 王林口吐古神之语，化作虚幻印记落于炉上，喝出神通名：**「天皇王炉，十斧炼奴」**。
4. **第一斧**：灵动双手掐诀，身后幻化出此前召唤过的**魔神雕像**，幽光碰撞、斧头消散、雕像崩溃；灵动喷血，鲜血再化雕像护体。
5. **第二至第八斧**：王林面色微白，抬手一指，古神身后魂魄疯狂凝聚，第二、三、四、五、六、七、第八尊古神接连幻出，八道惊天之斧融合如残影直奔灵动。王林低吼「给我炼」。
6. 八斧归一，雕像终于承受不住碎裂，斧头残余之力穿透灵动天灵而过落地，天皇炉剧震，灵动喷血，**眼中出现短暂迷茫**。

## 三、关键转折：道术·梦道

王林等的就是这转瞬即逝的迷茫。他双眼露出诡异之芒，双手掐诀点在眉心，喃喃：**「道术——梦道」**。灵动身子一震，迷茫更浓，一生记忆迅速闪过：

| 人生节点 | 场景 | 「王林」的位置 |
|---|---|---|
| 幼年入道 | 模糊身影的青年对跪着的少年说「我可引你入灵动族修道……记住我的名字，我名王林」，少年答「晚辈谨记，终生不忘」 | 引路人 |
| 承受族印 | 黑衣老者胸口血肉模糊、元神崩溃弥留之际，将自身族印挖出相赠跪着的中年灵动，并道「为师真名并非你所知，而是王林」 | 恩师本名 |
| 太古星辰死劫 | 老者（灵动）急速逃遁、被三人神通化三凶龙追杀，已决意自爆；星空柔和之光中虚幻大手一挥击退三人，留言「救你者，王林」 | 救命恩人 |
| 天人第五衰 | 灵动族内白发老者全身腐朽将死，惨笑「天人第五衰……莫非真的要止步在这里」，闭目瞬间入一片模糊天地，背对身影冷声道「为我之奴，让你成道」；转身正是王林之貌 | 成道之主 |
| 赐名 | 「若你同意，从此之后你不再是灵动，赐名——古奴子」 | 命名者 |

- 效果：**「王林」这个名字几乎伴随了灵动一生，成为其一生的梦幻**。此语一出，模糊天地轰然崩溃化作碎片，**撕开灵动全部记忆**，令其在炉内剧烈颤抖后清醒——但仍残存迷茫。

## 四、收官：第十斧与烙印

- 八尊古神身影相互重叠融合为**第九尊古神**，举斧斩下**第十斧**。
- 灵动茫然抬头，眼中挣扎闪烁，下意识欲反抗。
- 王林冰冷之声在炉内回荡：**「你是灵动，还是古奴子」**；灵动骇然仰天低吼「你到底是谁」；王林一身疲惫，缓缓答：**「我是王林」**——声入炉中化作心神雷霆，满耳皆是「王林」二字。
- 第十斧落在灵动头顶，于其**眉心化作一个圆形印记**；灵动双眼再无神采，向后倒下，被魂魄风暴卷中，不知去向。

## 五、王林的评估与后手

- 成果：借天皇炉，梦道之术成功搅乱灵动之心，**留下了自己的烙印**。
- 未竟：眼下仍需**一段时间的温养祭炼**，再加**诸多禁制防范**，才可让对方真正为其所用。
- 自评：「可惜还存在了不少弊端，但时间有限，也只能做到这一步了。」

## 六、悬念：道灵之谜

- 王林大袖甩动，天皇炉内浑浊起而复散，露出另一处天地——其中**单独封印的道灵**：形似麒麟，不断低吼，全身弥漫火焰，**体内伤势正以极为恐怖的速度痊愈**，看样子不久便会彻底恢复如初。
- 王林不知道灵为何物，此生亦为**第一次见到**，见其疗伤之速不由双目一凝：「我倒要看看，这道灵是什么」。
- 手段：掐诀一挥，在道灵身前召出巨大石门——即王林在**风仙界感悟流月**所得的**万古沧桑通天之门**；催动**「流月逆转光阴」**，时光逆行，透过石门看到道灵在岁月中被剥去一层层神秘面纱。
- 结局：片刻之后，王林**面色失变、猛地站起、下意识退后几步**，失声道「这——这是——不可能——」。本章至此断章。

## 八、要点提炼

- **手段升级**：王林首次（本章）完整施展「天皇王炉·十斧炼奴」并与「梦道」组合——先以物理/神通层面（十斧）打出心神迷茫的窗口，再以梦道在窗口内改写记忆、种下烙印，最后一斧定印。属典型的「以术破道心」而非硬炼。
- **道心攻防**：灵动上人的自信基于「数万年道心不可炼化」，其败因不在修为而在**记忆被贯穿式篡改**——「王林」被植入其一生所有关键节点。
- **奴仆非成品**：古奴子此刻只是「留下烙印」，尚需温养祭炼＋禁制，且弊端不少，为后续埋伏笔。
- **新悬念**：道灵之恐怖恢复力 + 逆转光阴所见真相令王林失态，为下一章核心钩子。
