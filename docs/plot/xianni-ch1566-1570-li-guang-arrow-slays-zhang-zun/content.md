# 第1656-1657章 大爆发／决战(一)

## 一、王林归来的征兆
- **清水父女**：风雷大汉狞笑临近、清水已黯淡欲闭目，忽感受到极熟悉的气息——「是他的兄弟，是他的师弟」；扶他的粉衣女子双目骤亮。
- **木冰眉**：已然绝望，忽而身子颤抖、双目放光、绝美一笑，确信「他，不会死」。逼至其十丈外的**道非杉**头皮发麻，猛然回头。
- **旧识齐望**：西子凤、战空烈、申公虎、炎雷子等无数熟悉王林之人同时望向星空。
- **界外反应**：数十万界外修士心神俱颤；当年参与围杀王林的几个空玄大能纷纷回头——「王林」「他居然还没死」；两名仙妃惊呼「**这是李广的箭**」。
- **界内高层**：青霖露出无法置信之色，隐觉此箭眼熟却不敢想象；红杉子完全愣住，没想到王林不但未死，修为更到如此程度。

## 二、李广箭的形貌与来路
- 箭长**万丈**，箭尖**成圆形**，一路呼啸间星空在其面前崩溃，一切力量都无法阻止。
- 箭尖上立着**一身白衣、一头白发**的王林；其后**一上一下两个巨大的不动转轮**轰轰紧随。
- 所过星域波纹回荡、生生豁开，形成**在星空中永存的沟壑**，此沟壑**自与云海的边界而来**，无尽长短。
- 此箭承载王林走过**昆虚、召河、云海**之后的杀戮与怒意。

## 三、王林 vs 掌尊：四层破防
1. **掌印**：掌尊自裂缝宫殿上空落下的巨大掌印，爆七彩之芒万丈，仍被无光只有杀戮的一箭震碎穿透。
2. **七彩光幕**：掌尊迈步至箭尖之前，双手挥舞布下七道光幕；赤橙红绿四幕略挡即崩，青蓝紫三幕扭曲后轰然崩溃。掌尊双臂黑袍碎开，连连后退。
3. **金色太阳**：掌尊咬破舌尖喷出**蕴含金色的仙人血脉之血**，化作金色太阳，一出现便有**太初规则**笼罩星域。王林喝「区区掌印小厮，给我滚」，太阳颤抖不前，终于爆开，冲击尽数反卷掌尊。掌尊喷血、黑袍尽碎、撞上裂缝延伸出的宫殿，宫殿现出数道裂缝。
4. **香火井**：掌尊掐诀推出一口竖起的巨井，内蕴乾坤日月、无尽星空——此为其**第二个香火界**，是他在**仙罡大陆时被疯子赐予**的法宝。井面幻化出一支一模一样的虚幻之箭迎击，一触即崩，掌尊再喷血。

## 四、掌尊的断言（关键情报）
> 「你是用了主人的**仙人不灭体**……这仙人不灭体如此珍贵，一生只有一次机会获得，你居然放弃、居然这般挥霍。但这样的一箭，你还能射出几次？我断言你**只剩下两弓仙力**，两弓之后，你此生**再成不了仙人**，再获得不了仙人血脉，那时你的，就是蝼蚁。」

话未说完，箭已撞在其身上。

## 五、掌尊灭、宫殿崩、三命复活
- 掌尊肉身直接崩溃；其身后**宫殿**——界外修士精神形状、心中永不毁灭的圣物——同时四分五裂爆开。
- 但掌尊未彻底死亡：崩溃的血肉碎末诡异重聚，在失去宫殿的裂缝中再度凝聚成形。王林瞳孔一缩：「**封灭族，三命之术**」。
- 复活后的掌尊面色苍白，毫不犹豫冲入裂缝，右手在后一抓，裂缝崩溃消散，遁走身影**极为狼狈**。

## 六、余波与转向道非杉
- 界外空玄老妪面色苍白、极度恐惧；黑衣老者神色骇然如见死亡；两位仙罡大陆的仙妃虽地位尊高，仍对这个在她们眼中「卑微的洞府之修」露出畏惧。
- **云落大司**看到的是王林的背影——这正是她曾推衍看到的**毁灭天地之人**，身子控制不住地颤抖。
- 王林转身，双目如剑盯住道非杉：「**她虽不是我红颜，可却是我儿王平的母亲，你方才，说什么？**」
- 道非杉修为仅**空涅**，此前认为掌尊等人以幻阵轰杀王林是小题大做，此刻恐惧达到一生巅峰，退后数步、面色苍白、几乎魂飞魄散，悔于招惹木冰眉、对「封尊的红颜」生出淫秽念头。

## 场景与背景

界外之修入侵界内已百年，屠杀无数生灵，此刻围攻界内残存修士所据的星阵。王林先前一箭之威震慑全场，界外修士人人自危。

## 一、道非杉之死（承前章）

- **困兽求生**：道非杉身为第三步空涅大能，明知必死，将唯一生机押在挟持**木冰眉**上，疯狂扑向十丈外的木冰眉。
- **木冰眉的态度**：不闪不躲，冷冷相望，美眸中只有**无视**。
- **王林出手**：一步走出，速度超出道非杉想象，残影尚在远处、人已至木冰眉身前，右手一抓便擒住道非杉手腕。
- **杀意根由**：王林明言木冰眉虽非他的红颜，却是**王平的母亲**，道非杉的银秽亵渎是他绝不允许之事。
- **处刑过程**：
  1. 抡起砸向大地，惨叫惊天；
  2. 抛起后一指点胸，修为之力冲入体内，**右臂崩溃**；
  3. 再一点，**左臂崩溃**；
  4. 双指连点数下，**双腿崩溃**、血肉模糊；
  5. 一掌拍其天灵，砰砰回荡，肉身轰然爆开、四分五裂——飞溅之血无一滴沾身，被王林甩袖倒卷；
  6. 元神茫然飞出，被王林一把掐住脖子，**狠狠一捏，彻底死亡**。
- **威慑效果**：四周界外修士倒吸凉气、骇然退后，无人敢救，也已来不及。

## 二、追杀风雷大汉·救治清水

- **动机**：王林红着双眼，一句『**伤我师兄，岂能让你逃掉**』锁定意欲逃遁的风雷大汉。
- **交手**：一挥之下震碎大汉双臂，其倒卷退后百丈；大汉咬破舌尖喷血箭，化作夹带无数赤色雷球的血色风暴反扑。
- **本源之评**：王林点评其『风之本源成三步大能后，又获得了尚未圆满的雷本源，倒也难得』。
- **雷霆之祖**：王林一掌按上风暴、五指内扣如握拳外拽，风暴崩溃；因其**雷本源大威圆满、身为雷霆之祖**，天地雷霆皆臣服，一声『滚』令雷球颤抖散尽。
- **极刑**：『伤我师兄，我要你承受世间巨痛』——双指点其颈部：
  - 全身血液被吸聚颈部，形成紫黑巨大鼓包，随后如喷泉般爆出，直至最后一滴；
  - 吸力不减，继续抽取**生机**，白气喷洒，身体枯萎成骷髅；
  - 骨骼化髓液消融，连同**元神**一并抽出，最终凝为王林掌心一枚**絮状雾球**——那雾球即是这名第三步空涅大能的全部。
- **救清水**：王林闪至垂死的清水面前，左手按其头顶，逼出七窍中如蟒蛇般挣扎的**七道黑气之毒**；清水死气大消、生机复苏。随后将雾球拍入清水体内，言『吸收之后，师兄伤势可以加速恢复』。
- **旁证**：清水身边有一名粉衣女子怔怔望着王林；王林只扫了一眼，转身走向星空。

# 第1658-1659章 决战（二·三）：斩杀仙妃与因果阵反杀

## 一、战场态势
- 地点：星空战场，界内修士与界外修士大军混战，血流成河。
- 王林走过之地鲜血四溅，无数修士惨叫崩溃而亡，头颅漂浮身后，气势毁天灭地。
- 王林此刻修为：**空灵中期**，且与**吉神（古神）肉身融合**，可杀空玄修士——远非当年可比。

## 二、王林 vs 仙妃

### 仙妃的手段
1. **古琴音浪**：虚空一抓取出王林所熟悉的古琴，抚琴化无数音浪冲击。王林眉心古神星点旋转，古神之力凝聚全身每一处，以古神之体硬抗，仅受一定伤害。
2. **五脏之术（心、肝、脾、肺、肾）**：掐诀按琴，琴弦一震传出五道音浪波纹，虚空一按令王林五脏剧痛、开始碎裂。王林凭空灵中期修为与古神之体扛下，速度反而更快。
3. **仙人血脉之力**：淡金色光芒幻化，仙人血脉威压笼罩八方。

### 王林的连环杀招（讲究心机与时机）
- **一拳（道吉头颅 + 古之三族虚影）**：上空道吉头颅幻化、古之三族虚影融入一拳，化千丈拳影轰下，与五脏神通波纹对撞，仙妃喷血后退，王林亦嘴角溢血。
- **李广之弓（震慑用）**：仙妃首次欲施仙人血脉仙术时，王林取出曾**轰杀掌尊**的弓，拿弓非为射出，只为震慑，逼其放弃一切神通急速逃遁；随即挥手令弓箭消散。
- **一字「定」**：仙妃身子一顿，虽凭仙人血脉立刻挣脱，但这一顿足够王林追至。
- **白凡仙术 → 阴月有睛**：狂风、黑龙、无尽雨水、山崩与虚幻大地碎裂只是起手，目的是推出最后一式「阴月有睛」——星空中现出血月映照仙妃，其绝美容颜被撕开，仙妃转为怨毒死战。
- **役灵印**：正面对撞后，王林再出役灵印巨掌印直奔仙妃。
- **传音道破天机**：「仙罡大陆之修，七道宗宗主的侍妃，你当王某不知晓这一切么」——仙妃全无准备之下心神剧震，神通下意识一顿，对此等修士而言是致命破绽。
- **血剑一斩**：血光如斩天开地，与役灵印同至。

### 结果
- 仙妃惨叫，身子一颤，**直接崩溃、形神俱灭**。
- 死前仙妃终究施展了仙人血脉神通，虽被役灵印遮盖，爆发之力仍传入王林体内，令其连退百丈、再度喷血。
- 王林评价：杀一人自身亦受伤，但值。

### 仙妃的心理
- 她极度珍惜性命，远超此地一切修士——因为她自知**不属于这里**，「这里只是一座洞府」，她的身份远超所有洞府之修，故越发畏死。
- 战前她已生出「与王林厮杀自己必死无疑」的恐惧。

## 三、黑衣老者偷袭与因果阵

### 偷袭
- 王林喷血调息之际，远处一道剑气穿身而过，横扫星空撕开巨大星空裂缝。
- 偷袭者：**当年参与围杀王林的另一位空玄大能——黑衣老者**，手持乌光之剑，认定「他此刻受伤，正是杀他的最好时机」。

### 化雾吞噬回复
- 王林退后化作**黑色雾气**，冲入正在厮杀的界外修士大军，雾气弥漫方圆万丈。
- 凡被笼罩者尽皆凄厉死亡，只剩被吸干生机与血肉的骸骨；数息间**上万界外修士**崩溃。
- 借此吞噬，王林**伤势恢复大半**，随即重新凝聚身体。

### 因果阵两段式
1. **第一段（承因）**：右手上掀祭出「因果阵」所化的**不动转轮**，立于身前推出，硬撼黑衣老者斩下的一剑。剑气崩溃、老者倒卷喷血；不动转轮亦四分五裂。
2. **第二段（果起）**：王林毫不心痛，长笑掐诀——「**因果阵成，你之一剑，便是我阵之因；此刻阵碎化作无数，便是因果之终。因果阵，开**」。
   - 崩溃阵法化作**五万道因果混沌之气**，横扫八方，每一道瞬息改变形态，**尽数变成黑衣老者之前斩下的剑气**。
   - 王林大袖一甩，五万剑气散开轰击四周界外修士，**五万界外修士崩溃死亡**。

## 四、要点提炼
- 王林战法核心：**心机 + 时机**。以弓慑敌、以言乱心，两次均精准打断仙妃的仙人血脉神通。
- 因果阵机理首次具象化：**敌人的攻击即为「因」，阵破即为「果」，破碎之阵可将敌招复制放大万倍反噬全场**。
- 此战确认仙妃为「本尊」而非当年的虚幻之影，是来自**仙罡大陆**的真正仙人。

# 第1659-1660章 决战（三·四）：天皇炉镇压 · 三阵重凝

## 一、斩击界外黑衣老者（空玄初期）
王林踏前一步，穿透崩溃的因果大阵直奔黑衣老者，冷言「仙妃难杀，但杀你一个空玄初期，还是不难」。

连环三道：
1. **生死道**——左手为生、右手为死，生死二气在老者身前相撞轰鸣，老者喷血后退。
2. **真假道**——王林闭双目，「闭目的一刻，天地一切都是虚假」，直接从老者施展的神通中穿透而过，瞬息临身。
3. **因果道**——右手按在老者胸口，五指内扣、猛地外拽，抓出其本源气息，睁目握拳捏碎老者部分本源。

收尾：左手虚空一挥开启**储物裂缝**，取出**所有七彩钉**掷出，七彩之芒尽数刺入老者胸口，老者眼露恐惧、口溢鲜血急退。

## 二、战场全景（罗天星域星空）
- **蓝衣仙妃**：化蓝云弥漫，甩出蓝色彩带卷向王林；**青霖**紧随其后（此前三人厮杀，仙妃强行走出二人围攻直扑王林）。
- **召河紫衣女修**：如罗刹般连杀数个空涅大能，正与最后两个阴沉之人交战。
- **老妪（第三名仙妃）**：与**红杉子**厮杀，红杉子明显不敌，但死死拖住对方。
- **伤亡**：界内修士死亡诸多；界外死亡已超**十多万**，嘶吼杀戮之声弥漫整个罗天星域。

## 三、天皇炉镇压（本章核心）
王林判断：**界外这几个空玄大能不死，战斗便不会结束**，遂转身、眼露疯狂。

- 眉心**吉神星点**内幻化出**天皇炉**，向外一扩笼罩四周星空，把仙妃与黑衣老者一并包裹。
- 天皇炉散出柔和之气，先将随仙妃而来的**青霖推出炉外**，随即吞噬黑衣老者与仙妃并骤然收缩。
- 天皇炉难以炼化二人，嗡鸣之下几近崩溃碎开。
- 王林盘膝坐于炉顶，**喷血落在炉身**；一点眉心，**古神星点**全部飞出一一落于炉上。
- 眉心中**仙人不灭体所化的金色鲜血**飞出，被其按下与炉融合，天皇炉爆发**万丈金光**。
- 宣言：「以仙人血脉，以古神血脉，融天皇炉力，**镇压你二人万万年**」。
- 自创神通**流月**化作巨大**石门**压在天皇炉上，石门一出**岁月急速流转**——以王林此刻修为，足以推动此术流转岁月无尽。
- 王林额头泌汗、双眼通红，向天地低吼。

## 四、请援与布阵指令
王林点名请**青霖、红杉子、召河前辈**三人联手拖住最后两个空玄大能，为自己争取时间**布置生死因果真假大阵**。三人点头照办。

## 五、王林的动机与判断
既然这场战争是**七彩道人**与**战老鬼**的游戏、是二人为某种目的而必须进行，王林便毫不在意，宁可让界外之修**全部死亡**以此结束战争——「去看看这两个人，到底是在寻找什么」。

## 六、第1660章：三阵重凝
- 王林身后已存在**近十万头颅**，凄厉嘶吼与星空战场的杀戮之声交融。
- **生死阵成，因果阵散**。王林坐于天皇炉上，右手一握，身后飞出**五万头颅**急速旋转化作巨大漩涡，轰然转动成为**不动转轮**，**因果大阵**再现。
- 「睁目为真，闭目为假，真假道成，真假大阵」——剩余**五万头颅**全部飞出，在其面前形成又一漩涡；此漩涡处于虚幻与真实之间，似不存在于这片星空，扭曲模糊，真假本源气息急速扩散，片刻成型，**真假大阵**轰轰出现。

## 关键结论
- 三大道（生死道／因果道／真假道）在本战中被王林连贯组合使用，构成其正面击杀空玄大能的战法主轴。
- 天皇炉 + 仙人血脉 + 古神血脉 + 流月石门 = 一套「不杀而永镇」的封印组合技，用于处理难以直接炼化的空玄级敌手。
- 十万头颅为生死／因果／真假三阵的共用阵材，五万一组分别撑起因果大阵与真假大阵。

## 概述

界内对界外的决战终局：王林祭出自创最强神通「本源之轮」，以四圈转动将罗天境内数十万界外修士尽数轰灭，只余一名仙妃破界逃生。战后界内元气大伤，王林宣告「最后的三年」由他独自守护。

## 一、三大本源阵法成形

- 王林右手一指星空漂浮的生死漩涡，生死、真假、因果三大漩涡转轮急速凝聚、彼此重叠。
- 三大虚之本源阵法完全呈现。王林言明：**需一万界内同道自愿献出元神**，成为三大本源阵法之灵，推动本源转轮，改变天地星空轨道、扰乱星辰运转，轰杀此地所有非界内之人。
- 话音落下，界内一万修士毫不犹豫盘膝而坐、元神出窍，数息间坐镇转轮。
- 三轮轰鸣转动，**由三化一**，膨胀为几乎齐天之高、无尽大小的巨大车轮，散发生死、真假、因果本源之力：一转则天地轨迹改变，一动则星空可崩溃。
- 定性：**王林自创神通中最强一式**，三大本源融合而成，此生只能凝聚一个，绝无第二。

## 二、四圈转动（战况推进）

| 圈次 | 推动者 | 战果 |
|---|---|---|
| 第一圈 | 一万界内元神（阵灵） | 组成星阵的修真星崩溃，星空生机被抽尽；数十万界外修士近三成碎体骤死。一万元神随即全部黯淡无力 |
| 第二圈 | 界内数万修士元神（含木冰眉），全体盘膝元神飞出 | 界外修士又有三成直接崩溃死亡，血流成河 |
| 第三圈 | 青霖、红杉子、召河紫衣女子、清水 四人元神按动 | 星空真正崩溃如碎片横扫，已远遁的界外修士在逃亡途中被轰碎 |
| 第四圈 | 王林掐诀、元神飞出亲按 | 融合王林与所有界内之修全部元神，惊天横扫；无论身在罗天何处的残存界外修士全部崩溃 |

- 第二圈后余下界外修士恐惧至极、四散疯逃，不敢也无法反抗。
- 与青霖三人厮杀的两个空玄大能（那老妪与最后一个仙妃）骇然挣脱围攻、瞬息远走。
- 第三圈后转轮尚有余力却无法自行完成第四圈，故王林亲自出手。

## 三、结局与生还者

- **当年围杀王林的老妪**：第四圈横扫下身子一颤，烟消云散、形神俱灭。
- **最后一个仙妃**：凭其在仙罡大陆上的损命神通，提前一步破开天地、撕开裂缝，面色苍白走入，成为唯一幸存者。
- 界内：无数元神萎靡归体，回体一瞬齐齐喷血、纷纷重伤；王林同样喷血。

## 四、王林的复盘（力量代价与前提）

- 三大本源所化转轮对王林负荷极大，**纵是古神肉身亦无法承受**。
- 若非数万界内修士共同抵消负荷，他转不动本源之轮。
- 若另外三个空玄大能未被他或杀或困、一旦联手反抗，他也无法让界内之人共同推动此轮。

## 五、尾声

- 王林带着疲惫从**天皇炉**上站起，携天皇炉与本源之轮化作长虹远去。
- 留话：「**三年，最后的三年**」「你等修养三年，我来守护。」——界内进入三年休整期，由王林独自守护。
