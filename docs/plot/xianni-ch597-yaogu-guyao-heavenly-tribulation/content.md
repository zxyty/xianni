# 第597章 妖鼓

## 一、天劫压顶，燕京崩毁

- 王林于成为废墟的燕京直面天劫，天空红云剧烈翻滚，分三次下压：**三寸 → 八寸 → 一丈**。
- 每一次下压，破坏逐级升级：
  - 三寸：大地砰砰碎裂，王林全身泌血、骨骼挤压作响，双腿陷入地面至膝。
  - 八寸：燕京地面被生生压碎，环形气浪波及小半个天妖城，王林只剩小半身露在外面。
  - 一丈：整个天妖城化为飞灰，大地龟裂四分五裂；王林喷血、彻底被埋入地底，只留深坑。
- 天威并非只压肉身，还直落心神——王林元神中如有威严之声咆哮。王林一语不发，抬头直视。

## 二、五名古妖后裔老者

- 五道气浪破开十丈高度，冲出**五个白发苍苍、双目妖异、赤上身、干瘦而带蛮荒气息**的老头子。
- 他们在天威下不但无不适反而狂笑，彼此争执『老祖宗』留下的说法（『天威压身舒服』/『天道是个小娘皮，不想被她压就要把她压下面』/『典籍看了百遍没这话』）。
- 自称：**「老子身为古妖后代，古妖不在法界之内，超脱天道束缚」**，遂全身妖力纵横覆盖天妖城，直冲红云。
- 结果：连续三次被无形大手般的天威拍落，砸出五个深坑，仍爬起破口大骂『你毁我天妖城，老子跟你拼了』。

## 三、妖鼓之声：古之一族的来历（关键设定）

幽幽之声在王林心神中回荡，交代了逆修者与天道的三层关系：

| 类别 | 定义 | 天劫态度 |
|---|---|---|
| 顺修 / 避劫逆修 | 顺天道，或心存避意 | 不引天劫；心存避意者『不再是逆』 |
| 第一类逆修生灵 | 宇宙初开、与天道同岁的**「古」之一族** | 天劫无法毁灭，天威无法屈服 |
| 第二类逆修生灵 | 古族分裂后的**古神（以力证道）/ 古魔（杀戮变天）/ 古妖（神通灭道）** | — |
| 第三类逆修生灵 | 不躲避、选择**迎战**天道者（王林所属） | 天道不允许其出现，会将其拣去 |

- 『别人问鼎，或顺、或避，不会引下天劫；而你选择直接面对，所以天劫自然降临。』
- 王林并非第一个，也不会是最后一个。

## 四、妖鼓中的古妖自述

- 身份：**「我，是古妖」**，但**不完整**。
- 苏醒即在**妖鼓**内；**妖鼓之皮便是它当年之物**；无数年来无法离开妖鼓太远。
- 以神通制作了**龙潭**，教化子民。
- **妖灵之地其余八个妖郡同样有类似存在**，方法相同（造龙潭、教化子民）。
- 彼此沟通无数年却无法统一想法：每一个都想**吞噬对方**使自己强大——这或许是唯一让它们完整的方法。
- **妖灵九郡无数年的战争由此而来**；修士的出现使这场无胜负的战争出现倾斜，这也是修士能在妖灵之地存在的原因。

## 五、交易

**古妖给出的条件**
1. 修复王林身体；
2. 帮其渡过天劫；
3. 在天妖郡内给予足够权利。

**王林需付出**：帮其**取回其他八郡的圣物**。

**选中王林的理由**：
- 王林不是妖灵之地第一个逆修者，但是**第一个以凡人修炼古神者**；
- 其身上有**古神的气息，很淡却很纯正**；
- 被古妖教化之人与其非同族，肉身无法承受其力量；修士肉身稍好但也有限，只有极少数能勉强接受——**王林比所有人都合适**。

**王林的回应**（沉默许久后，平淡）：『修复我的身体，给我可以对抗天劫的力量。』——古妖答『如你所愿』。

## 六、肉身重塑与妖影出世

- 浩淼之力覆盖王林肉身，经脉重新连接且**比以往更坚韧**，骨头重聚且**强度高出数倍**，血肉瞬间复原。
- 仙力顺经脉流转全身；那股浩淼之力随后**收缩进入王林体内**。
- 王林自深坑飘出：长发无风自动、双目合上，散发出无法想象的**妖力**；天地压力对他仿佛失效。
- 背后妖力凝聚成**高约百丈的虚幻之影：头生双角、气息阴森、皮肤紫黑**，其现身令红云咆哮雷鸣，好似妖孽出世。
- 五名老者齐齐一怔，盯向深坑：『这……是老祖宗的气息』。
