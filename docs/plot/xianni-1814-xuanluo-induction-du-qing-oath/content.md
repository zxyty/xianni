# 第1814章 玄罗的感应

## 一、金印收入体内

- 王林见识金印之效（震慑杜青），目内精光一闪，张口一吸，金印化作金光没入其幻化于巨大火球之上的面孔口中。
- 金印消失，金光散于天地。王林淡淡一句「不送」。
- 杜青直至亲眼见金印消失才暗自松气，退后数步意欲速离——他一路追击屡遭震撼，最终被金印上的**大天尊气息**吓退，早已放弃拼杀。

## 二、杜青的转念：从退走到攀附

退出百丈后，杜青忽然驻足，心思剧转：

1. 此人背景极深，且拥有**大天尊所赐法宝**；
2. 若能借他得大天尊指点，修为必增；
3. 一旦跟随，便有了背景，再不必顾忌**大魂门**、不必把宝贝好东西第一时间送去大魂门；
4. 若**天牛洲**其他宗派得知此事，必疯狂争抢、奉为上宾——因此**此秘密必须由他一人独占**；
5. 至于背后是哪一位大天尊，杜青认为无所谓。

> 细节：杜青为木头身体，本无心脏，此刻却隐隐听到「心脏怦怦加速」之声。

## 三、杜青的托词与誓言之符

- 杜青抱拳堆笑，信口开河：称自己早觉**苍龙宗**山门破旧、想毁掉重建，正巧王林出手「帮忙」，追上来实为道谢。
- 王林似笑非笑，显然看透。
- 杜青毫不尴尬，反怕王林不信，抬手指天立誓：「**仙罡法则在上，在下今日为道友护法，若是存了半点歹毒之心，必叫天雷诛灭，道统崩溃，灵魂消散**。」
- 其右手浮现**红色符文**（仙罡大陆的**誓言之符**），内蕴誓言，化红芒直奔天空消失。

### 设定要点：誓言之符
- 仙罡大陆特有；一旦用出，**极少有不遵守者**；
- 由冥冥之中的**仙罡法则**作为见证；
- 违誓代价：天雷诛灭、道统崩溃、灵魂消散。

## 四、王林的将计就计

- 王林「大有深意」地应允：「也罢，你既有心，我便给你一个护法的机会。」
- 杜青大喜——他最怕的正是前番误会引起王林戒心，那便断了求造化之路。遂退至数百丈外盘膝坐于天空，神识轰然散开笼罩四周，唯独**刻意不让神识进入王林身边**，以安其心，并称「老夫拼了性命，也要保得道友安全」。
- 王林内心冷笑，判断清楚：
  - 杜青被金印震慑，目的是金印背后的大天尊；
  - 自己**初来仙罡大陆**，很多事非搜魂可知，正需这样一个人在旁；
  - 关键在于「**是他自己贴上来，不是我主动要求**」——对方有所求，王林便占据主动。

## 五、结果：三日吞噬火焰本源

- 王林面孔自巨大火球上慢慢隐匿消失，闭目修行；分出一丝神识在外提防杜青。
- 杜青严守誓言，紧密防范四周，意在好好表现以抵消前嫌。
- 时间流逝，转眼三天，王林身体在火球内**急速吸收火焰本源**。

# 王林融地火脉本源凝朱雀 · 玄罗感应金印

## 一、天牛洲：火球吞本源

### 所吞之物
- 火球乃地火脉的一条**子脉**所化（非支脉），故吸收缓慢。
- 其内蕴合**火本源之力**，极为磅礴，隐隐有**法则**在内。
- 此法则即**火的意志**；王林要吞的不只是火本源，还包括这份意志。

### 进程（按时序）
| 时点 | 火球状态 | 要点 |
|---|---|---|
| 三日内 | 外围十六条火龙逐一消失 | 被火球融合，火之意志开始扩散，杜青最先感受到，神色一正而不语 |
| 第五日清晨（初阳驱散黑暗一刹） | 爆发惊天巨响，急速收缩至**十丈** | 火焰扭曲，浑浊中隐见王林身影，身边似有一条朱雀回旋，朱雀嘶鸣回荡天地 |
| 其后数个时辰 | 缓慢收缩至**七丈** | 内中火之意志轰然爆发，笼罩天地，隐隐要与大地地火脉意志抗衡——天牛洲一时并存两种火的意志 |
| 随即 | 七丈骤缩为**三丈** | 王林身影一晃，自火球内走出 |
| 王林出球后 | 三丈再缩至**一丈** | 王林白发飘动、盘膝而坐、神色凝重，双手掐诀一指；一丈火球内可见一尊缩小许多的朱雀急速回旋，朱雀之音不断散出 |

### 杜青的观察与判断
- 「不愧是被**大天尊**赐予法宝之人，其火本源竟可抗衡此地火的意志。」
- 见一丈火球后骤生念头：**那朱雀就是王林的火本源之身**；他把地火脉的一切本源力量尽数送入朱雀体内——
- 「莫非他要**凝聚本源真身**？」杜青倒吸口气，骇然、难以置信。

## 二、设定：仙罡大陆的「本源」体系

- **本源一出**，修为可入**第三步空境**；以本源之力吸收天地浩荡，战无不胜。
- **实之本源**往往比较好获得；但修为若想达到**空玄**，必须亲自感悟出**虚之本源**的变化。
- **本源越多，实力越强**——此为仙罡大陆修士皆知之事。
- **层次递进**：本源出现 → 凝聚**本源法器** → **本源大成**，需一一走过。
- 传说中有天骄之辈，可推动本源在大成之后**再次壮大**，最终凝聚出**本源真身**。
- 本源真身颇为少见，一旦出现强大得可怕。杜青一生仅在**大魂门老祖**身上见过一个**魂之本源真身**，再无第二个。

## 三、仙罡大陆 · 天空郡：玄罗睁眼

- **疆域**：仙罡大陆古国三十六郡中，**道古一脉占据十二郡**；其中**天空郡**内即道古一脉**皇族所在**。
- **地貌**：天空郡有一处青山绿水之地，树叶纷飞、河水哗哗；落叶深处隐见一座**高耸入云的青色祭坛**，充满沧桑气息。
- **人物**：祭坛上有一**黑衣青年**盘膝打坐，看似年轻却给人万古岁月在身之感，似已存活很久很久——他就是**玄罗**。
- **触发**：王林在天牛洲取出**金印**的一瞬间，本已闭关的玄罗**突然睁开双眼**，面露微笑：「他来了。」
- **内心断定**：他所选择的弟子必定不会死在虚无中，一定会来到**仙罡大陆**。

## 四、要点提炼

1. 王林的火本源已凝出具象化的**朱雀本源之身**，并正冲击极罕见的**本源真身**。
2. 其火之意志强到足以与一洲地火脉意志分庭抗礼，侧证其本源层次远超常修。
3. **金印**是玄罗与王林之间的感应信物/因果纽带；金印现世＝师徒线正式接上。
4. 天牛洲线（本源）与天空郡线（玄罗/道古皇族）在本章并行推进，指向王林后续入道古一脉的走向。
