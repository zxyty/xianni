# 仙逆 第1362章 天道使者再现！（第九卷 云海之巅）

## 一、征兆再现：太古星辰群雄仰望

- 蓝梦道尊面色阴沉望天，目光似能穿透虚无，断言「远古仙妃所说的征兆，再次出现了」。
- 同一瞬间，太古星辰几乎所有第三步大能纷纷色变抬头。
- 存在于太古星辰、由远古仙域分裂出的那一部分（所在罕有人知），亦有数名女子从闭关中睁眼看向上方。

## 二、拓森的癫狂与「同族气息」

- 蛮荒星域内，拓森红着双眼疾驰，右手疯狂捶打眉心，咆哮：「想奴役本神，你在做梦……本神高贵万灵之巅……要夺我魂魄，痴心妄想，给本神滚出来」——其体内显然另有意志相争。
- 征兆出现刹那，拓森动作全停，血目死盯星空：「同族的气息……我隐隐似乎认识他……不，是涂司认识他。」
  - 关键线索：拓森与涂司（古神）之间存在记忆/身份的交叠。

## 三、夺雷对峙：王林 vs 漩涡内的存在

- 王林双手死抓不灭雷霆，那如惊雷般的声音出现时非但不松，反而更狠地外拽。
- 王林回应：「不管你是谁，这不灭雷霆，是我之物。你若再冥顽，休怪王某狠辣。」
- 对方震怒，星空轰鸣，漩涡内闪电狂走。王林冷评：「若我火之本源大成，单单你这滔天怒火，我就可以让你反噬，不死也要重伤。」
- 王林凭一身古神之力，把融入漩涡的那截雷霆一点点拉出，几近全部脱离。

## 四、天道使者现身

- 那存在斥王林为「叛空灭道、被空罚的古神一族后代余孽」，称若非其身上气息熟悉早已将他灭亡。
- 漩涡中心崩溃，黑气化作两只巨掌撕开缝隙，缝隙内漆黑一片，一只弥漫雷霆的粗糙手臂伸出，星空随之崩溃——仿佛它不该出现在这世界。
- **王林认出这手臂**：一千多年前，在朱雀星上，正是这些人从他手中夺走了李慕婉的魂魄。他凄厉大喝：「是你们！当年在朱雀星上，从我手中夺取婉儿魂魄的，就是你们，天道使者！」

## 五、一剑斩天

王林一生唯有一道逆鳞——凡涉李慕婉，冷静必崩。他毫不犹豫松开雷霆，直扑手臂：

1. **古神虚影**：全身古神之力爆发，修为疯狂燃烧，身后幻化庞大古神虚影；漩涡内传出震惊之声「这……这是涂司」。
2. **火**：左目瞳中蓝色火焰宣泄，化蓝色朱雀成形长鸣，火海弥漫方圆无尽。
3. **雷**：右目雷光一闪，本源印记幻化，下方徘徊的庞大雷龙直扑而来，与朱雀龙凤交错。
4. **战**：血剑出现，膨胀成百丈被握于手；古神虚影手中同现数千丈血剑虚影。
5. **融合**：古神之力、蓝色火海与朱雀、庞大雷龙尽数被吸入血剑，加上眉心规则之星旋转，战意滔天，向前狠狠一斩。

**战果：**
- 下方圣地瞬息崩溃成碎末；远处十六颗修真星被冲击推开，改变了运转轨迹。
- 手腕现血线，手掌从手臂上分离落下，鲜血喷洒；漩涡内传出闷闷惨叫。
- 剑势不散再扫漩涡，漩涡只是转速更快、形成凹陷，毫发无伤；残臂与漩涡随即消失如从未出现。
- 王林追斩落空（斩空）。消散前那存在惊问：「你怎么会拥有这把剑，这把剑……」

## 六、立誓与收雷

- 王林神色狰狞立誓：「早晚有一日，我王林将破开天地杀入上去。你等当年在我尚未道成之时收我妻之魂，使她最终落得如此下场，此仇不共戴天！」——这是他来到太古星辰后第一次真正意义上的愤怒与疯狂。
- 变故太快，不灭雷霆尚未来得及钻入漩涡，漩涡已散，此雷再无可遁之处。
- 不灭雷霆此前被七百万天所化七尺长剑重创，又受王林发狂波及，极为虚弱，似有神智般急退。
- 王林缩地成寸拦在其前，右手一抓擒住，张口一吞，雷霆入腹。

## 七、王林的下一步盘算

> 「炼化此雷，炼化八条太古雷龙魂魄，搜刮大长老元神召唤伴随之雷，我雷之本源，大成！修为可增！」

- 三重雷源：不灭雷霆 + 八条太古雷龙魂魄 + 闪雷族大长老元神中召唤伴随之雷。
- 目标：雷之本源大成，修为大增。（另伏笔：火之本源大成亦在其规划中。）

## 八、伏笔与因果

- 天道使者 = 朱雀星夺李慕婉魂魄的元凶，正式确认，构成王林「杀上去」的终极动机。
- 血剑来历成谜：对方惊问「你怎么会拥有这把剑」。
- 涂司之名两处呼应：拓森感应「是涂司认识他」，漩涡内见古神虚影惊呼「这是涂司」。
- 王林被定性为「被空罚的古神一族后代余孽」，其古神血脉与「空罚」旧案挂钩。
