# 第1672章 古族战印

## 一、九棺合体：道古气息的无名中年男子

- 九个棺木在太古星辰战场依次爆开，封印之物逐一显露：
  1. 第一棺：赤红色左臂，长满红毛，形似兽臂，狰狞五指、锋利指甲，出现即爆发惊天凶焰，凶焰同源于**道古气息**。
  2. 第二棺：右臂，红毛摇曳，皮下青筋鼓起蠕动。
  3. 第三、四棺：两条散发道古气息的腿。
  4. 第五至第八棺：被分为四份的无肢躯体，诡异融合成一具漂浮星空的巨大躯体；双臂双腿呼啸而来接上，形成**无头的完整肉身**，约千丈之高，凶焰滔天，被属于**道古烨寞**的气息浓浓环绕。
  5. 第九棺：头颅飞出，四周蔓延的无尽黑发齐齐卷向脑后，铺展如扇。
- 头颅为一中年男子，闭目、相貌平凡却威严骇人。**眉心有两个吉神之星**——与王林所见的一切古神之星完全不同，远看更像两滴鲜血烙印。
- 头身相接的刹那完整肉身成形，男子睁眼：两道奇异之芒使星空欲崩，恐怖威压轰起。**左眼内三颗妖星，右眼中三颗魔星。**

## 二、王林的判断

- 「他是谁？」——王林的**道古传承记忆内没有此人任何线索**。
- 确定此人**绝非道古左眼**：气息虽强悍，但显然无法与道古左眼媲美。
- 关键区别：王林身上的道古气息是**传承而来、与自身融合**，是道古但**不是烨寞的气息**；而此男子散出的感觉**属于烨寞**，且精纯至极。

## 三、掌尊的算计（太古星辰）

- 掌尊以神识遥望战场。九棺封印之人是其**长尊会的至宝之一**，为他与**七彩道人**在无尽岁月中多次搜集、最终凝聚而成，为此掀起过一次次杀戮。
- 此物对掌尊的未来有大用，不到万不得已不愿取出；此番为**逼出王林的两弓之力**，才交给太古星辰之修去轰杀王林。
- 掌尊评估：「他尽管还不完美，**还差一滴**……但他们都是传承道古，**自相残杀之下引动的天变，或许可以让这阵法出现裂痕**。」

## 四、支线：罗天星域尘埃中的冰封世界与女古神

- 罗天星域深处有一片苍茫无边、无任何修真星、无一丝生机的区域，其中弥漫无尽肉眼不可察觉的尘埃；**一粒尘埃内另有乾坤**。
- 该乾坤是一片**冰封的世界**，大小无尽，一切（包括云朵与大地）皆被寒冰封住。
  - 此处是**往昔的东临星所在**；
  - 此处是**罗天星域唯一的远古修真家族**所在；
  - 此处有一个**女古神**。
- 界内界外大战波及四大星域，战火却未烧到这里——该家族传承至远古，既能避开岁月中一次次毁灭，也自有办法在此战中独善其身。
- 冰封世界一处祭坛山峰顶部，美貌女子盘膝而坐，**眉心七个古神星点缓缓转动**。九份合体的瞬间，她睁眼遥望：「我感受到了**父祖血脉的气息**。」
- 她抬右手一点眉心，七星旋转加快、连成一片继而诡异融合，**七星合一化为一滴血液印记**，散发赤红妖异之芒。

## 五、古族战印：规则

源自王林的道古传承记忆——此印在**古之三族**中、亦即**道古所在的吉国**内至高无上：

1. 名为**战印**，是古族之间相互交战时必须祭献出的印记；
2. 一旦有古族之人施展，**被其所指之人必须接受这场战斗**；
3. 这是**生死斗**，一旦死亡则**以古祖为冥**，败者的一切都将属于战胜者；
4. **见此印而不战，则不配称之为古族之修**——此点与仙人完全不同，此印一出必须要战；
5. 唯一例外：**双方修为相差悬殊可避战**；若修为相差不多而不战，则在古族中便是弱者，而**弱者无法生存**。

该印本身**没有任何攻击之力**，更像一个象征性手印；掐出后收回右手按在胸口。

## 六、应战与第一拳

- 中年男子咆哮、右手遥指阵法内王林，掐出战印按向胸口，双眼战意滔滔，静待王林选择。
- 王林沉默片刻后战意轰然爆发，右手一指对方，同样掐出古族战印按向自己胸口——**应战**。
- 王林的动机：一生皆在战斗杀戮中度过，没有道理也不会拒绝；他要战胜对方、**获得对方的一切**；对方身上的道古气息，对**王林的古神星点达到八星**有致命吸引力。
- 王林**第一次走出转轮阵法**，立于太古星辰的星空中，身体疯狂膨胀：十丈→百丈→数百丈→**千丈巨人**，与对方同声咆哮。
- 战斗方式：**古族交战以肉身为主、神通辅助**；吉族修士肉身达到一定程度后，**天地朽而身不朽，天地灭而身不灭**。
- 对方一拳轰至不足百丈，王林同样握拳轰出，两拳相撞——一声**震动界内、传遍界外**的惊天巨响如风暴般轰鸣，狂风倒卷，吹动王林的白发与对方的黑发，二人目中战意明亮如阳。

## 七、阵法内

- **西子凤**面色苍白望着阵法外，却不发一声，不愿让王林分心；沉默中低下头，**继续为王林温酒**——她相信王林不会败。
