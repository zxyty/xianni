# 第七卷 名震罗天 · 第691章 离去

## 一、孙泰之死

- 孙泰于榻前燃尽最后一丝寿元，神色安详。临终听到王林的承诺，深深看了王林一眼，把这个与自己恩怨纠葛之人再一次记在心里。
- 弥留之际眼前恍惚，回到几百年前**雨之仙界**的一幕幕画面，最终定格在王林平静而略显苍老的容颜上。
- 遗言：「生死之间，原来是如此的短暂。」随即含笑闭目。身上死气一瞬浓郁至巅峰，下一刻烟消云散。
- 王平痛哭唤「孙爷爷」；王林轻叹抚其头，眼中平淡——看破生死、看透轮回，如烟丝浮云，看到了却不留在心里。

## 二、葬礼与空墓

- 葬于**落月村后山**，村中死者共同的安葬之地。
- 墓碑由王平亲手所刻：碑文「孙泰之墓」，落款「义孙王平」。
- **墓中无尸**：孙泰尸身已化为一坛骨灰，收在王林储物袋内——这是王林对孙泰的承诺。
- 义孙名分来历：王平十二岁那年孙泰收其为义孙，王林未阻止（孙泰年长，足以为王平之爷爷）；而王林与孙泰之间实为平辈，孙泰骨子里对王林怀有敬畏。

## 三、修道之争（孙泰死后一年）

- 孙泰曾借义孙之便**暗中传授王平修道之术**，违逆王林的意愿；为传法动了生机，因而**提前四年归去**。此事瞒不过王林的神通。
- 院中父子对坐雕刻。王林授艺：「雕刻，要用心去下刀，每一刀，都是刻画在了记忆中，只有如此，才可以称得上匠师之称。」
- 王平所雕木雕是**孙泰**：一脸傲色、双目望天、双手各结印诀、诡异气息凝聚、脚踏朵朵云层，虽粗糙却得神韵三分。
- 对话要点：
  - 王平问为何不许学孙爷爷留下的仙人法术 → 王林答「因为修道的人生，不适合你」。
  - 王平坦白：孙爷爷所传口诀，他**从未修炼**（王林早已知晓）。
  - 王平问父亲是否仙人 → 王林：「算不上仙人，只是一个修士罢了。」
  - 王平试探「如果平儿不愿呢」——十六年人生中第一次如此对父亲说话；王林只平静注视，最终以「此事不要再提」定音，语淡而坚定，双目深处闪过极浓的悲哀（王平看不到）。
- 王林让王平**吃药**后入睡，并留下承诺：「除了修道，这世间之事，我可以全部给予你。」
- 王平顺从，接受平凡一生；黑暗中王林独坐院内，悲哀再闪。

## 四、离村（孙泰去世三年后 / 入村第十九年）

- 王平十九岁，已是俊朗青年，相貌愈发肖似母亲**柳眉**；王林则更为苍老，十九年岁月在脸上留下深深痕迹。
- 王林收起家中之物，带王平离开落月村。
- 村中人事：十九年生老病死，当年邻居十人已去三四；周家大汉身子仍硬朗但不复年轻，与王林感慨叙别、互道保重。
- 送别场面：与王平一起长大的童年伙伴多为女孩，目光幽怨，尤以**周家二姑娘周若彤**为甚。王平对女色看得极轻，答「应该不会（回来）了」，女孩哭喊「我恨你王平」。
- 父子远去，王平抱怨「这些女孩为什么这么麻烦，尤其是那个周若彤」，王林大笑反问他是否不喜欢周家闺女。

# 第692章 升华：八年游历与灵魂洗涤

## 一、地点背景：冉云星
- 冉云星海水占据很大范围，但陆地上名山苍峰也不少。
- 多年前的那场浩劫使冉云星灵气不再浓郁，但相比当年的朱雀星仍要略好一些。
- 有一条环绕了大半个冉云星的大河，河流最终汇入大海。
- 落月村旁有祁连峰（高大，峰顶飘着无数云层）。王平幼时听人说祁连峰上有仙雾，吸上一口可十年不生病。

## 二、王林的教育方式：不授道法，只涤心灵
- 王林**没有传授王平修道之术**，而是以游历天地的方式给王平心灵以无限冲击。
- 三阶段路线：
  1. **山**（约三年）：攀爬一座座名山，登顶迎风远望；王平瘦弱的身子渐有力量，心灵开阔。
  2. **河**：一叶孤舟在怒浪中前进，游历大半个冉云星的大河，直至大海入口。此间王平笑声频出，王林亦发出罕见的爽朗笑声。
  3. **海**：海船乘风破浪，见天雷轰击海面、堪比一个村子的巨鲸、海市蜃楼。
- 生活方式：渴饮山泉，饿食果兽，累则席地而坐，困则以天为被。
- 内核：王平以凡人之身，从一次次攀越中**传承了王林心神中那股逆天之意**——感受天地浩荡而绝不止步、绝不屈服。

## 三、结果：王平的升华
- 前后**八年**，归来时王平**二十七岁**，稚气尽扫，代之以坚毅；相貌中那一丝妖异被驱除，只剩绝伦俊朗，笑容如阳光。
- 仍是**一介凡人**，但心灵已可容纳天地。
- 王平对父亲的尊重更浓：祁连山虽伟岸高大，却比不过、高不过父亲的脊梁。

## 四、怨气问题（王林此行的真实目的）
- 这八年是王林**想了很久之后想到的、彻底驱除王平灵魂中怨气的方法**。
- 怨气清除进程：
  - 柳眉的丹药 + 王林的神通 → 只驱散大半；
  - 怨气太深，已融入灵魂、根深蒂固；
  - 二十年的平静 → 渐渐缓和；
  - 八年心灵净化、灵魂升华 → 不知不觉中只剩下**一丝**。
- 这最后一丝，**任何法术、任何丹药都无法驱除，只能在轮回中把它抹去**。

## 五、祁连峰顶：仙人掠过与第二次求道
- 峰顶目睹雷雨：雨水拍地扬尘，尘土未升高便被雨淋透、重归大地——似逆天修行之人本欲升天却被天威打落，真正能升天者能有几人。父子二人立于峰上，滔天雨水半点未落身上。
- 雨歇云散，七彩虹横空，七种颜色近观似蕴含天道。
- 一道剑光化作奔雷，穿虹而过：剑光中站着一名**仙风道骨、仙气弥漫的中年男子，脚踏一把青色飞剑（散发寒芒）**。他见凡人能攀至此处，眼露赞赏，轻咦一声，却未停留，直奔远处而去。
- 王平震撼如怒浪，喃喃问「父亲，这便是仙人么」，王林轻叹答「是的」。
- 王平请求修道，王林摇头不语，眼中深处再露一丝悲伤。

## 六、马车上的第二次请求
- 下山后王平一路沉默，经镇子坐上去大城的马车，仍未说一句话。
- 王林望向窗外，眼中悲哀更浓，还有一丝难言的苦涩。
- 王平低头轻声道「父亲，我想修道」——这是他**第二次**说出修道；第一次是十年前，他十七岁那年。
- 王林不收回目光，平静道：「你，不适合修道。」王平追问为什么，王林**如十年前那般**只是平静地望着他，不说话。
- 最终王平低头：「我知道了，父亲。」
- 王林收回目光，眼中的悲哀，王平看不到。（承接第693章「青宜」开篇）

## 七、伏笔与要点
- 王平灵魂残余的一丝怨气「只能在轮回中抹去」——为后续轮回相关情节埋线。
- 王林两次拒绝王平修道，且理由从未言明，只以沉默与悲哀作答，暗示王平体质/命数存在王林不愿说破的问题。
- 王平「即便下一世轮回不再是父子，我也永远不会忘记你」的誓言，与「轮回抹去怨气」形成呼应。

- 其师尊（原结丹修士）面色苍白无血，修为**已从结丹跌落至筑基后期**。
- 红脸老者问「此人真的这么说」；元婴后期的孙家修士（酒楼阻拦者）确认王林原话为「只此一次，下不为例」。
- 青衣长老冷哼，判断：「一眼便可让结丹修士碎丹，一步之下便使得三个元婴修士退步，其修为，怕是达到了**婴变期**」。
- 第三位长老平淡回应：「婴变期又如何，我**孙家老祖**尚在，而且还有**那位前辈**庇护百年，连**千幻星的幻家**都不敢招惹那位前辈，有他在，我孙家便不会坍塌」——此「那位前辈」指的正是王林本人（其百年庇护之诺），构成本章反讽伏笔。

## 六、伏笔与看点

1. 孙家长老低估王林境界（仅推测婴变期），且不知所倚仗的「那位前辈」与酒楼中人是同一人。
2. 王林不让王平修道的真正原因被明确标为唯一隐瞒，为后续「王平的要求」张本。
3. 王平—青宜的感情线起点。

# 祁水城风波：孙家追查、王平三十年富贵之约、孙启明入城

## 一、孙家分支：逼问青宜与逐出族门
- 红脸长老第二次追问神秘修士“姓什么”，下方修士沉默；元婴后期老者苦笑称不知，但看到外姓族人青宜曾与对方有所交谈，或许知情。
- 青宜身子一颤，沉默后摇头称“晚辈不知”。红脸长老以阅历一眼看破其说谎，怒斥“好大的胆子”，青宜仍苦涩坚称不知。
- 红脸长老冷哼起身，作出处置：
  1. 此事暂且放下，已禀告宗族，近日将有家族**婴变期修士**前来祁水城；
  2. 外姓族人青宜“心中有了二意”，**赶出孙家**；
  3. 放言要看看此人凭什么说出“下不为例”这般狂妄之话——在**冉云星**，没有人可以对孙家如此说话。

## 二、祁水城城北：王府易牌与父子夜谈
- 王家大院门外旧府牌摘下，换上王林**亲笔所书“王府”**二字；府内丫鬟仆从一律沿用，冷清之色因此淡了不少。
- 深夜书房，王林与王平对坐：
  - 王林为王平的人生作账：**十九年平凡生活 + 八年山河之貌 + 接下来三十年富贵**，要他遍历喜怒哀乐、富贵贫穷。
  - 王平微笑点破：“这便是不让我修道的补偿么”，王林答“是的”，目光越过儿子投向窗外，升起王平看不到的浓重悲哀。
  - 王林心声：“不是为父不让你修道，而是你**不能修**”——真正的隐秘只能自己装在心里；他也知道王平对修道的执着，以及埋在心底对自己的一丝怨。
- 关于“富贵”的问答：
  - 王平引王林旧训——“人当逆天而行，莫要被这天地所压，遇山则越，遇川则度，遇海则跨，遇这天地，同样绝不屈服”，立志既不能修道，便做**凡人之中的至尊**。
  - 更进一步：“我不要唾手可得的至尊，我要的，是自己打下。”
  - 王林两次平静应允“可以”，随后右手一挥，**身后虚影走出、融入王平身后**，言：“带着此物，这冉云星，你可以做到一切。”
- 王林起身离去，背影蹒跚低落；王平张口欲言终未出口，心中默问：父亲既能给一切，为何独不许修道——“平儿修道，不是为了自己，而是为了**当年的承诺**，为了可以永远陪在你的身边；父亲，你太孤独了。”
- 月下王林回房躺下轻语：“总有一天，你会明白，可是，我希望那一天，来的缓慢一些，甚至，你永远都不要知道，为什么。”这一夜，王平无眠。

## 三、三日后：婴变后期的孙启明抵达
- 一名黑衣、形貌苍老者入祁水城，径直前往孙家分支族部；分支上下修士全部出门恭迎，三位长老见其真容更为恭敬，齐呼“拜见副家主”。
- 其人正是**孙启明**：当年因王林之事在孙家立下大功，加之修为已至**婴变后期**，被**孙析**提拔为下一代家主（副家主）。
- 孙启明不作寒暄，直问“那人，在何处”。
- 其专业判断（家族晚辈不解、他却明白的关键）：
  - “一眼碎金丹”这一手，**他自己也能做到**；
  - 但若真如玉简所记，**不见任何神通**便逼退三名元婴修士——施展了神通尚可解释，未施神通则除**问鼎老怪**外，断不可能出现在寻常修士身上。

## 四、要点与伏笔
- 青宜为护王林（父子）而对婴变级长老说谎，代价是被逐出孙家，恩义线埋下。
- 王林以虚影（护身手段）替代修道之路，给王平“凡俗至尊”的通路，父子间的隔阂与未言明的隐秘（王平“不能修”）成为核心悬念。
- 孙家追查升级：从分支长老 → 婴变后期副家主孙启明亲至，并已把目标层级推测到“问鼎老怪”。
