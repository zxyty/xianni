# 第1897章 绿魔炉！

## 一、至阴之刀显威
- 王林右手血肉间伸出的阴刀一出，绿色空间掀起风暴，八方覆冰。
- 绿袍老者袍子玄妙，寒气被挡在外；两名绿魔使者则神色巨变、连退数步，全身结冰、眉毛成冰，运转修为勉强抵抗。
- 旁白点明此刀潜力：眼下仍属「无主」状态；若王林元神敞开、于刀上留下意念，并借魂铠使修为暴增，则此刀一出惊天地泣鬼神，可一刀幻化出其内蕴含的二十九洲镇压之魂齐出，形成吞天噬地之势——两名绿魔使者根本难以抵抗，即便对上空劫后期亦可一战不落下风。
- 绿袍老者见刀缩回王林掌内，面色红润、双目兴奋，大笑称「如此阴刀，唯有绿魔大人方配拥有」，随即剧烈咳嗽咳血——他年纪太大，已近油尽灯枯。

## 二、清点这具「近乎完美」的肉身
绿袍老者自陈王林肉身此番所得：
1. 体内多了第九道本源
2. 身躯多了韧性
3. 双目多了镇压
4. 体内多了一条仙祖发丝所化经脉
5. 右手骨多了一把至阴之刀

结论：这具肉身已快要完美，但本源真身只有三具，**尚缺一具水本源之体**。老者决意「以我族数万年的准备，为这具身体，凝出第四具本源真身」。

## 三、倾族之藏，凝水本源真身
投入之物（依次）：
- **仙海魂母**：幽色光芒中一团精纯至极的水本源之力，气息强大到令绿色空间泛起层层水波。来历——其族**不惜发动一场战争掠夺而来**，原定于绿魔复活时献出，供绿魔蝎疗伤之用；此刻毫不犹豫取出。
- **凡梦幽水**：黑色瓷瓶中仅一滴水液。其族在岁月中收集凡人之梦、以此种下，历无数年后取大量凡人梦中所梦之水凝聚而成；本是虚幻，却蕴含至极水本源之力。
- **道心融液**、**水仙之血**、**天地水源**等：一一飞出，临近王林时轰然爆开，钻入其凝固的血液中。

效果：王林体内水本源疯狂暴增，那种感觉唯有当年在洞府核心内**虚幻的东临池**中才有类似体验。这些物品每一样都极为罕见，若王林自行搜集至少需千年，有些更已在世间绝迹、无从寻觅。

**献寿**：老者两度咬破舌尖喷血。两口鲜血各含其一族传承之力与**八年寿元生机**（合计十六年），化作血雾融入王林全身，令其水本源疯狂凝聚、血液急速流转。

**成果**：数月后，王林体内爆发惊天水本源气息，**第四具真身——水本源真身**成形。此真身如同沉睡、未融入任何意志，但王林心念一动便可操控，成为天地大能。

## 四、隐忍：岁月造化的比拼
- 王林在这场「岁月年华的比拼」中已赢下一部分，但要继续赢就必须继续等待，不为任何之物心动，拼到最后。
- 此时老者备物已用去近大半，尚余四五样漂浮。老者已不到十五年寿命，却忘记疲惫与代价，脑中唯一念头是亲眼看到绿魔大人降临、绿魔蝎复活。

## 五、绿魔炉起
- 老者大袖一甩，剩余全部物品尽数飞向王林、轰然爆开化作碎末笼罩其身。
- 绿色空间骤然颤抖，四周无数蝎子齐齐嘶鸣、身体崩溃化作点点绿芒扑向王林；空间随之收缩，最终在王林体外化作一个**千丈大小、通体绿色的巨大丹炉——绿魔炉**，内蕴大量绿蝎气息与老者余下的全部罕见物品。
- 目的：**温养炼化王林肉身，完成绿魔大人夺舍前的最后准备，将其改造成完全适合绿魔大人的蝎体。**
- 烧炉：两名绿魔使者奉命盘膝炉旁，双手掐诀，元神自天灵飘起，向炉喷出大量元神之气化火轰烧。

## 六、天地之力灌体，王林仍在等
- 炉内散出一丝丝绿气，从四面八方钻入王林体内；每一道绿气蕴含一股精纯**天地之力**。
- 此力**非古族之气、非仙族气息**，属于绿魔蝎，但同样也属于王林。
- 王林肉身如无底洞般全部容纳，天地之力不断沉积。其元神在**天逆**保护下旁观，眼露激动却生生忍住不去吸收——只要心念一动操控身躯便可吸收，使修为暴增；但他要等更多天地之力融入体内。
- 动机：他已等了一百多年就为这一次造化；若元神提前出现被外界察觉，造化会大幅减少。
- 时间流逝：一年、两年、三年……转眼十年。天地之力几乎占据其全身每一寸血肉，王林仍在等。绿袍老者盘膝炉外，双眼通红，以残躯苦撑，只为看到绿魔复活的一瞬。

## 七、结尾伏笔：三道长虹来临
- 蝎子建筑外、一百多年无人出现的雾气中，三道长虹隐隐闪烁飞临，极为小心谨慎。
- 其内是王林相识之人——**天牛魂铠的另外三人**。
- 旁白：**归一宗宗主的计划，不知为何拖延了一百多年，至今方才重新开展。**
- 此时绿袍老者已毫不在意外来者。
