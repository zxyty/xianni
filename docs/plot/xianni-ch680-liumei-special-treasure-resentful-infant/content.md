# 第七卷 名震罗天 · 第680章 柳眉的特殊法宝

## 一、破万幻天魔道
- 王林元神蕴含上古雷龙、拥天地雷威，柳眉融入其体内的一道道青烟所化雾团无法撼动其元气。
- 王林抬手将雾团捏碎，虚无中传来闷哼，柳眉身影被迫幻化现身，面色苍白、眼含恨意。
- 王林点评：柳眉修为系被强行提升，意境领悟不够，是“拔苗助长”的写照。

## 二、旧怨对质
- 柳眉指控：“我一心向道，可你却以银秽意境之魂破我处子之身。”
- 王林回应：是柳眉出手在前，且意境之魂一事是意外。
- 柳眉笑声转为恶毒——她对任何人都能保持万幻天魔道境，唯独面对王林无法保持心态。
- 柳眉以“你给我一个意外，我也给你一个意外”作为报复的引子。

## 三、特殊法宝：怨婴“厉儿”
- 柳眉拍开储物袋，黑雾冲出，滔天怨气弥漫，天空阴云浑浊、现巨大旋涡，方圆十里如鬼境。
- 黑芒速度极快，神识无法锁定，跃过仙卫直奔王林。王林双指成剑点出，风扫雾散，露出一双浑浊无神、只含怨焰的黑色眼睛。
- 王林心神剧震，涌起水乳交融之感，如数万奔雷炸响，下意识收指后退。
- 柳眉揭破：这是她与王林的孩子，在体内炼化百年炼成怨婴，取名“厉儿”，并在其有意识后不断灌输“是父亲王林抛弃了他”。
- 柳眉自述动机：“你毁我道心，破我意境，取了我清白的身子”，故以此“特殊法宝”相报。
- 王林的反应是彻底的沉默——不同于得知李慕婉复活有望时的震动，也不同于面对藤化元时的疯狂爆发；生机如被抽走，只余死气。
- 王林挥手令仙卫傀儡化作大片阴影将怨婴包裹、阻其行动，随后轻声道“谢谢”，并断言：“你能把他炼成怨婴，我便可以让他恢复过来，哪怕千年哪怕万年。”

## 四、斗法过程
1. **黄泉指**：王林踏前，拇指一点，天空霹雳，黄泉化无尽黄龙融入拇指，以道化黄泉形成黄泉一指直击柳眉。
2. **古镜格挡**：柳眉取出幻家老祖所赠的巨大古镜（下品仙宝）横立硬挡，声响惊天。
3. **七星剑阵 + 寂灭指**：七道剑气自四周呼啸而至，配合寂灭指直逼柳眉。王林评其为“伪问鼎后期，空有仙力而无意境，连真正的问鼎中期修士都不如”。
4. **第四魂黑针**：柳眉咬破舌尖喷血，口中飞出一根黑针，绕体游走，阻住七星剑阵并穿透寂灭指风。王林识破为“第四魂”，一点喝“定”将其定住。
5. **点破眉心**：王林瞬间欺身，右手重点柳眉眉心，黑气大散，柳眉元神被震伤，仅因仙力浑厚未死。
6. **元神雷威杀招**：王林分出元神雷威凝于指尖，欲取其性命。柳眉撕声呼喊“厉儿”，怨婴凄叫如利剑撕裂王林之心；王林眼露悲哀，仍毫不犹豫出指。

## 五、幻家老祖出手
- 柳眉身前突现漆黑环形漩涡，一只略枯的手臂探出，随意按在王林双指之上，一声巨响将王林震退、喷出大口鲜血。
- 漩涡内苍老声音诧异：“咦，不死”，随即抓住柳眉拽回漩涡。
- 王林认定救人者必为幻家老祖，放话：“你救她，幻家灭族”，并凝聚凌天候剑气一指电射入漩涡。
- 幻家老祖警告：王林“即便有一个阴阳虚实境界的傀儡”也非其对手；念王林与“幻眉”有旧，不愿理会二人恩怨，但若再纠缠决不轻饶。
- 该称呼“幻眉”暗示柳眉与幻家的渊源。
- 章末：凌天候剑气随之冲入漩涡，直奔另一端的幻家老祖。

## 六、关键伏笔与待续线索
- 怨婴“厉儿”落入王林之手，王林立誓复原他——后续修复怨婴之法为悬念。
- 王林与幻家已彻底结死仇（“灭族”之誓）。
- 柳眉重伤未死，被幻家老祖救走。
- 王林在此展现的手段跨度：黄泉指、七星剑阵、寂灭指、定字诀、凌天候剑气、仙卫傀儡（阴阳虚实境界）。
