# 第九卷 云海之巅 第1381章 少帝

## 一、司墨子分身之死

### 王林的连环杀招
- **龙崩丹**：先手冲击，司墨子受伤、舌尖残血。
- **炎火异晶**：蕴含天地之火，在王林操控下被挤压无数倍，崩溃威力远超龙崩丹，形成足以威胁**天人第五衰**修士的死亡之力。王林一声「爆」，光芒笼罩整个修真星，司墨子全身燃起**深蓝色火焰**——不烧衣衫，只焚血肉与元神。
- **千万剑气**。
- **血光剑**：关键时刻自血光中飞出的短剑，速度肉眼不可见、神识无法锁定，仿若脱离天地规则，自司墨子胸口前后穿透。

即便如此，司墨子分身重伤而未死，唯余「逃」之一念。

### 大帝出手
虚无中传出声音：「我颠落之地，岂能是你说来就来，说走就走。」

司墨子已遁至天边、身外波纹回荡将要瞬遁时，天空扭曲成巨大漩涡，一根与天地齐高、由气浪组成、远看透明的巨指穿出按下。司墨子被无形之力凝固一切行动，无法躲避、无法遁走，肉身裂缝蔓延后轰然崩碎，**元神四分五裂**，与血肉一同消散。手指缓缓收回漩涡，天地恢复如初。

## 二、王林的战力定位（本章明写）
- 现只是**一道本源大成**；若达第二、第三、第四、第五道本源大成，即便不开空门，也足以与**第三步大能**一拼。
- 能将天人第五衰分身重伤至此，「足以称豪界内界外」，但耗尽全身解数仍无法一举击杀。
- 战后王林体内有伤，本欲立刻疗伤。

## 三、王林对大帝的判断
> 「司墨子分身尽管重伤，但能一指将其杀死，这大帝修为绝对超过了水道子一流，不知与蓝梦道尊相比如何……且此人明显是在帮我。」

王林随即决意试探底线：「落生会第九长老敢帮司墨子，便是与我为敌……我倒要看看，那大帝的底线在哪里。」

## 四、血洗龙甲族
- 龙甲族少族长惊恐悔意，退至其父身边；龙甲族族长自恃身份，判断王林受伤不敢来寻麻烦。
- 王林化流星疾驰而至，族长下令「所有龙甲族第二步族人，阻止一切外人踏入我族半步」，近十名第二步修士飞出。
- 王林一掌按下化巨大掌印：触之者尽数喷血倒卷，**三人肉身直接崩溃**，掌印穿透落地，**龙甲族之地立刻崩溃**。
- 王林冷笑：「区区小族，也敢算计王某，简直是找死。」抬手引雷霆闪电欲杀。
- 族长挟子后退尖吼：「我是落生会第九长老，是大帝亲自定下……你就算伤我一丝，大帝定将你碎尸万段。」

## 五、大帝使者与「少帝」之称
- 远处剑光如遮天之虹而来，走出一名**赤红衣衫中年男子**，身上毫无修为气息（修炼了隐藏修为的绝顶功法，连王林亦无法察觉）。龙甲族父子狂喜。
- 使者取出**红色玉简**，宣大帝口谕：
  > 剥去龙甲族族长落生会第九长老资格，赐丹药一枚，即刻服下。
- 甩袖飞出一枚**黑色丹药**——族长惨白失声：「毒……毒命丹……」
- 使者：「有些人，不是你可以招惹与算计的，需要付出代价。」
- 随即转向王林，冰冷尽去、堆起笑容恭敬抱拳：**「属下参见少帝。」**

## 六、旁观者
火雀族老者与族人呆望全程，处于无法置信与骇然之中；修真星上所有修士面色大变，无人敢阻拦王林。
