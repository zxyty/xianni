# 第1339章 不怀好意（第九卷 云海之巅）

## 一、通道内诛杀周天子

**背景**：出口距通向七百万天地不足十里，以窥涅修士之速眨眼可至，但周天子连这眨眼时间都没有。通道内无法挪移，他叫天不应叫地不灵。

**过程**：
- 周天子刚欲疾驰，王林讥讽之声落入其心神，随即现身其前，冰冷阴寒的目光如雷霆闪电直轰入其双目。
- 王林的神通融入目光，如音爆雷霆的火线，点燃周天子数千年修炼所积蓄于体内的全部雷霆之力，使其从内部崩溃。
- 周天子喷出带内脏碎肉的鲜血，双眼涣散；体内雷霆失控爆开，连惨叫都未传出，肉身化作大片血肉散开并持续崩溃扩张。
- 元神被族印包裹冲出，已受重创近乎透明，急急逃遁；王林右手虚空一抓即将其擒于掌中。修为差距之大，使其连自爆都做不到。
- 周天子尖声求饶「长老饶命，晚辈无意冒犯」，话未说完，因通道光芒环绕使王林身体好似被穿透，他清晰看到**王林体内封印着一个魂魄**，惊道「你你不是」——王林右手一捏，**形神俱灭**。

**战果**：
- 王林吸收其毁灭元神中传出的雷霆之力。
- 收走其**族印**。
- 全程极为短暂，「杀了周天子，如捏死蝼蚁」。

**因果回溯**：周天子临死翻起无尽悔意——若当初在**雷晶殿**不去招惹对方，何至今日下场。

## 二、踏入七百万天地

王林破开前方一切壁障直奔出口，冲入闪雷族重地七百万天地。

**历史地位**：此地自建成之日起，除当年帮助闪雷族那位**第三步老祖**的一群神秘修士外，再无任何外人踏入。**王林是那群神秘修士之后的第一个外人**。

**地貌**：
- 一片浩瀚星空，星云弥漫，蕴含**七百万个修真星**，彼此分散、相隔极远，几乎无边无际。
- 王林的判断：此星空**虚假**——璀璨好似被装饰上去，庞大如同被生生开拓，**每一颗修真星的距离一模一样**（人为造界的痕迹）。
- 星空中心有一片庞大陆地，遍布高耸阁楼，正中矗立一座**全身弥漫雷霆的男子巨像**，远望如巨人遥望远方。此处即**中心广场**，为接受该任务的闪雷族修士进入后的落点。

**人口与修为分布**（中心广场）：
- 修士不下数万；绝大多数为**婴变**；**问鼎**修士不少；**阴虚阳实**随处可见；**窥涅**以上不多，且匆匆来去。
- 每座大殿外均有一座巨大传送阵。

## 三、领取入场三物

王林自传送阵现身，虽有准备仍神色震惊——但初来者皆如此，未引起看守注意。

看守传送阵的**阳实修士**催其交玉简查验。王林取出**于非的族中玉简**，验毕归还，并挥出一道幽光，内含三物：

| 物品 | 说明 |
|---|---|
| 玉简 | 介绍进入七百万天地的注意之处及另外两物 |
| **灵符** | 踏入七百万天地的**关键**，唯有持此方可进入 |
| **一丝灵念之雷** | 一团雷霆闪电 |

**灵念之雷详解**（王林高度重视）：
- 看去存在，以手触之却无形；内部闪电游走，排列如某种阵法。
- 神识一扫，这小小一团**丝毫不弱于凝聚了十万里雷池之力**。
- 其内更有一股说不清的**意念**，蕴含勃勃生机、隐透对生命的执着，「好似手中拿的不是一团雷霆，而是一个生灵」——令王林深吸口气。
- **规则**：凡第一次进入者，闪雷族赠予一丝灵念之雷，以此方可搜集此地念雷；**一千份**不完整的「一丝」才能形成**一道完整念雷**——此为闪雷族防止族人凭族规巧取豪夺的防护设计。
- **限制**：任何族人一生**只有一次**获得机会，丢失则再无可能从族中获得，除非抢夺或私下买卖。

## 四、张景云的「不怀好意」

- 广场上仍有专抢新进入者念雷的修士。此刻**三个修士**目光盯上了王林手中的念雷。
- **张景云**（问鼎中期）上前搭话，自称第二次来此、熟悉此地，提议结伴并代为介绍。神色真诚、言辞温和，但在活了**两千年**的王林眼中**破绽百出**。
- 王林右手一翻收起念雷，笑而应允；其大有深意的一瞥令张景云心神警惕，隐有秘密被看穿之感，却查不出端倪。
- 王林自报**「于非」**。张景云觉名字耳熟，旋即认出：**今日刚刚晋升闪雷榜的于非道友**，连称失敬。
- 张景云自认看透王林后，以「此非说话之处、前往七百万天地的阵法也要开启」为由带其离去。
- 旁观修士纷纷暗自摇头：「又有人要倒霉了，凡是被那张景云带走之人，怕是不但念雷会失，就连性命也都不保。」
- 二人抵达一处磅礴阵法之外，阵外数百修士分群等待；张景云所属一群十余人中，有若干新进入者，余下四人修为高深，**其中一人达阴虚境界**。张景云上前哈哈笑道「我又带回了一人，这位于非道友之名想必大家也都有所听闻」。

## 五、关键伏笔
- 周天子临死所见——**王林体内封印着一个魂魄**——是其识破「于非」身份的线索，随其形神俱灭而未泄。
- 七百万天地的「虚假」与「人为开拓」痕迹，指向当年那位第三步老祖与神秘修士群的造界旧事。
- 张景云一伙（含阴虚修为者）明为结伴，实为图谋念雷与性命，杀局将至。
