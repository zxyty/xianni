# 第1951章 一鸣惊人（一）

## 场景：天尊涅之地

- 天尊涅之地万古长存于一处奇异虚无之内，**唯有天尊修士散开神识直入九霄，方可踏入**。
- 其构架原理至今少有人参透，只知是**当年的仙祖模仿太古神境之地制作**，目的是让仙族后人提前适应，以便出现更多大天尊修士。
- 无数年来，天尊修士几乎人人多次前来，一层层闯殿以见证自身修为、成名于仙族大地。
- 当今**五位大天尊**极重此地，其招揽的麾下几乎九成是闯过一定阶层的天尊。

## 王林登场

- 王林所化长虹呼啸而至第一层大殿外，长虹消散落地；四周数百天尊修士目光齐聚。
- 王林神色如常扫视四周：有认识者含笑抱拳，他微笑回应——天尊之间无仇隙者多喜结交。
- 王林虽销声匿迹十几年，但当年**首次闯第一层失败、随后连闯四层**的小范围轰动，足以让部分天尊愿与之结交；亦有人认为四层不足道，神色冷淡。
- 旁观议论：「这白发天尊……首次就失败，但随后一连闯过四层，绝非寻常之辈」；反方则「四层如何，我等哪个闯不过第四层」，预计他**此番最多第五层**。
- 远处**竹林天尊**沉默端坐，目光凝于王林片刻后闭目不再看——他不轻视任何天尊，但也不认为王林能如自己一般闯过第七层，对七层以下者在意有限。
- 王林没有立刻闯殿，而是立于第一层殿外抬头仰望，层层大殿越来越高，**第九层所在一片模糊**。

## 天尊涅阶层格局（王林这些年了解到的）

| 层级 | 意义 |
|---|---|
| 第一至第九层 | 能闯过第九层者，如今仙族大地不足六十人，皆为天尊层次最巅峰 |
| 第十层 | 闯过即可成为**跃天尊**；每有人来闯必引起所有天尊轰动，甚至引大天尊凝神念亲自目睹 |
| 第十一层以上 | 唯有跃天尊方可去闯 |
| 第十九层 | 传闻踏入者未来极可能成为大天尊，且拥有让大天尊也不愿轻易出手的战力 |

- 全书当下：**跃天尊仅四十八人**，很多年来从未出现第四十九位，可见第十层之艰难。
- 至今**无人闯到第十九层**；最高者为跃天尊中的**冥道尊**，止步第十六层，数万年来无人超越。

## 冥道尊

- 被誉为**跃天尊中第一人**、最有可能成为大天尊之人，甚至有人称其为「仙族第六尊」。
- 名气仅次于大天尊，为大天尊之下最瞩目者。
- 被**仙皇八极大天尊**耗费极大代价招揽于麾下，且不与寻常天尊、跃天尊同等对待，而是礼遇有加。

## 伏笔

- 王林心念：「此次去往**仙族皇城**，或许会遇到这位声名赫赫的冥道尊，此人被誉为跃天尊中第一人，必定不凡。」目光微不可查地一勾——为后续闯殿「一鸣惊人」与皇城之行埋线。

## 备注

- 本章王林以「白发天尊」之名/形被众修士称呼，属外号而非冒用他人姓名，言行均归王林本人。
- 原文有「大夭尊」「威为大天尊」「仙族第六阳」等错字，应为「大天尊」「成为大天尊」「仙族第六尊」。

# 王林再闯天尊涅第五层：二十三道神通融于一拳

## 起因：不穿魂铠，先试自身极限
王林立意「一鸣惊人」，但在此之前先要试探：在没有穿上**魂铠**前，凭自身之力究竟能闯到天尊涅第几层。他神色平静，闭目片刻后猛然睁眼，目内精光弥漫，化作长虹自第一层宫殿外飞起，直上高空。

四周天尊多数收回目光、闭目打坐，未太理会；**竹林天尊**同样闭目打坐，没有去看。

## 规则：已通过之层可直接跃过
天尊涅之地的规则是——若此前已有所通过，再次闯来时可直接跃过该层，不会受到每层宫殿散出的威压阻止。故王林越过前四层，直接出现在天空中的**第五层宫殿**外，毫不迟疑一步迈入。

## 第五层之景：四十五颗修真星，五颗金色星辰
入内瞬间眼前一片模糊，当年前四层的感觉再度浮现；视野清晰后，他仍处在一处虚无的星空之中。

- **第四层**：三十六颗修真星凝聚而来，其内更有金色星辰；每一颗金色星辰内部拥有不弱于当层所有修真星融合之力。
- **第五层**：前方星空突有**四十五颗修真星**改变运转轨迹，带着震耳呼啸自四面八方急速来临；其中**五颗**爆发夺目金光，瞬息彻底化作**金色星辰**，透出令虚无似颤抖的威压，随其余修真星直奔王林。

（注：原文后文亦以「四十个修真星」称之，数字表述前后略有出入。）

## 核心：神通凝拳的递进与上限推演
王林右手抬起，空劫修为轰然爆发，开始逐道凝聚神通入拳：

1. 起手以**空劫初期**气息凝出十三道神通于一拳（此刻气息尚在攀升）。
2. 王林自陈：「空劫中期之后，我还没有完全释放一次」，遂将气息全部爆发，从空劫初期直达其此刻巅峰——**空劫中期**。
3. 修为攀升中，第十四、十五、十六、十七道神通接连融入，转眼达**二十一道**。
4. 王林的推演公式：
   - 空劫修为**每提高一个境界，可多融九道神通入体**；
   - 空劫初期极限=**九道**，中期=**十八道**；
   - 因此前**金与木本源**出现、修为略有精进，**强行多凝聚出四道**，合计**二十二道**。
5. 第二十二道凝出，惊天之力散于拳内，似足以轰开一片虚无。
6. 王林不急于出手，反而跃向上方，整条右臂青筋鼓起，庞大力量取代血液在血管内急速流动，最终凝于拳中——**第二十三道神通**凝聚而出。
   - 王林判定：二十三道是他如今修为的**极限**；多出的这一道，源于**在东临池内多次感悟**，使其余本源亦略增一丝。

## 出手：五行真身叠加，四十六道神通一拳
其时四十个修真星自下方呼啸而来，五颗金色星辰散发强大威压，距王林已不足数百丈。

王林判断：「这第五层，出动一具真身就可」——身上转眼出现重叠，**五行真身**幻化而出。握拳的右拳向下方修真星一拳轰去：

> 二十三道神通融入一拳 + 分身叠加 = **相当于四十六道神通**

## 结果与影响
- 剧烈轰鸣中虚无崩溃，无尽金光刺目而起，穿透星空、破开虚无。
- 金光自天尊涅第五层大殿内急速扩散而出，**笼罩整个天尊涅**。
- 下方数百天尊一个个抬头看到——从无人在意到举座侧目，「一鸣惊人」之势已成。
