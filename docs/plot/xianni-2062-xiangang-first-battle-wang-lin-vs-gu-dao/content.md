# 第2062章 仙罡第一战

## 一、出关：踏天之桥归来

- 王林第二次前往踏天之桥，走过第五桥并踏足第六桥；**除王林自己外无人知晓他走过几桥**。古道大天尊的极限即第五桥，故只能察觉王林走过第五桥，第六桥成败无从判断。
- 在苍茫大海所化盆地旁的深山外，层层波纹环绕数月后消散，王林平静走出。
- 出关状态：白色长衫，一头白发，神色与数月前无异，但**体内没有丝毫运转痕迹，竟如凡人一般**。

## 二、王林的三重心愿（内心独白）

1. **救疯子**：当年发誓再临祖城皇宫时要将疯子救出。若疯子愿同去，则仙罡大陆无人可阻；若其选择成为仙皇，则要做“不再沉睡的真正仙皇”。
2. **寻故人**：司徒、清水、十三、大头、红蝶皆在仙罡大陆但不在古族，判定必是**转世在仙族的大地上**，此行要一一找到。提及李倩梅时目露复杂之色。
3. **归家**：最终要回到**七道宗 → 洞府界 → 朱雀星**，“才是我的家”。

随后他以当年第一次横穿此地百倍之速，数日间直抵苍茫大海中心。

## 三、海墙风暴与三百年之约

- 苍茫大海中心，海水竖起形成无边无尽的**海墙风暴**：轰鸣震天、二百余年不断转动、内部空间碎裂、向八方弥漫无形威压。
- 海墙深处可见**九根巨大柱子形成的门**。
- 王林已知：**三百年后此门开启**，届时他将带李慕婉踏入，以**轮回之力**令李慕婉复活并超越轮回；且“在那里，或许我可以找到一个真相”。

## 四、仙罡两强首次照面

王林抬脚欲穿海墙时忽然停步等待。十息后昏暗天空咔嚓炸裂，一道巨大裂缝被凭空撕开，雾气疯狂宣泄，**古道大天尊自裂缝中走出，却始终不离雾气**。

- 意义：这是仙罡大陆**最强两人的第一次面对面相见**，也是**仅有的两个半只脚迈入踏天境者**的第一次对望；当年古道山上因修为不等的隔塔相望远不能比。
- 古道确认王林“早就知道我的来临”，并追问其第二次走过几桥；王林答“这不重要，重要的是你来此的目的”。

## 五、谈判：留与走

**古道的条件**
- 王林可杀古祖后人烨道、可随意指认新皇尊、可在古族做任何想做之事，**但不能离开古族**。
- “除非我阻止不了，否则你不能离开。”只需**再留三百年**，待**太古神境开启**即可随意离去，甚至愿付出一些报答。
- 拒绝给出解释：“没有解释，我不让你走，你就必须留下，要么，就战胜我。”

**王林的还价（恩怨分明，三笔账）**
1. 古道山上，借其威压完成**仙古融合**；
2. 道古皇城，王林杀烨道时以当时修为本无胜算，古道**保持沉默**未出手；
3. **始古一脉计都**成为新皇尊，古道**未加阻止**。

因这三次，王林愿在无任何解释的情况下**再留一百年**，余下二百年则要离开。古道回绝：一百年不够，必须等到太古神境开启。

**未解之谜**：王林反问，以古道之修为足以横扫仙祖所有强者，为何仍保留仙族存在？此问是古族与仙族无数年来共同的疑问，无人敢当面问古道。古道沉默良久，只答：**“我获得的古祖之赐与你不一样。”** 王林目露思索，似有所悟。

## 六、开战：仙罡第一战

王林：“你要战，那便战吧。”——他也想知道如今自己与古道之间谁才是仙罡最强。此战是仙罡大陆**自仙祖、古祖无踪后的第一战**，两大最强者的巅峰之战。

**双方战力对比**

| | 古道大天尊 | 王林 |
|---|---|---|
| 境界 | 无数万年前已入踏天境，止步第六桥 | 仙古融合，两真身完整即半只脚踏天境 |
| 战绩/底牌 | **唯一击杀过大天尊之人** | 虚本源真身尚未完整；**虚无分身**经数百近千年已成长，融合后将爆发恐怖之力 |

**古道首击**
- 身外雾气轰然滔天，化作**九头狰狞雾兽**，仰天嘶吼，古老沧桑似有灵、存世无数岁月——**与王林当年在古神之地所见异兽“吉穷”颇为相似**。
- 雾兽内古道抬右手一指，指尖缭绕雾气、隐见弯曲指甲寒光。
- 一指之下天地大变：苍穹与大地被无数**规则细线**弥漫牵引，缠向王林；风云雷电与金木水火土五行神通在王林四周幻化。临近时万法凝聚为一根**由神通与规则细线组成的虚幻手指**，带着弯曲指甲与毁灭之意，**直点王林眉心**。
