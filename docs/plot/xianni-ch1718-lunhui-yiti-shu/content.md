# 第1718章 轮回一体（第二更）

## 一、青霖查魂：无端倪

- 青霖以神识查验王林手中的**天运子分身之魂**，许久后皱眉收回：
  - 「此魂与寻常分魂一般无二，且极为虚弱，随时都可以死亡的样子。」
- 王林提出更进一步的验证方案：**自己全部心神融入该分魂，同时让青霖神识进入自己身体，观察本源是否有变化**。

## 二、信任的分量

- 在全部心神外投时让他人神识入体，是极危险之举——对方若有异心，对王林伤害极大。
- 王林与青霖相见次数不多，但多年往事足以换来「信任」二字。青霖亦为此感慨：他知王林**一生谨慎**，能说出这样的话，可见信任之深。

## 三、青霖入体：三重震撼

王林盘膝闭目、心神融入分魂；青霖散开神识融入王林体内观察，连受震撼：

1. **七道本源**——「之前只是听说他有六道本源，六道已经是让人无法想象，眼下居然出现了七道」。青霖倒吸凉气，直言「太惊人了」。
2. **恐怖血脉之力**——远比本源更令其心神颤抖，「仿若蝼蚁面对苍天」。该血脉气息：
   - 古老悠悠，似与天地同在，万物众生在其面前都要低头膜拜、颤抖、滋生恐惧与敬畏；
   - 霸道无比，仿佛若有半点不敬，就会被其**毁灭一切轮回、抹去生命**。
   - 青霖面色苍白、下意识后退数步，目光由震惊转为恐怖：「我只知道他有古神肉身，但其体内血脉中的气息，**绝不是古神**——这是什么气息，竟然如此恐怖？」
3. **禁制本源异动**——融合关键之时，青霖发现王林体内七道本源中的**禁制本源**，在王林未操控的情况下**自行分出一丝**、在体内自行运转，「仿若有某种奇异的力量将其操控」；随融合加深，运转愈快，一圈圈环绕。王林本人几乎无察觉，只觉「有些不对劲」。

## 四、定神术与追丝：召河星空之战

- 青霖不假思索，右手点在王林眉心：**「定神术」**——王林全身一震，融合与运转在瞬间被强行阻止。
- 青霖手指下划至王林胸口，向外一拽，拽出一缕**幽光如丝**（即那自行运转的禁制本源的一小部分），缠绕于指。
- 青霖神识凝聚融入细丝，脑海轰鸣、天地混乱，睁眼时置身一片熟悉星空——**召河星域**。细丝延伸向前方星空，不见踪迹。
- 青霖神色阴沉，顺丝疾追：「我倒要看看，到底是这天运子本尊在搞鬼，还是其他人。」
- 约半炷香后，前方细丝延伸处**七彩之芒**大放，一个苍老声音回旋：「青霖，这不是你该管的事情，给老夫滚回去！」
- 七彩之芒化作**占据整个星空的巨大镰刀**横扫斩下。青霖掐诀施展：**「星，月，日，三光护体，三剑开河」**——星光、月光、阳光回旋护体，与镰刀相撞。
- 结果：镰刀直接崩溃，但青霖同样全身一震、身影消失于该星空；仙界雪山上，其手中细线崩溃，身子后退数步，面色极为苍白。王林同时一震，定神术消散，从融合中分离睁眼。

## 五、青霖的推断与疑点

青霖复述：「我没见过天运子，但却看到了七彩。」并给出判断与四点疑问：

- **判断**：天运子分身之魂即王林与天运子之间的**联系所在**，天运子可通过此魂**偷走王林的本源**；此人算计惊人。
- **疑点一**：他究竟如何做到？为何凭一个分身就能偷走本源？
- **疑点二**：若真被偷走，为何王林的本源**没有半点减少**？
- **疑点三**：对方所施神通看似简单，实则**运转了整个星空的力量**，不像寻常手段。
- 王林杀机更浓，猜测：「或许，他是选择了类似于**拓印**的方法。」

## 六、蓝梦道尊现身：道破「轮回一体术」

蓝芒自天空垂落映照雪山，**蓝梦道尊**（文中亦作「蓝芒道尊」）身影幻化而来；青霖抱拳行礼「青霖见过道尊前辈」。

蓝梦道尊所述（自称从**掌尊**处听闻）：

| 要点 | 内容 |
| --- | --- |
| 名称 | 轮回一体术 |
| 出处 | **七彩仙尊**的神通之一；连七彩仙尊似也未修成 |
| 法门重点 | 在无数次轮回中，**把每一次轮回都看成自己的一个分身**，最终以奇异方法**相互吞噬**，方有希望修成（其中尚有复杂之处，道尊未见过此术，无法尽知） |
| 分身特性 | 以此术所修的分身若被外人获得，**很短时间内获得者便与之成为一体** |
| 一体后果 | 成为一体后，**吞噬较多的一方**可获得另一方的**所有气息，包括修为**——「你有多少本源，对方就会有多少」 |
| 评价 | 「太过歹毒，可一旦修成，极为强大」 |

- **诊断**：结合王林状态、青霖描述与手中之魂，蓝梦道尊有**四成把握**判定王林中了他人的轮回一体术。王林沉默。
- **破解**：任何神通都有破法——**王林若能反过来吞噬对方，修为亦会增加**；「你与这分魂已经融合成了一体，你们轮回连接，这对你来说，或许也是一场造化。」
- **承诺与界限**：蓝梦道尊愿帮王林**找出施术者**（「我想要看看，七彩仙尊都没有修成的神通，此人有多高的天资」），但**杀他须王林自己出手**。

## 七、结尾：目光重叠

蓝梦道尊抬手凝聚蓝光光环，一按按在王林眉心：

- 王林脑中轰鸣，眼前蓝光弥漫，星空急速流转；
- 他看到**召河星域深处漂浮的一颗陨石**；
- 更看到陨石内**盘膝而坐、猛然睁眼露出震惊之色的天运子**；
- 两人目光在这一刹那**重叠**。

## 八、待解伏笔

1. 王林血脉中远超古神的古老霸道气息究竟为何物（青霖亦不识）。
2. 天运子如何仅凭一枚分身之魂偷取本源，且被偷者本源不减——「拓印」猜想待证。
3. 召河星域中出手斩断细丝的七彩之芒/苍老声音，与七彩仙尊的关系。
4. 王林能否反吞噬对方，把这场算计转为「造化」。
