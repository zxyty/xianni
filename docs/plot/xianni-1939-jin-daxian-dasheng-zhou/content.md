# 第1939章 金大仙！（第二更）

## 一、地理背景：大圣洲

- **位置**：东州偏北，一洲名为「大圣」。
- **荒凉程度**：对修士而言极为偏僻，甚至比当年**天牛洲**所在更加荒凉。
- **凡人生态**：此洲地灵、农植生长顺利，凡人数量不少且生活多为殷富。
- **信仰风气**：无数年来流传仙人之事，凡人几乎人人拜仙，对仙人极为崇敬，皆想寻仙缘。
- **宗门风气**：此洲仙家宗门弟子极少外出，大都神秘，被认为与此洲第一宗门**东临宗**有关；这份神秘反使凡人更为向往。
- **天象特征**：天空多有白云，少见万里无云的碧空，多年如此，凡人习以为常；若逢万里无云反会诧异（此点为下文金彪子「拨云」神迹埋伏笔）。

## 二、东临宗

- 大圣洲第一宗门，位列**东州九宗十三门**之内。
- 在九宗十三门中显得极为低调、神秘。
- 门内弟子绝少外出，大都在宗门中修行。

## 三、凡尘迎仙：等候三个时辰

- 地点：大圣洲内某处凡尘都城之外。
- 人物：近百人恭候，以三四个衣着华丽、病快快（病恹恹）的老者为首，由仆从搀扶。
- 众人自鸡鸣起等候，已近三个多时辰，至当午酷热仍不敢散去，以能在此等候为荣。
- **冲突小插曲**：一名穿员外袍的中年男子（布绸店主）不堪酷热抱怨「大仙是不是忘记了要来此地」，被为首老者厉声喝斥——老者称是自己与几位好友哀求许久，大仙才怜悯答应今日前来，并威胁若惹了大仙便叫其全家滚出此城。
- **口耳相传的「仙迹」**：
  - 「一旦成仙，鸡犬升天」为大仙所言，数十年来在大圣洲广为流传。
  - 邻近临镇请大仙过去，七名孩童被看中，后送回三人，四人进入仙门。
  - 临镇李员外（前述老者好友）家中曾住过该仙人，其孙女已双十年华、按传闻不可能入仙门，但因李员外哀求仍被带走。

## 四、金大仙出场：完整的行头与神迹

出场排场（自远处天空而来，先起阴风扫地使众人通体清凉）：

| 要素 | 描述 |
| --- | --- |
| 华盖 | 约数十丈的红色大伞 |
| 座驾 | 紫色竹子编制的轿椅 |
| 抬轿 | 四个金袍大汉，踏清风于天空迈步 |
| 随侍 | 十多个童子，或持宝瓶、或持拂尘、或持发光宝玉 |
| 本尊 | 白发苍苍老者，白色道袍，仙风道骨，皮肤如婴儿般细腻，双目射出明亮光芒 |

**颂号**（先由四大汉齐吼、再由童子齐喊，声音融合如仙音）：

- 「金彪大仙，助凡成仙；金彪大仙，降尘炼丹；金彪大仙，送子入仙」
- 「金彪大仙，不朽之仙；金彪大仙，天地之仙；金彪大仙，圣洲再现」

**神迹三连**：

1. 右手大袖一甩 → 风云滚滚，天空刹那**万里无云**，露出蔚蓝天幕（正击中此洲「罕见晴空」的天象常识，效果极强）。
2. 左手一挥 → 蔚蓝天幕上幻化出极为奢华的宫殿虚影，如仙宫。
3. 仙宫内飞出几只仙鹤，天幕回旋、掀起清风吹向大地。
4. 异象巅峰之际起身大喝「一旦成仙，鸡犬升天」，如雷鸣回荡，城内外凡人齐齐跟诵。

**破绽（叙述者视角）**：老者眼中闪过得意；额头泌出汗水，说明这一幕对他本人也是不小的负荷；只因距离不近，下方凡人无从察觉。

## 五、金彪子自白：骗道生涯

落地后含笑宣布安排：

- 「本仙一向随和」，时间有限，**只在此城居住三天**；
- 三天内众人把子嗣带来，由他一一查看，**具备仙缘者便随我而去**。

内心独白（本章关键信息）：

- 自称**金彪子**，六七岁就离开村子在外行骗，多年来所骗之人极多。
- 自评「天生禀异」：不但具备骗术天赋、无师自通，且**未加入任何山门便自己真的炼出了修为**。
- 自称是「千辛万苦费尽心神骗人把我传送过来」才到大圣洲。
- 评价此地：民风淳朴、向往成仙，是「我辈之人的一块宝地」；且**从未被同道开掘**，只编造一句「一旦成仙，鸡犬升天」，便在此地一帆风顺。

> 归属说明：据《世界状态须知》，「金彪子/金彪大仙」即**刘金彪**（惯用骗道之术，第1336章曾以骗道伪装成「六代朱雀」骗过火雀族老祖的火焰探查、验血与搜魂）。本章「金彪大仙」的言行归于刘金彪。

## 六、王林线：抵达大圣洲

- 同一时刻，大圣洲内、距该城约**数万里**外的天地间，天幕波纹回荡，**王林**身影显露。
- 环视四周后确认：「这里，就是大圣洲了——东临宗所在之洲。」
- 叙事意义：王林此行目标指向**东临宗**；与刘金彪在同一洲内活动，两条线已在空间上汇合，为后续重逢/交集铺垫。

## 七、结构要点

1. 前半以纯凡人视角铺陈「仙迹」，后半用金彪子内心独白当场拆穿，形成骗局的正反打。
2. 「大圣洲多云、罕见晴空」的天象设定被直接转化为骗术的舞台效果。
3. 章末王林登场，将凡尘骗局与主线（东临宗）扣合。
