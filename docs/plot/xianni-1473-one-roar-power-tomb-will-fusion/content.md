# 第1473章 一吼之力！！（第三更）

## 一、开篇更正
- 作者更正：拓森的星点为**八星**，非九星（八星王族古神之肉身）。

## 二、神识横扫全墓
王林坐于古墓宫殿的椅子上，与古墓意志融合后，神识不受操控地扩散，瞬息扫遍整座古墓，看到了墓内所有存活的太古星辰修士。

各方反应（按地图由后至前）：
- **第九张地图·九天魔尊分身**：正驱墓台疾驰，笃定「就算你抢走一切，也无法活着离开」。神识一扫，他心神轰鸣、面色大变，有「全身一切隐秘尽被知晓」之感与魂飞魄散之惧——这种感觉，唯有他当年尚未成为第三步大能时才有过。此为其第一次出现恐惧。
- **第七幅地图·大荒上人**（本尊亲至，麻布老者，双唇被三根针穿透，容颜残忍）：空玄修为弥漫，信步五步跨一图。神识扫过时，他掐诀抬手向前一抓，欲将神识抓出；右手触及神识刹那被反震意志撞击，蹬蹬后退，心神一颤，喝问「阁下是谁」，无人作答。
- **第四幅地图·九天本尊与妙音老道**：正并肩前行，九天本尊刚说「老夫分身发现」便被神识扫过而顿住；妙音老道瞳孔一缩、心神被牵引震动，大吃一惊。九天魔尊面色阴沉，评曰「很强，非常强」。
- **第一张地图·白衣女子（远古八妃之三妃）**：本已放弃在此获取造化，加速后撤欲离，冥冥中觉得再不走将被永久留下。神识扫至其身时停顿片刻，她额头泌汗、不敢动弹，除恐惧外更有一丝羞恼被强压下去；神识移开后她面带红晕，复杂地望向神识去向。

## 三、隔裂缝对话「掌尊」
王林神识最终延伸至古墓通往太古星辰的裂缝旁。借古墓意志，他看到了以自身修为、乃至妙音道尊等人都看不到的东西：
- 该**裂缝被人以莫大法力凝固**，使其无法收拢闭合。
- 裂缝外太古星辰星空中，此前出现的**巨大掌印始终未散**，掌印下**黑袍人影**默默漂浮守候。

黑袍人猛然抬头，目光似穿透裂缝看到王林神识。二人几乎同时问「你是谁」——黑袍人以口出声，万古沧桑而嘶哑；王林则借墓地意志以神识波动传话，同样苍老如活了无数万年。

- 黑袍人自报：「老夫太古星辰，**掌尊**。」并请求放墓内之人出来，事后重谢。
- 王林沉默良久后回以一句：「**井中捞月**，很不错的神通。」——一语道破对方神通。

## 四、封裂缝 vs 太初之力一掌
话音落处，掌尊身子一震，毫不犹豫挥右手，令上空巨大掌印轰然降临直奔裂缝，但**晚了一步**。

王林此刻「便是这墓地」，心神一动，裂缝内那凝固之力无法承受整个古墓（含**道古烨寞残留神念之力**）的挤压，裂缝急速收缩。王林更可趁势烙印一道封印，令古墓**若无意外数万年再无法开启**，将所有入墓者困死其中——此举等于**断太古星辰三成之力**。

掌尊低吼上前，右掌与降临的掌印瞬间融合，掌心散发炙热之气——**不是火，而是光，是太初之力**。一掌穿透裂缝落入古墓，整座古墓轰然一震，王林融入的意志神识被风暴般横扫倒卷。此掌之力**足以灭世，已是这星空的极限**。

## 五、一吼之力
掌力入墓刹那，**古墓第三层**骤然传出一声大吼——道古烨寞残留神念之力所化。此吼外人听不到，唯有神识融入墓地意志的王林听得清晰。

吼声经神识传入王林肉身，其双目爆出万丈金光，化作奇异波动涌入喉咙，王林张口吼出：

| 对象 | 后果 |
|---|---|
| 拓森 | 喷血倒卷，双臂护身，大半身血肉分离露出森森白骨——**八星王族古神之肉身崩溃** |
| 九天魔尊分身 | **直接崩溃**，没有任何反抗资格 |
| 远古八妃第四妃（风情粉衣女子） | 所舞**远古仙尊所赐绸缎崩溃**，肉身爆开，元神飞出，数度崩溃后勉强残存 |
| 大荒上人 / 九天本尊 / 妙音老道 | 三人同时喷血、肉身瞬息崩溃；空玄修为亦无抵抗资格。凭保命神通元神存活，各自取出祭炼备用肉身换上，骇然不敢再进，**毫不犹豫后退欲离开古墓** |

吼声轰轰直奔第一张地图的裂缝，与掌尊的掌印**无形碰撞**。（章末悬置）

## 六、要点与伏笔
- 王林与古墓意志的融合，使其战力/感知远超自身修为，可直接压制空玄大能。
- 「掌尊」为太古星辰新登场的顶尖存在，神通「井中捞月」，掌握**太初之力**（光属性）。
- 王林握有**封墓困杀**的战略选项，可断太古星辰三成之力，成为与掌尊博弈的筹码。
- 道古烨寞的残留神念是古墓真正的底牌来源。
