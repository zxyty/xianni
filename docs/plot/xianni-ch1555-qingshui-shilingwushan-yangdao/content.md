# 第1555章 清水！

## 一、山下：石化玄武与疑似玄武圣皇的尸体

- 王林见到一具**正面盘膝的中年男子尸体**，死前神色**似喜似惊**：仿佛最初狂喜（似正在吸收玄武之力），却在最兴奋时遭遇骇然之事而死。
- 王林未曾见过此人，却冥冥中判断：**此人很可能就是当年叛离四圣宗、投入修真联盟的玄武圣皇**。四圣宗与老圣皇多年不解玄武为何叛族甘为联盟走狗，王林此刻隐隐有了猜测。
- **巨大玄武石兽**散出的气息极为惊人，虽为死气，其生前之强足令王林动容——堪比当年在**古神墓地**所见的那两条巨龙。

## 二、峰顶：清水的现状

- 一声疯狂咆哮震开七彩云雾，峰顶显露。王林**双眼疯狂之色滔天而起——他看到了清水**。
- 清水形貌：全身干瘦、神色狰狞、容颜大变、风姿尽失、乱发遮面、眼中癫狂红芒与杀戮。王林仍一眼认出「清水师兄」。
- 被**九根散发七彩之芒的利刺**（并非七彩钉）生生钉在山壁上，挣扎不脱，只能怒吼：「杀……杀光你们，杀光所有人。」
- 身前悬有一根**约十丈大小的七彩食指**，细长指甲点在清水眉心三寸之外，似已悬停极久；**红色细丝自清水眉心钻出，被该食指不断吸收**。

## 三、交手：极境与血影

1. 王林逼近至不足百丈，清水咆哮中蕴含惊天杀气，足以轰开修士道心、令接近者道心被杀气融入而骇然死亡。
2. 逼近至三十丈时，清水瞳孔内幻化出**红色闪电（其极境）**，内含天地至极杀戮与**杀戮本源之力**，激射王林。王林掐诀击溃之，双手一麻，一股极境之力冲入体内欲崩其心神，被其压下。
3. 清水随即发出入地后最强一吼，身前幻化出**巨大血影头颅**张口扑来。王林**左目金火、右目金雷**同出相撞，嘴角溢血、急退。
4. 王林后退中大吼：「清水师兄我是王林啊，我是你的师弟王林啊！」

## 四、关键发现

- 冲击吹开乱发，露出清水完整面孔：**一道道鼓起的青筋，青筋内似有某物正在蠕动**。
- 王林呼喊时清水双眼一凝，露出痛苦——那痛苦透着悲哀，透着**似发现了某种隐秘之事后的绝望**，并喊出：「**我魂被玄武肉身镇压，王林杀了我！**」
- 话音未落，地面石化玄武轰然一震，**一股灰气爆出、融入山峰直冲清水体内**，清醒瞬间被癫狂杀戮再度取代。
- 王林看到清水**头顶天灵右侧三寸另有第十根利刺**，藏于发中极难发现——「十根利刺，不是九根，是十根，我明白了！」

## 五、王林推演的大阵真相

| 构件 | 作用 |
|---|---|
| 十万大山 | 化作**十根利刺**，封印清水之身 |
| 十万修士（活死人） | 以鲜血滋养玄武，以其一生的杀戮**刺激**清水 |
| 玄武 | **并非死亡，而是真身肉身**，用以**镇压清水之魂** |
| 七彩食指 | **一切的根源**，吸收从清水身上诞生的**杀戮本源** |

- 结论：**清水师兄如同一个炉鼎，此炉鼎就是为杀戮本源而存在。**
- 玄武圣皇叛变之因：修真联盟不知在何处寻得这具玄武肉身；该玄武**很可能是仙尊麾下四大战将**之一，肉身万年不腐、内蕴玄武一族气息。玄武圣皇身为后代子孙，欲获其祖之力——**唯有这等诱惑才足以让其成为叛徒**。
- 清水当年来此，是为寻找自己疯癫的缘由；他**定是发现了什么**，这发现让他再次疯狂。

## 六、血雾幻象：清水的来历

血雾凝聚于清水四周，浮现血色画面：

1. **凡间小国顷刻颠覆**，其**储君少年**带凄惨悲哀之色丧家逃走。天空有一道**七彩之芒**，芒内有模糊虚影。
2. 少年**拜入山门、倍受凌辱**，立于山峰之上发出声声呐喊，**恨天恨地、恨尽一切众生**——**极境诞生**。天空依旧有那七彩之芒，芒中身影**似时刻望着下方那个少年**。

- 王林心神震动，其骇然不亚于当年知晓**闪雷族七百万天地**，并生出一个可怕猜测：**「养道」**。

## 七、悬念与待解

- 「养道」究竟为何：是否有人自幼刻意培育清水之极境与杀戮，以收割杀戮本源。
- 七彩之芒中的虚影是谁，与七彩食指、七彩利刺是否同源。
- 清水青筋内蠕动之物为何。
- 清水求死之请（「王林杀了我」）王林将如何取舍。
