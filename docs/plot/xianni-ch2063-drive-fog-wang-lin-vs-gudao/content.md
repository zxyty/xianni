# 第2063章 驱雾！

## 一、对阵双方
- **古道大天尊**：仙罡大陆第一强者，修为莫测，已多年没有出手。本章一指之下天地色变、风云倒卷，连旁边的海墙风暴都出现深深凹陷。
- **王林**：一头白发舞动，始终背着左手，气质莫测。此时修为已半只脚迈入踏天之境，与仙祖相差不多。

## 二、试探一击：规则崩断
1. 古道虚幻一指凝聚风雨雷电之力，雷霆轰鸣、弧光游走、云雾雨滴混沌交织；其中更升起金木水火土五行之力，**与王林的五行真身本源丝毫不差**，堪称夺天地造化，足以击杀大天尊。
2. 王林早有心理准备，双脚未动，右手一指点出。指出的一瞬，天地间无数细线规则齐齐震动、无声崩碎——**这一刹四周成了没有规则存在的空间**。
3. 双指相触，巨响压过海墙风暴咆哮。王林闷哼退后三步；古道那虚幻手指内窜出黑气，轰然四分五裂，其内神通尽碎，雾兽中的古道身影同震退三步。

> 结论：试探之击**势均力敌**。

## 三、王林连施八极道
八极道为**仙祖神通**。王林并未学全，但凭近乎仙祖的层次施展，威力近仙祖之力。其后三极乃**第二次走踏天之桥时于第五座桥上顿悟**——看似走过很快，实则如度无数年。

本章施展顺序与表现：
| 极道 | 表现 |
|---|---|
| 极水道 / 极金道 / 极木道 / 极土道 | 右手生青色烟丝、化素色烟圈，火热之感散出；五行之力幻化成八极道光环直奔九头雾兽 |
| 极地道 | 一拳轰地，海水竖起所成的巨大盆地震裂，地气污浊上涌，内含海水中无数万年死亡生灵所化的死亡阴气，凝成唯一一个灰色光环，收缩爆发惊天之威 |
| 极天道 | 一指点天，如抓下天空光明，天空瞬间黯淡，化出太阳般光环压向雾兽 |
| 极命道 | 右手点眉心，双目射出幽光，身前化幽色光环环绕四周形成防护，硬抗近万雾球 |

王林自评：八极道**除最后一道外，全部完成**（金木水火土 + 天、地）。古道则暗自惊疑：「他到底走过了几座踏天之桥？」

## 四、古道的手段
- **九头雾兽**：浓雾所化护身，九头仰天嘶吼形成波纹，九道不同光芒结成**九色彩虹**环绕对抗八极道。
- **雾球**：双手一晃，凭空出现数百雾球，**每一个都蕴含足以轰杀跃天尊的力量**，连大天尊面对亦要心惊；转眼分裂为数千上万，密密麻麻漂浮四周。

## 五、战况推进
1. 五行极道被一一粉碎，但**极天道与极地道的光环穿透层层阻碍，落在雾兽身上**，雾兽凄厉嘶吼。
2. 王林全力运转**速神脉**，速度暴增，一步跨出消失无影：先在雾兽身前一拳，不看结果再度消失，出现在雾气内**古道身后**再狠狠一拳。
3. 古道转身甩袖，将王林倒卷弹出雾兽身后；古道亦闷哼一声，**袖子灰飞烟散**。
4. 王林的两拳早有计算——以雾兽为中心相互碰触，爆发暴风横扫，**撕裂雾兽身躯**。
5. 古道毕竟是仙罡最强，近万雾球齐至，王林无法闪躲被尽数轰中，遂以极命道护身。

## 六、余波：两族强者齐赴苍茫盆地
轰鸣如百万天雷同炸，震动整个苍茫盆地，向古族与仙族方向扩散，音浪牵动天地规则，**整个仙罡大陆所有位置风云色变**。

- **仙族一方**：道一宗、祖城帝山、紫阳宗、北州冰川之地四地的仙祖（除适非外的四个大天尊）心神震动，辨出「与古道交战的气息是王林」，化四道长虹直奔苍茫盆地。
- **古族一方**：玄罗、末天，以及始终神秘的**极古一脉大天尊**，三人不假思索冲天而去，疾驰苍茫盆地。

## 七、备注
- 原文多处将「古道」误排为「吉道」，同一人；「托森/拓森」式的错字现象同类，按规范名归一。
- 「跃天尊」为原文所载境界名，低于大天尊。
