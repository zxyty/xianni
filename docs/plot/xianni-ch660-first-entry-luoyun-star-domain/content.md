# 第七卷 名震罗云 第660章 初入罗云

## 一、背景设定：罗天（罗云）星域

- **归属**：雷之仙界之下的星域；罗天星域很大，其内修真星多不胜数。
- **信息开放度**：其内修士大部知晓「风雨雷电四大仙界下各有一方星域」。与之相对，联盟星域内因修真联盟一家独大并刻意隐瞒，包括王林在内的绝大部分修士一直认为星空下唯有修真联盟。罗天星域较为自由，隐秘之事不会太过封锁。
- **势力形态**：罗天星域内**没有门派**，只有一个个**修真家族**，注重**血脉**——唯有流淌相同血脉才有惊人凝聚力，方可形成一方势力。
- **雷之偏向**：因与雷之仙界关联，雷系神通在此地是威力最大的法术神通。

- 四人本为**试炼**而来，阴差阳错**撬出一块赤耀石**，因而引来大量**冥雾虫**，被追击数日后团团围住。
- 四人脚下各有**星罗盘**代步；冉月以水袖挥出大片晶光阻拦，仍被雾气追上。

## 三、冥雾虫与赤耀石

- **冥雾虫**：手指大小的飞虫，藏于自身散出的灰色雾气中，远看只见星空中一大片翻滚灰雾。
- **雾气之毒**：对修士为剧毒，触之伤及元神，更可**磨灭神通**，极为可怕。
- **弱点**：最怕**雷系法术**。
- **执念**：对抢走其赤耀石的敌人，即便把石头扔出也会追击（冉月语）。
- **四人处境**：全靠冉月玉镯散出的微弱雷电之光笼罩护身；其余三人展开神通、拿出法宝试图破开缺口而不得。随时间推移，仙力渐少、丹药不多。冉月已向家族求救，但距家族尚有距离。

## 四、王林登场与出手

- **来路**：王林整个人融入那漩涡后，好似进入传送阵，出现在陌生星空——不是家乡联盟星域，而是雷之仙界下的**罗云星域**。沉默少顷后拿出**星罗盘**，带着一丝茫然在陌生星域回荡。
- **形貌（本章）**：乘龙形银光；一身白衣胜雪，长发随意束于脑后，相貌寻常但皮肤晶莹，双目深邃、时有电光闪过。
- **目光退虫**：王林目光扫下，雾中冥雾虫轻颤避开，形成一片空白处——冉月由此暗惊，心神一震。
- **四人求救**：孙雪山自报「冉云星孙家族人」求救并许以重谢，冉辰、冉风恭敬求救，冉月自报「冉云星冉家族人」许冉家答谢。王林收回目光，雾气立刻重新吞噬空白处。孙雪山遂以**赤耀石**为谢礼相求——但赤耀石为何物王林并不知晓，对他并无诱惑力。
- **真实动机**：王林对罗天星域太过陌生，必须尽快了解，随后方可去**画轴女子所说的向家**。
- **问路**：王林只问一句「冉云星，在哪」。孙雪山答：距此约十日星路，在**正北方**，并请为其带路以报救命之恩。
- **出手**：王林抬右手向前虚空一点，元神内涌出一道闪电顺右手弹出，雷鸣轰隆，闪电如一条雷龙化作无尽威压冲入雾内。
- **关键设定**：此雷**并非寻常法术幻化之雷，而是真正的天雷**——王林元神内与**太古雷龙**融合后产生的**元神本能**。故雾中毒素无法削弱它。
- **结果**：雾气全部消散，冥雾虫齐齐远退，四人脱困化作四道长虹飞至王林身边，劫后余生之余更是心神剧震。

## 五、「雷仙使者」之疑

- 孙雪山虽不会雷系神通，但身为罗云星域之人深知雷法；他震惊的是那道雷电内蕴含的**一丝真正的雷威**——**家族内的长老与先祖都无法做到**。
- 冉月因修为达婴变中期、家族地位较高，知晓一些较为隐秘之事，遂深吸口气恭敬问道：「晚辈冉家九代族人，前辈可是**雷仙使者**？」
- 孙雪山闻言面色大变，暗道此人一定是雷仙使者，并生疑：雷仙使者为何要去冉云星？（章末悬念）

## 六、伏笔与后续线索

1. **向家**：王林此行真正目的地，由「画轴女子」指明，本章尚未启程。
2. **雷仙使者身份误认**：冉月的猜测将直接影响王林在罗云星域的处境与待遇。
3. **赤耀石**：其真实价值本章未揭，王林不识。
4. **冉云星之行**：正北方十日星路，四人愿带路，构成下一步行程。

## 七、归属说明

- 本章「王林」即王林本人（白衣青年、乘银光、元神含太古雷龙），无化名冒充情形。
- 原文一处「孙云山」与「孙雪山」为同一人的异写。
- 「罗天星域」与「罗云星域」在本章交替出现，指同一星域。
