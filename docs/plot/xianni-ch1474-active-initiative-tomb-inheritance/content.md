# 第九卷 云海之巅 第1474章 主动（第四更）

## 一、一吼之力：掌尊掌印崩溃、重伤遁走

- 古墓中的吼声之下，掌尊施展的**井中捞月**掌印毫无抵抗、如枯木般直接崩溃。
- 吼声顺裂缝宣泄至外界，落在漂浮星空中的黑袍人（掌尊）心神。
- 掌尊袍内容颜骤变、身躯剧震喷血，疯狂后退仅三步，双腿骤然爆开——**没有血肉，只有白骨**；黑袍撕开大半，惨叫中急退遁走。
- 身份定位：**一代掌尊，太古星辰最神秘之修**，曾对王林施展井中捞月之术；此刻如丧家之犬。
- 旧事呼应：当年他在界内曾被一人吼声退出亿万里、直接退出界内；今日再被一吼之力所退。
- 悬念：**这两次吼声是否同一人，除他之外无人知晓**（原文亦点明「是一人，或者不是」）。

## 二、王林放白衣女子出裂缝，并封印古墓

- 太古星辰的这道裂缝急速收缩；古墓内白衣女子面色苍白赶至裂缝旁。
- 她虽以特殊方法保留了肉身存在，仍被吼声震伤，时间上来不及离去，近乎绝望。
- 王林以神识之音道：**「你帮我一次，我也帮你一次」**；话语出口瞬间，将闭合的裂缝突然一顿。
- 白衣女子压下震惊，直奔裂缝迈出；回身深望古墓，隐隐感到王林神识存在，忆起此前神识在自己身上停留、「全身被看光」的羞恼，复杂之色一闪而过。
- 她出去的瞬间，裂缝骤然收缩、消失于太古星辰。
- 王林神识退去前，**以这墓地的意志将古墓封印万万年**。
- 动机：掌尊未死，必知白衣女子曾入古墓；若发觉其竟已离开，会否心中起疑——「若真起疑也不枉费我的一番动作」。

## 三、面对重伤拓森：不出手的两个理由

- 神识归体后，因神识与古墓意志融合，王林坐在宫殿座椅上**再无半点排斥之力**。
- 破损的虚幻大网内，拓森被一吼之力卷动，极为狼狈：血肉模糊、森森白骨，残存血肉急速蠕动愈合。
- 拓森重伤是极难得的机会，换任何人都会出手，**王林没有**：
  1. **古神尊严**——他是古神，拓森也是古神，古神应有古神的尊严；有七星之前他会不假思索出手，眼下他要与**完整的拓森**一战。
  2. **他自己更需要时间**——不能起身离座去战。
- 王林居高临下、霸道气势融入声音落入拓森心神：
  > 「你古神星点多次碎开，尽管被你不知以什么方法恢复，重新达到了八星，但终究还是不如当年了。」
- 拓森沉默，加快恢复肉身速度。其自**朱雀星脱困**后占据了**涂司的肉身**——存活万古岁月的**八星王族古神**之躯。

## 四、谋求完整古魔分身：以魔气灌注古魔尸体

- 王林现状：眉心**七颗星点**旋转；右目内魔气成漩，凝聚**古魔之星**。
- 限制：所获传承因**没有古妖之力**而不完全，古魔之星无法彻底凝聚；破解之法——**除非拥有完整的古魔分身**。
- 古之墓地宫殿内尚存古之三族石化尸体，其中一尊**千丈大小、保持生前狰狞的古魔尸体**格外显眼。
- 王林右手虚空一抓，尸体飞至身前被按住；右目魔气纵横顺右手涌入，石化肉身如**无底洞**般不断融入魔气。
- 遗憾：**「可惜这里没有王族古魔，这具尸体，也仅仅有一些王族古魔的气息罢了」**。
- 灌注魔气期间，王林双眼始终盯着虚幻大网后急速疗伤的拓森。

## 五、关键抉择：主动斩断融合、逆转吸取传承

- 悖论：排斥之力消散的同时，**座椅内那让王林红眼的传承气息也一并没有了**。
- 冥冥明悟（源自神识与墓地意志融合）：**一旦起身，即便再次坐下，也将不会再有任何传承出现**——故他不能起身。
- 王林不满足于仅凭传承成为七星古神，**他要更多传承**；要让传承气息一如既往数倍暴增、从第三层那跳动的心脏内逼出，唯一办法就是**让排斥之力再现**。
- 决断：明知拓森在外、排斥之力凶险无比，仍**毅然斩断自己神识与墓地意志的融合**。
- 结果：座椅再次爆发惊天动地的排斥之力；第三层跳动的心脏中一股股传承气息轰轰涌入座椅。
- 姿态逆转（本章题眼「主动」）：七星古神之强远超六星，王林凝固身子半点不动抵抗反震，**不再封锁体内借来的气势**（此前担心被收走），放开一切，在座椅反震之下**主动强行吸收座椅内弥漫的传承气息**。
