# 仙逆 第823章 姚长空（段2/3）——封仙印杀局与帝仙符封身

## 一、王林抢先机：偷袭 + 融入天地的鬼魅战法

- 王林抱拳作势欲言，张口刹那喷出一道元神精气，化作虚幻之剑疾冲姚长东；同时身子前踏，消失于虚无。
- 姚长东掐诀按出青光化骷髅头吞剑，抬手刹那身后波纹晃动——王林现身、右手双指成剑一点，不看结果即退散。
- 此后王林如鬼魅般在姚长东身旁不断闪现，**每次只攻击一下便融入天地**。姚长东次次转身落空，被迫处处抵抗、无法主动出击，心中烦躁。
- 姚长东自述：修道至今交手不少，从未有过如此被动的一战。

## 二、封仙印与二十道斩罗诀的合击杀局

- 天空封仙印旋转砸落，印上**数十万金符**一一幻化，笼罩天地向姚长东封印；十丈大印反复来临，加剧其烦躁。
- 姚长东脚下三丈大剑分裂为**十九把小剑**，结成剑阵旋转外冲，卷起剑气风暴，扭曲四周天地之力；王林退至百丈外。
- 王林低喝「封」，更多金符更快冲入剑阵漩涡；封仙印再砸，被姚长东以剑气漩涡顶住一顿。
- 姚长东欲一步踏出封仙印范围时，**塔山**闪现身前一拳轰出（剑气漩涡落其拳上，塔山面色苍白仍再挥一拳）。
- 王林虚空一抓取出**仙剑**（许立国早已缩进剑内），连施**二十道斩罗诀**，耗费大量元力，刹那凝聚成一道「斩开规则」的庞大剑技，星空如被撕裂一道口子直奔姚长东，生生斩开剑阵漩涡，金符顺裂缝涌入封印。
- 王林随即踏出，现身于半空封仙印之上，盘膝双手掐诀下按，以全身元力灌注封仙印砸落。
- **四击同时到达**：封印、斩罗诀、塔山之拳、封仙印。巨响传遍方圆万里，如一颗修真星崩溃。

## 三、仙人金丹：杀局失败

- 一声愤怒咆哮，可怕气息如狂龙弥漫，封仙印被掀起，无数金符如被撕碎退散；塔山右拳骨碎、半身受创被抛出。
- 姚长东披头散发、衣衫破碎但**未受半点伤**——身前一颗拳头大小、形似修士金丹之物吸收了全部攻击。
- 姚长东咬牙：「你是第二个逼我用出老祖所赐**仙人金丹**者。」其杀机除家族**天穹令**外，绝大部分源自这股怒火。
- 王林退后，拍储物袋取出**尊魂幡**，抓出两个阴虚元神吞下补元力。
- 王林判断：**阳实境界与窥涅初期差距巨大**——此杀局可杀任何阳实修士，对姚长东却无用；即便没有金丹，姚长东也必有其他仙术。并推想「传承至仙界的修真家族，渊源流传的仙术定然不少」。

## 四、姚长东的仙术连击

| 仙术 | 表现 |
|---|---|
| 虚崩 | 所指之处星空坍塌崩溃，形成巨大冲击 |
| 随影之崩 | 崩溃如影随形、入髓入骨追近不舍 |
| 十九魂 | 吐出白雾，内含十九个全身漆黑、状若鬼物的婴儿冲敌；可旋转合成一个放大婴儿的虚幻之影 |
| 云劫 | 身外散出雷光云雾，彼此连接成全方位守护 |
| 血魂六转 | 喷元神精血勾出血色漩涡旋风；先祖**血神子**所传，据传为当年仙界先祖大神通，最高血魂十九转，姚长东仅能六转且耗元力极多 |

王林的应对：
- 闪至身后十丈施斩罗诀 → 被绕来的仙人金丹吸收。
- 遇十九魂即融入天地，婴魂扑空回旋。
- 姚长东**捏碎仙人金丹**（宁受老祖责罚也要破此神通），爆发毁灭风暴，扭曲方圆万丈天地之力使其失衡——融入天地者若无「拨乱反正」的神通必须尽快离开。
- 王林现身百丈外，指出**子母道枯**，狰狞兽骨双目幽光一闪、煞气弥漫，将姚长东的婴儿虚影咆哮到一半即**石化**；王林趁机后退，再从尊魂幡取两个阴虚元神吞下。
- 王林施**呼风**：黑风扩散化作黑龙，喷出阴风，姚长东全身一寒、元神欲崩，云劫云雾刹那消散，惊呼「这是什么仙术」，被迫以血魂六转的血色旋风与阴风相互消融。

## 五、帝仙符：王林被封

- 姚长东拍储物袋取出一张**纸符**（老祖所赐神符）：暗红铭文勾勒复杂印记，掐诀、咬破舌尖喷血染符，铭文如活、燃起赤色火焰，喝「**帝仙符，杀此人**」。
- 该符穿透血魂漩涡与阴风毫无损伤，直奔王林眉心。王林认出它与自己储物袋内两张纸符几乎一模一样，但其上气息令其心神剧震，判定「不能抵挡」。
- 王林急退：放出**射神车**，同时取出自己的一张纸符，学姚长东咬舌喷精血激活对撞。王林的符全部燃尽成灰，姚长东的符**残余指甲大小一片**穿透而至，落在王林眉心。
- 眉心如火燃烧，封印之力瞬息蔓延全身，**元力连同元神全部被封印**，王林虚弱如凡人。惊道：「这是**仙遗族的符文之力**——但仙遗族的符文，怎么可能这么强？」
- 王林所有法宝停转、呼风消散。**塔山**急速赶来，让王林盘膝坐于其左手，才未坠入下方无尽星空。

## 六、蝴蝶反击（本段结尾）

- 射神车化作蝴蝶悬于王林身旁，看似无害。
- 姚长东大笑迈步，右手双指成剑直取王林眉心，喝：「区区阳实修为，也敢与我斗？**许木**，你去死！」——此指若中，肉身崩溃且元神无法逃脱。
- 蝴蝶**虽无王林元力驱使，但一旦开启便自成循环**，翅膀轻轻一扇：姚长东身子一顿、胸口炸裂、被抛出十丈；翅膀再扇。
- 姚长东杀机一闪，再取一张纸符，这次不抛出而是**按在自己眉心**，符文之力爆发，大片符文在其身外星空中幻化而出。（悬念，接段3）

## 七、要点归纳

1. 战力标尺：阳实巅峰杀局 ≠ 窥涅初期可伤，境界鸿沟被明确点出。
2. 姚家底牌来自「传承至仙界的修真家族」：仙人金丹（吸收一切攻击的护身丹）、帝仙符（仙遗族符文之力的杀符）、血魂仙术（血神子传承）。
3. 王林手牌清点：元神精气偷袭、融入天地闪现、斩罗诀（可叠加至二十道斩规则）、封仙印（数十万金符）、呼风（黑龙阴风克元神）、子母道枯（石化煞气）、尊魂幡（吞阴虚元神补元力）、仙剑（许立国寄居）、射神车（自成循环，不依赖主人元力）、帝仙符×2（用掉一张）。
4. 化名：本段王林以「许木」之名行事（自661/669/711章沿用，疑为自创化名）。
