# 第603章 有杀气……

## 一、子鼠之死的收尾
- 王林飞走一刻，地面上子鼠肉身**全部枯萎、失去生机**，元神已崩溃，肉身自半空摔落。
- 子鼠**眉心之上有一道金芒微微闪烁**（未展开说明，疑与其师尊有关，为伏笔）。
- 双方差距太大，子鼠**师尊所赠的那道剑气都没来得及施展**便已身亡。

## 二、王林的疯狂状态
- 体内**仙力暴虐游走**，充斥经脉与元神；叠加**升仙果**的刺激。
- 表现：双眼通红、战意滔天、杀机无限；脚踏半空如踏碎天空，大步流星急速而行。
- **关键机制——杀意敏感**：此刻王林对杀意的敏感堪称恐怖，不主动招惹者不被理会；一旦对其生出杀意，几乎瞬间被察觉，**凡有杀意者，毫不犹豫杀之**。
- 沿途所过：大地不断枯萎，草木鸟兽尽死化白芒，在寂灭下滋养其身，如来自魔界地狱般吞噬一切生机。

## 三、新出场设定：莫域与莫祖
- **莫域**：天运星远处的一个**私人星球**。
- **莫祖**：莫域之主，自称莫祖，修为达**问鼎阴阳虚实**中的**阴虚之中**。
- 因修为超过进入妖灵之地的资格，本人未入；其**亲传弟子三人**，除首徒外，其余二人进入妖灵之地。

## 四、灭莫祖二弟子
1. 两名灰衣青年（均**婴变后期**）在火妖郡急速飞行，其中一人遥感前方有『远古凶兽』般的无法想象的杀机直冲而来，急喝『师弟，速退』，二人立即散开。
2. 王林如流星踏步从二人身边一晃而过——二人认出『问鼎』，并发现其**身受伤**。
3. 师弟传音起意：问鼎修士身上定有不少宝贝，可夺其**妖晶**；师兄权衡『你我都是婴变后期，联手战一个受伤的问鼎，配合法宝或可一搏』。
4. **杀意即被感知**：王林脚步一顿，血红双眼回望，喃喃『有杀气』，身化奔雷去而复返。
5. 击杀师弟：一指点向眉心，此指『好似代表了天道』，青年身子枯萎摔落，元神刹那崩溃，肉身精华与元神化作**杀戮之气**从七窍钻出飞向王林。
6. 击杀师兄：其惊醒后立即**瞬移**踏入虚无；王林右手成爪穿透虚无，硬生生把人抓出，其急呼『我是莫祖弟——』未毕即被一捏崩溃，化血肉洒落大地，生机化灰气飞向王林。
7. 结果：王林眼中红芒更浓、战意更盛，继续疾驰。

## 五、火妖郡围剿部署
- **动机**：王林在火妖郡内的飞行路线几乎是**一条直线**，这条直线上万物枯亡，造成大量死亡，对一郡而言是**耻辱与挑衅**。
- **兵力**：数十个妖将被派出围剿这个『大孽不道的修士』。
- **地点**：火妖郡与**天妖郡**交界处的**万妖山**——山上浓雾弥漫长久不散；山两侧各有一城，火妖郡一侧为**天逸城**，对面天妖郡一侧为**融火城**。
- **天逸城内**：十万妖兵整装待发，十多个妖将立于城阁，中间是一名神态阴沉的**中年男子（副帅）**。

### 副帅其人
- 身份极为尊贵，众妖将对其笑谈中仍露恭敬（『有副帅大人在，我等谈笑间便可使得那人灰飞烟灭』）。
- 本为**私事**要去一趟天妖郡，刚到此地便接**火妖郡妖帝之命**，须停留数日统领妖将击杀一个修士，颇为无奈，认为『杀一个修士根本不用派这么多人』。
- 交代『你等速战速决，杀了那修士后，我就会离开』。

### 情报与疑点
- 妖将确认：已派多人查探，此人所行是一条直线，必经此地。
- **疑虑**：派出查探之人**十人中死了三个，而非全部死亡**，令下属费解——『那修士杀人，似乎有某种癖好一般』。（呼应王林只杀有杀意者的机制）

## 六、尹东出战与秒杀
- 青色铠甲妖将**尹东**主动请缨『愿出战杀了此人』，欲在副帅面前漂亮杀敌以求赏识、青云直上。
- 尹东自估：**妖力已近三十万**，与真正的问鼎一战把握不大，但对方重伤，杀之不难。
- 尹东施展几乎全部妖力大喝『来者止步』，声如雷霆，城内**十万妖兵齐齐助威**，浓浓杀气弥漫天地；副帅暗赞其『懂得以势压人』。
- **反噬**：这股天地杀气被王林的恐怖敏感瞬间察觉，本已疯狂的战意**无数倍爆发**——这声势实为『打开了一道通向地狱的血腥之门』。
- 王林身子不停，抬头右手向前一点，**寂灭指**化作**数丈粗细的黑芒**迅猛爆发；尹东连闪躲都来不及，被黑芒笼罩，肉眼可见地枯萎、崩溃。

## 七、大战开启
- 十万妖兵呐喊骤止，诡异安静笼罩四周；副帅**第一次露出慎重表情**。
- 王林仰天咆哮『杀』，将刚吸收的**三万多道杀戮之气**全部散出，化作**三万多条苍龙**环绕己身，好似**魔尊降临**。
- 妖将中一名老者大喝『各都统听令，阵法灭敌』，十万妖兵出动；王林身外三万杀戮之气疯狂降临，腥风血雨就此展开。

## 八、要点小结
- 王林当前定位：他人眼中的『受伤的问鼎初期修士』，实际战力远超估计（一指秒杀婴变后期、秒杀近三十万妖力妖将）。
- 本章确立两条战斗规则：①杀意=死亡触发器；②寂灭/枯萎类杀戮吸收生机反哺自身，杀戮之气可外放为苍龙作战。
- 势力线新增：莫域·莫祖（阴虚）与其门下；火妖郡妖帝—副帅—妖将—都统—妖兵的军制层级。
