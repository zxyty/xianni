# 第九卷 云海之巅 第1260章 隐现生死劫

> 世界状态须知：本章「吕子浩」即王林（自第1063章起以归元宗故人吕子浩之名行事，身份由吕烟菲奉上）。

## 一、余波：一战成名

- 残夜之力已震撼全场，流月神通中的「岁月逆转」更是前所未闻；除白发老者（无极宗太上长老）外，四周数万观战修士心神尽被吸摄，各自经历不同程度的岁月逆转与无尽回忆。
- 众修看向王林的目光尽是敬畏。此地无人不知归元宗，无人不知归元宗的「吕子浩」。
- 冯海对王林的怨恨被敬畏强行驱散，自忖在此神通下必死无疑；持同样心思的无极宗长老不在少数。
- 王林给人的印象只有「高深莫测」四字：众人普遍相信他远未施展全部神通，仍有杀手锏未出。加之此前传闻弥漫、又被认出是横闯六、七阶星域并施展神宗役灵印之人，其形象愈发莫测。
- **流传语**：此事之后无数年内，云海星域流传——「宁走兽雾界，不惹归元宗」。

## 二、无极宗高层的判断与决策

无极宗宗主（白袍老者）暗中判断：

- 此人当为**天人衰劫**修士，因重伤未愈故修为跌落，但一身神通尚在，方能与太上长老一战。
- 此人应无恶意，否则以其修为必藏有大量法宝，一旦辅以法宝将是恶斗。
- 结论：必须隆重礼待，且不能限制其自由；若能请其出战八阶大比，无极宗定可崛起。

## 三、旧识群像的反应

| 人物 | 反应 |
| --- | --- |
| 吕烟菲 | 心神震惊，回想百年前师尊死前施展择灵之术后的话语，眼内隐有晶莹 |
| 卢云从 | 一脸苦涩，自认修为增长仍远不及对方；醒悟若百年前强行出手，恐早已灰飞烟灭 |
| 李倩梅 | 心神震动，分不清百年前后的距离；对她而言修为变化不重要，重要的是她从妖宗离开只为看一个人，而她看到了 |
| 木冰眉 | 咬唇；自认昆虚一别后与他已成陌路，相遇亦只是擦肩而过，冷漠永不消散 |
| 王珊珊（神宗） | 无人察觉，她以玉简刻印所见一切，捏碎化烟传给神宗师尊 |

**伏笔**：王珊珊此举本属例行——发现云海天骄后有义务告知师尊，她甚至以为师尊会在大比中召此人入神宗。但这枚玉简在师尊看到后，掀起了一场轩然大浪（蝴蝶效应）。

## 四、认输与延揽

- 太上长老退至半空，称「老夫败了」，赞王林对天道的感悟极为深刻，看他的目光已如看同辈之人。王林面色苍白但神色从容，抱拳自谦。
- 无极宗宗主起身长笑，主动走到王林数十丈外抱拳致敬，毫无托大。
- 太上长老（宗主称其为**柳长老**）破例为一个宗派进言：「归元宗能有吕道友坐镇，若还在五阶星域，似乎有些不恰当。」此为其一生痴迷修道、不问世事以来首次，兼有修补方才试探与教训之意。
- **决定**：宗主当场许诺，让**归元宗搬迁进入七阶星域**。王林抱拳致谢。

## 五、交易条件

- 王林表态：八阶宗派大比可以出战，但重伤未愈，需向无极宗**索要一物疗伤**；若此物交付，则全力以赴。
- 王林以**神念**私下将所求之物告知宗主与太上长老，二人神色一动、相互对视、均都沉吟。
- 宗主似有顾忌，改邀王林前往山门小叙再谈，王林应允。

## 六、封锁消息

- 宗主命**冯海**负责余下事宜，并冷厉要求在场诸修「多居几日，莫要着急离去」。
- 用意：为数日后的八阶宗派盛典，彻底封锁王林存在的消息，以求奇兵之效；宁可得罪一些宗派。
- 宗主看向李倩梅与王珊珊等人略有犹豫，仅抱拳示意并未召唤。王林临走回头看了一眼身后，内心暗叹无言。

## 七、无极宗山门

- 山门不在大比所在的修真星上，三人破开苍穹出星球，踏入另一颗修真星。
- 无极宗身为八阶星域宗派，**山门即一整颗修真星**：壮观建筑耸立、阁楼无数、修道广场弥漫，全星禁制无处不在。
- 王林隐约看出星上有数百个被开辟出的空间裂缝，各有大小，另有乾坤。太上长老介绍：宗内有**空间界三百七十二处**，其中**一百一十一处无边无际**，其余为储物或历代大神通修士闭关之所。
- 沿途无极宗修士见三人皆放弃一切行为、恭敬抱拳静立，待三人离去方敢行动。

## 八、章末悬念：剑意山峰

- 王林前方出现一座直插云端的山峰，云层缭绕，仿若雾中之山，隐透仙气。
- 山峰弥漫出一股**剑之感悟**意境：好似此山化身利剑，直欲冲天斩开天地。
- 王林身子一顿，双目精光一闪，隐约似发现了什么，心神轰然一震（章末断在此处）。
