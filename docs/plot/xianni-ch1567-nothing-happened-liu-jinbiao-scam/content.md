# 第1567章 什么都没干

## 一、场景：修真星西北孤峰洞府
- 修真星西北方向山脉纵横、灵气充足，山下密林遮天，泥土常年潮湿。
- 密林深处有一座不高的孤峰，雾气缭绕，远看如雾山。
- 峰内藏有一处昏暗阴森的洞府，洞府中设有**传送阵**；五光十色的阵法光芒穿峰而出，持续数息后转弱。

## 二、抵达与「记账讨赏」局
- 传送光芒中现出三人：**疯子**（自称「本王」）、**许立国**、**刘金彪**。
- 疯子被一路传送绕得迷糊，问「这里是哪」。许立国强忍兴奋，阿谀称「王爷，到了」，并以「去看看那小娘子准备好了没有」支开话头。疯子一听「小娘子」立刻来了精神，许诺「本王有赏」。
- 刘金彪卷来石椅侍奉疯子坐下，卖力揉肩，轻重拿捏巧妙；随后骤然停手，双手奉上、弯腰低头，索要赏赐。
- 疯子起初拒绝：「本王的鲜血可是很宝贵的」——点明所求即其**鲜血**。
- 刘金彪逐笔列账施压：
  - 疯子来此修真星共 **13 天**；
  - 花费**灵石 73 万**、**银子 985 万两**（凡间城池所用）；
  - 声称这是自己「数千年来的全部积蓄」。
- 疯子记忆混乱，只记得「遇到好玩的、好吃的就让他们去弄来」，额头冒汗。
- 刘金彪话锋一转：主子有吩咐要照顾王爷，王爷不小气，只是暂时没灵石，「宝贝什么的都在**小红**那里」。疯子顺势推说所有东西都在小红身上，让刘金彪去找小红要。
- 刘金彪改用示弱：说「就算送给王爷好了，也不用去找小红索要」，随即走开望壁发呆，作失落状。
- 疯子心生亏欠，咬破指尖挤出**一滴鲜血**相赠，称「你是好人，和那许立国一样都是好人」；见刘金彪面无表情低声道谢，愈发过意不去，又挤出**七八滴鲜血**尽数奉上。刘金彪身子颤抖、难掩兴奋，急急收起并一拜。

## 三、「小娘子」与「法华子」
- 许立国自洞府拐角走出，低笑称「那小娘子准备好了」，看疯子的目光「好似在看一座移动的宝藏」。
- 洞府深处一间偏房，门口有暗色光幕阻隔，内中似有人盘膝而坐。
- 疯子入内，见到的却是一名**身穿黑衣、相貌极为英俊的青年修士**，自报「贫道**法华子**」。

## 四、骗局自陈：几十个传送阵，七三分成
- 房外许立国搓手兴奋，赞刘金彪「这骗局不错」，称**之前那几十个传送阵已得到不少血液**，并重申「按照约定，咱俩**七三分**」。
- 刘金彪的骗术论：
  - 「老夫当年所骗之人可没有什么疯子」，皆是**修为高深、心智过人之辈**，对付他们需设局严密、不能有丝毫破绽；
  - 疯子**心性简单**，复杂严密的骗局对他如对牛弹琴无效；
  - 故这次索性用了**最简单、漏洞百出却有效**的局。
- 许立国催促抓紧：完事后还有几个地方要去，须尽快结束并**做好善后**，「不然**那煞星**回来一旦知晓——」说到此处心神一颤，可见极为害怕。

## 五、「捉奸」局：十壶鲜血的勒索
- 许立国捏碎一枚**玉简**，传送阵再起光芒，现出**十多名凶神恶煞的修士**，带头者是一名**一脸冰霜的女修**。
- 双方碰面相视微笑（分明同谋）。许立国旋即在偏房门口发出凄厉惨叫：「王爷，不好，那法华子的道侣寻来了」，喷出一口灵体之气、萎靡倒地；刘金彪拍胸吐血。
- 女修撕开光幕率众闯入，喝斥疯子「你们居然干出这种事情」。疯子惊恐辩解：「**我们什么也没有干**……我就是问他叫什么名字」（呼应章名）。法华子面露羞愧，起身避于一旁沉默。
- 女修甩袖取出**十个玉壶**，勒令疯子「用你的鲜血把这十壶装满，否则我便先杀他们」；随即将浑身是血、身插利剑的许立国与刘金彪押入。
- 二人配合演出：许立国喊「王爷，不用管我，你快逃走」；刘金彪内心暗骂其台词失当，转而惨叫「王爷，我们是因你才被连累的，王爷豪爽，你要救我们」。

## 六、结局转折：白衣身影现身
- 众人做戏之际，无人发觉身后**无声无息走出一个身穿白衣、眼中寒光的身影**。
- 一声喝破全场：「**许立国，刘金彪，你二人好大的胆子。很好，很好嘛**」——骗局当场败露，章节至此收束。

## 七、要点与伏笔
- **疯子鲜血为核心标的**：其血极其宝贵，且已被二人用「几十个传送阵」的连环骗局反复榨取。
- **「小红」**：疯子的宝物财物尽在其处，被刘金彪当作施压的话术支点。
- **「主子」与「煞星」**：许立国、刘金彪奉「主子」之命照顾疯子，同时极度惧怕「那煞星」回来知晓——两者语境指向同一位上位者（依世界状态语境即王林），末尾白衣身影出现印证其归来。
- **刘金彪的骗道**：因人设局、简单局对简单人，是其骗术的方法论自陈。

## 八、存疑
- 白衣身影的身份文中未直接点名，仅以「煞星」与话语口吻暗示；本条以低置信度记为王林。
- 「疯子」与「小红」的真实身份、其鲜血为何珍贵，本章未交代。
