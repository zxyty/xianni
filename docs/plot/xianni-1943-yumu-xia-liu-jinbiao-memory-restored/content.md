# 第1943章 雨幕下（第三更）

## 一、仙罡大陆重逢：王林点破刘金彪

- 王林当面道破刘金彪的**骗道**，刘金彪身子颤抖，生出「来自灵魂的恐惧」，隐隐觉得这一幕「并非第一次遇到」。
- 王林答：「是你亲口告诉我的。」并喝酒相待。
- 刘金彪慌乱自保，抬出靠山：**「我家主人是孤崖天尊」**，威胁王林若伤他便形神俱灭；旋即又疑惑地问「莫非你是同道中人」。
- 王林报出双方姓名——「你叫做刘金彪，我叫做王林」——刘金彪对「王林」二字生出熟悉与挣扎，陷入痛苦。

## 二、破封：一指点开两世记忆

- 王林判断：**刘金彪无法自行破开封印，周佚不能，他也不能**；并暗忖不知是否有旧部能自行破封恢复记忆。
- 王林右手点其眉心，刘金彪脑海如「万万雷霆同时爆开」。

### 今生（转世后）记忆片段
- 自取名号：「金彪大仙，不朽之仙」→ 「老子姓刘，以后就叫刘金彪」。
- 自创名句「一旦成仙，鸡犬升天」，欲在**大圣洲**借此大发一笔。
- 骗术套路：自称「本仙转世重生，自然是童子的相貌」「本仙第一次降临凡尘」等。
- 七岁时因「村子内该骗的都差不多了」而外出发展；最早的记忆是四岁去骗邻家小孩的冰糖葫芦。
- 关键片段：遇见一贼眉鼠眼汉子，自称「应该叫许立国」，被刘金彪指点「你去中州，会有造化」。
- 自嘲：「说不定我前世就是个大骗子。」

### 前世记忆
- 苦修仙道，为求强大慢慢琢磨出**骗道**，凭一样法宝几乎无往不利。
- 最终栽在一个叫**王林**的修士面前，此后无数年忐忑跟随，直至轮回转世。
- 想起好友**许立国**：当年虽被其做过让自己不舒服的事，但二人臭味相投终成好友。

## 三、认主与拒认主

- 两世记忆重叠，刘金彪落泪，称「主人」，激动发自灵魂；他形容闭眼前还在**洞府界**，睁眼后如梦初醒。
- 王林大笑递酒：**「为我们在这仙罡大陆的见面，喝口酒。」**
- 刘金彪起身深拜，理由二：①送再造之恩；②借转世让其明白真正的骗道。
- 王林摇头：**「我不是你的主人，转世前你便自由，转世后，也是如此。」**
- 刘金彪以「仙罡大陆太危险」为由赖着跟随，王林应允：「你便随我，有我在，自然护你安生」，并说明其记忆已复、前世修为很容易重修上去。

## 四、骗道的顿悟（设定要点）

- 洞府界时刘金彪自以为骗道已达**第二步圆满**：可瞬间欺骗自己、让自己相信一切。
- 经这场「似梦非梦的转世」方悟：**这才是真正的骗道第二步**。
- 反推：若转世前欺骗自己是「一个九世善人」，转世后必定会继续以善人身份活下去。

## 五、许立国线索

- 刘金彪回报：约**数百年前**，在**东州天水洲**见过一名相貌极凶恶的山贼，自称「应该叫许立国」；因刘金彪当地小有名气，被请上山供奉，求指点仙缘，刘金彪胡乱指其去**中州**。
- 王林沉默片刻，忆起许立国魔头当年阿谀之态，微笑判断：以许立国的性格不会吃亏，若还在必定有了仙缘。
- 王林计划：**过段日子也要去中州**，看能否遇上；并笑想「他看到我后，会是什么表情」。
- 刘金彪暗喜自己是转世后第一个跟随王林之人，盘算趁许立国记忆未复「报答」当年被其以「第一个跟随主子」压人之事。
- 补记：刘金彪与**司徒南**并不熟，故其记忆中那个「想当王爷的家伙」（曾被他所骗）此刻已被忘记。

## 六、东临宗与雨幕

- **东临宗**：大圣洲内第一宗门，九宗十三门之一，向来神秘莫测，外人少知底细。
- 地貌：山峦起伏，其内多山谷、盆地；护山大阵挡不住王林。
- 王林曾在洞府界幻境中到过东临宗，此番临近时对大地与山门隐隐熟悉。
- 入宗后未先去**东临池**，而是先往幻境中**七彩仙尊苏道**生活过的地方：小山、清澈小河、游鱼、取水童子、山间石阶。
- 沿途有修士经过却毫无察觉二人，「仿若不是同一个空间」。
- 登顶时天生阴云、暴雨倾盆，雨落大殿外青石板荡起涟漪、溅碎雨、水汽弥漫欲升天而散于半空——与当年幻境极像，王林似在雨中有所升华，闭目一动不动。
