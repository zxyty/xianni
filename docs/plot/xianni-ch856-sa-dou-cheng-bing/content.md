# 第七卷 名震罗天 第856章 撒豆成兵

## 一、清水吞天雷
- 血神子以羽毛化作千里内无数兵器，清水轻蔑评之「风声鹤唳草木皆兵，没有真正的仙元，也敢称自创仙术」，看都不看，一步踏至王林身前。
- 七道七彩天雷疯狂落下。清水**右目红光**一闪，散出大片红芒如红色大口，将赤色天雷一口吞噬；再进吞橙色雷劫，七道天雷无一停顿，尽被右目所化之物吞尽。
- 吞雷后电弧弥漫其身，气息更冷更危险，右目红光近乎血色、蕴含「极」，观者心神剧震。清水自言「这天雷，不错，可以让我的**极境**有所恢复」，看王林的目光虽冷但有一丝不同。

## 二、师尊神通前三式
清水掐印回忆：

| 式 | 领悟耗时 |
| --- | --- |
| 呼风之术 | 一时三刻 |
| 唤雨神通 | 月余 |
| 撒豆成兵 | 足足百年方炼化而出 |

- 三式皆出自其**师尊**(血神子指认为**仙帝白凡**之仙术)。

## 三、撒豆成兵：仙魂点名
右手随意一挥，一片晶光无声浮现，千里内血神子的兵器立顿。晶光逐一散作死气缭绕的人影，清水逐一报出：

- **上古修士**：孟木、康染(眉清目秀少年，煞气浓)、吕杰 —— 「我杀此人于仙界之前」。
- **天仙**：五品天仙晨风(仙界之战)、八品天仙柔蝶(叛逃之战)。
- **仙王**：三品仙王圣天候(风之仙界一战)、七品仙王云梦(逐鹿一战)、九品仙王姚海青(仙术流散之战)。
- **仙君**：一品仙君流云(封仙君之战)、雨之仙界三品仙君曹德(闯仙之战)、五品仙君陈寒(叛乱之战)、风之仙界七品仙君火韩子(远古通道一战)、雨之仙界九品仙君青霜**第一分身**(雷雨仙战)。

### 术理
> 「我一生，杀孽太重，这撒豆成兵之术，便是要把内心所有杀孽一一祭炼，使得所有被杀之人，把他们的魂，从轮回虚无中抽出，让他们入不了轮回，炼化成本命之一，如此，撒豆成兵之术，便可小成。」

- 诸魂皆带强大杀机与怨气，死不瞑目、不甘入轮回，星空如同炼狱。
- **姚海青**之魂与血神子有几分相似(姚家先祖之一)，家族典籍语焉不详、从未提及其死于清水之手，血神子面色大变，惊呼「这哪里是什么仙帝，这分明就是魔尊」。
- 王林见青霜虚影后内心掀起轰天大浪，对这些仙魂身份毫不怀疑。

## 四、交战与波及
- 血神子红目、眉心妖光大闪，大吼**「草木之攻」**，千里羽毛兵器尽出迎击仙魂 → 神通一一瓦解，兵器全部碎裂，毫无抵抗之力。
- 仙魂临身自爆冲击血神子，四周无数仙魂凝聚，血神子眼中**第一次露出恐惧**——他已很久没感受过死亡威胁；尤忌数个仙君之魂(一两个尚可灭，眼下体内带伤又有清水在旁)。
- **姚云**在血神子身后抵抗，修为不济，连续损伤后萎靡不振，体内妖物几近崩溃。
- 战斗波及**整个罗天南域**，星空崩溃扩散、无法操控；时间一长浩劫必现且无法改变。

## 五、血神子的反击：吞姚云、召古妖、取古灯
- 清水虚空一抓化出黑色阴寒气团，答「杀你又如何」。
- 血神子退至姚云身旁，右手一指其眉心：姚云双目凸起、身子收缩，血肉、元力、元神被体内古妖尽数吸收，急速衰竭成皮包骨。
- 姚云临死眼中迷茫浑浊消散、**从未有过的清醒**，想起数千年一直找不到的记忆，惨笑留言：**「姚家，已经不在」**，身子自星空跌落。
- 头顶古妖虚影比先前凝实不少，如吞补品般飞出，带浓郁妖气融入血神子体内。
- 血神子妖气磅礴、双目幽光，右手在虚空一撕，缝隙中飘出**一盏古灯**。
- 放话：**「清水，你既找死，就莫要怪老夫弑仙」**——身上凝出高约数十丈的巨大虚幻**古妖之体**，血红双目直盯清水，发出无声咆哮。

## 六、悬念
- 古灯来历与「弑仙」之说未明；清水极境仅「有所恢复」，古妖虚体对阵撒豆成兵仙魂大军的结果本章未出。
- 姚云之死与「姚家已不在」，与姚海青之魂被清水所擒形成姚家因果双重打击。
