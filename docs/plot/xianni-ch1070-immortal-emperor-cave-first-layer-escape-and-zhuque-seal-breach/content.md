# 第八卷 联盟隐秘 第1070章（五更）｜仙帝洞府第一层突围

## 一、场景与在场者
地点：**妖灵之地** 内的 **仙帝洞府第一层**；同时并线于 **妖灵之地外的星空**。

洞府内一方：王林（本片段以「许木」之名行事）、司徒南（自第336章起自称司徒南的**司徒南的断臂**所化人影）、王巍、胡娟，以及四周众多修士。
对面一方：**古魔塔珈**，其身后立有 **虚空子**、**凌天候**、**天运子**。

## 二、古魔的“望月”之物
- 古神体内有 **望月** 为宠，古魔体内自然也有类似之物，那 **人形之物** 显然即是此类。
- 该物**并非古神生前就有**：是在古神死后被放置于此、**古魔与仙帝纠缠进入这洞府后分出**的，不知为何进入了 **葬仙池** 内的 **古神头颅** 之中。

## 三、三人状态速写
| 人物 | 状态 |
|---|---|
| 虚空子 | 双眼呆滞透出疯狂，眉心一枚符文印记透出森森魔气，被塔珈封印；王林清晰感到其气息大范围消散，**濒临死亡** |
| 凌天候 | 神色复杂，下意识避开王林目光，望着一旁不知在想什么 |
| 天运子 | 最为莫测——神色坦然，一如初入仙帝洞府时，目露一切了然于心之色，见王林望来**报以微笑** |

## 四、王林的判断与撤退
1. 禁制上的血液**只对古魔塔珈有效**，对天运子等人无用——这条布置已失去意义。
2. 好在此处已是仙帝洞府**第一层**，出去之路不难。
3. 心中不妙：之前一幕幕经历总有奇异之处却说不出古怪在哪；见天运子站在塔珈身后时，此感更浓。
4. 复盘所得（关键伏笔）：一切都发生在极短时间内，来不及思索；**众人的一切行动，都好似被那古魔逼出，仿佛皆是古魔有意而为**，一如天运子的算计般可怕。
5. 王林沉默中立刻后退。司徒南（断臂人影）一直望着他，见状不假思索直奔王林与之同退；王巍、胡娟同样如此；四周修士纷纷争先疾驰。

## 五、灰衣天运子破禁 vs 三人合布禁制
- 天运子微笑抬手一指，体内灰芒一闪，**灰衣天运子**幻化而出；它冷冷扫了天运子本尊一眼、哼了一声，仍直奔禁制而去。
- 无数杀戮之气瞬息化作无尽，冲入禁制，禁制剧烈闪烁。
- 但禁制并非王林一人所布，还有王巍与胡娟——**胡娟的禁制之术已登峰造极，超出王林甚多**，故灰衣天运子难以轻松破开，为众人争取到时间。

## 六、合力凿破壁垒
- 王巍后退中右手一指上方，水幕轰然而出，化作**海水组成的巨人**，挥拳砸向上方，地动山摇、大片碎石脱落。
- 胡娟不退，站在远处双手掐诀，不断打出大片禁制落地，巩固禁制之威。
- 王林掐诀神通环绕，与王巍一同攻击上方；四周众人纷纷出手，轰鸣回荡于第一层。

## 七、并线：朱雀真灵定位并轰击妖灵之地封印
- 妖灵之地外的星空，**六名碎涅修士**环绕 **朱雀真灵** 盘膝掐诀、咒语弥漫，时而抬指点入真灵体内，使其火焰更浓。
- 片刻后朱雀真灵嘶鸣，赤红火海轰然散开：其高温**对朱雀圣宗之人无效**，却可焚烧四周一切**肉眼与神识都看不到的尘埃**。
- 焚烧之下四周尘埃尽数崩溃，**唯有一处存在**——那就是妖灵之地所在。该尘埃燃起火焰，位置清晰落入众人眼中。
- 朱雀真灵嘶鸣冲出，不断撞击尘埃上的封印，每撞一次封印便松动一分；六名碎涅修士同时展开神通轰击。此封印乃**当年在仙界之时由青霖亲手留下**。

## 八、内外共振与收束
- 外部撞击清晰传入妖灵之地内，整个妖灵之地大范围震动，洞府中众人亦清晰感受到震动越来越剧烈；但此刻无人分心去理会。
- 众人不断攻击之下，**仙帝洞府与妖灵之地的壁垒轰然崩溃**。
- 几乎同一瞬间，**灰衣天运子破开胡娟的禁制冲出**；胡娟面色苍白，被王巍一拉，带着她直奔破开的壁垒而去。

## 九、悬念
- 王林所感的“一切皆被古魔逼出”尚未点破，指向古魔塔珈（乃至天运子）的更深布局。
- 妖灵之地封印在朱雀真灵与六名碎涅修士轰击下即将告破，内外两条线正在合流。

> 归属说明：本片段中「司徒南」的言行归属于**司徒南的断臂**所化人影（自第336章起自称司徒南，真司徒南第61章已死，真伪未定）；王林本片段以自创化名「许木」行事。

# 第987章 · 古魔塔珈魔龙屠戮与壁垒突围伤亡

## 一、魔龙出世：壁垒内的第一轮屠戮

- 古魔**塔珈**一步踏出，面带阴森微笑，张口一吸，无尽**魔气**疯狂散出，化作一条条**黑龙**咆哮扑向众人。
- **尘道三子中的老二**被一条魔龙缠绕，挣扎中眼露绝望，被古魔吞噬身亡。**王林有心去救，晚了一步。**
- **村姑美妇的一名女弟子**同样被黑龙卷起（按世界状态：村姑美妇本人已于第977章死亡，此处为其门下弟子）。
- **千琴**面色苍白，眼看将被黑龙横扫——**粉衣女子**一闪而出，全身雪花旋转，拉住千琴直奔已打开的**壁垒**而去。
  - 黑龙落于其身，与雪花碰撞；粉衣女子喷出鲜血，其**雪花法宝**在多次阻挡后碎裂。
  - 但粉衣女子仍拉着千琴冲了出去。

## 二、突围：众人冲出壁垒

- **大头童子**等人在以下助力下全部冲出：
  - **司徒南**（按世界状态须知：自第336章起自称司徒南者实为「司徒南的断臂」所化人影，真司徒南第61章已死）；
  - **浮沉子**；
  - **王林从储物袋召唤出的银衣女子**。

## 三、第二击：一捏之威，妖灵之地上的崩溃

古魔塔珈一步迈出，右手向前狠狠一捏，浩荡之威弥漫刚踏上**妖灵之地**的众人：

| 对象 | 后果 |
|---|---|
| 千琴 | 修为不足，喷血，**肉身崩溃** |
| 粉衣女子 | 身子一颤，**肉身崩溃化作血雾** |
| 尘道三子第三子 | **肉身崩溃**，元神被一尘子救下急速逃遁 |
| 一尘子 | 存活，救下三弟元神后逃遁 |
| 雷吉 | 肉身强悍，仍**崩溃一半**，残余半身被大头童子救走 |
| 大头童子 | **侥幸未受损**，反向救人 |
| 浮沉子 | 净涅修为，重伤喷血，**肉身未崩溃** |
| 司徒南 | 净涅修为，重伤喷血肉身未崩，但**体内毒素发作**，表情诡异 |
| 王林 | 喷血，神色黯淡，**元神大范围萎靡** |

### 关键设定点：元神融合

粉衣女子元神之上有一件**得自昆虚之境的法宝**，此刻闪烁，将她与千琴的元神一并笼罩。二女元神俱受重创，又被同一法宝笼罩，**彼此之间竟出现了融合**。这是本章最重要的伏笔性变化。

## 四、因果：王巍、胡娟的报恩

- 古魔此神通**原本足以令这些人全部形神俱灭**。
- 结果之所以未至最坏，是因**王巍与胡娟**在塔珈出手的刹那立刻上前阻挡对抗，**承受了绝大部分神通**。
- 二人如此做的理由：他们知晓这些人中有一部分与**王林关系莫逆**，**王林的恩，他们要报**。
- **王林**亦同时对抗该神通，与王巍、胡娟三方分担后：喷出鲜血，神色黯淡，体内元神连连重伤、出现大范围萎靡；**尽管体内火元力无穷，却无法阻止元神的消散**。

## 五、要点与悬念

1. 古魔塔珈展现的是压制全场的碾压级神通（吞噬型魔龙 + 隔空一捏的形神俱灭之威）。
2. 王林当前的核心危机不在肉身而在**元神消散**——火元力无穷亦无解。
3. 千琴与粉衣女子的**元神融合**为后续身份/存续问题埋下伏笔。
4. 司徒南（断臂人影）**毒素发作**是另一条独立隐患线。
5. 王巍、胡娟的舍身为「因果/报恩」母题的又一次兑现。


# 古魔塔珈破青霖第一规则 · 花妃启动第二重规则

## 一、王林疗伤与敌情
- 敌人：**占据青霖肉身的古魔**（自称『本魔』，名 **塔珈**）。
- 王林连续受创，**古神皮甲**在这种连续伤势下已无法起到太大作用。
- 王林不假思索，从储物袋取出**王巍此前所赠的蜡丸**，捏碎吞服；丹药神奇，服下后**元神之伤立即停止扩散并飞快痊愈**。

## 二、王巍、胡娟夫妇的托付
- 二人神色不振，后退中鲜血自嘴角流下，相视苦笑，眼中却有坚定。
- 王巍言：**「我二人拼死拖住古魔，恩师复活之事从此不提」**，并托王林**日后若有机会，代夫妇二人救活青霜**。
- 王巍右手一抓，身前出现裂缝，**将周佚从裂缝内甩出**（送其脱离战场）。
- 王巍自陈：夫妇二人**已存活太久**，**多次进入这洞府**，却因某些原因**始终无法接近恩师**；没想到此次接近之后竟是这种结果，神色复杂。

## 三、塔珈的自陈：青霖的第一重规则已被破
- 古魔塔珈**缓缓从壁垒内走出**，望天狂笑，神色激动。
- 其自述青霖的布置：为防止被夺舍成功后离开，青霖**定下规则**——塔珈**以青霖肉身之下无法最终离开这洞府，更无法摧毁任何一个禁制**。
- 塔珈的破法：**只用『区区幻术』**，便使这些前来救青霖之人**「如驱赶一般为本魔开道」**，轻松破开了青霖制定的规则。
- 后果：王巍、胡娟顿时面无血色；王林倒吸口气，**心中一直环绕的不妙之感豁然开朗**，看向古魔的目光一缩。
- 塔珈抬起右手，眼露嗜血疯狂：**「现在，就让你们见识一下本魔，真正的力量」**。

## 四、花妃现身：第二重规则
- 刹那间大地一颤，天空扭曲，浮现一座虚幻画面：**环绕在姹紫千红花海内的宫殿**。
- 冰冷动听的声音回荡天地，虚幻大殿内走出**一名白衣女子**——王林认出：**「花妃」**。
- 花妃宣告：自称**「我夫君青霖」**，即青霖之妻；古魔**「你能破一」**，但**走出洞府的你，同样踏入了夫君对你的第二个规则**。

## 五、同一时刻：妖灵之地封印松动
- 妖灵之地所在的**尘埃**，在**朱雀真灵**的不断轰击下，**封印最终松动，随时可以破开**。
- 同时，一种**与星球内曰初有区别的『星空初之规则』所成之芒**照耀在妖灵之地尘埃所在之处——**它所在之处，便是曰初之时**。

## 六、要点与悬念
- 青霖对古魔的防范是**多重规则叠加**：第一重（不得离洞府/不得毁禁制）已被幻术借外人之手破解，第二重于其出洞府时触发。
- 未决线索：**青霜的救活**（王巍夫妇遗托）、**恩师复活之事就此搁置**、**塔珈『真正的力量』**尚未展示、**妖灵之地封印破开在即**。
