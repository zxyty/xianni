# 第十卷 叱咤界内 第1514章 螳臂挡车

## 一、幽冥兽的恐惧与安抚

- 幽冥兽被在场众多大能死死盯住，感到目光『要把自己穿透』，恐惧到吼声如雷——旁人听来是愤怒咆哮，实为极度惊惧。
- 因与王林**本命相连**，在它感受中王林是其最亲之人。受惊后它不逃反冲，如孩童扑向父母怀抱，直奔王林而去。
- 众修士（含大能）骇然齐齐后退，唯王林上前一步，右手按抚其身，并以心神传出安抚，幽冥兽恐惧渐消，如小猫般用巨大头颅轻拱王林。
- 这一『轻拱』撞击轰隆作响，**力量不弱于第三步大能全力一击**。回溯：当年在罗天时，此兽一撞曾令王林后退，可见其力大无穷。

## 二、群修的贪念与幻灭

| 人物 | 出身/立场 | 反应 |
| --- | --- | --- |
| 周德（黑衣老者） | 召河星域大能 | 先舔唇垂涎『要是老夫也能有一只』，见撞击之力后惊为『养祖宗』，贪念半点不剩 |
| 云烽子 | 大能 | 疑惑此兽能吞金色风暴『与传闻不大一样』，起贪念；后设想战斗中被它高兴撞一下，头皮发麻，自认养不起 |
| 鬼宗、妖宗大神通 | — | 骇然又狂热：『有此兽在身边，就算不是大能，也足以名震』 |
| 红杉子 + 联盟尸阴宗老者 | — | 对望一眼，认定：王林竟能收服**本命之兽**，『封尊的选择，应该不会错了』 |

- 结论：残酷现实瓦解一切贪念，众修清醒——只有王林强悍的肉身才敢养此兽。

## 三、幽冥兽的性情反转

- 恐惧消失后爆发隐藏性格：尾巴一摇、神色狰狞，转而向四周先前令它害怕的修士低吼。
- 皮肤泌出大量绒毛并根根竖起，威武虎视，作出前冲之势，却似被无形之绳拉住，始终不离王林身边，只能怒吼更重。
- 连王林也为这反差愣了一下。

## 四、王林 vs 水道子：螳臂挡车

1. **水道子逃遁**：趁众人目光皆被幽冥兽吸引，身子疾退。水道子眼中恐惧透出绝望——全部计划因这头幽冥兽而改变。
2. **王林追击**：王林目光一闪，『别人或许会忘记水道子，但他绝不会忽略』，向后一步迈出，天地轰轰，直奔水道子。
3. **水道子反击**：掐诀喷出一口紫黑鲜血，阴寒弥漫八方，其内又生炙热，寒炎急速转换，化作圆形暗紫色漩涡轰向王林。
4. **王林第二拳**（此前对峙中未打出的那一拳）：巨大虚幻拳影迎上漩涡，轰鸣横扫整颗修真星与云海星域。
   - 拳头先被急速蔓延的冰层笼罩，成冰雕状；
   - 漩涡内火热之力轰出，冰层未及融化即骤然崩溃、四分五裂；
   - 水道子红着眼吼『给我爆』，但拳势不散，破开一切阻挡，以毁灭天地之势砸落。
5. **结果**：水道子双臂硬挡，砰砰之下双臂崩溃、血肉横飞、臂内白骨寸寸碎开——如螳臂挡车；虚幻巨拳随即砸中其身，血肉爆开，**肉身彻底崩溃**（应验王林此前所言）。其**元神在肉身瓦解前逃遁**，带着滔天恐惧疯狂后逃。

## 五、因果与形象

- 王林半空冷漠而立，一头白发飘摇、一身白衣舞动，在四周修士眼中『如同一尊战仙』，此景令众人一生难忘。
- 王林点明因果：『水道子，你当年让王某濒临死亡，在你面前一切还手之力都脆弱不堪，你可曾想过会有一日，你在我王林面前，如丧家之犬——这，便是因果。接下来，取你之命。』他等这一天已很久。

## 六、水道子求饶（章末悬置）

- 水道子虽为第三步大能，心性远不如修为，生死危机下顾不得颜面，咆哮求生：
  - 『我是**神宗长老**，我是**云海大能**，我是**封尊之奴**，你不能杀我』
  - 筹码：『我可以为界内立功，我知晓**界外信息**』
  - 乞求：『我愿成你之奴仆，你别杀我』
- 悬念：王林是否取其性命、界外信息为何，本章未交代。

## 备注

- 世界状态须知列有『水道子已于第1242章死亡』；本章水道子作为神宗长老、第三步大能正面出场并被击溃肉身，与该条目不符，此处按本章正文如实记录，死亡归属存疑待核。
