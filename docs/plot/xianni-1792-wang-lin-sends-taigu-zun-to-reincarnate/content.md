# 第1792章 今夕王家送投胎！（第三更）

## 一、洞府界众人拜别赴转世

王林身边之人一个个离去，临走前皆与王林一拜，走向洞府大门去追寻梦想。

- **十三**：跪在虚空向王林一拜，双眼坚定，言『师尊，十三走了，即便记忆没有苏醒，十三也坚信自己绝不会忘记师尊传道之恩，即便转世投胎，此事也定不忘』。其意志极坚，很可能在记忆被封印后仍保留本能——即他最在意的与王林的师徒之情。
- **司徒南**（据世界状态须知：自第336章起自称司徒南者实为司徒南的断臂所化人影，真司徒南第61章已死）：性格洒脱，笑声中化作长虹走向洞府大门，反手抛出一个酒壶给王林，『这辈子喜欢喝酒，下辈子不知道如何，这酒壶给你，寻到我后再给我就是』，并大笑『老子一定要投胎成为王爷』。能否如愿，玄罗与王林皆不确定；王林神色古怪，总觉此事不会如其想象。
- **李倩梅**（据世界状态须知：李倩梅已于第1202章死亡，此处为其转世前的送别情节）：最后离去，含笑无多余话语，只轻轻一句『我会等你，若你寻找不到，我会在轮回中，一次次的等下去』——选择了便无怨无悔。

## 二、王林与玄罗之约：再送一批人投胎

星空中洞府大门外只剩王林与玄罗。

- 玄罗告知需展开神通对抗仙罡法则，询问王林何时进去。
- 王林反问能否再多送一些人去仙罡大陆转世。玄罗答：原以为会有数百上千人，如今不到二十人，不会对他产生太多消耗，只要再带的人不算太多便无妨。
- 王林请玄罗再等**五天**，要再带一些人送去投胎。
- **动机**：有些人因顾忌玄罗承受的压力此番未带走，且彼此仇恨并非直接、甚至根本没有仇恨，处于可杀可不杀之间；为了日后洞府界的平和，听闻玄罗之言后王林改变主意——眼中寒光一闪而过。

## 三、重返界外太古星辰

- 界内与界外之间的**新两界之阵**为王林当年亲手布置，凭熟悉半柱香即通过，踏入界外**太古星辰**。
- **太古五尊清点**：掌尊已被王林封印收走；蓝梦道尊迁移居住仙界；余下**妙音、虚神、九大**三尊。王林判断此三人留着日后终究是祸害，趁其虚弱一一寻出、送去投胎。
- **王林当前战力**：经洞府核心五花八门后修为已达**空灵巅峰**，道古传承几乎圆满，配合七道本源与道古神通，发挥战力足以与**空玄后期**一战；受伤的三尊根本不是对手。
- 神识轰然散开弥漫八方，锁定目标后向前一步刹那消失。

## 四、封印九大魔尊（太古星辰东部·月牙修真星）

**地点特征**：太古星辰东部一颗月牙形修真星，不规则、灵气罕有、如死亡之地，凶兽稀少；满地黄沙、没有白天全是黑夜；因不完整而草木灭绝，大量石块漂浮回旋。月牙最上方黄沙浮空、地面漆黑、裂缝弥漫。

**九大魔尊状态**：盘坐裂缝正中，面色苍白、双目紧闭疗伤，黑血时而自嘴角滴落。当年被蓝梦重伤、香火界被毁、心神受伤，残存至今，借此星死气维持生机并欲恢复香火界。

**过程**：
1. 漆黑天空爆发万丈光芒，白衣白发、一脸冷漠的王林走出；九大魔尊倒吸口气，化长虹钻入裂缝直奔地底逃遁。
2. 王林右手向下一撕，虚空轰鸣现出巨大裂缝轰向大地，整星震动、裂缝向两旁扩散延伸，转眼便看到地底疾驰的九大魔尊。
3. 九大魔尊求饶：『你我根本就没有这样的深仇大恨，你放我一次，我发誓绝不再入界内半步』，并震惊于王林短时间内又变强。
4. 王林答『不要怕，王某不杀你，只是送你去投胎』，左手抬起，双手同时施展**撕天之术**猛撕。
5. 九大魔尊掐诀布下全部神通、大量法宝抵抗，仍被整星撕裂——月牙修真星自中间被彻底撕成两半，冲击化作大浪推力卷入星空向八方扩散。
6. 其神通尽数瓦解、法宝全部崩溃、喷血挣扎欲逃；王林无声出现在其身前，右手按其眉心，**将其封印收入储物空间**。全程自来临到封印仅数息。

## 五、转向妙音仙尊（金色海洋修真星）

**地点特征**：一颗灵气极为浓郁的水星，无大陆只有岛屿，余皆海水；海水为**金色**，风中泛起浪花，海中有身形极大的兽类黑影游走。

**妙音道尊状态**：盘坐金色海洋最深处，四周漆黑，可见一片森森白骨（多为兽骨），疗伤时水中时有嘶吼传递。其在蓝梦手中重伤，修为跌落**空灵**，百年无法恢复巅峰，只能不断疗伤争取缩短时间。睁眼时瞳孔扭曲、一片血丝，怒言『王林，蓝梦，你二人不得好死』。抬手于海中卷来一条百丈长黑色海蛇，咬其七寸吸尽全身精华，海蛇瞬息化为白骨。

**转折**：正要继续吐纳，妙音神色大变抬头——金色海洋之上天空扭曲，一袭白衣的王林自虚无中走出，目光如电看向下方海水，宣告：『妙音，今日王某特来此地，送你去投胎』。

## 六、悬念与后续钩子

- 王林承诺的五天之期与『再带一些人送去投胎』尚未兑现。
- 太古五尊余下的**虚神**尚未处置。
- 司徒南能否如愿在仙罡大陆转世为王爷，王林预感不会如其所想。
- 十三、李倩梅的转世后重逢线索（酒壶信物、轮回中等待）已埋下。
