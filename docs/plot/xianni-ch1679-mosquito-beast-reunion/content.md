# 第1679章 蚊兽重逢（第四更）

## 一、李倩梅随父离去

- 李倩梅最终与父亲**蓝梦道尊**一同离开，**第五妃**也被蓝梦带走。
- 三人将回到**蓝丝族**；再次归来时，会带着整个蓝丝族在界内择一区域，作为蓝丝族新的族落之地。
- 安全评估：蓝梦道尊虽受伤，但以其修为，除非**掌尊**出手否则此行无险；而即便掌尊出手也不会逼得太急——因蓝梦已是**空玄巅峰**且再无任何道心破绽，只要他愿意便可一步踏入**玄劫**、引动玄劫降临，玄劫之下掌尊亦要退避。
- 父女身影消失于界外星空，阵法外的蓝色随之消散，星空复归漆黑。
- 李倩梅走时很快乐，笑容如当年一样，回头看王林的目光尽是温柔。她以前不后悔，现在不后退，将来纵然因此而死也不后悔——「这就是李倩梅，属于她的性格」。

## 二、木冰眉的辞别

- 转轮阵法内只剩王林与木冰眉。木冰眉目睹了此前一切，心绪很乱；二人无话可说，她欲开口时，王林闭目开始吐纳、参悟**撕天之术**，话便消散在口中。
- 她的性格终究与李倩梅不同，与西子凤不同，甚至与红蝶也不相似——「她就是她，木冰眉」。
- 最后半年过去五个月，只剩一个月时，木冰眉起身，眼中不再复杂而是一片清明，看着闭目的王林许久，只说了两个字：**「保重」**。这是她这一年说出的第一句、也是最后一句话。
- 说完转身走向界内**昆虚**——她是**昆虚圣女**，要回昆虚。十一个月的陪伴仿佛只为说这一句；她没等满一年，把剩下的一个月留在心里、放在以后。
- 内心独白：她羡慕李慕婉，也羡慕李倩梅——李倩梅还有父亲，李慕婉还有王林，而她家没了、师尊没了、伴她长大的人全都死了。若真说还有，那便是**王平**——她是王平的母亲，这是改变不了的事实。「就算是我死了，也不会有人知晓吧……平儿也恨我。」
- 待其身影消失，王林睁眼望向那个方向，沉默不语。**对木冰眉，王林已没有了恨，但同样也没有情。**

## 三、本尊与分身：王林再次分身

- 剩最后一个月，王林右手抬起在眉心一点，全身震动、砰砰之声回荡，身影模糊虚幻，仿若两个王林重叠，随后扭曲分开，阵法内出现两个一模一样的王林。
  - **本尊**（盘膝而坐）：古神、吉妖、古魔于一体，获得**道古传承**之身。
  - **分身**（站立）：修士之体，一身白衣，修为**空灵中期**。
- 曾有一段日子王林长期如此：本尊打坐、分身外出，两身同修；如今久未如此，眼下再次分身。
- 分身与本尊对望后，分身一步走入界内星空消失；本尊闭目坚守阵法内最后一个月。
- 分身特点：没有了强悍肉身之力，已是完整的修士，**无法以肉身对敌，只能以神通杀人**。

## 四、重凝四大仙界的计划

- 目标：在**远古仙域四大战将**走出之前，**重凝四大仙界、融为一体成为新的仙界**。
- 意义：界内之修生存在仙界内便可凝聚**香火之力**；此后诞生的修士仍是修仙，可在**化神**之后飞升，进入此仙界修炼。
- 历史：古往今来只有**上代封尊**一人做到，开辟四大仙界；随封尊重伤濒死、四大仙界崩溃，界内此后再无香火之力。前人也曾想重凝，但没有封尊的法宝，且当时**封界大阵**尚未削弱到将崩溃的程度，条件不允许。
- 当下时机：王林已轰开封界大阵，界内星空存在**太古星辰**的气息，界内香火的限制瓦解——正是重凝仙界的最好时机。

## 五、重回风仙界

- 第一站：**云海**的**风仙界**。理由有二：其一，风仙界保存较为完整，界内被大量蚊兽占据，当年王林修为不足以撼动此界，如今可以；其二，王林早已感应到当年与其失散的**蚊兽**在大战中进入风仙界并存活下来。
- 王林身融星空、波纹扩散，现身于**云海深处风仙界入口裂缝**之外，一晃冲入界中。
- 界内景象：如刀呼啸的狂风扑面，无尽狂风弥漫，呜咽风声是唯一声响；天空被层层风幕扫过，大地尘土在岁月中被一层层掀起，如今风扫大地再无半点尘土。王林白发飘舞，狂风非但阻不住他，反在他面前轰然崩溃。

## 六、金色巨蚊与重逢

- 风仙界深部一处碎片大陆，狂风更烈，两群蚊兽在风中厮杀，每群逾万；死伤全在其中一群，另一群双目嗜血、以锋利口器疯狂穿刺，**毫发无损**。
- 一头约**百丈大小、如同小山的金色蚊兽**自远处山峰闪出，威压笼罩、神色狰狞、口器数十丈长、寒芒毕露，如王者降临；横冲直撞数息即杀千余，随后其蚊群合围，近万只敌群**全部死亡、无一逃出**。
- 该群百年来极为疯狂，每到新的碎片大陆便残杀一片，不离开者被撕碎；此刻嘶鸣一起，大陆上诸多蚊兽（含不少身形庞大者）皆惊恐逃离。
- 金色巨蚊虽满身同族之血、双目寒光，内里却藏哀伤：**百年来始终找不到主人**，只能以杀戮宣泄悲意，向天悲鸣如被抛弃的幼子。
- 忽然它剧震、嘶吼骤停，寒芒崩溃，取而代之的是消散了百年的迷茫，继而化作激动惊喜，发狂般朝远处飞去——如同感受到失散已久的主人气息。
- 王林在风仙界半空身子一顿，转头看向左侧，**脸上露出了开心的微笑**。

## 七、时间线要点

1. 李倩梅、蓝梦道尊、第五妃离去 → 阵内只剩王林与木冰眉（约定期限还剩半年）。
2. 五个月后（剩一个月）：木冰眉说「保重」返回昆虚。
3. 王林分身而出，本尊守阵法最后一个月，分身出发重凝四大仙界。
4. 分身入云海风仙界 → 与失散百年的金色蚊兽重逢。
