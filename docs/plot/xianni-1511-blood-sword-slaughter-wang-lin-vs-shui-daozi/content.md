# 第十卷 叱咤界内 第1511章 弱弱弱！

## 一、血剑破山峰（虚幻天地内，三息之事）
- 水道子右手一挥，令悬于盆地上空的巨大山峰失去漂浮屏障轰然下沉，意在把盆地内所有**归元宗**修士生生砸死；山峰四周浮着十余名黑衣修士，神色冷漠、面露残忍笑意。
- 盆地内血光骤闪染红整幕画面，一把**血剑**尖啸冲出，直取下沉山峰。
- 山峰外布无数禁制、且为水道子法宝/神宗宝物，仍挡不住血剑——文中明言：血剑之锋连第三步大能都抵抗不住，连**拓森的肉身**都要在其面前破开。
- 血剑穿透山峰，血色裂缝弥漫，山峰四分五裂。

## 二、屠十余黑衣修士，吸尽生机
- 十余黑衣修士齐冲而上欲封印血剑，反被血剑瞬息穿身：胸前血洞、眉心血线，元神来不及逃出即崩溃。
- 血剑触体即吸生机，穿透离体时尸体已成骨骸般**干尸**。
- 全程之快不可视，若放慢时间方能看清枯萎—吸摄—穿透的次第。
- 时间尺度：整场屠杀仅在王林那句「**你配么**」出口后的**三息**之内完成。
- 随后血剑破开虚幻之幕冲出，虚幻内的血腥之气随之弥漫修真星。

## 三、王林一掌 vs 七彩钉
- 王林眼中冰冷，血剑在旁，向前迈步逼近愣神的水道子，右手抬起，天地幻化出遮天巨掌，穿过其身直拍下方立于五座山峰上的水道子（五峰形如手掌，与天空巨掌对拍）。
- 王林**并非第三步大能**，但肉身足以支撑此掌。
- 水道子大袖一甩祭出数个**七彩钉**化七彩长虹迎击，仍口出狂言「小杂种，你既找死，老夫成全你」。
- 结果：王林虚幻手掌崩溃、蹬蹬退后三步；七彩钉亦被震得倒卷远去，水道子喷出一口鲜血，露出骇然——他料到王林很强，未料强悍至此，来不及施展其余后手，只能以极大代价求助。

## 四、援手登场与被挡
### 1. 黑衣老者（分神）
- 水道子疯狂低吼「**周德**」，天地黑墨吞天、白昼转黑夜，虚幻人影凝实为满脸脓包、样貌狰狞的黑衣老者。
- 其言：「拿人钱财，与人消灾，水道子你莫要忘记承诺之物，老夫只为你出手一次」，并向王林索要「让老夫得到那**六品道灵**」。
- 文中比较：比之当年的**大荒上人**，他还差之太远。
- 其实他贪六品道灵早已分神前来，但被王林那一掌惊得犹豫，故话语平淡而出手用全力：身后幻化无边淤泥之海，欲吞王林。
- **灵动上人**自王林眉心古神星点的紫光中现身，狞笑迎上：滔天紫海、无尽香火之魂呼啸、灵动魔神像屹立张臂。老者作为分神在**香火**上远不能与灵动相比，遮天淤泥当场崩溃，喷出元神之气、面色惨白败退，惊问「你是谁」，得答「**我主之奴，灵动**」，二人追战而去。

### 2. 算盘珠子中年男子（本体）
- 王林身后漆黑天地中三十二个**算盘珠子**幻化成环形波纹拉成直线无声临近。
- **周瑾**化作数万丈血狼迎上，施展「**群狼拜月**」，血月撕开黑天砸落，狼嚎传遍云海；算盘珠子砰砰爆开，露出满脸震惊、不可置信的中年男子——此人乃**本体**前来，溢血后退。
- 周瑾退出数步却神色平静，掐诀一指，血狼张口吞噬扑向该中年男子。

## 五、水道子的最后底牌
- 水道子神色狰狞疯狂，尖啸「**阴阳门徒**」，身后撕开巨大裂缝，无尽阴阳门徒飞出，经其右手一指化作巨大长枪刺向王林。
- 此枪融合了水道子**一生修为**与**全部香火**，惊鸿一现即天崩地裂，修真星出现大量裂缝，仿佛要毁灭。

## 六、要点
- 王林此时以化名「吕子浩」立足云海星域（自第1063章由吕烟菲奉上），本章正文直呼其本名。
- 战力刻度：血剑 > 第三步大能防御（连拓森肉身亦可破）；王林非第三步大能而肉身可硬撼第三步大能水道子并占上风。
- 两名第三步大能联手围杀一人，文中称即便在界外都极为罕见，界内更甚。
- 王林麾下两大战力同时出手：灵动上人（香火/紫海/魔神像一系）、周瑾（血狼/群狼拜月一系）。
