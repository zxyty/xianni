# 仙逆 第2085章 缺的一个

## 一、太古神境的真容

- **无人知晓的所在**：仙罡大陆上代代都有「什么是太古神境」之问，连大天尊亦无答案；进入过的人回来后也说不清那是何地。
- **环境**：天空血红，无星辰日月却有柔和之光；大地为圆形。王林的神识在此受限，无法弥漫整个大陆，只能看到附近纵横山脉与漫长裂缝沟壑。
- **裂缝**：笔直无弯曲，如被一剑豁开；内散出淡淡黑气，升空即消失，深处一片漆黑。
- **升空俯瞰得出的结论**：裂缝排列极为规则，构成「刻度」；交错山脉自然形成沧桑符文——整块圆形大地是一个**巨大的罗盘**。
  - 但这罗盘**没有指针**；
  - 且并不完整，**缺少了一半**（有一半看起来虚幻、不太真实）。

## 二、七彩雪花之山与那座桥

- 大地正中心一座高耸入云、飘着七彩雪花的山。此山王林曾在**始古祖庙**内、于**吉道三分神**时在飘渺中见过。
- 昔日所见：山上有一个**抱着尸体的身影**仰天凄吼、质问天地。
- 此刻所见：山上无抱尸身影，取而代之是一个熟悉之人盘膝而坐望着自己——似老非老、全身弥漫七彩之芒、目带激动兴奋，正是**如天运子、如七彩仙尊、如道吉国师之人**。
- 山后有**一座桥**：一端连接大地，一端融入天幕，形成巨大弧形，与**踏天之桥**几乎一模一样。桥与天相接处，血色天幕后隐有一片模糊虚幻，其中**两个模糊身影**——与王林当年在踏天之桥上所见的**第九桥之后的虚幻**相同。

## 三、天运子的图谋与揭示

### 1. 出手
天运子大笑「你终于来了」，称「这一切只是你的一场梦，但当你来到这里的时候，你的梦会出现扭曲」，双手外挥——全大地裂缝同时爆发浓郁黑气，直奔此山，遮盖血色天空，在其身后凝成一个撑起天地的**黑袍巨影**（与天运子同貌），随后天运子退后一步与巨影融合，掀开黑袍露出妖异之脸。

### 2. 宣告
- 「即便你前世是**踏天境**的强者，但在这**定界盘**内，老夫就是至高无上的存在。」
- 「整个仙罡大陆，此地是老夫**唯一可以将你吞噬融合**的地方。」
- 「在这里，你的梦会扭曲，从此之后，**老夫就是你**。」

### 3. 世界观揭示（天运子口述）
- **仙罡大陆是不存在的**，只是王林以梦幻化出来，实际是一片**虚无**，属于**逆尘界**的一部分。
- 宇宙苍穹存在**四大界**，此界为逆尘界；**每一界都有一样至宝**。
- 逆尘界的至宝便是**定界罗盘**，也是**唯一的空灭之宝**。
- **太古神境就是逆尘界的定界罗盘**。
- 那座桥是**定界罗盘的踏天之桥**，也是**逆尘界一切众生修为达到一定程度后所感受到的踏天之桥的本体**。

### 4. 关于王林的「前世」
- 前世为**天地最强之人、踏天境之修**，本该叱咤逆尘。
- 为复活一个女子（妻子），**从守护者手中借/抢走定界罗盘**。
- 更以**自创的梦道之术**，亲自**散开真我、重化轮回**，试图让梦想成真，在轮回内复活妻子、逆转天地。天运子自言对此疯狂举动亦感震惊。
- 天运子自陈身份：**定界罗盘的守护者**；并道「我有个弟子，你应该认识，他的名字，叫做**墨智**」。

### 5. 黑色漩涡中的往事
天运子右手一挥，散出部分黑气在天空形成**黑色漩涡**，放映画面供王林自判真假：
- 另一个王林**抱着一具尸体仰天凄吼**；
- 不知多少年前，**复活李慕婉失败**后的悲哀、愤怒与疯狂；
- 誓言：「天让你死，我也要将你抢回来。我要碎灭这天，轰开这地，我要沉入轮回，将你的点点滴滴从轮回中取出，重造生生世世；若我依旧没有成功，则我王林永不苏醒，与你沉浸在那轮回中，直至永恒。」
- 王林观之，往事如**本就存在、只是一直遗忘**的记忆般浮现脑海。

## 四、王林的反制

- 问：「你之前为了让我来此，告诉我在这里可以将李慕婉复活，是真是假？」
  - 答：「**可真，可假**。定界罗盘是逆尘界唯一的空灭之宝，它可以改变一切。不过，你没有这个机会了。」
- 天运子察觉不对劲：王林**至今神色平静，毫无意识扭曲**，故犹豫未轻举妄动。
- 王林指桥发问，得知踏天之桥本体之说。
- 王林点破其心思：「你是在迟疑与猜测，我为何没有意识扭曲，如睡眠中的人在将醒的一刹那出现的模糊之时么。」
- 天运子面色大变、庞大身子后退数步，露出难以置信之色：「你不对……以往的几次，你都是在这一步苏醒，这一次，绝不会不同！」——**说明此前已有过多次同样的循环**。
- 本章结句，王林缓缓开口：「**你不是守护者，而是缺的那一个。**」天运子内心咯噔一声。

## 五、要点与伏笔

1. 「缺的一个」呼应罗盘**缺少一半、且无指针**的意象——天运子被指为那个「缺失的部分」而非守护者。
2. 王林**前世踏天境**、以梦道散开真我入轮回，为本书「逆天/轮回/虚幻」母题的总收束。
3. **四大界 + 各界一至宝**的宇宙框架首度点明，逆尘界至宝＝定界罗盘＝空灭之宝＝太古神境。
4. 天幕后的**两个模糊身影**与第九桥后所见相同，指向更高层级的存在，悬念未解。
5. **墨智**被点为天运子（自称守护者者）的弟子，因果线索。
6. 天运子承认此为**多次重复的循环**，王林此次的「未苏醒/未扭曲」是变量所在。
