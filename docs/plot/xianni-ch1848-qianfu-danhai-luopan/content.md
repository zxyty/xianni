# 第1848章 潜伏

## 一、化雾潜行：以禁制本源伪装阵法

- 王林现身丹海上空，其下即是无形的禁制阵法；有此阵法阻隔，禁制内修士难以循气息寻他。
- 他依旧极为谨慎，收紧全身修为气息，如幽魂般向丹海远处疾驰，数步跨空即接近绿魔洲海域。
- 越近绿魔洲，天空巡弋修士越多：修为多在**第二步**，**第三步**不多但可见，随后**空玄**境界强者也隐隐出现，逼得王林放缓行程。
- 应对之策：双目瞳孔血丝弥漫笼罩全身，冲入下方无形阵法禁制，化作一丝雾气沉入其中。**王林拥有禁制本源**，以本源模仿笼罩丹海的阵法，短时间内有信心不被察觉。
- 他潜入禁制**第七层雾气**内小心疾驰，目标是找到真正的**阵法中枢罗盘**。

## 二、沿途所见：绿魔洲的战争动员

- 头顶绿魔洲修士往往数十人一组、神色严肃呼啸而过；王林估算一路所见**不下数万**，断定其虎视**天牛洲**。
- 王林内心感慨：宗门与宗门、洲与洲之间的杀戮无处不在，洞府界如此，**仙罡大陆**亦然；世间本无净土，除非有极强者镇压八方。

### 人器合一的黑色大鼓

| 项 | 内容 |
| --- | --- |
| 外形 | 约百丈大小，通体漆黑，鼓面亦黑，四周凸起大量狰狞凶兽 |
| 异象 | 鼓外无数冤魂环绕、无声咆哮，形成层层波纹向八方扩散 |
| 护送 | 数百绿魔洲修士，四名**空玄**强者分列东西南北如护驾；鼓极重，近百修士全力托举缓行 |
| 关键 | 鼓内**隐藏一名修士**，似与鼓融合为一；路过王林藏身处上空时自鼓上散出神识横扫 |

- 王林见此鼓一刹那即化雾一动不动，暗记「与修士结合的法宝」。
- 其后他一共见到**八个**同样的大鼓，另有数种同为近百丈、样式各异的宗门厮杀用大范围法宝，气息惊人、笼罩四周形成威压。
- 结论：此地不宜久留，须**速战速决后尽快离开**。越是心惊肉跳，他越发冷静。

## 三、阵法中枢：三杆大旗与罗盘

- 靠近绿魔洲的海面上立有**三杆直冲天际的大旗**，随风舞动、发出吹打之声、层层涟漪扩散，王林判断其为**防护法器**——此事有些难办。
- 旗下人物：
  - **持罗盘的秀美女子**：低头皱眉查看中枢罗盘；罗盘内密密麻麻皆为绿色小点、无一白光，却如水面涟漪般泛起波动，是阵法察觉异常后的自行举动。她连续掐诀打印记按于罗盘，仍无发现。
  - **面白如玉的青年**（王林此前见过，持扇；女子称其「赵师兄」）：上前看罗盘后微笑劝解「不要疑神疑鬼，有云空大师兄在，一切无碍」。
  - 四周另有**数百绿衣修士**如侍卫般一动不动、闭目打坐。
- 王林的判断与困局：
  1. 罗盘是**唯一可知晓他进入丹海之物**，夺得后便无需再藏身阵法内；
  2. 罗盘也是茫茫丹海中**寻找云空**的关键，杀云空后方能安全逃走；
  3. 但要拿罗盘就必须走出阵法，走出即会被下方之人知晓——故须**极快**、不放走一人、不给女子传讯之机。

## 四、云空出手：九个漩涡与半粒仙丹

- 女子言：**云空大师兄已在出手**，用不了多久这片丹海就会消失，届时便可见传说中的**半粒仙丹**及其威力。
- 话音方落，整个丹海剧烈轰鸣如海浪咆哮，海面风起云涌、大浪滔天；不同位置赫然出现**九个巨大漩涡**，缓缓转动却传出惊天动地的轰鸣。
- 女子遂不再看罗盘，目露期待望向远处海面。王林在雾气内听到二人交谈，从神色中察觉端倪，心中一动。

## 五、潜伏得手与罗盘示警

- 与此同时，一队约十余人的**绿魔卫**自海底飞出，是外出执行女子之命后返回者；此类进出调动很寻常，未引起女子及四周修士注意。
- 王林双目闪过幽光，趁其路过瞬间化作一道烟丝自雾气中疾驰而出，**钻入其中一名修士的耳内**。该修士身子一顿、双眼迷茫，旋即被平静取代，随队继续接近三杆大旗。
- 就在这一刹那，**女子手中罗盘突然震动示警**。她低头看时一切已结束。
  - 女子神色凝重：「应该是非绿魔洲修士进入到了丹海内」「此人擅长隐匿，我一时察觉不到」。
  - 她请**赵师兄**相助：青年右手按在其背部，女子深吸口气、双眼奇异之芒，以**师尊所授之法**左手掐诀连点罗盘，欲**逆转罗盘**回溯方才那一瞬所发生之事。
- 她并未留意：那十余名她派出归来的绿魔卫正越来越近——其中一道**潜杀的目光**若隐若现。

## 六、要点与伏笔

- 王林的行动逻辑链：藏身阵法 → 找到中枢 → 夺罗盘 → 循罗盘寻云空 → 杀云空 → 撤离。
- 未决风险：三杆大旗（防护法器）、逆转罗盘可能暴露其潜入手法、附身之身随时可能被识破。
- 世界层面情报：绿魔洲已聚数万修士并携八尊冤魂黑鼓等大型战争法宝，明显针对**天牛洲**；丹海将因云空之举而消失，半粒仙丹将现世。
