# 仙逆 第九卷 云海之巅 第1155章 连斩！

## 一、决断动机：绝不能回蛮荒大陆

- 因黑猿之故，蛮荒大陆上绝大部分凶兽都死死记住了王林；王林若随队返回，凶兽必将躁动。
- 这种躁动在有心人眼中即是「天大的破绽」，足以说明王林是从蛮荒大陆离开。
- 配合**施洛刑死亡的时间**，即便六阶宗派修士分析出施洛刑死于**五毒门毒婆子**之手，也会对王林产生极大怀疑。
- 一旦怀疑成立，必被搜查储物空间，遇霸道修士甚至直接**搜魂**——对王林而言是灾难。
- 因此王林表面露出「不忿」（合理且不引警惕的神情），实则在八名核心弟子临近、自己艹控黑猿转身的刹那，眼中杀机骤起。

## 三、战斗经过（数息之间）

### 第一波·八人同灭
1. **呼风之术**化五条黑龙咆哮，直奔四周五人；五个阳实修士毫无反抗之力，黑龙入体，轰然崩溃。
2. 王林速逾对手反应，一指点在**窥涅修士**眉心，血洞喷出，净涅修士毁灭性力量搅碎其元神。
3. 不作停留，撞上另一修士，右手在其胸口连点数下，喷血而亡。
4. **黑猿**双臂狂猛之力，将一人直接拍成血肉。

→ 八人身体几乎同时爆开，四周尽成血色。

### 第二波·硬闯与火海
- 钱贵钟转身狰狞扑来，神通化一道黑光阻其前行。
- 王林掐诀凝聚**杀戮之气**成层层杀戮防护，不假思索猛冲；防护层层崩溃、喷出一口鲜血，但身子冲出黑芒。
- 冲至九名核心弟子处，**左眼火光**融入左手一挥，星空燃起火海，三名华清宗核心弟子被生生烧成灰烬，其余六人后退。

### 第三波·封仙印格挡与青光斩首
- 钱贵钟身下黑蟒化作**黑色长枪**疯狂逼近。
- 王林张口吐出**十八地狱封仙印**横挡，与长枪相撞后封仙印缩退落回其身，王林喷血后退。
- 后退途中直奔一人，右手横扫化**一道青光**；对方以体内黑光大盾阻挡，盾碎、双手断裂、头颅爆开、元神死亡。

### 第四波·唤雨剑雨与拂尘规则
- 王林掐诀，**唤雨之术**化雨水横扫星空，凝为五把晶光小剑扑向余下五名核心弟子。
- 钱贵钟虚空一抓开储物裂缝，取出**白色拂尘**一挥，引动**天地规则**化白光如剑雨降临。
- 王林左眼火光闪烁，幻化**赤红色铠甲**护身；仍被震得喷血、面色苍白、元神萎靡、右腿被白光穿透血肉模糊。**若非护甲在身，此击足以令其身亡。**
- 晶光小剑穿透五人：四人肉身崩溃元神灭亡；一人捏碎**玉简**护住元神逃遁。

### 第五波·追杀与拾遗
- 王林虚空一抓，储物裂缝内飞出剑光——**许立国**叫嚣着追那元神而去。王林第一句神念即是「**不杀他，你便死**」，许立国不敢轻视，疯狂追击。
- **银衣女子**自储物空间飞出，不参与围攻钱贵钟，而直奔四周**失去了主人的本名灵兽**。

## 四、杀手锏出场与「次空涅」

- 王林一指封仙印，一挥之下晶光弥漫，一个个魂魄自**十八地狱**内冲出；其中最强之魂为**虚空子与天运子两个分身融合而成之魂**——王林的杀手锏，出现刹那星域内阴寒之气弥漫。
- 钱贵钟震惊：短短数息，这白发青年斩尽所有核心弟子，自己的神通竟未能杀死他；更被两道死魂生前修为的气息所惊恐。
- 王林虚空一抓取出**铁剑**：星空震动，四周星雾一颤，磅礴之力将星雾齐齐推退、翻滚云涌。
- 钱贵钟双眼一凝，脱口喝出「**次空涅**」——由震惊转为**浓浓贪欲**，身子前迈，碎涅修为疯狂爆发。

## 五、要点与伏笔

- **本尊不在**：王林两次心念「若是本尊在，杀此人定比现在要容易一些」，明确本片段行动者为其分身，实力受限。
- 碎涅远超净涅，此战对王林是苦战，**必须赢且必须快**（后方援兵将至）。
- 铁剑暴露「次空涅」之名，激起碎涅修士贪欲，为后续争夺埋下因果。
- 灭口动机链：黑猿→蛮荒凶兽记忆→返回即破绽→关联施洛刑之死→搜魂之灾。
