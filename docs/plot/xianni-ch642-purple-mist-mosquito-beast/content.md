# 第642章 紫雾蚊兽

## 一、妖灵之地：云仙道侣勘破禁制

### 现场
轻风碧草之地，一男一女立于地面禁制之上。男子为**云仙王巍**，女子为其道侣**娟儿**。

### 王巍对禁制的判读
- **成分混杂**：手法包含**上古禁术**，另有**一丝仙禁味道**。
- **娟儿补充**：上古禁术手法娴熟，但带仙禁味道的部分较为粗糙，应是**刚摸索没多久**。
- **无杀机、有耳目**：此禁制没有杀机也无杀意，但内含**启发神识**——只要踏入其内，布置者立刻察觉。
- **连环相扣**：禁制不止一个，而是环环相扣；即便破解，只要不能**一瞬间全部破除**，布置者仍会知晓。
- **借物设禁之上乘**：王巍点评「凭空设禁乃下乘，借物设禁只是中乘」，而此处更高一层——
  - 他右手一抓压下满地青草，独留一根随风而动的草；
  - 此草**真中带假**：草是真的，草内**汁液是假的**；
  - 两指一搓，白气缭绕，汁液散出，青草枯黄，掌心浮现**一滴晶莹剔透的青色液体**；
  - 这一滴汁液内**蕴含一千多道禁制**，彼此完美组合、结构极为稳固。

### 由禁制推人
王巍断言：能以寻常禁制做到如此组合者，**必修行万年以上**——须经历人生百态、看透生死、感悟自身道念，方有此心机与推衍。他强调：

> 「禁制，与天资关系不是很大，真正关联的，是心态，是心机。」

说此话时，王巍眼中露出**感慨与一丝追忆**。

### 赌约
- 王巍提议打赌：若布置禁制者**没有修行万年**，便算他输。
- 娟儿应赌：她**赌布置者没有万年修行**。
- 娟儿评语：平日自称「一切禁制都可破解」的云仙王巍，竟对一个小小禁制如此在意；她深知王巍性子随和，但一遇禁制便判若两人。

（读者视角：布置者实为王林，远未修行万年——赌局伏笔已埋。）

## 二、云仙道侣的底细与目的

- 二人在**妖灵之地已数万年**，把一座**虚府**彻底研究透彻，所得宝贝不计其数。
- **贪狼**踏入妖灵之地的刹那，行踪便已被这对云仙道侣察觉。
- 王巍除禁制外**擅长卜卦**，虽在此道**不及天运子**，但足以算出贪狼的方位与一些变化。
- **令牌**同样被二人算出；只因令牌太过奇异、**必须在特定时间内才能获得**，故此前未动手，直到此时才赶来**火妖郡出口**守候。
- 对「贪狼见到他们会反抗还是乖乖交令牌」，王巍轻描淡写：**「他，不敢反抗。」**

## 三、潮汐深渊：王林奔赴火妖郡出口

- 王林踏着**周佚所在的仙剑**，如电光直奔火妖郡出口；周佚速度极快，数日后顺回廊抵达**通向火妖郡的深渊裂缝**。
- **地貌特性**：火妖郡出口是潮汐深渊内**唯一阻力向上**之地，飞行于此如被无穷之力推动，速度更快；也因这股向上喷出的推力，出口处的声音**传不出多远**。
- 途中周佚神念示警：剑识查到前方有一片**紫色雾气**，雾内**似困有修士**，雾气诡异，**剑识无法全部探入**。
- 王林一路未见**慕容卓**与**赵、赵徐二女**（赵、徐二女），目光一凝，暗忖被困者莫非正是这三人。

## 四、紫雾外的蚊兽群

### 群兽状态
- 紫雾另一端，蚊兽**密密麻麻铺散开**，深红双目死盯紫雾，凶芒浓烈。
- 体型极大而**腹部扁瘪**——显然已饥饿很久；长长**口器如利剑**，散出森森寒芒。
- 体色不全为黑，**不少为灰色**，绒毛如利刺。
- 只在雾外徘徊，**不敢深入紫雾**；暴虐气息越来越浓。
- 深渊之壁上挂着**几块布条**、大片**干枯血痕**，旁边还有**一把黯淡无光的大剑**——先前遇难者遗迹。

### 内讧与镇压
- 蚊兽口器相互碰触即打出火花，嗡鸣加重，濒临自相残杀；
- 每次都有**一声厉啸**自兽群深处传出，生生压下野性；
- 因滞留过久，凶性渐难压制，终有两只蚊兽厮杀起来，厉啸再起也不听。

### 紫色蚊兽出场
- 厉啸第三次响起，兽群散开让出通道，飞出一只**约十丈大小、通体略带淡紫色**的蚊兽（紫色很淡）。
- **头部插着七根银针**，银针散出阵阵波动，令其**双目时而露出痛苦之色**。
- 它一声嘶鸣**似拥有神通**，所有蚊兽闻之身子一颤；趁此翅膀一扇如电光掠至内斗二兽旁，**巨大口器连点两下**穿透二兽，一吸即令其**枯萎化作干尸**坠落。
- 转身冷视四周，群兽发出**臣服嘶鸣**，再不敢相残。紫色蚊兽缓缓飞回兽群深处，身上**透出一股沧桑**。

## 五、看点与伏笔
- 王巍夫妇的赌局直接指向王林的禁制水准（借物设禁 + 千道禁制汁液），并已在火妖郡出口张网候「贪狼」交令牌。
- 王林与截击者正在同一出口对向汇聚，中间隔着紫雾这道未知变数。
- 紫色蚊兽头上的**七根银针**、身上的**沧桑**之感，暗示其来历不寻常（被人以针镇压/驱使）。
- 紫雾能困住修士、连仙剑剑识都无法尽探，性质待解；慕容卓与赵、徐二女下落存疑。
