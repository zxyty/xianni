# 第1722章 他的身份！！（第三更）

## 一、天运子的轮回记忆：第九十七次觉醒

王林（本尊）沉浸在天运子的轮回画面中，逐幕回溯其历次「觉醒」。

- **地点**：天运星·天运宗密室（王林熟悉之地）。
- **过程**：天运子盘膝而坐，身前九名青年闭目昏迷；天运子张口一吞，九人尽被吞噬。随后其身一颤、面露痛苦，闭目沉睡；岁月悠悠后睁眼，目露明悟。
- **自陈**：「这是我第九十七次觉醒。下一次沉睡与觉醒的人选，是**凌天侯**。」
- **王林当时的判断（后被推翻）**：「他应该就是七彩仙尊三魂七魄之一，只有这样，才可以解释其一次次觉醒。」

## 二、关键闪回：天运子当年「结善缘」的真相

某次觉醒（于一颗陌生蛮荒星吞噬选定修士后）之后：

- 天运子星空前行时忽然驻足，俯视下方一颗**土黄色的半废弃修真星**。
- 神念传音：讥其「区区元婴修为，即便是化神感悟，也不要太贪」，断言此人若继续追寻此等天道，没有千百万年以上无法找到本源，而到那时肉身早已腐朽。
- 右手抬起，向该星**一掌拍去**；并留话：「老夫天运子，今日便与你结个善缘。你若是能走出这废弃星球，可来天运星寻我，我收你做**记名弟子**，让你跟随百年。」
- **内心真意**：「此子不错，可以略作培养，成为我日后吞噬的**分身一体**。不过其修为太弱，以后能否用上还是两说，但我却有种感觉，此子会有不凡。」

王林凭那修真星散出的气息，在这一瞬间**明白了一切**——当年那颗土黄色半废弃修真星上的元婴修士，正是他自己；所谓「善缘」，从头就是算计与择食。

## 三、外界同步：三千天运子分身自毁化魂，扑向王林分身

- 本尊沉浸轮回之时，界内四大星域**所有天运子分身同时抬起右手，不假思索点在眉心**。
- 召河星域东部、第一个出现的那个天运子自陈：「老夫天运，此生最后一次沉睡，最后一次觉醒，即将开始。这一次觉醒，我会完成**轮回万古的计划**。」随即手指穿透眉心深入头骨。
- 近**三千**天运子分身在同一刻肉身碎灭，轰鸣回荡四大星域；一缕缕魂幻化而出，极速直奔召河星域内的**王林分身**。
- 三千魂在途中魂念合流，形成惊天声音咆哮：「看看你是快，还是我快！老夫算计你时，你还只是一个小小元婴修士，若非老夫，你早就肉身腐烂。你的一切，都是我的！」
- 召河内数百缕魂先行钻入王林分身体内；**王林分身神色平静盘坐不动，任其融合**，天运子的魂在其体中越加壮大，隐隐占据王林分身身体的全部。其余三大星域之魂亦在急速赶来（外界极快，本尊感受极慢）。

## 四、更早的轮回：形貌全非，唯气息可辨

王林发现越往前，画面中人与「天运子」样貌**完全不同、几乎换了一个人**，唯有气息锁定可确认是同一存在。

### 第三十四次觉醒——上古修真界（四大仙界尚未崩溃）
- 一名**蓝衫中年男子**，含笑吞噬身前昏迷青年——**那是他唯一的弟子**。
- 同为上古修真界，另有一名**容颜娇媚女子**，在星空漂浮的废弃尘埃中，笑着吞噬身边昏迷男子；该男子修为不俗、仙气弥漫，显然是四大仙界中的**某位仙人**。

### 第三次觉醒——太古时代
- 太古星空修士**并非修仙**（尚无仙界），所修为自身力量与感悟天地气息。
- 一名**兽皮老者**已死，正被数百族人以火焰焚化；老者忽然睁眼（先迷茫、后无情），坐起、诡笑、张口猛吞：四周数百男女连同火堆尽被吞噬；修真星剧震崩溃，天空现一张大口，**整颗修真星被吞入口中**。
- 自陈：「这是我第三次觉醒。我记得第二次觉醒时，我**吞下了七彩仙尊的第七魄**。」

> 此语令王林心神再度轰鸣：既然他能吞七彩的魂魄，**他就不是七彩仙尊的三魂七魄之一**——那么他到底是谁？

### 吞噬之力的衰减规律
王林观其九十多次轮回后发现：**对方的吞噬之力随轮回不断虚弱**——第三次能吞一整颗修真星，到九十多次苏醒时只能吞人。

## 五、第二次觉醒：身份揭晓（本章戛然而止）

- **场景**：一片陌生、**毫无任何生命痕迹**的死寂星域，修真星无数却半点生机皆无。王林判断：这是**洞府界最早、尚未诞生生命的时期**。
- 一缕微弱灵魂气息急速而来，内中包容一个模糊虚幻身影，透出**属于七彩仙尊的魂魄之力**。
- 星空中**无声无息撕开一个巨大裂缝**，一口将该魂魄吞噬；裂缝收拢后，从中幻化出一名**全身散发幽光的青年**（眼中先迷茫、后清明）。
- **青年自白（关键设定）**：
  - 「七彩仙尊的第七魄，味道不错。我帮了他很多，眼下他既然死亡，就再也**没有人能将我操控**。」
  - 「可惜他的**三魂**力量太大，我与身体分离后不敢去吞；但有这最原始的**一魄**融合，我也一样可以借此魄让自己成长。」
  - 「或许在很多很多年后，我可以从此魄身上**推衍出完整的七彩仙尊**，到了那个时候，**我就是七彩了**。但最重要的，还是我的成长。」
  - 「我要先**学会成为修士**，我要让所有人，包括那**七彩三魂与其余六魄**，也认不出我的身份。**我要重新掌控轮回。**」
  - 神色始终毫无变化，抬手**拽了拽自己的嘴角**，才使自己看起来仿佛在笑。
- 王林神色滔天震撼——「他是……」本章至此收束，未点破名字。

## 六、要点与伏笔

1. **天运子=吞噬型轮回体**，非七彩仙尊魂魄，而是曾被七彩仙尊「操控」、并在其死后吞其第七魄的存在；目标是推衍出完整七彩、并**重新掌控轮回**。
2. **王林与天运子的因果**在本章彻底闭环：当年朱雀星（土黄色半废弃修真星）上的「善缘」与记名弟子之约，本质是天运子为日后吞噬择定的「分身一体」。
3. **凌天侯（剑尊凌天候）** 被点名为天运子第九十七次沉睡后的下一个觉醒人选，为其命运埋线。
4. **三千分身同毁化魂夺舍王林分身**，构成本章外界主线冲突；王林分身任其入体，疑为将计就计。
5. **吞噬之力递减**是可用于推断其本源与虚弱程度的重要设定。
6. 时间轴跨度：洞府界无生命之初（第二次觉醒）→ 太古（第三次）→ 上古修真界·四大仙界未崩（第三十四次）→ 近世（第九十七次，天运星）。
