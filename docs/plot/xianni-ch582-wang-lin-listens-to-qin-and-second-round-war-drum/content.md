# 仙逆 第582章（下）：琴音悟逆与战妖鼓之变

## 一、河畔顿悟：「逆」为问鼎之关键

- 王林脑中如闪电划过、耳边回荡琴音，整个人好似顿悟：**「黑夜，被阳光扫去，这，算不算是逆？」**
- 他由此得出模糊感悟：**「这逆字，便是我达到问鼎的关键。」** 感悟不深，但已「生根」。
- 王林没有回莫府，而是在河道旁如老僧打坐，虽无琴音，耳中却有心之余声回荡。
- 自我辨析：琴音本身无情，因弹者心含悲伤而成「悲音」，这与他所悟的「逆」不同——但他偏偏从这琴音中听出了「逆」的韵味（悬念未解）。

## 二、画舫夜谈：两个「过客」

### 场景
- 晌午画舫再来，弹琴女子（**明萱**）身旁站着数日前那名青年，目光远远落在王林身上，举杯相邀。
- 王林举酒壶相碰饮下；青年却摇头、指船首，手中酒未尝半口——示意其登船。
- 王林见此人相貌寻常却有一股洒脱之感，遂踏河面落于船头。弹琴女子并未察觉船头多人。
- 三人整日无言，只有琴音；青年言「在这琴音下，任何言语都是杂音」。画舫顺河而行，王林一坐便是一天，入夜灯火辉明，直至次日天边露白。

### 对话要点（傍晚回到上船处后）
| 话头 | 王林 | 青年 |
|---|---|---|
| 听琴感触 | 「想起了故人」 | 「若心无牵挂者，不会被这琴音所动，兄台与我一样，也是一个俗人」 |
| 身与神 | 「俗人一个，若真说过客，也只不过是虚幻罢了。你不也一样么，神在这船上，可身却不知去了哪里」 | 「家里来了不少莽客，太过吵闹，于是这神，便飞来这里图个清静」 |
| 家 | 「有，不过很远很远」（脑中浮现**朱雀星**的那处山谷）；「家中没有别人了」 | 有家；「有个侄女，不过这侄女太顽皮了，而且最近还被一个恶客缠上」 |

- 细节伏笔：二人谈及「故人/俗人」时，**弹琴的明萱身子一颤，琴音随之出现颤声**。
- 青年提出「把酒天明，聆听明萱姑娘的琴音」，王林点头应允。明萱先行离去休息，二人枯坐至天明；王林抱拳踏风而去，消失于清晨薄雾。

> 注：青年言「侄女被恶客缠上」，与莫府/莫厉海线索呼应（本片段未点明）。

## 三、妖将第一轮战结果

- 持续数日的第一轮战结束：**数百妖将中仅四十八人胜出**，其余不是败落，便是一胜一负失去资格。
- 伤亡对比：**妖将中除熬迪外无一人受重伤**；**修士死伤极重**（毕竟这是修士间的厮杀）。
- **大罗剑宗**数人表现突出：面对妖将点到为止，面对同修则无比辛辣，似欲借机展现自身实力。

## 四、第二轮变数：敲响战妖鼓

### 现场
- 清晨阳光扫过燕京万丈广场，三侧高架看台人数更多。
- 四十八名妖将自**天妖门**走出，战意如远古凶兽呼啸而出；待妖将与其帮助者全部走出后，天妖门轰隆隆关闭。
- 广场正中**金甲男子**神色冷漠，扫视众人，看到王林时冷哼一声。

### 金甲男子对王林的敌意
- 心中判词：区区一个修士，在妖灵之地竟敢重伤一位妖将，「足够他出手杀此人十遍百遍」。
- 更认为来妖灵之地的修士不外乎是为吉妖传承的强盗，「死就死了，但若敢伤及妖将，则大逆不道」。
- **王林因修炼杀戮仙诀，对杀气极为敏感**，冷冷回扫金甲男子一眼。

### 规则宣布
- 金甲男子一指身边巨大妖鼓：**「奉帝君令，这第二轮有所变化，并非比斗，而是敲响这战鼓。」**
- 众妖将面色一变而后露出强烈精芒，**莫厉海**身子一颤、眼中滔天之光。

### 战妖鼓设定（据现场议论与宣示）
| 项 | 内容 |
|---|---|
| 地位 | 天妖郡内**仅次于龙潭**的圣物 |
| 来历 | **第一代帝君**留下，传闻以**古妖之皮**制成 |
| 旧例 | 以往只在**副帅晋级正帅**时才被赐予敲响之权；传闻所有妖帅即位时都会敲响此鼓 |
| 风险 | **血气不足者，未敲响便自身崩溃** |
| 评级 | 响三声为**强者**，六声为**天骄**；金甲男子断言能超过三下者不多 |
| 纪录 | 至今唯有**天帅大人**可敲出十五下 |

### 引发的推断
- 往常妖将之战从未有过任何变动，今日突变——众人由此认为「**从妖将中选择两名副帅**」之事并非空穴来风。
- 议论之声之盛，甚至超过此前王林重伤熬迪之时。

## 五、悬念与看点

1. 「逆」之感悟已生根，指向王林突破**问鼎期**的路径。
2. 画舫青年身份成谜（神游而至、家中有莽客、侄女被恶客缠上），与王林互认「过客/虚幻」。
3. 明萱琴音何以带「逆」之韵味、闻言颤音之因未解。
4. 金甲男子对王林已生明确杀机，而王林须以修士之身去敲以古妖之皮制成的战妖鼓——血气一关对修士极为不利。

# 第588、589章 打赌

## 一、本轮规则

金甲男子宣布：**「此轮规则，妖将与各自帮助者所敲之声叠加」**——即妖将本人与其帮助者敲响妖鼓的次数累计计算。宣布后不待四周议论，直接点名出场者。

妖鼓背景：据看台议论，此鼓**乃「吉妖之皮」炼化而成**，敲击者纵能敲响，也会被鼓内反震之力所伤。

## 二、妖将于森：四响

### 出场与蓄势
- 于森目光冷漠，铠甲行走间清脆作响，来到妖鼓之下。
- 望鼓时眼中爆出精芒，燃起浓浓战意；但**他对敲响此鼓内心并无自信**——此鼓于他如圣物般存在。
- 未立刻出手，闭目运转妖力调整内息，体外散出成散发状的浓浓妖气，升至半空云涌不断。

### 旁观者评价
- 「杀戮道极难修炼，这于森修炼杀戮道多年，今日第一个上场，恐怕会一鸣惊人。」
- 反方：「妖鼓乃吉妖之皮炼化，于森即便真敲响，也定会被反震成伤。」
- **金甲男子的内心判断**：以于森的修为能敲响四下，**若强行敲第五下，定会血气崩溃**。判断完即闭目。
- 八位妖帅露出兴趣之色，彼此对视即能猜出十之八九；六位副帅亦能看出端倪。

### 四声鼓鸣的过程
1. **第一响**：双目猛张，如战神附体，双脚踏地掠向妖鼓，半空中右手双指成剑，精气神尽凝于双指点在鼓面。鼓面略凹又迅猛弹回，「咚」声传遍广场、延伸整个**燕京**、波及小半个**天妖城**。同时一股巨力自鼓内势如破竹冲击其身。
2. **第二响**：面色苍白却不退反进，再踏一步，双指毫不犹豫再点，鼓声如奔雷落地。此时体外妖气化作无数痛苦妖异面孔，生灭周而复始。
3. **第三响**：低喝**「噬魂杀戮第一式」**，无尽痛苦面孔尽数涌入右手，右手闪现刺目蓝芒；右手成掌拍出，**掌未及鼓，掌风已先敲响妖鼓**。四周动容——以掌风敲鼓虽有取巧，却足见噬魂杀戮之强悍。
4. **第四响**：掌风扫过后手掌按上鼓面，第四声紧追第三声，两声几成一道，如奔雷滚滚。

### 代价与结算
- 迅速收手，蹬蹬蹬退出**百丈之外**方稳住身形。
- 面色妖异红润，强行压下一口血气；**右手轻颤、已失去知觉**；**体内妖力耗费八成**，尽数融于噬魂杀戮第一式中。
- 金甲男子唤「四下，妖将于森的帮助者，出列」，于森沉声答：**「我没有帮助者。」**

## 三、看台伏线：玄副帅与黄副帅的赌约

- 众人皆看于森，**唯独玄副帅盯着妖将队列中的王林**，心中自问：「王林，不知你能敲响几下。」
- 黄副帅轻笑挑衅：赌约老夫恐怕要赢了——**玄副帅选中的这名修士只能自己上场，如此必败无疑**（呼应叠加规则：无帮助者极为吃亏）。
- 玄副帅冷哼：「你且拭目以待，此人，绝非你想象的那么简单。」

## 四、墨非登场

- 金甲男子挑选下一人时**首先看向王林，内心冷笑，却偏偏未让王林出场**，转而点名「妖将墨非，出列」。
- 全场议论骤止，目光尽聚一人：铠甲加身、脸戴狰狞面具、黑发随风，步伐不快却**与观者心跳频率相同**，极为诡异。
- 旁观情报：
  - **「妖将墨非，三百年前妖将第一人」**。
  - 常年驻守**边境**；在**火妖郡**人眼中其人头价值不菲。
  - 功法神秘，至今只施展过**「转法」**一式神通；有人确信他**最少可敲五下以上**。
- **地帅**细看后微笑：「此子若再经历一次**龙潭**磨练，可称为副帅之中前三人。」旁边紫袍儒雅中年男子笑问是否动了爱才之心，地帅哈哈点头，并言：**「此子若能敲响六下，那即便没有成为副帅，我也会为他推荐。」**
- 墨非从容走向妖鼓，四周目光随之而动（本片段止于此，结果未出）。

## 五、要点提炼

- 于森立下的标杆：**四响、无帮助者**，且已是其极限（第五下必崩）。
- 规则「叠加」使得**是否有帮助者**成为胜负关键，直接构成对王林（孤身一人）的压力与赌局张力。
- 王林被金甲男子刻意押后并冷笑相待，暗示主持者对其有敌意或另有安排。
- 墨非被高层公开看好（地帅愿以六响为标准举荐），成为本轮最强参照物。

# 天妖城妖鼓试炼：墨非八声 · 王林五声合一

## 一、比试规则与妖鼓
- 副帅选拔第二轮：敲击广场中央的漆黑巨大**妖鼓**，以敲响次数定高下。
- 妖鼓材质被王林辨认为**古妖之皮**：鼓面非平整镜面，布满密密麻麻的细小坑洼与细微脉络，如兽皮；近距离可闻腥气。
- 机制：每敲响一次，都要承受**数倍于攻击的反震之力**；多数人选择远距离虚空敲击以减少反震。
- 门槛：**能敲响六下者，是为天骄**。

## 二、墨非的八声
1. 于十丈外停下，不调息，直接虚空一拳 → 第一声。铠甲狂震、发丝乱舞，身形纹丝不动，面色不改，轻笑“原来，也不是很难”。
2. 每踏出一丈打出一拳，连响至第三声，鼓鸣如远古巨吼，看客中妖力不足者被生生震出内伤。
3. 三声后一股大浪般气息自鼓中扑出，墨非如浪中之岩稳住，评一句“倒也有趣”，继续踏步进击至**第六声**——全场高呼其名，妖帅（天帅除外）与金甲男子皆露赞赏。
4. 第七声透出**铁石杀伐之念**，墨非面色骤变急退，铠甲砰砰粉碎化作飞灰，面色苍白。
5. 第八声：双手掐诀，白芒化作镜面般晶体缠身，一指弹出。结晶瞬溃但卸去大半冲击，墨非仍被震退**百丈**，面具彻底碎裂，强咽鲜血退回妖将人群后闭目打坐。

### 关键伏笔
- 面具碎裂露出英俊面孔，**王林一眼认出：此人相貌与洪牢深处那黑发男子一模一样**。

## 三、帮助者与总分
- 墨非的帮助者：背负大剑的**青衫修士**，人如剑。掐诀虚空一点（一声）、低语拍掌（二声）、抽剑下斩以剑气破开余音阻拦（三声）。
- 其自评：三下轻松，拼命四下，五下必重伤——判断“墨非胜势已定”，不值得为此重伤，主动退回。
- **合计十一下**。要超越需妖将与帮助者各敲六下，众妖将面色阴沉，认为几乎不可能完成。

## 四、各方反应
- **莫厉海**：面色苍白，向王林认输——“王老弟，罢了，这第二轮，我们输了。”
- **石萧 & 陈涛**：陈涛称全盛可敲十下以上，当前服丹只能七下；评墨非“若在我们修真界，此刻可称问鼎之下第一人，问鼎若不到中期，怕也只能一战”。石萧眼露杀机，冷哼。
- **看台议论**：熬迪在妖将中修为只算中等，石萧、墨非、于森、邪炼任一人皆可轻松胜他，故王林杀熬迪不算什么。
- **黄副帅 vs 玄副帅**（赌约延续）：黄副帅催其认输；玄副帅坚称墨非极强、经龙潭洗礼后更强，但仍不如自己选的人。其内心：“墨非只是强罢了，可这王林，他是**可怕**。”见王林微笑时寒意顿生，暗道“当初此人出手时，也是这么笑的”。

## 五、金甲男子的赌约
- 金甲男子点名“你，出列”，王林当场回敬：“我不叫你，我叫王林。”
- **赌注**：
  - 金方：赌王林敲不到五下。王林赢 → 亲自向**妖帝**举荐，保其为妖将；王林输 → 为打伤妖将之事负责，且不得参战、滚出天妖城。
  - 王林拒绝举荐彩头，改口索要——“**我要你，一只手**。”（声如九幽寒风）
  - 金甲男子应下：超过五下给一只手；若敲响十下，两只手也无妨。

## 六、王林敲鼓：五声合一
- 不取远距离虚空敲击，**直接走到鼓下，双脚离地飘空而起，贴身敲击**。
- 触鼓瞬间反震传入体内，全身弥漫**三千多道生之烙印**作三千多道防护笼罩己身。
- 左手拍储物袋取出酒壶，仰头饮酒，笑道：“金甲妖人，你且看好。”
- 第一拳后右拳仅离鼓面**三寸**，连续轰下四拳；四声几乎同时响起并追上第一声，**五声无声合一**，以妖鼓为中心形成声之风暴：
  - 广场大地寸寸断裂，如环形地龙翻滚散开；
  - 天空雷鸣更烈，看台上无数人当场喷血、受严重内伤，数人被震至**假死**。
- **真正震撼全场的是：连续五下，王林身子一动未动。**
- 八名妖帅中除天帅面色平静外，其余七人猛然起身、面露不敢置信；金甲男子面色大变；黄副帅惊呼“这、这不可能”。

## 七、悬念
- 王林尚未停手，赌约中的“十下＝两只手”仍悬。
- 墨非与洪牢黑发男子的同貌之谜未解。
