# 仙逆 第1543章 收我为徒吧

## 一、幽冥兽反噬旧惧

- 王林唤来的幽冥兽一见那疯子，便认出他就是当年那个人，魂内轰轰咆哮，吓得身子发颤。
- 若王林不在，幽冥兽必定疯狂逃遁；但因主子在侧，其性格中的另一面被激发，短暂恐惧后神色转为狰狞，庞大身躯全部幻化，反向疯子冲去。
- 幽冥兽一生都在被别人吓跑，几乎从未体会过吓唬别人的乐趣，此刻心神极为兴奋，连灵魂都振奋起来。
- 两根巨大须子甩动作响，逼近时无意触到疯子，双方各自惊退——兽也怕，人更怕。

## 二、王林设局：假意护主，实为骗术

- 疯子被吓破胆，跌坐在地连声呼救（"小红，快来救我""护驾，护驾"），口不择言。
- 王林一步迈出立于疯子身前，形象在疯子眼中"极为高大"，疯子感激涕零，许诺把小红、小银道、七彩小娘子乃至"后宫佳丽四万"全部相赠。
- **关键机关**：王林抬手前按的同时传出一道神念，幽冥兽虽不解却听从，误以为主子要与自己玩游戏。幽冥兽轻轻一碰，王林即喷血后退——在疯子眼中成了"高人硬扛凶兽"。
- 王林抓着疯子始终"逃不快"，刻意维持极近距离制造持续压迫感。
- 王林两句台词完成心理施压：
  1. 渲染此兽"最喜活活吞人、慢慢咬碎腐蚀，肉身难灭者要被折磨千年万年直至死亡"；
  2. 长叹"可惜我空有一身修为，却没有能发挥出来的神通"。
- 疯子提议"要不你让它吃掉，它饱了说不定就不吃我了"，王林被气笑，反问"你看它那庞大的身子，吃一个，能饱么"。

## 三、三大神通到手

| 神通 | 交出时机 | 备注 |
|---|---|---|
| 焚界古伞（焚界吉伞） | 疯子首次"顿悟"自己会神通时，毫不犹豫全盘托出口诀与一切 | 王林印证后越发凝重：口诀极为准确，正是**当年朱雀之主也只能偷学、未能完整掌握的真正大神通道术** |
| 李族碎天一弓道 | 王林施展焚界古伞后古伞崩溃，称"还是不够" | 疯子紧张下立刻再传弓术口诀 |
| 七彩之术（七彩之枪） | 幽冥兽须子擦身而过的刹那 | 疯子同时声明"其他的我就不能说了，就算是被这大兽吞了，也不能说" |

- 王林当场左手掐诀一挥，百万禁制幻化，偷学而来的焚界古伞现于天地之间；古伞一现幽冥兽即恐惧顿住，但古伞骤然崩溃。
- **设定要点**：此等级别的神通道术非可立即学会之物，需闭关潜修多年、不断明悟，方可真正发挥。

## 四、因果与性格

- 王林眼中歉意渐深却始终隐藏不表；他不愿逼疯子太紧，只因这些神通对他作用太大。
- 心中已然"存了因果"：与疯子的种种虽无耻，但日后必数倍偿还。
- 修道之士一旦决断便不再犹豫，王林即是此类人；疯子之恩牢记于心，绝不会忘，**哪怕日后因此遭遇大难，也会毫不犹豫选择偿还——只因其性格中的四个字：有恩必报**。
- 讽刺呼应：疯子逃跑时高喊"你不是勇士，你是本王的恩人，我哥曾说，有恩就一定要报答，你放心，你死后我会报答的"。

## 五、收场与拜师

- 记住七彩之枪与李族弓道后，王林骤然停步，左手向身后幽冥兽落下，同时把疯子抛向下方大地，右手一挥以浓雾笼罩自己与幽冥兽，遮断疯子视线。
- 轰鸣滔天但未持续太久，一声巨响后雾散，王林一步走出，幽冥兽狰狞地"追"在其后。
- 疯子闭眼引颈待死，久候无事睁眼，只见那令他畏惧的大兽神色亲昵地在王林身边拱来拱去，王林右手轻拍其身。
- 疯子狂热直呼"你把它收服了"，并称"我哥说这宇星大天内高人不少，你一定就是高人之一，此兽能让我如此害怕，估计就算是我哥也收服不了"——**跪求王林收其为徒**。

## 六、留待后续

- 疯子仍保留部分神通未吐露（自称"其他的我就不能说了"）。
- 焚界古伞、李族碎天一弓道、七彩之术三术均需王林日后闭关潜修方能真正掌握。
- 疯子拜师之请，王林尚未作答。
- 疯子屡次提及的"我哥"，被其视为宇星大天中极强者（连此兽都收服不了），身份仍未揭示。
