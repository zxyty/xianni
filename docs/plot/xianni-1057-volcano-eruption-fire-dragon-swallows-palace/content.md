# 仙逆 第八卷 联盟隐秘 第1057章

## 一、火山剧变：宫殿开启即引爆

- 「魔」字消散、宫殿大门打开的刹那，下方成海岩浆剧烈翻滚，如波浪卷天般向上冲击，宛若被一股无法相容的冲击之力推动。
- 高温比之前浓郁无数倍，四周岩石当场碎裂、未及脱落便化为黑气升空。
- 火山口对外狂喷黑烟，成环形扩散遮天蔽日，地表唯余龟裂中流淌的岩浆散发赤红之芒。

## 二、抢入大殿与三重杀机

**争抢次序**
1. 贝罗第一个冲入宫殿，众人随后陆续冲去。
2. 王巍、胡娟认出紫红棺材，掐诀合击使身影透明，越过所有人抢先入殿。
3. 天运子以言语（双唇微张）令红袍老者一顿，借机大袖一甩冲向大殿。
4. 虚空子为最后一个踏入者。

**三重变故**
- **岩浆手臂**：村姑美妇被岩浆内探出的狰狞手臂抓住，火焰弥漫下被生生拖入岩浆。
- **紫红棺材**：岩浆中浮出紫红色棺材，咆哮渐浓；众人入殿刹那棺材崩溃，碎块横扫落在众人身上。
- **红袍老者→火龙**：棺内走出一名全身死气、毫无生机的红袍老者，被天运子止住片刻后自身崩溃，体内咆哮化火海、再化庞大火龙，一口吞噬众人。

## 三、火龙吞殿，王林被卷入

- 粉衣女子（全身环绕雪花）离开岩石欲入大殿，被火龙吞噬，身化晶光吸入龙体。
- 虚空子入殿前猛地转身冷冷盯住王林，尚未出手，火龙已至。
- 火龙庞大到一口吞下整座宫殿；王林被巨大吸力裹挟，与大殿一同被吞。
- 火龙钻回岩浆，岩浆云涌暴升、顺火山口喷发，落下化作燃烧火团轰击大地。喷发止息后岩浆重归山底，**大殿就此失踪**。

## 四、岩浆深处：王林的意外机缘

- 大殿实处于成海岩浆的**最深处**，四面皆岩浆，殿内亦可感受浓浓高温。
- 王林现身殿外远处岩浆中：高温不但未伤他，反而**缓解体内伤势**；身上**朱雀图腾**散发赤红之芒，回荡朱雀之音。
- 王林盘膝下沉至岩浆底，距宫殿约**千丈**，掐诀吸收浓郁火属性元力，全身红润，元力运转不但无滞留反而更为精进。
- 判断此等浓郁火元力之地极难再遇，遂不急于离去，继续打坐吸收。
- **三次苏醒**：每次皆因岩浆剧烈波动引发火山爆发；他都仔细观察爆发全过程，爆发毕再入定。
- **第四次苏醒**：岩浆虽仍有无数火元力，但因吸收日久隐约与岩浆融为一体，察觉其中另有一个**奇异之灵**——按其分析即是吞噬一切的那头火龙；恐惊扰之，遂停止吸收。

## 五、气泡相遇：粉衣女子与濒死的村姑美妇

- 王林起身走向大殿，途中见殿门外有一**气泡**缓缓靠近，泡内正是被吞噬的粉衣女子与村姑美妇。
- **村姑美妇**：昏迷不醒，全身红斑，状若「悬死阶段」，体内诡异地充满火焰之力，无法救醒。
- **粉衣女子**：体外雪花已消失，改为眉心一枚雪花痕迹散发清凉，赖此在气泡内存活；靠其**师姐所送法宝**护身，已在岩浆中艰难跋涉**数月**方寻至大殿。
- 见王林在岩浆中如履平地且毫发无伤，粉衣女子惊骇：「难怪那些人对于当年的四圣宗如此忌惮，没想到这朱雀觉醒之后，此人竟然对于火焰，有了如此可怕的抵抗之力。」
- 她推测王林是来杀村姑美妇（王林与村姑美妇一行有过节），急操气泡加速冲向大殿，气泡因此不稳几欲崩溃。
- 王林神色冷漠，一步步逼近至不足数十丈。粉衣女子大喊：**「王林，虚空子与你有仇，但我二人却是与你没有任何仇隙。」**

## 六、悬念与看点

- 大殿被火龙吞入岩浆最深处，众夺宝者被打散，殿内格局重新洗牌。
- 火龙作为岩浆中的「奇异之灵」尚未正面交锋，是后续最大威胁。
- 王林借岩浆火元力伤势得缓、修为精进，并再度印证朱雀觉醒的抗火之能与四圣宗渊源。
- 王林与粉衣女子、村姑美妇的对峙尚未落定。
