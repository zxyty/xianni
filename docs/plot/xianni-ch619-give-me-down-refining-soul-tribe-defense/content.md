# 第619章 给我下来！

## 一、来犯：修士联盟小队抵达炼魂部落

修士联盟一行人踏清风迎白云直奔炼魂部落。远方是连绵不绝的**黑雾**——雾气浓到视线不可及，神识探入立刻被生生震退，稍有不慎会被其内魂魄吞噬；雾中不断传出尖锐呼啸，震慑人心。黑雾密布方圆数百里，足以让绝大部分人止步。

领队的**金衣男子**面色阴沉，冷哼断言：王林所在之处不过这一道防护，破之则此子手到擒来。

### 队伍构成
- 连同孙云山在内**不足二十人**。
- 修为大都**婴变初期**，几人**婴变中期**。
- **婴变后期**仅一人：一路沉默的「风师叔」。
- 队伍最后另有一名**仙卫黑衣男子**压阵，修为高深。

## 二、内情：孙云山的处境（视角披露）

孙云山眼中一丝嘲讽——此事他从妹妹处知晓一些：**老祖派出一个仙卫擒拿王林**，各小队都认为十拿九稳，纷纷抢夺立功机会；使者转述的「黑雾厉害」这一警告被众人无视。

- **风师叔**：孙云山父亲的同门师弟，此次入妖灵之地的目的是保护孙云山；如今已被**老祖以秘法抹去记忆，成为傀儡**（队中代号「三号」）。
- **孙云山本人**：被老祖**种下仙种**，生死不由己。
- 起因：妹妹暗中跟来，最终致他落到这般下场。

## 三、试探：两人葬于黑雾

1. **十号**（婴变初期）奉命破雾。他面色难看、不敢反抗，接近黑雾时压迫元神的力量越发浓郁，呼啸声如音波神通般冲出；在**千丈外**便无法前行，直觉执意飞入必死无疑。
2. 金衣男子喝斥抗命，十号苦笑长叹（「这人不像人的生活，也该有个终结了」），一步冲出、转眼越过千丈。黑雾骤动，惊天咆哮传出，幻化成**吞吐天地的大口**，一口将其吞下、丝毫不剩。黑雾如怒浪翻滚、蘑菇状向外膨胀，呼啸更烈。联盟众人虽远，却如身临其境，汗湿衣衫。
3. 仙卫黑衣男子在此刻双目爆出精芒，细看黑雾后**露出疑惑**。
4. 金衣男子再指老者：「**三号**，你去。」风师叔表情呆滞、无言前行，至黑雾前百丈时，黑雾加速膨胀、从中分开一条空白道路；他被飞出的一股黑雾一卷包住，不见踪影。孙云山捏拳，心在淌血、双目发红。

## 四、请君入瓮：十三引路

黑雾分道处走出一名**神色冷峻的青年——十三**，冷目扫过老者与联盟众人，平淡传话：「我家老祖，有请各位。」

金衣男子命三号杀他，三号刚要接近即被黑雾卷走（见上）。十三伸手作请，转身而回。金衣男子回头看了眼后方的黑衣男子，内心略安，冷笑入内。众人顺道飞入，**身后道路被黑雾渐渐吞噬**。

## 五、部落对峙与天魔音

入内所见：一个庞大的部落，族人尽数抬头冷视来客；地面正中有**十里空白地**，中心**一座高塔**耸立，威严徐徐散出笼罩天地，众人几乎喘不过气。

十三于空白界外禀报：「老祖，客人带到。」

王林的声音自高塔内传出：「各位道友带着杀机而来，可是王某有所得罪？」——语气谦虚，声音却带魔力，弥漫整个炼魂部落。

- **天魔音**：王林在不断加深**散魔烙印**的过程中已渐掌握一些。音随声传，除仙卫外联盟众人瞬间魔音灌耳。
- 仙卫因修为高深未太过迷失，双目精芒爆闪直盯宝塔，**再次露出惊疑不定之色**。
- 金衣男子元神震动、双眼迷茫，不由自主答「没有得罪」。
- 王林阴森接话：「既如此，你们来寻王某麻烦，也未免太过放肆。」
- **全族齐喝「放肆」**：炼魂部落所有族人心神相引齐声怒喝，与天空黑雾内魂魄呼啸融合，比奔雷更烈；落在联盟众人耳中如利剑穿心，耳中嗡鸣、元神颤动，修为较低者口角流血、内府受震伤及元神。同时这一喝也让众人**清醒过来**。

孙云山则激动远超震撼，心中呐喊：「是他，真的是他！」（认出王林）

## 六、高潮：「给我下来」

金衣男子退后数丈，尖声令「仙卫，出手」。

- 黑衣男子双目精芒爆闪，一步跨越距离直抵**十里空白的高塔上空**，右手掐诀向下一拍，化作**金光闪闪的大印**，如拔山之力迅猛撞向宝塔。
- 王林自塔中走出，**看都不看天空**，右手闪烁黑芒抬手下抓，平淡道：「**给我下来。**」
- 金光大印出现裂纹、咔咔崩溃；黑衣男子面色瞬息大变、**眼中首次露出骇然**，欲避不得，被一股**好似可以吸收生机的力量**抓住，从天空狠狠拽下，轰然砸在地上。

## 七、要点提炼

- 王林方的三层防线依次展示：**黑雾魂阵（吞人）→ 全族心神齐喝（伤元神）→ 王林本人一抓（压制仙卫）**。
- 联盟方的轻敌与内部残酷（仙种、抹忆傀儡、编号化的「十号/三号」）被同章并列呈现。
- 仙卫三次情绪变化标记其判断失误：看黑雾**疑惑** → 见宝塔**惊疑不定** → 被抓落**骇然**。

## 八、章节小结

本章为炼魂部落守御战的开场：修士联盟自恃仙卫而来，反被王林以魂雾、天魔音与部落之势层层碾压，末尾以王林一抓拽落仙卫作结，正面确立王林在妖灵之地作为「老祖」的绝对威慑。
