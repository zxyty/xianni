# 仙逆 第八卷 联盟隐秘 第1131章 — 冰封血龙与虚无之地的岁月之力

## 一、尸阴宗八王 vs 血龙
- **对撞**：血龙冲来之际，尸阴宗八王以印决操控冰球带阴寒之气迎击。冰球撞上血龙头部即刻碎裂成八份玄冰爆开，爆开瞬间喷出一股至强冲击，正中血龙头颅。
- **血龙重创**：血龙怒吼含痛，庞大身躯一颤后疯狂后退。其身由血海组成、通体赤红，此刻身外幽光环绕，咔咔作响，仿佛要被彻底冰封，一路疾遁。
- **八王现身与换体**：八块玄冰逐一融化，露出尸阴宗八王。第七块玄冰内的中年男子喷出鲜血，眉心生出裂缝并瞬间贯穿全身，肉身崩溃，只余一缕寒气化作人形，言：“这具身体，无法承受刚才之力”。
- **紫纹棺材换体**：八王中一名老者虚空一抓，从储物裂缝取出雕刻紫色花纹的棺材。寒气人影穿透棺材入内，片刻后棺盖弹飞，一个七八岁童子自棺中坐起，活动身子并向七人点头——完成换体。
- **追击令**：取棺老者斩钉截铁道“追”，八人尽化长虹，直奔血龙逃走方向。

## 二、王林在虚无之地的遭遇
- **循迹扑空**：王林循血光波纹赶到波纹传来之地，一无所获，唯余可怕的天地波动残余之力，显示此前有过极为激烈的神通之战。
- **熟悉的震动**：刚离开不远，虚无之地骤然无边扩散地震动。王林清楚记得，**当年拓森走出血海的一刻，此地也正是如此震动**。
- **上百道气息**：震动消失后，虚无之地多出上百道极为强大的气息。王林头皮发麻，全速远遁。
- **判断**：他断定血海世界已经打开、大量上古炼气士走出；这些上古炼气士的修为比他当年所遇“天地之差”，本不合情理，但联系拓森的存在便不再是他可思考之事。心中念头：“拓森，应该快要走出来了。”

## 三、三名上古炼气士的追杀与反杀
- **来敌**：三道红影，皆上古炼气士——两人修为相当于**净涅初期**，为首红衣老者为**净涅后期大圆满**，距碎涅仅一步。
- **黄色纸符**：王林从储物裂缝取出黄色纸符贴胸，旋风冲天，化残影前冲，距离迅速拉开；但三人以某种方法提速，短时间紧跟不舍。
- **决意速战**：王林虑及若再撞上其他上古炼气士将遭夹击，遂停身反击。
- **布置山崩**：转身掐诀，体外虚幻火山之影回荡，与仙力融合后火山几近成真，随即袖子一挥尽数隐去——实为**预设**：无论敌人在何处，只要进入百丈便触发山崩仙术。自语“此地危险，速战速决”。
- **一字“定”**：对当先的净涅圆满红衣老者抬手一指喝“定”，天地规则降临，无数细丝缠身，老者身形一顿。王林仅净涅初期，施展定身术遭反噬，但可压下，随即后退。
- **“山”与“崩”**：身后两名净涅初期老者抢入百丈，王林掐诀喝“山”，两座火山轰然而出；不给机会再低吼“崩”，火山崩溃、岩浆倾泻并爆开成毁天灭地的冲击，二老全身狼狈、喷血后退。山崩之威足令王林在同阶中占据绝大优势。
- **斩杀一人**：王林一步化流光出现在一名老者身后，右手双指成剑如流星点其眉心；该老者本已重创，肉身轰然崩溃化血肉消散。**临死前嘴角露出解脱的微笑**——王林见之双目一凝。

## 四、血龙折返与分身受伤
- **危机感**：王林正欲了结另一人，骤生强烈危机感，以不可思议的角度斜着瞬移而退。
- **横扫**：被尸阴宗八王重创的血龙呼啸而来，全身已有一小半化为蓝冰，速度反而更快，自王林身边横扫而过。狂风扑面使王林身子颤抖闪出，体内咔咔作响，胸口出现一道裂缝——**受伤的是石头所化的分身**。
- **两敌消失**：血龙远去后，被定身的净涅圆满老者与山崩重伤的净涅初期修士皆失去身影。
- **判断与规避**：王林推断血龙受伤逃遁，其后必有追击者，不愿无准备遭遇，遂全速远离。

## 五、八王掠过与王林尾随
- 王林后退不久，八道长虹呼啸掠过，直追血龙。其中一道长虹内一名**桀骜的中年男子**遥遥看了王林一眼、轻咦一声，未作停顿，转眼与其余七道长虹消失于虚无尽头。
- 王林从储物裂缝取出**速符兽皮**贴胸前冲，速度再次达到其**一千多年修道的巅峰**，遥遥跟去。他隐约感觉：**拓森就要出现了**。

## 六、血龙至虚无之地中心：岁月之力
- 血龙一路怒吼咆哮，身体已有一半化为冰晶，蔓延的蓝光令它极为愤怒。
- 它以最快速度抵达**虚无之地的正中心**，盘身而卧，口中缓缓传出**古之语言**，一股沧桑气息环绕四周。
- 血龙蓦然张开大口向上惊天咆哮，一股**岁月之力**自口中喷出，瞬间笼罩整个虚无之地。
