# 第八卷 联盟隐秘 第1090章 墨智再现

## 一、背景补充：四圣宗与昆虚之境的古老渊源

- 四圣宗源远流长，**仙界尚未崩溃时就已存在**。
- 虽以雨仙界为尊，但全盛时期四大圣皇皆在，即便雨仙界也要给几分薄面；无论哪一宗新皇出现，仙界都会送来贺礼。
- 那个时代**尚无修真联盟**，只有**昆虚之境**——雨仙界的直属一脉，负责为仙界掌控下界一切炼气士。
- 因四圣宗强悍，加上一些特殊原因，雨仙界允许**昆虚星域内四圣宗与昆虚之境同时存在**。
- 历任圣皇出现都会引起磅礴的元力变化，对大神通修士而言清晰可查。

## 二、触发事件：王林九玄第一变成功

王林**九玄第一变**成功，天地元力以**朱雀圣宗**为中心向四周波动而去，渐渐回荡整个**联盟星域**。这一波动成为本章各方反应的引线。

## 三、各方反应

### 1. 罗天·雷神殿（联盟星域西、北两大区域）

- 罗天已**成功吞并联盟星域西、北两大区域**，雷神殿成为此地最高掌控者，处处可见雷神殿使者身影。
- **数百座**如小山般的黑色大殿漂浮星空缓缓前行，殿外凝聚大量罗天修士，连绵如大军，**前行方向正是中央位置的联盟各个势力**。
- 修士虽多却悄无人声，唯有飞剑呼啸；经年战斗后稚嫩尽去，代之以萧杀。
- 普通罗天修士修为不足，难以察觉元力细微变化。
- 后方一座近**十座大殿大小**的磅礴宫殿内，**炎雷子**猛然睁眼，殿中十余名老者同时目光精光爆闪。
  - 一老者判断：波动来自**联盟星域东部**。
  - 有人猜测东部有重宝出世。
  - 炎雷子否定重宝之说：联盟东部是四圣宗范围，**莫非有新圣皇出现**；因离开联盟太久，他无法完全确定。
  - **红发老者**倨傲不屑：四圣宗连修真联盟都不如，罗天大军逼压之下定会崩溃。
  - 炎雷子瞥其一眼，沉声反驳四圣宗绝非如此，并**隐隐生出一丝玄妙而清晰的不安**。

### 2. 黑衣老者（自联盟西部与罗天入口踏出）

- 一名黑衣老者自**联盟西部与罗天的入口**一步踏出，抬头远望，目光仿佛可穿透整个星域。
- 由波动中蕴含的**一丝火元**判断：新皇当是**朱雀圣皇**。
- 自语："这场戏，会更有意思一些——**无极子**，老夫就不信，这联盟星域乱成这样，你，还不出现"。
- 章名"墨智再现"暗示此人身份指向墨智（本片段文本未明写其名，故仅作提示，不作断言）。

### 3. 尸阴宗（联盟星域南部）

- 宗内深处有一座**巨大黑色棺木**，八角以铁链与另一具棺木相连；此地棺木众多，密布如蛛网。
- 棺木群外围环绕着**一颗颗以未知神通挪移而来的修真星**，层层环绕。
- 波纹传来，最深处黑色棺材中传出轻咦："四圣宗在这个时刻出现了新的圣皇，有意思。"
- 其声一出，四周所有棺木同时响起**指甲摩擦棺盖之声**，闻之如心神撕裂，四周星空甚至出现裂缝。

### 4. 修真联盟四大势力

- 四方势力同样感受到波动。
- 其中最大一方为**原八级修真国出云国**，掌控数十个星球，环绕成一个**阵法图案**。

## 四、格局要点

| 区域 | 掌控者 | 状态 |
|---|---|---|
| 联盟星域西、北 | 罗天·雷神殿 | 已吞并，大军向中央推进 |
| 联盟星域东 | 四圣宗（朱雀圣宗等） | 新圣皇诞生 |
| 联盟星域南 | 尸阴宗 | 棺木群深处有存在苏醒关注 |
| 联盟中央 | 修真联盟四大势力（最大者出云国） | 罗天进军目标 |

## 五、伏笔

- 炎雷子的**不安**预示朱雀新圣皇（王林）将成为罗天大计的变数。
- 黑衣老者点名**无极子**，意在借联盟大乱逼其现身。
- 尸阴宗棺中存在被惊动，联盟南部势力亦将入局。

# 王林继任朱雀圣宗圣皇：三宝传承与出云宗的贺礼

## 一、出云宗一线：白发老者与墨智

- **地点**：出云国主星之上的出云宗，后山密室。出云宗为整个出云国的霸主。
- **人物**：密室中盘膝的白发老者，慈眉善目、极为慈祥；在天地波纹回荡中睁眼，唤出弟子「墨智」。
- **墨智出场**：老者话音方落，身前虚空即现波纹，一个身穿青布卦衣的光头汉子自波纹中一步走出，抱拳道「墨智见过师尊」。

### 贺礼清单（贺四圣宗新圣皇）

| 物品 | 数量/说明 |
| --- | --- |
| 极品仙丹 | 五粒 |
| 寻常仙丹 | 一百 |
| 仙宝 | 千件 |
| 精魂 | 一头，老者五年前炼化 |

- 墨智对「那精魂」欲言又止，最终点头。
- 老者解释：精魂极为贵重，但**出云国的贺礼必须有此物**；他并已推算出**墨智与新任圣皇有故交**，此次交好圣皇「对于我出云国来说，极为重要」。
- 墨智一生朋友甚少，闻「故交」二字心生疑惑，却没有多问，后退告辞。

> 伏笔：墨智与新圣皇（王林）的「故交」关系尚未点明，是后续可能的旧识重逢线。

## 二、朱雀圣宗一线：三宝传承

- **场面**：四圣宗范围内一道道身影疾驰直奔朱雀圣宗；朱雀圣宗火焰滔天，「圣皇」之声此起彼伏，达到巅峰。
- 王林深吸一口气，抬头望着前方雷火弥漫的星空；身后不远处的朱雀圣皇（老圣皇）眼露激动：「好，我朱雀圣宗，终于有了新圣皇，老夫可以含笑而走。」
- 老圣皇右手虚空一抓，前方裂缝出现，飞出三道流光。

### 圣皇三宝

1. **历代圣皇之披风**
   - 白色披风，其上九条朱雀缠绕，威严散出。
   - 老圣皇于**天人第三衰**时脱下，本以为再无穿上之日，今日传于王林。
   - 王林右手一碰，流光弥漫全身，披风即穿于身上；其上有仿若已存在永恒岁月的沧桑感。
2. **朱雀圣灵**
   - 朱雀圣宗历任圣皇的**身份所在**（身份令牌）。
   - 巴掌大小的火焰形状令牌，握住刹那即传出阵阵火元力，亦有与披风一般的岁月沧桑。
3. **太古圣器**
   - 朱雀圣宗最重要之物，化作一块白色石块。
   - 石块内有**数之不尽的印记**不断闪烁，每闪烁一下石块上的炙热便强大一丝，印记仿佛恒古以来从未停止。
   - **关键线索**：王林在其上隐约感受到一丝与「**天逆**」相似的气息——气息很淡但真实存在，若非亲手握住极难察觉。王林心神因此掀起风暴、双目凝重。

- 老圣皇补充：**青霖肉身眉心上还有「圣器之血」，王林可随时取下。**
- 三样物品为朱雀圣宗**第一任圣皇**留下之物，唯有历代圣皇才可传承。

### 继位与告别

- 老圣皇肉身已萎靡，仅仅起身便痛苦更浓，但激动与欣慰让他忘却疼痛。
- 他招手唤王林近前，右手放在王林天灵：「从今天起，你，就是圣皇。去吧，去见见你的族人。老夫要进行此生最后一次打坐，七天后，你回来见我。」
- 王林张口欲言，最终只是点头，深深看了老者一眼，转身远去。
- **此刻王林形象**：白色长发、赤红色铠甲、白色披风、白色朱雀图腾，形成极为特殊的气质。
- 老者带着欣慰闭目吐纳，开始「此生最后一次打坐」。

## 三、要点与待续

- 王林正式取得朱雀圣宗圣皇的**法统三件套**（披风 / 朱雀圣灵 / 太古圣器），身份完成从「候选」到「圣皇」的确立。
- **太古圣器 ↔ 天逆** 的气息关联，是本片段最重要的设定钩子。
- **七日之约**：七天后王林回来见老圣皇，老圣皇「最后一次打坐」暗示其大限将至。
- **圣器之血**尚在青霖肉身眉心，是一件待取之物。
- 出云宗贺礼车队（含贵重精魂）与墨智即将抵达，与王林的「故交」身份待揭。

> 归属说明：本片段中「圣皇」的新任者即王林本人（王林别名铁柱）；据世界状态须知，旧「圣皇」已于第1006章死亡语境中标记，此处出场的「朱雀圣皇/老圣皇」为传位后即将坐化的前任圣皇，其言行独立记录。
