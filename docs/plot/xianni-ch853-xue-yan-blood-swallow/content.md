# 仙逆 第七卷 名震罗天 · 第853章 血燕

## 一、场景与背景
- 地点：罗天南域星空，王林渡劫处。大片劫云弥漫，万丈星空尽入天劫范围。
- 天劫烈度：本次天劫蕴含的天威与毁灭气息**超过之前的几次**。
- 波及范围：罗天南域内凡拥有大神通的修士几乎都隐约察觉天地之力暴虐波动，且这波动仿佛能操控其体内元力，众修士纷纷盘膝打坐、封锁体内元力。
- 关键限制：**天劫临身，无法瞬移、无法融入天地之间**——王林失去遁走手段，只能以肉身速度疯狂后退。

## 二、血神子登场
- 姚云眉心妖文忽明忽暗，狰狞与青筋渐平，双目转为迷茫，眼底深处却隐藏疯狂挣扎。
- 血神子自姚云身前的红芒中走出：血衣大袍松散、红发无风自动、面色沧桑、隐含一丝妖异之色，身份为**姚家老祖**。
- 现身即随手向身后一挥，姚云眉心妖文骤然浓郁，姚云身躯剧震，眼中挣扎彻底消散——**血神子以妖文压制姚云神智**。

## 三、言出法随：规则之力
血神子开口索要：「把你从望月体内取出之物，给我」。
- 其声化作惊天之雷，形成雷爆，四周天地剧烈晃动，连天空劫云都为之退缩。
- 声中蕴含**规则之力**，可在瞬息间改变四周万丈的规则，使一切必须符合其心意，否则崩溃——「仿佛在这万丈内，血神子便是真仙」。
- 王林辨认出这是**言出法随**神通，且修炼到骇人程度；他看不懂改变规则的力量，只清晰感到相当于成千上万个斩罗诀同时挥出的可怕。
- 结果：一句话之下，王林身外**古神大鼎**自动浮现护体，仍喷出一大口鲜血、面色苍白。

### 王林的判断
> 「这血神子身上，定然有伤，古神幼子碎星之击，此人绝不可能如此短的时间内便恢复。」

### 口舌交锋
- 王林：「以前辈的身份，对在下出手，未免以大欺小，传出去，姚家之名，一扫千丈。」
- 血神子（冷漠）：「避的过老夫仙术，便算你造化。」

## 四、血燕：可吞噬并反用神通的仙术
血神子右手红光一闪，一道红芒化作**血燕**扑向王林。王林三度出手抵挡：

1. **仙界山石·魂爆**
   - 山石取自**贪狼**之手，其内有**山魂**，抽魂而出威力无穷；此番魂未出而蕴于内自爆，威力更烈。
   - 山石崩溃化作携魂的毁灭风暴与巨大漩涡。
   - 血燕张口一吸，风暴由大变小，**尽数被吞入口中**。
2. **封仙印**
   - 王林张口喷出封仙印，掐诀使其无限变大迎击，化出**数十万金色符文**齐向血燕凝聚。
   - 血燕张口，把先前吞下的山石风暴**重新放出并为己操控**，弥漫身周与金色符文对撞。
   - 王林震惊：「吞噬我的神通尚且寻常，但吞噬之后居然还可以施展而出。」
3. **第三辆射神车 → 五彩蝴蝶**
   - 王林一拍储物袋祭出**第三辆射神车**，化作五彩蝴蝶；蝴蝶现身瞬间**血神子双目猛凝、略一皱眉**（说明其忌惮/认得此物）。
   - 蝴蝶扇翅令血燕顿滞、被迫吸收；再扇则弥漫**五彩之粉**，激得血燕戾鸣直扑。
   - 蝴蝶环绕血燕盘旋、持续洒粉，血燕红光渐暗、终至透出五彩之色，**不再冲击而随蝶飞舞**，在王林四周起伏。
   - 代价：五彩蝴蝶自身光芒同样明显黯淡——**对抗此神通对射神车亦属艰难**。

## 五、断退路与引雷
- 血神子冷哼上前一步，王林身后星空轰然大片撕裂，出现一道**难以跨过的沟壑**，寒风吹出，王林身形一顿。
- 王林寒声：「前辈莫非食言」；血神子阴沉答：「食言，又如何」——**明确毁诺**。
- 同一步之下，血神子将一股天地元力融入劫云：劫云急速凝聚，雷鸣回荡，**红色天雷**降临，一分为二——一半直奔血神子，一半冲向王林。整片星空笼罩雷劫。
- 血神子看都不看雷劫，一步现身王林身前，随意向前一抓：**无任何神通之术，王林却觉无从闪躲**，心神剧震。

## 六、转折：古妖贝罗
危急之际王林低吼：「你可知晓古妖贝罗」
- 血神子身子瞬间一顿，双目爆出浓郁妖异之芒。
- 其**眉心浮现一团疯狂旋转的黑气**，从中钻出一个**头生双角、全身青色、散发妖气的妖物**。
- 妖物一出现，即在王林元神内回荡尖锐之声：**「贝罗在哪」**

> 悬念：血神子体内另有妖物寄身，且与「古妖贝罗」有极深牵连；王林以此暂时止住杀招。

## 七、要点小结
- 血神子核心手段：**言出法随（规则之力）** + **可吞噬并反施他人神通的血燕仙术** + 一步撕裂星空 + 借劫云引雷。
- 血神子弱点线索：身负**古神幼子碎星之击**旧伤，未愈。
- 王林本章消耗：仙界山石（自爆）、封仙印、第三辆射神车、古神大鼎护体、喷血受创。
- 未解：望月体内取出之物为何物；古妖贝罗与血神子眉心青色妖物的关系。
