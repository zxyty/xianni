# 第2033章 皇尊之死！

## 一、九曲与古祖虚影：全族跪拜
- 九曲同出、古祖虚影降临，是古族传说中的画面与曲乐，此刻在道古皇宫奏响。
- 皇宫内十多万族人神色激动，向大殿上方天地间幻化出的古祖虚影齐齐跪拜；其余两族族人亦跪。
- **道古皇尊之父**（断去一臂的皇袍老者）无丝毫犹豫地跪拜，身子颤抖，心中不是激动而是骇然：「即便我皇族历代也从未有人能做到……此人血脉，莫非比我皇族还要精纯？」
- **玄罗**不跪，只抱拳向虚影一拜，眼中恭敬。

## 二、道古皇尊的崩溃
- 道古皇尊目瞪口呆、连连后退至广场，尖声嘶吼「不可能」「朕才是天之骄子、朕才是道古皇尊、朕更是古祖后人」。
- 他反复宣称这是王林弄出的幻境、是假的，喝令族人起身，甚至冲上去踢打十八王之一，呼喝「诸王、不灭将」。
- 全场死寂，无人看他一眼——古族敬畏皇权的根源正是创立吉之三族的古祖，古祖在其心中至高无上；四周跪拜反而逼他不得不承认这一切是真的。

## 三、借古祖之手，赐你一死
- 王林搂着融入**李慕婉残魂**的**宋致**自大殿走出，身形一晃出现在天空，古祖虚影与其重叠，威压惊天动地。
- 王林低头，古祖虚影同低头；同样的银色双目看向道古皇尊，其嘶吼戛然而止。
- 道古皇尊哀求：「我是你的后人，我没有背叛古族，你不能杀我。」
- 王林抬右手，古祖虚影同抬巨手；王林虚空一指，虚影巨手随之指下。
- 王林开口（虚影出现后第一次开口）：**「烨道王某借古祖之手，赐你一死。」** 银线自古祖右手射出。
- 道古皇尊绝望求救：「古道大天尊救我、父尊救我、祖尊救我、国师救我！」

### 地底的旁观者
- 皇宫地底一间符文封印密室内，**紫色棺木**中躺着一位形如骷髅、身着皇袍的老妪，猛然睁眼，露出忌惮与犹豫，最终没有现身。
- 道古皇尊身外紫光一闪护体，触及银线立刻崩溃成紫色光片倒卷，银线直穿其胸心。

### 结果
- 头颅轰然爆开，身体碎裂为无数碎块并持续崩溃、彻底瓦解；**灵魂亦被生生抹去**。
- 一代道古皇尊在自家皇宫、在族人众目睽睽下死亡。
- 其父曾有挣扎，但不敢救、也无法在古祖一指下救人。
- 一指过后，王林面色隐隐苍白，古祖虚影渐渐消散。

## 四、真凶指向：道古一脉神秘国师
- 王林判定：致使婉儿之魂如此波折的罪魁祸首**不是道古皇尊，而是道古一脉的神秘国师**。
- 依据来自**大魂门老祖的推衍玉简**：
  - 是国师从**洞府界**取走李慕婉的命魂；
  - 是国师将此魂交给道古皇尊；
  - 是国师令其不断选择妃子、挑选可以融魂之人。
  - 道古皇尊只是被迷惑，沦为国师某种计划的一部分。
- 该国师全身缭绕**王林所熟悉的七彩之芒**；王林心中已有猜测，欲亲自去看此人「是否就是那个人」。

## 五、古祖一指劈荒山
- 王林神识找不到国师，但在诛杀皇尊的瞬间，借**魂血燃烧 + 九曲回旋 + 古祖之影**，感受到皇尊身上散出的死气被大地吸走、被城外一处**荒山**吸去。
- 借古祖之影，他感知到荒山内部中空，其内有庞大阵法，阵法中心隐有一个身影——必是国师。
- 趁虚影将散，王林抬手施展从**计都皇子**所赠玉简中习得的**古祖一指**神通；虚影同抬右手一指点出后烟消云散，而这一指实实在在落下。
- 天空之城外的荒山区域被生生分割挤压，山体被穿透劈成两半，露出其内巨大阵法；但荒山骤起**十色光芒**急速闪烁与之对抗，最终一指之力与十色之光一同消散。

## 六、离场受阻
- 王林瞳孔一缩，大袖一甩带宋致直奔天空；**仙祖头颅与仙皇之魂**早被其重新收走。
- 起身欲走之际，皇宫地底传出低吼：**「弑皇之罪，不可饶恕，你必须留下仙皇魂与仙祖头颅！」**

## 七、后续线索
- 王林下一步目标：追查并面对道古一脉神秘国师，验证其是否为心中所猜之人。
- 地底紫棺老妪与地底低吼者的身份、与皇族的关系待明。
- 荒山十色光芒的来历与阵法用途待明。
