# 仙逆 第1469章 传承（一）

> 归属提示：本章「王林」即主角王林（铁柱）；其在幻象中「化身成为道古烨寞」为借势/记忆代入状态，相关咆哮与自称应归到王林并注明代入道古烨寞。

## 一、幻象战场浮现

王林坐于石台座椅之上，眼前展开一场极为真实的当年大战，仿若他踏入岁月、亲眼目睹：

- 石台八方大地轰然震动，数万修士疯狂冲来，掀起风暴直奔石台。
- 其后有十倍不止的更多修士以极快速度不畏死亡地冲来。
- 更远处一座座庞大战车轰隆接近，其上光芒万丈，射出足以毁灭一切的光芒。
- 宫殿上空虚无被撕开巨大裂缝，近百个千丈大小的**古之三族**轰然降临，以神通、肉身之力、法宝力抗数十万修士。
- 裂缝内又降下**八个齐天之高的巨人**，肉身极强，挥臂风雷滚滚，触之者喷血后退乃至肉身崩溃。
- 远处**撑伞修士**低吟，天地扭曲化作镜面，镜中放出**八条万丈巨龙**，龙头冲石台怒吼，欲破开一切吞噬石台。

王林平静而坐，如同当年曾坐在此处之人，一股自信与霸道的气势在体内积累爆发，使他此刻似成了另外一人。

## 二、三式：神、妖、魔

王林借来之势在体内融合，化身当年那个战天踏地的男子，连出三式（口中说出的是陌生的话语）：

1. **「神震，兵修列位」**（隔虚空一拳）
   - 石台八方数万最靠前修士身子轰震，四周凭空生出漩涡，被牵引着从散乱排成一行行整齐列队。
   - 同时内府被震碎、元神被震碎、一切生机被震崩，死气弥漫。
2. **「妖术，烽火成山」**（松拳成掌，随意前挥）
   - 列队数万修士头顶燃起绿色妖火，滚滚烟气升空如狼烟烽火。
   - 狼烟被狂风般横扫，穿透下方数十万修士，在石台八方结成**八座烟山**。
   - 烟山生出无法抵抗的吸摄之力，将数十万修士吸拽吞噬；烟气消散后，八座烟山化为**八座尸山**。
3. **「魔道，生死逆动」**（食指前指）
   - 波纹扩散震动天地：诸多战车内生机肉眼可见地逆转为死气，轰然停止前行、凝固原地。
   - 八条万丈巨龙毫无抵抗之力，体内生机尽变死气，保持身前动作漂浮半空、一动不动。
   - 凡被波纹触及的修士，生机化死气，瞬息亡魂。

## 三、道古之力与齐天头颅

王林喃喃**「神、妖、魔，古道无仙」**，伸出的手指成掌向前轻拍：

- 眉心古神星点急速旋转，由**六星**直接增至**九星**；
- 双目内**十二个星点**同时暴增，旋转下达到**十八星**；
- 即成 **九星古神 / 九星古妖 / 九星古魔**——三族之力刹那融合，化作一股**道古之力**融入右手。

一拍之下，石台上、王林身前化出一个巨大虚影：**只有头颅，单其头颅便与天地齐高**，散发似与整个星空齐寿的沧桑之气，略显模糊、看不清真正样子。头颅张口喷出一道气息，如狂风横扫，所过之处死亡修士身体僵硬并出现**石化**迹象。

## 四、七彩之芒 vs 九封印骨弓

- **撑伞中年文士**轻叹一声，右手撑伞间从伞中扩散**七彩之芒**，七彩如虹交错似一化彩太阳，向四周宣泄，与道古之力对抗，天地颤抖。
- 其身后**始终闭目的黑衣修士**手中现出一张**闪烁九道封印的大弓**：
  - 枝干为骨，首端刻有日月，末端烙印星空，弓弦不知何物组成，散发沧桑气息；
  - 弓中现一根**带九片羽毛的漆黑长箭**，箭杆满是伤痕，似经历无数次战斗、杀死诸多修士，其上凝聚惊天杀气。
- **闭目拉弓，松手目睁**：箭离弦而出，速度震出大地裂缝，风雷滚滚如射日之芒，压倒天地一切声音。
- 此箭穿透七彩之芒、穿透道古头颅所喷毁灭之息、穿透一切，似连星空与时光都无法阻止，惊鸿一闪刺入并**穿透头颅左目**，箭尖挑着一颗鲜血淋淋的左目破开天地与宫殿，直奔虚无，不知去向。

## 五、左目之痛与「道记李广」

- 剧痛自王林心神潮涌，如割裂般要把他的记忆与自身撕开；**王林左目流下鲜血，其左目内借来的九颗妖星轰然崩溃**。
- 脑海浮现之前曾出现过的声音：**「道记李广，射下了我一只左眼，那左眼内，包含了我半生的记忆与对故乡的思念」**。
- 此刻的王林在剧痛下似彻底忘记了自己，**化身成为道古烨寞**，咆哮：**「把我的左眼，还给我」**。

## 六、双修士石化收场

- 随咆哮，头颅虚影所吹气息向前翻滚，**崩溃撑伞男子的七彩之术**，卷落其身：撑伞男子嘴角泛起苦涩，身子渐失一切生机，**连人带伞化为石人**。
- 气息穿透中年男子后落在其身后**射箭之修**身上：此修沉默、闭上双目，身体瞬息化为石人，保持生前动作。
- 其闭目刹那说出**第一句也是最后一句话：「我完成了与你的约定」**。

## 七、要点与待解

- 本章为「传承」序章：王林所见并非单纯幻象，而是可以亲身施为的当年之战，其借势代入使他短暂成为道古烨寞。
- 「道记李广」为射落左目者之名（与射箭黑衣修士的对应关系本章未点破，仅由声音道出）。
- 被射走的左目「包含半生记忆与对故乡的思念」，去向不知——为后续伏笔。
- 撑伞文士与射箭修士之间存在某种「约定」，射箭修士以完成约定作为遗言。
