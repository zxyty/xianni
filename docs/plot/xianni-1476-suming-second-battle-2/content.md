# 第1476章 宿命第二战！（二）

> 第九卷 云海之巅 · 界外古墓 · 宫殿内

## 一、齐天涂司虚影对轰

- 王林与拓森拳头相撞的同时，身后各自的齐天涂司身影亦双拳碰触。
- **拓森之涂司虚影**：狰狞暴虐，全身一震后右臂骤然崩溃并倒卷全身，一步千丈连退四步后轰然崩溃。
- **王林之涂司虚影**：睿智，左臂直接爆开席卷全身，后退三步，全身弥漫细密裂缝后四分五裂爆开。
- 两尊虚幻古神的膨胀撕裂宫殿虚空，咔咔之声自二影之间疾驰而出，化作一道**连接天地的巨大沟壑**。

## 二、两种「以力证道」

| | 拓森 | 王林 |
|---|---|---|
| 手段 | 转瞬连挥**九十九拳**融合为一拳 | 大帝星自**二代朱雀**处感悟的**玄武之术** |
| 理念 | 以力破天、**万力归一**，不讲任何技巧 | 借**反震之力**融入拳内，视对手为水面 |
| 力量构成 | 九十九拳合一 | 自身之力 + 借来的拓森之力 + **座椅下的反震排斥之力** |

- 座椅反震冲入王林体内，顺一拳呼啸而出化作滔天神通——正因这第三股力量，王林面对**八星**的拓森悍然无惧。

### 对轰结果
- 王林：嘴角溢血；座椅现**三道裂缝**；座椅下巨大石台自底部崩溃，转眼崩掉一半、四分五裂。
- 拓森：嘴角流血，半空无处宣泄力道，倒卷连退数百丈，接近虚幻大网。
- 拓森评语：「爽快！单单这以力证道之法，你王林确有资格称为古神。」

## 三、拓森反手驱逐仙妃

- 之前重伤的**风情女子（仙妃）**以神通重新凝聚肉身，循与拓森冥冥中的感应寻至，目睹此战后动杀机，欲入虚幻大网助拓森杀王林。
- 拓森倒退中转身一拳轰向她：「滚开！本神族中之战，外人没有资格参与！」
- 仙妃掐诀化绸带旋转硬扛，喷血后退数步，风情妩媚尽消，转为狰狞凄厉：「拓森，你敢反坑本妃意志！」
- 拓森再轰一拳化风暴，森然道破：**若非要借她疗伤，本神岂能让你操控；这天地间无人有资格操控本神**；斥其为「仙尊的玩物」。
- 拓森双手抓住虚幻大网狠狠一扯，以古神之力将其**再次封死**，仙妃无法进入。
- 转身对王林：「现在，没人能打扰你我这一战。」

## 四、王林的三重危机（息数推进）

### 第三十九息
- 座椅反震已达王林**承受极限**；纵有七星古神恢复之力、体内两道本源急速抵消，也难以坚持。
- 若再继续，**肉身会再次崩溃、彻底死亡**。

### 传承与星点
- 座椅内传承气息随崩溃暴增，被王林疯狂吸收，眉心**第八颗星点的气旋**越来越清晰。
- 身旁前战未毁的**古魔尸体**右目中，魔气疯狂涌入，幻化出**第二、第三、第四颗魔星**。

### 左目之痛与记忆撕裂
- 因当年**李广射下烨寞左眼**，这道古传承不再完整；越吸收传承气息，王林左目越痛、流血，所视天地渐渐模糊，好似左目正在急速失去。
- 关键在于：被射下的道古左目**包含其半生记忆与对故乡的思念**。
- 故王林**半生千年记忆**——对李慕婉的思念、对故乡界内、对朱雀星、对一切人的思绪——都被生生撕裂，似要随左目消散而永恒失去。
- 脑海一遍遍回荡嘶声裂肺的咆哮：**「把我的左眼，还给我！」**

## 五、灭神矛与反击

- 拓森右手向天一握，取出百丈大小的长矛——**涂司王族法器·灭神矛**，倾身全力甩出，闪烁刺目之光、散发浓浓古神气息，如闪电破开天地直奔王林。
- 王林左眼鲜血不断流下染满全身，左目所视世界已模糊大半，记忆撕裂令其面部青筋鼓起。

### 第四十四息
- 座椅反震绝天地而起轰入体内，王林**闭目**，脑海浮现当年道古烨寞在这座椅上挥出的**一拳、一掌、一指**。
- **「神震，兵修列位！」**——身体如呼吸般狠狠一吸，在剧烈反震中七窍流血，却从座椅内吸收到大量传承气息；左手向前轻轻一拳，前方虚空扭曲，波纹以其为中心浩荡而起。
- **第八星筑基**：眉心七颗星点外的第八星气旋赫然凝聚、急速成型。虽距真正成为第八星尚远，但如同修士筑基——**有了筑基，也就有了未来成为八星古神的资格**。
  - 设定：任何星点的最终诞生，都要先气旋成型，再在不断旋转中吸收足够古神之力，方能成星。
- 灭神矛逼近不足十丈，王林头发向后卷动，石台碎块向后急射，厉风扑面。
- **「魔道，生死逆动！」**——王林始终闭目，左手由拳化指，猛地一指点向临近的灭神矛；指尖与矛尖相触刹那，**双眼猛地睁开**。
- 同时其神识轰然爆出，不顾一切冲入身下座椅，在反震之力下神识层层崩溃，仍顺着**座椅与第三层跳动心脏的奇异连接**，直奔那心脏而去。

## 六、作者按语（卷末说明）

- 界外以**宿命第一战**开篇，界外结束之时也以**宿命之战**为终；次日起**第十卷「叱咤界内」**开始。
- 释疑「为何已到界外仍是第九卷云海之巅」：大纲中「云海之巅」分两部分——**上部「云海」**为云海星域的一切，**下部「之巅」**为进入界外、成为巅峰。
- 本卷要点：云海的构架与战前因果、界外「井中捞月」的隐晦与最终恍然、古墓传承之重，以及「一吼之力」等前后连贯的细节伏笔。
- **悬念**：古墓内「那之前少了一个的存在」是谁？（猜中没奖）
