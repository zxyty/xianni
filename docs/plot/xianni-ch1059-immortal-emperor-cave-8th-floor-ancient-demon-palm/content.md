# 仙逆 第1059章（第八卷 联盟隐秘·四更）

## 一、承接：处置粉衣女子（村姑美妇）
- 搜记忆后粉衣女子面色苍白、香汗虚弱，但伤害不大，调息可复。
- 王林由此对**昆虚圣女**心中已有想要的答案（虽不完全，凭心智与了解看出问题所在）。
- 处置手段（王林一贯的冷硬风格）：
  - 未杀之，但在搜魂时**毁掉其知晓王林隐秘的一切记忆**；
  - **暗中留下禁制**，若再纠缠不休即引发禁制，令其心神崩溃。
- 王林在大殿内寻到开启之处，留话「开启此阵法，你二人可以进入第八层，好自为之」，随即启动传送阵离去。

## 二、仙帝洞府第八层的环境
- 一片漆黑，全被**黑雾**笼罩；**神识无法散开**，看不到远处端倪。
- 远处不断有轰隆巨响与无数元力波动疯狂回荡，隐约夹杂怒吼——听声似凌天候。

## 三、凌天候的绝境与血祭麒麟
- 凌天候冲出黑雾，极为狼狈：面色苍白、神色惊恐，**胸前一个乌黑掌印**破衣印肤，黑雾不断向掌印涌去。
- 身后一道魔影卷动黑雾化作巨大魔头（古魔）追噬。
- 凌天候的应对：
  1. 喷元神之气、虚空一抓撕开裂缝，放出其**麒麟之兽**（已浑身是伤、鲜血长流）拦截；
  2. 低喝「**血嗜**」，一拍眉心，将**仅剩的两把元神之剑**射向麒麟而非魔头；麒麟悲鸣却不反抗，任其贯体，鲜血弥漫方圆百丈；
  3. 大喝「**兽魂现**」，麒麟身躯崩溃，自体内现出**麒麟之魂**——其咆哮肉耳不闻、唯元神可察，落入王林元神如惊雷；
  4. 掐诀引满地麒麟之血（血中带一丝金色，所过之处黑雾消散大半）尽数凝向魔头。
- 情感刻画：麒麟随其无数年，已是生命中难以分割的一部分，此刻不得不亲手杀之、以血祭魂催化其成长，凌天候双眼血丝、心在滴血。
- 求援：「王林，助我，此地之凶险，绝非一人可以抵抗，容我稍后为你解释」。他逃向此处，正因察觉有人传送进来，且判断**最有资格第一个进来的唯有王林**。

## 四、古魔的特征与禁忌
- 形貌近似**散魔**，但有一点迥异：**左目内有八个星点**，其中七个黯淡，唯一个散发滔天魔气；吃痛时星点急速旋转、魔气更浓。
- 凌天候的两条关键警告：
  - 「一切神通，对于此物没有任何用处，更是会让此物吞噬」；
  - 「这魔掌可以穿透一切防护」——其胸口伤势正是此掌所致。
- 凌天候另出一记：拍储物袋取出**红色小剑**掷出，喝「爆」，自爆形成毁灭性力量冲入魔头体内（心痛低喝，显然是宝物代价）。

## 五、王林出手：古神虚影 → 昆极鞭 → 一掌惊天
1. **古神虚影一拳**：融入黑雾未清晰显露，但古魔身躯剧震、放弃凌天候转身直扑王林——**显然认出了王林的古神气息**。
2. **昆极鞭**：王林心神运转，身后浮现**黑白二气环绕的太极图案**，右手虚空一抓，黑白二气交错化出已**融入道念**的法宝昆极鞭。一抖之下鞭身砰砰作响、**翻起多处皮、露出内里一丝丝金光**；连续横扫抽击，古魔喷洒魔气、尖叫嗜血，终至畏惧连连后退。
3. **古魔化魔掌**：退出数十丈后身体急缩，化作巨大黑色掌印呼啸扑来。
4. **一掌惊天**：王林脑中浮现**当年在雨之仙界感悟出的那一掌**——当年修为不够无法用，如今已是**窥涅巅峰 + 古神肉身**。意念涌入右手，向前一拍：
   - 天地色变，黑雾如遭狂风向四周疯狂退缩；
   - 掌意为「**天上地下唯我独尊**」，前方幻化出几乎遮天蔽地的巨大掌印。

## 六、战果与后续钩子
- 魔掌与掌印相撞，**魔掌轰然崩溃**，古魔重凝现身、骇然欲逃。
- 掌印不散，疯狂横扫前推：
  - 古魔被追上，自体内穿透击碎，凄厉惨叫；
  - **古魔左眼于身碎之际飞出、直奔前方遁走**（明显伏笔，与「八星点」设定相关）；
  - 一路阁楼尽数崩塌，**在黑雾中生生开出一条长通道**；
  - 尽头撞上**第八层中心位置的巨大宫殿**，将其**毁去一半**。
- 宫殿内露出**九十九盏烛台**：此前仅存两盏燃烧，被掌风扫过后**其中一盏剧烈晃动后熄灭**，仅存最后一盏也现熄灭之兆、仍在挣扎。
- 凌天候呆望倒吸口气，不敢置信，对王林心中掀起骇然风暴。
