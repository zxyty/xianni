# 第1809章 杜青的骇然（仙逆 1809）

## 一、清痕遁走
- 地火脉异变已引起注意，王林判断洞府不宜久留。
- 大袖一甩清除洞府内全部禁制；再以火焰将洞府焚烧一丈多深，痕迹尽消。
- 动机：不给追寻者留下「其擅长禁制」的线索——在陌生大陆，多一分神秘即多一分自保。
- 出洞府时天色已白，万里无云；王林化长虹疾驰，转眼飞出万里，速度较此前更快。

## 二、杜青首度追至（王林离去第三天）
- 苍龙宗老祖杜青率长虹一行抵达十万山峦上空，神色阴沉。
- 右手一按，大地钻出约百丈粗细、带火焰的木头手臂，一拳轰碎山峰。
- 判断三天前地火异变处即「那姓王的修士」藏身地，恨已全速仍晚一步。
- 下令就地散开继续搜寻，扬言「他还能逃出天牛洲」，并称此人若躲很难寻找，「看来要请大魂门帮助了」。

## 三、王林的真实动机：地火即大补之物
- 王林并非有意躲避——真要躲，随便寻一远山沉浸十年八年即无后患。
- 离开的主因是发现了壮大火焰本源的大补之物：天牛洲地火。
- 神识散开笼罩大地，估算天牛洲地火支脉「恐怕有数千条不止」。
- 设想：若全部吸收、甚至吸收主脉火焰，火本源能否如在东临池那般凝聚出**本源真身**。

### 与本地大能的路数之别
- 仙罡大陆传统：将地火供奉，获天地之火认可后感悟其本源而成大能，从不敢也不能吞。
- 王林非仙罡大陆之人，火本源非在此地感悟、未获此地火认可，必然存在排斥——如同顺应天意与逆天而行之别。
- 正因这种排斥，王林吞噬地火支脉魂后火本源反而大增。
- 玄罗之言佐证：自古至今从无洞府界之人强行走出进入仙罡大陆，且王林不是投胎于此。
- 王林结论：**仙罡大陆对我而言不是险地，而是宝藏。**

## 四、第二条地火支脉魂之战
- 抵达一片翠绿山峦，表面全无地火痕迹，王林凭火本源感应「看到」地底深处一条巨大火龙闭目沉睡。
- 目光落下刹那火龙睁眼，双目一片火海，隔地怒视，发出常人与一般修士皆不可闻的龙吼（同类火本源间的极度排斥）。
- 王林冷哼：「小小地火支脉魂，也敢对我低吼」，踏落山峰，右手下抓，喝「抽地火之魂」。
- 火海冲天、山峰崩溃，一条头颅千丈的火龙冲出；天空转赤红，大地裂开炎浆流淌。
- 该火龙较前一条更大，火焰之力堪比一个**空灵修**的全力一击。
- 王林正面一拳轰去：自身仅轻微一晃、未退半步，火龙头颅崩溃爆开。
- 火龙头欲于火海中重凝、龙目先成，王林上前一步，左目瞳孔中朱雀幻化冲出，喝「地火支脉魂，还不归位」，将崩溃火海连同整条火龙尽数吸入。

## 五、朱雀壮大与本源真身之路
- 吞噬两条地火支脉魂后，朱雀身躯膨胀至数万丈，飘空似要遮盖苍穹，嘶鸣化作层层波纹扩散。
- 王林踏于朱雀头顶，被火海弥漫，如一片火云掠空前行。
- 火本源再次壮大：此前在洞府界火本源已停滞不变，王林一度误以为那便是大成极限，却总觉缺了什么。
- 转折点是洞府核心「五花八门」内、东临池中的剧变，为他轰开通往更高程度之门——得知火焰本源可化作**本源真身**。
- 本源真身最直观的变化：神通出手不再是一次，而是**双次重叠**，威力远超当前形态。
- 于强者如云的陌生大陆，修为增长最令人振奋；王林继续散开神识寻找下一条地火支脉。

## 六、杜青二度追至与骇然（王林离去两天后）
- 杜青来临更快，落于山峰，神色阴沉中露出震惊。
- 判断：引动地火异变一次两次可称意外，眼下已然三次，显系有意为之，但目的不明。
- 神识深入地底查探后倒吸凉气、面色大变：**地火脉枯萎、地火消散，这条支脉已经死亡**。
- 骇然认知：修士纵有火本源也不敢强行吸收地火，一旦如此极可能引发体内火本源反噬、被天牛洲天地之火排斥；他从未听说有人能吞噬地火脉。
- 悬念：「他到底是怎么做到的，他到底要干什么」。

## 七、时间线（本章内）
1. 王林清痕离开洞府 → 2. 第三天，杜青首度追至并布下搜索、拟请大魂门 → 3. 王林寻得并吞噬第二条地火支脉魂，朱雀膨胀至数万丈 → 4. 两天后，杜青再至并查明地火支脉死亡，骇然。

## 八、待解伏笔
- 大魂门是否入局协助苍龙宗搜捕。
- 王林能否吸收地火主脉、凝聚火焰本源真身。
- 火本源排斥与反噬风险对王林是否真正无害。
