# 第1609章 梦问己

## 一、陌生的回眸

白衣女子（李慕婉容颜）回眸看向王林，目光一扫而过，没有半点熟悉，如看一个完全陌生之人，随即踏风远去。王林怔立目送，直至背影全无。

他由此确认一个反常：

- 梦中所遇之人——周蕊、徐飞、柳眉，以及离开赵国的十九年间所去宗门、所见修士——**均对他有说不出的熟悉之感**；
- **唯独她一人**，毫无熟悉。

王林容颜更苍老，扶枯树睁眼，目中迷茫之外更多是一种复杂的明悟。

## 二、死亡火山：自欺的崩塌

王林在火焚国大地上茫然行走，看不到日出日落，身后不留足迹，日复一日、月复一月，以迷茫掩盖几乎已完全明悟的真相，只余一丝连自己都不信的侥幸。

直至某年某日，他停在一座**死火山**下：

- 地面环形坑洼，黑色碎石弥漫，方圆数百里无人烟；
- 山上两道**如龙蛇纠缠的裂缝**，如生死印记；
- 这正是他**当年在大海上所见虚幻天地中正在爆发的那座山**。

海上的虚幻与眼前的真实重叠融合，化作无形之力冲入王林体内，冲散他五十多年的欺骗，令他第一次真正面对自己与这个天地。

## 三、梦问己：对本尊的诘问

王林指山仰天大笑，笑声悲哀，随后披头散发坐于石上，仿若疯癫，向编织此界的『另一个王林』发问与宣判：

### 1. 世界的真相

- 本尊**吞下三个道果**，以**梦道之术回到两千年前**；
- 以自己的思绪、道果的驳杂道念、梦道之力、自身记忆，**编制了这个世界**；
- 更在梦道中**学习刘金彪的骗道之术，把自己也骗过**，忘记记忆、忘记身处梦中；
- 目的是借三道果之力，**自成一界、自成轮回**，在自己的轮回内编制一次次因果。

### 2. 已被识破的『编制因果』清单

| 编制内容 | 本尊意图 |
|---|---|
| 出现**苏道** | 要遇一大儒，最终明悟天地 |
| 两次遇**柳眉**、柳眉赠丹药 | 斩断与柳眉的因果 |
| 带入**红蝶**之事 | 梦道前听闻，于梦中完成一次因果循环 |
| 带入**炼魂宗念天**往事 | 自以为地完成炼魂宗的因果 |
| 李慕婉对他**全然陌生** | 斩断与李慕婉的因果 |

### 3. 识破的时点

王林自陈：起初确实不知、确实迷茫，但**自遇到疯子那一刻，在火堆熄灭的一瞬，看到疯子右手腕上的手印的一刹那，他就明白了**；此后骗了自己五十多年，今日不愿再骗。

### 4. 两个『王林』的对照

- **本尊**：封界至尊，修为通天，尚未到第三步便可斩三步大能；如今已度过**生死大劫**，正要进军**无上天道**，进入亘古以来三步大能之**空境**。
- **梦中之我**：未曾修道，却感悟天地、明悟道理，一身**浩然之气惊鬼神**，为**当世大儒**。

### 5. 关于李慕婉的拒绝

王林推演本尊三种可能的用意（前世／轮回／梦），指向同一件事——让李慕婉忘记他：

- 不再有那痛苦漫长的等待；
- 不再有无助的寿元断尽；
- 不再有活死人一样的两千年；
- 让她如未遇他之前一般快乐平静地过一生，或另有姻缘道侣。

王林大笑落泪，斥其『完完全全错了』：什么是真、什么是假，本尊没有他明白；**其他因果也就罢了，斩断与李慕婉的因果，他不能接受**，凄厉连问『你舍得让她忘记自己么』『你斩得断么』。

## 四、天怒与漩涡：本尊将醒之兆

王林苍老之声仰天咆哮，天地轰鸣、雷霆闪电连成一片，如同天怒：

- 天空裂开**巨大漩涡**，内为一片无尽漆黑世界；
- 漆黑中有**一缕红芒**，红芒内**两具闭眼尸体**；
- 其中一具**一头白发**，闭着的双眼出现挣扎，仿若被咆哮震动心神、轰击灵魂，**有苏醒之迹象**。

王林右手指天，苍发飘动，**浩然之气**扩散冲入天空，喝道『你既然斩不断，就不要来干涉我，你这所谓的因果，在我看来如同儿戏』。大袖一甩，漩涡急速缩小直至消失，化作一个白点——**一只白色飞鸟**，盘旋许久后飞远。

## 五、收束：三问

『什么是因果，什么是生死，什么是真假，我因这三问而来，这天地间无人能比我更明白。从现在起，道果也好，记忆也好，这虚假的世界也好，不要来干涉我。』

## 归属说明

- 本章白衣女子以李慕婉容颜出现于梦道世界；李慕婉本人已于第188章死亡，此处为梦道所编制之人，行动不计入其本人。
- 本章『梦中的王林（大儒）』与『编制此界的封界至尊王林』为同一人的两端，前者为梦道分身式存在，故以 avatarOf 连接。
