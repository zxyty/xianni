# 第九卷 云海之巅 第1187章 丰收！

## 一、留人「护法」的杀局
- 苍松子对王林（此时以化名「吕子浩」行事）语气一沉，逼其同意由庞姓老者留下「护法」，随后与青衫老妪转身离开洞府，直奔远处如墙般的山脉。
- 临走前青衫老妪余光扫过王林，苍松子亦看了庞姓老者一眼——双方各有默契与算计。
- 庞姓老者转动手中戒指，阴笑着让王林「继续吐纳」，随即以神识放肆扫过确认王林伤势，转身在洞府三间石室内搜刮。

## 二、反杀：出手即杀招
- 庞姓老者搜出宝物后狂喜，回头翻出王林先前所言「话若乱口，恐有杀身之祸」当面嘲弄，认定王林重伤可欺，抬手拍向王林。
  - 他刻意等到苍松子与青衫老妪彻底走远才动手，以免被青衫老妪察觉。
- 王林实则未伤：左手闪电抓住其右手一捏，骨骼咔咔碎裂；随即欺身而上，右拳轰在其胸口，肉身当场爆开。
- 元神尖叫逃遁之际，王林取出**铁剑**一斩，元神一分为二；大袖一挥擒住，捏碎一半化作元力当场**生吞**，另一半近乎透明、不敢逃遁。
- 全程片刻结束，庞姓老者的神通与法宝根本来不及祭出。

## 三、逼降与搜魂
- 王林以「打开储物空间，我不杀你」相胁，庞姓老者元神虚弱、判断拒绝即死，遂开启储物空间。
- 王林铁剑斩断其与储物空间的联系，尽取其物，随后强行施展**搜寻记忆神通**，将尚未死亡的残余元神收入自己储物空间。
- **不杀的理由**：推测「此人与苍松子关系莫逆，说不定有命简在苍松子之手，一旦死亡即被察觉」，虽记忆中未证实，但王林一向谨慎，宁信其有——避免破坏既定计划。

## 四、缴获清单（「丰收」）
| 类别 | 内容 |
| --- | --- |
| 资源 | 仙玉数十万；元晶五六万 |
| 药材 | 大量草药与丹方（此行准备充分） |
| 玉简 | 两张**七彩界地图**（标注路线、可用仙玉喂食取元晶的**化雾凶兽**位置）＋一份离开此地的口诀印记 |
| 洞府所获 | 不少丹药；一把**带封印的短剑** |

## 五、两处疑点与情报
- **司马墨洞府之谎**：搜魂得知此处根本不是司马墨的洞府，只是苍松子随意找的；苍松子从未打算带他去真正洞府。司马墨真正洞府所在，王林现已知晓。
- **苍松子的目的**：庞姓老者亦不知其真正目的，只知「那里封印了众多凶兽之魂」。
- **鹿骨与短剑**：第三间石室地面一具一人大小、具鹿之形的漆黑兽骨，大半已因取剑而化作碎末。短剑封印未开已非凡品，却被刺在鹿身固定于石室内。王林在短剑上察觉一丝**熟悉却想不起来**的不寻常气息，线索不足，暂时收起离去。

## 六、五彩指环解封
- 指环共**九层封印**：庞姓老者已破七层、第八层破了大半，掌握部分操控之力。
- 王林抹去其神识、留下自身印记，以自身禁制造诣掐诀，砰砰声中破开第八层封印。
- 效果：指环散发五彩之芒，化**五道长虹**环绕全身，形成严密防护，**可阻一切神通临近**。
- 王林判断：若庞姓老者事先破开第八层，斩杀他不会如此快捷。

## 七、尾随追击
- 王林遁出洞府，神识不散远、仅环绕己身，凭**一丝奇异感应**在山谷间穿梭——其路线正是苍松子与青衫老妪所走之路。
- 收束语：「王某的散魔铠甲，岂能让你白穿」——暗示先前赠出/被穿的散魔铠甲留有感应手段，可追踪对方。

## 归属提示
- 本章「吕道友／吕子浩」即**王林**（自第1063章起沿用归元宗故人化名，身份由吕烟菲奉上），所有言行归王林。
- 「司马墨」本章仅作为洞府主人被提及，无冒名关系。
