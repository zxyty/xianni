# 第1383章 贪狼（第九卷 云海之巅）

## 一、人物登场：颠落之地的传奇「贪狼」

贪狼来历神秘，最早不知何年出现在**颠落之地**，初现时修为寻常，仅**窥涅**层次。但其人有三大特点：

1. **宝多** —— 从其手中拿出的丹药与法宝，一次次在颠落之地掀起风暴。
2. **油滑谨慎** —— 擅长诡异神通、更有法宝防身，见势不妙毫不犹豫逃离。
3. **遁术惊人** —— 某种逃遁神通一晃之下**速度暴增九十七倍**，寻常修士根本追击不上。

因此即便修为高出他者，想生擒贪狼也极为困难，他也极少真正陷入危机。

## 二、成名三战

### 1. 净涅期反杀碎涅（第一次轰动）

修为稳定增长至**净涅**后，神通更为诡异莫测，引起颠落之地一些族落强者窥伺，遭三名**碎涅**修士联手追杀。

- 众人皆认为贪狼必死，他却祭出众多从未施展的法宝，每一样都有惊天动地的神通；
- 三名碎涅修士猝不及防被伤，**当场被击杀一人**，余下两人重伤逃遁；
- 一名净涅修士反杀碎涅，此事在颠落之地掀起滔天巨浪，贪狼之名由此赫赫。

### 2. 残破雕像灭杀天人第一衰（第二次轰动）

被杀者所属族落震怒。该族虽无**落生会**长老，实力却同样很强，为杀贪狼派出一名修为达**天人第一衰**的大神通修士——时人视之如猛虎踩蚁。

- 贪狼取出一件法宝，后世绝大部分传闻中描述其为**一个残破的雕像**；
- 雕像一出：整个颠落之地轰然，云雾滚滚笼罩星域，一声声仿若传自太古的咆哮惊天动地；
- **天人第一衰修士当场轰然灭绝**。

此力更震惊了颠落之地所有天人衰劫修士——其灭绝之力**足以毁灭第三衰修士**，即便**第四衰**，也须大费周折方可无碍。众人无法想象天地间竟有可让净涅修士催动、却能诛杀天人衰劫的宝物；且无人知晓贪狼身上是否还藏有更强之物。

### 3. 重伤天人第四衰（第三次轰动）

此战后贪狼销声匿迹。传闻**颠落大帝**对其颇为赏识并曾寻访，贪狼趁机献出另一样法宝；大帝收下后，**赐其提高修为的丹药**。

若干年后贪狼再现世人面前，修为已达**碎涅中期**，引起多名天人第四衰修士的高度注意。其中一人暗中贪图其宝物出手抢夺，最终**重伤而退**。自此贪狼之名再度赫赫，再无一人敢打其主意。

## 三、两句流传于颠落之地的评语

- **「贪狼宝多」** —— 法宝层出不穷。
- **「贪狼不去无宝之地」** —— 凡他出现之处必有天材地宝出现；即便是一颗蛮荒星，他若出现，也能从中找出让众人震惊的法宝之物。此为其寻宝天赋。

## 四、逆鳞：元神之内的臭气

贪狼唯一的逆鳞是**身体上的气味**：

- 不知修炼了什么神通，凡其所在之处均臭气熏天，远距离即可清晰闻到，久久不散；
- 凡被人提起、或在其身前露出怪异表情者，都会遭其报复；
- 本章随行的十多名修士虽难以忍受，却丝毫不敢露出异常，神色恭敬。

**关键设定**：这股臭气**存在于元神之内，已与元神融为一体，根深蒂固**。他想了很多办法都无法驱散，且**自己已经闻不到**，只能从旁人表情上一次次受刺激，几乎发狂。

## 五、心境与因果：对王林等人的巅峰之恨

- 贪狼当年**九死一生来到界外**，凭一己之力成就今日：修为远超当年，法宝也在这些年彻底换了一身，其中几样几乎是**用命换来**；
- 他自认早非当年界内的小人物，若能回去，身份必极为尊高；
- 但他从无半点兴奋——身上的臭气如阴影般在心中弥漫不断；
- 这种折磨至今的痛苦，使他对 **王林**、对 **天运子** 等人、对 **望月** 的恨，**已然到了巅峰**。

## 六、本章当下场景

一行人速度极快，不多时远远看到**暗蝎族所在修真星**。贪狼目光如电盯着远处修真星，目中闪过激动。

## 七、待确认线索

- 「残破的雕像」法宝的真实来历与名称未明（仅为传闻描述），是否还有更强之物同样未知。
- 贪狼臭气的成因（所修何种神通）未明，但与王林、天运子、望月三者结怨直接相关，暗示其界内出身与旧事。


# 贪狼的心魔：王林是他的命中克星

## 一、旧恨清算（贪狼的回忆）

本片段为贪狼独处时的内心独白与往事回溯，牵出他与王林、望月、天运子三方的因果。

### 1. 对天运子
- 「若非是你们当年逼我去罗天，我如何能落得那凄惨的下场」——贪狼将自己的悲惨遭遇归因于天运子等人的逼迫。
- 正是这次被逼前往罗天寻找王林，才引出后续被望月吞噬、被王林夺宝的连锁厄运。

### 2. 对望月
- 贪狼被望月吞入排泄之处，饱受折磨。
- 「老夫发誓一定要将其碎尸万段」。
- 望月臭气至今缠身，成为他眼下最急于解决的现实难题（见第三节）。

### 3. 对王林（核心）
- **夺宝**：王林抢走了贪狼「数万年搜集」的全部法宝——挪移大鼎、太古雷龙、山河图、抽魂仙山及种种法宝之物。贪狼一生寻宝，唯独在王林处被搜刮一空。
- **天逆之失**：在朱雀星，贪狼看中的法宝「天逆」，最终在妖灵之地被王林抢走。
- **雷龙之痛**：太古雷龙自幼跟随贪狼长大，却被王林吞噬。贪狼自陈「若是那雷龙还在，我融合之后彻底炼化可成为雷修」——即王林断了他成为雷修的道途。他强调当时「我明明修为高他很多」，结果仍是败局。
- **绝杀之阻**：贪狼将要逃出望月口时，又被王林阻止，导致重伤将死；侥幸逃出后藏在一处修真星才活了下来。

## 二、恐惧的性质：道心裂痕

- 贪狼对王林除恨之外，还有一层浓浓的阴影；数次交手后的**忌惮**随时间推移**演变为恐惧**。
- 关键设定点：**修为提高并未消解这份恐惧，反而越来越浓**，且他自己说不出原因，每次想到王林都心神一颤。
- 文本以「惊弓之鸟」作喻：飞鸟被箭伤几乎濒死，存活后即便更强壮、甚至成为飞鸟之首，听到弓声仍会心颤。
- 定性结论：**这是道心裂痕**。除非贪狼能亲手杀了王林、毁去这个噩梦，否则他一生都是惊弓之鸟。

## 三、现状与谋划（界外·太古星辰·颠落之地）

- **所在**：贪狼身处界外的太古星辰「颠落之地」。
- **实力**：已换了一身法宝，自称修为远超当年，这身法宝「比当年还要强大无数倍」。
- **自我宽慰**：「我就不信，你王林还能从界内冲出，到这太古星辰、到这颠落之地再来抢我的宝物」——他认为这是完全不可能发生的事；「好在老夫所处界外，断然不会与那克星遇到，否则的话，真说不准我这一身法宝又要易主」。（叙事上是典型的反向铺垫）
- **当前目标——驱散望月臭气**：
  1. 云遁族有一件宝物，或可让他全身气味消散；
  2. 此宝**无法从云遁族取走**，故他只能留在云遁族**成为供奉**，直至彻底研究明白；
  3. 目前已研究**十之七八**；
  4. 只需再寻到**暗蝎族**传说中的**万古蝎尸**，便有**九成把握**驱散望月臭气；
  5. 事成之后「天大地大，我随时可走」，便可永远避开克星。

# 第1384、1385章 惊弓之鸟（三、四更合一）

> 视角：王林（自第1063章起长期以化名行事，本片段正文直呼本名）。

## 一、王林尽取龙甲族积蓄

王林离开龙甲族修真星，星空中疾驰而走。他取走了龙甲族全族的积累之物，尽入储物空间：

- **大量龙崩丹**
- **不少炎火异晶**
- **众多傀儡**——其中修为最高的一具已达**天人第一衰**

这些皆是龙甲族一族的积蓄，由**新族长全部献出**（旧族长已受颠落大帝使者惩罚）。

## 二、王林对颠落大帝的推演

行走中王林目光闪烁，一路沉吟与司墨子一战时颠落大帝突然现身、最终赐其**少帝**名号之事。他的疑问与推断分列如下：

### 疑问
- 那大帝与**四圣宗**究竟有无关联？若有，他是谁？
- 若无关联，此人又因什么目的如此待我？
- 且他只送出**玉佩**，并无与我见面的打算——这里面蕴含什么想法？

### 对「五息之约 → 亲手灭杀」的分析
- 大帝起初只说出**五息之约**，这在王林意料之内：他与司墨子一战本就很可能将大帝引出，且**司墨子属追杀而来**，按**颠落之地的规定**必受惩罚、被驱赶出颠落之地。
- 但大帝竟直接**杀死司墨子分身**。若仅是驱赶还好说，出手杀人无疑是一种**表态**——毕竟司墨子是**第三步大能**，这种态度定是**做给长尊会所看**。
- 结论：在那数息之内，大帝**改变了想法**——最初只打算旁观，最后却亲自参与。关键是什么让他改变？

### 王林想到的可能（自承为猜测，未证实）
1. 他身负**五道本源之力**，颠落大帝修为高深，很可能看出；
2. 他最后施展的**炎火异晶**露出了**火焰本源之力**；
3. 若大帝真与四圣宗有关，凭此**一眼便能看出他是朱雀**。

### 对施威与邀约的判断
- 大帝通过**使者之口惩罚龙甲族族长**，是在**给王林施威**。
- 使者最终告知：**三个月后落生会的长老之选**，令王林前去。
- 王林认定此事**透着诡异**，决意「三个月后便去一趟，看看这大帝到底有什么目的」。

随后他收起心思，向前一步迈出，**缩地成寸**之下直奔**暗蝎族修真星**。

## 三、贪狼大军压境暗蝎族修真星

- 贪狼一行速度极快，距暗蝎族修真星已然颇近；**上千道长虹**呼啸，在星空内掀起层层波纹，化作惊天动地的呼啸。
- 片刻后千虹轰然降临，前方**数百修士**势如破竹，直接破开该修真星的**罡风层**直奔下方。
- **贪狼**被众人簇拥、**神色倨傲**地迈步降临。
- 星上异象：天地色变、风云倒卷，天空仿佛被撕开一道巨大裂缝，一道道**剑光**自其内呼啸而出；大地颤抖，似难承受威压。星上所有修士面色大变、露出惊恐之色。

## 四、暗蝎族这一侧

- **暗蝎族新的聚集地，正是王林洞府外围**。
- 此刻**钟大洪**正背着双手、一脸严肃地向几个暗蝎族族人训斥——大难临头而不自知。

## 五、悬念与后续线索

1. **三个月后落生会长老之选**：王林已决定赴会，探明颠落大帝目的（明确的未来时间锚点）。
2. **朱雀身份是否已暴露**：五道本源之力／火焰本源之力是否被大帝看破，尚未证实。
3. **暗蝎族危局**：贪狼大军已至王林洞府外围，而王林正在赶回途中——两线即将交汇。

# 第1297章 云遁族征星、贪狼摆宝与望见王林即逃

## 一、开场：钟大洪训斥暗蝎族
- 钟大洪以“主子（王林）之仆”身份，在暗蝎族修真星上训斥修为高于自己的暗蝎族族人，责其数日探查不出消息，威胁待主子归来问责。
- 章姓老者跟随其后，见暗蝎族高修胆颤心惊而颇为自得。
- 暗蝎族族长此前受王林授意提前返回，此刻正在王林洞府外一处山谷盘膝吐纳。

## 二、云遁族降临：征用此星三月
- 天空波纹如海掀浪，上千剑光长虹自远方疾驰而来，轰鸣惊天。
- 宣告：「云遁族来此寻物，征用此星三月，暗蝎全族，立刻统统离开此地，不得有误」。
- 暗蝎族族长以“暗蝎族虽小，但也是落生会族落之一”抗辩，被一声「聒噪」压下。

## 三、贪狼出手
- 自千修士中走出一人，修为运转即散发浓烈恶臭，暗蝎族族长倒退数步失声唤出「贪狼」。
- 钟大洪修为低、不识其身份，被臭气熏得当场呕吐，触怒贪狼。
- 贪狼一挥巨扇：地面剧震、群峰崩塌，**王林的洞府亦在此击下崩溃**；上百暗蝎族族人喷血倒卷；章姓老者重伤昏迷被抛飞不见踪影。
- 钟大洪被大力卷至贪狼面前，被问「臭么」，只得违心称不臭，还深吸一口作陶醉状，反而再吐一口。

## 四、以主人相胁与贪狼的回应
- 钟大洪求生急吼：我家主人修为通天，暗蝎族族长接不下我家主人一式神通；暗蝎族就因伤我而成主人之奴，你动我必死无疑。
- 贪狼冷笑回应：既然你有主人，「奴才得罪老夫，其主也有过错，犯了我逆鳞之事，都要死」；又言若主仆是暗蝎族人尚不便下手，既非暗蝎族人，便要看看其主如何让自己必死。
- 贪狼送元力入体重伤钟大洪，抛于地面；随后狂风横扫，将暗蝎族族人**全部驱离此修真星**。

## 五、贪狼展宝（云遁族修士围观）
依次取出：
1. 九块沧桑石碑（一出天地色变）
2. 九十九把幻化长剑，环绕掀起滔天剑气
3. 洒下青光生出密林，密林合抱坐起，化为**约万丈高的巨大树人**；贪狼立于树人头顶
4. 撕开巨大裂缝，取出至宝**天皇炉**
5. 黑雾凝成的**长枪**，毁天灭地之力

围观云遁族修士议论要点：
- 贪狼法宝在**颠落之地**传闻最多，法宝之多无人知其全部。
- 传闻其法宝可击杀**天人衰劫**修士。
- 传闻贪狼尚是**净涅**修为时，即以天皇炉在三名**碎涅大圆满**修士追击下反杀一人、重伤余下二人。
- 贪狼自夸：这些只是众多法宝中的一小部分，真正强大者尚未取出，「就算是第三步大能，也远远无法相比」。

作者点明：贪狼享受这种敬畏目光，可借此忘却身上臭气、**当年的屈辱与对王林恐惧的阴影**。

## 六、转折：来人是王林
- 天空波纹中心现出一道修长身影，冷漠之意弥漫天地；贪狼四周法宝轰鸣，已有开启之象，众修士满怀期待。
- 贪狼看清身影刹那身子剧震、瞳孔收缩、揉眼再看，认出正是那「抢夺了他所有法宝、成为噩梦」的王林。
- 记忆闪回：**太古雷龙被抢、挪移大鼎被抢、山河图被抢、抽魂山峰被抢**，所有法宝尽被抢走。
- 内心独白：「他在界内，怎么会出现在界外……克星，他是我的克星，他定是知晓了我换了一身法宝，又来抢夺」。
- 贪狼凄厉尖叫，毫不犹豫向后急退，元力急转使**速度暴增九十多倍**，肉眼难见、神识无法锁定，连已取出的法宝都来不及收便逃之夭夭。
- 四周修士与钟大洪全部愣住，议论“大供奉这是何种神通/是不是在逃”。
- 王林身影自天地内走出，同样愣了一下，道：「贪狼」。
